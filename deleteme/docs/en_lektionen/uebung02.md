# Exercise 2

### Grammar Review: Present Tense (Lat)

## Exercise

A) Translate into English:
1. *Bālāḥ paṭhanti.* = The children read.
2. *Naraḥ pṛcchati.* = The man asks.
3. *Gajāḥ khādanti.* = The elephants eat.

B) Translate into Sanskrit:
1. The teacher speaks. (*Guruḥ vadati.*)
2. They see the forest. (*Vanaṃ paśyanti.*)
3. I go to the village. (*Grāmaṃ gacchāmi.*)
