    Neue Funktion renderPreview():
    - Liest editorInput.value
    - Ruft window.md.render(editorInput.value) auf (window.md = window.buildRenderer() einmalig)
    - Setzt editorPreview.innerHTML = gerendertesHTML

    Initialisierung: window.md wird einmalig nach dem DOM-Load gesetzt:
    window.md = null; // wird lazy bei erstem Editor-Aufruf gesetzt

    In renderPreview(): if (!window.md) { window.md = window.buildRenderer(); }

    Debounce: let editorDebounce = null;
    editorInput.addEventListener('input', () => {
      clearTimeout(editorDebounce);
      editorDebounce = setTimeout(renderPreview, 300);
    });
    (Diese Event-Listener-Registrierung erfolgt einmalig beim Script-Load.)

    ANPASSUNG 3 — loadEditorContent():
    Neue Funktion loadEditorContent():
    - Ermittelt den Markdown-Pfad der aktuell ausgewählten linken Lektion
      (analog zu fetchRaw: baseUrl + leftVal + '.md' für lektionen-Pfade)
    - fetch(url) → text → editorInput.value = text
    - Nach dem Setzen: renderPreview() aufrufen
    - Bei Fehler: editorInput.value = '' (leere Textarea, kein Absturz)
