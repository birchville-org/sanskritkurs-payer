## 41.2. Yderligere ⟪कृत्⟩-dannelser på -a

### 41.2.1. Nutidsparticiple (⟪लडादेशः⟩) Ā, passiv nutidsparticiple (⟪लडादेशः⟩) Passiv, fremtidsparticiple (⟪ऌडादेशः⟩) Ā

#### 41.2.1.1. Tematiske nutidsstammer, passiv og fremtid

::: grammar-box
**Dannelse:**

Nutidsstamme / passivstamme / fremtidsstamm + -māna (fem. mānā)
:::
Eksempler:

⟪यज्⟩ 1U, Nutidspart.Ā ⟪यजमान⟩ 3 "en, der ærer med et offer i sin egen interesse = ofrersherre"

⟪मन्⟩ 4Ā, Nutidspart.Ā  ⟪मन्यमान⟩ 3 "en tænker"

⟪कृ⟩ 8U, Nutidspart.Passiv ⟪क्रियमाण⟩ 3 "noget, der bliver gjort"

⟪दा⟩ 3U, Fremtidspart.Ā ⟪दास्यमान⟩ 3 "en, der vil give i sin egen interesse"

#### 41.2.1.2. Athematiske nutidsklasser

::: grammar-box
**Dannelse:**

Svag nutidsstamme (i den form, den har før endelsen -ate i 3.fl.Ā) + -āna (fem. -ānā)
:::
Eksempler:

::: grammar-box
| Rod / klasse | Nutidspart. Ā |
| :--- | :--- |
| ⟪द्विष्⟩ 2U | ⟪द्विषाण⟩ |
| ⟪हु⟩ 3P | ⟪जुह्वान⟩:brju-hu + āna |
| ⟪सु⟩ 5U | ⟪सुन्वान⟩:brsu-nu + āna |
| ⟪रुध्⟩ 7U | ⟪रुन्धान⟩:brru-n-dh-āna |
| ⟪तन्⟩ 8U | ⟪तन्वान⟩:brtan-u + āna |
| ⟪क्री⟩ 9U | ⟪क्रीणान⟩:brkrī + n-āna |
:::
### 41.2.2. "Particippet" af den passive nødvendighed (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**For at udtrykke den passive nødvendighed ("det, der skal gøres/bør gøres"), kan man alternativt danne adjektiver fra rødder og afledte verbalstammer med følgende suffikser:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (i stedet for **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Suffixet -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Suffixet -⟪तव्य⟫ / -⟪तव्या⟫ tilføjes på samme måde til rødder og afledte verbalstammer (f.eks. kausativ) som infinitivsuffixet -⟪तुम्⟫ (se [Lektion 23](lektion23.md)), dvs.**

* **stærk rod + ⟪तव्य⟫**

eller

* **stærk rod + -i- + ⟪तव्य⟫**

**I kausativ:**

* **kausativstamme på -ay + -i- + ⟪तव्य⟫**
:::
Eksempler:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "en, der skal besejres; en at besejre" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "det, hvor man bør opholde sig" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "en, der skal vækkes; en at vække" |

:::
#### 41.2.2.2. Suffixet -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Dannelse:**

Stærk rod + -⟪अनीय⟫ / -⟪अनीया⟫

**Kausativ og 10. præsensklasse:**

Rod, som den fremtræder i kausativstammen, uden -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Eksempler:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "det, der skal gives; det, der må gives" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "en at besejre" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "det, der skal gøres" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "det, der skal ses; se-værdigt" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "en at vække" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "det, der skal gives" |

:::
#### 41.2.2.3. Suffixet -⟪य⟫ / -⟪या⟫

::: grammar-box
**Dannelsettelse:**

Rod (i dyb-, høj- eller forlængelsesgrad) + -⟪य⟫

Se nøjagtige regler hos Kielhorn, Grammatik der Sanskrit-Sprache, s. 195 - 197!
:::
Behandling af udløbende vokaler:

::: grammar-box
**1. Rødder på -ā danner denne gerundivum på -eya**
:::

::: no-header

### 41.2.3. Syntaks vedrørende "particippet" af passiv nødvendighed (gerundivum) (⟪कृत्य⟫)

::: grammar-box
Gerundivum kan bruges attributivt:

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = "en by, der skal ses; en seværdig by"
:::
Gerundivum kan også bruges som prædikatnavn i sætninger med passiv konstruktion, der udtrykker en forpligtelse eller et befael (med ⟪न⟫ en forbud, en umulighed):

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = "De tofødte må se Benares"
:::

### 41.2.4. Forskelle i brugen af gerundiv-suffixer

::: grammar-box
Brugen af disse suffixer overlapper i vid udstrækning

* **-⟪तव्य⟫ (fem. -⟪तव्या⟫):** udtrykker altid en nødvendighed og bruges foretrukket prædikativt (sjældnere attributivt). Dannelser med dette suffix bør ikke bruges i nominalkomposita.
* **-⟪अनीय⟫ (fem. -⟪अनीया⟫) og -⟪य⟫ (fem. -⟪या⟫) / -⟪त्य⟫ (fem. -⟪त्या⟫) (i stedet for -⟪य⟫/-⟪या⟫):** kan have en yderligere betydning (især -⟪य⟫) i betydningen af det tyske "-wert" (f.eks. "seværdig") eller kun en mulighed "-bar" (⟪दृश्य⟫ "synlig"). Dannelser med disse suffixer kan negativeres med ⟪अ⟫-/-⟪अन्⟫- (men ikke dannelser med -⟪तव्य⟫), og der findes ⟪तत्पुरुष⟫ som deres efterled, de forekommer i.
:::
### 41.2.5. Ingen forbindelse med ⟪सु⟫- og ⟪दुस्⟫-

::: grammar-box
Med ⟪सु⟫- og ⟪दुस्⟫- i betydningen "let" hhv. "svær" må gerundiva ikke forbindes. I stedet står ⟪तत्पुरुष⟫ af typen  ⟪सुकर⟫ 3 ("let at gøre") (s. [Lektion 18](lektion18.md)).
:::
