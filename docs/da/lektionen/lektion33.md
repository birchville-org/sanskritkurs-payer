# Lektion 33

## 33.1. Reduplikationen (⟪अभ्यास⟫ m.)

* Den tredje præsensklasse
* (samt nogle verber af andre præsensklasser),
* perfektum,
* den redupliserede aorist,
* frequentativum og
* desiderativum

dannes ved hjælp af reduplikation. Den del af en redupliceret form, der sættes foran roden, kaldes reduplikationssyllebe.

Reduplikationssylleben består af (en konsonant og) en vokal.

### 33.1.1. Reduplikationskonsonanten

::: grammar-box
**1. Almindeligvis:**  
**Gentagelse af rodens første konsonant**
:::
Eksempler:

::: indent
⟪दा⟫ 3 "give"
* 3.sg.P.Ind.Præs. ⟪ददाति पॄ⟫ 3 "fylde"
* 3.sg.P.Ind.Præs. :sig[⟪पि⟫]⟪पर्ति मा⟫ 3Ā "måle"
* 3.sg.Ā.Ind.Præs. :sig[⟪मि⟫]⟪मीते⟫
:::
::: grammar-box
**2. En aspireret startkonsonant i en rod redupliceres med den tilsvarende ikke-aspirerede konsonant.**
:::
Eksempler:

::: indent
⟪धा⟫ 3 "sætte"
* 3.sg.P.Ind.Præs. ⟪दधाति भी⟫ 3 "frygte"
* 3.sg.P.Ind.Præs. :sig[⟪बि⟫]⟪भेति⟫
:::
::: grammar-box
**3. En guttural redupliceres med den tilsvarende ikke-aspirerede palatal:**

:::
::: indent
⟪क्⟫, ⟪ख्⟫ gennem ⟪च् ग्⟫, ⟪घ्⟫ gennem ⟪ज्⟫
:::
**⟪ह्⟫ redupliceres altid med ⟪ज्⟫.**
Eksempler:

::: indent
⟪हु⟫ 3 "(til offer) hælde i ild"
* 3.sg.P.Ind.Præs. ⟪जुहोति⟫
:::
::: grammar-box
**4. Starter en rod med flere konsonanter, gentages kun den første (eventuelt under anvendelse af regel 2 eller 3).**
:::
::: grammar-box
**5. Starter en rod med en konsonantgruppe sibilant + stemtlos konsonant, redupliceres ikke sibilanten, men den efterfølgende stemtlose konsonant i henhold til ovenstående regler.**
:::
Eksempel:

::: indent
⟪स्था⟫ 1 "stå"
* 3.sg.P.Ind.Præs. ⟪तिष्ठति⟫
:::
## 33.2. Den tredje præsensklasse (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ osv.")

::: grammar-box
**Dannelse:**

**stærk stamme:**  
**redupliceret højtrinnede rod + ending**

**svag stamme:**  
**redupliceret lavtrinnede rod + ending**

**For reduplikationskonsonanten gælder de ovenfor angivne regler.**
:::
### 33.2.1. Reduplikationsvokalen i den 3. præsensklasse

::: grammar-box
* **Den regelmæssige reduplikationsvokal er -i-**
* **u-holdige rødder reduplicerer med -u-**
* **rødderne ⟪दा⟫, ⟪धा⟫, ⟪हा⟫ med -a-**
:::
Eksempler:

::: grammar-box
⟪हु⟫ 3P "(til offer) i ild hælde"

* **stærk stamme:** ⟪जुहो⟫
* **svag stamme:** ⟪जुहु⟫

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Præsens** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | ⟪जुहुते⟫ | ⟪जुह्वते⟫:brjuhu + ate |
| **Imperfekt** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | ⟪अजुहुत⟫ | ⟪अजुह्वत⟫:bra-juhu + ata |
| **Optativ** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | ⟪जुह्वीत⟫:brjuhu + ī-ta | ⟪जुह्वीरन्⟫:brjuhu + ī-ran |
:::
## 33.3. Om ablaut af ā

ā kann

* på den ene side forlænget trin af en af ablaut-rækkerne med -a-
* på den anden side højtrin i en ablaut-række af ā-gruppen

De to vigtigste ablaut-rækker i ā-gruppen er:

::: grammar-box
**A.**

* **Lavtrin**
* **foran konsonant: -i-**  
f.eks. ⟪धा⟫ PPP: ⟪हित⟫ (hi-ta)
* **foran vokal: Ø**  
f.eks. ⟪धा⟫ 3.pl.P.Ind.Præs. ⟪दधति⟫ (dadh-ati)
* **Højtrin: -ā-**  
f.eks. ⟪धा⟫ 3.sg.P.Ind.Præs. ⟪दधाति⟫
:::
Hertil hører f.eks. også:

::: indent
⟪स्था⟫ 1
* PPP ⟪स्थित⟫ (sthi-ta)
* 3.sg.P.Fut. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **Tiefstufe: -ī-**
f.eks. ⟪पा⟫ 1: PPP ⟪पीत⟫ (pī-ta)
* **Højstufe: -ā-**  
f.eks. ⟪पा⟫ 1: Inf. ⟪पातुम्⟫
:::
## 33.4. Rødder på -ā i den tredje præsensklasse

::: grammar-box
**Rødder på -ā (undtagen ⟪दा⟫ og ⟪धा⟫) har i den svage stamme normalt afledningen -ī-** (se herom Thumb-Hauschild Bd. 1,1 s. 271. Formodentlig virkede den ovenfor nævnte ablautserie B som forbillede, selvom disse rødder ellers følger række A i ablaut), **foran vokalske endelser forsvinder rodvokalen fuldstændigt (se ablautserie A).**
:::
Eksempler:

::: grammar-box
⟪मा⟫ 3Ā "måle"

| | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- |
| **Indikativ Præsens** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Imperfekt** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Optativ** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3P "forlade"

| | 3. sg. P. | 3. pl. P. |
| :--- | :--- | :--- |
| **Indikativ Præsens** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Imperfekt** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Optativ** | ⟪जह्यात्⟫:brjah-yā-t:br(Roden ⟪हा⟫ har foran optativ-yā/y samme form som foran vokaler!) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. Rødderne ⟪दा⟫ og ⟪धा⟫

::: grammar-box
**Rødderne ⟪दा⟫ og ⟪धा⟫ rederuplicerer med vokalen -a- og mister rodvokalen i den svage stamme.**

**Bemærk ved ⟪धा⟫ loven om dissimilation af hyletiske konsonanter!**
:::

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Præsens** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Forklaring: Thumb-Hauschild 1,1 s. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Imperfekt** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Optativ** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::
Formerne af ⟪दा⟫ opnås ved at erstatte **dh** med **d** i paradigmet for ⟪धा⟫. Altså:

::: grammar-box
⟪दा⟫ 3U "give"

| **Optativ** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |

## 33.7. Øvelse

A) Indsæt de tilsvarende former for ordene i parentes i følgende mønster:

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने बहुवचने च⟫) ... ⟪अन्नं ददाति ।⟫ (⟪भिक्षु । अग्नि । शूद्रा । गुनवान्पुत्र । देवान्स्तुवन्कवि । ब्राह्मणी । महान्साधु । धेनु⟫)

B) Indsæt de tilsvarende former for verberne angivet i parentes i indikativ præsens, imperfekt og optativ:

⟪ब्राह्मणो घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥ बुद्धगता भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥ सुगतः कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥ दुर्जना भिक्षुभ्यो ऽन्नं न⟫ ... (⟪दा⟫) ⟪॥४॥ साधुः कृष्णे मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो लोकान्⟫ ... ⟪जनास्तु न⟫ ... (⟪मा⟫) ⟪॥६॥ दासा भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥ ब्राह्मणी पात्रं जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫

C) Oversæt, og omform flertals sætninger til entalssætniger og omvendt:

⟪योगयुक्तो मतिं दुःखमक्षनयन्त्यां प्रज्ञायां समाधत्ते ॥१॥ यो भिक्षवे दानानि दद्यात्सो ऽपि दानपुण्यमाददीत ॥२॥ ब्राह्मणा भारं न बिभ्रतीति ब्राह्मणदासो भारं गृहमबिभः ॥३॥⟫
