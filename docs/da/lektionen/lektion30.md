# Lektion 30

## 30.1. Den 9. præsensklasse (⟪क्र्यादि⟫ = "⟪क्री⟫ o.s.v.")

::: grammar-box
**Dannelse:**

*   stærk stamme: lavtrinsrod + -nā-

*   svag stamme:

*   foran konsonant: lavtrinsrod + -nī-

*   foran vokal: lavtrinsrod + -n-
:::
Eksempel:

::: indent
⟪क्री⟫ 9U "købe"
:::
::: grammar-box

| |Singular:br⟪एकवचन⟫|Plural:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3. person:brParasmaipada**|⟪क्रीणाति⟫:br(krī + nā + ti)|⟪क्रीणन्ति⟫:br(krī + n + anti)|
|**3. person:brĀtmanepada**|⟪क्रीणीते⟫:br(krī + nī + te)|⟪क्रीणते⟫:br(krī + n + ate)|

:::
Ved denne præsensklasse skal man særligt bemærke dannelsen af præsensstammen for roden ⟪ज्ञा⟫ 9U "erkende, vide":

::: grammar-box

| |Singular:br⟪एकवचन⟫|Plural:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3. person:brParasmaipada**|⟪जानाति⟫:br(jā-nā-ti)|⟪जानन्ति⟫:br(jā-n-anti)|
|**3. person:brĀtmanepada**|⟪जानीते⟫:br(jā-nī-te)|⟪जानते⟫:br(jā-n-ate)|

:::

## 30.2. Brug af optativ (⟪लिङ्⟫)

Optativ bruges:

::: grammar-box
**1. til angivelse**

*   **et ønske**
*   **en bøn**
*   **et mildet befaling**

**(her overlapper optativ - ⟪लिङ्⟫ - med imperativ - ⟪लोट्⟫)**
:::
Eksempel:

::: indent
⟪दासो ग्राममागच्छेत्⟫ = "Tjeneren må komme til landsbyen"
:::
::: grammar-box
**2. Når noget som**

*   **muligt**
*   **sandsynligt**
*   **formodentlig**

**skal fremstilles.**
:::
Eksempel:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं न शृणुयात्⟫ = "Hvis han gik fra landsbyen, ville han ikke høre mesteren"
:::
::: grammar-box
**3. Relativsætninger med optativ har nogle gange betydningen: "Hvis nogen ..."**
:::
Eksempel:

::: indent
⟪यो नृतं वदेत्स नरकं पतेत्⟫ = "Hvis nogen ville sige en usandhed, ville han falde i helvedet = Hvis nogen siger en usandhed, falder han i helvedet"
:::

:::

## 30.5. Sandhi af udløbende -r

::: grammar-box
**Med undtagelse af -ar gælder de samme sandhiregler for udløbende -r som for udløbende -s.**

**-ar foran stemte lyde forbliver -ar, men før r- falder -r bort og -a- erstattes af -ā-.**
:::
Eksempler:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना रोदिति⟫
:::
