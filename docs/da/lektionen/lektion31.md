# Lektion 31

## 31.1. Den 7. præsensklasse (⟪रुधादि⟫ = "⟪रुध्⟫ osv.")

::: grammar-box
**Dann:**

**Foran de udtalende konsonanter i den dybe rod indskydes et såkaldt nasal-infix (-na- eller -n-):**

*   **i den stærke stamme: -na-**
*   **i den svage stamme: -n-**

**For forbindelsen af rodens udtalende konsonanter med konsonantisk begyndende endelser gælder de samme regler som for den 2. præsensklasse.**
:::
Eksempler:

⟪युज्⟫ 7U "forbinde, spænde for"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. sg.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(for gutturale i midten af ordet erstattes nasalerne med -ṅ-) |
| | **3. pl.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Optativ** | **3. sg.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. pl.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Particip præsens** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brfem.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "stoppe, bringe til standsning"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. sg.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. pl.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Optativ** | **3. sg.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. pl.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Particip præsens** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brfem.: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**For some roots, the -n- of the weak present stem has also penetrated into non-present tenses, so that these roots are posited with an infix nasal.**
:::
Example:

⟪भञ्ज्⟫ 7P "to break"

::: indent
*   Indicative Present
*   3.sg.P. ⟪भनक्ति⟫ (bha-na + j + ti)
*   3.pl.P. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Future: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Passive: ⟪भज्यते⟫ (either from the original root ⟪भज्⟫ or from *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (possibly from *bhñj + na)
:::
