# Lektion 3

## 3.1. Nominativ singular af femininum

### 3.1.1. Nominativ singular på -s

Også følgende nominalstammer, der ender med en vokal, danner nominativ singular på **-s**:

::: grammar-box
**Feminina på -i**: f.eks. **śruti** f. "det at høre" -- Nom. sg.: **śrutis** = ⟪श्रुतिस्⟫
**Feminina på -u**: f.eks. **dhenu** f. "malkeko" -- Nom. sg.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Nominativ singular uden endelse

Danner nominativ singular uden endelse:

::: grammar-box
**Feminina på -ā**: f.eks. **devatā** f. "guddom" -- Nom. sg.: **devatā** = ⟪देवता⟫
**Feminina på -ī**: f.eks. **devī** f. "gudinde" -- Nom. sg.: **devī** = ⟪देवी⟫
:::
::: important
**Bemærk!** Der findes også entstavelige feminine rodnomina på -ī, hvis nominativ singular ender på -s: f.eks. dhī f. "tanke" -- Nom. sg.: dhīs = ⟪धीस्⟫. Også lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "båd" og tantrī (⟪तन्त्री⟫) f. "streng" danner uregelmæssigt nominativ singular på -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Dannelse af feminina til maskulina

::: grammar-box
**Maskulina på -a:**
**Femininum på -ā**: f.eks. **kṣatriya** m. » **kṣatriyā** f. "Kṣatriya-kvinde" = ⟪क्षत्रिया⟫
**Femininum på -ī**: f.eks. **brāhmaṇa** m. » **brāhmaṇī** f. "Brahman-kvinde" = ⟪ब्राह्मणी⟫

**Maskulina på -u:**
**Femininum på -ī**: f.eks. **sādhu** m. » **sādhvī** f. (god, hellig) = ⟪साध्वी⟫
(**-u-** bliver til **-v-** foran vokal, derfor **-u- + -ī** » **-vī**)
:::

## 3.3. Nominativ plural maskulinum og femininum

::: grammar-box
Endelsen for nominativ plural i maskulinum og femininum er **-as**.
**Maskulina på -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
**Feminina på -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**Maskulina på -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**Feminina på -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**Feminina på -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**Maskulina på -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**Feminina på -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Note: **e** is the strong grade (**guṇa**) of **i**, **o** is the strong grade of **u**.


## 3.4. Vokalsandhi

::: grammar-box
**Simple vowels that do not differ or only differ in length “merge” into the corresponding long vowel:**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)
:::
e.g.

devatā + annapūrṇā » devatānnapūrṇā "Annapūrṇā er en guddom" = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā er gudinden for mad og madlavning, hun anses for en inkarnation af Pārvatī, Shivas hustru.)

devī + indrāṇī » devīndrāṇī "Indrāṇī er en gudinde" = ⟪देवीन्द्राणी⟫

> (Indrāṇī er guden Indras hustru.)

::: grammar-box
**Simple vowels (except -a / -ā) are replaced by the corresponding semivowel before dissimilar vowels:**
i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**
(!! Der findes undtagelser fra denne regel, især for dualisformer !!)
:::
e.g.

devī + umā » devy umā "Umā er en / gudinden" = ⟪देव्युमा⟫

> (Umā er et navn for Pārvatī, Shivas hustru.)

::: grammar-box
**-a / -ā foran uensartet vokal:**
a / -ā + i- / ī- » **-e-**
a / -ā + ṛ- » **-ar-**
a / -ā + e- / ai- » **-ai-**
a / -ā + o- / au- » **-au-**
:::

## 3.5. Sætningssandhi for -ās

::: grammar-box
**-ās erstattes af -ā foran alle stemte lyde.**
:::
f.eks.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Vaiśyas er dobbeltfødte" = ⟪द्विजा वैश्याः⟫


## 3.6. Ordbog

**Lær følgende ord:**

**śruti** f. = ⟪श्रुति⟫ : hørelse, den evige overlevering (betegnelse for Vedaerne og Brāhmaṇa's).

**smṛti** f. = ⟪स्मृति⟫ : erindring, meditationel erindring = opmærksomhed, overlevering (modbegreb til **śruti**). Omfatter:
de seks **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): korrekt udtale
2. **chandas** n. (⟪छन्दस्⟫): metrik
3. **vyākaraṇa** n. (⟪व्याकरण⟫): grammatik
4. **nirukta** n. (⟪निरुक्त⟫) : ordforklaring, etymologi
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : astronomi, kalenderlære
6. **kalpa** m. (⟪कल्प⟫) : ceremoniel
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : lærebøger for udførelsen af de store ofringer
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : lærebøger for ceremonier og ofringer i det daglige liv
**dharmasūtra** n. (⟪धर्मसूत्र⟫) og **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : lærebøger om ret og skik (korrekt adfærd)
de store episke digte **mahābhārata** n. (⟪महाभारत⟫) og **rāmāyaṇa** n. (⟪रामायण⟫)
**purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫) : lærebøger om livsklogskab

**smṛti** er især også betegnelse for Dharma-lærebøger.

**dhenu** f. = ⟪धेनु⟫ : (mælke-)ko.

**paśu** m. = ⟪पशु⟫ : domestikeret husdyr, kvæg (kollektivum).

**devatā** f. = ⟪देवता⟫ : guddommelighed (abstrakt og konkret).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : brahmanisk kvinde.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : kvindelig kṣatriya.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : kone til en kṣatriya.

**vaiśyā** f. = ⟪वैश्या⟫ : kvindelig vaiśya.

**śūdrā** f. = ⟪शूद्रा⟫ : kvindelig śūdra.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : kone til en śūdra.

**devī** f. = ⟪देवी⟫ : gudinde, især Durgā f. = ⟪दुर्गा⟫, Śivas hustru = ⟪शिव⟫.

**sādhvī** f. = ⟪साध्वी⟫ : femininum til sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : femininum til guru.

**asmitā** f. = ⟪अस्मिता⟫ : "jeg-væren", dvs. den (falske) tro: **Jeg** er det, der ser osv.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : filosofi (videnskaben, der når sine konklusioner gennem logisk korrekte begrundelser).

**upekṣā** f. = ⟪उपेक्षा⟫ : ikke-omsorg, ligegyldighed.

**karuṇā** f. = ⟪करुणा⟫ : medfølelse, barmhjertighed.

**muditā** f. = ⟪मुदिता⟫ : glæde, især medglæde (modsat af misundelse).


## 3.7. Øvelse

**A) Sæt følgende sætninger i flertal:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**B) Dannes nominalfraser ved indsættelse:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Overfør til femininum:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**D) Oversæt til sanskrit:**

1. Umā er en gudinde.
2. Vedaen er śruti.
3. Lærerinderne er gudinder.
4. Mælkekøer er domestikeret dyr.
5. Digtere er lærere.
6. Kṣatriyas er dvijaer (to-gangsfødte).
7. De hellige mænd er śūdras.
