# Øvelse 54

Dannes de tilsvarende aoristformer for følgende præsens- eller perfektformer:

::: grammar-box
| Nr. | Form | Bestemmelse / Betydning | Aorist |
|:---|:---|:---|:---|
| ⟪१⟫. | ⟪यन्ति⟫ | de går | ⟪अगुः⟫ |
| ⟪२⟫. | ⟪पिबामि⟫ | jeg drikker | ⟪अपाम्⟫ |
| ⟪३⟫. | ⟪ददौ⟫ | jeg har / han har givet | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | ⟪बभूव⟫ | jeg / han / de var / I var | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | ⟪दधति⟫ | de sætter | ⟪अधुः⟫ |
| ⟪६⟫. | ⟪ऐम⟫ | vi gik | ⟪अगाम⟫ |
| ⟪७⟫. | ⟪पपिथ⟫ | du har drukket / vogtet | ⟪अपाः⟫ (til :sig[⟪पा⟫] "drikke") |
| ⟪८⟫. | ⟪तिष्ठति⟫ | han står | ⟪अस्थात्⟫ |
| ⟪९⟫. | ⟪इयेथ⟫ | du er gået | ⟪अगाः⟫ |
| ⟪१०⟫. | ⟪पप⟫ | I har drukket | ⟪अपात⟫ |
| ⟪११⟫. | ⟪एष्यथ⟫ | I vil gå | ⟪अगात⟫ |
| ⟪१२⟫. | ⟪तस्थुः⟫ | de stod | ⟪अस्थुः⟫ |
| ⟪१३⟫. | ⟪अधत्त⟫ | I satte | ⟪अधात⟫ |
| ⟪१४⟫. | ⟪अददाः⟫ | du gav | ⟪अदाः⟫ |
| ⟪१५⟫. | ⟪अभवन्⟫ | de var | ⟪अभूवन्⟫ |
| ⟪१६⟫. | ⟪ददिम⟫ | vi har givet | ⟪अदाम⟫ |
| ⟪१७⟫. | ⟪भिद्यते⟫ | det bliver splittet | ⟪अभेदि⟫ |
| ⟪१८⟫. | ⟪उद्यते⟫ | det bliver sagt | ⟪अवादि⟫ |
| ⟪१९⟫. | ⟪स्तूयते⟫ | han bliver rost | ⟪अस्तावि⟫ |
| ⟪२०⟫. | ⟪कृष्यते⟫ | det bliver pløjet | ⟪अकर्षि⟫ |
| ⟪२१⟫. | ⟪जायते⟫ | han bliver født | ⟪अजनि⟫ |
| ⟪२२⟫. | ⟪गीयते⟫ | det bliver sunget | ⟪अगायि⟫ |
| ⟪२३⟫. | ⟪गम्यते⟫ | det er gået | ⟪अगामि⟫ |
