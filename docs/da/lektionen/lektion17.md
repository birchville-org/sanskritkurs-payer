# Lektion 17

## 17.1. Anden præsensklasse (⟪अदादि⟫ = ⟪अद्⟫ osv.)

De verbale endelser tilføjes direkte til roden. Her skal der tages hensyn til de lydmæssige ændringer, der opstår som følge af ord-sandhi.

::: grammar-box

Der findes følgende dannelsesformer i den anden præsensklasse:

1.  Rødder med stamvokaludsving (Ablaut) 
*   mest almindeligt: høj grad - lav grad
*   nogle rødder: forlænget grad - lav grad 
2.  Rødder uden stamvokaludsving (Ablaut) 
3.  To-stavelses rødder på -i/-ī med stamvokaludsving (Ablaut)

:::
## 17.2. Rødder i den anden præsensklasse med stamvokaludsving (Ablaut) høj grad - lav grad

Eksempler:

⟪द्विष्⟫ 2 U "at hade"

*   stærk præsensstamme: dveṣ-
*   svag præsensstamme: dviṣ-

::: no-header

## 17.3. Rødder i den anden præsensklasse med stammeafstigning gradesteg - lavgrad

Eksempel:

⟪स्तु⟫ 2 U "pris"

*   stærk præsensstamme: stau-
*   svag præsensstamm:
*   før konsonant: stu-
*   før vokal: stuv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. præs. P | ⟪स्तौति⟫ (stau-ti):broder: ⟪स्तवीति⟫ |

| 3\. pl. præs. Ā | ⟪स्तुवते⟫ (stuv-ate) |

## 17.4. Rødder i den anden præsensklasse uden stammeafstigning

::: grammar-box
Uden stammeafstigning er rødder i den anden præsensklasse på -ā
:::
Eksempel:

⟪पा⟫ 2 P "beskytte, vogte"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. præs. P | ⟪पाति⟫ (pā-ti) |
| 3\. pl. præs. P | ⟪पान्ति⟫ (« pā- + -anti) |

:::
Også nogle andre rødder i den anden klasse har ingen stammeafstigning:

## 17.5. To-stavede rødder på -i/-ī med stammeafstamning

Flere rødder er i en række former to-stavet, dvs. de har foran konsonantisk endelse et -i (henholdsvis foran nogle endelser -ī). Disse rødder betragtes dog stadig af de indfødte grammatikere og i ordbøger osv. som en-stavet.

Eksempler:

⟪रुद्⟫ 2 P "græde, hyle"

*   stærk præsensstamme: rodi-
*   svag præsensstamme:
*   foran konsonant: rudi-
*   foran vokal: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Præs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Præs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "tale"

*   stærk præsensstamme: bravī- (« bro- + -ī)
*   svag præsensstamme:
*   foran konsonant: brū-
*   foran vokal: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Præs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Præs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Præs. A | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Præs. A | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Også ⟪स्तु⟫ 2 U "pris" har udover de under 3. angivne former former efter dette mønster:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Præs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::

## 17.7. Øvelse 1

A) Indsæt verbet i følgende sætninger og oversæt:

⟪१⟫. ⟪ब्राह्मणो ऽनृतं न⟫ ... (⟪ब्रू । वच् । वद्⟫)

⟪२⟫. ⟪क्षत्रियो जनान्⟫ ... (⟪पा । रक्ष्⟫)

⟪३⟫. ⟪बलवद्योधो द्विजारीन्⟫ ... (⟪जि । हन् । युध्⟫)

⟪४⟫. ⟪ब्राह्मणकविर्लोकेश्वरम्⟫ ... (⟪स्तु । यज्⟫)

⟪५⟫. ⟪अग्निर्यज्ञान्नम्⟫ ... (⟪अद् । दह्⟫)

⟪६⟫. ⟪बालवैश्यो धेनुम्⟫ ... (⟪दुह् । रक्ष् । पा⟫)

⟪७⟫. ⟪द्विजदासो मृगमार्गेण ब्राह्मणग्रामम्⟫ ... (⟪गम् । इ । पद्⟫)

⟪८⟫. ⟪द्विजदासः शूद्रस्⟫ ... (⟪अस् २ । भू⟫)

⟪९⟫. ⟪बालब्राह्मणी⟫ ... (⟪रुद् । आस् । मृ⟫)
