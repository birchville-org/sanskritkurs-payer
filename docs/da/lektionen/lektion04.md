# Lektion 4

## 4.1. Enkle supplerende spørgsmål (ordspørgsmål) og svar

### 4.1.1. Spørgepronomena og demonstrativpronomina

#### 4.1.1.1. Spørgepronomen (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Nominativ singular | Nominativ plural |
| :--- | :--- | :--- |
| **Neutrum** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Maskulinum** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Femininum** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Demonstrativpronomina (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Stammer** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"han, dem/hende/det; den, der, det":br(En nævnt)** | **etad = ⟪एतद्⟫:br"denne, denne, dette":br(Meget tæt på taleren)** | **idam = ⟪इदम्⟫:br"denne, denne, dette":br(Tæt på)** |
| **Nominativ singular** ||||
| **Neutrum** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Maskulinum** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Femininum** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Nominativ plural** ||||
| **Neutrum** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Maskulinum** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Femininum** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**Om Nom. sg. mask.:**
**sa, eṣa** (⟪स एष⟫) står foran alle lyde undtagen kort **-a**
**so, eṣo** (⟪सो एषो⟫) står foran **-a**, som elideres (udfaldes) med Avagraha
**saḥ, eṣaḥ** (⟪सः एषः⟫) står kun i pause (sættslutning, versslutning)

For at kunne danne sætninger med disse pronominer (sarvanāman n.), er det nødvendigt at kende følgende sandhi-regler:

### 4.1.2. Sandhi af udtalende -m

::: grammar-box
**Udtalende -m erstattes af anusvāra (-ṃ) foran konsonanter. Ved slutningen af et sætning eller vers og foran vokaler bevares -m.**
:::
### 4.1.3. Sandhi af udtalende -e

::: grammar-box
1. **Foran a- forbliver -e uændret: det anlødende a- elideres med avagraha:**
f.eks. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Disse ildguder"

2. **Foran andre vokaler end kort a- erstattes -e normalt af -a med hiatus. Erstatning ved hjælp af -ay forekommer også:**
f.eks. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (sjældent: imay īśvarāh = ⟪इमयीश्वराः⟫) "Disse HERRE"
:::
### 4.1.4. Sandhi af udtalende -d

::: grammar-box
**Udtalende -d erstattes i pause samt foran stemløse gutturale (k, kh) og labiale (p, ph) konsonanter af -t.**

Erstatningen foran andre konsonanter vil blive drøftet senere. Undgå foreløbigt sådanne lydsammenstød!
:::
### 4.1.5. Spørgsformler

Med disse pronominer dannes der f.eks. følgende spørgsformler:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Singular** | **Neutrum** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं किम्⟫, ⟪किमिदम्⟫ | "Hvad er det?" |
| ^^| **Maskulinum** | sa kaḥ? / kaḥ saḥ?:br⟪स कः⟫, ⟪कः सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष कः⟫, ⟪क एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं कः⟫, ⟪को ऽयम्⟫ | "Hvem er det?":br"Hvem er den?" |
| ^^| **Femininum** | sā kā? / kā sā?:br⟪सा का⟫, ⟪का सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं का⟫, ⟪केयम्⟫ | "Hvem er det?":br"Hvem er hun?" |
| **Plural** | **Neutrum** | tāni kāni? / kāni tāni?:br⟪तानि कानि⟫, ⟪कानि तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि कानि⟫, ⟪कानीमानि⟫ | |
|^^ | **Maskulinum** | te ke? / ke te?:br⟪ते के⟫, ⟪के ते⟫:brete ke? / ka ete?:br⟪एते के⟫, ⟪क एते⟫:brime ke? / ka ime?:br⟪इमे के⟫, ⟪क इमे⟫ | |
| ^^| **Femininum** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः काः⟫, ⟪का एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः काः⟫, ⟪का इमाः⟫ | |
:::
Et eksempel på andre spørgsmål:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ Svar: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (I en nominal sætning kan man f.eks. placere subjektet i starten for at understrege sammenhængen med spørgsmålet.)

BEMÆRK: De svar, du kan give på sådanne spørgsmål med dine hidtidige sanskritkundskaber, svarer naturligvis endnu ikke i alle henseender til idiomatisk godt sanskrit.
