# Lektion 16

## 16.1. Om sandhi af udstødende konsonanter

Til dannelse af sammensætninger, hvis første led består af stammer med konsonantisk udstødning, kræves følgende regler:

Udstødende gutturale, retroflexe, dentale og labiale stoplyde (dvs. ingen nasaler og ingen palatale).

::: no-header

|   |   |
| :--- | :--- |
| **i pause og foran lydløse lyde** | **Erstatning med den tilsvarende lydløse ikke-aspirerede lyd:** :br **f.eks.** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **foran stemte ikke-nasale lyde** | **Erstatning med den tilsvarende stemte ikke-aspirerede lyd:** :br **f.eks.** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **foran nasaler** | **Erstatning med den tilsvarende nasal:** :br **f.eks.** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::
Undtagelse fra ovenstående regel:

Udstødende dental stoplyd (ikke nasal):

::: no-header

|   |   |
| :--- | :--- |
| **foran palatal** | **Erstatning med den pågældende unaspirerede palatal:** :br **dvs.** :br :indent -t + c- » -cc- :br :indent -d + c- » -cc- :br :indent -th + c- » -cc- :br :indent -dh + c- » -cc- :br :indent -t/-th/-d/-dh + ch- » -cch- :br :indent -t/-th/-d/-dh + j- » -jj- :br :indent -t/-th/-d/-dh + jh- » -jjh- |
**+ ś** | **» -cś- eller -cch-** |
| **foran retrofleks** | **Erstatning med den pågældende unaspirerede retrofleks:** :br **dvs.** :br :indent -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- :br :indent -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **foran l-** | **Erstatning med -l:** :br **dvs.** :br :indent -t/-th/-d/-dh + l- » -ll- |

:::
Eksempler:

⟪तद्⟫ + ⟪फल⟫ = ⟪तत्फल पुण्यवत्⟫ + ⟪ब्राह्मण⟫ = ⟪पुण्यवद्ब्राह्मण पुण्यवत्⟫ + ⟪नर⟫ = ⟪पुण्यवन्नर पुण्यवत्⟫ + ⟪पुरुष⟫ = ⟪पुण्यवत्पुरुष सत्यवत्⟫ + ⟪चैतन्य⟫ =⟪सत्यवच्चैतन्य सुखवत्⟫ + ⟪लोक⟫ = ⟪सुखवल्लोक पुत्रवत्⟫ + ⟪जन⟫ = ⟪पुत्रवज्जन बलवत्⟫ + ⟪शत्रु⟫ = ⟪बलवच्छत्रु⟫
