### 45.1.2. Syvende præsensklasse (⟪रुधादि⟫)

::: grammar-box
**Hvis en udtalende k/g fra roden kommer til at stå mellem nasal ṅ og en dental i endingen, kan k/g valgfrit udelades**

f.eks. ⟪युज्⟫ 3.sg.ind.præs.ā ⟪युङ्क्ते⟫ eller ⟪यु⟫:sig[⟪ङ्ते⟫]
:::

## 45.2. Den vokativ singular (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**De fleste vokativer i singular er stammerne med høj grad af udtale.**

f.eks. **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** osv.

**Undtagelser er femininum på -ā og -ī samt stammerne på -in, hvis vokativ sg. især skal huskes.**
:::
::: no-header
| | Vokativ singular |
| --- | --- |
| Maskulinum på -a | ⟪देव⟫ |
| Neutrum på -a | ⟪फल⟫ |
| Femininum på -ā | ⟪देवते⟫ |
| Maskulinum på -i | ⟪कवे⟫ |
| Femininum på -i | ⟪मते⟫ |
| Maskulinum på -u | ⟪शत्रो⟫ |
| Femininum på -u | ⟪धेनो⟫ |
| Femininum på -ī | ⟪देवि⟫ |
| Maskulinum på -ṛ | ⟪पितर्⟫ |
| Femininum på -ṛ | ⟪मातर्⟫ |
| Maskulinum på -an | ⟪राजन्⟫ |
| Neutrum på -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Maskulinum på -man/-van | ⟪आत्मन्⟫ |
| Maskulinum på -in | ⟪बलिन्⟫ |
| Maskulinum på -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt m. | ⟪महन्⟫ |
| mahānt n. | ⟪महत्⟫:br= Nominativ |
| Maskulinum på -mant/-vant | ⟪गुणवन्⟫ |
| Neutrum på -mant/-vant | ⟪गुणवत्⟫:br= Nominativ |
| Pronominer | en vokativ dannes ikke |
:::

## 45.4. Øvelse

A) Oversæt til sanskrit (brug venligst imperfektum ⟪लङ्⟫ for fortidsformer):

1. Du splitter den (buddhistiske) samfund.

::: indent
om samfundsopdeling (⟪सङ्घभेद⟫) se:

**Payer, Alois (1944–):** Vinayamukha : Grundbegreber i munkeordenens regler og ordensret for Theravāda. -- Del I. -- (Materialer til grundbegreberne i buddhismen). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::
2. Har I nydt jorden?

3. Har du modtaget en gave fra kongen?

Hellige mand, hvorfor frygter du ikke for farer?

Fader, hvorfor forlader du familien?

Śūdrakvinde, har du båret byrden ind i den rige brahmanes hus?

Gudinde, du burde opfylde Vaiśyaens ønske om lykke, som har udført fortjenstfulde gerninger.

Elefanter, I bør ikke bryde jernbåndene.

Du løvelige mand, hvorfor retter du ikke din hele opmærksomhed mod det Absolutte (Brahman)?

Har du, digter, målt verdensrummet?

B) Oversæt:

⟪अर्जुन हतो वा प्राप्स्यसि स्वर्गं जित्वा वा भोक्ष्यसे महीं । तस्माद्भवता योध्यम् ॥१॥ भवति कथमनन्तदुःखमरुणत् ॥२॥ ब्राह्मण किमग्नौ घृतमजुहोः ॥३॥ शत्रो शस्तेण जीवं न छिनत्सि ॥४॥⟫
