# Lektion 21

## 21.1. Yderligere præsensstammer på -nt

### 21.1.1. Particium præsens (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
Dette particium er en nominaldannelse fra præsensstammen, altså et rigtigt particium. Det er et adjektiv, der angiver, at nogen eller noget lige udfører det, som udtrykkes ved verbroden (+ præfix), mens andet sker. Det kan også bruges til at udtrykke en vedvarende tilstand.

**Eksempler:**

:::
::: indent
"Medens fader læser, ryger han = den læsende fader ryger"  
"en værende (= virkelig, ægte) ven"
:::
::: grammar-box

| **Dannelse af particium præsens Parasmaipada til tematisk præsensstammer:** |||
| :--- | :--- | :--- |
| **Maskulinum, Neutrum** | | |
| | **stærk stamme** | Præsensstamm + **-nt-** |
| | **svag stamme** | Præsensstamm + **-t-** |
| **Femininum** | | |

| | **6. præsensklasse** | Præsensstamm + **-nt-** + **-ī** :broder::brPræsensstamm + **-t-** + **-ī** |

:::

## 21.2. Sandhi for udstående nasaler

::: grammar-box

## 21.3. Høflige tiltaleformer

::: grammar-box
**Man kan på sanskrit, uden at være utilladelig, tale til nogen i 2. person ental. Men hvis man vil være høflig, kan man bruge et substantiv, der betyder "Ærværdige" og lignende, og sætte verbet i 3. person ental eller flertal, eller bruge en passivkonstruktion. Forøgelsen af høflighed ved brug af person i tiltalen er omtrent følgende:**

:::
::: indent
**2. sg. » 2. pl. » 3. sg. med tilsvarende substantiv » 3. pl. med tilsvarende substantiv**
:::
**Det vigtigste sådanne høfligheds-substantiv er ⟪भवन्त्⟫ , hunkøn: ⟪भवती⟫ . Det svarer i sin brug til vores høflige "De".**
Dette ⟪भवन्त्⟫ er en sammentrækning af ⟪भगवन्त्⟫, sin deklinering er den for substantiver på **-vant** (se [Lektion 13](lektion13.md)). Dette ⟪भवन्त्⟫ skal skelnes fra participium nutid P af ⟪भू⟫ "blive" ⟪भवन्त्⟫ : nominativ ental maskulinum af ⟪भवन्त्⟫ "De" lyder ⟪भवान्⟫, det af participiet ⟪भवन्⟫.

**Eksempler:**

::: indent
**⟪किं भवान्करोति⟫** = **⟪किं भवता क्रियते⟫** = "Hvad gør De?"
:::
høfligere:

::: indent
**⟪किं भवन्तः कुर्वन्ति⟫** = **⟪किं भवद्भिः क्रियते⟫**
:::
Femininum:

::: indent
**⟪किं भवती करोति⟫** = **⟪किं भवत्या क्रियते⟫**  
**⟪किं भवत्यः कुर्वन्ति⟫** = **⟪किं भवतीभिः क्रियते⟫**
:::
Yderligere ord, der kan bruges på samme måde som ⟪भवन्त्⟫:

*   ⟪आर्य⟫ (f.: ⟪आर्या⟫) "Ædel". f.eks. **⟪यदार्य इच्छति⟫** "Hvad De ønsker"
*   ⟪महाभाग⟫ "den hvis andel / lykke er stor = fornem". Ofte brugt af kvinder ved henvendelse til eller omtale af mænd af god stand. Meget almindeligt i moderne talt sanskrit.

Ønsker man ikke blot at udtrykke høflighed, men også ærefrygt for nogen, bruger man i stedet for ⟪भवन्त् अत्रभवन्त्⟫ , når personen er til stede eller i nærheden, for en fraværende eller fjern person ⟪तत्रभवन्त्⟫. ⟪अत्रभवन्त्⟫ og ⟪तत्रभवन्त्⟫ kan oversættes med "De", "Edel" osv.:

::: indent
**⟪किमत्रभवत्यत्रभवतां भार्या⟫** = "Er den nådige (her til stede) kone Deres hustru?"  
**⟪किं तत्रभवतां कुशलवृत्तम्⟫** (i et brev eller telefonsamtale) = "Har De det godt?"
:::
