# Lektion 50

## 50.1. Nominalbildung: regulär gradbøjning

::: grammar-box
**Den regulære gradbøjning foregår i sanskrit med ⟪तद्धित⟫-suffixerne**
* **-⟪तर⟫ (fem.: ⟪तरा⟫) i "komparativ"**
* **⟪तम⟫ (fem.: ⟪तमा⟫) i "superlativ"**

**Disse suffixer tilføjes adjektiver i maskulinum-stammen. Ved nominaler med stamme-apophoni tilføjes de den svage stamme, som har formen ligesom før endelsen -su i lokativ (⟪पञ्चमी⟫) pluralis.**
:::
::: media
![](/images/lekt5007.webp)
Fig.: ⟪लोकस्योत्तमो गिरिः सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = Mount Everest
(Billedkilde: [Details](/da/licenses#lekt5007))
:::

::: grammar-box
**Betydning:**

**"Komparativ" betyder, når et sammenlignet objekt ikke udtrykkes: "temmelig, meget, for":**

:::
::: indent
f.eks. ⟪सुचितर⟫ 3 "temmelig ren", "meget ren", "for ren"
:::
**Når et sammenlignet objekt udtrykkes, står dette i ablativ (⟪पञ्चमी⟫). Komparativ + ablativ svarer til gradbøjning med "end" på tysk.**

::: indent
f.eks. ⟪देवदत्ताद्रामो धीमत्तरः⟫ = ordligt.: "fra Devadatta set er Rāma mere indsigtsfuld" = "Rāma er mere indsigtsfuld end Devadatta"
:::
**"Superlativ" betyder, når et sammenlignet objekt ikke udtrykkes: "højst, meget":**

::: indent
f.eks. ⟪सत्तम⟫ 3 (til ⟪सन्त्⟫) "højst god, meget god"
:::
**Når et sammenlignet objekt udtrykkes, står dette i genitiv (⟪षष्ठी⟫) ("af", "blandt"), og superlativet svarer til den tyske superlativ (højeste grad):**

::: indent
f.eks. ⟪द्विजानां सत्तमः⟫ = "den bedste af de to gange fødte"

Eksempler:

::: indent
⟪गजतम⟫ m. "den bedste elefant" (⟪गज⟫) (også betegnelse for Buddha)

⟪गोतम⟫ m. "den største okse" (⟪गो⟫) eller: "den rigeste på køer"

⟪उद्⟫ indekl. "op", "til op" » ⟪उत्तर⟫ 3 "højere" » ⟪उत्तम⟫ 3 "højest"
:::
**Når disse efterledsættelser tilføjes en verbalform, optræder de altid i den adverbiale form:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

Eksempler:

::: indent
⟪पचतितराम्⟫ "han/hun/det koger bedre"

⟪पचतितमाम्⟫ "han/hun/det koger bedst"
:::
**Denne form har disse efterledsættelser også, når de tilføjes et indeklinabilium og det afledte ord bruges adverbiale:**

::: indent
f.eks. ⟪सुतराम्⟫ (til ⟪सु⟫) "på en bedre måde" (adverbiale)
:::
