# Lektion 35

## 35.1. Perfekt Typ III: Stark stamme høj grad/forlænget grad

::: grammar-box
**Dannelse:**

**stark stamme:**
*   3.sg.P: Forlænget grad
*   2.sg.P: Høj grad
*   1.sg.P: Valgfrit høj grad eller forlænget grad

**svag stamme:** se under undertyperne
:::
### 35.1.1. Perfekt Typ IIIa: Stark stamme høj grad/forlænget grad, svag stamme lav grad

::: grammar-box
**Dannelse:**

:::
::: indent
**svag stamme:** Lav grad
:::
Dannes af rødder af typerne:
*   (Konsonant)-(Konsonant) - i/ī/u/ū
*   (Konsonant) - ṛ

Foran vokalisk begyndende endning erstattes:
*   -i/-ī med -iy
*   -u/-ū med -uv
*   -ṛ med r

| ⟪नी⟫ 1U | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2U | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |

## 35.2. Perfekt Typ IV: Rødder med -ā / -āi

::: grammar-box
**Dannelse:**

**stærk stamme:**
*   3./1. sg. P Perfekt slutter på -au
*   2\. sg. P : Høj grad -ā eller Lav grad -i

**svag stamme:**
*   før konsonant: Lav grad -i
*   før vokal: Lav grad Ø

Dannes af rødder med -ā / -āi
:::

## 35.3. Perfekt Typ V: Rødder Konsonant-a-Konsonant

::: grammar-box
**Dannelse:**

**stærk stamme:**

*   2.sg.P: Høj grad

### 35.3.2. Perfekt type Vb: svag stamme kontraktion (e-type)

::: grammar-box
**Dannelse:**

:::
::: indent
**svag stamme:** ingen reduplikation. Erstatning af -a- i roden med -e-  
(til forklaring se Thumb-Hauschild 1,2 s. 286f.)
:::
Dannes af rødder med -a- mellem to enkle konsonanter, hvis startkonsonant ikke ændres i reduplikationssyllebet (dvs. hvis startkonsonant ikke er en guttural, aspirat eller h).
Eksempel:

| Rod | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 1U | ⟪पपाच⟫ | :sig[⟪पे⟫]⟪चुर्⟫ | :sig[⟪पे⟫]⟪चे⟫ | :sig[⟪पे⟫]⟪चिरे⟫ |

### 35.3.3. Perfekt type Vc: Rødder konsonant-a-konsonant. Svag stamme høj grad

::: grammar-box
**Dannelse:**

**svag stamme:** høj grad

Dannes af alle andre rødder med mellemliggende -a-, dvs. rødder med mellemliggende -a-
*   som starter med to konsonanter
*   som starter med guttural
*   som starter med aspirat
*   som starter med h

forudsat at de ikke tilhører perfekt type Va.
:::
Eksempel:

| Rod | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪क्रम्⟫ 1U | ⟪चक्राम⟫ | ⟪चक्रमुर्⟫ | ⟪चक्रमे⟫ | ⟪चक्रमिरे⟫ |
