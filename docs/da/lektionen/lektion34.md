# Lektion 34

## 34.1. Perfektum (⟪लिट्⟫)

I klassisk sanskrit findes kun indikativ og participium af perfektumstammen.

::: grammar-box
**Der findes to måder at danne perfektum på:**
*   **det reduplicerede perfektum = ⟪द्वित्वलिट्⟫**
*   **det perifrastiske perfektum = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Det perifrastiske perfektum (⟪अनुप्रयोगलिट्⟫) bruges:**
1. **ved de afledte bøjninger (kausativum, desiderativum, frequentativum, denominativum)**
2. **ved rødder, der begynder med en lang vokal (undtagen ā-), eller med en vokal (undtagen a-) foran to konsonanter**
3. **ved visse andre rødder**
:::
## 34.2. Det reduplicerede perfektum (⟪द्वित्वलिट्⟫)

### 34.2.1. Stammeaflyd

::: grammar-box
**Dannelse:**

**stærk stamme:** singularis parasmaipada
*   **redupliceret fuldtrins- hhv. forlængelsestringsrod + perfektumendelse**

**svag stamme:** alle øvrige former
*   **redupliceret svagtrinsrod + perfektumendelse**
:::
::: grammar-box
**Generelt (også uden for perfektum) har rødder af følgende form ingen stammeaflyd:**
*   **(konsonant)-konsonant-langvokal-konsonant**
*   **(konsonant)-konsonant-vokal-konsonant-konsonant**

**I perfektum har rødder af følgende form desuden ingen stammeaflyd:**
*   **a-konsonant**
*   **ā-konsonant**
:::
### 34.2.2. Perfektumendelserne

::: grammar-box

| | 3. Singular | 3. Plural |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |

:::
### 34.2.3. Bindevokal -i-

::: grammar-box
**Foran endelsen i 3. pl. Ā (-re) træder altid bindevokalen -i-, foran de andre konsonantisk begyndende endelser ved flertallet af rødder.**
:::
### 34.2.4. Reduplikation af konsonantisk begyndende rødder

::: grammar-box
**Reglerne for reduplikation af konsonantisk begyndende rødder er de samme som angivet i [Lektion 33](lektion33.md).**

**Reduplikationsvokalen ved konsonantisk begyndende rødder er den korte rodvokal.**

**Diftonger foran konsonant reduceres til den korte lavvokalkontrast.**

**ṛ, ṝ, ḷ og udstødende diftonger reduplikeres med -a-.**
:::
Eksempler:

::: grammar-box

| Rod | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::
::: grammar-box
**Nogle rødder, der begynder med y- eller v-, reduplikeres med i- henholdsvis u-, hvilket i de svage former "smelter sammen" med rodvokalen.**
:::
Eksempler:

::: grammar-box

| Rod | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Reduplikation af vokalisk begyndende rødder

::: grammar-box
**1. Indledende a-, ā- reduplikeres med a-, hvilket resulterer i ā-.**
:::
Eksempler:

::: grammar-box

| Rod | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "være" og ⟪अस्⟫ 4 "kaste" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. Rødder med indledende i- har som reduplikationssylle i den stærke stamme iy-, og i den svage stamme i-, hvilket smelter sammen med rodvokalen til ī-. Tilsvarende gælder for indledende u-.**
:::
Eksempler:

::: grammar-box

| Rod | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |
:::
::: grammar-box
**3. Rødder, der begynder med a- foran to konsonanter eller med ṛ-, har som reduplikationsstavelse ān-**
:::
Eksempler:

::: grammar-box

| Rod | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. Typer af det reduplicerede perfektum

Inddelingsprincip: Særligheder ved stammeaflyd:
*   Perfektum uden stammeaflyd: Type I
*   Perfektum med stammeaflyd: Type II - V
*   uregelmæssige perfektumdannelser

## 34.4. Perfektum type I: Perfektum uden stammeaflyd

::: grammar-box
**Perfektum type I (uden stammeaflyd) har rødder af typerne:**
*   **(konsonant)-konsonant-langvokal-konsonant**
*   **(konsonant)-konsonant-vokal-konsonant-konsonant**
*   **a-konsonant**
*   **ā-konsonant**
:::
Eksempler:

::: grammar-box

| Rod | 3. sg. Perf. | 3. pl. Perf. |
| :--- | :--- | :--- |
| ⟪बन्ध्⟫ 9P | ⟪बबन्ध⟫:brba-bandh-a | ⟪बबन्धुर्⟫ |
| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |
| ⟪आप्⟫ 5P | ⟪आप⟫:bra + āp-a | ⟪आपुर्⟫ |
| ⟪अस्⟫ 2P "være":br⟪अस्⟫ 4 "kaste" | ⟪आस⟫:bra + as-a | ⟪आसुर्⟫ |
| ⟪अश्⟫ | ⟪आनशे⟫:bruregelmæssig reduplikation! | ⟪आनशिरे⟫ |

:::
## 34.5. Perfektum type II: Stærk stamme fuldtrin, svag stamme svagtrin

::: grammar-box
**Dannes af rødder af formen:**
*   **(konsonant)-(konsonant)-i/u/ṛ/ḷ-konsonant**

**Dannelse:**
*   **stærk stamme: fuldtrin**
*   **svag stamme: svagtrin**
:::
Eksempler:

::: grammar-box

| :--- | :--- | :--- | :--- | :--- |
| ⟪भिद्⟫ | ⟪बिभेद⟫ | ⟪बिभिदुर्⟫ | ⟪बिभिदे⟫ | ⟪बिभिदिरे⟫ |
| ⟪इष्⟫ | ⟪इयेष⟫ | ⟪ईषुर्⟫ | | |
| ⟪मुच्⟫ | ⟪मुमोच⟫ | ⟪मुमुचुर्⟫ | ⟪मुमुचे⟫ | ⟪मुमुचिरे⟫ |
| ⟪वृत्⟫ | | | ⟪ववृते⟫ | ⟪ववृतिरे⟫ |
