## 58.6. Aorist 5: iṣ-aorist

::: grammar-box
**iṣ-aoristen dannes af alle seṭ-rødder, for hvilke der ikke udtrykkeligt kun læres en anden form af aoristen.**

**Dannelse:**

**Augment + rod + i + s + athematiske sekundære endelse**

**!!!** 2.sg.P og 3.sg.P går ud på **-**īs hhv. -īt fra **!!!** (Dette er opstået ved en overførsel af imperfekttet fra rødder af typen ⟪अब्रवीत्⟫; det er således egentlig rod-aorist-former).
:::
Stamdannelse-suffix + endelserne for iṣ-aoristen lyder derfor:

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | **-iṣam** | **-iṣma** | **-iṣi** | **-iṣmahi** |
| **2. ⟪द्वितीयः⟫** | **-īs** | **-iṣṭa** | **-iṣṭhās** | **-**idhvam / :br-iḍhvam:br(valgfrit efter -h eller halvkonsonant) |
| **3. ⟪प्रथमः⟫** | **-īt** | **-iṣur** | **-iṣṭa** | **-iṣata** |

:::
::: grammar-box
**Form af roden:**

*   **Rødder med kort vokal foran enkelt konsonant: høj grad i P og Ā**  
Eksempler:  
⟪बुध्⟫ 1U: 1.sg.P ⟪अबोधिषम् कॢप्⟫ 1Ā: 1.sg.Ā ⟪अकल्पिषि⟫

*   **Rødder med udstødende vokal:**
*   **P: Forlængelsesgrad**
*   **Ā: Høj grad**

Eksempler:  
⟪पू⟫ 9U: 1.sg.P ⟪अपाविषम्⟫ ; 1. sg.Ā ⟪अपविषि⟫

*   **Rødder på -ar., -al samt ⟪वद्⟫ 1P "sige", ⟪व्रज्⟫ 1P "gå væk": P: Forlængelsesgrad**  
Eksempler:  
⟪चर्⟫ 1P: 1.sg.P ⟪अचारिषम् वद्⟫ 1P: 1.sg.P ⟪अवादिषम्⟫

*   **Andre rødder af formen (Kons.-)Kons.-a-Kons.: i P valgfrit forlængelsesgrad (gælder ikke for rødder på -h, -m, -y samt nogle få andre rødder)**  
Eksempel:  
⟪तन्⟫ 8U: 1.sg.P ⟪अतनिषम्⟫ / ⟪अतानिषम्⟫  
men:  
⟪क्रम्⟫ 1U: 1.sg.P ⟪अक्रमिषम्⟫
:::
