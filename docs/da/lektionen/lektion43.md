# Lektion 43

## 43.1. Personendelser for den anden person (⟪मध्यमः⟫ = "mellem ⟨Person\>")

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||

Bemærk, at den sekundære endelse for 2.flertal er identisk med den sekundære endelse for 3.enkelttal.Ā.

## 43.3. Det personlige pronomen i anden person

*   Singular: ⟪त्वद्⟫ "du"
*   Plural: ⟪युष्मद्⟫ "I"

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम् त्वा⟫ | ⟪युष्मान् वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम् ते⟫ | ⟪युष्मभ्यम् वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪तव ते⟫ | ⟪युष्माकम् वस्⟫ |
| ⟪सप्तमी⟫ | ⟪त्वयि⟫ | ⟪युष्मासु⟫ |
:::
Formerne ⟪त्वा⟫, ⟪ते⟫, ⟪वस्⟫ må ikke bruges i første position i en sætning eller et vershalv. De må heller ikke bruges før ⟪च⟫, ⟪वा⟫, ⟪एव⟫ og nogle andre partikler:

::: indent
⟪त्वां मां च⟫ "dig og mig"
:::
