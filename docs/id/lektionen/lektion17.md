# Pelajaran 17

## 17.1. Zweite Presentklasse (⟪अदादि⟫ = ⟪अद्⟫ usw.)

Akhiran verbal melekat langsung pada akar. Dalam hal ini, perubahan fonetik yang dihasilkan dari sandhi kata harus diperhitungkan.

::: grammar-box

[B0] Bentuk-bentuk pembentukan berikut terdapat dalam kelas kedua sekarang:

1.  Roots with stem-apophony (gradation)
    *   mostly: strong grade - weak grade
    *   some roots: guṇa grade - weak grade
2.  Roots without stem-apophony (gradation)
3.  Two-syllable roots ending in -i/-ī with stem-apophony (gradation)

:::
## 17.2. Akar-akar kelas present kedua dengan gradasi vokal pada akar: tingkat kuat - tingkat lemah

Examples:

⟪द्विष्⟫ 2 U "to hate"

*   strong present stem: dveṣ-
*   weak present stem: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪द्वेष्टि⟫ (« dveṣ + -ti) |
| 3\. pl. Pres. P | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 3\. sg. Pres. Ā | ⟪द्विष्टे⟫ (« dviṣ + -te) |
| 3\. pl. Pres. Ā | ⟪द्विषते⟫ (dviṣ-ate) |

:::
The following word-sandhi rule applies here:

::: grammar-box
Word-sandhi of -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-
:::
Further examples:

⟪इ⟫ 2 P "to go" (Ā after certain preverbs)

*   strong present stem: e-
*   weak present stem:
    *   before consonant: i-
    *   before vowel: y-/iy-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪एति⟫ (e-ti) |
| 3\. pl. Pres. P | ⟪यन्ति⟫ (y-anti) |
| 3\. sg. Pres. Ā | ⟪इते⟫ (i-te) |
| 3\. pl. Pres. Ā | ⟪इयते⟫ (iy-ate) |

:::
⟪दुह्⟫ 2 U "to milk"

*   strong present stem: doh-
*   weak present stem: duh-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪दोग्धि⟫ (« doh- + -ti) |
| 3\. pl. Pres. P | ⟪दुहन्ति⟫ (duh-anti) |
| 3\. sg. Pres. Ā | ⟪दुग्धे⟫ (« duh- + -te) |
| 3\. pl. Pres. Ā | ⟪दुहते⟫ (duh-ate) |

:::
⟪हन्⟫ 2 P "memukul, membunuh, membantai"

*   strong present stem: han-
*   weak present stem:
    *   before consonant: ha- (« \*hn-)
    *   before vowel: ghn-/han-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪हन्ति⟫ (han-ti) |
| 3\. pl. Pres. P | ⟪घ्नन्ति⟫ (ghn-anti) |
| 3\. sg. Pres. Ā | ⟪हते⟫ (ha-te) |
| 3\. pl. Pres. Ā | ⟪घ्नते⟫ (ghn-ate) |

:::
⟪अस्⟫ 2 P "to be"

*   strong present stem: as-
*   weak present stem: s-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪अस्ति⟫ (as-ti) |
| 3\. pl. Pres. P | ⟪सन्ति⟫ (s-anti) |

:::
## 17.3. Akar-akar kata kelas presens kedua dengan gradasi vokal pada dasar kata: tingkat perpanjangan - tingkat nol

Example:

⟪स्तु⟫ 2 U "to praise"

*   strong present stem: stau-
*   weak present stem:
    *   before consonant: stu-
    *   before vowel: stuv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪स्तौति⟫ (stau-ti):broder: ⟪स्तवीति⟫ |
| 3\. pl. Pres. P | ⟪स्तुवन्ति⟫ (stuv-anti) |
| 3\. sg. Pres. Ā | ⟪स्तुते⟫ (stu-te) |
| 3\. pl. Pres. Ā | ⟪स्तुवते⟫ (stuv-ate) |

:::
## 17.4. Akar-akar kata kelas presens kedua tanpa gradasi akar kata

::: grammar-box
Roots of the second present class without stem gradation end in *-ā*.
:::
Example:

⟪पा⟫ 2 P “to protect, guard, watch over”

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪पाति⟫ (pā-ti) |
| 3\. pl. Pres. P | ⟪पान्ति⟫ (pā- + -anti) |

:::
A few other roots of the second class also lack stem gradation:

Examples:

⟪अद्⟫ 2 P “to eat”

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪अत्ति⟫ (ad- + -ti) |
| 3\. pl. Pres. P | ⟪अदन्ति⟫ (ad-anti) |

:::
⟪आस्⟫ 2 Ā “to sit”

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. Ā | ⟪आस्ते⟫ (ās-te) |
| 3\. pl. Pres. Ā | ⟪आसते⟫ (ās-ate) |

:::
⟪वच्⟫ 2 P “to speak”

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪वक्ति⟫ (vac- + -ti) |
| 3\. pl. Pres. P | does not occur |

:::
## 17.5. Akar kata dwisuku kata yang berakhiran -i/-ī dengan gradasi batang

Beberapa akar kata bersuku kata dua dalam sejumlah bentuk, yaitu, mereka memiliki -i (atau, sebelum akhiran tertentu, -ī) sebelum akhiran konsonantal. Meskipun demikian, akar-akar ini diperlakukan oleh para gramatikawan pribumi dan dalam kamus-kamus, dll., sebagai bersuku kata satu.

Examples:

⟪रुद्⟫ 2 P “to weep, to howl”

*   strong present stem: rodi-
*   weak present stem:
    *   before consonant: rudi-
    *   before vowel: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Pres. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U “to speak”

*   strong present stem: bravī- (“bro- + -ī)
*   weak present stem:
    *   before consonant: brū-
    *   before vowel: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Pres. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Pres. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Pres. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
⟪स्तु⟫ 2 U “memuji” juga memiliki bentuk sesuai pola ini, di samping bentuk yang diberikan pada no. 3.:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::

## 17.7. Latihan 1

A) Masukkan kata kerja dalam kalimat-kalimat berikut dan terjemahkan:

⟪१⟫. ⟪ब्राह्मणो⟫ ⟪ऽनृतं⟫ ⟪न⟫ ... (⟪ब्रू⟫ ⟪।⟫ ⟪वच्⟫ ⟪।⟫ ⟪वद्⟫)

⟪२⟫. ⟪क्षत्रियो⟫ ⟪जनान्⟫ ... (⟪पा⟫ ⟪।⟫ ⟪रक्ष्⟫)

⟪३⟫. ⟪बलवद्योधो⟫ ⟪द्विजारीन्⟫ ... (⟪जि⟫ ⟪।⟫ ⟪हन्⟫ ⟪।⟫ ⟪युध्⟫)

⟪४⟫. ⟪ब्राह्मणकविर्लोकेश्वरम्⟫ ... (⟪स्तु⟫ ⟪।⟫ ⟪यज्⟫)

⟪५⟫. ⟪अग्निर्यज्ञान्नम्⟫ ... (⟪अद्⟫ ⟪।⟫ ⟪दह्⟫)

⟪६⟫. ⟪बालवैश्यो⟫ ⟪धेनुम्⟫ ... (⟪दुह्⟫ ⟪।⟫ ⟪रक्ष्⟫ ⟪।⟫ ⟪पा⟫)

⟪७⟫. ⟪द्विजदासो⟫ ⟪मृगमार्गेण⟫ ⟪ब्राह्मणग्रामम्⟫ ... (⟪गम्⟫ ⟪।⟫ ⟪इ⟫ ⟪।⟫ ⟪पद्⟫)

⟪८⟫. ⟪द्विजदासः⟫ ⟪शूद्रस्⟫ ... (⟪अस्⟫ ⟪२⟫ ⟪।⟫ ⟪भू⟫)

⟪९⟫. ⟪बालब्राह्मणी⟫ ... (⟪रुद्⟫ ⟪।⟫ ⟪आस्⟫ ⟪।⟫ ⟪मृ⟫)

⟪१०⟫. ⟪साधुजनो⟫ ⟪ऽधर्मम्⟫ ... (⟪द्विष्⟫ ⟪।⟫ ⟪न⟫ ⟪कृ⟫)

[B1] B) Bentuklah kalimat-kalimat dalam A) dengan subjek dan kata kerja dalam bentuk jamak.
