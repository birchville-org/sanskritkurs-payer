# Pelajaran 17

## 17.1. Kelas Present Kedua (⟪अदादि⟫ = ⟪अद्⟫ dan seterusnya)

Akhiran verba melekat langsung pada akar. Perubahan bunyi yang dihasilkan dari sandhi kata perlu diperhatikan.

::: grammar-box

Terdapat bentuk-bentuk pembentukan berikut dalam kelas present kedua:

1. Akar dengan variasi akar (stammabstufung)
*   kebanyakan: Tingkat Tinggi - Tingkat Rendah
*   beberapa akar: Tingkat Panjang - Tingkat Rendah
2. Akar tanpa variasi akar (stammabstufung)
3. Akar dua suku kata berakhiran -i/-ī dengan variasi akar (stammabstufung)

:::
## 17.2. Akar kelas present kedua dengan variasi akar Tingkat Tinggi - Tingkat Rendah

Contoh:

⟪द्विष्⟫ 2 U "membenci"

*   Stamm present kuat: dveṣ-
*   Stamm present lemah: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Present P | ⟪द्वेष्टि⟫ (« dveṣ + -ti) |
| 3\. pl. Present P | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 3\. sg. Present Ā | ⟪द्विष्टे⟫ (« dviṣ + -te) |
| 3\. pl. Present Ā | ⟪द्विषते⟫ (dviṣ-ate) |

:::
Di sini berlaku hukum sandhi kata berikut:

::: grammar-box
Sandhi kata dari -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-
:::
Contoh lainnya:

⟪इ⟫ 2 P "pergi" (Ā setelah partikel tertentu)

*   Stamm present kuat: e-
*   Stamm present lemah:
*   sebelum konsonan: i-
*   sebelum vokal: y-/iy-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Present P | ⟪एति⟫ (e-ti) |
| 3\. pl. Present P | ⟪यन्ति⟫ (y-anti) |
| 3\. sg. Present Ā | ⟪इते⟫ (i-te) |
| 3\. pl. Present Ā | ⟪इयते⟫ (iy-ate) |

:::
⟪दुह्⟫ 2 U "memerah"

*   Stamm present kuat: doh-
*   Stamm present lemah: duh-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Present P | ⟪दोग्धि⟫ (« doh- + -ti) |
| 3\. pl. Present P | ⟪दुहन्ति⟫ (duh-anti) |
| 3\. sg. Present Ā | ⟪दुग्धे⟫ (« duh- + -te) |
| 3\. pl. Present Ā | ⟪दुहते⟫ (duh-ate) |

:::
⟪हन्⟫ 2 P "memukul, membunuh, membantai"

*   batang present kuat: han-
*   batang present lemah:
*   sebelum konsonan: ha- (« \*hn-)
*   sebelum vokal: ghn-/han-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. present P | ⟪हन्ति⟫ (han-ti) |
| 3\. pl. present P | ⟪घ्नन्ति⟫ (ghn-anti) |
| 3\. sg. present Ā | ⟪हते⟫ (ha-te) |
| 3\. pl. present Ā | ⟪घ्नते⟫ (ghn-ate) |

:::
⟪अस्⟫ 2 P "ada"

*   batang present kuat: as-
*   batang present lemah: s-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. present P | ⟪अस्ति⟫ (as-ti) |
| 3\. pl. present P | ⟪सन्ति⟫ (s-anti) |

:::
## 17.3. Akar kelas present kedua dengan ablaut batang tingkat panjang - tingkat rendah

Contoh:

⟪स्तु⟫ 2 U "memuji"

*   batang present kuat: stau-
*   batang present lemah:
*   sebelum konsonan: stu-
*   sebelum vokal: stuv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. present P | ⟪स्तौति⟫ (stau-ti):broder: ⟪स्तवीति⟫ |
| 3\. pl. present P | ⟪स्तुवन्ति⟫ (stuv-anti) |
| 3\. sg. present Ā | ⟪स्तुते⟫ (stu-te) |
| 3\. pl. present Ā | ⟪स्तुवते⟫ (stuv-ate) |

:::
## 17.4. Akar kelas present kedua tanpa ablaut batang

::: grammar-box
Tanpa ablaut batang adalah akar kelas present kedua pada -ā
:::
Contoh:

⟪पा⟫ 2 P "melindungi, menjaga, menggembala"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. present P | ⟪पाति⟫ (pā-ti) |
| 3\. pl. present P | ⟪पान्ति⟫ (« pā- + -anti) |

:::
Beberapa akar kelas kedua lainnya juga tidak memiliki ablaut batang:

Contoh:

⟪अद्⟫ 2 P "makan"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. present P | ⟪अत्ति⟫ (« ad- + -ti) |
| 3\. pl. present P | ⟪अदन्ति⟫ (ad-anti) |

:::
⟪आस्⟫ 2 Ā "duduk"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. Ā | ⟪आस्ते⟫ (ās-te) |
| 3\. pl. Präs. Ā | ⟪आसते⟫ (ās-ate) |

:::
⟪वच्⟫ 2 P "berkata"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪वक्ति⟫ (« vac- + -ti) |
| 3\. pl. Präs. P | tidak ada bentuknya |

:::
## 17.5. Akar dua suku kata dengan akhiran -i/-ī dan variasi bentuk akar

Beberapa akar memiliki dua suku kata dalam sejumlah bentuk, yaitu mereka memiliki -i (atau sebelum beberapa akhiran -ī) sebelum akhir konsonan. Namun, akar-akar ini tetap dianggap oleh para gramatikawan asli dan dalam kamus-kamus sebagai satu suku kata.

Contoh:

⟪रुद्⟫ 2 P "menangis, meratap"

*   bentuk dasar present kuat: rodi-
*   bentuk dasar present lemah:
*   sebelum konsonan: rudi-
*   sebelum vokal: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "berbicara"

*   bentuk dasar present kuat: bravī- (« bro- + -ī)
*   bentuk dasar present lemah:
*   sebelum konsonan: brū-
*   sebelum vokal: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Juga ⟪स्तु⟫ 2 U "memuji" memiliki, di samping bentuk-bentuk yang disebutkan pada poin 3., bentuk-bentuk mengikuti pola ini:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::

## 17.7. Latihan 1

A) Masukkan kata kerja dalam kalimat-kalimat berikut dan terjemahkan:

⟪१⟫. ⟪ब्राह्मणो ऽनृतं न⟫ ... (⟪ब्रू । वच् । वद्⟫)

⟪२⟫. ⟪क्षत्रियो जनान्⟫ ... (⟪पा । रक्ष्⟫)

⟪३⟫. ⟪बलवद्योधो द्विजारीन्⟫ ... (⟪जि । हन् । युध्⟫)

⟪४⟫. ⟪ब्राह्मणकविर्लोकेश्वरम्⟫ ... (⟪स्तु । यज्⟫)

⟪५⟫. ⟪अग्निर्यज्ञान्नम्⟫ ... (⟪अद् । दह्⟫)

⟪६⟫. ⟪बालवैश्यो धेनुम्⟫ ... (⟪दुह् । रक्ष् । पा⟫)

⟪७⟫. ⟪द्विजदासो मृगमार्गेण ब्राह्मणग्रामम्⟫ ... (⟪गम् । इ । पद्⟫)

⟪८⟫. ⟪द्विजदासः शूद्रस्⟫ ... (⟪अस् २ । भू⟫)

⟪९⟫. ⟪बालब्राह्मणी⟫ ... (⟪रुद् । आस् । मृ⟫)

⟪१०⟫. ⟪साधुजनो ऽधर्मम्⟫ ... (⟪द्विष् । न कृ⟫)

B) Terapkan subjek dan kata kerja dalam bentuk jamak pada kalimat-kalimat yang dibentuk di A)
