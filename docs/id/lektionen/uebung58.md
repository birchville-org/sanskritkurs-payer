8. ⟪पुनते⟫ - ⟪पू⟫ 9U 3.pl.Ind.Präs.Ā mereka menyucikan untuk kepentingan sendiri - ⟪अपविषत⟫

10. ⟪इयेषिथ⟫ - ⟪इष्⟫ 6P 2.sg.Perf.P Anda menginginkan - ⟪ऐषीः⟫
