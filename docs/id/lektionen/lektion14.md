# Pelajaran 14

## 14.1. Ungkapan hubungan yang ditunjukkan oleh kata benda: Genitif (ṣaṣṭhī f. = ⟪षष्टी⟫ = akhiran kasus keenam)

::: grammar-box
Jika hubungan yang dinyatakan oleh dua kata benda ingin ditunjukkan, maka digunakan genitif (ṣaṣṭhī f. "akhiran kasus keenam"). Genitif berbeda dari semua kasus lainnya karena ia — dengan beberapa pengecualian kecil — tidak berfungsi untuk menentukan lebih lanjut tindakan yang dinyatakan oleh kata kerja, melainkan untuk mengungkapkan hubungan antara orang atau benda yang ditunjukkan oleh kata benda. Genitif sering kali menjawab pertanyaan: Milik siapa?
:::
Contoh-contoh:

⟪कवेः पुत्रः⟫ "Anak penyair"

⟪धनस्य लोभः⟫ "Kerinduan akan kekayaan"

⟪नगरस्यार्धम्⟫ "Setengah kota"

⟪रामस्य कृतम्⟫ "Perbuatan Rāma / Sebuah perbuatan Rāma"

::: grammar-box
Urutan kata yang normal adalah:

> **Kata penentu dalam Genitif — Kata benda yang ditentukan lebih lanjut dalam kasus lain**
:::
**Genitif dan PPP:**

::: grammar-box
Pada PPP, genitif dapat menggantikan instrumentalis (tṛtīyā) untuk agen (kartṛ); Dalam konstruksi dengan instrumentalis, PPP dianggap sebagai bentuk verba pasif (yang berada dalam instrumentalis menunjukkan agen), sedangkan dalam konstruksi dengan genitif, PPP dianggap sebagai kata benda atau adjektiva (yang berada dalam genitif oleh karena itu tidak sebenarnya berfungsi sebagai agen).

Menurut Pāṇini 2.3.67, pada PPP genitif digunakan jika PPP memiliki makna present (lihat di atas), dan instrumentalis digunakan jika PPP memiliki makna lampau:

> ⟪रामस्येष्टं फलम्⟫ "Buah yang diinginkan Rāma = Buah yang saat ini diinginkan oleh Rāma"
> 
> ⟪रामेणेष्टं फलम्⟫ "Buah yang telah diinginkan oleh Rāma"

Tentu saja, untuk PPP Neutrum Singular yang digunakan sebagai abstrak verbal - yaitu sebagai kata benda - maka digunakan Genetif.
:::
## 14.2. Pembentukan bentuk Genetif (ṣaṣṭhī f. = ⟪षष्ठी⟫)

Genetif dibentuk dari bentuk akar lemah pada akar verbal dengan ablaut.

**Genetif untuk akar yang berakhiran konsonan:**

::: grammar-box

Setelah konsonan, akhiran Genetif yang teratur adalah:
* Singular: **-as**
* Plural: **-ām**

:::
::: center

| Akar Nominal | Bentuk Lemah | Genetif Singular | Genetif Plural |
| :--- | :--- | :--- | :--- |
| **guṇa-vant-** :br ⟪गुणवन्त्⟫ | **guṇa-vat-** :br ⟪गुणवत्⟫ | **guṇa-vat-as** :br ⟪गुणवतस्⟫ | **guṇa-vat-ām** :br ⟪गुणवताम्⟫ |
| **paśu-mant-** :br ⟪पशुमन्त्⟫ | **paśu-mat-** :br ⟪पशुमत्⟫ | **paśu-mat-as** :br ⟪पशुमतस्⟫ | **paśu-mat-ām** :br ⟪पशुमताम्⟫ |

:::
**Genetif untuk akar yang berakhiran vokal, kecuali nomina akar monosilabis dan akar yang berakhiran diftong:**

**Plural:**

::: grammar-box

Genetif Plural untuk akar yang berakhiran vokal dibentuk sebagai berikut:

> **-vokal panjang akhir dari akar + -nām**

:::
::: center

| Akar Nominal | Genetif Plural |
| :--- | :--- |
| **deva** m.:br ⟪देव⟫ | **devā-nām** :br ⟪देवानाम्⟫ |
| **phala** n.:br ⟪फल⟫ | **phalā-nām** :br ⟪फलानाम्⟫ |
| **devatā** f.:br ⟪देवता⟫ | **devatā-nām** :br ⟪देवतानाम्⟫ |
| **kavi** m.:br ⟪कवि⟫ | **kavī-nām** :br ⟪कवीनाम्⟫ |
| **śruti** f.:br ⟪श्रुति⟫ | **śrutī-nām** :br ⟪श्रुतीनाम्⟫ |
| **devī** f.:br ⟪देवी⟫ | **devī-nām** :br ⟪देवीनाम्⟫ |
| **paśu** m.:br ⟪पशु⟫ | **paśū-nām** :br ⟪पशूनाम्⟫ |

:::
**Genetif tunggal untuk stem vokal:**

::: grammar-box

Genetif tunggal untuk stem vokal dibentuk secara tidak teratur dan harus dihafal dengan baik.

:::

| :--- | :--- |

| **phala** n.:br ⟪फल⟫ | **phalasya** :br ⟪फलस्य⟫ |
| **devatā** f.:br ⟪देवता⟫ | **devatāyās** :br ⟪देवतायास्⟫ |
| **kavi** m.:br ⟪कवि⟫ | **kaves** :br ⟪कवेस्⟫ |
| **paśu** m.:br ⟪पशु⟫ | **paśos** :br ⟪पशोस्⟫ |
| **devī** f.:br ⟪देवी⟫ | **devyās** :br ⟪देव्यास्⟫ |
| **śruti** f.:br ⟪श्रुति⟫ | **śrutes / śrutyās** :br **⟪श्रुतेस्⟫ / ⟪श्रुत्यास्⟫** :br(yaitu, baik seperti kavi atau seperti devī) |
| **dhenu** f.:br ⟪धेनु⟫ | **dhenos / dhenvās** :br **⟪धेनोस्⟫ / ⟪धेन्वास्⟫** :br(yaitu, baik seperti paśu atau seperti feminin multisilaba berakhiran -ū) |

:::
**Kata ganti tanya dan kata ganti demonstratif:**

::: center

| | | kim | tad | etad | idam |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Maskulinum / Neutrum** | **Genetif Tunggal** | kasya:br ⟪कस्य⟫ | tasya:br ⟪तस्य⟫ | etasya:br ⟪एतस्य⟫ | asya:br ⟪अस्य⟫ |
| | **Genetif Jamak** | keṣām:br ⟪केषाम्⟫ | teṣām:br ⟪तेषाम्⟫ | eteṣām:br ⟪एतेषाम्⟫ | eṣām:br ⟪एषाम्⟫ |
| **Femininum** | **Genetif Tunggal** | kasyās:br ⟪कस्यास्⟫ | tasyās:br ⟪तस्यास्⟫ | etasyās:br ⟪एतस्यास्⟫ | asyās:br ⟪अस्यास्⟫ |
| | **Genetif Jamak** | kāsām:br ⟪कासाम्⟫ | tāsām:br ⟪तासाम्⟫ | etāsām:br ⟪एतासाम्⟫ | āsām:br ⟪आसाम्⟫ |

:::
**Kesamaan bentuk:**

::: important

Pada semua stem nominal kecuali maskulinum dan neutrum berakhiran -a serta kata ganti, bentuk Genetif Tunggal identik dengan bentuk Ablatif (pañcamī "akhiran kasus kelima") Tunggal!

Perhatikan bahwa pada stem yang berakhir dengan konsonan, Ablativ dan Genetif Singular terdengar sama seperti Akkusativ Plural Maskulinum dan Femininum!

:::
## 14.3. Lebih lanjut tentang penggunaan Genetif (⟪षष्ठी⟫)

::: grammar-box
Bertentangan dengan aturan dasar di atas, Genetif digunakan untuk menyatakan objek dari beberapa kata kerja, misalnya pada kata kerja mengingat:

> ⟪देवानां स्मरति⟫ "Ia mengingat para dewa"

Namun, objek untuk semua kata kerja ini juga dapat berada dalam Akkusativ:

> ⟪देवान्स्मरति⟫ "Ia mengingat para dewa"

Lebih lanjut nanti.
:::
