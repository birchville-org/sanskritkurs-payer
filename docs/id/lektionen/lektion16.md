# Pelajaran 16

## 16.1. Tentang Sandhi konsonan akhir

Untuk membentuk komposita, yang bagian depannya terdiri dari akar kata dengan konsonan akhir, diperlukan aturan-aturan berikut:

Konsonan letup (plosif) gutural, retrofleks, dental, dan labial yang berakhir dengan konsonan (yaitu bukan nasal dan bukan palatal).

::: no-header

|   |   |
| :--- | :--- |
| **dalam jeda dan sebelum bunyi tak bersuara** | **Penggantian dengan konsonan tak bersuara yang tidak aspirasi sesuai:** :br **misalnya** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **sebelum bunyi bersuara non-nasal** | **Penggantian dengan konsonan bersuara yang tidak aspirasi sesuai:** :br **misalnya** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **sebelum nasal** | **Penggantian dengan nasal yang sesuai:** :br **misalnya** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::
Pengecualian dari aturan di atas:

Konsonan letup dental yang berakhir dengan konsonan (bukan nasal):

::: no-header

|   |   |
| :--- | :--- |
| **sebelum Palatal** | **Penggantian dengan konsonan palatal unaspirasi yang sesuai:** :br **artinya** :br :indent -t + c- » -cc- :br :indent -d + c- » -cc- :br :indent -th + c- » -cc- :br :indent -dh + c- » -cc- :br :indent -t/-th/-d/-dh + ch- » -cch- :br :indent -t/-th/-d/-dh + j- » -jj- :br :indent -t/-th/-d/-dh + jh- » -jjh- |
**+ ś** | **» -cś- atau -cch-** |
| **sebelum Retrofleks** | **Penggantian dengan konsonan retrofleks unaspirasi yang sesuai:** :br **artinya** :br :indent -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- :br :indent -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **sebelum l-** | **Penggantian dengan -l:** :br **artinya** :br :indent -t/-th/-d/-dh + l- » -ll- |

:::
Contoh:

⟪तद्⟫ + ⟪फल⟫ = ⟪तत्फल पुण्यवत्⟫ + ⟪ब्राह्मण⟫ = ⟪पुण्यवद्ब्राह्मण पुण्यवत्⟫ + ⟪नर⟫ = ⟪पुण्यवन्नर पुण्यवत्⟫ + ⟪पुरुष⟫ = ⟪पुण्यवत्पुरुष सत्यवत्⟫ + ⟪चैतन्य⟫ =⟪सत्यवच्चैतन्य सुखवत्⟫ + ⟪लोक⟫ = ⟪सुखवल्लोक पुत्रवत्⟫ + ⟪जन⟫ = ⟪पुत्रवज्जन बलवत्⟫ + ⟪शत्रु⟫ = ⟪बलवच्छत्रु⟫
