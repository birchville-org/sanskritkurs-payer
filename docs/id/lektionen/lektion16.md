# Pelajaran 16

## 16.1. Tentang Sandhi Konsonan Akhir

Untuk membentuk komposita, yang anggotanya terdiri dari akar kata yang berakhir dengan konsonan, diperlukan aturan-aturan berikut:

Konsonan letak (guttural, retrofleks, dental, dan labial) yang berakhir (yaitu, bukan nasal dan bukan palatal).

::: no-header

|   |   |
| :--- | :--- |
| **dalam jeda dan sebelum bunyi tak bersuara** | **Penggantian dengan bunyi tak bersuara non-aspirasi yang sesuai:** :br **mis.** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **sebelum bunyi bersuara non-nasal** | **Penggantian dengan bunyi bersuara non-aspirasi yang sesuai:** :br **mis.** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **sebelum bunyi nasal** | **Penggantian dengan bunyi nasal yang sesuai:** :br **mis.** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::
