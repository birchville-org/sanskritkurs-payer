# Devanāgarī = देवनागरी

## Ejercicio de Escritura 1

El sánscrito fue y es escrito en una variedad de escrituras. El siguiente resumen ofrece una pequeña muestra de estas escrituras:

![](/images/schrift001.jpg)  
Fig.: Muestras de escritura sánscrita

La escritura sánscrita moderna más importante del norte de la India es la Devanāgarī:

![](/images/schrift002.jpg)

Cada signo de consonante incluye una "a" que sigue a la consonante. Si se desea escribir la consonante pura (sin vocal posterior), debe marcarse mediante una línea diagonal inferior -- virāma = विराम --:

क् = k, च् = c, ट् = ṭ, त्  = t, प् = p

Las vocales que siguen a una consonante -- excepto la "a" -- se escriben así:

का = kā, कि = ki, की = kī, कु = ku, कू = kū, कृ = kṛ, कॄ = kṝ, कॢ  = kḷ

के = ke, कै = kai, को = ko, कौ = kau

El orden al escribir estas combinaciones de consonante + vocal es:

![](/images/schrift003.jpg)

Al escribir, cada letra, incluyendo la línea horizontal superior, se completa antes de escribir la siguiente letra.

## Ejercicio

Escriba en Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

Lea y translitere:

तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ
