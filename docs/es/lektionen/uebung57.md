# Ejercicio 57

## A) Transformaciones del Aoristo

Traduzca y determine las siguientes formas y forme las correspondientes formas del **Aoristo**. A excepción de las causativas y de las raíces que forman el **aoristo en s**, se indica entre paréntesis la clase del aoristo correspondiente:

::: grammar-box
| Núm. | Forma | Determinación / Significado | Aoristo |
|:---|:---|:---|:---|
| ⟪१⟫. | **⟪पेचिथ⟫** | *⟪पच्⟫* 1U: 2. Sg. Perf. P. (tú engendraste) | **⟪अपाक्षीः⟫** |
| ⟪२⟫. | **⟪अवक्⟫** (⟪३⟫) | *⟪वच्⟫* 2P: 2. 3. Sg. Impf. P. (tú hablaste / él habló) | **⟪अवोचः⟫ / ⟪अवोचत्⟫** |
| ⟪३⟫. | **⟪सोष्यसि⟫** | *⟪सु⟫* 1/2P: 2. Sg. Fut. P. (tú te multiplicarás) | **⟪असौषीः⟫** |
| ⟪४⟫. | **⟪छिन्दे⟫** | *⟪छिद्⟫* 7U: 1. Sg. Ind. Pres. Ā. (yo corto) | **⟪अच्छित्सि⟫** |
| ⟪५⟫. | **⟪कुरुषे⟫** | *⟪कृ⟫* 8U: 2. Sg. Ind. Pres. Ā. (tú haces por tu propio interés) | **⟪अकृथाः⟫** |
| ⟪६⟫. | **⟪आधत्ते⟫** | *⟪आ⟫-⟪धा⟫* 3Ā: 3. Sg. Ind. Pres. Ā. (él coloca) | **⟪आधित⟫** |
| ⟪७⟫. | **⟪पद्यते⟫** | *⟪पद्⟫* 4Ā: 3. Sg. Ind. Pres. Ā. (él va) | **⟪अपादि⟫** |
| ⟪८⟫. | **⟪जिगाय⟫** | *⟪जि⟫* 1P: 1. 3. Sg. Perf. P. (yo triunfé / él triunfó) | **⟪अजैषीत्⟫** |
| ⟪९⟫. | **⟪जिघ्रामः⟫** (⟪१⟫,⟪६⟫) | *⟪घ्रा⟫* 1P: 1. Pl. Ind. Pres. P. (nosotros olemos) | **⟪अघ्रास्म⟫ / ⟪अघ्राम⟫** |
| ⟪१०⟫. | **⟪शासति⟫** (⟪२⟫) | *⟪शास्⟫* 2P: 3. Pl. Ind. Pres. P. (ellos ordenan) | **⟪अशिषन्⟫** |
| ⟪११⟫. | **⟪स्तुवे⟫** | *⟪स्तु⟫* 2U: 1. Sg. Ind. Pres. Ā. (yo alabo) | **⟪अस्तोष⟫i** |
| ⟪१२⟫. | **⟪दिग्धे⟫** | *⟪दिह्⟫* 2U: 3. Sg. Ind. Pres. Ā. (él unta) | **⟪अदिग्ध⟫** |
| ⟪१३⟫. | **⟪प्लवध्वे⟫** | *⟪प्लु⟫* 1Ā: 2. Pl. Ind. Pres. Ā. (vosotros nadáis) | **⟪अप्लोढ्वम्⟫** |
| ⟪१४⟫. | **⟪तस्थिथ⟫** (⟪१⟫) | *⟪स्था⟫* 1P: 2. Sg. Perf. P. (tú estuviste de pie) | **⟪अस्थाः⟫** |
| ⟪१५⟫. | **⟪बिभ्यति⟫** | *⟪भी⟫* 3P: 3. Pl. Ind. Pres. P. (ellos temen) | **⟪अभैषुः⟫** |
| ⟪१६⟫. | **⟪ततर्प⟫** | *⟪तृप्⟫* 4/6P: 1. 3. Sg. Perf. P. (yo / él sació) | **⟪अतार्प्सीत्⟫ / ⟪अत्राप्सीत्⟫** |
| ⟪१७⟫. | **⟪जुहुथ⟫** | *⟪हु⟫* 3P: 2. Pl. Ind. Pres. P. (vosotros ofrecéis) | **⟪अहौष्ट⟫** |
| ⟪१८⟫. | **⟪ऊषुः⟫** | *⟪वस्⟫* 1P: 3. Pl. Perf. P. (ellos residieron) | **⟪अवात्सुः⟫** |
| ⟪१९⟫. | **⟪ससर्जिथ⟫** | *⟪सृज्⟫* 6P: 2. Sg. Perf. P. (tú has creado) | **⟪अस्राक्षीः⟫** |
| ⟪२०⟫. | **⟪लिल्यिरे⟫** | *⟪ली⟫* 4Ā: 3. Pl. Perf. Ā. (ellos se abrazan) | **⟪अलेषत⟫ / ⟪अलासत⟫** |
| ⟪२१⟫. | **⟪अत्याजयम्⟫** | *⟪त्यज्⟫* 1P: 1. Sg. Impf. P. Caus. (yo dejé abandonar) | **⟪अतित्यजम्⟫** |
| ⟪२२⟫. | **⟪सिध्यथ⟫** (⟪२⟫) | *⟪सिध्⟫* 4P: 2. Pl. Ind. Pres. P. (vosotros estáis en la meta) | **⟪असिधत⟫** |
| ⟪२३⟫. | **⟪निन्य⟫** | *⟪नी⟫* 1U: 2. Pl. Perf. P. (vosotros habéis guiado) | **⟪अनैष्ट⟫** |
| ⟪२४⟫. | **⟪कर्षन्ति⟫** | *⟪कृष्⟫* 1P: 3. Pl. Ind. Pres. P. (ellos se mueven) | **⟪अकार्क्षुः⟫ / ⟪अक्राक्षुः⟫** |
| ⟪२५⟫. | **⟪अप्रच्छयन्⟫** | *⟪प्रच्छ्⟫* 6P: 3. Pl. Impf. P. Caus. (ellos dejaron preguntar) | **⟪अपप्रच्छन्⟫** |
