# Ejercicio 61

La Lección 61 forma el cierre del curso de sánscrito y no contiene más ejercicios escritos.

Con el estudio de los nombres radicales, el futuro perifrástico y los nombres denominativos, se sientan las bases para la lectura de textos originales en sánscrito. El curso concluye con la invocación tradicional a Gaṇeśa (श्रीगणनाथ), que marca la transición del libro de texto a la lectura independiente.
