# Lección 56

Determine y traduzca las siguientes formas:

::: grammar-box
| Núm. | Forma | Determinación / Significado |
|:---|:---|:---|
| १. | **अस्मत्** | *वयम्*: Abl. (de nosotros) |
| २. | **अस्मात्** | *इदम्*: Abl. Sg. m. n. (de este) |
| ३. | **दध्यौ** | *ध्यै* 1P: 1. 3. Sg. Perf. P. (yo he / él ha pensado) |
| ४. | **लिल्यिरे** | *ली* 4Ā: 3. Pl. Perf. Ā. (se han estrechado) |
| ५. | **अगामि** | *गम्* 1P: 3. Sg. Aor. Pass. (se fue) |
| ६. | **आगामी** | *आगामिन्*: Nom. Sg. m. (el que suele venir) |
| ७. | **अक्लिद्यत्** | *क्लिद्* 4P: 3. Sg. Impf. P. (se humedeció) |
| ८. | **अक्लिदत्** | *क्लिद्* 4P: 3. Sg. a-Aor. P. (se humedeció) |
| ९. | **अचिक्लिदत्** | *क्लिद्* 4P: 3. Sg. Redupl. Aor. P. Caus. (hizo humedecer) |
| १०. | **स्त्रीघ्नाय** | *स्त्रीघ्न*: Dat. Sg. m. n. (el asesino de mujeres) |
| ११. | **नेद** | *नद्* 1P: 2. Pl. Perf. P. (rugisteis) |
| १२. | **प्लवमान** | *प्लv* 1Ā: Part. Pres. Ā. Voc. Sg. m. (¡nadador!) |
| १३. | **अकारि** | *कृ* 8U: 3. Sg. Aor. Pass. (se hizo) |
| १४. | **अद्य** | hoy (Adv.) |
| १५. | **अतन्द्रिते** | *अतन्द्रित*: Loc. Sg. m. n.; Nom. Acus. Voc. Du. n.; Voc. Sg. f. (incansable) |
| १६. | **अन्तरे** | *अन्तर*: Nom. Voc. m. Pl.; Loc. Sg. m.; Nom. Acus. Du. n. (otro) |
| १७. | **महीक्षितम्** | *महीक्षित्* m.: Acus. Sg. m. (el rey); *मही* + *ईक्षित*: Acus. Sg. m. n. |
| १८. | **आर्दिधाम** | *ऋध्* 5P: 1. Pl. Redupl. Aor. P. Caus. (hicimos prosperar) |
| १९. | **आसम्** | *अस्* 2P: 1. Sg. Impf. P. (yo estaba) |
| २०. | **आसाम्** | *इदम्*: Gen. Pl. f. (estas) |
| २१. | **आसि** | *आस्* 2Ā: 1. Sg. Impf. Ā. (yo estaba sentado) |
| २२. | **अनूनुदत्** | *नुद्* 6U: 2. Pl. Redupl. Aor. P. Caus. (hicisteis apartar) |
| २३. | **जिघ्रति** | *घ्रा* 1P: 3. Sg. Ind. Pres. P. (huele) |
| २४. | **जाग्रति** | *जागृ* 2P: 3. Pl. Ind. Pres. P. (velan) |
| २५. | **आस्थत्** | *अस्* 4P: 3. Sg. a-Aor. P. (arrojó) |
| २६. | **आस्थात्** | *आ-स्था* 1P: 3. Sg. Aor. Raíz. P. (se acercó) |
| २७. | **अबीभषम्** | *भाष्* 1Ā: 1. Sg. Redupl. Aor. P. Caus. (hice hablar) |
| २८. | **अशुषः** | *शुष्* 4P: 2. Sg. a-Aor. P. (te secaste) |
| २९. | **कपी** | *कपि* m.: Nom. Acus. Voc. Du. (dos monos) |
| ३०. | **आततायी** | *आततायिन्* m.: Nom. Sg. (el gran criminal) |
| ३१. | **महती** | *महान्त*: Nom. Sg. f.; Nom. Acus. Voc. Du. n. (grande) |
| ३२. | **इतरेतरेषाम्** | *इतरेतर*: Gen. Pl. m. n. (recíproco) |
| ३३. | **धेक्षि** | *दिह्* 2U: 2. Sg. Ind. Pres. P. (untas) |
| ३४. | **अश्यन्** | *शो* 4P: 3. Pl. Impf. P. (afilaban) |
| ३५. | **कन्ये** | *कन्या* f.: Voc. Sg.; Nom. Acus. Voc. Du. (niña) |
| ३६. | **सौमि** | *सु* 2P: 1. Sg. Ind. Pres. P. (me reproduzco) |
| ३७. | **आर्पिपन्** | *ऋ* 1P: 3. Pl. Redupl. Aor. P. Caus. (pusieron en movimiento) |
| ३८. | **परिव्राट्** | *परिव्राज्* m.: Nom. Voc. Sg. (monje errante) |
| ३९. | **जेरिम** | *जॄ* 4/9P: 1. Pl. Perf. P. (envejecimos) |

| ४०. | **अततर्पत** | *तृप्* 4/6P: 2. Pl. P. / 3. Sg. Ā. Aor. Redupl. Caus. |
| ४१. | **तत्रिरे** | *त्रै* 1Ā: 3. Pl. Perf. Ā. (rescataron) |
| ४२. | **मात्रीकुरु** | *मात्रीकृ*: 2. Sg. Imper. P. (haz de madre / de medida) |
| ४३. | **आनीः** | *अन्* 2P: 2. Sg. Impf. P. (has respirado) |
| ४४. | **मानुषाभ्याम्** | *मानुष*: Instr. Dat. Abl. Du. m. n. (humano) |
| ४५. | **अजिघ्रपम्** | *घ्रा* 1P: 1. Sg. Aor. Redupl. P. Caus. (hice oler) |
| ४६. | **रते** | *रम्* 1Ā: PPP Loc. Sg. m. n.; Nom. Akk. Voc. Du. n.; Voc. Sg. f. |
| ४७. | **जातु** | en absoluto (Adv.) |
| ४८. | **जाती** | *जाति* f.: Nom. Akk. Voc. Du. (dos nacimientos) |
| ४९. | **जाता** | *जन्* 1Ā: PPP Nom. Sg. f. (la nacida) |
| ५०. | **अपरस्मै** | *अपर*: Dat. Sg. m. n. (a otro) |
| ५१. | **अदीपि** | *दीप्* 4Ā: 3. Sg. Aor. Pass. (se encendió) |
| ५२. | **अजूजुषाम** | *जुष्* 6Ā: 1. Pl. Aor. Redupl. P. Caus. (satisficimos) |
| ५३. | **नवानाम्** | *नव*: nueve; *नव*: Gen. Pl. m. f. n. (nuevo) |
| ५४. | **अश्रुणोः** | *अश्रु* n.: Gen. Loc. Du. (de dos lágrimas) |
| ५५. | **पृथक्पृथक्** | cada uno (Adv.) |
| ५६. | **असिष्णिहम्** | *स्निह्* 4P: 1. Sg. Aor. Redupl. P. Caus. (engrasé) |
| ५७. | **मन्मय्यः** | *मन्मय*: Nom. Pl. f. (las que consisten en mí) |
| ५८. | **औजिहः** | *ऊह्* 1Ā: 2. Sg. Aor. Redupl. P. Caus. (hiciste empujar) |
| ५९. | **अशिनट्** | *शिष्* 7P: 2. 3. Sg. Impf. P. (has dejado / ha dejado) |
| ६०. | **पाप्यभूवन्** | *पापीभू*: 3. Pl. Aor. raíz. P. (se han vuelto malos) |
| ६१. | **शोत्स्यामः** | *शुध्* 4P: 1. Pl. Fut. P. (limpiaremos) |
| ६२. | **अदीर्यथाः** | *दॄ* 9U: 2. Sg. Impf. Pass. (fuiste partido) |
| ६३. | **भस्मसात्संपेदे** | *भस्मसात्सम्पद्* 4Ā: 1. 3. Sg. Perf. Ā. (yo / él se convirtió en ceniza) |
| ६४. | **नवधा** | nueve veces (Adv.) |
| ६५. | **अविनक्** | *विज्* 7P: 2. 3. Sg. Impf. P. (temblaste / tembló) |
| ६६. | **आन** | *अन्* 2P: 1. 3. Sg. 2. Pl. Perf. P. (yo / él / ustedes respiraron) |
| ६७. | **शान्तयोः** | *शम्* 4P: PPP Gen. Loc. Du. m. f. n. (tranquilo) |
| ६८. | **वारीणि** | *वारि* n.: Nom. Akk. Voc. Pl. (las aguas) |
| ६९. | **वारिणी** | *वारि* n.: Nom. Akk. Voc. Du. (las dos aguas) |
| ७०. | **वारिणि** | *वारि* n.: Loc. Sg. (en el agua) |
| ७१. | **अद्भिः** | *अप्* f.: Instr. Pl. (por las aguas) |
| ७२. | **अदिध्मपन्** | *ध्मा* 1P: 3. Pl. Aor. Redupl. P. Caus. (hicieron soplar) |
| ७३. | **अववर्जन्** | *वृज्* 7P: 3. Pl. Aor. Redupl. P. Caus. (evitaron) |
| ७४. | **शितवत्यौ** | *शो* 4P: Nom. Akk. Voc. f. Du. Part. Perf. P. (-vant) |
| ७५. | **अहो** | ay, ¡ay! (Interj.) |
| ७६. | **एकशः** | cada uno, uno a uno (Adv.) |
| ७७. | **अपप्तः** | *पत्* 1P: 2. Sg. Aor. Redupl. P. (has volado) |
| ७८. | **अकस्मात्** | inesperadamente (Adv.) |
| ७९. | **मित्रध्रुक्** | *मित्रद्रुह्*: Nom. Voc. Sg. m. f. n. (dañador de enemigos) |
| ८०. | **अवोचन्** | *वच्* 2P: 3. Pl. a-Aor. P. (hablaron) |
