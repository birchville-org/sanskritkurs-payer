# Lección 54

Formen los correspondientes aoristos de las siguientes formas de presente o perfecto:

::: grammar-box
| Núm. | Forma | Determinación / Significado | Aoristo |
|:---|:---|:---|:---|
| ⟪१⟫. | **⟪यन्ति⟫** | ellos van | **⟪अगुः⟫** |
| ⟪२⟫. | **⟪पिबामि⟫** | yo bebo | **⟪अपाम्⟫** |
| ⟪३⟫. | **⟪ददौ⟫** | yo he / él ha dado | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | **⟪बभूव⟫** | yo / él / ellos fue / fuisteis | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | **⟪दधति⟫** | ellos sientan | **⟪अधुः⟫** |
| ⟪६⟫. | **⟪ऐम⟫** | nosotros fuimos | **⟪अगाम⟫** |
| ⟪७⟫. | **⟪पपिथ⟫** | tú has bebido / protegido | **⟪अपाः⟫** (a *:sig[⟪पा⟫]* "beber") |
| ⟪८⟫. | **⟪तिष्ठति⟫** | él está de pie | **⟪अस्थात्⟫** |
| ⟪९⟫. | **⟪इयेथ⟫** | tú has ido | **⟪अगाः⟫** |
| ⟪१०⟫. | **⟪पप⟫** | vosotros habéis bebido | **⟪अपात⟫** |
| ⟪११⟫. | **⟪एष्यथ⟫** | vosotros iréis | **⟪अगात⟫** |
| ⟪१२⟫. | **⟪तस्थुः⟫** | ellos estuvieron | **⟪अस्थुः⟫** |
| ⟪१३⟫. | **⟪अधत्त⟫** | vosotros sentasteis | **⟪अधात⟫** |
| ⟪१४⟫. | **⟪अददाः⟫** | tú diste | **⟪अदाः⟫** |
| ⟪१५⟫. | **⟪अभवन्⟫** | ellos fueron | **⟪अभूवन्⟫** |
| ⟪१६⟫. | **⟪ददिम⟫** | nosotros hemos dado | **⟪अदाम⟫** |
| ⟪१७⟫. | **⟪भिद्यते⟫** | se parte | **⟪अभेदि⟫** |
| ⟪१८⟫. | **⟪उद्यते⟫** | se dice | **⟪अवादि⟫** |
| ⟪१९⟫. | **⟪स्तूयते⟫** | él es alabado | **⟪अस्तावि⟫** |
| ⟪२०⟫. | **⟪कृष्यते⟫** | se ara | **⟪अकर्षि⟫** |
| ⟪२१⟫. | **⟪जायते⟫** | él nace | **⟪अजनि⟫** |
| ⟪२२⟫. | **⟪गीयते⟫** | se canta | **⟪अगायि⟫** |
| ⟪२३⟫. | **⟪गम्यते⟫** | se ha ido | **⟪अगामि⟫** |
