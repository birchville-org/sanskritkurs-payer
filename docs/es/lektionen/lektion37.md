# Lección 37

## 37.1. El adverbio (⟪क्रियाविशेषणम्⟫)

Los adverbios se forman en sánscrito

1. mediante formas casuales de sustantivos y pronombres
2. con ayuda de sufijos y terminaciones especiales

En el primer caso, la frontera entre el uso casuativo vivo y el adverbio es fluida. A esto pertenecen, como caso especial, los adverbios que son formas casuales antiguas cristalizadas, mientras que en la declinación se emplean otras formas o los sustantivos correspondientes ya no se utilizan como sustantivos.

## 37.2. Uso adverbial de formas casuales

### 37.2.1. Acusativo (⟪द्वितीया⟫)

::: grammar-box
El acusativo (⟪द्वितीया⟫) puede usarse adverbialmente para las preguntas:

* ¿de qué manera?
* ¿cuánto tiempo?
* ¿hacia dónde?
* y similares.

El acusativo puede usarse adverbialmente:

* de sustantivos  
Ejemplos:  
⟪कामम्⟫ "según el deseo, a voluntad"  
⟪अर्थम्⟫ "por causa de"

* de adjetivos en neutro  
Ejemplos:  
⟪सुखम्⟫ "fácilmente, felizmente"  
⟪नित्यम्⟫ "siempre"  
⟪साधु⟫ "correctamente, bien"

* de pronombres en neutro  
Ejemplos:  
⟪तद्⟫ "entonces, por eso"  
⟪यद्⟫ "cuando, que"  
⟪एतद्⟫ "así, aquí, ahora"
:::
### 37.2.2. Instrumental (⟪तृतीया⟫)

::: grammar-box
El instrumental (⟪तृतीया⟫) puede usarse adverbialmente para las preguntas:

* ¿por medio de qué?
* ¿con qué?
* y similares.

El instrumental puede usarse adverbialmente:

* de sustantivos  
Ejemplos:  
⟪अर्थेन⟫ "por causa de"  
⟪क्षणेन⟫ "en el momento, inmediatamente" (de ⟪क्षण⟫ m. "momento")

* de adjetivos, a menudo también en forma plural  
Ejemplos:  
⟪दूरेण⟫ "lejos, desde lejos" (a ⟪दूर⟫ 3 "lejos, distante de")  
⟪उच्चैस्⟫ "alto, fuerte" (a ⟪उच्च⟫ 3 "alto, elevado, fuerte, agudo (de voz)")
:::
### 37.2.3. Dativo (⟪चतुर्थी⟫)

::: grammar-box
Rara vez se usa el dativo (⟪चतुर्थी⟫) de manera adverbial para las preguntas:

*   ¿con qué propósito?
*   y similares.

Ejemplo:
:::
::: indent
⟪अर्थाय⟫ "con el propósito de, por ... sake"
:::
### 37.2.4. Ablativo (⟪पञ्चमी⟫)

::: grammar-box
El ablativo (⟪पञ्चमी⟫) puede usarse de manera adverbial para las preguntas:

*   ¿por qué?
*   ¿en virtud de quién/cosa?
*   ¿de dónde?
*   y similares.

El ablativo puede usarse de manera adverbial:

*   con sustantivos  
p.ej. ⟪बलात्⟫ "violentamente, con fuerza"  

*   con adjetivos  
p.ej. ⟪दूरात्⟫ "de lejos"  

*   con pronombres  
Ejemplos:  
⟪कस्मात्⟫ "por qué"  
⟪अकस्मात्⟫ "inesperadamente"
:::
### 37.2.5. Genitivo (⟪षष्ठी⟫)

::: grammar-box
Rara vez se usa el genitivo (⟪षष्ठी⟫) de manera adverbial para la pregunta "¿después de cuánto tiempo?"

p.ej. ⟪चिरस्य⟫ "después de mucho tiempo" (referido a ⟪चिर⟫ 3 "largo (tiempo)")
:::
### 37.2.6. Locativo (⟪सप्तमी⟫)

::: grammar-box
El locativo (⟪सप्तमी⟫) puede usarse de manera adverbial para las preguntas:

*   ¿dónde?
*   ¿bajo qué circunstancias?
*   y similares.

Ejemplos:
:::
::: indent
\-⟪अर्थे⟫ "debido a"  
\-⟪कृते⟫ "por sake de"  
⟪दूरे⟫ "lejos"
:::
## 37.3. Uso adverbial de formas casuales ya no en uso

Ejemplos:
::: indent
⟪जातु⟫ "en absoluto" (originalmente "por nacimiento, por naturaleza", acusativo singular neutro de ⟪जातु⟫ \<ya no usado como sustantivo\>)

⟪तूष्णीम्⟫ "silenciosamente" (acusativo singular de un ⟪तूष्णी⟫ f. "silencio" ya no en uso)

⟪एवम्⟫ "así" (referido a una raíz pronominal de lo contrario perdida ⟪एव⟫ "uno, único")
:::
## 37.4. Formación de adverbios con sufijos adverbiales

::: grammar-box
De las raíces pronominales ⟪तद्⟫, ⟪इदम्⟫ o bien ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ o bien ⟪कु⟫ se pueden derivar con los sufijos adverbiales

*   \-⟪तस्⟫ (ablativo)
*   \-⟪त्र⟫ (locativo)
*   \-⟪था⟫ (modo)
*   \-⟪थम्⟫ (modo)
*   \-⟪दा⟫ (tiempo)

los correspondientes adverbios pronominales.
:::
::: grammar-box

| Sufijo | Raíz pronominal | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(Ablativo) | ⟪ततस्⟫ :brde allí, sobre eso, por ello | ⟪इतस्⟫ :br ⟪अतस्⟫ :brde aquí, por esto | ⟪यतस्⟫ :brde dónde, de qué | ⟪कुतस्⟫ :br¿de dónde?, ¿por qué? |
| **-⟪त्र⟫** :br(Locativo) | ⟪तत्र⟫ :brallí, allí | ⟪अत्र⟫ :braquí | ⟪यत्र⟫ :brdónde | ⟪कुत्र⟫ :br¿dónde? |
| **-⟪था⟫** :br(Modo) | ⟪तथा⟫ :brasí | | ⟪यथा⟫ :brcómo | |
| **-⟪थम्⟫** :br(Modo) | | | | ⟪कथम्⟫ :br¿cómo? |
| **-⟪दा⟫** :br(Tiempo) | ⟪तदा⟫ :brentonces, entonces | | ⟪यदा⟫ :brcuando (en ese momento) | ⟪कदा⟫ :br¿cuándo? |

:::

## 37.5. Compuestos adverbiales

### 37.5.1. Compuestos con un adverbio o caso usado como adverbio como segundo miembro

Ejemplo: ⟪सुचिरम्⟫ "muy largo (tiempo)"

### 37.5.2. ⟪बहुव्रीहि⟫ usados como adverbios

Ejemplo: ⟪रक्षार्थम्⟫ "del tipo de alguien cuyo propósito es proteger, con el propósito de proteger". También puede considerarse perteneciente a 5.1.: -⟪अर्थम्⟫ como segundo miembro adverbial.

### 37.5.3. Compuestos ⟪अव्ययीभाव⟫

⟪अव्ययीभाव⟫ = "que se ha vuelto invariable/no declinable"

::: grammar-box
Un ⟪अव्ययीभाव⟫ es un compuesto adverbial cuyo primer miembro es un indeclinable (posposición, partícula, etc.) y cuyo segundo miembro es un sustantivo que toma la terminación del acusativo singular neutro.

Al resolver el compuesto, el primer miembro regiría al segundo:

Ejemplos:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = "contra el fuego"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "según las fuerzas"

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = "hacia adelante, en dirección a"
:::
Especialmente importantes son los ⟪अव्ययीभाव⟫ con ⟪यथा⟫ "como" como primer miembro:

p.ej. ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ = "como es el deseo, según el deseo, arbitrariamente"

## 37.7. Pronombres indefinidos

::: grammar-box
Los pronombres indefinidos (palabras indeterminadas) se forman añadiendo

*   \-⟪चिद्⟫
*   \-⟪चन⟫
*   ⟪अपि⟫

al caso del pronombre interrogativo ⟪किम्⟫.

p.ej.
:::
::: indent
⟪कश्चिद्⟫ = ⟪कश्चन⟫ = ⟪को ऽपि⟫ = "alguien, cualquiera"  
⟪कस्यचिद्⟫ = de alguien
:::
## 37.8. La oración interrogativa

::: grammar-box
"¿Quién?, ¿cómo?, ¿qué?, ¿por qué?  
Quien no pregunta, se queda ignorante."

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

Lema de Sesamstrasse (Plaza Sésamo), que es una buena guía para la vida y el estudio del sánscrito
:::
Véase también [Lección 4](lektion04.md).

Hay que distinguir entre

*   Preguntas por palabras (preguntas complementarias)
*   Preguntas por oraciones

En las preguntas por palabras se pregunta por un agente (⟪कर्तृ⟫), un objeto, una acción, una circunstancia, etc., p.ej.

*   ¿quién viene?
*   ¿qué hace Rāma?
*   ¿a quién escucha él?
*   ¿cómo habla ella sánscrito?
*   ¿dónde está la madre?

En las preguntas por oraciones se pregunta por todo el contenido de la oración, p.ej.

*   ¿va Rāma hoy a Ofterdingen?
*   ¿es correcto que ... ?

### 37.8.1. Preguntas por palabras (preguntas complementarias)

::: grammar-box
Esquema:

Pronombre interrogativo/adverbio interrogativo - Oración
:::
Ejemplos:
::: indent
⟪को ग्रामं गच्छति⟫ =  ⟪केन ग्रामो गम्यते⟫ = "¿Quién va a la aldea?"

⟪किं बाला अधीयीरन्⟫ = "¿Qué deberían aprender los niños?"

⟪क्व रामो वसति⟫ = ¿Dónde vive Rāma?
:::

### 37.8.2. Preguntas de oración

::: grammar-box
A veces solo es evidente por el contexto si una oración es una pregunta.
:::
::: grammar-box
Esquema I:

Verbo - resto de la oración
:::
Ejemplo:
::: indent
⟪गमिष्यति ब्राह्मणबालो गुरुम् ।⟫ "¿Acudirá el joven brahmán a un maestro?"
:::
::: grammar-box
Esquema II:

Partícula interrogativa (generalmente al inicio de la oración) - oración

Las partículas interrogativas más importantes son:

*   ⟪अपि⟫

*   ⟪किम्⟫ (a menudo hace esperar una respuesta negativa)

*   ⟪कच्चिद्⟫


Estas partículas corresponden al signo de interrogación.
:::
Ejemplo:
::: indent
⟪अपि सत्यम् ।⟫ "¿Es también verdad?"

⟪किं शक्नोति ।⟫ "¿Puede él acaso?"

⟪कच्चित्क्षत्रियेण शत्रवो जिताः ।⟫ "¿Acaso el kṣatriya ha derrotado a los enemigos?"
:::
Nota: ⟪किम्⟫ puede significar no solo "¿qué?" sino también, como partícula interrogativa, "¿por qué?, ¿para qué?". Así especialmente con el instrumental (⟪तृतीया⟫):
::: indent
⟪किं क्रोधेन ।⟫ "¿Para qué la cólera? ¿De qué sirve la cólera? ¿Qué se propone la cólera?"
:::

## 37.11. Ejercicio de repaso

Traduzca al sánscrito utilizando exclusivamente formas verbales del perfecto:

Una vez, cuando un anciano iba a otro pueblo, se cansó en el camino. Entonces fue para descansar hasta la base de un árbol de mango que estaba al lado. En este árbol había frutos maduros. El anciano tuvo ganas de estos. Pero no pudo subir al árbol ni alcanzar los frutos. Por suerte, había algunos monos en este árbol que comían frutos. Cuando los vio, el anciano se alegró. ¿Qué hizo? Tomó algunas piedras, apuntó a los monos y lanzó. Los monos enfadados recogieron algunos frutos y se los lanzaron al anciano. El anciano tomó estos con alegría y fue hacia la región deseada. ¡Vean, el destino del anciano!
