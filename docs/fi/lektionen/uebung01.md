# Harjoitus 1

Luento 1 ei sisällä kirjallisia harjoituksia, koska se on suunniteltu äänneoppi- ja ääntämisesittelyksi. Luennon lopussa olevat lukuharjoitukset palveleva äänteiden käytännön harjoittelua, eivätkä ne vaadi erillistä ratkaisuvihkosta.
