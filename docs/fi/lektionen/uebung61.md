# Harjoitus 61

Luento 61 muodostaa sanskrittikurssin lopetuksen, eikä se sisällä enempää kirjallisia harjoituksia.

Juurtenominatiivien, perifraastisen tulevaisuuden aikamuodon ja nominatiivijohdannaisten opiskelun myötä perusteet sanskritinkielisten alkuperäisteosten lukemiseen on luotu. Kurssi päättyy perinteiseen Gaṇeśa-kutsuun (⟪श्रीगणनाथ⟩), joka merkitsee siirtymää oppikirjasta itsenäiseen lukemiseen.
