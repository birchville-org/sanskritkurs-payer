# Luento 30

## 30.1. 9. preesensluokka (⟪क्र्यादि⟫ = "⟪क्री⟫ jne.")

::: grammar-box
**Muodostus:**

*   vahva vartalo: syönnyn juuri + -nā-

*   heikko vartalo:

    *   konsonantin edellä: syönnyn juuri + -nī-

    *   vokaalin edellä: syönnyn juuri + -n-
:::
Esimerkki:

::: indent
⟪क्री⟫ 9U "ostaa"
:::
::: grammar-box

| | yksikkö:br⟪एकवचन⟫ | monikko:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. persoonan:brParasmaipada** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **3. persoonan:brĀtmanepada** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
Tässä preesensluokassa on erityisesti huomioitava preesanssivarsan muodostaminen juureen ⟪ज्ञा⟫ 9U "tunnistaa, tietää":

::: grammar-box

| | yksikkö:br⟪एकवचन⟫ | monikko:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **3. Person:brĀtmanepada** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
Muoto ⟪जा⟫, joka perustuu preesensvartoon ⟪ज्ञा⟫, voidaan joko selittää ablautisarjalla -ā (matala aste) -nā (korkea aste), tai dissimilaatiolla muodosta *jñā-nā-ti.

Jotkin pitkän vokaalin sisältävät verbijuuret lyhentävät tätä vokaalia ennen preesensvartopäätteen 9. konjugaatioluokkaa:

Esimerkki:

::: indent
⟪पू⟫ 9U "puhdistaa"
:::
::: grammar-box

| | yksikkö:br⟪एकवचन⟫ | monikko:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. persoonan:brParasmaipada** | ⟪पुनाति⟫:br(pu-nā-ti) | ⟪पुनन्ति⟫:br(pu-n-anti) |
| **3. persoonan:brĀtmanepada** | ⟪पुनीते⟫:br(pu-nī-te) | ⟪पुनते⟫:br(pu-n-ate) |

:::
Preesin partisiivin Parasmaipada-muodon muodostus:

Esimerkki:

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant) ; fem.: ⟪क्रीणती⟫ (krī + n + at + ī)

## 30.2. Optatiivin käyttö (⟪लिङ्⟫)

Optatiivia käytetään:

::: grammar-box
**1. ilmaisemaan**

*   **toivetta**
*   **pyyntöä**
*   **lievennettyä käskyä**

**(tässä optatiivi - ⟪लिङ्⟫ - leikkaa imperatiivin kanssa - ⟪लोट्⟫)**
:::
Esimerkki:

::: indent
⟪दासो⟫ ⟪ग्राममागच्छेत्⟫ = "Orja tulkaa kylään"
:::
::: grammar-box
**2. Jos jotain**

*   **mahdollisena**
*   **todennäköisenä**
*   **arveltaisiin**

**halutaan esittää.**
:::
Esimerkki:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं⟫ ⟪न⟫ ⟪शृणुयात्⟫ = "Hän menisi kylästä, hän ei kuulis opettajaa"
:::
::: grammar-box
**3. Optatiivisia suhteellislauseita voi joskus tarkoittaa: "Jos joku ..."**
:::
Esimerkki:

::: indent
⟪यो⟫ ⟪नृतं⟫ ⟪वदेत्स⟫ ⟪नरकं⟫ ⟪पतेत्⟫ = "Jos joku sanoisi epätotuutta, hän lankeaisi helvettiin = Jos joku sanoo epätotuutta, hän langkee helvettiin"
:::

:::

## 30.5. Lopun -r:n sandhi

::: grammar-box
**Paitsi -ar:n kohdalla, lopun -r:lle pätevät samat sandhisäännöt kuin lopulle -s:lle.**

**-ar tönäisten äänneaseiden edellä pysyy -ar, mutta r-:n edessä -r katoaa ja -a- korvautuu -ā:lla.**
:::
Esimerkit:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
