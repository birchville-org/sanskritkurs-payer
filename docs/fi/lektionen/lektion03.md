# Oppitunti 3

## 3.1. Nominatiivin yksikkö naispuolisessa sukuvaihtelussa

### 3.1.1. Nominatiivin yksikkö päättymällä -s

Myös seuraavat vokaalilla päättyvät substantiivinvartalo muodostavat nominatiivin yksikössä pääte **-s**:

::: grammar-box
- **Naispuoliset substantiivit päättelyllä -i**: esim. **śruti** f. "kuuleminen" -- Nom. sg.: **śrutis** = ⟪श्रुतिस्⟫
- **Naispuoliset substantiivit päättelyllä -u**: esim. **dhenu** f. "maitolehmä" -- Nom. sg.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Nominatiivi yksikössä ilman päätettä

Nominatiivin yksikkö muodostetaan ilman päätettä:

::: grammar-box
- **Naispuoliset substantiivit päättelyllä -ā**: esim. **devatā** f. "jumaluus" -- Nom. sg.: **devatā** = ⟪देवता⟫
- **Naispuoliset substantiivit päättelyllä -ī**: esim. **devī** f. "jumalatar" -- Nom. sg.: **devī** = ⟪देवी⟫
:::
::: important
**Huomio!** Sen lisäksi on olemassa yksitavuisia naispuolisia juurisubstantiiveja päättelyllä -ī, joiden nominatiivin yksikkö päättyy s-äänneeseen: esim. dhī f. "ajatus" -- Nom. sg.: dhīs = ⟪धीस्⟫. Myös lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "vene" ja tantrī (⟪तन्त्री⟫) f. "kieli" muodostavat epäsäännöllisesti nominatiivin yksikön päättelyllä -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Feminiinien muodostaminen maskuliineista

::: grammar-box
**-a-päätteiset maskuliinit:**
- **feminiinien pääte on -ā**: esim. **kṣatriya** m. » **kṣatriyā** f. "Ksatriyanainen" = ⟪क्षत्रिया⟫
- **feminiinien pääte on -ī**: esim. **brāhmaṇa** m. » **brāhmaṇī** f. "Brahmaninainen" = ⟪ब्राह्मणी⟫

**-u-päätteiset maskuliinit:**
- **feminiinien pääte on -ī**: esim. **sādhu** m. » **sādhvī** f. (hyvä, pyhimys) = ⟪साध्वी⟫
(**-u-** muuttuu vokaalin edellä muodoksi **-v-**, joten **-u- + -ī** » **-vī**)
:::

## 3.3. Maskuliinin ja feminiinin nominatiivin monikko

::: grammar-box
Maskulinin ja feminiinin nominatiivin monikon pääte on **-as**.
- **Maskuliinit vokaalipäätteellä -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **Feminiinit vokaalipäätteellä -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **Maskuliinit vokaalipäätteellä -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **Feminiinit vokaalipäätteellä -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **Feminiinit vokaalipäätteellä -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **Maskuliinit vokaalipäätteellä -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **Feminiinit vokaalipäätteellä -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Huomautus: **e** on korkeampi aste (**guṇa**) vokaalille **i**, ja **o** on korkeampi aste vokaalille **u**.

## 3.4. Vokalisandhi

::: grammar-box
**Yksinkertaiset vokaalit, jotka eroavat vain pituudeltaan tai eivät lainkaan, "sulautuvat" vastaavaksi pitkäksi vokaaliksi:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
Esim.

devatā + annapūrṇā » devatānnapūrṇā "Annapūrṇā on jumalatar" = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā on ruokien ja keittämisen jumalatar, häntä pidetään Pārvatīn, Śivan vaimon, ilmentymänä.)

devī + indrāṇī » devīndrāṇī "Indrāṇī on jumalatar" = ⟪देवीन्द्राणी⟫

> (Indrāṇī on jumala Indran vaimo.)

::: grammar-box
**Yksinkertaiset vokaalit (paitsi -a / -ā) korvataan vastaavalla puolivokaalilla epäsamanlaisten vokaalien edellä:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! Tälle säännölle on erityisesti kaksikkomuodoissa poikkeuksia !!)
:::
esim.

devī + umā » devy umā "Umā on jumalatar" = ⟪देव्युमा⟫

> (Umā on nimi Pārvatīlle, Śivan vaimolle)

::: grammar-box
**-a / -ā epäsamanlaisen vokaalin edellä:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**

## 3.5. Satzsandhi -ās:lla

::: grammar-box
**-ās wird vor allen stimmhaften Lauten durch -ā ersetzt.**
:::
esim.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Vaišyat ovat kaksinkertaisesti syntyneet" = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. Sanalista

**Opettele seuraavat sanat:**

**śruti** f. = ⟪श्रुति⟫ : kuuntelu, ikuinen perimätieto (nimitys Vedeille ja Brāhmaṇa-teoksille).

**smṛti** f. = ⟪स्मृति⟫ : läsnäolo, muistaminen, meditatiivinen läsnäolo = huomioisuus, perimätieto (**śruti**n vastakäsite). Kattaa:
- kuusi **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): oikea ääntäminen
  2. **chandas** n. (⟪छन्दस्⟫): mittasäe
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): kielioppi
  4. **nirukta** n. (⟪निरुक्त⟫) : sanaselitys, etymologia
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : tähtitiede, kalenteriope
  6. **kalpa** m. (⟪कल्प⟫) : seremonia
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : opukset suurten uhrausten suorittamisesta
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : opukset arkisten seremonioiden ja uhrausten käsittelystä
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) ja **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : opukset oikeudesta ja tavasta (oikea käytös)
- suuret eepokset **mahābhārata** n. (⟪महाभारत⟫) ja **rāmāyaṇa** n. (⟪रामायण⟫)
- **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : elämänviisauden opukset

**smṛti** on erityisesti myös nimitys dharmaopeille.

**dhenu** f. = ⟪धेनु⟫ : (maitoa antava) lehmä.

**paśu** m. = ⟪पशु⟫ : domesticoidtu kotieläin, karja (kollektiivi).

**devatā** f. = ⟪देवता⟫ : jumaluus (abstrakti ja konkreetinen).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : brāhmaṇi (nainen).

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : naispuolinen kṣatriya.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : Kṣatriyan vaimmainen.

**vaiśyā** f. = ⟪वैश्या⟫ : naispuolinen vaiśya.

**śūdrā** f. = ⟪शूद्रा⟫ : naispuolinen śūdra.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : śūdran vaimmainen.

**devī** f. = ⟪देवी⟫ : jumalatar, erityisesti Durgā f. = ⟪दुर्गा⟫, Šivan vaimo = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)

**sādhvī** f. = ⟪साध्वी⟫ : fem. sanasta sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : fem. sanasta guru.

**asmitā** f. = ⟪अस्मिता⟫ : "minä-olo", ts. (väärä) usko: **Minä** olen se, joka näkee jne.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : filosofia (tiede, joka päättelynsä johtopäätöksiin loogisesti oikeutetuilla perusteluilla).

**upekṣā** f. = ⟪उपेक्षा⟫ : huomioimatta jättäminen, tasapainoisuus.

**karuṇā** f. = ⟪करुणा⟫ : myötätunto, sääli.

**muditā** f. = ⟪मुदिता⟫ : ilo, erityisesti iloitseminen (vastakohta kateudelle).

## 3.7. Harjoitus

**A) Muunna seuraavat lauseet monikkoon:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**B) Muodosta sijoittamalla nimellisiä lauseita:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Muunna feminiiniksi:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**D) Käännä sanskritiksi:**

1. Umā on jumalatar.
2. Veda on śruti.
3. Opettajat ovat jumalattaria.
4. Maitolehmät ovat kesytettyjä eläimiä.
5. Runoilijat ovat opettajia.
6. Kṣatriyas ovat kaksinkertaisesti syntyneitä.
7. Pyhät miehet ovat śūdras.
