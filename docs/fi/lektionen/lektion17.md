# Oppitunti 17

## 17.1. Toinen preesensluokka (⟪अदादि⟫ = ⟪अद्⟫ jne.)

Verppäätteet liitetään suoraan vartalon juureen. Tässä yhteydessä on huomioitava sanayhdistymisen (sandhi) aiheuttamat äännemuutokset.

::: grammar-box

Toinen preesensluokka muodostuu seuraavilla tavoilla:

1. Vartalon astevaihtelua käyttävät juuret
*   yleisin: vahva aste – heikko aste
*   joissakin juuressa: pidennetty aste – heikko aste
2. Vartalon astevaihtelua käyttämättömät juuret
3. Kaksitavuiset -i/-ī-päätteiset juuret, joissa on vartalon astevaihtelua

:::
## 17.2. Toinen preesensluokka: vartalon astevaihtelua käyttävät juuret (vahva aste – heikko aste)

Esimerkkejä:

⟪द्विष्⟫ 2 U "vihata"

*   vahva preesensvartalo: dveṣ-
*   heikko preesensvartalo: dviṣ-

## 17.5. Kaksitavuiset -i/-ī-päätteiset vartalonmuodostelut

Useat verbivarsi ovat monissa taivutusmuodoissaan kaksitavuisia, eli ne sisältävät konsonanttisen päätteen edellä -i:n (tai tietyissä päätteissä -ī:n). Nämä varret kuitenkin luokitellaan kotimaisten grammatistien ja sanakirjojen mukaan silti yksitavuisiksi.

Esimerkkejä:

⟪रुद्⟫ 2 P "itkua, ulvoa"

*   vahva preesensvarsi: rodi-
*   heikko preesensvarsi:
*   konsonantin edellä: rudi-
*   vokaalin edellä: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "puhua"

*   vahva preesensvarsi: bravī- (« bro- + -ī)
*   heikko preesensvarsi:
*   konsonantin edellä: brū-
*   vokaalin edellä: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Myös ⟪स्तु⟫ 2 U "ylistää" sisältää kohdassa 3. mainittujen muotojen lisäksi tämän mallin mukaisia muotoja:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::
