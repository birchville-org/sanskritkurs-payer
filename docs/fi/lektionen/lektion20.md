# Luento 20

## 20.1. Possessiivikomposita = ⟪बहुव्रीहि⟫ m.

::: media
![](/images/lekt2004.webp)
Kuva: ⟪बहुव्रीहिः⟫ ⟪पुरुषः⟫
Jodhpur = ⟪जोधपुर⟫
(Kuv lähde: [Yksityiskohdat](/fi/licenses#lekt2004))
:::
⟪बहुव्रीहिः⟫ = ⟪बहवो⟫ ⟪व्रीहयो⟫ ⟪यस्य⟫ ⟪सः⟫ = "joka omistaa paljon riisiä"

::: grammar-box

**Bahuvrīhi-koostumus tarkoittaa erona Tatpuruṣa-kompositumiin jotakin muuta kuin mitä sen osat ilmaisevat: kun ⟪बालपुत्रः⟫ ratkaistaan Tatpuruṣana "nuori poika", eli jotain, mitä ilmaisee koostumuksen pääte (⟪पुत्र⟫), tarkoittaa ⟪बालपुत्रः⟫ Bahuvrīhina ratkaistuna "jonka poika on nuori", eli merkitty ei ole poika (⟪पुत्र⟫) eikä välttämättä nuori (⟪बाल⟫), vaan nuoresta pojasta erillinen henkilö, nimittäin hänen isänsä.**

**Posessiivikompositumit ovat aluksi aina adjektiiveja, jotka voidaan kuitenkin substantivoida. Siksi Bahuvrīhin grammatillinen suku riippuu siitä, mihin Bahuvrīhi viittaa, eikä viimeisen koostumusosan suvusta.**

:::
::: grammar-box

**Kaava bahuvrīhin ratkaisemiseksi:**

**1. Jäsen yleensä nominativissa (⟪प्रथमा⟫) yksikössä, duaalissa tai monikossa -- 2. Jäsen nominativissa yksikössä, duaalissa tai monikossa -- Relatiivipronomini muussa sijassa kuin nominatiivi (yleensä genetiivi - ⟪षष्ठी⟫) ja sukuna sekä lukuna koko bahuvrīhin mukainen -- Demonstratiivipronomini lukuna, sijana ja sukuna koko bahuvrīhin mukainen.**

:::
Esimerkkejä:

::: indent
⟪गतपापः⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪सः⟫ = "joka, jonka paha on mennyt" = "joka on vapaa huonoista teoista"

Akk. sg. ⟪गतपापम्⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तम्⟫

Inst. sg. ⟪गतपापेन⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तेन⟫

Gen. sg. ⟪गतपापस्य⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तस्य⟫

Nom. pl. ⟪गतपापाः⟫ = ⟪गतानि⟫ ⟪पापानि⟫ ye⟪षां⟫ ⟪ते⟫

jne.

⟪अस्तमोहा⟫ = ⟪अस्तो⟫ ⟪मोहो⟫ ⟪यया⟫ ⟪सा⟫ = "nainen, joka on hylännyt harhaan"

⟪प्राप्तोदको⟫ ⟪ग्रामः⟫ = ⟪प्राप्तमुदकं⟫ ⟪यं⟫ s ⟪ग्रामः⟫ = "kylä, johon vesi on yltänyt" = "tulvauhanalainen kylä"

⟪पुण्यवत्पुत्रः⟫ bahuvrīhina = ⟪पुण्यवान्पुत्रो⟫ ⟪यस्य⟫ ⟪सः⟫, tai: ⟪पुण्यवन्तः⟫ ⟪पुत्रा⟫ ⟪यस्य⟫ ⟪सः⟫ = "joka omistaa ansion" tai: "jonka pojat omistavat ansion"
:::
::: grammar-box

**Vahuvrīhin etuliitteen ja jälkiliitteen välinen suhde voi olla:**

*   **attributiivinen**
*   **apposiitio**
*   **kasuaali**
*   **adverbiaalinen**

**Kuten Tatpuruṣassa tarkemmin määritetty jäsen on yleensä toisena.**

:::

*   ⟪समानाधिकरणबहुव्रीहिः⟫: sanassa ⟪विग्रहवाक्य⟫ etujäsen ja jälkijäsen ovat samassa sijamuodossa

*   ⟪व्यधिकरणबहुव्रीहिः⟫: sanassa ⟪विग्रहवाक्य⟫ etujäsen ja jälkijäsen ovat eri sijamuodoissa

## 20.2. Bahuvrīhi, jonka etujäsen on attribuutti

::: grammar-box

**Kaava:**

:::
::: indent
**Adjektiivi -- Substantiivi**
:::
**Esimerkki:**

::: indent
⟪गुणवत्पुत्रो⟫ ⟪ब्राह्मणः⟫ =  ⟪गुणवान्पुत्रो⟫ ⟪यस्य⟫ ⟪स⟫ ⟪ब्राह्मणः⟫ = "brahmanina, jolla on hyväominaisuuksia omaava poika / pojat"
:::
**Erityisen yleistä on -- Tatpuruṣassa harvinainen -- attribuuttimääritys PPP:llä. Relatiivipronomini on ratkaisussa yleensä instrumentaalisissa (⟪तृतीया⟩) (harvemmin genetiivissä / ⟪षष्ठी⟩).**

**Kultasääntö:**

*   **PPP - substantiivi = useimmiten Bahuvrīhi**
*   **Substantiivi -- PPP = useimmiten Tatpuruṣa**

**Esimerkki:**

::: indent
⟪कृतफल⟫ ⟪३⟫ = ⟪कृतं⟫ ⟪फलं⟫ ye⟪न⟫ ⟪सः⟫ ⟪।⟫ ⟪यया⟫ ⟪सा⟫ ⟪।⟫ ye⟪न⟫ ⟪तत्⟫ = "yksi / yksi / yksi, joka tuotti tuloksen, joku / jotain tehokas"
:::
## 20.3. Bahuvrīhi appositionaalisen etuosan kanssa

::: grammar-box

**Kaava:**

:::
::: indent
**Substantiivi -- Substantiivi**
:::
**Esimerkit:**

::: indent
⟪शूरपुत्रो⟫ ⟪नरः⟫ = ⟪शूरा⟫ ⟪एव⟫ ⟪पुत्रा⟫ ⟪यस्य⟫ ⟪स⟫ ⟪नरः⟫ = "mies, jonka pojat ovat sankareita"

⟪तदन्त⟫ ⟪३⟫ = ⟪सो⟫ ⟪ऽन्तो⟫ ⟪यस्य⟫ ⟪सः⟫ ⟪।⟫ ⟪यस्याः⟫ ⟪सा⟫ ⟪।⟫ ⟪यस्य⟫ ⟪तत्⟫ = "joka / joka / joka, jonka pää on tämä" = "tällä päättyvä"
:::
::: grammar-box

**Erittäin tärkeitä ovat apposiittiset Bahuvrīhi-yhdyssanat, joiden jälkiosat ovat ⟪आदि⟫ ⟪।⟫ ⟪आदिक⟫ ⟪।⟫ ⟪आद्य⟫ "ensimmäinen, alku", harvemmin ⟪प्रभृति⟫ "alku". Tällaiset yhdyssanat vastaavat "jne.":**

**Esimerkki:**

:::
::: indent
⟪देवा⟫ ⟪इन्द्रादयः⟫ =  ⟪इन्द्र⟫ ⟪आदिर्येषां⟫ ⟪ते⟫ ⟪देवाः⟫ = "Jumalat, joiden alku on Indra" = "jumalat Indra jne." = "Indra ja muut jumalat"
:::
**"Vain"-merkityksen ilmaisemiseksi voidaan käyttää bahuvrīhi-yhdyssanoja, joiden jälkiosana on ⟪मात्रा⟫ f. "mitta, raja":**

**Esimerkki:**

::: indent
⟪शब्दमात्रम्⟫ = ⟪शब्दो⟫ ⟪मात्रा⟫ ⟪यस्य⟫ ⟪तत्⟫ = "sanan-mātra-samāna-artha" = "jonka mittana on sana" = "vain yksi sana"
:::
**⟪मात्र⟫ kun sitä seuraa partisiipin menneisyyden passiivin muoto (PPP), se käännetään "heti kun" tai "sillä hetkellä, kun":**

**Esimerkki:**

::: indent
⟪जातमात्रं⟫ ⟪शत्रुं⟫ ⟪घ्नन्ति⟫ = ⟪जातं⟫ ⟪मात्रा⟫ ⟪यस्य⟫ ⟪तं⟫ ⟪शत्रुं⟫ ⟪घ्नन्ति⟫ = "jātv-antakaṃ śatruṃ vadanti" = "he tappavat vihollisen, jonka syntyminen on mittana" = "he tappavat vihollisen heti kun se on syntynyt"

## 20.5. Bahuvrīhi adverbiaalisella etuosalla

Etuosassa on adverbialauseke, prepositio, prefiksi tai muu indeklinabii; tällaiset yhdyssanat ovat yleensä ⟪नित्यसमास⟩.

Esimerkit:

::: indent

## 20.6. Bahuvrīhi-loppuosan taivutus

::: grammar-box

**Bahuvrīhin loppupääte taivutetaan sukupuolesta riippumatta monisukupuolisena adjektiivina. Jos yhdyssanan loppupääte on eri sukua kuin alkuperäinen, sen täytyy olla Bahuvrīhi, ellei se ole Samāhāradvanva (neutri yksikkö).**

**Adjektiivisoinnissa**

*   **-ā-vaikaiset muuttuvat maskuliinissa ja neutriissä -a-vaikaisiksi**
*   **-a-vaikaiset (m., n.) muodostavat feminiinimuodon -ā tai -ī**
*   **-ī-vaikaiset (f.) on otettava Bahuvrīhin lopussa suffiksi -ka, -kā, -ka (n.); monet muutkin Bahuvrīhit voivat tai täytyy ottaa tämä suffiksi**

:::
## 20.7. Toinen luokittelu Bahuvrīhi-tyypeistä

Esimerkit on annettu myöhempää käsittelyä varten; joillekin niistä tarvittavaa kielioppia ja sanastoa ei ole vielä käsitelty

1.  määrittävä sana etuosassa -- määritetty sana jälkiosassa: ⟪स्थिरचित्तः⟫ = ⟪स्थिरं⟫ ⟪चित्तं⟫ ⟪यस्य⟫ ⟪सः⟫
2.  indeklinabi etuosassa: ⟪उच्चैःश्रवस्⟫
3.  vertaus etuosassa: ⟪कुशाग्रधीः⟫ =  ⟪कुशाग्र⟫ ⟪इव⟫ ⟪धीर्यस्य⟫ ⟪सः⟫
4.  implisiittinen vertaus: ⟪उष्ट्रमुखः⟫ = ⟪उष्ट्रस्य⟫ ⟪मुखमिव⟫ ⟪मुखं⟫ ⟪यस्य⟫ ⟪सः⟫ = "kamelin suu" = jonka suu on kuin kamelin
5.  numeraali jälkiosassa likimääräisen määrän ilmaisemiseen: ⟪उपसशाः⟫ = ⟪दशानां⟫ ⟪समीपे⟫ ⟪ये⟫ ⟪सन्ति⟫ ⟪ते⟫ = "noin kymmenen"
6.  molemmat osat ovat numeraaleja: ⟪एकद्वाः⟫ = ⟪एको⟫ ⟪वा⟫ ⟪द्वौ⟫ ⟪वा⟫ = "yksi tai kaksi"
7.  sanalla sa-/saha- etuosassa: ⟪सपुत्रः⟫ ⟪।⟫ ⟪सहपुत्रः⟫
8.  sanalla sa- (= ⟪समान⟫) etuosassa: ⟪सजनपदः⟫ = ⟪समानो⟫ ⟪जनपदो⟫ ⟪यस्य⟫ ⟪सः⟫
9.  ⟪नञ्बहुव्रीहिः⟫ = sanalla a-/an- etuosassa: ⟪अपुत्रः⟫ = ⟪न⟫ ⟪विद्यते⟫ ⟪पुत्रो⟫ ⟪यस्य⟫ ⟪सः⟫ ; ⟪अनङ्गः⟫ = ⟪न⟫ ⟪विद्यते⟫ ⟪अङ्गं⟫ ⟪यस्य⟫ ⟪सः⟫
10.  prepositiolla ja vastaavilla etuosassa: ⟪प्रवातः⟫ =⟪प्रकृष्टो⟫ ⟪वातो⟫ ⟪यस्मिन्⟫ ⟪सः⟫ ; ⟪निर्धनः⟫ = ⟪निर्गतं⟫ ⟪धनं⟫ ⟪यस्मात्सः⟫ ; ⟪सुबुद्धिः⟫ = ⟪सुष्ठु⟫ ⟪बुद्धिर्यस्य⟫ ⟪सः⟫ ; ⟪दुर्बुद्धिः⟫ = ⟪दुष्टा⟫ ⟪बुद्धिर्यस्य⟫ ⟪सः⟫

12.  PPP etuosassa: ⟪कृतकटः⟫ = ⟪कृतः⟫ ⟪कटो⟫ ⟪येन⟫ ⟪सः⟫

## 20.8. Bahuvrīhin ja suhteellislauseen välinen suhde

Vaikka jokainen Bahuvrīhi voidaan ratkaista suhteellisella lauseella, ei jokaista suhteellislauseita voida korvata Bahuvrīhilla. Hermann Georg Jacobi (1850 - 1937), joka on tutkinut näiden välistä suhdetta tarkemmin (Compositum und Nebensatz, 1897), kirjoittaa:

::: indent
"Käännettäessä saksasta tai jostakin muusta nykysanskritista sanskritiin, ei kaikkia sivulauseita voida ilmaista yhdyssanoilla, vaan vain koristeelliset ja kuvailevat; ne kuitenkin, jotka sisältävät käsitteellisesti välttämättömän tai tärkeän määritelmän, esiintyvät sanskritissa myös suhteellisina lauseina."
:::
::: media
![](/images/lekt2002.jpg)
Kuv.: Hermann Jacobi
(Kuvan lähde: [Details](/fi/licenses#lekt2002))
:::
Tämä voi pitää paikkansa. Intialaiset kuitenkin pitävät monia asioita koristeellisina ja kuvailevina, mitä me pitäisimme "käsitteellisesti välttämättöminä tai tärkeinä."

B) Käännä sanskritiksi käyttämällä yhdyssanoja:

1\. Sauvaa kädessään pitämätön ksatriya ei suojaa kansaa.

2\. Kālidāsa ja muut runoilijat ovat sanskritin opettajia.

3\. Ksatriyalla on elantonsa aseilla.

4\. Myös śūdra-naiset noudattavat dharmaa: väkivallattomuus, totuus, puhtaus, valittamattomuus, pahuuden puuttuminen ja kärsivällisyys.
