# Oppitunti 4

## 4.1. Yksinkertaiset täydennyskysymykset (sanakysymykset) ja vastaukset

### 4.1.1. Kysymyspronominit ja demonstratiivipronominit

#### 4.1.1.1. Kysymyspronominit (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Nominatiivi singularis | Nominatiivi pluralis |
| :--- | :--- | :--- |
| **Neutrum** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Maskuliini** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Feminiiini** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Demonstratiivipronominit (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Vartalon muodot** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"hän, he, se; se, ne":br(Haettu)** | **etad = ⟪एतद्⟫:br"tämä, nämä":br(Puhujalle hyvin lähellä)** | **idam = ⟪इदम्⟫:br"tämä, nämä":br(Lähellä)** |
| **Nominatiivi singularis** ||||
| **Neutrum** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Maskuliini** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Feminiiini** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Nominatiivi pluralis** ||||
| **Neutrum** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Maskuliini** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Feminiiini** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**Nominatiivin singularis maskuliini:**
**sa, eṣa** (⟪स एष⟫) esiintyy ennen kaikkia äänteitä paitsi lyhyen **-a**
**so, eṣo** (⟪सो एषो⟫) esiintyy ennen **-a**:ta, joka elidioidaan avagrahalla (jätetään pois)
**saḥ, eṣaḥ** (⟪सः एषः⟫) esiintyy vain pausissa (lauseen tai runon lopussa)

Jotta näiden pronominien (sarvanāman n.) kanssa voisi muodostaa lauseita, tarvitaan seuraavien sandhi-sääntöjen tuntemus:

### 4.1.2. Lopasääntö ulos puhetulle -m:lle

::: grammar-box
**Ulos puhettu -m korvataan konsonanttien edellä anusvāralla (-ṃ). Lauseen tai säkeen lopussa sekä vokaalien edessä -m säilyy.**
:::
### 4.1.3. Lopasääntö ulos puhetulle -e:lle

::: grammar-box
1. **a-:n edessä -e pysyy muuttumattomana: alkuun puhettu a- elidiintuu avagrahalla:**
esim. ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ "Nämä tulit"

2. **Muiden kuin lyhyiden a-:n edessä -e korvataan yleensä -a:lla ja hiatuksella. Myös korvaaminen -ay:llä on mahdollista:**
esim. ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (harv. imay īśvarāh = ⟪इमयीश्वराः⟫) "Nämä HERRAT"
:::
### 4.1.4. Lopasääntö ulos puhetulle -d:lle

::: grammar-box
**Lopussa oleva -d korvataan pausassa sekä soinnittomien gutturaalien (k, kh) ja labiaalien (p, ph) edellä -t:llä.**

Muiden konsonanttien edessä tapahtuvaa korvaamista käsitellään myöhemmin. Vältä näitä äänteytymisvastakkainasetteluja toistaiseksi!
:::
### 4.1.5. Kysymyslauseet

Näiden pronominaalien avulla muodostetaan esimerkiksi seuraavat kysymyslauseet:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **yksikkö** | **neutri** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं⟫ ⟪तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं⟫ ⟪किम्⟫, ⟪किमिदम्⟫ | "Mikä tämä on?" |
| ^^ | **maskuliini** | sa kaḥ? / kaḥ saḥ?:br⟪स⟫ ⟪कः⟫, ⟪कः⟫ ⟪सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष⟫ ⟪कः⟫, ⟪क⟫ ⟪एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं⟫ ⟪कः⟫, ⟪को⟫ ⟪ऽयम्⟫ | "Kuka tämä on?":br"Mitä hän on?" |
| ^^ | **feminiini** | sā kā? / kā sā?:br⟪सा⟫ ⟪का⟫, ⟪का⟫ ⟪सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा⟫ ⟪का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं⟫ ⟪का⟫, ⟪केयम्⟫ | "Kuka tämä on?":br"Kuka hän on?" |
| **monikko** | **neutri** | tāni kāni? / kāni tāni?:br⟪तानि⟫ ⟪कानि⟫, ⟪कानि⟫ ⟪तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि⟫ ⟪कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि⟫ ⟪कानि⟫, ⟪कानीमानि⟫ | |
| ^^ | **maskuliini** | te ke? / ke te?:br⟪ते⟫ ⟪के⟫, ⟪के⟫ ⟪ते⟫:brete ke? / ka ete?:br⟪एते⟫ ⟪के⟫, ⟪क⟫ ⟪एते⟫:brime ke? / ka ime?:br⟪इमे⟫ ⟪के⟫, ⟪क⟫ ⟪इमे⟫ | |
| ^^ | **feminiini** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः⟫ ⟪काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः⟫ ⟪काः⟫, ⟪का⟫ ⟪एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः⟫ ⟪काः⟫, ⟪का⟫ ⟪इमाः⟫ | |
:::
Esimerkki muista kysymyksistä:

> viṣṇuḥ kaḥ? = ⟪विष्णुः⟫ ⟪कः⟩ Vastaus: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (Tässä nominilauseessa voi esimerkiksi asettaa subjektin alkuun korostaakseen yhteyttä kysymykseen.)

HUOMAUTUS: Vastaukset, joita voit antaa näihin kysymyksiin aiemman sanskritintuntemuksesi perusteella, eivät tietenkään vielä ole kaikilta osin idiomattisesti hyvää sanskritia.

## 4.2. Harjoitus

**A) Muodosta suullisesti seuraavilla sanoilla kysymyksiä viṣṇuḥ kaḥ -kaavan (⟪विष्णुः⟫ ⟪कः⟩) mukaisesti ja vastaa kysymyksiin sanskritiksi:**

śruti, śiva, brāhmaṇa, dvija (monikko), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫
