# Devanāgarī = ⟪देवनागरी⟫

## Kirjoitusharjoitus 1

Sanskritia on kirjoitettu ja sitä edelleen kirjoitetaan monissa eri kirjoitusjärjestelmissä. Seuraava yleiskatsaus esittää pienen otteen näistä kirjoitusjärjestelmistä:

![](/images/schrift001.webp)  
Kuv.: Sanskritin kirjoitusnäytteet
\[Kuvan lähde: Wikipedia, GNU FD LIzenz\]

Tärkein nykyaikainen pohjoisintialainen sanskritinkirjoitus on devanāgarī:

![](/images/schrift002.webp)

Jokainen konsonanttimerkki sisältää mukanaan konsonantin perään tulevan "a":n. Jos halutaan kirjoittaa pelkkä konsonantti (ilman perään tulevaa vokaalia), tämä on merkittävä alaviivalla olevalla vinoviivalla -- virāma = ⟪विराम⟫ --:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

Konsonantin perään tulevat vokaalit -- paitsi "a" -- kirjoitetaan näin:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

Näiden konsonantti + vokaali -yhdistelmien kirjoitusjärjestys on:

![](/images/schrift003.jpg)

Kirjoitettaessa jokainen kirjain, mukaan lukien yläviiva, on saatettava loppuun ennen seuraavan kirjaimen kirjoittamista.

## Harjoitus

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

Lue ja translitteroi:

⟪तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ⟫

Lisäluuntiharjoitus:

⟪पिता⟩ Isä, ⟪कपि⟩ apina, ⟪कृत⟩ tehnyt,  ⟪टीका⟩ alikommentti, ⟪तत्⟩ tämä, ⟪तट⟩ ranta, ⟪पत्⟩ ampua eteenpäin, ⟪पट⟩ kangas, ⟪काच⟩ lasi,  ⟪काकुत्⟩ kitalaki, ⟪चित्⟩ havaita, ⟪पृच्⟩ sekoittaa,  ⟪पोटक⟩ palvelija, ⟪चेतु⟩ tarkoitus, ⟪तौतातित⟩ Kumārilan kannattaja (Mīmāṃsā), ⟪तूत⟩ mulperipuu, ⟪पीत⟩ juonut,  ⟪पीति⟩ juoma, ⟪कॢप्⟩  mahtua, ⟪कृपते⟩ hän valittaa, ⟪पुटी⟩ rypytys, ⟪चापि⟩ samankaltainen, ⟪तोक⟩ jälkeläiset, ⟪तृपत्⟩ kylläinen, ⟪पॄ⟩ täyttää, ⟪कृकाटी⟩ kaulanivelen, ⟪पूपौ⟩ kaksi kakun, ⟪पैतृकी⟩ isällinen (naispuol.), ⟪कौट⟩ huijarinen, ⟪कच⟩ päähiukset, ⟪कुतपे⟩ vuohenhäntäpeitolla, ⟪कुचौ⟩ rinta, ⟪चकिता⟩ säikähtänyt (naispuol.)
