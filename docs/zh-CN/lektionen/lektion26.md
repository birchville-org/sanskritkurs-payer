# 第26课

## 26.1. 词中-s-的腭化规律

::: grammar-box
当 **k, r, l** 或除 **a, ā** 外的元音 — 直接或仅通过 ⟪अनुस्वार⟫ 或 ⟪विसर्ग⟫ 分隔 — 紧随其后，且后接非 **ṛ, r** 的音时，**-s-** 替换为 **-ṣ-**。

此 Sandhi（连声）规则同样适用于复合词中无声的软腭音和双唇音前的 **⟪दुस्⟫-**。
:::
*示例：*
::: indent
⟪तेषाम्⟫（源自：*te-sām*）

但： ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. 词中齿音的腭化规律

::: grammar-box
齿塞音在卷舌音（包括 **-ṣ-**）之后，替换为相应的卷舌音：

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*（**ṣ** 是因为前面的 **i**，**ṭh** 是因为随后的 **ṣ**）*
:::
## 26.3. 腭音、软腭音、ṣ、h + -s 的词尾 Sandhi

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

示例见下文
:::
## 26.4. Grassmann 送气音异化律

::: grammar-box
**两个送气音的直接序列（送气音 - 元音 - 送气音）会导致第一个音的送气特征丢失：**

示例：

:::
::: indent
\*dhu(gh) » du(g)h
:::
**如果由于语音规律第二个音失去了送气特征，那么第一个音会重新获得送气特征。**

## 26.6. 简单将来时（⟪ऌत्⟫，⟪भविष्यन्ती⟫ 阴性）的用法

::: grammar-box
**简单将来时（⟪ऌत्⟫，⟪भविष्यन्ती⟫ 阴性）表示：**

**将来**
**意图或意愿的行为（“我将去”，“我想去”）**
**预期（“事情将会如此发生”）**
**希望**
**担忧**
**可能性**
**说话者的观点**
**命令**

**将来时在某些情况下与虚拟语气存在竞争关系（见后文）。**
:::
例如，⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = “发愿者前往寺庙。”

## 26.7. 简单将来时（⟪ऌत्⟫，⟪भविष्यन्ती⟫ 阴性）的构成

::: grammar-box
**简单将来时：**

:::
::: indent
**将来时词干 + 主要变位后缀**
:::
::: grammar-box
**将来时词干：**

:::
::: indent
**（通常）强级词根 + -sya**  
**或**  
**（通常）强级词根 + -i- + -sya (= - iṣya)**
:::
**哪些词根构成哪种将来时词干形式，必须通过记忆其词形变化表来掌握！**  
**通常来说，将来时的词根形式和连接元音与不定式一致。**  
**某些词根的将来时构成可选项，即带或不带连接元音 -i-。**  
**将来时主动态分词通过在将来时词干后添加后缀 -nt- 构成，阴性形式可选择性地以 -ntī 或 -tī 结尾：**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
