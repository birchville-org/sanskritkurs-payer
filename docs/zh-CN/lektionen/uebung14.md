# 第14课

翻译以下谚语并背诵：

⟪निचो⟫ ⟪वदति⟫ ⟪न⟫ ⟪कुरुते⟫  
⟪वदति⟫ ⟪न⟫ ⟪साधुः⟫ ⟪करोत्येव⟫ ⟪॥१॥⟫  
卑贱者不言亦不行，善良者不言而行。

⟪शीलं⟫ ⟪नरस्य⟫ ⟪भूषणम्⟫ ⟪॥२॥⟫  
美德是人的装饰。

⟪सत्येन⟫ ⟪जनानां⟫ ⟪सुखं⟫ ⟪भवति⟫ ⟪॥३॥⟫  
真理使人幸福。

⟪पापा⟫ ⟪नराः⟫ ⟪स्वर्गं⟫ ⟪न⟫ ⟪लभन्ते⟫ ⟪॥४॥⟫  
恶人不得入天界。

⟪सत्यं⟫ ⟪लोकस्य⟫ ⟪दीपः⟫ ⟪॥५॥⟫  
真理是世界之光。

A) 为下列词语构成单数和复数属格。给出词语的意义和词性：

⟪१⟫. ⟪अनृत⟫ : n. 不真实 — ⟪अनृतस्य⟫ ⟪अनृतानाम्⟫

⟪२⟫. ⟪ऋषि⟫ : m. 吠陀先知 — ⟪ऋषेः⟫ ⟪ऋषीणाम्⟫

⟪३⟫. ⟪पाद⟫ : m. 脚 — ⟪पादस्य⟫ ⟪पादानाम्⟫

⟪४⟫. ⟪बुद्धि⟫ : f. 知识 — ⟪बुद्धेः⟫ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम्⟫

⟪५⟫. ⟪गुरु⟫ : m. 主人 — ⟪गुरोः⟫ ⟪गुरूणाम्⟫

⟪६⟫. ⟪स्वर्ग⟫ : m. 天界 — ⟪स्वर्गस्य⟫ ⟪स्वर्गाणाम्⟫

⟪७⟫. ⟪नगर⟫ : n. 城市 — ⟪नगरस्य⟫ ⟪नगराणाम्⟫

⟪८⟫. ⟪धेनु⟫ : f. 母牛 — ⟪धेनोः⟫ (⟪धेन्वाः⟫) ⟪धेनूनाम्⟫

⟪९⟫. ⟪द्विज⟫ : m. 再生者 — ⟪द्विजस्य⟫ ⟪द्विजानाम्⟫

⟪१०⟫. ⟪मुक्ता⟫ : f. 解脱者 — ⟪मुक्तायाः⟫ ⟪मुक्तानाम्⟫

⟪११⟫. ⟪विद्या⟫ : f. 知识，科学 — ⟪विद्यायाः⟫ ⟪विद्यानाम्⟫

⟪१२⟫. ⟪वर्ण⟫ : m. 种姓 — ⟪वर्णस्य⟫ ⟪वर्णानाम्⟫

⟪१३⟫. ⟪द्विजाति⟫ : 3 再生者 — ⟪द्विजातेः⟫ (⟪द्विजात्याः⟫) ⟪द्विजातीनाम्⟫

⟪१४⟫. ⟪रूप⟫ : n. 形式 — ⟪रूपस्य⟫ ⟪रूपाणाम्⟫

⟪१५⟫. ⟪प्रतिग्रह⟫ : m. 接受 — ⟪प्रतिग्रहस्य⟫ ⟪प्रतिग्रहाणाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 忍受 — ⟪सोढस्य⟫ ⟪सोढायाः⟫ ⟪सोढानाम्⟫

⟪१७⟫. ⟪नायिका⟫ : f. 爱人 — ⟪नायिकायाः⟫ ⟪नयिकानाम्⟫

⟪१८⟫. ⟪साध्वी⟫ : f. 圣者 — ⟪साध्व्याः⟫ ⟪साध्वीनाम्⟫

⟪१९⟫. ⟪अग्नि⟫ : m. 火 — ⟪अग्नेः⟫ ⟪अग्नीनाम्⟫

⟪२०⟫. ⟪वैश्या⟫ : f. 吠舍妇女 — ⟪वैश्यायाः⟫ ⟪वैश्यानाम्⟫

⟪२१⟫. ⟪लोक⟫ : m. 世界，人们 — ⟪लोकस्य⟫ ⟪लोकानाम्⟫

⟪२२⟫. ⟪उक्ति⟫ : f. 格言 — ⟪उक्तेः⟫ (⟪उक्त्याः⟫) ⟪उक्तीनाम्⟫

⟪२३⟫. ⟪शत्रु⟫ : m. 敌人 — ⟪शत्रोः⟫ ⟪शत्रूणाम्⟫

⟪२४⟫. ⟪सुखवन्त्⟫ : 3 幸福 — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : f. 有一或多个儿子的妇女 — ⟪पुत्रवत्याः⟫ ⟪पुत्रवतीनाम्⟫

⟪२६⟫. ⟪जल⟫ : n. 水 — ⟪जलस्य⟫ ⟪जलानाम्⟫

⟪२७⟫. ⟪मार्ग⟫ : m. 道路 — ⟪मर्गस्य⟫ ⟪मर्गाणाम्⟫

⟪२८⟫. ⟪मोक्ष⟫ : m. 解脱，救赎 — ⟪मोक्षस्य⟫ ⟪मोक्षाणाम्⟫

⟪२९⟫. ⟪शूद्रा⟫ : f. 首陀罗妇女 — ⟪शूद्रायाः⟫ ⟪शूद्राणाम्⟫

⟪३०⟫. ⟪अन्न⟫ : n. 食物，饮食 — ⟪अन्नस्य⟫ ⟪अन्नानाम्⟫

⟪३१⟫. ⟪साधु⟫ : m. 圣人 — ⟪साधोः⟫ ⟪साधनाम्⟫

⟪३२⟫. ⟪नीति⟫ : f. 引导 — ⟪नीत्याः⟫ ⟪नीतीनाम्⟫

⟪३३⟫. ⟪योध⟫ : m. 战士，士兵 — ⟪योधस्य⟫ ⟪योधानाम्⟫

⟪३४⟫. ⟪सत्यवन्त्⟫ : 3 诚实的 — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : m. 利益 — ⟪लाभस्य⟫ ⟪लाभानाम्⟫

⟪३६⟫. ⟪मोह⟫ : m. 混乱，迷惑 — ⟪मोहस्य⟫ ⟪मोहानाम्⟫

⟪३७⟫. ⟪गति⟫ : f. 行走，目标 — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम्⟫

⟪३८⟫. ⟪प्रश्न⟫ : m. 问题 — ⟪प्रश्नस्य⟫ ⟪प्रश्नानाम्⟫

⟪३९⟫. ⟪सृष्टि⟫ : f. 创造 — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम्⟫

⟪४०⟫. ⟪नेत्र⟫ : n. 眼睛 — ⟪नेत्रस्य⟫ ⟪नेत्राणाम्⟫

⟪४१⟫. ⟪गुरुता⟫ : f. 技艺/精通 — ⟪गुरुतायाः⟫ ⟪गुरुतानाम्⟫

⟪४२⟫. ⟪ईश्वर⟫ : m. 主人/神 — ⟪ईश्वरस्य⟫ ⟪ईश्वराणाम्⟫

⟪४३⟫. ⟪कारण⟫ : n. 原因 — ⟪कारणस्य⟫ ⟪कारणानाम्⟫

⟪४४⟫. ⟪कृत⟫ : 3 做 — ⟪कृतस्य⟫ (⟪कृतायाः⟫) ⟪कृतानाम्⟫

⟪४५⟫. ⟪धर्मवन्त्⟫ : 3 正义的，宗教的 — ⟪धर्मवतः⟫ (⟪धर्मवत्याः⟫) ⟪धर्मवताम्⟫ (⟪धर्मवतीनाम्⟫)

⟪४६⟫. ⟪युद्ध⟫ : 3 战斗 — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम्⟫

⟪४७⟫. ⟪दर्शन⟫ : n. 看见，现象 — ⟪दर्शनस्य⟫ ⟪दर्शनानाम्⟫

⟪४८⟫. ⟪धातु⟫ : m. 元素，动词词根 — ⟪धातोः⟫ ⟪धातूनाम्⟫

⟪४९⟫. ⟪गूढा⟫ : f. 一位隐藏者 — ⟪गूढायाः⟫ ⟪गूढानाम्⟫

⟪५०⟫. ⟪ईष्टा⟫ (2 种含义): f. 一位被渴望者，一位被献祭者 — ⟪इष्टायाः⟫ ⟪इष्टानाम्⟫

⟪५१⟫. ⟪उदित⟫ : 3 说 — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम्⟫

⟪५२⟫. ⟪इदम्⟫ : 3 这个 — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 什么 — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) 翻译：

⟪१⟫. ⟪ब्राह्मणस्य⟫ ⟪पुत्रो⟫ ⟪ब्राह्मण्या⟫ ⟪ग्रामं⟫ ⟪गतः⟫ ⟪।⟫ (2 种可能性)
婆罗门的儿子去了婆罗门女人的村庄。婆罗门的儿子和婆罗门女人一起去了村庄。

⟪२⟫. ⟪यज्ञस्याग्निनान्नं⟫ ⟪दग्धम्⟫ ⟪।⟫
祭火烧毁了食物。

⟪३⟫. ⟪बुद्धः⟫ ⟪स्तयस्य⟫ ⟪बुद्ध्या⟫ ⟪मुक्तः⟫ ⟪।⟫
佛陀通过真理的觉悟获得了解脱。

⟪४⟫. ⟪अधर्मो⟫ ⟪ऽनृतस्य⟫ ⟪वदनमित्यृषयो⟫ ⟪वदन्ति⟫ ⟪।⟫
吠陀智者说，说假话是不义的。

⟪५⟫. ⟪नरा⟫ ⟪देवानां⟫ ⟪यज्ञैर्न⟫ ⟪मुच्यन्ते⟫ ⟪।⟫
人们通过向神献祭并不能获得解脱。

⟪६⟫. ⟪बलवन्तः⟫ ⟪क्षत्रियाः⟫ ⟪शत्रूणां⟫ ⟪धनवन्ति⟫ ⟪नगराणि⟫ ⟪जयन्ति⟫ ⟪।⟫
强大的刹帝利征服了敌人的富庶城市。

⟪७⟫. ⟪कवेरुक्तिं⟫ ⟪शृण्वन्ति⟫ ⟪।⟫
他们听到诗人的颂词。

⟪८⟫. ⟪कविर्देव्याः⟫ ⟪कृतं⟫ ⟪वद⟫ti ⟪।⟫
诗人叙述了女神的功绩。

⟪९⟫. ⟪द्विजाः⟫ ⟪पशोर्लाभमिच्छन्ति⟫ ⟪।⟫
再生族渴望获得牲畜。

⟪१०⟫. ⟪रामः⟫ ⟪पुण्यवतो⟫ ⟪गुरोर्मन्त्रस्य⟫ ⟪स्मरति⟫ ⟪।⟫
罗摩回忆起那位有德行的主人的咒语。

⟪११⟫. ⟪अयं⟫ ⟪बालः⟫ ⟪कस्याः⟫ ⟪पुत्रः⟫ ⟪।⟫
这位男孩是谁（阴性）的儿子？

⟪१२⟫. ⟪केषामिमानि⟫ ⟪गृहाणि⟫ ⟪।⟫
这些房子属于谁？

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम्⟫ ⟪।⟫
这位吠陀智者献祭了谁的食物？
