## 52.2. 名词构成

### 52.2.1. PPP + -vant: Parasmaipada过去分词

::: grammar-box
**Parasmaipada过去分词按如下方式构成：**

**PPP + -vant / 阴性：vatī**
**变格如同-vant词干或阴性⟪देवी⟫**
:::
PPP + -vant / 阴性：vatī

变格如同-vant词干或阴性⟪देवी⟫

示例：

::: indent
⟪कृतवन्त्⟫ (kṛta-vant) / ⟪कृतवती⟫ “做过的人/女性”

⟪भिन्नवन्त्⟫ “劈开的人”
:::
### 52.2.2. ⟪तद्धित⟫后缀 -maya / -mayī

::: grammar-box
**⟪तद्धित⟫后缀 -maya / 阴性：-mayī 为名词构成形容词，意为**

*   **“由……制成”**
*   **“由……组成”**
*   **“富含……”**

**在-maya之前（如同在-⟪मात्र⟫之前），位于停顿处的塞音必须替换为相应的鼻音。**
:::
示例：

::: indent
⟪अन्नमय⟫ 3 “富含食物”

⟪चिन्मय⟫ 3 （源自⟪चित्⟫ f. “智力”）“由思维/理智构成”

⟪वाङ्मय⟫ 3 （源自⟪वाच्⟫ f. “语言”）“由言语构成”

⟪सोममय⟫ 3 “由苏摩制成，由苏摩构成”
:::
::: grammar-box
**以-maya结尾的名词偶尔被用作中性名词，此时它们表示由所附加的名词所指代事物的过剩。**
:::
::: indent
例如，⟪अन्नमय⟫ n. “食物的过剩”
:::

## 52.4. 表达“某物成为或变成其先前所不是之物”的动词复合词（⟪अभुततद्भावः⟫）

### 52.4.1. cvi 类构词法

::: grammar-box
**置于词根之前**

*   **⟪कृ⟫ 8U “做”**
*   **⟪अस्⟫ 2P “是”**
*   **⟪भू⟫ 1P “成为”**

**名词和形容词可以作为前缀使用，以表达某人或某物成为该名词所指的人或事物。**

**词干的处理方式如下：**


词干的处理方式如下：

*   **可变格词的尾音 -a 和 -ā 替换为 -ī**
例如：  
⟪कृष्णीभवति⟫ “非黑之物变为黑色”  
⟪कृष्णीकरोति⟫ “使非黑之物变为黑色”  
⟪गङ्गीभवति⟫ “他/她成为恒河”

*   **尾音 -i 和 -u 替换为相应的长元音**
例如：  
⟪शुचीभवति⟫ “他/她/它变得纯洁”  
⟪गुरूभवामि⟫ “我成为主人”

*   **尾音 -ṛ 替换为 --rī**
例如 ⟪पित्रीभवति⟫ “非父亲者成为父亲 = 男子得长子”

*   **尾音 -n 脱落， preceding vowel 按上述规则处理**
例如 ⟪राजीबभूव⟫ “非王者成为王者（⟪राजन्⟫）”

*   **其他多干名词以它们在位格（⟪सप्तमी⟫）复数形式中的词干形式出现。该词干随后遵循常规的连音规则。参见Kielhorn，《语法》§ 489,3。**
例如，⟪तिर्यक्करोति⟫ “他向侧面放置（⟪तिर्यच्⟫）”
:::

### 52.4.2. 后缀 -sāt

::: grammar-box
**为了表达一个人或事物完全成为某物，或者某人将某物或某人彻底变成由名词所指称的事物，可以在该名词后**

**附加后缀 -sāt（它永远不会变成 -ṣāt）**

**并以此方式构成的词与以下动词词根**

*   ⟪कृ⟫ 8U “做”
*   ⟪अस्⟫ 2P “是”
*   ⟪भू⟫ 1P “成为”
*   ⟪सम्⟫-⟪पद्⟫ 4Ā

**结合构成动词复合词。**
:::
示例：

::: indent
⟪अग्निसाद्भवति । अग्निसात्संपद्यते⟫ “他完全成为火”

⟪भस्मसात्करोति⟫ “他彻底转化为灰烬（⟪भस्मन्⟫ n. ‘灰烬’）”
:::
::: grammar-box
**有时后缀 -sāt 表示一个人或事物**


*   **变得依赖于某物，或者**
*   **成为该物的所有者**
*   **或者某人使某物依赖于由名词所指称的事物**

**该事物由名词所指称**
:::
示例：

::: indent
⟪राजसाद्भवति⟫ “他变得依附于国王，成为国王的财产”
:::
::: grammar-box
**带有 -sāt 构成的词，其后的动词词根不像前缀那样处理，因此为绝对式：**

:::
::: indent
⟪भस्मसात्कृ⟫:sig[⟪त्वा⟫]
:::
## 52.5. 词的重叠（⟪द्विरुक्तम्⟫）

::: grammar-box
**在梵语中，词的重叠表示：**

*   **动作的重复**  
例如，⟪पुनः पुनः⟫ “反复地”
*   **分配性**  
示例：  
⟪पृथक्पृथक्⟫ “各自地，逐一”
⟪यद्यद्⟫ ... ⟪तत्तद्⟫ “无论什么……所有这些”
⟪युगे युगे⟫ “在每一个单独的时代”

**偶尔，可以从这类组合中构成复合词**

:::
示例：

::: indent
⟪एकैक⟫ 3 “每一个”
⟪अल्पाल्प⟫ 3 “非常小”
⟪नवनव⟫ 3 “始终新的”
:::
关于所谓的⟪आम्रेडित⟫复合词，其中屈折变化的单词被重复使用，但第二个单词在古典时期之前获得了重音，因此构成复合词，参见瓦克纳格尔《古印度语法》第二卷第一分册第142页及以下。
## 52.6. 数词（⟪सम्ख्या⟫阴性）

此处未涵盖的内容，参见基尔霍恩《语法》§201及以下。

### 52.6.1. 基数词

#### 52.6.1.1. 数形容词（用于1至19）

::: grammar-box
**表示*1至19*的数词是形容词。**
**表示**1至4**的数词在三种性别的变格中有所不同。**

**对于表示**5至19**的数词（:sig[⟪नवदशन्⟫]），三种性别只有一种变格形式。**

**对于这些数形容词，与所有形容词一样：它必须与其所修饰的名词在格、数和性别上保持一致（即单数用1，双数用2，其余用复数）。**
:::
基数词：

::: indent
1 ⟪एक⟫ 3（变格同 ⟪सर्व⟫，复数意为“一些”）
2 ⟪द्वि⟫ 3
3 ⟪त्रि⟫ 3
4 ⟪चतुर्⟫ 3
5 ⟪पञ्चन्⟫ 3
6 ⟪षष्⟫ 3
7 ⟪सप्तन्⟫ 3
8 ⟪अष्टन्⟫ 3
9 ⟪नवन्⟫ 3
10 ⟪दशन्⟫ 3
:::
其变格见词汇表中的相应位置。

关于直至19的其他基数副词，参见Kielhorn，《语法》§201。

#### 52.6.1.2. 基数名词（用于19及以上）

::: grammar-box
**表示 *19（⟪एकोनविंशति⟫ “比20少一”）* 至 *99* 的基数词是阴性名词，其变格同 ⟪मति⟫ 阴性形式或词干以 -t 结尾的根名词（例如 ⟪त्रिंशत्⟫ 阴性）。**

:::
示例：

::: indent
20 ⟪विंशति⟫ f.：br
30 ⟪त्रिंशत्⟫ f.
:::

::: grammar-box

**表示 *100及以上* 的基数词是中性名词。其变格同 ⟪फलम्⟫。**
:::

示例：

::: indent
100 ⟪शत⟫ n.：br
1000 ⟪सहस्र⟫ n.
:::
各个基数名词参见Kielhorn，《语法》§201。
#### 52.6.1.3. 基数词的句法

::: grammar-box
**基数词的动词形容词与动词名词之间的区别，对句法产生以下后果：**
*   形容词性基数词只能像形容词一样与所计数的名词结合  
例如 ⟪तिसृभिर्नारीभिः⟫ “通过三位女性”  
*   名词性基数词可以通过三种方式与所计数的名词结合
*   它们支配所计数名词的属格（⟪षष्ठी⟫）  
例如 ⟪विंशत्या नारीणाम्⟫ “通过二十位女性”  
*   它们作为同位语，与所计数名词处于相同的格（但为单数）  
例如 ⟪विंशत्या नारीभिः⟫ “通过二十位女性” 
*   它们作为 ⟪तत्पुरुष⟫ 的后半部分，所计数名词为前半部分  
例如 ⟪गोविंशत्या⟫ “通过二十头母牛”

:::
### 52.6.2. 序数词

参见例如 Kielhorn，《语法》§201f。

### 52.6.5. 复合词中带有基数词的在前成分

::: grammar-box
**⟪बहुव्रीहि⟫ 这类复合词构成得非常规则。**
:::
例如：

::: indent
⟪चतुर्मुख⟫ 阳性，“拥有四张面孔者” = ⟪चत्वारि मुखानि यस्य सः⟫（梵天的一个称号）
:::

图：⟪चतुर्मुखः⟫

::: grammar-box
**⟪तत्पुरुष⟫ 在前成分中包含基数词的复合词不得随意构成：**

**规则1：表示方位的词（如 ⟪पूर्व⟫ 3 “东方的”，⟪उत्तर⟫ 3 “北方的”）以及表示基数词的词，只有当该复合词被用作专有名词时，才能与其他词构成⟪कर्मधारय⟫复合词。**
:::
因此，例如不能从⟪उत्तरा वृक्षाः⟫“北方的树木”或⟪पञ्च ब्राह्मणः⟫构成Tatpuruṣa复合词。然而，可以从⟪सप्तन्⟫和⟪ऋषि⟫构成Tatpuruṣa复合词⟪सप्तर्षि⟫阳性“七位仙人”，如果它作为大熊星座（Ursa maior）的名称使用。
::: media
![](/images/lekt5206.jpg)
图：⟪सप्तर्षयः⟫
北斗七星 = 大熊星座（Ursa maior）中最亮的七颗恒星
（图片来源：[详情](/zh-CN/licenses#lekt5206)）
:::

::: grammar-box
**规则2：与规则1不同，表示方位或基数的词可以与另一个名词构成Tatpuruṣa复合词，如果**

1. 在该构成的复合词后附加Taddhita后缀  
例如：  
pūrva + śālā（“厅堂”）» \*pūrvaśālā（不得这样使用！）+ Taddhita -a » ⟪पौर्वशाल⟫ 3 “位于东厅”  
ṣaṣ + mātṛ » \*ṣaṇmātṛ（不允许！）+ Taddhita -a » ⟪षण्मातुर⟫ 阳性 “六个母亲的孩子”（= ⟪कार्त्तिकेय⟫）  

2. 该构成的复合词以通常由Taddhita后缀表示的意义使用（这种类型的Bahuvrīhi过渡是流畅的）：  
例如：  
dvi + go » ⟪द्विगु⟫：不是“两头母牛”，而是：“**为两头母牛所换取**”  
⟪द्विवर्ष⟫不是“两年”，而是：“**两岁**”  

3. 该构成的复合词作为另一个复合词的组成部分  
例如：  
pañca + go » pañcagava（作为独立词不允许！）+ dhana » ⟪पञ्चगवधन⟫ 阳性 “其财富为五头母牛的人”
:::

::: grammar-box
**表示基数词（而非方位）的词，作为复合词的前半部分与其他名词结合时，即使所构成的复合词表示多个事物的集合（即把两个或多个事物合并为一个整体），也能构成限定性复合词（Tatpuruṣa）。**

**根据此规则构成的限定性复合词称为“数词复合词”（Dvigu，见⟪द्विगु⟫）。**

**表示整体的数词复合词通常为中性。若后半部分以-a结尾，则可附加阴性后缀-ī。若后半部分以阴性-ā结尾，则其位置可替换为中性-a或阴性-ī。若后半部分以-an结尾，则可替换为-a或-ī。**
:::
示例：

::: indent
⟪त्रि⟫ + ⟪भुवनव्⟫ » ⟪त्रिभुवन⟫ 中性：“三界之集合，将三界视为一个整体，即三界（天、地、地下世界）”

⟪त्रिलोक⟫ 中性 ⟪। त्रिलोकी⟫ 中性：“三界”
