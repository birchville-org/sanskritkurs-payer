## 7.1. 带直接宾语的动词句

::: grammar-box
**结构：**
**(施事者 = kartṛ m. = ⟪कर्तृ⟫) – 直接宾语 (karman n. = ⟪कर्मन्⟫) – 动词**

例如
**rāmaḥ phalaṃ khādati** = ⟪रामः फलं खादति⟫ : “罗摩吃（咀嚼）水果。”
**brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो देवं यजति⟫ : “婆罗门以祭祀（为他人）供奉神。”
:::
当动词处于 Parasmaipada（他称语尾）或 Ātmanepada（自称语尾）时，直接宾语（**karman** n. = ⟪कर्मन्⟫）通常处于 **第四格**（宾格，dvitīyā f. = ⟪द्वितीया⟫）。


## 7.2. 第四格（宾格，dvitīyā f. = ⟪द्वितीया⟫ = “第二格词尾”）

::: grammar-box
**阳性与阴性单数第四格以元音结尾的词尾：-m**

| 阳性名词以...结尾 | 单数第四格 |
| :--- | :--- |
| **-a**: deva | **devam** :br⟪देवम्⟫ |
| **-i**: kavi | **kavim** :br⟪कविम्⟫ |
| **-u**: guru | **gurum** :br⟪गुरुम्⟫ |
| 阴性名词以...结尾 | 单数第四格 |
| **-ā**: devatā | **devatām** :br⟪देवताम्⟫ |
| **-i**: śruti | **śrutim** :br⟪श्रुतिम्⟫ |
| **-ī**: devī | **devīm** :br⟪देवीम्⟫ |
| **-u**: dhenu | **dhenum** :br⟪धेनुम्⟫ |
:::
::: grammar-box
**阳性复数宾格，元音结尾的词干（例外：长元音结尾的单音节根词干）：词尾元音延长 + -n**

| 阳性以...结尾 | 复数宾格 |

| 阴性以...结尾 | 复数宾格 |
| :--- | :--- |
| **-ā**: devatā | **devatās** :br⟪देवतास्⟫ |

### 7.2.1. 疑问代词和指示代词的单数与复数宾格

::: grammar-box
| || 阳性 | 阴性 | 中性 |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :br谁/什么 | 单. | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |
| | 复. | **kān** :br⟪कान्⟫ | **kās** :br⟪कास्⟫ | **kāni** :br⟪कानि⟫ |
| **tad** :br他/它/那个 | 单. | **tam** :br⟪तम्⟫ | **tām** :br⟪ताम्⟫ | **tad** :br⟪तद्⟫ |
| | 复. | **tān** :br⟪तान्⟫ | **tās** :br⟪तास्⟫ | **tāni** :br⟪तानि⟫ |
| **etad** :br这个 这里 | 单. | **etam / enam** :br⟪एतम्⟫ / ⟪एनम्⟫ | **etām / enām** :br⟪एताम्⟫ / ⟪एनाम्⟫ | **etad / enad** :br⟪एतद्⟫ / ⟪एनद्⟫ |
| | 复. | **etān / enān** :br⟪एतान्⟫ / ⟪एनान्⟫ | **etās / enās** :br⟪एतास्⟫ / ⟪एनास्⟫ | **etāni / enāni** :br⟪एतानि⟫ / ⟪एनानि⟫ |
| **idam** :br这个 | 单. | **imam / enam** :br⟪इमम्⟫ / ⟪एनम्⟫ | **imām / enām** :br⟪इमाम्⟫ / ⟪एनाम्⟫ | **idam / enad** :br⟪इदम्⟫ / ⟪एनद्⟫ |
| | 复. | **imān / enān** :br⟪इमान्⟫ / ⟪एनान्⟫ | **imās / enās** :br⟪इमास्⟫ / ⟪एनास्⟫ | **imāni / enāni** :br⟪इमानि⟫ / ⟪एनानि⟫ |
:::
形式 **enam**（⟪एनम्⟫）等属于词干 **enad**（⟪एनद्⟫），该词干仅在部分格中形成变位形式。当所指代的内容在前文中已提及时，便使用这些形式来代替 **etad** 和 **idam** 的形式。
例如：**ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं देवः⟫ | ⟪एनं यजन्ते⟫ ||：“他是一位神。人们向他献祭。”


### 7.2.2. 宾格（第二格，dvitīyā f. = ⟪द्वितीया⟫ = “第二个格后缀”）的用法

::: grammar-box
宾格（dvitīyā f. = ⟪द्वितीया⟫）表示：
1. 在非被动动词句中：作为由动词所表达动作的**直接宾语**（karman n. = ⟪कर्मन्⟫）：
例如
**devaṃ yajati** = ⟪देवं यजति⟫：“他通过祭祀来崇敬一位神。”
**phalam āpnoti** = ⟪फलमाप्नोति⟫：“他获得果实（例如其行为的果报）。”
2. 在表示去、移动、引导或类似含义的动词中，宾格表示运动的目标：
例如
**narakaṃ gacchati** = ⟪नरकं गच्छति⟫：“他前往地狱。”
:::
宾格的其他用法将在后文讨论。



## 7.3. 词尾 -n 的连声（Sandhi）

::: grammar-box
**词尾 -n：**

1. 在浊音腭塞音和卷舌塞音以及 **ś-** 之前，被相应的鼻音取代：
**-n** 在 **j-, jh-, ñ-, ś-** 之前 » **-ñ**
**-n** 在 **ḍ-, ḍh-, ṇ-, ṣ-** 之前 » **-ṇ**
例如：**kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫：“他战胜了刹帝利。”
此时词首的 **ś-** 通常被替换为 **ch-**：
**gurūn + śṛṇoti** » **gurūñ chṛṇoti**（与 gurūñ śṛṇoti 并存）= ⟪गुरूञ्छृणोति⟫（⟪गुरूञ्शृणोति⟫）：“他听老师们说话。”“他听从老师们的话。”

2. 若词首为 **l-**，则通过带鼻音的 **-l**（即鼻化 l，书写形式为 ⟪ल्⟫ 并带有鼻音符号 ⟪ँ⟫）进行替换：
例如 **paśūn + labhate** » ⟪पशूंल्लभते⟫ ：“他获得牲畜。”

3. 若词首为清腭音、卷舌音或齿音，则通过 **Anusvāra**（鼻化符号）加上对应这些辅音的擦音进行替换：
**c-, ch-** 前的 **-n** » **-ṃś**
**ṭ-, ṭh-** 前的 **-n** » **-ṃṣ**
**t-, th-** 前的 **-n** » **-ṃs**
例如 **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ ：“以及诸神（宾格）”
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ ：“然而诸神（宾格）”

4. 除非在短元音之后（见后文），否则在其他所有情况下，词尾的 **-n** 保持不变。
:::

## 7.4. 中性名词 (napuṃsaka n. = ⟪नपुंसक⟫)

::: grammar-box
**在中性名词中，主格 (prathamā) 和宾格 (dvitīyā) 的形式是相同的。**
:::
### 7.4.1. 以 -a 结尾的中性词干

::: grammar-box
**单数主格/宾格词尾：-m**
例如 **phala** n. = ⟪फल⟫ = “果实”：单数主格/宾格 **phalam** = ⟪फलम्⟫
**复数主格/宾格词尾：-āni**
例如 **phala** n. = ⟪फल⟫：复数主格/宾格 **phalāni** = ⟪फलानि⟫
:::

## 7.5. 非主题现在时类

第五现在时类构成所谓的“非主题”现在时词干，即其现在时词干的结尾不像主题现在时类（第一、第四、第六、第十类）那样以“主题元音” **-a** 结尾。

::: grammar-box
**非主题现在时类具有词干强弱交替（ablaut），即存在两种现在时词干形式：**
1. **强式词干**：全格（偶尔为长音格）
2. **弱式词干**：低格

**强词干形式为：**
陈述语气单数第三人称（laṭ）和未完成时（laṅ）的 Parasmaipada 语态
命令语气（loṭ）Parasmaipada 和 Ātmanepada 语态的所有第一人称
命令语气（loṭ）Parasmaipada 语态的第三人称单数

**所有其他形式使用弱现在时词干。**
:::
### 7.5.1. 非词根现在时第三人称复数的主词尾

::: grammar-box
**对于非词根现在时词干，第三人称复数的主词尾为：**
**Parasmaipada: -anti**
**Ātmanepada: -ate**
:::
### 7.5.2. 第五现在时类 (svādi = ⟪स्वादि⟫ = "su 等")

::: grammar-box
**强词干**：（通常）低等级根 + **-no-**
**弱词干**：（通常）低等级根 + **-nu-**

**对于以元音结尾的词根，在元音词尾前，-nu- 变为 -nv-；对于以辅音结尾的词根，在元音词尾前，-nu- 变为 -nuv-。**
:::
**示例：**

| 词根:br⟪धातु⟫ | 强词干 | 弱词干 | 元音前:br(弱) |
| :--- | :--- | :--- | :--- |
| **āp** :br5 P:br⟪आप्⟫:br"到达" | **āp-no** :br(3.sg. āpnoti = ⟪आप्नोति⟫) | **āp-nu** | **āp-nuv** :br(3.pl. āpnuvanti = ⟪आप्नुवन्ति⟫) |
| **aś** :br5 Ā:br⟪अश्⟫:br"到达" | — | **aś-nu** :br(3.sg. aśnute = ⟪अश्नुते⟫) | **aś-nuv** :br(3.pl. aśnuvate = ⟪अश्नुवते⟫) |
| **su** :br5 U:br⟪सु⟫:br"压榨" | **su-no** :br(3.sg. sunoti = ⟪सुनोति⟫) | **su-nu** :br(3.sg. sunute = ⟪सुनुते⟫) | **su-nv** :br(3.pl. sunvanti = ⟪सुन्वन्ति⟫,:br3.pl. sunvate = ⟪सुन्वते⟫) |
| **śru** :br5 P:br⟪श्रु⟫:br"听" | **śṛ-ṇo** :br(3.sg. śṛṇoti = ⟪शृणोति⟫) | **śṛ-ṇu** | **śṛ-ṇv** :br(3.pl. śṛṇvanti = ⟪शृण्वन्ति⟫) |
