# 书写练习9

### 分词规则

在句子（半行诗）内部，书写中的分词仅发生在以下情况：一个单词以

*   元音
*   鼻化符号（ṃ）
*   送气符号（ḥ）

结尾，且下一个单词以辅音开头。此外，当根据句内连声规则在元音之间产生 hiatus（元音间隔）时，也进行分词。

### 标点符号

句子的结束在散文部分用 |（ardhadanda，阳性）表示。在诗歌中，| 表示半行诗的结束，||（danda，阳性）表示整行诗的结束。在散文中，|| 表示较大的停顿（例如段落的结尾）。行数标记置于两个 || 之间，例如 ||⟪१⟫||。

### 缩写规则

缩略符号（例如在作品名称中）为 °，例如 ⟪पा⟫° = pā(ṇinīye) = “在波你尼的语法著作中”。
