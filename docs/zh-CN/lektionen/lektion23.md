# 第23课

## 23.1. 不定式 (⟪तुमुन्⟫)

::: grammar-box
**若要在梵语中表达某项活动是为了另一项活动的目的而进行（“为了”），可以使用不定式 (⟪तुमुन्⟫) 来表示其目的活动。不定式主要表示目的或意图：**

> ⟪रामो गुरुवचनं श्रोतुं गतः⟫ = “罗摩去听导师的演讲。”

**请注意，不定式——除了一些明确规定的例外情况——不能用作动词的主语或宾语：**

> 因此，不能用不定式（“跳舞”）来翻译“他学习跳舞”，而必须使用动名词，例如：⟪नर्तनमधीते⟫ (⟪इ⟫ + ⟪अधि⟫ 2 Ā: “学习”)。

**当不定式的施事者（⟪कर्तृ⟫）与动词的施事者相同时，不定式也用于表示“想要”或“渴望”含义的动词和名词：**

> ⟪रामो गुरुवचनं श्रोतुमिच्छति⟫ = “罗摩想要听导师的演讲。”

**不定式还用于表示“能够”、“有”、“知道”、“开始”等含义的动词：**

> ⟪साधुरधर्मं कर्तुं न शक्नोति⟫ = “圣人不能作恶。”  
> ⟪अस्ति भोक्तुमन्नम्⟫ = “有食物可吃” (⟪भुज्⟫ 7: Ā: 吃, P: 统治)

**不定式也用于表示“足够”、“能够”含义的词，以及表示“能力”、“力量”、“技巧”含义的名词：**

> ⟪अस्त्यग्नेर्विभवः सर्वं दग्धुम्⟫ = “火具有燃烧一切的力量。”

**即使在与“时间”含义相同的词语中，也可以使用不定式，例如在表达“是时候……了”时：**

> ⟪कालो भोजनं सेवितुम्⟫ = “是时候致力于进食了” = “是时候吃饭了”

**不定式可以主动和被动使用。德语中的被动不定式在梵语中通过将从属的不定式的动词（尤其是⟪शक्⟫“能够，可以”）变为被动语态来表达。**

**就宾语而言，不定式的行为类似于动词形式，即当使用主动不定式时，直接宾语（⟪कर्मन्⟫）处于与格（⟪द्वितीया⟫），或者该动词所要求的格；当使用被动不定式时，直接宾语处于主格。**

例如：

> ⟪साधुरधर्मं कर्तुं न शक्नोति⟫ = ⟪साधुनाधर्मः कर्तुं न शक्यते⟫ = “圣人不能作恶。”

**在第二人称中，⟪अर्ह्⟫ + 不定式常用作委婉的命令：“你应该。”**

**当不定式从属于名词时，它不能与该名词结合成复合词。例外的是Bahuvrīhi复合词，其第二个成分是⟪काम⟫或⟪मनस्⟫：**

> ⟪वक्तुकामः⟫ = ⟪वक्तुं कामो यस्य सः⟫ = “其愿望是说话的人；想要说话的人”。
:::
## 23.2. 不定式的构成（⟪तुमुन्⟫）

::: grammar-box
**强级词根 + -tum**

**或者**

**强级词根 + -i- + -tum**

**词根的尾辅音在-tum之前按照与PPP的-ta之前相同的规则发生变化。**

**带前缀的动词以与简单词根相同的方式构成不定式。**
:::
例如：

::: indent
⟪दिश्⟫ : ⟪देष्टुम् रुद्⟫ : ⟪रोदितुम्⟫
:::
关于连接元音 -i- 的使用，无法制定固定的规则。基本上，不定式中连接元音的分布与将来时一致。

对于迄今为止所学到的词根，以下不定式需要特别注意：

::: indent
⟪गम्⟫ : ⟪गन्तुम् प्रच्छ्⟫ : ⟪प्रष्टुम्⟫
:::
>> -ra- 作为 -ṛ- 的高阶形式，在不定式中：

::: indent
⟪दृश्⟫ : ⟪द्रष्टुम् सृज्⟫ : ⟪स्रष्टुम्⟫
:::
其他倒数第二个位置带有 -ṛ- 的词根，如果属于 aniṭ（非元音结尾）类，则可选地采用 -ra- 或 -ar-。
