# 第27课

## 27.1. 与格的用法（⟪सप्तमी⟫ f. = “第七格词尾”）

::: grammar-box

**与格（⟪सप्तमी⟫）用于回答以下问题：**
*   **在哪里？**
*   **何时？**
*   **在什么情况下？**
*   **关于什么？**

:::
::: grammar-box

**1. 与格（⟪सप्तमी⟫）在回答“在哪里？”时，指代动作的施事者（⟪कर्ता⟫）或受事者所在的空间（在、在……旁、在……上），或者动作本身发生的地方。**

> ⟪नगरे⟫ ⟪वसति⟫ = “他住在城里”

:::: media
![](/images/lekt2701.webp)
图：⟪जयपुरनगरे⟫
斋浦尔，1875年。
（图片来源：[详情](/zh-CN/licenses#lekt2701)）
::::
:::

::: grammar-box

**2. 与格在回答“何时？”时，指代时间点或外部情况：**

> ⟪तस्मिन्काले⟫ = “在那个时刻，在那时”

**这里还包括所谓的绝对与格（Locativus Absolutus）：**

**如果某人或某物的动作或状态决定了另一人/物进行动作或处于特定状态的时间——或情况，那么指代第一个人或事物的词，连同进一步限定该词的词（通常是一个分词），会进入与格（⟪सप्तमी⟫）：**

> ⟪एवं⟫ ⟪गच्छति⟫ ⟪काले⟫ = “当时光流逝……”
>
> ⟪तस्मिन्गते⟫ = “当他离开之后……”

**有时施事者（⟪कर्ता⟫）不特别指明：**

> ⟪एवं⟫ ⟪सति⟫ = “既然情况如此”

**绝对与格（Locativus absolutus）必须根据上下文翻译为“当……时”（例如现在分词）、“在……之后”、“当……时”（例如过去被动分词）、“因为”、“既然”、“虽然”、“如果”等。**

**注意：在绝对结构中，绝对格的施事者与主句的施事者必须相同；而在绝对与格中，绝对与格的施事者与主动词的施事者必须不同。**

![](/images/lekt2702.webp)
图：⟪एवं⟫ ⟪गच्छति⟫ ⟪कालयुष्ट्रः⟫ ⟪स्वपित⟫i
拉贾斯坦邦。
（图片来源：[详情](/zh-CN/licenses#lekt2702)）
::::
:::

::: grammar-box

**3. 与格也用于回答“关于什么？”等问题：**

> ⟪अस्ति⟫ ⟪तस्य⟫ ⟪पुत्रे⟫ ⟪स्नेहः⟫ = “他对儿子有爱”（字面意：“关于儿子，他心中有爱”）

::::
:::

::: grammar-box

**4. 与格在本地词典和注释家的著作中，用于说明词语的含义：**

> ⟪भू⟫ ⟪सत्तायाम्⟫ = “词根 ⟪भू⟫ 在‘存在性’（sat-tā）意义上的用法”

:::

## 27.4. 包含 ⟪राम⟫ 所有变格形式（单数）的一首诗

::: media
![](/images/lekt2708.webp)
图：⟪रामे⟫ ⟪चित्तलयः⟫ ⟪सदा⟫ ⟪भवतु⟫ ⟪मे⟫ ⟪भो⟫ ⟪राम⟫ ⟪मामुद्धर⟫ ⟪॥⟫

(图片来源：[详细信息](/zh-CN/licenses#lekt2708))

***⟪रामो⟫*** ⟪राजमणिः⟫ ⟪सदा⟫ ⟪विजयते⟫ ***⟪रामं⟫*** ⟪रमेशं⟫ ⟪भजे⟫:br ***⟪रामेणा⟫***⟪भिहता⟫ ⟪निशाचरचमू⟫ ***⟪रामाय⟫*** ⟪तस्मै⟫ ⟪नमः⟫ ⟪।⟫:br ***⟪रामान्ना⟫***⟪स्ति⟫ ⟪परायणम्⟫ ⟪परतरं⟫ ***⟪रामस्य⟫*** ⟪दासोऽस्म्यहम्⟫:br ***⟪रामे⟫*** ⟪चित्तलयः⟫ ⟪सदा⟫ ⟪भवतु⟫ ⟪मे⟫ ⟪भो⟫ ***⟪राम⟫*** ⟪मामुद्धर⟫ ⟪॥⟫

**翻译：**
1. **主格：** 罗摩，众王（⟪राजन्⟫ 阳性）中的宝石（⟪मणि⟫ 阳性）总是胜利（⟪सदा⟫）。
2. **宾格：** 我爱（⟪भज्⟫ 第一人称单数）罗摩，罗摩的（⟪ईश⟫ 阳性）主人和丈夫（即罗摩 = 拉克什米）。
3. **工具格：** 罗摩杀死了夜游者（即恶魔）的军队（⟪चमू⟫ 阴性 = 夜）（⟪निशा⟫ 阴性）。
4. **与格：** 向这位罗摩致敬！
5. **离格：** 除了罗摩之外，没有更好的（⟪परतर⟫ 第三）庇护所（⟪परायण⟫ 中性）。
6. **属格：** 我（⟪अहम्⟫）是罗摩的仆人（⟪अस्मि⟫）。
7. **与格：** 愿我的（⟪मे⟫）心（⟪लय⟫ 阳性）中永远（⟪भवतु⟫）有安宁。
8. **呼格：** 罗摩，拯救（⟪उद्धर⟫ = ⟪उद्⟫ + ⟪हृ⟫ 或 ⟪उद्⟫ + ⟪धृ⟫ 的命令式）我（⟪माम्⟫）！
