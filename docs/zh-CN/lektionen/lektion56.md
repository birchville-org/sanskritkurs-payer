# 第56课

## 56.1. 重音过去时（Reduplicierter Aorist）

::: grammar-box
**构成：**

**增强音 + 重音词根 + a + 主题性次要词尾**

**词根音节可以是低重音或高重音。对于以-i或-u结尾的词根，低重音是规则。**

**词尾的-i、-u分别替换为-iy和-uv。**

**词尾的-ā（代表-e）脱落。**
:::
变位表：

⟪श्रि⟫ 1U “前往，依靠”

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | ⟪अशिश्रियम्⟩:br(⟪अ⟫-⟪शि⟫-⟪श्रिय्⟫-⟪अम्⟫) | ⟪अशिश्रियाम⟫ | ⟪अशिश्रिये⟫ | ⟪अशिश्रियामहि⟫ |
| **2. ⟪द्वितीयः⟫** | ⟪अशिश्रियस्⟫ | ⟪अशिश्रियत⟫ | ⟪अशिश्रियथास्⟫ | ⟪अशिश्रियध्वम्⟫ |
| **3. ⟪प्रथमः⟫** | ⟪अशिश्रियत्⟫ | ⟪अशिश्रियन्⟫ | ⟪अशिश्रियत⟫ | ⟪अशिश्रियन्त⟫ |

以下词根构成此种过去时形式：

*   ⟪श्रि⟫ 1U “前往”
*   ⟪द्रु⟫ 1P “奔跑”
*   ⟪कम्⟫ 1Ā “爱”：⟪अचकमत⟫ / ⟪अचीकमत⟫（见下文！）
*   ⟪पत्⟫ 1P “落下”：⟪अपप्तत्⟫ (a-pa-pt-a-t; pt 为 pat 的低重音形式)
*   ⟪वच्⟫ 2P “说”：⟪अवोचत्⟫ (a-va + uc-a-t)

::: grammar-box
**所有第十类现在时词根以及使动词始终构成重音过去时。**
:::
### 56.1.1. 使动词和第十类现在时词根的过去时构成

词干音节：

::: grammar-box
**起点是现在时词干或使动词词干的形式，即去除构成成分-aya-后的形式（因此对于以-paya-结尾的使动词，词干以-p结尾）。**

**这种所谓“词干音节”中的元音在过去时中根据以下规则确定：**

*   **\-ā- 在简单辅音前被 -a- 替换：**  
⟪पॄ⟫ 第三人称：使役式 :sig[⟪पार⟫]⟪यति⟫，不定过去式 ⟪अपि⟫:sig[⟪पर⟫]⟪त् द्रु⟫ 第一人称：使役式 :sig[⟪द्राव⟫]⟪यति⟫，不定过去式 ⟪अदु⟫:sig[⟪द्रव⟫]⟪त्⟫ / ⟪अदि⟫:sig[⟪द्रव⟫]⟪त् नी⟫ 第一人称：使役式 :sig[⟪नाय⟫]⟪यति⟫，不定过去式 ⟪अनी⟫:sig[⟪नय⟫]⟪त् ज्ञा⟫ 第九人称：使役式 :sig[⟪ज्ञाप⟫]⟪यति⟫，不定过去式 ⟪अजि⟫:sig[⟪ज्ञप⟫]⟪त्⟫  

*   **\-ī-, -e-, -ai- 在简单辅音前被 -i- 替换：**  
⟪चित्⟫ 第一人称：使役式 :sig[⟪चेत⟫]⟪यति⟫，不定过去式（长音） ⟪अची⟫:sig[⟪चित⟫]⟪त⟫  

*   **\-u-, -o-, -au- 在简单辅音前被 -u- 替换：**  
⟪चुर्⟫ 第十人称：使役式 :sig[⟪चोर⟫]⟪यति⟫，不定过去式 ⟪अचू⟫:sig[⟪चुर⟫]⟪त्⟫

**对于某些词根，上述变化是可选的或必须避免：**

*   **紧随词干音节末尾辅音之后、替代 ṛ, ṝ, ḷ 的 ar, ār, īr, al，可选择保持不变或被替换为 ṛ 或 ḷ：**  
⟪कॢप्⟫ 第一人称：使役式 :sig[⟪कल्प⟫]⟪यति⟫，不定过去式 ⟪अच⟫:sig[⟪कल्प⟫]⟪त्⟫ / ⟪अची⟫:sig[⟪कॢ⟫]⟪पत् कृष्⟫ 第一人称/第六人称：使役式 :sig[⟪कर्ष⟫]⟪यति⟫，不定过去式 ⟪अच⟫:sig[⟪कर्ष⟫]⟪त्⟫ / ⟪अची⟫:sig[⟪कृ⟫]⟪षत्⟫
:::
重读音节的元音：

在对词干音节应用上述规则后，必须遵循以下关于重读音节元音的规则：

::: grammar-box
**起点是常规的重读元音，即：**

*   a 对应 a, ā, ṛ, ṝ, ḷ
*   i 对应 i, ī, e, ai
*   u 对应 u, ū, o, au

**该重读元音经历以下变化：**

*   **i, u 被 ī, ū 替换，当词干音节以单个辅音开头且韵律上为短时：**
⟪भिद्⟫ 7U: 使役 ⟪भेदयति⟫, 不定过去时 ⟪अ⟫:sig[⟪बी⟫]⟪भिदत् तुद्⟫ 6U: 使役 ⟪तोदयति⟫, 不定过去时 ⟪अ⟫:sig[⟪तू⟫]⟪तुदत्⟫

*   **a 被 ī 替换，当词干音节韵律上为短且以单个辅音开头时。若词干音节韵律上为短但以多于一个辅音开头，则重复音节的 a 被替换为 i。若词干音节韵律上为长，则保留 a：**
⟪नी⟫ 1U: 使役 ⟪नाययति⟫, 不定过去时词干 ⟪नय्⟫, 不定过去时 ⟪अ⟫:sig[⟪नी⟫]⟪नयत् कृ⟫ 8U: 使役 ⟪कारयति⟫, 不定过去时词干 ⟪कर्⟫, 不定过去时 ⟪अ⟫:sig[⟪ची⟫]⟪करत् त्यज्⟫ 1P: 使役 ⟪त्याजयति⟫, 不定过去时词干 ⟪त्यज्⟫, 不定过去时 ⟪अ⟫:sig[⟪ति⟫]⟪त्यजत् भू⟫ 1P: 使役 ⟪भावयति⟫, 不定过去时词干 ⟪भव्⟫, 不定过去时 ⟪अ⟫:sig[⟪बी⟫]⟪भवत्⟫

关于基尔霍恩（Kielhorn）语法 § 435c ff. 中特定词根的例外情况。

**以元音开头的词干音节按照以下规则进行重复：**

*   **若起始元音后仅跟随单个辅音或一组辅音，且该组辅音的第一个成员既非鼻音也非 d 或 r，则重复音节为：**

元音 - 其后跟随的第一个辅音（即在重复音节中所需的相应代表）- **i** - 所有其他辅音

:::
::: indent
⟪अश्⟫ 9P: 使役 ⟪आशयति⟫, 重复音节 ⟪आशिश्⟫, 不定过去时 ⟪आशिशत् इष्⟫ 6P: 使役 ⟪एषयति⟫, 重复音节 ⟪एषिष्⟫, 不定过去时 ⟪ऐषिषत् ईक्ष्⟫ 1Ā: 使役 ⟪ईक्षयति⟫, 重复音节 ⟪ईचिक्ष्⟫, 不定过去时 ⟪ऐचिक्षत्⟫
:::
*   如果起始元音后跟随以鼻音或 d、r 开头的辅音群，则该辅音群的第二个辅音（或其替代者）会按照以下模式插入 i：


元音 - 第一个辅音 - 第二个辅音（替代者）- i - 第二个辅音

::: indent
⟪अञ्ज्⟫ 7P：使役 ⟪अञ्जयति⟫，重音节 ⟪अञ्जिज्⟫，不定过去时 ⟪आञ्जिजत् ऋ⟫ 1P：使役 ⟪अर्पयति⟫，重音节 ⟪अर्पिप्⟫，不定过去时 ⟪आर्पिपत् अर्ह्⟫ 1P：使役 ⟪अर्हयति⟫，重音节 ⟪अर्जिह्⟫，不定过去时 ⟪आर्जिहत्⟫
:::
这种以元音开头的派生词干（使役动词）的重叠形式被称为“阿提卡式重叠”。
## 56.2. 祈愿语气

::: grammar-box
**祈愿语气是去增音的形式，即其形式与陈述式过去未完成时或不定过去时的去增音形式相同。本土印度语法并未将祈愿语气视为独立的语法范畴。**
:::

霍夫曼，卡尔（1915–1996）：《吠陀中的祈愿语气：一项共时功能研究》/ 卡尔·霍夫曼著。-- 海德堡 : 温特出版社, 1967. -- 298页。-- (印度日耳曼图书馆 : 第3系列, 研究)
:::
祈愿语气在吠陀中具有以下特征：

*   它不是叙述性的，而是提及性的
*   它是无时间阶段的
*   祈愿语气现在时（=去增音的过去未完成时）表示未完成的体貌
*   祈愿语气不定过去时表示已完成的体貌。

::: grammar-box
**在后吠陀梵语中，祈愿式仅与禁止副词⟪मा⟫（+ 祈愿式不定过去时）或⟪मा स्म⟫（+ 祈愿式现在时或不定过去时）连用，不同的体貌特征通常不再体现。**

（带体貌

*   ⟪मा⟫ + 祈愿式不定过去时构成禁止句：意为“不要开始……！”、“别做……！”
*   ⟪मा स्म⟫ + 祈愿式现在时构成抑制句，即禁止已经进行的行为或已存在的状态：意为“停止……！”、“放弃……！”

然而，在古典梵语中通常不作此区分。）
:::
## 56.3. 禁止句

::: grammar-box
**主要形式：**

**⟪मा⟫ + 祈愿式不定过去时**

**⟪मा स्म⟫ + 祈愿式不定过去时或祈愿式现在时**
:::
例句：

::: indent
⟪मा कर्महेतुर्भूः⟫ “不要成为受业果驱动的人！”（祈愿式不定过去时）（⟪भगवद्गीता⟫ 2,47c)

⟪क्लैब्यं मा स्म गमः⟫ “不要变得不男子汉！”（禁止式不定过去时）(⟪भगवद्गीता⟫ 2,3a)
:::
::: media
![](/images/lekt5602.webp)
图：⟪क्लैब्यं मा स्म गमः⟫
海报（欧内斯托·切·格瓦拉）属于瓦拉奇拉（വാല്ലചിര），特里苏尔（തൃശ്ശൂര്‍）的一个政党。“对其上文字的粗略翻译如下：殉道对革命者而言是一种迷人的体验。而对懦夫来说，则是一种令人畏惧的退路。切不是胆小鬼的榜样。”
（图片来源：[详情](/zh-CN/licenses#lekt5602)）
:::
这两个例子都具有禁止意义。因此，这里的禁止式不定过去时是在其原始意义上使用的。（此类句子中禁止式不定过去时的占主导地位，或许可以解释为禁止句相对于抑制句的占主导地位，但这一问题对于古典梵语仍有待研究。）

::: grammar-box
**其他形式的禁止句：**

*   **⟪मा⟫ + (⟪स्म⟫) + 祈使式（罕见） **
**例如： ⟪मा ते सङ्गो ऽस्त्वकर्मणि⟫**

*   ⟪अलम्⟫ 或 ⟪कृतम्⟫ = 抑制句中的工具格  
例如 ⟪अलं विषादेन⟫ “别再沮丧了！= 停止沮丧吧！= 振作起来！”  

*   ⟪न⟫ + 动形词（必要分词）

## 第56.4节。 ⟪स्म⟫

::: grammar-box
**⟪स्म⟫ 强调：“确实，的确，无疑，正是”**

**此外，以下结构也非常重要：**

:::
::: indent
⟪स्म⟫ + 陈述式现在时用于讲述过去的事情，特别是用来表示过去的持续时间：

例如 ⟪वसति स्म⟫ “曾经居住”（⟪स्म⟫ 有时也可以省略）。
:::
