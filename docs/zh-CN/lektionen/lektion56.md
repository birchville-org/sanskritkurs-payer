# Lektion 56

## 56.1. Der reduplizierte Aorist

::: grammar-box
**教育：**

**Augment + 重复词根 + a + 主题次要词尾**

**词根音节可以是低阶或高阶。对于以 -i 或 -u 结尾的词根，低阶是常规形式。**

词尾的 -i, -u 分别替换为 -iy 和 -uv。

词尾的 -ā（对应 -e）脱落。
:::

以下动词构成此种不定过去时：

*   ⟪श्रि⟫ 1U “前往”
*   ⟪द्रु⟫ 1P “奔跑”
*   ⟪कम्⟫ 1Ā “爱”：⟪अचकमत⟫ / ⟪अचीकमत⟫（见下文！）
*   ⟪पत्⟫ 1P “落下”：⟪अपप्तत्⟫（a-pa-pt-a-t；pt 为 pat 的弱级）
*   ⟪वच्⟫ 2P “说”：⟪अवोचत्⟫（a-va + uc-a-t）

::: grammar-box
**第十类现在时态的所有词根以及所有使动态词干，均始终构成重音过去时。**
:::
### 56.1.1. 使动态与第十类现在时态词根的过去时构成

词根音节：

::: grammar-box
**出发点为现在时词干或使动词词干的形式，即在去除构成成分 -aya- 之后所剩余的形式（即使动词 -paya- 的词干为 -p）。**

**词干音节中元音的确定，在不定过去时中遵循以下规则：**

*   **\-ā- 在简单辅音前被 -a- 取代：**  
    ⟪पॄ⟫ 第三人称单数：使役 ***⟪पार⟫***⟪यति⟫，不定过去式 ⟪अपि⟫***⟪पर⟫***⟪त्⟫  
    ⟪द्रु⟫ 第一人称单数：使役 ***⟪द्राव⟫***⟪यति⟫，不定过去式 ⟪अदु⟫***⟪द्रव⟫***⟪त्⟫ / ⟪अदि⟫***⟪द्रव⟫***⟪त्⟫  
    ⟪नी⟫ 第一人称单数（不规则）：使役 ***⟪नाय⟫***⟪यति⟫，不定过去式 ⟪अनी⟫***⟪नय⟫***⟪त्⟫  
    ⟪ज्ञा⟫ 第九人称单数（不规则）：使役 ***⟪ज्ञाप⟫***⟪यति⟫，不定过去式 ⟪अजि⟫***⟪ज्ञप⟫***⟪त्⟫

*   **\-ī-, -e-, -ai- 在简单辅音前被 -i- 替换：**  
    ⟪चित्⟫ 第一人称：使役 ***⟪चेत⟫***⟪यति⟫，不定过去时（Ā） ⟪अची⟫***⟪चित⟫***⟪त⟫

*   **-u-, -o-, -au- 在简单辅音前被 -u- 替换：**  
    ⟪चुर्⟫ 10U: ***⟪चोर⟫***⟪यति⟫, 过去时 ⟪अचू⟫***⟪चुर⟫***⟪त्⟫

**对于某些词根，上述变化是可选的，或者必须避免：**

*   **词干音节末尾辅音前直接跟随的、替代 ṛ, ṝ, ḷ 的 ar, ār, īr, al 保持可选不变，或由 ṛ 和 ḷ 替换：**  
    ⟪कॢप्⟩ 1Ā: 使役 ***⟪कल्प⟩***⟪यति⟩, 过去时 ⟪अच⟩***⟪कल्प⟩***⟪त्⟩ / ⟪अची⟩***⟪कॢ⟩***⟪पत्⟩  
    ⟪कृष्⟩ 1P/6U: 使役 ***⟪कर्ष⟩***⟪यति⟩, 过去时 ⟪अच⟩***⟪कर्ष⟩***⟪त्⟩ / ⟪अची⟩***⟪कृ⟩***⟪षत्⟩
:::
重复音节的元音：

在将上述规则应用于词根音节之后，必须遵循以下关于重叠音节元音的规则：

::: grammar-box
**起点是规则的重复元音，即。**

*   a 代表 a, ā, ṛ, ṝ, ḷ
*   i 代表 i, ī, e, ai
*   u 代表 u, ū, o, au

**这个重叠元音经历以下变化：**

*   **i, u 被 ī, ū 替换，当词干音节仅以一个辅音开头且韵律上为短音时：**  
    ⟪भिद्⟫ 7U：使动 ⟪भेदयति⟫，不定过去 ⟪अ⟫***⟪बी⟫***⟪भिदत्⟫  
    ⟪तुद्⟫ 6U：使动 ⟪तोदयति⟫，不定过去 ⟪अ⟫***⟪तू⟫***⟪तुदत्⟫

*   **a 被 ī 替换，如果词干音节在韵律上为短音节且仅以一个辅音开头。如果词干音节在韵律上为短音节且以多于一个辅音开头，则重复音节的 a 被 i 替换。如果词干音节在韵律上为长音节，则保留 a：**  
    ⟪नी⟫ 1U：使役 ⟪नाययति⟫，不定过去时词干音节 ⟪नय्⟫，不定过去时 ⟪अ⟫***⟪नी⟫***⟪नयत्⟫  
    ⟪कृ⟫ 8U：使役 ⟪कारयति⟫，不定过去时词干音节 ⟪कर्⟫，不定过去时 ⟪अ⟫***⟪ची⟫***⟪करत्⟫  
    ⟪त्यज्⟫ 1P：使役 ⟪त्याजयति⟫，不定过去时词干音节 ⟪त्यज्⟫，不定过去时 ⟪अ⟫***⟪ति⟫***⟪त्यजत्⟫  
    ⟪भू⟫ 1P：使役 ⟪भावयति⟫，不定过去时词干音节 ⟪भव्⟫，不定过去时 ⟪अ⟫***⟪बी⟫***⟪भवत्⟫

Kielhorn《语法》§ 435c 及以下部分中特定词根的特殊情况

**以元音开头的词根音节，按照以下规则进行重

*   **如果起始元音后仅跟随一个辅音或辅音群，且其首辅音既非鼻音，也非 d 或 r，则重叠音节为：**

Vokal - erster darauf folgender Konsonant (bzw. dessen in einer Reduplikationssilbe geforderter Vertreter) - **i** \- alle Konsonanten

:::
::: indent
⟪अश्⟫ 9P：Kaus. ⟪आशयति⟫，重叠音节 ⟪आशिश्⟫，不定过去式 ⟪आशिशत्⟫
⟪इष्⟫ 6P：Kaus. ⟪एषयति⟫，重叠音节 ⟪एषिष्⟫，不定过去式 ⟪ऐषिषत्⟫
⟪ईक्ष्⟫ 1Ā：Kaus. ⟪ईक्षयति⟫，重叠音节 ⟪ईचिक्ष्⟫，不定过去式 ⟪ऐचिक्षत्⟫
:::
*   **如果词首元音后跟随以鼻音或 d 或 r 开头的辅音群，则该辅音群的第二个辅音（或其代表）会按照以下模式插入 i：**

元音 - 第一个辅音 - 第二个辅音（替代者）- i - 第二个辅音

::: indent
⟪अञ्ज्⟫ 7P：使役。⟪अञ्जयति⟫，重叠音节⟪अञ्जिज्⟫，不定过去时⟪आञ्जिजत्⟫
⟪ऋ⟫ 1P：使役。⟪अर्पयति⟫，重叠音节⟪अर्पिप्⟫，不定过去时⟪आर्पिपत्⟫
⟪अर्ह्⟫ 1P：使役。⟪अर्हयति⟫，重叠音节⟪अर्जिह्⟫，不定过去时⟪आर्जिहत्⟫
:::
这种以元音开头的派生词干（使役）的重叠形式被称为“阿提卡式重叠”。
## 56.2. 祈愿语气

::: grammar-box
**祈使语气（Injunktiv）是去增音（augmentlose）形式，即其形式与陈述语气过去时（Imperfekt）或不定过去时（Aorist）的去增音形式相同。印度本土语法并未将祈使语识别为特殊的语法范畴。**
:::
根据这项基础性著作：

::::

吠陀中的祈愿语气具有以下特征：

*   它不是陈述性的，而是提及性的
*   它是无时间阶段的
*   祈使语气现在时（= 无增补的不完整过去时）表示未完成体
*   祈使语气不定过去时表示完成体。

::: grammar-box
**在后吠陀梵语中，祈愿式仅与禁止副词⟪मा⟫（+祈愿式过去时）或⟪⟪मा⟫⟪स्म⟫（+祈愿式现在时或过去时）连用，其不同的体貌特征通常不再起作用。**

(mit Aspekt)

*   würde ⟪मा⟫ + 祈使语气完成时 表示禁止句：“不要开始……！”，“不要做……！”
*   würde ⟪मा⟫ ⟪स्म⟫ + 祈使语气现在时 表示抑制句，即禁止已经进行的行为或已经存在的状态：“停止做……！”，“放弃……！”

然而，这种区别在古典梵语中通常不予区分。）
:::
## 56.3. 禁止句

::: grammar-box
**主要形式：**

**⟪मा⟩ + 祈愿式不定过去时**

**⟪मा⟫ ⟪स्म⟫ + 祈愿语气不定过去时或祈愿语气现在时**
:::
例子：

::: indent
⟪मा⟫ ⟪कर्महेतुर्भूः⟫ “不要成为因行为果报而行动的人！”（命令式不定过去时）（⟪भगवद्गीता⟫ 2,47c）

⟪क्लैब्यं⟫ ⟪मा⟫ ⟪स्म⟫ ⟪गमः⟫ “不要变得不男子气概！”（祈使语气不定过去时）（⟪भगवद्गीता⟫ 2,3a）
:::: media
![](/images/lekt5602.webp)
图：⟪क्लैब्यं⟫ ⟪मा⟫ ⟪स्म⟫ ⟪गमः⟫
海报（欧内斯特·切·格瓦拉）来自瓦拉奇拉（വാല്ലചിര）特里苏尔（തൃശ്ശൂര്⟪‍⟫）的一个政党。“对其上文字的大致翻译是：殉道对革命者来说是一种迷人的体验。而对懦夫来说，这是一种令人望而生畏的退路。切不是胆小鬼的榜样。”
（图片来源：[详情](/zh-CN/licenses#lekt5602)）
::::
:::
这两个例子都具有禁止的含义。因此，这里的祈使语气不定过去时是在其原始意义上使用的。（此类句子中祈使语气不定过去时的占主导地位，也许可以解释为禁止句相对于抑制句的占主导地位，但这一问题尚需对古典梵语进行进一步研究。）

::: grammar-box
**禁止句的其他形式：**

*   **⟪मा⟫ + (⟪स्म⟫) + Imperativ (selten)  **
**例如：  ⟪मा⟫ ⟪ते⟫ ⟪सङ्गो⟫ ⟪ऽस्त्वकर्मणि⟫**

*   ⟪अलम्⟫ 或 ⟪कृतम्⟫ = 否定句中的工具格  
    例如：⟪अलं⟫ ⟪विषादेन⟫ “别再沮丧了！= 停止沮丧！= 振作起来！”

*   ⟪न⟫ + 动形词（必要性分词）

## 56.4. ⟪स्म⟫

::: grammar-box
**⟪स्म⟫ betont: „wahrhaftig, gewiss, zweifellos, geradezu“**

**此外，以下结构也非常重要：**

:::
::: indent
⟪स्म⟫ + 现在时陈述语气用于叙述过去的事件，特别是用来表示过去持续的状态：

例如 ⟪वसति⟫ ⟪स्म⟫ “曾经居住”（⟪स्म⟫ 有时也可能缺失）。
