# 第3课

## 3.1. 阴性单数主格

### 3.1.1. 以-s结尾的阴性单数主格

以下以元音结尾的名词词干，其阴性单数主格也形成**-s**尾：

::: grammar-box
**以-i结尾的阴性名词**：例如 **śruti** f. “听觉” -- 主格单数：**śrutis** = ⟪श्रुतिस्⟫
**以-u结尾的阴性名词**：例如 **dhenu** f. “奶牛” -- 主格单数：**dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. 无词尾的阴性单数主格

以下形成无词尾的阴性单数主格：

::: grammar-box
**以-ā结尾的阴性名词**：例如 **devatā** f. “神灵” -- 主格单数：**devatā** = ⟪देवता⟫
**以-ī结尾的阴性名词**：例如 **devī** f. “女神” -- 主格单数：**devī** = ⟪देवी⟫
:::
::: important
**注意！** 此外，还存在一些以-ī结尾的单音节阴性词根名词，其单数主格以-s结尾：例如 dhī f. “思想” -- 主格单数：dhīs = ⟪धीस्⟫。此外，lakṣmī (⟪लक्ष्मी⟫) f.、tarī (⟪तरी⟫) f. “船” 和 tantrī (⟪तन्त्री⟫) f. “弦” 也 irregularly（不规则地）形成以-s结尾的单数主格：lakṣmīs = ⟪लक्ष्मीस्⟫。
:::

## 3.2. 由阳性名词构成阴性名词的方法

::: grammar-box
**以-a结尾的阳性名词：**
**以-ā结尾的阴性名词**：例如 **kṣatriya** m. » **kṣatriyā** f. “刹帝利女子” = ⟪क्षत्रिया⟫
**以-ī结尾的阴性名词**：例如 **brāhmaṇa** m. » **brāhmaṇī** f. “婆罗门女子” = ⟪ब्राह्मणी⟫

**以-u结尾的阳性名词：**
**以-ī结尾的阴性名词**：例如 **sādhu** m. » **sādhvī** f. （善良的，女圣者）= ⟪साध्वी⟫
（**-u-** 在元音前变为 **-v-**，因此 **-u- + -ī** » **-vī**）
:::

## 3.3. 阳性和阴性名词的复数主格

::: grammar-box
阳性和阴性名词复数主格的词尾是 **-as**。
**以-a结尾的阳性名词**：**deva- + -as** » **devās** = ⟪देवास्⟫
**以-ā结尾的阴性名词**：**devatā- + -as** » **devatās** = ⟪देवतास्⟫
**以-i结尾的阳性名词**：**kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**以-i结尾的阴性名词**：**śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**以-ī结尾的阴性名词**：**devī- + -as** » **devyas** = ⟪देव्यस्⟫
**以-u结尾的阳性名词**：**guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**以-u结尾的阴性名词**：**dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
注释：**e** 是 **i** 的高阶（guṇa），**o** 是 **u** 的高阶。


## 3.4. 元音连声

::: grammar-box
**简单元音，若仅长度不同或无区别，则“融合”为相应的长元音：**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**）
:::
例如

devatā + annapūrṇā » devatānnapūrṇā “安纳普尔那是位神祇” = ⟪देवतान्नपूर्णा⟫

> （安纳普尔那是掌管食物与烹饪的女神，被视为湿婆之妻帕尔瓦蒂的化身。）

devī + indrāṇī » devīndrāṇī “因陀罗尼是位女神” = ⟪देवीन्द्राणी⟫

> （因陀罗尼是神祇因陀罗之妻。）

::: grammar-box
**简单元音（除 -a / -ā 外）在遇到不同类元音前，替换为相应的半元音：**
i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**
(!! 关于此规则，尤其对双数形式存在例外 !!)
:::
例如

devī + umā » devy umā “乌玛是一位/那位女神” = ⟪देव्युमा⟫

> （乌玛是帕尔瓦蒂的名字，即湿婆之妻）

::: grammar-box
**-a / -ā 在遇到不同类元音前：**
a / -ā + i- / ī- » **-e-**
a / -ā + ṛ- » **-ar-**
a / -ā + e- / ai- » **-ai-**
a / -ā + o- / au- » **-au-**
:::
因此，此连声遵循以下模式：

śūdrā + itarā » śudretarā “Itarā 是一位首陀罗女性” = ⟪शूद्रेतरा⟫


## 3.5. -ās 的句法连声（Sattsandhi）

::: grammar-box
**-ās 在所有浊音前均替换为 -ā。**
:::
例如：

dvijās + vaiśyāḥ » dvijā vaiśyāḥ “吠舍是再生人” = ⟪द्विजा वैश्याः⟫


## 3.6. 词汇表

**请学习以下单词：**

**śruti** f. = ⟪श्रुति⟫ ：听闻，永恒的传统（对《吠陀》和《梵书》的称呼）。

**smṛti** f. = ⟪स्मृति⟫ ：再现，记忆，冥想中的再现 = 正念，传统（与 **śruti** 相对的概念）。包括：
六个 **vedāṅga** n.（⟪वेदाङ्ग⟫）
1. **śikṣā** f.（⟪शिक्षा⟫）：正确的发音
2. **chandas** n.（⟪छन्दस्⟫）：韵律
3. **vyākaraṇa** n.（⟪व्याकरण⟫）：语法
4. **nirukta** n.（⟪निरुक्त⟫）：词源学，词语解释
5. **jyotiṣa** n.（⟪ज्योतिष⟫）：天文学，历法学
6. **kalpa** m.（⟪कल्प⟫）：仪式
**śrautasūtra** n.（⟪श्रौतसूत्र⟫）：关于大型祭祀执行的经典著作
**gṛhyasūtra** n.（⟪गृह्यसूत्र⟫）：关于日常生活仪式和祭祀的经典著作
**dharmasūtra** n.（⟪धर्मसूत्र⟫）和 **dharmaśāstra** n.（⟪धर्मशास्त्र⟫）：关于法律和习俗的经典著作（正确的行为准则）
两大史诗 **mahābhārata** n.（⟪महाभारत⟫）和 **rāmāyaṇa** n.（⟪रामायण⟫）
**purāṇa** n.（⟪पुराण⟫）
**nītiśāstra** n.（⟪नीतिशास्त्र⟫）：处世智慧经典

**smṛti** 也特别指代法论（Dharmalehrwerke）。

**dhenu** f. = ⟪धेनु⟫ :（母）牛。

**paśu** m. = ⟪पशु⟫ : 驯化的家畜，牲畜（集合名词）。

**devatā** f. = ⟪देवता⟫ : 神祇（抽象与具体）。

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : 婆罗门女。

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : 刹帝利女。

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : 刹帝利之妻。

**vaiśyā** f. = ⟪वैश्या⟫ : 吠舍女。

**śūdrā** f. = ⟪शूद्रा⟫ : 首陀罗女。

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : 首陀罗之妻。

**devī** f. = ⟪देवी⟫ : 女神，特指难近母（Durgā）f. = ⟪दुर्गा⟫，湿婆（Śiva）的配偶 = ⟪शिव⟫。

::: media
![](/images/lekt0303.webp)
图注：难近母（Durgā）= ⟪दुर्गा⟫，奥里萨邦
（图片来源：[详情](/images/lekt0303)）
:::
**sādhvī** f. = ⟪साध्वी⟫ : sādhu 的阴性形式。

**gurvī** f. = ⟪गुर्वी⟫ : guru 的阴性形式。

**asmitā** f. = ⟪अस्मिता⟫ : “我性”，即（错误的）信念：**我**是那个看等等的人。

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : 哲学（通过逻辑上正确的推理得出结论的科学）。

**upekṣā** f. = ⟪उपेक्षा⟫ : 忽视，冷漠。

**karuṇā** f. = ⟪करुणा⟫ : 慈悲，怜悯。

**muditā** f. = ⟪मुदिता⟫ : 喜悦，特别是随喜（与嫉妒相对）。


## 3.7. 练习

**A) 将下列句子变为复数：**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**B) 通过填入内容构成名词句：**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) 转换为阴性形式：**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**D) 翻译成梵文：**

1. Umā是一位女神。
《吠陀》是śruti（天启）。
女教师们是女神。
奶牛是被驯化的动物。
诗人们是教师。
Kṣatriyas（刹帝利）是再生族。
圣人们属于Śūdras（首陀罗）。
