# 第11课

## 11.1. 双第四格（双重宾格）

::: grammar-box
**某些动词可支配双第四格（dvitīyā）：人的第四格与事物的第四格。**

**包括以下动词：**
**表说话的动词**：对某人（第四格）说关于某事（第四格）；告诉某人（第四格）某事（第四格）
**表提问的动词**：就某事（第四格）询问某人（第四格）
**表教学的动词**：教某人（第四格）某事（第四格）
其他一些动词，其用法会在词汇表中注明

**若将此类结构转换为被动语态，则人（被询问者等）变为第一格（prathamā），事物（所问之事等）仍保留在第四格。**

例如 **rāmo brāhmaṇaṃ dharmaṃ pṛcchati** = ⟪रामो ब्राह्मणं धर्मं पृच्छति⟫ = “罗摩向婆罗门询问正法。”
» 被动语态：**rāmeṇa brāhmaṇo dharmaṃ pṛcchyate** = ⟪रामेण ब्राह्मणो धर्मं पृच्छयते⟫

**此规则仅适用于人和事物均为宾语的情况。若某事是唯一宾语，则按被动句的基本方案置于第一格（prathamā）：**

例如 **rāmo dharmaṃ pṛcchati** = ⟪रामो धर्मं पृच्छति⟫ = “罗摩询问正法。”
» 被动语态：**rāmeṇa dharmaḥ pṛcchyate** = ⟪रामेण धर्मः पृच्छयते⟫
:::

## 11.2. 词汇表

**请学习以下单词：**

**iti** ⟪इति⟫ ：如此
置于思想、愿望、言论或引文的表述之后，犹如引号（"）。
例如 **sādhavaḥ svargaṃ gacchantīti brāhmaṇā vadanti** “婆罗门说：‘善人升入天堂’” = “婆罗门说，善人升入天堂”。
梵语中没有间接引语；含 **iti** 的结构在德语中通常需转换为间接引语。
**... (引文) ... iti śrutiḥ** = “《吠陀》如是说”。
**iti** 之后常隐含一个表思维的动词：“心想：‘……’而做某事”。在德语中需以地道方式表达（例如：“因为他饿了，他便……”）。

**evam** ⟪एवम्⟫：如此（副词用法，例如 **evaṃ jayati** “他因此获胜”）。
**na** ⟪न⟫：不
否定单个词语（置于该词之前：**na sādhuḥ** “非善者”）或整个句子（置于句首或动词之前）。

**putra** 阳性 ⟪पुत्र⟫：儿子（在印度，生育一个能够为先祖举行祭祀的儿子是必要的。）
**dharma** 阳性 ⟪धर्म⟫：（“那稳固之物”，即）正法、法律、习俗、品格。
最接近自然法则/道德法则的概念。每个人根据其 **varṇa**（种姓）和 **āśrama**（人生阶段）都有其自身的职责（**svadharma**）。
**adharma** 阳性 ⟪अधर्म⟫：非正法（与 **dharma** 相对）。
**iṣ** 第六变位（icchati） ⟪इष् इच्छति⟫：渴望（**iṣ-ccha-ti**）。

**一些名词派生：**

**vad** 第一变位 ⟪वद्⟫：说
**vāda** 阳性 ⟪वाद⟫：言论、陈述、话语
**vadana** 中性 ⟪वदन⟫：说话；发声器官：嘴、脸

**prach** 第六变位 ⟪प्रच्छ्⟫：询问
**praśna** 阳性 ⟪प्रश्न⟫：问题（后缀 **-na**，同 **yaj-ña**）

**iṣ** 第六变位 ⟪इष्⟫：渴望
**iṣṭi** 阴性 ⟪इष्टि⟫：愿望（由 **iṣ** + **-ti** 构成）
