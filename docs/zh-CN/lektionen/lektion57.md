# 第五十七课

## 57.1. 第四不定过去式：s-不定过去式

::: grammar-box
**s-词干过去时（s-Aorist）由大多数⟪अनिट्⟫词根构成，除非它们仅具有其他过去时形式。可选的⟪अनिट्⟫词根通常可以选择构成s-词干过去时或iṣ-过去时。此外，⟪अनिट्⟫词根在按照过去时的第一、第二或第六种形式构成⟪परस्मैपद⟫时，也按照s-词干过去时的规则构成⟪आत्मनेपद⟫。**

**形态学：增音 + 词根 + s + 无元音后缀第二变位**
:::
带有词干构成后缀的词尾表

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟫** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟫** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**应用一般语音规律，即两个塞音之间的擦音脱落（参见 ⟪उद्⟫ + ⟪स्थित⟩ ⟪उत्थित⟩），也就是说，以 -t- 或 -th- 开头的词尾前的词干构成后缀 -s- 脱落（但在鼻音或 r- 之后不脱落）。**

示例：

:::
::: indent
3.sg.Ā a-kṣip + s + ta » ⟪अ⟫***⟪क्षिप्त⟫***
2.sg.Ā a-kṣip + s + thās » ⟪अ⟫***⟪क्षिप्था⟫***⟪स्⟫
:::
此类形式也可能属于词根不定过去时，并且可能部分确实属于词根不定过去时。
印度语法学家也将如 ⟪अकृत⟫（3.sg.Ā）这样的形式归入 s-不定过去时，尽管它们明确属于词根不定过去时。为此，印度语法学家为 s-不定过去时发明了以下临时音变规则：

::: indent
“短元音之后，以 -st- 或 -sth- 开头的词尾会失去 -s-。”
:::
否则，需注意尾辅音与 s- 结合的音变规则。

对于 -dhvam 有：

::: grammar-box
**-dhvam 中的 -dh- 在所有非 a/ā 元音以及 -r 之后均替换为 -ḍh-。**

:::
::: indent
例如，***⟪चि⟫*** 5U: 第二人称复数.Ā ***⟪अचेढ्वम्⟫***
:::
::: grammar-box
**⟪परस्मैपद⟫ : 强音级**

*   **⟪आत्मनेपद⟫ :**
*   **⟪आत्मनेपद⟫ :**
*   **以 -ṝ 结尾者替换为 -īr 或 -ūr**
*   **可变换元音的词根，以 ā/e/o 结尾：弱音级**
*   **其他词根元音：保持不变（即通常为弱音级）**
*   **其他词根元音：保持不变（即通常为弱音级）**
:::
示例：

| --- | --- |

| ⟪श्रु⟫ 5P | ⟪अश्रौषीत्⟫ |

**⟪दृश्⟫ 和 ⟪सृज्⟫ 在 ⟪परस्मैपद⟫ 中带有升调双元音 -rā- 的长音阶段：**

:::
::: indent

:::

**不规则形式：**

**1. 以鼻音结尾的词根（⟪गम्⟫, ⟪मन्⟫, ⟪रम्⟫）构成高音质 s-不定过去时：**
**⟪अगंसि⟩ ⟪।⟩ ⟪अमंसि⟩ ⟪।⟩ ⟪अरंस्त⟩**
**此外，对于 ⟪गम्⟩，存在规则的低音质形式：**
**⟪अगसि⟩（“\*a-gm-si”）⟪।⟩ ⟪अगथास्⟩ ⟪।⟩ ⟪अगत⟩（在第三人称单数中，⟪गम्⟩ 具有主题元音不定过去时）**

2.  ⟪⟪पद्⟫⟫ 4Ā 是常规的（例如 ⟪⟪अपत्सि⟫⟫），但在第三人称单数Ā中，它却具有被动词干不定过去式的形式：
    ⟪⟪अपादि⟫⟫ “他走了”

3.  ⟪बुध्⟩ Ā 可以在第三人称单数中可选地采用被动词干不定过去式的形式：
    ⟪अबोधि⟩ / ⟪अबुद्ध⟩ “他认识”
:::
