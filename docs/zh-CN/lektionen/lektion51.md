# 第51课

## 51.1. ⟪उपपद⟫复合词

::: grammar-box
**⟪उपपद⟫复合词（⟪उपपद⟫ n. “伴随语”）是⟪तत्पुरुष⟫，其后续成分为动词性名词（verbal noun），该词仅作为复合词的后续部分出现，不作为独立的单词使用。⟪उपपद⟫通过⟪कृत्⟫后缀构成**
* **-Ø**
* **-a**
* **-t**

**构成。它们是施事名词（nomina agentis），即指代执行由底层词根所表示之行为的施事者（⟪कर्तृ⟫）。**

**此类复合词由本土注释家并非通过名词组合，而是借助动词形式来解析：**

例如：

:::
::: indent
⟪सुखकरः⟫ = ⟪सुखं करोतीति सुखकरः कुलघ्नः⟫ = ⟪कुलम्हन्तीति कुलघ्नः⟫
:::
例如：

a) ⟪कृत्⟫后缀 \-Ø

::: indent
\-⟪नी⟫ 3 “引导者”，例如 ⟪सेनानी⟫ m. “军队统帅”（⟪सेना⟫ f. “军队”）

\-⟪भुज्⟫ 3 “享受、食用”，例如 ⟪भूमिभुज्⟫ m. “国王”（⟪भूमि⟫ f. “大地”）

\-⟪विद्⟫ 3 “知晓”，例如 ⟪धर्मविद्⟫ 3 “知法者”
:::

c) ⟪कृत्⟫后缀 -a

::: indent
\-⟪ग⟫ 3 “行走（在……中，向）”（可能源自词根 gā，最简形式为 g + a），例如 ⟪खग⟫ 3 “飞翔”，阳性名词意为“鸟、行星”（⟪ख⟫ 中性名词意为“洞，‘空中’空间”）

\-⟪घ्न⟫ 3 “击杀”，例如 ⟪कुलघ⟫ 3 “杀害家族”

\-⟪ज⟫ 3（jña » jā » 最简形式为 j + a）“源自……，生于”，例如 ⟪आत्मज⟫ “儿子”

\-⟪ज्ञ⟫ 3 “精通”（jñ-a），例如 ⟪सर्वज्ञ⟫ 3 “全知”

\-⟪द⟫ 3 “给予”（d-a），例如 ⟪वारिद⟫ 阳性名词意为“云”（⟪वारि⟫ 中性名词意为“水”）

\-⟪प⟫ 3 “饮用”（p-a），例如 ⟪द्विप⟫ 阳性名词意为“大象（两次饮水）”

\-⟪प⟫ 3 “保护”（p-a），例如 ⟪भूप⟫ “守护大地 = 国王”

\-⟪स्थ⟫ 3 “站立于，位于”（sth-a），例如 ⟪गृहस्थ⟫ 阳性名词意为“管家、家长”

\-⟪कर⟫ 3 “造成，做”，例如 ⟪सुखकर⟫ 3 “带来幸福”

## 51.2. 以简单辅音（鼻音、半元音、-s 除外）结尾的词干变格

::: grammar-box
**以简单辅音（鼻音、半元音、-s 除外）结尾的词干没有词干级差。变格完全规则，只需附加标准的格尾。**

**唯一的例外：在阳性、中性名词的呼格复数中，词干末尾前会插入一个鼻音。**
:::
### 51.2.1. 词干以非腭塞音结尾

::: grammar-box
**适用常规语音变化规律，即：**
* **在词尾位置出现相应的清不送气音**
* **在以 -su 结尾的复数方位格前，词尾首先被相应的清不送气音替换，随后发生相应的语音变化**
* **在浊辅音前，词尾被相应的浊不送气音替换。**
:::
示例：

⟪शत्रुजित्⟫ 3 “战胜敌人者”

::: indent
阳性、阴性：

:::
::: indent
单数：

:::
::: indent
主格/呼格 ⟪शत्रुजित्⟫ (śatrujit + s)
宾格 ⟪शत्रुजितम्⟫
:::
复数：

::: indent
主格/宾格/呼格 ⟪शत्रुजितस्⟫
工具格 ⟪शत्रुजिद्भिस्⟫
方位格 ⟪शत्रुजित्सु⟫
:::
中性

::: indent

复数主格/宾格/呼格 :sig[⟪शत्रुजिन्ति⟫]
:::
⟪सुयुध्⟫ 3 “善于战斗者”

::: indent

等等。
:::
完整变位表见 Kielhorn《语法》第 16 页及以下。

### 51.2.2. 词干以腭塞音（c, ch, j）、ś、ṣ 结尾

::: grammar-box
**在以元音开头的词尾前，词干词尾保持不变。**

**对于其他词尾适用以下规则：**

* **以 -c 和 -j 结尾的词干，其词尾被替换为 k，随后该词干按以 -k 结尾的词干进行处理**
* **在某些词汇中（见 Kielhorn《语法》第 18 页列表），以 -j 结尾的词干，其词尾被替换为 -ṭ**
* **以 -ch 结尾的词干，其词尾被替换为 -ṭ**
* **以 -ś 和 -ṣ 结尾的词干，除少数例外情况外，其词尾被替换为 -ṭ。在例外情况下，-ś 和 -ṣ 被替换为 -k**

**即**

* **-c » -k**
* **-ch » -ṭ**
* **-j » -k 或 -ṭ**
* **-ś » -ṭ 或 -k**
* **-ṣ » -ṭ 或 -k**
:::
例如：

⟪सत्यवाच्⟫ 3 “说真话”（⟪बहुव्रीहि⟫）

:::

### 51.2.3. 以 -h 结尾的词干

::: grammar-box
**在元音开头的词尾之前，-h 保持不变。**

**在其他词尾之前**
* **-h 通常被替换为 -ḍh**
* **如果底层词根以 d- 开头，则 -h 被替换为 -gh。其他一些词也可选或强制使用此规则（参见 Kielhorn《语法》§80,2 的汇总）**
* **（在词根名词的词尾处，-h 被替换为 -dh）**

**根据这些替换，词干将继续被处理为以 -ḍh、-gh 或 -dh 结尾。**

**参见 Kielhorn《语法》第20页及以下。**
:::

阳性，阴性：

宾格 ⟪गुहम्⟫
:::
复数：

::: indent
工具格 ⟪घुड्भिस्⟫
处所格 ⟪घुट्सु⟫

## 51.3. 词首 h- 的连声

::: grammar-box
**在词首 h- 之前，前面的塞音被相应的浊不送气音取代，而词首的 h- 则被该塞音对应的浊送气音取代：**

:::
::: indent
⟪तत्⟫ + ⟪हि⟫ » ⟪तद्धि वाक्⟫ + ⟪हि⟫ » ⟪वाग्घि परिव्राट्⟫ + ⟪हि⟫ » ⟪परिव्राड्ढि⟫
:::
## 51.4. 词首 ch- 的连声

::: grammar-box
**短元音之后，⟪मा⟫ “不” 和 ⟪आ⟫ “去/向” 之后，词首的 ch- 被替换为 cch-：**

:::
::: indent
⟪न⟫ + ⟪छिन्दति⟫ » ⟪न च्छिन्दति⟫
:::
## 51.5. 词中的 -ch-

::: grammar-box
**在词中，所有元音之后的 -ch- 被替换为 -cch-：**

:::
::: indent
例如 ⟪छिद्⟫ » ⟪चिच्छेद⟫
:::

由于排卵发生在月经开始前的14天，因此在这种确定生育期的规定下，如果两次月经间隔为19至30天，那么几乎“保证”了生育能力。禁止的日子（第11天和第13天）提高了在第12天和第14天发生性行为的概率，即在周期为28天的情况下（精子在女性体内的寿命约为3天）的受孕概率。这些规定可以说是克努斯-奥吉诺法的积极应用。
