# 第35课

## 35.1. 第三类完成时：强干高/长音级

::: grammar-box
**构成：**

**强干：**
*   3.单.中：长音级
*   2.单.中：高干
*   1.单.中：可选高干或长音级

**弱干：** 见各子类型
:::
### 35.1.1. 第三类完成时a型：强干高/长音级，弱干低干

::: grammar-box
**构成：**

:::
::: indent
**弱干：** 低干
:::
由以下类型的词根构成：
*   (辅音)-(辅音) - i/ī/u/ū
*   (辅音) - ṛ

在元音开头的词尾前，替换为：
*   -i/-ī 变为 -iy
*   -u/-ū 变为 -uv
*   -ṛ 变为 r
例如：


| 词根 | 3.单.完成时.中 | 3.复.完成时.中 | 3.单.完成时.外 | 3.复.完成时.外 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2类 | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:br + iy + ur | | |
| ⟪नी⟫ 1类 | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2类 | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

### 35.1.2. 第三类完成时b型：强干高/长音级，弱干高干

::: grammar-box
**构成：**

:::
::: indent
**弱干：** 高干
:::
由以下类型的词根构成：
*   (辅音)-(辅音)-ṝ
*   辅音-辅音-ṛ（即：在多个辅音之后的 -ṛ 词根）
例如：


| 词根 | 3.单.完成时.中 | 3.复.完成时.中 | 3.单.完成时.外 | 3.复.完成时.外 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पॄ⟫ 3类 | ⟪पपार⟫ | ⟪पपरुर्⟫ | | |
| ⟪स्मृ⟫ 1类 | ⟪सस्मार⟫ | ⟪सस्मरुर्⟫ | | |
| ⟪संस्कृ⟫ 8类 | ⟪सञ्चस्कार⟫:brsam + ca-skār-a | ⟪सञ्चस्करुर्⟫ | ⟪सञ्चस्करे⟫ | ⟪सञ्चस्करिरे⟫ |

## 35.2. 第四类完成时：以 -ā / -āi 结尾的词根

::: grammar-box
**构成：**

**强干：**
*   第三人称/第一人称单数主动语态完成时以 -au 结尾
*   第二人称单数主动语态：高变格 -ā 或低变格 -i

**弱干：**
*   辅音前：低变格 -i
*   元音前：低变格 Ø

由以 -ā / -āi 结尾的词根构成
:::
示例：


| 词根 | 第三人称单数主动语态完成时：第一人称单数主动语态完成时 | 第三人称复数主动语态完成时 | 第三人称单数中动语态完成时 | 第三人称复数中动语态完成时 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪दा⟫ 第三变格 | ⟪ददौ⟫ | ⟪ददुर्⟫:brda-d-ur | ⟪ददे⟫ | ⟪ददिरे⟫:brda-d-i-re |

## 35.3. 第五类完成时：辅音-a-辅音结构的词根

::: grammar-box
**构成：**

**强干：**
*   第三人称单数主动语态：延长变格
*   第二人称单数主动语态：高变格
*   第一人称单数主动语态：可选高变格或延长变格

**弱干：** 见子类型

由 (辅音)-辅音-a-辅音类型的词根构成
:::
### 35.3.1. 第五类完成时 Va：弱干低变格

::: grammar-box
**构成：**

:::
::: indent
**弱干：** 低变格
:::
由以下词根等构成：
*   ⟪गम्⟫
*   ⟪हन्⟫
*   ⟪जन्⟫
*   ⟪वच्⟫
*   ⟪वद्⟫
*   ⟪यज्⟫
示例：


| 词根 | 第三人称单数主动语态完成时 | 第三人称复数主动语态完成时 | 第三人称单数中动语态完成时 | 第三人称复数中动语态完成时 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪गम्⟫ 第一变格 | ⟪जगाम⟫ | ⟪जग्मुर्⟫:brja-gm-ur | | |
| ⟪हन्⟫ 第二变格 | :sig[⟪जघान⟫] :brja-**ghān**-a | :sig[⟪जघ्नुर्⟫] | | |
| ⟪जन्⟫ 第四中动语态 | | | ⟪जज्ञे⟫:brja-jñ-e | ⟪जज्ञिरे⟫ |
| ⟪वच्⟫ 第二变格 | ⟪उवाच⟫ | ⟪ऊचुर्⟫:bru + uc-ur | | |
| ⟪वद्⟫ 第一变格 | ⟪उवाद⟫ | ⟪ऊदुर्⟫ | ⟪ऊदे⟫ | ⟪ऊदिरे⟫ |
| ⟪यज्⟫ 第三变格 | ⟪इयाज⟫ | ⟪ईजुर्⟫:bri + ij-ur | ⟪ईजे⟫ | ⟪ईजिरे⟫ |

### 35.3.2. 完成时类型 Vb：弱词干收缩（e-型）

::: grammar-box
**构成：**

:::
::: indent
**弱词干：** 无重音。将词根中的 -a- 替换为 -e-  
（解释参见 Thumb-Hauschild 1,2 第 286-287 页）
:::
由在两个简单辅音之间带有 -a- 的词根构成，其首辅音在重音节中不发生变化（即其首辅音不是软腭音、送气音或 h）。
示例：

| 词根 | 3. sg. 完成时主动态 | 3. pl. 完成时主动态 | 3. sg. 完成时中动态 | 3. pl. 完成时中动态 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 第一类动词 | ⟪पपाच⟫ | :sig[⟪पे⟫]⟪चुर्⟫ | :sig[⟪पे⟫]⟪चे⟫ | :sig[⟪पे⟫]⟪चिरे⟫ |

### 35.3.3. 完成时类型 Vc：辅音-a-辅音词根。弱词干强级

::: grammar-box
**构成：**

**弱词干：** 强级（Guṇa）

由所有其他中间带有 -a- 的词根构成，即中间带有 -a-
*   以两个辅音开头的词根
*   以软腭音开头的词根
*   以送气音开头的词根
*   以 h 开头的词根

只要它们不属于完成时类型 Va。
:::
示例：

| 词根 | 3. sg. 完成时主动态 | 3. pl. 完成时主动态 | 3. sg. 完成时中动态 | 3. pl. 完成时中动态 |
| :--- | :--- | :--- | :--- | :--- |
| ⟪क्रम्⟫ 第一类动词 | ⟪चक्राम⟫ | ⟪चक्रमुर्⟫ | ⟪चक्रमे⟫ | ⟪चक्रमिरे⟫ |
