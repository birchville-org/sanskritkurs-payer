# 第14课

## 14.1. 由名词所表示之关系的表达：属格（ṣaṣṭhī f. = ⟪षष्टी⟫ = 第六格词尾）

::: grammar-box
若要表达由两个名词所指示内容之间的关系，则使用属格（ṣaṣṭhī f. “第六格词尾”）。属格区别于其他所有格之处在于：它——除少数例外之外——并不用于进一步限定由动词所表示的动作，而是用于表达由名词所指代的人或事物之间的关系。属格常用于回答以下问题：谁的？
:::
示例：

⟪कवेः पुत्रः⟫ “诗人的儿子”

⟪धनस्य लोभः⟫ “对财富的渴望”

⟪नगरस्यार्धम्⟫ “城市的一半”

⟪रामस्य कृतम्⟫ “罗摩的/某项行为”

::: grammar-box
> 正常的语序为：

> **属格中的限定词 — 其他格中受限定的名词**
:::
> **属格与过去分词（PPP）：**

::: grammar-box
> 在过去分词（PPP）中，属格可替代工具格（tṛtīyā）来表示施事者（kartṛ）；在工具格结构中，过去分词被视为被动动词形式（处于工具格位置的成分表示施事者）；在属格结构中，过去分词被视为名词或形容词（因此处于属格位置的成分并不真正作为施事者）。

> 根据波你尼（Pāṇini）2.3.67，当过去分词具有现在时意义时（见上文），使用属格；当过去分词具有过去时意义时，使用工具格：

> ⟪रामस्येष्टं फलम्⟫ “罗摩所渴望的果实 = 罗摩此刻所渴望的果实”
> 
> ⟪रामेणेष्टं फलम्⟫ “罗摩所渴望的果实”

当然，当作为动词抽象名词（即作为名词）使用的PPP中性单数时，使用属格。
:::
## 14.2. 属格形式（ṣaṣṭhī f. = ⟪षष्ठी⟫）的构成

对于具有词干变格的动词词干，属格由弱词干构成。

**辅音结尾词干的属格：**

::: grammar-box

辅音后的规则属格词尾为：
* 单数：**-as**
* 复数：**-ām**

:::
::: center

| 名词词干 | 弱词干 | 属格单数 | 属格复数 |
| :--- | :--- | :--- | :--- |
| **guṇa-vant-** :br ⟪गुणवन्त्⟫ | **guṇa-vat-** :br ⟪गुणवत्⟫ | **guṇa-vat-as** :br ⟪गुणवतस्⟫ | **guṇa-vat-ām** :br ⟪गुणवताम्⟫ |
| **paśu-mant-** :br ⟪पशुमन्त्⟫ | **paśu-mat-** :br ⟪पशुमत्⟫ | **paśu-mat-as** :br ⟪पशुमतस्⟫ | **paśu-mat-ām** :br ⟪पशुमताम्⟫ |

:::
**元音结尾词干的属格，除单音节根名词和双元音结尾的词干外：**

**复数：**

::: grammar-box

元音结尾词干的属格复数构成如下：

> **-长元音的词干结尾 + -nām**

:::
::: center

| 名词词干 | 属格复数 |
| :--- | :--- |
| **deva** m.:br ⟪देव⟫ | **devā-nām** :br ⟪देवानाम्⟫ |
| **phala** n.:br ⟪फल⟫ | **phalā-nām** :br ⟪फलानाम्⟫ |
| **devatā** f.:br ⟪देवता⟫ | **devatā-nām** :br ⟪देवतानाम्⟫ |
| **kavi** m.:br ⟪कवि⟫ | **kavī-nām** :br ⟪कवीनाम्⟫ |
| **śruti** f.:br ⟪श्रुति⟫ | **śrutī-nām** :br ⟪श्रुतीनाम्⟫ |
| **devī** f.:br ⟪देवी⟫ | **devī-nām** :br ⟪देवीनाम्⟫ |
| **paśu** m.:br ⟪पशु⟫ | **paśū-nām** :br ⟪पशूनाम्⟫ |
| **dhenu** f.:br ⟪धेनु⟫ | **dhenū-nām** :br ⟪धेनूनाम्⟫ |

:::
**以元音结尾的词干的单数属格：**

::: grammar-box

以元音结尾的词干的单数属格是不规则变化的，需要熟记。

:::
::: center

| 词干 | 单数属格 |
| :--- | :--- |
| **deva** m.:br ⟪देव⟫ | **devasya** :br ⟪देवस्य⟫ |
| **phala** n.:br ⟪फल⟫ | **phalasya** :br ⟪फलस्य⟫ |
| **devatā** f.:br ⟪देवता⟫ | **devatāyās** :br ⟪देवतायास्⟫ |
| **kavi** m.:br ⟪कवि⟫ | **kaves** :br ⟪कवेस्⟫ |
| **paśu** m.:br ⟪पशु⟫ | **paśos** :br ⟪पशोस्⟫ |
| **devī** f.:br ⟪देवी⟫ | **devyās** :br ⟪देव्यास्⟫ |
| **śruti** f.:br ⟪श्रुति⟫ | **śrutes / śrutyās** :br **⟪श्रुतेस्⟫ / ⟪श्रुत्यास्⟫** :br(即：要么像 kavi，要么像 devī) |
| **dhenu** f.:br ⟪धेनु⟫ | **dhenos / dhenvās** :br **⟪धेनोस्⟫ / ⟪धेन्वास्⟫** :br(即：要么像 paśu，要么像多音节阴性以 -ū 结尾的词) |

:::
**疑问代词和指示代词：**

::: center

| | | kim | tad | etad | idam |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **阳性 / 中性** | **单数属格** | kasya:br ⟪कस्य⟫ | tasya:br ⟪तस्य⟫ | etasya:br ⟪एतस्य⟫ | asya:br ⟪अस्य⟫ |
| | **复数属格** | keṣām:br ⟪केषाम्⟫ | teṣām:br ⟪तेषाम्⟫ | eteṣām:br ⟪एतेषाम्⟫ | eṣām:br ⟪एषाम्⟫ |
| **阴性** | **单数属格** | kasyās:br ⟪कस्यास्⟫ | tasyās:br ⟪तस्यास्⟫ | etasyās:br ⟪एतस्यास्⟫ | asyās:br ⟪अस्यास्⟫ |
| | **复数属格** | kāsām:br ⟪कासाम्⟫ | tāsām:br ⟪तासाम्⟫ | etāsām:br ⟪एतासाम्⟫ | āsām:br ⟪आसाम्⟫ |

:::
**形式相同：**

::: important

除阳性与中性以 -a 结尾的名词词干以及代词外，所有名词词干的单数属格形式与单数离格（pañcamī“第五格尾”）形式相同！

请注意，在以辅音结尾的词干中，离格和属格的单数形式与宾格的复数（阳性及阴性）相同！

:::
## 14.3. 关于属格用法的补充（⟪षष्ठी⟫）

::: grammar-box
与上述基本规则相反，属格用于表达某些动词的宾语，例如表示“纪念”或“想起”的动词：

> ⟪देवानां स्मरति⟫ “他想起诸神”

然而，所有这些动词的宾语也可以以宾格形式出现：

> ⟪देवान्स्मरति⟫ “他想起诸神”

更多内容稍后介绍。
:::
