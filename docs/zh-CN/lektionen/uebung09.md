# 第9课

A) 请尝试确定以下词语的可能含义：

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. 仅类似于婆罗门者 = 劣等婆罗门

2\. mati ⟪मति⟫ : f. 意见

3\. śravaṇa ⟪श्रवण⟫ : n. 耳朵

4\. dhenuka ⟪धेनुक⟫ : m. （性交）如母牛般

5\. jayaka ⟪जयक⟫ : 3 胜利者

6\. rakṣikā ⟪रक्षिका⟫ : f. 守护者，护身符

7\. karṣaka ⟪कर्षक⟫ : 3 耕种者；m. 农民

8\. kleśa ⟪क्लेश⟫ : m. 痛苦

9\. nāyikātva ⟪नायिकात्व⟫ : n. 情妇的状态

10\. tantraka ⟪तन्त्रक⟫ : 3 （刚刚）从经线/织机而来 = 新织成

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : 舞者

12\. naraka ⟪नरक⟫ : m. 地狱

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. 主宰状态

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. 战士

17\. kopa ⟪कोप⟫ : m. 愤怒

18\. veśaka ⟪वेशक⟫ : 3 进入者

19\. darśaka ⟪दर्शक⟫ : 3 观看者

20\. kopaka ⟪कोपक⟫ : 3 易怒者，脾气暴躁者

B) 请翻译：

1\. 所有再生族（Dvijāti）的共同职责：

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

（《耶若伏吉亚法论》I, 118）

祭祀，吠陀学习，布施。

2\. 婆罗门的特定职责：

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

（《高塔玛法经》X,2）

教导，代他人祭祀，接受布施。

3\. 刹帝利的特定职责：

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं⟫ ⟪सर्वभूतानाम्⟫

（sarvabhūtānām = 属格（所有格）：“所有众生”）

（《高塔玛法经》X,7）

守护所有众生。

4\. 吠舍的特定职责：

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

（据《高塔玛法经》X,49）

农业，商业，畜牧业和放贷。

5\. 首陀罗的职责：

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं⟫ ⟪शुश्रूषा⟫ ⟪वार्त्त्ता⟫ ⟪कारुकुशीलवकर्म⟫ ⟪च⟫

（据《政事论》1.3.8。）

解释：
dvijātīnām = 属格（所有格）复数，源自动词 dvijāti（此处译为：“相对于再生族”）

kārukuśīlavakarma 是一个有财复合词（Tatpuruṣa），其前成分为一个并列复合词（Dvandva，即 kārukuśīlava）。karma = karman n. “行为、活动、业”的单数主格，源自词根 kṛ 8 U）。请翻译“……（由并列复合词所指代者）的行为/活动”（属格）。

服从再生族，谋生活动，工匠或流浪艺人的职业。

6\. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः⟫ ⟪पाशुपाल्यं⟫ ⟪वणिज्या⟫ ⟪च⟫ ⟪वार्त्ता⟫

（据《政事论》1.4.1。）

经济包括农业、畜牧业和商业。
