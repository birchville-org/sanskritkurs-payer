# 第22课

## 22.1. 绝对分词（⟪क्त्वा । ल्यप्⟫）

::: grammar-box

若要在梵语中表达施事者（⟪कर्तृ⟫）的某一动作先于其另一动作发生，或与其作为伴随状况同时发生，则使用绝对分词（⟪क्त्वा । ल्यप्⟫）。即

“在他做了那件事之后，他做这件事”；“他先做这个，然后做那个”；“由于这个原因，他做了那个”；“我来了，看见了，战胜了”等。

绝对分词是一种动词副词，即它既不能变位也不能变格，但它总是——除少数例外情况外——具有与它所表示的动作先于其发生或伴随发生的动作相同的施事者（⟪कर्तृ⟫）。因此，绝对分词的施事者处于主格（⟪प्रथमा⟫）或工具格（⟪तृतीया⟫）。

除了复合词之外，绝对分词是梵语中最常见的表达手段之一。

在翻译成德语时，应避免不断使用“nachdem”（在……之后）。应改用德语中常用的表示时间顺序的表达方式。

**模式：**

（对绝对分词的进一步限定：状语、宾语等）- 绝对分词 - 绝对分词 - ... - 绝对分词 - ... 施事者 + 动词句（主动或被动）

:::
**示例：**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = 被动结构：**⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**
“男子走进房屋，看见小女孩并与之交谈。”

复数：**⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. 绝对分词（Absolutivum）的构成

::: grammar-box
**绝对分词（Absolutivum）的构成**

*   无前缀动词：绝对分词以 **-tvā** 结尾
*   有前缀动词：绝对分词以 **-ya** 或 **-tya** 结尾
:::
### 22.2.1. 无前缀动词：以 -⟪त्वा⟫ 结尾的绝对分词

::: grammar-box

**构成规则：**

（通常）为强干（PPP之前出现的形态）的弱级词根 + **-tvā** （**-⟪त्वा⟫**）

仅否定前缀 **a-** / **an-** 可与后缀 **-⟪त्वा⟫** 结合： ⟪अकृत्वा⟫ “在未曾做……之后”

:::
**示例：**

::: indent
⟪आप्त्वा⟫ “在达到之后”（他/她/它/我/你/我们/你们/他们/我们俩/你们俩/他们俩 已经/曾经达到）

⟪आसित्वा⟫ “在坐过之后”（他/她/它 已经/曾经坐着）

⟪इत्वा⟫ “在走过之后”（他/她/它 已经/曾经行走）

⟪स्थित्वा⟫ “在站过之后”（他/她/它 已经/曾经站立）

⟪जित्वा⟫ “在战胜之后”（他/她/它 已经/曾经获胜）

⟪उक्त्वा⟫ “在说过之后”（他/她/它 已经/曾经说话）
:::
### 22.2.2. 有前缀动词

#### 22.2.2.1. 以长元音（除 -ā 外）或辅音结尾的词根

::: grammar-box

**（通常）弱级词根 + -ya**

:::
**示例：**

::: indent
⟪उपनीय⟫ “在带来之后”（他/她/它 已经/曾经带来）

⟪प्रभूय⟫ “在突出之后”（他/她/它 已经/曾经突出）；“在拥有权力之后”

⟪प्राप्य⟫ “在获得之后”（他/她/它 已经/曾经获得）
:::
#### 22.2.2.2. 以 -ā 结尾的词根

::: grammar-box

**保持强级形态不变的词根 + -ya**

:::
**示例：**

::: indent
⟪उपस्थाय⟫ “在踏入之后”（他/她/它 已经/曾经踏入）；（但无前缀形式为： ⟪स्थित्वा⟫）
:::
#### 22.2.2.3. 在弱级中以短元音 -i, -u, -ṛ 结尾的词根

::: grammar-box

**低阶词根 + -tya**

:::
**示例：**

::: indent
⟪प्रस्तुत्य⟫ “在（……）高声赞美之后”

⟪विस्मृत्य⟫ “在（……）遗忘之后”

⟪संस्कृत्य⟫ “在（……）为祭祀准备之后”
:::
#### 22.2.2.4. 以-am/-an结尾且在低阶形式中以-a结尾的词根

::: grammar-box

**可选：**

以**-am** / **-an**结尾的词根 + **-ya**

或者：

以**-a**结尾的词根 + **-tya**

:::
**示例：**

::: indent
⟪विगम्य⟫ 或 ⟪विगत्य⟫ “在（……）过去/经过之后”
:::
