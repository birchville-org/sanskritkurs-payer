# 第2课


## 2.1. 名词句

::: grammar-box
**模式：谓语名词 - 主语**

例如，devo viṣṇuḥ = ⟪देवो विष्णुः⟫ = “毗湿奴是一位神。”
:::
动词系词（“是”、“都是”、“我是”、“你是”、“你们是”）并非必需，但有时会出现。

Sanskrit中**没有冠词**：**devaḥ** -- ⟪देवः⟫ 可以表示“这位神”或“一位神”。

尽管在 Sanskrit 中语序相当自由（尤其在诗中），但在翻译名词句时，必须首先考虑根据上述标准模式进行的翻译。

在名词句中，主语处于主格（第一格 = **prathamā** f. = ⟪प्रथमा⟫）。谓语名词与主语在数和格上保持一致；如果谓语名词是形容词，则在性上也保持一致。


## 2.2. 关于变格（名词的屈折变化）

Sanskrit中有：

**三种数**（数量形式）= **vacana** n. -- ⟪वचन⟫
单数 = **ekavacana** n. -- ⟪एकवचन⟫
双数 = **dvivacana** n. -- ⟪द्विवचन⟫
复数 = **bahuvacana** n. -- ⟪बहुवचन⟫
**三种性**（语法性别）= **liṅga** n. / **vyakti** f. -- ⟪लिङ्ग⟫ / ⟪व्यक्ति⟫
阳性 = **puṃs** m. -- ⟪पुंस्⟫
阴性 = **strī** f. -- ⟪स्त्री⟫
中性 = **napuṃsaka** n. -- ⟪नपुंसक⟫
**八个格**（格位）= **sup** -- ⟪सुप्⟫（= 格词尾）

变格时，格词尾（**sup** = ⟪सुप्⟫）加在所谓的**名词词干**（不带格词尾的名词形式）上。

示例：**devas** = ⟪देवस्⟫（主格单数阳性）“神/一位神” = **deva-** -- ⟪देव⟫-（名词词干） + **-s** -- -⟪स्⟫（格词尾）。

在梵语词典中，名词以**名词词干**形式列出：
**deva** m. -- ⟪देव⟩ m.（阳性）
**vacana** n. -- ⟪वचन⟩ n.（中性）
**vyakti** f. -- ⟪व्यक्ति⟩ f.（阴性）


## 2.3. 主格单数

**主格单数 = prathamā ekavacanam = ⟪प्रथमा एकवचनम्⟫**

::: grammar-box
**主格单数以 -s 结尾 = -⟪स्⟫，或者无词尾。**
:::
### 2.3.1. 以 -s 结尾的主格单数

以下以元音结尾的名词词干，其主格单数以 **-s** 构成：

::: grammar-box
**以 -a 结尾的阳性名词：** 例如 deva m. = ⟪देव⟫ “神” -- 主格单数：devas = ⟪देवस्⟫
**以 -i 结尾的阳性名词：** 例如 kavi m. = ⟪कवि⟫ “诗人” -- 主格单数：kavis = ⟪कविस्⟫
**以 -u 结尾的阳性名词：** 例如 guru m. = ⟪गुरु⟫ “老师” -- 主格单数：gurus = ⟪गुरुस्⟫
:::

## 2.4. 连音 -- ⟪सन्धि⟫

在梵语中，一个词的词尾也受其后接词语的词首影响。这种现象称为**Sandhi**（连音，阳性）= ⟪सन्धि⟫（“连接”）。

### 2.4.1. 词尾 -s 的连音

另见概述：

> **Payer, Alois (1944–):** 词尾 -s 的连音。 -- （梵语材料）。-- URL: http://www.payer.de/sanskritmaterialien/ssandhi.htm

词尾的 **-s**：

**在绝对词尾位置**（句末）变为 **Visarga (-ḥ)**：
**devas** = ⟪देवस्⟫ » **devaḥ** = ⟪देवः⟫
**kavis** = ⟪कविस्⟫ » **kaviḥ** = ⟪कविः⟫
**gurus** = ⟪गुरुस्⟫ » **guruḥ** = ⟪गुरुः⟫

**在清辅音前**：
在 **k, kh, p, ph** 和 **ś, ṣ, s** 前：变为 **Visarga (-ḥ)**
**devas + śivaḥ** » **devaḥ śivaḥ** = ⟪देवः शिवः⟫ (“Śiva 是一位神”)
在 **c, ch** 前：变为 **-ś**
在 **ṭ, ṭh** 前：变为 **-ṣ**
在 **t, th** 前：保持 **-s**
**sādhus + caitanyas** » **sādhuś caitanyaḥ** = ⟪साधुश्चैतन्यः⟫ (“Caitanya 是一位圣人”)

**在浊辅音前**：
在非 a 元音后：变为 **-r**
**kavis + Māghas** » **kavir māghaḥ** = ⟪कविर्माघः⟫ (“Māgha 是一位诗人”)
在非 a 元音后且在 **r-** 前：**-s** 脱落，元音拉长。
**gurus + rāmas** » **gurū rāmaḥ** = ⟪गुरू रामः⟫ (“Rāma 是一位老师”)
在 **a-** 后：**-as**
在浊辅音/a 前：变为 **-o**（词首 a 脱落 » ⟪ऽ⟫）
**devas viṣṇus** » **devo viṣṇuḥ** = ⟪देवो विष्णुः⟫
**devas agnis** » **devo 'gniḥ** = ⟪देवो ऽग्निः⟫
在其他元音前：变为 **-a**（Hiatus，即元音连读）
**devas + indras** » **deva indraḥ** = ⟪देव इन्द्रः⟫

**标注：**

这三个阶层身着各自的等级服饰。在其上——由此被称为神意所定——的种姓之上，基督端坐王座。

马克斯·韦伯（1864–1920）如此定义“Stand”（等级/阶层）：

::: note-box
»**等级**« 应指一群人在一个共同体内有效
a) 享有等级特有的特殊评价，——可能因此也包括
b) 主张等级的特殊垄断权。

种姓可以产生
a) 原初地，通过自身种姓式的生活方式，尤其是通过**职业**的方式（生活方式或职业种姓），
b) 次生地，世袭魅力型，通过凭借种姓**出身**的成功声望主张（出生种姓），
c) 通过种姓对政治或神权统治权力的**占有**作为垄断（政治或神权种姓）。

出生种姓的发展通常是特权对某个团体或有资格的个人的（世袭）占有的常规形式。任何对机会的固定占有，特别是对[主人][权力或谋生]机会的占有，倾向于导致种姓的形成。任何种姓的形成都倾向于导致对主人权力和谋生机会的垄断性占有。

当职业阶级在面向市场的经济基础上成长时，种姓则更倾向于在垄断性利他主义、封建或种姓式家产制的团体需求满足基础上产生和存在。

如果社会划分主要依据种姓，则称该社会为»**种姓式**»；如果主要依据阶级划分，则称为»**阶级化**»。在“阶级”中，“社会”阶级最接近“种姓”，而“职业”阶级则相距最远。种姓往往由其重心通过占有阶级构成。

任何种姓社会都是惯例性的，由生活方式的规则所规范，因此在经济上创造了非理性的消费条件，并通过垄断性占有和排除对个人谋生能力的自由支配，阻碍了自由市场的形成。

[**韦伯，马克斯（1864–1920）：**《经济与社会的社会学基础：理解性社会学纲要》。——第5版，修订版。——蒂宾根：莫尔出版社，1976年。——第625页及以下。]
:::

## 2.6. 练习

**A) 注意连音（Sandhi）并填入，构成名词句：**

1. **devas ... (Śiva, Agni, Viṣṇu, Gaṇeśa, Kṛṣṇa, Indra)**
= ⟪देवस्⟫ ... (⟪शिव⟫, ⟪अग्नि⟫, ⟪विष्णु⟫, ⟪गणेश⟫, ⟪कृष्ण⟫, ⟪इन्द्र⟫)
2. **dvijas ... (brāhmaṇa, kṣatriya, vaiśya)**
= ⟪द्विजस्⟫ ... (⟪ब्राह्मण⟫, ⟪क्षत्रिय⟫, ⟪वैश्य⟫)
3. **gurus ... (brāhmaṇa, Candrakīrti)**
= ⟪गुरुस्⟫ ... (⟪ब्राह्मण⟫, ⟪चन्द्रकीर्ति⟫)
4. **vaiśyas ... (Tulādhara)**
= ⟪वैश्यस्⟫ ... (⟪तुलाधर⟫)
5. **sādhus ... (guru, Rāma)**
= ⟪साधुस्⟫ ... (⟪गुरु⟫, ⟪राम⟫)
6. **kavis ... (Kālidāsa, Māgha, Bhāravi, Harṣadeva)**
= ⟪कविस्⟫ ... (⟪कालिदास⟫, ⟪माघ⟫, ⟪भारवि⟫, ⟪हर्षदेव⟫)

1. Rāma是婆罗门。

3. 首陀罗是神圣之人。
4. 诗人是老师。
5. Viṣṇu是主（HERR）。
6. 主是Śiva。
7. 再生族（Zweimalgeborene）是婆罗门。
8. 神圣之人是老师。
9. 老师是神圣之人。
