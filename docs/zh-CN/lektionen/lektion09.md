## 9.1. Samāhāradvandva（⟪समाहारद्वन्द्व⟫ = “总结性双数”）

::: grammar-box
**如果一个复合词意在表达一系列事物等构成一个整体，那么它通常以中性单数形式出现：**

例如，**āhāra-nidrā-maithuna-bhayam** = ⟪आहारनिद्रामैथुनभयम्⟫ 并不简单地意味着“摄取食物（**āhāra** 阳性）、睡眠（**nidrā** 阴性）、交配（**maithuna** 中性）和恐惧（**bhaya** 中性）”，而是指作为**整体**的这四项，它们构成了动物生命的特征。
:::
除了这个构成 Samāhāradvandvas（复合词）的基本规则外，还有另外一系列规则，可以在帕尼尼 2,4,2-17 或例如 Mr. R. Kale 的《高级梵文语法》（1969 年重印版）§ 189 - 192 a 中找到。在语言发展的不同阶段，并非总是遵守相同的规则！

## 9.2. 名词词干的构成

### 9.2.1. -ka (taddhita)

::: grammar-box
**taddhita后缀 -ka 主要构成：**

1\. **指小词（如德语中的 -chen, -lein, -li, -le 等缩小形式）：**
**putra m. “儿子” » putraka m. ⟪पुत्रक⟫ “小儿子”**

2\. **表示近似相似性的名词：**
**aśva m. “马” » aśvaka m. ⟪अश्वक⟫ “小马，类似马的东西”**

3\. **名词，其意义与基础名词无差异：**
   **putraka m. ⟪पुत्रक⟫ = putra m. ⟪पुत्र⟫**

4\. **表示“与词根概念相关”的名词：**
**kāśi f. "瓦拉纳西" » kāśika 3 ⟪काशिक⟫ "瓦拉纳西出生的，来自瓦拉纳西的"**
**rūpa n. "形态" » rūpaka 3 ⟪रूपक⟫ "拥有某物形态的"**
:::

### 9.2.2. -aka (kṛt)，阴性通常为 -ikā

::: grammar-box
**后缀 -aka（阴性常为 -ikā）用于构成动词名词（表示施事者的名词），适用于任何词根。**

词根末尾的元音以及词根倒数第二个位置的**-a-**会被其延长阶段（**vṛddhi**）所取代（存在一些例外），其余元音则会被其增强阶段（**guṇa**）所取代。
:::
**示例：**

| Wurzel:br⟪धातु⟫ | + -aka / -ikā (kṛt) | 含义 |
| :--- | :--- | :--- |
| **kṛ** :br8 U:br⟪कृ⟫:br"machen" | **kāraka** :br(⟪कारक⟫) | “使因者，制造者” |
| **śru** :br5 P:br⟪श्रु⟫:br"hören" | **śrāvaka** m.:br(⟪श्रावक⟫) | “听者，弟子,:br佛教：佛陀的追随者” |
| **nī** :br1 U:br⟪नी⟫:br"führen" | **nāyaka** m.:br(⟪नायक⟫) /:br **nāyikā** f.:br(⟪नायिका⟫) | “领袖，主人，丈夫,:br情人 / 爱人，女士” |
| **yaj** :br1 U:br⟪यज्⟫:br"opfern" | **yājaka** m.:br(⟪याजक⟫) | “祭祀者，祭司” |
| **nṛt** :br4 P:br⟪नृत्⟫:br"tanzen" | **nartaka** m.:br(⟪नर्तक⟫) /:br **nartakī** f.:br(⟪नर्तकी⟫) | “舞者 / 舞女” |
| **ji** :br1 P:br⟪जि⟫:br"siegen" | **jayaka** 3:br(⟪जयक⟫) | “胜利的” |

::: grammar-box
**这些构词中的一些具有更狭窄的含义：“以词根所表达的习惯性或义务性或良好地执行者”。**
:::
参见上文，例如 **śrāvaka**、**yājaka**、**jayaka**

**Beispiele:**

| Wurzel:br⟪धातु⟫ | + -aka (kṛt) | 含义 |
| :--- | :--- | :--- |
| **kṛṣ** :br6 U:br⟪कृष्⟫:br"pflügen" | **kṛṣaka** m.:br(⟪कृषक⟫) | “农夫”:br(弱级!) |
| **kliś** :br9 P:br⟪क्लिशु⟫:br"quälen" | **kleśaka** m.:br(⟪क्लेशक⟫) | “折磨者” |
| **khād** :br1 P:br⟪खाद्⟫:br"kauen, essen" | **khādaka** m.:br(⟪खादक⟫) | “食者，吃者” |

此外，后缀 **-aka** 还有一些不太重要的用法。参见 Wackernagel，《古印度语法》，第二卷，§45ff。

**B) 翻译：**

1. 所有再生者的职责：
   **ijyādhyayanadānāni**
   ⟪इज्याध्ययनदानानि⟫
   (《耶若伏吉法论》I, 118)

2. 婆罗门的具体职责：
   **pravacanayājanapratigrahāḥ**
   ⟪प्रवचनयाजनप्रतिग्रहाः⟫
   (《高塔玛法论》第十卷，第二章)

3. 刹帝利的特定职责：
   **rakṣaṇaṃ sarvabhūtānām**
   ⟪रक्षणं⟫ ⟪सर्वभूतानाम्⟫
   (sarvabhūtānām = 属格（所有格）：“所有众生”；《乔荼波尼法论》X, 7)

4. 吠舍的具体职责：
   **kṛṣivāṇijyapāśupālyakusīdam**
   ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫
   （据《高塔玛法论》第十卷第49条）

5. Śūdra的职责：
   **dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca.**
   ⟪द्विजातीनां⟫ ⟪शुश्रूषा⟫ ⟪वार्त्ता⟫ ⟪कारुकुशीलवकर्म⟫ ⟪च⟫
   （据《考底利耶政事论》1.3.8）
   释义：dvijātīnām = 复数属格（与格）dvijāti（此处译为：“相对于再生者”）；kārukuśīlavakarma 是一个前成分为复合词（kārukuśīlava）的持业释。karma = karman n. “行为、活动、业”（词根 kṛ 8 U）的单数主格。请翻译“……（由复合词所指代者）的行为/活动”（属格）。

6. **kṛṣiḥ pāśupālyaṃ vāṇijyā ca vārttā.**
   ⟪कृषिः⟫ ⟪पाशुपाल्यं⟫ ⟪वाणिज्या⟫ ⟪च⟫ ⟪वार्त्ता⟫ |
   （据《政事论》1.4.1。）
