# 第46课

## 46.1. 第二人称动词形式（⟪मध्यमः⟫）的构成：完成时态（⟪लिट्⟫）

### 46.1.1. 词尾

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :---: | :---: | :---: | :---: |
| **完成时态词尾** | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| ^^ \-tha | \-a | \-se | \-dhve |
:::
请注意，第二人称复数（2.pl.P）的词尾——通常并非其形式本身——与第一人称和第三人称单数（1. und 3.sg.P）的完成时态形式相同。

::: grammar-box
在大多数以 -ṛ 结尾的词根后，-tha 前不出现连接元音 \-i-。在某些词根中，\-tha 前的 \-i- 是可选的。
:::
### 46.1.2. 词尾 -dhve 的音变

::: grammar-box
如果词干中直接 preceding -u 或 -ṛ，则完成时态中的词尾 -dhve 必须替换为 -ḍhve。如果该元音前是半元音或 h，则这种替换可以选择在连接元音 -i- 之后进行。
:::
### 46.1.3. 完成时态类型 I：无词干级音变化

遵循此类型的动词包括：

*   辅音-长元音-辅音
*   辅音-短元音-辅音-辅音
*   a-辅音（-辅音）
*   ā-Konsonant

::: grammar-box
第一人称单数完成时态 = 第三人称单数完成时态 = 第二人称复数完成时态

### 46.1.9. 迂回完成时（⟪अनुप्रयोगलिट्⟫）

迂回完成时由以下成分构成：

*   派生动词词干（使役、欲求、反复、名词性派生），尤其是使役
*   以长元音（除 ā 外）开头的词根
*   词根：元音（除 a-）-辅音-辅音
*   其他一些情况
*   对于某些词根，两种完成时均可选择性地构成：uṣ “燃烧”，vid “知道”，jāgṛ “醒着”，daridrā “贫穷”
*   对于以下词根，两种完成时均可选择性地构成，且迂回完成时也带有重叠，具体使用现在词根的重叠音节：
*   bhī “害怕”
*   bhṛ “携带”
*   hu “祭祀”
*   hrī “羞愧”
