# 第17课

## 17.1. 第二现在时类（⟪अदादि⟫ = ⟪अद्⟫ 等）

动词词尾直接附加于词根。需注意由此产生的语音连音变化。

::: grammar-box

第二现在时类包含以下构成形式：

1. 具有词干变格的词根
*   大多数情况：强格 - 弱格
*   部分词根：长音格 - 弱格
2. 无词干变格的词根
3. 以 -i/-ī 结尾的双音节词根，具有词干变格

:::
## 17.2. 具有强格-弱格变格的第二现在时类词根

示例：

⟪द्विष्⟫ 第二类动词 “憎恶”

*   强现在时词干：dveṣ-
*   弱现在时词干：dviṣ-

::: no-header

| | |
| :--- | :--- |
| 第三人称单数现在时主动语态 | ⟪द्वेष्टि⟫ (dveṣ + -ti) |
| 第三人称复数现在时主动语态 | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 第三人称单数现在时中动语态 | ⟪द्विष्टे⟫ (dviṣ + -te) |
| 第三人称复数现在时中动语态 | ⟪द्विषते⟫ (dviṣ-ate) |

:::
此处适用以下语音连音规则：

::: grammar-box
ṣ 与 t(h)- 的语音连音

\-ṣ + t(h)- » -ṣṭ(h)-
:::
更多示例：

⟪इ⟫ 第二类动词 “去”（在某些前词后使用中动语态）

*   强现在时词干：e-
*   弱现在时词干：
*   在辅音前：i-
*   在元音前：y-/iy-

::: no-header

| | |
| :--- | :--- |
| 第三人称单数现在时主动语态 | ⟪एति⟫ (e-ti) |
| 第三人称复数现在时主动语态 | ⟪यन्ति⟫ (y-anti) |
| 第三人称单数现在时中动语态 | ⟪इते⟫ (i-te) |
| 第三人称复数现在时中动语态 | ⟪इयते⟫ (iy-ate) |

:::
⟪दुह्⟫ 第二类动词 “挤奶”

*   强现在时词干：doh-
*   弱现在时词干：duh-

::: no-header

| | |
| :--- | :--- |
| 第三人称单数现在时主动语态 | ⟪दोग्धि⟫ (doh- + -ti) |
| 第三人称复数现在时主动语态 | ⟪दुहन्ति⟫ (duh-anti) |
| 第三人称单数现在时中动语态 | ⟪दुग्धे⟫ (duh- + -te) |
| 第三人称复数现在时中动语态 | ⟪दुहते⟫ (duh-ate) |

:::
⟪हन्⟫ 第二人称 "打击，击打，杀死"

*   强式现在词干：han-
*   弱式现在词干：
*   在辅音前：ha-（即 \*hn-）
*   在元音前：ghn-/han-

::: no-header

| | |
| :--- | :--- |
| 第三人称单数现在主动态 | ⟪हन्ति⟫ (han-ti) |
| 第三人称复数现在主动态 | ⟪घ्नन्ति⟫ (ghn-anti) |
| 第三人称单数现在中动态 | ⟪हते⟫ (ha-te) |
| 第三人称复数现在中动态 | ⟪घ्नते⟫ (ghn-ate) |

:::
⟪अस्⟫ 第二人称 "是"

*   强式现在词干：as-
*   弱式现在词干：s-

::: no-header

| | |
| :--- | :--- |
| 第三人称单数现在主动态 | ⟪अस्ति⟫ (as-ti) |
| 第三人称复数现在主动态 | ⟪सन्ति⟫ (s-anti) |

:::
## 17.3. 第二现在类具有词干交替（长音级-弱音级）的词根

示例：

⟪स्तु⟫ 第二人称 "赞美"

*   强式现在词干：stau-
*   弱式现在词干：
*   在辅音前：stu-
*   在元音前：stuv-

::: no-header

| | |
| :--- | :--- |
| 第三人称单数现在主动态 | ⟪स्तौति⟫ (stau-ti)：broder: ⟪स्तवीति⟫ |
| 第三人称复数现在主动态 | ⟪स्तुवन्ति⟫ (stuv-anti) |
| 第三人称单数现在中动态 | ⟪स्तुते⟫ (stu-te) |
| 第三人称复数现在中动态 | ⟪स्तुवते⟫ (stuv-ate) |

:::
## 17.4. 第二现在类无词干交替的词根

::: grammar-box
第二现在类以 -ā 结尾的词根没有词干交替：
:::
示例：

⟪पा⟩ 第二人称 "保护，守护，照料"

::: no-header

| | |
| :--- | :--- |
| 第三人称单数现在主动态 | ⟪पाति⟫ (pā-ti) |
| 第三人称复数现在主动态 | ⟪पान्ति⟫（即 pā- + -anti） |

:::
第二类的其他一些词根也没有词干交替：

示例：

⟪अद्⟫ 第二人称 "吃"

::: no-header

| | |
| :--- | :--- |
| 第三人称单数现在主动态 | ⟪अत्ति⟫（即 ad- + -ti） |
| 第三人称复数现在主动态 | ⟪अदन्ति⟫ (ad-anti) |

:::
⟪आस्⟫ 2 Ā “坐”

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. Ā | ⟪आस्ते⟫ (ās-te) |
| 3\. pl. Präs. Ā | ⟪आसते⟫ (ās-ate) |

:::
⟪वच्⟫ 2 P “说”

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪वक्ति⟫ (« vac- + -ti) |
| 3\. pl. Präs. P | 不存在

:::
## 17.5. 带-i/-ī结尾的双音节词根及其元音强弱交替

若干词根在一系列形态中呈现双音节，即在辅音结尾前带有-i（或在某些结尾前为-ī）。尽管如此，本土语法学家及词典等仍将其视为单音节词根处理。

例如：

⟪रुद्⟫ 2 P “哭泣，嚎叫”

*   强式现在词干：rodi-
*   弱式现在词干：
*   在辅音前：rudi-
*   在元音前：rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U “说话”

*   强式现在词干：bravī- (« bro- + -ī)
*   弱式现在词干：
*   在辅音前：brū-
*   在元音前：bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
此外，⟪स्तु⟫ 2 U “赞美”除了第3项所列形式外，还具有遵循此模式的形式：

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::

⟪२⟫。⟪क्षत्रियो जनान्⟫ ...（⟪पा । रक्ष्⟫）
