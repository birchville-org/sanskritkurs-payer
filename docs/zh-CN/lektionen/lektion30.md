# Lektion 30

## 30.1. Die 9. Präsensklasse (⟪क्र्यादि⟫ = "⟪क्री⟫ u.s.w.")

::: grammar-box
**教育：**

*   starker Stamm: tiefstufige Wurzel + -nā-

*   弱词干：

*   辅音前：低降调词根 + -nī-

*   元音前：低降根 + -n-
:::
例：

::: indent
⟪क्री⟫ 9U “购买”
:::
::: grammar-box

| |单数：br⟪एकवचन⟫|复数：br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**第三人称：brParasmaipada**|⟪क्रीणाति⟫:br(krī + nā + ti)|⟪क्रीणन्ति⟫:br(krī + n + anti)|
|**第三人称：brĀtmanepada**|⟪क्रीणीते⟫:br(krī + nī + te)|⟪क्रीणते⟫:br(krī + n + ate)|

:::
对于此类现在时，需特别注意根据词根⟪ज्ञा⟫ 9U“知晓、认知”构成现在时词干：

::: grammar-box

| |单数：br⟪एकवचन⟫|复数：br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**第三人称：brParasmaipada**|⟪जानाति⟫:br(jā-nā-ti)|⟪जानन्ति⟫:br(jā-n-anti)|
|**第三人称：brĀtmanepada**|⟪जानीते⟫:br(jā-nī-te)|⟪जानते⟫:br(jā-n-ate)|

:::
⟪जा⟫ 这种形式，作为 ⟨ज्ञा⟩ 现在词根的基础，要么可以通过元音交替序列 -ā（低等级）-nā（高等级）来解释，要么可以通过从 *jñā-nā-ti 的同化来解释。

某些带长元音的词根在第九类动词现在时词干后缀前会缩短该元音：

例子：

::: indent
⟪पू⟫ 9U “reinigen”
:::
::: grammar-box

| |单数：br⟪एकवचन⟫|复数：br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**第三人称：brParasmaipada**|⟪पुनाति⟫:br(pu-nā-ti)|⟪पुनन्ति⟫:br(pu-n-anti)|
|**第三人称：brĀtmanepada**|⟪पुनीते⟫:br(pu-nī-te)|⟪पुनते⟫:br(pu-n-ate)|

:::
现在时主动语态分词的构成：

示例：

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant)；阴性：⟪क्रीणती⟫ (krī + n + at + ī)
:::
## 30.2. 愿 mood（⟪लिङ्⟫）的用法

祈愿语气（Optativ）的使用场景如下：

::: grammar-box
**1. 用于表示**

*   **一个愿望**
*   **一个请求**
*   **一个缓和的命令**

（在此，愿语气——⟪लिङ्⟫——与命令语气——⟪लोट्⟫——发生重叠）
:::
例如：

::: indent
⟪दासो⟫ ⟪ग्राममागच्छेत्⟫ = “佃农应来到村庄”
:::
::: grammar-box
**2. 如果某事作为**

*   **möglich**
*   **wahrscheinlich**
*   **vermutlich**

**dargestellt werden soll.**
:::
Beispiel:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं⟫ ⟪न⟫ ⟪शृणुयात्⟫ = “如果他离开村庄，他就听不到老师的话”
:::
::: grammar-box
**3. 带有祈愿语气的关系从句有时具有“如果有人……”的含义：**
:::
例如：

::: indent
⟪यो⟫ ⟪नृतं⟫ ⟪वदेत्स⟫ ⟪नरकं⟫ ⟪पतेत्⟫ = “如果有人会说谎，他就会堕入地狱 = 如果说谎，人就会堕入地狱”
:::
## 30.3. 第三人称单数和复数的次要词尾

optative（⟪लिङ्⟫）、imperfekt（⟪लङ्⟫）、aorist（⟪लुङ्⟫）、prekativ（⟪आशिर्लिङ्⟫）以及conditionalis具有所谓的secondary词尾：

::: grammar-box

| |第三人称单数|第三人称复数|
| :--- | :--- | :--- |
|**Parasmaipada**|**-t**|非词干类：**-an** 或 **-ur** :br optative：**-ur**|
|**Ātmanepada**|**-ta**|非词干类：**-ata**（来自 *nta）:br optative：**-ran**|

:::

## 30.5. Sandhi von auslautendem -r

::: grammar-box
**除了以-ar结尾的词外，以-r结尾的词遵循与以-s结尾的词相同的Sandhi规则。**

**-ar 在浊音前保持 -ar，但在 r- 前 -r 脱落，且 -a- 被 -ā- 取代。**
:::
示例：

::: indent
⟪⟪भवेयुर्⟫⟫ + ⟪⟪च⟫⟫ » ⟪⟪भवेयुश्च⟫⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
