# 第30课

## 30.1. 第九现在时类（⟪क्र्यादि⟫ = "⟪क्री⟫ 等"）

::: grammar-box
**构成：**

*   强词干：低等级根 + -nā-

*   弱词干：

*   在辅音前：低等级根 + -nī-

*   在元音前：低等级根 + -n-
:::
示例：

::: indent
⟪क्री⟫ 9U “购买”
:::
::: grammar-box

| |单数:br⟪एकवचन⟫|复数:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**第三人称:br外位语**|⟪क्रीणाति⟩:br(krī + nā + ti)|⟪क्रीणन्ति⟩:br(krī + n + anti)|
|**第三人称:br内位语**|⟪क्रीणीते⟩:br(krī + nī + te)|⟪क्रीणते⟩:br(krī + n + ate)|

:::
对于这一现在时类，特别需要注意的是由根 ⟪ज्ञा⟫ 9U “认识，知道”构成现在词干的方式：

::: grammar-box

| |单数:br⟪एकवचन⟩|复数:br⟪बहुवचन⟩|
| :--- | :--- | :--- |
|**第三人称:br外位语**|⟪जानाति⟩:br(jā-nā-ti)|⟪जानन्ति⟩:br(jā-n-anti)|
|**第三人称:br内位语**|⟪जानीते⟩:br(jā-nī-te)|⟪जानते⟩:br(jā-n-ate)|

:::
形式 ⟪जा⟩，其基于根 ⟪ज्ञा⟩ 的现在词干，可以通过元音交替序列 -ā（低等级）-nā（高等级）来解释，或者通过从 *jñā-nā-ti 发生同位异化而来。

一些以长元音结尾的根在第九类现在时词干后缀前会缩短该元音：

示例：

::: indent
⟪पू⟩ 9U “净化”
:::
::: grammar-box

| |单数:br⟪एकवचन⟩|复数:br⟪बहुवचन⟩|
| :--- | :--- | :--- |
|**第三人称:br外位语**|⟪पुनाति⟩:br(pu-nā-ti)|⟪पुनन्ति⟩:br(pu-n-anti)|
|**第三人称:br内位语**|⟪पुनीते⟩:br(pu-nī-te)|⟪पुनते⟩:br(pu-n-ate)|

:::
现在时主动态分词的形成：

示例：

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant)；阴性： ⟪क्रीणती⟫ (krī + n + at + ī)
:::
## 30.2. 虚拟式（⟪लिङ्⟫）的用法

虚拟式用于：

::: grammar-box
**1. 表示**

*   **愿望**
*   **请求**
*   **委婉的命令**

**（在此情况下，虚拟式 - ⟪लिङ्⟫ - 与祈使式 - ⟪लोट्⟫ - 有重叠）**
:::
示例：

::: indent
⟪दासो ग्राममागच्छेत्⟫ = “让奴隶来到村庄”
:::
::: grammar-box
**2. 当某事被呈现为**

*   **可能的**
*   **大概的**
*   **推测的**

**时。**
:::
示例：

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं न शृणुयात्⟫ = “如果他离开村庄，他就听不到主人”
:::
::: grammar-box
**3. 带有虚拟式的定语从句有时具有“如果有人……”的含义**
:::
示例：

::: indent
⟪यो नृतं वदेत्स नरकं पतेत्⟫ = “如果有人会说谎，他就会下地狱” = 如果有人说谎，他就会下地狱
:::
## 30.3. 第三人称单数和复数的次要词尾

虚拟式（⟪लिङ्⟫）、过去时（⟪लङ्⟫）、不定过去时（⟪लुङ्⟫）、祈愿式（⟪आशिर्लिङ्⟫）和条件式具有所谓的次要词尾：

::: grammar-box

| |第三人称单数|第三人称复数|
| :--- | :--- | :--- |
|**主动态**|**-t**|无词干变化类：**-an** 或 **-ur** :br虚拟式：**-ur**|
|**中动态**|**-ta**|无词干变化类：**-ata**（源自 *nta）:br虚拟式：**-ran**|

:::

## 30.5. 词尾 -r 的连音变化

::: grammar-box
**除 -ar 外，词尾 -r 适用与词尾 -s 相同的连音规则。**

**-ar 在浊辅音前保持为 -ar，但在 r- 前则脱落 -r，且其中的 -a- 替换为 -ā-。**
:::
示例：

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना रोदिति⟫
:::

⟪जना आर्यसत्यानि जानीयुरिति सुगतेनार्याणां सुखाय जना धर्मं ज्ञाप्यन्ते ॥१॥ ये नरा देवान्न यजेरन्व्रतानि च न चरेयुरनृतं च वदेयुरधर्मं च कुर्युस्ते सुखं नाप्नुयुर्मृत्वा च नरकं पतेयुः ॥२॥ ज्ञातिरागच्छेतितीष्ट्वार्यपुत्रो ज्ञातिं दासमाययति ॥३॥ अन्नलोभाद्दुःखं जायेतेति प्राप्तज्ञानः सुफलानि नाश्नाति ॥४॥ क्रयेण च विक्रयेण च वैश्या जीवेयुरिति वैश्यधर्मः । एवं सति वैश्यपुत्राः क्रीणन्ति विक्रीणते च ॥५॥ कृतपापो नरश्चेन्नरके पापात्पूतः स्यात्पुनर्भवं गच्छेत् ॥६॥ ब्राह्मणपुत्रा वेदाध्यायांश्च स्मृत्यध्यायांश्च पुनः पुनरधीयीरन्नित्यार्यधर्मः ॥७॥ यो ब्राह्मणः शूद्रां कामयेत स सद्ब्राह्मणो न स्यात् । सद्ब्राह्मणो हि ब्राह्मणीं कामयेत ॥८॥ सत्यं ब्रूयात्प्रियं ब्रूयान्न ब्रूयात्सत्यमप्रियम् । प्रियं च नानृतं ब्रूयादेष धर्मः सनातनः ॥९॥ ॥मनुस्मृति ४⟫.⟪१३८॥⟫
