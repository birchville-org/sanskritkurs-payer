开头先讲一个奇闻：


>“当威廉·琼斯（1746–1794）和亨利·托马斯·科尔布鲁克（1765—1857）首次对梵语进行彻底研究、部分翻译，并发现它拥有丰富的文学以及与古典语言有着不小的亲缘关系时，他们遭遇了相当大的阻力。由于梵语与地理上如此遥远的欧洲语言之间这种密切的关系，无法调和那些要么将所有语言都归源于希伯来语、要么认为它们彼此完全隔离的旧有观念，因此著名的哲学家杜格尔德·斯图尔特（1753—1828）采取了最简单的解决办法，他将整个梵语历史斥为谎言。他撰写了一篇论文，试图证明这是由狡诈的婆罗门按照希腊语和拉丁语的模子伪造出来的，无论是语言还是文学都是赝品。都柏林的教授查尔斯·威廉·沃尔（Charles William Wall）在1840年仍广泛阐述了这一观点（《哥廷根学术通报》1842年第1888页）。”
>

## 1.2. 梵语的语音

根据传统印度分类法及科学转写系统呈现的梵语语音。

::: media
![](/images/lekt0106.webp)
（图片来源：[详情](/zh-CN/licenses#lekt0106)）
:::
现代梵语词典均按照此分类顺序编排。该分类对于理解梵语语法至关重要，因此必须熟记于心：

::: note-box
分类法
**单元音** (samānākṣara -- ⟪समानाक्षर⟫):
⟪अ⟫ a, ⟪आ⟫ ā, ⟪इ⟫ i, ⟪ई⟫ ī, ⟪उ⟫ u, ⟪ऊ⟫ ū, ⟪ऋ⟫ ṛ, ⟪ॠ⟫ ṝ, ⟪ऌ⟫ ḷ
**双元音** (sandhyakṣara -- ⟪सन्ध्यक्षर⟫):
⟪ए⟫ e, ⟪ऐ⟫ ai, ⟪ओ⟫ o, ⟪औ⟫ au
**辅音** (vyañjana / hal -- ⟪व्यञ्जन⟫ / ⟪हल्⟫):
⟪क⟫ ka, ⟪ख⟫ kha, ⟪ग⟫ ga, ⟪घ⟫ gha, ⟪ङ⟫ ṅa
⟪च⟫ ca, ⟪छ⟫ cha, ⟪ज⟫ ja, ⟪झ⟫ jha, ⟪ञ⟫ ña
⟪ट⟫ ṭa, ⟪ठ⟫ ṭha, ⟪ड⟫ ḍa, ⟪ढ⟫ ḍha, ⟪ण⟫ ṇa
⟪त⟫ ta, ⟪थ⟫ tha, ⟪द⟫ da, ⟪ध⟫ dha, ⟪न⟫ na
⟪प⟫ pa, ⟪फ⟫ pha, ⟪ब⟫ ba, ⟪भ⟫ bha, ⟪म⟫ ma
⟪य⟫ ya, ⟪र⟫ ra, ⟪ल⟫ la, ⟪व⟫ va
⟪श⟫ śa, ⟪ष⟫ ṣa, ⟪स⟫ sa
⟪ह⟫ ha
:::
### 1.2.1. 关于个别音素的发音

::: laut-table
| 音素 | 描述 |
| :--- | :--- |
| **a - ⟪अ⟫** | “短音 a”在印度人那里——自古至今——常被发为 ə。在欧洲，人们将其发为短音 a；在孟加拉地区，则发为短而暗的 o。 |
| **ṛ - ⟪ऋ⟫** | 类似捷克语中元音化的 r。带有轻微的 i 尾韵。 |
| **ṝ - ⟪ॠ⟫** | 类似捷克语中元音化的 r。带有轻微的 u 尾韵。 |
| **jñ - ⟪ज्ञ्⟫** | 也可发为 dny（马拉地语）或 gy（北印度方言）。 |
| **ś - ⟪श्⟫** | 舌尖向下弯曲的 sch 音。类似于德语“mischen”中的 sch。 |
| **ṣ - ⟪ष्⟫** | 舌根向后弯曲的 ach 音。有时在喉咙深处发音，以至于听起来几乎像 kh。 |
| **h - ⟪ह्⟫** | 送气音，绝非长音符号。 |
| **ḥ - :** | **Visarga（出气音）** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫。无声送气音，带有 preceding 元音或前一个双元音第二部分的尾韵：agniḥ -- ⟪अग्निः⟫ = agnihi, devaiḥ -- ⟪देवैः⟫ = devaihi, gauḥ -- ⟪गौः⟫ = gauhu |
| **ṃ** | **Anusvara（鼻音化符号）** -- ⟪अनुस्वर⟫。在咝音、h、l 之前：元音鼻化。词尾时 = m。在辅音前：对应于后续辅音的鼻音：saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
要达到最佳的发音效果，应以相当缓慢且单调的语调朗读句子、诗句或单词，并精确注意元音的长度。
