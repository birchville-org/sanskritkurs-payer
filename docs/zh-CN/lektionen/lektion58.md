## 58.6. 过去时5：iṣ-过去时

::: grammar-box
**iṣ-过去时由所有带增强音（seṭ）的词根构成，除非明确仅教授该词根的另一种过去时形式。**

**构成：**

**增强音 + 词根 + i + s + 无韵尾的次要后缀**

**!!!** 第二人称单数（2.sg.P）和第三人称单数（3.sg.P）分别以 **-**īs 或 -īt 结尾 **!!!** （这是由将 ⟪अब्रवीत्⟫ 类型词根的未完成时形式转移而来而产生的；因此，它们实际上是词根过去时形式）。
:::
因此，iṣ-过去时的词干构成后缀和词尾如下：

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | **-iṣam** | **-iṣma** | **-iṣi** | **-iṣmahi** |
| **2. ⟪द्वितीयः⟫** | **-īs** | **-iṣṭa** | **-iṣṭhās** | -**idhvam** / :br-iḍhvam:br（根据 -h 或半元音选择） |
| **3. ⟪प्रथमः⟫** | **-īt** | **-iṣur** | **-iṣṭa** | **-iṣata** |

:::
::: grammar-box
**词根形式：**

*   **短元音后接单一辅音的词根：在现在时（P）和被动语态（Ā）中为强级**  
例如：  
⟪बुध्⟫ 1U：第一人称单数现在时（1.sg.P）⟪अबोधिषम् कॢप्⟫ 第一人称单数被动语态（1.Ā）：⟪अकल्पिषि⟫

*   **以元音结尾的词根：**
*   **P：强化级**
*   **Ā：强式**

例如：  
⟪पू⟫ 9U：1.sg.P ⟪अपाविषम्⟫；1. sg.Ā ⟪अपविषि⟫

*   **以-ar、-al结尾的词根以及 ⟪वद्⟫ 1P “说”、⟪व्रज्⟫ 1P “离开”：P：强化级**  
例如：  
⟪चर्⟫ 1P：1.sg.P ⟪अचारिषम् वद्⟫ 1P：1.sg.P ⟪अवादिषम्⟫

*   **其他形式为（辅音-）辅音-a-辅音的词根：在P中可选强化级（不适用于以-h、-m、-y结尾的词根以及另外一些词根）**  
例如：  
⟪तन्⟫ 8U：1.sg.P ⟪अतनिषम्⟫ / ⟪अतानिषम्⟫  
但是：  
⟪क्रम्⟫ 1U：1.sg.P ⟪अक्रमिषम्⟫
:::
