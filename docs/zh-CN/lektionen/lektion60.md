## 60.4. 重叠完成时（⟪द्वित्वलिट्⟫）的 ⟪परस्मैपद⟫ 分词

::: grammar-box
**Bildung:**

**弱完成词干 + vāṃs**

**若弱完成词干仅由一个音节构成，则添加连接元音 -i-。在某些完成时中，该连接元音是可选的。**
:::
示例：

| ⟪भिद्⟫ 7U | ⟪बिभिद्वांस्⟫ "jemand, der gespalten hat" |
| --- | --- |
| ⟪अस्⟫ 2P; 4P | ⟪आसिवांस्⟫ "jemand, der gewesen ist" ; "jemand, der geworfen hat" |
| ⟪दा⟫ 3U | ⟪ददिवांस्⟫ (da-d-i-vāṃs) "jemand, der gegeben hat" |
| ⟪पच्⟫ 1U | ⟪पेचिवांस्⟫ "jemand, der gegart hat" |
| ⟪गम्⟫ 1U | ⟪जग्मिवांस्⟫ / ⟪जगन्वांस्⟫ "jemand, der gegangen ist" |

::: grammar-box
**变格：**

*   **强词干：-vāṃs**
*   **弱词干：**
*   **辅音前：-vat** **(!)**
*   **元音前：-uṣ**

**在 uṣ 之前，连接元音 -i- 脱落。**

**阴性：**

**元音前的弱词干 + -ī（按 ⟪देवी⟫ 变格）**

示例： ⟪विदुषी⟫ “一位有知者”

## 60.5. -añc (-ac) 结尾词干的变格

::: grammar-box
**-añc/-ac 结尾的词干是前缀等与词根名词 ⟪अञ्च्⟫ / ⟪अच्⟫ 1U “移动”的结合。**
:::
### 60.5.1. -añc 结尾的三词干形式

::: grammar-box
**构成：**

*   **强词干：-añc**
*   **弱词干：**
*   **辅音前：-ac**
*   **元音前：**
*   **弱词干 -ac 中的 -a- 脱落，且若前接半元音，则用对应的长元音替代：**  
⟪प्रत्यच्⟫ » ⟪प्रतीच् अन्वच्⟫ » ⟪अनूच्⟫
*   **若 -ac 前无半元音，则用 -īc 替代 -ac：**  
⟪उदच्⟫ » ⟪उदीच्⟫
*   ⟪तिर्यञ्च्⟫ » ⟪तिरश्⟫

**阴性：**

**元音前的弱词干 + -ī（按 ⟪देवी⟫ 变格）**

示例： ⟪प्रतीची⟫
:::

## 60.6. 欲求态（⟪सन्⟫）

::: grammar-box
**每个词根以及使动态都可以构成欲求态（⟪सन्⟫）。欲求态可以在主动、中动和被动语态的所有时态和语气中进行变位。但除现在词干外的欲求态形式非常罕见。**

**含义：**

*   **某人或某物希望做或通过词根/使动态所表达的动作**
*   **较少见：某人或某物正准备做通过词根或使动态所表达的动作**
:::
#### 示例：

| ⟪कृ⟫ 8U | ⟪चिकीर्षति⟫ “他想要做” |
| --- | --- |
| ⟪पत्⟫ 1P | ⟪पिपतिषति⟫ “他正打算倒下” |
| ⟪चुर्⟫ 10U | ⟪चुचोरयिषति⟫ “他想要偷窃” |
| ⟪बुध्⟫ 使役 | ⟪बुबोधयिषति⟫ “他想要教导（唤醒其认知）” |

### 60.6.1. 欲求词干的构成

::: grammar-box
**第一至第九现在时词根的规则：**

**重叠的词根 + sa**

**或者：**

**重叠的词根 + i + ṣa**

关于连接元音 -i- 的使用规则，参见 Kielhorn《语法》§ 443 - 445。

**第十现在时词根及使役动词：**

**重叠的现在时词干 + i + ṣa**
:::
::: grammar-box
**词根的形态：**

1. 词根通常处于弱等级：⟪जीव्⟫ » ⟪जिजीविष⟫-  

1. 若后面没有连接元音，词尾的 -i、-u 分别替换为 -ī 或 -ū：  
⟪जि⟫ » ⟪जि⟫:sig[⟪गी⟫]⟪ष⟫- “想要获胜”  
⟪द्रु⟫ » ⟪दु⟫:sig[⟪द्रू⟫]⟪ष⟫- “想要奔跑”  

2. 若后面没有连接元音，词尾的 -ṛ、-ṝ 分别替换为 -īr；在唇音后替换为 -ūr：  
⟪कृ⟫ » ⟪चि⟫:sig[⟪कीर्ष⟫]\- “想要做”  
⟪मृ⟫ » ⟪मु⟫:sig[⟪मूर्ष⟫]\- “正打算死去”  
⟪पॄ⟫ » ⟪पु⟫:sig[⟪पूर्ष⟫]\- “想要填满”  

3. ⟪दा⟫、⟪धा⟫、⟪मा⟫ 以及一些以 -ā、-e、-o 结尾的其他词根处于弱等级 Ø：  
⟪दा⟫ » ⟪दित्स⟫- (di-**d** + sa)  
⟪धा⟫ » ⟪धित्स⟫-  
⟪मा⟫ » ⟪मित्स⟫-  

2. 处于强等级的词根在欲求式中： 
1. 大多数以 -ā（-e、-ai 等）结尾的词根：  
⟪गै⟫ » ⟪जिगास⟫- “想要歌唱”  
⟪पा⟫ » ⟪पिपास⟫- “想要饮用，渴望”

2. 大多数形式为（辅音 -）a / ā - 辅音的词根：  
⟪दह्⟫ » ⟪दिधक्ष⟫- “想要燃烧”  
⟪खाद्⟫ » ⟪चिखादिष⟫- “想要咀嚼”  

3. 当连接元音 -i- 出现时： 
1. 强制性：形式为 i/u - 辅音以及（辅音 -）ṛ/ḷ - 辅音的词根：  
⟪इष्⟫ » ⟪एषिषिष⟫- “想要渴望”  
⟪कॢप्⟫ » ⟪चिकल्पिष⟫- “想要合适”  
⟪स्मि⟫ » ⟪सि⟫:sig[⟪स्म⟩]⟪यिष⟫- “想要微笑”  

2. 可选：形式为辅音 -（辅音 -）i/u - 辅音的词根，除了 -v\_  
⟪द्युत्⟫ » ⟪दिद्योतिष⟫- / ⟪दिद्युतिष⟫- “想要闪烁”
:::
::: grammar-box
**关于重叠：**

1. 以辅音开头的词根：根据上述规则修改后的词根按照通常的重叠规则进行重叠。但作为重叠元音的 a 变为 i：  
⟪पा⟫ » ⟪पिपास⟫-  
⟪त्यज्⟫ » ⟪तित्यज⟫-  
⟪चुर्⟫ » ⟪चुचोरयिष⟫-  
如果词尾的 -s 被颚化，则来自词根末尾的 -s 在 i/u 后的腭化不会发生：  
⟪स्मि⟫ » ⟪सिस्मयिष⟫-  

2. 以元音开头的词根按照相应的规则进行重叠（参见 [第56课](lektion56.md)）：  
⟪इष्⟫ » ⟪एषिषिष⟫- (eṣ-i-ṣ-i-ṣa)  
⟪ईक्ष⟫ » ⟪ईचिक्षिष⟫- (ī-c-i-kṣ-i-ṣa)  
⟪ऋ⟫ » ⟪अरिरिष⟫-  

3. 某些特殊词根的重叠形式参见 Kielhorn，《语法》§ 451。
:::
::: grammar-box
**对于某些词根，会构成没有愿望意义的欲求态。在这些具有非愿望意义的欲求态基础上，可以进一步构成具有愿望意义的欲求态。**
:::

### 60.6.2. 欲求态的变位（⟪सन्⟫）

::: grammar-box
**欲求态——除少数例外情况外——根据其所基于的词根（或动词词干）是P类、Ā类还是U类，分别呈现为P、Ā或U类的变位特征。**

**现在时词干：按主题词干的规则进行变位：**

⟪यज्⟫ 第一类（U类）：

:::
::: indent
P类：⟪यियक्षति⟫ “他希望为他人进行祭祀”
Ā类：⟪यियक्षते⟫ “他希望为自己（作为祭祀主）进行祭祀”
被动语态：⟪यियक्ष्यते⟫ “人们希望进行祭祀”
:::
**完成时：分析式构成：**

::: indent
⟪आप्⟫ » ⟪ईप्स⟫- » ⟪ईप्सां चकार⟫ “他曾经希望获得”
:::
**不定过去时：iṣ-不定过去时：**

::: indent
⟪आप्⟫ » ⟪ऐप्सिषम्⟫ (a + īps-i-ṣ-am)
:::
**将来时：⟪सेट्⟫**

::: indent
⟪आप्⟫ » ⟪ईप्सिष्यामि⟫
:::
