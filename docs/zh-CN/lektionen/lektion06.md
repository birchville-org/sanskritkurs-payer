# 第6课

## 6.1. 动词句

::: grammar-box

**模式 I：动词形式**
例如，**yajati** = ⟪यजति⟫ = “他（她，它）以祭祀来尊崇”，“他（她，它）进行祭祀”

**模式 II：施事者（kartṛ m. = ⟪कर्तृ⟫） – 动词形式**
例如，**rāmo yajati** = ⟪रामो यजति⟫ = “罗摩以祭祀来尊崇”，“罗摩进行祭祀”

:::

如果在非被动的动词句中提到了施事者（**kartṛ** m. = ⟪कर्तृ⟫），那么施事者处于**主格**（第一格，prathamā = ⟪प्रथमा⟫）。在数（Zahl, vacana n. = ⟪वचन⟫）上，施事者与动词形式保持一致。


## 6.2. 关于动词形式的构成

限定式动词形式，即带有词尾变化的动词形式，在梵语中表达以下内容：

1. **意义**（**artha** m. ⟪अर्थ⟫）
2. **人称**和**数**（Zahl, **vacana** n. = ⟪वचन⟫）（我，你，他/她/它 <他/她/它们>，我们俩，你们俩，他们/她们/它们俩，我们，你们，他们）
3. 语态（genus verbi）：
1. **Parasmaipada**（n. = ⟪परस्मैपद⟫）（“指向他人的词形”）：主动语态。例如，**yajati** = ⟪यजति⟫ = “他进行祭祀”（即祭司为其他人执行祭祀）
2. **Ātmanepada**（n. = ⟪आत्मनेपद⟫）（“指向自身的词形”）：中间语态。例如，**yajate** = ⟪यजते⟫ = “他为了自身利益进行祭祀”（即祭主为自己和家人进行祭祀）
3. **被动语态**（**karman** n. = ⟪कर्मन्⟫）。例如，**ijyate** = ⟪इज्यते⟫ = “被以祭祀来尊崇”

在许多情况下，Ātmanepada 的意义细微差别已无法察觉；甚至艺术诗人也常常使用 Ātmanepada，而与 Parasmaipada 没有意义区别。然而，在翻译时始终必须仔细注意是否存在这样的意义细微差别。

在Parasmaipada和Ātmanepada（特指Ātmanepada的语义）中使用的动词，被称为**Ubhayapada**-动词（**ubhayapada** n. = ⟪उभयपद⟫ = “两种词形”）。

有些动词仅用于Parasmaipada或仅用于Ātmanepada。对于这些动词，Ātmanepada或Parasmaipada没有特定的语义。例如：**manyate** = ⟪मन्यते⟫ = “他（她，它）思考”（无特定的Ātmanepada语义）。

4. **陈述方式**（语气）：
1. **Indikativ**：陈述式
2. **Optativ**：愿望式和可能式
3. **Imperativ**：命令式
5. **时间**（时态）：
1. **Präsens**：现在时
2. **Imperfekt**
3. **Perfekt**
4. **Aorist**
5. **Futur**：将来时
6. **Konditional**

时态由时干构成：现在时干、不定过去时干、完成时干、将来时干。


## 6.3. Indikativ Präsens (laṭ = ⟪लट्⟫)

现在时是表示现在的时态，特别是持续的状态。

::: grammar-box

**Indikativ（陈述式）现在时的构成，是在现在时干后附加所谓的“主词尾”。**

:::

## 6.5. 现在时词干的构成

### 6.5.1. 第六类现在时动词（tudādi = ⟪तुदादि⟫ = “tud 等”）

::: grammar-box

**现在时词干 = 弱式根（即其被列出的形式）+ a-**

| 词根（dhātu m.）：br⟪धातु⟫ | 现在时词干 |
| :--- | :--- |
| **viś** ：br⟪विश्⟫ | **viśa-** ：br⟪विश⟫- |
| **sṛj** ：br⟪सृज्⟫ | **sṛja-** ：br⟪सृज⟫- |

:::

### 6.5.2. 第一类现在时动词（bhvādi / bhūvādi = ⟪भ्वादि⟫ / ⟪भूवादि⟫ = “bhū 等”）

::: grammar-box

| 现在时词干 = 强式根（罕见为长音式）+ a- ||||
| 词根（dhātu m.）：br⟪धातु⟫ | 强式 | a-前的强式 | 现在时词干 |
| :--- | :--- | :--- | :--- |
| **bhū** ：br⟪भू⟫ | **bho** ：br⟪भो⟫ | **bhav** ：br⟪भव्⟫ | **bhava-** ：br⟪भव⟫- |
| **nī** ：br⟪नी⟫ | **ne** ：br⟪ने⟫ | **nay** ：br⟪नय्⟫ | **naya-** ：br⟪नय⟫- |
| **smṛ** ：br⟪स्मृ⟫ | **smar** ：br⟪स्मर्⟫ | **smar** ：br⟪स्मर्⟫ | **smara-** ：br⟪स्मर⟫- |
| **yaj** ：br⟪यज्⟫ | **yaj** ：br⟪यज्⟫ | **yaj** ：br⟪यज्⟫ | **yaja-** ：br⟪यज⟫- |
| 若元音位于长闭音节中，即短元音后跟两个或更多辅音，则不形成强式 ||||
| **nind** ：br⟪निन्द्⟫ | **nind** ：br⟪निन्द्⟫ | **nind** ：br⟪निन्द्⟫ | **ninda-** ：br⟪निन्द⟫- |

:::

#### 6.5.2.1. 词中 e 和 o 的连音变化
在元音之前，词内的 **e** 替换为 **ay**，**o** 替换为 **av**。

#### 6.5.2.2. 元音交替（Ablaut）

::: grammar-box

| 低阶：br弱阶 | 中阶：br全阶：brGuṇa m.:br⟪गुण⟫ | 长阶：brVṛddhi f.:br⟪वृद्धि⟫ |
| :--- | :--- | :--- |
| **ø** | **a** | **ā** |
| **i / ī** | **e** | **ai** |
| **u / ū** | **o** | **au** |
| **ṛ / ṝ** | **ar** | **ār** |
| **ḷ** | **al** | **āl** |

:::

### 6.5.3. 第四类现在时动词（divādi = ⟪दिवादि⟫ = "div 等"）

::: grammar-box

**现在时词干 = 根的低阶形式（即其被列出的形式）+ ya-**

| 词根 (dhātu m.):br⟪धातु⟫ | 现在时词干 |
| :--- | :--- |
| **nṛt** :br⟪नृत्⟫ | **nṛtya-** :br⟪नृत्य⟫- |
| **muh** :br⟪मुह्⟫ | **muhya-** :br⟪मुह्य⟫- |
| **yudh** :br⟪युध्⟫ | **yudhya-** :br⟪युध्य⟫- |
| **man** :br⟪मन्⟫ | **manya-** :br⟪मन्य⟫- |

:::

### 6.5.4. 主题元音，有主题现在时类

::: grammar-box

现在时类词干构成后缀中的 **a** 被称为**主题元音**。因此，词干构成后缀中包含 **a** 的现在时类被称为“有主题现在时类”。

:::

## 6.6. 口语梵语：其他问题（praśna m. = ⟪प्रश्न⟫）

::: grammar-box

**N. N. kiṃ karoti?** = N.N. ⟪किं करोति⟫ = "N.N. 在做什么？"
**N. N. (plural) kiṃ kurvanti?** = N.N. ⟪किं कुर्वन्ति⟫ = "N.N.s 们在做什么？"
(karoti, kurvanti 来自 **kṛ** = ⟪कृ⟫ 第8类: "做，制作")
**kiṃ kuśalam?** = ⟪किं कुशलम्⟫ = "您还好吗？/ 您好吗？"
回答: **sarvathā kuśalam** = ⟪सर्वथा कुशलम्⟫ = "(我)各方面都很好。"

:::

## 6.7. 词汇表

::: grammar-box

在梵语中，动词以**词根形式**列出。词根后的数字表示**变位类**。

**P：** 该词根仅用于 Parasmaipada（他称语态）
**Ā：** 该词根仅用于 Ātmanepada（自称语态）
**U：** Ubhayapada（“两种形式”）：该词根在 Parasmaipada 和 Ātmanepada 中均使用。
**()：** 括号内为第三人称单数现在时直陈式（laṭ）。

:::

**请学习以下词汇：**
**yaj** 1 U (yajati) ⟪यज् यजति⟫ : 以祭祀敬奉，献祭
**bhū** 1 P (bhavati) ⟪भू भवति⟫ : 成为，产生，存在
**smṛ** 1 P (smarati) ⟪स्मृ स्मरति⟫ : 使再现，回忆
**nṛt** 4 P (nṛtyati) ⟪नृत् नृत्यति⟫ : 跳舞
**nī** 1 U (nayati) ⟪नी नयति⟫ : 引导
**man** 4 Ā (manyate) ⟪मन् मन्यते⟫ : 思考
**muh** 4 P (muhyati) ⟪मुह् मुह्यति⟫ : 困惑
**yudh** 4 Ā (yudhyate) ⟪युध् युध्यते⟫ : 战斗
**viś** 6 P (viśati) ⟪विश् विशति⟫ : 进入
**sṛj** 6 P (sṛjati) ⟪सृज् सृजति⟫ : 释放，放出，发出
