# 第8课



## 8.1. 名词词干的构成

在传统印度语法中，对于用于构成名词词干的后缀，人们区分如下：

**kṛt后缀（⟪कृत्⟫）（主要后缀）：** 由动词词根（**dhātu** m. = ⟪धातु⟫）和动词词干构成名词词干、绝对副词（Absolutiva）和不定式。
**taddhita后缀（⟪तद्धित⟫）（次要后缀）：** 附加于名词词干和不变词之上，构成新的名词词干或不变词。

::: grammar-box
**图示：**
**词根 + kṛt后缀 » 名词词干等 + taddhita后缀 » 新的名词词干等**

**名词词干 + 格尾 » 可句法使用的名词**
:::

## 8.2. 名词后缀的分类

**kṛt (kṛdanta) = ⟪कृत्⟫ (⟪कृदन्त⟫)**
**kārakakṛt** (⟪कारककृत्⟫) » 施事名词（指代执行词根所表示动作的人）
**kṛtikṛt** (⟪कृतिकृत्⟫) » 动作名词（指代由词根表达的动作）或抽象概念

**taddhita**
**viśeṣyataddhita** (⟪विशेष्यतद्धित⟫) » 形容词
**bhāvārthakataddhita (tanmātrataddhita)** (⟪भावार्थकतद्धित⟫ / ⟪तन्मात्रतद्धित⟫) » 抽象概念
**tadvattaddhita** (⟪तद्वत्तद्धित⟫) » 表所属（例如 **-mant** -⟪मन्त्⟫, **-vant** -⟪वन्त्⟫）
**tolanataddhita (atiśāyanataddhita)** (⟪तोलनतद्धित⟫ / ⟪अतिशायनतद्धित⟫) » 比较级（形容词比较级、最高级），比较
**pūraṇataddhita** (⟪पूरणतद्धित⟫) » 序数词（第一等）
**vibhaktitaddhita** (⟪विभक्तितद्धित⟫) » 替代格尾（例如 **-tas** -⟪तस्⟫, **-tra** -⟪त्र⟫）
**abhūtatadbhāva (cvitaddhita)** (⟪अभूततद्भाव⟫ / ⟪च्वितद्धित⟫) » （cvi构成 ⟨�च्वि⟫, **-sāt** -⟪सात्⟫）

**按元音交替分类：**
**guṇya**（⟪गुण्य⟫）：强级形式
**na guṇya**（⟪न गुण्य⟫）：弱级形式
**vṛddhyarha**（⟪वृद्ध्यर्ह⟫）：长级形式


## 8.3. 一些重要的名词后缀

### 8.3.1. -a m.（kṛt）

::: grammar-box
**kṛt 后缀 -a 构成阳性（较少为中性）名词，指代由词根所表示的动作或状态；有时也构成形容词或名词，表达由动词词根所指动作的施事者（kartṛ）。对于短倒数第二个音节（即词根结尾辅音前的元音）或词尾的词根元音，通常以强级（guṇa）或长级（vṛddhi）替代。**
:::
**示例：**

| 词根:br⟪धातु⟫ | + -a（kṛt） | 含义 |
| :--- | :--- | :--- |
| **ji** 1 P:br⟪आप्⟫:br“胜利” | **jaya** m.:br⟪जय⟫ | “胜利，胜者” |
| **muh** 4 P:br⟪मुह्⟫:br“迷惑” | **moha** m.:br⟪मोह⟫ | “迷惑，蒙蔽，错误” |
| **krudh** 4 P:br⟪क्रुध्⟫:br“愤怒” | **krodha** m.:br⟪क्रोध⟫ | “愤怒” |
| **kup** 4 P:br⟪कुप्⟫:br“愤怒” | **kopa** m.:br⟪कोप⟫ | “愤怒” |
| **lubh** 4 P:br⟪लुभ्⟫:br“渴望” | **lobha** m.:br⟪लोभ⟫ | “欲望” |
| **labh** 1 Ā:br⟪लभ्⟫:br“获得” | **lābha** m.:br⟪लाभ⟫ | “获得，收益” |
| **sṛj** 6 P:br⟪सृज्⟫:br“释放，使 emanate” | **sarga** m.:br⟪सर्ग⟫ | “释放，流注，创造”（关于词法连音 j » g 见后文） |
| **śru** 5 P:br⟪श्रु⟫:br“听” | **śrava** m.:br⟪श्रव⟫ | “听” |
| **bhū** 1 P:br⟪भू⟫:br“成为，存在” | **bhāva** m.:br⟪भाव⟫ | “成为，（某物）存在，本性，性格” |
| **yudh** 4 Ā:br⟪युध्⟫:br“战斗” | **yodha** m.:br⟪योध⟫ | “战士，武士，士兵” |


### 8.3.2. -ana n. (kṛt)

::: grammar-box
**词缀后缀 -ana 通常构成中性名词，表示由词根或动词词干所指称的动作得以实现的行为、状态或手段/工具。对于短元音居中的倒数第二个音节（penultima）或词尾的元音，通常替换为强级形式（guṇa）。**
:::
**示例：**

| 词根:br⟪धातु⟫ | + -ana (kṛt) | 含义 |
| :--- | :--- | :--- |
| **gam** 1 P:br⟪गम्⟫:br"走" | **gamana** n.:br⟪गमन⟫ | "行走" |
| **nī** 1 U:br⟪नी⟫:br"引导" | **nayana** n.:br⟪नयन⟫ | "(引导的工具，即) 眼睛" |
| **śru** 5 P:br⟪श्रु⟫:br"听" | **śravaṇa** n.:br⟪श्रवण⟫ | "(听觉工具 =) 耳朵" |
| **kṛ** 8 U:br⟪कृ⟫:br"做" | **kāraṇa** n.:br⟪कारण⟫ | "(使某事得以做的东西，即) 原因、理由" |
| **bhū** 1 P:br⟪भू⟫:br"成为" | **bhavana** n.:br⟪भवन⟫ | "成为、产生" |
| **dṛś** 4 P:br⟪दृश्⟫:br"看" | **darśana** n.:br⟪दर्शन⟫ | "看、观点、哲学体系、显现，特指：Darśan" |

::: note-box
**"Darshan"** 或 **"Darshana"** 是印度教中的一个术语，指对神圣和神性的观看与愿景。*Darshana* 可理解为例如学生受大师邀请而进行的正式会面。但它也可以指在凝视神像时的*沉浸*状态。后一种含义在现代印地语的使用中最为常见。在涉及玛塔·阿默蒂南达迈伊（Mata Amritanandamayi）的语境中，Darshan 指上师的拥抱。

虔诚的印度教徒前往寺庙，通过被视为神灵精神存在的象征或神像来“观看”（Darshan）神明。在此意义上，这也包括接受来自神明的祝福。然而，Darshan 也可以通过在祈祷或冥想中见到神明而获得。此外，被视为神明化身（如 Avatara）的活人也可以提供 Darshan。
（来源：维基百科）
:::

### 8.3.3. -tra n. (kṛt)

::: grammar-box
**派生后缀 -tra 构成（通常）中性名词，指代使词根所表示的动作得以实现的手段或工具。词根的短元音非重读部分和尾随元音通过增强形式（guṇa）替换。**
:::

**示例：**

| 词根:br⟪धातु⟫ | + -tra (kṛt) | 含义 |
| :--- | :--- | :--- |
| **nī** 1 U:br⟪नी⟫:br“引导” | **netra** n.:br⟪नेत्र⟫ | “（引导的手段 =）眼睛” |
| **śru** 5 P:br⟪श्रु⟫:br“听” | **śrotra** :br⟪श्रोत्र⟫ | “（听觉工具 =）耳朵” |
| **man** 4 Ā:br⟪मन्⟫:br“思考” | **mantra** **m. (!)** :br⟪मन्त्र⟫ | “（思考工具：）咒语，‘魔法’公式（Mantra）” |
| **tan** 8 U:br⟪तन्⟫:br“拉伸” | **tantra** n.:br⟪तन्त्र⟫ | “经线” |

### 8.3.4. -ti f. (kṛt)

::: grammar-box
**后缀 -ti 构成阴性名词，通常表示词根所指的动作或状态。词根的形态为弱级。**
:::
**示例：**

| 词根:br⟪धातु⟫ | + -ti (kṛt) | 含义 |
| :--- | :--- | :--- |
| **śru** 5 P:br⟪श्रु⟫:br“听” | **śruti** f.:br⟪श्रुति⟫ | “听，吠陀” |
| **smṛ** 1 P:br⟪स्मृ⟫:br“忆念” | **smṛti** f.:br⟪स्मृति⟫ | “忆念，记忆，传承，正念” |
| **nī** 1 U:br⟪नी⟫:br“引导” | **nīti** f.:br⟪नीति⟫ | “引导，领导，行为” |
| **sṛj** 6 P:br⟪सृज्⟫:br“发出” | **sṛṣṭi** f.:br⟪सृष्टि⟫ | “流溢，创造” |
| **dṛś** 4 P:br⟪दृश्⟫:br“看” | **dṛṣṭi** f.:br⟪दृष्टि⟫ | “视，面，见解” |
| **gam** 1 P:br⟪गम्⟫:br“走” | **gati** f.:br⟪गति⟫ | “行，道路，行走的目标”（源自 *gm » ga + -ti） |
| **man** 4 Ā:br⟪मन्⟫:br“思” | **mati** f.:br⟪मति⟫ | “思，想法，意见”（源自 *mn » ma + -ti） |

*注：形式前的 \* 表示该形式在梵语中不存在，而是作为特定构词的前提理论上推导出来的。**gam** 的弱级是 gṃ = \*gm，其中的 m 作为所谓鼻响音被 **a** 替代 » **ga**。对于 **man** » **ma** 同理。



### 8.3.5. -tva n., -tā f. (taddhita)

::: grammar-box
**taddhita 后缀 -tva n. 和 -tā f. 构成名词的抽象名词。底层名词词干保持不变。**
:::
**示例：**

| 名词词干：br⟪नामप्रातिपदिक⟫:br | + -tva n.:br（附加词尾） | + -tā f.:br（附加词尾） | 含义 |
| :--- | :--- | :--- | :--- |
| **guru** :br⟪गुरु⟫:br3 “沉重，庄严,:brm. 导师” | **gurutva** n.:br⟪गुरुत्व⟫ | **gurutā** f.:br⟪गुरुता⟫ | “沉重，庄严,:br教师身份（教师的本质或性质）” |
| **brāhmaṇa** :br⟪ब्राह्मण⟫:brm. “婆罗门” | **brāhmaṇatva** n.:br⟪ब्राह्मणत्व⟫ | **brāhmaṇatā** f.:br⟪ब्राह्मणता⟫ | “婆罗门性,:br使某人成为婆罗门的因素,:br婆罗门的本质 / 性质” |
| **deva** :br⟪देव⟫:brm. “天神，神” | — | **devatā** f.:br⟪देवता⟫ | “神性” |

这些构词形式几乎可以应用于任何名词，在学术梵文著作中非常常见。


## 8.4. 第八现在时类（tanādi = ⟪तनादि⟫ = “tan 等”）

::: grammar-box
**词干构成：**
**强词干：词根 + -o-**
**弱词干：词根 + -u-（元音前为 -v-）**

示例 **tan** 8 U（⟪तन्⟫）“伸展”：
3\. sg. P. **tanoti** :br⟪तनोति⟫
3\. pl. P. **tanvanti** :br⟪तन्वन्ति⟫
3\. sg. Ā. **tanute** :br⟪तनुते⟫
3\. pl. Ā. **tanvate** :br⟪तन्वते⟫
:::
注：关于 **tan** 究竟是否属于第五类词根（*tn » ta + no-*）的争论，参见 Thumb-Hauschild，《梵文手册》第二卷，第 265 页。

第八类最重要的词根是 **kṛ** 8 U（⟪कृ⟫）“做，制作”。其变位不规则：

::: grammar-box
**kṛ 8 U（⟪कृ⟫）“制作，做”**

3\. sg. Ā. **kurute** :br⟪कुरुते⟫

:::
