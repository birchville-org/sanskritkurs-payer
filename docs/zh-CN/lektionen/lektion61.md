# 第61课

## 61.1. 以 -ā, -ī, -ū 结尾的词根名词变格

### 61.1.1. 以 -ā 结尾的词根名词在 ⟪तत्पुरुष⟫ 末尾

::: grammar-box
**在元音词尾前，弱格中的词干元音变为零级 Ø。**

**阳性与阴性变格相同。**
:::
范式：

⟪विश्वपा⟫ m.f. “守护一切”

|   | ⟪एकवचनम्⟫ | ⟪द्विवचनम्⟫ | ⟪बहुवचनम्⟫ |
| --- | --- | --- | --- |
| **⟪प्रथमा⟫ /:br⟪आमन्त्रितम्⟫** | ⟪विश्वपास्⟫ | ⟪विश्वपौ⟫ | ⟪विश्वपास्⟫ |
| ⟪द्वितीया⟫ | ⟪विश्वपाम्⟫ | ^^ | ⟪विश्वपस्⟫ |
| ⟪तृतीया⟫ | ⟪विश्वपा⟫ | ⟪विश्वपाभ्याम्⟫ | ⟪विश्वपाभस्⟫ |
| ⟪चतुर्थी⟫ | ⟪विश्वपे⟫ | ^^ | ⟪विश्वपाभ्यस्⟫ |
| ⟪पञ्चमी⟫ | ⟪विश्वपस्⟫ | ^^ | ^^ |
| ⟪षष्ठी⟫ | ^^ | ⟪विश्वपोस्⟫ | ⟪विश्वपाम्⟫ |
| ⟪सप्तमी⟫ | ⟪विश्वपि⟫ | ^^ | ⟪विश्वपासु⟫ |

### 61.1.2. 以 -ī 结尾的阴性词根名词

::: grammar-box
**在元音词尾前，-ī 替换为 -iy。**

**除规则格尾形式外，在单数与格/离格/属格/位格以及复数属格中，也存在遵循多音节阴性名词 -ī（⟪देवी⟫）模式的变体。**
:::
范式：

⟪धी⟫ f. “思想”

|   | ⟪एकवचनम्⟫ | ⟪द्विवचनम्⟫ | ⟪बहुवचनम्⟫ |
| --- | --- | --- | --- |
| **⟪प्रथमा⟫ /:br⟪आमन्त्रितम्⟫** | ⟪धीस्⟫ | ⟪धियौ⟫ | ⟪धियस्⟫ |
| ⟪द्वितीया⟫ | ⟪धियम्⟫ | ^^ | ^^ |
| ⟪तृतीया⟫ | ⟪धिया⟫ | ⟪धीभ्याम्⟫ | ⟪धीभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪धिये⟫ / ⟪धियै⟫ | ^^ | ⟪धीभ्यस्⟫ |
| ⟪पञ्चमी⟫ | ⟪धियस्⟫ / ⟪धिया्स्⟫ | ^^ | ^^ |
| ⟪षष्ठी⟫ | ^^ | ⟪धियोस्⟫ | ⟪धियाम्⟫ / ⟪धीनाम्⟫ |
| ⟪सप्तमी⟫ | ⟪धियि⟫ / ⟪धियाम्⟫ | ^^ | ⟪धीषु⟫ |

不规则：⟪स्त्री⟫ f. “女性”

::: grammar-box
|   | ⟪एकवचनम्⟫ | ⟪द्विवचनम्⟫ | ⟪बहुवचनम्⟫ |
| --- | --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪स्त्री⟫ | ⟪स्त्रियौ⟫ | ⟪स्त्रियस्⟫ |
| ⟪द्वितीया⟫ | ⟪स्त्रियम्⟫ / ⟪स्त्रीम्⟫ | ^^ | ⟪स्त्रियस्⟫ / ⟪स्त्रीस्⟫ |
| ⟪तृतीया⟫ | ⟪स्त्रिया⟫ | ⟪स्त्रीभ्याम्⟫ | ⟪स्त्रीभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪स्त्रियै⟫ | ^^ | ⟪स्त्रीभ्यस्⟫ |
| ⟪पञ्चमी⟫ | ⟪स्त्रियास्⟫ | ^^ | ^^ |

### 61.1.3. 以 -ī 结尾的词根名词在 ⟪तत्पुरुष⟫ 末尾

::: grammar-box
**在元音词尾前，如果 -ī 前面只有一个属于词根的辅音，则 -ī 被替换为 -y。如果前面有多个属于词根的辅音，则在元音词尾前将 -ī 替换为 -iy。**

**阳性与阴性变格相同。**

**不规则性：以 -⟪नी⟫ “引导” 结尾的复合词，在位格单数中词尾为 -ām（如 ⟪देवी⟫）：**
例如 ⟪ग्रामणी⟩ “引导一群/村庄”：位格单数 m.f. ⟪ग्रामण्याम्⟫
:::
变格表：

⟪शुद्धधी⟫ m., f. “纯净地思考”

|   | ⟪एकवचनम्⟫ | ⟪द्विवचनम्⟫ | ⟪बहुवचनम्⟫ |
| --- | --- | --- | --- |
| **⟪प्रथमा⟫ /:br⟪आमन्त्रितम्⟫** | ⟪शुद्धधीस्⟫ | ⟪शुद्धध्यौ⟫ | ⟪शुद्धध्यस्⟫ |

| ⟪चतुर्थी⟫ | ⟪शुद्धध्ये⟫ | ^^ | ⟪शुद्धधीभ्यस्⟫ |
| ⟪पञ्चमी⟫ | ⟪शुद्धध्यस्⟫ | ^^ | ^^ |
| ⟪षष्ठी⟫ | ^^ | ⟪शुद्धध्योस्⟫ | ⟪शुद्धध्याम्⟫ |

### 61.1.5. 位于 ⟪तत्पुरुष⟫ 末尾的以 -ū 结尾的词根名词

::: grammar-box

## 61.2. 迂回将来时（⟪लुट्⟫）

::: grammar-box
**除了简单将来时（⟪ऌत्⟫）之外，还存在一种迂回将来时（⟪लुट्⟫）。根据本土语法学家的理论，迂回将来时用于表示遥远的未来（“在当天之后”），而简单将来时表示近来的未来（“在当天内”。）在古典梵语中，通常在使用这两种将来时态时并不加以区分。**

**构成：**

**迂回将来时由以 -tṛ 结尾的施事名词与 ⟪अस्⟫ 2. 的现在时结合而成。第三人称形式为简单的名词，具有相应的数，不区分语法性别。在与 ⟪अस्⟫ 结合时，该名词在所有人称和数中均采用主格单数的 -tā 形式。**
:::
因此，迂回将来时（periphrastisches Futur）的词尾如下：

::: grammar-box
|   | ⟪परस्मैपदम्⟫ ||| ⟪आत्मनेपदम्⟫ |||
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪द्विवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪द्विवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1\. ⟪तृतीयः⟫** | \-tāsmi:br(-tā + asmi) | \-tāsvas | \-tāsmas:br(-tā smas) | **\-tāhe** | \-tāsvahe | \-tāsmahe |
| **2\. ⟪मध्यमः⟫** | \-tāsi | \-tāsthas | \-tāstha | \-tāse | \-tāsāthe | \-tādhve |
| **3\. ⟪प्रथमः⟫** | \-tā | \-tārau | \-tāras | \-tā | \-tārau | \-tāras |
:::
::: grammar-box
**词根形式：词根通常与简单将来时中的形式相同。连接元音 -i- 的情况也是如此。**
:::
示例：

| ⟪दा⟫ 3U | ⟪दातास्मि⟫, ⟪दतासि⟫, ⟪दाता⟫ 等 |
| --- | --- |
| ⟪भू⟫ 1P | ⟪भवितास्मि⟫ ... ⟪भाविता⟫ 等 |
| ⟪तुद्⟫ 6U | ⟪तोत्तास्मि⟫ ... ⟪तोत्ता⟫ 等 |
| ⟪गै⟫ 1P | ⟪गातास्मि⟫ ... ⟪गाता⟫ 等 |

## 61.3. 强调式（频繁式）(⟪चर्करीतम्⟫)

::: grammar-box
**对于前九个现在时词根中每一个以辅音开头的单音节词根，都可以构成强调式（⟪चर्करीतम्⟫）；也就是说：除了少数例外，双音节词根（例如 ⟪जागृ⟫）、以元音开头的词根以及第十类现在时词根（⟪चुरादिगण⟫）不能构成强调式。**

**强调式的含义是：**

*   **表示某人或某物反复做或经历词根所表达的动作**  
⟪कृ⟫ 8U: ⟪चेक्रीयते⟫ / ⟪चर्करीति⟫ “他反复做”  
⟪भू⟫ 1P: ⟪बोभूयते⟫ / ⟪बोभवीति⟫ “他经常是（变得）”  

*   **表示某人或某物强烈地做或经历词根所表达的动作：**  
⟪कृ⟫ 8U: ⟪चेक्रीयते⟫ / ⟪चर्करीति⟫ “他强烈地做，他做得很出色”  

*   **对于表示运动的词根，强调式意味着弯曲的运动：**  
⟪व्रज्⟫ 1P:  ⟪वव्रज्यते⟫ “他弯曲地行走”（NOT：“他经常走”）  

*   **对于某些词根（列举：Kielhorn，《语法》§ 458b），强调式表示贬义：**  
⟪लुप्⟫ 6U: ⟪लोलुप्यते⟫ “他切得不好”  
⟪सद्⟫ 1P: ⟪सासद्यते⟫ “他坐得不好”
:::

::: grammar-box
**强调式的构成：**

**存在两种类型的强调式构成：**

*   **Atmanepada 强调式**
*   **Parasmaipada 强调式**

**两者均由带有强重音重叠的词根构成。两者在意义上没有区别。两者都可以由相同的词根构成。**
:::
### 61.3.1. Ātmanepada-强化式

::: grammar-box
**构成：**

**重辅音词根 + -ya-**

**词根形式：通常与被动语态相同，即多为弱级：**

示例：

:::
::: indent
⟪स्वप्⟫ 第二人称：被动语态 ⟪सुप्यते⟫；强化式 ⟪सोषुप्यते दा⟫ 第三人称中性：被动语态 ⟪दीयते⟫；强化式 ⟪देदीयते⟫
:::
具体规则见 Kielhorn《语法》第 461 节。

**重辅音：遵循一般规则。但重辅音元音：a、i、u 分别变为 ā、e、o**
示例：

| ⟪दा⟫ 第三人称中性 | ⟪देदीय⟫- |
| --- | --- |
| ⟪भू⟫ 第一人称单数 | ⟪बोभूय⟫- |
| ⟪कृ⟫ 第八人称中性 | ⟪चेक्रीय⟫- |
| ⟪जीव्⟫ 第一人称单数 | ⟪जेजीव्य⟫- |
| ⟪शास्⟫ 第二人称单数 | ⟪शेशिष्य⟫- |
| ⟪ज्ञा⟫ 第九人称中性 | ⟪जाज्ञाय⟫- |

::: grammar-box
**以 -a-Nasal 结尾的词根在重辅音音节中不延长元音，而是重复该 Nasal。**

:::
::: indent
例如：⟪यम्⟫ 第一人称单数：⟪यंयम्य⟫-
:::
**在某些词根中，重辅音音节的元音与词根的起始辅音之间插入 -nī- 或 -rī-（若强化式词根包含 ṛ，则插入 -rī-）。**

::: indent
例如：
⟪पत्⟫ 第一人称单数：⟪प⟫:sig[⟪नी⟫]⟪पत्य⟫-
⟪वृत्⟫ 第一人称中：⟪व⟫:sig[⟪री⟫]⟪वृत्य⟫-
:::
::: grammar-box
**变位：**

*   **现在时词干：如同第四类现在时的 Ātmanepada（⟪दिवादिगण⟫）。**
*   **被动语态及其他时态词干：若强化式词干的 -ya- 前为元音，则 -ya- 变为 -y-；若 -ya- 前为辅音，则省略 -ya-：**
*   **被动语态现在时：⟪बुध्⟫ : ⟪बोबुध्यते⟫ ; ⟪भू⟫ : ⟪बोभूय्यते⟫**
*   **完成时：迂回式： ⟪बोबुधाञ्चक्रे⟫ ; ⟪बोभूयाञ्चक्रे⟫**
*   **不定过去时：iṣ-不定过去时（第五类不定过去时）：⟪अबोबुधिष्ट⟫ ; ⟪अबोभूयिष्ट⟫**
*   **将来时：带 seṭ 标记：⟪बोबुधिष्यते⟫ ; ⟪बोभूयिष्यते⟫**
*   **迂回将来时： ⟪बोबुधिता⟫ ; ⟪बोभूयिता⟫**
:::
### 61.3.2. Parasmaipada-加强式

::: grammar-box
**现在词干（其他形式极为罕见）：构成和变位如同第三类现在动词的变位（⟪जुहोत्यादिगण⟫），区别在于重叠音节的元音为高重音，若为-a-则为长重音。**

**在单数直陈式现在时以及第二、三人称单数的未完成过去时和第三人称单数命令式中，词根与词尾之间可以插入一个-ī-。若插入了这个-ī-，倒数第二个位置的短元音不得进行guṇi增强。**

## 61.4. 派生动词（⟪नामधातु⟫）

派生动词（⟪नामधातवः⟫）与之前讲解的动词不同，它们并非由词根构成，而是由名词词干构成。其中存在多种构型类型。

### 61.4.1. 无特殊后缀的构成，他称

::: grammar-box
**含义：**

:::
::: indent
**某人或某物以名词词干所指称的事物为行为方式，或与后者相似。**
:::
**变位：**

::: indent
**现在时词干如同第一类现在时动词（⟪भ्वादिगण⟫）的变位。若名词以元音-a结尾，则仅最后一个元音按第一类词根元音的方式处理。词尾的-a在主题元音前脱落。位于词尾鼻音前的元音由相应的长元音替代。**
:::
示例：

| ⟪कवि⟩ m. “诗人” | ⟪कवयति⟫ “他表现得像一位诗人” |
| --- | --- |
| ⟪भू⟫ f. “大地” | ⟪भवति⟫ “他表现得像大地一样” |
| ⟪पितृ⟫ “父亲” | ⟪पितरति⟫ “他表现得像一位父亲” |
| ⟪कृष्ण⟫ m. Kṛṣṇa | ⟪कृष्णति⟫ “他表现得像黑天一样” |
| ⟪माला⟫ f. “花环” | ⟪मालाति⟫ “它类似于一个花环” |
| ⟪राजन्⟫ m. “国王” | ⟪राजानति⟫ “他表现得像一位国王一样” |

### 61.4.2. 带后缀 -ya 的构成，他称

::: grammar-box
**含义：**

*   **某人渴望由名词词干所指称的事物**
*   **某人对人或事物进行对待或看待，如同由名词词干所指称的那样**

**词干构成：**

:::
::: indent
**在 -ya 之前，名词词干的尾音会经历以下变化：**

*   **a, ā » ī ： ⟪पुत्र⟫ » ⟪पुत्रीय⟫-**
*   **i, u » ī, ū ： ⟪कवि⟫ » ⟪कवीय⟫-**
*   **ṛ » rī ： ⟪कर्तृ⟫ » ⟪कर्त्रीय⟫-**
*   **o » av ： ⟪गो⟫ » ⟪गव्य⟫-**
*   **au » āv ： ⟪नौ⟫ » ⟪नाव्य⟫-**
*   **词尾鼻音脱落，其前的元音按上述规则处理： ⟪राजन्⟫ » ⟪राजीय⟫-**
*   **其他词尾辅音保持不变**
:::
示例：

| ⟪पुत्र⟩ m. “儿子” | ⟪पुत्रीयति⟫ “他渴望一个儿子” |
| --- | --- |
| ⟪कवि⟫ m. “诗人” | ⟪कवीयति⟫ “他渴望一位诗人” |
| ⟪गो⟫ f. “母牛” | ⟪गव्यति⟫ “他渴望一头母牛” |
| ⟪राजन्⟫ m. “国王” | ⟪राजीयति⟫ “他渴望一位国王” |
| ⟪विष्णु⟫ m. 毗湿奴 (Viṣṇu) | ⟪विष्णूयति⟫ “他将某人视为毗湿奴” |
| ⟪प्रासाद⟫ m. “宫殿” | ⟪प्रासादीयति⟫ “他将（例如他的茅屋）视为宫殿” |

请注意以下含义：

| ⟪तपस्⟫ n. “苦行” | ⟪तपस्यति⟫ “他进行苦修” |
| --- | --- |
| ⟪नमस्⟫ n. “崇拜” | ⟪नमस्यति⟫ “他进行崇拜” |

### 61.4.5. 带后缀 -ya 的构成，Ātmanepada（自称）

::: grammar-box
**含义：**

:::
::: indent
**某人以由名词词干所指称的事物为行为方式，或与之相似。**
:::
**构成规则：**

*   **以 -a 结尾的变为 -ā**
*   **以 -ā 结尾的保持不变**
*   **其他情况如同前接 -ya，Parasmaipada（他称）构成（见上文 4.2。）**
*   **以 -as 结尾的可变为 -ā（可选）**
*   **阴性词干通常转为阳性词干**

示例：

| ⟪कृष्ण⟫ m. Kṛṣṇa（黑天） | ⟪कृष्णायते⟫ “他表现得像 Kṛṣṇa” |

| ⟪कुमारी⟫ f. “女孩” | ⟪कुमारायते⟫ “他表现得像个女孩” |

::: grammar-box
**对于某些名词词干，该后缀表示：某物变得如同……，或成为由该名词词干所指称的事物：**

:::

:::

示例：

::: indent

⟪शब्द⟫ m. “声音”：⟪शब्दायते⟫ “他发出声响”

## 61.6. 条件式（⟪ऌङ्⟫）

::: grammar-box
**条件式（⟪ऌङ्⟫）用于在条件句中表达所提及的条件并未发生、未曾发生或将不会发生。在此类句子中，条件从句和主句都必须使用条件式。**
:::
示例：

::: indent
⟪सुवृष्टिश्चेदभविष्यत्सुभिक्षमभविष्यत्⟫ “如果雨水充足（或正在下雨），食物就会丰裕。（但事实上并没有下足够的雨。）”
:::
::: grammar-box
**条件式（⟪ऌङ्⟫）的构成：**

**增强成分 + 简单将来时词干（⟪ऌत्⟫）+ 次要词尾**

即，如同过去时（⟪लङ्⟫）针对将来词干的构成方式。

例如，⟪अदास्यम्⟫；⟪अभविष्यम्⟫；⟪अतोत्स्यम्⟫
:::
变位表：
