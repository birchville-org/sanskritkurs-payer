# Упражнение 54

Образувайте съответните форми на аориста от следните форми на настоящето или перфекта:

::: grammar-box
| №. | Форма | Определение / Значение | Аорист |
|:---|:---|:---|:---|
| ⟪१⟫. | ⟪यन्ति⟫ | те отиват | ⟪अगुः⟫ |
| ⟪२⟫. | ⟪पिबामि⟫ | аз пия | ⟪अपाम्⟫ |
| ⟪३⟫. | ⟪ददौ⟫ | аз / той е дал | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | ⟪बभूव⟫ | аз / той / те бяха / бяхте | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | ⟪दधति⟫ | те поставят | ⟪अधुः⟫ |
| ⟪६⟫. | ⟪ऐम⟫ | ние отидохме | ⟪अगाम⟫ |
| ⟪७⟫. | ⟪पपिथ⟫ | ти си пил / пазиш | ⟪अपाः⟫ (към :sig[⟪पा⟫] "пия") |
| ⟪८⟫. | ⟪तिष्ठति⟫ | той стои | ⟪अस्थात्⟫ |
| ⟪९⟫. | ⟪इयेथ⟫ | ти си отишъл | ⟪अगाः⟫ |
| ⟪१०⟫. | ⟪पप⟫ | вие сте пили | ⟪अपात⟫ |
| ⟪११⟫. | ⟪एष्यथ⟫ | вие ще отидете | ⟪अगात⟫ |
| ⟪१२⟫. | ⟪तस्थुः⟫ | те стояха | ⟪अस्थुः⟫ |
| ⟪१३⟫. | ⟪अधत्त⟫ | вие поставяхте | ⟪अधात⟫ |
| ⟪१४⟫. | ⟪अददाः⟫ | ти даде | ⟪अदाः⟫ |
| ⟪१५⟫. | ⟪अभवन्⟫ | те бяха | ⟪अभूवन्⟫ |
| ⟪१६⟫. | ⟪ददिम⟫ | ние сме дали | ⟪अदाम⟫ |
| ⟪१७⟫. | ⟪भिद्यते⟫ | се разделя | ⟪अभेदि⟫ |
| ⟪१८⟫. | ⟪उद्यते⟫ | се казва | ⟪अवादि⟫ |
| ⟪१९⟫. | ⟪स्तूयते⟫ | той се възхвалява | ⟪अस्तावि⟫ |
| ⟪२०⟫. | ⟪कृष्यते⟫ | се оре | ⟪अकर्षि⟫ |
| ⟪२१⟫. | ⟪जायते⟫ | той се ражда | ⟪अजनि⟫ |
| ⟪२२⟫. | ⟪गीयते⟫ | се пее | ⟪अगायि⟫ |
| ⟪२३⟫. | ⟪गम्यते⟫ | се ходи | ⟪अगामि⟫ |
