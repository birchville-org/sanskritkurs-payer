# Урок 31

## 31.1. 7-ти клас на настоящето време (⟪रुधादि⟫ = "⟪रुध्⟫ и т.н.")

::: grammar-box
**Образуване:**

**Пред изходящите съгласни на корена с ниска степен на гласност се вмъква т.нар. назален инфикс (-na- или -n-):**

*   **в силния корен: -na-**
*   **в слабия корен: -n-**

**За свързването на изходящите съгласни на корена с окончания, започващи със съгласна, важат същите правила, както за 2-ри клас на настоящето време.**
:::
Примери:

⟪युज्⟫ 7U "свързвам, впрягам"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Индикатив** | **3. ед.ч.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(vor Guttural im Wortinnern werden Nasale durch -ṅ- ersetzt) |
| | **3. мн.ч.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Оптим** | **3. ед.ч.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. мн.ч.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Partizip Сегашно време** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brfem.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "спiram, спра"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Индикатив** | **3. ед.ч.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. мн.ч.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Оптим** | **3. ед.ч.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. мн.ч.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Partizip Сегашно време** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brfem.: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**При някои корени -n- на слабия корен на настоящето време е проникнал и в непозитивните времена, поради което тези корени се започват с инфиксиран назал.**
:::
Пример:

**⟪भञ्ज्⟫** 7P "чупя"

::: indent
*   Индикатив за настояще време
    *   3.ед.ч.Н. **⟪भनक्ति⟫** (bha-na + j + ti)
    *   3.мн.ч.Н. **⟪भञ्जन्ति⟫** (bha + n + j-anti)
*   Бъдеще време: **⟪भङ्क्ष्यति⟫** (bha + n + j + sya + ti)
*   Страдателен залог: **⟪भज्यते⟫** (или от първоначалния корен **⟪भज्⟫**, или от *bhñj-ya-te)
*   PPP: **⟪भग्न⟫** (възможно от *bhñj + na)
:::
