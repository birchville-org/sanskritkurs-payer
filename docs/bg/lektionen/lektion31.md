# Урок 31

## 31.1. Седми клас на настоящето време (⟪रुधादि⟫ = "⟪रुध्⟫ и т.н.")

::: grammar-box
**Образуване:**

**Пред изходящите съгласни на корена в ниска степен се вмъква т.нар. назален инфикс (-na- или -n-):**

*   **в силната основа: -na-**
*   **в слабата основа: -n-**

**За свързването на изходящите съгласни на корена с окончания, започващи със съгласна, важат същите правила както за втория клас на настоящето време.**
:::
Примери:

⟪युज्⟫ 7U "свързвам, впрягам"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Индикатив** | **3. л., ед.ч.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(пред гутурални в средата на думата назалните се заменят с -ṅ-) |
| | **3. л., мн.ч.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Оптив** | **3. л., ед.ч.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. л., мн.ч.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Действително причастие** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brж.р.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "спiram, спрам"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |

| | **3. л., мн.ч.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Оптив** | **3. л., ед.ч.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |

:::
::: grammar-box
**При някои корени -n- на слабия настоящ корен е проникнало и в непросентичните времена, така че тези корени се анализират с инфиксен назал.**
:::
Пример:

⟪भञ्ज्⟫ 7P "чупя"

::: indent
*   Индикатив Презес
*   3.ед.Н. ⟪भनक्ति⟫ (bha-na + j + ti)
*   3.мн.Н. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Футур: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Пасив: ⟪भज्यते⟫ (или от първоначалния корен ⟪भज्⟫ или от *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (възможно от *bhñj + na)
:::
