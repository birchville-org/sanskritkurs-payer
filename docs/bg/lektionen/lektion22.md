# Урок 22

## 22.1. Абсолютивът (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

Ако искаме на санскрит да изразим, че действие на агенса (⟪कर्तृ⟫) предхожда друго действие на същия агент или го придружава като съпътстващо обстоятелство, използваме абсолютива (⟪क्त्वा । ल्यप्⟫). Следователно

"след като е направил това, той прави онова"; "той прави това, след което прави онова"; "в резултат на това той прави онова"; "доидох, видях и победих" и т.н.

Абсолютивът е глаголно наречие, т.е. той не се спряга и не се склонява, но винаги — с малки изключения — има същия агент (⟪कर्तृ⟫) като действието, на което предхождащото или съпътстващо действие от абсолютива е подчинено. Агентът на абсолютива стои в именителен (⟪प्रथमा⟫) или творителен падеж (⟪तृतीया⟫).

Освен съставните имена абсолютивът е едно от най-често срещаните изразни средства в санскрита.

При превод на немски език избягвайте да повтаряте постоянно "след като". Вместо това използвайте обичайните за немския език изразни средства за времева последователност.

**Схема:**

(по-точно определение за абсолютива: обстоятелствено определение, обект и т.н.) - Абсолютив - Абсолютив - ... - Абсолютив - ... Агент + глаголова част (в актив или пасив)

:::
**Примери:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = пасивна конструкция: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**
"Мъжът влиза в къщата, вижда малкото момиче и заговаря с него."

Множествено число: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. Образуване на абсолутита

::: grammar-box
**Образуване на абсолутита**

*   Глаголи без префикс: Абсолютит на **-tvā**
*   Глаголи с префикс: Абсолютит на **-ya** или **-tya**
:::
### 22.2.1. Глаголи без префикс: Абсолютит на -⟪त्वा⟫

::: grammar-box

**Образуване:**

(повечето случаи) корен в дълбока степен, в формата, която има преди PPP + **-tvā** (**-⟪त्वा⟫**)

Само отрицателното **a-** / **an-** съвместимо с суфикса **-⟪त्वा⟫** : ⟪अकृत्वा⟫ "след като не е направил"

:::
**Примери:**

::: indent
⟪आप्त्वा⟫ "след като той / тя / то / аз / ти / ние / вие / те / двамата / вас двамата / тях двамата е достигнал"

⟪आसित्वा⟫ "след като той (...) е седял"

⟪इत्वा⟫ "след като той (...) е ходил"

⟪स्थित्वा⟫ "след като той (...) е стоял"

⟪जित्वा⟫ "след като той (...) е победил"

⟪उक्त्वा⟫ "след като той (...) е говорил"
:::
### 22.2.2. Глаголи с префикс

#### 22.2.2.1. Корени с дълъг гласен (освен -ā) или със съгласна

::: grammar-box

**(повечето случаи) корен в дълбока степен + -ya**

:::
**Примери:**

::: indent
⟪उपनीय⟫ "след като той (...) е довел"

⟪प्रभूय⟫ "след като той (...) е излязъл" ; "след като той (... имал власт"

⟪प्राप्य⟫ "след като той (...) е постигнал"
:::
#### 22.2.2.2. Корени на -ā

::: grammar-box

**непроменен корен в висока степен + -ya**

:::
**Пример:**

::: indent
⟪उपस्थाय⟫ "след като той (...) е влязъл" ; (но без префикс: ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. Корени, които в дълбока степен завършват на късо -i, -u, -ṛ

::: grammar-box

**корен в дълбока степен + -tya**

:::
**Примери:**

::: indent
⟪प्रस्तुत्य⟫ "след като (...) възхвали силно / е възхвалявал"

⟪विस्मृत्य⟫ "след като (...) забрави / е забравил"

⟪संस्कृत्य⟫ "след като (...) подготви за жертвоприношението / е подготвял"
:::
#### 22.2.2.4. Корени на -am / -an, които в дълбока степен завършват на -a

::: grammar-box

**По желание:**

Корен на **-am** / **-an** + **-ya**

или:

Корен на **-a** + **-tya**

:::
**Пример:**

::: indent
⟪विगम्य⟫ или ⟪विगत्य⟫ "след като (...) измина / е изминал"
:::
