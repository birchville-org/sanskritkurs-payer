## 7.1. Глаголовото изречение с директен обект

::: grammar-box
**Схема:**
**(Агент = kartṛ м. = ⟪कर्तृ⟫) – директен обект (karman с. = ⟪कर्मन्⟫) – глагол**

напр.
**rāmaḥ phalaṃ khādati** = ⟪रामः फलं खादति⟫ : „Рама яде (кълва) плод.“
**brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो देवं यजति⟫ : „Брахманът почита бог с жертвоприношение (за друг).“
:::
Ако глаголът е в парасмаипада или атманепада, директният обект (**karman** с. = ⟪कर्मन्⟫) обикновено е в **винителен падеж** (Wenfall, dvitīyā ж. = ⟪द्वितीया⟫).

| :--- | :--- |

| **-ī**: devī | **devīm** :br⟪देवीम्⟫ |

:::

### 7.2.1. Акузатив единствено и множествено число на въпросителните и указателните местоимения

::: grammar-box
| || Мъжки род | Женски род | Среден род |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :brкой/какво | ед.ч. | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |
| | мн.ч. | **kān** :br⟪कान्⟫ | **kās** :br⟪कास्⟫ | **kāni** :br⟪कानि⟫ |
| **tad** :brтой/този/онзи | ед.ч. | **tam** :br⟪तम्⟫ | **tām** :br⟪ताम्⟫ | **tad** :br⟪तद्⟫ |
| | мн.ч. | **tān** :br⟪तान्⟫ | **tās** :br⟪तास्⟫ | **tāni** :br⟪तानि⟫ |
| **etad** :brтози тук | ед.ч. | **etam / enam** :br⟪एतम्⟫ / ⟪एनम्⟫ | **etām / enām** :br⟪एताम्⟫ / ⟪एनाम्⟫ | **etad / enad** :br⟪एतद्⟫ / ⟪एनद्⟫ |
| | мн.ч. | **etān / enān** :br⟪एतान्⟫ / ⟪एनान्⟫ | **etās / enās** :br⟪एतास्⟫ / ⟪एनास्⟫ | **etāni / enāni** :br⟪एतानि⟫ / ⟪एनानि⟫ |
| **idam** :brтози | ед.ч. | **imam / enam** :br⟪इमम्⟫ / ⟪एनम्⟫ | **imām / enām** :br⟪इमाम्⟫ / ⟪एनाम्⟫ | **idam / enad** :br⟪इदम्⟫ / ⟪एनद्⟫ |
| | мн.ч. | **imān / enān** :br⟪इमान्⟫ / ⟪एनान्⟫ | **imās / enās** :br⟪इमास्⟫ / ⟪एनास्⟫ | **imāni / enāni** :br⟪इमानि⟫ / ⟪एनानि⟫ |
:::
Формите **enam** (⟪एनम्⟫) и т.н. принадлежат към основата **enad** (⟪एनद्⟫), която образува форми само в някои падежи. Те се използват вместо формите на **etad** и **idam**, когато означаваното вече е споменато в предходния текст.
напр. **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं देवः⟫ | ⟪एनं यजन्ते⟫ || : "Той е бог. Му се принася жертва."


### 7.2.2. Употребата на винителен падеж (dvitīyā f. = ⟪द्वितीया⟫ = "второ падежно окончание")

::: grammar-box
Винителният падеж (dvitīyā f. = ⟪द्वितीया⟫) означава:
1. В не-пасивното глаголно изречение: **директния обект** (karman n. = ⟪कर्मन्⟫) на действието, изразено от глагола:
напр.
**devaṃ yajati** = ⟪देवं यजति⟫ : "Той почита бог с жертва."
**phalam āpnoti** = ⟪फलमाप्नोति⟫ : "Той постига плода (напр. на своето действие)."
2. При глаголи, които изразяват ходене, движение, водене или подобно нещо към някое място, винителният падеж означава целта на движението:
напр.
**narakaṃ gacchati** = ⟪नरकं गच्छति⟫ : "Той отива в ада."
:::
Други употреби на винителния падеж ще бъдат разгледани по-късно.



## 7.3. Сандхи на крайното -n

::: grammar-box
**Крайно -n:**

1. Преди звънки палатни и ретрофлексни sparśa и пред **ś-** се заменя с назалния съответстващ на тези звуци:
**-n** пред **j-, jh-, ñ-, ś-** » **-ñ**
**-n** пред **ḍ-, ḍh-, ṇ-, ṣ-** » **-ṇ**
напр. **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "Той побеждава кшатриите."
Началното **ś-** се заменя обикновено с **ch-**:
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (заедно с gurūñ śṛṇoti) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "Той чува учителите." "Той слуша учителите."

2. Ако пред начално **l-** стои **-l** с Ануна́сика (назализирано l, в писмеността ⟪ल्⟫ с Ануна́сика ⟪ँ⟫), се заменя:
напр. **paśūn + labhate** » ⟪पशूंल्लभते⟫ : „Получава добитък.“

3. Пред начално беззвучен палатал, ретрофлекс или дентал се заменя чрез **Анусвара** + съответстващия на тези звукове шипящ звук:
**-n** пред **c-, ch-** » **-ṃś**
**-n** пред **ṭ-, ṭh-** » **-ṃṣ**
**-n** пред **t-, th-** » **-ṃs**
напр. **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : „и боговете (винителен падеж)“
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : „но боговете (винителен падеж)“

4. Освен след кратка гласна (вж. по-долу) крайното **-n** във всички останали случаи остава непроменено.
:::

## 7.4. Среден род (napuṃsaka n. = ⟪नपुंसक⟫)

::: grammar-box
**В средния род формите за именителен (prathamā) и винителен падеж (dvitīyā) са идентични.**
:::
### 7.4.1. Среден род на основите на -a

::: grammar-box
**Спряжение именителен / винителен единствено число: -m**
напр. **phala** n. = ⟪फल⟫ = „плод“: Имен. / Винителен ед. ч. **phalam** = ⟪फलम्⟫
**Спряжение именителен / винителен множествено число: -āni**
напр. **phala** n. = ⟪फल⟫: Имен. / Винителен мн. ч. **phalāni** = ⟪फलानि⟫
:::

## 7.5. Атематични класове на настоящето

Петата класа на настоящето образува т.нар. атематична основа за настояще, т.е. основата на настоящето не завършва с „тематичната гласка“ **-a**, както при тематичните класове на настоящето (1., 4., 6., 10. класа).

::: grammar-box
**Атематичните класове на настоящето имат градиране на основата, т.е. съществуват две форми на основата за настояще:**
1. **силен ствол**: висока степен (рядко удължена степен)
2. **слаб ствол**: ниска степен

**Силният корен стои:**
в индикатив единствено число Парасмаипада Настояще време (laṭ) и Имперфект (laṅ)
на всички първи лица на императив (loṭ) Парасмаипада и Атманепада
в трето лице единствено число императив (loṭ) Парасмаипада

**Всички други форми имат слабия настоящ корен.**
:::
### 7.5.1. Първични окончания на трето лице множествено число при безгласни корени

::: grammar-box
**При безгласни настоящи корени първичните окончания на трето лице множествено число са:**
**Парасмаипада: -anti**
**Атманепада: -ate**
:::
### 7.5.2. Петият клас на настоящите времена (svādi = ⟪स्वादि⟫ = "su и т.н.")

::: grammar-box
**Силен корен**: (повечето пъти) ниско степенуване на основата (както е посочено) + **-no-**
**Слаб корен**: (повечето пъти) ниско степенуване на основата (както е посочено) + **-nu-**

**Преди гласникови окончания, при корени, завършващи на гласна, -nu- се заменя с -nv-, а при корени, завършващи на съгласна, преди гласникови окончания -nu- се заменя с -nuv-.**
:::
**Примери:**

| Основа:br⟪धातु⟫ | Силен корен | Слаб корен | Преди гласна:br(слаб) |
| :--- | :--- | :--- | :--- |
| **āp** :br5 P:br⟪आप्⟫:br"достигна" | **āp-no** :br(3.ед.ч. āpnoti = ⟪आप्नोति⟫) | **āp-nu** | **āp-nuv** :br(3.мн.ч. āpnuvanti = ⟪आप्नुवन्ति⟫) |
| **aś** :br5 Ā:br⟪अश्⟫:br"достигна" | — | **aś-nu** :br(3.ед.ч. aśnute = ⟪अश्नुते⟫) | **aś-nuv** :br(3.мн.ч. aśnuvate = ⟪अश्नुवते⟫) |
| **su** :br5 U:br⟪सु⟫:br"изстисвай" | **su-no** :br(3.ед.ч. sunoti = ⟪सुनोति⟫) | **su-nu** :br(3.ед.ч. sunute = ⟪सुनुते⟫) | **su-nv** :br(3.мн.ч. sunvanti = ⟪सुन्वन्ति⟫,:br3.мн.ч. sunvate = ⟪सुन्वते⟫) |
| **śru** :br5 P:br⟪श्रु⟫:br"чуя" | **śṛ-ṇo** :br(3.ед.ч. śṛṇoti = ⟪शृणोति⟫) | **śṛ-ṇu** | **śṛ-ṇv** :br(3.мн.ч. śṛṇvanti = ⟪शृण्वन्ति⟫) |
