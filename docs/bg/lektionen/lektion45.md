## 45.2. Волативът единствено число (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**Повечето волативи на единствено число са коренът с висока степен на изход.**

напр. **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** и т.н.

**Изключения са женските родове на -ā и -ī както и корените на -in, чиито волативи sg. трябва да се запомнят особено.**
:::
::: no-header
| | Волатив единствено число |
| --- | --- |
| Мъжки родове на -a | ⟪देव⟫ |
| Среден род на -a | ⟪फल⟫ |
| Женски родове на -ā | ⟪देवते⟫ |
| Мъжки родове на -i | ⟪कवे⟫ |
| Женски родове на -i | ⟪मते⟫ |
| Мъжки родове на -u | ⟪शत्रो⟫ |
| Женски родове на -u | ⟪धेनो⟫ |
| Женски родове на -ī | ⟪देवि⟫ |
| Мъжки родове на -ṛ | ⟪पितर्⟫ |
| Женски родове на -ṛ | ⟪मातर्⟫ |
| Мъжки родове на -an | ⟪राजन्⟫ |
| Среден род на -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Мъжки родове на -man/-van | ⟪आत्मन्⟫ |
| Мъжки родове на -in | ⟪बलिन्⟫ |
| Мъжки родове на -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt m. | ⟪महन्⟫ |
| mahānt n. | ⟪महत्⟫:br= Nominativ |
| Мъжки родове на -mant/-vant | ⟪गुणवन्⟫ |
| Среден род на -mant/-vant | ⟪गुणवत्⟫:br= Nominativ |
| Местоимения | не се образува волатив
:::

## 45.3. Речник на думите

## 45.4. Упражнение

A) Преведете на санскрит (за минало време моля използвайте имперфекта ⟪लङ्⟫):

1. Ти разделяш (будистката) общност.

::: indent
за разделянето на общността (⟪सङ्घभेद⟫) вижте:

**Payer, Alois (1944–):** Vinayamukha : Основни понятия на монашеските правила и орденското право на Тхеравада. -- Част I. -- (Материали за основните понятия на будизма). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::
2. Насладихте ли се на земята?

3. Приехте ли дар от краля?

4. Свещениче, защо не се страхуваш от опасностите?

5. Татко, защо напускаш семейството си?

6. Шудра-жена, носихте ли товара в дома на богатия брахман?

7. Богиньо, ти трябваше да изпълниш желанието за щастие на вайшията, който е извършил заслуги.

8. Слонове, вие не трябва да чупите оковите.

9. Ти, мъже подобен на лъв, защо не насочваш цялото си внимание към Абсолюта (Брахман)?

10. Поет, измерил ли си светове?

B) Преведете:

⟪अर्जुन हतो वा प्राप्स्यसि स्वर्गं जित्वा वा भोक्ष्यसे महीं । तस्माद्भवता योध्यम् ॥१॥ भवति कथमनन्तदुःखमरुणत् ॥२॥ ब्राह्मण किमग्नौ घृतमजुहोः ॥३॥ शत्रो शस्तेण जीवं न छिनत्सि ॥४॥⟫
