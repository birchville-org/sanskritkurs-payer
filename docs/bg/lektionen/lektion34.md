# Урок 34

## 34.1. Перфектът (⟪लिट्⟫)

В класическото санскрит има само индикатив и причастие от перфектния корен.

::: grammar-box
**Има два вида образуване на перфект:**
*   **редуплициран перфект = ⟪द्वित्वलिट्⟫**
*   **перифразен перфект = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Перифразният перфект (⟪अनुप्रयोगलिट्⟫) се използва:**
1. **при производните спряжения (каузатив, десидератив, фрекватив, номинални)**
2. **при корени, които започват с дълъг гласен (освен ā-) или с гласен (освен a-) пред две съгласни**
3. **при някои други корени**
:::
## 34.2. Редуплицираният перфект (⟪द्वित्वलिट्⟫)

### 34.2.1. Степенуване на корена

::: grammar-box
**Образуване:**

**силен корен:** единствено число Парасмаипада
*   **редуплициран висшестепенен или удължен корен + перфектно окончание**

**слаб корен:** всички останали форми
*   **редуплициран нискостепенен корен + перфектно окончание**
:::
::: grammar-box
**Общо (и извън перфекта) не подлежат на степенуване корените от вида:**
*   **(съгласна)-Съгласна-ДълъгГласен-Съгласна**
*   **(съгласна)-Съгласна-Гласен-Съгласна-Съгласна**

**В перфекта освен това не подлежат на степенуване корените от вида:**
*   **a-Съгласна**
*   **ā-Съгласна**
:::
### 34.2.2. Перфектни окончания

::: grammar-box

| | 3. ед.ч. | 3. мн.ч. |
| :--- | :--- | :--- |
| **Парасмаипада** | **-a** | **-ur** |
| **Атманепада** | **-e** | **-re** |

:::
### 34.2.3. Свързващ гласен -i-

::: grammar-box
**Преди окончанието на 3.мн.ч.Ат (-re) винаги се появява свързващият гласен -i-, преди другите съгласно започващи окончания при множеството на корените.**
:::
### 34.2.4. Редупликация на корени, започващи с съгласна

::: grammar-box
**За редупликацията на началните съгласни важат правилата, дадени в [Урок 33](lektion33.md).**

**Редупликационната гласна при корени, започващи с съгласна, е кратката коренова гласна.**

**Дифтонгите пред съгласни се редукцират до съответната кратка гласна от ниската степен.**

**ṛ, ṝ, ḷ и крайните дифтонги се редуплицират чрез -a-.**
:::
Примери:

::: grammar-box

| Корен | 3. л., ед.ч., аорист, деятелно наклонение |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::
::: grammar-box
**Някои корени, започващи с y- или v-, се редуплицират съответно с i- и u-, които в слабите форми „сливат“ с кореновата гласна.**
:::
Примери:

::: grammar-box

| Корен | 3. л., ед.ч., аорист, деятелно наклонение | 3. л., мн.ч., аорист, деятелно наклонение |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Редупликация на корени, започващи с гласна

::: grammar-box
**1. Началното a-, ā- се редуплицира с a-, така че се появява ā-.**
:::
Примери:

::: grammar-box

| Корен | 3. л., ед.ч., аорист, деятелно наклонение |
| :--- | :--- |
| ⟪अस्⟫ 2 „бъда“ и ⟪अस्⟫ 4 „хвърлям“ | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. Корените с начално i- имат като редупликационна сричка в силния корен iy-, а в слабия корен i-, която „слива“ с кореновата гласна до ī-. Аналогично важи и за началното u-.**
:::
Примери:

::: grammar-box

| Корен | 3. л., ед.ч., аорист, деятелно наклонение | 3. л., мн.ч., аорист, деятелно наклонение |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. Корени, които започват с a- пред две съгласни или с ṛ-, имат като редупликационна сричка ān-**
:::
Примери:

::: grammar-box

| Корен | 3. л., ед.ч., аорист, деят. | 3. л., мн.ч., аорист, деят. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. Типове на редуплицирания перфект

Критерий за класификация: Особености на степенуването на основата:
*   Перфект без стеменно степенуване: Тип I
*   Перфект със стемено степенуване: Тип II - V
*   Нерегулярни перфектни форми

## 34.4. Перфект Тип I: Перфект без стемено степенуване

::: grammar-box
**Перфект Тип I (без стемено степенуване) имат корени от типовете:**
*   **(Съгласна)-Дълъг гласен-Съгласна**
*   **(Съгласна)-Кратък гласен-Съгласна**
*   **a-Съгласна**
*   **ā-Съгласна**
:::
Примери:

::: grammar-box

| Корен | 3. л., ед.ч., перфект, деят. | 3. л., мн.ч., перфект, деят. |
| :--- | :--- | :--- |
| ⟪बन्ध्⟫ 9P | ⟪बबन्ध⟫:brba-bandh-a | ⟪बबन्धुर्⟫ |
| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |
| ⟪आप्⟫ 5P | ⟪आप⟫:bra + āp-a | ⟪आपुर्⟫ |
| ⟪अस्⟫ 2P "бъда":br⟪अस्⟫ 4 "хвърля" | ⟪आस⟫:bra + as-a | ⟪आसुर्⟫ |
| ⟪अश्⟫ | ⟪आनशे⟫:brнерегулярна редупликация! | ⟪आनशिरे⟫ |

:::
## 34.5. Перфект Тип II: силна основа в висша степен, слаба основа в ниска степен

::: grammar-box
**Образува се от корени с форма:**
*   **(Съгласна)-(Съгласна)-i/u/ṛ/ḷ-Съгласна**

**Образуване:**
*   **силна основа: висша степен**
*   **слаба основа: ниска степен**
:::
Примери:

::: grammar-box

| Корен | 3. л., ед.ч., перфект, деят. | 3. л., мн.ч., перфект, деят. | 3. л., ед.ч., перфект, страд. | 3. л., мн.ч., перфект, страд. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪भिद्⟫ | ⟪बिभेद⟫ | ⟪बिभिदुर्⟫ | ⟪बिभिदे⟫ | ⟪बिभिदिरे⟫ |
| ⟪इष्⟫ | ⟪इयेष⟫ | ⟪ईषुर्⟫ | | |
| ⟪मुच्⟫ | ⟪मुमोच⟫ | ⟪मुमुचुर्⟫ | ⟪मुमुचे⟫ | ⟪मुमुचिरे⟫ |
| ⟪वृत्⟫ | | | ⟪ववृते⟫ | ⟪ववृतिरे⟫ |
| ⟪कॢप्⟫ | | | ⟪चकॢपे⟫ | ⟪चकॢपिरे⟫ |

:::
