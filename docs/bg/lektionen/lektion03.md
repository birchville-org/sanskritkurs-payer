# Урок 3

## 3.1. Именителен падеж, единствено число на женски род

### 3.1.1. Именителен падеж, единствено число с окончание -s

Следните именни основи, които завършват на гласна, също образуват именителен падеж, единствено число с окончание **-s**:

::: grammar-box
**Женски род на основа -i**: напр. **śruti** ж. "слушане" -- Именителен падеж, ед.ч.: **śrutis** = ⟪श्रुतिस्⟫
**Женски род на основа -u**: напр. **dhenu** ж. "крава" -- Именителен падеж, ед.ч.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Именителен падеж, единствено число без окончание

Именителен падеж, единствено число се образува без окончание:

::: grammar-box
**Женски род на основа -ā**: напр. **devatā** ж. "божество" -- Именителен падеж, ед.ч.: **devatā** = ⟪देवता⟫
**Женски род на основа -ī**: напр. **devī** ж. "богиня" -- Именителен падеж, ед.ч.: **devī** = ⟪देवी⟫
:::
::: important
**Внимание!** Освен това съществуват едносрични женски коренови имена на основа -ī, чийто именителен падеж, единствено число завършва на -s: напр. dhī ж. "мисъл" -- Именителен падеж, ед.ч.: dhīs = ⟪धीस्⟫. Също lakṣmī (⟪लक्ष्मी⟫) ж., tarī (⟪तरी⟫) ж. "лодка" и tantrī (⟪तन्त्री⟫) ж. "струна" образуват неправилно именителен падеж, единствено число с окончание -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Образувание на женски род от мъжки род

::: grammar-box
**Мъжки род на основа -a:**
**Женски род на основа -ā**: напр. **kṣatriya** м. » **kṣatriyā** ж. "кшатрийка" = ⟪क्षत्रिया⟫
**Женски род на основа -ī**: напр. **brāhmaṇa** м. » **brāhmaṇī** ж. "брахманка" = ⟪ब्राह्मणी⟫

**Мъжки род на основа -u:**
**Женски род на основа -ī**: напр. **sādhu** м. » **sādhvī** ж. (добра, светия) = ⟪साध्वी⟫
(**-u-** става **-v-** пред гласна, следователно **-u- + -ī** » **-vī**)
:::

## 3.3. Именителен падеж, множествено число на мъжки и женски род

::: grammar-box
Окончанието на именителен падеж, множествено число при мъжки и женски род е **-as**.
**Мъжки род на основа -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
**Женски род на основа -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**Мъжки род на основа -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**Женски род на основа -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**Женски род на основа -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**Мъжки род на основа -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**Женски род на основа -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Бележка: **e** е повишена степен (**guṇa**) на **i**, **o** е повишена степен на **u**.


## 3.4. Вокален сандхи

::: grammar-box
**Простите гласни, които се различават само по дължина или изобщо не се различават, „сливат“ в съответния дълъг гласен:**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)
:::
напр.

devatā + annapūrṇā » devatānnapūrṇā „Annapūrṇā е божество“ = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā е богинята на храната и готвенето, тя се счита за въплъщение на Pārvatī, съпругата на Śiva.)

devī + indrāṇī » devīndrāṇī „Indrāṇī е богиня“ = ⟪देवीन्द्राणी⟫

> (Indrāṇī е съпругата на бога Indra.)

:::

::: grammar-box
**Простите гласни (освен -a / -ā) се заменят с съответния полугласен пред несходни гласни:**
i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**
(!! За това правило има изключения, особено за двойствено число !!)
:::
напр.

devī + umā » devy umā „Umā е богиня“ = ⟪देव्युमा⟫

> (Umā е име за Pārvatī, съпругата на Śiva)

::: grammar-box
**-a / -ā пред несходен гласен:**
a / -ā + i- / ī- » **-e-**
a / -ā + ṛ- » **-ar-**
a / -ā + e- / ai- » **-ai-**
a / -ā + o- / au- » **-au-**
:::

## 3.5. Сандхи на изречението за -ās

::: grammar-box
**-ās се заменя с -ā пред всички звънки звуци.**
:::
напр.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ „Вайшъите са двапородени“ = ⟪द्विजा वैश्याः⟫


## 3.6. Речник

**Заучете следните думи:**

**śruti** ж. р. = ⟪श्रुति⟫ : слушане, вечното предаване (наименование за Ведите и Брахманите).

**smṛti** ж. р. = ⟪स्मृति⟫ : присъствено осмисляне, памет, медитативно присъствено осмисляне = внимателност, предаване (противоположност на **śruti**). Включва:
шестте **vedāṅga** ср. р. (⟪वेदाङ्ग⟫)
1. **śikṣā** ж. р. (⟪शिक्षा⟫): правилно произношение
2. **chandas** ср. р. (⟪छन्दस्⟫): метър
3. **vyākaraṇa** ср. р. (⟪व्याकरण⟫): граматика
4. **nirukta** ср. р. (⟪निरुक्त⟫) : етимология
5. **jyotiṣa** ср. р. (⟪ज्योतिष⟫) : астрономия, календарно учение
6. **kalpa** м. р. (⟪कल्प⟫) : церемониал
**śrautasūtra** ср. р. (⟪श्रौतसूत्र⟫) : учебници за извършването на големите жертвоприношения
**gṛhyasūtra** ср. р. (⟪गृह्यसूत्र⟫) : учебници за церемониите и жертвоприношенията на ежедневния живот
**dharmasūtra** ср. р. (⟪धर्मसूत्र⟫) и **dharmaśāstra** ср. р. (⟪धर्मशास्त्र⟫) : учебници за правото и обичая (правилно поведение)
големите епоси **mahābhārata** ср. р. (⟪महाभारत⟫) и **rāmāyaṇa** ср. р. (⟪रामायण⟫)
**purāṇa** мн. р. (⟪पुराण⟫)
**nītiśāstra** ср. р. (⟪नीतिशास्त्र⟫) : учебници за жизната мъдрост

**smṛti** е особено също наименование за учебници по дхарма.

**dhenu** f. = ⟪धेनु⟫ : (млечна) крава.

**paśu** m. = ⟪पशु⟫ : одомашнено стопанско животно, добитък (колективно).

**devatā** f. = ⟪देवता⟫ : божество (абстрактно и конкретно).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : брахманка.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : жена от кшатрийската варна.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : съпруга на кшатрий.

**vaiśyā** f. = ⟪वैश्या⟫ : жена от вайшиевската варна.

**śūdrā** f. = ⟪शूद्रा⟫ : жена от шудърската варна.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : съпруга на шудра.

**devī** f. = ⟪देवी⟫ : богиня, особено Durgā f. = ⟪दुर्गा⟫, съпругата на Śiva = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
Ил.: Durgā = ⟪दुर्गा⟫, Ориса
(Източник на изображението: [Подробности](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : женски род на sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : женски род на guru.

**asmitā** f. = ⟪अस्मिता⟫ : „аз-айство“, т.е. (грешното) вярване: **Аз** съм този, който вижда и т.н.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : философия (науката, която стига до своите заключения чрез логически правилни обосновки).

**upekṣā** f. = ⟪उपेक्षा⟫ : пренебрегване, безразличие.

**karuṇā** f. = ⟪करुणा⟫ : съчувствие, милост.

**muditā** f. = ⟪मुदिता⟫ : радост, особено съучастие в чуждата радост (противоположност на завистта).


## 3.7. Упражнение

**A) Преобразувайте следните изречения в множествено число:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**Б) Образувате номинативни изречения чрез попълване:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**В) Преобразувайте в женски род:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**Г) Преведете на санскрит:**

1. Ума е богиня.
2. Ведата ешрути.
3. Учителките са богини.
4. Млечните крави са одомашнени животни.
5. Поетите са учители.
6. Кшатриите са дваж родени.
7. Свещените мъже са шудри.
