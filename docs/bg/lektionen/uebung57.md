# Упражнение 57

## A) Аорист-трансформации

Превете и определете следните форми, както и образувайте съответните форми на **аориста**. Освен при каузативите и корените, които образуват **s-аорист**, в скоби е посочен класът на съответния аорист:

::: grammar-box
| № | Форма | Определение / Значение | Аорист |
|:---|:---|:---|:---|
| १. | **पेचिथ** | *पच्* 1U: 2. ед. перф. нар. (ти се радваше) | **अपाक्षीः** |
| २. | **अवक्** (३) | *वच्* 2М: 2. 3. ед. импф. нар. (ти каза / той каза) | **अवोचः / अवोचत्** |
| ३. | **सोष्यसि** | *सु* 1/2М: 2. ед. фют. нар. (ти ще се размножиш) | **असौषीः** |
| ४. | **छिन्दे** | *छिद्* 7U: 1. ед. инд. пр. а. (аз отрезах) | **अच्छित्सि** |
| ५. | **कुरुषे** | *कृ* 8U: 2. ед. инд. пр. а. (ти постъпваш в свой интерес) | **अकृथाः** |
| ६. | **आधत्ते** | *आ-धा* 3а: 3. ед. инд. пр. а. (той поставя) | **आधित** |
| ७. | **पद्यते** | *पद्* 4а: 3. ед. инд. пр. а. (той отива) | **अपादि** |
| ८. | **जिगाय** | *जि* 1М: 1. 3. ед. перф. нар. (аз победих / той победи) | **अजैषीत्** |
| ९. | **जिघ्रामः** (१,६) | *घ्रा* 1М: 1. мн. инд. пр. нар. (ние миришем) | **अघ्रास्म / अघ्राम** |
| १०. | **शासति** (२) | *शास्* 2М: 3. мн. инд. пр. нар. (те заповядват) | **अशिषन्** |
| ११. | **स्तुवे** | *स्तु* 2U: 1. ед. инд. пр. а. (аз възхвалявам) | **अस्तोषi** |
| १२. | **दिग्धे** | *दिह्* 2U: 3. ед. инд. пр. а. (той намазва) | **अदिग्ध** |
| १३. | **प्लवध्वे** | *प्लु* 1а: 2. мн. инд. пр. а. (вие плувате) | **अप्लोढ्वम्** |
| १४. | **तस्थिथ** (१) | *स्था* 1М: 2. ед. перф. нар. (ти стоеше) | **अस्थाः** |
| १५. | **बिभ्यति** | *भी* 3М: 3. мн. инд. пр. нар. (те се боят) | **अभैषुः** |
| १६. | **ततर्प** | *तृप्* 4/6М: 1. 3. ед. перф. нар. (аз / той насити) | **अतार्प्सीत् / अत्राप्सीत्** |
| १७. | **जुहुथ** | *हु* 3М: 2. мн. инд. пр. нар. (вие принасяте жертва) | **अहौष्ट** |
| १८. | **ऊषुः** | *वस्* 1М: 3. мн. перф. нар. (те живяха) | **अवात्सुः** |
| १९. | **ससर्जिथ** | *सृज्* 6М: 2. ед. перф. нар. (ти създаде) | **अस्राक्षीः** |
| २०. | **लिल्यिरे** | *ली* 4а: 3. мн. перф. а. (те се притискат) | **अलेषत / अलासत** |
| २१. | **अत्याजयम्** | *त्यज्* 1М: 1. ед. импф. нар. кауз. (аз оставих да напусне) | **अतित्यजम्** |
| २२. | **सिध्यथ** (२) | *सिध्* 4М: 2. мн. инд. пр. нар. (вие сте в целта) | **असिधत** |
| २३. | **निन्य** | *नी* 1U: 2. мн. перф. нар. (вие сте водили) | **अनैष्ट** |
| २४. | **कर्षन्ति** | *कृष्* 1М: 3. мн. инд. пр. нар. (те се движат) | **अकार्क्षुः / अक्राक्षुः** |
| २५. | **अप्रच्छयन्** | *प्रच्छ्* 6М: 3. мн. импф. нар. кауз. (те оставиха да питат) | **अपप्रच्छन्** |
:::

## Б) Определения на думите

Определете и преведете следните форми:

::: grammar-box
| № | Форма | Определение / Значение |
|:---|:---|:---|
| १. | **चेलुः** | *चल्* 1P: 3. мн. ч. Пр. пр. вр. (те са се раздвижили) |
| २. | **जन्तुः** | *जन्तु* м.: Им. ед. ч. (създанието, хората) |
| ३. | **अश्वसीत्** | *श्वस्* 2P: 3. ед. ч. Непр. пр. вр. (той духнал) |
| ४. | **ज्येष्ठायाः** | *ज्येष्ठ*: Род. Исх. ед. ч. ж. (от най-добрите / най-възрастните) |
| ५. | **संयक्** | правилно (наречие) |
| ६. | **असे** | *असि* м.: Зв. ед. ч. (мече!) |
| ७. | **असि** | *अस्* 2P: 2. ед. ч. Пр. пр. вр. (ти си) |
| ८. | **अचैष्ट** | *चि* 5U: 3. ед. ч. s-аор. Ā. (той е наредил) |
| ९. | **अचेष्ट** | *चि*: s-аор. Ā. (корекция: s-аор. Ā. както по-горе) |
| १०. | **अभग्नम्** | *अ-* + PPP от *भञ्ज्* 7P: Им. Вин. ед. ч. ср.; Вин. ед. ч. м. (неразбит) |
| ११. | **भस्म** | *भस्मन्* ср.: Им. Вин. ед. ч. (пепелта) |
| १२. | **हवींषि** | *हविस्* ср.: Им. Вин. Зв. мн. ч. (подношенията) |
| १३. | **अद्राक्षीः** | *दृश्* 4P: 2. ед. ч. s-аор. пр. вр. (видя) |
| १४. | **शनैः** | бавно, постепенно (наречие) |
| १५. | **अपन्थाः** | *अ-पथ्* м.: Им. Зв. ед. ч. (не-пътят) |
| १६. | **शत्रुह** | *शत्रुहन्*: Им. Вин. ед. ч. ср. (убиеца на враговете) |
| १७. | **उदासीне** | *उदासीन*: Мест. ед. ч. м. ср.; Зв. ед. ч. ж.; Им. Вин. Зв. дв. ч. ср. ж. |
| १८. | **कनीयान्** | Степенителна степен м. Им. ед. ч. (по-малкият) |
| १९. | **कन्याम्** | *कन्या* ж.: Вин. ед. ч. (момичето) |
| २०. | **आरम्** | *ऋ* 1/9P: 1. ед. ч. a-аор. пр. вр. (отидох) |
| २१. | **रिपू** | *रिपु* м.: Им. Вин. Зв. дв. ч. (двата врага) |
| २२. | **अदात्** | *दा* 3U: 3. ед. ч. Коренен аор. пр. вр. (той дал) |
| २३. | **आदत्** | *अद्* 2P: 3. ед. ч. Непр. пр. вр. (той ял) |
| २४. | **अवोढ** | *वह्* 1U: 3. ед. ч. s-аор. Ā. (той пътувал); *अ-वह्*: Зв. ед. ч. м. ср. |
| २५. | **अवोचम्** | *वच्* 2P: 1. ед. ч. a-аор. пр. вр. (говорих) |
| २६. | **दिक्** | *दिश्* ж.: Им. ед. ч. (посоката) |
| २७. | **शुनोः** | *श्वन्* м.: Род. Мест. дв. ч. (кучетата) |
| २८. | **यते** | *यति* м.: Зв. ед. ч.; *यम्* 1P: PPP Мест. ед. ч. м. ср.; *यत्* 1Ā: 1. ед. ч. Пр. пр. вр. Ā. |
| २९. | **येते** | *यत्* 1Ā: 1. 3. ед. ч. Пр. пр. вр. Ā. (стремех се / той стремеше) |

| ३४. | **ते** | *त्वम्*: Дат. Род. енклит.; *तद्*: Им. мн. ч. м.; Им. Вин. дв. ч. ж. ср. |
| ३५. | **रजसि** | *रजस्* ср.: Мест. ед. ч. (в светлината) |
| ३६. | **रजसी** | *रजस्* ср.: Им. Вин. Зв. дв. ч. (двете светлини) |

| ३८. | **युष्मत्** | *युष्मद्*: Исх. мн. ч. (от вас) |
| ३९. | **अघम्** | *अघ* ср.: Им. Вин. Зв. ед. ч. (злото); Вин. ед. ч. м. (лошия) |
| ४०. | **अभुक्थाः** | *भुज्* 7U: 2. ед. ч. s-аор. Ā. (изял си) |
| ४१. | **उत्थानाय** | *उत्थान* ср.: Дат. ед. ч. (вставането) |
| ४२. | **अलुम्पत** | *लुप्* 6U: 2. мн. ч. Непр. пр. вр. пр. / 3. ед. ч. Непр. пр. вр. Ā. |

| ४३. | **अलुपत** | *लुप्* 6U: 2. мн. ч. a-аор. пр. (вие разбихте) |
| ४४. | **अलुप्त** | *लुप्* 6U: 3. ед. ч. s-аор. пр. (той се разби) |
| ४५. | **अलुप्तम्** | *अ-* + ППМ от *लुप्*: Именителен, винителен ед. ч. ср. род; винителен ед. ч. м. род. |

| ४७. | **वर्षिष्ठे** | Превъзходна степен на *वृद्ध*: местен ед. ч. м. ср. род; звателен ед. ч. ж. род; именителен, винителен двойствено число ср. ж. род. |
| ४८. | **अक्षैष्म** | *क्षि* 1/5/9П: 1. мн. ч. s-аор. пр. (ние унищожихме) |
| ४९. | **अहृत** | *हृ* 1U: 3. ед. ч. s-аор. пр. (той задържа) |
| ५०. | **कामधुग्भिः** | *कामदुह्* ж. род: творителен мн. ч. (чрез крави-давателни на желанията) |
| ५१. | **अमुत्र** | там (наречие) |
| ५२. | **पत्युः** | *पति* м. род: отделителен, притежателен ед. ч. (на съпруга) |
| ५३. | **क्षेपीयन्** | Сравнителна степен на *क्षिप्र*: звателен ед. ч. м. род (много бързи!) |
| ५४. | **आदिषि** | *आ-दा* 3П: 1. ед. ч. s-аор. пр. (аз взех) |
| ५५. | **पाणी** | *पाणि* м. род: именителен, винителен, звателен двойствено число (двете ръце) |
| ५६. | **अस्प्राक्षम्** | *स्पृश्* 6П: 1. ед. ч. s-аор. пр. (докоснах) |
