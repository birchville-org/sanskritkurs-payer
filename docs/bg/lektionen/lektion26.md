# Урок 26

## 26.1. Закон за церебрализация на -s- в средата на думата

::: grammar-box
**-s-** се заменя с **-ṣ-**, когато **k, r, l** или гласен — освен **a, ā** — предхожда непосредствено или само разделени от ⟪अनुस्वार⟫ или ⟪विसर्ग⟫ и следва друг звук освен **ṛ, r**.

Този сандхи следва също и **⟪दुस्⟫-** пред беззвучни гърлени и устни в съставни думи.
:::
*Примери:*
::: indent
⟪तेषाम्⟫ (от: *te-sām*)

но: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. Закон за церебрализация на дентални в средата на думата

::: grammar-box
Денталните спирали се заменят с съответните ретрофлексни след ретрофлекси (включително **-ṣ-**):

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** поради предхождащото **i**, **ṭh** поради следващото тогава **ṣ**)*
:::
## 26.3. Сандхи на думи за палатални, гърлени, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

Примери вижте по-долу
:::
## 26.4. Закон за дисимилиране на аспирацията на Грасман

::: grammar-box
**Непосредствената последователност на две аспирати (аспирата - гласна - аспирата) води до загуба на аспирация при първия звук:**

Пример:

:::
::: indent
\*dhu(gh) » du(g)h
:::
**Ако поради звукови закони вторият звук загуби аспирацията си, тогава аспирация се появява отново при първия звук.**

Примери: вижте по-долу бъдеще време на  ⟪दुह्⟫ и  ⟪बुध्⟫

## 26.5. Вортсандхи за -m, -n пред швиляса (звучни)

::: grammar-box
**Пред швилясите -n и -m се заменят с -ṃ-:**

Пример: вж. по-долу за бъдещето време на ⟪मन्⟫
:::
## 26.6. Употреба на простото бъдеще време (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ж.р.)

::: grammar-box
**Простото бъдеще време (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ж.р.) изразява:**

**бъдещето**
**предполагаемо или желано действие ("аз ще отида", "искам да отида")**
**очакване ("ще стане така")**
**надежда**
**притеснение**
**вероятност**
**мнение на говорещия**
**заповед**

**Бъдещето време частично конкурира с оптивата (виж по-късно).**
:::
напр. ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = "Некой, който иска да направи обет, отива в храма."

## 26.7. Образувание на простото бъдеще време (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ж.р.)

::: grammar-box
**Просто бъдеще време:**

:::
::: indent
**Основа на бъдещето време + първични окончания**
:::
::: grammar-box
**Основа на бъдещето време:**

:::
::: indent
**(обикновено) силна степен на корена + -sya**  
**или**  
**(обикновено) силна степен на корена + -i- + -sya (= - iṣya)**
:::
**Кой корен има каква форма на основата на бъдещето време, трябва да се научи с помощта на формите на основата!**  
**Обикновено формата на корена и свързващата гласка в бъдещето време съвпадат с инфинитива.**  
**Някои корени могат опционално да образуват бъдеще време с и без свързваща гласка -i-.**  
**Причастие на Parasmaipada за бъдещето време се образува чрез добавяне на суфикса -nt- към основата на бъдещето време, женски род факултативно с -ntī или -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
Примери:

::: grammar-box

| Корен | Бъдеще време 3. л. ед. ч. П (Ā) |
| :--- | :--- |
| ⟪नी⟫ | ⟪नेष्यति⟫ |
| ⟪भू⟫ | ⟪भविष्यति⟫ (⟪भो⟫ +  ⟪इ⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दिश्⟫ | ⟪देक्ष्यति⟫ (⟪देश्⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दृश्⟫ | ⟪द्रक्ष्यति⟫ |
| ⟪पच्⟫ | ⟪पक्ष्यति⟫ |
| ⟪प्रच्छ्⟫ | ⟪प्रक्ष्यति⟫ |
| ⟪यज्⟫ | ⟪यक्ष्यति⟫ |
| ⟪सृज्⟫ | ⟪स्रक्ष्यति⟫ |
| ⟪पद्⟫ | ⟪पत्स्यति⟫ |
| ⟪अद्⟫ | ⟪अत्स्यति⟫ |
| ⟪दुह्⟫ | ⟪धोक्ष्यति⟫ (⟪दोग्⟫ +  ⟪स्य⟫ + ⟪ति⟫) |
| ⟪बुध्⟫ | ⟪भोत्स्यते⟫ (⟪बोध्⟫ пред гласен = ⟪भोत्⟫) |
| ⟪मन्⟫ | ⟪मंस्यते⟫ (⟪मन्⟫ + ⟪स्य⟫ + ⟪ते⟫) |

:::
