# Урок 50

## 50.1. Образувание на съществителни: правилно сравнение

::: grammar-box
**Правилното сравнение в санскрита се извършва с ⟪तद्धित⟫ суфиксите**
* **-⟪तर⟫ (фем.: ⟪तरा⟫) в "компаратив"**
* **⟪तम⟫ (фем.: ⟪तमा⟫) в "суперлатив"**

**Тези суфикси се добавят към мъжкия корен на прилагателните. При съществителни с промяна в основата те се добавят към слабия корен, който има формата като преди окончанието -su на локал (⟪पञ्चमी⟫) множествено число.**
:::
::: media
![](/images/lekt5007.webp)
Ил.: ⟪लोकस्योत्तमो गिरिः सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = Еверест
(Източник на изображението: [Подробности](/bg/licenses#lekt5007))
:::

::: grammar-box
**Значение:**

**"Компаративът" означава, когато не е изразен сравнителен обект: "доволно, много, прекалено":**

:::
::: indent
напр. ⟪सुचितर⟫ 3 "доволно чист", "много чист", "прекалено чист"
:::
**Ако е изразен сравнителен обект, той стои в аблатив (⟪पञ्चमी⟫). Компаратив + аблатив съответства на сравнението с "отколкото" в немския език.**

::: indent
напр. ⟪देवदत्ताद्रामो धीमत्तरः⟫ = досл.: "гледано от Девата, Рам е по-мъдр" = "Рам е по-мъдър от Девата"
:::
**"Суперлативът" означава, когато не е изразен сравнителен обект: "най-висок, много":**

::: indent
напр. ⟪सत्तम⟫ 3 (към ⟪सन्त्⟫) "най-добър, много добър"
:::
**Ако е изразен сравнителен обект, той стои в генитив (⟪षष्ठी⟫) ("от", "сред") и суперлативът съответства на немския суперлатив (висша степен):**

::: indent
напр. ⟪द्विजानां सत्तमः⟫ = "най-добрият от дваж родените"
:::
**Суфиксите -⟪तर⟫ и -⟪तम⟫ могат да се присъединяват не само към прилагателни, но и към съществителни имена, неизменими думи и дори глаголни форми:**

Примери:

::: indent
⟪गजतम⟫ м.р. "най-добрият слон" (⟪गज⟫) (също име на Буда)

⟪गोतम⟫ м.р. "най-големият бик" (⟪गो⟫) или: "най-богат на крави"

⟪उद्⟫ неизм. "нагоре", "по-високо" » ⟪उत्तर⟫ 3 "по-висок" » ⟪उत्तम⟫ 3 "най-висок"
:::
**Когато тези суфикси се присъединят към глаголна форма, те винаги се появяват в наречна форма:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

Примери:

::: indent
⟪पचतितराम्⟫ "той/тя/то готви по-добре"

⟪पचतितमाम्⟫ "той/тя/то готви най-добре"
:::
**Тази форма тези суфикси имат и когато се присъединят към неизменима дума и производната дума се използва наречно:**

::: indent
напр. ⟪सुतराम्⟫ (към ⟪सु⟫) "по-добър начин" (наречно)
:::
::: media
![](/images/lekt5006.webp)
Ил.: ⟪का पचतितमाम्⟫
Лису = 傈僳族, ⟪अरुणाचल प्रदेश⟫
(Източник на изображението: [Подробности](/bg/licenses#lekt5006))
:::
