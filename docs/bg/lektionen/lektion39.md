# Урок 39

## 39.1. Личните окончания на първо лице (***⟪तृतीयः⟫*** ⟪पुरुषः⟫ = "**трето** лице")

Окончанията на първо лице (***⟪तृतीयः⟫*** ⟪पुरुषः⟫ = "**трето** лице") са:

::::grammar-box

| | **⟪परस्मैपदम्⟫** || **⟪आत्मनेपदम्⟫** ||
| :--- | :---: | :---: | :---: | :---: |
| | **⟪एकवचनम्⟫** | **⟪बहुवचनम्⟫** | **⟪एकवचनम्⟫** | **⟪बहुवचनम्⟫** |
| **Основно окончание тематични основи** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **Основно окончание атематични основи** | ^^ | ^^ | **-e** | ^^ |
| **Вторично окончание тематични основи** | **-m** | **-ma** | **-i** | **-mahi** |
| **Вторично окончание атематични основи** | **-am** | ^^ | ^^ | ^^ |
| **Окончание на конъюнктив** | ^^ | ^^ | **-a** | ^^ |
| **Окончание на перфект** | **-a** | ^^ | **-e** | **-mahe** |

::::1 Бележка: всъщност основното окончание на тематичните основи Ā също трябва да се разглежда като -e, пред който тематичният гласен -a- изчезва по аналогия. Ефектът обаче е такъв, сякаш окончанието -i се присъединява към тематичния гласен -a-: a + i » e.
