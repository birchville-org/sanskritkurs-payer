# Упражнение 14

Преведете следните пословици и ги запомнете наизуст:

⟪निचो वदति न कुरुते वदति न साधुः करोत्येव ॥१॥⟫  
Нисшият човек не говори и не постъпва, добрият човек не говори, а постъпва.

⟪शीलं नरस्य भूषणम् ॥२॥⟫  
Добродетелта е украса на човека.

⟪सत्येन जनानां सुखं भवति ॥३॥⟫  
Чрез истината хората получават щастие.

⟪पापा नराः स्वर्गं न लभन्ते ॥४॥⟫  
Злите хора не влизат в небето.

⟪सत्यं लोकस्य दीपः ॥५॥⟫  
Истината е светлината на света.

А) Образувателитете единствено и множествено число за следните думи. Посочете значението и рода на думите:

⟪१⟫. ⟪अनृत⟫ : н. Невярност — ⟪अनृतस्य अनृतानाम् २⟫. ⟪ऋषि⟫ : м. ведически мъдрец — ⟪ऋषेः ऋषीणाम् ३⟫. ⟪पाद⟫ : м. крак — ⟪पादस्य पादानाम् ४⟫. ⟪बुद्धि⟫ : ж. Познание — ⟪बुद्धेः⟫ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम् ५⟫. ⟪गुरु⟫ : м. учител — ⟪गुरोः गुरूणाम् ६⟫. ⟪स्वर्ग⟫ : м. небе — ⟪स्वर्गस्य स्वर्गाणाम् ७⟫. ⟪नगर⟫ : н. град — ⟪नगरस्य नगराणाम् ८⟫. ⟪धेनु⟫ : ж. крава — ⟪धेनोः⟫ (⟪धेन्वाः⟫) ⟪धेनूनाम् ९⟫. ⟪द्विज⟫ : м. Дважди роден — ⟪द्विजस्य द्विजानाम् १०⟫. ⟪मुक्ता⟫ : ж. Изкупената — ⟪मुक्तायाः मुक्तानाम् ११⟫. ⟪विद्या⟫ : ж. знание, наука — ⟪विद्यायाः विद्यानाम् १२⟫. ⟪वर्ण⟫ : м. състояние — ⟪वर्णस्य वर्णानाम् १३⟫. ⟪द्विजाति⟫ : 3 дважди родени — ⟪द्विजातेः⟫ (⟪द्विजात्याः⟫) ⟪द्विजातीनाम् १४⟫. ⟪रूप⟫ : н. форма — ⟪रूपस्य रूपाणाम् १५⟫. ⟪प्रतिग्रह⟫ : м. приемане — ⟪प्रतिग्रहस्य प्रतिग्रहाणाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 понасям — ⟪सोढस्य सोढायाः सोढानाम् १७⟫. ⟪नायिका⟫ : ж. любима — ⟪नायिकायाः नयिकानाम् १८⟫. ⟪साध्वी⟫ : ж. свещена — ⟪साध्व्याः साध्वीनाम् १९⟫. ⟪अग्नि⟫ : м. огън — ⟪अग्नेः अग्नीनाम् २०⟫. ⟪वैश्या⟫ : ж. жена на вайшя — ⟪वैश्यायाः वैश्यानाम् २१⟫. ⟪लोक⟫ : м. свят, хора — ⟪लोकस्य लोकानाम् २२⟫. ⟪उक्ति⟫ : ж. изречение — ⟪उक्तेः⟫ (⟪उक्त्याः⟫) ⟪उक्तीनाम् २३⟫. ⟪शत्रु⟫ : м. враг — ⟪शत्रोः शत्रूणाम् २४⟫. ⟪सुखवन्त्⟫ : 3 щастлив — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : ж. жена с един или повече синове — ⟪पुत्रवत्याः पुत्रवतीनाम् २६⟫. ⟪जल⟫ : н. вода — ⟪जलस्य जलानाम् २७⟫. ⟪मार्ग⟫ : м. път — ⟪मर्गस्य मर्गाणाम् २८⟫. ⟪मोक्ष⟫ : м. освобождение, избавление — ⟪मोक्षस्य मोक्षाणाम् २९⟫. ⟪शूद्रा⟫ : ж. жена на шудра — ⟪शूद्रायाः शूद्राणाम् ३०⟫. ⟪अन्न⟫ : н. храна, ядене — ⟪अन्नस्य अन्नानाम् ३१⟫. ⟪साधु⟫ : м. светия — ⟪साधोः साधनाम् ३२⟫. ⟪नीति⟫ : ж. насочване — ⟪नीत्याः नीतीनाम् ३३⟫. ⟪योध⟫ : м. боец, войник — ⟪योधस्य योधानाम् ३४⟫. ⟪सत्यवन्त्⟫ : 3 истински — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : м. печалба — ⟪लाभस्य लाभानाम् ३६⟫. ⟪मोह⟫ : м. объркване, заблуда — ⟪मोहस्य मोहानाम् ३७⟫. ⟪गति⟫ : ж. ходене, цел — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम् ३८⟫. ⟪प्रश्न⟫ : м. въпрос — ⟪प्रश्नस्य प्रश्नानाम् ३९⟫. ⟪सृष्टि⟫ : ж. творение — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम् ४०⟫. ⟪नेत्र⟫ : н. око — ⟪नेत्रस्य नेत्राणाम् ४१⟫. ⟪गुरुता⟫ : ж. господство — ⟪गुरुतायाः गुरुतानाम्⟫

⟪४२⟫. ⟪ईश्वर⟫ : м. ГОСПОДЬ — ⟪ईश्वरस्य ईश्वराणाम् ४३⟫. ⟪कारण⟫ : с. причина — ⟪कारणस्य कारणानाम् ४४⟫. ⟪कृत⟫ : 3 извършен — ⟪कृतस्य⟫ (⟪कृतायाः⟫) ⟪कृतानाम् ४५⟫. ⟪धर्मवन्त्⟫ : 3 праведен, религиозен — ⟪धर्मवतः⟫ (⟪धर्मवत्याः⟫) ⟪धर्मवताम्⟫ (⟪धर्मवतीनाम्⟫)

⟪४६⟫. ⟪युद्ध⟫ : 3 побеждава — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम् ४७⟫. ⟪दर्शन⟫ : с. виждане, явление — ⟪दर्शनस्य दर्शनानाम् ४८⟫. ⟪धातु⟫ : м. елемент, глаголен корен — ⟪धातोः धातूनाम् ४९⟫. ⟪गूढा⟫ : ж. една скрита — ⟪गूढायाः गूढानाम् ५०⟫. ⟪ईष्टा⟫ (2 значения): ж. една желана, една принесена в жертва — ⟪इष्टायाः इष्टानाम् ५१⟫. ⟪उदित⟫ : 3 казано — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम् ५२⟫. ⟪इदम्⟫ : 3 този — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 какво — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) Преведете:

⟪१⟫. ⟪ब्राह्मणस्य पुत्रो ब्राह्मण्या ग्रामं गतः ।⟫ (2 възможности)
Синът на брахманите отиде в селото на брахманката. Синът на брахманите отиде с брахманката в селото.

⟪२⟫. ⟪यज्ञस्याग्निनान्नं दग्धम् ।⟫
Жертвеният огън изпечи храната.

⟪३⟫. ⟪बुद्धः स्तयस्य बुद्ध्या मुक्तः ।⟫
Буда беше избавен чрез познанието на истината.

⟪४⟫. ⟪अधर्मो ऽनृतस्य वदनमित्यृषयो वदन्ति ।⟫
Ведийските мъдреци казват, че да лъжеш е несправедливо.

⟪५⟫. ⟪नरा देवानां यज्ञैर्न मुच्यन्ते ।⟫
Хората не се избавят чрез жертвоприношения към боговете.

⟪६⟫. ⟪बलवन्तः क्षत्रियाः शत्रूणां धनवन्ति नगराणि जयन्ति ।⟫
Могъщите кшатрии завладяват богатите градове на враговете.

⟪७⟫. ⟪कवेरुक्तिं शृण्वन्ति ।⟫
Чувате стиха на поета.

⟪८⟫. ⟪कविर्देव्याः कृतं वद⟫ti ⟪।⟫
Поетът разказва делото на богинята.

⟪९⟫. ⟪द्विजाः पशोर्लाभमिच्छन्ति ।⟫
Дважды родените желаят да получат добитък.

⟪१०⟫. ⟪रामः पुण्यवतो गुरोर्मन्त्रस्य स्मरति ।⟫
Рама си спомня мантрата на достойния учител.

⟪११⟫. ⟪अयं बालः कस्याः पुत्रः ।⟫
Чий (ж.) син е това момче?

⟪१२⟫. ⟪केषामिमानि गृहाणि ।⟫
На кого принадлежат тези къщи?

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम् ।⟫
Чия храна е принесъл в жертва този ведически мъдрец?
