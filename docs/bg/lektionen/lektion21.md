# Урок 21

## 21.1. Други настоящосъществителни основи на -nt

### 21.1.1. Причастие за настояще време (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
Това причастие е номинална форма, произлязла от настоящата основа, т.е. истинско причастие. То е прилагателно, което показва, че някой или нещо прави точно това, изразено от глаголовата основа (+ префикс), докато се случва нещо друго. Може да изрази и постоянно състояние.

**Примери:**

:::
::: indent
"Докато бащата чете, той пуши = пушащият четащ баща"  
"един бъдещ (= реален, истински) приятел"
:::
::: grammar-box

| **Образуване на причастие за настояще време Parasmaipada към тематични настоящосъществителни основи:** |||
| :--- | :--- | :--- |
| **Мъжки род, Среден род** | | |
| | **силна основа** | Настояща основа + **-nt-** |
| | **слаба основа** | Настояща основа + **-t-** |
| **Женски род** | | |
| | | Настояща основа + **-nt-** + **-ī** (спрягане като **devī** :br⟪देवी⟫) |
| | **6. настоящокласа** | Настояща основа + **-nt-** + **-ī** :broder::brНастояща основа + **-t-** + **-ī** |

:::

::: grammar-box

## 21.3. Вежливи форми на обръщение

::: grammar-box
**На санскрит може да се обръщате към някого във 2-то лице единствено число, без да сте груби. Ако обаче искате да бъдете учтиви, можете да използвате съществително име, чието значение е "достопочтени" и подобни, и да поставите глагола в 3-то лице ед. или мн. число, съответно да използвате пасивна конструкция. Степенуването на учтивостта при употребата на лице при обръщението е приблизително следното:**

:::
::: indent
**2. ед. » 2. мн. » 3. ед. с подходящо съществително име » 3. мн. със съответното съществително име**
:::
**Най-важното такова учтиво съществително име е ⟪भवन्त्⟫ , женски род: ⟪भवती⟫ . То отговаря на нашето учтиво "Вие".**
Този ⟪भवन्त्⟫ е съкращение от ⟪भगवन्त्⟫, неговата деклинация е на съществителните имена с окончание **-vant** (виж [Урок 13](lektion13.md)). Този ⟪भवन्त्⟫ трябва да се различава от причастие за настояще време P на ⟪भू⟫ "стана" ⟪भवन्त्⟫ : именителен падеж, единствено число, мъжки род на ⟪भवन्त्⟫ "Вие" е ⟪भवान्⟫, а на причастието ⟪भवन्⟫.

**Примери:**

::: indent
**⟪किं भवान्करोति⟫** = **⟪किं भवता क्रियते⟫** = "Какво правите вие?"
:::
учтиво:

::: indent
**⟪किं भवन्तः कुर्वन्ति⟫** = **⟪किं भवद्भिः क्रियते⟫**
:::
Женски род:

::: indent
**⟪किं भवती करोति⟫** = **⟪किं भवत्या क्रियते⟫**  
**⟪किं भवत्यः कुर्वन्ति⟫** = **⟪किं भवतीभिः क्रियते⟫**
:::
Други думи, които могат да се използват по подобен начин на ⟪भवन्त्⟫:

*   ⟪आर्य⟫ (ж.р.: ⟪आर्या⟫) "Благороден". напр. **⟪यदार्य इच्छति⟫** "Какво желаете"
*   ⟪महाभाग⟫ "онзи, чийто дял/съдба е голям = Благороден". Често използвано от жени при обръщение или говор за мъже с добро положение. В съвременния разговорен санскрит много често срещано.

Ако искаме да изразим не само учтивост, но и почит към някого, използваме при присъстващ или близо човек вместо ⟪भवन्त् अत्रभवन्त्⟫ , за отсъстващ или далечен ⟪तत्रभवन्त्⟫. ⟪अत्रभवन्त्⟫ и ⟪तत्रभवन्त्⟫ могат да се преведат като "вие", "ваше благородие", "вашо преосвещенство" и т.н.:

::: indent
**⟪किमत्रभवत्यत्रभवतां भार्या⟫** = "Дали благородната (тук присъстваща) жена е вашата съпруга?"  
**⟪किं तत्रभवतां कुशलवृत्तम्⟫** (в писмо или телефонен разговор) = "Как сте?"
:::

⟪मृतं दहन्नग्निः सतीमपि दहति ॥१॥ सद्गुरुर्महाकविस्तोत्रैर्महादेवं स्तौति ॥२॥ महान्ति फलान्यदन्तो बाला जलमापि पिबन्ति ॥३॥ पूजां कुर्वञ्जनो यजते च स्तौति च देवताम् ॥४॥ गुरूपनीतनरो द्विजः ॥५॥⟫
