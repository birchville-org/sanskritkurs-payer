# Упражнение 58

## A) iṣ-Аорист-трансформации

Определете и преведете следните форми и образувате съответните форми на **iṣ-Аориста**:

1.  ⟪औहे⟫ - ⟪ऊह्⟫ 1А 1.ед.изр.Наст.А аз бутам - ⟪औहिषि⟫
2.  ⟪जाग्रति⟫ - ⟪जागृ⟫ 2П 3.мн.изр.Наст.П те са будни - ⟪अजागरिषुः⟫
3.  ⟪जीर्यन्ति⟫ - ⟪जॄ⟫ 4П 3.мн.изр.Наст.П те остаряват - ⟪अजारिषुः⟫
4.  ⟪आनर्च⟫ - ⟪अर्च्⟫ 1П почитат 1.3.ед.2.мн.Съст.П - ⟪आर्चिषम्⟫ ⟪।⟫ ⟪आर्चीत्⟫ ⟪।⟫ ⟪आर्चिष्ट⟫
5.  ⟪खादामः⟫ - ⟪खाद्⟫ 1П 1.мн.изр.Наст.П ние дъвчем - ⟪अखादिष्म⟫
6.  ⟪नेद⟫ - ⟪नद्⟫ 1П 2.мн.Съст.П вие звучите - ⟪अनादिष्ट⟫ ⟪।⟫ ⟪अनदिष्ट⟫
7.  ⟪आश्नीत⟫ -⟪अश्⟫ 9П 2.мн.Наст.П вие ядохте - ⟪आशिष्ट⟫
8.  ⟪पुनते⟫ - ⟪पू⟫ 9У 3.мн.изр.Наст.А те се чистят сами - ⟪अपविषत⟫
9.  ⟪अशेरत⟫ - ⟪शी⟫ 2А 3.мн.Наст.А те лежахат - ⟪अशयिषत⟫
10.  ⟪इयेषिथ⟫ - ⟪इष्⟫ 6П 2.ед.Съст.П ти пожела - ⟪ऐषीः⟫
11.  ⟪आर्च्छत्⟫  - ⟪ऋ⟫ 1П 3.ед.Наст.П той отиде - ⟪आरीत्⟫
12.  ⟪अर्हन्ति⟫ - ⟪अर्ह्⟫ 1П 3.мн.изр.Наст.П те са достойни - ⟪आर्हिषुः⟫
13.  ⟪ऊदुः⟫ - ⟪वद्⟫ 1П 3.мн.Съст.П те казаха - ⟪अवादिषुः⟫
14.  ⟪इन्त्से⟫ - ⟪इन्ध्⟫ 7А 2.ед.изр.Наст,А ти запалваш - ⟪ऐन्धिष्ठाः⟫
15.  ⟪आध्वे⟫ - ⟪आस्⟫ 2А 2.мн.изр.Наст.А вие седите -⟪आसिध्वम्⟫
16.  ⟪कल्पे⟫ - ⟪कॢप्⟫ 1.ед.изр.Наст.А аз пася -⟪अकल्पिषि⟫
17.  ⟪आनीत्⟫ - ⟪अन्⟫ 2П 3.ед.Наст.П той дишаше - ⟪आनीत्⟫
18.  ⟪ऐक्षध्वम्⟫ - ⟪ईक्ष्⟫ 1А 2.мн.Наст.А вие видяхте - ⟪ऐक्षिध्वम्⟫
19.  ⟪अचेतः⟫ - ⟪चित्⟫ 1П 2.ед.Наст.П ти възприехте - ⟪अचेतीः⟫
