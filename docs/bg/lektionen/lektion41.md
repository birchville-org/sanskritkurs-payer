## 41.2. Други ⟪कृत्⟫-образувания на -a

### 41.2.1. Причастие сегашно време (⟪लडादेशः⟫) Ā, Причастие сегашно време (⟪लडादेशः⟫) Страдателен залог, Причастие бъдеще време (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Тематични настоящосъществителни основи, страдателен залог и бъдеще време

::: grammar-box
**Образуване:**

Настояща основа / Страдателна основа / Бъдеща основа + -māna (ж.р. mānā)
:::
Примери:

⟪यज्⟫ 1U, Прич. сег.вр.Ā ⟪यजमान⟫ 3 "някой, който почита с жертва в собствената си полза = господар на жертвата"

⟪मन्⟫ 4Ā, Прич. сег.вр.Ā ⟪मन्यमान⟫ 3 "мислещ"

⟪कृ⟫ 8U, Прич. сег.вр.Страдателен ⟪क्रियमाण⟫ 3 "нещо, което се прави"

⟪दा⟫ 3U, Прич. бъд.вр.Ā ⟪दास्यमान⟫ 3 "някой, който ще даде в собствената си полза"

#### 41.2.1.2. Атематични класи на настоящето

::: grammar-box
**Образуване:**

Слаба настояща основа (в формата, която има преди окончанието -ate на 3.мн.Ā) + -āna (ж.р. -ānā)
:::
Примери:

::: grammar-box
| Корен / Класа | Причастие сегашно време Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. „Партцип“ на пасивната необходимост (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**За да изразите пасивната необходимост („това, което трябва/следва да бъде направено“), можете по избор да образувате прилагателни от корени и производни глаголни основи, като използвате следните суфикси:**

* **-⟪तव्य⟫** (ж.р. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (ж.р. **-⟪अनीया⟫**)
* **-⟪य⟫** (ж.р. **-⟪या⟫**)
* **-⟪त्य⟫** (ж.р. **-⟪त्या⟫**) (вместо **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Сuffix -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Suffix -⟪तव्य⟫ / -⟪तव्या⟫ се добавя към корени и производни глаголни основи (напр. каузатив) по същия начин, както suffix -⟪तुम्⟫ за инфинитив (вж. [Лекция 23](lektion23.md)), т.е.**

* **силна степен на корена + ⟪तव्य⟫**

или

* **силна степен на корена + -i- + ⟪तव्य⟫**

**В каузатива:**

* **Каузативна основа на -ay + -i- + ⟪तव्य⟫**
:::
Примери:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1Л | ⟪जेतव्य⟫ 3 | „който трябва да бъде победен; един за побеждаване“ |
| ⟪वृत्⟫ 1А | ⟪वर्तितव्य⟫ 3 | „това, където трябва да се намираме“ |
| ⟪बुध्⟫ Кауз. | ⟪बोधयितव्य⟫ | „който трябва да бъде събуден; един за събуждане“ |

:::
#### 41.2.2.2. Сuffix -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Образуване:**

Силна степен на корена + -⟪अनीय⟫ / -⟪अनीया⟫

**Каузатив и 10. клас на настоящето време:**

Корен, както се появява в каузативната основа, без -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Примери:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3У | ⟪दानीय⟫ 3 | „даващо; това, което трябва да бъде дадено“ |
| ⟪जि⟫ 1Л | ⟪जयनीय⟫ 3 | „който трябва да бъде победен“ |
| ⟪कृ⟫ 8У | ⟪करणीय⟫ 3 | „това, което трябва да бъде направено“ |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | „това, което трябва да се види; достойно за гледане“ |
| ⟪बुध्⟫ Кауз. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | „един за събуждане“ |
| ⟪दा⟫ Кауз. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | „това, което трябва да бъде дадено“ |

:::
#### 41.2.2.3. Суфиксът -⟪य⟫ / -⟪या⟫

::: grammar-box
**Образуване:**

Корен (в дълбока, висока или удължена степен) + -⟪य⟫

За точните правила вижте при Kielhorn, Граматика на санскритския език, стр. 195 - 197!
:::
Обработка на крайни гласни:

::: grammar-box
**1. Корени на -ā образуват това герундив на -eya**
:::
Примери:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "което трябва да се знае; което трябва да бъде разпознато" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "което трябва да бъде дадено" |

:::
::: grammar-box
**2. Корени на -i /-ī / -u / -ū /-ṛ обикновено имат висока или удължена степен, освен ако не принадлежат към онези корени на -i / -u /-ṛ, които образуват герундив с суфикса -⟪त्य⟫ (женски род -⟪त्या⟫) (списък на тези корени при Kielhorn, Граматика §537).**
:::
Пример:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 | "на което трябва да се помисли" |

:::
::: grammar-box
**2a. Корени на -i/-ī имат висока степен**
:::
Примери:

::: no-header

| | | |
| :--- | :--- | :--- |

| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "който трябва да бъде воден" |

:::

#### 41.2.2.4. Суфиксът -⟪त्य⟫ / ⟪त्या⟫ (вместо -⟪य⟫ / -⟪या⟫)

::: grammar-box
Списък на корените, завършващи на -i / -u /-ṛ, които образуват герундив не с -⟪य⟫ / -⟪या⟫, а с суфикса -⟪त्य⟫ (женски род -⟪त्या⟫), вж. Kielhorn, Граматика §537.

**Формиране:**

корен в ниска степен + -⟪त्य⟫ / -⟪त्या⟫
:::
Примери:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "онзи, когото трябва да се ходи" |
|  ⟪श्रु⟫ 5P |  ⟪श्रुत्य⟫ 3 | "онзи, когото трябва да се чуе" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "онзи, когото трябва да се прави" |

:::
### 41.2.3. Синтаксис на „причастие“ за пасивна необходимост (герундив) (⟪कृत्य⟫)

::: grammar-box
Герундивът може да се използва атрибутивно:

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = „град, който трябва да се види; достоен за посещение град“
:::
Герундивът може също така да се използва като предикатно име в изречения с пасивна конструкция, които изразяват задължение или заповед (с ⟪न⟫ забрана, невъзможност):

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = „Дваждыродените трябва да видят Бенарес“
:::

### 41.2.4. Разлики в употребата на герундивните суфикси

::: grammar-box
Употребата на тези суфикси се припокрива в значителна степен

* **-⟪तव्य⟫ (ж.р. -⟪तव्या⟫):** винаги изразява необходимост и се предпочита предикативно (по-рядко атрибутивно). Образувания с този суфикс не трябва да се използват в номинални композитуми.
* **-⟪अनीय⟫ (ж.р. -⟪अनीया⟫) и -⟪य⟫ (ж.р. -⟪या⟫) / -⟪त्य⟫ (ж.р. -⟪त्या⟫) (вместо -⟪य⟫/-⟪या⟫):** могат да имат допълнително значение (особено -⟪य⟫) в смисъл на немското „-worth“ (напр. „достоен за посещение“) или само възможност „-bar“ (⟪दृश्य⟫ „видим“). Образувания с тези суфикси могат да бъдат отрицани с ⟪अ⟫-/-⟪अन्⟫- (но не и образувания с -⟪तव्य⟫) и съществуват ⟪तत्पुरुष⟫ като техен втори компонент, в който се срещат.
:::
### 41.2.5. Няма връзка с ⟪सु⟫- и ⟪दुस्⟫-

::: grammar-box
С ⟪सु⟫- и ⟪दुस्⟫- в значение „лесно“ съответно „трудно“, герундивите не трябва да се свързват. Вместо това стоят ⟪तत्पुरुष⟫ от тип  ⟪सुकर⟫ 3 („лесно за правене“) (вж. [Урок 18](lektion18.md)).
:::

⟪कन्यां व्युवह तस्यां च पुत्रमजनयं महाधनं च लेभ एवं सुखमापेत्यतीते मुमोह । ततः प्रजज्ञौ सुखाद्दुःखं जायते तस्माल्लोकसुखमपि त्यजनीयं न च किंचिदिन्द्रियैः स्प्रष्टव्यमिति ॥३॥ विक्रेयाणि विक्रीयापुत्रवैश्यो भिक्षुभ्यो विक्रयफलमददाद्दानपुण्यं चादत्त । एतत्कर्म स्तुत्यमिति भिक्षवः प्रोचुर्बुद्धिमन्तस्तु विकल्पयन्ति किमेवं कुर्वाणो वश्यः पुण्यं चकारेति ॥४॥ गुरुभिः शिष्याः शासितव्याः शिष्यैरध्ययनमध्येतव्यम् ॥५॥⟫
