# Урок 16

## 16.1. За сандхи на изходящи съгласни

За образуването на съставни думи, чийто първи елемент са основи с изходящи съгласни, се нуждаете от следните правила:

Изходящи гърлени, ретрофлексни, дентални и устни спирали (т.е. не носови и не палатални).

::: no-header

|   |   |
| :--- | :--- |
| **в пауза и пред беззвучни звуци** | **Замяна с съответния им беззвучен неаспириран звук:** :br **напр.** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **пред звучни неназални звуци** | **Замяна с съответния им звучен неаспириран звук:** :br **напр.** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **пред носови** | **Замяна с съответния им назален звук:** :br **напр.** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::
Изключение от горното правило:

Изходящ дентален спирали (не назален):

::: no-header

|   |   |
| :--- | :--- |
| **пред палатал** | **Замяна с съответния неаспириран палатал:** :br **т.е.** :br :indent -t + c- » -cc- :br :indent -d + c- » -cc- :br :indent -th + c- » -cc- :br :indent -dh + c- » -cc- :br :indent -t/-th/-d/-dh + ch- » -cch- :br :indent -t/-th/-d/-dh + j- » -jj- :br :indent -t/-th/-d/-dh + jh- » -jjh- |
| **+ ś** | **» -cś- или -cch-** |
| **пред ретрофлекс** | **Замяна с съответния неаспириран ретрофлекс:** :br **т.е.** :br :indent -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- :br :indent -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **пред l-** | **Замяна с -l:** :br **т.е.** :br :indent -t/-th/-d/-dh + l- » -ll- |

:::
Примери:

⟪तद्⟫ + ⟪फल⟫ = ⟪तत्फल पुण्यवत्⟫ + ⟪ब्राह्मण⟫ = ⟪पुण्यवद्ब्राह्मण पुण्यवत्⟫ + ⟪नर⟫ = ⟪पुण्यवन्नर पुण्यवत्⟫ + ⟪पुरुष⟫ = ⟪पुण्यवत्पुरुष सत्यवत्⟫ + ⟪चैतन्य⟫ =⟪सत्यवच्चैतन्य सुखवत्⟫ + ⟪लोक⟫ = ⟪सुखवल्लोक पुत्रवत्⟫ + ⟪जन⟫ = ⟪पुत्रवज्जन बलवत्⟫ + ⟪शत्रु⟫ = ⟪बलवच्छत्रु⟫
