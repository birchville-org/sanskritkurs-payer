# Урок 17

## 17.1. Втори клас на настоящето време (⟪अदादि⟫ = ⟪अद्⟫ и т.н.)

Глаголните окончания се присъединяват директно към корена. При това трябва да се вземат предвид фонетичните промени, произтичащи от словния сандхи.

::: grammar-box

Съществуват следните форми на образуване във втория клас на настоящето време:

1. Корени с промяна в основата
*   най-често: Висока степен - Ниска степен
*   някои корени: Дълга степен - Ниска степен
2. Корени без промяна в основата
3. Двусрични корени на -i/-ī с промяна в основата

:::
## 17.2. Корени на втория клас на настоящето време с промяна в основата Висока степен - Ниска степен

Примери:

⟪द्विष्⟫ 2 U "мразя"

*   силен настоящ корен: dveṣ-
*   слаб настоящ корен: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪द्वेष्टि⟫ (« dveṣ + -ti) |
| 3\. мн.ч. наст. P | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 3\. ед.ч. наст. Ā | ⟪द्विष्टे⟫ (« dviṣ + -te) |
| 3\. мн.ч. наст. Ā | ⟪द्विषते⟫ (dviṣ-ate) |

:::
При това действа следният закон за словния сандхи:

::: grammar-box
Словен сандхи на -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-
:::
Други примери:

⟪इ⟫ 2 P "отивам" (Ā след определени предлози)

*   силен настоящ корен: e-
*   слаб настоящ корен:
*   пред съгласна: i-
*   пред гласна: y-/iy-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪एति⟫ (e-ti) |
| 3\. мн.ч. наст. P | ⟪यन्ति⟫ (y-anti) |
| 3\. ед.ч. наст. Ā | ⟪इते⟫ (i-te) |
| 3\. мн.ч. наст. Ā | ⟪इयते⟫ (iy-ate) |

:::
⟪दुह्⟫ 2 U "доя"

*   силен настоящ корен: doh-
*   слаб настоящ корен: duh-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪दोग्धि⟫ (« doh- + -ti) |
| 3\. мн.ч. наст. P | ⟪दुहन्ति⟫ (duh-anti) |
| 3\. ед.ч. наст. Ā | ⟪दुग्धे⟫ (« duh- + -te) |
| 3\. мн.ч. наст. Ā | ⟪दुहते⟫ (duh-ate) |

:::

:::
## 17.3. Корени на втория клас на настоящето с коренова диференциация степен на удължение - ниска степен

Пример:

⟪स्तु⟫ 2 U "славя"

*   силен настоящ корен: stau-
*   слаб настоящ корен:
*   пред съгласна: stu-
*   пред гласна: stuv-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪स्तौति⟫ (stau-ti):broder: ⟪स्तवीति⟫ |
| 3\. мн.ч. наст. P | ⟪स्तुवन्ति⟫ (stuv-anti) |
| 3\. ед.ч. наст. Ā | ⟪स्तुते⟫ (stu-te) |
| 3\. мн.ч. наст. Ā | ⟪स्तुवते⟫ (stuv-ate) |

:::
## 17.4. Корени на втория клас на настоящето без коренова диференциация

::: grammar-box
Без коренова диференциация са корените на втория клас на настоящето, завършващи на -ā
:::
Пример:

⟪पा⟫ 2 P "пазя, пазя, охранявам"

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪पाति⟫ (pā-ti) |
| 3\. мн.ч. наст. P | ⟪पान्ति⟫ (« pā- + -anti) |

:::
Някои други корени от втория клас също нямат коренова диференциация:

Примери:

⟪अद्⟫ 2 P "ям"

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪अत्ति⟫ (« ad- + -ti) |
| 3\. мн.ч. наст. P | ⟪अदन्ति⟫ (ad-anti) |

:::
⟪आस्⟫ 2 Ā "седя"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. Ā | ⟪आस्ते⟫ (ās-te) |
| 3\. pl. Präs. Ā | ⟪आसते⟫ (ās-ate) |

:::
⟪वच्⟫ 2 P "казвам"

::: no-header

| | |
| :--- | :--- |

:::
## 17.5. Двусрични корени на -i/-ī с редукция на основата

Няколко корена са в редица форми двусрични, т.е. имат пред съгласна крайна -i (съответно преди някои окончания -ī). Въпреки това тези корени се разглеждат от местните грамматици и в речници и т.н. като едносрични.

Примери:

⟪रुद्⟫ 2 P "плача, викам"

*   силен настоящ корен: rodi-
*   слаб настоящ корен:
*   пред съгласна: rudi-
*   пред гласна: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "говоря"

*   силен настоящ корен: bravī- (« bro- + -ī)
*   слаб настоящ корен:
*   пред съгласна: brū-
*   пред гласна: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Също ⟪स्तु⟫ 2 U "славя" има освен формите, посочени в точка 3., форми по този модел:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::

## 17.7. Упражнение 1

A) Вмъкнете глагола в следните изречения и преведете:

⟪१⟫. ⟪ब्राह्मणो ऽनृतं न⟫ ... (⟪ब्रू । वच् । वद्⟫)

⟪२⟫. ⟪क्षत्रियो जनान्⟫ ... (⟪पा । रक्ष्⟫)

⟪३⟫. ⟪बलवद्योधो द्विजारीन्⟫ ... (⟪जि । हन् । युध्⟫)

⟪६⟫. ⟪बालवैश्यो धेनुम्⟫ ... (⟪दुह् । रक्ष् । पा⟫)

⟪८⟫. ⟪द्विजदासः शूद्रस्⟫ ... (⟪अस् २ । भू⟫)

⟪९⟫. ⟪बालब्राह्मणी⟫ ... (⟪रुद् । आस् । मृ⟫)
