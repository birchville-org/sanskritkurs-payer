# Урок 17

## 17.1. Втор клас на настоящето време (⟪अदादि⟫ = ⟪अद्⟫ и т.н.)

Глаголните окончания се присъединяват директно към корена. При това трябва да се вземат предвид фонетичните промени, произтичащи от словния сандхи.

::: grammar-box

Съществуват следните форми на образуване във втория клас на настоящето време:

1.  Корени с промяна на стъпалото на корена
    *   повечето: Високо стъпало - Ниско стъпало
    *   някои корени: Дълго стъпало - Ниско стъпало
2.  Корени без промяна на стъпалото на корена
3.  Двусрични корени на -i/-ī с промяна на стъпалото на корена

:::
## 17.2. Корени на втория клас на настоящето време с промяна на стъпалото на корена Високо стъпало - Ниско стъпало

Примери:

⟪द्विष्⟩ 2 У "мразя"

*   силен настоящ корен: dveṣ-
*   слаб настоящ корен: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪द्वेष्टि⟩ (« dveṣ + -ti) |
| 3\. мн.ч. наст. P | ⟪द्विषन्ति⟩ (dviṣ-anti) |
| 3\. ед.ч. наст. Ā | ⟪द्विष्टे⟩ (« dviṣ + -te) |
| 3\. мн.ч. наст. Ā | ⟪द्विषते⟩ (dviṣ-ate) |

:::
При това действа следният закон за словния сандхи:

::: grammar-box
Словен сандхи на -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-
:::
Други примери:

⟪इ⟩ 2 P "отивам" (Ā след определени префикси)

*   силен настоящ корен: e-
*   слаб настоящ корен:
    *   пред съгласна: i-
    *   пред гласна: y-/iy-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪एति⟩ (e-ti) |
| 3\. мн.ч. наст. P | ⟪यन्ति⟩ (y-anti) |
| 3\. ед.ч. наст. Ā | ⟪इते⟩ (i-te) |
| 3\. мн.ч. наст. Ā | ⟪इयते⟩ (iy-ate) |

:::
⟪दुह्⟩ 2 У "доя"

*   силен настоящ корен: doh-
*   слаб настоящ корен: duh-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪दोग्धि⟩ (« doh- + -ti) |
| 3\. мн.ч. наст. P | ⟪दुहन्ति⟩ (duh-anti) |
| 3\. ед.ч. наст. Ā | ⟪दुग्धे⟩ (« duh- + -te) |
| 3\. мн.ч. наст. Ā | ⟪दुहते⟩ (duh-ate) |

:::
⟪हन्⟩ 2 P "бия, убивам, застрелвам"

*   силен настоящ корен: han-
*   слаб настоящ корен:
    *   пред съгласна: ha- (« \*hn-)

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪हन्ति⟩ (han-ti) |
| 3\. мн.ч. наст. P | ⟪घ्नन्ति⟩ (ghn-anti) |
| 3\. ед.ч. наст. Ā | ⟪हते⟩ (ha-te) |
| 3\. мн.ч. наст. Ā | ⟪घ्नते⟩ (ghn-ate) |

:::
⟪अस्⟩ 2 P "съм"

*   слаб настоящ корен: s-

| 3\. мн.ч. наст. P | ⟪सन्ति⟩ (s-anti) |

:::
## 17.3. Корени на втория клас на настоящето време с промяна на стъпалото на корена Дълго стъпало - Ниско стъпало

Пример:

⟪स्तु⟩ 2 У "хваля"

*   силен настоящ корен: stau-
*   слаб настоящ корен:
    *   пред съгласна: stu-
    *   пред гласна: stuv-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. P | ⟪स्तौति⟫ (stau-ti):broder: ⟪स्तवीति⟫ |
| 3\. мн.ч. наст. P | ⟪स्तुवन्ति⟩ (stuv-anti) |
| 3\. ед.ч. наст. Ā | ⟪स्तुते⟩ (stu-te) |
| 3\. мн.ч. наст. Ā | ⟪स्तुवते⟩ (stuv-ate) |

:::
## 17.4. Корени на втория клас на настоящето време без промяна на стъпалото на корена

::: grammar-box
Без промяна на стъпалото на корена са корените на втория клас на настоящето време на -ā
:::
Пример:

⟪पा⟫  2 P "защита, пасти, пазя"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪पाति⟫ (pā-ti) |
| 3\. pl. Präs. P | ⟪पान्ति⟫ (« pā- + -anti) |

:::
Някои други корени от втория клас също нямат степенуване на основата:

Примери:

⟪अद्⟫ 2 P "ядене"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪अत्ति⟫ (« ad- + -ti) |
| 3\. pl. Präs. P | ⟪अदन्ति⟫ (ad-anti) |

:::
⟪आस्⟫ 2 Ā "седене"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. Ā | ⟪आस्ते⟫ (ās-te) |
| 3\. pl. Präs. Ā | ⟪आसते⟫ (ās-ate) |

:::
⟪वच्⟫ 2 P "казване"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪वक्ति⟫ (« vac- + -ti) |
| 3\. pl. Präs. P | не се среща |

:::
## 17.5. Двусрични корени на -i/-ī със степенуване на основата

Няколко корена са в редица от форми двусрични, т.е. те имат -i (съответно -ī пред някои окончания) пред съгласно крайче. Тези корени обаче все пак се разглеждат от местните грамматици и в речници и т.н. като едносрични.

Примери:

⟪रुद्⟫ 2 P "плач, вой"

*   силен настоящ корен: rodi-
*   слаб настоящ корен:
    *   пред съгласна: rudi-
    *   пред гласна: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "говорене"

*   силен настоящ корен: bravī- (« bro- + -ī)
*   слаб настоящ корен:
    *   vor Konsonant: brū-
    *   пред гласна: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Също ⟪स्तु⟫ 2 U "прослава" има освен посочените под 3. форми форми по този модел:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::
