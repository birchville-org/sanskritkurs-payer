# Урок 35

## 35.1. Перфект тип III: Силна основа висока степен/удължена степен

::: grammar-box
**Образуване:**

**силна основа:**
*   3.л.ед.П: Удължена степен
*   2.л.ед.П: Висока степен
*   1.л.ед.П: по избор висока степен или удължена степен

**слаба основа:** виж подтиповете
:::
### 35.1.1. Перфект тип IIIa: Силна основа висока степен/удължена степен, слаба основа ниска степен

::: grammar-box
**Образуване:**

:::
::: indent
**слаба основа:** Ниска степен
:::
Образува се от корени на типовете:
*   (Съгласна)-(Съгласна) - i/ī/u/ū
*   (Съгласна) - ṛ

Преди гласоначално окончание се заменя:
*   -i/-ī с -iy
*   -u/-ū с -uv
*   -ṛ с r
Примери:


| Корен | 3. л. ед. Перф. П. | 3. мн. перф. П. | 3. л. ед. Перф. А. | 3. мн. перф. А. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2П | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:bri + iy + ur | | |
| ⟪नी⟫ 1У | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2У | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

### 35.1.2. Перфект тип IIIb: Силна основа висока степен/удължена степен, слаба основа висока степен

::: grammar-box
**Образуване:**

:::
::: indent
**слаба основа:** Висока степен
:::
Образува се от корени на типовете:
*   (Съгласна)-(Съгласна)-ṝ
*   Съгласна-Съгласна-ṛ (т.е. корени на -ṛ, ако им предхождат няколко съгласни)
Примери:


| Корен | 3. л. ед. Перф. П. | 3. мн. перф. П. | 3. л. ед. Перф. А. | 3. мн. перф. А. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पॄ⟫ 3П | ⟪पपार⟫ | ⟪पपरुर्⟫ | | |
| ⟪स्मृ⟫ 1П | ⟪सस्मार⟫ | ⟪सस्मरुर्⟫ | | |
| ⟪संस्कृ⟫ 8У | ⟪सञ्चस्कार⟫:brsam + ca-skār-a | ⟪सञ्चस्करुर्⟫ | ⟪सञ्चस्करे⟫ | ⟪सञ्चस्करिरे⟫ |

## 35.2. Перфект тип IV: Корени на -ā / -āi

::: grammar-box
**Образуване:**

**силен корен:**
*   3./1. л. ед.ч. Перф. П. завършва на -au
*   2\. л. ед.ч. П.: Висока степен -ā или Ниска степен -i

**слаб корен:**
*   пред съгласна: Ниска степен -i
*   пред гласна: Ниска степен Ø

Образува се от корени на -ā / -āi
:::
Пример:


| Корен | 3. л. ед.ч. Перф. П.:br1. л. ед.ч. Перф. П. | 3. мн.ч. Перф. П. | 3. л. ед.ч. Перф. А. | 3. мн.ч. Перф. А. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪ददौ⟫ | ⟪ददुर्⟫:brda-d-ur | ⟪ददे⟫ | ⟪ददिरे⟫:brda-d-i-re

## 35.3. Перфект тип V: Корени съгласна-a-съгласна

::: grammar-box
**Образуване:**

**силен корен:**
*   3.л.ед.: Дълга степен
*   2.л.ед.: Висока степен
*   1.л.ед.: по избор Висока степен или Дълга степен

**слаб корен:** вж. подтипове

Образува се от корени от типа (съгласна)-Съгласна-a-съгласна
:::
### 35.3.1. Перфект тип Va: слаб корен Ниска степен

::: grammar-box
**Образуване:**

:::
::: indent
**слаб корен:** Ниска степен
:::
Образува се между другото от корените:
*   ⟪गम्⟫
*   ⟪हन्⟫
*   ⟪जन्⟫
*   ⟪वच्⟫
*   ⟪वद्⟫
*   ⟪यज्⟫
Примери:


| Корен | 3. л. ед.ч. Перф. П. | 3. мн.ч. Перф. П. | 3. л. ед.ч. Перф. А. | 3. мн.ч. Перф. А. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪गम्⟫ 1P | ⟪जगाम⟫ | ⟪जग्मुर्⟫:brja-gm-ur | | |
| ⟪हन्⟫ 2P | :sig[⟪जघान⟫] :brja-**ghān**-a | :sig[⟪जघ्नुर्⟫] | | |
| ⟪जन्⟫ 4Ā | | | ⟪जज्ञे⟫:brja-jñ-e | ⟪जज्ञिरे⟫
| ⟪वच्⟫ 2P | ⟪उवाच⟫ | ⟪ऊचुर्⟫:bru + uc-ur | | |
| ⟪वद्⟫ 1P | ⟪उवाद⟫ | ⟪ऊदुर्⟫ | ⟪ऊदे⟫ | ⟪ऊदिरे⟫
| ⟪यज्⟫ 1U | ⟪इयाज⟫ | ⟪ईजुर्⟫:bri + ij-ur | ⟪ईजे⟫ | ⟪ईजिरे⟫

### 35.3.2. Перфект тип Vb: слаб корен, контракция (e-тип)

::: grammar-box
**Образуване:**

:::
::: indent
**слаб корен:** без редупликация. Замяна на -a- в основата с -e-  
(за обяснение вижте Thumb-Hauschild 1,2 стр. 286 сл.)
:::
Образува се от корени с -a- между две прости съгласни, чиято начална съгласна в редупликационната сричка не се променя (т.е. началната съгласна не е гутурал, аспират или h).
Пример:

| Основа | 3. л. ед. Перф. Актив | 3. мн. ч. Перф. Актив | 3. л. ед. Перф. Медиум | 3. мн. ч. Перф. Медиум |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 1U | ⟪पपाच⟫ | :sig[⟪पे⟫]⟪चुर्⟫ | :sig[⟪पे⟫]⟪चे⟫ | :sig[⟪पे⟫]⟪चिरे⟫ |

### 35.3.3. Перфект тип Vc: корени съгласна-a-съгласна. Слаб корен, силна степен

::: grammar-box
**Образуване:**

**слаб корен:** силна степен

Образува се от всички останали корени със средно -a-, т.е. корени със средно -a-
*   които започват с две съгласни
*   които започват с гутурал
*   които започват с аспират
*   които започват с h

стига да не принадлежат към Перфект тип Va.
:::
Пример:

| Основа | 3. л. ед. Перф. Актив | 3. мн. ч. Перф. Актив | 3. л. ед. Перф. Медиум | 3. мн. ч. Перф. Медиум |
| :--- | :--- | :--- | :--- | :--- |
| ⟪क्रम्⟫ 1U | ⟪चक्राम⟫ | ⟪चक्रमुर्⟫ | ⟪चक्रमे⟫ | ⟪चक्रमिरे⟫ |
