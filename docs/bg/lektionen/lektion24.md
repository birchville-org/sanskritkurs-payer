# Урок 24

## 24.1. Дативът (⟪चतुर्थी⟫ = "четвърто падежно окончание")

::: grammar-box
**1. За да се изрази цел или намерение ("за да") на едно действие, вместо инфинитива (⟪तुमुन्⟫) може да се използва съществително име с kṛt суфикс, което обозначава действие или състояние, в датив (⟪चतुर्थी⟫ = "четвърто падежно окончание").**

Пример:

вместо:

:::
::: indent
⟪रामो गुरुवचनं श्रोतुं गतः ।⟫
:::
може също да се каже:

::: indent
⟪रामो गुरुवचनस्य श्रवणाय गतः ।⟫

или:

⟪रामो गुरुवचनश्रवणाय गतः ।⟫
:::
= "Рама е отишъл, за да чуе речта на учителя."
::: media
![](/images/lekt2404.webp)
Ил.: ⟪बाला गुरुश्रवणाय गताः⟫
(Източник на изображението: [Подробности](/bg/licenses#lekt2404))
:::

::: grammar-box
**2. Дативът (⟪चतुर्थी⟫) може също да обозначава обекта на допълващ инфинитив за цел:**

Пример:

:::
::: indent
⟪फलेभ्यो ग्रामं गच्छति⟫ = "Той отива в селото с цел плодове = Той отива в селото, за да вземе плодове."
:::
**По същия начин дативът (⟪चतुर्थी⟫) обозначава целта на нещо или действие:**

Пример:

::: indent
⟪यज्ञायान्नम्⟫ = "Храна с цел жертвоприношение = Храна за жертвоприношение"
:::
::: media
![](/images/lekt2401.webp)
Ил.: ⟪यज्ञायान्नम्⟫
'Annakut' [⟪अन्नकूट⟫ = ⟪गोवर्धन पूजा⟫] е традиционен индуистки празник, който се провежда по време на честванията за Индуистка Нова Година във всички BAPS [બોચાસનવાસી અક્ષ૨ પુરુષોત્તમ સ્વામિનારાયણ સંસ્થા = Bochasanwasi Akshar Purushottam Swaminarayan Sanstha] мандири. Стотици вегетариански ястия се предлагат на Бхагван Сваминараян [સ્વામિનારાયણ] в този ден.
(Източник на изображението: [Подробности](/bg/licenses#lekt2401))
:::

::: grammar-box
**3. Дативът (⟪चतुर्थी⟫) обозначава също лицето или нещото, за които е предназначено обектът на действието (непряк обект; въпрос: кому?). (Обърнете внимание обаче на глаголите с двоен винителен падеж (⟪द्वितीया⟫)!)**

Пример:

:::
::: indent
⟪रामाय फलं ददाति⟫ = "Той дава на Рама плод." (Корен ⟪दा⟫ 3. клас на настоящето време)
:::
::: media
![](/images/lekt2402.webp)
Ил.: ⟪बाला बालाय रक्षबन्धनं ददाति⟫

(Източник на изображението: [Подробности](/bg/licenses#lekt2402))
:::

::: grammar-box
**4. Дативът стои при някои глаголи (и някои други думи) подобно на немския език на въпроса "кому?":**

Примери:

:::
::: indent
⟪क्रुध्⟫ : ⟪देवो नरेभ्यो क्रुध्यति⟫ = "Бог гневява на мъжете."

⟪अलम्⟫ Наречие: "достатъчно, достатъчно, способен": ⟪अलं योधो योधाय⟫ = "воин е равен на другия воин"
:::

## 24.2. Образувание на датив (⟪चतुर्थी⟫)

::: grammar-box
**Правилните окончания на датив са:**

* **Единствено число: -e; феминитивни основи, завършващи на гласна: -ai**
* **Множествено число: Датив и аблатив ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. Съгласни основи

::: grammar-box

| | Датив единствено число | Датив множествено число |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. Въпросителни местоимения

::: grammar-box

| | Мъжки род / Среден род | Женски род |
| :--- | :--- | :--- |
| **Датив единствено число** | ⟪कस्मै⟫ | ⟪कस्यै⟫ |
| **Датив множествено число** | ⟪केभ्यस्⟫ | ⟪काभ्यस्⟫ |

:::
### 24.2.3. Указателни местоимения

::: grammar-box

| | | ⟪तद्⟫ | ⟪एतद्⟫ | ⟪इदम्⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **Мъжки род / Среден род** | **Дат. ед.** | ⟪तस्मै⟫ | ⟪एतस्मै⟫ | ⟪अस्मै⟫ |
| | **Дат. мн.** | ⟪तेभ्यस्⟫ | ⟪एतेभ्यस्⟫ | ⟪एभ्यस्⟫ |
| **Женски род** | **Дат. ед.** | ⟪तस्यै⟫ | ⟪एतस्यै⟫ | ⟪अस्यै⟫ |
| | **Дат. мн.** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::
### 24.2.4. Гласови основи

::: grammar-box
**Гласови основи**

* **Мъжки род / Среден род на -a:** ⟪देव⟫
* Дат. ед. ⟪देवाय⟫
* Дат. мн. ⟪देवेभ्यस्⟫
* **Мъжки род на -i:** ⟪कवि⟫
* Дат. ед. ⟪कवये⟫
* Дат. мн. ⟪कविभ्यस्⟫
* **Мъжки род на -u:** ⟪पशु⟫
* Дат. ед. ⟪पशवे⟫
* Дат. мн. ⟪पशुभ्यस्⟫
* **Женски род на -ā:** ⟪देवता⟫
* Дат. ед. ⟪देवतायै⟫
* Дат. мн. ⟪देवताभ्यस्⟫
* **Женски род на -ī:** ⟪देवी⟫
* Дат. ед. ⟪देव्यै⟫
* Дат. мн. ⟪देवीभ्यस्⟫
* **Женски род на -i:** ⟪श्रुति⟫
* Дат. ед. ⟪श्रुतये⟫ или ⟪श्रुत्यै⟫ (т.е. като ⟪कवि⟫ или като ⟪देवी⟫)
* Дат. мн. ⟪श्रुतिभ्यस्⟫
* **Женски род на -u:** ⟪धेनु⟫
* Дат. ед. ⟪धेनवे⟫ или ⟪धेन्वै⟫
* Дат. мн. ⟪धेनुभ्यस्⟫
:::
## 24.3. Сандхи на крайните -ai и -au

::: grammar-box
**Сандхи на крайните -ai и -au**

* **-ai пред гласна обикновено се заменя с -ā (по-рядко с -āy, както в средата на думата)**
* **-au пред гласна обикновено се заменя с -āv (по-рядко с -ā)**

Пример:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा अग्नये⟫ = "на този огън"
:::
## 24.4. Речник на думите

⟪अलम्⟫ Наречие: достатъчно, напълно; (за някого или нещо) способен ; с датив: достатъчно за, напълно за; със инструментал: достатъчно с, престанай да , напр. ⟪अलं क्रोधेन⟫ = "достатъчно с гнева = престанай да се ядосваш!"

По същия начин, както ⟪अलम्⟫ с инструментал се използва:

⟪कृतम्⟫ : ⟪कृतं क्रोधेन⟫ = "Гневът е утихнал = престанай да се ядосваш!"

## 24.6. Допълнителни упражнения за употреба на датив
