# Урок 4

## 4.1. Прости допълнителни въпроси (въпросителни думи) и отговори

### 4.1.1. Въпросителни и указателни местоимения

#### 4.1.1.1. Въпросителни местоимения (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Именителен падеж, единствено число | Именителен падеж, множествено число |
| :--- | :--- | :--- |
| **Среден род** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Мъжки род** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Женски род** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Указателни местоимения (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Основа** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"той, тя, то; онзи, онази, онова":br(споменат)** | **etad = ⟪एतद्⟫:br"този, тази, това":br(много близо до говорещия)** | **idam = ⟪इदम्⟫:br"този, тази, това":br(близо)** |
| **Именителен падеж, единствено число** ||||
| **Среден род** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Мъжки род** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Женски род** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Именителен падеж, множествено число** ||||
| **Среден род** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Мъжки род** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Женски род** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**За им. ед. м.р.:**
**sa, eṣa** (⟪स एष⟫) стои пред всички звуци, освен краткото **-a**
**so, eṣo** (⟪सो एषो⟫) стои пред **-a**, което се елидира с авиграха (изпада)
**saḥ, eṣaḥ** (⟪सः एषः⟫) стои само в пауза (край на изречение, край на стих)

За да могат тези местоимения (sarvanāman n.) да се използват за образуване на изречения, е необходимо още познаването на следните правила за Сандхи:

### 4.1.2. Сандхи на крайното -m

::: grammar-box
**Крайното -m се заменя пред съгласни с Анушвара (-ṃ). В края на изречение или стих и пред гласни -m остава непроменено.**
:::
### 4.1.3. Сандхи на крайното -e

::: grammar-box
1. **пред a- крайното -e остава непроменено: началното a- се елидира с Аваграха:**
напр. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Тези огньове"

2. **Пред други гласни, различни от краткото a-, крайното -e обикновено се заменя с -a с хиазъм. Среща се и замяната с -ay:**
напр. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (рядко: imay īśvarāh = ⟪इमयीश्वराः⟫) "Тези ГОСПОДАРИ"
:::
### 4.1.4. Сандхи на крайното -d

::: grammar-box
**Крайното -d се заменя с -t в пауза, както и пред беззвучни гърлени (k, kh) и устни съгласни (p, ph).**

Замяната пред други съгласни ще бъде обсъдена по-късно. Временно избягвайте такива съвпадения на звуци!
:::
### 4.1.5. Въпросни формули

С помощта на тези местоимения се образуват например следните въпросни формули:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Ед. число** | **Среден род** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं किम्⟫, ⟪किमिदम्⟫ | "Какво е това?" |
| ^^| **Мъжки род** | sa kaḥ? / kaḥ saḥ?:br⟪स कः⟫, ⟪कः सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष कः⟫, ⟪क एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं कः⟫, ⟪को ऽयम्⟫ | "Кой е това?":br"Какъв е той?" |
| ^^| **Женски род** | sā kā? / kā sā?:br⟪सा का⟫, ⟪का सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं का⟫, ⟪केयम्⟫ | "Коя е това?":br"Коя е тя?" |
| **Мн. число** | **Среден род** | tāni kāni? / kāni tāni?:br⟪तानि कानि⟫, ⟪कानि तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि कानि⟫, ⟪कानीमानि⟫ | |
|^^ | **Мъжки род** | te ke? / ke te?:br⟪ते के⟫, ⟪के ते⟫:brete ke? / ka ete?:br⟪एते के⟫, ⟪क एते⟫:brime ke? / ka ime?:br⟪इमे के⟫, ⟪क इमे⟫ | |
| ^^| **Женски род** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः काः⟫, ⟪का एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः काः⟫, ⟪का इमाः⟫ | |
:::
Пример за други въпроси:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ Отговор: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (В именната конструкция може например да се постави подлогата в началото, за да се подчертае връзката с въпроса.)

ЗАБЕЛЕЖКА: Отговорите, които можете да дадете на такива въпроси с досегашните си знания по санскрит, разбира се, все още не отговарят напълно на идиоматичния санскрит.


## 4.2. Упражнение

**А) Образувате устно въпроси по схемата viṣṇuḥ kaḥ (⟪विष्णुः कः⟫) със следните думи и отговорете на въпросите на санскрит:**

śruti, śiva, brāhmaṇa, dvija (множествено число), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**Б) Образувате въпроси по модела etat kim (⟪एतत्किम्⟫) към следното упражнение за четене и отговорете на въпросите с посочените думи и указателни местоимения, напр. eṣa bālaḥ (⟪एष बालः⟫):**
