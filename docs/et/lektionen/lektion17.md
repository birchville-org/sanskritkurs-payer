# Lesson 17

## 17.1. Second Present Class (⟪अदादि⟫ = ⟪अद्⟫ etc.)

The verbal endings attach directly to the root. In doing so, one must observe the sound changes resulting from word-sandhi (phonetic combination).

::: grammar-box

The following formation types exist in the second present class:

1. Roots with stem gradation (apophony) 
*   mostly: strong grade - weak grade
*   some roots: guṇa grade (lengthened) - weak grade 
2. Roots without stem gradation
3. Two-syllable roots ending in -i/-ī with stem gradation

:::

## 17.2. Roots of the second present class with stem gradation strong grade - weak grade

Examples:

⟪द्विष्⟫ 2 U "to hate"

*   strong present stem: dveṣ-
*   weak present stem: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪द्वेष्टि⟫ (« dveṣ + -ti) |
| 3\. pl. Pres. P | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 3\. sg. Pres. Ā | ⟪द्विष्टे⟫ (« dviṣ + -te) |
| 3\. pl. Pres. Ā | ⟪द्विषते⟫ (dviṣ-ate) |

:::

The following word-sandhi rule applies here:

::: grammar-box

Word-sandhi of -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-

:::

Further examples:

⟪इ⟫ 2 P "to go" (Ā after certain prefixes)

*   strong present stem: e-
*   weak present stem:
*   before consonant: i-
*   before vowel: y-/iy-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪एति⟫ (e-ti) |
| 3\. pl. Pres. P | ⟪यन्ति⟫ (y-anti) |
| 3\. sg. Pres. Ā | ⟪इते⟫ (i-te) |
| 3\. pl. Pres. Ā | ⟪इयते⟫ (iy-ate) |

:::

⟪दुह्⟫ 2 U "to milk"

*   strong present stem: doh-
*   weak present stem: duh-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪दोग्धि⟫ (« doh- + -ti) |
| 3\. pl. Pres. P | ⟪दुहन्ति⟫ (duh-anti) |
| 3\. sg. Pres. Ā | ⟪दुग्धे⟫ (« duh- + -te) |
| 3\. pl. Pres. Ā | ⟪दुहते⟫ (duh-ate) |

:::

⟪हन्⟫ 2 P "schlagen, erschlagen, töten"

*   tugev oleviku tüvi: han-
*   nõrk oleviku tüvi:
*   kaashääliku ees: ha- (« \*hn-)
*   täishääliku ees: ghn-/han-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪हन्ति⟫ (han-ti) |
| 3\. pl. Präs. P | ⟪घ्नन्ति⟫ (ghn-anti) |
| 3\. sg. Präs. Ā | ⟪हते⟫ (ha-te) |
| 3\. pl. Präs. Ā | ⟪घ्नते⟫ (ghn-ate) |

:::

⟪अस्⟫ 2 P "sein"

*   starker Präsensstamm: as-
*   schwacher Präsensstamm: s-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪अस्ति⟫ (as-ti) |
| 3\. pl. Präs. P | ⟪सन्ति⟫ (s-anti) |

:::

## 17.3. Roots of the second present class with stem gradation lengthened grade - zero grade

Beispiel:

⟪स्तु⟫ 2 U "preisen"

*   tugev oleviku tüvi: stau-
*   nõrk oleviku tüvi:
*   kaashääliku ees: stu-
*   täishääliku ees: stuv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तौति⟫ (stau-ti):broder: ⟪स्तवीति⟫ |
| 3\. pl. Präs. P | ⟪स्तुवन्ति⟫ (stuv-anti) |
| 3\. sg. Präs. Ā | ⟪स्तुते⟫ (stu-te) |
| 3\. pl. Präs. Ā | ⟪स्तुवते⟫ (stuv-ate) |

:::

## 17.4. Roots of the second present class without stem gradation

::: grammar-box

Without stem gradation, roots of the second present class end in -ā

:::

Beispiel:

⟪पा⟫ 2 P "schützen, behüten, hüten"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪पाति⟫ (pā-ti) |
| 3\. pl. Präs. P | ⟪पान्ति⟫ (« pā- + -anti) |

:::

Also some other roots of the second class have no stem gradation:

Beispiele:

⟪अद्⟫ 2 P "essen"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪अत्ति⟫ (« ad- + -ti) |
| 3\. pl. Präs. P | ⟪अदन्ति⟫ (ad-anti) |

:::

⟪आस्⟫ 2 Ā "sitzen"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. Ā | ⟪आस्ते⟫ (ās-te) |
| 3\. pl. Präs. Ā | ⟪आसते⟫ (ās-ate) |

:::

⟪वच्⟫ 2 P "sagen"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪वक्ति⟫ (« vac- + -ti) |

:::

## 17.5. Disyllabic roots in -i/-ī with stem gradation

Several roots are disyllabic in a series of forms, i.e. they have an -i before consonantal endings (or -ī before some endings). Nevertheless, these roots are posited as monosyllabic by indigenous grammarians and in dictionaries, etc.

Beispiele:

⟪रुद्⟫ 2 P "weinen, heulen"

*   tugev oleviku tüvi: rodi-
*   nõrk oleviku tüvi:
*   kaashääliku ees: rudi-
*   täishääliku ees: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::

⟪ब्रू⟫ 2 U "sprechen"

*   tugev oleviku tüvi: bravī- (« bro- + -ī)
*   nõrk oleviku tüvi:
*   kaashääliku ees: brū-
*   täishääliku ees: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::

Ka ⟪स्तु⟫ 2 U "kiitma" omab lisaks punktis 3 toodud vormidele ka selle mustri järgi vorme:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::
