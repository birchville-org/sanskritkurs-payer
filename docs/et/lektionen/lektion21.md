# Lesson 21

## 21.1. Further present stems in -nt

### 21.1.1. Present Participle (⟪लडादेशः⟫) Parasmaipada

::: grammar-box

This participle is a nominal formation derived from the present stem, i.e., it is a true participle. It functions as an adjective indicating that someone or something is currently performing the action expressed by the verbal root (+ prefix) while another event occurs. It can also express a continuous state.

**Examples:**

:::

::: indent

"While the father reads, he smokes = the reading father smokes"  
"a being (= real, genuine) friend"

:::

::: grammar-box

| **Formation of the Present Participle Parasmaipada for thematic present stems:** |||
| :--- | :--- | :--- |
| **Masculine, Neuter** | | |
| | **strong stem** | present stem + **-nt-** |
| | **weak stem** | present stem + **-t-** |
| **Feminine** | | |
| | | present stem + **-nt-** + **-ī** (declension like **devī** :br⟪देवी⟫) |
| | **6th present class** | present stem + **-nt-** + **-ī** :broder::brpresent stem + **-t-** + **-ī** |

:::

## 21.3. Viisakad pöördumisvormid

::: grammar-box

**Sanskriti keeles võib kellegi poole pöörduda ainsuse 2. isikus, ilma et see oleks ebaviisakas. Kui aga soovitakse olla viisakas, võib kasutada nimisõna, mille tähendus on "austatud" ja sarnane, ning panna tegusõna ainsuse või mitmuse 3. isikusse või kasutada passiivkonstruktsiooni. Viisakuse astmete suurenemine pöördumisel isiku kasutamisel on umbes järgmine:**

:::

::: indent

**2. ainsus » 2. mitmus » 3. ainsus vastava nimisõnaga » 3. mitmus vastava nimisõnaga**

:::

**Kõige olulisem selline viisakusnimisõna on ⟪भवन्त्⟫, naissoost: ⟪भवती⟫. See vastab oma kasutuselt meie viisakale "Teie".**
See ⟪भवन्त्⟫ on lühend sõnast ⟪भगवन्त्⟫, selle käändumine on sama mis **-vant**-lõpulistel nimisõnadel (vt [13. õppetund](lektion13.md)). Seda ⟪भवन्त्⟫ tuleb eristada ⟪भू⟫ "saama" oleviku kesksõnast ⟪भवन्त्⟫: ⟪भवन्त्⟫ "Teie" meessoost ainsuse nimetav kääne on ⟪भवान्⟫, kesksõna oma on ⟪भवन्⟫.

**Beispiele:**

::: indent

**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = "Mida Te teete?"

:::

höflicher:

::: indent

**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**

:::

Femininum:

::: indent

**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**

:::

Teised sõnad, mida saab kasutada sarnaselt ⟪भवन्त्⟫-ga:

*   ⟪आर्य⟫ (n.: ⟪आर्या⟫) "õilis". nt **⟪यदार्य⟫ ⟪इच्छति⟫** "Mida Te soovite"
*   ⟪महाभाग⟫ "see, kelle osa / õnn on suur = üllas". Sageli kasutavad naised pöördumisel või rääkides heast seisusest meestest. Kaasaegses kõnes sanskriti keeles väga levinud.

Kui soovitakse väljendada kellegi vastu mitte ainult viisakust, vaid ka austust, kasutatakse kohalviibiva või lähedalasuva isiku puhul ⟪भवन्त्⟫ asemel ⟪अत्रभवन्त्⟫, puuduva või eemalasuva isiku puhul ⟪तत्रभवन्त्⟫. ⟪अत्रभवन्त्⟫ ja ⟪तत्रभवन्त्⟫ võib tõlkida kui "Teie", "Auväärne", "Kõrgeausus" jne:

::: indent

**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = "Kas see armuline (siin viibiv) daam on teie abikaasa?"
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (kirjas või telefonivestluses) = "Kuidas teil läheb?"

:::
