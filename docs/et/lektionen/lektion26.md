# Lektion 26

## 26.1. Cerebraalse assimilatsiooni seadus -s- jaoks sõna sees

::: grammar-box

**-s-** asendatakse **-ṣ-**-ga, kui **k, r, l** või **vokaal** — välja arvatud **a, ā** — eelneb vahetult või on eraldatud ainult ⟪अनुस्वार⟫ või ⟪विसर्ग⟫-ga ja järgneb muu heli kui **ṛ, r**.

Seda sandhit järgib ka **⟪दुस्⟫-** enne helituid guturaale ja labiaale liitsõnades.

:::

*Beispiele:*

::: indent

⟪तेषाम्⟫ (aus: *te-sām*)

aber: ⟪तासाम्⟫ (*tā-sām*)

:::

## 26.2. Dentaalide cerebraalse assimilatsiooni seadus sõna sees

::: grammar-box

Dentaalsed sulghäälikud asendatakse pärast retroflekse (kaasa arvatud **-ṣ-**) vastavate retrofleksidega:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** wegen des vorangehenden **i**, **ṭh** wegen des dann vorausgehenden **ṣ**)*

:::

## 26.3. Sõnasandhi palataali, guturaali, ṣ, h + -s jaoks

::: grammar-box

**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

Beispiele siehe unten

:::

## 26.4. Grassmanns Hauchdissimilationsgesetz

::: grammar-box

**Kahe aspiraadi (aspiraat - vokaal - aspiraat) vahetu järgnemine toob kaasa esimese hääliku aspiratsiooni kadumise:**

Beispiel:

:::

::: indent

\*dhu(gh) » du(g)h

:::

**Kui häälikuseaduste tõttu kaotab teine häälik oma aspiratsiooni, siis ilmub aspiratsioon uuesti esimese hääliku juurde.**

## 26.6. Lihtfutuurumi (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) kasutus

::: grammar-box

**Lihtfutuurum (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) väljendab:**

**tulevikku**
**kavandatud või tahtlikku tegevust ("ma lähen", "ma tahan minna")**
**ootust ("see juhtub nii")**
**lootust**
**kartust**
**tõenäosust**
**kõneleja arvamust**
**käsku**

**Futuurum konkureerib osaliselt optatiiviga (vt hiljem).**

:::

## 26.7. Lihtfutuurumi (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) moodustamine

::: grammar-box

**Einfaches Futur:**

:::

::: indent

**Futursstamm + Primärendung**

:::

::: grammar-box

**Futurstamm:**

:::

::: indent

**(enamasti) kõrgtaseme tüvi + -sya**
**või**
**(enamasti) kõrgtaseme tüvi + -i- + -sya (= - iṣya)**

:::

**Milline tüvi millise futuurumi tüve moodustab, tuleb õppida koos tüvevormidega!**
**Üldiselt ühtivad futuurumi tüvevorm ja sidevokaal infinitiiviga.**
**Mõned tüved võivad futuurumi moodustada valikuliselt nii sidevokaaliga -i- kui ka ilma.**
**Futuurumi Parasmaipada partitsiip moodustatakse sufiksi -nt- lisamisega futuurumi tüvele, naissoost on valikuliselt -ntī või -tī:**

⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫

:::
