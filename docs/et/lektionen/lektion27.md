# Lesson 27

## 27.1. Use of the Locative (⟪सप्तमी⟫ f. = "seventh case ending")

::: grammar-box

**The Locative (⟪सप्तमी⟫) answers the questions:**
*   **where?**
*   **when?**
*   **under what circumstances?**
*   **with respect to what?**

:::

::: grammar-box

**1. The Locative (⟪सप्तमी⟫) answers the question "Where?" by indicating the space in (at, on, near) which the agent (⟪कर्ता⟫) or object of an action is located, or where the action itself takes place.**

> ⟪नगरे वसति⟫ = "He lives in the city"

:::

::: media

![](/images/lekt2701.webp)

Fig.: ⟪जयपुरनगरे⟫
Jaipur, 1875.
(Image source: [Details](/et/licenses#lekt2701))

:::

::: grammar-box

**2. The Locative answers the question "When?" by indicating the point in time or external circumstances:**

> ⟪तस्मिन्काले⟫ = "at that time, at this time"

**Also belonging here is the so-called Locativus Absolutus:**

**If an action or state of a person or thing determines the time at which, or the circumstances under which, ANOTHER person or thing performs an action or is in a specific state, then the word designating the first person or thing, together with the word specifying it further (which is often a participle), appears in the Locative case (⟪सप्तमी⟫):**

> ⟪एवं गच्छति काले⟫ = "while time passes thus..."
\>
> ⟪तस्मिन्गते⟫ = "when he had gone..."

**Sometimes the agent (⟪कर्ता⟫) is not explicitly stated:**

> ⟪एवं सति⟫ = "since it is so"

**The Locativus Absolutus must be translated according to context as "while" (e.g., Present Participle), "after", "when" (e.g., PPP), "since", "because", "although", "if", etc.**

**Note: In the absolute construction, the agent of the absolute must be identical to the agent of the main clause; in the locative absolute, the agent of the locative absolute and the agent of the main verb must be different.**

:::

::: media

![](/images/lekt2702.webp)

Fig.: ⟪एवं गच्छति कालयुष्ट्रः स्वपित⟫i
Rajasthan.
(Image source: [Details](/et/licenses#lekt2702))

:::

::: grammar-box

**3. The locative also answers the question "With respect to what?" etc.:**

> ⟪अस्ति तस्य पुत्रे स्नेहः⟫ = "He has love for his son" (literally: "With respect to the son, there is love in him")

:::

::: media

![](/images/lekt2703.webp)

Fig.: ⟪अस्ति तस्य पुत्रे स्नेहः⟫
Holi.
(Image source: [Details](/et/licenses#lekt2703))

:::

::: grammar-box

**4. The locative is used in native dictionaries and by commentators to indicate the meaning of a word:**

> ⟪भू सत्तायाम्⟫ = "the root ⟪भू⟫ in the meaning 'beingness' (sat-tā)"

:::

Further details on the usage of the locative will follow later.

## 27.2. Formation of the Locative (⟪सप्तमी⟫)

::: grammar-box

**The regular endings of the locative (⟪सप्तमी⟫) are:**
*   **Singular: -i**
*   **Plural: -su**

**Note the sound changes before -su as well as the possible cerebralization of -su to -ṣu!**

:::

## 27.4. Salm kõigi käändevormidega (ainsus) sõnast ⟪राम⟫

::: media

![](/images/lekt2708.webp)

Rāma-Satz.
(Pildi allikas: [Details](/et/licenses#lekt2708))

:::

sig[⟪रामो⟫] ⟪राजमणिः सदा विजयते⟫ :sig[⟪रामं⟫] ⟪रमेशं भजे⟫:br :sig[⟪रामेणा⟫]⟪भिहता निशाचरचमू⟫ :sig[⟪रामाय⟫] ⟪तस्मै नमः ।⟫:br :sig[⟪रामान्ना⟫]⟪स्ति परायणम् परतरं⟫ :sig[⟪रामस्य⟫] ⟪दासोऽस्म्यहम्⟫:br :sig[⟪रामे⟫] ⟪चित्तलयः सदा भवतु मे भो⟫ :sig[⟪राम⟫] ⟪मामुद्धर ॥⟫

**Tõlge:**
1. **Nimetav:** Rāma, kuningate (⟪राजन्⟫ m.) juveel (⟪मणि⟫ m.) võidab alati (⟪सदा⟫).
2. **Omastav:** Ma armastan (⟪भज्⟫ 1U) Rāmat, Ramā (= Lakṣmī) isandat ja abikaasat (⟪ईश⟫ m.).
3. **Alaleütlev:** Rāma tappis öösel ringi uitajate (= deemonite) (⟪निशा⟫ f. = öö) armee (⟪चमू⟫ f.).
4. **Daativ:** Sellele Rāmale olgu austus!
5. **Ablatiiv:** Parem (⟪परतर⟫ 3) varjupaik (⟪परायण⟫ n.) kui Rāma puudub.
6. **Genitiiv:** Mina (⟪अहम्⟫) olen (⟪अस्मि⟫) Rāma teenija.
7. **Lokatiiv:** Rāmas olgu (⟪भवतु⟫) alati minu (⟪मे⟫) südame rahu (⟪लय⟫ m.).
8. **Vokatiiv:** Rāma, päästa (⟪उद्धर⟫ = imperatiiv sõnast ⟪उद्⟫ + ⟪हृ⟫ või ⟪उद्⟫ + ⟪धृ⟫) mind (⟪माम्⟫)!
