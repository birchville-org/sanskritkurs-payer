## 41.2. Further ⟪कृत्⟫ formations on -a

### 41.2.1. Present Participle (⟪लडादेशः⟫) Ā, Passive Present Participle (⟪लडादेशः⟫) Ā, Future Participle (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Thematic present stems, passive and future

::: grammar-box

**Formation:**

Present stem / passive stem / future stem + -māna (fem. mānā)

:::

Examples:

⟪यज्⟫ 1U, Pres.P.Ā ⟪यजमान⟫ 3 "one who is honoured with a sacrifice for one's own benefit = lord of the sacrifice"

⟪मन्⟫ 4Ā, Pres.P.Ā ⟪मन्यमान⟫ 3 "a thinking one"

⟪कृ⟫ 8U, Pres.P.Pass. ⟪क्रियमाण⟫ 3 "something that is done"

⟪दा⟫ 3U, Fut.P.Ā ⟪दास्यमान⟫ 3 "one who will give for one's own benefit"

#### 41.2.1.2. A-thematic present classes

::: grammar-box

**Formation:**

Weak present stem (in the form it has before the ending -ate of 3.pl.Ā) + -āna (fem. -ānā)

:::

Examples:

::: grammar-box

| Root / Class | Present Participle Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |

:::

### 41.2.2. Passiivse vajaduse "kesksõna" (gerundiiv) (⟪कृत्य⟫)

::: grammar-box

**To express passive necessity ("what must/should be done"), adjectives derived from roots and derived verbal stems can optionally be formed with the following suffixes:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (statt **-⟪य⟫**/**-⟪या⟫**)

:::

#### 41.2.2.1. Sufiks -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box

**Sufiks -⟪तव्य⟫ / -⟪तव्या⟫ lisatakse tüvedele ja tuletatud tegusõnatüvedele (nt kausatiiv) samamoodi nagu infinitiivi sufiks -⟪तुम्⟫ (vt [23. õppetund](lektion23.md)), st**

* **hochstufige Wurzel + ⟪तव्य⟫**

oder

* **hochstufige Wurzel + -i- + ⟪तव्य⟫**

**Kausatiivis:**

* **Causative stem in -ay + -i- + ⟪तव्य⟫**

:::

Beispiele:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "jemand, der besiegt werden muss; ein zu besiegender" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "das, wo man sich befinden soll" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "jemand, der geweckt werden soll; ein zu erweckender" |

:::

#### 41.2.2.2. Sufiks -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box

**Bildung:**

Hochstufige Wurzel + -⟪अनीय⟫ / -⟪अनीया⟫

**Causative and 10th conjugation class:**

Root as it appears in the causative stem, without -aya- + -⟪अनीय⟫ / -⟪अनीया⟫

:::

Beispiele:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "zu gebendes; was gegeben werden muss" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "zu besiegender" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "zu tuendes" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "was man sehen muss; sehenswertes" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "ein zu weckender" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "was man geben lassen muss" |

:::

#### 41.2.2.3. The Suffix -⟪य⟫ / -⟪या⟫

::: grammar-box

**Formation:**

Root (in weak, strong or guṇa grade) + -⟪य⟫

For the exact rules, see Kielhorn, Grammar of the Sanskrit Language, pp. 195 - 197!

:::

Treatment of final vowels:

::: grammar-box

**1. Roots ending in -ā form this gerundive with the suffix -eya**

:::

Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "to be known; that which must be recognized" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "that which must be given" |

:::

::: grammar-box

**2. Roots ending in -i /-ī / -u / -ū /-ṛ generally have strong or guṇa grade, unless they belong to those roots ending in -i / -u /-ṛ that form a gerundive with the suffix -⟪त्य⟫ (fem. -⟪त्या⟫) (list of these roots in Kielhorn, Grammar §537).**

:::

Example:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 | "that which must be remembered" |

:::

::: grammar-box

**2a. Roots ending in -i/-ī have strong grade**

:::

Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | "to be sold; salable" |
| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "to be led" |

:::

![lekt4103.jpg](/images/lekt4103.webp)

:::

::: grammar-box

**2b. Roots ending in -u /-ū replace the strong grade -o before -ya with -av, and the guṇa grade -au with -āv. Guṇa grade formation in this case denotes necessity.**

:::

Example:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्तु⟫ 2U | ⟪स्तव्य⟫ 3 | "that which should be praised" |
|   | ⟪स्ताव्य⟫ 3 | "that which must necessarily be praised" |

:::

#### 41.2.2.4. Sufiks -⟪त्य⟫ / ⟪त्या⟫ (sufiksi -⟪य⟫ / -⟪या⟫ asemel)

::: grammar-box

Liste der Wurzeln auf -i / -u /-ṛ, die ein Gerundiv statt mit -⟪य⟫ / -⟪या⟫ mit dem Suffix -⟪त्य⟫ (fem. -⟪त्या⟫) bilden, bei Kielhorn, Grammatik §537.

### 41.2.3. Passiivse vajaduse "kesksõna" (gerundiivi) (⟪कृत्य⟫) süntaks

::: grammar-box

The gerundive can be used attributively:

:::

::: indent

**⟪दर्शनीयं नगरम्⟫** = "linn, mida peab nägema; vaatamisväärne linn"

:::

Gerundiivi saab kasutada ka predikaatnimisõnana lausetes, millel on passiivne konstruktsioon ja mis väljendavad kohustust või käsku (koos ⟪न⟫-ga keeldu, võimatust):

::: indent

**⟪काशी द्विजैर्द्रष्टव्या⟫** = "Kaks korda sündinud peavad nägema Benaresit"

:::

### 41.2.4. Differences in the usage of the gerundive suffixes

::: grammar-box

The usage of these suffixes largely overlaps

* **-⟪तव्य⟫ (naissoost -⟪तव्या⟫):** väljendab alati vajadust ja seda kasutatakse eelistatult predikatiivselt (harvem atributiivselt). Selle sufiksiga moodustatud sõnu ei tohiks kasutada nimisõnaühendites.
* **-⟪अनीय⟫ (naissoost -⟪अनीया⟫) ja -⟪य⟫ (naissoost -⟪या⟫) / -⟪त्य⟫ (naissoost -⟪त्या⟫) (sufiksi -⟪य⟫/-⟪या⟫ asemel):** võivad omada täiendavat tähendust (eriti -⟪य⟫) saksa keele "-wert" (nt "sehenswert" – vaatamisväärne) või lihtsalt võimalust "-bar" (⟪दृश्य⟫ "sichtbar" – nähtav). Nende sufiksitega moodustatud sõnu saab eitada ⟪अ⟫-/-⟪अन्⟫- abil (kuid mitte -⟪तव्य⟫-ga moodustatud sõnu) ja esineb ⟪तत्पुरुष⟫, mille tagaliikmena need esinevad.

:::

### 41.2.5. Puudub ühendus ⟪सु⟫- ja ⟪दुस्⟫-ga

::: grammar-box

Gerundiive ei tohi ühendada ⟪सु⟫- ja ⟪दुस्⟫-ga tähenduses "lihtne" või "raske". Selle asemel kasutatakse ⟪तत्पुरुष⟫ tüüpi ⟪सुकर⟫ 3 ("lihtne teha") (vt [18. õppetund](lektion18.md)).

:::
