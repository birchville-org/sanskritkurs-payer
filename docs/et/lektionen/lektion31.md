# Lektsioon 31

## 31.1. 7. praesensklass (⟪रुधादि⟫ = "⟪रुध्⟫ jne")

::: grammar-box

**Koostis:**

**Sügavastadi juure lõpus kaonantside ees sisestatakse nn nasaliinfix (-na- või -n-):**

*   **tugevas varras: -na-**
*   **nõrgas varras: -n-**

**Juure lõppkaonantside ja kaonantsiga algavate pöördete ühendamise kehtivad samad reeglid mis 2. praesensklassi puhul.**

:::

Näited:

⟪युज्⟫ 7U "ühendama, rakendama"

::: grammar-box

**For some roots, the -n- of the weak present stem has also penetrated into non-present tenses, so that these roots are posited with an infix nasal.**

:::

Beispiel:

⟪भञ्ज्⟫ 7P "brechen"

::: indent

*   Oleviku indikatiiv
*   3.ains.P. ⟪भनक्ति⟫ (bha-na + j + ti)
*   3.mitm.P. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Tulevik: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Passiiv: ⟪भज्यते⟫ (kas algsest juurest ⟪भज्⟫ või *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (võimalik, et *bhñj + na)

:::
