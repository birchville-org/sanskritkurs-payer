# Lesson 34

## 34.1. The Perfect (⟪लिट्⟫)

In Classical Sanskrit, the perfect stem has only indicative and participle forms.

::: grammar-box

**There are two types of perfect formation:**
*   **the reduplicated perfect = ⟪द्वित्वलिट्⟫**
*   **the periphrastic perfect = ⟪अनुप्रयोगलिट्⟫**

:::

::: grammar-box

**The periphrastic perfect (⟪अनुप्रयोगलिट्⟫) is used:**
1. **with derived conjugations (causative, desiderative, frequentative, denominatives)**
2. **with roots that begin with a long vowel (except ā-) or with a vowel (except a-) before two consonants**
3. **with some other roots**

:::

## 34.2. The reduplicated perfect (⟪द्वित्वलिट्⟫)

### 34.2.1. Stem gradation

::: grammar-box

**Formation:**

**strong stem:** singular parasmaipada
*   **reduplicated guṇa or vṛddhi grade root + perfect ending**

**weak stem:** all other forms
*   **reduplicated zero grade root + perfect ending**

:::

::: grammar-box

**Generally (also outside the perfect), roots of the following forms do not undergo stem gradation:**
*   **(consonant)-vowel-long vowel-consonant**
*   **(consonant)-vowel-vowel-consonant-consonant**

**In the perfect, additionally, roots of the following forms do not undergo stem gradation:**
*   **a-consonant**
*   **ā-consonant**

:::

### 34.2.2. The perfect endings

::: grammar-box

| | 3rd singular | 3rd plural |
| :--- | :--- | :--- |
| **parasmaipada** | **-a** | **-ur** |
| **ātmanepada** | **-e** | **-re** |

:::

### 34.2.3. Connecting vowel -i-

::: grammar-box

**Before the ending of the 3rd plural ātmanepada (-re), the connecting vowel -i- always appears; before other consonant-initial endings in the plural, it appears for most roots.**

:::

### 34.2.4. Reduplikation konsonantisch anlautender Wurzeln

::: grammar-box

**Reduplikatsiooni alguskonsonantide puhul kehtivad [33. õppetükis](lektion33.md) toodud reeglid.**

**Reduplikatsiooni vokaal konsonandiga algavate tüvede puhul on lühike tüvevokaal.**

**Diftongid enne konsonanti redutseeritakse vastavaks lühikeseks madala astme vokaaliks.**

**ṛ, ṝ, ḷ ja lõpus olevad diftongid reduplitseeritakse -a- abil.**

:::

Examples:

::: grammar-box

| Root | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::

::: grammar-box

**Mõned y- või v-ga algavad tüved reduplitseeruvad i- või u-ga, mis nõrkades vormides tüvevokaaliga "sulandub".**

:::

Examples:

::: grammar-box

| Root | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::

### 34.2.5. Reduplikation vokalisch anlautender Wurzeln

::: grammar-box

**1. algav a-, ā- reduplitseeritakse a-ga, nii et ilmub ā-.**

:::

Examples:

::: grammar-box

| Root | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "sein" und ⟪अस्⟫ 4 "werfen" | ⟪आस⟫:bra + as-a |

:::

::: grammar-box

**2. i-ga algavate tüvede reduplikatsioonisilp on tugevas tüves iy-, nõrgas tüves i-, mis tüvevokaaliga ī-ks "sulandub". Analoogne kehtib u-ga algavate tüvede puhul.**

:::

Examples:

::: grammar-box

| Root | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::

::: grammar-box

**3. Tüvedel, mis algavad a-ga enne kahte konsonanti või ṛ-ga, on reduplikatsioonisilp ān-.**

:::

Beispiele:

::: grammar-box

| Stamm | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::

## 34.3. Reduplitseeritud perfekti tüübid

Klassifitseerimispõhimõte: Tüveastmestiku eripärad:
*   Perfekt ilma tüveastmestikuta: Tüüp I
*   Perfekt tüveastmestikuga: Tüüp II - V
*   Ebaregulaarsed perfektivormid

## 34.4. Perfekt Tüüp I: Perfekt ilma tüveastmestikuta

::: grammar-box

**Perfekt Tüüp I (ilma tüveastmestikuta) on järgmiste tüüpide tüvedel:**
*   **(Konsonand)-Konsonand-Pikkvokaal-Konsonand**
*   **(Konsonand)-Konsonand-Vokaal-Konsonand-Konsonand**
*   **a-Konsonand**
*   **ā-Konsonand**

:::

Beispiele:

::: grammar-box

| Stamm | 3. sg. Perf. | 3. pl. Perf. |
| :--- | :--- | :--- |
| ⟪बन्ध्⟫ 9P | ⟪बबन्ध⟫:brba-bandh-a | ⟪बबन्धुर्⟫ |
| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |
| ⟪आप्⟫ 5P | ⟪आप⟫:bra + āp-a | ⟪आपुर्⟫ |
| ⟪अस्⟫ 2P "sein":br⟪अस्⟫ 4 "werfen" | ⟪आस⟫:bra + as-a | ⟪आसुर्⟫ |
| ⟪अश्⟫ | ⟪आनशे⟫:brunregelmässige Reduplikation! | ⟪आनशिरे⟫ |

:::

## 34.5. Perfekt Typ II: Starker Stamm Hochstufe, schwacher Stamm Tiefstufe

::: grammar-box

**Moodustatakse järgmise vormiga tüvedest:**
*   **(Konsonand)-(Konsonand)-i/u/ṛ/ḷ-Konsonand**

**Bildung:**
*   **starker Stamm: Hochstufe**
*   **schwacher Stamm: Tiefstufe**

:::
