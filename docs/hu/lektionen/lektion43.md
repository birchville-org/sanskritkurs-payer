# Lecke 43

## 43.1. A második személy ragozóvégződéseinek (⟪मध्यमः⟫ = "középső \<Személy\>")

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Prímár végződés** | -si | -tha | -se | -dhve |
| **Szekundér végződés** | -s | -ta | -thās | -dhvam |
| **Perfekt végződés** | -tha | -a | -se | -dhve |
:::
Vegye észre, hogy a második személy többes számú szekundér végződése megegyezik a harmadik személy egyes számú átmédiumos szekundér végződésével.

## 43.2. A második személy ragozott alakjainak képzése (⟪मध्यमः⟫)

Második személy:

*   Egyes szám: "te"
*   Többes szám: "ti" (kettőnél több!)

## 43.3. A második személyű névmás

*   Ees szám: ⟪त्वद्⟫ "te"
*   Többes szám: ⟪युष्मद्⟫ "ti"

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम् त्वा⟫ | ⟪युष्मान् वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम् ते⟫ | ⟪युष्मभ्यम् वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪तव ते⟫ | ⟪युष्माकम् वस्⟫ |
| ⟪सप्तमी⟫ | ⟪त्वयि⟫ | ⟪युष्मासु⟫ |
:::
A ⟪त्वा⟫, ⟪ते⟫, ⟪वस्⟫ alakokat nem szabad egy mondat vagy egy versszak elején használni. Ugyanígy a ⟪च⟫, ⟪वा⟫, ⟪एव⟫ és néhány más partikula előtt sem alkalmazhatók:

::: indent
⟪त्वां मां च⟫ "téged és engem"
:::
