# ትምህርት 37

## 37.1. ቃላት (⟪क्रियाविशेषणम्⟫)

በሳንስክሪት ቃላት ይፈጠራሉ

1.  በስም እና በምንጮች ሁኔታዎች
2.  በተለየ ቅጦች እና መጨረሻዎች በመጠቀም

በመጀመሪያው ሁኔታ ውስጥ በሕይወት ያለው ሁኔታ እና በቃላት መካከል ያለው ገደብ ይለዋወጣል። ይህንን ለማካተት እንደ ልዩ ሁኔታ የሚቆጠሩት ቃላት፣ የተረጋጉ፣ ጥንታዊ ሁኔታዎች ናቸው፣ በሌላ በኩል በመደበኛ ስም ውስጥ ሌሎች ሁኔታዎች ይጠቀማሉ ወይም ተመጣጣኝ ስሞች እንደ ስም አይጠቀሙም።

## 37.2. የሁኔታ ቃላት

### 37.2.1. አካሳቲቭ (⟪द्वितीया⟫)

::: grammar-box

አካሳቲቭ (⟪द्वितीया⟫) በቃላት ሊጠቀም ይችላል በጥያቄዎች፡

*   በምን አይነት መንገድ?
*   ምን ያህል ጊዜ?
*   ወዴት?
*   እና ሌሎች።

አካሳቲቭ በቃላት ሊጠቀም ይችላል፡

*   ከስሞች  
ምሳሌዎች፡  
⟪कामम्⟫ "በፍላጎት መሰረት፣ በፍላጎት"  
⟪अर्थम्⟫ "ለምክንያት"  

*   ከአስተያየቶች በንጥረ ነገር  
ምሳሌዎች፡  
⟪सुखम्⟫ "ቀላል፣ ደስተኛ"  
⟪नित्यम्⟫ "ሁልጊዜ"  
⟪साधु⟫ "ትክክል፣ ጥሩ"  

*   ከምንጮች በንጥረ ነገር  
ምሳሌዎች፡  
⟪तद्⟫ "ከዚያ፣ ስለዚህ"  
⟪यद्⟫ "እንደ፣ ወደ"  
⟪एतद्⟫ "እንደ፣ እዚህ፣ አሁን"

:::

### 37.2.2. ኢንስትሩመንታሊስ (⟪तृतीया⟫)

::: grammar-box

ኢንስትሩመንታሊስ (⟪तृतीया⟫) በቃላት ሊጠቀም ይችላል በጥያቄዎች፡

*   በምን?
*   በምን ጋር?
*   እና ሌሎች።

ኢንስትሩመንታሊስ በቃላት ሊጠቀም ይችላል፡

*   ከስሞች  
ምሳሌዎች፡  
⟪अर्थेन⟫ "ለምክንያት"  
⟪क्षणेन⟫ "በወቅቱ፣ ወዲያውኑ" (ከ ⟪क्षण⟫ m. "ወቅት")  

*   ከአስተያየቶች፣ ብዙ ጊዜ በብዛት ስም  
ምሳሌዎች፡  
⟪दूरेण⟫ "ርቆ፣ ከርቀት" (ወደ ⟪दूर⟫ 3 "ርቆ፣ ከርቀት")  
⟪उच्चैस्⟫ "ከፍተኛ፣ ከፍተኛ" (ወደ ⟪उच्च⟫ 3 "ከፍተኛ፣ ከፍተኛ፣ ከፍተኛ፣ ከፍተኛ (ከድምጽ)")

:::

### 37.2.3. ዳቲቭ (⟪चतुर्थी⟫)

::: grammar-box

በጣም አልተለመደም ሆኖ ዳቲቭ (⟪चतुर्थी⟫) በሚከተሉት ጥያቄዎች ላይ እንደ አዮብያዊ (adverbial) ያገለግላል፡-

*   ለምን ዓላማ?
*   እና ሌሎች

ምሳሌ፡-

:::

::: indent

⟪अर्थाय⟫ "ለ... ዓላማ፣ ... ለማድረግ"

:::

### 37.2.4. አብላቲቭ (⟪पञ्चमी⟫)

::: grammar-box

አብላቲቭ (⟪पञ्चमी⟫) እንደ አዮብያዊ (adverbial) በሚከተሉት ጥያቄዎች ላይ ሊያገለግል ይችላል፡-

*   ለምን?
*   በምን ምክንያት?
*   ከየት?
*   እና ሌሎች

አብላቲቭ እንደ አዮብያዊ (adverbial) ሊያገለግል የሚችለው፡-

*   ከስም (Substantiven)  
ለምሳሌ፡- ⟪बलात्⟫ "በግፊት፣ በኃይል"  

*   ከባለጾሮ (Adjektiven)  
ለምሳሌ፡- ⟪दूरात्⟫ "ከሩቅ"  

*   ከተውላጠ ስሞች
ምሳሌዎች፡-  
⟪कस्मात्⟫ "ለምን"  
⟪अकस्मात्⟫ "ያልተጠበቀ"

:::

### 37.2.5. ጀኔቲቭ (⟪षष्ठी⟫)

::: grammar-box

በጣም አልተለመደም ሆኖ ጀኔቲቭ (⟪षष्ठी⟫) "ከምን ያህል ጊዜ በኋላ?" በሚለው ጥያቄ ላይ እንደ አዮብያዊ (adverbial) ያገለግላል።

ለምሳሌ፡- ⟪चिरस्य⟫ "ከረጅም ጊዜ በኋላ" (ወደ ⟪चिर⟫ 3 "ረጅም (ጊዜ)")

:::

### 37.2.6. ሎኬቲቭ (⟪सप्तमी⟫)

::: grammar-box

ሎኬቲቭ (⟪सप्तमी⟫) እንደ አዮብያዊ (adverbial) በሚከተሉት ጥያቄዎች ላይ ሊያገለግል ይችላል፡-

*   እየት?
*   በምን ሁኔታዎች?
*   እና ሌሎች

ምሳሌዎች፡-

:::

::: indent

\-⟪अर्थे⟫ "በምክር"  
\-⟪कृते⟫ "ለ... ዓላማ"  
⟪दूरे⟫ "ርቆ"

:::

## 37.3. አዮብያዊ አገልግሎት የማይጠቀሙባቸው የቀድሞ ኬሱ ቅርጾች

ምሳሌዎች፡-

::: indent

⟪जातु⟫ "በጠቅላላው" (በመጀመሪያ "ከልደት፣ ከተፈጥሮ"፣ አኩዬቲቭ ነጠላ ለንግድ ወደ ⟪जातु⟫ \<በስምነት አሁን አይጠቀምበትም\>)

⟪तूष्णीम्⟫ "ድምጽ አልባ" (አኩዬቲቭ ነጠላ ወደ አሁን የማይጠቀምበት ⟪तूष्णी⟫ ሴት "ድምጽ አልባነት")

⟪एवम्⟫ "እንዲህ" (ወደ በሌላ በኩል የጠፋ ምንጭ ⟪एव⟫ "አንድ፣ ብቸኛ")

:::

## 37.4. ትምህርት 37.4. የአዮብ ቃላትን በአዮብ ቃላት ማጠናከሪያዎች መጠቀም

::: grammar-box

ከፕሮኒሚናል ስርዓቶች ⟪तद्⟫, ⟪इदम्⟫ ወይም ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ ወይም ⟪कु⟫ ጋር አዮብ ቃላት ማጠናከሪያዎችን በመጠቀም

*   \-⟪तस्⟫ (አብላጭ)
*   \-⟪त्र⟫ (ሎኬቲቭ)
*   \-⟪था⟫ (አይነት እና መንገድ)
*   \-⟪थम्⟫ (አይነት እና መንገድ)
*   \-⟪दा⟫ (ጊዜ)

ተዛማጅ ፕሮኒሚናል አዮብ ቃላትን መጠቀም ይቻላል።

:::

## 37.5. ሰዋስባዊ ኮምፖዚታ

### 37.5.1. ኮምፖዚታ በአዮርቭ ወይም በአዮርቭ ልክ የሚጠቀም ካሱ እንደ ኋላ ክፍል

ምሳሌ: ⟪सुचिरम्⟫ "በጣም ረጅም (ጊዜ)"

### 37.5.2. በአዮርቭ ልክ የሚጠቀም ⟪बहुव्रीहि⟫

ምሳሌ: ⟪रक्षार्थम्⟫ "እንደ ማስተዳደር ዓላማ ያለው ሰው ልክ፣ ለማስተዳደር ዓላማ"። እንደ 5.1. የሚያካትት ሊታሰብ ይችላል፡- ⟪अर्थम्⟫ እንደ አዮርቭ ኋላ ክፍል።

### 37.5.3. ⟪अव्ययीभाव⟫-ኮምፖዚታ

⟪अव्ययीभाव⟫ = "ቋሚ/ማይለወጥ የሆነ"

::: grammar-box

⟪अव्ययीभाव⟫ ማለት አዮርቭ ኮምፖዚም ሲሆን፣ ፊት ለፊት ክፍሉ ኢንዴክሊናብል (ፖስትፖዚሽን፣ ፓርቲክል ወዘተ) ሲሆን፣ ኋላ ክፍሉ ደግሞ የአካዬቲቭ ሲንጉላር ኒውትረም መጨረሻ የሚወስድ ስም ነው።

ኮምፖዚሙን ስንፈታው፣ ፊት ለፊት ክፍሉ ኋላ ክፍሉን ይቆጣጠራል፡-

ምሳሌዎች፡

:::

## 37.11. እንደገና ልምምድ

በሴንስክሪት ይተርጉሙ እና በዚህም የፐርፌክት ቅርጾችን ብቻ ይጠቀሙ፡-

አንድ ጥንቃቄ ሰው ወደ ሌላ ገጠር ሲሄድ፣ በመንገድ ላይ ታድቷል። ከዚያም ለመደሰት ወደ ጎን የሚቆም የማንጎ ዛፍ ታች ሄደ። በዚህ ዛፍ ላይ ተጣጣፉ ፍሬዎች ነበሩ። ጥንቃቄው ለእነዚህ ፍሬዎች ፍላጎት አገኘ። ነገር ግን ወደ ዛፉ ላይ ማድረስ እና ፍሬዎቹን ማግኘት አልቻለም። በድንገት በዚህ ዛፍ ላይ ፍሬዎችን የሚበሉ አንዳንድ ድመቶች ነበሩ። እነዚህን ሲያይ ጥንቃቄው ደስ ተብሎበታል። ምን አደረገ? አንዳንድ ድንጋዮችን ወስዶ ወደ ድመቶቹ ማዶ አድርጎ ገሰፈ። ድመቶቹም በጣም ተቃጠሉ። አንዳንድ ፍሬዎችን ወስዶ ወደ ጥንቃቄው ገሰፈ። ጥንቃቄው እነዚህን ፍሬዎች በደስታ ወስዶ ወደ የተፈለገበት ቦታ ሄደ። እይ፣ የጥንቃቄው ጉዳይ!
