## 39.1. የአንደኛ መደብ የግሥ መድረሻዎች (sig[तृतीयः] ⟪पुरुषः⟫ = "**ሶስተኛ** መደብ")

የአንደኛ መደብ መድረሻዎች (sig[⟪तृतीयः⟫] ⟪पुरुषः⟫ = "**ሶስተኛ** መደብ") እነዚህ ናቸው፦

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **የቲማቲክ ግንድ ዋና መድረሻ** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **የአቲማቲክ ግንድ ዋና መድረሻ** | ^^ | ^^ | **-e** | ^^ |
| **የቲማቲክ ግንድ ሁለተኛ መድረሻ** | **-m** | **-ma** | **-i** | **-mahi** |
| **የአቲማቲክ ግንድ ሁለተኛ መድረሻ** | **-am** | ^^ | ^^ | ^^ |
| **የኦፕታቲቭ መድረሻ** | ^^ | ^^ | **-a** | ^^ |
| **የፍጹም ጊዜ መድረሻ** | **-a** | ^^ | **-e** | **-mahe** |

:::
¹ ማስታወሻ፡ እንደ እውነቱ ከሆነ የቲማቲክ ግንድ Ā ዋና መድረሻ እንደ -e መቆጠር አለበት፤ ከዚህ በፊት የቲማቲክ አናባቢው -a- በአመሳስሎ ምክንያት ይጠፋል። ነገር ግን ውጤቱ ልክ መድረሻ -i ከቲማቲክ አናባቢ -a- ጋር እንደተገናኘ ነው፡ a + i » e።
