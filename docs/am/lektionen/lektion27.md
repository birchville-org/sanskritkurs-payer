# ትምህርት 27

## 27.1. የሎኬቲቭ (⟪सप्तमी⟫ f. = "ሰባተኛው የቃል መጨረሻ") ተጠቃሚነት

::: grammar-box

**ሎኬቲቭ (⟪सप्तमी⟫) በሚከተሉት ጥያቄዎች ላይ ይቆማል፦**
*   **የት?**
*   **ምንድን ነው?**
*   **በምን አይነት ሁኔታዎች?**
*   **ስለ ምን?**

:::
::: grammar-box

**1. ሎኬቲቭ (⟪सप्तमी⟫) በ"የት?" ጥያቄ ላይ ቦታን ያመለክታል፣ በዚህም (በፊት፣ በላይ፣ ጎን) አክቲቨር (⟪कर्ता⟫) ወይም የአንድ ስራ ነገር ይገኛል ወይም ስራው ራሱ የሚከናወንበት ቦታ።**

> ⟪नगरे वसति⟫ = "በከተማ ውስጥ ይኖራል"

:::
::: media
![](/images/lekt2701.webp)
ስዕል፦ ⟪जयपुरनगरे⟫
ጃይፑር፣ 1875.
(የስዕል ምንጭ፦ [ዝርዝር](/am/licenses#lekt2701))
:::

::: grammar-box

**2. ሎኬቲቭ በ"ምንድን ነው?" ጥያቄ ላይ ጊዜን ወይም ውጫዊ ሁኔታዎችን ያመለክታል፦**

> ⟪तस्मिन्काले⟫ = "በዚያ ጊዜ፣ በዚያ ጊዜ"

**እዚህ ላይ የሚገኘውም የሚባለው Locativus Absolutus ነው፦**

**የአንድ ሰው ወይም ነገር ስራ ወይም ሁኔታ ጊዜን የሚወስን ከሆነ - ወይም ሁኔታዎችን - ሌላ ሰው ወይም ነገር ስራን የሚያከናውን ወይም በተወሰነ ሁኔታ ውስጥ የሚገኝ ከሆነ፣ የመጀመሪያውን ሰው ወይም ነገር የሚገልጽ ቃል ከዚያው ቃል ጋር በተጨማሪ የሚገልጽ ቃል (የተለመደው ፓርቲሲፕ ነው) በሎኬቲቭ (⟪सप्तमी⟫) ውስጥ ይቀመጣል፦**

> ⟪एवं गच्छति काले⟫ = "ጊዜው እንዲህ እየሄደ..."
\>
> ⟪तस्मिन्गते⟫ = "እንደሄደ በኋላ..."

**አንዳንድ ጊዜ አክቲቨር (⟪कर्ता⟫) በተለየ አይገለጽም፦**

> ⟪एवं सति⟫ = "ስለዚህ እንደሆነ"

**Locativus absolutus በተለያየ ሁኔታ "በሚያልፍበት ጊዜ" (ለምሳሌ ፓርቲሲፕ Present)፣ "ከመጨረሻው በኋላ"፣ "እንደሆነ" (ለምሳሌ PPP)፣ "ምክንያቱም"፣ "ምንም እንኳን"፣ "እንደሆነ" ወዘተ. መተርጎም አለበት።**

**ማስታወሻ፡ በአብሶሉቲቨም ውስጥ የአብሶሉቲቭ ግብር እና የዋናው ዓረፍተ ነገር ግብር ተመሳሳይ መሆን አለባቸው፤ በሎኬቲቨስ አብሶሉቱስ ውስጥ ደግሞ የሎኬቲቨስ አብሶሉቱስ ግብር እና የዋናው ግብር ግብር የተለያዩ መሆን አለባቸው።**

## 27.2. የሎኬቲቭ (⟪सप्तमी⟫) መፍጠር

::: grammar-box

**የሎኬቲቭ መደበኛ መጨረሻዎች (⟪सप्तमी⟫) የሚከተሉት ናቸው፡**
*   **ነጠላ፡ -i**
*   **ብዙ፡ -su**

**ከ-su በፊት የሚከሰቱ የድምጽ ለውጦችን እና -su ወደ -ṣu ሊቀየር የሚችለውን ማስታወስ ያስፈልጋል!**

## 27.4. ሁሉንም የመታወቂያ ቅርጾች (አንዴ ቁጥር) ያካተተ ግጥም ከ ⟪राम⟫ ጋር

::: media
![](/images/lekt2708.webp)
ስዕል፡ ⟪रामे चित्तलयः सदा भवतु मे भो राम मामुद्धर ॥⟫
Rāma-Satz.
(የስዕሉ ምንጭ፡ [ዝርዝሮች](/am/licenses#lekt2708))
:::
sig[⟪रामो⟫] ⟪राजमणिः सदा विजयते⟫ :sig[⟪रामं⟫] ⟪रमेशं भजे⟫:br :sig[⟪रामेणा⟫]⟪भिहता निशाचरचमू⟫ :sig[⟪रामाय⟫] ⟪तस्मै नमः ।⟫:br :sig[⟪रामान्ना⟫]⟪स्ति परायणम् परतरं⟫ :sig[⟪रामस्य⟫] ⟪दासोऽस्म्यहम्⟫:br :sig[⟪रामे⟫] ⟪चित्तलयः सदा भवतु मे भो⟫ :sig[⟪राम⟫] ⟪मामुद्धर ॥⟫

**ትርጉም፡**
1. **ኖሚናቲቭ፡** ራማ፣ በሥላሴዎች (⟪राजन्⟫ ሰዎች) መካከል ያለው ብሩህ ክብር (⟪मणि⟩ ሰው) ሁልጊዜ ያሸንፋል (⟪सदा⟩)።
2. **አኩዛቲቭ፡** ራማን፣ የራማ ጌታ እና ገበሬ (⟪ईश⟩ ሰው) የሆነውን ራማ እወዳለሁ (⟪भज्⟩ 1U)።
3. **ኢንስትሩመንታሊስ፡** ራማ የሌሊት ጠባቂዎችን (⟪निशा⟩ ሴት = ሌሊት) ሠራዊት (⟪चमू⟩ ሴት) ገደለ።
4. **ዳቲቭ፡** ይህ ራማ ማክበር ይሁን!
5. **አብላቲቭ፡** ከራማ በጣም የተሻለ (⟪परतर⟩ 3) መጠለያ (⟪परायण⟩ ሰው) የለም።
6. **ጀነቲቭ፡** እኔ (⟪अहम्⟩) የራማ አገር (⟪अस्मि⟩) ነኝ።
7. **ሎካቲቭ፡** በራማ ውስጥ ሁልጊዜ የእኔ ልብ (⟪मे⟩) ሰላም (⟪लय⟩ ሰው) ይሁን (⟪भवतु⟩)።
8. **ቮካቲቭ፡** ራማ፣ እኔን (⟪माम्⟩) አድን (⟪उद्धर⟩ = ለ ⟪उद्⟩ + ⟪हृ⟩ ወይም ⟪उद्⟩ + ⟪धृ⟩)።
