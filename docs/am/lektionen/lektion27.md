# ምዕራፍ 27

## 27.1. የሎካቲቭ አጠቃቀም (⟪सप्तमी⟫ ሴ. = "ሰባተኛው የጉዳይ ቅጥያ")

::: grammar-box

**ሎከቲቭ (⟪सप्तमी⟫) ለሚከተሉት ጥያቄዎች መልስ ይሰጣል፡**
*   **የት?**
*   **መቼ?**
*   **በምን ሁኔታዎች ውስጥ?**
*   **ከምን አንጻር?**

:::
::: grammar-box

**1. ሎካቲቭ (⟪सप्तमी⟫) "የት?" ለሚለው ጥያቄ መልስ ሲሰጥ፣ ድርጊት ፈጻሚው (⟪कर्ता⟫) ወይም የድርጊቱ ተቀባይ የሚገኝበትን ቦታ (ውስጥ፣ ላይ፣ አጠገብ) ወይም ድርጊቱ ራሱ የሚፈጸምበትን ቦታ ያመለክታል።**

> ⟪नगरे⟫ ⟪वसति⟫ = "እሱ በከተማ ውስጥ ይኖራል"

:::
::: media
![](/images/lekt2701.webp)
ምስል፡ ⟪जयपुरनगरे⟫
ጃይፑር፣ 1875
(የምስል ምንጭ: [ዝርዝሮች](/licenses#lekt2701))
:::

::: grammar-box

**2. ሎካቲቭ "መቼ?" ለሚለው ጥያቄ መልስ ሲሰጥ ጊዜውን ወይም ውጫዊ ሁኔታዎችን ያመለክታል፡**

> ⟪तस्मिन्काले⟫ = "በዚያን ጊዜ፣ በዚህ ጊዜ"

**በተጨማሪም ሎካቲቩስ አብሶሉቱስ (Locativus Absolutus) የሚባለው እዚህ ውስጥ ይካተታል፡**

**የአንድ ሰው ወይም ነገር ድርጊት ወይም ሁኔታ፣ ሌላ ሰው ወይም ነገር አንድን ድርጊት የሚፈጽምበትን ወይም በተወሰነ ሁኔታ ውስጥ የሚገኝበትን ጊዜ ወይም ሁኔታዎች የሚወስን ከሆነ፣ ያ የመጀመሪያውን ሰው ወይም ነገር የሚያመለክተው ቃል እርሱን በቅርበት ከሚገልጸው ቃል ጋር (ብዙውን ጊዜ ፓርቲሲፕል ከሆነው) በመሆን በሎካቲቭ (⟪सप्तमी⟫) ውስጥ ይገባል፡**

> ⟪एवं⟫ ⟪गच्छति⟫ ⟪काले⟫ = "ጊዜው እንዲህ እያለፈ..."
>
> ⟪तस्मिन्गते⟫ = "እሱ ከሄደ በኋላ..."

**አንዳንድ ጊዜ አድራጊው (⟪कर्ता⟫) በተለየ ሁኔታ አይገለጽም፦**

> ⟪एवं⟫ ⟪सति⟫ = "ነገሩ እንዲህ ስለሆነ"

**ሎካቲቩስ አብሶሉቱስ እንደ አገባቡ በ"በ... ጊዜ" (ለምሳሌ የአሁን ጊዜ ተካፋይ)፣ "ከ... በኋላ"፣ "ሲ..." (ለምሳሌ PPP)፣ "ስለ..."፣ "ምክንያቱም"፣ "ምንም እንኳን"፣ "ከሆነ" ወዘተ. መተርጎም አለበት።**

**ማስታወሻ: በአብሶሉቲቩም ጊዜ የአብሶሉቲቩሙ ባለቤት እና የዋናው ግስ ባለቤት አንድ መሆን አለባቸው፤ በሎካቲቩስ አብሶሉቱስ ጊዜ ደግሞ የሎካቲቩስ አብሶሉቱሱ ባለቤት እና የዋናው ግስ ባለቤት የተለያዩ መሆን አለባቸው።**

## 27.2. የሎካቲቭ አፈጣጠር (⟪सप्तमी⟫)

**ከ -su በፊት ያሉትን የድምፅ ለውጦች እና የ -su ወደ -ṣu ሊሆን የሚችለውን ሴሬብራላይዜሽን ልብ ይበሉ!**

## 27.4. ለ:sig[⟪राम⟫] ሁሉንም የመራብዕ ቅርጾች (ነጠላ) የያዘ አንድ ስንኝ

::: media

:sig[⟪रामेणा⟫]⟪भिहता⟫ ⟪निशाचरचमू⟫ :sig[⟪रामाय⟫] ⟪तस्मै⟫ ⟪नमः⟫ ⟪।⟫
:sig[⟪रामान्ना⟫]⟪स्ति⟫ ⟪परायणम्⟫ ⟪परतरं⟫ :sig[⟪रामस्य⟫] ⟪दासोऽस्म्यहम्⟫

**ትርጉም፦**
1. **ስም አድራጊ፦** ራማ፣ በነገሥታት (⟪राजन्⟫ ተ.) መካከል ያለው ዕንቁ (⟪मणि⟫ ተ.)፣ ሁልጊዜም ያሸንፋል (⟪सदा⟫)።
2. **ተቀባይ ስም፦** እኔ ራማን፣ የራማ (= ላክሽሚ) ጌታና ባል (⟪ईश⟫ ተ.) የሆነውን እወደዋለሁ (⟪भज्⟫ 1U)።
3. **መሳሪያዊ፦** ራማ የሌሊት ተጓዦችን (= አጋንንትን) (⟪निशा⟫ አን. = ሌሊት) ሠራዊት (⟪चमू⟫ አን.) ገድሏል።
4. **ሰጪ ተቀባይ፦** ለዚህ ራማ አክብሮት ይሁን!
5. **ምንጭ አመልካች፦** ከራማ የተሻለ (⟪परतर⟫ 3) መጠጊያ (⟪परायण⟫ ገ.) የለም።
6. **ባለቤት አመልካች፦** እኔ (⟪अहम्⟫) የራማ አገልጋይ (⟪अस्मि⟫) ነኝ።
7. **ቦታ አመልካች፦** በራማ ውስጥ የልቤ (⟪मे⟫) ዕረፍት (⟪लय⟫ ተ.) ሁልጊዜ ይሁን (⟪भवतु⟫)።
