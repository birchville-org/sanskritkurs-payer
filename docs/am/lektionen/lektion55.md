# ትምህርት 55

## 55.1. የ a-አዎርስት (አዎርስት በቲማቫኮል)

::: grammar-box
**የ a-አዎርስት እንደ ኢምፔርፌክት (⟪लङ्⟫) የ 6ኛው ፕሬዘንስ ክፍል (⟪तुदादि⟫) ይፈጠራል፣ ማለት፡-**

**ኦግመንት + ዝቅተኛ ደረጃ ዱምር + a + ሰኩንደሪ መጨረሻ**

**-a- በተመሳሳይ ጉዳዮች እንደ ኢምፔርፌክት በ -ā- ይተካል።**

**ምንም ናስል ኢንፊክስ የለም።**

**አትማኔፐዳ አጭር ነው፤ ለ ዩብያፓዳ ዱሞች በተለምዶ በሌሎች አዎርስት ክፍሎች ይፈጠራል (እባክዎ ኪልሆርን፣ ግራማቲክ §340 እና ከዚህ በታች በተዛማጅ አዎርስት ክፍሎች ይመልከቱ)።**

**የዱሞች ዝርዝር ይህን አዎርስት ያላቸው፣ በ ኪልሆርን፣ ግራማቲክ §340።**
:::
