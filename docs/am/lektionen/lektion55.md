# ትምህርት 55

## 55.1. a-አኦሪስት (ጭብጥ አናባቢ ያለው አኦሪስት)

::: grammar-box
**a-አኦሪስት የሚመሰረተው እንደ 6ኛው የአሁን ጊዜ መደብ (⟪तुदादि⟫) ኢምፐርፌክት (⟪लङ्⟫) ነው፤ ማለትም፦**

**አውግመንት + ዜሮ ደረጃ ሥር + a + ሁለተኛ ደረጃ ቅጥያ**

**-a- በኢምፐርፌክት ውስጥ ባሉት ተመሳሳይ ሁኔታዎች በ -ā- ይተካል።**

**የአፍንጫ ውስጥ ቅጥያዎች የሉም።**

**Ātmanepada ብዙም አይገኝም፤ ለ Ubhayapada ሥሮች ብዙውን ጊዜ በሌሎች የአኦሪስት ክፍሎች መሠረት ይፈጠራል (Kielhorn, Grammatik §340 እንዲሁም ከታች በተዛማጅ የአኦሪስት ክፍሎች ይመልከቱ)።**

**ይህን አኦሪስት ያላቸው ሥሮች ዝርዝር፣ በኪልሆርን፣ ሰዋሰው §340።**
:::
