## 36.2. ገላጭ ፍጹም ግሥ (ፐሪፍራስቲክ ፐርፌክት) (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
ገላጭ ፍጹም ግሥ (ፐሪፍራስቲክ ፐርፌክት) (⟪अनुप्रयोगलिट्⟫) ጥቅም ላይ ይውላል፦

1. በተገኙት የግሥ እርባታዎች (ምክንያታዊ፣ ምኞታዊ፣ ተደጋጋሚ፣ ስማዊ)
2. ከ ā- በስተቀር በረጅም አናባቢ በሚጀምሩ ሥሮች፣ ወይም ከ a- በስተቀር ከሁለት ተነባቢዎች በፊት ባለ አናባቢ
3. በአንዳንድ ሌሎች ሥሮች
:::
::: grammar-box
**አሠራር፦**

(ደካማ) የአሁን ጊዜ ግንድ + -ām + የ⟪कृ⟫፣ ⟪अस्⟫ ወይም ⟪भू⟫ ተዛማጅ የፍጹም ጊዜ ቅርጽ

- Auslautender Stammvokal wird vor -ām guṇiert.
- ⟪अस्⟫ እና ⟪भू⟫ በĀtmanepada ግሶችም ቢሆን በParasmaipada ይረግባሉ።
:::
Das periphrastische Perfekt ist wohl aus dem Akkusativ eine Verbalnomens auf -ā entstanden. Dieser Akkusativ wird -- wie auch sonst oft -- adverbial verwendet.
