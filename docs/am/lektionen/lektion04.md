# ትምህርት 4

## 4.1. ቀላል ማጠናከሪያ ጥያቄዎች (የቃል ጥያቄዎች) እና መልሶች

### 4.1.1. የጥያቄ ተካዮች እና የማሳየት ተካዮች

#### 4.1.1.1. የጥያቄ ተካዮች (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | ነጥባዊ ተካ (Nominativ) አንስር | ነጥባዊ ተካ (Nominativ) ብዙር |
| :--- | :--- | :--- |
| **ንጹህ** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **ወንድ** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |

#### 4.1.1.2. የማሳየት ተካዮች (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

**ለነጥባዊ ተካ (Nominativ) አንስር ወንድ:**
**sa, eṣa** (⟪स एष⟫) ከሁሉም ድምፆች በስተቀር ረጅም **-a** ይመጣል
**so, eṣo** (⟪सो एषो⟫) ከ **-a** ጋር ይመጣል፣ ይህም በ Avagraha elidiert (ይወጣል)
**saḥ, eṣaḥ** (⟪सः एषः⟫) በ Pausa (የአረፈ ቦታ፣ የመዝሙር መጨረሻ) ብቻ ይመጣል

ንነዞም ፕሮኖምናት (sarvanāman n.) ብምጥቃም ሓሳባት ንምስራሕ፡ እዞም ዝስዕቡ ሕግታት ሳንድሂ ክንፈልጦም የድሊ፦

### 4.1.2. ሳንድሂ ናይ ወጻኢ -m

::: grammar-box
**ወጻኢ -m ኣብ ቅድሚ ኮንሶናንት ብኣኑስቫራ (-ṃ) ይትካእ። ኣብ መወዳእታ ሓሳብ ወይ ግዝያዊ ምስ ዝኸውንን ኣብ ቅድሚ ቀጥታዊ ድምጽታትን -m ከም ዘሎ ይተርፍ።**
:::
### 4.1.3. ሳንድሂ ናይ ወጻኢ -e

::: grammar-box
1. **ኣብ ቅድሚ a- -e ከም ዘሎ ይተርፍ፦ እቲ ኣብ መጀመርታ ዘሎ a- ምስ ኣቫግራህ ይጠፍእ፦**
ንኣብነት፦ ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "እዞም ኣገደስቲ"

2. **ኣብ ቅድሚ ካልኦት ቀጥታዊ ድምጽታት ካብ ሓጺር a- -e ብተለምዶ ብ-a ምስ ሃያተስ ይትካእ። ከምኡ’ውን ብ-aṣ ይትካእ ይከኣል፦**
ንኣብነት፦ ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (ብዙሕ ዘይኮነ፦ imay īśvarāh = ⟪इमयीश्वराः⟫) "እዞም ኣቦታት"
:::
### 4.1.4. ሳንድሂ ናይ ወጻኢ -d

::: grammar-box
**ወጻኢ -d ኣብ ፓውሳ ከምኡ’ውን ኣብ ቅድሚ ዘይድምጺ ጉትቱራላት (k, kh) ከምኡ’ውን ላብያላት (p, ph) ብ-t ይትካእ።**

ኣብ ቅድሚ ካልኦት ኮንሶናንት ዘሎ ምትካእ ድሕሪኡ ይዝርዝር። ቅድሚ እዚ ዓይነት ምትእስሳር ድምጺ ክትከላኸሉ።
:::

ብመጠቀም እዞም ፕሮኖምናት ንኣብነት እዞም ዝስዕቡ ሕቶ ፎርሙላታት ንስራሕ፦

ሌላ የጥያቄዎች ምሳሌ፡-

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ መልስ፡ viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫። (በዚህ ሁኔታ በስም ላይ በተመሰረተው ሀረግ ውስጥ ግራጫውን ለምሳሌ ወደ ፊት በማድረግ ከጥያቄው ጋር ያለውን ግንኙነት ማጉላት ይቻላል።)

ማስታወሻ፡ በእርስዎ የአሁኑ የሳንስክሪት ጥበብ መሰረት እንደዚህ ዓይነቱ ጥያቄዎች ላይ የሚሰጡት መልሶች በተፈጥሮ በሁሉም አንጻር ለሳንስክሪት ቋንቋ ተፈጥሯዊነት ሙሉ በሙሉ አይዛመዱም።


## 4.2. ልምምድ

**ሀ) ከሚከተሉት ቃላት ጋር በ viṣṇuḥ kaḥ (⟪विष्णुः कः⟫) ስርዓት መሰረት በድምጽ ይጠይቁ እና መልሱን በሳንስክሪት ይስጡ፡-**

śruti, śiva, brāhmaṇa, dvija (ብዙ ቁጥር), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**ለ) ከሚከተለው የማንበብ ልምምድ ጋር በ etat kim (⟪एतत्किम्⟫) ስርዓት መሰረት ጥያቄ ይፍጠሩ እና መልሱን በተሰጡት ቃላት እና በማመልከቻ ስሞች ለምሳሌ eṣa bālaḥ (⟪एष बालः⟫) ይስጡ፡-**
