# ትምህርት 4

::: deleteme-box
**በዚህ ትምህርት ውስጥ የሚከተሉትን ይማራሉ፦**
- የጥያቄ ተውላጠ ስሞች እና አመልካች ተውላጠ ስሞች በስም መደብ
- በመጨረሻ -m የሚመጣበት የሳንዲ ህግ
- በመጨረሻ -e የሚመጣበት የሳንዲ ህግ
- በመጨረሻ -d የሚመጣበት የሳንዲ ህግ
- ቀላል የጥያቄ አረፍተ ነገሮች
:::
## 4.1. ቀላል የማብራሪያ ጥያቄዎች (የቃላት ጥያቄዎች) እና መልሶች

### 4.1.1. የጥያቄ ተውላጠ ስሞች እና አመልካች ተውላጠ ስሞች

#### 4.1.1.1. የጥያቄ ተውላጠ ስም (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | ነጠላ ስም | ብዙ ስም |
| :--- | :--- | :--- |
| **ገለልተኛ ጾታ** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **ተባዕታይ ጾታ** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **ሴቴ ጾታ** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. አመልካች ተውላጠ ስሞች (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **ግንዶች** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"er, sie, es; der, die, das":br(Erwähnte)** | **etad = ⟪एतद्⟫:br"dieser, diese, dieses":br(dem Sprechenden sehr Nahe)** | **idam = ⟪इदम्⟫:br"dieser, diese, dieses":br(Nahe)** |
| **ነጠላ ስም** ||||
| **ገለልተኛ ጾታ** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **ተባዕታይ ጾታ** | **sa, so saḥ = ⟪स⟫ ⟪सो⟫ ⟪सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष⟫ ⟪एषो⟫ ⟪एषः⟫** | **ayam = ⟪अयम्⟫** |
| **ሴቴ ጾታ** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **ብዙ ስም** ||||
| **ገለልተኛ ጾታ** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **ተባዕታይ ጾታ** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **ሴቴ ጾታ** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**ለነጠላ ተባዕታይ ስም፡**
- **sa, eṣa** (⟪स⟫ ⟪एष⟫) ከአጭር **-a** በስተቀር ከሁሉም ድምፆች በፊት ይቆማል
- **so, eṣo** (⟪सो⟫ ⟪एषो⟫) ከ**-a** በፊት ይቆማል፣ ይህም በአቫግራሃ ይወገዳል (ይጠፋል)
- **saḥ, eṣaḥ** (⟪सः⟫ ⟪एषः⟫) በፓውዛ (በአረፍተ ነገር መጨረሻ፣ በግጥም መጨረሻ) ብቻ ይቆማል

በእነዚህ ተውላጠ ስሞች (sarvanāman n.) ዓረፍተ ነገሮችን ለመመስረት፣ የሚከተሉትን የሳንዲሂ ህጎች ማወቅ ያስፈልጋል፡

### 4.1.2. የመጨረሻ -m ሳንዲ

::: grammar-box
**የመጨረሻ -m ከተነባቢዎች በፊት በአኑስቫራ (-ṃ) ይተካል። በአረፍተ ነገር ወይም በስንኝ መጨረሻ እና ከአናባቢዎች በፊት -m እንደነበረ ይቆያል።**
:::
### 4.1.3. የመጨረሻ -e ሳንዲ

::: grammar-box
1. **ከ a- በፊት -e ሳይለወጥ ይቆያል፡ የመጀመርያው a- በአቫግራሃ ይወገዳል፡**
ለምሳሌ ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ "እነዚህ እሳቶች"

2. **ከአጭር a- ውጪ ካሉ ሌሎች አናባቢዎች በፊት -e ብዙውን ጊዜ በ -a ከሂያተስ ጋር ይተካል። በ -ay መተካትም ይከሰታል፡**
ለምሳሌ ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (አልፎ አልፎ፡ imay īśvarāh = ⟪इमयीश्वराः⟫) "እነዚህ ጌቶች"
:::
### 4.1.4. የመጨረሻ -d ሳንዲ

::: grammar-box
**በመጨረሻ ላይ ያለ -d በፓውዛ (በአረፍተ ነገር መጨረሻ) እንዲሁም ከድምፅ አልባ ጉሮሯዊ ተነባቢዎች (k, kh) እና ከንፈራዊ ተነባቢዎች (p, ph) በፊት በ -t ይተካል።**

ከሌሎች ተነባቢዎች በፊት ያለው መተካት በኋላ ላይ ይብራራል። ለጊዜው እንደዚህ ያሉ የድምፅ ግጭቶችን ያስወግዱ!
:::
### 4.1.5. የጥያቄ ቀመሮች

በእነዚህ ተውላጠ ስሞች ለምሳሌ የሚከተሉት የጥያቄ ቀመሮች ይመሰረታሉ፦

የሌሎች ጥያቄዎች ምሳሌ፦

> viṣṇuḥ kaḥ? = ⟪विष्णुः⟫ ⟪कः⟫ መልስ፡ viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (እዚህ ላይ በስም ዓረፍተ ነገር ውስጥ ከጥያቄው ጋር ያለውን ግንኙነት ለማጉላት ባለቤቱን ለምሳሌ መጀመሪያ ላይ ማስቀመጥ ይቻላል።)

ማስታወሻ፡ እስካሁን ባለው የሳንስክሪት እውቀትዎ ለእንደዚህ አይነት ጥያቄዎች ሊሰጧቸው የሚችሏቸው መልሶች፣ በእርግጥ በሁሉም ረገድ ጥሩ የሳንስክሪት አነጋገርን ገና አያሟሉም።

## 4.2. ልምምድ

**ሀ) በሚከተሉት ቃላት የ viṣṇuḥ kaḥ (⟪विष्णुः⟫ ⟪कः⟫) አብነትን በመከተል በቃል ጥያቄዎችን ይፍጠሩ እና ጥያቄዎቹን በሳንስክሪት ይመልሱ፡**

śruti, śiva, brāhmaṇa, dvija (ብዙ), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**ለ) ለሚከተለው የንባብ ልምምድ etat kim (⟪एतत्किम्⟫) በሚለው አብነት ጥያቄዎችን ይስሩ እና ጥያቄዎቹን በተሰጡት ቃላትና አመልካች ተውላጠ ስሞች ለምሳሌ eṣa bālaḥ (⟪एष⟫ ⟪बालः⟫) ብለው ይመልሱ፡**
