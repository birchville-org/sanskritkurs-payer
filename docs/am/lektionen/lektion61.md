# ትምህርት 61

## 61.1. በ -ā፣ -ī፣ -ū የሚያልቁ የስር ስሞች እርባታ

### 61.1.1. በ⟪तत्पुरुष⟫ መጨረሻ ላይ በ -ā የሚያልቁ የስር ስሞች

::: grammar-box
**በደካማ ውድቀቶች ውስጥ፣ ከአናባቢ ቅጥያዎች በፊት የግንዱ አናባቢ ይጠፋል (የዜሮ ደረጃ Ø)።**

**በተባዕታይና በአንስታይ ጾታ ያለው እርባታ ተመሳሳይ ነው።**
:::

### 61.1.2. በ -ī የሚያልቁ አንስታይ ሥር ስሞች

::: grammar-box
**Vor vokalischer Endung wird -ī durch -iy ersetzt.**

**ከተለመዱት የኢርእስት መድረሻዎች ጋር ከሚፈጠሩት ቅርጾች በተጨማሪ፣ በዳቲቭ፣ አብላቲቭ፣ ጀነቲቭ፣ ሎከቲቭ ነጠላ እና በጀነቲቭ ብዙ ቁጥር ላይ፣ በ -ī (⟪देवी⟫) የሚያልቁ ባለብዙ-ክፍለ-ቃል አንስታይ ስሞች አወራረድ መሰረት የተፈጠሩ ቅርጾችም ይገኛሉ።**

### 61.1.3. በ⟪तत्पुरुष⟫ መጨረሻ ላይ በ-ī የሚያልቁ የስር ስሞች

::: grammar-box
**ከአናባቢ ቅጥያዎች በፊት፣ -ī በ-y ይተካል፣ ከሱ በፊት አንድ ብቻ የስሩ የሆነ ተነባቢ ካለ። ከሱ በፊት ብዙ የስሩ የሆኑ ተነባቢዎች ካሉ፣ ከአናባቢ ቅጥያ በፊት ያለው -ī በ-iy ይተካል።**

**አገባቡ በተባዕታይና በአንስታይ ጾታ ተመሳሳይ ነው።**

**ልዩ ሁኔታ፦ በ-:sig[⟪नी⟫] "የሚመራ" የሚጨርሱ ቅጽል ስሞች በነጠላ አካባቢያዊ (Lok.sg) ላይ -ām የሚል ቅጥያ አላቸው (እንደ ⟪देवी⟫)፦**
ለምሳሌ፦ ⟪ग्रामणी⟫ "ሰራዊት/መንደር የሚመራ"፦ ነጠላ አካባቢያዊ ተባዕታይ/አንስታይ (Lok.sg.m.f.) ⟪ग्रामण्याम्⟫
