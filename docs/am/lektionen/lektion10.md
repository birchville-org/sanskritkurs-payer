# ትምህርት 10

## 10.1. የገደል ሐረግ

::: grammar-box
**ስኬማ፦**
**(አክታን - kartṛ - በኢስትሩመንታሊስ (tṛtīyā)) - (ቀጥተኛ ኦብጀክት - karman - በናሚነቲቭ) - ፓስቪ ቅርጽ**

ምሳሌ **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "አንድ ብራህማኒ አምላክ በቅርበት ያገለግላል" (መደበኛ፦ "አንድ አምላክ በብራህማኒ በቅርበት ይገደዋል።")

ዚህ ሐረግ **በጣም (!) ትርጓሜው እኩል** ነው ምስ ሐረግ፦
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
- በገደል ሐረግ ውስጥ አክታን (**kartṛ**) በ **ኢስትሩመንታሊስ** (tṛtīyā f. "ሶስተኛ ካሱስ") ይገኛል፣ ቀጥተኛ ኦብጀክት (**karman** n.) በ **ናሚነቲቭ** (prathamā f.) ይገኛል።
- Passivsätze, in denen der Agens nicht bezeichnet wird, haben meist unpersönliche Bedeutung ("man"): <!-- TODO: Fallback translation -->
**አክቲቭ ሐረግ አካል (dvitīyā) ይዞ ቢመጣም በገደል ሐረግ ውስጥ በናሚነቲቭ (prathamā) ሊደርስ ይችላል፦**
:::

::: grammar-box
ምስ አክቲቭ ሐረግ **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "ራማ ወደ ግሬም ይሄዳል" የሚመለከቱ ገደል ሐረጎች፦
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
ሌላ አማራጭ፦ **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫

**אינטראנזיטיב (פעלים ללא אובייקט ישיר) נוטים לכפול במשפט פסיבי, בפרט בבקשות מנומסות:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "שיבואו פנימה"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "שישבו"
- מבנים פסיביים בסנסקריט נפוצים מאוד: הפסיב קל לכתיבה יותר מאשר למשל ערכות נוכחיות רבות.
- **באופן כללי, משפטים פסיביים בסנסקריט לא ישוחזרו בגרמנית כמשפט פסיבי, שכן לפסיב הגרמני יש תפקיד סגנוני אחר לחלוטין.**
:::

::: grammar-box
**Intransitive Verben (Verben ohne direktes Objekt) haben häufig Passivkonstruktionen, bes. auch in höflichen Aufforderungen:** <!-- TODO: Fallback translation -->
- **praviśyatām** = ⟪प्रविश्यताम्⟫ = "Man möge eintreten = Bitte treten Sie ein = Herein!" <!-- TODO: Fallback translation -->
- **niṣadyatām** = ⟪निषद्यताम्⟫ = "Man möge sich setzen = Bitte setzen Sie sich = Bitte nehmen Sie Platz" <!-- TODO: Fallback translation -->
:::
Sanskrit-Passivkonstruktionen sind ausgesprochen häufig: das Passiv ist ja auch leichter bildbar als z.B. zahlreiche Präsensstämme. <!-- TODO: Fallback translation -->

::: important
**Sanskrit-Passivsätze dürfen im Allgemeinen im Deutschen nicht durch einen Passivsatz wiedergegeben werden, da das deutsche Passiv eine ganz andere stilistische Funktion hat.** <!-- TODO: Fallback translation -->
:::

### 10.2.1. በመሳሪያ ስም (tṛtīyā = ⟪तृतीया⟫) ጥቅም

::: grammar-box
**Der Instrumentalis (tṛtīyā) steht hauptsächlich auf die Fragen:** <!-- TODO: Fallback translation -->
- **Wodurch?** <!-- TODO: Fallback translation -->
- **Womit?** <!-- TODO: Fallback translation -->
- **Mit wem?** <!-- TODO: Fallback translation -->

**ይህም ይቀመጣል**
1. **በንዑስ ሀረጎች ውስጥ፡ ተጠቃሚ (kartṛ) በመሳሪያ ሁኔታ**
2. **አንድ ነገር የሚከናወንበትን መስመር ወይም መሳሪያ ለማመልከት**
3. **አንድ ሰው ወደየት እንደሚገኝ የመስመር መግለጫ ለማቅረብ**
4. **ለግንኙነት፣ ማዋሃድ፣ ከ... ጋር መንኮራኩር ለመግለጽ**
5. **በከዋክብት ስም ውስጥ "አንድ ላይ ከ... ጋር" ተብሎ በመጠቀም; ምሳሌ፡ saha = ⟪सह⟫ = "ከ... ጋር"** :brምሳሌ፡ **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "ከብራህማን ጋር አንድ ሆነው"
:::
ተጨማሪ የመሳሪያ ሁኔታ (tṛtīyā) ተጠቃሚዎች በኋላ ይመጣሉ።

## 10.4. የገደል ቃላት (Passive Voice)፣ ጠቅላላ ቀን (Indicative Present) (yak = ⟪यक्⟫)
