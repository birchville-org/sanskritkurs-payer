# ትምህርት 10

## 10.1. የፓሲቭ ሐረግ

::: grammar-box
**ስኬማ፡**
**(አጀንስ - ካርትሪ - በኢንስትሩመንታሊስ (ትሪቲያ) - (ቀጥተኛ ኦብጀክት - ካርማን - በኖሚናቲቭ) - ፓሲቭ የግስ ቅርጽ**

ለምሳሌ **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "አንድ ብራህማኒ በቅዳሜ አንድ አምላክ ያክብራል" (ቃል በቃል፡ "አንድ አምላክ በአንድ ብራህማኒ በቅዳሜ ይከብራል።")

ይህ ሐረግ **ሙሉ በሙሉ (!) ትርጉም እኩል** ነው ከሚከተለው ሐረግ ጋር፡
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
በፓሲቭ ሐረግ ውስጥ አጀንስ (**ካርትሪ**) በ**ኢንስትሩመንታሊስ** (ትሪቲያ ል. "ሶስተኛው የካሱስ መጨረሻ")፣ ቀጥተኛው ኦብጀክት (**ካርማን** ገ.) በ**ኖሚናቲቭ** (ፕራታማ ል.) ይገኛል።
ፓሲቭ ሐረጎች፣ አጀንስ ሳይጠቀስ፣ ብዙውን ጊዜ ሰው ሳይጠቀስ ትርጉም አላቸው ("ማንም")፡
ለምሳሌ **ijyate** = ⟪इज्यते⟫ "ማንም ያቅርባል" (ቃል በቃል፡ "በቅዳሜ ይከብራል።")።
:::

::: grammar-box
**በተመጣጣኝ ንቁ ሐረግ የታቀብ (ድቪቲያ) የቦታ ኦብጀክት ቢኖርም፣ ይህ በፓሲቭ ሐረግ ውስጥ ወደ ኖሚናቲቭ (ፕራታማ) ሊቀየር ይችላል፡**

ከንቁ ሐረግ **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "ራማ ወደ ገጠር ይሄዳል።" ጋር የሚዛመዱ ፓሲቭ ሐረጎች፡
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
አማራጭ፡ **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**ትራንዚቲቭ ያልሆኑ ግሦች (ቀጥተኛ ኦብጀክት የሌላቸው ግሦች) ብዙውን ጊዜ የፓሲቭ ግንኙነቶች አሏቸው፣ በተለይም በጥሩ ማሳወቂያዎች፡**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "ማንም እንዲግባ = እባክዎ ይግቡ = ውስጥ!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "ማንም እንዲቀመጥ = እባክዎ ቀመጡ = እባክዎ ቦታ ይውሰዱ"
:::
የሳንስክሪት ፓሲቭ ግንባታዎች በጣም ብዙ ጊዜ ይገኛሉ፡- ፓሲቭ ለምሳሌ ከብዙ ፕሬዘንት ስታምፖች ጋር ሲነፃፀር ለመፍጠር ቀላል ነው።

::: important
**በአጠቃላይ የሳንስክሪት ፓሲቭ ሀሳቦች በጀርመንኛ በፓሲቭ ሀሳብ መተርጎም አይገባቸውም፣ ምክንያቱም የጀርመንኛ ፓሲቭ ሙሉ በሙሉ የተለየ ስታይሊስቲክ ተግባር ስላለው።**
:::

### 10.2.1. ስለ መሣሪያው (tṛtīyā = ⟪तृतीया⟫) ተጠቃሚነት

::: grammar-box
**መሣሪያው (tṛtīyā) በዋናነት በሚከተሉት ጥያቄዎች ላይ ይቀመጣል፡**
**በምን?**
**ምስ ምን?**
**ምስ ማን?**

**ይህም ይቀመጣል**
1. **በንቁ ማንነት (Passiv) ማገሮች ውስጥ፡ ሰራተኛ (kartṛ) በመሣሪያ**
2. **ምንም ነገር ለማከናወን የሚያገለግለውን መንገድ ወይም መሣሪያ ለመግለጽ**
3. **አንድ ሰው ወደየትም እንዴት እንደሚደርስ ለመግለጽ**
4. **ለማገናኘት፣ ለማጣመር፣ ለመጋራት ለመግለጽ**
5. **በከፊል ቃላት ትርጉም "አንድ ላይ፣ ጋር" ላይ፤ ለምሳሌ፡ saha = ⟪सह⟫ = "ጋር"** :brለምሳሌ፡br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "አብሮ ከብራህማኑ ጋር"
:::
የሶስተኛውን ሁኔታ (tṛtīyā) ሌሎች ተጠቃሚዎች በኋላ ይመጣሉ።


## 10.3. ለ-n- የተባለው የሴረብራሊዜሽን ሕግ (የቃል ወንድሳንዲ)

::: grammar-box
