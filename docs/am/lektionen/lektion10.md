# ትምህርት 10

::: deleteme-box
**በዚህ ትምህርት ውስጥ የሚከተሉትን ይማራሉ፦**
- ተገብሮ ዓረፍተ ነገር (የአድራጊው መሣሪያዊ)
- የመሣሪያዊ (tṛtīyā) ስም እርባታ
- ለ -n- የሴሬብራላይዜሽን ሕግ (የቃል ውህደት)
- በአሁን ጊዜ አመልካች ውስጥ የተገብሮ (yak) አፈጣጠር
- ስለ መስዋዕት፣ እውነት እና ማህበራዊ ሚናዎች የሚመለከቱ ቃላት
:::
## 10.1. ተገብሮ ዓረፍተ ነገር

::: grammar-box
**መርሐግብር፦**
**(አድራጊ - kartṛ - በመሣሪያዊ (tṛtīyā)) - (ቀጥተኛ ተሳቢ - karman - በስም መደብ) - ተገብሮ ግሥ**

ለምሳሌ **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन⟫ ⟪देव⟫ ⟪इज्यते⟫ = "አንድ ብራህማና አንድን አምላክ በመስዋዕት ያመልካል" (ቃል በቃል፡ "አንድ አምላክ በብራህማና በመስዋዕት ይመለካል")

ይህ ዓረፍተ ነገር **ሙሉ በሙሉ (!) ተመሳሳይ ትርጉም** ካለው ዓረፍተ ነገር ጋር ነው፡
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो⟫ ⟪देवं⟫ ⟪यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
- በተገብሮ ዓረፍተ ነገር ውስጥ ፈጻሚው (**kartṛ**) በ**መሳሪያዊ** (tṛtīyā f. "ሶስተኛው የርቢ መድረሻ")፣ ቀጥተኛው ተሳቢ (**karman** n.) በ**ስም መደብ** (prathamā f.) ላይ ይቆማል።
- ፈጻሚው ያልተገለጸባቸው ተገብሮ ዓረፍተ ነገሮች ብዙውን ጊዜ ግላዊ ያልሆነ ትርጉም ("ሰው") አላቸው፡
ለምሳሌ **ijyate** = ⟪इज्यते⟫ "ሰው ይሰዋል" (ቃል በቃል፡ "በመስዋዕት ይመለካል")።
:::

::: grammar-box
**ተዛማጁ ገብሪ ዓረፍተ ነገር የመድረሻን ተሳቢ (dvitīyā) ቢይዝም እንኳ፣ ይህ በተገብሮ ዓረፍተ ነገር ውስጥ ወደ ስም መደብ (prathamā) ሊቀየር ይችላል፡**

ለተግባሪ ዓረፍተ ነገር **rāmo grāmaṃ gacchati** = ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "ራማ ወደ መንደሩ ይሄዳል" የሚከተሉት ተገብሮ ዓረፍተ ነገሮች ይዛመዳሉ፡
- **rāmeṇa grāmaṃ gamyate** = ⟪रामेण⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫
- በአማራጭ: **rāmeṇa grāmo gamyate** = ⟪रामेण⟫ ⟪ग्रामो⟫ ⟪गम्यते⟫
:::

::: grammar-box
**አላፊ ግሶች (ቀጥተኛ ተሳቢ የሌላቸው ግሶች) በተለይ በትህትና በተሞላባቸው ጥያቄዎች ውስጥ አብዛኛውን ጊዜ ተገብሯዊ አወቃቀሮች አሏቸው፡**
- **praviśyatām** = ⟪प्रविश्यताम्⟫ = "ሰው ይግባ = እባክዎ ይግቡ = ግቡ!"
- **niṣadyatām** = ⟪निषद्यताम्⟫ = "ሰው ይቀመጥ = እባክዎ ይቀመጡ = እባክዎ ቦታ ይያዙ"
:::
የሳንስክሪት ተገብሯዊ አወቃቀሮች በጣም የተለመዱ ናቸው፡ ተገብሮው ለምሳሌ ከበርካታ የአሁን ጊዜ ግንድ ቅርጾች ይልቅ ለመመስረት ቀላል ነውና።

::: important
**የሳንስክሪት ተገብሯዊ ዓረፍተ ነገሮች በአጠቃላይ በጀርመንኛ በተገብሮ ዓረፍተ ነገር መተረጎም የለባቸውም፣ ምክንያቱም የጀርመን ተገብሮ ሙሉ ለሙሉ የተለየ የአጻጻፍ ስልት ተግባር አለው።**
:::

### 10.2.1. ስለ መሳሪያዊው አጠቃቀም (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**መሳሪያዊው (tṛtīyā) በዋናነት ለሚከተሉት ጥያቄዎች መልስ ይሰጣል፡**
- **በምን?**
- **በምን ነገር?**
- **ከማን ጋር?**

**ይህ ጥቅም ላይ ይውላል**
1. **በተገብሮ ዓረፍተ ነገሮች ውስጥ፡ ድርጊት ፈጻሚው (kartṛ) በመሳሪያዊው ይገለጻል**
2. **አንድ ነገር የተከናወነበትን መንገድ ወይም መሳሪያ ለመግለጽ**
3. **አንድ ሰው ወደ አንድ ቦታ የደረሰበትን መንገድ ለመግለጽ**
4. **ግንኙነትን፣ አንድነትን፣ አብሮነትን ለመግለጽ**
5. **"አብሮ" ወይም "ጋር" የሚል ትርጉም ባላቸው ድህረ-አያያዦች፤ ለምሳሌ፡ saha = ⟪सह⟫ = "ጋር"** :brz.B.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन⟫ ⟪सह⟫ = "ከብራህመኑ ጋር በጋራ"
:::
የመሳሪያዊው (tṛtīyā) ተጨማሪ አጠቃቀሞች በኋላ ላይ ይቀርባሉ።

## 10.3. ለ -n- የሚሰራው ሴሬብራላይዜሽን ህግ (የቃል ሳንዲ)

::: grammar-box

:::

**በአራተኛው የአሁን ጊዜ ክፍል ግሶች ላይ፣ Ātmanepada እና ተገብሮ ግሥ ተመሳሳይ ቅርጾች እንዳሏቸው ልብ ይበሉ! በዚህ ሁኔታ Ātmanepada ወይም ተገብሮ ግሥ መሆኑን ማወቅ የሚቻለው ከአረፍተ ነገሩ አወቃቀር ብቻ ነው።**

### 10.4.1. ተገብሮ ግሥን ለመመስረት ልዩ ሕጎች

1. **በ -i ወይም -u የሚያልቁ ሥሮች** ከተገብሮ ግሥ ቅጥያ **-ya-** በፊት አናባቢያቸውን ያረዝማሉ።
