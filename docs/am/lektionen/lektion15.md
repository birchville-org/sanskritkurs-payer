# ትምህርት 15

## 15.1. ⟪सुभाषितम् गुरुशुश्रूषया विद्या पुष्कलेन धनेन वा । अथवा विद्यया विद्या चतुर्थी नैव विद्यते ॥⟫

## 15.2. Determinativkomposita = Tatpuruṣa m. = ⟪तत्पुरुष⟫

በስም (ስም እና ቅጽል) የተገለጡ ነገሮች መካከል ያለው ግንኙነት በጄኔቲቭ ግንኙነት ብቻ ሳይሆን በታትፑሩሻ (⟪तत्पुरुष⟫) በኩልም መግለጽ ይቻላል። በተመሳሳይ ሁኔታ የቅጽሎችን ተጣምሮ መስጫ (attributive) ወይም የስሞችን ተከታታይ መስጫ (appositional) ግንኙነት በተወሰነ ዓይነት ታትፑሩሻ፣ ማለትም በተባለው ካርማዳራያ (m.) = ⟪कर्मधारय⟫ በኩል መግለጽ ይቻላል።

⟪तत्पुरुषः⟫ =  ⟪तस्य पुरुषः⟫ "የእሱ ገበሬ"፣ ማለትም የዚህ ዓይነት ኮምፖዚታ ስም ለመግለጽ የእንደዚህ ዓይነት ኮምፖዚታ ምሳሌ ያገለግላል።
::: grammar-box

በዲተርሚናቲቭ ኮምፖዚታ (ታትፑሪሻ) ውስጥ አንድ ስም (ስም ወይም ቅጽል) በሌላ ስም ወይም በአድቨርብ ይበለጽጋል። የበለጸገው ቃል በተለምዶ የኮምፖዚተሙን ኋላ ክፍል ይፈጥራል።

የፊት ክፍል (determinierendes Glied) እና የኋላ ክፍል (determiniertes Glied) ግንኙነት ሊሆን የሚችለው፡-

*   ተጣምሮ ወይም ተከታታይ መስጫ፡ ኮምፖዚተሙ ሲፈታ፣ ፊት ክፍሉ ለኋላ ክፍሉ በተመሳሳይ ካሱ (ማለትም፣ ከጥቅስ ውጭ በኖሚናቲቭ (⟪प्रथमा⟫)፣ በጥቅስ ውስጥ በሲንታክቲክ የተጠየቀ ካሱ) የበለጠ ማብራሪያ ይሰጣል
*   ካሱያል፡ ፊት ክፍሉ ኮምፖዚተሙ ሲፈታ ከኋላ ክፍሉ በተለየ ካሱ ውስጥ ይገኛል (ማለትም፣ ኖሚናቲቭ ውስጥ አይደለም - ⟪प्रथमा⟫)
*   አድቨርባል፡ ፊት ክፍሉ ዲክሊነሽን የማይደረግበት ቃል ነው

የሁለቱንም ክፍሎች የጥንድ ግንኙነት በአንድ ውስብስብ ቃል ውስጥ ከሚገኘው ጥንድ ግንኙነት ጋር ልዩነት የለውም፡ ውስብስብ ቃሉ እንደ አንድ ቃል ነው የሚለወጠው፡

ለምሳሌ

> ስም. ነጠ. ⟪तत्पुरुषः⟫ = ⟪तस्य पुरुषः⟫
> ረጂ. ነጠ. ⟪तत्पुरुषम्⟫ = ⟪तस्य पुरुषम्⟫
> ሰዋ. ነጠ. ⟪तत्पुरुषेण⟫ = ⟪तस्य पुरुषेण⟫
> ምን. ነጠ. ⟪तत्पुरुषस्य⟫ = ⟪तस्य पुरुषस्य⟫
> ስም. ብዴ. ⟪तत्पुरुषाः⟫ = ⟪तस्य पुरुषाः⟫
> ወዘተ.

የአንድ ታትፑሩሳ ውስብስብ ቃል ስም ለብዙ ልዩነቶች ከኋላ ክፍሉ ጋር ነው።

## 15.3. ዲተርሚናቲቭ ኮምፖዲታ ምስ አትሪቡቲቭ / አፖዚሽናል ፍሪድግሊድ = ካርማዳራያ ም. = ⟪कर्मधारय⟫
::: grammar-box

በካርማዳራያ ውስጥ ሁለቱም ክፍሎች በተመሳሳይ ጥንድ ግንኙነት ይገኛሉ።

:::
ለምሳሌ

⟪गुणवत्पुत्रः⟫ = ⟪गुणवान्पुत्रः⟫ = "አንድ ልጅ በጥሩ ባህሪያት"
ረጂ. ነጠ. ⟪गुणवत्पुत्रम्⟫
ስም. ብዴ. ⟪गुणवत्पुत्राः पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती क्षत्रिया⟫ = "አንድ የተሻለ ክሽትሪያ ሴት"

ለካርማዳራያ ውስጥ ያሉት ክፍሎች ቅደም ተከተል የሚከተለው ልዩ ህግ ይገኛል፡

*   ካርማዳራያ ማነፃፀሪያን ይገልጻል፣ ከዚያም ከዚያ ጋር የሚነፃፀረው ክፍል በኋላ ክፍል ውስጥ ይገኛል፡

*   ነገር ግን አንድ ካርማዳራያ (Karmadhāraya) አፖዚሽን (የኋለኛውን ክፍል በስም ይበልጥ መግለጽ) ሲገልጽ፣ ገላጩ ክፍል በቀዳማይ ክፍሉ ላይ ይቆማል (Kielhorn)፦

⟪नरसिंहः⟫ እንዲሁም ሊፈታ ይችላል፦ ⟪नर एव सिंहः⟫ = «አንበሳ፣ እርሱም (በእውነቱ) ሰው የሆነ።» (Kielhorn)

እንደነዚህ ያሉት አፖዚሽናዊ ካርማዳራያዎች በአገር ውስጥ ትንታኔዎች ከላይ እንዳለው ምሳሌ በ ⟪एव⟫ አማካኝነት ይፈታሉ (Kielhorn)።

## 15.4. ታትፑሩሻ በጠባቡ ትርጉም (Tatpuruṣa) (Kielhorn)

::: grammar-box

ታትፑሩሻቬራይንግስ (Tatpuruṣaverbindungen) ለኖሚና (ስታንታቲቭ እና አጅክቲቭ) ግንኙነቶች ሊሆኑ ይችላሉ፣ እነዚህም ፊት ክፍሉ - በሲንታክስ ህጎች መሰረት - በማንኛውም ካሱ ላይ ሊሆን ይችላል። በተጠበቀ መልኩ፣ ፊት ክፍሉ በብዛት ጄኔቲቭን (⟪षष्ठी⟫) ይወክላል፣ ምክንያቱም ይህ ካሱ ኖሚናዎችን መግለጫ ለመግለጽ የሚያገለግል ነው።

:::
ለምሳሌ

⟪क्षत्रियपुत्रः⟫ = ⟪क्षत्रियस्य पुत्रः⟫ = «የክሻትሪያ ልጅ»፣ «ወጣት ክሻትሪያ»፣ «የክሻትሪያዎች ወገን አባል» (Kielhorn)  
Akk. sg. ⟪क्षत्रियपुत्रम्⟫  
Gen. sg. ⟪क्षत्रियपुत्रस्य⟫  
ወዘተ  

⟪गुरुभावः⟫ =  ⟪गुरोर्भावः⟫  = «የመምህር ባህሪ» (Kielhorn)

⟪धनलोभः⟫ = ⟪धनस्य लोभः⟫ = «የሀብት ምኞት፣ ስግብግብነት» (Kielhorn)

⟪लोकगतिः⟫ =  ⟪लोकस्य गतिः⟫ = «የዓለም አካሄድ፣ የሰዎች ጠባይ» (Kielhorn)

ማንኛውም የጄነቲቭ ግንኙነት በታትፑሩሻ (Tatpuruṣa) ሊተካ ይችላል። ትንሽ መዘርዝሮች ለምሳሌ በካል (Kale)፣ ከፍተኛ የሳንስክሪት ስነ-ግራመር § 211 ይታያሉ፣ እዚያም በፓኒኒ (Pāṇini) ላይ ተመሳሳይ ክፍሎች ይገኛሉ።

ነገር ግን የታትፑሩሻ (Tatpuruṣa) ቀዳማይ ክፍል በመሰረቱ ማንኛውም ኬስየስ (Kasus) መወከል ይችላል። ነገር ግን ሁሉም በስነ-ቃል (syntactically) የተፈቀዱ ኬስየስ ግንኙነቶች በታትፑሩሻ (Tatpuruṣa) ሊተኩ አይችሉም። ተዛማጅ ሕጎችን በረግጠኛነት ሁኔታ ካል (Kale)፣ ከፍተኛ የሳንስክሪት ስነ-ግራመር § 203 - 217 ወይም ፓኒኒ (Pāṇini) 2,1,22 - 2,2,22 ላይ ይገኛሉ።

::: grammar-box

ቀዳማይ ክፍሉ በቅርንጫፎች (Kompositum) ሲሰበር በአንድ ቁጥር (Singular)፣ ሁለት ቁጥር (Dual) ወይም በብዛት ቁጥር (Plural) ሊሆን ይችላል። የትኛውም አማራጭ እንዳለ ከቃል ትርጓሜ እና ከአውዱ መተንበይ አለብት።

:::
ምሳሌዎች፡-

ቀዳማይ ክፍሉ አኩዛቲቭ (⟪द्वितीया⟫) ይወክላል፡ ለምሳሌ በተለያዩ PPPs ከእንቅስቃሴ ግብሮች (Pāṇini 2,1,24) ጋር፡-

⟪ग्रामगतः⟫ = ⟪ग्रामं गतः⟫ = "ወደ ጎበዝ የሄደ አንድ"  
⟪नरकपतिता⟫ = ⟪नरकं पतिता⟫ = "ወደ ጊዜያዊነት የፈረሰች አንድ"

ቀዳማይ ክፍሉ ኢንስትሩመንታሊስ (⟪तृतीया⟫) ይወክላል፡ ለምሳሌ ብዙውን ጊዜ አጀንስ (⟪कर्तृ⟫) ነው በኖሚናል ቅርጾች ላይ kṛt-ሶፊክስ (ለምሳሌ PPP) ሲጠቀሙ፡-

⟪देवकृतम्⟫ = ⟪देवेन⟫ / ⟪देवैः कृतम्⟫ = "ከአምላክ / ከአማልክት የተፈጠረ"  
እንዲሁም ሊፈታ ይችል ነበር፡- ⟪देवस्य⟫ / ⟪देवानां कृतम्⟫ = "የአምላክ / የአማልክት ስራ / ተግባር ; የአምላክ ስራ, የአማልክት ስራ"  

⟪बुद्धरक्षिता⟫  = ⟪बुद्धेन रक्षिता⟫ = "የቡድን በሚጠበቅ ነበር" (የተለመደ ስም)

## 15.5. የቅርንጫፎች (Komposita) መሰበር (ድንድቫስ ውጪ)

በሳንስክሪት ውስጥ ማንኛውም የረዘመ ቅርንጫፎች (Komposita) ሊፈጠሩ ይችላሉ እና በተደጋጋሚም ይፈጠራሉ (ከ10 እስከ 30 ክፍሎች ያላቸው ቅርንጫፎች ልዩ አይደሉም!)፣ ነገር ግን - በድንድቫስ (Dvandvas) ውጪ ሁሉም ቅርንጫፎች በደረጃ ሁለት ክፍሎች ይከፋፈላሉ፡-

ለምሳሌ

⟪गुणवत्पुत्रकृतपुण्यम्⟫

::: indent
1\. ደረጃ (ዋና ቁጥጥር)፡ ⟪गुणवत्पुत्रकृतं ॥१॥ पुण्यम्⟫

2\. ደረጃ (1. ጎን ቁጥጥር)፡ ⟪गुणवत्पुत्रेण ॥२॥ कृतं ॥१॥ पुण्यम्⟫

3\. ደረጃ (2. ጎን ቁጥጥር)፡ ⟪गुणवता॥३॥ पुत्रेण ॥२॥ कृतं ॥१॥ पुण्यम्⟫

= "የተወደሰው ጥፋት (የተወደሰው)፣ የተሳካው ተስማሚ ልጄ የሰራው"
:::
በዚህ ሂደት የተለያዩ የተዋሃዱ ቃላት ዓይነቶች ሊቀላቀሉ ይችላሉ፣ ለምሳሌ፡ ቅድሚያ ክፍል፡ ባሁቪሪሂ (⟪बहुव्रीहि⟫) - ኋላ ክፍል፡ ታትፑሩሻ እናዘ።

ለምሳሌ

⟪ब्राह्मणक्षत्रियवैश्यधर्मः⟫

::: indent
1\. ደረጃ፡ ⟪ब्राह्मणक्षत्रियवैश्यानां धर्मः⟫ (ቅድሚያ ክፍል፡ ኢታሬታራዳንድቫ)

2\. ደረጃ፡ ⟪ब्राह्मणानां क्षत्रियाणां वैश्यानां च धर्मः⟫

= "የብራህማን፣ ክሽትሪያስ እና ቫይሻስ ዘር"
:::
ብዙ ጊዜ ለአንድ የተዋሃደ ቃል የመፍታት የተለያዩ አማራጮች ይኖራሉ። ትክክለኛው ወይም ቢያንስ ምርጡ ምንድን ነው የሚለው ከግንኙነቱ እና ከጽሑፉ ይዘት ብቻ ሊወሰን ይችላል። አንዳንድ ጊዜ እንዲህ ዓይነቱ ውሳኔ ማድረግ አይቻልም። ብዙ ጊዜ ሁለት የመፍታት አማራጮች በጽሑፉ ጸሐፊ የተፈለጉ ሊሆኑ ይችላሉ። ከዚያ በተርጉሞች ሁለቱንም የመፍታት አማራጮች መግለጽ አለብን ("እና"፣ "ወይም" "በተለየ" እና እንደዚህ ዓይነት ቃላት በመጠቀም)።

ለምሳሌ

2. ⟪पुण्यवतः पुत्रस्य कृतम्⟫ = "የተከናወነው ነገር በእኔ ምስጋና የሚገባው ወንድ"

## 15.6. በተዋህዶ ቃላት (⟪समास⟫ m.) ውስጥ የመጀመሪያው ክፍል ቅርጽ
::: grammar-box

በሁሉም የተዋህዱ ቃላት ዓይነቶች ውስጥ፣ የመጀመሪያው ክፍል በአጠቃላይ የማይቀየር የቃል ሥር ነው። ሁለት ሥሮች ያሏቸው ስምዎች በደካማ ሥር ይቀመጣሉ። ሴት ተባላሪ ቃላት፣ የሚከተለውን ክፍል በተዋህዶ ቃል ውስጥ የሚገልጹ፣ በአጠቃላይ በወንድ ሥር ይቀመጣሉ፡-

ለምሳሌ፡-

⟪पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती क्षत्रिया⟫ = "ምስጋና የሚገባት ኢክሽትሪያ ሴት"  
⟪गुणवत्पुत्रः⟫ = ⟪गुणवान् पुत्रः⟫ = "ጥሩ ባህሪ ያለው ወንድ"

:::
## 15.7. የ⟪तत्पुरुष⟫ ክፍፍል

1. ⟪प्रथमातत्पुरुषः⟫ : የመጀመሪያው ክፍል በ⟪विग्रहवाक्य⟫ ስም (⟪प्रथमा⟫) ይቀመጣል
2. ⟪द्वितीयातत्पुरुषः⟫ : የመጀመሪያው ክፍል በ⟪विग्रहवाक्य⟫ ስም (⟪द्वितीया⟫) ይቀመጣል
3. ⟪तृतीयातत्पुरुषः⟫ : የመጀመሪያው ክፍል በ⟪विग्रहवाक्य⟫ ስም (⟪तृतीया⟫) ይቀመጣል
4. ⟪चतुर्थीतत्पुरुषः⟫ : የመጀመሪያው ክፍል በ⟪विग्रहवाक्य⟫ ስም (⟪चतुर्थी⟫) ይቀመጣል
5. ⟪पञ्चमीतत्पुरुषः⟫ : የመጀመሪያው ክፍል በ⟪विग्रहवाक्य⟫ ስም (⟪पज्चमी⟫) ይቀመጣል
6. ⟪षष्ठीतत्पुरुषः⟫ : የመጀመሪያው ክፍል በ⟪विग्रहवाक्य⟫ ስም (⟪षष्ठी⟫) ይቀመጣል
7. ⟪सप्तमीतत्पुरुषः⟫ : የመጀመሪያው ክፍል በ⟪विग्रहवाक्य⟫ ስም (⟪सप्तमी⟫) ይቀመጣል

* ⟪कर्मधारयः⟫ : ተዛማጅ ታትፑሩሻ፣ በሌሎችም መንገዶች፡-
* ⟪उपमानपूर्वपदकर्मधारयः⟫ : ⟪विग्रहवाक्य⟫ ከመጀመሪያው ክፍል በኋላ ⟪इव⟫ ጋር
* ⟪उपमानोत्तरपदकर्मधारयः⟫ : ⟪विग्रहवाक्य⟫ ከሁለተኛው ክፍል በኋላ ⟪इव⟫ ጋር
* ⟪रूपकसमासः⟫ : ⟪विग्रहवाक्य⟫ ጋር ⟪एव⟫
* ⟪द्विगुसमासः⟫ : ቁጥር በመጀመሪያው ክፍል ውስጥ
* ⟪नञ्तत्पुरुषः⟫ (⟪निषेधतत्पुरुषः⟫) : በመነሻው ክፍል a-, an- ማረጋገጫ ጋር
* ⟪गतिसमासः⟫ : በመነሻው ክፍል በቅድመ ቃል ጋር
* ⟪प्रथमातत्पुरुषः⟫ ወዘተ. (እዚህ ላይ ይመልከቱ)

### 15.7.1. ክፍል ስርዓት कर्मधारय

1. ⟪विशेषणपूर्वपदकर्मधारयः⟫ : ቀዳማይ ክፍል ስም-መንግሻ (⟪विशेषण⟫)
2. ⟪विशेषणोभयपदकर्मधारयः⟫ : ክልቲኡ ክፍላት ስም-መንግሻ እዮም፣ ናይ ምውሳኽ-ግዜ ዘመልክቱ ስም-መንግሻ እውን ኣብዚ ይኣትዉ፦ "መጀመርታ ተሓምማምካ፣ ድሕሪኡ ተወቅስካ"
3. ⟪उपमानपूर्वपदकर्मधारयः⟫ (= ⟪उपमासमासः⟫): ኣብ ቀዳማይ ክፍል ምስሊ/ምንጽጻር፣ ኣብ ካልኣይ ክፍል እቲ ዝተነጻጸረ ባህርይ፦ ንኣብነት "ንወርቂ ዝበለ"
4. ⟪उपमानोत्तरपदकर्मधारयः⟫ (= ⟪उपमितसमासः⟫): ምንጽጻር ኣብ ካልኣይ ክፍሊ
5. ⟪रूपकसमासः⟫ : ⟪विग्रहवाक्य⟫ ምስ एव⟩ ኣብ ቀዳማይ ክፍሊ (ምስላ)
6. ⟪संभावनपूर्वपदकर्मधारयः⟫ : ክልቲኡ ክፍላት ናይ ሓደ ሰብ ወይ ነገር እዮም፣ ንኣብነት ⟪कालिदासकविः⟫ = ⟪कालिदास इति कविः⟫ = "እቲ ኣዝያይ ሓላፊ ካሊዳሳ"
7. ⟪कर्मधारयः⟫ ምስ कु⟩ / ⟪कद्⟫ ከም ቀዳማይ ክፍሊ፦ "ኣእምሮ..."
8. ⟪कर्मधारयः⟫ ምስ किम्⟩ ከም ቀዳማይ ክፍሊ፦ ጥቕዓት
9. PPP + ኣሉታዊ PPP፦ "ከም ዝተኻእለ"፣ ንኣብነት ⟪कृताकृतम्⟫ = "ከም ዝተገብረ"
10. ⟪द्विगुसमासः⟫ : ቁጽሪ ኣብ ቀዳማይ ክፍሊ
