# ትምህርት 53

## 53.1. ሁለተኛ ብዜት (⟪द्विवचन⟫ n.) ስምዎች

::: grammar-box
**ሁለተኛ ብዜት (⟪द्विवचनम्⟫) ሁለትን ለመግለጽ ያገለግላል፡**

:::
::: indent
⟪अश्विनौ⟫ "ሁለቱ አሽዊኖች"
:::
**ሁለተኛ ብዜት በሚያስፈልጉበት ሁለት ነገሮች ወይም ተመሳሳይ ሁኔታዎች ውስጥ አስገድዶ መጠቀም ያለበት ነው፡**

::: indent
⟪हस्तौ⟫ "እጆች (የአንድ ሰው)"
⟪पादौ⟫ "ጉሮሮዎች (የሰው ፣ የአንበሳ ወይም ሌላ ትክክለኛ ሁለት እግር ያላቸው)"
:::
**አንዳንድ ጊዜ ሁለተኛ ብዜት አንድ ወንድ እና አንድ ግላ ተመሳሳይ ክፍል (ዝርያ ፣ ዓይነት) የሚገልጽ ነው፡**

::: indent
⟪पितरौ⟫ "አባት እና እናት = ወላጆች"
:::
**"ጥንድ" የሚል ቃል ማለት - ለምሳሌ ⟪युग⟫ n. ፣ ⟪द्वन्द्व⟫ n. ፣ ⟪द्वय⟫ n. - በአጠቃላይ ነጠላ ቁጥር ውስጥ ይጠቀማሉ ፣ ነገር ግን ሁለት ወይም ከዚያ በላይ ጥንዶች ቢኖሩ፡**

::: indent
⟪बाहुद्वयम्⟫ "ጥንድ እጆች"
:::

*   ⟪अन्य⟫ 3 "ሌላ"

*   ⟪उभय⟫ 3 "ሁለቱ" ድርጊት (Dual) የለውም። በከፊል ቁጥር (Singular) እና በብዛት ቁጥር (Plural) ለወንድ እና ለጾታ-የለሽ (neutr.) እንደ ⟪सर्व⟫ ይቀየራል። ሴት (Femininum)፡ ⟪उभयी⟫ (እንደ ⟪देवी⟫)።
*   ⟪उभ⟫ 3 "ሁለቱ" በድርጊት ቁጥር (Dual) ብቻ ይጠቀማል እና እንደ ⟪देव⟫ ወንድ፣ ⟪फल⟫ ጾታ-የለሽ፣ ወይም ⟪देवता⟫ ሴት ይቀየራል።

## 53.8. ስህተት ያለው ንጽፀት (Unregelmässige Steigerung)

::: grammar-box
**አንዳንድ ተመሳሳይ ስሞች (Adjektives) ንጽፀትን በሚከተሉት ⟪कृत्⟫-ስም ማጠቃለያዎች (-Suffixen) ይፈጥራሉ (!)**፡

*   ንጽፀት (Komparativ)፡ **-īyas**
*   ከፍተኛ ንጽፀት (Superlativ)፡ **-iṣṭha**

**⟪तद्धित⟫-ስም ማጠቃለያዎች -⟪तर⟫ እና -⟪तम⟫ በተመሳሳይ ስም (Adjektiv) ወንድ ግስት ላይ ሲጨመሩ፣ -⟪ईयस्⟫ እና -⟪इष्ठ⟫ ስም ማጠቃለያዎች በተመሳሳይ ስም (Adjektiv) የተገኘበት ዋና ቃል (Wurzel) ላይ ይጨመራሉ (እንደዚያው ከተኖር!)። የዋና ቃል (Wurzel) ስም ማጠቃለያ ከፍተኛ ደረጃ (hochstufig) አለው።**

**-iṣṭha (ሴት፡ iṣṭhā) ከፍተኛ ንጽፀት (Superlative) እንደ a ወይም ā ግስት ይቀየራል።**

**-īyas ማለት ይቀንሳል እና ይደርስ**
