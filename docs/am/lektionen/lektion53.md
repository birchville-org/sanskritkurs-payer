# ትምህርት 53

## 53.1. ዱዋል (⟪द्विवचन⟫ n.) የስም ለውጦች

::: grammar-box
**ዱዋል (⟪द्विवचनम्⟫) ለመግለጽ ያገለግላል፡፡ "ሁለት"**

:::
::: indent
⟪अश्विनौ⟫ "ሁለቱ አሽዊን"
:::
**የዱዋል ተጠቃሚነት በሁለት ነገሮች ወይም ሌሎች ሁኔታዎች ላይ ሲሆን ግዴታ ነው፡፡**

::: indent
⟪हस्तौ⟫ "እጆች (የአንድ ግለሰብ)"
⟪पादौ⟫ "ጉንዶች (የሰው፣ የወፍ ወይም ሌላ ሁለት እግር ያለው)"
:::
**አንዳንድ ጊዜ ዱዋል የተወሰነ ክፍል (ዝርያ፣ ስም) ውስጥ ያለ ሁለት ልዩ ልዩ ምሳሌዎችን ያመለክታል፡፡**

::: indent
⟪पितरौ⟫ "አባት እና እናት = ወላጆች"
:::
**"ጥንድ" የሚል ትርጉም ያላቸው ቃላት - ለምሳሌ ⟪युग⟫ n.፣ ⟪द्वन्द्व⟫ n.፣ ⟪द्वय⟫ n. - ሁልጊዜ በነጠላ ቁጥር ይጠቀማሉ፣ ሁለት ወይም ከዚያ በላይ ጥንዶች ካልሆኑ፡፡**

::: indent
⟪बाहुद्वयम्⟫ "ጥንድ እጆች"
:::

## 53.7. የምሳሌ ቃላት

የሚከተሉት የምሳሌ ቃላት በሁሉም ግራር ሁኔታዎች እንደ ⟪यद्⟫ ይቀየራሉ፡

*   ⟪उभय⟫ 3 "ሁለቱ" ሁለቱን አያውቅም። በነጠላ እና በብዙ ቁጥር ማርካ. እና ኒውትር. እንደ ⟪सर्व⟫ ይቀየራል። ፌሚኒን፡ ⟪उभयी⟫ (እንደ ⟪देवी⟫)።
*   ⟪उभ⟫ 3 "ሁለቱ" በሁለቱ ቁጥር ብቻ ይጠቀማል እና እንደ ⟪देव⟫ ማርካ.፣ ⟪फल⟫ ኒውትር. ወይም ⟪देवता⟫ ፌሚኒን ይቀየራል።

የሚከተሉት የምሳሌ ቃላት እንደ ⟪सर्व⟫ ይቀየራሉ። በአብላ.ሎክ.ሐ.ማ.ኒ. እና በነጠላ.ብ. ሊሆኑ ይችላሉ በ-a- ወይም -ā- ልዩነት ይቀየራሉ፡

## 53.8. ያልተለመደ ማሳደግ

::: grammar-box
**ብዙ ቃላት ኮምፓራቲቭ ወይም ሱፐርሌቲቭን በሚከተሉት ⟪कृत्⟫-ሶፊክስ ለመፍጠር ይፈጥራሉ (!)፡**

### 53.10.1. የሜትሩም ማስታወቂያ ትርጉም

የሜትሩም ማስታወቂያ ከሚከተሉት ምክንያቶች ምክንያት አስፈላጊ ነው፡

1.  **አስተማማኝ:** የቃል መጠን በተለይም የአንድን ሀሳብ ውበት ያስከትላል። እንዲሁም የተወሰኑ የቃል መጠኖች ለተወሰኑ ስሜቶችን ለመግለጽ ወይም ለተወሰኑ ማህበራዊ ደረጃዎች (⟪वर्ण⟫) ለመዛመድ ሊያገለግሉ ይችላሉ። የተለያዩ የቃል መጠኖች በተለያየ መንገድ ይነበባሉ። :br ለምሳሌ የ⟪शिवताण्डवस्तोत्र⟫ (የሸዋ ግጥም) ማንበብ ስለ አስተማማኝ ተጽዕኖ ጥሩ ሀሳብ ይሰጣል፡ [http://de.youtube.com/watch?v=5KjfiJlkO58](http://de.youtube.com/watch?v=5KjfiJlkO58)

3.  **የጊዜ ቅደም ተከተል:** በታሪክ ሂደት ውስጥ የተወሰኑ የቃል መጠኖች የተወሰኑ ለውጦችን አልፈዋል። ይህ ጽሑፉን በግምት ለመቀመጥ ሊረዳ ይችላል። ለዚህ **ኦልደንበርግ፣ ሄርማን (1854–1920):** ስለ ትሪሹብ ስብሰባ ታሪክ ; ይሁን፡ ስለ ስሎክ ታሪክ። -- ሁለቱም በ፡ :br **ኦልደንበርግ፣ ሄርማን (1854–1920):** ትናንሽ ጽሑፎች / ሄርማን ኦልደንበርግ። አዘጋጅ፡ ክላውስ ኤል። ጃነርት። -- ዊዝባደን ፡ ስታይነር። -- 3 መጻሕፍት። -- (ግላዜናፕ-ስቶፍቱንግ ; ...)። -- መጽሐፍ 2። -- 1967። -- ገጽ 1188 - 1255።
