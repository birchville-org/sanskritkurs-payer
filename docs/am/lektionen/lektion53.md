# ትምህርት 53

## 53.1. የስሞች ሁለትዮሽ (⟪द्विवचन⟫ n.)

::: grammar-box
**ሁለትዮሽ (⟪द्विवचनम्⟫) 'ሁለት' የሚለውን ለመግለጽ ያገለግላል፦**

:::
::: indent
⟪अश्विनौ⟫ "ሁለቱ አሽቪኖች"
:::
**የሁለትዮሽ ቁጥር አጠቃቀም ሁለት ነገሮችን ወዘተ በሚመለከትበት ጊዜ ግዴታ ነው፡**

::: indent
⟪हस्तौ⟫ "እጆች (የአንድ ግለሰብ)"
⟪पादौ⟫ "እግሮች (የሰው፣ የዝንጀሮ ወይም የሌላ ባለ ሁለት እግር)"
:::
**አንዳንድ ጊዜ ሁለትዮሽ ቁጥር የአንድ ዓይነት ክፍል (ዝርያ፣ ወገን) ወንድ እና ሴት ናሙናን ያመለክታል፡**

::: indent
⟪पितरौ⟫ "አባት እና እናት = ወላጆች"
:::
**"ጥንድ" የሚል ትርጉም ያላቸው ቃላት - ለምሳሌ ⟪युग⟫ n., ⟪द्वन्द्व⟫ n., ⟪द्वय⟫ n. - ነገር ግን ሁልጊዜ በነጠላ ቁጥር ጥቅም ላይ ይውላሉ፣ ጉዳዩ ሁለት ወይም ከዚያ በላይ ጥንዶችን የሚመለከት ካልሆነ በስተቀር፡**

::: indent
⟪बाहुद्वयम्⟫ "አንድ ጥንድ ክንዶች"
:::

ሰባተኛው ክፍለ-ቃል በሁለተኛው እና በአራተኛው ፓዳ ውስጥ አጭር ሲሆን በሌሎቹ ሁለቱ ደግሞ ረጅም ነው።"

::: grammar-box
