# ትምህርት 33

## 33.1. ድግግሞሽ (⟪अभ्यास⟫ m.)

* ሦስተኛው የአሁን ጊዜ መደብ
* (እንዲሁም የሌሎች የአሁን ጊዜ መደቦች አንዳንድ ግሶች)፣
* ፍጹም ጊዜ፣
* የተደገመው አኦሪስት፣
* ተደጋጋሚው ግስ እና
* ምኞታዊው ግስ
