# ትምህርት 47

## 47.1. ትዕዛዛዊ ግስ (⟪लोट्⟫)

::: grammar-box
ትዕዛዛዊ ግስ (⟪लोट्⟫) የሚያመለክተው

*   **ትዕዛዝ** (በጌሩንዲቩም (⟪कृत्य⟫) ጭምር ይገለጻል)
*   **መመሪያ**
*   **ጥያቄ**
*   **ምኞት**
*   **ልመና**
*   **ግብዣ**
*   **ማሰላሰል**
*   **ጥያቄ**

እነዚህን የተጠቀሱትን ትርጉሞች ከኦፕታቲቭ (⟪विधिलिङ्⟫) ጋር ይጋራል።

በትዕዛዝ አንቀጽ በተጨማሪም የሚከተሉት ይገለጻሉ፡

*   **ፈቃድ**
*   **አንድ ድርጊት ጊዜው መድረሱን** (በጌሩንዲቩም (⟪कृत्य⟫) ጭምር ይገለጻል)
*   **ምርቃት**
:::
ምሳሌዎች፡

::: indent
⟪एहि⟫ ⟪।⟫ "ና!"

⟪ग्रामं⟫ ⟪भवानागच्छतु⟫ ⟪।⟫ ወይም አማራጭ ፡ ⟪ग्रामं⟫ ⟪भवानगच्छेत्⟫ ⟪।⟫ "ወደ መንደሩ ይምጡ!"

⟪वेदमध्ययै⟫ ⟪।⟫ ወይም አማራጭ፡ ⟪वेदमधीयीय⟫ ⟪।⟫ "ቬዳን ማጥናት እፈልጋለሁ።"

⟪इच्छामि⟫ ⟪भुङ्क्तां⟫ ⟪भवान्⟫ ⟪।⟫ ወይም አማራጭ፡  ⟪इच्छामि⟫ ⟪भुञ्जीत⟫ ⟪भवान्⟫ ⟪।⟫ "እንዲበሉ እመኛለሁ።"

⟪किं⟫ ⟪वेदमध्ययै⟫ ⟪।⟫ ወይም ኦፕታቲቭ: ⟪किं⟫ ⟪वेदमधीयीय⟫ ⟪।⟫ "ቬዳውን ላጥናው?"

⟪करोतु⟫ ⟪शस्त्रं⟫ ⟪भवान्⟫ ⟪।⟫ ወይም ጌሩንዲቭ: ⟪भवता⟫ ⟪शस्त्रं⟫ ⟪कर्तव्यम्⟫ ⟪।⟫ "ቢላዋ ይስሩ!" ; "ቢላዋ መስራት ይችላሉ።" ; "ቢላዋ የሚሰሩበት ጊዜ ነው።"

⟪चिरं⟫ ⟪जीवतु⟫ ⟪भवान्⟫ ⟪।⟫ "እድሜዎ ይርዘም!"
:::
::: grammar-box
ትህትና የተሞላባቸው ትዕዛዞች ብዙውን ጊዜ በተግባሪ ተዕዛዛዊ ግሦች ይገለጻሉ።
:::
ምሳሌዎች:

::: indent
⟪भवता⟫ ⟪प्रविश्यताम्⟫ ⟪।⟫ "**እባክዎ** ይግቡ!"

⟪निषद्यताम्⟫ ⟪।⟫ "እባክዎ ይቀመጡ!"
:::
በጥንታዊ ሳንስክሪት ትዕዛዛዊ ግሥ ውስጥ፣ የ1ኛ መደብ ቅርጾች የድሮ የግንኙነት ቅርጾች ናቸው። የቬዲክ ግንኙነት በዋነኝነት ምኞትን የሚገልጽ ዘዴ ነው፦ "እንሂድ!" "እንሂድ!"

::: grammar-box
ትዕዛዛዊ ግሡ ከግሡ የአሁን ጊዜ ግንድ የተገኘ ነው።
:::

22\. ሰው (ብዙ) ትእዛዝ ይሰጣል።

እነርሱ ያዙ።

እንዲሁ ይሁን!

ፈረሱን ምታ!

እነሱ ይንከራተቱ።

28\. የጎታው ጭነትን መሸከም አለበት።
