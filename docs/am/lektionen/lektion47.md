# ትምህርት 47

## 47.1. ትዕዛዝ (⟪लोट्⟫)

::: grammar-box
ትዕዛዝ (⟪लोट्⟫) ይገልጻል

*   **ትዕዛዝ** (በገሩንቲቨም (⟪कृत्य⟫) ይገለጻልም)
*   **መመሪያ**
*   **ጥያቄ/ድላይ**
*   **ፈንታ/ድላይ**
*   **ጥያቄ/እንክብላ**
*   **አስተዋውቀ/እንክብላ**
*   **አስተዳደር/ማሰብ**
*   **ጥያቄ/መጠየቂያ**

ከተዘረዘሩት ትርጉማት ጋር ኦፕቲቭ (⟪विधिलिङ्⟫) ይጋራል።

በትዕዛዝ ሌሎችንም ይገልጻል:

*   **ንቁ/ማስተዋወቂያ**
*   **አንድ ግብ በጊዜው መሆኑ** (በገሩንቲቨም (⟪कृत्य⟫) ይገለጻልም)
*   **የእንቁ/መስገደል ፈንታ**
:::
ምሳሌዎች:

::: indent
⟪एहि ।⟫ "ውጣ!"

⟪ग्रामं भवानागच्छतु ।⟫ ወይም ኦፕቲቭ : ⟪ग्रामं भवानगच्छेत् ।⟫ "ወደ ጎቢው ይመጡ!"

⟪वेदमध्ययै ।⟫ ወይም ኦፕቲቭ: ⟪वेदमधीयीय ।⟫ "ቬዳን ማጥናት እፈልጋለሁ።"

⟪इच्छामि भुङ्क्तां भवान् ।⟫ ወይም ኦፕቲቭ:  ⟪इच्छामि भुञ्जीत भवान् ।⟫ "እንዲመገቡ እፈልጋለሁ።"

⟪किं वेदमध्ययै ।⟫ ወይም ኦፕቲቭ: ⟪किं वेदमधीयीय ।⟫ "ቬዳን ማጥናት ነው?"

⟪करोतु शस्त्रं भवान् ।⟫ ወይም ገሩንቲቭ: ⟪भवता शस्त्रं कर्तव्यम् ।⟫ "ጥርስ ይሠሩ!" ; "ጥርስ ማምረት ይችላሉ" ; "ጊዜው የተነሳ ሲሆን ይሠሩ።"

⟪चिरं जीवतु भवान् ।⟫ "ረጅም ሕይወት ይኖርልዎ!"
:::
::: grammar-box
ጥንቃቄ ያለው ትዕዛዝ በፓሲቭ-ትዕዛዝ ቅርጾች በተለምዶ ይገለጻል።
:::
ምሳሌዎች:

::: indent
⟪भवता प्रविश्यताम् ।⟫ "እባክዎ **ይግቡ**!"

⟪निषद्यताम् ।⟫ "እባክዎ ወሰዱ!"
:::
በክላሲካል ሳንስኪርት ትዕዛዝ ውስጥ የ1. ሰው ቅርጾች አሮጊ ኦንቲንክቲቭ ቅርጾች ናቸው። ቬዲክ ኦንቲንክቲቭ በተለይ ድላይ የሚገልጽ ሞዱስ ነው: "እንሂድ!" "እንጓዝ!"

::: grammar-box
ትዕዛዙ ከገለጻ ሥር ይመሰረታል።
:::

## 47.3. ልምምድ

A) ይተርጉሙ፡-

⟪यदि गच्छसि गच्छ त्वम् । अहं न गमिष्यामि ॥१॥ आर्य प्रेक्षस्व मे परिभवम् ॥२॥ भो राम यदि मया गन्तव्यं तदैषा कन्यापि मम सहायिनी भवतु ॥३॥⟫

![](/images/lekt4703.webp)
ስዕል፡- ⟪भो राम यदि मया गन्तवं तदैषा कन्यापि मम सहायिनी भवतु⟫
(ምንጭ ስዕል፡ [ዝርዝሮች](/am/licenses#lekt4703))

⟪आर्ये तिष्ठ तिष्ठ । न त्वया भेतव्यम् ॥४॥ प्रसीदत्वार्यः ॥५॥ आर्ये स्वागतं ते ॥६॥⟫

::: media
![](/images/lekt4704.webp)
ስዕል፡- ⟪आर्ये स्वागतं ते⟫
(ምንጭ ስዕል፡ [ዝርዝሮች](/am/licenses#lekt4704))
:::
⟪आज्ञापयत्वार्यः किं मया क्रियतामिति ॥७॥ युद्धाय युज्यस्व नैवं पापमवाप्स्यसि ॥८॥ प्रश्नः⟫ : ⟪कस्मात्त्वं भीतः । प्रतिवचनम्⟫ : ⟪तस्य रामस्य गुणेभ्यः । प्रष्टा⟫ : ⟪के तस्य गुणा यस्य गृहं प्रविश्याशितव्यमपि नास्ति ॥९॥ तवैव हस्ते शस्त्रं तिष्ठतु ॥१०॥ भवति न ते परिभवस्तत्रभवतो रामस्य निवेदयितव्यः ॥११॥⟫

B.) ወደ ሳንስክሪት ትርጉም (እባክዎን እፈቃድ/Imperative ያጠቀሙ)፡-

1\. እኔ መቀበል እፈልጋለሁ።

2\. ሰውዬው እረፍት ይኖርበት።

3\. እኛ መጥራት እንወዳለን።

4\. እኔ ራሴን ወደ አንተ (⟪चतुर्थ्या⟫) መጥምቅ እፈልጋለሁ።

5\. ይህ ሥነ-ምግባር መስራት አለበት።

6\. እነርሱ ያዙ (በፓስቭ/ተገላቢጦሽ መዋቅር)።

7\. ወንድሜ ጥበብን ይመኝ!

8\. ጥናቱን ይጀምሩ!

9\. (⟪प्र⟫-⟪यम्⟫) ለአያቶች የኮንፋ ዱቄት ቅርስ ይሰጡ!

10\. እነርሱ ይደስታል!

11\. እኔ ወደ ግሪክ አለም መመልከት እፈልጋለሁ።

12\. ወደ በናረስ መሄድ እንወዳለን (⟪पद्⟫)።

13\. እነርሱ (ብዙ) በአበረከች ሰውነት እግዚአብሔርን በአበረከች ሰውነት ይጸልዩ።

14\. ሙግት አብድ!

15\. ወንዶች ልጆች እኔን መውለድ አለባቸው!

16\. ቤቴን እርስዎ ማሳየት አለብኝ።

17\. ከእኔ ርቀ!

18\. ያለግደ ሊሆን አለበት!

19\. ባልኔን እኛ ልጥፋለሁ።

20\. ሞት፣ ተጋድሎ!

21\. ፈልጉ!

22\. እነሱ (pl.) መምራት ይገባል።

23\. በእርስዎ ቤት ውስጥ እኛ መኖር አለብን።

24\. እንዲህ ሊከናወን አለበት!

25\. ፈረስዎን ይምቱ!

26\. እነሱ (pl.) ሊዘዋወር አለባቸው።

27\. ራስዎን ይጠብቁ!
