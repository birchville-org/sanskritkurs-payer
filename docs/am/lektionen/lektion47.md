# ትምህርት 47

## 47.1. ትዕዛዝ (⟪लोट्⟫)

::: grammar-box
ትዕዛዝ (⟪लोट्⟫) ማለት

*   **ትዕዛዝ** (በገሮንዲቭም (⟪कृत्य⟫)ም ይገለጻል)
*   **መመሪያ**
*   **ጥያቄ**
*   **ፍላጎት**
*   **ጥያቄ**
*   **ግብረመልስ**
*   **ግምት**
*   **ጥያቄ**

እነዚህ ትርጉሞች ከኦፕቲቲቭ (⟪विधिलिङ्⟫) ጋር የተጋሩ ናቸው።

በትዕዛዝ ሌሎችንም ለመግለጽ ይጠቅማል፡

*   **ፍቃድ**
*   **አንድ ስራ በጊዜው መሆኑን** (በገሮንዲቭም (⟪कृत्य⟫)ም ይገለጻል)
*   **የእንግዳ ፍላጎት**
:::
ምሳሌዎች፡

::: indent
⟪एहि ।⟫ "መጣ!"

⟪ग्रामं भवानागच्छतु ।⟫ ወይም ኦፕቲቲቭ፡ ⟪ग्रामं भवानगच्छेत् ।⟫ "ወደ ገጠር ይመጡ!"

⟪वेदमध्ययै ।⟫ ወይም ኦፕቲቲቭ፡ ⟪वेदमधीयीय ।⟫ "ቬዳን ማጥናት እፈልጋለሁ።"

⟪इच्छामि भुङ्क्तां भवान् ।⟫ ወይም ኦፕቲቲቭ፡  ⟪इच्छामि भुञ्जीत भवान् ।⟫ "እነሱ እንዲበሉ እፈልጋለሁ።"

⟪किं वेदमध्ययै ।⟫ ወይም ኦፕቲቲቭ፡ ⟪किं वेदमधीयीय ।⟫ "ቬዳን ማጥናት አለብኝ?"

⟪करोतु शस्त्रं भवान् ।⟫ ወይም ገሮንዲቭ፡ ⟪भवता शस्त्रं कर्तव्यम् ।⟫ "ጠርዝ ያዘጋጁ!" ; "ጠርዝ ማዘጋጀት ይችላሉ።" ; "ጠርዝ ማዘጋጀት በጊዜው ነው።"

⟪चिरं जीवतु भवान् ।⟫ "ረጅም ጊዜ ይኖሩ!"
:::
::: grammar-box
ለጥበብ ትዕዛዞች በፓሲቭ-ትዕዛዝ ይገለጻሉ።
:::
ምሳሌዎች፡

::: indent
⟪भवता प्रविश्यताम् ।⟫ "**እባክዎ** ይግቡ!"

⟪निषद्यताम् ।⟫ "እባክዎ ይቀመጡ!"
:::
በክላሲካል ሳንስክሪት ትዕዛዝ ውስጥ የ1ኛው ሰዎች ቅርጾች ጥንታዊ ኮንጂንክቲቭ ቅርጾች ናቸው። ቬዲክ ኮንጂንክቲቭ በዋናነት ፍላጎትን የሚገልጽ ሞዱስ ነው፡ "እኛ እንሂድ!" "እኛ እንሂድ!"

::: grammar-box
ትዕዛዙ ከአሁን ጥቅል (present stem) ይፈጠራል።
:::

## 47.3. ልምምድ

ለ) ይተርጉሙ፡-

⟪यदि गच्छसि गच्छ त्वम् । अहं न गमिष्यामि ॥१॥ आर्य प्रेक्षस्व मे परिभवम् ॥२॥ भो राम यदि मया गन्तव्यं तदैषा कन्यापि मम सहायिनी भवतु ॥३॥⟫

ለ.) ወደ ሳንስክሪት ይተርጉሙ (እባክዎ ኢምፐራቲቭ ይጠቀሙ)፡-

1\. እኔ መቀበል እፈልጋለሁ።

2\. ሰላም ይኑረው።

3\. እኛ መጥራት እንፈልጋለን።

4\. እኔ ራሴን ለአንተ (⟪चतुर्थ्या⟫) እዘርጋለሁ።

5\. ይህ ሥራ መስራት አለበት።

6\. እነሱ ይኑሩ (ፓሲቭ ግንባታ)።

7\. ወንድዬ ሀብትን ይፈልግ!

8\. ጥናትን ይጀምሩ!

9\. (⟪प्र⟫-⟪यम्⟫) ለአያቶቻችን የአሸዋ ቅቤ ይስጡ!

10\. እነሱ ይደሰቱ!

11\. እኔ ወደ ዓለም እንደምታች ተመልከት።

12\. ወደ በናረስ እንሂድ (⟪पद्⟫)።

13\. እነሱ (ብዙ) እንደ ቅዳሜ ጌታዎች አምላኮችን በቅዳሜ ያከብሩ።

14\. ለእኛ ምስጋና ግባ!

15\. ልጆች ለእኔ ይወለዱ!

16\. ቤቴን እርስዎን እሳይን።

17\. ከእኔ ርቀ!

18\. ነፃ ይውጣ!

19\. ሚስትህን እኔ እጠብቃለሁ።

20\. ሞት፣ ተጠላ!

21\. ግጥሙን ይፍጽሙ!

22\. እነሱ (ብዙ) ይወስኑ።

23\. በቤትህ እንኖር።

24\. እንዲህ ይሁን!

25\. ፈረሱን ምታት!

26\. እነሱ (ብዙ) ይዘዋወሩ።

27\. ይስቁ!

29\. ዓለማትን እንደሚገባ እናስተካክላለን።

30\. መስቀለኛውን ይጠጡ!

31\. አስብ!

32\. እነሱ (ብዙ) ይሸነፉ!

33\. እኛ እርስዎን እንደሚመራን እንፈልጋለን።

34\. ወደ ዕድል ይሁን! (የእንቅስቃሴ ምኞት)
