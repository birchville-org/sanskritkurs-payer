# ትምህርት 5

## 5.1. ስምያዊ ውስብስቦች (samāsa m. = ⟪समास⟫)

የቃላት ውስብስቦችን በጣም በሰፊው መፍጠር የሳንስክሪት ባህሪ ነው።

ዋና ዋና የውስብስብ ፍጥረት መንገዶች፡-
**ኮፑላቲቭ ውስብስቦች** (dvandva n. = ⟪द्वन्द्व⟫)
**ዲተርሚናቲቭ ውስብስቦች** (tatpuruṣa m. = ⟪तत्पुरुष⟫)
**Possesivkomposita** (bahuvrīhi m. = ⟪बहुव्रीहि⟫)

(ለሁለቱም የመጨረሻዎቹ ስም ያላቸው በኋላ ይመልከቱ!)


## 5.2. ስለ ሳንስክሪት ቃል ትርጉም ለውስብስቦች

**ghaṭakapadāni** n. pl. = ⟪घटकपदानि⟫ : የውስብስብ ክፍሎች
**vigrahavākyam** n. = ⟪विग्रहवाक्यम्⟫ : የውስብስብ መፍቻ
**nityasamāsaḥ** m. = ⟪नित्यसमासः⟫ : ለውስብስብ vigrahavākya የሌለው ወይም vigrahavākyaው በውስብስቡ ቃላት ሊሆን የማይችልው።
**aluksamāsaḥ** m. = ⟪अलुक्समासः⟫ : ፊት ለፊት ክፍል የግራጫ መጨረሻ የሚይዝበት ውስብስብ
**luksamāsaḥ** m. = ⟪लुक्समासः⟫ : ፊት ለፊት ክፍሎቹ የግራጫ መጨረሻ የሌላቸው ውስብስቦች (መደበኛው ሁኔታ)
**madhyamapadalopī** m. = ⟪मध्यमपदलोपी⟫ : አንድ ወይም ከዚያ በላይ መካከለኛ ክፍሎች የተጣሉበት ውስብስብ


## 5.3. ኮፑላቲቭ ውስብስቦች (Dvandva n. = ⟪द्वन्द्व⟫)

ኮፑላቲቭ ውስብስቦች ለግራጫ ተመሳሳይ፣ ተዛማጅ ክፍሎች (ስሞች ወይም ቅጦች) ማገናኘት ያገለግላሉ።

::: grammar-box
**አንድ Dvandva ያመለክታል፡**

1. **በተለያዩ ክፍሎቹ የሚገለጹት ሰዎች፣ ነገሮች፣ ባህሪያት ድምር ግንኙነት፡**
Itaretaradvandva = ⟪इतरेतरद्वन्द्व⟫

2. **ወይም እነዚህን ሰዎች፣ ነገሮች ወይም ባህሪያት ወደ አንድ ክፍል ያጠቃልላል፡**
Samāhāradvandva ("Zusammenfassungsdvandva") = ⟪समाहारद्वन्द्व⟫

**በመጀመሪያው ጉዳይ (ኢተረታራድቫንዳ)፦**
ዳቭንዋ የመጨረሻውን ክፍል ተዋህዶ ይይዛል እናም የዱዋል መጨረሻዎችን (ለሁለት ነገሮች) ወይም የብዙ ቁጥር መጨረሻዎችን (ለሁለት ከሚበልጡ ነገሮች)። የአንድ ቁጥር መጨረሻዎችም ተፈቅደዋል።

**በሁለተኛው ጉዳይ (ሳማሃራድቫንዳ)፦**
ዳቭንዋ በአጠቃላይ ኒውትረም (ጾታ ነፃ) ነው (የመጨረሻው ክፍል ጾታ ምንም ይሁን ምን) እና በአንድ ቁጥር ይቆማል።

**መፍታት፦**
በ"እና" (**ca** = ⟪च⟫) ይከናወናል፣ አንዳንዴ በ"ወይም" (**vā** = ⟪वा⟫) ወይም "እያንዳንዱ"።
:::
ስለ ዱዋል ዳቭንዋ ወደፊት ይመልከቱ!

### 5.3.1. የኮምፖዚታ ፊት ለፊት ክፍሎች

የኮምፖዚታ ፊት ለፊት ክፍሎች (ዳቭንዋ ብቻ አይደለም) በአጠቃላይ የማይቀየረውን **የስም ሥር** ቅርጽ አላቸው። የኮምፖዚታ ክፍሎች በ**የውাক्य ሳንዲ** ህጎች ይገናኛሉ (ማለትም፣ እስካሁን ያወቅነው ሳንዲ፣ ከቃሉ ሳንዲ ጋር በተቃራኒ፣ ይህም በቃሉ ውስጥ ለፎርማቲቭ ኤለመንቶች በፊት ይተገበራል)።

### 5.3.2. ብዙ ቁጥር ኢተረታራድቫንዳ

ለብዙ ቁጥር ዳቭንዳ ምሳሌዎች፦

**brāhmaṇa-kṣatriya-vaiśya-śūdrāḥ** = ⟪ब्राह्मणक्षत्रियवैश्यशूद्राः⟫
> = brāhmaṇāḥ kṣatriyā vaiśyāḥ śūdrāś ca = ⟪ब्राह्मणाः क्षत्रिया वैश्याः शूद्राश्च⟫
> (ብራህማኖች፣ ክሽትሪያስ፣ ቫይሽያስ እና ሹድራስ)
> 
> ወይም = brāhmaṇaḥ kṣatriyo vaiśyaḥ śūdraś ca = ⟪ब्राह्मणः क्षत्रियो वैश्यः शूद्रश्च⟫
> ((አንድ/የ) ብራህማነ፣ ክሽትሪያ፣ ቫይሽያ እና ሹድራ)

**kavi-guravaḥ** = ⟪कविगुरवः⟫
> = kavayo guravaś ca = ⟪कवयो गुरवश्च⟫
> (ግጥም ጸሐፊዎች እና ተማሪዎች [ብዙ ቁጥር])
> (ማስታወሻ፦ "አንድ ግጥም ጸሐፊ እና አንድ ተማሪ" በዱዋል መሆን አለበት!)

**ለድቭንድቫ ውስጥ ያሉት ቃላት ቅደም ተከተል የሚከተሉትን ህጎች ያከብራል፦**
የተለያዩ ምድቦችን (**varṇa**) ስም በሄይራርኪያቸው (ከፍተኛው በመጀመሪያ) መደርደር አለበት።
የጥንቱ እህት ስም ከእህቱ ስም በፊት መቀመጥ አለበት።
በአጠቃላይ ወሳኝ ቃል በመጀመሪያ መቀመጥ አለበት።
በ**-i** ወይም **-u** የሚጠናቀቁ ቃላት መቀድም አለባቸው።
በ**-a** የሚጠናቀቁ እና በቃላት የሚጀምሩ ቃላት መቀድም አለባቸው።
ያነሱ ሲላብስ ያላቸው ቃላት መቀድም አለባቸው።

ከሦስቱ በኋላ የተጠቀሱት ህጎች በአንድ ጊዜ ሊሰሩ ከቻሉ፣ ሁልጊዜ በኋላ የተሰጠው ህግ መከተል አለበት። (ለእነዚህ ህጎች የዱዋልድቭንድቫ ምሳሌዎች በኪልፎርን፣ ግራማቲክ § 570)።


## 5.4. የቃላት ዝርዝር

**የሚከተሉትን ቃላት ይማሩ፦**

**abhiniveṣa** m. = ⟪अभिनिवेष⟫ : ወደፊት ያለ ስሜት፣ ጽናት፣ መቆም፤ በተለይ፡ ከሰውነት ጋር ያለው ግንኙነት እንደ ራሱ ነው ብሎ መቆም።

**kāma** m. = ⟪काम⟫ : ፍላጎት፣ ፍቅር፣ የተፈለገ ስጦታ፣ የስሜት ፍቅር፣ ፍቅር።

::: media
![](/images/lekt0501.webp)
ስዕል፦ አምላክ ካማ = ካማደቫ = ⟪कामदेव⟫፣ 18ኛው ክፍለ ዘመን
(የስዕል ምንጭ፦ ዊኪፔዲያ፣ ህዝባዊ ክልል)
:::
**krodha** m. = ⟪क्रोध⟫ : ግርጭት።

**kleśa** m. = ⟪क्लेश⟫ : ስቃይ፣ ማህተም።

**trayī** f. = ⟪त्रयी⟫ : ሦስት ቁጥር፤ በተለይ ሦስቱ ቬድዎች (ግግቬዳ፣ ሳማቬዳ፣ ያጁርቬዳ)።

**daṇḍanīti** f. = ⟪दण्डनीति⟫ : ፖለቲካ (ከ daṇḍa m. = "ግንድ፣ ኃይል፣ ሥልጣን፣ ቅጣት" እና nīti f. = "ትክክለኛ መመሪያ" የተገኘ ታትፑሩሳ)።

**dvijāti** 3 / **dvija** 3 = ⟪द्विजाति⟫ / ⟪द्विज⟫ : ሁለት ጊዜ የተወለደ።

**dveṣa** ማ. = ⟪द्वेष⟫ : ስገን።

**maitrī** ለ. = ⟪मैत्री⟫ : ጸጋ፣ ጽጋዊነት፣ ጽጋዊ ምርጥ ልቦለድ።

**rāga** ማ. = ⟪राग⟫ : (ቀይ) ቀለም፣ ፍቅር፣ ፍቅር።

**lobha** ማ. = ⟪लोभ⟫ : ስገን፣ ስገን።

**varṇa** ማ. = ⟪वर्ण⟫ : ቀለም፣ ስርዓት፣ ስርዓት።

**vārttā** ለ. = ⟪वार्त्ता⟫ : ማግኘት፣ ኢኮኖሚ (ኢኮኖሚ)።

**vidyā** ለ. = ⟪विद्या⟫ : ጥበብ፣ ሳይንስ።

**avidyā** ለ. = ⟪अविद्या⟫ : ጥበብ፣ ጥበብ።

**ca** = ⟪च⟫ : እና።
(ከዚህ ቃል ጋር በተያያዘ በኋላ ይቀመጣል። ብዙ ቃላት ከተያያዙ በኋላ በመጨረሻው የማገናኛ ቃል ላይ በተሻለ ሁኔታ ይቀመጣል፡ brāhmaṇāḥ kṣatriyā vaiśyāḥ śūdrāś ca = ⟪ब्राह्मणाः क्षत्रिया वैश्याः शूद्राश्च⟫)።

**ca ... ca** = ⟪च⟫ ... ⟪च⟫ : ሁለቱም ... እናም።


## 5.5. ልምምድ

**ሀ) የሚከተሉትን ሐረጎች እና ኮምፖዚታዎች ወደ ሳንስክሪት ይተርጉሙ እና በውስጣቸው የሚገኙትን ዳንድቫስ ይፍቱ፡**

1. catvāro varṇā brāhmaṇakṣatriyavaiśyaśūdrāḥ።
(Āpastambīyadharmasūtra I,1,1,4 = Vāsiṣṭhadharmaśāstra II,1)
⟪चत्वारो वर्णा ब्राह्मणक्षत्रियवैश्यशूद्राः⟫ ||
(ማብራሪያ፡ catvāras = ⟪चत्वारस्⟫ = "አራት")

2. trayo varṇā dvijātayo brāhmaṇakṣatriyavaiśyāḥ።
(Vāsiṣṭhadharmaśāstra II,1)
⟪त्रयो वर्णा द्विजातयो ब्राह्मणक्षत्रियवैश्याः⟫ ||
(ማብራሪያ፡ trayas = ⟪त्रयस्⟫ = "ሶስት")

3. sāmavedargvedayajurvedās trayī።
(Kauṭilīya-arthaśāstra 1.3.1. / በጥሩ ሳንስክሪት፡ sāmārgyajurvedās trayī)
⟪सामवेदर्ग्वेदयजुर्वेदास्त्रयी⟫ ||
(በጥሩ ሳንስክሪት፡ ⟪सामार्यजुर्वेदास्त्रयी⟫)

4. የሰው ልጅ ሦስት ተጠላፎች፣ ወደ ገሃነም በር የሚሆኑት (Viṣṇusmṛti 33,1+6)፡
   kāmakrodhalobhāḥ
⟪कामक्रोधलोभाः⟫ ||

5. maitrīkaruṇāmuditopekṣāś catvāro brahmavihārāḥ.
⟪मैत्रीकरुणामुदितोपेक्षाश्चत्वारो ब्रह्मविहाराः⟫ ||
(ማብራሪያ: brahmavihāra: "የብራማ መኖሪያ ሁኔታዎች"፣ "ወሰን የለሽ" ተብሎም ይጠራሉ። እነሱ የቡድዲስት ማሥያት ዓይነቶች ናቸው።)

6. avidyāsmitārāgadveṣābhiniveṣāḥ pañca kleśāḥ.
(የዮጋ ስጡራ 2,3)
⟪अविद्यास्मितारागद्वेषाभिनिवेषाः पञ्च क्लेशाः⟫ ||
(ማብራሪያ: pañca = "አምስት")

7. ānvīkṣikītrayīvārttādaṇḍanitayo vidyāḥ.
(ከካውቴሊያ-አርታሻስትራ 1.2.1 በኋላ።)
⟪आन्वीक्षिकीत्रयीवार्त्तादण्डनितयो विद्याः⟫ ||
