# ትምህርት 34

## 34.1. ፍጹም ጊዜ (⟪लिट्⟫)

በክላሲካል ሳንስክሪት ከፍጹም ጊዜ ግንድ አመልካች እና ተካፋይ ብቻ ይገኛሉ።

::: grammar-box
**ሁለት አይነት የፍጹም ግሥ አፈጣጠር አሉ፡**
*   **የተደገመ ፍጹም ግሥ = ⟪द्वित्वलिट्⟫**
*   **ዙሪያ-ገለጻዊ ፍጹም ግሥ = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**ዙሪያ-ገለጻዊው ፍጹም ግሥ (⟪अनुप्रयोगलिट्⟫) ጥቅም ላይ ይውላል፡**
1. **ከተገኙት የግሥ እርባታዎች ጋር (አስደራጊ፣ ፈላጊ፣ ተደጋጋሚ፣ ስማዊ)**
2. **በረጅም አናባቢ (ከ ā- በስተቀር) በሚጀምሩ ሥሮች፣ ወይም ከሁለት ተነባቢዎች በፊት ባለ አናባቢ (ከ a- በስተቀር)**
3. **ከአንዳንድ ሌሎች ሥሮች ጋር**
:::
## 34.2. የተደገመ ፍጹም ግሥ (⟪द्वित्वलिट्⟫)

### 34.2.1. የግንድ ደረጃ አወራረድ

::: grammar-box
**አፈጣጠር፡**

**ጠንካራ ግንድ፡** ነጠላ Parasmaipada
*   **የተደገመ ከፍተኛ-ደረጃ ወይም የተለጠጠ-ደረጃ ሥር + የፍጹም ግሥ ቅጥያ**

**ደካማ ግንድ፦** ሁሉም የቀሩት ቅርጾች
*   **የተደገመ ዝቅተኛ ደረጃ ሥር + የፍጹም ጊዜ ቅጥያ**
:::
::: grammar-box
**በአጠቃላይ (ከፍጹም ጊዜ ውጭም ቢሆን) የሚከተለው ቅርጽ ያላቸው ሥሮች የግንድ ደረጃ ለውጥ የላቸውም፦**
*   **(ተነባቢ)-ተነባቢ-ረጅም አናባቢ-ተነባቢ**
*   **(ተነባቢ)-ተነባቢ-አናባቢ-ተነባቢ-ተነባቢ**

**በፍጹም ጊዜ በተጨማሪም የሚከተለው ቅርጽ ያላቸው ሥሮች የግንድ ደረጃ ለውጥ የላቸውም፦**
*   **a-ተነባቢ**
*   **ā-ተነባቢ**
:::
