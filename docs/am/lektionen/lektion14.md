# ትምህርት 14

## 14.1. የሁለት ስምዎችን ግንኙነት የሚገልጽ መግለጫ፡ የመታወቂያ (Genetiv) (ṣaṣṭhī f. = ⟪षष्टी⟫ = ስድስተኛው የመታወቂያ መጨረሻ)

::: grammar-box

ሁለት ስምዎችን የሚገልጹትን ግንኙነት ለመግለጽ የመታወቂያ (ṣaṣṭhī f. "ስድስተኛው የመታወቂያ መጨረሻ") ይጠቀማሉ። የመታወቂያ ከሌሎች ሁሉም የመታወቂያዎች የሚለየው በጥቂት ልዩ ሁኔታዎች ብቻ ሳይሆን በግፊት ለማሳየት የሚያገለግል ሳይሆን በስምዎች የሚገለጹ ሰዎች ወይም ነገሮች መካከል ያለውን ግንኙነት ለማሳየት ነው። ብዙ ጊዜ የመታወቂያ በጥያቄው ላይ ይቀመጣል፡ የማን?

:::

ምሳሌዎች፡

⟪कवेः पुत्रः⟫ "የግጥም ጸሐፊው ልጅ"

⟪धनस्य लोभः⟫ "የብዛት ማገድ"

⟪नगरस्यार्धम्⟫ "የከተማው ግማሽ"

⟪रामस्य कृतम्⟫ "የራማ ክፍለ ጊዜ"

::: grammar-box

መደበኛው የቃላት ቅደም ተከተል ነው፡

> **በመታወቂያ ውስጥ ያለው ቃል — በሌላ የመታወቂያ ውስጥ ያለው ስም**

:::

**የመታወቂያ እና PPP፡**

::: grammar-box

በPPPዎች ላይ የመታወቂያ ከመሳሪያ (tṛtīyā) ለአገልጋይ (kartṛ) ሊቀመጥ ይችላል፤ በመሳሪያ ግንኙነት ውስጥ PPP እንደ ማንኛውም የግፊት ቃል ይቆጠራል (በመሳሪያ ውስጥ ያለው አገልጋይን ያመለክታል)፣ በመታወቂያ ግንኙነት ውስጥ PPP እንደ ስም ወይም ተገቢነት ይቆጠራል (በመታወቂያ ውስጥ ያለው በእውነት እንደ አገልጋይ አይቆጠርም)።

በፓኒኒ 2.3.67 መሰረት በPPP ላይ የመታወቂያ ይቀመጣል፣ PPP የአሁን ጊዜ ትርጉም ካለው (እንደላይ ያስታውሱ)፣ መሳሪያ ካለው የPPP የድሮ ጊዜ ትርጉም ካለው፡

> ⟪रामस्येष्टं फलम्⟫ "የራማ ፍላጎት ያለበት ፍሬ = ራማ በአሁኑ ጊዜ የሚፈልገው ፍሬ"
> 
> ⟪रामेणेष्टं फलम्⟫ "ራማ የፈለገው ፍሬ"

በተፈጥሮ፣ በአንድ PPP ኒውተር ሲንጉላር፣ እንደ ቃላዊ አብስትራክተም - ማለትም እንደ ስም - ሲጠቀም፣ ጀኔቲቭ ይቆያል።

:::

ልብ ይበሉ፣ በድምፅ-መጨረሻ ስርዓቶች (consonant-ending stems) አብላጭ (Ablativ) እና ባለቤትነት (Genetiv) ነጠላ ቁጥር ከአካላዊ ብዙ ቁጥር ሁለቱም ልጅ እና ጓደኛ ጾታ ጋር ተመሳሳይ ናቸው!

:::

## 14.3. የባለቤትነት (⟪षष्ठी⟫) ተጠቃሚነት ስለሚቀጥል

::: grammar-box

ከላይ ከተጠቀሰው መሰረታዊ ህግ ጋር በተቃራኒ፣ ባለቤትነት (Genetiv) ለአንዳንድ ግስቶች ቁጥጥር (object) ለመግለጽ ያገለግላል፣ ለምሳሌ ለማስታወስ ግስቶች፡-

> ⟪देवानां स्मरति⟫ "የእጆችን ያስታውሳል"

ነገር ግን በእነዚህ ግስቶች ሁሉ ቁጥጥሩ በአካላዊ ቁጥር (Akkusativ) ሊቀመጥ ይችላል፡-

> ⟪देवान्स्मरति⟫ "የእጆችን ያስታውሳል"

ተጨማሪ በኋላ።

:::
