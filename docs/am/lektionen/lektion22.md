# ትምህርት 22

## 22.1. The Absolute (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

If one wants to express in Sanskrit that an action of the agent (⟪कर्तृ⟫) precedes another action of the agent or accompanies it as a circumstantial condition, one uses the absolute (⟪क्त्वा । ल्यप्⟫). Thus

"after he has done that, he does this"; "he does that, then he does this"; "as a result of this he does that"; "I came, saw, and conquered" etc.

The absolute is a verbal adverb, i.e., it is neither conjugable nor declinable, but it always has — with few exceptions — the same agent (⟪कर्तृ⟫) as the action that precedes or accompanies the action designated by the absolute. The agent of the absolute is therefore in the nominative (⟪प्रथमा⟫) or instrumental (⟪तृतीया⟫).

Besides compounds, the absolute is one of the most frequent means of expression in Sanskrit.

When translating into German, avoid constantly saying "after". Instead, use the common German expressions for temporal sequence.

**Schema:**

(further specification of the absolute: circumstantial specification, object, etc.) - absolute - absolute - ... - absolute - ... agent + verbal sentence (in active or passive)

:::
**Examples:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = passive construction: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**  
"The man enters the house, sees the little girl, and speaks to her."

Plural: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. የፍጹም ቃላት መፈጠር

::: grammar-box
**የፍጹም ቃላት መፈጠር**

*   ስም-ቅዳሜያል (Preverb) የሌላቸው ስም-ፍጥነት (Verb): በ **-tvā** የሚያልቅ ፍጹም ቃል
*   ስም-ቅዳሜያል (Preverb) ያላቸው ስም-ፍጥነት (Verb): በ **-ya** ወይም **-tya** የሚያልቅ ፍጹም ቃል
:::
### 22.2.1. ስም-ቅዳሜያል (Preverb) የሌላቸው ስም-ፍጥነት (Verb): በ -⟪त्वा⟫ የሚያልቅ ፍጹም ቃል

::: grammar-box

**መፈጠር:**

(በአብዛኛው) ከፍተኛ ደረጃ (Guna) የለውጥ ስም-መሠርት በ PPP (Past Participle) ቅድመ ሁኔታ ያለው መልክ + **-tvā** (**-⟪त्वा⟫**)

የሚያስተጋባው እና የማይያስተጋባው **a-** / **an-** ብቻ ነው ስለሆነም ከ **-⟪त्वा⟫** ጋር ይጣጣማል፡ ⟪अकृत्वा⟫ "ምንም ሳያደርግ"

:::
**ምሳሌዎች:**

::: indent
⟪आप्त्वा⟫ "ከተገኘ በኋላ / ከነበር"

⟪आसित्वा⟫ "ከቀመበ በኋላ / ነበር"

⟪इत्वा⟫ "ከሄደ በኋላ / ነበር"

⟪स्थित्वा⟫ "ከነበረ በኋላ / ነበር"

⟪जित्वा⟫ "ከተሸነፈ በኋላ / ነበር"

⟪उक्त्वा⟫ "ከገለጸ በኋላ / ነበር"
:::

⟪अन्नं पक्त्वा ब्राह्मणदासो ऽत्ति ॥१॥ इष्टदेवतापूजां कृत्वेन्द्रादिदेवान्सद्ब्राह्मणाः स्तुवन्ति ॥२॥ प्रस्थाय रामः सपुत्रः सद्गुरुश्रवणार्थेन ब्राह्मणग्रामं गच्छति ॥३॥ अनिष्ट्वा नरो भगवद्भक्तिमात्रेणापि मोक्षमाप्नोति ॥४॥ गृहगर्भं प्रविश्य ब्राह्मणपुत्रमुपस्थाय क्षत्रियशूरो वक्ति ॥५॥ सम्बुध्य दुःखाद्यार्यसत्यानि प्रोच्य सुगतो मोक्षमार्गेण नरान्नयति ॥६॥ मन्त्रं विस्मृत्य यजन्यज्ञदोषं करोति ॥७॥ धनं प्राप्य बुद्धमार्गभिक्षवो दुष्यन्ति ॥८॥ अनार्यशत्रुभिः संगत्य नरसिंहा विजयन्ते ॥९॥ पुण्यं कृत्वा सत्यमेवोदित्वा नरो नरकं नोपपद्यते ॥१०॥⟫
