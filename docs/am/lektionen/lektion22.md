# ምዕራፍ 22

## 22.1. አብሶሉቲቩም (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫)

::: grammar-box

በሳንስክሪት ቋንቋ የአድራጊው (⟪कर्तृ⟫) አንድ ድርጊት ከሌላው የአድራጊው ድርጊት በፊት እንደሚቀድም ወይም እንደ አጃቢ ሁኔታ አብሮ እንደሚሄድ ለመግለጽ አብሶሉቲቩም (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫) ጥቅም ላይ ይውላል። ማለትም

"ይህን ካደረገ በኋላ ያንን ያደርጋል"፤ "ይህን ያደርጋል፣ ከዚያም ያንን ያደርጋል"፤ "በዚህ ምክንያት ያንን ያደርጋል"፤ "መጣሁ፣ አየሁ፣ አሸነፍኩ" እና የመሳሰሉት።

አብሶሉቲቩም ግሳዊ-ተውሳከ-ግስ ነው፣ ማለትም አይረባም ወይም በየአገባቡ አይለወጥም፤ ነገር ግን ሁልጊዜ - ከጥቂት ልዩ ሁኔታዎች በስተቀር - በአብሶሉቲቩም የተገለጸው ድርጊት ከሚቀድመው ወይም ከሚያጅበው ድርጊት ጋር ተመሳሳይ የሆነ አድራጊ (⟪कर्तृ⟫) አለው። ስለዚህ የአብሶሉቲቩም አድራጊ በኖሚናቲቭ (⟪प्रथमा⟫) ወይም በኢንስትሩሜንታሊስ (⟪तृतीया⟫) መልክ ይገኛል።

ከውህድ ቃላት (Komposita) በተጨማሪ አብሶሉቲቩም በሳንስክሪት ቋንቋ ውስጥ በብዛት ጥቅም ላይ ከሚውሉ ገላጭ መንገዶች አንዱ ነው።

ወደ ጀርመንኛ ሲተረጉሙ፣ 'ከ... በኋላ' የሚለውን ቃል በተደጋጋሚ ከመጠቀም ይቆጠቡ። በምትኩ፣ በጀርመንኛ ለጊዜ ቅደም ተከተል የተለመዱትን አገላለጾች ይጠቀሙ።

**ንድፍ፡**

(ለፍጹም አንቀጽ ተጨማሪ መግለጫ፡ ሁኔታ ገላጭ፣ ተሳቢ ወዘተ) - ፍጹም አንቀጽ - ፍጹም አንቀጽ - ... - ፍጹም አንቀጽ - ... ባለቤት + ግሳዊ ሐረግ (በገቢር ወይም በተገብሮ)

:::
**ምሳሌዎች፡**

::: indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = ተገብሮአዊ አረፍተ ነገር: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**
"ሰውየው ወደ ቤቱ ገባ፣ ትንሿን ልጅ አየና አነጋገራት።"

ብዛት: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**
:::
## 22.2. የአብሶሉቲቩም ምስረታ

::: grammar-box
**የአብሶሉቲቩም ምስረታ**

*   ቅድመ-ቅጥያ የሌላቸው ግሶች: አብሶሉቲቩም በ **-tvā**
*   ቅድመ-ቅጥያ ያላቸው ግሶች: አብሶሉቲቩም በ **-ya** ወይም **-tya**
:::
### 22.2.1. ቅድመ-ቅጥያ የሌላቸው ግሶች: አብሶሉቲቩም በ -⟪त्वा⟫

::: grammar-box

**አፈጣጠር፡**

(በአብዛኛው) ከPPP በፊት ባለው ቅርጽ ዝቅተኛ ደረጃ ያለው ሥር + **-tvā** (**-⟪त्वा⟫**)

አፍራሽ የሆኑት **a-** / **an-** ብቻ ከ **-⟪त्वा⟫** ቅጥያ ጋር ይስማማሉ፡ ⟪अकृत्वा⟫ "ሳያደርጉ"

:::
**ምሳሌዎች፡**

::: indent
⟪आप्त्वा⟫ "እሱ / እሷ / እሱ / እኔ / አንተ / እኛ / እናንተ / እነሱ / ሁለታችን / ሁለታችሁ / ሁለቱም ከደረሰ/ች/ኩ/ህ/ን/ችሁ/ሱ በኋላ"

⟪आसित्वा⟫ "እሱ (...) ከተቀመጠ በኋላ"

⟪इत्वा⟫ "እሱ (...) ከሄደ በኋላ"

⟪स्थित्वा⟫ "እሱ (...) ከቆመ በኋላ"

⟪जित्वा⟫ "እሱ (...) ካሸነፈ በኋላ"

⟪उक्त्वा⟫ "እሱ (...) ከተናገረ በኋላ"
:::
### 22.2.2. ቅድመ-ግስ ያላቸው ግሶች

#### 22.2.2.1. ሥሮች በረጅም አናባቢ (ከ-ā በስተቀር) ወይም በተነባቢ የሚጨርሱ

::: grammar-box

**(በአብዛኛው) ዝቅተኛ ደረጃ ሥር + -ya**

:::
**ምሳሌዎች፦**

::: indent
⟪उपनीय⟫ "«(...) ካቀረበ በኋላ»"

⟪प्रभूय⟫ "«(...) ከበለጠ በኋላ» «(...) ኃይል ከነበረው በኋላ»"

⟪प्राप्य⟫ "እሱ (...) ካገኘ በኋላ"
:::
#### 22.2.2.2. በ -ā የሚያልቁ ሥሮች

::: grammar-box

**ያልተለወጠ ከፍተኛ ደረጃ ሥር + -ya**

:::
**ምሳሌ:**

::: indent
⟪उपस्थाय⟫ "እሱ (...) ከቀረበ በኋላ"፤ (ነገር ግን ያለ ቅድመ-ግስ፡ ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. በዝቅተኛ ደረጃ በአጭር -i, -u, -ṛ የሚጨርሱ ሥሮች

::: grammar-box

**ደካማ ሥር + -tya**

:::
**ምሳሌዎች፡**

::: indent
⟪प्रस्तुत्य⟫ "እሱ (...) በታላቅ ድምፅ ካወደሰ በኋላ"

⟪विस्मृत्य⟫ "እሱ (...) ከረሳ በኋላ"

⟪संस्कृत्य⟫ "እርሱ (...) ለመስዋዕት ካዘጋጀ በኋላ / አዘጋጅቶ ከነበረ በኋላ"
:::
#### 22.2.2.4. በ -am / -an ላይ ያሉ ሥሮች፣ በዝቅተኛ ደረጃ በ -a የሚያልቁ

::: grammar-box

**አማራጭ፦**

በ **-am** / **-an** የሚያልቅ ሥር + **-ya**

:::

**⟪व्रत⟫ ገ. ፆታ፦** ስዕለት፣ ሃይማኖታዊ ግዴታ፣ ሃይማኖታዊ ሥርዓት (አንድ ሰው ከአምላክ አንድ ነገር ለማግኘት ቃል ይገባል። ምሳሌ፦ አንዲት እናት ልጇ ከዳነች እንደ ቤተ መቅደስ ዝሙት አዳሪ (⟪देवदासी⟫) አድርጋ እንደምትሰጣት ቃል ትገባለች። በዛሬው ጊዜ ጠቃሚ ⟪व्रत⟫፦ ጾም፤ ከሚወዷቸው ምግቦች መታቀብ፤ ከጾታዊ ግንኙነት መታቀብ፤ ቅዱሳት መጻሕፍትን ማንበብ፤ የተወሰኑ ሥርዓቶችን መፈጸም፤ ብራህማኖችን መመገብ እና የመሳሰሉት። ስለ ⟪व्रत⟫ በአጭሩ፦ Walker, Hindu World Bd. II, S. 581f. በዝርዝር፦ P. V. Kane: History of Dharmaśāstra Bd. 5,1 S. 1 - 462. በዚያ ገጽ 253 - 462 ላይ የ⟪व्रत⟫ እና የሃይማኖታዊ በዓላት ዝርዝር ("የሚከተለው ዝርዝር ... ሙሉ በሙሉ የተሟላ ነው የሚል መከራከሪያ የለውም" !!!)

**⟪चर्⟫ 1 P charati Pass. charyate PPP charita Inf. charitum (Sanskrit: ⟪चर्⟫ 1 P ⟪चरति⟫ Pass. ⟪चर्यते⟫ PPP ⟪चरित⟫ Inf. ⟪चरितुम्⟫) :** መጋጥ፣ መዞር፣ መንቀሳቀስ፣ መንቀሳቀስ፣ መሥራት፣ አንድን ነገር መፈጸም፣ ማከናወን (ለምሳሌ **⟪व्रतं⟫ ⟪चर्⟫**: ስእለትን መፈጸም፣ በተለይም ከጾታዊ ግንኙነት መታቀብ)
