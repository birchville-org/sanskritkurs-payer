# ትምህርት 54

## 54.1. መግቢያ

በ54ኛው ክፍል ዩኒቨርሲቲ ትምህርት ሁለተኛውን ክፍል ያስጀምራል። ከዚያን በኋላ ስርዓተ ተምሳሌቱ ከዚህ ምዕራፉ ዋና ጭብጥ በተለየ መልኩ ይሰራል፡ የባግቫድ ጊታን ሙሉ ቃል መፅሐፍ ንባብ ማለት ነው። የተማሪዎች ዓላማ አንድ መካከለኛ ጥቅም ያለውን ቃል በፈጣነት ማንበብ ነው። በመጨረሻ ሦስተኛ ክፍል ውስጥ ባግቫድ ጊታን ከላይኛው ቃል በመጀመሪያ ምዕራፎች ይተርጉማል። በመጀመሪያ ምዕራፎች ውስጥ ቃል መዝገቦች ሰጡ፣ በኋላ ተማሪዎች ራሳቸው ቃል መፅሐፎችን (Monier-Williams, Apte, PW) መጠቀም አለባቸው።

በትምህርት 54 በዩኒቨርሲቲ ትምህርት ሁለተኛው ሴሚስተር ይጀምራል።

የሳንስክሪት ትምህርት ክፍሎች እስካሁን ያልተሸፈኑ የሳንስክሪት ሰዋስው ርዕሶችን ይዳስሳሉ።

## 54.2. የቃል ምስረታ፡ ⟪कृत्⟫-ቅጥያ -u ከፍላጎት ግንዶች ጋር

## 54.5. የአኦሪስት (Aorist) ምስረታ አይነቶች (⟪लुङ्⟫)

::: grammar-box
**ለሁሉም የአኦሪስት (⟪लुङ्⟫) ምስረታ አይነቶች የጋራ የሆነው ነገር a- የሚለው ቅጥያ (augment) ሲሆን፣ ይህም ልክ እንደ ኢምፐርፌክት (⟪लङ्⟫) በተመሳሳይ ህጎች መሰረት ይቀመጣል።**

በሳንስክሪት ውስጥ ከአኦሪስት ውስጥ አመልካች እና ፕሬካቲቭ ብቻ ናቸው ጥቅም ላይ የሚውሉት።
:::
::: grammar-box
**የአኦሪስት (⟪लुङ्⟫) የሚከተሉት የአፈጣጠር አይነቶች አሉ፡**

1.  ሲቢላንት ያልሆኑ (አሲግማቲክ) አኦሪስቶች፡
    *   ሥር አኦሪስት፡ አውግመንት + ሥር + ሁለተኛ ደረጃ ቅጥያ
    *   ጭብጥ አናባቢ አኦሪስት፡ አውግመንት + ሥር + **a** + ሁለተኛ ደረጃ ቅጥያ
    *   የተደገመ አኦሪስት፡ አውግመንት + **የተደገመ** ሥር + **a** + ሁለተኛ ደረጃ ቅጥያ
2.  ሲቢላንት (ሲግማቲክ) አኦሪስቶች፡ s ወይም s (ṣ) የያዘ ክፍለ ቃል ከግላዊ ቅጥያ በፊት ይመጣል
    *   -s-አኦሪስት፡ አውግመንት + ሥር + **s** \+ ሁለተኛ ደረጃ ቅጥያ
    *   -iṣ-አኦሪስት፡ አውግመንት + ሥር + **i** + **ṣ** + ሁለተኛ ደረጃ ቅጥያ
    *   -siṣ-አኦሪስት፡ አውግመንት + ሥር + **siṣ** + ሁለተኛ ደረጃ ቅጥያ
    *   -sa-አኦሪስት፡ አውግመንት + ሥር + **s** + **a** + ሁለተኛ ደረጃ ቅጥያ

የሥሮቹ ስርጭት በተለያዩ የአፈጣጠር አይነቶች ላይ በእያንዳንዱ አይነት ስር ይመልከቱ
:::
