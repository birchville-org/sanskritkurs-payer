# ትምህርት 54

## 54.1. ቅድመ-ማስታወቂያ

በትምህርት 54 ዩኒቨርሲቲ ትምህርት ውስጥ ሁለተኛው ሴሚስተር ይጀምራል። ከዚህ በኋላ ኮርሱ በዋናው የዚህ ሴሚስተር ርዕሰ ጉዳይ ጎን ለጎን ብቻ ይከናወናል፡ የባግቫድጊታ ሙሉ ጽሑፍን ማንበብ። የመማሪያ ዒላማ አማካይ-ከከባድ የሆነ ጽሑፍን በማንበብ ረገድ እንዲህ ዓይነት ብቃት ማግኘት ሲሆን፣ በሴሚስተሩ የመጨረሻው ሶስተኛ ክፍል ውስጥ የባግቫድጊታ ትልልቅ ክፍሎች ከቦታው ተገንዝበው ሊተረጎሙ ይችላሉ። በመጀመሪያው ደረጃ በዩኒቨርሲቲ ትምህርት ውስጥ የቃላት ዝርዝሮች ይሰጡ ነበር፣ በኋላ ተማሪዎች ባለቤት-ዊልያምስ፣ አፕቴ፣ PW (PW) የመሳሰሉ ቃላት መዝገበ ቃላትን ራሳቸው መጠቀም አለባቸው።

የባግቫድጊታ ኮርስ ጊዜያዊ ለመስመር ላይ አይገኝም።

የሳንስክሪት ኮርስ ትምህርቶች እስካሁን ያልተካተቱ የሳንስክሪት ስነ-ጽሑፍ ርዕሰ ጉዳዮችን ያካትታሉ።

## 54.5. የአዎሪስት (⟪लुङ्⟫) የመፍጠር ዓይነቶች

::: grammar-box
**ለሁሉም የአዎሪስት (⟪लुङ्⟫) የመፍጠር ዓይነቶች የሚጋራው ነገር ኦግመንት a- ሲሆን፣ ይህም በተመሳሳይ ህግ እንደ ኢምፔርፌክት (⟪लङ्⟫) ይገባል።**

ከአዎሪስት በሳንስክሪት ውስጥ ኢንዲኬቲቭ እና ፕሬኬቲቭ ብቻ ናቸው የሚጠቀሙት።
:::
::: grammar-box
**የሚከተሉት የአዎሪስት (⟪लुङ्⟫) የመፍጠር ዓይነቶች አሉ፡**

1.  ኖን-ሲቢላንቲክ (አሲጋማቲክ) አዎሪስቶች፡
*   54.1. የመሰረት አዎሪስት፡ ኦግመንት + መሰረት + ሰኩንደሪ ማጠናቀቂያ
*   54.2. ቲማ-ቫኮሊክ አዎሪስት፡ ኦግመንት + መሰረት + **a** + ሰኩንደሪ ማጠናቀቂያ
*   54.3. ሬዱፕሊኬትድ አዎሪስት፡ ኦግመንት + **የተደጋገመ** መሰረት + **a** + ሰኩንደሪ ማጠናቀቂያ
2.  ሲቢላንቲክ (ሲጋማቲክ አዎሪስቶች፡ s ወይም s (ṣ) የያዘ ሲሊብ ለግላዊ ማጠናቀቂያው በፊት ይቀመጣል
*   54.4. -s-አዎሪስት፡ ኦግመንት + መሰረት + **s** \+ ሰኩንደሪ ማጠናቀቂያ
*   54.5. -iṣ-አዎሪስት፡ ኦግመንት + መሰረት + **i** + **ṣ** + ሰኩንደሪ ማጠናቀቂያ
*   54.6. -siṣ-አዎሪስት፡ ኦግመንት + መሰረት + **siṣ** + ሰኩንደሪ ማጠናቀቂያ
*   54.7. -sa-አዎሪስት፡ ኦግመንት + መሰረት + **s** + **a** + ሰኩንደሪ ማጠናቀቂያ

ስርዓተ-ክፍፍል ሥሮች በተለያዩ የመገንባት ዓይነቶች ላይ ለማየት እያንዳንዱን ዓይነት ይመልከቱ
:::

የሥር አዎርስት ልዩ ቅርጽ የ3.ነጠላ ተላላኪ ልዩነት አዎርስት ነው። ይህ ከሁሉም ሥሮች ሊገነባ ይችላል።

::: grammar-box
**መገንባት:**

**ኦግመንት + ሥር + i**

**ሥሩ የሚከተለውን ቅርጽ አለው፡-**

ከፍተኛ ደረጃ፡-

*   አጭር ምላሽ (a በስተቀር) ከቀላል ቃላት በፊት ያሉ ሥሮች እንዲሁም ⟪जन्⟫ እና አብዛኛዎቹ በ-am የሚጠናቀቁ ሥሮች  
ምሳሌዎች፡  
⟪भिद्⟫ 7U፡ ⟪अभेदि⟫ "ተሰባብሯል"  
⟪तुद्⟫ 6U፡ ⟪अतोदि⟫ "ተገፋ ነበር"

የዲኒ ምድብ፡

*   በመጨረሻ ቃላት ላይ የሚገኙ ቃላት  
ምሳሌዎች፡  
⟪नी⟫ 1U: ⟪अनायि⟫ "እንደተሳለ"  
⟪स्तु⟫ 2U: ⟪अस्तावि⟫ "እንደተመሰገነ"  
⟪कृ⟫ 8U: ⟪अकारि⟫ "እንደተሰራ"  


*   በቀላል ገጽታ ላይ የሚገኙ ቃላት (በ⟪जन्⟫ እና በ-am መጨረሻ ላይ የሚገኙ ቃላት ውጪ)  
ምሳሌ፡  
⟪वद्⟫ 1P: ⟪अवादि⟫ "እንደተገለጸ"  
ነገር ግን፡  
⟪जन्⟫ 4Ā: ⟪अजनि⟫ "እንደተወለደ"  


*   ጥቂት ቃላት በ-am መጨረሻ ላይ  
ምሳሌ፡  
⟪गम् अगामि⟫


በመጨረሻ ቃላት ላይ የሚገኙ ቃላት፡

*   በ-am, -e, -ai, -o መጨረሻ ላይ የሚገኙ ቃላት በ-am መጨረሻ ላይ የሚገኙ ቃላት እና በ-am መጨረሻ ላይ የሚገኙ ቃላት ውስጥ y ይጨምራሉ፡  
ምሳሌ፡  
⟪दा⟫ 3U: ⟪अदायि⟫ "እንደተሰጠ"


የናስ ክፍል፡
