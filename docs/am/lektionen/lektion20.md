# ትምህርት 20

## 20.1. ባለቤትነት ኮምፖዚታ = ⟪बहुव्रीहि⟫ m.

::: media
![](/images/lekt2004.webp)
ስዕል፡ ⟪बहुव्रीहिः पुरुषः⟫
ጆድፑር = ⟪जोधपुर⟫
(ምስል ምንጭ፡ [ዝርዝር](/am/licenses#lekt2004))
:::
⟪बहुव्रीहिः⟫ = ⟪बहवो व्रीहयो यस्य सः⟫ = "ብዙ ሩዝ ያለው ሰው"

::: grammar-box

**አንድ ባሁቭሪሂ (Bahuvrīhi) ከታትፑሩሻ (Tatpuruṣa) ጋር ሲነፃፀር ከክፍሎቹ የሚገለጸውን ነገር ሳይሆን ሌላ ነገር ያመለክታል፡ ምንም እንኳን ⟪बालपुत्रः⟫ እንደ ታትፑሩሻ ሲፈታ "ወጣት ልጅ" ቢልም፣ ይህም በኮምፖዚቱ መጨረሻ ክፍል (⟪पुत्र⟫) የሚገለጽ ነገር ከሆነ፣ ⟪बालपुत्रः⟫ እንደ ባሁቭሪሂ ሲፈታ "ልጁ ወጣት የሆነው ሰው" ይሆናል፣ ማለትም የሚጠቀሰው ነገር ልጁ (⟪पुत्र⟫)ም ሆነ ለግድ ወጣት (⟪बाल⟫) አይደለም፣ ነገር ግን ከወጣት ልጁ የተለየ ሰው ማለትም አባቱ ነው።**

**ባለቤትነት ኮምፖዚታ በመጀመሪያ ሁልጊዜ አዲጀክቲቭ ናቸው፣ ነገር ግን ስም (substantivized) ሊሆኑ ይችላሉ። ስለዚህ የአንድ ባሁቭሪሂ ግራማቲካዊ ስላንት (gender) የሚወሰነው በባሁቭሪሁ የሚያመለክተው ነገር ላይ ነው፣ እንጂ በመጨረሻው የኮምፖዚሽን ክፍል ስላንት ላይ አይደለም።**

:::
::: grammar-box

**የባሁቭሪሂ ፍቺ ስኬማ፡**

**1. የመጀመሪያ ክፍል በተለምዶ በኖሚናቲቭ (⟪प्रथमा⟫) ነጠላ፣ ዱዋል ወይም ብዙ -- 2. ክፍል በኖሚናቲቭ ነጠላ፣ ዱዋል ወይም ብዙ -- ሪሌቲቭ ፕሮኒን በኖሚናቲቭ ያልሆነ ኬሱስ (በተለምዶ ጄኔቲቭ - ⟪षष्ठी⟫) እና በጠቅላላው ባሁቭሪሂ ስላንት እና ቁጥር -- ዲሞንስትሬቲቭ ፕሮኒን በጠቅላላው ባሁቭሪሂ ቁጥር፣ ኬሱስ እና ስላንት።**

:::
ምሳሌዎች፡


::: indent

አክ. ነጠላ ⟪गतपापम्⟫ = ⟪गतं पापं यस्य तम्⟫

ጄን. ነጠላ ⟪गतपापस्य⟫ = ⟪गतं पापं यस्य तस्य⟫

ኖም. ብዙ ⟪गतपापाः⟫ = ⟪गतानि पापानि⟫ ye⟪षां ते⟫

⟪पुण्यवत्पुत्रः⟫ እንደ ባሁቭሪሂ = ⟪पुण्यवान्पुत्रो यस्य सः⟫፣ ወይም፡ ⟪पुण्यवन्तः पुत्रा यस्य सः⟫ = "ልጁ ምስጋና የሚኖረው" ወይም፡ "ልጆቹ ምስጋና የሚኖራቸው"

## 20.2. ባሁቭሪሂ በተገዢ የፊት ክፍል ጋር

::: grammar-box

**ስኬማ፡**

:::
::: indent
**አዲጀክቲቭ -- ኖመን**
:::
**ምሳሌ፡**

::: indent
⟪गुणवत्पुत्रो ब्राह्मणः⟫ =  ⟪गुणवान्पुत्रो यस्य स ब्राह्मणः⟫ = "ልጁ / ልጆቹ ጥሩ ባህሪ ያለው / ያላቸው ብራህማን"
:::
**በተለይም በታትፑሩሻ ውስጥ አስቀድሞ የሚገኝ ያልሆነው -- በተገዢ ማብራሪያ በ PPP (Past Participle) ሊሰጥ ይችላል። በዚህ ጊዜ የተወሳሰበው ቃል ብዙውን ጊዜ በኢንስትሩመንታሊስ (⟪तृतीया⟫) (በጣም አልፎ አልፎ በጄኔቲቭ / ⟪षष्ठी⟫) ውስጥ ይገኛል።**

**መሰረታዊ ህግ:**

*   **PPP - ስም = ብዙ ጊዜ ባሁቪሪሂ**
*   **ስም -- PPP = ብዙ ጊዜ ታትፑሩሳ**

**ምሳሌ:**

::: indent
⟪कृतफल ३⟫ = ⟪कृतं फलं⟫ ye⟪न सः । यया सा ।⟫ ye⟪न तत्⟫ = "አንድ / አንድ / አንድ፣ ውጤት ያመነጨው፣ ማንኛውም ሰው / ማንኛውም ነገር ውጤታማ"

## 20.6. የባሁቭሪሂ የመጨረሻ ክፍል ቅጽ

::: grammar-box

**የባሁቭሪሂ የመጨረሻ ክፍል ከመጀመሪያ ጾታው ገለልተኛ በመሆን እንደ ብዙ-ጾታ አመልካች ይቅጻል። ስለዚህ በአንድ ውስብስብ ቃል ውስጥ የመጨረሻው ክፍል ከመጀመሪያ ጾታው ሌላ ከሆነ፣ ሳማሃራድቫንቫ (ንጹህ ቁጥር 1) ካልሆነ ባሁቭሪሂ መሆን አለበት።**

**በአመልካችነት ሲቀየሩ**

*   **-ā-መሰረቶች በወንድ እና በንጹህ ጾታ ወደ -a-መሰረቶች ይቀየራሉ**
*   **-a-መሰረቶች (ወንድ፣ ንጹህ) ሴታዊ ጾታቸውን በ-ā ወይም በ-ī ይፈጥራሉ**
*   **-ī-መሰረቶች (ሴታዊ) በባሁቭሪሂ መጨረሻ ላይ ቅጽ -ka፣ -kā፣ -ka (ንጹህ) መቀበል አለባቸው፤ ይህ ቅጽ ብዙ ሌሎች ባሁቭሪሂዎችም መቀበል ወይም መቀበል አለባቸው**

:::
## 20.7. የባሁቭሪሂዎች ዓይነቶች ሌላ ክፍፍል

ምሳሌዎች እዚህ ለኋላ ላይ ለማጥናት ተሰጥተዋል፣ ለአንዳንዶቹ ከፍተኛ ግራመር እና ቃላት አሁንም አልተወያዩም

1.  ማስተካከያ ቃል በፊት ክፍል -- የተረጋገጠ ቃል በኋላ ክፍል፡ ⟪स्थिरचित्तः⟫ = ⟪स्थिरं चित्तं यस्य सः⟫
2.  በፊት ክፍል ውስጥ ያልሚቀየሩ ቃላት፡ ⟪उच्चैःश्रवस्⟫
3.  ማነፃፀር በፊት ክፍል፡ ⟪कुशाग्रधीः⟫ =  ⟪कुशाग्र इव धीर्यस्य सः⟫
4.  ቀዶ ጥገና ማነፃፀር፡ ⟪उष्ट्रमुखः⟫ = ⟪उष्ट्रस्य मुखमिव मुखं यस्य सः⟫ = "የቱላማ ገንዘብ" = የገንዘቡ እንደ የቱላማ ገንዘብ ነው
5.  ቁጥር በኋላ ክፍል ላይ ለግምታዊ ቁጥር፡ ⟪उपसशाः⟫ = ⟪दशानां समीपे ये सन्ति ते⟫ = "ግምታዊ ዐሥር"
6.  ሁለቱም ክፍሎች ቁጥሮች ናቸው፡ ⟪एकद्वाः⟫ = ⟪एको वा द्वौ वा⟫ = "አንድ ወይም ሁለት"
7.  ስa-/saha- በፊት ክፍል፡ ⟪सपुत्रः । सहपुत्रः⟫
8.  ስa- (= ⟪समान⟫) በፊት ክፍል፡ ⟪सजनपदः⟫ = ⟪समानो जनपदो यस्य सः⟫
9.  ⟪नञ्बहुव्रीहिः⟫ = በፊት ክፍል ውስጥ a-/an- ጋር፡ ⟪अपुत्रः⟫ = ⟪न विद्यते पुत्रो यस्य सः⟫ ; ⟪अनङ्गः⟫ = ⟪न विद्यते अङ्गं यस्य सः⟫
10.  በፊት ክፍል ውስጥ በመስመር እና ሌሎች ጋር፡ ⟪प्रवातः⟫ =⟪प्रकृष्टो वातो यस्मिन् सः⟫ ; ⟪निर्धनः⟫ = ⟪निर्गतं धनं यस्मात्सः⟫ ; ⟪सुबुद्धिः⟫ = ⟪सुष्ठु बुद्धिर्यस्य सः⟫ ; ⟪दुर्बुद्धिः⟫ = ⟪दुष्टा बुद्धिर्यस्य सः⟫
11.  አቅጣጫ ማመልከቻዎች መካከለኛ አቅጣጫዎችን ለማመልከት፡ ⟪पुर्वोत्तरा⟫ "ሰሜን-ምሥራቅ"

## 20.8. የባሁቭሪሂ እና የቃላት ግንኙነት
