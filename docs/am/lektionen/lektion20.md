# ትምህርት 20

## 20.1. የባለቤትነት ቅጽል ቃላት = ⟪बहुव्रीहि⟫ m.

::: media
![](/images/lekt2004.webp)
ምስል፡ ⟪बहुव्रीहिः⟫ ⟪पुरुषः⟫
Jodhpur = ⟪जोधपुर⟫
(የምስል ምንጭ: [ዝርዝሮች](/licenses#lekt2004))
:::
⟪बहुव्रीहिः⟫ = ⟪बहवो⟫ ⟪व्रीहयो⟫ ⟪यस्य⟫ ⟪सः⟫ = "ብዙ ሩዝ ያለው ሰው"

::: grammar-box

**ባሁቭሪሂ ከታትፑሩሻ በተለየ መልኩ፣ በአባላቱ ከሚገለጸው ነገር የተለየ ነገርን ያመለክታል፤ ለምሳሌ ⟪बालपुत्रः⟫ እንደ ታትፑሩሻ ሲፈታ "ወጣት ልጅ" ማለት ሲሆን፣ ይህም በቅንጅቱ የመጨረሻ ክፍል (⟪पुत्र⟫) የሚገለጽ ነገር ነው፤ ⟪बालपुत्रः⟫ ደግሞ እንደ ባሁቭሪሂ ሲፈታ "ልጁ ወጣት የሆነ ሰው" ማለት ነው፤ ይህም ማለት የሚገለጸው ነገር ልጁም (⟪पुत्र⟫) አይደለም የግድም ወጣት (⟪बाल⟫) አይደለም፣ ነገር ግን ከወጣቱ ልጅ የተለየ ሰው ነው፣ ይኸውም አባቱ ነው።**

**የባለቤትነት ቅንጅቶች መጀመሪያ ላይ ሁልጊዜ ቅጽሎች ናቸው፣ ሆኖም ግን ወደ ስምነት ሊለወጡ ይችላሉ። ስለዚህ የባሁቭሪሂ ሰዋሰዋዊ ጾታ የሚወሰነው ባሁቭሪሂው በሚያመለክተው ነገር ላይ ነው እንጂ በቅንጅቱ የመጨረሻ ክፍል ጾታ ላይ አይደለም።**

:::
::: grammar-box

**የባሁቭሪሂን አፈታት ሥርዓት፡**

**1ኛ ክፍል አብዛኛውን ጊዜ በስም መደብ (⟪प्रथमा⟫) በነጠላ፣ በሁለት ወይም በብዙ ቁጥር -- 2ኛ ክፍል በስም መደብ በነጠላ፣ በሁለት ወይም በብዙ ቁጥር -- አንጻራዊ ተውላጠ ስም ከስም መደብ ውጪ በሌላ መደብ (አብዛኛውን ጊዜ በባለቤትነት መደብ - ⟪षष्ठी⟫) እና በጠቅላላው የባሁቭሪሂ ጾታና ቁጥር -- አመልካች ተውላጠ ስም በጠቅላላው የባሁቭሪሂ ቁጥር፣ መደብ እና ጾታ።**

:::
ምሳሌዎች፡

::: indent
⟪गतपापः⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪सः⟫ = "ክፋቱ የሄደለት ሰው" = "ከክፉ ሥራ ነፃ የሆነ ሰው"

አኩዛቲቭ ነጠላ ⟪गतपापम्⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तम्⟫

ኢንስትሩመንታል ነጠላ ⟪गतपापेन⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तेन⟫

ጄኔቲቭ ነጠላ ⟪गतपापस्य⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तस्य⟫

ኖሚናቲቭ ብዙ ⟪गतपापाः⟫ = ⟪गतानि⟫ ⟪पापानि⟫ ye⟪षां⟫ ⟪ते⟫

ወዘተ.

⟪अस्तमोहा⟫ = ⟪अस्तो⟫ ⟪मोहो⟫ ⟪यया⟫ ⟪सा⟫ = "ድንቁርናን የጣለች (ሴት)"

⟪प्राप्तोदको⟫ ⟪ग्रामः⟫ = ⟪प्राप्तमुदकं⟫ ⟪यं⟫ s ⟪ग्रामः⟫ = "ውሃ የደረሰበት መንደር" = "በጎርፍ አደጋ የተጋለጠ መንደር"

⟪पुण्यवत्पुत्रः⟫ እንደ Bahuvrīhi = ⟪पुण्यवान्पुत्रो⟫ ⟪यस्य⟫ ⟪सः⟫, ወይም፡ ⟪पुण्यवन्तः⟫ ⟪पुत्रा⟫ ⟪यस्य⟫ ⟪सः⟫ = "ልጁ መልካም ሥራ ያለው" ወይም፡ "ልጆቹ መልካም ሥራ ያላቸው"
:::
::: grammar-box

**በአንድ ባሁቭሪሂ ውስጥ የቀዳሚው ክፍል እና የኋለኛው ክፍል ግንኙነት እንዲህ ሊሆን ይችላል፦**

*   **ቅጽላዊ**
*   **አፖዚሽናል**
*   **በአገባብ ላይ የተመሰረተ**
*   **ተውሳከ ግሳዊ**

**እንደ ታትፑሩሻ ሁሉ፣ በይበልጥ የሚብራራው ክፍል አብዛኛውን ጊዜ በሁለተኛ ደረጃ ላይ ይገኛል።**

:::
በባህላዊ መንገድ እንደሚከተለው ይለያል፦

*   ⟪समानाधिकरणबहुव्रीहिः⟫ : በ ⟪विग्रहवाक्य⟫ ውስጥ የመጀመሪያው ክፍል እና የኋለኛው ክፍል በተመሳሳይ መደብ ውስጥ ይገኛሉ

*   ⟪व्यधिकरणबहुव्रीहिः⟫ : በ ⟪विग्रहवाक्य⟫ ውስጥ የመጀመሪያው ክፍል እና የኋለኛው ክፍል በተለያዩ መደቦች ውስጥ ይገኛሉ

## 20.2. ባሁቭሪሂ ከቅጽላዊ የመጀመሪያ ክፍል ጋር

::: grammar-box

**መርሐግብር፡**

:::
::: indent
**ቅጽል -- ስም**
:::
**ምሳሌ፡**

::: indent
⟪गुणवत्पुत्रो⟫ ⟪ब्राह्मणः⟫ = ⟪गुणवान्पुत्रो⟫ ⟪यस्य⟫ ⟪स⟫ ⟪ब्राह्मणः⟫ = "ልጁ / ልጆቹ መልካም ባሕርያት ያሉት / ያላቸው ብራህማና"
:::
**በPPP የሚደረግ የባሕርይ ገለጻ -- በታትፑሩሻ ውህድ ውስጥ ብዙም የማይታይ -- በተለይ የተለመደ ነው። ውህዱ ሲተነተን አንጻራዊ ተውላጠ ስሙ በአብዛኛው በኢንስትሩመንታል (⟪तृतीया⟫) (አልፎ አልፎ ደግሞ በጌኔቲቭ / ⟪षष्ठी⟫) መደብ ላይ ይገኛል።**

**የአውራ ጣት ደንብ፡**

*   **PPP - ስም = በአብዛኛው Bahuvrīhi**
*   **ስም -- PPP = በአብዛኛው Tatpuruṣa**

**ምሳሌ፦**

::: indent
⟪कृतफल⟫ ⟪३⟫ = ⟪कृतं⟫ ⟪फलं⟫ ye⟪न⟫ ⟪सः⟫ ⟪।⟫ ⟪यया⟫ ⟪सा⟫ ⟪।⟫ ye⟪न⟫ ⟪तत्⟫ = "ውጤትን ያስገኘ፤ ውጤታማ የሆነ ሰው ወይም ነገር"
:::
## 20.3. አፖዚሽናል የፊት ክፍል ያለው Bahuvrīhi

::: grammar-box

**መርሐግብር፡**

:::
::: indent
**ስም -- ስም**
:::
**ምሳሌዎች፡**

::: indent
⟪शूरपुत्रो⟫ ⟪नरः⟫ = ⟪शूरा⟫ ⟪एव⟫ ⟪पुत्रा⟫ ⟪यस्य⟫ ⟪स⟫ ⟪नरः⟫ = "ልጆቹ ጀግኖች የሆኑለት ሰው"

⟪तदन्त⟫ ⟪३⟫ = ⟪सो⟫ ⟪ऽन्तो⟫ ⟪यस्य⟫ ⟪सः⟫ ⟪।⟫ ⟪यस्याः⟫ ⟪सा⟫ ⟪।⟫ ⟪यस्य⟫ ⟪तत्⟫ = "መጨረሻው ይህ የሆነ" = "በዚህ የሚያልቅ"
:::
::: grammar-box

**በመጨረሻ አባሎቻቸው ⟪आदि⟫ ⟪।⟫ ⟪आदिक⟫ ⟪।⟫ ⟪आद्य⟫ "የመጀመሪያ፣ መጀመሪያ"፣ እና አልፎ አልፎ ⟪प्रभृति⟫ "መጀመሪያ" የሆኑ አፖዚሽናል ባሁቭሪሂዎች በጣም አስፈላጊ ናቸው። እነዚህ ቅንጅቶች "ወዘተ" ከሚለው ጋር ይዛመዳሉ፦**

**ምሳሌ፦**

:::
::: indent
⟪देवा⟫ ⟪इन्द्रादयः⟫ =  ⟪इन्द्र⟫ ⟪आदिर्येषां⟫ ⟪ते⟫ ⟪देवाः⟫ = "መጀመሪያቸው ኢንድራ የሆኑ አማልክት" = "አማልክት ኢንድራ ወዘተ" = "ኢንድራ እና ሌሎች አማልክት"
:::

**ምሳሌ፦**

:::
**ከPPP በኋላ ⟪मात्र⟫ "ልክ እንደ" ተብሎ ይተረጎማል፦**

**ምሳሌ፦**

## 20.4. ከአገባባዊ የመጀመሪያ ክፍል ጋር Bahuvrīhi

ማለትም Bahuvrīhi፣ የመጀመሪያው ክፍላቸው ከስመ-አመልካች (⟪प्रथमा⟫) ውጪ ሌላ መደብን የሚወክሉ ናቸው።

ምሳሌ፦

::: indent
⟪देवरूपा⟫ = ⟪देवस्यैव⟫ ⟪रूपं⟫ ⟪यस्याः⟫ ⟪सा⟫ = "ቅርጿ የአምላክ የሆነች (ሴት)" "መለኮታዊ መልክ ያላት ሴት"
:::
::: grammar-box

**የግቢ-ቃል ክፍሎች ቅደም ተከተል አጠቃላይ ደንብ ልዩ ሁኔታ፦**

**የስም መደብ ክፍል የሰውነትን ክፍል (በተለይ እጅን) ሲያመለክት በሁለተኛ ደረጃ ላይ ይቆማል፦**

**ምሳሌ፦**

:::
