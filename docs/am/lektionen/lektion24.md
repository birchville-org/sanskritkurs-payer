## 24.2. የዳቲቭ አፈጣጠር (⟪चतुर्थी⟫)

::: grammar-box
**የዳቲቭ መደበኛ ቅጥያዎች እነዚህ ናቸው፦**

* **ነጠላ፡ -e፤ በአናባቢ የሚጨርሱ የሴት ጾታ ስሞች፡ -ai**
* **ብዛት፡ ዳቲቭ እና አብላቲቭ ⟪पञ्चमी⟫፡ -bhyas**
:::
### 24.2.1. በተነባቢ የሚጨርሱ ስሞች

::: grammar-box

| | የተቀባይ ነጠላ | የተቀባይ ብዙ |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |

:::

| | **ዳቲቭ ብዙ** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::
### 24.2.4. አናባቢ ግንዶች

::: grammar-box
**አናባቢ ግንዶች**

* **በ -a የሚያልቁ ወንድ / ገለልተኛ ቃላት:** ⟪देव⟫
  * ዳቲቭ ነጠላ ⟪देवाय⟫
  * ዳቲቭ ብዙ ⟪देवेभ्यस्⟫
* **በ -i የሚያልቁ ወንድ ቃላት:** ⟪कवि⟫
  * ዳቲቭ ነጠላ ⟪कवये⟫
  * ዳቲቭ ብዙ ⟪कविभ्यस्⟫
* **በ -u የሚያልቁ ወንድ ቃላት:** ⟪पशु⟫
  * ዳቲቭ ነጠላ ⟪पशवे⟫
  * ዳቲቭ ብዙ ⟪पशुभ्यस्⟫
* **በ -ā የሚያልቁ ሴት ቃላት:** ⟪देवता⟫
  * ዳቲቭ ነጠላ ⟪देवतायै⟫
  * ዳቲቭ ብዙ ⟪देवताभ्यस्⟫
* **በ -ī የሚያልቁ ሴት ቃላት:** ⟪देवी⟫
  * ዳቲቭ ነጠላ ⟪देव्यै⟫
  * ዳቲቭ ብዙ ⟪देवीभ्यस्⟫
* **በ -i የሚያልቁ ሴት ቃላት:** ⟪श्रुति⟫
  * ዳቲቭ ነጠላ ⟪श्रुतये⟫ ወይም ⟪श्रुत्यै⟫ (ማለትም እንደ ⟪कवि⟫ ወይም እንደ ⟪देवी⟫)
  * ዳቲቭ ብዙ ⟪श्रुतिभ्यस्⟫
* **በ -u የሚያልቁ ሴት ቃላት:** ⟪धेनु⟫
  * ዳቲቭ ነጠላ ⟪धेनवे⟫ ወይም ⟪धेन्वै⟫
  * ዳቲቭ ብዙ ⟪धेनुभ्यस्⟫
:::
## 24.3. የመጨረሻ -ai እና -au ሳንዲ

::: grammar-box
**የመጨረሻ -ai እና -au ሳንዲ**

* **-ai ከመጀመሪያ አናባቢ በፊት ሲመጣ አብዛኛውን ጊዜ በ -ā ይተካል (አልፎ አልፎ በቃሉ ውስጥ እንደሚሆነው በ -āy ይተካል)**
* **-au ከአናባቢ በፊት ሲመጣ አብዛኛውን ጊዜ በ -āv ይተካል (አልፎ አልፎ በ -ā ይተካል)**

ምሳሌ፡

:::

## 24.4. የቃላት ዝርዝር

⟪अलम्⟫ ተውሳከ ግሥ፦ በቂ፣ የሚበቃ፣ (ለአንድ ሰው፣ ለአንድ ነገር) የሚመጥን፤ ከዳቲቭ ጋር፦ ለ... በቂ፣ ለ... የሚበቃ፣ ለዚያ የሚመጥን፤ ከኢንስትሩሜንታሊስ ጋር፦ ከ... ጋር በቃ፣ ...ን ተው፣ ለምሳሌ ⟪अलं⟫ ⟪क्रोधेन⟫ = "ከቁጣው ጋር በቃ = ቁጣውን ተው!"

ልክ እንደ ⟪अलम्⟫ ከኢንስትሩሜንታሊስ ጋር በተመሳሳይ መልኩ ጥቅም ላይ ይውላል፦

⟪कृतम्⟫ ፦ ⟪कृतं⟫ ⟪क्रोधेन⟫ = "ከቁጣው ጋር ተፈጸመ = ቁጣውን ተው!"
