# ትምህርት 29

## 29.1. የ Parasmaipada (⟪परस्मैपद⟫) እና Ātmanepada (⟪आत्मनेपद⟫) ጥቅም በ Kausativum ውስጥ


::: grammar-box
**Kausativ በትንሽ ልዩነቶች Ubhayapada (⟪उभयपद⟫) ነው**
:::
::: grammar-box
**በ Kausativum ውስጥ Ātmanepada (⟪आत्मनेपद⟫) ይጠቀማል፡**

**1. የተፈጸመው ክስተት ፍሬ ለተፈጸመው ሰው ጠቃሚ ሲሆን፡**
:::
ምሳሌ፡

⟪रामः कटं कारयते⟫ = "ራማ ለራሱ (በራሱ ጥቅም) ጣት ያዘጋጃል"

**2. Kausativum የ transitiver verbs reflexiv ሲጠቀም ("ራሱን ማሳየት" "ራሱን ማስማማት" ወዘተ.)፣ ወይም የቀላል verb object Agens (⟪कर्तृ⟫) የ Kausativ ሲሆን፡**

ምሳሌ፡

⟪विष्णुर्भक्तान्दर्शयते⟫ = "ጊዡ ራሱን ለአማኞቹ ያሳያል"

ውጤት፡ ⟪भक्ता विष्णुं पश्यन्ति⟫ = "አማኞች ጊዡን ይመለከታሉ"


ህጎቹ በአጠቃላይ ከ Ātmanepada (⟪आत्मनेपद⟫) ህጎች ጋር ይስማማሉ። Ubhayapada (⟪उभयपद⟫) verbs ላይ።

## 29.3. የመተርጎም ልምምድ ለማጠቃለያ

በጥብቅ በጥሩ ጀርመንኛ ይተርጉሙ እና የሳንስክሪት ጽሑፎችን ያስታውሱ፡

1\. የ ⟪अविद्या⟫ ትርጉም፡

⟪अनित्याशुचिदुःखा⟫:sig[⟪नात्मसु⟫] ⟪नित्यशुचिसुखात्मख्यातिरविद्या ॥योगसूत्र २⟫.⟪५॥⟫

2\. ⟪कौटिलीयार्थशास्त्र⟫ 1.4. ስለ ትክክለኛው መጠቀም ከ ⟪दण्ड⟫ ጋር ስለሆነ፡
