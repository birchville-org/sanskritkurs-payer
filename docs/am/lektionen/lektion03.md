# ትምህርት 3

::: deleteme-box
**በዚህ ትምህርት ውስጥ የሚከተሉትን ይማራሉ፦**
- የሴት ጾታ ነጠላ ስም መራኄ
- የወንድና የሴት ጾታ ብዙ ስም መራኄ
- ከወንድ ጾታ ስሞች የሴት ጾታ ስሞችን መፍጠር
- የአናባቢ ሳንዲ
- Satzsandhi von -ās
:::
## 3.1. የሴት ጾታ ነጠላ ስም መራኄ

### 3.1.1. በ -s የሚያልቅ ነጠላ ስም መራኄ

በተጨማሪም፣ በአናባቢ የሚጨርሱ የሚከተሉት የስም ግንድ ዓይነቶች ነጠላ ቁጥር ኖሚናቲቭን በ **-s** ይፈጥራሉ፦

::: grammar-box
- **በ -i የሚያልቁ አንስታይ ቃላት**፦ ለምሳሌ **śruti** አን. "መስማት" -- ነጠላ ቁ. ኖሚ.፦ **śrutis** = ⟪श्रुतिस्⟫
- **በ -u የሚያልቁ አንስታይ ቃላት**፦ ለምሳሌ **dhenu** አን. "አልቢ ላም" -- ነጠላ ቁ. ኖሚ.፦ **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. ያለ ቅጥያ ነጠላ ቁጥር ኖሚናቲቭ

የሚከተሉት ያለ ቅጥያ ነጠላ ቁጥር ኖሚናቲቭን ይፈጥራሉ፦

::: grammar-box
- **በ -ā የሚያልቁ አንስታይ ቃላት**፦ ለምሳሌ **devatā** አን. "አምላክነት" -- ነጠላ ቁ. ኖሚ.፦ **devatā** = ⟪देवता⟫
- **በ -ī የሚያልቁ አንስታይ ቃላት**፦ ለምሳሌ **devī** አን. "ሴት አምላክ" -- ነጠላ ቁ. ኖሚ.፦ **devī** = ⟪देवी⟫
:::
::: important
**ማስታወሻ!** ከዚህ በተጨማሪ፣ በ -ī የሚያልቁ እና ነጠላ ቁጥር ኖሚናቲቫቸው በ -s የሚጨርስ ባለ አንድ ክፍለ-ቃል አንስታይ ሥር-ስሞች አሉ፦ ለምሳሌ dhī አን. "ሀሳብ" -- ነጠላ ቁ. ኖሚ.፦ dhīs = ⟪धीस्⟫። እንዲሁም lakṣmī (⟪लक्ष्मी⟫) አን.፣ tarī (⟪तरी⟫) አን. "ጀልባ" እና tantrī (⟪तन्त्री⟫) አን. "ክር" ያልተለመደ በሆነ መንገድ ነጠላ ቁጥር ኖሚናቲቭን በ -s ይፈጥራሉ፦ lakṣmīs = ⟪लक्ष्मीस्⟫።
:::

## 3.2. የሴት ጾታ ከወንድ ጾታ አመሰራረት

::: grammar-box
**በ -a የሚያልቁ የወንድ ጾታ ቃላት፡**
- **በ -ā የሚያልቅ የሴት ጾታ፡** ለምሳሌ **kṣatriya** m. » **kṣatriyā** f. "የክሻትሪያ ሴት" = ⟪क्षत्रिया⟫
- **በ -ī የሚያልቅ የሴት ጾታ፡** ለምሳሌ **brāhmaṇa** m. » **brāhmaṇī** f. "ብራህሚን ሴት" = ⟪ब्राह्मणी⟫

**በ -u የሚያልቁ የወንድ ጾታ ቃላት፡**
- **በ -ī የሚያልቅ የሴት ጾታ፡** ለምሳሌ **sādhu** m. » **sādhvī** f. (ጥሩ፣ ቅድስት) = ⟪साध्वी⟫
(**-u-** ከአናባቢ በፊት **-v-** ይሆናል፣ ስለዚህ **-u- + -ī** » **-vī**)
:::

## 3.3. የወንድና የሴት ጾታ ነጠላ ስም መደብ ብዙ ቁጥር

::: grammar-box
በተባዕታይና በአንስታይ ጾታ የብዙ ቁጥር ስም መደብ ቅጥያው **-as** ነው።
- **በ -a የሚያልቁ ተባዕታይ ስሞች**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **በ -ā የሚያልቁ አንስታይ ስሞች**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **በ -i የሚያልቁ ተባዕታይ ስሞች**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **በ -i የሚያልቁ አንስታይ ስሞች**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **በ -ī የሚያልቁ አንስታይ ስሞች**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **በ -u የሚያልቁ ተባዕታይ ስሞች**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **በ -u የሚያልቁ አንስታይ ስሞች**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
ማስታወሻ፡ **e** የ **i** ከፍተኛ ደረጃ (**guṇa**) ሲሆን፣ **o** ደግሞ የ **u** ከፍተኛ ደረጃ ነው።

## 3.4. የአናባቢዎች ውህደት

::: grammar-box
**የማይለያዩ ወይም በርዝመታቸው ብቻ የሚለያዩ ቀላል አናባቢዎች፣ ወደ ተመጣጣኙ ረጅም አናባቢ "ይዋሃዳሉ"፡**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
ለምሳሌ

devatā + annapūrṇā » devatānnapūrṇā "አናፑርና አምላክ ናት" = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā የምግብና የማብሰል አምላክ ስትሆን፣ የŚiva ባለቤት የሆነችው የPārvatī አካል መገለጫ ተደርጋ ትቆጠራለች።)

devī + indrāṇī » devīndrāṇī "Indrāṇī አምላክ ናት" = ⟪देवीन्द्राणी⟫

## 3.5. የ-ās የአረፍተ ነገር ሳንዲ

::: grammar-box
**-ās wird vor allen stimmhaften Lauten durch -ā ersetzt.**
:::
ለምሳሌ

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "ቫይሽያዎች ሁለት ጊዜ የተወለዱ ናቸው" = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. የቃላት ዝርዝር

**የሚከተሉትን ቃላት ይማሩ፡**

**śruti** f. = ⟪श्रुति⟫ : መስማት፣ ዘላለማዊው ትውፊት (ለቬዳዎችና ለብራህማናዎች የሚሰጥ ስያሜ)።

**smṛti** f. = ⟪स्मृति⟫ : ማስታወስ፣ ትዝታ፣ በማሰላሰል ማስታወስ = ንቃት፣ ትውፊት (የ**śruti** ተቃራኒ ጽንሰ-ሀሳብ)። የሚከተሉትን ያጠቃልላል፦
- ስድስቱ **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): ትክክለኛ አነባበብ
  2. **chandas** n. (⟪छन्दस्⟫): የሥነ-ግጥም ሥርዓት
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): ሰዋስው
  4. **nirukta** n. (⟪निरुक्त⟫) : የቃላት ማብራሪያ፣ ሥርወ-ቃል
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : ሥነ-ፈለክ፣ የቀን መቁጠሪያ ትምህርት
  6. **kalpa** m. (⟪कल्प⟫) : ሥነ-ሥርዓት
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : ለታላላቅ መስዋዕቶች አፈጻጸም የሚያገለግሉ የማስተማሪያ መጻሕፍት
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : ለዕለት ተዕለት ሕይወት ሥነ-ሥርዓቶችና መስዋዕቶች የሚያገለግሉ የማስተማሪያ መጻሕፍት
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) እና **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : ስለ ሕግና ልማድ (ትክክለኛ ባህሪ) የሚያስተምሩ መጻሕፍት
- ታላላቆቹ ቅኔዎች **mahābhārata** n. (⟪महाभारत⟫) እና **rāmāyaṇa** n. (⟪रामायण⟫)
- **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : የሕይወት ጥበብ ማስተማሪያ መጻሕፍት

**smṛti** በተለይም ለዳርማ ማስተማሪያ መጻሕፍት የሚሰጥ ስያሜም ነው።

**dhenu** f. = ⟪धेनु⟫ : (ወተት የምትሰጥ) ላም።

**paśu** m. = ⟪पशु⟫ : የለማደ የቤት እንስሳ፣ ከብት (በስብስብ)።

**devatā** f. = ⟪देवता⟫ : መለኮት (ረቂቅ እና ተጨባጭ)።

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : ብራህማኒን።

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : ሴት ክሻትሪያ።

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : የክሻትሪያ ሚስት።

**vaiśyā** f. = ⟪वैश्या⟫ : ሴት ቫይሽያ።

**śūdrā** f. = ⟪शूद्रा⟫ : ሴት ሹድራ።

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : የሹድራ ሚስት።

**devī** f. = ⟪देवी⟫ : አምላክ፣ በተለይ Durgā f. = ⟪दुर्गा⟫፣ የŚiva ባለቤት = ⟪शिव⟫።

**sādhvī** f. = ⟪साध्वी⟫ : የsādhu ሴቴ ጾታ።

**gurvī** f. = ⟪गुर्वी⟫ : የguru ሴቴ ጾታ።

**asmitā** f. = ⟪अस्मिता⟫ : "እኔ-ነኝ-ነት"፣ ማለትም (የተሳሳተ) እምነት፦ የሚያየው **እኔ** ነኝ፣ ወዘተ።

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : ፍልስፍና (በአመክንዮ ትክክለኛ በሆኑ ምክንያቶች ወደ ድምዳሜዎቿ የምትደርስ ሳይንስ)።

**upekṣā** f. = ⟪उपेक्षा⟫ : ቸልተኝነት፣ የአእምሮ ሰላም።

**karuṇā** f. = ⟪करुणा⟫ : ርኅራኄ፣ ሐዘኔታ።

**muditā** f. = ⟪मुदिता⟫ : ደስታ፣ በተለይም በሌሎች ደስታ መደሰት (የቅናት ተቃራኒ)።

## 3.7. መልመጃ

**ሀ) የሚከተሉትን ዓረፍተ ነገሮች ወደ ብዙ ቁጥር ይለውጡ፡**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**ለ) በማስገባት የስም ዓረፍተ ነገሮችን ይፍጠሩ፡**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**ሐ) ወደ አንስታይ ጾታ ይለውጡ፦**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**መ) ወደ ሳንስክሪት ይተርጉሙ፦**

1. Umā አምላክ ናት።
2. Veda śruti ነው።
3. መምህራቱ አማልክት ናቸው።
4. የወተት ላሞች የቤት እንስሳት ናቸው።
5. ገጣሚዎች መምህራን ናቸው።
6. Kṣatriyas ሁለት ጊዜ የተወለዱ ናቸው።
7. ቅዱሳን ሰዎች Śūdras ናቸው።
