## 18.2. ድብልቅ ቃላት (⟪तत्पुरुष⟫) ከተውሳከ-ግሥ ቀዳማይ ክፍል ጋር (Kielhorn)

*   ተውሳከ-ግሦች
*   መስተዋድዶች
*   ቅንጣቶች
*   ሌሎች የማይለወጡ ቃላት

::: indent

:::

### 18.2.2. የ nañ-Tatpuruṣa (a- / an-) ትርጉሞች (Kielhorn)

3.  ልዩ መሆን (⟪तदन्यत्वम्⟫)፦  
    ⟪अपटम्⟫ = ልብስ ያልሆነ ነገር (⟪पट⟫ m: ጨርቅ፣ ልብስ)

    ⟪अकालः⟫ = ያልተገባ ጊዜ
6.  ጠላትነት (⟪निरोधः⟫)፦

ከመሠረታዊ ቃላት ከተጣመሩ ቃላት በኩል ከክሬት-ስፖስፒክስ በኩል ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ከተጣመሩ ቃላት ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ ቃላት ማለትም ከፊል-ተዋህዶ
