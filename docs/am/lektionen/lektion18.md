### 18.2.2. የ nañ-Tatpuruṣa (a- / an-) ትርጉሞች

ከ a- / an- ጋር ያሉ Tatpuruṣa የሚከተሉት ትርጉሞች ሊኖራቸው ይችላል፡

1.  ተመሳሳይነት (⟪तत्सादृश्यम्⟫):
⟪अब्राह्मणः⟫ = ቅዱስ ክር (⟪यज्ञोपवीत⟫ n.) የሚለብስ እና ብራህማን ሳይሆን ብራህማንን የሚመስል ክሻትሪያ ወይም ቫይሽያ
2.  አለመኖር፣ አለመገኘት (⟪तदभावः⟫):
⟪अज्ञानम्⟫ = ድንቁርና (የእውቀት ማጣት)
3.  ልዩነት (⟪तदन्यत्वम्⟫):
⟪अपटम्⟫ = ጨርቅ / ልብስ ያልሆነ ነገር (⟪पट⟫ m: ጨርቅ፣ ልብስ)
4.  ትንሽነት (⟪तदल्पता⟫):
⟪अनुदरम्⟫ = ትንሽ ሆድ (ሆድ ያልሆነ)
5.  አለመስማማት (⟪अप्राशास्त्यम्⟫):
⟪अकालः⟫ = ያልተገባ ጊዜ
6.  ጠላትነት (⟪निरोधः⟫):
⟪असुरः⟫ = ፀረ-አምላክ (በተሳሳተው የ a-sura ሥርወ-ቃል መሠረት)

የሚከተለው ስንኝ እነዚህን ትርጉሞች ያጠቃልላል፦

::: indent
⟪तत्सादृश्यमभावश्च⟫
