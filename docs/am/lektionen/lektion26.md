# ትምህርት 26

## 26.1. በቃል ውስጥ ላለ -s- የሴሬብራላይዜሽን ህግ

::: grammar-box
**-s-** በ**-ṣ-** ይተካል፣ **k, r, l** ወይም አንድ **አናባቢ** — ከ **a, ā** በስተቀር — በቀጥታ ወይም በ⟪अनुस्वार⟫ ወይም በ⟪विसर्ग⟫ ብቻ ተለያይቶ ከቀደመ እና ከ **ṛ, r** የተለየ ድምፅ ከተከተለ።

ይህን ሳንዲህ ደግሞ **⟪दुस्⟫-** በቅጽል ቃላት ውስጥ ድምፅ አልባ ከሆኑ የጉሮሮ እና የከንፈር ድምፆች በፊት ይከተላል።
:::
*ምሳሌዎች:*
::: indent
⟪तेषाम्⟫ (ከ፡ *te-sām* የመጣ)

ነገር ግን፡ ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. በቃል ውስጥ ለሚገኙ የጥርስ ድምፆች የሴሬብራላይዜሽን ህግ

::: grammar-box
የጥርስ ፈንጂ ድምፆች ከሬትሮፍሌክስ ድምፆች (**-ṣ-**ን ጨምሮ) በኋላ በተመጣጣኝ ሬትሮፍሌክስ ድምፆች ይተካሉ፡

- **iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** ከፊት ባለው **i** ምክንያት፣ **ṭh** ከዚያም በፊት ባለው **ṣ** ምክንያት)*
:::
## 26.3. ለፓላታል፣ ጉቱራል፣ ṣ, h + -s የቃል-ሳንዲህ

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

ምሳሌዎች ከታች ይመልከቱ
:::
## 26.4. የግራስማን የትንፋሽ መለያየት ህግ

::: grammar-box
**የሁለት ትንፋሻዊ ፊደላት (ትንፋሻዊ - አናባቢ - ትንፋሻዊ) ቀጥተኛ ተከታታይነት የመጀመሪያው ድምፅ ትንፋሹን እንዲያጣ ያደርገዋል፡**

ምሳሌ፡

:::

\*dhu(gh) » du(g)h
:::

ምሳሌዎች፡ ከታች የ ⟪दुह्⟫ እና ⟪बुध्⟫ የወደፊት ጊዜ (futur) ይመልከቱ።

## 26.5. ከፉጨት ድምፅ በፊት ለ -m, -n የሚሆን ቃል-ሳንዲ (Wortsandhi)

::: grammar-box
**ከፉጨት ድምፆች በፊት -n እና -m በ -ṃ- ይተካሉ፡**

ምሳሌ፡ ከታች የ ⟪मन्⟫ የወደፊት ጊዜ (futur) ይመልከቱ።
:::
## 26.6. የቀላል የወደፊት ጊዜ (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) አጠቃቀም

::: grammar-box
**ቀላል የወደፊት ጊዜ (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) የሚከተሉትን ይገልጻል፦**

- **የወደፊቱን**
- **የታሰበ ወይም የተፈለገ ድርጊት ("እሄዳለሁ", "መሄድ እፈልጋለሁ")**
- **ግምት ("እንደዚህ ይሆናል")**
- **ተስፋ**
- **ስጋት**
- **ሊሆን የሚችል ነገር**
- **የተናጋሪው አስተያየት**
- **ትዕዛዝ**

**የወደፊት ጊዜው በከፊል ከኦፕታቲቭ ጋር ተፎካካሪ ነው (በኋላ ይመልከቱ)።**
:::

## 26.7. የቀላል የወደፊት ጊዜ አፈጣጠር (⟪ऌत्⟫, ⟪भविष्यन्ती⟫  f.)

::: grammar-box
**ቀላል የወደፊት ጊዜ፡**

:::
::: indent
**የወደፊት ጊዜ ግንድ + የመጀመሪያ ደረጃ ቅጥያ**
:::
::: grammar-box
**የወደፊት ጊዜ ግንድ፡**

:::
::: indent
**(በአብዛኛው) ከፍተኛ ደረጃ ያለው ሥር + -sya**
**ወይም**
**(በአብዛኛው) ከፍተኛ ደረጃ ያለው ሥር + -i- + -sya (= - iṣya)**
:::
**የትኛው ሥር የትኛውን የወደፊት ጊዜ ግንድ እንደሚፈጥር ከግንዱ ቅርጾች ጋር አብሮ መማር ያስፈልጋል!**
**በአጠቃላይ፣ የወደፊት ጊዜው የሥር ቅርጽ እና አያያዥ አናባቢ ከኢንፊኒቲቩ ጋር ይዛመዳሉ።**
**አንዳንድ ሥሮች የወደፊት ጊዜን በአማራጭነት ከአያያዥ አናባቢ -i- ጋር ወይም ያለሱ ሊፈጥሩ ይችላሉ።**
**የወደፊቱ ጊዜ ፓራስማይፓዳ ፓርቲሲፕል የሚፈጠረው -nt- የሚለውን ቅጥያ ከወደፊቱ ጊዜ ግንድ ጋር በማያያዝ ሲሆን፣ የሴት ጾታው በአማራጭነት በ -ntī ወይም በ -tī ያበቃል፡**

::: indent
