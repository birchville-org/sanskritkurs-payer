# ደቫናጋሪ = ⟪देवनागरी⟫

## የጽሑፍ ልምምድ 1

ሳንስክሪት በብዙ አይነት ጽሑፎች ተጻፏል እና ይጻፋል። የሚከተለው ማጠቃለያ ከእነዚህ ጽሑፎች ትንሽ ክፍል ያቀርባል፡

![](/images/schrift001.webp)  
ስዕል፡ የሳንስክሪት ጽሑፍ ናሙናዎች  
\[የስዕል ምንጭ፡ ዊኪፔዲያ፣ GNU FD ስርጭት\]

ዋናው የዘመናዊ ሰሜን ኢንዲያ ሳንስክሪት ጽሑፍ ደቫናጋሪ ነው፡

![](/images/schrift002.webp)

እያንዳንዱ የቀላል ገጽታ ፊትሆን ከቀላል ገጽታ በኋላ የሚመጣ "a" ይዟል። ሙሉ ቀላል ገጽታ (ያለ የከተመ ቃላት) ለጻፍ ኖሮ ይህን በታች የተዘጋ ሸካራ መስመር -- virāma = ⟪विराम⟫ -- ማመልከት አለብዎት፡

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

ከቀላል ገጽታ በኋላ የሚመጡ ቃላት -- "a" በስተቀር -- እንደሚከተለው ይጻፋሉ፡

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

እነዚህን የቀላል ገጽታ + ቃላት ግንኙነቶች በመጻፍ ወቅት ቅደም ተከተሉ እንዲሁ ነው፡

![](/images/schrift003.jpg)

በመጻፍ ሂደት እያንዳንዱ ፊትሆን ከጎን መስመር ጋር በማጠናቀቅ ከዚያ ተከታይ ፊትሆን ይጻፋል።
