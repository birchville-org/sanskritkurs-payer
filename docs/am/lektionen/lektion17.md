# ትምህርት 17

## 17.1. ሁለተኛ የአሁን ጊዜ ክፍል (⟪अदादि⟫ = ⟪अद्⟫ ወዘተ)

የግስ ቅጥያዎች በቀጥታ ከሥሩ ጋር ይያያዛሉ። በዚህ ጊዜ ከቃላት-ሳንዲ የሚመነጩ የድምፅ ለውጦች መታየት አለባቸው።

::: grammar-box

በሁለተኛው የአሁን ጊዜ ክፍል ውስጥ የሚከተሉት የአፈጣጠር ቅርጾች አሉ፡

1.  የግንድ ደረጃ ያላቸው ሥሮች
    *   ብዙውን ጊዜ፡ ከፍተኛ ደረጃ - ዝቅተኛ ደረጃ
    *   አንዳንድ ሥሮች፡ የተራዘመ ደረጃ - ዝቅተኛ ደረጃ
2.  የግንድ ደረጃ የሌላቸው ሥሮች
3.  በ -i/-ī የሚያልቁ ባለ ሁለት ክፍለ-ቃል ሥሮች ከግንድ ደረጃ ጋር

:::

## 17.5. በ -i/-ī የሚያልቁ ባለ ሁለት ክፍለ-ቃል ሥሮች ከግንድ ደረጃ ለውጥ ጋር

በርካታ ሥሮች በተለያዩ ቅርጾቻቸው ባለ ሁለት ክፍለ-ቃል ናቸው፣ ይህም ማለት ከተነባቢ ቅጥያ በፊት -i (ወይም በአንዳንድ ቅጥያዎች ፊት -ī) አላቸው። ይሁን እንጂ እነዚህ ሥሮች በአገር በቀል ሰዋሰው ሊቃውንት እና በመዝገበ ቃላት ወዘተ. ውስጥ እንደ ባለ አንድ ክፍለ-ቃል ተደርገው ይመደባሉ።

ምሳሌዎች፦

## 17.7. መልመጃ 1

A) በሚከተሉት ዓረፍተ ነገሮች ውስጥ ግሱን አስገብተው ይተርጉሙ፡

⟪१⟫. ⟪ब्राह्मणो⟫ ⟪ऽनृतं⟫ ⟪न⟫ ... (⟪ब्रू⟫ ⟪।⟫ ⟪वच्⟫ ⟪।⟫ ⟪वद्⟫)

⟪२⟫. ⟪क्षत्रियो⟫ ⟪जनान्⟫ ... (⟪पा⟫ ⟪।⟫ ⟪रक्ष्⟫)

⟪३⟫. ⟪बलवद्योधो⟫ ⟪द्विजारीन्⟫ ... (⟪जि⟫ ⟪।⟫ ⟪हन्⟫ ⟪।⟫ ⟪युध्⟫)

⟪४⟫. ⟪ब्राह्मणकविर्लोकेश्वरम्⟫ ... (⟪स्तु⟫ ⟪।⟫ ⟪यज्⟫)

⟪५⟫. ⟪अग्निर्यज्ञान्नम्⟫ ... (⟪अद्⟫ ⟪।⟫ ⟪दह्⟫)

⟪६⟫. ⟪बालवैश्यो⟫ ⟪धेनुम्⟫ ... (⟪दुह्⟫ ⟪।⟫ ⟪रक्ष्⟫ ⟪।⟫ ⟪पा⟫)

⟪७⟫. ⟪द्विजदासो⟫ ⟪मृगमार्गेण⟫ ⟪ब्राह्मणग्रामम्⟫ ... (⟪गम्⟫ ⟪।⟫ ⟪इ⟫ ⟪।⟫ ⟪पद्⟫)

⟪८⟫. ⟪द्विजदासः⟫ ⟪शूद्रस्⟫ ... (⟪अस्⟫ ⟪२⟫ ⟪।⟫ ⟪भू⟫)

⟪९⟫. ⟪बालब्राह्मणी⟫ ... (⟪रुद्⟫ ⟪।⟫ ⟪आस्⟫ ⟪।⟫ ⟪मृ⟫)

⟪१०⟫. ⟪साधुजनो⟫ ⟪ऽधर्मम्⟫ ... (⟪द्विष्⟫ ⟪।⟫ ⟪न⟫ ⟪कृ⟫)

B) በ A) ውስጥ በተፈጠሩት ዓረፍተ ነገሮች ውስጥ ባለቤቱንና ግሱን ወደ ብዙ ቁጥር ይለውጡ
