# ትምህርት 17

## 17.1. ሁለተኛ የፕሬዝንት ክፍል (⟪अदादि⟫ = ⟪अद्⟫ ወዘተ)

የፊኑት መጨረሻዎች በቀጥታ ወደ ሥሩ ይጣመራሉ። በዚህ ሂደት ከቃላት ጥምረት (Wortsandhi) የሚከተሉት የድምፅ ለውጦች መጠንቀቅ ያስፈልጋል።

::: grammar-box

በሁለተኛው የፕሬዝንት ክፍል ውስጥ የሚከተሉት የመፍጠር ቅርጾች አሉ፡-

1.  ሥሮች ከግንባታ ደረጃ ጋር (የሥር ደረጃ ለውጥ)
*   በአብዛኛው፡ ከፍተኛ ደረጃ - ዝቅተኛ ደረጃ
*   አንዳንድ ሥሮች፡ ማራዘም ደረጃ - ዝቅተኛ ደረጃ
2.  ሥሮች ከግንባታ ደረጃ ጋር ያልሆኑ
3.  ሁለት ድምፅ ያላቸው ሥሮች በ-i/-ī መጨረሻ ላይ ከግንባታ ደረጃ ጋር

:::
