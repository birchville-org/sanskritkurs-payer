# ትምህርት 19

## 19.1. አንጻራዊ ዓረፍተ ነገር

::: grammar-box

**ንድፍ፡**

**አንጻራዊ ተውላጠ ስም -- አንጻራዊው ዓረፍተ ነገር የሚመለከተውን ስም የያዘው አንጻራዊ ዓረፍተ ነገር -- (አመልካች ተውላጠ ስም) -- ዋና ዓረፍተ ነገር**

**አንጻራዊው ዓረፍተ ነገር ከዋናው ዓረፍተ ነገር በኋላም ሊመጣ ይችላል፣ ነገር ግን በዋናው ዓረፍተ ነገር ውስጥ ሊገባ አይችልም።**

**አንጻራዊው ተውላጠ ስምና ተዛማጁ ቃል (ይህም - ከጀርመንኛ በተቃራኒ - በአንጻራዊው ዓረፍተ ነገር ውስጥ የሚገኝ ነው)፣ አንጻራዊው ዓረፍተ ነገር በአገባብ በሚጠይቀው ምዕላድ ውስጥ ይቀመጣሉ። አመልካቹ ተውላጠ ስም ዋናው ዓረፍተ ነገር በአገባብ በሚጠይቀው ምዕላድ ውስጥ ይቀመጣል።**
:::

ምሳሌዎች፡

ማስታወሻ፡ አጠቃላይ ይዘት ባላቸው አንጻራዊ ዓረፍተ ነገሮች ውስጥ ከአመላካች ግስ ይልቅ ምኞታዊ ግስ (Optativ) መጠቀም የተለመደ ነው። ስለዚህ ብዙዎቹ ምሳሌዎቻችን በተሻለ ሁኔታ በምኞታዊ ግስ (Optativ) ውስጥ ይቀመጡ ነበር።

**1. የዓረፍተ ነገሩ ባለቤት (⟪कर्तृ⟫) በአንጻራዊ ዓረፍተ ነገር በዝርዝር ይገለጻል፡**

::: indent
⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪स⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫ =  ⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ = ⟪येन⟫ ⟪नरेण⟫ ⟪पुण्यम्⟫ ⟪क्रियते⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ ወዘተ. = "መልካም ሥራ የሚሠራ ሰው ወደ ሰማይ ይገባል።"
:::
**2. የዋናው ዓረፍተ ነገር ቀጥተኛ ተሳቢ (⟪कर्म⟫) በአንጻራዊ ዓረፍተ ነገር በዝርዝር ይገለጻል፡**

::: indent
⟪यो⟫ ⟪ब्राह्मणो⟫ ⟪देवान्यजते⟫ ⟪तं⟫ ⟪देवा⟫ ⟪रक्षन्ति⟫ = "አማልክት ለእነርሱ መስዋዕት አቅራቢ ሆኖ የሚሰዋውን ብራህማንን ይጠብቃሉ።"
:::
**3. የዋናው ዓረፍተ ነገር ስም ዝርዝር መግለጫ በተዛማጅ ዓረፍተ ነገር ውስጥ ይገኛል፡**

::: indent
⟪ये⟫ ⟪नराः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪तेषां⟫ ⟪पुत्रा⟫ ⟪धनं⟫ ⟪न⟫ ⟪लभन्ते⟫ = "ክፉን የሚሰሩ ሰዎች ልጆች ሀብት አያገኙም።"
:::
**4. ተዛማጅ ተውላጠ ስም እና ተዛማጅ ቃል በባለቤትነት መደብ (⟪षष्ठी⟫) ውስጥ ይገኛሉ፡**

::: indent
⟪यस्य⟫ ⟪नरस्य⟫ ⟪पुत्राः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪स⟫ ⟪न⟫ ⟪सुखवान्⟫ = "ልጆቹ ክፉን የሚሰሩ ሰው ደስተኛ አይደለም።"
:::
**5. ተዛማጅ ተውላጠ ስም እና ተዛማጅ ቃል በመሳሪያ መደብ (⟪तृतीया⟫) ውስጥ ይገኛሉ፡**

::: indent
⟪येन⟫ ⟪शत्रुणा⟫ ⟪ग्रामो⟫ ⟪जितस्तं⟫ ⟪द्विषन्ति⟫ = "መንደራቸውን ያሸነፈውን / የያዘውን ጠላት ይጠላሉ።"
:::
**6. ተዛማጅ ተውላጠ ስም እና ተዛማጅ ቃል በተሳቢ መደብ (⟪द्वितीया⟫) ውስጥ ይገኛሉ፡**

::: indent
⟪यं⟫ ⟪नरं⟫ ⟪देवी⟫ ⟪रक्षति⟫ ⟪स⟫ ⟪सुखमाप्नोति⟫ = "አማልክቷ የምትጠብቀው ሰው ደስታን ያገኛል።"
:::

## 19.3. የቃላት ዝርዝር

**⟪अर्थ⟫ m.:** ዓላማ፣ ግብ፣ ትርጉም (የአንድ ቃል)፣ ሀብት፣ ንብረት፣ ሀብት። ⟪अर्थम्⟫ (አኩዛቲቭ)፣ ⟪अर्थेन⟫ (ኢንስትሩሜንታል) ከጀነቲቭ ጋር ወይም እንደ የታፑሩሻ መጨረሻ ክፍል፡ ለ... ስል፣ ለማድረግ።

⟪अर्थ⟫ በዓለማዊ እና በሃይማኖታዊ ጽሑፎች ውስጥ እንደተገለጸው ከሶስቱ የህይወት ዓላማዎች (⟪पुरुषार्थ⟫) አንዱ ነው፡

::: indent
**⟪धर्म⟫ m.:** ትክክል የሆነውን ነገር በማድረግ ዋጋን ማግኘት፣ ወይም ቢያንስ ድሀርማን ካለመከተል የሚመጣውን ክፉ ነገር ማስወገድ

**⟪अर्थ⟫ m.:** ዓላማን መሰረት ያደረገ ባህሪ፣ የሀብት ማግኛ

**⟪काम⟫ m.:** የስሜት ደስታ፣ በተለይም በጾታዊ መስክ

## 19.4. ልምምድ

**ወደ ሳንስክሪት ተርጉሙ፡**

የቫይሽያዋ ሴት፣ ልጇ የሞተባት፣ ታለቅሳለች።

ራማ ለሚጠብቀው አምላክ መስዋዕት ያቀርባል።

ገጣሚው ሀብቱን የሚመኘውን ክሻትርያ ያወድሳል።

እሳት አግኒን በመስዋዕት የማያመልከውን ሰው ቤት ያቃጥላል።

ነብር መሳይ ሰው በራማ የተሸነፉትን የክሻትርያ ተዋጊዎች ይገድላል (ተገብሮ)።
