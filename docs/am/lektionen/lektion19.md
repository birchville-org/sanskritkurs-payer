# ትምህርት 19

## 19.1. የአንድነት ሁኔታ (Relativsatz)

::: grammar-box

**ስኬማ፦**


**የአንድነት ስም -- የአንድነት ሁኔታ፣ ይህም ስሙን የያዘውን ስም ያመለክታል -- (የማመልከቻ ስም) -- ዋና ሁኔታ**

**የአንድነት ሁኔታ ከዋናው ሁኔታ በኋላ ሊቀመጥ ይችላል፣ ነገር ግን በዋናው ሁኔታ ውስጥ ሊገባ አይችልም።**

**የአንድነት ስሙ እና የማገናኛው ቃል፣ ይህም በጀርመንኛ ልዩነት በአንድነት ሁኔታ ውስጥ የሚገኝ -- በሁኔታው ውስጥ ይቀመጣሉ፣ ይህም የአንድነት ሁኔታ በሲንታክቲክስ የሚፈልገው ሁኔታ ነው። የማመልከቻው ስም በዋናው ሁኔታ በሲንታክቲክስ የሚፈልገው ሁኔታ ውስጥ ይቀመጣል።**
:::

ምሳሌዎች፦

ማስታወሻ፦ በአጠቃላይ ትክክለኛ ይዘት ያላቸው በአንድነት ሁኔታዎች ውስጥ ብዙውን ጊዜ ኦፕቲቭ ከዲኢክቲቭ ይልቅ ይጠቀማል። ስለዚህ ብዙ ከምሳሌዎቻችን በኦፕቲቭ ውስጥ ሊቀመጡ ይገባል።

**1. የሁኔታው ሰራተኛ (⟪कर्तृ⟫) በአንድነት ሁኔታ በተጨማሪ ይገለጻል፦**

::: indent
⟪यो नरः पुण्यं करोति स स्वर्गं गच्छति⟫ =  ⟪यो नरः पुण्यं करोति तेन स्वर्गं गम्यते⟫ = ⟪येन नरेण पुण्यम् क्रियते तेन स्वर्गं गम्यते⟫ u.s.w. = "ሰው ጥሩ ነገር ሲያደርግ፣ ወደ ሰማይ ይሄዳል።"
:::
**2. የዋናው ሁኔታ ቀጥተኛ ነገር (⟪कर्म⟫) በአንድነት ሁኔታ በተጨማሪ ይገለጻል፦**

::: indent
⟪यो ब्राह्मणो देवान्यजते तं देवा रक्षन्ति⟫ = "እግዚአብሔራን ብራህማኖችን ይጠብቃሉ፣ ይህም ለእነሱ እንደ ቅዳሜ ሰው ያቀርባል።"
:::
**3. የዋናው ሁኔታ ስም ተጨማሪ ማብራሪያ በአንድነት ሁኔታ ውስጥ ይገኛል፦**

::: indent
⟪ये नराः पापं कुर्वन्ति तेषां पुत्रा धनं न लभन्ते⟫ = "የሰው ልጆች ልጆች ስህተት ሲያደርጉ ሀብት አያገኙም።"
:::
**4. ተዛማጅ ስም እና ግንኙነት ቃል በጀነቲቭ ይቆማሉ (⟪षष्ठी⟫):**

::: indent
⟪यस्य नरस्य पुत्राः पापं कुर्वन्ति स न सुखवान्⟫ = "ወንድሙ ልጆቹ ሕማም ከሚያደርስበት ጊዜ ደስተኛ አይደለም።"
:::
**5. ተዛማጅ ስም እና ግንኙነት ቃል በኢንስትሩመንታሊስ ይቆማሉ (⟪तृतीया⟫):**

::: indent
⟪येन शत्रुणा ग्रामो जितस्तं द्विषन्ति⟫ = "የራሳቸውን ሕዝብ የሚያሸንፉትን ተጠላት ይጠላሉ።"
:::
**6. ተዛማጅ ስም እና ግንኙነት ቃል በአኩዜቲቭ ይቆማሉ (⟪द्वितीया⟫):**

::: indent
⟪यं नरं देवी रक्षति स सुखमाप्नोति⟫ = "እግዚአብሔር የሚያስተዳድር ወንድም ደስተኛ ይሆናል።"
:::

## 19.3. የቃላት ዝርዝር

**⟪अर्थ⟫ ስፍራ፡** ዓላማ፣ ግብ፣ ትርጉም (የአንድ ቃል)፣ ንብረት፣ ሃብት፣ ንብረት። ⟪अर्थम्⟫ (አክዩሴቲቭ)፣ ⟪अर्थेन⟫ (ኢንስትራመንታል) ከጄኔቲቭ ጋር ወይም እንደ ኋላ ክፍል በታትፑሩሳ ውስጥ፡ ለ... ምክንያት፣ ለማድረግ።

⟪अर्थ⟫ ከሦስቱ የሕይወት ዓላማዎች (⟪पुरुषार्थ⟫) አንዱ ሲሆን፣ እንደሚገለጸው በዓለምአቀፍ እና በሃይማኖታዊ ጽሑፎች ውስጥ፡

::: indent
**⟪धर्म⟫ ስፍራ፡** በሚገባ ስራ ማድረግ ወይም ቢያንስ ከዳርማ ማለፍ አለመፈጸም የሚከተለውን ምንም አይነት ስህተት መፈጸምን በመቀነስ የሚገኘውን ጥሩ ስም።

**⟪अर्थ⟫ ስፍራ፡** ዓላማ-አስተሳሰብ ያለው ባህሪ፣ የሕይወት ውድነት ማግኘት

**⟪काम⟫ ስፍራ፡** የኢንድሪያዎች ፍላጎት፣ በተለይም በሴክስ ዘርፍ
:::

## 19.4. ልምምድ

**ወደ ሳንስክሪት ተርጉሙ:**

1. ልጁ የሞተችው ቫይሻ ሴት ትብላለች።

2. ራማ ራሱን የሚጠብቀውን አምላክ ይቅዳል።

3. ፖዌት ከራሱን የሚፈልገውን ክሽትሪያን ይስቀላል።

4. እሳት የአገኘውን ገንዘብ የሚያከብር ሰውን አያከብርም።

5. የወፍ ልብስ ያለው ሰው ራማን ያሸነፉትን ክሽትሪያን ጦርተኞች ያጠፋል (ፓስቭ)።
