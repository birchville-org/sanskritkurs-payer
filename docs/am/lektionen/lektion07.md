## 7.1. የግስ ሀረግ ከቀጥታ ቁጥጥር ጋር

::: grammar-box
**ስኬማ፡**
**(ግብረኛ = kartṛ m. = ⟪कर्तृ⟫) – ቀጥታ ቁጥጥር (karman n. = ⟪कर्मन्⟫) – ግስ**

ለምሳሌ
**rāmaḥ phalaṃ khādati** = ⟪रामः फलं खादति⟫ : "ራማ ፍሬ ይበላል (ይበላል)።"
**brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो देवं यजति⟫ : "ብራህማኑ አምላክን በቅዳሜ (ለሌላ ሰው) ይከብረዋል።"
:::
ግሱ በ Parasmaipada ወይም Ātmanepada ከሆነ፣ ቀጥታ ቁጥጥሩ (**karman** n. = ⟪कर्मन्⟫) በአጠቃላይ በ **Akkusativ** (Wenfall, dvitīyā f. = ⟪द्वितीया⟫) ይገኛል።

### 7.2.1. የአኩዬቲቭ ነጠላ እና ብዙ ቁጥር ለጥያቄ እና ለማሳያ ስም-ዝርዝሮች

::: grammar-box
| || ወንድ | ሴት | ኒውትረም |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :brwho/what | ነጠላ | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |
| | ብዙ | **kān** :br⟪कान्⟫ | **kās** :br⟪कास्⟫ | **kāni** :br⟪कानि⟫ |

ቅርጾች **enam** (⟪एनम्⟫) ወዘተ. ወደ **enad** (⟪एनद्⟫) ሥር ይመለሳሉ፣ ይህም በአንዳንድ ጥራዝ ቅርጾችን ብቻ ይፈጥራል። እነዚህ ቅርጾች ከ **etad** እና ከ **idam** ቅርጾች ይልቅ፣ በዚህ የተጠቀሰው ነገር በቀድሞው አጻጻፍ ተጠቅሷል ሲባል ይጠቀማሉ።
ለምሳሌ **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं देवः⟫ | ⟪एनं यजन्ते⟫ || : "እሱ አምላክ ነው። ለእሱ ቅዳ ያቀርባሉ።"


### 7.2.2. የአኩዬቲቭ (ድምጽ-ሰጪ፣ dvitīyā f. = ⟪द्वितीया⟫ = "ሁለተኛ ጥራዝ መጨረሻ") መጠቀሚያ

::: grammar-box
አኩዬቲቭ (dvitīyā f. = ⟪द्वितीया⟫) የሚያመለክተው፡
1. በአ-ፓሲቭ ግስ-ግሰኛ ሀረግ ውስጥ፡ **ቀጥተኛ ነገር** (karman n. = ⟪कर्मन्⟫) በግስ የተገለጸውን ተግባር፡
ለምሳሌ
**devaṃ yajati** = ⟪देवं यजति⟫ : "አንድን አምላክ በቅዳ ያከብራል።"
**phalam āpnoti** = ⟪फलमाप्नोति⟫ : "ፍሬውን (ለምሳሌ የራሱን ተግባር) ያገኛል።"
2. ማለፍን፣ እንቅስቃሴን፣ መመራትን ወይም ሌላ ተመሳሳይ ነገር ወደ አንድ ነገር የሚያመለክቱ ግሶች ላይ፣ አኩዬቲቭ የእንቅስቃሴውን ዒላማ ያመለክታል፡
ለምሳሌ
**narakaṃ gacchati** = ⟪नरकं गच्छति⟫ : "ወደ ድንገተኛ ቦታ ይሄዳል።"
:::
የአኩዬቲቭ ተጨማሪ መጠቀሚያዎች በኋላ ይወያያሉ።



## 7.3. ከመጨረሻ -n ጋር ያለው ሳንዲ

::: grammar-box
**ከመጨረሻ -n፡**

1. ከገጽታ ገጽታ እና ከሬትሮፍሌክስ sparśa እና ከ **ś-** በፊት በእነዚህ ድምጾች ተዛማጅ ናዛል በመተካት ይቀየራል፡
**-n** ከ **j-, jh-, ñ-, ś-** በፊት » **-ñ**
**-n** ከ **ḍ-, ḍh-, ṇ-, ṣ-** በፊት » **-ṇ**
ለምሳሌ **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "ክሽትሪያዎችን ያሸንፋል።"
ከመጀመሪያ **ś-** በተለምዶ በ **ch-** ይተካል፡
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (ከ gurūñ śṛṇoti ጋር) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "መምህራኑን ይሰማል።" "ወደ መምህራኑ ይስማማል።"

2. በመጀመሪያ ላይ በ **l-** ሲጀምር በ **-l** በኒናሲካ (በጽሑፍ ⟪ल्⟫ በኒናሲካ ⟪ँ⟫) ይተካል፡
ለምሳሌ **paśūn + labhate** » ⟪पशूंल्लभते⟫ : "እንስሳት ያገኛል።"

3. በመጀመሪያ ላይ በሚጀምር ስለማይሆን ፓታላል፣ ሬትሮፍሌክስ ወይም ዴንታል በ **Anusvāra** + እነዚህን ገጽታዎች የሚዛመድ ጽሑፍ ይተካል፡
**-n** በ **c-, ch-** ፊት » **-ṃś**
**-n** በ **ṭ-, ṭh-** ፊት » **-ṃṣ**
**-n** በ **t-, th-** ፊት » **-ṃs**
ለምሳሌ **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : "እና አምላኾች (አኩዜቲቭ)"
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : "ነገር ግን አምላኾች (አኩዜቲቭ)"

4. ከአጭር ቃላት በስተቀር (እንደሚከተለው ይመልከቱ) በሁሉም ሌሎች ሁኔታዎች ውስጥ የመጨረሻው **-n** ሳይቀየር ይቆያል።
:::

## 7.4. ኒውትራም (napuṃsaka n. = ⟪नपुंसक⟫)

::: grammar-box
**በኒውትራም ውስጥ ለኖሚናቲቭ (prathamā) እና አኩዜቲቭ (dvitīyā) ቅርጾች ተመሳሳይ ናቸው።**
:::
### 7.4.1. በ-a የሚጠናቀቁ የኒውትራም ስብስቦች

::: grammar-box
**የኖሚናቲቭ / አኩዜቲቭ ነጠላ መጨረሻ፡ -m**
ለምሳሌ **phala** n. = ⟪फल⟫ = "ፍሬ": ኖም. / አክ. ነጠላ **phalam** = ⟪फलम्⟫
**የኖሚናቲቭ / አኩዜቲብ ብዛት መጨረሻ፡ -āni**
ለምሳሌ **phala** n. = ⟪फल⟫: ኖም. / አክ. ብዛት **phalāni** = ⟪फलानि⟫
:::

## 7.5. አተማቲክ ፕሬዝንት ክፍሎች

5ኛው የፕሬዝንት ክፍል የተባለውን አተማቲክ ፕሬዝንት ስብስብ ይፈጥራል፣ ማለትም የፕሬዝንት ስብስቡ እንደ ተማቲክ የፕሬዝንት ክፍሎች (1ኛ፣ 4ኛ፣ 6ኛ፣ 10ኛ ክፍል) በ "ተማቲክ ቃላት" **-a** አይጠናቀቅም።

::: grammar-box
**አተማቲክ የፕሬዝንት ክፍሎች የስብስብ ልዩነት አላቸው፣ ማለትም ሁለት የፕሬዝንት ስብስብ ቅርጾች አሉ፡**
1. **ጠንካራ ስብስብ**: ከፍተኛ ደረጃ (በጣም አልፎ አልፎ ማራዘም ደረጃ)
2. **ደካማ ስብስብ**: ዝቅተኛ ደረጃ

**የጠንካራው ሥር ይቆማል፡**
