## 30.2. የኦፕታቲቭ አጠቃቀም (⟪लिङ्⟫)

ኦፕታቲቩ ጥቅም ላይ ይውላል፡

::: grammar-box

*   **ምኞትን**

*   **ለስለስ ያለ ትዕዛዝን**

**(በዚህ ጊዜ ኦፕታቲቭ - ⟪लिङ्⟫ - ከኢምፔራቲቭ - ⟪लोट्⟫ - ጋር ይደራረባል)**

::: indent

:::
::: grammar-box
**2. አንድ ነገር እንደ**

:::
::: grammar-box
**3. ከምኞት ገላጭ (Optativ) ጋር ያሉ አንጻራዊ ዓረፍተ ነገሮች አንዳንድ ጊዜ "አንድ ሰው ... ቢያደርግ" የሚል ትርጉም አላቸው።**
:::
ምሳሌ፦

::: indent

## 30.3. የ3ኛ መደብ ነጠላ እና ብዙ ቁጥር ሁለተኛ ደረጃ ቅጥያዎች

ምኞት ገላጭ (⟪लिङ्⟫)፣ ያልተጠናቀቀ ያለፈ ጊዜ (⟪लङ्⟫)፣ አኦሪስት (⟪लुङ्⟫)፣ ፕሬካቲቭ (⟪आशिर्लिङ्⟫) እና ሁኔታዊ (Konditionalis) ሁለተኛ ደረጃ ቅጥያዎች የሚባሉትን ይጠቀማሉ፦
