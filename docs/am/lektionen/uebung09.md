# ትምህርት 9

ሀ) የሚከተሉትን ቃላት ሊኖሯቸው የሚችሉ ትርጉሞችን ይወስኑ፡-

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. ከብራህማን ጋር ተመሳሳይነት ያለው = ደካማ ብራህማን

2\. mati ⟪मति⟫ : f. አስተሳሰብ

3\. śravaṇa ⟪श्रवण⟫ : n. ጆሮ

4\. dhenuka ⟪धेनुक⟫ : m. (የፆታ ግንኙነት) እንደ አንበሳ አይነት

5\. jayaka ⟪जयक⟫ : 3 ድል ያደረገ

6\. rakṣikā ⟪रक्षिका⟫ : f. ጠባቂ፣ ማጥበቢያ

7\. karṣaka ⟪कर्षक⟫ : 3 የሚያረስ ; m. ገበሬ

8\. kleśa ⟪क्लेश⟫ : m. መቃብር

9\. nāyikātva ⟪नायिकात्व⟫ : n. የፍቅር ጓደኛ ሁኔታ

10\. tantraka ⟪तन्त्रक⟫ : 3 (ቅርብ) ከውሽት ሰንሰለት / ከውሽት ማሽን የመጣ = አዲስ የተሰራ

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : ዳንሻ

12\. naraka ⟪नरक⟫ : m. ገሃነም

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. ጌታ መሆን

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. ፈጣሪ

17\. kopa ⟪कोप⟫ : m. ግርዶሽ

18\. veśaka ⟪वेशक⟫ : 3 የሚገባ

19\. darśaka ⟪दर्शक⟫ : 3 የሚያየ

20\. kopaka ⟪कोपक⟫ : 3 በቀላሉ ግርዶሽ የሚያወርድ፣ በፍጥነት ግርዶሽ የሚያወርድ

ለ) ይተርጉሙ፡-

1\. ሁሉንም ሁለጊዜ የተወለዱት ሰዎች ኃላፊነት፡-

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

(Yājñavalkyadharmaśāstra I, 118)

ቅዳሽ፣ የቬዳ ጥናት፣ ስጦታ መስጠት።

2\. የብራህማን ልዩ ኃላፊነት፡-

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

(Gautamadharmasūtra X,2)

ማስተማር፣ በመመሪያ መሰረት ቅዳሽ ማቅረብ፣ ስጦታ መቀበል።

3\. የክሽትሪያ ልዩ ኃላፊነት፡-

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं सर्वभूतानाम्⟫

(sarvabhūtānām = Genetiv (Wesfall): "ሁሉንም ፈጠራዎች")

(Gautamadharmasūtra X,7)

ሁሉንም ፈጠራዎች መጠበቅ።

4\. የቫይሳ የተለየ ሚና፡

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(ከጋውታማዳርማሱትራ X,49)

ግብርና፣ ንግድ፣ የእንስሳት ማሳደግ እና ገንዘብ መቀበል።

5\. የሱድራ ሚና፡

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं शुश्रूषा वार्त्त्ता कारुकुशीलवकर्म च⟫

4\. የቫይሳ የተለየ ሚና፡

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(ከጋውታማዳርማሱትራ X,49)

ግብርና፣ ንግድ፣ የእንስሳት ማሳደግ እና ገንዘብ መቀበል።

5\. የሱድራ ሚና፡

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं शुश्रूषा वार्त्त्ता कारुकुशीलवकर्म च⟫

(ከካውቲሊያ-ርታሻስትራ 1.3.8.)

ማብራሪያ፡
dvijātīnām = Genetiv (Wesfall) Plural zu dvijāti (übersetzen Sie hier: "gegenüber den Zweimalgeborenen")

kārukuśīlavakarma በፊተኛው ክፍል ድቫንድቫ (kārukuśīlava) ያለው ታትፑሩሻ ነው (Kielhorn)። karma = Nom. sg. ከ karman n. «ተግባር፣ ሥራ፣ ካርማ» ከሥሩ kṛ 8 U)። «የ... ተግባር / ሥራ» ተብሎ ይተረጎማል።

ለሁለት ጊዜ ለተወለዱት መታዘዝ፣ የሕይወት መተዳደሪያ ሥራዎች፣ የእጅ ባለሙያነት ወይም ተጓዥ ተዋናይነት ሥራ (Kielhorn)።

6\. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः पाशुपाल्यं वणिज्या च वार्त्ता⟫

(ከካውቲሊያ-ርታሻስትራ 1.4.1.)

ኢኮኖሚ ግብርና፣ የእንስሳት ማሳደግ እና ንግድ ነው።
