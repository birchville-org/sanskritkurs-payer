# ትምህርት 2


## 2.1. የስም ሀብት (Nominalsatz)

::: grammar-box
**ስኬማ፡ ገለጻ-ስም - ግራኝ**

ለምሳሌ፡ devo viṣṇuḥ = ⟪देवो विष्णुः⟫ = "Viṣṇu አምላክ ነው።"
:::
የተግባር ቃል (verbale Kopula) ("ነው"፣ "ነዋሉ"፣ "ኔ ነኝ"፣ "አንተ ነህ"፣ "እናንተ ናችኋል") አያስፈልግም፣ ነገር ግን አንዳንዴ ሊኖር ይችላል።

**የተወሳኪ ቃል (Artikel) የለም**፡ **devaḥ** -- ⟪देवः⟫ "አምላኩ" ወይም "አንድ አምላክ" ማለት ይችላል።

በስንስክርት ምንም እንኳን የሀብት ቅደም ተከተል በጣም ነፃ ቢሆንም (በተለይ በመዝሙሮች ውስጥ)፣ የስም ሀብትን (Nominalsatz) በሚተርጉም ጊዜ ሁልጊዜ በመጀመሪያ ደረጃ ከላይ ባለው መደበኛ ስኬማ መሠረት ባለው ትርጉም ማሰብ አለብን።

በስም ሀብት (Nominalsatz) ውስጥ ግራኝ በመነጨ (Nominativ) ይቀመጣል (የመጀመሪያው ሁኔታ = **prathamā** f. = ⟪प्रथमा⟫)። ገለጻ-ስም ከግራኝ በቁጥር እና በሁኔታ ይስማማል፤ ገለጻ-ስም ተዋሕዶ (Adjektiv) ከሆነ በጾታም ይስማማል።


## 2.2. ስለ ቅርጽ-መቀየር (Deklination)

በስንስክርት ውስጥ የሚከተሉት አሉ፡

**ሦስት ቁጥሮች** (Numeri) = **vacana** n. -- ⟪वचन⟫
ብድር (Singular) = **ekavacana** n. -- ⟪एकवचन⟫
ሁለት (Dual) = **dvivacana** n. -- ⟪द्विवचन⟫
ብዙ (Plural) = **bahuvacana** n. -- ⟪बहुवचन⟫
**ሦስት ጾታዎች** (Genera) = **liṅga** n. / **vyakti** f. -- ⟪लिङ्ग⟫ / ⟪व्यक्ति⟫
ወንድ (Maskulinum) = **puṃs** m. -- ⟪पुंस्⟫
ሴት (Femininum) = **strī** f. -- ⟪स्त्री⟫
ጾታ አልበለ (Neutrum) = **napuṃsaka** n. -- ⟪नपुंसक⟫
**ስምንት ሁኔታዎች** (Kasus) = **sup** -- ⟪सुप्⟫ (= የሁኔታ መጨረሻዎች)

ስለ ቅርጽ-መቀየር የሁኔታ መጨረሻዎች (**sup** = ⟪सुप्⟫) ወደ "የስም ግንድ" (Nominalstamm) ይጨመራሉ (የስም ቅርጽ ሁኔታ መጨረሻዎችን ያለ)።

ምሳሌ፡ **devas** = ⟪देवस्⟫ (አባላዊ ብዜት ወንድ) "እግዚአብሔር/የተለመደ እግዚአብሔር" = **deva-** -- ⟪देव⟫- (የስም መሰር) + **-s** -- -⟪स्⟫ (የግስ መወያ).

በሳንስክርት ቃል መዝገበ-ቃላት ውስጥ ስሞች በ **የመደበኛ መሰር** ይቀርጻሉ፡
**deva** ወ. -- ⟪देव⟩ ወ. (ወንድ)
**vacana** ነ. -- ⟪वचन⟩ ነ. (ነጭ)
**vyakti** ሴ. -- ⟪व्यक्ति⟩ ሴ. (ሴት)


## 2.3. አባላዊ ብዜት

**አባላዊ ብዜት = prathamā ekavacanam = ⟪प्रथमा एकवचनम्⟫**

::: grammar-box
**አባላዊ ብዜት በ -s ያልፃል = -⟪स्⟫ ወይም በመደበኛነት የለው።**
:::
### 2.3.1. አባላዊ ብዜት በ -s

የተከለሉ መስመሮች፣ በአናት ላይ የተዘጉ ቃላትን ያመለክታል በ **-s**፡

::: grammar-box
**ወንድ በ -a፡** ምሳሌ። deva ወ. = ⟪देव⟫ "እግዚአብሔር" -- አ. ቁ.፡ devas = ⟪देवस्⟫
**ወንድ በ -i፡** ምሳሌ። kavi ወ. = ⟪कवि⟫ "አዋቂ" -- አ. ቁ.፡ kavis = ⟪कविस्⟫
**ወንድ በ -u፡** ምሳሌ። guru ወ. = ⟪गुरु⟫ "አስተማሪ" -- አ. ቁ.፡ gurus = ⟪गुरुस्⟫
:::

## 2.4. ሳንዲ -- ⟪सन्धि⟫

በሳንስክርት ውስጥ የአንድ ቃል መጨረሻ በቀጣይ ቃል ላይ ያለውን መነሻ በመከተል ይቀየራል። ይህን ሁኔታ **Sandhi** (ወ.) = ⟪सन्धि⟫ ("መጣበቅ") ይላል።

### 2.4.1. በመጨረሻ ላይ ያለ -s Sandhi

እንዲሁም ማየት፡-

> **Payer, Alois (1944–):** በመጨረሻ ላይ ያለ -s Sandhi. -- (የሳንስክርት ቁጥጥር). -- URL: http://www.payer.de/sanskritmaterialien/ssandhi.htm

በመጨረሻ ላይ ያለ **-s**፡-

**በአብራር መጨረሻ** (የዓለም መግቢያ) ወደ **Visarga (-ḥ)** ይቀየራል፡-
**devas** = ⟪देवस्⟫ » **devaḥ** = ⟪देवः⟫
**kavis** = ⟪कविस्⟫ » **kaviḥ** = ⟪कविः⟫
**gurus** = ⟪गुरुस्⟫ » **guruḥ** = ⟪गुरुः⟫

**በድምጽ የሌላቸው ረዥም ድምፆች ቅድመ**:
በ **k, kh, p, ph** እና **ś, ṣ, s**: ወደ **Visarga (-ḥ)** ይቀየራል
**devas + śivaḥ** » **devaḥ śivaḥ** = ⟪देवः शिवः⟫ ("ሺቫ አምላክ ነው")
በ **c, ch**: ወደ **-ś** ይቀየራል
በ **ṭ, ṭh**: ወደ **-ṣ** ይቀየራል
በ **t, th**: **-s** ይቆያል
**sādhus + caitanyas** » **sādhuś caitanyaḥ** = ⟪साधुश्चैतन्यः⟫ ("ቻይተንያ ቅዱስ ነው")

**በድምጽ ያላቸው ረዥም ድምፆች ቅድመ**:
ከ Non-a ረጅም ድምፆች በኋላ: ወደ **-r** ይቀየራል
**kavis + Māghas** » **kavir māghaḥ** = ⟪कविर्माघः⟫ ("ማጋ ፓይተን ነው")
ከ Non-a ረጅም ድምፆች በኋላ **r-** ቅድመ: **-s** ይጠፋል፣ ረጅም ድምፁ ይራዘማል።
**gurus + rāmas** » **gurū rāmaḥ** = ⟪गुरू रामः⟫ ("ራማ መምህር ነው")
በ **a-**: **-as**
በድምጽ ያላቸው ኮንሶናንት/a ቅድመ: ወደ **-o** ይቀየራል (በጀምሮ a ይጠፋል » ⟪ऽ⟫)
**devas viṣṇus** » **devo viṣṇuḥ** = ⟪देवो विष्णुः⟫
**devas agnis** » **devo 'gniḥ** = ⟪देवो ऽग्निः⟫
በሌሎች ረጅም ድምፆች ቅድመ: ወደ **-a** (Hiatus)
**devas + indras** » **deva indraḥ** = ⟪देव इन्द्रः⟫


## 2.5. ቃላት ዝርዝር

**deva** m. -- ⟪देव⟫ : ሰማያዊ፣ አምላክ; ንጉስ፣ ነገሥት።

**īśvara** m. -- ⟪ईश्वर⟫ : ባለቤት፣ አስተዳዋሪ፣ አምላክ (monotheistic)።

**brāhmaṇa** m. -- ⟪ब्राह्मण⟫ : ብራህማን (የጽናት ማኅበረሰብ)።

**kṣatriya** m. -- ⟪क्षत्रिय⟫ : ክሽትሪያ (የንጉስ እና የወታደር ማኅበረሰብ)።

**vaiśya** m. -- ⟪वैश्य⟫ : ቫይሲያ (የምግብ እና የንግድ ማኅበረሰብ)።

**śūdra** m. -- ⟪शूद्र⟫ : ሱድራ (የአገልግሎት ማኅበረሰብ)።

**dvija** m. -- ⟪द्विज⟫ : "በሁለት ጊዜ የተፈጠረ" (የከፍተኛ ሶስት ደረጃዎች ተቀባይ: Brāhmaṇa, Kṣatriya, Vaiśya).

**varṇa** m. -- ⟪वर्ण⟫ : ቀለም፣ የልደት ደረጃ (ማንቀሳቀስ)።

አራት ደረጃዎች (**varṇa** m.) ብዙ ጊዜ ከካስት ጋር ይቀላቀላሉ። ነገር ግን አራት ደረጃዎች -- ከካስቶች ጋር በተለየ መልኩ -- ልዩ የሆነ ኢንዲያዊ አይደሉም፤ በአውሮፓ ውስጥም (እስከ የመጀመሪያው ዓለም ጦርነት እስከ) የደረጃ ትእዛዝ ነበርን፣ እንደሚከተለው ምስል ከ15ኛው መቶ ዓመት ያሳያል፡

የሙያ ደረጃዎች ሊፈጠሩ ይችላሉ
ሀ) በመጀመሪያ ደረጃ፣ በራሳቸው የሙያ ሕይወት አመራር፣ በተለይም በ**ስራ** (**የሕይወት አመራር ወይም የስራ ሙያ**) መልክ፣
ለ) በሁለተኛ ደረጃ፣ በወርሃዊ ቅዳሜነት፣ በተሳካ የብልጽግና ጥያቄዎች በሙያ **የመውለድ** (**የልደት ሙያ**) ኃይል፣
ሐ) በሙያ **በመቆጣጠር** የፖለቲካ ወይም ሃይማኖታዊ የመንግሥት ኃይሎችን እንደ ሞኖፖል (**የፖለቲካ ወይም ሃይማኖታዊ ሙያ**) መልክ።

የልደት ሙያ እድገት በተለምዶ የልደታዊ ሞኖፖል በአንድ ቡድን ወይም በተሻለ ግለሰብ ነው። እያንዳንዱ የተረጋገጠ ሞኖፖል በዕድሎች፣ በተለይም [በ] የመንግሥት [ኃይል ወይም ማስተዋወቅ] ዕድሎች፣ ሙያን ለመፍጠር ያደርጋል። እያንዳንዱ ሙያ ሞኖፖል በመንግሥት ኃይሎች እና ማስተዋወቅ ዕድሎች ሞኖፖል ለመፍጠር ያደርጋል።

ማስተዋወቅ ክፍሎች በማኑፋክቸር ማስተዋወቅ ኢኮኖሚ ውስጥ ሲያድጉ፣ ሙያዎች በተለይም በሞኖፖል ማስተዋወቅ ወይም በፌውዳል ወይም ሙያዊ ባለቤትነት የሚፈልጉ ማስተዋወቅ ይፈጠራሉ።

»**ሙያዊ**« ማለት አንድ ማኅበረሰብ በሙያ ይጠራል፣ »**ክፍለ-ማኅበረሰብ**« ማለት በክፍል ይጠራል። «ሙያ» ከ«ክፍል» ጋር በተለይ «ማህበራዊ» ክፍል ይቀርባል፣ «ማስተዋወቅ ክፍል» በጣም ይርቃል። ሙያዎች በተለይም በማስተዋወቅ ክፍሎች ይፈጠራሉ።

እያንዳንዱ ሙያዊ ማኅበረሰብ በተለምዶ፣ በሕይወት አመራር ህጎች የተደረደረ ነው፣ ስለዚህ በኢኮኖሚያዊ አይፕራሽናል የምስክርነት ሁኔታዎችን ያመጣል እና በሞኖፖል ማስተዋወቅ እና በራሱ የማስተዋወቅ አቅም ነፃ ጥበቃን በማስወገድ ነፃ ማኑፋክቸርን ያስተዋውቃል።
