# ትምህርት 2


## 2.1. የስም ሀብት ሀብት

::: grammar-box
**ስኬም: ፕሪዲኬትስክር - ሰብጀክት**

ለምሳሌ devo viṣṇuḥ = ⟪देवो विष्णुः⟫ = "Viṣṇu አምላክ ነው።"
:::
የተግባር ኮፕላ ("ነው"፣ "ነው"፣ "ነኝ"፣ "ነህ"፣ "ነው") አስፈላጊ አይደለም፣ ነገር ግን ምናልባት ሊከሰት ይችላል።

**ምንም አይነት ስም አልባ** የለም፡ **devaḥ** -- ⟪देवः⟫ "አምላኩ" ወይም "አምላክ" ማለት ሊሆን ይችላል።

በሳንስክሪት ውስጥ የሀብት አቀማመጥ በጣም ነፃ ቢሆንም (በተለይ በግጥሞች ውስጥ)፣ የስም ሀብትን ለመተርጎም ሁልጊዜ በመጀመሪያ ደረጃ ከላይ ከተጠቀሰው መደበኛ ስኬም ጋር በሚስማማ መተርጎም ላይ ማሰብ አለብን።

በስም ሀብት ውስጥ ሰብጀክቱ በኖሚናቲቭ (የመጀመሪያ ጉዳይ = **prathamā** f. = ⟪प्रथमा⟫) ውስጥ ይገኛል። ፕሪዲኬትስክር ከሰብጀክት ጋር በቁጥር እና በጉዳይ ይስማማል፤ ፕሪዲኬትስክር አዲጀክቲቭ ከሆነ በፆታውም ይስማማል።


## 2.2. ስለ ዴክሊኔሽን (የስሞች መቀየር)

በሳንስክሪት ውስጥ፡-

**ሦስት ቁጥሮች** (የቁጥር ቅርጾች) = **vacana** n. -- ⟪वचन⟫
ሲንጉላር (አንድ ቁጥር) = **ekavacana** n. -- ⟪एकवचन⟫
ዱአል (ሁለት ቁጥር) = **dvivacana** n. -- ⟪द्विवचन⟫
ፕላራል (ብዙ ቁጥር) = **bahuvacana** n. -- ⟪बहुवचन⟫
**ሦስት ገነቦች** (ግራማቲካዊ ፆታዎች) = **liṅga** n. / **vyakti** f. -- ⟪लिङ्ग⟫ / ⟪व्यक्ति⟫
ማስኩሊን (ወንድ) = **puṃs** m. -- ⟪पुंस्⟫
ፌሚኒን (ሴት) = **strī** f. -- ⟪स्त्री⟫
ኒውትራል (የተፈጥሮ) = **napuṃsaka** n. -- ⟪नपुंसक⟫
**ስምንት ካሳሶች** (ጉዳዮች) = **sup** -- ⟪सुप्⟫ (= ካሳ ማጠናቀቂያዎች)

ለዴክሊኔሽን ካሳ ማጠናቀቂያዎች (**sup** = ⟪सुप्⟫) ወደ "የስም ስታምፕ" (የስም ቅርጽ ከካሳ ማጠናቀቂያዎች በስተቀር) ይገባሉ።

ምሳሌ፡ **devas** = ⟪देवस्⟫ (Nominativ Singular Maskulinum) "der/ein Gott" = **deva-** -- ⟪देव⟫- (Nominalstamm) + **-s** -- -⟪स्⟫ (Kasusendung)።

በሳንስክሪት ቃላት መዝገበ-ቃላት (Sanskritwörterbücher) ውስጥ ስሞች (Nomina) በ**Nominalstamm** ይቀርባሉ፡
**deva** m. -- ⟪देव⟫ m. (maskulin)
**vacana** n. -- ⟪वचन⟫ n. (neutrum)
**vyakti** f. -- ⟪व्यक्ति⟫ f. (femininum)


## 2.3. Der Nominativ Singular

**Nominativ Singular = prathamā ekavacanam = ⟪प्रथमा एकवचनम्⟫**

::: grammar-box
**Der Nominativ Singular endet auf -s = -⟪स्⟫ bzw. ist endungsfrei።**
:::
### 2.3.1. Nominativ Singular auf -s

Folgende Nominalstämme, die mit einem Vokal enden, bilden den Nominativ Singular auf **-s**፡

::: grammar-box
**ተባዕታይ በ -a የሚያበቃ:** ምሳሌ፡ deva m. = ⟪देव⟫ «አምላክ» -- Nom. sg.: devas = ⟪देवस्⟫ (Kielhorn)
**ተባዕታይ በ -i የሚያበቃ:** ምሳሌ፡ kavi m. = ⟪कवि⟫ «ገጣሚ» -- Nom. sg.: kavis = ⟪कविस्⟫
**ተባዕታይ በ -u የሚያበቃ:** ምሳሌ፡ guru m. = ⟪गुरु⟫ «መምህር» -- Nom. sg.: gurus = ⟪गुरुस्⟫
:::

## 2.4. Sandhi -- ⟪सन्धि⟫

Der Auslaut eines Wortes richtet sich im Sanskrit auch nach dem Anlaut des darauffolgenden Wortes. Diese Erscheinung nennt man **Sandhi** (m.) = ⟪सन्धि⟫ ("Verbindung")።

### 2.4.1. Sandhi von auslautendem -s

Siehe auch die Übersicht፡

> **Payer, Alois (1944–):** Sandhi (Kielhorn). -- URL: http://www.payer.de/sanskritmaterialien/ssandhi.htm

የመጨረሻው **-s** (Sandhi) (Kielhorn)፡

**በፍጹም መጨረሻ** (የዐረፍተ ነገር መጨረሻ) ወደ **Visarga (-ḥ)** ይቀየራል (Kielhorn)፡
**devas** = ⟪देवस्⟫ » **devaḥ** = ⟪देवः⟫
**kavis** = ⟪कविस्⟫ » **kaviḥ** = ⟪कविः⟫
**gurus** = ⟪गुरुस्⟫ » **guruḥ** = ⟪गुरुः⟫

**ከድምጺ የሌላቸው ቃላት በፊት**:
ለ **k, kh, p, ph** እና **ś, ṣ, s**: ወደ **Visarga (-ḥ)** ይቀየራል
**devas + śivaḥ** » **devaḥ śivaḥ** = ⟪देवः शिवः⟫ ("ሺቫ አምላክ ነው")
ለ **c, ch**: ወደ **-ś** ይቀየራል
ለ **ṭ, ṭh**: ወደ **-ṣ** ይቀየራል
ለ **t, th**: **-s** ይቆያል
**sādhus + caitanyas** » **sādhuś caitanyaḥ** = ⟪साधुश्चैतन्यः⟫ ("ቻይተንያ ቅዱስ ነው")

**ከድምጺ ያላቸው ቃላት በፊት**:
ከ Non-a ቁምጥናዎች በኋላ: ወደ **-r** ይቀየራል
**kavis + Māghas** » **kavir māghaḥ** = ⟪कविर्माघः⟫ ("ማጋ ፓይተን ነው")
ከ Non-a ቁምጥናዎች በኋላ ለ **r-**: **-s** ይጠፋል፣ ቁምጥናው ይረዝማል።
**gurus + rāmas** » **gurū rāmaḥ** = ⟪गुरू रामः⟫ ("ራማ መምህር ነው")
ለ **a-**: **-as**
ከድምጺ ያላቸው ቁምጥናዎች/a በፊት: ወደ **-o** ይቀየራል (መጀመሪያ a ይጠፋል » ⟪ऽ⟫)
**devas viṣṇus** » **devo viṣṇuḥ** = ⟪देवो विष्णुः⟫
**devas agnis** » **devo 'gniḥ** = ⟪देवो ऽग्निः⟫
ለሌሎች ቁምጥናዎች: ወደ **-a** ይቀየራል (Hiatus)
**devas + indras** » **deva indraḥ** = ⟪देव इन्द्रः⟫


## 2.5. ቃላት ዝርዝር

**deva** m. -- ⟪देव⟫ : ሰማያዊ፣ አምላክ; ንጉስ፣ ነገሥት።

**īśvara** m. -- ⟪ईश्वर⟫ : ባለቤት፣ አስተዳዳሪ፣ አምላክ (monotheistic)።

**brāhmaṇa** m. -- ⟪ब्राह्मण⟫ : ብራህማን (የጽናት ደረጃ)።

**kṣatriya** m. -- ⟪क्षत्रिय⟫ : ክሽትሪያ (የንጉስ እና የኮማንድ ደረጃ)።

**vaiśya** m. -- ⟪वैश्य⟫ : ቫይሲያ (የምግብ እና የንግድ ደረጃ)።

**śūdra** m. -- ⟪शूद्र⟫ : ሹድራ (የአገልግሎት ደረጃ)።

**dvija** m. -- ⟪द्विज⟫ : "በሁለት ጊዜ የተወለደ" (የሦስቱ ከፍተኛ ደረጃዎች ማስተዋወቂያ: Brāhmaṇa, Kṣatriya, Vaiśya).

**varṇa** m. -- ⟪वर्ण⟫ : ቀለም፣ የልደት ደረጃ (ጥረት)።

አራቱ ደረጃዎች (**varṇa** m.) ብዙ ጊዜ ከካስት ጋር ይቀላቀላሉ። ነገር ግን አራቱ ደረጃዎች -- ከካስት ጋር በተለየ ሁኔታ -- ልዩ ለሆነ ለህንድ ነገር አይደሉም፤ በአውሮፓም እንዲሁ (እስከ የመጀመሪያው ዓለም ጦርነት ድረስ በክፍል) የደረጃ ስርዓት ነበረን፣ እንደሚከተለው ከ15ኛው ክፍለ ዘመን ስዕል ያረጋገጠው፡

ለ) በሁለተኛ ደረጃ፣ በወርሃዊ ባህሪ ያለው፣ በተሳካ የሙሉ ማህበረሰብ ጥያቄዎች ኃይል በሙሉ ማህበረሰብ **የመወለድ** (**የመወለድ ምድቦች**)፣
ሐ) በሙሉ ማህበረሰብ **የመያዝ** የፖለቲካ ወይም የሃይማኖታዊ ሥልጣን እንደ ሞኖፖሊዎች (**የፖለቲካ ወይም የሃይማኖታዊ ምድቦች**)።

የመወለድ ምድብ ልማት በተለምዶ የ(ወርሃዊ) የመያዝ ልምድ ከፍተኛ ማህበረሰብ ወይም ለተሻለ ግለሰብ ነው። ማንኛውም የተረጋጋ የመያዝ ልምድ ከፍተኛ ማህበረሰብ፣ በተለይም [ከ] ሥልጣን [ወይም የሙያ] ልምዶች፣ ወደ ምድብ ልማት ለመሄድ ይፈልጋል። ማንኛውም ምድብ ልማት ወደ ሞኖፖሊዊ የሥልጣን እና የሙያ ልምዶች ለመሄድ ይፈልጋል።

የሙያ ምድቦች በገበያ ላይ የተመሰረተ ኢኮኖሚ ላይ ሲያድጉ፣ ምድቦች በተለይም በሞኖፖሊዊ ሊቱርጂክ ወይም በፌደራል ወይም በሙሉ ማህበረሰብ ፓትሪሞኒያል የፍላጎት ማሟሊያ ላይ ይፈጠራሉ።

»**ሙሉ ማህበረሰብ**« ማህበረሰብ ምድቦችን በተለይም በሙሉ ማህበረሰብ ማህበረሰብ ሲሆን፣ »**ምድብ**« ማህበረሰብ ምድቦችን በተለይም በምድብ ሲሆን። ከምድቦች ጋር የሚዛመደው የ**ማህበረሰብ** ምድብ ከ**የሙያ** ምድብ በጣም ርቆ ይገኛል። ምድቦች ብዙ ጊዜ በባለሥልጣን ምድቦች ይፈጠራሉ።

ማንኛውም ሙሉ ማህበረሰብ ማህበረሰብ በሕይወት አሰሳ ህጎች የተደራጀ ነው፣ ስለዚህ ኢኮኖሚያዊ ራሲዮናል ያልሆነ የምግብ ሁኔታዎችን ይፈጥራል፣ እና በዚህ መንገድ በሞኖፖሊዊ የመያዝ ልምዶች እና በራሱ የሙያ ችሎታ ነፃ ማስተዳደርን በማስወገድ ነፃ ገበያ ልማትን ያግዳል።
