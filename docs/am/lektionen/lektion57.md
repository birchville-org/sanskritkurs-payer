# ትምህርት 57

## 57.1. ኦሪስት 4፡ s-ኦሪስት

::: grammar-box
**s-ኦሪስት ከብዙ ⟪अनिट्⟫-ዱምር ጋር ይፈጠራል፣ እነሱ ሌላ ኦሪስት ቅርጽ ብቻ ካልሆነ። ምርጫዊ ⟪अनिट्⟫-ዱምር በአጠቃላይ ይህን ወይም iṣ-ኦሪስት ለመፍጠር ይፈቀዳል። እንዲሁም ⟪अनिट्⟫-ዱምር፣ ⟪परस्मैपद⟫ን በ1ኛ፣ 2ኛ ወይም 6ኛ ቅርጽ ኦሪስት ከሚፈጥሩ፣ ⟪आत्मनेपद⟫ን በs-ኦሪስት መሰረት ይፈጥራሉ።**

**መፍጠር፡ ኦግመንት + ዱምር + s + አተማቲክ ሁለተኛ መደምደሚያ**
