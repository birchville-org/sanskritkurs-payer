# ትምህርት 50

## 50.1. የስም ልማት፡ መደበኛ ማሳደግ

::: grammar-box

**መደበኛ ማሳደግ በሳንስክሪት በ⟪तद्धित⟫-ተሰባሪዎች ይከናወናል**
* **-⟪तर⟫ (ጾታ፡ ⟪तरा⟫) በ"ምንጭ"**
* **⟪तम⟫ (ጾታ፡ ⟪तमा⟫) በ"ጫፍ"**

**እነዚህ ተሰባሪዎች ለቁጥር ቃላት በወንድ ስም ስር ላይ ይጨመራሉ። ስም ለስም ስር ለማሳደግ በደካማ ስር ላይ ይጨመራሉ፣ እነሱም እንደ ይገኛሉ ከመጨረሻው -su የቦታ (⟪पञ्चमी⟫) ብዛት።**

:::

::: media

![](/images/lekt5007.webp)

ስዕል፡ ⟪लोकस्योत्तमो गिरिः सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = ሙንት ኤቨረስት
(ምስል ምንጭ፡ [ዝርዝር](/am/licenses#lekt5007))

:::

::: grammar-box

**ትርጉም፡**

**"ምንጭ" ማለት፣ ምንም የተወዳደረ ነገር ካልተገለጸ፡ "በቂ፣ በጣም፣ ለመሆን፡"**

:::

::: indent

ለምሳሌ፡ ⟪सुचितर⟫ 3 "በቂ ጽድቅ"፣ "በጣም ጽድቅ"፣ "ለመሆን ጽድቅ"

:::

**የተወዳደረ ነገር ካልተገለጸ፣ ይህ በአብላጭ (⟪पञ्चमी⟫) ይገኛል። ምንጭ + አብላጭ ከጀርመንኛ "ከ" ጋር የሚዛመድ ማሳደግ ነው።**

::: indent

ለምሳሌ፡ ⟪देवदत्ताद्रामो धीमत्तरः⟫ = ቃላት፡ "ከደቫዳታ ሲታይ ራማ ምርጥ ነው" = "ራማ ከደቫዳታ ምርጥ ነው"

:::

**"ጫፍ" ማለት፣ ምንም የተወዳደረ ነገር ካልተገለጸ፡ "በጣም፣ በጣም፡"**

::: indent

ለምሳሌ፡ ⟪सत्तम⟫ 3 (ወደ ⟪सन्त्⟫) "በጣም ጥሩ፣ በጣም ጥሩ"

:::

**የተወዳደረ ነገር ካልተገለጸ፣ ይህ በጄኔቲቭ (⟪षष्ठी⟫) ("ከ"፣ "በመካከል") ይገኛል እና ጫፍ ከጀርመንኛ ጫፍ (ከፍተኛ ደረጃ) ጋር ይዛመዳል፡**

::: indent

ለምሳሌ፡ ⟪द्विजानां सत्तमः⟫ = "የሁለት ጊዜ የተወለዱት ምርጥ"

:::

**የ -⟪तर⟫ እና -⟪तम⟫ ተራራዎች ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ ከተለምዶ
