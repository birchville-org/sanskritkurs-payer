# ትምህርት 50

## 50.1. የስም ምስረታ፡ መደበኛ ንጽጽር

::: grammar-box
**በሳንስክሪት መደበኛ ንጽጽር የሚፈጠረው በ⟪तद्धित⟫ ቅጥያዎች ነው**
* **-⟪तर⟫ (ሴት፡ ⟪तरा⟫) በ"ንጽጽራዊ" ደረጃ**
* **⟪तम⟫ (ሴት፡ ⟪तमा⟫) በ"ልዕለታዊ" ደረጃ**

**እነዚህ ቅጥያዎች በቅጽሎች ላይ ከወንድ ጾታ ግንድ ጋር ይያያዛሉ። የሥር ለውጥ ባላቸው ስሞች ላይ፣ ከብዙ ቁጥር ሎካቲቭ (⟪पञ्चमी⟫) -su መጨረሻ በፊት እንዳለው ዓይነት ቅርጽ ካለው ደካማ ግንድ ጋር ይያያዛሉ።**
:::

::: grammar-box
**ትርጉም፡**

**"ንጽጽራዊ" የሚለው ቃል፣ የሚነጻጸር ነገር ሳይገለጽ ሲቀር፣ "በጣም፣ እጅግ፣ ከልክ በላይ" የሚል ትርጉም አለው፡**

:::
::: indent
ለምሳሌ ⟪सुचितर⟫ 3 "በጣም ንጹሕ", "እጅግ ንጹሕ", "ከልክ በላይ ንጹሕ"
:::
**የሚነጻጸር ነገር ከተገለጸ፣ ይህ ነገር በአብላቲቭ (⟪पञ्चमी⟫) መልክ ይቀመጣል። ንጽጽራዊ + አብላቲቭ በጀርመንኛ ከ"als" ጋር የሚደረግን ንጽጽር ይወክላል።**

::: indent
ለምሳሌ ⟪देवदत्ताद्रामो⟫ ⟪धीमत्तरः⟫ = ቃል በቃል፡ "ከዴቫዳታ አንጻር ሲታይ ራማ የበለጠ አስተዋይ ነው" = "ራማ ከዴቫዳታ የበለጠ አስተዋይ ነው"
:::
**"የላቀ" የሚለው ቃል፣ የሚነጻጸር ነገር ሳይገለጽ ሲቀር፣ "እጅግ በጣም" ወይም "በጣም" የሚል ትርጉም አለው፡**

::: indent
ለምሳሌ ⟪सत्तम⟫ 3 (ከ⟪सन्त्⟫) "እጅግ በጣም ጥሩ፣ በጣም ጥሩ"
:::
**የሚነጻጸር ነገር ሲገለጽ፣ ያ ነገር በጌኔቲቭ (⟪षष्ठी⟫) ("ከ"፣ "መካከል") ይቀመጣል፤ የላቀውም ደረጃ ከጀርመንኛው የላቀ ደረጃ (የበላይ ደረጃ) ጋር ይዛመዳል፡**

::: indent
ለምሳሌ ⟪द्विजानां⟫ ⟪सत्तमः⟫ = "ሁለት ጊዜ ከተወለዱት መካከል ምርጡ"
:::
**-⟪तर⟫ እና -⟪तम⟫ ቅጥያዎች ከቅጽሎች ጋር ብቻ ሳይሆን ከስሞች፣ የማይለወጡ ቃላት እና እንዲያውም ከግሥ ቅርጾች ጋርም ሊቀጠሉ ይችላሉ፡**

ምሳሌዎች፡

::: indent
⟪गजतम⟫ ተ. "ምርጡ ዝሆን" (⟪गज⟫) (የቡድሃ መጠሪያም ነው)

⟪गोतम⟫ ተ. "ትልቁ በሬ" (⟪गो⟫) ወይም፡ "በከብቶች እጅግ የበለጸገ"

⟪उद्⟫ ቅርጹን የማይቀይር "ላይ"፣ "ወደ ላይ" » ⟪उत्तर⟫ 3 "ከፍ ያለ" » ⟪उत्तम⟫ 3 "ከፍተኛ"
:::

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

ምሳሌዎች፦
