# ትምህርት 56

## 56.1. የተደጋገመው አኦሪስት

::: grammar-box
**መፈጠር:**

**ኦግመንት + የተደጋገመ ሥር + a + ተማሪ ዋና ሁለተኛ መጨረሻ**

**የሥር ሲሊባ ዝቅተኛ ወይም ከፍተኛ ሊሆን ይችላል። በ -i ወይም -u የሚያልቁ ሥሮች፣ ዝቅተኛ ደረጃ ህግ ነው።**

**በመጨረሻ ላይ ያለው -i, -u በ -iy ወይም -uv ይተካል።**

**በመጨረሻ ላይ ያለው -ā (ለ-e) ይጠፋል።**
:::
ምሳሌ፡-

⟪श्रि⟫ 1U "ወደ መሄድ፣ ማንከባለል"

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | ⟪अशिश्रियम्⟩:br(⟪अ⟫-⟪शि⟫-⟪श्रिय्⟫-⟪अम्⟫) | ⟪अशिश्रियाम⟫ | ⟪अशिश्रिये⟫ | ⟪अशिश्रियामहि⟫ |
| **2. ⟪द्वितीयः⟫** | ⟪अशिश्रियस्⟫ | ⟪अशिश्रियत⟫ | ⟪अशिश्रियथास्⟫ | ⟪अशिश्रियध्वम्⟫ |
| **3. ⟪प्रथमः⟫** | ⟪अशिश्रियत्⟫ | ⟪अशिश्रियन्⟫ | ⟪अशिश्रियत⟫ | ⟪अशिश्रियन्त⟫ |

ይህ የአኦሪስት ቅርጽ በተለይም እነዚህን ይፈጥራል፡-

*   ⟪श्रि⟫ 1U "ወደ መሄድ"
*   ⟪द्रु⟫ 1P "መገላበጥ"
*   ⟪कम्⟫ 1Ā "ፍቅር"፡- ⟪अचकमत⟫ / ⟪अचीकमत⟫ (እንደታች ይመልከት!)
*   ⟪पत्⟫ 1P "መውደቅ"፡- ⟪अपप्तत्⟫ (a-pa-pt-a-t; pt = pat ላይ ዝቅተኛ ደረጃ)
*   ⟪वच्⟫ 2P "ማለት"፡- ⟪अवोचत्⟫ (a-va + uc-a-t)

::: grammar-box
**ሁሉም የ10ኛው ቅርጽ ክፍል ሥሮች እና ሁሉም ምክንያታዊ ሥሮች ሁልጊዜ የተደጋገመ አኦሪስት ይፈጥራሉ።**
:::
### 56.1.1. የምክንያታዊ እና የ10ኛው ቅርጽ ክፍል ሥሮች አኦሪስት መፈጠር

የቅርጽ ሲሊባ፡-

::: grammar-box
**ነጥቡ የመነሻው ቅርጽ የአሁን ስም ወይም የምክንያታዊ ስም ነው፣ ይህም በ -aya- መስመር ሲወገድ ይቀራል (ስለዚህ በ -paya- ላይ ያለው የምክንያታዊ ቅርጽ በ -p ያልቃል)።**

**የዚህ ስም የተባለው ቃል በአኦሪስት ውስጥ በሚከተሉት ህጎች ይወሰናል፡-**

*   **\-ā- በቀላል ልኬት ከጎን ቢመጣ በ-a- ይተካል:**  
⟪पॄ⟫ 3P: Kaus. :sig[⟪पार⟫]⟪यति⟫, Aor. ⟪अपि⟫:sig[⟪पर⟫]⟪त् द्रु⟫ 1P: Kaus. :sig[⟪द्राव⟫]⟪यति⟫, Aor. ⟪अदु⟫:sig[⟪द्रव⟫]⟪त्⟫ / ⟪अदि⟫:sig[⟪द्रव⟫]⟪त् नी⟫ 1U: Kaus.  :sig[⟪नाय⟫]⟪यति⟫, Aor. ⟪अनी⟫:sig[⟪नय⟫]⟪त् ज्ञा⟫ 9U: Kaus. :sig[⟪ज्ञाप⟫]⟪यति⟫, Aor. ⟪अजि⟫:sig[⟪ज्ञप⟫]⟪त्⟫  

*   **\-ī-, -e-, -ai- በቀላል ልኬት ከጎን ቢመጣ በ-i- ይተካል:**  
⟪चित्⟫ 1P: Kaus. :sig[⟪चेत⟫]⟪यति⟫, Aor. (Ā) ⟪अची⟫:sig[⟪चित⟫]⟪त⟫  

*   **\-u-, -o-, -au- በቀላል ልኬት ከጎን ቢመጣ በ-u- ይተካል:**  
⟪चुर्⟫ 10U: :sig[⟪चोर⟫]⟪यति⟫, Aor. ⟪अचू⟫:sig[⟪चुर⟫]⟪त्⟫

**በአንዳንድ ሥሮች ውስጥ ከነበሩት የተጠቀሱ ለውጦች በምርጫ ይከናወናሉ ወይም መቆየት አለባቸው፡**

*   **ከመደበኛው የስም ስብስብ ድምጽ በቀጣይነት የሚመጣ ለ-ṛ, -ṝ, -ḷ ተተኪ የሆነው ar, ār, īr, al በምርጫ ሳይቀየር ይቆያል ወይም በ-ṛ ወይም -ḷ ይተካል፡**  
⟪कॢप्⟫  1Ā: Kaus. :sig[⟪कल्प⟫]⟪यति⟫, Aor. ⟪अच⟫:sig[⟪कल्प⟫]⟪त्⟫ / ⟪अची⟫:sig[⟪कॢ⟫]⟪पत् कृष्⟫ 1P/6U: Kaus. :sig[⟪कर्ष⟫]⟪यति⟫, Aor. ⟪अच⟫:sig[⟪कर्ष⟫]⟪त्⟫ / ⟪अची⟫:sig[⟪कृ⟫]⟪षत्⟫
:::
የድግግሞሽ ስብስብ ድምጽ፡

ከነበሩት ህጎች በስም ስብስቡ ላይ ከተጠቀሱት በኋላ የድግግሞሽ ስብስቡን ድምጽ ለመከተል የሚከተሉትን ህጎች መከተል አለባቸው፡

::: grammar-box
**መነሻ ደረጃ መደበኛው የድግግሞሽ ድምጽ ነው ማለት**

*   a ለ-a, ā, ṛ,  ṝ, ḷ
*   i ለ-i, ī, e, ai
*   u ለ-u, ū, o, au

**ይህ የድግግሞሽ ድምጽ በሚከተሉት ለውጦች ይዳርጋል፡**

*   **i, u በቅድመ-ግስ ላይ አንድ ቀዳሚ ነጥብ ሲኖር እና በሜትሪክ አጭር ሲሆን በī, ū ይተካሉ፡**  
⟪भिद्⟫ 7U: ምክንያት ⟪भेदयति⟫, አዮር. ⟪अ⟫:sig[⟪बी⟫]⟪भिदत् तुद्⟫ 6U: ምክንያት ⟪तोदयति⟫, አዮር. ⟪अ⟫:sig[⟪तू⟫]⟪तुदत्⟫  

*   **a በቅድመ-ግስ ላይ አንድ ቀዳሚ ነጥብ ሲኖር እና በሜትሪክ አጭር ሲሆን በī ይተካል። ቅድመ-ግሱ በሜትሪክ አጭር ሆኖ ከአንድ በላይ ቀዳሚ ጥምር ነጥቦችን ይይዛል እና ሲጀምር የመደጋገሚያ ቅድመ-ግስ a በi ይተካል። ቅድመ-ግሱ በሜትሪክ ረጅም ከሆነ a ይቀጥላል፡**  
⟪नी⟫ 1U: ምክንያት ⟪नाययति⟫, ቅድመ-ግስ አዮር. ⟪नय्⟫, አዮር. ⟪अ⟫:sig[⟪नी⟫]⟪नयत् कृ⟫ 8U: ምክንያት ⟪कारयति⟫, ቅድመ-ግስ አዮር. ⟪कर्⟫, አዮር. ⟪अ⟫:sig[⟪ची⟫]⟪करत् त्यज्⟫ 1P: ምክንያት ⟪त्याजयति⟫, ቅድመ-ግስ አዮር. ⟪त्यज्⟫, አዮር. ⟪अ⟫:sig[⟪ति⟫]⟪त्यजत् भू⟫ 1P: ምክንያት ⟪भावयति⟫, ቅድመ-ግስ አዮር. ⟪भव्⟫, አዮር. ⟪अ⟫:sig[⟪बी⟫]⟪भवत्⟫

በKielhorn, Grammatik § 435c ff. ላይ የተወሰኑ መሠረቶች ልዩነቶች

**በቅድመ-ግስ ላይ የሚጀምሩ ቅድመ-ግሶች በሚከተሉት ህጎች መደጋገም ይኖርባቸዋል፡**

*   **ከመነሻ ቀዳሚ ነጥብ በኋላ አንድ ቀዳሚ ነጥብ ወይም የመጀመሪያው ቅድመ-ግስ ነጥብ ያልሆነ ቀዳሚ ጥምር ነጥቦች ካሉ የመደጋገሚያ ቅድመ-ግስ ይሆናል፡**

ቀዳሚ ነጥብ - የመጀመሪያው ቀዳሚ ነጥብ (በተለይም በመደጋገሚያ ቅድመ-ግስ ውስጥ የሚፈለገው ተወካይ) - **i** \- ሁሉም ቀዳሚ ነጥቦች

:::
::: indent
⟪अश्⟫ 9P: ምክንያት ⟪आशयति⟫, የመደጋገሚያ ቅድመ-ግስ ⟪आशिश्⟫, አዮር. ⟪आशिशत् इष्⟫ 6P: ምክንያት ⟪एषयति⟫, የመደጋገሚያ ቅድመ-ግስ ⟪एषिष्⟫, አዮር. ⟪ऐषिषत् ईक्ष्⟫ 1Ā: ምክንያት ⟪ईक्षयति⟫, የመደጋገሚያ ቅድመ-ግስ ⟪ईचिक्ष्⟫, አዮር. ⟪ऐचिक्षत्⟫
:::
*   **ከተነጠለ ቀዳማይ ፊደል በኋላ የናጋል ወይም d ወይም r በሚጀምር የኮንሶናንት ቡድን ከተገኘ፣ የቡድኑ ሁለተኛ ኮንሶናንት (ወይም ተካ) በሚከተለው ስርዓት እንደ i ይጨመራል፡**


ቀዳማይ ኮንሶናንት - ሁለተኛ ኮንሶናንት (ተካ) - i - ሁለተኛ ኮንሶናንት

::: indent
⟪अञ्ज्⟫ 7P: ምክንያት ⟪अञ्जयति⟫፣ ተደጋጋሚ ሲሊብ ⟪अञ्जिज्⟫፣ አዮር. ⟪आञ्जिजत् ऋ⟫ 1P: ምክንያት ⟪अर्पयति⟫፣ ተደጋጋሚ ሲሊብ ⟪अर्पिप्⟫፣ አዮር. ⟪आर्पिपत् अर्ह्⟫ 1P: ምክንያት ⟪अर्हयति⟫፣ ተደጋጋሚ ሲሊብ ⟪अर्जिह्⟫፣ አዮር. ⟪आर्जिहत्⟫
:::
ይህ የቀዳማይ ቀዳማይ ፊደል ያላቸውን የተገለጡ ስሞች (ምክንያቶች) የመደጋገም ዘይቤ "አቲክ መደጋገም" ይባላል።
## 56.2. ኢንጁንክቲቭ

::: grammar-box
**ኢንጁንክቲቭ ከአውግመንት የተነጠለ ቅርጽ ነው፣ ማለትም ቅርጾቹ ከአውግመንት የተነጠለ ቅርጾች ምስክር ወይም አዮሪስ ጋር ተመሳሳይ ናቸው። የአካባቢው ሕንድ ቋንቋ ግራማር ኢንጁንክቲቭን እንደ ልዩ የግራማር ክፍል አልተለየም።**
:::
በመሰረታዊው ስራ መሰረት፡
