# ልምምድ 41

ሀ) በትምህርቱ መጀመሪያ ላይ የሚገኙትን ሁለት ምሳሌዎች ይተርጉሙ፡-

⟪१⟫. **⟪पुस्तकस्था च या विद्या परहस्ते च यद्धनम् ।⟫**  
**⟪कार्यकाले समुत्पन्ने न सा विद्या न तद्धनम् ॥ १ ॥⟫**  
በመጽሐፍ ውስጥ ብቻ የተጻፈው ጥበብ እና በገዳይ እጅ ውስጥ ያለው ገንዘብ፡ የሚያስፈልግበት ጊዜ ሲመጣ፣ ይህ ጥበብ ጥበብ አይደለም፣ ይህ ገንዘብም ገንዘብ አይደለም።

⟪२⟫. **⟪उपदेशो हि मूर्खाणां प्रकोपाय न शान्तये ।⟫**  
**⟪पयःपानं भुजङ्गानां केवलं विषवर्धनम् ॥ २ ॥⟫**  
ለጭካኔዎች የሚሰጠው ትምህርት ወደ ቁጣ ይመራል፣ ወደ ሰላም አይደለም። በሰገኖች የሚጠጣው ገብ ወደ መርዝ መጨመር ብቻ ነው።

## የልምምድ ጽሑፎች

ለ) ይተርጉሙ፡-

⟪१⟫. **⟪बुद्धं शरणं गच्छामि धर्मं शरणं गच्छामि सङ्घं शरणं गच्छामीति बुद्धगतैर्वक्तव्यम् ॥ १ ॥⟫**
"ወደ ቡዳ ስጥታ ይዘዋለሁ፣ ወደ ዳርማ ስጥታ ይዘዋለሁ፣ ወደ ሳንጋ ስጥታ ይዘዋለሁ" — ይህንን የሚሉት ወደ ቡዳ የሄዱት ናቸው።

### ማስታወሻ፡ ሦስቱ ስጥታዎች
ይህ ሦስት ጊዜ የሚደገም ስጥታ፣ በመፈወስ መንገድ ላይ ተገቢውን ሞቅ ያለ ስሜት እና ቆም ብሎ መቆየት ለመያዝ ወሳኝ ነው። ምክንያቱም ብዙ ምሳሌያዊ መምህራን ስላሉ፣ ለሁሉም በተናጠል መከተል አይቻልም። ምርጫ ማድረግ ያስፈልጋል። የአንድ መምህር ግላዊ ባህሪ ልብ ወለድ ያለው መሆን አለበት (**ወደ ቡዳ ስጥታ**)።

ነገር ግን ዋናው ነገር የመዳን ግላዊ ባህሪ ሳይሆን፣ ለግለሰብ መንገዱን በራሱ እንዲጓዝ የሚያስችለው የመዳን ትምህርት ነው። ከትምህርቱ እንዲህ ያለ እምነት ሊኖርዎት ይገባል፣ እውነትን ለመፈተሽ ኃይል እንዲያወጡ (**ወደ ዳርማ ስጥታ**)።

በተጨማሪም ሌሎችም ይህንን መንገድ በተሳካ ሁኔታ እንደገለገሉበት ማመን ያስፈልጋል። ይህ **ወደ ሳንግሃ የመጠገው** ሲሆን፣ ይህም የቡድን ማለትም የቡድን አባላት ማለት ነው።
⟪२⟫. **⟪काशीं पत्स्ये गङ्गां द्रक्ष्यामि तत्र च मरिष्यामीति मन्यमानो मान्यो वृद्धनरः पुत्रांश्च पुत्रपुत्रांश्च धनं च तत्याज काशीं च प्राव्रजत् । एवं च रोध्यं दुःखं तरिष्यतीति मन्ये ॥ २ ॥⟫**
"ወደ በናራስ (Kāśī) እሄዳለሁ፣ ጋንገስ እይባለሁ እና እዚያ እሞታለሁ" — በዚህ አስተሳሰብ ከሚከተሉት ልጆች፣ ልጅ ልጆች እና ንብረት ተገንጥሎ ወደ በናራስ ተገብቷል። እኔ እንደሚያስብው ይህንን ስሜት ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀረት ይህንን ለማስቀ

⟪३⟫. **⟪कन्यां व्युवह तस्यां च पुत्रमजनयं महाधनं च लेभ एवं सुखमापेत्यतीते मुमोह । ततः प्रजज्ञौ सुखाद्दुःखं जायते तस्माल्लोकसुखमपि त्यजनीयं न च किंचिदिन्द्रियैः स्प्रष्टव्यमिति ॥ ३ ॥⟫**
«አንዲት ሴት አግብቻለሁ፣ ከእርሷም ወንድ ልጅ ወልጃለሁ እና ታላቅ ሀብት አግኝቻለሁ፤ በዚህም ደስታን አግኝቻለሁ» — ባለፈው ጊዜ በዚህ መንገድ ራሴን አታልዬ ነበር (Kielhorn)። ከዚያም ተረዳሁ፦ ከደስታ መከራ ይወለዳል፤ ስለዚህ ዓለማዊ ደስታም መተው አለበት፣ በስሜት ህዋሳትም ምንም ሊነካ አይገባም።

⟪४⟫. **⟪विक्रेयाणि विक्रीयापुत्रवैश्यो भिक्षुभ्यो विक्रयफलमददाद्दानपुण्यं चादत्त । एतत्कर्म स्तुत्यमिति भिक्षवः प्रोचुर्बुद्धिमन्तस्तु विकल्पयन्ति किमेवं कुर्वाणो वैश्यः पुण्यं चकारेति ॥ ४ ॥⟫**
የሚሸጡትን ሸቀጦች ከሸጠ በኋላ ልጅ የሌለው ቫይሽያ ገቢውን ለመነኮሳት ሰጠ እና የስጦታውን በጎ ዋጋ ተቀበለ (Kielhorn)። መነኮሳቱም፦ «ይህ ተግባር የሚያስመሰግን ነው» ብለው አወጁ። አስተዋዮች ግን ይህን ያደረገው ቫይሽያ በእርግጥ በጎ ተግባር ሠርቷል ወይ ብለው ይጠራጠራሉ።

⟪५⟫. **⟪गुरुभिः शिष्याः शासितव्याः शिष्यैरध्ययनमध्येतव्यम् ॥ ५ ॥⟫**
ተማሪዎች በመምህራን መምረቅ አለባቸው፤ ተማሪዎች ደግሞ የትምህርት ክፍልን መጽናት አለባቸው።
