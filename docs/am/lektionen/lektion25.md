# ትምህርት 25

## 25.1. የአብላቲቭ ምስረታ (⟪पञ्चमी⟫ = "አምስተኛው የጉዳይ ቅጥያ")

::: grammar-box
በ-a ከሚጨርሱ ተባዕታይ/ገለልተኛ ጾታዎች እና ተውላጠ ስሞች በስተቀር፣ በነጠላ ቁጥር በሁሉም የርቢ ክፍሎች ውስጥ የአብላቲቭ (⟪पञ्चमी⟫) ቅርጾች ከጀነቲቭ (⟪षष्ठी⟫) ቅርጾች ጋር ተመሳሳይ ናቸው።

ከግላዊ ተውላጠ ስሞች በስተቀር፣ በሁሉም እርባታዎች በብዙ ቁጥር የአብላቲቭ ቅርጾች ከዳቲቭ (⟪चतुर्थी⟫) ቅርጾች ጋር ተመሳሳይ ናቸው።
:::
አሁን በሳንስክሪት የካሱስ (⟪विभक्ति⟫) ቅደም ተከተል ምክንያቱን ይረዳሉ፤ እነሱ የተደራጁት ተመሳሳይ ድምጽ ያላቸው ቅርጾች በተቻለ መጠን ጎን ለጎን ወይም አንዱ ከሌላው በታች እንዲሆኑ ነው።

::: grammar-box
**በ -a የሚያልቁ የወንድ / ገለልተኛ ጾታ ስሞች አብላቲቭ ነጠላ ቁጥር**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
የጥያቄ፣ አንጻራዊ እና አመልካች ተውላጠ ስሞች፦

::: grammar-box

| :--- | :--- | :--- |

| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |

## 25.2. የአብላቲቭ አጠቃቀም (⟪पञ्चमी⟫)

"አብላቲቭ የሚያመለክተው አንድ ነገር ከእሱ ሲለይ ጸንቶ የሚቀረውን ነገር ነው።"

Pāṇini 2,3,28 + 1,4,24

አብላቲቭ በዋነኝነት "ከየት?"፣ "ለምን?" ለሚሉት ጥያቄዎች መልስ ይሰጣል።

::: grammar-box
1. ስለዚህ አብላቲቭ መነሻን፣ አመጣጥን እና ቁስን ያመለክታል።

ስለዚህ አብላቲቭ አንድ ነገር የሚገዛበትን፣ የሚሰማበትን፣ የሚፈለግበትን ወዘተ ሰው ሊያመለክት ይችላል።
:::
ምሳሌዎች፦

::: indent
⟪ग्रमादागच्छति⟫ = "ከመንደሩ ይመጣል"

⟪अश्वात्पतितः⟫ = "ከፈረሱ የወደቀ"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "ከእነርሱ (ዘንድ) የተቀበለ"
:::
ምሳሌዎች፦

::: indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟫ = "ከመምህሩ ስለ ድሀርማ ይሰማል"

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = "ብራህማናው ከክሻትሪያው ወተት የምትሰጥ ላም ይመኛል"
:::
::: grammar-box
2. አብላቲቭ "ከ... መከልከል"፣ "ከ... መጠበቅ"፣ "ከ... መከላከል"፣ "ከ... መፍራት" የሚሉ ትርጉሞች ካሏቸው ግሶች ጋር ይቆማል፦
:::
ምሳሌ፦

::: indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = "ከጠላቶች ይጠብቃል"
:::
::: grammar-box
3. አብላቲቭ ምክንያት ወይም መንስኤን ያመለክታል፡
:::
ምሳሌዎች፡

::: indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = "ልጁን በቁጣ ገደለው"

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = "ክፉ ስላደረገ ወደ ሲኦል ይመጣል" (« ክፉ የተደረገበት ሰው ስለሆነ)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = "ክፉ ስለሚያደርግ / ስላደረገ ወደ ሲኦል ይመጣል"
:::
ሴት ጾታ ያልሆኑ ስሞች፣ የድርጊትን ምክንያት ለመግለጽ፣ በኢንስትሩመንታሊስ (⟪तृतीया⟫) ወይም በአብላቲቭ (⟪पञ्चमी⟫) ሊቆሙ ይችላሉ። በዚህ ትርጉም ሴት ጾታ ስሞች በአብዛኛው በኢንስትሩመንታሊስ ይቆማሉ፣ ነገር ግን አልፎ አልፎ በአብላቲቭም ሊቆሙ ይችላሉ።

## 25.3. ቅጥያው -⟪तस्⟫

::: grammar-box
በነጠላ ቁጥር (በግልጽ) ቃሉ በአብላቲቭ ትርጉም ጥቅም ላይ እንደዋለ ለመግለጽ ከተፈለገ፣ ከቃሉ ግንድ ጋር -⟪तस्⟫ ቅጥያውን መጨመር ይቻላል፤ ይህም ብዙውን ጊዜ በአብላቲቭ ትርጉም ("ከየት?" ለሚለው ጥያቄ) ተውሳከ ግሶችን ይፈጥራል።
:::
ምሳሌዎች፦

::: indent
⟪आदितस्⟫ = "ከመጀመሪያው ጀምሮ"

⟪धर्मतस्⟫ = "በዳርማ ምክንያት፣ በዳርማ መሰረት"
:::
::: grammar-box
ቅጥያው -⟪तस्⟫ እንዲሁም ከተውላጠ ስም ግንዶች ጋር ይያያዛል፦
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "ከዚያ፣ እዚያ፣ ወደዚያ፣ በዚያ ላይ፣ ከዚያም፣ ስለዚህ"

⟪यद्⟫ : ⟪यतस्⟫ "ከየትኛው፣ ከምን፣ ከየት፣ የት፣ ወዴት፣ ለምን፣ ምክንያቱም" (አንጻራዊ)

⟪किम्⟫ : ⟪कुतस्⟫ "ከየት?" "ለምን?"
:::
## 25.4. ምክንያቶችን ለመግለጽ ሌሎች መንገዶች

::: grammar-box
**1\. አንጻራዊ ዓረፍተ ነገሮች**

አንጻራዊ ዓረፍተ ነገሮች ብዙውን ጊዜ ከዋናው ዓረፍተ ነገር ጋር የምክንያት (ምክንያት ሰጪ)፣ የውጤት (ተከታይ) ወይም የዓላማ (ዓላማን የሚያሳይ) ግንኙነትን ይገልጻሉ።

እንደ ምክንያት አያያዥ ሆነው የሚያገለግሉ የአንጻራዊ ተውላጠ ስም ቅርጾች፡

*   አብላቲቭ፡
*   ⟪यतस्⟫ ... ንዑስ ዓረፍተ ነገር ... ⟪ततस्⟫ ... ዋና ዓረፍተ ነገር ... = "ምክንያቱም ...፣ ስለዚህ ..."
*   ⟪यस्मात्⟫ ... ንዑስ ዓረፍተ ነገር ... ⟪तस्मात्⟫ ... ዋና ዓረፍተ ነገር ... = "ምክንያቱም ...፣ ስለዚህ ..."
*   መሳሪያዊ፡
*   ⟪येन⟫ ... ንዑስ ዓረፍተ ነገር ... ⟪तेन⟫ ... ዋና ዓረፍተ ነገር ... = "በዚህም/ምክንያቱም ...፣ በዚህም / በዚህ ምክንያት ..."
:::
ምሳሌ፡

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = "ራማ ብልጽግናን ስለሚፈልግ፣ ስእለቱን ይፈጽማል"
:::
::: grammar-box
**2\. ⟪हि⟫**

ዋና ዓረፍተ ነገሮችን ⟪हि⟫ "ምክንያቱም፣ ስለሆነ" በሚለው ቅንጣት ማገናኘት ይቻላል። ⟪हि⟫ ያለው ዓረፍተ ነገር (በመጀመሪያ ቦታ ላይ መቆም የማይችል፣ ነገር ግን በስድ ንባብ በሁለተኛ ቦታ ላይ መቆም ያለበት) ለቀዳሚው ዓረፍተ ነገር ወይም ለተከታዩ ዓረፍተ ነገር ምክንያት ይሰጣል፡
:::
ምሳሌ፡

::: indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = "ሰዎቹ መልካም ነገር ያደርጋሉ። ወደ ሰማይ መሄድ ይፈልጋሉና።"
:::
::: grammar-box
**3. መሳሪያዊ (⟪तृतीया⟫)**

ከአብላቲቭ (⟪पञ्चमी⟫) በተጨማሪ መሳሪያዊው (⟪तृतीया⟫) ምክንያትን ወይም መንስኤን ለመግለጽ ያገለግላል። በሴት ጾታ ስሞች ላይ መሳሪያዊው በአጠቃላይ ግዴታ ነው።
:::
ምሳሌ፦

::: indent
⟪क्रोधेन⟫ ⟪पुत्रं⟫ ⟪हन्ति⟫ = "ልጁን በቁጣ ገደለው" = "ልጁን በንዴት ገደለው"
:::
::: grammar-box
**4. ስሞች**

ከዚህ በተጨማሪ ምክንያቶችን በሚከተሉት ግንባታዎች መግለጽ ይቻላል

*   ⟪कारण⟫ n. "ምክንያት": ⟪कारणात्⟫ ⟪।⟫ ⟪कारणेन⟫
*   ⟪हेतु⟫ m.
