# ትምህርት 25

## 25.1. የአብላቲቭ (⟪पञ्चमी⟫ = "አምስተኛው የግስ ቅጽ") መፍጠር

::: grammar-box
ከማስኩሊና / ኒውትራ በ-a የሚጠናቀቁ እና ከፕሮኖሚና በተጨማሪ በሁሉም የዲክሊኔሽን ክፍሎች ውስጥ በሴንጉላር ውስጥ የአብላቲቭ ቅጾች (⟪पञ्चमी⟫) ከጄኔቲቭ (⟪षष्ठी⟫) ጋር ተመሳሳይ ናቸው።

ከፈርሶናል ፕሮኖሚና በተጨማሪ በሁሉም ዲክሊኔሽኖች ውስጥ በፕላራል ውስጥ የአብላቲቭ ቅጾች ከዳቲቭ (⟪चतुर्थी⟫) ጋር ተመሳሳይ ናቸው።
:::
አሁን የሳንስክሪትን የግስ ቅጾች (⟪विभक्ति⟫) ቅደም ተከተል ምክንያት ይረዱዋል፡ ተመሳሳይ ድምጽ ያላቸው ቅጾች እንዲቅረቡ - ወይም እርስ በርስ እንዲሆኑ በሚያስችል መልኩ ተደርገዋል።

::: grammar-box
**የ-a በ-a የሚጠናቀቁ ማስኩሊና / ኒውትራ አብላቲቭ ሴንጉላር**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::

## 25.2. የአብላቲቭ (⟪पञ्चमी⟫) ተጠቃሚነት

"አብላቲቭ ነገሩ ከሚወጣበት ጊዜ ጋር ቆሞ የሚቆየውን ይገልጻል።"

Pāṇini 2,3,28 + 1,4,24

አብላቲቭ በዋናነት "የትከውን?"፣ "ለምን?" ለሚሉ ጥያቄዎች ይቀመጣል።

::: grammar-box
1\. ስለዚህ አብላቲቭ የመነሻ ነጥብን፣ ምንጭን እና ቁስን ይገልጻል።

ስለዚህ አብላቲቭ ማንኛውንም ነገር የሚገዙ፣ የሚሰማዩ፣ የሚፈልጉ ወዘተ. ከሚያደርጉት ሰው ሊያመለክት ይችላል።
:::
ምሳሌዎች፡-

::: indent
⟪ग्रमादागच्छति⟫ = "ከደረታው ይመጣል"

⟪अश्वात्पतितः⟫ = "ከፈረስ ላይ ወደቀ"

⟪तेभ्यो लब्धम्⟫ = "ከእነርሱ (ከእነርሱ) ተቀብሏል"
:::
ምሳሌዎች፡-

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "ከአስተማሪው ስለ ዳርሞ ይሰማል"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "ብራሂማኑ ከክሽትሪያ ለውጥ ወንድ ልጅ ይፈልጋል"
:::
::: grammar-box
2\. አብላቲቭ በ "ከመቆጣጠር"፣ "ከመጠበቅ"፣ "ከመከላከል"፣ "ከመፍራት" ትርጉም ያላቸው ቃላት ላይ ይቆማል፡-
:::
ምሳሌ፡-

::: indent
⟪अरिभ्यो रक्षति⟫ = "ከጠላቶች ይጠብቃል"
:::
::: grammar-box
3\. አብላቲቭ ምክንያትን ወይም ምክንያትን ያመለክታል፡-
:::
ምሳሌዎች፡-

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "በጭንቀት ልጁን ያጠፋል"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "ሌባ ስለሆነ ወደ ገሃነም ይሄዳል" ("ሌባ ስለሆነ")

⟪पापकरणान्नरकं गच्छति⟫ = "ሌባ ስለሆነ ወደ ገሃነም ይሄዳል"
:::
ስምዎች፣ ሴት ስም ያልሆኑ፣ ስራን ለመግለጽ በመሳሪያ (⟪तृतीया⟫) ወይም አብላቲቭ (⟪पञ्चमी⟫) ሊቆሙ ይችላሉ። ሴት ስምዎች በዚህ ሁኔታ በተለምዶ በመሳሪያ ይቆማሉ፣ ነገር ግን በአብላቲቭ ሊቆሙ ይችላሉ።

## 25.3. ስፔል -⟪तस्⟫

::: grammar-box
በአንድ ቃል (በግልጽ) አብላቲቭ ትርጉም እንደሚጠቀም ለመግለጽ፣ በቃሉ ስም ላይ ስፔል -⟪तस्⟫ ማገናኘት ይቻላል፣ ይህም በአብላቲቭ ትርጉም ያላቸውን ቃላት ይፈጥራል (ለ "የትኛው?" ጥያቄ)፡-
:::
ምሳሌዎች፡-

::: indent
⟪आदितस्⟫ = "ከመጀመሪያው ጊዜ ጀምሮ"

⟪धर्मतस्⟫ = "በዒርግ ምክንያት፣ በዒርግ ምክንያት"
:::
::: grammar-box
ቅጥዩ -⟪तस्⟫ በፕሮኖሚናል ሥሮች ላይም ይገኛል፡-
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "ከዚያን ቦታ፣ እዚያ፣ ወደዚያ፣ በዚህ ላይ፣ ከዚያን ጊዜ፣ ስለዚህ"

⟪यद्⟫ : ⟪यतस्⟫ "የትኛው፣ ስለምን፣ ከየት፣ የት፣ ወደየት፣ ለምን፣ ስለዚህ" (ተዛማጅ)

⟪किम्⟫ :  ⟪कुतस्⟫ "ከየት?" "ለምን?"
:::
## 25.4. ሌሎች ምክንያቶችን ለመግለጽ መንገዶች

::: grammar-box
**1\. ተዛማጅ ሐረጎች**

ተዛማጅ ሐረጎች ብዙውን ጊዜ ከዋናው ሐረግ ጋር ምክንያታዊ (ምክንያታዊ)፣ ተከታታይ (ተከታይ) ወይም ዓላማዊ (ዓላማዊ) ግንኙነትን ይገልጻሉ።

እንደ ምክንያታዊ ግንኙነት ቃል የሚያገለግሉ የተዛማጅ ስም ምልክቶች ቅርጾች፡-

*   ከአብለቲቭ፡-
*   ⟪यतस्⟫ ... ሐረግ ... ⟪ततस्⟫ ... ዋና ሐረግ ... = "ምክንያቱም ...፣ ስለዚህ ..."
*   ⟪यस्मात्⟫ ... ሐረግ ... ⟪तस्मात्⟫ ... ዋና ሐረግ ... = "ምክንያቱም ...፣ ስለዚህ ..."
*   ከኢንስትሩመንታል፡-
*   ⟪येन⟫ ... ሐረግ ... ⟪तेन⟫ ... ዋና ሐረግ ... = "በምክንያቱም/ምክንያቱም ...፣ በዚህ ምክንያት / ስለዚህ ..."
:::
ምሳሌ፡-

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "ራማ ጤናማ ሕይወት ስለሚፈልግ፣ ቃሉን ይጠብቃል"
:::
::: grammar-box
**2\. ⟪हि⟫**

ዋና ሐረጎች በ⟪हि⟫ "ምክንያቱም፣ ምክንያቱም" ቃል በማገናኘት ይገናኛሉ። ሐረግ ከ⟪हि⟫ ጋር (ይህ በመጀመሪያ ቦታ ላይ ሊቀመጥ አይችልም፣ ነገር ግን በጽሑፍ በሁለተኛ ቦታ ላይ መቀመጥ አለበት) ምክንያትን ይሰጣል ወይም ለቀድሞው ሐረግ ወይም ለቀጣዩ ሐረግ፡-
:::
ምሳሌ፡-

::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "ሰዎች ጥሩ ሥራ ያደርጋሉ። ምክንያቱም ወደ ገነት ለመሄድ ስለሚፈልጉ ነው።"
:::
::: grammar-box
**3\. Instrumentalis (⟪तृतीया⟫)**

ከ Ablativ (⟪पञ्चमी⟫) በተጨማሪ Instrumentalis (⟪तृतीया⟫) ለምክንያት ወይም ምክንያት ለመግለጽ ያገለግላል። ለጾታዊ ስሞች Instrumentalis በአጠቃላይ ግዴታ ነው።
:::
ምሳሌ፡-

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = "በጭንቀት ልጁን ያጠፋል" = "በጭንቀት ውስጥ ልጁን ያጠፋል"
:::
::: grammar-box
**4\. ስሞች**

በተጨማሪም ምክንያቶችን በእርግጥ በ

\+ Genetiv (⟪षष्ठी⟫) ወይም እንደ የኋላ ክፍል በ Compound ውስጥ፡-
:::
ምሳሌ፡-

::: indent
⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ ወዘተ) = "በጥሩ ሥራ ምክንያት"
:::
::: grammar-box
**5\. ⟪इति⟫**

ለአንድ ሥራ ምክንያት እንደ አስተሳሰብ በ ⟪इति⟫ ማቅረብ ይቻላል፡-
