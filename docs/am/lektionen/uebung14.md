# ልምምድ 14

የሚከተሉትን ምሳሌዎች ተርጉም እና አስታውሳቸው፡

⟪निचो वदति न कुरुते वदति न साधुः करोत्येव ॥१॥⟫  
ዝቅተኛ ሰው አይናገርም፣ አይሰራም፤ ጥሩ ሰው አይናገርም፣ ይሰራል።

⟪शीलं नरस्य भूषणम् ॥२॥⟫  
ጥበብ የሰው ልጅ ውበት ነው።

⟪सत्येन जनानां सुखं भवति ॥३॥⟫  
በእውነት ሰዎች ዕድል ያገኛሉ።

⟪पापा नराः स्वर्गं न लभन्ते ॥४॥⟫  
ርህራሄ የሌላቸው ሰዎች ወደ ሰማይ አይገቡም።

⟪सत्यं लोकस्य दीपः ॥५॥⟫  
እውነት የዓለም ብርሃን ነው።

ሀ) ለሚከተሉት ቃላት የጄኔቲቭ ነጠላ እና ብዱር ቅጦችን ይፍጠሩ። የቃላቱን ትርጉም እና ስላንድ (ጾታ) ይግለጹ፡

⟪१⟫. ⟪अनृत⟫ : n. ያልተለመደ — ⟪अनृतस्य अनृतानाम् २⟫. ⟪ऋषि⟫ : m. የቬዳ ሥላሴ — ⟪ऋषेः ऋषीणाम् ३⟫. ⟪पाद⟫ : m. እግር — ⟪पादस्य पादानाम् ४⟫. ⟪बुद्धि⟫ : f. ግንዛቤ — ⟪बुद्धेः⟩ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम् ५⟫. ⟪गुरु⟫ : m. ባለቤት — ⟪गुरोः गुरूणाम् ६⟫. ⟪स्वर्ग⟫ : m. ሰማይ — ⟪स्वर्गस्य स्वर्गाणाम् ७⟫. ⟪नगर⟫ : n. ከተማ — ⟪नगरस्य नगराणाम् ८⟫. ⟪धेनु⟫ : f. ዘንዶ — ⟪धेनोः⟫ (⟪धेन्वाः⟫) ⟪धेनूनाम् ९⟫. ⟪द्विज⟫ : m. ሁለጊዜ የተወለደ — ⟪द्विजस्य द्विजानाम् १०⟫. ⟪मुक्ता⟫ : f. የተድለችው — ⟪मुक्तायाः मुक्तानाम् ११⟫. ⟪विद्या⟫ : f. ጥበብ፣ ሳይንስ — ⟪विद्यायाः विद्यानाम् १२⟫. ⟪वर्ण⟫ : m. ደረጃ — ⟪वर्णस्य वर्णानाम् १३⟫. ⟪द्विजाति⟫ : 3 ሁለጊዜ የተወለዱ — ⟪द्विजातेः⟫ (⟪द्विजात्याः⟫) ⟪द्विजातीनाम् १४⟫. ⟪रूप⟫ : n. ቅርጽ — ⟪रूपस्य रूपाणाम् १५⟫. ⟪प्रतिग्रह⟫ : m. መቀበል — ⟪प्रतिग्रहस्य प्रतिग्रहाणाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 ርግብ — ⟪सोढस्य सोढायाः सोढानाम् १७⟫. ⟪नायिका⟫ : ፍ. ወዳጅ — ⟪नायिकायाः नयिकानाम् १८⟫. ⟪साध्वी⟫ : ፍ. ቅዱስ — ⟪साध्व्याः साध्वीनाम् १९⟫. ⟪अग्नि⟫ : ም. እሳት — ⟪अग्नेः अग्नीनाम् २०⟫. ⟪वैश्या⟫ : ፍ. የቫይሻዪ ሴት — ⟪वैश्यायाः वैश्यानाम् २१⟫. ⟪लोक⟫ : ም. ዓለም፣ ሕዝብ — ⟪लोकस्य लोकानाम् २२⟫. ⟪उक्ति⟫ : ፍ. ቃል — ⟪उक्तेः⟫ (⟪उक्त्याः⟫) ⟪उक्तीनाम् २३⟫. ⟪शत्रु⟫ : ም. ጠላት — ⟪शत्रोः शत्रूणाम् २४⟫. ⟪सुखवन्त्⟫ : 3 ደስተኛ — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : ፍ. አንድ ወይም ከዚያ በላይ ልጆች ያሉት ሴት — ⟪पुत्रवत्याः पुत्रवतीनाम् २६⟫. ⟪जल⟫ : ን. ውሃ — ⟪जलस्य जलानाम् २७⟫. ⟪मार्ग⟫ : ም. መንገድ — ⟪मर्गस्य मर्गाणाम् २८⟫. ⟪मोक्ष⟫ : ም. ለቀቀለ፣ ማድረስ — ⟪मोक्षस्य मोक्षाणाम् २९⟫. ⟪शूद्रा⟫ : ፍ. የሱድራ ሴት — ⟪शूद्रायाः शूद्राणाम् ३०⟫. ⟪अन्न⟫ : ን. ምግብ — ⟪अन्नस्य अन्नानाम् ३१⟫. ⟪साधु⟫ : ም. ቅዱስ — ⟪साधोः साधनाम् ३२⟫. ⟪नीति⟫ : ፍ. መመሪያ — ⟪नीत्याः नीतीनाम् ३३⟫. ⟪योध⟫ : ም. ጦርkar፣ ጦርkar — ⟪योधस्य योधानाम् ३४⟫. ⟪सत्यवन्त्⟫ : 3 እውነተኛ — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : ም. ጥቅም — ⟪लाभस्य लाभानाम् ३६⟫. ⟪मोह⟫ : ም. ብዝሃ፣ ብዝሃ — ⟪मोहस्य मोहानाम् ३७⟫. ⟪गति⟫ : ፍ. ጉዞ፣ ዓላማ — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम् ३८⟫. ⟪प्रश्न⟫ : ም. ጥያቄ — ⟪प्रश्नस्य प्रश्नानाम् ३९⟫. ⟪सृष्टि⟫ : ፍ. ፍጥረት — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम् ४०⟫. ⟪नेत्र⟫ : ን. ዓይን — ⟪नेत्रस्य नेत्राणाम् ४१⟫. ⟪गुरुता⟫ : ፍ. ብቁነት — ⟪गुरुतायाः गुरुतानाम्⟫

⟪४२⟫. ⟪ईश्वर⟫ : m. ሌብ — ⟪ईश्वरस्य ईश्वराणाम् ४३⟫. ⟪कारण⟫ : n. ምክንያት — ⟪कारणस्य कारणानाम् ४४⟫. ⟪कृत⟫ : 3 ተገብቷል — ⟪कृतस्य⟫ (⟪कृतायाः⟫) ⟪कृतानाम् ४५⟫. ⟪धर्मवन्त्⟫ : 3 ቀኝ፣ ሃይማኖታዊ — ⟪धर्मवतः⟫ (⟪धर्मवत्याः⟫) ⟪धर्मवताम्⟫ (⟪धर्मवतीनाम्⟫)

⟪४६⟫. ⟪युद्ध⟫ : 3 ተጋጭቷል — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम् ४७⟫. ⟪दर्शन⟫ : n. ማየት፣ ቅርጽ — ⟪दर्शनस्य दर्शनानाम् ४८⟫. ⟪धातु⟫ : m. ንጥረ ነገር፣ የግጥም ሥር — ⟪धातोः धातूनाम् ४९⟫. ⟪गूढा⟫ : f. ሚስጥር — ⟪गूढायाः गूढानाम् ५०⟫. ⟪ईष्टा⟫ (2 ትርጉሞች): f. የሚፈለግ፣ የተቀዳ — ⟪इष्टायाः इष्टानाम् ५१⟫. ⟪उदित⟫ : 3 ተብሏል — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम् ५२⟫. ⟪इदम्⟫ : 3 ይህ — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 ምን — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) ተርጉሙ፡

⟪१⟫. ⟪ब्राह्मणस्य पुत्रो ब्राह्मण्या ग्रामं गतः ।⟫ (2 አማራጮች)
የብራህማን ልጅ ወደ ብራህማኒት ደረሳ ሄደ። የብራህማን ልጅ ከብራህማኒት ጋር ወደ ደረሳ ሄደ።

⟪२⟫. ⟪यज्ञस्याग्निनान्नं दग्धम् ।⟫
የቅዳሜ እሳት ምግቡን አቃጥሏል።

⟪३⟫. ⟪बुद्धः स्तयस्य बुद्ध्या मुक्तः ।⟫
ቡድዳ በእውነት ግንዛቤ ተድሳል።

⟪४⟫. ⟪अधर्मो ऽनृतस्य वदनमित्यृषयो वदन्ति ।⟫
ቬዳዊ ምሁራን ሀሰት መናገር ስህተት ነው ይላሉ።

⟪५⟫. ⟪नरा देवानां यज्ञैर्न मुच्यन्ते ।⟫
ሰዎች በእጆች ለእጆች ቅዳሜ አይድሱም።

⟪६⟫. ⟪बलवन्तः क्षत्रियाः शत्रूणां धनवन्ति नगराणि जयन्ति ।⟫
ጠንካራው Kṣatriyas የጠላትን ብዙ ከተሞች ይወራሉ።

⟪७⟫. ⟪कवेरुक्तिं शृण्वन्ति ।⟫
እነሱ የገጠሙትን ቃል ይሰማሉ።

⟪८⟫. ⟪कविर्देव्याः कृतं वद⟫ti ⟪।⟫
ገጠሙቱ የእግዚአብሔርን ስራ ይገልጻል።

⟪९⟫. ⟪द्विजाः पशोर्लाभमिच्छन्ति ।⟫
ሁለጊዜ የተወለዱ ሰዎች እንስሳትን ለማግኘት ይፈልጋሉ።

⟪१०⟫. ⟪रामः पुण्यवतो गुरोर्मन्त्रस्य स्मरति ।⟫
ራማ የቅንነት ባለሙያውን ማንትራ ያስታውሳል።

⟪११⟫. ⟪अयं बालः कस्याः पुत्रः ।⟫
ይህ ሕፃን የማን ልጅ ነው?

⟪१२⟫. ⟪केषामिमानि गृहाणि ।⟫
እነዚህ ቤቶች የማን ናቸው?

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम् ।⟫
ይህ የቬዳ ምሁር ምን አይነት ምግብ አቅርቧል?
