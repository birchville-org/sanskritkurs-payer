# ትምህርት 12


## 12.1. ሙሉ የተዘጋ (PPP) ቃል

አንድ መንገድ የኋለኛውን ጊዜ ተጽዕኖ ያለባቸውን ማሳያ አጻጻፎች መስራት ሙሉ የተዘጋ (PPP) ቃል ከሚባለው ግንኙነት ጋር መጠቀም ነው።

::: grammar-box
**በእውነቱ ሙሉ የተዘጋ (PPP) ቃል እውነተኛ ሳይሆን፣ ከጊዜ መነሻ ላይ አይመስልም። ይልቁንም ከሥር ጋር በመጀመሪያው ቃል -ta ወይም -na ጋር የተፈጠረ ነው። ስለዚህ በኢንዲያ ጽሑፎች ውስጥ ከ kta ቃል ጋር እንደሚባል ይገለፃል።**
:::

### 12.1.1. ለተጽዕኖ ያለባቸው ቃላት ስልተ-ቃላት

::: grammar-box
**ግብ (kartṛ) በመሳሪያ ላይ (tṛtīyā) -- ቀጥተኛ ስም (karman) በመነሻ ላይ (prathamā) -- ሙሉ የተዘጋ (PPP) ቃል**

በዚህ ሁኔታ PPP ከምንነት (object) በብዛት፣ በመደበኛነት እና በሴታ ጾታ ጋር ይስማማል።

ተረዳች ግስ (እንደ “ነው”) አያስፈልግም።

ምሳሌዎች:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = „(በቅዱስ የሰማይ ምድር ተገኝቷል) = ቅዱሱ ሰማይን አግኝቷል።“
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = „(በብራሚናዊ የእግዚአብሔር ምስክርነት ተጸድቃለች) = ብራሚናዊው እግዚአብሔርን በምስክርነት ተጸድቋል።“
:::

### 12.1.2. ስክማ I ለትራንዚቲቭ ያልሆኑ ቃላት እና ለእንቅስቃሴ ቃላት

::: grammar-box
**ግስ (kartṛ) በኖሚናቲቭ (prathamā) -- ፓርቲስፕ ኢንጂክቲቭ ስም**

በዚህ ሁኔታ PPP ከግስ (agens) በብዛት፣ በመደበኛነት እና በሴታ ጾታ ጋር ይስማማል። ፓርቲስፕ ኢንጂክቲቭ „ስም“ በትራንዚቲቭ ያልሆኑ ቃላት (እንደ ምንነት የለም) እና በእንቅስቃሴ ቃላት ላይ ንግድ አለው።

ምሳሌ፦
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = „የክሽትሪያ ሴት ወደ ከተማ ትይዛለች።“
:::

### 12.1.3. ስኬማ II ለትራንዚቲቭ ያልሆኑ ተግባራት እና ለእንቅስቃሴ ተግባራት

::: grammar-box
**አጀንስ (kartṛ) በመሳሪያ ሁኔታ (tṛtīyā) -- PPP በነሲያቲቭ ነጠላ ስም ያልነበረ**

ምሳሌ፦
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(በክሽትሪያ (ወደ ከተማ) ተጓዟል) = ክሽትሪያው (ወደ ከተማ) ትይዛል።“

በስኬማ II መሰረት ያለው ግንባታ ከስኬማ I ግንባታ በጣም ያነሰ ነው።
:::

## 12.2. ስለ PPP ትርጉም

ስለዚህ የተባለው „ፓርቲስፕ ፐርፌክት ፓሲቭ“ ለትራንዚቲቭ ተግባራት በመጀመሪያ ደረጃ ፓሲቭ ትርጉም አለው (**āpta** = „ተደረሰ (የተደረሰ)“) እና ለትራንዚቲቭ ያልሆኑ ተግባራት እና ለእንቅስቃሴ ተግባራት አክቲቭ ትርጉም (**gata** = „ተጓዟል“)፣ ምንም እንኳን አንዳንድ ተግባራት PPP ሁለቱም አክቲቭ እና ፓሲቭ ትርጉም ሊኖራቸው ይችላል፦

ምሳሌ
**gata** = ⟪गत⟫ = „ተጓዟል“ (አክቲቭ)፤ ነገር ግን፦ **gato mārgaḥ** = ⟪गतो मार्गः⟫ = „የተጓዘ መንገድ“ (ፓሲቭ)
**āpta** = ⟪आप्त⟫ = „ተደርሷል“ (ፓሲቭ)፣ „ተደርሶ ያለ“ (አክቲቭ)


## 12.3. የPPP ልማት

::: grammar-box
የሚከተሉት ልማቶች ይገኛሉ (ለእያንዳንዱ ሥር PPP መማር ያስፈልጋል!)፦

**(በአብዛኛው) ጥልቅ ደረጃ ሥር**

**+ -ta**
ከዚህ በፊት የማያያዣ ገጽታ **-i-** ጋር፦ **-ita**
ከዚህ በፊት የማያያዣ ገጽታ ያለበት፦ **-ta**
**+ -na**

የፈሚኒን ጥቅልዎች **-tā**፣ **-itā**፣ **-nā** ናቸው፤ ስም ያልነበረ እንደ **phala** n. ይለያያል።
:::

### 12.3.1. PPP በ -ta (kta)

#### 12.3.1.1. ከዚህ በፊት የማያያዣ ገጽታ -i- (aniṭ) ያለበት

*aniṭ* = „እንደማይሆን (*an-*) ቅድመ-ተከታይ ሳፊክስ (*-i-*) *t*“ (ማለትም እንደማይሆን የመገናኛ ቅጥያ *i*).

::: grammar-box
እንደማይሆን የመገናኛ ቅጥያ ሲጠቀም የተዘረጋው PPP በአጭር ሁኔታ ከድምፅ-በመጨረሻ ላይ የሚያልቁ መሰረቶች እና ከበርካታ ሌሎች መሰረቶች ይፈጠራል፣ እንደ ምን ዓይነት መዋቅር ያላቸው መሰረቶች የመገናኛ ቅጥያ ይኖራል ወይም አይኖርም በማለት ቋሚ ህግ መስጠት አይቻልም።

የ *aniṭ* መሰረቶች ዝርዝር በ Kielhorn, *Grammatik* § 298 ላይ ይገኛል።
:::
**ምሳሌዎች፡**

| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |
| **su** 5 U:br(⟪सु⟫) | **su-ta** :br(⟪सुत⟫) |

*seṭ* = *sa-iṭ* = „በመሆኑ (*sa-*) ቅድመ-ተከታይ ሳፊክስ (*-i-*) *t*“ (ማለትም በመገናኛ ቅጥያ *i* ጋር).

## 12.4. የድምጽ ማያያዝ ህጎች በቃላት ውስጥ

በ *aniṭ*- ስሪቶች ውስጥ የሚከተሉትን በቃላት ውስጥ የድምጽ ማያያዝ ህጎች መከተል ያስፈልጋል። **እነዚህ ህጎች ለመላው የሳንስክርት ቅርጽ ምላሽ መረዳት በጣም አስፈላጊ ናቸው።**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p በገለልተኛ የመዝጋት ድምፅ (ለምሳሌ t, th) ላይ ተዛማጅነት አያጣሉም:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct በ kt = ⟪क्त्⟫ ይተካል:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt በ ṣṭ = ⟪ष्ट्⟫ ይተካል:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. በገለልተኛ ድምፅ ላይ የማያዝ ነጻ-አልባ የመዝጋት ድምፅ – በ j ብቻ ሳይሆን – በተዛማጅ የማያዝ ነጻ-አልባ ድምፅ ይተካል:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (ለ 2ኛው የጊዜ ክፍል አስፈላጊ) |
| **5. jt በ kt ወይም ṣṭ ይተካል (በማንኛውም መንገድ አይደለም!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\&lt; \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. በገለልተኛ የመዝጋት ድምፅ + በገለልተኛ የመዝጋት ድምፅ » በገለልተኛ ነጻ-አልባ የመዝጋት ድምፅ + በገለልተኛ የመዝጋት ድምፅ (በርቶሎማየስ የአስፓይሬት ህግ):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t በ ḍh ይተካል ከዚያም ቀድሞ የነበረ i ወይም u ማጉላት; ወይም በ gdh. ከእንደዚህ አይነት ḍh በፊት a በ o, በጣም አልፎ ተርፎም በ ā ይተካል:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „ምስጢር ማድረግ”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::
