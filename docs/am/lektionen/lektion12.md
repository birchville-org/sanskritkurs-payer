## 12.1. ያለፈው ጊዜ ተገብሮ ተካፋይ (PPP)

ያለፈ ጊዜ ተገብሮ ዓረፍተ ነገሮችን ለመመስረት አንዱ መንገድ፣ Partizip Perfekt Passiv (PPP) ተብሎ በሚጠራው ግንባታ ነው።

::: grammar-box
**እንደ እውነቱ ከሆነ፣ PPP ከጊዜ ግንድ ስላልተፈጠረ እውነተኛ ተካፋይ (participle) አይደለም። ይልቁንም ከሥሩ በዋና ቅጥያ -ta ወይም -na የተገኘ የስም ምስረታ ነው። ስለዚህ በህንድ ሰዋሰው ውስጥ ስለ kta ቅጥያ ይነገራል።**
:::

### 12.1.1. ለተሻጋሪ ግሶች ንድፍ

::: grammar-box
**ባለቤት (kartṛ) በመሳሪያዊ (tṛtīyā) -- ቀጥተኛ ተሳቢ (karman) በስም መደብ (prathamā) -- Partizip Perfekt Passiv**

በዚህ ሁኔታ፣ PPP ከዕቃው ጋር በቁጥር፣ በውድቀት እና በጾታ ይስማማል።

ረዳት ግስ ("መሆን") አያስፈልግም።

ምሳሌዎች፦
> **sādhunā svarga āptaḥ** = ⟪साधुना⟫ ⟪स्वर्ग⟫ ⟪आप्तः⟫ = „(በቅዱሱ ሰው ሰማይ ተገኘ) = ቅዱሱ ሰው ሰማይን አግኝቷል።“
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन⟫ ⟪देवीष्टा⟫ = „(በብራህሚኑ አማልክቷ በመሥዋዕት ተመለከች) = ብራህሚኑ አማልክቷን በመሥዋዕት አምልኳል።“
:::

### 12.1.2. ለኢንትራንሲቲቭ ግሶች እና የእንቅስቃሴ ግሶች እቅድ I

::: grammar-box
**አድራጊ (kartṛ) በስም መደብ (prathamā) -- ያለፈው ጊዜ ተገብሮ ተካፋይ**

በዚህ ሁኔታ፣ ያለፈው ጊዜ ተገብሮ ተካፋይ (PPP) ከአድራጊው ጋር በቁጥር፣ በመደብ እና በጾታ ይስማማል። “ተገብሮ” የሚለው ያለፈው ጊዜ ተካፋይ ተሻጋሪ ላልሆኑ ግሶች (ቀጥተኛ ተሳቢ የሌላቸው ግሶች) እና የእንቅስቃሴ ግሶች ላይ አድራጊአዊ ትርጉም አለው።

ምሳሌ:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया⟫ ⟪नगरं⟫ ⟪गता⟫ = “የክሻትሪያዋ ሴት ወደ ከተማ ሄዳለች።”
:::

### 12.1.3. መርሐግብር II ለተሻጋሪ ላልሆኑ ግሶች እና የእንቅስቃሴ ግሶች

::: grammar-box
**ባለቤት (kartṛ) በመሳሪያ መራኁ (tṛtīyā) -- PPP በስም መራኁ ነጠላ ገለልተኛ ጾታ**

ምሳሌ፡
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(በክሻትሪያው (ወደ ከተማ) ተሄዷል) = ክሻትሪያው (ወደ ከተማ) ሄዷል።“

በስርዓተ-ጥለት II መሠረት ያለው አወቃቀር በስርዓተ-ጥለት I መሠረት ካለው አወቃቀር በጣም ያነሰ ነው።
:::

## 12.2. ስለ PPP ትርጉም

ስለዚህ፣ “ያለፈው ጊዜ ተገብሮ ተሳታፊ” (PPP) ተብሎ የሚጠራው ለተሻጋሪ ግሶች በዋነኝነት ተገብሮ ትርጉም ሲኖረው (**āpta** = “የተደረሰበት (የሆነ)”) እና ለማይሻገሩ ግሶችና ለእንቅስቃሴ ግሶች ገብሮ ትርጉም ሲኖረው (**gata** = “የሄደ”)፣ አንዳንድ ግሶች አሉ፣ PPP ሁለቱንም ገብሮ እና ተገብሮ ትርጉም ሊኖረው የሚችልባቸው፡

ለምሳሌ፡
- **gata** = ⟪गत⟫ = “የሄደ” (ገብሮ)፤ ነገር ግን ደግሞ፡ **gato mārgaḥ** = ⟪गतो⟫ ⟪मार्गः⟫ = “የተሄደበት መንገድ” (ተገብሮ)
- **āpta** = ⟪आप्त⟫ = “የተደረሰበት” (ተገብሮ)፣ “የደረሰ” (ገብሮ)

## 12.3. የPPP አፈጣጠር

::: grammar-box
የሚከተሉት የአፈጣጠር መንገዶች አሉ (ለእያንዳንዱ ሥር የራሱ PPP መማር አለበት!)፡

**(በአብዛኛው) ዝቅተኛ ደረጃ ሥር**

- **+ -ta**
  - ከማያያዣ አናባቢ **-i-** ጋር ከፊት ለፊቱ: **-ita**
  - ያለ ማያያዣ አናባቢ: **-ta**
- **+ -na**

የሴት ጾታ ግንዶች እንዲህ ናቸው: **-tā**, **-itā**, **-nā**; ገለልተኛው ጾታ እንደ **phala** n. ይረባል።
:::

### 12.3.1. PPP በ -ta (kta) ላይ

#### 12.3.1.1. ያለ ማያያዣ አናባቢ -i- (aniṭ)

*aniṭ* = "ያለ (*an-*) ቅጥያውን የሚቀድም (*-i-*) *t*" (ማለትም ያለ ማያያዣ አናባቢ *i*)።

::: grammar-box
ያለ ማያያዣ አናባቢ፣ PPP በአጠቃላይ በአናባቢ ከሚጨርሱ ሥሮች እንዲሁም ከሌሎች ብዙ ሥሮች ይፈጠራል፤ ነገር ግን ማያያዣ አናባቢው በምን ዓይነት መዋቅር ባላቸው ሥሮች ላይ እንደሚታይ ወይም እንደማይታይ ቋሚ ደንብ መስጠት አይቻልም።

የ*aniṭ* ሥሮች ዝርዝር በኪልሆርን፣ *ግራማቲክ* § 298 ላይ ይገኛል።
:::

## 12.4. በቃል ውስጥ ያሉ የድምፅ ውህደት ህጎች

በ*aniṭ* አፈጣጠር ጊዜ በቃል ውስጥ ያሉትን የሚከተሉትን የድምፅ ውህደት ህጎች ልብ ማለት ያስፈልጋል። **እነዚህ ህጎች ለመላው የሳንስክሪት ቅርፅ ጥናት (morphology) ግንዛቤ በጣም አስፈላጊ ናቸው።**

::: no-header
| | |
| :--- | :--- |
