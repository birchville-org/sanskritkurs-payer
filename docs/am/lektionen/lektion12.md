# ትምህርት 12


## 12.1. ፓርቲሲፕ ፐርፌክት ፓሲቭ (PPP)

አንድ የሆነ ለጥፊ ለቀድሞ ጊዜ ለመገንባት የሚያገለግለው መንገድ ከተባለው ፓርቲሲፕ ፐርፌክት ፓሲቭ (PPP) ጋር የሚደረግ ግንኙነት ነው።

::: grammar-box
**በእውነቱ PPP እውነተኛ ፓርቲሲፕ አይደለም፣ ምክንያቱም ከጊዜ ስር ስለማይፈጠር። ይልቁንም ከመሠረት ጋር ከመጀመሪያው ተሸጋገሪ -ta ወይም -na ጋር የሚደረግ የስም ልማት ነው። ስለዚህ በሕንድ ስነ-ጽሑፍ ስለ kta ተሸጋገሪ ይነገራል።**
:::

### 12.1.1. ለትራንዚቲቭ ግሴቶች ስኬማ

::: grammar-box
**አገልጋይ (kartṛ) በመሳሪያ (tṛtīyā) -- ቀጥተኛ ነገር (karman) በክፍል (prathamā) -- ፓርቲሲፕ ፐርፌክት ፓሲቭ**

PPP በዚህ ሁኔታ ከነገር ጋር በቁጥር፣ በክፍል እና በፆታ ይስማማል።

የእርዳታ ግሴት ("ሆነ") አያስፈልግም።

ምሳሌዎች:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = „(ከቅዱስ የተገኘ ገነት) = ቅዱሱ ገነትን አግኝቷል።“
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = „(ከብራህማኑ የተከበረችው ጌታ በቅዳሜ) = ብራህማኑ ጌታን በቅዳሜ አከበረች።“
:::

### 12.1.2. ስኬማ I ለኢንትራንዚቲቭ ግሴቶች እና ለእንቅስቃሴ ግሴቶች

::: grammar-box
**አገልጋይ (kartṛ) በክፍል (prathamā) -- ፓርቲሲፕ ፐርፌክት ፓሲቭ**

በዚህ ሁኔታ PPP ከአገልጋይ ጋር በቁጥር፣ በክፍል እና በፆታ ይስማማል። ፓርቲሲፕ ፐርፌክት „ፓሲቭ“ ኢንትራንዚቲቭ ግሴቶች (ቀጥተኛ ነገር የሌላቸው ግሴቶች) እና ለእንቅስቃሴ ግሴቶች ንቁ ትርጉም አለው።

ምሳሌ:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = „የክሽትሪያ ሴት ወደ ከተማ ገብታለች።“
:::

### 12.1.3. סכמה II לזמרים לא-טרנזיטיביים ולזמרי תנועה

::: grammar-box
**אגנס (קארטר) באינסטרומנטליס (טרטייה) -- PPP בנומינטיב סוגר נייטרל**

דוגמה:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(על ידי ה-קשטריה נכנס (לעיר)) = ה-קשטריה נכנס (לעיר).“

הקונסטרוקציה לפי סכמה II נדירה יותר מהקונסטרוקציה לפי סכמה I.
:::

## 12.2. על משמעות ה-PPP

בעוד שמה שנקרא „פארטיסיפ פפרקט פאסיב“ לזמרים טרנזיטיביים בעיקר בעל משמעות פאסיבית (**āpta** = „הושג (נעשה)“) ולזמרים לא-טרנזיטיביים ולזמרי תנועה בעל משמעות אקטיבית (**gata** = „הלך“), ישנם כמה זמרים שבהם ה-PPP יכולה להיות גם אקטיבית וגם פאסיבית:

למשל
**gata** = ⟪गत⟫ = „הלך“ (אקטיבי); אבל גם: **gato mārgaḥ** = ⟪गतो मार्गः⟫ = „דרך שהלכה“ (פאסיב)
**āpta** = ⟪आप्त⟫ = „הושג“ (פאסיב), „משיג“ (אקטיבי)


## 12.3. יצירת ה-PPP

::: grammar-box
להלן דרכי היצירה הנפוצות (יש ללמוד עבור כל שורש את ה-PPP המתאים לו!):

**(בדרך כלל) שורש ברמה עמוקה**

**+ -ta**
עם ווקאל חיבור **-i-** לפני: **-ita**
ללא ווקאל חיבור: **-ta**
**+ -na**

שורשי הנקבה נכתבים: **-tā**, **-itā**, **-nā**; הנייטרל מתאים כמו **phala** n.
:::

### 12.3.1. PPP על -ta (kta)

#### 12.3.1.1. ללא ווקאל חיבור -i- (aniṭ)

*aniṭ* = „ללא (*an-*) לפני הסופיקס (*-i-*) *t*“ (כלומר ללא ווקאל החיבור *i*).

::: grammar-box
በመያያ ቃል (Bindevokal) ሳይሆን፣ PPP በአጠቃላይ ከቃላት በመጨረሻ በቃላት የሚወጡ ሥሮች እና ብዙ ሌሎች ሥሮች ይፈጠራል፣ ምንም እንኳን ምን ዓይነት ሥሮች ላይ መያያ ቃል እንደሚኖር ወይም እንደማይኖር ግልጽ ህግ ለመስጠት አይቻልም።

የ *aniṭ* ሥሮች ዝርዝር በ Kielhorn, *Grammatik* § 298 ውስጥ ይገኛል።
:::

## 12.4. በቃል ውስጥ የድምጽ ጥምረት ህጎች

በ *aniṭ* ልጆች ላይ የሚከተሉት የድምጽ ጥምረት ሕጎች በቃሉ ውስጥ መከታተል አለባቸው። **እነዚህ ሕጎች ለሙሉው የሳንስክሪት ቅርጽ ትምህርት ግንዛቤ በጣም አስፈላጊ ናቸው።**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p ከሌለ ድምጽ ያለው የመዝጋት ድምጽ (ለምሳሌ t, th) በፊት ሳይቀየር ይቆያሉ፡** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct በ kt = ⟪क्त्⟫ ይተካል፡** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt በ ṣṭ = ⟪ष्ट्⟫ ይተካል፡** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. ድምጽ ያለው ሳይፈነዳ የመዝጋት ድምጽ – በ j በስተቀር – ከሌለ ድምጽ ያለው ድምጽ በፊት በተዛመደው ሳይፈነዳ የመዝጋት ድምጽ ይተካል፡** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (ለ 2ኛው የጊዜ ክፍል አስፈላጊ ነው) |
| **5. jt በ kt ወይም ṣṭ ይተካል (አማራጭ አይደለም!)፡** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. ድምጽ ያለው ፈነዳ የመዝጋት ድምጽ + ሌለ ድምጽ ያለው የመዝጋት ድምጽ » ድምጽ ያለው ሳይፈነዳ የመዝጋት ድምጽ + ድምጽ ያለው ፈነዳ የመዝጋት ድምጽ (የ Bartholomae ፈነዳ ሕግ)፡** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t በ ḍh ይተካል ከዚያም ቀድሞ ያለ i ወይም u ይረዝማል፤ ወይም በ gdh። ከእንደዚህ አይነት ḍh በፊት a በ o ይተካል፣ በጣም አልፎ አልፎ በ ā ይተካል፡** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „አንድ ነገር ማደን”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::
