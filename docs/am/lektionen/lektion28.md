# ትምህርት 28

## 28.1. አስደራጊው (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**አንድ ሰው ወይም ነገር፣ ሌላ ሰው ወይም ሌላ ነገር (ከቅድመ-ግስ ጋር ወይም ያለ ቅድመ-ግስ) በስር የሚገለጽን አንድ ነገር እንዲያደርግ ወይም እንዲደርስበት እንደሚያደርግ ወይም እንደሚያስከትል ለመግለጽ ሲፈለግ፣ አስደራጊው (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫) ጥቅም ላይ ይውላል።**

ምሳሌ፦
⟪गम्⟫ "መሄድ" » አስገዳጅ ግስ፦ ⟪गमयति⟫ "አንድ ሰው እንዲሄድ ያደርጋል፤ ይልካል"
⟪दृश्⟫ "ማየት" » አስገዳጅ ግስ፦ ⟪दर्शयति⟫ "እንዲያይ ያደርጋል = ያሳያል"
:::

## 28.2. ከአስገዳጅ ግስ ጋር የአረፍተ ነገር አወቃቀር (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**መርሐግብር 1፦**

**ለአስገዳጅ ግሱ መሠረት የሆነው ሥር (ቅድመ-ግስ ያለው ወይም የሌለው) ተሻጋሪ ካልሆነ (ማለትም፣ ተሳቢ ሊኖረው የማይችል) ወይም እንቅስቃሴን፣ ዕውቀትን፣ መረጃን ወይም መብላትን የሚገልጽ ከሆነ፦**

**የአስገዳጅ ግስ ፈጻሚ (⟪कर्ता⟫) በስም መደብ (⟪प्रथमा⟫) — የተቀሰቀሰው ድርጊት ፈጻሚ በተሳቢ መደብ (⟪द्वितीया⟫) — (የእንቅስቃሴው ግብ፣ የእውቀት ነገር ወዘተ. በተሳቢ መደብ = ⟪द्वितीया⟫) — አስገዳጅ ግስ**
:::
ምሳሌዎች፦

⟪दुर्जनो⟫ ⟪रामं⟫ ⟪मोहयति⟫ = "አንድ ክፉ ሰው ራማ እንዲደናገር ያደርጋል = ራማን ያደናግረዋል = ራማ እንዲሳሳት ያደርጋል"
ውጤት፦ ⟪रामो⟫ ⟪मुह्यति⟫ = "ራማ ተደናግሯል / ታውሯል / ተሳስቷል።"

⟪रामः⟫ ⟪शत्रून्स्वर्गं⟫ ⟪गमयति⟫ = "ራማ ጠላቶቹ ወደ ሰማይ እንዲሄዱ ያደርጋል = ጠላቶቹን ወደ ሰማይ ይልካል"
ውጤት፦ ⟪शत्रवः⟫ ⟪स्वर्गं⟫ ⟪गच्छन्ति⟫ = "ጠላቶቹ ወደ ሰማይ ይሄዳሉ / ወደ ሰማይ ይመጣሉ"

⟪गुरू⟫ ⟪रामं⟫ ⟪वेदार्थं⟫ ⟪वेदयति⟫ = "መምህሩ ራማ የቬዳን ትርጉም እንዲያውቅ ያደርጋል = ለራማ የቬዳን ትርጉም ያብራራል / ያስተምራል"
ውጤት፦ ⟪रामो⟫ ⟪वेदार्थं⟫ ⟪वेत्ति⟫ = "ራማ የቬዳን ትርጉም ያውቃል / ይረዳል"

⟪स⟫ ⟪रामं⟫ ⟪वेदमध्यापयति⟫ = "እሱ ራማን ቬዳን ያስተምረዋል"
ውጤት፦ ⟪रामो⟫ ⟪वेदमधीते⟫ "ራማ ቬዳን ያጠናል"

⟪रामो⟫ ⟪देवानामृतमाशयति⟫ = "ራማ አማልክቱ የማይሞት ምግብ እንዲበሉ ያደርጋል = ለአማልክቱ የማይሞት ምግብ እንዲበሉ ይሰጣል" (⟪अश्⟫ 9 "መብላት")
ውጤት፦ ⟪देवा⟫ ⟪अमृतमश्नन्ति⟫ "አማልክቱ የማይሞት ምግብ ይበላሉ"

**መርሃግብር 2፡**

**በተሻጋሪ ግሶች (በስዕላዊ መግለጫ 1 ከተጠቀሱት በስተቀር)። እንዲሁም በሁሉም ግሶች ላይ፣ በምክንያታዊ ግስ የተገለጸው ነገር እንዲፈጸም ሲደረግ (ማለትም ምክንያታዊ ግሱ ለሌላ ምክንያታዊ ግስ ምክንያት ሲሆን)፦**

**የምክንያታዊ ግሱ ፈጻሚ (⟪कर्ता⟫) በባለቤትነት መደብ (⟪प्रथमा⟫) — የተፈጸመው ድርጊት ፈጻሚ በመሳሪያነት መደብ (⟪तृतीया⟫) — የተፈጸመው ድርጊት ተሳቢ በቀላል ግሱ መሠረት በሚኖረው መደብ (ማለትም በአብዛኛው በተሳቢ መደብ) — ግሱ በምክንያታዊ መልክ**
:::

⟪विष्णुमित्रो⟫ ⟪रामेण⟫ ⟪गोविन्दं⟫ ⟪गमयति⟫ = "ቪሽኑሚትራ ራማ ጎቪንዳን እንዲሄድ እንዲያደርገው ያደርጋል = ቪሽኑሚትራ ራማ ጎቪንዳን እንዲልከው ያደርጋል"
ውጤት፦ ⟪रामो⟫ ⟪गोविन्दं⟫ ⟪गमयति⟫ = "ራማ ጎቪንዳን ይልከዋል"
የዚህ ውጤት ውጤት፦ ⟪गोविन्दो⟫ ⟪गच्छति⟫ = "ጎቪንዳ ይሄዳል"
:::

⟪रामो⟫ ⟪बालेनान्नमादयति⟫ ⟪खादयति⟫ ⟪वा⟫ = "ራማ ልጁን ምግብ እንዲበላ ወይም እንዲያኘክ ያደርገዋል"
ውጤት: ⟪बालो⟫ ⟪ऽन्नमत्ति⟫ ⟪खादति⟫ ⟪वा⟫ = "ልጁ ምግብ ይበላል ወይም ያኝካል"

አስደራጊ ግስ በተገብሮ አረፍተ ነገር ውስጥ ጥቅም ላይ ሲውል፣ ሁልጊዜ ማለት ይቻላል የሚከተለው መዋቅር ይተገበራል፦

::: grammar-box
**መዋቅር ሀ (ተገብሮ አረፍተ ነገር)፦**

**የአስደራጊው ግስ ፈጻሚ በመሳሪያዊ (⟪तृतीया⟫) — የተደረገው ድርጊት ፈጻሚ በስም አኳያ (⟪प्रथमा⟫) — የተደረገው ድርጊት ተሳቢ በቀላል ግስ መሠረት በሚኖረው መደብ (ማለትም አብዛኛውን ጊዜ በተሳቢ መደብ) — ግሱ በአስደራጊ መልክ**
:::
ምሳሌዎች፦

⟪गुरुणा⟫ ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫ = "መምህሩ ራማን ወደ መንደሩ ይልከዋል"
ውጤት፦ ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "ራማ ወደ መንደሩ ይሄዳል"

⟪रामेण⟫ ⟪भृत्यः⟫ ⟪कटं⟫ ⟪कार्यते⟫ = "ራማ አገልጋዩን ምንጣፍ እንዲሰራ ያደርገዋል"
ውጤት፦ ⟪भृत्यः⟫ ⟪कटं⟫ ⟪करोति⟫ = "አገልጋዩ ምንጣፍ ይሠራል"

⟪रामेण⟫ ⟪भृत्यो⟫ ⟪भारं⟫ ⟪हार्यते⟫ = "ራማ አገልጋዩን ሸክሙን እንዲያመጣ ያደርገዋል"
ውጤት፦ ⟪भृत्यो⟫ ⟪भारं⟫ ⟪हरति⟫ = "አገልጋዩ ሸክሙን ያመጣል"

**ልክ እንደ አስገዳጅ ግሶች፣ አንዳንድ የ10ኛው የአሁን ጊዜ ክፍል ሥሮች አስገዳጅ ሳይሆኑ የአሁን ጊዜን (እና ሌሎች ጊዜዎችን) ይፈጥራሉ።**

ምሳሌዎች፡
1.  የተለጠጠ ሥር + -aya- : ⟪कम्⟫ 10Ā ⟪कामयते⟫ "መውደድ"
2.  ከፍተኛ ደረጃ ሥር + -aya- : **cur** 10U **corayati** "መስረቅ"; ወደፊት፡ **corayiṣyate**; ተገብሮ፡ **coryate**
:::
::: grammar-box
**የ10ኛው የአሁን ጊዜ ክፍል ግሶች አስገዳጅ ቅርጾች ከተራው ግስ ቅርጾች ጋር ተመሳሳይ ናቸው። አስገዳጅ ግስ መኖሩን መወሰን የሚቻለው ከትርጉሙ ወይም አንዳንድ ጊዜ ከአረፍተ ነገር አወቃቀሩ ብቻ ነው።**
