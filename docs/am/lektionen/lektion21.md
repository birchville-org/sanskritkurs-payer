# ትምህርት 21

## 21.1. ሌሎች የ-present stems በ -nt

### 21.1.1. Present Participle (⟪लडादेशः⟫) Parasmaipada

::: grammar-box

ይህ ቃል ከ-present stem የተፈጠረ ስም እና እውነተኛ ቃል ነው። እንደ ቃል ነው፣ ማንም ሰው ወይም ነገር በ-verb root (+ prefix) የሚገለጸውን ነገር እየሰራ ነው ብሎ ያሳያል። ሌላ ነገር እየተከሰተ ሲሆን። ረጅም ጊዜ ሁኔታም በዚህ ሊገለጽ ይችላል።

**ምሳሌዎች:**

:::

::: indent

"አባት ሲያነብ፣ ሲጠብቅ ነው = የሚያነብ አባት ሲጠብቅ ነው"  
"እውነተኛ (እውነተኛ) ጓደኛ"

:::

::: grammar-box

| | **6. present class** | Present stem + **-nt-** + **-ī** :broder::brPresent stem + **-t-** + **-ī** |
