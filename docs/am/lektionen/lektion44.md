## 44.2. ስለ ቃል-ሳንዲ

በተነባቢ በሚጨርሱ የአሁን ጊዜ ግንዶች ላይ፣ አስቀድሞ የተብራሩት የቃል-ሳንዲ ሕጎች መታየት አለባቸው።

በተጨማሪም፣ የሚከተሉት የቃል-ሳንዲ ሕጎች ተግባራዊ ይሆናሉ።

(ከዚህ ጋር የተያያዙ የድምፅ ለውጦች ሁሉ ዝርዝር ማጠቃለያ በኪልሆርን፣ ሰዋሰው ገጽ 76f ላይ ይገኛል።)

### 44.2.1. ለ dh- ስለ ቃላት-ሳንዲሂ

::: grammar-box
1. **አስፒራታ ከአስፒራታ በፊት ሲመጣ በተዛማጁ አስፒራታ ባልሆነው ይተካል፡**
ለምሳሌ ⟪रुध्⟫ 7U: ⟪रुन्ध्⟫ + ⟪ध्वे⟫ » ⟪रुन्द्ध्वे⟫ (run**ddh**ve)
2. **-h + dh- » -gdh-**
ለምሳሌ ⟪दुह्⟫ 2U: ⟪दुह्⟫ + ⟪ध्वे⟫ » ⟪धुग्ध्वे⟫ (dhu**gdh**ve)
3. **-ṣ + dh- » -ḍḍh-** (ይህ ህግ የሚሰራው ለግስ እርባታ ብቻ ነው!)
ለምሳሌ ⟪द्विष्⟫ 2U: ⟪द्विष्⟫ + ⟪ध्वे⟫ » ⟪द्विड्ढ्वे⟫ (dvi**ḍḍh**ve)
4. **-s + dh- » -dh-** (-s ይወድቃል)
ለምሳሌ ⟪आस्⟫ 2Ā: ⟪आस्⟫ + ⟪ध्वे⟫ » ⟪आध्वे⟫ (ādhve)
:::
### 44.2.2. ለ s- ስለ ቃላት-ሳንዲሂ

::: grammar-box
1. **-s + s- » -ts- ወይም (በምርጫ አይደለም!) -ss-** (በ2ኛ የፕሬዘንስ ክፍል እንደሚሆነው)
ምሳሌዎች፡
* ⟪वस्⟫ 1P: የወደፊት ጊዜ፡ ⟪वस्⟫ + ⟪स्य⟫ + ⟪ति⟫ » ⟪वत्स्यति⟫ (va**ts**yati)
* ⟪वस्⟫ 2Ā: ⟪वस्⟫ + ⟪से⟫ » ⟪वस्से⟫ (va**ss**e)
2. **-ṣ + s- » -kṣ-**
ለምሳሌ ⟪द्विष्⟫ 2U: ⟪द्वेष्⟫ + ⟪सि⟫ » ⟪द्वेक्षि⟫ (dve**kṣ**i)
:::

## 44.4. የጥሪ መደብ (ቮኬቲቭ) (⟪आमन्त्रितम्⟫)
