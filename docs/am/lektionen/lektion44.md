## 44.2. ስለ ዎርትሳንዲ

በቅርፊት-መጨረሻ ፕሬዝንት ስቶምስ ላይ፣ ቀድሞ የተወያዩት የዎርትሳንዲ ሕጎች መከተል አለባቸው።

በተጨማሪም የሚከተሉት የዎርትሳንዲ ሕጎች ይተገበራሉ።

(በዚህ ርዕስ ስር ካሉ ሁሉም የድምፅ ለውጦች ማጠቃለያ ለኪልፎርን፣ ግራማቲክ ገጽ 76f.)

### 44.2.1. ስለ dh- ለዎርትሳንዲ

::: grammar-box
1. **አስፒሬታ በአስፒሬታ ፊት በተዛመደው ኖን-ስፒራተት ይተካል፡**
ለምሳሌ፣ ⟪रुध्⟫ 7U: ⟪रुन्ध्⟫ + ⟪ध्वे⟫ » ⟪रुन्द्ध्वे⟫ (run**ddh**ve)
2. **-h + dh- » -gdh-**
ለምሳሌ፣ ⟪दुह्⟫ 2U: ⟪दुह्⟫ + ⟪ध्वे⟫ » ⟪धुग्ध्वे⟫ (dhu**gdh**ve)
3. **-ṣ + dh- » -ḍḍh-** (ይህ ህግ ለኮንጁጌሽን ብቻ ነው!)
ለምሳሌ፣ ⟪द्विष्⟫ 2U: ⟪द्विष्⟫ + ⟪ध्वे⟫ » ⟪द्विड्ढ्वे⟫ (dvi**ḍḍh**ve)
4. **-s + dh- » -dh-** (-s መጥፋት)
ለምሳሌ፣ ⟪आस्⟫ 2Ā: ⟪आस्⟫ + ⟪ध्वे⟫ » ⟪आध्वे⟫ (ādhve)
:::
### 44.2.2. ስለ s- ለዎርትሳንዲ

::: grammar-box
1. **-s + s- » -ts- ወይም (ምርጫ አልባ!) -ss-** (እንደ 2. ፕሬዝንት ክፍል)
ምሳሌዎች፡
* ⟪वस्⟫ 1P: ፉቹር፡ ⟪वस्⟫ + ⟪स्य⟫ + ⟪ति⟫ » ⟪वत्स्यति⟫ (va**ts**yati)
* ⟪वस्⟫ 2Ā: ⟪वस्⟫ + ⟪से⟫ » ⟪वस्से⟫ (va**ss**e)
2. **-ṣ + s- » -kṣ-**
ለምሳሌ፣ ⟪द्विष्⟫ 2U: ⟪द्वेष्⟫ + ⟪सि⟫ » ⟪द्वेक्षि⟫ (dve**kṣ**i)
:::

## 44.4. ቀረንታ (⟪आमन्त्रितम्⟫)
