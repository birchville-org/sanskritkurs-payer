## 41.2. Ďalšie ⟪कृत्⟫-tvary na -a

### 41.2.1. Prítomný príčestie (⟪लडादेशः⟫) Ā, pasívne prítomné príčestie (⟪लडादेशः⟫) a budúce príčestie (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Tématické prítomné korene, pasívum a budúci čas

::: grammar-box
**Vytvorenie:**

Prítomný kmeň / pasívny kmeň / budúci kmeň + -māna (ž. ród mānā)
:::
Príklady:

⟪यज्⟫ 1U, Part.Präs.Ā ⟪यजमान⟫ 3 "ten, kto uctieva obetou vo vlastnom záujme = pán obety"

⟪मन्⟫ 4Ā, Part.Präs.Ā  ⟪मन्यमान⟫ 3 "mysliaci"

⟪कृ⟫ 8U, Part.Präs.Passiv ⟪क्रियमाण⟫ 3 "niečo, čo sa robí"

⟪दा⟫ 3U, Part.Fut.Ā ⟪दास्यमान⟫ 3 "ten, kto bude dávať vo vlastnom záujme"

#### 41.2.1.2. Atématické prítomné triedy

::: grammar-box
**Vytvorenie:**

Slabý prítomný kmeň (v tvare, ktorý má pred koncovkou -ate 3.os.č.) + -āna (ž. ród -ānā)
:::
Príklady:

::: grammar-box
| Kmeň / Trieda | Prítomné príčestie Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "Participium" pasívnej nevyhnutnosti (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Na vyjadrenie pasívnej nevyhnutnosti ("čo sa musí/má urobiť") možno prídavné mená odvodené od koreňov a odvodných slovesných kmeňov tvoriť voľbou nasledujúcich prípon:**

* **-⟪तव्य⟫** (ž. r. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (ž. r. **-⟪अनीया⟫**)
* **-⟪य⟫** (ž. r. **-⟪या⟫**)
* **-⟪त्य⟫** (ž. r. **-⟪त्या⟫**) (namiesto **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Prípona -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Prípona -⟪तव्य⟫ / -⟪तव्या⟫ sa pripája ku koreňom a odvodným slovesným kmeňom (napr. kauzatív) rovnakým spôsobom ako infinitívna prípona -⟪तुम्⟫ (pozri [Lektion 23](lektion23.md)), t.j.**

* **stupeň posilnenia koreňa + ⟪तव्य⟫**

alebo

* **stupeň posilnenia koreňa + -i- + ⟪तव्य⟫**

**V kauzatíve:**

* **Kauzativný kmeň na -ay + -i- + ⟪तव्य⟫**
:::
Príklady:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "ten, kto musí byť porazený; ten, ktorý má byť porazený" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "to, kde sa má človek nachádzať" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "ten, kto má byť prebudený; ten, ktorý má byť prebudený" |

:::
#### 41.2.2.2. Prípona -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Tvorba:**

Stupeň posilnenia koreňa + -⟪अनीय⟫ / -⟪अनीया⟫

**Kauzatív a 10. trieda prítomného času:**

Koreň, v akom sa vyskytuje v kauzativnom kmeni, bez -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Príklady:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "čo má byť dané; čo sa musí dať" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "ten, ktorý má byť porazený" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "čo sa má urobiť" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "čo sa musí vidieť; čo stojí za to vidieť" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "ten, ktorý má byť prebudený" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "čo sa musí dať" |

:::
#### 41.2.2.3. Sufix -⟪य⟫ / -⟪या⟫

::: grammar-box
**Tvorba:**

Koreň (v nízk-, vysok- alebo predĺženom stupni) + -⟪य⟫

Presné pravidlá pozri u Kielhorna, Gramatika sanskrtského jazyka, s. 195 - 197!
:::
Zaobchádzanie s výslednými samohláskami:

::: grammar-box
**1. Korene na -ā tvoria toto gerundívum na -eya**
:::
Príklady:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "poznateľné; čo musí byť spoznané" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "čo musí byť dané" |

:::
::: grammar-box
**2. Korene na -i /-ī / -u / -ū /-ṛ majú spravidla vysoký alebo predĺžený stupeň, pokiaľ nepatria k tým koreňom na -i / -u /-ṛ, ktoré tvoria gerundívum so sufixom -⟪त्य⟫ (ž. r. -⟪त्या⟫) (zoznam týchto koreňov u Kielhorna, Gramatika §537).**
:::

#### 41.2.2.4. Suffix -⟪त्य⟫ / ⟪त्या⟫ (namiesto -⟪य⟫ / -⟪या⟫)

::: grammar-box
Zoznam koreňov končiacich na -i / -u /-ṛ, ktoré tvoria gerundívum nie s -⟪य⟫ / -⟪या⟫, ale s suffixom -⟪त्य⟫ (ženský rod -⟪त्या⟫), pozri Kielhorn, Gramatika §537.

**Budovanie:**

kmeň v hlbokom stupni + -⟪त्य⟫ / -⟪त्या⟫

### 41.2.3. Syntax k „participiu“ pasívnej nevyhnutnosti (gerundívmum) (⟪कृत्य⟫)

::: grammar-box
Gerundívmum sa môže použiť atributívne:

:::

**⟪दर्शनीयं नगरम्⟫** = „mesto, ktoré treba vidieť; zaujímavé mesto“

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = „Dvaja narodení musia vidieť Benares“

### 41.2.4. Rozdiely v používaní gerundívnych prípon

::: grammar-box
Používanie týchto prípon sa vo veľkej miere prekrýva

* **-⟪तव्य⟫ (fem. -⟪तव्या⟫):** vždy vyjadruje nevyhnutnosť a používa sa preferenčne predikatívne (zriedkavo atributívne). Tvary s touto príponou sa nemajú používať v nominálnych kompozitách.
* **-⟪अनीय⟫ (fem. -⟪अनीया⟫) a -⟪य⟫ (fem. -⟪या⟫) / -⟪त्य⟫ (fem. -⟪त्या⟫) (miesto -⟪य⟫/-⟪या⟫):** môžu mať ďalší význam (najmä -⟪य⟫) v zmysle nemeckého „-wert“ (napr. „hodný pozretia“) alebo len možnosti „-bar“ (⟪दृश्य⟫ „viditeľný“). Tvary s týmito príponami sa môžu záporne vyjadriť pomocou ⟪अ⟫-/-⟪अन्⟫- (nie však tvary s -⟪तव्य⟫) a existujú ⟪तत्पुरुष⟫ ako ich zadné členy, v ktorých sa vyskytujú.
:::
### 41.2.5. Žiadne spojenie s ⟪सु⟫- a ⟪दुस्⟫-

::: grammar-box
S ⟪सु⟫- a ⟪दुस्⟫- v zmysle „ľahko“ resp. `ťažko` sa gerundíva nesmú spájať. Namiesto toho stoja ⟪तत्पुरुष⟫ typu  ⟪सुकर⟫ 3 („ľahko urobiť“) (pozri [Lekcia 18](lektion18.md)).
:::
