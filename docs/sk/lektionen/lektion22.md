# Lekcia 22

## 22.1. Absolutívum (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

Ak chce v sanskrite vyjadriť, že činnosť agensa (⟪कर्तृ⟫) predchádza inej činnosti agensa alebo s ňou súvisí ako sprievodná okolnosť, používa sa absoltívum (⟪क्त्वा । ल्यप्⟫). Teda

„po tom, čo to urobil, robí tamto“; „robí toto, potom robí tamto“; „ako následok tohto robí tamto“; „prišiel, videl a zvíťazil“ atď.

Absolutívum je verbálne príslovie, to znamená, že nie je ani skloňované, ani časované; má však vždy – s výnimkou niekoľkých málo výnimiek – toho istého agensa (⟪कर्तृ⟫) ako činnosť, ktorej predchádza alebo ktorú sprevádza činnosť vyjadrená absoltívom. Agent absolutíva je teda v nominatíve (⟪प्रथमा⟫) alebo inštrumentáli (⟪तृतीया⟫).

Vedľa kompozít je absolutívum jedným z najčastejších vyjadrovacích prostriedkov v sanskrite.

Pri preklade do nemčiny sa vyhnite neustálemu používaniu slova „po tom, čo“. Namiesto toho použite v nemčine bežné spôsoby vyjadrovania časového za sebou nasledovania.

**Schéma:**

(bližšie určenie k absolutívu: okolnostné určení, objekty atď.) - Absolutívum - Absolutívum - ... - Absolutívum - ... Agent + slovesná veta (v aktíve alebo pasíve)

:::
**Príklady:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = pasívna konštrukcia: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**
„Muž vstupuje do domu, vidí malé dievča a oslovuje ho.“

Množné číslo: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. Tvorba absolútu

::: grammar-box
**Tvorba absolútu**

*   Slovesá bez prefixu: absolutív na **-tvā**
*   Slovesá s prefixom: absolutív na **-ya** resp. **-tya**
:::
### 22.2.1. Slovesá bez prefixu: absolutív na -⟪त्वा⟫

::: grammar-box

**Tvorba:**

(zvyčajne) koreň v slabom stupni v tvare, ktorý má pred PPP + **-tvā** (**-⟪त्वा⟫**)

Iba záporové **a-** / **an-**兼容 s príponou **-⟪त्वा⟫** : ⟪अकृत्वा⟫ "bez toho, aby urobil"

:::
**Príklady:**

::: indent
⟪आप्त्वा⟫ "po tom, čo on / ona / ono / ja / ty / my / vy / oni / my dvaja / vy dvaja / oni dvaja dosiahol / dosiahla / dosiahlo"

⟪आसित्वा⟫ "po tom, čo on (...) sedel / je"

⟪इत्वा⟫ "po tom, čo on (...) išiel / je"

⟪स्थित्वा⟫ "po tom, čo on (...) stál / je"

⟪जित्वा⟫ "po tom, čo on (...) zvíťazil / zvíťazila"

⟪उक्त्वा⟫ "po tom, čo on (...) hovoril / povedal"
:::
### 22.2.2. Slovesá s prefixom

#### 22.2.2.1. Korene na dlhý samohlásku (okrem -ā) alebo na spoluhlásku

::: grammar-box

**(zvyčajne) koreň v slabom stupni + -ya**

:::
**Príklady:**

::: indent
⟪उपनीय⟫ "po tom, čo on (...) priviedol / priviedla"

⟪प्रभूय⟫ "po tom, čo on (...) vyčnieval / vyčnievala" "po tom, čo mal moc"

⟪प्राप्य⟫ "po tom, čo on (...) získal / získala"
:::
#### 22.2.2.2. Korene na -ā

::: grammar-box

**nezmenený koreň v silnom stupni + -ya**

:::
**Príklad:**

::: indent
⟪उपस्थाय⟫ "po tom, čo on (...) vstúpil / vstúpila" ; (ale bez prefixu: ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. Korene, ktoré v slabom stupni končia na krátké -i, -u, -ṛ

::: grammar-box

**koreň v nízkej stupni + -tya**

:::
**Príklady:**

::: indent
⟪प्रस्तुत्य⟫ "po tom, čo (...) hlasno oslávil / bol oslávil"

⟪विस्मृत्य⟫ "po tom, čo (...) zabudol / bol zabudol"

⟪संस्कृत्य⟫ "po tom, čo (...) na obeť pripravil / bol pripravil"
:::
#### 22.2.2.4. Korene na -am / -an, ktoré v nízkej stupni končia na -a

::: grammar-box

**Voliteľné:**

Koreň na **-am** / **-an** + **-ya**

alebo:

Koreň na **-a** + **-tya**

:::
**Príklad:**

::: indent
⟪विगम्य⟫ alebo ⟪विगत्य⟫ "po tom, čo (...) uplynul / bol"
:::
