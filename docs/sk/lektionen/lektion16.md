# Lekcia 16

## 16.1. K sandhi koncových spoluhlások

Na tvorbu zloženín, ktorých prvý člen tvoria korene končiace na spoluhlásku, sú potrebné nasledujúce pravidlá:

Koncové velárne, retroflexné, dentálne a labiálne uzatváracie spoluhlásky (t.j. nie nosové ani palátalne).

::: no-header

|   |   |
| :--- | :--- |
| **v pauze a pred bezhlásnymi zvukmi** | **Nahrada zodpovedajúcim bezhlásnym neaspirovaným zvukom:** :br **napr.** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **pred hláskami s hlasivkovou vibráciou, ktoré nie sú nosové** | **Nahrada zodpovedajúcim hláskam s hlasivkovou vibráciou, ktoré nie sú aspirované:** :br **napr.** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **pred nosovkami** | **Nahrada zodpovedajúcou nosovkou:** :br **napr.** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::
Výnimka z vyššie uvedeného pravidla:

Koncová dentálna uzatváracia spoluhláska (nie nosovka):

::: no-header

|   |   |
| :--- | :--- |
| **pred palatálmi** | **Nahrada príslušnou neaspirovanou palatálnou spoluhláskou:** :br **t.j.** :br :indent -t + c- » -cc- :br :indent -d + c- » -cc- :br :indent -th + c- » -cc- :br :indent -dh + c- » -cc- :br :indent -t/-th/-d/-dh + ch- » -cch- :br :indent -t/-th/-d/-dh + j- » -jj- :br :indent -t/-th/-d/-dh + jh- » -jjh- |
| **+ ś** | **» -cś- alebo -cch-** |
| **pred retroflexmi** | **Nahrada príslušnou neaspirovanou retroflexnou spoluhláskou:** :br **t.j.** :br :indent -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- :br :indent -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **pred l-** | **Nahrada za -l:** :br **t.j.** :br :indent -t/-th/-d/-dh + l- » -ll- |

:::
Príklady:

⟪तद्⟫ + ⟪फल⟫ = ⟪तत्फल पुण्यवत्⟫ + ⟪ब्राह्मण⟫ = ⟪पुण्यवद्ब्राह्मण पुण्यवत्⟫ + ⟪नर⟫ = ⟪पुण्यवन्नर पुण्यवत्⟫ + ⟪पुरुष⟫ = ⟪पुण्यवत्पुरुष सत्यवत्⟫ + ⟪चैतन्य⟫ =⟪सत्यवच्चैतन्य सुखवत्⟫ + ⟪लोक⟫ = ⟪सुखवल्लोक पुत्रवत्⟫ + ⟪जन⟫ = ⟪पुत्रवज्जन बलवत्⟫ + ⟪शत्रु⟫ = ⟪बलवच्छत्रु⟫
