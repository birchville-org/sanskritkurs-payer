# Devanāgarī = ⟪देवनागरी⟫

## Písomný cvik 4

![](/images/schrift006.webp)

Anusvāra ṃ: Bodka nad písmenom. predchádza zvuku, ktorému je priradené: ⟪कं कां किं कीं कुं कूं कें कैं कों कौं⟫

Zápis:

![](/images/schrift007.jpg)

Všímajte si povinný zápis hṛ: ⟪हृ⟫

## Cviky

A) Napíšte do Devanāgarī:

nṛt nī man muh sṛjati viśati yajate viśeṣaḥ namas doṣo mūlaṃ meru hṛdayaṃ hanumat hariṃ setuṃ puruṣaṃ kumārī satī saṃśayaṃ
