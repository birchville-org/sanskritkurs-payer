# Lekcia 3

## 3.1. Nominatív singuláru ženského rodu

### 3.1.1. Nominatív singulár na -s

Nasledujúce kmeňe podstatných mien, ktoré končia na samohlásku, tvoria nominatív singulára na **-s**:

::: grammar-box
**Ženské mená na -i**: napr. **śruti** ž. „počúvanie“ – Nom. sg.: **śrutis** = ⟪श्रुतिस्⟫
**Ženské mená na -u**: napr. **dhenu** ž. „dojnica“ – Nom. sg.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Nominatív singulár bez koncovky

Nominatív singulár tvoria bez koncovky:

::: grammar-box
**Ženské mená na -ā**: napr. **devatā** ž. „božstvo“ – Nom. sg.: **devatā** = ⟪देवता⟫
**Ženské mená na -ī**: napr. **devī** ž. „bohyňa“ – Nom. sg.: **devī** = ⟪देवी⟫
:::
::: important
**Pozor!** Okrem toho existujú jednoslabičné ženské koreňové podstatné mená na -ī, ktorých nominatív singulár končí na -s: napr. dhī ž. „myšlienka“ – Nom. sg.: dhīs = ⟪धीस्⟫. Tiež lakṣmī (⟪लक्ष्मी⟫) ž., tarī (⟪तरी⟫) ž. „loď“ a tantrī (⟪तन्त्री⟫) ž. „struna“ tvoria nepravidelne nominatív singulár na -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Tvorba ženských podstatných mien k mužským

::: grammar-box
**Mužské mená na -a:**
**Ženské meno na -ā**: napr. **kṣatriya** m. » **kṣatriyā** ž. „žena Kšatríja“ = ⟪क्षत्रिया⟫
**Ženské meno na -ī**: napr. **brāhmaṇa** m. » **brāhmaṇī** ž. „brahmanka“ = ⟪ब्राह्मणी⟫

**Mužské mená na -u:**
**Ženské meno na -ī**: napr. **sādhu** m. » **sādhvī** ž. (dobrá, svätica) = ⟪साध्वी⟫
(**-u-** sa pred samohláskou mení na **-v-**, preto **-u- + -ī** » **-vī**)
:::

## 3.3. Nominatív plurálu mužského a ženského rodu

::: grammar-box
Koncovka nominatívu plurálu v mužskom a ženskom rode je **-as**.
**Mužské mená na -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
**Ženské mená na -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**Mužské mená na -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**Ženské mená na -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**Ženské mená na -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**Mužské mená na -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**Ženské mená na -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Poznámka: **e** je zvýšená hladina (**guṇa**) k **i**, **o** je zvýšená hladina k **u**.


## 3.4. Vokálový sandhi

::: grammar-box
**Jednoduché samohlásky, ktoré sa líšia len dĺžkou alebo vôbec, „splynú“ na príslušnú dlhú samohlásku:**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)
:::
napr.

devatā + annapūrṇā » devatānnapūrṇā „Annapūrṇá je bohyňa“ = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇá je bohyňa jedla a varenia, považuje sa za vtelenie Pārvatího, manželky Śivy.)

devī + indrāṇī » devīndrāṇī „Indrāṇí je bohyňa“ = ⟪देवीन्द्राणी⟫

> (Indrāṇí je manželka boha Indraho.)

::: grammar-box
**Jednoduché samohlásky (okrem -a / -ā) sa pred nezhodnými samohláskami nahradia príslušným polosamohláskovým zvukom:**
i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**
(!! K tomuto pravidlu existujú najmä pre duálne tvary výnimky !!)
:::
napr.

devī + umā » devy umá „Umá je bohyňa“ = ⟪देव्युमा⟫

> (Umá je meno pre Pārvatí, manželku Śivu)

::: grammar-box
**-a / -ā pred nezhodnou samohláskou:**
a / -ā + i- / ī- » **-e-**
a / -ā + ṛ- » **-ar-**
a / -ā + e- / ai- » **-ai-**
a / -ā + o- / au- » **-au-**
:::

## 3.5. Větný sandhi -ās

::: grammar-box
**-ās sa před všemi znělými hláskami mění na -ā.**
:::
napr.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ „Vaišjové jsou dvakrát zrození“ = ⟪द्विजा वैश्याः⟫


## 3.6. Slovní zásoba

**Naučte se následující slova:**

**śruti** f. = ⟪श्रुति⟫ : poslech, věčná tradice (označení pro Védy a Bráhmanu).

**smṛti** f. = ⟪स्मृति⟫ : připomenutí, paměť, meditativní připomenutí = bdělost, tradice (protiklad k **śruti**). Zahrnuje:
šest **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): správné vyslovování
2. **chandas** n. (⟪छन्दस्⟫): metrum
3. **vyākaraṇa** n. (⟪व्याकरण⟫): gramatika
4. **nirukta** n. (⟪निरुक्त⟫) : výklad slov, etymologie
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : astronomie, kalendářní nauka
6. **kalpa** m. (⟪कल्प⟫) : ceremoniál
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : učebnice pro provádění velkých obětí
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : učebnice pro ceremonie a oběti každodenního života
**dharmasūtra** n. (⟪धर्मसूत्र⟫) a **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : učebnice práva a mravů (správného chování)
velké epické básně **mahābhārata** n. (⟪महाभारत⟫) a **rāmāyaṇa** n. (⟪रामायण⟫)
**purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫) : učebnice životní moudrosti

**smṛti** je zvláště také označením pro dharmické učebnice.

**dhenu** ž. = ⟪धेनु⟫ : (mliečna) krava.

**paśu** m. = ⟪पशु⟫ : domestikované hospodárske zviera, dobytok (kolektívum).

**devatā** ž. = ⟪देवता⟫ : božstvo (abstraktné a konkrétné).

**brāhmaṇī** ž. = ⟪ब्राह्मणी⟫ : bráhmanistka.

**kṣatriyā** ž. = ⟪क्षत्रिया⟫ : ženský Kṣatriya.

**kṣatriyī** ž. = ⟪क्षत्रियी⟫ : manželka Kṣatriyu.

**vaiśyā** ž. = ⟪वैश्या⟫ : ženská Vaiśya.

**śūdrā** ž. = ⟪शूद्रा⟫ : ženská Śūdra.

**śūdrī** ž. / **śūdrāṇī** ž. = ⟪शूद्री शूद्राणी⟫ : manželka Śúdry.

**devī** ž. = ⟪देवी⟫ : bohyňa, najmä Durgā ž. = ⟪दुर्गा⟫, manželka Śivy = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
Obr.: Durgā = ⟪दुर्गा⟫, Orissa
(Zdroj obrázku: [Details](/images/lekt0303))
:::
**sādhvī** ž. = ⟪साध्वी⟫ : ženský rod k sādhu.

**gurvī** ž. = ⟪गुर्वी⟫ : ženský rod k guru.

**asmitā** ž. = ⟪अस्मिता⟫ : „ja-štvosť“, t. j. (falošná) viera: **Ja** som ten, kto vidí atď.

**ānvīkṣikī** ž. = ⟪आन्वीक्षिकी⟫ : filozofia (veda, ktorá prichádza k svojim záverom prostredníctvom logicky správnych odôvodnení).

**upekṣā** ž. = ⟪उपेक्षा⟫ : ignorovanie, rovnováha.

**karuṇā** ž. = ⟪करुणा⟫ : súcit, ľútosť.

**muditā** ž. = ⟪मुदिता⟫ : radosť, najmä súcitná radosť (protiklad k závisti).


## 3.7. Cvičenie

**A) Preložte nasledujúce vety do množného čísla:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**B) Vytvorte nominálne vety doplnením:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Preveďte do ženského rodu:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**D) Preložte do sanskrtu:**

1. Umā je bohyňa.
2. Veda je śruti.
3. Učiteľky sú bohyne.
4. Mliečne kravy sú domestikované zvieratá.
5. Básnici sú učitelia.
6. Kṣatriyas sú dvakrát narodení.
7. Svätí muži sú Śūdras.
