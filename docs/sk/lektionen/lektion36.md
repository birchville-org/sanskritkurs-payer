## 36.2. Perifrázické perfektum (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
Perifrázické perfektum (⟪अनुप्रयोगलिट्⟫) sa používa:

1. pri odvodených konjugáciách (kauzatív, desideratív, frekventatív, denominatíva)
2. pri koreňoch, ktoré začínajú dlhým samohláskou (okrem ā-), alebo samohláskou (okrem a-) pred dvoma spoluhláskami
3. pri niektorých iných koreňoch
:::
::: grammar-box
**Vznik:**

(slabý) kmeň prvého času + -ām + príslušný tvar dokonalého času (perfektum) od ⟪कृ⟫, ⟪अस्⟫ alebo ⟪भू⟫

Koncový samohláska kmeňa sa pred -ām guṇuje.
⟪अस्⟫ a ⟪भू⟫ sa konjugujú aj pri slovesách v átmänepade (sebeprázdnom spôsobe) v parasmaipade (svetoprázdny spôsob).
:::
Perifrázované perfektum pravdepodobne vzniklo z akuzatíva verbálneho podstatného mena na -ā. Tento akuzatív sa používa -- ako je inak často bežné -- adverbialne.

Príklady:

| Koreň: br⟪धातु⟫ | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪ईक्ष्⟫ 1Ā | | | **⟪ईक्षां चक्रे⟫** :br ⟪ईक्षामास⟫ :br **⟪ईक्षां बभूव⟫** | **⟪ईक्षां चक्रिरे⟫** :br ⟪ईक्षामासुर्⟫ :br **⟪ईक्षां बभूवुर्⟫** |
| ⟪बन्ध्⟫ :brKauzatív: ⟪बन्धय⟫-:br"nechať viazať" | **⟪बन्धयां चकार⟫** :br ⟪बन्धयामास⟫ :br **⟪बन्धयां बभूव⟫** | **⟪बन्धयां चक्रुर्⟫** :br ⟪बन्धयामासुर्⟫ :br **⟪बन्धयां बभूवुर्⟫** | | |




## 36.3. Perfektum pasíva

::: grammar-box
Pri perfektu sa pre pasívum používajú tvary átmänepady. Oproti tomu sa však uprednostňuje použitie PPP (prídavného mena z perfektnej participiovej formy). Konštrukcia je v oboch prípadoch konštrukciou pasívnych viet:

:::
::: indent
⟪तेन पुण्यं चक्रे⟫ = ⟪तेन पुण्यं कृतम्⟫ = "Urobil záslužné dielo"
:::
