# Úloha 54

Vytvorte príslušné aoristové tvary k nasledujúcim prítomným alebo perfektovým tvarom:

::: grammar-box
| Č. | Tvar | Určenie / Význam | Aorist |
|:---|:---|:---|:---|
| ⟪१⟫. | ⟪यन्ति⟫ | oni idú | ⟪अगुः⟫ |
| ⟪२⟫. | ⟪पिबामि⟫ | ja pijem | ⟪अपाम्⟫ |
| ⟪३⟫. | ⟪ददौ⟫ | ja som / on dal | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | ⟪बभूव⟫ | ja / on / oni boli / ste boli | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | ⟪दधति⟫ | oni sadajú / umiestňujú | ⟪अधुः⟫ |
| ⟪६⟫. | ⟪ऐम⟫ | my išli | ⟪अगाम⟫ |
| ⟪७⟫. | ⟪पपिथ⟫ | ty si pil / ochraňoval | ⟪अपाः⟫ (k :sig[⟪पा⟫] "piť") |
| ⟪८⟫. | ⟪तिष्ठति⟫ | on stojí | ⟪अस्थात्⟫ |
| ⟪९⟫. | ⟪इयेथ⟫ | ty si išiel | ⟪अगाः⟫ |
| ⟪१०⟫. | ⟪पप⟫ | vy ste pili | ⟪अपात⟫ |
| ⟪११⟫. | ⟪एष्यथ⟫ | vy pôjdete | ⟪अगात⟫ |
| ⟪१२⟫. | ⟪तस्थुः⟫ | oni stáli | ⟪अस्थुः⟫ |
| ⟪१३⟫. | ⟪अधत्त⟫ | vy ste sadali / umiestňovali | ⟪अधात⟫ |
| ⟪१४⟫. | ⟪अददाः⟫ | ty si dal | ⟪अदाः⟫ |
| ⟪१५⟫. | ⟪अभवन्⟫ | oni boli | ⟪अभूवन्⟫ |
| ⟪१६⟫. | ⟪ददिम⟫ | my sme dali | ⟪अदाम⟫ |
| ⟪१७⟫. | ⟪भिद्यते⟫ | sa delí / láme | ⟪अभेदि⟫ |
| ⟪१८⟫. | ⟪उद्यते⟫ | sa hovorí | ⟪अवादि⟫ |
| ⟪१९⟫. | ⟪स्तूयते⟫ | on je chválený | ⟪अस्तावि⟫ |
| ⟪२०⟫. | ⟪कृष्यते⟫ | sa orie | ⟪अकर्षि⟫ |
| ⟪२१⟫. | ⟪जायते⟫ | sa rodí | ⟪अजनि⟫ |
| ⟪२२⟫. | ⟪गीयते⟫ | sa spieva | ⟪अगायि⟫ |
| ⟪२३⟫. | ⟪गम्यते⟫ | sa ide | ⟪अगामि⟫ |
