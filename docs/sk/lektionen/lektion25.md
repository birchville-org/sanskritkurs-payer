# Lekcia 25

## 25.1. Vznik ablatívu (⟪पञ्चमी⟫ = "piaty pádový koncovka")

::: grammar-box
Okrem maskulin / neutrá na -a a zámen sú v singulári vo všetkých deklinčných triedach tvary ablatívu (⟪पञ्चमी⟫) totožné s tvarmi genitívu (⟪षष्ठी⟫).

Okrem osobných zámen sú vo všetkých deklinciách v pluráli tvary ablatívu totožné s tvarmi datívu (⟪चतुर्थी⟫).
:::
Teraz rozpoznáte dôvod pre poradie pádov (⟪विभक्ति⟫) v sanskrite: sú usporiadané tak, aby zhodné tvary boli čo najbližšie pri sebe – prípadne pod sebou.

::: grammar-box
**Ablatív singuláru maskulin / neutrá na -a**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Otázne, vztažné a ukazovacie zámena:

::: grammar-box

| | Ablatív singuláru:brMaskulinum / Neutrum | Ablatív singuláru:brFemininum |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |

| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Použitie ablatívu (⟪पञ्चमी⟫)

"Ablatív označuje to, čo zostáva na mieste, keď sa niečo z neho vzdialí."

Pāṇini 2,3,28 + 1,4,24

Ablatív sa predovšetkým používa na otázky "Odkiaľ?", "Prečo?".

::: grammar-box
1\. Ablatív teda označuje východiskový bod, pôvod a materiál.

Ablatív môže preto tiež označovať osobu, od ktorej niečo kupujeme, počúvame, želáme si atď.
:::
Príklady:

::: indent
⟪ग्रमादागच्छति⟫ = "Prichádza z dediny"

⟪अश्वात्पतितः⟫ = "spadol z koňa"

⟪तेभ्यो लब्धम्⟫ = "prijal od nich (sem)"
:::
Príklady:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "počuje od učiteľa o dhamme"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "bráhman si želá od kṣatriju kravú mliečnicu"
:::
::: grammar-box
2\. Ablatív stojí pri slovesách s významom "zdržať od", "chrániť pred", "obhajovať proti", "boja sa pred":
:::
Príklad:

::: indent
⟪अरिभ्यो रक्षति⟫ = "chráni pred nepriateľmi"
:::
::: grammar-box
3\. Ablatív označuje dôvod alebo príčinu:
:::
Príklady:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "Zabíja svojho syna zo hnevu"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "Pretože urobil zlo, ide do pekla" (« Pretože je tým, ktorým sa urobilo zlo)

⟪पापकरणान्नरकं गच्छति⟫ = "Pretože robí / urobil zlo, ide do pekla"
:::
Podstatné mená, ktoré nie sú ženského rodu, môžu na označenie dôvodu činnosti stáť v inštrumentáli (⟪तृतीया⟫) alebo ablatíve (⟪पञ्चमी⟫). Ženského rodu stávajú v tomto zmysle zvyčajne v inštrumentáli, ale môžu občas stáť aj v ablatíve.

## 25.3. Prípona -⟪तस्⟫

::: grammar-box
Ak chceme v jednotnom čísle (jednoznačne) vyjadriť, že slovo sa používa v ablatívnom význame, môžeme na kmeň slova pripojiť príponu -⟪तस्⟫, ktorá tvorí príslovky s väčšinou ablatívneho významu (na otázku "Odkiaľ?"):
:::
Príklady:

::: indent
⟪आदितस्⟫ = "od počiatku"

⟪धर्मतस्⟫ = "pretože dharmy, v dôsledku dharma"
:::
::: grammar-box
Koncovka -⟪तस्⟫ sa vyskytuje aj na kmeňoch zámen:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "odtam, tam, tamto, na to, potom, preto"

⟪यद्⟫ : ⟪यतस्⟫ "od ktorého, o čom, odkiaľ, kde, kam, prečo, pretože" (relatívne)

⟪किम्⟫ :  ⟪कुतस्⟫ "odkiaľ?" "prečo?"
:::
## 25.4. Iné spôsoby vyjadrovania dôvodov

::: grammar-box
**1\. Relatívne vety**

Relatívne vety často vyjadrujú kauzálny (dôvodový), konsekutívny (sledujúci) alebo finálny (účelový) vzťah k hlavnej vete.

Tvary relátívneho zámena, ktoré slúžia ako kauzálna spojka:

*   ablatívne:
*   ⟪यतस्⟫ ... podradená veta ... ⟪ततस्⟫ ... hlavná veta ... = "pretože ..., preto ..."
*   ⟪यस्मात्⟫ ... podradená veta ... ⟪तस्मात्⟫ ... hlavná veta ... = "pretože ..., preto ..."
*   instrumentál:
*   ⟪येन⟫ ... podradená veta ... ⟪तेन⟫ ... hlavná veta ... = "čím/pretože ..., tým / preto ..."
:::
Príklad:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "Pretože Rāma túži po blahobytu, vykonáva sľub"
:::
::: grammar-box
**2\. ⟪हि⟫**

Hlavné vety možno pomocou častice ⟪हि⟫ "lebo, pretože" prepojiť. Veta s ⟪हि⟫ (ktorá nesmie stáť na prvom mieste, ale v próze musí stáť na druhom mieste) uvádza dôvod buď pre predchádzajúcu vetu, alebo pre nasledujúcu vetu:
:::
Príklad:

::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "Ľudia konajú záslužne. Chcú sa totiž dostať do neba."
:::
::: grammar-box
**3\. Instrumentál (⟪तृतीया⟫)**

Okrem ablatívu (⟪पञ्चमी⟫) sa instrumentál (⟪तृतीया⟫) používa na vyjadrenie dôvodu alebo príčiny. Pri ženských podstatných menách je instrumentál všeobecne povinný.
:::
Príklad:

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = "Zabíja svojho syna zo hnevu" = "Zabíja svojho syna v hneve"
:::
::: grammar-box
**4\. Podstatné mená**

Okrem toho možno samozrejme dôvody vyjadriť aj pomocou konštrukcií s

*   ⟪कारण⟫ n. "príčina": ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ m.
*   iné podstatné mená vo význame "príčina"

\+ genitív (⟪षष्ठी⟫) alebo ako zadný člen kompozít:
:::
Príklad:

::: indent
⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ atď.) = "kvôli zásluhe"
:::
::: grammar-box
**5\. ⟪इति⟫**

Motiv činnosti možno vyjadriť ako myšlienku pomocou ⟪इति⟫:
:::
Príklad:

::: indent
⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫  = "Pretože Sugata úplne prebudil k pravde, pýta sa Ānanda Gautamu na jeho učenie" (« "Mysliac si 'Sugata je úplne prebudil k pravde' ..."
:::

## 25.7. ⟪सुभाषितानि यतो यतो निवर्तते ततस्ततो विमुच्यते । निवर्तनाद्धि सर्वतो न वेत्ति दुःखमण्वपि ॥१॥⟫

::: indent
