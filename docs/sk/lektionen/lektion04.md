# Lekcia 4

## 4.1. Jednoduché doplňovacie otázky (slovné otázky) a odpovede

### 4.1.1. Otázkové zámená a ukazovacie zámená

#### 4.1.1.1. Otázkové zámená (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Nominatív singulár | Nominatív plurál |
| :--- | :--- | :--- |
| **Neutrum** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Maskulinum** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Femininum** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Ukazovacie zámená (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Korene** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"on, ona, to; ten, tá, to":br(Oni/To spomínané)** | **etad = ⟪एतद्⟫:br"tento, táto, toto":br(Veľmi blízko hovoriacemu)** | **idam = ⟪इदम्⟫:br"tento, táto, toto":br(Blízko)** |
| **Nominatív singulár** ||||
| **Neutrum** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Maskulinum** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Femininum** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Nominatív plurál** ||||
| **Neutrum** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Maskulinum** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Femininum** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**K nom. sg. mask.:**
**sa, eṣa** (⟪स एष⟫) stojí pred všetkými zvukmi okrem krátkého **-a**
**so, eṣo** (⟪सो एषो⟫) stojí pred **-a**, ktoré je elidované (vypadne) s Avagrahou
**saḥ, eṣaḥ** (⟪सः एषः⟫) stojí len v pauze (konci vety, konci verša)

Aby bolo možné vety tvoriť pomocou týchto zámen (sarvanāman n.), je potrebné poznať nasledujúce sandhické pravidlá:

### 4.1.2. Sandhi koncového -m

::: grammar-box
**Koncové -m sa pred spoluhláskami nahrádza anusvārou (-ṃ). Na konci vety alebo verša a pred samohláskami sa -m zachováva.**
:::
### 4.1.3. Sandhi koncového -e

::: grammar-box
1. **pred a- zostáva -e nezmenené: úvodné a- sa eliduje s avagrahou:**
napr. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Tieto ohne"

2. **Pred ostatnými samohláskami než krátkym a- sa -e zvyčajne nahrádza -a s hiátom. Niekedy sa tiež vyskytuje náhrada za -ay:**
napr. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (zriedkavo: imay īśvarāh = ⟪इमयीश्वराः⟫) "Tí PÁNI"
:::
### 4.1.4. Sandhi koncového -d

::: grammar-box
**Koncové -d sa v pauze a pred bezhlásnymi guturálmi (k, kh) a labiálnymi spoluhláskami (p, ph) nahrádza za -t.**

Náhrada pred ostatnými spoluhláskami bude prebratá neskôr. Dočasne sa takýmto zhlukom spoluhlások vyhnite!
:::
### 4.1.5. Otázkové vzorce

Pomocou týchto zámen sa tvoria napr. nasledujúce otázkové vzorce:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Singular** | **Neutrum** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं किम्⟫, ⟪किमिदम्⟫ | "Čo je to?" |
| ^^| **Maskulinum** | sa kaḥ? / kaḥ saḥ?:br⟪स कः⟫, ⟪कः सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष कः⟫, ⟪क एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं कः⟫, ⟪को ऽयम्⟫ | "Kto je to?":br"Čo je ten?" |
| ^^| **Femininum** | sā kā? / kā sā?:br⟪सा का⟫, ⟪का सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं का⟫, ⟪केयम्⟫ | "Kto je to?":br"Kto je tá?" |
| **Plural** | **Neutrum** | tāni kāni? / kāni tāni?:br⟪तानि कानि⟫, ⟪कानि तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि कानि⟫, ⟪कानीमानि⟫ | |
|^^ | **Maskulinum** | te ke? / ke te?:br⟪ते के⟫, ⟪के ते⟫:brete ke? / ka ete?:br⟪एते के⟫, ⟪क एते⟫:brime ke? / ka ime?:br⟪इमे के⟫, ⟪क इमे⟫ | |
| ^^| **Femininum** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः काः⟫, ⟪का एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः काः⟫, ⟪का इमाः⟫ | |
:::
Príklad iných otázok:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ Odpoveď: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (V nominatívnom vete možno napríklad postaviť podmet na začiatok, aby sa zdôraznilo nadväzovanie na otázku.)

POZNÁMKA: Odpovede, ktoré môžete na takéto otázky dať so svojimi doterajšími vedomosťami sanskrtu, samozrejme ešte nezodpovedajú vo všetkých ohľadoch idiomaticky dobrému sanskrtu.


## 4.2. Cvičenie

**A) Vytvorte ústne s nasledujúcimi slovami otázky podľa schémy viṣṇuḥ kaḥ (⟪विष्णुः कः⟫) a odpovedzte na otázky v sanskrite:**

śruti, śiva, brāhmaṇa, dvija (plurál), indrāṇī, dhenu, tulādhara, kālidāsa
