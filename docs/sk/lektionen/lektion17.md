# Lekcia 17

## 17.1. Druhá trieda prézenta (⟪अदादि⟫ = ⟪अद्⟫ atď.)

Koncovky sloves sa pripájajú priamo na koreň. Pri tom je potrebné brať do úvahy fonetické zmeny vyplývajúce zo sandhi.

::: grammar-box

V druhej triede prézenta existujú nasledovné tvary:

1.   Korene s ablautom kmeňa
*   zvyčajne: silná stupňová forma – slabá stupňová forma
*   niektoré korene: dĺžková stupňová forma – slabá stupňová forma
2.   Korene bez ablautu kmeňa
3.   Dvoslabičné korene na -i/-ī s ablautom kmeňa

:::
## 17.2. Korene druhej triedy prézenta s ablautom kmeňa silná stupňová forma – slabá stupňová forma

Príklady:

⟪द्विष्⟫ 2 U „nenávidieť“

*   silný kmeň prézenta: dveṣ-
*   slabý kmeň prézenta: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. préz. P | ⟪द्वेष्टि⟫ (« dveṣ + -ti) |
| 3\. pl. préz. P | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 3\. sg. préz. Ā | ⟪द्विष्टे⟫ (« dviṣ + -te) |
| 3\. pl. préz. Ā | ⟪द्विषते⟫ (dviṣ-ate) |

:::
Pri tom platí nasledovné sandhi pravidlo:

::: grammar-box
Sandhi -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-
:::

## 17.4. Korene druhej triedy prítomného času bez kmeňovej gradácie

::: grammar-box
Bez kmeňovej gradácie sú korene druhej triedy prítomného času na -ā
:::
Príklad:

⟪पा⟩ 2 P "chrániť, strážiť"

:::
Niektoré iné korene druhej triedy tiež nemajú kmeňovú gradáciu:

⟪अद्⟩ 2 P "jesť"

## 17.5. Dvoslabičné korene na -i/-ī s kmeňovou gradáciou

Niekoľko koreňov je v rade foriem dvoslabičných, t.j. majú pred spoluhláskovou koncovkou -i (prípadne pred niektorými koncovo-kami -ī). Tieto korene sa však napriek tomu domácimi gramatikmi a v slovníkoch atď. uvádzajú ako jednoslabičné.

Príklady:

⟪रुद्⟫ 2 P "plakať, vydať hlas"

*   silný kmeň prítomného času: rodi-
*   slabý kmeň prítomného času:
*   pred spoluhláskou: rudi-
*   pred samohláskou: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "hovoriť"

*   silný kmeň prítomného času: bravī- (« bro- + -ī)
*   slabý kmeň prítomného času:
*   pred spoluhláskou: brū-
*   pred samohláskou: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Aj ⟪स्तु⟫ 2 U "chváliť" má okrem foriem uvedených pod bodom 3. aj formy podľa tohto vzoru:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::
