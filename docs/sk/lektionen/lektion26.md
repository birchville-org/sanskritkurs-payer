# Lekcia 26

## 26.1. Zákon cerebralizácie pre -s- vo vnútri slova

::: grammar-box
**-s-** sa nahrádza za **-ṣ-**, ak **k, r, l** alebo samohláska — okrem **a, ā** — bezprostredne predchádza alebo je oddelená len ⟪अनुस्वार⟫ alebo ⟪विसर्ग⟫ a nasleduje iný zvuk než **ṛ, r**.

Tomuto sandhiho pravidlu podlieha aj **⟪दुस्⟫-** pred bezhlásovými guturálmi a labiálami v kompozitách.
:::
*Príklady:*
::: indent
⟪तेषाम्⟫ (z: *te-sām*)

ale: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. Zákon cerebralizácie pre dentály vo vnútri slova

::: grammar-box
Dentálne uzatváracie spoluhlásky sa po retroflexoch (vrátane **-ṣ-**) nahrádzajú zodpovedajúcimi retroflexmi:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** kvôli predchádzajúcemu **i**, **ṭh** kvôli následnému **ṣ**)*
:::
## 26.3. Sandhiho pravidlá pre palatály, guturály, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

Príklady pozri nižšie
:::
## 26.4. Grassmannovo pravidlo disimilácie aspirát

::: grammar-box
**Bezprostredná postupnosť dvoch aspirát (aspiráta - samohláska - aspiráta) má za následok stratu aspirácie prvého zvuku:**

Príklad:

:::
::: indent
\*dhu(gh) » du(g)h
:::
**Ak druhý zvuk v dôsledku fonetických zákonov stratí svoju aspiráciu, objaví sa aspirácia znova na prvom zvuku.**

Príklady: pozri nižšie budúci čas od  ⟪दुह्⟫ a  ⟪बुध्⟫

## 26.5. Wortsandhi pre -m, -n pred zápornými spoluhláskami

::: grammar-box
**Pred zápornými spoluhláskami sa -n a -m nahradí za -ṃ-:**

Príklad: s. nižšie budúci čas od ⟪मन्⟫
:::
## 26.6. Použitie jednoduchého budúceho času (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**Jednoduchý budúci čas (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) vyjadruje:**

**budúcnosť**
**zamýšľaný alebo želaný čin ("budem ísť", "chcem ísť")**
**očakávanie ("stane sa takto")**
**nádej**
**obavu**
**pravdepodobnosť**
**názor hovoriaceho**
**príkaz**

**Búdúci čas stojí čiastočne v konkurencii s optatívom (pozri neskôr).**
:::
napr. ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = "Niektorý, kto chce dať sľub, ide do chrámu."

## 26.7. Vytvorenie jednoduchého budúceho času (⟪ऌत्⟫, ⟪भविष्यन्ती⟫  f.)

::: grammar-box
**Jednoduchý budúci čas:**

:::
::: indent
**Kmeň budúceho času + primárna koncovka**
:::
::: grammar-box
**Kmeň budúceho času:**

:::
::: indent
**(zvyčajne) silná koreňová forma + -sya**  
**alebo**  
**(zvyčajne) silná koreňová forma + -i- + -sya (= - iṣya)**
:::
**Ktorý koreň má akú tvorbu kmeňa budúceho času, treba sa naučiť so základnými tvarovými formami!**  
**Vo všeobecnosti sa zhoduje koreňová forma a spojovacie samohlásky budúceho času s infinitívom.**  
**Niektoré korene môžu budúci čas voliteľne tvoriť s a bez spojovacej samohlásky -i-.**  
**Príčastie Parasmaipada budúceho času sa tvorí pripojením prípony -nt- ku kmeňu budúceho času, ženský rod fakultatívne na -ntī alebo -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
Príklady:

::: grammar-box

| Kmeň | Budúcnosť 3. os. P (Ā) |

| ⟪पच्⟫ | ⟪पक्ष्यति⟫ |
| ⟪प्रच्छ्⟫ | ⟪प्रक्ष्यति⟫ |
| ⟪यज्⟫ | ⟪यक्ष्यति⟫ |
| ⟪सृज्⟫ | ⟪स्रक्ष्यति⟫ |
