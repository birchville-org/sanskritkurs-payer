# Lekcia 43

## 43.1. Osobné koncovky druhej osoby (⟪मध्यमः⟫ = "stredná \<osoba\>")

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Primárne koncovky** | -si | -tha | -se | -dhve |
| **Sekundárne koncovky** | -s | -ta | -thās | -dhvam |
| **Perfektné koncovky** | -tha | -a | -se | -dhve |
:::
Všímajte si, že sekundárna koncovka 2.os.čís. je totožná so sekundárnou koncovkou 3.os.jed.aktívu.

## 43.2. Tvorba slovesných foriem druhej osoby (⟪मध्यमः⟫)

2.osoba:

*   Singulár: "ty"
*   Plurál: "vy" (viac ako dvaja!)

## 43.3. Osobné zámeno druhej osoby

*   Jednotné číslo: ⟪त्वद्⟫ "ty"
*   Množné číslo: ⟪युष्मद्⟫ "vy"

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम् त्वा⟫ | ⟪युष्मान् वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम् ते⟫ | ⟪युष्मभ्यम् वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪तव ते⟫ | ⟪युष्माकम् वस्⟫ |

:::
Tvary ⟪त्वा⟫, ⟪ते⟫, ⟪वस्⟫ nesmú byť použité na začiatku vety alebo polovice verša. Tiež pred ⟪च⟫, ⟪वा⟫, ⟪एव⟫ a niektorými inými časticami nesmú byť použité:

::: indent
⟪त्वां मां च⟫ "teba a mňa"
:::
