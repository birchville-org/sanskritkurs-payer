# Lekcia 21

## 21.1. Ďalšie prítomné korene na -nt

### 21.1.1. Prítomný príčestie (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
Toto príčestie je nominálna tvorba z prítomného koreňa, teda skutočné príčestie. Je to adjektívum, ktoré uvádza, že niekto alebo niečo práve vykonáva to, čo je vyjadrené slovesným koreňom (+ prefix), zatiaľ čo sa deje niečo iné. Týmto možno vyjadriť aj trvalý stav.

**Príklady:**

:::
::: indent
"Zatiaľ čo otec číta, fajčí = fajčiaričiaci otec"
"skutočný (= pravý, skutočný) priateľ"
:::
::: grammar-box

| **Tvorba prítomného príčestia Parasmaipada k tematickým prítomným koreňom:** |||
| :--- | :--- | :--- |
| **Maskulínum, Neutrum** | | |
| | **silný kmeň** | Prítomný koreň + **-nt-** |
| | **slabý kmeň** | Prítomný koreň + **-t-** |
| **Femininum** | | |
| | | Prítomný koreň + **-nt-** + **-ī** (skloňovanie ako **devī** :br⟪देवी⟫) |
| | **6. trieda prítomného času** | Prítomný koreň + **-nt-** + **-ī** :broder::brPrítomný koreň + **-t-** + **-ī** |

:::

## 21.3. Zdvorilé formy oslovenia

::: grammar-box
**V sanskrite je možné osloviť niekoho v 2. osobe jednotného čísla, aniž by to bolo nezdvorilé. Ak chceme byť zdvorilí, môžeme použiť podstatné meno s významom "ctihodný" a podobne, a sloveso uviesť do 3. osoby jednotného alebo množného čísla, prípadne použiť pasívnu konštrukciu. Stupňovanie zdvorilosti pri používaní osoby v oslovení je približne nasledovné:**

:::
::: indent
**2. sg. » 2. pl. » 3. sg. s príslušným podstatným menom » 3. pl. s príslušným podstatným menom**
:::
**Najdôležitejšie takéto zdvorilé podstatné meno je ⟪भवन्त्⟫ , ž. r.: ⟪भवती⟫ . Vo svojom používaní zodpovedá našmu zdvorilému "Vy".**
Toto ⟪भवन्त्⟫ je skrátenina z ⟪भगवन्त्⟫, jeho deklinácia je rovnaká ako u podstatných mien na **-vant** (pozri [Lekcia 13](lektion13.md)). Toto ⟪भवन्त्⟫ sa musí rozlišovať od prítomného príčastia P slovesa ⟪भू⟫ "stať sa" ⟪भवन्त्⟫ : nominatív jednotného čísla mužského rodu slovesa ⟪भवन्त्⟫ "Vy" je ⟪भवान्⟫, nominatív príčastia ⟪भवन्⟫.

**Príklady:**

::: indent
**⟪किं भवान्करोति⟫** = **⟪किं भवता क्रियते⟫** = "Čo robíte?"
:::
zdvorilý:

::: indent
**⟪किं भवन्तः कुर्वन्ति⟫** = **⟪किं भवद्भिः क्रियते⟫**
:::
Femininum:

::: indent
**⟪किं भवती करोति⟫** = **⟪किं भवत्या क्रियते⟫**  
**⟪किं भवत्यः कुर्वन्ति⟫** = **⟪किं भवतीभिः क्रियते⟫**
:::
Ďalšie slová, ktoré sa môžu používať podobne ako ⟪भवन्त्⟫:

*   ⟪आर्य⟫ (f.: ⟪आर्या⟫) "Vznešený". Napr. **⟪यदार्य इच्छति⟫** "Čo si želáte"
*   ⟪महाभाग⟫ "ten, ktorého diel / šťastie je veľké = Vznešený". Často používané ženami pri oslovovaní alebo hovorení o mužoch dobrého postavenia. V modernom hovorčenom sanskrite veľmi časté.

Ak sa chce vyjadriť nielen zdvorilosť, ale aj úctu k niekomu, používa sa pri prítomnej osobe namiesto ⟪भवन्त् अत्रभवन्त्⟫ , pri neprítomnej alebo vzdialenej osobe ⟪तत्रभवन्त्⟫. ⟪अत्रभवन्त्⟫ a ⟪तत्रभवन्त्⟫ možno preložiť ako "Vy", "Vaša ctihodnosť", "Vaše excelencia" atď.:

::: indent
**⟪किमत्रभवत्यत्रभवतां भार्या⟫** = "Je milostivá (tu prítomná) žena Vašou manželkou?"  
**⟪किं तत्रभवतां कुशलवृत्तम्⟫** (v liste alebo telefonickom rozhovore) = "Máte sa dobre?"
:::
