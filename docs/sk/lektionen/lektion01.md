## 1.2. Zvuky sanskrtu

Zvuky sanskrtu podľa tradičnej indickej klasifikácie a ich vedecký prepis.

::: media
![](/images/lekt0106.webp)
(Zdroj obrázku: [Podrobnosti](/sk/licenses#lekt0106))
:::
Moderné slovníky sanskrtu sú usporiadané podľa tohto klasifikačného poradia. Táto klasifikácia je nevyhnutná pre pochopenie sanskrtickej gramatiky a preto ju treba vedieť naspamäť:

::: note-box
Klasifikácia
**jednoduché samohlásky** (samānākṣara -- ⟪समानाक्षर⟫):
⟪अ⟫ a, ⟪आ⟫ ā, ⟪इ⟫ i, ⟪ई⟫ ī, ⟪उ⟫ u, ⟪ऊ⟫ ū, ⟪ऋ⟫ ṛ, ⟪ॠ⟫ ṝ, ⟪ऌ⟫ ḷ
**diftongy** (sandhyakṣara -- ⟪सन्ध्यक्षर⟫):
⟪ए⟫ e, ⟪ऐ⟫ ai, ⟪ओ⟫ o, ⟪औ⟫ au
**spoluhlásky** (vyañjana / hal -- ⟪व्यञ्जन⟫ / ⟪हल्⟫):
⟪क⟫ ka, ⟪ख⟫ kha, ⟪ग⟫ ga, ⟪घ⟫ gha, ⟪ङ⟫ ṅa
⟪च⟫ ca, ⟪छ⟫ cha, ⟪ज⟫ ja, ⟪झ⟫ jha, ⟪ञ⟫ ña
⟪ट⟫ ṭa, ⟪ठ⟫ ṭha, ⟪ड⟫ ḍa, ⟪ढ⟫ ḍha, ⟪ण⟫ ṇa
⟪त⟫ ta, ⟪थ⟫ tha, ⟪द⟫ da, ⟪ध⟫ dha, ⟪न⟫ na
⟪प⟫ pa, ⟪फ⟫ pha, ⟪ब⟫ ba, ⟪भ⟫ bha, ⟪म⟫ ma
⟪य⟫ ya, ⟪र⟫ ra, ⟪ल⟫ la, ⟪व⟫ va
⟪श⟫ śa, ⟪ष⟫ ṣa, ⟪स⟫ sa
⟪ह⟫ ha
:::
### 1.2.1. O výslovnosti jednotlivých hlások

::: laut-table
| Hláška | Popis |
| :--- | :--- |
| **a - ⟪अ⟫** | "krátke a" sa u Indov -- už od staroveku -- často vyslovuje ako ə. V Európe sa vyslovuje ako krátke a, v Bengálsku ako krátke tmavé o. |
| **ṛ - ⟪ऋ⟫** | ako české vokalizované r. Ľahký dozvuk i. |
| **ṝ - ⟪ॠ⟫** | ako české vokalizované r. Ľahký dozvuk u. |
| **jñ - ⟪ज्ञ्⟫** | tiež ako dny (Maráthí) alebo gy (Severné Indické). |
| **ś - ⟪श्⟫** | sch-hláška so špičkou jazyka ohnutou nadol. Podobné ako sch v "miesiť". |
| **ṣ - ⟪ष्⟫** | ach-hláška so špičkou jazyka ohnutou dozadu. Často sa artikuluje tak ďaleko vzadu v hrdle, že znie takmer ako kh. |
| **h - ⟪ह्⟫** | dychová hláška, nikdy znak predĺženia. |
| **ḥ - :** | **Visarga (Visarjanīya)** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫. Bezhlásna dychová hláška s dozvukom predchádzajúcej samohlásky alebo druhej časti predchádzajúceho diftongu: agniḥ -- ⟪अग्निः⟫ = agnihi, devaiḥ -- ⟪देवैः⟫ = devaihi, gauḥ -- ⟪गौः⟫ = gauhu |
| **ṃ** | **Anusvára** -- ⟪अनुस्वर⟫. Pred zášmykovými hláškami, h, l: nazalizácia samohlásky. Na konci slova = m. Vo vnútri slova pred spoluhláskou: nazálna spoluhláska zodpovedajúca nasledujúcej spoluhláske: saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
Najlepšiu výslovnosť dosiahnete, ak budete vety, verše alebo slová pomerne pomaly a monotónne čítať s presným dodržiavaním dĺžky samohlások.


## 1.3. Cvičenie

**A) Prečítajte si nasledujúce slová:**

1. varṇa brāhmaṇaḥ kṣatriya vaiśya śūdra — ⟪वर्ण ब्राह्मणः क्षत्रिय वैश्य शूद्र⟫
2. brahmā viṣṇu śiva — ⟪ब्रह्मा विष्णु शिव⟫
3. āśrama brāhmacārin gṛhastha vānaprastha saṃnyāsin — ⟪आश्रम ब्राह्मचारिन् गृहस्थ वानप्रस्थ संन्यासिन्⟫
4. ṛgveda sāmaveda yajurveda atharvaveda — ⟪ऋग्वेद सामवेद यजुर्वेद अथर्ववेद⟫
5. upaniṣad — ⟪उपनिषद्⟫
6. jaina bauddha — ⟪जैन बौद्ध⟫
7. prajñāpāramitā — ⟪प्रज्ञापारमिता⟫
8. cakra vajra — ⟪चक्र वज्र⟫
9. pitṝn — ⟪पितॄन्⟫
10. saṃskṛta — ⟪संस्कृत⟫

**B) Prečítajte si sanskritské výrazy v hore uvedenej fonetickej klasifikácii.**
