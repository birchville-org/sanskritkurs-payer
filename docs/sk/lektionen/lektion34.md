# Lekcia 34

## 34.1. Perfekt (⟪लिट्⟫)

V klasickom sanskrite existujú od koreňa perfekta len oznamovací spôsob a príčestie.

::: grammar-box
**Existujú dva druhy tvorby perfekta:**
*   **reduplikované perfektum = ⟪द्वित्वलिट्⟫**
*   **perifrázované perfektum = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Perifrázované perfektum (⟪अनुप्रयोगलिट्⟫) sa používa:**
1. **pri odvodených konjugáciách (kauzatív, desideratív, frekvatívum, denominatíva)**
2. **pri koreňoch, ktoré začínajú dlhým samohláskou (okrem ā-), alebo samohláskou (okrem a-) pred dvoma spoluhláskami**
3. **pri niektorých iných koreňoch**
:::
## 34.2. Reduplikované perfektum (⟪द्वित्वलिट्⟫)

### 34.2.1. Stupňovanie koreňa

::: grammar-box
**Tvorba:**

**Silný kmeň: jednotné číslo Parasmaipada**
*   **reduplikovaný koreň v silnom stupni alebo dĺžkovom stupni + koncovka perfekta**

**Slabý kmeň: všetky ostatné tvary**
*   **reduplikovaný koreň v slabom stupni + koncovka perfekta**
:::
::: grammar-box
**Všeobecne (aj mimo perfekta) nemajú stupňovanie korene tvaru:**
*   **(spoluhláska)-spoluhláska-dlhá samohláska-spoluhláska**
*   **(spoluhláska)-spoluhláska-samohláska-spoluhláska-spoluhláska**

**V perfekte navyše nemajú stupňovanie korene tvaru:**
*   **a-spoluhláska**
*   **ā-spoluhláska**
:::
### 34.2.2. Koncovky perfekta

::: grammar-box

| | 3. jednotné číslo | 3. množné číslo |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |

:::
### 34.2.3. Spojovacie samohlásky -i-

::: grammar-box
**Pred koncovkou 3. os. množného čísla Ā (-re) sa vždy vyskytuje spojovacia samohláska -i-, pred ostatnými spoluhláskami začínajúcimi koncovkami pri väčšine koreňov.**
:::
### 34.2.4. Reduplicácia spoluhláskovo začínajúcich koreňov

::: grammar-box
**Pre reduplicáciu spoluhláskovo začínajúcich koreňov platia pravidlá uvedené v [Lekcia 33](lektion33.md).**

**Reduplikačný samohláskový znak pri spoluhláskovo začínajúcich koreňoch je krátky samohláskový znak koreňa.**

**Diftongy pred spoluhláskou sa redukujú na príslušný krátky samohláskový znak základnej úrovne.**

**ṛ, ṝ, ḷ a koncové diftongy sa reduplikujú pomocou -a-.**
:::
Príklady:

::: grammar-box

| Koreň | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::
::: grammar-box
**Niektoré korene začínajúce na y- alebo v- sa reduplikujú s i- resp. u-, ktoré sa v slabých tvaroch "spája" so samohláskovým znakom koreňa.**
:::
Príklady:

::: grammar-box

| Koreň | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Reduplicácia samohláskovo začínajúcich koreňov

::: grammar-box
**1. Začínajúce a-, ā- sa reduplikuje s a-, takže sa objaví ā-.**
:::
Príklady:

::: grammar-box

| Koreň | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "byť" a ⟪अस्⟫ 4 "hodiť" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. Korene s začínajúcim i- majú v silnom kmeni reduplikačnú slabiku iy-, v slabom kmeni i-, ktorá sa so samohláskovým znakom koreňa spája na ī-. Analogicky to platí pre začínajúce u-.**
:::
Príklady:

::: grammar-box

| Koreň | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. Korene, ktoré začínajú na a- pred dvoma spoluhláskami alebo s ṛ-, majú ako reduplikačnú slabiku ān-**
:::
Príklady:

::: grammar-box

| Koreň | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. Typy reduplikovaného perfekta

Princíp členenia: Špecifiká koreňovej gradácie:
*   Perfektum bez koreňovej gradácie: Typ I
*   Perfektum s koreňovou gradáciou: Typ II - V
*   nepravidelné tvary perfekta

## 34.4. Perfektum Typ I: Perfektum bez koreňovej gradácie

::: grammar-box
**Perfektum Typ I (bez koreňovej gradácie) majú korene typov:**
*   **(Spoluhláska)-Spoluhláska-Dlhý samohláska-Spoluhláska**
*   **(Spoluhláska)-Spoluhláska-Samohláska-Spoluhláska-Spoluhláska**
*   **a-Spoluhláska**
*   **ā-Spoluhláska**
:::
Príklady:

::: grammar-box

| Koreň | 3. sg. Perf. | 3. pl. Perf. |
| :--- | :--- | :--- |
| ⟪बन्ध्⟫ 9P | ⟪बबन्ध⟫:brba-bandh-a | ⟪बबन्धुर्⟫ |
| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |
| ⟪आप्⟫ 5P | ⟪आप⟫:bra + āp-a | ⟪आपुर्⟫ |
| ⟪अस्⟫ 2P "byť":br⟪अस्⟫ 4 "hodiť" | ⟪आस⟫:bra + as-a | ⟪आसुर्⟫ |
| ⟪अश्⟫ | ⟪आनशे⟫:brnepravidelná reduplikácia! | ⟪आनशिरे⟫ |

:::
## 34.5. Perfektum Typ II: Silný koreň v silnej stupni, slabý koreň v slabej stupni

::: grammar-box
**Tvorí sa z koreňov tvaru:**
*   **(Spoluhláska)-(Spoluhláska)-i/u/ṛ/ḷ-Spoluhláska**

**Tvorba:**
*   **silný koreň: silná stupeň**
*   **slabý koreň: slabá stupeň**
:::
Príklady:

::: grammar-box

| Koreň | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪भिद्⟫ | ⟪बिभेद⟫ | ⟪बिभिदुर्⟫ | ⟪बिभिदे⟫ | ⟪बिभिदिरे⟫ |
| ⟪इष्⟫ | ⟪इयेष⟫ | ⟪ईषुर्⟫ | | |
| ⟪मुच्⟫ | ⟪मुमोच⟫ | ⟪मुमुचुर्⟫ | ⟪मुमुचे⟫ | ⟪मुमुचिरे⟫ |
| ⟪वृत्⟫ | | | ⟪ववृते⟫ | ⟪ववृतिरे⟫ |

:::
