# Lekcia 31

## 31.1. 7. trieda präsensa (⟪रुधादि⟫ = "⟪रुध्⟫ atď.")

::: grammar-box
**Vznik:**

**Pred koncovými spoluhláskami koreňa v slabom stupni sa vloží takzvaný nasálny infix (-na- resp. -n-):**

*   **v silnom kmeni: -na-**
*   **v slabom kmeni: -n-**

**Pre spojenie koncových spoluhlások koreňa s koncami začínajúcimi sa na spoluhlásku platia tie isté pravidlá ako pre 2. triedu präsensa.**
:::
Príklady:

⟪युज्⟫ 7U "spájať, zapriahať"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikatív** | **3. sg.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(v pred guturálnami vo vnútri slova sa nazály nahrádzajú za -ṅ-) |
| | **3. pl.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Optatív** | **3. sg.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. pl.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Particip präsens** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brfem.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "zastaviť, priniesť do stavu pokoja"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikatív** | **3. sg.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. pl.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Optatív** | **3. sg.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. pl.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Particip präsens** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brfem.: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**U niektorých koreňov preniklo -n- slabého prítomného kmeňa aj do neprítomných časov, takže tieto korene sa uvádzajú s infixovým nosňou.**
:::
Príklad:

⟪भञ्ज्⟫ 7P "rozbiť"

::: indent
*   Indikatív prítomný čas
*   3.os.jed. ⟪भनक्ति⟫ (bha-na + j + ti)
*   3.os.mnoh. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Budúci čas: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Trpný rod: ⟪भज्यते⟫ (buď z pôvodného koreňa ⟪भज्⟫ alebo z *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (prípadne z *bhñj + na)
:::
## 31.2. Slovník

⟪युज्⟫ 7U ⟪युनक्ति⟫ : zapriahať, upriahnuť, napnúť, upevniť ; Ā tiež: namáhať sa (= usilovať sa), spájať sa s, sústrediť sa na (lokál, ⟪सप्तमी⟫)
::: indent
**Fut. ⟪योक्ष्यति⟫**
**Pass. ⟪युज्यते⟫**
**Kaus. ⟪योजयति⟫**
**PPP ⟪युक्त⟫**
**Inf. ⟪योक्तुम्⟫**

odtiaľ:
**⟪युग⟫ n. → ⟪युग⟫ n.:** jarmo, pár, éra sveta (existujú štyri éry sveta:
1. ⟪कृत⟫
2. ⟪त्रेता⟫
3. ⟪द्वापर⟫
4. ⟪कलि⟫

Toto ⟪कलियुग⟫ sa začalo okolo roku 3102 pred Kr., v roku ⟪महाभारत⟫-vej vojny. Viac informácií u Basham, Wonder s. 323)

**⟪योग⟫ m.:** "zapriahnutie, napnutie", úsilie, spojenie, jóga (pozri Basham, Wonder s. 327n.)
