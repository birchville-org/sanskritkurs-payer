## 7.1. ܦܬܓܡܐ ܦܥܠܝܐ ܥܡ ܚܒܝܫܐ ܦܫܝܛܐ

::: grammar-box
**Schema:**
**(Agent = kartṛ m. = ⟪कर्तृ⟫) – direct object (karman n. = ⟪कर्मन्⟫) – verb**

على سبيل المثال:
- **rāmaḥ phalaṃ khādati** = ⟪रामः⟫ ⟪फलं⟫ ⟪खादति⟫ : "يأكل راما (يستهلك) ثمرة."
- **brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो⟫ ⟪देवं⟫ ⟪यजति⟫ : "يعبد البراهمة إلهاً بذبيحة (لشخص آخر)."
:::
إذا كان الفعل في الباراسمايبادا أو ātmanepada، فإن المفعول به المباشر (**karman** n. = ⟪कर्मन्⟫) يكون عادةً في **المفعول به** (حالة المفعول، dvitīyā f. = ⟪द्वितीया⟫).

### 7.2.1. ܩܛܝܥܐ ܚܕܝܕܝܐ ܘܣܓܝܐܝܐ ܕܟܢܘܫܝ̈ܐ ܫܐܠܢܝ̈ܐ ܘܡܚܘܝܢܝ̈ܐ

::: grammar-box
| || זכר | נקבה | סתם |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :brמי/מה | יח' | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |
| | רב' | **kān** :br⟪कान्⟫ | **kās** :br⟪कास्⟫ | **kāni** :br⟪कानि⟫ |
| **tad** :brהוא/אותו/שזה | יח' | **tam** :br⟪तम्⟫ | **tām** :br⟪ताम्⟫ | **tad** :br⟪तद्⟫ |
| | רב' | **tān** :br⟪तान्⟫ | **tās** :br⟪तास्⟫ | **tāni** :br⟪तानि⟫ |
| **etad** :brזה כאן | יח' | **etam / enam** :br⟪एतम्⟫ / ⟪एनम्⟫ | **etām / enām** :br⟪एताम्⟫ / ⟪एनाम्⟫ | **etad / enad** :br⟪एतद्⟫ / ⟪एनद्⟫ |
| | רב' | **etān / enān** :br⟪एतान्⟫ / ⟪एनान्⟫ | **etās / enās** :br⟪एतास्⟫ / ⟪एनास्⟫ | **etāni / enāni** :br⟪एतानि⟫ / ⟪एनानि⟫ |
| **idam** :brזה | יח' | **imam / enam** :br⟪इमम्⟫ / ⟪एनम्⟫ | **imām / enām** :br⟪इमाम्⟫ / ⟪एनाम्⟫ | **idam / enad** :br⟪इदम्⟫ / ⟪एनद्⟫ |
| | רב' | **imān / enān** :br⟪इमान्⟫ / ⟪एनान्⟫ | **imās / enās** :br⟪इमास्⟫ / ⟪एनास्⟫ | **imāni / enāni** :br⟪इमानि⟫ / ⟪एनानि⟫ |
:::
הצורות **enam** (⟪एनम्⟫) וכו' שייכות לשורש **enad** (⟪एनद्⟫), היוצר מקרים רק בהקשרים מסוימים. אלו משמשים במקום צורות של **etad** ו-**idam** כאשר הנזכר כבר הוזכר בהקדם.
למשל: **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं⟫ ⟪देवः⟫ | ⟪एनं⟫ ⟪यजन्ते⟫ || : "הוא אל. הם מקריבים לו."

### 7.2.2. ܡܬܚܫܚܢܘܬܐ ܕܩܛܝܥܐ (ܩܛܝܥܐ ܡܩܒܠܢܐ، ܕܒܝܬܝܐ ܐܢܬܬܝܐ = ⟪द्वितीया⟫ = "ܫܘܠܡܐ ܕܩܛܝܥܐ ܬܪܝܢܐ")

::: grammar-box
ܐܘܪ̈ܚܬܐ (ܕܝܬܝܵܐ ܢ̈ܟܼܘܿܬܐ = ⟪द्वितीया⟫) ܡ̈ܕܠܩܬ:
1. ܒܡ̈ܠܬܐ ܕܠܵܐ ܒܣܘܼܟܪܵܢܹܐ: ܗܝ ܡ̈ܕܠܩܬ **ܐܘܪ̈ܚܬ ܡܕܒܪܐ** (ܟܲܪ̈ܡܢ ܢ̈ܟܼܘܿܬ = ⟪कर्मन्⟫) ܕܡ̈ܠܬܐ ܕܢ̈ܩܒܪ:
ܡܼܠܐ:
- **devaṃ yajati** = ⟪देवं⟫ ⟪यजति⟫ : "ܗܘ ܢ̈ܩܒ ܐܠܹܗܵܐ ܒܡ̈ܠܬܐ."
- **phalam āpnoti** = ⟪फलमाप्नोति⟫ : "ܗܘ ܢ̈ܩܒ ܦܠܵܚ (ܡܼܠܐ: ܕܢ̈ܩܒ)."
2. ܥܡ ܡ̈ܠܬܐ ܕܢ̈ܩܒܘ ܚܲܬܹܐ, ܡ̈ܠܬܐ ܕܢ̈ܩܒܘ, ܡ̈ܠܬܐ ܕܢ̈ܩܒܘ, ܐܘ ܡ̈ܠܬܐ ܕܢ̈ܩܒܘ, ܗܝ ܡ̈ܕܠܩܬ ܐܘܪ̈ܚܬ ܡ̈ܠܬܐ:
ܡܼܠܐ:
- **narakaṃ gacchati** = ⟪नरकं⟫ ⟪गच्छति⟫ : "ܗܘ ܚܲܬ ܠܹܐ."
:::
ܡ̈ܠܬܐ ܕܢ̈ܩܒܘ ܕܡ̈ܠܬܐ ܕܢ̈ܩܒܘ ܕܡ̈ܠܬܐ ܕܢ̈ܩܒܘ.

## 7.3. ܣܢܕܗܝ ܕ-ܢ ܡܫܠܡܢܝܬܐ

::: grammar-box
**Final -n:**

1. קודם לכן, חניכא ורטרופלקס ספרסי ומלפני **ś-**, מוחלף על ידי הנזל המתאים לצלילים אלו:
- **-n** לפני **j-, jh-, ñ-, ś-** » **-ñ**
- **-n** לפני **ḍ-, ḍh-, ṇ-, ṣ-** » **-ṇ**
למשל, **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "הוא כובש את הKṣatriyas."
**ś-** ראשוני מוחלף ברובו על ידי **ch-**:
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (בצד gurūñ śṛṇoti) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "הוא שומע את המורים." "הוא מקשיב למוסרים."

2. אם **l-** ראשוני מוקדם על ידי **-l**, הוא מוחלף על ידי -l עם אנונסיקה (נזלי l, בכתיבה **⟪ल्⟫** עם אנונסיקה **⟪ँ⟫**):
למשל, **paśūn + labhate** » ⟪पशूंल्लभते⟫ : "הוא מקבל בקר."

3. אם חניכא, רטרופלקס או דנטלי ראשוני מוקדם על ידי **Anusvāra**, הוא מוחלף על ידי הסובילנט המתאים:
- **-n** לפני **c-, ch-** » **-ṃś**
- **-n** לפני **ṭ-, ṭh-** » **-ṃṣ**
- **-n** לפני **t-, th-** » **-ṃs**
למשל, **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : "והאלים (אק.)"
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : "אבל האלים (אק.)"

4. Except after a short vowel (see later), final **-n** remains unchanged in all other cases.
:::

## 7.4. ܡܨܰܥܝܵܐ (ܢܲܦܘܼܡܣܲܟܵܐ ܕܲܟ݂ܪܵܢܵܐ = ⟪ܢܲܦܘܼܡܣܲܟ⟫)

::: grammar-box
**ܒܢܘܬܐ ܕܡܠܦܬܐ ܟܝܢ̈ܐ ܕܠܫܘܿܟܒܬܐ (ܪܝܫܬܐ) ܘܠܡܥܒܕܐ (ܬܪܝܬܐ) ܗܘ̈ܢܐ.**
:::
### 7.4.1. ܡܨܥܝܐ ܕܥܩܪ̈ܐ ܕܫܠܡܝܢ ܒ-ܐ

::: grammar-box
- **Ending Nominative / Accusative Singular: -m**
  e.g. **phala** n. = ⟪फल⟫ = "fruit": Nom. / Acc. sg. **phalam** = ⟪फलम्⟫
- **Ending Nominative / Accusative Plural: -āni**
  e.g. **phala** n. = ⟪फल⟫: Nom. / Acc. pl. **phalāni** = ⟪फलानि⟫
:::

## 7.5. ܕܽܘܟܝܵܬ̈ܳܐ ܕܙܲܒ݂ܢܵܐ ܕܗܳܫܵܐ ܠܵܐ ܬܹܡܵܬܝܼܩܵܝ̈ܳܐ

ܐܘܪ̈ܚܐ 5 ܕܡܢܐ ܩܪܝܒ ܫܠܣܬ ܐܘܪ̈ܚܐ ܕܠܫܢܐ ܐܬܝܡܬܐ، ܗܘ ܕܫܠܣܬ ܠܫܢܐ ܠܐ ܡܬܚܝܒ ܒܦܘܟܪܢܐ ܕܠܫܢܐ **-a** ܟܡܘܪ̈ܚܐ ܕܠܫܢܐ ܬܝܡܬܐ (1, 4, 6, 10).

::: grammar-box
**ܐܘܪ̈ܚܐ ܕܠܫܢܐ ܐܬܝܡܬܐ ܠܗܘܢ ܫܘܬܦܬܐ، ܗܝ ܕܠܫܢܐ ܡܬܚܘܒ:**
1. **שׁלֵּם**: גְּבוֹהָ (בְּנִינָא נָדֵר)
2. **שְׁלִימָא**: נְמוּכָה

**ܫܠܣܬ ܐܘܪ̈ܚܐ:**
- בְּלִשׁוֹן הַדָּרוֹשׁ בְּיָחִיד (לַט) וּבְעֵת הָאֱמֶת (לַנ)
- כָּל הָרִאשׁוֹנִים בְּצַוָּה (לוֹט) פָּרָשָׁא וְאַתְמַנִּי
- בְּשָׁלִישִׁי יָחִיד בְּצַוָּה (לוֹט) פָּרָשָׁא

**All other forms have the weak present stem.**
:::
### 7.5.1. ܫܘܠܡܐ ܩܕܡܝܐ ܕܓܢܣܐ ܬܠܝܬܝܐ ܣܓܝܐܐ ܒܫܪ̈ܫܐ ܐܬܝܡܛܝܩܝܐ

### 7.5.2. ܟܘܪܣܐ ܚܡܝܫܝܐ ܕܗܘܝܐ (ܣܒܐܕܝ = ⟪स्वादि⟫ = "ܣܘ ܐܠܝܦ.")

::: grammar-box
- **Strong stem**: (mostly) low-grade root (as stated) + **-no-**
- **Weak stem**: (mostly) low-grade root (as stated) + **-nu-**

**Before vocalic endings, -nu- is replaced by -nv- in roots ending in a vowel; in consonant-ending roots, -nu- is replaced by -nuv- before vocalic endings.**
:::

## 7.6. ܡܠܘܐܐ

**Learn the following words:**

- **aś** 5 Ā (aśnute) ⟪अश्⟫ ⟪अश्नुते⟫ : ܠܒܝܐ, ܠܬܝܐ

- **krudh** 4 P (krudhyati) ⟪क्रुध्⟫ ⟪क्रुध्यति⟫ : ܐܝܡܢ
