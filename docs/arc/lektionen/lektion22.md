# ܕܲܪܫܵܐ 22

## 22.1. ܐܒܣܘܠܘܛܝܒܐ (ܩܛܒܐ | ܠܝܦ)

::: grammar-box

ܐܝܟܢܐ ܕܡܠܠ ܒܣܘܿܢ̈ܩܪܝܬ ܕܦܥܠܐ ܕܡܫܬܡܠ (⟪कर्तृ⟫) ܩܕܡ ܦܥܠܐ ܐܚܪܢ ܕܡܫܬܡܠ ܐܘ ܗܘ ܒܨܪܟܬܐ ܕܫܠܡܘܬܐ، ܐܝܟ ܕܢܫܬܡܠ ܒܐܘܓܪܝܛܘܿܢ (⟪क्त्वा ⟫ । ⟫ ल्यप्). ܠܗٰذَا

"after he has done that, he does that" ; "he does that, then he does that" ; "as a consequence of this he does that" ; "I came, saw and conquered" etc.

The absolutive is a verbal adverb, i.e., it is neither conjugable nor declinable, but it always — with few exceptions — has the same agent (⟪कर्तृ⟫) as the action that precedes or accompanies the action designated by the absolutive. The agent of the absolutive is therefore in the nominative (⟪प्रथमा⟫) or instrumental (⟪तृतीया⟫).

Neben den Komposita ist das Absolutiv eines der häufigsten Ausdrucksmittel im Sanskrit.

Bei der Übersetzung ins Deutsche vermeide man, ständig "nachdem" zu sagen. man verwende statt dessen die im Deutschen gebräuchlichen Ausdrucksweisen für zeitliche Anreihung.

**Schema:**

(nähere Bestimmung zum Absolutiv: Umstandsbestimmung, Objekt u.sw.) - Absolutiv - Absolutiv - ... - Absolutiv - ... Agens + Verbalsatz (im Aktiv oder Passiv)

:::
**Examples:**

::: indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = ܣܘܩܠܐ ܦܥܝܠ: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**  
"ܐܢܫ ܐܬܐ ܠܒܝܬܐ، ܚܙܐ ܢܫܝܐ ܩܠܬܐ، וְאָמַר לָהּ."

Plural: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**
:::
## 22.2. ܨܘܪܬܐ ܕܫܡܐ ܦܥܠܐ

::: grammar-box
**Formation of the Nominative**

*   Verbs without prefix: Absolutive ending in **-tvā**
*   Verbs with prefix: Absolutive ending in **-ya** or **-tya**
:::
### 22.2.1. ܦܥܠ̈ܐ ܕܠܐ ܡܠܝܠܘܬܐ: ܫܘܠܡܐ ܡܫܠܡܢܐ ܒ-⟪त्वा⟫

::: grammar-box

**Bildung:**

(mostly) root-level in the form it has before the PPP + **-tvā** (**-⟪त्वा⟫**)

רק השלילה **a-** / **an-** תואמת לסיומת **-⟪त्वा⟫** : **⟪अकृत्वा⟫** "שלא עשה"

:::
**Examples:**

::: indent
**⟪आप्त्वा⟫** "after he / she / it / I / you / we / they / we both / you both / they both has / had / have / had"

**⟪आसित्वा⟫** "after he (...) had sat / was"

**⟪इत्वा⟫** "after he (...) had gone / is"

**⟪स्थित्वा⟫** "after he (...) had confessed / is"

**⟪जित्वा⟫** "after he (...) has won / had won"

**⟪उक्त्वा⟫** "after he (...) has spoken / had spoken"
:::
### 22.2.2. ܡܠܬܐ ܥܡ ܩܕܡܝܬܐ

#### 22.2.2.1. ܥܩܳܪܶܐ ܕܐܝܬ ܒܗܽܘܢ ܩܳܠܳܐ ܝܰܪܺܝܟܳܐ (ܠܒܰܪ ܡܶܢ -ܳܐ) ܐܰܘ ܕܐܝܬ ܒܗܽܘܢ ܐܳܬܳܐ ܫܰܠܝܳܐ

::: grammar-box

**(mostly) root of the lowest grade + -ya**

:::
**Examples:**

::: indent
**⟪उपनीय⟫** "having brought / having led (...) forward"

**⟪प्रभूय⟫** "after he (...) has protruded / was" "after he (...) had power"

**⟪प्राप्य⟫** "after he (...) has obtained / had obtained"
:::
#### 22.2.2.2. ܫܶܪ̈ܫܶܐ ܕܡܶܫܬܰܠܡܺܝܢ ܒ-ܐܳ

::: grammar-box

**unchanged high-grade root + -ya**

:::
**Example:**

::: indent
**⟪उपस्थाय⟫** "after he (...) had stepped / is" ; (but without prefix: **⟪स्थित्वा⟫**)
:::
#### 22.2.2.3. ܫܪ̈ܫܐ ܕܡܫܬܠܡܝܢ ܒܕܪܓܐ ܟܪܝܗܐ ܥܡ -ܝ ܟܪܝܐ, -ܘ, -ܪ

::: grammar-box

**root of the lowest grade + -tya**

:::
**Examples:**

::: indent
**⟪प्रस्तुत्य⟫** "after he (...) has praised / had praised aloud"

**⟪विस्मृत्य⟫** "after he (...) has forgotten / had forgotten"

**⟪संस्कृत्य⟫** "after he (...) has prepared / had prepared for the sacrifice"
:::
#### 22.2.2.4. ܥܩܪ̈ܐ ܕܡܫܠܡܝܢ ܒ-ܐܡ / -ܐܢ, ܕܡܫܠܡܝܢ ܒ-ܐ ܒܕܪܓܐ ܟܪܝܗܐ

::: grammar-box

**Optional:**

Root on **-am** / **-an** + **-ya**

or:

Root on **-a** + **-tya**

:::
**Example:**

::: indent
**⟪विगम्य⟫** or **⟪विगत्य⟫** "after he (...) has passed / was"
:::
