# Lekcija 17

## 17.1. Druga klasa prezensa (⟪अदादि⟫ = ⟪अद्⟫ itd.)

Glagolske nastavke se direktno dodaju na koren. Prilikom toga treba uzeti u obzir fonetske promene koje proizilaze iz rečnog sandhija.

::: grammar-box

Postoje sledeće forme nastanka u drugoj klasi prezensa:

1. Koreni sa stepenovanjem osnove
*   najčešće: visoki stepen - niski stepen
*   neki koreni: produženi stepen - niski stepen
2. Koreni bez stepenovanja osnove
3. Dvosložni koreni na -i/-ī sa stepenovanjem osnove

:::

*   weak present stem:
*   before consonant: stu-

## 17.5. Disyllabic roots ending in -i/-ī with stem gradation

Several roots are disyllabic in a number of forms, i.e., they have an -i (or before some endings -ī) before a consonantal ending. Nevertheless, these roots are posited as monosyllabic by native grammarians and in dictionaries etc.

Examples:

⟪रुद्⟫ 2 P "to weep, to howl"

*   strong present stem: rodi-
*   weak present stem:
*   before consonant: rudi-
*   before vowel: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Pres. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "to speak"

*   strong present stem: bravī- (« bro- + -ī)
*   weak present stem:
*   before consonant: brū-
*   before vowel: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Pres. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Pres. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Pres. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Pres. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
