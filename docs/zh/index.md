Alois Payer 的《梵語課程》是一套全面且具學術基礎的教學課程，旨在教授梵語語言與天城文書寫系統。此數位版本將整個課程提供於一個現代化、多語且可搜尋的閱讀環境中。

這些語言是透過人工智慧（Qwen3.6-32B）完全自動地從德文翻譯而來。歡迎回報任何翻譯錯誤。
