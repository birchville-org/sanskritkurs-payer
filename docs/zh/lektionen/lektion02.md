# 第2課


## 2.1. 名詞句

::: grammar-box
**範例：表語名詞 - 主語**

例如 devo viṣṇuḥ = ⟪देवो विष्णुः⟫ = 「毗濕奴是一位神。」
:::
語法上的繫詞（「是」、「都是」、「我是」、「你是」、「你們是」）並非必要，但有時會出現。

梵文**沒有冠詞**：**devaḥ** -- ⟪देवः⟫ 可以表示「那位神」或「一位神」。

儘管梵文的語序相當自由（尤其在詩歌中），但在翻譯名詞句時，必須首要考慮根據上述標準範例進行的翻譯。

在名詞句中，主語使用主格（第一格 = **prathamā** f. = ⟪प्रथमा⟫）。表語名詞需與主數在數和格上保持一致；如果表語名詞是形容詞，還需與主語在性上一致。


## 2.2. 關於變格（名詞的屈折變化）

梵文中有：

**三種數**（數量形式）= **vacana** n. -- ⟪वचन⟫
單數 = **ekavacana** n. -- ⟪एकवचन⟫
雙數 = **dvivacana** n. -- ⟪द्विवचन⟫
複數 = **bahuvacana** n. -- ⟪बहुवचन⟫
**三種性**（語法性別）= **liṅga** n. / **vyakti** f. -- ⟪लिङ्ग⟫ / ⟪व्यक्ति⟫
陽性 = **puṃs** m. -- ⟪पुंस्⟫
陰性 = **strī** f. -- ⟪स्त्री⟫
中性 = **napuṃsaka** n. -- ⟪नपुंसक⟫
**八種格**（語法格位）= **sup** -- ⟪सुप्⟫（= 格尾）

變格時，格尾（**sup** = ⟪सुप्⟫）會加在所謂的**名詞詞幹**（名詞去掉格尾後的形態）上。

範例：**devas** = ⟪देवस्⟫（主格單數陽性）「神／一位神」= **deva-** -- ⟪देव⟫-（名詞詞幹）+ **-s** -- -⟪स्⟫（格詞尾）。

在梵語詞典中，名詞以**名詞詞幹**的形式列出：
**deva** m. -- ⟪देव⟫ m.（陽性）
**vacana** n. -- ⟪वचन⟫ n.（中性）
**vyakti** f. -- ⟪व्यक्ति⟫ f.（陰性）


## 2.3. 主格單數

**主格單數 = prathamā ekavacanam = ⟪प्रथमा एकवचनम्⟫**

::: grammar-box
**主格單數以 -s 結尾 = -⟪स्⟫，或者無詞尾。**
:::
### 2.3.1. 以 -s 結尾的主格單數

以下以元音結尾的名詞詞幹，其主格單數形式以 **-s** 結尾：

::: grammar-box
**以 -a 結尾的陽性名詞：**例如 deva m. = ⟪देव⟫「神」-- 主格單數：devas = ⟪देवस्⟫
**以 -i 結尾的陽性名詞：**例如 kavi m. = ⟪कवि⟫「詩人」-- 主格單數：kavis = ⟪कविस्⟫
**以 -u 結尾的陽性名詞：**例如 guru m. = ⟪गुरु⟫「老師」-- 主格單數：gurus = ⟪गुरुस्⟫
:::

## 2.4. 連聲（Sandhi）-- ⟪सन्धि⟫

在梵語中，一個詞的尾音也會受到後續詞首音的影響。這種現象稱為**Sandhi**（連聲，陽性名詞）= ⟪सन्धि⟫（「結合」）。

### 2.4.1. 尾音 -s 的連聲規則

請參閱以下概覽：

> **Payer, Alois (1944–)：**尾音 -s 的連聲規則。--（梵語教材）。-- URL: http://www.payer.de/sanskritmaterialien/ssandhi.htm

尾音為 **-s**：

**在絕對詞尾處**（句末）會變為 **Visarga (-ḥ)**：
**devas** = ⟪देवस्⟫ » **devaḥ** = ⟪देवः⟫
**kavis** = ⟪कविस्⟫ » **kaviḥ** = ⟪कविः⟫
**gurus** = ⟪गुरुस्⟫ » **guruḥ** = ⟪गुरुः⟫

**在無聲輔音前**：
在 **k, kh, p, ph** 和 **ś, ṣ, s** 前：變為 **Visarga (-ḥ)**
**devas + śivaḥ** » **devaḥ śivaḥ** = ⟪देवः शिवः⟫（「Śiva 是一位神」）
在 **c, ch** 前：變為 **-ś**
在 **ṭ, ṭh** 前：變為 **-ṣ**
在 **t, th** 前：保持為 **-s**
**sādhus + caitanyas** » **sādhuś caitanyaḥ** = ⟪साधुश्चैतन्यः⟫（「Caitanya 是一位聖者」）

**在濁輔音前**：
在非 a 元音後：變為 **-r**
**kavis + Māghas** » **kavir māghaḥ** = ⟪कविर्माघः⟫（「Māgha 是一位詩人」）
在非 a 元音後且位於 **r-** 前：**-s** 消失，該元音延長。
**gurus + rāmas** » **gurū rāmaḥ** = ⟪गुरू रामः⟫（「Rāma 是一位老師」）
在 **a-** 後：**-as**
在濁輔音/a 前：變為 **-o**（詞首的 a 消失 » ⟪ऽ⟫）
**devas viṣṇus** » **devo viṣṇuḥ** = ⟪देवो विष्णुः⟫
**devas agnis** » **devo 'gniḥ** = ⟪देवो ऽग्निः⟫
在其他元音前：變為 **-a**（Hiatus，即元音連讀）
**devas + indras** » **deva indraḥ** = ⟪देव इन्द्रः⟫

**dvija** m. -- ⟪द्विज⟫ : 「再生者」（前三個種姓：婆羅門、剎帝利、吠舍的入學者）。

**varṇa** m. -- ⟪वर्ण⟫ : 顏色，出生階級（傾向）。

四個種姓（**varṇa** m.）常被誤認為是「賤民」或「種姓」。然而，四個種姓與「種姓」不同——它並非印度特有；在歐洲，我們也曾有（部分直至第一次世界大戰）種姓制度，如下圖所示，出自十五世紀：

**標註：**
**神職人員階級**（~婆羅門）：Tu supplex ora = 你應懇切祈禱！
**貴族階級**（~剎帝利）：Tu protege = 你應保護！
**農民階級**（~吠舍/首陀羅）：Tuque labora = 你應工作！

這三個階級各自穿著所屬階級的服裝。在這些被標記為「神意」的階級之上，基督端坐寶座。

馬克斯·韋伯（1864–1920）如此定義「階級」：

::: note-box
»**階級**「應指一群人在某個組織內，有效
a) 享有階級特有的特殊評價——可能也包括
b) 主張階級特有的特權。」

種姓可以產生
a) 原生地，透過自身種族的生活方式，尤其是透過**職業**（生活方式或職業種姓）的方式產生，
b) 次生地，世襲魅力型，透過成功的聲望主張並憑藉種族**血統**（出生種姓）產生，
c) 透過將政治或神權統治權力作為壟斷進行種族**佔有**（政治或神權種姓）。

出生種族的發展通常是一種將特權（世襲地）佔有給一個團體或合格個人的形式。任何對機會的固定佔有，特別是[由]主人[統治權或謀生]機會的固定佔有，傾向導致種族的形成。任何種族的形成都傾向於導致對統治權力和謀生機會的壟斷性佔有。

當職業階級在市場導向經濟的基礎上成長時，種族則更傾向於在壟斷性公共服務、封建或種族家產制需求的基礎上產生並存在。

如果社會的分層主要是按照種族進行的，則稱其為「**種族性**」；如果主要是按照階級進行的，則稱其為「**階級性**」。在「階級」中，與「種族」最接近的是「社會」階級，而「職業階級」則是最遙遠的。種族通常由其重點由財產階級構成。

任何種族社會都是常規性的，由生活方式的規則所規範，因此在經濟上創造了非理性的消費條件，並透過壟斷性佔有和排除對自身謀生能力的自由支配來阻礙自由市場的形成。

[**韋伯，馬克斯（1864–1920）：**《經濟與社會：理解 sociologie 的綱要》。– 第5版，修訂版。– 蒂賓根：莫爾出版社，1976年。– 第625頁及以下。]
:::
因此，varṇas（種姓）是基於出身的階級。

## 2.6. 練習

**A) 請在注意 Sandhi（連聲）規則的情況下填入並構成名詞句：**

1. **devas ... (Śiva, Agni, Viṣṇu, Gaṇeśa, Kṛṣṇa, Indra)**
= ⟪देवस्⟫ ... (⟪शिव⟫, ⟪अग्नि⟫, ⟪विष्णु⟫, ⟪गणेश⟫, ⟪कृष्ण⟫, ⟪इन्द्र⟫)
2. **dvijas ... (brāhmaṇa, kṣatriya, vaiśya)**
= ⟪द्विजस्⟫ ... (⟪ब्राह्मण⟫, ⟪क्षत्रिय⟫, ⟪वैश्य⟫)
3. **gurus ... (brāhmaṇa, Candrakīrti)**
= ⟪गुरुस्⟫ ... (⟪ब्राह्मण⟫, ⟪चन्द्रकीर्ति⟫)
4. **vaiśyas ... (Tulādhara)**
= ⟪वैश्यस्⟫ ... (⟪तुलाधर⟫)
5. **sādhus ... (guru, Rāma)**
= ⟪साधुस्⟫ ... (⟪गुरु⟫, ⟪राम⟫)
6. **kavis ... (Kālidāsa, Māgha, Bhāravi, Harṣadeva)**
= ⟪कविस्⟫ ... (⟪कालिदास⟫, ⟪माघ⟫, ⟪भारवि⟫, ⟪हर्षदेव⟫)

**B) 請翻譯成梵文：**

1. Rāma 是一位婆羅門。
2. 這位老師是一位吠舍（Vaiśya）。
3. 首陀羅是一位聖人。
4. 這位詩人是老師。
5. Viṣṇu 是主（HERR）。
6. 主是 Śiva。
7. 再生族（Zweimalgeborene）是一位婆羅門。
8. 聖人是一位老師。
9. 老師是一位聖人。
