# 練習十四

請翻譯以下諺語並背誦：

⟪निचो वदति न कुरुते वदति न साधुः करोत्येव ॥१॥⟫  
卑劣之人言而不行，善良之人不言而行。

⟪शीलं नरस्य भूषणम् ॥२॥⟫  
美德是人的裝飾。

⟪सत्येन जनानां सुखं भवति ॥३॥⟫  
真理使人幸福。

⟪पापा नराः स्वर्गं न लभन्ते ॥४॥⟫  
惡人不得升天。

⟪सत्यं लोकस्य दीपः ॥५॥⟫  
真理是世間之光。

A) 請為以下詞語構成單數屬格和複數屬格。並給出這些詞的意義與性別：

⟪१⟫. ⟪अनृत⟫ : n. 不實 — ⟪अनृतस्य अनृतानाम् २⟫. ⟪ऋषि⟫ : m. 吠陀聖賢 — ⟪ऋषेः ऋषीणाम् ३⟫. ⟪पाद⟫ : m. 腳 — ⟪पादस्य पादानाम् ४⟫. ⟪बुद्धि⟫ : f. 認知 — ⟪बुद्धेः⟫ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम् ५⟫. ⟪गुरु⟫ : m. 大師 — ⟪गुरोः गुरूणाम् ६⟫. ⟪स्वर्ग⟫ : m. 天界 — ⟪स्वर्गस्य स्वर्गाणाम् ७⟫. ⟪नगर⟫ : n. 城市 — ⟪नगरस्य नगराणाम् ८⟫. ⟪धेनु⟫ : f. 母牛 — ⟪धेनोः⟫ (⟪धेन्वाः⟫) ⟪धेनूनाम् ९⟫. ⟪द्विज⟫ : m. 再生者 — ⟪द्विजस्य द्विजानाम् १०⟫. ⟪मुक्ता⟫ : f. 解脫者 — ⟪मुक्तायाः मुक्तानाम् ११⟫. ⟪विद्या⟫ : f. 知識，學問 — ⟪विद्यायाः विद्यानाम् १२⟫. ⟪वर्ण⟫ : m. 種姓 — ⟪वर्णस्य वर्णानाम् १३⟫. ⟪द्विजाति⟫ : 三再生者 — ⟪द्विजातेः⟫ (⟪द्विजात्याः⟫) ⟪द्विजातीनाम् १४⟫. ⟪रूप⟫ : n. 形式 — ⟪रूपस्य रूपाणाम् १५⟫. ⟪प्रतिग्रह⟫ : m. 接受 — ⟪प्रतिग्रहस्य प्रतिग्रहाणाम्⟫

⟪१६⟫。⟪सोढ⟫：3 忍受 — ⟪सोढस्य सोढायाः सोढानाम् १७⟫。⟪नायिका⟫：f. 摯愛 — ⟪नायिकायाः नयिकानाम् १८⟫。⟪साध्वी⟫：f. 聖者 — ⟪साध्व्याः साध्वीनाम् १९⟫。⟪अग्नि⟫：m. 火 — ⟪अग्नेः अग्नीनाम् २०⟫。⟪वैश्या⟫：f. 吠舍女 — ⟪वैश्यायाः वैश्यानाम् २१⟫。⟪लोक⟫：m. 世界，人們 — ⟪लोकस्य लोकानाम् २२⟫。⟪उक्ति⟫：f. 言說 — ⟪उक्तेः⟫（⟪उक्त्याः⟫）⟪उक्तीनाम् २३⟫。⟪शत्रु⟫：m. 敵人 — ⟪शत्रोः शत्रूणाम् २४⟫。⟪सुखवन्त्⟫：3 幸福 — ⟪सुखवतः⟫（⟪सुखवत्याः⟫）⟪सुखवताम्⟫（⟪सुखवतीनाम्⟫）

⟪२५⟫。⟪पुत्रवती⟫：f. 擁有一子或多子的婦女 — ⟪पुत्रवत्याः पुत्रवतीनाम् २६⟫。⟪जल⟫：n. 水 — ⟪जलस्य जलानाम् २७⟫。⟪मार्ग⟫：m. 道路 — ⟪मर्गस्य मर्गाणाम् २८⟫。⟪मोक्ष⟫：m. 解脫，救贖 — ⟪मोक्षस्य मोक्षाणाम् २९⟫。⟪शूद्रा⟫：f. 首陀羅女 — ⟪शूद्रायाः शूद्राणाम् ३०⟫。⟪अन्न⟫：n. 食物，飲食 — ⟪अन्नस्य अन्नानाम् ३१⟫。⟪साधु⟫：m. 聖人 — ⟪साधोः साधनाम् ३२⟫。⟪नीति⟫：f. 引導 — ⟪नीत्याः नीतीनाम् ३३⟫。⟪योध⟫：m. 戰士，士兵 — ⟪योधस्य योधानाम् ३४⟫。⟪सत्यवन्त्⟫：3 誠實 — ⟪सत्यवतः⟫（⟪सत्यवत्याः⟫）⟪सत्यवताम्⟫（⟪सत्यवतीनाम्⟫）

⟪३५⟫。⟪लाभ⟫：m. 利益 — ⟪लाभस्य लाभानाम् ३६⟫。⟪मोह⟫：m. 困惑，迷惑 — ⟪मोहस्य मोहानाम् ३७⟫。⟪गति⟫：f. 行走，目標 — ⟪गतेः⟫（⟪गत्याः⟫）⟪गतीनाम् ३८⟫。⟪प्रश्न⟫：m. 問題 — ⟪प्रश्नस्य प्रश्नानाम् ३९⟫。⟪सृष्टि⟫：f. 創造 — ⟪सृष्तेः⟫（⟪सृष्ट्याः⟫）⟪सृष्टीनाम् ४०⟫。⟪नेत्र⟫：n. 眼睛 — ⟪नेत्रस्य नेत्राणाम् ४१⟫。⟪गुरुता⟫：f. 統治權 — ⟪गुरुतायाः गुरुतानाम्⟫

⟪४२⟫. ⟪ईश्वर⟫ : m. 主 — ⟪ईश्वरस्य ईश्वराणाम् ४३⟫. ⟪कारण⟫ : n. 原因 — ⟪कारणस्य कारणानाम् ४४⟫. ⟪कृत⟫ : 3 做 — ⟪कृतस्य⟫ (⟪कृतायाः⟫) ⟪कृतानाम् ४५⟫. ⟪धर्मवन्त्⟫ : 3 正義的，宗教性的 — ⟪धर्मवतः⟫ (⟪धर्मवत्याः⟫) ⟪धर्मवताम्⟫ (⟪धर्मवतीनाम्⟫)

⟪४६⟫. ⟪युद्ध⟫ : 3 戰鬥 — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम् ४७⟫. ⟪दर्शन⟫ : n. 看，顯現 — ⟪दर्शनस्य दर्शनानाम् ४८⟫. ⟪धातु⟫ : m. 元素，動詞根 — ⟪धातोः धातूनाम् ४९⟫. ⟪गूढा⟫ : f. 隱藏者 — ⟪गूढायाः गूढानाम् ५०⟫. ⟪ईष्टा⟫ (2 含義): f. 所渴望者，被獻祭者 — ⟪इष्टायाः इष्टानाम् ५१⟫. ⟪उदित⟫ : 3 說 — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम् ५२⟫. ⟪इदम्⟫ : 3 這 — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 什麼 — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) 翻譯：

⟪१⟫. ⟪ब्राह्मणस्य पुत्रो ब्राह्मण्या ग्रामं गतः ।⟫ (2 種可能)
婆羅門之子前往了婆羅門女所在的村莊。婆羅門之子與婆羅門女一同前往村莊。

⟪२⟫. ⟪यज्ञस्याग्निनान्नं दग्धम् ।⟫
祭火燒毀了食物。

⟪३⟫. ⟪बुद्धः स्तयस्य बुद्ध्या मुक्तः ।⟫
佛陀透過對真理的覺悟而獲得解脫。

⟪४⟫. ⟪अधर्मो ऽनृतस्य वदनमित्यृषयो वदन्ति ।⟫
吠賢智者說，說謊是不義的。

⟪५⟫. ⟪नरा देवानां यज्ञैर्न मुच्यन्ते ।⟫
人們透過向神靈獻祭無法獲得解脫。

⟪६⟫. ⟪बलवन्तः क्षत्रियाः शत्रूणां धनवन्ति नगराणि जयन्ति ।⟫
強大的剎帝利征服了敵人富饒的城市。

⟪७⟫。⟪कवेरुक्तिं शृण्वन्ति ।⟫
你們聽見詩人的偈頌。

⟪८⟫。⟪कविर्देव्याः कृतं वद⟫ti ⟪।⟫
詩人敘述女神的功績。

⟪९⟫。⟪द्विजाः पशोर्लाभमिच्छन्ति ।⟫
再生族渴望獲得牲畜。

⟪१०⟫。⟪रामः पुण्यवतो गुरोर्मन्त्रस्य स्मरति ।⟫
羅摩想起那位有德之師的咒語。

⟪११⟫。⟪अयं बालः कस्याः पुत्रः ।⟫
這個男孩是哪位（女）性的兒子？

⟪१२⟫。⟪केषामिमानि गृहाणि ।⟫
這些房屋屬於誰？

⟪१३⟫。⟪कस्यान्नमनेनर्षिणेष्टम् ।⟫
這位精通吠陀的賢者將誰的食物作為供品獻祭？
