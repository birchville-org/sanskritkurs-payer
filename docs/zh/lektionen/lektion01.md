## 1.2. 梵語的音素

根據傳統印度分類法的梵語音素及其科學轉寫。

::: media
![](/images/lekt0106.webp)
（圖片來源：[詳情](/zh/licenses#lekt0106)）
:::
現代的梵語詞典均按照此分類順序排列。此分類法對於理解梵語文法至關重要，因此必須熟記：

::: note-box
分類法
**單元音**（samānākṣara -- ⟪समानाक्षर⟫）：
⟪अ⟫ a, ⟪आ⟫ ā, ⟪इ⟫ i, ⟪ई⟫ ī, ⟪उ⟫ u, ⟪ऊ⟫ ū, ⟪ऋ⟫ ṛ, ⟪ॠ⟫ ṝ, ⟪ऌ⟫ ḷ
**雙元音**（sandhyakṣara -- ⟪सन्ध्यक्षर⟫）：
⟪ए⟫ e, ⟪ऐ⟫ ai, ⟪ओ⟫ o, ⟪औ⟫ au
**輔音**（vyañjana / hal -- ⟪व्यञ्जन⟫ / ⟪हल्⟫）：
⟪क⟫ ka, ⟪ख⟫ kha, ⟪ग⟫ ga, ⟪घ⟫ gha, ⟪ङ⟫ ṅa
⟪च⟫ ca, ⟪छ⟫ cha, ⟪ज⟫ ja, ⟪झ⟫ jha, ⟪ञ⟫ ña
⟪ट⟫ ṭa, ⟪ठ⟫ ṭha, ⟪ड⟫ ḍa, ⟪ढ⟫ ḍha, ⟪ण⟫ ṇa
⟪त⟫ ta, ⟪थ⟫ tha, ⟪द⟫ da, ⟪ध⟫ dha, ⟪न⟫ na
⟪प⟫ pa, ⟪फ⟫ pha, ⟪ब⟫ ba, ⟪भ⟫ bha, ⟪म⟫ ma
⟪य⟫ ya, ⟪र⟫ ra, ⟪ल⟫ la, ⟪व⟫ va
⟪श⟫ śa, ⟪ष⟫ ṣa, ⟪स⟫ sa
⟪ह⟫ ha
:::
### 1.2.1. 關於個別音素的發音

::: laut-table
| 音素 | 描述 |
| :--- | :--- |
| **a - ⟪अ⟫** | 短音 a 在印度人那裡——自古以來——經常被發成 ə。在欧洲，人們將其發為短音 a；在孟加拉地區，則發為短促的暗 o。 |
| **ṛ - ⟪ऋ⟫** | 類似捷克語中元音化的 r。帶有輕微的 i 共鳴。 |
| **ṝ - ⟪ॠ⟫** | 類似捷克語中元音化的 r。帶有輕微的 u 共鳴。 |
| **jñ - ⟪ज्ञ्⟫** | 也可發為 dny（馬拉地語）或 gy（北印度方言）。 |
| **ś - ⟪श्⟫** | 舌葉音 sch，舌尖向下彎曲。類似德語 "mischen"（混合）中的 sch 音。 |
| **ṣ - ⟪ष्⟫** | 舌根音 ach，舌尖向後捲曲。有時在喉嚨深處發音，聽起來幾乎像 kh。 |
| **h - ⟪ह्⟫** | 氣音，從不作為長音標記。 |
| **ḥ - :** | **Visarga（出氣音）** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫。無聲氣音，帶有前一個元音或前一個雙元音第二部分的共鳴：agniḥ -- ⟪अग्निः⟫ = agnihi，devaiḥ -- ⟪देवैः⟫ = devaihi，gauḥ -- ⟪गौः⟫ = gauhu |
| **ṃ** | **Anusvara（鼻音化標記）** -- ⟪अनुस्वर⟫。在擦音、h、l 之前：元音鼻化。在詞尾 = m。在詞中輔音前：發為與後接輔音相應的鼻音：saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
若要達到最佳的發音效果，應以相當緩慢且平穩的語調朗讀句子、詩句或詞彙，並精確注意元音的長度。
