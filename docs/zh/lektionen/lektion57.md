# 第57課

## 57.1. 未完成過去時第四類：s-未完成過去時

::: grammar-box
**s-未完成過去時通常附加於大多數⟪अनिट्⟫詞根，除非該詞根僅有其他的未完成過去時形式。可變的⟪अनिट्⟫詞根通常可以選擇構成s-未完成過去時或iṣ-未完成過去時。此外，⟪अनिट्⟫詞根若在該未完成過去時的第一、第二或第六種形式後帶有⟪परस्मैपद⟫，則依s-未完成過去時規則構成⟪आत्मनेपद⟫。**

**構詞法：增音 + 詞根 + s + 無韻尾二階後綴**
:::
帶有詞幹構造成綴的後綴表

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **第一人稱 ⟪तृतीयः⟫** | -sam | -sma | -si | -smahi |
| **第二人稱 ⟪द्वितीयः⟫** | **-sīs** | -sta | -sthās | **-dhvam** |
| **第三人稱 ⟪प्रथमः⟫** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**適用一般音律法則：兩個塞音之間的擦音會脫落（參見⟪उद्⟫ + ⟪स्थित⟫ » ⟪उत्थित⟫），也就是說，詞幹構造成綴-s-在那些以-t-或-th-開頭的後綴前會脫落（但在鼻音或r之後則不脫落）。**

範例：

:::
::: indent
第三人稱單數.動詞 a-kṣip + s + ta » ⟪अ⟫:sig[⟪क्षिप्त⟫]
第二人稱單數.動詞 a-kṣip + s + thās » ⟪अ⟫:sig[⟪क्षिप्था⟫]⟪स्⟫
:::
此類形式也可能屬於根未完成過去時，且可能部分確實歸屬該類別。
印度語法學家也將如⟪अकृत⟫（第三人稱單數.動詞）此類形式歸入s-未完成過去時，儘管這些形式明確屬於根未完成過去時。為此目的，印度語法學家為s-未完成過去時發明瞭以下臨時音律規則：

::: indent
「短元音之後，以 -st- 或 -sth- 開頭的「詞尾」會失去其 -s-。」
:::
否則，需留意詞尾輔音與 s- 連接的發音規則。

對於 -dhvam，適用以下規則：

::: grammar-box
**-dhvam 中的 -dh-，在所有非 a/ā 元音以及 -r 之後，會替換為 -ḍh-。**

:::
::: indent
例如：sig[⟪चि⟫] 5U: 2.pl.Ā :sig[⟪अचेढ्वम्⟫]
:::
::: grammar-box
**詞根形式：**

*   **⟪परस्मैपद⟫ : 長音階**
*   **⟪आत्मनेपद⟫ :**
*   **以 i/ī/u/ū 結尾的詞根：高階**
*   **以 -ṝ 結尾者，替換為 -īr 或 -ūr**
*   **可變音的 ā/e/o 結尾詞根：低階**
*   **其他詞根元音：保持不變（即通常為低階）**
:::
範例：

|   | **3.sg.P** |
| --- | --- |
| ⟪चि⟫ 5U | ⟪अचैषीत्⟫ |
| ⟪श्रु⟫ 5P | ⟪अश्रौषीत्⟫ |
| ⟪कृ⟫ 8U | ⟪अकार्षीत्⟫ |
| ⟪भज्⟫ 1U | ⟪अभाक्षीत्⟫ |
| ⟪भञ्ज्⟫ 7P | ⟪अभाङ्क्षीत्⟫ |
| ⟪भुज्⟫ 7U | ⟪अभौक्षीत्⟫ |

|   | **3.sg.Ā** |
| --- | --- |
| ⟪चि⟫ 5U | ⟪अचेष्ट⟫ |
| ⟪नी⟫ 1U | ⟪अनेष्ट⟫ |
| ⟪सू⟫ 2/4 | ⟪असोष्ट⟫ |
|   | **sg.Ā** |
| ⟪दा⟫ 3U | ⟪अदिषि⟫:br ⟪अदिथास्⟫ :br ⟪अदित⟫ |
|   | **1.sg.Ā** |
| ⟪कृ⟫ 8U | ⟪अकृषि⟫ |
| ⟪पच्⟫ 1U | ⟪अपक्षि⟫ |

::: grammar-box
**⟪दृश्⟫ 與 ⟪सृज्⟫ 在 ⟪परस्मैपद⟫ 中，其長音階帶有上升雙元音 -rā-：**

:::
::: indent
⟪दृश्⟫ 3.sg.P ⟪अ⟫:sig[⟪द्राक्षी⟫]⟪त्⟫
:::
其他以 -ṛ- 結於倒數第二音節的詞根，其不定過去時亦可如此構成：

::: indent
⟪कृष्⟫ 1P/6U 3.sg.P ⟪अकार्क्षीत्⟫ / ⟪अ⟫:sig[⟪क्राक्षी⟫]⟪त्⟫
:::

**不規則形式：**

**1. 以鼻音結尾的詞根（⟪गम्⟫、⟪मन्⟫、⟪रम्⟫）構成高階的 s-aorist：**
**⟪अगंसि । अमंसि । अरंस्त⟫**
**此外，對於 ⟪गम्⟫ 也存在規則的低階形式：**
**⟪अगसि⟫（「 \*a-gm-si） ⟪। अगथास् । अगत⟫（在 P 中，⟪गम्⟫ 具有主題元音 aorist）**

2. ⟪पद्⟫ 4Ā 通常（例如 ⟪अपत्सि⟫），但在第三人稱單數主動語態中，它採用被動根過去式的形式：
⟪अपादि⟫ 「他去了」

3. ⟪बुध्⟫ Ā 在第三人稱單數主動語態中，可選擇性地採用被動根過去式的形式：
⟪अबोधि⟫ / ⟪अबुद्ध⟫ 「他認出了」
:::
