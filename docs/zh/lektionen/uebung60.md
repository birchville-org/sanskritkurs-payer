# 練習60

A) 根據Kielhorn《文法》§451，學習迄今所學動詞的規則外欲求態（Desiderativ）構形

B) 不使用輔助工具，判斷並翻譯以下形式：

1. ⟪ददुषोः⟫ - ⟪ददिवांस्⟫ 完成被動分詞（Part.Perf.P）對 ⟪दा⟫ 第三類主動態（3U）雙數屬格/位格，陽性/中性。給出的那兩個 / 在那兩個給出者那裡

2. ⟪अहिंसीः⟫ - ⟪हिंस्⟫ 第七類主動態（7P）第二人稱單數未完成過去時（Aor(5)）。主動態。你傷害了

3. ⟪देमथुः⟫ - ⟪दम्⟫ 第四類主動態（4P）第二人稱雙數完成時。主動态。你們兩個制服了

4. ⟪वक्त्वा⟫ - ⟪वञ्च्⟫ 第一類主動態（1P）絕對格。在他搖晃之後

5. ⟪अक्षथाः⟫ - ⟪क्षन्⟫ 第八類主動態（8U）第二人稱單數未完成過去時（Aor(5/1)）。被動态。你出於自身利益而傷害

6. ⟪मुमुषिषिष्यतः⟫ - ⟪मुष्⟫ 第九類主動態（9P）欲求态。第三人稱雙數未來時。主動态。那兩個將想要偷竊

7. ⟪अचिक्षंसेथाम्⟫ - ⟪क्षम्⟫ 第一類被動态（1Ā）欲求态。第二人稱雙數被動态。你們兩個將想要忍受

8. ⟪अस्नाः⟫ - ⟪स्ना⟫ 第二類主動態（2P）第二人稱單數未完成過去時。被動态。你洗過澡

9. ⟪जिहिंसुषि⟫ - ⟪हिंस्⟫ 第七類主動態（7P）完成被動分詞。單數屬格/位格，陽性/中性。在那個傷害者那裡

10. ⟪जिहिंसिषुणा⟫ - ⟪जिहिंसिषु⟫ 第三類（對欲求态而言，源自 ⟪हिंस्⟫ 第七類主動態（7P））單數工具格，陽性/中性。透過那個想要傷害的人

11. ⟪द्युभिः⟫ - ⟪दिव् । द्यौ⟫ 陰性。複數工具格。透過那些天空

12. ⟪जग्लिव⟫ - ⟪ग्लै⟫ 第一類主動態（1P）第一人稱雙數完成時。我們兩個感到不情願

13. ⟪अतिस्तीर्षम्⟫ - ⟪स्तॄ⟫ 第五類/第九類主動態（5/9U）欲求态。第一人稱單數未完成過去時。被動态。我希望播撒

14. ⟪अस्मेष्ठाः⟫ - ⟪स्मि⟫ 第一類被動态（1Ā）第二人稱單數未完成過去時。被動态。你微笑了

15. ⟪ईशिष्व⟫ - ⟪ईश्⟫ 第二類被動态（2Ā）第二人稱單數命令式。被動态。統治吧！

16. ⟪रुरुषतुः⟫ - ⟪रुष्⟫ 第四類/第十類主動態（4/10P）第三人稱雙數完成時。那兩個發怒了

17. ⟪रुरुषुः⟫ - ⟪रुष्⟫ 第四類/第十類主動態（4/10P）第三人稱複數完成時。他們發怒了

18. ⟪रुरुषिषुः⟫ - ⟪रुरुषिषु⟫（源自動詞欲求之願態，參見⟪रुष्⟫ 4/10P）主格單數陽性，意為「欲發怒者」

19. ⟪अपिप्रीणताम्⟫ - ⟪प्री⟫ 9U 使動語態，第三人稱雙數未完成時（第三式）主動語態，意為「二者令其喜愛」

20. ⟪अपिप्रीषतम्⟫ - ⟪प्री⟫ 9U 願態，第三人稱雙數未完成時主動語態，意為「爾二君欲求喜愛」

21. ⟪पिप्रियतुः⟫ - ⟪प्री⟫ 9U 第三人稱雙數完成時主動語態，意為「二者已喜愛」

22. ⟪तिस्रः⟫ - ⟪त्रि⟫ 主格、賓格、呼格陰性，意為「三」

23. ⟪अदांक्ष्टाम्⟫ - ⟪दंश्⟫ 1P 第三人稱雙數未完成時（第四式）主動語態，意為「二者已咬」

24. ⟪असिसीर्ष्यत⟫ - ⟪सृ⟫ 1/3P 願態，第三人稱單數未完成時被動語態，意為「欲行走之事發生」

25. ⟪बभासाते⟫ - ⟪भास्⟫ 1Ā 第三人稱雙數完成時中動語態，意為「二者發光」

26. ⟪बिभासिषेथे⟫ - ⟪भास्⟫ 1Ā 願態，第二人稱雙數現在時直陳式中動語態，意為「爾二君欲發光」

27. ⟪अबीभणत⟫ - ⟪भण्⟫ 1P 使動語態，第二人稱複數未完成時（第三式）主動語態，意為「爾等令其描繪」

28. ⟪चकर्त⟫ - ⟪कृत्⟫ 6P 第一、三人稱單數完成時主動語態，意為「我已 / 他已切斷」

29. ⟪चकर्थ⟫ - ⟪कृ⟫ 8U 第二人稱單數完成時主動語態，意為「你已製作」

30. ⟪दिद्युते⟫ - ⟪द्युत्⟫ 1Ā 第一、三人稱單數完成時中動語態，意為「我已 / 他已發光」

31. ⟪दिद्युतिषे⟫ - ⟪द्युत्⟫ 1Ā 願態，第一人稱單數現在時直陳式中動語態，意為「我欲發光」

32. ⟪चुच्यूषवे⟫ - ⟪चुच्यूषु⟫（源自動詞欲求之願態，參見⟪च्यु⟫ 1Ā）與格單數陽性/中性，意為「欲移動者」

33. ⟪दित्सामि⟫ - ⟪दा⟫ 3U 願態，第一人稱單數現在時直陳式主動語態，意為「我欲給予」

34. ⟪अचीकृतम्⟫ - ⟪कॄत्⟫ 10P 第一人稱單數未完成時（第三式）主動語態，意為「我已讚頌」；⟪कृत्⟫ 6P 使動語態，第一人稱單數未完成時（第三式）主動語態，意為「我令其切斷」

35. ⟪विजिगीषौ⟫ - ⟪विजिगीषु⟫（源自動詞欲求之願態，參見⟪वि⟫-⟪जि⟫）處格單數陽性/中性，意為「在欲征服者身旁」

36. ⟪पित्सेथे⟫ -⟪पद्⟫ 4Ā 願態，第二人稱雙數現在時直陳式中動語態，意為「爾二君欲前行」

37. ⟪उदीचि⟫ - ⟪उदञ्च्⟫ 3 Lok.sg.m.n. 在北方的

38. ⟪संगणय्य⟫ - ⟪सम्⟫-⟪गण्⟫ 10P 絕對分詞，在加總之後

39. ⟪अतिस्तराव⟫ - ⟪स्तॄ⟫ 5/9U 使動式，1.雙數Aor(3).P 我們兩人都讓……散落

40. ⟪त्रिलोक्याः⟫ - ⟪त्रिलोकी⟫ f. 屬格/離格單數 （來自）三界

41. ⟪अहः⟫ - ⟪अहन्⟫ n. 主格/賓格單數 那 / 那天

42. ⟪जग्मुषः⟫ - ⟪जग्मिवांस् । जगन्वांस्⟫ 完成被動分詞，指向 ⟪गम्⟫ 1P 屬格/離格單數.m.n.賓格複數.m. 那位離開的人……

43. ⟪अताप्स्व⟫ - ⟪तप्⟫ 1P 1.雙數Aor(4).P 我們兩人都燃燒

44. ⟪ईशिशिषाञ्चक्रे⟫ - ⟪ईश्⟫ 2Ā 欲求式，1.3單數周邊完成時Ā. 我 / 他渴望統治

45. ⟪ईशाञ्चक्रे⟫ - ⟪ईश्⟫ 2Ā 1.3單數周邊完成時ġ. 我 / 他統治

46. ⟪ईशयाञ्चक्रे⟫ - ⟪ईश्⟫ 2Ā 使動式，1.3單數周邊完成時Ā. 我 / 他讓……為了自身利益而統治

47. ⟪षण्णाम्⟫ - ⟪षष्⟫ 屬格，六個的

48. ⟪अघुक्षम्⟫ - ⟪गुह्⟫ 1U 1.單數Aor.P 我隱藏了

49. ⟪अष्टौ⟫ - ⟪अष्टन्⟫ 主格/賓格/呼格，八

50. ⟪प्साथः⟫ - ⟪प्सा⟫ 2P 2.雙數直陳現在時.P 你們兩人都吞噬

51. ⟪अवाचः⟫ - ⟪अवाञ्च्⟫ 3 Abl/Gen.sg.m.n.Akk.pl.m. 向下的……

52. ⟪ईयुषे⟫ - ⟪ईयिवांस्⟫ 完成被動分詞，指向 ⟪इ⟫ 2P 與格單數.m.n. 那位離開的人
