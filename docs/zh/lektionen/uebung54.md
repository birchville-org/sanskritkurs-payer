# 練習54

請為以下現在時或完成時形式構建相應的未完成過去時（Aorist）形式：

::: grammar-box
| 編號 | 形式 | 語法規定／含義 | 未完成過去時 |
|:---|:---|:---|:---|
| ⟪१⟫. | ⟪यन्ति⟫ | 他們走動 | ⟪अगुः⟫ |
| ⟪२⟫. | ⟪पिबामि⟫ | 我飲用 | ⟪अपाम्⟫ |
| ⟪३⟫. | ⟪ददौ⟫ | 我／他給予了 | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | ⟪बभूव⟫ | 我／他／她們是（過去）/ 你們是（過去） | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | ⟪दधति⟫ | 他們放置 | ⟪अधुः⟫ |
| ⟪६⟫. | ⟪ऐम⟫ | 我們走動了 | ⟪अगाम⟫ |
| ⟪७⟫. | ⟪पपिथ⟫ | 你飲用了／保護了 | ⟪अपाः⟫ (源自：sig[⟪पा⟫] "飲用") |
| ⟪८⟫. | ⟪तिष्ठति⟫ | 他站立 | ⟪अस्थात्⟫ |
| ⟪९⟫. | ⟪इयेथ⟫ | 你走動了 | ⟪अगाः⟫ |
| ⟪१०⟫. | ⟪पप⟫ | 你們飲用了 | ⟪अपात⟫ |
| ⟪११⟫. | ⟪एष्यथ⟫ | 你們將要走動 | ⟪अगात⟫ |
| ⟪१२⟫. | ⟪तस्थुः⟫ | 他們站立了 | ⟪अस्थुः⟫ |
| ⟪१३⟫. | ⟪अधत्त⟫ | 你們放置了 | ⟪अधात⟫ |
| ⟪१४⟫. | ⟪अददाः⟫ | 你給予了 | ⟪अदाः⟫ |
| ⟪१५⟫. | ⟪अभवन्⟫ | 他們是（過去） | ⟪अभूवन्⟫ |
| ⟪१६⟫. | ⟪ददिम⟫ | 我們給予了 | ⟪अदाम⟫ |
| ⟪१७⟫. | ⟪भिद्यते⟫ | 被劈開 | ⟪अभेदि⟫ |
| ⟪१८⟫. | ⟪उद्यते⟫ | 被說 | ⟪अवादि⟫ |
| ⟪१९⟫. | ⟪स्तूयते⟫ | 他被讚美 | ⟪अस्तावि⟫ |
| ⟪२०⟫. | ⟪कृष्यते⟫ | 被耕種 | ⟪अकर्षि⟫ |
| ⟪२१⟫. | ⟪जायते⟫ | 他被出生（被生下） | ⟪अजनि⟫ |
| ⟪२२⟫. | ⟪गीयते⟫ | 被歌唱 | ⟪अगायि⟫ |
| ⟪२३⟫. | ⟪गम्यते⟫ | 被走動（已行） | ⟪अगामि⟫ |
