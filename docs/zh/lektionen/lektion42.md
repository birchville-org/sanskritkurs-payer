# 第42課

## 42.1. 以 -ṛ 結尾的詞幹

### 42.1.1. 強格詞幹中帶有長音階的詞幹

::: grammar-box
所有以 -ṛ 結尾的陽性名詞，除了第1.3節所列的親屬稱謂。此處也包括以下親屬稱謂：

*   ⟪नप्तृ⟫ 陽性「孫子」
*   ⟪भर्तृ⟫ 陽性「丈夫（字面意：維持者）」

此類名詞的大部分由以 ⟪कृत्⟫-後綴 -⟪तृ⟫ 結尾的動詞性名詞（agentis）組成。

**構成：**

*   **強格詞幹：-ār**
*   **弱格詞幹**
*   **元音前：-r**
*   **輔音前：-ṛ**

請注意不規則構成（以 **紅色** 標記）！
:::
陽性：

::: indent
⟪दातृ⟫ 陽性「給予者」
:::
::: grammar-box

| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| :--- | :--- | :--- |
| ⟪प्रथमा⟫ | :sig[⟪दाता⟫] | ⟪दातारस्⟫ |
| ⟪द्वितीया⟫ | ⟪दातारम्⟫ | :sig[⟪दातॄन्⟫] |
| ⟪तृतीया⟫ | ⟪दात्रा⟫ | ⟪दातृभिस्⟫ |

| ⟪षष्ठी⟫ | :sig[⟪दातुस्⟫] | :sig[⟪दातॄणाम्⟫] |

::: indent

:::
### 42.1.2. 名詞構成：⟪कृत्⟫-後綴 -⟪तृ⟫

::: grammar-box
使用非常常見的 ⟪कृत्⟫-後綴 -⟪तृ⟫，可以為幾乎每個詞根或使動詞幹構成動詞性名詞（表示 ⟪कर्तृ⟫ 的名稱）。

**構成：**

*   **高階詞根 + -tṛ**

或者

*   **高階詞根 / 使役詞幹 + i + tṛ**
:::
範例：

::: indent
⟪कर्तृ⟫ m. 「執行者」

⟪जेतृ⟫ m. 「勝利者」

⟪धातृ⟫ m. 「創造者」

⟪रक्षितृ⟫ m. 「保護者」

⟪बोधयितृ⟫ m. 「喚醒者」
:::
::: media
![lekt4201.jpg](/images/lekt4201.jpg)
圖：⟪अयं बोधयिता⟫
（圖片來源：[詳情](/zh/licenses#lekt4201)）
:::

::: grammar-box
罕見的以 -⟪तृ⟫ 結尾的中性名詞具有部分獨立的變格（參見 Kielhorn，《語法》§ 148）。

以 -⟪तृ⟫ 結尾的詞幹對應的陰性形式以 **-⟪त्री⟫** 結尾（如同 ⟪देवी⟫）。

例如：⟪कर्त्री⟫ f. 「女執行者」
:::
### 42.1.3. 強格詞幹含高階的詞幹

::: grammar-box
以下親屬稱謂屬於此類：

*   ⟪पितृ⟫ m. 「父親」
*   ⟪मातृ⟫ f. 「母親」
*   ⟪दुहितृ⟫ f. 「女兒」
*   ⟪भ्रातृ⟫ m. 「兄弟」
*   ⟪देवृ⟫ m. 「丈夫的兄弟（妻子的姐夫或妹夫）」
*   ⟪यातृ⟫ f. 「丈夫兄弟的妻子」
*   ⟪ननान्दृ⟫ f. 「丈夫的姐妹（妻子的嫂子或小姑）」

**構成：**

*   **強格詞幹：-ar**
*   **弱格詞幹**
*   **元音前：-r**
*   **輔音前：-ṛ**
:::
範例：

::: indent
⟪पितृ⟫ m. 「父親」

⟪मातृ⟫ f. 「母親」
:::

| :--- | :--- | :--- | :--- | :--- |

:::
### 42.1.4. 複合詞中的 -ṛ 結尾詞幹

::: grammar-box
作為複合詞的前半部分，以 -ṛ 結尾的名詞自然處於其弱格詞幹形式，即
*   **在輔音前：-ṛ**
*   **在元音前：-r**
:::
