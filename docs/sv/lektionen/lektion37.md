# Lesson 37

## 37.1. The Adverb (⟪क्रियाविशेषणम्⟫)

In Sanskrit, adverbs are formed

1. by case forms of nouns and pronouns
2. with the help of special suffixes and endings

In the first case, the boundary between living cases and adverbs is fluid. This includes as a special case those adverbs that are fossilized, old case forms, while in declension other forms are used or the corresponding nouns are no longer used as nouns.

## 37.2. Adverbial Use of Case Forms

### 37.2.1. Accusative (⟪द्वितीया⟫)

::: grammar-box

The accusative (⟪द्वितीया⟫) can be used adverbially in response to the questions:

*   in what manner?
*   for how long?
*   whither?
*   etc.

The accusative can be used adverbially:

*   from substantives  
Examples:  
⟪कामम्⟫ "as desired, according to wish"  
⟪अर्थम्⟫ "on account of"

*   from adjectives in the neuter  
Examples:  
⟪सुखम्⟫ "easily, happily"  
⟪नित्यम्⟫ "always"  
⟪साधु⟫ "correctly, well"

*   from pronouns in the neuter  
Examples:  
⟪तद्⟫ "then, therefore"  
⟪यद्⟫ "if, that"  
⟪एतद्⟫ "thus, here, now"

:::

### 37.2.2. Instrumental (⟪तृतीया⟫)

::: grammar-box

The instrumental (⟪तृतीया⟫) can be used adverbially in response to the questions:

*   by what means?
*   with what?
*   etc.

The instrumental can be used adverbially:

*   from substantives  
Examples:  
⟪अर्थेन⟫ "on account of"  
⟪क्षणेन⟫ "at the moment, immediately" (from ⟪क्षण⟫ m. "moment")

*   from adjectives, often also in the plural form  
Examples:  
⟪दूरेण⟫ "far, from afar" (to ⟪दूर⟫ 3 "far, distant from")  
⟪उच्चैस्⟫ "high, loud" (to ⟪उच्च⟫ 3 "high, elevated, loud, shrill (of voice)")

:::

### 37.2.3. Dative (⟪चतुर्थी⟫)

::: grammar-box

Rarely is the dative (⟪चतुर्थी⟫) used adverbially in response to the questions:

*   for what purpose?
*   etc.

Example:

:::

::: indent

⟪अर्थाय⟫ "for the purpose of, for the sake of ..."

:::

### 37.2.4. Ablative (⟪पञ्चमी⟫)

::: grammar-box

The ablative (⟪पञ्चमी⟫) can be used adverbially in response to the questions:

*   why?
*   on account of whom/what?
*   from where?
*   etc.

The ablative can be used adverbially:

*   with substantives  
e.g. ⟪बलात्⟫ "violently, by force"  

*   with adjectives  
e.g. ⟪दूरात्⟫ "from afar"  

*   with pronouns  
Examples:  
⟪कस्मात्⟫ "why"  
⟪अकस्मात्⟫ "unexpectedly"

:::

### 37.2.5. Genitive (⟪षष्ठी⟫)

::: grammar-box

Rarely is the genitive (⟪षष्ठी⟫) used adverbially in response to the question "after how long a time?"

e.g. ⟪चिरस्य⟫ "after a long time" (to ⟪चिर⟫ 3 "long (time)")

:::

### 37.2.6. Locative (⟪सप्तमी⟫)

::: grammar-box

The locative (⟪सप्तमी⟫) can be used adverbially in response to the questions:

*   where?
*   under what circumstances?
*   etc.

Examples:

:::

::: indent

\-⟪अर्थे⟫ "because of"  
\-⟪कृते⟫ "for the sake of"  
⟪दूरे⟫ "far away"

:::

## 37.3. Adverbial usage of case forms no longer in common use

Examples:

::: indent

⟪जातु⟫ "at all" (originally "by birth, by nature", acc. sg. n. to ⟪जातु⟫ \<no longer used as a noun\>)

⟪तूष्णीम्⟫ "silently" (acc. sg. to a no longer used ⟪तूष्णी⟫ f. "silence")

⟪एवम्⟫ "thus" (to an otherwise lost pronominal stem ⟪एव⟫ "one, single")

:::

## 37.4. Formation of adverbs with adverbial suffixes

::: grammar-box

From the pronominal stems ⟪तद्⟫, ⟪इदम्⟫ or respectively ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ or respectively ⟪कु⟫, one can derive corresponding pronominal adverbs with the following adverbial suffixes:

*   \-⟪तस्⟫ (Ablative)
*   \-⟪त्र⟫ (Locative)
*   \-⟪था⟫ (Manner)
*   \-⟪थम्⟫ (Manner)
*   \-⟪दा⟫ (Time)

corresponding pronominal adverbs can be derived.

:::

::: grammar-box

| Suffix | Pronominal stem | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(Ablative) | ⟪ततस्⟫ :brfrom there, on that account, therefore | ⟪इतस्⟫ :br ⟪अतस्⟫ :brfrom here, on this account | ⟪यतस्⟫ :brfrom where, from what | ⟪कुतस्⟫ :brfrom where?, why? |
| **-⟪त्र⟫** :br(Locative) | ⟪तत्र⟫ :brthere, in that place | ⟪अत्र⟫ :brhere | ⟪यत्र⟫ :brwhere | ⟪कुत्र⟫ :brwhere? |
| **-⟪था⟫** :br(Manner) | ⟪तथा⟫ :brthus, so | | ⟪यथा⟫ :brhow | |
| **-⟪थम्⟫** :br(Manner) | | | | ⟪कथम्⟫ :brhow? |
| **-⟪दा⟫** :br(Time) | ⟪तदा⟫ :bat that time, then | | ⟪यदा⟫ :bat the time when | ⟪कदा⟫ :brwhen? |

:::

## 37.5. Adverbiala sammansätt

### 37.5.1. Sammansätt med ett adverb eller i adverbiell funktion använd kasus som andra ledet

Exempel: ⟪सुचिरम्⟫ "mycket lång (tid)"

### 37.5.2. Adverbiellt använda ⟪बहुव्रीहि⟫

Exempel: ⟪रक्षार्थम्⟫ "på det sättet av någon vars syfte är att skydda, med syftet att skydda". Kan också betraktas som tillhörande 5.1.: -⟪अर्थम्⟫ som adverbiellt andra ledet.

### 37.5.3. ⟪अव्ययीभाव⟫-sammansättningar

⟪अव्ययीभाव⟫ = "oföränderlig/odeklinabel gjord"

::: grammar-box

Ett ⟪अव्ययीभाव⟫ är ett adverbiellt sammansätt vars första led är en indeklinabel (postposition, partikel o.s.v.) och vars andra led är ett substantiv som antar ändelsen för ackusativ singular neutrum.

Vid upplösning av sammansättningen skulle det första ledet styra det andra:

Exempel:

:::

::: indent

⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = "mot elden"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "enligt krafterna"

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = "framåt, emot"

:::

Särskilt viktiga är ⟪अव्ययीभाव⟫ med ⟪यथा⟫ "som" som första led:

t.ex. ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ = "som önskan är, efter önskan, godtyckligt"

## 37.7. Obestämda pronomen

::: grammar-box

Obestämda pronomen bildas genom att lägga till

*   \-⟪चिद्⟫
*   \-⟪चन⟫
*   ⟪अपि⟫

till kasusformerna av det interrogativa pronomenet ⟪किम्⟫.

## 37.8. Der Fragesatz

::: grammar-box

"Vem?, hur?, vad?, varför?, av vilken anledning?, varför?
Den som inte frågar förblir dum."

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

Motto från Sesam, som är en bra riktlinje för livet och sanskritstudier

:::

Siehe auch [Lektion 4](lektion04.md).

Man muss unterscheiden

*   Wortfragen (Ergänzungsfragen)
*   Satzfragen

Vid ordfrågor frågas efter ett agens (⟪कर्तृ⟫), ett objekt, en aktivitet, en omständighet etc., t.ex.

*   vem kommer?
*   vad gör Rāma?
*   vem hör han?
*   hur talar hon sanskrit?
*   var är modern?

Vid satsfrågor frågas hela satsens innehåll, t.ex.

*   går Rāma till Ofterdingen idag?
*   är det sant att ... ?

### 37.8.1. Wortfragen (Ergänzungsfragen)

::: grammar-box

Schema:

Fragepronomen/Frageadverb - Satz

:::

Beispiele:

::: indent

⟪को ग्रामं गच्छति⟫ =  ⟪केन ग्रामो गम्यते⟫ = "Wer geht ins Dorf?"

⟪किं बाला अधीयीरन्⟫ = "Was sollten Kinder lernen?"

⟪क्व रामो वसति⟫ = Wo wohnt Rāma?

:::

::: media

![lekt3704.jpg](/images/lekt3704.webp)

Abb.: ⟪किं बाला अधीयीरन्⟫

(Bildkälla: [Details](/sv/licenses#lekt3704))

*   ⟪अपि⟫

*   ⟪किम्⟫ (often suggests a negative answer)

*   ⟪कच्चिद्⟫


These particles correspond to the question mark.

:::

Example:

::: indent

⟪अपि सत्यम् ।⟫ "Is it also true?"

⟪किं शक्नोति ।⟫ "Can he, then?"

⟪कच्चित्क्षत्रियेण शत्रवो जिताः ।⟫ "Has the Kṣatriya perhaps defeated the enemies?"

:::

Note: ⟪किम्⟫ can mean not only "what?" but also as a question particle "why?, for what purpose?". Especially with the instrumental case (⟪तृतीया⟫):

::: indent

⟪किं क्रोधेन ।⟫ "What is the anger for? What does the anger help? What should the anger do?"

:::

## 37.11. Review Exercise

Translate into Sanskrit using exclusively perfect verb forms:

Once, when an old man was going to another village, he became tired on the way. So he went to lean against a mango tree standing by the side, in order to rest. On this tree there were ripe fruits. The old man desired these. But he could not climb the tree and reach for the fruits. Fortunately, there were some monkeys on this tree that ate fruits. When he saw these, the old man rejoiced. What did he do? He took some stones, aimed at the monkeys and threw them. The enraged monkeys picked up some fruits and threw them at the old man. The old man joyfully took these and went to his desired region. Behold, the fate of the old man!
