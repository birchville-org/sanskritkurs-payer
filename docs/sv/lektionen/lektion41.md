## 41.2. Further ⟪कृत्⟫ formations on -a

### 41.2.1. Present Participle (⟪लडादेशः⟫) Ā, Passive Present Participle (⟪लडादेशः⟫) Passive, Future Participle (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Thematic present stems, passive and future

::: grammar-box

**Formation:**

Present stem / passive stem / future stem + -māna (fem. mānā)

:::

Examples:

⟪यज्⟫ 1U, Pres.P.Ā ⟪यजमान⟫ 3 "one who is honoured with a sacrifice for one's own benefit = lord of the sacrifice"

⟪मन्⟫ 4Ā, Pres.P.Ā ⟪मन्यमान⟫ 3 "a thinking one"

⟪कृ⟫ 8U, Pres.P.Passive ⟪क्रियमाण⟫ 3 "something that is done"

⟪दा⟫ 3U, Fut.P.Ā ⟪दास्यमान⟫ 3 "one who will give for one's own benefit"

#### 41.2.1.2. A-thematic present classes

::: grammar-box

**Formation:**

Weak present stem (in the form it has before the ending -ate of 3.pl.Ā) + -āna (fem. -ānā)

:::

Examples:

::: grammar-box

| Root / Class | Present Participle Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |

:::

### 41.2.2. "Particip" av passiv nödvändighet (Gerundivum) (⟪कृत्य⟫)

::: grammar-box

**För att uttrycka passiv nödvändighet ("vad som måste/bör göras") kan man bilda adjektiv från rötter och avledda verbstammar valfritt med följande suffix:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (statt **-⟪य⟫**/**-⟪या⟫**)

:::

#### 41.2.2.1. Suffixet -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box

**Suffixet -⟪तव्य⟫ / -⟪तव्या⟫ fogas till rötter och avledda verbstammar (t.ex. kausativ) på samma sätt som infinitivsuffixet -⟪तुम्⟫ (se [Lektion 23](lektion23.md)), d.v.s.**

* **hochstufige Wurzel + ⟪तव्य⟫**

oder

* **hochstufige Wurzel + -i- + ⟪तव्य⟫**

**I kausativ:**

* **Kausativstam på -ay + -i- + ⟪तव्य⟫**

:::

Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "someone who must be defeated; one to be defeated" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "that where one should be located" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "someone who should be awakened; one to be awakened" |

:::

#### 41.2.2.2. Suffixet -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box

**Bildung:**

Hochstufige Wurzel + -⟪अनीय⟫ / -⟪अनीया⟫

**Kausativ och 10:e presensklass:**

Rot, som den framträder i kausativstammen, utan -aya- + -⟪अनीय⟫ / -⟪अनीया⟫

:::

Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "to be given; what must be given" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "one to be defeated" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "to be done" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "what must be seen; worth seeing" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "one to be awakened" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "what must be caused to give" |

:::

#### 41.2.2.3. The Suffix -⟪य⟫ / -⟪या⟫

::: grammar-box

**Formation:**

Root (in low, strong or guṇa grade) + -⟪य⟫

For the exact rules, see Kielhorn, Grammar of the Sanskrit Language, pp. 195 - 197!

:::

Treatment of final vowels:

::: grammar-box

**1. Roots ending in -ā form this gerundive on -eya**

:::

Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "to be known; what must be recognized" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "what must be given" |

:::

::: grammar-box

**2. Roots ending in -i /-ī / -u / -ū /-ṛ generally have strong or guṇa grade, unless they belong to those roots ending in -i / -u /-ṛ that form a gerundive with the suffix -⟪त्य⟫ (fem. -⟪त्या⟫) (list of these roots in Kielhorn, Grammar §537).**

:::

Example:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 | "that which must be remembered" |

:::

::: grammar-box

**2a. Roots ending in -i/-ī have strong grade**

:::

Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | "to be sold; sellable" |
| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "to be led" |

:::

![lekt4103.jpg](/images/lekt4103.webp)

Fig.: ⟪विक्रेयाणि पुष्पानि⟫
(Image source: [Details](/sv/licenses#lekt4103))

:::

::: grammar-box

**2b. Roots ending in -u /-ū replace the strong grade -o before -ya with -av, and the guṇa grade -au with -āv. Guṇa grade formation in this case denotes necessity.**

:::

Example:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्तु⟫ 2U | ⟪स्तव्य⟫ 3 | "what should be praised" |
|   | ⟪स्ताव्य⟫ 3 | "what must necessarily be praised" |

:::

#### 41.2.2.4. Suffixet -⟪त्य⟫ / ⟪त्या⟫ (istället för -⟪य⟫ / -⟪या⟫)

::: grammar-box

Liste der Wurzeln auf -i / -u /-ṛ, die ein Gerundiv statt mit -⟪य⟫ / -⟪या⟫ mit dem Suffix -⟪त्य⟫ (fem. -⟪त्या⟫) bilden, bei Kielhorn, Grammatik §537.

### 41.2.3. Syntax för "participet" av passiv nödvändighet (Gerundivum) (⟪कृत्य⟫)

::: grammar-box

Gerundivet kan användas attributivt:

:::

::: indent

**⟪दर्शनीयं नगरम्⟫** = "en stad som man måste se; en sevärd stad"

:::

Gerundivet kan också användas som predikatsnomen i satser med passiv konstruktion som uttrycker en skyldighet eller ett kommando (med ⟪न⟫ ett förbud, en omöjlighet):

::: indent

**⟪काशी द्विजैर्द्रष्टव्या⟫** = "Två gånger födda måste se Benares"

:::

### 41.2.4. Skillnader i användningen av gerundivsuffixen

::: grammar-box

Användningen av dessa suffix överlappar i stor utsträckning

* **-⟪तव्य⟫ (fem. -⟪तव्या⟫):** uttrycker alltid en nödvändighet och används företrädesvis predikativt (mer sällan attributivt). Bildningar med detta suffix ska inte användas i nominalkomposita.
* **-⟪अनीय⟫ (fem. -⟪अनीया⟫) och -⟪य⟫ (fem. -⟪या⟫) / -⟪त्य⟫ (fem. -⟪त्या⟫) (istället för -⟪य⟫/-⟪या⟫):** kan ha en ytterligare betydelse (särskilt -⟪य⟫) i betydelsen av svenska "-värd" (t.ex. "sevärd") eller bara en möjlighet "-bar" (⟪दृश्य⟫ "synlig"). Bildningar med dessa suffix kan nekas med ⟪अ⟫-/-⟪अन्⟫- (men inte bildningar med -⟪तव्य⟫) och det finns ⟪तत्पुरुष⟫ som deras efterled de förekommer.

:::

### 41.2.5. Ingen koppling till ⟪सु⟫- och ⟪दुस्⟫-

::: grammar-box

Gerundiver får inte kopplas till ⟪सु⟫- och ⟪दुस्⟫- i betydelsen "lätt" respektive "svår". Istället används ⟪तत्पुरुष⟫ av typen ⟪सुकर⟫ 3 ("lätt att göra") (se [Lektion 18](lektion18.md)).

:::
