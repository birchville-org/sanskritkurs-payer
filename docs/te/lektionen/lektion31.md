# పాఠం 31

## 31.1. ఏడవ వర్తమాన క్లాస్ (⟪रुधादि⟫ = "⟪रुध्⟫ మొదలైనవి")

::: grammar-box
**రూపకల్పన:**

**ఆధార రూపంలోని లోతైన స్థాయిలో ఉన్న అక్షరం తర్వాత ఒక నాసిక్య ఇన్‌ఫిక్స్ (-na- లేదా -n-) చేర్చబడుతుంది:**

*   **బలమైన రూపంలో: -na-**
*   **దుర్బల రూపంలో: -n-**

**ఆధార రూపం యొక్క అంత్య అక్షరాలను సంయుక్తాంతాలతో కలపడానికి రెండవ వర్తమాన క్లాస్‌కు వర్తింపే నియమాలు ఇక్కడ కూడా వర్తిస్తాయి.**
:::
