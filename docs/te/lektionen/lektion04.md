# నాల్గవ పాఠం

## 4.1. సరళమైన పూరిత ప్రశ్నలు (పద ప్రశ్నలు) మరియు సమాధానాలు

### 4.1.1. ప్రశ్నార్థక సర్వనామాలు మరియు నిదర్శక సర్వనామాలు

#### 4.1.1.1. ప్రశ్నార్థక సర్వనామాలు (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | ప్రథా విభక్తి ఏకవచనం | ప్రథా విభక్తి బహువచనం |
| :--- | :--- | :--- |
| **పుంలింగం** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **స్త్రీలింగం** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **నపుంసకలింగం** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. నిదర్శక సర్వనామాలు (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **ప్రత్యయాలు** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"అతడు, ఆమె, అది; వాడు, ఆమె, దాని":br(ప్రస్తావించబడినది)** | **etad = ⟪एतद्⟫:br"ఈ, ఈ, ఇది":br(మాట్లాడే వ్యక్తికి చాలా దగ్గరగా ఉన్నది)** | **idam = ⟪इदम्⟫:br"ఈ, ఈ, ఇది":br(దగ్గరగా ఉన్నది)** |
| **ప్రథా విభక్తి ఏకవచనం** ||||
| **పుంలింగం** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **స్త్రీలింగం** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **నపుంసకలింగం** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **ప్రథా విభక్తి బహువచనం** ||||
| **పుంలింగం** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **స్త్రీలింగం** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **నపుంసకలింగం** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**ప్రథా. ఏ. పుం. విషయంలో:**
**sa, eṣa** (⟪स एष⟫) అనేది **అ-కారం** తప్ప మిగతా అన్ని ధ్వనులకు ముందు వస్తుంది
**so, eṣo** (⟪सो एषो⟫) అనేది **అ-కారం** కు ముందు వస్తుంది, ఇది అవగ్రహంతో లోపించిపోతుంది (ఎలిడీ)
**saḥ, eṣaḥ** (⟪सः एषः⟫) అనేది విరామంలో మాత్రమే వస్తుంది (వాక్యం ముగింపు, శ్లోకం ముగింపు)

ఈ ప్రత్యయాలతో (sarvanāman n.) వాక్యాలను రూపొందించడానికి, క్రింద ఉన్న సాంధి నియమాల జ్ఞానం కూడా అవసరం:

### 4.1.2. అంత్యంలో ఉండే -m యొక్క సాంధి

::: grammar-box
అంత్యంలో ఉండే -m అనుస్వారం (-ṃ) తో మారుతుంది. వాక్యం లేదా పద్య అంతంలో మరియు స్వరాల ముందు -m ఉంటుంది.
:::
### 4.1.3. అంత్యంలో ఉండే -e యొక్క సాంధి

::: grammar-box
1. **a- ముందు -e మారదు: ప్రారంభంలో ఉండే a- అవగ్రహతో లోపిస్తుంది:**
ఉదా. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "ఈ అగ్నులు"

అల్పకాలిక a- తప్ప ఇతర స్వరాల ముందు -e సాధారణంగా హైయటస్ తో -a తో మారుతుంది. -ay తో కూడా మారవచ్చు:
ఉదా. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (అరుదు: imay īśvarāh = ⟪इमयीश्वराः⟫) "ఈ ప్రభువులు"
:::
### 4.1.4. అంత్యంలో ఉండే -d యొక్క సాంధి

::: grammar-box
అంత్యంలో ఉండే -d విరామం మరియు నిస్పంద గుహ్యాక్షరాల (k, kh) మరియు ఓష్ఠ్యాల (p, ph) ముందు -t తో మారుతుంది.

ఇతర వ్యంజనాల ముందు మార్పును తర్వాత చర్చిస్తాము. ప్రస్తుతం ఈ రకమైన ధ్వని సంఘర్షణలను నివారించండి!
:::
### 4.1.5. ప్రశ్నా వాక్యాలు

ఈ ప్రత్యయాలతో, ఉదాహరణకు, క్రింది ప్రశ్నా వాక్యాలను రూపొందిస్తారు:

మరొక ప్రశ్నలకు ఉదాహరణ:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ సమాధానం: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (ఇక్కడ ప్రశ్నకు అనుసంధానాన్ని బలపరచడానికి నిర్మాణవాక్యంలో విషయాన్నీ ఉదాహరణకు మొదట ఉంచవచ్చు.)

గమనిక: మీరు ఇప్పటి వరకు కలిగిన సంస్కృత జ్ఞానంతో ఈ రకమైన ప్రశ్నలకు ఇచ్చే సమాధానాలు, ఖచ్చితంగా అన్ని విషయాలలో సంస్కృత భాషకు సరైన శైలిని కలిగి ఉండవు.


## 4.2. అభ్యాసం

**A) viṣṇuḥ kaḥ (⟪विष्णुः कः⟫) అనే నమూనా ప్రకారం ఈ క్రింది పదాలతో వాయిస్తూ ప్రశ్నలు అడిగి, సంస్కృతంలో సమాధానం ఇవ్వండి:**

śruti, śiva, brāhmaṇa, dvija (బహువచనం), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**B) ఈ క్రింది చదువు ప్రశ్నలకు etat kim (⟪एतत्किम्⟫) అనే నమూనా ప్రకారం ప్రశ్నలు అడిగి, ఇచ్చిన పదాలు మరియు సూచించు పదాలతో eṣa bālaḥ (⟪एष बालः⟫) వంటి సమాధానాలు ఇవ్వండి:**
