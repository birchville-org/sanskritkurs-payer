## 7.1. ప్రత్యక్ష కర్మతో కూడిన వాక్యం

::: grammar-box
**సూత్రం:**
**(కర్త = kartṛ m. = ⟪कर्तृ⟫) – ప్రత్యక్ష కర్మ (karman n. = ⟪कर्मन्⟫) – క్రియ**

ఉదాహరణకు
**rāmaḥ phalaṃ khādati** = ⟪रामः फलं खादति⟫ : "రామ ఫలాన్ని తింటాడు."
**brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो देवं यजति⟫ : "బ్రాహ్మణుడు దేవుడిని యజ్ఞంతో పూజిస్తాడు (ఇతరుల కోసం)."
:::
క్రియ పరస్మైపదం లేదా ఆత్మనెపదంలో ఉంటే, ప్రత్యక్ష కర్మ (**karman** n. = ⟪कर्मन्⟫) సాధారణంగా **విశేష్య విభక్తి** (Wenfall, dvitīyā f. = ⟪द्वितीया⟩)లో ఉంటుంది.

### 7.2.1. ప్రశ్నార్థక మరియు సూచిక సర్వనామాల యొక్క ఏకవచన మరియు బహువచన కర్త్రార్థక విభక్తి

::: grammar-box
| || పుల్లీంగం | స్త్రీలింగం | నపుंसలింగం |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :brఎవరు/ఏమిటి | ఏ. | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |
| | బ. | **kān** :br⟪कान्⟫ | **kās** :br⟪कास्⟫ | **kāni** :br⟪कानि⟫ |
| **tad** :brఆ/అది/ఆ సమీపంలో ఉన్నది | ఏ. | **tam** :br⟪तम्⟫ | **tām** :br⟪ताम्⟫ | **tad** :br⟪तद्⟫ |
| | బ. | **tān** :br⟪तान्⟫ | **tās** :br⟪तास्⟫ | **tāni** :br⟪तानि⟫ |
| **etad** :brఈ/ఇది | ఏ. | **etam / enam** :br⟪एतम्⟫ / ⟪एनम्⟫ | **etām / enām** :br⟪एताम्⟫ / ⟪एनाम्⟫ | **etad / enad** :br⟪एतद्⟫ / ⟪एनद्⟫ |
| | బ. | **etān / enān** :br⟪एतान्⟫ / ⟪एनान्⟫ | **etās / enās** :br⟪एतास्⟫ / ⟪एनास्⟫ | **etāni / enāni** :br⟪एतानि⟫ / ⟪एनानि⟫ |
| **idam** :brఈ/ఇది | ఏ. | **imam / enam** :br⟪इमम्⟫ / ⟪एनम्⟫ | **imām / enām** :br⟪इमाम्⟫ / ⟪एनाम्⟫ | **idam / enad** :br⟪इदम्⟫ / ⟪एनद्⟫ |
| | బ. | **imān / enān** :br⟪इमान्⟫ / ⟪एनान्⟫ | **imās / enās** :br⟪इमास्⟫ / ⟪एनास्⟫ | **imāni / enāni** :br⟪इमानि⟫ / ⟪एनानि⟫ |
:::
**enam** (⟪एनम्⟫) మొదలైన రూపాలు **enad** (⟪एनद्⟫) అనే మూలానికి చెందినవి, ఇది కొన్ని విభక్తులలో మాత్రమే రూపాలను ఏర్పరుస్తుంది. ఇవి **etad** మరియు **idam** రూపాలకు బదులుగా, ఆ పదం ద్వారా సూచించబడినది ముందుగానే ప్రస్తావించబడినప్పుడు ఉపయోగించబడతాయి.
ఉదా: **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं देवः⟫ | ⟪एनं यजन्ते⟫ || : "అతను ఒక దేవుడు. వారు అతనికి యజ్ఞం చేస్తారు."


### 7.2.2. ద్వితీయా విభక్తి (కర్తృవాచకం, dvitīyā f. = ⟪द्वितीया⟫ = "రెండవ విభక్తి ప్రత్యయం")

::: grammar-box
ద్వితీయా విభక్తి (dvitīyā f. = ⟪द्वितीया⟫) ఈ క్రింది అర్థాలను సూచిస్తుంది:
1. క్రియాపదం ద్వారా వ్యక్తమయ్యే పని యొక్క **ప్రత్యక్ష కర్మ** (karman n. = ⟪कर्मन्⟫) ను సూచిస్తుంది:
ఉదాహరణకు,
**devaṃ yajati** = ⟪देवं यजति⟫ : "అతను ఒక దేవునికి యజ్ఞం చేస్తాడు."
**phalam āpnoti** = ⟪फलमाप्नोति⟫ : "అతను ఫలాన్ని (ఉదా: తన కృషి యొక్క) పొందుతాడు."
2. ఏదైనా దిశగా వెళ్లడం, కదిలడం లేదా తీసుకువెళ్ళడం వంటి అర్థాలను వ్యక్తపరిచే క్రియలలో, ద్వితీయా విభక్తి చలన యొక్క లక్ష్యాన్ని సూచిస్తుంది:
ఉదాహరణకు,
**narakaṃ gacchati** = ⟪नरकं गच्छति⟫ : "అతను నరకానికి వెళ్తాడు."
:::
ద్వితీయా విభక్తి యొక్క ఇతర ఉపయోగాలను తర్వాత చర్చిస్తాము.



## 7.3. అంత్య -n యొక్క సందర్భం

::: grammar-box
**అంత్య -n:**

1. మూర్ఛిత పల్టాల మరియు రెట్రోఫ్లెక్స్ స్పర్శాలు మరియు **ś-** కు ముందు, ఆ ధ్వనులకు అనుగుణంగా ఉన్న నాసల్‌తో భర్తీ చేయబడుతుంది:
**j-, jh-, ñ-, ś-** కు ముందు **-n** » **-ñ**
**ḍ-, ḍh-, ṇ-, ṣ-** కు ముందు **-n** » **-ṇ**
ఉదా: **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "అతను క్షత్రియులను ఓడిస్తాడు."
ప్రారంభంలో ఉన్న **ś-** తరచుగా **ch-** గా భర్తీ చేయబడుతుంది:
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (గురువులను వినడం) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "అతను గురువులను వినുന്നു."

2. అనునాసిక (ముక్కు గొంతుతో కూడిన ల్, వ్రాయుటలో ⟪ल्⟫ అనునాసికతో ⟪ँ⟫) చేత ప్రారంభంలో **l-** ఉన్నప్పుడు **-l** తో మార్చబడుతుంది:
ఉదా. **paśūn + labhate** » ⟪पशूंल्लभते⟫ : "అతను పశువులను పొందుతాడు."

3. నిస్పందన లేని పల్టల్, రెట్రోఫ్లెక్స్ లేదా డెంటల్ ముందు **అనుస్వారం** + ఆ శబ్దానికి అనుగుణంగా ఉండే జిహ్వారవ్వుతో మార్చబడుతుంది:
**c-, ch-** ముందు **-n** » **-ṃś**
**ṭ-, ṭh-** ముందు **-n** » **-ṃṣ**
**t-, th-** ముందు **-n** » **-ṃs**
ఉదా. **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : "మరియు దేవతలు (ఆకర్షణ)"
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : "కాని దేవతలు (ఆకర్షణ)"

4. తక్కువ స్వరం తర్వాత (నామకరణం కోసం చూడండి) మినహా, మిగతా అన్ని సందర్భాలలో చివరన ఉండే **-n** మారదు.
:::

## 7.4. నపుంసక లింగం (napuṃsaka n. = ⟪नपुंसक⟫)

## 7.5. అతమధ్యాత్మిక ప్రస్తుత కాల వర్గాలు

ఐదవ ప్రస్తుత కాల వర్గం ఒక అతమధ్యాత్మిక ప్రస్తుత కాల మూలాన్ని ఏర్పరుస్తుంది, అంటే ప్రస్తుత కాల మూలం థీమాటిక్ ప్రస్తుత కాల వర్గాలలో (1., 4., 6., 10. వర్గం) ఉండే "థీమా స్వరం" **-a** తో ముగియదు.

::: grammar-box
**అతమధ్యాత్మిక ప్రస్తుత కాల వర్గాలకు మూల భేదం ఉంటుంది, అంటే ప్రస్తుత కాల మూలానికి రెండు రూపాలు ఉంటాయి:**
1. **బలమైన మూలం**: ఎత్తైన స్థాయి (అరుదుగా పొడవైన స్థాయి)
2. **బలహీన మూలం**: తక్కువ స్థాయి

**బలవంతమైన మూలం నిలుస్తుంది:**
ఇండికేటివ్ సింగులార్ పరస్మైపద ప్రెజెంట్ (laṭ) మరియు ఇంపర్ఫెక్ట్ (laṅ) లో
ఇంపరటివ్ యొక్క మొదటి వ్యక్తి అన్ని రూపాలలో (loṭ) పరస్మైపద మరియు ఆత్మనేపద
మూడవ వ్యక్తి సింగులార్ ఇంపరటివ్ (loṭ) పరస్మైపదలో

**మిగతా అన్ని రూపాలు బలహీనమైన ప్రెజెంట్ మూలాన్ని కలిగి ఉంటాయి.**
:::
### 7.5.1. అథమాటిక్ మూలాలలో తృతీయ వ్యక్తి బహువచన ప్రాథమిక అంత్యములు

::: grammar-box
**అథమాటిక్ ప్రెజెంట్ మూలాలలో, తృతీయ వ్యక్తి బహువచన ప్రాథమిక అంత్యములు ఇలా ఉంటాయి:**
**పరస్మైపద: -anti**
**ఆత్మనేపద: -ate**
:::
### 7.5.2. ఐదవ ప్రెజెంట్ వర్గం (svādi = ⟪स्वादि⟫ = "su మొదలైనవి")

::: grammar-box
**బలవంతమైన మూలం**: (సాధారణంగా) తక్కువ స్థాయి వ్యుత్పత్తి (గా పేర్కొన్నట్లు) + **-no-**
**బలహీనమైన మూలం**: (సాధారణంగా) తక్కువ స్థాయి వ్యుత్పత్తి (గా పేర్కొన్నట్లు) + **-nu-**

**స్వరంతో ముగిసే వ్యుత్పత్తులలో, స్వర అంత్యాల ముందు -nu- ని -nv- గా ప్రతిక్షేపిస్తారు; అకారంతో ముగిసే వ్యుత్పత్తులలో, స్వర అంత్యాల ముందు -nu- ని -nuv- గా ప్రతిక్షేపిస్తారు.**
:::

| **aś** :br5 Ā:br⟪अश्⟫:br"అందుకోవడం" | — | **aś-nu** :br(3.sg. aśnute = ⟪अश्नुते⟫) | **aś-nuv** :br(3.pl. aśnuvate = ⟪अश्नुवते⟫) |

## 7.6. పదజాలం

**క్రింది పదాలు నేర్చుకోండి:**

**aś** 5 Ā (aśnute) ⟪अश् अश्नुते⟫ : చేరుకోవడం, అందుబాటులోకి రావడం, సంపాదించడం
**āp** 5 P (āpnoti) ⟪आप् आप्नोति⟫ : చేరుకోవడం, సంపాదించడం
**kup** 4 P (kupyati) ⟪कुप् कुप्यति⟫ : కోపించడం
**krudh** 4 P (krudhyati) ⟪क्रुध् क्रुध्यति⟫ : కోపించడం
**khād** 1 P (khādati) ⟪खाद् खादति⟫ : నమలడం, తినడం
**śru** 5 P (śṛṇoti !) ⟪श्रु शृणोति⟫ : వింటుంది (ఏదైనా: కర్తృవిభక్తి, ఎవరినైనా: జన్యు విభక్తి లేదా కర్తృవిభక్తి; గురించి: కర్తృవిభక్తి; ఎవరి నుండి: జన్యు విభక్తి, అపాదన విభక్తి, కరణ విభక్తి)
**su** 5 U (sunoti) ⟪सु सुनोति⟫ : నురుగు తీయడం
**soma** m. ⟪सोम⟫ : నురుగు తీసిన పానీయం, సోమ; చంద్రుడు (ఏ మొక్క నుండి సోమాన్ని నురుగు తీశారు అనేది ఇప్పటికీ వివాదాస్పదంగా ఉంది).
::: media
![](/images/lekt0701.webp)
చిత్రం: ఇది వేద కాల సోమ మొక్కనా?: పుట్టగొడుగు: *Amanita muscaria* (L.) Lam.
(చిత్ర మూలం: [వివరాలు](/te/licenses#lekt0701))
:::
**phala** n. ⟪फल⟫ : ఫలం (అంతర్గత అర్థంలో కూడా: కర్మ యొక్క ఫలం)
**nṛtya** n. ⟪नृत्य⟫ : నృత్యం
**svarga** m. ⟪स्वर्ग⟫ : స్వర్గం
**naraka** m. ⟪नरक⟫ : నరకం (ఒక హిందూ దృక్పథం ప్రకారం, విశ్వం ఒక గుడ్డ ఆకారంలో ఉంటుంది (**Brahmāṇḍa** m.n. = ⟪ब्रह्माण्ड⟫ = "బ్రహ్మ గుడ్డు"): భూమికి పైన ఎక్కువ ఆనందం కలిగించే ఛఠ్ స్వర్గాలు ఉన్నాయి, భూమికి కింద ఏడు పాతాల n. = ⟪पाताल⟫, **nāga** m. = ⟪नाग⟫ (సర్పాలు) మరియు ఇతర పౌరాణిక జీవుల నివాస ప్రదేశాలు ఉన్నాయి, అక్కడ ఎక్కువ బాధలు కలిగించే ఏడు నరకాలు ఉన్నాయి)
**aṅga** n. ⟪अङ्ग⟫ : శరీర భాగం, అంగం; కూడా = **vedāṅga** = ⟪वेदाङ्ग⟫
**gam** 1 P (gacchati) ⟪गम् गच्छति⟫ : వెళ్ళడం (స్థానిక క్రియా వర్గీకరణ ప్రకారం ఇది మొదటి క్రియా వర్గంలోకి వస్తుంది, కానీ నిజానికి ఇది ఒక ప్రత్యయం **-ccha-** తో కూడిన రూపం: **gam** » లోతైన స్థాయి (**gm** ») **ga-ccha-ti**)




## 7.7. అభ్యాసం

**A) ప్రతి సందర్భంలో ఏకవచన మరియు బహువచనాలలో పరోక్ష వస్తువు లేదా దిశాత్మక నిత్యవాచకాన్ని ప్రతిక్షేపించండి:**

1. brāhmaṇas ... yajati (deva, devī, viṣṇu, agni, devatā)
⟪ब्राह्मणस्⟫ ... ⟪यजति⟫ (⟪देव⟫, ⟪देवी⟫, ⟪विष्णु⟫, ⟪अग्नि⟫, ⟪देवता⟫)

2. gurus ... khādati (phala)
⟪गुरुस्⟫ ... ⟪खादति⟫ (⟪फल⟫)

⟪साधुस्⟫ ... ⟪गच्छति⟫ (⟪स्वर्ग⟫)
4. śūdrā ... gacchati (naraka)
⟪शूद्रा⟫ ... ⟪गच्छति⟫ (⟪नरक⟫)

⟪जयति⟫ (⟪शूद्र⟫)

**B) సంబంధిత క్రియా రూపాలను ప్రతిక్షేపించండి:**

1. sādhuḥ svargaṃ ... (āp, gam, aś)
⟪साधुः स्वर्गम्⟫ ... (⟪आप्⟫, ⟪गम्⟫, ⟪अश्⟫)

⟪ब्राह्मणः सोमम्⟫ ... (⟪सु⟫)
3. sādhur gurum ... (śru)

⟪देवी⟫ ... (⟪कुप्⟫, ⟪क्रुध्⟫)

**C) అభ్యాస వాక్యాలు B) లోని కర్త, వస్తువు మరియు క్రియలను బహువచనంలో ప్రతిక్షేపించండి.**

**F) అనువదించండి:**
