# పాఠం 50

## 50.1. నామ ఉత్పత్తి: క్రమానుసార తులన

::: grammar-box
**క్రమానుసార తులన సంస్కృతంలో ⟪तद्धित⟫ ప్రత్యయాలతో జరుగుతుంది**
* **-⟪तर⟫ (స్త్రీలింగం: ⟪तरा⟫) "సమాన తులన"లో**
* **⟪तम⟫ (స్త్రీలింగం: ⟪तमा⟫) "అత్యధిక తులన"లో**

**ఈ ప్రత్యయాలు విశేషణాలకు పుంలింగ నామపదానికి జోడించబడతాయి. స్థితి మార్పు కలిగిన నామాలకు, వాటి బలహీన రూపానికి జోడించబడతాయి, ఇవి లోకativ (⟪पञ्चमी⟫) బహువచనం -su ముందు ఉన్న రూపాన్ని కలిగి ఉంటాయి.**
:::
::: media
![](/images/lekt5007.webp)
చిత్రం: ⟪लोकस्योत्तमो गिरिः सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = ఎవరెస్ట్ పర్వతం
(చిత్ర మూలం: [వివరాలు](/te/licenses#lekt5007))
:::

::: grammar-box
**అర్థం:**

**"సమాన తులన" అంటే, పోల్చబడే వస్తువు ప్రకటించబడనప్పుడు: "పర్వాలేదు, చాలా, అత్యధిక":**

:::
::: indent
ఉదా. ⟪सुचितर⟫ 3 "పర్వాలేదు శుద్ధి", "చాలా శుద్ధి", "అత్యధిక శుద్ధి"
:::
**పోల్చబడే వస్తువు ప్రకటించబడినప్పుడు, అది Ablativ (⟪पञ्चमी⟫)లో ఉంటుంది. సమాన తులన + Ablativ అనేది జర్మన్లో "కంటే"తో తులనకు సమానం.**

::: indent
ఉదా. ⟪देवदत्ताद्रामो धीमत्तरः⟫ = అక్షరాలా: "దేవదత్త నుండి చూస్తే రామ అధిక జ్ఞానం కలిగి ఉన్నాడు" = "రామ దేవదత్త కంటే అధిక జ్ఞానం కలిగి ఉన్నాడు"
:::
**"అత్యధిక తులన" అంటే, పోల్చబడే వస్తువు ప్రకటించబడనప్పుడు: "అత్యధిక, చాలా":**

::: indent
ఉదా. ⟪सत्तम⟫ 3 (⟪सन्त्⟫ కి) "అత్యధిక మంచి, చాలా మంచి"
:::
**పోల్చబడే వస్తువు ప్రకటించబడినప్పుడు, అది Genetiv (⟪षष्ठी⟫)లో ఉంటుంది ("వై", "మధ్య") మరియు అత్యధిక తులన జర్మన్ అత్యధిక తులనకు (అత్యధిక స్థాయి) సమానం:**

::: indent
ఉదా. ⟪द्विजानां सत्तमः⟫ = "రెండుసార్లు జన్మించిన వారిలో అత్యుత్తముడు"
:::
**-⟪तर⟫ మరియు -⟪तम⟫ ప్రత్యయాలు కేవలం విశేషణాలకు మాత్రమే కాక, సర్వనామాలు, అవికార్య పదాలు మరియు క్రియా రూపాలకు కూడా జతచేయబడవచ్చు:**

ఉదాహరణలు:

::: indent
⟪गजतम⟫ పుం. "ఉత్తమ ఏనుగు" (⟪गज⟫) (బుద్ధుని పేరు కూడా)

⟪गोतम⟫ పుం. "ఉత్తమ యాజ్ఞము" (⟪गो⟫) లేదా: "గోవులలో అత్యధికం కలిగినది"

⟪उद्⟫ అవికార్య. "పైకి", "ఎక్కువ" » ⟪उत्तर⟫ 3 "అధికతరం" » ⟪उत्तम⟫ 3 "అధికతమం"
:::
**ఈ ప్రత్యయాలు క్రియారూపానికి జతచేయబడినప్పుడు, అవి ఎల్లప్పుడూ విశేషణ రూపంలో కనిపిస్తాయి:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

ఉదాహరణలు:

::: indent
⟪पचतितराम्⟫ "అతను/ఆమె/దాని మంచిగా వంట చేస్తుంది"

⟪पचतितमाम्⟫ "అతను/ఆమె/దాని అత్యంత మంచిగా వంట చేస్తుంది"
:::
**ఈ రూపం ఈ ప్రత్యయాలు అవికార్యానికి జతచేయబడి, ఉత్పన్నమైన పదం విశేషణంగా వాడబడినప్పుడు కూడా ఉంటుంది:**

::: indent
ఉదా. ⟪सुतराम्⟫ (⟪सु⟫ కు) "మంచి విధంగా" (విశేషణం)
:::
