# పాఠం 25

## 25.1. అభివాక్యం (Ablativ) రూపాల నిర్మాణం (⟪पञ्चमी⟫ = "ఐదవ విభక్తి ప్రత్యయం")

::: grammar-box
a అంత్యాలతో ముగియే పుల్లింగం/నపుంసక లింగాలకు మరియు సర్వనామాలు తప్ప, అన్ని విభక్తి వర్గాలలో ఏకవచనంలో అభివాక్యం (⟪पञ्चमी⟫) రూపాలు జనకం (⟪षष्ठी⟫) రూపాలతో ఒకేలా ఉంటాయి.

వ్యక్తిగత సర్వనామాలు తప్ప, అన్ని విభక్తులలో బహువచనంలో అభివాక్యం రూపాలు సమానార్థక విభక్తి (⟪चतुर्थी⟫) రూపాలతో ఒకేలా ఉంటాయి.
:::
ఇప్పుడు మీకు సంస్కృతంలో విభక్తుల (⟪विभक्ति⟫) క్రమం వెనుక ఉన్న కారణం అర్థమవుతుంది: ఒకే రూపాలు సాధ్యమైనంత వరకు పక్కపక్కనే లేదా ఒకదాని క్రింద మరొకటి ఉండేలా అవి అమర్చబడ్డాయి.

::: grammar-box
**-a అంత్యాలతో ముగియే పుల్లింగం/నపుంసక లింగాలకు అభివాక్య ఏకవచన రూపాలు**

## 25.2. అభివాక్యం (⟪पञ्चमी⟫) ఉపయోగం

"అభివాక్య అంటే ఏదైనా దాని నుండి వెళ్ళినప్పుడు స్థిరంగా ఉండేది."

పాణిని 2,3,28 + 1,4,24

అభివాక్యం ప్రధానంగా "ఎక్కడి నుండి?", "ఎందుకు?" అనే ప్రశ్నలకు సమాధానంగా వస్తుంది.

::: grammar-box
1\. కాబట్టి అభివాక్యం ప్రారంభ బిందువు, ఉద్భవ స్థానం మరియు పదార్థాన్ని సూచిస్తుంది.

ಆದ್ದರಿಂದ ಅಭಿಧಾನವು ಖರೀದಿಸುವ, ಕೇಳುವ, ಇಚ್ಛಿಸುವ ಮುಂತಾದವುಗಳಿಂದ ಯಾರು ಎಂಬ ವ್ಯಕ್ತಿಯನ್ನು ಸೂಚಿಸಬಹುದು.
:::
ಉದಾಹರಣೆಗಳು:

::: indent
⟪ग्रमादागच्छति⟫ = "ಅವನು ಗ್ರಾಮದಿಂದ ಬರುತ್ತಾನೆ"

⟪अश्वात्पतितः⟫ = "ಘೋಷದಿಂದ ಬಿದ್ದ"

⟪तेभ्यो लब्धम्⟫ = "ಅವರಿಂದ (ಹಿಂದೆ) ಪಡೆದ"
:::
ಉದಾಹರಣೆಗಳು:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "ಅವನು ಗುರುವಿನಿಂದ ಧರ್ಮದ ಬಗ್ಗೆ ಕೇಳುತ್ತಾನೆ"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "ಬ್ರಾಹ್ಮಣನು ಕ್ಷತ್ರಿಯನಿಂದ ಹಾಲಿನ ಗೋವನ್ನು ಇಚ್ಛಿಸುತ್ತಾನೆ"
:::
::: grammar-box
2\. ಅಭಿಧಾನವು "ತಡೆಯುವ", "ರಕ್ಷಿಸುವ", "ಪ್ರತಿರೋಧಿಸುವ", "ಭಯಪಡುವ" ಅರ್ಥಗಳನ್ನು ಹೊಂದಿರುವ ಕ್ರಿಯಾಪದಗಳಿಗೆ ಸಂಬಂಧಿಸಿದೆ:
:::
ಉದಾಹರಣೆ:

::: indent
⟪अरिभ्यो रक्षति⟫ = "ಅವನು ಶತ್ರುಗಳಿಂದ ರಕ್ಷಿಸುತ್ತಾನೆ"
:::
::: grammar-box
3\. ಅಭಿಧಾನವು ಕಾರಣ ಅಥವಾ ಕಾರಣವನ್ನು ಸೂಚಿಸುತ್ತದೆ:
:::
ಉದಾಹರಣೆಗಳು:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "ಅವನು ಕೋಪದಿಂದ ತನ್ನ ಮಗನನ್ನು ಹೊಡೆಯುತ್ತಾನೆ"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "ಅವನು ಕೆಟ್ಟದನ್ನು ಮಾಡಿದುದರಿಂದ, ಅವನು ನರಕಕ್ಕೆ ಹೋಗುತ್ತಾನೆ" («ಅವನು ಕೆಟ್ಟದನ್ನು ಮಾಡಿದ ವ್ಯಕ್ತಿಯಾದುದರಿಂದ)

⟪पापकरणान्नरकं गच्छति⟫ = "ಅವನು ಕೆಟ್ಟದನ್ನು ಮಾಡುತ್ತಾನೆ/ಮಾಡಿದುದರಿಂದ, ಅವನು ನರಕಕ್ಕೆ ಹೋಗುತ್ತಾನೆ"
:::
ಸ್ತ್ರೀಲಿಂಗವಲ್ಲದ ಪದಗಳು, ಕ್ರಿಯೆಯ ಕಾರಣವನ್ನು ಸೂಚಿಸಲು, ಉಪಕರಣಾಭಿಧಾನ (⟪तृतीया⟫) ಅಥವಾ ಅಭಿಧಾನ (⟪पञ्चमी⟫) ನಲ್ಲಿ ಇರಬಹುದು. ಸ್ತ್ರೀಲಿಂಗ ಪದಗಳು ಈ ಅರ್ಥದಲ್ಲಿ ಸಾಮಾನ್ಯವಾಗಿ ಉಪಕರಣಾಭಿಧಾನದಲ್ಲಿ ಇರುತ್ತವೆ, ಆದರೆ ಕೆಲವೊಮ್ಮೆ ಅಭಿಧಾನದಲ್ಲಿಯೂ ಇರಬಹುದು.

## 25.4. కారణాలను వ్యక్తపరచడానికి ఇతర మార్గాలు

::: grammar-box
**1\. సంబంధిత వాక్యాలు**

సంబంధిత వాక్యాలు ప్రధాన వాక్యంతో కారణ-పరంగా (కారణభూతమైన), అనువర్తనం-పరంగా (ఫలితంగా) లేదా ఉద్దేశ్య-పరంగా (లక్ష్యాన్ని సూచించే) సంబంధాన్ని వ్యక్తపరుస్తాయి.

కారణ సంయోజకంగా పనిచేసే సర్వనామ రూపాలు:

*   అభ్యధికార విభక్తిలో:
*   ⟪यतस्⟫ ... ఉపవాక్యం ... ⟪ततस्⟫ ... ప్రధాన వాక్యం ... = "ఎందుకంటే ..., అందువల్ల ..."
*   ⟪यस्मात्⟫ ... ఉపవాక్యం ... ⟪तस्मात्⟫ ... ప్రధాన వాక్యం ... = "ఎందుకంటే ..., అందువల్ల ..."
*   కరణ విభక్తిలో:
*   ⟪येन⟫ ... ఉపవాక్యం ... ⟪तेन⟫ ... ప్రధాన వాక్యం ... = "దీనివల్ల/ఎందుకంటే ..., దాని వల్ల / అందువల్ల ..."
:::

1.5.2. ⟪प्राणभृताम्⟫ : సామాన్య వచనం, పుంలింగం. ⟪प्राणभृत्⟫ m. "జీవులు" కి సంబంధించినది.

1.5.5. ⟪इतरम्⟫ సమాపిక. ఏకవచనం, పుంలింగం. ⟪इतर ३⟫ "ఇతర" కి సంబంధించినది.

1.5.7. ⟪कर्मा⟫ : నామవాచకం, ఏకవచనం, పుంలింగం. ⟪कर्मन्⟫ తటస్థలింగం "కార్యం, పని" కి సంబంధించినది. ⟪उपयुञ्जीत⟫ : ఆప్త 3. ఏకవచనం Ā upa-yuj 7 "స్వాధీనం చేసుకోవడం" కి సంబంధించినది: "అతను స్వాధీనం చేసుకోవాలి."

1.5.8. ⟪वक्तृप्रयोक्तृभ्यस्⟫ అభిధాన వచనం, సమాపిక. ⟪वक्त्र्प्रयोक्तृ⟫ (⟪इतरेतरद्वन्द्व⟫) "సిద్ధాంతవాదులు మరియు ఆచరణాత్మకులు" కి సంబంధించినది.

1.5.9. ⟪षोडश ३⟫ : "పదహారవది."

1.5.10. ⟪कर्म⟫ నామవాచకం, సమాపిక. ఏకవచనం. ⟪कर्मन्⟫ n. "కార్యం" కి సంబంధించినది.

1.5.16. ⟪धि⟫ సంధి రూపం. ⟪हि⟫ ; ⟪आत्मवत्ता⟫ f.: "స్వయం-ఆధిపత్యం."

1.6.1. ⟪कार्य ३⟫ "చేయవలసినది, చేయాల్సినది."
