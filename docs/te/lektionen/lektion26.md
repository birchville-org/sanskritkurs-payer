# పాఠం 26

## 26.1. పదంలోని -s- కి సంబంధించిన మూర్ఛా నియమం

::: grammar-box
**k, r, l** లేదా ఒక **స్వరం** — **a, ā** తప్ప — వెంటనే లేదా కేవలం ⟪अनुस्वार⟫ లేదా ⟪विसर्ग⟫ ద్వారా వేరు చేయబడి ముందు ఉండి, **ṛ, r** తప్ప మరొక ధ్వని అనుసరించినప్పుడు, **-s-** ని **-ṣ-** తో మార్చబడుతుంది.

ఈ సందర్భంలో, **⟪दुस्⟫-** అనేది సంయుక్త పదాలలో నిస్పందన లేని గుంజాలు మరియు ఊష్మలకు ముందు కూడా ఈ సందర్భాన్ని అనుసరిస్తుంది.
:::
*ఉదాహరణలు:*
::: indent
⟪तेषाम्⟫ (మూలం: *te-sām*)

కానీ: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. పదంలోని దంత ధ్వనులకు సంబంధించిన మూర్ఛా నియమం

::: grammar-box
పశ్చాత్తాలవీయ ధ్వనులకు (**-ṣ-** సహితం) తర్వాత దంత విస్ఫోటక ధ్వనులు సంబంధిత పశ్చాత్తాలవీయ ధ్వనులుగా మారుతాయి:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(ముందున్న **i** వల్ల **ṣ**, తర్వాత ఉన్న **ṣ** వల్ల **ṭh**)*
:::
## 26.3. తాలవీయ, గుంజాలు, ṣ, h + -s కి సంబంధించిన పదాంత సందర్భ నియమాలు

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

ఉదాహరణలు క్రింద చూడండి
:::
## 26.4. గ్రాస్‌మన్ ఊష్మ విసరణ నియమం

::: grammar-box
**రెండు ఊష్మల (ఊష్మ - స్వరం - ఊష్మ) తక్షణ అనుసరణ మొదటి ధ్వని యొక్క ఊష్మత కోల్పోవడానికి దారితీస్తుంది:**

ఉదాహరణ:

:::
::: indent
\*dhu(gh) » du(g)h
:::
**ధ్వని నియమాల వల్ల రెండవ ధ్వని తన ఊష్మతను కోల్పోయినప్పుడు, మొదటి ధ్వనిపై ఊష్మత తిరిగి కనిపిస్తుంది.**

ఉదాహరణలు: క్రింద చూడండి  ⟪दुह्⟫ మరియు  ⟪बुध्⟫ యొక్క భవిష్యత్ కాల రూపాలు

## 26.5. వర్గసంధి -m, -n ముందు ఉచ్చారణలకు

::: grammar-box
**ఉచ్చారణల ముందు -n మరియు -m లను -ṃ- తో ప్రతిక్షేపిస్తారు:**

ఉదాహరణ: s. క్రింద భవిష్యత్తు ⟪मन्⟫

## 26.6. సాధారణ భవిష్యత్తు వినియోగం (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**సాధారణ భవిష్యత్తు (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) ఈ క్రింది విధంగా సూచిస్తుంది:**

**భవిష్యత్తు**
**ఒక ఉద్దేశించిన లేదా కోరిన చర్య ("నేను వెళ్తాను", "నేను వెళ్లాలని కోరుకుంటున్నాను")**
**ఆశ ("ఇలా జరుగుతుంది" అని ఆశించడం)**
**ఆశ**
**భయం**
**సాధ్యత**
**మాటలాడే వారి అభిప్రాయం**
**ఆజ్ఞ**

> **భవిష్యత్తు కొన్నిసార్లు ఆశీర్వాదంతో పోటీపడుతుంది (తరువాత చూడండి).**
:::
ఉదా. ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = "ఒక వ్రతం చేయాలనుకునే వ్యక్తి దేవాలయానికి వెళ్తాడు."

## 26.7. సాధారణ భవిష్యత్తు నిర్మాణం (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**సాధారణ భవిష్యత్తు:**

:::
::: indent
> **భవిష్యత్తు మూలం + ప్రాథమిక అంత్యములు**
:::
::: grammar-box
> **భవిష్యత్తు మూలం:**

:::
::: indent
> **(సాధారణంగా) ఉన్నత స్థాయి మూలం + -sya**  
> **లేదా**  
> **(సాధారణంగా) ఉన్నత స్థాయి మూలం + -i- + -sya (= - iṣya)**
:::
> **ఏ మూలం ఏ భవిష్యత్తు నిర్మాణాన్ని కలిగి ఉంటుందో, దానిని మూల రూపాలతో నేర్చుకోవాలి!**  
> **సాధారణంగా మూల రూపం మరియు భవిష్యత్తు యొక్క సంధి వర్ణం అనంతర రూపంతో సరిపోలుతాయి.**  
> **కొన్ని మూలాలు భవిష్యత్తును సంధి వర్ణం -i- తో లేదా లేకుండా ఐచ్ఛికంగా నిర్మించగలవు.**  
> **భవిష్యత్తు యొక్క పరస్మైపద భాగశబ్దం భవిష్యత్తు మూలానికి -nt- ప్రత్యాగమనాన్ని జోడించడం ద్వారా నిర్మించబడుతుంది, స్త్రీలింగం ఐచ్ఛికంగా -ntī లేదా -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
ఉదాహరణలు:

| మూలధాతువు | భవిష్యత్ కాలం 3. వ్యక్తి ఏకవచనం పరస్మైపదం (ఆ) |
