# పాఠం 10

## 10.1. క్రియాపద నిర్మాణం (Passive Voice)

::: grammar-box

**రూపకల్పన:**
**(కర్త - kartṛ - కరణ విభక్తిలో (tṛtīyā)) - (పరోక్ష వస్తువు - karman - ప్రథమ విభక్తిలో) - క్రియాపద నిర్మాణం (Passive form)**

ఉదా. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "ఒక బ్రాహ్మణుడు దేవుని యజ్ఞంతో పూజిస్తాడు" (అక్షరార్థం: "ఒక దేవుని ఒక బ్రాహ్మణుడు యజ్ఞంతో పూజిస్తారు.")

ఈ వాక్యం **పూర్తిగా (!) అర్థంలో సమానంగా** ఉంటుంది ఈ వాక్యానికి:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫

:::

::: grammar-box

క్రియాపద నిర్మాణ వాక్యంలో, కర్త (**kartṛ**) **కరణ విభక్తిలో** (tṛtīyā f. "మూడవ విభక్తి"), పరోక్ష వస్తువు (**karman** n.) **ప్రథమ విభక్తిలో** (prathamā f.) ఉంటుంది.
కర్తను సూచించని క్రియాపద నిర్మాణ వాక్యాలు, సాధారణంగా అనిశ్చిత కర్తను సూచిస్తాయి ("వారు" లేదా "ఒకరు"):
ఉదా. **ijyate** = ⟪इज्यते⟫ "వారు యజ్ఞం చేస్తారు" (అక్షరార్థం: "యజ్ఞంతో పూజించబడుతుంది").

:::

::: grammar-box

**సంబంధిత క్రియాపద నిర్మాణ వాక్యంలో లక్ష్యం యొక్క ద్వితీయా విభక్తి (dvitīyā) ఉన్నప్పటికీ, దానిని క్రియాపద నిర్మాణ వాక్యంలో ప్రథమ విభక్తిలో (prathamā) ఉంచవచ్చు:**

క్రియాపద నిర్మాణ వాక్యం **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "రాము ఊరికి వెళ్తాడు." కు సమానమైన క్రియాపద నిర్మాణ వాక్యాలు:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
లేదా: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫

:::

::: grammar-box

**నిష్క్రియాపద క్రియలు (పరోక్ష వస్తువు లేనవి) తరచుగా క్రియాపద నిర్మాణ నిర్మాణాలను కలిగి ఉంటాయి, ముఖ్యంగా గౌరవప్రదమైన ఆహ్వానాలలో:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "వారు ప్రవేశించాలి = దయచేసి లోపలికి రండి = అंदरకు రండి!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "వారు కూర్చోాలి = దయచేసి కూర్చోండి = దయచేసి స్థానం పట్టండి"

:::

సంస్కృత నిష్క్రియా రూపాలు చాలా సాధారణంగా ఉంటాయి: నిష్క్రియా రూపం, ఉదాహరణకు అనేక ప్రేసెన్స్ స్టమ్‌ల కంటే సులభంగా నిర్మించబడుతుంది.

::: important

**సాధారణంగా సంస్కృత నిష్క్రియా వాక్యాలను జర్మన్‌లో నిష్క్రియా వాక్యంగా అనువదించకూడదు, ఎందుకంటే జర్మన్ నిష్క్రియా రూపం పూర్తిగా వేరైన శైలి కార్యాన్ని కలిగి ఉంటుంది.**

:::

### 10.2.1. కరణ విభక్తి (tṛtīyā = ⟪तृतीया⟫) వినియోగం గురించి

::: grammar-box

**కరణ విభక్తి (tṛtīyā) ప్రధానంగా ఈ క్రింది ప్రశ్నలకు సమాధానంగా ఉంటుంది:**
**ఏ ద్వారా?**
**ఎంతతో?**
**ఎవరితో?**

**ఇది ఈ క్రింది సందర్భాల్లో ఉంటుంది**
1. **క్రియా విశేషణ వాక్యాలలో: కర్త (kartṛ) కరణ విభక్తిలో**
2. **ఏదైనా పని జరిగే మార్గాన్ని లేదా సాధనాన్ని సూచించడానికి**
3. **ఒకరు ఎక్కడికి వెళ్ళారో సూచించే మార్గాన్ని సూచించడానికి**
4. **సంబంధం, ఐక్యత, సహవాసాన్ని వ్యక్తపరచడానికి**
5. **అధిక పదాలతో "సహితంగా, తో" అనే అర్థంలో; ఉదా: saha = ⟪सह⟫ = "తో"** :brఉదా:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "బ్రాహ్మణునితో కలిసి"

:::

ఇతర ఉపయోగాలు యొక్క కర్త్ర్ (tṛtīyā) తరువాత వస్తాయి.


## 10.3. -n- కి సంబంధించిన సెరెబ్రలైజేషన్ నియమం (ఒక పద సంధి)

::: grammar-box

ఒక **-n-** తర్వాత స్వరం లేదా **n, m, y, v** వస్తే, పదంలో **-n-** కి ముందు **ṛ, ṝ, r, ṣ** ఉంటే లేదా ఈ ధ్వనులు మరియు తర్వాతి **-n-** మధ్య స్వరాలు, గుత్తూరలు, లాబియల్స్, **y, v, h** లేదా అనుస్వారం తప్ప మరే ధ్వని ఉండకపోతే, అది **-ṇ-** గా మారుతుంది.

:::

**కాబట్టి:**

::: grammar-box

| | కర్త్ర్ ఏకవచనం |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |

:::

**ఈ విధంగా -ṇ- ని ఈ క్రింది వాటిలో వివరించవచ్చు:**

::: indent

**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫

:::

### 10.4.1. నిష్క్రమణ ఏర్పాటుకు ప్రత్యేక నియమాలు

1. **-i** లేదా **-u** తో ముగిసే మూలలు నిష్క్రమణ ప్రత్యయం **-ya-** కి ముందు తమ స్వరాన్ని పొడవుగా చేస్తాయి:
* **ji** 1 వ్యక్తి: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 వ్యక్తి: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 ఉత్తమ: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **అనునాసికలు, y, r, v తప్ప మూల్యాల మధ్య -a- ఉన్న మూలలు** ఎత్తు స్థాయిలోనే ఉంటాయి:
* **labh** 1 ఆత్మ: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **కొన్ని మూలలు తమ నిష్క్రమణ రూపాన్ని ఎత్తు స్థాయిలో (లేదా ప్రత్యయ మూలకాల యొక్క అభ్లావ స్థాయిలో) ఏర్పరుస్తాయి:**
* **āp** 5 వ్యక్తి: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫

4. **ya, va, ra తో మొదలయ్యే క్రియల యొక్క అల్ప స్థాయి, లేదా ఈ ధ్వనులు మరేదైనా అనునాసిక తర్వాత ఉన్నప్పుడు (సంప్రసారణ = ⟪सम्प्रसारण⟫):**

| మూలం:br⟪धातु⟫ | అల్ప స్థాయి:br⟪सम्प्रसारण⟫ | నిష్క్రమణ:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 ఉత్తమ:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 వ్యక్తి:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |

5. ఒక ఏకైక వ్యంజనాంతరంలో తర్వాత **ఆత్మనేపదీ ప్రత్యయం -ya-** ముందు ఒకే వర్ణాంత **ṛ** అనేది **-ri-** తో మారుతుంది:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* కానీ: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **-an** తో ముగిసే కొన్ని మూలపదాలకు ప్రత్యామ్నాయంగా రెండు ఆత్మనేపదీ నిర్మాణాలు ఉంటాయి:
* ఒకటి **-an-ya**
* మరొకటి **-ā-ya-** (పొడవైన **ā** అనేది ఒక ఊహాత్మక పొడవైన నాసలకు ప్రతినిధి)

## 10.6. అభ్యాసం

**A) క్రియారూపాలకు నిష్క్రియాత్మక రూపాన్ని (Passiv) ఏర్పరచండి (క్రియారూపం యొక్క అనువాదంతో):**

1. **sṛjati** (⟪सृजति⟫)
2. **yudhyate** (⟪युध्यते⟫)
3. **bhavanti** (⟪भवन्ति⟫)
4. **yajati** (⟪यजति⟫)
5. **nṛtyati** (⟪नृत्यति⟫)
6. **nayanti** (⟪नयन्ति⟫)
7. **smarati** (⟪स्मरति⟫)
8. **śṛṇvanti** (⟪शृण्वन्ति⟫)
9. **paśyati** (⟪पश्यति⟫) (నిష్క్రియాత్మక రూపం **dṛś** నుండి ఏర్పడుతుంది!)
10. **jayanti** (⟪जयन्ति⟫)
11. **kurvate** (⟪कुर्वते⟫)
12. **āpnuvanti** (⟪आप्नुवन्ति⟫)
13. **viśati** (⟪विशति⟫)

17. **manyante** (⟪मन्यन्ते⟫)
18. **labhante** (⟪लभन्ते⟫)
19. **rakṣanti** (⟪रक्षन्ति⟫)
20. **vadanti** (⟪वदन्ति⟫)
21. **pṛcchanti** (⟪पृच्छन्ति⟫)
22. **tanvanti** (⟪तन्वन्ति⟫) (2 రూపాలు!)

**B) పాఠంలో ఇప్పటివరకు నేర్చుకున్న అన్ని నామాలకు కర్త్ర్ విభక్తి ఏకవచనం మరియు బహువచనం రూపాలను రూపొందించండి.**

**C) కింది వాక్యాలను కర్మణి ప్రయోగంలోకి మార్చి, వాటిని అనువదించండి:**
1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो देवीं यजति⟫)
2. **sādhuḥ svargaṃ gacchati.** (⟪साधुः स्वर्गं गच्छति⟫)
3. **śūdraṃ jayati.** (⟪शूद्रं जयति⟫)
4. **guruḥ phalāni khādati.** (⟪गुरुः फलानि खादति⟫)
5. **gurūñchṛṇoti.** (⟪गुरूञ्छृणोति⟫)
6. **ko 'gniṃ paśyati.** (⟪को ऽग्निं पश्यति⟫)
7. **ayaṃ kavirmantraṃ smarati.** (⟪अयं कविर्मन्त्रं स्मरति⟫)
8. **iyaṃ devī kṣatriyā rakṣati.** (⟪इयं देवी क्षत्रिया रक्षति⟫)
9. **kṣatriyā viṣṇuṃ yajante.** (⟪क्षत्रिया विष्णुं यजन्ते⟫) (2 అవకాశాలు)
10. **brāhmaṇo 'gniṃ karoti.** (⟪ब्राह्मणो ऽग्निं करोति⟫)
11. **vaiśyā imaṃ grāmaṃ gacchanti.** (⟪वैश्या इमं ग्रामं गच्छन्ति⟫) (2 అవకాశాలు)
12. **ete gurūṃstu śṛṇvanti.** (⟪एते गुरूंस्तु शृण्वन्ति⟫)
13. **sādhuḥ svargamāpnoti.** (⟪साधुः स्वर्गमाप्नोति⟫)
14. **brāhmāṇāḥ somaṃ sunvanti.** (⟪ब्राह्मणाः सोमं सुन्वन्ति⟫)
15. **paśūllabhate.** (⟪पशूल्लभते⟫)
16. **ke yodhāḥ kṣatriyaiḥ saha yudhyante.** (⟪के योधाः क्षत्रियैः सह युध्यन्ते⟫)

**D) సంస్కృతంలోకి అనువదించండి:**
1. ఒక బ్రాహ్మణుడు ఒక వైశ్యుతో కలిసి గ్రామానికి వెళ్తాడు.
2. అతను ఒక యజ్ఞంతో విష్ణువును పూజిస్తాడు. (యజ్ఞం **yajña** అని వ్యక్తీకరించండి!)
3. వేదం శ్రుతి అని పిలువబడుతుంది. (**vad**)
4. నేత గట్టిని (వెబ్ కెటెన్) అమర్చబడుతుంది. (2 సాధ్యమైన మార్గాలు)

5. గురువులు ప్రశ్నించబడతారు. (కర్మణి ప్రయోగం)

7. కవి ఒక దేవతను చూస్తాడు. (కర్మణి ప్రయోగం)

10. దానశీలత ద్వారా ఒక బౌద్ధ అనుచరుడు ఒక స్వర్గాన్ని పొందుతాడు.
