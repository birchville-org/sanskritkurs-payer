# పాఠం 57

## 57.1. ఆయరిస్ట్ 4: s-ఆయరిస్ట్

::: grammar-box
**s-ఆయరిస్ట్ అనేది ⟪अनिट्⟫ మూలకాలకు ఏర్పాటు చేయబడుతుంది, అవి వేరొక ఆయరిస్ట్ రూపాన్ని మాత్రమే కలిగి ఉండకపోతే. ఐచ్ఛిక ⟪अनिट्⟫ మూలకాలు సాధారణంగా ఈ s-ఆయరిస్ట్ లేదా iṣ-ఆయరిస్ట్‌ను ఏర్పరచవచ్చు. అలాగే, ఆయరిస్ట్ యొక్క 1.,2. లేదా 6. రూపం తర్వాత ⟪परस्मैपद⟫ను ఏర్పరచే ⟪अनिट्⟫ మూలకాలు కూడా s-ఆయరిస్ట్ ప్రకారం ⟪आत्मनेपद⟫ను ఏర్పరుస్తాయి.**

**రూపకల్పన: ఆగ్మెంట్ + మూలం + s + అథమాటిక్ సెకండరీ ప్రత్యయం**
:::
ప్రత్యయాల పట్టిక, మూల రూపకల్పన సర్ఫిక్స్‌తో

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟫** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟫** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**సాధారణ ధ్వని నియమం వర్తిస్తుంది: రెండు విస్పోటక ధ్వనుల మధ్య ఉన్న ఒక సీజింగ్ ధ్వని (sibilant) తొలగించబడుతుంది (ఉదా: ⟪उद्⟫ + ⟪स्थित⟫ » ⟪उत्थित⟫), అంటే, ప్రత్యయాల ముందు ఉన్న -t- లేదా -th- తో ప్రారంభమయ్యే ప్రత్యయానికి ముందు ఉండే మూల రూపకల్పన సర్ఫిక్స్ -s- తొలగించబడుతుంది (నాసల్‌లు లేదా r- తర్వాత మాత్రమే కాదు).**

ఉదాహరణలు:

:::
::: indent
3.వ్య.ఆ a-kṣip + s + ta » ⟪अ⟫:sig[⟪क्षिप्त⟫]
2.వ్య.ఆ a-kṣip + s + thās » ⟪अ⟫:sig[⟪क्षिप्था⟫]⟪स्⟫
:::
ఈ రూపాలు మూల ఆయరిస్ట్‌కు కూడా సంబంధించినవిగా ఉండవచ్చు మరియు వాటిలో కొన్ని మూల ఆయరిస్ట్‌కు సంబంధించినవే అని భావిస్తున్నారు.
భారతీయ వ్యాకరణకారులు ⟪अकृत⟫ (3.వ్య.ఆ) వంటి రూపాలను కూడా s-ఆయరిస్ట్‌కు సంబంధించినవని వర్గీకరించారు, అయితే అవి స్పష్టంగా మూల ఆయరిస్ట్‌కు సంబంధించినవే. ఈ ఉద్దేశ్యంతో, భారతీయ వ్యాకరణకారులు s-ఆయరిస్ట్‌కు సంబంధించి ఈ క్రింది అడ్-హాక్ ధ్వని నియమాన్ని కనుగొన్నారు:

::: indent
"బ్రహ్మవర్ణం తరువాత, -st- లేదా -sth- తో ప్రారంభమయ్యే 'అంత్యప్రత్యాగాలు' తమ -s- న కోల్పోతాయి."
:::
ఇతర సందర్భాల్లో, అంత్యవ్యాజనం s- తో కలసినప్పుడు వచ్చే ధ్వని నియమాలను పాటించాలి.

dhvam కు వర్తించే నియమం:

::: grammar-box
**-dhvam లోని -dh- అనేది అన్ని అ/ఆ కాని స్వరాల తర్వాత మరియు -r తర్వాత -ḍh- గా మారుతుంది.**

:::
::: indent
ఉదా: :sig[⟪चि⟫] 5U: 2.pl.Ā :sig[⟪अचेढ्वम्⟫]
:::
::: grammar-box
**మూలరూపం:**

*   **⟪परस्मैपद⟫ : దీర్ఘస్థితి**
*   **⟪आत्मनेपद⟫ :**
*   **అంత్య i/ī/u/ū ఉన్న మూలాలు: ఊర్ధ్వస్థితి**
*   **అంత్య -ṝ ను -īr లేదా -ūr తో ప్రతిక్షేపించాలి**
*   **ఆప్లవ్-సాధ్య మూలాలు ā/e/o తో: అధస్థితి**
*   **ఇతర మూల స్వరాలు: మార్పు లేదు (అంటే సాధారణంగా అధస్థితిలో)**
:::
