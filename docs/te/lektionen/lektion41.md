## 41.2. మరిన్ని ⟪कृत्⟫-రూపాలు -a తో

### 41.2.1. ప్రస్తుత కాల పురుషపదం (⟪लडादेशः⟫) Ā, ప్రస్తుత కాల పురుషపదం (⟪लडादेशः⟫) నిష్క్రియ, భవిష్యత్ కాల పురుషపదం (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. విషయక ప్రస్తుత కాల మూలాలు, నిష్క్రియ మరియు భవిష్యత్

::: grammar-box
**రూపకల్పన:**

ప్రస్తుత కాల మూలం / నిష్క్రియ మూలం / భవిష్యత్ కాల మూలం + -māna (స్త్రీలింగం mānā)
:::
ఉదాహరణలు:

⟪यज्⟫ 1U, ప్ర.కా.పు. Ā ⟪यजमान⟫ 3 "తన స్వంత ప్రయోజనం కోసం యాగంతో పూజించబడే వ్యక్తి = యాగాధిపతి"

⟪मन्⟫ 4Ā, ప్ర.కా.పు. Ā ⟪मन्यमान⟫ 3 "చింతించే వ్యక్తి"

⟪कृ⟫ 8U, ప్ర.కా.ని. ⟪क्रियमाण⟫ 3 "చేయబడే ఏదైనా"

⟪दा⟫ 3U, భ.కా.పు. Ā ⟪दास्यमान⟫ 3 "తన స్వంత ప్రయోజనం కోసం ఇచ్చే వ్యక్తి"

#### 41.2.1.2. అవిషయక ప్రస్తుత కాల వర్గాలు

::: grammar-box
**రూపకల్పన:**

బలహీన ప్రస్తుత కాల మూలం (3.పు. Ā యొక్క -ate అంత్యప్రత్యయం ముందు ఉన్న రూపంలో) + -āna (స్త్రీలింగం -ānā)
:::
ఉదాహరణలు:

::: grammar-box
| మూలం / వర్గం | ప్రస్తుత కాల పురుషపదం Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. నిష్క్రియావశ్యకత్వానికి సంబంధించిన "భావపదం" (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**నిష్క్రియావశ్యకత్వాన్ని వ్యక్తపరచడానికి ("ఏమి చేయబడాలి/కావాలి"), మూలపదాలు మరియు ఉత్పన్న క్రియాపద స్థానాల నుండి ఈ క్రింది ప్రత్యయాలతో ఎంపిక చేసి విశేషణాలను రూపొందించవచ్చు:**

* **-⟪तव्य⟫** (స్త్రీలింగం - **⟪तव्या⟫**)
* **-⟪अनीय⟫** (స్త్రీలింగం - **⟪अनीया⟫**)
* **-⟪य⟫** (స్త్రీలింగం - **⟪या⟫**)
* **-⟪त्य⟫** (స్త్రీలింగం - **⟪त्या⟫**) (**-⟪य⟫**/**-⟪या⟫** స్థానంలో)
:::
#### 41.2.2.1. ప్రత్యయం -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**ప్రత్యయం -⟪तव्य⟫ / -⟪तव्या⟫ ను మూలపదాలు మరియు ఉత్పన్న క్రియాపద స్థానాలకు (ఉదా: హేతువచకం) అనంతర ప్రత్యయం -⟪तुम्⟫ (చూ. [పాఠం 23](lektion23.md)) తో ఒకే విధంగా జతపరుస్తారు, అంటే**

* **ఉన్నత స్థాయి మూలపదం + ⟪तव्य⟫**

లేదా

* **ఉన్నత స్థాయి మూలపదం + -i- + ⟪तव्य⟫**

**హేతువచకంలో:**

* **-ay** తో ముగిసే హేతువచక స్థానం + -i- + ⟪तव्य⟫
:::
ఉదాహరణలు:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "జయించబడాలసిన వ్యక్తి; జయించడానికి అర్హుడు" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "ఉండాలసిన స్థలం" |
| ⟪बुध्⟫ హేతు. | ⟪बोधयितव्य⟫ | "ఎప్పటికైనా మేల్కొள்ளబడాలసిన వ్యక్తి; మేల్కొలిపడానికి అర్హుడు" |

:::
#### 41.2.2.2. ప్రత్యయం -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**రూపకల్పన:**

ఉన్నత స్థాయి మూలపదం + -⟪अनीय⟫ / -⟪अनीया⟫

**హేతువచకం మరియు 10. వర్గ ప్రస్తుత కాలం:**

హేతువచక స్థానంలో కనిపించే మూలపదం, -aya- తో కూడినది కాకుండా + -⟪अनीय⟫ / -⟪अनीया⟫
:::
ఉదాహరణలు:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "ఇవ్వబడాలసినది; ఇవ్వడానికి అర్హుడు" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "జయించబడాలసిన వ్యక్తి" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "చేయబడాలసినది" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "చూడబడాలసినది; చూడదగినది" |
| ⟪बुध्⟫ హేతు. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "మేల్కొలిపడానికి అర్హుడు" |
| ⟪दा⟫ హేతు. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "ఇప్పించబడాలసినది" |

:::
#### 41.2.2.3. ప్రత్యయం -⟪य⟫ / -⟪या⟫

::: grammar-box
**రూపకల్పన:**

మూలధాతువు (ఆందోళన, ఉన్నత లేదా విస్తృత స్థాయిలో) + -⟪य⟫

కచ్చితమైన నియమాలు కోల్హోర్న్, సంస్కృత భాష వ్యాకరణం, పేజీ 195 - 197లో చూడండి!
:::
అంత్య స్వరాల చికిత్స:

::: grammar-box
**1. -ā తో ముగిసే ధాతువులు ఈ క్రియావిశేషణాన్ని -eya తో రూపొందిస్తాయి**
:::
ఉదాహరణలు:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "తెలుసుకోవలసినది; గుర్తించబడాలి" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "ఇవ్వబడాలి" |

:::
::: grammar-box
**2. -i /-ī / -u / -ū /-ṛ తో ముగిసే ధాతువులు సాధారణంగా ఉన్నత లేదా విస్తృత స్థాయిని కలిగి ఉంటాయి, అవి -i / -u /-ṛ తో ముగిసే ధాతువులకు చెందినవి కాకపోతే, అవి -⟪त्य⟫ (స్త్రీలింగం -⟪त्या⟫) ప్రత్యయంతో క్రియావిశేషణాన్ని రూపొందిస్తాయి (ఈ ధాతువుల జాబితా కోల్హోర్న్, వ్యాకరణం §537లో ఉంది).**
:::

::: no-header

| | | |
| :--- | :--- | :--- |

:::

**2a. -i/-ī తో ముగిసే ధాతువులు ఉన్నత స్థాయిని కలిగి ఉంటాయి**
:::

| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "తీసుకువెళ్ళబడవలసినది" |

#### 41.2.2.4. ప్రత్యయం -⟪त्य⟫ / ⟪त्या⟫ (-⟪य⟫ / -⟪या⟫ కు బదులుగా)

::: grammar-box
Liste der Wurzeln auf -i / -u /-ṛ, die ein Gerundiv statt mit -⟪य⟫ / -⟪या⟫ mit dem Suffix -⟪त्य⟫ (fem. -⟪त्या⟫) bilden, bei Kielhorn, Grammatik §537.

:::

### 41.2.3. వాక్య నిర్మాణపరంగా "గెరుండివం" (నిష్కృత్యార్థక క్రియావిశేషణం) గురించి (⟪कृत्य⟫)

::: grammar-box
గెరుండివం విశేషణంగా ఉపయోగించబడుతుంది:

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = "చూడవలసిన నగరం; చూడదగిన నగరం"
:::
గెరుండివం బలవంతం లేదా ఆజ్ఞను వ్యక్తపరిచే నిష్కృత్య నిర్మాణాలతో కూడిన వాక్యాలలో ప్రధానపదంగా (ప్రెడికేట్ నోమిన్) కూడా ఉపయోగించబడుతుంది (⟪न⟫ తో నిషేధం, అసాధ్యత):

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = "ద్వినీతులు వారణాసిని చూడవలెను"
:::

### 41.2.4. గెరుండివం ప్రత్యయాల ఉపయోగంలో తేడాలు

::: grammar-box
ఈ ప్రత్యయాల ఉపయోగం గణనీయంగా ఒకదానితో ఒకటి కలుస్తుంది

* **-⟪तव्य⟫ (స్త్రీలింగం -⟪तव्या⟫):** ఎల్లప్పుడూ అవసరాన్ని వ్యక్తపరుస్తుంది మరియు ప్రధానపదంగా (ప్రెడికేటివ్‌గా) ఉపయోగించబడుతుంది (విశేషణంగా తక్కువ). ఈ ప్రత్యయంతో ఏర్పడిన పదాలు నామ సంయుక్త పదాలలో (నోమినల్ కంపోజిట్స్) ఉపయోగించకూడదు.
* **-⟪अनीय⟫ (స్త్రీలింగం -⟪अनीया⟫) మరియు -⟪य⟫ (స్త్రీలింగం -⟪या⟫) / -⟪त्य⟫ (స్త్రీలింగం -⟪त्या⟫) (-⟪य⟫/-⟪या⟫ స్థానంలో):** ఇతర అర్థాలను కలిగి ఉండవచ్చు (ముఖ్యంగా -⟪य⟫) జర్మన్ "-వర్త్" (ఉదా: "చూడదగిన") లేదా కేవలం సాధ్యత "-బార్" (⟪दृश्य⟫ "కనిపించదగిన") అనే అర్థంలో. ఈ ప్రత్యయాలతో ఏర్పడిన పదాలను ⟪अ⟫-/-⟪अन्⟫ తో ఖండించవచ్చు (కానీ -⟪तव्य⟫ తో ఏర్పడిన పదాలను కాదు) మరియు వాటి వెనుక భాగంగా ఉండే ⟪तत्पुरुष⟫ లు ఉన్నాయి.
:::

## 41.4. అభ్యాసం

A) పాఠము యొక్క ప్రారంభంలో ఉన్న రెండు సూక్తులను అనువదించండి.

B) అనువదించండి:

⟪बुद्धम् शरणं गच्छामि धर्मं शरणं गच्छामि सङ्घं शरणं गच्छामीति बुद्धगतैर्वक्तव्यम् ॥१॥ काशीं पत्स्ये गङ्गां द्रक्ष्यामि तत्र च मरिष्यामीति मन्यमानो मान्यो वृद्धनरः पुत्रांश्च पुत्रपुत्रांश्च धनं च तत्याज काशीं च प्राव्रजत् । एवं च रोध्यं दुःखं तरिष्यतीति मन्ये ॥२॥⟫
