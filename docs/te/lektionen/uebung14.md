# అభ్యాసం 14

క్రింది సామెతలను అనువదించండి మరియు వాటిని మనోరథంగా నేర్చుకోండి:

⟪निचो वदति न कुरुते वदति न साधुः करोत्येव ॥१॥⟫  
తక్కువ స్థాయి వ్యక్తి మాట్లాడడు మరియు పనిచేయడు, మంచి వ్యక్తి మాట్లాడడు, కానీ పనిచేస్తాడు.

⟪शीलं नरस्य भूषणम् ॥२॥⟫  
సదాచారం మనిషి అలంకారం.

⟪सत्येन जनानां सुखं भवति ॥३॥⟫  
> సత్యం ద్వారా మనుషులకు శుభం కలుగుతుంది.

⟪पापा नराः स्वर्गं न लभन्ते ॥४॥⟫  
చెడు మనుషులు స్వర్గానికి వెళ్లరు.

⟪सत्यं लोकस्य दीपः ॥५॥⟫  
సత్యం ప్రపంచానికి వెలుగు.

A) క్రింది పదాలకు ఏకవచన మరియు బహువచన యొక్క జన్యు విభక్తిని (Genitive) ఏర్పరచండి. పదాల యొక్క అర్థం మరియు లింగాన్ని (Gender) సూచించండి:

⟪१⟫. ⟪अनृत⟫ : n. అసత్యం — ⟪अनृतस्य अनृतानाम् २⟫. ⟪ऋषि⟫ : m. వేద ఋషి — ⟪ऋषेः ऋषीणाम् ३⟫. ⟪पाद⟫ : m. పాదం — ⟪पादस्य पादानाम् ४⟫. ⟪बुद्धि⟫ : f. అవగాహన — ⟪बुद्धेः⟫ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम् ५⟫. ⟪गुरु⟫ : m. గురువు — ⟪गुरोः गुरूणाम् ६⟫. ⟪स्वर्ग⟫ : m. స్వర్గం — ⟪स्वर्गस्य स्वर्गाणाम् ७⟫. ⟪नगर⟫ : n. నగరం — ⟪नगरस्य नगराणाम् ८⟫. ⟪धेनु⟫ : f. గావు — ⟪धेनोः⟫ (⟪धेन्वाः⟫) ⟪धेनूनाम् ९⟫. ⟪द्विज⟫ : m. ద్విజుడు — ⟪द्विजस्य द्विजानाम् १०⟫. ⟪मुक्ता⟫ : f. విముక్త మహిళ — ⟪मुक्तायाः मुक्तानाम् ११⟫. ⟪विद्या⟫ : f. జ్ఞానం, విద్య — ⟪विद्यायाः विद्यानाम् १२⟫. ⟪वर्ण⟫ : m. వర్ణం — ⟪वर्णस्य वर्णानाम् १३⟫. ⟪द्विजाति⟫ : 3 ద్విజులు — ⟪द्विजातेः⟫ (⟪द्विजात्याः⟫) ⟪द्विजातीनाम् १४⟫. ⟪रूप⟫ : n. రూపం — ⟪रूपस्य रूपाणाम् १५⟫. ⟪प्रतिग्रह⟫ : m. స్వీకరణ — ⟪प्रतिग्रहस्य प्रतिग्रहाणाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 ertragen — ⟪सोढस्य⟫ ⟪सोढायाः⟫ ⟪सोढानाम्⟫

⟪१७⟫. ⟪नायिका⟫ : f. Geliebte — ⟪नायिकायाः⟫ ⟪नयिकानाम्⟫

⟪१८⟫. ⟪साध्वी⟫ : f. Heilige — ⟪साध्व्याः⟫ ⟪साध्वीनाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 తట్టుకోవడం — ⟪सोढस्य सोढायाः सोढानाम् १७⟫. ⟪नायिका⟫ : స్త్రీ. ప్రేమికురాలు — ⟪नायिकायाः नयिकानाम् १८⟫. ⟪साध्वी⟫ : స్త్రీ. పవిత్రురాలు — ⟪साध्व्याः साध्वीनाम् १९⟫. ⟪अग्नि⟫ : పుంలింగం. అగ్ని — ⟪अग्नेः अग्नीनाम् २०⟫. ⟪वैश्या⟫ : స్త్రీ. వైశ్యస్త్రీ — ⟪वैश्यायाः वैश्यानाम् २१⟫. ⟪लोक⟫ : పుంలింగం. ప్రపంచం, జనులు — ⟪लोकस्य लोकानाम् २२⟫. ⟪उक्ति⟫ : స్త్రీ. ఉక్తి — ⟪उक्तेः⟫ (⟪उक्त्याः⟫) ⟪उक्तीनाम् २३⟫. ⟪शत्रु⟫ : పుంలింగం. శత్రువు — ⟪शत्रोः शत्रूणाम् २४⟫. ⟪सुखवन्त्⟫ : 3 సంతోషకరమైనది — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : స్త్రీ. ఒకటి లేదా అంతకంటే ఎక్కువ కుమారులు ఉన్న స్త్రీ — ⟪पुत्रवत्याः पुत्रवतीनाम् २६⟫. ⟪जल⟫ : నపుంసకలింగం. నీరు — ⟪जलस्य जलानाम् २७⟫. ⟪मार्ग⟫ : పుంలింగం. మార్గం — ⟪मर्गस्य मर्गाणाम् २८⟫. ⟪मोक्ष⟫ : పుంలింగం. విముక్తి, మోక్షం — ⟪मोक्षस्य मोक्षाणाम् २९⟫. ⟪शूद्रा⟫ : స్త్రీ. శూద్రస్త్రీ — ⟪शूद्रायाः शूद्राणाम् ३०⟫. ⟪अन्न⟫ : నపుంసకలింగం. ఆహారం, భోజనం — ⟪अन्नस्य अन्नानाम् ३१⟫. ⟪साधु⟫ : పుంలింగం. పవిత్రుడు — ⟪साधोः साधनाम् ३२⟫. ⟪नीति⟫ : స్త్రీ. నాయకత్వం — ⟪नीत्याः नीतीनाम् ३३⟫. ⟪योध⟫ : పుంలింగం. యోధుడు, సైనికుడు — ⟪योधस्य योधानाम् ३४⟫. ⟪सत्यवन्त्⟫ : 3 నిజమైనది — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : పుంలింగం. లాభం — ⟪लाभस्य लाभानाम् ३६⟫. ⟪मोह⟫ : పుంలింగం. గందరగోళం, మోహం — ⟪मोहस्य मोहानाम् ३७⟫. ⟪गति⟫ : స్త్రీ. నడక, లక్ష్యం — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम् ३८⟫. ⟪प्रश्न⟫ : పుంలింగం. ప్రశ్న — ⟪प्रश्नस्य प्रश्नानाम् ३९⟫. ⟪सृष्टि⟫ : స్త్రీ. సృష్టి — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम् ४०⟫. ⟪नेत्र⟫ : నపుంసకలింగం. కన్ను — ⟪नेत्रस्य नेत्राणाम् ४१⟫. ⟪गुरुता⟫ : స్త్రీ. ఆధిపత్యం — ⟪गुरुतायाः गुरुतानाम्⟫

⟪४६⟫. ⟪युद्ध⟫ : 3 యుద్ధం చేయబడింది — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम् ४७⟫. ⟪दर्शन⟫ : n. చూపు, ప్రత్యక్షం — ⟪दर्शनस्य दर्शनानाम् ४८⟫. ⟪धातु⟫ : m. మూలకం, క్రియామూలం — ⟪धातोः धातूनाम् ४९⟫. ⟪गूढा⟫ : f. ఒక దాగినది — ⟪गूढायाः गूढानाम् ५०⟫. ⟪ईष्टा⟫ (2 అర్థాలు): f. ఒక కోరబడినది, ఒక బలి ఇవ్వబడినది — ⟪इष्टायाः इष्टानाम् ५१⟫. ⟪उदित⟫ : 3 చెప్పబడింది — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम् ५२⟫. ⟪इदम्⟫ : 3 ఈ — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 ఏమి — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) అనువదించండి:

⟪१⟫. ⟪ब्राह्मणस्य पुत्रो ब्राह्मण्या ग्रामं गतः ।⟫ (2 సాధ్యతలు)
బ్రాహ్మణుని కుమారుడు బ్రాహ్మణీ యొక్క గ్రామానికి వెళ్ళాడు. బ్రాహ్మణుని కుమారుడు బ్రాహ్మణీతో గ్రామానికి వెళ్ళాడు.

⟪२⟫. ⟪यज्ञस्याग्निनान्नं दग्धम् ।⟫
యాగ అగ్ని ఆహారాన్ని కాలబెట్టింది.

⟪३⟫. ⟪बुद्धः स्तयस्य बुद्ध्या मुक्तः ।⟫
బుద్ధ సత్యం యొక్క అవగాహన ద్వారా విముక్తి పొందబడ్డాడు.

⟪४⟫. ⟪अधर्मो ऽनृतस्य वदनमित्यृषयो वदन्ति ।⟫
వేద పండితులు అబద్ధం మాట్లాడటం తప్పు అని చెపుతారు.

⟪५⟫. ⟪नरा देवानां यज्ञैर्न मुच्यन्ते ।⟫
మనుషులు దేవతలకు బలి ఇవ్వడం ద్వారా విముక్తి పొందరు.

⟪६⟫. ⟪बलवन्तः क्षत्रियाः शत्रूणां धनवन्ति नगराणि जयन्ति ।⟫
శక్తివంతులైన క్షత్రియులు శత్రువుల యొక్క సమృద్ధిగా ఉన్న నగరాలను జయిస్తారు.

⟪७⟫. ⟪कवेरुक्तिं शृण्वन्ति ।⟫
మీరు కవి వాక్యాన్ని వింటారు.

⟪८⟫. ⟪कविर्देव्याः कृतं वद⟫తి ⟪।⟫
కవి దేవత యొక్క పనిని వివరిస్తారు.

⟪९⟫. ⟪द्विजाः पशोर्लाभमिच्छन्ति ।⟫
రెండుసార్లు జన్మించినవారు పశువులను పొందాలని కోరుకుంటారు.

⟪१०⟫. ⟪रामः पुण्यवतो गुरोर्मन्त्रस्य स्मरति ।⟫
రామ ధర్మాత్ముడైన గురువు మంత్రాన్ని స్మరిస్తారు.

⟪११⟫. ⟪अयं बालः कस्याः पुत्रः ।⟫
ఈ బాలుడు ఎవరి కుమారుడు?

⟪१२⟫. ⟪केषामिमानि गृहाणि ।⟫
ఈ ఇళ్లు ఎవరివి?

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम् ।⟫
ఈ వేద ముని ఎవరి ఆహారాన్ని బలి ఇచ్చారు?
