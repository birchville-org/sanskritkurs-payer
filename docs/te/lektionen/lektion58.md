## 58.2. విశేషణాత్మక ప్రస్తుత కాల వర్గాల ద్వివచనం: లక్షణ ప్రస్తుత కాలం (⟪लट्⟫)

## 58.6. ఆర్‌యస్ట్ 5: iṣ-ఆర్‌యస్ట్

::: grammar-box
**iṣ-ఆర్‌యస్ట్ అన్ని seṛ మూలాల నుండి ఏర్పడుతుంది, వాటికి స్పష్టంగా మరొక ఆర్‌యస్ట్ రూపం మాత్రమే బోధించబడలేదు.**

**రూపకల్పన:**

**ఆగ్మెంట్ + మూలం + i + s + అథమాటిక్ సెకండరీ ప్రత్యయం**

**!!!** 2. sg.P మరియు 3. sg.P **-**īs లేదా -īt నుండి వస్తాయి **!!!** (ఇది ⟪अब्रवीत्⟫ రకపు మూలాల ఇంపెర్ఫెక్ట్ నుండి బదిలీ వల్ల ఏర్పడింది; కాబట్టి ఇవి నిజానికి మూల ఆర్‌యస్ట్ రూపాలు).
:::
కాబట్టి స్టామ్ రూపకల్పన సఫిక్స్ + iṣ-ఆర్‌యస్ట్ అంత్య ప్రత్యయాలు ఇలా ఉంటాయి:
