# పాఠం 3

## 3.1. స్త్రీలింగ ఏకవచన ప్రథమ విభక్తి

### 3.1.1. -s తో ముగియే ఏకవచన ప్రథమ విభక్తి

క్రింది వాటిలో స్త్రీలింగ నామపదాలు, అక్షరంతో ముగిసినప్పటికీ, ప్రథమ విభక్తి ఏకవచనంలో **-s** తో ముగుస్తాయి:

::: grammar-box
**-i** తో ముగియే స్త్రీలింగ నామపదాలు: ఉదా. **śruti** f. "శ్రవణం" -- ప్రథమ విభక్తి ఏకవచనం: **śrutis** = ⟪श्रुतिस्⟫
**-u** తో ముగియే స్త్రీలింగ నామపదాలు: ఉదా. **dhenu** f. "పాలగొర్రె" -- ప్రథమ విభక్తి ఏకవచనం: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. ప్రత్యయం లేకుండా ఏకవచన ప్రథమ విభక్తి

ప్రత్యయం లేకుండా ఏకవచన ప్రథమ విభక్తి ఏర్పడేవి:

::: grammar-box
**-ā** తో ముగియే స్త్రీలింగ నామపదాలు: ఉదా. **devatā** f. "దేవత" -- ప్రథమ విభక్తి ఏకవచనం: **devatā** = ⟪देवता⟫
**-ī** తో ముగియే స్త్రీలింగ నామపదాలు: ఉదా. **devī** f. "దేవి" -- ప్రథమ విభక్తి ఏకవచనం: **devī** = ⟪देवी⟫
:::
::: important
**గమనిక!** దీనికి విరుద్ధంగా, **-ī** తో ముగియే ఒక అక్షర స్త్రీలింగ మూలనామపదాల ప్రథమ విభక్తి ఏకవచనం **-s** తో ముగుతుంది: ఉదా. dhī f. "ఆలోచన" -- ప్రథమ విభక్తి ఏకవచనం: dhīs = ⟪धीस्⟫. అలాగే lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "బోటు" మరియు tantrī (⟪तन्त्री⟫) f. "తీయ" కూడా అసాధారణంగా ప్రథమ విభక్తి ఏకవచనంలో **-s** తో ముగుస్తాయి: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. పుంలింగ నామపదాలకు స్త్రీలింగాలు ఏర్పరచడం

::: grammar-box
**-a** తో ముగియే పుంలింగ నామపదాలు:
**-ā** తో ముగియే స్త్రీలింగ నామపదం: ఉదా. **kṣatriya** m. » **kṣatriyā** f. "క్షత్రియ స్త్రీ" = ⟪क्षत्रिया⟫
**-ī** తో ముగియే స్త్రీలింగ నామపదం: ఉదా. **brāhmaṇa** m. » **brāhmaṇī** f. "బ్రాహ్మణ స్త్రీ" = ⟪ब्राह्मणी⟫

**-u** తో ముగియే పుంలింగ నామపదాలు:
**-ī** తో ముగియే స్త్రీలింగ నామపదం: ఉదా. **sādhu** m. » **sādhvī** f. (మంచిది, సాధువు) = ⟪साध्वी⟫
(**-u-** అక్షరం స్వరముకు ముందు **-v-** గా మారుతుంది, కాబట్టి **-u- + -ī** » **-vī**)
:::

## 3.3. పుంలింగ మరియు స్త్రీలింగ బహువచన ప్రథమ విభక్తి

::: grammar-box
పుంలింగ మరియు స్త్రీలింగ బహువచన ప్రథమ విభక్తిలో ప్రత్యయం **-as**.
**-a** తో ముగియే పుంలింగ నామపదాలు: **deva- + -as** » **devās** = ⟪देवास्⟫
**-ā** తో ముగియే స్త్రీలింగ నామపదాలు: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**-i** తో ముగియే పుంలింగ నామపదాలు: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**-i** తో ముగియే స్త్రీలింగ నామపదాలు: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**-ī** తో ముగియే స్త్రీలింగ నామపదాలు: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**-u** తో ముగియే పుంలింగ నామపదాలు: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**-u** తో ముగియే స్త్రీలింగ నామపదాలు: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
గమనిక: **e** అనేది **i** కి హోచ్‌స్టూఫే (గుణ), **o** అనేది **u** కి హోచ్‌స్టూఫే.


## 3.4. వర్ణసంధి

::: grammar-box
**సరళ వర్ణాలు, అవి తమ పొడవులో మాత్రమే భిన్నంగా ఉంటే, అవి సంబంధిత పొడవైన వర్ణంలో "కలిసిపోతాయి":**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)
:::
ఉదాహరణకు

devatā + annapūrṇā » devatānnapūrṇā "అన్నపూర్ణ ఒక దేవత" = ⟪देवतान्नपूर्णा⟫

> (అన్నపూర్ణ అనేది ఆహారం మరియు వంటల దేవి, ఆమె శివుని భార్య పార్వతి యొక్క అవతారంగా పరిగణించబడుతుంది.)

devī + indrāṇī » devīndrāṇీ "ఇంద్రాణి ఒక దేవి" = ⟪देवीन्द्राणी⟫

> (ఇంద్రాణి అనేది దేవేంద్రుని భార్య.)

i / -ī » **-y-**

## 3.5. Satzsandhi of -ās

::: grammar-box
**-ās అన్ని గంభీర ధ్వనుల ముందు -ā తో ప్రతిక్షేపించబడుతుంది.**

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Vaiśyas are Twice-born" = ⟪द्विजा वैश्याः⟫


## 3.6. Word List

**Learn the following words:**

**śruti** f. = ⟪श्रुति⟫ : hearing, eternal tradition (designation for the Vedas and Brāhmaṇa's).

**smṛti** f. = ⟪स्मृति⟫ : recollection, memory, meditative recollection = mindfulness, tradition (counter-concept to **śruti**). Includes:
the six **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): correct pronunciation
2. **chandas** n. (⟪छन्दस्⟫): meter
3. **vyākaraṇa** n. (⟪व्याकरण⟫): grammar
4. **nirukta** n. (⟪निरुक्त⟫) : word explanation, etymology
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : astronomy, calendar science
6. **kalpa** m. (⟪कल्प⟫) : ceremonial
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : treatises for the performance of great sacrifices
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : treatises for the ceremonies and sacrifices of daily life
**dharmasūtra** n. (⟪धर्मसूत्र⟫) and **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : treatises on law and custom (right conduct)
the great epics **mahābhārata** n. (⟪महाभारत⟫) and **rāmāyaṇa** n. (⟪रामायण⟫)
the **purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫) : treatises on worldly wisdom

**smṛti** is also particularly a designation for Dharma treatises.

**ధేను** స్త్రీ. = ⟪धेनु⟫ : (పాలు ఇచ్చే) గాడిద.

**పశు** పుం. = ⟪पशु⟫ : పశువు, సాధారణంగా ఉపయోగించే జంతువు (సమూహ పదం).

**దేవతా** స్త్రీ. = ⟪देवता⟫ : దేవత (అభిప్రాయపూర్వకంగా మరియు నిజమైనదిగా).

**బ్రాహ్మణీ** స్త్రీ. = ⟪ब्राह्मणी⟫ : బ్రాహ్మణురాలు.

**క్షత్రియా** స్త్రీ. = ⟪क्षत्रिया⟫ : క్షత్రియ స్త్రీ.

**క్షత్రియీ** స్త్రీ. = ⟪क्षत्रियी⟫ : క్షత్రియుని భార్య.

**వైశ్యా** స్త్రీ. = ⟪वैश्या⟫ : వైశ్య స్త్రీ.

**శూద్రా** స్త్రీ. = ⟪शूद्रा⟫ : శూద్ర స్త్రీ.

**శూద్రీ** స్త్రీ. / **శూద్రాణీ** స్త్రీ. = ⟪शूद्री शूद्राणी⟫ : శూద్రుని భార్య.

**దేవీ** స్త్రీ. = ⟪देवी⟫ : దేవి, ప్రత్యేకంగా దుర్గా స్త్రీ. = ⟪दुर्गा⟫, శివుని భార్య = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
చిత్రం: దుర్గా = ⟪दुर्गा⟫, ఒరిస్సా
(చిత్ర మూలం: [వివరాలు](/images/lekt0303))
:::
**సాధ్వీ** స్త్రీ. = ⟪साध्वी⟫ : సాధు పదం యొక్క స్త్రీలింగ రూపం.

**గుర్వీ** స్త్రీ. = ⟪गुर्वी⟫ : గురు పదం యొక్క స్త్రీలింగ రూపం.

**అస్మితా** స్త్రీ. = ⟪अस्मिता⟫ : "నేను-అని భావించడం", అంటే (తప్పుడు) నమ్మకం: **నేను** చూస్తున్నాను మొదలైన వాటిని చేస్తున్నాను.

**ఆన్వీక్షికీ** స్త్రీ. = ⟪आन्वीक्षिकी⟫ : తత్వశాస్త్రం (తార్కికంగా సరైన కారణాల ద్వారా తన నిర్ధారణలకు చేరుతున్న విజ్ఞానం).

**ఉపేక్షా** స్త్రీ. = ⟪उपेक्षा⟫ : నిర్లక్ష్యం, సమతృప్తి.

**కరుణా** స్త్రీ. = ⟪करुणा⟫ : కరుణ, దయ.

**ముదితా** స్త్రీ. = ⟪मुदिता⟫ : సంతోషం, ప్రత్యేకంగా ఇతరుల సంతోషంలో పాలుపంచుకోవడం (అసూయకు వ్యతిరేకం).


## 3.7. అభ్యాసం

**ఎ) క్రింది వాక్యాలను బహువచనంలోకి మార్చండి:**

1. ద్విజో బ్రాహ్మణః = ⟪द्विजो ब्राह्मणः⟫
2. ద్విజః క్షత్రియః = ⟪द्विजः क्षत्रियः⟫
3. ద్విజో వైశ్యః = ⟪द्विजो वैश्यः⟫
4. గురుః బ్రాహ్మణః = ⟪गुरुर्ब्राह्मणः⟫
5. సాధుః గురుః = ⟪साधुर्गुरुः⟫
6. గురుః కవిః = ⟪गुरुः कविः⟫
7. సాధ్వీ బ్రాహ్మణీ = ⟪साध्वी ब्राह्मणी⟫
8. దేవతా గురుః = ⟪देवता गुरुः⟫
9. పశుః ధేనుః = ⟪पशुर्धेनुः⟫
10. గుర్వీ సాధ్వీ = ⟪गुर्वी साध्वी⟫

**B) పేర్ల వాక్యాలను నింపి రూపొందించండి:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) స్త్రీలింగంలోకి మార్చండి:**
