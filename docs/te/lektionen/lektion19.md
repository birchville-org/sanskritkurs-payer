# పాఠం 19

## 19.1. సమాస వాక్యం (Relativsatz)

::: grammar-box

**రూపకల్పన:**


**సమాస విశేషణం -- సమాస వాక్యం, ఇది తనను అనుసరించే పదాన్ని కలిగి ఉంటుంది -- (నిర్దిష్ట విశేషణం) -- ప్రధాన వాక్యం**

**సమాస వాక్యం ప్రధాన వాక్యానికి తర్వాత కూడా రావచ్చు, కానీ అది ప్రధాన వాక్యం మధ్యలో చేర్చబడలేదు.**

**సమాస విశేషణం మరియు సంబంధిత పదం, ఇది జర్మన్ భాషకు విరుద్ధంగా సమాస వాక్యంలో ఉంటుంది, అది సింటాక్టిక్‌గా సమాస వాక్యం యొక్క అవసరాన్ని పూర్తి చేస్తుంది. నిర్దిష్ట విశేషణం ప్రధాన వాక్యం యొక్క సింటాక్టిక్ అవసరాన్ని పూర్తి చేస్తుంది.**
:::

ఉదాహరణలు:

గమనిక: సార్వత్రిక అర్థం కలిగిన సమాస వాక్యాలలో, లక్షణం (Indikativ) బదులుగా ఆశావాద రూపం (Optativ) ఉపయోగించడం సర్వసాధారణం. కాబట్టి మన ఉదాహరణలలో చాలా వరకు ఆశావాద రూపం ఉండటం ఇష్టం.

**1. వాక్యంలోని కర్త (⟪कर्तृ⟫) సమాస వాక్యం ద్వారా మరింత వివరించబడుతుంది:**

::: indent
⟪यो नरः पुण्यं करोति स स्वर्गं गच्छति⟫ =  ⟪यो नरः पुण्यं करोति तेन स्वर्गं गम्यते⟫ = ⟪येन नरेण पुण्यम् क्रियते तेन स्वर्गं गम्यते⟫ మొదలైనవి = "ధర్మకార్యాలు చేసే వ్యక్తి స్వర్గానికి వెళ్తాడు."
:::
**2. ప్రధాన వాక్యంలోని కర్మ (⟪कर्म⟫) సమాస వాక్యం ద్వారా మరింత వివరించబడుతుంది:**

::: indent
⟪यो ब्राह्मणो देवान्यजते तं देवा रक्षन्ति⟫ = "దేవతలు తమకు యజమానిగా ఉండి బలి ఇచ్చే బ్రాహ్మణులను రక్షిస్తారు."
:::
**3. ప్రధాన వాక్యంలోని పదం యొక్క వివరణ సమాస వాక్యంలో ఉంటుంది:**

::: indent
⟪ये नराः पापं कुर्वन्ति तेषां पुत्रा धनं न लभन्ते⟫ = "దుష్కార్యాలు చేసే వ్యక్తుల కుమారులకు ఐశ్వర్యం లభించదు."
:::
**4. సాపేక్ష విశేషణం మరియు సంబంధిత పదం జనటివ్‌లో ఉంటాయి (⟪षष्ठी⟫):**

::: indent
⟪यस्य नरस्य पुत्राः पापं कुर्वन्ति स न सुखवान्⟫ = "అతని కుమారులు చెడు చేసే వ్యక్తి సంతోషవంతుడు కాదు."
:::
**5. సాపేక్ష విశేషణం మరియు సంబంధిత పదం ఇన్‌స్ట్రుమెంటలిస్‌లో ఉంటాయి (⟪तृतीया⟫):**

::: indent
⟪येन शत्रुणा ग्रामो जितस्तं द्विषन्ति⟫ = "వారు తమ గ్రామాన్ని జయించిన/కైవసం చేసుకున్న శత్రువును ద్వేషిస్తారు."
:::
**6. సాపేక్ష విశేషణం మరియు సంబంధిత పదం ఆక్యుసటివ్‌లో ఉంటాయి (⟪द्वितीया⟫):**

::: indent
⟪यं नरं देवी रक्षति स सुखमाप्नोति⟫ = "దేవత రక్షించే వ్యక్తి సౌభాగ్యాన్ని పొందుతాడు."
:::

## 19.3. పదకోశం

**⟪अर्थ⟫ పుం.:** ప్రయోజనం, లక్ష్యం, అర్థం (పదం యొక్క), సంపద, ఆస్తి. ⟪अर्थम्⟫ (ద్వితీయ), ⟪अर्थेन⟫ (తృతీయ) షష్ఠితో లేదా ఉత్తరపదంగా: ... కొరకు, ... నిమిత్తం.

## 19.4. అభ్యాసం

**సంస్కృతంలోకి అనువదించండి:**

1. తన కుమారుడు చనిపోయిన వైశ్యస్త్రీ రోదిస్తుంది.

2. రాముడు తనను కాపాడే దైవానికి యజ్ఞం చేస్తాడు.

3. కవి తన ఐశ్వర్యాన్ని కోరుకునే క్షత్రియుని స్తుతిస్తాడు.

4. అగ్నికి యజ్ఞంతో పూజించని వ్యక్తి యొక్క ఇంటిని అగ్ని దహనం చేస్తుంది.

5. పులివలె ఉన్న వ్యక్తి రాముని ఓడించిన క్షత్రియ యోధులను సంహరిస్తాడు (క్రియావిశేషణం).
