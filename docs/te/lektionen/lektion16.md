# పాఠం 16

## 16.1. అంత్య వర్ణాల సంధి గురించి

సంయోగ పదాల నిర్మాణానికి, వీటి ముందు భాగం అంత్యంలో వర్ణం కలిగిన పదరూపాలను ఏర్పరుస్తుంది, ఈ క్రింది నియమాలు అవసరం:
