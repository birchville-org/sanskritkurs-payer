# పాఠం 46

## 46.1. రెండవ పురుష వాక్యరూపాల నిర్మాణం (⟪मध्यमः⟫) పూర్వకాలం (⟪लिट्⟫)

### 46.1.1. ప్రత్యయాలు

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :---: | :---: | :---: | :---: |
| **పూర్వకాల ప్రత్యయాలు** | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| ^^ \-tha | \-a | \-se | \-dhve |

:::

రెండవ బహువచనపు ప్రత్యయం -- సాధారణంగా రూపం కాదు -- మొదటి మరియు మూడవ ఏకవచన పూర్వకాల ప్రత్యయాలతో సరిపోలుతుందని గమనించండి.

::: grammar-box

tha ముందు అనేక మూలాలలో -ṛ తర్వాత సంధి స్వరం \-i- వస్తుంది. కొన్ని మూలాలలో -tha ముందు \-i- ఐచ్ఛికంగా ఉంటుంది.

:::

### 46.1.2. ప్రత్యయం -dhve యొక్క ఉచ్చారణ మార్పు

::: grammar-box

పూర్వకాలంలో, మూలస్వరం -u లేదా -ṛ తర్వాత ప్రత్యయం -dhve ని -ḍhve గా మార్చాలి. ఈ మార్పు సంధి స్వరం -i- తర్వాత జరిగితే, దానికి ముందు అంతస్వరం లేదా హల్లు ఉంటే ఎంపికతో జరుగుతుంది.

:::
