# పాఠం 30

## 30.1. 9వ వర్తమాన క్లాస్ (⟪क्र्यादि⟫ = "⟪क्री⟫ మొదలైనవి")

::: grammar-box
**రూపకల్పన:**

*   బలమైన మూలం: తక్కువ స్థాయి వేర్ + -nā-

*   బలహీన మూలం:

*   వ్యంజనానికి ముందు: తక్కువ స్థాయి వేర్ + -nī-

*   స్వరం ముందు: తక్కువ స్థాయి వేర్ + -n-
:::
ఉదాహరణ:

::: indent
⟪क्री⟫ 9U "కొనుగోలు చేయడం"
:::

| |ఏకవచనం:br⟪एकवचन⟫|బహువచనం:br⟪बहुवचन⟫|

:::

::: grammar-box

పొడవైన స్వరాలతో కొన్ని వేర్లు 9వ క్లాస్ యొక్క వర్తమాన మూల సఫిక్స్‌కు ముందు ఆ స్వరాలను సంక్షేపిస్తాయి:

::: grammar-box

:::

::: indent

:::

::: grammar-box
**3. ఓప్టివ్‌తో కూడిన సంబంధ వాక్యాలు కొన్నిసార్లు "ఎవరైనా... అయితే" అనే అర్థంలో ఉంటాయి**

## 30.5. అంత్య -r యొక్క సంధి

::: grammar-box
**-ar తప్ప, అంత్య -r కు అంత్య -s కి వర్తించే సంధి నియమాలు అన్నీ వర్తిస్తాయి.**

**-ar ముందు ఉచ్చారణాత్మక ధ్వనులు వస్తే -ar గానే ఉంటుంది, కానీ r- ముందు వస్తే -r తొలగిపోయి, -a- స్థానంలో -ā- వస్తుంది.**
:::
ఉదాహరణలు:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना रोदिति⟫
:::
