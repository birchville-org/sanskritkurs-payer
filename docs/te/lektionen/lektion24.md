# పాఠం 24

## 24.1. ద్వితియ విభక్తి (⟪चतुर्थी⟫ = "నాల్గవ విభక్తి ప్రత్యయం")

::: grammar-box
**1. ఒక కార్యానికి ఉద్దేశ్యం లేదా లక్ష్యాన్ని ("...వెంట" అని సూచించడానికి) వ్యక్తపరచడానికి, క్రియావిశేషణం (⟪तुमुन्⟫) బదులుగా, క్రియ లేదా స్థితిని సూచించే nomen (నామపదం) kṛt ప్రత్యయంతో కూడి, ద్వితియ విభక్తిలో (⟪चतुर्थी⟫ = "నాల్గవ విభక్తి ప్రత్యయం") ఉపయోగించవచ్చు.**

ఉదాహరణ:

బదులుగా:

:::
::: indent

:::

::: indent

లేదా:

⟪रामो गुरुवचनश्रवणाय गतः ।⟫

## 24.2. దత్త కారకం (⟪चतुर्थी⟫) నిర్మాణం

::: grammar-box
**దత్త కారకం యొక్క సాధారణ అంత్యములు:**

* **ఏకవచనం: -e ; స్త్రీలింగ నామాలకు శబ్దాంతం వచ్చినవి: -ai**
* **బహువచనం: దత్త మరియు అభ్యయ కారకాలు ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. వ్యంజనాంత నామాలు

::: grammar-box

| | దత్త ఏకవచనం | దత్త బహువచనం |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. ప్రశ్నార్థక సర్వనామాలు

::: grammar-box

| | పుంలింగం / నಪుంసకలింగం | స్త్రీలింగం |
| :--- | :--- | :--- |
| **సకార్థక ఏకవచనం** | ⟪कस्मै⟫ | ⟪कस्यै⟫ |
| **సకార్థక బహువచనం** | ⟪केभ्यस्⟫ | ⟪काभ्यस्⟫ |

:::
### 24.2.3. నిర్దేశక సర్వనామాలు

::: grammar-box

| | | ⟪तद्⟫ | ⟪एतद्⟫ | ⟪इदम्⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **పుంలింగం / నపుంసకలింగం** | **స. ఏ.వ.** | ⟪तस्मै⟫ | ⟪एतस्मै⟫ | ⟪अस्मै⟫ |
| | **స. బ.వ.** | ⟪तेभ्यस्⟫ | ⟪एतेभ्यस्⟫ | ⟪एभ्यस्⟫ |
| **స్త్రీలింగం** | **స. ఏ.వ.** | ⟪तस्यै⟫ | ⟪एतस्यै⟫ | ⟪अस्यै⟫ |
| | **స. బ.వ.** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::
### 24.2.4. స్వరంత విశేషణాలు

::: grammar-box
**స్వరంత విశేషణాలు**

* **పుంలింగ / నపుంసక -a తో ముగియడం:** ⟪देव⟫
* స. ఏ.వ. ⟪देवाय⟫
* స. బ.వ. ⟪देवेभ्यस्⟫
* **పుంలింగ -i తో ముగియడం:** ⟪कवि⟫
* స. ఏ.వ. ⟪कवये⟫
* స. బ.వ. ⟪कविभ्यस्⟫
* **పుంలింగ -u తో ముగియడం:** ⟪पशु⟫
* స. ఏ.వ. ⟪पशवे⟫
* స. బ.వ. ⟪पशुभ्यस्⟫
* **స్త్రీలింగ -ā తో ముగియడం:** ⟪देवता⟫
* స. ఏ.వ. ⟪देवतायै⟫
* స. బ.వ. ⟪देवताभ्यस्⟫
* **స్త్రీలింగ -ī తో ముగియడం:** ⟪देवी⟫
* స. ఏ.వ. ⟪देव्यै⟫
* స. బ.వ. ⟪देवीभ्यस्⟫
* **స్త్రీలింగ -i తో ముగియడం:** ⟪श्रुति⟫
* స. ఏ.వ. ⟪श्रुतये⟫ లేదా ⟪श्रुत्यै⟫ (అంటే ⟪कवि⟫ లాగా లేదా ⟪देवी⟫ లాగా)
* స. బ.వ. ⟪श्रुतिभ्यस्⟫
* **స్త్రీలింగ -u తో ముగియడం:** ⟪धेनु⟫
* స. ఏ.వ. ⟪धेनवे⟫ లేదా ⟪धेन्वै⟫
* స. బ.వ. ⟪धेनुभ्यस्⟫
:::
## 24.3. -ai మరియు -au తో ముగియడం యొక్క సందీ

::: grammar-box
**-ai మరియు -au తో ముగియడం యొక్క సందీ**

* **-ai ముందు స్వరం ఉంటే, సాధారణంగా -ā తో మారుతుంది (అరుదుగా -āy తో, పదం లోపల ఉన్నట్లు)**
* **-au ముందు స్వరం ఉంటే, సాధారణంగా -āv తో మారుతుంది (అరుదుగా -ā తో)**

ఉదాహరణ:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा अग्नये⟫ = "ఈ అగ్నికి"
:::

⟪ब्राह्मणो देवप्रतिमादर्शनाय गर्भगृहं विशति ॥१॥ नरा धनलाभाय व्रतानि चरन्ति ॥२॥ गुरुर्धर्मोपदेशाय नगरं गतः ॥३॥ बाला अपि गुरुवचनश्रुत्यै नगरं गताः ॥४॥ देवप्रतिमायै गृहं गर्भगृहम् ॥५॥ स्वर्गेभ्यो नराः पुण्यं कर्तुमिच्छन्ति ॥६॥ मोक्षार्थं बुद्धगता बुद्ध्याप्तिमिच्छन्ति ॥७॥ देवास्तेभ्यो ऽकृतपूजाब्राह्मणेभ्यः क्रुध्यन्ति ॥८॥ मरणाय जना जायन्ते ॥९॥⟫

D) వాక్యం A) 7లో -⟪अर्थ⟫తో కూడిన నిర్మాణాన్ని సమానార్థకమైన డేటివ్‌తో మార్చండి.

## 24.6. డేటివ్ వినియోగంపై మరిన్ని అభ్యాసాలు

సంస్కృతంలోకి అనువదించండి:

1\. బలిపెట్టని దేవి మనుషులపై కోపిస్తుంది.

2\. అతడు పశువును గ్రామానికి వదిలివేస్తాడు.

3\. ఇప్పుడే సరి = ఓపికతో చాలు.

4\. ఇది బ్రాహ్మణునికి మంచిది (⟪हित⟫, ⟪सुख⟫).

5\. శివునికి నమస్కారం (⟪नमस्⟫)! శ్రీ గణేశునికి నమస్కారం!
