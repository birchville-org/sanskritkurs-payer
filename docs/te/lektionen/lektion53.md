# పాఠం 53

## 53.1. ద్వివచనం (⟪द्विवचन⟫ n.) నామాల యొక్క

::: grammar-box
**ద్వివచనం (⟪द्विवचनम्⟫) "రెండు" అని సూచించడానికి ఉపయోగిస్తారు:**

:::
::: indent
⟪अश्विनौ⟫ "రెండు ఆశ్వినులు"
:::
**ద్వివచనం ఉపయోగించడం అక్కడ తప్పనిసరి, ఇది రెండు వస్తువులు లేదా అలాంటివి గురించి ఉన్నప్పుడు:**

::: indent
⟪हस्तौ⟫ "చేతులు (ఒక వ్యక్తి యొక్క)"
⟪पादौ⟫ "కాలు (ఒక మనిషి, గుర్రం లేదా ఇతర రెండు కాళ్ళ జంతువు యొక్క)"
:::
**కొన్నిసార్లు ద్వివచనం ఒకే వర్గానికి (జాతి, కుటుంబం) చెందిన ఒక పురుష మరియు ఒక స్త్రీ ప్రతినిధిని సూచిస్తుంది:**

::: indent
⟪पितरौ⟫ "తండ్రి మరియు తల్లి = పితామహులు"
:::
**"ఒక జంట" అని అర్థం ఉన్న పదాలు - ఉదాహరణకు ⟪युग⟫ n., ⟪द्वन्द्व⟫ n., ⟪द्वय⟫ n. - ఎప్పుడూ ఏకవచనంలోనే ఉపయోగిస్తారు, రెండు లేదా అంతకంటే ఎక్కువ జతలు ఉన్నప్పుడు మాత్రమే:**

::: indent
⟪बाहुद्वयम्⟫ "ఒక జంట చేతులు"
:::
