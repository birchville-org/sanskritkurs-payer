# దేవనాగరీ = ⟪देवनागरी⟫

## లిపి వ్యాయామం 1

సంస్కృతాన్ని వివిధ లిపులలో రాసి, రాస్తున్నారు. ఈ క్రింది సారాంశం ఆ లిపులలో కొన్నింటిని చూపిస్తుంది:

![](/images/schrift001.webp)  
చిత్రం: సంస్కృత లిపి నమూనాలు  
\[చిత్ర మూలం: వికీపీడియా, GNU FD లైసెన్స్\]

ప్రధాన ఆధునిక ఉత్తర భారతీయ సంస్కృత లిపి దేవనాగరీ:

![](/images/schrift002.webp)

ప్రతి వ్యంజన గుర్తు వ్యంజనానికి తర్వాత వచ్చే "అ" అనే స్వరంతో కూడి ఉంటుంది. శుద్ధ వ్యంజనాన్ని (తర్వాత స్వరం లేకుండా) రాసేందుకు, దీన్ని క్రింద ఉన్న వాలు గీతతో -- విరామం = ⟪विराम⟫ -- గుర్తించాలి:

⟪क्⟫ = క, ⟪च्⟫ = చ, ⟪ट्⟫ = ట, ⟪त्⟫  = త, ⟪प्⟫ = ప

వ్యంజనానికి తర్వాత వచ్చే స్వరాలు -- "అ" తప్ప -- ఇలా రాస్తారు:

⟪का⟫ = కా, ⟪कि⟫ = కి, ⟪की⟫ = కీ, ⟪कु⟫ = కు, ⟪कू⟫ = కూ, ⟪कृ⟫ = కృ, ⟪कॄ⟫ = కౠ, ⟪कॢ⟫  = కృ

⟪के⟫ = కే, ⟪कै⟫ = కై, ⟪को⟫ = కో, ⟪कौ⟫ = కౌ

వ్యంజనం + స్వరం కలయికలను రాసే క్రమం:

![](/images/schrift003.jpg)

రాసేటప్పుడు, ప్రతి అక్షరాన్ని పై గీతతో సహా పూర్తి చేసి, తర్వాతే తర్వాతి అక్షరాన్ని రాస్తారు.

## వ్యాయామం

దేవనాగరిలో వ్రాయండి:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

చదవండి మరియు ట్రాన్స్‌లిటరేట్ చేయండి:

⟪तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ⟫

⟪पिता⟫ తండ్రి, ⟪कपि⟫ వానరము, ⟪कृत⟫ చేసినది,  ⟪टीका⟫ ఉపవ్యాఖ్య, ⟪तत्⟫ ఈ, ⟪तट⟫ తీరము, ⟪पत्⟫ విసరుట, ⟪पट⟫ నేత, ⟪काच⟫ కిరీటము,  ⟪काकुत्⟫ నోరు, ⟪चित्⟫ గ్రహించుట, ⟪पृच्⟫ కలపడము,  ⟪पोटक⟫ దాసుడు, ⟪चेतु⟫ ఉద్దేశ్యము, ⟪तौतातित⟫ కుమారీల (మీమాంస) అనుచరుడు, ⟪तूत⟫ తులసి చెట్టు, ⟪पीत⟫ తాగినది,  ⟪पीति⟫ పానీయము, ⟪कॢप्⟫  సరిపోవుట, ⟪कृपते⟫ అతడు విలపించును, ⟪पुटी⟫ మడత, ⟪चापि⟫ అదేవిధముగా, ⟪तोक⟫ సంతతి, ⟪तृपत्⟫ తృప్తి చెందిన, ⟪पॄ⟫ నింపుట, ⟪कृकाटी⟫ గొండెముడి, ⟪पूपौ⟫ రెండు పిండిపూరకములు, ⟪पैतृकी⟫ తండ్రికి సంబంధించినది (స్త్రీలింగము), ⟪कौट⟫ మోసగాడు, ⟪कच⟫ తలయొక్క ముఖ్యమైన వెంట్రుకలు, ⟪कुतपे⟫ మేక వెంట్రుకల పరుపుపై, ⟪कुचौ⟫ వక్షస్థలి, ⟪चकिता⟫ భయపడినది (స్త్రీలింగము)
