# పాఠం 22

## 22.1. నిర్బంధ విభక్తి (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

సంస్కృతంలో ఒక కర్త (⟪कर्तृ⟫) చేసే ఒక పని, మరొక కర్త (⟪कर्तृ⟫) చేసే మరొక పనికి ముందు జరుగుతుందో లేదా అది ఒక సహచర పరిస్థితిగా జరుగుతుందో తెలియజేయడానికి నిర్బంధ విభక్తిని (⟪क्त्वा । ल्यप्⟫) ఉపయోగిస్తారు. కాబట్టి

"అతను ఆ పని చేసిన తర్వాత, అతను ఈ పని చేస్తాడు" ; "అతను ఇది చేస్తాడు, అప్పుడు అతను ఆ పని చేస్తాడు" ; "దీనికి ఫలితంగా అతను ఆ పని చేస్తాడు" ; "నేను వచ్చి, చూసి, గెలిచాను" మొదలైనవి.

నిర్బంధ విభక్తి ఒక క్రియావిశేషణం (Verbal-Adverb), అంటే దీనిని సంఖ్య, వాక్యరూపం లేదా లింగాల ప్రకారం మార్చలేము. అయితే, కొన్ని వినాయకాలను తప్పించి, ఇది ఎల్లప్పుడూ నిర్బంధ విభక్తి ద్వారా సూచించబడిన పనికి ముందు జరిగే లేదా దానితో సహచరంగా జరిగే పనికి కర్త (⟪कर्तृ⟫) ఒకటే ఉంటుంది. కాబట్టి నిర్బంధ విభక్తి యొక్క కర్త నామవాచక విభక్తి (⟪प्रथमा⟫) లేదా కరణ విభక్తి (⟪तृतीया⟫) లో ఉంటుంది.

సంయోగ పదాలతో పాటు నిర్బంధ విభక్తి కూడా సంస్కృతంలో అత్యంత సాధారణమైన వ్యక్తీకరణ మార్గాలలో ఒకటి.

జర్మన్ భాషకు అనువాదం చేసేటప్పుడు, నిరంతరం "తర్వాత" అని చెప్పకూడదు. దానికి బదులుగా జర్మన్ భాషలో సాధారణంగా ఉపయోగించే కాల అనుసంధాన వ్యక్తీకరణలను ఉపయోగించాలి.

**మాదిరి:**

(నిర్బంధ విభక్తికి మరింత నిర్దిష్టమైన నిర్వచనం: పరిస్థితి వాక్యభాగం, కర్తృ విభక్తి మొదలైనవి) - నిర్బంధ విభక్తి - నిర్బంధ విభక్తి - ... - నిర్బంధ విభక్తి - ... కర్త + క్రియా వాక్యం (క్రియాత్మక లేదా పాశ్చాత్య రూపంలో)

:::
**ఉదాహరణలు:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = పాశ్చాత్య నిర్మాణం: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**  
"మనిషి ఇంటిలోకి ప్రవేశించి, చిన్న పిల్లవాడిని చూసి, అతన్ని సంభాషించాడు."

బహువచనం: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. యోగవాక్యం (Absolutiv) నిర్మాణం

::: grammar-box
**యోగవాక్యం (Absolutiv) నిర్మాణం**

*   ఉపసర్గ లేని క్రియలు: యోగవాక్యం **-tvā** తో ముగుస్తుంది
*   ఉపసర్గ కలిగిన క్రియలు: యోగవాక్యం **-ya** లేదా **-tya** తో ముగుస్తుంది
:::
### 22.2.1. ఉపసర్గ లేని క్రియలు: యోగవాక్యం -⟪त्वा⟫ తో ముగియుట

::: grammar-box

**నిర్మాణం:**

(సాధారణంగా) తక్కువ స్థాయిలో ఉన్న మూలం, అది పూర్ణ ప్రత్యయ విశేషణం (PPP) ముందు ఉన్న రూపంలో + **-tvā** (**-⟪त्वा⟫**)

ఋణార్థక **a-** / **an-** మాత్రమే **-⟪त्वा⟫** ప్రత్యయంతో కలవగలదు: ⟪अकृत्वा⟫ "చేయకుండా"

:::
**ఉదాహరణలు:**

::: indent
⟪आप्त्वा⟫ "అతను/ఆమె/దాని/నేను/నీవు/మేము/మీరు/వారు/ఇద్దరు మిత్రులు/ఇద్దరు మీ మిత్రులు/ఆ ఇద్దరు వారు చేరిన తర్వాత / చేరెను / చేరారు"

⟪आसित्वा⟫ "అతను (...) కూర్చున్న తర్వాత / కూర్చుండెను"

⟪इत्वा⟫ "అతను (...) వెళ్లిన తర్వాత / వెళ్ళెను"

⟪स्थित्वा⟫ "అతను (...) నిలబడిన తర్వాత / నిలిచెను"

⟪जित्वा⟫ "అతను (...) విజయం సాధించిన తర్వాత / విజయం సాధించెను"

⟪उक्त्वा⟫ "అతను (...) మాట్లాడిన తర్వాత / మాట్లాడెను"
:::
### 22.2.2. ఉపసర్గ కలిగిన క్రియలు

#### 22.2.2.1. పొడవైన స్వరం (-ā తప్ప) లేదా వ్యঞ্జనంతో ముగియు మూలాలు

::: grammar-box

**(సాధారణంగా) తక్కువ స్థాయి మూలం + -ya**

:::
**ఉదాహరణలు:**

::: indent
⟪उपनीय⟫ "అతను (...) తీసుకువచ్చిన తర్వాత / తీసుకొని వచ్చెను"

⟪प्रभूय⟫ "అతను (...) బయటకు వచ్చిన తర్వాత / బయలుదేరెను" "అతను (...) శక్తిని పొందిన తర్వాత / పొందెను"

⟪प्राप्य⟫ "అతను (...) పొందిన తర్వాత / పొందెను"
:::
#### 22.2.2.2. -ā తో ముగియు మూలాలు

::: grammar-box

**మార్పు లేని ఎత్తైన స్థాయి మూలం + -ya**

:::
**ఉదాహరణ:**

::: indent
⟪उपस्थाय⟫ "అతను (...) నడచిన తర్వాత / నడిచెను" ; (ఉపసర్గ లేకుండా: ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. తక్కువ స్థాయిలో -i, -u, -ṛ తో ముగియు మూలాలు

::: grammar-box

**అత్యల్ప స్థాయి మూలం + -tya**

:::
**ఉదాహరణలు:**

::: indent
⟪प्रस्तुत्य⟫ "అతను (...) ప్రశంసించిన తర్వాత / ఉన్నాడు"

⟪विस्मृत्य⟫ "అతను (...) మరచిన తర్వాత / ఉన్నాడు"

⟪संस्कृत्य⟫ "అతను (...) బలికి సిద్ధం చేసిన తర్వాత / ఉన్నాడు"
:::
#### 22.2.2.4. అత్యల్ప స్థాయిలో -a తో ముగియే -am / -an మూలాలు

::: grammar-box

**ఐచ్ఛికంగా:**

**-am** / **-an** తో ముగియే మూలం + **-ya**

లేదా:

**-a** తో ముగియే మూలం + **-tya**

:::
**ఉదాహరణ:**

::: indent
⟪विगम्य⟫ లేదా ⟪विगत्य⟫ "అతను (...) వెళ్ళిపోయిన తర్వాత / ఉన్నాడు"
:::
