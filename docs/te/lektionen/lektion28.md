# పాఠం 28

## 28.1. కారణక్రియ (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**ఒక వ్యక్తి లేదా వస్తువు మరొక వ్యక్తి లేదా వస్తువు ఏదైనా చేయడానికి లేదా అనుభవించడానికి కారణమవుతుందని వ్యక్తపరచాలనుకుంటే, దానికి కారణక్రియ (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫) ఉపయోగిస్తారు. ఇది ఒక మూలధాతువు (ఉపసర్గతో లేదా లేకుండా) ద్వారా వ్యక్తమవుతుంది.**

ఉదాహరణ:
⟪गम्⟫ "వెళ్ళు" » కారణక్రియ: ⟪गमयति⟫ "అతను ఎవరో వెళ్ళేలా చేస్తాడు; అతను పంపుతాడు"
⟪दृश्⟫ "చూడు" » కారణక్రియ: ⟪दर्शयति⟫ "అతను చూపిస్తాడు = అతను ప్రదర్శిస్తాడు"
:::

## 28.2. కారణక్రియతో వాక్య నిర్మాణం (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**మాదిరి 1:**

**కారణక్రియకు ఆధారమైన మూలధాతువు (ఉపసర్గతో లేదా లేకుండా) అకర్మకంగా ఉంటే (అంటే దానికి కర్తృవిభక్తి వస్తువు ఉండలేదు) లేదా చలనం, జ్ఞానం, సమాచారం లేదా ఆహారం వంటి అర్థాలను వ్యక్తపరిస్తే:**

**కారణక్రియ యొక్క కర్త (⟪कर्ता⟫) ప్రథా విభక్తిలో (⟪प्रथमा⟫) — ప్రేరేపించబడిన క్రియ యొక్క కర్త ద్వితీయా విభక్తిలో (⟪द्वितीया⟫) — (చలన లక్ష్యం, జ్ఞాన వస్తువు మొదలైనవి ద్వితీయా విభక్తిలో = ⟪द्वितीया⟫) — కారణక్రియ**
:::
ఉదాహరణలు:

⟪दुर्जनो रामं मोहयति⟫ = "ఒక దుర్మార్గుడు రాముడిని గందరగోళంలోకి నెట్టాడు = రాముడిని గందరగోళపరిచాడు = రాముడు తప్పుగా ఆలోచించేలా చేశాడు"
ఫలితం: ⟪रामो मुह्यति⟫ = "రాముడు గందరగోళంలో ఉన్నాడు / మూఢుడయ్యాడు / తప్పుగా ఆలోచిస్తున్నాడు."

⟪रामः शत्रून्स्वर्गं गमयति⟫ = "రాముడు శత్రువులను స్వర్గానికి పంపాడు = శత్రువులను స్వర్గంలోకి వెళ్ళేలా చేశాడు"
ఫలితం: ⟪शत्रवः स्वर्गं गच्छन्ति⟫ = "శత్రువులు స్వర్గానికి వెళ్ళారు / స్వర్గంలోకి వచ్చారు"

⟪गुरू रामं वेदार्थं वेदयति⟫ = "గురువు రాముడికి వేదం యొక్క అర్థాన్ని తెలియజేశాడు = రాముడికి వేదం యొక్క అర్థాన్ని బోధించాడు"
ఫలితం: ⟪रामो वेदार्थं वेत्ति⟫ = "రాముడు వేదం యొక్క అర్థాన్ని తెలుసుకున్నాడు / అర్థం చేసుకున్నాడు"

⟪स रामं वेदमध्यापयति⟫ = "వాడు రాముకు వేదాన్ని బోధిస్తాడు"
ఫలితం: ⟪रामो वेदमधीते⟫ "రాముడు వేదాన్ని అధ్యయనం చేస్తాడు"

⟪रामो देवानामृतमाशयति⟫ = "రాముడు దేవతలకు అమృతాన్ని తినిపించు = దేవతలకు అమృతాన్ని ఇస్తాడు" (⟪अश्⟫ 9 "తిను")
ఫలితం: ⟪देवा अमृतमश्नन्ति⟫ "దేవతలు అమృతాన్ని తింటారు"

**స్కీమా 1 ప్రకారం నిర్మించబడిన మూలం ⟪दृश्⟫:**

**స్కీమా 1 కి వివాదాలు స్కీమా 2 క్రింద చూడండి**

ఉదాహరణ:
(⟪स⟫) ⟪रामं पुत्रं दर्शयति⟫ = "వాడు రామునికి కుమారున్ని చూపిస్తాడు"
:::
క్రింది శ్లోకం స్కీమా 1 ప్రకారం కారణక్రియ ఉదాహరణలను సంగ్రహిస్తుంది (క్రియా రూపాలు అన్నీ 3వ పురుషుడు, భూతకాలం, బహువచనం):
::: indent
⟪शत्रूनगमयत्स्वर्गं वेदार्थं स्वानवेदयत् । आशयच्चामृतं देवान् वेदमध्यापयद्विधिम् । आसयत्सलिलै पृथ्वीं यः स मे श्रीहरिगतिः ॥⟫
:::

**స్కీమా 2:**

**సర్వనామ క్రియల కోసం (స్కీమా 1 లో పేర్కొన్న వాటి తప్ప). అన్ని క్రియల కోసం కూడా, ఒకవేళ కారణక్రియ ద్వారా సూచించబడినది ప్రేరేపించబడితే (ఒకవేళ కారణక్రియ అనేది కారణక్రియకు సంబంధించినదైతే):**

**కారణభావంలో నిర్దేశితుడు (⟪कर्ता⟫) ప్రథా విభక్తిలో (⟪प्रथमा⟫) — కార్యకర్తను ప్రేరేపించిన చర్యలో నిర్దేశితుడు తృతీయా విభక్తిలో (⟪तृतीया⟫) — ప్రేరేపించిన చర్య యొక్క వస్తువు సాధారణ క్రియ ద్వారా ఉండే విభక్తిలో (అంటే సాధారణంగా చతుర్థి) — క్రియ కారణభావంలో**
:::
::: indent
ఉదాహరణలు:
(⟪स⟫) ⟪रामेण भार्यां त्याजयति⟫ = "రాముని తన భార్యను వదిలివేయమని ప్రేరేపిస్తాడు"
ఫలితం: ⟪रामो भार्यां त्यजति⟫ = "రాముడు తన భార్యను వదిలివేస్తాడు"

⟪विष्णुमित्रो रामेण गोविन्दं गमयति⟫ = "విష్ణుమిత్రుడు రాముని గోవిందుడిని వెళ్ళమని ప్రేరేపించమని చేస్తాడు = విష్ణుమిత్రుడు రాముడికి గోవిందుడిని పంపివేయమని చెబుతాడు"
ఫలితం: ⟪रामो गोविन्दं गमयति⟫ = "రాముడు గోవిందుడిని పంపివేస్తాడు"
ఈ ఫలితం యొక్క ఫలితం: ⟪गोविन्दो गच्छति⟫ = "గోవిందుడు వెళ్తాడు"
:::
::: grammar-box
**స్కీమా 1 కి వివరణలు:**

**స్కీమా 2 ప్రకారం క్రింది క్రియలు కూడా నిర్మించబడతాయి:**

**కారణభావం యొక్క:**
**⟪नी⟫ "నడిపించు"**
**⟪वह्⟫ "ప్రయాణించు" (కార్యకర్తను ప్రేరేపించిన చర్యలో నిర్దేశితుడు డ్రైవర్ కానప్పుడు మాత్రమే)**
**⟪स्मृ⟫ "స్మరించుకో" (దీనికి వివరణలు ఉన్నాయి)**
**⟪अद्⟫ "తినು"**
**⟪खाद्⟫ "కొరకడం"**
:::
ఉదాహరణలు:

⟪रामो भृत्येन भारं नाययति वाहयति वा⟫ = "రాముడు సేవకుడికి బరువును నడపమని లేదా ప్రయాణించమని చెబుతాడు"
ఫలితం: ⟪भृत्यो भारं नयति वहति वा⟫ = "సేవకుడు బరువును నడపగా లేదా ప్రయాణించగా"

⟪रामो बालेनान्नमादयति खादयति वा⟫ = "రాముడు బాలుడికి ఆహారాన్ని తినమని లేదా కొరకమని చెబుతాడు"
ఫలితం: ⟪बालो ऽन्नमत्ति खादति वा⟫ = "బాలుడు ఆహారాన్ని తింటాడు లేదా కొరుకుతాడు"

(⟪स⟫) ⟪रामेण स्मारयति⟫ = "రాముడు స్మరించుకోవడానికి కారణమవుతాడు"
ఫలితం: ⟪रामः स्मरति⟫ = "రాముడు స్మరించుకుంటాడు"

::: grammar-box
**క్రింది కారణకాలు రెండు విధానాల ప్రకారం నిర్మించబడతాయి:**

**⟪हृ⟫ "ఉంచు, తెచ్చు"**
**⟪कृ⟫ "చేయు, చేయించు"**
**ఆత్మనెపదక కారణకం ⟪दृश्⟫ కు**
:::
ఉదాహరణలు:

⟪रामो भृत्यं कटं कारयति हारयति वा⟫ = "రాము సేయుడు ఒక పరుపును (⟪कट⟫ m.) చేయించు లేదా తెప్పించు"
లేదా:
⟪रामो भृत्येन कटं कारयति हारयति वा⟫
ఫలితం: ⟪भृत्यः कटं करोति हरति वा⟫ = "సేయుడు ఒక పరుపును చేస్తాడు లేదా తెచ్చుకుంటాడు"

⟪रामो बालं प्रतिमां दर्शयते⟫ = "రాము బాలునికి చిత్రాన్ని కనిపించజేయు = బాలునికి చిత్రాన్ని చూపు (తన స్వార్థం కోసం)"
లేదా:
⟪रामो बालेन प्रतिमां दर्शयते⟫
ఫలితం: ⟪बालः प्रतिमां पश्यति⟫ = "బాలుడు చిత్రాన్ని చూస్తాడు"

కారణకం నిష్క్రియాత్మక నిర్మాణంలో ఉపయోగించబడినప్పుడు, దాదాపు ఎల్లప్పుడూ క్రింది విధానం వర్తిస్తుంది:

::: grammar-box
**విధానం A (నిష్క్రియాత్మక నిర్మాణం):**

**కారణక కర్త ఉపాధాన విభక్తిలో (⟪तृतीया⟫) — ప్రేరేపించబడిన క్రియ యొక్క కర్త నిర్దేశ విభక్తిలో (⟪प्रथमा⟫) — ప్రేరేపించబడిన క్రియ యొక్క వస్తువు సాధారణ క్రియ ద్వారా ఉండే విభక్తిలో (అంటే సాధారణంగా నిర్దేశ విభక్తిలో) — క్రియ కారణక రూపంలో**
:::
ఉదాహరణలు:

⟪गुरुणा रामो ग्रामं गम्यते⟫ = "ఆచార్యుడు రామును గ్రామానికి పంపు"
ఫలితం: ⟪रामो ग्रामं गच्छति⟫ = "రాము గ్రామానికి వెళ్తాడు"

⟪रामेण भृत्यः कटं कार्यते⟫ = "రాము సేయుడు ఒక పరుపును చేయించు"
ఫలితం: ⟪भृत्यः कटं करोति⟫ = "సేయుడు ఒక పరుపును చేస్తాడు"

## 28.4. కారకానికి పాస్సివ్ నిర్మాణం (⟪यक्⟫)

::: grammar-box

**కారక మూలం -aya- తో పాటు + పాస్సివ్ సఫిక్స్ -ya-**

**sthāpyate** (sthāp-ya-te) "అతను/ఆమె/దాని ఏర్పాటు చేయబడుతుంది"
:::
