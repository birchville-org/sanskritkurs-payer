# పాఠం 39

## 39.1. మొదటి వ్యక్తి యొక్క వాక్యంతంలు (:sig[तृतीयः] ⟪पुरुषः⟫ = "**మూడవ** వ్యక్తి")

మొదటి వ్యక్తి యొక్క వాక్యంతంలు (:sig[⟪तृतीयः⟫] ⟪पुरुषः⟫ = "**మూడవ** వ్యక్తి") ఈ క్రింది విధంగా ఉన్నాయి:

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **ప్రాథమిక వాక్యంతంలు థీమాటిక స్టెమ్స్** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **ప్రాథమిక వాక్యంతంలు అథీమాటిక స్టెమ్స్** | ^^ | ^^ | **-e** | ^^ |
| **ద్వితీయ వాక్యంతంలు థీమాటిక స్టెమ్స్** | **-m** | **-ma** | **-i** | **-mahi** |
| **ద్వితీయ వాక్యంతంలు అథీమాటిక స్టెమ్స్** | **-am** | ^^ | ^^ | ^^ |
| **ఆప్టేటివ్ వాక్యంతం** | ^^ | ^^ | **-a** | ^^ |
| **పెర్ఫెక్ట్ వాక్యంతం** | **-a** | ^^ | **-e** | **-mahe** |

:::
¹ గమనిక: నిజానికి, థీమాటిక స్టెమ్స్ యొక్క ప్రాథమిక వాక్యంతం Ā కూడా -e గా ఉండాలి, కానీ అనలాజీ కారణంగా థీమా వోకల్ -a- తొలగించబడుతుంది. కానీ ఫలితం అలా ఉంటుంది, వాక్యంతం -i థీమా వోకల్ -a- కి జతకట్టింది: a + i » e.
