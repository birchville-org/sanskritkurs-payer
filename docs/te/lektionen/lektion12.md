# పాఠం 12


## 12.1. పర్టిసిప్ పర్ఫెక్ట్ పాసివ్ (PPP)

భూతకాల వాక్యాలను నిర్మించడానికి ఒక మార్గం, సొగసైన పర్టిసిప్ పర్ఫెక్ట్ పాసివ్ (PPP) నిర్మాణంతో.

::: grammar-box
**నిజానికి, PPP నిజమైన పర్టిసిప్ కాదు, ఎందుకంటే అది కాల మూలం నుండి ఏర్పడదు. ఇది వేరుగా ఒక పదార్థ నిర్మాణం మూలంతో ప్రాథమిక సుఫిక్స్ -ta లేదా -na తో. అందువల్ల, భారతీయ వ్యాకరణంలో kta సుఫిక్స్ గా పేర్కొంటారు.**
:::

### 12.1.1. క్రియల కోసం స్కీమా

::: grammar-box
**ఆగెన్స్ (కర్త) ఇన్‌స్ట్రుమెంటలిస్ (త్రితీయా) -- ప్రత్యక్ష వస్తువు (కర్మణ్) నామినేటివ్ (ప్రథమా) -- పర్టిసిప్ పర్ఫెక్ట్ పాసివ్**

ఈ సందర్భంలో, PPP వస్తువుతో సంఖ్య, కేసు మరియు లింగం అనుసరించాలి.

సహాయక క్రియ ("ఉండటం") అవసరం లేదు.

ఉదాహరణలు:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = "(పవిత్రుడు ద్వారా స్వర్గం పొందబడింది) = పవిత్రుడు ఒక స్వర్గాన్ని పొందాడు."
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = "(బ్రాహ్మణుడు ద్వారా దేవి ఒక యజ్ఞంతో పూజించబడింది) = బ్రాహ్మణుడు దేవిని ఒక యజ్ఞంతో పూజించాడు."
:::

### 12.1.2. అకర్మక క్రియలు మరియు చలన క్రియల కోసం స్కీమా I

::: grammar-box
**ఆగెన్స్ (కర్త) నామినేటివ్ (ప్రథమా) -- పర్టిసిప్ పర్ఫెక్ట్ పాసివ్**

ఈ సందర్భంలో, PPP ఆగెన్స్‌తో సంఖ్య, కేసు మరియు లింగం అనుసరించాలి. పర్టిసిప్ పర్ఫెక్ట్ "పాసివ్" అకర్మక క్రియల (ప్రత్యక్ష వస్తువు లేని క్రియలు) మరియు చలన క్రియలలో సక్రమ అర్థం ఉంటుంది.

ఉదాహరణ:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = "క్షత్రియ స్త్రీ నగరానికి వెళ్లింది."
:::

### 12.1.3. రెండవ నమూనా అకర్తృక క్రియలు మరియు చలన క్రియలకు

::: grammar-box
**కర్తృ (kartṛ) ఉపకరణ విభక్తిలో (tṛtīyā) -- PPP నామవాచక ఏకవచనపు లింగంలో**

ఉదాహరణ:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(క్షత్రియునిచే (నగరానికి) వెళ్లబడింది) = క్షత్రియుడు (నగరానికి) వెళ్లాడు.“

రెండవ నమూనా ప్రకారం నిర్మాణం మొదటి నమూనా ప్రకారం నిర్మాణం కంటే చాలా అరుదు.
:::

## 12.2. PPP యొక్క అర్థం గురించి

కాబట్టి, సాధారణంగా "పర్ఫెక్ట్ పార్టిసిప్యల్ పాస్వీవ్" అకర్తృక క్రియలకు ప్రధానంగా పాస్వీవ్ అర్థాన్ని కలిగి ఉంటుంది (**āpta** = "అందుబాటులోకి వచ్చింది (చేయబడింది)") మరియు అకర్తృక క్రియలు మరియు చలన క్రియలకు యాక్టివ్ అర్థాన్ని (**gata** = "వెళ్ళినది") కలిగి ఉంటుంది, కొన్ని క్రియలలో PPP యాక్టివ్ మరియు పాస్వీవ్ అర్థాలను కలిగి ఉంటుంది:

ఉదాహరణకు
**gata** = ⟪गत⟫ = "వెళ్ళినది" (యాక్టివ్); కానీ ఇలా కూడా: **gato mārgaḥ** = ⟪गतो मार्गः⟫ = "ఒక వెళ్ళిన మార్గం" (పాస్వీవ్)
**āpta** = ⟪आप्त⟫ = "అందుబాటులోకి వచ్చింది" (పాస్వీవ్), "అందుబాటులోకి వచ్చినది" (యాక్టివ్)


## 12.3. PPP నిర్మాణం

::: grammar-box
ఈ క్రింది నిర్మాణ పద్ధతులు ఉన్నాయి (ప్రతి మూలానికి సంబంధించిన PPP నేర్చుకోవాలి!):

**(సాధారణంగా) లోతైన మూలం**

**+ -ta**
ముందు బింధు వర్ణం **-i-** తో: **-ita**
బింధు వర్ణం లేకుండా: **-ta**
**+ -na**

స్త్రీలింగ నామవాచకాలు **-tā**, **-itā**, **-nā** అని ఉంటాయి; లింగం **phala** n. వలె విభక్తిలో మారుతుంది.
:::

### 12.3.1. -ta (kta) తో PPP

#### 12.3.1.1. బింధు వర్ణం -i- లేకుండా (aniṭ)

*aniṭ* = "లేకుండా (*an-*) పిల్లవాడికి ముందు ఉన్న (*-i-*) *t*" (అంటే బింధు వర్ణం *i* లేకుండా).

::: grammar-box
సంధి స్వరం లేకుండా, సాధారణంగా క్రియాపద పూర్వరూపం (PPP) స్వరాంత మూలాల నుండి, మరియు ఇతర చాలా మూలాల నుండి ఏర్పడుతుంది; సంధి స్వరం ఎప్పుడు లేదా ఎందుకు ఉపయోగించబడదు అనే దానికి సంబంధించి ఖచ్చితమైన నియమాన్ని ఇవ్వడం కష్టం.

:::
::: grammar-box
సంధి స్వరం లేకుండా, సాధారణంగా క్రియాపద పూర్వరూపం (PPP) స్వరాంత మూలాల నుండి, మరియు ఇతర చాలా మూలాల నుండి ఏర్పడుతుంది; సంధి స్వరం ఎప్పుడు లేదా ఎందుకు ఉపయోగించబడదు అనే దానికి సంబంధించి ఖచ్చితమైన నియమాన్ని ఇవ్వడం కష్టం.

*aniṭ* మూలాల జాబితా కోసం, కిల్హోర్న్‌లోని *Grammatik* § 298 చూడండి.
:::

## 12.4. పదంలో ధ్వని సంయోగ నియమాలు

*aniṭ* నిర్మాణాలలో పదంలో ధ్వని సంయోగం యొక్క క్రింది నియమాలను పాటించాలి. **ఈ నియమాలు సంస్కృత రూపశాస్త్రం యొక్క మొత్తం అవగాహనకు చాలా ముఖ్యమైనవి.**

::: no-header
| | |
| :--- | :--- |
| **1. నిఘోష విరామ ధ్వని (ఉదా: t, th) ముందు k, t, p అవికృతంగా ఉంటాయి:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct ని kt = ⟪क्त्⟫ తో ప్రతిక్షేపించబడుతుంది:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt ని ṣṭ = ⟪ष्ट्⟫ తో ప్రతిక్షేపించబడుతుంది:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. ఘోష విరామ ధ్వని – j తప్పించి – నిఘోష ధ్వనికి ముందు దానికి సంబంధించిన నిఘోష విరామ ధ్వనితో ప్రతిక్షేపించబడుతుంది:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (2వ వర్తమాన కాల వర్గానికి ముఖ్యం) |
| **5. jt ని kt లేదా ṣṭ తో ప్రతిక్షేపించబడుతుంది (ఐచ్ఛికం కాదు!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. ఘోష ఖర్జూర విరామ ధ్వని + నిఘోష విరామ ధ్వని » ఘోష విరామ ఖర్జూర విరామ ధ్వని (బార్థోలోమీయ ఖర్జూర నియమం):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t ని ḍh తో ప్రతిక్షేపించబడుతుంది, దానికి ముందు i లేదా u విస్తరించడం; లేదా gdh తో. అటువంటి ḍh ముందు a ని o తో, అరుదుగా ā తో ప్రతిక్షేపించబడుతుంది:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) "మూసివేయడం"):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::
