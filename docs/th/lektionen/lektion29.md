# บทที่ 29

## 29.1. การใช้ Parasmaipada (⟪परस्मैपद⟫) และ Ātmanepada (⟪आत्मनेपद⟫) ใน Kausativum

::: grammar-box
**Kausativ โดยข้อยกเว้นเล็กน้อยเป็น Ubhayapada (⟪उभयपद⟫)**
:::
::: grammar-box
**ใน Kausativum ใช้ Ātmanepada (⟪आत्मनेपद⟫):**

**1. เมื่อผลของการกระทำที่ก่อเกิดเป็นประโยชน์ต่อผู้ก่อ:**
:::
ตัวอย่าง:

⟪रामः⟫ ⟪कटं⟫ ⟪कारयते⟫ = "Rāma ทำให้เสื่อทำสำหรับตนเอง (เพื่อประโยชน์ของตนเอง)"

**2. เมื่อ Kausativum ของกริยา transitiv ใช้ในเชิงสะท้อน ("แสดงตน" "ทำให้ได้ยิน" ฯลฯ) หรือเมื่อวัตถุของกริยาธรรมดาเป็น Agens (⟪कर्तृ⟫) ของ Kausativ:**

ตัวอย่าง:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "Viṣṇu แสดงตนต่อผู้ภักดีของพระองค์"

ผลลัพธ์: ⟪भक्ता⟫ ⟪विष्णुं⟫ ⟪पश्यन्ति⟫ = "ผู้ศรัทธาเห็น Viṣṇu"

ดังนั้นกฎเหล่านี้โดยทั่วไปสอดคล้องกับกฎสำหรับการใช้ Ātmanepada (⟪आत्मनेपद⟫) ในกริยา Ubhayapada (⟪उभयपद⟫)
