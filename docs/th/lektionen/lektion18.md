## 18.2. ตัตปุรุషะคละ (⟪तत्पुरुष⟫) ที่มีส่วนหน้าเป็นวิเศษณ์

ในฐานะที่เป็นส่วนหน้า (ที่ไม่มีการผัน) ในลักษณะของวิเศษณ์ สามารถ

*   วิเศษณ์
*   คำบุพบท
*   อักขระพิเศษ (Particle)
*   คำที่ไม่มีการผันอื่นๆ

::: indent
ได้ใช้ สัมมาสมาสประเภทตัตปุรุషะดังกล่าวส่วนใหญ่อยู่ในหมวดของ นิตยะสัมมาสะ = ⟪नित्यसमास⟫ (n. "สมาสถาวร") ซึ่งหมายถึงสมาสที่ไม่สามารถแยกความหมายออกได้ หรือไม่สามารถแยกออกได้ด้วยคำที่มีอยู่ในตัวสมาสนั้นเอง
:::
ตัวอย่าง:

⟪अति⟫ "ยิ่งไปกว่านั้น":

::: indent
⟪अतिगुरु⟫ 3: ร้ายแรงอย่างยิ่ง, มีน้ำหนักมาก

⟪अतिपुरुष⟫ m.: ชายที่เหนือกว่า, ซูเปอร์แมน, วีรบุรุษ

⟪अतिस्तुति⟫ f.: คำชมเชยที่เกินควร

⟪अत्युक्ति⟫ f.: การพูดที่เกินควร, คำกล่าวเกินจริง
:::
ส่วนหน้าที่เป็นวิเศษณ์ที่สำคัญที่สุดได้แก่ a-/an-, su-, dus-.

⟪अ⟫ (ก่อนพยัญชนะ), ⟪अन्⟫ (ก่อนสระ): un-: ใช้ในสมาสแทน ⟪न⟫ "ไม่"

ตัวอย่าง:

::: indent
⟪अनृत⟫ n. = ⟪नर्तम्⟫ (= ⟪न⟫ + ⟪ऋतम्⟫): ความไม่จริง, คำโกหก

⟪अकृत⟫ 3 = ⟪न⟫ ⟪कृत⟫ 3: ไม่ได้ทำ, ไม่กระทำ

⟪अब्राह्मणी⟫ f. = ⟪न⟫ ⟪ब्राह्मणी⟫ : หญิงที่ไม่ใช่พราหมณ์, อับราห์มิน

⟪अदेव⟫ m. = ⟪न⟫ ⟪देवः⟫ : เทวดาที่ไม่ใช่, อสุรเทพ
:::
⟪सु⟫ "ดี, ดีงาม"; เมื่อแยกความหมายของสมาส นักอรรถกถาจะแทนที่ด้วยคำคุณศัพท์ที่มีความหมายว่า "ดี" (เช่น ⟪सुष्टु⟫ 3, ⟪शोभन⟫ 3)

ตัวอย่าง:

::: indent
⟪सुकवि⟫ m.: กวีที่ดี

⟪सुकृत⟫ n.: กุศลกรรม

⟪सुखादित⟫ 3: เคี้ยวดี

⟪सुदुःख⟫ n.: ความทุกข์ใหญ่หลวง
:::
⟪दुस्⟫ "เลว, ชั่ว" (โปรดสังเกตสันธินะ!).

ตัวอย่าง:

::: indent
⟪दुर्नय⟫ m.: การนำทางที่เลว, พฤติกรรมที่ไม่ดี

⟪दुष्करण⟫ n.: กุศลกรรมที่เลว, กรรมที่ยากลำบาก
:::
ในกรณีนี้ มีกฎดังนี้:

::: grammar-box

การเปลี่ยนแปลงเสียงของ -s ในสมาส

### 18.2.2. ความหมายของ ตัตปุรุศะประเภท nañ- (a- / an-)

ตัตปุรุศะที่มี a- / an- สามารถมีความหมายดังต่อไปนี้:

1.  ความคล้ายคลึง (⟪तत्सादृश्यम्⟫):  
⟪अब्राह्मणः⟫ = กษัตริย์หรือไวศยะที่สวมสายศักดิ์สิทธิ์ (⟪यज्ञोपवीत⟫ n.) และจึงคล้ายกับพราหมณ์ โดยไม่ใช่พราหมณ์
2.  การขาดหายไป, ความไม่มี (⟪तदभावः⟫):  
⟪अज्ञानम्⟫ = อวิชชา (การขาดความรู้)
3.  ความแตกต่าง (⟪तदन्यत्वम्⟫):  
⟪अपटम्⟫ = สิ่งที่ไม่ใช่ผ้า / เสื้อผ้า (⟪पट⟫ m: ผ้าทอ, เสื้อผ้า)
4.  ความเล็ก (⟪तदल्पता⟫):  
⟪अनुदरम्⟫ = ท้องเล็ก (ท้องที่ไม่ใช่)
5.  การไม่อนุมัติ (⟪अप्राशास्त्यम्⟫):  
⟪अकालः⟫ = อเวลา
6.  ความศัตรู (⟪निरोधः⟫):  
⟪असुरः⟫ = เทวดาตรงข้าม (ตามรากศัพท์ที่ผิด a-sura)

Versต่อไปนี้สรุปความหมายเหล่านี้:

::: indent
⟪तत्सादृश्यमभावश्च⟫  
⟪तदन्यत्वं⟫ ⟪तदल्पता⟫ ⟪।⟫  
⟪अप्राशास्त्यं⟫ ⟪निरोधश्च⟫  
⟪नजर्थाः⟫ ⟪षट्प्रकीर्तिताः⟫ ⟪॥⟫

เราเรียกความหมายหกประการของ nañ (= a-/an-) ....
:::
## 18.3. Verbalkomposita (คำกริยาประสม)

::: indent
⟪उपसर्गेण⟫ ⟪धात्वर्थो⟫  
⟪बलादन्यत्र⟫ ⟪नीयते⟫ ⟪।⟫  
⟪गङ्गासलिलमाधुर्यं⟫  
⟪सागरेण⟫ ⟪यथाम्भसा⟫ ⟪॥⟫
:::
⟪चन्द्रकीर्ति⟫ : ⟪प्रसन्नपदा⟫ น. 2 บรรทัดที่ 14-15

โดยการใช้คำนำหน้ากริยา (preverb) จะเปลี่ยนแปลงความหมายของรากศัพท์อย่างรุนแรง เช่นเดียวกับที่น้ำเค็มจากทะเลเปลี่ยนรสหวานของแม่น้ำคงคา

::: grammar-box

ในภาษาสันสกฤต คำกริยาสามารถเชื่อมกับคำนำหน้ากริยา (⟪उपसर्ग⟫ น.) ได้ โดยทั่วไปจะปฏิบัติตามกฎ Sandhi ของประโยค คำนำหน้ากริยาอาจปรับเปลี่ยนความหมายของรากศัพท์อย่างมีนัยสำคัญ ในหลายกรณีจึงจำเป็นต้องเรียนรู้ความหมายของคำกริยารากศัพท์ที่ประกอบกับคำนำหน้าแยกต่างหาก คำกริยาที่มีคำนำหน้าอาจมีโหมด (P, Ā) ต่างจากรากศัพท์พื้นฐาน สามารถวางคำนำหน้ากริยาได้หลายคำพร้อมกันก่อนรากศัพท์

:::
คำนำหน้ากริยาสำคัญบางคำได้แก่:

### 18.3.1. การสร้างนามศัพท์จากคำกริยาประสม

::: grammar-box

:::
ตัวอย่าง:
