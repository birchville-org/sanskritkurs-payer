# บทที่ 20

## 20.1. พหุพพีหิสมาส = ⟪พหุวฺรีหิ⟫ ปุ.

::: media
![](/images/lekt2004.webp)
Abb.: ⟪बहुव्रीहिः⟫ ⟪पुरुषः⟫
Jodhpur = ⟪जोधपुर⟫
(Bildquelle: [Details](/th/licenses#lekt2004))
:::
⟪बहुव्रीहिः⟫ = ⟪बहवो⟫ ⟪व्रीहयो⟫ ⟪यस्य⟫ ⟪सः⟫ = "ผู้ที่มีข้าวสารมาก"

::: grammar-box

**Bahuvrīhi หมายถึงสิ่งอื่นแตกต่างจาก Tatpuruṣa ซึ่งไม่ได้แสดงออกผ่านองค์ประกอบของมัน: ในขณะที่ ⟪बालपुत्रः⟩ เมื่อแยกเป็น Tatpuruṣa หมายถึง "บุตรหนุ่ม" ซึ่งหมายถึงสิ่งที่แสดงโดยองค์ประกอบสุดท้ายของคำประสม (⟪पुत्र⟩) แต่ ⟪बालपुत्रः⟩ เมื่อแยกเป็น Bahuvrīhi หมายถึง "ผู้ที่มีบุตรหนุ่ม" นั่นคือ สิ่งที่ถูกระบุไม่ใช่ทั้งบุตร (⟪पुत्र⟩) และไม่ได้หมายถึงหนุ่มเสมอไป (⟪बाल⟩) แต่เป็นบุคคลอื่นที่แตกต่างจากบุตรหนุ่ม นั่นคือ บิดาของเขา**

**Possessivkomposita เป็นคำคุณศัพท์เสมอในเบื้องต้น ซึ่งสามารถเปลี่ยนเป็นคำนามได้ ดังนั้น เพศทางไวยากรณ์ของ Bahuvrīhi จึงขึ้นอยู่กับสิ่งที่ Bahuvrīhi อ้างอิงถึง ไม่ใช่เพศขององค์ประกอบสุดท้ายของการประสม**

:::
::: grammar-box

**แผนผังสำหรับการแยก Bahuvrīhi:**

**1. องค์ประกอบหน้าอยู่ในกริยาช่องที่ 1 (⟪प्रथमा⟩) เอกพจน์ ทวิพจน์ หรือ พหูพจน์ -- 2. องค์ประกอบหลังอยู่ในกริยาช่องที่ 1 เอกพาท ทวิพจน์ หรือ พหูพจน์ -- คำคุณศัพท์ในกริยาช่องอื่นที่ไม่ใช่กริยาช่องที่ 1 (มักเป็น Genetiv - ⟪षष्ठी⟩) และในเพศและจำนวนของ Bahuvrīhi ทั้งหมด -- คำคุณศัพท์แสดงปริมาณ จำนวน กรณี และเพศของ Bahuvrīhi ทั้งหมด**

:::
ตัวอย่าง:


::: indent
⟪गतपापः⟩ = ⟪गतं⟩ ⟪पापं⟩ ⟪यस्य⟩ ⟪सः⟩ = "ผู้ที่มีบาปไปแล้ว" = "ผู้ที่ปราศจากกรรมชั่ว"

Akk. sg. ⟪गतपापम्⟩ = ⟪गतं⟩ ⟪पापं⟩ ⟪यस्य⟩ ⟪तम्⟩

Inst. sg. ⟪गतपापेन⟩ = ⟪गतं⟩ ⟪पापं⟩ ⟪यस्य⟩ ⟪तेन⟩

Gen. sg. ⟪गतपापस्य⟩ = ⟪गतं⟩ ⟪पापं⟩ ⟪यस्य⟩ ⟪तस्य⟩

Nom. pl. ⟪गतपापाः⟩ = ⟪गतानि⟩ ⟪पापानि⟩ ye⟪षां⟩ ⟪ते⟩

เป็นต้น

⟪अस्तमोहा⟩ = ⟪अस्तो⟩ ⟪मोहो⟩ ⟪यया⟩ ⟪सा⟩ = "สตรีผู้ได้ละความหลงใหลไปแล้ว"

⟪प्राप्तोदको⟩ ⟪ग्रामः⟩ = ⟪प्राप्तमुदकं⟩ ⟪यं⟩ s ⟨ग्रामः⟩ = "หมู่บ้านที่น้ำได้มาถึงแล้ว" = "หมู่บ้านที่ถูกคุกคามโดยน้ำท่วม"

⟪पुण्यवत्पुत्रः⟩ ในฐานะ Bahuvrīhi = ⟪पुण्यवान्पुत्रो⟩ ⟨यस्य⟩ ⟪सः⟩ หรือ: ⟨पुण्यवन्तः⟩ ⟪पुत्रा⟩ ⟨यस्य⟩ ⟪सः⟩ = "ผู้ที่มีบุตรมีคุณงามความดี" หรือ: "ผู้มีบุตรหลายคนมีคุณงามความดี"
:::
::: grammar-box

**ความสัมพันธ์ระหว่างองค์ประกอบหน้าและหลังใน Bahuvrīhi อาจเป็น:**

*   **attributiv**
*   **appositionell**
*   **kasuell**
*   **adverbial**

**เช่นเดียวกับ Tatpuruṣa องค์ประกอบที่กำหนดรายละเอียดมากกว่ามักอยู่ในตำแหน่งที่สอง**

:::
โดยทั่วไปเราแบ่งแยก:

*   ⟪समानाधिकरणबहुव्रीहिः⟩ : ใน ⟨विग्रहवाक्य⟩ องค์ประกอบหน้าและหลังอยู่ในกริยาช่องเดียวกัน

*   ⟪व्यधिकरणबहुव्रीहिः⟩ : ใน ⟨विग्रहवाक्य⟩ องค์ประกอบหน้าและหลังอยู่ในกริยาช่องต่างกัน


## 20.2. Bahuvrīhi ที่มีองค์ประกอบหน้าแบบ attributiv

::: grammar-box

**แผนผัง:**

:::
::: indent
**คำคุณศัพท์ -- คำนาม**
:::
**ตัวอย่าง:**


::: indent
⟪गुणवत्पुत्रो⟫ ⟪ब्राह्मणः⟫ =  ⟪गुणवान्पुत्रो⟫ ⟪यस्य⟫ ⟪स⟫ ⟪ब्राह्मणः⟫ = "พราหมณ์ผู้ซึ่งมีบุตร / บุตรที่มีคุณสมบัติดี"
:::
**มักพบการกำหนดคุณศัพท์โดย PPP ซึ่งหาได้ยากใน Tatpuruṣa เป็นพิเศษ คำสรรพนามเชิงสัมพันธ์มักอยู่ในกรณีนัย (⟪तृतीया⟫) (หาได้ยากในกรณีเจ้าของ / ⟪षष्ठी⟫).**

**กฎทั่วไป:**

*   **PPP - คำนาม = ส่วนใหญ่เป็น Bahuvrīhi**
*   **คำนาม -- PPP = ส่วนใหญ่เป็น Tatpuruṣa**

**ตัวอย่าง:**

::: indent
⟪कृतफल⟫ ⟪३⟫ = ⟪कृतं⟫ ⟪फलं⟫ ye⟪न⟫ ⟪सः⟫ ⟪।⟫ ⟪यया⟫ ⟪सा⟫ ⟪।⟫ ye⟪न⟫ ⟪तत्⟫ = "ผู้หนึ่ง / ผู้หญิงหนึ่ง / สิ่งหนึ่ง ซึ่งได้อุบัติผลขึ้นมา ใครบางคน / บางสิ่งที่มีประสิทธิภาพ"
:::
## 20.3. Bahuvrīhi ที่มีส่วนหน้าเป็นคำคุณศัพท์

::: grammar-box

**แผนผัง:**

:::
::: indent
**คำนาม -- คำนาม**
:::
**ตัวอย่าง:**

::: indent
⟪शूरपुत्रो⟫ ⟪नरः⟫ = ⟪शूरा⟫ ⟪एव⟫ ⟪पुत्रा⟫ ⟪यस्य⟫ ⟪स⟫ ⟪नरः⟫ = "ชายผู้ซึ่งมีบุตรเป็นวีรบุรุษ"

⟪तदन्त⟫ ⟪३⟫ = ⟪सो⟫ ⟪ऽन्तो⟫ ⟪यस्य⟫ ⟪सः⟫ ⟪।⟫ ⟪यस्याः⟫ ⟪सा⟫ ⟪।⟫ ⟪यस्य⟫ ⟪तत्⟫ = "ผู้ซึ่ง / ผู้หญิงซึ่ง / สิ่งซึ่ง ซึ่งมีจุดจบนี้" = "ผู้ซึ่งสิ้นสุดด้วยสิ่งนี้"
:::
::: grammar-box

**Bahuvrīhi แบบคำคุณศัพท์ที่มีส่วนท้ายเป็น ⟪आदि⟫ ⟪।⟫ ⟪आदिक⟫ ⟪।⟫ ⟪आद्य⟫ "แรก, จุดเริ่มต้น" มีความสำคัญมาก หาได้ยาก ⟪प्रभृति⟫ "จุดเริ่มต้น" คำประสมดังกล่าวสอดคล้องกับ "และอื่นๆ":**

**ตัวอย่าง:**

:::
::: indent
⟪देवा⟫ ⟪इन्द्रादयः⟫ =  ⟪इन्द्र⟫ ⟪आदिर्येषां⟫ ⟪ते⟫ ⟪देवाः⟫ = "เทพเจ้าผู้ซึ่งมีจุดเริ่มต้นเป็นอินทร์" = "เทพเจ้าอินทร์และอื่นๆ" = "อินทร์และเทพเจ้าที่เหลือ"
:::
**เพื่อแสดงถึง "เพียง" สามารถใช้ Bahuvrīhi ที่มี ⟪मात्रा⟫ f. "ขนาด, ขอบเขต" เป็นส่วนท้ายได้:**

**ตัวอย่าง:**

**ตัวอย่าง:**

::: indent

## 20.4. Bahuvrīhi ที่มีส่วนหน้าเป็นกรณี

นั่นคือ Bahuvvrīhi ซึ่งส่วนหน้าแทนกรณีนอกเหนือจาก nominative (⟪प्रथमा⟫)

ตัวอย่าง:

::: indent
⟪देवरूपा⟫ = ⟪देवस्यैव⟫ ⟪रूपं⟫ ⟪यस्याः⟫ ⟪सा⟫ = "หญิงผู้ซึ่งมีรูปร่างเป็นเทพ" "ผู้หญิงที่มีลักษณะเหมือนเทพ"

## 20.5. Bahuvrīhi ที่มีส่วนหน้าเป็นคำวิเศษณ์


ในส่วนหน้าของคำประกอบ มีกริยาวิเศษณ์ คำบุพบท หรือคำนำหน้าคำกริยา (preverb) หรือนามอนิยมอื่น ๆ อยู่ โดยทั่วไปแล้วคำประกอบประเภทนี้คือ ⟪नित्यसमास⟫

ตัวอย่าง:

::: indent
⟪अपुत्रो⟫ ⟪नरः⟫ = ⟪पुत्रो⟫ ⟪यस्य⟫ ⟪नास्ति⟫ ⟪स⟫ ⟪नरः⟫ = "ชายที่ไม่มีบุตร" = "ชายไร้บุตร"

⟪दुर्बल⟫ ⟪३⟫ = "ผู้/สิ่งที่มีกำลังไม่ดี" = "อ่อนแรงแรงงาน"
:::
::: grammar-box

**⟪सह⟫ "กับ" ในฐานะส่วนหน้าของ Bahuvrīhi มักจะถูกแทนที่ด้วย ⟪स⟫**

**ตัวอย่าง:**

:::
::: indent
⟪सपुत्रः⟫ =  ⟪सहपुत्रः⟫ =  ⟪पुत्रेण⟫ ⟪सहितः⟫ ⟪।⟫ ⟪पुत्रेण⟫ ⟪सह्⟫ = "มีบุตร" "ติดตามด้วยบุตร"

## 20.6 การผันรูปส่วนท้ายของ Bahuvrīhi

::: grammar-box

**ส่วนท้ายของ Bahuvrīhi จะถูกผันเป็นคำคุณศัพท์หลายเพศ โดยไม่คำนึงถึงเพศเดิมของมัน ดังนั้นหากในคำประกอบหนึ่ง ๆ ส่วนท้ายมีเพศต่างจากเพศเดิมของมัน คำนั้นจะต้องเป็น Bahuvrīhi เว้นแต่จะเป็น Samāhāradvanva (กลางเอกพจน์)**

**ในการทำให้เป็นคำคุณศัพท์**

*   **-ā-stems ในเพศชายและกลาง กลายเป็น -a-stems**
*   **-a-stems (ชาย, กลาง) สร้างเพศหญิงของพวกมันด้วย -ā หรือ -ī**
*   **-ī-stems (หญิง) ต้องรับคำลงท้าย -ka, -kā, -ka (กลาง) ที่ส่วนท้ายของ Bahuvrīhi; คำลงท้ายนี้คำอื่น ๆ ของ Bahuvrīhi หลายคำก็สามารถหรือต้องรับได้เช่นกัน**

:::
## 20.7 การจัดประเภทอื่น ๆ ของ Bahuvrīhi

ตัวอย่างเหล่านี้ให้ไว้สำหรับการทบทวนในภายหลัง สำหรับบางตัวอย่างนั้นไวยากรณ์และคำศัพท์ที่จำเป็นยังไม่ได้กล่าวถึง

1. คำระบุลักษณะในส่วนหน้า -- คำที่ถูกกำหนดลักษณะในส่วนหลัง: ⟪स्थिरचित्तः⟫ = ⟪स्थिरं⟫ ⟪चित्तं⟫ ⟪यस्य⟫ ⟪सः⟫
2. นามอนิยมในส่วนหน้า: ⟪उच्चैःश्रवस्⟫
3. การเปรียบเทียบในส่วนหน้า: ⟪कुशाग्रधीः⟫ =  ⟪कुशाग्र⟫ ⟪इव⟫ ⟪धीर्यस्य⟫ ⟪सः⟫
4. การเปรียบเทียบโดยนัย: ⟪उष्ट्रमुखः⟫ = ⟪उष्ट्रस्य⟫ ⟪मुखमिव⟫ ⟪मुखं⟫ ⟪यस्य⟫ ⟪सः⟫ = "ปากอูฐ" = ผู้ที่มีปากเหมือนอูฐ
5. เลขจำนวนเป็นคำส่วนหลังสำหรับตัวเลขโดยประมาณ: ⟪उपसशाः⟫ = ⟪दशानां⟫ ⟪समीपे⟫ ⟪ये⟫ ⟪सन्ति⟫ ⟪ते⟫ = "ประมาณสิบ"
6. ทั้งสองส่วนเป็นเลขจำนวน: ⟪एकद्वाः⟫ = ⟪एको⟫ ⟪वा⟫ ⟪द्वौ⟫ ⟪वा⟫ = "หนึ่งหรือสอง"
7. ด้วย sa-/saha- ในส่วนหน้า: ⟪सपुत्रः⟫ ⟪।⟫ ⟪सहपुत्रः⟫
8. ด้วย sa- (= ⟪समान⟫) ในส่วนหน้า: ⟪सजनपदः⟫ = ⟪समानो⟫ ⟪जनपदो⟫ ⟪यस्य⟫ ⟪सः⟫

## 20.8. ความสัมพันธ์ระหว่าง Bahuvrīhi และประโยคสัมพันธะ

แม้ว่าจะสามารถขยายความ Bahuvrīhi ทุกชนิดด้วยประโยคสัมพันธะได้ แต่ไม่สามารถแทนที่ประโยคสัมพันธะทุกประเภทด้วย Bahuvrīhi ได้ Hermann Georg Jacobi (1850 - 1937) ซึ่งได้ศึกษาความสัมพันธ์ระหว่างทั้งสองอย่างใกล้ชิดยิ่งขึ้น (Compositum und Nebensatz, 1897) ได้เขียนไว้ว่า:

:::
