# บทที่ 35

## 35.1. Perfecto Tipo III: รากที่แข็งแรง ระดับสูง/ระดับขยาย

::: grammar-box
**การสร้าง:**

**รากที่แข็งแรง:**
*   3.sg.P: ระดับขยาย
*   2.sg.P: ระดับสูง
*   1.sg.P: ระดับสูงหรือระดับขยายตามตัวเลือก

**รากที่อ่อน:** ดูในส่วนย่อย
:::
### 35.1.1. Perfecto Tipo IIIa: รากที่แข็งแรง ระดับสูง/ระดับขยาย, รากที่อ่อน ระดับต่ำ

::: grammar-box
**การสร้าง:**

:::
::: indent
**รากที่อ่อน:** ระดับต่ำ
:::
สร้างจากรากของประเภท:
*   (พยัญชนะ)-(พยัญชนะ) - i/ī/u/ū
*   (พยัญชนะ) - ṛ

ก่อนทวิภาคที่ขึ้นต้นด้วยสระจะถูกแทนที่โดย:
*   -i/-ī โดย -iy
*   -u/-ū โดย -uv
*   -ṛ durch r
ตัวอย่าง:

| ราก | 3. sg. Perfecto P. | 3. pl. Perfecto P. | 3. sg. Perfecto Ā. | 3. pl. Perfecto Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:bri + iy + ur | | |
| ⟪नी⟫ 1U | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2U | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

## 35.2. Perfecto Tipo IV: รากที่ลงท้ายด้วย -ā / -āi

::: grammar-box
**การสร้าง:**

**รากที่แข็งแรง:**
*   3./1. sg. P Perfecto ลงท้ายด้วย -au
*   2\. sg. P : ระดับสูง -ā หรือระดับต่ำ -i

**รากที่อ่อน:**
*   ก่อนพยัญชนะ: ระดับต่ำ -i
*   ก่อนสระ: ระดับต่ำ Ø

สร้างจากรากที่ลงท้ายด้วย -ā / -āi
:::
ตัวอย่าง:

| ราก | 3. sg. Perfecto P.:br1. sg. Perfecto P. | 3. pl. Perfecto P. | 3. sg. Perfecto Ā. | 3. pl. Perfecto Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪ददौ⟫ | ⟪ददुर्⟫:brda-d-ur | ⟪ददे⟫ | ⟪ददिरे⟫:brda-d-i-re |

## 35.3. Perfecto Tipo V: ราก พยัญชนะ-a-พยัญชนะ

::: grammar-box
**การสร้าง:**

**รากที่แข็งแรง:**
*   3.sg.P: ระดับขยาย
*   2.sg.P: ระดับสูง
*   1.sg.P: ระดับสูงหรือระดับขยายตามตัวเลือก

**รากที่อ่อน:** ดูในส่วนย่อย

สร้างจากรากของประเภท (พยัญชนะ)-พยัญชนะ-a-พยัญชนะ
:::
### 35.3.1. Perfecto Tipo Va: รากที่อ่อน ระดับต่ำ

::: grammar-box
**การสร้าง:**

:::
::: indent
**รากที่อ่อน:** ระดับต่ำ
:::
สร้างจากรากต่างๆ เช่น:
*   ⟪गम्⟫
*   ⟪हन्⟫
*   ⟪जन्⟫
*   ⟪वच्⟫
*   ⟪वद्⟫
*   ⟪यज्⟫

### 35.3.2. ประเภทของ Perfectus Vb: รากคำอ่อน การลดรูป (ประเภท e)

::: grammar-box
**การสร้าง:**

:::
::: indent
**รากคำอ่อน:** ไม่มีการซ้ำพยางค์ (Reduplikation) แทนที่ -a- ของรากคำด้วย -e-  
(ดูคำอธิบายใน Thumb-Hauschild 1,2 หน้า 286f.)
:::
สร้างจากรากคำที่มี -a- อยู่ระหว่างพยัญชนะสองตัว ซึ่งพยัญชนะต้นของพยางค์ซ้ำไม่มีการเปลี่ยนแปลง (นั่นคือ พยัญชนะต้นไม่ใช่ Gutural, Aspirate หรือ h)
ตัวอย่าง:

| รากคำ | 3. sg. Perfectus P. | 3. pl. Perfectus P. | 3. sg. Perfectus Ā. | 3. pl. Perfectus Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 1U | ⟪पपाच⟫ | :sig[⟪पे⟫]⟪चुर्⟫ | :sig[⟪पे⟫]⟪चे⟫ | :sig[⟪पे⟫]⟪चिरे⟫ |

### 35.3.3. ประเภทของ Perfectus Vc: รากคำพยัญชนะ-a-พยัญชนะ รากคำอ่อน ระดับสูง

::: grammar-box
**การสร้าง:**

**รากคำอ่อน:** ระดับสูง (ระดับเสียงสูง)

สร้างจากรากคำอื่นๆ ทั้งหมดที่มี -a- อยู่ตรงกลาง นั่นคือ รากคำที่มี -a- อยู่ตรงกลาง
*   ที่เริ่มด้วยพยัญชนะสองตัว
*   ที่เริ่มด้วย Gutural
*   ที่เริ่มด้วย Aspirate
*   ที่เริ่มด้วย h

เว้นแต่จะอยู่ในประเภท Perfectus Va
:::
ตัวอย่าง:

| รากคำ | 3. sg. Perfectus P. | 3. pl. Perfectus P. | 3. sg. Perfectus Ā. | 3. pl. Perfectus Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪क्रम्⟫ 1U | ⟪चक्राम⟫ | ⟪चक्रमुर्⟫ | ⟪चक्रमे⟫ | ⟪चक्रमिरे⟫ |
