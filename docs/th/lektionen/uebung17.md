# แบบฝึกหัด 17

ก) จงใส่กริยาในประโยคต่อไปนี้แล้วแปล:

⟪१⟫. ⟪ब्राह्मनो⟫ ⟪ऽनृतं⟫ ⟪न⟫ ... (⟪ब्रू⟫ ⟪।⟫ ⟪वच्⟫ ⟪।⟫ ⟪वद्⟫) ⟪।⟫
⟪ब्रवीति⟫ ⟪।⟫ ⟪वक्ति⟫ ⟪।⟫ ⟪वदति⟫ ⟪।⟫
พราหมณ์ไม่พูดเท็จ

⟪२⟫. ⟪क्षत्रियो⟫ ⟪जनान्⟫ ... (⟪पा⟫ ⟪।⟫ ⟪रक्ष्⟫) ⟪।⟫
⟪पाति⟫ ⟪।⟫ ⟪रक्षति⟫ ⟪।⟫
กษัตริย์ดูแลประชาชน

⟪३⟫. ⟪बलवद्योधो⟫ ⟪द्विजारीन्⟫ ... (⟪जि⟫ ⟪।⟫ ⟪हन्⟫ ⟪।⟫ ⟪युध्⟫) ⟪।⟫
⟪द्विजारीञ्जयति⟫ ⟪।⟫ ⟪द्विजारीन्हन्ति⟫ ⟪।⟫ ⟪युध्यते⟫ ⟪।⟫
นักรบผู้ทรงพลังชนะ / ฆ่า / ต่อสู้กับศัตรูของสองครั้งเกิด

⟪४⟫. ⟪ब्राह्मणकविर्लोकेश्वरम्⟫ ... (⟪स्तु⟫ ⟪।⟫ ⟪यज्⟫) ⟪।⟫
⟪स्तौति⟫ ⟪।⟫ ⟪स्तुते⟫ ⟪।⟫ ⟪यजते⟫ ⟪।⟫ ⟪यजति⟫ ⟪।⟫
กวีพราหมณ์สรรเสริญพระผู้เป็นเจ้าแห่งโลก (หรือ: ...บูชา...ต่อพระผู้เป็นเจ้าแห่งโลก)

⟪५⟫. ⟪अग्निर्यज्ञान्नम्⟫ ... (⟪अद्⟫ ⟪।⟫ ⟪दह्⟫) ⟪।⟫
⟪अत्ति⟫ ⟪।⟫ ⟪दहति⟫ ⟪।⟫
ไฟเผา / รับประทานอาหาร

⟪६⟫. ⟪बालवैश्यो⟫ ⟪धेनुम्⟫ ... (⟪दुह्⟫ ⟪।⟫ ⟪रक्ष्⟫ ⟪।⟫ ⟪पा⟫) ⟪।⟫
⟪दोग्धि⟫ ⟪।⟫ ⟪दुग्धे⟫ ⟪।⟫ ⟪रक्षति⟫ ⟪।⟫ ⟪पाति⟫ ⟪।⟫
วัยหนุ่มไวศยะรีดนม / เลี้ยงดูวัว

⟪७⟫. ⟪द्विजदासो⟫ ⟪मृगमार्गेण⟫ ⟪ब्राह्मणग्रामम्⟫ ... (⟪गम्⟫ ⟪।⟫ ⟪इ⟫ ⟪।⟫ ⟪पद्⟫) ⟪।⟫
⟪गच्छति⟫ ⟪।⟫ ⟪एति⟫ ⟪।⟫ ⟪पद्यते⟫ ⟪।⟫
ทาสของสองครั้งเกิดเดินบนทางป่าไปยังหมู่บ้านพราหมณ์

⟪८⟫. ⟪द्विजदासः⟫ ⟪शूद्रस्⟫ ... (⟪अस्⟫ ⟪२⟫ ⟪।⟫ ⟪भू⟫) ⟪।⟫
⟪द्विजदासः⟫ ⟪शूद्रो⟫ ⟪ऽस्ति⟫ ⟪।⟫ ... ⟪शूद्रो⟫ ⟪भवति⟫ ⟪।⟫
Ein Śūdra ist Knecht der Zweimalgeborenen.

⟪९⟫. ⟪बालब्राह्मणी⟫ ... (⟪रुद्⟫ ⟪।⟫ ⟪आस्⟫ ⟪।⟫ ⟪मृ⟫) ⟪।⟫
⟪रोदिति⟫ ⟪।⟫ ⟪बालब्राह्मण्याते⟫ ⟪।⟫ ⟪म्रियते⟫ ⟪।⟫
พราหมณีตัวน้อยร้องไห้ / นั่ง / ตาย

⟪१०⟫. ⟪साधुजनो⟫ ⟪ऽधर्मम्⟫ ... (⟪द्विष्⟫ ⟪।⟫ ⟪न⟫ ⟪कृ⟫) ⟪।⟫
⟪द्वेष्टि⟫ ⟪।⟫ ⟪द्विष्टे⟫ ⟪।⟫ ⟪न⟫ ⟪करोति⟫ ⟪।⟫ ⟪न⟫ ⟪कुरुते⟫ ⟪।⟫
บุคคลที่ดีเกลียดความอยุติธรรม (หรือ: ...ไม่กระทำผิด...)

ข) จงใส่กริยาและประธานในพหูพจน์ของประโยคที่สร้างไว้ใน ก)

⟪१⟫. ⟪ब्राह्मणा⟫ ⟪अनृतं⟫ ⟪न⟫ ⟪ब्रुवन्ति⟫ ⟪।⟫ (พหูพจน์ของ ⟪वच्⟫ ไม่ปรากฏ) ⟪।⟫ ⟪वदन्ति⟫ ⟪।⟫

⟪२⟫. ⟪क्षत्रिया⟫ ⟪जनान्पान्ति⟫ ⟪।⟫ ⟪रक्षन्ति⟫ ⟪।⟫

⟪३⟫. ⟪बलवद्योधा⟫ ⟪द्विजारीञ्जयन्ति⟫ ⟪।⟫ ... ⟪द्विजारीन्घन्ति⟫ ⟪।⟫ ⟪युध्यन्ते⟫ ⟪।⟫

⟪४⟫. ⟪ब्राह्मणकवयो⟫ ⟪लोकेश्वरं⟫ ⟪स्तुवन्ति⟫ ⟪।⟫ ⟪स्तुवते⟫ ⟪।⟫ ⟪यजन्ति⟫ ⟪।⟫ ⟪यजन्ते⟫ ⟪।⟫

⟪५⟫. ⟪अग्नयो⟫ ⟪यज्ञान्नमदन्ति⟫ ⟪।⟫ ⟪दहन्ति⟫ ⟪।⟫

⟪६⟫. ⟪बालवैश्या⟫ ⟪धेनुं⟫ ⟪दुहन्ति⟫ ⟪।⟫ ⟪दुहते⟫ ⟪।⟫ ⟪रक्षन्ति⟫ ⟪।⟫ ⟪पान्ति⟫ ⟪।⟫

⟪७⟫. ⟪द्विजदासा⟫ ⟪मृगमार्गेण⟫ ⟪ब्राह्मणग्रामं⟫ ⟪गच्छन्ति⟫ ⟪।⟫ ⟪यन्ति⟫ ⟪।⟫ ⟪पद्यन्ते⟫ ⟪।⟫

⟪८⟫. ⟪द्विजदासाः⟫ ⟪शूद्राः⟫ ⟪सन्ति⟫ ⟪।⟫ ... ⟪शूद्रा⟫ ⟪भवन्ति⟫ ⟪।⟫

⟪९⟫. ⟪बालब्राह्मण्या⟫ ⟪रुदन्ति⟫ ⟪।⟫ ⟪बालब्राह्मण्य⟫ ⟪आसते⟫ ⟪।⟫ ⟪बालब्राह्मण्यो⟫ ⟪म्रियन्ते⟫ ⟪।⟫

⟪१०⟫. ⟪साधुजनो⟫ ⟪ऽधर्मं⟫ ⟪द्विषन्ति⟫ ⟪।⟫ ⟪द्विषते⟫ ⟪।⟫ ⟪न⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪न⟫ ⟪कुर्वते⟫ ⟪।⟫

## แบบฝึกหัดรูปกริยา

จงแปลรูปกริยาดังต่อไปนี้และระบุรากศัพท์ที่เกี่ยวข้อง:

⟪१⟫. ⟪अदन्ति⟫ (⟪अद्⟫ 2P): พวกเขากิน

⟪२⟫. ⟪सन्ति⟫ (⟪अस्⟫ 2P): พวกเขาเป็น

⟪३⟫. ⟪आसते⟫ (⟪आस्⟫ 2Ā): พวกเขา นั่ง

⟪४⟫. ⟪यन्ति⟫ (⟪इ⟫ 2P): พวกเขา เดิน

⟪५⟫. ⟪इच्छति⟫ (⟪इष्⟫ 6P): เขา ต้องการ

⟪६⟫. ⟪कुर्वते⟫ (⟪कृ⟫ 8U): พวกเขา ทำ (เพื่อประโยชน์ของตนเอง)


⟪७⟫. ⟪गच्छन्ति⟫ (⟪गम्⟫ 1P): พวกเขากำลังไป

⟪८⟫. ⟪जायते⟫ (⟪जन्⟫ 4Ā): เขาเกิดขึ้น

⟪९⟫. ⟪जयति⟫ (⟪जि⟫ 1P): เขาชนะ

⟪१०⟫. ⟪तनोति⟫ (⟪तन्⟫ 8U): เขาตึง

⟪११⟫. ⟪दहति⟫ (⟪दह्⟫ 1P): เขาเผา

⟪१२⟫. ⟪दोग्धि⟫ (⟪दुह्⟫ 2U): เขารีดนม

⟪१३⟫. ⟪पश्यति⟫ (⟪दृश्⟫ 4P): เขาเห็น

⟪१४⟫. ⟪द्विष्टे⟫ (⟪द्विष्⟫ 2U): เขาเกลียด

⟪१५⟫. ⟪नयन्ति⟫ (⟪नी⟫ 1U): พวกเขาพาไป

⟪१६⟫. ⟪नृत्यति⟫ (⟪नृत्⟫ 4P): เขาเต้น

⟪१७⟫. ⟪पद्यन्ते⟫ (⟪पद्⟫ 4Ā): พวกเขาเดิน

⟪१८⟫. ⟪पिबति⟫ (⟪पा⟫ 1P): เขาดื่ม

⟪१९⟫. ⟪पान्ति⟫ (⟪पा⟫ 2P): พวกเขาเลี้ยง

⟪२०⟫. ⟪पृच्छति⟫ (⟪प्रच्छ्⟫ 6P): เขาถาม

⟪२१⟫. ⟪बुध्यन्ते⟫ (⟪बुध्⟫ 4Ā): พวกเขาตื่น

⟪२२⟫. ⟪ब्रवीति⟫ (⟪ब्रू⟫ 2U): เขาพูด

⟪२३⟫. ⟪भवन्ति⟫ (⟪भू⟫ 1P): พวกเขาเป็น

⟪२४⟫. ⟪मन्यते⟫ (⟪मन्⟫ 4Ā): เขาคิด

⟪२५⟫. ⟪मुञ्चन्ति⟫ (⟪मुच्⟫ 6U): พวกเขาปลดปล่อย

⟪२६⟫. ⟪म्रियन्ते⟫ (⟪मृ⟫ 4Ā): พวกเขาตาย

⟪२७⟫. ⟪यजते⟫ (⟪यज्⟫ 1U): เขาทำพิธีบูชาในฐานะเจ้าพิธี

⟪२८⟫. ⟪युध्यन्ते⟫ (⟪युध्⟫ 4Ā): พวกเขาต่อสู้

⟪२९⟫. ⟪रक्षति⟫ (⟪रक्ष्⟫ 1P): เขาเลี้ยง

⟪३०⟫. ⟪रोदिति⟫ (⟪रुद्⟫ 2P): เขาเห่า

⟪३१⟫. ⟪लभते⟫ (⟪लभ्⟫ 1Ā): เขาได้รับ

⟪३२⟫. ⟪वक्ति⟫ (⟪वच्⟫ 2P): เขาพูด

⟪३३⟫. ⟪वदति⟫ (⟪वद्⟫ 1P): เขาพูด

⟪३४⟫. ⟪शृणोति⟫ (⟪श्रु⟫ 5P): เขาได้ยิน

⟪३५⟫. ⟪स्तौति⟫ (⟪स्तु⟫ 2U): เขาสรรเสริญ

⟪३९⟫. ⟪कुप्यते⟫ (⟪कुप्⟫ 4P): มันถูกโกรธ

⟪४०⟫. ⟪कर्षन्ति⟫ (⟪कृष्⟫ 6U): พวกเขาเคลื่อนย้าย

⟪४१⟫. ⟪उद्यते⟫ (⟪वद्⟫ 1P): มันถูกกล่าว

⟪४२⟫. ⟪सहन्ते⟫ (⟪सह्⟫ 1Ā): พวกเขาทน

⟪४३⟫. ⟪सिच्यन्ते⟫ (⟪सिच्⟫ 6U): พวกเขาถูกหยด

⟪४४⟫. ⟪आप्नोति⟫ (⟪आप्⟫ 5P): เขาบรรลุ

⟪४६⟫. ⟪दिश्यन्न्ते⟫ (⟪दिश्⟫ 6U): พวกเขาถูกแสดง
