## 36.2. Perfect แบบ Periphrastic (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
Perfect แบบ Periphrastic (⟪अनुप्रयोगलिट्⟫) ใช้ในกรณี:

1. ในกลุ่มการผันที่มาจากอนุพันธ์ (Kausativ, Desiderativ, Frequentativ, Denominativa)
2. ในรากศัพท์ที่เริ่มต้นด้วยสระยาว (ยกเว้น ā-) หรือด้วยสระ (ยกเว้น a-) นำหน้าโดยพยัญชนะสองตัว
3. ในรากศัพท์อื่นๆ บางส่วน
:::
::: grammar-box
**การสร้าง:**

ราก Present (อ่อน) + -ām + รูป Perfect ที่สอดคล้องกันของ ⟪कृ⟫, ⟪अस्⟫ หรือ ⟪भू⟫

- Auslautender Stammvokal wird vor -ām guṇiert.
- ⟪अस्⟫ และ ⟪भू⟫ ยังถูกผันใน Parasmaipada สำหรับกริยา Ātmanepada ด้วย
:::
Das periphrastische Perfekt ist wohl aus dem Akkusativ eine Verbalnomens auf -ā entstanden. Dieser Akkusativ wird -- wie auch sonst oft -- adverbial verwendet.

## 36.5. แบบฝึกหัด

A) รากศัพท์ต่อไปนี้มีทั้ง Perfect ที่มีการซ้ำคำ (redupliziertes) และแบบรอบนัย (periphrastisches) จงสร้างรูป Perfect แบบรอบนัยและแบบซ้ำคำที่สอดคล้องกับรูปแบบต่อไปนี้:

1.  ⟪बिभ्रते⟫
2.  ⟪बिभ्यति⟫
3.  ⟪जुहोति⟫
4.  ⟪वेत्ति⟫

B) รากศัพท์ ⟪आस्⟫ "นั่ง" มี Perfect แบบรอบนัย จงสร้างรูปนี้ให้กับรูปแบบต่อไปนี้:

1.  ⟪आस्ते⟫
2.  ⟪आसते⟫

C) จงสร้างรูป Perfect ที่สอดคล้องกับรูปแบบต่อไปนี้:

1.  ⟪जीयते⟫
2.  ⟪विदन्ति⟫
3.  ⟪विन्दति⟫
4.  ⟪त्याजयिष्यति⟫

11.  ⟪क्रामन्ति⟫
