# แบบฝึกหัด 9

A) พยายามกำหนดความหมายที่เป็นไปได้ของคำต่อไปนี้:

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. ผู้ที่คล้ายกับพราหมณ์เพียงอย่างเดียว = พราหมณ์ชั้นเลว

2\. mati ⟪मति⟫ : f. ความเห็น

3\. śravaṇa ⟪श्रवण⟫ : n. หู

4\. dhenuka ⟪धेनुक⟫ : m. (การร่วมเพศ) ในลักษณะของวัว

5\. jayaka ⟪जयक⟫ : 3 ผู้ชนะ

6\. rakṣikā ⟪रक्षिका⟫ : f. ผู้รักษา, ยันต์

7\. karṣaka ⟪कर्षक⟫ : 3 กำลังไถ ; m. ชาวนา

8\. kleśa ⟪क्लेश⟫ : m. ความทุกข์

9\. nāyikātva ⟪नायिकात्व⟫ : n. สถานะของหญิงคนรัก

10\. tantraka ⟪तन्त्रक⟫ : 3 (เพิ่ง) มาจากเส้นด้ายยืน / เครื่องทอผ้า = ทอใหม่

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : นักเต้น

12\. naraka ⟪नरक⟫ : m. นรก

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. การเป็นเจ้า

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. นักสู้

17\. kopa ⟪कोप⟫ : m. โกรธ

18\. veśaka ⟪वेशक⟫ : 3 กำลังเข้าสู่

19\. darśaka ⟪दर्शक⟫ : 3 กำลังดู

20\. kopaka ⟪कोपक⟫ : 3 ผู้ที่โกรธง่าย, หงุดหงิดง่าย

B) จงแปล:

1\. หน้าที่ของชนสองครั้งเกิดทั้งหมด:

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

(Yājñavalkyadharmaśāstra I, 118)

การบูชา, การศึกษาพระเวท, การให้ทาน.

2\. หน้าที่เฉพาะของพราหมณ์:

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

(Gautamadharmasūtra X,2)

การสอน, การบูชาแทน, การรับทาน.

3\. หน้าที่เฉพาะของกษัตริย์:

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं⟫ ⟪सर्वभूतानाम्⟫

(sarvabhūtānām = Genetiv (กรณีเจ้าของ): "ของสรรพสัตว์")

(Gautamadharmasūtra X,7)

การปกป้องสรรพสัตว์.

4\. หน้าที่เฉพาะของไวศยะ:

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(ตาม Gautamadharmasūtra X,49)

การทำนา, การค้าขาย, การเลี้ยงสัตว์ และการให้กู้ยืม.

5\. หน้าที่ของศูทร:

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं⟫ ⟪शुश्रूषा⟫ ⟪वार्त्त्ता⟫ ⟪कारुकुशीलवकर्म⟫ ⟪च⟫

(ตาม Kauṭilīya-arthaśāstra 1.3.8.)

คำอธิบาย:
dvijātīnām = Genetiv (กรณีเจ้าของ) พหูพจน์ของ dvijāti (แปลที่นี่ว่า "ต่อหน้าชนสองครั้งเกิด")

kārukuśīlavakarma เป็น Tatpuruṣa ที่มี Dvandva (kārukuśīlava) อยู่ข้างหน้า. karma = Nom. sg. ของ karman n. "การกระทำ, กิจกรรม, กัมมะ" จากรากศัพท์ kṛ 8 U). จงแปล "การกระทำ / กิจกรรมของ ... (กรณีเจ้าของ)" (ตามที่ระบุโดย Dvandva).

ความเชื่อฟังต่อชนสองครั้งเกิด, กิจกรรมเพื่อเลี้ยงชีพ, การทำงานเป็นช่างฝีมือหรือผู้แสดงเร่ร่อน.

6\. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः⟫ ⟪पाशुपाल्यं⟫ ⟪वणिज्या⟫ ⟪च⟫ ⟪वार्त्ता⟫

(ตาม Kauṭilīya-arthaśāstra 1.4.1.)

เศรษฐกิจคือการทำนา การเลี้ยงสัตว์ และการค้าขาย.
