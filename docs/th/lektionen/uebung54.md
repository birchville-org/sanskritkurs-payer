# แบบฝึกหัด 54

จงสร้างรูป Aorist ที่สอดคล้องกับกริยาปัจจุบันหรือ Perfect ต่อไปนี้:

::: grammar-box
| ลำดับที่ | รูป | คำจำกัดความ / ความหมาย | Aorist |
|:---|:---|:---|:---|
| ⟪१⟫. | ⟪यन्ति⟫ | พวกเขาไป | ⟪अगुः⟫ |
| ⟪२⟫. | ⟪पिबामि⟫ | ฉันดื่ม | ⟪अपाम्⟫ |
| ⟪३⟫. | ⟪ददौ⟫ | ฉัน/เขาให้ | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | ⟪बभूव⟫ | ฉัน/เขา/พวกเขาเป็น/เคยอยู่ | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | ⟪दधति⟫ | พวกเขาตั้ง/วาง | ⟪अधुः⟫ |
| ⟪६⟫. | ⟪ऐम⟫ | เราไป | ⟪अगाम⟫ |
| ⟪७⟫. | ⟪पपिथ⟫ | คุณดื่ม/คุ้มครอง | ⟪अपाः⟫ (จาก sig[⟪पा⟫] "ดื่ม") |
| ⟪८⟫. | ⟪तिष्ठति⟫ | เขาตั้ง/ยืน | ⟪अस्थात्⟫ |

| ⟪१०⟫. | ⟪पप⟫ | พวกคุณดื่ม | ⟪अपात⟫ |
| ⟪११⟫. | ⟪एष्यथ⟫ | พวกคุณจะไป | ⟪अगात⟫ |
| ⟪१२⟫. | ⟪तस्थुः⟫ | พวกเขาตั้ง/ยืน | ⟪अस्थुः⟫ |
| ⟪१३⟫. | ⟪अधत्त⟫ | พวกคุณตั้ง/วาง | ⟪अधात⟫ |
| ⟪१४⟫. | ⟪अददाः⟫ | คุณให้ | ⟪अदाः⟫ |
| ⟪१५⟫. | ⟪अभवन्⟫ | พวกเขาเป็น/เคยอยู่ | ⟪अभूवन्⟫ |
| ⟪१६⟫. | ⟪ददिम⟫ | เราให้ | ⟪अदाम⟫ |
| ⟪१७⟫. | ⟪भिद्यते⟫ | มันจะถูกแยก/ผ่า | ⟪अभेदि⟫ |
| ⟪१८⟫. | ⟪उद्यते⟫ | มันจะถูกกล่าว/พูด | ⟪अवादि⟫ |

| ⟪२०⟫. | ⟪कृष्यते⟫ | มันจะถูกไถพรวน | ⟪अकर्षि⟫ |

| ⟪२३⟫. | ⟪गम्यते⟫ | มันถูกไป/เดินทาง | ⟪अगामि⟫ |
