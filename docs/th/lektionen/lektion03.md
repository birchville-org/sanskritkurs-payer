# บทที่ 3

::: deleteme-box
**ในบทนี้ท่านจะได้เรียนรู้:**
- กรณียกเอกพจน์ของคำนามเพศหญิง
- กรณียกพหูพจน์ของคำนามเพศชายและเพศหญิง
- การสร้างคำเพศหญิงจากคำเพศชาย
- วokalซันทหิ (การรวมสระ)
- Satzsandhi von -ās
:::
## 3.1. กรณียกเอกพจน์ของคำนามเพศหญิง

### 3.1.1. กรณียกเอกพจน์ลงท้ายด้วย -s

นอกจากนี้ รากนามที่ลงท้ายด้วยสระ ยังสร้างกรณียกเอกพจน์โดยลงท้ายด้วย **-s** ดังนี้:

::: grammar-box
- **เพศหญิงลงท้ายด้วย -i**: เช่น **śruti** f. "การฟัง" -- Nom. sg.: **śrutis** = ⟪श्रुतिस्⟫
- **เพศหญิงลงท้ายด้วย -u**: เช่น **dhenu** f. "แม่โค" -- Nom. sg.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. กรณียกเอกพจน์ไม่มีคำลงท้าย

สร้างกรณียกเอกพจน์โดยไม่มีคำลงท้าย:

::: grammar-box
- **เพศหญิงลงท้ายด้วย -ā**: เช่น **devatā** f. "เทพเจ้า" -- Nom. sg.: **devatā** = ⟪देवता⟫
- **เพศหญิงลงท้ายด้วย -ī**: เช่น **devī** f. "เทพี" -- Nom. sg.: **devī** = ⟪देवी⟫
:::
::: important
**ข้อควรระวัง!** นอกจากนี้ยังมีรากนามเพศหญิงพยางค์เดียวที่ลงท้ายด้วย -ī ซึ่งกรณียกเอกพจน์ลงท้ายด้วย -s: เช่น dhī f. "ความคิด" -- Nom. sg.: dhīs = ⟪धीस्⟫. เช่นเดียวกับ lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "เรือ" และ tantrī (⟪तन्त्री⟫) f. "สาย" ที่สร้างกรณียกเอกพจน์ลงท้ายด้วย -s แบบผิดปกติ: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. การสร้างคำเพศหญิงจากคำเพศชาย

::: grammar-box
**คำเพศชายลงท้ายด้วย -a:**
- **เพศหญิงลงท้ายด้วย -ā**: เช่น **kṣatriya** m. » **kṣatriyā** f. "สตรีวรรณะกษัตริย์" = ⟪क्षत्रिया⟫
- **เพศหญิงลงท้ายด้วย -ī**: เช่น **brāhmaṇa** m. » **brāhmaṇī** f. "สตรีวรรณะพราหมณ์" = ⟪ब्राह्मणी⟫

**คำเพศชายลงท้ายด้วย -u:**
- **เพศหญิงลงท้ายด้วย -ī**: เช่น **sādhu** m. » **sādhvī** f. (ดี, นักบวช) = ⟪साध्वी⟫
(**-u-** เปลี่ยนเป็น **-v-** ก่อนสระ ดังนั้น **-u- + -ī** » **-vī**)
:::

## 3.3. กรณียกพหูพจน์เพศชายและเพศหญิง

::: grammar-box
คำลงท้ายกรณียกพหูพจน์ในเพศชายและเพศหญิงคือ **-as**.
- **คำเพศชายลงท้ายด้วย -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **เพศหญิงลงท้ายด้วย -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **คำเพศชายลงท้ายด้วย -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **เพศหญิงลงท้ายด้วย -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **เพศหญิงลงท้ายด้วย -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **คำเพศชายลงท้ายด้วย -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **เพศหญิงลงท้ายด้วย -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
หมายเหตุ: **e** เป็นระดับสูง (**guṇa**) ของ **i**, **o** เป็นระดับสูงของ **u**.

## 3.4. วokalซันทหิ (การรวมสระ)

::: grammar-box
**สระพื้นฐานที่แตกต่างเพียงความยาวหรือไม่แตกต่างกันเลย จะรวมกันเป็นสระยาวที่เหมาะสม:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
ตัวอย่างเช่น

devatā + annapūrṇā » devatānnapūrṇā "อันนาปূรณาเป็นเทพเจ้า" = ⟪देवतान्नपूर्णा⟫

> (อันนาปূรณาเป็นเทพีแห่งอาหารและการทำครัว ทรงถือเป็นสำแดงกายองค์หนึ่งของปารวตี ภรรยาของศิวะ)

devī + indrāṇī » devīndrāṇī "อินทราณีเป็นเทพี" = ⟪देवीन्द्राणी⟫

> (อินทราณีเป็นชายาของพระอินทร์)

(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt0301))

::: grammar-box
**สระเดี่ยว (ยกเว้น -a / -ā) ก่อนสระที่แตกต่างจะถูกแทนด้วยกึ่งสระที่เหมาะสม:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! ข้อยกเว้นสำหรับกฎนี้มีโดยเฉพาะสำหรับรูปทวิพจน์ !!)
:::
เช่น

devī + umā » devy umā "อุมาเป็น/คือเทพี" = ⟪देव्युमा⟫

> (อุมาเป็นชื่อหนึ่งของปารวตี ชายาของพระศิวะ)

::: grammar-box
**-a / -ā ก่อนสระที่แตกต่าง:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::

śūdrā + itarā » śudretarā "อิตาราเป็นสตรีศูทร" = ⟪शूद्रेतरा⟫

## 3.5. สันธินิกรณของ -ās

::: grammar-box
**-ās wird vor allen stimmhaften Lauten durch -ā ersetzt.**
:::
เช่น

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "ไวศยะคือผู้เกิดสองครั้ง" = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. รายการคำศัพท์

**เรียนรู้คำศัพท์ต่อไปนี้:**

**śruti** f. = ⟪श्रुति⟫ : การฟัง, ศรัทธนิกรณ (ชื่อเรียกพระเวทและคัมภีร์พราหมณะ)

**smṛti** f. = ⟪स्मृति⟫ : การระลึกถึง, ความทรงจำ, การระลึกถึงอย่างมีสติ = สติ, ศรัทธนิกรณ (ตรงข้ามกับ **śruti**) ประกอบด้วย:
- หก **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): การออกเสียงที่ถูกต้อง
  2. **chandas** n. (⟪छन्दस्⟫): ฉันทลักษณ์
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): ไวยากรณ์
  4. **nirukta** n. (⟪निरुक्त⟫) : คำอธิบายศัพท์, ปรนิรุตติ
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : โหราศาสตร์, ปฏิทินวิทยา
  6. **kalpa** m. (⟪कल्प⟫) : พิธีกรรม
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : คัมภีร์สำหรับพิธีบูชาใหญ่
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : คัมภีร์สำหรับพิธีกรรมและเครื่องบูชาในชีวิตประจำวัน
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) และ **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : คัมภีร์เกี่ยวกับกฎหมายและจารีต (พฤติกรรมที่ถูกต้อง)
- มหากาพย์ใหญ่ **mahābhārata** n. (⟪महाभारत⟫) และ **rāmāyaṇa** n. (⟪रामायण⟫)
- **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : คัมภีร์แห่งความฉลาดในชีวิต

**smṛti** ยังเป็นชื่อเรียกคัมภีร์ธรรมศาสตร์โดยเฉพาะ

**dhenu** f. = ⟪धेनु⟫ : (โคนม)

**paśu** m. = ⟪पशु⟫ : สัตว์ใช้งานที่เลี้ยงไว้, ปศุสัตว์ (นามรวม)

**devatā** f. = ⟪देवता⟫ : เทวดา (นามธรรมและรูปธรรม)

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : พราหมณี

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : กษัตริยสตรี

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : ภรรยาของกษัตริย์

**vaiśyā** f. = ⟪वैश्या⟫ : ไ往ศยสตรี

**śūdrā** f. = ⟪शूद्रा⟫ : ศูทรสตรี

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : ภรรยาของศูทร

**devī** f. = ⟪देवी⟫ : เทพี, โดยเฉพาะดูรคา f. = ⟪दुर्गा⟫, ชายาของพระศิวะ = ⟪शिव⟫

::: media
![](/images/lekt0303.webp)
ภาพ: Durgā = ⟪दुर्गा⟫, Orissa
(แหล่งที่มาของภาพ: [Details](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : รูปสตรีของ sādhu

**gurvī** f. = ⟪गुर्वी⟫ : รูปสตรีของ guru

**asmitā** f. = ⟪अस्मिता⟫ : "ความเป็นฉัน" คือความเชื่อ (ที่ผิด) ว่า **ตัวฉัน** เป็นผู้ที่เห็นเป็นต้น

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : ปรัชญา (ศาสตร์ที่มาถึงข้อสรุปผ่านการให้เหตุผลที่ถูกต้องตามตรรกะ)

**upekṣā** f. = ⟪उपेक्षा⟫ : ความไม่ใส่ใจ, ความวางเฉย

**karuṇā** f. = ⟪करुणा⟫ : ความเมตตา, ความสงสาร

**muditā** f. = ⟪मुदिता⟫ : ความยินดี, โดยเฉพาะความยินดีแทนผู้อื่น (ตรงข้ามกับความอิจฉา)

## 3.7. แบบฝึกหัด

**A) จงเปลี่ยนประโยคต่อไปนี้ให้เป็นพหูพจน์:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**B) จงสร้างประโยคชื่อโดยเติมคำ:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) จงแปลงเป็นเพศหญิง:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**D) จงแปลเป็นภาษาสันสกฤต:**

1. อุมาเป็นเทวี
2. เวดะคือศฺรุตฺิ
3. ครูผู้สอนเป็นเทวี
4. โคโคนมเป็นสัตว์ที่ถูกทำให้เชื่อง
5. กวีคือครู
6. กษัตริย์เป็นผู้เกิดสองครั้ง
7. ผู้ศักดิ์สิทธิ์คือศูทร
