# บทที่ 61

## 61.1. การผันคำศัพท์รากฐานลงท้ายด้วย -ā, -ī, -ū

### 61.1.1. คำศัพท์รากฐานลงท้ายด้วย -ā ที่ตำแหน่งสุดท้ายของ ⟪तत्पुरुष⟫

::: grammar-box
**ก่อนท้ายคำที่เป็นสระ พยัญชนะต้นของรากศัพท์ในกรณียาก (weak cases) จะลดรูปเป็น Ø**

**การผันคำศัพท์ในเพศชายและเพศหญิงเหมือนกัน**
:::
ตัวอย่างการผันคำ:

⟪विश्वपा⟫ m.f. "ผู้ปกป้องทุกสิ่ง"

|   | ⟪एकवचनम्⟫ | ⟪द्विवचनम्⟫ | ⟪बहुवचनम्⟫ |
| --- | --- | --- | --- |
| **⟪प्रथमा⟫ /:br⟪आमन्त्रितम्⟫** | ⟪विश्वपास्⟫ | ⟪विश्वपौ⟫ | ⟪विश्वपास्⟫ |
| ⟪द्वितीया⟫ | ⟪विश्वपाम्⟫ | ^^ | ⟪विश्वपस्⟫ |
| ⟪तृतीया⟫ | ⟪विश्वपा⟫ | ⟪विश्वपाभ्याम्⟫ | ⟪विश्वपाभस्⟫ |
| ⟪चतुर्थी⟫ | ⟪विश्वपे⟫ | ^^ | ⟪विश्वपाभ्यस्⟫ |
| ⟪पञ्चमी⟫ | ⟪विश्वपस्⟫ | ^^ | ^^ |
| ⟪षष्ठी⟫ | ^^ | ⟪विश्वपोस्⟫ | ⟪विश्वपाम्⟫ |
| ⟪सप्तमी⟫ | ⟪विश्वपि⟫ | ^^ | ⟪विश्वपासु⟫ |

### 61.1.2. คำศัพท์รากฐานเพศหญิงลงท้ายด้วย -ī

::: grammar-box
**ก่อนท้ายคำที่เป็นสระ -ī จะถูกแทนที่ด้วย -iy**

**นอกจากการสร้างรูปตามท้ายคำกรณียกมาตรฐานแล้ว ในกรณี Dat.Ab.Gen.Lok.sg. และ Gen.pl. ยังมีการสร้างรูปตามรูปแบบของคำศัพท์เพศหญิงพยางค์หลายพยางค์ลงท้ายด้วย -ī (⟪देवी⟫) ด้วย**
:::
ตัวอย่างการผันคำ:

⟪धी⟫ f. "ความคิด"

| --- | --- | --- | --- |
| **⟪प्रथमा⟫ /:br⟪आमन्त्रितम्⟫** | ⟪धीस्⟫ | ⟪धियौ⟫ | ⟪धियस्⟫ |
| ⟪द्वितीया⟫ | ⟪धियम्⟫ | ^^ | ^^ |
| ⟪तृतीया⟫ | ⟪धिया⟫ | ⟪धीभ्याम्⟫ | ⟪धीभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪धिये⟫ / ⟪धियै⟫ | ^^ | ⟪धीभ्यस्⟫ |
| ⟪पञ्चमी⟫ | ⟪धियस्⟫ / ⟪धिया्स्⟫ | ^^ | ^^ |
| ⟪षष्ठी⟫ | ^^ | ⟪धियोस्⟫ | ⟪धियाम्⟫ / ⟪धीनाम्⟫ |
| ⟪सप्तमी⟫ | ⟪धियि⟫ / ⟪धियाम्⟫ | ^^ | ⟪धीषु⟫ |

### 61.1.3. รากนามที่ลงท้ายด้วย -ī ในตอนปลายของ ⟪तत्पुरुष⟫

::: grammar-box
**ก่อนทวิภาคสระ -ī จะถูกแทนที่ด้วย -y หากมีพยัญชนะซึ่งเป็นส่วนหนึ่งของรากคำตามหลังเพียงหนึ่งตัวเท่านั้น หากมีพยัญชนะซึ่งเป็นส่วนหนึ่งของรากคำหลายตัวตามหลัง -ī ก่อนทวิภาคสระจะถูกแทนที่ด้วย -iy**

**การผันรูปในเพศชายและเพศหญิงเหมือนกัน**

**ความไม่เป็นปกติ: คำประสมที่ลงท้ายด้วย -⟪नी⟫ "ผู้ Leading" ใน loc.sg มีทวิภาค -ām (เช่น ⟪देवी⟫):**
เช่น ⟪ग्रामणी⟫ "ผู้ Leading หมู่บ้าน/หมู่บ้าน": loc.sg.m.f. ⟪ग्रामण्याम्⟫
:::
ตารางการผันรูป:

### 61.1.4. รากนามเพศหญิงพยางค์เดียวลงท้ายด้วย -ū

::: grammar-box
**รากก่อนสระ: -uv**

**การผันคำคล้ายกับรากนามเพศหญิงลงท้ายด้วย -ī**
:::

### 61.1.5. รากนามลงท้ายด้วย -ū ณ ท้ายของ ⟪तत्पुरुष⟫

::: grammar-box
**ก่อนรูปผันที่มีสระลงท้าย -ū จะเปลี่ยนเป็น -v หากมีพยัญชนะที่เป็นส่วนหนึ่งของรากคำตามหลังเพียงตัวเดียว แต่หากมีพยัญชนะของรากคำหลายตัวตามหลัง -ū จะเปลี่ยนเป็น -uv ก่อนรูปผันที่มีสระลงท้าย**

**การผันคำในเพศชายและเพศหญิงเหมือนกัน**
:::

### 61.1.6. การผันรูปคำนามเพศหญิงพยางค์หลายพยางค์ลงท้ายด้วย -ū

::: grammar-box
**คำนามเพศหญิงพยางค์หลายพยางค์ลงท้ายด้วย -ū จะผันรูปตามแบบคำนามพยางค์หลายพยางค์ที่ลงท้ายด้วย -ī (⟪देवी⟫) แต่จะลงท้ายในกรณีประธานเอกพจน์ด้วย -s**
:::

## 61.2. อนาคตกาลแบบวงรอบ (⟪लुट्⟫)

::: grammar-box
**นอกจากอนาคตกาลแบบง่าย (⟪ऌत्⟫) แล้ว ยังมีการใช้อนาคตกาลแบบวงรอบ (⟪लुट्⟫) ตามทฤษฎีของนักไวยากรณ์พื้นเมือง ใช้เพื่อระบุถึงอนาคตอันไกล ("หลังจากวันที่กำลังดำเนินอยู่") ในขณะที่อนาคตกาลแบบง่ายใช้ระบุถึงอนาคตอันใกล้ ("ในวันที่กำลังดำเนินอยู่") ในภาษาสันสกฤตคลาสสิก มักไม่มีการแยกความแตกต่างในการใช้งานระหว่างอนาคตกาลทั้งสองรูปแบบนี้**

**การสร้างรูป:**

**อนาคตกาลแบบวงรอบสร้างโดยการเชื่อมคำนามผู้กระทำ (nomen agentis) ที่ลงท้ายด้วย -tṛ กับรูปปัจจุบันกาลของ ⟪अस्⟫ คำสั่งที่สามใช้คำนามแบบง่ายในจำนวนที่เหมาะสม โดยไม่มีการแยกความแตกต่างตามเพศทางไวยากรณ์ สำหรับการเชื่อมกับ ⟪अस्⟫ คำนามในทุกบุคคลและจำนวนจะมีรูปเป็นประธานเอกพจน์ลงท้ายด้วย -tā**
:::

## 61.3. อินเทนซีฟัม (ฟรีเควนทาติฟัม) (⟪चर्करीतम्⟫)

::: grammar-box
**จากรากศัพท์ (root) ที่ออกเสียงด้วยพยัญชนะและอยู่ในกลุ่มประธาน 9 กลุ่มแรก สามารถสร้างรูปเน้น (⟪चर्करीतम्⟫) ได้; นั่นหมายความว่า: ยกเว้นบางกรณี รูปเน้นไม่สามารถสร้างจากรากศัพท์สองพยางค์ (เช่น ⟪जागृ⟫) รากศัพท์ที่ออกเสียงด้วยสระ และรากศัพท์ของกลุ่มประธานที่ 10 (⟪चुरादिगण⟫) ได้**

**รูปเน้น (Intensivum) มีความหมายว่า:**

*   **ที่บุคคลหรือสิ่งใดสิ่งหนึ่งกระทำหรือประสบกับสิ่งที่รากศัพท์สื่อถึง ซ้ำแล้วซ้ำเล่า**  
⟪कृ⟫ 8U: ⟪चेक्रीयते⟫ / ⟪चर्करीति⟫ "เขากระทำซ้ำแล้วซ้ำเล่า"  
⟪भू⟫ 1P: ⟪बोभूयते⟫ / ⟪बोभवीति⟫ "เขาเป็น (กลายเป็น) บ่อยครั้ง"  

*   **ที่บุคคลหรือสิ่งใดสิ่งหนึ่งกระทำหรือประสบกับสิ่งที่รากศัพท์สื่อถึง อย่างเข้มข้น:**  
⟪कृ⟫ 8U: ⟪चेक्रीयते⟫ / ⟪चर्करीति⟫ "เขากระทำอย่างเข้มข้น เขากระทำอย่างมีทักษะ"  

*   **สำหรับรากศัพท์ที่สื่อถึงการเคลื่อนไหว รูปเน้นหมายถึง การเคลื่อนไหวแบบโค้งงอ:**  
⟪व्रज्⟫ 1P:  ⟪वव्रज्यते⟫ "เขาเดินเป็นเส้นโค้ง" (ไม่ใช่: "เขามักจะเดิน")  

*   **สำหรับรากศัพท์บางประการ (รายการ: Kielhorn, Grammar § 458b) รูปเน้นหมายถึง การตำหนิ:**  
⟪लुप्⟫ 6U: ⟪लोलुप्यते⟫ "เขาตัดไม่ดี"  
⟪सद्⟫ 1P: ⟪सासद्यते⟫ "เขาตั้งตัวไม่ดี"

### 61.3.1. Ātmanepada-Intensivum

::: grammar-box
**การสร้าง:**

**รากศัพท์ที่ซ้ำ + -ya-**

**รูปแบบของรากศัพท์: โดยทั่วไปเหมือนกับในรูป Passive กล่าวคือ มักอยู่ในระดับเสียงต่ำ (tiefstufig):**

ตัวอย่าง:

:::
::: indent
⟪स्वप्⟫ บุรุษที่ 2: Pass. ⟪सुप्यते⟫ ; Intens. ⟪सोषुप्यते दा⟫ บุรุษที่ 3: Pass. ⟪दीयते⟫ ; Intens. ⟪देदीयते⟫
:::
รายละเอียดของกฎเกณฑ์ต่างๆ ดูได้ที่ Kielhorn, Grammatik § 461

**การซ้ำ (Reduplikation): ตามกฎเกณฑ์ทั่วไป แต่สระของการซ้ำ: แทนที่ด้วย a,i,u จะใช้ ā, e, o**

::: grammar-box
**รากศัพท์ที่มีรูปแบบ -a-Nasal จะไม่ยืดสระในพยางค์ของการซ้ำ แต่จะซ้ำพยัญชนะ Nasal**

**การผันคำกริยา:**

*   **รากศัพท์ปัจจุบัน (Präsensstamm): เหมือนกับ Ātmanepada ของกลุ่มกริยาปัจจุบันที่ 4 (⟪दिवादिगण⟫).**
*   **Passive และรากศัพท์ของกาลอื่นๆ: หากมีสระนำหน้า -ya- ของรากศัพท์ Intensiv จะเปลี่ยน -ya- เป็น -y- หากมีพยัญชนะนำหน้า -ya- จะตัด -ya- ออก:**
*   **Passive ปัจจุบัน: ⟪बुध्⟫ : ⟪बोबुध्यते⟫ ; ⟪भू⟫ : ⟪बोभूय्यते⟫**

*   **Aorist: iṣ-Aorist (Aorist 5): ⟪अबोबुधिष्ट⟫ ; ⟪अबोभूयिष्ट⟫**
*   **Future: seṭ: ⟪बोबुधिष्यते⟫ ; ⟪बोभूयिष्यते⟫**
*   **Future แบบรอบรู้ (periphrastisches Futur): ⟪बोबुधिता⟫ ; ⟪बोभूयिता⟫**

### 61.3.2. Parasmaipada-Intensivum

::: grammar-box
**รากศัพท์ปัจจุบัน (รูปอื่นๆ พบน้อยมาก): การสร้างและการผันเหมือนกริยาในชั้นปัจจุบันที่ 3 (⟪जुहोत्यादिगण⟫) โดยมีความแตกต่างที่ว่าสระของพยางค์ซ้ำเสียงจะสูงระดับ (high-grade) และหากเป็น -a- จะยาวระดับ (lengthened).**

**ในเอกพจน์ของปัจจุบันบอกเหตุ และบุพบทที่ 2.3.sg. ของอดีตบอกเหตุ และ 3.sg.ของคำสั่ง สามารถแทรก -ī- ระหว่างรากศัพท์และท้ายคำได้ หากมีการแทรก -ī- นี้ สระสั้นที่ตำแหน่งรองสุดท้ายจะไม่ถูก guṇa.**

**เกี่ยวกับการซ้ำเสียงด้วย nasal และการแทรก -nī- หรือ -rī- นั้นเป็นไปตามกฎเดียวกับ Ātmanepada-Intensivum แทนที่ -rī- อาจใช้ -ri- ได้เช่นกัน**
:::

## 61.4. นามวิเศษณ์ (⟪नामधातु⟫)

นามวิเศษณ์ (⟪नामधातवः⟫) จะถูกสร้างจากฐานนาม ไม่ใช่จากรากกริยา ซึ่งแตกต่างจากกริยาที่กล่าวถึงก่อนหน้านี้ โดยมีการสร้างหลายประเภท

### 61.4.1. การสร้างโดยไม่มีส่วนขยายพิเศษ ปารัสไพบท

::: grammar-box
**ความหมาย:**

:::
::: indent
**บุคคลหรือสิ่งหนึ่งประพฤติตนเหมือน หรือคล้ายคลึงกับสิ่งที่ฐานนามนั้นหมายถึง**
:::
**การผันกริยา:**

::: indent
**ในฐานปัจจุบัน เหมือนกับกริยาชั้นปัจจุบันที่ 1 (⟪भ्वादिगण⟫) หากนามมีสระ 'm' เป็นสระสุดท้าย จะพิจารณาเฉพาะสระตัวสุดท้ายเหมือนสระรากของชั้นที่ 1 สระ 'a' ที่ออกเสียงท้ายจะหายไปก่อนสระธีม สระหน้าสระนำท้ายจะถูกแทนที่ด้วยสระยาวที่เหมาะสม**

### 61.4.2. การสร้างด้วยส่วนขยาย -ya ปารัสไพบท

::: grammar-box
**ความหมาย:**

*   **บุคคลหนึ่งปรารถนาสิ่งที่ถูก обозначโดยรากนาม**
*   **บุคคลหนึ่งปฏิบัติหรือพิจารณาบุคคลหรือสิ่งใดสิ่งหนึ่งเสมือนกับสิ่งที่ถูก обозначโดยรากนาม**

**การสร้างรากศัพท์:**

:::
::: indent
**ก่อนหน้า -ya การลงท้ายของรากนามจะเกิดการเปลี่ยนแปลงดังต่อไปนี้:**

*   **a, ā » ī :** ⟪पुत्र⟫ » ⟪पुत्रीय⟫-
*   **i, u » ī, ū :** ⟪कवि⟫ » ⟪कवीय⟫-
*   **ṛ » rī :** ⟪कर्तृ⟫ » ⟪कर्त्रीय⟫-
*   **o » av :** ⟪गो⟫ » ⟪गव्य⟫-
*   **au » āv :** ⟪नौ⟫ » ⟪नाव्य⟫-
*   **พยัญชนะนำหน้าเสียงสระสุดท้ายจะหายไป และสระที่อยู่ก่อนหน้าจะถูกจัดการตามกฎที่กล่าวมาข้างต้น:** ⟪राजन्⟫ » ⟪राजीय⟫-
*   **พยัญชนะนำหน้าเสียงสระสุดท้ายอื่นๆ จะคงเดิม**
:::

### 61.4.5. การสร้างด้วยปัจจัย -ya, Ātmanepada

::: grammar-box
**ความหมาย:**

:::
::: indent
**บุคคลหนึ่งปฏิบัติตนเป็นสิ่งที่ หรือคล้ายคลึงกับสิ่งที่รากนามระบุไว้**
:::
**การสร้าง:**

*   **-a ที่ท้ายคำ เปลี่ยนเป็น -ā**
*   **-ā ที่ท้ายคำ คงไว้ไม่เปลี่ยนแปลง**
*   **กรณีอื่น ๆ เหมือนกับก่อนหน้า -ya, Parasmaipada (ดูข้างต้น 4.2.)**
*   **-as ที่ท้ายคำ เปลี่ยนเป็น -ā ได้ตามต้องการ**
*   **รากนามเพศหญิง ส่วนใหญ่เปลี่ยนเป็น รากนามเพศชาย**

ตัวอย่าง:

| ⟪कृष्ण⟫ น. คุรณะ | ⟪कृष्णायते⟫ "เขาปฏิบัติตนเหมือนคุรณะ" |
| --- | --- |
| ⟪यशस्⟫ 3 "มีชื่อเสียง" | ⟪यशायते । यशस्यते⟫ "เขาปฏิบัติตนเหมือนผู้มีชื่อเสียง" |
| ⟪कुमारी⟫ น. "เด็กหญิง" | ⟪कुमारायते⟫ "เขาปฏิบัติตนเหมือนเด็กหญิง" |

::: grammar-box
**สำหรับรากนามบางชนิดsuffix นี้มีความหมายว่า: สิ่งหนึ่งกลายเป็นเหมือนสิ่งนั้น หรือกลายเป็นสิ่งที่ถูกสื่อโดยรากนาม:**

:::
::: indent
เช่น ⟪उन्मनस्⟫ 3 "กระตุ้น": ⟪उन्मनायते⟫ "เขาถูกกระตุ้น"

## 61.5. Benediktiv (⟪आशीर्लिङ्⟫)

::: grammar-box
**ความหมาย:**

:::
::: indent
**คำอธิษฐานอวยพร**
:::
**การศึกษา:**

**ปราสมาปททะ (Parasmaipada):**

**รากศัพท์ระดับต่ำ + yās + การลงท้ายขั้นที่สอง**

::: indent
เช่น ⟪बुध्यासम्⟫ "ขอให้ข้าพเจ้ารู้แจ้ง!"

**(ส่วนใหญ่) รากศัพท์ระดับสูง + sī(y) + การลงท้ายขั้นที่สอง**

**หรือ:**

**(รากศัพท์ระดับสูง) ราก + ⟪ै⟫ + sī(y) + การลงท้ายขั้นที่สอง**

::: indent
เช่น
⟪जि⟫ : ⟪जेषीय⟫ "ขอให้ข้าพเจ้าชนะเพื่อประโยชน์ส่วนตน!"

## 61.6. ศัพท์เงื่อนไข (⟪ऌङ्⟫)

::: grammar-box
**ศัพท์เงื่อนไข (⟪ऌङ्⟫) ใช้เมื่อต้องการแสดงในประโยคเงื่อนไขว่า สิ่งที่ถูกกล่าวว่าเป็นเงื่อนไขนั้น ไม่ได้เกิดขึ้น / ไม่ได้เกิดขึ้นแล้ว / จะไม่เกิดขึ้นในอนาคต ศัพท์เงื่อนไขนี้จะต้องใช้ในทั้งประโยคเงื่อนไขและประโยคหลักเมื่อกล่าวถึงประโยคดังกล่าว**
:::
ตัวอย่าง:

::: indent
⟪सुवृष्टिश्चेदभविष्यत्सुभिक्षमभविष्यत्⟫ "หากฝนตกดี (หรือจะตก) ก็จะมีอาหารอุดมสมบูรณ์ แต่ในความเป็นจริง ฝนไม่ได้ตก (เพียงพอ)"
:::
::: grammar-box
**การสร้างรูปเงื่อนไข (⟪ऌङ्⟫):**

**อ็อกเมนต์ + รากของอนาคตธรรมดา (⟪ऌत्⟫) + การลงท้ายแบบทุติยภูมิ**

นั่นคือ เหมือนกับอดีตกาล (⟪लङ्⟫) ที่ใช้กับรากอนาคต

เช่น ⟪अदास्यम्⟫ ; ⟪अभविष्यम्⟫ ; ⟪अतोत्स्यम्⟫
:::
ตารางผันคำ:

⟪भू⟫ "เป็น, กลายเป็น"
