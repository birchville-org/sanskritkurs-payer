# บทที่ 61

## 61.1. การผันรากนามลงท้ายด้วย -ā, -ī, -ū

### 61.1.1. รากนามลงท้ายด้วย -ā ณ ท้ายของ ⟪तत्पुरुष⟫

::: grammar-box
**ก่อนทศวรรณยุกต์ (vocalic endings) สระฐานของรากในกรณียากมีระดับการหายไป Ø**

**การผันในเพศชายและเพศหญิงเหมือนกัน**
:::

### 61.1.2. รากนามเพศหญิงลงท้ายด้วย -ī

::: grammar-box
**Vor vokalischer Endung wird -ī durch -iy ersetzt.**

**นอกจากการสร้างด้วยทศวรรณยุกต์กรณามาตรฐาน ใน Dat.Ab.Gen.Lok.sg. และ Gen.pl. ยังมีการสร้างตามรูปแบบของนามเพศหญิงพยางค์หลายพยางค์ลงท้ายด้วย -ī (⟪देवी⟫) ด้วย**
:::

### 61.1.3. รากนามลงท้ายด้วย -ī ณ ท้ายของ ⟪तत्पुरुष⟫

::: grammar-box
**ก่อนทศวรรณยุกต์ -ī จะถูกแทนที่ด้วย -y หากมีพยัญชนะซึ่งเป็นส่วนหนึ่งของรากตามหลังเพียงหนึ่งตัว หากมีพยัญชนะซึ่งเป็นส่วนหนึ่งของรากหลายตัวนำหน้า -ī จะถูกแทนที่ด้วย -iy ก่อนทศวรรณยุกต์**

**การผันในเพศชายและเพศหญิงเหมือนกัน**

**ข้อยกเว้น: คำประสมลงท้ายด้วย -⟪नी⟫ "ผู้leading" ใน Lok.sg. มีทศวรรณยุกต์ -ām (เช่น ⟪देवी⟫):**
เช่น ⟪ग्रामणी⟫ "ผู้leadingฝูงชน/หมู่บ้าน": Lok.sg.m.f. ⟪ग्रामण्याम्⟫
:::

### 61.1.5. รากนามลงท้ายด้วย -ū ณ ท้ายของ ⟪तत्पुरुष⟫

::: grammar-box
**ก่อนรูปผันที่มีสระ -ū จะถูกแทนที่ด้วย -v หากมีพยัญชนะซึ่งเป็นส่วนหนึ่งของรากคำตามหลังมาเพียงตัวเดียว หากมีพยัญชนะซึ่งเป็นส่วนหนึ่งของรากคำหลายตัวตามมา -ū ก่อนรูปผันที่มีสระจะถูกแทนที่ด้วย -uv**

**การผันในเพศชายและเพศหญิงเหมือนกัน**

## 61.2. อนาคตแบบเพริฟราสติก (⟪लुट्⟫)

::: grammar-box
**นอกเหนือจากอนาคตแบบง่าย (⟪ऌत्⟫) แล้ว ยังมีอนาคตแบบเพริฟราสติก (⟪लुट्⟫) ตามทฤษฎีของนักไวยากรณ์ท้องถิ่น จะใช้เพื่อระบุอนาคตอันไกล ("หลังจากวันปัจจุบัน") ในขณะที่อนาคตแบบง่ายระบุถึงอนาคตอันใกล้ ("ในวันปัจจุบัน") ในภาษาสันสกฤตคลาสสิก ดูเหมือนจะไม่มีความแตกต่างในการใช้งานระหว่างอนาคตทั้งสองรูปแบบ**

**การศึกษา:**

**อนาคตแบบเพอริฟราสติก (periphrastic future) ถูกสร้างโดยการเชื่อม nomina agentis ที่ลงท้ายด้วย -tṛ กับรูปปัจจุบันของ ⟪अस्⟫ 2. ในฐานะบุคคลที่สาม ใช้คำนามอย่างง่ายในจำนวนที่เหมาะสม โดยไม่มีการแยกแยะตามเพศทางไวยากรณ์ ในการเชื่อมกับ ⟪अस्⟫ คำนามในทุกบุคคลและจำนวนมีรูปเป็น Nom.sg. ที่ลงท้ายด้วย -tā.**
:::

## 61.3. คำเน้น (Frequentativum) (⟪चर्करीतम्⟫)

::: grammar-box
**จากรากศัพท์หนึ่งพยางค์ที่ขึ้นต้นด้วยพยัญชนะของคลาสปัจจุบันเก้าชั้นแรก สามารถสร้างคำเน้น (⟪चर्करीतम्⟩) ได้; นั่นหมายความว่า ยกเว้นบางกรณี รากศัพท์สองพยางค์ (เช่น ⟪जागृ⟫), รากศัพท์ที่ขึ้นต้นด้วยสระ และรากศัพท์ของคลาสปัจจุบันชั้นที่ 10 (⟪चुरादिगण⟫) ไม่สามารถสร้างคำเน้นได้**

**ความหมายของคำเน้นคือ:**

*   **ว่าบุคคลหรือสิ่งหนึ่งทำหรือประสบสิ่งที่รากศัพท์แสดงออกซ้ำแล้วซ้ำอีก**  
⟪कृ⟫ 8U: ⟪चेक्रीयते⟫ / ⟪चर्करीति⟫ "เขาทำซ้ำแล้วซ้ำอีก"  
⟪भू⟫ 1P: ⟪बोभूयते⟫ / ⟪बोभवीति⟫ "เขาเป็น (กลายเป็น) บ่อยครั้ง"  

*   **ว่าบุคคลหรือสิ่งหนึ่งทำหรือประสบสิ่งที่รากศัพท์แสดงออกอย่างเข้มข้น:**  
⟪कृ⟫ 8U: ⟪चेक्रीयते⟫ / ⟪चर्करीति⟫ "เขาทำอย่างเข้มข้น เขาทำอย่างเก่งกาจ"  

*   **ในกรณีของรากศัพท์ที่แสดงการเคลื่อนไหว คำเน้นหมายถึงการเคลื่อนไหวแบบโค้ง:**  
⟪व्रज्⟫ 1P:  ⟪वव्रज्यते⟫ "เขาเดินในลักษณะโค้ง" (ไม่ใช่: "เขามักจะเดิน")  

*   **ในบางกรณีของรากศัพท์ (รายการ: Kielhorn, Grammar § 458b) คำเน้นหมายถึงการตำหนิ:**  
⟪लुप्⟫ 6U: ⟪लोलुप्यते⟫ "เขาตัดไม่ดี"  
⟪सद्⟫ 1P: ⟪सासद्यते⟫ "เขาตั้งตัวไม่ดี"
:::

### 61.3.1. อินเทนซีฟัมอัตมันเนปะทะ (Ātmanepada-Intensivum)

::: grammar-box
**การสร้าง:**

**รากที่ซ้ำ + -ya-**

**รูปแบบของราก: โดยทั่วไปเหมือนในรูปพาสซีฟ กล่าวคือ มักเป็นระดับต่ำ (tiefstufig):**

ตัวอย่าง:

:::
::: indent
⟪स्वप्⟫ 2P: พาส. ⟪सुप्यते⟫ ; อินเทน. ⟪सोषुप्यते⟫

:::

**Reduplikation: nach den allgemeinen Regeln. Reduplikationsvokal aber: statt a,i,u steht ā, e, o**
ตัวอย่าง:

| ⟪दा⟫ 3U | ⟪देदीय⟫- |
| --- | --- |

| ⟪ज्ञा⟫ 9U | ⟪जाज्ञाय⟫- |

เช่น ⟪यम्⟫ 1P: ⟪यंयम्य⟫-

*   **พาสซีฟและรากกาลอื่นๆ: หากมีสระนำหน้า -ya- ของรากอินเทนซีฟ จะเปลี่ยน -ya- เป็น -y-, หากมีพยัญชนะนำหน้า -ya- จะตัด -ya- ออก:**
    *   **พาสซีฟปัจจุบัน: ⟪बुध्⟫ : ⟪बोबुध्यते⟫ ; ⟪भू⟫ : ⟪बोभूय्यते⟫**

### 61.3.2. อินเทนซีฟัมปารัสเมปะทะ (Parasmaipada-Intensivum)

::: grammar-box
**รากปัจจุบัน (รูปอื่นพบได้หายมาก): การสร้างและการผันคำเหมือนกริยาชั้นปัจจุบันที่ 3 (⟪जुहोत्यादिगण⟫) โดยแตกต่างที่ว่าสระของพยางค์ตัวซ้ำเป็นระดับสูง (high-stufe), หากเป็น -a- จะเป็นระดับขยาย (dehnstufig)**

:::

## 61.4. คำที่สร้างจากนาม (⟪नामधातु⟫)

คำที่สร้างจากนาม (⟪नामधातवः⟫) เมื่อเปรียบเทียบกับกริยาที่กล่าวมาจนถึงปัจจุบัน ไม่สร้างจากรากศัพท์ของกริยา แต่สร้างจากรากนาม โดยมีการสร้างหลายประเภท

### 61.4.1. การสร้างโดยไม่มีคำลงท้ายพิเศษ แบบปารัสไมปะทะ

::: grammar-box
**ความหมาย:**

:::
::: indent

:::
**การผัน:**

::: indent
**ในรากปัจจุบัน เหมือนกับกริยาในกลุ่มปัจจุบันที่ 1 (⟪भ्वादिगण⟫). หากนามมีสระอา เป็นตัวสุดท้าย จะพิจารณาเฉพาะสระตัวสุดท้ายเหมือนรากศัพท์ของกริยาในกลุ่มที่ 1 สระท้ายจะหายไปก่อนคำหลัก หากมีสระนำหน้าเสียงนาสิกสุดท้าย จะเปลี่ยนเป็นสระยาวที่สอดคล้องกัน**
:::

::: grammar-box
**ความหมาย:**

:::
::: indent

*   **-a ท้ายคำ เปลี่ยนเป็น » -ā**

| ⟪कृष्ण⟫ นามบุรุษที่ 1 กฤษณะ | ⟪कृष्णायते⟫ "เขาปฏิบัติเสมือนกฤษณะ" |

นักประพันธ์และกวี: ปุรันทะรทาสะ (ಪುರಂದರ ದಾಸ) (1484 - 1564)

*   ārohaṇa: s r1 m1 p d1 S

*   avarohaṇa: S d1 p m1 g3 r1 s

ตาล: รุปกะ: o |4
