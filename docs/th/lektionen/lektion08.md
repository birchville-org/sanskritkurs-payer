# บทที่ 8



## 8.1. การสร้างนาม

ในไวยากรณ์อินเดียแบบดั้งเดิม มีการจำแนกแอกซอน (suffixes) ที่ใช้สร้างรากนามออกเป็นสองประเภทหลัก:

**แอกซอน kṛt (⟪कृत्⟫) (แอกซอนปฐมภูมิ):** สร้างรากนาม, อับโซลูติฟ และอินฟินิตีฟ จากกริยาราก (**dhātu** น. = ⟪धातु⟫) และรากกริยา
**แอกซอน taddhita (⟪तद्धित⟫) (แอกซอนทุติยภูมิ):** ต่อท้ายรากนามและคำอนิยม และสร้างรากนามใหม่หรือคำอนิยมใหม่

::: grammar-box
**แผนภาพ:**
**ราก + แอกซอน kṛt » รากนาม ฯลฯ + แอกซอน taddhita » รากนามใหม่ ฯลฯ**

**รากนาม + การผันกรณี » นามที่สามารถทำหน้าที่ทางไวยากรณ์ได้**
:::

## 8.2. การจำแนกแอกซอนนาม

**kṛt (kṛdanta) = ⟪कृत्⟫ (⟪कृदन्त⟫)**
**kārakakṛt** (⟪कारककृत्⟫) » นามผู้กระทำ (หมายถึงบุคคลที่ทำสิ่งที่รากกริยาสื่อถึง)
**kṛtikṛt** (⟪कृतिकृत्⟫) » นามการกระทำ (หมายถึงการกระทำที่สื่อผ่านรากกริยา) หรือนาม 추상

**taddhita**
**viśeṣyataddhita** (⟪विशेष्यतद्धित⟫) » คำคุณศัพท์
**bhāvārthakataddhita (tanmātrataddhita)** (⟪भावार्थकतद्धित⟫ / ⟪तन्मात्रतद्धित⟫) » นาม抽象
**tadvattaddhita** (⟪तद्वत्तद्धित⟫) » แสดงความเป็นเจ้าของ (เช่น **-mant** -⟪मन्त्⟫, **-vant** -⟪वन्त्⟫)
**tolanataddhita (atiśāyanataddhita)** (⟪तोलनतद्धित⟫ / ⟪अतिशायनतद्धित⟫) » การเปรียบเทียบ (คำคุณศัพท์ระดับกว่า, ระดับที่สุด), การเปรียบเทียบ
**pūraṇataddhita** (⟪पूरणतद्धित⟫) » เลขลำดับ (อันดับหนึ่ง ฯลฯ)
**vibhaktitaddhita** (⟪विभक्तितद्धित⟫) » แทนการผันกรณี (เช่น **-tas** -⟪तस्⟫, **-tra** -⟪त्र⟫)
**abhūtatadbhāva (cvitaddhita)** (⟪अभूततद्भाव⟫ / ⟪च्वितद्धित⟫) » (การสร้างแบบ cvi- ⟨JAच्वि⟫, **-sāt** -⟪सात्⟫)

**การจัดประเภทตามการเปลี่ยนสระ Ablaut:**
**guṇya** (⟪गुण्य⟫): การสร้างระดับสูง
**na guṇya** (⟪न गुण्य⟫): การสร้างระดับต่ำ
**vṛddhyarha** (⟪वृद्ध्यर्ह⟫): การสร้างระดับขยายเสียง


## 8.3. สuffix คำนามสำคัญบางประการ

### 8.3.1. -a ชาย (kṛt)

::: grammar-box
**Suffix kṛt -a สร้างคำนามเพศชาย (และบางครั้งเพศกลาง) ซึ่งหมายถึงการกระทำหรือสถานะที่ระบุโดยรากศัพท์; บางครั้งก็สร้างคำคุณศัพท์หรือนามที่แสดงถึงผู้กระทำ (kartṛ) ของการกระทำที่ระบุโดยรากกริยา สำหรับสระหน้าสุดท้ายสั้น (= สระนำหน้าพยัญชนะซึ่งรากศัพท์ลงท้าย) หรือสระรากศัพท์ที่ออกเสียงสุดท้าย มักจะแทนที่ด้วยระดับสูง (guṇa) หรือระดับขยายเสียง (vṛddhi)**
:::

### 8.3.2. -ana n. (kṛt)

::: grammar-box
**Suffix kṛt -ana โดยทั่วไปสร้างคำนามเพศกลางที่หมายถึง การกระทำ สถานะ หรือเครื่องมือ/อุปกรณ์ ที่ทำให้การกระทำซึ่งระบุโดยรากศัพท์หรือฐานกริยาเกิดขึ้น โดยปกติสระสั้นในพยางค์ก่อนสุดท้าย หรือสระที่ออกเสียงท้ายของรากศัพท์ จะถูกแทนที่ด้วยระดับสูง (guṇa)**
:::

| **gam** 1 P:br⟪गम्⟫:br"ไป" | **gamana** n.:br⟪गमन⟫ | "การไป" |
| **nī** 1 U:br⟪नी⟫:br"นำทาง" | **nayana** n.:br⟪नयन⟫ | "(เครื่องมือของการนำทาง นั่นคือ) ตา" |

::: note-box
**"Darshan" หรือ "Darshana"** เป็นศัพท์ในศาสนาฮินดูที่หมายถึง การมองเห็นและวิสัยทัศน์ต่อสิ่งศักดิ์สิทธิ์และเทพเจ้า ภายใต้คำว่า *Darshana* อาจหมายถึง การพบกันอย่างเป็นทางการระหว่างศิษย์กับครู ซึ่งศิษย์ได้รับเชิญจากครู นอกจากนี้ยังอาจหมายถึง *การจมดิ่ง* ขณะมองรูปเคารพของเทพเจ้า ความหมายหลังนี้เป็นความหมายที่พบได้บ่อยที่สุดในภาษาฮินดีปัจจุบัน ในบริบทของ Mata Amritanandamayi Darshan หมายถึง การโอบกอดจากคุรุ

ฮินดูผู้ศรัทธาไปวัดเพื่อรับदर्शनของพระเจ้าผ่านสัญลักษณ์หรือประติมากรรม ซึ่งเชื่อกันว่าเป็นการสถิตอยู่ทางจิตวิญญาณของเทพเจ้า ในความหมายนี้ยังรวมถึงการได้รับพรจากเทพเจ้าอีกด้วย อย่างไรก็ตาม दर्शन สามารถรับได้ผ่านการเห็นเทพเจ้าในขณะสวดมนต์หรือทำสมาธิ นอกจากนี้ บุคคลที่มีชีวิตซึ่ง被视为การอวตารของเทพเจ้า เช่น อวตะระ ก็สามารถให้दर्शनได้
(แหล่งที่มา: Wikipedia)

### 8.3.4. -ti f. (kṛt)

::: grammar-box
**Suffix kṛt -ti สร้างคำนามเพศหญิง ซึ่งโดยทั่วไปแสดงถึงกริยาหรือสถานะที่ระบุโดยรากศัพท์ รูปของรากศัพท์อยู่ในระดับต่ำ (deep grade).**
:::

## 8.4. ชั้นปัจจุบันที่ 8 (tanādi = ⟪तनादि⟫ = "tan เป็นต้น")
