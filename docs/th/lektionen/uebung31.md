# แบบฝึกหัด 31

A) จงแปลประโยคต่อไปนี้และแยกคำสมาส:

⟪१⟫. **⟪प्रज्ञा⟫ ⟪दुःखसम्भवं⟫ ⟪रुन्ध्यादिति⟫ ⟪बुद्धिमानार्यबुद्धमार्गेण⟫ ⟪गच्छेत्⟫ ⟪॥१॥⟫**
(⟪दुःखस्य⟫ ⟪सम्भवम्⟫ ⟪।⟫ ⟪आर्येण⟫ ⟪बुद्धस्य⟫ / ⟪बुद्धानां⟫ ⟪मार्गेण⟫)
เพื่อที่ปัญญาจะป้องกันความเกิดแห่งทุกข์ มนุษย์ผู้มีเหตุผลควรเดินตามมรรคอันประเสริฐของพระพุทธเจ้า (หรือ: ของพระตถาคตทั้งหลาย)

⟪२⟫. **⟪शस्त्राणि⟫ ⟪शरीरमेव⟫ ⟪छिन्दन्ति⟫ ⟪जीवस्तु⟫ ⟪न⟫ ⟪म्रियत⟫ ⟪इति⟫ ⟪भगव्द्गीतायां⟫ ⟪भगवतोच्यते⟫ ⟪॥२॥⟫**
(⟪भगवतो⟫ ⟪गीतायाम्⟫)
ท่านผู้มีคุณธรรมกล่าวในพระภัควัทคีตาว่า ดาบเพียงตัดร่างกายเท่านั้น แต่จิตวิญญาณ (ชีวิต) ไม่ตาย

⟪३⟫. **⟪बुद्ध्या⟫ ⟪युक्तो⟫ ⟪दुःखान्मुच्यते⟫ ⟪तस्मान्मोक्षमिच्छन्नरो⟫ ⟪योगेन⟫ ⟪युञ्जीत⟫ ⟪॥३॥⟫**
ผู้มีปัญญาย่อมหลุดพ้นจากทุกข์; เพราะฉะนั้น บุคคลผู้ปรารถนาความหลุดพ้นพึงตั้งใจมั่นด้วยโยคะ

⟪४⟫. **⟪पुत्रो⟫ ⟪जातो⟫ ⟪बन्धनं⟫ ⟪जातमिति⟫ ⟪सुगतो⟫ ⟪मत्वा⟫ ⟪कुलबन्धनं⟫ ⟪भिनत्ति⟫ ⟪।⟫ ⟪ततो⟫ ⟪भग्नबन्धो⟫ ⟪मोक्षनयन्तीं⟫ ⟪प्रज्ञामाप्तुमर्हति⟫ ⟪॥४॥⟫**
(⟪कुलस्य⟫ ⟪बन्धनम्⟫ ⟪।⟫ ⟪भग्नो⟫ ⟪बन्धो⟫ ⟪येन⟫ ⟪सः⟫ ⟪।⟫ ⟪मोक्षं⟫ ⟪नयन्तीम्⟫)
"บุตรเกิดแก่ข้าพเจ้า — บ่วงเกิด" — ด้วยความคิดนี้ พระพุทธเจ้าตัดความผูกพันต่อครอบครัว เมื่อตัดสายใยเหล่านั้นได้แล้ว ท่านก็สามารถบรรลุปัญญาซึ่งนำไปสู่ความหลุดพ้น

⟪५⟫. **⟪समोहः⟫ ⟪स्वन्नानि⟫ ⟪च⟫ ⟪सुरूपाश्च⟫ ⟪भुङ्क्ते⟫ ⟪वीतमोहस्त्वन्नं⟫ ⟪च⟫ ⟪सम्पन्नरूपशरीरां⟫ ⟪च⟫ ⟪न⟫ ⟪लुभ्यति⟫ ⟪।⟫ ⟪स⟫ ⟪हि⟫ ⟪लोभं⟫ ⟪च⟫ ⟪क्रोधं⟫ ⟪च⟫ ⟪रुणद्धि⟫ ⟪प्रज्ञायां⟫ ⟪च⟫ ⟪युङ्क्ते⟫ ⟪॥५॥⟫**
(⟪मोहेन⟫ ⟪सहितः⟫ ⟪।⟫ ⟪शोभनं⟫ ⟪रूपं⟫ ⟪यासां⟫ ⟪ताः⟫ ⟪।⟫ ⟪वीतो⟫ ⟪मोहो⟫ ⟪यस्य⟫ ⟪सः⟫ ⟪।⟫ ⟪सम्पन्नं⟫ ⟪रूपं⟫ ⟪यस्याः⟫ ⟪सा⟫)
คนเขลาเพลิดเพลินกับอาหารอันประณีตและสตรีรูปงาม ผู้ whose ความเขลาล่วงลับไป ไม่ปรารถนาอาหารอันประณีตและสตรีที่มีร่างกายสมบูรณ์ เพราะเขาป้องกันความโลภและความโกรธ และตั้งใจมั่นในปัญญา
