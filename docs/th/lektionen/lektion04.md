## 4.1. คำถามเพิ่มเติมง่ายๆ (คำถามด้วยคำ) และคำตอบ

### 4.1.1. สรรพนามคำถามและสรรพนามแสดงอาการ

#### 4.1.1.1. สรรพนามคำถาม (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

#### 4.1.1.2. สรรพนามแสดงอาการ (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box

| :--- | :---: | :---: | :---: |

**สำหรับกรณีนามเอกพจน์เพศชาย:**
- **sa, eṣa** (⟪स⟫ ⟪एष⟫) อยู่ก่อนเสียงทั้งหมดยกเว้น **-a** สั้น
- **so, eṣo** (⟪सो⟫ ⟪एषो⟫) อยู่ก่อน **-a** ซึ่งถูกตัดออกด้วย Avagraha (หายไป)
- **saḥ, eṣaḥ** (⟪सः⟫ ⟪एषः⟫) อยู่เฉพาะในหยุด (ท้ายประโยค, ท้ายบทกวี)

เพื่อให้สามารถสร้างประโยคด้วยสรรพนามเหล่านี้ (sarvanāman n.) จำเป็นต้องมีความรู้เกี่ยวกับกฎสันธิต่อไปนี้:

### 4.1.2. สันธิของ -m ที่ออกเสียงท้าย

::: grammar-box
**-m ที่ออกเสียงท้ายจะถูกแทนที่ด้วย Anusvāra (-ṃ) ก่อนพยัญชนะ ที่ท้ายประโยคหรือบทกวีและก่อนสระ -m จะคงอยู่**
:::
### 4.1.3. สันธิของ -e ที่ออกเสียงท้าย

::: grammar-box
1. **ก่อน a- -e จะคงอยู่: a- ที่ขึ้นต้นจะถูกตัดออกด้วย Avagraha:**
เช่น ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ "ไฟเหล่านี้"

2. **ก่อนสระอื่นที่ไม่ใช่ a- สั้น -e จะถูกแทนที่ด้วย -a พร้อม Hiatus โดยทั่วไป การแทนที่ด้วย -ay ก็เกิดขึ้นเช่นกัน:**
เช่น ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (หายาก: imay īśvarāh = ⟪इमयीश्वराः⟫) "เจ้านายเหล่านี้"
:::
### 4.1.4. สันธิของ -d ที่ออกเสียงท้าย

::: grammar-box
**-d ที่ออกเสียงท้ายจะถูกแทนที่ด้วย -t ในหยุดและก่อนพยัญชนะกutturales ไร้เสียง (k, kh) และ Labials (p, ph)**

การแทนที่ก่อนพยัญชนะอื่นจะได้รับการกล่าวถึงในภายหลัง หลีกเลี่ยงการรวมเสียงดังกล่าวชั่วคราว!
:::

ตัวอย่างคำถามรูปแบบอื่น:

> viṣṇuḥ kaḥ? = ⟪विष्णुः⟫ ⟪कः⟫ คำตอบ: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (ในประโยคนาม สามารถวางประธานไว้ที่ต้นประโยคเพื่อเน้นการเชื่อมโยงกับคำถามได้ เช่น)

หมายเหตุ: คำตอบที่คุณสามารถให้ได้จากความรู้ภาษาสันสกฤตที่มีอยู่จนถึงขณะนี้ ยังไม่ถือว่าถูกต้องตามสำนวนภาษาสันสฤกต์ที่ดีในทุกด้าน
