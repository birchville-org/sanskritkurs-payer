# บทที่ 22

## 22.1. อับโซลูติฟ (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

หากต้องการแสดงในภาษาสันสกฤตว่า การกระทำของประธาน (⟪कर्तृ⟫) เกิดขึ้นก่อนการกระทำอื่นของประธานเดียวกัน หรือเกิดขึ้นพร้อมกันในฐานะเหตุการณ์ประกอบ จะใช้รูปอับโซลูติฟ (⟪क्त्वा । ल्यप्⟫) ดังนั้น

"หลังจากที่เขาได้กระทำสิ่งนั้นแล้ว เขาก็กระทำอีกสิ่งหนึ่ง" ; "เขากระทำสิ่งนี้ แล้วจึงกระทำอีกสิ่งหนึ่ง" ; "เนื่องจากเหตุนี้ เขาจึงกระทำอีกสิ่งหนึ่ง" ; "ข้าพเจ้ามา เห็น และชนะ" เป็นต้น

อับโซลูติฟเป็นคำวิเศษณ์เชิงกริยา (Verbal-Adverb) กล่าวคือ ไม่มีการผันสำหรับบุคคลและจำนวน และไม่มีการเปลี่ยนรูปตามกรณีทางไวยากรณ์ แต่โดยทั่วไป (ยกเว้นข้อยกเว้นบางประการ) จะมีประธาน (⟪कर्तृ⟫) เดียวกันกับการกระทำหลักที่อับโซลูติฟกล่าวถึง ซึ่งเกิดขึ้นก่อนหรือเป็นเหตุการณ์ประกอบ ประธานของรูปอับโซลูติฟจึงอยู่ในกรณีนาม (⟪प्रथमा⟫) หรือกรณีเครื่องมือ (⟪तृतीया⟫)

นอกเหนือจากคำสมาสแล้ว อับโซลูติฟเป็นเครื่องมือการแสดงออกที่พบบ่อยที่สุดในภาษาสันสกฤต

ในการแปลเป็นภาษาไทย ควรหลีกเลี่ยงการใช้คำว่า "หลังจากที่" ซ้ำๆ ให้ใช้รูปแบบการแสดงออกทางเวลาที่ใช้กันทั่วไปในภาษาไทยแทน

**แผนภาพ:**

(คำระบุเพิ่มเติมเกี่ยวกับอับโซลูติฟ: คำบอกเงื่อนไข, กรรม ฯลฯ) - อับโซลูติฟ - อับโซลูติฟ - ... - อับโซลูติฟ - ... ประธาน + วลีกริยา (ในรูปกัมมันตุกรรมหรือรับกรรม)

:::
**ตัวอย่าง:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = โครงสร้างรับกรรม: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**  
"ชายคนนั้นก้าวเข้าสู่บ้าน เห็นเด็กหญิงตัวน้อย และกล่าวทักทาย"

พหูพจน์: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. การสร้างรูปกรรมวิเศษ (Absolutiv)

::: grammar-box
**การสร้างรูปกรรมวิเศษ (Absolutiv)**

*   กริยาที่ไม่มีคำนำหน้า: รูปกรรมวิเศษลงท้ายด้วย **-tvā**
*   กริยาที่มีคำนำหน้า: รูปกรรมวิเศษลงท้ายด้วย **-ya** หรือ **-tya**
:::
### 22.2.1. กริยาที่ไม่มีคำนำหน้า: รูปกรรมวิเศษลงท้ายด้วย -⟪त्वा⟫

::: grammar-box

**วิธีการสร้าง:**

(โดยทั่วไป) รากศัพท์ในระดับต่ำสุด ในรูปแบบที่มีก่อนรูปกริยาวิเศษณ์อดีต (PPP) + **-tvā** (**-⟪त्वा⟫**)

มีเพียง **a-** / **an-** ในความหมายปฏิเสธเท่านั้น ที่สามารถประสมกับคำลงท้าย **-⟪त्वा⟫** ได้: ⟪अकृत्वा⟫ "โดยไม่ได้กระทำ"

:::
**ตัวอย่าง:**

::: indent
⟪आप्त्वा⟫ "หลังจากที่เขาสังหาร / เธอสังหาร / มันสังหาร / ฉันสังหาร / คุณสังหาร / เราสังหาร / พวกคุณสังหาร / พวกเขาสังหาร / ข้าทั้งสองสังหาร / ท่านทั้งสองสังหาร / พวกเขาทั้งสองสังหาร แล้ว"

⟪आसित्वा⟫ "หลังจากที่เขานั่ง / นั่งอยู่"

⟪इत्वा⟫ "หลังจากที่เขาเดิน / เดินอยู่"

⟪स्थित्वा⟫ "หลังจากที่เขาตั้งตัว / ตั้งอยู่"

⟪जित्वा⟫ "หลังจากที่เขาชนะ / ชนะแล้ว"

⟪उक्त्वा⟫ "หลังจากที่เขาพูด / พูดแล้ว"
:::
### 22.2.2. กริยาที่มีคำนำหน้า

#### 22.2.2.1. รากศัพท์ที่มีสระยาว (ยกเว้น -ā) หรือลงท้ายด้วยพยัญชนะ

::: grammar-box

**(โดยทั่วไป) รากศัพท์ในระดับต่ำสุด + -ya**

:::
**ตัวอย่าง:**

::: indent
⟪उपनीय⟫ "หลังจากที่เขาได้นำมา / ได้นำมาแล้ว"

⟪प्रभूय⟫ "หลังจากที่เขาโผล่พ้นออกมา / โผล่ออกมา" "หลังจากที่เขาได้มีอำนาจ"

⟪प्राप्य⟫ "หลังจากที่เขาได้รับ / ได้รับแล้ว"
:::
#### 22.2.2.2. รากศัพท์ที่ลงท้ายด้วย -ā

::: grammar-box

**รากศัพท์ในระดับสูงสุดโดยไม่เปลี่ยนแปลง + -ya**

:::
**ตัวอย่าง:**

::: indent
⟪उपस्थाय⟫ "หลังจากที่เขาได้ก้าวเข้ามา / ก้าวเข้ามา" ; (แต่หากไม่มีคำนำหน้า: ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. รากศัพท์ที่ในระดับต่ำสุดลงท้ายด้วย -i, -u, -ṛ สั้น

::: grammar-box

**รากศัพท์ระดับลึก + -tya**

:::
**ตัวอย่าง:**

::: indent
⟪प्रस्तुत्य⟫ "หลังจากที่เขาสรรเสริญ (...) อย่างดังแล้ว"

⟪विस्मृत्य⟫ "หลังจากที่เขา (...) ลืมไปแล้ว"

⟪संस्कृत्य⟫ "หลังจากที่เขา (...) เตรียมไว้สำหรับเครื่องบูชาแล้ว"
:::
#### 22.2.2.4. รากศัพท์ลงท้ายด้วย -am / -an ซึ่งในระดับลึกจะลงท้ายด้วย -a

::: grammar-box

**เลือกได้:**

รากศัพท์ลงท้ายด้วย **-am** / **-an** + **-ya**

หรือ:

รากศัพท์ลงท้ายด้วย **-a** + **-tya**

:::
**ตัวอย่าง:**

::: indent
⟪विगम्य⟫ หรือ ⟪विगत्य⟫ "หลังจากที่เขา (...) ผ่านพ้นไปแล้ว"
:::
## 22.3. รายการคำศัพท์

**⟪काम⟫ นามเพศชาย:** ความปรารถนา, ความใคร่; ของกำนัลที่พึงประสงค์, ความสุขทางประสาทสัมผัส, รัก, เทพเจ้าแห่งความรัก

::: indent
⟪कामम्⟫ กริยาวิเศษณ์กรณี accusative: ตามความปรารถนา, อย่างใจพอใจ
:::

**⟪शक्र⟫ นามเพศชาย:** ผู้ทรงพลัง (สมัญญาของ ⟪इन्द्र⟫)

**⟪अर्ह⟫ 1 P ⟪अर्हति⟫ Pass. ⟪अर्ह्यते⟫ PPP ⟪अर्हित⟫ Inf. ⟪अर्हितुम्⟫ :** ได้รับสิ่งที่สมควร (มีความเหมาะสมในสิ่งใด), ควร, มีหน้าที่ต้องทำ, ต้อง (ในบุรุษที่สอง การนำ ⟪अर्ह्⟫ มาใช้ร่วมกับกริยาวิเศษณ์มักถูกใช้เป็นคำสั่งที่อ่อนลง: "ท่านควร...")

::: indent
**⟪अर्हन्त्⟫ 3** Part. Präs. P: ผู้ควรแก่การเคารพ ในพุทธศาสนาและเชนศาสนา: บุคคลที่บรรลุถึงการหลุดพ้นขั้นสุดท้ายแล้ว
:::
**⟪व्रत⟫ n.:** คำปฏิญาณ, หน้าที่ทางศาสนา, การปฏิบัติทางศาสนา (บุคคลให้คำมั่นกับเทพเจ้าเพื่อให้ได้สิ่งใดสิ่งหนึ่งจากท่าน ตัวอย่าง: มารดาคนหนึ่งปฏิญาณว่าจะถวายบุตรสาวของตนให้เป็นเทวโสเภณี (⟪देवदासी⟫) หากบุตรสาวของตนหายจากโรคภัยไข้เจ็บ ⟪व्रत⟫ ที่สำคัญในปัจจุบัน: การถือศีลอดอาหาร; การละเว้นจากอาหารที่ตนโปรดปราน; ความสำรวมทางเพศ; การอ่านคัมภีร์ศักดิ์สิทธิ์; การประกอบพิธีกรรมเฉพาะบางประการ; การเลี้ยงดูพราหมณ์ ฯลฯ สรุปสั้นๆ เกี่ยวกับ ⟪व्रत⟫: Walker, Hindu World Vol. II, หน้า 581-582 อย่างละเอียด: P. V. Kane: History of Dharmaśāstra Vol. 5,1 หน้า 1 - 462 ที่นั่นหน้า 253 - 462 เป็นรายการของ ⟪व्रत⟫ และเทศกาลทางศาสนา ("รายการต่อไปนี้... ไม่ได้อ้างว่าครอบคลุมอย่างสมบูรณ์" !!!)

**⟪चर्⟫ 1 P charati Pass. charyate PPP charita Inf. charitum (ภาษาสันสกฤต: ⟪चर्⟫ 1 P ⟪चरति⟫ Pass. ⟪चर्यते⟫ PPP ⟪चरित⟫ Inf. ⟪चरितुम्⟫):** เลี้ยงดู, เดินไปมา, เคลื่อนไหว, กระทำ, ปฏิบัติสิ่งใดสิ่งหนึ่ง, ดำเนินการ (เช่น **⟪व्रतं चर्⟫**: ปฏิบัติคำปฏิญาณ โดยเฉพาะความสำรวมทางเพศ)

จากสิ่งนี้:

::: indent
**⟪चर ३⟫:** เคลื่อนที่ได้; n.: สิ่งที่สามารถเคลื่อนไหวได้ = สัตว์ (ต่างจากพืช)

**⟪चरण⟫ n., m.:** เท้า

**⟪चरित⟫ n.:** การดำเนินชีวิต, กิจที่ทำในชีวิต

**⟪ब्रह्मचर्य⟫ n.:** การปฏิบัติตามพระเวท (⟪ब्रह्मन्⟫) = การศึกษาพระเวทในขั้นชีวิตแรก (คือสถานะของ ⟪ब्रह्मचारिन्⟫) ซึ่งจำเป็นต้องมีความสำรวมทางเพศอย่างเคร่งครัด; ดังนั้นจึงยังหมายถึง: ความสำรวมทางเพศ, การดำเนินชีวิตแบบพรหมจรรย์
:::
