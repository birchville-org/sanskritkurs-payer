# แบบฝึกหัด 21

ก) จงแยกคำสมาสในภาษาสันสกฤตต่อไปนี้แล้วแปล:

⟪१⟫. ⟪अनादिकालिकसंसरः⟫ ⟪।⟫
⟪अनादिः⟫ ⟪कालो⟫ ⟪यस्य⟫ ⟪सो⟫ ⟪ऽनादिकालिकः⟫ ⟪संसरः⟫ ⟪।⟫
การเวียนว่ายตายเกิดที่ไม่มีจุดเริ่มต้นและไม่มีระยะเวลาที่แน่นอน

⟪२⟫. ⟪अनादिमध्यान्तः⟫ ⟪।⟫
⟪न⟫ ⟪आदिश्च⟫ ⟪मध्यं⟫ ⟪च⟫ ⟪अन्तश्च⟫ ⟪यस्य⟫ ⟪सः⟫ ⟪।⟫
ไม่มีจุดเริ่มต้น จุดกลาง และจุดสิ้นสุด

⟪३⟫. ⟪महामैत्रीकरुणाचित्तः⟫ ⟪।⟫
⟪महती⟫ ⟪मैत्री⟫ ⟪च⟫ ⟪करुणा⟫ ⟪च⟫ ⟪यस्मिंस्तच्चित्तं⟫ ⟪यस्य⟫ ⟪सः⟫ ⟪।⟫
ด้วยหัวใจที่เปี่ยมไปด้วยเมตตาและกรุณาอันยิ่งใหญ่

⟪४⟫. ⟪सर्वहतान्धकारः⟫ ⟪।⟫
⟪सर्वस्मिन्हतो⟫ ⟪ऽन्धकारो⟫ ⟪येन⟫ ⟪सः⟫ ⟪।⟫
ผู้ที่กำจัดความมืดบอดไปทั่วทุกแห่ง

ข) จงแปล:

⟪१⟫. ⟪मृतं⟫ ⟪दहन्नग्निः⟫ ⟪सतीमपि⟫ ⟪दहति⟫ ⟪॥⟫
ไฟที่เผาผลาญศพนั้น ยังเผาผลาณีภริยาผู้ซื่อสัตย์ (สัตี) ด้วย

⟪२⟫. ⟪सद्गुरुर्महाकविस्तोत्रैर्महादेवं⟫ ⟪स्तौति⟫ ⟪॥⟫
กุรุจารย์ผู้ประเสริฐสรรเสริญพระมหาเทพด้วยบทสวดสรรเสริญของกวีเอก

⟪३⟫. ⟪महान्ति⟫ ⟪फलान्यदन्तो⟫ ⟪बाला⟫ ⟪जलमापि⟫ ⟪पिबन्ति⟫ ⟪॥⟫
เด็กชายที่กินผลไม้รสหวานนั้น ดื่มน้ำด้วย

⟪४⟫. ⟪पुजां⟫ ⟪कुर्वञ्जनो⟫ ⟪यजते⟫ ⟪च⟫ ⟪स्तौति⟫ ⟪च⟫ ⟪देवताम्⟫ ⟪॥⟫
ในระหว่างพิธีบูชา ชายผู้หนึ่งทำการบูชายัญและสรรเสริญเทพเจ้า

⟪५⟫. ⟪गुरूपनीतनरो⟫ ⟪द्विजः⟫ ⟪॥⟫
ผู้เกิดสองครั้งคือชายผู้ซึ่งได้รับการอุปสมบทในพระเวทโดยคุรุ

⟪६⟫. ⟪जितक्रोधो⟫ ⟪घ्नन्तमप्यरिं⟫ ⟪न⟫ ⟪द्वेष्टि⟫ ⟪।⟫ ⟪क्रोधजितस्तु⟫ ⟪द्वेष्टि⟫ ⟪॥⟫
ผู้ที่พิชิตความโกรธแล้ว ไม่เกลียดศัตรู แม้ศัตรูจะฆ่าเขาก็ตาม แต่ผู้ที่ถูกความโกรธพิชิตนั้น จะเกลียด
