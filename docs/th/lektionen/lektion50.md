# บทที่ 50

## 50.1. การสร้างคำนาม: การเปรียบเทียบระดับปกติ

::: grammar-box
**การเปรียบเทียบระดับปกติในภาษาสันสกฤตใช้ ⟪तद्धित⟫-ประสมท้าย**
* **-⟪तर⟫ (เพศหญิง: ⟪तरा⟫) ใน "ระดับเปรียบเทียบ"**
* **⟪तम⟫ (เพศหญิง: ⟪तमा⟫) ใน "ระดับสูงสุด"**

**ประสมท้ายเหล่านี้จะเติมเข้ากับรากศัพท์เพศบุรุษของคำคุณศัพท์ สำหรับคำนามที่มีการลดรูปกริยา (stem alternation) จะเติมเข้ากับรากศัพท์รูปแบบอ่อน ซึ่งมีรูปร่างเหมือนก่อนหน้าการลงท้าย -su ของกรณี locative (⟪पञ्चमी⟫) พหูพจน์**
:::
::: media
![](/images/lekt5007.webp)
ภาพประกอบ: ⟪लोकस्योत्तमो⟫ ⟪गिरिः⟫
⟪सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_  = ภูเขาเอเวอเรสต์
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt5007))
:::

::: grammar-box
**ความหมาย:**

**"ระดับเปรียบเทียบ" หมายถึง เมื่อไม่ได้ระบุวัตถุที่นำมาเปรียบเทียบกับ: "ค่อนข้าง, มาก, เกินไป":**

:::
::: indent
เช่น ⟪सुचितर⟫ 3 "ค่อนข้างบริสุทธิ์", "บริสุทธิ์มาก", "บริสุทธิ์เกินไป"
:::
**หากมีการระบุวัตถุที่นำมาเปรียบเทียบกับ วัตถุนั้นจะอยู่ในกรณี Ablative (⟪पञ्चमी⟫) ระดับเปรียบเทียบ + Ablative สอดคล้องกับการใช้ "กว่า" ในภาษาเยอรมัน**

::: indent
เช่น ⟪देवदत्ताद्रामो⟫ ⟪धीमत्तरः⟫ = ตามตัวอักษร: "เมื่อมองจากเทวทัตแล้ว ราชะมีปัญญามากกว่า" = "ราชะมีปัญญามากว่าเทวทัต"
:::
**"ระดับสูงสุด" หมายถึง เมื่อไม่ได้ระบุวัตถุที่นำมาเปรียบเทียบกับ: "ที่สุด, มาก":**

::: indent
เช่น ⟪सत्तम⟫ 3 (จาก ⟪सन्त्⟫) "ดีที่สุด, ดีมาก"
:::
**หากมีการระบุวัตถุที่นำมาเปรียบเทียบกับ วัตถุนั้นจะอยู่ในกรณี Genetive (⟪षष्ठी⟫) ("ของ", "ในหมู่") และระดับสูงสุดสอดคล้องกับระดับสูงสุด (superlative degree) ในภาษาเยอรมัน:**

::: indent
เช่น ⟪द्विजानां⟫ ⟪सत्तमः⟫ = "ผู้ที่ดีที่สุดของชนสองครั้งเกิด"
:::
**ประสมท้าย -⟪तर⟫ และ -⟪तम⟫ ไม่เพียงแต่สามารถเกิดขึ้นกับคำคุณศัพท์เท่านั้น แต่ยังเกิดกับคำนาม คำที่ไม่มีการผันรูป และแม้แต่รูปแบบกริยา:**

ตัวอย่าง:

::: indent
⟪गजतम⟫ บุรุษ. "ช้างที่ดีที่สุด" (⟪गज⟫) (ยังเป็นชื่อเรียกของพระพุทธเจ้าด้วย)

⟪गोतम⟫ บุรุษ. "วัวที่ใหญ่ที่สุด" (⟪गो⟫) หรือ: "ผู้ที่มีความมั่งคั่งในวัวมากที่สุด"

⟪उद्⟫ คำไม่มีการผันรูป. "ขึ้น", "ขึ้นไป" » ⟪उत्तर⟫ 3 "สูงกว่า" » ⟪उत्तम⟫ 3 "สูงสุด"
:::
**เมื่อประสมท้ายเหล่านี้เกิดขึ้นกับรูปแบบกริยา พวกมันจะปรากฏในรูปแบบ adverbial เสมอ:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

ตัวอย่าง:

::: indent
⟪पचतितराम्⟫ "เขา/เธอปรุงอาหารได้ดีกว่า"

⟪पचतितमाम्⟫ "เขา/เธอปรุงอาหารได้ดีที่สุด"
:::
**รูปแบบนี้ประสมท้ายเหล่านี้ยังมีอยู่เมื่อเกิดขึ้นกับคำที่ไม่มีการผันรูป และคำที่อนุพันธ์ถูกใช้ในลักษณะ adverbial:**

::: indent
เช่น ⟪सुतराम्⟫ (จาก ⟪सु⟫) "ในลักษณะที่ดีกว่า" (adverbial)
:::

![](/images/lekt5006.webp)
