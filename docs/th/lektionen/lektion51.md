# บทที่ 51

## 51.1. ⟪उपपद⟫-คอมโพสิตา

::: grammar-box
**⟪उपपद⟫-คอมโพสิตา (⟪उपपद⟩ n. "คำประกอบ") เป็น ⟪तत्पुरुष⟫ ที่มีนามกริยา (verbal noun) เป็นองค์ประกอบหลัง ซึ่งปรากฏเฉพาะในตำแหน่งองค์ประกอบหลังของคอมโพสิตาเท่านั้น ไม่ปรากฏเป็นคำเดี่ยวที่เป็นอิสระ ⟪उपपद⟫ ถูกสร้างด้วย ⟪कृत्⟫-suffixes**
* **-Ø**
* **-a**
* **-t**

**ถูกสร้างขึ้น เป็นนามผู้กระทำ (nomina agentis) กล่าวคือ หมายถึง ผู้กระทำการ (⟪कर्तृ⟫) ซึ่งกระทำกิจการที่ระบุโดยรากศัพท์พื้นฐาน**

**คอมโพสิตาประเภทนี้ โดยผู้แสดงความคิดเห็นดั้งเดิมไม่ได้แก้ความด้วยการรวมกันของนาม แต่แก้ไขโดยใช้รูปกริยา:**

ตัวอย่าง:

:::

⟪कुलघ्नः⟫ = ⟪कुलम्हन्तीति⟫ ⟪कुलघ्नः⟫
:::

## 51.2. การผันคำของรากศัพท์ที่ลงท้ายด้วยพยัญชนะเดี่ยว (ยกเว้น Nasal, Halbvokal, -s)

::: grammar-box
**รากศัพท์ที่ลงท้ายด้วยพยัญชนะเดี่ยว (ยกเว้น Nasal, Halbvokal, -s) ไม่มีการผันระดับรากศัพท์ การผันคำเกิดขึ้นอย่างสม่ำเสมอโดยสมบูรณ์โดยการเติม ending ของกรณี (casus endings) ตามปกติ**

**ข้อยกเว้นเพียงอย่างเดียว: ในกรณี Nom., Akk., Vok. พหูพจน์ของเพศกลาง จะมีการแทรกตัวอักษรนาสัล (nasal) ไว้ก่อนเสียงสุดท้ายของรากศัพท์**
:::
### 51.2.1. รากศัพท์ที่ลงท้ายด้วยพยัญชนะหยุด (consonant) ที่ไม่ใช่พาละตา (non-palatal stop)

::: grammar-box
**กฎการเปลี่ยนแปลงเสียงตามปกติใช้บังคับ กล่าวคือ**
* **ที่ตำแหน่งท้ายคำ (Auslaut) จะปรากฏเป็นพยัญชนะหยุดไม่พ่นลม (Nonaspirate) ที่ไม่มีเสียงร้อง (voiceless) ที่สอดคล้องกัน**
* **ก่อนส่วนต่อท้าย -su ของกรณี Lok. พหูพจน์ เสียงสุดท้ายของรากศัพท์จะถูกแทนที่ด้วยพยัญชนะหยุดไม่พ่นลมที่ไม่มีเสียงร้องที่สอดคล้องกันก่อน จากนั้นจึงเกิดการเปลี่ยนแปลงเสียงตามกฎที่เกี่ยวข้อง**
* **ก่อนพยัญชนะที่มีเสียงร้อง (voiced consonant) เสียงสุดท้ายของรากศัพท์จะถูกแทนที่ด้วยพยัญชนะหยุดไม่พ่นลมที่มีเสียงร้องที่สอดคล้องกัน**
:::

### 51.2.2. รากศัพท์ที่ลงท้ายด้วยพยัญชนะหยุดพาละตา (palatal stop) (c, ch, j), ś, ṣ

::: grammar-box
**ก่อนส่วนต่อท้ายที่ขึ้นต้นด้วยสระ เสียงสุดท้ายของรากศัพท์จะคงเดิมไม่เปลี่ยนแปลง**

**ก่อนส่วนต่อท้ายอื่นๆ ใช้กฎดังนี้:**

* **-c และ -j ที่ลงท้าย จะถูกแทนที่ด้วย k จากนั้นรากศัพท์จะถูกปฏิบัติเสมือนว่าลงท้ายด้วย -k**
* **ในคำบางคำ (ดูรายชื่อได้ที่ Kielhorn, Grammatik หน้า 18) -j ที่ลงท้ายจะถูกแทนที่ด้วย -ṭ**
* **-ch ที่ลงท้าย จะถูกแทนที่ด้วย -ṭ**
* **-ś และ -ṣ ที่ลงท้าย จะถูกแทนที่ด้วย -ṭ ยกเว้นบางกรณี ในกรณีพิเศษนั้น -ś และ -ṣ จะถูกแทนที่ด้วย -k**

**กล่าวคือ**

* **-c » -k**
* **-ch » -ṭ**
* **-j » -k หรือ -ṭ**
* **-ś » -ṭ หรือ -k**
* **-ṣ » -ṭ หรือ -k**
:::

### 51.2.3. รากศัพท์ที่ลงท้ายด้วย -h

::: grammar-box
**ก่อนส่วนต่อท้ายที่ขึ้นต้นด้วยสระ ตัว -h จะคงเดิมไม่เปลี่ยนแปลง**

**ก่อนส่วนต่อท้ายอื่นๆ**
* **โดยปกติแล้ว -h จะถูกแทนที่ด้วย -ḍh**
* **หากรากศัพท์พื้นฐานเริ่มต้นด้วย d- -h จะถูกแทนที่ด้วย -gh เช่นเดียวกันกับคำอื่นๆ บางคำซึ่งอาจเลือกได้หรือบังคับ (ดูสรุปได้ที่ Kielhorn, Grammatik §80,2)**
* **(ในตำแหน่งท้ายของชื่อรากศัพท์ -h จะถูกแทนที่ด้วย -dh)**

**หลังจากการแทนที่เหล่านี้ รากศัพท์จะถูกพิจารณาต่อไป เสมือนว่าลงท้ายด้วย -ḍh, -gh หรือ -dh**

**ดูตารางผันคำที่ Kielhorn, Grammatik, หน้า 20-21**
:::

## 51.3. การประสมเสียงของ h- ที่ขึ้นต้นคำ

::: grammar-box
**ก่อนหน้า h- ที่ขึ้นต้นคำ พยัญชนะหยุดตามหลังจะถูกแทนที่ด้วยพยัญชนะไม่พ่นลมที่มีเสียงร้องคู่กัน และ h- ที่ขึ้นต้นจะถูกแทนที่ด้วยพยัญชนะพ่นลมที่มีเสียงร้องคู่กันซึ่งสอดคล้องกับพยัญชนะหยุดนั้น:**

:::
::: indent
⟪तत्⟫ + ⟪हि⟫ » ⟪तद्धि⟫

⟪वाक्⟫ + ⟪हि⟫ » ⟪वाग्घि⟫

⟪परिव्राट्⟫ + ⟪हि⟫ » ⟪परिव्राड्ढि⟫
:::
## 51.4. การประสมเสียงของ ch- ที่ขึ้นต้นคำ

::: grammar-box
**ch- ที่ขึ้นต้นคำจะถูกแทนที่ด้วย cch- หลังสระสั้น, หลัง ⟪मा⟩ "ไม่" และหลัง ⟪आ⟩ "เพื่อ":**

:::
::: indent
⟪न⟫ + ⟪छिन्दति⟫ » ⟪न⟫ ⟪च्छिन्दति⟫
:::

::: grammar-box
**ภายในคำ -ch- หลังสระทุกชนิดจะถูกแทนที่ด้วย -cch-:**

:::
::: indent
เช่น ⟪छिद्⟫ » ⟪चिच्छेद⟫
