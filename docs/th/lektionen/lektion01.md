## 1.2. เสียงของภาษาสันสกฤต

เสียงของภาษาสันскฤตตามการจัดประเภทแบบดั้งเดิมของอินเดีย และอักษรโรมันทางวิทยาศาสตร์

::: media
![](/images/lekt0106.webp)
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt0106))
:::
พจนานุกรมภาษาสันสกฤตสมัยใหม่เรียงลำดับตามการจัดประเภทนี้ การจัดประเภทและลำดับของเสียงเหล่านี้มีความจำเป็นต่อการเข้าใจไวยากรณ์ภาษาสันสกฤต จึงจำเป็นต้องจำให้ได้:

::: note-box
การจัดประเภท
- **สระเดี่ยว** (samānākṣara -- ⟪समानाक्षर⟫):
⟪अ⟫ a, ⟪आ⟫ ā, ⟪इ⟫ i, ⟪ई⟫ ī, ⟪उ⟫ u, ⟪ऊ⟫ ū, ⟪ऋ⟫ ṛ, ⟪ॠ⟫ ṝ, ⟪ऌ⟫ ḷ
- **สระประสม** (sandhyakṣara -- ⟪सन्ध्यक्षर⟫):
⟪ए⟫ e, ⟪ऐ⟫ ai, ⟪ओ⟫ o, ⟪औ⟫ au
- **พยัญชนะ** (vyañjana / hal -- ⟪व्यञ्जन⟫ / ⟪हल्⟫):
⟪क⟫ ka, ⟪ख⟫ kha, ⟪ग⟫ ga, ⟪घ⟫ gha, ⟪ङ⟫ ṅa
⟪च⟫ ca, ⟪छ⟫ cha, ⟪ज⟫ ja, ⟪झ⟫ jha, ⟪ञ⟫ ña
⟪ट⟫ ṭa, ⟪ठ⟫ ṭha, ⟪ड⟫ ḍa, ⟪ढ⟫ ḍha, ⟪ण⟫ ṇa
⟪त⟫ ta, ⟪थ⟫ tha, ⟪द⟫ da, ⟪ध⟫ dha, ⟪न⟫ na
⟪प⟫ pa, ⟪फ⟫ pha, ⟪ब⟫ ba, ⟪भ⟫ bha, ⟪म⟫ ma
⟪य⟫ ya, ⟪र⟫ ra, ⟪ल⟫ la, ⟪व⟫ va
⟪श⟫ śa, ⟪ष⟫ ṣa, ⟪स⟫ sa
⟪ह⟫ ha
:::
### 1.2.1. เกี่ยวกับการออกเสียงของเสียงแต่ละตัว

::: laut-table
| เสียง | คำอธิบาย |
| :--- | :--- |
| **a - ⟪अ⟫** | "สระ a สั้น" ชาวอินเดีย -- ตั้งแต่สมัยโบราณ -- มักออกเสียงเป็น ə ในยุโรปออกเสียงเป็นสระ a สั้น ในเบงกอลออกเสียงเป็นสระ o สั้นเข้ม |
| **ṛ - ⟪ऋ⟫** | เหมือนกับ r ที่มีการเปล่งเสียงสระในภาษาเช็ก มีเสียงสะท้อนเบาๆ ของ i |
| **ṝ - ⟪ॠ⟫** | เหมือนกับ r ที่มีการเปล่งเสียงสระในภาษาเช็ก มีเสียงสะท้อนเบาๆ ของ u |

| **jñ - ⟪ज्ञ्⟫** | เช่นเดียวกับ dny (ภาษามราฐี) หรือ gy (อินเดียเหนือ) |
| **ś - ⟪श्⟫** | เสียงช โดยปลายลิ้นโค้งลงด้านล่าง คล้ายกับเสียง ช ในคำว่า "ผสม" |
| **ṣ - ⟪ष्⟫** | เสียงจ โดยปลายลิ้นโค้งกลับเข้าหาเพดานปาก มักถูกออกเสียงลึกในลำคอมากจนเกือบเหมือนเสียง kh |
| **h - ⟪ह्⟫** | เสียงพ่นลม ไม่ใช้เป็นเครื่องหมายยืดเสียง |
| **ḥ - :** | **วิสর্ชนะ (Visarga)** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫. เสียงพ่นลมไม่มีเสียงร้อง พร้อมกับการสะท้อนของสระก่อนหน้าหรือส่วนที่สองของไดฟธองต์ก่อนหน้า: agniḥ -- ⟪अग्निः⟫ = agnihi, devaiḥ -- ⟪देवैः⟫ = devaihi, gauḥ -- ⟪गौः⟫ = gauhu |
| **ṃ** | **อนุสวาร (Anusvara)** -- ⟪अनुस्वर⟫. ก่อนเสียงเสียดสี, h, l: การทำให้สระเป็นเสียงจมจมูก ในตำแหน่งท้ายประโยค = m. ในกลางประโยคก่อนพยัญชนะ: เป็นเสียงจมจมูกที่สอดคล้องกับพยัญชนะตามหลัง: saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
การออกเสียงที่ดีที่สุดเกิดขึ้นเมื่อคุณอ่านประโยค บทกวี หรือคำศัพท์ค่อนข้างช้าและเรียบๆ โดยคำนึงถึงความยาวของสระอย่างแม่นยำ
