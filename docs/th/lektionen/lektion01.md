## 1.2. เสียงของภาษาสันสกฤต

เสียงของภาษาสันสกฤตตามการจัดหมวดหมู่แบบอินเดียดั้งเดิมและการถอดเสียงทางวิทยาศาสตร์

::: media
![](/images/lekt0106.webp)
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt0106))
:::
พจนานุกรมภาษาสันสกฤตสมัยใหม่เรียงลำดับตามการจัดหมวดหมู่นี้ การจัดหมวดหมู่นี้จำเป็นต่อการเข้าใจไวยากรณ์ภาษาสันสกฤต จึงต้องจำให้ได้:

::: note-box
การจัดหมวดหมู่
- **สระเดี่ยว** (samānākṣara -- ⟪समानाक्षर⟫):
⟪अ⟫ a, ⟪आ⟫ ā, ⟪इ⟫ i, ⟪ई⟫ ī, ⟪उ⟫ u, ⟪ऊ⟫ ū, ⟪ऋ⟫ ṛ, ⟪ॠ⟫ ṝ, ⟪ऌ⟫ ḷ
- **สระประสม** (sandhyakṣara -- ⟪सन्ध्यक्षर⟫):
⟪ए⟫ e, ⟪ऐ⟫ ai, ⟪ओ⟫ o, ⟪औ⟫ au
- **พยัญชนะ** (vyañjana / hal -- ⟪व्यञ्जन⟫ / ⟪हल्⟫):
⟪क⟫ ka, ⟪ख⟫ kha, ⟪ग⟫ ga, ⟪घ⟫ gha, ⟪ङ⟫ ṅa
⟪च⟫ ca, ⟪छ⟫ cha, ⟪ज⟫ ja, ⟪झ⟫ jha, ⟪ञ⟫ ña
⟪ट⟫ ṭa, ⟪ठ⟫ ṭha, ⟪ड⟫ ḍa, ⟪ढ⟫ ḍha, ⟪ण⟫ ṇa
⟪त⟫ ta, ⟪थ⟫ tha, ⟪द⟫ da, ⟪ध⟫ dha, ⟪न⟫ na
⟪प⟫ pa, ⟪फ⟫ pha, ⟪ब⟫ ba, ⟪भ⟫ bha, ⟪म⟫ ma
⟪य⟫ ya, ⟪र⟫ ra, ⟪ल⟫ la, ⟪व⟫ va
⟪श⟫ śa, ⟪ष⟫ ṣa, ⟪स⟫ sa
⟪ह⟫ ha
:::
### 1.2.1. เกี่ยวกับการออกเสียงของเสียงแต่ละตัว

::: laut-table
| เสียง | คำอธิบาย |
| :--- | :--- |
| **a - ⟪अ⟫** | "สระ a สั้น" ชาวอินเดีย -- ตั้งแต่สมัยโบราณ -- มักออกเสียงเป็น ə ในยุโรปออกเสียงเป็นสระ a สั้น ในเบงกอลออกเสียงเป็นสระ o สั้นทึบ |
| **ṛ - ⟪ऋ⟫** | เหมือนสระ r ที่มีการเปล่งเสียงของเช็ก ปล่อยเสียง i เบาๆ |
| **ṝ - ⟪ॠ⟫** | เหมือนสระ r ที่มีการเปล่งเสียงของเช็ก ปล่อยเสียง u เบาๆ |

| **jñ - ⟪ज्ञ्⟫** | เช่นเดียวกับ dny (ภาษา มราฐี) หรือ gy (อินเดียเหนือ) |
| **ś - ⟪श्⟫** | เสียงช ด้วยปลายลิ้นโค้งลงด้านล่าง คล้ายกับเสียง ช ในคำว่า "ผสม" |
| **ṣ - ⟪ष्⟫** | เสียงอ ด้วยปลายลิ้นโค้งกลับ มักถูกออกเสียงลึกในลำคอมากจนเกือบเหมือน kh |
| **h - ⟪ह्⟫** | เสียงพ่นลม ไม่ใช้เป็นเครื่องหมายยืดเสียง |
| **ḥ - :** | **Visarga (Visarjanīya)** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫. เสียงพ่นลมไม่มีเสียงตามหลังด้วยเสียงสะท้อนของสระก่อนหน้าหรือส่วนที่สองของไดฟธองต์ที่มาก่อน: agniḥ -- ⟪अग्निः⟫ = agnihi, devaiḥ -- ⟪देवैः⟫ = devaihi, gauḥ -- ⟪गौः⟫ = gauhu |
| **ṃ** | **Anusvara** -- ⟪अनुस्वर⟫. ก่อนเสียงเสียดสี, h, l: การทำให้สระเป็นนาซัล ในตำแหน่งสิ้นสุด = m. ในตำแหน่งกลางคำก่อนพยัญชนะ: นาซัลที่สอดคล้องกับพยัญชนะตามหลัง: saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
การออกเสียงที่ดีที่สุดเกิดขึ้นเมื่ออ่านประโยค บทกวี หรือคำค่อนข้างช้าและ monotone โดยคำนึงถึงความยาวของสระอย่างแม่นยำ


## 1.3. แบบฝึกหัด

1. varṇa brāhmaṇaḥ kṣatriya vaiśya śūdra — ⟪वर्ण⟫ ⟪ब्राह्मणः⟫ ⟪क्षत्रिय⟫ ⟪वैश्य⟫ ⟪शूद्र⟫
2. brahmā viṣṇu śiva — ⟪ब्रह्मा⟫ ⟪विष्णु⟫ ⟪शिव⟫

4. ṛgveda sāmaveda yajurveda atharvaveda — ⟪ऋग्वेद⟫ ⟪सामवेद⟫ ⟪यजुर्वेद⟫ ⟪अथर्ववेद⟫
5. upaniṣad — ⟪उपनिषद्⟫
6. jaina bauddha — ⟪जैन⟫ ⟪बौद्ध⟫
7. prajñāpāramitā — ⟪प्रज्ञापारमिता⟫
8. cakra vajra — ⟪चक्र⟫ ⟪वज्र⟫
9. pitṝn — ⟪पितॄन्⟫
10. saṃskṛta — ⟪संस्कृत⟫
