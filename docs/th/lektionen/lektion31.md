# บทที่ 31

## 31.1. กลุ่มกริยาปัจจุบันที่ 7 (⟪रुधादि⟫ = "⟪रुध्⟫ ฯลฯ")

::: grammar-box
**การสร้าง:**

**ก่อนพยัญชนะท้ายของรากศัพท์ระดับต่ำ จะมีการแทรกสิ่งที่เรียกว่า "นาสิกอินฟิกซ์" (-na- หรือ -n-) เข้าไป:**

*   **ในรากที่แข็งแรง: -na-**
*   **ในรากที่อ่อนแอ: -n-**

**สำหรับการเชื่อมพยัญชนะท้ายของรากศัพท์กับรูปผันที่เริ่มต้นด้วยพยัญชนะนั้น ใช้กฎเดียวกันกับกลุ่มกริยาปัจจุบันที่ 2**
:::
ตัวอย่าง:

⟪युज्⟫ 7U "ผูก, ร้อย"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **บอกเล่า** | **บุรุษที่ 3 เอกพจน์** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(ก่อนกuttural ภายในคำ พยัญชนะนาสิกจะถูกแทนที่ด้วย -ṅ-) |
| | **บุรุษที่ 3 พหูพจน์** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **ออปติฟ** | **บุรุษที่ 3 เอกพจน์** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |

:::
⟪रुध्⟫ 7U "หยุด, ทำให้หยุดนิ่ง"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **บอกเล่า** | **บุรุษที่ 3 เอกพจน์** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **บุรุษที่ 3 พหูพจน์** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **ออปติฟ** | **บุรุษที่ 3 เอกพจน์** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **บุรุษที่ 3 พหูพจน์** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **ปาร์ทิซิพ ปัจจุบัน** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brหญิง: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**ในรากศัพท์บางชนิด -n- ของกริยาปัจจุบันรูปอ่อนได้แทรกเข้าไปสู่กาลที่ไม่ใช่ปัจจุบันแล้ว ทำให้รากศัพท์เหล่านี้ถูกกำหนดโดยมีนาสิกอินฟิกซ์**
:::
ตัวอย่าง:

⟪भञ्ज्⟫ 7P "แตก"

::: indent
*   บอกเล่า ปัจจุบัน
*   3.ส.ป. ⟪भनक्ति⟫ (bha-na + j + ti)
*   3.พ.ป. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   อนาคต: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   ปาสซีฟ: ⟪भज्यते⟫ (either จากเดิมรากศัพท์ ⟪भज्⟫ หรือจาก *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (อาจมาจาก *bhñj + na)
:::
