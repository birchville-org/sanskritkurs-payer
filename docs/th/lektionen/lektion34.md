# บทที่ 34

## 34.1. รูปสมบูรณ์ (⟪लिट्⟫)

ในภาษาสันสกฤตคลาสสิก มีเฉพาะรูปบอกเล่า (Indikativ) และคำคุณศัพท์นาม (Partizip) ของรากสมบูรณ์เท่านั้น

::: grammar-box
**มีรูปแบบการสร้างรูปสมบูรณ์สองแบบ:**
*   **รูปสมบูรณ์ที่มีคำซ้ำ (reduplizierte Perfekt) = ⟪द्वित्वलिट्⟫**
*   **รูปสมบูรณ์แบบอภินิหาร (periphrastische Perfekt) = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**รูปสมบูรณ์แบบอภินิหาร (⟪अनुप्रयोगलिट्⟫) ใช้ในกรณี:**
1. **กับคำกริยาที่สร้างจากคำอื่น (Kausativ, Desiderativ, Frequentativ, Denominativa)**
2. **กับรากที่ขึ้นต้นด้วยสระยาว (ยกเว้น ā-) หรือด้วยสระ (ยกเว้น a-) นำหน้าโดยพยัญชนะสองตัว**
3. **กับรากอื่นๆ อีกบางประการ**
:::
## 34.2. รูปสมบูรณ์ที่มีคำซ้ำ (⟪द्वित्वलिट्⟫)

### 34.2.1. การลดระดับของราก (การผันแปรของรากคำ)

::: grammar-box
**การสร้าง:**

**รากแข็งแรง (รากเต็มรูp):** เอกพจน์ ปารัสไพบท
*   **รากที่มีคำซ้ำอยู่ในระดับสูงหรือระดับขยาย + ท้ายรูปสมบูรณ์**

**รากอ่อน (รากลดรูป):** รูปแบบอื่นๆ ทั้งหมด
*   **รากที่มีคำซ้ำอยู่ในระดับต่ำ + ท้ายรูปสมบูรณ์**
:::
::: grammar-box
**โดยทั่วไป (แม้แต่ภายนอกรูปสมบูรณ์) รากที่มีรูปแบบดังต่อไปนี้ไม่มีการลดระดับของราก:**
*   **(พยัญชนะ)-พยัญชนะ-สระยาว-พยัญชนะ**
*   **(พยัญชนะ)-พยัญชนะ-สระ-พยัญชนะ-พยัญชนะ**

**ในรูปสมบูรณ์ รากที่มีรูปแบบดังต่อไปนี้ additionally ไม่มีการลดระดับของราก:**
*   **a-พยัญชนะ**
*   **ā-พยัญชนะ**
:::
### 34.2.2. ท้ายรูปสมบูรณ์

::: grammar-box

| | เอกพจน์ที่ 3 | พหูพจน์ที่ 3 |
| :--- | :--- | :--- |
| **ปารัสไพบท** | **-a** | **-ur** |
| **อัตมันเนปท** | **-e** | **-re** |

:::
### 34.2.3. สระเชื่อม -i-

::: grammar-box
**ก่อนท้ายรูปพหูพจน์ที่ 3 ของอัตมันเนปท (-re) จะปรากฏสระเชื่อม -i- เสมอ ก่อนท้ายรูปอื่นๆ ที่ขึ้นต้นด้วยพยัญชนะในกรณีของรากส่วนใหญ่**
:::
### 34.2.4. การทำคำซ้ำของรากที่ขึ้นต้นด้วยพยัญชนะ

::: grammar-box
**กฎสำหรับการทำคำซ้ำพยัญชนะต้นเป็นไปตามที่กำหนดไว้ใน [บทที่ 33](lektion33.md)**

**สระที่ใช้ในการทำคำซ้ำของรากที่ขึ้นต้นด้วยพยัญชนะคือสระสั้นของราก**

**ไดฟธองก์นำหน้าพยัญชนะจะถูกลดรูปเป็นสระระดับต่ำสั้นที่สอดคล้องกัน**

**ṛ, ṝ, ḷ และไดฟธองก์ท้ายจะถูกทำคำซ้ำด้วย -a-**
:::
ตัวอย่าง:

::: grammar-box

| ราก | รูปสมบูรณ์ เอกพจน์ที่ 3 ป. |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::
::: grammar-box
**รากบางประการที่ขึ้นต้นด้วย y- หรือ v- จะทำคำซ้ำด้วย i- หรือ u- ซึ่งในรูปอ่อนจะ "รวมตัว" กับสระราก**
:::
ตัวอย่าง:

::: grammar-box

| ราก | รูปสมบูรณ์ เอกพจน์ที่ 3 ป. | พหูพจน์ที่ 3 รูปสมบูรณ์ ป. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. การทำคำซ้ำของรากที่ขึ้นต้นด้วยสระ

::: grammar-box
**1. a- หรือ ā- ต้นจะได้รับการทำคำซ้ำด้วย a- ส่งผลให้ปรากฏเป็น ā-**
:::
ตัวอย่าง:

::: grammar-box

| ราก | รูปสมบูรณ์ เอกพจน์ที่ 3 ป. |
| :--- | :--- |
| ⟪अस्⟫ 2 "เป็น" และ ⟪अस्⟫ 4 "โยน" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. รากที่ขึ้นต้นด้วย i- จะมีพยางค์ทำคำซ้ำเป็น iy- ในรากแข็งแรง และ i- ในรากอ่อน ซึ่งรวมตัวกับสระรากกลายเป็น ī- หลักการเดียวกันนี้ใช้กับการขึ้นต้นด้วย u-**
:::
ตัวอย่าง:

::: grammar-box

| รากศัพท์ | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. รากศัพท์ที่ลงท้ายด้วย a- ก่อนพยัญชนะสองตัว หรือลงท้ายด้วย ṛ- มีพยางค์ซ้ำเป็น ān-**
:::
ตัวอย่าง:

::: grammar-box

| รากศัพท์ | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. ประเภทของ Perfect ที่มีการซ้ำ

หลักการแบ่งประเภท: ลักษณะพิเศษของการลดรูปฐานศัพท์:
*   Perfect โดยไม่มีการลดรูปฐานศัพท์: ประเภท I
*   Perfect ที่มีการลดรูปฐานศัพท์: ประเภท II - V
*   การสร้าง Perfect ที่ไม่สม่ำเสมอ

## 34.4. Perfect ประเภท I: Perfect โดยไม่มีการลดรูปฐานศัพท์

::: grammar-box
**Perfect ประเภท I (โดยไม่มีการลดรูปฐานศัพท์) มีรากศัพท์ของประเภท:**
*   **(พยัญชนะ)-พยัญชนะ-สระยาว-พยัญชนะ**
*   **(พยัญชนะ)-พยัญชนะ-สระ-พยัญชนะ-พยัญชนะ**
*   **a-พยัญชนะ**
