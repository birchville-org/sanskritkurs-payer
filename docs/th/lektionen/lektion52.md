## 52.2. การสร้างคำนาม

### 52.2.1. PPP + -vant: วิภัตติกาลปัจจุบันปารัสไปท

::: grammar-box
**การสร้างวิภัตติกาลปัจจุบันปารัสไปท ทำได้ดังนี้:**

**PPP + -vant / หญิง: vatī**
**การผันเหมือนรากศัพท์ที่ลงท้ายด้วย -vant หรือ หญิง ⟪देवी⟫**
:::
PPP + -vant / หญิง: vatī

การผันเหมือนรากศัพท์ที่ลงท้ายด้วย -vant หรือ หญิง ⟪देवी⟫

ตัวอย่าง:

::: indent
⟪कृतवन्त्⟫ (kṛta-vant) / ⟪कृतवती⟫ "ผู้ที่ได้กระทำ"

⟪भिन्नवन्त्⟫ "ผู้ที่ได้แยก"
:::
### 52.2.2. ⟪तद्धित⟫-ประติ -maya / -mayī

::: grammar-box
**ประติ ⟪तद्धित⟫ -maya / หญิง: -mayī สร้างคำคุณศัพท์จากคำนามที่มีความหมายว่า**

*   **"ทำจาก"**
*   **"ประกอบด้วย"**
*   **"อุดมด้วย"**

**ก่อน -maya (เช่นเดียวกับก่อน -⟪मात्र⟫) พยัญชนะปิดที่ออกเสียงในรูปหยุดต้องถูกแทนที่ด้วยนิคิตะที่สอดคล้องกัน**
:::
ตัวอย่าง:

::: indent
⟪अन्नमय⟫ 3 "อุดมด้วยอาหาร"

⟪चिन्मय⟫ 3 (จาก ⟪चित्⟫ หญิง "ปัญญา") "ประกอบด้วยความคิด/สติ"

⟪वाङ्मय⟫ 3 (จาก ⟪वाच्⟫ หญิง "ภาษา") "ประกอบด้วยคำพูด"

⟪सोममय⟫ 3 "ทำจากโซมา หรือ ประกอบด้วยโซมา"
:::
::: grammar-box
**นามที่ลงท้ายด้วย -maya บางครั้งใช้เป็นคำนามกลาง และหมายถึงความอุดมสมบูรณ์ของสิ่งที่ระบุโดยคำนามที่ต่อท้ายด้วย -maya**
:::
::: indent
เช่น ⟪अन्नमय⟫ ก. "ความอุดมสมบูรณ์ของอาหาร"
:::

:::

::: grammar-box
**ประติ ⟪तद्धित⟫ -eya / หญิง: -eyī มักปรากฏกับคำคุณศัพท์หญิง ในความหมายว่า**

*   **"บุตรของ"**
*   **"ทายาทของ"**

**ระดับขยาย (⟪वृद्धि⟫) ของสระตัวแรก**

เช่น ⟪कौन्तेय⟫ ชาย "บุตรของ ⟪कुन्ती⟫"

## 52.3. การสร้างคำวิเศษณ์: ประติ -śas

::: grammar-box
**ประติคำวิเศษณ์ -śas สร้างคำวิเศษณ์จาก (ส่วนใหญ่) ความหมายแบบกระจาย:**

*   **คำคุณศัพท์บอกจำนวน**  
ตัวอย่าง:  
⟪एकशस्⟫ "ทีละหนึ่ง, คนละหนึ่ง"  
⟪द्विशस्⟫ "ทีละสอง, คนละสอง"  
⟪शतशस्⟫ "ทีละร้อย, คนละร้อย"

*   **คำอื่นๆ**  
ตัวอย่าง:  
⟪भागशस्⟫ "ทีละส่วน"  
⟪सर्वशस्⟫ "ทุกแห่ง, ทั้งหมด"  
⟪नित्यशस्⟫ "สม่ำเสมอ"
:::

## 52.4. คำประกอบกริยาที่แสดงว่าสิ่งหนึ่งกลายเป็นหรือถูกทำให้เป็นสิ่งที่มันไม่ใช่ก่อนหน้า (⟪अभुततद्भावः⟫)

### 52.4.1. การสร้างด้วย cvi-

::: grammar-box
**หน้ารากศัพท์**

*   **⟪कृ⟫ 8U "ทำ"**
*   **⟪अस्⟫ 2P "เป็น"**
*   **⟪भू⟫ 1P "กลายเป็น"**

**นามและคุณศัพท์สามารถถูกวางเป็นคำนำหน้ากริยา เพื่อแสดงว่าบุคคลหรือสิ่งหนึ่งกลายเป็นสิ่งที่นามนั้นระบุ หรือทำให้บุคคลหรือสิ่งหนึ่งเป็นสิ่งที่นามนั้นระบุ**

**การลงท้ายของนามจะถูกจัดการดังนี้:**

การลงท้ายของนามจะถูกจัดการดังนี้:

*   **การลงท้าย -a และ -ā ของคำที่ผันรูปได้ จะถูกแทนด้วย -ī  **
ตัวอย่าง:  
⟪कृष्णीभवति⟫ "สิ่งที่ไม่ใช่สีดำ กลายเป็นสีดำ"  
⟪कृष्णीकरोति⟫ "เขาทำให้สิ่งที่ไม่ใช่สีดำ เป็นสีดำ"  
⟪गङ्गीभवति⟫ "เขา/เธอ กลายเป็นแม่น้ำคงคา"  

*   **การลงท้าย -i และ -u จะถูกแทนด้วยสระยาวที่สอดคล้องกัน  **
ตัวอย่าง:  
⟪शुचीभवति⟫ "เขา/เธอ/มัน กลายเป็นบริสุทธิ์"  
⟪गुरूभवामि⟫ "ฉันกลายเป็นอาจารย์"  

*   **การลงท้าย -ṛ จะถูกแทนด้วย --rī  **
เช่น ⟪पित्रीभवति⟫ "ผู้ที่ไม่ใช่พ่อ (⟪पितृ⟫) กลายเป็นพ่อ = ชายคนหนึ่งมีบุตรคนแรก"  

*   **การลงท้าย -n จะถูกตัดออก และสระที่อยู่ก่อนหน้าจะถูกจัดการตามกฎข้างต้น  **
เช่น ⟪राजीबभूव⟫ "ผู้หนึ่ง (ที่ไม่ใช่กษัตริย์) กลายเป็นกษัตริย์ (⟪राजन्⟫)"  

*   **นามอื่นๆ ที่มีหลายฐานจะอยู่ในรูปของฐานที่มันมีในกรณีท้องถิ่น (⟪सप्तमी⟫) พหูพจน์ ฐานนั้นจะอยู่ภายใต้กฎแซนดิทั่วไป ดู Kielhorn, Grammar § 489,3.  **
เช่น ⟪तिर्यक्करोति⟫ "เขาวางไปด้านข้าง (⟪तिर्यच्⟫)"
:::
::: media

ภาพ: ⟪भस्मीकृतं⟫ ⟪वनम्⟫
การเผาไร่, Arunachal Pradesh = ⟪अरुणाचल⟫ ⟪प्रदेश⟫
(ที่มาภาพ: [รายละเอียด](/th/licenses#lekt5209))

### 52.4.2. สuffix -sāt

::: grammar-box
**เพื่อแสดงว่าบุคคลหรือสิ่งหนึ่งกลายเป็นสิ่งที่นามนั้นระบุโดยสมบูรณ์ หรือทำให้บุคคลหรือสิ่งหนึ่งเป็นสิ่งที่นามนั้นระบุอย่างสิ้นเชิง สามารถต่อ**

**suffix -sāt (ซึ่งจะไม่กลายเป็น -ṣāต)**

**เข้ากับนาม และคำที่สร้างด้วยวิธีนี้จะถูกเชื่อมกับรากศัพท์**

*   ⟪कृ⟫ 8U "ทำ"
*   ⟪अस्⟫ 2P "เป็น"
*   ⟪भू⟫ 1P "กลายเป็น"
*   ⟪सम्⟫-⟪पद्⟫ 4Ā

**เพื่อสร้างคำประกอบกริยา**
:::
ตัวอย่าง:

::: indent
⟪अग्निसाद्भवति⟫ ⟪।⟫ ⟪अग्निसात्संपद्यते⟫ "เขากลายเป็นไฟโดยสมบูรณ์"

⟪भस्मसात्करोति⟫ "เขาเปลี่ยนเป็นเถ้าถ่านโดยสิ้นเชิง (⟪भस्मन्⟫ n. "เถ้าถ่าน"))
:::
::: grammar-box
**Manchmal bedeutet das Suffix -sāt, dass eine Person oder Sache**

*   **ขึ้นอยู่กับหรือ**
*   **เปลี่ยนไปสู่การเป็นเจ้าของสิ่งนั้น**
*   **หรือที่ใครบางคนทำให้ขึ้นอยู่กับสิ่งนั้น**

**สิ่งที่คำนามระบุไว้**
:::
ตัวอย่าง:

::: indent
⟪राजसाद्भवति⟫ "เขาขึ้นอยู่กับกษัตริย์ เขาเป็นทรัพย์สินของกษัตริย์"
:::
::: grammar-box
**จากการสร้างด้วย -sāt รากศัพท์ไม่ได้รับการปฏิบัติเหมือนหลังคำนำหน้า ดังนั้น Absolutive:**

:::
::: indent
⟪भस्मसात्कृ⟫:sig[⟪त्वा⟫]
:::
## 52.5 การซ้ำคำ (⟪द्विरुक्तम्⟫)

::: grammar-box
**การซ้ำคำในภาษาสันสกฤตแสดงว่า:**

*   **การทำซ้ำของการกระทำ**  
เช่น ⟪पुनः⟫ ⟪पुनः⟫ "เสมอๆ"
*   **การกระจาย**  
ตัวอย่าง:  
⟪पृथक्पृथक्⟫ "แต่ละแยกกัน แต่ละเดี่ยวๆ"  
⟪यद्यद्⟫ ... ⟪तत्तद्⟫ "อะไรก็ตาม ... ทั้งหมดนี้"  
⟪युगे⟫ ⟪युगे⟫ "ในแต่ละยุคของโลก"

**บางครั้งสามารถสร้างคำประสมจากความสัมพันธ์ดังกล่าวได้**

:::
ตัวอย่าง:

::: indent
⟪एकैक⟫ 3 "แต่ละคน"
⟪अल्पाल्प⟫ 3 "เล็กมาก"
⟪नवनव⟫ 3 "ใหม่เสมอ"
:::
สำหรับคำประสมที่เรียกว่า ⟪आम्रेडित⟫ ซึ่งมีการซ้ำคำที่ผัน แต่คำที่สองได้รับเสียงหนักในยุคก่อนคลาสสิก ดังนั้นจึงเป็นคำประสม ดู Wackernagel, Altindische Grammatik II,1 หน้า 142 เป็นต้นไป
## 52.6 คำจำนวน (⟪सम्ख्या⟫ f.)

สิ่งที่ไม่ได้กล่าวถึงที่นี่ดูตัวอย่างเช่นที่ Kielhorn, Grammatik §201f.

### 52.6.1 เลขนับ

#### 52.6.1.1 คำคุณศัพท์จำนวน (สำหรับ 1 ถึง 19)

::: grammar-box
**คำจำนวนสำหรับ *1 ถึง 19* เป็นคำคุณศัพท์**
**คำจำนวนสำหรับ **1 ถึง 4** มีการผันเสียงต่างกันทั้งสามเพศ**

**สำหรับคำจำนวนสำหรับ **5 ถึง 19** (:sig[⟪नवदशन्⟫]) มีการผันเสียงเพียงแบบเดียวสำหรับทั้งสามเพศ**

**สำหรับคำคุณศัพท์จำนวนเหล่านี้ เช่นเดียวกับคำคุณศัพท์ทั้งหมด: ต้องอยู่ในกรณี จำนวน และเพศเดียวกันกับคำนามที่เกี่ยวข้องและในทางกลับกัน (นั่นคือ สำหรับ 1 เอกพจน์, สำหรับ 2 ทวิภาค, สำหรับที่เหลือ พหูพจน์)**
:::
คำคุณศัพท์จำนวน:

::: indent
1 ⟪एक⟫ 3 (การผันเสียงเช่น ⟪सर्व⟫, ในพหูพจน์: "บาง")
2 ⟪द्वि⟫ 3
3 ⟪त्रि⟫ 3
4 ⟪चतुर्⟫ 3
5 ⟪पञ्चन्⟫ 3
6 ⟪षष्⟫ 3
7 ⟪सप्तन्⟫ 3
8 ⟪अष्टन्⟫ 3
9 ⟪नवन्⟫ 3
10 ⟪दशन्⟫ 3
:::
การผันเสียงจะปรากฏในรายการคำ ณ สถานที่ที่กำหนด

ดูเลขวิเศษอื่นๆ ถึง 19 ตัวอย่างเช่นที่ Kielhorn, Grammatik §201

#### 52.6.1.2 คำนามจำนวน (สำหรับ 19 เป็นต้นไป)

::: grammar-box
**คำจำนวนสำหรับ *19 (⟪एकोनविंशति⟫* "น้อยกว่าหนึ่งจาก 20") *ถึง 99* เป็นคำนามเพศหญิง และถูกผันเสียงเช่น ⟪मति⟫ f. หรือรากนามบน -t (เช่น ⟪त्रिंशत्⟫ f.)**

:::
ตัวอย่าง:

::: indent
20 ⟪विंशति⟫ f.:br
30 ⟪त्रिंशत्⟫ f.
:::

::: grammar-box

**คำจำนวนสำหรับตัวเลข **ตั้งแต่ 100** เป็นคำนามเพศกลาง พวกเขาถูกผันเสียงเช่น ⟪फलम्⟫**
:::

ตัวอย่าง:

::: indent
100 ⟪शत⟫ n.:br
1000 ⟪सहस्र⟫ n.
:::
ดูคำนามจำนวนแต่ละคำ ตัวอย่างเช่นที่ Kielhorn, Grammatik §201
#### 52.6.1.3 ไวยากรณ์เกี่ยวกับเลขนับ

::: grammar-box
**จากความแตกต่างระหว่างคำคุณศัพท์กริยาและคำนามกริยาสำหรับเลขนับเกิดผลต่อไปนี้สำหรับไวยากรณ์:**

    *   พวกเขาควบคุมกรณียกรรม (⟪षष्ठी⟫) ของสิ่งที่นับ

## 52.9. งานระหว่างภาคเรียนฤดูร้อน

ด้วยบทที่ 52 นี้ ภาคเรียนแรก (13 สัปดาห์ × 4 ชั่วโมงการสอน) ของหลักสูตรภาษาสันสกฤตได้สิ้นสุดลงแล้ว

ในระหว่างวันหยุดภาคเรียน ควรดำเนินการตามข้อต่อไปนี้:

1.  ทบทวนสิ่งที่ได้เรียนรู้ทั้งหมดจนถึงปัจจุบัน โดยเฉพาะอย่างยิ่ง:
    1.  การท่องจำรูปแบบการผันกริยาและคำนาม
    2.  คำศัพท์
    3.  รูปพื้นฐานของคำ (Stammformen)
2.  การท่องจำบทกวีและข้อความร้อยแก้วจากวรรณกรรมคลาสสิกให้มากที่สุดเท่าที่จะทำได้
3.  ทำแบบฝึกหัดจาก[บทที่ 53](lektion53.md)
4.  ทำแบบฝึกหัดจากใบงาน Bhg 1 - 11 (ยังไม่มีบนอินเทอร์เน็ต)
5.  เตรียมความพร้อมสำหรับ ⟪भगवद्गीता⟩ บทที่ 1 เรียนรู้คำศัพท์ที่เกี่ยวข้องจากรายการคำศัพท์ (ยังไม่มีบนอินเทอร์เน็ต)
