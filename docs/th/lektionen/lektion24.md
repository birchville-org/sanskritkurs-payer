# บทที่ 24

## 24.1. การกริยาช่องสาม (⟪चतुर्थी⟫ = "วิติยะการก")

::: grammar-box
**1. เพื่อแสดงวัตถุประสงค์หรือเจตนา ("เพื่อ") ของการกระทำ สามารถใช้คำนามที่มีsuffix kṛt ซึ่งหมายถึงการกระทำหรือสถานะ ในกรณีกริยาช่องสาม (⟪चतुर्थी⟫ = "วิติยะการก") แทนการใช้กริยาไม่จำกัดรูป (⟪तुमुन्⟫) ได้**

ตัวอย่าง:

แทนที่จะใช้:

:::
::: indent
⟪रामो⟫ ⟪गुरुवचनं⟫ ⟪श्रोतुं⟫ ⟪गतः⟫ ⟪।⟫
:::
สามารถพูดได้ว่า:

::: indent
⟪रामो⟫ ⟪गुरुवचनस्य⟫ ⟪श्रवणाय⟫ ⟪गतः⟫ ⟪।⟫

หรือ:

⟪रामो⟫ ⟪गुरुवचनश्रवणाय⟫ ⟪गतः⟫ ⟪।⟫
:::
= "รามาได้ไปเพื่อฟังคำปราศรัยของอาจารย์"
::: media
![](/images/lekt2404.webp)
Abb.: ⟪बाला⟫ ⟪गुरुश्रवणाय⟫ ⟪गताः⟫
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt2404))
:::

::: grammar-box
**2. การกริยาช่องสาม (⟪चतुर्थी⟫) ยังสามารถแสดงวัตถุของกริยาไม่จำกัดรูปที่ควรเติมในบริบทของวัตถุประสงค์ได้:**

ตัวอย่าง:

:::
::: indent
⟪फलेभ्यो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "เขาไปที่หมู่บ้านเพื่อวัตถุประสงค์ของผลไม้ = เขาไปที่หมู่บ้านเพื่อกวาดเก็บผลไม้"
:::
**ในทำนองเดียวกัน การกริยาช่องสาม (⟪चतुर्थी⟫) แสดงวัตถุประสงค์ของสิ่งของหรือการกระทำ:**

ตัวอย่าง:

::: indent
⟪यज्ञायान्नम्⟫ = "อาหารสำหรับวัตถุประสงค์ของการบูชา = อาหารสำหรับการบูชา"
:::
::: media
![](/images/lekt2401.webp)
Abb.: ⟪यज्ञायान्नम्⟫
'Annakut' [⟪अन्नकूट⟫ = ⟪गोवर्धन⟫ ⟪पूजा⟫] เป็นงานประเพณีฮินดูที่จัดขึ้นในวันฉลองปีใหม่ฮินดูที่วัด BAPS [બોચાસનવાસી અક્ષ૨ પુરુષોત્તમ સ્વામિનારાયણ સંસ્થા = Bochasanwasi Akshar Purushottam Swaminarayan Sanstha] ทั้งหมด มีอาหารมังสวิรัติหลายร้อยชนิดถูกถวายแด่ Bhagwan Swaminarayan [સ્વામિનારાયણ] ในวันนี้
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt2401))
:::

::: grammar-box
**3. การกริยาช่องสาม (⟪चतुर्थी⟫) ยังแสดงบุคคลหรือสิ่งของที่วัตถุของการกระทำนั้นกำหนดไว้ (กรรมทางอ้อม; คำถาม: สำหรับใคร?) (โปรดสังเกตคำกริยาที่มีกรรมตรงสองตัว (⟪द्वितीया⟫)! )**

ตัวอย่าง:

:::
::: indent
⟪रामाय⟫ ⟪फलं⟫ ⟪ददाति⟫ = "เขามอบผลไม้ให้รามา" (รากศัพท์ ⟪दा⟫ ชั้นที่ 3 ปัจจุบัน)
:::
::: media
![](/images/lekt2402.webp)
Abb.: ⟪बाला⟫ ⟪बालाय⟫ ⟪रक्षबन्धनं⟫ ⟪ददाति⟫
Raksha bandhan ถูกเฉลิมฉลองด้วยความตื่นเต้นและความสุขทั่วทั้งอินเดีย เทศกาลนี้แสดงถึงความรักที่ไม่มีเงื่อนไขระหว่างพี่น้องชายหญิง
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt2402))
:::

::: grammar-box
**4. การกริยาช่องสามปรากฏกับคำกริยาบางตัว (และคำอื่นๆ บางตัว) ในลักษณะเดียวกับภาษาเยอรมันที่ตอบคำถาม "สำหรับใคร?":**

ตัวอย่าง:

:::
::: indent
⟪क्रुध्⟫ : ⟪देवो⟫ ⟪नरेभ्यो⟫ ⟪क्रुध्यति⟫ = "เทพเจ้าทรงกริ้วต่อผู้ชาย"

⟪अलम्⟫ คำวิเศษณ์: "เพียงพอ, เพียงพอ, มีกำลัง": ⟪अलं⟫ ⟪योधो⟫ ⟪योधाय⟫ = "นักรบคนหนึ่งมีกำลังเทียบเท่านักรบอีกคน"
:::
::: media
![](/images/lekt2403.webp)

"รามา (ขวา) นั่งบนไหล่ของหนานรบกับราชาปีศาจราวณะ" ประมาณ ค.ศ. 1820
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt2403))
:::
การใช้งานอื่นๆ ของการกริยาช่องสามจะกล่าวถึงในภายหลัง

## 24.2. การสร้างกริยาวิภัตติการก (⟪चतुर्थी⟫)

::: grammar-box
**วิภัตติการกที่ลงท้ายอย่างสม่ำเสมอมีดังนี้:**

* **เอกพจน์: -e ; รากศัพท์เพศหญิงที่ลงท้ายด้วยสระ: -ai**
* **พหูพจน์: การกและ Ablative ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. รากศัพท์ที่ลงท้ายด้วยพยัญชนะ

::: grammar-box

| | การกเอกพจน์ | การกพหูพจน์ |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. คำสรรพนามคำถาม

::: grammar-box

| | เพศชาย / เพศกลาง | เพศหญิง |
| :--- | :--- | :--- |
| **การกเอกพจน์** | ⟪कस्मै⟫ | ⟪कस्यै⟫ |
| **การกพหูพจน์** | ⟪केभ्यस्⟫ | ⟪काभ्यस्⟫ |

:::
### 24.2.3. คำสรรพนามแสดงอาการ

::: grammar-box

| | | ⟪तद्⟫ | ⟪एतद्⟫ | ⟪इदम्⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **เพศชาย / เพศกลาง** | **การกเอกพจน์.** | ⟪तस्मै⟫ | ⟪एतस्मै⟫ | ⟪अस्मै⟫ |
| | **การกพหูพจน์.** | ⟪तेभ्यस्⟫ | ⟪एतेभ्यस्⟫ | ⟪एभ्यस्⟫ |
| **เพศหญิง** | **การกเอกพจน์.** | ⟪तस्यै⟫ | ⟪एतस्यै⟫ | ⟪अस्यै⟫ |
| | **การกพหูพจน์.** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::
### 24.2.4. รากศัพท์ที่ลงท้ายด้วยสระ

::: grammar-box
**รากศัพท์ที่ลงท้ายด้วยสระ**

* **เพศชาย / เพศกลาง ที่ลงท้ายด้วย -a:** ⟪देव⟫
  * การกเอกพจน์ ⟪देवाय⟫
  * การกพหูพจน์ ⟪देवेभ्यस्⟫
* **เพศชาย ที่ลงท้ายด้วย -i:** ⟪कवि⟫
  * การกเอกพจน์ ⟪कवये⟫
  * การกพหูพจน์ ⟪कविभ्यस्⟫
* **เพศชาย ที่ลงท้ายด้วย -u:** ⟪पशु⟫
  * การกเอกพจน์ ⟪पशवे⟫
  * การกพหูพจน์ ⟪पशुभ्यस्⟫
* **เพศหญิง ที่ลงท้ายด้วย -ā:** ⟪देवता⟫
  * การกเอกพจน์ ⟪देवतायै⟫
  * การกพหูพจน์ ⟪देवताभ्यस्⟫
* **เพศหญิง ที่ลงท้ายด้วย -ī:** ⟪देवी⟫
  * การกเอกพจน์ ⟪देव्यै⟫
  * การกพหูพจน์ ⟪देवीभ्यस्⟫
* **เพศหญิง ที่ลงท้ายด้วย -i:** ⟪श्रुति⟫
  * การกเอกพจน์ ⟪श्रुतये⟫ หรือ ⟪श्रुत्यै⟫ (นั่นคือ เช่นเดียวกับ ⟪कवि⟫ หรือเช่นเดียวกับ ⟪देवी⟫)
  * การกพหูพจน์ ⟪श्रुतिभ्यस्⟫
* **เพศหญิง ที่ลงท้ายด้วย -u:** ⟪धेनु⟫
  * การกเอกพจน์ ⟪धेनवे⟫ หรือ ⟪धेन्वै⟫
  * การกพหูพจน์ ⟪धेनुभ्यस्⟫
:::
## 24.3. การประสมเสียง (Sandhi) ของ -ai และ -au ที่ออกท้าย

::: grammar-box
**การประสมเสียง (Sandhi) ของ -ai และ -au ที่ออกท้าย**

* **-ai นำหน้าด้วยสระ มักจะถูกแทนที่ด้วย -ā (หาได้ยากที่จะเป็น -āy เช่นภายในคำ)**
* **-au นำหน้าด้วยสระ มักจะถูกแทนที่ด้วย -āv (หาได้ยากที่จะเป็น -ā)**

ตัวอย่าง:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा⟫ ⟪अग्नये⟫ = "ไฟนี้"
:::
## 24.4. รายการคำศัพท์

⟪अलम्⟫ คำวิเศษณ์: เพียงพอ, พอเหมาะ, (แก่ใครบางคน, สิ่งใดสิ่งหนึ่ง) เหมาะสม ; พร้อมกับการการก: เพียงพอสำหรับ, พอเหมาะสำหรับ, เหมาะกับ ; พร้อมกับการเครื่องมือ (Instrumentalis): เพียงพอกับ, เลิกทำจาก , เช่น ⟪अलं⟫ ⟪क्रोधेन⟫ = "พอแล้วกับโกรธ = เลิกทำจากความโกรธ!"

ในลักษณะเดียวกันกับ ⟪अलम्⟫ พร้อมกับการเครื่องมือ (Instrumentalis) จะถูกใช้:

## 24.6. แบบฝึกหัดเพิ่มเติมเกี่ยวกับการใช้กรณีให้ (Dative)

จงแปลเป็นภาษาสันสกฤต:

1\. เทวีผู้ไม่ได้รับการบูชาย่อมกริ้วต่อมนุษย์

2\. เขาปล่อยวัวเข้าหมู่บ้าน

3\. ตอนนี้พอแล้ว = พอใจกับความอดทนเพียงพอ

4\. นั่นดี (⟪हित⟫, ⟪सुख⟫) สำหรับพราหมณ์

5\. การบูชา (⟪नमस्⟫) จงมีต่อพระศิวะ! การบูชาจงมีต่อพระศรีคเณศ!

:::
6\. ลาก่อน! (= ความสวัสดิภาพ (⟪स्वस्ति⟫ f.) แก่ท่าน!)

7\. ผลไม้นี้เพียงพอสำหรับการบริโภค

8\. นักสู้คนหนึ่งมีความสามารถเทียบเท่า (⟪शक्त⟫) ต่อนักสู้คนอื่น

9\. แม้แต่พระวิษณุก็ไม่เหนือกว่า (⟪प्र⟫-⟪भू⟫ + Dat.) พระศิวะ

10\. หลังจากฉันได้กราบไหว้ต่อปราชญ์ทั้งสาม (Akk.) แล้ว (⟪नमस्कृ⟫)... เขากราบไหว้ต่อพระนารสีมหะ (Dat.)

11\. ยินดีต้อนรับ (⟪स्वागतम्⟫) แก่ท่าน ยินดีต้อนรับต่อราชินี

12\. ฉันขออวยพรความสวัสดิภาพ (⟪कुशल⟫) แก่ท่าน = ความสวัสดิภาพจงมีแก่ท่าน!

13\. เขาไม่มองเขาว่าเป็นเพียงหญ้า
