# บทที่ 12


## 12.1. กรรตุวาจกสมบูรณ์กรรมวาจก (PPP)

หนึ่งในวิธีการสร้างประโยค Passive ในอดีต คือการใช้โครงสร้างที่เรียกว่า Participium Perfekti Passivum (PPP)

::: grammar-box
**ในความเป็นจริงแล้ว PPP ไม่ใช่ Participium แท้จริง เนื่องจากไม่ได้สร้างจากฐานของกาลเวลา (tempus) แต่เป็นการสร้างคำนามจากรากศัพท์ด้วย Primärsuffix -ta หรือ -na ดังนั้นในไวยากรณ์อินเดียจึงเรียก suffix นี้ว่า kta**
:::

### 12.1.1. แผนภาพสำหรับกริยา Transitiv

::: grammar-box
**Agens (kartṛ) ใน Instrumentalis (tṛtīyā) -- กรรมตรง (karman) ใน Nominativ (prathamā) -- Participium Perfekti Passivum**

ในกรณีนี้ PPP จะตรงกันกับกรรมในจำนวน กรณี และเพศ

ไม่จำเป็นต้องใช้กริยาช่วย (คือ "to be")

ตัวอย่าง:
> **sādhunā svarga āptaḥ** = ⟪साधुना⟫ ⟪स्वर्ग⟫ ⟪आप्तः⟫ = "(โดยฤๅษีได้สวรรค์บรรลุ) = ฤๅษีได้บรรลุสวรรค์"
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन⟫ ⟪देवीष्टा⟫ = "(โดยพราหมณ์ได้เทพีบูชาด้วยเครื่องสังเวย) = พราหมณ์ได้บูชาเทพีด้วยเครื่องสังเวย"
:::

### 12.1.2. แผนภาพ I สำหรับกริยา Intransitiv และกริยาสถานที่

::: grammar-box
**Agens (kartṛ) ใน Nominativ (prathamā) -- Participium Perfekti Passivum**

ในกรณีนี้ PPP จะตรงกันกับ Agens ในจำนวน กรณี และเพศ Participium Perfekti "Passive" สำหรับกริยา Intransitiv (กริยาที่ไม่มีกรรมตรง) และกริยาสถานที่ มีความหมาย Active

ตัวอย่าง:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया⟫ ⟪नगरं⟫ ⟪गता⟫ = "หญิงกษัตริย์ได้เข้าไปในเมือง"
:::

### 12.1.3. แผนภาพ II สำหรับกริยา Intransitiv และกริยาสถานที่

::: grammar-box
**Agens (kartṛ) ใน Instrumentalis (tṛtīyā) -- PPP ใน Nominativ เอกพจน์ Neutrum**

ตัวอย่าง:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = "(โดยกษัตริย์ได้(เข้าไปในเมือง)) = กษัตริย์ได้(เข้าไปในเมือง)"

โครงสร้างตามแผนภาพ II พบน้อยกว่าโครงสร้างตามแผนภาพ I มาก
:::

## 12.2. เกี่ยวกับความหมายของ PPP

ดังนั้น "Participium Perfekti Passivum" สำหรับกริยา Transitiv ในหลักมีความหมาย Passive (**āpta** = "บรรลุ (แล้ว)") และสำหรับกริยา Intransitiv และกริยาสถานที่มีความหมาย Active (**gata** = "ไปแล้ว") มีบางคำที่ PPP สามารถมีความหมายทั้ง Active และ Passive:

เช่น
- **gata** = ⟪गत⟫ = "ไปแล้ว" (active); แต่ยัง: **gato mārgaḥ** = ⟪गतो⟫ ⟪मार्गः⟫ = "ทางที่ไปแล้ว" (passive)
- **āpta** = ⟪आप्त⟫ = "บรรลุแล้ว" (passive), "มีสิ่งที่บรรลุ" (active)

## 12.3. การสร้างรูป PPP

::: grammar-box
มีวิธีการสร้างดังต่อไปนี้ (สำหรับรากศัพท์แต่ละคำ ต้องเรียนรู้ PPP ของมันด้วย!):

**(ส่วนใหญ่) รากศัพท์ระดับต่ำสุด**

- **+ -ta**
  - โดยมีสระเชื่อมต่อ **-i-** นำหน้า: **-ita**
  - โดยไม่มีสระเชื่อมต่อ: **-ta**
- **+ -na**

รากศัพท์เพศหญิงลงท้ายด้วย: **-tā**, **-itā**, **-nā**; ลักษณนามเพศกลางผันแปรเหมือน **phala** n.
:::

### 12.3.1. PPP ลงท้ายด้วย -ta (kta)

#### 12.3.1.1. โดยไม่มีสระเชื่อมต่อ -i- (aniṭ)

*aniṭ* = “ไม่มี (*an-*) ต่อท้ายด้วย (*-i-) *t*” (นั่นคือ ไม่มีสระเชื่อมต่อ *i*).

::: grammar-box
โดยไม่มีสระเชื่อมต่อ การสร้าง PPP โดยทั่วไปทำจากรากศัพท์ที่ลงท้ายด้วยเสียงสระ รวมถึงรากศัพท์อื่นๆ อีกจำนวนมาก โดยไม่สามารถระบุกฎตายตัวได้ว่า รากศัพท์ที่มีโครงสร้างแบบใดจะมีหรือไม่มีสระเชื่อมต่อ

รายการรากศัพท์ *aniṭ* พบได้ใน Kielhorn, *Grammatik* § 298.
:::
**ตัวอย่าง:**

## 12.4. กฎการรวมเสียงภายในคำ

ในการสร้างแบบ *aniṭ* ต้องคำนึงถึงกฎการรวมเสียงภายในคำต่อไปนี้ **กฎเหล่านี้มีความสำคัญอย่างยิ่งต่อการเข้าใจรูปศัพท์สันสกฤตทั้งหมด**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p ก่อนพยัญชนะหยุดไม่มีเสียง (เช่น t, th) คงเดิม:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct เปลี่ยนเป็น kt = ⟪क्त्⟫:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt เปลี่ยนเป็น ṣṭ = ⟪ष्ट्⟫:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. พยัญชนะหยุดมีเสียงไม่พ่นเสียง – ยกเว้น j — เปลี่ยนเป็นพยัญชนะหยุดไม่มีเสียงไม่พ่นเสียงที่สอดคล้องกัน ก่อนพยัญชนะไม่มีเสียง:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (สำคัญสำหรับชั้นปัจจุบันที่ 2) |
| **5. jt เปลี่ยนเป็น kt หรือ ṣṭ (ไม่ใช่ทางเลือก!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. พยัญชนะหยุดมีเสียงพ่นเสียง + พยัญชนะหยุดไม่มีเสียง » พยัญชนะหยุดมีเสียงไม่พ่นเสียง + พยัญชนะหยุดมีเสียงพ่นเสียง (กฎการพ่นเสียงของ Bartholomae):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t จะถูกแทนที่ด้วย ḍh พร้อมการยืดเสียง i หรือ u ก่อนหน้า; หรือด้วย gdh. ก่อน ḍh ดังกล่าว a จะถูกแทนที่ด้วย o น้อยครั้งด้วย ā:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „etwas verbergen”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.6. แบบฝึกหัด

**A) จงสร้างประโยคกัมมะวาจกาในกาลอดีตจากประโยคกระตุกวาจกาของ [บทที่ 7](/lektionen/lektion07) แบบฝึกหัด A สำหรับกริยาอกรรมกและกริยาแห่งการเคลื่อนไหว ให้สร้างประโยคกระตุกวาจกาในกาลอดีต**

**B) จงสร้างคำคุณศัพท์กัมมะวาจกา (PPP) ที่สอดคล้องกับรูปกริยาจาก [บทที่ 10](/lektionen/lektion10) แบบฝึกหัด A โปรดสังเกตว่ารูปกริยาเช่น sṛjati นั้นสอดคล้องกับคำคุณศัพท์กัมมะวาจกา (PPP) ในทั้งสามเพศ**

**C) จงแปลงประโยคจาก [บทที่ 10](/lektionen/lektion10) แบบฝึกหัด C เป็นกัมมะวาจกาในกาลอดีต**
