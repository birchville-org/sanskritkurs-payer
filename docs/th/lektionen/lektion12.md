# บทที่ 12


## 12.1. Participle Perfekt Passiv (PPP)

หนึ่งในวิธีการสร้างประโยค passive ในอดีต คือการใช้โครงสร้างที่เรียกว่า Participle Perfekt Passiv (PPP)

::: grammar-box
**ในความเป็นจริงแล้ว PPP ไม่ใช่ participle ที่แท้จริง เนื่องจากไม่ถูกสร้างจากรากของกาลเวลา (tense stem) แต่เป็นรูปแบบนาม (nominal formation) จากศัพท์รากฐานพร้อมด้วย suffix หลัก -ta หรือ -na ดังนั้นในไวยากรณ์อินเดียจึงเรียก suffix นี้ว่า kta**
:::

### 12.1.1. แผนภาพสำหรับกริยากรรม (transitive verbs)

::: grammar-box
**ผู้กระทำ (kartṛ) ในกรณีเครื่องมือ (tṛtīyā) -- กรรมตรง (karman) ในกรณีนาม (prathamā) -- Participle Perfekt Passiv**

ในกรณีนี้ PPP จะตรงกันกับกรรมในจำนวน กรณี และเพศ

ไม่จำเป็นต้องใช้กริยาช่วย (เช่น "เป็น")

ตัวอย่าง:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = "(โดยฤๅษีได้สวรรค์) = ฤๅษีได้รับสวรรค์"
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = "(โดยพราหมณ์ได้เทพีด้วยการบูชา) = พราหมณ์ได้อาราธนาเทพีด้วยการบูชา"
:::

### 12.1.2. แผนภาพ I สำหรับกริยาอกรรม (intransitive verbs) และกริยาสถานที่

::: grammar-box
**ผู้กระทำ (kartṛ) ในกรณีนาม (prathamā) -- Participle Perfekt Passiv**

ในกรณีนี้ PPP จะตรงกันกับผู้กระทำในจำนวน กรณี และเพศ Participle Perfekt "Passive" สำหรับกริยาอกรรม (กริยาที่ไม่มีกรรมตรง) และกริยาสถานที่ มีความหมายเชิง active

ตัวอย่าง:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = "หญิงกษัตริย์ได้เข้าไปในเมือง"
:::

### 12.1.3. แผนภาพที่ II สำหรับกริยาอกรรมกริยาและการเคลื่อนไหว

::: grammar-box
**ผู้กระทำ (kartṛ) ในกรณียที่ 3 (tṛtīyā) -- PPP ในนามเอกพจน์กลาง**

ตัวอย่าง:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(โดยกษัตริย์) (เข้าไปในเมือง) ได้เดินไป“ = กษัตริยะนั้นได้ (เข้าไปในเมือง) ไปแล้ว.“

โครงสร้างตามแผนภาพที่ II พบน้อยกว่าโครงสร้างตามแผนภาพที่ I มาก
:::

## 12.2. เกี่ยวกับความหมายของ PPP

ดังนั้น ในขณะที่คำว่า „Participle Perfekt Passiv“ สำหรับกริยากรรมกริยามักมีความหมายแบบถูกกระทำเป็นหลัก (**āpta** = „ได้รับการบรรลุ“) และสำหรับกริยาอกรรมกริยาและการเคลื่อนไหวมีความหมายแบบกระทำ (**gata** = „ไปแล้ว“) มีบางกริยาที่ PPP สามารถมีความหมายได้ทั้งแบบกระทำและถูกกระทำ:

เช่น
**gata** = ⟪गत⟫ = „ไปแล้ว“ (แบบกระทำ); แต่ยังมี: **gato mārgaḥ** = ⟪गतो मार्गः⟫ = „ทางที่เดินไปแล้ว“ (แบบถูกกระทำ)
**āpta** = ⟪आप्त⟫ = „ได้รับการบรรลุ“ (แบบถูกกระทำ), „ผู้ที่ได้บรรลุแล้ว“ (แบบกระทำ)


## 12.3. การสร้าง PPP

::: grammar-box
มีวิธีการสร้างดังต่อไปนี้ (สำหรับรากศัพท์แต่ละคำ ต้องเรียนรู้ PPP ของมันด้วย!):

**(ส่วนใหญ่) รากศัพท์ระดับต่ำ**

**+ -ta**
มีสระเชื่อม **-i-** นำหน้า: **-ita**
ไม่มีสระเชื่อม: **-ta**
**+ -na**

รากศัพท์เพศหญิงลงท้ายด้วย: **-tā**, **-itā**, **-nā**; เพศกลางผันเหมือน **phala** n.
:::

### 12.3.1. PPP ลงท้ายด้วย -ta (kta)

#### 12.3.1.1. ไม่มีสระเชื่อม -i- (aniṭ)

*aniṭ* = „ไม่มี (*an-*) นำหน้าด้วย (*-i-*) *t*“ (นั่นคือ ไม่มีสระเชื่อม *i*).

::: grammar-box
โดยทั่วไป การสร้าง PPP (Participle Past Passive) จากรากศัพท์ที่ลงท้ายด้วยสระนั้นไม่มีการใช้สระเชื่อม (Bindevokal) และจากรากศัพท์อื่นๆ อีกจำนวนมาก โดยไม่สามารถระบุกฎตายตัวได้ว่า รากศัพท์แบบใดควรมีหรือไม่มีสระเชื่อม

รายชื่อรากศัพท์ประเภท *aniṭ* สามารถพบได้ใน Kielhorn, *Grammatik* § 298.
:::
**ตัวอย่าง:**

::: grammar-box
| รากศัพท์ (Wurzel) | PPP (kta) |
| :--- | :--- |
| **bhū** 1 P:br(⟪भू⟫) | **bhū-ta** :br(⟪भूत⟫) |
| **smṛ** 1 P:br(⟪स्मृ⟫) | **smṛ-ta** :br(⟪स्मृत⟫) |
| **nṛt** 4 P:br(nṛt-ta):br(⟪नृत्त⟫) | **nṛt-ta** :br(⟪नृत्त⟫) |
| **nī** 1 U:br(⟪नी⟫) | **nī-ta** :br(⟪नीत⟫) |
| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |
| **su** 5 U:br(⟪सु⟫) | **su-ta** :br(⟪सुत⟫) |
| **gam** 1 P:br(⟪गम्⟫) | **ga-ta** (\< \*gm-ta):br(⟪गत⟫) |
| **ji** 1 P:br(⟪जि⟫) | **ji-ta** :br(⟪जित⟫) |
| **śru** 5 P:br(⟪श्रु⟫) | **śru-ta** :br(⟪श्रुत⟫) |
| **kṛ** 8 U:br(⟪कृ⟫) | **kṛ-ta** :br(⟪कृत⟫) |
| **tan** 8 U:br(⟪तन्⟫) | **ta-ta** (\< \*tn-ta):br(⟪तत⟫) |

:::
#### 12.3.1.2. พร้อมสระเชื่อม -i- (seṭ)

*seṭ* = *sa-iṭ* = “มี (*sa-*) ท่อน้ำเสียงนำหน้า (*-i-*) *t*” (นั่นคือ มีสระเชื่อม *i*)

## 12.4. กฎของการรวมเสียงภายในคำ

ในการสร้างรูป *aniṭ* ต้องคำนึงถึงกฎเกณฑ์ของการรวมเสียงภายในคำดังต่อไปนี้ **กฎเกณฑ์เหล่านี้มีความสำคัญอย่างยิ่งต่อการเข้าใจรูปศัพท์ภาษาสันสกฤตโดยรวม**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p หน้าพยัญชนะหยุดไม่ก้อง (เช่น t, th) จะคงเดิม:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct จะถูกแทนที่ด้วย kt = ⟪क्त्⟫:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt จะถูกแทนที่ด้วย ṣṭ = ⟪ष्ट्⟫:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. พยัญชนะหยุดไม่ก้องและไม่มีลมหายใจ – ยกเว้น j – จะถูกแทนที่ด้วยพยัญชนะหยุดไม่ก้องและไม่มีลมหายใจที่สอดคล้องกัน เมื่ออยู่หน้าเสียงไม่ก้อง:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (สำคัญสำหรับชั้นปัจจุบันที่ 2) |
| **5. jt จะถูกแทนที่ด้วย kt หรือ ṣṭ (ไม่ใช่ทางเลือก!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. พยัญชนะหยุดมีลมหายใจและก้อง + พยัญชนะหยุดไม่ก้อง » พยัญชนะหยุดไม่มีลมหายใจและก้อง + พพยัญชนะหยุดมีลมหายใจและก้อง (กฎการมีลมหายใจของบาร์โธโลเม):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t จะถูกแทนที่ด้วย ḍh พร้อมการยืดเสียง i หรือ u ที่ตามมา; หรือแทนที่ด้วย gdh. หน้า ḍh ดังกล่าว a จะถูกแทนที่ด้วย o และหาได้ยากด้วย ā:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „ซ่อนเร้น”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.6. แบบฝึกหัด

**A) จงสร้างประโยคปฏิกิริยา (Passiv) ในอดีตจากประโยคกัมมะวาจก์ (Aktivsätze) ของ [บทที่ 7](/lektionen/lektion07) แบบฝึกหัด A สำหรับกริยาอกรรมกิริยา (intransitive verbs) และกริยาแห่งการเคลื่อนไหว ให้สร้างเป็นประโยคกัมมะวาจก์ในอดีต**

**B) จงสร้างรูป PPP (Participles of the Past Passive) ที่สอดคล้องกับรูปกริยาจาก [บทที่ 10](/lektionen/lektion10) แบบฝึกหัด A โปรดสังเกตว่ารูปกริยาเช่น sṛjati นั้นสอดคล้องกับ PPP ในทั้งสามเพศ (ชาย หญิง และกลาง)**

**C) จงแปลงประโยคจาก [บทที่ 10](/lektionen/lektion10) แบบฝึกหัด C ให้เป็นประโยคปฏิกิริยา (Passiv) ในอดีต**
