- การใช้อนุภาค **iti**, **evam** และ **na**
- คำศัพท์พื้นฐานเช่น **dharma**, **adharma** และ **putra**

## 11.1. กริยากรรมสองอย่าง

::: grammar-box
**กริยาบางชนิดสามารถบังคับให้ใช้กริยากรรมสองอย่าง (dvitīyā) ได้แก่ กริยากรรมของผู้และกริยากรรมของ**

**ซึ่งรวมถึง:**
- **กริยาแห่งการพูด**: พูดกับใครบางคน (กริยากรรม) เกี่ยวกับสิ่งใดสิ่งหนึ่ง (กริยากรรม); บอกอะไรบางอย่าง (กริยากรรม) แก่ใครบางคน (กริยากรรม)
- **กริยาแห่งการถาม**: ถามใครบางคน (กริยากรรม) เกี่ยวกับสิ่งใดสิ่งหนึ่ง (กริยากรรม)
- **กริยาแห่งการสอน**: สอนอะไรบางอย่าง (กริยากรรม) แก่ใครบางคน (กริยากรรม)
- กริยาอื่นๆ อีกบางชนิด ซึ่งมีการระบุไว้ในรายการคำศัพท์

**เมื่อโครงสร้างดังกล่าวถูกเปลี่ยนเป็นเสียง被动 (Passive) ผู้ (ผู้ที่ถูกถาม ฯลฯ) จะอยู่ในกริยาบทประธาน (prathamā) ส่วนของ (สิ่งที่ถูกถาม ฯลฯ) ยังคงอยู่ในกริยากรรม**

เช่น **rāmo brāhmaṇaṃ dharmaṃ pṛcchati** = ⟪रामो⟫ ⟪ब्राह्मणं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫ = "Rāma ถามพราหมณ์เกี่ยวกับธรรมะ"
» เสียง被动: **rāmeṇa brāhmaṇo dharmaṃ pṛcchyate** = ⟪रामेण⟫ ⟪ब्राह्मणो⟫ ⟪धर्मं⟫ ⟪पृच्छयते⟩

**กฎนี้มีผลเฉพาะเมื่อทั้งผู้และของเป็นวัตถุ หากมีเพียงสิ่งเดียวที่เป็นวัตถุ สิ่งนั้นจะอยู่ในกริยาบทประธาน (prathamā) ตามรูปแบบพื้นฐานของประโยคเสียง被动:**

เช่น **rāmo dharmaṃ pṛcchati** = ⟪रामो⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫ = "Rāma ถามเกี่ยวกับธรรมะ"
» เสียง被动: **rāmeṇa dharmaḥ pṛcchyate** = ⟪रामेण⟫ ⟪धर्मः⟫ ⟪पृच्छयते⟫
:::

## 11.2. รายการคำศัพท์

**เรียนรู้คำต่อไปนี้:**

- **iti** ⟪इति⟫ : อย่างนี้
  - อยู่ *หลัง* การแสดงความคิด ความปรารถนา คำพูด หรือคำquoted เสมือนหนึ่งเป็นเครื่องหมายคำพูด (").
  - เช่น **sādhavaḥ svargaṃ gacchantīti brāhmaṇā vadanti** "พราหมณ์กล่าวว่า 'ผู้ศักดิ์สิทธิ์ไปสู่สวรรค์'" = "พราหมณ์กล่าวว่าการที่ผู้ศักดิ์สิทธิ์ไปสู่สวรรค์"
  - ในภาษาสันสกฤตไม่มีคำพูดทางอ้อม; การสร้างด้วย **iti** มักต้องแปลเป็นภาษาเยอรมันในรูปของคำพูดทางอ้อม
  - **... (quoted) ... iti śrutiḥ** = "ดังนั้นพระเวท"
  - บ่อยครั้งหลัง **iti** มีกริยาแห่งการคิดเพิ่มเติม: "คิดว่า '...' เขาทำเช่นนั้น" แปลเป็นภาษาเยอรมันตามสำนวน (เช่น "เพราะเขารู้สึกหิว เขาจึงไป...")

- **evam** ⟪एवम्⟫ : อย่างนี้ (กริยาวิเศษณ์ เช่น **evaṃ jayati** "เขาชนะอย่างนี้")
- **na** ⟪न⟫ : ไม่
  - ปฏิเสธคำเดียว (อยู่ตรงหน้า: **na sādhuḥ** "ผู้ไม่ดี") หรือประโยคทั้งหมด (อยู่ต้นหรือตรงหน้ากริยา)

- **putra** ชาย ⟪पुत्र⟫ : ลูกชาย (ในอินเดียจำเป็นต้องมีลูกชายเพื่อทำพิธีบูชาบรรพบุรุษ)
- **dharma** ชาย ⟪धर्म⟫ : ("สิ่งที่มั่นคง" หมายถึง) ความถูกต้อง กฎหมาย จารีต ลักษณะ
  - ตรงกับกฎธรรมชาติ/ศีลธรรมมากที่สุด ทุกคนมีหน้าที่ของตนเองตาม **varṇa** และ **āśrama** (ระยะชีวิต) (**svadharma**)
- **adharma** ชาย ⟪अधर्म⟫ : ความไม่ถูกต้อง (ตรงข้ามกับ **dharma**)
- **iṣ** 6 P (icchati) ⟪इष्⟫ ⟪इच्छति⟫ : ต้องการ (**iṣ-ccha-ti**)

**การสร้างคำนามบางประการ:**

- **vad** 1 P ⟪वद्⟫ : พูด
  - **vāda** m. ⟪वाद⟫ : คำพูด, ถ้อยคำ, วาจา
  - **vadana** n. ⟪वदन⟫ : การพูด; อวัยวะสำหรับการพูด: ปาก, ใบหน้า

- **prach** 6 P ⟪प्रच्छ्⟫ : ถาม
  - **praśna** m. ⟪प्रश्न⟫ : คำถาม (suffix **-na** เหมือนใน **yaj-ña**)

- **iṣ** 6 P ⟪इष्⟫ : ต้องการ
  - **iṣṭi** f. ⟪इष्टि⟫ : ความปรารถนา (**iṣ** + **-ti**)

## 11.4. แบบฝึกทบทวน

**ก) จงแปลเป็นภาษาสันสกฤตโดยใช้รูปถูกกระทำ (Passive voice):**
1. สตรีวรรณะไวศยะถามพระพราหมณ์เกี่ยวกับธรรมะ
2. ครูกล่าวมนต์คาถา
3. สตรีผู้ศักดิ์สิทธิ์เข้าถึงสวรรค์
4. มุนีในพระเวทไม่กระทำสิ่งชั่วร้ายใดๆ
5. พราหมณ์ในฐานะผู้ประกอบพิธีบูชายัญเคารพบูชาเทพีด้วยการถวายเครื่องสังเวย
6. สตรีวรรณะศูทรไปยังหมู่บ้าน
7. ใครเห็นความจริง?

**ข)**
1. จงระบุหน้าที่ของชนสองครั้งเกิด (Dvija) ทั้งหมดโดยใช้คำประกอบชนิดทวندวะ (Dvandva) และจงแยกวิเคราะห์คำประกอบนั้นในภาษาสันสกฤต
2. จงระบุหน้าที่ของชนวรรณะไวศยะโดยใช้คำประกอบชนิดทวندวะ (Dvandva) และจงแยกวิเคราะห์คำประกอบนั้นในภาษาสันสกฤต

**ค) จงแปล:**

1. ⟪श्रवणेन⟫ ⟪श्रूयते⟫ | |
2. ⟪कर्षर्कैः⟫ ⟪कृष्यते⟫ | |
3. ⟪श्रावकेणेश्वरो⟫ ⟪नेज्यते⟫ | |
4. ⟪रक्षिक्या⟫ ⟪गुरू⟫ ⟪रक्ष्यते⟫ | |
5. ⟪ब्राह्मणेनानृतं⟫ ⟪नोद्यते⟫ | |
6. ⟪शूद्रेतरा⟫ | |
7. ⟪शिक्षा⟫ ⟪कल्पो⟫ ⟪व्याकरणं⟫ ⟪निरुक्तं⟫ ⟪छन्दो⟫ ⟪ज्योतिषमङ्गानि⟫ | |
8. ⟪आन्वीक्षिकीत्रयीवार्त्तादण्डनीतयो⟫ ⟪विद्याः⟫ ||

**ง) จงแปลและเปลี่ยนในภาษาสันสกฤตโดยทำให้ผู้กระทำ (Agent), กรรม และกริยาอยู่ในรูปพหูพจน์:**

1. ⟪फलमश्नुते⟫ | |
2. ⟪गुरुणा⟫ ⟪सत्यमुद्यते⟫ | |
3. ⟪वैश्यः⟫ ⟪पशुं⟫ ⟪लभते⟫ | |
4. ⟪पुत्रः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ||

**จ) จงเปลี่ยนประโยคในข้อ ค) 1-5 เป็นรูปกระทำ (Active voice)**
