# แบบฝึกหัด 47

ก) จงแปล:

⟪१⟫. **⟪यदि⟫ ⟪गच्छसि⟫ ⟪गच्छ⟫ ⟪त्वम्⟫ ⟪।⟫ ⟪अहं⟫ ⟪न⟫ ⟪गमिष्यामि⟫ ⟪॥⟫ ⟪१⟫ ⟪॥⟫**
หากท่านต้องการจะไป ก็จงไปเถิด! ข้าจะไม่ไป

⟪२⟫. **⟪आर्य⟫ ⟪प्रेक्षस्व⟫ ⟪मे⟫ ⟪परिभवम्⟫ ⟪॥⟫ ⟪२⟫ ⟪॥⟫**
ข้าแต่ผู้ประเสริฐ ขอทรงทอดพระเนตรความต่ำต้อยของข้าพระองค์!

⟪३⟫. **⟪भो⟫ ⟪राम⟫ ⟪यदि⟫ ⟪मया⟫ ⟪गन्तव्यं⟫ ⟪तदैषा⟫ ⟪कन्यापि⟫ ⟪मम⟫ ⟪सहायिनी⟫ ⟪भवतु⟫ ⟪॥⟫ ⟪३⟫ ⟪॥⟫**
พระรามเจ้า หากข้าพระองค์จำต้องไป ขอให้นางเด็กน้อยนี้เป็นผู้ติดตามไปด้วย

⟪४⟫. **⟪आर्ये⟫ ⟪तिष्ठ⟫ ⟪तिष्ठ⟫ ⟪।⟫ ⟪न⟫ ⟪त्वया⟫ ⟪भेतव्यम्⟫ ⟪॥⟫ ⟪४⟫ ⟪॥⟫**
ขอพระองค์ทรงหยุดอยู่เถิด ทรงหยุดอยู่เถิด พระองค์ไม่จำเป็นต้องกลัว

⟪५⟫. **⟪प्रसीदत्वार्यः⟫ ⟪॥⟫ ⟪५⟫ ⟪॥⟫**
ขอพระองค์ทรงสงบพระทัยเถิด ข้าแต่ท่านผู้ประเสริฐ!

⟪६⟫. **⟪आर्ये⟫ ⟪स्वागतं⟫ ⟪ते⟫ ⟪॥⟫ ⟪६⟫ ⟪॥⟫**
ขอทรงยินดีเถิด พระเจ้าค่ะ/ครับ

⟪७⟫. **⟪आज्ञापयत्वार्यः⟫ ⟪किं⟫ ⟪मया⟫ ⟪क्रियतामिति⟫ ⟪॥⟫ ⟪७⟫ ⟪॥⟫**
ข้าแต่ท่านผู้ประเสริฐ ขอรับสั่งเถิดว่าข้าพระองค์ควรทำอย่างไร

⟪८⟫. **⟪युद्धाय⟫ ⟪युज्यस्व⟫ ⟪नैवं⟫ ⟪पापमवाप्स्यसि⟫ ⟪॥⟫ ⟪८⟫ ⟪॥⟫**
จงเตรียมพร้อมสำหรับสงคราม แล้วความชั่วร้ายใดๆ จะไม่เกิดขึ้นแก่ท่าน

⟪९⟫. **⟪कस्मात्त्वं⟫ ⟪भीतः⟫ ⟪।⟫ ⟪प्रतिवचनम्⟫ : ⟪तस्य⟫ ⟪रामस्य⟫ ⟪गुणेभ्यः⟫ ⟪।⟫ ⟪प्रष्टा⟫ : ⟪के⟫ ⟪तस्य⟫ ⟪गुणा⟫ ⟪यस्य⟫ ⟪गृहं⟫ ⟪प्रविश्याशितव्यमपि⟫ ⟪नास्ति⟫ ⟪॥⟫ ⟪९⟫ ⟪॥⟫**
คำถาม: "ท่านกลัวอะไร?" คำตอบ: "ต่อคุณงามความดีของพระรามนี้" ผู้ถาม: "แล้วคุณงามความดีของผู้ชายประเภทใดกันเล่า ที่ในบ้านของเขาไม่มีอาหารเมื่อใครเดินเข้าไป"

⟪१०⟫. **⟪तवैव⟫ ⟪हस्ते⟫ ⟪शस्त्रं⟫ ⟪तिष्ठतु⟫ ⟪॥⟫ ⟪१०⟫ ⟪॥⟫**
ขอให้ง้าวอยู่ในมือของท่าน!

⟪११⟫. **⟪भवति⟫ ⟪न⟫ ⟪ते⟫ ⟪परिभवस्तत्रभवतो⟫ ⟪रामस्य⟫ ⟪निवेदयितव्यः⟫ ⟪॥⟫ ⟪११⟫ ⟪॥⟫**
พระเจ้าค่ะ/ครับ ความต่ำต้อยของพระองค์ไม่ควรแจ้งให้พระรามทรงทราบ

## การแปลเป็นภาษาสันสกฤต (คำสั่ง)

ข) จงแปลเป็นภาษาสันสกฤตโดยใช้รูปคำสั่ง:

⟪१⟫. **⟪भ्रियै⟫ ⟪॥⟫ ⟪१⟫ ⟪॥⟫**
ข้าพเจ้าต้องการจะได้รับการรักษา

⟪२⟫. **⟪तुष्यतु⟫ ⟪॥⟫ ⟪२⟫ ⟪॥⟫**
เขาพึงพอใจ

⟪३⟫. **⟪ह्वयाम⟫ ⟪॥⟫ ⟪३⟫ ⟪॥⟫**
เราต้องการจะเรียก

⟪४⟫. **⟪तुभ्यं⟫ ⟪नमानि⟫ ⟪।⟫** (หรือ: **⟪नमानि⟫ ⟪ते⟫ ⟪॥⟫ ⟪४⟫ ⟪॥⟫**)
ข้าพเจ้าต้องการจะโค้งคำนับต่อท่าน

⟪५⟫. **⟪एतत्कर्म⟫ ⟪क्रियताम्⟫ ⟪॥⟫ ⟪५⟫ ⟪॥⟫**
กิจนี้พึงกระทำ

⟪६⟫. **⟪भवता⟫ ⟪सुप्यताम्⟫ ⟪॥⟫ ⟪६⟫ ⟪॥⟫**
พวกเขาจงหลับนอน (โครงสร้างแบบถูกกระทำ)

⟪७⟫. **⟪पुत्र⟫ ⟪धने⟫ ⟪यतस्व⟫ ⟪॥⟫ ⟪७⟫ ⟪॥⟫** (หรือ: **... ⟪धनं⟫ / ⟪धनाय⟫ ...**)
ลูกเอ๋ย จงแสวงหาความมั่งคั่ง!

⟪८⟫. **⟪अध्ययनमारभध्वम्⟫ ⟪॥⟫ ⟪८⟫ ⟪॥⟫**
จงเริ่มการศึกษา!

⟪९⟫. **⟪पितृभ्यः⟫ ⟪पिण्डान्प्रयच्छत⟫ ⟪॥⟫ ⟪९⟫ ⟪॥⟫**
จงถวายภัตตาหารแก่บรรพบุรุษ!

⟪१०⟫. **⟪नन्दन्तु⟫ ⟪॥⟫ ⟪१०⟫ ⟪॥⟫**
พวกเขาจงยินดี!

⟪११⟫. **⟪लोकमवेक्षै⟫ ⟪॥⟫ ⟪११⟫ ⟪॥⟫**
ข้าพเจ้าต้องการจะทอดพระเนตรโลก

⟪१२⟫. **⟪काशीं⟫ ⟪पद्यामहै⟫ ⟪॥⟫ ⟪१२⟫ ⟪॥⟫**
เราต้องการจะไปยังเมืองวาราณสี

⟪१३⟫. **⟪देवान्यजन्ताम्⟫ ⟪॥⟫ ⟪१३⟫ ⟪॥⟫**
พวกเขาจงบูชาเทพเจ้าในฐานะเจ้าของพิธีบูชายัญ

⟪१४⟫. **⟪स्तोत्रं⟫ ⟪गाय⟫ ⟪॥⟫ ⟪१४⟫ ⟪॥⟫**
จงขับร้องบทสรรเสริญ!

⟪१५⟫. **⟪पुत्रा⟫ ⟪मे⟫ ⟪जायन्ताम्⟫ ⟪॥⟫ ⟪१५⟫ ⟪॥⟫**
ขอให้ได้ลูกชายเกิดแก่ข้า!

⟪१६⟫. **⟪तुभ्यं⟫ ⟪मे⟫ ⟪गृहं⟫ ⟪दिशानि⟫ ⟪॥⟫ ⟪१६⟫ ⟪॥⟫**
ข้าพเจ้าต้องการจะแสดงบ้านของข้าให้ท่านเห็น

⟪१७⟫. **⟪मत्प्रव्रज⟫ ⟪॥⟫ ⟪१७⟫ ⟪॥⟫**
จงไปจากข้า!

⟪१८⟫. **⟪मुच्यताम्⟫ ⟪॥⟫ ⟪१८⟫ ⟪॥⟫**
เขาพึงได้รับการปลดปล่อย!

⟪१९⟫. **⟪तव⟫ ⟪भार्यां⟫ ⟪रक्षाणि⟫ ⟪॥⟫ ⟪१९⟫ ⟪॥⟫**
ข้าพเจ้าต้องการจะคุ้มครองภรรยาของท่าน


⟪२०⟫. **⟪शत्रो⟫ ⟪म्रियस्व⟫ ⟪॥⟫ ⟪२०⟫ ⟪॥⟫**
จงตายเถิด โอ้ศัตรู!

⟪२१⟫. **⟪युध्यध्वम्⟫ ⟪॥⟫ ⟪२१⟫ ⟪॥⟫**
จงต่อสู้!

⟪२२⟫. **⟪आज्ञापयन्तु⟫ ⟪॥⟫ ⟪२२⟫ ⟪॥⟫**
จงสั่งการเถิด

⟪२३⟫. **⟪तव⟫ ⟪गृहे⟫ ⟪वसाम⟫ ⟪॥⟫ ⟪२३⟫ ⟪॥⟫**
เราจักอาศัยอยู่ในบ้านของท่าน

⟪२४⟫. **⟪एवं⟫ ⟪भवतु⟫ ⟪॥⟫ ⟪२४⟫ ⟪॥⟫**
จงเป็นไปดังนี้!

⟪२५⟫. **⟪अश्वं⟫ ⟪तुद⟫ ⟪॥⟫ ⟪२५⟫ ⟪॥⟫**
จงตีม้า!

⟪२६⟫. **⟪भ्रमन्तु⟫ ⟪॥⟫ ⟪२६⟫ ⟪॥⟫**
จงเร่ร่อนไป

⟪२७⟫. **⟪माद्यत⟫ ⟪॥⟫ ⟪२७⟫ ⟪॥⟫**
จงเมา!

⟪२८⟫. **⟪अश्वो⟫ ⟪भारं⟫ ⟪कर्षतु⟫ ⟪॥⟫ ⟪२८⟫ ⟪॥⟫**
จงให้ม้าลากภาระ

⟪२९⟫. **⟪लोकान्कल्पयाम⟫ ⟪॥⟫ ⟪२९⟫ ⟪॥⟫**
เราจักจัดระเบียบโลกทั้งหลาย

⟪३०⟫. **⟪पानं⟫ ⟪पिब⟫ ⟪॥⟫ ⟪३०⟫ ⟪॥⟫**
จงดื่มน้ำเมา!

⟪३१⟫. **⟪मन्यस्व⟫ ⟪॥⟫ ⟪३१⟫ ⟪॥⟫**
จงคิด!

⟪३२⟫. **⟪जीयन्ताम्⟫ ⟪॥⟫ ⟪३२⟫ ⟪॥⟫**
จงถูกพิชิต!

⟪३३⟫. **⟪त्वया⟫ ⟪नीयामहै⟫ ⟪॥⟫ ⟪३३⟫ ⟪॥⟫**
เราจักถูกนำทางโดยท่าน

⟪३४⟫. **⟪सुखाय⟫ ⟪भवतात्⟫ ⟪॥⟫ ⟪३४⟫ ⟪॥⟫**
จงเป็นมงคล! (คำอวยพร)
