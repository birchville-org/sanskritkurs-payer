# บทที่ 13


## 13.1. PPP ที่ลงท้ายด้วย -na-

ไม่สามารถกำหนดกฎตายตัวสำหรับการกระจายตัวของ PPP ที่ลงท้ายด้วย -ta- หรือ -na- ได้ อย่างไรก็ตาม:

::: grammar-box

รากศัพท์ส่วนใหญ่ที่ลงท้ายด้วย -d จะสร้าง PPP ที่ลงท้ายด้วย -na ในกรณีนี้ -d-n- จะถูกแทนที่ด้วย -n-n- ซึ่งโดยปกติจะไม่เกิดขึ้นใน Wortsandhi แต่เป็นการเลียนแบบ Satzsandhi

ตัวอย่าง:
pad 4 Ā PPP: panna 3 = ⟪पन्न⟫

:::

## 13.2. ข้อมูลเพิ่มเติมเกี่ยวกับการใช้งาน PPP

::: grammar-box

**1. PPP ของกริยาที่มีความหมายว่า "คิด", "ปรารถนา", "รู้จัก", "รู้", "เคารพบูชา" รวมถึงกริยาอื่นๆ บางตัวที่ใน Dhātupāṭha (บัญชีรากศัพท์ของปาณินิ) ถูกทำเครื่องหมายด้วย ñi ไม่ได้มีความหมายเพียงอดีตเท่านั้น แต่ยังสามารถใช้ในความหมายปัจจุบันได้อีกด้วย:**
เช่น
:::
::: indent
⟪इष्ट⟫ "ที่ปรารถนา" (หมายถึงไม่ได้แค่เคยปรารถนาในอดีต แต่ยังรวมถึงปัจจุบันด้วย)
⟪त्वरित⟫ "เร่งรีบ, รีบด่วน" (PPP ของ tvar 1 Ā "เร่งรีบ"; Dhātupāṭha: ñitvárā)
:::

**2. PPP สามารถใช้เป็นคำคุณศัพท์แบบกำหนดนาม (attributive) ได้:**
เช่น
::: indent
⟪इष्टं फलम्⟫ "ผลที่ปรารถนา (เช่น ผลของการกระทำ)"
:::

หากในกรณีนี้ ⟪अपि⟫ อยู่หลัง PPP แล้ว ⟪अपि⟫ จะมีความหมายว่า "แม้ว่า":
เช่น
::: indent
⟪इष्टमपि फलं न लभते⟫ = "แม้ว่าเขาจะปรารถนาผล แต่เขาก็ไม่ได้รับมัน"
:::

**3. รูปเอกพจน์เพศกลางของ PPP จากกริยาใดๆ ก็สามารถใช้เป็นนามเชิงกริยา (Verbalabstraktum) ได้เช่นกัน:**
เช่น
::: indent
⟪गत⟫ n.: "การเดิน, กิริยาเดิน"
⟪नृत्त⟫ n.: "การเต้นรำ, การฟ้อน"
:::

## 13.3. คำขยายลักษณะของนาม (ลำดับคำ)

::: grammar-box

โดยใช้ทัทธิตา (taddhita) สuffix -mant หรือ -vant จะสร้างคำคุณศัพท์ที่แสดงความเป็นเจ้าของจากคำนาม ความหมายคือ "ผู้เป็นเจ้าของสิ่งที่ถูกอ้างถึงโดยคำนามพื้นฐาน"

vant จะเติมเข้ากับคำนามที่เสียงสุดท้ายหรือก่อนสุดท้ายเป็น a, ā หรือ m รวมถึงคำนามที่ลงท้ายด้วยพยัญชนะหยุด; ส่วนคำนามอื่นๆ มักจะเติม -mant

ตัวอย่าง:

:::
::: indent
⟪पशुमन्त्⟫ "ผู้เป็นเจ้าของสัตว์"

⟪गुणवन्त्⟫ "ผู้เป็นเจ้าของคุณสมบัติดี / คุณธรรม"
:::

## 13.5. การลดรูปฐานของคำนาม

ฐานที่ลงท้ายด้วย -mant หรือ -vant จัดอยู่ในกลุ่มนามฐานที่มีการลดรูป

::: grammar-box
ในนามฐานที่มีการลดรูป จะแบ่งออกเป็นกรณีเข้ม (strong cases) และกรณีอ่อน (weak cases) ในกรณีเข้ม สuffix ที่สร้างฐาน — สำหรับนามรากคือส่วนที่เป็นราก — จะอยู่ในระดับสูง (Guna) หรือระดับยืดเสียง (Vriddhi) ส่วนในกรณีอ่อนจะอยู่ในระดับต่ำ
:::

## 13.6. เกี่ยวกับกฎการประสมคำ (Wortsandhi)

เพื่อความเข้าใจรูปต่างๆ ของการผันคำนามลงท้ายด้วย -mant และ -vant จำเป็นต้องทราบกฎเกณฑ์ของการประสมคำดังต่อไปนี้:

::: grammar-box
1. จำนวนพยัญชนะท้ายคำ: จากพยัญชนะสองตัวหรือมากกว่าที่คำจะลงท้ายด้วย จะคงไว้เฉพาะพยัญชนะตัวแรกเท่านั้น ส่วนที่เหลือจะหายไป อนุญาตให้ใช้การเชื่อม -r- + พยัญชนะได้

2. พยัญชนะปิดเสียงเบา (Stimmloser Verschlusslaut) จะถูกแทนที่ด้วยพยัญชนะปิดเสียงดัง (stimmhaften Verschlusslaut) ที่สอดคล้องกัน เมื่ออยู่หน้าพยัญชนะปิดเสียงดัง (ยกเว้น nasal):
:::
ตัวอย่าง:
::: indent
t + bh- » -d-bh- ⟪द्भ्⟫

k + bh- » -g-bh- ⟪ग्भ्⟫

c + bh- » -g-bh- ⟪ग्भ्⟫

c + dh- » -g-dh- ⟪ग्ध्⟫
:::

## 13.7. สuffix กรณียกของรากศัพท์ลงท้ายด้วยพยัญชนะ

::: grammar-box

สำหรับรากศัพท์ที่ลงท้ายด้วยพยัญชนะ:
* สuffix ของกรณียกที่สอง (dvitīyā) พหูพจน์ เพศชายและเพศหญิง คือ -as
* สำหรับรากศัพท์ที่สร้างตามปกติ รูปกลาง (Neutrum) ในกรณียกแรก (prathamā) และกรณียกที่สอง (dvitīyā) เอกพจน์ จะไม่มี suffix
* สำหรับรากศัพท์ที่สร้างตามปกติ ในรูปกลาง สuffix ของกรณียกแรกและกรณียกที่สอง พหูพจน์ คือ -i

:::

## 13.8. การผันรากศัพท์ลงท้ายด้วย -mant และ -vant

## 13.9. รายการคำศัพท์

เรียนรู้คำต่อไปนี้:

- **eva** ⟪एव⟫ : เน้นคำก่อนหน้า
- **asura** น. ⟪असुर⟫ : ยักษ์

> **ASURA.** 'ทางจิตวิญญาณ, พระเจ้า.'
>
> ในส่วนที่เก่าแก่ที่สุดของฤคเวท คำนี้ใช้เรียกจิตสูงสุด และมีความหมายเดียวกับ Ahura ของพวกโซโรอัสเตอร์ ในความหมายของ 'พระเจ้า' มันถูกใช้กับเทพเจ้าชั้นสูงหลายองค์ เช่น อินทร์ อคฺนิ และวรุณะ ต่อมาคำนี้มีความหมายตรงกันข้ามโดยสิ้นเชิง และหมายถึงปีศาจหรือศัตรูของเทพเจ้า
>
> พบคำนี้ในความหมายดังกล่าวในส่วนที่ภายหลังของฤคเวท โดยเฉพาะในเล่มสุดท้าย และยังพบในอถรรพเวท พราหมณ์มีความหมายเดียวกันและบันทึกการต่อสู้มากมายระหว่างอสูรกับเทพเจ้า ตามไทตฺติรียะพราหมณ์ ลมหายใจ *(asu)* ของพรหมาปตีมีชีวิต และ "ด้วยลมหายใจนั้น เขาสร้างข้าพเจ้าเป็นอสูร" ในส่วนอื่นของงานเดียวกันกล่าวว่า พรหมาปตี "ตั้งครรภ์ เขาสร้างอสูรจากช่องท้องของเขา" ศตปถพราหมณ์สอดคล้องกับข้อความก่อนหน้า และระบุว่า "เขาสร้างอสูรจากลมหายใจส่วนล่าง" ไทตฺติรียะอาเรนยกะระบุว่า พรหมาปตีสร้างเทพเจ้า มนุษย์ บิดา กัธรรวะ และอัปสรจากน้ำ และอสูร รากษส และปิศาจเกิดจากหยดที่หกออกมา คำกล่าวของมนุว่าพวกเขาถูกสร้างโดยพรหมาปตี
>
> ตามวิษณุปุราณะ พวกเขาเกิดจากขาของพระพรหม (พรหมาปตี) คำอธิบายของวายุปุราณะคือ: "อสูรถูกสร้างเป็นบุตรจากขาของเขา (พรหมาปตี) ก่อนแรก *Asu* ถูกประกาศโดยพราหมณ์ว่าหมายถึงลมหายใจ จากมันสิ่งมีชีวิตเหล่านี้ถูกสร้าง; ดังนั้นพวกเขาจึงเป็นอสูร" คำนี้ใช้เป็นชื่อทั่วไปสำหรับศัตรูของเทพเจ้ามาช้านาน รวมถึงไดตฺยะและดานวะ และลูกหลานอื่นๆ ของกัศยปะ แต่ไม่รวมรากษสที่สืบเชื้อสายจากปุละสตฺยะ
>
> ในความหมายนี้ มีการค้นพบที่มาอื่นสำหรับคำนี้: แหล่งที่มาจาก asu ไม่ใช่ 'ลมหายใจ' แต่ตัวอักษรต้น *a* ถือเป็นคำนำหน้าเชิงลบ และ *asura* หมายถึง 'ไม่ใช่พระเจ้า'; ดังนั้น ตามบางความเห็น จึงเกิดคำ *sura* ซึ่งใช้ทั่วไปสำหรับ 'พระเจ้า'"
>
> [แหล่ง: **Dowson, John (1820–1881):** พจนานุกรมคลาสสิกของตำนานฮินดูและศาสนา ภูมิศาสตร์ ประวัติศาสตร์ และวรรณกรรม. -- ลอนดอน, Trübner, 1879. -- ดูคำ ]
