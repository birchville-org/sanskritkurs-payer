## 7.1. ประโยคกริยาที่มีกรรมตรง

::: grammar-box
**แผนผัง:**
**(ผู้กระทำ = kartṛ ล.ชาย = ⟪कर्तृ⟫) – กรรมตรง (karman ล.กลาง = ⟪कर्मन्⟫) – กริยา**

เช่น
- **rāmaḥ phalaṃ khādati** = ⟪रामः⟫ ⟪फलं⟫ ⟪खादति⟫ : "รามกิน (ทาน) ผลไม้หนึ่งผล"
- **brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो⟫ ⟪देवं⟫ ⟪यजति⟫ : "พราหมณ์บูชาเทพเจ้าหนึ่งองค์ด้วยการบูชายัญ (เพื่อผู้อื่น)"
:::
หากกริยาอยู่ในรูปปารัสไมปะทะ (Parasmaipada) หรืออาตฺมเนปะทะ (Ātmanepada) โดยทั่วไปแล้วกรรมตรง (**karman** ล.กลาง = ⟪कर्मन्⟫) จะอยู่ในรูป **กรรตุการก** (Wenfall, dvitīyā ล.หญิง = ⟪द्वितीया⟫)

## 7.2. กรรตุการก (Wenfall, dvitīyā ล.หญิง = ⟪द्वितीया⟫ = "วิภัตติการกที่สอง")

| **-ī**: devī | **devīm** :br⟪देवीम्⟫ |

:::

::: grammar-box
**กรรตุการก พหูพจน์ ล.หญิง ของรากสระ (ข้อยกเว้น: รากคำพยางค์เดียวที่มีสระยาว): การยืดเสียงสระท้าย + -s**

### 7.2.1. กรรตุการก เอกพจน์และพหูพจน์ ของสรรพนามคำถามและสรรพนามแสดงอาการ

::: grammar-box
| || ล.ชาย | ล.หญิง | ล.กลาง |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :brใคร/อะไร | เอก. | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |
| | พหู. | **kān** :br⟪कान्⟫ | **kās** :br⟪कास्⟫ | **kāni** :br⟪कानि⟫ |
| **tad** :brer/นั้น/es | sg. | **tam** :br⟪तम्⟫ | **tām** :br⟪ताम्⟫ | **tad** :br⟪तद्⟫ |
| | pl. | **tān** :br⟪तान्⟫ | **tās** :br⟪तास्⟫ | **tāni** :br⟪तानि⟫ |
| **etad** :brนี้/นี่/níi | sg. | **etam / enam** :br⟪एतम्⟫ / ⟪एनम्⟫ | **etām / enām** :br⟪एताम्⟫ / ⟪एनाम्⟫ | **etad / enad** :br⟪एतद्⟫ / ⟪एनद्⟫ |

| **idam** :brนี้/níi | sg. | **imam / enam** :br⟪इमम्⟫ / ⟪एनम्⟫ | **imām / enām** :br⟪इमाम्⟫ / ⟪एनाम्⟫ | **idam / enad** :br⟪इदम्⟫ / ⟪एनद्⟫ |

รูป **enam** (⟪एनम्⟫) เป็นต้น เป็นของรากศัพท์ **enad** (⟪एनद्⟫) ซึ่งสร้างรูปกริยาเฉพาะในบางกรณีเท่านั้น รูปเหล่านี้จะถูกใช้แทนรูปของ **etad** และ **idam** เมื่อสิ่งที่กล่าวถึงนั้นได้ถูกเอ่ยถึงไปแล้วในบริบทก่อนหน้า
เช่น **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं⟫ ⟪देवः⟫ | ⟪एनं⟫ ⟪यजन्ते⟫ || : "พระองค์เป็นเทพเจ้า ผู้คนบูชามิใช่หรือ"

### 7.2.2. การใช้กริยาวิภัตติที่ 2 (กัมมการก, dvitīyā f. = ⟪द्वितीया⟫ = "วิภัตติที่ 2")

::: grammar-box
กริยาวิภัตติที่ 2 (dvitīyā f. = ⟪द्वितीया⟫) หมายถึง:
1. ในประโยคกริยาที่ไม่ใช่รูปถูกกระทำ (non-passive): **กรรมตรง** (karman n. = ⟪कर्मन्⟫) ของการกระทำที่แสดงโดยกริยา:
เช่น
   - **devaṃ yajati** = ⟪देवं⟫ ⟪यजति⟫ : "พระองค์บูชาเทพเจ้าด้วยการบูชายัญ"
   - **phalam āpnoti** = ⟪फलमाप्नोति⟫ : "พระองค์ได้รับผล (เช่น ผลจากการกระทำ)"
2. ในกริยาที่แสดงการไป การเคลื่อนไหว การนำ หรือทำนองเดียวกัน กริยาวิภัตติที่ 2 หมายถึงเป้าหมายของการเคลื่อนไหว:
เช่น
   - **narakaṃ gacchati** = ⟪नरकं⟫ ⟪गच्छति⟫ : "พระองค์ไปยังนรก"
:::
การใช้งานอื่น ๆ ของกริยาวิภัตติที่ 2 จะกล่าวถึงในภายหลัง

## 7.3. สันธิตัวท้าย -n

::: grammar-box
**ตัวท้าย -n:**

1. จะถูกแทนที่ด้วยพยัญชนะนาสิกะที่สอดคล้องกับพยัญชนะสัมผัส (sparśa) ที่ออกเสียงตามหลัง และก่อน **ś-**:
   - **-n** ก่อน **j-, jh-, ñ-, ś-** » **-ñ**
   - **-n** ก่อน **ḍ-, ḍh-, ṇ-, ṣ-** » **-ṇ**
เช่น **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "พระองค์พิชิตพวกกษัตริย์"
ตัวต้น **ś-** มักจะถูกแทนที่ด้วย **ch-**:
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (นอกเหนือจาก gurūñ śṛṇoti) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "พระองค์ฟังครู" "พระองค์เชื่อฟังครู"

2. จะถูกแทนที่ด้วย **-l** พร้อมอนุนาสิก (พยัญชนะ l ที่ออกเสียง nasally, ในอักษร ⟪ल्⟫ พร้อมอนุนาสิก ⟪ँ⟫) ก่อนตัวต้น **l-**:
เช่น **paśūn + labhate** » ⟪पशूंल्लभते⟫ : "พระองค์ได้รับปศุสัตว์"

3. จะถูกแทนที่ด้วย **anusvāra** + พยัญชนะเสียดสี (zhi) ที่สอดคล้องกับพยัญชนะสัมผัสที่ออกเสียงตามหลัง:
   - **-n** ก่อน **c-, ch-** » **-ṃś**
   - **-n** ก่อน **ṭ-, ṭh-** » **-ṃṣ**
   - **-n** ก่อน **t-, th-** » **-ṃs**
เช่น **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : "และเทพเจ้า (กัมมการก)"
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : "แต่เทพเจ้า (กัมมการก)"

4. เว้นแต่หลังสระสั้น (ดูข้างล่าง) **-n** ที่ออกเสียงท้ายจะคงเดิมในทุกกรณีอื่นๆ
:::

## 7.4. ลิงค์กลาง (napuṃsaka n. = ⟪नपुंसक⟫)

::: grammar-box
**ในลิงค์กลาง รูปนาม (prathamā) และรูปกรรม (dvitīyā) เหมือนกัน**
:::
### 7.4.1. ลิงค์กลางของรากศัพท์ลงท้ายด้วย -a

::: grammar-box
- **รูปเอกพจน์: -m**
เช่น **phala** n. = ⟪फल⟫ = "ผลไม้": เอกพจน์ **phalam** = ⟪फलम्⟫
- **รูปพหูพจน์: -āni**
เช่น **phala** n. = ⟪फल⟫: พหูพจน์ **phalāni** = ⟪फलानि⟫
:::

## 7.5. กลุ่มปัจจุบันแบบไม่มีสระTheme

กลุ่มปัจจุบันที่ 5 สร้างรากศัพท์ปัจจุบันแบบไม่มีสระTheme กล่าวคือ รากศัพท์ปัจจุบันไม่ลงท้ายด้วย "สระTheme" **-a** เหมือนกลุ่มปัจจุบันแบบมีสระTheme (กลุ่มที่ 1, 4, 6, 10)

::: grammar-box
**กลุ่มปัจจุบันแบบไม่มีสระTheme มีการลดระดับรากศัพท์ กล่าวคือ มีสองรูปแบบของรากศัพท์ปัจจุบัน:**
1. **รากแข็ง**: ระดับสูง (หากระดับขยายหายาก)
2. **รากอ่อน**: ระดับต่ำ

**รากแข็งใช้:**
- ในบอกเล่าเอกพจน์ ปารัสไพบท ปัจจุบัน (laṭ) และอดีตกาล (laṅ)
- ในคำสั่งทุกบุคคลของอิมเพอเรทีฟ (loṭ) ปารัสไพบท และอัตมานิปาท
- ในคำสั่งบุคคลที่สามเอกพจน์ ปารัสไพบท

**รูปแบบอื่นๆ ใช้รากปัจจุบันแบบอ่อน**
:::
### 7.5.1. รูปจบหลักของบุคคลที่สามพหูพจน์ในรากศัพท์แบบไม่มีสระTheme

::: grammar-box
**ในรากศัพท์ปัจจุบันแบบไม่มีสระTheme รูปจบหลักของบุคคลที่สามพหูพจน์คือ:**
- **ปารัสไพบท: -anti**
- **อัตมานิปาท: -ate**
:::
### 7.5.2. กลุ่มปัจจุบันที่ 5 (svādi = ⟪स्वादि⟫ = "su ฯลฯ")

::: grammar-box
- **รากแข็ง**: (ส่วนใหญ่) รากศัพท์ระดับต่ำ (ตามที่กล่าวมา) + **-no-**
- **รากอ่อน**: (ส่วนใหญ่) รากศัพท์ระดับต่ำ (ตามที่กล่าวมา) + **-nu-**

**ก่อนรูปจบแบบสระ ในรากศัพท์ที่ลงท้ายด้วยเสียงสระ -nu- จะเปลี่ยนเป็น -nv- และในรากศัพท์ที่ลงท้ายด้วยพยัญชนะ ก่อนรูปจบแบบสระ -nu- จะเปลี่ยนเป็น -nuv-**
:::

## 7.6. รายการคำศัพท์

**เรียนรู้คำต่อไปนี้:**

- **aś** 5 Ā (aśnute) ⟪अश्⟫ ⟪अश्नुते⟫ : บรรลุ, ถึง, ได้รับ

- **naraka** m. ⟪नरक⟫ : นรก (ตามความเชื่อของฮินดู จักรวาลมีรูปร่างเหมือนไข่ (**Brahmāṇḍa** m.n. = ⟪ब्रह्माण्ड⟫ = "ไข่ของพรหม"): เหนือพื้นโลกมีสวรรค์หกชั้นที่มีความสุขเพิ่มขึ้น ใต้พื้นโลกมีเจ็ดแห่งที่เรียกว่า **pātāla** n. = ⟪पाताल⟫ ซึ่งเป็นที่อยู่ของ **nāga** m. = ⟪नाग⟫ (งู) และสิ่งมีชีวิตในตำนานอื่นๆ ซึ่งด้านล่างมีนรกเจ็ดชั้นที่มีความทุกข์เพิ่มขึ้น)
- **aṅga** n. ⟪अङ्ग⟫ : อวัยวะของร่างกาย ส่วนประกอบ; ยังเท่ากับ **vedāṅga** = ⟪वेदाङ्ग⟫
- **gam** 1 P (gacchati) ⟪गम्⟫ ⟪गच्छति⟫ : ไป (ตามการจำแนกประเภทกริยาภายในประเทศจัดอยู่ในชั้นปัจจุบันที่ 1 แต่ในความเป็นจริงเป็นการสร้างด้วยsuffixการสร้างรากศัพท์ปัจจุบัน **-ccha-**: **gam** » ระดับลึก (**gm** ») **ga-ccha-ti**)
