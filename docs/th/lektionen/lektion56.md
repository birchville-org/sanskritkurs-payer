# บทที่ 56

## 56.1. ออริสต์แบบเติมเสียงซ้ำ (reduplicated Aorist)

::: grammar-box
**การสร้าง:**

**อ็อกเมนต์ + รากศัพท์ที่เติมเสียงซ้ำ + a + การลงท้ายแบบทุติยภาคตามธีม (thematic secondary ending)**

**พยางค์รากศัพท์อาจมีระดับเสียงต่ำหรือสูงได้ สำหรับรากศัพท์ที่ลงท้ายด้วย -i หรือ -u ระดับเสียงต่ำเป็นกฎทั่วไป**

**-i, -u ที่ลงท้ายจะถูกแทนที่ด้วย -iy หรือ -uv**

**-ā (สำหรับ -e) ที่ลงท้ายจะหายไป**
:::
ตารางผันคำ:

⟪श्रि⟫ 1U "มุ่งหน้าไปยัง, พึ่งพา"

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | ⟪अशिश्रियम्⟩:br(⟪अ⟫-⟪शि⟫-⟪श्रिय्⟫-⟪अम्⟫) | ⟪अशिश्रियाम⟫ | ⟪अशिश्रिये⟫ | ⟪अशिश्रियामहि⟫ |
| **2. ⟪द्वितीयः⟫** | ⟪अशिश्रियस्⟫ | ⟪अशिश्रियत⟫ | ⟪अशिश्रियथास्⟫ | ⟪अशिश्रियध्वम्⟫ |
| **3. ⟪प्रथमः⟫** | ⟪अशिश्रियत्⟫ | ⟪अशिश्रियन्⟫ | ⟪अशिश्रियत⟫ | ⟪अशिश्रियन्त⟫ |

รูปของออริสต์นี้สร้างโดยรากศัพท์ต่างๆ รวมถึง:

*   ⟪श्रि⟫ 1U "มุ่งหน้าไปยัง"
*   ⟪द्रु⟫ 1P "วิ่ง"
*   ⟪कम्⟫ 1Ā "รัก": ⟪अचकमत⟫ / ⟪अचीकमत⟫ (ดูด้านล่าง!)
*   ⟪पत्⟫ 1P "ตก": ⟪अपप्तत्⟫ (a-pa-pt-a-t; pt = ระดับเสียงต่ำของ pat)
*   ⟪वच्⟫ 2P "พูด": ⟪अवोचत्⟫ (a-va + uc-a-t)

::: grammar-box
**รากศัพท์ทั้งหมดของชั้นปัจจุบันที่ 10 และคำ causative ทั้งหมดจะสร้างออริสต์แบบเติมเสียงซ้ำเสมอ**
:::
### 56.1.1. การสร้างออริสต์ของคำ causative และรากศัพท์ของชั้นปัจจุบันที่ 10

พยางค์ฐาน:

::: grammar-box
**จุดเริ่มต้นคือรูปของฐานปัจจุบันหรือฐาน causative ซึ่งเหลืออยู่หลังจากที่องค์ประกอบทางการ -aya- หายไป (ดังนั้นฐานลงท้ายด้วย -p สำหรับคำ causative ที่ลงท้ายด้วย -paya-)**

**สระของพยางค์ฐานดังกล่าวนี้ในออริสต์ถูกกำหนดตามกฎต่อไปนี้:**

*   **\-ā- ก่อน辅音เดี่ยวจะถูกแทนที่ด้วย -a-**
⟪पॄ⟫ 3P: Caus. sig[⟪पार⟫]⟪यति⟫, Aor. ⟪अपि⟫sig[⟪पर⟫]⟪त्⟫
⟪द्रु⟫ 1P: Caus. sig[⟪द्राव⟫]⟪यति⟫, Aor. ⟪अदु⟫sig[⟪द्रव⟫]⟪त्⟫ / ⟪अदि⟫sig[⟪द्रव⟫]⟪त्⟫
⟪नी⟫ 1U: Caus. sig[⟪नाय⟫]⟪यति⟫, Aor. ⟪अनी⟫sig[⟪नय⟫]⟪त्⟫
⟪ज्ञा⟫ 9U: Caus. sig[⟪ज्ञाप⟫]⟪यति⟫, Aor. ⟪अजि⟫sig[⟪ज्ञप⟫]⟪त्⟫

*   **\-ī-, -e-, -ai- ก่อน辅音เดี่ยวจะถูกแทนที่ด้วย -i-**
⟪चित्⟫ 1P: Caus. sig[⟪चेत⟫]⟪यति⟫, Aor. (Ā) ⟪अची⟫sig[⟪चित⟫]⟪त⟫

*   **\-u-, -o-, -au- ก่อน辅音เดี่ยวจะถูกแทนที่ด้วย -u-**
⟪चुर्⟫ 10U: sig[⟪चोर⟫]⟪यति⟫, Aor. ⟪अचू⟫sig[⟪चुर⟫]⟪त्⟫

**สำหรับรากศัพท์บางตัว การเปลี่ยนแปลงที่กล่าวมาข้างต้นอาจเป็นทางเลือกหรือต้องละเว้น:**

*   **ar, ār, īr, al ซึ่งแทนที่ด้วย ṛ, ṝ, ḷ และอยู่ถัดจาก辅音ของพยางค์ฐานโดยตรง จะคงไว้เป็นทางเลือกหรือถูกแทนที่ด้วย ṛ หรือ ḷ:**
⟪कॢप्⟫ 1Ā: Caus. sig[⟪कल्प⟫]⟪यति⟫, Aor. ⟪अच⟫sig[⟪कल्प⟫]⟪त्⟫ / ⟪अची⟫sig[⟪कॢ⟫]⟪पत्⟫
⟪कृष्⟫ 1P/6U: Caus. sig[⟪कर्ष⟫]⟪यति⟫, Aor. ⟪अच⟫sig[⟪कर्ष⟫]⟪त्⟫ / ⟪अची⟫sig[⟪कृ⟫]⟪षत्⟫
:::
สระของพยางค์เติมเสียงซ้ำ:

หลังจากใช้กฎที่กล่าวมาข้างต้นกับพยางค์ฐานแล้ว ต้องปฏิบัติตามกฎต่อไปนี้สำหรับสระของพยางค์เติมเสียงซ้ำ:

::: grammar-box
**จุดเริ่มต้นคือสระเติมเสียงซ้ำปกติ นั่นคือ**

*   a สำหรับ a, ā, ṛ, ṝ, ḷ
*   i สำหรับ i, ī, e, ai
*   u สำหรับ u, ū, o, au


**สระเสียงหนักของการซ้ำพยางค์นี้มีการเปลี่ยนแปลงดังต่อไปนี้:**

*   **i, u จะถูกแทนที่ด้วย ī, ū เมื่อพยางค์ฐานเริ่มต้นด้วยพยัญชนะเพียงตัวเดียวและสั้นตามจังหวะ:**  
⟪भिद्⟫ 7U: Kaus. ⟪भेदयति⟫, Aor. ⟪अ⟫sig[⟪बी⟫]⟪भिदत्⟫  
⟪तुद्⟫ 6U: Kaus. ⟪तोदयति⟫, Aor. ⟪अ⟫sig[⟪तू⟫]⟪तुदत्⟫  

*   **a จะถูกแทนที่ด้วย ī เมื่อพยางค์ฐานสั้นตามจังหวะและเริ่มต้นด้วยพยัญชนะเพียงตัวเดียว หากพยางค์ฐานสั้นตามจังหวะแต่เริ่มต้นด้วยพยัญชนะมากกว่าหนึ่งตัว สระ a ในพยางค์ซ้ำจะถูกแทนที่ด้วย i หากพยางค์ฐานยาวตามจังหวะ สระ a จะคงอยู่:**  
⟪नी⟫ 1U: Kaus. ⟪नाययति⟫, พยางค์ฐานของ Aor. ⟪नय्⟫, Aor. ⟪अ⟫sig[⟪नी⟫]⟪नयत्⟫  
⟪कृ⟫ 8U: Kaus. ⟪कारयति⟫, พยางค์ฐานของ Aor. ⟪कर्⟫, Aor. ⟪अ⟫sig[⟪ची⟫]⟪करत्⟫  
⟪त्यज्⟫ 1P: Kaus. ⟪त्याजयति⟫, พยางค์ฐานของ Aor. ⟪त्यज्⟫, Aor. ⟪अ⟫sig[⟪ति⟫]⟪त्यजत्⟫  
⟪भू⟫ 1P: Kaus. ⟪भावयति⟫, พยางค์ฐานของ Aor. ⟪भव्⟫, Aor. ⟪अ⟫sig[⟪बी⟫]⟪भवत्⟫

ลักษณะเฉพาะของรากศัพท์บางประการใน Kielhorn, Grammatik § 435c เป็นต้นไป

**พยางค์ฐานที่เริ่มต้นด้วยสระจะถูกซ้ำตามกฎต่อไปนี้:**

*   **หากตามหลังสระต้นมีพยัญชนะเพียงตัวเดียวหรือกลุ่มพยัญชนะที่สมาชิกแรกไม่ใช่ nasal หรือ d หรือ r พยางค์ซ้ำจะ звучดังนี้:**

สระ - พยัญชนะตัวแรกตามหลัง (หรือตัวแทนที่จำเป็นในพยางค์ซ้ำ) - **i** - พยัญชนะทั้งหมด

:::
::: indent
⟪अश्⟫ 9P: Kaus. ⟪आशयति⟫, พยางค์ซ้ำ ⟪आशिश्⟫, Aor. ⟪आशिशत्⟫
⟪इष्⟫ 6P: Kaus. ⟪एषयति⟫, พยางค์ซ้ำ ⟪एषिष्⟫, Aor. ⟪ऐषिषत्⟫
⟪ईक्ष्⟫ 1Ā: Kaus. ⟪ईक्षयति⟫, พยางค์ซ้ำ ⟪ईचिक्ष्⟫, Aor. ⟪ऐचिक्षत्⟫
:::
*   **หากตามหลังสระต้นมีกลุ่มพยัญชนะที่เริ่มต้นด้วย nasal หรือ d หรือ r พยัญชนะตัวที่สองของกลุ่ม (หรือตัวแทน) จะถูกแทรกด้วย i ตามรูปแบบต่อไปนี้:**


สระ - พยัญชนะตัวแรก - พยัญชนะตัวที่สอง (ตัวแทน) - i - พยัญชนะตัวที่สอง

::: indent
⟪अञ्ज्⟫ 7P: Kaus. ⟪अञ्जयति⟫, พยางค์ซ้ำ ⟪अञ्जिज्⟫, Aor. ⟪आञ्जिजत्⟫
⟪ऋ⟫ 1P: Kaus. ⟪अर्पयति⟫, พยางค์ซ้ำ ⟪अर्पिप्⟫, Aor. ⟪आर्पिपत्⟫
⟪अर्ह्⟫ 1P: Kaus. ⟪अर्हयति⟫, พยางค์ซ้ำ ⟪अर्जिह्⟫, Aor. ⟪आर्जिहत्⟫
:::
รูปแบบการซ้ำนี้ของรากศัพท์อนุพันธ์ที่เริ่มต้นด้วยสระ (Kausative) เรียกว่า "การซ้ำแบบแอตติก"
## 56.2. อินจังก์ทีฟ (Injunktiv)

::: grammar-box
**อินจังก์ทีฟคือรูปแบบที่ไม่มี augment สำหรับรูปแบบที่มี augment กล่าวคือ รูปแบบของมันเหมือนกับรูปแบบไม่มีaugmentของ Indikativ Imperfekt หรือ Aorist ไวยากรณ์อินเดียพื้นเมืองไม่ได้ยอมรับอินจังก์ทีฟเป็นหมวดหมู่ไวยากรรมพิเศษ**
:::

ในพระเวท คำกริยาเชิงคำสั่ง (Injunktive) มีลักษณะดังนี้:

*   ไม่ใช้เพื่อรายงาน แต่ใช้เพื่อกำกับ
ไม่มีระดับเวลา
*   Injunktive ปัจจุบัน (= Imperfect ที่ไม่มี augment) หมายถึง aspect ที่ยังไม่สมบูรณ์
*   Injunktive Aorist หมายถึง aspect ที่สมบูรณ์

::: grammar-box
**ในภาษาสันสกฤตหลังพระเวท คำกริยาเชิงคำสั่ง (Injunktive) จะปรากฏเฉพาะในบริบทของอนุภาคห้าม ⟪मा⟫ (+ Injunktive Aorist) หรือ ⟪मा⟫ ⟪स्म⟫ (+ Injunktive ปัจจุบันหรือ Aorist) เท่านั้น โดยความแตกต่างของ aspect มักจะไม่ถูกนำมาใช้อีกต่อไป**

(โดยมี aspect

*   ⟪मा⟫ + Injunktive Aorist จะหมายถึงประโยคห้าม (Prohibitive sentence): "อย่าเริ่ม..." หรือ "อย่าทำ...!"
*   ⟪मा⟫ ⟪स्म⟫ + Injunktive ปัจจุบัน จะหมายถึงประโยคยับยั้ง (Inhibitive sentence) นั่นคือ การกระทำที่กำลังดำเนินอยู่หรือสถานะที่มีอยู่แล้วถูกห้าม: "หยุด..." หรือ "เลิก...!"

อย่างไรก็ตาม ความแตกต่างนี้มักไม่ถูกใช้ในภาษาสันสกฤตคลาสสิก)
:::
## 56.3. ประโยคห้าม

::: grammar-box
**รูปแบบหลัก:**

**⟪मा⟫ + Injunktive Aorist**

**⟪मा⟫ ⟪स्म⟫ + Injunktive Aorist หรือ Injunktive ปัจจุบัน**
:::
ตัวอย่าง:

::: indent
⟪मा⟫ ⟪कर्महेतुर्भूः⟫ "อย่าเป็นผู้ที่ถูกกระตุ้นโดยผลของการกระทำ!" (Injunktive Aorist) (⟪भगवद्गीता⟫ 2,47c)

⟪क्लैब्यं⟫ ⟪मा⟫ ⟪स्म⟫ ⟪गमः⟫ "อย่าเป็นผู้ชายไม่สมศักดิ์ศรี!" (Injunktive Aorist) (⟪भगवद्गीता⟫ 2,3a)
:::
::: media
![](/images/lekt5602.webp)
ภาพ: ⟪क्लैब्यं⟫ ⟪मा⟫ ⟪स्म⟫ ⟪गमः⟫
โปสเตอร์ (เออร์เนสตو เช เกวารา) ของพรรคการเมืองในวัลลาชิระ (വാല്ലചിര), ตรีชัวร์ (തൃശ്ശൂര്‍) "คำแปลอย่างหยาบของข้อความที่เขียนไว้คือ: การพลีชีพเป็นประสบการณ์ที่น่าสนใจสำหรับนักปฏิวัติ และเป็นที่พึ่งที่น่าเกรงขามสำหรับผู้ทรยศ เกวาราไม่ใช่แบบอย่างสำหรับคนขี้ขลาด"
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt5602))
:::
ตัวอย่างทั้งสองมีนัยยะของการห้าม ดังนั้น Injunktive Aorist จึงถูกใช้ในความหมายดั้งเดิมของมัน (การที่ Injunktive Aorist ครอบงำในประโยคดังกล่าวอาจอธิบายได้จากการที่มีประโยคห้าม (Prohibitive sentences) มากกว่าประโยคยับยั้ง (Inhibitive sentences) แต่คำถามนี้ยังต้องได้รับการตรวจสอบสำหรับภาษาสันสกฤตคลาสสิก)

::: grammar-box
**รูปแบบอื่นของประโยคห้าม:**

*   **⟪मा⟫ + (⟪स्म⟫) + Imperative (หาได้ยาก)**
**เช่น ⟪मा⟫ ⟪ते⟫ ⟪सङ्गो⟫ ⟪ऽस्त्वकर्मणि⟫**

*   ⟪अलम्⟫ หรือ ⟪कृतम्⟫ = Instrumental ในประโยคยับยั้ง
เช่น ⟪अलं⟫ ⟪विषादेन⟫ "พอกับความท้อแท้แล้ว! = หยุดรู้สึกท้อแท้! = ก้าวหน้า!"

*   ⟪न⟫ + Gerundive (Participle แห่งความจำเป็น)

นอกจากนี้ยังมีรูปแบบอื่นของประโยคห้ามที่หาได้ยากกว่า ดูเช่น

## 56.4. ⟪स्म⟫

::: grammar-box
**⟪स्म⟫ เน้นความหมาย: "แน่นอน, แท้จริง, แน่นอน, โดยเฉพาะ"**

**นอกจากนี้ โครงสร้างต่อไปนี้มีความสำคัญมาก:**

:::
::: indent
⟪स्म⟫ + Indicative ปัจจุบัน ใช้เพื่อเล่าเรื่องในอดีต โดยเฉพาะเพื่อบอกถึงระยะเวลาในอดีต:


เช่น ⟪वसति⟫ ⟪स्म⟫ “มีอยู่ครั้งหนึ่ง” (⟪स्म⟫ อาจหายไปบางครั้ง)
:::
