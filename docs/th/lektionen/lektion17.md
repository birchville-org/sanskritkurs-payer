[11] ## 17.1. ชั้นปัจจุบันที่สอง (⟪अदादि⟫ = ⟪अद्⟫ เป็นต้น)

[13] ท้ายคำกริยาจะติดกับรากศัพท์โดยตรง โดยต้องคำนึงถึงการเปลี่ยนแปลงของเสียงที่เกิดจากวอร์ทซันධิ (Wortsandhi)

## 17.5. รากศัพท์สองพยางค์ลงท้ายด้วย -i/-ī ที่มีระดับรากศัพท์

รากศัพท์หลายรากเป็นสองพยางค์ในรูปบางรูปแบบ กล่าวคือ มี -i (หรือ -ī ก่อนรูปจบบางแบบ) ก่อนรูปจบที่มีพยัญชนะ แต่รากศัพท์เหล่านี้ยังคงถูกกำหนดโดยนักไวยากรณ์พื้นเมืองและในพจนานุกรมต่างๆ ว่าเป็นรากศัพท์หนึ่งพยางค์

ตัวอย่าง:

⟪रुद्⟫ 2 P "ร้องไห้, ร้องครวญ"

*   รูปปัจจุบันที่แข็งแรง: rodi-
*   รูปปัจจุบันที่อ่อนแอ:
*   ก่อนพยัญชนะ: rudi-
*   ก่อนสระ: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "พูด"

*   รูปปัจจุบันที่แข็งแรง: bravī- (« bro- + -ī)
*   รูปปัจจุบันที่อ่อนแอ:
    *   vor Konsonant: brū-
*   ก่อนสระ: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
