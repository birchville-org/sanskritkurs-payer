# บทที่ 53

## 53.1. พหูพจน์คู่ (⟪द्विवचन⟫ n.) ของคำนาม

::: grammar-box
**พหูพจน์คู่ (⟪द्विवचनम्⟫) ใช้เพื่อระบุ "สอง":**

:::
::: indent
⟪अश्विनौ⟫ "อศวินทั้งสอง"
:::
**การใช้พหูพจน์คู่เป็นสิ่งที่จำเป็นเมื่อกล่าวถึงสิ่งของสองชิ้น เป็นต้น:**

::: indent
⟪हस्तौ⟫ "มือ (ของบุคคลหนึ่ง)"
⟪पादौ⟫ "เท้า (ของมนุษย์ ลิง หรือสัตว์สองขาอื่นๆ)"
:::
**บางครั้ง พหูพจน์คู่หมายถึงตัวผู้หนึ่งและตัวเมียหนึ่งจากประเภทเดียวกัน (ชนิด สกุล):**

::: indent
⟪पितरौ⟫ "บิดาและมารดา = ผู้ปกครอง"
:::
**คำที่มีความหมายว่า "คู่" - เช่น ⟪युग⟫ n., ⟪द्वन्द्व⟫ n., ⟪द्वय⟫ n. - จะถูกใช้ในรูปแบบเอกพจน์เสมอ เว้นแต่จะหมายถึงคู่สองคู่หรือมากกว่า:**

::: indent
⟪बाहुद्वयम्⟫ "แขนหนึ่งคู่"
:::

## 53.7. คำคุณศัพท์สรรพนาม

คำคุณศัพท์สรรพนามต่อไปนี้ถูกผันในทุกกรณีเหมือน ⟪यद्⟫:

*   ⟪अन्य⟫ 3 "ผู้อื่น"
*   ⟪अन्यतर⟫ 3 "หนึ่งในสอง"
*   ⟪इतर⟫ 3 "อีกผู้หนึ่ง"

*   ⟪सर्व⟫ 3 "ทุก, ทั้งหมด" ถูกผันในทุกกรณียกเว้น Nom.Akk.sg.n (⟪सर्वम्⟫) เหมือน ⟪यद्⟫
*   ⟪उभय⟫ 3 "ทั้งสอง" ไม่มีรูปพหูวจนะ ในเอกพจน์และพหูวจนะเพศชายและกลางจะถูกผันเหมือน ⟪सर्व⟫ เพศหญิง: ⟪उभयी⟫ (เหมือน ⟪देवी⟫)
*   ⟪उभ⟫ 3 "ทั้งสอง" ใช้เฉพาะในรูปพหูวจนะ และถูกผันเหมือน ⟪देव⟫ m., ⟪फल⟫ n. และ ⟪देवता⟫ f.

คำคุณศัพท์สรรพนามต่อไปนี้ถูกผันเหมือน ⟪सर्व⟫ ใน Abl.Lok.sg.m.n และ Nom.pl. สามารถผันตามการผัน -a- หรือ -ā- ได้:

*   ⟪अपर⟫ 3 "ผู้อื่น"
*   ⟪उत्तर⟫ 3 "ที่สูง, ทางเหนือ, ตามหลัง"
*   ⟪पर⟫ 3 "ตามหลัง, หลัง"
*   ⟪पूर्व⟫ 3 "นำหน้า, ตะวันออก"
*   ⟪स्व⟫ 3 "ของตนเอง (ของฉัน, ของคุณ, ของเขา ...)"

## 53.8. การเปรียบเทียบแบบผิดปกติ

::: grammar-box
**คำคุณศัพท์จำนวนหนึ่งสร้างรูปเปรียบเทียบและสูงสุดด้วย ⟪कृत्⟫ ต่อไปนี้ (!):**

*   รูปเปรียบเทียบ: **-īyas**
*   รูปสูงสุด: **-iṣṭha**

**ในขณะที่ ⟪तद्धित⟫ สuffix -⟪तर⟫ และ -⟪तम⟫ ต่อท้ายรากคำคุณศัพท์เพศชาย สuffix -⟪ईयस्⟫ และ -⟪इष्ठ⟫ ต่อท้ายรากศัพท์ที่คำคุณศัพท์นั้นมาจาก (หากมีเช่นนั้น!) สระของรากอยู่ในระดับสูง**

**รูปสูงสุดที่ลงท้ายด้วย -iṣṭha (Fem.: iṣṭhā) ถูกผันเหมือนราก a- หรือ ā-**

**Deklination von -īyas siehe unten.**
:::

### 53.10.1. ความสำคัญของการกำหนดเมตริก

การกำหนดเมตริกมีความสำคัญด้วยเหตุผลต่อไปนี้:

1.  **ด้านสุนทรียภาพ:** รูปแบบวรรคทำให้ข้อความมีความงามเป็นต้น นอกจากนี้รูปแบบวรรคบางชนิดอาจใช้เพื่อแสดงอารมณ์เฉพาะ หรือถูกกำหนดให้กับสถานะทางสังคม tertentu (⟪वर्ण⟫) รูปแบบวรรคต่างๆ จะถูกอ่านออกเสียงแตกต่างกันไป :br การได้รับภาพรวมที่ดีของผลกระทบด้านสุนทรียภาพคือตัวอย่างเช่นการอ่านออกเสียง ⟪शिवताण्डवस्तोत्र⟫ (คำสรรเสริญการเต้นรำของศิวะ): [http://de.youtube.com/watch?v=5KjfiJlkO58](http://de.youtube.com/watch?v=5KjfiJlkO58)
2.  **ด้านวิพากษ์ข้อความ:** ข้อผิดพลาดในรูปแบบวรรคอาจเป็นสัญญาณว่าข้อความนั้นไม่ได้ถูกส่งต่ออย่างถูกต้องในบางจุด รูปแบบวรรคช่วยในการปรับปรุงข้อความ
3.  **ด้านไวยากรณ์:** รูปแบบวรรคบางรูปแบบผ่านการเปลี่ยนแปลงบางอย่างตลอดประวัติศาสตร์ สิ่งนี้สามารถช่วยในการประมาณการวันที่ของข้อความ ดูเพิ่มเติม **Oldenberg, Hermann \&lt;1854 - 1920\&gt;:** เกี่ยวกับประวัติของ Triṣṭhubh ; เขาเอง: เกี่ยวกับประวัติของ Śloka. -- ทั้งสองถูกพิมพ์ใน: :br **Oldenberg, Hermann \&lt;1854 - 1920\&gt;:** งานเขียนขนาดเล็ก / โดย Hermann Oldenberg. บรรณาธิการโดย Klaus L. ### 53.10.2. ประเภทของเมตริก

::: grammar-box
**ชาวอินเดียแบ่งแยก:**

*   **⟪वृत्त⟩ n.:** เมตริกที่กำหนดจำนวนพยางค์ (⟪अक्षर⟩)
*   **⟪जाति⟩ f.:** เมตริกที่กำหนดผลรวมของหน่วยวัดเมตริก (⟪मात्रा⟩) (Moren) (ดูเพิ่มเติมในภายหลัง)

**สำหรับเมตริกที่กำหนดจำนวนพยางค์ (⟪वृत्त⟩) เราสามารถแบ่งแยกเพิ่มเติมได้ดังนี้:**

*   เมตริกที่จำนวนพยางค์ถูกกำหนดไว้ แต่ปริมาณของพยางค์เหล่านี้มีเพียงบางส่วน
*   เมตริกที่ทั้งจำนวนพยางค์และปริมาณของพยางค์ถูกกำหนดไว้
:::
### 53.10.3. ปริมาณเมตริกของพยางค์

::: grammar-box

⟪तथा⟫ ⟪पादान्तगो⟫ ⟪ऽपि⟫ ⟪वा⟫ ⟪॥⟫

"พยางค์หนึ่งมีน้ำหนักหนัก

*   wenn ihr Vokal einen Anusvāra hat,
*   ยาว,
*   มีวิสรฺคะ (Visarga),
*   เช่นเดียวกันเมื่ออยู่ก่อนกลุ่มพยัญชนะ
*   และเมื่อพยางค์นี้อยู่ท้ายบทครึ่ง (Pāda)"
::: grammar-box
**พยางค์หนึ่งคือ**

*   หรือว่า **⟪लघु⟫ = เบา**
*   หรือ **⟪गुरु⟫ = หนัก**

**⟪लघु⟫ = เบาคือพยางค์ที่**

*   สระของมันสั้น และตามหลังสระนี้
*   kein Anusvāra,
*   ไม่มีวิสรฺคะ,
*   ไม่ตามหลังด้วยพยัญชนะสองตัว

Kurze Vokale sind a, i, u, ṛ, ḷ

**พยางค์อื่นๆ ทั้งหมดคือ ⟪गुरु⟫ = หนัก พยางค์สุดท้ายของบทครึ่ง (⟪पाद⟫) ถือว่าเป็น ⟪गुरु⟫ เสมอ**

*   **—** = ⟪ग⟫ = ⟪गुरु⟫
*   **×** = ⟪लघु⟫ หรือ ⟪गुरु⟫
*   **/** = จรัสรา (การแบ่งคำ)
