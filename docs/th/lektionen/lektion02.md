# บทที่ 2

## 2.1. ประโยคนาม

::: grammar-box
**แผนภาพ: นามคำคุณศัพท์ในตำแหน่งกริยา - ประธาน**

เช่น devo viṣṇuḥ = ⟪देवो⟫ ⟪विष्णुः⟫ = "วิษณุเป็นเทพเจ้า"
:::
ไม่จำเป็นต้องมีกริยาเชื่อมโยง (copula) ("คือ", "เป็น", "ฉันคือ", "คุณคือ", "พวกท่านคือ") แต่อาจปรากฏในบางกรณี

**ไม่มีคำนำหน้า**: **devaḥ** -- ⟪देवः⟫ สามารถหมายถึง "เทพเจ้า" หรือ "เทพเจ้าหนึ่งองค์"

แม้ว่าการเรียงลำดับประโยคในภาษาสันสกฤตจะค่อนข้างอิสระ (โดยเฉพาะในบทกวี) แต่ในการแปลประโยคนาม คุณต้องพิจารณาการแปลตามแผนภาพมาตรฐานข้างต้นเป็นหลัก

ในประโยคนาม ประธานอยู่ในกรณีนามเอกพจน์ (กรณีแรก = **prathamā** f. = ⟪प्रथमा⟫) นามคำคุณศัพท์ในตำแหน่งกริยาจะตรงกันกับประธานทั้งจำนวนและกรณี; หากนามคำคุณศัพท์ในตำแหน่งกริยาคือคำคุณลักษณะ จะตรงกันทั้งเพศด้วย

## 2.2. เกี่ยวกับการผันรูป (การเปลี่ยนรูปของนาม)

ในภาษาสันสกฤตมี:

- **สามจำนวน** (รูปแบบการนับ) = **vacana** n. -- ⟪वचन⟫
  - เอกพจน์ (จำนวนเดียว) = **ekavacana** n. -- ⟪एकवचन⟫
  - ทวิพจน์ (จำนวนสอง) = **dvivacana** n. -- ⟪द्विवचन⟫
  - พหูพจน์ (จำนวนมาก) = **bahuvacana** n. -- ⟪बहुवचन⟫
- **สามเพศ** (เพศทางไวยากรณ์) = **liṅga** n. / **vyakti** f. -- ⟪लिङ्ग⟫ / ⟪व्यक्ति⟫
  - เพศชาย (บุรุษ) = **puṃs** m. -- ⟪पुंस्⟫
  - เพศหญิง (สตรี) = **strī** f. -- ⟪स्त्री⟫
  - เพศกลาง (อรูป) = **napuṃsaka** n. -- ⟪नपुंसक⟫
- **แปดกรณี** (กริยา) = **sup** -- ⟪सुप्⟫ (= สuffix กรณี)

สำหรับการผันรูปจะเติม suffix กรณี (**sup** = ⟪सुप्⟫) ลงบนสิ่งที่เรียกว่า **รากนาม** (รูปแบบของนามโดยไม่มี suffix กรณี)

ตัวอย่าง: **devas** = ⟪देवस्⟫ (นามเอกพจน์ เพศชาย) "เทพเจ้า/เทพเจ้าหนึ่งองค์" = **deva-** -- ⟪देव⟫- (รากนาม) + **-s** -- -⟪स्⟫ (suffix กรณี)

ในพจนานุกรมภาษาสันสกฤตนามจะถูกแสดงใน **รากนาม**:
- **deva** m. -- ⟪देव⟫ m. (เพศชาย)
- **vacana** n. -- ⟪वचन⟫ n. (เพศกลาง)
- **vyakti** f. -- ⟪व्यक्ति⟫ f. (เพศหญิง)

## 2.3. นามเอกพจน์

**นามเอกพจน์ = prathamā ekavacanam = ⟪प्रथमा⟫ ⟪एकवचनम्⟫**

::: grammar-box
**นามเอกพจน์ลงท้ายด้วย -s = -⟪स्⟫ หรือไม่มีการลงท้าย**
:::
### 2.3.1. นามเอกพจน์ลงท้ายด้วย -s

รากนามต่อไปนี้ซึ่งลงท้ายด้วยสระ จะสร้างรูปนามเอกพจน์โดยมี **-s** ลงท้าย:

::: grammar-box
**เพศชายลงท้ายด้วย -a:** เช่น deva m. = ⟪देव⟫ "เทพเจ้า" -- นามเอกพจน์: devas = ⟪देवस्⟫
**เพศชายลงท้ายด้วย -i:** เช่น kavi m. = ⟪कवि⟫ "กวี" -- นามเอกพจน์: kavis = ⟪कविस्⟫
**เพศชายลงท้ายด้วย -u:** เช่น guru m. = ⟪गुरु⟫ "อาจารย์" -- นามเอกพจน์: gurus = ⟪गुरुस्⟫
:::

## 2.4. สันธิ -- ⟪सन्धि⟫

การออกเสียงท้ายของคำในภาษาสันสกฤตยังขึ้นอยู่กับเสียงเริ่มต้นของคำถัดไป ปรากฏการณ์นี้เรียกว่า **สันธิ** (m.) = ⟪सन्धि⟫ ("การรวมกัน")

### 2.4.1. สันธิของ -s ที่ออกเสียงท้าย

ดูสรุปเพิ่มเติม:

> **Payer, Alois (1944–):** สันธิของ -s ที่ออกเสียงท้าย. -- (วัสดุสำหรับภาษาสันสกฤต). -- URL: http://www.payer.de/sanskritmaterialien/ssandhi.htm <!-- TODO: Fallback translation -->

การลงท้ายด้วย **-s**:

- **ในตำแหน่งออกเสียงสุดท้ายโดยสมบูรณ์** (สิ้นสุดประโยค) จะเปลี่ยนเป็น **Visarga (-ḥ)**:
  - **devas** = ⟪देवस्⟫ » **devaḥ** = ⟪देवः⟫
  - **kavis** = ⟪कविस्⟫ » **kaviḥ** = ⟪कविः⟫
  - **gurus** = ⟪गुरुस्⟫ » **guruḥ** = ⟪गुरुः⟫

- **ก่อนเสียงไร้เสียง**:
  - ก่อน **k, kh, p, ph** และ **ś, ṣ, s**: จะเปลี่ยนเป็น **Visarga (-ḥ)**
    - **devas + śivaḥ** » **devaḥ śivaḥ** = ⟪देवः⟫ ⟪शिवः⟫ ("Śiva เป็นเทพเจ้า")
  - ก่อน **c, ch**: จะเปลี่ยนเป็น **-ś**
  - ก่อน **ṭ, ṭh**: จะเปลี่ยนเป็น **-ṣ**
  - ก่อน **t, th**: ยังคงเป็น **-s**
    - **sādhus + caitanyas** » **sādhuś caitanyaḥ** = ⟪साधुश्चैतन्यः⟫ ("Caitanya เป็นนักบุญ")

- **ก่อนเสียงมีเสียง**:
  - หลังสระที่ไม่ใช่ a: จะเปลี่ยนเป็น **-r**
    - **kavis + Māghas** » **kavir māghaḥ** = ⟪कविर्माघः⟫ ("Māgha เป็นกวี")
  - หลังสระที่ไม่ใช่ a ก่อน **r-**: **-s** จะหายไป และสระจะยาวขึ้น
    - **gurus + rāmas** » **gurū rāmaḥ** = ⟪गुरू⟫ ⟪रामः⟫ ("Rāma เป็นครู")
  - หลัง **a-**: **-as**
    - ก่อนพยัญชนะมีเสียง/a: จะเปลี่ยนเป็น **-o** (a นำหน้าจะหายไป » ⟪ऽ⟫)
      - **devas viṣṇus** » **devo viṣṇuḥ** = ⟪देवो⟫ ⟪विष्णुः⟫
      - **devas agnis** » **devo 'gniḥ** = ⟪देवो⟫ ⟪ऽग्निः⟫
    - ก่อนสระอื่นๆ: จะเปลี่ยนเป็น **-a** (Hiatus)
      - **devas + indras** » **deva indraḥ** = ⟪देव⟫ ⟪इन्द्रः⟫

## 2.5. รายการคำศัพท์

**deva** นามบุรุษ -- ⟪देव⟫ : ผู้มีสวรรค์, เทพเจ้า; เจ้าชาย, กษัตริย์.

**īśvara** นามบุรุษ -- ⟪ईश्वर⟫ : เจ้า, ผู้ปกครอง, เทพเจ้า (แบบmonotheistic).

**brāhmaṇa** นามบุรุษ -- ⟪ब्राह्मण⟫ : พราหมณ์ (สถานะทางจิตวิญญาณ).

**kṣatriya** นามบุรุษ -- ⟪क्षत्रिय⟫ : กษัตริย์ (สถานะเจ้าชายและทหาร).

**vaiśya** นามบุรุษ -- ⟪वैश्य⟫ : ไวกษัย (สถานะเกษตรกรและพ่อค้า).

**śūdra** นามบุรุษ -- ⟪शूद्र⟫ : ศูทร (สถานะผู้ให้บริการ).

::: note-box Die vier Stände (varna)
ตามทฤษฎีคลาสสิก (เช่น Manusmṛti I, 88-91) งานถูกแบ่งดังนี้:

- **ของพราหมณ์**
  - การศึกษาพระเวท
  - การสอน
  - การบูชาเพื่อตนเอง
  - การบูชาเพื่อผู้อื่น
  - การให้
  - การรับของกำนัล
- **ของกษัตริย์**
  - ปกปวงประชาชน
  - ให้ของกำนัล (แก่พราหมณ์)
  - บูชาเพื่อตนเอง
  - การศึกษาพระเวท
- **ของไวกษัย**
  - การเลี้ยงสัตว์
  - เกษตรกรรม
  - การค้าขาย
  - การให้กู้ยืมเงิน
  - บูชาเพื่อตนเอง
  - ให้ของกำนัล (แก่พราหมณ์)
  - บูชาเพื่อตนเอง
  - การศึกษาพระเวท
- **ของศูทร**
  - รับใช้สามชั้นบน
:::
**dvija** นามบุรุษ -- ⟪द्विज⟫ : "ผู้เกิดสองครั้ง" (ผู้ที่ได้รับการเริ่มต้นในสามชั้นบน: Brāhmaṇa, Kṣatriya, Vaiśya).

**varṇa** นามบุรุษ -- ⟪वर्ण⟫ : สี, สถานะกำเนิด (ความพยายาม).

ชั้นทั้งสี่ (**varṇa** นามบุรุษ) มักถูกสับสนกับระบบวรรณะ (caste) แต่ชั้นทั้งสี่ -- ต่างจากระบบวรรณะ -- ไม่ใช่สิ่งที่เฉพาะเจาะจงของอินเดียเท่านั้น ในยุโรปเราก็มีระบบชั้นสังคม (บางส่วนจนถึงสงครามโลกครั้งที่หนึ่ง) ดังภาพประกอบจากศตวรรษที่ 15 ต่อไปนี้ยืนยัน:

**คำอธิบายภาพ:**
- **สถานะปุโรหิต** (~Brāhmaṇa): Tu supplex ora = จงอธิษฐานอย่างอ่อนน้อม!
- **สถานะขุนนาง** (~Kṣatriya): Tu protege = จงปกป้อง!
- **สถานะชาวนา** (~Vaiśya/Śūdra): Tuque labora = และจงทำงาน!

ชนชั้นทั้งสามสวมเครื่องแต่งกายตามชนชั้นของตน คริสต์เจ้าทรงสถิตเหนือชนชั้นเหล่านั้น ซึ่งถูกเรียกว่าเป็นไปตามประสงค์ของพระเจ้า

แม็กซ์ เวเบอร์ (1864–1920) นิยามคำว่า "ชนชั้น" ไว้ดังนี้:

::: note-box
»**ชนชั้น**« หมายถึงกลุ่มบุคคลจำนวนมากที่ภายในองค์กรหนึ่งๆ มีประสิทธิภาพ
a) ในการได้รับการยกย่องพิเศษตามชนชั้น — ซึ่งอาจรวมถึง
b) การอ้างสิทธิ์ในสิทธิพิเศษเฉพาะของชนชั้น

ชนชั้นสามารถเกิดขึ้นได้
a) โดยปฐมภูมิ ผ่านวิถีชีวิตตามชนชั้นของตนเอง โดยเฉพาะอย่างยิ่งผ่านลักษณะของ **อาชีพ** (**ชนชั้นที่มาจากวิถีชีวิตหรืออาชีพ**),
b) โดยทุติยภูมิ ผ่านลักษณะทางพันธุกรรมของพรสวรรค์ จากการอ้างสิทธิ์ในชื่อเสียงที่ประสบความสำเร็จโดยอาศัย **กำเนิด** ตามชนชั้น (**ชนชั้นที่เกิดมา**),
c) ผ่านการ **ยึดครอง** ตามชนชั้น ของอำนาจทางการเมืองหรืออำนาจทางศาสนาในฐานะสิทธิพิเศษ (**ชนชั้นทางการเมืองหรือทางศาสนา**)

การพัฒนาของชนชั้นที่เกิดมาโดยปกติเป็นรูปแบบหนึ่งของการยึดครองสิทธิพิเศษ (แบบสืบตระกูล) ต่อองค์กรหรือบุคคลที่มีคุณสมบัติเฉพาะ การยึดครองโอกาสอย่างถาวร โดยเฉพาะ [จาก] อำนาจของเจ้านาย หรือ **โอกาสในการประกอบอาชีพ** มีแนวโน้มที่จะนำไปสู่การก่อตัวของชนชั้น การก่อตัวตามชนชั้นใดๆ มีแนวโน้มที่จะนำไปสู่การยึดครองสิทธิพิเศษของอำนาจเจ้านายและโอกาสในการประกอบอาชีพแบบผูกขาด

ในขณะที่ชั้นทางเศรษฐกิจเติบโตขึ้นบนพื้นฐานของเศรษฐกิจที่มุ่งตลาด ชนชั้นเกิดขึ้นและดำรงอยู่โดยเฉพาะอย่างยิ่งบนพื้นฐานของการอุปถัมภ์แบบผูกขาด หรือระบบศักดินา หรือการตอบสนองความต้องการขององค์กรในรูปแบบสมบูรณาญาสิทธิราชย์ตามชนชั้น

»**ตามชนชั้น**« หมายถึงสังคมที่การจัดแบ่งทางสังคมเกิดขึ้นโดยหลักตามชนชั้น »**ตามชั้นวรรณะ**« หมายถึงสังคมที่เกิดจากการจัดแบ่งโดยหลักตามชั้นวรรณะ คำว่า "ชนชั้น" อยู่ใกล้กับ "สังคม" มากที่สุด และไกลจาก "ชั้นทางเศรษฐกิจ" มากที่สุด ชนชั้นมักถูกจัดตั้งโดยชั้นวรรณะที่มีทรัพย์สินเป็นหลัก

สังคมตามชนชั้นทุกสังคมเป็นไปตามจารีต ประเพณี โดยกฎของวิถีชีวิต จึงสร้างเงื่อนไขการบริโภคทางเศรษฐกิจที่ไร้เหตุผล และขัดขวางการพัฒนาตลาดอย่างอิสระผ่านการยึดครองสิทธิพิเศษแบบผูกขาดและการกีดกันการควบคุมเสรีต่อความสามารถในการประกอบอาชีพของตนเอง

[**เวเบอร์, แม็กซ์ (1864–1920):** เศรษฐกิจและสังคม : โครงร่างของจิตวิทยาสังคมเชิงเข้าใจ. – ฉบับแก้ไขครั้งที่ 5. – ทูบิงเงิน : โมร์, 1976. – หน้า 625 เป็นต้นไป]
:::
วรณะจึงเป็นชนชั้นที่เกิดมา

## 2.6. แบบฝึกหัด

**A) จงเติมคำโดยคำนึงถึงกฎซันทหะ และสร้างประโยคนาม:**

1. **devas ... (Śiva, Agni, Viṣṇu, Gaṇeśa, Kṛṣṇa, Indra)**
   = ⟪देवस्⟫ ... (⟪शिव⟫, ⟪अग्नि⟫, ⟪विष्णु⟫, ⟪गणेश⟫, ⟪कृष्ण⟫, ⟪इन्द्र⟫)
2. **dvijas ... (brāhmaṇa, kṣatriya, vaiśya)**
   = ⟪द्विजस्⟫ ... (⟪ब्राह्मण⟫, ⟪क्षत्रिय⟫, ⟪वैश्य⟫)
3. **gurus ... (brāhmaṇa, Candrakīrti)**
   = ⟪गुरुस्⟫ ... (⟪ब्राह्मण⟫, ⟪चन्द्रकीर्ति⟫)
4. **vaiśyas ... (Tulādhara)**
   = ⟪वैश्यस्⟫ ... (⟪तुलाधर⟫)
5. **sādhus ... (guru, Rāma)**
   = ⟪साधुस्⟫ ... (⟪गुरु⟫, ⟪राम⟫)
6. **kavis ... (Kālidāsa, Māgha, Bhāravi, Harṣadeva)**
   = ⟪कविस्⟫ ... (⟪कालिदास⟫, ⟪माघ⟫, ⟪भारवि⟫, ⟪हर्षदेव⟫)

**B) จงแปลเป็นภาษาสันสกฤต:**

1. รามะเป็นพราหมณ์
2. ครูเป็นไวศยะ
3. ศูทรเป็นผู้ศักดิ์สิทธิ์
4. กวีเป็นครู
5. วิษณุเป็นพระผู้เป็นเจ้า
6. พระผู้เป็นเจ้าคือศิวะ
7. ผู้เกิดสองครั้งเป็นพราหมณ์
8. ผู้ศักดิ์สิทธิ์เป็นครู
9. ครูเป็นผู้ศักดิ์สิทธิ์
