# แบบฝึกหัด 36

A) จงสร้างรูป Perfect ที่มีการซ้ำพยางค์ (reduplizierten) และแบบรอบนัย (periphrastischen) สำหรับรูปต่อไปนี้:

::: grammar-box
| Present | Redupliziert | Periphrastisch |
| :--- | :--- | :--- |
| ⟪१⟫. ⟪बिभ्रते⟫ | ⟪बभ्रिरे⟫ | ⟪बिभरां⟫ ⟪चक्रिरे⟫ / -⟪आसुः⟫ / -⟪बभूवुः⟫ |
| ⟪२⟫. ⟪बिभ्यति⟫ | ⟪बिभ्युः⟫ | ⟪बिभयां⟫ ⟪चक्रुः⟫ / -⟪आसुः⟫ / -⟪बभूवुः⟫ |
| ⟪३⟫. ⟪जुहोति⟫ | ⟪जुहाव⟫ | ⟪जुहवां⟫ ⟪चकार⟫ / -⟪आस⟫ / -⟪बभूव⟫ |
| ⟪४⟫. ⟪वेत्ति⟫ | ⟪विवेद⟫ | ⟪विदां⟫ ⟪चकार⟫ / -⟪आस⟫ / -⟪बभूव⟫ |
:::
B) จงสร้างรูป Perfect แบบรอบนัย (periphrastische Perfekt) สำหรับรากศัพท์ ⟪आस्⟫ (นั่ง):

::: grammar-box
| Present | Periphrastisches Perfekt |
| :--- | :--- |
| ⟪१⟫. ⟪आस्ते⟫ | ⟪आसां⟫ ⟪चक⟫re / -⟪आस⟫ / -⟪बभूव⟫ |
| ⟪२⟫. ⟪आसते⟫ | ⟪आसां⟫ ⟪चक्रिरे⟫ / -⟪आसुः⟫ / -⟪बभूवुः⟫ |
:::

## คำแปล

⟪१⟫. **⟪पुत्रे⟫ ⟪जाते⟫ ⟪सुगतः⟫ ⟪कुलं⟫ ⟪धनं⟫ ⟪च⟫ ⟪तत्याजागाराच्चानगर्यं⟫ ⟪प्रवव्राज⟫ ⟪।⟫ ⟪बुद्ध्यार्यसत्यानि⟫ ⟪प्रज्ञाय⟫ ⟪प्रज्ञया⟫ ⟪च⟫ ⟪दुःखान्मुक्तो⟫ ⟪मोक्तुकामार्यजनान्बोधयामासेति⟫ ⟪भिक्षव⟫ ⟪आहुः⟫ ⟪॥१॥⟫**
เมื่อเขาได้บุตรชายมา พระพุทธเจ้าทรงละครอบครัวและทรัพย์สิน แล้วออกบวชจากเรือนสู่ความเป็นอนาคาริก ทรงรู้แจ้งอริยสัจด้วยปัญญา ทรงหลุดพ้นจากความทุกข์โดยรู้เท่าทัน และนำพามุนีผู้ปรารถนาโมกขะให้ถึงความเห็นแจ้ง — คัมภีร์พระไตรปิฎกกล่าวไว้ดังนี้

⟪२⟫. **⟪ब्राह्मणा⟫ ⟪महादेवयज्ञायाग्निं⟫ ⟪चिक्यिरे⟫ ⟪।⟫ ⟪ब्राह्मणेष्विन्द्रादिदेवान्स्तुवत्स्वग्निर्यज्ञान्नमाश⟫ ⟪।⟫ ⟪एवं⟫ ⟪यज्ञ⟫en ⟪ब्राह्मणा⟫ ⟪महादेवैरादयां⟫ ⟪चक्रुस्तांश्च⟫ ⟪स्तोत्रानि⟫ ⟪श्रावयां⟫ ⟪बभूवुः⟫ ⟪॥२॥⟫**
พราหมณ์ทั้งหลายได้ก่อไฟสำหรับพิธีบูชาเทพเจ้าที่ยิ่งใหญ่ขึ้น เมื่อพราหมณ์สรรเสริญอินทระและเทวดาอื่น ๆ ไฟบูชาได้เผาผลาญอาหารไป ดังนั้นพราหมณ์จึงทำให้เทพเจ้าใหญ่กินอาหารผ่านพิธีบูชา และให้พวกเขาได้ยินบทสรรเสริญ

⟪३⟫. **⟪रक्षितधर्मक्षत्रिययोधा⟫ ⟪महानगरं⟫ ⟪जेतुकामाञ्छत्रून्विजिग्युर्न⟫ ⟪तु⟫ ⟪जघ्नुः⟫ ⟪॥३॥⟫**
ขัตติยราชนักรบผู้พิทักษ์ธรรมะได้ชนะศัตรูที่ต้องการยึดครองเมืองใหญ่ แต่ไม่ได้สังหารพวกเขา

⟪४⟫. **⟪अधीतवेदद्विजो⟫ ⟪द्विजधर्मं⟫ ⟪वेद⟫ ⟪॥४॥⟫**
ผู้เกิดสองครั้งผู้ศึกษาพระเวท รู้จักธรรมะและจารีตของผู้เกิดสองครั้ง

⟪५⟫. **⟪विद्ययैव⟫ ⟪जीवितुं⟫ ⟪न⟫ ⟪शक्यते⟫ ⟪।⟫ ⟪य⟫ ⟪एवं⟫ ⟪विदुर्नाधीयीरन्⟫ ⟪॥५॥⟫**
ไม่สามารถดำรงชีวิตได้ด้วยวิชาเพียงอย่างเดียว ผู้ที่รู้เช่นนี้ไม่ควรศึกษา

## เอกสารทางวิชาการ

### ⟪१⟫. **⟪महाभारत⟫ ⟪१३⟫.⟪७⟫.⟪२५⟫-⟪२६⟫**
**⟪येन⟫ ⟪प्रीणति⟫ ⟪पितरं⟫ ⟪तेन⟫ ⟪प्रीतः⟫ ⟪प्रजापतिः⟫ ⟪।⟫**  
**⟪प्रीणति⟫ ⟪मातरं⟫ ⟪येन⟫ ⟪पृथिवी⟫ ⟪तेन⟫ ⟪पूजिता⟫ ⟪॥⟫**  
**⟪येन⟫ ⟪प्रीणात्युपाध्यायं⟫ ⟪तेन⟫ ⟪स्याद्ब्रह्म⟫ ⟪पूजितम्⟫ ⟪।⟫**  
**⟪सर्वे⟫ ⟪तस्यादृता⟫ ⟪धर्मा⟫ ⟪यस्यैते⟫ ⟪त्रय⟫ ⟪आदृताः⟫ ⟪।⟫**  
**⟪अनादृतास्तु⟫ ⟪यस्यैते⟫ ⟪सर्वास्तस्याफलाः⟫ ⟪क्रियाः⟫ ⟪॥⟫**  
สิ่งที่ทำให้บิดาของท่านชื่นใจ สิ่งนั้นจะทำให้ผู้สร้างโลกชื่นใจ; สิ่งที่ทำให้มารดาของท่านชื่นใจ สิ่งนั้นจะได้รับการเคารพจากพื้นดิน; สิ่งที่ทำให้อาจารย์ของท่านชื่นใจ สิ่งนั้นจะได้รับการเคารพจากพระเวท ผู้ที่ให้ความสำคัญกับสิ่งเหล่านี้สามประการ ย่อมให้ความสำคัญกับกฎเกณฑ์ทั้งหมด; ผู้ที่ไม่ให้ความสำคัญกับสิ่งเหล่านี้ การกระทำของเขาย่อมไร้ผล

### ⟪२⟫. **⟪मनुस्मृति⟫ ⟪४⟫.⟪१५४⟫** (พฤติกรรมต่อผู้สูงอายุ)
**⟪अभिवादयेद्वृद्धांश्च⟫ ⟪दद्याच्चैवासनं⟫ ⟪स्वकम्⟫ ⟪।⟫**  
**⟪कृताञ्जलिरुपासीत⟫ ⟪गच्छतः⟫ ⟪पृष्ठतो⟫ ⟪ऽन्वियात्⟫ ⟪॥⟫**  
จงทักทายผู้สูงอายุตามแบบแผน มอบที่นั่งของตนให้พวกเขา และยืนต่อหน้าพวกเขาด้วยมือประสานกัน เมื่อผู้สูงอายุลับไป จงติดตามเขา

### ⟪३⟫. **⟪मनुस्मृति⟫ ⟪२⟫.⟪९८⟫** (การควบคุมอินทรีย์)
**⟪श्रुत्वा⟫ ⟪स्पृष्ट्वा⟫ ⟪च⟫ ⟪दृष्ट्वा⟫ ⟪च⟫ ⟪भुक्त्वा⟫ ⟪घ्रात्वा⟫ ⟪च⟫ ⟪यो⟫ ⟪नरः⟫ ⟪।⟫**  
**⟪न⟫ ⟪हृष्यति⟫ ⟪ग्लायति⟫ ⟪वा⟫ ⟪स⟫ ⟪विज्ञेयो⟫ ⟪जितेन्द्रियः⟫ ⟪॥⟫**  
เมื่อชายผู้ใดไม่ยินดีและไม่เศร้าโศก ไม่ว่าเขาจะได้ยิน ได้สัมผัส เห็น ลิ้มรส หรือดมกลิ่น เขาถูกเรียกว่าผู้ที่มีอินทรีย์อยู่ใต้บังคับ (⟪जितेन्द्रियः⟫)
