# บทที่ 30

## 30.1. ชั้นปัจจุบันกาลที่ 9 (⟪क्र्यादि⟫ = "⟪क्री⟫ ฯลฯ")

::: grammar-box
**การสร้าง:**

*   รากที่แข็งแรง: ศัพท์รากเสียงต่ำ + -nā-

*   รากที่อ่อนแอ:

    *   ก่อนพยัญชนะ: ศัพท์รากเสียงต่ำ + -nī-

    *   ก่อนสระ: ศัพท์รากเสียงต่ำ + -n-
:::
ตัวอย่าง:

::: indent
⟪क्री⟫ 9U "ซื้อ"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **บุคคลที่ 3:brปารัสไมปะทะ** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **บุคคลที่ 3:brอาตมันปะทะ** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
ในชั้นปัจจุบันกาลนี้ ควรสังเกตการสร้างรากปัจจุบันจากศัพท์ราก ⟪ज्ञा⟫ 9U "รู้, รู้จัก":

::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **บุคคลที่ 3:brปารัสไมปะทะ** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **บุคคลที่ 3:brอาตมันปะทะ** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
รูป ⟪जा⟫ ซึ่งอยู่เบื้องหลังรากปัจจุบันของ ⟪ज्ञा⟫ สามารถอธิบายได้โดยอนุกรมอับลาถะ -ā (เสียงต่ำ) -nā (เสียงสูง) หรือโดยการลดรูปจาก *jñā-nā-ti

ศัพท์รากบางตัวที่มีสระยาวจะลดความยาวของสระนั้นก่อนคำลงท้ายรากปัจจุบันกาลชั้นที่ 9:

ตัวอย่าง:

::: indent
⟪पू⟫ 9U "ชำระให้บริสุทธิ์"
:::

| **บุคคลที่ 3:brอาตมันปะทะ** | ⟪पुनीते⟫:br(pu-nī-te) | ⟪पुनते⟫:br(pu-n-ate) |

## 30.5. สันธะของ -r ที่ออกท้าย

::: grammar-box
**ยกเว้น -ar กฎสันธะสำหรับ -r ที่ออกท้ายนั้นเหมือนกับกฎสำหรับ -s ที่ออกท้าย**

**-ar ก่อนเสียงวรรคจะคงเป็น -ar แต่ก่อน r- จะตัด -r ออก และเปลี่ยน -a- เป็น -ā-**
:::
ตัวอย่าง:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
