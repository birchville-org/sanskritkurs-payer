# บทที่ 57

## 57.1. ออริสต์ที่ 4: s-ออริสต์

::: grammar-box
**s-ออริสต์ถูกสร้างกับรากศัพท์ ⟪अनिट्⟫ ส่วนใหญ่ เว้นแต่รากเหล่านั้นจะมีรูปออริสต์อื่นเฉพาะเท่านั้น รากศัพท์ ⟪अनिट्⟫ ที่เลือกได้โดยทั่วไปสามารถสร้าง s-ออริสต์หรือ iṣ-ออริสต์ได้อย่างใดอย่างหนึ่ง นอกจากนี้ รากศัพท์ ⟪अनिट्⟫ ที่สร้างรูป ⟪परस्मैपद⟫ หลังจากรูปที่ 1, 2 หรือ 6 ของออริสต์ ยังสร้างรูป ⟪आत्मनेपद⟫ ตามรูปแบบ s-ออริสต์ด้วย**

**การสร้าง: ออเกเมนต์ + รากศัพท์ + s + วิภัตติทุติยภาคแบบไม่มีสระ**
:::
ตารางวิภัตติพร้อมส่วนเติมเต็มการสร้างรากศัพท์

::: grammar-box

|   | ⟪परस्मैपदम्⟩ || ⟪आत्मनेपदम्⟩ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟩ | ⟪बहुवचनम्⟩ | ⟪एकवचनम्⟩ | ⟪बहुवचनम्⟩ |
| **1. ⟪तृतीयः⟩** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟩** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟩** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**กฎการออกเสียงทั่วไปถูกนำมาใช้ว่า เสียงเสียดสีจะหายไประหว่างสองเสียงปิด (เทียบ ⟪उद्⟩ + ⟪स्थित⟩ » ⟪उत्थित⟩) นั่นคือ ส่วนเติมเต็มการสร้างรากศัพท์ -s- จะหายไปก่อนวิภัตติที่ขึ้นต้นด้วย -t- หรือ -th- (แต่ไม่หลังจากเสียงจมูกหรือ r-)**

ตัวอย่าง:

:::
::: indent
3.sg.Ā a-kṣip + s + ta » ⟪अ⟩:sig[⟪क्षिप्त⟩]
2.sg.Ā a-kṣip + s + thās » ⟪अ⟩:sig[⟪क्षिप्था⟩]⟪स्⟩
:::
รูปเหล่านี้สามารถจัดอยู่ในกลุ่มรากออริสต์ได้ และน่าจะมีบางส่วนที่แท้จริงแล้วเป็นของรากออริสต์
นักไวยากรณ์อินเดียได้จัดรูปเช่น ⟪अकृत⟩ (3.sg.Ā) ไว้ใน s-ออริสต์ ทั้งที่แท้จริงแล้วเป็นของรากออริสต์ เพื่อวัตถุประสงค์นี้ นักไวยากรณ์อินเดียได้ประดิษฐ์กฎการออกเสียงเฉพาะหน้าสำหรับ s-ออริสต์ดังนี้:

::: indent
"หลังจากสระสั้นแล้ว ท้ายคำที่ขึ้นต้นด้วย -st- หรือ -sth- จะสูญเสีย -s-"
:::
นอกจากนี้ ต้องระวังกฎเสียงสำหรับการเชื่อมต่อพยัญชนะท้ายคำกับ s-

สำหรับ -dhvam ให้ใช้กฎดังนี้:

::: grammar-box
**-dh- ของ -dhvam จะถูกแทนที่ด้วย -ḍh- หลังจากสระทุกชนิดที่ไม่ใช่ a/ā และหลังจาก -r**

:::
::: indent
เช่น :sig[⟪चि⟫] 5U: 2.pl.Ā :sig[⟪अचेढ्वम्⟫]
:::
::: grammar-box
**รูปของรากศัพท์:**

*   **⟪परस्मैपद⟫ : ระดับขยาย**
*   **⟪आत्मनेपद⟫ :**
*   **รากศัพท์ที่มี i/ī/u/ū ท้าย: ระดับสูง**
*   **-ṝ ที่ท้ายจะถูกแทนที่ด้วย -īr หรือ -ūr**
*   **รากศัพท์ที่สามารถเปลี่ยนสระได้ ซึ่งลงท้ายด้วย ā/e/o: ระดับต่ำ**
*   **สระรากอื่นๆ: ไม่เปลี่ยนแปลง (โดยทั่วไปคือระดับต่ำ)**
:::

**รูปที่ไม่เป็นไปตามกฎเกณฑ์:**

**1. รากศัพท์ที่มีสระนาสิก (⟪गम्⟫, ⟪मन्⟫, ⟪रम्⟫) สร้างรูป aorist แบบ s-Aorist ระดับสูง:**
**⟪अगंसि । अमंसि । अरंस्त⟫**
**นอกจากนี้ สำหรับ ⟪गम्⟫ ยังมีรูประดับต่ำที่เป็นไปตามกฎเกณฑ์:**
**⟪अगसि⟫ (« \*a-gm-si) ⟪। अगथास् । अगत⟫ (ใน P มี ⟪गम्⟫ เป็น aorist แบบมีสระธีม)**

2. ⟪पद्⟫ 4Ā เป็นรูปแบบมาตรฐาน (เช่น ⟪अपत्सि⟫) แต่ในรูป 3.sg.Ā จะใช้รูปแบบของรากกริยาออร์ิสต์แบบพาสซีฟ:
⟪अपादि⟫ "เขาเดิน"

3. ⟪बुध्⟫ Ā สามารถเลือกใช้รูปแบบของรากกริยาออร์ิสต์แบบพาสซีฟในรูป 3.sg.Ā ได้:
⟪अबोधि⟫ / ⟪अबुद्ध⟫ "เขารู้จัก"
