# บทที่ 57

## 57.1. ออริสต์ที่ 4: s-ออริสต์

::: grammar-box
**s-ออริสต์ถูกสร้างกับรากศัพท์ ⟪अनिट्⟩ เกือบทั้งหมด เว้นแต่จะมีรูปออริสต์อื่นเฉพาะเจาะจง รากศัพท์ ⟪अनिट्⟩ ที่เลือกได้โดยทั่วไปสามารถสร้างรูปนี้หรือ iṣ-ออริสต์ได้อย่างใดอย่างหนึ่ง รากศัพท์ ⟪अनिट्⟩ ที่สร้างรูป ⟪परस्मैपद⟩ ตามรูปแบบที่ 1, 2 หรือ 6 ของออริสต์ ก็สร้างรูป ⟪आत्मनेपद⟩ ตาม s-ออริสต์เช่นกัน**

**การสร้าง: ออเกอมেন্ট + รากศัพท์ + s + การลงท้ายแบบอะเธมัติก**
:::
ตารางการลงท้ายพร้อมคำต่อท้ายการสร้างรากศัพท์

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟫** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟫** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**ใช้กฎเสียงทั่วไปที่ว่า เสียงเสียดสี (sibilant) ระหว่างเสียงปิดกั้น (stop) สองตัวจะหายไป (เทียบ ⟪उद्⟩ + ⟪स्थित⟩ » ⟪उत्थित⟩) นั่นคือ คำต่อท้ายการสร้างรากศัพท์ -s- หายไปก่อนการลงท้ายที่ขึ้นต้นด้วย -t- หรือ -th- (แต่ไม่หายไปหลังเสียงจมูกรากศัพท์หรือ r-)**

ตัวอย่าง:

:::
::: indent
3.sg.Ā a-kṣip + s + ta » ⟪अ⟩:sig[⟪क्षिप्त⟩]
2.sg.Ā a-kṣip + s + thās » ⟪अ⟩:sig[⟪क्षिप्था⟩]⟪स्⟩
:::
รูปเหล่านี้สามารถจัดอยู่ในกลุ่มรากศัพท์ออริสต์ได้ และน่าจะบางส่วนก็อยู่จริงในกลุ่มนั้น
นักไวยากรณ์อินเดียยังนับรูปเช่น ⟪अकृत⟩ (3.sg.Ā) เข้าใน s-ออริสต์ ทั้งที่ชัดเจนว่าอยู่ในกลุ่มรากศัพท์ออริสต์ เพื่อจุดประสงค์นี้ นักไวยากรณ์อินเดียได้ประดิษฐ์กฎเสียงเฉพาะกิจสำหรับ s-ออริสต์ดังนี้:

::: indent
"หลังสระสั้น การลงท้ายที่ขึ้นต้นด้วย -st- หรือ -sth- จะสูญเสีย -s-"
:::
นอกเหนือจากนี้ ต้องระวังกฎเสียงสำหรับการเชื่อมต่อพยัญชนะท้ายคำกับ s-

สำหรับ -dhvm มีกฎดังนี้:

::: grammar-box
**-dh- ของ -dhvm จะถูกแทนที่ด้วย -ḍh- หลังสระที่ไม่ใช่ a/ā ทั้งหมด และหลัง -r**

:::
::: indent
เช่น :sig[⟪चि⟩] 5U: 2.pl.Ā :sig[⟪अचेढ्वम्⟩]
:::
::: grammar-box
**รูปของรากศัพท์:**

*   **⟪परस्मैपद⟩ : ระดับขยายเสียง**
*   **⟪आत्मनेपद⟫ :**
    *   **รากศัพท์ที่มี i/ī/u/ū ท้าย: ระดับสูง**
    *   **-ṝ ที่ท้ายจะถูกแทนที่ด้วย -īr หรือ -ūr**
    *   **รากศัพท์ที่มีการเปลี่ยนสระ (ablaut) ได้ บน ā/e/o: ระดับต่ำ**
    *   **สระรากศัพท์อื่นๆ: ไม่เปลี่ยนแปลง (โดยทั่วไปคือระดับต่ำ)**
:::

**⟪दृश्⟩ และ ⟪सृज्⟩ มีระดับขยายเสียงใน ⟪परस्मैपद⟩ พร้อมไดฟธองต์เพิ่มขึ้น -rā-:**

:::

**รูปผิดปกติ:**

**1.  รากศัพท์ที่มี Nasal (⟪गम्⟫, ⟪मन्⟫, ⟪रम्⟫) สร้าง s-aorist แบบสูง:**
**⟪अगंसि⟫ ⟪।⟫ ⟪अमंसि⟫ ⟪।⟫ ⟪अरंस्त⟫**
**นอกจากนี้ยังมีรูปต่ำระดับปกติสำหรับ ⟪गम्⟫:**
**⟪अगसि⟫ (« \*a-gm-si) ⟪।⟫ ⟪अगथास्⟫ ⟪।⟫ ⟪अगत⟫ (ใน P มี ⟪गम्⟫ เป็น aorist แบบ thematic vowel)**

2.  ⟪पद्⟫ 4Ā เป็นปกติ (เช่น ⟪अपत्सि⟫) แต่ใน 3.sg.ġ มีรูปของ aorist รากศัพท์แบบ passive:
⟪अपादि⟫ "เขาไป"

3.  ⟪बुध्⟫ Ā สามารถเลือกมีรูปของ aorist รากศัพท์แบบ passive ใน 3.sg.ġ:
⟪अबोधि⟫ / ⟪अबुद्ध⟫ "เขารู้"
:::
