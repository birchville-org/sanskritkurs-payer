# แบบฝึกหัด 12

A) จงสร้างประโยคกัมมวาจกาในกาลอดีต จากประโยคกระตุกวาจาของ [บทที่ 7](lektion07.md) แบบฝึกหัด A สำหรับกริยาอกรรมกิริยากับกริยาสัมพันธภาพ จงสร้างประโยคกระตุกวาจาในกาลอดีต

⟪१⟫. ⟪ब्राह्मणेन⟫ ⟪देव⟫ ⟪इष्टः⟫ ⟪।⟫ ⟪देवीष्टा⟫ ⟪।⟫ ⟪विष्णुरिष्टः⟫ ⟪।⟫ ⟪ब्राह्मणेनाग्निरिष्टः⟫ ⟪।⟫ ⟪देवतेष्टा⟫ ⟪।⟫

⟪२⟫. guruṇā phalaṃ khāditam.
⟪गुरुणा⟫ ⟪फलं⟫ ⟪खादितम्⟫ ⟪।⟫

⟪३⟫. sādhuḥ svargaṃ gataḥ.
⟪साधुः⟫ ⟪स्वर्गं⟫ ⟪गतः⟫ ⟪।⟫

⟪४⟫. śūdrā narakaṃ gatā.
⟪शूद्रा⟫ ⟪नरकं⟫ ⟪गता⟫ ⟪।⟫

⟪५⟫. śūdro jitaḥ ⟪॥⟫
⟪शूद्रो⟫ ⟪जितः⟫ ⟪॥⟫

B) จงสร้างรูป Past Participle (PPP) ที่สอดคล้องกับรูปแบบกริยาจาก [บทที่ 10](lektion10.md) แบบฝึกหัด A โปรดสังเกตว่ารูปแบบเช่น sṛjati มี PPP ที่สอดคล้องกันในทั้งสามเพศ

1. sṛjati ⟪सृजति⟫ : ⟪सृष्टः⟫ ⟪३⟫ (⟪सृष्टः⟫ ⟪।⟫ ⟪सृष्टा⟫ ⟪।⟫ ⟪सृष्टम्⟫)
2. yudhyate ⟪युध्यते⟫ : ⟪युद्धः⟫ ⟪३⟫
3. bhavanti ⟪भवन्ति⟫ : ⟪भूताः⟫ ⟪३⟫ (⟪भूताः⟫ ⟪।⟫ ⟪भूताः⟫ ⟪।⟫ ⟪भूतानि⟫)
4. yajati ⟪यजति⟫ : ⟪इष्टः⟫ ⟪३⟫
5. nṛtyati ⟪नृत्यति⟫ : ⟪नृत्तः⟫ ⟪३⟫
6. nayanti ⟪नयन्ति⟫ : ⟪नीताः⟫ ⟪३⟫
7. smarati ⟪स्मरति⟫ : ⟪स्मृतः⟫ ⟪३⟫
8. śṛṇvanti ⟪शृण्वन्ति⟫ : ⟪श्रुताः⟫ ⟪३⟫
9. pāśyati ⟪पश्यति⟫ (กัมมวาจาสร้างจาก dṛś!) : ⟪दृष्टः⟫ ⟪३⟫
10. jayanti ⟪जयन्ति⟫ : ⟪जिताः⟫ ⟪३⟫
11. kurvate ⟪कुर्वते⟫ : ⟪कृताः⟫ ⟪३⟫
12. āpnuvanti ⟪आप्नुवन्ति⟫ : ⟪आप्ताः⟫ ⟪३⟫
13. viśati ⟪विशति⟫ : ⟪विष्टः⟫ ⟪३⟫
14. khādanti ⟪खादन्ति⟫ : ⟪खादिताः⟫ ⟪३⟫
15. sunoti ⟪सुनोति⟫ : ⟪सुतः⟫ ⟪३⟫
16. gacchati ⟪गच्छति⟫ : ⟪गतः⟫ ⟪३⟫
17. manyante ⟪मन्यन्ते⟫ : ⟪मताः⟫ ⟪३⟫
18. labhante ⟪लभन्ते⟫ : ⟪लब्धाः⟫ ⟪३⟫
19. rakṣanti ⟪रक्षन्ति⟫ : ⟪रक्षिताः⟫ ⟪३⟫
20. vadanti ⟪वदन्ति⟫ : ⟪उदिताः⟫ ⟪३⟫
21. pṛcchanti ⟪पृच्छन्ति⟫ : ⟪पृष्टाः⟫ ⟪३⟫
22. tanvanti ⟪तन्वन्ति⟫ : ⟪तताः⟫ ⟪३⟫

C) จงแปลงประโยคจาก [บทที่ 10](lektion10.md) แบบฝึกหัด C เป็นกัมมวาจาในกาลอดีต

1\. brāhmaṇo devīm yajati. ⟪ब्राह्मणो⟫ ⟪देवीं⟫ ⟪यजति⟫
⟪ब्रामणेन⟫ ⟪देवीष्टा⟫ ⟪।⟫

2\. sādhuḥ svargaṃ gacchati. ⟪साधुः⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫
⟪साधुः⟫ ⟪स्वर्गं⟫ ⟪गतः⟫ ⟪।⟫

3\. śūdraṃ jayati. ⟪शूद्रं⟫ ⟪जय⟫ti
⟪शूद्रो⟫ ⟪जितः⟫ ⟪।⟫

4\. guruḥ phalāni khādati. ⟪गुरुः⟫ ⟪फलानि⟫ ⟪खादति⟫
⟪गुरुणा⟫ ⟪फलानि⟫ ⟪खादितानि⟫ ⟪।⟫

5\. gurūñchṛṇoti. ⟪गुरूञ्छृणोति⟫
⟪ग्रुरवः⟫ ⟪श्रुताः⟫ ⟪।⟫

6\. ko 'gniṃ paśyati. ⟪को⟫ ⟪ऽग्निं⟫ ⟪पश्यति⟫
⟪केनाग्निर्दृष्टः⟫ ⟪।⟫

7\. ayaṃ kavirmantraṃ smarati. ⟪अयं⟫ ⟪कविर्मन्त्रं⟫ ⟪स्मरति⟫
⟪अनेन⟫ ⟪कविना⟫ ⟪मन्त्रः⟫ ⟪स्मृतः⟫ ⟪।⟫

8\. iyaṃ devī kṣatriyā rakṣati. ⟪इयं⟫ ⟪देवी⟫ ⟪क्त्रिया⟫ ⟪रक्षति⟫
⟪अनया⟫ ⟪देव्या⟫ ⟪क्षत्रिया⟫ ⟪रक्षिताः⟫ ⟪।⟫

9\. kṣatriyā viṣṇuṃ yajante. ⟪क्षत्रिया⟫ ⟪विष्णुं⟫ ⟪यजन्ते⟫ (มี 2 วิธี)
⟪क्षत्रियैर्विष्णुरिष्टः⟫ ⟪।⟫ ⟪क्षत्रियाभिर्विष्णुरिष्टः⟫ ⟪।⟫

10\. brāhmaṇo 'gniṃ karoti. ⟪ब्राह्मणो⟫ ⟪ऽग्निं⟫ ⟪करोति⟫
⟪ब्राह्मणेनाग्निः⟫ ⟪कृतः⟫ ⟪।⟫

11\. vaiśyā imaṃ grāmaṃ gacchanti. ⟪वैश्या⟫ ⟪इमं⟫ ⟪ग्रामं⟫ ⟪गच्छन्ति⟫
⟪वैश्या⟫ ⟪इमं⟫ ⟪ग्रामं⟫ ⟪गताः⟫ ⟪।⟫

12\. ete gurūṃstu śṛṇvanti. ⟪एते⟫ ⟪गुरूंस्तु⟫ ⟪शृण्वन्ति⟫
⟪एतैर्गुरवस्तु⟫ ⟪श्रुताः⟫ ⟪।⟫

13\. sādhuḥ svargamāpnoti. ⟪साधुः⟫ ⟪स्वर्गमाप्नोति⟫
⟪साधुना⟫ ⟪स्वर्ग⟫ ⟪आप्ताः⟫ ⟪।⟫

14\. brāhmāṇāḥ somaṃ sunvanti. ⟪ब्राह्मणाः⟫ ⟪सोमं⟫ ⟪सुन्वन्ति⟫
⟪ब्राह्मणैः⟫ ⟪सोमः⟫ ⟪सुतः⟫ ⟪।⟫

15\. paśūṃllabhate. ⟪पशूल्ंलभते⟫
⟪पशवो⟫ ⟪लब्धाः⟫ ⟪।⟫


16. นักสู้ต่อสู้ร่วมกับกษัตริย์ ⟪के⟫ ⟪योधाः⟫ ⟪क्षत्रियैः⟫ ⟪सह⟫ ⟪युध्यन्ते⟫
⟪कैर्योधैः⟫ ⟪क्षत्रियैः⟫ ⟪सह⟫ ⟪युद्धम्⟫ ⟪।⟫
