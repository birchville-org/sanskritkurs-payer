# บทที่ 42

## 42.1. กลุ่มคำศัพท์ลงท้ายด้วย -ṛ

### 42.1.1. กลุ่มคำศัพท์ที่มีระดับเสียงยาว (Guna) ในรูปกร่อนแข็ง

::: grammar-box
คำนามเพศผู้ทั้งหมดที่ลงท้ายด้วย -ṛ ยกเว้นคำเรียกความสัมพันธ์ในครอบครัวที่ได้กล่าวไว้ในข้อ 1.3. นอกจากนี้ ยังรวมถึงคำเรียกความสัมพันธ์ในครอบครัวต่อไปนี้:

*   ⟪नप्तृ⟫ เพศผู้ "หลาน"
*   ⟪भर्तृ⟫ เพศผู้ "สามี (ตามตัวอักษร: ผู้สนับสนุน)"

ส่วนใหญ่ของคำนามในกลุ่มนี้คือ คำนามผู้กระทำ (Nomina agentis) ที่ใช้后缀 ⟪कृत्⟫ -⟪तृ⟌

**การสร้าง:**

*   **รูปกร่อนแข็ง: -ār**
*   **รูปอ่อน (Weak stem)**
*   **ก่อนสระ: -r**
*   ก่อนพยัญชนะ: -ṛ

โปรดสังเกตการสร้างที่ผิดปกติ (ทำเครื่องหมายด้วย **สีแดง**)!
:::
คำนามเพศผู้:

::: indent
⟪दातृ⟫ เพศผู้ "ผู้อุปถัมภ์"
:::

:::
### 42.1.2. การสร้างคำนาม:后缀 ⟪कृत्⟌ -⟪तृ⟫

::: grammar-box
ด้วย后缀ที่พบบ่อยมาก ⟪कृत्⟌ -⟪तृ⟫ สามารถสร้างคำนามผู้กระทำ (คำเรียกสำหรับ ⟪कर्तृ⟌) จากรากศัพท์เกือบทุกชนิด หรือรูป causative ได้

**การสร้าง:**

*   **รากศัพท์ระดับสูง (Vrddhi) + -tṛ**

หรือ

*   **รากศัพท์ระดับสูง / รูป causative + i + tṛ**
:::
ตัวอย่าง:

::: indent
⟪कर्तृ⟌ เพศผู้ "ผู้กระทำ"

⟪जेतृ⟌ เพศผู้ "ผู้ชนะ"

⟪धातृ⟌ เพศผู้ "ผู้สร้าง"

⟪रक्षितृ⟌ เพศผู้ "ผู้ปกป้อง"

⟪बोधयितृ⟌ เพศผู้ "ปลุก"
:::
::: media
![lekt4201.jpg](/images/lekt4201.jpg)
ภาพ: ⟪अयं⟌ ⟪बोधयिता⟫
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt4201))
:::

::: grammar-box
คำนามกลางที่ลงท้ายด้วย -⟪तृ⟌ ซึ่งพบได้น้อย มีรูปแบบการผันคำที่แตกต่างออกไปบางส่วน (ดู Kielhorn, ไวยากรณ์ § 148)

คำนามเพศหญิงที่เกิดจากกลุ่มคำศัพท์ที่ลงท้ายด้วย -⟪तृ⟌ จะลงท้ายด้วย **-⟪त्री⟌** (เช่น ⟪देवी⟫)

ตัวอย่าง เช่น ⟪कर्त्री⟌ เพศหญิง "ผู้กระทำ (ผู้หญิง)"
:::
### 42.1.3. กลุ่มคำศัพท์ที่มีระดับเสียงสูง (Vrddhi) ในรูปกร่อนแข็ง

::: grammar-box
ซึ่งรวมถึงคำเรียกความสัมพันธ์ในครอบครัวต่อไปนี้:

*   ⟪पितृ⟌ เพศผู้ "บิดา"
*   ⟪मातृ⟌ เพศหญิง "มารดา"
*   ⟪दुहितृ⟌ เพศหญิง "ธิดา"
*   ⟪भ्रातृ⟌ เพศผู้ "พี่ชาย"
*   ⟪देवृ⟌ เพศผู้ "พี่ชายของสามี (น้องเขย)"
*   ⟪यातृ⟌ เพศหญิง "ภรรยาของพี่ชายของสามี"
*   ⟪ननान्दृ⟌ เพศหญิง "พี่สาวของสามี (น้องสะใภ้)"

**การสร้าง:**

*   **รูปกร่อนแข็ง: -ar**
*   **รูปแบบอ่อน (Weak stem)**
*   ก่อนสระ: -r
*   ก่อนพยัญชนะ: -ṛ
:::
ตัวอย่าง:

::: indent
⟪पितृ⟌ เพศผู้ "บิดา"

⟪मातृ⟌ เพศหญิง "มารดา"
:::

| ⟪द्वितीया⟌ | sig[⟪पितरम्⟫] | ⟪पितॄन्⟌ | sig[⟪मातरम्⟫] | ⟪मातॄस्⟌

### 42.1.4. ชนกลุ่มที่มี -ṛ ในคำประสม

::: grammar-box
ในฐานะส่วนหน้าของคำประสม คำนามที่มี -ṛ ย่อมอยู่ในรูปรากอ่อนของตน กล่าวคือ

*   **ก่อนพยัญชนะ: -ṛ**
*   **ก่อนสระ: -r**
:::
