# บทที่ 10

::: deleteme-box
**ในบทนี้ท่านจะได้เรียนรู้:**
- ประโยคแบบพาสซีฟ (Instrumentalis ของผู้กระทำ)
- การผันคำของ Instrumentalis (tṛtīyā)
- กฎการเปลี่ยนเป็นเสียงในช่องปากสำหรับ -n- (Wortsandhi)
- การสร้างรูปพาสซีฟ (yak) ใน Indikativ ปัจจุบัน
- ศัพท์เกี่ยวกับพิธีบูชา ความจริง และบทบาททางสังคม
:::
## 10.1. ประโยคแบบพาสซีฟ

::: grammar-box
**แผนผัง:**
**(ผู้กระทำ - kartṛ - ใน Instrumentalis (tṛtīyā)) - (กรรมตรง - karman - ใน Nominative) - รูปกริยาพาสซีฟ**

เช่น **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन⟫ ⟪देव⟫ ⟪इज्यते⟫ = "พราหมณ์คนหนึ่งบูชเทพด้วยพิธีบูชา" (ความหมายตรงตัว: "เทวดาหนึ่งถูกพราหมณ์คนหนึ่งบูชด้วยพิธีบูชา")

ประโยคนี้มีความหมาย **เหมือนกันโดยสิ้นเชิง (!)** กับประโยค:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो⟫ ⟪देवं⟫ ⟪यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
- ในประโยคพาสซีฟ ผู้กระทำ (**kartṛ**) อยู่ในรูป **Instrumentalis** (tṛtīyā f. "กรณีคำที่สาม") และกรรมตรง (**karman** n.) อยู่ในรูป **Nominative** (prathamā f.).
- ประโยคพาสซีฟที่ไม่ระบุผู้กระทำ มักมีความหมายแบบไม่มีประธาน ("ใครสักคน"):
เช่น **ijyate** = ⟪इज्यते⟫ "มีการบูชา" (ความหมายตรงตัว: "มันถูกบูชด้วยพิธีบูชา")
:::

::: grammar-box
**แม้ว่าประโยคกิริยาที่สอดคล้องกันจะมีกรรมตรง (dvitīyā) ของเป้าหมาย คำนั้นก็สามารถอยู่ในรูป Nominative (prathamā) ในประโยคพาสซีฟได้:**

ประโยคกิริยา **rāmo grāmaṃ gacchati** = ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "รามะไปยังหมู่บ้าน" สอดคล้องกับประโยคพาสซีฟ:
- **rāmeṇa grāmaṃ gamyate** = ⟪रामेण⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫
- หรืออีกแบบ: **rāmeṇa grāmo gamyate** = ⟪रामेण⟫ ⟪ग्रामो⟫ ⟪गम्यते⟫
:::

::: grammar-box
**กริยาอกรรม (กริยาที่ไม่มีกรรมตรง) มักมีการสร้างรูปพาสซีฟ โดยเฉพาะในการขอร้องอย่างสุภาพ:**
- **praviśyatām** = ⟪प्रविश्यताम्⟫ = "โปรดเข้า = กรุณาเข้ามา = เข้ามา!"
- **niṣadyatām** = ⟪निषद्यताम्⟫ = "โปรดนั่ง = กรุณานั่ง = โปรดนั่งลง"
:::
การสร้างรูปพาสซีฟในภาษาสันสกฤตพบได้บ่อยมาก: เพราะการสร้างรูปพาสซีฟนั้นง่ายกว่าการสร้างรากกริยาปัจจุบันจำนวนมาก

::: important
**โดยทั่วไป ประโยคพาสซีฟในภาษาสันสกฤตไม่สามารถแปลเป็นประโยคพาสซีฟในภาษาเยอรมันได้ เนื่องจากประโยคพาสซีฟในภาษาเยอรมันมีหน้าที่ทางสไตล์ที่แตกต่างโดยสิ้นเชิง**
:::

## 10.2. Instrumentalis (tṛtīyā f. = ⟪तृतीया⟫ = "กรณีคำที่สาม")

### 10.2.1. เกี่ยวกับการใช้ Instrumental (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**Instrumental (tṛtīyā) ใช้ตอบคำถามหลักๆ ดังนี้:**
- **โดยอะไร?**
- **ด้วยอะไร?**
- **กับใคร?**

**Instrumental ใช้**
1. **ในประโยค Passive: Agens (kartṛ) อยู่ใน Instrumental**
2. **เพื่อบอกเครื่องมือหรืออุปกรณ์ที่ใช้ในการกระทำ**
3. **เพื่อบอกเส้นทางที่ใครคนหนึ่งเดินทางไปยังสถานที่ใด**
4. **เพื่อแสดงการเชื่อมโยง การรวมตัว หรือการร่วมด้วย**
5. **ร่วมกับ Postposition ในความหมาย "พร้อมกับ, ด้วย"; เช่น saha = ⟪सह⟫ = "ด้วย"**:brเช่น:br **brāhmaṇena saha** = ⟪ब्राह्मणेन⟫ ⟪सह⟫ = "ร่วมกับพราหมณ์"
:::
การใช้งานอื่นๆ ของ Instrumental (tṛtīyā) จะตามมาในภายหลัง


## 10.3. กฎการเปลี่ยนเสียง Cerebralisation สำหรับ -n- (Wortsandhi ประเภทหนึ่ง)

::: grammar-box
**-n-** ที่ตามด้วยสระหรือ **n, m, y, v** จะถูกแทนที่ด้วย **-ṇ-** หากว่า **ṛ, ṝ, r, ṣ** อยู่ในคำนำหน้า **-n-** หรือไม่มีการออกเสียงอื่นนอกจากสระ, Guttural, Labial, **y, v, h** หรือ Anusvāra อยู่ระหว่างเสียงเหล่านี้กับ **-n-** ที่ตามมาในคำ
:::
**ดังนั้น:**

::: grammar-box
| | Instrumental เอกพจน์ |

| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**ดังนั้น -ṇ- จึงสามารถอธิบายได้ใน:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. ปฏิกิริยา (กรรมวาจกe Voice) ในปัจจุบันกาลบอกเล่า (yak = ⟪यक्⟫)

::: grammar-box
**การสร้าง:**
**(ส่วนใหญ่) รากศัพท์ระดับต่ำ + -ya- + รูปกริยาฝ่ายตน (Ātmanepada)**
:::
ตัวอย่างเช่น

| รากศัพท์:br⟪धातु⟫ | 3. เอกพจน์ ปฏิกิริยา ปัจจุบันบอกเล่า:br⟪यक्⟫ ⟪लट्⟫ | 3. พหูพจน์ ปฏิกิริยา ปัจจุบันบอกเล่า:br⟪यक्⟫ ⟪लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"เขาถูกนำทาง" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"เขาถูกคิด" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"มันถูกเข้า" | **viśyante** :br(⟪विश्यन्ते⟫) |

**โปรดสังเกตว่า สำหรับกริยาในชั้นปัจจุบันกาลที่ 4 รูปกริยาฝ่ายตน (Ātmanepada) และปฏิกิริยามีรูปเดียวกัน! การจะทราบว่าเป็นกริยาฝ่ายตนหรือปฏิกิริยานั้น ในกรณีนี้สามารถอนุมานได้จากโครงสร้างประโยคเท่านั้น。**



### 10.4.1. กฎพิเศษสำหรับการสร้างปฏิกิริยา

1. **รากศัพท์ลงท้ายด้วย -i หรือ -u** จะยืดเสียงสระก่อนส่วนเสริมปฏิกิริยา **-ya-**:
* **ji** 1 P: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 P: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 U: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **รากศัพท์ที่มี -a- อยู่ระหว่างพยัญชนะ** (ยกเว้น Nasal, y, r, v) จะคงระดับเสียงสูง:
* **labh** 1 Ā: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **รากศัพท์บางชนิดสร้างปฏิกิริยาในระดับเสียงสูง** (หรือในขั้นการเปลี่ยนเสียงของรากปัจจุบัน):
* **āp** 5 P: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 P: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 P: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **ระดับต่ำของกริยาที่เริ่มต้นด้วย ya, va, ra หรือเมื่อเสียงเหล่านี้ตามหลังพยัญชนะอื่น (Samprasāraṇa = ⟪सम्प्रसारण⟫):**

| รากศัพท์:br⟪धातु⟫ | ระดับต่ำ:br⟪सम्प्रसारण⟫ | ปฏิกิริยา:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 P:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

ชื่อเรียกแบบดั้งเดิมในท้องถิ่นสำหรับการสร้างระดับต่ำนี้สำหรับกริยาที่มี **ya** หรือ **va** คือ **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **-ṛ** ที่ลงท้ายหลังจากพยัญชนะเดียว จะถูกแทนที่ด้วย **-ri-** ก่อนส่วนเสริมปฏิกิริยา **-ya-**:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* แต่: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫


6. **รากศัพท์บางตัวที่ลงท้ายด้วย -an มีรูปแบบการสร้างรูปปาสสิฟ (Passiv) แบบทางเลือกสองแบบ:**
* รูปแบบหนึ่งคือ **-an-ya**
* อีกรูปแบบหนึ่งคือ **-ā-ya-** (ซึ่ง **ā** ที่ยาวนั้น เป็นตัวแทนของเสียงจมูกที่ยาวตามสมมติฐาน)

ตัวอย่างเช่น **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (มาจาก \*tn-ya-nte)



## 10.5. รายการคำศัพท์

**จงเรียนรู้คำต่อไปนี้:**

## 10.6. แบบฝึกหัด

**ก) จงสร้างรูปปาสสิฟ (Passiv) สำหรับรูปแบบกริยาต่อไปนี้ (พร้อมคำแปลของรูปแบบกริยานั้น):**

1. **sṛjati** (⟪सृजति⟫)
2. **yudhyate** (⟪युध्यते⟫)
3. **bhavanti** (⟪भवन्ति⟫)
4. **yajati** (⟪यजति⟫)
5. **nṛtyati** (⟪नृत्यति⟫)
6. **nayanti** (⟪नयन्ति⟫)
7. **smarati** (⟪स्मरति⟫)
8. **śṛṇvanti** (⟪शृण्वन्ति⟫)
9. **paśyati** (⟪पश्यति⟫) (รูปปาสสิฟสร้างจาก **dṛś**!)
10. **jayanti** (⟪जयन्ति⟫)
11. **kurvate** (⟪कुर्वते⟫)
12. **āpnuvanti** (⟪आप्नुवन्ति⟫)
13. **viśati** (⟪विशति⟫)
14. **khādanti** (⟪खादन्ति⟫)
15. **sunoti** (⟪सुनोति⟫)
16. **gacchati** (⟪गच्छति⟫)
17. **manyante** (⟪मन्यन्ते⟫)
18. **labhante** (⟪लभन्ते⟫)
19. **rakṣanti** (⟪रक्षन्ति⟫)
20. **vadanti** (⟪वदन्ति⟫)
21. **pṛcchanti** (⟪पृच्छन्ति⟫)
22. **tanvanti** (⟪तन्वन्ति⟫) (มี 2 รูปแบบ!)


**B) จงสร้าง Instrumental Singular และ Plural สำหรับคำนามทั้งหมดที่เรียนมาจนถึงปัจจุบัน**

**C) จงเปลี่ยนประโยคต่อไปนี้ให้เป็นรูป Passive และแปล:**
1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो⟩ ⟪देवीं⟩ ⟪यजति⟩)
2. **sādhuḥ svargaṃ gacchati.** (⟪साधुः⟩ ⟪स्वर्गं⟩ ⟪गच्छति⟩)
3. **śūdraṃ jayati.** (⟪शूद्रं⟩ ⟪जयति⟩)
4. **guruḥ phalāni khādati.** (⟪गुरुः⟩ ⟪फलानि⟩ ⟪खादति⟩)
5. **gurūñchṛṇoti.** (⟪गुरूञ्छृणोति⟩)
6. **ko 'gniṃ paśyati.** (⟪को⟩ ⟪ऽग्निं⟩ ⟪पश्यति⟩)
7. **ayaṃ kavirmantraṃ smarati.** (⟪अयं⟩ ⟪कविर्मन्त्रं⟩ ⟪स्मरति⟩)
8. **iyaṃ devī kṣatriyā rakṣati.** (⟪इयं⟩ ⟪देवी⟩ ⟪क्षत्रिया⟩ ⟪रक्षति⟩)
9. **kṣatriyā viṣṇuṃ yajante.** (⟪क्षत्रिया⟩ ⟪विष्णुं⟩ ⟪यजन्ते⟩) (มี 2 วิธี)
10. **brāhmaṇo 'gniṃ karoti.** (⟪ब्राह्मणो⟩ ⟪ऽग्निं⟩ ⟪करोति⟩)
11. **vaiśyā imaṃ grāmaṃ gacchanti.** (⟪वैश्या⟩ ⟪इमं⟩ ⟪ग्रामं⟩ ⟪गच्छन्ति⟩) (มี 2 วิธี)
12. **ete gurūṃstu śṛṇvanti.** (⟪एते⟩ ⟪गुरूंस्तु⟩ ⟪शृण्वन्ति⟩)
13. **sādhuḥ svargamāpnoti.** (⟪साधुः⟩ ⟪स्वर्गमाप्नोति⟩)
14. **brāhmāṇāḥ somaṃ sunvanti.** (⟪ब्राह्मणाः⟩ ⟪सोमं⟩ ⟪सुन्वन्ति⟩)
15. **paśūllabhate.** (⟪पशूल्लभते⟩)
16. **ke yodhāḥ kṣatriyaiḥ saha yudhyante.** (⟪के⟩ ⟪योधाः⟩ ⟪क्षत्रियैः⟩ ⟪सह⟩ ⟪युध्यन्ते⟩)

**D) จงแปลเป็นภาษาสันสกฤต:**
1. พราหมณ์คนหนึ่งเดินทางไปยังหมู่บ้านพร้อมกับไวศยะหนึ่งคน
2. เขาบูชาวิษณุด้วยเครื่องสังเวย (ต้องแสดงคำว่า **yajña**!)
3. เวดาถูกเรียกว่า śruti (**vad**)
4. มีการขึงเส้นยืนของผ้า (มี 2 วิธี)

::: media
![](/images/lekt1004.jpg)
ภาพ: ⟪तन्तुवायः⟩
(ที่มาของภาพ: [รายละเอียด](/th/licenses#lekt1004))
:::
5. ครูถามคำถาม (โครงสร้าง Passive)
6. ดวงตาเป็นผู้นำ (โครงสร้าง Passive)
7. กวีเห็นเทพเจ้าองค์หนึ่ง (โครงสร้าง Passive)
8. ใคร (เพศหญิง) คอยดูแลเด็กผู้หญิง? (โครงสร้าง Passive)
9. กษัตริย์บูชาพระผู้เป็นเจ้าด้วยเครื่องสังเวย (โครงสร้าง Passive โดยไม่ใช้คำว่า **yajña**)
10. ด้วยความเอื้อเฟื้อ ผู้ติดตามของพระพุทธเจ้าบรรลุถึงสรวงสวรรค์
