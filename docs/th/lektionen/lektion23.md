# บทที่ 23

## 23.1. อนินฟินีต์ (⟪तुमुन्⟫)

::: grammar-box
**หากต้องการแสดงในภาษาสันสกฤตว่ากิจกรรมหนึ่งเกิดขึ้นเพื่อวัตถุประสงค์ของกิจกรรมอื่น ("เพื่อให้") สามารถใช้ออนินฟินีต์ (⟪तुमुन्⟫) สำหรับกิจกรรมที่เป็นวัตถุประสงค์นั้น อนินฟินีต์บ่งบอกถึงจุดประสงค์หรือเจตนาเป็นสำคัญ:**

> ⟪रामो⟫ ⟪गुरुवचनं⟫ ⟪श्रोतुं⟫ ⟪गतः⟫ = "รามาได้ไปเพื่อฟังคำสอนของอาจารย์"

**โปรดสังเกตว่า อนินฟินีต์ — ยกเว้นข้อยกเว้นที่กำหนดไว้บางประการ — ไม่สามารถทำหน้าที่เป็นประธานหรือวัตถุของกริยาได้:**

> ดังนั้น "เขาเรียนรู้ที่จะเต้น" ไม่สามารถแปลด้วยอนินฟินีต์ ("เต้น") ได้ แต่ต้องใช้คำนามเชิงกริยา เช่น: ⟪नर्तनमधीते⟫ (⟪इ⟫ + ⟪अधि⟫ 2 Ā: "เรียนรู้")

**อนินฟินีต์ยังใช้กับกริยาและนามที่มีความหมายว่า "ต้องการ" หรือ "โหยหา" เมื่อผู้กระทำ (⟪कर्तृ⟫) ของอนินฟินีต์และกริยาคือบุคคลเดียวกัน:**

> ⟪रामो⟫ ⟪गुरुवचनं⟫ ⟪श्रोतुमिच्छति⟫ = "รามาต้องการฟังคำสอนของอาจารย์"

**อนินฟินีต์ยังใช้กับกริยาที่มีความหมายว่า "มีความสามารถ", "มีอยู่", "รู้", "เริ่มต้น" เป็นต้น:**

> ⟪साधुरधर्मं⟫ ⟪कर्तुं⟫ ⟪न⟫ ⟪शक्नोति⟫ = "ฤๅษีไม่สามารถกระทำผิดได้"  
> ⟪अस्ति⟫ ⟪भोक्तुमन्नम्⟫ = "มีอาหารให้กิน" (⟪भुज्⟫ 7: Ā: กิน, P: ปกครอง)

**อนินฟินีต์ยังใช้กับคำที่มีความหมายว่า "เพียงพอ", "สามารถ" และกับนามที่มีความหมายว่า "ความสามารถ", "พลัง", "ทักษะ":**

> ⟪अस्त्यग्नेर्विभवः⟫ ⟪सर्वं⟫ ⟪दग्धुम्⟫ = "ไฟมีอำนาจที่จะเผาไหม้ทุกสิ่ง"

**นอกจากนี้ อนินฟินีต์ยังสามารถใช้กับคำที่มีความหมายว่า "เวลา" ในสำนวนเช่น "ถึงเวลาที่จะ..." ได้:**

> ⟪कालो⟫ ⟪भोजनं⟫ ⟪सेवितुम्⟫ = "ถึงเวลาที่จะอุทิศให้กับการกิน" = "ถึงเวลาที่จะกิน"

**อนินฟินีต์สามารถใช้ได้ทั้งรูป aktif และ passive ในภาษาเยอรมัน อนินฟินีต์แบบ passive ในภาษาสันสกฤตแสดงโดยการเปลี่ยนกริยา (โดยเฉพาะอย่างยิ่ง ⟪शक्⟩ "มีความสามารถ, สามารถ") ซึ่งอนินฟินีต์ขึ้นอยู่กับรูป passive**

**ในแง่ของวัตถุ อนินฟินีต์ประพฤติตนเหมือนรูปกริยา กล่าวคือ วัตถุตรง (⟪कर्मन्⟫) อยู่ในกรณีอากุเมนตัม (⟪द्वितीया⟫) เมื่อใช้ออนินฟินีต์ในรูป aktif หรืออยู่ในกรณีตามที่กริยานั้นกำหนดไว้; เมื่อใช้ออนินฟินีต์ในรูป passive วัตถุตรงจะอยู่ในกรณีนามัตตัม**

เช่น

> ⟪साधुरधर्मं⟫ ⟪कर्तुं⟫ ⟪न⟫ ⟪शक्नोति⟫ = ⟪साधुनाधर्मः⟫ ⟪कर्तुं⟫ ⟪न⟫ ⟪शक्यते⟫ = "ฤๅษีไม่สามารถกระทำผิดได้"

**ในบุรุษที่ 2 ⟪अर्ह्⟫ + อนินฟินีต์มักใช้คำสั่งอย่างอ่อนโยน: "คุณควร"**

**หากอนินฟินีต์ขึ้นอยู่กับนาม ไม่อนุญาตให้รวมเข้ากับคำประสม ยกเว้น Bahuvrīhi ซึ่งมีส่วนที่สองเป็น ⟪काम⟫ หรือ ⟪मनस्⟫:**

> ⟪वक्तुकामः⟫ = ⟪वक्तुं⟫ ⟪कामो⟫ ⟪यस्य⟫ ⟪सः⟫ = "ผู้ที่มีความปรารถนาที่จะพูด; ผู้ที่ต้องการพูด"
:::
## 23.2. การสร้างคำกริยาอนัตถะ (⟪तुमुन्⟫)

::: grammar-box
**รากศัพท์ระดับสูง + -tum**

**หรือ**

**รากศัพท์ระดับสูง + -i- + -tum**

**พยัญชนะท้ายของรากศัพท์จะเปลี่ยนแปลงก่อนหน้า -tum ตามกฎเดียวกันกับการเปลี่ยนแปลงก่อนหน้า -ta ของ PPP**

**กริยาที่มีคำนำหน้าสร้างคำกริยาอนัตถะในลักษณะเดียวกับรากศัพท์พื้นฐาน**
:::
ตัวอย่าง:

::: indent
⟪दिश्⟫ : ⟪देष्टुम्⟫  
⟪रुद्⟫ : ⟪रोदितुम्⟫
:::
ไม่สามารถกำหนดกฎตายตัวเกี่ยวกับการใช้สระเชื่อม -i- ได้ โดยหลักแล้วการกระจายตัวของสระเชื่อมในคำกริยาอนัตถะสอดคล้องกับอนาคต tense

สำหรับรากศัพท์ที่เรียนมาจนถึงปัจจุบัน มีคำกริยาอนัตถะต่อไปนี้ที่ต้อง特别注意:

::: indent
⟪गम्⟫ : ⟪गन्तुम्⟫

⟪प्रच्छ्⟫ : ⟪प्रष्टुम्⟫
:::
-ra- als Hochstufe zu -ṛ- haben im Infinitiv:

::: indent
⟪दृश्⟫ : ⟪द्रष्टुम्⟫

⟪सृज्⟫ : ⟪स्रष्टुम्⟫
:::
Die anderen Wurzeln mit -ṛ- an vorletzter Stelle haben fakultativ -ra- oder -ar-, wenn sie aniṭ sind.

## 23.4. รายการคำศัพท์

⟪समान⟫ ⟪३⟫: เท่ากัน

⟪सामान्य⟫ n.: ความเท่ากัน, ความสอดคล้อง

⟪अधिक⟫ ⟪३⟫ : เกินจำเป็น, เพิ่มเติม, ใหญ่กว่า, ดีกว่า, luar biasa

⟪विशेष⟫ m.: ความพิเศษ, การระบุเฉพาะ, differentia specifica

## 23.6. แบบฝึกหัดทบทวน

กรุณาอย่าใช้เครื่องมือช่วย!

A) แปลเป็นภาษาสันสกฤต:

1\. ความทุกข์ห้าประการ (⟪पञ्च⟫) ได้แก่: อวิชชา, มิจฉาทิฏฐิในอัตตา, ราคะ, โทสะ และมานะต่อร่างกาย

2\. ความรู้มีได้จากการเชื่อฟังอาจารย์ หรือด้วยเงินจำนวนมาก หรือด้วยการแลกเปลี่ยนกับความรู้ ไม่มีวิธีที่สี่ในการได้มาซึ่งความรู้

3\. คนต่ำพูดแต่ไม่กระทำ; คนดีไม่พูด แต่กระทำเท่านั้น

4\. อรรถกถาของเวท ได้แก่: สัทศาสตร์, พิธีกรรม, ไวยากรณ์, นิรุกติศาสตร์, จันทริกาศาสตร์ และปฏิทินวิทยา

5\. โยคคือการหยุดกิจกรรมของจิต

6\. ความถูกต้องชนะ ไม่ใช่อคติ; สัจจะชนะ ไม่ใช่โกหก; ขันติชนะ ไม่ใช่โทสะ; พระเจ้าชนะ ไม่ใช่เทพเทียม (ใช้รูปพาสซีฟ)

7\. "ไม้เท้า" นำมาซึ่งการได้มาและการครอบครองปรัชญา เวท และเศรษฐศาสตร์อย่างมั่นคง การถือไม้เท้านี้คือรัฐศาสตร์

8\. ภรรยา ลูกชาย และทาส สามสิ่งนี้ (⟪त्रयस्⟫) ตามคำบอกเล่าไม่มีทรัพย์สิน สิ่งใดที่สามสิ่งนี้มาถึงนั้นเป็นของเจ้าของ (สามสิ่ง)

9\. ยุงต้องการแผล ผู้ปกครองต้องการทรัพย์สิน คนต่ำต้องการความขัดแย้ง คนดีต้องการสันติภาพ

10\. กิจเฉพาะของพราหมณ์คือ: การศึกษา, การสอน, การบูชาในฐานะเจ้าพิธี, การบูชาในนามผู้อื่น, การให้ และการรับ ; ของกษัตริย์คือ: การศึกษา, การบูชาในฐานะเจ้าพิธี, การให้, การดำรงชีวิตด้วยอาวุธ, การคุ้มครองสรรพสัตว์ ; ของไวศยะ: การศึกษา, การบูชาในฐานะเจ้าพิธี, การให้, การทำนา, การเลี้ยงสัตว์ และการค้า ; ของศูทร: ความเชื่อฟังต่อผู้เกิดสองครั้ง, กิจกรรมทางเศรษฐกิจ, งาน (⟪कर्म⟩) ของช่างฝีมือและผู้แสดง

11\. การชำระจิตเกิดขึ้นจากการเจริญเมตตา กรุณา มุทิตา และอุเบกขา ซึ่งมีสุขและทุกข์ เป็นวัตถุ คุณและโทษ

12\. คนจนมีบุตรมาก แม้จะไม่ปรารถนา คนรวยไม่มีบุตร น่าประหลาดใจคือ การเคลื่อนไหวของโชคชะตา

13\. ใครไม่ฆ่าหญิงร่าง (⟪वपुस्⟩ f.) เอวบาง สะโพกกว้าง ปากแดง ตาดำ รยางค์โค้ง หน้าอกตั้งตรง

B) จงผันคำในกรณีทั้งหมดที่คุณรู้จัก ⟪क्षत्रिया⟩ f.
