# บทที่ 19

## 19.1. วลีสัมพันธะ (Relativsatz)

::: grammar-box

**แผนผัง:**

**คำสรรพนามสัมพันธะ -- วลีสัมพันธะ ซึ่งระบุคำนามที่วลีสัมพันธะอ้างอิงถึง -- (คำสรรพนามชี้เฉพาะ) -- ประโยคหลัก**

**วลีสัมพันธะสามารถอยู่หลังประโยคหลักได้ แต่ไม่สามารถแทรกเข้าไปในประโยคหลักได้**

**คำสรรพนามสัมพันธะและคำอ้างอิง ซึ่งต่างจากภาษาเยอรมัน จะอยู่ในวลีสัมพันธะ อยู่ในกรณียก (Kasus) ที่วลีสัมพันธะต้องการทางไวยากรณ์ คำสรรพนามชี้เฉพาะอยู่ในกรณียกที่ประโยคหลักต้องการทางไวยากรณ์**
:::

ตัวอย่าง:

หมายเหตุ: ในประโยคสัมพันธะที่มีความหมายทั่วไป มักใช้กริยาในรูปอุปสรรค (Optativ) แทนบอกเล่า (Indikativ) ดังนั้นตัวอย่างจำนวนมากของเราจึงควรอยู่ในรูปอุปสรรค

**1. ผู้กระทำ (⟪कर्तृ⟫) ของประโยคถูกกำหนดรายละเอียดเพิ่มเติมโดยวลีสัมพันธะ:**

::: indent
⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪स⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫ =  ⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟩ = ⟪येन⟫ ⟪नरेण⟫ ⟪पुण्यम्⟫ ⟪क्रियते⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ ฯลฯ = "บุรุษผู้กระทำความดี ย่อมไปสู่สรวงสวรรค์"
:::
**2. กรรมตรง (⟪कर्म⟫) ของประโยคหลักถูกกำหนดรายละเอียดเพิ่มเติมโดยวลีสัมพันธะ:**

::: indent
⟪यो⟫ ⟪ब्राह्मणो⟫ ⟪देवान्यजते⟫ ⟪तं⟫ ⟪देवा⟫ ⟪रक्षन्ति⟫ = "เทพเจ้าคุ้มครองพราหมณ์ผู้ทำพิธีบูชาแก่พวกเขา"
:::
**การกำหนดรายละเอียดเพิ่มเติมของคำนามในประโยคหลักอยู่ในวลีสัมพันธะ:**

::: indent
⟪ये⟫ ⟪नराः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪तेषां⟫ ⟪पुत्रा⟫ ⟪धनं⟫ ⟪न⟫ ⟪लभन्ते⟫ = "บุตรของบุรุษผู้กระทำความชั่ว ไม่ได้รับทรัพย์สมบัติ"
:::
**4. คำสรรพนามสัมพันธะและคำอ้างอิงอยู่ในกรณียกเจ้าของ (Genetiv) (⟪षष्ठी⟫):**

::: indent
⟪यस्य⟫ ⟪नरस्य⟫ ⟪पुत्राः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪स⟫ ⟪न⟫ ⟪सुखवान्⟫ = "บุรุษผู้ซึ่งบุตรของตนกระทำความชั่วย่อมไม่มีความสุข"
:::
**5. คำสรรพนามสัมพันธะและคำอ้างอิงอยู่ในกรณียกเครื่องมือ (Instrumentalis) (⟪तृतीया⟫):**

::: indent
⟪येन⟫ ⟪शत्रुणा⟫ ⟪ग्रामो⟫ ⟪जितस्तं⟫ ⟪द्विषन्ति⟫ = "พวกเขาเกลียดศัตรูผู้พิชิต/ยึดครองหมู่บ้านของพวกเขา"
:::
**6. คำสรรพนามสัมพันธะและคำอ้างอิงอยู่ในกรณียกกรรม (Akkusativ) (⟪द्वितीया⟫):**

::: indent
⟪यं⟫ ⟪नरं⟫ ⟪देवी⟫ ⟪रक्षति⟫ ⟪स⟫ ⟪सुखमाप्नोति⟫ = "บุรุษผู้ซึ่งเทพธิดาคุ้มครอง ย่อมได้รับความสุข"
:::

## 19.3. รายการคำศัพท์

**⟪अर्थ⟫ นามบุรุษที่ 1:** จุดประสงค์, เป้าหมาย, ความหมาย (ของคำ), ความมั่งคั่ง, ทรัพย์สิน, สินทรัพย์. ⟪अर्थम्⟫ (อกรรมกริยา), ⟪अर्थेन⟫ (อกรรมกริยา) พร้อมกับสัมพันธการก หรือเป็นองค์หลังของคำประสมประเภทตัตปุรุสะ: เพื่อ..., เพื่อให้

⟪अर्थ⟫ เป็นหนึ่งในสามของเป้าหมายชีวิต (⟪पुरुषार्थ⟫) ตามที่อธิบายไว้ในวรรณกรรมทางโลกและศาสนา:

::: indent
**⟪धर्म⟫ นามบุรุษที่ 1:** การบรรลุคุณธรรมผ่านการกระทำสิ่งที่ถูกต้อง หรืออย่างน้อยคือการหลีกเลี่ยงความชั่วซึ่งจะตามมาจากการไม่ปฏิบัติตามธรรม

**⟪अर्थ⟫ นามบุรุษที่ 1:** พฤติกรรมที่มีเหตุผลตามวัตถุประสงค์, การบรรลุความมั่งคั่ง

## 19.4. การฝึกฝน

**แปลเป็นภาษาสันสกฤต:**

1\. ภรรยาของไวศยะซึ่งบุตรชายเสียชีวิตกำลังร้องไห้

2\. รามะบูชาเทพเจ้าผู้คุ้มครองเขา

3\. กวีสรรเสยกษัตริย์ซึ่งความมั่งคั่งที่เขาปรารถนา

4\. ไฟเผาบ้านของชายผู้ซึ่งไม่บูชาอgniด้วยการบูชายัญ

5\. ชายผู้มีลักษณะดุจเสือสังหารนักรบกษัตริย์ผู้ซึ่งรามะเอาชนะแล้ว (เสียง被动)
