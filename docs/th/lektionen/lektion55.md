# บทที่ 55

## 55.1. อ-อาเรสต์ (อาเรสต์ที่มีสระธีม)

::: grammar-box
**อ-อาเรสต์ถูกสร้างเหมือนอิมเพอร์เฟกต์ (⟪लङ्⟫) ของชั้นปัจจุบันที่ 6 (⟪तुदादि⟫), กล่าวคือ:**

**อ็อกเมนต์ + รากเสียงต่ำ + a + การลงท้ายแบบทุติยภูมิ**

**-a- จะถูกแทนที่ด้วย -ā- ในกรณีเดียวกันกับอิมเพอร์เฟกต์**

**ไม่มีนาสิกอินฟิกซ์**

**อาตมันเนปะดาหาได้บ่อยนัก; สำหรับรากที่ทั้งสองฝ่าย (ubhayapada) มักจะถูกสร้างตามชั้นอาเรสต์อื่น (ดูเคิลฮอร์น ไวยากรณ์ §340 และด้านล่างที่ชั้นอาเรสต์ที่เกี่ยวข้อง)**

**รายการรากที่มีอาเรสต์นี้ ดูที่เคิลฮอร์น ไวยากรณ์ §340**
:::
