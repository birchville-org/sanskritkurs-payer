# แบบฝึกหัด 61

บทที่ 61 เป็นบทสรุปของหลักสูตรภาษาสันสกฤต และไม่มีแบบฝึกหัดลายลักษณ์อักษรเพิ่มเติม

ด้วยการศึกษาคำนามรากศัพท์ อนาคตแบบเพริฟราสติก และคำนามอนุพันธ์ พื้นฐานสำหรับการอ่านข้อความต้นฉบับภาษาสันสกฤตได้ถูกวางไว้แล้ว หลักสูตรนี้ปิดท้ายด้วยการเรียกขานแบบดั้งเดิมถึง Gaṇeśa (⟪श्रीगणनाथ⟫) ซึ่งเป็นการเปลี่ยนผ่านจากหนังสือเรียนไปสู่การอ่านอย่างอิสระ
