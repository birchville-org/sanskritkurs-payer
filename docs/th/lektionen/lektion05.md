# บทที่ 5

## 5.1. นามคำประสม (samāsa m. = ⟪समास⟫)

การสร้างคำประสมในปริมาณมากเป็นลักษณะเฉพาะของภาษาสันสกฤต

รูปแบบการสร้างคำประสมที่สำคัญที่สุดได้แก่:
- **คำประสมแบบร่วม** (dvandva n. = ⟪द्वन्द्व⟫)
- **คำประสมแบบกำหนด** (tatpuruṣa m. = ⟪तत्पुरुष⟫)
- **คำประสมแบบแสดงความเป็นเจ้าของ** (bahuvrīhi m. = ⟪बहुव्रीहि⟫)

(ดูส่วนที่สองจากท้ายนี้ในภายหลัง!)

## 5.2. ศัพท์ภาษาสันสกฤตสำหรับคำประสม

- **ghaṭakapadāni** n. pl. = ⟪घटकपदानि⟫ : สมาชิกของคำประสม
- **vigrahavākyam** n. = ⟪विग्रहवाक्यम्⟫ : การแยกคำประสม
- **nityasamāsaḥ** m. = ⟪नित्यसमासः⟫ : คำประสมที่ไม่มี vigrahavākya หรือที่ซึ่ง vigrahavākya เป็นไปไม่ได้ด้วยคำของคำประสม
- **aluksamāsaḥ** m. = ⟪अलुक्समासः⟫ : คำประสมที่สมาชิกหน้าคงรูปนามกิต্তิ
- **luksamāsaḥ** m. = ⟪लुक्समासः⟫ : คำประสมที่สมาชิกหน้าไม่มีรูปนามกิต্তิ (กรณีปกติ)
- **madhyamapadalopī** m. = ⟪मध्यमपदलोपी⟫ : คำประสมที่สมาชิกกลางหนึ่งหรือหลายตัวถูกละไว้

## 5.3. คำประสมแบบร่วม (Dvandva n. = ⟪द्वन्द्व⟫)

คำประสมแบบร่วมใช้เพื่อเชื่อมโยงสมาชิกที่สอดคล้องกันทางไวยากรณ์และประสานกัน (นามหรือคุณศัพท์)

::: grammar-box
**Dvandva หนึ่งหมายถึง:**

1. **หรือการรวมเชิงบวกของบุคคล สิ่งต่างๆ หรือคุณสมบัติที่ระบุโดยสมาชิกแต่ละตัวของมัน:**
Itaretaradvandva = ⟪इतरेतरद्वन्द्व⟫

2. **หรือมันรวบรวมบุคคล สิ่งต่างๆ หรือคุณสมบัติเหล่านี้เข้าเป็นหนึ่งเดียว:**
Samāhāradvandva ("Dvandva แบบรวม") = ⟪समाहारद्वन्द्व⟫

**ในกรณีแรก (Itaretaradvandva):**
Dvandva ได้รับเพศทางไวยากรณ์ของสมาชิกตัวสุดท้ายและรูปพจน์คู่ (สำหรับสองสิ่ง) หรือพจน์พหูพจน์ (สำหรับมากกว่าสองสิ่ง) รูปเอกพจน์ก็อนุญาตได้เช่นกัน

**ในกรณีที่สอง (Samāhāradvandva):**
Dvandva โดยทั่วไปเป็นกลาง (ไม่ขึ้นกับเพศของสมาชิกตัวสุดท้าย) และอยู่ในรูปเอกพจน์

**การแยก:**
ทำด้วย "และ" (**ca** = ⟪च⟫) บางครั้งด้วย "หรือ" (**vā** = ⟪वा⟫) หรือ "แต่ละ"
:::
ดู Dvandva คู่ในภายหลัง!

### 5.3.1. สมาชิกหน้าของคำประสม

สมาชิกหน้าของคำประสม (ไม่ใช่เพียง Dvandvas) โดยทั่วไปมีรูปเป็น **รากนามที่เปลี่ยนแปลงไม่ได้** สมาชิกแต่ละตัวของคำประสมถูกเชื่อมตามกฎของ **ประโยคสันธิต (Satzsandhi)** (นั่นคือ สันธิตที่เราได้เรียนรู้จนถึงปัจจุบัน ซึ่งแตกต่างจากสันธิตภายในคำที่ประยุกต์ใช้กับองค์ประกอบเชิงรูปแบบ)

### 5.3.2. อิตเรตรทวันทวะพหูพจน์

ตัวอย่างของ Dvandva พหูพจน์:

**brāhmaṇa-kṣatriya-vaiśya-śūdrāḥ** = ⟪ब्राह्मणक्षत्रियवैश्यशूद्राः⟫
> = brāhmaṇāḥ kṣatriyā vaiśyāḥ śūdrāś ca = ⟪ब्राह्मणाः⟫ ⟪क्षत्रिया⟫ ⟪वैश्याः⟫ ⟪शूद्राश्च⟫
> (พราหมณ์ กษัตริย์ ไวกฺฤ และศูทร)
> 
> หรือ = brāhmaṇaḥ kṣatriyo vaiśyaḥ śūdraś ca = ⟪ब्राह्मणः⟫ ⟪क्षत्रियो⟫ ⟪वैश्यः⟫ ⟪शूद्रश्च⟫
> ((พราหมณ์ กษัตริย์ ไวกฺฤ และศูทร) (เอกพจน์))

**kavi-guravaḥ** = ⟪कविगुरवः⟫
> = kavayo guravaś ca = ⟪कवयो⟫ ⟪गुरवश्च⟫
> (กวีและอาจารย์ [พหูพจน์])
> (หมายเหตุ: "กวีหนึ่งคนและอาจารย์หนึ่งคน" จะต้องอยู่ในรูปทวิพจน์!)

**สำหรับลำดับของสมาชิกใน compound ดฺวันดฺวา มีกฎดังต่อไปนี้:**
- ชื่อของวรรณะต่างๆ (**varṇa**) ควรเรียงตามลำดับชั้น (สูงสุดก่อน)
- ชื่อของพี่ชายคนโตควรอยู่ข้างหน้าชื่อของน้องชายคนเล็ก
- โดยทั่วไป คำที่สำคัญกว่าควรอยู่ต้นประโยค
- คำที่ลงท้ายด้วย **-i** หรือ **-u** ควรอยู่ก่อน
- คำที่ลงท้ายด้วย **-a** และขึ้นต้นด้วยสระ ควรอยู่ก่อน
- คำที่มีพยางค์น้อยกว่าควรอยู่ก่อน

เมื่อมีข้อกำหนดสามข้อสุดท้ายที่กล่าวมาสามารถเกิดขึ้นพร้อมกันได้ ควรปฏิบัติตามกฎที่ให้ไว้ทีหลังเสมอ (ตัวอย่างของ compound ดฺวันดฺวาทวิพจน์สำหรับกฎเหล่านี้ดูใน Kielhorn, Grammar § 570).

## 5.4. รายการคำศัพท์

**เรียนรู้คำต่อไปนี้:**

**abhiniveṣa** m. = ⟪अभिनिवेष⟩ : ความโน้มเอียง, ความดื้อรั้น, การยึดมั่น; โดยเฉพาะ: ความผูกพันกับร่างกายเสมือนว่าเป็นของตัวตน

**kāma** m. = ⟪काम⟩ : ความปรารถนา, ความใคร่, ของขวัญที่พึงประสงค์, กามารมณ์, รัก; เทพเจ้าแห่งความรัก คาม

::: media
![](/images/lekt0501.webp)
ภาพ: เทพเจ้าคาม = kāmadeva = ⟪कामदेव⟩, ศตวรรษที่ 18
(แหล่งที่มาของภาพ: Wikipedia, สาธารณสมบัติ)
:::
**krodha** m. = ⟪क्रोध⟩ : โกรธ

**kleśa** m. = ⟪क्लेश⟩ : ความทุกข์ทรมาน, ความลำบาก

**trayī** f. = ⟪त्रयी⟩ : จำนวนสาม; โดยเฉพาะอย่างยิ่งเวททั้งสาม (ฤคเวท, สามเวท, ยชุรเวท)

**daṇḍanīti** f. = ⟪दण्डनीति⟩ : การเมือง (compound ตัทปุรุษจาก daṇḍa m. = "ไม้เท้า, อำนาจ, การปกครอง, โทษ" และ nīti f. = "การนำทางที่ถูกต้อง")

**dvijāti** 3 / **dvija** 3 = ⟪द्विजाति⟩ / ⟪द्विज⟩ : ผู้เกิดสองครั้ง

**dveṣa** m. = ⟪द्वेष⟩ : ความเกลียดชัง

**maitrī** f. = ⟪मैत्री⟩ : มิตรภาพ, ความเป็นมิตร, ความปรารถนาดีอย่างมีไมตรี

**rāga** m. = ⟪राग⟩ : (สีแดง) สี, ความหลงใหล, รัก

**lobha** m. = ⟪लोभ⟩ : ความโลภ, ความตระหนี่

**varṇa** m. = ⟪वर्ण⟩ : สี, ประเภท, วรรณะ

**vārttā** f. = ⟪वार्त्ता⟩ : การหาเลี้ยงชีพ, เศรษฐศาสตร์ (เศรษฐกิจ)

**vidyā** f. = ⟪विद्या⟩ : ความรู้, วิทยาศาสตร์

**avidyā** f. = ⟪अविद्या⟩ : ความไม่รู้, อวิชชา

**ca** = ⟪च⟩ : และ
(วางไว้หลังคำที่มันเชื่อม หากมีหลายคำถูกเชื่อมกัน ควรอยู่หลังคำแรกของกลุ่มการเชื่อมสุดท้าย: brāhmaṇāḥ kṣatriyā vaiśyāḥ śūdrāś ca = ⟪ब्राह्मणाः⟩ ⟪क्षत्रिया⟩ ⟪वैश्याः⟩ ⟪शूद्राश्च⟩).

**ca ... ca** = ⟪च⟩ ... ⟪च⟩ : ทั้ง ... และ

## 5.5. แบบฝึกหัด

**ก) จงแปลประโยคและ compound ต่อไปนี้ และแก้ compound ดฺวันดฺวาที่ปรากฏ therein ในภาษาสันสกฤต:**

1. catvāro varṇā brāhmaṇakṣatriyavaiśyaśūdrāḥ.
(Āpastambīyadharmasūtra I,1,1,4 = Vāsiṣṭhadharmaśāstra II,1)
⟪चत्वारो⟩ ⟪वर्णा⟩ ⟪ब्राह्मणक्षत्रियवैश्यशूद्राः⟩ ||
(คำอธิบาย: catvāras = ⟪चत्वारस्⟩ = "สี่")

2. trayo varṇā dvijātayo brāhmaṇakṣatriyavaiśyāḥ.
(Vāsiṣṭhadharmaśāstra II,1)
⟪त्रयो⟫ ⟪वर्णा⟫ ⟪द्विजातयो⟫ ⟪ब्राह्मणक्षत्रियवैश्याः⟫ ||
(คำอธิบาย: trayas = ⟪त्रयस्⟫ = "สาม")

3. sāmavedargvedayajurvedās trayī.
(Kauṭilīya-arthaśāstra 1.3.1. / ในภาษาสันสกฤตที่ดี: sāmārgyajurvedās trayī)
⟪सामवेदर्ग्वेदयजुर्वेदास्त्रयी⟫ ||
(ในภาษาสันสกฤตที่ดี: ⟪सामार्यजुर्वेदास्त्रयी⟫)

4. ศัตรูสามประการของมนุษย์ ซึ่งเป็นประตูสู่地狱 (Viṣṇusmṛti 33,1+6):
   kāmakrodhalobhāḥ
⟪कामक्रोधलोभाः⟫ ||

5. maitrīkaruṇāmuditopekṣāś catvāro brahmavihārāḥ.
⟪मैत्रीकरुणामुदितोपेक्षाश्चत्वारो⟫ ⟪ब्रह्मविहाराः⟫ ||
(คำอธิบาย: brahmavihāra: "สถานะการพำนักของพรหม" หรือเรียกอีกอย่างว่า "อพรหมวิหาร 4" เป็นรูปแบบการปฏิบัติธรรมในพุทธศาสนา)

6. avidyāsmitārāgadveṣābhiniveṣāḥ pañca kleśāḥ.
(Yogasūtra 2,3)
⟪अविद्यास्मितारागद्वेषाभिनिवेषाः⟫ ⟪पञ्च⟫ ⟪क्लेशाः⟫ ||
(คำอธิบาย: pañca = "ห้า")

7. ānvīkṣikītrayīvārttādaṇḍanitayo vidyāḥ.
(ตาม Kauṭilīya-arthaśāstra 1.2.1.)
⟪आन्वीक्षिकीत्रयीवार्त्तादण्डनितयो⟫ ⟪विद्याः⟫ ||

## 5.6. แบบฝึกหัดทบทวน

**A) จงแปล:**

1. vidyā vārttā.
   ⟪विद्या⟫ ⟪वार्त्ता⟫ |

2. brāhmaṇaḥ kṣatriyo vaiśyaś ca trayo varṇā dvijātayaḥ.
   ⟪ब्राह्मणः⟫ ⟪क्षत्रियो⟫ ⟪वैश्यश्च⟫ ⟪त्रयो⟫ ⟪वर्णा⟫ ⟪द्विजातयः⟫ |

3. dvijā vaiśyāḥ. (มี 2 วิธี)
   ⟪द्विजा⟫ ⟪वैश्याः⟫ |

**B) จงใส่รูปคำที่สอดคล้องกัน:**

1. (dvija, sādhu, kavi) ... rāmaḥ
   (⟪द्विज⟫, ⟪साधु⟫, ⟪कवि⟫) ... ⟪रामः⟫ |

2. (devī) ... indrāṇī
   (⟪देवी⟫) ... ⟪इन्द्राणी⟫ |

3. dvijātayas ... (vaiśyā, kṣatriya)
   ⟪द्विजातयस्⟫ ... (⟪वैश्या⟫, ⟪क्षत्रिय⟫) |

**C) จงแยกคำสมาสในประโยคต่อไปนี้เป็นภาษาสันสกฤต แล้วสร้างประโยคเดียวกันด้วยรูปที่แยกได้นั้น:**

sāmargyajurvedās trayī.
⟪सामर्ग्यजुर्वेदास्त्रयी⟫ |

**D) จงแปลเป็นภาษาสันสกฤตสองแบบ (ครั้งหนึ่งโดยใช้คำสมาส และอีกครั้งโดยไม่ใช้):**

"สถานะการพำนักของพรหม" ได้แก่: เมตตา, กรุณา, มุทิตา, อุเบกขา
