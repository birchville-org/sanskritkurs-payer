# บทที่ 28

## 28.1. การุติวะ (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**หากต้องการแสดงว่า บุคคลหรือสิ่งใดบุคคลหนึ่งหรือบางสิ่งบางอย่างถูกกระตุ้นหรือทำให้บุคคลอื่นหรือบางสิ่งบางอย่างกระทำหรือประสบกับสิ่งที่แสดงโดยรากศัพท์ (ที่มีหรือไม่มีการ์ก) ดังนั้นจึงใช้ การุติวะ (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫).**

ตัวอย่าง:
⟪गम्⟫ "ไป" » การุติวะ: ⟪गमयति⟫ "เขาทำให้บุคคลอื่นไป; เขาส่ง"
⟪दृश्⟫ "เห็น" » การุติวะ: ⟪दर्शयति⟫ "เขาทำให้เห็น = เขาแสดง"
:::

## 28.2. โครงสร้างประโยคด้วย การุติวะ (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**รูปแบบที่ 1:**

**หากรากศัพท์ที่อยู่เบื้องหลัง การุติวะ (ที่มีหรือไม่มีการ์ก) เป็น อินทรกรรม (นั่นคือ ไม่สามารถมีวัตถุกรรมในกรณีอาคเนยะได้) หรือแสดงการเคลื่อนไหว ความรู้ ข้อมูลหรืออาหาร:**

**ผู้กระทำ (⟪कर्ता⟫) ของ การุติวะ ในกรณีนอมินาทีฟ (⟪प्रथमा⟫) — ผู้กระทำของการกระทำที่ถูกกระตุ้นในกรณีอาคเนยะ (⟪द्वितीया⟫) — (เป้าหมายของการเคลื่อนไหว วัตถุของความรู้อื่นๆ ในกรณีอาคเนยะ = ⟪द्वितीया⟫) — กริยาใน การุติวะ**
:::
ตัวอย่าง:

⟪दुर्जनो⟫ ⟪रामं⟫ ⟪मोहयति⟫ = "คนชั่วทำให้รามะสับสน = ทำให้รามะสับสน = ทำให้รามะหลงผิด"
ผลลัพธ์: ⟪रामो⟫ ⟪मुह्यति⟫ = "รามะสับสน / หลงผิด / หลงผิด"

⟪रामः⟫ ⟪शत्रून्स्वर्गं⟫ ⟪गमयति⟫ = "รามะทำให้ศัตรูขึ้นไปสวรรค์ = ส่งศัตรูไปยังสรวงสวรรค์"
ผลลัพธ์: ⟪शत्रवः⟫ ⟪स्वर्गं⟫ ⟪गच्छन्ति⟫ = "ศัตรูไปยังสรวงสวรรค์ / มาถึงสรวงสวรรค์"

⟪गुरू⟫ ⟪रामं⟫ ⟪वेदार्थं⟫ ⟪वेदयति⟫ = "อาจารย์ทำให้รามะรู้ความหมายของเวทา = อธิบาย / สอนรามะถึงความหมายของเวทา"
ผลลัพธ์: ⟪रामो⟫ ⟪वेदार्थं⟫ ⟪वेत्ति⟫ = "รามะรู้จัก / เข้าใจความหมายของเวทา"

⟪स⟫ ⟪रामं⟫ ⟪वेदमध्यापयति⟫ = "เขาสอนรามะเวทา"
ผลลัพธ์: ⟪रामो⟫ ⟪वेदमधीते⟫ "รามะศึกษาเวทา"

⟪रामो⟫ ⟪देवानामृतमाशयति⟫ = "รามะปล่อยให้เทพเจ้ากินอาหารอมตะ = ให้เทพเจ้ากินอาหารอมตะ" (⟪अश्⟩ 9 "กิน")
ผลลัพธ์: ⟪देवा⟫ ⟪अमृतमश्नन्ति⟫ "เทพเจ้ากินอาหารอมตะ"

**แผนผัง 2:**

**สำหรับกริยาที่กกรรม (ยกเว้นกริยาที่ระบุในแผนผัง 1) นอกจากนี้ยังใช้กับกริยาทั้งหมด เมื่อสิ่งที่ถูกกล่าวถึงโดยรูป causative ถูกทำให้เกิดขึ้น (หากดังนั้นรูป causative จึงเป็น causative ของ causative):**

**ผู้กระทำ (⟪कर्ता⟫) ของรูป causative ในนามวิภัตติ (⟪प्रथमा⟫) — ผู้กระทำของการกระทำที่ถูกทำให้เกิดขึ้นในกรณีนามวิภัตติ (⟪तृतीया⟫) — วัตถุของการกระทำที่ถูกทำให้เกิดขึ้นในวิภัตตินั้น ซึ่งมันจะมีตามกริยาพื้นฐาน (นั่นคือ ส่วนใหญ่อยู่ในอรรถวิภัตติ) — กริยารูป causative**
:::
::: indent
ตัวอย่าง:
(⟪स⟫) ⟪रामेण⟫ ⟪भार्यां⟫ ⟪त्याजयति⟫ = "เขาทำให้ระมะละทิ้งภรรยาของเขา"
ผลลัพธ์: ⟪रामो⟫ ⟪भार्यां⟫ ⟪त्यजति⟫ = "ระมะละทิ้งภรรยาของเขา"

⟪विष्णुमित्रो⟫ ⟪रामेण⟫ ⟪गोविन्दं⟫ ⟪गमयति⟫ = "วิษณุมิตรทำให้ระมะละ ทำให้โกวินดาไป = วิษณุมิตร์ให้ระมะส่งโกวินดาออกไป"
ผลลัพธ์: ⟪रामो⟫ ⟪गोविन्दं⟫ ⟪गमयति⟫ = "ระมะส่งโกวินดาออกไป"
ผลลัพธ์ของผลลัพธ์นี้: ⟪गोविन्दो⟫ ⟪गच्छति⟫ = "โกวินดาไป"
:::
::: grammar-box
**ข้อยกเว้นต่อแผนผัง 1:**

**กริยาต่อไปนี้สร้างตามแผนผัง 2 ได้แก่:**

**Causative ของ:**
- **⟪नी⟫ "นำ"**
- **⟪वह्⟫ "เดินทาง" (เฉพาะเมื่อผู้กระทำของการกระทำที่ถูกทำให้เกิดขึ้นไม่ใช่คนขับ)**
- **⟪स्मृ⟫ "ทำให้ระลึกถึง" (มีข้อยกเว้นสำหรับเรื่องนี้)**
- **⟪अद्⟫ "กิน"**
- **⟪खाद्⟫ "เคี้ยว"**
:::
ตัวอย่าง:

⟪रामो⟫ ⟪भृत्येन⟫ ⟪भारं⟫ ⟪नाययति⟫ ⟪वाहयति⟫ ⟪वा⟫ = "ระมะให้คนใช้ขนหรือเดินทางกับภาระ"
ผลลัพธ์: ⟪भृत्यो⟫ ⟪भारं⟫ ⟪नयति⟫ ⟪वहति⟫ ⟪वा⟫ = "คนใช้ขนหรือเดินทางกับภาระ"

⟪रामो⟫ ⟪बालेनान्नमादयति⟫ ⟪खादयति⟫ ⟪वा⟫ = "ระมะให้เด็กกินหรือเคี้ยวอาหาร"
ผลลัพธ์: ⟪बालो⟫ ⟪ऽन्नमत्ति⟫ ⟪खादति⟫ ⟪वा⟫ = "เด็กกินหรือเคี้ยวอาหาร"

(⟪स⟫) ⟪रामेण⟫ ⟪स्मारयति⟫ = "เขาทำให้ระมะระลึกได้"
ผลลัพธ์: ⟪रामः⟫ ⟪स्मरति⟫ = "ระมะระลึกได้"

::: grammar-box
**Causative ต่อไปนี้สามารถสร้างได้ทั้งตามแผนผัง 1 และแผนผัง 2:**

- **⟪हृ⟫ "ถือ นำมา"**
- **⟪कृ⟫ "ทำ"**
- **Ātmanepadakausative ของ ⟪दृश्⟫**
:::
ตัวอย่าง:

⟪रामो⟫ ⟪भृत्यं⟫ ⟪कटं⟫ ⟪कारयति⟫ ⟪हारयति⟫ ⟪वा⟫ = "ระมะให้คนใช้ทำหรือขนเสื่อ (⟪कट⟫ ชาย) "
หรือ:
⟪रामो⟫ ⟪भृत्येन⟫ ⟪कटं⟫ ⟪कारयति⟫ ⟪हारयति⟫ ⟪वा⟫
ผลลัพธ์: ⟪भृत्यः⟫ ⟪कटं⟫ ⟪करोति⟫ ⟪हरति⟫ ⟪वा⟫ = "คนใช้ทำหรือขนเสื่อ"

⟪रामो⟫ ⟪बालं⟫ ⟪प्रतिमां⟫ ⟪दर्शयते⟫ = "ระมะให้เด็กเห็นภาพ = แสดงภาพแก่เด็ก (เพื่อประโยชน์ของตนเอง)"
หรือ:
⟪रामो⟫ ⟪बालेन⟫ ⟪प्रतिमां⟫ ⟪दर्शयते⟫
ผลลัพธ์: ⟪बालः⟫ ⟪प्रतिमां⟫ ⟪पश्यति⟫ = "เด็กเห็นภาพ"

หากใช้รูป causative ในโครงสร้าง passive จะพบการใช้แผนผังต่อไปนี้เกือบเสมอ:

::: grammar-box
**แผนผัง A (โครงสร้าง passive):**

**ผู้กระทำของ causative ในกรณีนามวิภัตติ (⟪तृतीया⟫) — ผู้กระทำของการกระทำที่ถูกทำให้เกิดขึ้นในนามวิภัตติ (⟪प्रथमा⟫) — วัตถุของการกระทำที่ถูกทำให้เกิดขึ้นในวิภัตตินั้น ซึ่งมันจะมีตามกริยาพื้นฐาน (นั่นคือ ส่วนใหญ่อยู่ในอรรถวิภัตติ) — กริยารูป causative**
:::
ตัวอย่าง:

⟪गुरुणा⟫ ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫ = "อาจารย์ส่งรามาไปยังหมู่บ้าน"
ผลลัพธ์: ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "รามาไปยังหมู่บ้าน"

⟪रामेण⟫ ⟪भृत्यः⟫ ⟪कटं⟫ ⟪कार्यते⟫ = "รามาให้ทาสีทำเสื่อ"
ผลลัพธ์: ⟪भृत्यः⟫ ⟪कटं⟫ ⟪करोति⟫ = "ทาสีทำเสื่อ"

⟪रामेण⟫ ⟪भृत्यो⟫ ⟪भारं⟫ ⟪हार्यते⟫ = "รามาให้ทาสีนำภาระ"
ผลลัพธ์: ⟪भृत्यो⟫ ⟪भारं⟫ ⟪हरति⟫ = "ทาสีนำภาระ"

## 28.3. การสร้างรากปัจจุบันของคำกริยาทำให้ (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**เติมส่วนท้ายของรากปัจจุบันที่มีลักษณะเป็นธีม (thematic endings) ลงที่รากคำกริยาทำให้**
:::
มีรูปแบบการสร้างหลายแบบ:

::: grammar-box
**รูปแบบการสร้างที่ 1: (ส่วนใหญ่) รากเสียงสูง + -aya-**
:::
ตัวอย่าง:

| ราก | คำกริยาทำให้ 3. เอกพจน์ บ่งชี้ ปัจจุบัน | ความหมาย |
| :--- | :--- | :--- |
| ⟪विश्⟫ | ⟪वेशयति⟫ | ทำให้เข้า, นำเข้าไป |
| ⟪लुभ्⟫ | ⟪लोभयति⟫ | ทำให้ปรารถนา, ทำให้มีราคะ, ล่อลวง |
| ⟪दृश्⟫ | ⟪दर्शयति⟫ | ทำให้เห็น = แสดงให้ดู |
| ⟪वृत्⟫ | ⟪वर्तयति⟫ | ทำให้หมุน, พลิก (transitive), กลิ้ง (transitive), ทำให้เริ่มเคลื่อนที่ |

:::

::: grammar-box
**การสร้างที่ผิดปกติ:**

**นักไวยากรณ์ท้องถิ่นถือว่ารูปแบบต่อไปนี้คือคำกริยาทำให้:**

- **han** : คำกริยาทำให้ **ghātayati**¹ "ทำให้ตาย, ฆ่า"
- **pā** 2 "คุ้มครอง": **pālayati**² "ข้าม, ช่วยชีวิต, ปกป้อง"
:::
หมายเหตุ:
1. **ghātayati** จริงๆ แล้วเป็นคำกริยาที่อนุพันธ์จากคำนาม **ghāta** ชาย "การตี" (denominative) และใช้แทนคำกริยาทำให้ของ **han**
2. **pālayati** เป็นคำกริยาทำให้ที่แท้จริง แต่มาจากราก **pṛ** 3 "ข้าม, ช่วยชีวิต, ปกป้อง": **pārayati** (pār-aya-ti) » **pālayati** (ในบางภูมิภาคของอินเดีย เสียง r ตรงกับ l ในบางแห่ง และในทางกลับกันเสียง l ตรงกับ r)

## 28.4. การสร้างรูปปัสสิฟ (⟪यक्⟫) จากคำkausativ

::: grammar-box
**การสร้างรูปปัสสิฟจากคำkausativ ทำได้ดังนี้:**

**รากkausativ โดยไม่มี -aya- + สuffix ปัสสิฟ -ya-**

ตัวอย่าง:
**bhāvyate** (bhāv-ya-te) "เขา/เธอ/มัน ถูกทำให้เกิดขึ้น"
**sthāpyate** (sthāp-ya-te) "เขา/เธอ/มัน ถูกตั้งไว้"
:::
ในขณะที่รูปปัสสิฟจากรากเดิมมักสร้างจากรากในระดับต่ำสุด (deep grade) รูปปัสสิฟของคำkausativ มักจะสังเกตได้จากความจริงที่ว่ามันสร้างจากรากในระดับสูงหรือระดับยาว (high/long grade)

## 28.5. การสร้างรูปอนาคต (⟪ऌट्⟫, ⟪भविष्यन्ती⟫ f.) จากคำkausativ

::: grammar-box
**รูปอนาคตของคำkausativ สร้างจากรากkausativ โดยที่ -a ท้ายสุดของ suffix kausativ จะหายไป:**

**-ay-iṣya-**

ตัวอย่าง:
**budh** อนาคต-kausativ: **bodhayiṣyati** (bodh-ay-i-ṣya-ti): "เขา/เธอ/มัน จะปลุก"
:::

## 28.6. การสร้างรูป PPP (⟪क्त⟫) จากคำkausativ

::: grammar-box
**รากkausativ ลงท้ายด้วย -ay (ไม่มี a ท้าย) + -i- + -ta**

ตัวอย่าง:
**gam** — **gamayati** — **gamita** (gam-i-ta) "ถูกส่ง" (PPP ของรากธรรมดา: **gata**)
**sthā** — **sthāpayati** — **sthāpita** (sthāp-i-ta) "ถูกตั้งไว้"
:::

## 28.7. การสร้างรูป Absolutive (⟪क्त्वा⟩ . ⟪ल्यप्⟫) จากคำkausativ

::: grammar-box
**รูป Absolutive ลงท้ายด้วย -tvā สร้างจากรากkausativ ลงท้ายด้วย -ay (ไม่มี a ท้าย):**

**รากkausativ ลงท้ายด้วย -ay + -i- + -tvā**

ตัวอย่าง:
**sthāpayitvā** (sthā-pay-i-tvā) "หลังจากที่เขาตั้งไว้แล้ว"
:::
::: grammar-box
**รูป Absolutive ลงท้ายด้วย -ya มักจะปรากฏกับคำkausativ ที่มี prefix โดยต่อเข้ากับรากkausativ โดยไม่มี -aya-**

ตัวอย่าง:
**prabudh** — **prabodhayati** — **prabodhya** (pra-bodh-ya) "หลังจากที่เขาปลุกแล้ว"
**ānī** — **ānayati** — **ānāyya** (ā-nāy-ya) "หลังจากที่เขาอนุญาตให้พาเข้ามาแล้ว, หลังจากที่เขาอนุญาตให้นำมาแล้ว"
:::
::: grammar-box
**อย่างไรก็ตาม หากพยางค์รากของคำkausativ มี -a สั้นนำหน้าด้วยพยัญชนะเดียว รูป -ya ของ Absolutive จะต่อเข้ากับรากkausativ ลงท้ายด้วย -ay (ไม่มี a ท้าย)**

ตัวอย่าง:
**āgam** — **āgamayati** — **āgamayya** (ā-gamay-ya) "หลังจากที่เขาอนุญาตให้มาแล้ว"
:::

## 28.8. การสร้างรูป Infinitive (⟪तुमुन्⟫) จากคำkausativ

::: grammar-box
**รูป Infinitive จากคำkausativ สร้างจากรากkausativ ลงท้ายด้วย -ay (ไม่มี a ท้าย):**

**รากkausativ ลงท้ายด้วย -ay + -i- + -tum**

ตัวอย่าง:
**jan** — **janayati** — **janayitum** (janay-i-tum) "เพื่อสร้าง"
:::

## 28.9. กลุ่ม Present ที่ 10 (⟪चुरादि⟫ = ⟪चुर्⟫ ฯลฯ)

::: grammar-box
**ในลักษณะเดียวกับคำkausativ รากบางรากของกลุ่ม Present ที่ 10 สร้างรูป Present (และ tempus อื่นๆ) โดยไม่ถือเป็นคำkausativ**

ตัวอย่าง:
1.  รากระดับยาว (Dehnstufe) + -aya- : ⟪कम्⟫ 10Ā ⟪कामयते⟫ "รัก"
2.  รากระดับสูง (Guna) + -aya- : **cur** 10U **corayati** "ขโมย"; อนาคต: **corayiṣyate**; ปัสสิฟ: **coryate**
:::
::: grammar-box
**รูปของคำkausativ จากกริยาในกลุ่ม Present ที่ 10 นั้นเหมือนกับรูปของกริยธรรมดา การตัดสินใจว่านี่คือคำkausativ หรือไม่ สามารถทราบได้เพียงจากความหมาย หรือบางครั้งจากการใช้ประโยคเท่านั้น**
:::
