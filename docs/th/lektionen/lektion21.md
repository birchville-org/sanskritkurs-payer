## 21.1. รากปัจจุบันเพิ่มเติมที่มี -nt

### 21.1.1. วิภัตติการปัจจุบัน (⟪लडादेशः⟫) ปารัสไพบท

::: grammar-box
วิภัตติการนี้เป็นนามธรรมจากรากปัจจุบัน จึงเป็นวิภัตติการที่แท้จริง เป็นคำคุณศัพท์ที่ระบุว่าบุคคลหรือสิ่งใดกำลังกระทำสิ่งที่รากกริยา (+ ปรวิปฺป) แสดงไว้ ขณะที่มีเหตุการณ์อื่นเกิดขึ้น หรือสามารถแสดงสถานะถาวรได้

**ตัวอย่าง:**

:::
::: indent
"ขณะที่บิดาอ่าน เขาสูบบุหรี่ = บิดาที่กำลังอ่านกำลังสูบ"  
"มิตรที่ดำรงอยู่ (= จริง, แท้จริง)"
:::
::: grammar-box

## 21.3. รูปแบบสุภาพในการเรียกขาน

::: grammar-box
**ในภาษาสันสกฤต คุณสามารถเรียกบุคคลที่สองเอกพจน์ได้โดยไม่เสียมารยาท แต่หากต้องการความสุภาพ สามารถใช้คำนามที่มีความหมายว่า "ผู้ทรงเกียรติ" และอื่นๆ โดยเปลี่ยนกริยาเป็นบุรุษที่สามเอกพจน์หรือพหูพจน์ หรือใช้โครงสร้างประโยคแบบถูกกระทำ ระดับความสุภาพที่เพิ่มขึ้นในการเรียกขานตามบุรุษมีดังนี้:**

:::
::: indent
**บุรุษที่ 2 เอกพจน์ » บุรุษที่ 2 พหูพจน์ » บุรุษที่ 3 เอกพจน์ พร้อมคำนามที่เกี่ยวข้อง » บุรุษที่ 3 พหูพจน์ พร้อมคำนามที่เกี่ยวข้อง**
:::
**คำนามสุภาพที่สำคัญที่สุดคือ ⟪भवन्त्⟫ , เพศหญิง: ⟪भवती⟫ . มันทำหน้าที่เทียบเท่ากับ "ท่าน" (สุภาพ) ในภาษาไทย**
⟪भवन्त्⟫ นี้เป็นการรวมตัวจาก ⟪भगवन्त्⟫ การผันคำของมันคือการผันของคำนามลงท้ายด้วย **-vant** (ดู [บทเรียน 13](lektion13.md)) ⟪भवन्त्⟫ นี้ต้องแยกจากกริยาวิเศษณ์ปัจจุบัน P ของ ⟪भू⟫ "กลายเป็น" ⟪भवन्त्⟫ : รูปเอกพจน์เพศชายของ ⟪भवन्त्⟫ "ท่าน" คือ ⟪भवान्⟫ ส่วนของกริยาวิเศษณ์คือ ⟪भवन्⟫. 

**ตัวอย่าง:**

::: indent
**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = "ท่านต้องการอะไร?"
:::
สุภาพกว่า:

::: indent
**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**
:::
เพศหญิง:

::: indent
**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**
:::
คำอื่นๆ ที่สามารถใช้ในลักษณะเดียวกับ ⟪भवन्त्⟫ ได้:

*   ⟪आर्य⟫ (f.: ⟪आर्या⟫) "ผู้สูงศักดิ์" เช่น **⟪यदार्य⟫ ⟪इच्छति⟫** "ตามความต้องการของท่าน"
*   ⟪महाभाग⟫ "ผู้มีส่วนแบ่ง/โชคใหญ่ = ผู้มีเกียรติ" มักใช้โดยสตรีในการเรียกขานหรือกล่าวถึงผู้ชายที่มีสถานะดี ในภาษาสันสกฤตพูดสมัยใหม่พบได้บ่อยมาก

หากต้องการแสดงไม่เพียงแต่ความสุภาพ แต่ยังเป็นการเคารพต่อบุคคลหนึ่ง ใช้ ⟪भवन्त्⟫ ⟪अत्रभवन्त्⟫ สำหรับบุคคลที่มีอยู่หรืออยู่ในบริเวณใกล้เคียง และใช้ ⟪तत्रभवन्त्⟫ สำหรับบุคคลที่ขาดหายไปหรืออยู่ห่างไกล ⟪अत्रभवन्त्⟫ และ ⟪तत्रभवन्त्⟫ สามารถแปลว่า "ท่าน", "ผู้ทรงเกียรติ", "พระคุณเจ้า" ฯลฯ ได้:

::: indent
**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = "ภรรยาผู้เมตตา (ซึ่งอยู่ที่นี่) เป็นคู่สมรสของท่านหรือไม่?"  
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (ในจดหมายหรือโทรศัพท์) = "ท่านสบายดีหรือไม่?"
:::
