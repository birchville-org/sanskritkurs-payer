# บทที่ 38

## 38.1. สุภาษิตประจำสัปดาห์

⟪मनुस्मृति⟫ ⟪४⟫.⟪३२⟫ เกี่ยวกับการปัสสาวะที่ถูกวิธี:

::: indent
⟪प्रत्य⟫:sig[⟪ग्नि⟫] ⟪प्रतिसूर्यं⟫ ⟪च⟫  
⟪प्रतिसोमोदकद्विजम्⟫ ⟪।⟫  
⟪प्रति⟫:sig[⟪गु⟫] ⟪प्रतिवातं⟫ ⟪च⟫  
⟪प्रज्ञा⟫ ⟪नश्यति⟫ ⟪मेहतः⟫ ⟪॥⟫
:::
คำอธิบาย:

\-⟪अग्नि⟫ ลิงค์กลาง เอกพจน์ นาม/อรรถกถา สัมพันธ์กับ ⟪अग्नि⟫ ชาย

\-⟪गु⟫ ลิงค์กลาง เอกพจน์ นาม/อรรถกถา สัมพันธ์กับ ⟪गो⟫ ชาย-หญิง "วัว, แม่โค"

## 38.2. การเปลี่ยนแปลงเสียงของนาสิกในคำ

::: grammar-box
นาสิกในคำจะถูกทำให้คล้ายกับพยัญชนะที่ตามมา นั่นคือ พวกมันจะถูกแทนที่ด้วยนาสิกที่สอดคล้องกับพยัญชนะนั้น

หลัง c- และ j- -n- จะถูกแทนที่ด้วย -ñ-
:::
## 38.3. การผันคำศัพท์รากฐานที่มี -n

### 38.3.1. คำนามที่มี -an และคำนามที่มี -man หรือ -van หลังสระ
::: grammar-box
คำนามที่มี **-an** และคำนามที่มี **-man** หรือ **-van** หลังสระ มีสามรากศัพท์:

| รากศัพท์ | -an | -man | -van | การใช้งาน |
| :--- | :---: | :---: | :---: | :--- |
| **รากศัพท์เข้ม** | **-ān** | **-mān** | **-vān** | นาม., อรรถกถา, วัก. เอกพชาย-หญิง:brนาม., อรรถกถา, วัก. ทวิภาคชาย-หญิง:brนาม., วัก. พหูพจน์ ชาย-หญิง:brนาม., อรรถกถา พหูพจน์ กลาง |
| **รากศัพท์อ่อนปานกลาง** | **-a** :br(จาก -*n) | **-ma** :br(จาก -*mn) | **-va** :br(จาก -*vn) | กรณีอื่นๆ ก่อนท้ายคำที่ขึ้นต้นด้วยพยัญชนะ:brตัวเลือกสำหรับ Lok. เอกพชาย-กลาง-หญิง |
| **รากศัพท์อ่อนที่สุด** | **-n** | **-mn** | **-vn** | กรณีอื่นๆ ก่อนท้ายคำที่ขึ้นต้นด้วยสระ |

**ท้ายคำเป็นไปตามปกติ การสร้างนามเอกพชาย-หญิงจะไม่มีการลงท้ายด้วย -n**
:::
ตัวอย่าง:

⟪राजन्⟫ ชาย "ราชา"

*   รากศัพท์เข้ม: ⟪राजान्⟫
*   รากศัพท์ปานกลาง: ⟪राज⟫
*   รากศัพท์อ่อนที่สุด: ⟪राज्ञ्⟫

*   รากศัพท์อ่อนที่สุด: ⟪सीम्न्⟫

⟪नामन्⟫ กลาง "ชื่อ"

*   รากศัพท์เข้ม: ⟪नामान्⟫
*   รากศัพท์ปานกลาง: ⟪नाम⟫
*   รากศัพท์อ่อนที่สุด: ⟪नाम्न्⟫

### 38.3.2. คำนามที่มี -man หรือ -van หลังพยัญชนะ

::: grammar-box
*   Starker Stamm: -mān, -vān
*   รากศัพท์อ่อน:
    *   ก่อนรูปผันที่ขึ้นด้วยพยัญชนะ: -ma, -va (มาจาก -\*mn, -\*vn)
    *   ก่อนรูปผันที่ขึ้นด้วยสระ: **\-man, -van**

ส่วนการสร้างอื่น ๆ เป็นไปตามข้อ 3.1
:::
ตัวอย่าง:

*   รากศัพท์เข้ม: ⟪आत्मान्⟫
*   รากศัพท์อ่อน:
    *   ก่อนพยัญชนะ: ⟪आत्म⟫
    *   ก่อนสระ: ⟪आत्मन्⟫

⟪ब्रह्मन्⟫ น.: สิ่งสัมบูรณ์, เวยท, พราหฺมณ

*   รากศัพท์เข้ม: ⟪ब्रह्मान्⟫
*   รากศัพท์อ่อน:
    *   ก่อนพยัญชนะ: ⟪ब्रह्म⟫
    *   ก่อนสระ: ⟪ब्रह्मन्⟫

### 38.3.3. คำคุณศัพท์ชายและคำกลางลงท้ายด้วย -in, -min, -vin

## 38.4. การสร้างนาม: ⟪तद्धित⟫-อุปสรรค -in

::: grammar-box
ด้วยอุปสรรค (ซึ่งสำคัญมาก!) ⟪तद्धित⟫ **-in** สร้างคำคุณศัพท์จากคำนาม ในความหมาย:

**มีลักษณะโดย, มี**

เดิมทีการสร้างด้วยอุปสรรค **-⟪इन्⟫** แตกต่างจากการสร้างด้วย **-⟪मन्त्⟫/-⟪वन्त्⟫** ตรงที่ **-⟪इन्⟫** หมายถึงการมีลักษณะพิเศษ ในขณะที่ **-⟪मन्त्⟫/-⟪वन्त्⟫** หมายถึงการมี possession หรือลักษณะของสิ่งที่ธรรมดาหรือทั่วไป
:::
ตัวอย่าง:

⟪हस्तिन्⟫ ชาย.: ผู้ที่มีมือพิเศษเป็นเครื่องหมาย = ช้าง (เพราะมือของเขามิใช่มือธรรมดา แต่คืองวง)

## 38.5. ไวยากรณ์ของ ⟪नामन्⟫

::: grammar-box
เพื่อแสดงว่า "บุคคลชื่อ N. N." ให้สร้างโครงสร้างดังนี้:

**N.N. (ในกรณีประธาน) ⟪नाम⟫**

ความหมายตรงตัว: "ชื่อก็คือ/เคยเป็น N.N" ดังนั้นจึงเป็นการแทรกประโยคนาม (nominal sentence) เข้าไป
:::
ตัวอย่าง:

::: indent
⟪आसीद्राजा⟫ ⟪नलो⟫ ⟪नाम⟫ ⟪वीरसेनसुतो⟫ ⟪बली⟫ ⟪।⟫ "กาลครั้งหนึ่งนานมาแล้ว มีพระราชา **นามว่า นล** ผู้เป็นบุตรอันเข้มแข็งของวีระเสน"
:::
แน่นอนว่าสามารถแสดงสิ่งเดียวกันนี้ด้วย ⟪बहुव्रीहि⟫ ได้เช่นกัน:

::: indent
⟪देवदत्तनामा⟫ ⟪पुरुषः⟫ "บุรุษผู้ whose ชื่อคือเทวทัต"

⟪मदयन्तिकानाम्नी⟫ ⟪बाला⟫ "เด็กหญิงผู้ whose ชื่อคือมทายนติกะ"
:::

## 38.6. ไวยากรณ์ของ ⟪आत्मन्⟫

::: grammar-box
⟪आत्मन्⟫ **เพศชาย** สามารถใช้ใน **เอกพจน์** ในฐานะคำสรรพนามสะท้อน (reflexive pronoun) สำหรับทั้งสามเพศ พจน์ (รวมถึงทวิพจน์และพหูพจน์) และบุรุษได้
:::
ตัวอย่าง:

::: indent
⟪आत्मन्येषा⟫ ⟪दोषं⟫ ⟪न⟫ ⟪पश्यति⟫ ⟪।⟫ "นางไม่พบข้อบกพร่องในตัวนางเอง"

⟪आत्मानं⟫ ⟪स्तुवन्ति⟫ ⟪।⟫ "พวกเขาชมเชยตนเอง"
:::
::: grammar-box
วิภัตติการที่ 6 (⟪षष्ठी⟫) ⟪आत्मनस्⟫ สามารถอยู่แทนคำว่า "ของฉัน/ของเธอ/ของเขา... ของตนเอง" ได้
:::
ตัวอย่าง:

::: indent
⟪आत्मनो⟫ ⟪गृहं⟫ ⟪प्रविशति⟫ ⟪।⟫ "เขาเข้าสู่บ้านของเขาเอง"
:::
## 38.7. รากศัพท์ที่ลงท้ายด้วยพยัญชนะในฐานะส่วนหน้าของคำประสม

::: grammar-box
รากศัพท์ที่ลงท้ายด้วยพยัญชนะ จะปรากฏในฐานะส่วนหน้าของคำประสมในรูปของรากศัพท์ที่อ่อน (weak stem) ซึ่งเกิดขึ้นก่อนวิภัตติการ -su ของกรณีท้องถิ่น (⟪सप्तमी⟫) พหูพจน์
:::
ตัวอย่าง:

::: indent
