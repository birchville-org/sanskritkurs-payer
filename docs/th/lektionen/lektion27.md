# บทที่ 27

## 27.1. การใช้กรณียวิภัตติบทที่เจ็ด (⟪सप्तमी⟫ f. = "กรณียวิภัตติบทที่เจ็ด")

::: grammar-box

**กรณียวิภัตติบทที่เจ็ด (⟪सप्तमी⟫) ใช้ตอบคำถามว่า:**
*   **ที่ไหน?**
*   **เมื่อไหร่?**
*   **ภายใต้เงื่อนไขใด?**
*   **ในแง่ของอะไร?**

:::
::: grammar-box

**1. กรณียวิภัตติบทที่เจ็ด (⟪सप्तमी⟫) ใช้ตอบคำถาม "ที่ไหน?" เพื่อบอกสถานที่ (ใน, ที่, บน, ใกล้กับ) ซึ่งกัมมการิก (⟪कर्ता⟫) หรือวัตถุของกริยาตั้งอยู่ หรือที่ตัวการกระทำนั้นเกิดขึ้น**

> ⟪नगरे⟫ ⟪वसति⟫ = "เขาอาศัยอยู่ในเมือง"

:::
::: media
![](/images/lekt2701.webp)
Abb.: ⟪जयपुरनगरे⟫
ไจปูร์, ค.ศ. 1875
(แหล่งที่มาของภาพ: [รายละเอียด](/th/licenses#lekt2701))
:::

::: grammar-box

**2. กรณียวิภัตติบทที่เจ็ดใช้ตอบคำถาม "เมื่อไหร่?" เพื่อบอกเวลาหรือเงื่อนไขภายนอก:**

> ⟪तस्मिन्काले⟫ = "ณเวลานั้น, ในขณะนั้น"

**ในหมวดนี้ยังรวมถึงสิ่งที่เรียกว่า Locativus Absolutus:**

**หากการกระทำหรือสถานะของบุคคลหรือสิ่งหนึ่งกำหนดเวลา - หรือเงื่อนไขที่ - บุคคลหรือสิ่งอื่นทำการกระทำใด ๆ หรืออยู่ในสถานะเฉพาะ คำที่บ่งชี้บุคคลหรือสิ่งแรกนั้น จะรวมกับคำที่กำหนดความหมายเดียวกัน (ซึ่งมักจะเป็นกริยาวิเศษณ์) อยู่ในรูปกรณียวิภัตติบทที่เจ็ด (⟪सप्तमी⟫):**

> ⟪एवं⟫ ⟪गच्छति⟫ ⟪काले⟫ = "ขณะที่เวลาผ่านไป..."
>
> ⟪तस्मिन्गते⟫ = "เมื่อเขาไปแล้ว..."

**บางครั้งกัมมการิก (⟪कर्ता⟫) ไม่ได้ระบุไว้ชัดเจน:**

> ⟪एवं⟫ ⟪सति⟫ = "เนื่องจากสถานการณ์เป็นเช่นนี้"

**Locativus absolutus ต้องแปลตามบริบทด้วยคำว่า "ขณะ" (เช่น กริยาวิเศษณ์ปัจจุบัน), "หลังจาก", "เมื่อ" (เช่น PPP), "เนื่องจาก", "เพราะว่า", "แม้ว่า", "ถ้าหาก" เป็นต้น**

**ข้อควรจำ: ในกรณีของ Absolutivum กัมมการิกของ Absolutivum และกัมมการิกของประโยคหลักต้องเหมือนกัน แต่ในกรณีของ Locativus absolutus กัมมการิกของ Locativus absolutus และกัมมการิกของกริยาหลักต้องแตกต่างกัน**

> ⟪भू⟫ ⟪सत्तायाम्⟫ = "รากศัพท์ ⟪भू⟫ ในความหมาย 'ความเป็นอยู่' (sat-tā)"

## 27.2. การสร้างกรณียวิภัตติบทที่เจ็ด (⟪सप्तमी⟫)

::: grammar-box

**วิภัตติบทปกติของกรณียวิภัตติบทที่เจ็ด (⟪सप्तमी⟫) คือ:**
*   **เอกพจน์: -i**
*   **พหูพจน์: -su**

**โปรดสังเกตการเปลี่ยนแปลงของเสียงก่อน -su รวมถึงความเป็นไปได้ที่ -su จะเปลี่ยนเป็น -ṣu!**

**คำแปล:**
1. **โนมิเนทีฟ:** รามะ อัญมณี (⟪मणि⟫ ชาย.) ในหมู่พระราชา (⟪राजन्⟫ ชาย.) ชัยชนะเสมอ (⟪सदा⟫).
2. **อักคูแซทีฟ:** ฉันรัก (⟪भज्⟫ 1U) รามะ ผู้เป็นเจ้านายและสามี (⟪ईश⟫ ชาย.) ของรามะ (= ลักษมี).
3. **อินสตรูเมนทาเลีย:** รามะได้สังหารกองทัพ (⟪चमू⟫ หญิง.) ของผู้เร่ร่อนกลางคืน (= ปีศาจ) (⟪निशा⟫ หญิง. = กลางคืน).
4. **ดาทีฟ:** ขอความเคารพต่อรามะนี้!
5. **อับลาทีฟ:** ไม่มีที่พึ่งที่ดีกว่า (⟪परतर⟫ 3) รามะ
6. **เจเนทีฟ:** ฉัน (⟪अहम्⟫) เป็น (⟪अस्मि⟫) ทาสของรามะ.
7. **ลอกาทิ:** ในรามะ ขอให้ความสงบ (⟪भवतु⟫) เสมอเป็นของหัวใจของฉัน (⟪लय⟫ ชาย.) ของฉัน (⟪मे⟫)
8. **โวเคทีฟ:** รามะ โปรดช่วย (⟪उद्धर⟫ = คำสั่งต่อกริยาสำหรับ ⟪उद्⟫ + ⟪हृ⟫ หรือ ⟪उद्⟫ + ⟪धृ⟫) ฉัน (⟪माम्⟫)!

## 27.6. แบบฝึกหัด

**A) จงใส่สำนวนในวงเล็บลงใน locative (⟪सप्तमी⟫) เอกพจน์ และ - หากสมเหตุสมผล - พหูพจน์ ในประโยคต่อไปนี้ โปรดสังเกต Sandhi ที่แตกต่างกัน กล่าวคือ จงเขียนประโยคเต็มทุกครั้ง!**

⟪रामस्⟫ ... ⟪वसति⟫ ⟪।⟫ (⟪ग्राम⟫ ⟪।⟫ ⟪गुरु⟫ ⟪।⟫ ⟪सत्यवान्कविः⟫ ⟪।⟫ ⟪पुत्रं⟫ ⟪लब्धुकामा⟫ ⟪ब्राह्मणी⟫ ⟪।⟫ ⟪गृह⟫ ⟪।⟫ ⟪तन्नगरम्⟫ ⟪।⟫ ⟪मुह्यञ्छत्रुः⟫)
