# แบบฝึกหัด 58

## ก) การแปลงรูปไวยากรณ์ของ iṣ-Aorist

12.  ⟪अर्हन्ति⟫ - ⟪अर्ह्⟫ 1P 3.pl.Ind.Präs.P พวกเขาสมควร - ⟪आर्हिषुः⟫
13.  ⟪ऊदुः⟫ - ⟪वद्⟫ 1P 3.pl.Perf.P พวกเขาพูด - ⟪अवादिषुः⟫
14.  ⟪इन्त्से⟫ - ⟪इन्ध्⟫ 7Ā 2.sg.Ind.Präs,Ā คุณจุด - ⟪ऐन्धिष्ठाः⟫
15.  ⟪आध्वे⟫ - ⟪आस्⟫ 2Ā 2.pl.Ind.Präs.ġ พวกคุณนั่ง -⟪आसिध्वम्⟫
16.  ⟪कल्पे⟫ - ⟪कॢप्⟫ 1.sg.Ind.Präs.Ā ฉันเหมาะสม -⟪अकल्पिषि⟫
