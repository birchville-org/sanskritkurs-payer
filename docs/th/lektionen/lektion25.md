# บทที่ 25

## 25.1. การสร้างกรรตุการก (⟪पञ्चमी⟫ = "วิภัตติที่ห้า")

::: grammar-box
ยกเว้นคำนามเพศชาย/กลางที่ลงท้ายด้วย -a และสรรพนาม ในเอกพจน์ รูปแบบกรรตุการก (⟪पञ्चमी⟫) ในทุกหมวดคำกร่อนตรงกันกับรูปสัมพันธการก (⟪षष्ठी⟫)

ยกเว้นสรรพนามบุรุษรูป ในพหูพจน์ รูปแบบกรรตุการกในทุกหมวดคำกร่อนตรงกันกับรูปสัมโพธนาการก (⟪चतुर्थी⟫)
:::
ตอนนี้ท่านจะเห็นเหตุผลของลำดับวิภัตติ (⟪विभक्ति⟫) ในภาษาสันสกฤต:ถูกจัดเรียงไว้เพื่อให้รูปที่ออกเสียงเหมือนกันอยู่ใกล้กันหรือซ้อนทับกันมากที่สุด

::: grammar-box
**กรรตุการกเอกพจน์ของคำนามเพศชาย/กลางที่ลงท้ายด้วย -a**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
สรรพนามคำถาม สัมพันธะ และแสดง:

| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |

## 25.2. การใช้กรรตุการก (⟪पञ्चमी⟫)

"กรรตุการกหมายถึงสิ่งที่ยังคงอยู่เมื่อมีบางสิ่งเคลื่อนที่ออกไปจากมัน"

ปาณินิ 2,3,28 + 1,4,24

กรรตุการกใช้ตอบคำถามหลักๆ ว่า "จากที่ไหน?" และ "ทำไม?"

::: grammar-box
1\. กรรตุการกจึงหมายถึงจุดเริ่มต้น แหล่งที่มา และวัสดุ

ดังนั้นกรรตุการกยังสามารถระบุบุคคลที่ซื้อ ฟัง หรือขอสิ่งของจากเขาได้
:::
ตัวอย่าง:

::: indent
⟪ग्रमादागच्छति⟫ = "เขามาจากหมู่บ้าน"

⟪अश्वात्पतितः⟫ = "ตกจากหลังม้า"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "ได้รับจากพวกเขา"
:::
ตัวอย่าง:

::: indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟫ = "เขาฟังธรรมจากอาจารย์"

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = "พราหมณ์ขอวัวนมจากกษัตริย์"
:::
::: grammar-box
2\. กรรตุการกใช้กับกริยาที่มีความหมายว่า "ป้องกันจาก" "ปกป้องจาก" "ต่อสู้กับ" "กลัวต่อ":
:::
ตัวอย่าง:

::: indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = "เขาปกป้องจากศัตรู"
:::
::: grammar-box
3\. กรรตุการกหมายถึงเหตุผลหรือสาเหตุ:
:::
ตัวอย่าง:

::: indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = "เขาฆ่าลูกชายของตนด้วยความโกรธ"

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = "เพราะเขาทำชั่ว เขาจึงตกนรก" (« เพราะผู้ทำให้ความชั่วเกิดขึ้น»)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = "เพราะเขาทำชั่ว / เคยทำชั่ว เขาจึงตกนรก"
:::
คำนามที่ไม่ใช่เพศหญิงสามารถอยู่ในเครื่องมือการก (⟪तृतीया⟫) หรือกรรตุการก (⟪पञ्चमी⟫) เพื่อระบุเหตุผลของกิจกรรมได้ โดยทั่วไปเพศหญิงอยู่ในเครื่องมือการก แต่บางครั้งก็อาจอยู่ในกรรตุการกได้

## 25.3. สuffix -⟪तस्⟫

::: grammar-box
หากต้องการแสดงอย่างชัดเจนในรูปเอกพจน์ว่าคำนี้ใช้ในความหมายเชิง Ablative (การแยกออก/จาก) สามารถเติมส่วนต่อท้าย -⟪तस्⟫ ลงที่รากศัพท์ ซึ่งทำหน้าที่สร้างคำวิเศษณ์ที่มีความหมายเชิง Ablative เป็นหลัก (ตอบคำถาม "จากที่ไหน?"):
:::
ตัวอย่าง:

::: indent
⟪आदितस्⟫ = "ตั้งแต่ต้นจนจบ"

⟪धर्मतस्⟫ = "เนื่องจากธรรมะ, โดยอาศัยธรรมะ"
:::
::: grammar-box
ส่วนต่อท้าย -⟪तस्⟫ ยังปรากฏอยู่หลังรากคำสรรพนามอีกด้วย:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "จากที่นั่น, ที่นั้น, ไปที่นั่น, เกี่ยวกับสิ่งนั้น, จากนั้น, ด้วยเหตุนี้"

⟪यद्⟫ : ⟪यतस्⟫ "จากใด, จากสิ่งใด, จากที่ไหน, ที่ไหน, ไปที่ใด, ด้วยเหตุใด, เพราะ" (เชิงสัมพันธ์)

⟪किम्⟫ :  ⟪कुतस्⟫ "จากที่ไหน?" "ทำไม?"
:::
## 25.4. วิธีอื่นๆ ในการแสดงเหตุผล

::: grammar-box
**1\. ประโยคสัมพัทธ์**

ประโยคสัมพัทธ์มักแสดงความสัมพันธ์เชิงสาเหตุ (ให้เหตุผล), เชิงผลที่ตามมา (สรุปความ) หรือเชิงวัตถุประสงค์ (มุ่งหมาย) ต่อประโยคหลัก

รูปของคำสรรพนามสัมพัทธ์ที่ทำหน้าที่เป็นสันธานเชิงสาเหตุ:

*   เชิง Ablative:
    *   ⟪यतस्⟫ ... ประโยคย่อย ... ⟪ततस्⟫ ... ประโยคหลัก ... = "เพราะ ..., ดังนั้น ..."
    *   ⟪यस्मात्⟫ ... ประโยคย่อย ... ⟪तस्मात्⟫ ... ประโยคหลัก ... = "เพราะ ..., ดังนั้น ..."
*   เชิง Instrumental:
    *   ⟪येन⟫ ... ประโยคย่อย ... ⟪तेन⟫ ... ประโยคหลัก ... = "โดยที่/เพราะ ..., ดังนั้น/ด้วยเหตุนี้ ..."
:::
ตัวอย่าง:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = "เนื่องจากพระรามปรารถนาความมั่งคั่ง ท่านจึงปฏิบัติคำปฏิญาณ"
:::
::: grammar-box
**2\. ⟪हि⟫**

ประโยคหลักสามารถเชื่อมโยงกันด้วยอนุภาค ⟪हि⟫ "เพราะว่า, เนื่องจาก" ประโยคที่มี ⟪हि⟫ (ซึ่งไม่สามารถอยู่ตำแหน่งแรกได้ แต่ต้องอยู่ในตำแหน่งที่สองในภาษาเขียน) ระบุเหตุผลสำหรับประโยคก่อนหน้าหรือประโยคถัดไป:
:::
ตัวอย่าง:

::: indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = "ประชาชนกระทำกุศล เพราะพวกเขาต้องการไปสวรรค์"
:::
::: grammar-box
**3\. Instrumental (⟪तृतीया⟫)**

นอกเหนือจาก Ablative (⟪पञ्चमी⟫) แล้ว Instrumental (⟪तृतीया⟫) ยังใช้เพื่อระบุสาเหตุหรือเหตุผลอีกด้วย สำหรับคำนามเพศหญิง Instrumental โดยทั่วไปเป็นสิ่งที่จำเป็น
:::
ตัวอย่าง:

::: indent
⟪क्रोधेन⟫ ⟪पुत्रं⟫ ⟪हन्ति⟫ = "เขาฆ่าลูกชายของตนด้วยความโกรธ" = "เขาฆ่าลูกชายของตนในอารมณ์โกรธ"
:::
::: grammar-box
**4\. คำนาม**

นอกจากนี้สามารถแสดงเหตุผลได้ผ่านโครงสร้างที่มี

*   ⟪कारण⟫ น. "สาเหตุ": ⟪कारणात्⟫ ⟪।⟫ ⟪कारणेन⟫
*   ⟪हेतु⟫ ก.
*   คำนามอื่นๆ ในความหมาย "สาเหตุ"

Genetive (⟪षष्ठी⟫) หรือเป็นองค์ประกอบหลังของคำประสม:
:::
ตัวอย่าง:

::: indent
⟪पुण्यस्य⟫ ⟪कारणात्⟫ (⟪हेतोः⟫ ฯลฯ) = "เนื่องจากบุญกุศล"
:::
::: grammar-box
**5\. ⟪इति⟫**

แรงจูงใจสำหรับกิจกรรมสามารถระบุได้ว่าเป็นความคิดด้วย ⟪इति⟫:
:::
ตัวอย่าง:

::: indent
⟪सम्यक्संबुद्धः⟫ ⟪सुगत⟫ ⟪इत्यानन्दो⟫ ⟪गौतमं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫  = "เนื่องจากพระสุคตะตื่นรู้ต่อความจริงอย่างสมบูรณ์แล้ว อานนท์จึงถามโกตมะเกี่ยวกับคำสอนของท่าน" (« "โดยคิดว่า 'พระสุคตะตื่นรู้ต่อความจริงอย่างสมบูรณ์แล้ว' ...")
:::
