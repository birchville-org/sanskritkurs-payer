# แบบฝึกหัด 14

จงแปลสุภาษิตต่อไปนี้และจำให้ขึ้นใจ:

⟪निचो⟫ ⟪वदति⟫ ⟪न⟫ ⟪कुरुते⟫  
⟪वदति⟫ ⟪न⟫ ⟪साधुः⟫ ⟪करोत्येव⟫ ⟪॥१॥⟫  
บุคคลต่ำช้าไม่พูดและไม่กระทำ บุคคลดีไม่พูดแต่กระทำการ

⟪शीलं⟫ ⟪नरस्य⟫ ⟪भूषणम्⟫ ⟪॥२॥⟫  
คุณธรรมคือเครื่องประดับของมนุษย์

⟪सत्येन⟫ ⟪जनानां⟫ ⟪सुखं⟫ ⟪भवति⟫ ⟪॥३॥⟫  
ด้วยความจริง มนุษย์ย่อมได้รับความสุข

⟪पापा⟫ ⟪नराः⟫ ⟪स्वर्गं⟫ ⟪न⟫ ⟪लभन्ते⟫ ⟪॥४॥⟫  
มนุษย์ชั่วร้ายไม่เข้าสู่สรวงสวรรค์

⟪सत्यं⟫ ⟪लोकस्य⟫ ⟪दीपः⟫ ⟪॥५॥⟫  
ความจริงคือแสงสว่างของโลก

ก) จงสร้างกรณวิภัตติเอกพจน์และพหูพจน์สำหรับคำต่อไปนี้ พร้อมระบุความหมายและเพศของคำ:

⟪१⟫. ⟪अनृत⟫ : น. ความไม่จริง — ⟪अनृतस्य⟫ ⟪अनृतानाम्⟫

⟪२⟫. ⟪ऋषि⟫ : ม. ฤๅษีในพระเวท — ⟪ऋषेः⟫ ⟪ऋषीणाम्⟫

⟪३⟫. ⟪पाद⟫ : ม. เท้า — ⟪पादस्य⟫ ⟪पादानाम्⟫

⟪४⟫. ⟪बुद्धि⟫ : อ. ความรู้ — ⟪बुद्धेः⟫ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम्⟫

⟪५⟫. ⟪गुरु⟫ : ม. อาจารย์ — ⟪गुरोः⟫ ⟪गुरूणाम्⟫

⟪६⟫. ⟪स्वर्ग⟫ : ม. สวรรค์ — ⟪स्वर्गस्य⟫ ⟪स्वर्गाणाम्⟫

⟪७⟫. ⟪नगर⟫ : น. นคร — ⟪नगरस्य⟫ ⟪नगराणाम्⟫

⟪८⟫. ⟪धेनु⟫ : อ. โค — ⟪धेनोः⟫ (⟪धेन्वाः⟫) ⟪धेनूनाम्⟫

⟪९⟫. ⟪द्विज⟫ : ม. ผู้เกิดสองครั้ง — ⟪द्विजस्य⟫ ⟪द्विजानाम्⟫

⟪१०⟫. ⟪मुक्ता⟫ : อ. ผู้หลุดพ้น — ⟪मुक्तायाः⟫ ⟪मुक्तानाम्⟫

⟪११⟫. ⟪विद्या⟫ : อ. ความรู้ วิทยา — ⟪विद्यायाः⟫ ⟪विद्यानाम्⟫

⟪१२⟫. ⟪वर्ण⟫ : ม. วรรณะ — ⟪वर्णस्य⟫ ⟪वर्णानाम्⟫

⟪१३⟫. ⟪द्विजाति⟫ : 3 ผู้เกิดสองครั้ง — ⟪द्विजातेः⟫ (⟪द्विजात्याः⟫) ⟪द्विजातीनाम्⟫

⟪१४⟫. ⟪रूप⟫ : น. รูป — ⟪रूपस्य⟫ ⟪रूपाणाम्⟫

⟪१५⟫. ⟪प्रतिग्रह⟫ : ม. การรับ — ⟪प्रतिग्रहस्य⟫ ⟪प्रतिग्रहाणाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 การทน — ⟪सोढस्य⟫ ⟪सोढायाः⟫ ⟪सोढानाम्⟫

⟪१७⟫. ⟪नायिका⟫ : อ. คนรัก — ⟪नायिकायाः⟫ ⟪नयिकानाम्⟫

⟪१८⟫. ⟪साध्वी⟫ : อ. ผู้ศักดิ์สิทธิ์ — ⟪साध्व्याः⟫ ⟪साध्वीनाम्⟫

⟪१९⟫. ⟪अग्नि⟫ : ม. ไฟ — ⟪अग्नेः⟫ ⟪अग्नीनाम्⟫

⟪२०⟫. ⟪वैश्या⟫ : อ. หญิงไวศยะ — ⟪वैश्यायाः⟫ ⟪वैश्यानाम्⟫

⟪२१⟫. ⟪लोक⟫ : ม. โลก ประชาชน — ⟪लोकस्य⟫ ⟪लोकानाम्⟫

⟪२२⟫. ⟪उक्ति⟫ : อ. คำกล่าว — ⟪उक्तेः⟫ (⟪उक्त्याः⟫) ⟪उक्तीनाम्⟫

⟪२३⟫. ⟪शत्रु⟫ : ม. ศัตรู — ⟪शत्रोः⟫ ⟪शत्रूणाम्⟫

⟪२४⟫. ⟪सुखवन्त्⟫ : 3 มั่งคั่ง — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : อ. หญิงที่มีบุตรหนึ่งคนหรือมากกว่า — ⟪पुत्रवत्याः⟫ ⟪पुत्रवतीनाम्⟫

⟪२६⟫. ⟪जल⟫ : น. น้ำ — ⟪जलस्य⟫ ⟪जलानाम्⟫

⟪२७⟫. ⟪मार्ग⟫ : ม. เส้นทาง — ⟪मर्गस्य⟫ ⟪मर्गाणाम्⟫

⟪२८⟫. ⟪मोक्ष⟫ : ม. การหลุดพ้น — ⟪मोक्षस्य⟫ ⟪मोक्षाणाम्⟫

⟪२९⟫. ⟪शूद्रा⟫ : อ. หญิงศูทร — ⟪शूद्रायाः⟫ ⟪शूद्राणाम्⟫

⟪३०⟫. ⟪अन्न⟫ : น. อาหาร — ⟪अन्नस्य⟫ ⟪अन्नानाम्⟫

⟪३१⟫. ⟪साधु⟫ : ม. นักบวช — ⟪साधोः⟫ ⟪साधनाम्⟫

⟪३२⟫. ⟪नीति⟫ : อ. การนำทาง — ⟪नीत्याः⟫ ⟪नीतीनाम्⟫

⟪३३⟫. ⟪योध⟫ : ม. นักสู้ ทหาร — ⟪योधस्य⟫ ⟪योधानाम्⟫

⟪३४⟫. ⟪सत्यवन्त्⟫ : 3 จริงใจ — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : ม. ผลประโยชน์ — ⟪लाभस्य⟫ ⟪लाभानाम्⟫

⟪३६⟫. ⟪मोह⟫ : ม. ความสับสน ความหลงผิด — ⟪मोहस्य⟫ ⟪मोहानाम्⟫

⟪३७⟫. ⟪गति⟫ : อ. การเดิน จุดหมาย — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम्⟫

⟪३८⟫. ⟪प्रश्न⟫ : ม. คำถาม — ⟪प्रश्नस्य⟫ ⟪प्रश्नानाम्⟫

⟪३९⟫. ⟪सृष्टि⟫ : อ. การสร้างสรรค์ — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम्⟫

⟪४०⟫. ⟪नेत्र⟫ : น. ตา — ⟪नेत्रस्य⟫ ⟪नेत्राणाम्⟫


⟪४१⟫. ⟪गुरुता⟫ : f. ความชำนาญ — ⟪गुरुतायाः⟫ ⟪गुरुतानाम्⟫

⟪४२⟫. ⟪ईश्वर⟫ : m. พระเจ้า — ⟪ईश्वरस्य⟫ ⟪ईश्वराणाम्⟫

⟪४३⟫. ⟪कारण⟫ : n. สาเหตุ — ⟪कारणस्य⟫ ⟪कारणानाम्⟫

⟪४४⟫. ⟪कृत⟫ : 3 กระทำ — ⟪कृतस्य⟫ (⟪कृतायाः⟫) ⟪कृतानाम्⟫

⟪४५⟫. ⟪धर्मवन्त्⟫ : 3 ยุติธรรม, ศีลธรรม — ⟪धर्मवतः⟫ (⟪धर्मवत्याः⟫) ⟪धर्मवताम्⟫ (⟪धर्मवतीनाम्⟫)

⟪४६⟫. ⟪युद्ध⟫ : 3 ต่อสู้ — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम्⟫

⟪४७⟫. ⟪दर्शन⟫ : n. การเห็น, ปรากฏ — ⟪दर्शनस्य⟫ ⟪दर्शनानाम्⟫

⟪४८⟫. ⟪धातु⟫ : m. ธาตุ, รากศัพท์ — ⟪धातोः⟫ ⟪धातूनाम्⟫

⟪४९⟫. ⟪गूढा⟫ : f. ผู้ซ่อนเร้น — ⟪गूढायाः⟫ ⟪गूढानाम्⟫

⟪५०⟫. ⟪ईष्टा⟫ (2 ความหมาย): f. ผู้ปรารถนา, ผู้ถูกบูชา — ⟪इष्टायाः⟫ ⟪इष्टानाम्⟫

⟪५१⟫. ⟪उदित⟫ : 3 กล่าว — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम्⟫

⟪५२⟫. ⟪इदम्⟫ : 3 นี้ — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 อะไร — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) จงแปล:

⟪१⟫. ⟪ब्राह्मणस्य⟫ ⟪पुत्रो⟫ ⟪ब्राह्मण्या⟫ ⟪ग्रामं⟫ ⟪गतः⟫ ⟪।⟫ (2 วิธี)
บุตรของพราหมณ์ได้ไปยังหมู่บ้านของพราหมณีแล้ว บุตรของพราหมณ์ได้เดินทางไปยังหมู่บ้านพร้อมกับพราหมณี

⟪२⟫. ⟪यज्ञस्याग्निनान्नं⟫ ⟪दग्धम्⟫ ⟪।⟫
ไฟบูชาได้เผาอาหาร

⟪३⟫. ⟪बुद्धः⟫ ⟪स्तयस्य⟫ ⟪बुद्ध्या⟫ ⟪मुक्तः⟫ ⟪।⟫
พุทธเจ้าได้รับการปลดปล่อยผ่านความรู้แจ้งในความจริง

⟪४⟫. ⟪अधर्मो⟫ ⟪ऽनृतस्य⟫ ⟪वदनमित्यृषयो⟫ ⟪वदन्ति⟫ ⟪।⟫
ปราชญ์แห่งพระเวทกล่าวว่า การพูดเท็จเป็นความผิด

⟪५⟫. ⟪नरा⟫ ⟪देवानां⟫ ⟪यज्ञैर्न⟫ ⟪मुच्यन्ते⟫ ⟪।⟫
มนุษย์ไม่ได้รับการปลดปล่อยผ่านการบูชาต่อเทพเจ้า

⟪६⟫. ⟪बलवन्तः⟫ ⟪क्षत्रियाः⟫ ⟪शत्रूणां⟫ ⟪धनवन्ति⟫ ⟪नगराणि⟫ ⟪जयन्ति⟫ ⟪।⟫
กษัตริย์ผู้ทรงพลังพิชิตเมืองอันอุดมสมบูรณ์ของศัตรู

⟪७⟫. ⟪कवेरुक्तिं⟫ ⟪शृण्वन्ति⟫ ⟪।⟫
พวกเขาได้ยินถ้อยคำของกวี

⟪८⟫. ⟪कविर्देव्याः⟫ ⟪कृतं⟫ ⟪वद⟫ti ⟪।⟫
กวีรายงานการกระทำของเทพี

⟪९⟫. ⟪द्विजाः⟫ ⟪पशोर्लाभमिच्छन्ति⟫ ⟪।⟫
ผู้เกิดสองครั้งปรารถนาที่จะได้รับปศุสัตว์

⟪१०⟫. ⟪रामः⟫ ⟪पुण्यवतो⟫ ⟪गुरोर्मन्त्रस्य⟫ ⟪स्मरति⟫ ⟪।⟫
รามาทรงระลึกถึงมนต์ของอาจารย์ผู้ทรงคุณธรรม

⟪११⟫. ⟪अयं⟫ ⟪बालः⟫ ⟪कस्याः⟫ ⟪पुत्रः⟫ ⟪।⟫
บุตรของใคร (f.) เป็นเด็กผู้ชายนี้?

⟪१२⟫. ⟪केषामिमानि⟫ ⟪गृहाणि⟫ ⟪।⟫
บ้านเหล่านี้เป็นของใคร?

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम्⟫ ⟪।⟫
อาหารของใครที่ปราชญ์แห่งพระเวทคนนี้ได้นำไปบูชา?
