# บทที่ 16

## 16.1. เกี่ยวกับสันดิของพยัญชนะท้ายคำ

เพื่อการสร้างคำสมาส (คอมโพสิต) ซึ่งส่วนหน้าเป็นรากศัพท์ที่มีพยัญชนะออกท้าย ต้องใช้กฎต่อไปนี้:

พยัญชนะหยุด (คอนโซแนนต์) ที่ออกท้าย เป็นเสียงกัณฐยะ (gutturals), มุทธะ (retroflexes), ทันตะ (dental) และโอष्ठยะ (labials) (นั่นคือ ไม่ใช่เสียงนาสิกและไม่ใช่เสียงเพดานกลาง palatals).
