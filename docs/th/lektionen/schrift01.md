# Devanāgarī = ⟪देवनागरी⟫

## แบบฝึกหัดการเขียนอักษร 1

ภาษาสันสกฤตถูกและยังคงถูกเขียนด้วยลายมือหลากหลายรูปแบบ ตารางสรุปด้านล่างแสดงตัวอย่างบางส่วนจากอักษรเหล่านี้:

![](/images/schrift001.webp)  
ภาพตัวอย่าง: ตัวอย่างอักษรภาษาสันสกฤต
\[แหล่งที่มาของภาพ: Wikipedia, ใบอนุญาต GNU FD\]

อักษรภาษาสันสกฤตทางเหนือของอินเดียสมัยใหม่ที่สำคัญที่สุดคืออักษรเทวนาครี:

![](/images/schrift002.webp)

สัญลักษณ์พยัญชนะแต่ละตัวจะรวมสระ "a" ที่ตามหลังพยัญชนะไว้ด้วย หากต้องการเขียนพยัญชนะล้วนๆ (ไม่มีสระตามมา) ต้องระบุโดยใช้เครื่องหมายขีดล่าง -- virāma = ⟪विराम⟫ -- เพื่อแสดงลักษณะนี้:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

สระที่ตามหลังพยัญชนะ -- ยกเว้น "a" -- จะเขียนดังนี้:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

ลำดับในการเขียนการผสมผสานระหว่างพยัญชนะ + สระเหล่านี้คือ:

![](/images/schrift003.jpg)

ในการเขียน แต่ละตัวอักษร รวมถึงเส้นแนวนอนด้านบน จะต้องเขียนให้สมบูรณ์ก่อนจึงจะเริ่มเขียนตัวอักษรถัดไป

## แบบฝึกหัด

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

อ่านและถอดเสียงเป็นอักษรโรมัน:

⟪तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ⟫

การอ่านเพิ่มเติม:

⟪पिता⟫ พ่อ, ⟪कपि⟫ ลิง, ⟪कृत⟫ ทำแล้ว, ⟪टीका⟫ คำอธิบายเสริม, ⟪तत्⟫ นี้, ⟪तट⟫ ฝั่ง, ⟪पत्⟫ ยิงไป, ⟪पट⟫ เนื้อผ้า, ⟪काच⟫ แก้ว, ⟪काकुत्⟫ เพดานปาก, ⟪चित्⟫ รับรู้, ⟪पृच्⟫ ผสม, ⟪पोटक⟫ ทาส, ⟪चेतु⟫ เจตนา, ⟪तौतातित⟫ ผู้ติดตามของกุมาริละ (มีมามสา), ⟪तूत⟫ ต้นหม่อน, ⟪पीत⟫ ดื่มแล้ว, ⟪पीति⟫ เครื่องดื่ม, ⟪कॢप्⟫ เหมาะสม, ⟪कृपते⟫ เขาคร่ำครวญ, ⟪पुटी⟫ รอยย่น, ⟪चापि⟫ เช่นกัน, ⟪तोक⟫ ลูกหลาน, ⟪तृपत्⟫ อิ่ม, ⟪पॄ⟫ เติมเต็ม, ⟪कृकाटी⟫ ข้อต่อคอ, ⟪पूपौ⟫ ขนมสองชิ้น, ⟪पैतृकी⟫ ฝ่ายบิดา (หญิง), ⟪कौट⟫ ฉ้อโกง, ⟪कच⟫ ผมบนศีรษะ, ⟪कुतपे⟫ บนผ้าห่มขนแพะ, ⟪कुचौ⟫ หน้าอก, ⟪चकिता⟫ ตกใจ (หญิง)
