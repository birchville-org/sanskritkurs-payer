# Devanāgarī = ⟪देवनागरी⟫

## แบบฝึกเขียนอักษร 1

ภาษาสันสกฤตถูกและยังคงได้รับการเขียนในชุดตัวอักษรมากมาย รายการต่อไปนี้แสดงตัวอย่างบางส่วนจากอักษรเหล่านี้:

![](/images/schrift001.webp)  
ภาพตัวอย่าง: ตัวอย่างอักษรสันสกฤต
\[แหล่งที่มาภาพ: Wikipedia, ใบอนุญาต GNU FD\]

![](/images/schrift002.webp)

สัญลักษณ์พยัญชนะแต่ละตัวหมายถึงสระ "a" ที่ตามหลังพยัญชนะนั้น หากต้องการเขียนเฉพาะพยัญชนะล้วนๆ (ไม่มีสระตามมา) ต้องระบุด้วยเครื่องหมายขีดล่าง -- วิรัมะ = ⟪विराम⟫ -- ดังนี้:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

สระอื่นๆ ที่ตามหลังพยัญชนะ (ยกเว้น "a") เขียนดังนี้:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kḷ, ⟪कॢ⟫  = kṝ <!-- TODO: Fallback translation -->

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau <!-- TODO: Fallback translation -->

ลำดับการเขียนคำผสมพยัญชนะ+สระเหล่านี้คือ:

![](/images/schrift003.jpg)

ในการเขียน จะ写完แต่ละตัวอักษร รวมถึงขีดแนวนอนบนเส้นขอบเขตด้านบน ก่อนที่จะเริ่มเขียนตัวถัดไป

## แบบฝึกหัด

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

อ่านและถอดเสียง:

⟪तॄ⟫ ⟪पाप⟫ ⟪चट्⟫ ⟪चि⟫ ⟪चाप⟫ ⟪पॄ⟫ ⟪पति⟫ ⟪पितृ⟫ ⟪कॢप्⟫ ⟪कृ⟫ ⟪कुप्⟫ ⟪कुतो⟫ ⟪चैक⟫ ⟪पुट⟫ ⟪पचति⟫ ⟪तौ⟫ ⟪पू⟫ ⟪चेत्⟫ ⟪पतति⟫ ⟪ततो⟫ ⟪तट⟫ ⟪तपति⟫ ⟪तु⟫ ⟪ते⟫ ⟪कृ⟫ ⟪पीतौ⟫

แบบฝึกอ่านเพิ่มเติม:

⟪पिता⟫ บิดา, ⟪कपि⟫ ลิง, ⟪कृत⟫ ทำแล้ว,  ⟪टीका⟫ อรรถกถาย่อย, ⟪तत्⟫ นี้, ⟪तट⟫ ฝั่งแม่น้ำ, ⟪पत्⟫ ยิงไปข้างหน้า, ⟪पट⟫ ผ้าทอ, ⟪काच⟫ แก้ว,  ⟪काकुत्⟫ เพดานปาก, ⟪चित्⟫ รับรู้, ⟪पृच्⟫ ผสมกัน,  ⟪पोटक⟫ ข้าราชการชั้นต่ำ, ⟪चेतु⟫ เจตนา, ⟪तौतातित⟫ ผู้ติดตามของคุมาริละ (มีมานสา), ⟪तूत⟫ ต้นหม่อน, ⟪पीत⟫ ดื่มแล้ว,  ⟪पीति⟫ เครื่องดื่ม, ⟪कॢप्⟫  เหมาะสมกับ, ⟪कृपते⟫ เขาคร่ำครวญ, ⟪पुटी⟫ รอยพับ, ⟪चापि⟫ เช่นกัน, ⟪तोक⟫ ลูกหลาน, ⟪तृपत्⟫ อิ่มแล้ว, ⟪पॄ⟫ เติมเต็ม, ⟪कृकाटी⟫ ข้อต่อคอ, ⟪पूपौ⟫ ขนมสองชิ้น, ⟪पैतृकी⟫ ฝ่ายบิดา (เพศหญิง), ⟪कौट⟫ ฉ้อโกง, ⟪कच⟫ ผมบนศีรษะ, ⟪कुतपे⟫ บนเสื่อขนแพะ, ⟪कुचौ⟫ หน้าอก, ⟪चकिता⟫ ตกใจ (เพศหญิง)
