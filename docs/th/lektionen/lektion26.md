# บทที่ 26

## 26.1. กฎการเปลี่ยนเป็นเสียงสมองส่วนหน้า (Cerebralisationsgesetz) สำหรับ -s- ภายในคำ

::: grammar-box
**-s-** จะถูกแทนที่ด้วย **-ṣ-** เมื่อ **k, r, l** หรือ **สระ** — ยกเว้น **a, ā** — นำหน้าโดยทันทีหรือคั่นด้วย ⟪अनुस्वार⟫ หรือ ⟪विसर्ग⟫ เพียงเล็กน้อย และตามหลังด้วยเสียงอื่นที่ไม่ใช่ **ṛ, r**

กฎ Sandhi นี้ยังใช้กับ **⟪दुस्⟫-** นำหน้าเสียงกักเพดานอ่อนและริมฝีปากที่ไร้เสียงในคำประสมอีกด้วย
:::
*ตัวอย่าง:*
::: indent
⟪तेषाम्⟫ (มาจาก: *te-sām*)

แต่: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. กฎการเปลี่ยนเป็นเสียงสมองส่วนหน้า (Cerebralisationsgesetz) สำหรับเสียงทันตะภายในคำ

::: grammar-box
เสียงกักทันตะจะถูกแทนที่ด้วยเสียงกักรetroflex ที่สอดคล้องกันเมื่ออยู่หลังเสียง retroflex (รวม **-ṣ-**):

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** เนื่องจาก **i** นำหน้า, **ṭh** เนื่องจาก **ṣ** ตามหลัง)*
:::
## 26.3. กฎ Wortsandhi สำหรับเสียงเพดานอ่อน, เสียงกักเพดานแข็ง, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

ดูตัวอย่างด้านล่าง
:::
## 26.4. กฎการลดทอนลมหายใจของ Grassmann (Grassmannsches Hauchdissimilationsgesetz)

::: grammar-box
**การที่ลมหายใจสองครั้ง (Aspirata - สระ - Aspirata) เกิดขึ้นติดกัน ส่งผลให้ลมหายใจของเสียงแรกหายไป:**

ตัวอย่าง:

:::
::: indent
\*dhu(gh) » du(g)h
:::
**หากเสียงที่สองสูญเสียลมหายใจไปเนื่องจากกฎทางเสียง เสียงแรกจะกลับมามีลมหายใจอีกครั้ง**

ตัวอย่าง: ดูด้านล่าง รูปอนาคตของ  ⟪दुह्⟫ และ  ⟪बुध्⟫

## 26.5. วอร์ทซานธิสำหรับ -m, -n หน้าเสียงเสียดสี

::: grammar-box
**หน้าเสียงเสียดสี -n และ -m จะถูกแทนที่ด้วย -ṃ-:**

ตัวอย่าง: ดูด้านล่าง อนาคตของ ⟪मन्⟫
:::
## 26.6. การใช้อนาคตธรรมดา (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ หญิง)

::: grammar-box
**อนาคตธรรมดา (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ หญิง) แสดงถึง:**

**อนาคต**
**การกระทำที่ตั้งใจหรือต้องการ ("ฉันจะไป", "ฉันอยากไป")**
**ความคาดหวัง ("มันจะเกิดขึ้นเช่นนั้น")**
**ความหวัง**
**ความกลัว**
**ความเป็นไปได้**
**ความคิดเห็นของผู้พูด**
**คำสั่ง**

**อนาคตอยู่ในสถานะแข่งขันกับออปติทีฟ (ดูเพิ่มเติมในภายหลัง)**
:::
ตัวอย่าง ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = "บุคคลที่ต้องการทำคำปฏิญาณ ไปที่วัด"

## 26.7. การสร้างอนาคตธรรมดา (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ หญิง)

::: grammar-box
**อนาคตธรรมดา:**

:::
::: indent
**รากอนาคต + การลงท้ายปฐม**
:::
::: grammar-box
**รากอนาคต:**

:::
::: indent
**(ส่วนใหญ่) รากเสียงสูง + -sya**  
**หรือ**  
**(ส่วนใหญ่) รากเสียงสูง + -i- + -sya (= - iṣya)**
:::
**รากใดมีรูปแบบการสร้างรากอนาคตอย่างไร ต้องเรียนรู้จากรูปแบบราก!**  
**โดยทั่วไป รูปแบบรากและสระเชื่อมของอนาคตจะตรงกับอินฟินิตีฟ**  
**บางรากสามารถสร้างอนาคตได้ทั้งแบบมีและไม่มีสระเชื่อม -i-**  
**พาร์ทิซิป ปารัสไมปะดา ของอนาคตสร้างโดยการเติมส่วนขยาย -nt- ที่รากอนาคต เพศหญิงอาจใช้ -ntī หรือ -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
ตัวอย่าง:

::: grammar-box

| รากศัพท์ | อนาคตกาล บุรุษที่ 3 เอกพจน์ ป (ปารัสไพบท, Ā) |
| :--- | :--- |
| ⟪नी⟫ | ⟪नेष्यति⟫ |
| ⟪भू⟫ | ⟪भविष्यति⟫ (⟪भो⟫ +  ⟪इ⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दिश्⟫ | ⟪देक्ष्यति⟫ (⟪देश्⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दृश्⟫ | ⟪द्रक्ष्यति⟫ |
| ⟪पच्⟫ | ⟪पक्ष्यति⟫ |
| ⟪प्रच्छ्⟫ | ⟪प्रक्ष्यति⟫ |
| ⟪यज्⟫ | ⟪यक्ष्यति⟫ |
| ⟪सृज्⟫ | ⟪स्रक्ष्यति⟫ |
| ⟪पद्⟫ | ⟪पत्स्यति⟫ |
| ⟪अद्⟫ | ⟪अत्स्यति⟫ |
| ⟪दुह्⟫ | ⟪धोक्ष्यति⟫ (⟪दोग्⟫ +  ⟪स्य⟫ + ⟪ति⟫) |
| ⟪बुध्⟫ | ⟪भोत्स्यते⟫ (⟪बोध्⟫ หน้าเสียงวรรค = ⟪भोत्⟫) |
| ⟪मन्⟫ | ⟪मंस्यते⟫ (⟪मन्⟫ + ⟪स्य⟫ + ⟪ते⟫) |

:::
