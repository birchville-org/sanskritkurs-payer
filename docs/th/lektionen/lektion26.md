# บทที่ 26

## 26.1. กฎการเปลี่ยนเป็นเสียงเพดานแข็งของ -s- ในกลางคำ

::: grammar-box
**-s-** จะถูกแทนที่ด้วย **-ṣ-** เมื่อ **k, r, l** หรือ **สระ** — ยกเว้น **a, ā** — ตามมาอย่างใกล้ชิดหรือคั่นด้วย ⟪अनुस्वार⟫ หรือ ⟪विसर्ग⟫ และตามหลังด้วยเสียงอื่นที่ไม่ใช่ **ṛ, r**

กฎสันธินี้ยังใช้กับ **⟪दुस्-** ก่อนเสียงกัฏฐะและโอष्ठยะที่ไร้เสียงในคำประสม
:::
*ตัวอย่าง:*
::: indent
⟪तेषाम्⟫ (จาก: *te-sām*)

แต่: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. กฎการเปลี่ยนเป็นเสียงเพดานแข็งของเสียงทันตะในกลางคำ

::: grammar-box
เสียงอุดทันตะจะถูกแทนที่ด้วยเสียงอุฏฐิต (retroflex) ที่สอดคล้องกันเมื่อตามหลังเสียงอุฎฐิต (รวม **-ṣ-**)

- **iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** เนื่องจาก **i** ที่นำหน้า, **ṭh** เนื่องจาก **ṣ** ที่จะตามมา)*
:::
## 26.3. สันธิคำสำหรับเสียงเพดานแข็ง, เสียงกัฏฐะ, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

ดูตัวอย่างด้านล่าง
:::
## 26.4. กฎการลดทอนเสียงห้าวของกราสมันน์

::: grammar-box
**การที่เสียงห้าวสองตัวปรากฏติดกัน (เสียงห้าว - สระ - เสียงห้าว) ส่งผลให้เสียงแรกสูญเสียความห้าว:**

ตัวอย่าง:

:::
::: indent
\*dhu(gh) » du(g)h
:::
**หากเสียงที่สองสูญเสียความห้าวเนื่องจากกฎการเปลี่ยนเสียง เสียงแรกจะกลับมามีความห้าวอีกครั้ง**

ตัวอย่าง: ดูด้านล่าง รูปอนาคตของ  ⟪दुह्⟫ และ  ⟪बुध्⟫

## 26.5. สันธิคำสำหรับ -m, -n ก่อนเสียงเสียดสี

::: grammar-box
**ก่อนเสียงเสียดสี -n และ -m จะถูกแทนที่ด้วย -ṃ-:**

ตัวอย่าง: ดูด้านล่าง รูปอนาคตของ ⟪मन्⟫
:::
## 26.6. การใช้รูปอนาคตธรรมดา (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**รูปอนาคตธรรมดา (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) แสดงถึง:**

- **อนาคต**
- **การกระทำที่ตั้งใจหรือต้องการ ("ฉันจะเดิน", "ฉันอยากเดิน")**
- **ความคาดหวัง ("มันจะต้องเกิดขึ้นเช่นนั้น")**
- **ความหวัง**
- **ความกังวล**
- **ความเป็นไปได้**
- **ความคิดเห็นของผู้พูด**
- **คำสั่ง**

**รูปอนาคตอยู่ในสถานะแข่งขันกับอนุสงคิต (ดูภายหลัง)**
:::
เช่น ⟪व्रतं⟫ ⟪करिष्यन्देवगृहं⟫ ⟪गच्छति⟫ = "บุคคลที่ต้องการทำปฏิญาณตน ไปที่วัด"

## 26.7. การสร้างรูปอนาคตธรรมดา (⟪ऌत्⟫, ⟪भविष्यन्ती⟫  f.)

::: grammar-box
**รูปอนาคตธรรมดา:**

:::
::: indent
**รากอนาคต + การลงท้ายปฐม**
:::
::: grammar-box
**รากอนาคต:**

:::
::: indent
**(ส่วนใหญ่) รากระดับสูง + -sya**  
**หรือ**  
**(ส่วนใหญ่) รากระดับสูง + -i- + -sya (= - iṣya)**
:::
**ว่ารากใดมีการสร้างรากอนาคตแบบใด ต้องเรียนรู้จากรูปฐาน!**  
**โดยทั่วไป รูปแบบรากและสระเชื่อมของรูปอนาคตจะตรงกับนามวิเสส**  
**รากบางชนิดสามารถสร้างรูปอนาคตได้ทั้งที่มีและไม่มีสระเชื่อม -i-**  
**กิตากนามปารัสไพบทของรูปอนาคตสร้างโดยการเติมส่วนขยาย -nt- ที่รากอนาคต เพศหญิงอาจลงท้ายด้วย -ntī หรือ -tī:**


::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
ตัวอย่าง:
