# ข้อมูลลิขสิทธิ์และวิธีการอ้างอิง

*ข้อความต่อไปนี้ถูกแยกออกจากไฟล์บทเรียนระหว่างการแปลงรูปแบบ เพื่อปรับปรุงการไหลของการอ่าน*

## วิธีการอ้างอิง | cite as:
**Payer, Alois \&lt;1944 - \&gt;:** Sanskritkurs. -- ฉบับปี 2010. -- URL: http://www.payer.de/sanskritkurs/

## วัตถุประสงค์
สร้างขึ้นสำหรับการเรียนการสอนปี 1980 - 1984

## ลิขสิทธิ์
ข้อความนี้เปิดให้สาธารณชนเข้าถึงได้ 
การนำไปใช้ประโยชน์ในสิ่งตีพิมพ์ที่เกินกว่าการอ้างอิงตามปกติ ต้องได้รับอนุญาตเป็นลายลักษณ์อักษรจากผู้เขียน

ข้อความนี้เป็นส่วนหนึ่งของแผนกภาษาสันสกฤตใน **Tüpfli's Global Village Library**
