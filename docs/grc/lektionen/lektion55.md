# Μάθημα νεʹ

## 55.1. Ὁ a-ἀόριστος (ἀόριστος μετὰ θεματικοῦ φωνήεντος)

::: grammar-box
**Ὁ α-αόριστος συνίσταται ὡς ἀνεστία (⟪लङ्⟫) τῆς ἓκτης παραταικῆς κλάσεως (⟪तुदादि⟫), δηλαδή:**

**Αὐγμένον + βαθύβαθμος ῥίζα + α + δευτεροπαθεῖς ἐνδύσεις**

**Τὸ -α- ἀνταλλάσσεται ἐν ταῖς αὐταῖς πτώσεσιν ὡς ἐν τῷ ἀνεστίᾳ διὰ τοῦ -ā-.**

**Οὐδὲν ἐμφατικὸν nasale.**

**Τὸ Ἀत्मनेपιδον σπάνιον ἐστίν· πρὸς τὰς Ὀβαγιαπαδαρίζας συνίσταται δέ τι ἐφ’ οἷς περὶ τὰς ἄλλας κλάσιν τοῦ Αοριστοῦ (βλ. Κίελχορν, Γραμματική §340 καὶ κάτω περὶ τὰς ἀντιστοίχους κλάσεις τοῦ Αοριστοῦ).**

**Κατάλογος τῶν ῥιζῶν, αἵτινες τοιοῦτον Αοριστὸν ἔχουσιν, παρὰ Κίελχορν, Γραμματική §340.**
:::
Παράδειγμα:

⟪सिच्⟫ 6U "βρέχειν"

::: indent
|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| 1\. ⟪तृतीयः⟫ | ⟪असिचम्⟫ | ⟪असिचाम⟫ | ⟪असिचे⟫ | ⟪असिचामहि⟫ |
| 2\. ⟪मध्यमः⟫ | ⟪असिचस्⟫ | ⟪असिचत⟫ | ⟪असिचथास्⟫ | ⟪असिचध्वम्⟫ |
| 3\. ⟪प्रथमः⟫ | ⟪असिचत्⟫ | ⟪असिचन्⟫ | ⟪असिचत⟫ | ⟪असिचन्त⟫ |
:::
Ἀνώμαλοι σχηματισμοί:

::: indent
⟪अस्⟫ 4P "cast": ***⟪आस्थम्⟫, ⟪आस्थत्⟫*** (see Thumb-Hauschild §541,4 for explanation)

⟪ख्या⟫ + ⟪आ⟫ 2P "tell": ***⟪अख्यम्⟫, ⟪अख्यत्⟫***

⟪दृश्⟫ "see": ***⟪अदर्शम्⟫, ⟪अदर्शत्⟫*** (strong grade!)
:::
Note:

::: indent
⟪शास्⟫ 2P "command": ⟪अशिषत्⟫ (regular weak grade!)
:::
