# Μάθημα αʹ7

## 17.1. Δευτέρα ἐνεστωτικὴ κλίσις (⟪अदादि⟫ = ⟪अद्⟫ κτλ.)

αἱ φωνητικαὶ καταλήξεις εὐθέως προστίθενται τῇ ἱερᾷ ρίζῃ. Τότε δὲ δεῖ τὰς φωνητικὰς μεταβολὰς ἐκ τοῦ ὀνοματοσυνθέτου προκύπτουσας παρατηρεῖν.

::: grammar-box

ἔστιν αἱ κάτωθεν μοραὶ τῆς παιδεύσεως ἐν τῇ δευτέρᾳ κλάσει τοῦ παρατατικοῦ:

1.  ῥίζαι μετὰ ἀναβαθμίσεως τῆς βάσεως
    *   πλεῖστα: ὑψηλὸς βαθμός - ταχεῖος βαθμός
    *   ἱκαναὶ ῥίζαι: ἐκτεταμένος βαθμός - ταχεῖος βαθμός
2.  ῥίζαι ἀναβαθμίσεως τῆς βάσεως οὐκ ἔχουσαι
3.  δισύλλαβαι ῥίζαι ἐπὶ -i/-ī μετὰ ἀναβαθμίσεως τῆς βάσεως

:::

## 17.5. Δισύλλαβοι ῥίζαι εἰς -i/-ī μετὰ φωνηεντικῆς ἐναλλαγῆς

Πολλαὶ ῥίζαι ἐν σειρᾷ μορφών δι syllabai εἰσίν, ὅπερ ἐστὶν πρὸ τερματισμοῦ συμφώνου -i (κατὰ τινὰς τερματισμοὺς -ī). Ταῦται αἱ ῥίζαι παρὰ τῶν ἐγχωρίων γραμματικῶν καὶ ἐν λεξικοῖς ὡς μονosyllabai τίθενται.

Παραδείγματα:

⟪रुद्⟫ 2 P "κλαίειν, ὀρυθαίνειν"

*   ἰσχυρὸς παρατατικὸς ρίζα: rodi-
*   ἀσθενὴς παρατατικὸς ρίζα:
    *   πρὸ συμφώνου: rudi-
    *   πρὸ φωνήεντος: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "λέγειν"

*   ἰσχυρὰ ρίζα ἐνεστῶτος: bravī- (« bro- + -ī)
*   ἀσθενὴς ρίζα ἐνεστῶτος:
    *   vor Konsonant: brū-

## 17.7. Ἄσκησις αʹ

Α) Ἐν τοῖς ἐπομένοις προτάσεσιν ἐμπλήσατε τὸ ῥῆμα καὶ μετάφραστε:

⟪१⟫. ⟪ब्राह्मणो⟫ ⟪ऽनृतं⟫ ⟪न⟫ ... (⟪ब्रू⟫ ⟪।⟫ ⟪वच्⟫ ⟪।⟫ ⟪वद्⟫)
