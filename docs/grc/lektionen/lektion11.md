# Μάθημα αʹ1

::: deleteme-box
**Ἐν τούτῃ τῇ μαθήσει μανθάνετε:**
- Τὴν διπλῆν αἰτιατικήν (αἰτιατικὴ τοῦ προσώπου καὶ τῆς ὑλικῆς)
- Τὴν χρῆσιν τῶν σωματιδίων **iti**, **evam** καὶ **na**
- Θεμελιῴδεις ἔννοιας ὡς **dharma**, **adharma** καὶ **putra**
- Τὴν σύνθεσιν ὀνομάτων ἐκ τῶν ριζῶν **vad**, **prach** καὶ **iṣ**
:::
## 11.1. Διπλῆ αἰτιατική

::: grammar-box
**Πολλά ρήματα δύναται ἄρχειν διπλῆς αἰτιατικῆς (δ्वितीया): αἰτιατικὸς τοῦ προσώπου καὶ αἰτιατικὸς τῆς ὑλικῆς.**

**Περὶ τούτων:**
- **Ῥήματα λέξεως**: λαλῶ πρὸς τινά (αἰτιατικός) περὶ τινός (αἰτιατικός); λέγω τινί (αἰτιατικός) τι (αἰτιατικός)
- **Ῥήματα ἐρωτήσεως**: ἐρωτῶ τινά (αἰτιατικός) περὶ τινός (αἰτιατικός)
- **Ῥήματα διδασκαλίας**: διδάσκω τινά (αἰτιατικός) τι (αἰτιατικός)
- ἕτερα τινὰ ρήματα, οἷς ἐν ταῖς λεξικογραφίαις σημειοῦται

**Τούτου τοῦ συντάγματος εἰς τὴν παθητικὴν μετατιθεμένου, τὸ πρόσωπον (τὸ ἐρωτώμενον κτλ.) εἰς τὴν ὀνομαστικήν (πρωταία) τίθεται, τὸ δὲ ὑλικόν (περὶ οὗ ἐρωτᾷται κτλ.) μένει ἐν τῇ αἰτιατικῇ.**

ὥσπερ **rāmo brāhmaṇaṃ dharmaṃ pṛcchati** = ⟪रामो⟫ ⟪ब्राह्मणं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫ = « Ῥάμης τὸν βραχμάνας περὶ τοῦ δάρμα ρωτᾷ. »
« Παθηκός: **rāmeṇa brāhmaṇo dharmaṃ pṛcchyate** = ⟪रामेण⟫ ⟪ब्राह्मणो⟫ ⟪धर्मं⟫ ⟪पृच्छयते⟫

**αὕτη ἡ κανών μόνον ἐσχύει, ὅταν καὶ πρόσωπον καὶ πρᾶγμα ἀντικείμενα εἰσίν. ὃ δὲ πρᾶγμα μόνον ἀντικείμενον ἐστίν, τοῦτο κατὰ τὸ θεμελιώδες σχῆμα τοῦ παθηκοῦ λόγου ἐν τῇ ὀνομαστικῇ (prathamā) τίθεται:**

ὥσπερ **rāmo dharmaṃ pṛcchati** = ⟪रामो⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫ = « Ῥάμης περὶ τοῦ δάρμα ρωτᾷ. »
« Παθηκός: **rāmeṇa dharmaḥ pṛcchyate** = ⟪रामेण⟫ ⟪धर्मः⟫ ⟪पृच्छयते⟫
:::

## 11.2. Λεξιλόγιον

**Μάθετε τα ακόλουθα λέξεις:**

- **iti** ⟪इति⟫ : ούτως
  - Στέκεται *μετά* τον σχηματισμό μιας σκέψης, επιθυμίας, δήλωσης, απόσπασματος ως είδος εισαγωγικών (").
  - π.χ. **sādhavaḥ svargaṃ gacchantīti brāhmaṇā vadanti** "Βραχμάνες λένε: 'Οι όσιοι πάνε στον ουρανό'" = "Βραχμάνες λένε ότι οι όσιοι πάνουν στον ουρανό".
  - Στο Σανσκριτικό δεν υπάρχει έμμεση ομιμία· σχηματισμοί με **iti** πρέπει συχνά να αποδοθούν στα Γερμανικά ως έμμεση ομιμία.
  - **... (απόσπασμα) ... iti śrutiḥ** = "ούτως ο Βέδας".
  - Συχνά μετά το **iti** πρέπει να νοηθεί ένα ρήμα σκέψης: "σκεπτόμενος: '...' κάνει αυτό". Στα Γερμανικά αποδίδεται ιδιωματικά (π.χ. "Επειδή έχει πείνα, πάει...").

- **evam** ⟪एवम्⟫ : ούτως (επιρρηματικά, π.χ. **evaṃ jayati** "ούτως νικάει").
- **na** ⟪न⟫ : όχι
  - Αρνητικά μεμονωμένα λέξεις (στέκεται ακριβώς πριν: **na sādhuḥ** "ένας όχι καλός") ή ολόκληρες προτάσεις (στέκεται στην αρχή ή ακριβώς πριν το ρήμα).

- **putra** αρ. ⟪पुत्र⟫ : υιός (Στην Ινδία ήταν απαραίτητο να γεννήσει κανείς έναν υιό, ο οποίος μπορούσε να προσφέρει τις θυσίες για τους προγόνους.)
- **dharma** αρ. ⟪धर्म⟫ : ("το σταθερό", δηλαδή) δίκαιο, νόμος, έθιμο, χαρακτήρας.
  - Αντιστοιχεί περισσότερο στον φυσικό/ηθικό νόμο. Κάθε ένας έχει σύμφωνα με το **varṇa** και το **āśrama** (στάδιο ζωής) τα δικά του καθήκοντα (**svadharma**).
- **adharma** αρ. ⟪अधर्म⟫ : αδικία (αντίθετο του **dharma**).
- **iṣ** 6 Π (icchati) ⟪इष्⟫ ⟪इच्छति⟫ : επιθυμώ (**iṣ-ccha-ti**).

**Περὶ τῆς ὀνοματουργίας:**

- **vad** 1 P ⟪वद्⟫ : λέγειν
  - **vāda** m. ⟪वाद⟫ : ῥῆμα, ἀπόφασις, λόγος
  - **vadana** n. ⟪वदन⟫ : τὸ λέγειν· ὄργανον λαλήσεως: στόμα, πρόσωπον

- **prach** 6 P ⟪प्रच्छ्⟫ : ἐρωτᾶν
  - **praśna** m. ⟪प्रश्न⟫ : ἐρώτημα (τὸ ὑπόθηκον **-na** ὡς ἐν τῷ **yaj-ña**)

- **iṣ** 6 P ⟪इष्⟫ : ἐπιθυμεῖν
  - **iṣṭi** f. ⟪इष्टि⟫ : ἐπιθυμία (**iṣ** + **-ti**)

## 11.4. Ἐπαναληπτικὴ ἄσκησις

**A) Μεταφράστε στα Σανσκριτικά χρησιμοποιώντας παθητικές κατασκευές:**
1. Οι γυναίκες Vaiśya ρωτούν τους Brahmanas περί του Dharma.
2. Ο δάσκαλος εκφωνεί ένα Mantra.
3. Οι ιερές γυναίκες φθάνουν σε έναν ουρανό.
4. Ένας vedικός σοφός δεν κάνει κακό.
5. Οι Brahmanas τιμούν ως ιερείς προσφορών τη θεά με προσφορές.
6. Η Śūdra γυναίκα πηγαίνει στο χωριό.
7. Ποιος βλέπει την αλήθεια;

**B)**
1. Αναφέρετε με ένα Dvandva τα καθήκοντα όλων των Διγεννημένων. Λύστε το σύνθετο στα Σανσκριτικά.
2. Αναφέρετε με ένα Dvandva τα καθήκοντα των Vaiśyas. Λύστε το σύνθετο στα Σανσκριτικά.

**C) Μεταφράστε:**

1. ⟪श्रवणेन⟫ ⟪श्रूयते⟫ | |
2. ⟪कर्षर्कैः⟫ ⟪कृष्यते⟫ | |
3. ⟪श्रावकेणेश्वरो⟫ ⟪नेज्यते⟫ | |
4. ⟪रक्षिक्या⟫ ⟪गुरू⟫ ⟪रक्ष्यते⟫ | |
5. ⟪ब्राह्मणेनानृतं⟫ ⟪नोद्यते⟫ | |
6. ⟪शूद्रेतरा⟫ | |
7. ⟪शिक्षा⟫ ⟪कल्पो⟫ ⟪व्याकरणं⟫ ⟪निरुक्तं⟫ ⟪छन्दो⟫ ⟪ज्योतिषमङ्गानि⟫ | |
8. ⟪आन्वीक्षिकीत्रयीवार्त्तादण्डनीतयो⟫ ⟪विद्याः⟫ ||

**D) Μεταφράστε και μετατρέψτε σε Σανσκριτικά το Υποκείμενο, το Αντικείμενο και το Ρήμα στον Πληθυντικό:**

1. ⟪फलमश्नुते⟫ | |
2. ⟪गुरुणा⟫ ⟪सत्यमुद्यते⟫ | |
3. ⟪वैश्यः⟫ ⟪पशुं⟫ ⟪लभते⟫ | |
4. ⟪पुत्रः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ||

**Ε) Μετατρέψτε τις προτάσεις Γ) 1-5 σε ενεργητικές κατασκευές.**
