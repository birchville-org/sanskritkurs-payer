# Μάθημα μβʹ

## 42.1. Θέματα εἰς -ṛ

### 42.1.1. Θέματα μετὰ ἐκτεταμένης βαθμίδος ἐν τῷ ἰσχυρῷ θέματι

::: grammar-box
Πάντα τὰ αρρενικά καταληκτικά σε -ṛ, εκτός των αναφερομένων υπό 1.3. ονομάτων σχετικών με συγγένειαν. Εις ταύτα ανήκουν επίσης τὰ ονόματα σχετικά με συγγένειαν:

*   **⟪नप्तृ⟫** αρσ. "εγγονός"
*   **⟪भर्तृ⟫** αρσ. "σύζυγος (κυρίως ὁ τρέφων)"

Τὸ πλεῖστον μέρος τῶν ἐνταῦθα ἀνηκόντων ὀνομάτων σχηματίζεται διὰ τῶν ὀνομάτων τοῦ πράκτορος ἐπὶ τῷ ⟪कृत्⟫-καταλήκτει -⟪तृ⟫.

**Σχηματισμός:**

*   **Ἰσχυρὰ ῥίζα: -ār**
*   **Ἀσθενὴς ῥίζα**
    *   **πρὸ φωνήεντος: -r**
    *   **πρὸ συμφώνου: -ṛ**

Σημειοῦτε τὰς ἀνώμαλους σχηματισμοὺς (σημαινομένα διὰ **κόκκου**)!
:::

### 42.1.2. Ὀνοματικὸς σχηματισμός: ⟪कृत्⟫-επίθητον -⟪तृ⟫

::: grammar-box
Μετὰ τοῦ πολὺ συχνὰ συνιόντος ⟪कृत्⟫-ἐπιθέτου -⟪तृ⟫ σχηματίζονται ὀνόματα ἐνεργητικά (ὀνομασίες τοῦ ⟪कर्तृ⟫) πρὸς ἑκάστην ῥίζαν ἢ καυστικὴν ρίζαν.

**Παιδεία:**

*   **βαθεῖα ῥίζη + -tṛ**

ἢ

*   **βαθεῖα ῥίζη / Αἰτιατικὸς + i + tṛ**
:::
Παραδείγματα:

::: indent
**⟪कर्तृ⟫** m. "ποιητής"

**⟪जेतृ⟫** m. "νικητής"

**⟪धातृ⟫** m. "δημιουργός"

**⟪रक्षितृ⟫** m. "προστάτης"

**⟪बोधयितृ⟫** m. "ἠγέρτης"
:::
::: media
![lekt4201.jpg](/images/lekt4201.jpg)

(Πηγὴ εἰκόνος: [Λεπτομέρειαι](/grc/licenses#lekt4201))
:::

::: grammar-box
Σπάνια occurring οὐδέτερα ἐπ’ -⟪तृ⟫ ἔχουσι μερικὴν αὑτὰ κλίσιν (βλ. Kielhorn, Γραμματικὴ § 148).

Τὸ θηλυκὸν πρὸς τοῖς ἱστορίαι ἐπ’ -⟪तृ⟫ φέρεται κατὰ **-⟪त्री⟫** (ὡς **⟪देवी⟫**).

π.χ. **⟪कर्त्री⟫** f. "ποιήτρια"
:::

⟪पितृ⟫ αρσ. πληθ.: οἱ τεθνάντες ἄρρενες πρόγονοι, δηλ.

1.  πατήρ, πάππος, προπάππος
2.  οἱ πρόγονοι τῆς ἀνθρωπότητος

Πρὸς τοὺς δύο τελοῦνται ἱεροπραγίαι, καλούμενοι ⟪श्राद्ध⟫ θ. Καθ' ἡμέραν προσφέρεται ἐκάστῳ τριῶν ἀρρένων προγόνων (ἐκ πατρικῆς καὶ μητρικῆς γραμμῆς) ὕδωρ καὶ ἐν τισὶν καιροῖς σφαίραι ὀρύζου ἢ σιταρίνου (⟪पिण्ड⟫ θ. "σφαίραι"). Ὥστε οἱ πρόγονοι τροφήν λαμβάνωσι. Ἡ τελειοποίησις ταύτης τῆς τελετῆς ἐστιν αἴτιον δι' ὃ ἄνηρ υἱὸν γεννήσαι βούλεται. Οἵτινες διὰ ταύτης τῆς ⟪पिण्ड⟫ δωρεᾶς συνδέονται, καλοῦνται ⟪सपिण्ड⟫ (οἷς ⟪पिण्ड⟫ κοινόν ἐστι). Ὁ ⟪सपिण्ड⟫ περιλαμβάνει ἓξ γενεάς: τρεῖς πρὸ ὀπίσω (μέχρι τοῦ προπάππου) καὶ τρεῖς πρὸ ἔμπροσθεν (μέχρι τοῦ ἐγγόνου).
