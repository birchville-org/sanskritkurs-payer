# Μάθημα αʹ2


## 12.1. Μετοχὴ παρακειμένου παθητικῆς φωνῆς (PPP)

Ἐνδεχόμενον τῶν προτατικῶν φραστῶν τοῦ παρελθόντος χρόνου εἰς τὴν κατασκευὴν μετὰ τοῦ λεγομένου ὀνόματος ἀρρήτου παθητικοῦ (PPP) εἶναι.

::: grammar-box
**Ὁρῶνται δὴ τὰ ὀνόματα ἀρήγυρα παθητικὰ οὐκ εἶναι ὀνόματα ἀληθινά, διότι οὐκ ἐκ τῶν ἱστάνων χρόνων συνίστανται. Ἀλλὰ τὸ ὄνομα τοῦ ρίζης μετὰ τοῦ πρωτογενικοῦ -ta ἢ -na. Διὸ λέγεται ἐν τῇ Ἰνδικῇ γραμματικῇ περὶ τοῦ kta.**
:::

### 12.1.1. Σχῆμα διὰ μεταβατικὰ ῥήματα

::: grammar-box
**ὄνυμα (καρτρ) ἐν ὀργανικῇ (τρίτη) -- εὐθεῖς ὄνυμα (καρμαν) ἐν οὐσιαστικῇ (πρώτη) -- μετοχὴ τελείας παθητικῆς**

ἡ μετοχὴ τελείας παθητικῆς ταύτῃ τῇ περιπτώσει μετὰ τοῦ ὀνόματος ἀριθμῷ, πτώσει καὶ γένει συμφωνεῖ.

ῥῆμα βοηθητικὸν (“εἶνα”) οὐχ ὅτι ἀνάγκη.

παραδείγματα:
> **σάθουνὰ σβάργα āπτḥ** = ⟪साधुना⟫ ⟪स्वर्ग⟫ ⟪आप्तः⟫ = “(ὑπὸ τοῦ ἁγίου ἐκτήθη οὐρανός) = ὁ ἅγιος οὐρανὸν ἐκτήσατο.”
> 
> **βρāχμανὲν δεβīṣτὰ** = ⟪ब्राह्मणेन⟫ ⟪देवीष्टा⟫ = “(ὑπὸ τοῦ βραχμάνου ἡ θεὰ ἐτιμήθη θυσίᾳ) = ὁ βραχμάνος τὴν θεὰν θυσίᾳ ἐτίμησε.”
:::

### 12.1.2. Σχῆμα Αʹ διὰ ῥήματα ἀμετάβατα καὶ ῥήματα κινήσεως

::: grammar-box
**Ἀγὴν (καρτρ) ἐν ὀνομαστικῇ (πρωτμά) -- Μέτοχος Παρακειμένου Παθητικοῦ**

Ἐν τούτῳ τῇ περιπτώσει, τὸ PPP συμφωνεῖ μετὰ τοῦ Ἀγέως κατ’ ἀριθμόν, πτώσιν καὶ γένος. Τὸ Μέτοχος Παρακειμένου «Παθητικόν» ἔχει ἐν ἀμεταβόλοις ρήμασι (ρήματα ἄνευ εὐθέως ἀντικειμένου) καὶ ρήμασι κινήσεως ἐνεργητικὴν σημασίαν.

Παράδειγμα:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया⟫ ⟪नगरं⟫ ⟪गता⟫ = «Ἡ Κσατρίγια γυνὴ εἰς τὴν πόλιν ἐπορεύθη.»
:::

### 12.1.3. Σχῆμα Βʹ διὰ ῥήματα ἀμετάβατα καὶ ῥήματα κινήσεως

::: grammar-box
**Ἀγὸς (καρτὴ) ἐν ὀργανικῇ (τρτυαίᾳ) -- PPP ἐν ὀνομαστικῇ πληθυνικοῦ οὐδετέρου**

Παράδειγμα:
> **κṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(ὑπὸ τοῦ κṣatriya ἐν τῇ πόλει) ἐπορεύθη = ὁ κṣatriya (ἐν τῇ πόλει) ἐπορεύθη.“

ἡ κατασκευὴ κατὰ σχῆμα II πολὺ σπανιότερά ἐστιν ἢ ἡ κατασκευὴ κατὰ σχῆμα I.
:::

## 12.2. Περὶ τῆς σημασίας τοῦ PPP

Ἐπεὶ οὖν τὸ λεγόμενον «Μετοχὴ Παρακειμένου Παθητικοῦ» διὰ τὰς μεταβατικὰς ρήσεις κυρίως παθητὴν σημασίαν ἔχει (**ᾄπτα** = «ἐληλυθός (γεγονώς)») καὶ διὰ τὰς ἀμεταβάτους ρήσεις καὶ τὰς κινήσεως ῥήσεις ἐνεργητικὴν σημασίαν (**γᾶτα** = «πορευθείς»), εἰσὶν ὁρισμέναι ρήσεις, αἷς τὸ PPP καὶ ἐνεργητικὴν καὶ παθητὴν σημασίαν ἔχει δύνασθαι:

οἷον·
- **γᾶτα** = ⟪गत⟫ = «πορευθείς» (ἐνεργητικῶς)· ἀλλὰ καὶ: **γᾴτο μάργαχ** = ⟪गतो⟫ ⟪मार्गः⟫ = «ὁδὸς πεπορευμένη» (παθητικῶς)
- **ᾄπτα** = ⟪आप्त⟫ = «ἐληλυθώς» (παθητικῶς), «ἐληθυῖα» (ἐνεργητικῶς)

## 12.3. Σχηματισμὸς τοῦ PPP

::: grammar-box
Ἐνταῦθα αἱ τῆς παιδεύσεως μέθοδοι παρατίθενται (πρὸς ἑκάστην ῥίζαν τὸ ἀντιστοιχοῦν αὐτῇ PPP μανθάνειν δεῖ!):

**(μάλιστα) βαθὺς σταθμὸς τῆς ῥίζης**

- **+ -ta**
  - μετὰ τοῦ συνδετικου φωνήεντος **-i-** πρὸ αὐτοῦ: **-ita**
  - **+ -na**
- **+ -na**

Αἱ θηλυκὲς ῥίζαι λέγονται: **-tā**, **-itā**, **-nā**; τὸ οὐδέτερον κλίνεται ὡς **phala** n.
:::

### 12.3.1. PPP εἰς -ta (kta)

#### 12.3.1.1. Ἄνευ φωνήεντος συνδετικοῦ -i- (aniṭ)

*aniṭ* = «χωρὶς (*an-*) τοῦ προτεθέντος εἰς τὸ ὑπόστροφον (*-i-) *t*» (δηλ. χωρὶς τοῦ συνδετικοῦ φωνήεντος *i*).

::: grammar-box
Ἄνευ τοῦ συνδετικοῦ φωνήεντος σχηματίζεται τὸ PPP γενικῶς ἐκ τῶν φωνηεντικῶν λήγοντων ριζῶν, ὡς καὶ ἐκ πολλῶν ἄλλων ριζῶν, οὐδενὸς σταθεροῦ κανόνος ὑπάρχοντος, δι’ οὖν δυνάμεθα εἰπεῖν ποίαις ριζαῖς ἢ δομηταῖς ῥίζαις τὸ συνδετικὸν φωνήεν ἐπακολουθεῖ ἢ οὐ.

Κατάλογος τῶν *aniṭ* ριζῶν εὑρίσκεται παρὰ Kielhorn, *Grammatik* § 298.
:::
**Ἀλλ’ παραδείγματα:**

## 12.4. Νόμοι τῆς φωνητικῆς συνδέσεως ἐν τῇ λέξει

Περὶ τῶν σχημάτων *aniṭ* δεῖ ταῦτα τὰ περὶ τὴν φωνὴν νόμια ἐν τῷ λόγῳ παρατηρεῖν. **Οὗτοι οἱ νόμοι σφόδρα σπουδαίοί εἰσι πρὸς τὴν σύνεσιν πάσης τῆς Σανσκρίτιδος μορφολογίας.**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p vor stimmlosem Verschlusslaut (z.B. t, th) bleiben unverändert:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct wird durch kt = ⟪क्त्⟫ ersetzt:** | **muc + ta » muk-ta** = **⟪मुक्त⟫** |
| **3. śt wird durch ṣṭ = ⟪ष्ट्⟫ ersetzt:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. Stimmhafter unaspirierter Verschlusslaut – außer j – wird vor stimmlosem Laut durch den ihm entsprechenden stimmlosen unaspirierten Laut ersetzt:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (wichtig für die 2. Präsensklasse) |
| **5. jt wird durch kt oder ṣṭ ersetzt (nicht fakultativ!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. Stimmhafter aspirierter Verschlusslaut + stimmloser Verschlusslaut » stimmhafter unaspirierter Verschlusslaut + stimmhafter aspirierter Verschlusslaut (Bartholomaesches Aspiratengesetz):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t wird ersetzt durch ḍh mit Dehnung eines vorhergehenden i bzw. u; oder durch gdh. ## 12.5. Λεξιλόγιον

- **budh** 4 Ā (budhyate) / 1 U (bodhati), PPP **buddha** ⟪बुध्⟫ ⟪बुध्यते⟫ ⟪बोधति⟫ ⟪बुद्ध⟫ : ἐγείρεσθαι, εἰς γνῶσιν ὀρθὴν ἐγείρεσθαι, γιγνώσκων· PPP **buddha** 3 ἐξηγέρθη, διό καὶ **Buddha** = « ὁ ἐξηγερμένος » (οὔχ· ὁ φωτισθείς)

- **dah** 1 P (dahati), PPP **dagdha** ⟪दह्⟫ ⟪दहति⟫ ⟪दग्ध⟫ : (τι) καίειν
- **sah** 1 Ā (sahate), PPP **soḍha** ⟪सह्⟩ sahate soḍha : ὑποφέρειν, ἀνεχεσθαι, ὑπομένειν μετὰ μακροθυμίας = συγχωρεῖν
- **mṛga** m. ⟪मृग⟫ : θηρίον ἄγριον
- **mārga** m. ⟪मार्ग⟫ : ὁδός (αἱ δόμοι συχνὰ τρέχοντα ὁρμητήρια θηρίων)

Πρὸς τὴν ἕκτην κλῆσιν παρατείνεως ἀριθμοῦσι τὴν παρὰ τοῖς αὐτόχθονι γραμματικοῖς ἱκαναὶ ρίζαι, αἵτινες τὸν παρατείνοντα σταθμὴν μετὰ τοῦ nasalinfix καὶ φωνήεντος θέματος a σχηματίζουσι, ὡς παράδειγμα:

- **muc** 6 U (muñcati), PPP **mukta** ⟪मुच्⟫ ⟪मुञ्चति⟫ ⟪मुक्त⟫ : λύειν, ἀπολύειν, ἐλευθεροῦ· τὸν κύκλον τῶν μετεννοήσεων (**saṃsāra** m.) ἐλευθεροῦ = σωτὴρ ἀποδίδωσι
- **sic** 6 U (siñcati), PPP **sikta** ⟪सिच्⟫ ⟪सिञ्चति⟫ ⟪सिक्त⟫ : ῥαντίζειν

- **muc**: **mokṣa** m. ⟪मोक्ष⟫ : ἀπολύσις, ἐλευθερία, σωτηρία
- **sic** + **abhi-**: **abhiṣeka** m. ⟪अभिषेक⟫ : ἱερὸν ἀνάπτυσμα βασιλέως ἐπὶ τῇ βασιλείᾳ, βασιλικὴ χρίσις
- **budh**: **bodhi** m./f. ⟪बोधि⟫ : ἡ ἐγείρεσις (δι’ ἧς Βούδδας ἢ Ἰνὰ εἰς τὴν σωτὴρ γνώμην ἵκνει)
