# Μάθημα γʹ1

## 31.1. Ἡ 7η ἐνεστωτικὴ κλίσις (⟪रुधादि⟫ = "⟪रुध्⟫ κτλ.")

::: grammar-box
**Παιδεία:**

**Πρὸ τῶν τελικῶν συλλαβῶν τῆς βάσεως ταπεινοῦ σταθμοῦ ἐντίθεται ὡς λεγόμενον nasalinfix (-na- ἢ -n-):**

*   **ἐν τῷ κρατίστῳ στοχαστῇ: -na-**
*   **ἐν τῷ ἀσθενεστάτῳ στοχαστῇ: -n-**

**Περὶ τῆς συνθέσεως τῶν τελικῶν συλλαβῶν τῆς βάσεως μετὰ τῶν ἀρχομένων συλλαβῶν ἰσχύουσι ταὐτὰ τὰ κανόνες οἵτινες ἰσχύουσι περὶ τῆς 2. κλάσεως τοῦ ἐνεστῶτος.**
:::
Παραδείγματα:

⟪युज्⟫ 7U "συνδέω, ζεύγνυμι"

**⟪भञ्ज्⟫** 7P "σπᾶν"

::: indent
