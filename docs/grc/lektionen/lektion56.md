# Μάθημα νϛʹ

## 56.1. Ὁ ἀναδιπλασιασμένος ἀόριστος

::: grammar-box
**Παιδεία:**

**Αύξημα + διπλασιασμένη ρίζα + a + θεματική δευτεροπαθής κατάληξη**

**Η συλλαβή της ρίζας μπορεί να είναι βαριά ή οξυμένη. Για ρίζες που λήγουν σε -i ή -u, η βαριά προφορά είναι ο κανόνας.**

**Το τελικό -i, -u αντικαθίσταται από -iy ή -uv.**

**Τὸ ἐντεληκτικὸν -ā (ἀντὶ τοῦ -e) ἀφαιρεῖται.**
:::
Παράδειγμα:

⟪श्रि⟫ 1U "ἀπέρχεται πρὸς, ἐφίπταται"

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | ⟪अशिश्रियम्⟫:br(⟪अ⟫-⟪शि⟫-⟪श्रिय्⟫-⟪अम्⟫) | ⟪अशिश्रियाम⟫ | ⟪अशिश्रिये⟫ | ⟪अशिश्रियामहि⟫ |
| **2. ⟪द्वितीयः⟫** | ⟪अशिश्रियस्⟫ | ⟪अशिश्रियत⟫ | ⟪अशिश्रियथास्⟫ | ⟪अशिश्रियध्वम्⟫ |
| **3. ⟪प्रथमः⟫** | ⟪अशिश्रियत्⟫ | ⟪अशिश्रियन्⟫ | ⟪अशिश्रियत⟫ | ⟪अशिश्रियन्त⟫ |

Ταύτην τὴν μορφὴν τοῦ ἀορίστου σχηματίζουσιν, ὧν ἐνεκα:

*   ⟪श्रि⟫ 1U "ἀπέρχεσθαι πρός"
*   ⟪द्रु⟫ 1P "δραμεῖν"
*   ⟪कम्⟫ 1Ā "φιλεῖν": ⟪अचकमत⟫ / ⟪अचीकमत⟫ (βλέπε κάτω!)
*   ⟪पत्⟫ 1P "πεσεῖν": ⟪अपप्तत्⟫ (a-pa-pt-a-t; pt = βαθὺς σταθμὸς πρὸς pat)
*   ⟪वच्⟫ 2P "εἰπεῖν": ⟪अवोचत्⟫ (a-va + uc-a-t)

::: grammar-box
**Πᾶσαι ῥίζαι τῆς δέκατης τάξεως τοῦ ἐνεστῶτος, ὡσαύτως δὲ πάντα τὰ αιτιατικά, ἀεὶ σχηματίζουσιν τὸν ἐπαναλαμβανόμενον ἀόριστον.**
:::
### 56.1.1. Σχηματισμὸς τοῦ ἀορίστου τῶν αἰτιατικῶν ῥημάτων καὶ τῶν ῥιζῶν τῆς ιʹ συζυγίας ἐνεστῶτος

Συλλαβὴ θεματική:

::: grammar-box
**Ἐκκίνημα ἐστὶ τὸ σχῆμα τοῦ ἔνδοξου σταδίου καὶ τῆς αἰτιατικῆς, ὅπερ μετὰ τὴν ἀφαίρεσιν τοῦ συνθέτου -aya- ἔχει (δηλ. σταδίου ἐπὶ -p παρὰ τοῖς αἰτιατικοῖς ἐπὶ -paya-).**

**Τὸ φωνήεν τῆς λεγομένης συλλαβῆς τοῦ σταδίου καθορίζεται ἐν τῷ ἀόριστῳ κατὰ τοὺς ἑξῆς κανόνας:**

*   **\-ā- πρὸ ἁπλοῦς συνωνύμου ἀντικαθίσταται ὑπὸ -a-:**
⟪पॄ⟫ 3P: Αἰτ. **:sig[⟪पार⟫]**⟪यति⟫, Ἀόρ. ⟪अपि⟫**:sig[⟪पर⟫]**⟪त्⟫  
⟪द्रु⟫ 1P: Αἰτ. **:sig[⟪द्राव⟫]**⟪यति⟫, Ἀόρ. ⟪अदु⟫**:sig[⟪द्रव⟫]**⟪त्⟫ / ⟪अदि⟫**:sig[⟪द्रव⟫]**⟪त्⟫  
:sig[⟪नी⟫] 1U: Αἰτ. **:sig[⟪नाय⟫]**⟪यति⟫, Ἀόρ. ⟪अनी⟫**:sig[⟪नय⟫]**⟪त्⟫  
⟪ज्ञा⟫ 9U: Αἰτ. **:sig[⟪ज्ञाप⟫]**⟪यति⟫, Ἀόρ. ⟪अजि⟫**:sig[⟪ज्ञप⟫]**⟪त्⟫

*   **\-ī-, -e-, -ai- πρὸ ἁπλοῦς συνωνύμου ἀντικαθίσταται ὑπὸ -i-:**
⟪चित्⟫ 1P: Αἰτ. **:sig[⟪चेत⟫]**⟪यति⟫, Ἀόρ. (Ἄ) ⟪अची⟫**:sig[⟪चित⟫]**⟪त⟫

*   **-u-, -o-, -au- προ简单辅音被-u-替换：**
⟪चुर्⟫ 10U: **:sig[⟪चोर⟫]**⟪यति⟫, 不定过去时 ⟪अचू⟫**:sig[⟪चुर⟫]**⟪त्⟫

**紧跟在词干音节末尾辅音之前的、替代ṛ, ṝ, ḷ的ar, ār, īr, al，保持原样或替换为ṛ/ ḷ：**

*   **τὸ ar, ār, īr, al ἀντικαθιστῶν τὸ ṛ, ṝ, ḷ, ὃ ἀμεσῶς προηγεῖται τῆς συλλαβῆς τοῦ ὀνόματος, τὸν ἐκφερόμενον σύμφωνον φέρον, μένει προαιρετικῶς ἀπαράλλακτον ἢ μεταβάλλεται εἰς ṛ ἢ ḷ:**
⟪कॢप्⟫ 1Ā: Αἰτιative **:sig[⟪कल्प⟫]**⟪यति⟫, Ἀόστος ⟪अच⟫**:sig[⟪कल्प⟫]**⟪त्⟫ / ⟪अची⟫**:sig[⟪कॢ⟫]**⟪पत्⟫  
⟪कृष्⟫ 1P/6U: Αἰτιative **:sig[⟪कर्ष⟫]**⟪यति⟫, Ἀόστος ⟪अच⟫**:sig[⟪कर्ष⟫]**⟪त्⟫ / ⟪अची⟫**:sig[⟪कृ⟫]**⟪षत्⟫
:::

在应用上述规则到词干后，必须遵循以下关于重音节节元音的规则：

::: grammar-box
**Ἄρχη ἐστὶν ὁ κανονικὸς φθόγγος τῆς ἀναδιπλασιάσεως, δηλ.**

*   a ὑπὸ a, ā, ṛ,  ṝ, ḷ
*   i ὑπὸ i, ī, e, ai
*   u ὑπὸ u, ū, o, au

*   **i, u ἀντικαθίσταται ὑπὸ ī, ū, ἐὰν ἡ συλλαβὴ τῆς ρίζης ἀρξάται ὑπὸ μόνου συνωνήεντος καὶ μέτρῳ βραχεία ᾖ:**
⟪भिद्⟫ 7U: Αἴτ. ⟪भेदयति⟫, Ἀόρ. ⟪अ⟫**:sig[⟪बी⟫]**⟪भिदत्⟫

:sig[⟪नी⟫] 1U: Καισ. ⟪नाययति⟫, θεματικὸς συλλαβὴ τοῦ Αορ. ⟪नय्⟫, Αορ. ⟪अ⟫**:sig[⟪नी⟫]**⟪नयत्⟫

## 56.3. Ἡ ἀπαγορευτικὴ πρότασις

::: grammar-box
**Μορφή Κύρια:**

**⟪मा⟫ + Αοριστὸς ὀρμητικός**

**⟪मा⟫ ⟪स्म⟫ + Αοριστὸς ὀρμητικὴ ἢ Παρεστῶς ὀρμητικός**
:::
Παραδείγματα:

::: indent
⟪मा⟫ ⟪कर्महेतुर्भूः⟫ "Μὴ γίνου ὃς ἐκ καρποῦ ἔργου κινεῖται!" (Αοριστὸς ὀρμητικός) (⟪भगवद्गीता⟫ 2,47c)

⟪क्लैब्यं⟫ ⟪मा⟫ ⟪स्म⟫ ⟪गमः⟩ "Mē gignou anandros!" (Imperativus Aoristus) (⟪भगवद्गीता⟫ 2,3a)
:::

**Aliae formae sententiarum prohibitarum:**

*   **⟪मा⟫ + (⟪स्म⟫) + Imperativus (raro)**
**e.g. ⟪मा⟫ ⟪ते⟫ ⟪सङ्गो⟫ ⟪ऽस्त्वकर्मणि⟫**

*   ⟪अलम्⟫ vel ⟪कृतम्⟫ = Instrumentalis in sententia inhibitionis
e.g. ⟪अलं⟫ ⟪विषादेन⟫ "Satis de desperatio! = Desistere despectum esse! = Caput attolle!"

*   ⟪न⟫ + Gerundivόν (Μετοχή της Αναγκαιότητας)
