# Μάθημα λδʹ

## 34.1. Ὁ παρακείμενος (⟪लिट्⟫)

ἐν τῇ κλασικῇ Σανσκρίτῃ ὑπάρχει ἐκ τοῦ παρακειμένου ρίζης μόνον ὀνομαστικὴ καὶ μετοχή.

::: grammar-box
**Δύο εἰσὶν ὁμοίως τῆς παρακειμένου συνθέσεως:**
*   **τὸ ἀναδιπλασιασμένον παρακείμενον = ⟪द्वित्वलिट्⟫**
*   **τὸ περιφραστικὸν παρακείμενον = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Τὸ περιφραστικὸν παρακείμενον (⟪अनुप्रयोगलिट्⟫) χρῆται:**
1. **ἐπὶ τῶν ἐκγενομένων συζυγιῶν (αἰτιατικόν, ἐπιθυμητικόν, συνηθισμένον, ὀνομαστικά)**
2. **ἐπὶ τῶν ῥιζῶν, αἵτινες μακρὸν φθόγγον (πλὴν ā-) ἤρχαντο, ἢ φθόγγον (πλὴν a-) πρὸ δύο συμφώνων**
3. **ἐπὶ τινῶν ἄλλων ριζῶν**
:::
## 34.2. Ὁ ἀναδιπλασιασμένος παρακείμενος (⟪द्वित्वलिट्⟫)

### 34.2.1. Φωνηεντικὴ ἐναλλαγή

::: grammar-box
**Παιδεία:**

**ἰσχυρὸς ῥίζα:** εἷς ἀριθμὸς Παρασμαίπαδα
*   **διπλασιασθεῖσα ὑψηλὴ βαθμὶς ἢ ἐκτεταμένη βαθμὶς ῥίζα + παρακελευστικὸς κατάληξις**

**ἀσθενὴς ῥίζα:** πᾶσαι λοιπαὶ μορφαί
*   **διπλασιασθεῖσα ταπεινὴ βαθμὶς ῥίζα + παρακελευστικὸς κατάληξις**
:::
::: grammar-box
**Γενικῶς (καὶ ἐκτὸς τοῦ παρακειμένου) οὐδεμίαν ῥιζικὴν μεταβολὼς ἔχουσι ρίζαι τῆς μορφῆς:**
*   **(σύμπνευμα)-σύνεπτος-μακρὸς φθόγγος-σύμπνευμα**
*   **(σύμπνευμα)-σύνεπτος-φθόγγος-σύνεπτος-σύμπνευμα**

**Ἐν τῷ παρακειμένῳ ἔτι οὐδεμίαν ῥιζικὴν μεταβολὼς ἔχουσι ρίζαι τῆς μορφῆς:**
*   **α-σύνεπτος**
*   **ā-σύνεπτος**
:::

### 34.2.3. Συνδετικὸν φωνῆεν -i-

::: grammar-box
**πρὸ τῆς καταλήξεως τῶν 3.πλ.Ā (-re) εἰσέρχεται ἀεὶ ὁ σύνδεσμος -i-, πρὸ δὲ τῶν ἄλλων καταλήξεων ἀρχομένων συμφώνοις ἐπὶ τῆς πλειονότητος τῶν ῥιζῶν.**
:::
### 34.2.4. Ἀναδιπλασιασμὸς ῥιζῶν ἀπὸ συμφώνου ἀρχομένων

::: grammar-box
**Περὶ τοῦ ἀναδιπλασιασμοῦ συμφώνων ἀρχομένων ἰσχύουσι τὰ ἐν [Λέξις 33](lektion33.md) δεδομένα.**

**Φθόγγος ἀναδιπλασιασμοῦ ἐπὶ ῥιζῶν ἀρχομένων συμφώνοις ἐστὶ φθόγγος βραχὺς τῆς ῥίζης.**

**Δίφθογγες πρὸ συμφώνου ἀμείβονται διὰ τοῦ ἀντιστοίχου φθόγγου βραχοῦ βαθμίδος.**

**τὰ ῥ, ρ̄, λ̣ καὶ οἱ τελικoiί διφθόγγου ἀντιγραφονται διὰ τοῦ -α-.**
