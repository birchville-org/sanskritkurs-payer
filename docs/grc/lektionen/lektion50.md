# Μάθημα εʹ0

## 50.1. Ὀνοματικὸς σχηματισμός: κανονικὴ σύγκρισις

::: grammar-box
**ἡ τακτικὴ αὔξησις ἐν τῷ Σανσ୍କρίτῳ γίνεται τοῖς ⟪तद्धित⟫ καταλήξεσιν**
* **-⟪तर⟫ (θηλ.: ⟪तरा⟫) ἐν τῷ "συγκριτικῷ"**
* **⟪तम⟫ (θηλ.: ⟪तमा⟫) ἐν τῷ "ὑπερθετικῷ"**

**αὗται αἱ καταλήξεις ἐπικείνται τοῖς ἐπιθετοῖς τῷ ἄρσενι ρίζῃ. Ὀνόμασι δὲ μεταβαλλομένοις ἐπικείνται τῷ ἀσθενεῖ ρίζῃ, ἥτις τὴν μορφὴν ἔχει ὡς πρὸ τῆς καταλήξεως -su τοῦ δοτικου (⟪पञ्चमी⟫) πληθυνικοῦ.**
:::
::: media
![](/images/lekt5007.webp)
Ἀπεικ.: ⟪लोकस्योत्तमो⟫ ⟪गिरिः⟫
⟪सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = Ὄρος Ἑβερστ
(πηγὴ εἰκόνος: [Λεπτομέρειαι](/grc/licenses#lekt5007))
:::

::: grammar-box
**σημασία:**

**Ὁ "συγκριτικὸς" σημαίνει, ἂν μὴ ἐκφράζηται τὸ συγκρινόμενον πρᾶγμα: "ἀρκέως, σφόδρα, ὑπερβολικῶς":**

:::
::: indent
π.χ. ⟪सुचितर⟫ 3 "σχεδὸν καθαρός", "καθαρτάτος", "ὑπερβολικῶς καθαρός"
:::
**Ἐκφραζομένου τοῦ συγκρινομένου αντικειμένου, τούτο τίθεται ἐν ἀπολειτικῇ (⟪पञ्चमी⟫). Ὁ συγκριτικὸς μετὰ ἀπολειτικοῦ ἀντιστοιχεῖ τῇ αὐξητικῇ μετὰ "παρ'" ἐν τῷ Γερμανικῷ.**

::: indent
π.χ. ⟪देवदत्ताद्रामो⟫ ⟪धीमत्तरः⟫ = κυρ.: "ἐκ τοῦ Δεβαδάττα ὁραθὲν ὁ Ρāμα φρονιμώτερος" = "Ὁ Ρāμα φρονιμότερός ἐστι τοῦ Δεβαδάττα"
:::
**Ὁ "ὑπερβατικός" σημαίνει, ὅταν οὐδεὶς συγκρινόμενος ἀντικείμενον ἐκφράζεται: "ἐξαιρετικός, πολύ":**

::: indent
π.χ. ⟪सत्तम⟫ 3 (πρὸς ἃ ⟪सन्त्⟫) "ἐξαιρετικῶς ἀγαθός, πολύ ἀγαθός"
:::
**Ἐκφραζομένου τοῦ συγκρινομένου αντικειμένου, τούτο τίθεται ἐν γενικῇ (⟪षष्ठी⟫) ("ἐκ", "ὑπὸ") καὶ ὁ ὑπερβατικὸς ἀντιστοιχεῖ τῷ Γερμανικῷ ὑπερβατικῷ (ἀκρότης):**

::: indent
π.χ. ⟪द्विजानां⟫ ⟪सत्तमः⟫ = "ὁ ἀρίστων τῶν δις γεγενημένων"
:::
**Τὰ ἐνδυτικὰ -⟪तर⟫ καὶ -⟪तम⟫ οὔτε μόνον ἐπὶ ἰδιωμάτων τίθενται, ἀλλὰ καὶ ἐπὶ ουσιαστικῶν, ἄκλιτα καὶ ἀκόμη ρηματικαί μορφαί:**

Παραδείγματα:

::: indent
⟪गजतम⟫ ἀρσ. "ὁ ἄριστος ἐλέφας" (⟪गज⟫) (καὶ ὁρισμὸς τοῦ Βούδδα)

⟪गोतम⟫ ἀρσ. "ὁ μέγιστος ταῦρος" (⟪गो⟫) ἢ: "ὁ πλουσιώτατος ἐν ταύροις"

⟪उद्⟫ ἀπαρ. "ἐπί", "ἀνά" » ⟪उत्तर⟫ 3 "ὑψηλότερος" » ⟪उत्तम⟫ 3 "ὕψιστος"
:::
**ἐὰν ταῦτα τὰ ἐπίθετα προστεθῶσι ρηματικῇ μορφῇ, ἀεὶ φαίνονται ἐν τῇ ἐπιρρηματικῇ μορφῇ:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

Παραδείγματα:

::: indent
⟪पचतितराम्⟫ "αυτός/αυτή/αυτό μαγειρεύει καλύτερα"

⟪पचतितमाम्⟫ "αυτός/αυτή/αυτό μαγειρεύει άριστα"
:::
**Αυτήν την μορφή έχουν και τα επίθετα αυτά, όταν προσαρτώνται σε ἀκλίνα και η παραγόμενη λέξη χρησιμοποιείται επιρρηματικά:**

::: indent
π.χ. ⟪सुतराम्⟫ (από ⟪सु⟫) "με καλύτερο τρόπο" (επιρρηματικά)
:::

![](/images/lekt5006.webp)

(Πηγή εικόνας: [Λεπτομέρειες](/grc/licenses#lekt5006))
:::
