# Ἄσκησις 9

Α) Προσπαθήσατε να προσδιορίσετε τὴν δυνατὴν σημασίαν τῶν ἑξῆς λέξεων:

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. ὅς ἐστιν ὁμοίως βραhmaνῇ = κακὸς βραhmanή

2\. mati ⟪मति⟫ : f. δόξα

3\. śravaṇa ⟪श्रवण⟫ : n. οὖς

4\. dhenuka ⟪धेनुक⟫ : m. (συνουσία) ὡς ἐκ βοός

5\. jayaka ⟪जयक⟫ : 3 νικῶν

6\. rakṣikā ⟪रक्षिका⟫ : f. φύλαξ, ἀμύλιον

7\. karṣaka ⟪कर्षक⟫ : 3 ὀρύσσων ; m. γεωργός

8\. kleśa ⟪क्लेश⟫ : m. λύπη

9\. nāyikātva ⟪नायिकात्व⟫ : n. κατάστασις ἐρωμένης

10\. tantraka ⟪तन्त्रक⟫ : 3 (μόλις) ἐκ τῆς ὀροφῆς / τοῦ υφαντικοῦ ἐρχόμενος = νέον ὑφασμένον

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : χορευτής <!-- TODO: Fallback translation -->

12\. naraka ⟪नरक⟫ : m. ἄδης

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. κυριότης

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. πολεμιστής

17\. kopa ⟪कोप⟫ : m. ὀργή

18\. veśaka ⟪वेशक⟫ : 3 εἰσπορευόμενος

19\. darśaka ⟪दर्शक⟫ : 3 θεωρῶν

20\. kopaka ⟪कोपक⟫ : 3 ὅς ἐστιν εὐκόλως ὀργιζόμενος, ὀξύθυμος

Β) Μεταφράσατε:

1\. ἔργα πάντων τῶν διγεννηθέντων:

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

(Yājñavalkyadharmaśāstra I, 118)

θυσία, μελέτη τῶν Βέδων, παροχὴ δωρεῶν.

2\. ἰδιαίτερα ἔργα βραhmanῆς:

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

(Gautamadharmasūtra X,2)

διδασκαλία, θυσία κατ’ ἐντολήν, λῆψις δωρεῶν.

3\. ἰδιαίτερα ἔργα Kṣatriya:

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं⟫ ⟪सर्वभूतानाम्⟫

(sarvabhūtānām = γενικὴ πτῶσις: "πάντων τῶν ὄντων")

(Gautamadharmasūtra X,7)

φυλακὴ πάντων τῶν ὄντων.

4\. ἰδιαίτερα ἔργα Vaiśya:

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(κατὰ Gautamadharmasūtra X,49)

γεωργία, ἐμπόριον, κτηνοτροφία καὶ δανεισμός χρημάτων.

5\. ἔργα Śūdra:

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं⟫ ⟪शुश्रूषा⟫ ⟪वार्त्त्ता⟫ ⟪कारुकुशीलवकर्म⟫ ⟪च⟫

(κατὰ Kauṭilīya-arthaśāstra 1.3.8.)

ἑρμηνεία:
dvijātīnām = γενικὴ πτῶσις πληθυντικοῦ το� dvijāti (μεταφράσατε ἐδὼ: "πρὸς τοὺς διγεννηθέντας")

kārukuśīlavakarma σύνθετον ἐστὶν Tatpuruṣa μετὰ Dvandva (kārukuśīlava) ἐν τῷ προτέρῳ μέλει. karma = ὀνομαστικὴ ενικὸς το� karman n. "ἔργον, δραστηριότης, Κάρμα" πρὸς τὴν ῥίζαν kṛ 8 U). Μεταφράσατε "ἔργον / δραστηριότης τῶν ... (γενική)" (διὰ τοῦ Dvandva δηλούμενοι).

ὑπακοὴ πρὸς τοὺς διγεννηθέντας, δραστηριότητες πρὸς τὴν διαβίωσιν, ἐργασία ὡς τεχνίτης ἢ περιπλανώμενος θεατάρχης.

6\. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः⟫ ⟪पाशुपाल्यं⟫ ⟪वणिज्या⟫ ⟪च⟫ ⟪वार्त्ता⟫

(κατὰ Kauṭilīya-arthaśāstra 1.4.1.)

οἰκονομία ἐστὶ γεωργία, κτηνοτροφία καὶ ἐμπόριον.
