# Μάθημα κβʹ

## 22.1. Ἀπόλυτον (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫)

::: grammar-box

Ἐὰν βούλῃς τὸ Σανσκριτὶ ἐκφράσαι ὅτι πρᾶξίς τινος πράγματος (⟪कर्तृ⟫) ἑτέρας πράξεως τοῦ αὐτοῦ πράγματος προηγείται ἢ συνάπτεται αὐτῇ ὡς συνοδευτικὸν περιστατόν, χρῆται τῷ ἀπολυτικῷ (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫). Ἄρα

«ὅπερ πεποίηκεν, τοῦτο ποιεῖ»· «τοῦτο ποιήσας, τοῦτο ποιεῖ»· «ἐκ τούτου ποιήσας, τοῦτο ποιεῖ»· «ἐλθών, ἰδὼν καὶ νικήσας» κτλ.

Τὸ ἀπολυτικόν ἐστιν ῥηματικὸς ἐπίρρημα, δηλαδή οὔτε κλίνεται οὔτε φλέγεται· ἀλλὰ πάντοτε — ἐκτὸς ὀλίγων ἐξαιρέσεων — τὸν αὐτὸν πράγμα (⟪कर्तृ⟫) ἔχει μετὰ τῆς πράξεως, ᾗ προηγείται ἢ συνοδεύει τὸ διὰ τοῦ ἀπολυτικοῦ δηλούμενον πρᾶγμα. Ὁ πράγματος τοῦ ἀπολυτικοῦ ἐν τῇ ὀνομαστικῇ (⟪प्रथमा⟫) ἢ ἐν τῇ ὀργανικῇ (⟪तृतीया⟫) τίθεται.

Πλὴν τῶν συνθέτων, τὸ ἀπολυτικόν ἐστιν ἓν τῶν συνηθισμένων μέσων ἐκφράσεως ἐν τῷ Σανσκριτῷ.

Bei der Übersetzung ins Deutsche vermeide man, ständig "nachdem" zu sagen. man verwende statt dessen die im Deutschen gebräuchlichen Ausdrucksweisen für zeitliche Anreihung.

**Schema:**

(nähere Bestimmung zum Absolutiv: Umstandsbestimmung, Objekt u.sw.) - Absolutiv - Absolutiv - ... - Absolutiv - ... Agens + Verbalsatz (im Aktiv oder Passiv)

:::
**Beispiele:**

::: indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = κατασκευὴ παθητική: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**  
"ὁ ἄνθρωπος εἰσέρχεται τὴν οἰκίαν, θεωρεῖ τὸ μικρὸν παιδίον καὶ λαλεῖ αὐτό."

Πλῆθος: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**
:::
## 22.2. Σχηματισμὸς τοῦ ἀπολυτικοῦ

::: grammar-box
**κατασκευὴ τοῦ ἀπολυτικοῦ**

*   ῥήματα ἄνευ προθέσεως: ἀπολυτικὸν εἰς **-tvā**
*   ῥήματα μετὰ προθέσεως: ἀπολυτικὸν εἰς **-ya** ἢ **-tya**
:::
### 22.2.1. Ῥήματα ἄνευ προθέσεως: Ἀπολυτικὸν εἰς -⟪त्वा⟫

::: grammar-box

**Παιδεία:**

(συνήθως) βαθύτατη ρίζα στη μορφή, την οποία προηγείται το PPP + **-tvā** (**-⟪त्वा⟫**)

Μόνο το αρνητικό **a-** / **an-** συμβιβάζεται με την κατάληξη **-⟪त्वा⟫** : **⟪अकृत्वा⟫** "χωρίς να έχει πράξει"

:::
**Παραδείγματα:**

::: indent
**⟪आप्त्वा⟫** "ὅτε / ὃν χρόνον ἐπελθόντος αὐτοῦ / αὐτῆς / αὐτοῦ / ἐμοῦ / σοῦ / ἡμῶν / ὑμῶν / αὐτῶν / ἀμφοτέρων ἡμῶν / ἀμφοτέρων ὑμῶν / ἀμφοτέρων αὐτῶν ἐφθασεν / ἔφθασεν / ἥκασιν / ἦλθον"

**⟪आसित्वा⟫** "ὅτε / ὃν χρόνον ἐπελθόντος αὐτοῦ (...) καθίσαντος / ἵσταται"

**⟪इत्वा⟫** "ὅτε / ὃν χρόνον ἐπελθόντος αὐτοῦ (...) πορευθέντος / ἵσταται"

**⟪स्थित्वा⟫** "ὅτε / ὃν χρόνον ἐπελθόντος αὐτοῦ (...) στάντος / ἵσταται"

**⟪जित्वा⟫** "having conquered / having been victorious"

**⟪उक्त्वा⟫** "having spoken / having been spoken"
:::
### 22.2.2. Verbs with prepositions

#### 22.2.2.1. Stems ending in a long vowel (except -ā) or a consonant

::: grammar-box

**(σχεδὸν) βαθυστάθμιον ῥίζα + -ya**

:::
**ὑποδείγματα:**

::: indent
**⟪उपनीय⟫** "ὅτι (...) προσηγάγετο / προσηνέγκεν"

**⟪प्रभूय⟫** "ὅτι (...) προεφάνη / ἦν" "ὅτι (...)" ἐξουσίαν εἶχεν"

**⟪प्राप्य⟫** "having obtained / having had (...)"
:::
#### 22.2.2.2. Roots in -ā

::: grammar-box

**ἀμετάβλητος ὑψηλοβαθμὶς ρίζη + -ya**

:::
**παράδειγμα:**

::: indent
**⟪उपस्थाय⟫** "ὅτι (...) ἐπεστάθη / ἕστηκεν"· (ἀλλ’ ἀνευ προθέσεως: **⟪स्थित्वा⟫**)
:::
#### 22.2.2.3. Ῥίζαι αἱ λήγουσαι εἰς βραχὺ -i, -u, -ṛ ἐν τῇ μηδενικῇ βαθμίδι

::: grammar-box

**ῥιζικὴ βαθμὶς + -tya**

:::
**ὑποδείγματα:**

::: indent
**⟪प्रस्तुत्य⟫** "ὅτι (...) ἐπῄνεσεν / ἐπήνει"

**⟪विस्मृत्य⟫** "ὅτι (...) ἐπέλαθε / ἐπελάθη"

**⟪संस्कृत्य⟫** "ὅτι (...) ἱερεῖον κατηρτισμένον ἐποίησεν / εἶχεν"
:::
#### 22.2.2.4. Ῥίζαι εἰς -am / -an αἱ λήγουσαι εἰς -a ἐν τῇ μηδενικῇ βαθμίδι

::: grammar-box

**Ἐπιλογόν:**

Ῥίζα ἐπὶ **-am** / **-an** + **-ya**

ἢ:

Ῥίζα ἐπὶ **-a** + **-tya**

:::
**παράδειγμα:**

::: indent
**⟪विगम्य⟫** ἢ **⟪विगत्य⟫** "ὅτι (...) παρελήλυθεν / ἐγένετο"
:::
