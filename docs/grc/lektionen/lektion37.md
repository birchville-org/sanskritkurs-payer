# Μάθημα 37

## 37.1. Το Επίρρημα (⟪क्रियाविशेषणम्⟫)

Τα επίρρημα σχηματίζονται στα Σανσκριτικά

1. μέσω πτώσεων ουσιαστικών και αντωνυμιών
2. με τη βοήθεια ειδικών καταλήξεων και προθέσεων

Στην πρώτη περίπτωση, το όριο μεταξύ ζωντανής πτώσης και επιρρήματος είναι ρευστό. Σε αυτή την κατηγορία ανήκουν ως ειδική περίπτωση τα επίρρηματα που είναι παγιωμένες, αρχαίες πτώσεις, ενώ στη κλίση χρησιμοποιούνται άλλες μορφές ή τα αντίστοιχα ουσιαστικά δεν χρησιμοποιούνται πλέον ως ουσιαστικά.

## 37.2. Επιρρηματική χρήση πτώσεων

### 37.2.1. Αιτιατική (⟪द्वितीया⟫)

::: grammar-box
Η αιτιατική (⟪द्वितीया⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά απαντώντας στα ερωτήματα:

*   με ποιον τρόπο;
*   για πόσο χρονικό διάστημα;
*   προς τα πού;
*   κ.λπ.

Η αιτιατική μπορεί να χρησιμοποιηθεί επιρρηματικά:

*   από ουσιαστικά  
Παραδείγματα:  
⟪कामम्⟫ "σύμφωνα με την επιθυμία, όπως επιθυμείς"  
⟪अर्थम्⟫ "λόγω"

*   από επίθετα στον ουδέτερο γένος  
Παραδείγματα:  
⟪सुखम्⟫ "εύκολα, ευτυχισμένα"  
⟪नित्यम्⟫ "πάντα"  
⟪साधु⟫ "σωστά, καλά"

*   από αντωνυμίες στον ουδέτερο γένος  
Παραδείγματα:  
⟪तद्⟫ "τότε, γι' αυτό"  
⟪यद्⟫ "αν, ότι"  
⟪एतद्⟫ "έτσι, εδώ, τώρα"
:::
### 37.2.2. Εργαλείκη (⟪तृतीया⟫)

::: grammar-box
Η εργαλείκη (⟪तृतीया⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά απαντώντας στα ερωτήματα:

*   με τι;
*   από ποιο μέσο;
*   κ.λπ.

Η εργαλείκη μπορεί να χρησιμοποιηθεί επιρρηματικά:

*   από ουσιαστικά  
Παραδείγματα:  
⟪अर्थेन⟫ "λόγω"  
⟪क्षणेन⟫ "την στιγμή, αμέσως" (από ⟪क्षण⟫ αρ. "στιγμή")

*   από επίθετα, συχνά και στον πληθυντικό  
Παραδείγματα:  
⟪दूरेण⟫ "μακριά, από μακριά" (προς ⟪दूर⟫ 3 "μακριά, μακρινό")  
⟪उच्चैस्⟫ "υψηλά, δυνατά" (προς ⟪उच्च⟫ 3 "υψηλό, ανωτερωμένο, δυνατός, οξύς (για φωνή)")
:::
### 37.2.3. Δατικός (⟪चतुर्थी⟫)

::: grammar-box
Σπάνια χρησιμοποιείται ο Δατικός (⟪चतुर्थी⟫) επιρρηματικά στις ερωτήσεις:

*   προς ποιον σκοπόν;
*   κ.λπ.

Παράδειγμα:
:::
::: indent
⟪अर्थाय⟫ "προς σκοπόν του, διά το ..."
:::
### 37.2.4. Αβλατίβ (⟪पञ्चमी⟫)

::: grammar-box
Ο Αβλατίβ (⟪पञ्चमी⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά στις ερωτήσεις:

*   γιατί;
*   εξαιτίας τίνος;
*   από πού;
*   κ.λπ.

Επιρρηματικά μπορεί να χρησιμοποιηθεί ο Αβλατίβ:

*   από ουσιαστικά  
π.χ. ⟪बलात्⟫ "βίαια, με βία"  

*   από επίθετα  
π.χ. ⟪दूरात्⟫ "από μακριά"  

*   από αντωνυμίες  
Παραδείγματα:  
⟪कस्मात्⟫ "γιατί"  
⟪अकस्मात्⟫ "απρόσμενα"
:::
### 37.2.5. Γενικός (⟪षष्ठी⟫)

::: grammar-box
Σπάνια χρησιμοποιείται ο Γενικός (⟪षष्ठी⟫) επιρρηματικά στην ερώτηση "μετά πόσον καιρό;"

π.χ. ⟪चिरस्य⟫ "μετά από πολύ καιρό" (προς ⟪चिर⟫ 3 "μακρός (χρόνος)")
:::
### 37.2.6. Λοκατίβ (⟪सप्तमी⟫)

::: grammar-box
Ο Λοκατίβ (⟪सप्तमी⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά στις ερωτήσεις:

*   πού;
*   υπό ποιες συνθήκες;
*   κ.λπ.

Παραδείγματα:
:::
::: indent
\-⟪अर्थे⟫ "λόγω"  
\-⟪कृते⟫ "διά το ..."  
⟪दूरे⟫ "μακριά"
:::
## 37.3. Επιρρηματική χρήση μη πλέον συνηθισμένων πτώσεων

Παραδείγματα:

## 37.4. Σύνταξις ἐπιρρημάτων μετὰ ἐπιρρηματικῶν καταλήξεων

::: grammar-box
Ἐκ τῶν ὀνοματίζων ⟪तद्⟫, ⟪इदम्⟫ ἢ ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ ἢ ⟪कु⟫ δύναται μετὰ τῶν ἐπιρρηματικῶν καταλήξεων

*   \-⟪तस्⟫ (Ἀποφατικόν)

*   \-⟪था⟫ (Τρόπος)
*   \-⟪थम्⟫ (Τρόπος)

## 37.5. Συνθετικὰ ἐπιρρηματικά

### 37.5.1. Συνθετικὰ μετ’ ἐπιρρήματος ἢ περιφραστικῶς χρωμένου πτώσεως ὡς μερὸς τῆς συνθέσεως

Παράδειγμα: ⟪सुचिरम्⟫ "πολὺν χρόνον"

### 37.5.2. Περιφραστικῶς χρώμενα ⟪बहुव्रीहि⟫

Παράδειγμα: ⟪रक्षार्थम्⟫ "κατὰ τρόπον ἀνθρώπου, οὗ σκοπός ἐστι τὸ φυλάττειν, πρὸς τὴν φύλαξιν". Ἔστι δ’ ὅστε καὶ ὡς πρὸς τὰ 5.1. ἀνήκειν λογίζεται: -⟪अर्थम्⟫ ὡς ἐπιρρηματικὸν μερὸς τῆς συνθέσεως.

### 37.5.3. ⟪अव्ययीभाव⟫-συνθετικὰ

⟪अव्ययीभाव⟫ = "ἀμετάβλητον/ἀκλίτητον γεγενημένον"

::: grammar-box
Ἐστὶ δ’ ⟪अव्ययीभाव⟫ συνθετικὸν ἐπιρρηματικόν, οὗ τὸ πρῶτον μέρος ἐστὶν ἀκλίτητον (μετὰ τὴν λέξιν, σωματίδιον κ.λπ.), καὶ τὸ δεύτερον μέρος ἐστὶν ὄνομα, τὸ δέχεται τὴν κατάληξιν τῆς αἰτιατικῆς ἑνικοῦ οὐδετέρου.

Κατὰ τὴν ἀνάλυσιν τοῦ συνθετικοῦ, τὸ πρῶτον μέρος ἄρχει τοῦ δευτέρου:

Παραδείγματα:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = "πρὸς τὴν πυράν"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "κατὰ δύναμιν"

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = "πρὸς τὰ ἔμπροσθεν, ἀντιμέτωπον"
:::

π.χ. ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ = "ὡς ἂν βούλονται, κατὰ βούλησιν, καθ’ ὅσον ἐθέλουσι"

## 37.8. Ἡ ἐρωτηματικὴ πρότασις

::: grammar-box
"Τίς;, πῶς;, τί;, διὰ τί; διότι; ἵνα;
Ὁ μὴ ἐρωτῶν μένει ἀμαθής."

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

Μotto τῆς Σέσαμος Ἄνοιξον, ὅ ἐστιν ἀγαθὸς κανών διὰ τὴν ζωὴν καὶ τὴν σπουδὴν Σανσκριτοῦ
:::
Βλ. καὶ [Μάθημα 4](lektion04.md).

Δεῖ διαφέρειν

*   ἐρωτήσεις λέξεων (ἐπικουρικαὶ ἐρωτήσεις)
*   ἐρωτήσεις προτάσεων

Κατὰ τὰς ἐρωτήσεις λέξεων ζητεῖται περὶ ἑνὸς πράκτορος (⟪कर्तृ⟫), ἑνὸς ἀντικειμένου, μιᾶς ἐνεργείας, ἑνὸς περιστατικοῦ κ.τ.λ., ὥσπερ:

*   τίς ἔρχεται;
*   τί ποιεῖ ὁ Ράμα;
*   τίνος ἀκούει αὐτός;
*   πῶς λαλεῖ Σανσκριτὰ αὐτή;
*   ποῦ ἐστιν ἡ μήτηρ;

Κατὰ τὰς ἐρωτήσεις προτάσεων ζητεῖται ὁλόκληρος ἡ περιεχόμενος τῆς προτάσεως, ὥσπερ:

*   πορεύεται ὁ Ράμα σήμερον εἰς τὴν Ὀφτερλίνδεν;
*   ἐστὶν ὀρθόν, ὅτι ... ;

### 37.8.2. Interrogative Sätze

::: grammar-box
Manchmal ist nur aus dem Zusammenhang erkennbar, ob ein Satz eine Frage ist.
:::
::: grammar-box
Schema I:

Verb - restlicher Satz
:::
Beispiel:
::: indent
⟪गमिष्यति ब्राह्मणबालो गुरुम् ।⟫ "Wird der Brahmanenjunge zu einem Meister gehen?"
:::
::: grammar-box
Schema II:

Fragepartikel (meist am Satzanfang) - Satz

Die wichtigsten Fragepartikel sind:

*   ⟪अपि⟫

*   ⟪किम्⟫ (lässt oft eine negative Antwort erwarten)

*   ⟪कच्चिद्⟫


Diese Partikel entsprechen dem Fragezeichen.
:::
Beispiel:
::: indent
⟪अपि सत्यम् ।⟫ "Ist es auch wahr?"

⟪किं शक्नोति ।⟫ "Kann er denn?"

⟪कच्चित्क्षत्रियेण शत्रवो जिताः ।⟫ "Hat etwa der Kṣatriya die Feinde besiegt?"
:::
Anmerkung: ⟪किम्⟫ kann ausser "was?" und als Fragepartikel auch "warum?, wozu?" bedeuten. So bes. mit dem Instrumentalis (⟪तृतीया⟫):
::: indent
⟪किं क्रोधेन ।⟫ "Wozu der Zorn? Was nützt der Zorn? Was soll der Zorn?"
:::

## 37.11. Άσκηση επανάληψης

Μεταφράστε στα Σανσκριτικά χρησιμοποιώντας αποκλειστικά ρηματικές μορφές του Παρακειμένου:

Μια φορά κι έναν καιρό, ένας γέροντας πήγαινε σε ένα άλλο χωριό και κουράστηκε στο δρόμο. Πήγε λοιπόν, για να ξεκουραστεί, στα πόδια ενός δέντρου μάνγκο που στεκόταν στο πλάι. Σε αυτό το δέντρο υπήρχαν ώριμα καρποί. Ο γέροντας πείραξε για αυτούς. Αλλά δεν μπορούσε να ανέβει στο δέντρο και να πιάσει τους καρπούς. Για τύχη, σε αυτό το δέντρο υπήρχαν κάποια μαϊμούδια που έτρωγαν καρπούς. Όταν τους είδε, χαρήκε ο γέροντας. Τι έκανε; Πήρε μερικές πέτρες, στοχεύσε τις μαϊμούδες και ρίξε. Οι θυμωμένες μαϊμούδες έκοψαν μερικούς καρπούς και τους ρίξανε στον γέροντα. Ο γέροντας πήρε αυτούς με χαρά και πήγε στην επιθυμητή περιοχή του. Ιδού, η μοίρα του γέροντα!
