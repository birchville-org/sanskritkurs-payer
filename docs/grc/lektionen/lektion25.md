# Μάθημα κεʹ

## 25.1. Σχηματισμὸς τῆς ἀφαιρετικῆς (⟪पञ्चमी⟫ = "πέμπτη πτωτικὴ κατάληξις")

::: grammar-box
Πλὴν τῶν ἁρρενογόνων / οὐδετερογόνων ἐπὶ -α ὅπως καὶ τῶν ἀντωνυμιῶν, ἐν τῷ ἑνικῷ ἐν πᾶσαις ταῖς κλίσεσι τὰ σχήματα τῆς ἀποτίνουσης (⟪पञ्चमी⟫) ταὐτὰ τοῖς τῆς γενικῆς (⟪षष्ठी⟫) εἰσίν.

Πλὴν τῶν προσωπικῶν ἀντωνυμιῶν, ἐν πᾶσαις ταῖς κλίσεσι τὸ πληθυντικόν, τὰ σχήματα τῆς ἀποτίνουσης ταὐτὰ τοῖς τῆς δοτικῆς (⟪चतुर्थी⟫) εἰσίν.
:::
Νυνὶ γινώσκεις τὴν αἰτίαν τοῦ τάκτου τῶν πτώσεων (⟪विभक्ति⟫) ἐν τῇ Σανσκριτικῇ: οὕτως κεῖνται, ὥστε τὰ ὁμόφωνα σχήματα ὅσον δυνατόν ἐγγύτατα — ἢ ἀλλήλοις — κεῖται.

::: grammar-box
**Αἰτιατικὸς ἑνικοῦ τῶν ἁρρενογόνων / οὐδετερογόνων ἐπὶ -α**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Ἐρωτηματικαί, ἀναφορικαὶ καὶ ἐκθετικαὶ ἀντωνυμίαι:

::: grammar-box

| :--- | :--- | :--- |

| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |

| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Χρῆσις τῆς ἀφαιρετικῆς (⟪पञ्चमी⟫)

"Ὀ ἀποστιβατικὸς σημαίνει τὸ μένον, ὅταν τι ἀπ’ αὐτοῦ ἀπαλλάττεται."

Πάνινος 2,3,28 + 1,4,24

Ὁ ἀποστιβατικὸς τίθεται κυρίως ἐπὶ τῶν ἐρωτημάτων "Πόθεν;", "Διὰ τί;".

::: grammar-box
1\. Ὁ ἀποστιβατικὸς σημαίνει οὖν τὴν ἀρχήν, τὴν καταγωγὴν καὶ τὸ ὑλικόν.

Ἡ αἰτιατικὴ δύναται διὰ τοῦτο καὶ τὸ πρόσωπον δηλοῦν, οὗ τις ἀγοράζει, ἀκούει, ἐπιθυμεῖ κτλ.
:::
Παραδείγματα:

::: indent
⟪ग्रमादागच्छति⟫ = "ἔρχεται ἐκ τοῦ χωρίου"

⟪अश्वात्पतितः⟫ = "πεπτωκὼς ὑπὸ τοῦ ήπου"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "παρ᾽ αὐτῶν ληφθέν"
:::
Παραδείγματα:

::: indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟫ = "ακούει παρὰ τοῦ διδασκάλου περὶ τῆς δικαιοσύνης"

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = "ὁ Βραχμανὸς ἐπιθυμεῖ παρὰ τοῦ Κσατρίου γαῖαν"
:::
::: grammar-box
2\. ἡ Αἰτιατικὴ χρήσις ἐστὶν παρὰ ῥήμασιν σημαίνουσι "ἀπέχεσθαι", "προστατεύειν ἀπό", "ἀμύνεσθαι κατά", "φοβεῖσθαι":
:::
παράδειγμα:

::: indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = "προστατεύει ἀπὸ τῶν ἐχθρῶν"
:::
::: grammar-box
3\. ἡ Αἰτιατικὴ δηλοῖ τὸν λόγον ἢ τὴν αἰτίαν:
:::
παραδείγματα:

::: indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = "κτείνει τὸν υἱὸν ἐκ θυμοῦ"

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = "ὅτι κακὸν ἐποίησεν, εἰς τὴν ἄβυσσον καταβαίνει" (ὅτι ἐστὶν οὗ δι’ ὃ κακὸν ἐπράχθη)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = "ὅτι κακὸν ποιεῖ / ἐποίησεν, εἰς τὴν ἄβυσσον καταβαίνει"
:::
Τὰ οὐθὲν θηλυκὰ ὀνόματα, ἵνα τὴν αἰτίαν τινὸς πράξεως δηλώσωσιν, δύναται εἶναι ἐργαλειακῇ (⟪तृतीया⟫) ἢ ἀποφορικῇ (⟪पञ्चमी⟫). Τὰ θηλυκὰ ἐν τούτῳ τῇ σημασίᾳ συνήθως ἐν τῇ ἐργαλειακῇ εἰσίν, δύναται δὲ κατὰ καιροὺς ἐν τῇ ἀποφορικῇ εἶναι.

## 25.3. Τὸ ἐπίθημα -⟪तस्⟫

::: grammar-box
Ἐὰν βούλῃ τὸν ἐν τῷ ἑνικῷ (ἀμφιβολία) ἐκφράζειν ὅτι τὸ ρῆμα ἐν τῇ ἀπολειτικῇ σημασίᾳ χρῆται, δύνασαι προστιθέναι τὸ ὑπόθημα -⟪तस्⟫ πρὸς τὴν ῥίζαν τοῦ λέξεως, ὃ ἐκφράζει ἐπίρρημα μετὰ ἀπολειτικῆς σημασίας (ἐπὶ τῷ ἐρωτήματι "Πόθεν;"):
:::
Παραδείγματα:

::: indent
⟪आदितस्⟫ = "ἀπ' ἀρχῆς"

⟪धर्मतस्⟫ = "διὰ τὸν δάρμαν, διὰ τὴν αἰτίαν τοῦ δάρμαν"
:::
::: grammar-box
Τὸ ὑπόθημα -⟪तस्⟫ ἐπικρατεῖ καὶ πρὸς τὰ ὑποκείμενα:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "ἐκεῖθεν, ἐκεῖ, ἐκείσε, ἐπ' αὐτῷ, τότε, διὰ τοῦτο"

⟪यद्⟫ : ⟪यतस्⟫ "ὅστις, ὅθεν, πόθεν, ποῖ, διὰ τί, ὅτι" (σχετικόν)

⟪किम्⟫ :  ⟪कुतस्⟫ "πόθεν;" "διὰ τί;"
:::
## 25.4. Ἄλλοι τρόποι τοῦ δηλοῦν αἰτίας

::: grammar-box
**1\. Σχετικοί λόγοι**

Οἱ σχετικοὶ λόγοι συχνὰ δηλοῦσιν αἰτιακὴν (ἀποφαινόμενον), συνεπαγωγικὴν (ἐπικοινωνοῦν) ἢ τελικὴν (σκοποῦν) σχέσιν πρὸς τὸν κύριον λόγον.

Μοφαὶ τοῦ σχετικοῦ ἀντωνύμου, αἵτινες ὡς αἰτιακὴ σύγκεισι dienen:

*   ἀπολειπτικῶς:
    *   ⟪यतस्⟫ ... ὑπόθεσις ... ⟪ततस्⟫ ... κύριον ῥᆴμα ... = "ὅτι ..., διὰ τοῦτο ..."
    *   ⟪यस्मात्⟫ ... ὑπόθεσις ... ⟪तस्मात्⟫ ... κύριον ῥᆴμα ... = "ὅτι ..., διὰ τοῦτο ..."
*   ὀργανικῶς:
    *   ⟪येन⟫ ... ὑπόθεσις ... ⟪तेन⟫ ... κύριον ῥᆴμα ... = "δι' οὗ/ὅτι ..., διὰ τοῦτο / διό ..."
:::
παράδειγμα:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = "Ἐπεὶ ὁ Ρāμα εὐδαιμονίαν ἐπιθυμεῖ, τηρεῖ τὴν ὁρμήν"
:::
::: grammar-box
**2\. ⟪हि⟫**

τὰ κύρια ῥήματα δύναται συνδέεσθαι διὰ τῆς μετοχῆς ⟪हि⟫ "γάρ, ὅτι" ἀλλήλοις. Πρότασις μετὰ ⟪हि⟫ (ἥτις οὐκ ἔστιν ἐν τῇ πρώτῃ θέσει, ἀλλὰ διανοητικῶς ἐν τῇ δευτέρᾳ θέσει εἶναδεῖ) αἰτίαν παρέχει ἢ περὶ τῆς προτέρας προτάσεως ἢ περὶ τῆς ἐπομένης προτάσεως:
:::
παράδειγμα:

::: indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = "Οἱ ἄνθρωποι ποιοῦσι ἀγαθὰ. Βούλονται γάρ εἰς τὸν οὐρανὸν ἐλθεῖν."
:::
::: grammar-box
**3\. Ὀργανικός (⟪तृतीया⟫)**

Παρὰ τὴν ἀφαιρετικὴν (⟪पञ्चमी⟫) χρῆσις τῇ ὀργανικῇ (⟪तृतीया⟫) πρὸς τὴν ὑπόδειξιν τοῦ λόγου ἢ τῆς αἰτίας. Κατὰ τὰ θηλυκὰ ὀνόματα ἀναγκαία ἐστὶν ἡ ὀργανική.
:::
Παράδειγμα:

::: indent
⟪क्रोधेन⟫ ⟪पुत्रं⟫ ⟪हन्ति⟫ = «Ἀναιρεῖ τὸν υἱὸν ἐκ θυμοῦ» = «Ἀναιρεῖ τὸν υἱὸν ἐν θυμῷ»
:::
::: grammar-box
**4\. Ὀνόματα**

Πέραν τούτου, φυσικῶς δύναται τις καὶ ἐκφράζειν αἰτίας διὰ συντάξεων μετὰ

*   ⟪कारण⟩ n. «αἰτία»: ⟪कारणात्⟩ ⟪।⟩ ⟪कारणेन⟩
*   ⟪हेतु⟩ m.
*   ἄλλα ὀνόματα ἐν τῇ σημασίᾳ «αἰτία»

Γενική (⟪षष्ठी⟫) ἢ ὡς συντελεστὴς σύνθετων:
:::
παράδειγμα:

::: indent
⟪पुण्यस्य⟫ ⟪कारणात्⟫ (⟪हेतोः⟫ κ.ο.κ.) = «διὰ τὴν ἀρετήν»
:::
::: grammar-box
**5\. ⟪इति⟫**

ἡ αἰτία πράξεως δύναται διὰ νοήματος μετὰ ⟪इति⟫ δηλοῦσθαι:
:::
παράδειγμα:

::: indent
⟪सम्यक्संबुद्धः⟫ ⟪सुगत⟫ ⟪इत्यानन्दो⟫ ⟪गौतमं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫  = «ὅτι ὁ Σουγάτα τελείως πρὸς τὴν ἀλήθειαν ἐγήγερται, ὁ Ānanda τὸν Gautama περὶ τῆς διδασκαλίας ἐρωτᾷ» («“Νομίζων “Ὁ Σουγάτα τελείως πρὸς τὴν ἀλήθειαν ἐγήγερται” ...»)
:::

## 25.6. Ἄσκησις

Α) Συμπληρώστε τὰ παραδείγματα κλίσεως ἐκ [Μαθήματος 16](lektion16.md), ἄσκησις ἀναμνήσεως Α, προστιθέμενων 4. Δακτυλίου (⟪चतुर्थी⟫) καὶ 5. Ἀποφατικοῦ (⟪पञ्चमी⟫). Σχηματίσατε δὲ κλίσεις πᾶσιν ταῖς μέχρι νῦν διδασκομέναις μορφαῖς πρὸς
