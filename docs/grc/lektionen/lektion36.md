## 36.2. Ὁ περιφραστικὸς παρακείμενος (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
Ὁ περιφραστικὸς παρακείμενος (⟪अनुप्रयोगलिट्⟫) χρῆσις ἔχει:

1. παρὰ ταῖς ἐκγενομέναις κλίσεσι (Καυστικόν, Ἐπιθυμητικόν, Συχναστικόν, Ὁνοματοποιία)
2. παρὰ ρίζαις, αἵτινες ἄρχονται φωνήεντος μακροῦ (ἐκτὸς ā-) ἢ φωνήεντος (ἐκτὸς a-) πρὸ δύο συλλαβῶν
3. παρὰ τισιν ἄλλαις ρίζαις
:::
::: grammar-box
**Σύνταξις:**

(ἀσθενὴς) σταθμὸς ἐνεστῶτος + -ām + ἀντιστοιχία παρακειμένου ὑπὸ ⟪कृ⟫, ⟪अस्⟫ ἢ ⟪भू⟫

- Auslautender Stammvokal wird vor -ām guṇiert.
- ⟪अस्⟫ καὶ ⟪भू⟫ ἐπὶ τῶν ἄτμανεπαδα-ῤῥημάτων ἐν τῷ παρασηπαδίᾳ συζυγία.
:::
Das periphrastische Perfekt ist wohl aus dem Akkusativ eine Verbalnomens auf -ā entstanden. Dieser Akkusativ wird -- wie auch sonst oft -- adverbial verwendet.
