# Ἄσκησις 14

Μεταφράσατε τὰ ἑξῆς παροιμίας καὶ μνημονεύσατε αὐτά:

⟪निचो⟫ ⟪वदति⟫ ⟪न⟫ ⟪कुरुते⟫
⟪वदति⟫ ⟪न⟫ ⟪साधुः⟫ ⟪करोत्येव⟫ ⟪॥१॥⟫
ὁ ταπεινὸς οὔτε λέγει οὔτε ποιεῖ, ὁ δὲ ἀγαθὸς οὔτε λέγει, ποιεῖ δέ.

⟪शीलं⟫ ⟪नरस्य⟫ ⟪भूषणम्⟫ ⟪॥२॥⟫
ἡ ἀρετὴ κόσμος τοῦ ἀνθρώπου ἐστίν.

⟪सत्येन⟫ ⟪जनानां⟫ ⟪सुखं⟫ ⟪भवति⟫ ⟪॥३॥⟫
διὰ τῆς ἀληθείας εὐδαιμονία τοῖς ἀνθρώποις γίνεται.

⟪पापा⟫ ⟪नराः⟫ ⟪स्वर्गं⟫ ⟪न⟫ ⟪लभन्ते⟫ ⟪॥४॥⟫
οἱ κακοὶ ἄνθρωποι εἰς τὸν οὐρανὸν οὐκ ἔρχονται.

⟪सत्यं⟫ ⟪लोकस्य⟫ ⟪दीपः⟫ ⟪॥५॥⟫
ἡ ἀλήθεια φῶς τοῦ κόσμου ἐστίν.

Α) Σχηματίσατε τὴν γενικὴν ἑνικοῦ καὶ πληθυντικοῦ τῶν ἑξῆς λέξεων. Δότε σημασίαν καὶ γένος τῶν λέξεων:

⟪१⟫. ⟪अनृत⟫ : οὐκ ἀλήθεια — ⟪अनृतस्य⟫ ⟪अनृतानाम्⟫

⟪२⟫. ⟪ऋषि⟫ : σοφιστὴς τῶν Βέδων — ⟪ऋषेः⟫ ⟪ऋषीणाम्⟫

⟪३⟫. ⟪पाद⟫ : πούς — ⟪पादस्य⟫ ⟪पादानाम्⟫

⟪४⟫. ⟪बुद्धि⟫ : γνῶσις — ⟪बुद्धेः⟫ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम्⟫

⟪५⟫. ⟪गुरु⟫ : διδάσκαλος — ⟪गुरोः⟫ ⟪गुरूणाम्⟫

⟪६⟫. ⟪स्वर्ग⟫ : οὐρανός — ⟪स्वर्गस्य⟫ ⟪स्वर्गाणाम्⟫

⟪७⟫. ⟪नगर⟫ : πόλις — ⟪नगरस्य⟫ ⟪नगराणाम्⟫

⟪८⟫. ⟪धेनु⟫ : ἵππος — ⟪धेनोः⟫ (⟪धेन्वाः⟫) ⟪धेनूनाम्⟫

⟪९⟫. ⟪द्विज⟫ : διγενής — ⟪द्विजस्य⟫ ⟪द्विजानाम्⟫

⟪१०⟫. ⟪मुक्ता⟫ : ἡ λυθεῖσα — ⟪मुक्तायाः⟫ ⟪मुक्तानाम्⟫

⟪११⟫. ⟪विद्या⟫ : ἐπιστήμη, γνῶσις — ⟪विद्यायाः⟫ ⟪विद्यानाम्⟫

⟪१२⟫. ⟪वर्ण⟫ : τάξις — ⟪वर्णस्य⟫ ⟪वर्णानाम्⟫

⟪१३⟫. ⟪द्विजाति⟫ : 3 διγενής — ⟪द्विजातेः⟫ (⟪द्विजात्याः⟫) ⟪द्विजातीनाम्⟫

⟪१४⟫. ⟪रूप⟫ : μορφή — ⟪रूपस्य⟫ ⟪रूपाणाम्⟫

⟪१५⟫. ⟪प्रतिग्रह⟫ : λῆψις — ⟪प्रतिग्रहस्य⟫ ⟪प्रतिग्रहाणाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 ὑπομένω — ⟪सोढस्य⟫ ⟪सोढायाः⟫ ⟪सोढानाम्⟫

⟪१७⟫. ⟪नायिका⟫ : ἐρώμενη — ⟪नायिकायाः⟫ ⟪नयिकानाम्⟫

⟪१८⟫. ⟪साध्वी⟫ : ἁγία — ⟪साध्व्याः⟫ ⟪साध्वीनाम्⟫

⟪१९⟫. ⟪अग्नि⟫ : πῦρ — ⟪अग्नेः⟫ ⟪अग्नीनाम्⟫

⟪२०⟫. ⟪वैश्या⟫ : γυνὴ Βαιśυῶν — ⟪वैश्यायाः⟫ ⟪वैश्यानाम्⟫

⟪२१⟫. ⟪लोक⟫ : κόσμος, ἄνθρωποι — ⟪लोकस्य⟫ ⟪लोकानाम्⟫

⟪२२⟫. ⟪उक्ति⟫ : ῥῆμα — ⟪उक्तेः⟫ (⟪उक्त्याः⟫) ⟪उक्तीनाम्⟫

⟪२३⟫. ⟪शत्रु⟫ : ἐχθρός — ⟪शत्रोः⟫ ⟪शत्रूणाम्⟫

⟪२४⟫. ⟪सुखवन्त्⟫ : 3 εὐδαίμων — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : γυνὴ ἔχουσα υἱούς ἕνα ἢ πλείους — ⟪पुत्रवत्याः⟫ ⟪पुत्रवतीनाम्⟫

⟪२६⟫. ⟪जल⟫ : ὕδωρ — ⟪जलस्य⟫ ⟪जलानाम्⟫

⟪२७⟫. ⟪मार्ग⟫ : ὁδός — ⟪मर्गस्य⟫ ⟪मर्गाणाम्⟫

⟪२८⟫. ⟪मोक्ष⟫ : λύτρωσις, σωτηρία — ⟪मोक्षस्य⟫ ⟪मोक्षाणाम्⟫

⟪२९⟫. ⟪शूद्रा⟫ : γυνὴ Σούδρων — ⟪शूद्रायाः⟫ ⟪शूद्राणाम्⟫

⟪३०⟫. ⟪अन्न⟫ : τροφή, βρῶμα — ⟪अन्नस्य⟫ ⟪अन्नानाम्⟫

⟪३१⟫. ⟪साधु⟫ : ἅγιος — ⟪साधोः⟫ ⟪साधनाम्⟫

⟪३२⟫. ⟪नीति⟫ : ἡγεμονία — ⟪नीत्याः⟫ ⟪नीतीनाम्⟫

⟪३३⟫. ⟪योध⟫ : πολεμιστής, στρατιώτης — ⟪योधस्य⟫ ⟪योधानाम्⟫

⟪३४⟫. ⟪सत्यवन्त्⟫ : 3 ἀληθινός — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : κέρδος — ⟪लाभस्य⟫ ⟪लाभानाम्⟫

⟪३६⟫. ⟪मोह⟫ : σύγχυσις, ἀγνόησις — ⟪मोहस्य⟫ ⟪मोहानाम्⟫

⟪३७⟫. ⟪गति⟫ : πορεία, σκοπός — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम्⟫

⟪३८⟫. ⟪प्रश्न⟫ : ἐρώτημα — ⟪प्रश्नस्य⟫ ⟪प्रश्नानाम्⟫

⟪३९⟫. ⟪सृष्टि⟫ : κτίσις — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम्⟫

⟪४०⟫. ⟪नेत्र⟫ : ὀφθαλμός — ⟪नेत्रस्य⟫ ⟪नेत्राणाम्⟫


⟪४१⟫. ⟪गुरुता⟫ : f. ἡγεμονία — ⟪गुरुतायाः⟫ ⟪गुरुतानाम्⟫

⟪४२⟫. ⟪ईश्वर⟫ : m. ὁ ΚΥΡΙΟΣ — ⟪ईश्वरस्य⟫ ⟪ईश्वराणाम्⟫

⟪४३⟫. ⟪कारण⟫ : n. αἰτία — ⟪कारणस्य⟫ ⟪कारणानाम्⟫

⟪४४⟫. ⟪कृत⟫ : 3 πεποίηκε — ⟪कृतस्य⟫ (⟪कृतायाः⟫) ⟪कृतानाम्⟫

⟪४५⟫. ⟪धर्मवन्त्⟫ : 3 δίκαιος, θρησκευτικός — ⟪धर्मवतः⟫ (⟪धर्मवत्याः⟫) ⟪धर्मवताम्⟫ (⟪धर्मवतीनाम्⟫)

⟪४६⟫. ⟪युद्ध⟫ : 3 ἀμύνεται — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम्⟫

⟪४७⟫. ⟪दर्शन⟫ : n. ὄψις, φαινόμενον — ⟪दर्शनस्य⟫ ⟪दर्शनानाम्⟫

⟪४८⟫. ⟪धातु⟫ : m. στοιχεῖον, ῥίζα ρήματος — ⟪धातोः⟫ ⟪धातूनाम्⟫

⟪४९⟫. ⟪गूढा⟫ : f. ἡ κρυπτή — ⟪गूढायाः⟫ ⟪गूढानाम्⟫

⟪५०⟫. ⟪ईष्टा⟫ (2 σημασίαι): f. ἡ ἐπιθυμητή, ἡ θυσιαζομένη — ⟪इष्टायाः⟫ ⟪इष्टानाम्⟫

⟪५१⟫. ⟪उदित⟫ : 3 εἴρηκε — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम्⟫

⟪५२⟫. ⟪इदम्⟫ : 3 οὗτος — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 τί — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) Μεταφράσατε:

⟪१⟫. ⟪ब्राह्मणस्य⟫ ⟪पुत्रो⟫ ⟪ब्राह्मण्या⟫ ⟪ग्रामं⟫ ⟪गतः⟫ ⟪।⟫ (2 τρόποι)
ὁ υἱὸς τοῦ βραhmaνοῦ εἰς τὸ κώμην τοῦ βραhmaνίδος ἐπορεύθη. ὁ υἱὸς τοῦ βραhmaνοῦ μετὰ τῆς βραhmaνίδος εἰς τὴν κώμην ἐπορεύθη.

⟪२⟫. ⟪यज्ञस्याग्निनान्नं⟫ ⟪दग्धम्⟫ ⟪।⟫
τὸ ἱερὸ πῦρ τὴν τροφὴν κατέκαυσεν.

⟪३⟫. ⟪बुद्धः⟫ ⟪स्तयस्य⟫ ⟪बुद्ध्या⟫ ⟪मुक्तः⟫ ⟪।⟫
ὁ Βούδας διὰ τῆς γνώσεως τῆς ἀληθείας ἐλύθη.

⟪४⟫. ⟪अधर्मो⟫ ⟪ऽनृतस्य⟫ ⟪वदनमित्यृषयो⟫ ⟪वदन्ति⟫ ⟪।⟫
οἱ σοφοὶ τῶν Βέδων λέγουσι ὅτι ψεύδεσθαι ἀδίκημά ἐστιν.

⟪५⟫. ⟪नरा⟫ ⟪देवानां⟫ ⟪यज्ञैर्न⟫ ⟪मुच्यन्ते⟫ ⟪।⟫
οἱ ἄνθρωποι διὰ θυσιῶν εἰς θεοὺς οὐ λύονται.

⟪६⟫. ⟪बलवन्तः⟫ ⟪क्षत्रियाः⟫ ⟪शत्रूणां⟫ ⟪धनवन्ति⟫ ⟪नगराणि⟫ ⟪जयन्ति⟫ ⟪।⟫
οἱ δυνατοὶ Κσατρίυες καταλαμβάνουσι τὰς πλούσιας πόλεις τῶν ἐχθρῶν.

⟪७⟫. ⟪कवेरुक्तिं⟫ ⟪शृण्वन्ति⟫ ⟪।⟫
ἀκούουσι τὸν λόγον τοῦ ποιητοῦ.

⟪८⟫. ⟪कविर्देव्याः⟫ ⟪कृतं⟫ ⟪वद⟫τι ⟪।⟫
ὁ ποιητὴς ἀπαγγέλλει τὸ ἔργον τῆς θεοῦ.

⟪९⟫. ⟪द्विजाः⟫ ⟪पशोर्लाभमिच्छन्ति⟫ ⟪।⟫
διजन्मῖνες ἐπιθυμοῦσι βοσκήματα λαβεῖν.

⟪१०⟫. ⟪रामः⟫ ⟪पुण्यवतो⟫ ⟪गुरोर्मन्त्रस्य⟫ ⟪स्मरति⟫ ⟪।⟫
ὁ Ρᾶμα μνημονεύει τὸν μαητρα τοῦ ἀρετῶνος διδασκάλου.

⟪११⟫. ⟪अयं⟫ ⟪बालः⟫ ⟪कस्याः⟫ ⟪पुत्रः⟫ ⟪।⟫
τίνος (f.) υἱὸς ἐστιν οὗτος ὁ παῖς;

⟪१२⟫. ⟪केषामिमानि⟫ ⟪गृहाणि⟫ ⟪।⟫
τίνι ἄνθρωποι ταῦτα οἰκίαι;

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम्⟫ ⟪।⟫
τίνος τροφὴν οὗτος βέδικος σοφὸς ἔθυσεν;
