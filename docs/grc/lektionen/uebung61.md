# Ἄσκησις 61

Ἡ μαθησιακὴ ἐνότητα 61 συνιστᾷ τὸ πέρας τοῦ μαθήματος τῶν Σανσκριτικῶν καὶ οὐκ ἔχει περαιτέρω γραπτὰς ἀσκήσεις. 

Μετὰ τὴν μελέτην τῶν ῥιζικῶν οὐσιαστικῶν, τοᦳ μελλουμένου περιφραστικοῦ καὶ τῶν ὀνοματοπαγώγων, τεθεμελιώθησαν αἱ βάσεις διὰ τὴν ἀνάγνωσιν κειμένων Σανσκριτικῶν ὀригинал. Τὸ μάθημα λήγει τῇ παραδοσιακῇ ἐπικλήσει πρὸς τὸν Gaṇeśa (⟪श्रीगणनाथ⟫), ἥτις σημαίνει τὴν μετάβασιν ἀπὸ τοῦ διδακτικοῦ βιβλίου πρὸς τὴν αὐτεξουσίαν ἀνάγνωσιν.
