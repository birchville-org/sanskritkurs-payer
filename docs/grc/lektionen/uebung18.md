# Ἄσκησις 18

Α) Μεταφράσατε τὸ ⟪सुभाषित⟫ ἐν ἀρχῇ τῆς μαθήσεως.

⟪नास्ति⟫ ⟪कामसमो⟫ ⟪व्याधिर्⟫  
⟪नास्ति⟫ ⟪मोहसमो⟫ ⟪रिपुः⟫ ⟪।⟫  
⟪नास्ति⟫ ⟪क्रोधसमो⟫ ⟪वह्निर्⟫  
⟪नास्ति⟫ ⟪ज्ञानसमं⟫ ⟪सुखम्⟫ ⟪॥⟫  
Οὐκ ἔστι νόσος ὡς ἀγάπη,
Οὐκ ἔστι δόλιος καὶ ἐχθρὸς ὡς ἀγνοία,
Οὐκ ἔστι πῦρ ὡς μῆνις,
Οὐκ ἔστι εὐδαιμονία ὡς γνῶσις.

Β) Μεταφράσατε ταῦτα τὰ Τατπορουṣα:

⟪१⟫. ⟪सुकर⟫ ⟪३⟫ — ῥᾴδιον ποιεῖν

⟪२⟫. ⟪सुकुल⟫ θηλ. — εὐγενὴς οἶκος

⟪३⟫. ⟪सुकृति⟫ θηλ. — εὐεργεσία

⟪४⟫. ⟪अकरण⟫ ουδ. — ἀπραξία

⟪५⟫. ⟪दुरिष्ट⟫ ουδ. — κακὸς ἐπιθυμία

⟪६⟫. ⟪दुरिष्टि⟫ θηλ. — ἁμαρτάνουσα θυσία

⟪७⟫. ⟪सुखादित⟫ 3 — καλῶς πεπυρωμένον

⟪८⟫. ⟪दुष्कर⟫ 3 — χαλεπὸν ποιεῖν

⟪९⟫. ⟪दुर्जय⟫ 3 — χαλεπὸν νικᾶν

⟪१०⟫. ⟪सुगत⟫ αρσ. — καλῶς (διὰ τῶν μετοικεσιῶν) πορευθείς (= Βούδας)

⟪११⟫. ⟪सुजन⟫ αρσ. — καλὸς ἄνθρωπος

⟪१२⟫. ⟪दुरुक्ति⟫ θηλ. — χαλεπὴ λαλία

⟪१३⟫. ⟪दुरुपदेश⟫ αρσ. — κακὴ ὁδηγία

⟪१४⟫. ⟪सुजात⟫ 3 — εὐγενής

⟪१५⟫. ⟪सु⟫guru 3 — σφόδρα χαλεπόν

⟪१६⟫. ⟪अनाप्त⟫ 3 — ἀπρεπές

⟪१७⟫. ⟪अनीति⟫ θηλ. — ἀκόσμιος ἔτις

⟪१८⟫. ⟪अनीश्वरत्व⟫ ουδ. — οὐ-ΚΥΡΙΟΣ-εἶναι

⟪१९⟫. ⟪सुदुःख⟫ ουδ. — μέγα πάθος

⟪२०⟫. ⟪दुर्जन⟫ αρσ. — κακὸς ἄνθρωπος

⟪२१⟫. ⟪दुर्दग्ध⟫ 3 — κακῶς πεπυρωμένον

⟪२२⟫. ⟪अतिकृत⟫ 3 — ὑπερβολή

⟪२३⟫. ⟪सुपुत्र⟫ αρσ. — καλὸς υἱός

⟪२४⟫. ⟪सुबुद्धि⟫ θηλ. — καλὴ ὄψις

⟪२५⟫. ⟪दुष्पुत्र⟫ αρσ. — κακὸς υἱός

⟪२६⟫. ⟪दुष्प्रणीत⟫ 3 — κακῶς ἐκτελεσθέν

⟪२७⟫. ⟪सुमति⟫ θηλ. — φιλανθρωπία

⟪२८⟫. ⟪दुर्लभ⟫ 3 — χαλεπὸν λαβεῖν

⟪२९⟫. ⟪दुर्वच⟫ 3 — χαλεπὸν εἰπεῖν

⟪३०⟫. ⟪दुर्वचन⟫ ουδ. — κακὴ λαλία

⟪३१⟫. ⟪अमृत⟫ ουδ. — ἀθανασία, ἄρτος ἀθανασίας, πόμα ἀθανασίας

## Πρόσθεται Ἀσκήσεις

Α) Λύσατε ταῦτα τὰ σύνθετα ἐν Σανσκριτὶ καὶ δότε προτάσεις μεταφράσεως:

⟪१⟫. ⟪अन्तगत⟫ ⟪३⟫ ⟪।⟫ ⟪अन्तं⟫ ⟪गतः⟫ ⟪।⟫ — πεπερασμένον, γραμματικὴ ἐκφυγόν

⟪२⟫. ⟪क्षमाकर⟫ ⟪३।⟫ ⟪क्षमा⟫-⟪करः⟫ ⟪।⟫ — ὁ ὑπομονῶν, ὑπομονητικὴ πράξις

⟪३⟫. ⟪क्षेमेन्द्र⟫ αρσ.⟪।⟫ ⟪क्षेमस्येन्द्रः⟫ ⟪।⟫ — Κύριος ἡσυχίας / εὐεξίας / εἰρήνης

⟪४⟫. ⟪शस्त्रकोपनिरोध⟫ αρσ. ⟪।⟫ ⟪शस्त्राणां⟫ ⟪कोपस्य⟫ ⟪निरोधः⟫ ⟪।⟫ — παῦσις μήνους μετὰ ξιφούς = παῦσις μάχης

⟪५⟫. ⟪सिंहसंहनन⟫ ουδ.⟪।⟫ ⟪सिंहस्य⟫ ⟪संहननम्⟫ ⟪।⟫ — σφαγὴ ἑνὸς / πολλῶν λεόντων, σφαγὴ ὑπὸ ἑνός / πολλῶν λεόντων

⟪६⟫. ⟪अरिसिंह⟫ αρσ. ⟪।⟫ ⟪सिंह⟫ ⟪इव⟫ ⟪अरिः⟫ ⟪।⟫ — λεοντοειδὴς ἐχθρός

⟪७⟫. ⟪आहारनिद्राभय⟫ ουδ. ⟪।⟫ ⟪आहारो⟫ ⟪निद्रा⟫ ⟪भयं⟫ ⟪च⟫ ⟪।⟫ — βρῶσις, ὕπνος καὶ φόβος

⟪८⟫. ⟪मृतिसाधनी⟫ θηλ. ⟪।⟫ ⟪मृतेः⟫ ⟪साधनी⟫ ⟪।⟫ — θάνατον ποιήσασα

⟪९⟫. ⟪कुलोपदेश⟫ αρσ. ⟪।⟫ ⟪कुलस्योपदेशः⟫ ⟪।⟫ — ὄνομα οἴκου (σημεῖον πρὸς τὸν οἶκον)

Β) Μεταφράσατε χρώμενοι ῥήμασι τῆς 2. παραταγῆς:

1\. ὁ Βραχμάνης ἐπαινεί τὰς θεάς.
⟪ब्राह्मणो⟫ ⟪देवीः⟫ ⟪स्तौति⟫ ⟪।⟫ (ἢ: ⟪स्तवीति⟫ ⟪।⟫)

2\. οἱ ἥρωες ἐπὶ τῇ χαλεπῇ διαβάτῳ ὁδῷ εἰς τὸ κώμην τῶν Ἀριῶν πορεύονται.
⟪शूरा⟫ ⟪दुर्गमेण⟫ ⟪मार्गेणार्यग्रामं⟫ ⟪यन्ति⟫ ⟪।⟫

3\. ἡ οἰκοθέρα γαμεῖ τὰς βοῦς.
⟪गृहदासी⟫ ⟪धेनूर्दोग्धि⟫ ⟪।⟫

4\. οἱ ἐχθροὶ τῶν Ἀριῶν κατακτείνουσι τοὺς δυνατοὺς Κṣatriyas.
⟪आर्यारयो⟫ ⟪बलवत्क्षत्रियान्घन्ति⟫ ⟪।⟫ (ἢ: ⟪आर्यशत्रवो⟫...)


5\. Φάντασμα οὐκ ἔδει καρπούς.
⟪भूतं⟫ ⟪फलानि⟫ ⟪नात्ति⟫ ⟪।⟫

6\. Οὕτως λέγει ὁ τὴν [τῆς μετεννοήσεως] ὁδὸν καλῶς βαδίσας πρὸς τὸν μαθητήν.
⟪एवं⟫ ⟪सुगतः⟫ ⟪श्रावकं⟫ ⟪वक्ति⟫ ⟪।⟫ (ἢ: ⟪ब्रवीति⟫ ⟪।⟫ ⟪ब्रूते⟫ ⟪।⟫)

C) Δότε τὴν ὁρισμὸν τοῦ योगα ἐν Σανσκριτὰ δι’ δύο τρόπων: ἅπαξ χρῶμενος συνθέσει, ἕτερον δὲ λύσιν τῆς συνθέσεως.

⟪योगश्चित्तवृत्तिनिरोधः⟫ ⟪।⟫ (⟪योगश्चित्तस्य⟫ ⟪वृत्तेर्निरोधः⟫ ⟪।⟫)

D) Μετάφρασον:

(⟪धर्मः⟫) ⟪सर्वेषामाहिंसा⟫ ⟪सत्यं⟫ ⟪शौचमनसूयानृशंस्यं⟫ ⟪क्षमा⟫ ⟪च⟫ ⟪॥⟫
ἔστιν ἀπασῶν αἰτία: ἀβιμσα, ὀρθότης, καθαρότης, οὐκ ἐπικρίσις περὶ τῆς τύχης, ἀπαλλαγὴ κακίας, καὶ ὑπομονή.
