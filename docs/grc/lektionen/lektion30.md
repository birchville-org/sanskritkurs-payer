## 30.1. Ἡ 9η ἐνεστωτικὴ κλίσις (⟪क्र्यादि⟫ = "⟪क्री⟫ κτλ.")

::: grammar-box
**Παιδεία:**

*   ἰσχυρὸς ρίζα: βαθύφωνη ῥίζα + -nā-

*   ἀσθενὴς ρίζα:

    *   πρὸ συμφώνου: βαθύφωνη ῥίζα + -nī-

    *   before vowels: low-toned root + -n-
:::

## 30.5. Sandhi τοῦ τελικοῦ -r

::: grammar-box
**Πλὴν τοῦ -ar, ἰσχύουσι περὶ τὸ ἐκβαῖνον -r αὐτὰ τὰ κανόνια Sandhi ὥσπερ περὶ τοῦ ἐκβαίνοντος -s.**

**-ar πρὸ φωνηέντων φθόγγων μένει -ar, πρὸ δὲ τοῦ r- ἀπαθραίνεται τὸ -r καὶ τὸ -a- μεταβάλλεται εἰς -ā-.**
:::
Παραδείγματα:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
