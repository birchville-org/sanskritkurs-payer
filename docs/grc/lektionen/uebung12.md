# Ἄσκησις 12

Α) Σχηματίσατε ἐκ τῶν φράσεων ὀρθίων τῆς [Μαθήσεως 7](lektion07.md), Ἄσκησις Α, φράσεις παθητικὰς τοῦ παρελθόντος χρόνου διὰ τῶν μετοχῶν παθητικῶς παρακειμένων, περὶ ἀκτίνων ρημάτων καὶ ῥημάτων τῆς κινήσεως φράσεις ἐνεργητικὰς τοῦ παρελθόντος χρόνου.

⟪१⟫. ⟪ब्राह्मणेन⟫ ⟪देव⟫ ⟪इष्टः⟫ ⟪।⟫ ⟪देवीष्टा⟫ ⟪।⟫ ⟪विष्णुरिष्टः⟫ ⟪।⟫ ⟪ब्राह्मणेनाग्निरिष्टः⟫ ⟪।⟫ ⟪देवतेष्टा⟫ ⟪।⟫

⟪२⟫. ὑπὸ τοῦ γουρου τὰ καρποὶ ἐφάγεται.
⟪गुरुणा⟫ ⟪फलं⟫ ⟪खादितम्⟫ ⟪।⟫

⟪३⟫. ὁ σādhu εἰς τὸν σωργὰν ἐπορεύθη.
⟪साधुः⟫ ⟪स्वर्गं⟫ ⟪गतः⟫ ⟪।⟫

⟪४⟫. ἡ σūdρā εἰς τὸν ναρακὰν ἐπορεύθη.
⟪शूद्रा⟫ ⟪नरकं⟫ ⟪गता⟫ ⟪।⟫

⟪५⟫. ὁ σūdρος νικᾶται ⟪॥⟫
⟪शूद्रो⟫ ⟪जितः⟫ ⟪॥⟫

Β) Σχηματίσατε τὰς ἀντιστοιχούσας μετοχὰς παθητικῶς παρακειμένων πρὸς τὰς ῥηματικὰς μορφὰς τῆας [Μαθήσεως 10](lektion10.md), Ἄσκησις Α. Παρατηρεῖτε δὲ, ὅτι μιᾷ μορφῇ ὡς sṛjati ἀντιστοιχοῦσιν μετοχαὶ παθητικῶς παρακειμένων ἐν πᾶσι τοῖς τρεῦσιν γένεσιν.

1. sṛjati ⟪सृजति⟫ : ⟪सृष्टः⟫ ⟪३⟫ (⟪सृष्टः⟫ ⟪।⟫ ⟪सृष्टा⟫ ⟪।⟫ ⟪सृष्टम्⟫)
2. yudhyate ⟪युध्यते⟫ : ⟪युद्धः⟫ ⟪३⟫
3. bhavanti ⟪भवन्ति⟫ : ⟪भूताः⟫ ⟪३⟫ (⟪भूताः⟫ ⟪।⟫ ⟪भूताः⟫ ⟪।⟫ ⟪भूतानि⟫)
4. yajati ⟪यजति⟫ : ⟪इष्टः⟫ ⟪३⟫
5. nṛtyati ⟪नृत्यति⟫ : ⟪नृत्तः⟫ ⟪३⟫
6. nayanti ⟪नयन्ति⟫ : ⟪नीताः⟫ ⟪३⟫
7. smarati ⟪स्मरति⟫ : ⟪स्मृतः⟫ ⟪३⟫
8. śṛṇvanti ⟪शृण्वन्ति⟫ : ⟪श्रुताः⟫ ⟪३⟫
9. pāśyati ⟪पश्यति⟫ (τὸ παθητικὸν σχηματίζεται ἐκ τοῦ dṛś!) : ⟪दृष्टः⟫ ⟪३⟫
10. jayanti ⟪जयन्ति⟫ : ⟪जिताः⟫ ⟪३⟫
11. kurvate ⟪कुर्वते⟫ : ⟪कृताः⟫ ⟪३⟫
12. āpnuvanti ⟪आप्नुवन्ति⟫ : ⟪आप्ताः⟫ ⟪३⟫
13. viśati ⟪विशति⟫ : ⟪विष्टः⟫ ⟪३⟫
14. khādanti ⟪खादन्ति⟫ : ⟪खादिताः⟫ ⟪३⟫
15. sunoti ⟪सुनोति⟫ : ⟪सुतः⟫ ⟪३⟫
16. gacchati ⟪गच्छति⟫ : ⟪गतः⟫ ⟪३⟫
17. manyante ⟪मन्यन्ते⟫ : ⟪मताः⟫ ⟪३⟫
18. labhante ⟪लभन्ते⟫ : ⟪लब्धाः⟫ ⟪३⟫
19. rakṣanti ⟪रक्षन्ति⟫ : ⟪रक्षिताः⟫ ⟪३⟫
20. vadanti ⟪वदन्ति⟫ : ⟪उदिताः⟫ ⟪३⟫
21. pṛcchanti ⟪पृच्छन्ति⟫ : ⟪पृष्टाः⟫ ⟪३⟫
22. tanvanti ⟪तन्वन्ति⟫ : ⟪तताः⟫ ⟪३⟫

Γ) Μετατρέψατε τὰς φράσεις τῆας [Μαθήσεως 10](lektion10.md), Ἄσκησις Γ, εἰς τὸ παθητικὸν καὶ εἰς τὸν παρελθόντα χρόνον.

1\. ὁ βρāhmaṇος τὴν θεὰν θυσιάζει. ⟪ब्राह्मणो⟫ ⟪देवीं⟫ ⟪यजति⟫
⟪ब्रामणेन⟫ ⟪देवीष्टा⟫ ⟪।⟫

2\. ὁ σādhu εἰς τὸν σωργὰν πορεύεται. ⟪साधुः⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫
⟪साधुः⟫ ⟪स्वर्गं⟫ ⟪गतः⟫ ⟪।⟫

3\. τὸν σūdρα νικᾷ. ⟪शूद्रं⟫ ⟪जय⟫τι
⟪शूद्रो⟫ ⟪जितः⟫ ⟪।⟫

4\. ὁ γουρὸς τὰ καρπᾶ ἐσθίει. ⟪गुरुः⟫ ⟪फलानि⟫ ⟪खादति⟫
⟪गुरुणा⟫ ⟪फलानि⟫ ⟪खादितानि⟫ ⟪।⟫

5\. τοὺς γουροῦς ἀκούει. ⟪गुरूञ्छृणोति⟫
⟪ग्रुरवः⟫ ⟪श्रुताः⟫ ⟪।⟫

6\. τίς τὸν ἄγνη βλέπει. ⟪को⟫ ⟪ऽग्निं⟫ ⟪पश्यति⟫
⟪केनाग्निर्दृष्टः⟫ ⟪।⟫

7\. οὗτος ὁ ποιητὴς τὸν μαντρα θυμᾶ. ⟪अयं⟫ ⟪कविर्मन्त्रं⟫ ⟪स्मरति⟫
⟪अनेन⟫ ⟪कविना⟫ ⟪मन्त्रः⟫ ⟪स्मृतः⟫ ⟪।⟫

8\. αὕθῃ ἡ θεὰ ὁ βρāhmaṇος φυλάσσει. ⟪इयं⟫ ⟪देवी⟫ ⟪क्त्रिया⟫ ⟪रक्षति⟫
⟪अनया⟫ ⟪देव्या⟫ ⟪क्षत्रिया⟫ ⟪रक्षिताः⟫ ⟪।⟫

9\. οἱ βρāhmaṇοι τὸν σωργὰ θυσιάζουσι. ⟪क्षत्रिया⟫ ⟪विष्णुं⟫ ⟪यजन्ते⟫ (δύο τρόποι)
⟪क्षत्रियैर्विष्णुरिष्टः⟫ ⟪।⟫ ⟪क्षत्रियाभिर्विष्णुरिष्टः⟫ ⟪।⟫

10\. ὁ βρāhmaṇος τὸν ἄγνη ποιεῖ. ⟪ब्राह्मणो⟫ ⟪ऽग्निं⟫ ⟪करोति⟫
⟪ब्राह्मणेनाग्निः⟫ ⟪कृतः⟫ ⟪।⟫

11\. οἱ βρāhmaṇοι εἰς τὴν κώμην ταύτην πορεύονται. ⟪वैश्या⟫ ⟪इमं⟫ ⟪ग्रामं⟫ ⟪गच्छन्ति⟫
⟪वैश्या⟫ ⟪इमं⟫ ⟪ग्रामं⟫ ⟪गताः⟫ ⟪।⟫

12\. οὗτοι τοὺς γουροῦς ἀκούουσιν. ⟪एते⟫ ⟪गुरूंस्तु⟫ ⟪शृण्वन्ति⟫
⟪एतैर्गुरवस्तु⟫ ⟪श्रुताः⟫ ⟪।⟫

13\. ὁ σādhu εἰς τὸν σωργὰν φθάνει. ⟪साधुः⟫ ⟪स्वर्गमाप्नोति⟫
⟪साधुना⟫ ⟪स्वर्ग⟫ ⟪आप्ताः⟫ ⟪।⟫

14\. οἱ βρāhmaṇοι τὸν σόμα ἐκπίπτουσι. ⟪ब्राह्मणाः⟫ ⟪सोमं⟫ ⟪सुन्वन्ति⟫
⟪ब्राह्मणैः⟫ ⟪सोमः⟫ ⟪सुतः⟫ ⟪।⟫

15\. τὰ πρόβατα λαμβάνεται. ⟪पशूल्ंलभते⟫
⟪पशवो⟫ ⟪लब्धाः⟫ ⟪।⟫


16. οἱ πολεμισταὶ σὺν τοῖς ὁπλίταις μάχονται. ⟪के⟫ ⟪योधाः⟫ ⟪क्षत्रियैः⟫ ⟪सह⟫ ⟪युध्यन्ते⟫
⟪कैर्योधैः⟫ ⟪क्षत्रियैः⟫ ⟪सह⟫ ⟪युद्धम्⟫ ⟪।⟫
