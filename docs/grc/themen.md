# Γραμματικὸς Ἰνδεξος

Ὁ Γραμματικὸς Ἰνδεξος καταλέγει πάντα τὰ γραμματικὰ θέματα καὶ φαινόμενα ἐκ τοῦ μαθήματος Σανσκριτοῦ καὶ παρέχει ταχὺν πρόσβασιν εἰς τὰς ἰδιαίτερα μαθήσεις.
