# Lekce 3

## 3.1. Nominativ singuláru feminina

### 3.1.1. Nominativ singuláru na -s

Také následující kmeny podstatných jmen, které končí samohláskou, tvoří nominativ singuláru na **-s**:

::: grammar-box
**Feminina na -i**: např. **śruti** f. "poslouchání" -- Nom. sg.: **śrutis** = ⟪श्रुतिस्⟫
**Feminina na -u**: např. **dhenu** f. "kráva" -- Nom. sg.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Nominativ singuláru bez koncovky

Nominativ singuláru tvoří bez koncovky:

::: grammar-box
**Feminina na -ā**: např. **devatā** f. "božstvo" -- Nom. sg.: **devatā** = ⟪देवता⟫
**Feminina na -ī**: např. **devī** f. "bohyně" -- Nom. sg.: **devī** = ⟪देवी⟫
:::
::: important
**Pozor!** Vedle toho existují jednoslabičná ženská kořenová podstatná jména na -ī, jejichž nominativ singuláru končí na -s: např. dhī f. "myšlenka" -- Nom. sg.: dhīs = ⟪धीस्⟫. Také lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "loď" a tantrī (⟪तन्त्री⟫) f. "struna" tvoří nepravidelně nominativ singuláru na -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Tvoření feminina k maskulinům

::: grammar-box
**Maskulina na -a:**
**Femininum na -ā**: např. **kṣatriya** m. » **kṣatriyā** f. "žena kšatríja" = ⟪क्षत्रिया⟫
**Femininum na -ī**: např. **brāhmaṇa** m. » **brāhmaṇī** f. "brahmanka" = ⟪ब्राह्मणी⟫

**Maskulina na -u:**
**Femininum na -ī**: např. **sādhu** m. » **sādhvī** f. (dobrý, svatá) = ⟪साध्वी⟫
(**-u-** se před samohláskou mění na **-v-**, proto **-u- + -ī** » **-vī**)
:::

## 3.3. Nominativ plurálu maskulinum a femininum

::: grammar-box
Koncovka nominativu plurálu u maskulina a feminina je **-as**.
**Maskulina na -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
**Feminina na -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**Maskulina na -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**Feminina na -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**Feminina na -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**Maskulina na -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**Feminina na -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Poznámka: **e** je zvýšená stupeň (**guṇa**) k **i**, **o** je zvýšená stupeň k **u**.


## 3.4. Vokální sandhi

::: grammar-box
**Jednoduché samohlásky, které se liší pouze délkou nebo vůbec ne, „splynou“ do příslušné dlouhé samohlásky:**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)
:::
např.

devatā + annapūrṇā » devatānnapūrṇā „Annapūrṇā je božstvo“ = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā je bohyně jídla a vaření, považována za ztělesnění Pārvatī, manželky Śivy.)

devī + indrāṇī » devīndrāṇī „Indrāṇī je bohyně“ = ⟪देवीन्द्राणी⟫

> (Indrāṇī je manželka boha Indry.)

::: grammar-box
**Jednoduché samohlásky (kromě -a / -ā) se před odlišnými samohláskami nahrazují příslušnou polosamohláskou:**
i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**
(!! K tomuto pravidlu existují zejména u duálních tvarů výjimky !!)
:::
např.

devī + umā » devy umā „Umā je bohyně“ = ⟪देव्युमा⟫

> (Umā je jméno pro Pārvatī, manželku Śivu)

::: grammar-box
**-a / -ā před odlišnou samohláskou:**
a / -ā + i- / ī- » **-e-**
a / -ā + ṛ- » **-ar-**
a / -ā + e- / ai- » **-ai-**
a / -ā + o- / au- » **-au-**
:::

## 3.5. Větný sandhi -ās

::: grammar-box
**-ās se před všemi zněnými hláskami nahrazuje za -ā.**
:::
např.

dvijās + vaiśyāḥ » dvijá vaiśyāḥ "Vaišjové jsou dvakrát zrození" = ⟪द्विजा वैश्याः⟫


## 3.6. Slovní zásoba

**Zapamatujte si následující slova:**

**śruti** ž. = ⟪श्रुति⟫ : poslech, věčná tradice (označení pro Védy a Bráhmanu).

**smṛti** ž. = ⟪स्मृति⟫ : připomenutí, paměť, meditativní připomenutí = bdělost, tradice (protiklad k **śruti**). Zahrnuje:
šest **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** ž. (⟪शिक्षा⟫): správné vyslovování
2. **chandas** n. (⟪छन्दस्⟫): metrum
3. **vyākaraṇa** n. (⟪व्याकरण⟫): gramatika
4. **nirukta** n. (⟪निरुक्त⟫) : výklad slov, etymologie
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : astronomie, kalendářní nauka
6. **kalpa** m. (⟪कल्प⟫) : ceremoniál
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : učebnice pro provádění velkých obětí
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : učebnice pro ceremonie a oběti každodenního života
**dharmasūtra** n. (⟪धर्मसूत्र⟫) a **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : učebnice práva a zvyklostí (správné chování)
velká epika **mahābhārata** n. (⟪महाभारत⟫) a **rāmāyaṇa** n. (⟪रामायण⟫)
**purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫) : učebnice životní moudrosti

**smṛti** je zvláště také označením pro dharmické učebnice.

**dhenu** f. = ⟪धेनु⟫ : (mléčná) kráva.

**paśu** m. = ⟪पशु⟫ : domestikované hospodářské zvíře, dobytek (kolektivum).

**devatā** f. = ⟪देवता⟫ : božstvo (abstraktní i konkrétní).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : bráhmankyně.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : ženská kṣatrijka.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : manželka kṣatriji.

**vaiśyā** f. = ⟪वैश्या⟫ : ženská vaišjka.

**śūdrā** f. = ⟪शूद्रा⟫ : ženská šúdrička.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : manželka šúdry.

**devī** f. = ⟪देवी⟫ : bohyně, zejména Durgā f. = ⟪दुर्गा⟫, manželka Šivy = ⟪शिव⟫.

![](/images/lekt0303.webp)

**sādhvī** f. = ⟪साध्वी⟫ : fem. k sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : fem. k guru.

**asmitā** f. = ⟪अस्मिता⟫ : „já-ství“, tj. (falešná) víra: **Já** jsem ten, kdo vidí atd.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : filozofie (věda, která přichází k svým závěrům prostřednictvím logicky správných zdůvodnění).

**upekṣā** f. = ⟪उपेक्षा⟫ : nezájem, klid.

**karuṇā** f. = ⟪करुणा⟫ : soucit, soucítění.

**muditā** f. = ⟪मुदिता⟫ : radost, zejména soucitná radost (opak závisti).


## 3.7. Cvičení

**A) Převeďte následující věty do množného čísla:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**B) Vytvořte nominativní věty doplněním:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Převeďte do ženského rodu:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**D) Přeložte do sanskrtu:**

1. Umā je bohyně.
Védá je śruti.
Učitelky jsou bohyněmi.
Mléčné krávy jsou domestikovaná zvířata.
Básníci jsou učiteli.
Kṣatrijové jsou dvakrát zrození.
Svatí muži jsou śúdrové.
