# Lekce 32

## 32.1. Časy minulosti

::: grammar-box
**V starší sanskrtské literatuře a podle domácích gramatiků se tři časy minulosti ve svém užití jasně rozlišují:**

*   **Aorist (⟪लुङ्⟫ , ⟪अद्यतनी⟫) označuje buď prosté dokončení děje, nebo to, co se stalo během běžného dne, tedy blízkou minulost**
*   **Imperfektum (⟪लङ्⟫) označuje to, co se stalo před běžným dnem, tedy vzdálenou minulost**
*   **Perfektum (⟪लिट्⟫) označuje stejně jako imperfektum vzdálenou minulost, ale na rozdíl od imperfekta se používá pouze pro události, které mluvčí sám neviděl**

**V klasické sanskrtské literatuře se tři časy minulosti používají bez rozdílu významu (výjimka: umělecká báseň ⟪भारवि⟫ ⟪किरातार्जुनीय⟫).**
:::
## 32.2. Imperfektum (⟪लङ्⟫)

::: grammar-box
**Tvorba:**

**Augment a- + kmen přítomného času + sekundární koncovka**

**Tři osoby singuláru indikativu imperfekta aktiva se u neathematických kmenů tvoří od silného kmene přítomného času, všechny ostatní tvary se tvoří od slabého kmene přítomného času.**

**Imperfektum má pouze indikativ.**
:::
Příklady:

::: indent
⟪भू⟫ 3. sg. Impf. P. ⟪अभवत्⟫ (a-bhava-t)

⟪सु⟫
*   3. sg. Impf. P. ⟪असुनोत्⟫ (a-suno-t)
*   3. pl. Impf. P. ⟪असुन्वन्⟫ (a + sunu + an)
:::
## 32.3. Pravidla pro augment

::: grammar-box
**1. Pokud preceduje augment a- kořen začínající samohláskou, splynou augment a počáteční souhláska kořene v ⟪वृद्धि⟫ samohlásky kořene.**
:::
Příklady:

::: grammar-box

| | 3. os. sing. imperfektum | 3. os. plurál imperfektum |
| :--- | :--- | :--- |
| ⟪इष्⟫ | ⟪ऐच्छत्⟫:br(a- + iccha-t) | |
| ⟪इ⟫ | ⟪ऐत्⟫:br(a- + e + t) | ⟪आयन्⟫:br(a + i + an) |
| ⟪आस्⟫ | ⟪आस्त⟫:br(a + ās-ta) | |

:::
::: grammar-box
**2. Pokud před kořenem stojí prefix, objevuje se augment a- bezprostředně za prefixem přímo před kořenem.**
:::
Příklady:

::: grammar-box

| | 3. os. sing. imperfektum |
| :--- | :--- |
| ⟪आगम्⟫ | ⟪आगच्छत्⟫:br(ā + a + gaccha-t) |
| ⟪संगम्⟫ | ⟪समगच्छत्⟫:br(sam-a-gaccha-t) |
| ⟪उपगम्⟫ | ⟪उपागच्छत्⟫:br(upa + a + gaccha-t) |
| ⟪उपागम्⟫ | ⟪उपागच्छत्⟫:br(upa + ā + a + gaccha-t) |

:::

C) Přeložte do sanskrtu:

1. Po narození syna pošle bráhmankyně služebníka k bráhmanovi. Bráhmane nechá tohoto služebníka vstoupit do domu a poté se zeptá na syna. Služebník říká, že je syn v pořádku. Když to slyšel, udělal se bráhmane šťastný.

2. Svatý snesl (jemu) způsobené zlo.

3. Ctnost je ozdobou muže.

4. Mocní válečníci odešli do vesnice bráhmanů.

5. Dívka pláče.

6. Neexistuje nemoc jako rozkoš, neexistuje nepřítel jako zmatek, neexistuje oheň jako hněv, neexistuje štěstí jako poznání.

7. Muž, kterého chrání bohyně, je šťastný.

8. Ať už jakýmkoli větrem oblak spouští vodu (⟪वारि⟫ n.), stejným větrem hýbe učencem se svým deštníkem.

9. Neexistují plodné činnosti kast, životních etap atd.

10. Kolo znovuzrozování nemá začátek.

11. Je čas věnovat se jídlu.

12. Vítejte královny.

13. Lidé konají záslužná čina pro nebe.

14. Muž, který z arogance, chamtivosti, hněvu nebo strachu vydává falešný soudní rozsudek, jde do pekla.

15. Rāma na pokyn učitele odešel z vesnice do města, vstoupil do domu svatého muže, pokorně se postavil před svatce a řekl: „Ustupte od hněvu!“

16. Vždy (budiž) jeho spojení s těmi, kteří jsou v naukách povzbuzováni, aby rostlo jeho vzdělání/dobré chování. (Toto) protože vzdělání/dobré chování má kořen v tomto (spojení s těmi).

17. Dokud učitel stojí, nesmí chlapec sedět.

18. Neexistuje lepší útočiště než Rāma.

19. Viṣṇumitra posílá Rāmu, aby vyslal Govindu do vesnice.

20. Govinda nechává Devadattu vařit rýži.

21. Dharma árijských je, že mladí bráhmanové stále znovu studují úseky Védy a Smṛti.

22. Učitel vyučil chlapce Védu a pak odešel do domu.

23. Jaký amulet ochránil dívku?

24. Pravda je světlem světa.

25. Komu patří tyto domy?

26. Dharmou všech je: neubližování, pravdomluvnost, čistota, bezzávislost a trpělivost.

27. Kṣatrijové, kteří porazili nepřátele, sedí v domě.

28. Ta je (pravou) manželkou, která mluví lásku; on však je (skutečným) synem, který žije. Žije ten, kdo má dobré vlastnosti; žije ten, kdo má dharmu.

29. Pán bohů poráží neárijské nepřátele, kteří jsou nepřáteli Indry. (Pasivum)

30. Yogem činu je asketismus (tapas n.), recitace Védy, služebnost vůči Pánu. Slouží rozvoji meditačního ponoření a oslabení kleśas.

31. Příjem potravy, spánek, strach a páření: to je společné lidem se zvířaty. V dharmě totiž spočívá jejich přibylá zvláštnost. Opusteni dharmou jsou zvířatům (instruktivem) rovni.

32. Lidé se rodí, aby zemřeli.

33. Pekla jsou kvůli zlu. Zlo má za počátek chudobu. Chudoba vzniká nedáváním.

34. Je dharmou Kṣatrijů, že Kṣatrijové chrání lidi před nepřáteli.

35. Proto mají tři (tisras) vědy vládu za kořen. Vláda, která má výchovu/dobré chování za kořen, přináší živým bytostem (⟪प्राणभृत्⟫) prospěch a jistý majetek.

36. Špatní lidé neposlouchají, když učitel mluví o dharmě.

37. Ačkoliv Ráma je ctěn!

38. Vznešený Hari je mou cestou/cílem, který (své) nepřátele poslal do nebe, svým věrným umožnil poznat smysl Védy, bohům dal nesmrtelnou potravu k jídlu, tvůrci (⟪विधि⟫) naučil Védu, zemi ve vodě (pevně) usadil.

39. Viṣṇu se ukazuje svým oddaným.

40. Vojsko, které není vykonáváno, způsobuje normu ryb.

41. Kdo má bohatství, ten má přátele; kdo má bohatství, ten má příbuzné; kdo má bohatství, ten je mužem (⟪पुमान्⟫ Nom. sq.) ve světě; kdo má bohatství, ten je totiž učencem.

42. Oheň, který spálí zemřelého, spálí také dobrou vdovu.

43. Služebná bráhmana uvařila jídlo a nyní ho jí (nyní).

44. Teď to stačí!

45. Toto ovoce mu stačí k jídlu.

46. Vnitřní svatyně je domem pro sochu boha.

47. Zloděj je osvobozen od krádeže trestem nebo propuštěním. Pokud však král (⟪राजा⟫ Nom. sg.) neztrestá (zloděje), získá vinu zloděje.

48. Protože udělal chybu při oběti, bráhman není hoden přijímat bohatství.

49. Pokud se konala iniciace, má si osvojiti Védu a filozofii od učenců, ekonomii od vedoucích oddělení (⟪उपयुज्⟫).

50. Vaiśjadharma je, že vaišjové žijí z nákupu a prodeje. Protože tak je, kupují a prodávají vaiśjasynové.

51. Má se říkat pravda, má se říkat příjemné; nemá se říkat nepříjemná pravda a nemá se říkat ani nepříjemná nepravda. Toto je věčný dharma.

52. Na shledanou!
