# Lekce 26

## 26.1. Zásada cerebralizace pro -s- uvnitř slova

::: grammar-box
**-s-** se nahrazuje za **-ṣ-**, pokud předchází **k, r, l** nebo samohláska — s výjimkou **a, ā** — bezprostředně nebo oddělená pouze ⟪अनुस्वार⟫ nebo ⟪विसर्ग⟫ a následuje jiný zvuk než **ṛ, r**.

Tomuto sandhi podléhá také **⟪दुस्⟫-** před bezhlásými velárními a labiály ve složeninách.
:::
*Příklady:*
::: indent
⟪तेषाम्⟫ (z: *te-sām*)

ale: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. Zásada cerebralizace pro dentály uvnitř slova

::: grammar-box
Dentální uzávěry se po retroflexech (včetně **-ṣ-**) nahrazují příslušnými retroflexy:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** kvůli předchozímu **i**, **ṭh** kvůli následujícímu **ṣ**)*
:::
## 26.3. Slovní sandhi pro palatály, velární, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

Příklady viz níže
:::
## 26.4. Grassmannův zákon disimilace aspirát

::: grammar-box
**Bezprostřední následnost dvou aspirát (aspirát - samohláska - aspirát) má za následek ztrátu aspirace prvního zvuku:**

Příklad:

:::
::: indent
\*dhu(gh) » du(g)h
:::
**Ztrácí-li druhý zvuk v důsledku fonetických zákonů svou aspiraci, objevuje se aspirace znovu u prvního zvuku.**

Příklady: viz níže budoucí čas od  ⟪दुह्⟫ a  ⟪बुध्⟫

## 26.6. Užití prostého budoucího času (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ž.)

::: grammar-box
**Prostý budoucí čas (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ž.) vyjadřuje:**

**budoucnost**
**záměrný nebo chtěný čin („jdu“, „chci jít“)**
**očekávání („stane se takto“)***
**naději**
**obavu**
**pravděpodobnost**
**názor mluvčího***
**příkaz**

**Budoucí čas stojí částečně v konkurenci s optativem (viz dále).**
:::
např. ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = „Někdo, kdo chce složit slib, jde do chrámu.“

## 26.7. Tvorba prostého budoucího času (⟪ऌत्⟫, ⟪भविष्यन्ती⟫  ž.)

::: grammar-box
**Prostý budoucí čas:**

:::
::: indent
**Kmen budoucího času + primární koncovka**
:::
::: grammar-box
**Kmen budoucího času:**

:::
::: indent
**(obvykle) silný stupeň kořene + -sya**  
**nebo**  
**(obvykle) silný stupeň kořene + -i- + -sya (= - iṣya)**
:::
**Který kořen má jakou tvorbu kmene budoucího času, je třeba se naučit s tvary kmenů!**  
**Obecně odpovídá tvar kořene a spojovací samohláska budoucího času infinitivu.**  
**Některé kořeny mohou tvořit budoucí čas volitelně se spojovací samohláskou -i- nebo bez ní.**  
**Particip aktivního způsobu budoucího času se tvoří připojením přípony -nt- ke kmene budoucího času, femininum fakultativně na -ntī nebo -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
