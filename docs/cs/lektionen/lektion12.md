# Lekce 12


## 12.1. Participium Perfektum Passivum (PPP)

Jedním ze způsobů, jak tvořit věty trpné v minulosti, je konstrukce se tzv. Participiem Perfektum Passivem (PPP).

::: grammar-box
**Ve skutečnosti není PPP pravým participiem, protože netvoří od kmenů časových. Je spíše substantivní utváření ke kořeni s primární příponou -ta resp. -na. Proto se v indické gramatice mluví o příponě kta.**
:::

### 12.1.1. Schéma pro tranzitivní slovesa

::: grammar-box
**Agent (kartṛ) v instrumentálu (tṛtīyā) -- předmět (karman) v nominativu (prathamā) -- Participium Perfektum Passivum**

V tomto případě PPP souhlasí s předmětem v čísle, pádu a rodu.

Pomocné sloveso („být“) není nutné.

Příklady:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = „(Nebesa byla dosažena svatým) = Svatý dosáhl nebes.“
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = „(Bohyně byla uctěvána brahmánem obětí) = Brahman uctil bohyni obětí.“
:::

### 12.1.2. Schéma I pro intranzitivní slovesa a slovesa pohybu

::: grammar-box
**Agent (kartṛ) v nominativu (prathamā) -- Participium Perfektum Passivum**

V tomto případě PPP souhlasí s agentem v čísle, pádu a rodu. Participium Perfektum „trpné“ má u intranzitivních sloves (sloves bez přímého předmětu) a sloves pohybu význam činný.

Příklad:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = „Kṣatrijovna šla do města.“
:::

### 12.1.3. Schéma II pro intranzitivní slovesa a slovesa pohybu

::: grammar-box
**Agent (kartṛ) v instrumentálu (tṛtīyā) -- PPP v nominativu singuláru neutra**

Příklad:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(Od kṣatriji bylo (do města) šlo) = Kṣatriya je (do města) šel.“

Konstrukce podle Schématu II je mnohem vzácnější než konstrukce podle Schématu I.
:::

## 12.2. K významu PPP

Zatímco tzv. „participium perfekta pasiva“ u tranzitivních sloves má především pasivní význam (**āpta** = „dosaženo (bylo)“) a u intranzitivních sloves a sloves pohybu aktivní význam (**gata** = „šel“), existuje několik sloves, u nichž může PPP mít jak aktivní, tak pasivní význam:

např.
**gata** = ⟪गत⟫ = „šel“ (aktivní); ale také: **gato mārgaḥ** = ⟪गतो मार्गः⟫ = „procházející cesta“ (pasivní)
**āpta** = ⟪आप्त⟫ = „dosaženo bylo“ (pasivní), „dosahující“ (aktivní)


## 12.3. Tvorba PPP

::: grammar-box
Vyskytují se následující způsoby tvorby (ke každému kořeni je třeba si naučit jeho PPP!):

**(většinou) slabý stupeň kořene**

**+ -ta**
s spojovacím samohláskou **-i-** před tím: **-ita**
bez spojovací samohlásky: **-ta**
**+ -na**

Ženské kmeny znějí: **-tā**, **-itā**, **-nā**; neutrum se skloňuje jako **phala** n.
:::

### 12.3.1. PPP na -ta (kta)

#### 12.3.1.1. Bez spojovací samohlásky -i- (aniṭ)

*aniṭ* = „bez (*an-*) předponě suffixu (*-i-*) *t*“ (tj. bez spojovací samohlásky *i*).

::: grammar-box
Bezprostředně bez spojovacího vokálu se participium minulého času pasivního (PPP) tvoří obecně od kořenů končících na vokál, jakož i od mnoha jiných kořenů, přičemž nelze stanovit pevné pravidlo pro to, kdy se spojovací vokál vyskytuje a kdy ne.

Seznam *aniṭ*-kořenů lze nalézt u Kielhorna, v *Grammatik* § 298.
:::
**Příklady:**

::: grammar-box
| Kořen | PPP (kta) |
| :--- | :--- |
| **bhū** 1 P:br(⟪भू⟫) | **bhū-ta** :br(⟪भूत⟫) |
| **smṛ** 1 P:br(⟪स्मृ⟫) | **smṛ-ta** :br(⟪स्मृत⟫) |
| **nṛt** 4 P:br(nṛt-ta):br(⟪नृत्त⟫) | **nṛt-ta** :br(⟪नृत्त⟫) |

| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |

#### 12.3.1.2. Se spojovacím vokálem -i- (seṭ)

*seṭ* = *sa-iṭ* = „s (*sa-*) představeným koncovkou (-i-) *t*“ (tj. se spojovacím vokálem *i*).

**Příklady:**

::: grammar-box
| Kořen | PPP (kta) |
| :--- | :--- |

| **vad** 1 P:br(⟪वद्⟫) | **ud-i-ta** (\< \*vd-i-ta):br(⟪उदित⟫) |
:::

## 12.4. Zákony spojení hlásek ve slově

U *aniṭ*-tvarech je třeba dodržovat následující zákony spojení hlásek ve slově. **Tyto zákony jsou pro pochopení celé sanskrtské morfologie velmi důležité.**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p před nepřízvučnou přerušovanou souhláskou (např. t, th) zůstávají nezměněny:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct se nahrazuje za kt = ⟪क्त्⟫:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt se nahrazuje za ṣṭ = ⟪ष्ट्⟫:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. Přízvučná nepřízvučná přerušovaná souhláska – kromě j – se před nepřízvučnou hláskou nahrazuje příslušnou nepřízvučnou nepřízvučnou souhláskou:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (důležité pro 2. třídu přítomného času) |
| **5. jt se nahrazuje za kt nebo ṣṭ (nikoliv fakultativně!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. Přízvučná přerušovaná souhláska + nepřízvučná přerušovaná souhláska » přízvučná nepřerušovaná souhláska + přerušovaná přerušovaná souhláska (Bartholomaeho zákon aspirace):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t se nahrazuje za ḍh s prodloužením předchozího i nebo u; nebo za gdh. Před takovým ḍh se a nahrazuje za o, vzácněji za ā:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „něco skrýt”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.5. Slovník

**budh** 4 Ā (budhyate) / 1 U (bodhati), PPP **buddha** ⟪बुध् बुध्यते बोधति बुद्ध⟫ : probudit se, probudit se k poznání, rozpoznat; PPP **buddha** 3 probuzený, proto **Buddha** = „ten probuzený“ (nikoliv: ten osvícený)

::: media

Obr.: ⟪गौतमो बुद्धः⟫
(Zdroj obrázku: [Podrobnosti](/cs/licenses#lekt1201))
:::
**dah** 1 P (dahati), PPP **dagdha** ⟪दह् दहति दग्ध⟫ : (něco) spálit
**sah** 1 Ā (sahate), PPP **soḍha** ⟪सह्⟫ sahate soḍha : zvládnout, snášet, trpělivě snášet = odpustit
**mṛga** m. ⟪मृग⟫ : divoké zvíře
**mārga** m. ⟪मार्ग⟫ : cesta (cesty byly často zvěřními stezkami)

::: media
![](/images/lekt1202.webp)
Obr.: ⟪मार्गः⟫
(Zdroj obrázku: [Podrobnosti](/cs/licenses#lekt1202))
:::
**api** ⟪अपि⟫ : také (postpozicní)

K šesté třídě přítomného času řadí domácí gramatici některé kořeny, které tvoří kmen přítomného času s nasálním infixem a tematickým vokálem a, např.:

**muc** 6 U (muñcati), PPP **mukta** ⟪मुच् मुञ्चति मुक्त⟫ : uvolnit, pustit, osvobodit; osvobodit z cyklu znovuzrozování (**saṃsāra** m.) = vykoupit
**sic** 6 U (siñcati), PPP **sikta** ⟪सिच् सिञ्चति सिक्त⟫ : pokapat

K tvorbě slov:

**muc**: **mokṣa** m. ⟪मोक्ष⟫ : uvolnění, osvobození, vykoupení
**sic** + **abhi-**: **abhiṣeka** m. ⟪अभिषेक⟫ : posvícení krále při korunovaci, korunní obřad
**budh**: **bodhi** m./f. ⟪बोधि⟫ : probuzení (díky němuž Buddha nebo Jina dosáhne osvobozujícího poznání)

::: media
![](/images/lekt1203.webp)
Obr.: ⟪महावीरो जिनः⟫
(Zdroj obrázku: [Podrobnosti](/cs/licenses#lekt1203))
:::
**buddhi** f. (**budh** + **-ti**) ⟪बुद्धि⟫ : poznání, orgán poznání.
