# Lekce 21

## 21.1. Další přítomné kmeny na -nt

### 21.1.1. Příčestí přítomného času (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
Toto příčestí je substantivní utváření z přítomného kmene, tedy skutečné příčestí. Je to adjektivum, které označuje, že někdo nebo něco právě dělá to, co vyjadřuje slovesný kořen (+ prefix), zatímco se děje něco jiného. Tím lze vyjádřit i trvalý stav.

**Příklady:**

:::
::: indent
"Zatímco otec čte, kouří = kouřící otec"
"přítel, který je (skutečný, opravdový)"
:::
::: grammar-box

| **Tvorba příčestí přítomného času Parasmaipada u tematických přítomných kmenů:** |||
| :--- | :--- | :--- |
| **Maskulinum, Neutrum** | | |
| | **silný kmen** | přítomný kmen + **-nt-** |
| | **slabý kmen** | přítomný kmen + **-t-** |
| **Femininum** | | |
| | | přítomný kmen + **-nt-** + **-ī** (skloňování jako **devī** :br⟪देवी⟫) |
| | **6. třída přítomného času** | přítomný kmen + **-nt-** + **-ī** :broder::brpřítomný kmen + **-t-** + **-ī** |

:::

## 21.3. Zdvořilé formy oslovení

::: grammar-box
**V sanskrtu lze oslovovat někoho ve 2. osobě singuláru, aniž by to bylo nezdvořilé. Chcete-li však být zdvořilí, můžete použít podstatné jméno s významem "ctihodný" a podobně, a sloveso uvést do 3. osoby singuláru nebo plurálu, případně použít pasivní konstrukci. Stupňování zdvořilosti při používání osoby v oslovení je přibližně následující:**

:::
::: indent
**2. sg. » 2. pl. » 3. sg. s příslušným podstatným jménem » 3. pl. s odpovídajícím podstatným jménem**
:::
**Nejdůležitějším takovým zdvořilostním podstatným jménem je ⟪भवन्त्⟫ , rod ženský: ⟪भवती⟫ . Odpovídá našemu zdvořilému "Vy".**
Toto ⟪भवन्त्⟫ je zkrácenina z ⟪भगवन्त्⟫, jeho deklinace je stejná jako u substantiv na **-vant** (viz [Lekce 13](lektion13.md)). Toto ⟪भवन्त्⟫ je třeba odlišit od přítomného příčestí P slovesa ⟪भू⟫ "stát se" ⟪भवन्त्⟫ : nominativ singuláru maskulina slovesa ⟪भवन्त्⟫ "Vy" je ⟪भवान्⟫, nominativ singuláru příčestí ⟪भवन्⟫.

**Příklady:**

::: indent
**⟪किं भवान्करोति⟫** = **⟪किं भवता क्रियते⟫** = "Co děláte?"
:::
zdvořile:

::: indent
**⟪किं भवन्तः कुर्वन्ति⟫** = **⟪किं भवद्भिः क्रियते⟫**
:::
Femininum:

::: indent
**⟪किं भवती करोति⟫** = **⟪किं भवत्या क्रियते⟫**  
**⟪किं भवत्यः कुर्वन्ति⟫** = **⟪किं भवतीभिः क्रियते⟫**
:::
Další slova, která lze použít podobně jako ⟪भवन्त्⟫:

*   ⟪आर्य⟫ (f.: ⟪आर्या⟫) "Ušlechtilý". Např. **⟪यदार्य इच्छति⟫** "Co si přejete"
*   ⟪महाभाग⟫ "ten, jehož díl/štěstí je velké = vznešený". Často používáno ženami při oslovování nebo mluvení o mužích dobrého postavení. V moderním hovorém sanskrtu velmi časté.

Pokud nechcete vyjádřit pouze zdvořilost, ale také úctu k někomu, používá se u přítomné osoby nebo někoho v blízkosti místo ⟪भवन्त् अत्रभवन्त्⟫ , u nepřítomné nebo vzdálené osoby ⟪तत्रभवन्त्⟫. ⟪अत्रभवन्त्⟫ a ⟪तत्रभवन्त्⟫ lze přeložit jako "Vy", "Vaše Excelence", "Váš Vznešenosti" atd.:

::: indent
**⟪किमत्रभवत्यत्रभवतां भार्या⟫** = "Je milostivá (zde přítomná) paní vaší manželkou?"  
**⟪किं तत्रभवतां कुशलवृत्तम्⟫** (v dopise nebo telefonickém rozhovoru) = "Máte se dobře?"
:::
