# Lekce 57

## 57.1. Aorist 4: s-Aorist

::: grammar-box
**s-Aorist se tvoří k většině ⟪अनिट्⟫-kořenů, pokud nemají výhradně jinou aoristovou formu. Fakultativní ⟪अनिट्⟫-kořeny mohou obecně volitelně tvořit buď tento, nebo iṣ-Aorist. Také ⟪अनिट्⟫-kořeny, které tvoří ⟪परस्मैपद⟫ po 1., 2. nebo 6. formě aoristu, tvoří ⟪आत्मनेपद⟫ podle s-Aoristu.**

**Tvorba: Augment + kořen + s + athematické sekundární koncovky**
:::
Tabulka koncovek s příponou pro tvorbu kmene

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟫** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟫** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**Aplikuje se obecné fonetické pravidlo, že mezi dvěma výbuchovými souhláskami vynechává šumivka (srov. ⟪उद्⟫ + ⟪स्थित⟫ » ⟪उत्थित⟫), tj. přípona pro tvorbu kmene -s- před koncovkami, které začínají na -t- nebo -th-, vypadává (ne však po nazálech nebo r-).**

Příklady:

:::
::: indent
3.sg.Ā a-kṣip + s + ta » ⟪अ⟫:sig[⟪क्षिप्त⟫]
2.sg.Ā a-kṣip + s + thās » ⟪अ⟫:sig[⟪क्षिप्था⟫]⟪स्⟫
:::
Takové formy by mohly patřit také ke kořenovému aoristu a pravděpodobně k němu částečně také patří.
Indičtí gramatici zařadili do s-Aoristu také formy jako ⟪अकृत⟫ (3.sg.Ā), které jednoznačně patří ke kořenovému aoristu. K tomuto účelu indičtí gramatici vymysleli následující ad-hoc fonetické pravidlo pro s-Aorist:

::: indent
„Po krátkém samohlásce ztrácejí koncovky začínající na -st- nebo -sth- své -s-.“
:::
Jinak je třeba dodržovat fonetická pravidla pro spojení koncových souhlásek s -s-.

Pro -dhvam platí:

::: grammar-box
**-dh- v -dhvam se po všech samohláskách kromě a/ā i po -r nahrazuje za -ḍh-.**

:::
::: indent
např. :sig[⟪चि⟫] 5U: 2.os.Ā :sig[⟪अचेढ्वम्⟫]
:::
::: grammar-box
**Podoba kořene:**

*   **⟪परस्मैपद⟫ : prodloužená stupeň**
*   **⟪आत्मनेपद⟫ :**
*   **Kořeny s koncovým i/ī/u/ū: zvýšená stupeň**
*   **koncové -ṝ se nahrazuje za -īr nebo -ūr**
*   **kořeny s ablautem na ā/e/o: snížená stupeň**
*   **ostatní samohlásky kořene: beze změny (tj. obvykle ve snížené stupni)**
:::

::: grammar-box
**⟪दृश्⟫ a ⟪सृज्⟫ mají v ⟪परस्मैपद⟫ prodloužená stupeň s rostoucím diphthongem -rā-:**

:::
::: indent

:::
