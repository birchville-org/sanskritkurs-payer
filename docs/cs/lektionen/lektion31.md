# Lekce 31

## 31.1. 7. třída přítomného času (⟪रुधादि⟫ = "⟪रुध्⟫ atd.")

::: grammar-box
**Vznik:**

**Před koncovými souhláskami kořene v hluboké stupni je vložen tzv. nasální infix (-na- resp. -n-):**

*   **ve silném kmeni: -na-**
*   **ve slabém kmeni: -n-**

**Pro spojení koncových souhlásek kořene s koncovkami začínajícími na souhlásku platí stejná pravidla jako pro 2. třídu přítomného času.**
:::
Příklady:

⟪युज्⟫ 7U "spojit, zapřáhnout"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. sg.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(před guturálními uvnitř slova jsou nazály nahrazeny -ṅ-) |
| | **3. pl.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Optativ** | **3. sg.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. pl.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Particip přítomný** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:bržens.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "zastavit, přivést k zastavení"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. sg.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. pl.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Optativ** | **3. sg.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. pl.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Particip přítomný** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:bržens.: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**U některých kořenů proniklo -n- slabého přítomného kmene i do neprítomných časů, takže tyto kořeny jsou uváděny s infixovaným nosovým souhláskou.**
:::
Příklad:

⟪भञ्ज्⟫ 7P "rozbít"

::: indent
*   Indikativ přítomný čas
*   3.os.jed. ⟪भनक्ति⟫ (bha-na + j + ti)
*   3.os.mnoh. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Budoucí čas: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Trpný rod: ⟪भज्यते⟫ (buď z původního kořene ⟪भज्⟫ nebo z *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (možná z *bhñj + na)
:::
