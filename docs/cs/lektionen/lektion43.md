# Lekce 43

## 43.1. Osobní koncovky 2. osoby (⟪मध्यमः⟫ = "prostřední \<osoba\>")

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Primární koncovky** | -si | -tha | -se | -dhve |
| **Sekundární koncovky** | -s | -ta | -thās | -dhvam |
| **Koncovky perfekta** | -tha | -a | -se | -dhve |
:::
Vezměte na vědomí, že sekundární koncovka 2.os.pl. je totožná se sekundární konovkou 3.os.jedn.Indikativu přítomného času.

## 43.2. Tvoření slovesných tvarů 2. osoby (⟪मध्यमः⟫)

2.osoba:

*   Jednotné číslo: "ty"
*   Množné číslo: "vy" (více než dva!)

## 43.3. Osobní zájmeno druhé osoby

*   Singulár: ⟪त्वद्⟫ "ty"
*   Plurál: ⟪युष्मद्⟫ "vy"

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम् त्वा⟫ | ⟪युष्मान् वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम् ते⟫ | ⟪युष्मभ्यम् वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪तव ते⟫ | ⟪युष्माकम् वस्⟫ |
| ⟪सप्तमी⟫ | ⟪त्वयि⟫ | ⟪युष्मासु⟫ |
:::
Tvary ⟪त्वा⟫, ⟪ते⟫, ⟪वस्⟫ nesmí být použity na začátku věty nebo poloviny verše. Také před ⟪च⟫, ⟪वा⟫, ⟪एव⟫ a některými dalšími částicemi nesmí být používány:

::: indent
⟪त्वां मां च⟫ "tebe a mě"
:::
