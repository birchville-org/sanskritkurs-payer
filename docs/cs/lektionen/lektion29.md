# Lekce 29

## 29.1. Použití Parasmaipada (⟪परस्मैपद⟫) a Ātmanepada (⟪आत्मनेपद⟫) v kauzativu


::: grammar-box
**Kauzativ je s výjimkami Ubhayapada (⟪उभयपद⟫)**
:::
::: grammar-box
**V kauzativu se používá Ātmanepada (⟪आत्मनेपद⟫):**

**1. Pokud prospěch z vyvolané činnosti přichází tomu, kdo ji vyvolal:**
:::
Příklad:

⟪रामः कटं कारयते⟫ = "Ráma nechává pro sebe (ve svém vlastním zájmu) vyhotovit podložku"

**2. Pokud se kauzativ tranzitivních sloves používá reflexivně ("ukazovat se", "nechat slyšet" atd.), nebo pokud je předmětem prostého slovesa Agens (⟪कर्तृ⟫) kauzativu:**

Příklad:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "Višnu se ukazuje svým oddaným"

Výsledek: ⟪भक्ता विष्णुं पश्यन्ति⟫ = "Věřící vidí Višnu"


Pravidla tedy obecně odpovídají pravidlům pro použití Ātmanepada (⟪आत्मनेपद⟫) u sloves Ubhayapada (⟪उभयपद⟫).

⟪अनित्याशुचिदुःखा⟫:sig[⟪नात्मसु⟫] ⟪नित्यशुचिसुखात्मख्यातिरविद्या ॥योगसूत्र २⟫.⟪५॥⟫
