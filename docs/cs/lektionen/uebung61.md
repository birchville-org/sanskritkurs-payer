# Cvičení 61

Lekce 61 tvoří závěr sanskrtského kurzu a neobsahuje žádné další písemné úkoly.

Se studiem kořenových jmen, periphrastického budoucího času a denominativ jsou položeny základy pro čtení sanskrtských originálních textů. Kurz končí tradičním vzýváním Gaṇeši (⟪श्रीगणनाथ⟫), které označuje přechod od učebnice k samostatnému čtení.
