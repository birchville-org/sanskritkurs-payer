# Lekce 17

## 17.1. Druhá třída přítomného času (⟪अदादि⟫ = ⟪अद्⟫ atd.)

Koncovky sloves se připojují přímo ke kořeni. Přitom je třeba vzít v úvahu fonetické změny vyplývající z sandhi.

::: grammar-box

V druhé třídě přítomného času existují následující tvary:

1. Kořeny s gradací kmene
*   většinou: silná stupeň – slabá stupeň
*   některé kořeny: prodloužená stupeň – slabá stupeň
2. Kořeny bez gradace kmene
3. Dvouslabičné kořeny na -i/-ī s gradací kmene

:::
## 17.2. Kořeny druhé třídy přítomného času s gradací kmene silná stupeň – slabá stupeň

Příklady:

⟪द्विष्⟫ 2 U „nenávidět“

*   silný kmen přítomného času: dveṣ-
*   slabý kmen přítomného času: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Přít. P | ⟪द्वेष्टि⟫ (« dveṣ + -ti) |
| 3\. pl. Přít. P | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 3\. sg. Přít. Ā | ⟪द्विष्टे⟫ (« dviṣ + -te) |
| 3\. pl. Přít. Ā | ⟪द्विषते⟫ (dviṣ-ate) |

::: grammar-box
Sandhi -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-

## 17.4. Kořeny druhé třídy přítomného času bez kmenové gradace

::: grammar-box
Bez kmenové gradace jsou kořeny druhé třídy přítomného času na -ā
:::
Příklad:

⟪पा⟫ 2 P "chránit, střežit"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. přítomný čas P | ⟪पाति⟫ (pā-ti) |
| 3\. pl. přítomný čas P | ⟪पान्ति⟫ (« pā- + -anti) |

:::
Některé další kořeny druhé třídy také nemají kmenovou gradaci:

Příklad:

⟪अद्⟫ 2 P "jíst"

::: no-header

| | |

| 3\. sg. přítomný čas P | ⟪अत्ति⟫ (« ad- + -ti) |
| 3\. pl. přítomný čas P | ⟪अदन्ति⟫ (ad-anti) |

:::
⟪आस्⟫ 2 Ā "sedět"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. Ā | ⟪आस्ते⟫ (ās-te) |

⟪वच्⟫ 2 P "říkat"

## 17.5. Dvouslabičné kořeny na -i/-ī s kmenovou gradací

Některé kořeny jsou v řadě tvarů dvouslabičné, tj. mají před konsonantickým zakončením -i (případně před některými koncovkami -ī). Tyto kořeny jsou však tradičními gramatiky a ve slovnících apod. uváděny jako jednoslabičné.

Příklady:

⟪रुद्⟫ 2 P "plakat, naříkat"

*   silný kmen přítomného času: rodi-
*   slabý kmen přítomného času:
*   před konsonantem: rudi-
*   před vokálem: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "mluvit"

*   silný kmen přítomného času: bravī- (« bro- + -ī)
*   slabý kmen přítomného času:
*   před konsonantem: brū-
*   před vokálem: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Také ⟪स्तु⟫ 2 U "chválit" má kromě tvarů uvedených pod bodem 3. tvary podle tohoto vzoru:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::
