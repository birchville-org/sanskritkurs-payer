# Lekce 16

## 16.1. Ke Sandhi koncových souhlásek

Pro tvorbu složenin, jejichž první člen tvoří kmeny končící souhláskou, jsou zapotřebí následující pravidla:

Koncové velární, retroflexní, dentální a labiální výbuchové souhlásky (tj. nikoliv nosovky ani palatály).
