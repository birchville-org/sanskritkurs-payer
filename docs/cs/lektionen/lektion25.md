# Lekce 25

## 25.1. Vznik ablativu (⟪पञ्चमी⟫ = "pátý pádový koncovka")

::: grammar-box
Kromě maskulin / neutra na -a a zájmen jsou v singuláru ve všech deklinacích tvary ablativu (⟪पञ्चमी⟫) totožné s tvary genitivu (⟪षष्ठी⟫).

Kromě osobních zájmen jsou ve všech deklinacích v plurálu tvary ablativu totožné s tvary dativu (⟪चतुर्थी⟫).
:::
Nyní rozpoznáte důvod pro pořadí pádů (⟪विभक्ति⟫) v sanskrtu: jsou uspořádány tak, aby shodné tvary stály co nejbliže u sebe – resp. pod sebou.

::: grammar-box
**Ablativ singuláru maskulin / neutra na -a**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
> Otázka, vztažná a ukazovací zájmena:

::: grammar-box

| | Ablativ singuláru:brMaskulinum / Neutrum | Ablativ singuláru:brFemininum |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Užití ablativu (⟪पञ्चमी⟫)

"Ablativ označuje to, co zůstává pevné, když se něco od něj vzdaluje."

Pāṇini 2,3,28 + 1,4,24

Ablativ stojí především na otázky "Odkud?", "Proč?".

::: grammar-box
1. Ablativ tedy označuje počáteční bod, původ a látku.

Ablativ může tedy také označovat osobu, od které něco kupujeme, slyšíme, přejeme si atd.
:::
Příklady:

::: indent
⟪ग्रमादागच्छति⟫ = "Přichází z vesnice"

⟪अश्वात्पतितः⟫ = "spadl z koně"

⟪तेभ्यो लब्धम्⟫ = "přijato od nich (sem)"
:::
Příklady:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "slyší od učitele o dharmě"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "bráhman si přeje od kṣatriji krávu"
:::
::: grammar-box
2. Ablativ stojí u sloves s významy "odrazovat od", "chránit před", "obhajovat proti", "bát se":
:::
Příklad:

::: indent
⟪अरिभ्यो रक्षति⟫ = "chrání před nepřáteli"
:::
::: grammar-box
3. Ablativ označuje důvod nebo příčinu:
:::
Příklady:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "Zabíjí svého syna ze vzteku"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "Protože spáchal zlo, jde do pekla" (« Protože je tím, skrze kterého bylo spácháno zlo)

⟪पापकरणान्नरकं गच्छति⟫ = "Protože koná/způsobuje zlo, jde do pekla"
:::
Podstatná jména, která nejsou ženského rodu, mohou k vyjádření důvodu činnosti stát v instrumentálu (⟪तृतीया⟫) nebo ablativu (⟪पञ्चमी⟫). Ženského rodu stojí v tomto smyslu obvykle v instrumentálu, ale mohou také někdy stát v ablativu.

## 25.3. Přípona -⟪तस्⟫

::: grammar-box
Chceme-li ve jednotném čísle (jednoznačně) vyjádřit, že je slovo použito v ablativovém významu, lze ke kmeni připojit příponu -⟪तस्⟫, která tvoří příslovce s převážně ablativovým významem (na otázku "Odkud?"):
:::
Příklady:

::: indent
⟪आदितस्⟫ = "od počátku"

⟪धर्मतस्⟫ = "kvůli dharmě, na základě dharmy"
:::
::: grammar-box
Koncovka -⟪तस्⟫ se vyskytuje také na kmenech zájmen:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "odtud, tam, tamto, na to, pak, proto"

⟪यद्⟫ : ⟪यतस्⟫ "odkud, čeho, kde, kam, proč" (relativní)

⟪किम्⟫ :  ⟪कुतस्⟫ "odkud?" "proč?"
:::
## 25.4. Jiné způsoby vyjádření zdůvodnění

::: grammar-box
**1\. Relativní věty**

Relativní věty často vyjadřují kauzální (zdůvodňující), konsekutivní (následnou) nebo finální (účelovou) vztah k hlavní větě.

Tvary relativního zájmena, které slouží jako kauzální spojka:

*   ablativní:
*   ⟪यतस्⟫ ... podřadná věta ... ⟪ततस्⟫ ... hlavní věta ... = "protože ..., proto ..."
*   ⟪यस्मात्⟫ ... podřadná věta ... ⟪तस्मात्⟫ ... hlavní věta ... = "protože ..., proto ..."
*   instrumentál:
*   ⟪येन⟫ ... podřadná věta ... ⟪तेन⟫ ... hlavní věta ... = "čím/protože ..., tím / proto ..."
:::
Příklad:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "Protože Ráma žádá blahobyt, praktikuje své sliby"
:::
::: grammar-box
**2\. ⟪हि⟫**

Hlavní věty lze pomocí částice ⟪हि⟫ "neboť, protože" propojit. Věta s ⟪हि⟫ (která nemůže stát na prvním místě, ale v próze musí stát na druhém místě) uvádí zdůvodnění buď pro předchozí větu, nebo pro následující větu:
:::
Příklad:

::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "Lidé konají záslužná čina. Chtějí přece vstoupit do nebe."
:::
::: grammar-box
**3\. Instrumentál (⟪तृतीया⟫)**

Vedle ablativu (⟪पञ्चमी⟫) se instrumentál (⟪तृतीया⟫) používá k vyjádření důvodu nebo příčiny. U ženských substantiv je instrumentál obecně povinný.
:::
Příklad:

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = "Zabíjí svého syna ze vzteku" = "Zabíjí svého syna ve vzteku"
:::
::: grammar-box
**4\. Substantiva**

::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "Lidé konají záslužná čina. Chtějí přece vstoupit do nebe."
:::
::: grammar-box
**3\. Instrumentál (⟪तृतीया⟫)**

Vedle ablativu (⟪पञ्चमी⟫) se instrumentál (⟪तृतीया⟫) používá k vyjádření důvodu nebo příčiny. U ženských substantiv je instrumentál obecně povinný.
:::
Příklad:

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = "Zabíjí svého syna ze vzteku" = "Zabíjí svého syna ve vzteku"
:::
::: grammar-box
**4\. Substantiva**

Kromě toho lze samozřejmě důvody vyjádřit také konstrukcemi s

*   ⟪कारण⟫ n. "příčina": ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ m.
*   jiná substantiva ve významu "příčina"

\+ genitiv (⟪षष्ठी⟫) nebo jako zadní člen složenin:
:::
Příklad:

::: indent
⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ atd.) = "kvůli zásluze"
:::
::: grammar-box
**5\. ⟪इति⟫**

Motiv činnosti lze vyjádřit jako myšlenku s ⟪इति⟫:
:::
Příklad:

::: indent
⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫  = "Protože Sugata plně probudil k pravdě, ptá se Ānanda Gautamy na jeho učení" (« "Myslel si: 'Sugata plně probudil k pravdě' ..."
:::
