# Lekce 24

## 24.1. Dativ (⟪चतुर्थी⟫ = "čtvrtý pád")

::: grammar-box
**1. K vyjádření účelu nebo záměru ("aby") děje lze místo infinitivu (⟪तुमुन्⟫) použít také podstatné jméno s kṛt příponou, která vyjadřuje děj nebo stav, v dativu (⟪चतुर्थी⟫ = "čtvrtý pád").**

Příklad:

místo:

:::
::: indent
⟪रामो गुरुवचनं श्रोतुं गतः ।⟫
:::
lze také říci:

::: indent
⟪रामो गुरुवचनस्य श्रवणाय गतः ।⟫

nebo:

⟪रामो गुरुवचनश्रवणाय गतः ।⟫
:::
= "Ráma odešel, aby poslechl přednášku učitele."
::: media
![](/images/lekt2404.webp)
Obr.: ⟪बाला गुरुश्रवणाय गताः⟫
(Zdroj obrázku: [Podrobnosti](/cs/licenses#lekt2404))
:::

::: grammar-box
**2. Dativ (⟪चतुर्थी⟫) může také označovat objekt doplňujícího infinitivu účelu:**

Příklad:

:::
::: indent
⟪फलेभ्यो ग्रामं गच्छति⟫ = "Jde do vesnice za účelem ovoce = Jde do vesnice, aby si pro ovoce."
:::
**Stejným způsobem vyjadřuje dativ (⟪चतुर्थी⟫) účel věci nebo děje:**

Příklad:

::: indent
⟪यज्ञायान्नम्⟫ = "Jídlo za účelem oběti = Jídlo pro oběť"
:::
::: media
![](/images/lekt2401.webp)
Obr.: ⟪यज्ञायान्नम्⟫

Stovky vegetariánských pokrmů je tohoto dne nabízeno Bhagwanu Swaminarayanovi [સ્વામિનારાયણ].
(Zdroj obrázku: [Podrobnosti](/cs/licenses#lekt2401))
:::

::: grammar-box
**3. Dativ (⟪चतुर्थी⟫) označuje také osobu nebo věc, pro kterou je předmět činnosti určen (nepřímý objekt; otázka: komu?). (Všimněte si však sloves s dvojitým akuzativem (⟪द्वितीया⟫)!)**

Příklad:

:::
::: indent
⟪रामाय फलं ददाति⟫ = "Dává Rámovi ovoce." (Kmen ⟪दा⟫ 3. třídy přítomného času)

::: grammar-box
**4. Dativ stojí u některých sloves (a některých dalších slov) podobně jako v němčině na otázku "komu?":**

Příklady:

:::
::: indent

⟪अलम्⟫ příslovce: "dostatečně, přiměřeně": ⟪अलं योधो योधाय⟫ = "bojovník je druhému bojovníku přiměřený"

## 24.2. Tvoření dativu (⟪चतुर्थी⟫)

::: grammar-box
**Pravidelné koncovky dativu jsou:**

* **Singular: -e ; ženská kmenová slova končící na samohlásku: -ai**
* **Plurál: Dativ a ablativ ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. Konsonantické kmeny

::: grammar-box

| | Dativ singuláru | Dativ plurálu |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. Tázací zájmena

::: grammar-box

| | Maskulinum / Neutrum | Femininum |
| :--- | :--- | :--- |
| **Dativ singuláru** | ⟪कस्मै⟫ | ⟪कस्यै⟫ |
| **Dativ plurálu** | ⟪केभ्यस्⟫ | ⟪काभ्यस्⟫ |

:::
### 24.2.3. Ukazovací zájmena

::: grammar-box

| | | ⟪तद्⟫ | ⟪एतद्⟫ | ⟪इदम्⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **Maskulinum / Neutrum** | **Dat. sg.** | ⟪तस्मै⟫ | ⟪एतस्मै⟫ | ⟪अस्मै⟫ |
| | **Dat. pl.** | ⟪तेभ्यस्⟫ | ⟪एतेभ्यस्⟫ | ⟪एभ्यस्⟫ |
| **Femininum** | **Dat. sg.** | ⟪तस्यै⟫ | ⟪एतस्यै⟫ | ⟪अस्यै⟫ |
| | **Dat. pl.** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::
### 24.2.4. Samohláskové kmeny

::: grammar-box
**Samohláskové kmeny**

* **Maskulina / Neutra na -a:** ⟪देव⟫
* Dat. sg. ⟪देवाय⟫
* Dat. pl. ⟪देवेभ्यस्⟫
* **Maskulina na -i:** ⟪कवि⟫
* Dat. sg. ⟪कवये⟫
* Dat. pl. ⟪कविभ्यस्⟫
* **Maskulina na -u:** ⟪पशु⟫
* Dat. sg. ⟪पशवे⟫
* Dat. pl. ⟪पशुभ्यस्⟫
* **Feminina na -ā:** ⟪देवता⟫
* Dat. sg. ⟪देवतायै⟫
* Dat. pl. ⟪देवताभ्यस्⟫
* **Feminina na -ī:** ⟪देवी⟫
* Dat. sg. ⟪देव्यै⟫
* Dat. pl. ⟪देवीभ्यस्⟫
* **Feminina na -i:** ⟪श्रुति⟫
* Dat. sg. ⟪श्रुतये⟫ nebo ⟪श्रुत्यै⟫ (tj. jako ⟪कवि⟫ nebo jako ⟪देवी⟫)
* Dat. pl. ⟪श्रुतिभ्यस्⟫
* **Feminina na -u:** ⟪धेनु⟫
* Dat. sg. ⟪धेनवे⟫ nebo ⟪धेन्वै⟫
* Dat. pl. ⟪धेनुभ्यस्⟫
:::
## 24.3. Sandhi koncového -ai a -au

::: grammar-box
**Sandhi koncového -ai a -au**

* **-ai před samohláskou se obvykle nahrazuje za -ā (vzácněji za -āy, jako uvnitř slova)**
* **-au před samohláskou se obvykle nahrazuje za -āv (vzácněji za -ā)**

Příklad:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा अग्नये⟫ = "tomu ohni"
:::
## 24.4. Slovník

⟪अलम्⟫ příslovce: dostatečně, přiměřeně; (komu, čemu) zdatný ; s dativem: dostatek pro, přiměřený pro; s instrumentálem: dostatek s, ustupti od , např. ⟪अलं क्रोधेन⟫ = "dostatek s hněvem = ustupti od hněvu!"

## 24.6. Další cvičení k užití dativu

Přeložte do sanskrtu:

1. Bohyně, které nebyť obětována, hněvá se na lidi.

2. Nechá krávu vyhnat do vesnice.

3. Teď to stačí = Dosť trpělivosti.

4. To je dobré (⟪हित⟫, ⟪सुख⟫) pro brahmána.

5. Uctívání (⟪नमस्⟫) ať je Šivovi! Uctívání ať je Śrī Gaṇešovi!
