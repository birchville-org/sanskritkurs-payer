# Lekce 35

## 35.1. Perfekt typ III: Silný kmen ve stupni prodlouženém/stupni zesíleném

::: grammar-box
**Tvorba:**

**silný kmen:**
*   3.os.P: stupeň prodloužený (dehnstufe)
*   2.os.P: stupeň zesílený (hochstufe)
*   1.os.P: volitelně stupeň zesílený nebo prodloužený

**slabý kmen:** viz podtypy
:::
### 35.1.1. Perfekt typ IIIa: Silný kmen ve stupni zesíleném/prodlouženém, slabý kmen v nízkém stupni

::: grammar-box
**Tvorba:**

:::
::: indent
**slabý kmen:** nízký stupeň (tiefstufe)
:::
Vytváří se od kořenů typů:
*   (Konsonant)-(Konsonant) - i/ī/u/ū
*   (Konsonant) - ṛ

Před koncovkou začínající samohláskou se nahrazuje:
*   -i/-ī za -iy
*   -u/-ū za -uv
*   -ṛ za r
Příklady:


| Kořen | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:brí + iy + ur | | |
| ⟪नी⟫ 1U | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2U | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

### 35.1.2. Perfekt typ IIIb: Silný kmen ve stupni zesíleném/prodlouženém, slabý kmen ve stupni zesíleném

::: grammar-box
**Tvorba:**

:::
::: indent
**slabý kmen:** stupeň zesílený (hochstufe)
:::
Vytváří se od kořenů typů:
*   (Konsonant)-(Konsonant)-ṝ
*   Konsonant-Konsonant-ṛ (tj. kořeny na -ṛ, pokud jim předchází více konsonantů)
Příklady:


| Kořen | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पॄ⟫ 3P | ⟪पपार⟫ | ⟪पपरुर्⟫ | | |
| ⟪स्मृ⟫ 1P | ⟪सस्मार⟫ | ⟪सस्मरुर्⟫ | | |
| ⟪संस्कृ⟫ 8U | ⟪सञ्चस्कार⟫:brsam + ca-skār-a | ⟪सञ्चस्करुर्⟫ | ⟪सञ्चस्करे⟫ | ⟪सञ्चस्करिरे⟫ |

## 35.2. Perfekt Typ IV: Kmeny končící na -ā / -āi

::: grammar-box
**Vznik:**

**silný kmen:**
*   3./1. sg. P Perfektum končí na -au
*   2\. sg. P : Vyšší stupeň -ā nebo Nižší stupeň -i

**slabý kmen:**
*   před souhláskou: Nižší stupeň -i
*   před samohláskou: Nižší stupeň Ø

Vytváří se od kořenů končících na -ā / -āi
:::
Příklad:


| Kořen | 3. sg. Perf. P.:br1. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪ददौ⟫ | ⟪ददुर्⟫:brda-d-ur | ⟪ददे⟫ | ⟪ददिरे⟫:brda-d-i-re |

## 35.3. Perfekt Typ V: Kořeny Konsonant-a-Konsonant

::: grammar-box
**Vznik:**

**silný kmen:**
*   3.sg.P: Prodloužený stupeň
*   2.sg.P: Vyšší stupeň
*   1.sg.P: volitelně Vyšší stupeň nebo Prodloužený stupeň

**slabý kmen:** viz podtypy

Vytváří se od kořenů typu (Konsonant)-Konsonant-a-Konsonant
:::
### 35.3.1. Perfekt Typ Va: slabý kmen Nižší stupeň

::: grammar-box
**Vznik:**

:::
::: indent
**slabý kmen:** Nižší stupeň
:::
Vytváří se mimo jiné od kořenů:
*   ⟪गम्⟫
*   ⟪हन्⟫
*   ⟪जन्⟫
*   ⟪वच्⟫
*   ⟪वद्⟫
*   ⟪यज्⟫
Příklady:

| ⟪हन्⟫ 2P | :sig[⟪जघान⟫] :brja-**ghān**-a | :sig[⟪जघ्नुर्⟫] | | |
| ⟪जन्⟫ 4Ā | | | ⟪जज्ञे⟫:brja-jñ-e | ⟪जज्ञिरे⟫ |

### 35.3.2. Perfekt typ Vb: slabý kmen kontrakce (typ e)

::: grammar-box
**Vznik:**

:::
::: indent
**slabý kmen:** žádná reduplikace. Nahrazení -a- kořene za -e-
(k vysvětlení viz Thumb-Hauschild 1,2 str. 286n.)
:::
Vytváří se od kořenů s -a- mezi dvěma jednoduchými souhláskami, jejichž počáteční souhláska se v reduplikačním slabiku nemění (tj. jejichž počáteční souhláska není guturála, aspiráta ani h).
Příklad:

| Kořen | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 1U | ⟪पपाच⟫ | :sig[⟪पे⟫]⟪चुर्⟫ | :sig[⟪पे⟫]⟪चे⟫ | :sig[⟪पे⟫]⟪चिरे⟫ |

### 35.3.3. Perfekt typ Vc: kořeny Souhláska-a-Souhláska. Slabý kmen silný stupeň

::: grammar-box
**Vznik:**

**slabý kmen:** silný stupeň

Vytváří se od všech ostatních kořenů se středním -a-, tj. kořeny se středním -a-
*   které začínají dvěma souhláskami
*   které začínají guturálou
*   které začínají aspirátou
*   které začínají h

pokud nepatří k Perfekt typu Va.
:::
Příklad:

| Kořen | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪क्रम्⟫ 1U | ⟪चक्राम⟫ | ⟪चक्रमुर्⟫ | ⟪चक्रमे⟫ | ⟪चक्रमिरे⟫ |
