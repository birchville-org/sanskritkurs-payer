# Lekce 34

## 34.1. Perfekt (⟪लिट्⟫)

V klasickém sanskrtu existují od kmene perfekta pouze oznamovací způsob a particip.

::: grammar-box
**Existují dva typy tvoření perfekta:**
*   **reduplikované perfektum = ⟪द्वित्वलिट्⟫**
*   **perifrázované perfektum = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Perifrázované perfektum (⟪अनुप्रयोगलिट्⟫) se používá:**
1. **u odvozených konjugací (kausativ, desiderativ, frekvantivum, denominativa)**
2. **u kořenů, které začínají dlouhým samohláskovým znakem (kromě ā-), nebo se samohláskou (kromě a-) před dvěma souhláskami**
3. **u některých dalších kořenů**
:::
## 34.2. Reduplikované perfektum (⟪द्वित्वलिट्⟫)

### 34.2.1. Stupňování kmene

::: grammar-box
**Tvoření:**

**Silný kmen: jednotné číslo Parasmaipada**
*   **reduplikovaný kořen ve vysokém stupni nebo prodlouženém stupni + koncovka perfekta**

**Slabý kmen: všechny ostatní tvary**
*   **reduplikovaný kořen v nízkém stupni + koncovka perfekta**
:::
::: grammar-box
**Obecně (také mimo perfektum) nemají stupňování kmene kořeny ve tvaru:**
*   **(souhláska)-souhláska-dlouhá-samohláska-souhláska**
*   **(souhláska)-souhláska-samohláska-souhláska-souhláska**

**V perfektu navíc nemají stupňování kmene kořeny ve tvaru:**
*   **a-souhláska**
*   **ā-souhláska**
:::
### 34.2.2. Koncovky perfekta

::: grammar-box

| | 3. jednotné číslo | 3. množné číslo |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |

:::
### 34.2.3. Vazebný samohláskový znak -i-
### 34.2.4. Reduplikation konsonantisch anlautender Wurzeln

::: grammar-box
**Pro reduplikaci kořenů začínajících souhláskou platí pravidla uvedená v [Lektion 33](lektion33.md).**

**Reduplikační samohláska u kořenů začínajících souhláskou je krátký samohláskový prvek kořene.**

**Diftong před souhláskou se redukuje na příslušný krátký samohláskový prvek v nízké poloze.**

**ṛ, ṝ, ḷ a koncové diftongy se reduplikují pomocí -a-.**
:::
Příklad:

::: grammar-box

| Kořen | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::
::: grammar-box
**Některé kořeny začínající y- resp. v- se reduplikují pomocí i- resp. u-, které ve slabých tvarech „splynou“ se samohláskou kořene.**
:::
Příklad:

::: grammar-box

| Kořen | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Reduplikation vokalisch anlautender Wurzeln

::: grammar-box
**1. počáteční a-, ā- se reduplikuje pomocí a-, takže vznikne ā-.**
:::
Příklad:

::: grammar-box

| Kořen | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "být" a ⟪अस्⟫ 4 "hodit" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. Kořeny s počátečním i- mají ve silném kmeni reduplikační slabiku iy-, v slabém kmeni i-, která se s samohláskou kořene splyne na ī-. Analogicky platí pro počáteční u-.**
:::
Příklad:

::: grammar-box

| Kořen | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. Kořeny začínající na a- před dvěma souhláskami nebo s ṛ-, mají jako reduplikční slabiku ān-**
:::
Příklady:

::: grammar-box

| Kořen | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. Typy reduplikovaného perfekta

Rozdělovací princip: Zvláštnosti gradace kmene:
*   Perfektum bez gradace kmene: Typ I
*   Perfektum s gradací kmene: Typ II - V
*   nepravidelné formy perfekta

## 34.4. Perfektum Typ I: Perfektum bez gradace kmene

::: grammar-box
**Perfektum Typ I (bez gradace kmene) tvoří kořeny typů:**
*   **(Souhláska)-Souhláska-Dlouhásamohláska-Souhláska**
*   **(Souhláska)-Souhláska-Samohláska-Souhláska-Souhláska**
*   **a-Souhláska**
*   **ā-Souhláska**
:::
Příklady:

::: grammar-box

| Kořen | 3. sg. Perf. | 3. pl. Perf. |
| :--- | :--- | :--- |
| ⟪बन्ध्⟫ 9P | ⟪बबन्ध⟫:brba-bandh-a | ⟪बबन्धुर्⟫ |
| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |
| ⟪आप्⟫ 5P | ⟪आप⟫:bra + āp-a | ⟪आपुर्⟫ |
| ⟪अस्⟫ 2P "být":br⟪अस्⟫ 4 "hodit" | ⟪आस⟫:bra + as-a | ⟪आसुर्⟫ |
| ⟪अश्⟫ | ⟪आनशे⟫:brnepravidelná reduplikace! | ⟪आनशिरे⟫ |

:::
## 34.5. Perfektum Typ II: Silný kmen ve stupni, slabý kmen v hlubokém stupni

::: grammar-box
**Tvoří se z kořenů tvaru:**
*   **(Souhláska)-(Souhláska)-i/u/ṛ/ḷ-Souhláska**

**Tvorba:**
*   **silný kmen: vysoký stupeň**
*   **slabý kmen: hluboký stupeň**
:::
Příklady:
