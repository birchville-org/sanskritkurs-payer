# Lekce 4

## 4.1. Jednoduché doplňovací otázky (slovní otázky) a odpovědi

### 4.1.1. Otázka zájmena a ukazovací zájmena

#### 4.1.1.1. Otázka zájmena (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Nominativ singulár | Nominativ plurál |
| :--- | :--- | :--- |
| **Neutrum** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Maskulinum** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Femininum** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Ukazovací zájmena (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Kmeny** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"on, ona, to; ten, ta, to":br(Oni zmiňovaní)** | **etad = ⟪एतद्⟫:br"tento, tato, toto":br(Běžně velmi blízko mluvčího)** | **idam = ⟪इदम्⟫:br"tento, tato, toto":br(Běžně blízko)** |
| **Nominativ singulár** ||||
| **Neutrum** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Maskulinum** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Femininum** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Nominativ plurál** ||||
| **Neutrum** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Maskulinum** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Femininum** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**K nom. sg. mask.:**
**sa, eṣa** (⟪स एष⟫) stojí před všemi zvuky kromě krátkého **-a**
**so, eṣo** (⟪सो एषो⟫) stojí před **-a**, které je elidováno (vynecháno) s Avagraha
**saḥ, eṣaḥ** (⟪सः एषः⟫) stojí pouze v pauze (konec věty, konec verše)

Aby bylo možné s těmito zájmeny (sarvanāman n.) tvořit věty, je třeba znát následující sandhi pravidla:

### 4.1.2. Sandhi koncového -m

::: grammar-box
**Koncové -m se před souhláskami nahrazuje anusvārou (-ṃ). Na konci věty či verše a před samohláskami zůstává -m zachováno.**
:::
### 4.1.3. Sandhi koncového -e

::: grammar-box
1. **před a- zůstává -e nezměněno: počáteční a- se eliduje s avagrahou:**
např. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ „Tato ohně“

2. **Před jinými samohláskami než krátkým a- se -m obvykle nahrazuje -a s hiátem. Častěji se však vyskytuje náhrada za -ay:**
např. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (vzácně: imay īśvarāh = ⟪इमयीश्वराः⟫) „TITO PÁNOVÉ“
:::
### 4.1.4. Sandhi koncového -d

::: grammar-box
**Koncové -d se v pauze i před bezhlásými velárními (k, kh) a labiály (p, ph) nahrazuje za -t.**

Náhrada před ostatními souhláskami bude probírána později. Těmto shodám hlásek se zatím vyhněte!
:::
### 4.1.5. Otázkové formule

Pomocí těchto zájmen se tvoří např. následující otázkové formule:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Singular** | **Neutrum** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं किम्⟫, ⟪किमिदम्⟫ | „Co to je?“ |
| ^^| **Maskulinum** | sa kaḥ? / kaḥ saḥ?:br⟪स कः⟫, ⟪कः सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष कः⟫, ⟪क एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं कः⟫, ⟪को ऽयम्⟫ | „Kdo to je?“:br„Co je ten?“ |
| ^^| **Femininum** | sā kā? / kā sā?:br⟪सा का⟫, ⟪का सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं का⟫, ⟪केयम्⟫ | „Kdo to je?“:br„Kdo ta je?“ |
| **Plural** | **Neutrum** | tāni kāni? / kāni tāni?:br⟪तानि कानि⟫, ⟪कानि तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि कानि⟫, ⟪कानीमानि⟫ | |
|^^ | **Maskulinum** | te ke? / ke te?:br⟪ते के⟫, ⟪के ते⟫:brete ke? / ka ete?:br⟪एते के⟫, ⟪क एते⟫:brime ke? / ka ime?:br⟪इमे के⟫, ⟪क इमे⟫ | |
| ^^| **Femininum** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः काः⟫, ⟪का एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः काः⟫, ⟪का इमाः⟫ | |
:::
Příklad jiných otázek:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ Odpověď: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (V nominativním souvětí lze předmět např. umístit na začátek, aby se zdůraznilo navázání na otázku.)

POZNÁMKA: Odpovědi, které můžete na takové otázky dát se svými dosavadními znalostmi sanskrtu, samozřejmě ještě neodpovídají ve všech ohledech idiomaticky dobrému sanskrtu.
