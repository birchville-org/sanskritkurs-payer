# Lekce 9

A) Pokuste se určit možné významy následujících slov:

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. ten, kdo je podobný Brahmanovi = špatný Brahman

2\. mati ⟪मति⟫ : f. názor

3\. śravaṇa ⟪श्रवण⟫ : n. ucho

4\. dhenuka ⟪धेनुक⟫ : m. (koitus) způsobem krávy

5\. jayaka ⟪जयक⟫ : 3 vítězný

6\. rakṣikā ⟪रक्षिका⟫ : f. strážkyně, amulet

7\. karṣaka ⟪कर्षक⟫ : 3 orající ; m. rolník

8\. kleśa ⟪क्लेश⟫ : m. trápení

9\. nāyikātva ⟪नायिकात्व⟫ : n. stav milované

10\. tantraka ⟪तन्त्रक⟫ : 3 (právě) pocházející z osnovy / tkalcovského stavu = nově tkaný

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : tanečník

12\. naraka ⟪नरक⟫ : m. peklo

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. být pánem

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. bojovník

17\. kopa ⟪कोप⟫ : m. vztek

18\. veśaka ⟪वेशक⟫ : 3 vstupující

19\. darśaka ⟪दर्शक⟫ : 3 vidící

20\. kopaka ⟪कोपक⟫ : 3 ten, kdo je snadno vzteklý, výbušný

B) Přeložte:

1\. Úkoly všech dvakrát narozených:

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

(Yājñavalkyadharmaśāstra I, 118)

Oběti, studium Védy, dávání darů.

2\. Specifické úkoly Brahmana:

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

(Gautamadharmasūtra X,2)

Učení, obětování na objednávku, přijímání darů.

3\. Specifické úkoly Kṣatriyi:

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं सर्वभूतानाम्⟫

(sarvabhūtānām = Genitiv: "všech bytostí")

(Gautamadharmasūtra X,7)

Střežení všech bytostí.

4. Specifické úkoly Vaiśyi:

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(podle Gautamadharmasūtra X,49)

Zemědělství, obchod, chov dobytka a půjčování peněz.

5. Úkoly Śúdry:

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं शुश्रूषा वार्त्त्ता कारुकुशीलवकर्म च⟫

(podle Kauṭilīya-arthaśāstra 1.3.8.)

Vysvětlení:
dvijātīnām = Genitiv (přivlastňovací pád) plurálu k dvijāti (zde přeložte: "ve vztahu ke dvakrát zrozeným")

kārukuśīlavakarma je Tatpuruša s Dvandvou (kārukuśīlava) v přední části. karma = nominativ singuláru od karman n. "činnost, činnost, Karma" ke kořeni kṛ 8 U). Přeložte "činnost / činnost ... (ve genitivu)" (označenou Dvandvou).

Poslušnost vůči dvakrát zrozeným, činnosti pro obživu, řemeslná činnost nebo putující vystupování.

6. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः पाशुपाल्यं वणिज्या च वार्त्ता⟫

(podle Kauṭilīya-arthaśāstra 1.4.1.)

Ekonomika je zemědělství, chov dobytka a obchod.
