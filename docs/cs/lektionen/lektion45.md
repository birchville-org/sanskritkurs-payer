## 45.2. Vokativ singuláru (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**Většina vokativů singuláru je kmen s přízvučným koncovým samohláskovým výstupem.**

např. **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** atd.

**Výjimkami jsou ženská rodová substantiva na -ā a -ī, stejně jako kmeny na -in, jejichž vokativ singuláru si je třeba zvlášť zapamatovat.**
:::
::: no-header
| | Vokativ singuláru |
| --- | --- |
| Maskulina na -a | ⟪देव⟫ |
| Neutrum na -a | ⟪फल⟫ |
| Ženská rodová substantiva na -ā | ⟪देवते⟫ |
| Maskulina na -i | ⟪कवे⟫ |
| Ženská rodová substantiva na -i | ⟪मते⟫ |
| Maskulina na -u | ⟪शत्रो⟫ |
| Ženská rodová substantiva na -u | ⟪धेनो⟫ |
| Ženská rodová substantiva na -ī | ⟪देवि⟫ |
| Maskulina na -ṛ | ⟪पितर्⟫ |
| Ženská rodová substantiva na -ṛ | ⟪मातर्⟫ |
| Maskulina na -an | ⟪राजन्⟫ |
| Neutrum na -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Maskulina na -man/-van | ⟪आत्मन्⟫ |
| Maskulina na -in | ⟪बलिन्⟫ |
| Maskulina na -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt m. | ⟪महन्⟫ |
| mahānt n. | ⟪महत्⟫:br= Nominativ |
| Maskulina na -mant/-vant | ⟪गुणवन्⟫ |
| Neutrum na -mant/-vant | ⟪गुणवत्⟫:br= Nominativ |
| Zájmena | Vokativ se netvoří |
:::

## 45.4. Cvičení

A) Přeložte do sanskrtu (pro minulé časy prosím použij imperfektum ⟪लङ्⟫):

1. Rozděluješ (buddhistickou) sanghu.

::: indent
k rozdělení sanghy (⟪सङ्घभेद⟫) viz:

**Payer, Alois (1944–):** Vinayamukha : Základní pojmy mnišských pravidel a řádového práva Theravády. -- Díl I. -- (Materiály k základním pojmům buddhismu). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::
2. Užívali jste země?

3. Obdrželi jste od krále dar?

Posvátný muži, proč se nebojíš nebezpečí?

Otče, kam opouštíš rodinu?

Šúdrovno, přinesla jsi břemeno do domu bohatého bráhmana?

Bohyně, měla bys splnit přání štěstí vaišyi, který vykonal zásluhy.

Sloni, neměli byste přerušit pouta.

Ty lvičím muži, proč nevěnuješ celou svou pozornost Absolutnu (Brahmanu)?

Ty básníku, změřil jsi světy?

B) Přeložte:

⟪अर्जुन हतो वा प्राप्स्यसि स्वर्गं जित्वा वा भोक्ष्यसे महीं । तस्माद्भवता योध्यम् ॥१॥ भवति कथमनन्तदुःखमरुणत् ॥२॥ ब्राह्मण किमग्नौ घृतमजुहोः ॥३॥ शत्रो शस्तेण जीवं न छिनत्सि ॥४॥⟫
