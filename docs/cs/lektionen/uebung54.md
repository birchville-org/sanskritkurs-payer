# Úkol 54

Sestavte k následujícím tvarům přítomného nebo dokonavého času příslušné tvary aoristu:

::: grammar-box
| Čís. | Tvar | Určení / Význam | Aorist |
|:---|:---|:---|:---|
| ⟪१⟫. | ⟪यन्ति⟫ | oni jdou | ⟪अगुः⟫ |
| ⟪२⟫. | ⟪पिबामि⟫ | já piji | ⟪अपाम्⟫ |
| ⟪३⟫. | ⟪ददौ⟫ | já jsem / on dal | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | ⟪बभूव⟫ | já / on / oni byli / jste byli | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | ⟪दधति⟫ | oni dávají / umisťují | ⟪अधुः⟫ |
| ⟪६⟫. | ⟪ऐम⟫ | my šli | ⟪अगाम⟫ |
| ⟪७⟫. | ⟪पपिथ⟫ | ty jsi pil / střežil | ⟪अपाः⟫ (k :sig[⟪पा⟫] "pít") |
| ⟪८⟫. | ⟪तिष्ठति⟫ | on stojí | ⟪अस्थात्⟫ |
| ⟪९⟫. | ⟪इयेथ⟫ | ty jsi šel | ⟪अगाः⟫ |
| ⟪१०⟫. | ⟪पप⟫ | vy jste pili | ⟪अपात⟫ |
| ⟪११⟫. | ⟪एष्यथ⟫ | vy půjdete | ⟪अगात⟫ |
| ⟪१२⟫. | ⟪तस्थुः⟫ | oni stáli | ⟪अस्थुः⟫ |
| ⟪१३⟫. | ⟪अधत्त⟫ | vy jste dávali / umisťovali | ⟪अधात⟫ |
| ⟪१४⟫. | ⟪अददाः⟫ | ty jsi dal | ⟪अदाः⟫ |
| ⟪१५⟫. | ⟪अभवन्⟫ | oni byli | ⟪अभूवन्⟫ |
| ⟪१६⟫. | ⟪ददिम⟫ | my jsme dali | ⟪अदाम⟫ |
| ⟪१७⟫. | ⟪भिद्यते⟫ | se štěpí / láme | ⟪अभेदि⟫ |
| ⟪१८⟫. | ⟪उद्यते⟫ | se říká | ⟪अवादि⟫ |
| ⟪१९⟫. | ⟪स्तूयते⟫ | on je chválen | ⟪अस्तावि⟫ |
| ⟪२०⟫. | ⟪कृष्यते⟫ | se orá | ⟪अकर्षि⟫ |
| ⟪२१⟫. | ⟪जायते⟫ | se rodí | ⟪अजनि⟫ |
| ⟪२२⟫. | ⟪गीयते⟫ | se zpívá | ⟪अगायि⟫ |
| ⟪२३⟫. | ⟪गम्यते⟫ | se jde | ⟪अगामि⟫ |
:::
