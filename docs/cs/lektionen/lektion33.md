# Lekce 33

## 33.1. Reduplikace (⟪अभ्यास⟫ m.)

* Třída třetí přítomného času
* (a některá slovesa jiných tříd přítomného času),
* perfektní čas,
* reduplikovaný aorist,
* frequentativum a
* desiderativum

jsou tvořeny pomocí reduplikace. Část reduplikované formy, která se umisťuje před kořen, se nazývá reduplikační slabika.

Reduplikační slabika se skládá z (jedné souhlásky a) samohlásky.

### 33.1.1. Reduplikační souhláska

::: grammar-box
**1. Obvykle:**  
**Opakování první souhlásky kořene**
:::
Příklady:

::: indent
⟪दा⟫ 3 "dát"
* 3.os.P.Ind.Prés. ⟪ददाति पॄ⟫ 3 "naplnit"
* 3.os.P.Ind.Prés. :sig[⟪पि⟫]⟪पर्ति मा⟫ 3Ā "měřit"
* 3.os.Ā.Ind.Prés. :sig[⟪मि⟫]⟪मीते⟫
:::
::: grammar-box
**2. Aspirovaná počáteční souhláska kořene se reduplikuje příslušnou neaspirovanou souhláskou.**
:::
Příklady:

::: indent
⟪धा⟫ 3 "umístit"
* 3.os.P.Ind.Prés. ⟪दधाति भी⟫ 3 "bát se"
* 3.os.P.Ind.Prés. :sig[⟪बि⟫]⟪भेति⟫
:::
::: grammar-box
**3. Velární souhláska se reduplikuje příslušnou neaspirovanou palatální souhláskou:**

:::
::: indent
⟪क्⟫, ⟪ख्⟫ prostřednictvím ⟪च् ग्⟫, ⟪घ्⟫ prostřednictvím ⟪ज्⟫
:::
**⟪ह्⟫ se vždy reduplikuje prostřednictvím ⟪ज्⟫.**
Příklady:

::: indent
⟪हु⟫ 3 "nalít do ohně (oběť)"
* 3.os.P.Ind.Prés. ⟪जुहोति⟫
:::
::: grammar-box
**4. Začíná-li kořen více souhláskami, opakuje se pouze první (případně za použití pravidel 2 nebo 3).**
:::
::: grammar-box
**5. Začíná-li kořen skupinou souhlásek fricatíva + bezesná souhláska, reduplikuje se nikoliv fricatívo, ale následující bezesná souhláska podle výše uvedených pravidel.**
:::
Příklad:

::: indent
⟪स्था⟫ 1 "stehen"
* 3.sg.P.Ind.Präs. ⟪तिष्ठति⟫
:::
## 33.2. Třída přítomného času (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ atd.")

::: grammar-box
**Vznik:**

**Silný kmen:**  
**reduplikovaný kořen ve vysoké stupnici + koncovka**

**Slabý kmen:**  
**reduplikovaný kořen v nízké stupnici + koncovka**

**Pro reduplikační souhlásku platí výše uvedená pravidla.**
:::
### 33.2.1. Reduplikační samohláska třetí třídy přítomného času

::: grammar-box
* **Pravidelná reduplikační samohláska je -i-**
* **Kořeny obsahující u reduplikují s -u-**
* **kořeny ⟪दा⟫, ⟪धा⟫, ⟪हा⟫ s -a-**
:::
Příklady:

::: grammar-box
⟪हु⟫ 3P "(do ohně) nalít pro oběť"

* **Silný kmen:** ⟪जुहो⟫
* **Slabý kmen:** ⟪जुहु⟫

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ přítomný čas** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | ⟪जुहुते⟫ | ⟪जुह्वते⟫:brjuhu + ate |
| **Imperfektum** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | ⟪अजुहुत⟫ | ⟪अजुह्वत⟫:bra-juhu + ata |
| **Optativ** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | ⟪जुह्वीत⟫:brjuhu + ī-ta | ⟪जुह्वीरन्⟫:brjuhu + ī-ran |
:::
## 33.3. K ablautu ā

ā kann

* za prvé může být prodlouženým stupněm jedné z řad ablautu s -a-
* za druhé vysokým stupněm v řadě ablautu skupiny ā

Dvě nejdůležitější řady ablautu ve skupině ā jsou:

::: grammar-box
**A.**

* **Nízký stupeň**
* **před souhláskou: -i-**  
např. ⟪धा⟫ PPP: ⟪हित⟫ (hi-ta)
* **před samohláskou: Ø**  
např. ⟪धा⟫ 3.pl.P.Ind.Präs. ⟪दधति⟫ (dadh-ati)
* **Vysoký stupeň: -ā-**  
např. ⟪धा⟫ 3.sg.P.Ind.Präs. ⟪दधाति⟫
:::
Sem patří např. také:

::: indent
⟪स्था⟫ 1
* PPP ⟪स्थित⟫ (sthi-ta)
* 3.sg.P.Fut. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **Tiefstupeň: -ī-**  
např. ⟪पा⟫ 1: PPP ⟪पीत⟫ (pī-ta)
* **Vysoký stupeň: -ā-**  
např. ⟪पा⟫ 1: Inf. ⟪पातुम्⟫
:::
## 33.4. Kořeny na -ā třetí třídy přítomného času

::: grammar-box
**Kořeny na -ā (kromě ⟪दा⟫ a ⟪धा⟫) mají ve slabém kmeni obvykle koncovku -ī-** (viz Thumb-Hauschild sv. 1,1 s. 271. Pravděpodobně zde působila výše uvedená ablativní řada B jako vzor, ačkoli tyto kořeny jinak ablautují podle řady A), **před vokálovými koncovkami kořenový samohláska zcela mizí (viz ablativní řada A).**
:::
Příklady:

::: grammar-box
⟪मा⟫ 3Ā "měřit"

| | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- |
| **Indikativ přítomný** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Imperfekt** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Optativ** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3P "opustit"

| | 3. sg. P. | 3. pl. P. |
| :--- | :--- | :--- |
| **Indikativ přítomný** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Imperfekt** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Optativ** | ⟪जह्यात्⟫:brjah-yā-t:br(Držte kořen ⟪हा⟫ má před optativem -yā/y stejný tvar jako před vokály!) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. Kořeny ⟪दा⟫ a ⟪धा⟫

::: grammar-box
**Kořeny ⟪दा⟫ a ⟪धा⟫ reduplikují s samohláskou -a- a ve slabém kmeni ztrácí kořenovou samohlásku.**

**Při ⟪धा⟫ si všimněte zákona hláskové dissimilace!**
:::
::: grammar-box
⟪धा⟫ 3U "umístit, stanovit, přidělit"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Präsens** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Vysvětlení: Thumb-Hauschild 1,1 S. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Imperfekt** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Optativ** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::
Tvary slovesa ⟪दा⟫ získáte tak, že v paradigmatu slovesa ⟪धा⟫ nahradíte **dh** za **d**. Tedy:

::: grammar-box
⟪दा⟫ 3U "dát"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Präsens** | ⟪ददाति⟫ | ⟪ददति⟫ | ⟪दत्ते⟫ | ⟪ददते⟫ |
| **Imperfekt** | ⟪अददात्⟫ | ⟪अददुर्⟫ | ⟪अदत्त⟫ | ⟪अददत⟫ |
| **Optativ** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
:::

## 33.7. Cvičení

A) Vložte do následujícího vzorce věty příslušné tvary slov v závorkách:

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने बहुवचने च⟫) ... ⟪अन्नं ददाति ।⟫ (⟪भिक्षु । अग्नि । शूद्रा । गुनवान्पुत्र । देवान्स्तुवन्कवि । ब्राह्मणी । महान्साधु । धेनु⟫)

B) Vložte příslušné tvary v závorkách uvedených sloves ve způsobu oznamovacím přítomném, minulé a optativním:

⟪ब्राह्मणो घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥ बुद्धगता भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥ सुगतः कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥ दुर्जना भिक्षुभ्यो ऽन्नं न⟫ ... (⟪दा⟫) ⟪॥४॥ साधुः कृष्णे मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो लोकान्⟫ ... ⟪जनास्तु न⟫ ... (⟪मा⟫) ⟪॥६॥ दासा भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥ ब्राह्मणी पात्रं जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫

⟪क्षत्रियशूरः पुत्रमादाय योद्धुं कुलमजहात् । स युद्धे शत्रुहतत्वाच्छरीरं हित्वा पुनर्भवमैत् ॥४॥ देवदत्तमपि सुखं दुःखमोक्षेष्टिं न पिपर्ति । सेष्टिः प्रज्ञयैव सम्पूर्यते ॥५॥ यः साधुर्भूतेभ्यो ऽभयं ददाति तस्माद्भूतानि न बिभ्यति स च तेभ्यो न बिभेति ॥६॥ मितमतयो नरकभयात्स्वर्गलोभाच्च पुण्यं कुर्वन्ति पापं च जहति । अमितप्रज्ञाबुद्धा हि नरकेभ्यो न बिभीयुः स्वर्गांश्च न लुभ्येयुः । ते भयं च लोभं चारुन्धन् ॥७॥⟫
