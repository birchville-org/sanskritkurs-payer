## 41.2. Další ⟪कृत्⟫-utváření na -a

### 41.2.1. Příčestí přítomného času (⟪लडादेशः⟫) Ā, příčestí přítomného času (⟪लडादेशः⟫) pasivum, příčestí budoucího času (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Tématické kmeny přítomného času, pasivum a budoucí čas

::: grammar-box
**Vytvoření:**

Kmen přítomného času / kmen pasiva / kmen budoucího času + -māna (ž. r. mānā)
:::
Příklady:

⟪यज्⟫ 1U, Part.Präs.Ā ⟪यजमान⟫ 3 "někdo, kdo je uctíván s obětí ve svém vlastním zájmu = pán oběti"

⟪मन्⟫ 4Ā, Part.Präs.Ā  ⟪मन्यमान⟫ 3 "myslící"

⟪कृ⟫ 8U, Part.Präs.Passiv ⟪क्रियमाण⟫ 3 "něco, co je děláno"

⟪दा⟫ 3U, Part.Fut.Ā ⟪दास्यमान⟫ 3 "někdo, kdo bude dávat ve svém vlastním zájmu"

#### 41.2.1.2. Atématické třídy přítomného času

::: grammar-box
**Vytvoření:**

Slabý kmen přítomného času (ve formě, kterou má před koncovkou -ate 3.os.č.m.) + -āna (ž. r. -ānā)
:::
Příklady:

::: grammar-box
| Kořen / Třída | Příčestí přítomného času Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "Participium" pasivní nutnosti (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Pro vyjádření pasivní nutnosti ("co musí/má být učiněno") lze adjektiva od kořenů a odvozených slovesných kmenů volitelně tvořit následujícími příponami:**

* **-⟪तव्य⟫** (ž. rod **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (ž. rod **-⟪अनीया⟫**)
* **-⟪य⟫** (ž. rod **-⟪या⟫**)
* **-⟪त्य⟫** (ž. rod **-⟪त्या⟫**) (místo **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Přípona -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Přípona -⟪तव्य⟫ / -⟪तव्या⟫ se přidává ke kořenům a odvozeným slovesným kmenům (např. kauzativu) stejným způsobem jako infinitivní přípona -⟪तुम्⟫ (viz [Lektion 23](lektion23.md)), tj.**

* **silná forma koene + ⟪तव्य⟫**

nebo

* **silná forma koene + -i- + ⟪तव्य⟫**

**V kauzativu:**

* **Kauzativní kmen na -ay + -i- + ⟪तव्य⟫**
:::
Příklady:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "ten, kdo musí být poražen; ten, který má být poražen" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "to, kde se má člověk nacházet" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "ten, kdo má být probuzen; ten, který má být probuzen" |

:::
#### 41.2.2.2. Přípona -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Tvorba:**

Silná forma koene + -⟪अनीय⟫ / -⟪अनीया⟫

**Kauzativ a 10. třída přítomného času:**

Kořen, jak se objevuje v kauzativním kmeni, bez -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Příklady:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "to, co má být dáno; to, co musí být dáno" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "ten, kdo má být poražen" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "to, co má být učiněno" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "to, co musí člověk vidět; to, za co stojí za to se podívat" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "ten, kdo má být probuzen" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "to, co musí být dáno (přes někoho)" |

:::
#### 41.2.2.3. Přípona -⟪य⟫ / -⟪या⟫

::: grammar-box
**Vznik:**

Kořen (v hluboké, vysoké nebo prodloužené stupni) + -⟪य⟫

Podrobná pravidla viz Kielhorn, Grammatik der Sanskrit-Sprache, str. 195 - 197!
:::
Zpracování koncových samohlásek:

::: grammar-box
**1. Kořeny na -ā tvoří toto gerundivum na -eya**
:::
Příklady:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "to, co má být vědováno; to, co musí být poznáno" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "to, co musí být dáno" |

:::
::: grammar-box
**2. Kořeny na -i /-ī / -u / -ū /-ṛ mají obvykle vysoký nebo prodloužený stupeň, pokud nepatří mezi ty kořeny na -i / -u /-ṛ, které tvoří gerundivum s příponou -⟪त्य⟫ (ž. r. -⟪त्या⟫) (seznam těchto kořenů u Kielhorna, Grammatik §537).**
:::

#### 41.2.2.4. Přípona -⟪त्य⟫ / ⟪त्या⟫ (místo -⟪य⟫ / -⟪या⟫)

::: grammar-box
Seznam kořenů na -i / -u /-ṛ, které tvoří gerundivum nikoli s -⟪य⟫ / -⟪या⟫, ale s příponou -⟪त्य⟫ (ženský rod -⟪त्या⟫), viz Kielhorn, Gramatika §537.

**Vytvoření:**

kořen v nízké stupni + -⟪त्य⟫ / -⟪त्या⟫
:::
Příklady:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "k chůzi" |
| ⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "k poslechu" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "k jednání" |

:::
### 41.2.3. Syntax k "gerundivu" pasivní nutnosti (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
Gerundivum může být používáno atributivně:

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = "město, které je třeba vidět; zajímavé město"
:::
Gerundivum může být také používáno jako predikativní jméno ve větách s pasivní konstrukcí, které vyjadřují povinnost nebo příkaz (s ⟪न⟫ zákaz, nemožnost):

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = "Dvakrátrození musí vidět Benáres"
:::

### 41.2.4. Rozdíly ve používání gerundivových přípon

::: grammar-box
Používání těchto přípon se do značné míry překrývá

* **-⟪तव्य⟫ (ž. -⟪तव्या⟫):** vždy vyjadřuje nutnost a používá se preferenčně predikativně (méně často atributivně). Tvoření s touto příponou by nemělo být používáno v nominálních složeninách.
* **-⟪अनीय⟫ (ž. -⟪अनीया⟫) a -⟪य⟫ (ž. -⟪या⟫) / -⟪त्य⟫ (ž. -⟪त्या⟫) (místo -⟪य⟫/-⟪या⟫):** mohou mít další význam (zejména -⟪य⟫) ve smyslu německého "-wert" (např. "hodný vidění") nebo pouze možnosti "-bar" (⟪दृश्य⟫ "viditelný"). Tvoření s těmito příponami mohou být záporně vyjádřena pomocí ⟪अ⟫-/-⟪अन्⟫- (nikoliv však tvoření s -⟪तव्य⟫) a existují ⟪तत्पुरुष⟫ jako jejich zadní člen, ve kterých se vyskytují.
:::
### 41.2.5. Žádné spojení s ⟪सु⟫- a ⟪दुस्⟫-

::: grammar-box
S ⟪सु⟫- a ⟪दुस्⟫- ve významu "lehce" resp. "těžce" nesmí být gerundiva spojována. Místo toho stojí ⟪तत्पुरुष⟫ typu  ⟪सुकर⟫ 3 ("snadno udělatelné") (s. [Lekce 18](lektion18.md)).
:::
