# პრაქტიკა 9

ა) სცადეთ განსაზღვროთ შემდეგი სიტყვების შესაძლო მნიშვნელობები:

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. ბრაჰმანის მხოლოდ მსგავსი = ცუდი ბრაჰმანი

2\. mati ⟪मति⟫ : f. აზრი

3\. śravaṇa ⟪श्रवण⟫ : n. ყურა

4\. dhenuka ⟪धेनुक⟫ : m. (კოიტუსი) ღორის მსგავსად

5\. jayaka ⟪जयक⟫ : 3 გამარჯვებული

6\. rakṣikā ⟪रक्षिका⟫ : f. მცველი, ამულეტი

7\. karṣaka ⟪कर्षक⟫ : 3 მოშვება ; m. მეურნე

8\. kleśa ⟪क्लेश⟫ : m. ტანჯვა

9\. nāyikātva ⟪नायिकात्व⟫ : n. საყვარლის მდგომარეობა

10\. tantraka ⟪तन्त्रक⟫ : 3 (ასევე) ქსოვის ჯაჭვიდან / მარცხენიდან მომდინარე = ახალი ქსოვილი

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : მოცეკვავე

12\. naraka ⟪नरक⟫ : m. ჯოჯოხეთი

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. ჭეშმარიტად-იყოს

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. მეომარი

17\. kopa ⟪कोप⟫ : m. ზიზღი

18\. veśaka ⟪वेशक⟫ : 3 შესვლა

19\. darśaka ⟪दर्शक⟫ : 3 ხედვა

20\. kopaka ⟪कोपक⟫ : 3 ადამიანი, რომელიც მალე ზიზღდება, მოულოდნელად

ბ) თარგმანის გაკეთება:

1\. ყველა ორჯერ დაბადებულის მოვალეობა:

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

(Yājñavalkyadharmaśāstra I, 118)

მსხვერპლი, ვედათა შესწავლა, საჩუქრების მიცემა.

2\. ბრაჰმანის სპეციფიკური მოვალეობა:

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

(Gautamadharmasūtra X,2)

სწავლება, მსხვერპლი მოთხოვნით, საჩუქრების მიღება.

3\. Kṣatriya-ს სპეციფიკური მოვალეობა:

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं सर्वभूतानाम्⟫

(sarvabhūtānām = გენეტივი: "ყველა არსების")

(Gautamadharmasūtra X,7)

ყველა არსების დაცვა.

4\. კონკრეტული მოვალეობები ვაიშისთვის:

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(გაუტამადჰარმასურის მიხედვით X,49)

სოფლის მეურნეობა, ვაჭრობა, პირუტყვის მოვლა და ფულადი სესხება.

5\. შუდრას მოვალეობები:

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं शुश्रूषा वार्त्त्ता कारुकुशीलवकर्म च⟫

(კაუტილიის ართჰასასტრას მიხედვით 1.3.8.)

ახსნა:
dvijātīnām = გენიტივი (მესაქმეობითი ბრუნვა) მრავლობითში dvijāti-სგან (აქ თარგმნეთ: "ორჯერ დაბადებულების მიმართ")

kārukuśīlavakarma არის ტატპურუშა დვანდვა-ს (kārukuśīlava) წინა ნაწილით. karma = ნომინativi ერთეულში karman n-დან "ქმედება, საქმიანობა, კარმა" ფესვი kṛ 8 U). თარგმნეთ "ქმედება / საქმიანობა ...-ის (დვანდვა-ს მიერ აღნიშნულის)" (გენიტივი).

დამორჩილება ორჯერ დაბადებულების მიმართ, ცხოვრების საშუალებით მოპოვებული საქმიანობები, მჭედლის ანუ მოგზაური შოუს გამომცემის საქმიანობა.

6\. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः पाशुपाल्यं वणिज्या च वार्त्ता⟫

(კაუტილიის ართჰასასტრას მიხედვით 1.4.1.)

ეკონომიკა არის სოფლის მეურნეობა, პირუტყვის მოვლა და ვაჭრობა.
