# ვარჯიში 1

ლექცია 1 არ შეიცავს წერილობით ვარჯიშებს, რადგან ის ხმოვანებისა და წაკითხვის საფუძვლების შესავლად არის შექმნილი. ლექციის ბოლოს მოცემული საკითხავი ვარჯიშები ხმოვანების პრაქტიკულ ათვისებას ემსახურება და არ საჭიროებს ცალკეულ პასუხების გასაღებს.
