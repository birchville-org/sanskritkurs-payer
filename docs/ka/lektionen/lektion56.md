::: grammar-box
**შექმნა:**

**ავგმენტი + რედუპლიცირებული ფუძე + a + თემატური მეორადი ბოლო**

### 56.1.1. კაუზატივების და 10-ე პრეზენტის კლასის ფუძეების აორისტის შექმნა

::: grammar-box
**საწყისი წერტილი არის რეგულარული რედუპლიკაციის ვოკალი, ანუ**

*   **i, u ჩანს ī-თ, ū-თ, თუ სახელის სილაბა ერთი კონსონანტით იწყება და მეტრიკულად მოკლეა:**

::: grammar-box

:::
::: indent
