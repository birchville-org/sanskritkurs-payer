# გაკვეთილი 17

## 17.1. მეორე პრეზენსის კლასი (⟪अदादि⟫ = ⟪अद्⟫ და ა.შ.)

ზმნის ბოლოები პირდაპირ ემატება ფუძეს. ამ დროს უნდა გაითვალისწინოთ სიტყვის შეერთებიდან (სანდჰი) გამომდინარე ხმოვანი ცვლილებები.

::: grammar-box

მეორე პრეზენსის კლასში არსებობს შემდეგი წარმოების ფორმები:

1.  ფუძეები გრადაციით (აფსვარა)
*   უმეტესად: მაღალი ხარისხი - დაბალი ხარისხი
*   ზოგიერთი ფუძე: გახანგრძლივებული ხარისხი - დაბალი ხარისხი
2.  ფუძეები გრადაციის გარეშე
3.  ორხმოვანი ფუძეები -ი/-ī ბოლოთი, გრადაციით

:::
