# გაკვეთილი 12


## 12.1. წარსული დროის პასიური ნაწილაკი (PPP)

წარსული დროის პასიური წინადადებების შესადგენად ერთ-ერთი გზაა ე.წ. წარსული დროის პასიური ნაწილაკის (PPP) კონსტრუქციის გამოყენება.

::: grammar-box
**სინამდვილეში, PPP არის ნამდვილი ნაწილაკი, რადგან ის არ იქმნება დროითი ფუძისაგან. ეს უფრო არის ნომინალური წარმოქმნა ფუძესთან ერთად პირველადი ზმნიდან -ta ანუ -na. ამიტომ ინდური გრამატიკაში ლაპარაკობენ kta ზმნიდან.**
:::

### 12.1.1. სქემა ტრანზიტული ზმნებისთვის

::: grammar-box
**აგენსი (kartṛ) ინსტრუმენტალში (tṛtīyā) -- პირდაპირი ობიექტი (karman) ნომინატივში (prathamā) -- წარსული დროის პასიური ნაწილაკი**

ამ შემთხვევაში PPP ემთხვევა ობიექტს რიცხვით, კეისით და სქესით.

საჭირო არ არის დამხმარე ზმა („იყოს“).

მაგალითები:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = „(წმინდანმა მიიღო ცა) = წმინდანი მიიღო ცა.“
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = „(ბრაჰმანმა გაუწია პატივი ღვთაებას სალოცავით) = ბრაჰმანმა გაუწია პატივი ღვთაებას სალოცავით.“
:::

### 12.1.2. სქემა I არატრანზიტული ზმნებისა და მოძრაობის ზმნებისთვის

::: grammar-box
**აგენსი (kartṛ) ნომინატივში (prathamā) -- წარსული დროის პასიური ნაწილაკი**

ამ შემთხვევაში PPP ემთხვევა აგენსს რიცხვით, კეისით და სქესით. წარსული დროის „პასიური“ ნაწილაკი არატრანზიტულ ზმნებში (ზმნები პირდაპირი ობიექტის გარეშე) და მოძრაობის ზმნებში აქტიურ მნიშვნელობას იძენს.

მაგალითი:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = „კშატრიის ქალი დაელოცა ქალაქში.“
:::

### 12.1.3. სქემა II არატრანზიტული ზმნებისა და მოძრაობის ზმნებისთვის

::: grammar-box
**აგენსი (kartṛ) ინსტრუმენტალით (tṛtīyā) -- PPP ნომინატის ერთეულში, მდედრობით სქესში**

მაგალითი:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(კშატრიას მიერ (ქალაქში) წასვლა მოხდა) = კშატრიამ (ქალაქში) წასვლა მოახდინა.“

სქემა II-ის კონსტრუქცია ბევრად უფრო იშვიათია, ვიდრე სქემა I-ის კონსტრუქცია.
:::

## 12.2. PPP-ის მნიშვნელობაზე

ამრიგად, თუ ტრანზიტული ზმნებისთვის ე.წ. „პერფექტის პასიური ნაწილაკი“ ძირითადად პასიურ მნიშვნელობას ატარებს (**āpta** = „მიღწეული (იქნა)“) და არატრანზიტული ზმნებისა და მოძრაობის ზმნებისთვის აქტიურ მნიშვნელობას (**gata** = „წასული“), არსებობს ზმნები, რომელთა PPP-ც როგორც აქტიურ, ასევე პასიურ მნიშვნელობას შეიძლება ატარებდეს:

მაგალითად
**gata** = ⟪गत⟫ = „წასული“ (აქტიური); ასევე: **gato mārgaḥ** = ⟪गतो मार्गः⟫ = „გავლილი გზა“ (პასიური)
**āpta** = ⟪आप्त⟫ = „მიღწეული (იქნა)“ (პასიური), „მიღწეული მქონე“ (აქტიური)


## 12.3. PPP-ის წარმოქმნა

::: grammar-box
შემდეგი წარმოქმნის გზებია შესაძლებელი (ყოველ ფუძესთან ერთად უნდა ისწავლოს მისი PPP!):

**(უმეტესად) ღრმა ხარისხის ფუძე**

**+ -ta**
ბინდვოკალით **-i-** წინ: **-ita**
ბინდვოკალის გარეშე: **-ta**
**+ -na**

მდედრობითი ფუძეები არის: **-tā**, **-itā**, **-nā**; მდედრობითი სქესის ნომინატი იცვლება როგორც **phala** n.
:::

### 12.3.1. -ta (kta) დამატებითი PPP

#### 12.3.1.1. ბინდვოკალი -i- გარეშე (aniṭ)

*aniṭ* = „გარეშე (*an-*) დანართის წინ (*-i-*) *t*“ (ე.ი. ბინდვოკალით *i*-ს გარეშე).

::: grammar-box
Без соединительного гласного причастие прошедшего времени (PPP) обычно образуется от корней, оканчивающихся на гласный, а также от многих других корней; при этом невозможно сформулировать чёткое правило о том, у каких именно корней соединительный гласный присутствует или отсутствует.

Список *aniṭ*-корней приведён у Киельгорна, «Грамматика», § 298.
:::
**Примеры:**

::: grammar-box
| Корень | PPP (kta) |
| :--- | :--- |
| **bhū** 1 P:br(⟪भू⟫) | **bhū-ta** :br(⟪भूत⟫) |
| **smṛ** 1 P:br(⟪स्मृ⟫) | **smṛ-ta** :br(⟪स्मृत⟫) |
| **nṛt** 4 P:br(nṛt-ta):br(⟪नृत्त⟫) | **nṛt-ta** :br(⟪नृत्त⟫) |
| **nī** 1 U:br(⟪नी⟫) | **nī-ta** :br(⟪नीत⟫) |
| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |
| **su** 5 U:br(⟪सु⟫) | **su-ta** :br(⟪सुत⟫) |
| **gam** 1 P:br(⟪गम्⟫) | **ga-ta** (\< \*gm-ta):br(⟪गत⟫) |
| **ji** 1 P:br(⟪जि⟫) | **ji-ta** :br(⟪जित⟫) |
| **śru** 5 P:br(⟪श्रु⟫) | **śru-ta** :br(⟪श्रुत⟫) |
| **kṛ** 8 U:br(⟪कृ⟫) | **kṛ-ta** :br(⟪कृत⟫) |
| **tan** 8 U:br(⟪तन्⟫) | **ta-ta** (\< \*tn-ta):br(⟪तत⟫) |
| **iṣ** 6 P:br(⟪इष्⟫) | **iṣ-ṭa** :br(⟪इष्ट⟫) |
:::
#### 12.3.1.2. С соединительным гласным -i- (seṭ)

*seṭ* = *sa-iṭ* = «с (*sa-*) суффиксом, перед которым стоит (*-i-*) *t*» (т.е. с соединительным гласным *i*).

**Примеры:**

::: grammar-box
| Корень | PPP (kta) |
| :--- | :--- |
| **kup** 4 P:br(⟪कुप्⟫) | **kup-i-ta** :br(⟪कुपित⟫) |
| **khād** 1 P:br(⟪खाद्⟫) | **khād-i-ta** :br(⟪खादित⟫) |
| **rakṣ** 1 P:br(⟪रक्ष्⟫) | **rakṣ-i-ta** :br(⟪रक्षित⟫) |
| **vad** 1 P:br(⟪वद्⟫) | **ud-i-ta** (\< \*vd-i-ta):br(⟪उदित⟫) |
:::

## 12.4. Законы сочетания звуков в слове

*aniṭ*-წარმოებებისას გასათვალისწინებელია სიტყვაში ბგერათშეერთების შემდეგი კანონები. **ეს კანონები ძალიან მნიშვნელოვანია სანსკრიტის მთელი ფორმათწარმოების გასაგებად.**

*aniṭ*-წარმოებებისას გასათვალისწინებელია სიტყვაში ბგერათშეერთების შემდეგი კანონები. **ეს კანონები ძალიან მნიშვნელოვანია სანსკრიტის მთელი ფორმათწარმოების გასაგებად.**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p ყრუ ხშულების წინ (მაგ. t, th) უცვლელი რჩება:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct იცვლება kt = ⟪क्त्⟫-ით:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt იცვლება ṣṭ = ⟪ष्ट्⟫-ით:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. მჟღერი არაასპირირებული ხშული – გარდა j-სა – ყრუ ბგერის წინ იცვლება შესაბამისი ყრუ არაასპირირებული ბგერით:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (მნიშვნელოვანია მე-2 აწმყოს კლასისთვის) |
| **5. jt იცვლება kt ან ṣṭ-ით (არაფაკულტატურია!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. მჟღერი ასპირირებული ხშული + ყრუ ხშული » მჟღერი არაასპირირებული ხშული + მჟღერი ასპირირებული ხშული (ბართოლომეს ასპირატების კანონი):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t იცვლება ḍh-ით წინა i-ს ან u-ს დაგრძელებით; ან gdh-ით. ასეთი ḍh-ის წინ a იცვლება o-თი, იშვიათად ā-თი:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „რამის დამალვა“):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.5. სიტყვების ლექსიკონი

**budh** 4 Ā (budhyate) / 1 U (bodhati), PPP **buddha** ⟪बुध् बुध्यते बोधति बुद्ध⟫ : გამოღვიძება, ცოდნისკენ გამოღვიძება; აღმოჩენა; PPP **buddha** 3 გამოღვიძებული, ამიტომ **Buddha** = "გამოღვიძებული" (არა: განათლებული)
