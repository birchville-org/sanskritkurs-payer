# გაკვეთილი 53

## 53.1. ორეული (⟪द्विवचन⟫ n.) სახელისა

::: grammar-box
**ორეული (⟪द्विवचनम्⟫) გამოიყენება „ორის“ მინიშნებისთვის:**

:::
::: indent
⟪अश्विनौ⟫ „ორივე აშვინი“
:::
**ორეულის გამოყენება აუცილებელია იქ, სადაც ორ ნივთს ეხება და ა.შ.:**

::: indent
⟪हस्तौ⟫ „ხელები (ერთი ინდივიდისა)“
⟪पादौ⟫ „ფეხები (ადამიანის, მაიმუნის ან სხვა ორფეხა ცხოველის)“
:::
**ზოგჯერ ორეული აღნიშნავს მამაკაცსა და ქალბატონს ერთივე კლასის (სახეობის, გვარის) წარმომადგენლებს:**

::: indent
⟪पितरौ⟫ „მამა და დედა = მშობლები“
:::
**სიტყვები, რომლებიც „წყვილს“ ნიშნავს — მაგ., ⟪युग⟫ n., ⟪द्वन्द्व⟫ n., ⟪द्वय⟫ n. — ყოველთვის ერთეულში გამოიყენება, გარდა იმ შემთხვევისა, როდესაც ორ ან მეტ წყვილზეა საუბარი:**

::: indent
⟪बाहुद्वयम्⟫ „წყვილი ხელები“
:::
