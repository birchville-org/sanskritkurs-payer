## 33.1. რედუპლიკაცია (⟪अभ्यास⟫ მ.რ.)

* მესამე პრეზენსის კლასი
* (ასევე სხვა პრეზენსის კლასების ზოგიერთი ზმნა),
* პერფექტი,
* რედუპლიცირებული აორისტი,

## 33.3. ā-ის აბლაუთზე

ā kann

* ერთი მხრივ, ის შეიძლება იყოს -a- შემცველი აბლაუთური რიგების გახანგრძლივებული ხარისხი
* მეორე მხრივ, ის შეიძლება იყოს მაღალი ხარისხი ā-ჯგუფის აბლაუთურ რიგში

ā-ჯგუფის ორი ყველაზე მნიშვნელოვანი აბლაუთური რიგია:

::: grammar-box
**A.**

* **დაბალი ხარისხი**
* **კონსონანტთან: -i-**  
მაგ. ⟪धा⟫ PPP: ⟪हित⟫ (hi-ta)
* **ვოკალთან: Ø**  
მაგ. ⟪धा⟫ 3ბ.მ.წვ.წარბ. ⟪दधति⟫ (dadh-ati)
* **მაღალი ხარისხი: -ā-**  
მაგ. ⟪धा⟫ 3პ.მ.წვ.წარბ. ⟪दधाति⟫
:::
Сюда же относится, например:

::: indent
⟪स्था⟫ 1
* ЧДП ⟪स्थित⟫ (sthi-ta)
* 3 л. ед.ч. Буд.вр. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**Б.**

* **Глубкая ступень: -ī-**  
напр. ⟪पा⟫ 1: ЧДП ⟪पीत⟫ (pī-ta)
* **Высокая ступень: -ā-**  
напр. ⟪पा⟫ 1: Инф. ⟪पातुम्⟫
:::
## 33.4. Корни на -ā третьего класса настоящего времени

::: grammar-box
**Корни на -ā (кроме ⟪दा⟫ и ⟪धा⟫) в слабой форме обычно оканчиваются на -ī-** (см. Thumb-Hauschild, т. 1, ч. 1, стр. 271. Вероятно, здесь образец послужила вышеупомянутая чередовательная серия Б, хотя эти корни в остальном чередуются по серии А), **перед гласными окончаниями корневой гласная полностью исчезает (см. чередовательную серию А).**
:::
Примеры:

::: grammar-box
⟪मा⟫ 3А "измерять"

| | 3 л. ед.ч. А. | 3 мн.ч. А. |
| :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Аорист** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Сослагательное наклонение** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3П "покидать"

| | 3 л. ед.ч. П. | 3 мн.ч. П. |
| :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Аорист** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Сослагательное наклонение** | ⟪जह्यात्⟫:brjah-yā-t:br(Корень ⟪हा⟫ перед Optativ-yā/y имеет ту же форму, что и перед гласными!) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. Корни ⟪दा⟫ и ⟪धा⟫

::: grammar-box
**Корни ⟪दा⟫ и ⟪धा⟫ редуплицируются с гласным -a- и теряют корневую гласную в слабой форме.**
:::
::: grammar-box
⟪धा⟫ 3U "setz, festsetz, zuerteile"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Präsens** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Explanation: Thumb-Hauschild 1,1 p. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Imperfekt** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Optativ** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::
The forms of ⟪दा⟫ are obtained by replacing **dh** with **d** in the paradigm of ⟪धा⟫. Thus:

::: grammar-box
⟪दा⟫ 3U "give"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Präsens** | ⟪ददाति⟫ | ⟪ददति⟫ | ⟪दत्ते⟫ | ⟪ददते⟫ |
| **Imperfekt** | ⟪अददात्⟫ | ⟪अददुर्⟫ | ⟪अदत्त⟫ | ⟪अददत⟫ |
| **Optativ** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
:::
## 33.5. The Present Participle Parasmaipada of the Roots of the 3rd Conjugation Class

::: grammar-box
**The verbs of the 3rd class form all forms of the Present Participle Parasmaipada from the weak stem.**

**Exception: Nominative/Accusative Plural Neuter can optionally be formed from the strong or weak stem.**

## 33.7. ვარჯიში

ა) ჩასვით შემდეგ წინადადების ნიმუშში ფრჩხილებში მოცემული სიტყვების შესაბამისი ფორმები:

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने बहुवचने च⟫) ... ⟪अन्नं ददाति ।⟫ (⟪भिक्षु । अग्नि । शूद्रा । गुनवान्पुत्र । देवान्स्तुवन्कवि । ब्राह्मणी । महान्साधु । धेनु⟫)

ბ) ჩასვით ფრჩხილებში მოცემული ზმნების შესაბამისი ფორმები ინდიკატივე პრეზენტი, იმპერფექტი და ოპტატივე:

⟪ब्राह्मणो घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥ बुद्धगता भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥ सुगतः कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥ दुर्जना भिक्षुभ्यो ऽन्नं न⟫ ... (⟪दा⟫) ⟪॥४॥ साधुः कृष्णे मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो लोकान्⟫ ... ⟪जनास्तु न⟫ ... (⟪मा⟫) ⟪॥६॥ दासा भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥ ब्राह्मणी पात्रं जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫

C) თარგმნეთ და გადაიყვანეთ ერთეული წინადადებები მრავლობითში და პირიქით:

⟪योगयुक्तो मतिं दुःखमक्षनयन्त्यां प्रज्ञायां समाधत्ते ॥१॥ यो भिक्षवे दानानि दद्यात्सो ऽपि दानपुण्यमाददीत ॥२॥ ब्राह्मणा भारं न बिभ्रतीति ब्राह्मणदासो भारं गृहमबिभः ॥३॥⟫
