# გაკვეთილი 27

## 27.1. ლოკატივის გამოყენება (⟪सप्तमी⟫ f. = "მეშვიდე კასუსის ბოლო")

::: grammar-box

**ლოკატივი (⟪सप्तमी⟫) პასუხობს შემდეგ კითხვებს:**
*   **სადაც?**
*   **როდის?**
*   **რა პირობებში?**
*   **რის მიმართ?**

:::
::: grammar-box

**1. ლოკატივი (⟪सप्तमी⟫) კითხვაზე "სადაც?" აღნიშნავს სივრცეს, სადაც (ან რომელშიც) აგენტი (⟪कर्ता⟫) ან მოქმედების ობიექტი მდებარეობს, ან სადაც თავად მოქმედება ხდება.**

> ⟪नगरे वसति⟫ = "ის ქალაქში ცხოვრობს"

:::

![](/images/lekt2701.webp)

:::

::: grammar-box

**2. ლოკატივი კითხვაზე "როდის?" აღნიშნავს დროს ან გარე პირობებს:**

> ⟪तस्मिन्काले⟫ = "მაშინდელ დროს, იმ პერიოდში"

**აქვე მიეკუთვნება ე.წ. ლოკატīvუს აბსოლუტუსი:**

**თუ ერთი პირის ან საგნის მოქმედება ან მდგომარეობა განსაზღვრავს დროს, რომლის დროსაც — ან პირობებს, რომელთა ქვეშაც — სხვა პირი ან საგნი ასრულებს მოქმედებას ან იმყოფება კონკრეტულ მდგომარეობაში, მაშინ პირველ პირს ან საგანს რომელიც აღნიშნავს სიტყვა, ერთად იმ სიტყვასთან რომელიც უფრო აკონკრეტებს (ხშირად ეს არის მე-5 ნაწილი), გადადის ლოკატივში (⟪सप्तमी⟫):**

> ⟪एवं गच्छति काले⟫ = "დროის მიმდინარეობისას..."
\>
> ⟪तस्मिन्गते⟫ = "როცა ის წავიდა..."

**ზოგჯერ აგენტი (⟪कर्ता⟫) ცალკე არ არის აღნიშნული:**

> ⟪एवं सति⟫ = "რადგან ასეა მდგომარეობა"

**ლოკატīvუს აბსოლუტუსი კონტექსტის მიხედვით უნდა ითარგმნოს როგორც "როდესაც" (მაგ. მე-5 ნაწილის დროებითი ფორმა), "შემდეგ", "როცა" (მაგ. PPP), "რადგან", "ვინაიდან", "მიუხედავად იმისა, რომ", "თუ" და ა.შ.**

**შენიშვნა: აბსოლუტივის შემთხვევაში, აბსოლუტივისა და მთავარი წინადადების აგენსი იგივე უნდა იყოს; ლოკატივის აბსოლუტუს შემთხვევაში კი ლოკატივის აბსოლუტისა და მთავარი ზმნის აგენსი სხვადასხვა უნდა იყოს.**

## 27.4. ერთი შლოკა ყველა დეკლინაციის ფორმით (ერთობლივი რიცხვ) ⟪राम⟫-ის შესახებ

::: media
![](/images/lekt2708.webp)
სურ.: ⟪रामे चित्तलयः सदा भवतु मे भो राम मामुद्धर ॥⟫
Rāma-Satz.
(სურათის წყარო: [დეტალები](/ka/licenses#lekt2708))
:::
:sig[⟪रामो⟫] ⟪राजमणिः सदा विजयते⟫ :sig[⟪रामं⟫] ⟪रमेशं भजे⟫:br :sig[⟪रामेणा⟫]⟪भिहता निशाचरचमू⟫ :sig[⟪रामाय⟫] ⟪तस्मै नमः ।⟫:br :sig[⟪रामान्ना⟫]⟪स्ति परायणम् परतरं⟫ :sig[⟪रामस्य⟫] ⟪दासोऽस्म्यहम्⟫:br :sig[⟪रामे⟫] ⟪चित्तलयः सदा भवतु मे भो⟫ :sig[⟪राम⟫] ⟪मामुद्धर ॥⟫

**თარგმანი:**
1. **ნომინატივი:** რამა, სამეფოთა შორის ჯვარი (⟪मणि⟫ მ.) ყოველთვის იგებს (⟪सदा⟫).
2. **აქუზატივი:** მე ვიყვარებ (⟪भज्⟫ 1U) რამას, მფარველსა და ქმარს (⟪ईश⟫ მ.) რამას (= ლაქშმის).
3. **ინსტრუმენტალი:** რამამ მოკლა ღამის მონადირეთა (დემონების) ლაშქარი (⟪चमू⟫ ფ. = ღამე) (⟪निशा⟫ ფ.).
4. **დატივი:** ამ რამას პატივისცემა!
5. **აბლატივი:** არ არსებობს რამასზე უკეთესი (⟪परतर⟫ 3) თავშესაფარი (⟪परायण⟫ ნ.).
6. **გენეტივი:** მე (⟪अहम्⟫) ვარ (⟪अस्मि⟫) რამას მონა.
7. **ლოკატივი:** რამასში ყოველთვის იყოს ჩემი გულის (⟪मे⟫) სიმშვიდე (⟪भवतु⟫ მ.).
8. **ვოკატივი:** რამა, გადარჩი (⟪उद्धर⟫ = იმპერატივი ⟪उद्⟫-დან + ⟪हृ⟫ ან उद्⟫ + ⟪धृ⟫) მე (⟪माम्⟫)!
