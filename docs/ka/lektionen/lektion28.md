# გაკვეთილი 28

## 28.1. კაუზატივი (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**როდესაც გვინდა გამოვსახოთ, რომ ვიღაც ან რაიმე იწვევს ან გამოიწვევს, რომ სხვა ვიღაცამ ან რაიმემ გააკეთოს ან განიცადოს ის, რაც გამოიხატება ფუძით (პრევერბის presence-ში ან absence-ში), მაშინ ვიყენებთ კაუზატივს (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫).**

მაგალითი:
⟪गम्⟫ "წასვლა" » კაუზატივი: ⟪गमयति⟫ "ის იწვევს, რომ ვიღაც წავიდეს; ის აგზავნის"
⟪दृश्⟫ "ხედვა" » კაუზატივი: ⟪दर्शयति⟫ "ის აკეთებს ხილვადს = ის აჩვენებს"
:::

## 28.2. წინადადების კონსტრუქცია კაუზატივთან (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**სქემა 1:**

**როდესაც კაუზატივის საფუძვლად მდგარი ფუძე (პრევერბის presence-ში ან absence-ში) არამოქმედია (ანუ მასთან ერთად აკუსატივის ობიექტი ვერ იქნება) ან გამოხატავს მოძრაობას, ცოდნას, ინფორმაციას ან ჭამას:**

**კაუზატივის აგენსი (⟪कर्ता⟫) ნომინატივში (⟪प्रथमा⟫) — იწვევადი ქმედების აგენსი აკუსატივში (⟪द्वितीया⟫) — (მოძრაობის მიზანი, ცოდნის ობიექტი და ა.შ. აკუსატივში = ⟪द्वितीया⟫) — ზმნა კაუზატივში**
:::
მაგალითები:

⟪दुर्जनो रामं मोहयति⟫ = "მავნე ადამიანი იწვევს, რომ რამა დაბნეულია = აბნევს რამას = იწვევს, რომ რამა შეცდება"
შედეგი: ⟪रामो मुह्यति⟫ = "რამა დაბნეულია / მოტყუებულია / შეცდება."

⟪रामः शत्रून्स्वर्गं गमयति⟫ = "რამა აიძულებს მტრებს ცას წავიდნენ = აგზავნის მტრებს ცაში"
შედეგი: ⟪शत्रवः स्वर्गं गच्छन्ति⟫ = "მტრები მიდიან ცას / მოდიან ცაში"

⟪गुरू रामं वेदार्थं वेदयति⟫ = "მასწავლებელი აიძულებს რამას ვედის მნიშვნელობა იცოდეს = ახსნის / ასწავლის რამას ვედის მნიშვნელობა"
შედეგი: ⟪रामो वेदार्थं वेत्ति⟫ = "რამა იცის / გესმის ვედის მნიშვნელობა"

⟪स रामं वेदमध्यापयति⟫ = "მას სწავლობს რამა ვედა"
შედეგი: ⟪रामो वेदमधीते⟫ "რამა სწავლობს ვედას"

⟪रामो देवानामृतमाशयति⟫ = "რამა აიძულებს ღმერთებს სიკვდილის საჭმელს მიირთვან = ღმერთებს სიკვდილის საჭმელს აწვდის" (⟪अश्⟫ 9 "მიირთმევა")
შედეგი: ⟪देवा अमृतमश्नन्ति⟫ "ღმერთები მიირთვამენ სიკვდილის საჭმელს"

**სქემა 2:**

**ტრანზიტული ზმნებისთვის (გარდა სქემა 1-ში მითითებულისა). ასევე ყველა ზმნისთვის, როდესაც კაუზატივით აღნიშნული მოქმედება იწვევა (როდესაც კაუზატივი არის კაუზატივის კაუზატივი):**

**აგენტი (⟪कर्ता⟫) კაუზატივის ნომინატში (⟪प्रथमा⟫) — გამოწვეული მოქმედების აგენტი ინსტრუმენტალით (⟪तृतीया⟫) — გამოწვეული მოქმედების ობიექტი იმავენაირ კასუსში, რაც მარტივ ზმნას ეკუთვნოდა (ანუ, ჩვეულებრივ, აქუსატივი) — ზმნა კაუზატივში**
:::
::: indent
მაგალითები:
(⟪स⟫) ⟪रामेण भार्यां त्याजयति⟫ = "ის აიძულებს რამას, დატოვოს თავისი ცოლი"
შედეგი: ⟪रामो भार्यां त्यजति⟫ = "რამა ტოვებს თავის ცოლს"

⟪विष्णुमित्रो रामेण गोविन्दं गमयति⟫ = "ვიშნუმიტრა აიძულებს რამას, ის გააგზავნოს გოვინდა = ვიშნუმიტრა აძლევს რამას საშუალებას, გაგზავნოს გოვინდა"
შედეგი: ⟪रामो गोविन्दं गमयति⟫ = "რამა აგზავნის გოვინდას"
ამ შედეგის შედეგი: ⟪गोविन्दो गच्छति⟫ = "გოვინდა მიდის"
:::

**განსხვავებები 1-ლი სქემიდან:**

**კაუზატივი:**
**⟪नी⟫ "წაყვანა"**
**⟪वह्⟫ "მგზავრობა" (მხოლოდ მაშინ, როცა გამოწვეული მოქმედების აგენტი მძღოლი არ არის)**
**⟪स्मृ⟫ "გახსენება" (ამასთან დაკავშირებით არის გამონაკლისები)**
**⟪अद्⟫ "ჭამა"**
**⟪खाद्⟫ "ჩაყლაპვა"**
:::
მაგალითები:

⟪रामो भृत्येन भारं नाययति वाहयति वा⟫ = "რამა მსახურს აიძულებს, დაატაროს ან წაიყვანოს ტვირთი"
შედეგი: ⟪भृत्यो भारं नयति वहति वा⟫ = "მსახური ატარებს ან წაიყვანს ტვირთს"

⟪रामो बालेनान्नमादयति खादयति वा⟫ = "რამა ბიჭს აიძულებს, ჭამოს ან ჩაყლაპოს საკვები"
შედეგი: ⟪बालो ऽन्नमत्ति खादति वा⟫ = "ბიჭი ჭამს ან ჩაყლაპავს საკვებს"

(⟪स⟫) ⟪रामेण स्मारयति⟫ = "ის იწვევს, რომ რამა გაიხსენოს"
შედეგი: ⟪रामः स्मरति⟫ = "რამა იხსენებს"

::: grammar-box
**ქვემოთ ჩამოყალიბებული კაუზატივები როგორც სქემა 1-ით, ისე სქემა 2-ით შეიძლება აგებული იყოს:**

**⟪हृ⟫ "შენახვა, მოყვანა"**
**⟪कृ⟫ "კეთება, გაკეთება"**
**Ātmanepadakausativ ⟪दृश्⟫-ის მიმართ**
:::
მაგალითები:

⟪रामो भृत्यं कटं कारयति हारयति वा⟫ = "რამა მონას კალათის (⟪कट⟩ m.) დამზადება ან მოყვანა უბრძანებს"
ან:
⟪रामो भृत्येन कटं कारयति हारयति वा⟫
შედეგი: ⟪भृत्यः कटं करोति हरति वा⟫ = "მონა კალათას ამზადებს ან მოჰყავს"

⟪रामो बालं प्रतिमां दर्शयते⟫ = "რამა ბიჭს სურათის ნახვა უბრძანებს = აჩვენებს ბიჭს სურათს (საკუთარი ინტერესებიდან გამომდინარე)"
ან:
⟪रामो बालेन प्रतिमां दर्शयते⟫
შედეგი: ⟪बालः प्रतिमां पश्यति⟫ = "ბიჭი სურათს ხედავს"

თუ კაუზატივი პასიურ კონსტრუქციაში გამოიყენება, თითქმის ყოველთვის შემდეგი სქემა გამოიყენება:

::: grammar-box
**სქემა A (პასიური კონსტრუქცია):**

**კაუზატივის აგენსი ინსტრუმენტალით (⟪तृतीया⟫) — გამოწვეული მოქმედების აგენსი ნომინატივით (⟪प्रथमा⟫) — გამოწვეული მოქმედების ობიექტი იმავე კასუსში, რაც მარტივ ზმნაზე (ანუ ჩვეულებრივ აკუსატივი) — ზმნა კაუზატივის ფორმაში**
:::
მაგალითები:

⟪गुरुणा रामो ग्रामं गम्यते⟫ = "მასტერი რამას სოფელში აგზავნის"
შედეგი: ⟪रामो ग्रामं गच्छति⟫ = "რამა სოფელში მიდის"

⟪रामेण भृत्यः कटं कार्यते⟫ = "რამა მონას კალათის დამზადება უბრძანებს"
შედეგი: ⟪भृत्यः कटं करोति⟫ = "მონა კალათას ამზადებს"

⟪रामेण भृत्यो भारं हार्यते⟫ = "რამა მონას ტვირთის მოყვანა უბრძანებს"
შედეგი: ⟪भृत्यो भारं हरति⟫ = "მონა ტვირთს მოჰყავს"


## 28.3. წარმოქმნა პრეზენდის ფუძის კაუზატივისთვის (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

:::

| ფუძე | კაუზატივი 3. პირი, ერთ. რიცხვ, მიმართებითი დრო, პრეზენდი | მნიშვნელობა |

| ⟪इ⟫ | ⟪आययति⟫:br(aus: ai-aya-ti) | გამოიწვიოს, რომ ვინმე წავიდეს |

**ბ. თარგმნეთ შემდეგი წინადადებები, დაშალეთ სანსკრიტში შედგენილი სახელები და გამოიყენეთ მარტივი ზმნები წინადადებების ასაგებად, რომლებიც გამოხატავს იმას, რაც ხდება, როცა კაუზატივით გამოხატული მოქმედება შესრულდება:**

მაგალითი: ⟪रामो दासं भारं हारयति⟫ » ⟪दासो भारं हरति शत्रुजयाय क्षत्रियो ब्राह्मणेन हरिहरं याजयित्वारीन्योत्स्यते ॥१॥ गुरुर्बालान्वेदमध्याप्य गृहं गतः ॥२॥ गर्भगृहे देवीप्रतिमा दृश्यते ॥३॥ यजन्नग्निनान्नमादयति पानं च पाययति ॥४॥ पुत्रे जाते ब्राह्मणी दासं ब्राह्मणं गमयति । ब्राह्मणस्तं दासं गृहं प्रवेश्य पुत्रं पृच्छति । सुभगः पुत्र इति दासो वक्ति । तच्छ्रुत्वा ब्राह्मणो सुखतां गच्छति ॥५॥ स्तुवता नरेण देवा महाकवेः स्तोत्राणि श्राविताः ॥६॥ आर्ययोधैर्महायुद्धे ऽरयो मार्यन्ते ॥७॥ सत्क्षत्रिया ब्राह्मणेनेष्टदेवतापूजां कारयति । स ब्राह्मणः पूजां कृत्वा क्षत्रियाया धनमेषिष्यति ॥८॥ धनं जेतुं महाक्षत्रियो योधव्याघ्रैर्व्रतानि चारयिष्यति ॥९॥ पापान्मोक्षार्थेन सुगत आर्यजनानार्यसत्यानि बोधयति ॥१०॥⟫
