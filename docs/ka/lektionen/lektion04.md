# გაკვეთილი 4

## 4.1. მარტივი დამატებითი კითხვები (სიტყვაკითხვები) და პასუხები

### 4.1.1. კითხვისა და მიუთარებელი სახელები

#### 4.1.1.1. კითხვის სახელები (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | ნომინატი ერთეული რიცხვი | ნომინატი მრავლობითი რიცხვი |
| :--- | :--- | :--- |
| **ნეიტრალური** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **მამრობითი** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **მდედრობითი** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. მიუთარებელი სახელები (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **ფუძეები** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"ის, ისინი, იგი; ის, ისინი, იგი":br(მოხსენიებული)** | **etad = ⟪एतद्⟫:br"ეს, ესე, ეს":br(მეტად ახლოს მყოფისთვის)** | **idam = ⟪इदम्⟫:br"ეს, ესე, ეს":br(ახლოს მყოფისთვის)** |

| **მამრობითი** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |

**ნომ. ერთეული მამრობითის შესახებ:**
**sa, eṣa** (⟪स एष⟫) გამოიყენება ყველა ხმოვანთან, გარდა მოკლე **-a**-სი
**so, eṣo** (⟪सो एषो⟫) გამოიყენება **-a**-სთან, რომელიც ავაგრახას საშუალებით ელიდირდება (იკარგება)
**saḥ, eṣaḥ** (⟪सः एषः⟫) გამოიყენება მხოლოდ პაუზაში (წინადალების ბოლოს, ლექსის ბოლოში)

Чтобы можно было образовывать предложения с этими местоимениями (sarvanāman n.), необходимо знание следующих правил сандхи:

### 4.1.2. Sandhi von auslautendem -m

::: grammar-box
**Окончательное -m перед согласными заменяется на анусвāру (-ṃ). В конце предложения или стиха, а также перед гласными -m сохраняется.**
:::
### 4.1.3. Sandhi von auslautendem -e

::: grammar-box
1. **перед a- окончание -e остается неизменным: начальное a- элидируется с помощью авagraхи:**
z.B. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Diese Feuer"

2. **Перед другими гласными, кроме краткого a-, окончание -e обычно заменяется на -a с образованием хиазуса. Также встречается замена на -ay:**
z.B. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (selten: imay īśvarāh = ⟪इमयीश्वराः⟫) "Diese HERREN"
:::
### 4.1.4. Sandhi von auslautendem -d

::: grammar-box
**Окончательное -d в паузе, а также перед глухими кавальными (k, kh) и губными (p, ph) согласными заменяется на -t.**

Замена перед другими согласными будет рассмотрена позже. Временно избегайте таких сочетаний звуков!
:::
### 4.1.5. Frageformeln

С помощью этих местоимений образуются, например, следующие вопросительные формулы:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |

სხვა კითხვების მაგალითი:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ პასუხი: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (აქ ნომინალურ წინადადებაში საგნის დასაწყისში გადატანა შესაძლებელია, რათა კითხვასთან დაკავშირება ხაზგასმული იყოს.)

შენიშვნა: პასუხები, რომლებსაც თქვენი ამჟამინდელი სანსკრიტის ცოდნით ასეთ კითხვებზე გაეცემათ, ბუნებრივია, ჯერ არ შეესაბამება ყველა თვალსაზრისით იდიომატურად კარგ სანსკრიტს.


## 4.2. ვარჯიში
