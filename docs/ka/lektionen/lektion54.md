# ლექსიონი 54

## 54.1. წინასწარი შენიშვნა

ლექსიონი 54-ით უნივერსიტეტში მეორე სემესტრი იწყება. ახალიდან კურსი მხოლოდ ამ სემესტრის ძირითად თემაზე გვერდით მიმდინარეობს: ბჰაგავად-გიტას მთლიანად წაკითხვაზე. სწავლის მიზანია საშუალო სირთულის ტექსტის წაკითხვაში ისეთი უნარიანობა, რომ სემესტრის ბოლო მესამედში ბჰაგავად-გიტას დიდი ნაწილები თავისუფლად ითარგმნოს. საწყის ეტაპზე უნივერსიტეტში სიტყვების სიები ვრცელდებოდა, მოგვიანებით სტუდენტებს უნდა გამოეყენებინათ შესაბამისი ლექსიკონები (Monier-Williams, Apte, PW).

ბჰაგავად-გიტას კურსი დროებით ონლაინ ხელმისაწვდომად არ იქნება.

სანსკრიტის კურსის ლექსიონები ეხება სანსკრიტის გრამატიკის თემებს, რომლებიც ჯერ არ განხილულა.

## 54.5. აორისტის წარმოების ტიპები (⟪लुङ्⟫) (Kielhorn)

::: grammar-box
**აორისტის (⟪लुङ्⟫) ყველა ფორმას საერთო აქვს აუგმენტი a-, რომელიც იმავე წესებით ერთვის, როგორც იმპერფექტში (⟪लङ्⟫) (Kielhorn).**

აორისტისგან სანსკრიტში მხოლოდ ინდიკატივი და პრეკატივი გამოიყენება (Kielhorn).
:::
::: grammar-box
**არსებობს აორისტის წარმოქმნის შემდეგი ტიპები (Kielhorn):**

1. არასიბილანტური აორისტები:
* 54.1. ფესვის აორისტი: აუგმენტი + ფესვი + მეორეული დაბოლოება
* 54.2. თემატური აორისტი: აუგმენტი + ფესვი + **a** + მეორეული დაბოლოება
* 54.3. რედუპლიცირებული აორისტი: აუგმენტი + რედუპლიცირებული ფესვი + **a** + მეორეული დაბოლოება
2. სიბილანტური აორისტები:
* 54.4. -s-აორისტი: აუგმენტი + ფესვი + **s** + მეორეული დაბოლოება
* 54.5. -iṣ-აორისტი: აუგმენტი + ფესვი + **i** + **ṣ** + მეორეული დაბოლოება
* 54.6. -siṣ-აორისტი: აუგმენტი + ფესვი + **siṣ** + მეორეული დაბოლოება
* 54.7. -sa-აორისტი: აუგმენტი + ფესვი + **s** + **a** + მეორეული დაბოლოება
:::
