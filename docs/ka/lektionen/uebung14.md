# ვარჯიში 14

გადათარგმნეთ შემდეგი ზაფხულის სიტყვები და შეისწავლეთ ისინი:

⟪निचो वदति न कुरुते वदति न साधुः करोत्येव ॥१॥⟫  
დაბალი ადამიანი არ საუბრობს და არ მოქმედებს, კარგი ადამიანი არ საუბრობს, არამედ მოქმედებს.

⟪शीलं नरस्य भूषणम् ॥२॥⟫  
> კეთილშობილება ადამიანის მორთვაა.

⟪सत्येन जनानां सुखं भवति ॥३॥⟫  
სიმართლით ადამიანებს ბედნიერება მოაქვთ.

⟪पापा नराः स्वर्गं न लभन्ते ॥४॥⟫  
ბოროტი ადამიანები ცას არ მიდიან.

⟪सत्यं लोकस्य दीपः ॥५॥⟫  
სიმართლე სამყაროს შუქია.

ა) შეადგინეთ გენეტივის ერთეული და მრავლობა შემდეგი სიტყვებისთვის. მიუთითეთ სიტყვის მნიშვნელობა და გენდერი:

⟪१⟫. ⟪अनृत⟫ : n. არასიმართლე — ⟪अनृतस्य अनृतानाम् २⟫. ⟪ऋषि⟫ : m. ვედური მოქალაქე — ⟪ऋषेः ऋषीणाम् ३⟫. ⟪पाद⟫ : m. ფეხი — ⟪पादस्य पादानाम् ४⟫. ⟪बुद्धि⟫ : f. ცოდნა — ⟪बुद्धेः⟫ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम् ५⟫. ⟪गुरु⟫ : m. მასწავლებელი — ⟪गुरोः गुरूणाम् ६⟫. ⟪स्वर्ग⟫ : m. ცა — ⟪स्वर्गस्य स्वर्गाणाम् ७⟫. ⟪नगर⟫ : n. ქალაქი — ⟪नगरस्य नगराणाम् ८⟫. ⟪धेनु⟫ : f. ძროხა — ⟪धेनोः⟫ (⟪धेन्वाः⟫) ⟪धेनूनाम् ९⟫. ⟪द्विज⟫ : m. ორჯერ დაბადებული — ⟪द्विजस्य द्विजानाम् १०⟫. ⟪मुक्ता⟫ : f. გადარჩენილი — ⟪मुक्तायाः मुक्तानाम् ११⟫. ⟪विद्या⟫ : f. ცოდნა, მეცნიერება — ⟪विद्यायाः विद्यानाम् १२⟫. ⟪वर्ण⟫ : m. კლასი — ⟪वर्णस्य वर्णानाम् १३⟫. ⟪द्विजाति⟫ : 3 ორჯერ დაბადებული — ⟪द्विजातेः⟫ (⟪द्विजात्याः⟫) ⟪द्विजातीनाम् १४⟫. ⟪रूप⟫ : n. ფორმა — ⟪रूपस्य रूपाणाम् १५⟫. ⟪प्रतिग्रह⟫ : m. მიღება — ⟪प्रतिग्रहस्य प्रतिग्रहाणाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 ertragen — ⟪सोढस्य⟫ ⟪सोढायाः⟫ ⟪सोढानाम्⟫

⟪१७⟫. ⟪नायिका⟫ : f. Geliebte — ⟪नायिकायाः⟫ ⟪नयिकानाम्⟫

⟪१८⟫. ⟪साध्वी⟫ : f. Heilige — ⟪साध्व्याः⟫ ⟪साध्वीनाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 ტანჯვა — ⟪सोढस्य सोढायाः सोढानाम् १७⟫. ⟪नायिका⟫ : f. საყვარელი — ⟪नायिकायाः नयिकानाम् १८⟫. ⟪साध्वी⟫ : f. წმინდანები — ⟪साध्व्याः साध्वीनाम् १९⟫. ⟪अग्नि⟫ : m. ცეცხლი — ⟪अग्नेः अग्नीनाम् २०⟫. ⟪वैश्या⟫ : f. ვაიშის ქალი — ⟪वैश्यायाः वैश्यानाम् २१⟫. ⟪लोक⟫ : m. მსოფლიო, ხალხი — ⟪लोकस्य लोकानाम् २२⟫. ⟪उक्ति⟫ : f. განცხადება — ⟪उक्तेः⟫ (⟪उक्त्याः⟫) ⟪उक्तीनाम् २३⟫. ⟪शत्रु⟫ : m. მტერი — ⟪शत्रोः शत्रूणाम् २४⟫. ⟪सुखवन्त्⟫ : 3 ბედნიერი — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : f. ქალი ერთი ან რამდენიმე შვილით — ⟪पुत्रवत्याः पुत्रवतीनाम् २६⟫. ⟪जल⟫ : n. წყალი — ⟪जलस्य जलानाम् २७⟫. ⟪मार्ग⟫ : m. გზა — ⟪मर्गस्य मर्गाणाम् २८⟫. ⟪मोक्ष⟫ : m. განთავისუფლება, გადარჩენა — ⟪मोक्षस्य मोक्षाणाम् २९⟫. ⟪शूद्रा⟫ : f. შუდრას ქალი — ⟪शूद्रायाः शूद्राणाम् ३०⟫. ⟪अन्न⟫ : n. საკვები, ჭამა — ⟪अन्नस्य अन्नानाम् ३१⟫. ⟪साधु⟫ : m. წმინდანები — ⟪साधोः साधनाम् ३२⟫. ⟪नीति⟫ : f. ხელმძღვანელობა — ⟪नीत्याः नीतीनाम् ३३⟫. ⟪योध⟫ : m. მეომარი, ჯარისკაცი — ⟪योधस्य योधानाम् ३४⟫. ⟪सत्यवन्त्⟫ : 3 სიმართლე — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : m. მოგება — ⟪लाभस्य लाभानाम् ३६⟫. ⟪मोह⟫ : m. აღრევა, მოტყუება — ⟪मोहस्य मोहानाम् ३७⟫. ⟪गति⟫ : f. სვლა, მიზანი — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम् ३८⟫. ⟪प्रश्न⟫ : m. კითხვა — ⟪प्रश्नस्य प्रश्नानाम् ३९⟫. ⟪सृष्टि⟫ : f. შექმნა — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम् ४०⟫. ⟪नेत्र⟫ : n. თვალი — ⟪नेत्रस्य नेत्राणाम् ४१⟫. ⟪गुरुता⟫ : f. ოსტატობა — ⟪गुरुतायाः गुरुतानाम्⟫

⟪४६⟫. ⟪युद्ध⟫ : 3 იბრძვის — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम् ४७⟫. ⟪दर्शन⟫ : n. ხედვა, გამოცხადება — ⟪दर्शनस्य दर्शनानाम् ४८⟫. ⟪धातु⟫ : m. ელემენტი, ზმნის ფუძე — ⟪धातोः धातूनाम् ४९⟫. ⟪गूढा⟫ : f. დამალული — ⟪गूढायाः गूढानाम् ५०⟫. ⟪ईष्टा⟫ (2 მნიშვნელობა): f. სასურველი, შეწირული — ⟪इष्टायाः इष्टानाम् ५१⟫. ⟪उदित⟫ : 3 ნათქვამია — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम् ५२⟫. ⟪इदम्⟫ : 3 ეს — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 რა — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) თარგმნეთ:

⟪१⟫. ⟪ब्राह्मणस्य पुत्रो ब्राह्मण्या ग्रामं गतः ।⟫ (2 ვარიანტი)
ბრაჰმანის ძე ბრაჰმანის სოფელში წავიდა. ბრაჰმანის ძე ბრაჰმანთან ერთად სოფელში წავიდა.

⟪२⟫. ⟪यज्ञस्याग्निनान्नं दग्धम् ।⟫
საკურთხელის ცეცხლმა ჭამა დაწვა.

⟪३⟫. ⟪बुद्धः स्तयस्य बुद्ध्या मुक्तः ।⟫
ბუდამ სიმართლის ცოდნით გათავისუფლება მოიპოვა.

⟪४⟫. ⟪अधर्मो ऽनृतस्य वदनमित्यृषयो वदन्ति ।⟫
ვედური მეცნიერები ამბობენ, რომ მცდარი საუბარი არასწორია.

⟪५⟫. ⟪नरा देवानां यज्ञैर्न मुच्यन्ते ।⟫
ადამიანები ღმერთებისთვის შეწირვით არ გათავისუფლდებიან.

⟪६⟫. ⟪बलवन्तः क्षत्रियाः शत्रूणां धनवन्ति नगराणि जयन्ति ।⟫
ძლიერი კშატრიები იპყრობენ მტრების მდიდარ ქალაქებს.

⟪७⟫. ⟪कवेरुक्तिं शृण्वन्ति ।⟫
ისმენთ პოეტის სიტყვას.

⟪८⟫. ⟪कविर्देव्याः कृतं वद⟫ti ⟪।⟫
პოეტი მოგვითხრობს ღმერთის საქციელზე.

⟪९⟫. ⟪द्विजाः पशोर्लाभमिच्छन्ति ।⟫
ორჯერ დაბადებულები გვინდა, რძის მსხვერპლი შეეწირათ.

⟪१०⟫. ⟪रामः पुण्यवतो गुरोर्मन्त्रस्य स्मरति ।⟫
რამა იხსენებს კეთილშობილი მასწავლებლის მანტრას.

⟪११⟫. ⟪अयं बालः कस्याः पुत्रः ।⟫
ვისი (f.) შვილია ეს ბავშვი?

⟪१२⟫. ⟪केषामिमानि गृहाणि ।⟫
ვის ეკუთვნის ეს სახლები?

⟪७⟫. ⟪कवेरुक्तिं शृण्वन्ति ।⟫
ისმენთ პოეტის სიტყვას.

⟪८⟫. ⟪कविर्देव्याः कृतं वद⟫ti ⟪।⟫
პოეტი მოგვითხრობს ღმერთის საქციელზე.

⟪९⟫. ⟪द्विजाः पशोर्लाभमिच्छन्ति ।⟫
ორჯერ დაბადებულები გვინდა, რძის მსხვერპლი შეეწირათ.

⟪१०⟫. ⟪रामः पुण्यवतो गुरोर्मन्त्रस्य स्मरति ।⟫
რამა იხსენებს კეთილშობილი მასწავლებლის მანტრას.

⟪११⟫. ⟪अयं बालः कस्याः पुत्रः ।⟫
ვისი (f.) შვილია ეს ბავშვი?

⟪१२⟫. ⟪केषामिमानि गृहाणि ।⟫
ვის ეკუთვნის ეს სახლები?

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम् ।⟫
ვისი საკვები შეეწირა ეს ვედური მოძღვარი?
