# გაკვეთილი 22

## 22.1. აბსოლუტივი (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

თუ სანსკრიტში გვინდა გამოვხატოთ, რომ აგენტის (⟪कर्तृ⟫) ერთი მოქმედება მეორე აგენტის (⟪कर्तृ⟫) მოქმედებას უძღვის ან თან ახლავს როგორც მომხდარე გარემოება, ვიყენებთ აბსოლუტივს (⟪क्त्वा । ल्यप्⟫). ანუ

"როცა მან ეს გააკეთა, ის იმას აკეთებს"; "ის ამას აკეთებს, შემდეგ იმას აკეთებს"; "ამის შედეგად ის იმას აკეთებს"; "მე მოვედი, ვნახე და დავამარცხე" და ა.შ.

აბსოლუტივი არის ვერბალური ადვერბი, ანუ ის არ იცვლება არა კონjugაციით, არა დეკლინაციით; მაგრამ ის ყოველთვის — რამდენიმე გამონაკლისის გარდა — იგივე აგენტს (⟪कर्तृ⟫) ეკუთვნის, რაც იმ მოქმედებას, რომელსაც აბსოლუტივით აღნიშნული მოქმედება უძღვის ან თან ახლავს. ამიტომ, აბსოლუტივის აგენტი ნომინატივში (⟪प्रथमा⟫) ან ინსტრუმენტაში (⟪तृतीया⟫) დგას.

კომპოზიტების გარდა, აბსოლუტივი სანსკრიტში ერთ-ერთი ყველაზე გავრცელებული გამოსახვის საშუალებაა.

გერმანულად თარგმნისას თავიდან აცილეთ "როცა" სიტყვის მუდმივად გამოყენება. ამის ნაცვლად, იხმარეთ გერმანულში დროითი თანმიმდევრობის ჩვეულებრივი გამოსახვის საშუალებები.

**სქემა:**

(აბსოლუტივის უფრო ზუსტი განმარტება: გარემოებრივი განსაზღვრა, ობიექტი და ა.შ.) - აბსოლუტივი - აბსოლუტივი - ... - აბსოლუტივი - ... აგენტი + ვერბალური წინადადება (აქტიურ ან პასიურ ფორმაში)

:::
**მაგალითები:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = პასიური კონსტრუქცია: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**  
"კაცი შედის სახლში, ხედავს პატარა გოგონას და ესაუბრება მას."

ბევრი რიცხვი: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. აბსოლუტივის წარმოება

::: grammar-box
**აბსოლუტივის წარმოება**

*   პრეფიქსის გარეშე: აბსოლუტივი **-tvā**-ზე
*   პრეფიქსით: აბსოლუტივი **-ya** ან **-tya**-ზე
:::
### 22.2.1. პრეფიქსის გარეშე: აბსოლუტივი -⟪त्वा⟫-ზე

::: grammar-box

**წარმოება:**

(უმეტესად) ღრმა ფორმის ფუძე იმ სახით, რაც მას PPP-ს წინ აქვს + **-tvā** (**-⟪त्वा⟫**)

მხოლოდ უარყოფითი **a-** / **an-** თავსებადია **-⟪त्वा⟫** ზმნაწარმოებთან: ⟪अकृत्वा⟫ "გამოუტანებლად"

:::
**მაგალითები:**

::: indent
⟪आप्त्वा⟫ "როცა მან / შენ / ის / ჩვენ / თქვენ / მე / ნებადამილი / ორივემ / ორნივმა მიიღწია"

⟪आसित्वा⟫ "როცა მან (...) იჯდა / ზის"

⟪इत्वा⟫ "როცა მან (...) წავიდა / მიდის"

⟪स्थित्वा⟫ "როცა მან (...) დგას / იდგა"

⟪जित्वा⟫ "როცა მან (...) გაიმარჯვა / იმარჯვებს"

⟪उक्त्वा⟫ "როცა მან (...) თქვა / ლაპარაკობს"
:::

:::
#### 22.2.2.3. ფუძეები, რომლებიც ღრმა ფორმით მოკლე -i, -u, -ṛ-ზე დამთავრდება

::: grammar-box

**ღრმა ფორმის ფუძე + -tya**

:::
**მაგალითები:**

::: indent
⟪प्रस्तुत्य⟫ "როცა (...) ზეიმით აქებდა / აღიარებდა"

⟪विस्मृत्य⟫ "როცა (...) დაივიწყა / იყო დასუსტებული"

⟪संस्कृत्य⟫ "როცა (...) მსხვერპლისთვის მოამზადა / იყო მომზადებული"
:::
#### 22.2.2.4. ფუძეები -am / -an-ით, რომლებიც ღრმა ფორმისას -a-ზე მთავრდება

::: grammar-box

**B) თარგმნეთ და გახსენით კომპოზიტები სანსკრიტულად:**

⟪अन्नं पक्त्वा ब्राह्मणदासो ऽत्ति ॥१॥ इष्टदेवतापूजां कृत्वेन्द्रादिदेवान्सद्ब्राह्मणाः स्तुवन्ति ॥२॥ प्रस्थाय रामः सपुत्रः सद्गुरुश्रवणार्थेन ब्राह्मणग्रामं गच्छति ॥३॥ अनिष्ट्वा नरो भगवद्भक्तिमात्रेणापि मोक्षमाप्नोति ॥४॥ गृहगर्भं प्रविश्य ब्राह्मणपुत्रमुपस्थाय क्षत्रियशूरो वक्ति ॥५॥ सम्बुध्य दुःखाद्यार्यसत्यानि प्रोच्य सुगतो मोक्षमार्गेण नरान्नयति ॥६॥ मन्त्रं विस्मृत्य यजन्यज्ञदोषं करोति ॥७॥ धनं प्राप्य बुद्धमार्गभिक्षवो दुष्यन्ति ॥८॥ अनार्यशत्रुभिः संगत्य नरसिंहा विजयन्ते ॥९॥ पुण्यं कृत्वा सत्यमेवोदित्वा नरो नरकं नोपपद्यते ॥१०॥⟫

**C) ზემოთ მოცემული წინადადებებიდან (გარდა 8 და 10-ე წინადადებებისა) შექმენით პასიური კონსტრუქციები**
