## 7.1. ზმნის წინადადება პირდაპირი დამატებით

::: grammar-box
**სქემა:**
**(აგენს = kartṛ m. = ⟪कर्तृ⟫) – პირდაპირი დამატება (karman n. = ⟪कर्मन्⟫) – ზმნა**

მაგალითად
**rāmaḥ phalaṃ khādati** = ⟪रामः फलं खादति⟫ : „რამა ჭამს (კარგავს) ხილს.“
**brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो देवं यजति⟫ : „ბრაჰმანადი ღმერთს ემსხვერპლება (საიდუმლოებით სავსე).“
:::
თუ ზმნა პარასმაიპადას ან Ātmanepadas-შია, მაშინ პირდაპირი დამატება (**karman** n. = ⟪कर्मन्⟫) ზოგადად **აკუზატივში** (მეორე კასუსი, dvitīyā f. = ⟪द्वितीया⟫)ა.

ფორმები **enam** (⟪एनम्⟫) და ა.შ. ეკუთვნის ფუძეს **enad** (⟪एनद्⟫), რომელიც ქმნის ფორმებს მხოლოდ ზოგიერთ კასუსში. ეს ფორმები **etad**-ისა და **idam**-ის ნაცვლად გამოიყენება მაშინ, როდესაც მითითებული ობიექტი წინა ტექსტში უკვე იყო ნახსენები.
მაგ., **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं देवः⟫ | ⟪एनं यजन्ते⟫ || : "ის ღმერთია. მას შესწირავენ ანუ სალოცავად იყენებენ."


### 7.2.2. აკუზატივის გამოყენება (მეორე კასუსი, dvitīyā f. = ⟪द्वितीया⟫ = "მეორე კასუსის დამატება")

::: grammar-box
აკუზატივი (dvitīyā f. = ⟪द्वितीया⟫) აღნიშნავს:
1. არა-პასიურ ვერბალურ წინადადებაში: **უშუალოდ ობიექტს** (karman n. = ⟪कर्मन्⟫), რომელიც გამოიხატება ზმნით:
მაგ.,
**devaṃ yajati** = ⟪देवं यजति⟫ : "ის ღმერთს შესწირავს ანუ სალოცავად იყენებს."
**phalam āpnoti** = ⟪फलमाप्नोति⟫ : "ის იღებს ნაყოფს (მაგ., თავისი ქმედების)."
2. იმ ზმნებთან, რომლებიც გამოხატავენ სვლას, მოძრაობას, მიმართვას ან მსგავს რაღაცას某个方向, აკუზატივი აღნიშნავს მოძრაობის მიზანს:
მაგ.,
**narakaṃ gacchati** = ⟪नरकं गच्छति⟫ : "ის მიდის ჯოჯოხეთში."
:::
აკუზატივის სხვა გამოყენებები მოგვიანებით განიხილება.



## 7.3. საბოლოო -n-ის სანდჰი

::: grammar-box
**საბოლოო -n:**

1. ზმნის ბოლოს მდებარე -n-ი შეიცვლება შესაბამის ნასალად, თუ ის მოჰყვა ზმნის ბოლოს მდებარე palatal და retroflex sparśa-ს, ასევე **ś-** ზმნის ბოლოს:
**-n** **j-, jh-, ñ-, ś-** წინ » **-ñ**
**-n** **ḍ-, ḍh-, ṇ-, ṣ-** წინ » **-ṇ**
მაგ., **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "ის იგებს კშატრიებს."
საწყისი **ś-** ხშირად შეიცვლება **ch**-თი:
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (გურუინ შრუნოტი-ს გვერდით) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "ის კითხულობს მასწავლებლებს." "ის მოუსმენს მასწავლებლებს."

2. თუ წინადადების დასაწყისში **l-** ხმოვანთან ერთად გამოიყენება, **-l** -ით იცვლება ანუნასიკას (ნაზალირებული l, წერტილოვანში ⟪ल्⟫ ანუნასიკით ⟪ँ⟫) მიმაგრებით:
მაგალითად, **paśūn + labhate** » ⟪पशूंल्लभते⟫ : "მას ღორებს იღებს."

3. თუ წინადადების დასაწყისში უხმო პალატური, რეტროფლექსული ან დენტალური ხმოვანთან ერთად გამოიყენება, **Anusvāra** + ამ ხმოვანთან შესაბამისი ზღუდრით იცვლება:
**-n** **c-, ch-** წინ » **-ṃś**
**-n** **ṭ-, ṭh-** წინ » **-ṃṣ**
**-n** **t-, th-** წინ » **-ṃs**
მაგალითად, **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : "და ღმერთები (აკუს.)"
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : "მაგრამ ღმერთები (აკუს.)"

4. მოკლე ხმოვანის შემდეგ (იხ. შემდგომში) გარდა, ყველა სხვა შემთხვევაში ბოლო **-n** უცვლელი რჩება.
:::

## 7.5. ათემატური პრეზენტის კლასები

5-ე პრეზენტის კლასი ქმნის ასეთ ათემატურ პრეზენტის ფუძეს, ანუ პრეზენტის ფუძე არ გამოიყენება თემური პრეზენტის კლასებში (1., 4., 6., 10-ე კლასი) "თემის ხმოვანით" **-a** ბოლოში.

::: grammar-box
**ათემატური პრეზენტის კლასები აქვთ ფუძის ცვალებადობა, ანუ არსებობს ორი ფორმა პრეზენტის ფუძის:**
1. **მძლავრი ფუძე**: მაღალი დონის (შორიდან გახანგრძლივებული)
2. **სუსტი ფუძე**: დაბალი დონის

**ძლიერი ფუძე დგას:**
ინდიკატივის ერთეულში პარასმაიპადის ახლა დროს (laṭ) და იმფერექტში (laṅ)
იმპერატივის ყველა პირველი პირისთვის (loṭ) პარასმაიპადასა და Ātmanepada-ს
იმპერატივის მესამე პირის ერთეულში (loṭ) პარასმაიპადას

**ყველა სხვა ფორმას აქვს სუსტი ახლა დროის ფუძე.**
:::
