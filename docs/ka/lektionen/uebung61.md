# ვარჯიში 61

ლექცია 61 წარმოადგენს სანსკრიტის კურსის დასასრულს და არ შეიცავს სხვა დამატებით წერილობით ვარჯიშებს. 

ფესვური სახელების, პერიფრაზული მომავალი დროისა და ზედსართავი სახელების შესწავლით ჩამოყალიბდა სანსკრიტის ორიგინალური ტექსტების წაკითხვის საფუძველი. კურსი მთავრდება ტრადიციული ანუკითხვით განეშას მიმართ (⟪श्रीगणनाथ⟫), რაც აღნიშნავს გადასვლას სახელმძღვანელოდან დამოუკიდებელ წაკითხვაზე.
