# გაკვეთილი 57

## 57.1. აორისტი 4: s-აორისტი

::: grammar-box
**s-აორისტი ყალიბდება უმეტეს ⟪अनिट्⟫-ფუძეებზე, თუ მათ არ გააჩნიათ exclusively სხვა აორისტული ფორმა. პარალელური ⟪अनिट्⟫-ფუძეები, როგორც წესი, შეუძლიათ აირჩიონ ეს ფორმა ან iṣ-აორისტი. ასევე, ⟪अनिट्⟫-ფუძეები, რომლებიც ყალიბდება ⟪परस्मैपद⟩-ს 1.,2. ან 6. ფორმის შემდეგ, ყალიბდება ⟪आत्मनेपद⟩ s-აორისტის მიხედვით.**

**ყალიბდება: აუგმენტი + ფუძე + s + თემური მეორადი დანართი**
:::
დანართების ცხრილი სტამბილური საფუძვლის სიგნალით

::: grammar-box

|   | ⟪परस्मैपदम्⟩ || ⟪आत्मनेपदम्⟩ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟩ | ⟪बहुवचनम्⟩ | ⟪एकवचनम्⟩ | ⟪बहुवचनम्⟩ |
| **1. ⟪तृतीयः⟩** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟩** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟩** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**გამოიყენება ზოგადი ფონეტიკური კანონი, რომლის მიხედვითაც ზისმოს ხმოვანი ორ ბგერას შორის ქრება (შედ. ⟪उद्⟩ + ⟪स्थित⟩ » ⟪उत्थित⟩), ანუ სტამბილური საფუძვლის -s- წინადადება, რომელიც იწყება -t- ან -th- ზე, ქრება (არა კი ნასალის ან r- შემდეგ).**

მაგალითები:

:::
::: indent
3.პ.ა. a-kṣip + s + ta » ⟪अ⟩:sig[⟪क्षिप्त⟩]
2.პ.ა. a-kṣip + s + thās » ⟪अ⟩:sig[⟪क्षिप्था⟩]⟪स्⟩
:::
ასეთი ფორმები შეიძლება ეკუთვნოდეს ფუძე-აორისტსაც და, სავარაუდოა, ნაწილობრივ მართლაც ეკუთვნის.
ინდური გრამატიკოსებმა ასევე მიიჩნიეს ⟪अकृत⟩ (3.პ.ა.) ფორმები s-აორისტს, რომლებიც ერთგვაროვნად ეკუთვნის ფუძე-აორისტს. ამ მიზნით, ინდურმა გრამატიკოსებმა შემოქმედებითი ხასიათის ფონეტიკური წესი შეიმუშავეს s-აორისტისთვის:

::: indent
«მოკლე ხმოვნის შემდეგ დაბოლოებები, რომლებიც იწყება -st- ან -sth--ით, კარგავენ -s--ს» (Kielhorn).
:::
Andernfalls sind die Lautregeln für die Verbindung auslautender Konsonanten mit s- zu beachten.

Für -dhvam gilt:

::: grammar-box
**-dhvam-ის -dh- ყველა არა-a/ā ხმოვნის და -r-ის შემდეგ იცვლება -ḍh--ით (Kielhorn).**

:::
::: indent
z.B. :sig[⟪चि⟫] 5U: 2.pl.Ā :sig[⟪अचेढ्वम्⟫]
:::
::: grammar-box

*   **⟪परस्मैपद⟫ : Dehnstufe**

*   **ბოლოკიდური -ṝ იცვლება -īr ან -ūr-ით (Kielhorn)**
*   **ablautfähige Wurzeln auf ā/e/o: Tiefstufe**
