# გაკვეთილი 34

## 34.1. პერფექტი (⟪लिट्⟫)

კლასიკურ სანსკრიტში პერფექტის ფუძეს აქვს მხოლოდ ინდიკატივი და პარტიციპი.

::: grammar-box
**არსებობს პერფექტის ფორმირების ორი ტიპი:**
*   **რედუპლიცირებული პერფექტი = ⟪द्वित्वलिट्⟫**
*   **პერიფრასტიული პერფექტი = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**პერიფრასტიული პერფექტი (⟪अनुप्रयोगलिट्⟫) გამოიყენება:**
1. **წარმოებული კონიუგაციებისთვის (კაუსატივი, დეზიდერატივი, ფრეკვენტატივი, დენომინატივები)**
2. **ამოკებისთვის, რომლებიც იწყება გრძელი ვოკალით (ā-ს გარდა), ან ვოკალით (a-ს გარდა) ორი კონსონანტის წინ**
3. **ზოგიერთ სხვა ამოკისთვის**
:::
## 34.2. რედუპლიცირებული პერფექტი (⟪द्वित्वलिट्⟫)

### 34.2.1. ფუძის გრადაცია

::: grammar-box
**ფორმირება:**

**ძლიერი ფუძე:** ერთობლივი რიცხვი, პარასმაიპადა
*   **რედუპლიცირებული მაღალი ხარისხის ან გასქელებული ამოკი + პერფექტის დამატება**

**სუსტი ფუძე:** ყველა დანარჩენი ფორმა
*   **რედუპლიცირებული დაბალი ხარისხის ამოკი + პერფექტის დამატება**
:::
::: grammar-box
**ზოგადად (პერფექტის გარეთაც) ფუძის გრადაციას არ აქვს ამოკები შემდეგი ფორმისა:**
*   **(კონსონანტი)-კონსონანტი-გრძელი ვოკალი-კონსონანტი**
*   **(კონსონანტი)-კონსონანტი-ვოკალი-კონსონანტი-კონსონანტი**

**პერფექტში გარდა ამისა, ფუძის გრადაციას არ აქვს შემდეგი ფორმის ამოკები:**
*   **a-კონსონანტი**
*   **ā-კონსონანტი**
:::

### 34.2.3. შემაერთებელი ვოკალი -i-

::: grammar-box
**მრავლობითი რიცხვის 3. Ā (-re) დამატების წინ ყოველთვის ჩნდება შემაერთებელი ვოკალი -i-, სხვა კონსონანტით დაწყებული დამატებების წინაც, მრავალი ამოკის შემთხვევაში.**
:::
### 34.2.4. კონსონანტით დაწყებული ფუძეების რედუპლიკაცია

::: grammar-box
**კონსონანტით დაწყებული ფუძეების რედუპლიკაციისთვის მოქმედებს [ლეცია 33](lektion33.md)-ში მითითებული წესები.**

**კონსონანტით დაწყებული ფუძეების რედუპლიკაციის ვოკალი არის მოკლე ფუძის ვოკალი.**

**დიფთონგები კონსონანტის წინ მცირე ღრმა ვოკალამდე მცირდება.**
