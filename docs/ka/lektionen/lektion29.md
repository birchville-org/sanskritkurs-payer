# გაკვეთილი 29

## 29.1. პარასმაიპადის (⟪परस्मैपद⟫) და Ātmanepada-ს (⟪आत्मनेपद⟫) გამოყენება კაუზატივში


::: grammar-box
**კაუზატივი, ცოტა გამონაკლისის გარდა, არის Ubhayapada (⟪उभयपद⟫)**
:::
::: grammar-box
**კაუზატივში გამოიყენება Ātmanepada (⟪आत्मनेपद⟫):**

**1. როდესაც მოტივირებული ქმედების შედეგი მამოტივებლის სასარგებლოდ ხდება:**
:::
მაგალითი:

⟪रामः कटं कारयते⟫ = "რამა თავისთვის (საკუთარი ინტერესებისთვის) აკეთებს კალას"

**2. როდესაც ტრანზიტული ზმნების კაუზატივი რეფლექსურად გამოიყენება ("თავის თავზე აჩვენებს", "გაჟღერდება" და სხვა.), ან როდესაც მარტივი ზმნის ობიექტია კაუზატივის აგენსი (⟪कर्तृ⟫):**

მაგალითი:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "ვიშნუ თავის მლოცველებს უჩვენებს"

შედეგი: ⟪भक्ता विष्णुं पश्यन्ति⟫ = "მორწმუნეები ხედავენ ვიშნუს"


ამრიგად, წესები ზოგადად ემთხვევა Ātmanepada-ს (⟪आत्मनेपद⟫) გამოყენების წესებს Ubhayapada (⟪उभयपद⟫)-ზმნებისთვის.

## 29.3. გადატანის ვარჯიში გამეორებისთვის
