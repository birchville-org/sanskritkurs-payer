# გაკვეთილი 50

## 50.1. სახელობითი წარმოება: რეგულარული შედარებითი ხარისხები

::: grammar-box
**რეგულარული შედარებითი ხარისხები სანსკრიტში წარმოიქმნება ⟪तद्धित⟫-დან**
* **-⟪तर⟫ (დედ. ⟪तरा⟫) "შედარებითი ხარისხში"**
* **⟪तम⟫ (დედ. ⟪तमा⟫) "უმაღლეს ხარისხში"**

**ეს დანართები ემატება ადიექტივების მამრობითი სქესის ფუძეს. ნომინალებისთვის, რომლებიც ავლენენ სტამბის ცვალებადობას (აფთოფონიას), ისინი ემატება სუსტ ფუძეს, რომელიც ჰგავს იმას, რაც წარმოიქმნება -su ლოკატივის ბრუნის დამთავრებამდე (⟪पञ्चमी⟫) მრავლობითში.**
:::
::: media
![](/images/lekt5007.webp)
სურ.: ⟪लोकस्योत्तमो गिरिः सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = მთა ევერესტი
(სურათის წყარო: [დეტალები](/ka/licenses#lekt5007))
:::

::: grammar-box
**მნიშვნელობა:**

**"შედარებითი ხარისხი" ნიშნავს, თუკი შედარების ობიექტი არ არის გამოხატული: "კმაყოფილი, ძალიან, ზედმეტად":**

:::
::: indent
მაგ., ⟪सुचितर⟫ 3 "კმაყოფილი სუფთა", "ძალიან სუფთა", "ზედმეტად სუფთა"
:::
**თუკი შედარების ობიექტი გამოხატულია, ის დგას აბლათივში (⟪पञ्चमी⟩). შედარებითი ხარისხი + აბლათივი შეესაბამება "როგორც" გამოყენებას გერმანულში.**

::: indent
მაგ., ⟪देवदत्ताद्रामो धीमत्तरः⟫ = ზეპირად: "დევადატასთან შედარებით რამა უფრო ჭკვიანია" = "რამა უფრო ჭკვიანია, ვიდრე დევდატა"
:::
**"უმაღლესი ხარისხი" ნიშნავს, თუკი შედარების ობიექტი არ არის გამოხატული: "უკიდურესად, ძალიან":**

::: indent
მაგ., ⟪सत्तम⟫ 3 (↦ ⟪सन्त्⟫) "უკიდურესად კარგი, ძალიან კარგი"
:::
**თუკი შედარების ობიექტი გამოხატულია, ის დგას გენეტივში (⟪षष्ठी⟩) ("განა", "შორის") და უმაღლესი ხარისხი შეესაბამება გერმანულ უმაღლეს ხარისხს (უკიდურესი ხარისხი):**

::: indent
მაგ., ⟪द्विजानां सत्तमः⟫ = "უკეთესი ორჯერ დაბადებულთა შორის"
:::
**დანართები -⟪तर⟫ და -⟪तम⟫ შეიძლება არა მხოლოდ სახელობის ნათესავებთან, არამედ ასევე მსგავსობის ნაწილაკებთან, ინდეკლინაბილებსა და ზმნიერ ფორმებთანაც მიემართოს:**

მაგალითები:

::: indent
⟪गजतम⟫ მ. "უკეთესი ჯირკვალი" (⟪गज⟫) (ბუდის სახელწოდებაც)

⟪गोतम⟫ მ. "უდიდესი ხარა" (⟪गो⟫) ან: "უფრო მეტი ხარა"

⟪उद्⟫ ინდეკლ. "ზემოთ", "ზემოთ" » ⟪उत्तर⟫ 3 "უფრო მაღალი" » ⟪उत्तम⟫ 3 "უმაღლესი"
:::
**როდესაც ეს დანართები ზმნიერ ფორმაზე მიემართება, ისინი ყოველთვის ადვირბიაში გამოჩნდება:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

მაგალითები:

::: indent
⟪पचतितराम्⟫ "ის/მას/მაგ" უკეთესად მოამზადებს

⟪पचतितमाम्⟫ "ის/მას/მაგ" ყველაზე კარგად მოამზადებს
:::
**ეს ფორმა ასევე გამოიყენება, როდესაც ეს დანართები ინდეკლინაბილთან მიემართება და გამოყენებული სიტყვა ადვირბიაშია:**

::: indent
