# გაკვეთილი 55

## 55.1. a-აორისტი (თემაური ვოკალიანი აორისტი)

::: grammar-box
**a-აორისტი იგება, როგორც აორისტის (⟪लङ्⟫) 6. პრეზენტის კლასის (⟪तुदादि⟫) იმპერფექტი, ანუ:**

**აუგმენტი + დაბალი ხარისხის ფუძე + a- + მეორადი დამთავრება**

**-a- იცვლება -ā-ით იმავე ფორმებში, რაც იმპერფექტში.**

**არ არის ნაზალური ინფიქსი.**

**Ātmanepada იშვიათია; ორმხრივი ფუძეებისთვის ის ჩვეულებრივ სხვა აორისტული კლასების მიხედვით იგება (იხ. Kielhorn, Grammatik §340 და ქვემოთ შესაბამის აორისტულ კლასებში).**

**ფუძეების სია, რომლებსაც აქვთ ეს აორისტი, Kielhorn-ში, Grammatik §340.**
:::
