# გაკვეთილი 39

## 39.1. პირველი პიროვნების პერსონალური დანართები (:sig[तृतीयः] ⟪पुरुषः⟫ = "**მესამე** პიროვნება")

პირველი პიროვნების დანართები (:sig[⟪तृतीयः⟫] ⟪पुरुषः⟫ = "**მესამე** პიროვნება") არის:

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **პირველადი დანართები თემატური ფუძეებისთვის** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **პირველადი დანართები ათემატური ფუძეებისთვის** | ^^ | ^^ | **-e** | ^^ |
| **მეორადი დანართები თემატური ფუძეებისთვის** | **-m** | **-ma** | **-i** | **-mahi** |
| **მეორადი დანართები ათემატური ფუძეებისთვის** | **-am** | ^^ | ^^ | ^^ |
| **ოპტივის დანართი** | ^^ | ^^ | **-a** | ^^ |
| **პერფექტის დანართი** | **-a** | ^^ | **-e** | **-mahe** |

:::
¹ შენიშვნა: სინამდვილეში, პირველადი დანართი Ā თემატური ფუძეებისთვის ასევე უნდა იყოს -e, სადაც თემის ვოკალი -a- ანალოგიური მიზეზების გამო ქრება. ეფექტი ისეთია, თითქოს დანართი -i შეუერთდებოდა თემის ვოკალს -a-: a + i » e.
