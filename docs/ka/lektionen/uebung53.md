# ვარჯიში 53

Lektion 53-ის ვარჯიშს წარმოადგენს მეტრიკული ანალიზი (Šloka-ს სქემის განსაზღვრა) ყველა იმ შლოკასთვის, რომელიც წინა ლექციებში ისწავლა. 

რადგან ეს ამოცანა მოიცავს ყველაფერს, რაც გახსნის საკვანძო სიტყვაა და ანალიზი, არ არსებობს კლასიკური გაგებით ცალკეული ამოხსნის საკვანძო. ამოხსნები გამომდინარეობს Lektion 53-ში გადაცემული წესების გამოყენებიდან უკვე ცნობილი ტექსტებზე.
