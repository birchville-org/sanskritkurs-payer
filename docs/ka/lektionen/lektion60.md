## 60.4. რედუპლიცირებული სრულის ნაწილობრივი (⟪द्वित्वलिट्⟫)

::: grammar-box
**შექმნა:**

**სუსტი სრულის ფუძე + vāṃs**

**თუ სუსტი სრულის ფუძე მხოლოდ ერთი ხმოვანით შედგება, მაშინ ემატება საკავშირო ვოკალი -i-. ზოგიერთ სრულში საკავშირო ვოკალი არჩევითია.**
:::
მაგალითები:

| ⟪भिद्⟫ 7U | ⟪बिभिद्वांस्⟫ "ვინც გახადა" |
| --- | --- |
| ⟪अस्⟫ 2P; 4P | ⟪आसिवांस्⟫ "ვინც იყო" ; "ვინც გადაყარა" |
| ⟪दा⟫ 3U | ⟪ददिवांस्⟫ (da-d-i-vāṃs) "ვინც მისცა" |
| ⟪पच्⟫ 1U | ⟪पेचिवांस्⟫ "ვინც მოამზადა" |
| ⟪गम्⟫ 1U | ⟪जग्मिवांस्⟫ / ⟪जगन्वांस्⟫ "ვინც წავიდა" |

::: grammar-box
**დეკლინაცია:**

*   **ძლიერი ფუძე: -vāṃs**
*   **სუსტი ფუძე:**
*   **კონსონანტის წინ: -vat** **(!)**
*   **ვოკალის წინ: -uṣ**

**-i- შეერთების ვოკალი uṣ-ის შემდეგ ქრება.**

**მდედრობითი სქესი:**

**სუსტი ფუძე ვოკალის წინ + -ī (დეკლინაცია, როგორც ⟪देवी⟫)**

მაგალითი: ⟪विदुषी⟫ "ცოდნის მფლობელი"

## 60.5. -añc (-ac) ფუძეების დეკლინაცია

::: grammar-box
**-añc/-ac ფუძეები წარმოადგენს პრევებიებისა და სხვა ელემენტთა კომბინაციას ⟪अञ्च्⟫ / ⟪अच्⟫ 1U ფუძის სახელთან "მოძრაობა".**
:::
### 60.5.1. სამფუძიანი -añc ფუძეები

::: grammar-box
**გამოყენება:**

*   **ძლიერი ფუძე: -añc**
*   **სუსტი ფუძე:**
*   **კონსონანტის წინ: -ac**
*   **ვოკალის წინ:**
*   **-a- სუსტი ფუძის -ac-დან ქრება და წინამდებარე ნახევარვოკალისთვის მასთან შესაბამისი გრძელი ვოკალი ჩანაცვლებული:**  
⟪प्रत्यच्⟫ » ⟪प्रतीच् अन्वच्⟫ » ⟪अनूच्⟫
*   **თუ -ac-ს წინ ნახევარვოკალი არ მოჰყვა, -ac ჩანაცვლებულია -īc-ით:**  
⟪उदच्⟫ » ⟪उदीच्⟫
*   ⟪तिर्यञ्च्⟫ » ⟪तिरश्⟫

**მდედრობითი სქესი:**

**სუსტი ფუძე ვოკალის წინ + -ī (დეკლინაცია, როგორც ⟪देवी⟫)**

## 60.6. დეზიდერატივი (⟪सन्⟫)

::: grammar-box
**ყოველი ფუძიდან და ასევე კაუზატივიდან შეიძლება დეზიდერატივის (⟪सन्⟫) შექმნა. დეზიდერატივი ყველა დროსა და მოდუსში, პრეზენტის (P), ატმანეპადესა (Ā) და პასივის კონიუგაციის შესაძლებელია. დეზიდერატიული ფორმები პრეზენტის ფუძის გარეთ, თუმცა, ძალიან იშვიათია.**

**მნიშვნელობა:**

*   **პირი ან საგანი სურს გააკეთოს ან განიცადოს ის, რასაც ფუძე ან კაუზატივი გამოხატავს**
*   **იშვიათად: ვინმე ან რაღაც მზად არის გააკეთოს ის, რასაც ფუძე ან კაუზატივი გამოხატავს**

### 60.6.1. დეზიდერატივის ფუძის წარმოქმნა

::: grammar-box
**პრეზენსის კლასების 1 - 9 ფუძეები:**

**რედუპლიცირებული ფუძე + sa**

**ან:**

**რედუპლიცირებული ფუძე + i + ṣa**

დამაკავშირებელი ვოკალის -i- გამოყენების წესები იხ. კიელჰორნის გრამატიკაში § 443 - 445.

**პრეზენსის მე-10 კლასის ფუძეები და კაუსატივები:**

**რედუპლიცირებული პრეზენსის ფუძე + i + ṣa**
:::
::: grammar-box
**ფუძის ფორმა:**

1.  ფუძე ჩვეულებრივ მძიმე ხარისხშია: ⟪जीव्⟫ » ⟪जिजीविष⟫-  

1.  ბოლოში -i, -u ჩანაცვლდება -ī ანუ -ū-თი, თუ დამაკავშირებელი ვოკალი არ მოჰყვება:  
⟪जि⟫ » ⟪जि⟫:sig[⟪गी⟫]⟪ष⟫- "გამარჯვების სურვილი"  
⟪द्रु⟫ » ⟪दु⟫:sig[⟪द्रू⟫]⟪ष⟫- "სირბილის სურვილი"

⟪पॄ⟫ » ⟪पु⟫:sig[⟪पूर्ष⟫]\- "შევსების სურვილი"
