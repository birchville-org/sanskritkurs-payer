## 1.2. სანსკრიტის ხმოვანი

სანსკრიტის ხმოვანი ტრადიციული ინდური კლასიფიკაციის მიხედვით და მათი სამეცნიერო ტრანსკრიფცია.

::: media
![](/images/lekt0106.webp)
(სურათის წყარო: [დეტალები](/ka/licenses#lekt0106))
:::
თანამედროვე სანსკრიტის ლექსიკონები მოცემულია ამ კლასიფიკაციის თანმიმდევრობით. ეს კლასიფიკაცია სანსკრიტის გრამატიკის გაგებისთვის აუცილებელია და ამიტომ მისი მეხსიერებით ცოდნა უნდა:

::: note-box
კლასიფიკაცია
**მარტივი ხმოვნები** (samānākṣara -- ⟪समानाक्षर⟫):
⟪अ⟫ a, ⟪आ⟫ ā, ⟪इ⟫ i, ⟪ई⟫ ī, ⟪उ⟫ u, ⟪ऊ⟫ ū, ⟪ऋ⟫ ṛ, ⟪ॠ⟫ ṝ, ⟪ऌ⟫ ḷ
**დიფთონგები** (sandhyakṣara -- ⟪सन्ध्यक्षर⟫):
⟪ए⟫ e, ⟪ऐ⟫ ai, ⟪ओ⟫ o, ⟪औ⟫ au
**ხმოვნები** (vyañjana / hal -- ⟪व्यञ्जन⟫ / ⟪हल्⟫):
⟪क⟫ ka, ⟪ख⟫ kha, ⟪ग⟫ ga, ⟪घ⟫ gha, ⟪ङ⟫ ṅa
⟪च⟫ ca, ⟪छ⟫ cha, ⟪ज⟫ ja, ⟪झ⟫ jha, ⟪ञ⟫ ña
⟪ट⟫ ṭa, ⟪ठ⟫ ṭha, ⟪ड⟫ ḍa, ⟪ढ⟫ ḍha, ⟪ण⟫ ṇa
⟪त⟫ ta, ⟪थ⟫ tha, ⟪द⟫ da, ⟪ध⟫ dha, ⟪न⟫ na
⟪प⟫ pa, ⟪फ⟫ pha, ⟪ब⟫ ba, ⟪भ⟫ bha, ⟪म⟫ ma
⟪य⟫ ya, ⟪र⟫ ra, ⟪ल⟫ la, ⟪व⟫ va
⟪श⟫ śa, ⟪ष⟫ ṣa, ⟪स⟫ sa
⟪ह⟫ ha
:::
### 1.2.1. ზოგიერთი ხმოვანის წარმოთქმა

::: laut-table
| ხმოვანი | აღწერა |
| :--- | :--- |
| **a - ⟪अ⟫** | მოკლე „ა“ ინდურებში — უძველესი დროიდან — ხშირად ə-სავით წარმოითქმის. ევროპაში მოკლე „a“-სავით, ბენგალურში კი — მოკლე მუქ „o“-სავით. |
| **ṛ - ⟪ऋ⟫** | ჩეხური ვოკალიზებული r-სავით. i-ის მსუბუქი რეონანსი. |
| **ṝ - ⟪ॠ⟫** | ჩეხური ვოკალიზებული r-სავით. u-ის მსუბუქი რეონანსი. |
| **jñ - ⟪ज्ञ्⟫** | ასევე dny (მარათჰი) ან gy (ჩრდილოეთ ინდური). |
| **ś - ⟪श्⟫** | sch-ხმოვანი დაბლა მოღუნული ენის წვერით. მსგავსია „mischen“-ში არსებული sch-ისა. |
| **ṣ - ⟪ष्⟫** | ach-ხმოვანი უკან მოღუნული ენის წვერით. ხშირად ისე შორს ყელშია არტიკულირებული, რომ თითქმის kh-სავით ჟღერს. |
| **h - ⟪ह्⟫** | ხმის გამტანი ხმოვანი, არასდროს — გაგრძელების ნიშანი. |
| **ḥ - :** | **ვიისარგა (Visarjanīya)** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫. ღრუ ხმის გამტანი ხმოვანი წინა ხმოვნის ან წინა დიფთონგის მეორე ნაწილის რეონანსით: agniḥ -- ⟪अग्निः⟫ = agnihi, devaiḥ -- ⟪देवैः⟫ = devaihi, gauḥ -- ⟪गौः⟫ = gauhu |
| **ṃ** | **ანუსვარა** -- ⟪अनुस्वर⟫. ზიზღის ხმოვნებთან, h-სა და l-თან: ხმოვნის ნასალიზაცია. სიტყვის ბოლოში = m. სიტყვა შიგნით, თანხმოვნის წინ: შემდეგი თანხმოვნის შესაბამისი ნასალი: saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
საუკეთესო წარმოთქმა მიიღწევა, თუ წინადადებებს, პოემებს ან სიტყვებს საკმაოდ ნელა და მონოტონურად წაიკითხავთ, ზუსტი ხმოვნების სიგრძის გათვალისწინებით.


## 1.3. ვარჯიში

**ა) წაიკითხეთ შემდეგი სიტყვები:**

1. varṇa brāhmaṇaḥ kṣatriya vaiśya śūdra — ⟪वर्ण ब्राह्मणः क्षत्रिय वैश्य शूद्र⟫
2. brahmā viṣṇu śiva — ⟪ब्रह्मा विष्णु शिव⟫
3. āśrama brāhmacārin gṛhastha vānaprastha saṃnyāsin — ⟪आश्रम ब्राह्मचारिन् गृहस्थ वानप्रस्थ संन्यासिन्⟫
4. ṛgveda sāmaveda yajurveda atharvaveda — ⟪ऋग्वेद सामवेद यजुर्वेद अथर्ववेद⟫
5. upaniṣad — ⟪उपनिषद्⟫
6. jaina bauddha — ⟪जैन बौद्ध⟫
7. prajñāpāramitā — ⟪प्रज्ञापारमिता⟫
8. cakra vajra — ⟪चक्र वज्र⟫
9. pitṝn — ⟪पितॄन्⟫
10. saṃskṛta — ⟪संस्कृत⟫

**ბ) წაიკითხეთ ზემოთ მოცემულ ხმოვანთა კლასიფიკაციაში სანსკრიტული გამოთქმები.**
