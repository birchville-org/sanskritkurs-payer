# გაკვეთილი 25

## 25.1. აბლატივის წარმოქმნა (⟪पञ्चमी⟫ = "ხუთეული კასუსის დამატება")

::: grammar-box
მასკულინებისა და ნეუტრების გარდა -a-ზე, ასევე პრონომინებში, სინგულარში ყველა დექლინაციურ კლასში აბლატივის ფორმები (⟪पञ्चमी⟫) იდენტურია გენეტივის ფორმებთან (⟪षष्ठी⟫).

პერსონალური პრონომინების გარდა, ყველა დექლინაციაში პლურალში აბლატივის ფორმები იდენტურია დათივის ფორმებთან (⟪चतुर्थी⟫).
:::
ახლა თქვენ ხედავთ კასუსების (⟪विभक्ति⟫) თანმიმდევრობის მიზეზს სანსკრიტში: ისინი განლაგებულია ისე, რომ იდენტური ფორმები რაც შეიძლება ახლოს — ანუ ერთმანეთის ქვეშ — იდგეს.

::: grammar-box
**აბლატივი სინგულარი მასკულინების / ნეუტრებისთვის -a-ზე**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
კითხვითი, რელატიური და დემონსტრაციული პრონომინები:

::: grammar-box

| | აბლატივი სინგულარი:brმასკულინი / ნეუტრი | აბლატივი სინგულარი:brფემინინი |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

## 25.2. აბლატივის გამოყენება (⟪पञ्चमी⟫)

"აბლატივი აღნიშნავს იმას, რაც უცვლელი რჩება, როდესაც რაღაც მასგან წავა."

პāṇini 2,3,28 + 1,4,24

აბლატივი გამოიყენება ძირითადად კითხვებზე "სადედან?", "რატომ?".

::: grammar-box
1. აბლატივი ასევე აღნიშნავს საწყის წერტილს, წარმოშობას და მასალას.

ამიტომ აბლატივი შეიძლება აღნიშნავდეს პირს, ვინაგანაც რამე ყიდულობენ, ისმევენ, სურთ და ა.შ.
:::
მაგალითები:

::: indent
⟪ग्रमादागच्छति⟫ = „ის სოფლიდან მოდის“

⟪अश्वात्पतितः⟫ = „აშკარად ცხენიდან ჩამოვარდა“

⟪तेभ्यो लब्धम्⟫ = „მათგან მიღებული“
:::
მაგალითები:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = „მას მასწავლებლისგან სმენია დჰარმის შესახებ“

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = „ბრაჰმანს კშატრიასგან ღორის ძროხა სურს“
:::
::: grammar-box
2\. აბლატივი გამოიყენება ზმნებთან ერთად, რომლებსაც აქვთ მნიშვნელობა „განდევნა რამისგან“, „დაცვა რაღაცისგან“, „დამუშავება რაიმეს წინააღმდეგ“, „მოშიშვა რამისგან“:
:::
მაგალითი:

::: indent
⟪अरिभ्यो रक्षति⟫ = „ის მტრებისგან იცავს“
:::
::: grammar-box
3\. აბლატივი აღნიშნავს მიზეზს ან გამომწვევ ფაქტორს:
:::
მაგალითები:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = „ის თავის შვილს სიბრაზით კლავს“

⟪कृतपापत्वान्नरकं गच्छति⟫ = „რადგან ცუდი საქმე გააკეთა, ის ჯოჯოხეთში მიდის“ („რადგან ის არის, ვინც ცუდი საქმე გააკეთა“)

⟪पापकरणान्नरकं गच्छति⟫ = „რადგან ცუდ საქმეს აკეთებს / გააკეთა, ის ჯოჯოხეთში მიდის“
:::
არა-ფემინური სახელები, რომლებიც მოქმედების მიზეზს აღნიშნავენ, შეიძლება იყოს ინსტრუმენტალში (⟪तृतीया⟫) ან აბლატივში (⟪पञ्चमी⟫). ფემინური სახელები ჩვეულებრივ ინსტრუმენტალშია, მაგრამ ზოგჯერ აბლატივშიც შეიძლება იყოს.

## 25.3. სუფიქსი -⟪तस्⟫

::: grammar-box
თუ ერთეულში (მკაფიოდ) გვინდა გამოვხატოთ, რომ სიტყვა აბლატიურ მნიშვნელობით გამოიყენება, შეგვიძლია სიტყვის ფუძეს დავამატოთ სუფიქსი -⟪तस्⟫, რომელიც ადვერბებს ქმნის, ძირითადად აბლატიურ მნიშვნელობით („სადან?“):
:::
მაგალითები:

::: indent
⟪आदितस्⟫ = "საწყისიდანვე"

⟪धर्मतस्⟫ = "დჰარმის გამო, დჰარმის საფუძველზე"
:::
::: grammar-box
ზმნის შემსხმო -⟪तस्⟫ ასევე ემატება პრონომინალურ ფუძეებს:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "იქედან, იქ, იმკენად, ამის გამო, მაშინ"

⟪यद्⟫ : ⟪यतस्⟫ "რომელიდან, რისგან, საიდან, სად, სადამდე, რატომ" (რელატიური)

⟪किम्⟫ :  ⟪कुतस्⟫ "საიდან?" "რატომ?"

## 25.4. სხვა შესაძლებლობები, მიზეზობრიობის გამოსახვისთვის

::: grammar-box
**1\. რელატიური წინადადებები**

რელატიურ წინადადებებს ხშირად აქვთ კავზალური (მიზეზობრივი), კონსეკუტიური (შედეგობრივი) ან ფინალური (მიზნობრივი) კავშირი მთავარ წინადადებასთან.

რელატიური ზმნის ფორმები, რომლებიც მოქმედებენ კავზალური კონიუნქციის როლში:

*   აბლატიური:
*   ⟪यतस्⟫ ... ქვეწინადადება ... ⟪ततस्⟫ ... მთავარი წინადადება ... = "რადგან ..., ამიტომ ..."
*   ⟪यस्मात्⟫ ... ქვეწინადადება ... ⟪तस्मात्⟫ ... მთავარი წინადადება ... = "რადგან ..., ამიტომ ..."
*   ინსტრუმენტალური:
*   ⟪येन⟫ ... ქვეწინადადება ... ⟪तेन⟫ ... მთავარი წინადადება ... = "რის გამოც/რადგან ..., ამიტომ / იმის გამო ..."
:::
მაგალითი:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "რადგან რამა სურს მდიდრობა, ის აკეთებს აღთქმას"
:::
::: grammar-box
**2\. ⟪हि⟫**

მთავარი წინადადებები შეიძლება დაკავშირდნენ ⟪हि⟫ "რადგან, რადგანაც" პარტიკულის საშუალებით. ⟪हि⟫-იანი წინადადება (რომელიც არ უნდა იყოს პირველ ადგილას, არამედ პროზაში მეორე ადგილას უნდა იყოს) მიუთითებს მიზეზზე ადგილმდებარეობის წინა წინადადებასთან ან მომდევნო წინადადებასთან:
:::
მაგალითი:

::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "ადამიანები ღირსეულ საქმეს ასრულებენ. რადგანაც ცას სურთ მიაღწიონ."
:::
::: grammar-box
**3\. ინსტრუმენტალი (⟪तृतीया⟫)**

აბლატივის (⟪पञ्चमी⟫) გარდა, ინსტრუმენტალი (⟪तृतीया⟫) გამოიყენება მიზეზის ან საფუძვლის მითითებისთვის. ფემინური სიტყვების შემთხვევაში, ინსტრუმენტალი ჩვეულებრივ აუცილებელია.
:::
მაგალითი:

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = "ის რისხვის გამო თავს ესხმის თავის შვილს" = "ის რისხვაში თავს ესხმის თავის შვილს"
:::
::: grammar-box
**4\. სახელები**

გარდა ამისა, რა თქმა უნდა, შეიძლება მიზეზების გამოხატვა კონსტრუქციებით

*   ⟪कारण⟫ n. "მიზეზი": ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ m.
*   სხვა სახელები "მიზეზის" მნიშვნელობით

\+ გენიტივი (⟪षष्ठी⟫) ან კომპოზიტების მეორე ნაწილად:
:::
მაგალითი:

::: indent
⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ და ა.შ.) = "ღირსების გამო"
:::
::: grammar-box
**5\. ⟪इति⟫**

მოტივს საქმიანობისთვის შეიძლება გამოხატოთ როგორც აზრი ⟪इति⟫-ით:
:::
მაგალითი:

::: indent
⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫  = "რადგან სუგატა სიმართლეზე სრულად გამოიღვიძა, ანანდა გაუტამას ეკითხება მის სწავლებაზე" (« "იფიქრებს: 'სუგატა სიმართლეზე სრულად გამოიღვიძა' ..." )
:::
