## 41.2. სხვა ⟪कृत्⟫-ფორმირებები -a ბოლოსწინა

### 41.2.1. მიმდინარე დროის ნაწილაკი (⟪लडादेशः⟫) Ā, მიმდინარე დროის ნაწილაკი (⟪लडादेशः⟫) პასივი, მომავალი დროის ნაწილაკი (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. თემატური მიმდინარე ფუძეები, პასივი და მომავალი დრო

::: grammar-box
**გაფორმება:**

მიმდინარე ფუძე / პასივის ფუძე / მომავალი დროის ფუძე + -māna (დედ. mānā)
:::
მაგალითები:

⟪यज्⟫ 1U, მიმდ. დროის ნაწილაკი Ā ⟪यजमान⟫ 3 "ვინმე, ვინც საკუთარი ინტერესით წირვის გზით პატივს სცემს = წირვის მფლობელი"

⟪मन्⟫ 4Ā, მიმდ. დროის ნაწილაკი Ā ⟪मन्यमान⟫ 3 "მსჯელობის მქონე"

⟪कृ⟫ 8U, მიმდ. დროის ნაწილაკი პასივი ⟪क्रियमाण⟫ 3 "რაღაც, რაც გაკეთდება"

⟪दा⟫ 3U, მომ. დროის ნაწილაკი Ā ⟪दास्यमान⟫ 3 "ვინმე, ვინც საკუთარი ინტერესით მისცემს"

### 41.2.2. "პარტიციპი" პასიური აუცილებლობის (გერუნდიუმის) (⟪कृत्य⟫)

### 41.2.4. განსხვავებები გერუნდიუმის შემაკავშირებელ ნაწილაკებს შორის გამოყენებისას

::: grammar-box
ამ ნაწილაკების გამოყენება თითქმის სრულად ემთხვევა ერთმანეთს

* **-⟪तव्य⟫ (დედ. -⟪तव्या⟫):** ყოველთვის გამოხატავს აუცილებლობას და უპირატესად პრედikatულად გამოიყენება (ნაკლებად ატრიბუტივად). ამ ნაწილაკით წარმოქმნილი სიტყვები არ უნდა გამოიყენოს ნომინალურ კომპოზიტებში.
