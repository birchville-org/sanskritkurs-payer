# გაკვეთილი 19

## 19.1. განმარტებითი წინადადება

::: grammar-box

**სქემა:**


**განმარტებითი ზედსართავი -- განმარტებითი წინადადება, რომელიც შეიცავს სახელს, რომლისკენაც მიმართულია განმარტებითი წინადადება -- (დემონსტრატული ზედსართავი) -- მთავარი წინადადება**

**განმარტებითი წინადადება ასევე შეიძლება მთავარი წინადადების შემდეგ იდგას, მაგრამ ის მთავარ წინადადებაში ჩართული ვერ იქნება.**

**განმარტებითი ზედსართავი და კავშირის სიტყვა, რომელიც — გერმანულთან განსხვავებით -- განმარტებით წინადადებაში დგას, იღებს იმ კასუსს, რომელსაც განმარტებითი წინადადება სინტაქტიკურად მოითხოვს. დემონსტრატული ზედსართავი იღებს იმ კასუსს, რომელსაც მთავარი წინადადება სინტაქტიკურად მოითხოვს.**
:::

მაგალითები:

შენიშვნა: ზოგადმისაღებ შინაარსის განმარტებით წინადადებაში ხშირად გამოიყენება ოპტივი ინდიკატივის ნაცვლად. ამიტომ, ჩვენი მაგალითების უმეტესობა ოპტივით იქნება წარმოდგენილი.

**1. მოქმედი (⟪कर्तृ⟫) განისაზღვრება განმარტებითი წინადადების მიერ:**

::: indent
⟪यो नरः पुण्यं करोति स स्वर्गं गच्छति⟫ =  ⟪यो नरः पुण्यं करोति तेन स्वर्गं गम्यते⟫ = ⟪येन नरेण पुण्यम् क्रियते तेन स्वर्गं गम्यते⟫ და ა.შ. = "კაცი, რომელიც ღირსეულ საქმეს ასრულებს, ცას მიდის."
:::
**2. პირდაპირი დამატება (⟪कर्म⟫) მთავარი წინადადებისა განისაზღვრება განმარტებითი წინადადების მიერ:**

::: indent
⟪यो ब्राह्मणो देवान्यजते तं देवा रक्षन्ति⟫ = "ღმერთები იცავენ ბრაჰმანს, რომელიც მათთვის საკურთხელის მეურვეობას უწევს."
:::
**3. მთავარი წინადადების სახელის დამატებითი განმარტება განმარტებით წინადადებაში დგას:**

::: indent
⟪ये नराः पापं कुर्वन्ति तेषां पुत्रा धनं न लभन्ते⟫ = "კაცების შვილები, რომლებიც ბოროტებას აკეთებენ, მდიდრულად ვერ ცხოვრობენ."
:::
**4. რელატიური ზედსართავი და მითითების სიტყვა გენიტივშია (⟪षष्ठी⟫):**

::: indent
⟪यस्य नरस्य पुत्राः पापं कुर्वन्ति स न सुखवान्⟫ = "კაცი ბედნიერი არ არის, რომლის შვილები სძულთ."
:::
**5. რელატიური ზედსართავი და მითითების სიტყვა ინსტრუმენტალითაა (⟪तृतीया⟫):**

::: indent
⟪येन शत्रुणा ग्रामो जितस्तं द्विषन्ति⟫ = "მტერს ურყევენ, რომელმაც მისი სოფელი დაიპყრო."
:::
**6. რელატიური ზედსართავი და მითითების სიტყვა აკუზატივშია (⟪द्वितीया⟫):**

::: indent
⟪यं नरं देवी रक्षति स सुखमाप्नोति⟫ = "კაცი, რომელსაც ღმერთი იცავს, ბედნიერებას აღწევს."
:::

## 19.4. ვარჯიში

**გადათარგმნეთ სანსკრიტზე:**

1. ვაიშის ქალი, რომლის შვილი გარდაიცვალა, ცრემლებს ღვრის.

2. რამა შესწირავს ღმერთს, რომელიც მას იცავს.

3. პოეტი ადიდებს კშატრიას, რომლის სიმდიდრესაც ის იღონებს.

4. ცეცხლი წვავს კაცის სახლს, რომელიც არ ადიდებს აგნის შესწირულობით.

5. მგლისმსგავსი კაცი ანადგურებს კშატრიის მეომრებს, რომლებიც რამას დაამარცხეს (პასივი).
