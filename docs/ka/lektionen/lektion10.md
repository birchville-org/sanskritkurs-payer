# გაკვეთილი 10

## 10.1. პასიური წინადადება

::: grammar-box
**სქემა:**
**(აგენსი - kartṛ - ინსტრუმენტალით (tṛtīyā)) - (პირდაპირი ობიექტი - karman - ნომინატივით) - პასიური ფორმა**

მაგ. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "ბრაჰმანა ღმერთს შესწირავს" (ზუსტად: "ღმერთს ბრაჰმანა შესწირავს")

ეს წინადადება **სრულად (!) მნიშვნელობით** ემთხვევა წინადადებას:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
პასიურ წინადადებაში აგენსი (**kartṛ**) **ინსტრუმენტალშია** (tṛtīyā f. "მესამე კასუსი"), პირდაპირი ობიექტი (**karman** n.) **ნომინატივშია** (prathamā f.).
პასიური წინადადებები, სადაც აგენსი არ არის მითითებული, ჩვეულებრივ უპირადობას ნიშნავს ("ერთები"):
მაგ. **ijyate** = ⟪इज्यते⟫ "ერთები შესწირავენ" (ზუსტად: "შესწირულია").
:::

::: grammar-box
**თუნდაც შესაბამის აქტიურ წინადადებაში მიზნისთვის დუიტია (dvitīyā) იყოს, პასიურ წინადადებაში ის ნომინატივად (prathamā) შეიძლება გადავიდეს:**

აქტიურ წინადადებას **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "რამა სოფელში მიდის" შეესაბამება პასიური წინადადებები:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
ალტერნატიულად: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**ინტრანზიტული ზმნები (პირდაპირი ობიექტის გარეშე) ხშირად აქვთ პასიური კონსტრუქციები, განსაკუთრებით вежлив მოწოდებებში:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "ერთი შევიდეს = გთხოვთ, შემოდი = მოგწონს!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "ერთი დაჯდეს = გთხოვთ, დაჯექი = გთხოვთ, ადგილი დაიკავე"
:::
[LN] Sanskrit-Passivkonstruktionen sind ausgesprochen häufig: das Passiv ist ja auch leichter bildbar als z.B. zahlreiche Präsensstämme.

::: important
[LN] **სანსკრიტული ვნებითი კონსტრუქციები ზოგადად განსხვავებულ სტილისტურ ფუნქციას ასრულებს (Kielhorn).**
:::

### 10.2.1. ინსტრუმენტალის გამოყენების შესახებ (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**ინსტრუმენტალი (tṛtīyā) ძირითადად პასუხობს შემდეგ კითხვებს:**
**რისი საშუალებით?**
**რით?**
**ვინთან ერთად?**

**ის გამოიყენება**
1. **პასიურ წინადადებში: აგენსი (kartṛ) ინსტრუმენტალში**
2. **შუამავლის ან ინსტრუმენტის მითითებისთვის, რისი საშუალებითაც რამე სრულდება**
3. **გზის მითითებისთვის, რომლითაც ვინმე სადღაც აღწევს**
**კავშირის, გაერთიანების თანხლების გამოსახატად**
**პოსტპოზიციებთან ერთად "ერთად, თან" მნიშვნელობით; მაგ: saha = ⟪सह⟫ = "თან"** :brმაგ:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "ბრაჰმანთან ერთად"
:::
შემდეგში მოყვება ინსტრუმენტალის (tṛtīyā) სხვა გამოყენებები.

### 10.4.1. პასივის წარმოქმნის განსაკუთრებული წესები

1. **-i ან -u-ზე დამთავრებული ფუძეები** პასივის სუფიქსის **-ya-** წინ ვოკალურს გრძელდება:
* **ji** 1 პ: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 პ: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 უ: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **ფუძეები, რომლებსაც ბგერებს შორის აქვთ -a-** (ნაზალების, y-ს, r-ის, v-ის გარდა) რჩებიან მაღალ ხარისხში:
* **labh** 1 Ā: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **ზოგიერთი ფუძე წარმოქმნის პასივს მაღალ ხარისხში** (ან პრეზენტური ფუძის აბლაუტ ხარისხში):
* **āp** 5 პ: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 პ: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 პ: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **დაბალი ხარისხი იმ ზმნებისა, რომლებიც იწყება ya-თი, va-თი, ra-თი, ან რომელთა შემდეგაც ეს ბგერები სხვა კონსონანტის მიმართ დგას (Samprasāraṇa = ⟪सम्प्रसारण⟫):**

| ფუძე:br⟪धातु⟫ | დაბალი ხარისხი:br⟪सम्प्रसारण⟫ | პასივი:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 უ:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 პ:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 პ:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

ტრადიციული ადგილობრივი სახელწოდება ამ ღრმა ეტაპის ფორმირებისთვის **ya** ანუ **va**-ს შემცველ ზმნებში არის **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **ბოლოში მდებარე -ṛ** ერთი კონსონანტის შემდეგ პასიური ზმნაწარმოქმნილი **-ya-** წინ იცვლება **-ri**-თ:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫

6. **ზოგიერთი -an-ზე დამთავრებული ფუძეს აქვს ალტერნატიულად ორი პასიური ფორმის წარმოქმნა:**

## 10.6. Übung

**A) შექმენით ვნებითი ფორმები შემდეგი ზმნის ფორმებისთვის (ზმნის ფორმის თარგმანით) (Kielhorn):**

1. **sṛjati** (⟪सृजति⟫)
2. **yudhyate** (⟪युध्यते⟫)
3. **bhavanti** (⟪भवन्ति⟫)
4. **yajati** (⟪यजति⟫)
5. **nṛtyati** (⟪नृत्यति⟫)
6. **nayanti** (⟪नयन्ति⟫)
7. **smarati** (⟪स्मरति⟫)
8. **śṛṇvanti** (⟪शृण्वन्ति⟫)
9. **paśyati** (⟪पश्यति⟫) (ვნებითი იწარმოება **dṛś**-ისგან!)
10. **jayanti** (⟪जयन्ति⟫)
11. **kurvate** (⟪कुर्वते⟫)
12. **āpnuvanti** (⟪आप्नुवन्ति⟫)
13. **viśati** (⟪विशति⟫)
14. **khādanti** (⟪खादन्ति⟫)
15. **sunoti** (⟪सुनोति⟫)
16. **gacchati** (⟪गच्छति⟫)
17. **manyante** (⟪मन्यन्ते⟫)
18. **labhante** (⟪लभन्ते⟫)
19. **rakṣanti** (⟪रक्षन्ति⟫)
20. **vadanti** (⟪वदन्ति⟫)
21. **pṛcchanti** (⟪पृच्छन्ति⟫)
22. **tanvanti** (⟪तन्वन्ति⟫) (2 ფორმა!)

**B) შექმენით ინსტრუმენტალის ერთეული და მრავლობა ყველა აქამდე შესწავლილ სახელისთვის.**

**C) გადაიყვანეთ შემდეგი წინადადებები პასიურ ფორმაში და თარგმნეთ ისინი:**
1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो देवीं यजति⟫)
2. **sādhuḥ svargaṃ gacchati.** (⟪साधुः स्वर्गं गच्छति⟫)
3. **śūdraṃ jayati.** (⟪शूद्रं जयति⟫)
4. **guruḥ phalāni khādati.** (⟪गुरुः फलानि खादति⟫)
5. **gurūñchṛṇoti.** (⟪गुरूञ्छृणोति⟫)
6. **ko 'gniṃ paśyati.** (⟪को ऽग्निं पश्यति⟫)
7. **ayaṃ kavirmantraṃ smarati.** (⟪अयं कविर्मन्त्रं स्मरति⟫)
8. **iyaṃ devī kṣatriyā rakṣati.** (⟪इयं देवी क्षत्रिया रक्षति⟫)
9. **kṣatriyā viṣṇuṃ yajante.** (⟪क्षत्रिया विष्णुं यजन्ते⟫) (2 ვარიანტი)
10. **brāhmaṇo 'gniṃ karoti.** (⟪ब्राह्मणो ऽग्निं करोति⟫)
11. **vaiśyā imaṃ grāmaṃ gacchanti.** (⟪वैश्या इमं ग्रामं गच्छन्ति⟫) (2 ვარიანტი)
12. **ete gurūṃstu śṛṇvanti.** (⟪एते गुरूंस्तु शृण्वन्ति⟫)
13. **sādhuḥ svargamāpnoti.** (⟪साधुः स्वर्गमाप्नोति⟫)
14. **brāhmāṇāḥ somaṃ sunvanti.** (⟪ब्राह्मणाः सोमं सुन्वन्ति⟫)
15. **paśūllabhate.** (⟪पशूल्लभते⟫)
16. **ke yodhāḥ kṣatriyaiḥ saha yudhyante.** (⟪के योधाः क्षत्रियैः सह युध्यन्ते⟫)

**D) თარგმნეთ სანსკრიტზე:**
1. ბრაჰმანა ვეიშასთან ერთად სოფელში მიდის.
2. ის პატივს სცემს ვიშნუს მსხვერპლით. (მსხვერპლის გამოსახატად გამოიყენეთ **yajña**!)
3. ვედას შრუთი ეწოდება. (**vad**)
4. იკიდებენ მბეჭდავ ძაფს. (2 ვარიანტი)
