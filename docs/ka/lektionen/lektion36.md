## 36.2. პერიფრაზული პერფექტი (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
პერიფრაზული პერფექტი (⟪अनुप्रयोगलिट्⟫) გამოიყენება:

1. გამოყვანილ კონიუგაციებში (კაუსატივი, დეზიდერატივი, ფრექვენტატივი, დენომინატივები)
2. ფესვებში, რომლებიც იწყება გრძელი ვოკალით (a--ს გარდა), ან ვოკალით (a--ს გარდა) ორი კონსონანტის წინ
3. ზოგიერთ სხვა ფესვში
:::
::: grammar-box
**გაჩენა:**

(სუსტი) პრეზენტის ფუძე + -ām + შესაბამისი პერფექტის ფორმა ⟪कृ⟫, ⟪अस्⟫ ან ⟪भू⟫-დან
