# გაკვეთილი 26

## 26.1. ცერებრალიზაციის კანონი -s- სთვის სიტყვის შიგნით

::: grammar-box

**-s-** იცვლება **-ṣ-** -ით, როდესაც **k, r, l** ან **ვოკალი** — გარდა **a, ā**-სი — პირდაპირ ან მხოლოდ ⟪अनुस्वार⟫ ან ⟪विसर्ग⟫-ით გამოყოფილი წინ უსწრებს და სხვა ხმოვანი თანხმობა, გარდა **ṛ, r**-ისი, მოჰყვება.

ამ სანდჰს ემორჩილება ასევე **⟪दुस्⟫-** უმღერო გუტურალების და ლაბიალების წინ კომპოზიტებში.

:::

*მაგალითები:*

::: indent

⟪तेषाम्⟫ (წყარო: *te-sām*)

მაგრამ: ⟪तासाम्⟫ (*tā-sām*)

:::

## 26.2. ცერებრალიზაციის კანონი დენტალური თანხმობებისთვის სიტყვის შიგნით

::: grammar-box

დენტალური პლუზივები რეტროფლექსების (მათ შორის **-ṣ-**) შემდეგ შესაბამისი რეტროფლექსებით იცვლება:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** წინა **i**-ს გამო, **ṭh** შემდგომი **ṣ**-ის გამო)*

:::

## 26.3. სიტყვის შიგნით პალატალების, გუტურალების, ṣ-ის, h-ს + -s სანდჰი

::: grammar-box

**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

მაგალითები იხილეთ ქვემოთ

:::

მაგალითი:

## 26.6. გამოყენება მარტივი მომავალი დროისა (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box

**მარტივი მომავალი დრო (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) გამოხატავს:**

**მომავალს**
**გეგმილ ან სურვილიან მოქმედებას ("მე წავალ", "მინდა წასვლა")**
**წარმოდგენას ("ეს ასე მოხდება")**
**იმედს**
**შფოთებას/წინასწარ ხედვას**
**ალბათობას**
**მეტყველის აზრს/განცხადებას**
**ბრძანებას/აუცილებლობას**

**მომავალი დრო ნაწილობრივ კონკურენციაში შედის ოპტიატთან (იხ. მოგვიანებით).**

## 26.7. მარტივი მომავალი დროის ფორმირება (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box

**მარტივი მომავალი დრო:**

:::

::: indent

**მომავლის ფუძე + პირველადი ბოლო**

:::

::: grammar-box

**მომავლის ფუძე:**

:::

::: indent

**(უმეტესად) მაღალი ხარისხის ფუძე + -sya**
**ან**
**(უმეტესად) მაღალი ხარისხის ფუძე + -i- + -sya (= - iṣya)**

:::

**რომელი ფუძე რომელ მომავლის ფორმას ქმნის, ეს ფორმების სახეობებთან ერთად უნდა ისწავლოთ!**
**ზოგადად, ფუძის ფორმა და შემაერთებელი ვოკალი მომავალში ინფინიტივის მსგავსია.**
**ზოგიერთ ფუძეს შეუძლია მომავალი დრო ოპციურად აიგოს -i- შემაერთებელი ვოკალით და მის გარეშე.**
**მომავლის პარტიციპი Parasmaipada-ში (საქმიან მოდელობაში) იქმნება -nt- დამატებით მომავლის ფუძესთან, მდედრობითი სქესისთვის ოპციურად -ntī ან -tī:**

⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
