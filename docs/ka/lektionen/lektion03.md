# გაკვეთილი 3

## 3.1. მდედრობითი სქესის ერთეული ნომინატივი

### 3.1.1. ერთეული ნომინატივი -s-ით

ასევე შემდეგი სახელმწოდებელი ფუძეები, რომლებიც ხმოვანით მთავრდება, ქმნიან ერთეულ ნომინატივს **-s**-ით:

::: grammar-box
**მდედრობითი სქესის -i-ზე:** მაგ., **śruti** მ. "სმენა" -- ერთ. ნომ.: **śrutis** = ⟪श्रुतिस्⟫
**მდედრობითი სქესის -u-ზე:** მაგ., **dhenu** მ. "ძროხა" -- ერთ. ნომ.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. ერთეული ნომინატივი ბოლოწარმოებული

ერთეულ ნომინატივს ქმნიან ბოლოწარმოებული:

::: grammar-box
**მდედრობითი სქესის -ā-ზე:** მაგ., **devatā** მ. "ღმერთი" -- ერთ. ნომ.: **devatā** = ⟪देवता⟫
**მდედრობითი სქესის -ī-ზე:** მაგ., **devī** მ. "ღმერთი" -- ერთ. ნომ.: **devī** = ⟪देवी⟫
:::
::: important
**შეხედეთ!** ამასთან ერთად არსებობს ერთწევრიანი მდედრობითი სქესის ფუძეები -ī-ზე, რომელთა ერთეული ნომინატივი -s-ით მთავრდება: მაგ., dhī მ. "აზრი" -- ერთ. ნომ.: dhīs = ⟪धीस्⟫. ასევე lakṣmī (⟪लक्ष्मी⟫) მ., tarī (⟪तरी⟫) მ. "ნავი" და tantrī (⟪तन्त्री⟫) მ. "სიმები" ქმნიან არეგულარულად ერთეულ ნომინატივს -s-ით: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. მდედრობითი სქესის ქმნა მამრობითი სქესიდან

::: grammar-box
**მამრობითი სქესის -a-ზე:**
**მდედრობითი სქესის -ā-ზე:** მაგ., **kṣatriya** მ. » **kṣatriyā** მ. "კშატრიას ქალი" = ⟪क्षत्रिया⟫
**მდედრობითი სქესის -ī-ზე:** მაგ., **brāhmaṇa** მ. » **brāhmaṇī** მ. "ბრაჰმანის ქალი" = ⟪ब्राह्मणी⟫

**მამრობითი სქესის -u-ზე:**
**მდედრობითი სქესის -ī-ზე:** მაგ., **sādhu** მ. » **sādhvī** მ. (კარგი, წმინდანის) = ⟪साध्वी⟫
(**-u-** ხმოვანთან გადადის **-v**-ად, ამიტომ **-u- + -ī** » **-vī**)
:::

## 3.3. მამრობითი და მდედრობითი სქესის ბევრეული ნომინატივი

::: grammar-box
ბევრეული ნომინატივის ბოლოწარმოებული მამრობით და მდედრობით სქესში არის **-as**.
**მამრობითი სქესის -a-ზე:** **deva- + -as** » **devās** = ⟪देवास्⟫
**მდედრობითი სქესის -ā-ზე:** **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**მამრობითი სქესის -i-ზე:** **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**მდედრობითი სქესის -i-ზე:** **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**მდედრობითი სქესის -ī-ზე:** **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**მამრობითი სქესის -u-ზე:** **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**მდედრობითი სქესის -u-ზე:** **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
შენიშვნა: **e** არის მაღალი ეტაპი (**guṇa**) **i**-სთვის, **o** არის მაღალი ეტაპი **u**-სთვის.


## 3.4. ვოკალური სანდჰი

a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**

## 3.6. სიტყვების ლექსიკონი

**ისწავლეთ შემდეგი სიტყვები:**

**śruti** f. = ⟪श्रुति⟫ : მოსმენა, მარადიული ტრადიცია (ვედების და ბრაჰმანების აღნიშვნა).

**smṛti** f. = ⟪स्मृति⟫ : წარმოდგენა, მეხსიერება, მდიდრიანი წარმოდგენა = ყურადღებამოხვევა, ტრადიცია (**śruti**-ს საპირისპირო ცნება). მოიცავს:
ექვს **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): სწორი წარმოთქმა
2. **chandas** n. (⟪छन्दस्⟫): მეტრიკა
3. **vyākaraṇa** n. (⟪व्याकरण⟫): გრამატიკა
4. **nirukta** n. (⟪निरुक्त⟫) : სიტყვის ახსნა, ეტიმოლოგია
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : ასტრონომია, კალენდრის მეცნიერება
6. **kalpa** m. (⟪कल्प⟫) : ცერემონიალი
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : სასწავლო ტექსტები დიდი მსხვერპლის შესასრულებლად
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : სასწავლო ტექსტები ყოველდღიური ცხოვრების ცერემონიებისა და მსხვერპლისთვის
**dharmasūtra** n. (⟪धर्मसूत्र⟫) და **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : სასწავლო ტექსტები კანონისა და ჩვეულების შესახებ (მართული ქცევა)
დიდი ეპოსები **mahābhārata** n. (⟪महाभारत⟫) და **rāmāyaṇa** n. (⟪रामायण⟫)
**purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫) : სასწავლო ტექსტები ცხოვრების სიბრძნის შესახებ

**smṛti** განსაკუთრებით ასევე არის დхарმასა სიტყვა.

**dhenu** f. = ⟪धेनु⟫ : (ძროხა) რძის ძროხა.

**paśu** m. = ⟪पशु⟫ : შინაური სასოფლო-სამეურნეო ცხოველი, საქონელი (კოლექტიური).

**devatā** f. = ⟪देवता⟫ : ღმერთი (აბსტრაქტული და კონკრეტული).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : ბრაჰმინი.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : ქალი კშატრიი.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : კშატრიას მეუღლე.

**vaiśyā** f. = ⟪वैश्या⟫ : ქალი ვაიშია.

**śūdrā** f. = ⟪शूद्रा⟫ : ქალი შუდრა.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : შუდრას მეუღლე.

**devī** f. = ⟪देवी⟫ : ღმერთიანი, განსაკუთრებით დურგა f. = ⟪दुर्गा⟫, შივას მეუღლე = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
სურ.: დურგა = ⟪दुर्गा⟫, ორიშა
(სურათის წყარო: [დეტალები](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : მდედრობითი სქესის sādhu-სთვის.

**gurvī** f. = ⟪गुर्वी⟫ : მდედრობითი სქესის guru-სთვის.

**asmitā** f. = ⟪अस्मिता⟫ : „მე-ობა“, ანუ (არასწორი) რწმენა: **მე** ვარ ის, ვინც ხედავს და ა.შ.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : ფილოსოფია (მეცნიერება, რომელიც ლოგიკურად სწორი დასაბუთებებით აღწევს საკუთარ დასკვნებს).

**upekṣā** f. = ⟪उपेक्षा⟫ : უყურადღებობა, სიმშვიდე.

**karuṇā** f. = ⟪करुणा⟫ : თანაგრძნობა, მზრუნველობა.

**muditā** f. = ⟪मुदिता⟫ : სიხარული, განსაკუთრებით მეორეების სიხარული (მტკივნეული შეურაცხყოფის საპირწონე).


## 3.7. ვარჯიში

**A) გადაყავით შემდეგი წინადადებები მრავლობითში:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**ბ) ჩასმით შექმენით სახელობითი წინადადებები:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**გ) გადაიტანეთ მდედრობით სქესში:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**დ) თარგმნეთ სანსკრიტზე:**

1. უმა ღმერთი ქალია.
2. ვედა შრუტია.
3. მასწავლებლები ღმერთ ქალებია.
4. რძის ძროხები შინაური ცხოველებია.
5. პოეტები მასწავლებლები არიან.
6. კშატრიები ორჯერ დაბადებულები არიან.
7. წმინდა მამაკაცები შუდრებია.
