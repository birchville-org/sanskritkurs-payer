# გაკვეთილი 11

## 11.1. ორმაგი ბრალდების მიმართულება

::: grammar-box
**ზოგიერთი ზმნა ორმაგ ბრალდების მიმართულებას (dvitīyā) აკონტროლებს: პირის ბრალდების მიმართულება და საგნის ბრალდების მიმართულება.**

**ამ კატეგორიას ეკუთვნის:**
**საუბრის ზმნები**: ვესაუბრო პირს (ბრალდების მიმართულება) რაიმეზე (ბრალდების მიმართულება); ვეტყვი პირს (ბრალდების მიმართულება) რაიმეს (ბრალდების მიმართულება)
**კითხვის ზმნები**: ვეკითხები პირს (ბრალდების მიმართულება) რაიმეზე (ბრალდების მიმართულება)
**სწავლების ზმნები**: ვასწავლი პირს (ბრალდების მიმართულება) რაიმეს (ბრალდების მიმართულება)
ზოგიერთი სხვა ზმნა, რომელიც სიტყვარში აღინიშნება

**როდესაც ასეთი კონსტრუქცია პასიურ ფორმაში გადადის, პირი (რომელსაც ეკითხებიან და ა.შ.) ნომინატივში (prathamā) გადადის, საგანი (რომლის შესახებაც ეკითხებიან და ა.შ.) რჩება ბრალდების მიმართულებაში.**

მაგალითად, **rāmo brāhmaṇaṃ dharmaṃ pṛcchati** = ⟪रामो ब्राह्मणं धर्मं पृच्छति⟫ = "რამა ბრამინს დჰარმის შესახებ ეკითხება."
» პასიური: **rāmeṇa brāhmaṇo dharmaṃ pṛcchyate** = ⟪रामेण ब्राह्मणो धर्मं पृच्छयते⟫

**ეს წესი მოქმედებს მხოლოდ მაშინ, როცა პირიც და საგანიც ობიექტია. თუ საგანია ერთადერთი ობიექტი, ის პასიური წინადადების ძირითადი სქემის მიხედვით ნომინატივში (prathamā) გადადის:**

მაგალითად, **rāmo dharmaṃ pṛcchati** = ⟪रामो धर्मं पृच्छति⟫ = "რამა დჰარმის შესახებ ეკითხება."
» პასიური: **rāmeṇa dharmaḥ pṛcchyate** = ⟪रामेण धर्मः पृच्छयते⟫
:::

## 11.2. სიტყვარი

**ისწავლეთ შემდეგი სიტყვები:**

**iti** ⟪इति⟫ : ასე
დგას *შემდეგ* აზრის, სურვილის, განცხადების, ციტატის ფორმულირებიდან და თითქოსდა აღნიშნავს მათ (").
მაგალითად, **sādhavaḥ svargaṃ gacchantīti brāhmaṇā vadanti** "ბრამინები ამბობენ: 'მართლმადიდებლები ცას მიდიან'" = "ბრამინები ამბობენ, რომ მართლმადიდებლები ცას მიდიან".
სანსკრიტში არ არის შუამდგომლობითი საუბარი; **iti**-თქმული ფორმირებები გერმანულში ხშირად შუამდგომლობით საუბარში უნდა გადაიცეს.
**... (ციტატა) ... iti śrutiḥ** = "ასე ვედები."
ხშირად **iti**-ს შემდეგ აზროვნების ზმნა უნდა დაემატოს: "იფიქრებს: '...' აკეთებს ამას". გერმანულად იდიომატურად გადაიცეს (მაგალითად, "რადგან შიმშილი აქვს, მიდის...").

**evam** ⟪एवम्⟫ : ასე (ადვერბიულად, მაგ. **evaṃ jayati** „ასე იმარჯვებს ის“).
**na** ⟪न⟫ : არა
უარყოფს ცალკეულ სიტყვებს (დგას მათ პირდაპირ წინ: **na sādhuḥ** „არა კეთილი“) ან მთელ წინადადებებს (დგას დასაწყისში ან პირდაპირ ზმნის წინ).

**putra** მ. ⟪पुत्र⟫ : ვაჟი (ინდოეთში აუცილებელი იყო ვაჟის შობა, რომელსაც შეეძლო წინაპრებისთვის მსხვერპლის შესწირვა).
**dharma** მ. ⟪धर्म⟫ : („რაც მყარია“, ანუ) სამართალი, კანონი, ჩვეულება, ხასიათი.
ყველაზე მეტად შეესაბამება ბუნების/ნორმის კანონს. ყველას აქვს საკუთარი მოვალეობები **varṇa**-ისა და **āśrama**-ს (ცხოვრების ეტაპი) მიხედვით (**svadharma**).
**adharma** მ. ⟪अधर्म⟫ : არასამართალი (**dharma**-ს საპირისპირო).
**iṣ** 6 პ (icchati) ⟪इष् इच्छति⟫ : სურვა (**iṣ-ccha-ti**).

**ზოგიერთი სახელობითი წარმოება:**

**vad** 1 პ ⟪वद्⟫ : თქმა
**vāda** მ. ⟪वाद⟫ : განცხადება, თქმა, სიტყვა
**vadana** ნ. ⟪वदन⟫ : ლაპარაკი; სალაპარაკო ორგანო: პირი, სახე
