# გაკვეთილი 15

## 15.1. ⟪सुभाषितम् गुरुशुश्रूषया विद्या पुष्कलेन धनेन वा । अथवा विद्यया विद्या चतुर्थी नैव विद्यते ॥⟫

## 15.2. დეტერმინატიული კომპოზიტები = ტატფურუშა მ. = ⟪तत्पुरुष⟫

ნომინალებით (სუბstantive-ებით და ადიექტივებით) აღნიშნული რამეების ურთიერთობა შეიძლება გამოისახოს არა მხოლოდ გენიტურული კონსტრუქციით, არამედ ტატფურუშა (⟪तत्पुरुष⟫) საშუალებით. აგრეთვე, ადიექტივების ატრიბუტული თანაწესრიგება ან სუბstantive-ების აპოზიციური თანაწესრიგება შეიძლება გამოისახოს ტატფურუშას კონკრეტული სახეობით, ანუ ე.წ. ქარმადაჰარა (მ.) = ⟪कर्मधारय⟫ საშუალებით.

⟪तत्पुरुषः⟫ =  ⟪तस्य पुरुषः⟫ "მისი მონა", ანუ ამ ტიპის კომპოზიტების სახელწოდებად მოცემულია ასეთი კომპოზიტის მაგალითი.
::: grammar-box

დეტერმინატიულ კომპოზიტებში (ტატფურუშა) ერთი ნომინალი (სუბstantive ან ადიექტივი) მეორე ნომინალით ან ადვერბით უფრო კონკრეტულად განისაზღვრება. უფრო კონკრეტულად განსაზღვრული სიტყვა ჩვეულებრივ კომპოზიტის მეორე ნაწილს (უკანასვრელ წევრს) ქმნის.

პირველი წევრის (დეტერმინირებელი წევრი) მეორე წევრთან (დეტერმინირებული წევრი) ურთიერთობა შეიძლება იყოს:

*   ატრიბუტული ან აპოზიციური: კომპოზიტის დაშლისას პირველი წევრი მეორე წევრთან ერთად ქმნის უფრო კონკრეტულ განსაზღვრებას იმავე კასუსში (ანუ, წინადადების კონტექსტის გარეთ ნომინატში (⟪प्रथमा⟫), წინადადების შიგნით კი სინტაქსურად მოთხოვნილ კასუსში)
*   კასუალური: პირველი წევრი კომპოზიტის დაშლისას სხვა კასუსშია, ვიდრე მეორე წევრი (ანუ არა ნომინატში - ⟪प्रथमा⟫)
*   ადვერბიალური: პირველი წევრი არის დეკლინაციასა და კონიუგაციაში უცვლელი სიტყვა

კასუსური თანაფარდება ორივე წევრს შორის კომპოზიტში დამოუკიდებელია იმგვარად, თუ რომელ კასუსში დგას კომპოზიტი: რადგან კომპოზიტი ერთია, დეკლინირებადი სიტყვაა:

მაგალითად,

> ნომ. სინ. ⟪तत्पुरुषः⟫ = ⟪तस्य पुरुषः⟫  
> აკ. სინ. ⟪तत्पुरुषम्⟫ = ⟪तस्य पुरुषम्⟫  
> ინსტრ. სინ. ⟪तत्पुरुषेण⟫ = ⟪तस्य पुरुषेण⟫  
> გენ. სინ. ⟪तत्पुरुषस्य⟫ = ⟪तस्य पुरुषस्य⟫  
> ნომ. მრავ. ⟪तत्पुरुषाः⟫ = ⟪तस्य पुरुषाः⟫  
> და ა.შ.

ტატპურუშას სქესი — რამდენიმე გამონაკლისის გარდა — არის მისი უკანა წევრის სქესი.

:::
## 15.3. დეტერმინატიული კომპოზიტები ატრიბუტიული / აპოზიციური წინა წევრით = კარმადაჰარა მ. = ⟪कर्मधारय⟫
::: grammar-box

კარმადაჰარას დაშლისას, კომპოზიტის ორივე წევრს აქვს ერთი და იგივე კასუსი.

:::
მაგალითად,

⟪गुणवत्पुत्रः⟫ = ⟪गुणवान्पुत्रः⟫ = "კეთილი თვისებების მქონე ვაჟი"  
აკ. სინ. ⟪गुणवत्पुत्रम्⟫  
ნომ. მრავ. ⟪गुणवत्पुत्राः पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती क्षत्रिया⟫ = "ღირსეული ქშატრიიელი ქალი"  

⟪साधुजनाः⟫ = ⟪साधवो जनाः⟫ = "კეთილი ადამიანები"  

⟪इष्टदेवता⟫ = ⟪इष्टा देवता⟫ = "სასურველი ღვთაება = ღვთაება, რომლის მიმართაც განსაკუთრებული მორწმუნეობისა და თავშესაფრის ურთიერთობა აქვს"

კარმადაჰარაში წევრების თანმიმდევრობის შესახებ შემდეგი განსაკუთრებული წესი უნდა გაითვალისწინო:

*   თუ კარმადაჰარა შედარებას გამოხატავს, მაშინ ის, რასაც ადარებენ, კომპოზიტის უკანა წევრში დგას:

ასეთი აპოზიციალური კარმადაჰარაები ადგილობრივ კომენტარებში, ზემოთ მოყვანილი მაგალითის მსგავსად, ⟪एव⟫-ით იშლება.

## 15.4. დეტერმინატიული კომპოზიტები წინა ნაწილით, რომელიც შემადგენელთან არის ატრიბუტიული/აპოზიციალური კასუსური ურთიერთობით = ტატპურუში ვიწრო გაგებით

::: grammar-box

ტატპურუშის კომბინაციები შესაძლებელია ნომინების (სუბstantivების და ადიექტივების) კომბინაციებში, სადაც წინა ნაწილი - სინტაქსის წესების შესაბამისად - ნებისმიერ კასუსში შეიძლება იყოს. მოსალოდნელია, რომ წინა ნაწილი ყველაზე ხშირად გენეტივს წარმოადგენს (⟪षष्ठी⟩), რადგან ეს არის კასუსი, რომელიც ნომინების ურთიერთობას გამოხატავს.

:::
მაგალითად:

⟪क्षत्रियपुत्रः⟫ = ⟪क्षत्रियस्य पुत्रः⟫ = "ქსატრიას ძე", "მწკრივის წევრი ქსატრიასი", "ახალგაზრდა ქსატრიასი"  
აკუს. სგ. ⟪क्षत्रियपुत्रम्⟫  
გენ. სგ. ⟪क्षत्रियपुत्रस्य⟫  
და ა.შ.  

⟪गुरुभावः⟫ =  ⟪गुरोर्भावः⟫  = "მასწავლებლის ბუნება"

⟪धनलोभः⟫ = ⟪धनस्य लोभः⟫ = "მდიდრებისკენ სწრაფვა, ლაყუჩობა"

⟪लोकगतिः⟫ =  ⟪लोकस्य गतिः⟫ = "მსოფლიოს მოძრაობა, ხალხის ქცევა"

თითქმის ყველა გენიტიური დამოკიდებულება შეიძლება ჩანაცვლდეს ტატპურუშით. რამდენიმე გამონაკლისი იხილეთ, მაგალითად, კალეს „A higher Sanskrit grammar“-ში § 211-ში; იქვეა შესაბამისი ადგილები პანინის „Aṣṭādhyāyī“-ში.

ტატპურუშის წინა ნაწილი თეორიულად შეიძლება ყველა კასუსს წარმოადგენდეს. თუმცა, ყველა სინტაქსურად შესაძლებელი კასუსური დამოკიდებულება არ შეიძლება ჩანაცვლდეს ტატპურუშით. შესაბამისი წესები ორგვარ შემთხვევაში იხილეთ კალეს „A higher Sanskrit grammar“-ში § 203 - 217-სა და პანინის „Aṣṭādhyāyī“-ში 2,1,22 - 2,2,22.

::: grammar-box

ტატპურუშის წინა ნაწილი კომპოზიტის გახსნისას შეიძლება იყოს ერთეული, ორეული ან მრავლობითი რიცხვი. რომელი ვარიანტია მოცემული, უნდა დაიშალოს მნიშვნელობისა და კონტექსტიდან.

:::
მაგალითები:

წინა ნაწილი აკუსატს წარმოადგენს (⟪द्वितीया⟫): მაგალითად, ზოგიერთ მოძრაობის ზმნასთან დაკავშირებულ პასიურ მონაწილეებთან (პანინი 2,1,24):

⟪ग्रामगतः⟫ = ⟪ग्रामं गतः⟫ = "სოფლში შესული"  
⟪नरकपतिता⟫ = ⟪नरकं पतिता⟫ = "ნიაღვარში ჩავარდნილი"

წინა ნაწილი ინსტრუმენტალს წარმოადგენს (⟪तृतीया⟫): მაგალითად, ხშირად აგენს (⟪कर्तृ⟫) ნომინალური წარმოებებისთვის კრით-სუფიქსებით (მაგ., პასიური მონაწილეები):

⟪देवकृतम्⟫ = ⟪देवेन⟫ / ⟪देवैः कृतम्⟫ = "ღმერთის მიერ შექმნილი / ღმერთების მიერ შექმნილი"  
ასევე გახსნადია: ⟪देवस्य⟫ / ⟪देवानां कृतम्⟫ = "ღმერთის მიერ შესრულებული / ღმერთების მიერ შესრულებული; ღვთაებრივი საქმე, ღვთაებრივი საქმე"  

⟪बुद्धरक्षिता⟫  = ⟪बुद्धेन रक्षिता⟫ = "ბუდამ რომ დაიცვა" (საკუთარი სახელი)
