# გაკვეთილი 14

## 14.1. ნათესაობითი მიმართულების გამოხატვა სახელებით: გენიტვი (ṣaṣṭhī f. = ⟪षष्टी⟫ = მეექვსე კასუსი)

::: grammar-box
თუ ორი სახელით გამოხატული ნათესაობის მიმართულება უნდა იქნას აღნიშნული, გამოიყენება გენიტვი (ṣaṣṭhī f. "მეექვსე კასუსი"). გენიტვი ყველა სხვა კასუსისგან განსხვავებით იმაში მდგომარეობს, რომ ის — რამდენიმე გამონაკლისის გარდა — არ გამოიყენება ზმნით გამოხატული მოქმედების უფრო დეტალური განსაზღვრისთვის, არამედ გამოხატავს ნათესაობას ადამიანებს შორის ან საგნებს შორის, რომლებიც სახელებით არიან აღნიშნულნი. ხშირად გენიტვი პასუხობს კითხვაზე: ვისი?
:::
მაგალითები:

⟪कवेः पुत्रः⟫ "მწერლის შვილი"

⟪धनस्य लोभः⟫ "მდიდრებისადმი სიყვარული"

⟪नगरस्यार्धम्⟫ "ქალაქის ნახევარი"

⟪रामस्य कृतम्⟫ "რაამას / ერთ-ერთი ქმედება"

::: grammar-box
ნორმალური სიტყვის თანმიმდევრობა არის:

> **გენიტვში მყოფი განმსაზღვრელი სიტყვა — სხვა კასუსში მყოფი განსაზღვრული სახელი**
:::
**გენიტვი და PPP:**

::: grammar-box
PPP-ების შემთხვევაში, გენიტვი შეიძლება გამოიყენებოდეს ინსტრუმენტალის (tṛtīyā) ნაცვლად აგენსის (kartṛ)თვის; ინსტრუმენტალთან ერთად გამოყენებისას, PPP-ი განიხილება როგორც პასიური ზმნის ფორმა (ინსტრუმენტალში მყოფი აღნიშნავს აგენსს), ხოლო გენიტვთან ერთად გამოყენებისას, PPP-ი განიხილება როგორც სახელი ან თანამდებობა (გენიტვში მყოფი არ არის პირდაპირ აგენსი).

პანინის მიხედვით 2.3.67-ში, PPP-თან ერთად გენიტვი გამოიყენება, თუ PPP-ს აქვს პრეზენტული მნიშვნელობა (იხ. ზემოთ), ხოლო ინსტრუმენტალი გამოიყენება, თუ PPP-ს აქვს წარსული მნიშვნელობა:

> ⟪रामस्येष्टं फलम्⟫ „რამას მიერ სასურველი ნაყოფი = ის ნაყოფი, რომელსაც რამა ამჟამად სასურველად მიიჩნევს“
> 
> ⟪रामेणेष्टं फलम्⟫ „ნაყოფი, რომელიც რამას ჰქონდა სასურველი“

ბუნებრივია, რომ PPP ნეიტრალური ერთეულის რიცხვის შემთხვევაში, რომელიც გამოიყენება როგორც ვერბალური აბსტრაქტი — ანუ, როგორც სახელი — გენეტივი გამოიყენება.
:::
## 14.2. გენეტივის ფორმების წარმოქმნა (ṣaṣṭhī f. = ⟪षष्ठी⟫)

გენეტივი წარმოიქმნება ვერბალური ფუძის შემთხვევაში, სუსტი ფუძიდან.

**გენეტივი კონსონანტურად დამთავრებული ფუძის შემთხვევაში:**

::: grammar-box

კონსონანტის შემდეგ არიან რეგულარული გენეტივის დამატებები:
* ერთეული: **-as**
* მრავლობითი: **-ām**

:::

ითვალისწინეთ, რომ კონსონანტით დამთავრებული ფუძეებისთვის აბლატივი და გენიტივის ერთეული რიცხვით ემთხვევა აკუსატივის მრავლობითს მამრობით და დედალი სქესში!

:::
## 14.3. გენიტივის გამოყენების დამატებით (⟪षष्ठी⟫)

::: grammar-box
ზემოთ მოყვანილ ძირითად წესს საპირისპიროდ, გენიტივი გამოიყენება ზოგიერთი ზმნის ობიექტის გამოსახატად, მაგალითად, გახსენების ზმნებში:

> ⟪देवानां स्मरति⟫ "ის ღმერთებს იხსენებს"

თუმცა, ამ ზმნების ყველა შემთხვევაში ობიექტი აკუსატივითაც შეიძლება იყოს:

> ⟪देवान्स्मरति⟫ "ის ღმერთებს იხსენებს"

დამატებითი ინფორმაცია მოგვიანებით.
:::

## 14.5. Subhāṣitāni = ⟪सुभाषितानि⟫ = ზეპირი სიტყვები

გადათარგმნეთ შემდეგი ზეპირი სიტყვები და გაიხსენეთ ისინი:

**⟪नीचो वद⟫ati ⟪न कुरुते⟫** **⟪वदति न साधुः करोत्येव ॥१॥⟫**

**⟪शीलं नरस्य भूषणम् ॥२॥⟫**

**⟪सत्येन जनानां सुखं भवति ॥३॥⟫**

**⟪पापा नराः स्वर्गं न लभन्ते ॥४॥⟫**

**⟪सत्यं लोकस्य दीपः ॥५॥⟫**
