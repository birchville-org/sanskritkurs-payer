## 58.6. აორისტი 5: iṣ-აორისტი

::: grammar-box
**iṣ-აორისტი იქმნება ყველა seṛ ფესვიდან, რომელთათვისაც არ არის მითითებული აორისტის სხვა ფორმის მხოლოდ ერთი გაცნობა.**

**შექმნა:**

**ავგმენტი + ფესვი + i + s + ათემატური მეორადი დანართი**

**!!!** 2. sg.P ანუ 3. sg.P წარმოიქმნება **-**īs ანუ -īt-დან **!!!** (ეს წარმოიქმნა Imperfect-ის გადატანით იგივე ტიპის ფესვებიდან, როგორიცაა ⟪अब्रवीत्⟫; ეს არის ფესვიანი აორისტის ფორმები).
:::
ამიტომ, სტამბილური საფუძველი + iṣ-აორისტის ბოლოებია:

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | **-iṣam** | **-iṣma** | **-iṣi** | **-iṣmahi** |
| **2. ⟪द्वितीयः⟫** | **-īs** | **-iṣṭa** | **-iṣṭhās** | **-**idhvam / :br-iḍhvam:br(სურვილისამებრ -h ან ნახევარხმოვანის შემდეგ) |
| **3. ⟪प्रथमः⟫** | **-īt** | **-iṣur** | **-iṣṭa** | **-iṣata** |

:::
::: grammar-box
**ფესვის ფორმა:**

*   **მოკლე ხმოვანით მარტივი თანხმოსნის წინ: მაღალი ხარისხი P-ში და Ā-ში**
