# დევანაგარი = ⟪देवनागरी⟫

## ხელნაწერის ვარჯიში 1

სანსკრიტი წერია და წერებას აგრძელებს სხვადასხვა ხელნაწერით. შემდეგი სარკე ამ ხელნაწერებიდან მცირე ნაწილს გვიჩვენებს:

![](/images/schrift001.webp)  
სურ.: სანსკრიტის ხელნაწერის ნიმუშები  
\[სურათის წყარო: ვიკიპედია, GNU FD ლიცენზია\]

ყველაზე მნიშვნელოვანი თანამედროვე ჩრდილოეთ ინდური სანსკრიტის ხელნაწერია დევანაგარი:

![](/images/schrift002.webp)

თითოეული თანხმოვნის ნიშანი აღნიშნავს თანხმოვნასთან მიმდევრობით "ა"-ს. თუ სუფთა თანხმოვნის წერა გვინდა (მის შემდეგ ვოკალის გარეშე), ეს უნდა აღვნიშნოთ ქვედა დახრილი ხაზით -- ვირამა = ⟪विराम⟫ -- :

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

თანხმოვნასთან მიმდევრობით მომდევნო ვოკალები -- "ა"-ს გარდა -- ასე იწერება:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

ამ კავშირების წერის თანმიმდევრობა თანხმოვანი + ვოკალია:

![](/images/schrift003.jpg)

წერისას თითოეული ასო, ზედა ხაზის ჩათვლით, სრულდება, მხოლოდ შემდეგ ასოს წერა იწყება.
