# გაკვეთილი 47

## 47.1. ბრძანებითი (⟪लोट्⟫)

::: grammar-box
ბრძანებითი (⟪लोट्⟫) აღნიშნავს

*   **ბრძანებას** (ასევე გამოიხატება გერუნდიუმით (⟪कृत्य⟫))
*   **წესს**
*   **მოთხოვნას**
*   **სურვილს**
*   **მოწვევას**
*   **გაფიქრებას/შეხედვას**
*   **კითხვას**


მითითებული მნიშვნელობები ის ოპტიტვივთან (⟪विधिलिङ्⟫) ერთად აქვს.

ბრძანებითის საშუალებით ასევე გამოიხატება:

*   **ნებართვა**
*   **რომ მოქმედება დროა** (ასევე გამოიხატება გერუნდიუმით (⟪कृत्य⟫))
*   **აბჯღვერის სურვილი**
:::
მაგალითები:

::: indent
⟪एहि ।⟫ "მოდი!"

⟪ग्रामं भवानागच्छतु ।⟫ ან ოპტიტვივი: ⟪ग्रामं भवानगच्छेत् ।⟫ "მოდი სოფელში!"

⟪वेदमध्ययै ।⟫ ან ოპტიტვივი: ⟪वेदमधीयीय ।⟫ "მინდა ვედი შევისწავლო."

⟪इच्छामि भुङ्क्तां भवान् ।⟫ ან ოპტიტვივი: ⟪इच्छामि भुञ्जीत भवान् ।⟫ "სურვილია, ჭამონ."

⟪किं वेदमध्ययै ।⟫ ან ოპტიტვივი: ⟪किं वेदमधीयीय ।⟫ "უნდა შევისწავლო ვედი?"

⟪करोतु शस्त्रं भवान् ।⟫ ან გერუნდივი: ⟪भवता शस्त्रं कर्तव्यम् ।⟫ "აკეთე ხოჭი!" ; "შენ შეგიძლია ხოჭის დამზადება." ; "დროა, ხოჭი გააკეთო."

⟪चिरं जीवतु भवान् ।⟫ "გრძელი იყოს შენი ცხოვრება!"
:::
::: grammar-box
вежливый ბრძანებები ხშირად გამოიხატება პასიური ბრძანებით.
:::
მაგალითები:

::: indent
⟪भवता प्रविश्यताम् ।⟫ "შედი **გთხოვ**!"

⟪निषद्यताम् ।⟫ "გთხოვ, დაჯექი!"
:::
კლასიკური სანსკრიტის ბრძანებითში პირველი პირის ფორმები არიან ძველი კონჟუნქტივის ფორმები. ვედაური კონჟუნქტივი არის ძირითადად მოდი, რომელიც სურვილს გამოხატავს: "ჩვენ გვინდა წასვლა!" "წავედით!"

::: grammar-box
Imperativი წარმოიქმნება პრეზენდის ფუძიდან.
:::

## 47.3. ვარჯიში

A) თარგმნეთ:

⟪यदि गच्छसि गच्छ त्वम् । अहं न गमिष्यामि ॥१॥ आर्य प्रेक्षस्व मे परिभवम् ॥२॥ भो राम यदि मया गन्तव्यं तदैषा कन्यापि मम सहायिनी भवतु ॥३॥⟫

::: media
![](/images/lekt4703.webp)
სურ.: ⟪भो राम यदि मया गन्तवं तदैषा कन्यापि मम सहायिनी भवतु⟫
(სურათის წყარო: [დეტალები](/ka/licenses#lekt4703))
:::
⟪आर्ये तिष्ठ तिष्ठ । न त्वया भेतव्यम् ॥४॥ प्रसीदत्वार्यः ॥५॥ आर्ये स्वागतं ते ॥६॥⟫

::: media
![](/images/lekt4704.webp)
სურ.: ⟪आर्ये स्वागतं ते⟫
(სურათის წყარო: [დეტალები](/ka/licenses#lekt4704))
:::
⟪आज्ञापयत्वार्यः किं मया क्रियतामिति ॥७॥ युद्धाय युज्यस्व नैवं पापमवाप्स्यसि ॥८॥ प्रश्नः⟫ : ⟪कस्मात्त्वं भीतः । प्रतिवचनम्⟫ : ⟪तस्य रामस्य गुणेभ्यः । प्रष्टा⟫ : ⟪के तस्य गुणा यस्य गृहं प्रविश्याशितव्यमपि नास्ति ॥९॥ तवैव हस्ते शस्त्रं तिष्ठतु ॥१०॥ भवति न ते परिभवस्तत्रभवतो रामस्य निवेदयितव्यः ॥११॥⟫

B.) თარგმნეთ სანსკრიტზე (გამოიყენეთ იმპერატივი):

1. მე გვინდა, რომ მივიღო.

2. მას კმაყოფილი უნდა იყოს.

3. ჩვენ გვინდა, რომ დავუძახოთ.

4. მე გვინდა, რომ შეგეწიო (⟪चतुर्थ्या⟫).

5. ეს საქმე შესრულებული უნდა იყოს.

6. ისინი უნდა დაიძინონ (პასიური კონსტრუქცია).

7. ჩემი ვაჟი სიმდიდრეს ეძებოს!

8. დაიწყეთ სწავლა!

9. (⟪प्र⟫-⟪यम्⟫) მიაწოდეთ წინაპრებს ბრინჯის გუნდები!

10. ისინი უნდა გახარდნენ!

11. მე გვინდა, რომ სამყაროსკენ დავიხედო.

12. ჩვენ გვინდა, ბენარესში წავიდეთ (⟪पद्⟫).

13. ისინი (მრავლობითში) უნდა იყვნენ საკუთარი მსხვერპლის მეშვეობით ღმერთების პატივისცემის მსხვერპლის ხელმძღვანელები.

14\. აქეშენი ლოცვა!

15\. ჩემთვის შვილები უნდა დაიბადონ!

16\. შენთვის ჩემს სახლს გავაჩენ.

17\. წადი ჩემგან!

18\. ის უნდა გათავისუფლდეს!

19\. შენს მეუღლეზე დაცვას გიწევს.

20\. მოკვდი, მტერო!

21\. იბრძვეთ!

22\. ისინი (მრავლობითში) უნდა ბრძანებდნენ.

23\. ჩვენ შენი სახლში უნდა ვიცხოვროთ.

24\. ასე უნდა მოხდეს!

25\. დაარტყი ცხენს!

26\. ისინი (მრავლობითში) უნდა დაუკარგონ გზა.

27\. ათვინიერდით!

28\. ცხენმა უნდა გადაიტანოს ტვირთი.

29\. ჩვენ სამყაროები უნდა მოვაწყოთ.

30\. დალიე სასმელი!

31\. იფიქრე!

32\. ისინი (მრავლობითში) უნდა დამარცხდნენ!

33\. ჩვენ შენი მიერ უნდა ვიქნეთ გაყვანილი.

34\. იყოს კარგი! (სასურველი სიტყვა)
