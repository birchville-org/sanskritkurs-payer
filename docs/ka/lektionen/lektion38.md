## 38.6. ⟪आत्मन्⟫に関する統語論

::: grammar-box
⟪आत्मन्⟫ **男性**は、**単数形**において、三つの性（性別）、数（双数および複数を含む）、人称のすべてに対して再帰代名詞（自己参照代名詞）として使用することができます。
:::
例：

::: indent
⟪आत्मन्येषा दोषं न पश्यति ।⟫ 「彼女は自分自身に欠陥を見出さない」

⟪आत्मानं स्तुवन्ति ।⟫ 「彼らは自分自身を称賛する」
:::
::: grammar-box
属格（⟪षष्ठी⟫）⟪आत्मनस्⟫は、「私自身の／あなた自身の／彼自身の／…」を意味するために置かれることがあります。
:::
例：

::: indent

## 38.7. 子音で終わる語幹を複合語の前半要素とする場合

::: grammar-box

:::

::: grammar-box
