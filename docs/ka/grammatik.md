# გრამატიკის თემები

ეს გვერდი სისტემატურ მიმოხილვას აწარმებს სამსკრიტის კურსის ყველა გრამატიკული თემის შესახებ. აქ 61-ვე გაკვეთილი თემატურად არის დაჯგუფებული.

## 4. მეტრიკა (ვერსიფიკაციის სახელოვნებო წესები)

*   **შესავალი და Śloka** -\> [ლეკცია 45](/ka/lektionen/lektion45), [ლეკცია 53](/ka/lektionen/lektion53)
