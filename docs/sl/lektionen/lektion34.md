# Učbenik 34

## 34.1. Perfekt (⟪लिट्⟫)

V klasičnem sanskrtu obstajata iz korena perfekta le indikativ in particip.

::: grammar-box
**Obstajata dve vrsti tvorbe perfekta:**
*   **reduplicirani perfekt = ⟪द्वित्वलिट्⟫**
*   **perifrazni perfekt = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Perifrazni perfekt (⟪अनुप्रयोगलिट्⟫) se uporablja:**
1. **pri izpeljanih konjugacijah (kauzativ, desiderativ, frekventativ, denominativa)**
2. **pri korenih, ki se začnejo z dolgim samoglasnikom (razen ā-) oziroma s samoglasnikom (razen a-) pred dvema soglasnikoma**
3. **pri nekaterih drugih korenih**
:::
## 34.2. Reduplicirani perfekt (⟪द्वित्वलिट्⟫)

### 34.2.1. Stopnjevanje korena

::: grammar-box
**Tvorba:**

**močan koren:** ednina Parasmaipada
*   **reduplicirani koren v stopnji guṇa oziroma v stopnji dīrgha + končnica perfekta**

**šibek koren:** vse ostale oblike
*   **reduplicirani koren v stopnji zero + končnica perfekta**
:::
::: grammar-box
**Načeloma (tudi zunaj perfekta) nimajo stopnjevanja korena koren oblike:**
*   **(soglasnik)-soglasnik-dolg-samoglasnik-soglasnik**
*   **(soglasnik)-soglasnik-samoglasnik-soglasnik-soglasnik**

**V perfektu poleg tega nimajo stopnjevanja korena koren oblike:**
*   **a-soglasnik**
*   **ā-soglasnik**
:::
### 34.2.2. Končnice perfekta

::: grammar-box

| | 3. ednina | 3. množina |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |

:::
### 34.2.3. Povezovalni samoglasnik -i-

::: grammar-box
**Pred končnico 3. množine Ā (-re) vedno pride povezovalni samoglasnik -i-, pred drugimi soglasniško se začinjajočimi končnicami pri večini korenov.**
:::
### 34.2.4. Reduplikation konsonantisch anlautender Wurzeln

::: grammar-box
**Za reduplikacijo začetnih soglasnikov veljajo pravila, podana v [Lekciji 33](lektion33.md).**

**Reduplikacijski samoglasnik pri korenih, ki se začenjajo s soglasnikom, je kratki korenski samoglasnik.**

**Diftongi pred soglasniki se zmanjšajo z ustreznim kratkim nizostopenjskim samoglasnikom.**

**ṛ, ṝ, ḷ in končni dvoglasniki se reduplicirajo z -a-.**
:::
Primeri:

::: grammar-box

| Wurzel | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::
::: grammar-box
**Nekateri koreni, ki se začenjajo z y- oziroma v-, se reduplicirajo z i- oziroma u-, ki se v šibkih oblikah "zlije" s korenskim samoglasnikom.**
:::
Primeri:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Reduplikation vokalisch anlautender Wurzeln

::: grammar-box
**1. Začetni a-, ā- se reduplicira z a-, tako da se pojavi ā-.**
:::
Primeri:

::: grammar-box

| Wurzel | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "sein" und ⟪अस्⟫ 4 "werfen" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. Koreni z začetnim i- imajo kot reduplikacijski zlog v močnem deblu iy-, v šibkem deblu i-, ki se zlije s korenskim samoglasnikom v ī-. Analogno velja za začetni u-.**
:::
Primeri:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. Koreni, ki se začenjajo z a- pred dvema soglasnikoma ali z ṛ-, imajo kot reduplikacijski zlog ān-**
:::
Primeri:

::: grammar-box

| Korenina | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. Vrste redupliciranega perfekta

Načelo razvrščanja: Posebnosti stopnjevanja korena:
*   Perfekt brez stopnjevanja korena: Tip I
*   Perfekt s stopnjevanjem korena: Tip II - V
*   Nepravilne tvorbe perfekta

## 34.4. Perfekt Tip I: Perfekt brez stopnjevanja korena

::: grammar-box
**Perfekt Tip I (brez stopnjevanja korena) tvorijo korenine tipov:**
*   **(Soglasnik)-Soglasnik-Dolgokroglik-Soglasnik**
*   **(Soglasnik)-Soglasnik-Kroglik-Soglasnik-Soglasnik**
*   **a-Soglasnik**
*   **ā-Soglasnik**
:::
Primeri:

::: grammar-box

| :--- | :--- | :--- |

| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |

| ⟪अश्⟫ | ⟪आनशे⟫:brunregelmässige Reduplikation! | ⟪आनशिरे⟫ |

:::
