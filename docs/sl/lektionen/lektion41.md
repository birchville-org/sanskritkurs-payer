## 41.2. Druge ⟪कृत्⟫-tvorbe na -a

### 41.2.1. Particip pretekli (⟪लडादेशः⟫) Ā, particip pasivni (⟪लडादेशः⟫), particip prihodnji (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Tematski prezentski koreni, pasiv in prihodnost

::: grammar-box
**Tvorba:**

Prezentski koren / pasivni koren / prihodnji koren + -māna (ž. r. mānā)
:::
Primeri:

⟪यज्⟫ 1U, Part.Präs.Ā ⟪यजमान⟫ 3 "nekdo, ki časti z darom v svojem lastnem interesu = gospodar žrtve"

⟪मन्⟫ 4Ā, Part.Präs.Ā ⟪मन्यमान⟫ 3 "nekdo, ki razmišlja"

⟪कृ⟫ 8U, Part.Präs.Passiv ⟪क्रियमाण⟫ 3 "nekaj, kar se naredi"

⟪दा⟫ 3U, Part.Fut.Ā ⟪दास्यमान⟫ 3 "nekdo, ki bo dal v svojem lastnem interesu"

#### 41.2.1.2. Atamatski prezentski razredi

::: grammar-box
**Tvorba:**

Šibek prezentski koren (v obliki, ki jo ima pred končnico -ate 3. pl. Ā) + -āna (ž. r. -ānā)
:::
Primeri:

::: grammar-box
| Koren / Razred | Particip pretekli Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "Partizip" pasivne nujnosti (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Za izražanje pasivne nujnosti ("kar je treba/narediti/mora biti storjeno") lahko pridevnike iz korenin in deriviranih glagalskih korenov po izbiri tvorimo z naslednjimi sufiksi:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (namesto **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Sufiks -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Sufiks -⟪तव्य⟫ / -⟪तव्या⟫ se na korenine in derivirane glagalske korene (npr. kauzativ) dodaja na enak način kot infinitivni sufiks -⟪तुम्⟫ (glej [Lektion 23](lektion23.md)), to je**

* **stopnjen koren + ⟪तव्य⟫**

ali

* **stopnjen koren + -i- + ⟪तव्य⟫**

**V kauzativu:**

* **Kauzativni koren na -ay + -i- + ⟪तव्य⟫**
:::
Primeri:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "nekdo, ki ga je treba premagati; tisti, ki ga je treba premagati" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "tisto, kjer se je treba nahajati" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "nekdo, ki ga je treba zbuditi; tisti, ki ga je treba zbuditi" |

:::
#### 41.2.2.2. Sufiks -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Tvorba:**

Stopnjen koren + -⟪अनीय⟫ / -⟪अनीया⟫

**Kauzativ in 10. prezentska klasa:**

Koren, kot se pojavi v kauzativnem korenu, brez -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Primeri:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "tisto, kar je treba dati; kar mora biti podano" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "tisti, ki ga je treba premagati" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "tisto, kar je treba storiti" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "kar je treba videti; vredno ogleda" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "nekdo, ki ga je treba zbuditi" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "kar je treba dati" |

:::
#### 41.2.2.3. Suffix -⟪य⟫ / -⟪या⟫

::: grammar-box
**Oblikovanje:**

Koren (v globokem, visokem ali zategnjenem stopnju) + -⟪य⟫

Natančna pravila glej pri Kielhornu, Grammatik der Sanskrit-Sprache, str. 195 - 197!
:::
Obravnava končnih samoglasnikov:

::: grammar-box
**1. Koreni na -ā tvorijo to gerundiv obliko na -eya**

### 41.2.3. Sintaktične značilnosti "particija" pasivne nuje (gerundivum) (⟪कृत्य⟫)

::: grammar-box

### 41.2.4. Razlike v rabi pripon gerundiva

::: grammar-box
Raba teh pripon se v veliki meri prekriva

* **-⟪तव्य⟫ (fem. -⟪तव्या⟫):** vedno izraža nujo in se raje uporablja predikativno (redkeje atributivno). Tvorbe s to pripono se ne smejo uporabljati v nominalnih kompozitih.
* **-⟪अनीय⟫ (fem. -⟪अनीया⟫) in -⟪य⟫ (fem. -⟪या⟫) / -⟪त्य⟫ (fem. -⟪त्या⟫) (namesto -⟪य⟫/-⟪या⟫):** lahko imajo dodatno pomen (zlasti -⟪य⟫) v smislu nemškega "-wert" (npr. "vreden ogleda") ali le možnosti "-bar" (⟪दृश्य⟫ "viden"). Tvorbe s temi priponami se lahko z ⟪अ⟫-/-⟪अन्⟫- zanikajo (ne pa tvorbe z -⟪तव्य⟫) in obstajajo ⟪तत्पुरुष⟫ kot njihovi zadnji členi, v katerih se pojavljajo.
:::
### 41.2.5. Brez povezave z ⟪सु⟫- in ⟪दुस्⟫-

::: grammar-box
Z ⟪सु⟫- in ⟪दुस्⟫- v pomenu "lahko" oziroma "težko" se gerundivi ne smejo povezovati. Namesto tega stojijo ⟪तत्पुरुष⟫ tipa  ⟪सुकर⟫ 3 ("lahko storiti") (glej [Lektion 18](lektion18.md)).
:::
