# Ura 43

## 43.1. Osebne končnice druge osebe (⟪मध्यमः⟫ = "srednja ⟨oseba⟩")

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Primarne končnice** | -si | -tha | -se | -dhve |
| **Sekundarne končnice** | -s | -ta | -thās | -dhvam |
| **Končnice perfekta** | -tha | -a | -se | -dhve |
:::
Upoštevajte, da je sekundarna končnica 2. osebe množine enaka sekundarni končnici 3. osebe ednine aktivnega glagolskega načina.

| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |

| ⟪चतुर्थी⟫ | ⟪तुभ्यम् ते⟫ | ⟪युष्मभ्यम् वस्⟫ |

::: indent
⟪त्वां मां च⟫ "tebe in mene"
:::
