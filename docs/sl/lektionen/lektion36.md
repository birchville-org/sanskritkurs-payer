## 36.2. Perifrazni perfekt (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
Perifrazni perfekt (⟪अनुप्रयोगलिट्⟫) se uporablja:

1. pri izpeljanih konjugacijah (kausativ, desiderativ, frekventativ, denominativa)
2. pri korenih, ki se začnejo z dolgim samoglasnikom (razen ā-) oziroma s samoglasnikom (razen a-) pred dvema soglasnikoma
3. pri nekaterih drugih korenih
:::
::: grammar-box
**Oblikovanje:**

(šibki) prezentski koren + -ām + ustrezna perfektne oblike ⟪कृ⟫, ⟪अस्⟫ ali ⟪भू⟫

Končni samoglasnik korena se pred -ām guunira.
⟪अस्⟫ in ⟪भू⟫ se konjugirajo tudi pri glagolih Ātmanepada v Parasmaipada.
:::
Perifrazni perfekt je verjetno nastal iz akuzativa glagolske imenice na -ā. Ta akuzativ se uporablja — kot je sicer pogosto — adverbialno.
