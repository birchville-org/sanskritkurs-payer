## 48.3. O tvorbi imen: sufiksi ⟪तद्धित⟫ -a in -ya

::: grammar-box
S sufiksom **-a** in (redkeje) **-ya** lahko iz enega imenika dobimo drugo ime. Pri tem dobi prvi slog prvotnega imena podaljšano stopnjo (⟪वृद्धि⟫). Če se prvotni koren besede že konča na **-a**, je ⟪वृद्धि⟫ edina oznaka tvorbe, saj se na koncu korena nič ne spremeni.

Izpeljane besede imajo pomen:

> "imajo neko povezavo s tistim, kar označuje osnovna beseda"

npr.

*   "izvaja iz"
*   "pristaja k"

Tako tvorjene besede so pridevniki, lahko pa se uporabljajo kot samostalniki, npr. kot patronimika (tvorba imen po očetu: "sin N.N.") ali abstrakta (večinoma srednjega spola).
:::
Primeri:

::: indent
| Osnovna beseda | Izpeljanec |
| :--- | :--- |
| ⟪शुचि⟫ 3 "svetleč, čist" | ⟪शौच⟫ n. "čistost" |
| ⟪पुत्र⟫ m. "sin" | ⟪पौत्र⟫ m. "izvaja iz sina = sinov sin, vnuk" |
| ⟪गोतम⟫ m. "lastnik zelo velikega števila govedi" lastno ime | ⟪गौतम⟫ m. "sin Gotame" |
| ⟪ब्रह्मन्⟫ n. "oblikovana resnica, Veda, absolutno" | ⟪ब्राह्मण⟫ m. "oblikovalec resnice, brahman" |
| ⟪शूर⟫ 3 "junaško" | ⟪शौर्य⟫ n. "junaštvo, pogum" |
| ⟪राजन्⟫ m. "kralj" | ⟪राज्य⟫ n. "kraljevanje" |
| ⟪देव⟫ m. "nebesni, bog" | ⟪दैव्य⟫ 3 "nebesen" |
| ⟪ग्राम⟫ m. "vas" | ⟪ग्राम्य⟫ 3 "vaški" |
:::
::: grammar-box
| **Obdelava konca korena pred sufiksom \-a:** ||
| :---: | :--- |
| **\-ṛ** | **\-a** se običajno doda na konec **\-r**: npr. ⟪जेतृ⟫ "zmagovalec" » ⟪जैत्र⟫ 3 "zmagovit" |
| **\-a** | Nadomestitev **\-a** osnovne besede z novim sufiksom **\-a**. primeri glej zgoraj. |
| **\-i** | Izpustitev **\-i**: npr. ⟪प्रकृति⟫ f. "narava" » ⟪प्राकृत⟫ 3 "naraven, normalen, običajen, vulgaren" |
| **\-u** | večinoma: **\-av-a**: npr. ⟪गुरु⟫ 3 "težek"; m. "gospodar, učitelj" » ⟪गौरव⟫ 3 "pristaja k gospodarju, izvaja iz učitelja"; n. "teža, težavnost, dostojanstvo" |
| **drugi sklonilni koreni:** | glej Wackernagel, Altind. Grammatik II,2 § 38 |

Pred sufiksom **-ya** se končnica osnove obravnava podobno kot pred sufiksom **-a**.
:::
Primeri glej zgoraj!

::: grammar-box
**S temi sufiksi je mogoče tvoriti derivacije tudi iz samostalnih besed (kompozitov).**

npr. ⟪स्वश्व⟫ m. "tisti, katerega konji so dobri" lastno ime » ⟪सौवश्व⟫ m. "potomca Svaśve"

**Pri kompozitih, kjer se zaradi sandhija na koncu prvega dela -i ali -u nadomesti z -y oziroma -v in tako predhodita prvemu samoglasniku osnovne besede (npr. kompoziti z ni-, vi-, su-), se ⟪वृद्धि⟫ tvori tako, kot bi stalo -iy oziroma -uv.**

npr. ⟪व्याघ्र⟫ m. "tiger" » ⟪वैयाघ्र⟫ 3 "izviren od tigra, pripadajoč tigrju"
:::

## 48.5. Vaja

A) Prevajajte ⟪सुभाषितानि⟫ na začetku lekcije.

B) Prevajajte v sanskrt (uporabite imperativ in po možnosti korene 2. in 3. prezentskega razreda):

1. Ko si dobil sina, zapusti družino!
2. Potomci Puruja, bojte se tistih, ki so storili zlo!
3. Dekleta naj dajejo hrano prosjakom.
4. Govoriti želimo.
5. Z besedami "Pridi, menih!" je Budda sprejel moža v red (⟪उपसम्पद्⟫ kausativ).
6. Bodite pravi potomci Manuja!
7. Želim ⟪शिव⟫ in druge bogove slaviti.
8. Povej!
9. Izmerite pekel!
10. Oni (mn.) naj ležijo na teh posteljah.
11. Tigru podobni možje naj ubijejo tiste, ki so Indri sovražni.
12. Osredotoči se!
13. Sedite tukaj!
14. Te sadeže jesti želimo.
15. Služabnik naj doji kravo.
16. Kralj, varuj dharma in ljudstvo.
17. Uči učence Vedo!
18. Nove obleke si naj oblači.
19. Oni (mn.) naj sedijo v mojem domu.
20. Možje naj vzdržujejo svoje žene (v pomenu preživljanja).
