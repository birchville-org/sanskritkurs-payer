# Ura 4

## 4.1. Preprosta dopolnilna vprašanja (besedna vprašanja) in odgovori

### 4.1.1. Vprašalna in kazalna zaimka

#### 4.1.1.1. Vprašalna zaimka (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Nominativ singular | Nominativ plural |
| :--- | :--- | :--- |
| **Neutrum** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Maskulinum** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Feminimum** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Kazalna zaimka (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Stems** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"on, ona, to; tisti, tista, tisto":br(Omenjeno)** | **etad = ⟪एतद्⟫:br"ta, ta, to":br(Zelo blizu govorniku)** | **idam = ⟪इदम्⟫:br"ta, ta, to":br(Bližina)** |
| **Nominativ singular** ||||
| **Neutrum** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Maskulinum** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Femininum** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Nominativ plural** ||||
| **Neutrum** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Maskulinum** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Femininum** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**Za nom. sg. mask.:**
**sa, eṣa** (⟪स एष⟫) stoji pred vsemi glasovi razen kratkim **-a**
**so, eṣo** (⟪सो एषो⟫) stoji pred **-a**, ki se z Avagraha elidira (izpusti)
**saḥ, eṣaḥ** (⟪सः एषः⟫) stoji le v pauzi (konec stavka, konec verza)

Ker naj bi se stavki tvorili s temi zaimki (sarvanāman n.), je potrebno poznavanje naslednjih pravil sandhija:

### 4.1.2. Sandhi končnega -m

::: grammar-box
**Končni -m se pred soglasniki nadomesti z anusvāro (-ṃ). Na koncu stavka ali verza in pred samoglasniki ostane -m ohranjen.**
:::
### 4.1.3. Sandhi končnega -e

::: grammar-box
1. **pred a- ostane -e nespremenjen: začetni a- se elidira z avagraho:**
npr. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Ti ognji"

2. **Pred drugimi samoglasniki kot kratkim a- se -e običajno nadomesti z -a z hiatusom. Pojavi se tudi nadomestitev z -ay:**
npr. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (redko: imay īśvarāh = ⟪इमयीश्वराः⟫) "Ti GOSPODJE"
:::
### 4.1.4. Sandhi končnega -d

::: grammar-box
**Končni -d se v pavzi ter pred nezvočnimi guturali (k, kh) in labiali (p, ph) nadomesti s -t.**

Nadomestitev pred drugimi soglasniki bo obravnavana kasneje. Zaenkrat se izogibajte takšnim zvočnim trkom!
:::
### 4.1.5. Vprašalne oblike

S pomočjo teh zaimkov se tvorijo npr. naslednje vprašalne oblike:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Singular** | **Neutrum** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं किम्⟫, ⟪किमिदम्⟫ | "Was ist das?" |
| ^^| **Maskulinum** | sa kaḥ? / kaḥ saḥ?:br⟪स कः⟫, ⟪कः सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष कः⟫, ⟪क एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं कः⟫, ⟪को ऽयम्⟫ | "Wer ist das?":br"Was ist der?" |
| ^^| **Femininum** | sā kā? / kā sā?:br⟪सा का⟫, ⟪का सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं का⟫, ⟪केयम्⟫ | "Wer ist das?":br"Wer ist die?" |
| **Plural** | **Neutrum** | tāni kāni? / kāni tāni?:br⟪तानि कानि⟫, ⟪कानि तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि कानि⟫, ⟪कानीमानि⟫ | |
|^^ | **Maskulinum** | te ke? / ke te?:br⟪ते के⟫, ⟪के ते⟫:brete ke? / ka ete?:br⟪एते के⟫, ⟪क एते⟫:brime ke? / ka ime?:br⟪इमे के⟫, ⟪क इमे⟫ | |
| ^^| **Femininum** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः काः⟫, ⟪का एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः काः⟫, ⟪का इमाः⟫ | |

Primer drugih vprašanj:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ Odgovor: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (Pri nominalnem stavku lahko na primer postavimo subjekt na začetek, da poudarimo povezavo s vprašanjem.)

OPOMBA: Odgovori, ki jih lahko na takšna vprašanja podate s svojimi dosedanjimi znanji sanskrt, se seveda še ne ujemajo povsod s stilsko dobro sanskritščino.


## 4.2. Vaje

**A) Ustno sestavite vprašanja po vzorcu viṣṇuḥ kaḥ (⟪विष्णुः कः⟫) z naslednjimi besedami in odgovorite na vprašanja v sanskrtu:**

śruti, śiva, brāhmaṇa, dvija (množina), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫
