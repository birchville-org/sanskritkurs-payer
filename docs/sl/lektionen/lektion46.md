# Ura 46

## 46.1. Oblikovanje glagolskih oblik druge osebe (⟪मध्यमः⟫) Perfekt (⟪लिट्⟫)

### 46.1.1. Končnice

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :---: | :---: | :---: | :---: |
| **Končnice perfekta** | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| ^^ \-tha | \-a | \-se | \-dhve |

:::

Upoštevajte, da se končnica -- večinoma ne pa oblika! -- 2. osebe množine perfekta ujema s končnico 1. in 3. osebe ednine perfekta.

::: grammar-box

Pred -tha pri večini korenov na -ṛ ni vmesnega samoglasnika \-i-. Pri nekaterih korenih je pred \-tha -i- fakultativen.

:::

### 46.1.2. Zvočna sprememba končnice -dhve

::: grammar-box

Končnico -dhve je treba v perfektu nadomestiti z -ḍhve, če ji neposredno predhaja korensko -u ali -ṛ. To nadomestitev je mogoče izvesti tudi po vmesnem samoglasniku -i-, če mu neposredno predhaja polglasnik ali h.

:::

### 46.1.9. Perifrazno perfekt (⟪अनुप्रयोगलिट्⟫)

Perifrazno perfekt se tvori iz:

*   izvedenih glagalskih korenov (kauzativ, desiderativ, frekventativ, denominativa), zlasti kauzativ
*   korenov, ki se začnejo z dolgim samoglasnikom (razen ā)
*   korenov: samoglasnik (razen a-)-suglasnik-suglasnik
*   nekaj drugih
*   pri nekaterih korenih se lahko oba perfekta tvorita opcionalno: uṣ "goreti", vid "vedeti", jāgṛ "bdeti", daridrā "biti reven"
*   pri naslednjih korenih se lahko oba perfekta tvorita opcionalno in je tudi perifrazno perfekt reduplicirano, in sicer z reduplikacijsko slogom prezentskega korena:
*   bhī "bati se"
*   bhṛ "nositi"
*   hu "žrtvovati"
*   hrī "sramovati se"
