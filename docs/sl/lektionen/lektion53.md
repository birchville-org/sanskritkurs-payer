# Ura 53

## 53.1. Dvojina (⟪द्विवचन⟫ n.) imen

::: grammar-box

**Dvojina (⟪द्विवचनम्⟩) se uporablja za označevanje "dveh":**

:::

::: indent

⟪अश्विनौ⟫ "obajta Aśvin"

:::

**Uporaba dvojine je obvezna tam, kjer gre za dve stvari itd.:**

::: indent

⟪हस्तौ⟫ "roke (posameznika)"
⟪पादौ⟫ "stopala (človeka, opice ali druge dvonožne živali)"

:::

**Včasih dvojina označuje moški in ženski primer iste vrste (vrsta, rod):**

::: indent

⟪पितरौ⟫ "oče in mati = starši"

:::

**Besede, ki pomenijo "par" - npr. ⟪युग⟫ n., ⟪द्वन्द्व⟫ n., ⟪द्वय⟫ n. - se vedno uporabljajo v ednini, razen če gre za dva ali več parov:**

::: indent

⟪बाहुद्वयम्⟫ "par rok"

:::

## 53.5. Dvandva (dvojina)

Primeri:

::: indent

⟪अर्थधर्मौ⟫ "korist (⟪अर्थ⟫) in dharma"
⟪युधिष्ठिरार्जुनौ⟫ "Yudhiṣṭhira in Arjuna"
⟪सुखदुःखे⟫ (poleg: ⟪सुखदुःखम्⟫) "sreča in nesreča"
⟪शीतोष्णे⟫ "hladno in toplo"

:::

::: grammar-box

**Če se dve besedi za sorodstvo na -ṛ (ali dve samostalniški besedi na -ṛ, ki označujeta žrtvenega duhovnika) združita v dvandvo, stoji prva členica v obliki nominativa singulara:**

:::

::: indent

⟪मा⟫:sig[⟪ता⟫]⟪पितरौ⟫ "mati in oče"

:::

**Enako se zgodi s takšno besedo za sorodstvo v dvandvi pred -⟪पुत्र⟫ :**

::: indent

⟪पितापुत्रौ⟫ "oče in sin"

:::

**Če imena dveh božanstev, ki se običajno omenjata pri žrtvovanju, tvorita dvandvo, se običajno podaljša zadnji samoglasnik prve členice:**

::: indent

⟪मि⟫:sig[⟪त्रा⟫]⟪वरुणौ⟫ "Mitra in Varuṇa"
⟪अग्नीसोमौ⟫ "Agni in Soma"

:::

**Tudi pri drugih dvandvah se pojavi to podaljšanje samoglasnika.**

### 53.10.3. Metrična kvantiteta zlogov

::: grammar-box

**Mnemski verz**

:::

::: indent

⟪सानुस्वारश्च दीर्घश्च विसर्गी च गुरुर्भवेत् । वर्णः संयोगपूर्वश्च तथा पादान्तगो ऽपि वा ॥⟫

:::

"En zlog je težek,

*   če ima njegov samoglasnik anusvāro,
*   je dolg,
*   ima visargo,
*   prav tako pa stoji pred soglasniško skupino
*   ter če zlog stoji na koncu četrtine verza (pāda)."

::: grammar-box

**En zlog je**

*   bodisi **⟪लघु⟩ = lahek**
*   bodisi **⟪गुरु⟩ = težek**

**⟪लघु⟩ = lahek je zlog, če**

*   njegov samoglasnik kratek je in temu samoglasniku
*   kein Anusvāra,
*   ne sledi visarga,
*   ne sledita dve soglasnici.

Kratki samoglasniki so a, i, u, ṛ, ḷ

**Vsi ostali zlogi so ⟪गुरु⟩ = težki. Zadnji zlog četrtine verza (⟪पाद⟩) velja vedno kot ⟪गुरु⟩.**

*   **◡** = ⟪ल⟩ = ⟪लघु⟩
*   **—** = ⟪ग⟩ = ⟪गुरु⟩
*   **×** = ⟪लघु⟩ ali ⟪गुरु⟩
