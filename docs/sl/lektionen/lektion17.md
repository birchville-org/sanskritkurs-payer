# Ura 17

## 17.1. Druga klasa prezensa (⟪अदादि⟫ = ⟪अद्⟫ itd.)

Glagolske končnice se neposredno pritrdijo na koren. Pri tem je treba upoštevati zvočne spremembe, ki izhajajo iz besednega sandhija.

::: grammar-box

V drugi klasa prezensa obstajajo naslednje tvorbeni oblike:

1. Koreni z ablacijo osnove 
*   večinoma: stopnja dviga - nizka stopnja
*   nekateri koreni: dolga stopnja - nizka stopnja 
2. Koreni brez ablacije osnove 
3. Dvosložni koreni na -i/-ī z ablacijo osnove

:::

## 17.5. Dvosložni koreni na -i/-ī z razlikovanjem glasu

Nekateri koreni so v vrsti oblik dvosložni, to je imajo pred soglasniško končnico -i (oziroma pred nekaterimi končnicami -ī). Vendar jih domači gramatiki in slovarji itd. kljub temu obravnavajo kot enosložne.

Primeri:

⟪रुद्⟫ 2 P "jokati, tuliti"

*   močan prezentski koren: rodi-
*   šibek prezentski koren:
*   pred soglasnikom: rudi-
*   pred samoglasnikom: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. os. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. mn. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "govoriti"

*   močan prezentski koren: bravī- (« bro- + -ī)
*   šibek prezentski koren:
*   pred soglasnikom: brū-
*   pred samoglasnikom: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. os. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. mn. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. os. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. mn. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
