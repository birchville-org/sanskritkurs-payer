# Ura 57

## 57.1. Aorist 4: s-Aorist

::: grammar-box
**s-Aorist se tvori k večini ⟪अनिट्⟫ korenov, razen če ti nimajo izključno druge oblike aorista. Fakultativne ⟪अनिट्⟫ korenine lahko na splošno izbirno tvorijo to ali iṣ-Aorist. Tudi ⟪अनिट्⟫ korenine, ki tvorijo ⟪परस्मैपद⟫ po 1., 2. ali 6. obliki aorista, tvorijo ⟪आत्मनेपद⟫ po s-Aoristu.**

**Tvorba: Augment + korenina + s + atemska sekundarna končnica**
:::
Tabela končnic s sufiksom za tvorbo korena

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟫** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟫** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**Uporabi se splošno zvočno pravilo, da med dvema zaprtima soglasnikoma odpade frikativ (glej ⟪उद्⟫ + ⟪स्थित⟫ » ⟪उत्थित⟫), to pomeni, da sufiks za tvorbo korena -s- pred končnicami, ki se začnejo z -t- ali -th-, odpade (vendar ne po nazalih ali r-).**

Primeri:

:::
::: indent
3.sg.Ā a-kṣip + s + ta » ⟪अ⟫:sig[⟪क्षिप्त⟫]
2.sg.Ā a-kṣip + s + thās » ⟪अ⟫:sig[⟪क्षिप्था⟫]⟪स्⟫
:::
Take oblike bi lahko spadale tudi k korenskemu aoristu in verjetno delno tudi res spadajo tja.
Indijski gramatiki so šteli med s-Aorist tudi oblike, kot je ⟪अकृत⟫ (3.sg.Ā), ki nedvomno spadajo korenskega aorista. Zaradi tega so indijski gramatiki izumili naslednje ad-hoc zvočno pravilo za s-Aorist:

::: indent
"Po kratkem samoglasniku končnice, ki se začnejo z -st- ali -sth-, izgubijo -s-."
:::
Sicer veljajo pravila o združevanju izgovorjenih soglasnikov s soglasnikom s.

Za -dhvam velja:

::: grammar-box
**-dh- v -dhvam se po vseh soglasnikih, ki niso a/ā, ter po -r nadomesti z -ḍh-.**

:::
::: indent
npr. :sig[⟪चि⟫] 5U: 2.os.Ā :sig[⟪अचेढ्वम्⟫]
:::
::: grammar-box
**Oblika korena:**

*   **⟪परस्मैपद⟫ : podaljšana stopnja**
*   **⟪आत्मनेपद⟫ :**
*   **Koreni z izgovorjenim i/ī/u/ū: visoka stopnja**
*   **izgovorjeno -ṝ se nadomesti z -īr ali -ūr**
*   **koreni, ki lahko spreminjajo samoglasnike na ā/e/o: nizka stopnja**
*   **drugi samoglasniki v korenu: nespremenjeni (t.j. običajno nizko stopnjo)**
:::
