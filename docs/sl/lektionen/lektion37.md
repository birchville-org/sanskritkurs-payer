# Ura 37

## 37.1. Prislovje (⟪क्रियाविशेषणम्⟫)

Prislovlja se v sanskrtu tvorijo

1. s sklonjenimi oblikami imen in zaimkov
2. s pomočjo posebnih sufiksov in končnic

V prvem primeru je meja med živo sklonjeno obliko in prislovjem prehodna. Sem spadajo kot poseben primer prislovlja, ki so okornele stare sklonjene oblike, medtem ko se v deklinaciji uporabljajo druge oblike ali pa ustreznih imen več ne uporabljamo kot imen.

## 37.2. Prislovna raba sklonjenih oblik

### 37.2.1. Tožilnik (⟪द्वितीया⟫)

::: grammar-box
Tožilnik (⟪द्वितीया⟫) se lahko uporabi prislovno na vprašanja:

*   kako?
*   koliko časa?
*   kam?
*   ipd.

Tožilnik se lahko uporabi prislovno:

*   od samostalnikov  
Primeri:  
⟪कामम्⟫ "po želji, po volji"  
⟪अर्थम्⟫ "zaradi"

*   od pridevnikov v srednjem rodu  
Primeri:  
⟪सुखम्⟫ "lahko, srečno"  
⟪नित्यम्⟫ "vedno"  
⟪साधु⟫ "pravilno, dobro"

*   od zaimkov v srednjem rodu  
Primeri:  
⟪तद्⟫ "takrat, zato"  
⟪यद्⟫ "če, da"  
⟪एतद्⟫ "tako, tukaj, zdaj"
:::
### 37.2.2. Orodnik (⟪तृतीया⟫)

::: grammar-box
Orodnik (⟪तृतीया⟫) se lahko uporabi prislovno na vprašanja:

*   s čim?
*   z kaj?
*   ipd.

Orodnik se lahko uporabi prislovno:

*   od samostalnikov  
Primeri:  
⟪अर्थेन⟫ "zaradi"  
⟪क्षणेन⟫ "v tistem trenutku, takoj" (od ⟪क्षण⟫ m. "trenutek")

*   od pridevnikov, pogosto tudi v množini  
Primeri:  
⟪दूरेण⟫ "daleč, iz daljave" (k ⟪दूर⟫ 3 "daleč, daleč stran")  
⟪उच्चैस्⟫ "visoko, glasno" (k ⟪उच्च⟫ 3 "visoko, dvignjeno, glasno, ostro (od glasu)")
:::
### 37.2.3. Dativ (⟪चतुर्थी⟫)

::: grammar-box
Dativ (⟪चतुर्थी⟫) se redko uporablja adverbialno na vprašanja:

*   za kakšen namen?
*   in podobno.

Primer:
:::
::: indent
⟪अर्थाय⟫ "zaradi, z namenom ..."
:::
### 37.2.4. Ablativ (⟪पञ्चमी⟫)

::: grammar-box
Ablativ (⟪पञ्चमी⟫) se lahko uporablja adverbialno na vprašanja:

*   zakaj?
*   zaradi česa?
*   od kod?
*   in podobno.

Ablativ se lahko uporablja adverbialno:

*   od samostalnikov  
npr. ⟪बलात्⟫ "z nasiljem, z grožnjo"  

*   od pridevnikov  
npr. ⟪दूरात्⟫ "od daleč"  

*   od zaimkov  
Primeri:  
⟪कस्मात्⟫ "zakaj"  
⟪अकस्मात्⟫ "nenadoma"
:::
### 37.2.5. Genitiv (⟪षष्ठी⟫)

::: grammar-box
Genitiv (⟪षष्ठी⟫) se redko uporablja adverbialno na vprašanje "po koliko časa?"

npr. ⟪चिरस्य⟫ "po dolgem času" (glej ⟪चिर⟫ 3 "dolgo (čas)")
:::
### 37.2.6. Lokativ (⟪सप्तमी⟫)

::: grammar-box
Lokativ (⟪सप्तमी⟫) se lahko uporablja adverbialno na vprašanja:

*   kje?
*   pod katerimi okoliščinami?
*   in podobno.

Primeri:
:::
::: indent
\-⟪अर्थे⟫ "zaradi"  
\-⟪कृते⟫ "zaradi"  
⟪दूरे⟫ "oddaljeno"
:::
## 37.3. Adverbialna raba ne več v uporabi oblik padežev

Primeri:
::: indent
⟪जातु⟫ "sploh" (sprva "od rojstva, po naravi", akuzativ ednine srednjega spola k ⟪जातु⟩ \<ne več v uporabi kot samostalnik\>)

⟪तूष्णीम्⟫ "molče" (akuzativ ednine k ne več v uporabi ⟪तूष्णी⟫ ž. spola "molčanje")

⟪एवम्⟫ "tako" (k sicer izgubljenemu zaimskemu korenu ⟪एव⟫ "eden, edini")
:::
## 37.4. Oblikovanje prislovov z prislovnimi sufiksi

::: grammar-box
Iz korenov zaimkov ⟪तद्⟫, ⟪इदम्⟫ oziroma ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ oziroma ⟪कु⟫ lahko s prislovnimi sufiksi

*   \-⟪तस्⟫ (ablativ)
*   \-⟪त्र⟫ (lokativ)
*   \-⟪था⟫ (način)
*   \-⟪थम्⟫ (način)
*   \-⟪दा⟫ (čas)

izpeljemo ustrezne zaimenske prislove.
:::
::: grammar-box

| Sufiks | Koren zaimka | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(Ablativ) | ⟪ततस्⟫ :brodtam, na to, zato | ⟪इतस्⟫ :br ⟪अतस्⟫ :brodtod, zaradi tega | ⟪यतस्⟫ :brodkod, od česa | ⟪कुतस्⟫ :brodkod?, zakaj? |
| **-⟪त्र⟫** :br(Lokativ) | ⟪तत्र⟫ :brtam, tam | ⟪अत्र⟫ :btukaj | ⟪यत्र⟫ :brkje | ⟪कुत्र⟫ :brkje? |
| **-⟪था⟫** :br(Način) | ⟪तथा⟫ :btako | | ⟪यथा⟫ :bkako | |
| **-⟪थम्⟫** :br(Način) | | | | ⟪कथम्⟫ :bkako? |
| **-⟪दा⟫** :br(Čas) | ⟪तदा⟫ :btakrat, tedaj | | ⟪यदा⟫ :bkadar | ⟪कदा⟫ :bkdaj? |

:::

Drugi vprašalni prislov je: ⟪क्व⟫ "kje?"

## 37.5. Adverbialna sestavljenka

### 37.5.1. Sestavljene besede z adverbom ali v adverbski rabi uporabljenim sklonom kot zadnjim členom

Primer: ⟪सुचिरम्⟫ "zelo dolgo (čas)"

### 37.5.2. V adverbski rabi ⟪बहुव्रीहि⟫

Primer: ⟪रक्षार्थम्⟫ "v naravi nekoga, katerega namen je varovanje, z namenom varovanja". Lahko se obravnava tudi kot pripadajoč 5.1.: -⟪अर्थम्⟫ kot adverbski zadnji člen.

### 37.5.3. ⟪अव्ययीभाव⟫-sestavljene besede

⟪अव्ययीभाव⟫ = "nespremenljiva/neodklonljiva postala"

::: grammar-box
⟪अव्ययीभाव⟫ je adverbska sestavljena beseda, katere prednji člen indeklinabil (postpozicija, delik in podobno) je, zadnji člen pa imenka, ki prevzame končnik akuzativa singulara srednjega rodu.

Pri razčlenitvi sestavljene besede bi prednji člen vladal zadnjemu:

Primeri:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = "proti ognju"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "po moči"

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = "naprej, nasproti"
:::
Zlasti pomembne so ⟪अव्ययीभाव⟫ z ⟪यथा⟫ "kot" kot prednjim členom:

npr. ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ "kot je želja, po želji, poljubno"

Neodretna zaimnika (neodrejeni zaimek) se tvorijo s pripono

## 37.8. Vprašalni stavek

::: grammar-box
"Kdo?, kako?, kaj, zakaj? zakaj? zakaj?  
Kdo ne vpraša, ostane bedak."

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

Moto Sesamove ulice, ki je dobra vodilna nit za življenje in študij sanskrta
:::
Glej tudi [Lektion 4](lektion04.md).

Razlikovati je treba med

*   besednimi vprašanji (dopolnilna vprašanja)
*   stavčnimi vprašanji

Pri besednih vprašanjih se sprašujemo po subjektu (⟪कर्तृ⟫), objektu, dejanju, okoliščinah itd., npr.

*   kdo prihaja?
*   kaj počne Rāma?
*   koga posluša?
*   kako govori sanskrt?
*   kje je mati?

Pri stavčnih vprašanjih se sprašujemo po celotni vsebini stavka, npr.

*   gre Rāma danes v Ofterdingen?
*   je prav, da ... ?

### 37.8.1. Besedna vprašanja (dopolnilna vprašanja)

::: grammar-box
Shema:

Vprašalno zaimnik/vprašalni prislov - stavek
:::
Primeri:
::: indent
⟪को ग्रामं गच्छति⟫ =  ⟪केन ग्रामो गम्यते⟫ = "Kdo gre v vas?"

⟪किं बाला अधीयीरन्⟫ = "Kaj bi morali otroci učiti?"

⟪क्व रामो वसति⟫ = Kje stanuje Rāma?
:::

### 37.8.2. Vprašalni stavki

::: grammar-box
Včasih je le iz konteksta razvidno, ali gre za vprašalni stavek.
:::
::: grammar-box
Shema I:

Glagol - preostanek stavka
:::
Primer:
::: indent
⟪गमिष्यति ब्राह्मणबालो गुरुम् ।⟫ "Ali bo brahminski deček šel k učitelju?"
:::
::: grammar-box
Shema II:

Vprašalna delca (običajno na začetku stavka) - stavek

Najpomembnejše vprašalne delce so:

*   ⟪अपि⟫

*   ⟪किम्⟫ (pogosto pričakuje negativen odgovor)

*   ⟪कच्चिद्⟫


Te delce ustrezajo vprašajniku.
:::
Primer:
::: indent
⟪अपि सत्यम् ।⟫ "Ali je tudi res?"

⟪किं शक्नोति ।⟫ "Ali more res?"

⟪कच्चित्क्षत्रियेण शत्रवो जिताः ।⟫ "Ali je morda kṣatrija premagal sovražnike?"
:::
Opomba: ⟪किम्⟫ lahko poleg "kaj?" in kot vprašalna delca pomeni tudi "zakaj?, za kaj?". Zlasti z instrumentalom (⟪तृतीया⟫):
::: indent
⟪किं क्रोधेन ।⟫ "Za kaj jezen? Kaj pomaga jeza? Kaj naj bo z jezo?"
:::

## 37.10. Vaje

A) Odgovorite na naslednja vprašanja v sanskrtu z uporabo besed, navedenih v oklepajih. Prevodite vprašalne stavke.

Primer: ⟪क आगच्छति⟫ (⟪राम⟫) ⟪।⟫ » ⟪राम आगच्छति । कस्मै ब्राह्मण्यन्नं ददौ ॥१॥⟫ (⟪भिक्षु⟫, ⟪बाला⟫, ⟪दास⟫, ⟪भगवन्त्⟫)

⟪क आर्यसत्यान्यजानात् ॥२॥⟫ (⟪बुद्ध⟫, ⟪शाक्यमुनि⟫)

⟪कुत्राग्निश्चीयते ॥३॥⟫ (⟪यज्ञस्थान⟫, ⟪मही⟫)

## 37.11. Ponovitvena vaja

Prevajajte v sanskrt tako, da izključno uporabljate oblike perfekta glagola:

Ko je nekoč starček šel v drugo vas, se je na poti utrujil. Šel je torej, da bi si oddihnil, k nogi mango drevesa, ki je stalo ob strani. Na tem drevesu so bile zrele plodove. Starček je začutil željo po teh plodovih. Vendar pa se ni mogel povzpeti na drevo in doseči plodov. Na srečo so bile na tem drevesu kakšne opice, ki so jedle plodove. Ko jih je zagledal, se je starček veselil. Kaj je storil? Vzel je nekaj kamnov, ciljal na opice in jih metel. Razjarjene opice so nabrale kakšne plodove in jih vržle na starčka. Starček je te veselo vzel in šel v svojo želeno okolico. Glejte, usoda starčka!
