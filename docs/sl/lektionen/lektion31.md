# Ura 31

## 31.1. 7. prezenska razreda (⟪रुधादि⟫ = "⟪रुध्⟫ itd.")

::: grammar-box
**Oblikovanje:**

**Pred izgovorjenimi soglasniki korena v stopnjevani obliki se vstavi tako imenovana nazalna infix (-na- ali -n-):**

*   **v močnem korenu: -na-**
*   **v šibkem korenu: -n-**

**Za združevanje izgovorjenih soglasnikov korena z začetnimi soglasniki končnic veljajo enaka pravila kot za 2. prezensko razred.**
:::
Primeri:

⟪युज्⟫ 7U "povezati, vpreči"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. os.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(v notranjosti besede se nazali pred guturali nadomestijo z -ṅ-) |
| | **3. mn.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Optativ** | **3. os.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. mn.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |

:::

:::

:::
