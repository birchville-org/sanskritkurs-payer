# Učenje 25

## 25.1. Oblikovanje ablativa (⟪पञ्चमी⟫ = "peti sklonilni primer")

::: grammar-box

Razen pri maskulinih/neutralnih besedah na -a ter zaimkih so v singularu v vseh deklinacijskih razredih oblike ablativa (⟪पञ्चमी⟫) enake kot tiste genitiva (⟪षष्ठी⟫).

Razen pri osebnih zaimkih so v vseh deklinacijah v pluralu oblike ablativa enake kot tiste dativa (⟪चतुर्थी⟫).

:::

Zdaj boste spoznali razlog za vrstni red sklonilnih primerov (⟪विभक्ति⟫) v sanskrtu: razvrščeni so tako, da se enako zveneče oblike čim bolj nahajajo skupaj - oziroma drug nad drugim.

::: grammar-box

**Ablativ singular maskulinov/neutrov na -a**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)

:::

Vprašalni, relativni in demonstrativni zaimki:

::: grammar-box

| | Ablativ singular:brMaskulinum / Neutrum | Ablativ singular:brFemininum |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::

## 25.2. Uporaba ablativa (⟪पञ्चमी⟫)

"Ablativ označuje tisto, kar ostane, ko nekaj odide."

Pāṇini 2,3,28 + 1,4,24

Ablativ stoji predvsem na vprašanji "Od kod?", "Zakaj?".

::: grammar-box

1. Ablativ torej označuje izhodišče, poreklo in snov.

Zato lahko ablativ označuje tudi osebo, od katere nekaj kupujemo, slišimo, želimo itd.

:::

Primeri:

::: indent

⟪ग्रमादागच्छति⟫ = "On prihaja iz vasi"

⟪अश्वात्पतितः⟫ = "padel s konja"

⟪तेभ्यो लब्धम्⟫ = "prejel od njih (naprej)"

:::

Primeri:

::: indent

⟪गुरोर्धर्मं शृणोति⟫ = "sliši od učitelja o dhammi"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "brahman si želi od ksatraja mlečno kravo"

:::

::: grammar-box

2. Ablativ stoji pri glagolih s pomeni "odvračati od", "zaščititi pred", "braniti proti", "bati se":

:::

Primer:

::: indent

⟪अरिभ्यो रक्षति⟫ = "zaščiti pred sovražniki"

:::

::: grammar-box

3. Abliv označuje vzrok ali povzročitev:

:::

Primeri:

::: indent

⟪क्रोधात्पुत्रं हन्ति⟫ = "Ubije svojega sina iz jeze"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "Ker je storil zlo, pride v pekel" (ker je nekdo, skozi katerega se je storilo zlo)

⟪पापकरणान्नरकं गच्छति⟫ = "Ker dela / je storil zlo, pride v pekel"

:::

Samostalniki, ki niso ženskega spola, lahko za označevanje vzroka dejanja stojijo v instrumentalu (⟪तृतीया⟫) ali ablativu (⟪पञ्चमी⟫). Ženske samostalniki v tem smislu običajno stojijo v instrumentalu, lahko pa včasih tudi v ablativu.

## 25.3. Suffix -⟪तस्⟫

::: grammar-box

Če želimo v singularu (enoznačno) izraziti, da se beseda uporablja v ablativnem pomenu, lahko na koren besede dodamo suffix -⟪तस्⟫, ki tvori prislove z običajno ablativnim pomenom (na vprašanje "Od kod?"):

:::

Primeri:

::: indent

⟪आदितस्⟫ = "od začetka"

⟪धर्मतस्⟫ = "zaradi dharme, na podlagi dharme"

:::

::: grammar-box

Suffix -⟪तस्⟫ se pojavlja tudi na pronomatskih korenih:

:::

::: indent

⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "od tam, tam, tja, na to, potem, zaradi tega"

⟪यद्⟫ : ⟪यतस्⟫ "od katerega, od česar, odkod, kje, kam, zakaj, ker" (relativno)

⟪किम्⟫ :  ⟪कुतस्⟫ "odkod?" "zakaj?"

:::

## 25.4. Druge možnosti za izražanje utemeljitev

::: grammar-box

**1\. Relativni stavki**

Relativni stavki pogosto izražajo vzročno (utemeljujočo), konsekutivno (sledno) ali finalno (namenjeno) razmerje do glavni stavk.

Oblike relativnega zaimka, ki služijo kot vzročni veznik:

*   ablativno:
*   ⟪यतस्⟫ ... podstavk ... ⟪ततस्⟫ ... glavni stavek ... = "ker ..., zato ..."
*   ⟪यस्मात्⟫ ... podstavk ... ⟪तस्मात्⟫ ... glavni stavek ... = "ker ..., zato ..."
*   instrumentalno:
*   ⟪येन⟫ ... podstavk ... ⟪तेन⟫ ... glavni stavek ... = "preko česar/ker ..., s tem / zaradi tega ..."

:::

Primer:

::: indent

⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "Ker Rāma želi blaginjo, izvaja zavetje"

:::

::: grammar-box

**2\. ⟪हि⟫**

Glavne stavke lahko povežemo z delkom ⟪हि⟫ "saj, ker". Stavek z ⟪हि⟫ (ki ne sme biti na prvem mestu, ampak mora v prozi stati na drugem mestu) navaja utemeljitev bodisi za prejšnji stavek bodisi za naslednji stavek:

:::

Primer:

::: indent

⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "Ljudje delajo zaslužna dela. Namreč želijo priti v nebesa."

:::

::: grammar-box

**3\. Instrumental (⟪तृतीया⟫)**

Poleg ablativa (⟪पञ्चमी⟫) se instrumental (⟪तृतीया⟫) uporablja za navedbo vzroka ali povoda. Pri ženskih imenikih je instrumental na splošno obvezen.

:::

Primer:

::: indent

⟪क्रोधेन पुत्रं हन्ति⟫ = "Ubije svojega sina iz jeze" = "Ubije svojega sina v jezi"

:::

::: grammar-box

**4\. Imeniki**

Poleg tega seveda lahko utemeljitve izrazimo tudi s konstrukcijami z

*   ⟪कारण⟫ n. "vzrok": ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ m.
*   drugimi imeniki v pomenu "vzrok"

\+ genitiv (⟪षष्ठी⟫) ali kot zadnji člen sestavljenk:

:::

Primer:

::: indent

⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ itd.) = "zaradi zaslužka"

:::

::: grammar-box

**5\. ⟪इति⟫**

Motiv za dejanje lahko kot misel navedemo z ⟪इति⟫:

:::

Primer:

::: indent

⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫  = "Ker je Sugata popolnoma prebudil k resnici, vpraša Ānanda Gautamo po njegovi nauki" (« "Misleč 'Sugata je popolnoma prebudil k resnici' ...)

:::

## 25.6. Übung

A) Dopolnite deklinacijske primere iz [lekcije 16](lektion16.md), ponovitvena vaja A z dodajanjem 4. dativ (⟪चतुर्थी⟫) in 5. ablativ (⟪पञ्चमी⟫). Ustvarite tudi deklinacijske vrste z vimi doslej naučenimi oblikami za

⟪१⟫. ⟪सन्त्⟫ (m., n.)

⟪२⟫. ⟪महान्त्⟫ (m., n.)

⟪३⟫. ⟪यद्⟫ (m., n., f.)

Naučite se teh sklanjatvenih paradigem na pamet!
