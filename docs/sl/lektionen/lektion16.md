# Učenje 16

## 16.1. O Sandhi izpadajočih soglasnikov

Za tvorbo besednih zvez, katerih prva komponenta tvori končnice s soglasniškim izpadom, so potrebna naslednja pravila:

Izpadajoči guturalni, retrofleksni, dentalni in labialni zaporniki (torej ne nosali in ne palatali).
