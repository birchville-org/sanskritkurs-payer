# Učenje 26

## 26.1. Zakon za cerebralizacijo -s- znotraj besede

::: grammar-box
**-s-** se nadomesti z **-ṣ-**, če mu neposredno ali ločeno le z ⟪अनुस्वार⟫ ali ⟪विसर्ग⟫ predhaja **k, r, l** ali samoglasnik — razen **a, ā** — in mu sledi drug glas kot **ṛ, r**.

Temu sandhiju sledi tudi **⟪दुस्⟫-** pred breztonalnimi guturali in labiali v kompozitih.
:::
*Primeri:*
::: indent
⟪तेषाम्⟫ (iz: *te-sām*)

a: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. Zakon za cerebralizacijo dentalov znotraj besede

::: grammar-box
Dentalni zaporniki se po retrofleksih (vključno z **-ṣ-**) nadomestijo z ustreznimi retrofleksami:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** zaradi predhodnega **i**, **ṭh** zaradi takratnega naslednjega **ṣ**)*
:::
## 26.3. Besedni sandhi za palatal, gutural, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

Primeri glej spodaj
:::

::: grammar-box

## 26.6. Uporaba preprostega future (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ž.)

::: grammar-box
**Preprosti futur (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ž.) izraža:**

**prihodnost**
**namenjeno ali želeno dejanje ("pojdem", "želim si iti")**
**pričakovanje ("tako se bo zgodilo")**
**upanje**
**strah**
**verjetnost**
**mnenje govorca**
**ukaz**

**Futur delno tekmuje z optativom (glej kasneje).**
:::
npr. ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = "Nekdo, ki želi skleniti obljubo, gre v tempelj."

## 26.7. Oblikovanje preprostega future (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ž.)

::: grammar-box
**Preprosti futur:**

:::
::: indent
**Futurni koren + primarna končnica**
:::
::: grammar-box
**Futurni koren:**

:::
::: indent
**(običajno) stopnjevana korenina + -sya**  
**ali**  
**(običajno) stopnjevana korenina + -i- + -sya (= - iṣya)**
:::
**Katera korenina ima katero oblikovanje futurnega korena, se mora naučiti iz osnovnih oblik!**  
**Na splošno se koreninska oblika in vezni samoglasnik future ujemata z infinitivom.**  
**Nekatere korenine lahko oblikujejo futur po lastni izbiri z in brez veznega samoglasnika -i-.**  
**Particip Parasmaipada future se tvori z dodajanjem sufiksa -nt- na futurni koren, ženski rod pa fakultativno z -ntī ali -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
