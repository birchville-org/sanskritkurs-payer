# Leçon 25

## 25.1. Formation de l'ablatif (⟪पञ्चमी⟫ = "cinquième désinence casuelle")

::: grammar-box
À l'exception des masculins/neutres en -a ainsi que des pronoms, au singulier, dans toutes les classes de déclinaison, les formes de l'ablatif (⟪पञ्चमी⟫) sont identiques à celles du génitif (⟪षष्ठी⟫).

À l'exception des pronoms personnels, dans toutes les déclinaisons au pluriel, les formes de l'ablatif sont identiques à celles du datif (⟪चतुर्थी⟫).
:::
Vous comprenez maintenant la raison de l'ordre des cas (⟪विभक्ति⟫) en sanskrit : ils sont disposés de manière à ce que les formes homonymes soient aussi proches les unes des autres, voire les unes sous les autres.

::: grammar-box
**Singulier de l'ablatif des masculins / neutres en -a**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Pronoms interrogatifs, relatifs et démonstratifs :

::: grammar-box

| | Ablatif singulier : br Masculin / Neutre | Ablatif singulier : br Féminin |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Usage de l'ablatif (⟪पञ्चमी⟫)

« L'ablatif désigne ce qui reste fixe lorsque quelque chose s'en éloigne. »

Pāṇini 2,3,28 + 1,4,24

L'ablatif répond surtout aux questions « D'où ? », « Pourquoi ? ».

::: grammar-box
1\. L'ablatif désigne donc le point de départ, l'origine et la matière.

L'ablatif peut donc également désigner la personne dont on achète, entend, souhaite, etc.
:::
Exemples :

::: indent
⟪ग्रमादागच्छति⟫ = « Il vient du village »

⟪अश्वात्पतितः⟫ = « tombé de cheval »

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = « reçu d’eux (en retour) »
:::
Exemples :

::: indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟫ = « il entend du professeur au sujet du Dharma »

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = «le brāhmaṇa souhaite une vache laitière du kṣatriya»
:::
::: grammar-box
2\. L’ablatif est utilisé avec des verbes ayant les significations « empêcher de », « protéger contre », « se défendre contre », « craindre » :
:::
Exemple :

::: indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = « il protège contre les ennemis »
:::
::: grammar-box
3\. L’ablatif indique la raison ou la cause :
:::
Exemples :

::: indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = « Il tue son fils par colère »

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = « Parce qu’il a fait le mal, il va en enfer » (« Parce qu’il est celui par qui le mal a été fait »)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = « Parce qu’il fait / a fait le mal, il va en enfer »
:::
Les noms qui ne sont pas des féminins peuvent, pour indiquer la cause d’une action, se trouver au instrumental (⟪तृतीया⟫) ou au ablatif (⟪पञ्चमी⟫). Les féminins se trouvent dans ce sens généralement au instrumental, mais peuvent parfois aussi se trouver au ablatif.

## 25.3. Le suffixe -⟪तस्⟫

::: grammar-box
Si l'on souhaite exprimer au singulier (de manière claire) que le mot est utilisé dans un sens ablatif, on peut ajouter au radical du mot le suffixe -⟪तस्⟫, qui forme des adverbes ayant généralement une signification ablative (à la question « D'où ? ») :
:::
Exemples :

::: indent
⟪आदितस्⟫ = « depuis le début »

⟪धर्मतस्⟫ = « en raison du dharma, en raison du dharma »
:::
::: grammar-box
Le suffixe -⟪तस्⟫ s'applique également aux stems pronominaux :
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "de là, là, vers là, sur cela, alors, pour cette raison"

⟪यद्⟫ : ⟪यतस्⟫ « de qui, de quoi, d'où, où, où aller, pourquoi, parce que » (relatif)

⟪किम्⟫ :  ⟪कुतस्⟫ « d’où ? » « pourquoi ? »
:::
## 25.4. Autres moyens d’exprimer les raisons

::: grammar-box
**1\. Les propositions relatives**

Les propositions relatives expriment souvent une relation causale (fondée), consécutive (conséquente) ou finale (visant) avec la proposition principale.

Formes du pronom relatif servant de conjonction causale :

*   ablatif :
    *   ⟪यतस्⟫ ... subordonnée ... ⟪ततस्⟫ ... principale ... = « parce que ..., donc ... »
    *   ⟪यस्मात्⟫ ... subordonnée ... ⟪तस्मात्⟫ ... principale ... = « parce que ..., donc ... »
*   instrumental :
    *   ⟪येन⟫ ... subordonnée ... ⟪तेन⟫ ... principale ... = « par quoi/parce que ..., par là / donc ... »
:::
Exemple :

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = «Puisque Rāma souhaite la prospérité, il observe le vœu»
:::
::: grammar-box
**2\. ⟪हि⟫**

Les propositions principales peuvent être reliées entre elles à l'aide de la particule ⟪हि⟩ « car, parce que ». Une phrase contenant ⟪हि⟩ (qui ne peut pas se trouver en première position, mais doit se trouver en deuxième position en prose) indique une justification soit pour la phrase précédente, soit pour la phrase suivante :
:::
Exemple :

::: indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = «Les gens accomplissent des méritoires. Ils veulent en effet aller au ciel.»
:::
::: grammar-box
**3\. Instrumental (⟪तृतीया⟫)**

Outre l’ablatif (⟪पञ्चमी⟩), l’instrumental (⟪तृतीया⟩) est utilisé pour indiquer la raison ou la cause. Avec les noms féminins, l’instrumental est généralement obligatoire.
:::
Exemple :

::: indent
⟪क्रोधेन⟫ ⟪पुत्रं⟫ ⟪हन्ति⟫ = « Il frappe son fils par colère » = « Il frappe son fils dans la colère »
:::
::: grammar-box
**4\. Noms**

On peut bien sûr également exprimer des justifications par des constructions avec

*   ⟪कारण⟫ n. «Cause» : ⟪⟪कारणात्⟫ ⟪।⟫ ⟪कारणेन⟫
*   ⟪हेतु⟫ m.
*   Génitif (⟪षष्ठी⟫) ou comme second membre de composés :

\+ Génitif (⟪षष्ठी⟫) ou comme second élément des composés :
:::
Exemple :

::: indent
⟪पुण्यस्य⟫ ⟪कारणात्⟫ (⟪हेतोः⟫ etc.) = « en raison du mérite »
:::
::: grammar-box
**5\. ⟪इति⟫**

Le motif d’une activité peut être indiqué comme une pensée avec ⟪इति⟫ :
:::
Exemple :

::: indent
⟪सम्यक्संबुद्धः⟫ ⟪सुगत⟫ ⟪इत्यानन्दो⟫ ⟪गौतमं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫  = « Parce que le Sugata s’est complètement éveillé à la vérité, Ānanda demande à Gautama sa doctrine » (« « Pensant : “Le Sugata s’est complètement éveillé à la vérité” ...)
:::
