# Leçon 55

## 55.1. L'aoriste en a- (aoriste avec voyelle thématique)

::: grammar-box
**L'aoriste en a- se forme comme un imparfait (⟪लङ्⟫) de la 6e classe de présent (⟪तुदादि⟫), c'est-à-dire :**

**Augment + racine au degré réduit + a + terminaison secondaire**

**Le -a- est remplacé par -ā- dans les mêmes cas que dans l'imparfait.**

**Pas d'infixe nasal.**

**L'ātmanepāda est rare ; pour les racines ubhayapada, il est généralement formé selon d'autres classes d'aoriste (voir Kielhorn, Grammatik §340, ainsi qu'ci-dessous pour les classes d'aoriste correspondantes).**

**Liste des racines ayant cet aoriste, dans Kielhorn, Grammatik §340.**
:::
Exemple :

⟪सिच्⟫ 6U "asperger"

::: indent
|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| 1\. ⟪तृतीयः⟫ | ⟪असिचम्⟫ | ⟪असिचाम⟫ | ⟪असिचे⟫ | ⟪असिचामहि⟫ |
| 2\. ⟪मध्यमः⟫ | ⟪असिचस्⟫ | ⟪असिचत⟫ | ⟪असिचथास्⟫ | ⟪असिचध्वम्⟫ |
| 3\. ⟪प्रथमः⟫ | ⟪असिचत्⟫ | ⟪असिचन्⟫ | ⟪असिचत⟫ | ⟪असिचन्त⟫ |
:::
Formations irrégulières :

::: indent
⟪अस्⟫ 4P "jeter" : :sig[⟪आस्थम्⟫, ⟪आस्थत्⟫] (explication voir Thumb-Hauschild §541,4)

⟪ख्या⟫ + ⟪आ⟫ 2P "raconter" : :sig[⟪अख्यम्⟫, ⟪अख्यत्⟫]

⟪दृश्⟫ "voir" : :sig[⟪अदर्शम्⟫, ⟪अदर्शत्⟫] (degré fort !)
:::
Remarquer :

::: indent
⟪शास्⟫ 2P "ordonner" : ⟪अशिषत्⟫ (degré réduit régulier !)
:::
