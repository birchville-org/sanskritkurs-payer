# Leçon 31

## 31.1. La 7e classe de présent (रुधादि = "रुध्, etc.")

:::: grammar-box
**Formation :**

**Avant les consonnes finales de la racine de niveau grave, on insère un soi-disant infixes nasal (-na- ou -n-) :**

*   **dans le thème fort : -na-**
*   **dans le thème faible : -n-**

**Pour la connexion des consonnes finales de la racine avec les désinences commençant par une consonne, les mêmes règles s'appliquent que pour la 2e classe de présent.**
::::

Exemples :

युज् 7U "relier, atteler"

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicatif** | **3. sg.** | युनक्ति[[br]]yu-na-j + -ti | युङ्क्ते[[br]]yu + n + j + te[[br]](à l'intérieur du mot, les nasales sont remplacées par -ṅ- devant les gutturales) |
| | **3. pl.** | युञ्जन्ति[[br]]yu + n + j-anti | युञ्जते[[br]]yu + n + j-ate |
| **Optatif** | **3. sg.** | युञ्ज्यात्[[br]]yu + n + j-yā-t | युञ्जीत[[br]]yu + n + j-ī-ta |
| | **3. pl.** | युञ्ज्युर्[[br]]yu + n + j-y-ur | युञ्जीरन्[[br]]yu + n + j-ī-ran |
| **Participe présent** | | युञ्जन्त्-[[br]]yu + n + j-ant-[[br]]fém. : युञ्जती[[br]]yu + n + j-at-ī | |

::::

रुध् 7U "arrêter, faire cesser"

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicatif** | **3. sg.** | रुणद्धि[[br]]ru + na + dh + ti | रुन्द्धे[[br]]ru-n + dh + te |
| | **3. pl.** | रुन्धन्ति[[br]]ru-n-dh-anti | रुन्धते[[br]]ru-n-dh-ate |
| **Optatif** | **3. sg.** | रुन्ध्यात्[[br]]ru-n-dh-yā-t | रुन्धीत[[br]]ru-n-dh-ī-ta |
| | **3. pl.** | रुन्ध्युर्[[br]]ru-n-dh-y-ur | रुन्धीरन्[[br]]ru-n-dh-ī-ran |
| **Participe présent** | | रुन्धन्त्-[[br]]ru-n-dh-ant-[[br]]fém. : रुन्धती[[br]]ru-n-dh-at-ī | |

::::

:::: grammar-box
**Pour certaines racines, le -n- du thème de présent faible s'est également introduit dans les temps non-présents, de sorte que ces racines sont considérées avec un infixes nasal.**
::::

Exemple :

**भञ्ज्** 7P "briser"

::: indent
*   Indicatif présent
    *   3.sg.P. **भनक्ति** (bha-na + j + ti)
    *   3.pl.P. **भञ्जन्ति** (bha + n + j-anti)
*   Futur : **भङ्क्ष्यति** (bha + n + j + sya + ti)
*   Passif : **भज्यते** (soit à partir de la racine originelle **भज्**, soit à partir de *bhñj-ya-te)
*   PPP : **भग्न** (éventuellement à partir de *bhñj + na)
:::

## 31.2. Liste de mots

**युज्** 7U **युनक्ति** : atteler, attacher, atteler, fixer ; Ā aussi : se tendre (= se fatiguer), se lier à, se concentrer sur (Locatif, सप्तमी)
::: indent
**Fut. योक्ष्यति**
**Pass. युज्यते**
**Kaus. योजयति**
**PPP युक्त**

dont :
**युग n. -&gt; युग n.** : joug, paire, âge du monde (il y a quatre âges du monde :
1. **कृत**
2. **त्रेता**
3. **द्वापर**
4. **कलि**

**योग m.** : « attelage, tension », effort, liaison, Yoga (voir à ce sujet Basham, Wonder p. 327ss.)
