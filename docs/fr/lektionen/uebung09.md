# Leçon 9

A) Essayez de déterminer les significations possibles des mots suivants :

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. celui qui ressemble à un brahmane = un mauvais brahmane

2\. mati ⟪मति⟫ : f. opinion

3\. śravaṇa ⟪श्रवण⟫ : n. oreille

4\. dhenuka ⟪धेनुक⟫ : m. (coït) à la manière d'une vache

5\. jayaka ⟪जयक⟫ : 3 victorieux

6\. rakṣikā ⟪रक्षिका⟫ : f. gardienne, amulette

7\. karṣaka ⟪कर्षक⟫ : 3 labourant ; m. agriculteur

8\. kleśa ⟪क्लेश⟫ : m. tourment

9\. nāyikātva ⟪नायिकात्व⟫ : n. état d'une amante

10\. tantraka ⟪तन्त्रक⟫ : 3 (tout juste) venant de la chaîne de trame / du métier à tisser = nouvellement tissé

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : danseur

12\. naraka ⟪नरक⟫ : m. enfer

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. être-seigneur

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. combattant

17\. kopa ⟪कोप⟫ : m. colère

18\. veśaka ⟪वेशक⟫ : 3 entrant

19\. darśaka ⟪दर्शक⟫ : 3 voyant

20\. kopaka ⟪कोपक⟫ : 3 quelqu'un qui est facilement en colère, colérique

B) Traduisez :

1\. Devoirs de tous les deux fois nés :

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

(Yājñavalkyadharmaśāstra I, 118)

Sacrifice, étude des Védas, faire des dons.

2\. Devoirs spécifiques d'un brahmane :

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

(Gautamadharmasūtra X,2)

Enseigner, sacrifier sur ordre, accepter des dons.

3\. Devoirs spécifiques d'un kṣatriya :

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं⟫ ⟪सर्वभूतानाम्⟫

(sarvabhūtānām = génitif (cas possesseur) : "de tous les êtres")

(Gautamadharmasūtra X,7)

Protéger tous les êtres.

4\. Devoirs spécifiques d'un vaiśya :

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(d'après Gautamadharmasūtra X,49)

Agriculture, commerce, élevage et prêt d'argent.

5\. Devoirs d'un śūdra :

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं⟫ ⟪शुश्रूषा⟫ ⟪वार्त्त्ता⟫ ⟪कारुकुशीलवकर्म⟫ ⟪च⟫

(d'après Kauṭilīya-arthaśāstra 1.3.8.)

Explication :
dvijātīnām = génitif (cas possesseur) pluriel de dvijāti (traduisez ici : "envers les deux fois nés")

kārukuśīlavakarma est un tatpuruṣa avec un dvandva (kārukuśīlava) dans le membre antérieur. karma = nominatif singulier de karman n. "acte, activité, karma" de la racine kṛ 8 U). Traduisez "acte / activité des ... (génitif)" (désignés par le dvandva).

Obéissance envers les deux fois nés, activités pour subsister, activité d'artisan ou de spectateur itinérant.

6\. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः⟫ ⟪पाशुपाल्यं⟫ ⟪वणिज्या⟫ ⟪च⟫ ⟪वार्त्ता⟫

(d'après Kauṭilīya-arthaśāstra 1.4.1.)

L'économie est l'agriculture, l'élevage et le commerce.
