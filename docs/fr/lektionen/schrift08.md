### Ligatures de consonnes

Lorsque dans un mot ou une phrase deux consonnes ou plusieurs consonnes se suivent immédiatement, elles s'écrivent avec une ligature (caractère lié).

1. Si le premier des caractères de consonne à lier se termine par une barre verticale à droite, il perd cette barre et est placé devant la deuxième consonne.

Exception : lorsque le deuxième caractère de consonne est न् ou ल्, celui-ci est placé sous le premier caractère de consonne, en perdant la barre horizontale. Selon la police de caractères, il existe d'autres exceptions, qui sont énumérées ci-dessous. Si une ligature n'est pas prévue dans la police de caractères concernée, un virāma est placé.

Exemples :

Dans la police utilisée dans ce script :

Le -a initial, qui, conformément aux règles de sandhi de phrase, est élidé (-as + a- » -o ' ), est désigné par ce qu'on appelle l'Avagraha :

ऽ

par exemple

देवो ऽग्निः \= devo 'gniḥ
