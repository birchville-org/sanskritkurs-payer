# Leçon 54

Formez les formes aoristes correspondantes des formes de présent ou de parfait suivantes :

::: grammar-box
| Nr. | Form | Bestimmung / Bedeutung | Aorist |
|:---|:---|:---|:---|
| १. | **यन्ति** | ils vont | **अगुः** |
| २. | **पिबामि** | je bois | **अपाम्** |
| ३. | **ददौ** | j'ai / il a donné | **अदाम् / अदात्** |
| ४. | **बभूव** | je / il / ils étaient / étiez | **अभूवम् / अभूत् / अभूत** |
| ५. | **दधति** | ils placent | **अधुः** |
| ६. | **ऐम** | nous sommes allés | **अगाम** |
| ७. | **पपिथ** | tu as bu / protégé | **अपाः** (à *पा* "boire") |
| ८. | **तिष्ठति** | il se tient | **अस्थात्** |
| ९. | **इयेथ** | tu es allé | **अगाः** |
| १०. | **पप** | vous avez bu | **अपात** |
| ११. | **एष्यथ** | vous irez | **अगात** |
| १२. | **तस्थुः** | ils étaient debout | **अस्थुः** |
| १३. | **अधत्त** | vous placiez | **अधात** |
| १४. | **अददाः** | tu as donné | **अदाः** |
| १५. | **अभवन्** | ils étaient | **अभूवन्** |
| १६. | **ददिम** | nous avons donné | **अदाम** |
| १७. | **भिद्यते** | il est fendu | **अभेदि** |
| १८. | **उद्यते** | il est dit | **अवादि** |
| १९. | **स्तूयते** | il est loué | **अस्तावि** |
| २०. | **कृष्यते** | il est labouré | **अकर्षि** |
| २१. | **जायते** | il est né | **अजनि** |
| २२. | **गीयते** | il est chanté | **अगायि** |
| २३. | **गम्यते** | il est allé | **अगामि** |
:::
