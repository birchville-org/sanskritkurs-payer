# Leçon 55

Déterminez et traduisez les formes suivantes, puis formez les formes correspondantes de **l’aoriste en a** :

:::grammar-box
| Nr. | Form | Bestimmung / Bedeutung | a-Aorist |
|:---|:---|:---|:---|
| १. | **दोक्ष्यन्ति** | *दुष्* 4P: 3. Pl. Fut. P. (sie werden verderben) | **अदुषन्** |
| २. | **बुबोध** | *बुध्* 1U: 1. 3. Sg. Perf. P. (ich erwachte / er erwachte) | **अबुधम् / अबुधत्** |
| ३. | **क्रुध्यसि** | *क्रुध्* 4P: 2. Sg. Ind. Präs. P. (du zürnst) | **अक्रुधः** |
| ४. | **तोक्ष्यथ** | *तुष्* 4P: 2. Pl. Fut. P. (ihr werdet zufrieden sein) | **अतुषत** |
| ५. | **कुप्यामः** | *कुप्* 4P: 1. Pl. Ind. Präs. P. (wir zürnen) | **अकुपाम** |

| १७. | **रुरोधिथ** | *रुध्* 7U: 2. Sg. Perf. P. (du hieltest auf) | **अरुधः** |
| १८. | **श्राम्यन्ति** | *श्रम्* 4P: 3. Pl. Ind. Präs. P. (sie mühen sich ab) | **अश्रमन्** |
