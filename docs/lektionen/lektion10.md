## 10.1. Der Passivsatz

::: grammar-box
**Schema: (Agens im Instrumentalis) - (Objekt im Nominativ) - passive Verbalform**

Beispiel:
**brāhmaṇena deva ijyate** = <span class="sanskrit-dev">ब्राह्मणेन देव इज्यते</span>  
"Ein Gott wird von einem Brahmanen mit einem Opfer verehrt."  
(Aktiv: _brāhmaṇo devaṃ yajati_)

Im Passivsatz steht der **Agens (kartṛ)** im **Instrumentalis** (_tṛtīyā_ = <span class="sanskrit-dev">तृतीया</span>) und das **Objekt (karman)** im **Nominativ** (_prathamā_).
:::

Unpersönliches Passiv ("man"):
- **ijyate** = <span class="sanskrit-dev">इज्यते</span> ("Man opfert.")

Höfliche Aufforderungen im Passiv:
- **praviśyatām** = <span class="sanskrit-dev">प्रविश्यताम्</span> ("Bitte treten Sie ein!")
- **niṣadyatām** = <span class="sanskrit-dev">निषद्यताम्</span> ("Bitte nehmen Sie Platz!")

## 10.3. Das Cerebralisationsgesetz für -n-

Ein **-n-** wird zu **-ṇ-**, wenn **ṛ, ṝ, r** oder **ṣ** vorausgehen und bestimmte Laute dazwischenstehen.
- _guru_ » **guruṇā** (<span class="sanskrit-dev">गुरुणा</span>)
- _śūdra_ » **śūdreṇa** (<span class="sanskrit-dev">शूद्रेण</span>)

---

## 10.4. Das Passiv (Indikativ Präsens)

::: grammar-box
**Bildung: (meist) tiefstufige Wurzel + -ya- + Ātmanepada-Endung**
- _nī_ » **nīyate** (<span class="sanskrit-dev">नीयते</span>)
- _yaj_ » **ijyate** (<span class="sanskrit-dev">इज्यते</span>) (Samprasāraṇa)
- _kṛ_ » **kriyate** (<span class="sanskrit-dev">क्रियते</span>)
:::

---

## 10.5. Wortliste

- **gṛha** n.: Haus.
- **grāma** m. / **nagara** n.: Dorf / Stadt.
- **yajña** m.: Opfer.
- **puṇya** n. / **pāpa** n.: Verdienst / Übeltat.
- **ṛṣi** m.: vedischer Weiser.
- **vad 1 P**: sprechen (_vadati_).
- **prach 6 P**: fragen (_pṛcchati_).
