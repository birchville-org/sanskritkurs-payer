## 58.1. Die Primärendungen des Dual (Dvivacanam)

| Person | Parasmaipada | Ātmanepada (them.) | Ātmanepada (athem.) |
| :--- | :--- | :--- | :--- |
| **3. P.** | -tas | -īte | -āte |
| **2. P.** | -thas | -īthe | -āthe |
| **1. P.** | -vas | -vahe | -vahe |

::: info Regel für thematische Verben
Vor **-vas** und **-vahe** wird der Themavokal _-a-_ durch **-ā-** ersetzt (Bsp: _bhavāvaḥ_).
:::

## 58.3. Der iṣ-Aorist (Typ 5)

Dieser Aorist wird von den meisten _seṭ_-Wurzeln gebildet.

::: grammar-box
**Bildung: Augment + Wurzel + i + s + athematische Sekundärendung**

**Wichtig**: Die 2./3. Sg. P. enden auf **-īs** bzw. **-īt** (Bsp: _abodhīt_).
:::

**Endungen (iṣ-Aorist)**:

| Person | Parasmaipada (Sg. / Pl.) | Ātmanepada (Sg. / Pl.) |
| :--- | :--- | :--- |
| **3. P.** | **-īt** / -iṣuḥ | -iṣṭa / -iṣata |
| **2. P.** | **-īs** / -iṣṭa | -iṣṭhāḥ / -idhvam |
| **1. P.** | -iṣam / -iṣma | -iṣi / -iṣmahi |

---

## 58.4. Stammbildung (iṣ-Aorist)

::: grammar-box
- **Kurzer Vokal vor Konsonant**: Hochstufe (Guṇa). Bsp: _budh_ » **abodiṣam**.
- **Auslautender Vokal**: 
  - Parasmaipada: Dehnstufe (Vṛddhi). Bsp: _pū_ » **apāviṣam**.
  - Ātmanepada: Hochstufe (Guṇa). Bsp: _pū_ » **apaviṣi**.
:::

## 58.5. Übung

Bestimmen Sie die Formen (Auswahl):
- **adhīyāte**: 3. Du. Ā. (sie beide studieren).
- **sunutaḥ**: 3. Du. P. (sie beide pressen aus).
- **abodhīt**: 3. Sg. P. iṣ-Aor. (er erwachte/erkannte).
- **kṛṇīte**: 3. Sg. Ā. (er kauft).
