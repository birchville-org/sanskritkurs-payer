## 26.1. Lautgesetze im Wortinnern

Das Futur erfordert oft komplexe Lautveränderungen der Wurzel.

### 26.1.1. Zerebralisierung (Retroflexion)
- **s » ṣ**: Nach _i, u, ṛ, k, r_ wird _s_ zu _ṣ_ (z.B. _teṣām_).
- **Dentale » Retroflexe**: Dentale werden nach Retroflexen selbst retroflex (z.B. _iṣ + ta_ » **iṣṭa** <span class="sanskrit-dev">इष्ट</span>).

### 26.1.2. Das Graßmannsche Gesetz (Hauchdissimilation)
Wenn zwei behauchte Laute (Aspirata) aufeinanderfolgen, verliert der erste seine Behauchung. Wenn der zweite sie verliert (z.B. vor _-sya_), kehrt sie beim ersten zurück.
- **budh-sya-te** » **bhotsyate** (<span class="sanskrit-dev">भोत्स्यते</span>).
- **duh-sya-ti** » **dhokṣyati** (<span class="sanskrit-dev">धोक्ष्यti</span>).

## 26.2. Das Futur (Lṛṭ = <span class="sanskrit-dev">ऌट्</span>)

### 26.2.1. Bildung
Das Futur wird gebildet aus: **Wurzel (Guṇa) + (i) + sya + Primärendung**.

::: grammar-box
| Typ | Bildung | Beispiel |
| :--- | :--- | :--- |
| **aniṭ** (ohne -i-) | Wurzel + **-sya-** | **neṣyati** (<span class="sanskrit-dev">नेष्यति</span>) |
| **seṭ** (mit -i-) | Wurzel + **-iṣya-** | **bhaviṣyati** (<span class="sanskrit-dev">भविष्यति</span>) |

**Sonderformen**:
- **dṛś** » **drakṣyati** (<span class="sanskrit-dev">द्रक्ष्यति</span>) : er wird sehen.
- **labh** » **lapsyate** (<span class="sanskrit-dev">लप्स्यते</span>) : er wird erlangen.
:::

## 26.3. Übung: Futur-Bildung

- **atti** » **atsyati** (<span class="sanskrit-dev">अत्स्यति</span>)
- **paśyati** (v. _dṛś_) » **drakṣyati** (<span class="sanskrit-dev">द्रक्ष्यति</span>)
- **bhavati** » **bhaviṣyati** (<span class="sanskrit-dev">भविष्यति</span>)
- **karoti** » **kariṣyati** (<span class="sanskrit-dev">करिष्यति</span>)
