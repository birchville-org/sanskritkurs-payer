## 57.1. Der s-Aorist (Typ 4)

Der s-Aorist wird zu den meisten _aniṭ_-Wurzeln gebildet. Er ist der wichtigste der sigmatischen Aoriste.

::: grammar-box
**Bildung: Augment + Wurzel + s + athematische Sekundärendung**
:::

**Endungen mit Stammbildungssuffix**:

| Person | Parasmaipada (Sg. / Pl.) | Ātmanepada (Sg. / Pl.) |
| :--- | :--- | :--- |
| **3. P.** | **-sīt** / -suḥ | -sta / -sata |
| **2. P.** | **-sīs** / -sta | -sthāḥ / **-dhvam** |
| **1. P.** | -sam / -sma | -si / -smahi |

---

## 57.2. Stammbildung und Lautregeln

::: grammar-box
**Form der Wurzel**:
- **Parasmaipada**: Dehnstufe (Vṛddhi). Bsp: _nī_ » **anāiṣam**.
- **Ātmanepada**: 
  - Auslautendes _i/u_: Hochstufe (Guṇa).
  - Sonst: meist Tiefstufe oder unverändert.
:::

::: info Sandhi-Regel
Ein _-s-_ zwischen zwei Verschlusslauten fällt aus.
- Bsp: _a-tud + s + ta_ » **atāutta** (3. Sg. P.).
- Bsp: _a-kṣip + s + ta_ » **akṣipta** (3. Sg. Ā.).
:::

## 57.3. Paradigmen (Auswahl)

### nī (नी = führen)
- **3. Sg. P.**: anāiṣīt | **3. Sg. Ā.**: aneṣṭa
- **1. Sg. P.**: anāiṣam | **1. Sg. Ā.**: aneṣi

### kṛ (कृ = tun)
- **3. Sg. P.**: akārṣīt | **3. Sg. Ā.**: akṛta
- **1. Sg. P.**: akārṣam | **1. Sg. Ā.**: akṛṣi

### tud (तुद् = schlagen)
- **3. Sg. P.**: atāutsīt | **3. Sg. Ā.**: atutta
- **1. Sg. P.**: atāutsam | **1. Sg. Ā.**: atutsi

---

## 57.4. Übung

Bestimmen Sie die Formen (Auswahl):
- **adraukṣma**: wir sahen (1. Pl. P. s-Aor. von _dṛś_).
- **akārṣam**: ich tat (1. Sg. P. s-Aor. von _kṛ_).
- **ajaiṣṭa**: ihr habt gesiegt (2. Pl. P. s-Aor. von _ji_).
- **atāutta**: er schlug (3. Sg. P. s-Aor. von _tud_).
