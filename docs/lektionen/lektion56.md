## 56.1. Der reduplizierte Aorist

**Bildung: Augment + reduplizierte Wurzel + a + thematische Sekundärendung**

::: grammar-box
**Alle Wurzeln der 10. Präsensklasse sowie alle Kausative bilden stets den reduplizierten Aorist.**
:::

**Beispiel: śri (श्रि = sich begeben zu)**

| Person | Parasmaipada (Sg. / Pl.) | Ātmanepada (Sg. / Pl.) |
| :--- | :--- | :--- |
| **3. P.** | aśiśriyat / aśiśriyan | aśiśriyata / aśiśriyanta |
| **2. P.** | aśiśriyaḥ / aśiśriyata | aśiśriyathāḥ / aśiśriyadhvam |
| **1. P.** | aśiśriyam / aśiśriyāma | aśiśriye / aśiśriyāmahi |

## 56.2. Der Injunktiv und der Verbotssatz

Der Injunktiv ist die augmentlose Form zu Augmentformen (Imperfekt oder Aorist). Im nachvedischen Sanskrit kommt er fast nur noch mit der Verbotspartikel **mā** vor.

::: tip Der Verbotssatz (Hauptformen)
- **mā** + Injunktiv Aorist: "Tu nicht...!"
- **mā sma** + Injunktiv Aorist oder Präsens.
:::

**Beispiele aus der Gītā**:
- **mā karma-hetur-bhūr**: "Werde nicht einer, der durch die Frucht der Tat motiviert wird!" (Gītā 2.47)
- **klaibyaṃ mā sma gamaḥ**: "Werde nicht unmännlich/feige!" (Gītā 2.3)

## 56.3. Genug mit dem Verzagen!

::: info Weitere Verbotsformen
- **alaṃ** / **kṛtam** + Instrumental: "Genug mit...!"
- **alaṃ viṣādena**: "Hör auf zu verzagen! / Kopf hoch!"
:::

## 56.4. Die Partikel 'sma'

- **sma** hebt hervor: "wahrlich, gewiss".
- **sma** + Indikativ Präsens: Erzählform für die Vergangenheit (Dauer).
  - Bsp: **vasati sma** (er wohnte einmal).

## 56.5. Übung

Bestimmen Sie die Formen (Auswahl):
- **asmat**: von uns (Abl. Pl.).
- **asmāt**: von diesem (Abl. Sg. m./n.).
- **akāri**: es wurde gemacht (3. Sg. Pass. Aor.).
- **rājan**: O König! (Vok. Sg. m.).
- **avocan**: sie sagten (3. Pl. Red. Aor. von _vac_).
