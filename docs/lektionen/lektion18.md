## 18.2. Determinativkomposita mit adverbialem Vorderglied

### 18.2.1. Nañ-Tatpuruṣa (Verneinung)
Das Präfix **a-** (vor Konsonant) bzw. **an-** (vor Vokal) ersetzt die Verneinung **na** (<span class="sanskrit-dev">न</span>).

::: grammar-box
**Bedeutungen von nañ**:
1. **Ähnlichkeit**: **abrāhmaṇaḥ** (sieht aus wie ein Brahmane, ist keiner).
2. **Fehlen**: **ajñānam** (Unwissenheit).
3. **Missbilligung**: **akālaḥ** (Unzeit).
4. **Feindschaft**: **asuraḥ** (Gegengott/Dämon).
:::

### 18.2.2. Prādi-Tatpuruṣa (su- / dus-)
- **su-** (<span class="sanskrit-dev">सु</span>) : "gut, wohl, leicht". z.B. **sukṛtam** (gute Tat).
- **dus-** (<span class="sanskrit-dev">दुस्</span>) : "schlecht, übel, schwer". z.B. **durjanaḥ** (böser Mensch).
  - Vor k, kh, p, ph wird **dus-** zu **duṣ-**. z.B. **duṣkara** (<span class="sanskrit-dev">दुष्कर</span>) "schwer zu tun".

## 18.3. Verbalkomposita (Präverben)

Durch ein Präverb (**upasarga**) wird die Bedeutung einer Wurzel oft grundlegend verändert.

::: grammar-box
**Saṃskṛta vs. Prākṛta**:
- **sam-kṛ** » **saṃskṛta** (<span class="sanskrit-dev">संस्कृत</span>) : "zubereitet, geweiht" (die heilige Sprache).
- **pra-kṛ** » **prākṛta** (<span class="sanskrit-dev">प्राकृत</span>) : "gewöhnlich, natürlich" (die Volkssprachen).
:::

**Saṃskāras (Lebenszyklen)**:
- **saṃskāra** m.: Weihe, Übergangsritual.
- **upanayana** n.: "Heranführen" (Initiation, Anlegen der heiligen Schnur).

- **śabda** m.: Wort, Laut.
- **daṇḍa** m.: Stock, Strafe.
