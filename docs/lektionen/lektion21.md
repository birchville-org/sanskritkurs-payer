## 21.1. Das Partizip Präsens Aktiv (PPA = <span class="sanskrit-dev">लडादेशः</span>)

Das PPA drückt Gleichzeitigkeit aus ("während er ... tut"). Es dekliniert als Adjektiv auf **-ant** (mask./neut.) bzw. **-antī / -atī** (fem.).

### 21.1.1. Deklination bei thematischen Verben (Klasse 1, 4, 6, 10)
::: grammar-box
**Stammbildung**:
- **Starker Stamm**: Präsensstamm + **-ant-** (z.B. _yajant-_).
- **Schwacher Stamm**: Präsensstamm + **-at-** (z.B. _yajat-_).

| Kasus | Maskulinum | Neutrum | Femininum |
| :--- | :--- | :--- | :--- |
| **Nom. Sg.** | yajan (<span class="sanskrit-dev">यजन्</span>) | yajat (<span class="sanskrit-dev">यजत्</span>) | yajantī (<span class="sanskrit-dev">यजन्ती</span>) |
| **Akk. Sg.** | yajantam (<span class="sanskrit-dev">यजन्तम्</span>) | yajat (<span class="sanskrit-dev">यजत्</span>) | yajantīm (<span class="sanskrit-dev">यजन्तीम्</span>) |
| **Gen. Sg.** | yajataḥ (<span class="sanskrit-dev">यजतः</span>) | yajataḥ (<span class="sanskrit-dev">यजतः</span>) | yajantyāḥ (<span class="sanskrit-dev">यजन्त्याः</span>) |
:::

### 21.1.2. Deklination von mahat (<span class="sanskrit-dev">महान्त्</span> = groß)
::: grammar-box
| Kasus | Maskulinum | Neutrum | Femininum |
| :--- | :--- | :--- | :--- |
| **Nom. Sg.** | mahān (<span class="sanskrit-dev">महान्</span>) | mahat (<span class="sanskrit-dev">महत्</span>) | mahatī (<span class="sanskrit-dev">महती</span>) |
| **Akk. Sg.** | mahāntam (<span class="sanskrit-dev">महान्तम्</span>) | mahat (<span class="sanskrit-dev">महत्</span>) | mahatīm (<span class="sanskrit-dev">महतीम्</span>) |

**Merke**: In Komposita wird **mahat** zu **mahā-** (z.B. **mahā-devaḥ**).
:::

## 21.2. Höfliche Anrede (bhavant = <span class="sanskrit-dev">भवान्</span>)

Will man jemanden höflich mit "Sie" ansprechen, verwendet man **bhavant** (m.) bzw. **bhavatī** (f.) mit der **3. Person Singular** des Verbs.

- **kiṃ bhavān karoti?** (<span class="sanskrit-dev">किं भवान्करोति ?</span>) : "Was tun Sie?"
- **kiṃ bhavatī karoti?** (<span class="sanskrit-dev">किं भवती करोति ?</span>) : "Was tun Sie (Gnädige Frau)?"

## 21.3. Wortliste

- **bhakti** f.: Hingabe, Liebe zu Gott.
- **bhagavant** 3: ehrwürdig (Beiname Krishnas).
- **bhikṣu** m.: Mönch.
- **sat / satī**: wahr, seiend / treue Gattin.
- **pac 1 U**: kochen, garen.
