## 45.1. Das Vokativ-Audit (Die Anredeform)

Der Vokativ (Sambhodhana) dient der direkten Anrede. Er weicht im Singular oft vom Nominativ ab.

::: grammar-box
**Übersicht der Vokativ-Formen (Singular)**:

| Stammtyp | Nominativ | Vokativ |
| :--- | :--- | :--- |
| **Mask. auf -a** | devaḥ | **deva** (<span class="sanskrit-dev">देव</span>) |
| **Fem. auf -ā** | devatā | **devate** (<span class="sanskrit-dev">देवते</span>) |
| **Fem. auf -ī** | devī | **devi** (<span class="sanskrit-dev">देवि</span>) |
| **Mask. auf -ṛ** | pitā | **pitar** (<span class="sanskrit-dev">पितर</span>) |
| **Mask. auf -an** | rājā | **rājan** (<span class="sanskrit-dev">राजन्</span>) |
| **Mask. auf -ant** | bhavān | **bhavan** (<span class="sanskrit-dev">भवन्</span>) |
| **Fem. auf -atī** | bhavati | **bhavati** (<span class="sanskrit-dev">भवति</span>) |
:::

## 45.2. Weisheit der Bhagavadgītā (2.37)

Kṛṣṇa stellt Arjuna vor die Wahl:

::: tip Der Appell
**hato vā prāpsyasi svargaṃ jitvā vā bhokṣyase mahīm |**  
**tasmād-uttiṣṭha kaunteya yuddhāya kṛta-niścayaḥ ||**  
<span class="sanskrit-dev">हतो वा प्राप्स्यसि स्वर्गं जित्वा वा भोक्ष्यसे महीम् ।<br>तस्मादुत्तिष्ठ कौन्तेय युद्धाय कृतनिश्चयः ॥</span>  
(Entweder erschlagen wirst du den Himmel erlangen, oder siegreich wirst du die Erde genießen. Deshalb stehe auf, o Sohn der Kuntī, zum Kampfe entschlossen!)
:::

## 45.3. Übung

1. **brāhmaṇa kim-agnau ghṛtam-ajuhoḥ?**  
   (<span class="sanskrit-dev">ब्राह्मण किमग्नौ घृतमजुहोः ॥</span>)  
   "O Brahmane, hast du Schmalz ins Feuer geopfert?"
2. **kanye kiṃ likhasi?**  
   (<span class="sanskrit-dev">कन्ये किं लिखसि ॥</span>)  
   "O Mädchen, was schreibst du?"

## 45.4. Wortliste

- **vā ... vā**: entweder ... oder.
- **kaunteya** m. (Vok.): Sohn der Kuntī (Arjuna).
- **mahī** f.: die Erde.
- **kṛta-niścaya**: entschlossen (wörtl. "dessen Entschluss gefasst ist").
