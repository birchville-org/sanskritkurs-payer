## 39.1. Das Passiv-Futur (Lṛṭ-Karmani = <span class="sanskrit-dev">लृट्-कर्मणि</span>)

Das Passiv-Futur wird gebildet, indem man an den Stamm des Aktiv-Futurs die Endungen des Ātmanepada anfügt.

::: grammar-box
**Struktur: Futurstamm + Ātmanepada-Endung**

- **kṛ** » **kariṣyate** (<span class="sanskrit-dev">करिष्यते</span>) : es wird getan werden.
- **gam** » **gamiṣyate** (<span class="sanskrit-dev">गमिष्यते</span>) : es wird gegangen werden.
- **śru** » **śroṣyate** (<span class="sanskrit-dev">श्रोष्यते</span>) : es wird gehört werden.
:::

## 39.3. Übung

1. **trayodaśa vānarāḥ phalāni bhokṣyante.**  
   (<span class="sanskrit-dev">त्रयोदश वानराः फलानि भोक्ष्यन्ते ॥</span>)  
   "Dreizehn Affen werden Früchte genießen."
2. **aṣṭādaśa purāṇāni brāhmaṇair-adhīyiṣyante.**  
   (<span class="sanskrit-dev">अष्टादश पुराणानि ब्राह्मणैरधीयिष्यन्ते ॥</span>)  
   "Die 18 Purāṇas werden von den Brahmanen studiert werden."

## 39.4. Formen-Audit

Bestimmen Sie die Formen:
- **cikṣipuḥ**: 3. Pl. Perf. P. (sie warfen).
- **ajani**: 3. Sg. Pass. Aor. (er wurde geboren).
- **bibhyati**: 3. Pl. Präs. P. (sie fürchten sich).
- **ajuhavuḥ**: 3. Pl. Impf. P. (sie opferten).
