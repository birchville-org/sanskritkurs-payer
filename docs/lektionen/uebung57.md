# Übung 57

## A) Aorist-Transformationen

Übersetzen und bestimmen Sie die folgenden Formen und bilden Sie die entsprechenden Formen des **Aorists**. Außer bei Kausativen und Wurzeln, die den **s-Aorist** bilden, ist in Klammern die Klasse des entsprechenden Aorists angegeben:

::: grammar-box
| Nr. | Form | Bestimmung / Bedeutung | Aorist |
|:---|:---|:---|:---|
| १. | **पेचिथ** | *पच्* 1U: 2. Sg. Perf. P. (du gartest) | **अपाक्षीः** |
| २. | **अवक्** (३) | *वच्* 2P: 2. 3. Sg. Impf. P. (du sprachst / er sprach) | **अवोचः / अवोचत्** |
| ३. | **सोष्यसि** | *सु* 1/2P: 2. Sg. Fut. P. (du wirst dich fortpflanzen) | **असौषीः** |
| ४. | **छिन्दे** | *छिद्* 7U: 1. Sg. Ind. Präs. Ā. (ich schneide ab) | **अच्छित्सि** |
| ५. | **कुरुषे** | *कृ* 8U: 2. Sg. Ind. Präs. Ā. (du tust im eigenen Interesse) | **अकृथाः** |
| ६. | **आधत्ते** | *आ-धा* 3Ā: 3. Sg. Ind. Präs. Ā. (er setzt hin) | **आधित** |
| ७. | **पद्यते** | *पद्* 4Ā: 3. Sg. Ind. Präs. Ā. (er geht) | **अपादि** |
| ८. | **जिगाय** | *जि* 1P: 1. 3. Sg. Perf. P. (ich siegte / er siegte) | **अजैषीत्** |
| ९. | **जिघ्रामः** (१,६) | *घ्रा* 1P: 1. Pl. Ind. Präs. P. (wir riechen) | **अघ्रास्म / अघ्राम** |
| १०. | **शासति** (२) | *शास्* 2P: 3. Pl. Ind. Präs. P. (sie befehlen) | **अशिषन्** |
| ११. | **स्तुवे** | *स्तु* 2U: 1. Sg. Ind. Präs. Ā. (ich preise) | **अस्तोषi** |
| १२. | **दिग्धे** | *दिह्* 2U: 3. Sg. Ind. Präs. Ā. (er bestreicht) | **अदिग्ध** |
| १३. | **प्लवध्वे** | *प्लु* 1Ā: 2. Pl. Ind. Präs. Ā. (ihr schwimmt) | **अप्लोढ्वम्** |
| १४. | **तस्थिथ** (१) | *स्था* 1P: 2. Sg. Perf. P. (du standest) | **अस्थाः** |
| १५. | **बिभ्यति** | *भी* 3P: 3. Pl. Ind. Präs. P. (sie fürchten) | **अभैषुः** |
| १६. | **ततर्प** | *तृप्* 4/6P: 1. 3. Sg. Perf. P. (ich / er sättigte) | **अतार्प्सीत् / अत्राप्सीत्** |
| १७. | **जुहुथ** | *हु* 3P: 2. Pl. Ind. Präs. P. (ihr opfert) | **अहौष्ट** |
| १८. | **ऊषुः** | *वस्* 1P: 3. Pl. Perf. P. (sie wohnten) | **अवात्सुः** |
| १९. | **ससर्जिथ** | *सृज्* 6P: 2. Sg. Perf. P. (du hast erschaffen) | **अस्राक्षीः** |
| २०. | **लिल्यिरे** | *ली* 4Ā: 3. Pl. Perf. Ā. (sie schmiegen sich an) | **अलेषत / अलासत** |
| २१. | **अत्याजयम्** | *त्यज्* 1P: 1. Sg. Impf. P. Kaus. (ich ließ verlassen) | **अतित्यजम्** |
| २२. | **सिध्यथ** (२) | *सिध्* 4P: 2. Pl. Ind. Präs. P. (ihr seid am Ziel) | **असिधत** |
| २३. | **निन्य** | *नी* 1U: 2. Pl. Perf. P. (ihr habt geführt) | **अनैष्ट** |
| २४. | **कर्षन्ति** | *कृष्* 1P: 3. Pl. Ind. Präs. P. (sie ziehen) | **अकार्क्षुः / अक्राक्षुः** |
| २५. | **अप्रच्छयन्** | *प्रच्छ्* 6P: 3. Pl. Impf. P. Kaus. (sie ließen fragen) | **अपप्रच्छन्** |
:::
