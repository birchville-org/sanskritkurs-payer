## 27.1. Genitiv (Ṣaṣṭhī) und Lokativ (Saptamī)

Zusammenfassung der Endungen für die wichtigsten Stammklassen:

::: grammar-box
| Kasus | Stamm -a (m./n.) | Stamm -ā (f.) | Stamm -i / -u |
| :--- | :--- | :--- | :--- |
| **Gen. Sg.** | -sya (<span class="sanskrit-dev">स्य</span>) | -āḥ (<span class="sanskrit-dev">आः</span>) | -eḥ / -oḥ (<span class="sanskrit-dev">एः / ओः</span>) |
| **Gen. Pl.** | -ānām (<span class="sanskrit-dev">आनाम्</span>) | -ānām (<span class="sanskrit-dev">आनाम्</span>) | -īnām / -ūnām |
| **Lok. Sg.** | -e (<span class="sanskrit-dev">ए</span>) | -ām (<span class="sanskrit-dev">आम्</span>) | -au (<span class="sanskrit-dev">औ</span>) |
| **Lok. Pl.** | -eṣu (<span class="sanskrit-dev">एषु</span>) | -āsu (<span class="sanskrit-dev">आसु</span>) | -iṣu / -uṣu |
:::

## 27.2. Der Lokativus Absolutus

Eine sehr häufige Konstruktion ("während..."). Nomen und Partizip stehen beide im Lokativ.

::: tip Beispiel
**tasmin sati** (<span class="sanskrit-dev">तस्मिन्सति</span>)  
"Während dies ist" = "Unter diesen Umständen" / "Wenn dem so ist".
:::

## 27.3. Pronominaldeklination (tad, yad, kim)

Die Pronomina folgen einem eigenen Deklinationsschema.

::: grammar-box
**Paradigma: tad (er, jener, dieses)**

| Kasus | Maskulinum | Neutrum | Femininum |
| :--- | :--- | :--- | :--- |
| **Nom. Sg.** | saḥ (<span class="sanskrit-dev">सः</span>) | tad (<span class="sanskrit-dev">तद्</span>) | sā (<span class="sanskrit-dev">सा</span>) |
| **Dat. Sg.** | tasmai (<span class="sanskrit-dev">तस्मै</span>) | tasmai (<span class="sanskrit-dev">तस्मै</span>) | tasyai (<span class="sanskrit-dev">तस्यै</span>) |
| **Abl. Sg.** | tasmāt (<span class="sanskrit-dev">तस्मात्</span>) | tasmāt (<span class="sanskrit-dev">तस्मात्</span>) | tasyāḥ (<span class="sanskrit-dev">तस्याः</span>) |
| **Gen. Sg.** | tasya (<span class="sanskrit-dev">तस्य</span>) | tasya (<span class="sanskrit-dev">तस्य</span>) | tasyāḥ (<span class="sanskrit-dev">तस्याः</span>) |
| **Lok. Sg.** | tasmin (<span class="sanskrit-dev">तस्मिन्</span>) | tasmin (<span class="sanskrit-dev">तस्मिन्</span>) | tasyām (<span class="sanskrit-dev">तस्याम्</span>) |
:::

## 27.5. Wortliste

- **viśva** / **sarva**: all, jeder. (Deklinieren wie Pronomina!).
- **ṣaṣṭhī** f.: Genitiv.
- **saptamī** f.: Lokativ.
- **param**: nach (Ablativ).
- **ṛte**: ohne (Ablativ).
