## 3.1. Nominativ Singular = prathamā ekavacanam = <span class="sanskrit-dev">प्रथमा एकवचनम्</span> (Fortsetzung)

### 3.1.1. Nominativ Singular auf -s (Fortsetzung)

Auch folgende Nominalstämme, die mit einem Vokal enden, bilden den Nominativ Singular auf **-s**:

::: grammar-box
- **Feminina auf -i**: z.B. _śruti_ f. "das Hören" -- Nom. sg.: **śrutis = <span class="sanskrit-dev">श्रुतिस्</span>**
- **Feminina auf -u**: z.B. _dhenu_ f. "Milchkuh" -- Nom. sg.: **dhenus = <span class="sanskrit-dev">धेनुस्</span>**
:::

---

### 3.1.2. Nominativ Singular ohne Endung

Den Nominativ Singular bilden ohne Endung:

::: grammar-box
- **Feminina auf -ā**: z.B. _devatā_ f. "Gottheit" -- Nom. sg.: **devatā = <span class="sanskrit-dev">देवता</span>**
- **Feminina auf -ī**: z.B. _devī_ f. "Göttin" -- Nom. sg.: **devī = <span class="sanskrit-dev">देवी</span>**
:::

**Achtung!!** Daneben gibt es einsilbige feminine Wurzelnomina auf **-ī**, deren Nominativ Singular auf **-s** endet:
z.B. _dhī_ f. "Gedanke" -- Nom. sg.: _dhīs_ = <span class="sanskrit-dev">धीस्</span>.

Auch _lakṣmī_ (<span class="sanskrit-dev">लक्ष्मी</span>) f. "Lakṣmī", _tarī_ (<span class="sanskrit-dev">तरी</span>) f. "Boot" und _tantrī_ (<span class="sanskrit-dev">तन्त्री</span>) f. "Saite" bilden unregelmäßig den Nominativ Singular auf **-s**: **lakṣmīs = <span class="sanskrit-dev">लक्ष्मीस्</span>**.

---

## 3.2. Bildung der Feminina zu Maskulina (Adjektive und Substantive)

::: grammar-box
**Maskulina auf -a:**
- **Femininum auf -ā**: z.B. _kṣatriya_ m. » **kṣatriyā** f. "Kṣatriyafrau" = <span class="sanskrit-dev">क्षत्रिया</span>
- **Femininum auf -ī**: z.B. _brāhmaṇa_ m. » **brāhmaṇī** f. "Brahmanin" = <span class="sanskrit-dev">ब्राह्मणणी</span>

Eine feste Regel für die Verteilung der Feminina auf _-ā_ bzw. _-ī_ lässt sich nicht aufstellen (s. Kale, § 305-336).

**Maskulina auf -u:**
- **Femininum auf -ī**: z.B. _sādhu_ m. » **sādhvī** f. (gut, Heilige) = <span class="sanskrit-dev">साध्वी</span>
  (_-u-_ wird vor Vokal durch den Halbvokal _-v-_ ersetzt, darum _-u-ī_ » **-vī**)
:::

---

## 3.3. Nominativ Plural = prathamā bahuvacanam = <span class="sanskrit-dev">प्रथमा बहुवचनम्</span>

::: grammar-box
**Die Endung des Nominativ Plural im Maskulinum und Femininum ist -as.**

- **Maskulina auf -a**: _deva- + -as_ » **devās = <span class="sanskrit-dev">देवास्</span>**
- **Feminina auf -ā**: _devatā- + -as_ » **devatās = <span class="sanskrit-dev">देवतास्</span>**
- **Maskulina auf -i**: _kavi-_ » Hochstufe: _kave- + -as_ » **kavayas = <span class="sanskrit-dev">कवयस्</span>**
- **Feminina auf -i**: _śruti-_ » Hochstufe: _śrute- + -as_ » **śrutayas = <span class="sanskrit-dev">श्रुतयस्</span>**
- **Feminina auf -ī**: _devī- + -as_ » **devyas = <span class="sanskrit-dev">देव्यस्</span>**
- **Maskulina auf -u**: _guru-_ » Hochstufe: _guro- + -as_ » **guravas = <span class="sanskrit-dev">गुरवस्</span>**
- **Feminina auf -u**: _dhenu-_ » Hochstufe: _dheno- + -as_ » **dhenavas = <span class="sanskrit-dev">धेनवस्</span>**
:::

**Anmerkung:** _e_ ist Hochstufe (_guṇa_) zu _i_, _o_ ist Hochstufe zu _u_; _ay_ ist der Vertreter von _e_ vor Vokalen, _av_ ist der Vertreter von _o_ vor Vokalen; _y_ ist der halbvokalische Vertreter von _i_ bzw. _ī_ vor Vokalen.

---

## 3.4. Vokalsandhi

::: grammar-box
**Einfache Vokale, die sich nicht oder nur in ihrer Länge unterscheiden, "verschmelzen" zum entsprechenden langen Vokal:**
- **-a / -ā + a- / ā- » -ā-**
- **-i / -ī + i- / ī- » -ī-**
- **-u / -ū + u- / ū- » -ū-**
- **(-ṛ + ṛ- » -ṝ-)**
:::

Beispiele:
- _devatā + annapūrṇā_ » _devatānnapūrṇā_ = <span class="sanskrit-dev">देवतान्नपूर्णा</span> ("Annapūrṇā ist eine Gottheit")
  - (Annapūrṇā ist die Göttin der Speisen und des Kochens, sie gilt als eine Verkörperung Pārvatīs.)
- _devī + indrāṇī_ » _devīndrāṇī_ = <span class="sanskrit-dev">देवीन्द्राणी</span> ("Indrāṇī ist eine Göttin")
  - (Indrāṇī ist die Gattin des Gottes Indra.)

</div>

::: grammar-box
**Einfache Vokale -- außer -a / -ā -- werden vor unähnlichen Vokalen durch den ihnen entsprechenden Halbvokal ersetzt:**
- **-i / -ī vor a- / ā- / u- / ū- ... / au » -y**
- **-u / -ū vor a- / ā- / i- / ī- / ṛ- ... / au » -v**
- **-ṛ vor a- / ā- / i- / ī- / u- / ū- ... / au » -r**

(!! Zu dieser Regel gibt es insbesondere für Dualformen Ausnahmen !!)
:::

Beispiel: _devī + umā_ » _devy umā_ = <span class="sanskrit-dev">देव्युमा</span> ("Umā ist eine / die Göttin")
- (Umā ist ein Name für Pārvatī, die Gattin Śivas)

::: grammar-box
**-a / -ā vor unähnlichem Vokal:**
- **-a / -ā + i- / ī- » -e-**
- **-a / -ā + ṛ- » -ar-**
- **-a / -ā + e- / ai- » -ai-**
- **-a / -ā + o- / au- » -au-**
:::

Für diesen Sandhi gilt folgendes Schema:

<div align="center">
  <img src="/images/lekt0302.jpg" alt="Stammabstufung Schema">
</div>

z.B. _śūdrā + itarā_ » _śūdretarā_ = <span class="sanskrit-dev">शूद्रेतरा</span> ("Itarā ist eine Śūdrafrau")

## 3.5. Satzsandhi von -ās

::: grammar-box
**-ās wird vor allen stimmhaften Lauten durch -ā ersetzt.**
:::

z.B. _dvijās + vaiśyāḥ_ » _dvijā vaiśyāḥ_ = <span class="sanskrit-dev">द्विजा वैश्याः</span> ("Vaiśyas sind Zweimalgeborene")

## 3.6. Wortliste

**Lernen Sie folgende Wörter:**

**śruti** f. = <span class="sanskrit-dev">श्रुति</span> : das Hören, die ewige Überlieferung (Veden und Brāhmaṇas).

**smṛti** f. = <span class="sanskrit-dev">स्मृति</span> : Vergegenwärtigung, Erinnerung, Achtsamkeit, Überlieferung (Gegenbegriff zu _śruti_). Umfasst:
- die sechs **vedāṅga** (<span class="sanskrit-dev">वेदाङ्ग</span>):
  1. _śikṣā_ (<span class="sanskrit-dev">शिक्षा</span>): rechte Aussprache
  2. _chandas_ (<span class="sanskrit-dev">छन्दस्</span>): Metrum
  3. _vyākaraṇa_ (<span class="sanskrit-dev">व्याकरण</span>): Grammatik
  4. _nirukta_ (<span class="sanskrit-dev">निरुक्त</span>): Worterklärung, Etymologie
  5. _jyotiṣa_ (<span class="sanskrit-dev">ज्योतिष</span>): Astronomie, Kalenderlehre
  6. _kalpa_ (<span class="sanskrit-dev">कल्प</span>): Zeremoniell
- **śrautasūtra** (<span class="sanskrit-dev">श्रौतसूत्र</span>): Lehrwerke für den Vollzug der großen Opfer.
- **gṛhyasūtra** (<span class="sanskrit-dev">गृह्यसूत्र</span>): Lehrwerke für Zeremonien des täglichen Lebens.
- **dharmasūtra** (<span class="sanskrit-dev">धर्मसूत्र</span>) und **dharmaśāstra** (<span class="sanskrit-dev">धर्मशास्त्र</span>): Lehrwerke zu Recht und Sitte.
- die großen Epen **Mahābhārata** (<span class="sanskrit-dev">महाभारत</span>) und **Rāmāyaṇa** (<span class="sanskrit-dev">रामायण</span>).
- die **purāṇa** (<span class="sanskrit-dev">पुराण</span>).
- **nītiśāstra** (<span class="sanskrit-dev">नीतिशास्त्र</span>): Lehrwerke der Lebensklugheit.

_smṛti_ ist besonders auch Bezeichnung für Dharmalehrwerke.

**dhenu** f. = <span class="sanskrit-dev">धेनु</span> : (Milch-)kuh.

**paśu** m. = <span class="sanskrit-dev">पशु</span> : domestiziertes Nutztier, Vieh (Kollektivum).

**devatā** f. = <span class="sanskrit-dev">देवता</span> : Gottheit (abstrakt und konkret).

**brāhmaṇī** f. = <span class="sanskrit-dev">ब्राह्मणी</span> : Brahmanin.

**kṣatriyā** f. = <span class="sanskrit-dev">क्षत्रिया</span> : weibliche Kṣatriya.

**kṣatriyī** f. = <span class="sanskrit-dev">क्षत्रियी</span> : Frau eines Kṣatriya.

**vaiśyā** f. = <span class="sanskrit-dev">वैश्या</span> : weibliche Vaiśya.

**śūdrā** f. = <span class="sanskrit-dev">शूद्रा</span> : weibliche Śūdra.

**śūdrī** f. / **śūdrāṇī** f. = <span class="sanskrit-dev">शूद्री / शूद्राणी</span> : Frau eines Śūdra.

**devī** f. = <span class="sanskrit-dev">देवी</span> : Göttin, insbes. **Durgā** (<span class="sanskrit-dev">दुर्गा</span>), die Gattin Śivas (<span class="sanskrit-dev">शिव</span>).

<div align="center">
  <img src="/images/lekt0303.jpg" alt="Durgā">
  <p>Abb.: Durgā (<span class="sanskrit-dev">दुर्गा</span>), Orissa. [Bildquelle: Wikipedia, GNU FDLizenz]</p>
</div>

**sādhvī** f. = <span class="sanskrit-dev">साध्वी</span> : fem. zu _sādhu_.

**gurvī** f. = <span class="sanskrit-dev">गुर्वी</span> : fem. zu _guru_.

**asmitā** f. = <span class="sanskrit-dev">अस्मिता</span> : "Ich-bin-heit", d.h. der (falsche) Glaube: **Ich** bin es, der sieht usw.

**ānvīkṣikī** f. = <span class="sanskrit-dev">आन्वीक्षिकी</span> : Philosophie (die Wissenschaft, die durch logisch korrekte Begründungen zu ihren Schlussfolgerungen kommt).

**upekṣā** f. = <span class="sanskrit-dev">उपेक्षा</span> : Nichtbeachtung, Gleichmut.

**karuṇā** f. = <span class="sanskrit-dev">करुणा</span> : Mitgefühl, Mitleid.

**muditā** f. = <span class="sanskrit-dev">मुदिता</span> : Freude, insbesondere Mitfreude (Gegensatz zu Neid).

## 3.7. Übung

**A) Setzen Sie folgende Sätze in den Plural:**

1. _dvijo brāhmaṇaḥ_ = <span class="sanskrit-dev">द्विजो ब्राह्मणः</span>
2. _dvijaḥ kṣatriyaḥ_ = <span class="sanskrit-dev">द्विजः क्षत्रियः</span>
3. _dvijo vaiśyaḥ_ = <span class="sanskrit-dev">द्विजो वैश्यः</span>
4. _gurur brāhmaṇaḥ_ = <span class="sanskrit-dev">गुरुर्ब्राह्मणः</span>
5. _sādhur guruḥ_ = <span class="sanskrit-dev">साधुर्गुरुः</span>
6. _guruḥ kaviḥ_ = <span class="sanskrit-dev">गुरुः कविः</span>
7. _sādhvī brāhmaṇī_ = <span class="sanskrit-dev">साध्वी ब्राह्मणी</span>
8. _devatā guruḥ_ = <span class="sanskrit-dev">देवता गुरुः</span>
9. _paśur dhenuḥ_ = <span class="sanskrit-dev">पशुर्धेनुः</span>
10. _gurvī sādhvī_ = <span class="sanskrit-dev">गुर्वी साध्वी</span>

**B) Bilden Sie durch Einsetzen Nominalsätze:**

1. _śrutis ... (veda)_ = <span class="sanskrit-dev">श्रुतिस् ... वेद</span>
2. _paśus ... (dhenu)_ = <span class="sanskrit-dev">पशुस् ... धेनु</span>
3. _devī ... (durgā, umā, indrāṇī)_ = <span class="sanskrit-dev">देवी ... दुर्गा, उमा, इन्द्राणी</span>
4. _devatā ... (mīnākṣī, annapūrṇā)_ = <span class="sanskrit-dev">देवता ... मीनाक्षी, अन्नपूर्णा</span>
5. _śūdrā ... (itarā)_ = <span class="sanskrit-dev">शूद्रा ... इतरा</span>

**C) Übertragen Sie ins Femininum:**

1. _gurur brāhmaṇaḥ_ = <span class="sanskrit-dev">गुरुर्ब्राह्मणः</span>
2. _sādhur guruḥ_ = <span class="sanskrit-dev">साधुर्गुरुः</span>
3. _kṣatriyaḥ sādhuḥ_ = <span class="sanskrit-dev">क्षत्रियः साधुः</span>

**D) Übersetzen Sie ins Sanskrit:**

1. Umā ist eine Göttin.
2. Der Veda ist _śruti_.
3. Die Lehrerinnen sind Göttinnen.
4. Milchkühe sind domestizierte Tiere.
5. Dichter sind Lehrer.
6. Kṣatriyas sind Zweimalgeborene.
7. Die heiligen Männer sind Śūdras.
