## 31.1. Die 7. Präsensklasse (Rudhādi = <span class="sanskrit-dev">रुधादि</span>)

Das Kennzeichen dieser Klasse ist ein Infix (**-na-** stark / **-n-** schwach), das unmittelbar vor dem letzten Konsonanten der Wurzel eingeschoben wird.

::: grammar-box
**Paradigma: rudh (रुध् = hemmen, versperren)**

| Person | Singular | Plural |
| :--- | :--- | :--- |
| **3. P. P.** | ru-ṇa-d-dhi (<span class="sanskrit-dev">रुणद्धि</span>) | run-d-dhanti (<span class="sanskrit-dev">रुन्धन्ति</span>) |
| **3. P. Ā.** | run-d-dhe (<span class="sanskrit-dev">रुन्द्धे</span>) | run-dhate (<span class="sanskrit-dev">रुन्धते</span>) |

**Wichtige Wurzeln**:
- **chid** » **chinatti** (<span class="sanskrit-dev">छिनत्ति</span>) : er schneidet (ab).
- **bhid** » **bhinatti** (<span class="sanskrit-dev">भिनatti</span>) : er spaltet.
- **bhuj** » **bhunakti** (<span class="sanskrit-dev">भूनक्ति</span>) : er genießt / beherrscht.
- **yuñj** » **yunakti** (<span class="sanskrit-dev">युनक्ति</span>) : er verbindet / schirrt an.
:::

## 31.2. Wortliste & Weisheit

- **prajñā** f.: Weisheit, Erkenntnis.
- **bandhana** n.: Fessel, Band.
- **śarīra** n.: Körper, Leib.

## 31.3. Übung

1. **prajñā duḥkha-sambhavaṃ ruṇaddhi...**  
   (<span class="sanskrit-dev">प्रज्ञा दुःखसम्भवं रुणद्धि ॥</span>)  
   "Die Weisheit hemmt das Entstehen von Leiden."

2. **śastrāṇi śarīram-eva chindanti...**  
   (<span class="sanskrit-dev">शस्त्राणि शरीरमेव छिन्दन्ति जीवस्तु न म्रियते ॥</span>)  
   "Waffen schneiden nur den Körper, die Seele aber stirbt nicht." (_Bhagavadgītā_)
