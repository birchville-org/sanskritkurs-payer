## 2.1. Der Nominalsatz

::: grammar-box
**Schema: Prädikatsnomen - Subjekt**

z.B. _devo viṣṇuḥ_ = <span class="sanskrit-dev">देवो विष्णुः</span> = "Viṣṇu ist ein Gott."
:::

Eine verbale Kopula ("ist", "sind", "bin", "bist", "seid") ist nicht nötig, kann aber manchmal vorkommen.

Es gibt **keine Artikel**: _devaḥ_ -- <span class="sanskrit-dev">देवः</span> kann bedeuten "der Gott" oder "ein Gott".

Obwohl im Sanskrit die Satzstellung ziemlich frei ist (besonders in Versen), muss man bei der Übersetzung eines Nominalsatzes immer in erster Linie eine Übersetzung gemäß obigem Standardschema in Betracht ziehen.

Im Nominalsatz steht das Subjekt im Nominativ (ersten Fall = _prathamā_ f. = <span class="sanskrit-dev">प्रथमा</span>). Das Prädikatsnomen stimmt mit dem Subjekt in Zahl und Fall überein; wenn das Prädikatsnomen ein Adjektiv ist, auch im Geschlecht.

## 2.2. Zur Deklination (Beugung von Nomina)

Im Sanskrit gibt es:

- **drei Numeri** (Zählformen) = _vacana_ n. -- <span class="sanskrit-dev">वचन</span>
  - Singular (Einzahl) = _ekavacana_ n. -- <span class="sanskrit-dev">एकवचन</span>
  - Dual (Zweizahl) = _dvivacana_ n. -- <span class="sanskrit-dev">द्विवचन</span>
  - Plural (Mehrzahl) = _bahuvacana_ n. -- <span class="sanskrit-dev">बहुवचन</span>
- **drei Genera** (grammatische Geschlechter) = _liṅga_ n. / _vyakti_ f. -- <span class="sanskrit-dev">लिङ्ग / व्यक्ति</span>
  - Maskulinum (männlich) = _puṃs_ m. -- <span class="sanskrit-dev">पुंस्</span>
  - Femininum (weiblich) = _strī_ f. -- <span class="sanskrit-dev">स्त्री</span>
  - Neutrum (sächlich) = _napuṃsaka_ n. -- <span class="sanskrit-dev">नपुंसक</span>
- **acht Kasus** (Fälle) = _sup_ -- <span class="sanskrit-dev">सुप्</span> (= Kasusendungen)

Zur Deklination treten die Kasusendungen (_sup_ = <span class="sanskrit-dev">सुप्</span>) an den sogenannten **Nominalstamm** (Form des Nomens ohne Kasusendungen).

Beispiel: _devas_ = <span class="sanskrit-dev">देवस्</span> (Nominativ Singular Maskulinum) "der/ein Gott" = _deva-_ -- <span class="sanskrit-dev">देव-</span> (Nominalstamm) + _-s_ -- <span class="sanskrit-dev">-स्</span> (Kasusendung).

In Sanskritwörterbüchern werden Nomina im **Nominalstamm** angeführt:
- _deva_ m. -- <span class="sanskrit-dev">देव</span> m. (maskulin)
- _vacana_ n. -- <span class="sanskrit-dev">वचन</span> n. (neutrum)
- _vyakti_ f. -- <span class="sanskrit-dev">व्यक्ति</span> f. (femininum)

## 2.3. Der Nominativ Singular

**Nominativ Singular = prathamā ekavacanam = <span class="sanskrit-dev">प्रथमा एकवचनम्</span>**

::: grammar-box
Der Nominativ Singular endet auf **-s = <span class="sanskrit-dev">-स्</span>** bzw. ist endungsfrei.
:::

**2.3.1. Nominativ Singular auf -s**

Folgende Nominalstämme, die mit einem Vokal enden, bilden den Nominativ Singular auf _-s_:
- **Maskulina auf -a**: z.B. _deva_ m. = <span class="sanskrit-dev">देव</span> "Gott" -- Nom. sg.: _devas_ = <span class="sanskrit-dev">देवस्</span>
- **Maskulina auf -i**: z.B. _kavi_ m. = <span class="sanskrit-dev">कवि</span> "Dichter" -- Nom. sg.: _kavis_ = <span class="sanskrit-dev">कविस्</span>
- **Maskulina auf -u**: z.B. _guru_ m. = <span class="sanskrit-dev">गुरु</span> "Lehrer" -- Nom. sg.: _gurus_ = <span class="sanskrit-dev">गुरुस्</span>

## 2.4. Sandhi -- <span class="sanskrit-dev">सन्धि</span>

Der Auslaut eines Wortes richtet sich im Sanskrit auch nach dem Anlaut des darauffolgenden Wortes. Diese Erscheinung nennt man **Sandhi** (m.) = <span class="sanskrit-dev">सन्धि</span> ("Verbindung").

**2.4.1. Sandhi von auslautendem -s**

Auslautendes _-s_:

- **im absoluten Auslaut (Satzende, Versende)** wird ersetzt durch **Visarga (-ḥ)**:
  - _devas_ » _devaḥ_ = <span class="sanskrit-dev">देवः</span>
  - _kavis_ » _kaviḥ_ = <span class="sanskrit-dev">कविः</span>
  - _gurus_ » _guruḥ_ = <span class="sanskrit-dev">गुरुः</span>

- **vor stimmlosen Lauten**:
  - **vor stimmlosen Gutturalen (k, kh)**: wird ersetzt durch **Visarga (-ḥ)**
  - **vor stimmlosen Labialen (p, ph)**: wird ersetzt durch **Visarga (-ḥ)**
  - **vor stimmlosen Zischlauten (ś, ṣ, s)**: wird ersetzt durch **Visarga (-ḥ)**
    - _devas + śivaḥ_ » _devaḥ śivaḥ_ = <span class="sanskrit-dev">देवः शिवः</span> ("Śiva ist ein Gott")
    - _kavis + kālidāsas_ » _kaviḥ kālidāsaḥ_ = <span class="sanskrit-dev">कविः कालिदासः</span> ("Kālidāsa ist ein Dichter")
  - **vor stimmlosen Palatalen (c, ch)**: wird ersetzt durch **-ś**
  - **vor stimmlosen Retroflexen (ṭ, ṭh)**: wird ersetzt durch **-ṣ**
  - **vor stimmlosen Dentalen (t, th)**: bleibt **-s** (d.h. in diesen Fällen steht der Zischlaut der Klasse des Anlauts)
    - _sādhus + caitanyas_ » _sādhuś caitanyaḥ_ = <span class="sanskrit-dev">साधुश्चैतन्यः</span> ("Caitanya ist ein Heiliger")

- **vor stimmhaften Lauten**:
  - **nach Nicht-a-Vokalen (außer vor r-)**: wird ersetzt durch **-r**
    - _kavis + Māghas_ » _kavir māghaḥ_ = <span class="sanskrit-dev">कविर्माघः</span> ("Māgha ist ein Dichter")
  - **nach Nicht-a-Vokalen vor r-**: **-s fällt aus**, ein dem -s vorhergehender kurzer Vokal wird durch den entsprechenden langen Vokal ersetzt, ein vorausgehender langer Vokal bleibt unverändert
    - _gurus + rāmas_ » _gurū rāmaḥ_ = <span class="sanskrit-dev">गुरू रामः</span> ("Rāma ist ein Lehrer")
  - **nach a-**: auslautendes **-as**
    - **vor stimmhaften Konsonanten und vor a**: wird ersetzt durch **-o**, anlautendes **a-** fällt nach diesem **-o** weg
      - _devas viṣṇus_ » _devo viṣṇuḥ_ = <span class="sanskrit-dev">देवो विष्णुः</span> ("Viṣṇu ist ein Gott")
      - _devas agnis_ » _devo 'gniḥ_ = <span class="sanskrit-dev">देवो ऽग्निः</span> ("Agni ist ein Gott")
    - **vor anderen Vokalen als -a**: **-as** wird ersetzt durch **-a** mit Hiatus
      - _devas + indras_ » _deva indraḥ_ = <span class="sanskrit-dev">देव इन्द्रः</span> ("Indra ist ein Gott")

## 2.5. Wortliste

**deva** m. -- <span class="sanskrit-dev">देव</span> : Himmlischer, Gott; Fürst, König.

**īśvara** m. -- <span class="sanskrit-dev">ईश्वर</span> : Herr, Herrscher, Gott (monotheistisch).

**brāhmaṇa** m. -- <span class="sanskrit-dev">ब्राह्मण</span> : Brahmane (geistlicher Stand).

**kṣatriya** m. -- <span class="sanskrit-dev">क्षत्रिय</span> : Kṣatriya (Fürsten- und Wehrstand).

**vaiśya** m. -- <span class="sanskrit-dev">वैश्य</span> : Vaiśya (Nähr- und Händlerstand).

**śūdra** m. -- <span class="sanskrit-dev">शूद्र</span> : Śūdra (Dienstleistungsstand).

::: info Die vier Stände (varna)
Nach der klassischen Theorie (Manusmṛti) sind die Aufgaben verteilt:
- **Brahmanen**: Studium, Lehre, Opfer, Geben/Empfangen.
- **Kṣatriyas**: Volksschutz, Gaben, Opfer, Studium.
- **Vaiśyas**: Viehhaltung, Landwirtschaft, Handel, Studium.
- **Śūdras**: Dienst an den drei oberen Klassen.
:::

**dvija** m. -- <span class="sanskrit-dev">द्विज</span> : "Zweimalgeborener" (Initiierte der oberen drei Stände).

**varṇa** m. -- <span class="sanskrit-dev">वर्ण</span> : Farbe, Geburtsstand.

**Exkurs: Max Weber über den "Stand"**
»Stand« soll eine Vielheit von Menschen heißen, die innerhalb eines Verbandes wirksam eine ständische Sonderschätzung oder Sondermonopole in Anspruch nehmen. Stände können entstehen:
1. primär durch Lebensführung/Beruf.
2. sekundär durch Abstammung (Geburtsstände).
3. durch Appropriation von Macht.
:::

## 2.6. Übung

**A) Setzen Sie unter Beachtung des Sandhi ein und bilden Sie Nominalsätze:**

1. _devas ... (Śiva, Agni, Viṣṇu, Gaṇeśa, Kṛṣṇa, Indra)_  
   = <span class="sanskrit-dev">देवस् ... (शिव, अग्नि, विष्णु, गणेश, कृष्ण, इन्द्र)</span>
2. _dvijas ... (brāhmaṇa, kṣatriya, vaiśya)_  
   = <span class="sanskrit-dev">द्विजस् ... (ब्राह्मण, क्षत्रिय, वैश्य)</span>
3. _gurus ... (brāhmaṇa, Candrakīrti)_  
   = <span class="sanskrit-dev">गुरुस् ... (ब्राह्मण, चन्द्रकीर्ति)</span>
4. _vaiśyas ... (Tulādhara)_  
   = <span class="sanskrit-dev">वैश्यस् ... (तुलाधर)</span>
5. _sādhus ... (guru, Rāma)_  
   = <span class="sanskrit-dev">साधुस् ... (गुरु, राम)</span>
6. _kavis ... (Kālidāsa, Māgha, Bhāravi, Harṣadeva)_  
   = <span class="sanskrit-dev">कविस् ... (कालिदास, माघ, भारवि, हर्षदेव)</span>

**B) Übersetzen Sie ins Sanskrit:**

1. Rāma ist ein Brahmane.
2. Der Lehrer ist ein Vaiśya.
3. Der Śūdra ist ein heiliger Mann.
4. Der Dichter ist der Lehrer.
5. Viṣṇu ist der HERR.
6. Der HERR ist Śiva.
7. Der Zweimalgeborene ist ein Brahmane.
8. Der heilige Mann ist ein Lehrer.
9. Der Lehrer ist ein heiliger Mann.
