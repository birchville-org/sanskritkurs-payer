## 43.1. Stämme auf -ant (Partizip Präsens)

Die Präsenspartizipien (Aktiv) enden auf **-ant**. Sie werden wie Adjektive dekliniert.

::: grammar-box
**Paradigma: bhavant (seiend / von bhū)**

| Kasus | Singular | Plural |
| :--- | :--- | :--- |
| **Nominativ** | bhava-n (<span class="sanskrit-dev">भवन्</span>) | bhava-ntaḥ (<span class="sanskrit-dev">भवन्तः</span>) |
| **Akkusativ** | bhava-ntam (<span class="sanskrit-dev">भवन्तम्</span>) | bhava-taḥ (<span class="sanskrit-dev">भवतः</span>) |
| **Instrumental** | bhava-tā (<span class="sanskrit-dev">भवता</span>) | bhava-dbhiḥ (<span class="sanskrit-dev">भवद्भिः</span>) |
:::

## 43.2. Stämme auf -mant und -vant (Besitz)

Diese Suffixe drücken aus, dass jemand etwas besitzt (z.B. "Geist habend").

::: grammar-box
- **buddhi** (Einsicht) » **buddhimant** (<span class="sanskrit-dev">बुद्धिमन्</span>) : einsichtig, klug.
- **bhaga** (Glück/Glanz) » **bhagavant** (<span class="sanskrit-dev">भगवन्</span>) : ehrwürdig, herrlich.  
  _Nom. Sg. mask._ **bhagavān** (<span class="sanskrit-dev">भगवान्</span>).
:::

## 43.3. Ashoka und der Kaufmann (Dialog)

Ashoka möchte für ein Geburtstagsfest Zucker kaufen:

| Sprecher | Dialog |
| :--- | :--- |
| **Ashoka** | **bho vaṇik! śarkarā-mūlyam-alpaṃ kim?**<br><span class="sanskrit-dev">भो वणिक् । शर्करामूल्यमल्पं किम् ?</span><br>(He, Kaufmann! Ist der Preis für Zucker niedrig?) |
| **Kaufmann** | **āṃ bālaka! alpīyas-eva mūlyam.**<br><span class="sanskrit-dev">आं बालक । अल्पीयसेव मूल्यम् ।</span><br>(Ja, Junge! Der Preis ist überaus gering.) |
| **Ashoka** | **gṛhāṇa mūlyam. mayā hi śīghraṃ gṛhaṃ gantavyam.**<br><span class="sanskrit-dev">गृहण मूल्यम् । मया हि शीघ्रं गृहं गन्तव्यम् ।</span><br>(Nimm den Preis. Ich muss nämlich schnell nach Hause.) |

## 43.4. Wortliste

- **vaṇij** m.: Kaufmann, Händler.
- **śarkarā** f.: Zucker.
- **mūlyam** n.: Preis, Wert.
- **paścāttāpa** m.: Reue (wörtl. "Nach-Hitze").
