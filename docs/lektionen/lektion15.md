## 15.2. Determinativkomposita (Tatpuruṣa = <span class="sanskrit-dev">तत्पुरुष</span>)

Ein **Tatpuruṣa** ist ein Kompositum, bei dem das Vorderglied das Hinterglied näher bestimmt.

::: grammar-box
**Bezeichnung**: **tat-puruṣaḥ** = <span class="sanskrit-dev">तस्य पुरुषः</span> ("sein Knecht").
- **Karmadhāraya**: Vorderglied ist Attribut oder Apposition.
- **Kasus-Tatpuruṣa**: Vorderglied steht im Verhältnis eines schrägen Kasus (meist Genetiv).

Das Geschlecht richtet sich in der Regel nach dem **Hinterglied**.
:::

---

## 15.3. Karmadhāraya (Appositionelle Komposita)

Beide Glieder stehen bei der Auflösung im selben Kasus.
- **guṇavat-putraḥ** = "ein tugendhafter Sohn" (<span class="sanskrit-dev">गुणवान्पुत्रः</span>)
- **iṣṭa-devatā** = "die gewünschte Gottheit" (<span class="sanskrit-dev">इष्टा देवता</span>)

- **nara-siṃhaḥ** = "ein Mann wie ein Löwe" (<span class="sanskrit-dev">सिंह इव नरः</span>)

## 15.4. Kasus-Tatpuruṣa

Das Vorderglied vertritt einen schrägen Kasus (Akk., Instr., Gen. etc.).
- **kṣatriya-putraḥ** = "Sohn eines Kṣatriya" (Genetiv-Tatpuruṣa).
- **grāma-gataḥ** = "ins Dorf gegangen" (Akkusativ-Tatpuruṣa).
- **deva-kṛtam** = "von Gott getan" (Instrumentalis-Tatpuruṣa).

---

## 15.5. Zerlegung langer Komposita

Komposita werden hierarchisch in je **zwei Teile** zerlegt.

::: grammar-box
Beispiel: **guṇavat-putra-kṛta-puṇyam**
1. [guṇavat-putra-kṛta] + [puṇyam]
2. [[guṇavat-putra] + kṛta]
3. [[guṇavat] + putra]
= "das von einem tugendhaften Sohn getane Verdienst"
:::

## 15.6. Wortliste

- **athavā**: oder.
- **caturtha** (f. **-ī**): vierter.
- **pūjā** f.: religiöse Verehrung.
- **kula** n.: Familie, Geschlecht.
- **indra** m.: Fürst, Götterkönig.
