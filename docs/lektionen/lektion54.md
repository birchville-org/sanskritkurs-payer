## 54.2. Wortbildung: Desiderativstämme auf -u

An Desiderativstämme ("etwas zu tun wünschen") tritt zur Bildung von _Nomina agentis_ das Suffix **-u**.

::: grammar-box
**Beispiel**:
**yuyutsu** (yu-yudh + s + u): "kampfbegierig, im Begriffe zu kämpfen".
:::

## 54.3. Metrik II: Triṣṭubh und Jagatī

Die **Triṣṭubh** ("Drei-Jauchzer") erscheint in den Epen oft an Stellen mit besonderem emotionalem Aufschwung. Sie besteht aus vier elfsilbigen _pāda_.

::: grammar-box
**Wichtige Formen**:
- **Indravajrā**: <span class="sanskrit-dev">स्यादिन्द्रवज्रा यदि तौ जगौ गः ।</span>
- **Upendravajrā**: <span class="sanskrit-dev">उपेन्द्रवज्रा प्रथमे लघौ सा ।</span>
- **Upajāti**: Mischform aus den beiden obigen Metren.
:::

## 54.4. Der Aorist (Luṅ = <span class="sanskrit-dev">लुङ्</span>)

Allen Bildungstypen des Aorist gemeinsam ist das **Augment a-**. Es gibt sieben Haupttypen, eingeteilt in nichtsibilantische und sibilantische Aoriste.

### 54.4.1. Wurzelaorist
**Bildung: Augment + Wurzel + Sekundärendung**

Beispiel: **pā** (trinken)
| Person | Singular | Plural |
| :--- | :--- | :--- |
| **3. P.** | apāt | apuḥ |
| **2. P.** | apāḥ | apāta |
| **1. P.** | apām | apāma |

---

## 54.5. Der Passiv-Aorist (3. Sg.)

Diese Spezialform kann von allen Wurzeln gebildet werden.

::: grammar-box
**Bildung: Augment + Wurzel + i**

- **Hochstufe**: bei kurzem Vokal (außer _a_). Bsp: _bhid_ » **abhāidi** (er wurde gespalten).
- **Dehnstufe**: bei auslautendem Vokal. Bsp: _kṛ_ » **akāri** (es wurde gemacht).
- **y-Einschub**: bei Wurzeln auf _-ā_. Bsp: _dā_ » **adāyi** (es wurde gegeben).
:::
