# Lektion 7

::: info Wochenspruch
<div align="center" style="font-style: italic;">
  <p class="sanskrit-dev" style="font-size: 1.2rem;">धर्मो जयति नधर्मः<br>सत्यं जयति नानृतम्<br>क्षमा जयति न क्रोधो<br>देवो जयति नासुरः</p>
  <p>dharmo jayati nādharmaḥ / satyaṃ jayati nānṛtam |<br>kṣamā jayati na krodho / devo jayati nāsuraḥ</p>
  <p>Das Recht siegt, nicht das Unrecht,<br>Die Wahrheit siegt, nicht die Unwahrheit,<br>Nachsicht siegt, nicht Zorn,<br>Gott siegt, nicht der Widergott.</p>
</div>
:::

## 7.1. Der Verbalsatz mit direktem Objekt

::: grammar-box
**Schema: (Agens = kartṛ m. = <span class="sanskrit-dev">कर्तृ</span>) - direktes Objekt (karman n. = <span class="sanskrit-dev">कर्मन्</span>) - Verb**

Beispiel:
_rāmaḥ phalaṃ khādati_ = <span class="sanskrit-dev">रामः फलं खादति</span> = "Rāma isst eine Frucht."

Steht das Verb im **Aktiv** (Parasmaipada/Ātmanepada), steht das direkte Objekt im **Akkusativ** (_dvitīyā_ = <span class="sanskrit-dev">द्वितीया</span>).
:::

## 7.3. Sandhi von auslautendem -n

::: grammar-box
Auslautendes **-n**:
1. Vor **j-, ś-** » **-ñ** (meist _ś-_ » _ch-_).
   - _gurūn + śṛṇoti_ » _gurūñ chṛṇoti_ = <span class="sanskrit-dev">गुरूञ्छृणोति</span>
2. Vor **l-** » nasaliertes **-l-**.
3. Vor **c-, t-** » **Anusvāra + Zischlaut**.
   - _devān + ca_ » _devāṃś ca_ = <span class="sanskrit-dev">देवांश्च</span>
   - _devān + tu_ » _devāṃs tu_ = <span class="sanskrit-dev">देवांस्तु</span>
:::

## 7.4. Das Neutrum (napuṃsaka = <span class="sanskrit-dev">नपुंसक</span>)

Im Neutrum sind Nominativ und Akkusativ identisch.
- **Singular**: _phalam_ (<span class="sanskrit-dev">फलम्</span>)
- **Plural**: _phalāni_ (<span class="sanskrit-dev">फलानि</span>)

---

## 7.5. 5. Präsensklasse (svādi = <span class="sanskrit-dev">स्वादि</span>)

::: grammar-box
Athematische Verben haben Stammabstufung:
- **Starker Stamm** (sg. P.): Wurzel + **-no-**
- **Schwacher Stamm** (sonst): Wurzel + **-nu-** (vor Vokal: _-nv-_ / _-nuv-_)

| Wurzel | 3. sg. P. | 3. pl. P. |
| :--- | :--- | :--- |
| **śru** (hören) | śṛṇoti (<span class="sanskrit-dev">शृणोति</span>) | śṛṇvanti (<span class="sanskrit-dev">शृण्वन्ति</span>) |
| **āp** (erlangen) | āpnoti (<span class="sanskrit-dev">आप्नोति</span>) | āpnuvanti (<span class="sanskrit-dev">आप्नुवन्ति</span>) |
:::

---

## 7.6. Wortliste

- **aś 5 Ā**: erlangen.
- **āp 5 P**: erreichen.
- **khād 1 P**: essen, kauen.
- **śru 5 P**: hören.
- **gam 1 P**: gehen (_gacchati_).
- **phala** n.: Frucht.
- **svarga** m. / **naraka** m.: Himmel / Hölle.
