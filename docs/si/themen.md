# ව්‍යාකරණ දර්ශකය

ව්‍යාකරණ දර්ශකය සංස්කෘත පාඨමාලාවේ ඇති සියලු ව්‍යාකරණ මූලධර්ම සහ දේශීය ලක්ෂණ ලැයිස්තුගත කර, නිශ්චිත පාඩම් වෙත ඉක්මනින් ප්‍රවේශ වීමට හැකියාව ලබා දෙයි.
