# පාඩම 22

## 22.1. උත්සර්ග පදය (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

සංස්කෘත භාෂාවේදී, ක්‍රියාකාරිත්වයක් (⟪कर्तृ⟫) අනෙකුත් ක්‍රියාකාරිත්වයක් මත පෙර සිදුවන බව හෝ එම ක්‍රියාකාරිත්වය සමඟ සහචර තත්ත්වයක් ලෙස සිදුවන බව ප්‍රකාශ කිරීමට, උත්සර්ග පදය (⟪क्त्वा । ल्यप्⟫) භාවිතා කරයි. එනම්

"එය කළ පසු, ඔහු එම කරුණ සිදු කරයි" ; "ඔහු මෙය සිදු කරයි, පසුව ඔහු එම කරුණ සිදු කරයි" ; "මෙය නිසා ඔහු එම කරුණ සිදු කරයි" ; "මම පැමිණියෙමි, දුටුවෙමි සහ ජය ගත්තෙමි" වැනි ප්‍රකාශ.

උත්සර්ග පදය යනු ක්‍රියා විශේෂණයකි, එනම් එය ක්‍රියාපද වින්‍යාසයට හෝ වචන වින්‍යාසයට භාජනය නොවේ, කෙසේ වෙතත් එය සැමවිටම - සුළු අපවාද කිහිපයක් හැර - උත්සර්ග පදය මඟින් සංකේතවත් කරනු ලබන ක්‍රියාකාරිත්වයට පෙර සිදුවන හෝ එය සහචර තත්ත්වයක් ලෙස සිදුවන ක්‍රියාකාරිත්වයේ ක්‍රියාකාරිත්වය (⟪कर्तृ⟫) සමඟ එකම වේ. උත්සර්ග පදයේ ක්‍රියාකාරිත්වය නිරූපණ පද (⟪प्रथमा⟫) හෝ කරණ පද (⟪तृतीया⟫) වලින් පවතී.

සංයුක්ත වචන හැර, උත්සර්ග පදය යනු සංස්කෘත භාෂාවේ වඩාත් පොදු ප්‍රකාශන මාර්ගවලින් එකකි.

ජර්මානු භාෂාවට පරිවර්තනය කිරීමේදී, "පසු" යන වචනය නිතරම භාවිතා කිරීමෙන් වැළකිය යුතුය. එහි ප්‍රතිවාර්තයක් ලෙස, කාලීන අනුපිළිවෙල සඳහා ජර්මානු භාෂාවේ පොදුවෙන් භාවිතා වන ප්‍රකාශන මාර්ග භාවිතා කළ යුතුය.

**ප්‍රස්තාරය:**

(උත්සර්ග පදය සම්බන්ධව වැඩි විස්තර: තත්ත්ව නිරූපණය, වස්තු පද ආදිය) - උත්සර්ග පදය - උත්සර්ග පදය - ... - උත්සර්ග පදය - ... ක්‍රියාකාරිත්වය + ක්‍රියා පද වාක්‍යය (සක්‍රීය හෝ නිෂ්ක්‍රීය)

:::
**උදාහරණ:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = නිෂ්ක්‍රීය වාක්‍ය වින්‍යාසය: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**  
"පුරුෂයා ගෙදරට පිවිසෙයි, කුඩා දැරිය දකී සහ ඇය හමුවෙයි."

බහු වචනය: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. ආබාෂිත පදය සෑදීම

::: grammar-box
**ආබාෂිත පදය සෑදීම**

*   උපසර්ග රහිත ක්‍රියාපද: **-tvā** මත ආබාෂිත පදය
*   උපසර්ග සහිත ක්‍රියාපද: **-ya** හෝ **-tya** මත ආබාෂිත පදය
:::
### 22.2.1. උපසර්ග රහිත ක්‍රියාපද: -⟪त्वा⟫ මත ආබාෂිත පදය

::: grammar-box

**සෑදීම:**

(බහුලව) PPP ට පෙර ඇති හැඩයෙන් යුත් ගාඪ ශ්‍රේණියේ මූලය + **-tvā** (**-⟪त्वा⟫**)

ඍණ **a-** / **an-** පමණක් **-⟪त्वा⟫** ප්‍රත්‍යය සමඟ ගැලපේ: ⟪अकृत्वा⟫ "කර නොමැතිව"

:::
**උදාහරණ:**

::: indent
⟪आप्त्वा⟫ "ඔහු / ඇය / එය / මම / ඔබ / අපි / ඔවුන් / අප දෙදෙනා / ඔබ දෙදෙනා / ඔවුන් දෙදෙනා ලඟා වූ පසු / ලඟා වී ඇත"

⟪आसित्वा⟫ "ඔහු (...) සිටගෙන / සිටියේ නම්"

⟪इत्वा⟫ "ඔහු (...) ගිය පසු / ගොස් ඇත"

⟪स्थित्वा⟫ "ඔහු (...) සිටගෙන / සිටියේ නම්"

⟪जित्वा⟫ "ඔහු (...) ජය ගත් පසු / ජයගෙන ඇත"

⟪उक्त्वा⟫ "ඔහු (...) කතා කළ පසු / කතා කර ඇත"
:::
### 22.2.2. උපසර්ග සහිත ක්‍රියාපද

#### 22.2.2.1. දිග ස්වරයකින් ( -ā හැර ) හෝ ව්‍යංජනයකින් අවසන් වන මූල

::: grammar-box

**(බහුලව) ගාඪ ශ්‍රේණියේ මූලය + -ya**

:::
**උදාහරණ:**

::: indent
⟪उपनीय⟫ "ඔහු (...) ගෙන ආ පසු / ගෙනවා ඇත"

⟪प्रभूय⟫ "ඔහු (...) පිටතට දිස් වූ පසු / වී ඇත" "ඔහු (...) බලය ලැබූ පසු / ලැබී ඇත"

⟪प्राप्य⟫ "ඔහු (...) ලබා ගත් පසු / ලබාගෙන ඇත"
:::
#### 22.2.2.2. -ā මත අවසන් වන මූල

::: grammar-box

**වෙනස් නොකළ උච්ච ශ්‍රේණියේ මූලය + -ya**

:::
**උදාහරණය:**

::: indent
⟪उपस्थाय⟫ "ඔහු (...) පියවර තැබූ පසු / තැබී ඇත" ; (නමුත් උපසර්ග රහිතව: ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. ගාඪ ශ්‍රේණියේදී කෙටි -i, -u, -ṛ මත අවසන් වන මූල

::: grammar-box

**ඉතා අඩු මට්ටමේ මූලය + -tya**

:::
**උදාහරණ:**

::: indent
⟪प्रस्तुत्य⟫ "ඔහු (...) උද්දීපනය කළ පසු / කළේය"

⟪विस्मृत्य⟫ "ඔහු (...) මතකයෙන් ඉවත් වූ පසු / විය"

⟪संस्कृत्य⟫ "ඔහු (...) පූජාව සඳහා සකස් කළ පසු / කළේය"
:::
#### 22.2.2.4. -am / -an මත අවසන් වන, ඉතා අඩු මට්ටමේ -a මත අවසන් වන මූල

::: grammar-box

**විකල්පය:**

**-am** / **-an** මත අවසන් වන මූලය + **-ya**

හෝ:

**-a** මත අවසන් වන මූලය + **-tya**

:::
**උදාහරණය:**

::: indent
⟪विगम्य⟫ හෝ ⟪विगत्य⟫ "ඔහු (...) ගත වූ පසු / විය"
:::
## 22.3. වචන මාලාව

**⟪काम⟫ පු.:** ආශාව, කැමැත්ත; අපේක්ෂිත දානය, ඉන්ද්‍රිය සුවය, ප්‍රේමය, කාම දෙවියා

::: indent
⟪कामम्⟫ ක්‍රියා විශේෂණය ලෙස උක්ත: කැමති පරිදි, හෘදයට අනුව
:::
