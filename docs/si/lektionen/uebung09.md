# පුහුණුව 9

A) පහත සඳහන් වචනවල ඇති කළ හැකි අර්ථ තීරණය කර බලන්න:

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. බ්‍රාහ්මණයෙකුට සමාන වූවෙක් = නරක බ්‍රාහ්මණයෙක්

2\. mati ⟪मति⟫ : f. මතය

3\. śravaṇa ⟪श्रवण⟫ : n. කන

4\. dhenuka ⟪धेनुक⟫ : m. (සංගමය) ගවයෙකුගේ ආකාරයෙන්

5\. jayaka ⟪जयक⟫ : 3 ජයග්‍රාහී

6\. rakṣikā ⟪रक्षिका⟫ : f. රැකවරණය කරන්නිය, අමුලෙට්

7\. karṣaka ⟪कर्षक⟫ : 3 බිඳීම ; m. ගොවියා

8\. kleśa ⟪क्लेश⟫ : m. වේදනාව

9\. nāyikātva ⟪नायिकात्व⟫ : n. ප්‍රේමිකාවෙකුගේ තත්වය

10\. tantraka ⟪तन्त्रक⟫ : 3 (නිවැරදිව) රෙදි පටියෙන් / වයනයෙන් එන = නවීනව වැළඳුණු

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : නර්තකයා

12\. naraka ⟪नरक⟫ : m. නරකය

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. ප්‍රභුත්වය

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. සටන්කරු

17\. kopa ⟪कोप⟫ : m. කෝපය

18\. veśaka ⟪वेशक⟫ : 3 ඇතුළු වන

19\. darśaka ⟪दर्शक⟫ : 3 බලන

20\. kopaka ⟪कोपक⟫ : 3 කෙටි මනස්කාන්තයෙක්, ඉක්මනින් කෝපයට පත්වන්නා

B) පරිවර්තනය කරන්න:

1\. දෙවරක් උපන් සියලු දෙනාගේ වැඩ:

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

(යාඥාවල්ක්‍ය ධර්මශාස්ත්‍ර I, 118)

බලිදීම, වේද අධ්‍යයනය, දාන දීම.

2\. බ්‍රාහ්මණයෙකුගේ විශිෂ්ට වැඩ:

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

(ගෞතම ධර්මසූත්‍ර X,2)

උපදෙස් දීම, බලිදීම සඳහා ඇණවුම් කිරීම, දාන පිළිගැනීම.

3\. ක්ෂත්‍රියයෙකුගේ විශිෂ්ට වැඩ:

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं सर्वभूतानाम्⟫

(sarvabhūtānām = ජනකාරී (වස්ත්‍ර ප්‍රභේදය): "සියලු ජීවීන්ගේ")

(ගෞතම ධර්මසූත්‍ර X,7)

සියලු ජීවීන් රැකබලා ගැනීම.

4\. විශේෂ වාය්‍යයන්:

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(ගෞතමධර්මසූත්‍ර X,49 අනුව)

කෘෂිකර්මය, වෙළඳාම, සත්වපාලනය සහ මුදල් ණය.

5\. ශූද්‍රයෙකුගේ වාය්‍යයන්:

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं शुश्रूषा वार्त्त्ता कारुकुशीलवकर्म च⟫

(කෞටිලීය අර්ථශාස්ත්‍ර 1.3.8. අනුව)

පැහැදිලි කිරීම:
dvijātīnām = Genetiv (වස්තෘ පද) Bahuvachana dvijāti සඳහා (මෙහිදී "ද්විජයන්ට සාපේක්ෂව" ලෙස පරිවර්තනය කරන්න)

kārukuśīlavakarma යනු පූර්වපදයේ Dvandva (kārukuśīlava) සහිත Tatpuruṣa වේ. karma = karman n "කර්මය, කාර්යය" සඳහා Nom. sg. (kṛ 8 U මූලයට). "කර්මය / ... (Dvandva මගින් සඳහන් කරන ලද) කාර්යය" (Genetiv) ලෙස පරිවර්තනය කරන්න.

ද්විජයන්ට අනුගත වීම, ජීවනෝපාය සඳහා කාර්යයන්, ශිල්පී හෝ චලන සංවේදකයෙකු ලෙස කාර්යය.

6\. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः पाशुपाल्यं वणिज्या च वार्त्ता⟫

(කෞටිලීය අර්ථශාස්ත්‍ර 1.4.1. අනුව)

ආර්ථිකය යනු කෘෂිකර්මය, සත්වපාලනය සහ වෙළඳාමයි.
