# පාඩම 29

## 29.1. හේතුක පදය තුළ පරස්මৈපද (⟪परस्मैपद⟫) සහ ආත්මනෙපද (⟪आत्मनेपद⟫) භාවිතය


::: grammar-box
**හේතුක පදය සීමිත අවස්ථා හැර උභයපද (⟪उभयपद⟫) වේ**
:::
::: grammar-box
**හේතුක පදය තුළ ආත්මනෙපද (⟪आत्मनेपद⟫) භාවිතා වේ:**

**1. සංවර්ධනය කරන ලද ක්‍රියාවේ පලය සංවර්ධකයාට (හේතුකරුවාට) ලැබෙන විට:**
:::
උදාහරණය:

⟪रामः कटं कारयते⟫ = "රාම තමන් වෙනුවෙන් (තම අයිතිකාරය සඳහා) පොතු මැදුරක් නිර්මාණය කරවයි"

**2. හේතුක පදය සර්වනාමික ලෙස භාවිතා වන විට ("ස්වයං පෙන්වීම" "ස්වයං ඇසෙන්නට කිරීම" ආදිය), හෝ සරල ක්‍රියාපදයේ වස්තුව හේතුක පදයේ කර්තෘ (⟪कर्तृ⟫) වන විට:**

උදාහරණය:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "විෂ්ණු තම භක්තයන්ට ස්වයං පෙන්වයි"

ප්‍රතිඵලය: ⟪भक्ता विष्णुं पश्यन्ति⟫ = "ශ්‍රද්ධාලීන් විෂ්ණු දකිති"


එබැවින් නීති සාමාන්‍යයෙන් උභයපද (⟪उभयपद⟫) ක්‍රියාපද තුළ ආත්මනෙපද (⟪आत्मनेपद⟫) භාවිතය සඳහා වන නීතිවලට අනුකූල වේ.

## 29.3. නැවත සිහිපත් කිරීම සඳහා පරිවර්තන අභ්‍යාසය
