# පාඩම 6

## 6.1. ක්‍රියා පද වාක්‍යය

::: grammar-box
**ප්‍රස්තාරය I: ක්‍රියා පද ආකෘතිය**
උදාහරණයක් ලෙස **yajati** = ⟪यजति⟫ = "ඔහු (ඇය, එය) පූජාවක් මගින් ගරු කරයි", "ඔහු (ඇය, එය) පූජා කරයි"

**ප්‍රස්තාරය II: කාත්‍ර (kartṛ m. = ⟪कर्तृ⟫) – ක්‍රියා පද ආකෘතිය**
උදාහරණයක් ලෙස **rāmo yajati** = ⟪रामो यजति⟫ = "රාමු පූජාවක් මගින් ගරු කරයි", "රාමු පූජා කරයි"
:::
ක්‍රියා පද වාක්‍යයක දී කාත්‍ර (**kartṛ** m. = ⟪कर्तृ⟫) සඳහන් කර ඇත්නම්, එය විශේෂණ පද්ධතියක (passive) නොමැතිනම්, කාත්‍ර **නෝමිනේටිව්** (පළමු විභක්තිය, prathamā = ⟪प्रथमा⟫) හි පවතී. සංඛ්‍යාවේදී (vacana n. = ⟪वचन⟫) කාත්‍ර සහ ක්‍රියා පද ආකෘතිය අනුගමනය කරයි.


## 6.2. ක්‍රියා පද ආකෘති සෑදීම පිළිබඳව

අන්තර්ගත ක්‍රියා පද ආකෘතියක්, එනම් පුද්ගල අන්තය සහිත ක්‍රියා පද ආකෘතියක්, සංස්කෘතයේ පහත දැක්වෙන කරුණු ප්‍රකාශ කරයි:

1. **අර්ථය** (**artha** m. ⟪अर्थ⟫)
2. **පුද්ගලය** සහ **සංඛ්‍යාව** (Zahl, **vacana** n. = ⟪वचन⟫) (මම, ඔබ, ඔහු \ඔහු, ඇය, එය\, අපි දෙදෙනා, ඔබ දෙදෙනා, ඔවුන් දෙදෙනා, අපි, ඔබ, ඔවුන්)
3. හැසිරීමේ රටාව (genus verbi):
1. **පරස්මෛපද** (n. = ⟪परस्मैपद⟫) ("වෙනත් අයෙකුට සම්බන්ධ වචන ආකෘතිය"): ක්‍රියාත්මක. උදාහරණයක් ලෙස **yajati** = ⟪यजति⟫ = "ඔහු පූජාවක් මගින් ගරු කරයි" (එනම්, තවත් අයෙකු වෙනුවෙන් පූජාව සිදු කරන ආරාධකයා)
2. **ආත්මනේපද** (n. = ⟪आत्मनेपद⟫) ("ස්වයංට සම්බන්ධ වචන ආකෘතිය"): මාධ්‍යම. උදාහරණයක් ලෙස **yajate** = ⟪यजते⟫ = "ඔහු තමන්ගේ අරමුණ සඳහා පූජාවක් මගින් ගරු කරයි" (එනම්, තමන් සහ පවුල වෙනුවෙන් පූජා කරන පූජකයා)
3. **විශේෂණ පද්ධතිය** (**karman** n. = ⟪कर्मन्⟫). උදාහරණයක් ලෙස **ijyate** = ⟪इज्यते⟫ = "පූජාවක් මගින් ගරු කරනු ලැබේ"

බොහෝ අවස්ථාවලදී ආත්මනේපදයේ අර්ථ නිෂ්පාදනය හඳුනා ගත නොහැක; කලාත්මක කවියන් ද ආත්මනේපදය පරස්මෛපදය සමඟ අර්ථ වෙනසක් නොමැතිව භාවිතා කරයි. එහෙත් පරිවර්තනයේදී සැමවිටම එවැනි අර්ථ නිෂ්පාදනයක් පවතින්නේ දැයි සලකා බැලිය යුතුය.

ආත්මනෙපදයේ සහ පරස්මෛපදයේ (විශේෂ ආත්මනෙපද අර්ථය තුළ) භාවිතා වන ක්‍රියාපද, **උභයපද**-ක්‍රියාපද (ubhayapada n. = ⟪उभयपद⟫ = "ශබ්ද දෙකම") ලෙස හැඳින්වේ.

සමහර ක්‍රියාපද පරස්මෛපදයේ හෝ ආත්මනෙපදයේ පමණක් භාවිතා වේ. මෙවැනි ක්‍රියාපද සඳහා ආත්මනෙපදය හෝ පරස්මෛපදය විශේෂ අර්ථයක් නොගනී. උදා: **manyate** = ⟪मन्यते⟫ = "ඔහු (ඇය, එය) සිතයි" (විශේෂ ආත්මනෙපද අර්ථයක් නොමැතිව).

4. **කියන ආකාරය** (Modus):
1. **ඉන්ඩිකටිව්**: ප්‍රකාශ ආකාරය
2. **ඔප්ටෙටිව්**: ආශාව සහ හැකියාව ප්‍රකාශ කරන ආකාරය
3. **ඉම්පෙරේටිව්**: ආදේශ ආකාරය
5. **සමය** (Tempus):
1. **ප්‍රේසන්ස්**: වත්මන් සමය
2. **ඉම්පෙර්ෆෙක්ට්**
3. **පෙර්ෆෙක්ට්**
4. **ඔරිස්ට්**
5. **ෆියුචර්**: අනාගත සමය
6. **කොන්ඩිෂනල්**

සමයන් තත්කාලික මූල (Tempusstämme) වලින් නිර්මාණය කරනු ලැබේ: ප්‍රේසන්ස් මූලය, ඔරිස්ට් මූලය, පෙර්ෆෙක්ට් මූලය, ෆියුචර් මූලය.


## 6.3. ඉන්ඩිකටිව් ප්‍රේසන්ස් (laṭ = ⟪लट्⟫)

ප්‍රේසන්ස් යනු වත්මන් සමයයි, විශේෂයෙන් දීර්ඝකාලීන බව ප්‍රකාශ කරයි.

::: grammar-box
**ඉන්ඩිකටිව් (ප්‍රකාශ ආකාරය) ප්‍රේසන්ස් නිර්මාණය කරනු ලබන්නේ ප්‍රේසන්ස් මූලයට "ප්‍රාථමික අවසන්" (Primärendungen) එක් කිරීමෙනි.**
:::
උදාහරණ:

| මූලය (dhātu) | ප්‍රේසන්ස් මූලය | 3. පුද්ගල ඒකවචන ඉන්ඩිකටිව් ප්‍රේසන්ස් පරස්මෛපදය |
| :--- | :--- | :--- |
| **viś** = ⟪विश्⟫ | **viśa** = ⟪विश⟫ | **viśati** = ⟪विशति⟫ = "ඔහු (ඇය, එය) ඇතුළු වේ" |
| **bhū** = ⟪भू⟫ | **bhava** = ⟪भव⟫ | **bhavati** = ⟪भवति⟫ = "ඔහු (ඇය, එය) උපදී" |
| **nṛt** = ⟪नृत्⟫ | **nṛtya** = ⟪नृत्य⟫ | **nṛtyati** = ⟪नृत्यति⟫ = "ඔහු (ඇය, එය) නර්තනය කරයි" |


## 6.4. ප්‍රථම පුරුෂයාගේ මූලික අවසන් (prathama m. = ⟪प्रथम⟫ = "පළමු (!) පුරුෂයා")

::: grammar-box
| | ඒක වචනය (Einzahl):brekavacana n.:br⟪एकवचन⟫ | බහු වචනය (Mehrzahl):brbahuvacana n.:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **පරස්මෛපද n.** :br⟪परस्मैपद⟫ | **-ti** :br-⟪ति⟫ | **-nti** :br-⟪न्ति⟫ |
| **ආත්මනේපද n.** :br⟪आत्मनेपद⟫ | **-te** :br-⟪ते⟫ | **-nte** :br-⟪न्ते⟫ |
:::
උදාහරණය **yaj** = ⟪यज्⟫ = "හෝමයක් මගින් පූජා කිරීම", "හෝම කරනවා":
වර්තමාන පදය: **yaja** = ⟪यज⟫
3. sg. P. **yajati** = ⟪यजति⟫
3. pl. P. **yajanti** = ⟪यजन्ति⟫
3. sg. Ā. **yajate** = ⟪यजते⟫
3. pl. Ā. **yajante** = ⟪यजन्ते⟫


## 6.5. වර්තමාන පදය සෑදීම

### 6.5.1. 6 වන වර්තමාන පන්තියේ ක්‍රියාපද (tudādi = ⟪तुदादि⟫ = "tud ආදිය")

::: grammar-box
**වර්තමාන පදය = මූලික තත්ත්වයේ (එහි ලැයිස්තුගත කර ඇති පරිදි) + a-**

| මූලය (dhātu m.):br⟪धातु⟫ | වර්තමාන පදය |
| :--- | :--- |

:::

## 6.7. වචන මාලාව

::: grammar-box
සංස්කෘත භාෂාවේ ක්‍රියාපද **මුල රූපයෙන්** (Wurzel-Form) දැක්වේ. මුලට පසුව ඇති සංඛ්‍යාව **විකාර වර්ගය** (Konjugationsklasse) දක්වයි. -> [L158] සංස්කෘත භාෂාවේ ක්‍රියාපද **මූල රූපයෙන්** (Wurzel-Form) දැක්වේ. මූලයට පසුව ඇති සංඛ්‍යාව **විකාර වර්ගය** (Konjugationsklasse) දක්වයි.

**P:** මුල භාවිතා වන්නේ පරස්මෛපදය (Parasmaipada) සඳහා පමණි
**Ā:** මුල භාවිතා වන්නේ आत्मनेपදය (Ātmanepada) සඳහා පමණි

:::
