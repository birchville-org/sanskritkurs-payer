# පාඩම 25

## 25.1. අබ්ලේටිවය සෑදීම (⟪पञ्चमी⟫ = "පස්වන විභක්ති පර්යන්තය")

::: grammar-box
a පර්යන්තයෙන් යුත් පුල්ලිංග / නපුंसක ලිංග සහ විශේෂණ පද හැර, සියලු ව්‍යවහාර ශ්‍රේණිවල ඒක වචනය තුළ අබ්ලේටිවය (⟪पञ्चमी⟫) සහ ජෙනෙටිවය (⟪षष्ठी⟫) හැඩතල එකිනෙකට සමාන වේ.

පුද්ගල විශේෂණ හැර, සියලු ව්‍යවහාර ශ්‍රේණිවල බහු වචනය තුළ අබ්ලේටිවය හැඩතල ඩේටිව (⟪चतुर्थी⟫) හැඩතල සමඟ එකිනෙකට සමාන වේ.
:::
දැන් ඔබට සංස්කෘතයේ විභක්ති (⟪विभक्ति⟫) අනුපිළිවෙලට හේතුව තේරෙනු ඇත: එය සකස් කර ඇත්තේ, සමාන හැඩතල උපරිම ලෙස එකට - හෝ එකිනෙක යටතේ - පවතින පරිදිය.

::: grammar-box
**පුල්ලිංග / නපුंसක ලිංග -a පර්යන්තයේ අබ්ලේටිව ඒක වචනය**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
ප්‍රශ්න, සම්බන්ධීකාරක සහ දැක්වීමේ විශේෂණ:

::: grammar-box

| | අබ්ලේටිව ඒක වචනය: පුල්ලිංග / නපුंसක ලිංග | අබ්ලේටිව ඒක වචනය: ස්ත්‍රී ලිංග |
| :--- | :--- | :--- |

| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

## 25.2. අබ්ලේටිවය භාවිතා කිරීම (⟪पञ्चमी⟫)

"අබ්ලේටිවය යනු, දෙයක් එයින් ඉවත් වූ විට ස්ථාවරව පවතින දෙයයි."

පාණිනි 2,3,28 + 1,4,24

අබ්ලේටිවය ප්‍රධාන වශයෙන් "කොහේ සිට?", "ඇයි?" යන ප්‍රශ්න වලට පිළිතුරු ලෙස භාවිතා වේ.

::: grammar-box
1\. එබැවින් අබ්ලේටිවය ආරම්භක ලක්ෂ්‍යය, පැමිණීමේ ස්ථානය සහ ද්‍රව්‍යය හැඳින්වේ.

එබැවින් අපවාදකය මිලට ගන්නා, ඇසෙන, ඉල්වන පුද්ගලයා ද සඳහන් කළ හැක.
:::
උදාහරණ:

::: indent
⟪ग्रमादागच्छति⟫ = "ඔහු ගමෙන් පැමිණෙයි"

⟪अश्वात्पतितः⟫ = "අශ්වයාගෙන් වැටුණ"

⟪तेभ्यो लब्धम्⟫ = "ඔවුන්ගෙන් (හැර) ලබා ගත්"
:::
උදාහරණ:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "ඔහු ගුරුවරයාගෙන් ධර්මය පිළිබඳව ඇසේ"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "බ්‍රාහ්මණයා ක්ෂත්‍රියයාගෙන් දුද ගවයකි ඉල්වා සිටී"
:::
::: grammar-box
2\. අපවාදකය "වැළකීම", "ආරක්ෂා කිරීම", "ප්‍රතිරෝධය", "භීතිය" යන අර්ථ දැක්වෙන ක්‍රියාපද සමඟ පවතී:
:::
උදාහරණ:

::: indent
⟪अरिभ्यो रक्षति⟫ = "ඔහු සතුරන්ගෙන් ආරක්ෂා කරයි"
:::
::: grammar-box
3\. අපවාදකය හේතුව හෝ කාරණාව දැක්වේ:
:::
උදාහරණ:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "ඔහු කෝපයෙන් තම පුත්‍රයා මරයි"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "ඔහු අකුසල කළ බැවින්, නරකයට පත් වේ" (« අකුසල කළ තැනැත්තෙක් නිසා)

⟪पापकरणान्नरकं गच्छति⟫ = "ඔහු අකුසල කරන බැවින් / කළ බැවින්, නරකයට පත් වේ"
:::
පුංචි නොවන නාම, ක්‍රියාවක හේතුව දැක්වීම සඳහා, උපකරණ විභක්තිය (⟪तृतीया⟫) හෝ අපවාදකය (⟪पञ्चमी⟫) හි පැවතිය හැක. මෙම අර්ථයෙන් ස්ත්‍රී ලිංගික නාම සාමාන්‍යයෙන් උපකරණ විභක්තියේ පවතින අතර, සමහර විට අපවාදකයේ ද පැවතිය හැක.

## 25.3. ප්‍රත්‍යය -⟪तस्⟫

::: grammar-box
ඒක වචනයේදී (නිශ්චිතව) ශබ්දය අපවාදකීය අර්ථයෙන් භාවිතා වන බව පැහැදිලි කිරීමට, ශබ්ද මූලයට -⟪तस्⟫ ප්‍රත්‍යය එකතු කළ හැක. මෙය බොහෝ විට අපවාදකීය අර්ථයක් සහිත කාලවිශේෂණ ගොඩනඟයි ("කෙතැනින්?" යන ප්‍රශ්නයට):
:::
උදාහරණ:

::: indent
⟪आदितस्⟫ = "ආදිය සිටම"

⟪धर्मतस्⟫ = "ධර්මය නිසා, ධර්මය මත පදනම්ව"
:::
::: grammar-box
⟪तस्⟫ ප්‍රත්‍යය සර්වනාම මූල වලට ද යෙදේ:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "එතැනින්, එහි, ඒ දෙසට, ඉන්පසු, එබැවින්"

⟪यद्⟫ : ⟪यतस्⟫ "යම් කිසියම් දෙයකින්, එයින්, මොහුගෙන්, මෙතැනින්, ඒ දෙසට, එය නිසා" (සම්බන්ධක)

⟪किम्⟫ :  ⟪कुतस्⟫ "මොහුගෙන්?" "ඇයි?"
:::
## 25.4. හේතු දැක්වීමට වෙනත් ක්‍රම

::: grammar-box
**1\. සම්බන්ධක වාක්‍ය**

සම්බන්ධක වාක්‍ය බොහෝ විට ප්‍රධාන වාක්‍යය සමඟ හේතු (හේතුව දැක්වීම), අනුප්‍රාප්තික (අඛණ්ඩව සිදුවන) හෝ අරමුණු (ඉලක්ක කරගත්) සම්බන්ධතාවයක් ප්‍රකාශ කරයි.

හේතු සම්බන්ධකයක් ලෙස ක්‍රියා කරන විශේෂණ පදයේ ආකාර:

*   අබ්ලේටිව් (ඉවත් වීම):
*   ⟪यतस्⟫ ... උප වාක්‍යය ... ⟪ततस्⟫ ... ප්‍රධාන වාක්‍යය ... = "මන්ද ..., එබැවින් ..."
*   ⟪यस्मात्⟫ ... උප වාක්‍යය ... ⟪तस्मात्⟫ ... ප්‍රධාන වාක්‍යය ... = "මන්ද ..., එබැවින් ..."
*   ඉන්ස්ට්‍රුමෙන්ටල් (උපකාරය):
*   ⟪येन⟫ ... උප වාක්‍යය ... ⟪तेन⟫ ... ප්‍රධාන වාක්‍යය ... = "එමගින්/මන්ද ..., එමඟින් / එබැවින් ..."
:::
උදාහරණය:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "රාමු සම්පත් කැමති නිසා, ඔහු ව්‍රතය පවත්වාගෙන යයි"
:::
