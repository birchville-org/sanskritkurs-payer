# පාඩම 55

## 55.1. a-ආරිස්ට් (තේමා ස්වරය සහිත ආරිස්ට්)

::: grammar-box
**a-ආරිස්ට් යනු අපෙරෆෙක්ට් (⟪लङ्⟫) මෙන්ම සෑදේ (6 වන ප්‍රෙසන්ස් ශ්‍රේණියේ (⟪तुदादि⟫)), එනම්:**

**ඔග්මෙන්ට් + ගැඹුරු මට්ටමේ වෘක්ෂය + a + ද්විතීයික අන්ත**

**අපෙරෆෙක්ට් මෙන්ම එකම අවස්ථාවලදී -a- යන්න -ā- වෙත ප්‍රතිස්ථාපනය කෙරේ.**

**නසල් ඉන්ෆික්ස් නොමැත.**

**ආත්මනෙපද දුර්ලභය; උබයපාද වෘක්ෂ සඳහා එය බොහෝ විට අනෙකුත් ආරිස්ට් ශ්‍රේණීන් මගින් සෑදේ (Kielhorn, ග්‍රැමටික් §340 සහ පහත අදාළ ආරිස්ට් ශ්‍රේණීන් බලන්න).**

**මෙම ආරිස්ට් සහිත වෘක්ෂ ලැයිස්තුව, Kielhorn, ග්‍රැමටික් §340 හි.**
:::
