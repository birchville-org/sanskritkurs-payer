# පාඩම 3

## 3.1. ස්ත්‍රී ලිංගයේ ඒක වචන නාම පදවි

### 3.1.1. -s මත අවසන් වන ඒක වචන නාම පදවි

තවද, ස්වරයකින් අවසන් වන පහත නාම මූල ද්‍රව්‍යද **-s** මත ඒක වචන නාම පදවි සෑදේ:

::: grammar-box
**-i** මත අවසන් වන ස්ත්‍රී ලිංගය: උදා. **śruti** f. "සවන් දීම" -- ඒක වචන නාම පදවි: **śrutis** = ⟪श्रुतिस्⟫
**-u** මත අවසන් වන ස්ත්‍රී ලිංගය: උදා. **dhenu** f. "කිරි ගවය" -- ඒක වචන නාම පදවි: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. ප්‍රත්‍යයකින් තොරව සෑදෙන ඒක වචන නාම පදවි

ප්‍රත්‍යයකින් තොරව ඒක වචන නාම පදවි සෑදේ:

::: grammar-box
**-ā** මත අවසන් වන ස්ත්‍රී ලිංගය: උදා. **devatā** f. "දෙවියන්" -- ඒක වචන නාම පදවි: **devatā** = ⟪देवता⟫
**-ī** මත අවසන් වන ස්ත්‍රී ලිංගය: උදා. **devī** f. "දේවිය" -- ඒක වචන නාම පදවි: **devī** = ⟪देवी⟫
:::
::: important
**සැලකිල්ලට ගන්න!** මීට අමතරව, **-ī** මත අවසන් වන එක සිලබු ස්ත්‍රී ලිංග මූල නාම ද්‍රව්‍ය තිබේ. ඒවායේ ඒක වචන නාම පදවි **-s** මත අවසන් වේ: උදා. dhī f. "චින්තාව" -- ඒක වචන නාම පදවි: dhīs = ⟪धीस्⟫. lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "බෝට්ටුව" සහ tantrī (⟪तन्त्री⟫) f. "තන්ත්‍රය" ද අසාමාන්‍ය ලෙස **-s** මත ඒක වචන නාම පදවි සෑදේ: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. පුංස ලිංගයට අනුරූප ස්ත්‍රී ලිංග සෑදීම

::: grammar-box
**-a** මත අවසන් වන පුංස ලිංගය:
**-ā** මත අවසන් වන ස්ත්‍රී ලිංගය: උදා. **kṣatriya** m. » **kṣatriyā** f. "ක්ෂත්‍රිය කාන්තාව" = ⟪क्षत्रिया⟫
**-ī** මත අවසන් වන ස්ත්‍රී ලිංගය: උදා. **brāhmaṇa** m. » **brāhmaṇī** f. "බ්‍රාහ්මණ කාන්තාව" = ⟪ब्राह्मणी⟫

**-u** මත අවසන් වන පුංස ලිංගය:
**-ī** මත අවසන් වන ස්ත්‍රී ලිංගය: උදා. **sādhu** m. » **sādhvī** f. (හොඳ, පුණ්‍යවතී) = ⟪साध्वी⟫
(**-u-** ස්වරයකට පෙර **-v-** බවට පත් වේ, එබැවින් **-u- + -ī** » **-vī**)
:::

## 3.3. පුංස සහ ස්ත්‍රී ලිංග බහුවචන නාම පදවි

::: grammar-box
පුංස සහ ස්ත්‍රී ලිංග බහුවචන නාම පදවියේ ප්‍රත්‍යය **-as** වේ.
**-a** මත අවසන් වන පුංස ලිංගය: **deva- + -as** » **devās** = ⟪देवास्⟫
**-ā** මත අවසන් වන ස්ත්‍රී ලිංගය: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**-i** මත අවසන් වන පුංස ලිංගය: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**-i** මත අවසන් වන ස්ත්‍රී ලිංගය: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**-ī** මත අවසන් වන ස්ත්‍රී ලිංගය: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**-u** මත අවසන් වන පුංස ලිංගය: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**-u** මත අවසන් වන ස්ත්‍රී ලිංගය: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
සටහන: **e** යනු **i** හි උසස් මට්ටම (**guṇa**) වන අතර, **o** යනු **u** හි උසස් මට්ටමයි.


## 3.4. ස්වර සන්ධි

::: grammar-box
**සරල ස්වර, එකිනෙකින් වෙනස් නොවේ හෝ දිග පමණක් වෙනස් වන ස්වර, අදාළ දිගු ස්වරයට "එකතු වේ":**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)
:::
උදාහරණයක් ලෙස

devatā + annapūrṇā » devatānnapūrṇā "Annapūrṇā යනු දෙවියකි" = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā යනු ආහාර සහ පිසීමේ දෙවඟන වන අතර, ඇය ශිවයාගේ සහකාරිය වන පාර්වතීගේ අත්පොතක් ලෙස සැලකේ.)

devī + indrāṇī » devīndrāṇī "Indrāṇī යනු දෙවඟනකි" = ⟪देवीन्द्राणी⟫

> (Indrāṇī යනු දෙවිඳුරුගේ සහකාරියයි.)

::: grammar-box
**-ās සියලුම ඝෝෂ ව්‍යජන හඬවල් මත -ā ලෙස පරිණාමය වේ.**
:::
උදාහරණයක් ලෙස,

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Vaiśyas යනු දෙවරක් උපන් පිරිසයි" = ⟪द्विजा वैश्याः⟫


## 3.6. වචන මාලාව

**පහත සඳහන් වචන ඉගෙන ගන්න:**

**śruti** f. = ⟪श्रुति⟫ : ඇසීම, සදාකාලික උරුමය (වේද සහ බ්‍රාහ්මණ පිළිබඳ නිරූපණය).

**smṛti** f. = ⟪स्मृति⟫ : සිහිපත් කිරීම, මතකය, භාවනාමය සිහිපත් කිරීම = සැලකිල්ල, උරුමය (**śruti** හට ප්‍රතිවිරුද්ධ අර්ථය). ඇතුළත් වන්නේ:
සතර **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): නිවැරදි උච්චාරණය
2. **chandas** n. (⟪छन्दस्⟫): මෙත්‍රය
3. **vyākaraṇa** n. (⟪व्याकरण⟫): ව්‍යාකරණය
4. **nirukta** n. (⟪निरुक्त⟫) : වචන පැහැදිලි කිරීම, භාෂාවේ මුල් අර්ථය
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : ඛණ්ඩායනය, දිනපොත පිළිබඳ විද්‍යාව
6. **kalpa** m. (⟪कल्प⟫) : උත්සව විධි
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : විශාල බलि පූජාවන්හි ක්‍රියාත්මක කිරීම සඳහා උපදෙස් පොත්

## 3.7. පුහුණුව

**A) පහත වාක්‍ය ඒකවචනයෙන් බහුවචනයට පරිවර්තනය කරන්න:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**B) සාමාන්‍ය ප්‍රතිපත්තියක් ලෙස නම් වාක්‍ය සකස් කරන්න:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) ඒවා ස්ත්‍රී ලිංගයට පරිවර්තනය කරන්න:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**D) සංස්කෘතයට පරිවර්තනය කරන්න:**

1. Umā is a goddess.
2. The Veda is śruti.
3. The female teachers are goddesses.
4. Milk cows are domesticated animals.
5. Poets are teachers.
6. Kṣatriyas are twice-born.
7. The holy men are Śūdras.
