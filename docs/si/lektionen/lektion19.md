# පාඩම 19

## 19.1. සම්බන්ධ වාක්‍යය

::: grammar-box

**ප්‍රස්තාරය:**


**සම්බන්ධ පදය -- සම්බන්ධ වාක්‍යය, එහි නාම පදය සම්බන්ධ වාක්‍යය යොමු වන -- (සංදර්ශක පදය) -- මූලික වාක්‍යය**

**සම්බන්ධ වාක්‍යය මූලික වාක්‍යයට පසුව ද තබා ගත හැකිය, නමුත් එය මූලික වාක්‍යය තුළ ඇතුළත් කළ නොහැකිය.**

**සම්බන්ධ පදය සහ සම්බන්ධ වාක්‍යය තුළ පිහිටන සම්බන්ධක වචනය, ජර්මානු භාෂාවට ප්‍රතිවිරුද්ධව, සම්බන්ධ වාක්‍යය විසින් අනුකූලව ඉල්ලා සිටි කාරකයේ පවතී. සංදර්ශක පදය මූලික වාක්‍යය විසින් අනුකූලව ඉල්ලා සිටි කාරකයේ පවතී.**
:::

උදාහරණ:

සටහන: පොදු අන්තර්ගතයක් ඇති සම්බන්ධ වාක්‍යවලදී, ඉඟිකිරීමේ ප්‍රයෝගය දැක්වීමේ ප්‍රයෝගයට වඩා බහුලව භාවිතා කෙරේ. එබැවින් අපගේ බොහෝ උදාහරණ ඉඟිකිරීමේ ප්‍රයෝගයෙන් යුක්ත විය හැක.

**1. ක්‍රියාකාරී (⟪कर्तृ⟫) වාක්‍යය සම්බන්ධ වාක්‍යයකින් තවදුරටත් නිර්ණය කර ඇත:**

::: indent
⟪यो नरः पुण्यं करोति स स्वर्गं गच्छति⟫ =  ⟪यो नरः पुण्यं करोति तेन स्वर्गं गम्यते⟫ = ⟪येन नरेण पुण्यम् क्रियते तेन स्वर्गं गम्यते⟫ ආදී = "කුසල ක්‍රියා කරන පුරුෂයෙක් ස්වර්ගයට යයි."
:::
**2. මූලික වාක්‍යයේ ප්‍රතිපත්තිය (⟪कर्म⟫) සම්බන්ධ වාක්‍යයකින් තවදුරටත් නිර්ණය කර ඇත:**

::: indent
⟪यो ब्राह्मणो देवान्यजते तं देवा रक्षन्ति⟫ = "දේවතාවෝ තමන්ට පූජාකරු ලෙස පූජා කරන බ්‍රහ්මණයකු ආරක්ෂා කරති."
:::
**3. මූලික වාක්‍යයේ නාම පදයක තවදුරටත් නිර්ණය කිරීම සම්බන්ධ වාක්‍යයේ පවතී:**

::: indent
⟪ये नराः पापं कुर्वन्ति तेषां पुत्रा धनं न लभन्ते⟫ = "අකුසල ක්‍රියා කරන පුරුෂයන්ගේ දරුවන්ට සම්පත් නොලැබේ."
:::
**4. සාපේක්ෂ ප්‍රතිඥය සහ සම්බන්ධක වචන ජෙනෙටිව් (⟪षष्ठी⟫) තත්ත්වයේ පවතී:**

::: indent
⟪यस्य नरस्य पुत्राः पापं कुर्वन्ति स न सुखवान्⟫ = "තම පුත්‍රයින් අපකාර කරන පුද්ගලයා සතුටු නොවේ."
:::
**5. සාපේක්ෂ ප්‍රතිඥය සහ සම්බන්ධක වචන ඉන්ස්ට්‍රුමෙන්ටලිස් (⟪तृतीया⟫) තත්ත්වයේ පවතී:**

::: indent
⟪येन शत्रुणा ग्रामो जितस्तं द्विषन्ति⟫ = "තම ගම්මානය පරාජය කර ඇති හෝ අල්ලාගත් ශත්‍රුවන් ඔවුහු සතුරු කරති."
:::
**6. සාපේක්ෂ ප්‍රතිඥය සහ සම්බන්ධක වචන ඇක්කුසටිව් (⟪द्वितीया⟫) තත්ත්වයේ පවතී:**

::: indent
⟪यं नरं देवी रक्षति स सुखमाप्नोति⟫ = "දේවිය ආරක්ෂා කරන පුද්ගලයෙකු සම්පත්තිය ලබයි."
:::
## 19.2. සාපේක්ෂ ප්‍රතිඥය = ⟪व्यपेक्षकसर्वनाम⟫ නපුංසක ලිංගය.

::: grammar-box

**⟪यद्⟫ "කවර, කවරක්, කවරය" ⟪तद्⟫ මෙන් ව්‍යාකරණ විපර්යාසයට ලක්වේ, නමුත් සාමාන්‍ය සඳ්ධි (Sandhi) රීති අනුගමනය කරයි.**

## 19.3. Woordenlijst

**⟪अर्थ⟫ m.:** doel, streven, betekenis (van een woord), rijkdom, bezit, vermogen. ⟪अर्थम्⟫ (acc.), ⟪अर्थेन⟫ (instr.) met gen. of als achterste lid van een Tatpuruṣa: om ... wil, om te.

⟪अर्थ⟫ is een van de drie levensdoelen (⟪पुरुषार्थ⟫), zoals beschreven in de wereldlijke en religieuze literatuur:

**⟪अर्थ⟫ m.:** doelmatig gedrag, verwerving van welvaart

**⟪काम⟫ m.:** zinnenlust, vooral ook op seksueel gebied

## 19.4. අභ්‍යාස

**සංස්කෘත භාෂාවට පරිවර්තනය කරන්න:**

1. තම පුත්‍රයා මිය ගිය වෛශ්‍ය කාන්තාව හඬයි.

2. රාමු තමන් ආරක්ෂා කරන දෙවියන්ට පූජාවක් සිදු කරයි.

3. කවියා තමන් ආශාවෙන් සිටි ක්ෂත්‍රියයාගේ ගුණ පසඟපතයි.

4. අග්නිය Agni වෙත පූජාවක් සිදු නොකරන පුරුෂයාගේ ගෙයි සලයි.

5. වෘෂභයා මෙන් සිටි පුරුෂයා රාමු විසින් පරාජය කරන ලද ක්ෂත්‍රිය සටන්කාමීන් මරයි.

## 19.5. ⟪सुभाषितानि⟫

**පරිවර්තනය කරන්න:**

::: indent
⟪येन येन च वातेन वारिदो वारि मुञ्चति । तेन तेन च वातेन छत्रं वहति पण्डितः ॥१॥⟫
:::
පැහැදිලි කිරීම: ⟪वारि⟫ නාම, අක්ක. ඒක වචනය ⟪वारि⟫ නපු.: ජලය

::: indent
⟪यो धर्ममर्थं कामं च यथाकालं निषेवते । धर्मार्थकामसंयोगं सो ऽमुत्रेह च विन्दति ॥२॥⟫
:::
පැහැදිලි කිරීම: ⟪यथाकालम्⟫ අවයීභාව කොම්පසිට්: නිවැරදි වේලාවට ; සෑම විටම එය සඳහා නිවැරදි වේලාව පවතින විට.

::: indent
⟪सा भार्या या प्रियं ब्रूते स पुत्रो यस्तु जीवति । स जीवति गुणो यस्य धर्मो यस्य स जीवति ॥३॥ यस्यार्थास्तस्य मित्राणि यस्यार्थास्तस्य बान्धवाः । यस्यार्थाः स पुमांल्लोके यस्यार्थाः स हि पण्डितः ॥४॥⟫
:::
