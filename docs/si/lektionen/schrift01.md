# Devanāgarī = ⟪देवनागरी⟫

## ලිපි පුහුණුව 1

සංස්කෘතය විවිධ ලිපි වලින් ලියනු ලැබූ අතර, තවමත් ලියනු ලැබේ. පහත සාරාංශය මගින් මෙම ලිපි වලින් කුඩා කොටසක් පෙන්වා දේ:

![](/images/schrift001.webp)  
ඡායාරූපය: සංස්කෘත ලිපි නියැදි
\[ඡායාරූප මූලාශ්‍රය: විකිපීඩියා, GNU FD ලයිසන්සය\]

වැදගත්ම නවීන උතුරු ඉන්දියානු සංස්කෘත ලිපිය Devanāgarī වේ:

![](/images/schrift002.webp)

සෑම විරාම අකුරක්ම එම විරාමයට පසුව එන "a" ස්වරය සමඟ සංකේතවත් කරයි. ශුද්ධ විරාමය පමණක් (පසුව එන ස්වරයකින් තොරව) ලිවීමට නම්, එය යටින් තබන ලද තිරස් රේඛාවකින් -- virāma = ⟪विराम⟫ -- සලකුණු කළ යුතුය:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

විරාමයකට පසුව එන ස්වර -- "a" හැර -- මෙසේ ලියනු ලැබේ:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

විරාම + ස්වර සම්බන්ධතා ලිවීමේදී අනුපිළිවෙල වන්නේ:

![](/images/schrift003.jpg)

ලිවීමේදී, ඊළඟ අකුර ලිවීමට පෙර සෑම අකුරක්ම ඉහළ රේඛාව සහිතව සම්පූර්ණ කරනු ලැබේ.

## පුහුණුව

දේවනාගරී අක්ෂරයෙන් ලියන්න:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

කියවන්න සහ ට්‍රාන්ස්ලිටරේට් කරන්න:

⟪तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ⟫

අමතර කියවීමේ පුහුණුව:

⟪पिता⟫ පියා, ⟪कपि⟫ වැලිපොළ, ⟪कृत⟫ කළේය,  ⟪टीका⟫ උපසංස්කෘතය, ⟪तत्⟫ මෙම, ⟪तट⟫ තීරය, ⟪पत्⟫ විදින්නේ, ⟪पट⟫ රෙදිපිළි, ⟪काच⟫ වීදුරුව,  ⟪काकुत्⟫ මුඛය, ⟪चित्⟫ හැඟීමට ලක්වේ, ⟪पृच्⟫ මිශ්‍ර කරන්නේ,  ⟪पोटक⟫ සේවකයා, ⟪चेतु⟫ අරමුණ, ⟪तौतातित⟫ කුමාරිලයාගේ (Mīmāṃsā) අනුගාමිකයා, ⟪तूत⟫ සෙරුන් ගස, ⟪पीत⟫ පානය කළේය,  ⟪पीति⟫ පානය, ⟪कॢप्⟫  ගැලපේ, ⟪कृपते⟫ ඔහු කම්පනය වේ, ⟪पुटी⟫ රැලි, ⟪चापि⟫ එසේම, ⟪तोक⟫ පරම්පරාව, ⟪तृपत्⟫ සෑහීමට පත්වේ, ⟪पॄ⟫ පිරියි, ⟪कृकाटी⟫ ගෙල සන්ධිය, ⟪पूपौ⟫ කේක් දෙකක්, ⟪पैतृकी⟫ පූර්වජ (ස්ත්‍රී ලිංගය), ⟪कौट⟫ වංචාකාරී, ⟪कच⟫ හිස කෙස්, ⟪कुतपे⟫ බැටළු කෙස් ඇති ආවරණය මත, ⟪कुचौ⟫ පපුව, ⟪चकिता⟫ භීතියට පත්වූ (ස්ත්‍රී ලිංගය)
