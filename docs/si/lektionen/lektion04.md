# පාඩම 4

## 4.1. සරල අතිරේක ප්‍රශ්න (පද ප්‍රශ්න) සහ පිළිතුරු

### 4.1.1. ප්‍රශ්න සර්වනාම සහ දර්ශක සර්වනාම

#### 4.1.1.1. ප්‍රශ්න සර්වනාම (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box

| | උත්තම පුළුල් (Nominative singular) | උත්තම බහුවචන (Nominative plural) |
| :--- | :--- | :--- |
| **ප්‍රකෘති** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |

| **ස්ත්‍රීලිංගය** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |

:::

#### 4.1.1.2. දර්ශක සර්වනාම (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

| **ප්‍රකෘති** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |

| **ස්ත්‍රීලිංගය** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |

| **ස්ත්‍රීලිංගය** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |

**උත්තම පුළුල් පුල්ලිංගය සඳහා:**
**sa, eṣa** (⟪स एष⟫) කෙටි **-a** හැර සියලු ශබ්ද වලට පෙර තිබේ
**so, eṣo** (⟪सो एषो⟫) Avagraha මගින් ඉවත් කරන ලද **-a** වලට පෙර තිබේ
**saḥ, eṣaḥ** (⟪सः एषः⟫) විරාමයේදී (වාක්‍ය අග, පද්‍ය අග) පමණක් තිබේ

[45] මෙම සර්වනාම (sarvanāman n.) භාවිතයෙන් වාක්‍ය ගොඩනැගීමට පහත සඳහන් සන්ධි නීති දැන සිටීම අවශ්‍ය වේ:

### 4.1.2. අවසාන -m හි සන්ධි

::: grammar-box

[50] **පදාන්ත -m ස්වරයකට පෙර හැර අනෙක් ස්ථානවලදී අනුස්වාරය (-ṃ) මගින් ප්‍රතිස්ථාපනය වේ. වාක්‍ය අග හෝ පද්‍ය අගදී සහ ස්වරයකට පෙර -m එලෙසම පවතී.**

:::

### 4.1.3. අවසාන -e හි සන්ධි

::: grammar-box

[55] 1. **a- ස්වරයට පෙර -e වෙනස් නොවේ: ආරම්භක a- Avagraha මගින් ඉවත් වේ:**
z.B. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Diese Feuer"

[58] 2. **කෙටි a- හැර අනෙක් ස්වරයකට පෙර -e සාමාන්‍යයෙන් Hiatus සහිත -a මගින් ප්‍රතිස්ථාපනය වේ. එය -ay මගින් ප්‍රතිස්ථාපනය වීම ද සිදුවේ:**
z.B. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (selten: imay īśvarāh = ⟪इमयीश्वराः⟫) "Diese HERREN"

:::

### 4.1.4. අවසාන -d හි සන්ධි

::: grammar-box

[64] **පදාන්ත -d විස්පෝෂිත ගුත්‍ය (k, kh) සහ උදාත්‍ය (p, ph) ස්වරයන්ට පෙර සහ විරාමයේදී -t මගින් ප්‍රතිස්ථාපනය වේ.**

[66] අනෙක් ස්වරයන්ට පෙර සිදුවන ප්‍රතිස්ථාපනය පසුව සාකච්ඡා කෙරේ. මේ දක්වා එවැනි ස්වර සංයෝග වලින් වළකින්න!

:::

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ පිළිතුර: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (මෙහිදී නාම ප්‍රකාර වාක්‍යයේ විෂයය උදාහරණයක් ලෙස ප්‍රශ්නයට සම්බන්ධ වීම අවධාරණය කිරීම සඳහා ආරම්භයට තබා ගත හැක.)

## 4.2. අභ්‍යාසය

**A) viṣṇuḥ kaḥ (⟪विष्णुः कः⟫) රටාව අනුව පහත වචන සමඟ මුඛයෙන් ප්‍රශ්න ගොඩනගා සංස්කෘතයෙන් පිළිතුරු ලබා දෙන්න:**

śruti, śiva, brāhmaṇa, dvija (බහුවචන), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**B) පහත කියවීමේ අභ්‍යාසය සඳහා etat kim (⟪एतत्किम्⟫) රටාව අනුව ප්‍රශ්න ගොඩනගා, ලබා දී ඇති වචන සහ ප්‍රදර්ශක විශේෂණ භාවිතයෙන් පිළිතුරු ලබා දෙන්න. උදාහරණයක්: eṣa bālaḥ (⟪एष बालः⟫):**
