## 41.2. තවත් ⟪कृत्⟫ -a ප්‍රතිපාදන

### 41.2.1. වර්තමාන කාලීන පද (⟪लडादेशः⟫) Ā, සක්‍රිය පද (⟪लडादेशः⟫) සක්‍රිය පද, අනාගත කාලීන පද (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. තේමාත්මක වර්තමාන මූල, සක්‍රිය පද සහ අනාගත කාලීන පද

::: grammar-box
**ගොඩනැගීම:**

වර්තමාන මූල / සක්‍රිය මූල / අනාගත මූල + -māna (ස්ත්‍රී. mānā)
:::
උදාහරණ:

⟪यज्⟫ 1U, වර්තමාන කාලීන පද Ā ⟪यजमान⟫ 3 "තමන්ගේ අරමුණ සඳහා පූජාවක් මගින් ගෞරවයට පත් කරන අයෙකු = පූජාපති"

⟪मन्⟫ 4Ā, වර්තමාන කාලීන පද Ā ⟪मन्यमान⟫ 3 "සිතන අයෙකු"

⟪कृ⟫ 8U, වර්තමාන කාලීන පද සක්‍රිය ⟪क्रियमाण⟫ 3 "කෙරෙන දෙයක්"

⟪दा⟫ 3U, අනාගත කාලීන පද Ā ⟪दास्यमान⟫ 3 "තමන්ගේ අරමුණ සඳහා දෙනු ඇති අයෙකු"

#### 41.2.1.2. අතේමාත්මක වර්තමාන කණ්ඩායම්

### 41.2.2. "Participle" of passive necessity (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**To express passive necessity ("what must/should be done"), one can optionally form adjectives from roots and derived verbal stems using the following suffixes:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (instead of **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. The suffix -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**The suffix -⟪तव्य⟫ / -⟪तव्या⟫ is attached to roots and derived verbal stems (e.g., causative) in the same way as the infinitive suffix -⟪तुम्⟫ (see [Lesson 23](lektion23.md)), i.e.**

* **guṇa-grade root + ⟪तव्य⟫**

or

* **guṇa-grade root + -i- + ⟪तव्य⟫**

**In the causative:**

* **Causative stem on -ay + -i- + ⟪तव्य⟫**
:::
Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "someone who must be defeated; one to be defeated" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "that where one should be located" |
| ⟪बुध्⟫ Caus. | ⟪बोधयितव्य⟫ | "someone who should be awakened; one to be awakened" |

:::
#### 41.2.2.2. The suffix -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Formation:**

Guṇa-grade root + -⟪अनीय⟫ / -⟪अनीया⟫

**Causative and 10th present class:**

Root, as it appears in the causative stem, without -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "to be given; what must be given" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "one to be defeated" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "to be done" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "what must be seen; worth seeing" |
| ⟪बुध्⟫ Caus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "one to be awakened" |
| ⟪दा⟫ Caus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "what must be caused to give" |

:::
#### 41.2.2.3. ප්‍රත්‍යය -⟪य⟫ / -⟪या⟫

::: grammar-box
**නිර්මාණය:**

මූලය (ආධම්, උත්තම හෝ දීර්ඝ පඩියේ) + -⟪य⟫

නිශ්චිත නීති සඳහා Kielhorn, Grammatik der Sanskrit-Sprache, පිටු 195 - 197 බලන්න!
:::

::: grammar-box
