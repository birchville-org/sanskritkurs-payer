## 18.2. නිර්ණායක සමාස (⟪तत्पुरुष⟫) පූර්වපදය වාක්‍ය භාවයෙන් යුත්

වාක්‍ය භාව පූර්වපදයක් (නිඝණ්ඩුගත නොකළ හැකි) ලෙස

*   ක්‍රියාවාචක
*   විබක්ත පද
*   අවයව
*   වෙනත් නිඝණ්ඩුගත නොකළ හැකි පද

::: indent
භාවිතා කළ හැක. මෙවැනි තත්පුරුෂ සමාස බොහෝ විට නිත්‍යසමාස = ⟪नित्यसमास⟫ (m. "ස්ථිර සමාස") කණ්ඩායමට අයත් වේ, එනම් සමාස තුළ ඇති පද මගින් පමණක් නොව, සමාසය තුළ ඇති වෙනත් පද මගින් ද විඝටනය කළ නොහැකි සමාස වේ.
:::
උදාහරණ:

⟪अति⟫ "එයට අමතරව":

::: indent
⟪अतिगुरु⟫ 3: ඉතා බර, ඉතා ගුරුත්වයෙන් යුක්ත

⟪अतिपुरुष⟫ m.: අතිශයින් උසස් පුරුෂයා, සුපිරි මනුෂ්‍යයා, වීරයා

⟪अतिस्तुति⟫ f.: අතිශයින් ප්‍රසංශාව

⟪अत्युक्ति⟫ f.: අතිශයින් කතා කිරීම, උත්කර්ෂණය
:::
වැදගත්ම වාක්‍ය භාව පූර්වපද a-/an-, su-, dus- වේ.

⟪अ⟫ (ව්‍යංජනයකට පෙර), ⟪अन्⟫ (ස්වරයකට පෙර): un-: සමාස තුළ ⟪न⟫ "නො" වෙනුවට පවතී.

උදාහරණ:

::: indent
⟪अनृत⟫ n. = ⟪नर्तम्⟫ (= ⟪न⟫ + ⟪ऋतम्⟫): අසත්‍යතාව, සිතිවිලිය

⟪अकृत⟫ 3 = ⟪न कृत⟫ 3: නොකළ, අක්‍රිය

⟪अब्राह्मणी⟫ f. = ⟪न ब्राह्मणी⟫ : බ්‍රාහ්මණියක නොවන කෙල්ල, අබ්‍රාහ්මණිය

⟪अदेव⟫ m. = ⟪न देवः⟫ : දෙවියකු නොවන පුරුෂයා, අදේවතාව
:::
⟪सु⟫ "හොඳින්, හොඳ"; සමාසය විඝටනය කිරීමේදී ටිකාවන් මගින් "හොඳ" යන අර්ථය දෙන විශේෂණයක් (උදා. ⟪सुष्टु⟫ 3, ⟪शोभन⟫ 3) මගින් ආදේශ කරනු ලැබේ.

උදාහරණ:

::: indent
⟪सुकवि⟫ m.: හොඳ කවියෙකු

⟪सुकृत⟫ n.: හොඳ ක්‍රියාව

⟪सुखादित⟫ 3: හොඳින් කෑව

⟪सुदुःख⟫ n.: මහත් දුක (විශාල දුක)
:::
⟪दुस्⟫ "නරක, අයහපත්, දුෂ්කර" (සන්ධි නීති සැලකිල්ලට ගන්න!).

උදාහරණ:

::: indent
⟪दुर्नय⟫ m.: නරක හැසිරීම, වැරදි මාර්ගෝපදේශනය

⟪दुष्करण⟫ n.: නරක ක්‍රියාව, දුෂ්කර ක්‍රියාව
:::
මෙහිදී පහත නීතිය අදාළ වේ:

### 18.2.2. නඤ්-තත්පුරුෂ (a- / an-) හි අර්ථයන්

a- / an- සහිත තත්පුරුෂ සමාසවලට පහත සඳහන් අර්ථයන් තිබිය හැක:

1.  සමානත්වය (⟪तत्सादृश्यम्⟫):  
    ⟪अब्राह्मणः⟫ = පූජනීය නූල (⟪यज्ञोपवीत⟫ n.) දරන, එහෙත් සැබෑ බ්‍රාහ්මණයෙකු නොවී බ්‍රාහ්මණයෙකුට සමාන වන ක්ෂත්‍රියයෙකු හෝ වෛශ්‍යයෙකු
2.  නොමැතිකම, අභාවය (⟪तदभावः⟫):  
    ⟪अज्ञानम्⟫ = නොදැනුවත්කම (ඥානය නොමැතිකම)
3.  වෙනස් බව, අන්‍යත්වය (⟪तदन्यत्वम्⟫):  
    ⟪अपटम्⟫ = රෙදි කඩක් හෝ වස්ත්‍රයක් නොවන යමක් (⟪पट⟫ m: රෙදි, වස්ත්‍රය)
4.  කුඩා බව, අල්පත්වය (⟪तदल्पता⟫):  
    ⟪अनुदरम्⟫ = කුඩා බඩක් (බඩක් නැත්තාක් බඳු)
5.  නොරිසිකම, නුසුදුසු බව (⟪अप्राशास्त्यम्⟫):  
    ⟪अकालः⟫ = නුසුදුසු වේලාව, අකාලය
6.  සතුරුකම, විරෝධය (⟪निरोधः⟫):  
    ⟪असुरः⟫ = අසුරයා, දෙවියන්ට විරුද්ධ තැනැත්තා

පහත ශ්ලෝකය මෙම අර්ථ එකතු කරයි:

::: indent
⟪तत्सादृश्यमभावश्च तदन्यत्वं तदल्पता । अप्राशास्त्यं निरोधश्च नजर्थाः षट्प्रकीर्तिताः ॥⟫

නන් (= අ-/අන-) හි ආරවුලක් සඳහා වූ අර්ථ හයක් ඇත ....
:::
## 18.3. ක්‍රියාපද සංයෝජන

::: indent
⟪उपसर्गेण धात्वर्थो बलादन्यत्र नीयते । गङ्गासलिलमाधुर्यं सागरेण यथाम्भसा ॥⟫
:::
⟪चन्द्रकीर्ति⟫ : ⟪प्रसन्नपदा⟫ පිටපත් 2 කොටස 14f.

ප්‍රෙවබයක් මගින් මූලධාතුවක අර්ථය බලහත්කාරයෙන් වෙනස් කරයි, ගංගා ජලයේ මිහිර සමුද්‍ර ජලය මගින් වෙනස් කරනවාක් මෙන්.

::: grammar-box

සංස්කෘතයේ ක්‍රියාපද ප්‍රෙවබ (⟪उपसर्ग⟫ m.) සමඟ සම්බන්ධ කළ හැක. මෙහිදී සාමාන්‍යයෙන් වාක්‍ය සඳ්ධි පවතී. ප්‍රෙවබ මගින් මූලධාතුවේ අර්ථය සැලකිය යුතු ලෙස වෙනස් කළ හැකි අතර, බොහෝ විට ප්‍රෙවබ සමඟ මූලධාතුවේ අර්ථය වෙන්ව ඉගෙන ගැනීමට සිදුවේ. ප්‍රෙවබ සහිත ක්‍රියාපද වලට මූලධාතුවේ ප්‍රකාරය (P, Ā) වලට වඩා වෙනස් ප්‍රකාරයක් තිබිය හැක. මූලධාතුවට පෙර එකවර බොහෝ ප්‍රෙවබ තැබිය හැක.

:::

⟪उप⟫ "සඳහා, දෙසට, එරෙහිව"

උදාහරණ:

::: indent

6\. නැවත ඉපදීමේ මාර්ගයෙහි මැනවින් ගමන් කළ තැනැත්තා ශ්‍රාවකයාට මෙසේ පවසයි.
