# පාඩම 7


::: center
**සතියේ වාක්‍ය ඛණ්ඩය**
:::


::: center
⟪धर्मो जयति नधर्मः सत्यं जयति नानृतम् | क्षमा जयति न क्रोधो देवो जयति नासुरः ||⟫

**dharmo jayati nādharmaḥ**
**satyaṃ jayati nānṛtam |**
**kṣamā jayati na krodho**
**devo jayati nāsuraḥ ||**

සත්‍යය ජය ගනී, අසත්‍යය නොවේ,
සැබෑ ජය ගනී, අසත්‍ය නොවේ,
සහනය ජය ගනී, කෝපය නොවේ,
දෙවියන් ජය ගනී, ප්‍රතිදේවතාව නොවේ.
:::


## 7.1. සෘජු ප්‍රතිවස්තුව සහිත ක්‍රියා වාක්‍ය

::: grammar-box
**ප්‍රස්තාරය:**
**(කර්තෘ = kartṛ පු. = ⟪कर्तृ⟫) – සෘජු ප්‍රතිවස්තුව (karman උ. = ⟪कर्मन्⟫) – ක්‍රියාව**

උදාහරණයක් ලෙස
**rāmaḥ phalaṃ khādati** = ⟪रामः फलं खादति⟫ : "රාමයන් පලක් කනු ලැබේ."
**brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो देवं यजति⟫ : "බ්‍රාහ්මණයන් දෙවියකුට පූජාවක් කරයි (තවත් කෙනෙකු සඳහා)."
:::
ක්‍රියාව පරස්මෛපද හෝ ආත්මනේපද තුළ පවතින්නේ නම්, සෘජු ප්‍රතිවස්තුව (**karman** උ. = ⟪कर्मन्⟫) සාමාන්‍යයෙන් **අක්කුසටිව්** (ප්‍රශ්න පදය, dvitīyā උ. = ⟪द्वितीया⟫) තුළ පවතී.


## 7.2. අක්කුසටිව් (ප්‍රශ්න පදය, dvitīyā උ. = ⟪द्वितीया⟫ = "දෙවන විභක්ති ප්‍රත්‍යය")

### 7.2.1. ප්‍රශ්න සහ දැක්වීමේ විශේෂණ වල ඒක වචන සහ බහු වචන ප්‍රථමා විශේෂණය

::: grammar-box
| || පුළුල් ප්‍රථමා විශේෂණය | ස්ත්‍රී ලිංගික ප්‍රථමා විශේෂණය | උදාර ප්‍රථමා විශේෂණය |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :brකවුද/මොනවා | ඒ. | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |
| | බ. | **kān** :br⟪कान्⟫ | **kās** :br⟪कास्⟫ | **kāni** :br⟪कानि⟫ |
| **tad** :brඔහු/එය/මෙය | ඒ. | **tam** :br⟪तम्⟫ | **tām** :br⟪ताम्⟫ | **tad** :br⟪तद्⟫ |
| | බ. | **tān** :br⟪तान्⟫ | **tās** :br⟪तास्⟫ | **tāni** :br⟪तानि⟫ |
| **etad** :brමෙය මෙහි | ඒ. | **etam / enam** :br⟪एतम्⟫ / ⟪एनम्⟫ | **etām / enām** :br⟪एताम्⟫ / ⟪एनाम्⟫ | **etad / enad** :br⟪एतद्⟫ / ⟪एनद्⟫ |

| **idam** :brමෙය | ඒ. | **imam / enam** :br⟪इमम्⟫ / ⟪एनम्⟫ | **imām / enām** :br⟪इमाम्⟫ / ⟪एनाम्⟫ | **idam / enad** :br⟪इदम्⟫ / ⟪एनद्⟫ |

**enam** (⟪एनम्⟫) ආදී ස්වරූපයන් **enad** (⟪एनद्⟫) මූලයට අයත් වන අතර, එම මූලයෙන් සාපේක්ෂ විභක්ති පද කිහිපයක ස්වරූපයන් පමණක් නිර්මාණය වේ. මෙම ස්වරූපයන් **etad** හා **idam** යන පදවල ස්වරූප වෙනුවට භාවිතා කරනු ලබන්නේ, එම පද මගින් ඉඟි කෙරෙන දේ පෙර සඳහන් කර ඇති විටය.
උදා: **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं देवः⟫ | ⟪एनं यजन्ते⟫ || : "ඔහු දෙවියකි. ඔහුට පූජා කරයි."


### 7.2.2. ක්‍රියාපද විභක්තියේ භාවිතය (කාරක පද, dvitīyā f. = ⟪द्वितीया⟫ = "දෙවන විභක්ති පර්යන්තය")

::: grammar-box
ක්‍රියාපද විභක්තිය (dvitīyā f. = ⟪द्वितीया⟫) පහත දැක්වෙන අර්ථයන් දේ:
1. සක්‍රිය ක්‍රියා වාක්‍යය තුළ: **කාරක පදය** (karman n. = ⟪कर्मन्⟫) ක්‍රියාවෙන් ප්‍රකාශ වන කර්තෘගේ ක්‍රියාවට ලක්වන්නා:
උදාහරණයක් ලෙස,
**devaṃ yajati** = ⟪देवं यजति⟫ : "ඔහු දෙවියකුට පූජා කරයි."
**phalam āpnoti** = ⟪फलमाप्नोति⟫ : "ඔහු පල ලබයි (උදා: තම ක්‍රියාවේ පල)."
2. යාම, චලනයක්, ගෙන යාම හෝ එවැනි අර්ථයන් දක්වන ක්‍රියා පද සමග, ක්‍රියාපද විභක්තිය චලනයේ අවසාන ගමන් බිම දක්වයි:
උදාහරණයක් ලෙස,
**narakaṃ gacchati** = ⟪नरकं गच्छति⟫ : "ඔහු නරකයට යයි."
:::
ක්‍රියාපද විභක්තියේ තවත් භාවිතයන් පසුව සාකච්ඡා කරනු ලැබේ.



## 7.3. අවසානයේ -n සඳහා සන්ධිය

::: grammar-box
**අවසානයේ -n:**

1. මූර්ඡිත පල්ටැල සහ රෙට්‍රොෆ්ලෙක්ස් sparśa හා **ś-** ඉදිරියේ, එම ශබ්දවලට අනුරූප නාසිකය මගින් ආදේශ වේ:
**j-, jh-, ñ-, ś-** ඉදිරියේ **-n** » **-ñ**
**ḍ-, ḍh-, ṇ-, ṣ-** ඉදිරියේ **-n** » **-ṇ**
උදා: **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "ඔහු ක්ෂත්‍රියයින් පරාජය කරයි."
ආරම්භක **ś-** සාමාන්‍යයෙන් **ch-** මගින් ආදේශ වේ:
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (gurūñ śṛṇoti සමඟ) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "ඔහු ගුරුවරුන් ඇසේ." "ඔහු ගුරුවරුන්ට අවධානය යොමු කරයි."

2. ආරම්භක **l-** කෙළවරේ **-l** මගින් අනුනාසිකය සහිතව (නාසික l, ලේඛනය ⟪ल्⟫ අනුනාසිකය සහිතව ⟪ँ⟫) ආදේශ කෙරේ:
උදා. **paśūn + labhate** » ⟪पशूंल्लभते⟫ : "ඔහු සතුන් ලබා ගනී."
