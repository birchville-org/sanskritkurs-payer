# පාඩම 53

## 53.1. ද්විත්වය (⟪द्विवचन⟫ n.) නාම වල

::: grammar-box
**ද්විත්වය (⟪द्विवचनम्⟫) "දෙකක්" යන්න හඳුන්වා දීම සඳහා භාවිතා කරයි:**

:::
::: indent
⟪अश्विनौ⟫ "අශ්වින දෙදෙනා"
:::
**ද්විත්වය භාවිතා කිරීම අනිවාර්ය වන්නේ එම දෙය "දෙකක්" හෝ ඊට සමාන වූ දේවල් පිළිබඳව කතා කරන විටය:**

::: indent
⟪हस्तौ⟫ "අත් (තනි පුද්ගලයෙකුගේ)"
⟪पादौ⟫ "පාද (මිනිසෙකුගේ, වැලිපොතෙකුගේ හෝ අනෙක් ද්විපාද සත්වයෙකුගේ)"
:::
**කිසියම් වර්ගයේ (විශේෂයක්, ගණයක්) පුරුෂ සහ භාර්යාවන් දෙදෙනෙකු හඳුන්වා දීම සඳහා ද්විත්වය භාවිතා කළ හැකිය:**

::: indent
⟪पितरौ⟫ "පියා සහ මව = දෙමාපියන්"
:::
**"යුගලයක්" යන අර්ථය දෙන වචන - උදා: ⟪युग⟫ n., ⟪द्वन्द्व⟫ n., ⟪द्वय⟫ n. - සෑම විටම ඒක වචනයෙන් භාවිතා කරන අතර, එය යුගල දෙකක් හෝ ඊට වැඩි ගණනක් නොවේ නම්:**

::: indent
⟪बाहुद्वयम्⟫ "අත් යුගලයක්"

ඊපික් කෘති (⟪महाभारत⟫, ⟪रामायण⟫) සහ අනෙකුත් නොගණන් කෘතිවල වැදගත්ම පද්‍ය මානය ශ්ලෝකාවයි ("ඇසීම" යන අරුත දෙන ⟪श्रु⟫ වෙතින් "බැසීම", "ශබ්දය", "පාඩම" යන අරුත් දේ).

## 53.11. අභ්‍යාසය

::: grammar-box
**ඔබ ඉගෙන ගත් සියලුම පද්‍යවලින් ශ්ලෝක හඳුනා ගන්න. ඒවා සඳහා මෙත්‍රික රටාව ලිඛිතව සකසන්න. හැකි අක්‍රමිකතා හෝ විපුලා ආකාර පෙන්වා දෙන්න.**
