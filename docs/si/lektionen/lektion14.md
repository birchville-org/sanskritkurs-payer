# පාඩම 14

## 14.1. නාම පද මගින් හැඳින්වෙන දේ අතර සම්බන්ධය ප්‍රකාශ කිරීම: ජෙනටිව් (ṣaṣṭhī f. = ⟪षष्टी⟫ = හයවන විභක්ති ප්‍රත්‍යය)

::: grammar-box

නාම පද දෙකක් මගින් හැඳින්වෙන දේ අතර සම්බන්ධය ප්‍රකාශ කිරීමට ජෙනටිව් (ṣaṣṭhī f. "හයවන විභක්ති ප්‍රත්‍යය") භාවිතා කරයි. අනෙක් සියලුම විභක්ති වලින් ජෙනටිව් වෙනස් වන්නේ, සුළු අපවාදයන් හැර, එය ක්‍රියා පදය මගින් ප්‍රකාශ වන ක්‍රියාව තවදුරටත් විස්තර කිරීම සඳහා නොව, නාම පද මගින් හැඳින්වෙන පුද්ගලයන් හෝ දේ අතර සම්බන්ධය ප්‍රකාශ කිරීම සඳහා යොදන බැවිනි. ජෙනටිව් බහුලවම පැකිළෙන ප්‍රශ්නය වන්නේ: කාගෙද?

:::

උදාහරණ:

⟪कवेः पुत्रः⟫ "කවියාගේ පුත්‍රයා"

⟪धनस्य लोभः⟫ "ධනය පිළිබඳ ආශාව"

⟪नगरस्यार्धम्⟫ "නගරයේ අඩකට"

⟪रामस्य कृतम्⟫ "රාමයන්ගේ ක්‍රියාව / එක් ක්‍රියාවක්"

::: grammar-box

සාමාන්‍ය වචන පිළිවෙල:

> **ජෙනටිව් විභක්තියෙන් යුත් නිර්දේශක වචනය — අනෙක් විභක්තියෙන් යුත් නිර්දේශිත නාම පදය**

:::

**ජෙනටිව් සහ PPP:**

::: grammar-box

PPP (පූර්ණ කාරක පද) සඳහා, ජෙනටිව් විභක්තිය ඉන්ස්ට්‍රුමෙන්ටල් (tṛtīyā) විභක්තිය වෙනුවට ආගන්තුකයා (kartṛ) සඳහා යොදා ගත හැක; ඉන්ස්ට්‍රුමෙන්ටල් සංයෝජනයේදී PPP එක නිෂ්ක්‍රිය ක්‍රියා පදයක් ලෙස සලකන අතර (ඉන්ස්ට්‍රුමෙන්ටල් විභක්තියේ ඇති දේ ආගන්තුකයා හැඳින්වේ), ජෙනටිව් සංයෝජනයේදී PPP එක නාම පදයක් හෝ විශේෂණයක් ලෙස සලකන අතර (එබැවින් ජෙනටිව් විභක්තියේ ඇති දේ සැබෑ ආගන්තුකයා ලෙස නොසලකයි).

පාණිනිය 2.3.67 අනුව, PPP එකට වර්තමාන තත්වයක් ඇති විට (ඉහත බලන්න) ජෙනටිව් විභක්තිය ද, අතීත තත්වයක් ඇති විට ඉන්ස්ට්‍රුමෙන්ටල් විභක්තිය ද යොදා ගනී:

> ⟪रामस्येष्टं फलम्⟫ "රාමයන්ගේ අපේක්ෂිත පල = රාමයන් වර්තමානයේ අපේක්ෂා කරන පල"
> 
> ⟪रामेणेष्टं फलम्⟫ "රාමයන් අපේක්ෂා කළ පල"

ස්වාභාවිකවම, PPP උදාසීන එක වචනයක් (Neutrum Singular), ක්‍රියාපද අබ්සට්‍රැක්ටම් ලෙස - එනම් නාම පදයක් ලෙස භාවිතා වේ, ජෙනටිව් (Genetiv) සිටී.

:::

## 14.2. ජෙනටිව් ආකාර (ṣaṣṭhī f. = ⟪षष्ठी⟫) සෑදීම

ක්‍රියාපද මූලයන් සහිතව ජෙනටිව්, මූල අවස්ථා වෙනස සහිතව දුර්වල මූලයෙන් සෑදේ.

**අකුරින් අවසන් වන මූලයන්ගේ ජෙනටිව්:**

::: grammar-box

අකුරක් පසුව, නිවැරදි ජෙනටිව් අන්තයන්:
* එක වචනය: **-as**
* බහු වචන: **-ām**

:::

| නාම මූලය | දුර්වල මූලය | ජෙනටිව් එක වචනය | ජෙනටිව් බහු වචන |

| **paśu-mant-** :br ⟪पशुमन्त्⟫ | **paśu-mat-** :br ⟪पशुमत्⟫ | **paśu-mat-as** :br ⟪पशुमतस्⟫ | **paśu-mat-ām** :br ⟪पशुमताम्⟫ |

:::

**ස්වරයින් අවසන් වන මූලයන්ගේ ජෙනටිව්, එක සීරු මූල නාමයන් සහ දිප්තොංගයින් අවසන් වන මූලයන් හැර:**

**බහු වචන:**

::: grammar-box

ස්වරයින් අවසන් වන මූලයන්ගේ ජෙනටිව් බහු වචනය මෙසේ සෑදේ:

> **-දිග අවසන් වන මූලයේ ස්වරය + -nām**

:::

::: grammar-box

ව්‍යංජනාන්ත සර්වනාම පදවල ඒකවචනයේ ප්‍රත්‍යය අනිසි ලෙස සෑදෙන අතර එය හොඳින් මුහුණත් කරගැනීමට සිදුවේ.
