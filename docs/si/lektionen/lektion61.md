# පාඩම 61

## 61.1. -ā, -ī, -ū අගින් පවතින මූල නාමයන්හි විභක්තිය

### 61.1.1. ⟪तत्पुरुष⟫ හි අගින් -ā මූල නාමයන්

::: grammar-box

**ස්වර අගයන්ට පෙර දුර්වල විභක්ති වලදී මූල ස්වරය ශුන්‍ය අවස්ථාවට (Ø) පත් වේ.**

**පුල්ලිංග සහ ඔබ්බිංග විභක්තිය එකම වේ.**

:::

### 61.1.2. -ī අගින් පවතින ඔබ්බිංග මූල නාමයන්

::: grammar-box

**ස්වර අගයකට පෙර -ī වෙනුවට -iy භාවිතා වේ.**

**සාමාන්‍ය විභක්ති අගයන්ට අමතරව, ඒක වචන දත්.අබ්.ජන්.ලොක් සහ බහු වචන ජන් විභක්තිවලදී, -ī (⟪देवी⟫) අගින් පවතින බහු ස්වර ඔබ්බිංග නාමයන්ට අනුකූලව සැදීම් ද පවතී.**

### 61.1.3. ⟪तत्पुरुष⟫ අවසානයේ -ī අගයෙන් යුත් මූල නාම

::: grammar-box

**ස්වර අගයන්ට පෙර, මූලයට අයත් එක් ව්‍යංජනයකින් පමණක් -ī ආරම්භ වේ නම්, එය -y මගින් ප්‍රතිස්ථාපනය කෙරේ. මූලයට අයත් ව්‍යංජන කිහිපයකින් -ī ආරම්භ වේ නම්, ස්වර අගයකට පෙර එය -iy මගින් ප්‍රතිස්ථාපනය කෙරේ.**

**ව්‍යඛ්‍යානය පුංශලිංග සහ භාර්යාව ලිංගයේ එකම වේ.**

උදා. ⟪ग्रामणी⟫ "ගමක්/ගම්පහනක් ගෙන යන": ලොක. sg.m.f. ⟪ग्रामण्याम्⟫

:::

### 61.1.6. -ū අවසාන බහු ස්වරයකින් යුත් උපන් පද වල විභක්ති රූප

**සරල අනාගත කාලය (⟪ऌत्⟫) හැර වාක්‍ය ඛණ්ඩී අනාගත කාලය (⟪लुट्⟫) ද ඇත. ස්වදේශීය වාක්‍ය විද්වතුන්ගේ මතයට අනුව, එය දුරස්ථ අනාගතය ("පවතින දිනයෙන් පසු") සඳහා භාවිතා කරන අතර, සරල අනාගත කාලය ආසන්න අනාගතය ("පවතින දිනයේ") සඳහා භාවිතා කරයි. ප්‍රමුඛ සංස්කෘතයේ, මෙම අනාගත කාල දෙක භාවිතයේ සැලකිය යුතු වෙනසක් නොමැති බව පෙනේ.**

## 61.9. සංස්කෘත සාහිත්‍ය සාගරයට පිවිසීම: ಶ್ರೀಗಣನಾಥ / ⟪श्रीगणनाथ⟫
