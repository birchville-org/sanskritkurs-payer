# පාඩම 50

## 50.1. නාම ව්‍යුත්පන්න: සාමාන්‍ය ශ්‍රේණිගත කිරීම

::: grammar-box
**සාමාන්‍ය ශ්‍රේණිගත කිරීම සංස්කෘතයෙන් ⟪तद्धित⟫ ප්‍රත්‍යයන් සමඟ සිදු වේ**
* **-⟪तर⟫ (ස්ත්‍රී: ⟪तरा⟫) "සංයුක්ත" තත්වයේ**
* **⟪तम⟫ (ස්ත්‍රී: ⟪तमा⟫) "ප්‍රධාන" තත්වයේ**

**මෙම ප්‍රත්‍යයන් විශේෂණ සඳහා පුංස් ලිංගික මූලයට එක් කරනු ලැබේ. මූල වෙනස්වීම් සහිත නාම සඳහා, ඒවා ශක්තිहीन මූලයට එක් කරනු ලැබේ, එය -su ආකාරයෙන් පවතින අතර (⟪पञ्चमी⟫) බහු වචනයේ.**
:::

::: grammar-box
**අර්ථය:**

**"සංයුක්ත" යනු, සැසඳිය හැකි වස්තුවක් ප්‍රකාශ නොවේ නම්: "ප්‍රමාණවත්, ඉතා, අතිශයින්":**

:::
::: indent
උදා: ⟪सुचितर⟫ 3 "ප්‍රමාණවත් පිරිසිදු", "ඉතා පිරිසිදු", "අතිශයින් පිරිසිදු"
:::
**සැසඳිය හැකි වස්තුවක් ප්‍රකාශ කරන විට, එය ආබ්ලේටිව් (⟪पञ्चमी⟫) තත්වයේ පවතී. සංයුක්ත + ආබ්ලේටිව් යනු ජර්මානු භාෂාවේ "සහ" සමඟ ශ්‍රේණිගත කිරීමට අනුරූප වේ.**

::: indent
උදා: ⟪देवदत्ताद्रामो धीमत्तरः⟫ = වචනාර්ථයෙන්: "දේවදත්තාගෙන් බැලූ විට රාමු තරම් සිතිවිල්ලක් ඇත" = "රාමු දේවදත්තාට වඩා සිතිවිල්ලක් ඇත"
:::
**"ප්‍රධාන" යනු, සැසඳිය හැකි වස්තුවක් ප්‍රකාශ නොවේ නම්: "අතිශයින්, ඉතා":**

::: indent
උදා: ⟪सत्तम⟫ 3 (⟪सन्त्⟫ වෙත) "අතිශයින් හොඳ, ඉතා හොඳ"
:::
**සැසඳිය හැකි වස්තුවක් ප්‍රකාශ කරන විට, එය ජෙනිටිව් (⟪षष्ठी⟫) තත්වයේ පවතී ("සිට", "අතර") සහ ප්‍රධාන යනු ජර්මානු ප්‍රධානයට අනුරූප වේ (උසස් මට්ටම):**

::: indent
උදා: ⟪द्विजानां सत्तमः⟫ = "ඉහළම දෙවර උපන් අය"
:::
**-⟪तर⟫ සහ -⟪तम⟫ ප්‍රත්‍යයන් විශේෂණවලට පමණක් නොව, නාමයන්ට, අවිකාරී පදවලට සහ ආශ්‍රය වචනවලට ද යෙදිය හැක:**

උදාහරණ:

::: indent
⟪गजतम⟫ පු. "හොඳම අනුවරයා" (⟪गज⟫) (බුදුන්ගේ නාමයක් ලෙස ද)

⟪गोतम⟫ පු. "වඩාත්ම විශිෂ්ට වැලිකෙළිය" (⟪गो⟫) හෝ: "ගවයින් වැඩිම"

⟪उद्⟫ අවි. "ඉහළට", "උඩට" » ⟪उत्तर⟫ 3 "වැඩිපුර" » ⟪उत्तम⟫ 3 "වඩාත්ම වැඩිපුර"
:::
**මෙම ප්‍රත්‍යයන් ආශ්‍රය වචනයකට යෙදෙන විට, ඒවා සැමවිටම ක්‍රියාදාරක ප්‍රතිපත්තියෙන් දිස්වේ:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

උදාහරණ:

::: indent
⟪पचतितराम्⟫ "ඔහු/ඇය/එය වඩා හොඳින් පිසයි"

⟪पचतितमाम्⟫ "ඔහු/ඇය/එය වඩාත්ම හොඳින් පිසයි"

**මෙම ප්‍රතිපත්තිය මෙම ප්‍රත්‍යයන් අවිකාරී පදයකට යෙදෙන විට ද, ව්‍යුත්පන්න වචනය ක්‍රියාදාරක ලෙස භාවිතා වන විට ද පවතී:**
