## 57.1. අඔරිස්ට් 4: s-අඔරිස්ට්

::: grammar-box
**s-අඔරිස්ට් යනු ⟪अनिट्⟫ මූලධාතු වලට සෑදේ, ඒවායින් අනෙකුත් අඔරිස්ට් පැහැදිලිවම නොමැතිනම්. විකල්ප ⟪अनिट्⟫ මූලධාතු සාමාන්‍යයෙන් s-අඔරිස්ට් හෝ iṣ-අඔරිස්ට් යන දෙකෙන් එකක් සෑදිය හැක. ⟪अनिट्⟫ මූලධාතු, අඔරිස්ට් 1.,2. හෝ 6. ආකාරයෙන් පසු ⟪परस्मैपद⟫ සෑදුවහොත්, s-අඔරිස්ට් පසු ⟪आत्मनेपद⟫ සෑදේ.**

**නිර්මාණය: ඔග්මෙන්ට් + මූලධාතු + s + අතෙමතික ද්විතීය පර්යන්ත**
:::
පර්යන්ත වගුව සහ මූල නිර්මාණ ප්‍රත්‍යය

**සාමාන්‍ය ශබ්ද විපර්යාස නීතිය යොදනු ලැබේ: ව්‍යංජනයක් අතර සිටින ශාකාර ව්‍යංජනයක් නැතිව යයි (උදා: ⟪उद्⟫ + ⟪स्थित⟫ » ⟪उत्थित⟫), එනම් පර්යන්ත -t- හෝ -th- වලින් ආරම්භ වන ප්‍රත්‍යයට පෙර මූල නිර්මාණ ප්‍රත්‍යය -s- නැතිව යයි (නාසික හෝ r- පසු නොවේ).**

::: indent
"කෙටි ස්වරයක් පසු කළ විට, -st- හෝ -sth- මගින් ආරම්භ වන "අවසාන ස්වර" හි -s- ඉවත් වේ."
:::
අනෙකුත් ස්වර නියමයන්, පිටතට එන අකුරු සහ s- හි සම්බන්ධය සඳහා අනුගමනය කළ යුතුය.

## 57.2. අභ්‍යාස

A) උපකරණ නොමැතිව පහත සඳහන් රූප අර්ථ දක්වා, ඒවාට අනුරූප අභ්‍යුද රූප සාදන්න. හේතුක ධාතුවලට සහ s-අභ්‍යුදයක් සාදන ධාතූන්ට අමතරව, වරහන් තුළ අනුරූප අභ්‍යුදයේ වර්ගය සඳහන් කර ඇත:

1. ⟪पेचिथ⟫
2. ⟪अवक्⟫ (⟪३⟫)
3. ⟪सोष्यसि⟫
4. ⟪छिन्दे⟫
5. ⟪कुरुषे⟫
