# පාඩම 31

## 31.1. සප්තම වර්තමාන පන්තිය (⟪रुधादि⟫ = "⟪रुध्⟫ ආදිය")

::: grammar-box
**නිර්මාණය:**

**ඉහළ මට්ටමේ මූලයේ අවසාන ස්පර්ශ ධ්වනි වලට පෙර, නාසික අන්තඃස්ථාපනයක් (-na- හෝ -n-) ඇතුළත් කරනු ලැබේ:**

*   **ශක්තිමත් පදය: -na-**
*   **දුර්වල පදය: -n-**

**මූලයේ අවසාන ස්පර්ශ ධ්වනි, ස්පර්ශ ආරම්භක ප්‍රත්යයන් සමඟ එකතු වීම සඳහා දෙවන වර්තමාන පන්තියට අදාළ එකම නීති වලංගු වේ.**
:::

::: indent
