# අන්තර්ගත වගුව

## [පාඩම 1](lektion01)

*   ⟪गणेशपूजनम्⟫ = gaṇeśapūjanam = ගණේශයන්ගේ පූජාව
*   ⟪मङ्गलचरणम्⟫ = maṅgalacaraṇam = "මංගල්‍යජනක ආරම්භය"
*   1\. ඉන්දියානු විද්‍යාවේ ආරම්භකයින් සඳහා සාහිත්‍යය
*   2\. සාම්ප්‍රදායික ඉන්දියානු වර්ගීකරණයට අනුව සංස්කෘත ධ්වනි සහ ඒවායේ විද්‍යාත්මක උච්චාරණය
*   2.1. තනි ධ්වනිවල උච්චාරණය පිළිබඳව
*   3\. අභ්‍යාසය

## [පාඩම 3](lektion03)

*   1\. නාම විභක්තිය ඒක වචනය = prathamā ekavacanam = ⟪प्रथमा एकवचनम्⟫ (ඉදිරියට)
*   1.1. -s මත අවසන් වන නාම විභක්තිය ඒක වචනය (ඉදිරියට)

*   2\. පුංසක නාම සඳහා ස්ත්‍රී ලිංගික නාම (විශේෂණ සහ නාම) සෑදීම
*   3\. නාම විභක්තිය බහු වචනය = prathamā bahuvacanam = ⟪प्रथमा बहुचनम्⟫
*   4\. ස්වර සන්ධිය
*   5\. -ās සඳහා වාක්‍ය සන්ධිය
*   6\. වචන මාලාව
*   7\. අභ්‍යාසය

*   1.1.2. ප්‍රදර්ශක සර්වනාම (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)
*   1.2. අවසානයේ -m සහිත සන්ධිය

*   1\. -ā, -ī, -ū අග්‍රයෙන් පවතින මූල නාම වල විභක්තිය
*   1.1. ⟪तत्पुरुष⟫ හි අග්‍රයේ පවතින -ā මූල නාම
*   1.2. -ī අග්‍රයෙන් පවතින ස්ත්‍රී ලිංගික මූල නාම
*   1.3. ⟪तत्पुरुष⟫ හි අග්‍රයේ පවතින -ī මූල නාම
*   1.4. -ū අග්‍රයෙන් පවතින එක සිලබු, ස්ත්‍රී ලිංගික මූල නාම
*   1.5. ⟪तत्पुरुष⟫ හි අග්‍රයේ පවතින -ū මූල නාම
*   1.6. -ū අග්‍රයෙන් පවතින බහු සිලබු ස්ත්‍රී ලිංගික නාම වල විභක්තිය
*   2\. පරිප්‍රස්ථිත අනාගත කාලය (⟪लुट्⟫)
*   3\. ඉන්ටෙන්සිවම් (බහු වාර ක්‍රියාපදය) (⟪चर्करीतम्⟫)
*   3.1. Ātmanepada-ඉන්ටෙන්සිවම්
*   3.2. Parasmaipada-ඉන්ටෙන්සිවම්
*   4\. නාම ව්‍යුත්පන්න ක්‍රියාපද (⟪नामधातु⟫)
*   4.1. විශේෂ ප්‍රත්‍යයකින් තොරව, Parasmaipada
*   4.2. -ya ප්‍රත්‍යය සමඟ, Parasmaipada
*   4.3. -kāmya ප්‍රත්‍යය සමඟ, Parasmaipada
*   4.4. -sya හෝ -asya ප්‍රත්‍යය සමඟ, Parasmaipada
*   4.5. -ya ප්‍රත්‍යය සමඟ, Ātmanepada
*   4.6. -aya, -āpaya ප්‍රත්‍යය සමඟ
*   5\. ආශීර්වාද කාලය (⟪आशीर्लिङ्⟫)
*   6\. කොන්ඩිෂනල් (සංකල්පිත) කාලය (⟪ऌङ्⟫)
*   7\. -ai, -o, -au අග්‍රයෙන් පවතින නාම වල විභක්තිය
*   8\. ඉතිරි සර්වනාම
*   8.1. ද්වි වචනයේ පුද්ගල සර්වනාම
*   8.2. ⟪अदस्⟫ "එම (දුරස්ථ)" ප්‍රදර්ශක සර්වනාම
*   9\. සංස්කෘත සාහිත්‍ය මුහුදට නික්ම යාම: ಶ್ರೀಗಣನಾಥ / ⟪श्रीगणनाथ⟫
