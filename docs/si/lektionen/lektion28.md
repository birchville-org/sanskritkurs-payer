# පාඩම 28

## 28.1. හේතු ක්‍රියාපදය (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**යම් කෙනෙකු හෝ යමක් තවත් කෙනෙකුට හෝ වෙනත් දෙයක් යම් මූලධර්මයකින් (ප්‍රතිවිබාග සහිත හෝ අසහිත) ප්‍රකට කරනු ලබන ක්‍රියාවක් සිදු කිරීමට හෝ අත්විඳීමට පෙළඹවීමක් හෝ සිදු කිරීමක් දැක්විය යුතු නම්, හේතු ක්‍රියාපදය (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫) භාවිතා කරයි.**

උදාහරණය:
⟪गम्⟫ "ගමන් කිරීම" » හේතු: ⟪गमयति⟫ "යම් කෙනෙකු ගමන් කරන පරිද්දෙන් සැලසීම; යවයි"
⟪दृश्⟫ "දැකීම" » හේතු: ⟪दर्शयति⟫ "දකින පරිද්දෙන් සැලසීම = පෙන්වයි"
:::

## 28.2. හේතු ක්‍රියාපදය සහිත වාක්‍ය ගොඩනැගීම (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**ප්‍රස්කාරය 1:**

**හේතු ක්‍රියාපදයට පදනම් වූ මූලධර්මය (ප්‍රතිවිබාග සහිත හෝ අසහිත) අකර්මක වන විට (එනම්, එය සමඟ කර්තෘ පදයක් තිබිය නොහැක) හෝ චලනය, දැනුම, තොරතුරු හෝ ආහාර ගැනීම ප්‍රකට කරන විට:**

**හේතු ක්‍රියාපදයේ කර්තෘ (⟪कर्ता⟫) නාම පදයෙන් (⟪प्रथमा⟩) — සිදු කරන ලද ක්‍රියාවේ කර්තෘ කර්ම පදයෙන් (⟪द्वितीया⟩) — (චලනයේ ඉලක්කය, දැනුමේ වස්තුව ආදිය කර්ම පදයෙන් = ⟪द्वितीया⟩) — හේතු ක්‍රියාපදය**
:::
උදාහරණ:

⟪दुर्जनो रामं मोहयति⟫ = "දුර්මනුෂ්යයෙකු රාමුව විසිදැලි කිරීම = රාමුව විසිදැලි කළේය = රාමු වැරදීම සිදු කරයි"
ප්‍රතිඵලය: ⟪रामो मुह्यति⟫ = "රාමු විසිදැලිය / මෝඩ වී ඇත / වැරදෙයි."

⟪रामः शत्रून्स्वर्गं गमयति⟫ = "රාමු සතුරන් ස්වර්ගයට යන පරිද්දෙන් සැලසීම = සතුරන් ස්වර්ගයට යවයි"
ප්‍රතිඵලය: ⟪शत्रवः स्वर्गं गच्छन्ति⟫ = "සතුරන් ස්වර්ගයට යති / ස්වර්ගයට පැමිණෙති"

⟪गुरू रामं वेदार्थं वेदयति⟫ = "ගුරුවරයා රාමු වේදයේ අර්ථය දන්නා පරිද්දෙන් සැලසීම = රාමුට වේදයේ අර්ථය පැහැදිලි කරයි / උගන්වයි"
ප්‍රතිඵලය: ⟪रामो वेदार्थं वेत्ति⟫ = "රාමු වේදයේ අර්ථය දනී / තේරුම් ගනී"

⟪स रामं वेदमध्यापयति⟫ = "ඔහු රාමට වේදය උගන්වයි"
ප්‍රතිඵලය: ⟪रामो वेदमधीते⟫ "රාම වේදය අධ්‍යනය කරයි"

⟪रामो देवानामृतमाशयति⟫ = "රාම දෙවියන්ට අමෘතය ආහාරයට ගනී = දෙවියන්ට අමෘතය ආහාරයට ලබා දෙයි" (⟪अश्⟫ 9 "ආහාරයට ගැනීම")
ප්‍රතිඵලය: ⟪देवा अमृतमश्नन्ति⟫ "දෙවියන් අමෘතය ආහාරයට ගනී"

**ප්‍රස්කාර 2:**

**සාධාරණ ක්‍රියාවලි සඳහා (ප්‍රස්කාර 1 යටතේ සඳහන් කර ඇති දේ හැර). එමෙන්ම හේතු කාරකය මගින් සිදු කරන ලද දෙයක් වැළඳවීමේදී (හේතු කාරකය හේතු කාරකයක් සඳහා වූ හේතු කාරකයක් වන විට):**

**කාරකය (⟪कर्ता⟫) කාෂටිව් පදයේ නිරුක්තික (⟪प्रथमा⟫) — ප්‍රේරිත ක්‍රියාවේ කර්තෘ උපකාරක පදයෙන් (⟪तृतीया⟩) — ප්‍රේරිත ක්‍රියාවේ විෂය පදය සාමාන්‍ය ක්‍රියාවෙන් ලැබෙන විභක්තියෙන් (එනම් බොහෝ විට චතුර්ථී) — ක්‍රියාව කාෂටිව් පදයෙන්**

⟪विष्णुमित्रो रामेण गोविन्दं गमयति⟫ = "විෂ්ණුමිත්‍ර රාම ගෝවින්ද යන ලෙස ප්‍රේරණය කරයි = විෂ්ණුමිත්‍ර රාම ගෝවින්ද යැවයි"

**⟪स्मृ⟫ "සිහිපත් කිරීම" (මෙයට අපවාද ඇත)**
**⟪अद्⟫ "ආහාර ගැනීම"**
**⟪खाद्⟫ "කඩා කෑම"**
:::
උදාහරණ:

⟪रामो भृत्येन भारं नाययति वाहयति वा⟫ = "රාම සේවකයාට බර ගෙන යන ලෙස හෝ ගමන් කරන ලෙස පවසයි"
ප්‍රතිඵලය: ⟪भृत्यो भारं नयति वहति वा⟫ = "සේවකයා බර ගෙන යයි හෝ ගමන් කරයි"

⟪रामो बालेनान्नमादयति खादयति वा⟫ = "රාම ළදරුවාට ආහාර ගන්නා ලෙස හෝ කඩා කන ලෙස පවසයි"
ප්‍රතිඵලය: ⟪बालो ऽन्नमत्ति खादति वा⟫ = "ළදරුවා ආහාර ගනී හෝ කඩා කරයි"

(⟪स⟫) ⟪रामेण स्मारयति⟫ = "රාම සිහිපත් කරන ලෙස ඔහු ප්‍රේරණය කරයි"
ප්‍රතිඵලය: ⟪रामः स्मरति⟫ = "රාම සිහිපත් කරයි"

::: grammar-box
**පහත කාෂටිව (Causative) ශබ්ද සකස් 1 හා සකස් 2 යන දෙකටම අනුව ගොඩනැගිය හැක:**

**⟪हृ⟫ "රැකගන්නා, ගෙනවිත් දෙන්නා"**
**⟪कृ⟫ "කරන්නා, සිදු කරන්නා"**
**⟪दृश्⟫ සඳහා Ātmanepadakausativ**
:::
උදාහරණ:

⟪रामो भृत्यं कटं कारयति हारयति वा⟫ = "රාමයන් විසින් සේවකයාට පොතු (⟪कट⟫ m.) සකස් කරන්න හෝ ගෙනවිත් දෙන්න"
නැතහොත්:
⟪रामो भृत्येन कटं कारयति हारयति वा⟫
ප්‍රතිඵලය: ⟪भृत्यः कटं करोति हरति वा⟫ = "සේවකයා පොතක් සකස් කරයි හෝ ගෙන එයි"

⟪रामो बालं प्रतिमां दर्शयते⟫ = "රාමයන් විසින් ළදරුවාට රූපය දැකීම සිදු කරයි = ළදරුවාට රූපය පෙන්වයි (ස්වාධීන අරමුණක් සඳහා)"
නැතහොත්:
⟪रामो बालेन प्रतिमां दर्शयते⟫
ප්‍රතිඵලය: ⟪बालः प्रतिमां पश्यति⟫ = "ශිෂ්‍යයා රූපය දකී"

කාෂටිව ශබ්දයක් පැසිව (Passive) වාක්‍ය ඛණ්ඩයක යොදන විට, පහත සඳහන් සැලසුම භාවිතා වන්නේ බොහෝ විටය:

::: grammar-box
**සැලසුම A (පැසිව වාක්‍ය ඛණ්ඩය):**

**කාෂටිවයේ කාරකය උපකරණ පදයෙන් (⟪तृतीया⟫) — සිදු කරවන ලද ක්‍රියාවේ කාරකය නාම පදයෙන් (⟪प्रथमा⟫) — සිදු කරවන ලද ක්‍රියාවේ වස්තුව සාමාන්‍ය ධාතු මගින් තිබිය යුත්තේ එම ක්‍රියාවට අදාළ වචනයෙන් (එනම් බොහෝ විට ආකුසතිවයේ) — ක්‍රියාවාචකය කාෂටිවයේ**
:::
උදාහරණ:

⟪गुरुणा रामो ग्रामं गम्यते⟫ = "ගුරුවරයා රාමයා ගම්මානයට යවයි"
ප්‍රතිඵලය: ⟪रामो ग्रामं गच्छति⟫ = "රාමයා ගම්මානයට යයි"

⟪रामेण भृत्यः कटं कार्यते⟫ = "රාමයන් විසින් සේවකයාට පොතක් සකස් කරන්න"
ප්‍රතිඵලය: ⟪भृत्यः कटं करोति⟫ = "සේවකයා පොතක් සකස් කරයි"

⟪रामेण भृत्यो भारं हार्यते⟫ = "රාමයන් විසින් සේවකයාට බර ගෙන එන්න"
ප්‍රතිඵලය: ⟪भृत्यो भारं हरति⟫ = "සේවකයා බර ගෙන එයි"


## 28.3. ප්‍රේෂණ කාල මූලය සෑදීම (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

:::
