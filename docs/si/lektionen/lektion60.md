## 60.4. පුනරාවර්තනය වූ භූත කාලයේ ⟨⟪परस्मैपद⟫⟩ පදනම (⟪द्वित्वलिट्⟫)

::: grammar-box
**නිර්මාණය:**

**දුර්වල භූත කාල පදනම + vāṃs**

**දුර්වල භූත කාල පදනම සිලබුවකින් පමණක් සෑදී ඇත්නම්, සන්ධිස්වරය -i- එකතු කරයි. භූත කාල රූප කිහිපයකදී සන්ධිස්වරය විකල්ප වේ.**
:::
උදාහරණ:

| ⟪भिद्⟫ 7U | ⟪बिभिद्वांस्⟫ "කැඩූ පුද්ගලයා" |
| --- | --- |
| ⟪अस्⟫ 2P; 4P | ⟪आसिवांस्⟫ "තිබූ පුද්ගලයා" ; "විසි කළ පුද්ගලයා" |
| ⟪दा⟫ 3U | ⟪ददिवांस्⟫ (da-d-i-vāṃs) "දුන් පුද්ගලයා" |
| ⟪पच्⟫ 1U | ⟪पेचिवांस्⟫ "පිසූ පුද්ගලයා" |
| ⟪गम्⟫ 1U | ⟪जग्मिवांस्⟫ / ⟪जगन्वांस्⟫ "ගිය පුද්ගලයා" |

::: grammar-box
**විභක්ති විපර්යාසය:**

*   **ශක්තිමත් මූල පදය: -vāṃs**
*   **දුර්වල මූල පදය:**
*   **අකුරක් ඉදිරියේ: **-vat** **(!)**
*   **ස්වරයක් ඉදිරියේ: -uṣ**

**uṣ ඉදිරියේ සන්ධි ස්වරය -i- අතුරුදහන් වේ.**

**ස්ත්‍රී ලිංගය:**

**දුර්වල මූල පදය ස්වරය ඉදිරියේ + -ī (⟪देवी⟫ මෙන් විභක්ති වේ)**
