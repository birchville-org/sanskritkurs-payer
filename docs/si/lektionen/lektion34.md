# පාඩම 34

## 34.1. සම්පූර්ණ කාලය (⟪लिट्⟫)

සම්භාව්‍ය සංස්කෘත භාෂාවේ, සම්පූර්ණ කාල මූලයෙන් පෙන්නුම් කරන ආකාරය (Indikativ) සහ විශේෂණ පද (Partizip) පමණක් ඇත.

::: grammar-box
**සම්පූර්ණ කාලය සෑදීමේ ආකාර දෙකක් ඇත:**
*   **නැවත සම්බන්ධ කළ සම්පූර්ණ කාලය = ⟪द्वित्वलिट्⟫**
*   **පරිභාෂිත සම්පූර්ණ කාලය = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**පරිභාෂිත සම්පූර්ණ කාලය (⟪अनुप्रयोगलिट्⟫) භාවිතා කරන්නේ:**
1. **ව්‍යුත්පන්න සර්වනාමික ආකාර (හේතු කාරක, අපේක්ෂා කිරීම, සංඛ්‍යාත, නාම ව්‍යුත්පන්න) සඳහා**
2. **දිගු ස්වරයකින් (ā හැර) ආරම්භ වන මූල පද සඳහා, හෝ දෙකක් වැනි විවර්ජනයන්ට පෙර ස්වරයකින් (a හැර) ආරම්භ වන මූල පද සඳහා**
3. **වෙනත් මූල පද කිහිපයක් සඳහා**
:::
## 34.2. නැවත සම්බන්ධ කළ සම්පූර්ණ කාලය (⟪द्वित्वलिट्⟫)

### 34.2.1. මූල පද අවස්ථා

::: grammar-box
**සෑදීම:**

**ශක්තිමත් මූල පදය:** ඒක වචන පරස්මෙයිපද
*   **නැවත සම්බන්ධ කළ ඉහළ අවස්ථාවේ හෝ දිගු ස්වර අවස්ථාවේ මූල පදය + සම්පූර්ණ කාල අවසන්**

**දුර්වල මූල පදය:** අනෙක් සියලුම ආකාර
*   **නැවත සම්බන්ධ කළ පහළ අවස්ථාවේ මූල පදය + සම්පූර්ණ කාල අවසන්**
:::
::: grammar-box
**සාමාන්‍යයෙන් (සම්පූර්ණ කාලයට පිටතින්ද) මූල පද අවස්ථා නොමැති වන්නේ:**
*   **(විවර්ජනය)-විවර්ජනය-දිගු ස්වර-විවර්ජනය**
*   **(විවර්ජනය)-විවර්ජනය-ස්වර-විවර්ජනය-විවර්ජනය**

**සම්පූර්ණ කාලයේදී, මෙම ආකාරවල මූල පද සඳහා ද මූල පද අවස්ථා නොමැත:**
*   **a-විවර්ජනය**
*   **ā-විවර්ජනය**
:::
### 34.2.2. සම්පූර්ණ කාල අවසන්

| :--- | :--- | :--- |

### 34.2.3. සම්බන්ධක ස්වරය -i-

::: grammar-box
**බහු වචනයේ 3. ආත්මනෙපද අවසන් (-re)ට සෑම විටම සම්බන්ධක ස්වරය -i- එක් වේ; බහුතර මූල පද සඳහා අනෙක් විවර්ජනයකින් ආරම්භ වන අවසන් සඳහා.**
:::
### 34.2.4. ස්වරයෙන් ආරම්භ වන මූලධාතු සඳහා පුනරාවර්තනය

::: grammar-box
**ස්වරයෙන් ආරම්භ වන මූලධාතු සඳහා පුනරාවර්තනය කිරීමේ නීති [පාඩම 33](lektion33.md) හි දක්වා ඇත.**

**ස්වරයෙන් ආරම්භ වන මූලධාතු සඳහා පුනරාවර්තන ස්වරය යනු කෙටි මූලධාතු ස්වරයයි.**

**සංස්කෘත වාක්‍ය ඛණ්ඩවල ස්වරයෙන් පසුව එන ස්වරය කෙටි මූලධාතු ස්වරයෙන් පුනරාවර්තනය කෙරේ.**

**ṛ, ṝ, ḷ සහ අවසාන ස්වරයන් -a- මගින් පුනරාවර්තනය කෙරේ.**
:::

### 34.2.5. ස්වරයෙන් ආරම්භ වන මූලධාතු සඳහා පුනරාවර්තනය

::: grammar-box
**1. ආරම්භක a-, ā- ස්වරයන් a- මගින් පුනරාවර්තනය කෙරේ. එමඟින් ā- පෙනී යයි.**
:::
උදාහරණ:

::: grammar-box

:::
::: grammar-box
**2. ආරම්භක i- ස්වරයෙන් යුත් මූලධාතු වල පුනරාවර්තන සිලබය දැඩි ආකාරවල iy-, දුර්වල ආකාරවල i- වේ. මෙම සිලබය මූලධාතු ස්වරය සමඟ එකට එක් වී ī- බවට පත්වේ. ආරම්භක u- ස්වරය සඳහා ද මෙම නීතිය අනුගමනය වේ.**

:::
::: grammar-box
**3. මූල පද a- වෙතින් ආරම්භ වන අතර ස්වරයෙන් පසුව එකට ඇති සංවෘත ව්යංජන දෙකක් හෝ ṛ- මගින් ආරම්භ වන අවස්ථාවලදී, පුනරාවර්තනය කිරීමේ සිල්බය (reduplication syllable) වන්නේ ān-**

## 34.3. පුනරාවර්තනය කළ සම්පූර්ණ කාලයේ (reduplizierten Perfekts) වර්ග

වර්ගීකරණ මූලධර්මය: මූල පද අවස්ථා (Stammabstufung) හි විශේෂත්වයන්:
*   මූල පද අවස්ථාවක් නොමැති සම්පූර්ණ කාලය: වර්ග I
*   මූල පද අවස්ථාවක් සහිත සම්පූර්ණ කාලය: වර්ග II - V
*   නියමිත රීතින්ට යටත් නොවන සම්පූර්ණ කාල ගොඩනැගීම්

## 34.4. සම්පූර්ණ කාල වර්ග I: මූල පද අවස්ථාවක් නොමැති සම්පූර්ණ කාලය

::: grammar-box
**මූල පද අවස්ථාවක් නොමැති සම්පූර්ණ කාල වර්ග I (Perfekt Typ I) ඇත්තේ පහත සඳහන් වර්ගවල මූල පද වලිනි:**
*   **(සංවෘත ව්යංජන)-සංවෘත ව්යංජන-දිග ස්වරය-සංවෘත ව්යංජන**
*   **(සංවෘත ව්යංජන)-සංවෘත ව්යංජන-ස්වරය-සංවෘත ව්යංජන-සංවෘත ව්යංජන**
*   **a-සංවෘත ව්යංජන**
*   **ā-සංවෘත ව්යංජන**
:::
උදාහරණ:
