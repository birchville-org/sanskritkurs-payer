# පාඩම 10

## 10.1. ක්‍රියාපදයේ සක්‍රීය ආකාරය (Passive Voice)

::: grammar-box
**ප්‍රස්තාරය:**
**(කරුණුවා - kartṛ - උපකාරක ක්‍රියාවේදී (tṛtīyā)) - (සෘජු වස්තුව - karman - නාම පදයේ) - ක්‍රියාවේ සක්‍රීය ආකාරය**

උදාහරණයක් ලෙස **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "එක් බ්‍රාහ්මණයෙකු දේවතාවියක් පූජා කරයි" (සරලව: "එක් දේවතාවියෙකු බ්‍රාහ්මණයෙක් විසින් පූජා කරනු ලැබේ.")

මෙම වාක්‍යය **සම්පූර්ණයෙන්ම (!) අර්ථ සමාන** වන්නේ:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
සක්‍රීය ආකාරයේදී කරුණුවා (**kartṛ**) **උපකාරක ක්‍රියාවේදී** (tṛtīyā f. "තෙවන කාසු අගය") සහ සෘජු වස්තුව (**karman** n.) **නාම පදයේ** (prathamā f.) පවතී.
සක්‍රීය ආකාරයේදී කරුණුවා නොසඳහන සක්‍රීය ආකාරයේදී, බොහෝ විට අපුරුෂාර්ථක වේ ("මිනිසා"):
උදාහරණයක් ලෙස **ijyate** = ⟪इज्यते⟫ "මිනිසා පූජා කරයි" (සරලව: "එය පූජාවක් මගින් පූජා කරනු ලැබේ").
:::

::: grammar-box
**අනුරූප සක්‍රීය වාක්‍යයක අවසාන ද්විතීයාව (dvitīyā) අඩංගු වුවද, එය සක්‍රීය ආකාරයේදී නාම පදයට (prathamā) යොදා ගත හැකිය:**

සක්‍රීය වාක්‍යය **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "රාම ගම්බිතයට යයි." සඳහා අනුරූප වන්නේ:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
විකල්පය: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**අකර්මක ක්‍රියාපද (සෘජු වස්තුවක් නොමැති ක්‍රියාපද) බොහෝ විට සක්‍රීය ආකාරයේදී, විශේෂයෙන්ම සැලසුම්කාරී ආරාධනාවලදී:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "මිනිසා ඇතුළු විය යුතුය = කරුණාකර ඔබ ඇතුළු වන්න = තුළට!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "මිනිසා වැඩහිටිය යුතුය = කරුණාකර ඔබ වැඩහිටිය යුතුය = කරුණාකර ඔබ වැඩහිටිය යුතුය"
:::
Sanskrit-පසිව් වාක්‍ය ඛණ්ඩ සෑදීම ඉතා බහුලව දක්නට ලැබේ: පසිව් යනු උදාහරණයක් ලෙස බොහෝ ප්‍රේසන්ස් තනු (present stems) වලට වඩා සෑදීම පහසුය.

::: important
**සාමාන්‍යයෙන් සංස්කෘත පසිව් වාක්‍ය ඛණ්ඩ, ජර්මන් බසින් පසිව් වාක්‍ය ඛණ්ඩයකින් නැවත සෑදිය නොහැක, මන්ද ජර්මන් පසිව් වලට සම්පූර්ණයෙන්ම වෙනස් ශෛලීය කාර්යභාරයක් ඇති බැවිනි.**
:::

## 10.2. උපකරණ කාරකය (tṛtīyā f. = ⟪तृतीया⟫ = "තෙවන කාරක අගය")

::: grammar-box
**උපකරණ කාරකයේ (tṛtīyā) නිත්‍ය අගයන්:**
**ඒක වචනය: -ā**
**බහු වචනය: -bhis**

**නිත්‍ය සෑදීම්:**

| | උපකරණ කාරකය - ඒක වචනය | උපකරණ කාරකය - බහු වචනය |
| :--- | :--- | :--- |
| **-i මත අවසන් වන ස්ත්‍රී ලිංගික:**brśruti:br⟪श्रुति⟫ | **śruty-ā** :br⟪श्रुत्या⟫ | **śruti-bhis** :br⟪श्रुतिभिस्⟫ |
| **-ī මත අවසන් වන ස්ත්‍රී ලිංගික:**brdevī:br⟪देवी⟫ | **devy-ā** :br⟪देव्या⟫ | **devī-bhis** :br⟪देवीभिस्⟫ |
| **-u මත අවසන් වන ස්ත්‍රී ලිංගික:**brdhenu:br⟪धेनु⟫ | **dhenv-ā** :br⟪धेन्वा⟫ | **dhenu-bhis** :br⟪धेनुभिस्⟫ |

**අනිත්‍ය සෑදීම් (ඒක වචනය):**

| | උපකරණ කාරකය - ඒක වචනය | උපකරණ කාරකය - බහු වචනය |
| :--- | :--- | :--- |
| **-i මත අවසන් වන පුල්ලිංගික:**brkavi:br⟪कवि⟫ | **kavi-n-ā** :br⟪कविना⟫ | **kavi-bhis** :br⟪कविभिस्⟫ |
| **-u මත අවසන් වන පුල්ලිංගික:**brpaśu:br⟪पशु⟫ | **paśu-n-ā** :br⟪पशुना⟫ | **paśu-bhis** :br⟪पशुभिस्⟫ |
| **-ā මත අවසන් වන ස්ත්‍රී ලිංගික:**brdevatā:br⟪देवता⟫ | **devat-ay-ā** :br⟪देवतया⟫ | **devatā-bhis** :br⟪देवताभिस्⟫ |

**-a මත අවසන් වන පුල්ලිංගික සහ නපුංසක ලිංගික (ඒක වචනය සහ බහු වචනය දෙකම අනිත්‍ය):**

| | උපකරණ කාරකය - ඒක වචනය | උපකරණ කාරකය - බහු වචනය |

| :--- | :--- | :--- |

### 10.2.1. උපකරණ පදයේ (tṛtīyā = ⟪तृतीया⟫) භාවිතය පිළිබඳව

::: grammar-box
**උපකරණ පදය (tṛtīyā) මූලික වශයෙන් පහත ප්‍රශ්න සඳහා යොදයි:**
**මගින්?**
**කුමක් සමඟ?**
**විසින්?**

**එය යොදයි**
1. **ක්‍රියා පද වාක්‍යවල: ක්‍රියාකාරී (kartṛ) උපකරණ පදයේ**
2. **මෙවලම් හෝ මාර්ගයක් සඳහා, එයින් කිසියම් දෙයක් කරනු ලැබේ**
3. **මාර්ගයක් සඳහා, එයින් කිසියම් දෙයක් කරනු ලැබේ**
4. **සම්බන්ධය, එකතුවීම, සහභාගීත්වය ප්‍රකට කිරීම සඳහා**
5. **පශ්චාත් පද සමඟ "සහ, සමඟ" යන අර්ථයෙන්; උදා: saha = ⟪सह⟫ = "සමඟ"** :brඋදා:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "බ්‍රාහ්මණයා සමඟ"

## 10.6. අභ්‍යාසය

**A) පහත ක්‍රියා පද සඳහා කර්මකාරක රූප සාදන්න (ක්‍රියා පදයේ පරිවර්තනය ද සමඟ):**

1. **sṛjati** (⟪सृजति⟫)
2. **yudhyate** (⟪युध्यते⟫)
3. **bhavanti** (⟪भवन्ति⟫)
4. **yajati** (⟪यजति⟫)
5. **nṛtyati** (⟪नृत्यति⟫)
6. **nayanti** (⟪नयन्ति⟫)
7. **smarati** (⟪स्मरति⟫)
8. **śṛṇvanti** (⟪शृण्वन्ति⟫)
9. **paśyati** (⟪पश्यति⟫) (කර්මකාරකය **dṛś** වෙතින් සාදනු ලැබේ!)
10. **jayanti** (⟪जयन्ति⟫)
11. **kurvate** (⟪कुर्वते⟫)
12. **āpnuvanti** (⟪आप्नुवन्ति⟫)
13. **viśati** (⟪विशति⟫)
14. **khādanti** (⟪खादन्ति⟫)
15. **sunoti** (⟪सुनोति⟫)
16. **gacchati** (⟪गच्छति⟫)
17. **manyante** (⟪मन्यन्ते⟫)
18. **labhante** (⟪लभन्ते⟫)
19. **rakṣanti** (⟪रक्षन्ति⟫)
20. **vadanti** (⟪वदन्ति⟫)
21. **pṛcchanti** (⟪पृच्छन्ति⟫)
22. **tanvanti** (⟪तन्वन्ति⟫) (ආකෘති 2ක්!)

**B) මේ දක්වා උගත් සියලුම නාම පද සඳහා තෘතියා විභක්ති ඒකවචන සහ බහුවචන රූප සාදන්න.**

**C) පහත වාක්‍ය කර්මකාරකයට හරවා පරිවර්තනය කරන්න:**
1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो देवीं यजति⟫)
2. **sādhuḥ svargaṃ gacchati.** (⟪साधुः स्वर्गं गच्छति⟫)
3. **śūdraṃ jayati.** (⟪शूद्रं जयति⟫)
4. **guruḥ phalāni khādati.** (⟪गुरुः फलानि खादति⟫)
5. **gurūñchṛṇoti.** (⟪गुरूञ्छृणोति⟫)
6. **ko 'gniṃ paśyati.** (⟪को ऽग्निं पश्यति⟫)
7. **ayaṃ kavirmantraṃ smarati.** (⟪अयं कविर्मन्त्रं स्मरति⟫)
8. **iyaṃ devī kṣatriyā rakṣati.** (⟪इयं देवी क्षत्रिया रक्षति⟫)
9. **kṣatriyā viṣṇuṃ yajante.** (⟪क्षत्रिया विष्णुं यजन्ते⟫) (ක්‍රම 2ක්)
10. **brāhmaṇo 'gniṃ karoti.** (⟪ब्राह्मणो ऽग्निं करोति⟫)
11. **vaiśyā imaṃ grāmaṃ gacchanti.** (⟪वैश्या इमं ग्रामं गच्छन्ति⟫) (ක්‍රම 2ක්)
12. **ete gurūṃstu śṛṇvanti.** (⟪एते गुरूंस्तु शृण्वन्ति⟫)
13. **sādhuḥ svargamāpnoti.** (⟪साधुः स्वर्गमाप्नोति⟫)
14. **brāhmāṇāḥ somaṃ sunvanti.** (⟪ब्राह्मणाः सोमं सुन्वन्ति⟫)
15. **paśūllabhate.** (⟪पशूल्लभते⟫)
16. **ke yodhāḥ kṣatriyaiḥ saha yudhyante.** (⟪के योधाः क्षत्रियैः सह युध्यन्ते⟫)

**D) සංස්කෘත භාෂාවට පරිවර්තනය කරන්න:**
1. බ්‍රාහ්මණයෙක් වෛශ්‍යයෙකු සමඟ ගමට යයි.
2. ඔහු යාගයක් මඟින් විෂ්ණුට වන්දනා කරයි. (යාගය සඳහා **yajña** යොදන්න!)
3. වේදය ශ්‍රුති ලෙස හැඳින්වේ. (**vad**)
4. රෙදි වියන්නා නූල් අදින්නේය. (ක්‍රම 2ක්)

5. ගුරුවරු අසති. (කර්මකාරක වාක්‍යය)
