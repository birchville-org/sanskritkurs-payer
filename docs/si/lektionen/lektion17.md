# පාඩම 17

## 17.1. දෙවන වර්තමාන කාල පන්තිය (⟪अदादि⟫ = ⟪अद्⟫ ආදී වශයෙන්)

ක්‍රියාපද අවසන් ඒකක මූලධාතුවට සෘජුවම එකතු වේ. මෙහිදී ශබ්ද සන්ධියෙන් (Wortsandhi) ඇතිවන ධ्वනි වෙනස්කම් සැලකිල්ලට ගත යුතුය.

::: grammar-box

දෙවන වර්තමාන කාල පන්තිය තුළ පහත සඳහන් නිර්මාණ ආකාර ඇත:

1. මූලධාතු ව්‍යුත්පන්න අවනතිය සහිත මූලධාතු
*   බොහෝ විට: උසස් මට්ටම - අඩු මට්ටම
*   සමහර මූලධාතු: දිගු මට්ටම - අඩු මට්ටම
2. මූලධාතු ව්‍යුත්පන්න අවනතිය නොමැති මූලධාතු
3. -i/-ī වලින් අවසන් වන ද්විස්වර්ණ මූලධාතු, මූලධාතු ව්‍යුත්පන්න අවනතිය සහිත

:::
## 17.2. මූලධාතු ව්‍යුත්පන්න අවනතිය උසස් මට්ටම - අඩු මට්ටම සහිත දෙවන වර්තමාන කාල පන්තියේ මූලධාතු

## 17.5. ද්විස්වර සාර්ථක මූල -i/-ī අගින් යුක්ත සම්බන්ධිකරණය

මූල කිහිපයක් ආකාර කිහිපයක ද්විස්වර වේ, එනම් ඔවුන්ට සංයෝජක අගයක් පෙර -i (හෝ කිසියම් අගයන්ට පෙර -ī) ඇත. මෙම මූල ස්වදේශික වාක්ය විද්‍යාඥයින් සහ ශබ්දකෝෂ ආදියේ එකමස්වර ලෙස සැලකේ.
