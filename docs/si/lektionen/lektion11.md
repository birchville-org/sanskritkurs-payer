# පාඩම 11

## 11.1. ද්විත්ව අකුසේටීවය

::: grammar-box
**කිසියම් ක්‍රියාපදවලට ද්විත්ව අකුසේටීවයක් (ද්විතියා) පරාවර්තනය කළ හැක: පුද්ගලයා සඳහා වූ අකුසේටීවය සහ ද්‍රව්‍යය සඳහා වූ අකුසේටීවය.**

**ඊට ඇතුළත් වන්නේ:**
**කතා කිරීමේ ක්‍රියාපද:** කෙනෙකුට (අකුසේටීවය) යමක් (අකුසේටීවය) පිළිබඳව කතා කිරීම; කෙනෙකුට (අකුසේටීවය) යමක් (අකුසේටීවය) කීම
**ප්‍රශ්න කිරීමේ ක්‍රියාපද:** කෙනෙකුගෙන් (අකුසේටීවය) යමක් පිළිබඳව (අකුසේටීවය) විමසීම
**උගන්වා දීමේ ක්‍රියාපද:** කෙනෙකුට (අකුසේටීවය) යමක් උගන්වා දීම (අකුසේටීවය)
වචන ලැයිස්තු තුළ සටහන් කර ඇති අනෙකුත් ක්‍රියාපද කිහිපයක්

**මෙවැනි ව්‍යුහයක් පාසීවයට (passive voice) හැරවූ විට, පුද්ගලයා (ප්‍රශ්න කරන්නේ වැනි) නොමිනේටීවයට (ප්‍රථමා) තබන අතර, ද්‍රව්‍යය (ප්‍රශ්න කරන්නේ වැනි) අකුසේටීවය තුළම පවතී.**

උදා: **rāmo brāhmaṇaṃ dharmaṃ pṛcchati** = ⟪रामो ब्राह्मणं धर्मं पृच्छति⟫ = "රාමු බ්‍රහ්මණයාගෙන් ධර්මය පිළිබඳව විමසයි."
» පාසීව: **rāmeṇa brāhmaṇo dharmaṃ pṛcchyate** = ⟪रामेण ब्राह्मणो धर्मं पृच्छयते⟫

**මෙම නියමය අදාළ වන්නේ පුද්ගලයා සහ ද්‍රව්‍ය යන දෙකම වස්තුවක් ලෙස පවතින විට පමණි. ද්‍රව්‍යය එකම වස්තුවක් නම්, එය පාසීව වාක්‍ය මූලික රටාව අනුව නොමිනේටීවය (ප්‍රථමා) තුළ පවතී:**

උදා: **rāmo dharmaṃ pṛcchati** = ⟪रामो धर्मं पृच्छति⟫ = "රාමු ධර්මය පිළිබඳව විමසයි."
» පාසීව: **rāmeṇa dharmaḥ pṛcchyate** = ⟪रामेण धर्मः पृच्छयते⟫
:::

## 11.2. වචන ලැයිස්තුව

**පහත සඳහන් වචන ඉගෙන ගන්න:**

**iti** ⟪इति⟫ : මෙසේ
සිතුවමක්, ආශාවක්, ප්‍රකාශයක්, යොමුවක් ඉදිරිපත් කිරීමෙන් පසු සටහන් ලෙස (") තබයි.
උදා: **sādhavaḥ svargaṃ gacchantīti brāhmaṇā vadanti** "බ්‍රහ්මණයෝ කියති: 'සාධුන් ස්වර්ගයට යයි'" = "බ්‍රහ්මණයෝ සාධුන් ස්වර්ගයට යන බව කියති".
සංස්කෘතයේ වක්‍ර උච්චාරණයක් නොමැත; **iti** සහිත ගොඩනැගීම් ජර්මානු බසින් වක්‍ර උච්චාරණයකින් නැවත සටහන් කළ යුතු විය හැක.
**... (යොමුව) ... iti śrutiḥ** = "වේදය මෙසේ කියයි".
බොහෝ විට **iti** ට පසු සිතීමේ ක්‍රියාපදයක් එකතු විය හැක: "සිතමින්: '...' කරයි". ජර්මානු බසට සුවිශේෂී ලෙස නැවත සටහන් කිරීම (උදා: "ඔහුට දිවසක් ඇති බැවින්, ඔහු යයි...").

**evam** ⟪एवम्⟫ : එසේ (විශේෂණයක් ලෙස, උදාහරණයක් ලෙස **evaṃ jayati** "එසේ ඔහු දිනයි").
**na** ⟪न⟫ : නො
වචන තනිව (එය ඉහළින්ම පවතී: **na sādhuḥ** "නොහොත් හොඳ") හෝ සම්පූර්ණ වාක්‍ය (වාක්‍ය ආරම්භයේදී හෝ ක්‍රියාපදයට ඉහළින්ම පවතී) විනිශ්චය කරයි.

**putra** පු. ⟪पुत्र⟫ : පුත්‍රයා (ඉන්දියාවේ, පූර්වජයින් සඳහා බලිපූජාවන් ඉටු කළ හැකි පුත්‍රයෙකු බිහි කිරීම අවශ්‍ය විය.)
**dharma** පු. ⟪धर्म⟫ : ("නියත වූ දේ", එනම්.) අධිකරණය, නීතිය, සිරිත්, චරිතය.
ස්වාභාවික නීතිය/නෛතික නීතියට වඩාත් ගැලපේ. සෑම කෙනෙකුටම **varṇa** හා **āśrama** (ජීවන අදියර) අනුව තමන්ගේ වගකීම් (**svadharma**) ඇත.
**adharma** පු. ⟪अधर्म⟫ : අධර්මය (**dharma** ට ප්‍රතිවිරුද්ධ).
**iṣ** 6 ප (icchati) ⟪इष् इच्छति⟫ : කැමති වන්න (**iṣ-ccha-ti**).

**සමහර නාම ව්‍යුත්පන්න:**

**vad** 1 ප ⟪वद्⟫ : කියන්න
**vāda** පු. ⟪वाद⟫ : නිකේතනය, ප්‍රකාශය, වචන
**vadana** නපු. ⟪वदन⟫ : කතා කිරීම; කතා උපකරණය: මුඛය, මුහුණ

**prach** 6 ප ⟪प्रच्छ्⟫ : විමසන්න
**praśna** පු. ⟪प्रश्न⟫ : ප්‍රශ්නය (**-na** අනුප්‍රේරකය **yaj-ña** මෙන්)

**iṣṭi** ස්ත්‍රී. ⟪इष्टि⟫ : කැමති වීම (**iṣ** + **-ti**)


## 11.3. අභ්‍යාසය

**අ) පහත සඳහන් වාක්‍ය අනුවදින් ඉංග්‍රීසි බසට පරිවර්තනය කරන්න:**

1. ⟪ऋषिः सत्यं वदति⟫ |
2. ⟪ब्राह्मणः पुत्रमिच्छति⟫ |
3. ⟪साधुः स्वर्गं गच्छति⟫ |
4. ⟪ब्राह्मणो ऽनृतं न वदतीति स्मृतिः⟫ |
5. ⟪क्षत्रियो ब्राह्मणं धर्मं पृच्छति⟫ |
6. ⟪एवं ब्राह्मणो यज्ञेन देवं यजति⟫ |
7. ⟪पुत्रः पापं करोतीति वैश्या मन्यते⟫ |
8. ⟪क्षत्रियः क्षत्रियेण सह युध्यते⟫
9. ⟪अधर्मो ऽनृतमिति पुत्रः पापं न करोति⟫ | |
10. ⟪अयं क्षत्रियो धर्मं रक्षति⟫ | |
11. ⟪को ऽग्निं यजते⟫ | |
12. ⟪स श्रावको बुद्धं धर्मं पृच्छति⟫ ||

**B) Setzen Sie die Sätze von A) in Passivkonstruktion.** -> **A හි වාක්‍ය ප්‍රතිවේදන ආකාරයට (Passive voice) පත් කරන්න.**

**C) Setzen Sie in den Sätzen A), wo es sinnvoll ist, Subjekt, Objekt und Prädikat in den Plural.** -> **A හි වාක්‍යවල, එය අර්ථවත් නම්, කර්තෘ, කාරක සහ ව්‍යාකරණික පද බහුවචනයට (Plural) පත් කරන්න.**

**D) Bilden Sie zu den nach C) gebildeten Sätzen die Passivkonstruktion.** -> **C හිදී සකස් කරන ලද වාක්‍යවලට ප්‍රතිවේදන ආකාරය (Passive voice) සාදන්න.**

## 11.4. නැවත සිහිපත් කිරීමේ පුර්වාභ්‍යාසය

**A) ප්‍රතිවේදන ආකාර (Passive constructions) සමඟ සංස්කෘතයට පරිවර්තනය කරන්න:**
1. Vaiśyafrauen fragen Brahmanen nach dem Dharma. -> 1. වෛශ්‍ය කාන්තාවෝ ධර්මය පිළිබඳව බ්‍රාහ්මණයන්ගෙන් විමසති.
2. Der Lehrer spricht ein Mantra. -> 2. ගුරුවරයා මන්ත්‍රයක් උච්ඡාරණය කරයි.
3. Heilige Frauen gelangen in einen Himmel. -> 3. පවිත්‍ර කාන්තාවෝ ස්වර්ගයකට පැමිණෙති.
4. Ein vedischer Weiser tut nichts Böses. -> 4. වේද ඥානවන්තයෙක් කිසිදු අකුසලයක් නොකරයි.
5. Brahmanen verehren als Opferpriester die Göttin mit Opfern. -> 5. බ්‍රාහ්මණයෝ පූජකවරුන් ලෙස බලිපූජා සමඟ දේවියට පුද කරති.
6. Die Śūdrafrau geht ins Dorf. -> 6. ශූද්‍ර කාන්තාව ගමට යයි.
7. Wer sieht die Wahrheit? -> 7. සත්‍යය කවුරුන් දකීද?

**B)** -> **B)**
1. Geben Sie mit einem Dvandva die Aufgaben aller Zweimalgeborenen an. Lösen Sie das Kompositum in Sanskrit auf. -> 1. ද්වන්ද සංඛ්‍යාතයක් (Dvandva) භාවිතා කර සියලු ද්විජයන්ගේ (Zweimalgeborenen) කාර්යයන් සඳහන් කරන්න. එම සංස්කෘත සමාසය විභජනය කරන්න.
2. Geben Sie mit einem Dvandva die Aufgaben der Vaiśyas an. Lösen Sie das Kompositum in Sanskrit auf. -> 2. ද්වන්ද සංඛ්‍යාතයක් (Dvandva) භාවිතා කර වෛශ්‍යයන්ගේ කාර්යයන් සඳහන් කරන්න. එම සංස්කෘත සමාසය විභජනය කරන්න.

**C) Übersetzen Sie:** -> **C) පරිවර්තනය කරන්න:**

1. ⟪श्रवणेन श्रूयते⟫ | | -> 1. ⟪श्रवणेन श्रूयते⟫ | |
2. ⟪कर्षर्कैः कृष्यते⟫ | | -> 2. ⟪कर्षर्कैः कृष्यते⟫ | |
3. ⟪श्रावकेणेश्वरो नेज्यते⟫ | | -> 3. ⟪श्रावकेणेश्वरो नेज्यते⟫ | |
4. ⟪रक्षिक्या गुरू रक्ष्यते⟫ | | -> 4. ⟪रक्षिक्या गुरू रक्ष्यते⟫ | |
5. ⟪ब्राह्मणेनानृतं नोद्यते⟫ | | -> 5. ⟪ब्राह्मणेनानृतं नोद्यते⟫ | |
6. ⟪शूद्रेतरा⟫ | | -> 6. ⟪शूद्रेतरा⟫ | |
7. ⟪शिक्षा कल्पो व्याकरणं निरुक्तं छन्दो ज्योतिषमङ्गानि⟫ | | -> 7. ⟪शिक्षा कल्पो व्याकरणं निरुक्तं छन्दो ज्योतिषमङ्गानि⟫ | |
8. ⟪आन्वीक्षिकीत्रयीवार्त्तादण्डनीतयो विद्याः⟫ || -> 8. ⟪आन्वीक्षिकीत्रयीवार्त्तादण्डनीतयो विद्याः⟫ ||

**D) Übersetzen Sie und setzen Sie in Sanskrit Agens, Objekt und Verb in den Plural:** -> **D) පරිවර්තනය කර සංස්කෘතයේ කාරක (Agens), කාරක (Objekt) සහ ක්‍රියාපදය බහුවචනයට (Plural) පත් කරන්න:**

1. ⟪फलमश्नुते⟫ | | -> 1. ⟪फलमश्नुते⟫ | |
2. ⟪गुरुणा सत्यमुद्यते⟫ | | -> 2. ⟪गुरुणा सत्यमुद्यते⟫ | |
3. ⟪वैश्यः पशुं लभते⟫ | | -> 3. ⟪वैश्यः पशुं लभते⟫ | |
4. ⟪पुत्रः पुण्यं करोति⟫ || -> 4. ⟪पुत्रः पुण्यं करोति⟫ ||

**E) ප්‍රකාර C) 1-5 හි වාක්‍ය සක්‍රිය ආකාරවලට පරිවර්තනය කරන්න.**
