# පුහුණුව 53

Lektion 53 සඳහා වූ පුහුණුව, ඉදිරියේ Lektion වලින් ඉගෙන ගත් සියලු ශ්ලෝකවල මෙතරි විශ්ලේෂණය (ශ්ලෝක රටාව තීරණය කිරීම) අඩංගු වේ.

මෙය සමස්ත නැවත පුහුණුවක් සහ විශ්ලේෂණ කාර්යයක් බැවින්, සම්ප්‍රදායික අර්ථයෙන් වෙනම විසඳුම් යතුරක් නොමැත. විසඳුම් Lektion 53 හි ඉගන්වන ලද නීති දැනටමත් ප්‍රසිද්ධ වූ උපුටා දැක්වීම් මත යෙදීමෙන් ලැබේ.
