# පාඩම 30

## 30.1. නව වර්තමාන පන්තිය (⟪क्र्यादि⟫ = "⟪क्री⟫ ආදිය")

::: grammar-box
**නිර්මාණය:**

*   ප්‍රබල මූලිකය: ගැඹුරු පඩියේ මූලධාතුව + -nā-

*   දුර්වල මූලිකය:

*   ව්‍යංජනයට පෙර: ගැඹුරු පඩියේ මූලධාතුව + -nī-

*   ස්වරයකට පෙර: ගැඹුරු පඩියේ මූලධාතුව + -n-
:::
උදාහරණය:

::: indent
⟪क्री⟫ 9U "මිලට ගැනීම"
:::
::: grammar-box

| |ඒක වචනය:br⟪एकवचन⟫|බහු වචනය:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3 වන පුද්ගලයා:brපරස්මෛපදය**|⟪क्रीणाति⟫:br(krī + nā + ti)|⟪क्रीणन्ति⟫:br(krī + n + anti)|
|**3 වන පුද්ගලයා:brආත්මනේපදය**|⟪क्रीणीते⟫:br(krī + nī + te)|⟪क्रीणते⟫:br(krī + n + ate)|

:::
මෙම වර්තමාන පන්තියේදී විශේෂයෙන් සලකා බැලිය යුත්තේ ⟪ज्ञा⟫ 9U "දැන ගැනීම, දැන සිටීම" මූලධාතුව වෙතින් වර්තමාන මූලිකය නිර්මාණය කිරීමයි:

::: grammar-box

| |ඒක වචනය:br⟪एकवचन⟫|බහු වචනය:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3 වන පුද්ගලයා:brපරස්මෛපදය**|⟪जानाति⟫:br(jā-nā-ti)|⟪जानन्ति⟫:br(jā-n-anti)|
|**3 වන පුද්ගලයා:brආත්මනේපදය**|⟪जानीते⟫:br(jā-nī-te)|⟪जानते⟫:br(jā-n-ate)|

:::
⟪जा⟫ ආකෘතිය, එය ⟪ज्ञा⟫ හි වර්තමාන මූලිකයට පදනම් වී ඇති අතර, එය -ā (ගැඹුරු පඩිය) -nā (උසස් පඩිය) යන ආප්ත ශ්‍රේණියක් මගින් හෝ *jñā-nā-ti වෙතින් විසංයුක්ත කිරීම මගින් පැහැදිලි කළ හැක.

දීර්ඝ ස්වරයෙන් අවසන් වන මූලධාතුව කිහිපයක් 9 වන පන්තියේ වර්තමාන මූලික ප්‍රත්‍යයට පෙර තම ස්වර කෙටි කරයි:

උදාහරණය:

::: indent
⟪पू⟫ 9U "පිරිසිදු කිරීම"
:::
::: grammar-box

| |ඒක වචනය:br⟪एकवचन⟫|බහු වචනය:br⟪बहुवचन⟫|
| :--- | :--- | :--- |

|**3 වන පුද්ගලයා:brආත්මනේපදය**|⟪पुनीते⟫:br(pu-nī-te)|⟪पुनते⟫:br(pu-n-ate)|

## 30.2. ඔප්ටේටිවය (⟪लिङ्⟫) භාවිතය

ඔප්ටේටිවය භාවිතා වන්නේ:

::: grammar-box
**1. පහත සඳහන් දේ හැඟවීමට**

*   **අපේක්ෂාවකි**
*   **ඉල්ලීමකි**
*   **මෘදු කරන ලද උපදෙසකි**

**(මෙහිදී ඔප්ටේටිවය - ⟪लिङ्⟫ - ඉම්පෙරේටිවය සමඟ ⟪लोट्⟫ - ගැටෙයි)**
:::
උදාහරණයක්:

::: indent
⟪दासो ग्राममागच्छेत्⟫ = "ගොවිතැන්කරු ගමට පැමිණිය යුතුය"
:::
::: grammar-box
**2. යමක්**

*   **සම්භාව්‍ය ලෙස**
*   **සම්භාව්‍ය ලෙස**
*   **අනුමානයක් ලෙස**

**පෙන්විය යුතුය.**
:::
උදාහරණයක්:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं न शृणुयात्⟫ = "ඔහු ගමින් පිටවූයේ නම්, ඔහු ගුරුවරයා අසන්නට නොලැබේ"
:::
::: grammar-box
**3. ඔප්ටේටිවය සහිත විශේෂණ වාක්‍ය තුළ "කෙනෙක් නම් ..." යන අර්ථය ඇත.**
:::
උදාහරණයක්:

::: indent
⟪यो नृतं वदेत्स नरकं पतेत्⟫ = "කෙනෙක් අසත්‍ය කියන්නට නම්, ඔහු නරකට වැටේ = කෙනෙක් අසත්‍ය කියන්නේ නම්, ඔහු නරකට වැටේ"
:::
## 30.3. තෘතීය පුරුෂ ඒක වචන සහ බහුවචනයේ ද්විතීයික අන්තය

ඔප්ටේටිවය (⟪लिङ्⟫), අයිම්පෙර්ෆෙක්ට් (⟪लङ्⟫), අයෝරිස්ට් (⟪लुङ्⟫), ප්‍රෙකටිව් (⟪आशिर्लिङ्⟫) සහ කොන්ඩිෂනල් යනු එසේ හැඳින්වෙන ද්විතීයික අන්තය සහිත වේ:

::: grammar-box

| |තෘතීය පුරුෂ ඒක වචන|තෘතීය පුරුෂ බහුවචනය|
| :--- | :--- | :--- |
|**ප්‍රසාරණය කාලීන සත්වපද**|**-t**|අතමේධ්‍ය වර්ග: **-an** හෝ **-ur** :brඔප්ටේටිවය: **-ur**|
|**ආත්මනේපද**|**-ta**|අතමේධ්‍ය වර්ග: **-ata** (*nta) සිට:brඔප්ටේටිවය: **-ran**|

:::
## 30.4. ඔප්ටතිව වර්තමාන කාලය සෑදීම (⟪लिङ्⟫)

### 30.4.1. තේමාත්මක වර්තමාන කණ්ඩායම්

::: grammar-box
**ව්‍යංජන අකුරින් ආරම්භ වන ප්‍රත්‍යයන්ට පෙර:**

**වර්තමාන මූලය + -i- (-a- සමඟ එකතු වී -e- බවට පත්වේ) + ද්විතියක ප්‍රත්‍යය**

**ස්වර අකුරින් ආරම්භ වන ප්‍රත්‍යයන්ට පෙර:**

**වර්තමාන මූලය + -i- (» -e-) + -y- + ද්විතියක ප්‍රත්‍යය**
