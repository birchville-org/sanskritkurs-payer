# පාඩම 27

## 27.1. ලොකටිවය භාවිතා කිරීම (⟪सप्तमी⟫ f. = "හත්වන විභක්ති පරිච්ඡේදය")

::: grammar-box

**ලොකටිවය (⟪सप्तमी⟫) පහත ප්‍රශ්න වලට සිටී:**
*   **මොහොතේද?**
*   **කවදාද?**
*   **යම් තත්ත්ව යටතේද?**
*   **මොනවා සම්බන්ධයෙන්ද?**

:::
::: grammar-box

**1. ලොකටිවය (⟪सप्तमी⟫) "මොහොතේද?" යන ප්‍රශ්නයට අනුව, කාරකය (⟪कर्ता⟫) හෝ කර්තෘවයක් වන දේ සිටින අවකාශය හෝ ක්‍රියාවම සිදුවන තැන පෙන්වයි.**

> ⟪नगरे वसति⟫ = "ඔහු නගරයේ වාසය කරයි"

:::

![](/images/lekt2701.webp)

::: grammar-box

**2. ලොකටිවය "කවදාද?" යන ප්‍රශ්නයට අනුව කාලය හෝ බාහිර තත්ත්ව පෙන්වයි:**

> ⟪तस्मिन्काले⟫ = "එම කාලයේදී, එම සමයේ"

**මෙහිට අදාළ වන්නේ Locativus Absolutus ලෙස හැඳින්වෙන දේය:**

**පුද්ගලයෙකු හෝ වස්තුවක් සිටින කාලය හෝ තත්ත්ව යටතේ - වෙනත් පුද්ගලයෙකු හෝ වස්තුවක් ක්‍රියාවක් සිදු කරන විට හෝ යම් තත්ත්වයක පවතින විට, එම පළමු පුද්ගලයා හෝ වස්තුව නිරූපණය කරන පදය එම පදය තවදුරටත් විස්තර කරන පදය (බොහෝ විට ක්‍රියාපද නිකේතනයක් වන) සමඟ ලොකටිවය (⟪सप्तमी⟫) තුළ පැමිණේ:**

> ⟪एवं गच्छति काले⟫ = "කාලය ගත වන විට..."
\>
> ⟪तस्मिन्गते⟫ = "ඔහු ගිය විට..."

**කාරකය (⟪कर्ता⟫) සෑම විටම පැහැදිලිව නොපෙන්වා තබා ගත හැකිය:**

> ⟪एवं सति⟫ = "මෙසේ සිදුවන විට"

**Locativus Absolutus යන්න සන්දර්භය අනුව "විට" (උදා: ක්‍රියාපද නිකේතනය), "පසු", "විට" (උදා: PPP), "මන්ද", "කෙරෙහි", "වුවද", "යම් විට" ආදී ලෙස පරිවර්තනය කළ යුතුය.**

**සටහන්: ආබ්සොලියුටිවයේදී, ආබ්සොලියුටිවයේ කාරකය සහ ප්‍රධාන වාක්‍යයේ කාරකය එකම විය යුතු අතර, ලොකටිවස් ආබ්සොලියුටස් (Locativus absolutus) සඳහා ලොකටිවස් ආබ්සොලියුටස් හි කාරකය සහ ප්‍රධාන ක්‍රියාවල කාරකය වෙනස් විය යුතුය.**

**3. ලොකටිව් "මොනවා සම්බන්ධයෙන්?" යන ප්‍රශ්නයට හෝ ඊට සමාන දේවලට පිළිතුරු ලෙසද යොදයි:**

> ⟪अस्ति तस्य पुत्रे स्नेहः⟫ = "තම පුත්‍රයා සම්බන්ධයෙන් ඔහුට ආදරය ඇත" (සැබෑ අර්ථය: "පුත්‍රයා සම්බන්ධයෙන් ඔහු තුළ ආදරය ඇත")

> ⟪भू सत्तायाम्⟫ = "⟪भू⟫ මූලධාතුව 'සත්-තා' (sat-tā) අර්ථයෙන්"

## 27.2. ලොකටිව් නිර්මාණය (⟪सप्तमी⟫)

::: grammar-box

**ලොකටිව් හි නියමිත අන්තයන් (⟪सप्तमी⟫) වන්නේ:**
*   **ඒකවචනය: -i**
*   **බහුවචනය: -su**

**-su ට පෙර සිදුවන ශබ්ද වෙනස්වීම් සහ -su ට -ṣu බවට පත්වීම (Cerebralisation) සිදුවිය හැකි බව සලකන්න!**
