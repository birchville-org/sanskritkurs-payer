## 44.2. වචන සන්ධිය පිළිබඳව

ව්‍යංජන මගින් අවසන් වන වර්තමාන පද මූලයන් සඳහා, දැනටමත් සාකච්ඡා කළ වචන සන්ධි නීති අනුගමනය කළ යුතුය.

මීට අමතරව, පහත සඳහන් වචන සන්ධි නීති ද යෙදේ.

(මෙහි අයත් සියලු ශබ්ද විපර්යාසවල විස්තෘත එකතු කිරීම Kielhorn, Grammar පිටු 76f. හි ඇත.)

### 44.2.1. dh- සඳහා වචන සන්ධිය පිළිබඳව

::: grammar-box

1. **ආසප්තයක් ආසප්තයකට පෙර අනුරූප නොආසප්තය මගින් ආදේශ කෙරේ:**
උදා: ⟪रुध्⟫ 7U: ⟪रुन्ध्⟫ + ⟪ध्वे⟫ » ⟪रुन्द्ध्वे⟫ (run**ddh**ve)
2. **-h + dh- » -gdh-**
උදා: ⟪दुह्⟫ 2U: ⟪दुह्⟫ + ⟪ध्वे⟫ » ⟪धुग्ध्वे⟫ (dhu**gdh**ve)
3. **-ṣ + dh- » -ḍḍh-** (මෙම නියමය ව්‍යාකරණය සඳහා පමණක් අදාළ වේ!)
උදා: ⟪द्विष्⟫ 2U: ⟪द्विष्⟫ + ⟪ध्वे⟫ » ⟪द्विड्ढ्वे⟫ (dvi**ḍḍh**ve)
4. **-s + dh- » -dh-** (-s හි අතුරුදහන් වීම)
උදා: ⟪आस्⟫ 2Ā: ⟪आस्⟫ + ⟪ध्वे⟫ » ⟪आध्वे⟫ (ādhve)

:::

### 44.2.2. s- සඳහා වචන සන්ධිය පිළිබඳව

::: grammar-box

1. **-s + s- » -ts- හෝ (විකල්ප නොවේ!) -ss-** (2 වන වර්තමාන පන්තියේ මෙසේය)
උදාහරණ:
* ⟪वस्⟫ 1P: අනාගතය: ⟪वस्⟫ + ⟪स्य⟫ + ⟪ति⟫ » ⟪वत्स्यति⟫ (va**ts**yati)
* ⟪वस्⟫ 2Ā: ⟪वस्⟫ + ⟪से⟫ » ⟪वस्से⟫ (va**ss**e)
2. **-ṣ + s- » -kṣ-**
උදා: ⟪द्विष्⟫ 2U: ⟪द्वेष्⟫ + ⟪सि⟫ » ⟪द्वेक्षि⟫ (dve**kṣ**i)

:::
