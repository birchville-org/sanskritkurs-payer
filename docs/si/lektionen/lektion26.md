# පාඩම 26

## 26.1. වචනය තුළ -s- සඳහා මූලික කිරීමේ නියමය

::: grammar-box
**-s-** යනු **k, r, l** හෝ **ස්වරයක්** — **a, ā** හැර — ආසන්න වශයෙන් හෝ ⟪अनुस्वार⟫ හෝ ⟪विसर्ग⟫ මගින් වෙන්වූ පසුපස සිටියදී, **ṛ, r** හැර වෙනත් ශබ්දයක් පසුපස සිටියහොත් **-ṣ-** මගින් ආදේශ කරනු ලැබේ.

මෙම සන්ධියට **⟪दुस्⟫-** ආශ්‍රිතව නිර්ඝෝෂ ගුට්ට සහ ලාබියල් ශබ්දවලින් පසුපස කොම්පෝසිටාවක දී අනුගමනය වේ.
:::
*උදාහරණ:*
::: indent
⟪तेषाम्⟫ (මූලාශ්‍රය: *te-sām*)

නමුත්: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. වචනය තුළ දන්ත ශබ්ද සඳහා මූලික කිරීමේ නියමය

::: grammar-box
ප්‍රතිලෝම ශබ්ද (**-ṣ-** ඇතුළුව) පසුපස දන්ත ව්‍යවහාරක ශබ්ද පිළිතුරු දන්ත ව්‍යවහාරක ශබ්ද මගින් ආදේශ කරනු ලැබේ:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** පෙර **i** නිසා, **ṭh** ඉන්පසු පැමිණෙන **ṣ** නිසා)*
:::
## 26.3. ප්‍රතිලෝම, ගුට්ට, ṣ, h + -s සඳහා වචන සන්ධිය

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

උදාහරණ පහත බලන්න
:::

## 26.5. වචන සන්ධිය -m, -n ඝෝෂ හට පෙර

## 26.6. සරල අනාගත කාලය භාවිතය (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**සරල අනාගත කාලය (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) පහත දැක්වෙන ආකාරයෙන් ප්‍රකාශ කරයි:**

**අනාගතය**
**ආශ්‍රිත හෝ අපේක්ෂිත ක්‍රියාව ("මම යන්නෙමි", "මට යාමේ අපේක්ෂාව ඇත")**
**අපේක්ෂාව ("එසේ සිදුවනු ඇත")**
**ආශාව**
**අනුමානය**
**සම්භාවිතාව**
**කතුවරයාගේ මතය**
**ආදේශය**

> **අනාගත කාලය සමහර අවස්ථාවලදී ඔප්ටේටිවය (සාමාන්‍ය කාලය) සමඟ තරඟ කරයි (පසුව බලන්න).**

## 26.7. සරල අනාගත කාලය ගොඩනැගීම (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**සරල අනාගත කාලය:**

:::
::: indent
**අනාගත මූල පදය + ප්‍රථමික අවසානය**
:::
::: grammar-box
**අනාගත මූල පදය:**

:::
::: indent
**(සාමාන්‍යයෙන්) උච්ච මට්ටම් වර්ගය + -sya**  
**හෝ**  
**(සාමාන්‍යයෙන්) උච්ච මට්ටම් වර්ගය + -i- + -sya (= - iṣya)**
:::
**මූල පදයක් අනාගත මූල පදයේ කුමන ආකාරයක් ගන්නා ද යන්න මූල පද ස්වරූපයන් සමඟ ඉගෙන ගත යුතුය!**  
**සාමාන්‍යයෙන් මූල පද ස්වරූපය සහ අනාගත කාලයේ සම්බන්ධක ස්වරය අනුප්‍රාසයට ගැලපේ.**  
**කිහිප මූල පදයක් අනාගත කාලය සම්බන්ධක -i- සහිතව හෝ නැතිව ගොඩනගා ගත හැක.**
