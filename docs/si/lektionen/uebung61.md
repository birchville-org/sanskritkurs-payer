# පුහුණුව 61

61 වන ඉගැන්වීම සංස්කෘත පාඨමාලාවේ අවසානය සපුරයි, එය තවදුරටත් ලිඛිත පුහුණුවන් අඩංගු නොවේ. 

මූලික නාම, පරිභාෂිත අනාගත කාලය සහ නිර්දේශිත නාම පිළිබඳ අධ්‍යනය සමඟ, සංස්කෘත මුල් පාඨ කියවීම සඳහා මූලික කරුණු පදනම් වී ඇත. මෙම පාඨමාලාව ගණේශයන්ට (⟪श्रीगणनाथ⟫) සාම්ප්‍රදායිකව කරනු ලබන ආහ්වානය සමඟ අවසන් වේ, එය පාඩම් පොතෙන් ස්වාධීනව කියවීමට යන මාර්ගයේ සංකේතය වේ.
