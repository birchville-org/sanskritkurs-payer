## 58.6. Аорист 5: iṣ-аорист

::: grammar-box
**iṣ-аорист утворюється від усіх seṭ-коренів, для яких явно не вказано виключно іншу форму аориста.**

**Утворення:**

**Авґмент + корінь + i + s + безтематичні вторинні закінчення**

**!!!** 2.os. та 3.os. формуються на **-**īs або -īt з **!!!** (Це виникло внаслідок перенесення імперфекту від коренів типу ⟪अब्रवीत्⟫; отже, це фактично форми кореневого аориста).
:::
Отже, суфікс основи та закінчення iṣ-аористу мають такий вигляд:

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | **-iṣam** | **-iṣma** | **-iṣi** | **-iṣmahi** |
| **2. ⟪द्वितीयः⟫** | **-īs** | **-iṣṭa** | **-iṣṭhās** | **-**idhvam / :br-iḍhvam:br(за бажанням після -h або напівголосного) |
| **3. ⟪प्रथमः⟫** | **-īt** | **-iṣur** | **-iṣṭa** | **-iṣata** |

:::
::: grammar-box
**Форма кореня:**

*   **Корені з коротким голосним перед простим приголосним: сильний ступінь у P та Ā**  
Приклади:  
⟪बुध्⟫ 1U: 1.os.P ⟪अबोधिषम् कॢप्⟫ 1Ā: 1.os.Ā ⟪अकल्पिषि⟫

*   **Корені з голосним на кінці:**
*   **P: подовжений ступінь**
*   **Ā: посилений ступінь**

Приклади:  
⟪पू⟫ 9U: 1.os.P ⟪अपाविषम्⟫ ; 1. os.Ā ⟪अपविषि⟫

*   **Корені на -ar., -al та ⟪वद्⟫ 1P "казати", ⟪व्रज्⟫ 1P "відходити": P: подовжений ступінь**  
Приклади:  
⟪चर्⟫ 1P: 1.os.P ⟪अचारिषम् वद्⟫ 1P: 1.os.P ⟪अवादिषम्⟫

*   **Інші корені форми (конс.-)конс.-a-конс.: у P за бажанням подовжений ступінь (не стосується коренів на -h, -m, -y та кількох інших коренів)**  
Приклад:  
⟪तन्⟫ 8U: 1.os.P ⟪अतनिषम्⟫ / ⟪अतानिषम्⟫  
але:  
⟪क्रम्⟫ 1U: 1.os.P ⟪अक्रमिषम्⟫
:::
