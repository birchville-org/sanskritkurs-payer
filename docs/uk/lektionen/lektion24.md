

# Lektion 24

## 24.1. Der Давальний відмінок (चतुर्थी = "vierte Kasusendung")

:::: grammar-box
**1. Щоб виразити мету або намір ("щоб") дії, замість інфінітива (तुमुन्) можна також вживати іменник із суфіксом кріт (kṛt), що позначає дію або стан, у давині (चतुर्थी = "четверта відмінка").**

Приклад:

замість:

::: indent
रामो गुरुवचनं श्रोतुं गतः ।
:::

можна також сказати:

::: indent
रामो गुरुवचनस्य श्रवणाय गतः ।

або:

रामो गुरुवचनश्रवणाय गतः ।
:::

= "Рама пішов, щоб почути слова вчителя."
::::

::: media
![](/images/lekt2404.jpg)
Рис.: बाला गुरुश्रवणाय गताः
(Джерело зображення: [Деталі](/licenses#lekt2404))
:::

:::: grammar-box
**2. Давін (चतुर्थी) може також позначати об'єкт інфінітива мети, який потрібно доповнити:**

Приклад:

::: indent
फलेभ्यो ग्रामं गच्छति = "Він йде до села з метою плодів = Він йде до села, щоб зібрати плоди."
:::

**Аналогічно давін (चतुर्थी) позначає мету речі або дії:**

Приклад:

::: indent
यज्ञायान्नम् = "Їжа з метою жертвоприношення = Їжа для жертвоприношення"
:::
::::

::: media
![](/images/lekt2401.jpg)
Рис.: यज्ञायान्नम्
(Джерело зображення: [Деталі](/licenses#lekt2401))
:::

:::: grammar-box
**3. Давін (चतुर्थी) також позначає особу або річ, для яких призначено об'єкт дії (непрямий об'єкт; питання: кому?). (Зверніть увагу на дієслова з подвійним вінальним відмінком (द्वितीया)! )**

Приклад:

::: indent
रामाय फलं ददाति = "Він дає Рама фрукт." (корінь दा 3. клас теперішнього часу)
:::
::::

::: media
![](/images/lekt2402.jpg)
Рис.: बाला बालाय रक्षबन्धनं ददाति
(Джерело зображення: [Деталі](/licenses#lekt2402))
:::

:::: grammar-box
**4. Давін стоїть при деяких дієсловах (та деяких інших словах) так само, як у німецькій мові, на питання "кому?":**

Приклади:

::: indent
क्रुध् : देवो नरेभ्यो क्रुध्यति = "Бог гнівається на людей."

अलम् прислівник: "достатньо, достатній, рівний": अलं योधो योधाय = "воїн є рівним іншому воїну"
:::
::::

::: media
![](/images/lekt2403.jpg)
Рис.: अलं योधो योधाय

## 24.3. Sandhi von auslautendem -ai und -au

::: grammar-box
**Сандхі кінцевих -ai та -au**

* **-ai перед голосним, що починає наступне слово, зазвичай замінюється на -ā (рідше — на -āy, як у середині слова)**
* **-au перед голосним зазвичай замінюється на -āv (рідше — на -ā)**

Приклад:

::: indent
तस्मै + अग्नये » तस्मा अग्नये = «цьому вогню»
:::
:::

## 24.4. Словник

अलम् Нареч.: достатньо, цілком; (кому, чому) здатний; з давальним відмінком: достатньо для, цілком для, здатний до; з орудним відмінком: достатньо з, відмовся від , наприклад, अलं क्रोधेन = "достатньо гніву = відмовся від гніву!"

## 24.6. Weitere Вправаen zum Вживання des Давальний відмінок

Перекладіть санскритом:

1\. Богиня, якій не принесли жертви, гнівається на людей.

2\. Він відпускає корову в село.

3\. Тепер достатньо = Хай вистачить терпіння.

4\. Це добре (हित, सुख) для брахмана.

5\. Нехай буде шанована (नमस्) Шіва! Нехай буде шанована Шрі Ґанеша!

::: media
![](/images/lekt2409.jpg)
Рис.: श्रीगणेशाय नमः
(Джерело зображення: [Деталі](/licenses#lekt2409))
:::

6\. До побачення! (= Нехай буде благополуччя (स्वस्ति f.) Вам!)

7\. Цей плід вистачає для їжі.

8\. Борець є рівним (शक्त) (іншому) борцю.

9\. Навіть Вішну не перевершує (प्र-भू + Dat.) Шіву.

10\. Після того як я поклонився трьом мудрецам (Akk)... Він поклоняється Нарасімху (Dat.)

::: indent
Пояснення: मुनित्रयम् "триада мудреців = три мудреці" = граматисти पाणिनि, कात्यायन, पतञ्जलि
:::

::: media
![](/images/lekt2410.jpg)
Рис.: नरो नरसिंहाय नमस्करोति
(Джерело зображення: [Деталі](/licenses#lekt2410))
:::

11\. Ласкаво просимо (स्वागतम्) Вам. Ласкаво просимо королеву.

12\. Бажаю Вам благополуччя (कुशल) = Нехай буде благополуччя Вам!

13\. Він не вважає його за стеблину трави.

14\. Вистачає одного плоду для їжі та води для пиття.

15१५. До нових зустрічей! (Неосанскрит: पुनर्दर्शनाय)
