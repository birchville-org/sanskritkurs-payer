# Урок 16

## 16.1. Про санді кінцевих приголосних

Для утворення складних слів (компаундів), перша частина яких складається з основ, що закінчуються на приголосний, необхідні такі правила:

Кінцеві гортанні, ретрофлексні, зубні та губні смычні приголосні (тобто, не носові та не палатальні).

:::: grammar-box

::: no-header

|   |   |
| :--- | :--- |
| **в паузі та перед глухими звуками** | **Замінюються на відповідний їм глухий ненапрямлений звук:** [[br]] **напр.** [[br]] [[indent]] -g + p- » -kp- [[br]] [[indent]] -d + ph- » -tph- [[br]] [[indent]] -dh + p- » -tp- |
| **перед дзвінкими неносовими звуками** | **Замінюються на відповідний їм дзвінкий ненапрямлений звук:** [[br]] **напр.** [[br]] [[indent]] -t + g- » -dg- [[br]] [[indent]] -k + b- » -gb- [[br]] [[indent]] -dh + d- » -dd- [[br]] [[indent]] -k + a- » -ga- |
| **перед носовими** | **Замінюються на відповідний їм носовий звук:** [[br]] **напр.** [[br]] [[indent]] -t + n- » -nn- [[br]] [[indent]] -p + n- » -mn- |

:::

::::

Виняток із наведеного вище правила:

Кінцевий зубний смычний приголосний (не носовий):

:::: grammar-box

::: no-header

|   |   |
| :--- | :--- |
| **перед палатальними** | **Замінюються на відповідний ненапрямлений палатальний:** [[br]] **тобто** [[br]] [[indent]] -t + c- » -cc- [[br]] [[indent]] -d + c- » -cc- [[br]] [[indent]] -th + c- » -cc- [[br]] [[indent]] -dh + c- » -cc- [[br]] [[indent]] -t/-th/-d/-dh + ch- » -cch- [[br]] [[indent]] -t/-th/-d/-dh + j- » -jj- [[br]] [[indent]] -t/-th/-d/-dh + jh- » -jjh- |
| **+ ś** | **» -cś- або -cch-** |
| **перед ретрофлексними** | **Замінюються на відповідний ненапрямлений ретрофлексний:** [[br]] **тобто** [[br]] [[indent]] -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- [[br]] [[indent]] -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **перед l-** | **Замінюються на -l:** [[br]] **тобто** [[br]] [[indent]] -t/-th/-d/-dh + l- » -ll- |

:::

::::

Приклади:

तद् + फल = तत्फल

पुण्यवत् + ब्राह्मण = पुण्यवद्ब्राह्मण

पुण्यवत् + नर = पुण्यवन्नर

पुण्यवत् + पुरुष = पुण्यवत्पुरुष

सत्यवत् + चैतन्य =सत्यवच्चैतन्य

सुखवत् + लोक = सुखवल्लोक

पुत्रवत् + जन = पुत्रवज्जन

बलवत् + शत्रु = बलवच्छत्रु

## 16.4. Вправи на повторення

А) Утворіть усі вивчені відмінки для наведених слів як приклади для раніше вивчених класів відмінювання.

Використовуйте для цього наступну схему, яка відповідає порядку відмінків у індійських граматиках і яку, через її (згодом обговорювані) переваги, запозичили й західні граматисти:

Б) Перекладіть та розберіть усі санскритські складні слова (самаси):

१. योगश्चित्तवृत्तिनिरोधः ॥योगसूत्र १.२॥

२. स्वधर्मो ब्राह्मणस्याध्ययनमध्यापनं यजनं याजनं दानं प्रतिग्रहश्च ॥५॥

क्षत्रियस्याध्ययनं यजनं दानं शस्त्राजीवो भूतरक्षणं च ॥६॥

वैश्यस्याध्ययनं यजनं दानं कृषिपाशुपाल्ये वणिज्या च ॥७॥

शूद्रस्य द्विजातिशुश्रूषा वार्त्ता कारुकुशीलवकर्म च ॥८॥

सर्वेषामहिंसा सत्यं शौचमनसूयानृशंस्यं क्षमा च ॥१३॥

(कौटिलीयार्थशास्त्र १.३.५-८, १३)

Пояснення;

Речення 7: कृषिपाशुपाल्ये — дуал, ном. і акуз.: дхвадва (самаса), що позначає дві «речі».

Речення 8: कर्म — ном. і акуз. однини середнього роду від कर्मन् «дія».

Речення 13: सर्वेषाम — ген. мн. ч. чоловічого роду від सर्व «кожен, усі» (займенник, відмінюється не як deva).
:::
