# Урок 22

## 22.1. Абсолютив (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫)

::: grammar-box

Якщо потрібно виразити санскритом, що дія агенса (⟪कर्तृ⟫) передує іншій дії агенса або супроводжує її як супутній обставина, використовують абсолютив (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫). Тобто

"після того, як він зробив це, він робить те" ; "він робить це, тоді він робить те" ; "в результаті цього він робить те" ; "я прийшов, побачив і переміг" тощо.

Абсолютив є дієприслівником, тобто він не підлягає ні дієслівному відмінюванню, ні відмінюванню за родами чи числами, але завжди — за винятком кількох винятків — має того самого агенса (⟪कर्तृ⟫), що й дія, якій передує або яку супроводжує дія, позначена абсолютивом. Отже, агент абсолютива стоїть у називному (⟪प्रथमा⟫) або орудному відмінках (⟪तृतीया⟫).

Серед складних слів абсолютив є одним із найпоширеніших засобів вираження в санскриті.

Під час перекладу на німецьку мову слід уникати постійного вживання слова "після того, як". Натомість слід використовувати прийняті в німецькій мові способи вираження часової послідовності.

**Схема:**

(точніше визначення до абсолютива: обставинне означення, додаток тощо) — абсолютив — абсолютив — ... — абсолютив — ... агент + дієслівний вислів (в активі або пасиві)

:::
**Приклади:**

::: indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = пасивна конструкція: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**  
"Чоловік входить до будинку, бачить маленьку дівчинку і звертається до неї."

Множина: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**
:::
## 22.2. Утворення абсолутива

::: grammar-box
**Утворення абсолутива**

*   Дієслова без префікса: абсолутив на **-tvā**
*   Дієслова з префіксом: абсолутив на **-ya** або **-tya**
:::
### 22.2.1. Дієслова без префікса: абсолутів на -⟪त्वा⟫

::: grammar-box

**Утворення:**

(переважно) корінь у глибокому ступені в тій формі, яку він має перед PPP + **-tvā** (**-⟪त्वा⟫**)

Лише заперечний **a-** / **an-** узгоджується з суфіксом **-⟪त्वा⟫** : **⟪अकृत्वा⟫** "не зробивши"

:::
**Приклади:**

::: indent
**⟪आप्त्वा⟫** "після того, як він / вона / воно / я / ти / ми / ви / вони / ми двоє / ви двоє / вони двоє досягли / досягли"

**⟪आसित्वा⟫** "після того, як він (...) сидів / сидить"

**⟪इत्वा⟫** "після того, як він (...) йшов / пішов"

**⟪स्थित्वा⟫** "після того, як він (...) стояв / став"

**⟪जित्वा⟫** "після того, як він (...) переміг / переміг"

**⟪उक्त्वा⟫** "після того, як він (...) говорив / говорив"
:::
### 22.2.2. Дієслова з префіксами

#### 22.2.2.1. Корені на довгий голосний (окрім -ā) або на приголосник

::: grammar-box

**(переважно) корінь у низькому ступені + -ya**

:::
**Приклади:**

::: indent
**⟪उपनीय⟫** "після того, як він (...) підвів / підніс"

**⟪प्रभूय⟫** "після того, як він (...) виступив / виступив" "після того, як він (...) мав владу"

**⟪प्राप्य⟫** "після того, як він (...) отримав / отримав"
:::
#### 22.2.2.2. Корені на -ā

::: grammar-box

**без змін корінь у високому ступені + -ya**

:::
**Приклад:**

::: indent
**⟪उपस्थाय⟫** "після того, як він (...) вступив / вступив" ; (але без префікса: **⟪स्थित्वा⟫**)
:::
#### 22.2.2.3. Корені, що в низькому ступені закінчуються на короткий -i, -u, -ṛ

::: grammar-box

**корінь у низькому ступені + -tya**

:::
**Приклади:**

::: indent
**⟪प्रस्तुत्य⟫** "після того, як він (...) гучно прославив / прославив"

**⟪विस्मृत्य⟫** "після того, як він (...) забув / забув"

**⟪संस्कृत्य⟫** "після того, як він (...) підготував / підготував для жертвоприношення"
:::
#### 22.2.2.4. Корені на -am / -an, що в низькому ступені закінчуються на -a

::: grammar-box

**За бажанням:**

Корінь на **-am** / **-an** + **-ya**

або:

Корінь на **-a** + **-tya**

:::
**Приклад:**

::: indent
**⟪विगम्य⟫** або **⟪विगत्य⟫** "після того, як він (...) минув / минув"
:::

**⟪व्रत⟫ ср.р.:** обітниця, релігійний обов'язок, релігійне дотримання (людина обіцяє божеству щось, щоб отримати щось від нього. Приклад: мати обіцяє віддати свою доньку як храмову проститутку (**⟪देवदासी⟫**), якщо її донька одужає. Важливі **⟪व्रत⟫** сьогодні: пост; утримання від їжі, яку любиш; сексуальне утримання; читання священних писань; виконання певних ритуалів; годів брахманів тощо. Коротко про **⟪व्रत⟫**: Walker, Hindu World Vol. II, стор. 581f. Детально: P. V. Kane: History of Dharmaśāstra Vol. 5,1 стор. 1 - 462. Там стор. 253 - 462 список **⟪व्रत⟫** та релігійних свят ("наведений нижче список ... не претендує на повноту" !!!)

**⟪चर्⟫ 1 дієсл. charati пас. charyate дієпризм. мин. ч. charita інфінітив. charitum (санскрит: ⟪चर्⟫ 1 дієсл. ⟪चरति⟫ пас. ⟪चर्यते⟫ дієпризм. мин. ч. ⟪चरित⟫ інфінітив. ⟪चरितुम्⟫) :** пасти, блукати, рухатися, діяти, здійснювати щось, виконувати (напр. **⟪व्रतं⟫ ⟪चर्⟫**: практикувати обітницю, зокрема сексуальне утримання)

з цього:

::: indent

**⟪चरण⟫ ср.р., ч.р.:** нога

**⟪चरित⟫ ср.р.:** спосіб життя, життєдіяльність

**⟪ब्रह्मचर्य⟫ ср.р.:** виконання Вед (**⟪ब्रह्मन्⟫**) = вивчення Вед на першому етапі життя (етапі **⟪ब्रह्मचारिन्⟫**), який вимагає суворого сексуального утримання; тому також: сексуальне утримання, цібатський спосіб життя
