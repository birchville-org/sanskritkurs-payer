# Урок 20

## 20.1. Позитивні складені прикметники = ⟪बहुव्रीहि⟫ m.

::: media
![](/images/lekt2004.webp)
Мал.: ⟪बहुव्रीहिः⟫ ⟪पुरुषः⟫
Джодхпур = ⟪जोधपुर⟫
(Джерело зображення: [Деталі](/uk/licenses#lekt2004))
:::
⟪बहुव्रीहिः⟫ = ⟪बहवो⟫ ⟪व्रीहयो⟫ ⟪यस्य⟫ ⟪सः⟫ = "той, хто має багато рису"

::: grammar-box

**Бахувріхі, на відміну від татпуріші, позначає щось інше, ніж виражено його членами: тоді як ⟪बालपुत्रः⟫ як татпуріша розкладається на "молодий син", тобто те, що виражено останнім членом складного слова (⟪पुत्र⟫), ⟪बालपुत्रः⟫ як бахувріхі розкладається на "той, чий син молодий", тобто позначуваний є не сином (⟪पुत्र⟫) і не обов'язково молодим (⟪बाल⟫), а іншою особою, відмінною від молодого сина, а саме його батьком.**

**Позитивні складені прикметники спочатку завжди є прикметниками, які, однак, можуть бути субстантивовані. Тому граматичний рід бахувріхі залежить від того, на що посилається бахувріхі, а не від роду останнього члена композиції.**

:::
::: grammar-box

**Схема розкладання бахувріхі:**

**1. Член зазвичай у називному відмінку (⟪प्रथमा⟫) однини, подвійного числа або множини -- 2. Член у називному відмінку однини, подвійного числа або множини -- відносний займенник в іншому відмінку, ніж називний (зазвичай родовий - ⟪षष्ठी⟫) і в роді та числі всього бахувріхі -- вказівний займенник у числі, відмінку та роді всього бахувріхі.**

:::
Приклади:

::: indent
⟪गतपापः⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪सः⟫ = "той, чий зло пішло" = "той, хто вільний від злочинів"

Ак. одн. ⟪गतपापम्⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तम्⟫

Інстр. одн. ⟪गतपापेन⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तेन⟫

Род. одн. ⟪गतपापस्य⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तस्य⟫

Наз. мн. ⟪गतपापाः⟫ = ⟪गतानि⟫ ⟪पापानि⟫ ye⟪षां⟫ ⟪ते⟫

тощо.

⟪अस्तमोहा⟫ = ⟪अस्तो⟫ ⟪मोहो⟫ ⟪यया⟫ ⟪सा⟫ = "та (жінка), яка скинула невігластво"

⟪प्राप्तोदको⟫ ⟪ग्रामः⟫ = ⟪प्राप्तमुदकं⟫ ⟪यं⟫ s ⟪ग्रामः⟫ = "село, до якого підійшла вода" = "село, загрожене повінню"

⟪पुण्यवत्पुत्रः⟫ як бахувріхі = ⟪पुण्यवान्पुत्रो⟫ ⟪यस्य⟫ ⟪सः⟫, або: ⟪पुण्यवन्तः⟫ ⟪पुत्रा⟫ ⟪यस्य⟫ ⟪सः⟫ = "той, чий син має заслуги" або: "той, чії сини мають заслуги"
:::
::: grammar-box

**Співвідношення між першим і другим членами може бути в бахувріхі:**

*   **атрибутивне**
*   **аппозитивне**
*   **кезальне**
*   **адвербіальне**

**Як і в татпуріші, означуваний член зазвичай стоїть на другому місці.**

:::
Традиційно розрізняють:

*   ⟪समानाधिकरणबहुव्रीहिः⟫ : в ⟪विग्रहवाक्य⟫ перший і другий члени стоять в одному відмінку

*   ⟪व्यधिकरणबहुव्रीहिः⟫ : в ⟪विग्रहवाक्य⟫ перший і другий члени стоять в різних відмінках

## 20.2. Бахувріхі з атрибутивним першим членом

::: grammar-box

**Схема:**

:::
::: indent
**Прикметник -- Іменник**
:::
**Приклад:**

::: indent
⟪गुणवत्पुत्रो⟫ ⟪ब्राह्मणः⟫ =  ⟪गुणवान्पुत्रो⟫ ⟪यस्य⟫ ⟪स⟫ ⟪ब्राह्मणः⟫ = "брахман, син / сини якого має / мають добрі якості"
:::
**Дуже часто зустрічається -- рідкісна для Татпуріші -- атрибутивна означувальність за допомогою дієприкметника минулого часу пасивного стану (PPP). Відносний займенник при розборі зазвичай стоїть у орудному відмінку (⟪तृतीया⟫) (рідше у родовому / ⟪षष्ठी⟫).**

**Правило великого пальця:**

*   **PPP - іменник = зазвичай Бавувріхі**
*   **Іменник -- PPP = зазвичай Татпуріша**

**Приклад:**

::: indent

:::

## 20.6. Відмінювання останнього члена бахувріхі

::: grammar-box

**Останній член бахувріхі відмінюється як багатоідіомне прикметник, незалежно від його початкового роду. Отже, якщо в складному слові останній член має рід, відмінний від його початкового, то це має бути бахувріхі, якщо це не самаягардхвана (середній рід, однина).**

**При прикметниковому утворенні**

*   **-ā-основи в чоловічому роді та середньому роді стають -a-основами**
*   **-a-основи (чол., сер.) утворюють жіночий рід на -ā або -ī**
*   **-ī-основи (жін.) повинні в кінці бахувріхі приймати суфікс -ka, -kā, -ka (сер.); цей суфікс можуть або повинні приймати й багато інших бахувріхі**

:::
## 20.7. Інша класифікація видів бахувріхі

Приклади наведені тут для подальшого опрацювання, для деяких з них граматика та словниковий запас ще не були розглянуті

1.  означувальне слово в першому члені — означуваний слово в другому члені: ⟪स्थिरचित्तः⟫ = ⟪स्थिरं⟫ ⟪चित्तं⟫ ⟪यस्य⟫ ⟪सः⟫
2.  незмінні слова в першому члені: ⟪उच्चैःश्रवस्⟫
3.  порівняння в першому члені: ⟪कुशाग्रधीः⟫ =  ⟪कुशाग्र⟫ ⟪इव⟫ ⟪धीर्यस्य⟫ ⟪सः⟫
4.  приховане порівняння: ⟪उष्ट्रमुखः⟫ = ⟪उष्ट्रस्य⟫ ⟪मुखमिव⟫ ⟪मुखं⟫ ⟪यस्य⟫ ⟪सः⟫ = "верблюдомордий" = той, чий рот подібний до рота верблюда
5.  числівник як другий член при приблизній кількості: ⟪उपसशाः⟫ = ⟪दशानां⟫ ⟪समीपे⟫ ⟪ये⟫ ⟪सन्ति⟫ ⟪ते⟫ = "приблизно десять"
6.  обидва члени є числівниками: ⟪एकद्वाः⟫ = ⟪एको⟫ ⟪वा⟫ ⟪द्वौ⟫ ⟪वा⟫ = "один або два"
7.  з sa-/saha- в першому члені: ⟪सपुत्रः⟫ ⟪।⟫ ⟪सहपुत्रः⟫
8.  з sa- (= ⟪समान⟫) в першому члені: ⟪सजनपदः⟫ = ⟪समानो⟫ ⟪जनपदो⟫ ⟪यस्य⟫ ⟪सः⟫
9.  ⟪नञ्बहुव्रीहिः⟫ = з a-/an- в першому члені: ⟪अपुत्रः⟫ = ⟪न⟫ ⟪विद्यते⟫ ⟪पुत्रो⟫ ⟪यस्य⟫ ⟪सः⟫ ; ⟪अनङ्गः⟫ = ⟪न⟫ ⟪विद्यते⟫ ⟪अङ्गं⟫ ⟪यस्य⟫ ⟪सः⟫
10.  з прийменником тощо в першому члені: ⟪प्रवातः⟫ =⟪प्रकृष्टो⟫ ⟪वातो⟫ ⟪यस्मिन्⟫ ⟪सः⟫ ; ⟪निर्धनः⟫ = ⟪निर्गतं⟫ ⟪धनं⟫ ⟪यस्मात्सः⟫ ; ⟪सुबुद्धिः⟫ = ⟪सुष्ठु⟫ ⟪बुद्धिर्यस्य⟫ ⟪सः⟫ ; ⟪दुर्बुद्धिः⟫ = ⟪दुष्टा⟫ ⟪बुद्धिर्यस्य⟫ ⟪सः⟫
11.  позначення напрямків для позначення проміжних напрямків: ⟪पुर्वोत्तरा⟫ "північно-східний"
12.  дієприкметник минулого часу активного стану (PPP) як перший член: ⟪कृतकटः⟫ = ⟪कृतः⟫ ⟪कटो⟫ ⟪येन⟫ ⟪सः⟫
13.  та інші

## 20.8. Відносини між бахувріхі та відносним реченням

Хоча кожне бахувріхі можна розкласти на відносне речення, не кожне відносне речення можна замінити бахувріхі. Герман Георг Якобі (1850–1937), який ближче досліджував відносини між цими двома явищами («Композитум і підрядне речення», 1897), пише:

::: indent
«Якщо перекладати з німецької або іншої сучасної мови санскритом, не всі підрядні речення можна відтворити за допомогою складних слів, а лише описові та описові; ті ж, що містять концептуально необхідне або важливе визначення, в санскриті також виступають як відносні речення.»
:::
::: media
![](/images/lekt2002.jpg)
Рис.: Герман Якобі
(Джерело зображення: [Деталі](/uk/licenses#lekt2002))
:::
Це може бути правдою. Однак тоді індійці багато чого вважають описовим і описовим, що ми б вважали «концептуально необхідним або важливим».
