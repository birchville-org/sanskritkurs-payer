# Урок 45

## 45.1. Утворення дієслівних форм другої особи (⟪मध्यमः⟫) безголосих основ, що не мають голосового суфікса (продовження)

### 45.1.2. Сьомий клас теперішнього часу (⟪रुधादि⟫)

::: grammar-box

наприклад ⟪युज्⟫ 3.од.Ind.Prez.Ā ⟪युङ्क्ते⟫ або ⟪यु⟫:sig[⟪ङ्ते⟫]
:::

## 45.2. Вокатив однини (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**Більшість вокативів однини є основою з високим кінцевим звуком.**

Напр. **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** тощо.

**Винятками є жіночі роди на -ā та -ī, а також основи на -in, вокатив однини яких слід запам’ятати особливо.**
:::
::: no-header
| | Вокатив однини |
| --- | --- |
| Чоловічий рід на -a | ⟪देव⟫ |
| Середній рід на -a | ⟪फल⟫ |
| Жіночий рід на -ā | ⟪देवते⟫ |
| Чоловічий рід на -i | ⟪कवे⟫ |
| Жіночий рід на -i | ⟪मते⟫ |
| Чоловічий рід на -u | ⟪शत्रो⟫ |
| Жіночий рід на -u | ⟪धेनो⟫ |
| Жіночий рід на -ī | ⟪देवि⟫ |
| Чоловічий рід на -ṛ | ⟪पितर्⟫ |
| Жіночий рід на -ṛ | ⟪मातर्⟫ |
| Чоловічий рід на -an | ⟪राजन्⟫ |
| Середній рід на -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Чоловічий рід на -man/-van | ⟪आत्मन्⟫ |
| Чоловічий рід на -in | ⟪बलिन्⟫ |
| Чоловічий рід на -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt ч.р. | ⟪महन्⟫ |
| mahānt с.р. | ⟪महत्⟫:br= Називний відмінок |
| Чоловічий рід на -mant/-vant | ⟪गुणवन्⟫ |
| Середній рід на -mant/-vant | ⟪गुणवत्⟫:br= Називний відмінок |
| Займенники | вокатив не утворюється |
:::

## 45.4. Вправи

A) Перекладіть санскритською (для минулого часу, будь ласка, використовуйте імперфект ⟪लङ्⟫):

1\. Ти розділяєш (буддійську) громаду.

::: indent
щодо розколу громади (⟪सङ्घभेद⟫) див.:

**Payer, Alois (1944–):** Vinayamukha : Основні поняття чернечих правил і орденського права Тхеравади. -- Частина I. -- (Матеріали до основних понять буддизму). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::
2\. Чи насолоджувалися ви землею?

3\. Ти отримав дар від царя?

О, святійший чоловіче, чому ти не боїшся небезпек?

О, батьку, куди залишаєш ти родину?

О, жінка-шудра, чи неси ти тягар до будинку багатого брахмана?

О, богине, ти мала б виконати бажання щастя вайш'ї, який вчинив заслуги.

О, слони, ви не мали б ламати пута.

О, ти, рівний левові чоловіче, чому не спрямовуєш всю свою увагу на Абсолютне (Брахман)?

Чи виміряв ти, о поете, світи?
