# Урок 57

## A) Аорист-трансформації

Перекладіть та визначте наведені форми та утворіть відповідні форми **аориста**. За винятком каузативів та коренів, що утворюють **s-аорист**, у дужках вказано клас відповідного аориста:

:::grammar-box
| №. | Форма | Визначення / Значення | Аорист |
|:---|:---|:---|:---|
| १. | **पेचिथ** | *पच्* 1U: 2. од. Perf. P. (ти гартував) | **अपाक्षीः** |
| २. | **अवक्** (३) | *वच्* 2M: 2. 3. од. Impf. P. (ти говорив / він говорив) | **अवोचः / अवोचत्** |
| ३. | **सोष्यसि** | *सु* 1/2M: 2. од. Fut. P. (ти розмножуватимешся) | **असौषीः** |
| ४. | **छिन्दे** | *छिद्* 7U: 1. од. Ind. Прас. Ā. (я відрізаю) | **अच्छित्सि** |
| ५. | **कुरुषे** | *कृ* 8U: 2. од. Ind. Прас. Ā. (ти робиш у власних інтересах) | **अकृथाः** |

| ९. | **जिघ्रामः** (१,६) | *घ्रा* 1M: 1. мн. Ind. Прас. P. (ми нюхаємо) | **अघ्रास्म / अघ्राम** |
| १०. | **शासति** (२) | *शास्* 2M: 3. мн. Ind. Прас. P. (вони наказують) | **अशिषन्** |
| ११. | **स्तुवे** | *स्तु* 2U: 1. од. Ind. Прас. Ā. (я славлю) | **अस्तोषi** |
| १२. | **दिग्धे** | *दिह्* 2U: 3. од. Ind. Прас. Ā. (він маже) | **अदिग्ध** |
| १३. | **प्लवध्वे** | *प्लु* 1Ā: 2. мн. Ind. Прас. Ā. (ви пливете) | **अप्लोढ्वम्** |
| १४. | **तस्थिथ** (१) | *स्था* 1M: 2. од. Perf. P. (ти стояв) | **अस्थाः** |
| १५. | **बिभ्यति** | *भी* 3M: 3. мн. Ind. Прас. P. (вони бояться) | **अभैषुः** |
| १६. | **ततर्प** | *तृप्* 4/6M: 1. 3. од. Perf. P. (я / він наситив) | **अतार्प्सीत् / अत्राप्सीत्** |
| १७. | **जुहुथ** | *हु* 3M: 2. мн. Ind. Прас. P. (ви приносите жертву) | **अहौष्ट** |
| १८. | **ऊषुः** | *वस्* 1M: 3. мн. Perf. P. (вони жили) | **अवात्सुः** |
| १९. | **ससर्जिथ** | *सृज्* 6M: 2. од. Perf. P. (ти створив) | **अस्राक्षीः** |
| २०. | **लिल्यिरे** | *ली* 4Ā: 3. мн. Perf. Ā. (вони притискаються) | **अलेषत / अलासत** |
| २१. | **अत्याजयम्** | *त्यज्* 1M: 1. од. Impf. P. Kaus. (я залишив) | **अतित्यजम्** |
| २२. | **सिध्यथ** (२) | *सिध्* 4M: 2. мн. Ind. Прас. P. (ви досягли мети) | **असिधत** |

| २५. | **अप्रच्छयन्** | *प्रच्छ्* 6M: 3. мн. Impf. P. Kaus. (вони залишили запитувати) | **अपप्रच्छन्** |
