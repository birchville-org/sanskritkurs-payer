## 3.1. Називний відмінок Однина des Жіночий рідs

### 3.1.1. Називний відмінок Однина auf -s

Auch folgende Nominalstämme, die mit einem Vokal enden, bilden den Nominativ Singular auf **-s**: <!-- TODO: Fallback translation -->

::: grammar-box
- **Feminina auf -i**: z.B. **śruti** f. "das Hören" -- Nom. sg.: **śrutis** = श्रुतिस् <!-- TODO: Fallback translation -->
- **Feminina auf -u**: z.B. **dhenu** f. "Milchkuh" -- Nom. sg.: **dhenus** = धेनुस् <!-- TODO: Fallback translation -->
:::

### 3.1.2. Називний відмінок Однина ohne Закінчення

Den Nominativ Singular bilden ohne Endung: <!-- TODO: Fallback translation -->

::: grammar-box
- **Feminina auf -ā**: z.B. **devatā** f. "Gottheit" -- Nom. sg.: **devatā** = देवता <!-- TODO: Fallback translation -->
- **Feminina auf -ī**: z.B. **devī** f. "Göttin" -- Nom. sg.: **devī** = देवी <!-- TODO: Fallback translation -->
:::

::: important
**Achtung!** Daneben gibt es einsilbige feminine Wurzelnomina auf -ī, deren Nominativ Singular auf -s endet: z.B. dhī f. "Gedanke" -- Nom. sg.: dhīs = धीस्. Auch lakṣmī (लक्ष्मी) f., tarī (तरी) f. "Boot" und tantrī (तन्त्री) f. "Saite" bilden unregelmäßig den Nominativ Singular auf -s: lakṣmīs = लक्ष्मीस्. <!-- TODO: Fallback translation -->
:::

## 3.2. Утворення der Feminina zu Maskulina

::: grammar-box
**Чоловічий рід на -a:**
- **Жіночий рід на -ā**: наприклад, **kṣatriya** ч.р. » **kṣatriyā** ж.р. «жінка-кшатрій» = क्षत्रिया
- **Жіночий рід на -ī**: наприклад, **brāhmaṇa** ч.р. » **brāhmaṇī** ж.р. «брахманка» = ब्राह्मणी

**Чоловічий рід на -u:**
- **Жіночий рід на -ī**: наприклад, **sādhu** ч.р. » **sādhvī** ж.р. (добрий, свята) = साध्वी
  (**-u-** перед голосним переходить у **-v-**, тому **-u- + -ī** » **-vī**)
:::

## 3.3. Називний відмінок Множина Чоловічий рід und Жіночий рід

::: grammar-box
Закінчення називного відмінка множини для чоловічого та жіночого роду — **-as**.

- **Чоловічий рід на -a**: **deva- + -as** » **devās** = देवास्
- **Жіночий рід на -ā**: **devatā- + -as** » **devatās** = देवतास्
- **Чоловічий рід на -i**: **kavi-** » **kave- + -as** » **kavayas** = कवयस्
- **Жіночий рід на -i**: **śruti-** » **śrute- + -as** » **śrutayas** = श्रुतयस्
- **Жіночий рід на -ī**: **devī- + -as** » **devyas** = देव्यस्
- **Чоловічий рід на -u**: **guru-** » **guro- + -as** » **guravas** = गुरवस्
- **Жіночий рід на -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = धेनवस्
:::

Примітка: **e** є піднесеним ступенем (**guṇa**) від **i**, **o** є піднесеним ступенем від **u**.

## 3.4. Vokalsandhi

::: grammar-box
**Прості голосні, які не відрізняються або відрізняються лише довготою, «злитися» у відповідний довгий голосний:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::

напр.

devatā + annapūrṇā » devatānnapūrṇā «Аннапурна є божеством» = देवतान्नपूर्णा

> (Аннапурна — богиня їжі та кулінарії, її вважають втіленням Парваті, дружини Шиви.)

devī + indrāṇī » devīndrāṇī «Індрані є богинею» = देवीन्द्राणी

> (Індрані — дружина бога Індри.)

::: media
![](/images/lekt0301.jpg)
Рис.: Індра та Індрані на слоні Айравата, мініатюра, Раджастхан, 1670/80
(Джерело зображення: [Деталі](/licenses#lekt0301))
:::

::: grammar-box
**Прості голосні (окрім -a / -ā) перед подібними голосними замінюються відповідним напівголосним:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! До цього правила існують винятки, особливо для форм двини !!)
:::

напр.

devī + umā » devy umā «Ума є богинею» = देव्युमा

> (Ума — ім’я Парваті, дружини Шиви)

::: grammar-box
**-a / -ā перед подібним голосним:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::

Для цього сандхі діє таке правило:

:::

Щодо цього так званого чергування кореня див. пізніше!

напр.

śūdrā + itarā » śudretarā «Ітара — шудра» = शूद्रेतरा

## 3.5. Satzsandhi von -ās

::: grammar-box
**-ās замінюється на -ā перед усіма дзвінкими звуками.**
:::

напр.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ «Вайшії є двічі народженими» = द्विजा वैश्याः

## 3.6. Словник

**śruti** ж.р. = श्रुति : слухання, вічна традиція (назва для Вед та Брахман).

**smṛti** ж.р. = स्मृति : усвідомлення, пам’ять, медитативне усвідомлення = усвідомленість, передача (антонім до **śruti**). Включає:
- шість **vedāṅga** ч.р. (वेदाङ्г)
  1. **śikṣā** ж.р. (शिक्षा): правильне вимовляння
  2. **chandas** ч.р. (छन्दस्): метр
  3. **vyākaraṇa** ч.р. (व्याकरण): граматика
  4. **nirukta** ч.р. (निरुक्त) : тлумачення слів, етимологія
  5. **jyotiṣa** ч.р. (ज्योतिष) : астрономія, календарне вчення
  6. **kalpa** ч.р. (कल्प) : церемоніал
- **śrautasūtra** ч.р. (श्रौतसूत्र) : навчальні тексти для виконання великих жертвоприношень
- **gṛhyasūtra** ч.р. (गृह्यसूत्र) : навчальні тексти для церемоній та жертвоприношень повсякденного життя
- **dharmasūtra** ч.р. (धर्मसूत्र) та **dharmaśāstra** ч.р. (धर्मशास्त्र) : навчальні тексти про право та звичай (правильна поведінка)
- великі епоси **mahābhārata** ч.р. (महाभारत) та **rāmāyaṇa** ч.р. (रामायण)
- **purāṇa** ч.р. (पुराण)
- **nītiśāstra** ч.р. (नीतिशास्त्र) : навчальні тексти життєвої мудрості

**smṛti** є особливо також назвою для текстів про дхарму.

**dhenu** ж.р. = धेनु : (молочна) корова.

**paśu** ч.р. = पशु : одомашнене господарське тваринство, худоба (колектив).

**devatā** ж.р. = देवता : божество (абстрактне та конкретне).

**brāhmaṇī** ж.р. = ब्राह्मणी : брахманка.

**kṣatriyā** ж.р. = क्षत्रिया : жінка кшатрія.

**kṣatriyī** ж.р. = क्षत्रियী : дружина кшатрія.

**vaiśyā** ж.р. = वैश्या : жінка вайшья.

**śūdrā** ж.र. = शूद्रा : жінка шудра.

**śūdrī** ж.р. / **śūdrāṇī** ж.р. = शूद्री शूद्राणी : дружина шудри.

**devī** ж.р. = देवी : богиня, зокрема Durgā ж.р. = दुर्गा, дружина Шиви = शिव.

::: media
![](/images/lekt0303.jpg)
Рис.: Durgā = दुर्га, Орисса
(Джерело зображення: [Деталі](/images/lekt0303))
:::

**sādhvī** ж.р. = साध्वी : жіночий рід до sādhu.

**gurvī** ж.р. = गुर्वी : жіночий рід до guru.

**asmitā** ж.р. = अस्मिता : "я-є-ність", тобто (хибний) погляд: **Я** є той, хто бачить тощо.

**ānvīkṣikī** ж.р. = आन्वीक्षिकी : філософія (наука, яка приходить до своїх висновків через логічно правильні обґрунтування).

**upekṣā** ж.р. = उपेक्षा : непомічання, рівність духу.

**karuṇā** ж.р. = करुणा : співчуття, милосердя.

**muditā** ж.р. = मुदिता : радість, зокрема радівання (протилежність до заздрості).

## 3.7. Вправа

**A) Перетворіть наведені речення на множину:**

1. dvijo brāhmaṇaḥ = द्विजो ब्राह्मणः
2. dvijaḥ kṣatriyaḥ = द्विजः क्षत्रियः
3. dvijo vaiśyaḥ = द्विजो वैश्यः
4. gurur brāhmaṇaḥ = गुरुर्ब्राह्मणः
5. sādhur guruḥ = साधुर्गुरुः
6. guruḥ kaviḥ = गुरुः कविः
7. sādhvī brāhmaṇī = साध्वी ब्राह्मणी
8. devatā guruḥ = देवता गुरुः
9. paśur dhenuḥ = पशुर्धेनुः
10. gurvī sādhvī = गुर्वी साध्वी

**B) Утворіть номінативні речення, вставивши відповідні слова:**

1. śrutis ... (veda) = श्रुतिस् ... वेद
2. paśus ... (dhenu) = पशुस् ... धेनु
3. devī ... (durgā, umā, indrāṇī) = देवी ... दुर्गा, उमा, इन्द्राणी
4. devatā ... (mīnākṣī, annapūrṇā) = देवता ... मीनाक्षी, अन्नपूर्णा
5. śūdrā ... (itarā) = शूद्रा ... इतरा

**C) Переведіть у жіночий рід:**

1. gurur brāhmaṇaḥ = गुरुर्ब्राह्मणः
2. sādhur guruḥ = साधुर्गुरुः
3. kṣatriyaḥ sādhuḥ = क्षत्रियः साधुः

**D) Перекладіть санскритом:**

1. Ума є богинею.
2. Веда є śruti.
3. Вчительки є богинями.
4. Корови є одомашненими тваринами.
5. Поети є вчителями.
6. Кшатрії є двічі народженими.
7. Святі чоловіки є шудрами.
