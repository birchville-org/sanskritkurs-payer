# Урок 28

## 28.1. Каузатив (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Якщо потрібно виразити, що хтось або щось спонукає або змушує іншу особу або предмет виконувати або зазнавати дії, вираженої коренем (з префіксом або без нього), використовується каузатив (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫).**

Приклад:
⟪गम्⟩ "йти" » Каузатив: ⟪गमयति⟩ "він спонукає когось йти; він посилає"
⟪दृश्⟩ "бачити" » Каузатив: ⟪दर्शयति⟩ "він змушує бачити = він показує"
:::

## 28.2. Синтаксична конструкція з каузативом (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Схема 1:**

**Якщо корінь, що лежить в основі каузатива (з префіксом або без нього), є НЕПЕРЕХІДНИМ (тобто не може мати об'єкта в знахідному відмінку) або виражає рух, знання, інформацію або їжу:**

**Агент (⟪कर्ता⟩) каузатива у називному відмінку (⟪प्रथमा⟩) — Агент спонукуваної дії в знахідному відмінку (⟪द्वितीया⟩) — (Мета руху, об'єкт знання тощо в знахідному відмінку = ⟪द्वितीया⟩) — Дієслово в каузативі**
:::
Приклади:

⟪दुर्जनो⟩ ⟪रामं⟩ ⟪मोहयति⟩ = "злий чоловік змушує Раму збентежитися = збентошує Раму = спонукає Раму блукати"
Результат: ⟪रामो⟩ ⟪मुह्यति⟩ = "Рама збентежений / осліплений / блукає."

⟪रामः⟩ ⟪शत्रून्स्वर्गं⟩ ⟪गमयति⟩ = "Рама змушує ворогів йти на небо = посилає ворогів на небо"
Результат: ⟪शत्रवः⟩ ⟪स्वर्गं⟩ ⟪गच्छन्ति⟩ = "вороги йдуть на небо / приходять на небо"

⟪गुरू⟩ ⟪रामं⟩ ⟪वेदार्थं⟩ ⟪वेदयति⟩ = "Вчитель змушує Раму знати сенс Вед = пояснює / вчить Раму сенсу Вед"
Результат: ⟪रामो⟩ ⟪वेदार्थं⟩ ⟪वेत्ति⟩ = "Рама знає / розуміє сенс Вед"

⟪स⟩ ⟪रामं⟩ ⟪वेदमध्यापयति⟩ = "він вчить Раму Ведам"
Результат: ⟪रामो⟩ ⟪वेदमधीते⟩ "Рама вивчає Ведам"

⟪रामो⟩ ⟪देवानामृतमाशयति⟩ = "Рама змушує богів їсти амріту = дає богам амріту для їжі" (⟪अश्⟩ 9 "їсти")
Результат: ⟪देवा⟩ ⟪अमृतमश्नन्ति⟩ "боги їдять амріту"

**За схемою 1 також утворюється корінь ⟪दृश्⟩:**

**Винятки до схеми 1 див. під схемою 2**

Приклад:
(⟪स⟩) ⟪रामं⟩ ⟪पुत्रं⟩ ⟪दर्शयति⟩ = "він показує Рамі сина"
:::
Наступний вірш узагальнює приклади утворення каузатива за схемою 1 (дієслівні форми є 3-ю особою минулого часу в парасмайпаді):
::: indent
⟪शत्रूनगमयत्स्वर्गं⟫
⟪वेदार्थं⟫ ⟪स्वानवेदयत्⟫ ⟪।⟫
⟪आशयच्चामृतं⟫ ⟪देवान्⟫

⟪यः⟫ ⟪स⟫ ⟪मे⟫ ⟪श्रीहरिगतिः⟫ ⟪॥⟫
:::

::: grammar-box
**Схема 2:**

**Для перехідних дієслів (окрім тих, що зазначені під схемою 1). Також для всіх дієслів, якщо тим, що позначається каузативом, є спонукання (тобто, якщо каузатив є каузативом до каузативу):**

**Агент (⟪कर्ता⟫) каузатива в називному відмінку (⟪प्रथमा⟫) — Агент спровокованої дії в орудному відмінку (⟪तृतीया⟫) — Об'єкт спровокованої дії у тому відмінку, який він мав би за простим дієсловом (тобто, зазвичай у знахідному) — Дієслово в каузативі**
:::
::: indent
Приклади:
(⟪स⟫) ⟪रामेण⟫ ⟪भार्यां⟫ ⟪त्याजयति⟫ = "Він спонукає Рāму залишити свою дружину"
Результат: ⟪रामो⟫ ⟪भार्यां⟫ ⟪त्यजति⟫ = "Рāма залишає свою дружину"

⟪विष्णुमित्रो⟫ ⟪रामेण⟫ ⟪गोविन्दं⟫ ⟪गमयति⟫ = "Вішнумітра спонукає Рāму спонукати Говінду йти = Вішнумітра наказує Рāмі відправити Говінду"
Результат: ⟪रामो⟫ ⟪गोविन्दं⟫ ⟪गमयति⟫ = "Рāма відправляє Говінду"
Результат цього результату: ⟪गोविन्दो⟫ ⟪गच्छति⟫ = "Говінда йде"
:::
::: grammar-box
**Винятки до схеми 1:**

**За схемою 2 конструюються, зокрема, такі дієслова:**

**Казатив до:**
- **⟪नी⟩ "вести"**
- **⟪वह्⟩ "їхати" (тільки якщо агент спровокованої дії не є водієм)**
- **⟪स्मृ⟩ "нагадувати" (існують винятки)**
- **⟪अद्⟩ "їсти"**
- **⟪खाद्⟩ "жувати"**
:::
Приклади:

⟪रामो⟩ ⟪भृत्येन⟩ ⟪भारं⟩ ⟪नाययति⟩ ⟪वाहयति⟩ ⟪वा⟩ = "Рāма наказує слозі нести або везти тягар"
Результат: ⟪भृत्यो⟩ ⟪भारं⟩ ⟪नयति⟩ ⟪वहति⟩ ⟪वा⟩ = "Слуга несе або везе тягар"

⟪रामो⟩ ⟪बालेनान्नमादयति⟩ ⟪खादयति⟩ ⟪वा⟩ = "Рāма наказує хлопчикові їсти або жувати їжу"
Результат: ⟪बालो⟩ ⟪ऽन्नमत्ति⟩ ⟪खादति⟩ ⟪वा⟩ = "хлопчик їсть або жує їжу"

(⟪स⟩) ⟪रामेण⟩ ⟪स्मारयति⟩ = "Він спричиняє, що Рāма згадує"
Результат: ⟪रामः⟩ ⟪स्मरति⟩ = "Рāма згадує"

::: grammar-box
**Наступні каузативи можуть конструюватися як за схемою 1, так і за схемою 2:**

- **⟪हृ⟩ "тримати, приносити"**
- **⟪कृ⟩ "робити, творити"**
- **Каузатив до дієслова на -ānī з аґентом у знахідному відмінку до ⟪दृश्⟩**
:::
Приклади:

⟪रामो⟩ ⟪भृत्यं⟩ ⟪कटं⟩ ⟪कारयति⟩ ⟪हारयति⟩ ⟪वा⟩ = "Рāма наказує слозі зробити або принести килимок (⟪कट⟩ ж.р.)"
або:
⟪रामो⟩ ⟪भृत्येन⟩ ⟪कटं⟩ ⟪कारयति⟩ ⟪हारयति⟩ ⟪वा⟩
Результат: ⟪भृत्यः⟩ ⟪कटं⟩ ⟪करोति⟩ ⟪हरति⟩ ⟪वा⟩ = "Слуга робить або приносить килимок"

⟪रामो⟩ ⟪बालं⟩ ⟪प्रतिमां⟩ ⟪दर्शयते⟩ = "Рāма наказує хлопчикові побачити зображення = показує хлопчикові зображення (у власних інтересах)"
або:
⟪रामो⟩ ⟪बालेन⟩ ⟪प्रतिमां⟩ ⟪दर्शयते⟩
Результат: ⟪बालः⟩ ⟪प्रतिमां⟩ ⟪पश्यति⟩ = "хлопчик бачить зображення"

Якщо каузатив використовується в пасивній конструкції, майже завжди застосовується наступна схема:

::: grammar-box
**Схема А (пасивна конструкція):**

**Агент каузатива в орудному відмінку (⟪तृतीया⟩) — Агент спровокованої дії в називному відмінку (⟪प्रथमा⟩) — Об'єкт спровокованої дії у тому відмінку, який він мав би за простим дієсловом (тобто, зазвичай у знахідному) — Дієслово в каузативі**
:::
Приклади:

⟪गुरुणा⟫ ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫ = "Майстер посилає Раму до села"
Результат: ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "Рама йде до села"

⟪रामेण⟫ ⟪भृत्यः⟫ ⟪कटं⟫ ⟪कार्यते⟫ = "Рама наказує слозі зробити килимок"
Результат: ⟪भृत्यः⟫ ⟪कटं⟫ ⟪करोति⟫ = "Слуга робить килимок"

⟪रामेण⟫ ⟪भृत्यो⟫ ⟪भारं⟫ ⟪हार्यते⟫ = "Рама наказує слозі принести тягар"
Результат: ⟪भृत्यो⟫ ⟪भारं⟫ ⟪हरति⟫ = "Слуга приносить тягар"

## 28.3. Утворення основи теперішнього часу від каузативу (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**До основи каузатива додаються тематичні закінчення основи теперішнього часу**
:::
Існують різні типи утворення:

::: grammar-box
**Тип утворення 1: (найчастіше) ступень гуйни (гуна) кореня + -aya-**
:::
Приклади:

| Корінь | Kausativ 3. sg. Indikativ Теперішній час | Значення |
| :--- | :--- | :--- |
| ⟪विश्⟫ | ⟪वेशयति⟫ | він/вона/воно дозволяє увійти, вводить всередину |
| ⟪लुभ्⟫ | ⟪लोभयति⟫ | викликати бажання, робити бажаним, спокушати |
| ⟪दृश्⟫ | ⟪दर्शयति⟫ | робити видимим = показувати |
| ⟪वृत्⟫ | ⟪वर्तयति⟫ | змушувати обертатися, повертати (перехідний), котити (перехідний), запускати в рух |

::: grammar-box
**Тип утворення 2: ступінь подовження (дха) кореня + -aya-**

**Часто зустрічається у коренях, що закінчуються на голосний, та у коренях, після -a- яким слідує лише один кінцевий приголосний.**
:::
Приклади:

| Корінь | Kausativ 3. sg. Indikativ Теперішній час | Значення |
| :--- | :--- | :--- |
| ⟪भू⟫ | ⟪भावयति⟫:br(aus: bhau-aya-ti) | змушувати когось або щось стати, породжувати |
| ⟪इ⟫ | ⟪आययति⟫:br(aus: ai-aya-ti) | змушувати когось йти |
| ⟪नी⟫ | ⟪नाययति⟫:br(aus: nai-aya-ti) | дозволяти вести |
| ⟪कृ⟫ | ⟪कारयति⟫:br(kār-aya-ti) | дозволяти робити |
| ⟪वच्⟫ | ⟪वाचयति⟫:br(vāc-aya-ti) | дозволяти говорити, змушувати говорити, (змушувати говорити текст =) читати вголос |

::: grammar-box
**Тип утворення 3: ступінь слабкого ступеня (вікара) кореня + -aya-**

**Зустрічається.**
:::
Приклад:

| Корінь | Kausativ 3. sg. Indikativ Теперішній час | Значення |
| :--- | :--- | :--- |
| ⟪दुष्⟫ | ⟪दूषयति⟫:br(dūṣ-aya-ti) | (кого-небудь) псувати |

::: grammar-box
**Тип утворення 4: корінь + -paya-**

**У коренях на -ā та в деяких інших коренях.**
:::
Приклади:

| Корінь | Kausativ 3. sg. Indikativ Теперішній час | Значення |
| :--- | :--- | :--- |
| ⟪स्था⟫ | ⟪स्थापयति⟫:br(sthā-paya-ti) | змушувати стояти, встановлювати |
| ⟪इ⟫ + ⟪अधि⟫:br"studieren" | ⟪अध्यापयति⟫:br(aus: adhi+ā-paya-ti):br(zur Пояснення siehe Thumb-Hauschildt Bd. I,2 S. 341) | дозволяти вивчати, навчати |

::: grammar-box
**Нерегулярні утворення:**

**Місцеві граматисти вважають наступні форми каузативами:**

- **han** : Каз. **ghātayati**¹ "дозволяти вбивати, вбивати"
- **pā** 2 "охороняти": **pālayati**² "перевозити, рятувати, захищати"
:::
Примітки:
1. **ghātayati** насправді є дієсловом, утвореним від іменника **ghāta** ч.р. "удар" (деніномінатив), яке використовується замість каузатива від **han**.
2. **pālayati** є справжнім каузативом, але до кореня **pṛ** 3 "перевозити, рятувати, захищати": **pārayati** (pār-aya-ti) » **pālayati** (в деяких регіонах Індії r відповідає l, в інших навпаки l відповідає r).

## 28.4. Утворення пасиву (⟪यक्⟫) до каузативу

::: grammar-box
**Пасив до каузативу утворюється так:**

**Корінь каузативу БЕЗ -aya- + суфікс пасиву -ya-**

Приклади:
**bhāvyate** (bhāv-ya-te) "він/вона/воно буде викликане"
**sthāpyate** (sthāp-ya-te) "він/вона/воно буде встановлене"
:::
Поки пасив до первинного кореня зазвичай утворюється від кореня в глибокому ступені, пасив каузативу зазвичай можна впізнати за тим, що він утворюється від кореня в високому або видовженому ступені.

## 28.5. Утворення майбутнього часу (⟪ऌट्⟫, ⟪भविष्यन्ती⟫ ж.р.) до каузативу

::: grammar-box
**Майбутній час каузативу утворюється від кореня каузативу, при цьому кінцеве -a- каузативного суфіпа випадає:**

**-ay-iṣya-**

Приклад:
**budh** майбутній час каузативу: **bodhayiṣyati** (bodh-ay-i-ṣya-ti): "він/вона/воно буде будити"
:::

## 28.6. Утворення дієприкметника минулого часу стражданого (⟪क्त⟫) до каузативу

::: grammar-box
**Корінь каузативу на -ay- (без кінцевого a) + -i- + -ta**

Приклади:
**gam** — **gamayati** — **gamita** (gam-i-ta) "надіслане" (дієприкметник минулого часу стражданого простого кореня: **gata**)
**sthā** — **sthāpayati** — **sthāpita** (sthāp-i-ta) "встановлене"
:::

## 28.7. Утворення абсолутів (⟪क्त्वा⟫ . ⟪ल्यप्⟫) до каузативу

::: grammar-box
**Абсолут на -tvā утворюється від кореня каузативу на -ay- (без кінцевого a):**

**Корінь каузативу на -ay- + -i- + -tvā**

Приклад:
**sthāpayitvā** (sthā-pay-i-tvā) "після того, як він встановив"
:::
::: grammar-box
**Абсолут на -ya зазвичай приєднується до кореня каузативу БЕЗ -aya-, якщо каузатив має префікс.**

Приклади:
**prabudh** — **prabodhayati** — **prabodhya** (pra-bodh-ya) "після того, як він прокинув"
**ānī** — **ānayati** — **ānāyya** (ā-nāy-ya) "після того, як він привів, після того, як він приніс"
:::
::: grammar-box
**Однак, якщо склад кореня каузативу містить коротке -a- перед єдиним приголосним, -ya абсолуту приєднується до кореня каузативу на -ay- (без кінцевого a).**

Приклад:
**āgam** — **āgamayati** — **āgamayya** (ā-gamay-ya) "після того, як він дозволив прийти"
:::

## 28.8. Утворення інфінітиву (⟪तुमुन्⟫) до каузативу

::: grammar-box
**Інфінітив до каузативу утворюється від кореня каузативу на -ay- (без кінцевого a):**

**Корінь каузативу на -ay- + -i- + -tum**

Приклад:
**jan** — **janayati** — **janayitum** (janay-i-tum) "щоб викликати"
:::

## 28.9. 10-й клас теперішнього часу (⟪चुरादि⟫ = ⟪चुर्⟫ тощо)

::: grammar-box
**Так само, як каузативи, деякі корені 10-го класу теперішнього часу утворюють теперішній час (та інші часи), не будучи каузативами.**

Приклади:
1.  Корінь у видовженому ступені + -aya- : ⟪कम्⟫ 10А ⟪कामयते⟫ "любити"
2.  Корінь у високому ступені + -aya- : **cur** 10У **corayati** "красти"; майбутній час: **corayiṣyate**; пасив: **coryate**
:::
::: grammar-box
**Форми каузативу до дієслів 10-го класу теперішнього часу ідентичні до форм простого дієслова. Вирішити, чи є це каузативом, можна лише за змістом або, іноді, за конструкцією.**
:::
