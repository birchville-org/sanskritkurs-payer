# Урок 54

Утворіть відповідні форми аориста від наведених нижче форм теперішнього або доконаного часу:

::: grammar-box
| №. | Форма | Визначення / Значення | Аорист |
|:---|:---|:---|:---|
| ⟪१⟫. | **⟪यन्ति⟫** | вони йдуть | **⟪अगुः⟫** |
| ⟪२⟫. | **⟪पिबामि⟫** | я п’ю | **⟪अपाम्⟫** |
| ⟪३⟫. | **⟪ददौ⟫** | я / він дав | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | **⟪बभूव⟫** | я / він / вони були / були / були | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | **⟪दधति⟫** | вони саджають | **⟪अधुः⟫** |
| ⟪६⟫. | **⟪ऐम⟫** | ми йшли | **⟪अगाम⟫** |
| ⟪७⟫. | **⟪पपिथ⟫** | ти пив / охороняв | **⟪अपाः⟫** (до *⟪पा⟫* "пити") |
| ⟪८⟫. | **⟪तिष्ठति⟫** | він стоїть | **⟪अस्थात्⟫** |
| ⟪९⟫. | **⟪इयेथ⟫** | ти пішов | **⟪अगाः⟫** |
| ⟪१०⟫. | **⟪पप⟫** | ви пили | **⟪अपात⟫** |
| ⟪११⟫. | **⟪एष्यथ⟫** | ви підете | **⟪अगात⟫** |
| ⟪१२⟫. | **⟪तस्थुः⟫** | вони стояли | **⟪अस्थुः⟫** |
| ⟪१३⟫. | **⟪अधत्त⟫** | ви садили | **⟪अधात⟫** |
| ⟪१४⟫. | **⟪अददाः⟫** | ти дав | **⟪अदाः⟫** |
| ⟪१५⟫. | **⟪अभवन्⟫** | вони були | **⟪अभूवन्⟫** |
| ⟪१६⟫. | **⟪ददिम⟫** | ми дали | **⟪अदाम⟫** |
| ⟪१७⟫. | **⟪भिद्यते⟫** | розщеплюється | **⟪अभेदि⟫** |
| ⟪१८⟫. | **⟪उद्यते⟫** | говориться | **⟪अवादि⟫** |
| ⟪१९⟫. | **⟪स्तूयते⟫** | він хвалиться | **⟪अस्तावि⟫** |
| ⟪२०⟫. | **⟪कृष्यते⟫** | ореється | **⟪अकर्षि⟫** |
| ⟪२१⟫. | **⟪जायते⟫** | він народжується | **⟪अजनि⟫** |
| ⟪२२⟫. | **⟪गीयते⟫** | співається | **⟪अगायि⟫** |
| ⟪२३⟫. | **⟪गम्यते⟫** | йдеться | **⟪अगामि⟫** |
