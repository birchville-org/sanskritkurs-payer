# Урок 19

## 19.1. Відносний речення

::: grammar-box

**Схема:**

**Відносний займенник -- відносне речення, що містить іменник, до якого відноситься відносне речення -- (вказівний займенник) -- головне речення**

**Відносне речення може стояти і після головного речення, але воно не може бути вставлене в головне речення.**

**Відносний займенник і відносне слово, яке, на відміну від німецької мови, стоїть у відносному реченні, стоять у тому відмінку, який синтаксично вимагає відносне речення. Вказівний займенник стоїть у тому відмінку, який синтаксично вимагає головне речення.**
:::

Приклади:

Примітка: У відносних реченнях загального змісту часто використовується оптатив замість індикативу. Тому багато наших прикладів бажано було б сформулювати в оптативі.

**1. Агенс (⟪कर्तृ⟫) речення уточнюється за допомогою відносного речення:**

::: indent
⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪स⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫ =  ⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ = ⟪येन⟫ ⟪नरेण⟫ ⟪पुण्यम्⟫ ⟪क्रियते⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ тощо. = "Людина, яка вчиняє гідні вчинки, потрапляє на небо."
:::
**2. Пряме додаток (⟪कर्म⟫) головного речення уточнюється за допомогою відносного речення:**

::: indent
⟪यो⟫ ⟪ब्राह्मणो⟫ ⟪देवान्यजते⟫ ⟪तं⟫ ⟪देवा⟫ ⟪रक्षन्ति⟫ = "Боги захищають брахмана, який приносить їм жертву як господар жертви."
:::
**3. Уточнення іменника головного речення стоїть у відносному реченні:**

::: indent
⟪ये⟫ ⟪नराः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪तेषां⟫ ⟪पुत्रा⟫ ⟪धनं⟫ ⟪न⟫ ⟪लभन्ते⟫ = "Сини людей, які вчиняють зло, не отримують багатства."
:::
**4. Відносний займенник і відносне слово стоять у родовому відмінку (⟪षष्ठी⟫):**

::: indent
⟪यस्य⟫ ⟪नरस्य⟫ ⟪पुत्राः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪स⟫ ⟪न⟫ ⟪सुखवान्⟫ = "Не є щасливою людина, чия сини вчиняють зло."
:::
**5. Відносний займенник і відносне слово стоять у орудному відмінку (⟪तृतीया⟫):**

::: indent
⟪येन⟫ ⟪शत्रुणा⟫ ⟪ग्रामो⟫ ⟪जितस्तं⟫ ⟪द्विषन्ति⟫ = "Вони ненавидять ворога, який переміг / захопив їхнє село."
:::
**6. Відносний займенник і відносне слово стоять у знахідному відмінку (⟪द्वितीया⟫):**

::: indent
⟪यं⟫ ⟪नरं⟫ ⟪देवी⟫ ⟪रक्षति⟫ ⟪स⟫ ⟪सुखमाप्नोति⟫ = "Людина, яку захищає богиня, досягає щастя."
:::
## 19.2. Відносний займенник = ⟪व्यपेक्षकसर्वनाम⟫ n.

::: grammar-box

**⟪यद्⟫ "який, яка, яке" відмінюється як ⟪तद्⟫, але з правильним санді.**

| | | **Чоловічий рід** :br ⟪पुंस्⟫ | **Середній рід** :br ⟪नपुंसक⟫ | **Жіночий рід** :br ⟪स्त्री⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **Однина** :br ⟪एकवचन⟫ | **1. Називний відмінок** :br ⟪प्रथमा⟫ | **yas** :br ⟪यस्⟫ | **yad** :br ⟪यद्⟫ | **yā** :br ⟪या⟫ |
| | **2. Знахідний відмінок** :br ⟪द्वितीया⟫ | **yam** :br ⟪यम्⟫ | **yad** :br ⟪यद्⟫ | **yām** :br ⟪याम्⟫ |
| | **3. Орудний відмінок** :br ⟪तृतीया⟫ | **yena** :br ⟪येन⟫ | **yena** :br ⟪येन⟫ | **yayā** :br ⟪यया⟫ |
| | **6. Родовий відмінок** :br ⟪षष्ठी⟫ | **yasya** :br ⟪यस्य⟫ | **yasya** :br ⟪यस्य⟫ | **yasyās** :br ⟪यस्यास्⟫ |
| **Множина** :br ⟪बहुवचन⟫ | **1. Називний відмінок** :br ⟪प्रथमा⟫ | **ye** :br ⟪ये⟫ | **yāni** :br ⟪यानि⟫ | **yās** :br ⟪यास्⟫ |
| | **2. Знахідний відмінок** :br ⟪द्वितीया⟫ | **yān** :br ⟪यान्⟫ | **yāni** :br ⟪यानि⟫ | **yās** :br ⟪यास्⟫ |
| | **3. Орудний відмінок** :br ⟪तृतीया⟫ | **yais** :br ⟪यैस्⟫ | **yais** :br ⟪यैस्⟫ | **yābhis** :br ⟪याभिस्⟫ |
| | **6. Родовий відмінок** :br ⟪षष्ठी⟫ | **yeṣām** :br ⟪येषाम्⟫ | **yeṣām** :br ⟪येषाम्⟫ | **yāsām** :br ⟪यासाम्⟫ |

**У складі складених слів виступає основа ⟪यद्⟫ (з урахуванням сандхі).**

:::

## 19.3. Словник

**⟪अर्थ⟫ чол. роду:** мета, ціль, значення (слова), багатство, майно, статки. ⟪अर्थम्⟫ (знах.), ⟪अर्थेन⟫ (оруд.) з родовим відмінком або як другий член складного слова Татпуріша: заради ..., щоб.

⟪अर्थ⟫ є одним із трьох життєвих цілей (⟪पुरुषार्थ⟫), як вони описуються в світській та релігійній літературі:

::: indent
**⟪धर्म⟫ чол. роду:** здобуття заслуги через виконання того, що є правом, або, принаймні, уникнення зла, яке могло б настати від невиконання Дхарми

**⟪अर्थ⟫ чол. роду:** раціонально-цільове поводження, здобуття добробуту

**⟪काम⟫ чол. роду:** насолода почуттів, зокрема й у сексуальній сфері
:::

**⟪स्था⟫ + ⟪उप⟫ 1 ухвал. ⟪उपतिष्ठति⟫ :** наближатися, ставати в шанобливій позі перед кимось

**⟪धनगर्भ⟫ 3-тя особа:** "внутрішність якого є грошима = в якому знаходяться гроші"

**⟪गर्भगृह⟫ сер. роду:** найглибший святилищний приміщення індуїстського храму, що містить найважливіше зображення бога храму (про будівництво індуїстських храмів див.: Volwahsen, A.: Індія: споруди індуїстів, буддистів і джайнів. -- Мюнхен, 1968)

## 19.4. Вправа

**Перекладіть санскритом:**

1\. Вайшьянка, чий син помер, плаче.

2\. Рама приносить жертву богині, яка його охороняє.

3\. Поет прославляє кшатрія, багатством якого він прагне.

4\. Вогонь спалює дім чоловіка, який не шанує Аґні жертвою.

5\. Чоловік, рівний тигрові, вбиває кшатріїв-воїнів, які перемогли Раму (пасив).
