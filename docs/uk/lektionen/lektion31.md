# Lektion 31

## 31.1. Die 7. Теперішній часklasse (रुधादि = "रुध् u.s.w.")

:::: grammar-box
**Утворення:**

**Перед вихідними приголосними кореня низького ступеня вставляється так званий назальний інфікс (-na- або -n-):**

*   **у сильному корені: -na-**
*   **у слабкому корені: -n-**

**Для поєднання вихідних приголосних кореня з закінченнями, що починаються на приголосний, діють ті самі правила, що й для другого класу пресенса.**
::::

**У деяких коренях -n- слабкого пресенсного кореня проникло й у непресенсні часи, тому ці корені подаються з інфіксованим назальним.**
::::

Приклад:

**भञ्ज्** 7P "ламати"

::: indent
*   Індикатив пресенса
    *   3.од.П. **भनक्ति** (bha-na + j + ti)
    *   3.мн.П. **भञ्जन्ति** (bha + n + j-anti)
*   Фютур: **भङ्क्ष्यति** (bha + n + j + sya + ti)
*   Пасив: **भज्यते** (або з початкового кореня **भज्**, або з *bhñj-ya-te)
*   PPP: **भग्न** (можливо, з *bhñj + na)
:::

## 31.2. Словник

**युज्** 7U **युनक्ति** : запрягати, припрягати, напружувати, кріпити; Ā також: напружувати себе (= зусилля), з’єднуватися з, зосереджуватися на (Локатив, сепаратив)
::: indent
**Fut. योक्ष्यति**
**Pass. युज्यते**
**Kaus. योजयति**
**PPP युक्त**
**Inf. योक्तुम्**

від них:
**युग n. -&gt; युग n.:** ярмо, пара, світова епоха (існує чотири світові епохи:
1. **कृत**
2. **त्रेता**
3. **द्वापर**
4. **कलि**

**कलियुг** почалася близько 3102 р. до н. е., року війни **महाभारत**. Детальніше у Башам, Wonder, с. 323)

**योग m.:** «запрягання, напруження», зусилля, з’єднання, йога (див. Башам, Wonder, с. 327 і далі)

## 31.3. Вправа

А) Перекладіть наведені речення та розберіть складні іменники (самаси):

प्रज्ञा दुःखसम्भवं रुन्ध्यादिति बुद्धिमानार्यबुद्धमार्गेण गच्छेत् ॥१॥

शस्त्राणि शरीरमेव छिन्दन्ति जीवस्तु न म्रियत इति भगवद्गीतायां भगवतोच्यते ॥२॥
