## 18.2. Детермінативні складні слова (⟪तत्पुरुष⟫) з прислівниковим першим членом

Як прислівниковий (незмінюваний) перший член можуть виступати

*   прислівники
*   прийменники
*   частки
*   інші незмінювані слова

::: indent
можуть використовуватися. Такі татпуріша зазвичай належать до класу нітьясамаса = ⟪नित्यसमास⟫ (м. "сталі складні слова"), тобто складних слів, які взагалі не можна або не можна лише за допомогою слів, що входять до самого складного слова, розкласти на прості.
:::
Приклади:

⟪अति⟫ "окрім того":

::: indent
⟪अतिगुरु⟫ 3: надзвичайно важкий, надзвичайно вагомий

⟪अतिपुरुष⟫ м.: видатна людина, супермен, герой

⟪अतिस्तुति⟫ ж.: надмірна похвала

⟪अत्युक्ति⟫ ж.: надмірне говоріння, перебільшення
:::
Найважливішими прислівниковими першими членами є a-/an-, su-, dus-.

⟪अ⟫ (перед приголосним), ⟪अन्⟫ (перед голосним): не-: стоїть у складному слові замість ⟪न⟫ "не".

Приклади:

::: indent
⟪अनृत⟫ с. = ⟪नर्तम्⟫ (= ⟪न⟫ + ⟪ऋतम्⟫): неправда, брехня

⟪अकृत⟫ 3 = ⟪न⟫ ⟪कृत⟫ 3: не зроблено, незроблено

⟪अब्राह्मणी⟫ ж. = ⟪न⟫ ⟪ब्राह्मणी⟫ : небрахманка, небрахманка

⟪अदेव⟫ м. = ⟪न⟫ ⟪देवः⟫ : не бог, небог
:::
⟪सु⟫ "добре, добре"; при розкладанні складного слова коментатори замінюють його прикметником зі значенням "добре" (наприклад, ⟪सुष्टु⟫ 3, ⟪शोभन⟫ 3).

Приклади:

::: indent
⟪सुकवि⟫ м.: хороший поет

⟪सुकृत⟫ с.: добра справа

⟪सुखादित⟫ 3: добре пережоване

⟪सुदुःख⟫ с.: велике страждання
:::
⟪दुस्⟫ "погано, погано" (звернути увагу на сандхі!).

Приклади:

::: indent
⟪दुर्नय⟫ м.: погане керівництво, погане поводження

⟪दुष्करण⟫ с.: погана справа, складна справа
:::
При цьому діє таке правило:

::: grammar-box

Звук зміна -s у складних словах

На відміну від реченнєвого сандхі, у кінці першого члена складних слів діє:

\-s після -i- або -u- перед безголосим гортанним або губним » -ṣ

Тому: ⟪दुष्करण⟫

:::
### 18.2.1. Композити типу ⟪सुकर⟫ / ⟪दुष्कर⟫

::: grammar-box

Композити типу ⟪सुकर⟫ / ⟪दुष्कर⟫ мають переважно значення пасивної можливості:

Приклади:

:::
::: indent
⟪सुकर⟫ 3: легко зробити

⟪सुगम⟫ 3: легко йти

⟪दुर्गम⟫ 3: важко йти

⟪सुदुर्गम⟫ 3: дуже важко йти
:::
### 18.2.2. Значення наñ-Татпуріша (a- / an-)

Татпуріша з a- / an- можуть мати такі значення:

1.  Подібність (⟪तत्सादृश्यम्⟫):  
::: indent
⟪अब्राह्मणः⟫ = кшатрій або вайшья, який носить священний шнур (⟪यज्ञोपवीत⟫ ч.р.), і таким чином подібний до брахмана, не будучи ним
:::
2.  Відсутність, непроведення (⟪तदभावः⟫):  
::: indent
⟪अज्ञानम्⟫ = невігластво (відсутність знання)
:::
3.  Іншість (⟪तदन्यत्वम्⟫):  
::: indent
⟪अपटम्⟫ = те, що не є тканиною / одягом (⟪पट⟫ ч.р.: тканина, одяг)
:::
4.  Малість (⟪तदल्पता⟫):  
::: indent
⟪अनुदरम्⟫ = маленький живіт (не-живіт)
:::
5.  Не схвалення (⟪अप्राशास्त्यम्⟫):  
::: indent
⟪अकालः⟫ = незгода
:::
6.  Ворожнеча (⟪निरोधः⟫):  
::: indent
⟪असुरः⟫ = бог-ворог (за хибною етимологією a-sura)
:::

Наступний вірш узагальнює ці значення:

::: indent
⟪तत्सादृश्यमभावश्च⟫  
⟪तदन्यत्वं⟫ ⟪तदल्पता⟫ ⟪।⟫  
⟪अप्राशास्त्यं⟫ ⟪निरोधश्च⟫  
⟪नजर्थाः⟫ ⟪षट्प्रकीर्तिताः⟫ ⟪॥⟫

Називають шість значень наñ (= a-/an-) ....
:::
## 18.3. Верbalьні композити

::: indent
⟪उपसर्गेण⟫ ⟪धात्वर्थो⟫  
⟪बलादन्यत्र⟫ ⟪नीयते⟫ ⟪।⟫  
⟪गङ्गासलिलमाधुर्यं⟫  
⟪सागरेण⟫ ⟪यथाम्भसा⟫ ⟪॥⟫
:::
⟪चन्द्रकीर्ति⟫ : ⟪प्रसन्नपदा⟫ С. 2 Зл. 14ф.

За допомогою префікса значення кореня насильницьки змінюється, подібно до того, як солодкість води Гангу змінюється морською водою.

::: grammar-box

Дієслова в санскриті можуть поєднуватися з префіксами (⟪उपसर्ग⟫ чол. р.). Зазвичай застосовується сандхі речення. Префікси можуть у певних випадках суттєво модифікувати значення кореня, тому в багатьох випадках значення дієслова з префіксом потрібно вивчати окремо. Дієслова з префіксом можуть мати інший спосіб (P, Ā), ніж простий корінь. Перед коренем можуть одночасно ставитися кілька префіксів.

:::
Деякі важливі префікси:

⟪उप⟫ "до, туди, проти"

Приклади:

::: indent
⟪उपगम्⟫ 1 ⟪उपगच्छति⟫ : йти туди, наближатися

⟪उपदिश्⟫ 6 ⟪उपदिशति⟫ : вказувати, навчати, радити

⟪उपपद्⟫ 4 Ā ⟪उपपद्यते⟫ : діставатися туди

*   PPP ⟪उपपन्न⟫ 3: оздоблений (орудний відмінок)

⟪उपलभ्⟫ 1 Ā ⟪उपलभते⟫ : охоплювати, здобувати
:::
⟪प्र⟫ "вперед, назовні"

Приклади:

::: indent
⟪प्राप्⟫ (pra-āp) 5 ⟪प्राप्नोति⟫ : здобувати

⟪प्रदिश्⟫ 6 ⟪प्रदिशति⟫ : показувати

⟪प्रबुध्⟫ 4 Ā ⟪प्रबुध्यते⟫ : прокидатися, розпізнавати

⟪प्रभू⟫ 1 ⟪प्रभवति⟫ : виходити, виділятися, мати владу над (родовий, місцевий, давальний відмінки)

⟪प्रवच्⟫ 2 ⟪प्रवक्ति⟫ PPP ⟪प्रोक्त⟫ (« pra + ukta) : пояснювати, повідомляти, висловлювати

⟪प्रवद्⟫ 1 ⟪प्रवदति⟫ : висловлювати, називати, вважати за

⟪प्रस्तु⟫ 2 ⟪प्रस्तौति⟫ : прославляти перед, гучно прославляти, згадувати про щось, починати
:::
⟪वि⟫ "розділено, геть, роз-, роз-"

Приклади:

::: indent
⟪विगम्⟫ 1 ⟪विगच्छति⟫ : розходитися, минати, зникати

⟪विजि⟫ 1 Ā (!) ⟪विजयते⟫ : перемагати

⟪विमुच्⟫ 6 ⟪विमुञ्चति⟫ : відокремлювати, звільняти

⟪विवद्⟫ 1 ⟪विवदति⟫ : диспутувати, розглядати, розповідати

⟪विस्मृ⟫ 1 ⟪विस्मरति⟫ : забувати

⟪विहन्⟫ 2 ⟪विहन्ति⟫ : розбивати, руйнувати, нищити
:::
⟪सम्⟫ "разом, з"

Приклади:

::: indent
⟪समास्⟫ 2 Ā ⟪समास्ते⟫ : сидіти разом, перебувати, жити

⟪समि⟫ 2 ⟪समेति⟫ : збиратися разом, об'єднуватися

⟪संगम्⟫ 1 Ā (!) ⟪संगच्छते⟫ : збиратися разом, зустрічатися (дружньо або вороже), мати статевий зв'язок з (знахідний відмінок)

⟪संजन्⟫ 4 Ā ⟪संजायते⟫ : виникати

⟪सम्बुध्⟫ 4 Ā ⟪सम्बुध्यते⟫ : повністю прокидатися (до істини)

⟪सम्पद्⟫ 4 Ā ⟪सम्पद्यते⟫ : надаватися комусь, вдаватися

### 18.3.1. Іменникові утворення від дієслівних складених

::: grammar-box
