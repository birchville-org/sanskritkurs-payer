# Урок 29

## 29.1. Вживання парасмайпада (⟪परस्मैपद⟫) та āтманепада (⟪आत्मनेपद⟫) у каузативі

::: grammar-box
**Каузатив, за винятком кількох випадків, є убхайпада (⟪उभयपद⟫)**
:::
::: grammar-box
**У каузативі вживається āтманепад (⟪आत्मनेपद⟫):**

**1. Якщо наслідок спричиненої дії приносить користь тому, хто спричиняє:**
:::
Приклад:

⟪रामः⟫ ⟪कटं⟫ ⟪कारयते⟫ = "Рама змушує зробити для себе (у власних інтересах) килимок"

**2. Якщо каузатив дієслів, що мають перехідне вживання, вживається в рефлексивному значенні ("показувати себе", "давати про себе знати" тощо), або якщо об'єкт простого дієслова є агентом (⟪कर्तृ⟫) каузатива:**

Приклад:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "Вішну показує себе своїм шанувальникам"

Результат: ⟪भक्ता⟫ ⟪विष्णुं⟫ ⟪पश्यन्ति⟫ = "Віруючі бачать Вішну"

Отже, правила в цілому відповідають правилам вживання āтманепада (⟪आत्मनेपद⟫) при дієсловах убхайпада (⟪उभयपद⟫).

## 29.3. Вправа на переклад для повторення

⟪अनित्याशुचिदुःखा⟫*⟪नात्मसु⟫* ⟪नित्यशुचिसुखात्मख्यातिरविद्या⟫ ⟪॥योगसूत्र⟫ ⟪२⟫.⟪५॥⟫
