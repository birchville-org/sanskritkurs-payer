# Вправа 61

Урок 61 є завершенням курсу санскриту і не містить додаткових письмових вправ.

З вивченням іменників кореневої форми, перифрастичного майбутнього часу та похідних іменників закладено основи для читання оригінальних санскритських текстів. Курс завершується традиційним звертанням до Ґанеші (⟪श्रीगणनाथ⟫), яке позначає перехід від підручника до самостійного читання.
