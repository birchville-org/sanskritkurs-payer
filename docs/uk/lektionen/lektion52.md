# Урок 52

## 52.1. Середній рід основ на -i та -u

::: grammar-box
**Перед закінченнями, що починаються з голосного, вставляється -n-, що є впливом n-основ (-in).**
:::

## 52.2. Іменникова деривація

### 52.2.1. Дієприкметник минулого часу (PPP) + -vant: Дієприкметник минулого часу Parasmaipada

::: grammar-box
**Дієприкметник минулого часу Parasmaipada утворюється так:**

**PPP + -vant / ж.р.: vatī**
**Склонення як у основ на -vant або ж.р. ⟪देवी⟫**
:::
PPP + -vant / ж.р.: vatī

Склонення як у основ на -vant або ж.р. ⟪देवी⟫

Приклади:

::: indent
⟪कृतवन्त्⟫ (kṛta-vant) / ⟪कृतवती⟫ "той/та, хто зробив"

⟪भिन्नवन्त्⟫ "той, хто розщепив"
:::
### 52.2.2. ⟪तद्धित⟫-суфікс -maya / -mayī

::: grammar-box
**Суфікс ⟪तद्धित⟫ -maya / ж.р.: -mayī утворює від іменників прикметники зі значенням**

*   **"зроблений з"**
*   **"складений з"**
*   **"багатий на"**

**Перед -maya (як і перед -⟪मात्र⟫) вихідні приголосні форми паузи замінюються відповідним їм носовим.**
:::
Приклади:

::: indent
⟪अन्नमय⟫ 3 "багатий на їжу"

⟪चिन्मय⟫ 3 (від ⟪चित्⟫ ж.р. "інтелект") "складений з мислення/розуму"

⟪वाङ्मय⟫ 3 (від ⟪वाच्⟫ ж.р. "мова") "складений з мовлення"

⟪सोममय⟫ 3 "зроблений з соми, складений з соми"
:::
::: grammar-box
**Іменники на -maya іноді вживаються як середнього роду іменники й позначають тоді надлишок того, що позначається іменником, до якого додано -maya.**
:::
::: indent
напр. ⟪अन्नमय⟫ ср.р. "надлишок їжі"
:::

## 52.3. Утворення прислівників: прислівниковий суфікс -śas

::: grammar-box
**Прислівниковий суфікс -śas утворює прислівники (переважно) розподільного значення з:**

*   **числівниками**  
    Приклади:  
    ⟪एकशस्⟫ "окремо, по одному"  
    ⟪द्विशस्⟫ "парою, по два"  
    ⟪शतशस्⟫ "сотнями, по сто"

*   **іншими словами**  
    Приклади:  
    ⟪भागशस्⟫ "частина за частиною"  
    ⟪सर्वशस्⟫ "всюди, зовсім усі"  
    ⟪नित्यशस्⟫ "постійно"
:::

## 52.4. Дієслівні складні слова, що виражають, що щось стає або робиться тим, чим воно не було раніше (⟪अभुततद्भावः⟫)

### 52.4.1. Утворення з cvi

::: grammar-box
**Перед коренями**

*   **⟪कृ⟫ 8U "робити"**
*   **⟪अस्⟫ 2P "бути"**
*   **⟪भू⟫ 1P "ставати"**

**іменники та прикметники можуть ставитися як префікси, щоб виразити, що хтось робить особу або річ тією, якою вона є, або що особа або річ стає тим, що позначається цим іменником.**

**Кінцівка іменника обробляється наступним чином:**

Кінцівка іменника обробляється наступним чином:

*   **кінцеве -a та -a відмінюваних слів замінюються на -ī**  
    Приклади:  
    ⟪कृष्णीभवति⟫ "те, що не є чорним, стає чорним"  
    ⟪कृष्णीकरोति⟫ "він робить те, що не є чорним, чорним"  
    ⟪गङ्गीभवति⟫ "він/вона стає Гангом"  

*   **кінцеве -i та -u замінюються відповідним довгим голосним**  
    Приклади:  
    ⟪शुचीभवति⟫ "він/вона/воно стає чистим"  
    ⟪गुरूभवामि⟫ "я стаю майстром"  

*   **кінцеве -ṛ замінюється на --rī**  
    Напр. ⟪पित्रीभवति⟫ "той, хто не є батьком (⟪पितृ⟫), стає батьком = чоловік отримує свою першу дитину"  

*   **кінцеве -n відпадає, а попередній голосний обробляється згідно з вищезгаданими правилами**  
    Напр. ⟪राजीबभूव⟫ "той (хто не був королем) став королем (⟪राजन्⟫)"  

*   **багатостовбурні інші іменники стоять у формі основи, яку вони мають у локативі (⟪सप्तमी⟫) множини. Основа підпадає під звичайні правила сандхі. Див. Кіельгорн, Граматика § 489,3.**  
    Напр. ⟪तिर्यक्करोति⟫ "він кладе на бік (⟪तिर्यच्⟫)"
:::
::: media
![](/images/lekt5209.webp)
Рис.: ⟪भस्मीकृतं⟫ ⟪वनम्⟫
Випалювання підсічки, Аруначал-Прадеш = ⟪अरुणाचल⟫ ⟪प्रदेश⟫
(Джерело зображення: [Деталі](/uk/licenses#lekt5209))

### 52.4.2. Суфікс -sāt

::: grammar-box
**Щоб виразити, що особа або річ повністю стає тією, або що хтось робить щось або когось зовсім тим, що позначається іменником, до іменника**

**можна додати суфікс -sāt (який ніколи не стає -ṣāt)**

**і так утворене слово з коренями**

*   ⟪कृ⟫ 8U "робити"
*   ⟪अस्⟫ 2P "бути"
*   ⟪भू⟫ 1P "ставати"
*   ⟪सम्⟫-⟪पद्⟫ 4Ā

**повинно бути з'єднано в дієслівне складне слово.**
:::
Приклади:

::: indent
⟪अग्निसाद्भवति⟫ ⟪।⟫ ⟪अग्निसात्संपद्यते⟫ "він повністю стає вогнем"

⟪भस्मसात्करोति⟫ "він перетворює зовсім на попіл (⟪भस्मन्⟫ n. "попіл"))
:::
::: grammar-box
**Manchmal bedeutet das Suffix -sāt, dass eine Person oder Sache**

*   **від якого залежить або**
*   **у володіння якого переходить**
*   **або що хтось робить від якого залежним**

**те, що позначається іменником**
:::
Приклад:

::: indent
⟪राजसाद्भवति⟫ "він стає залежним від царя, він стає власністю царя"
:::
::: grammar-box
**Згідно з утвореннями з -sāt корені не обробляються так, як після префіксів, тобто абсолутив:**

:::
::: indent
⟪भस्मसात्कृ⟫:sig[⟪त्वा⟫]
:::
## 52.5. Повторення слів (⟪द्विरुक्तम्⟫)

::: grammar-box
**Повторення слова виражає в санскриті:**

*   **Повторення дії**  
    наприклад, ⟪पुनः⟫ ⟪पुनः⟫ "знову і знову"
*   **Дистрибуція**  
    Приклади:  
    ⟪पृथक्पृथक्⟫ "кожен окремо, кожен індивідуально"  
    ⟪यद्यद्⟫ ... ⟪तत्तद्⟫ "що б не ... все це"  
    ⟪युगे⟫ ⟪युगे⟫ "в кожному окремому світовому віці"

**Іноді з таких поєднань можна утворити складне слово**

:::
Приклади:

::: indent
⟪एकैक⟫ 3 "кожен окремий"
⟪अल्पाल्प⟫ 3 "дуже малий"
⟪नवनव⟫ 3 "завжди новий"
:::
Щодо т.зв. ⟪आम्रेडित⟫-складних слів, у яких повторюються відмінювані слова, але друге в докласичний час отримувало наголос, тобто маємо справу зі складним словом, див. Вакернагель, Староіндійська граматика II,1 с. 142н.
## 52.6. Числівник (⟪सम्ख्या⟩ f.)

Тут не розглянуте див. наприклад, у Кільгорна, Граматика §201н.

### 52.6.1. Кількісні числівники

#### 52.6.1.1. Числівні прикметники (для 1 до 19)

::: grammar-box
**Числівники для *1 до 19* є прикметниками.**
**Числівники для **1 до 4** є різними для трьох родів у відмінюванні.**

**Для числівників для **5 до 19** (:sig[⟪नवदशन्⟫]) існує лише одне відмінювання для трьох родів.**

**Для цих числівних прикметників, як і для всіх прикметників, дійсним є: вони повинні стояти в тому самому відмінку, числі та роді, що й відповідний іменник, і навпаки (тобто для 1 однина, для 2 подвійний, для решти множина).**
:::
Числівні прикметники:

::: indent
1 ⟪एक⟫ 3 (відмінювання як ⟪सर्व⟫, у множині: "деякі")
2 ⟪द्वि⟫ 3
3 ⟪त्रि⟫ 3
4 ⟪चतुर्⟫ 3
5 ⟪पञ्चन्⟫ 3
6 ⟪षष्⟫ 3
7 ⟪सप्तन्⟫ 3
8 ⟪अष्टन्⟫ 3
9 ⟪नवन्⟫ 3
10 ⟪दशन्⟫ 3
:::
Відмінювання наведено в належному місці в списках слів.

Інші числівні прислівники до 19 див. наприклад, у Кільгорна, Граматика §201.

#### 52.6.1.2. Числівні іменники (для 19н.)

::: grammar-box
**Числівники для чисел **19 (⟪एकोनविंशति⟫* "на один менше ніж 20") *до 99* є жіночого роду іменниками і відмінюються як ⟪मति⟫ f.  або кореневі іменники на -t (наприклад, ⟪त्रिंशत्⟫ f.).**

:::
Приклади:

::: indent
20 ⟪विंशति⟫ f.:br
30 ⟪त्रिंशत्⟫ f.
:::

::: grammar-box

**Числівники для чисел **від 100** є середнього роду іменниками. Вони відмінюються як ⟪फलम्⟫.**
:::

Приклади:

::: indent
100 ⟪शत⟫ n.:br
1000 ⟪सहस्र⟫ n.
:::
Окремі числівні іменники див. наприклад, у Кільгорна, Граматика §201.
#### 52.6.1.3. Синтаксичні питання щодо кількісних числівників

::: grammar-box
**З різниці між дієприкметниковими та дієіменниковими числівниками для кількісних числівників випливає наступний наслідок для синтаксису:**
*   прикметникові числівники можуть бути пов'язані з іменником для підраховуваних об'єктів лише як прикметники  
    наприклад, ⟪तिसृभिर्नारीभिः⟫ "трьома жінками"  
*   іменникові числівники можуть бути пов'язані з іменником для підраховуваних об'єктів трьома способами
    *   вони керують родовим відмінком (⟪षष्ठी⟫) підраховуваних об'єктів  
        наприклад, ⟪विंशत्या⟫ ⟪नारीणाम्⟫ "двадцятьма жінками"  
    *   вони стоять як додаток у тому самому відмінку (але в однині), що й підраховувані об'єкти  
        наприклад, ⟪विंशत्या⟫ ⟪नारीभिः⟫ "двадцятьма жінками" 
    *   вони стоять як задній член ⟪तत्पुरुष⟫ з підраховуваними об'єктами як передній член  
        наприклад, ⟪गोविंशत्या⟫ "двадцятьма коровами"

:::
### 52.6.2. Порядкові числівники

Дивіться, наприклад, у Кільгорна, Граматика §201f.

### 52.6.3. Числові прислівники

a) "-раз":

::: indent
один раз: ⟪सकृत्⟫
два рази: ⟪द्विस्⟫
три рази: ⟪त्रिस्⟫
чотири рази: ⟪चतुस्⟫
п’ять разів тощо утворюється за допомогою суфікса -:sig[⟪कृत्वस्⟫]: ⟪पञ्चकृत्वस्⟫
:::
b) "-кратний": виражається за допомогою суфікса -:sig[⟪धा⟫]

::: indent
простий: ⟪एकधा⟫
подвійний: ⟪द्विधा⟫ ⟪।⟫ ⟪द्वेधा⟫
тощо
:::
c) "кожен ...", "по ...": виражається за допомогою суфікса -:sig[⟪शस्⟫] (див. вище!)

::: indent
⟪द्विशस्⟫ "по двоє, по два"
:::
### 52.6.4. Числівникові прикметники

"-кратний":

::: indent
подвійний, що складається з двох
потрійний, що складається з трьох частин

починаючи з 4 "-кратний" виражається за допомогою суфікса -:sig[⟪तय⟫] (ж.р.: -:sig[⟪तयी⟫]): ⟪चतुष्टय⟫ ч.р.м.н. ⟪चतुष्टयी⟫ ж.р. "чотирикратний"
:::
Інші утворення можна знайти у словниках або граматиках.

::: grammar-box
**⟪तत्पुरुष⟫ з кількісним числівником у першій частині не можуть утворюватися довільно:**

**Правило 1: Слова, що позначають сторону світу (як ⟪पूर्व⟫ 3 "східний", ⟪उत्तर⟫ 3 "північний"), та слова для кількісних числівників можуть утворювати з іншими словами лише ⟪कर्मधारय⟫-композит, якщо цей композит вживається як власна назва.**
:::
Тому, наприклад, з ⟪उत्तरा⟫ ⟪वृक्षाः⟫ "північні дерева" або ⟪पञ्च⟫ ⟪ब्राह्मणः⟫ не може бути утворений татпуріша. З ⟪सप्तन्⟫ та ⟪ऋषि⟫ можна, однак, утворити татпурішу ⟪सप्तर्षि⟫ ч.р. "сім рші", якщо це вживається як назва сузір’я Великого Ведмедя (Ursa maior).
::: media
![](/images/lekt5206.jpg)
Рис.: ⟪सप्तर्षयः⟫
Сім’я зірок = сім найяскравіших зірок Великого Ведмедя (Ursa maior)
(Джерело зображення: [Деталі](/uk/licenses#lekt5206))
:::

::: grammar-box
**Правило 2: Відхиляючись від правила 1, слово, що позначає сторону світу або кількісний числівник, може утворювати з іншим іменником татпурішу, якщо**

1.  до так утвореного композиту додається таддіта-суфікс  
    Приклади:  
    pūrva + śālā ("зал) » \*pūrvaśālā (так вживати не можна!) + таддіта -a » ⟪पौर्वशाल⟫ 3 "той, що знаходиться у східній залі"  
    ṣaṣ + mātṛ » \*ṣaṇmātṛ (не дозволено!) + таддіта -a » ⟪षण्मातुर⟫ ч.р. "дитина від шести матерів" (= ⟪कार्त्तिकेय⟫)  

2.  так утворений композит вживається в значенні, яке зазвичай позначається таддіта-суфіксом (у цьому випадку перехід до бахувріхі є плавним):  
    Приклади:  
    dvi + go » ⟪द्विगु⟫ : не: "дві корови", а: "**куплений за дві корови**"  
    ⟪द्विवर्ष⟫ не: "два роки", а: "**дворічний**"  

3.  так утворений композит є першою частиною іншого композиту  
    Приклад:  
    pañca + go » pañcagava (як окреме слово неприпустимо!) + dhana » ⟪पञ्चगवधन⟫ ч.р. "той, чий статок складається з п’яти корів"
:::
::: media
![](/images/lekt5207.webp)

Джалакандапурам = ஜலகண்டபுரம்
(Джерело зображення: [Деталі](/uk/licenses#lekt5207))
:::

::: grammar-box
**Назва кардинального числа (але не напрямку сторони світу) може виступати як перший член складного слова з іншим іменником, утворюючи Tatpuruṣa, навіть якщо такий утворений склад означає агрегат кількох речей, тобто об’єднує дві або кілька речей в одну єдність.**

**Tatpuruṣa, утворені за цим правилом, називаються Dvigu (:sig[⟪द्विगु⟫]).**

**Dvigu-композити, що позначають єдність, зазвичай є середнього роду. Якщо другий член закінчується на -a, може додаватися жіночий суфікс -ī. Якщо другий член закінчується на жін. -ā, то на його місце виступає або середній рід -a, або жіночий -ī. Якщо другий член закінчується на -an, то замість нього виступає -a або -ī.**
:::

## 52.9. Завдання під час семестрових канікул

З уроком 52 завершується перший семестр (13 тижнів по 4 години навчання) курсу санскриту.

Під час семестрових канікул слід виконати наступні завдання:

1.  Повторення всього вивченого досі, особливо:
    1.  Запам’ятовування парадигм дієслівних відмінювань та іменникових склонінь
    2.  Слова
    3.  Основи слів
2.  Запам’ятовування якомога більшої кількості віршів та прозових текстів з класичної літератури
3.  Опрацювання [Лекції 53](lektion53.md)
4.  Опрацювання аркушів Bhg 1 - 11 (ще не в інтернеті)
5.  Підготовка до ⟪भगवद्गीता⟫ Розд. 1, вивчення відповідних слів зі списків слів (ще не в інтернеті)
6.  Метричний аналіз усіх віршів з ⟪भगवद्गीता⟫ ⟪१⟫  
    Гарне враження від тексту в речитативній формі дає: [http://www.vaisnava.cz/gita/mp3/Bhagavad-gita01.mp3](http://www.vaisnava.cz/gita/mp3/Bhagavad-gita01.mp3). -- Доступ станом на 2009-01-19
7.  Читання переказу ⟪महाभारत⟫, наприклад:  
    Mahābhārata : Велика епопея Індії / пер. з санскр. та скор. Бірен Рой. -- 10-те вид. -- Мюнхен : Дідріхс, 1995. -- 335 с. ; 19 см. -- (Жовта серія Дідріхс ; 16 : Індія)
