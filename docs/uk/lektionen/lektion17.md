# Урок 17

## 17.1. Другий клас теперішнього часу (अदादि = अद् тощо)

Сполучення закінчень дієслова безпосередньо приєднуються до кореня. При цьому слід враховувати зміни звуків, що виникають внаслідок слов’яндгі.

:::: grammar-box

Існують такі форми утворення в другому класі теперішнього часу:

1.  Корені зі зміною ступеня кореня
    *   зазвичай: високий ступінь — низький ступінь
    *   деякі корені: подовжений ступінь — низький ступінь
2.  Корені без зміни ступеня кореня
3.  Двоскладні корені на -i/-ī зі зміною ступеня кореня

::::

## 17.2. Корені другого класу теперішнього часу зі зміною кореня високий рівень – низький рівень

Приклади:

द्विष् 2 U "ненадіти"

*   сильний корінь теперішнього часу: dveṣ-
*   слабкий корінь теперішнього часу: dviṣ-

:::: grammar-box

::: no-header

| :--- | :--- |

| 3\. pl. теп. P | द्विषन्ति (dviṣ-anti) |
| 3\. sg. теп. Ā | द्विष्टे (« dviṣ + -te) |

## 17.4. Корені другого класу теперішнього часу без чергування кореня

Приклад:

## 17.5. Двоскладні корені на -i/-ī зі зміною основи

Кілька коренів у низці форм є двоскладними, тобто вони мають -i (або перед деякими закінченнями -ī) перед приголосним закінченням. Ці корені все ж таки внутрішніми граматиками та в словниках тощо вказуються як односкладні.

Приклади:

रुद् 2 P "плакати, вити"

*   сильний теперішній корінь: rodi-
*   слабкий теперішній корінь:
    *   перед приголосним: rudi-
    *   перед голосним: rud-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. sg. теп. час. P | रोदिति (rodi-ti) |
| 3\. pl. теп. час. P | रुदन्ति (rud-anti) |

:::

::::

ब्रू 2 U "говорити"

*   сильний теперішній корінь: bravī- (« bro- + -ī)
*   слабкий теперішній корінь:
    *   перед приголосним: brū-
    *   перед голосним: bruv-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. sg. теп. час. P | ब्रवीति (bravī-ti) |
| 3\. pl. теп. час. P | ब्रुवन्ति (bruv-anti) |
| 3\. sg. теп. час. Ā | ब्रूते (brū-te) |
| 3\. pl. теп. час. Ā | ब्रुवते (bruv-ate) |

:::

::::

Також स्तु 2 U "хвалити" має, окрім форм, зазначених під п. 3, форми за цим зразком:

A) Вставте дієслово в наведених нижче реченнях та перекладіть:
