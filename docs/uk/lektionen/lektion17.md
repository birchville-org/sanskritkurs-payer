# Урок 17

## 17.1. Другий клас теперішнього часу (अदादि = अद् тощо)

Закінчення дієслова приєднуються безпосередньо до основи кореня. При цьому необхідно враховувати фонетичні зміни, що виникають внаслідок сандхі.

:::: grammar-box

Існують такі форми утворення в другому класі теперішнього часу:

1.  Корені зі зміною ступеня основи
    *   найчастіше: сильний ступінь – слабкий ступінь
    *   деякі корені: посилений ступінь – слабкий ступінь
2.  Корені без зміни ступеня основи
3.  Двоскладні корені на -i/-ī зі зміною ступеня основи

::::

## 17.2. Корені другої класу теперішнього часу зі ступенюванням основи: сильний ступінь – слабкий ступінь

Приклади:

द्विष् 2 U "ненадіти"

*   сильний теперішній корінь: dveṣ-
*   слабкий теперішній корінь: dviṣ-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. os. теп. P | द्वेष्टи (« dveṣ + -ti) |
| 3\. мн. ос. теп. P | द्विषन्ти (dviṣ-anti) |
| 3\. os. теп. Ā | द्विष्टе (« dviṣ + -te) |
| 3\. мн. ос. теп. Ā | द्विषते (dviṣ-ate) |

:::

::::

Діяє наступне правило сандхи слів:

Сандхи слів від -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-

## 17.4. Корені другого класу теперішнього часу без чергування основи

Приклад:

पा 2 P "охороняти, берегти, плекати"

## 17.5. Двоскладні основи на -i/-ī зі змінюваним ступенем

Кілька основ є в низці форм двоскладними, тобто вони мають перед приголосним закінченням -i (або перед деякими закінченнями -ī). Ці основи все ж таки вважаються рідними граматиками та в словниках тощо як односкладні.

Приклади:

रुद् 2 P "плакати, ревіти"

*   сильний теперішній час: rodi-
*   слабкий теперішній час:
    *   перед приголосним: rudi-
    *   перед голосним: rud-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. sg. теп. час P | रोदिति (rodi-ti) |
| 3\. pl. теп. час P | रुदन्ति (rud-anti) |

:::

::::

ब्रू 2 U "говорити"

*   сильний теперішній час: bravī- (« bro- + -ī)
*   слабкий теперішній час:
    *   перед приголосним: brū-
    *   перед голосним: bruv-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. sg. теп. час P | ब्रवीति (bravī-ti) |
| 3\. pl. теп. час P | ब्रुवन्ति (bruv-anti) |
| 3\. sg. теп. час Ā | ब्रूते (brū-te) |
| 3\. pl. теп. час Ā | ब्रुवते (bruv-ate) |

:::

::::

## 17.7. Вправа 1

А) Вставте дієслово в наведені нижче речення та перекладіть їх:

१. брахман не говорить неправду ... (бру. вач. вад)

२. кшатрія захищає людей ... (па. ракш)

३. сильний воїн-брахман перемагає ... (джі. хан. юдх)

४. брахман-поет прославляє володаря світу ... (сту. ядж)

ॅ. агні (вогонь) споживає жертвопринесення ... (ад. дах)

६. хлопчик-вайшья доїть корову ... (дух. ракш. па)

७. слуга-брахман йде дорогою, що веде до села брахманів ... (гам. і. пад)

८. слуга-брахман є шудрою ... (ас 2. бху)

९. дівчинка-брахманка ... (руд. ас. мрі)

१०. праведна людина ненавидить беззаконня ... (двіш. на крі)

В) Утворіть від речень, наведених у частині А, множинну форму для підмета (агенса) та присудка (дієслова).
