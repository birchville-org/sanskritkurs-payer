# Деванаґарі = ⟪देवनागरी⟫

## Письмова вправа 1

Санскрит писали і продовжують писати різними системами письма. Наступна довідка надає невеликий огляд цих систем:

![](/images/schrift001.webp)  
Мал.: Зразки санскритського письма
\[Джерело зображення: Вікіпедія, ліцензія GNU FD\]

Найважливішою сучасною північноіндійською системою письма для санскриту є деванаґарі:

![](/images/schrift002.webp)

Кожна приголосна літера позначає також наступний за нею голосний "a". Якщо потрібно написати чистий приголосний (без наступного голосного), це слід позначити підкресленою рискою -- вірама = ⟪विराम⟫ --:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

Голосні, що стоять після приголосного (окрім "a"), пишуться так:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

Порядок написання таких поєднань приголосний + голосний є таким:

![](/images/schrift003.jpg)

Під час письма кожна літера, включаючи поперечну риску на верхній лінії, дописується повністю перед тим, як починається наступна літера.

## Вправа

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

Прочитайте та транслітеруйте:

⟪तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ⟫

Додаткове читання:

⟪पिता⟫ батько, ⟪कपि⟫ мавпа, ⟪कृत⟫ зробив, ⟪टीका⟫ підкоментар, ⟪तत्⟫ цей, ⟪तट⟫ берег, ⟪पत्⟫ стріляти, ⟪पट⟫ тканина, ⟪काच⟫ скло, ⟪काकुत्⟫ піднебіння, ⟪चित्⟫ сприймати, ⟪पृच्⟫ змішувати, ⟪पोटक⟫ слуга, ⟪चेतु⟫ намір, ⟪तौतातित⟫ прихильник Кумаріли (Міманса), ⟪तूत⟫ шовковиця, ⟪पीत⟫ випив, ⟪पीति⟫ напій, ⟪कॢप्⟫ пасувати, ⟪कृपते⟫ він скаржиться, ⟪पुटी⟫ зморшка, ⟪चापि⟫ так само, ⟪तोक⟫ нащадки, ⟪तृपत्⟫ ситий, ⟪पॄ⟫ наповнювати, ⟪कृकाटी⟫ шийний хребець, ⟪पूपौ⟫ два пиріжки, ⟪पैतृकी⟫ батьківський (ж.р.), ⟪कौट⟫ шахрайський, ⟪कच⟫ волосся на голові, ⟪कुतपे⟫ на козячій шкурі, ⟪कुचौ⟫ груди, ⟪चकिता⟫ наляканий (ж.р.)
