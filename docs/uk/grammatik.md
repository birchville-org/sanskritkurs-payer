# Граматичні теми

Ця сторінка пропонує систематичний огляд усіх граматичних тем курсу санскриту. Кожна з 61 лекції тут тематично класифікована.

## 1. Фонетика та письмо (Саṃхйā та Ліпі)

*   **Вступ до звуків**: Систематика та вимова → [Лекція 1](/uk/lektionen/lektion01)
*   **Вступ до письма (Деванагарі)**:
    *   Голосні та прості приголосні → [Лекція 40](/uk/lektionen/lektion40)
    *   Складні приголосні (лігатури) → [Лекція 41](/uk/lektionen/lektion41) та [Лекція 42](/uk/lektionen/lektion42)
*   **Сандха (звучна комбінація)**:
    *   Сандха кінцевого **-s/Вісарґа** → [Лекція 2](/uk/lektionen/lektion02), [Лекція 3](/uk/lektionen/lektion03), [Лекція 30](/uk/lektionen/lektion30)
    *   Сандха **-m, -e, -d** → [Лекція 4](/uk/lektionen/lektion04)
    *   **Голосний сандха** → [Лекція 3](/uk/lektionen/lektion03), [Лекція 24](/uk/lektionen/lektion24)
    *   Сандха **-n** → [Лекція 7](/uk/lektionen/lektion07)
    *   Сандха для **назальних** → [Лекція 21](/uk/lektionen/lektion21), [Лекція 26](/uk/lektionen/lektion26)
    *   Церевіалізація (**n → ṇ / s → ṣ**) → [Лекція 10](/uk/lektionen/lektion10), [Лекція 26](/uk/lektionen/lektion26)
    *   Словесний сандха (h-, ch-) → [Лекція 44](/uk/lektionen/lektion44), [Лекція 51](/uk/lektionen/lektion51)
    *   **Приголосний сандха** (узагальнення) → [Лекція 16](/uk/lektionen/lektion16), [Лекція 43](/uk/lektionen/lektion43)
