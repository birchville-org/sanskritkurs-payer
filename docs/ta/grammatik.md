# இலக்கணப் பொருட்கள்

இந்தப் பக்கம் சமஸ்கிருத பாடத்திட்டத்தின் அனைத்து இலக்கணப் பொருட்களுக்கும் ஒரு முறையான கண்ணோட்டத்தை வழங்குகிறது. 61 பாடங்களில் ஒவ்வொன்றும் இங்கு பொருள் வாரியாக வகைப்படுத்தப்பட்டுள்ளது.

## 1. ஒலியியல் & எழுத்துமுறை (சம்ஹிதா & லிபி)

*   **ஒலிகளுக்கான அறிமுகம்**: அமைப்பு மற்றும் எழுத்தோச்சல் -> [பாடம் 1](/ta/lektionen/lektion01)
*   **எழுத்துமுறை அறிமுகம் (தேவநாகரி)**:
    *   உயிரொலிகள் மற்றும் எளிய உயிரில்லாஒலிகள் -> [பாடம் 40](/ta/lektionen/lektion40)
    *   இணைவுஒலிகள் (இணை எழுத்துகள்) -> [பாடம் 41](/ta/lektionen/lektion41) & [பாடம் 42](/ta/lektionen/lektion42)
*   **சந்தி (ஒலி இணைவு)**:
    *   வாரியிற்பிறப்பு **-ச/விசர்கா** சந்தி -> [பாடம் 2](/ta/lektionen/lektion02), [பாடம் 3](/ta/lektionen/lektion03), [பாடம் 30](/ta/lektionen/lektion30)
    *   **-ம், -ஏ, -த** சந்தி -> [பாடம் 4](/ta/lektionen/lektion04)
    *   **உயிர்சந்தி** -> [பாடம் 3](/ta/lektionen/lektion03), [பாடம் 24](/ta/lektionen/lektion24)
    *   **-ந்** சந்தி -> [பாடம் 7](/ta/lektionen/lektion07)
    *   **நிலைநிலைஒலிகளுக்கான** சந்தி -> [பாடம் 21](/ta/lektionen/lektion21), [பாடம் 26](/ta/lektionen/lektion26)
    *   மூக்கொலிமாற்றம் (**ந் -> ண் / ச -> ஷ்**) -> [பாடம் 10](/ta/lektionen/lektion10), [பாடம் 26](/ta/lektionen/lektion26)
    *   சொல்சந்தி (ஹ, ச்) -> [பாடம் 44](/ta/lektionen/lektion44), [பாடம் 51](/ta/lektionen/lektion51)
    *   **உயிரில்லாஒலிசந்தி** (சுருக்கங்கள்) -> [பாடம் 16](/ta/lektionen/lektion16), [பாடம் 43](/ta/lektionen/lektion43)

## 2. சொல் அறிவு (இலக்கண வகைப்படுத்தல்)

### 2.1 பெயர்ச்சொற்கள் மற்றும் உரிச்சொற்கள் (பால்வினை)

*   **அடிப்படைகள்**: பால்வினைக் கற்றல் -> [பாடம் 1](/ta/lektionen/lektion01), [பாடம் 2](/ta/lektionen/lektion02)
*   **ஆ-அகர இறுதிப் பெயர்கள்** (புலிங்கம் & ஈழிங்கம்) -> [பாடம் 2](/ta/lektionen/lektion02), [பாடம் 7](/ta/lektionen/lektion07)
*   **இ- மற்றும் உ-அகர இறுதிப் பெயர்கள்** -> [பாடம் 3](/ta/lektionen/lektion03), [பாடம் 27](/ta/lektionen/lektion27), [பாடம் 52](/ta/lektionen/lektion52)
*   **ஒலி எழுத்து இறுதிப் பெயர்கள்**:
    *   **-mant / -vant** என்னும் ஒலி எழுத்துக்களால் முடிவன -> [பாடம் 13](/ta/lektionen/lektion13)
    *   **-n** என்னும் ஒலி எழுத்தால் முடிவன (ராஜன், ஆத்மன்) -> [பாடம் 38](/ta/lektionen/lektion38)
    *   எளிய ஒலி எழுத்து இறுதிப் பெயர்கள் -> [பாடம் 51](/ta/lektionen/lektion51), [பாடம் 54](/ta/lektionen/lektion54)
    *   மூலப் பெயர்களான **-ā, -ī, -ū** என்னும் ஒலி எழுத்துக்களால் முடிவன -> [பாடம் 61](/ta/lektionen/lektion61)
*   **இரட்டைப் பால்** (இரட்டைமை) பெயர்களுக்கு -> [பாடம் 49](/ta/lektionen/lektion49), [பாடம் 50](/ta/lektionen/lektion50), [பாடம் 53](/ta/lektionen/lektion53)
*   **எண்கள் & விரிவு**:
    *   எண்ணுப் பெயர்கள் (முதலெண்ணம்/வரிசை எண்ணம்) -> [பாடம் 52](/ta/lektionen/lektion52)
    *   விரிவு (ஒப்பீடு/அதிக ஒப்பீடு) -> [பாடம் 53](/ta/lektionen/lektion53)

### 2.2 உரிச்சொற்கள் & வினையெச்சங்கள்

*   **உரிச்சொற்கள்**:
    *   வினா & அசைவு உரிச்சொற்கள் → [பாடம் 4](/ta/lektionen/lektion04)
    *   தொடர்பு உரிச்சொல் (yad) → [பாடம் 19](/ta/lektionen/lektion19)
    *   தனிநபர் உரிச்சொற்கள் (1. & 2. ஆள்) → [பாடம் 46](/ta/lektionen/lektion46), [பாடம் 47](/ta/lektionen/lektion47)
    *   அசைவு உரிச்சொற்கள் → [பாடம் 37](/ta/lektionen/lektion37)
*   **வினையெச்சங்கள் & அழைப்பு**:
    *   வினையெச்சங்கள் உருவாக்கம் → [பாடம் 37](/ta/lektionen/lektion37), [பாடம் 52](/ta/lektionen/lektion52)
    *   மரியாதையான அழைப்பு & அழைப்பு → [பாடம் 21](/ta/lektionen/lektion21), [பாடம் 44](/ta/lektionen/lektion44)

*   **நிகழ்கால அமைப்பு (சான்றுநிலை)**:
    *   தனிநபர் முடிப்புகள் (3., 2., 1. நபர்) -> [பாடம் 6](/ta/lektionen/lektion06), [பாடம் 44](/ta/lektionen/lektion44), [பாடம் 39](/ta/lektionen/lektion39)
    *   தீம் வகுப்புகள் (1, 4, 6, 10) -> [பாடம் 6](/ta/lektionen/lektion06), [பாடம் 28](/ta/lektionen/lektion28)
    *   அத்தீம் வகுப்புகள் -> [பாடம் 17](/ta/lektionen/lektion17), [பாடம் 33](/ta/lektionen/lektion33), [பாடம் 7](/ta/lektionen/lektion07), [பாடம் 31](/ta/lektionen/lektion31), [பாடம் 8](/ta/lektionen/lektion08), [பாடம் 30](/ta/lektionen/lektion30)
*   **பிற காலங்கள் & மோடி**:

    *   **பெர்ஃபெக்ட்** (ஒருமை/பன்மை) -> [பாடம் 34](/ta/lektionen/lektion34), [பாடம் 35](/ta/lektionen/lektion35), [பாடம் 36](/ta/lektionen/lektion36)
    *   **பெர்ஃபெக்ட் (துவாரம்)** -> [பாடம் 60](/ta/lektionen/lektion60)
    *   **பியூச்சர்** (எளிமை & பெரிஃப்ராஸ்டிக்) -> [பாடம் 26](/ta/lektionen/lektion26), [பாடம் 61](/ta/lektionen/lektion61)
    *   **அவரைஸ்ட்** (கடந்தகாலம்) -> [பாடம் 54](/ta/lektionen/lektion54), [பாடம் 55](/ta/lektionen/lektion55), [பாடம் 56](/ta/lektionen/lektion56), [பாடம் 57](/ta/lektionen/lektion57), [பாடம் 58](/ta/lektionen/lektion58)
*   **வகைப்படுத்தப்பட்ட வினை வடிவங்கள்**:
    *   **பாசீவ் & கௌசேடிவ்** -> [பாடம் 10](/ta/lektionen/lektion10), [பாடம் 28](/ta/lektionen/lektion28), [பாடம் 29](/ta/lektionen/lektion29)
    *   **இன்டென்சிவம் & டெனோமினேட்டிவா** -> [பாடம் 61](/ta/lektionen/lektion61)
*   **துவாரத்தில் வினைச்சொற்கள்** -> [பாடம் 59](/ta/lektionen/lektion59), [பாடம் 60](/ta/lektionen/lektion60)

### 2.4 பெயர்ச்சொல் உருவாக்கங்கள் & சங்கமங்கள்

## 4. அளவியல் (வசனவியல்)

சமஸ்கிருத தத்துவமும் இலக்கியமும் பெரும்பாலும் வசனங்களில் எழுதப்பட்டுள்ளன. அளவியல் இந்த வசனங்களின் இசைக்கட்டமைப்பையும் அமைப்பையும் கற்பிக்கிறது.

*   **அறிமுகம் & ஸ்லோகம்** → [பாடம் 45](/ta/lektionen/lektion45), [பாடம் 53](/ta/lektionen/lektion53)
*   **மேம்பட்ட அளவுகள்** (த்ரிஷ்டுப, ஜாகதி) → [பாடம் 54](/ta/lektionen/lektion54)
