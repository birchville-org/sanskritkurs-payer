# தலைப்புப் பட்டியல்

தலைப்புப் பட்டியல் அனைத்து பாடங்களின் தலைப்புகளிலிருந்து தானியங்கியாக உருவாக்கப்படுகிறது. இது குறிப்பிட்ட இலக்கண நிகழ்வுகளுக்கு விரைவான அணுகலை அனுமதிக்கிறது.
