# பாடம் 57

## 57.1. அருஸ்ட் 4: எஸ்-அருஸ்ட்

::: grammar-box
**अनिट्-வழக்குகளில் பெரும்பாலானவற்றிற்கு எஸ்-அருஸ்ட் உருவாக்கப்படுகிறது, அவை வேறு அருஸ்ட் வடிவத்தை மட்டுமே கொண்டிருந்தால் தவிர. விருப்பமான अनिट्-வழக்குகள் பொதுவாக இந்த அல்லது இஷ்-அருஸ்ட்டை விரும்பியபடி உருவாக்கலாம். अनिट्-வழக்குகளும், அருஸ்ட்டின் 1, 2 அல்லது 6 வடிவத்திற்குப் பிறகு परस्मैपद-ஐ உருவாக்குபவை, எஸ்-அருஸ்ட்டிற்குப் பிறகு आत्मनेपद-ஐ உருவாக்குகின்றன.**

**உருவாக்கம்: ஆக்ட் + வழக்கு + எஸ் + அத்தெமாட்டிக் செகண்டரி அந்தம்**
:::

முடிச்சு வடிவமைப்புச் சuffix கொண்ட முடிச்சுகளின் அட்டவணை

::: grammar-box

|   | **परस्मैपदम्** || **आत्मनेपदम्** ||
| :--- | :---: | :---: | :---: | :---: |
|   | **एकवचनम्** | **बहुवचनम्** | **एकवचनम्** | **बहुवचनम्** |
| **1. तृतीयः** | -சம் | -சமா | -சி | -சமாஹி |
| **2. द्वितीयः** | ***-சிஸ்*** | -ஸ்தா | -ஸ்தஹாஸ் | ***-தஹ்வம்*** |
| **3. प्रथमः** | ***-சித்*** | -சுர் | -ஸ்தா | -சதா |
:::

:::: grammar-box
**ஒரு பொதுவான ஒலி விதி பயன்படுத்தப்படுகிறது, இரண்டு அடைப்புச் சுவர்களிற்கு இடையே ஒரு நசல் ஒலி கைவிடப்படுகிறது (उद् + स्थित » उत्थित) பற்றி, அதாவது, முடிச்சு வடிவமைப்புச் சuffix -ச- முடிச்சுகளுக்கு முன், அவை -த- அல்லது -தஹ- உடன் தொடங்குகின்றன, கைவிடப்படுகிறது (நசல்கள் அல்லது ர்-க்குப் பிறகு அல்ல).**

உதாரணங்கள்:

::: indent
3.ஒ.ஆ a-க்ஷிப் + எஸ் + தா » अ***क्षिप्त***
2.ஒ.ஆ a-க்ஷிப் + எஸ் + தஹாஸ் » अ***क्षिप्था***स्
:::

இத்தகைய வடிவங்கள் வழக்கு-அருஸ்ட்டிற்கும் சேர்ந்திருக்கலாம் மற்றும் பகுதியாக அங்கே சேர்ந்திருக்கலாம்.
::::

இந்திய வியாகரணியாளர்கள் अकृत (3.ஒ.ஆ) போன்ற வடிவங்களையும் எஸ்-அருஸ்ட்டிற்குக் கணக்கிட்டனர், அவை தெளிவாக வழக்கு-அருஸ்ட்டிற்குச் சேர்ந்தன. இந்த நோக்கத்திற்காக இந்திய வியாகரணியாளர்கள் எஸ்-அருஸ்ட்டிற்கான பின்வரும் அட்-ஹோக் ஒலி விதியைக் கண்டுபிடித்தனர்:

::: indent
"சுருக்கமான ஒலிக்குப் பிறகு, -ஸ்த- அல்லது -ஸ்தஹ- உடன் தொடங்கும் 'முடிச்சுகள்', -ச-ஐ இழக்கின்றன."
:::

மற்றும், கடைசி ஒலிகளுடன் எஸ்-ஐ இணைக்க ஒலி விதிகளைக் கவனிக்க வேண்டும்.

-தஹ்வத்திற்கு:

:::: grammar-box
**अचेढ्वम्-வின் -தஹ- அனைத்து அல்லாத அ/ஆ-ஒலிகளுக்கும் மற்றும் -ர்-க்குப் பிறகு -ḍh-ஆல் மாற்றப்படுகிறது.**

::: indent
உதாரணம்: ***चि*** 5U: 2.ஒ.ஆ ***अचेढ्वम्***
:::
::::

::: grammar-box

*   **आत्मनेपद :**
    *   **கடைசி i/ī/u/ū கொண்ட வழக்குகள்: உயர்ந்த நிலை**
    *   **கடைசி -ṝ-ḍh-īr அல்லது -ūr-ஆல் மாற்றப்படுகிறது**

    *   **மற்ற வழக்கு ஒலிகள்: மாற்றமில்லை (அதாவது பொதுவாக தாழ்ந்த நிலை)**

    अपादि "அவர் சென்றார்"

3.  बुध् Ā 3.sg.Ā-ல் செயலற்ற வார்த்தை அரிஸ்டின் வடிவத்தைத் தேர்ந்தெடுக்கலாம்:
    अबोधि / अबुद्ध "அவர் அறிந்தார்"
:::
