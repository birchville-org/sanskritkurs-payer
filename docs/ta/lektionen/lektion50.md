# பாடம் 50

## 50.1. பெயர் உருவாக்கம்: வழக்கமான உயர்த் தரம்

::: grammar-box
**வழக்கமான உயர்த் தரம் சமஸ்கிருதத்தில் तद्धित பின்னசைகளால் நிகழ்கிறது**
* **-तर (பால்வி: तरा) "ஒப்பீட்டு"யில்**
* **तम (பால்வி: तमा) "அதிகபட்ச"த்தில்**

**இந்த பின்னசைகள் உரிச்சொற்களுக்கு ஆண்பால் மூலத்திற்கு இணைக்கப்படுகின்றன. மூல வார்ப்பு வேறுபாடு கொண்ட பெயர்ச்சொற்களுக்கு, அவை -su என்ற லோகடிவின் (पञ्चमी) பன்மைக்கு முன் உள்ள வடிவத்தைக் கொண்ட வலியற்ற மூலத்திற்கு இணைக்கப்படுகின்றன.**
:::

::: media
![](/images/lekt5007.webp)
படம்: लोकस्योत्तमो गिरिः
सगरमाथा = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = எவரெஸ்ட் மலை
(பட மூலம்: [விவரங்கள்](/ta/licenses#lekt5007))
:::

:::: grammar-box
**பொருள்:**

**"ஒப்பீட்டு" என்பது, ஒப்பிடப்படும் பொருள் வெளிப்படுத்தப்படாத போது: "ஒப்பீட்டளவிலான, மிகவும், மிகை":**

::: indent
எ.கா. सुचितर 3 "ஒப்பீட்டளவிலான சுத்தமானது", "மிகவும் சுத்தமானது", "மிகை சுத்தமானது"
:::

**ஒப்பிடப்படும் பொருள் வெளிப்படுத்தப்படும் போது, அது அபிலாடிவ் (पञ्चमी) இல் இருக்கும். ஒப்பீட்டு + அபிலாடிவ் என்பது ஜெர்மனில் "என" உடன் உயர்த் தரத்திற்கு சமமானது.**

::: indent
எ.கா. देवदत्ताद्रामो धीमत्तरः = சொற்பொருள்: "தேவதத்தாவை விட ராமன் கணிதாளர்" = "ராமன் தேவதத்தாவை விட கணிதாளர்"
:::

**"அதிகபட்சம்" என்பது, ஒப்பிடப்படும் பொருள் வெளிப்படுத்தப்படாத போது: "மிக உயர்ந்த, மிகவும்":**

::: indent
எ.கா. सत्तम 3 (सन्त् இல்) "மிக உயர்ந்த நல்லது, மிகவும் நல்லது"
:::

**ஒப்பிடப்படும் பொருள் வெளிப்படுத்தப்படும் போது, அது ஜெனிட்டிவ் (षष्ठी) ("இதிலிருந்து", "கீழ்") இல் இருக்கும் மற்றும் அதிகபட்சம் ஜெர்மன் அதிகபட்சத்திற்கு (உயர்ந்த நிலை) சமமானது:**

::: indent
எ.கா. द्विजानां सत्तमः = "இருமுறை பிறந்தவர்களில் சிறந்தவர்"
:::

**-तर மற்றும் -तम பின்னசைகள் உரிச்சொற்களுக்கு மட்டுமல்லாமல், பெயர்ச்சொற்களுக்கும், அசைக்க முடியாத சொற்களுக்கும், ஏன் வினைச்சொற்களுக்கும் கூட இணைக்கப்படலாம்:**

உதாரணங்கள்:

::: indent
गजतम ஆ. "சிறந்த யானை" (गज) (புத்தரின் பெயரும் கூட)

गोतम ஆ. "மிகப்பெரிய எருமை" (गो) அல்லது: "பசுக்களில் மிகுந்தவன்"

उद् அசைக்க முடியாத. "மேல்", "மேலே" » उत्तर 3 "உயர்ந்த" » उत्तम 3 "மிக உயர்ந்த"
:::

**இந்த பின்னசைகள் ஒரு வினை வடிவத்திற்கு இணைக்கப்படும் போது, அவை எப்போதும் வினையிலா வடிவத்தில் தோன்றும்:**

* **-तराम्**
* **-तमाम्**

உதாரணங்கள்:

::: indent
पचतितराम् "அவர்/அவள்/அது சிறப்பாக வேகவைக்கிறது"

पचतितमाम् "அவர்/அவள்/அது மிக சிறப்பாக வேகவைக்கிறது"
:::

**இந்த வடிவம் இந்த பின்னசைகள் ஒரு அசைக்க முடியாத சொல்லிற்கு இணைக்கப்படும் போதும், பெயர்ச்சொல் வினையிலா முறையில் பயன்படுத்தப்படும் போதும் இருக்கும்:**

::: indent
எ.கா. सुतराम् (सु க்கு) "சிறந்த முறையில்" (வினையிலா)
:::

::: indent
उपनीय तु यः शिष्यं
वेदमधापयेत्द्द्विजः ।
सकल्पं सरहस्यं च
तमाचार्यां प्रचक्षते ॥९॥

एकदेशं तु वेदस्य
वेदाङ्गान्यपि वा पुनः ।
यो ऽध्यापयति वृत्त्यर्थम्
उपाध्यायः स उच्यते ॥१०॥

निषेका***दीनि*** कर्माणि
यः करोति यथाविधि ।
संभावयति चान्नेन
स विप्रो गुरुरुच्यते ॥११॥
