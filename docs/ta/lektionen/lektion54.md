# பாடம் 54

## 54.1. முன்னுரை

பாடம் 54 ஆனது பல்கலைக்கழக வகுப்பில் இரண்டாவது பாதியைக் குறிக்கிறது. இனி இந்த வகுப்பு இந்த பாதியின் முக்கிய தலைப்பு: பூகவத் கீதாவின் முழு வாசிப்பு — இவற்றிற்கு இணையாகவே நடைபெறும். கற்றல் இலக்கு, நடுத்தர அளவிலான ஒரு வாசகத்தை வாசிக்கத் தேவையான திறமை பெறுவதாகும்; இதன் மூலம், பாதியின் கடைசி மூன்றில் ஒரு பகுதியில், பூகவத் கீதாவின் பெரும் பகுதிகளைத் திடீரென மொழிபெயர்க்க முடியும். தொடக்கத்தில், பல்கலைக்கழக வகுப்பில் சொற்பட்டியல்கள் வழங்கப்பட்டன; பின்னர், மாணவர்கள் தங்களுக்குரிய அகராதிநூல்களை (Monier-Williams, Apte, PW) பயன்படுத்த வேண்டும்.

பூகவத் கீதா வகுப்பு, தற்காலிகமாக, ஆன்லைனில் கிடைக்காது.

சம்ஸ்கிருத வகுப்பின் பாடங்கள், இதுவரை கையாளப்படாத, சம்ஸ்கிருத இலக்கணத்தின் தலைப்புகளைக் கையாள்கின்றன.

## 54.5. அகற்றத்தின் கல்வி வகைகள் (लुङ्)

::: grammar-box
**அகற்றத்தின் (लुङ्) அனைத்து கல்வி வகைகளுக்கும் பொதுவானது, அகற்றம் போலவே அசைவு விதிப்படி முன்னர் வைக்கப்படும் அசைவு a- ஆகும். (लङ्)**

சமசுகிருதத்தில் அகற்றத்திற்கு அசைவு மற்றும் முன்னர் பயன்படுத்தப்பட்டவை மட்டுமே பொருத்தமானவை.
:::

::: grammar-box
**அகற்றத்தின் (लुङ्) பின்வரும் கல்வி வகைகள் உள்ளன:**

1.  அசைவற்ற (அசைவற்ற) அகற்றங்கள்: 
    *   54.1. மூல அகற்றம்: அசைவு + மூலம் + இரண்டாம் முடிப்பு
    *   54.2. தீர்வு அசைவு அகற்றம்: அசைவு + மூலம் + ***a*** + இரண்டாம் முடிப்பு
    *   54.3. மீண்டும் செய்யப்பட்ட அகற்றம்: அசைவு + ***மீண்டும் செய்யப்பட்ட*** மூலம் + ***a*** + இரண்டாம் முடிப்பு 
2.  அசைவு அகற்றங்கள் (அசைவு அகற்றங்கள்: s அல்லது s (ṣ) கொண்ட ஒரு அசைவு) ஆனது தனிப்பட்ட முடிப்புக்கு முன் வருகிறது.
    *   54.4. -s அகற்றம்: அசைவு + மூலம் + ***s*** \+ இரண்டாம் முடிப்பு
    *   54.5. -iṣ அகற்றம்: அசைவு + மூலம் + ***i*** + ***ṣ*** + இரண்டாம் முடிப்பு
    *   54.6. -siṣ அகற்றம்: அசைவு + மூலம் + ***siṣ*** + இரண்டாம் முடிப்பு
    *   54.7. -sa அகற்றம்: அசைவு + மூலம் + ***s*** + ***a*** + இரண்டாம் முடிப்பு

ஒவ்வொரு வகைக்கும் வார்த்தைகளின் பங்கீடு காண்க.
:::

### 54.6.1. பசீவத்தின் 3.ஒ.ஒற்றைமைக்காலம்

ஒரு வார்த்தைக்காலத்தின் சிறப்பு வடிவம் பசீவத்தின் 3.ஒ.ஒற்றைமைக்காலம் ஆகும். இது அனைத்து வார்த்தைகளிலிருந்தும் உருவாக்கப்படலாம்.

::: grammar-box
**உருவாக்கம்:**

**ஆக்ட் + வார்த்தை + i**

**வார்த்தை பின்வரும் வடிவத்தைக் கொண்டுள்ளது:**

உயர் நிலை:

*   சுருக்கமான ஒலி (a தவிர) எளிமையான ஒலியை முன்னர் கொண்ட வார்த்தைகள் மற்றும் जन् மற்றும் -am மீது அமைந்த பெரும்பாலான வார்த்தைகள்  
    எடுத்துக்காட்டுகள்:  
    भिद् 7U: अभेदि "அவர் பிரிக்கப்பட்டார்"  
    तुद् 6U: अतोदि "அவர் தள்ளப்பட்டார்"

நீட்டப்பட்ட நிலை:

*   முடிவில் ஒலி கொண்ட வார்த்தைகள்  
    எடுத்துக்காட்டுகள்:  
    नी 1U: अनायि "அவர் வழிநடத்தப்பட்டார்"  
    स्तु 2U: अस्तावि "அவர் பாராட்டப்பட்டார்"  
    कृ 8U: अकारि "அது செய்யப்பட்டது"  
     
    
*   எளிமையான ஒலியை முன்னர் கொண்ட a வார்த்தைகள் (जन् மற்றும் -am மீது அமைந்த வார்த்தைகள் தவிர)  
    எடுத்துக்காட்டு:  
    वद् 1P: अवादि "அது சொல்லப்பட்டது"  
    ஆனால்:  
    जन् 4Ā: अजनि "அவர் பிறந்தார்"  
     

*   -am மீது அமைந்த சில வார்த்தைகள்  
    எடுத்துக்காட்டு:  
    गम् अगामि
    

முடிவுக்கு முன் y சேர்ப்பது:

*   -ā, -e, -ai, -o மீது அமைந்த வார்த்தைகள் வார்த்தையின் -ā மற்றும் முடிவுக்கு இடையே y சேர்க்கின்றன:  
    எடுத்துக்காட்டு:  
    दा 3U: अदायि "அது கொடுக்கப்பட்டது"
    

நாசிக இணைப்பு:

*   சில வார்த்தைகள் நாசிக இணைப்பைக் கொண்டுள்ளன:  
    எடுத்துக்காட்டு:  
    लभ् 1Ā: अलम्भि अलाभि பக்கத்தில் : "அது பெறப்பட்டது"
    

(பசீவத்தின் மற்ற வடிவங்கள் அகாரத்தில் ஆத்மனேபத வடிவங்களால் மீண்டும் சொல்லப்படுகின்றன).
:::
