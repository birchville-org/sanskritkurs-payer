ஒன்றாம் நபை ஒருமை இறுதிகள் P,Ā ஆகியவை மூன்றாம் நபை ஒருமை இறுதிகளுடன் ஒத்திருப்பதைக் கவனிக்கவும். எனவே, வகை III(a,b) மற்றும் வகை V(a,b,c) தவிர்த்த அனைத்து முற்றெச்ச வகைகளிலும், ஒருமை P மற்றும் Ā ஆகியவற்றின் வடிவங்கள் மூன்றாம் நபை ஒருமை P மற்றும் Ā ஆகியவற்றின் வடிவங்களுடன் எப்போதும் ஒத்திருக்கும்.

வகை IV-ல், ஒருமை P இறுதி -au என மூன்றாம் நபை ஒருமை P போல இருக்கும்.

முற்றெச்ச வகைகள் III மற்றும் V-ல், ஒருமை Ā எப்போதும் மூன்றாம் நபை Ā க்கு ஒத்திருக்கும்.

முற்றெச்ச வகைகள் III மற்றும் V-ல், ஒருமை P மற்றும் மூன்றாம் நபை P ஆகியவை மாற்றத்தக்கவாறு ஒத்திருக்கும்: இந்த வடிவமைப்பு வகைகளில், மூன்றாம் நபை P எப்போதும் நீட்டப்பட்ட நிலையில் இருக்க வேண்டும், ஒருமை P ஆகியது மாற்றத்தக்கவாறு உயர்ந்த நிலையில் அல்லது நீட்டப்பட்ட நிலையில் இருக்கலாம்.
::::::grammar-box
ஒலிவடிவம் கொண்ட இறுதிகளுக்கு முன், பல வேர்களுக்கு இணைப்பு எழுத்து -i- தோன்றும்.

-re இறுதிக்கு முன் எப்போதும் -i- வர வேண்டும், இது இணைப்பு எழுத்து ஒலிவடிவம் கொண்ட இறுதிகளுக்கு முன் எட்டு வேர்களுக்கு -ṛ அல்லது -u இறுதியில் வராது, அவை:

:::## 40.3. முதல் நபரின் சுயசரிதையியல் முற்றெச்ச வினை வடிவங்களின் உருவாக்கம் (अनुप्रयोगलिट्)

சுயசரிதையியல் முற்றெச்சம் பின்வற்றால் உருவாக்கப்படுகிறது:

*   வகைப்படுத்தப்பட்ட வினை மூலங்கள் (காரகம், விருப்பம், அடிக்கடி, பெயர்ச்சொல்-வினை), குறிப்பாக காரகம்
*   நீண்ட ஒலியால் (ā தவிர) தொடங்கும் மூலங்கள்
*   மூலங்கள்: ஒலி (a- தவிர)-ஒலி-ஒலி
*   சில பிறவற்றால்
*   சில மூலங்களில் இரண்டு முற்றெச்சங்களும் விருப்பமாக உருவாக்கப்படலாம்: uṣ "சூடு", vid "அறிதல்", jāgṛ "விழித்திருத்தல்", daridrā "நீத்தவன்"
*   பின்வரும் மூலங்களில் இரண்டு முற்றெச்சங்களும் விருப்பமாக உருவாக்கப்படலாம் மற்றும் சுயசரிதையியல் முற்றெச்சமும் மீண்டும் வரும், அதாவது முன்னோடி வடிவத்தின் மீண்டும் வரும் எழுத்தால்:
    *   bhī "அஞ்சுதல்"
    *   bhṛ "ஏற்றுதல்"
    *   hu "பலிசெய்தல்"
    *   hrī "நாணுதல்"

:::## 40.4. முதல் பற்றிய இலக்கணம் (तृतीयः)

:::grammar-box
ஒரு வரையறுத்த வினைச்சொல் (சொற்றொடர்ப்படு வினை) காரணத்தை (कर्तृ) வெளிப்படுத்துவதால், "நான்", "நாம்" போன்றவை அசெய்யுள் வினைத்தொடர்களில் வரையறுத்த வினைச்சொல்லுடன் கூடுதலாக ஒரு தனிப்பட்ட பெயர்ச்சொல்லால் வெளிப்படுத்தப்பட வேண்டிய அவசியம் இல்லை.
:::## 40.5. முதல் ஒருமை மற்றும் பன்மை ஆண்பால்/பெண்பால்/நடுவுபால் पुरुषार्थकसर्वनाम தனிநபர் உரிச்சொற்கள்

:::grammar-box
தனிநபர் உரிச்சொல்லின் (தனிப்பட்ட பதிலி) வடிவம் அனைத்து பால் வகைகளுக்கும் ஒன்றே.
:::::::grammar-box

| | **एकवचनम्**[[br]]"நான்" | **बहुवचनम्**[[br]]"நாம்" |
| :---: | :---: | :---: |
| **प्रथमा** | **अहम्** | **वयम्** |
| **द्वितीया** | **माम्** / **मा** | **अस्मान्** / **नस्** |
| **तृतीया** | **मया** | **अस्माभिस्** |
| **चतुर्थी** | **मह्यम्** / **मे** | **अस्मभ्यम्** / **नस्** |
| **पञ्चमी** | **मत्** | **अस्मत्** |
| **षष्ठी** | **मम** / **मे** | **अस्माकम्** / **नस्** |
| **सप्तमी** | **मयि** | **अस्मासु** |

:::::::grammar-box
மேலே இரண்டாவது இடத்தில் உள்ள குறுகிய வடிவங்கள் (मा, मे, नस्) ஒரு வாக்கியத்தின் அல்லது வசனத்தின் தொடக்கத்தில் எப்போதும் பயன்படுத்தக்கூடாது.

च, वा, एव ஆகிய பகுதிகளுக்கு முன் இந்த அழைக்கப்படும் என்க்ளிடிக் வடிவங்களையும் பயன்படுத்தக்கூடாது:

மட்டும்: ... मां च ... "என்னையும்"
::::::grammar-box
தனிநபர் உரிச்சொற்களின் பன்மை (षष्ठी) ஒரு சொத்துக்குறிப்பு உரிச்சொல்லாகப் பயன்படுத்தப்படுகிறது:

मम । मे = "என்"

अस्माकम् । नस् = "நம்"
::::::grammar-box
இந்த உரிச்சொற்களுக்கான சமசுகிருத கலப்பினங்களின் முன் உறுப்பாக இந்த வடிவங்கள் உள்ளன:

*   ஒருமை मद्
*   பன்மை अस्मद्

எ.கா. मत्पुस्तकम् "என் புத்தகம்" ; अस्मद्पुस्तकानि "நம் புத்தகங்கள்"
