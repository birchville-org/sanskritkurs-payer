# பாடம் 14

## 14.1. பெயர்ச்சொற்களால் குறிக்கப்படும் பொருள்களுக்கு இடையேயான உறவின் வெளிப்பாடு: ஆறாம் விபக்கம் (ṣaṣṭhī f. = ⟪षष्टी⟫ = ஆறாம் விபக்க முடிப்பு)

::: grammar-box
இரண்டு பெயர்ச்சொற்களால் வெளிப்படுத்தப்படும் உறவு குறிக்கப்பட வேண்டுமானால், அண்புப் பால் (ṣaṣṭhī f. "ஆறாம் வினைமுற்று") பயன்படுத்தப்படுகிறது. அண்புப் பால், மற்ற அனைத்து வினைமுற்றுகளிலிருந்தும் வேறுபடுகிறது; ஏனெனில், அது -- சில விதிவிலக்குகள் தவிர -- வினையால் வெளிப்படுத்தப்படும் செயலை நெருக்கமாகக் குறிக்கப் பயன்படுவதில்லை, மாறாக, பெயர்ச்சொற்களால் குறிக்கப்படும் நபர்கள் அல்லது பொருட்களுக்கு இடையேயான உறவை வெளிப்படுத்தப் பயன்படுகிறது. அண்புப் பால் பெரும்பாலும் கேள்வி: யாருடைய? என்பதற்கு பதிலாக அமைகிறது.
:::
உதாரணங்கள்:

⟪कवेः⟫ ⟪पुत्रः⟫ "கவிஞரின் மகன்"

⟪धनस्य⟫ ⟪लोभः⟫ "செல்வத்தின் ஆசை"

⟪नगरस्यार्धम्⟫ "நகரத்தின் பாதியளவு"

⟪रामस्य⟫ ⟪कृतम्⟫ "ராமனின் செயல்"

::: grammar-box
சாதாரண வார்த்தை வரிசை:

> **உரிச்சொல் அல்லது பெயர்ச்சொல் — வேறு ஒரு பாலில் உள்ள அருகமை பெயர்ச்சொல்**
:::
**பெயர்ச்சொல் மற்றும் முந்தை கால பண்புவினை விசேஷணம்:**

::: grammar-box
PPP-களில், காரணர் (kartṛ)க்கு கருவிப் பால் (tṛtīyā)க்குப் பதிலாக உரிமைப் பால் (Genetiv) பயன்படுத்தப்படலாம்; கருவிப் பால் அமைப்பில், PPP ஒரு செயலிலா வினைச்சொல் வடிவமாகக் கருதப்படுகிறது (கருவிப் பாலில் உள்ளது காரணரைக் குறிக்கிறது), உரிமைப் பால் அமைப்பில், PPP ஒரு பெயர்ச்சொல் அல்லது விசேஷணமாகக் கருதப்படுகிறது (எனவே உரிமைப் பாலில் உள்ளது உண்மையில் காரணராகக் கருதப்படாது).

பாṇினி 2.3.67 இன்படி, PPP-க்கு உரியது: PPP-க்கு நிகழ்காலப் பொருள் இருந்தால் (மேலே காண்க), பெயரெச்சத்திற்கு உருபு, PPP-க்கு முற்காலப் பொருள் இருந்தால், கருவியெச்சத்திற்கு உருபு:

> ⟪रामस्येष्टं फलम्⟫ "ராமனால் விரும்பப்பட்ட பலன் = ராம் தற்போது விரும்பும் பலன்"
> 
> ⟪रामेणेष्टं फलम्⟫ "ராமனால் விரும்பப்பட்ட பலன்"

இயல்பாக, ஒரு PPP நடுலிங்க ஏகவచ数ம் (Neutrum Singular), இது ஒரு வினைச்சார்பெயராக - அதாவது பெயர்ச்சொல்லாக - பயன்படுத்தப்படும்போது, உரிமை (Genetiv) வரும்.
:::
## 14.2. உரிமை வடிவங்களின் (ṣaṣṭhī f. = ⟪षष्ठी⟫) உருவாக்கம்

வினைமூலங்களுடன் மூல மாற்றத்துடன் (Stammabstufung), பலவீனமான மூலத்திலிருந்து உரிமை வடிவம் உருவாக்கப்படுகிறது.

**ஒலி எழுத்துகளால் முடிவடையும் மூலங்களின் உரிமை:**

::: grammar-box

ஒலி எழுத்துகளுக்குப் பிறகு, வழக்கமான உரிமை முடிப்புகள்:
* ஏகவచ数ம்: **-as**
* பன்மை: **-ām**

:::

**ஒலி வடிவ ஒற்றுமை:**

::: important

a என முடியும் ஆண் மற்றும் நடுப் பெயர்ச்சொற்கள் மற்றும் பெயர்ச்சொல் அல்லாத சொற்களைத் தவிர்த்து, மற்ற அனைத்து பெயர்ச்சொல் தனிமை நிலைகளிலும் ஒலி வடிவத்தில் முடியும் பெயர்ச்சொல் தனிமை நிலை மற்றும் ஐந்தாம் விகாரம் (pañcamī "ஐந்தாவது விகாரம்") ஆகியவை ஒரே மாதிரியான சொல் வடிவத்தைக் கொண்டுள்ளன!
:::
**வடிவ ஒற்றுமை:**

::: important

-a என்ற -a ஆகிய பாலினங்கள் மற்றும் உரிச்சொற்களைத் தவிர்த்து, அனைத்து பெயர் மூலச்சொற்களுக்கும், ஒருமை பண்புப் பால் (Genetiv Singular) வடிவம், ஒருமை விலக்குப் பால் (Ablativ Singular) வடிவத்துடன் ஒன்றாகும் (pañcamī "ஐந்தாம் பண்புப் பால் முடிப்பு").

கொன்சோனண்டால் முடிவடையுமாறு வரும் சொற்றொடர்களில், அபிலேடிவ் மற்றும் ஜெனிட்டிவ் சிங்குலர் ஆகியவை ஆக்கியூசேடிவ் பிளூரல் மஸ்குலினம் மற்றும் ஃபெமினினத்திற்கு சமமாக இருக்கும் என்பதைக் கவனிக்கவும்!

:::
## 14.3. பெயர்ச்சொல் வினையெச்சத்தின் பயன்பாடு பற்றிய மேலும் விவரங்கள் (⟪षष्ठी⟫)

::: grammar-box
மேலுள்ள அடிப்படை விதிக்கு முரணாக, சில வினைகளுக்குப் பொருளைக் குறிக்கப் பெயரெச்சம் பயன்படுத்தப்படுகிறது; எடுத்துக்காட்டாக, நினைவுகூரும் வினைகளில்:

> ⟪देवानां⟫ ⟪स्मरति⟫ "தெய்வங்களை நினைவுகூருகிறார்"

இவ்வாறு அனைத்து வினைச்சொற்களிலும், பொருள் சொல் ஆக்கவியலில் அமைவது சாத்தியமாகும்:

> ⟪देवान्स्मरति⟫ "தெய்வங்களை நினைவுகூறுகிறார்"

மேலும் பின்னர்.
:::

* **jan 4 Ā** (jāyate), Pass. janyate / jāyate, PPP jāta (⟪जन्⟫ ⟪जायते⟫ ⟪जन्यते⟫ ⟪जायते⟫ ⟪जात⟫) : பிறத்தல், உருவாதல், தோன்றல்

  * **uk-ti f.** (⟪उक्ति⟫) : உரை, சொல்

  * **vāk-ya n.** (⟪वाक्य⟫) : சொல், உரை

## 14.5. Subhāṣitāni = ⟪सुभाषितानि⟫ = சொற்கள்

கீழ்க்காணும் பழமொழிகளை மொழிபெயர்க்கவும், அவற்றை மனப்பாடம் செய்யவும்:

**⟪नीचो⟫ ⟪वद⟫அதி ⟪न⟫ ⟪कुरुते⟫** **⟪वदति⟫ ⟪न⟫ ⟪साधुः⟫ ⟪करोत्येव⟫ ⟪॥१॥⟫**

**⟪सत्येन⟫ ⟪जनानां⟫ ⟪सुखं⟫ ⟪भवति⟫ ⟪॥३॥⟫**

**⟪सत्यं⟫ ⟪लोकस्य⟫ ⟪दीपः⟫ ⟪॥५॥⟫**
