# பாடம் 14

## 14.1. பெயர்ச்சொற்களால் குறிக்கப்படும் பொருள்களுக்கு இடையேயான உறவை வெளிப்படுத்தும் வடிவம்: அழைப்பு (ṣaṣṭhī f. = षष्टी = ஆவது அழைப்பு)

::: grammar-box
இரண்டு பெயர்ச்சொற்களால் குறிக்கப்படும் உறவை வெளிப்படுத்த, அழைப்பு (ṣaṣṭhī f. "ஆவது அழைப்பு") பயன்படுத்தப்படுகிறது. அழைப்பு, மற்ற அனைத்து அழைப்புகளிலிருந்தும் வேறுபடுகிறது, ஏனெனில் அது -- சில விதிவிலக்குகள் தவிர -- கிரியையால் வெளிப்படுத்தப்படும் செயலை மேலும் குறிப்பிட பயன்படுத்தப்படுவதில்லை, மாறாக பெயர்ச்சொற்களால் குறிக்கப்படும் நபர்கள் அல்லது பொருட்களுக்கு இடையேயான உறவை வெளிப்படுத்த பயன்படுத்தப்படுகிறது. அழைப்பு பெரும்பாலும் கேள்வி: யாருடைய? என்பதற்கு பதிலளிக்கும்.
:::

உதாரணங்கள்:

कवेः पुत्रः "கவிஞரின் மகன்"

धनस्य लोभः "செல்வத்தின் மீதான ஆசை"

नगरस्यार्धम् "நகரத்தின் பாதியை"

रामस्य कृतम् "ராமனின் செயல் / ஒரு செயல்"

::: grammar-box
சாதாரண வார்த்தை வரிசை:

> **அழைப்பில் உள்ள குறிப்பிட்ட வார்த்தை — வேறு அழைப்பில் உள்ள மேலும் குறிப்பிடப்பட்ட பெயர்ச்சொல்**
:::

**அழைப்பு மற்றும் PPP:**

::: grammar-box
PPP க்கு, அழைப்பு கருவியின் (tṛtīyā) பதிலாக காரணர் (kartṛ) க்கு இருக்கலாம்; கருவியுடன் கட்டமைப்பில், PPP ஒரு செயலற்ற கிரியை வடிவமாக கருதப்படுகிறது (கருவியில் உள்ளது காரணரை குறிக்கிறது), அழைப்புடன் கட்டமைப்பில், PPP ஒரு பெயர்ச்சொல் அல்லது உரிச்சொல்லாக கருதப்படுகிறது (அழைப்பில் உள்ளது உண்மையில் காரணர் அல்ல).

பாணிநி 2.3.67 படி, PPP அழைப்பில், PPP நிகழ்கால அர்த்தம் கொண்டிருந்தால் (மேலே பார்க்கவும்), கருவியில், PPP கால அர்த்தம் கொண்டிருந்தால்:

> रामस्येष्टं फलम् "ராமனால் விரும்பப்பட்ட கனி = ராமன் தற்போது விரும்பும் கனி"
> 
> रामेणेष्टं फलम् "ராமன் விரும்பிய கனி"

நிச்சயமாக, ஒரு PPP நடுநிலை ஒருமை, கிரியை அபசாரமாக - அதாவது பெயர்ச்சொல்லாக - பயன்படுத்தப்படும் போது, அழைப்பு இருக்கும்.
:::

## 14.3. பெயர்ச்சொல் விகுதியின் பயன்பாடு குறித்த மேலும் (षष्ठी)

::: grammar-box
மேலே உள்ள அடிப்படை விதிக்கு மாறாக, பெயர்ச்சொல் விகுதி சில வினைகளுக்கான பொருளைக் குறிக்கப் பயன்படுத்தப்படுகிறது, எ.கா. நினைவுகூரும் வினைகள்:

> देवानां स्मरति "அவர் தேவர்களை நினைவுகூர்கிறார்"

இந்த அனைத்து வினைகளுக்கும் பொருள் பெயர்ச்சொல் விகுதியிலும் இருக்கலாம்:

> देवान्स्मरति "அவர் தேவர்களை நினைவுகூர்கிறார்"

மேலும் விவரங்கள் பின்னர்.
:::

## 14.5. Subhāṣitāni = सुभाषितानि = கவிதைகள்

கீழ்க்காணும் கவிதைகளை மொழிபெயர்க்கவும் மற்றும் அவற்றை மனப்பாடம் செய்யவும்:

**नीचो वदதி न कुरुते** **वदति न साधुः करोत्येव ॥१॥**

**शीलं नरस्य भूषणम् ॥२॥**

**सत्येन जनानां सुखं भवति ॥३॥**

**पापा नराः स्वर्गं न लभन्ते ॥४॥**

**सत्यं लोकस्य दीपः ॥५॥**
