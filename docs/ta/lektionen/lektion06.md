# பாடம் 6

::: deleteme-box
**இந்த பாடத்தில் நீங்கள் கற்றுக்கொள்வது:**
- வினைத்தொடரின் அமைப்பு (காரணன் மற்றும் வினைச்சொல் வடிவம்)
- வினைச்சொல் வடிவங்களின் உருவாக்கம் (பரமஸ்பதம், ஆத்மனேபதம், செயப்படுபொருள்)
- வினையின் முறைகள் மற்றும் காலங்கள்
- விதிவார்த்தை முன்னிலை (லட்) மற்றும் மூன்றாம் முனைவின் முதன்மை முனைகள்
- முன்னிலை மூலச்சொல் உருவாக்கம் (வகுப்புகள் 1, 4 மற்றும் 6)
- ஒலி மாற்றம் (அலௌத்: குணா மற்றும் வ்ருத்தி)
:::
## 6.1. வினைத்தொடர்

::: grammar-box
**அமைப்பு I: வினைச்சொல் வடிவம்**
- எ.கா. **yajati** = ⟪यजति⟫ = "அவர் (அவள், அது) ஒரு பலியால் வணங்குகிறார்", "அவர் (அவள், அது) பலிகொடுக்கிறார்"

**அமைப்பு II: காரகம் (kartṛ m. = ⟪कर्तृ⟫) – வினைச்சொல் வடிவம்**
- எ.கா. **rāmo yajati** = ⟪रामो⟫ ⟪यजति⟫ = "ராமர் ஒரு பலியால் வணங்குகிறார்", "ராமர் பலிகொடுக்கிறார்"
:::
காரகம் (**kartṛ** m. = ⟪कर्तृ⟫) ஒரு வினைத்தொடரில் குறிப்பிடப்படும்போது, அது பண்புத்தொகை அல்லாத நிலையில் இருந்தால், காரகம் **நியமி** (முதல் விகாரம், prathamā = ⟪प्रथमा⟫) இல் இருக்கும். எண்ணளவில் (vacana n. = ⟪वचन⟫) காரகத்திற்கும் வினைச்சொல் வடிவத்திற்கும் ஒற்றுமை இருக்கும்.

## 6.2. வினைச்சொல் வடிவங்களின் உருவாக்கம் பற்றி

ஒரு வரையறுக்கப்பட்ட வினைச்சொல் வடிவம், அதாவது ஒரு தனிநபர் முடிப்புடன் கூடிய வினைச்சொல் வடிவம், சமஸ்கிருதத்தில் பின்வற்றைக் குறிக்கிறது:

1. **பொருள்** (**artha** m. ⟪अर्थ⟫)
2. **பேச்சாளர்** மற்றும் **எண்ணிக்கை** (எண்ணிக்கை, **vacana** n. = ⟪वचन⟫) (நான், நீ, அவர் \<அவள், அது\>, நாங்கள் இருவர், நீங்கள் இருவர், அவர்கள் இருவர், நாங்கள், நீங்கள், அவர்கள்)
3. நடத்தை முறை (genus verbi):
   1. **பரஸ்மைபத** (n. = ⟪परस्मैपद⟫) ("ஒருவருக்குரிய சொல் வடிவம்"): செயல்பாடு. எ.கா. **yajati** = ⟪यजति⟫ = "ஒரு பலியைக் கொண்டு அவர் வழிபடுகிறார்" (அதாவது, வேறு ஒருவருக்காக பலியை நிறைவேற்றும் பிராமணர்)
   2. **ஆத்மனைபத** (n. = ⟪आत्मनेपद⟫) ("தன்னுக்கான சொல் வடிவம்"): நடுநிலை. எ.கா. **yajate** = ⟪यजते⟫ = "ஒரு பலியைக் கொண்டு அவர் தனது நலனுக்காக வழிபடுகிறார்" (அதாவது, தனக்காகவும் தனது குடும்பத்திற்காகவும் பலியை நிறைவேற்றும் பலியாளர்)
   3. **செய்யுள்** (**karman** n. = ⟪कर्मन्⟫). எ.கா. **ijyate** = ⟪इज्यते⟫ = "ஒரு பலியைக் கொண்டு அது வழிபடுகிறது"

பல சந்தர்ப்பங்களில், ஆத்மனைபதத்தின் பொருள் நுணுக்கம் இனி தெரியவில்லை; மேலும் கவிஞர்களும் பரஸ்மைபதத்துடன் பொருள் வேறுபாடு இல்லாமல் ஆத்மனைபதத்தைப் பயன்படுத்துகிறார்கள். இருப்பினும், மொழிபெயர்ப்பின் போது, அத்தகைய பொருள் நுணுக்கம் உள்ளதா என்பதைக் கவனமாகக் கவனிக்க வேண்டும்.

பரஸ்மைபதம் மற்றும் ஆத்மனைபதத்தில் (குறிப்பிட்ட ஆத்மனைபதப் பொருளில்) பயன்படுத்தப்படும் வினைச்சொற்களை **உபயபத**-வினைச்சொற்கள் (**ubhayapada** n. = ⟪उभयपद⟫ = "இரு சொல் வடிவங்கள்") என்று அழைக்கிறார்கள்.

சில வினைச்சொற்கள் பரஸ்மைபதத்திலோ அல்லது ஆத்மனைபதத்திலோ மட்டுமே பயன்படுத்தப்படுகின்றன. இந்த வினைச்சொற்களில், ஆத்மனைபதம் அல்லது பரஸ்மைபதம் குறிப்பிட்ட பொருளைக் கொண்டிருக்கவில்லை. எ.கா. **manyate** = ⟪मन्यते⟫ = "அவர் (அவள், அது) நினைக்கிறார்" (குறிப்பிட்ட ஆத்மனைபதப் பொருள் இல்லாமல்).

4. **சொல்லும் முறை** (Modus):
   1. **சுட்டிய**: கூற்று வடிவம்
   2. **ஆசை**: ஆசை வடிவம் மற்றும் சாத்திய வடிவம்
   3. **கட்டளை**: கட்டளை வடிவம்
5. **நேரம்** (Tempus):
   1. **நிகழ்காலம்**: நிகழ்காலம்
   2. **சங்கீதம்**
   3. **சிறப்பு**
   4. **அகோரிஸ்ட்**
   5. **எதிர்காலம்**: எதிர்காலம்
   6. **நிபந்தனை**

நேரங்கள் கால மூலங்களால் உருவாக்கப்படுகின்றன: நிகழ்கால மூலம், அகோரிஸ்ட் மூலம், சிறப்பு மூலம், எதிர்கால மூலம்.

## 6.3. குறிப்பிடும் நிகழ்காலம் (லட் = ⟪லட்⟫)

நிகழ்காலம் என்பது நிகழ்காலத்தின் காலமாகும், குறிப்பாக நீடித்தல்.

::: grammar-box
**விநியோகப் பெயர்ச்சொல் (அறிவிப்பு வடிவம்) நிகழ்காலம், நிகழ்கால வடிவத்திற்கு பின்னர் அழைக்கப்படும் முதன்மை முடிவுகள் இணைக்கப்படுகின்றன.**
:::
உதாரணங்கள்:

| வேர் (dhātu) | நிகழ்கால வடிவம் | 3. பகுதி ஒருமை விநியோகப் பெயர்ச்சொல் பரமசுபாதம் |
| :--- | :--- | :--- |
| **viś** = ⟪विश्⟫ | **viśa** = ⟪विश⟫ | **viśati** = ⟪विशति⟫ = "அவர் (அவள், அது) நுழைகிறார்" |
| **bhū** = ⟪भू⟫ | **bhava** = ⟪भव⟫ | **bhavati** = ⟪भवति⟫ = "அவர் (அவள், அது) உருவாகிறார்" |
| **nṛt** = ⟪नृत्⟫ | **nṛtya** = ⟪नृत्य⟫ | **nṛtyati** = ⟪नृत्यति⟫ = "அவர் (அவள், அது) நடனமாடுகிறார்" |

## 6.4. மூன்றாம் வேற்றுமைப் பால் வினைச்சொற்களின் முதன்மை இறுதிகள் (prathama m. = ⟪प्रथम⟫ = "முதல் (!) பால்")"

::: grammar-box
| | Singular (Einzahl):brekavacana n.:br⟪एकवचन⟫ | Plural (Mehrzahl):brbahuvacana n.:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **Parasmaipada n.** :br⟪परस्मैपद⟫ | **-ti** :br-⟪ति⟫ | **-nti** :br-⟪न्ति⟫ |
| **Ātmanepada n.** :br⟪आत्मनेपद⟫ | **-te** :br-⟪ते⟫ | **-nte** :br-⟪न्ते⟫ |
:::
உதாரணம் **yaj** = ⟪यज्⟫ = "ஒரு பலியால் வழிபடுதல்", "பலியிடுதல்":
- பெயர்ச்சொல் வடிவம்: **yaja** = ⟪यज⟫
  - 3. ஒருமை ப. **yajati** = ⟪यजति⟫
  - 3. பன்மை ப. **yajanti** = ⟪यजन्ति⟫
  - 3. ஒருமை ஆ. **yajate** = ⟪यजते⟫
  - 3. பன்மை ஆ. **yajante** = ⟪यजन्ते⟫

### 6.5.4. கருப்பொருள் உயிரெழுத்து, கருப்பொருள் நிகழ்கால வகுப்புகள்

## 6.6. பேச்சுவழக்கு சமஸ்கிருதம்: மேலும் கேள்விகள் (ப்ரஷ்ண m. = ⟪ப்ரஷ்ண⟫)

::: grammar-box
- **N. N. kiṃ karoti?** = N.N. ⟪किं⟫ ⟪करोति⟫ = "N. N. என்ன செய்கிறார்?"
- **N. N. (plural) kiṃ kurvanti?** = N.N. ⟪किं⟫ ⟪कुर्वन्ति⟫ = "N.N.s. என்ன செய்கிறார்கள்?"
- (karoti, kurvanti zu **kṛ** = ⟪कृ⟫ 8 U: "செய், செய்")
- **kiṃ kuśalam?** = ⟪किं⟫ ⟪कुशलम्⟫ = "நீங்கள் நலமா? எப்படி இருக்கிறீர்கள்?"
- பதில்: **sarvathā kuśalam** = ⟪सर्वथा⟫ ⟪कुशलम्⟫ = "(எனக்கு) எல்லா வகையிலும் நலம்."
:::

## 6.7. சொற்களஞ்சியம்

::: grammar-box
சமஸ்கிருதத்தில், வினைச்சொற்கள் **மூல வடிவத்தில்** (Wurzel-Form) பட்டியலிடப்படுகின்றன. மூலத்திற்குப் பின் உள்ள எண் **இணைப்பு வகுப்பைக்** (Konjugationsklasse) குறிக்கிறது.

- **P:** மூலம் பரமச்பதத்திற்கு மட்டுமே
- **Ā:** மூலம் ஆத்மனபதத்திற்கு மட்டுமே
- **U:** உபயபதம் ("இரு வடிவங்களும்"): மூலம் பரமச்பதம் மற்றும் ஆத்மனபதம் ஆகிய இரண்டிலும் பயன்படுத்தப்படுகிறது.
- **():** வட்டக்குறிக்குள், 3-வது ஆண்பால் ஒருமை முன்னிலை விசேஷணம் (laṭ) கொடுக்கப்பட்டுள்ளது.
:::
**கீழ்க்காணும் சொற்களைக் கற்றுக்கொள்ளுங்கள்:**
- **yaj** 1 U (yajati) ⟪यज्⟫ ⟪यजति⟫ : ஒரு பலியால் வணங்கு, பலி கொடு
- **bhū** 1 P (bhavati) ⟪भू⟫ ⟪भवति⟫ : ஆகு, உருவாகு, இரு
- **smṛ** 1 P (smarati) ⟪स्मृ⟫ ⟪स्मरति⟫ : நினைவுகூர், நினைவுகொள்
- **nṛt** 4 P (nṛtyati) ⟪नृत्⟫ ⟪नृत्यति⟫ : நடனமாடு
- **nī** 1 U (nayati) ⟪नी⟫ ⟪नयति⟫ : வழிநடத்து, அழைத்துவா
- **man** 4 Ā (manyate) ⟪मन्⟫ ⟪मन्यते⟫ : எண்ணு, கருது
- **muh** 4 P (muhyati) ⟪मुह्⟫ ⟪मुह्यति⟫ : குழப்பமுற்று இரு
- **yudh** 4 Ā (yudhyate) ⟪युध्⟫ ⟪युध्यते⟫ : போர் செய், சண்டையிடு
- **viś** 6 P (viśati) ⟪विश्⟫ ⟪विशति⟫ : நுழை, உள்சேர்
- **sṛj** 6 P (sṛjati) ⟪सृज्⟫ ⟪सृजति⟫ : விடு, வெளியிடு, பிறக்கவிடு

## 6.8. பயிற்சி

**அ) அடைப்புக்குறிக்குள் கொடுக்கப்பட்ட மூலச்சொற்களைக் கொண்டு வினைத்தொடர்களை உருவாக்கவும்:**
1. brāhmaṇas ... (yaj, nṛt, viś, man, yudh, nī, muh)
   ⟪ब्राह्मणस्⟫ ... ⟪यज्⟫, ⟪नृत्⟫, ⟪विश्⟫, ⟪मन्⟫, ⟪युध्⟫, ⟪नी⟫, ⟪मुह्⟫
2. devas ... (nṛt, yudh, smṛ, sṛj)
   ⟪देवस्⟫ ... ⟪नृत्⟫, ⟪युध्⟫, ⟪स्मृ⟫, ⟪सृज्⟫
3. kavis ... (man, smṛ, viś)
   ⟪कविस्⟫ ... ⟪मन्⟫, ⟪स्मृ⟫, ⟪विश्⟫
4. dhenus ... (viś, bhū)
   ⟪धेनुस्⟫ ... ⟪विश्⟫, ⟪भू⟫

**அ) பயிற்சி அ-வில் உருவாக்கப்பட்ட தொடர்களைப் பெண்பால் பலவாக்கில் மாற்றவும்.**

**அ) சமஸ்கிருதத்திற்கு மொழிபெயர்க்கவும்:**
1. ஒரு பலியின் மூலம் அவர் வழிபடுகிறார். (ஒரு பலிக்குரிசலுக்கான பலி ஆசாரியர்)
2. சிவம் நடனமாடுகிறார்.
3. ராமம் வழிநடத்துகிறார்.
4. சூத்திரர்கள் குழப்பமடைகிறார்கள்.
5. க்ஷத்திரிய பெண்கள் உள்ளே வருகிறார்கள்.
6. கர்த்தர் வெளியிடுகிறார்.
7. க்ஷத்திரியர் ஒரு பலியின் மூலம் வழிபடுகிறார். (பலிக்குரிசலாக)
8. சூத்திர பெண்கள் நடனமாடுகிறார்கள்.
9. க்ஷத்திரியர்கள் போரிடுகிறார்கள்.
10. புனித ஆண்கள் வழிநடத்துகிறார்கள்.
11. அவர்கள் நினைவுகூர்கிறார்கள்.
12. யார் (பெண்) நடனமாடுகிறார்?
13. (குறிப்பிடப்பட்ட) பிராமணர் நடனமாடுகிறார்.
