# பாடம் 21

## 21.1. -nt என்ற முன்னிலைத் தொடர்கள் தொடர்பான கூடுதல் தகவல்கள்

### 21.1.1. நிகழ்காலப் பண்பெச்சம் (⟪लडादेशः⟫) பரமஸ்பதம்

::: grammar-box
இந்த பகுத்தெச்சம் என்பது முன்னிலை மூலத்திலிருந்து உருவான பெயர்ப்பொருள் ஆகும், எனவே இது ஒரு உண்மையான பகுத்தெச்சமாகும். இது ஒரு வினைமுற்றுப் பண்புச்சொல் ஆகும், இது ஒருவர் அல்லது ஏதேனும் ஒரு வினைமூலம் (+ முன்னொட்டு) மூலம் வெளிப்படுத்தப்படும் செயலை மற்றொரு செயல் நடைபெறும் போது செய்கிறது என்று குறிக்கிறது. நிலையான நிலையையும் இது மூலம் வெளிப்படுத்தலாம்.

**உதாரணங்கள்:**

:::

"அப்பா படிக்கும்போது, அவர் புகைபிடிக்கிறார் = படிக்கும் அப்பா புகைபிடிக்கிறார்"  
"ஒரு இருப்பவன் (= உண்மையான, உண்மையான) நண்பர்"

## 21.3. மரியாதையான அழைப்பு வடிவங்கள்

::: grammar-box
**சமஸ்கிருதத்தில், அவதூறாக இல்லாமல், இரண்டாம் நபரில் ஒருவரை அழைக்கலாம். ஆனால் மரியாதையாக இருக்க விரும்பினால், "மதிக்கத்தக்கவர்" என்ற பொருள் கொண்ட ஒரு பெயர்ச்சொல்லைப் பயன்படுத்தி, வினையை மூன்றாம் நபரில் ஒருமை அல்லது பன்மைக்கு மாற்றலாம் அல்லது செயப்படுநிலையைப் பயன்படுத்தலாம். அழைப்பில் நபர் பயன்பாட்டில் மரியாதையின் அதிகரிப்பு தோராயமாக பின்வருமாறு:**

:::
::: indent
**2. பி. » 2. பி. » 3. பி. தொடர்புடைய பெயருடன் » 3. பி. தொடர்புடைய பெயருடன்**
:::
**இந்த மரியாதைப் பெயர்களில் மிக முக்கியமானது ⟪भवन्त्⟫ , பெண்பால்: ⟪भवती⟫ . இது எங்கள் மரியாதையான "நீங்கள்" என்பதற்கு இணையானது.**
இந்த ⟪भवन्त्⟫ என்பது ⟪भगवन्त्⟫ இன் சுருக்கமாகும், இது **-vant** (பார்க்க [பாடம் 13](lektion13.md)) பெயர்களுக்கான விளிவழக்கு. இந்த ⟪भवन्त्⟫ என்பது ⟪भू⟫ "ஆவது" ⟪भवन्त्⟫ ஆகியவற்றின் முன்னிலைப் பண்புச்சொல் P இலிருந்து வேறுபடுத்தப்பட வேண்டும்: ⟪भवन्त्⟫ "நீங்கள்" ஆகியவற்றின் பெயரொன்றின் ஆண்பால் ⟪भवान्⟫, பண்புச்சொல் ⟪भवन्⟫ ஆகியவற்றின் பெயரொன்றாகும்.

**உதாரணங்கள்:**

::: indent
**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = "நீங்கள் என்ன செய்கிறீர்கள்?"
:::
மரியாதையுடன்:

::: indent
**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**
:::
பெண்பால்:

::: indent
**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**
:::
⟪भवन्त्⟫ போலவே பயன்படுத்தக்கூடிய பிற சொற்கள்:

*   ⟪आर्य⟫ (பெண்பால்: ⟪आर्या⟫) "அரியவர்". எ.கா. **⟪यदार्य⟫ ⟪इच्छति⟫** "உங்கள் விருப்பம் என்ன?"
*   ⟪महाभाग⟫ "யாருக்குப் பங்கு/வாய்ப்பு பெரியவரோ = அரியவர்". பெண்கள் ஆண்களை அழைக்கும்போதோ அல்லது நல்ல நிலையினரான ஆண்களைப் பற்றிப் பேசும்போதோ அடிக்கடி பயன்படுத்தப்படுகிறது. நவீன பேச்சுச் சமஸ்கிருதத்தில் மிகவும் பொதுவானது.

ஒருவருக்கு வெறும் மரியாதையல்ல, மாறாக பக்தியையும் வெளிப்படுத்த விரும்பினால், அருகில் அல்லது இருக்கும் ஒருவருக்கு ⟪भवन्त्⟫ ⟪अत्रभवन्त्⟫ என்பதற்குப் பதிலாக ⟪तत्रभवन्त्⟫ பயன்படுத்தப்படுகிறது. ⟪अत्रभवन्त्⟫ மற்றும் ⟪तत्रभवन्त्⟫ ஆகியவற்றை "நீங்கள்", "மதிப்புக்குரியவர்", "பெருமையுடையவர்" என்று மொழிபெயர்க்கலாம்:

::: indent
**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = "அருள்புரிவதில் (இங்கு இருக்கும்) பெண்ணா உங்கள் மனைவி?"  
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (கடிதம் அல்லது தொலைபேசி உரையாடலில்) = "நீங்கள் நலமாக இருக்கிறீர்களா?"
:::
