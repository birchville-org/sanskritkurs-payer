# பாடம் 26

## 26.1. வார்த்தையின் உள்ளே -s- க்கான மூளைமாற்ற விதி

:::grammar-box
**-s-** என்பது **-ṣ-** ஆக மாற்றப்படுகிறது, **k, r, l** அல்லது **ஒலி** — **a, ā** தவிர — **⟪अनुस्वार⟫** அல்லது **⟪विसर्ग⟫** மூலம் பிரிக்கப்பட்டிருந்தால் அல்லது நேரடியாக முன்னால் வந்தால், மற்றும் **ṛ, r** தவிர வேறு ஒலி பின்னால் வந்தால்.

இந்த சந்தி **⟪दुस्⟫-** க்கும் பின்பற்றப்படுகிறது, அது கீழ்நிலை மற்றும் லேபியல்களுக்கு முன் கலப்பில்.
:::
*உதாரணங்கள்:*
:::indent
**⟪तेषाम्⟫** (வழி: *te-sām*)

ஆனால்: **⟪तासाम्⟫** (*tā-sām*)
:::
## 26.2. வார்த்தையின் உட்பகுதியில் அடங்கிய பற்கள் தொடர்பான மூளைப்படுத்தல் விதி

:::grammar-box
பின்னடைவு எழுத்துக்களுக்குப் (**-ṣ-** உட்பட) பின்னர் வரும் பற்கை அடைவு எழுத்துக்கள், அவற்றிற்கு ஏற்ப பின்னடைவு எழுத்துக்களால் மாற்றப்படுகின்றன:

- **iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
  *(**ṣ** முன்னர் வரும் **i** காரணமாக, **ṭh** பின்னர் வரும் **ṣ** காரணமாக)*
:::
## 26.3. வார்த்தை சந்தி மெய்யொலிகள், கழுத்து ஒலிகள், ṣ, h + -s

:::grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

எடுத்துக்காட்டுகள் கீழே காணலாம்
:::
## 26.4. கிராஸ்மேனின் மூச்சு ஒற்றுமை நீக்க விதி

::::grammar-box
**இரண்டு மூச்சொலிகளின் (மூச்சொலி - உயிர் - மூச்சொலி) நேரடி விளைவு, முதல் ஒலியின் மூச்சு இழப்பை ஏற்படுத்துகிறது:**

உதாரணம்:

:::indent
\*dhu(gh) » du(g)h
:::
**ஒலிநிலைகளின் காரணமாக இரண்டாவது ஒலி தனது மூச்சை இழந்தால், முதல் ஒலியில் மூச்சு மீண்டும் தோன்றும்.**

உதாரணங்கள்: கீழே உள்ள ⟪दुह्⟫ மற்றும் ⟪बुध्⟫ ஆகியவற்றின் எதிர்காலம் பார்க்கவும்
:::::::media
![](/images/lekt2601.webp)
வரைபடம்: ஹெர்மான் கிராஸ்மேன்

## 26.5. வார்த்தசந்தி -m, -n முன் உயிரெழுத்துக்களுக்கு

:::grammar-box
**உயிரெழுத்துக்களுக்கு முன் -n மற்றும் -m ஆகியவை -ṃ- ஆல் மாற்றப்படுகின்றன:**

உதாரணம்: பார்ப்பீர் கீழே ⟪मन्⟫ இன் எதிர்காலம்
:::
## 26.6. எளிய எதிர்காலத்தின் பயன்பாடு (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ப.)

:::grammar-box
**எளிய எதிர்காலம் (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ப.) பின்வற்றைக் குறிக்கிறது:**

- **எதிர்காலம்**
- **ஒரு எண்ணப்பட்ட அல்லது விரும்பப்பட்ட செயல் ("நான் செல்வேன்", "நான் செல்ல விரும்புகிறேன்")**
- **ஒரு எதிர்பார்ப்பு ("அது இவ்வாறு நடக்கும்")**
- **நம்பிக்கை**
- **அச்சம்**
- **நிகழ்தகவு**
**பேசுவோரின் கருத்து**
- **கட்டளை**

**எதிர்காலம் பகுதியாக ஆசீர்வாதத்திற்கு எதிர்ப்பில் உள்ளது (பின்னர் பார்க்கவும்).**
:::
உதாரணமாக, ⟪व्रतं⟫ ⟪करिष्यन्देवगृहं⟫ ⟪गच्छति⟫ = "ஒரு வாக்குறுதியை நிறைவேற்ற விரும்பும் ஒருவர், கோவிலை நோக்கிச் செல்கிறார்."

## 26.7. எளிய எதிர்காலத்தின் உருவாக்கம் (⟪ऌत्⟫, ⟪भविष्यन्ती⟫  f.)

::::grammar-box
**எளிய எதிர்காலம்:**

:::indent
**எதிர்கால மூலம் + முதன்மை முற்று**
:::::::::::grammar-box
**எதிர்கால மூலம்:**

:::indent
**(பொதுவாக) உயர்நிலை வேர் + -sya**  
**அல்லது**  
**(பொதுவாக) உயர்நிலை வேர் + -i- + -sya (= - iṣya)**
:::
**எந்த வேர் எந்த எதிர்கால மூல உருவாக்கத்தைக் கொண்டுள்ளது என்பதை, மூல வடிவங்களுடன் கற்றுக்கொள்ள வேண்டும்!**  
**பொதுவாக, வேர் வடிவம் மற்றும் எதிர்காலத்தின் இணைப்பு உயிர் எழுத்து ஆகியவை பெயர்ச்சொல்லுடன் ஒத்துப்போகும்.**  
**சில வேர்கள், எதிர்காலத்தை இணைப்பு உயிர் எழுத்து -i- உடனும், இல்லாமலும் விருப்பத்திற்கு உருவாக்கலாம்.**  
**எதிர்காலத்தின் பரமைப்பதத்தின் பங்கேற்பி, எதிர்கால மூலத்திற்கு -nt- பின்னசொற்றை இணைப்பதன் மூலம் உருவாக்கப்படுகிறது, பெண்பால் விருப்பத்திற்கு -ntī அல்லது -tī மீது:**

:::indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::::::
