# பாடம் 26

## 26.1. சொல் உள்ளே -s- க்கான மூளைப்படுத்தல் விதி

::: grammar-box
**-s-** என்பது **-ṣ-** ஆக மாற்றப்படுகிறது, மேலும் **k, r, l** அல்லது ஒரு **ஒலி** — **a, ā** தவிர்த்தவை — உடனடியாக அல்லது ⟪अनुस्वार⟫ அல்லது ⟪विसर्ग⟫ மூலம் பிரிக்கப்பட்டிருந்தால், மற்றும் வேறு ஒரு ஒலி **ṛ, r** அல்லாதது தொடர்ந்து வந்தால்.

இந்த சந்திக்குப் பிறகு, **⟪दुस्⟫-** என்பது ஒலியில்லா வாய் எழுத்துக்கள் மற்றும் உதட்டு எழுத்துக்களுக்கு முன் சமசுகிருதச் சொற்றொடர்களில் வருகிறது.
:::
*எடுத்துக்காட்டுகள்:*
::: indent
⟪तेषाम्⟫ (இதிலிருந்து: *te-sām*)

ஆனால்: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. சொல்லின் உட்பகுதியில் உள்ள தந்தங்களிற்கான மூளைப்படுத்தல் விதி

::: grammar-box
பற்கள் மூடி அடைப்பு ஒலிகள், பின்னடைவு ஒலிகளால் (**-ṣ-** உட்பட) பதிலீடு செய்யப்படுகின்றன:

- **iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
  *(**ṣ** முந்தைய **i** காரணமாக, **ṭh** பின்வரும் **ṣ** காரணமாக)*
:::
## 26.3. பல்லவ, கண்ப்ப, ṣ, h + -s ஆகியவற்றிற்கான வார்த்தை சந்தி

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

உதாரணங்கள் கீழே காண்க
:::
## 26.4. கிராஸ்மனின் மூச்சு ஒற்றுமை நீக்க விதி

::: grammar-box
**இரண்டு அச்பிரேட்டாக்களின் (அச்பிரேட்டா - உயிர் - அச்பிரேட்டா) நேரடி விளைவு, முதல் எழுத்தின் மூச்சு இழப்பை விளைவிக்கிறது:**

உதாரணம்:

:::
::: indent
*dhu(gh) » du(g)h
:::
**ஒலிவழிபடிநிலைகளினால் இரண்டாவது ஒலியின் மூச்சு இழக்கப்படுமானால், அந்த மூச்சு முதல் ஒலியில் மீண்டும் தோன்றும்.**

உதாரணங்கள்: கீழே உள்ள दुह् மற்றும் बुध् ஆகியவற்றின் எதிர்காலம் பார்க்கவும்

## 26.5. -m, -n முன் இயைபு

::: grammar-box
**ஒலிப்பு விதிகளின்படி, -n மற்றும் -m ஆகியவை -ṃ- ஆல் மாற்றப்படுகின்றன:**

உதாரணம்: கீழே பார்த்து Futur வடிவம் ⟪मन्⟫

## 26.6. எளிய எதிர்கால பயன்பாடு (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ பெண்பால்)

::: grammar-box
**எளிய எதிர்காலம் (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ பெ.) பின்வருவற்றைக் குறிக்கிறது:**

- **எதிர்காலம்**
- **ஒரு குறிக்கப்பட்ட அல்லது விரும்பப்பட்ட செயல் ("நான் செல்வேன்", "நான் செல்ல விரும்புகிறேன்")**
- **ஒரு எதிர்பார்ப்பு ("அது இவ்வாறு நடக்கும்")**
- **நம்பிக்கை**
- **அச்சம்**
- **சாத்தியக்கூறு**
- **பேச்சாளரின் கருத்து**
- **கட்டளை**

**எதிர்காலம் சில சமயங்களில் விசேடப் பொருளிற்குப் போட்டியாக அமைகிறது (பின்னர் காண்க).**
:::
எ. கா. ⟪व्रतं⟪करिष्यन्देवगृहं⟫ ⟪गच्छति⟫ = "ஒரு வாக்குறுதியை நிறைவேற்ற விரும்பும் ஒருவர் கோவிலுக்குச் செல்கிறார்."

## 26.7. எளிய எதிர்காலம் உருவாக்கம் (⟪ऌत्⟫, ⟪भविष्यन्ती⟫  f.)

::: grammar-box
**எளிய எதிர்காலம்:**

:::
::: indent
**எதிர்கால வினைமுற்று + முதன்மை முற்று**
:::
::: grammar-box
**எதிர்கால வினைமுற்று:**

:::
::: indent
**(பெரும்பாலும்) உயர்நிலை மூலம் + -sya**  
**அல்லது**  
**(பெரும்பாலும்) உயர்நிலை மூலம் + -i- + -sya (= - iṣya)**
:::
**எந்த மூலம் எந்த எதிர்கால வடிவத்தைக் கொண்டுள்ளது என்பதை, மூல வடிவங்களுடன் கற்றுக்கொள்ள வேண்டும்!**  
**பொதுவாக, மூல வடிவம் மற்றும் இணைப்பு உயிரெழுத்தானது, வினைச்சொல்லுடன் ஒத்துப்போகும்.**  
**சில மூலங்கள், இணைப்பு உயிரெழுத்து -i- உடனும், இல்லாமலும், எதிர்காலத்தை விருப்பமாக உருவாக்கலாம்.**  
**எதிர்காலத்தின் பரமஸ்பத பாகுபாதத்தின், எதிர்கால வடிவத்திற்கு -nt- என்ற பின்னொட்டை இணைத்து உருவாக்கப்படுகிறது, பெண்பால் விருப்பமாக -ntī அல்லது -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
உதாரணங்கள்:
