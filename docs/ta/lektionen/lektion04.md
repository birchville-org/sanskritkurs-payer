# பாடம் 4

:::deleteme-box
**இந்த பாடத்தில் நீங்கள் கற்றுக்கொள்வீர்கள்:**
- நேர்மை வினா உரிச்சொற்கள் மற்றும் நேர்மை அசைவு உரிச்சொற்கள்
- இறுதி -m இன் சந்தி
- இறுதி -e இன் சந்தி
- இறுதி -d இன் சந்தி
- எளிய வினா வார்த்தைகள்
:::## 4.1. எளிய நிரப்புக் கேள்விகள் (சொல் கேள்விகள்) மற்றும் பதில்கள்

### 4.1.1. வினாவுரிச்சொற்களும் அசைவுரிச்சொற்களும்

#### 4.1.1.1. வினாவுரிச்சொல் (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

:::grammar-box
| | ஒருமை பெயர்ச்சொல் | பலர்மை பெயர்ச்சொல் |
| :--- | :--- | :--- |
| **நடுமை** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **பால்மை** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **பெண்பால்மை** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::#### 4.1.1.2. அசைவுரிச்சொல் (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

:::grammar-box
| **அடிச்சொற்கள்** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"அவர், அவள், அது; அது, அது, அது":br(ஒன்றைக் குறிப்பது)** | **etad = ⟪एतद्⟫:br"இவர், இவள், இது":br(பேசுபவருக்கு மிக அருகில்)** | **idam = ⟪इदम्⟫:br"இவர், இவள், இது":br(அருகில்)** |
| **ஒருமை பெயர்ச்சொல்** ||||
| **நடுமை** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **பால்மை** | **sa, so saḥ = ⟪स⟫ ⟪सो⟫ ⟪सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष⟫ ⟪एषो⟫ ⟪एषः⟫** | **ayam = ⟪अयम्⟫** |
| **பெண்பால்மை** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **பலர்மை பெயர்ச்சொல்** ||||
| **நடுமை** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **பால்மை** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **பெண்பால்மை** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::**ஒருமை பெயர்ச்சொல் பால்மைக்கு:**
- **sa, eṣa** (⟪स⟫ ⟪एष⟫) என்பது **சிறிய -a** தவிர அனைத்து ஒலிகளுக்கும் முன் வரும்
- **so, eṣo** (⟪सो⟫ ⟪एषो⟫) என்பது **-a** க்கு முன் வரும், இது Avagraha மூலம் நீக்கப்படும் (வெளியேற்றப்படும்)
- **saḥ, eṣaḥ** (⟪सः⟫ ⟪एषः⟫) என்பது நிறுத்தத்தில் (வாக்கிய முடிவு, பாடல் முடிவு) மட்டுமே வரும்

இந்த உரிச்சொற்களைக் (sarvanāman n.) கொண்டு வாக்கியங்களை உருவாக்க, பின்வரும் சந்தி விதிகளை அறிந்து கொள்ள வேண்டும்:

### 4.1.2. வார்ப்புருவத்தின் கடைசியில் உள்ள -m

:::grammar-box
**ஒலிப்புக்கூறு எழுத்துக்களுக்கு முன் கடைசியில் உள்ள -m, அனுஸ்வாரா (-ṃ) ஆல் மாற்றப்படும். வாக்கியம் அல்லது வசனத்தின் கடைசியிலும், ஒலிப்புக்கூறு எழுத்துக்களுக்கு முனும் -m நிலைநிறுத்தப்படும்.**
:::### 4.1.3. இறுதியில் வரும் -e இன் சந்தி

:::grammar-box
1. **a- விற்கு முன் -e மாறாமல் இருக்கும்: தொடக்கத்தில் வரும் a- Avagraha மூலம் நீக்கப்படும்:**
   எ.கா. ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ "இந்த அக்னிகள்"

2. **குறுகிய a- தவிர்த்த பிற சுவரங்களுக்கு முன் -e பொதுவாக -a ஆல் மாற்றப்பட்டு, இடைவெளி விடப்படும். -ay ஆல் மாற்றுவதும் நிகழ்கிறது:**
   எ.கா. ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (அரிதாக: imay īśvarāh = ⟪इमयीश्वराः⟫) "இந்த ஆண்டவர்கள்"
:::### 4.1.4. வாய்மைச் சந்தி: இறுதியில் வரும் -d

:::grammar-box
**இறுதியில் வரும் -d, நிறுத்தக்குறிக்கு முன்னரும், ஒலியில்லாத கண்டிய ஒலிகள் (k, kh) மற்றும் உதட்டு ஒலிகள் (p, ph) க்கு முன்னரும் -t ஆக மாற்றப்படுகிறது.**

பிற ஒலிகளுக்கு முன் வரும் மாற்றம் பின்னர் விவரிக்கப்படும். இத்தகைய ஒலி மோதல்களை தற்காலிகமாக தவிர்க்கவும்!
:::### 4.1.5. கேள்வி வடிவங்கள்

இந்த உரிச்சொற்களைக் கொண்டு, எடுத்துக்காட்டாக, பின்வரும் கேள்வி வடிவங்களை உருவாக்குகிறோம்:

குறிப்பு: நீங்கள் உங்கள் தற்போதைய சமசுகிருத அறிவுடன் இந்தக் கேள்விகளுக்கு அளிக்கும் பதில்கள், எல்லா வகைகளிலும் இயல்பான சிறந்த சமசுகிருதத்திற்கு இன்னும் பொருந்தாது.

## 4.2. பயிற்சி

**அ) பின்வரும் சொற்களுடன் viṣṇuḥ kaḥ (⟪विष्णुः⟫ ⟪कः⟫) என்ற வடிவத்தின் படி வாய்வாராகக் கேள்விகளை எழுப்பி, அவற்றிற்குச் சமசுகிருதத்தில் பதிலளிப்பீர்:**

śruti, śiva, brāhmaṇa, dvija (பன்மை), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**ஆ) பின்வரும் வாசிப்பப் பயிற்சிக்கென etat kim (⟪एतत्किम्⟫) என்ற வடிவத்தின் படி கேள்விகளை எழுப்பி, கொடுக்கப்பட்ட சொற்கள் மற்றும் அசைவுப் பெயர்ச்சொற்களைக் கொண்டு, எ.கா. eṣa bālaḥ (⟪एष⟫ ⟪बालः⟫) என்ற வடிவத்தில் பதிலளிப்பீர்:**
