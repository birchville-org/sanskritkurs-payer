## 4.1. எளிய நிரப்பு வினாக்கள் (சொல் வினாக்கள்) மற்றும் பதில்கள்

### 4.1.1. Fragepronomina und Demonstrativpronomina

#### 4.1.1.1. வினாச்சொற்கள் (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | ஒருமை வினைமுற்று | பன்மை வினைமுற்று |
| :--- | :--- | :--- |
| **நடுவினம்** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **புலன்வினம்** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **பெண்பால்** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. குறிப்புப் பெயர்ச்சொற்கள் (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **குலங்கள்** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"er, sie, es; der, die, das":br(Erwähnte)** | **etad = ⟪एतद्⟫:br"dieser, diese, dieses":br(dem Sprechenden sehr Nahe)** | **idam = ⟪इदम्⟫:br"dieser, diese, dieses":br(Nahe)** |
| **பெயர்ச்சொல் ஒருமை** ||||
| **பால்: நடு** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **பால்: ஆண்** | **sa, so saḥ = ⟪स⟫ ⟪सो⟫ ⟪सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष⟫ ⟪एषो⟫ ⟪एषः⟫** | **ayam = ⟪अयम्⟫** |
| **பால்: பெண்** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **பெயர்ச்சொல் பன்மை** ||||
| **பால்: நடு** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **பால்: ஆண்** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **பால்: பெண்** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**பெ.ஒ.ஆ.க்கு:**
- **sa, eṣa** (⟪स⟫ ⟪एष⟩) என்பது குறுகிய **-a** தவிர அனைத்து ஒலிகளுக்கும் முன் வரும்.
- **so, eṣo** (⟪सो⟫ ⟪एषो⟫) என்பது **-a** முன் வரும், இது அகரஹ மூலம் நீக்கப்படும் (வெளியேறும்).
- **saḥ, eṣaḥ** (⟪सः⟫ ⟪एषः⟫) என்பது இடைவெளியில் (வாக்கிய முடிவு, பாடல் முடிவு) மட்டுமே வரும்.

இந்த सर्वनामன் (sarvanāman n.) உரிச்சொற்களைக் கொண்டு வாக்கியங்களை உருவாக்க, பின்வரும் சந்தி விதிகளை அறிவது அவசியம்:

### 4.1.2. Sandhi von auslautendem -m

::: grammar-box
**ஒலிப்பு முடிவில் உள்ள -m என்பது உயிரெழுத்துக்களுக்கு முன் Anusvāra (-ṃ) ஆக மாற்றப்படுகிறது. வாக்கியம் அல்லது வரி முடிவில் மற்றும் உயிரெழுத்துக்களுக்கு முன் -m மாறாது.**
:::
### 4.1.3. -e இன் Sandhi

::: grammar-box
1. **a- முன்னால் -e மாறாது: தொடக்க a- எலிடிக்கப்பட்டு அகிராகஹா மூலம் இணைக்கப்படும்:**
   எ.கா. ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ "இந்த அக்னிகள்"

2. **சுருக்கமான அல்லாத பிற உயிரெழுத்துக்களுக்கு முன் -e என்பது பொதுவாக -a ஆல் ஹியாட்டஸ் மூலம் மாற்றப்படுகிறது. -ay மூலம் மாற்றமும் நிகழ்கிறது:**
   எ.கா. ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (அரிதாக: imay īśvarāh = ⟪इमयीश्वराः⟫) "இந்த ஆண்டவர்கள்"
:::
### 4.1.4. -d இன் சந்தி

::: grammar-box
**இறுதியில் வரும் -d என்பது இடைவெளியிலும், ஒலி இல்லாத வாய்மொழி எழுத்துக்களுக்கு முன்னரும் (k, kh) மற்றும் உதட்டு எழுத்துக்களுக்கு முன்னரும் (p, ph) -t ஆக மாற்றப்படுகிறது.**

பிற ஒலிக்குரல்களுக்கு முன் மாற்றம் பின்னர் விவரிக்கப்படும். இதுவரை அத்தகைய ஒலி மோதல்களைத் தவிர்க்கவும்!
:::
### 4.1.5. கேள்வி வடிவங்கள்

இந்த உரிச்சொற்கள் மூலம், எடுத்துக்காட்டாக, பின்வரும் கேள்வி வடிவங்களை உருவாக்குகிறோம்:

மற்ற கேள்விகளுக்கான ஒரு எடுத்துக்காட்டு:

> viṣṇuḥ kaḥ? = ⟪विष्णुः⟫ ⟪कः⟫ பதில்: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (இங்கு பெயர்ப் பத்தின் பொருள், கேள்வியுடன் தொடர்பு கொள்ள, உதாரணமாக, பொருளை தொடக்கத்தில் வைக்கலாம்.)

குறிப்பு: உங்கள் தற்போதைய சமஸ்கிருத அறிவுடன் நீங்கள் அத்தகைய கேள்விகளுக்குத் தரக்கூடிய பதில்கள், இயல்பாகவே, அனைத்து விதமான விஷயங்களிலும் இயல்பான சிறந்த சமஸ்கிருதத்திற்கு இன்னும் பொருந்தாது.

## 4.2. Übung

**அ) பின்வரும் சொற்களுடன் viṣṇuḥ kaḥ (⟪विष्णुः⟫ ⟪कः⟫) என்ற வடிவத்தின் படி வாய்வாராகக் கேள்விகளை எழுப்பி, அவற்றிற்குச் சமசுகிருதத்தில் பதிலளிப்பீர்:**

śruti, śiva, brāhmaṇa, dvija (பன்மை), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**ஆ) பின்வரும் வாசிப்பப் பயிற்சிக்கென etat kim (⟪एतत्किम्⟫) என்ற வடிவத்தின் படி கேள்விகளை எழுப்பி, கொடுக்கப்பட்ட சொற்கள் மற்றும் அசைவுப் பெயர்ச்சொற்களைக் கொண்டு, எ.கா. eṣa bālaḥ (⟪एष⟫ ⟪बालः⟫) என்ற வடிவத்தில் பதிலளிப்பீர்:**
