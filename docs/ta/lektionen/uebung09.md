# பாடம் 9

A) பின்வரும் சொற்களின் சாத்தியமான அர்த்தங்களைக் கண்டறிய முயற்சிக்கவும்:

1\. brāhmānaka ⟪ब्राह्मणक⟫ : m. ஒரு பிராமணனுக்கு ஒத்தவர் = ஒரு மோசமான பிராமணன்

2\. mati ⟪मति⟫ : f. கருத்து

3\. śravaṇa ⟪श्रवण⟫ : n. காது

4\. dhenuka ⟪धेनुक⟫ : m. (கோபம்) ஒரு பசுவின் வகையில்

5\. jayaka ⟪जयक⟫ : 3 வெற்றிகரமான

6\. rakṣikā ⟪रक्षिका⟫ : f. காவலர், காவல்

7\. karṣaka ⟪कर्षक⟫ : 3 பயிர்செய்பவர் ; m. விவசாயி

8\. kleśa ⟪क्लेश⟫ : m. வேதனை

9\. nāyikātva ⟪नायिकात्व⟫ : n. ஒரு காதலியின் நிலை

10\. tantraka ⟪तन्त्रक⟫ : 3 (சமீபத்தில்) நெசவுத் துணை / நெசவு எந்திரத்திலிருந்து வந்தது = புதிதாக நெய்யப்பட்டது

11\. nartaka (f. nartakī) ⟪नर्तक⟫ (⟪नर्तकी⟫) : நடனக்காரர்

12\. naraka ⟪नरक⟫ : m. நரகம்

13\. lābhaka ⟪लाभक⟫ : m. = lābha

14\. īśvaratā ⟪ईश्वरता⟫ : f. இறைவன்-நிலை

15\. dhenukā ⟪धेनुका⟫ : f. = dhenu

16\. yodhaka ⟪योधक⟫ : m. போராளி

17\. kopa ⟪कोप⟫ : m. கோபம்

18\. veśaka ⟪वेशक⟫ : 3 நுழையும்

19\. darśaka ⟪दर्शक⟫ : 3 காண்பவர்

20\. kopaka ⟪कोपक⟫ : 3 எளிதில் கோபப்படும் நபர், விரைவு கோபம்

B) மொழிபெயர்க்கவும்:

1\. இருமுறை பிறந்தவர்களின் அனைத்து கடமைகளும்:

ijyādhyayanadānāni ⟪इज्याध्ययनदानानि⟫

(யாஞ்ஞவல்க்கியதர்மசாஸ்திரம் I, 118)

பலி, வேதபடிப்பு, அளித்தல்.

2\. ஒரு பிராமணனின் குறிப்பிட்ட கடமைகள்:

pravacanayājanapratigrahāḥ ⟪प्रवचनयाजनप्रतिग्रहाः⟫

(கௌதமதர்மசூத்திரம் X,2)

பாடம், பலி, அளித்தல்.

3\. ஒரு க்ஷத்திரியனின் குறிப்பிட்ட கடமைகள்:

rakṣaṇaṃ sarvabhūtānām ⟪रक्षणं⟫ ⟪सर्वभूतानाम्⟫

(sarvabhūtānām = Genetiv (Wesfall): "அனைத்து உயிர்களின்")

(கௌதமதர்மசூத்திரம் X,7)

அனைத்து உயிர்களையும் காத்தல்.

4\. ஒரு வைசியனின் குறிப்பிட்ட கடமைகள்:

kṛṣivāṇijyapāśupālyakusīdam ⟪कृषिवाणिज्यपाशुपाल्यकुसीदम्⟫

(கௌதமதர்மசூத்திரம் X,49 படி)

விவசாயம், வணிகம், பசுக்கள் மற்றும் பணம் கடன்.

5\. ஒரு சூத்திரனின் கடமைகள்:

dvijātīnāṃ śuśrūṣā vārttā kārukuśīlavakarma ca. ⟪द्विजातीनं⟫ ⟪शुश्रूषा⟫ ⟪वार्त्त्ता⟫ ⟪कारुकुशीलवकर्म⟫ ⟪च⟫

(கௌடிலீய-அர்த்தசாஸ்திரம் 1.3.8. படி)

விளக்கம்:
dvijātīnām = Genetiv (Wesfall) Plural to dvijāti (மொழிபெயர்க்கவும்: "இருமுறை பிறந்தவர்களுக்கு எதிராக")

kārukuśīlavakarma என்பது ஒரு Tatpuruṣa (kārukuśīlava) முன்னங்கீழில் ஒரு Dvandva (kārukuśīlava) உள்ளது. karma = Nom. sg. to karman n. "செயல், செயல், கர்மா" க்கான வர்ஷ kṛ 8 U). "செயல் / செயல் ... (Genetiv)" (Dvandva மூலம் குறிக்கப்பட்டது) மொழிபெயர்க்கவும்.

இருமுறை பிறந்தவர்களுக்கு கீழ்ப்படிதல், வாழ்க்கைக்கான செயல்கள், கைவினைஞர் அல்லது பயணிக்கும் காட்சியாளராக செயல்.

6\. kṛṣiḥ pāśupālyaṃ vaṇijyā ca vārttā. ⟪कृषिः⟫ ⟪पाशुपाल्यं⟫ ⟪वणिज्या⟫ ⟪च⟫ ⟪वार्त्ता⟫

(கௌடிலீய-அர்த்தசாஸ்திரம் 1.4.1. படி)

நீதிசாஸ்திரம் விவசாயம், பசுக்கள் மற்றும் வணிகம்.
