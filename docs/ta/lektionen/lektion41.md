## 41.2. மேலும் ⟪कृत्⟫-a வடிவங்கள்

### 41.2.1. பத்திச ப்ரேசன்ஸ் (⟪लडादेशः⟫) Ā, பத்திச ப்ரேசன்ஸ் (⟪लडादेशः⟫) பசசிவ், பத்திச ப்யூர் (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. தீமத்திக ப்ரேசன்ஸ்ஸ்தம், பசசிவ் மற்றும் ப்யூர்

:::grammar-box
**உருவாக்கம்:**

ப்ரேசன்ஸ்ஸ்தம் / பசசிவ்ஸ்தம் / ப்யூர்ஸ்தம் + -māna (fem. mānā)
:::
உதாரணங்கள்:

⟪यज्⟫ 1U, பத்த.ப்ரேச.Ā ⟪यजमान⟫ 3 "ஒருவர், ஒருவரின் சொந்த நலனுக்காக ஒரு பலியால் வணங்கப்படுகிறார் = பலியின் கணவர்"

⟪मन्⟫ 4Ā, பத்த.ப்ரேச.Ā  ⟪मन्यमान⟫ 3 "ஒரு சிந்திப்பவர்"

⟪कृ⟫ 8U, பத்த.ப்ரேச.பசசிவ் ⟪क्रियमाण⟫ 3 "செய்யப்படும் ஒரு விஷயம்"

⟪दा⟫ 3U, பத்த.ப்யூ.Ā ⟪दास्यमान⟫ 3 "ஒருவர், ஒருவரின் சொந்த நலனுக்காக கொடுப்பார்"

:::grammar-box

### 41.2.2. "பகுத்தெச்சம்" எதிர்மறைத் தேவையைக் குறிக்கும் (Gerundivum) (⟪कृत्य⟫)

:::grammar-box
**எதிர்மறைத் தேவையைக் ("செய்யப்பட வேண்டியது/செய்யப்பட வேண்டும்") குறிக்க, வலைகள் மற்றும் பெயர்ச்சொற்றொடர் வடிவமைப்புக்களிலிருந்து பெறப்பட்ட எதிர்மறைப் பகுத்தெச்சங்களைக் கீழ்க்கண்ட பின்னொட்டுகளுடன் தேர்ந்தெடுக்கலாம்:**

* **-⟪तव्य⟫** (பெ. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (பெ. **-⟪अनीया⟫**)
* **-⟪य⟫** (பெ. **-⟪या⟫**)
* **-⟪त्य⟫** (பெ. **-⟪त्या⟫**) (மாற்றாக **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. பின்னொட்டு -⟪तव्य⟫ / -⟪तव्या⟫

:::grammar-box
**பின்னொட்டு -⟪तव्य⟫ / -⟪तव्या⟫ வலைகள் மற்றும் பெயர்ச்சொற்றொடர் வடிவமைப்புக்களில் (எ.கா. காரகம்) அமைக்கப்படுகிறது, அதுவே இன்ஃபினிட்டிவ் பின்னொட்டு -⟪तुम्⟫ (பார் [பாடம் 23](lektion23.md)) அமைக்கப்படும் விதத்தில், அதாவது**

* **உயர்நிலை வலை + ⟪तव्य⟫**

அல்லது

* **உயர்நிலை வலை + -i- + ⟪तव्य⟫**

**காரகத்தில்:**

* **காரக வடிவம் -ay + -i- + ⟪तव्य⟫**
:::

#### 41.2.2.3. பின்னொட்டு -⟪य⟫ / -⟪या⟫

### 41.2.3. "பாசண்டிவம்" (Gerundivum) என்ற செயலுரிமைச் சொல்லின் இலக்கணம் (⟪कृत्य⟫)

**⟪काशी⟫ ⟪द्विजैर्द्रष्टव्या⟫** = "இருமுறை பிறந்தோர் வாரணசியைக் காண வேண்டும்"

### 41.2.4. Gerundiv-ஒட்டுகளின் பயன்பாட்டில் வேறுபாடுகள்

:::grammar-box
இந்த ஒட்டுகளின் பயன்பாடு பெரும்பாலும் ஒன்றுக்கொன்று ஒத்துப்போகிறது

* **-⟪तव्य⟫ (பெ. -⟪तव्या⟫):** எப்போதும் ஒரு அவசியத்தைக் குறிக்கிறது; இது முக்கியமாக விசேசனமாகப் பயன்படுத்தப்படுகிறது (அரிதாகப் பெயர்விசேசனமாக). இந்த ஒட்டுடன் உருவாக்கப்பட்ட சொற்கள் பெயர்விசேசனக் கலப்பொருள்களில் பயன்படுத்தக்கூடாது.
* **-⟪अनीय⟫ (பெ. -⟪अनीया⟫) மற்றும் -⟪य⟫ (பெ. -⟪या⟫) / -⟪त्य⟫ (பெ. -⟪त्या⟫) (-⟪य⟫/-⟪या⟫-க்குப் பதிலாக):** கூடுதல் பொருளைக் கொண்டிருக்கலாம் (குறிப்பாக -⟪य⟫) ஜெர்மன் "-worth" (எ.கா. "காணத்தக்கது") அல்லது ஒரு வசதி "-able" (⟪दृश्य⟫ "காணக்கூடிய") என்ற அர்த்தத்தில். இந்த ஒட்டுகளுடன் உருவாக்கப்பட்ட சொற்களை ⟪अ⟫-/-⟪अन्⟫-ஆல் எதிர்மறையாக்கலாம் (-⟪तव्य⟫-உடன் உருவாக்கப்பட்ட சொற்களை அல்ல); மேலும் அவை ⟪तत्पुरुष⟫-இன் பின்னங்கூறாகக் காணப்படுகின்றன.
:::
### 41.2.5. ⟪सु⟫ மற்றும் ⟪दुस्⟫ உடன் தொடர்பில்லை

:::grammar-box

:::
