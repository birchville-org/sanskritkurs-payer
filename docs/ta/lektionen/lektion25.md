# பாடம் 25

## 25.1. Ablative உருவாக்கம் (⟪पञ्चमी⟫ = "ஐந்தாம் விபக்க முடிப்பு")

::: grammar-box
a என்ற இறுதியைக் கொண்ட பால்பெயர்கள் / நடுப்பால்கள் மற்றும் உரிச்சொற்களைத் தவிர, அனைத்து வகைமைப்படுத்தல் வகுப்புகளிலும் ஒற்றையெண்ணில் Ablative (⟪पञ्चमी⟫) வடிவங்கள் Genetive (⟪षष्ठी⟫) வடிவங்களுடன் ஒத்திருக்கும்.

தனிப்பட்ட உரிச்சொற்களைத் தவிர, அனைத்து வகைமைப்படுத்தல்களிலும் பன்மையில் Ablative வடிவங்கள் Dative (⟪चतुर्थी⟫) வடிவங்களுடன் ஒத்திருக்கும்.
:::
இப்போது சமஸ்கிருதத்தில் விபக்கங்களின் (⟪विभक्ति⟫) வரிசைக்கு காரணத்தை நீங்கள் அறிவீர்கள்: ஒத்த வடிவங்கள் முடிந்தவரை அருகருகே - அல்லது ஒன்றுக்கொன்று கீழே - இருக்கும் வகையில் அவை அமைக்கப்பட்டுள்ளன.

::: grammar-box
**-a என்ற இறுதியைக் கொண்ட பால்பெயர்கள் / நடுப்பால்களின் Ablative ஒற்றையெண்**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
கேள்வி, தொடர்பு மற்றும் குறிப்பு உரிச்சொற்கள்:

| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |

| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

## 25.2. Ablative பயன்பாடு (⟪पञ्चमी⟫)

"Ablative என்பது, ஏதேனும் ஒன்று அதிலிருந்து செல்லும்போது நிலையாக இருக்கும் அந்த வஸ்துவைக் குறிக்கிறது."

Pāṇini 2,3,28 + 1,4,24

Ablative முக்கியமாக "எங்கிருந்து?", "ஏன்?" என்ற கேள்விகளுக்கு பதிலளிக்கிறது.

::: grammar-box
1\. எனவே, Ablative ஆரம்ப புள்ளியை, தோற்றத்தை மற்றும் பொருளைக் குறிக்கிறது.

எனவே, அபிலேட்டிவ் (Ablativ) என்பது ஒருவர் எதையோ வாங்கும், கேட்கும், விரும்புகிறார் போன்றவற்றைச் செய்யும் நபரைக் குறிக்கலாம்.
:::
எடுத்துக்காட்டுகள்:

::: indent
⟪ग्रमादागच्छति⟫ = "அவன் கிராமத்திலிருந்து வருகிறான்"

⟪अश्वात्पतितः⟫ = "குதிரையிலிருந்து விழுந்த"

⟪तेभ्यो लब्धम्⟫ = "அவர்களிடமிருந்து (பெறப்பட்டது)"
:::
எடுத்துக்காட்டுகள்:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "அவர் ஆசிரியரிடமிருந்து தர்மத்தைப் பற்றிக் கேட்கிறார்"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "பிராமணர் க்ஷத்திரியரிடமிருந்து பால் கொடுக்கும் ஆட்டை விரும்புகிறார்"
:::
::: grammar-box
2\. அபிலேட்டிவ் என்பது "தடுக்க", "காப்பாற்ற", "பிரதிபாகமாக இருக்க", "அஞ்சு" போன்ற பொருட்களைக் கொண்ட வினைச்சொற்களுக்குப் பின்னால் வருகிறது:
:::
எடுத்துக்காட்டு:

::: indent
⟪अरिभ्यो रक्षति⟫ = "அவர் எதிரிகளிடமிருந்து பாதுகாக்கிறார்"
:::
::: grammar-box
3\. அபிலேட்டிவ் என்பது காரணம் அல்லது உறுப்பைக் குறிக்கிறது:
:::
எடுத்துக்காட்டுகள்:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "அவன் கோபத்தினால் தனது மகனைக் கொல்கிறான்"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "அவன் தீமையைச் செய்ததால், அவன் நரகத்திற்குச் செல்கிறான்" ("அவன் ஒருவர், அவரிடமிருந்து தீமை நடந்தது")

⟪पापकरणान्नरकं गच्छति⟫ = "அவன் தீமையைச் செய்கிறான் / செய்ததால், அவன் நரகத்திற்குச் செல்கிறான்"
:::
பெயர்ச்சொற்கள், அவை பால் (Feminina) அல்லவோ, செயலின் காரணத்தைக் குறிக்க, கருவி (Instrumentalis) (⟪तृतीया⟫) அல்லது அபிலேட்டிவ் (⟪पञ्चमी⟫) ஆகியவற்றில் இருக்கலாம். பால் சொற்கள் இந்த அர்த்தத்தில் பொதுவாக கருவி (Instrumentalis) ஆக இருக்கும், ஆனால் சில நேரங்களில் அபிலேட்டிவ் (Ablativ) ஆகவும் இருக்கலாம்.

## 25.3. பின்னணி -⟪तस्⟫

::: grammar-box
ஒருமை (Singular) இல், சொல் அபிலேட்டிவ் பொருளில் பயன்படுத்தப்படுகிறது என்பதைத் தெளிவாகக் காட்ட, சொல் வடிவத்திற்கு பின்னணி -⟪तस्⟫ ஐ இணைக்கலாம், இது பெரும்பாலும் அபிலேட்டிவ் பொருள் கொண்ட வினையெச்சங்களை உருவாக்குகிறது ("எங்கிருந்து?" என்ற கேள்விக்கு):
:::
உதாரணங்கள்:

::: indent
⟪आदितस्⟫ = "முதலிலிருந்தே"

⟪धर्मतस्⟫ = "தர்மத்தின் காரணமாக, தர்மத்தின் அடிப்படையில்"
:::
::: grammar-box
⟪तस्⟫ என்ற பிறப்பியல் உறுப்பு, விசேஷப் பெயர் மூலங்களுக்கும் இணையும்:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "அங்கிருந்து, அங்கே, அங்குக்கு, அதற்குப் பின்னர், ஆகவே"

⟪यद्⟫ : ⟪यतस्⟫ "எதிலிருந்து, என்னிடமிருந்து, எங்கிருந்து, எங்கே, எங்குக்கு, ஏன்" (சார்பெச்சம்)

⟪किम्⟫ :  ⟪कुतस्⟫ "எங்கிருந்து?" "ஏன்?"
:::
## 25.4. காரணங்களை வெளிப்படுத்தும் பிற வழிகள்

::: grammar-box
**1\. சார்பெச்ச வாக்கியங்கள்**

சார்பெச்ச வாக்கியங்கள், பெரும்பாலும் முக்ய வாக்கியத்துடன் காரண (காரணப்படுத்தும்), தொடர்ச்சி (தொடரும்) அல்லது நோக்கம் (நோக்கமுள்ள) தொடர்பை வெளிப்படுத்துகின்றன.

காரண இணையாகச் செயல்படும் சார்பெச்ச உருவங்கள்:

*   அபிலாதீவாக:
*   ⟪यतस्⟫ ... துணை வாக்கியம் ... ⟪ततस्⟫ ... முக்ய வாக்கியம் ... = "ஏனென்றால் ..., அதனால் ..."
*   ⟪यस्मात्⟫ ... துணை வாக்கியம் ... ⟪तस्मात्⟫ ... முக்ய வாக்கியம் ... = "ஏனென்றால் ..., அதனால் ..."
*   கரணமாக:
*   ⟪येन⟫ ... துணை வாக்கியம் ... ⟪तेन⟫ ... முக்ய வாக்கியம் ... = "எதன் மூலமாக/ஏனென்றால் ..., அதனால் / ஆகவே ..."
:::
உதாரணம்:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "ராமன் செல்வத்தை விரும்புவதால், அவர் சத்தியத்தைக் கடைப்பிடிக்கிறார்"
:::
::: grammar-box
**2\. ⟪हि⟫**

முக்ய வாக்கியங்களை ⟪हि⟫ என்ற இடைச்சொல் "ஏனென்றால், ஏன்" மூலம் இணைக்கலாம். ⟪हि⟫ கொண்ட வாக்கியம் (அது முதல் இடத்தில் இருக்கக்கூடாது, ஆனால் சார்பெச்சத்தில் இரண்டாவது இடத்தில் இருக்க வேண்டும்) முந்தைய வாக்கியத்திற்கோ அல்லது அதற்குப் பிந்தைய வாக்கியத்திற்கோ ஒரு காரணத்தைக் குறிப்பிடுகிறது:
:::
உதாரணம்:

::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "மக்கள் புண்ணியமான செயல்களைச் செய்கிறார்கள். ஏனென்றால் அவர்கள் சொர்க்கத்திற்குச் செல்ல விரும்புகிறார்கள்."
:::
::: grammar-box
**3\. கருவி நிலை (⟪तृतीया⟫)**

விலக்க நிலை (⟪पञ्चमी⟫) தவிர, கருவி நிலை (⟪तृतीया⟫) காரணம் அல்லது உடன்காரணியைக் குறிக்கப் பயன்படுத்தப்படுகிறது. பெண்மைச் சொற்களுக்கு கருவி நிலை பொதுவாக அவசியம்.
:::
உதாரணம்:

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = "அவன் கோபத்தினால் தனது மகனைக் கொல்கிறான்" = "அவன் கோபத்தில் தனது மகனைக் கொல்கிறான்"
:::
::: grammar-box
**4\. பெயர்ச்சொற்கள்**

மேலும், நிச்சயமாக காரணங்களை பின்வரும் அமைப்புகள் மூலம் வெளிப்படுத்தலாம்:

*   ⟪कारण⟫ ந. "காரணம்": ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ ஆ.
*   "காரணம்" என்ற பொருளில் உள்ள பிற பெயர்ச்சொற்கள்

\+ உரித்தொடை (⟪षष्ठी⟫) அல்லது சந்தி சொற்களின் பின்கூறாக:
:::
உதாரணம்:

::: indent
⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ முதலியன) = "புண்ணியத்தின் காரணமாக"
:::
::: grammar-box
**5\. ⟪इति⟫**

ஒரு செயலுக்கான ஊக்கத்தை ⟪इति⟫ மூலம் ஒரு சிந்தனையாகக் குறிப்பிடலாம்:
:::
உதாரணம்:

::: indent

:::
