# பாடம் 25

## 25.1. அபிலத்திவின் உருவாக்கம் (पञ्चमी = "ஐந்தாவது விபத்தியந்தம்")

:::grammar-box
பால், நடுவினப் பெயர்கள் -a-வில் முடிவதும், உரிச்சொற்களும் தவிர, அனைத்து விகுதி வகுப்புகளிலும் ஒருமை அபிலத்திவின் வடிவங்கள் (पञ्चमी) ஜெனிட்டிவின் (षष्ठी) வடிவங்களுடன் ஒத்திருக்கும்.

நபர் உரிச்சொற்கள் தவிர, அனைத்து விகுதி வகுப்புகளிலும் பன்மையில் அபிலத்திவின் வடிவங்கள் டேட்டிவின் (चतुर्थी) வடிவங்களுடன் ஒத்திருக்கும்.
:::இப்போது சமஸ்கிருதத்தில் விபத்தியந்தங்களின் (विभक्ति) வரிசைக்கு காரணத்தை நீங்கள் அறிவீர்கள்: ஒத்த வடிவங்கள் முடிந்தவரை அருகருகே அல்லது ஒன்றுக்கொன்று கீழே இருக்கும் வகையில் அவை அமைக்கப்பட்டுள்ளன.

:::grammar-box

::::## 25.2. விலக்கத்தின் பயன்பாடு (पञ्चमी)

"விலக்கம், ஒரு பொருள் அங்கிருந்து விலகும்போது, அது நிலைத்து நிற்கும் பொருளைக் குறிக்கிறது."

பாணினி 2,3,28 + 1,4,24

விலக்கம் முக்கியமாக "எங்கிருந்து?", "ஏன்?" என்ற கேள்விகளுக்கு பதிலளிக்கிறது.

:::grammar-box
1\. விலக்கம் எனவே தொடக்கப் புள்ளி, தோற்றம் மற்றும் பொருளைக் குறிக்கிறது.

விலக்கம், ஒருவர் ஒரு பொருளை வாங்கும், கேட்கும், விரும்பும் போது, அந்த நபரைக் குறிக்கலாம்.
:::உதாரணங்கள்:

:::indent
ग्रमादागच्छति = "அவன் கிராமத்திலிருந்து வருகிறான்"

अश्वात्पतितः = "குதிரையிலிருந்து விழுந்த"

तेभ्यो लब्धम् = "அவர்களிடமிருந்து (நேராக) பெற்றது"
:::உதாரணங்கள்:

:::indent
गुरोर्धर्मं शृणोति = "அவர் ஆசிரியரிடமிருந்து தர்மத்தின் பற்றி கேட்கிறார்"

ब्राह्मणः क्षत्रियाद्धेनुमिच्छति = "பிராமணர் க்ஷத்திரியரிடமிருந்து ஒரு பசுவுக்கான பால் கன்றை விரும்புகிறார்"
::::::grammar-box
2\. விலக்கம் "தடுக்க", "காக்க", "பாதுகாக்க", "அச்சப்பட" என்ற பொருள்களைக் கொண்ட வினைச்சொற்களுடன் பயன்படுத்தப்படுகிறது:
:::உதாரணம்:

:::indent
अरिभ्यो रक्षति = "அவன் எதிரிகளிடமிருந்து பாதுகாக்கிறான்"
::::::grammar-box
3\. விலக்கம் காரணம் அல்லது காரணத்தைக் குறிக்கிறது:
:::உதாரணங்கள்:

:::indent
क्रोधात्पुत्रं हन्ति = "அவன் கோபத்தினால் தனது மகனைக் கொல்கிறான்"

कृतपापत्वान्नरकं गच्छति = "அவன் கீழ்மை செய்ததால், அவன் நரகத்திற்குச் செல்கிறான்" ("அவன் ஒருவன், அவனிடமிருந்து கீழ்மை செய்யப்பட்டது")

पापकरणान्नरकं गच्छति = "அவன் கீழ்மை செய்கிறான் / செய்ததால், அவன் நரகத்திற்குச் செல்கிறான்"
:::பெண்பால் அல்லாத பெயர்ச்சொற்கள், ஒரு செயலின் காரணத்தைக் குறிக்க, கருவிநிலை (तृतीया) அல்லது விலக்கநிலை (पञ्चमी) ஆகியவற்றில் இருக்கலாம். பெண்பால் பெயர்ச்சொற்கள் இந்த அர்த்தத்தில் பொதுவாக கருவிநிலையில் இருக்கும், ஆனால் சில நேரங்களில் விலக்கநிலையிலும் இருக்கலாம்.

## 25.3. -तस् என்ற முற்பொருள்

:::grammar-box
ஒருமை (தெளிவாக) அழல்பொருள் கொண்ட சொல் பயன்படுத்தப்படுவதை வெளிப்படுத்த விரும்பினால், சொற்றொடருக்கு -तस् என்ற முற்பொருளை இணைக்கலாம், இது பெரும்பாலும் அழல்பொருள் கொண்ட வினையெச்சங்களை உருவாக்குகிறது ("எங்கிருந்து?" என்ற கேள்விக்கு):
:::உதாரணங்கள்:

:::indent
आदितस् = "தொடக்கத்திலிருந்தே"

धर्मतस् = "தர்மத்தின் காரணமாக, தர்மத்தின் அடிப்படையில்"
::::::grammar-box
-तस् என்ற முற்பொருள் பெயர்ச்சொற்றொடர்களுக்கும் பயன்படுத்தப்படுகிறது:
::::::indent
तद् : ततस् (« ta-tas) "அங்கிருந்து, அங்கு, அங்கே, அதற்கு, பின்னர், அதனால்"

यद् : यतस् "எதிலிருந்து, எதிலிருந்து, எங்கிருந்து, எங்கு, எங்கே, ஏன், ஏனெனில்" (சார்பு)

किम् :  कुतस् "எங்கிருந்து?" "ஏன்?"
:::## 25.4. காரணங்களை வெளிப்படுத்த வேறு வழிகள்

:::grammar-box
**1\. தொடர்புப் பற்றிய வாக்கியங்கள்**

தொடர்புப் பற்றிய வாக்கியங்கள் பெரும்பாலும் முக்கிய வாக்கியத்துடன் காரணக் (காரணப்படுத்தும்), தொடர்ச்சியான (முடிவான) அல்லது நோக்கக் (நோக்கமுள்ள) தொடர்பை வெளிப்படுத்துகின்றன.

காரண இணைப்பாகச் செயல்படும் தொடர்புப் பெயர்ச்சொல்லின் வடிவங்கள்:

*   அபிலாஷை:
    *   यतस् ... துணை வாக்கியம் ... ततस् ... முக்கிய வாக்கியம் ... = "ஏனெனில் ..., எனவே ..."
    *   यस्मात् ... துணை வாக்கியம் ... तस्मात् ... முக்கிய வாக்கியம் ... = "ஏனெனில் ..., எனவே ..."
*   கருவி:
    *   येन ... துணை வாக்கியம் ... तेन ... முக்கிய வாக்கியம் ... = "எதன் மூலம்/ஏனெனில் ..., அதன் மூலம் / எனவே ..."
:::உதாரணம்:

:::indent
यतो (यस्माद् / येन) धर्ममिच्छति \[ततो (तस्माद् / तेन)\] रामो व्रतं चरति = "ராமன் செழிப்பை விரும்புவதால், அவர் வாக்கைப் பின்பற்றுகிறார்"
::::::grammar-box
**2\. हि**

हि "ஏனெனில், ஏனெனில்" என்ற கண்ணோட்டத்தின் மூலம் முக்கிய வாக்கியங்களை இணைக்கலாம். हि கொண்ட வாக்கியம் (அது முதல் இடத்தில் இருக்கக்கூடாது, ஆனால் கவிதை இரண்டாவது இடத்தில் இருக்க வேண்டும்) முந்தைய வாக்கியத்திற்கோ அல்லது அடுத்த வாக்கியத்திற்கோ காரணத்தைக் குறிக்கிறது:
:::உதாரணம்:

:::indent
जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति = "மக்கள் நன்மை செய்கிறார்கள். அவர்கள் வானத்திற்குச் செல்ல விரும்புகிறார்கள்."
::::::grammar-box
**3\. கருவி (तृतीया)**

அபிலாஷைக்கு (पञ्चमी) கூடுதலாக, கருவி (तृतीया) காரணம் அல்லது காரணத்தைக் குறிக்கப் பயன்படுத்தப்படுகிறது. பெண்பால் பெயர்ச்சொற்களுக்கு கருவி பொதுவாக கட்டாயமாகும்.
:::உதாரணம்:

:::indent
क्रोधेन पुत्रं हन्ति = "அவன் கோபத்தால் தனது மகனைக் கொல்கிறான்" = "அவன் கோபத்தில் தனது மகனைக் கொல்கிறான்"
::::::grammar-box
**4\. பெயர்ச்சொற்கள்**

அத்துடன், நிச்சயமாக காரணங்களைக் கீழ்க்கண்ட கட்டமைப்புகளுடன் வெளிப்படுத்தலாம்

*   कारण n. "காரணம்": कारणात् । कारणेन
*   हेतु m.
*   "காரணம்" என்ற அர்த்தத்தில் வேறு பெயர்ச்சொற்கள்

\+ உரிமை (षष्ठी) அல்லது சமசுகிருதத்தின் பின்னங்கட்டமாக:
:::உதாரணம்:

:::indent
पुण्यस्य कारणात् (हेतोः u.s.w.) = "நன்மை காரணமாக"
::::::grammar-box
**5\. इति**

ஒரு செயலுக்கான ஊக்கத்தை इति என்ற எண்ணத்துடன் குறிக்கலாம்:
:::உதாரணம்:

:::indent
सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति  = "சுகதன் முழுமையாக உண்மைக்கு எழுந்திருப்பதால், ஆனந்தர் கௌதமரிடம் அவர் கற்பித்தலைக் கேட்கிறார்" (« "சுகதன் முழுமையாக உண்மைக்கு எழுந்திருக்கிறார்" என்று எண்ணி ...)
