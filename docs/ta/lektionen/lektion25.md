## 25.1. அபிலத்திவின் உருவாக்கம் (⟪पञ्चमी⟫ = "ஐந்தாம் விபத்தியின் முடிப்பு")

::: grammar-box
-a என்ற -a ஆகிய பாலினம்/நடுபாலினம் மற்றும் உரிச்சொற்கள் தவிர்த்த மற்ற அனைத்து விகுதி வகைகளிலும், ஒருமை நிலையில் அபிலதிவ விகுதி (⟪पञ्चमी⟫) மற்றும் ஜெனிட்டிவ் விகுதி (⟪षष्ठी⟫) ஆகிய இரண்டும் ஒன்றாகவே இருக்கும்.

பொருள்முற்றுப் பெயர்ச்சொற்களைத் தவிர, அனைத்து பன்மை விகுதிகளிலும், விளிப்பு விசாரத்தின் வடிவங்கள், தரப்பு விசாரத்தின் வடிவங்களுடன் (⟪चतुर्थी⟫) ஒத்திருக்கின்றன.
:::
இப்போது, சமஸ்கிருதத்தில் விசாரங்களின் வரிசைக்குக் காரணத்தை நீங்கள் புரிந்துகொள்கிறீர்கள்: (⟪विभक्ति⟫) அவை ஒரே மாதிரியான வடிவங்கள் சாத்தியமான அளவுக்கு அருகருகே அல்லது ஒன்றுக்கொன்று கீழே இருக்கும் வகையில் அமைக்கப்பட்டுள்ளன.

::: grammar-box

## 25.2. அபிலிவின் பயன்பாடு (⟪पञ्चमी⟫)

"விலக்கம் என்பது, ஒரு பொருள் அதிலிருந்து விலகும்போது நிலையாக இருப்பதைக் குறிக்கிறது."

பாணி 2,3,28 + 1,4,24

விலக்கம் முக்கியமாக "எங்கிருந்து?", "ஏன்?" என்ற கேள்விகளுக்கு உட்பட்டது.

::: grammar-box
1\. ஆகவே, அபிலதிவ் தொடக்கப்புள்ளியையும், தோற்றத்தையும், பொருளையும் குறிக்கிறது.

எனவே, அளவியல் பணியாளர், அவரிடமிருந்து நீங்கள் எதையாவது வாங்கும், கேட்கும், விரும்பும் போன்றவற்றைக் குறிக்கலாம்.
:::
உதாரணங்கள்:

::: indent
⟪ग्रमादागच्छति⟫ = "அது கிராமத்திலிருந்து வருகிறது"

⟪अश्वात्पतितः⟫ = "குதிரையிலிருந்து விழுந்தது"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "அவர்களிடமிருந்து (நோக்கி) பெறப்பட்டது"
:::
உதாரணங்கள்:

::: indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟫ = "அவர் ஆசிரியரிடமிருந்து தர்மத்தைக் கேட்கிறார்"

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = "பிராமணன் க்ஷத்திரியிடமிருந்து ஒரு பசுப் பசுவை விரும்புகிறான்"
:::
::: grammar-box
2\. செயல்களுக்கு "தடுக்க", "காக்க", "பாதுகாக்க", "அச்சப்படு" ஆகிய பொருள்கள் உள்ளன:
:::
உதாரணம்:

::: indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = "அவன் எதிரிகளிலிருந்து பாதுகாக்கிறான்"
:::
::: grammar-box
3\. விலக்கம் காரணம் அல்லது காரியத்தைக் குறிக்கிறது:
:::
உதாரணங்கள்:

::: indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = "அவன் கோபத்தால் தனது மகனைக் கொலையிடுகிறான்"

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = "தீமையைச் செய்தவன் நரகத்திற்குச் செல்கிறான்" ("அவன் ஒருவன் மூலம் தீமை செய்யப்பட்டான் என்பதால்")

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = "அவன் தீமையைச் செய்கிறான் / செய்தான் என்பதால், அவன் நரகத்திற்குச் செல்கிறான்"
:::
பெண்பால் அல்லாத பெயர்ச்சொற்கள், ஒரு செயலின் காரணத்தைக் குறிக்க, கருவி விபாகை (⟪तृतीया⟫) அல்லது அபவிபாகை (⟪पञ्चमी⟫) ஆகியவற்றில் வரலாம். இச்செயலில் பெண்பால் பெயர்ச்சொற்கள் பொதுவாக கருவி விபாகையில் இருக்கும், ஆனால் சில நேரங்களில் அபவிபாகையில் இருக்கலாம்.

## 25.4. காரணங்களை வெளிப்படுத்த வேறு வழிகள்

::: grammar-box
**1\. தொடர்பு வாக்கியங்கள்**

சார்பு வாக்கியங்கள் பெரும்பாலும் முக்கிய வாக்கியத்துடன் காரண (விளக்க), தொடர்ச்சி (முடிவு) அல்லது நோக்க (நோக்கம்) ஆகியவற்றிற்கான தொடர்பை வெளிப்படுத்துகின்றன.

காரண உபச்சாரமாகச் செயல்படும் தொடர்புப் பெயர்ச்சொல்லின் வடிவங்கள்:

*   அபிலேடிவ்:
    *   ⟪यतस्⟫ ... துணை வாக்கியம் ... ⟪ततस्⟫ ... முக்கிய வாக்கியம் ... = "ஏனெனில் ..., எனவே ..."
    *   ⟪यस्मात्⟫ ... துணை வாக்கியம் ... ⟪तस्मात्⟫ ... முக்கிய வாக்கியம் ... = "ஏனெனில் ..., எனவே ..."
*   இன்ஸ்ட்ருமென்டல்:
    *   ⟪येन⟫ ... துணை வாக்கியம் ... ⟪तेन⟫ ... முக்கிய வாக்கியம் ... = "எதன் மூலம்/ஏனெனில் ..., அதன் மூலம் / எனவே ..."
:::
உதாரணம்:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = "ராமர் செல்வத்தை விரும்புவதால், அவர் நேர்த்திக்கடையை நிறைவேற்றுகிறார்"
:::
::: grammar-box
**2\. ⟪हि⟫**

⟪हि⟫ "ஏனெனில், ஏற்கெனவே" என்ற உறுப்பு மூலம் முக்கிய வாக்கியங்களை இணைக்கலாம். ⟪हि⟫ (இது முதல் இடத்தில் இருக்கக்கூடாது, ஆனால் கவிதை இரண்டாவது இடத்தில் இருக்க வேண்டும்) கொண்ட வாக்கியம் முந்தைய வாக்கியத்திற்கோ அல்லது அதற்கு அடுத்த வாக்கியத்திற்கோ ஒரு காரணத்தைக் குறிக்கிறது:
:::
உதாரணம்:

::: indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = "மக்கள் புண்ணியமான செயல்களைச் செய்கிறார்கள். அவர்கள் சொர்க்கத்திற்குச் செல்ல விரும்புகிறார்கள்."
:::
::: grammar-box
