# பாடம் 38

## 38.1. வாரத்தின் தீர்வு

⟪मनुस्मृति ४⟫.⟪३२⟫ சரியான சிறுநீர் கழித்தல் பற்றிய:

::: indent
⟪प्रत्य⟫:sig[⟪ग्नि⟫] ⟪प्रतिसूर्यं च प्रतिसोमोदकद्विजम् । प्रति⟫:sig[⟪गु⟫] ⟪प्रतिवातं च प्रज्ञा नश्यति मेहतः ॥⟫
:::
விளக்கங்கள்:

\-⟪अग्नि⟫ நடுவினம் பெயரெச்ச.ஒரு.பன்மைக்கு ⟪अग्नि⟫ ஆண்பால்.

\-⟪गु⟫ நடுவினம் பெயரெச்ச.ஒரு.பன்மைக்கு ⟪गो⟫ ஆண்/பெண்பால். "ஆடு, பசு"

## 38.2. சொல்லில் மூக்கொலிகளின் ஒலிமாற்றம்

::: grammar-box
சொல்லில் உள்ள மூக்கொலிகள், அதனைத் தொடர்ந்து வரும் ஒலிகளுடன் இணைக்கப்படுகின்றன, அதாவது அவை அந்த ஒலிக்கு ஏற்ப உள்ள மூக்கொலியால் மாற்றப்படுகின்றன.

c- மற்றும் j-க்குப் பின் -n- என்பது -ñ- ஆல் மாற்றப்படுகிறது.
:::
## 38.3. -n இன் அடிப்படையிலான சொற்களின் வார்ப்புரு

### 38.3.1. -an இன் அடிப்படையிலான சொற்கள் மற்றும் உயிரெழுத்திற்குப் பின் -man அல்லது -van இன் அடிப்படையிலான சொற்கள்
::: grammar-box
**-an** இன் அடிப்படையிலான சொற்கள் மற்றும் உயிரெழுத்திற்குப் பின் **-man** அல்லது **-van** இன் அடிப்படையிலான சொற்கள் மூன்று வார்ப்புருக்களைக் கொண்டுள்ளன:

### 38.3.3. -in, -min, -vin இறுதியுள்ள பால்பெயர்கள் மற்றும் பெண்பால்

::: grammar-box
இந்தப் பெயர்கள் **எந்த** தனி மாற்றத்தையும் கொண்டிருக்கவில்லை.

பெயர் ஒருமை பால் மற்றும் பெயர் பலவினம் ஆகியவை -an தனிக்கு இணையாக உருவாக்கப்பட்டுள்ளன (-i- நீட்டிப்பு), அதே போல உயிர்மெய் இறுதியின் முன் **\-i-** தனி.

பெண்பால் -ī பின்னணி மூலம் உருவாக்கப்படுகிறது: எ.கா. ⟪बलिनी⟫

## 38.4. பெயர்ச்சொல் உருவாக்கம் பற்றி: ⟪तद्धित⟫-சுட்டு -in

::: grammar-box
மிகவும் முக்கியமான! ⟪तद्धित⟫-சுட்டு **-in** மூலம் பெயர்ச்சொற்களிலிருந்து பண்புவிசேஷணங்கள் உருவாக்கப்படுகின்றன, அதன் பொருள்:

**குறிக்கப்பட்டது, கொண்டிருப்பவர்**

ஆரம்பகாலத்தில் **-⟪इन्⟫** சுட்டு மூலம் உருவாக்கம், **-⟪मन्त्⟫/-⟪वन्त्⟫** மூலம் உருவாக்கத்திலிருந்து வேறுபட்டது, ஏனெனில் **-⟪इन्⟫** ஒரு சிறப்பு விஷயத்தால் குறிக்கப்படுவதைக் குறிக்கிறது, அதே சமயம் **-⟪मन्त्⟫/-⟪वन्त्⟫** பொதுவான அல்லது வழக்கமான விஷயத்தைக் கொண்டிருப்பதை, அதனால் குறிக்கப்படுவதை வெளிப்படுத்துகிறது.
:::

## 38.5. ⟪नामन्⟫ பற்றிய இலக்கணம்

::: grammar-box
"N. N. என்ற பெயர் கொண்ட ஒருவர்" என்று வெளிப்படுத்த, பின்வரும் கட்டமைப்பு பயன்படுத்தப்படுகிறது:

**N.N. (நியமன விகாரம்) ⟪नाम⟫**

சொற்பொருள்: "பெயர் N.N. ஆகும்/ஆக இருந்தது". எனவே இது ஒரு நடுவில் சேர்க்கப்பட்ட பெயர்ச்சொல் வாக்கியமாகும்.
:::
உதாரணம்:

::: indent
⟪आसीद्राजा नलो नाम वीरसेनसुतो बली ।⟫ "முன்பு ஒரு அரசன் இருந்தார், **நளா** என்ற பெயருடன், வலிமையான வீரசேனனின் மகன்."
:::
இயல்பாகவே, அதே கருத்தை ⟪बहुव्रीहि⟫ என வெளிப்படுத்தலாம்:

::: indent
⟪देवदत्तनामा पुरुषः⟫ "தெவதத்தா என்ற பெயருடைய ஒரு ஆண்"

⟪मदयन्तिकानाम्नी बाला⟫ "மதயந்திகா என்ற பெயருடைய ஒரு சிறுமி"
:::

## 38.6. ⟪आत्मन्⟫ இன் இலக்கண அமைப்பு

::: grammar-box
⟪आत्मन्⟫ **ஆண்பால்** என்பது **ஒருமை**யில், அனைத்து மூன்று பால்களுக்கும் (ஆண், பெண், நடுவு), எண்ணிற்கும் (இருமை மற்றும் பலமையும்) மற்றும் ஆளுக்குமான பின்னடைவு உரிச்சொல் (Reflexivpronomen) ஆகப் பயன்படுத்தப்படலாம்.
:::
எடுத்துக்காட்டுகள்:

::: indent
⟪आत्मन्येषा दोषं न पश्यति ।⟫ "அவள் தன்னிடம் எந்த குறையையும் காணவில்லை"

⟪आत्मानं स्तुवन्ति ।⟫ "அவர்கள் தங்களைப் பற்றிப் பாராட்டுகின்றனர்"
:::
::: grammar-box
பண்புப்பெயர் (⟪षष्ठी⟫) ⟪आत्मनस्⟫ எனவே, "என்/உனது/அவனின்... சொந்த" என்று நிற்கலாம்.
:::
எடுத்துக்காட்டு:

::: indent
⟪आत्मनो गृहं प्रविशति ।⟫ "அவன் தனது சொந்த வீட்டிற்குள் நுழைகிறான்."
:::
## 38.7. உயிர்மையற்ற எழுத்தால் முடிவடைந்த மூலச்சொற்கள் சேர்க்கைச் சொல்லின் முன் உறுப்பாக

::: grammar-box
ஒரு உயிர்மையற்ற எழுத்தால் முடிவடையும் மூலச்சொற்கள், லோகதிவம் (⟪सप्तमी⟫) பலத்தின் -su முடிபிற்கு முன் ஏற்கும் (தளர்வான) மூலச்சொல்லாகச் சேர்க்கைச் சொல்லின் முன் உறுப்பாகத் தோன்றும்.
:::

::: grammar-box
