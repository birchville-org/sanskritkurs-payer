# பாடம் 3

:::deleteme-box
**இந்த பாடத்தில் நீங்கள் கற்றுக்கொள்வீர்கள்:**
- பெண்பால் ஒருமை அசைநிலை
- ஆண்பால் மற்றும் பெண்பால் பலவசைநிலை
- ஆண்பால் பெண்பாலாக மாற்றம்
- ஒலி இணைப்பு
- Satzsandhi von -ās
:::## 3.1. பெண்பால் ஒருமை அசை

### 3.1.1. பெயர்ச்சொல் ஒருமை -s இல்

ஒலியால் முடியும் பின்வரும் பெயர்ச்சொல் வகைகள், **ச** இல் ஒருமை பெயர்ச்சொல் வகைமை செய்கின்றன:

:::grammar-box
- **பெண்பால் -i இல்**: எ.கா. **śruti** பெ. "கேட்டல்" -- பெ. ஒருமை: **śrutis** = ⟪श्रुतिस्⟫
- **பெண்பால் -u இல்**: எ.கா. **dhenu** பெ. "பால்சேகரிக்கும் பசு" -- பெ. ஒருமை: **dhenus** = ⟪धेनुस्⟫
:::### 3.1.2. பெயர்ச்சொல் ஒருமை முற்றுநிலை இல்லாமல்

பெயர்ச்சொல் ஒருமை முற்றுநிலை இல்லாமல் அமைவது:

:::grammar-box
- **பெண்சொல் -ā** இறுதியில் வரும்: எ.கா. **devatā** பெ. "தெய்வம்" -- பெ.ஒ: **devatā** = ⟪देवता⟫
- **பெண்சொல் -ī** இறுதியில் வரும்: எ.கா. **devī** பெ. "தெய்வம்" -- பெ.ஒ: **devī** = ⟪देवी⟫
::::::important
**எச்சரிக்கை!** இதற்கு அப்பால், ஒற்றெழுத்து பெண்சொல் வார்த்தைகள் -ī இறுதியில் வரும், அவற்றின் பெயர்ச்சொல் ஒருமை முற்றுநிலை -s இல் அமைவது: எ.கா. dhī பெ. "எண்ணம்" -- பெ.ஒ: dhīs = ⟪धीस्⟫. lakṣmī (⟪लक्ष्मी⟫) பெ., tarī (⟪तरी⟫) பெ. "கப்பல்" மற்றும் tantrī (⟪तन्त्री⟫) பெ. "நூல்" ஆகியனவும் விதிவிலக்காக பெயர்ச்சொல் ஒருமை முற்றுநிலை -s இல் அமைவது: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::---

## 3.2. பெண்பால் வடிவங்கள் ஆண்பால் சொற்களுக்கு

:::grammar-box
**-a** க்கு இறுதியாக வரும் ஆண்பால் சொற்கள்:
- **-ā** க்கு இறுதியாக வரும் பெண்பால்: எ.கா. **kṣatriya** ஆ. » **kṣatriyā** பெ. "கட்சத்திரியப் பெண்" = ⟪क्षत्रिया⟫
- **-ī** க்கு இறுதியாக வரும் பெண்பால்: எ.கா. **brāhmaṇa** ஆ. » **brāhmaṇī** பெ. "பிராமணப் பெண்" = ⟪ब्राह्मणी⟫

**-u** க்கு இறுதியாக வரும் ஆண்பால் சொற்கள்:
- **-ī** க்கு இறுதியாக வரும் பெண்பால்: எ.கா. **sādhu** ஆ. » **sādhvī** பெ. (நல்லவர், புனிதர்) = ⟪साध्वी⟫
  (**-u-** என்பது உயிரெழுத்திற்கு முன் **-v-** ஆக மாறுவதால், **-u- + -ī** » **-vī**)
:::---

## 3.3. பெண்பால் மற்றும் ஆண்பால் அமைப்புப் பன்மை

:::grammar-box
ஆண்பால் மற்றும் பெண்பால் அமைப்புப் பன்மை இறுதி எழுத்து **-as** ஆகும்.
- **-a** க்குரிய ஆண்பால்: **deva- + -as** » **devās** = ⟪देवास्⟫
- **-ā** க்குரிய பெண்பால்: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **-i** க்குரிய ஆண்பால்: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **-i** க்குரிய பெண்பால்: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **-ī** க்குரிய பெண்பால்: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **-u** க்குரிய ஆண்பால்: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **-u** க்குரிய பெண்பால்: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::குறிப்பு: **e** என்பது **i** க்குரிய உயர்நிலை (**guṇa**), **o** என்பது **u** க்குரிய உயர்நிலை ஆகும்.

## 3.4. ஒலிநிலை இணைவு

:::grammar-box
**ஒரே மாதிரியான அல்லது நீளத்தில் மட்டும் வேறுபடுகிற எளிய ஒலிகள், ஒத்த நீண்ட ஒலியாக "ஒன்றிணைகின்றன":**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::எ.கா.

devatā + annapūrṇā » devatānnapūrṇā "அன்னபூர்ணை ஒரு தெய்வம்" = ⟪देवतान्नपूर्णा⟫

> (அன்னபூர்ணை உணவு மற்றும் பக்குவத்தின் தெய்வம்; அவர் சிவனின் மனைவி பார்வதியின் அவதாரம் என்று கருதப்படுகிறார்.)

devī + indrāṇī » devīndrāṇī "இந்திராணி ஒரு தெய்வம்" = ⟪देवीन्द्राणी⟫

> (இந்திராணி இந்திரன் என்ற தெய்வத்தின் மனைவி.)

:::media
![](/images/lekt0301.webp)

(படத்தின் மூலம்: [விவரங்கள்](/ta/licenses#lekt0301))

**எளிய ஒலிகள் (-a / -ā தவிர), ஒத்திலாத ஒலிகளுக்கு முன், ஒத்தியற்ற ஒலியால் மாற்றப்படுகின்றன:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! இந்த விதிக்கு, குறிப்பாக இருமை வடிவங்களுக்கு விலக்குகள் உள்ளன !!)
:::எ.கா.

devī + umā » devy umā "உமா ஒரு / அந்த தெய்வம்" = ⟪देव्युमा⟫

> (உமா சிவனின் மனைவி பார்வதிக்கு ஒரு பெயர்)

:::grammar-box
**-a / -ā ஒத்திலாத ஒலிக்கு முன்:**

- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**

எ.கா.

śūdrā + itarā » śudretarā "இதரா ஒரு சூத்திரப் பெண்" = ⟪शूद्रेतरा⟫

## 3.6. சொற்பட்டியல்

**கீழ்க்காணும் சொற்களைக் கற்றுக்கொள்ளுங்கள்:**

**śruti** பெ. = ⟪श्रुति⟫ : கேட்டல், நித்தியமான பாரம்பரியம் (வேதங்கள் மற்றும் பிராமணங்களுக்கான பெயர்).

**smṛti** பெ. = ⟪स्मृति⟫ : நினைவுறுத்தல், நினைவு, தியான ரீதியான நினைவுறுத்தல் = கவனம், பாரம்பரியம் (**śruti** க்கு எதிர்ப்பொருள்). இது பின்வற்றவை உள்ளடக்கியது:
- ஆறு **vedāṅga** பெ. (⟪वेदाङ्ग⟫)
  1. **śikṣā** பெ. (⟪शिक्षा⟫): சரியான எழுத்துப்படுத்தல்
  2. **chandas** பெ. (⟪छन्दस्⟫): அளவியல்
  3. **vyākaraṇa** பெ. (⟪व्याकरण⟫): இலக்கணம்
  4. **nirukta** பெ. (⟪निरुक्त⟫) : சொற்பொருள் விளக்கம், மொழியியல்
  5. **jyotiṣa** பெ. (⟪ज्योतिष⟫) : வானியல், நாட்காட்டி அறிவியல்
  6. **kalpa** பெ. (⟪कल्प⟫) : விழிப்புநிலை
- **śrautasūtra** பெ. (⟪श्रौतसूत्र⟫) : பெரிய யாகங்களை நிறைவேற்றுவதற்கான கற்பித்தல் நூல்கள்
- **gṛhyasūtra** பெ. (⟪गृह्यसूत्र⟫) : தினசரி வாழ்க்கையின் விழிப்புநிலை மற்றும் பலிகளுக்கான கற்பித்தல் நூல்கள்
- **dharmasūtra** பெ. (⟪धर्मसूत्र⟫) மற்றும் **dharmaśāstra** பெ. (⟪धर्मशास्त्र⟫) : சட்டம் மற்றும் பழக்கவழக்கம் குறித்த கற்பித்தல் நூல்கள் (சரியான நடத்தை)
- பெரிய காவியங்கள் **mahābhārata** பெ. (⟪महाभारत⟫) மற்றும் **rāmāyaṇa** பெ. (⟪रामायण⟫)
- **purāṇa** பெ. (⟪पुराण⟫)
- **nītiśāstra** பெ. (⟪नीतिशास्त्र⟫) : வாழ்க்கை நுணுக்கத்தின் கற்பித்தல் நூல்கள்

**smṛti** என்பது குறிப்பாக தர்ம கற்பித்தல் நூல்களுக்கான பெயரும் ஆகும்.

**dhenu** பெ. = ⟪धेनु⟫ : (பால்) எருமை.

**paśu** பெ. = ⟪पशु⟫ : வளர்ப்பு விலங்கு, பசுமை (ஒருங்கிணைப்பு).

**devatā** பெ. = ⟪देवता⟫ : தெய்வீகம் (நาม மற்றும் உருவம்).

**brāhmaṇī** பெ. = ⟪ब्राह्मणी⟫ : பிராமணர்.

**kṣatriyā** பெ. = ⟪क्षत्रिया⟫ : க்ஷத்திரியர் பெண்.

**kṣatriyī** பெ. = ⟪क्षत्रियी⟫ : க்ஷத்திரியரின் மனைவி.

**vaiśyā** பெ. = ⟪वैश्या⟫ : வைசியர் பெண்.

**śūdrā** பெ. = ⟪शूद्रा⟫ : சூத்திரர் பெண்.

**śūdrī** பெ. / **śūdrāṇī** பெ. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : சூத்திரரின் மனைவி.

**devī** பெ. = ⟪देवी⟫ : தெய்வீகப் பெண், குறிப்பாக Durgā பெ. = ⟪दुर्गा⟫, சிவரின் மனைவி = ⟪शिव⟫.

:::media
![](/images/lekt0303.webp)
ஒளிப்படம்: Durgā = ⟪दुर्गा⟫, ஒரிசா
(படத்தின் மூலம்: [விவரங்கள்](/images/lekt0303))
:::**sādhvī** பெ. = ⟪साध्वी⟫ : பெண்பால், sādhu க்கு.

**gurvī** பெ. = ⟪गुर्वी⟫ : பெண்பால், guru க்கு.

**asmitā** பெ. = ⟪अस्मिता⟫ : "நான்-இயல்பு", அதாவது (தவறான) நம்பிக்கை: **நான்** பார்ப்பவன் என்பது போன்றது.

**ānvīkṣikī** பெ. = ⟪आन्वीक्षिकी⟫ : தத்துவம் (தர்க்க ரீதியாக சரியான காரணங்களைக் கொண்டு முடிவுகளை அடையும் அறிவியல்).

**upekṣā** பெ. = ⟪उपेक्षा⟫ : கவனிக்காமை, சமநிலை.

**karuṇā** பெ. = ⟪करुणा⟫ : அன்பு, கருணை.

**muditā** பெ. = ⟪मुदिता⟫ : மகிழ்ச்சி, குறிப்பாக பிறரின் மகிழ்ச்சியில் மகிழ்தல் (சீற்றத்திற்கு எதிர்ப்பொருள்).

## 3.7. பயிற்சி

**அ) பின்வரும் வாக்கியங்களைப் பெருக்கால் மாற்றவும்:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**அ) பெயர் வாக்கியங்களை உருவாக்கவும்:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**அ) பெண்பால் மொழிபெயர்க்கவும்:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**அ) சமசுகிருதத்திற்கு மொழிபெயர்க்கவும்:**

1. உமா ஒரு தெய்வீகப் பெண்.
2. வேதம் ஸ்ருதி ஆகும்.
3. ஆசிரியர்கள் தெய்வீகப் பெண்கள் ஆவர்.
4. பால் எருமைகள் விலங்குகள் ஆகும்.
5. கவிஞர்கள் ஆசிரியர்கள் ஆவர்.
6. க்ஷத்திரியர்கள் இரண்டுமுறை பிறந்தவர்கள்.
7. புனித ஆண்கள் சூத்திரர்கள் ஆவர்.
