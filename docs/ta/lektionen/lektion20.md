# பாடம் 20

## 20.1. Possesivkomposita = बहुव्रीहि ஆண்பால்.

::: media
![](/images/lekt2004.webp)
அமைப்பு: बहुव्रीहिः पुरुषः
ஜோத்பூர் = जोधपुर
(பட மூலம்: [விவரங்கள்](/ta/licenses#lekt2004))
:::


बहुव्रीहिः = बहवो व्रीहयो यस्य सः = "நிறைய அரிசியைக் கொண்டவர்"

:::: grammar-box

**ஒரு பahuவ்ரிஹி என்பது, தத்புருஷாவிற்கு எதிராக, அதன் உறுப்புகளால் வெளிப்படுத்தப்படும் வேறு ஏதோ ஒன்றைக் குறிக்கிறது: बालपुत्रः ஒரு தத்புருஷாவாகக் கரைக்கப்படும்போது "ஒரு இளம் மகன்" என்று அர்த்தம், அதாவது, கலப்புச் சொல்லின் இறுதி உறுப்பால் (पुत्र) வெளிப்படுத்தப்படும் ஒரு விஷயம், बालपुत्रः ஒரு பahuவ்ரிஹியாகக் கரைக்கப்படும்போது "ஒருவரின் மகன் இளமையானவர்" என்று அர்த்தம், அதாவது, குறிக்கப்பட்டது மகன் (पुत्र) அல்லது இளமையானவர் (बाल) அல்ல, மாறாக இளம் மகனிலிருந்து வேறுபட்ட ஒரு நபர், அதாவது அவரது தந்தை.**

**சொத்துக் கலப்புச் சொற்கள் (Possessivkomposita) தொடக்கத்தில் எப்போதும் பெயர்ச்சொல்லாக்கம் செய்யக்கூடிய உரிச்சொற்களாகும். எனவே, ஒரு பahuவ்ரிஹியின் ஆண்பால்/பெண்பால்/நடுப்பால், கலப்புச் சொல்லின் இறுதி உறுப்பின் பால் அல்ல, அது குறிக்கும் விஷயத்தைப் பொறுத்தது.**

::::

:::: grammar-box

**ஒரு பahuவ்ரிஹியைக் கரைக்க வரைபடம்:**

**1. முதல் உறுப்பு பெரும்பாலும் பெயர்ச்சொல் (प्रथमा) ஒருமை, இரட்டை அல்லது பன்மை -- 2. உறுப்பு பெயர்ச்சொல் ஒருமை, இரட்டை அல்லது பன்மை -- வேறு ஒரு விகுதியில் தொடர்புச்சொல் (பெரும்பாலும் உரிமை விகுதி - षष्ठी) மற்றும் மொத்த பahuவ்ரிஹியின் பால் மற்றும் எண்ணிக்கையில் -- மொத்த பahuவ்ரிஹியின் எண்ணிக்கை, விகுதி மற்றும் பாலில் விளக்கச்சொல்.**

::::

உதாரணங்கள்:


::: indent
गतपापः = गतं पापं यस्य सः = "ஒருவரின் கெடுதல் சென்றது" = "ஒருவன் கீழ்மைகளிலிருந்து விடுபட்டவர்"

பால்வினை ஒருமை गतपापम् = गतं पापं यस्य तम्

கருவி ஒருமை गतपापेन = गतं पापं यस्य तेन

உரிமை ஒருமை गतपापस्य = गतं पापं यस्य तस्य

பெயர்ச்சொல் பன்மை गतपापाः = गतानि पापानि yeषां ते

மற்றும் பல.

अस्तमोहा = अस्तो मोहो यया सा = "ஒரு (பெண்), அவள் மயக்கத்தை அகற்றியவர்"

प्राप्तोदको ग्रामः = प्राप्तमुदकं यं s ग्रामः = "ஒரு கிராமம், அங்கு நீர் வந்தது" = "ஒரு வெள்ளத்தால் அச்சுறுத்தப்பட்ட கிராமம்"

पुण्यवत्पुत्रः ஒரு பahuவ்ரிஹியாக = पुण्यवान्पुत्रो यस्य सः, அல்லது: पुण्यवन्तः पुत्रा यस्य सः = "ஒருவரின் மகன் புண்ணியத்தைக் கொண்டவர்" அல்லது: "ஒருவரின் மக்கள் புண்ணியத்தைக் கொண்டவர்"
:::

:::: grammar-box

**முதல் உறுப்பு மற்றும் இறுதி உறுப்புக்கு இடையேயான தொடர்பு ஒரு பahuவ்ரிஹியில் இருக்கலாம்:**

*   **உரிச்சொல்**
*   **இணைச்சொல்**
*   **விகுதி**
*   **வினையிலக்கணம்**

**தத்புருஷாவைப் போல, குறிப்பிட்ட உறுப்பு பெரும்பாலாக இரண்டாவது இடத்தில் இருக்கும்.**

::::

பாரம்பரியமாக, நாம் வேறுபடுத்துகிறோம்:

*   समानाधिकरणबहुव्रीहिः : विग्रहवाक्य இல் முதல் உறுப்பு மற்றும் இறுதி உறுப்பு ஒரே விகுதியில் இருக்கும்
    
*   व्यधिकरणबहुव्रीहिः : विग्रहवाक्य இல் முதல் உறுப்பு மற்றும் இறுதி உறுப்பு வேறுபட்ட விகுதிகளில் இருக்கும்

## 20.2. பகுவிரிஹி குணப்பெயர் முன்சொல் உடன்

:::: grammar-box

**வடிவமைப்பு:**

::: indent
**குணப்பெயர் -- பெயர்ச்சொல்**
:::

**உதாரணம்:**

::: indent
गुणवत्पुत्रो ब्राह्मणः =  गुणवान्पुत्रो यस्य स ब्राह्मणः = "ஒரு பிராமணர், அவருடைய மகன் / மக்கள் நல்ல குணங்களைக் கொண்டவர்"
:::

**குறிப்பாக, தத்புருஷத்தில் அரிதான -- பிபூதபூர்வபாத (PPP) மூலம் குணப்பெயர் விகாரம். விடுதலையில் பெரும்பாலும் கருவிநிலையில் (तृतीया) (அரிதாக உடைமையிலும் / षष्ठी) தொடர்புச்சொல் இருக்கும்.**

**நெறிமுறை:**

*   **பிபூதபூர்வபாதம் - பெயர்ச்சொல் = பெரும்பாலும் பகுவிரிஹி**
*   **பெயர்ச்சொல் -- பிபூதபூர்வபாதம் = பெரும்பாலும் தத்புருஷம்**

**உதாரணம்:**

::: indent
कृतफल ३ = कृतं फलं yeन सः । यया सा । yeन तत् = "ஒருவர் / ஒருத்தி / ஒன்று, அது ஒரு பலனை உருவாக்கியவர், ஒருவர் / ஏதேனும் பயனுள்ளவர்"
:::

::::

## 20.3. பல்லவீஹி இணைப்பீட முன் உறுப்புடன்

:::: grammar-box

**வார்ப்புரு:**

::: indent
**பெயர்ச்சொல் -- பெயர்ச்சொல்**
:::

**எடுத்துக்காட்டுகள்:**

::: indent
शूरपुत्रो नरः = शूरा एव पुत्रा यस्य स नरः = "ஒரு ஆண், அவனுடைய மக்கள் வீரர்கள்"

तदन्त ३ = सो ऽन्तो यस्य सः । यस्याः सा । यस्य तत् = "அதன் முடிவு இதுவானது" = "இதனுடன் முடிவது"
:::

::::

:::: grammar-box

**आदि । आदिक । आद्य "முதல், தொடக்கம்" என்ற பின் உறுப்புடன் கூடிய இணைப்பீட பல்லவீஹிகள் மிகவும் முக்கியமானவை; அரிதாக प्रभृति "தொடக்கம்" என்ற பின் உறுப்புடன் கூடியவை. அத்தகைய சங்கிலிச் சொற்கள் "மற்றும் பல" என்பதைக் குறிக்கும்:**

**எடுத்துக்காட்டு:**

::: indent
देवा इन्द्रादयः =  इन्द्र आदिर्येषां ते देवाः = "இந்திரன் முதலானவர்கள் தேவர்கள்" = "இந்திரன் மற்றும் மற்ற தேவர்கள்" = "இந்திரன் மற்றும் மீதமுள்ள தேவர்கள்"
:::

**"ஒரே" என்பதை வெளிப்படுத்த, मात्रा பெ. "அளவு, வரம்பு" என்ற பின் உறுப்புடன் கூடிய பல்லவீஹிகளைப் பயன்படுத்தலாம்:**

**எடுத்துக்காட்டு:**

::: indent
शब्दमात्रम् = शब्दो मात्रा यस्य तत् = "ஒரு சொல் அளவு கொண்டது" = "ஒரே ஒரு சொல்"
:::

**ஒரு முன்னர் வந்த பண்பு விசேஷணத்திற்குப் பின் मात्र வந்தால், "உடனடியாக" என்று மொழிபெயர்க்க வேண்டும்:**

**எடுத்துக்காட்டு:**

::: indent
जातमात्रं शत्रुं घ्नन्ति = जातं मात्रा यस्य तं शत्रुं घ्नन्ति = "அவர்கள் ஒரு எதிரியைக் கொல்கிறார்கள், அதன் அளவு உருவாவதாகும்" = "அவர்கள் எதிரியை அவன் உருவான உடனேயே கொல்கிறார்கள்"
:::

## 20.4. கசுவல் முற்பகுதியுடன் பahuव्रीहि

அதாவது, பahuव्रीहि, जिसका முற்பகுதி nominative-க்கு (प्रथमा) மாற்றாக வேறு ஒரு கசுவைக் குறிக்கிறது.

உதாரணம்:

::: indent
देवरूपा = देवस्यैव रूपं यस्याः सा = "ஒரு (பெண்), जिसका உருவம் ஒரு கடவுளின் உருவம்" "கடவுளின் அழகிய உருவம் கொண்ட ஒரு பெண்"
:::

:::: grammar-box

**பொதுவான விதிக்கு விலக்கு கலப்புப் பகுதிகளின் வரிசை குறித்த:**

**ஒரு உடல் பகுதியை (குறிப்பாக கை) குறிக்கும் கசுவல் பகுதி இரண்டாவது இடத்தில் இருக்கும்:**

**உதாரணம்:**

::: indent
दण्डहस्तः =  दण्डो हस्ते (Lok. sg.) यस्य सः = "ஒருவர், जिसका கையில் ஒரு கத்தி உள்ளது" = "ஒருவர், கையில் ஒரு கத்தி வைத்திருப்பவர்."
:::

## 20.5. முற்பகுதியில் வினையெச்சம் கொண்ட பahuव्रीहि

முற்பகுதியில் ஒரு வினையெச்சம், ஒரு முன்னொட்டு, ஒரு முன்னொட்டு அல்லது வேறு ஒரு அசைவிலா சொல் இருக்கும்; அத்தகைய சங்கிலிச் சொற்கள் பொதுவாக नित्यसमास ஆகும்.

உதாரணங்கள்:

::: indent
अपुत्रो नरः = पुत्रो यस्य नास्ति स नरः = "ஒரு மகனை இல்லாத ஒரு ஆண்" = "மகனற்ற ஒரு ஆண்"

दुर्बल ३ = "ஒருவர் / ஏதேனும் ஒன்றின் வலிமை மோசமானது" = "வலிமை இல்லாத, பலவீனமான"
:::

:::: grammar-box

**सह "கூடிய" என்பது ஒரு பahuவ्रीஹியின் முற்பகுதியாக இருக்கும்போது, அது பெரும்பாலும் स ஆல் மாற்றப்படுகிறது.**

**உதாரணம்:**

::: indent
सपुत्रः =  सहपुत्रः =  पुत्रेण सहितः । पुत्रेण सह् = "ஒரு மகனுடன்", "ஒரு மகனால் தொடர்ந்து செல்லப்பட்ட"
:::

## 20.6. முடிவுறு உறுப்பின் விகாரம் ஒரு பahuரீஹியின்

:::: grammar-box

**ஒரு பahuரீஹியின் முடிவுறு உறுப்பு, அதன் அசல் பால் எதுவாயினும், பலபால் உரிச்சொல்லாக விகரிக்கப்படுகிறது. எனவே, ஒரு சமசுகிருதத்தில் முடிவுறு உறுப்பு அதன் அசல் பாலிலிருந்து வேறுபட்ட பால் கொண்டிருந்தால், அது ஒரு பahuரீஹியாக இருக்க வேண்டும், அது ஒரு சமஹாரதவ்வா (நடுபால் ஒருமை) அல்லவென்றால்.**

## 20.7. பஹுவிர்ஹீ வகைகளின் வேறு பிரிவு

உதாரணங்கள் பின்னர் பயிற்சிக்காகத் தரப்பட்டுள்ளன; சிலவற்றிற்குத் தேவையான இலக்கணம் மற்றும் சொற்பொருள் இதுவரை விவரிக்கப்படவில்லை.

1.  முன்பகுதியில் குணப்படுத்தும் சொல் — பின்பகுதியில் குணப்படுத்தப்பட்ட சொல்: स्थिरचित्तः = स्थिरं चित्तं यस्य सः
2.  முன்பகுதியில் அசைக்கப்படாத சொல்: उच्चैःश्रवस्
3.  முன்பகுதியில் ஒப்பீடு: कुशाग्रधीः =  कुशाग्र इव धीर्यस्य सः
4.  அமைந்த ஒப்பீடு: उष्ट्रमुखः = उष्ट्रस्य मुखमिव मुखं यस्य सः = "ஒட்டக வாய்" = அதன் வாய் ஒட்டகத்தின் வாயைப் போன்றது
5.  தோராயமான எண்ணிக்கையில் பின்பகுதியாக எண்ணுப்பெயர்: उपसशाः = दशानां समीपे ये सन्ति ते = "தோராயமாக பத்து"
6.  இரண்டு பகுதிகளும் எண்ணுப்பெயர்கள்: एकद्वाः = एको वा द्वौ वा = "ஒன்று அல்லது இரண்டு"
7.  முன்பகுதியில் sa-/saha- உடன்: सपुत्रः । सहपुत्रः
8.  முன்பகுதியில் sa- (= समान) உடன்: सजनपदः = समानो जनपदो यस्य सः
9.  नञ्बहुव्रीहिः = முன்பகுதியில் a-/an- உடன்: अपुत्रः = न विद्यते पुत्रो यस्य सः ; अनङ्गः = न विद्यते अङ्गं यस्य सः
10.  முன்பகுதியில் பெயர்ச்சொல் போன்றவை உடன்: प्रवातः =प्रकृष्टो वातो यस्मिन् सः ; निर्धनः = निर्गतं धनं यस्मात्सः ; सुबुद्धिः = सुष्ठु बुद्धिर्यस्य सः ; दुर्बुद्धिः = दुष्टा बुद्धिर्यस्य सः
11.  இடைநிலை திசைகளைக் குறிக்க திசைச்சொற்கள்: पुर्वोत्तरा "வடகிழக்கு"

## 20.8. பகுவ்ரிஹீ மற்றும் விக்லிப வாக்கியத்தின் தொடர்பு

ஒவ்வொரு பகுவ்ரிஹீயும் விக்லிப வாக்கியத்தால் விரிவுபடுத்தப்படலாம், ஆனால் ஒவ்வொரு விக்லிப வாக்கியத்தையும் பகுவ்ரிஹீயால் மாற்ற முடியாது. ஹெர்மான் ஜார்ஜ் ஜாகோபி (1850 - 1937), இருவற்றின் தொடர்பையும் நெருக்கமாக ஆராய்ந்தவர் (Compositum und Nebensatz, 1897), எழுதுகிறார்:

::: indent
"ஜெர்மன் அல்லது பிற நவீன மொழிகளிலிருந்து சமஸ்கிருதத்திற்கு மொழிபெயர்க்கும்போது, அனைத்து துணை வாக்கியங்களையும் சங்கிலிகளால் மீண்டும் வழங்கக்கூடாது, ஆனால் அலங்காரமான மற்றும் விவரிக்கும் ones மட்டுமே; அவை கருத்து ரீதியான அவசியமான அல்லது முக்கியமான தீர்மானத்தைக் கொண்டிருக்கும், அவை சமஸ்கிருதத்திலும் விக்லிப வாக்கியங்களாகத் தோன்றும்."
:::

இது சரி என்று இருக்கலாம். இருப்பினும், இந்தியர்கள் நம்மை "கருத்து ரீதியான அவசியமான அல்லது முக்கியமான" என்று கருதுவதை பலவற்றை அலங்காரமான மற்றும் விவரிக்கும் என்று கருதுகிறார்கள்.

## 20.11. பயிற்சி 2

A) சமஸ்கிருதத்தில் மொழிபெயர்க்கவும் மற்றும் சங்கிலிச் சொற்களைப் பிரிக்கவும்:

इन्द्रशत्र्वनार्या देवेन्द्रेण जीयन्ते ॥१॥

शूरबलक्षत्रिययोधः शूरपुत्रमिच्छति ॥२॥

सुदुर्गममार्गेण स्वर्गं गम्यते । सुगमस्तु नरकमार्गः ॥३॥

मृतपुत्रब्राह्मणी रोदिति ॥४॥

वीतमोहब्राह्मणः सम्पन्नरूपामपि शूद्रां न लुभ्यति ॥५॥

सुनीतिपुत्रः प्राप्तमतिदर्शनसाधुं गच्छति ॥६॥

प्राप्तप्रभावक्षत्रिया दृष्टमात्राञ्छत्रून्घ्नन्ति ॥७॥

जितशत्रुयोधाः शत्रुजितान्मुञ्चन्ति ॥८॥

कृतोपनयनबालः शिवादिदेवपूजां करोति ॥९॥

बुद्धगता दुःखादिसत्यानि शृण्वन्ति ॥१०॥

B) சங்கிலிச் சொற்களைப் பயன்படுத்தி சமஸ்கிருதத்திற்கு மொழிபெயர்க்கவும்:

1. கையில் கத்தியைப் பிடிக்காத ஒரு க்ஷத்திரியர் மக்களைக் காக்கமாட்டான்.

2. காளிதாசனும் பிற கவிஞர்களும் சமஸ்கிருதத்தின் ஆசிரியர்களாவர்.

3. ஒரு க்ஷத்திரியர் ஆயுதங்களின் மூலம் தனது வாழ்வாதாரத்தைப் பெறுகிறார்.

4. சூத்திரப் பெண்களுக்கும் தர்மத்தின் கீழ் அहिंसा (கொல்லாமை), உண்மை, சுத்தம், புகார் செய்யாமை, கெடுதல் இன்மை மற்றும் பொறுமை ஆகியவை உள்ளன.
