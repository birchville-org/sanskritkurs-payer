(காளிதாசன்: ரகுவம்சம் 1.1)

நான் உலகின் பெற்றோர்களை வணங்குகிறேன்,
பார்வதி மற்றும் சிவன்,
அவர்கள் ஒன்றுடன் ஒன்று இணைந்திருப்பது போல
சொல்லும் பொருளும் புரிதலுக்கு இணைந்திருப்பது போல
சொல்லின் பொருள்.

தொடக்கத்தில் ஒரு விசித்திரம்:


>"விலியம் ஜோன்ஸ் [1746–1794] மற்றும் ஹென்றி தாமஸ் கோல்ப்ரூக் (1765—1857) சமஸ்கிருதத்தை முதன்முதலில் ஆழமாகக் கற்று, பகுதி துல்லியமாக மொழிபெயர்த்து, அது செழுமையான இலக்கியத்தைக் கொண்டிருப்பதையும், பண்டைய மொழிகளுடன் குறைந்த அளவு தொடர்பு கொண்டிருப்பதையும் கண்டபோது, அவர்கள் குறைந்த அளவு எதிர்விமர்சனத்தை எதிர்கொண்டனர். சமஸ்கிருதத்தின் இந்த நெருக்கமான தொடர்பு, புவியியல் ரீதியாக மிகவும் தொலைவில் உள்ள ஐரோப்பிய மொழிகளுடன், யூத மொழியிலிருந்து அனைத்து மொழிகள் வந்தன அல்லது பெரும்பாலும் தனிமைப்படுத்தப்பட்டன என்ற பழைய கருத்துகளுடன் பொருந்தவில்லை. எனவே, பிரபலமான மொழியியல் நிபுணர் டக்லாட் ஸ்டீவர்ட் (1753—1828) எளிமையான வழியைத் தேர்ந்தெடுத்தார், அவர் சமஸ்கிருத மொழியுடன் தொடர்பான அனைத்து வரலாற்றையும் பொய் என்று அறிவித்தார். அவர் ஒரு கட்டுரை எழுதி, அதில் பிராமணர்கள் யூத மொழியைப் போலவே கிரேக்கம் மற்றும் லத்தீன் மொழிகளை அடிப்படையாகக் கொண்டு உருவாக்கியதாகவும், மொழி மற்றும் இலக்கியம் அனைத்தும் பொய் என்று நிரூபிக்க முயன்றார். இந்த கருத்தை டப்லின் பல்கலைக்கழகப் பேராசிரியர் சார்ல்ஸ் வில்லியம் வாள், 1840 ஆம் ஆண்டில் விரிவாகக் கூறினார் (கோட்டிங்கன் அறிவியல் செய்திகள் 1842 பக். 1888)."
>

(ஆர்தர் லுயெல்லின்) (1914–1986) _இந்தியா அதிசயம்_ பகுதி: முஸ்லீம்கள் வருவதற்கு முன் இந்திய துணைக்கண்டத்தின் கலாச்சாரத்தை ஒரு ஆய்வு. -- லண்டன் : சிட்க்விக் & ஜாக்சன், 1954. -- அதன்பிறகு பல பதிப்புகள், சிறுநூல் பதிப்புகளும். -- **கட்டாய வாசிப்பு.** முஸ்லீம்கள் வருவதற்கு முன் இந்தியாவில் வாழ்வு, வரலாறு மற்றும் கலாச்சாரம் குறித்த ஒரு நல்ல சுருக்கக் காட்சி. சக்தியமான இந்துவியலின் வெவ்வேறு துறைகள் குறித்த முழுமையான சுருக்கக் காட்சி.

## 1.2. சமஸ்கிருதத்தின் ஒலிகள்

பாரம்பரிய இந்திய வகைப்பாட்டின்படி சமஸ்கிருதத்தின் ஒலிகள் மற்றும் அவற்றின் அறிவியல் எழுத்துப்பெயர்ப்பு.

::: media
![](/images/lekt0106.webp)
(பட மூலம்: [விவரங்கள்](/ta/licenses#lekt0106))
:::
சமஸ்கிருதத்தின் நவீன அகராதி இந்த வகைப்பாட்டின் தொடர்பில் அமைக்கப்பட்டுள்ளது. சமஸ்கிருத இலக்கணத்தைப் புரிந்து கொள்ள இந்த வகைப்பாடு அவசியம்; எனவே அதனை மனப்பாடமாக அறிந்திருக்க வேண்டும்:

::: note-box
வகைப்பாடு
**எளிய உயிர் எழுத்துகள்** (samānākṣara -- ⟪समानाक्षर⟫):
⟪अ⟫ a, ⟪आ⟫ ā, ⟪इ⟫ i, ⟪ई⟫ ī, ⟪उ⟫ u, ⟪ऊ⟫ ū, ⟪ऋ⟫ ṛ, ⟪ॠ⟫ ṝ, ⟪ऌ⟫ ḷ
**இரட்டை உயிர் எழுத்துகள்** (sandhyakṣara -- ⟪सन्ध्यक्षर⟫):
⟪ए⟫ e, ⟪ऐ⟫ ai, ⟪ओ⟫ o, ⟪औ⟫ au
**உயிர்மெய் எழுத்துகள்** (vyañjana / hal -- ⟪व्यञ्जन⟫ / ⟪हल्⟫):
⟪क⟫ ka, ⟪ख⟫ kha, ⟪ग⟫ ga, ⟪घ⟫ gha, ⟪ङ⟫ ṅa
⟪च⟫ ca, ⟪छ⟫ cha, ⟪ज⟫ ja, ⟪झ⟫ jha, ⟪ञ⟫ ña
⟪ट⟫ ṭa, ⟪ठ⟫ ṭha, ⟪ड⟫ ḍa, ⟪ढ⟫ ḍha, ⟪ण⟫ ṇa
⟪त⟫ ta, ⟪थ⟫ tha, ⟪द⟫ da, ⟪ध⟫ dha, ⟪न⟫ na
⟪प⟫ pa, ⟪फ⟫ pha, ⟪ब⟫ ba, ⟪भ⟫ bha, ⟪म⟫ ma
⟪य⟫ ya, ⟪र⟫ ra, ⟪ल⟫ la, ⟪व⟫ va
⟪श⟫ śa, ⟪ष⟫ ṣa, ⟪स⟫ sa
⟪ह⟫ ha
:::
### 1.2.1. தனித்தனி ஒலிகளின் உச்சரிப்பு

::: laut-table
| ஒலி | விளக்கம் |
| :--- | :--- |
| **a - ⟪अ⟫** | “குறில் a” இந்தியர்களிடம் -- பழங்காலம் முதலே -- பொதுவாக ə என உச்சரிக்கப்படுகிறது. ஐரோப்பாவில் குறில் a ஆகவும், வங்காளத்தில் குறில் இருண்ட o ஆகவும் உச்சரிக்கப்படுகிறது. |
| **ṛ - ⟪ऋ⟫** | போஹீமிய உயிரொலி r போல். இ என்ற ஒலியின் மெல்லிய அடிதொனி உடையது. |
| **ṝ - ⟪ॠ⟫** | போஹீமிய உயிரொலி r போல். உ என்ற ஒலியின் மெல்லிய அடிதொனி உடையது. |
| **jñ - ⟪ज्ञ्⟫** | மராட்டியில் dny அல்லது வட இந்தியாவில் gy என்றும் உச்சரிக்கலாம். |
| **ś - ⟪श्⟫** | நாக்கின் நுனி கீழ்நோக்கி வளைந்த நிலையில் sch ஒலி. “mischen” என்ற சொல்லில் உள்ள sch போன்றது. |
| **ṣ - ⟪ष्⟫** | நாக்கின் நுனி பின்னோக்கி வளைந்த நிலையில் ach ஒலி. பெரும்பாலும் தொண்டையின் பின்பகுதியில் உச்சரிக்கப்பட்டு kh போல் ஒலிக்கிறது. |
| **h - ⟪ह्⟫** | மூச்சொலி, ஒருபோதும் நீட்டல் குறியீடாக இல்லை. |
| **ḥ - :** | **விசர்க (விசர்ஜனீய)** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫. முன்வரும் உயிரெழுத்தின் அல்லது முன்வரும் இரட்டை உயிரொலியின் இரண்டாம் பகுதியின் அடிதொனி கொண்ட குரல்வளையற்ற மூச்சொலி: agniḥ -- ⟪अग्निः⟫ = agnihi, devaiḥ -- ⟪देवैः⟫ = devaihi, gauḥ -- ⟪गौः⟫ = gauhu |
| **ṃ** | **அனுஸ்வர** -- ⟪अनुस्वर⟫. உரசல் ஒலிகள், h, l முன்: உயிரெழுத்தின் மூக்கொலி. சொல்முடிவில் = m. சொல் நடுவில் மெய்யெழுத்துகளுக்கு முன்: அடுத்த மெய்யெழுத்துக்கு ஒத்த மூக்கொலி: saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
வாக்கியங்களை, செய்யுட்களை அல்லது சொற்களை மிகவும் மெதுவாகவும் சீராகவும் உயிரெழுத்துகளின் நீளத்தை கவனமாகக் கருதி படிப்பதன் மூலம் சிறந்த உச்சரிப்பை அடையலாம்.

## 1.3. பயிற்சி

**அ) பின்வரும் சொற்களைப் படியுங்கள்:**

1. varṇa brāhmaṇaḥ kṣatriya vaiśya śūdra — ⟪वर्ण⟫ ⟪ब्राह्मणः⟫ ⟪क्षत्रिय⟫ ⟪वैश्य⟫ ⟪शूद्र⟫
2. brahmā viṣṇu śiva — ⟪ब्रह्मा⟫ ⟪विष्णु⟫ ⟪शिव⟫
3. āśrama brāhmacārin gṛhastha vānaprastha saṃnyāsin — ⟪आश्रम⟫ ⟪ब्राह्मचारिन्⟫ ⟪गृहस्थ⟫ ⟪वानप्रस्थ⟫ ⟪संन्यासिन्⟫
4. ṛgveda sāmaveda yajurveda atharvaveda — ⟪ऋग्वेद⟫ ⟪सामवेद⟫ ⟪यजुर्वेद⟫ ⟪अथर्ववेद⟫
5. upaniṣad — ⟪उपनिषद्⟫
6. jaina bauddha — ⟪जैन⟫ ⟪बौद्ध⟫
7. prajñāpāramitā — ⟪प्रज्ञापारमिता⟫
8. cakra vajra — ⟪चक्र⟫ ⟪वज्र⟫
9. pitṝn — ⟪पितॄन्⟫
10. saṃskṛta — ⟪संस्कृत⟫

**அ) மேலே உள்ள ஒலி வகைப்பாட்டில் சமசுகிருத வாக்கியங்களைப் படியுங்கள்.**
