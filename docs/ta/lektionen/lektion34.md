# பாடம் 34

## 34.1. பூதக்காலம் (⟪லிட்⟫)

சங்கீத சமஸ்கிருதத்தில், முழுமை வடிவத்திற்கு அசைவு மற்றும் பங்கீடு மட்டுமே உள்ளன.

::: grammar-box
**முழுமை உருவாக்கத்திற்கு இரண்டு வகைகள் உள்ளன:**
*   **மீண்டும் சொல்லப்பட்ட முழுமை = ⟪द्वित्वलिट्⟫**
*   **சிறப்பு முழுமை = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**சிறப்பு முழுமை (⟪अनुप्रयोगलिट्⟫) பயன்படுத்தப்படுகிறது:**
1. **விலக்கப்பட்ட தொடர்புகளுடன் (காரணம், விருப்பம், அடிக்கடி, பெயர்ச்சொற்கள்)**
2. **நீண்ட ஒலியால் (ā- தவிர) தொடங்கும் வார்த்தைகளுடன், அல்லது இரண்டு எழுத்துக்களுக்கு முன் ஒலியால் (a- தவிர)**
3. **சில பிற வார்த்தைகளுடன்**
:::
## 34.2. இரட்டித்த பூதக்காலம் (⟪த்வித்வலிட்⟫)

### 34.2.1. தண்டு நிலை மாற்றம்

::: grammar-box
**கல்வி:**

**வலிமையான தனிச்சொல்:** ஒருமை பரமைபதம்
*   **மீள்வடிவம் உயர்நிலை அல்லது நீட்சிநிலை வேர் + முற்றுப்பெயர்**

**வலிமையற்ற மூலம்:** எஞ்சிய அனைத்து வடிவங்களும்
*   **பெருக்கப்பட்ட ஆழ்நிலை மூலம் + முன்னிலை முடிப்பு**
:::
::: grammar-box
**பொதுவாக (முன்னிலைக்கு வெளியேயும்) மூலவடிவ மாற்றம் இல்லாத மூலங்கள்:**
*   **(ஒலிப்பு)-ஒலிப்பு-நீண்டசொல்-ஒலிப்பு**
*   **(ஒலிப்பு)-ஒலிப்பு-சொல்-ஒலிப்பு-ஒலிப்பு**

**இலக்கணத்தில், மேலும் a-ஒலி வடிவத்தின் மூலச்சொற்களுக்கு வேர்ச்சொல் மாற்றம் இல்லை:**
*   **a-ஒலி**
*   **ā-ஒலி**
:::

### 34.2.4. ஒலிவல்ல எழுத்துக்களால் தொடங்கும் மூலச்சொற்களின் மீண்டும் வருகை

::: grammar-box
**ஒலிப்புக்கான மீள்சேர்க்கைக்கான விதிகள் [பாடம் 33](lektion33.md)-ல் கொடுக்கப்பட்டுள்ளன.**

**ஒலிப்பு வல்லினத் தாய்ச்சொற்களுக்கு இடையே குறுகிய மூல ஒலிப்பு வல்லினம் இருக்கும்.**

**ஒலிவாய்ப்புகள் ஒலியெழுத்துக்களுக்கு முன், தொடர்புடைய குறுகிய ஆழ்நிலை ஒலியால் குறைக்கப்படுகின்றன.**

**ṛ, ṝ, ḷ, மற்றும் இறுதி இடையியல் ஒலிகள் -a- மூலம் மீள்வதால் வரும்.**

## 34.3. மறுநிகைத்த முற்றெச்ச வகைகள்

வகைப்படுத்தல் தத்துவம்: மூலச்சொல் மாற்றத்தின் சிறப்பு அம்சங்கள்:
*   மூலச்சொல் மாற்றம் இல்லாத முற்றெச்சம்: வகை I
*   மூலச்சொல் மாற்றம் உள்ள முற்றெச்சம்: வகை II - V
*   விதிவிலக்கான முற்றெச்ச உருவாக்கங்கள்

## 34.4. முழுமை வகை I: மூலச்சொல் மாற்றம் இல்லாத முழுமை

## 34.7. பயிற்சி

கீழ்க்கண்ட வினை வடிவங்களுக்கு, ஆள், எண் மற்றும் பால் ஆகியவற்றிற்கேற்ப பொருந்தும் முற்றெச்ச வடிவங்களை உருவாக்குக:

## 34.8. மொழிபெயர்ப்புப் பயிற்சி

⟪पद्मपुराण⟫ பிராமணர்களுக்கு அளித்தல் குறித்த பின்வரும் உரை மொழிபெயர்க்கவும்:

⟪क्षितिं⟫ ⟪सशस्यां⟫ ⟪यो⟫ ⟪दद्याद्ब्राह्मणाय⟫ ⟪द्विजो⟫*:sig[⟪त्तम⟫]* ⟪।⟫
