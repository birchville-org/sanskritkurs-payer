# பாடம் 29

## 29.1. காரணவினையில் பரஸ்மைபதம் (⟪பரஸ்மைபத⟫) மற்றும் ஆத்மநேபதம் (⟪ஆத்மநேபத⟫) பயன்பாடு

::: grammar-box
**காரகம் சில விதிவிலக்குகளுடன் உபாயபதம் (⟪उभयपद⟫)**
:::
::: grammar-box
**காரகத்தில் ஆத்மனபதம் (⟪आत्मनेपद⟫) பயன்படுத்தப்படுகிறது:**

**1. தூண்டப்பட்ட செயலின் பலன் தூண்டப்படுபவருக்கு நன்மை பயக்கும் போது:**
:::
உதாரணம்:

⟪रामः⟫ ⟪कटं⟫ ⟪कारयते⟫ = "ராமா தனக்காக (தனது சொந்த நலனுக்காக) ஒரு பாய் செய்யச்செய்கிறான்"

**2. காரகம் பரவாய்மொழி வினைச்சொற்களுக்கு ப்ரதிபிம்பமாக பயன்படுத்தப்படும் போது ("தன்னைக் காட்டு", "தன்னைக் கேட்கச்செய்" போன்றவை), அல்லது எளிய வினையின் பொருள் காரகத்தின் காரணமாக (⟪कर्तृ⟫) இருக்கும் போது:**

உதாரணம்:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "விஷ்ணு தனது பக்தர்களுக்குத் தன்னைக் காட்டுகிறான்"

முடிவு: ⟪भक्ता⟫ ⟪विष्णुं⟫ ⟪पश्यन्ति⟫ = "நம்பிக்கை கொண்டவர்கள் விஷ்ணுவைக் காண்கிறார்கள்"

எனவே விதிகள் பொதுவாக உபாயபதம் (⟪उभयपद⟫) வினைச்சொற்களில் ஆத்மனபதம் (⟪आत्मनेपद⟫) பயன்பாட்டு விதிகளுக்கு ஏற்ப உள்ளன.

## 29.3. மீள்பார்வைக்கான மொழிபெயர்ப் பயிற்சி

சரியான ஜெர்மனில் சொல்வார்த்தை மொழிபெயர்ப்பு செய்யவும் மற்றும் சமஸ்கிருத உரைகளை மனப்பாடம் செய்யவும்:

1\. ⟪अविद्या⟫ இன் வரையறை:

⟪अनित्याशुचिदुःखा⟫:sig[⟪नात्मसु⟫] ⟪नित्यशुचिसुखात्मख्यातिरविद्या ॥योगसूत्र २⟫.⟪५॥⟫

விளக்கம்: ⟪आत्मसु⟫ = ⟪आत्मन्⟫ m. "ஆன்மா ; அத்தியாத்மிகத்தில் நிறைவேற்றப்படும் வரை பரம்பொருள்" என்பதற்கு உயாழ்பெயர் ஒருமை

2\. ⟪कौटिलीयार्थशास्त्र⟫ 1.4. ⟪दण्ड⟫ சரியான பயன்பாடு பற்றி :

⟪।१६।⟫ ⟪चतुर्⟫ "நான்கு" ஒரு சமசுகிருத சொல்லின் முன் உறுப்பாக

⟪राज्ञा⟫ கருவி. ஒருமை. ஆண்பால். ⟪राजन्⟫ ஆண்பால். "அரசன்"

⟪स्वेषु⟫ : பலர் ஆண்பால் / பெண்பால். ⟪स्व⟫ ⟪३⟫ "சொந்தமான (என், உன், அவன் முதலியன)"

⟪वर्त्मसु⟫ : பலர் பெண்பால். ⟪वर्त्मन्⟫ பெண்பால். "பாதை, ரயில் பாதை, பாதை"
