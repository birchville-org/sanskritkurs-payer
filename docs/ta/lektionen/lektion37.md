# Lektion 37

## 37.1. Das Adverb (⟪क्रियाविशेषणम्⟫)

சமஸ்கிருதத்தில் வினையுரிச்சொற்கள் உருவாக்கப்படுகின்றன

1.  பெயர்ச்சொற்கள் மற்றும் உரிச்சொற்களின் விபக்க வடிவங்கள் மூலம்
2.  சிறப்புப் பிறப்பொட்டுச் சொற்கள் மற்றும் இறுதிச்சொற்கள் உதவியுடன்

முதல் நிலையில், உயிர்ப்புள்ள விபக்கத்திற்கும் வினையுரிச்சொல்லிற்கும் இடையேயான எல்லை மங்கலானதாக உள்ளது. இதில், பழைய, நிலைத்த விபக்க வடிவங்களாக மாற்றமடைந்த வினையுரிச்சொற்கள் ஒரு சிறப்பு நிலையாக அமைகின்றன; அதேசமயம், பிறழ்வியலில் பிற வடிவங்கள் பயன்படுத்தப்படுகின்றன அல்லது தொடர்புடைய பெயர்ச்சொற்கள் பெயர்ச்சொற்களாகப் பயன்படுத்தப்படுவதில்லை.

## 37.2. வினைச்சொற்களின் விகாரப் பயன்பாடு

### 37.2.1. Akkusativ (⟪द्वितीया⟫)

::: grammar-box
காரகம் (⟪द्वितीया⟫) பின்வரும் கேள்விகளுக்கு விடையாக வினையாலணைப்புப் பொருளில் பயன்படுத்தப்படலாம்:

*   எங்கே?
*   மற்றும் பிற.
*   எங்கே?
*   மற்றும் பிற.

பெயரெச்சத்தால் வினையடைவுகள் பயன்படுத்தப்படலாம்:

*   பெயர்ச்சொற்களிலிருந்து
    எடுத்துக்காட்டுகள்:  
    ⟪कामम्⟫ "விருப்பப்படி, விருப்பத்திற்கு"  
    ⟪अर्थम्⟫ "காரணமாக"

*   நடுவினப் பண்புச்சொற்களிலிருந்து
    எடுத்துக்காட்டுகள்:  
    ⟪सुखम्⟫ "எளிதான, நல்வாழ்வு"  
    ⟪नित्यम्⟫ "எப்போதும்"  
    ⟪साधु⟫ "சரி, நல்ல"

*   வினைச்சொற்களில் நடுவினையில்
    எடுத்துக்காட்டுகள்:  
    ⟪तद्⟫ "அப்போது, அதனால்"  
    ⟪यद्⟫ "எங்கே, அது"  
    ⟪एतद्⟫ "இவ்வாறு, இங்கே, இப்போது"
:::
### 37.2.2. கருவிப்பெயர் (⟪तृतीया⟫)

::: grammar-box
கருவிப் பன்மை (⟪तृतीया⟫) ஆகியது பின்வரும் கேள்விகளுக்கு விடையாக வினையெச்சமாகப் பயன்படுத்தப்படலாம்:

*   எதன் மூலம்?
*   என்னோடு?
*   மற்றும் பிற

கருவிப் பால் வினையிலக்கணத்தில் பயன்படுத்தப்படலாம்:

*   பெயர்ச்சொற்களிலிருந்து
    எடுத்துக்காட்டுகள்:  
    ⟪अर्थेन⟫ "காரணமாக"  
    ⟪क्षणेन⟫ "நொடியில், உடனடியாக" (⟪क्षण⟩ ஆண்பால் "நொடி" என்பதிலிருந்து)

*   பண்புச்சொற்களிலிருந்து, பெரும்பாலும் பன்மை வடிவத்திலும்
    எடுத்துக்காட்டுகள்:  
    ⟪दूरेण⟫ "தொலைவில், தொலைவிலிருந்து" (⟪दूर⟫ 3 "தொலைவில், தொலைவில்" என்பதற்கு)  
    ⟪उच्चैस्⟫ "உயர்ந்த, உயர்ந்த ஒலி" (⟪उच्च⟫ 3 "உயர்ந்த, உயர்ந்த, உயர்ந்த ஒலி, கூர்மையான (ஒலி)")
:::
### 37.2.3. திணை (⟪चतुर्थी⟫)

::: grammar-box
அரிதாகவே பெயர்ச்சொல் (⟪चतुर्थी⟫) வினாக்களுக்கு:

*   மற்றும் பிற
*   மற்றும் பிற

உதாரணம்:
:::
::: indent
⟪अर्थाय⟫ "இதற்காக, ... நோக்கத்திற்காக"
:::
### 37.2.4. அபிலவி (⟪पञ्चमी⟫)

::: grammar-box
விலக்கம் (⟪पञ्चमी⟫) பின்வரும் கேள்விகளுக்கு விடையளிக்கும் விதத்தில் வினையெச்சமாகப் பயன்படுத்தப்படலாம்:

*   ஏன்?
*   மற்றும் பிற.
*   எங்கிருந்து?
*   மற்றும் பிற.

பின்வரும் நிலைப்பெயர் வினையெச்சமாகப் பயன்படுத்தப்படலாம்:

*   பெயர்ச்சொற்களிலிருந்து
    எ.கா. ⟪बलात्⟫ "வன்மையாக, வலியுடன்"

*   பண்புச்சொற்களிலிருந்து
    எ.கா. ⟪दूरात्⟫ "தொலைவிலிருந்து"

*   வினைச்சொற்களிலிருந்து
    எடுத்துக்காட்டுகள்:  
    ⟪कस्मात्⟫ "ஏன்"  
    ⟪अकस्मात्⟫ "எதிர்பாராத"
:::
### 37.2.5. பிறப்பு (⟪षष्ठी⟫)

::: grammar-box
அரிதாகவே பெயர்ச்சொல் (⟪षष्ठी⟫) "எவ்வளவு காலத்திற்குப் பிறகு?" என்ற கேள்விக்கு விடையாக வினையிலக்கணப் பயன்பாட்டில் காணப்படுகிறது.

எ.கா. ⟪चिरस्य⟫ "நீண்ட காலத்திற்குப் பிறகு" (⟪चिर⟫ 3-ஐப் பார்க்க: "நீண்ட (காலம்)")
:::
### 37.2.6. இடவிளிச்சை (⟪सप्तमी⟫)

::: grammar-box
இடப்பெயரடை (⟪सप्तमी⟫) பின்வரும் கேள்விகளுக்கு விடையளிக்கும் விதத்தில் வினையெச்சமாகப் பயன்படுத்தப்படலாம்:

*   எங்கே?
*   மற்றும் பிற.
*   மற்றும் பிற.

உதாரணங்கள்:
:::
::: indent
\-⟪अर्थे⟫ "காரணமாக"  
\-⟪कृते⟫ "நிமித்தமாக"  
⟪दूरे⟫ "தொலைவில்"
:::
## 37.3. பயன்பாட்டில் இல்லாத பால்வடிவங்களின் வினையெச்சப் பயன்பாடு

உதாரணங்கள்:
::: indent
⟪जातु⟫ "ஒட்டுமொத்தமாக" (மூலத்தில் "பிறப்பால், இயற்கையாக", பெண்பால் ஒருமை அசைவுக்கு ⟪जातु⟫ \<பெயர்ச்சொல்லாக இப்போது பயன்படுத்தப்படவில்லை\>)

⟪तूष्णीम्⟫ "அமைதியாக" (ஒரு பயன்படுத்தப்படாத ⟪तूष्णी⟫ பெண்பால் "அமைதி"க்கு ஒருமை அசைவுக்கு)

⟪एवम्⟫ "இவ்வாறு" (மற்றவற்றில் இழந்த ஒரு பெயர்ச்சொல் வடிவமான ⟪एव⟫ "ஒன்று, ஒரே"க்கு)
:::
## 37.4. Bildung von Adverbien mit Adverbialsuffixen

::: grammar-box
⟪तद्⟫, ⟪इदम्⟫ அல்லது ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ அல்லது ⟪कु⟫ ஆகிய பண்புச்சொல் மூலங்களிலிருந்து, வினையெச்சப் பின்னொட்டுகளைக் கொண்டு

*   \-⟪तस्⟫ (வினையெச்சம்)
*   \-⟪त्र⟫ (இடவினையெச்சம்)
*   \-⟪था⟫ (நிலை மற்றும் வகை)
*   \-⟪थम्⟫ (நிலை மற்றும் வகை)
*   \-⟪दा⟫ (நேரம்)

ஒத்த பண்புச்சொல் வினையெச்சங்களைப் பெறலாம்.
:::

## 37.5. Adverbiale Komposita

### 37.5.1. வினையெச்சம் அல்லது வினையெச்சப் பயன்பாட்டில் உள்ள விளித்தொகை பின்னொற்றாகக் கொண்ட தொகையிலக்கணம்

உதாரணம்: ⟪सुचिरम्⟫ "மிக நீண்ட (நேரம்)"

### 37.5.2. Adverbial gebrauchte ⟪बहुव्रीहि⟫

உதாரணம்: ⟪रक्षार्थम्⟫ "யாரின் நோக்கம் காத்தல் என்பதோ, அத்தகையவரின் நோக்கத்திற்காக". இது 5.1. உடன் தொடர்புடையதாகவும் கருதப்படலாம்: -⟪अर्थम्⟫ ஒரு வினையெச்சப் பின்னூட்டமாக.

### 37.5.3. ⟪अव्ययीभाव⟫-Komposita

⟪अव्ययीभाव⟫ = "மாறாத/அசைவிலா ஆகிய"

::: grammar-box
ஒரு ⟪अव्ययीभाव⟫ என்பது ஒரு வினையெச்ச சமச்சீர் சொல், அதன் முன் பகுதி ஒரு நிலையற்ற சொல் (பின்னொட்டு, துகள் முதலியவை) ஆகவும், பின் பகுதி ஒரு பெயர்ச்சொல் ஆகவும், அது ஒருமை நடுலிங்க வினைப்பெயர் முடிபை ஏற்கிறது.

கலவையின் பிரிவினையில், முன் உறுப்பு பின் உறுப்பை ஆட்சி செய்யும்:

உதாரணங்கள்:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं⟫ ⟪प्रति⟫ = "அக்ஷிக்கு எதிராக"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "தனது சக்திக்கு ஏற்ப"

⟪अभिमुखम्⟫ = ⟪मुखम्⟫ ⟪अभि⟫ = "முன்னோக்கி, எதிர்"
:::
⟪अव्ययीभाव⟫ மற்றும் यथा⟩ "எவ்வாறு" முன் உறுப்புடன் குறிப்பாக முக்கியமானவை:

எ.கா. ⟪यथाकामम्⟫ = ⟪कामो⟫ ⟪यथास्ति⟫ = "வாழ்க்கை விரும்பியபடி, விருப்பப்படி, தன்னிச்சையாக"

## 37.6. இலக்கண

::: grammar-box
வினைச்சொற்களில்

*   ⟪अस्⟫ 2P "இரு"

## 37.11. Wiederholungsübung

சமஸ்கிருதத்திற்கு மொழிபெயர்க்கவும், முற்றம் கால வினைமுற்றுக்களை மட்டும் பயன்படுத்தவும்:

ஒரு முதியவர் ஒரு கிராமத்திலிருந்து வேறு கிராமத்திற்குச் சென்றபோது, வழியில் அவர் களைத்துப்போனார். எனவே, அவர் ஓய்வெடுக்க, பக்கத்தில் நின்ற மாமரத்தின் அடியில் சென்றார். அந்த மரத்தில் பக்குவமான பழங்கள் இருந்தன. முதியவருக்கு அந்தப் பழங்கள் மீது ஆசை வந்தது. ஆனால், அவர் மரத்தில் ஏறவும், பழங்களைப் பிடிக்கவும் முடியவில்லை. அதிர்ஷ்டவசமாக, அந்த மரத்தில் பழங்களை உண்ணும் வானரங்கள் இருந்தன. அவற்றைக் கண்டபோது, முதியவர் மகிழ்ச்சியடைந்தார். அவர் என்ன செய்தார்? அவர் சில கற்களை எடுத்து, வானரங்களை நோக்கி எறிந்தார். கோபமடைந்த வானரங்கள், சில பழங்களைப் பிடித்து, முதியவன் மீது எறிந்தன. முதியவர், அந்தப் பழங்களை மகிழ்ச்சியுடன் எடுத்து, தான் விரும்பிய இடத்திற்குச் சென்றார். பாருங்கள், முதியவனின் விதி!
