# பாடம் 37

## 37.1. வினையெச்சம் (⟪क्रियाविशेषणम्⟫)

சமஸ்கிருதத்தில் வினையெச்சங்கள் உருவாக்கப்படுகின்றன

1.   பெயர்ச்சொல் மற்றும் உரிமம் சொற்களின் விபாகை வடிவங்கள் மூலமாக
2.   சிறப்பு உறுப்புகள் மற்றும் முடிச்சுக்கள் மூலமாக

முதல் நிலையில், உயிர்ப்புள்ள விபாகை மற்றும் வினையெச்சத்திற்கு இடையேயான எல்லை மிதமாக உள்ளது. இதில் சிறப்பு விஷயங்களாக, பழைய நிலைத்திருக்கும் விபாகை வடிவங்கள் ஆகியவை உள்ளன, அதே சமயம் விபாகையில் பிற வடிவங்கள் பயன்படுத்தப்படுகின்றன அல்லது தொடர்புடைய பெயர்ச்சொற்கள் இப்போதும் பெயர்ச்சொல்லாக பயன்படுத்தப்படவில்லை.

## 37.2. விபாகை வடிவங்களின் வினையெச்ச பயன்பாடு

### 37.2.1. ஆக்காரம் (⟪द्वितीया⟫)

::: grammar-box
ஆக்காரம் (⟪द्वितीया⟫) வினையெச்சமாக பயன்படுத்தப்படலாம்:

*   எப்படி?
*   எவ்வளவு நேரம்?
*   எங்கு செல்ல வேண்டும்?
*   மற்றும் பிற.

ஆக்காரம் வினையெச்சமாக பயன்படுத்தப்படலாம்:

*   பெயர்ச்சொற்களிலிருந்து  
உதாரணங்கள்:  
⟪कामम्⟫ "விருப்பத்திற்கு ஏற்ப, விருப்பம் போல"  
⟪अर्थम्⟫ "காரணமாக"  

*   நடுவுலகத்தில் உள்ள உரிச்சொற்களிலிருந்து  
உதாரணங்கள்:  
⟪सुखम्⟫ "எளிதாக, சந்தோஷமாக"  
⟪नित्यम्⟫ "எப்போதும்"  
⟪साधु⟫ "சரியாக, நல்லதாக"  

*   உரிச்சொற்களிலிருந்து  
உதாரணங்கள்:  
⟪तद्⟫ "அப்போது, அதனால்"  
⟪यद्⟫ "எப்போது, என்று"  
⟪एतद्⟫ "இப்படி, இங்கு, இப்போது"
:::
### 37.2.2. கருவியாக (⟪तृतीया⟫)

::: grammar-box
கருவியாக (⟪तृतीया⟫) வினையெச்சமாக பயன்படுத்தப்படலாம்:

*   எதன் மூலமாக?
*   என்னுடன்?
*   மற்றும் பிற.

கருவியாக பயன்படுத்தப்படலாம்:

*   பெயர்ச்சொற்களிலிருந்து  
உதாரணங்கள்:  
⟪अर्थेन⟫ "காரணமாக"  
⟪क्षणेन⟫ "நேரத்தில், உடனடியாக" (⟪क्षण⟩ m. "நேரம்")  

*   உரிச்சொற்களிலிருந்து, பெரும்பாலும் பல வடிவங்களில்  
உதாரணங்கள்:  
⟪दूरेण⟫ "தொலைவில், தொலைவிலிருந்து" (⟪दूर⟫ 3 "தொலைவில், தொலைவிலிருந்து")  
⟪उच्चैस्⟫ "உயரமாக, உச்சமாக" (⟪उच्च⟫ 3 "உயரமாக, உயர்ந்ததாக, உச்சமாக, கூர்மையானது (குரல்)")
:::
### 37.2.3. இடையீட்டு (⟪चतुर्थी⟫)

::: grammar-box
அரிதாக இடையீட்டு (⟪चतुर्थी⟫) வினாக்களுக்கு இடைநிலையாகப் பயன்படுத்தப்படுகிறது:

*   எந்த நோக்கத்திற்காக?
*   மற்றும் பிறவும்

உதாரணம்:
:::
::: indent
⟪अर्थाय⟫ "நோக்கத்திற்காக, ... காரணமாக"
:::
### 37.2.4. விலக்கீட்டு (⟪पञ्चमी⟫)

::: grammar-box
விலக்கீட்டு (⟪पञ्चमी⟫) வினாக்களுக்கு இடைநிலையாகப் பயன்படுத்தப்படலாம்:

*   ஏன்?
*   எதன் அடிப்படையில்?
*   எங்கிருந்து?
*   மற்றும் பிறவும்

விலக்கீட்டு இடைநிலையாகப் பயன்படுத்தப்படலாம்:

*   பெயர்ச்சொற்களிலிருந்து  
எ.கா. ⟪बलात्⟫ "வன்முறையாக, வலியால்"  

*   உரிச்சொற்களிலிருந்து  
எ.கா. ⟪दूरात्⟫ "தொலைவிலிருந்து"  

*   வினைச்சொற்களிலிருந்து  
உதாரணங்கள்:  
⟪कस्मात्⟫ "ஏன்"  
⟪अकस्मात्⟫ "எதிர்பாராத வகையில்"
:::
### 37.2.5. உடைமையீட்டு (⟪षष्ठी⟫)

::: grammar-box
அரிதாக உடைமையீட்டு (⟪षष्ठी⟫) "எவ்வளவு காலத்திற்குப் பிறகு?" என்ற வினாவிற்கு இடைநிலையாகப் பயன்படுத்தப்படுகிறது

எ.கா. ⟪चिरस्य⟫ "நீண்ட காலத்திற்குப் பிறகு" (⟪चिर⟫ 3 "நீண்ட (காலம்)" என்பதற்கு)
:::
### 37.2.6. இடையீட்டு (⟪सप्तमी⟫)

::: grammar-box
இடையீட்டு (⟪सप्तमी⟫) வினாக்களுக்கு இடைநிலையாகப் பயன்படுத்தப்படலாம்:

*   எங்கே?
*   எந்தச் சூழ்நிலைகளில்?
*   மற்றும் பிறவும்

உதாரணங்கள்:
:::
::: indent
\-⟪अर्थे⟫ "காரணமாக"  
\-⟪कृते⟫ "காரணமாக"  
⟪दूरे⟫ "தொலைவில்"
:::
## 37.3. இனி பயன்பாட்டில் இல்லாத விகுதி வடிவங்களின் இடைநிலைப் பயன்பாடு

உதாரணங்கள்:
::: indent
⟪जातु⟫ "மொத்தமாக" (அசல்: "பிறப்பிலிருந்து, இயற்கையாக", ஒருமை பன்மைப் பொருள் ⟪जातु⟫ \<இனி பெயர்ச்சொல்லாகப் பயன்பாட்டில் இல்லை\>)

⟪तूष्णीम्⟫ "அமைதியாக" (ஒருமை பன்மைப் பொருள் இனி பயன்பாட்டில் இல்லாத ⟪तूष्णी⟫ பெண்பால் "அமைதி" என்பதற்கு)

⟪एवम्⟫ "இவ்வாறு" (பொதுவாக இழந்த வினைச்சொல் வடிவம் ⟪एव⟫ "ஒன்று, தனி" என்பதற்கு)
:::
## 37.4. வினையெச்சங்களை உருவாக்குதல்

::: grammar-box
⟪तद्⟫, ⟪इदम्⟫ அல்லது ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ அல்லது ⟪कु⟫ ஆகிய பண்புப்பெயர் மூலங்களிலிருந்து, வினையெச்சப் பின்சேர்க்கைகளைக் கொண்டு

*   \-⟪तस्⟫ (வினையெச்சம்)
*   \-⟪त्र⟫ (இடவினையெச்சம்)
*   \-⟪था⟫ (நிலை)
*   \-⟪थम्⟫ (நிலை)
*   \-⟪दा⟫ (காலம்)

தொடர்புடைய பண்புப்பெயர் வினையெச்சங்களை உருவாக்கலாம்.

## 37.5. வினையெச்ச சேர்க்கைகள்

### 37.5.1. வினையெச்சம் அல்லது வினையெச்சப் பயன்பாட்டில் உள்ள பால்வினை முடிபு பின்னங்கூறாகக் கொண்ட சேர்க்கைகள்

எடுத்துக்காட்டு: ⟪सुचिरम्⟫ "மிக நீண்ட (காலம்)"

### 37.5.2. வினையெச்சப் பயன்பாட்டில் உள்ள ⟪बहुव्रीहि⟫

எடுத்துக்காட்டு: ⟪रक्षार्थम्⟫ "யாரின் நோக்கம் காப்பதோ, அத்தகையவரின் வடிவில், காக்கும் நோக்கில்". இது 5.1-க்கு உரியதாகவும் கருதப்படலாம்: -⟪अर्थम्⟫ வினையெச்சப் பின்னங்கூறாக.

### 37.5.3. ⟪अव्ययीभाव⟫-சேர்க்கைகள்

⟪अव्ययीभाव⟫ = "மாறாத/அசைக்க முடியாததாக மாறிய"

::: grammar-box
ஒரு ⟪अव्ययीभाव⟫ என்பது, அதன் முன்னங்கூறு ஒரு அசைக்க முடியாத சொல் (பின்னொட்டு, உருபு முதலியவை) ஆகவும், பின்னங்கூறு ஒரு பெயர்ச்சொல்லாகவும், அது ஈற்றசை நடுவுபால் ஒருமை விகுதியை ஏற்கும் சேர்க்கையாகும்.

சேர்க்கையைப் பிரிக்கும்போது, முன்னங்கூறு பின்னங்கூற்றை ஆளும்:

எடுத்துக்காட்டுகள்:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = "நெருப்பிற்கு எதிராக"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "சக்திக்கு ஏற்ப"

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = "முன்னோக்கி, எதிர்முகமாக"
:::
⟪अव्ययीभाव⟫ ⟪यथा⟫ "எப்படி" என்ற முன்னங்கூறுடன் மிகவும் முக்கியமானது:

எ.கா. ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ = "விருப்பம்போல, விருப்பத்திற்கேற்ப, இச்சையின்படி"

## 37.8. வினா வாக்கியம்

::: grammar-box
"யார்?, எப்படி?, என்ன?, ஏன்? எதற்காக?, ஏன்?  
வினவாதவர் அறிவிலி ஆவார்."

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

சேமிப்புப் பாதையின் (Sesamstrasse) முழக்கம், இது வாழ்க்கைக்கும் சமஸ்கிருதக் கற்றலுக்கும் ஒரு நல்ல வழிகாட்டியாகும்.
:::
மேலும் பார்க்க: [பாடம் 4](lektion04.md).

வேறுபடுத்த வேண்டும்:

*   சொல் வினாக்கள் (Ergänzungsfragen)
*   வாக்கிய வினாக்கள்

சொல் வினாக்களில், ஒரு செயலாளர் (⟪कर्तृ⟫), ஒரு பொருள், ஒரு செயல், ஒரு சூழ்நிலை போன்றவற்றைப் பற்றி வினவுவர், எடுத்துக்காட்டு:

*   யார் வருகிறார்கள்?
*   ராமர் என்ன செய்கிறார்?
*   அவன் யாரைக் கேட்கிறான்?
*   அவள் சமஸ்கிருதத்தை எப்படிப் பேசுகிறாள்?
*   தாய் எங்கே இருக்கிறார்?

வாக்கிய வினாக்களில், வாக்கியத்தின் முழு உள்ளடக்கமும் கேட்கப்படுகிறது, எடுத்துக்காட்டு:

*   ராமர் இன்று ஓஃப்டர்திங்கனிற்குச் செல்கிறாரா?
*   ... என்பது சரியானதா?

### 37.8.1. சொல் வினாக்கள் (Ergänzungsfragen)

::: grammar-box
வடிவமைப்பு:

வினாச்சொல்/வினாவிசேஷணம் - வாக்கியம்
:::
எடுத்துக்காட்டுகள்:
::: indent
⟪को ग्रामं गच्छति⟫ =  ⟪केन ग्रामो गम्यते⟫ = "யார் கிராமத்திற்குச் செல்கிறார்கள்?"

⟪किं बाला अधीयीरन्⟫ = "குழந்தைகள் என்ன கற்க வேண்டும்?"

⟪क्व रामो वसति⟫ = ராமர் எங்கே வசிக்கிறார்?
:::

### 37.8.2. வினா வாக்கியங்கள்

::: grammar-box
சூழலை மட்டும் பார்த்தால், ஒரு வாக்கியம் வினா வாக்கியமா என்பதை அறிவது சில நேரங்களில் கடினமாக இருக்கும்.
:::
::: grammar-box
வரைபடம் I:

வினைச்சொல் - மீதமுள்ள வாக்கியம்
:::
உதாரணம்:
::: indent
⟪गमिष्यति ब्राह्मणबालो गुरुम् ।⟫ "பிராமணப் பையன் ஒரு குருவிடம் செல்வானா?"
:::
::: grammar-box
வரைபடம் II:

வினா உருப்படி (பொதுவாக வாக்கியத்தின் தொடக்கத்தில்) - வாக்கியம்

முக்கியமான வினா உருப்படிகள்:

*   ⟪अपि⟫

*   ⟪किम्⟫ (பொதுவாக எதிர்மறை விடையை எதிர்பார்க்க வைக்கும்)

*   ⟪कच्चिद्⟫


இந்த உருப்படிகள் வினாக்குறிக்கு இணையானவை.
:::
உதாரணம்:
::: indent
⟪अपि सत्यम् ।⟫ "அதுவும் உண்மையா?"

⟪किं शक्नोति ।⟫ "அவனால் முடியுமா?"

⟪कच्चित्क्षत्रियेण शत्रवो जिताः ।⟫ "சத்திரியனா எதிரிகளைத் தோற்கடித்தானா?"
:::
குறிப்பு: ⟪किम्⟫ என்பது "என்ன?" என்ற பொருளோடு, ஒரு வினா உருப்படியாகவும் "ஏன்?, எதற்கு?" என்ற பொருளில் வரும். குறிப்பாக கரண விபத்தியுடன் (⟪तृतीया⟫):
::: indent
⟪किं क्रोधेन ।⟫ "கோபத்திற்கு எதற்கு? கோபம் என்ன பயன் தரும்? கோபம் எதற்காக?"
:::

## 37.11. மீள்பயிற்சி

முழுமையான வினை வடிவங்களை மட்டும் பயன்படுத்தி சம்ஸ்கிருதத்திற்கு மொழிபெயர்க்கவும்:

ஒருமுறை ஒரு முதியவர் மற்றொரு கிராமத்திற்குச் சென்றபோது, வழியில் அவர் சோர்வடைந்தார். எனவே, ஓய்வெடுக்க, பக்கத்தில் நின்ற மாமரத்தின் அடியில் சென்றார். அந்த மரத்தில் பக்குவமான கனிகள் இருந்தன. முதியவர் அவற்றை விரும்பினார். ஆனால், மரத்தில் ஏறவும் கனிகளைப் பிடிக்கவும் முடியவில்லை. அதிர்ஷ்டவசமாக, அந்த மரத்தில் சில குரங்குகள் கனிகளை உண்பதற்காக இருந்தன. அவற்றைக் கண்டபோது, முதியவர் மகிழ்ச்சியடைந்தார். அவர் என்ன செய்தார்? சில கற்களை எடுத்து, குரங்குகள் மீது இலக்கு வைத்து வீசினார். கோபமடைந்த குரங்குகள் சில கனிகளைப் பிடித்து, அவற்றை முதியவர் மீது வீசின. முதியவர் அவற்றை மகிழ்ச்சியுடன் எடுத்து, தனது விரும்பிய இடத்திற்குச் சென்றார். பாருங்கள், முதியவரின் விதி!
