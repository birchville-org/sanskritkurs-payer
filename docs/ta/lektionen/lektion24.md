# Lektion 24

## 24.1. Der Dativ (⟪चतुर्थी⟫ = "vierte Kasusendung")

::: grammar-box
**1. ஒரு செயலின் நோக்கம் அல்லது நோக்கத்தை ("செய்ய" என்று) மீண்டும் குறிக்க, ⟪तुमुन्⟫ (⟪तुमुन्⟫) என்ற பெயர்ச்சொல்லின் பதிலாக, ஒரு செயல் அல்லது நிலையைக் குறிக்கும் kṛt-பின்னணி கொண்ட பெயர்ச்சொல், கொடுப்பான்மையில் (⟪चतुर्थी⟫ = "நான்காம் வினைச்சொல்") பயன்படுத்தலாம்.**

உதாரணம்:

மாற்றாக:

:::
::: indent
⟪रामो⟫ ⟪गुरुवचनं⟫ ⟪श्रोतुं⟫ ⟪गतः⟫ ⟪।⟫
:::
நீங்கள் இப்படிச் சொல்லலாம்:

::: indent
⟪रामो⟫ ⟪गुरुवचनस्य⟫ ⟪श्रवणाय⟫ ⟪गतः⟫ ⟪।⟫

அல்லது:

⟪रामो⟫ ⟪गुरुवचनश्रवणाय⟫ ⟪गतः⟫ ⟪।⟫
:::
= "ராமர் ஆசிரியரின் பேச்சைக் கேட்கச் சென்றார்."
::: media
![](/images/lekt2404.webp)
சுருக்கம்: ⟪बाला⟫ ⟪गुरुश्रवणाय⟫ ⟪गताः⟫
(படத்தின் மூலம்: [விவரங்கள்](/ta/licenses#lekt2404))
:::

::: grammar-box
**2. கொடுப்பான்மை (⟪चतुर्थी⟫) ஒரு நோக்கத்திற்கான பெயர்ச்சொல்லின் பொருளைக் குறிக்கலாம்:**

உதாரணம்:

:::
::: indent
⟪फलेभ्यो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "பழங்களுக்காக கிராமத்திற்குச் செல்கிறார் = பழங்களைப் பெற கிராமத்திற்குச் செல்கிறார்."
:::
**அதே போல, கொடுப்பான்மை (⟪चतुर्थी⟫) ஒரு பொருள் அல்லது செயலின் நோக்கத்தைக் குறிக்கிறது:**

உதாரணம்:

::: indent
⟪यज्ञायान्नम्⟫ = "ஒரு பலிக்கு நோக்கமான உணவு = ஒரு பலிக்கான உணவு"
:::
::: media
![](/images/lekt2401.webp)
சுருக்கம்: ⟪यज्ञायान्नम्⟫
'Annakut' [⟪अन्नकूट⟫ = ⟪गोवर्धन⟫ ⟪पूजा⟫] என்பது அனைத்து BAPS [બોચાસનવાસી અક્ષ૨ પુરુષોત્તમ સ્વામિનારાયણ સંસ્થા = Bochasanwasi Akshar Purushottam Swaminarayan Sanstha] மந்திர்களில் இந்திய புத்தாண்டு கொண்டாட்டங்களில் நடக்கும் ஒரு பாரம்பரிய இந்திய நிகழ்வாகும். இந்த நாளில், பகவான் சுாமீனாராயணர் [સ્વામિનારાયણ]க்கு நூற்றுக்கணக்கான தாவர உணவுகள் அர்ப்பணிக்கப்படுகின்றன.
(படத்தின் மூலம்: [விவரங்கள்](/ta/licenses#lekt2401))
:::

::: grammar-box
**3. கொடுப்பான்மை (⟪चतुर्थी⟫) ஒரு செயலின் பொருளுக்காக அமைந்த நபர் அல்லது பொருளைக் குறிக்கிறது (மறைமுக பொருள்; கேள்வி: யாருக்கு?). (இரு மறைமுகப் பெயர்ச்சொற்களுடன் கூடிய வினைச்சொற்களைக் (⟪द्वितीया⟫!) கவனியுங்கள்!)**

உதாரணம்:

:::
::: indent
⟪रामाय⟫ ⟪फलं⟫ ⟪ददाति⟫ = "அவர் ராமருக்கு ஒரு பழத்தைத் தருகிறார்." (வேர் ⟪दा⟫ 3. முன்னிலை வகுப்பு)
:::
::: media
![](/images/lekt2402.webp)
சுருக்கம்: ⟪बाला⟫ ⟪बालाय⟫ ⟪रक्षबन्धनं⟫ ⟪ददाति⟫
ரக்ஷா பந்தன் இந்தியாவெங்கும் ஆர்வத்தோடும் மகிழ்ச்சியோடும் கொண்டாடப்படுகிறது. இந்தத் திருநாளானது அண்ணன் மற்றும் தங்கையிடையேயான நிபந்தனை இல்லாத அன்பைக் குறிக்கிறது.
(படத்தின் மூலம்: [விவரங்கள்](/ta/licenses#lekt2402))
:::

::: grammar-box
**4. சில வினைச்சொற்கள் (மற்றும் சில பிற சொற்கள்) கொடுப்பான்மை, ஜெர்மனில் "யாருக்கு?" என்ற கேள்விக்கு ஏற்ப அமைகிறது:**

உதாரணங்கள்:

:::
::: indent
⟪क्रुध्⟫ : ⟪देवो⟫ ⟪नरेभ्यो⟫ ⟪क्रुध्यति⟫ = "கடவுள் ஆண்களுக்குக் கோபப்படுகிறார்."

⟪अलम्⟫ வினையெச்சம்: "போதுமானது, போதுமானது, வளர்ந்தவர்": ⟪अलं⟫ ⟪योधो⟫ ⟪योधाय⟫ = "ஒரு போர்வீரர் மற்றொரு போர்வீரருக்கு வளர்ந்தவர்"
:::
::: media
![](/images/lekt2403.webp)
சுருக்கம்: ⟪अलं⟫ ⟪योधो⟫ ⟪योधाय⟫
"ராமர் (வலதுபுறம்) ஹனுமந்தின் தோள்களில் அமர்ந்து, அசுர அரசன் ராவணனுடன் போரிடுகிறார்." சுமார் 1820
(படத்தின் மூலம்: [விவரங்கள்](/ta/licenses#lekt2403))

கொடுப்பான்மையின் மற்ற பயன்பாடுகள் பின்னர்.

## 24.2. Bildung des Dativ (⟪चतुर्थी⟫)

::: grammar-box
**பெறுநர் விகுதிகள்:**

* **ஒருமை: -e ; அசைநிலை பெண்பால் அடிச்சொற்கள்: -ai**
* **பன்மை: பெறுநர் மற்றும் விலக்குநர் ⟪पञ्चमी⟫: -bhyas**
:::

## 24.3. -ai மற்றும் -au ஆகியவற்றின் இறுதிச்சொல் சந்தி

::: grammar-box
**வெளிப்படும் -ai மற்றும் -au ஆகியவற்றின் சந்தி**

* **-ai முன்னால் உயிரெழுத்து வந்தால், பொதுவாக -ā ஆல் மாற்றப்படும் (சொல்லின் உள்ளே -āy ஆல் மாற்றுவது அரிது)**
* **-au முன்னால் உயிரெழுத்து வந்தால், பொதுவாக -āv ஆல் மாற்றப்படும் (சில நேரங்களில் -ā ஆல் மாற்றப்படும்)**

உதாரணம்:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा⟫ ⟪अग्नये⟫ = "இந்த அக்னியை"
:::
## 24.4. Wortliste

⟪अलम्⟫ வினையெச்சம்: போதுமானது, போதுமானது, (ஒருவருக்கு, ஏதேனும்) பொருத்தமானது ; பெயர்வினை விகுதியுடன்: ஒருவருக்கு போதுமானது, ஒருவருக்கு போதுமானது, பொருத்தமானது ; கருவிவினை விகுதியுடன்: ஒருவருக்கு போதுமானது, விடு, எ.கா. ⟪अलं⟫ ⟪क्रोधेन⟫ = "கோபத்திற்கு போதுமானது = கோபத்தை விடு!"

அதே போல ⟪अलम्⟫ கருவிவினையுடன் பயன்படுத்தப்படுகிறது:

⟪कृतम्⟫ : ⟪कृतं⟫ ⟪क्रोधेन⟫ = "கோபத்திற்கு முடிந்தது = கோபத்தை விடு!"

## 24.6. தத்திய பதத்தின் பயன்பாட்டிற்கான கூடுதல் பயிற்சிகள்

சமஸ்கிருதத்திற்கு மொழிபெயர்க்கவும்:

1\. பலிசெய்யப்படாத தெய்வம் மக்களின் மீது கோபிக்கிறது.

2\. அவர் பசுவை கிராமத்திற்கு விடுகிறார்.

3\. இப்போது போதும் = பொறுமைக்கு போதும்.

4\. இது ஒரு பிராமணருக்கு நல்லது (⟪हित⟫, ⟪सुख⟫).

5\. வணக்கம் (⟪नमस्⟫) ஸிவாவிற்கு! வணக்கம் ஸ்ரீ கணேசாவிற்கு!

::: media
![](/images/lekt2409.webp)

(படத்தின் மூலம்: [விவரங்கள்](/ta/licenses#lekt2409))
:::
6\. வணக்கம்! (= நலம் (⟪स्वस्ति⟫ பெ.) உங்களுக்கு!)

7\. இந்த பழம் உண்ணுவதற்கு போதும்.

8\. ஒரு போராளி (மற்ற) போராளியை விட மேலானவன் (⟪शक्त⟫).

9\. விஷ்ணுவே (⟪प्र⟫-⟪भू⟫ + தத்தவம்) ஸிவாவை விட மேலானவன் அல்ல.

10\. நான் மூன்று அறிஞர்களுக்கு (பொ.யி.) வணங்கிய பிறகு (⟪नमस्कृ⟫)... நரசிம்ஹாவிற்கு வணங்குகிறார் (தத்தவம்)

::: indent
விளக்கம்: ⟪मुनित्रयम्⟫ "அறிஞர்களின் மூவரம் = மூன்று அறிஞர்கள்" = இலக்கண அறிஞர்கள் ⟪पाणिनि⟫, ⟪कात्यायन⟫, ⟪पतञ्जलि⟫
:::

⟪नरसिंह⟫ கீறுகிறார் ⟪हिरण्यकशिपु⟫, ⟪भागवतपुराण⟫ கையெழுத்துப் பிரதியிலிருந்து ஒரு தாள்
(படத்தின் மூலம்: [விவரங்கள்](/ta/licenses#lekt2410))
:::
11\. வணக்கம் (⟪स्वागतम्⟫) உங்களுக்கு. ராணியிற்கு வணக்கம்.

12\. நான் உங்களுக்கு நலம் (⟪कुशल⟫) விரும்புகிறேன் = நலம் உங்களுக்கு!

13\. அவர் அவரை புல்நாற்றாகக் கருதவில்லை.

14\. உண்ண ஒரு பழமும், குடிக்க நீரும் போதும்.

15⟪१५⟫. மீண்டும் காண்போம்! (புதிய சமஸ்கிருதம்: ⟪पुनर्दर्शनाय⟫)
