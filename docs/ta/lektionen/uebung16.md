# பாடம் 16

A) பின்வரும் வெளிப்பாடுகளை தத்புருஷ ஆக்கமாக்கி, மொழிபெயர்க்கவும்:

⟪१⟫. ⟪देवस्य⟫ ⟪पुरुषः⟫ ⟪।⟫ — ⟪देवपुरुषः⟫

⟪२⟫. ⟪गुणवती⟫ ⟪ब्राह्मणी⟫ ⟪।⟫ — ⟪गुणवद्ब्राह्मणी⟫

⟪३⟫. ⟪सत्यवान्ब्राह्मणः⟫ ⟪।⟫ — ⟪सत्यवद्ब्राह्मणः⟫

⟪४⟫. ⟪पशुमन्तो⟫ ⟪जनाः⟫ ⟪।⟫ — ⟪पशुमज्जनाः⟫

⟪५⟫. ⟪सुखवान्वैश्यायाः⟫ ⟪पुत्रः⟫ ⟪।⟫ — ⟪सुखवद्वैश्यापुत्रः⟫

⟪६⟫. ⟪सुखवत्या⟫ ⟪वैश्यायाः⟫ ⟪पुत्रः⟫ ⟪।⟫ — ⟪सुखवद्वैश्यापुत्रः⟫

⟪७⟫. ⟪कवेरुक्त्याः⟫ ⟪सत्यम्⟫ ⟪।⟫ — ⟪कव्युक्तिसत्यम्⟫

⟪८⟫. ⟪शिव⟫en ⟪रक्षिता⟫ ⟪बाला⟫ ⟪।⟫ — ⟪शिवरक्षितबाला⟫

⟪९⟫. ⟪रामेण⟫ ⟪पीतं⟫ ⟪जलम्⟫ ⟪।⟫ — ⟪रामपीतजलम्⟫

⟪१०⟫. ⟪फलवांल्लाभः⟫ ⟪।⟫ — ⟪फलवद्लाभः⟫

⟪११⟫. ⟪इष्टाया⟫ ⟪देवतायाः⟫ ⟪पूजा⟫ ⟪।⟫ — ⟪इष्टदेवतापूजा⟫

⟪१२⟫. ⟪देवानां⟫ ⟪स्तुतिः⟫ ⟪।⟫ — ⟪देवस्तुतिः⟫

B) பின்வரும் வாக்கியங்களில் அனைத்து சமசுகிருத சங்கிலிச் சொற்களையும் (சமாசங்கள்) பிரித்து, விகுதி பெயர்களுடன் கூடிய வாக்கியங்களை உருவாக்கி, மொழிபெயர்க்கவும்:

⟪१⟫. ⟪पुण्यवद्वैश्यपुत्रो⟫ ⟪देवेन्द्रलोकं⟫ ⟪गच्छति⟫ ⟪।⟫
⟪पुण्यवान्वैश्यस्य⟫ ⟪पुत्रो⟫ ⟪देवानामिन्द्रस्य⟫ ⟪लोकं⟫ ⟪गच्छति⟫ ⟪।⟫ (அல்லது: ⟪पुण्यवतो⟫ ⟪वैश्यस्य⟫ ⟪पुत्रो⟫...)
ஒரு வைசியனின் கர்மநிபுணமான மகன் தேவர்களின் தலைவனின் வானத்திற்குச் செல்கிறான். (அல்லது: ஒரு கர்மநிபுணமான வைசியனின் மகன்...)

⟪२⟫. ⟪पुण्यकरणं⟫ ⟪स्वर्गमार्गः⟫ ⟪।⟫
⟪पुण्यस्य⟫ ⟪करणं⟫ ⟪स्वर्गस्य⟫ ⟪मार्गः⟫ ⟪।⟫ (அல்லது: ⟪पुण्यानां⟫ ⟪करणं⟫ ⟪स्वर्गं⟫ ⟪मार्गः⟫ ⟪।⟫)
நல்ல காரியங்களைச் செய்வதே வானத்திற்கான பாதை.

⟪३⟫. ⟪न⟫ ⟪साधुः⟫ ⟪पशुवन्नरधेनुलोभः⟫ ⟪।⟫
⟪न⟫ ⟪साधुः⟫ ⟪पशुवतो⟫ ⟪नरस्य⟫ ⟪धेनूनां⟫ ⟪लोभः⟫ ⟪।⟫ (அல்லது: ...⟪धेनोर्लोभः⟫ ⟪।⟫)
பசுக்கள் நிறைந்த மனிதனின் பசுக்கள் / பசுவுக்கான ஆசை நல்லதல்ல.

⟪४⟫. ⟪न⟫ ⟪पशुयज्ञैर्नराः⟫ ⟪स्वर्गं⟫ ⟪गच्छन्ति⟫ ⟪।⟫ ⟪धर्मयज्ञैस्तु⟫ ⟪स्वर्गसुखमाप्नुवन्ति⟫ ⟪।⟫
⟪न⟫ ⟪पशूनां⟫ ⟪यज्ञैर्नराः⟫ ⟪स्वर्गं⟫ ⟪गच्छन्ति⟫ ⟪।⟫ ⟪धर्मस्य⟫ ⟪यज्ञैस्तु⟫ ⟪स्वर्गस्य⟫ ⟪सुखमाप्नुवन्ति⟫ ⟪।⟫
விலங்கு பலியீடுகளால் மனிதர்கள் வானத்திற்குச் செல்வதில்லை. (இரத்தமற்ற) நீதியான பலியீடுகளால் அவர்கள் வான இன்பத்தை அடைகிறார்கள்.

⟪५⟫. ⟪द्विजदासा⟫ ⟪इति⟫ ⟪शूद्रा⟫ ⟪उच्यन्ते⟫ ⟪।⟫
⟪द्विजानां⟫ ⟪दासा⟫ ⟪इति⟫ ⟪शूद्रा⟫ ⟪उच्यन्ते⟫ ⟪।⟫
Śūdras nennt man Sklaven der Zweimalgeborenen.

⟪६⟫. ⟪बालब्राह्मणपुत्राः⟫ ⟪सत्यवन्नरं⟫ ⟪शृण्वन्ति⟫ ⟪।⟫
⟪बा्ला⟫ ⟪ब्राह्मणानां⟫ ⟪पुत्राः⟫ ⟪स्त्यवन्तं⟫ ⟪नरं⟫ ⟪शृण्वन्ति⟫ ⟪।⟫
இளம் பிராமண மகன்கள் உண்மையான மனிதனைக் கேட்கிறார்கள்.

⟪७⟫. ⟪बलवत्क्षत्रिया⟫ ⟪धनवच्छत्रुनगरं⟫ ⟪जयन्ति⟫ ⟪।⟫
⟪बलवन्तः⟫ ⟪क्षत्रिया⟫ ⟪धनवतां⟫ ⟪शत्रूनां⟫ ⟪नगरं⟫ ⟪जयन्ति⟫ ⟪।⟫
சக்திவாய்ந்த க்ஷத்திரியர்கள் எதிரிகளின் செழித்த நகரை வெற்றிகொள்கிறார்கள்.

⟪८⟫. ⟪ऋष्युक्त्या⟫ ⟪सत्यमुच्यते⟫ ⟪।⟫
⟪ऋषीणामुक्त्या⟫ ⟪सत्यमुच्यते⟫ ⟪।⟫
வேத ஞானிகளின் வார்த்தை உண்மையைக் கூறுகிறது.

⟪९⟫. ⟪बलवद्योधा⟫ ⟪ब्राह्मणग्रामं⟫ ⟪गताः⟫ ⟪।⟫
⟪बलवन्तो⟫ ⟪योधा⟫ ⟪ब्राह्मणानां⟫ ⟪ग्रामं⟫ ⟪गताः⟫ ⟪।⟫
வலிமையான போர்வீரர்கள் பிராமண கிராமத்திற்குச் சென்றுள்ளனர்.

⟪१०⟫. ⟪पुण्यवद्वैश्येष्टवेवतापूजां⟫ ⟪करोति⟫ ⟪।⟫
⟪पुन्यवतो⟫ ⟪वैश्यस्येष्टाया⟫ ⟪देवतायाः⟫ ⟪पूजां⟫ ⟪करोति⟫ ⟪।⟫
ஒரு கர்மநிபுணமான வைசியனின் தனிப்பட்ட தெய்வத்தை அவர் வணங்குகிறார்.

## கூடுதல் பயிற்சிகள்

B) சமஸ்கிருதத்தில் மொழிபெயர்க்கவும் மற்றும் அனைத்து சங்கிலிச் சொற்களையும் (சமசுகிருத கலப்பொருள் சொற்கள்) பிரிக்கவும்:

⟪१⟫. ⟪योगश्चित्तवृत्तिनिरोधः⟫ ⟪॥⟫ ⟪योगसूत्र⟫ ⟪१⟫.⟪२⟫ ⟪॥⟫
⟪योगश्चित्तस्य⟫ ⟪वृत्तेर्निरोधः⟫ (அல்லது: ⟪वृत्तीनां⟫ ⟪निरोधः⟫) ⟪।⟫
யோகம் என்பது மனத்தின் செயல்பாட்டை நிறுத்துவதாகும்.

⟪२⟫. ⟪स्वधर्मो⟫ ⟪ब्राह्मणस्याध्ययनमध्यापनं⟫ ⟪यजनं⟫ ⟪याजनं⟫ ⟪दानं⟫ ⟪प्रतिग्रहश्च⟫ ⟪॥५॥⟫
பிராமணனின் குறிப்பிட்ட கடமை: வேதம் படித்தல், வேதம் கற்பித்தல், தானிகர் ஆகியோரிடம் பலிபீடத்தில் பலிபெயர்த்தல், வேறோரின் ஆணைப்படி பலிபெயர்த்தல், பிராமணர்களுக்கு அளித்தல், அன்பளிப்புகளை ஏற்றுக்கொள்ளல்.

⟪क्षत्रियस्याध्ययनं⟫ ⟪यजनं⟫ ⟪दानं⟫ ⟪शस्त्राजीवो⟫ ⟪भूतरक्षणं⟫ ⟪च⟫ ⟪॥६॥⟫
⟪क्षत्रियस्याध्ययनं⟫ ⟪यजनं⟫ ⟪दानं⟫ ⟪शास्त्रेणाजीवो⟫ ⟪भूतानां⟫ ⟪रक्षणं⟫ ⟪च्⟫ ⟪।⟫
ஒரு க்ஷத்திரியனின் குறிப்பிட்ட கடமை: வேதம் படித்தல், தானிகர் ஆகியோரிடம் பலிபீடத்தில் பலிபெயர்த்தல், பிராமணர்களுக்கு அளித்தல், வாளைக் கையாள்தல், உயிர்களைக் காத்தல்.

⟪वैश्यस्याध्ययनं⟫ ⟪यजनं⟫ ⟪दानं⟫ ⟪कृषिपाशुपाल्ये⟫ ⟪वणिज्या⟫ ⟪च⟫ ⟪॥७॥⟫
⟪वैश्यस्याध्ययनं⟫ ⟪यजनं⟫ ⟪दानं⟫ ⟪कृषिः⟫ ⟪पाशुपाल्यं⟫ ⟪च⟫ ⟪वणिज्या⟫ ⟪च⟫ ⟪।⟫
ஒரு வைசியனின் குறிப்பிட்ட கடமை: வேதம் படித்தல், தானிகர் ஆகியோரிடம் பலிபீடத்தில் பலிபெயர்த்தல், பிராமணர்களுக்கு அளித்தல், வேளாண்மை மற்றும் பசுக்களை மேய்த்தல், வணிகம்.

⟪शूद्रस्य⟫ ⟪द्विजातिशुश्रूषा⟫ ⟪वार्त्ता⟫ ⟪कारुकुशीलवकर्म⟫ ⟪च⟫ ⟪॥८॥⟫
⟪शुड्रस्य⟫ ⟪द्विजातीनां⟫ ⟪शुश्रूषा⟫ ⟪वार्त्ता⟫ ⟪कारूणां⟫ ⟪कुशीलवानां⟫ ⟪च⟫ ⟪कर्म⟫ ⟪।⟫
ஒரு சூத்திரனின் குறிப்பிட்ட கடமை: இருமுறை பிறந்தோரிடம் அடிமைத்தனமான சேவை, பொருளாதார நடவடிக்கை மற்றும் கைவினைஞர் மற்றும் காட்சியாளராக செயல்படுதல்.

⟪सर्वेषामहिंसा⟫ ⟪सत्यं⟫ ⟪शौचमनसूयानृशंस्यं⟫ ⟪क्षमा⟫ ⟪च⟫ ⟪॥१३॥⟫
அனைவருடைய கடமை: அহিংசை, உண்மை, சுத்தம், தனது பங்கைக் குறைகூறாமை, கெடுதல் இல்லாமல் இருத்தல், பொறுமையான பொறுமை.
(⟪कौटिलीयार्थशास्त्र⟫ ⟪१⟫.⟪३⟫.⟪५⟫-⟪८⟫, ⟪१३⟫)
