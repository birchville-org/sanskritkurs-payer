## 36.2. சுற்றுவினை முன்னிலை (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
வெளிப்படுத்தப்பட்ட முற்றெச்சம் (⟪अनुप्रयोगलिट्⟫) பயன்படுத்தப்படுகிறது:

1. விலக்கப்பட்ட இயல்பு வினைச்சொற்களில் (காரணம், விருப்பம், அடிக்கடி, பெயர்ச்சொல் வழி)
2. நீண்ட ஒலியால் (ā- தவிர) தொடங்கும் மூலச்சொற்களில், அல்லது ஒலியால் (a- தவிர) இரண்டு உயிரெழுத்துக்களுக்கு முன்
3. சில பிற மூலச்சொற்களில்
:::
::: grammar-box
**உருவாக்கம்:**

(வலுவற்ற) முன்னிலைத் தனிமை + -ām + ⟪कृ⟫, ⟪अस्⟫ அல்லது ⟪भू⟫ இன் தொடர்புடைய முற்றெச்ச வடிவம்

- Auslautender Stammvokal wird vor -ām guṇiert.
- ⟪अस्⟫ மற்றும் ⟪भू⟫ ஆகியவை ஆத்மனைபத வினைச்சொற்களில் பரமஸ்பதத்தில் அமைக்கப்படுகின்றன.
:::
Das periphrastische Perfekt ist wohl aus dem Akkusativ eine Verbalnomens auf -ā entstanden. Dieser Akkusativ wird -- wie auch sonst oft -- adverbial verwendet.

## 36.3. முற்றுச்செய்யுள் செய்பெயர்ப்பெயர்

::: grammar-box
செய்யுளில், செய்பெயரின் வடிவங்கள் ஆத்மனைபதத்தின் வடிவங்கள் பயன்படுத்தப்படுகின்றன. மாறாக, PPP-யின் பயன்பாடு விரும்பப்படுகிறது. இரண்டு வழிகளிலும் கட்டமைப்பு செய்பெயர் வாக்கியங்களின் கட்டமைப்பாகும்:

:::
::: indent
⟪तेन⟫ ⟪पुण्यं⟫ ⟪चक्रे⟫ = ⟪तेन⟫ ⟪पुण्यं⟫ ⟪कृतम्⟫ = "அவர் ஒரு புண்ணியமான செயலைச் செய்தார்"
