# பாடம் 18

A) பாடத்தின் தொடக்கத்தில் உள்ள ⟪सुभाषित⟫-ஐ மொழிபெயர்க்கவும்.

⟪नास्ति⟫ ⟪कामसमो⟫ ⟪व्याधिर्⟫  
⟪नास्ति⟫ ⟪मोहसमो⟫ ⟪रिपुः⟫ ⟪।⟫  
⟪नास्ति⟫ ⟪क्रोधसमो⟫ ⟪वह्निर्⟫  
⟪नास्ति⟫ ⟪ज्ञानसमं⟫ ⟪सुखम्⟫ ⟪॥⟫  
காதல் போன்ற நோய் எதுவும் இல்லை,  
மோசடி செய்பவரும் எதிரியும் போல அவிவேகம் இல்லை,  
சினம் போன்ற தீ எதுவும் இல்லை,  
அறிவு போன்ற நல்வாழ்வு எதுவும் இல்லை.

B) பின்வரும் தத்புருஷாவை மொழிபெயர்க்கவும்:

⟪१⟫. ⟪सुकर⟫ ⟪३⟫ — செய்வதற்கு எளிதானது

⟪२⟫. ⟪सुकुल⟫ பெ. — நல்ல குடும்பம்

⟪३⟫. ⟪सुकृति⟫ பெ. — நல்ல செயல்

⟪४⟫. ⟪अकरण⟫ பெ. — செய்கையின்மை

⟪५⟫. ⟪दुरिष्ट⟫ பெ. — கெட்ட விருப்பம்

⟪६⟫. ⟪दुरिष्टि⟫ பெ. — பிழையான யாகம்

⟪७⟫. ⟪सुखादित⟫ 3 — நன்றாக நக்கது

⟪८⟫. ⟪दुष्कर⟫ 3 — செய்வதற்கு கடினமானது

⟪९⟫. ⟪दुर्जय⟫ 3 — வெல்வதற்கு கடினமானது

⟪१०⟫. ⟪सुगत⟫ பெ. — நன்றாக (பிறவிகளில்) சென்றவன் (= புத்தர்)

⟪११⟫. ⟪सुजन⟫ பெ. — நல்ல மனிதன்

⟪१२⟫. ⟪दुरुक्ति⟫ பெ. — கடுமையான பேச்சு

⟪१३⟫. ⟪दुरुपदेश⟫ பெ. — கெட்ட கட்டளை

⟪१४⟫. ⟪सुजात⟫ 3 — நல்ல பிறப்புடையது

⟪१५⟫. ⟪सु⟫guru 3 — மிகவும் கடினமானது

⟪१६⟫. ⟪अनाप्त⟫ 3 — பொருத்தமற்றது

⟪१७⟫. ⟪अनीति⟫ பெ. — பொருந்தாத நடத்தை

⟪१८⟫. ⟪अनीश्वरत्व⟫ பெ. — கணவன் அல்லாமையது

⟪१९⟫. ⟪सुदुःख⟫ பெ. — பெரிய துக்கம்

⟪२०⟫. ⟪दुर्जन⟫ பெ. — கெட்ட மனிதன்

⟪२१⟫. ⟪दुर्दग्ध⟫ 3 — கெட்டவாறு எரிக்கப்பட்டது

⟪२२⟫. ⟪अतिकृत⟫ 3 — மிகைப்படுத்தப்பட்டது

⟪२३⟫. ⟪सुपुत्र⟫ பெ. — நல்ல மகன்

⟪२४⟫. ⟪सुबुद्धि⟫ பெ. — நல்ல புரிதல்

⟪२५⟫. ⟪दुष्पुत्र⟫ பெ. — கெட்ட மகன்

⟪२६⟫. ⟪दुष्प्रणीत⟫ 3 — கெட்டவாறு நிறைவேற்றப்பட்டது

⟪२७⟫. ⟪सुमति⟫ பெ. — நட்பு

⟪२८⟫. ⟪दुर्लभ⟫ 3 — பெறுவதற்கு கடினமானது

⟪२९⟫. ⟪दुर्वच⟫ 3 — சொல்வதற்கு கடினமானது

⟪३०⟫. ⟪दुर्वचन⟫ பெ. — கெட்ட பேச்சு

⟪३१⟫. ⟪अमृत⟫ பெ. — அமிர்தம், அமிர்த உணவு, அமிர்தக் கலவை

## கூடுதல் பயிற்சிகள்

A) கீழ்க்கண்ட சமசுகிருத சங்கிலிச் சொற்களைப் பிரித்து, மொழிபெயர்ப்பு முன்மொழிவுகளைத் தரவும்:

⟪१⟫. ⟪अन्तगत⟫ ⟪३⟫ ⟪।⟫ ⟪अन्तं⟫ ⟪गतः⟫ ⟪।⟫ — முடிந்தது, இலக்கணம்: இறுதியில் வரும்

⟪२⟫. ⟪क्षमाकर⟫ ⟪३।⟫ ⟪क्षमा⟫-⟪करः⟫ ⟪।⟫ — பொறுமையுள்ளவர், பொறுமையான செயல்

⟪३⟫. ⟪क्षेमेन्द्र⟫ ஆண்.⟪।⟫ ⟪क्षेमस्येन्द्रः⟫ ⟪।⟫ — அமைதியின் / நலத்தின் / அமைதியின் கணவர்

⟪४⟫. ⟪शस्त्रकोपनिरोध⟫ ஆண். ⟪।⟫ ⟪शस्त्राणां⟫ ⟪कोपस्य⟫ ⟪निरोधः⟫ ⟪।⟫ — கத்தியால் கோபத்தை நிறுத்துதல் = போரை நிறுத்துதல்

⟪५⟫. ⟪सिंहसंहनन⟫ பெ.⟪।⟫ ⟪सिंहस्य⟫ ⟪संहननम्⟫ ⟪।⟫ — ஒரு / பல சிங்கங்களைக் கொல்லுதல், ஒரு / பல சிங்கங்களால் கொல்லப்படுதல்

⟪६⟫. ⟪अरिसिंह⟫ ஆண். ⟪।⟫ ⟪सिंह⟫ ⟪इव⟫ ⟪अरिः⟫ ⟪।⟫ — சிங்கத்திற்குச் சமமான எதிரி

⟪७⟫. ⟪आहारनिद्राभय⟫ பெ. ⟪।⟫ ⟪आहारो⟫ ⟪निद्रा⟫ ⟪भयं⟫ ⟪च⟫ ⟪।⟫ — உணவு, தூக்கம் மற்றும் அச்சம்

⟪८⟫. ⟪मृतिसाधनी⟫ பெ. ⟪।⟫ ⟪मृतेः⟫ ⟪साधनी⟫ ⟪।⟫ — சாவை ஏற்படுத்தும்

⟪९⟫. ⟪कुलोपदेश⟫ ஆண். ⟪।⟫ ⟪कुलस्योपदेशः⟫ ⟪।⟫ — குடும்பப் பெயர் (குடும்பத்தைக் குறிக்கும் குறிப்பு)

B) 2-வது முன்னால் வகை வினைச்சொற்களைப் பயன்படுத்தி மொழிபெயர்க்கவும்:

1\. பிராமணர் பெண்தெய்வங்களைப் பாராட்டுகிறார்.
⟪ब्राह्मणो⟫ ⟪देवीः⟫ ⟪स्तौति⟫ ⟪।⟫ (அல்லது: ⟪स्तवीति⟫ ⟪।⟫)

2\. வீரர்கள் கடினமான பாதையில் ஆரியர்களின் கிராமத்திற்குச் செல்கிறார்கள்.
⟪शूरा⟫ ⟪दुर्गमेण⟫ ⟪मार्गेणार्यग्रामं⟫ ⟪यन्ति⟫ ⟪।⟫

3\. வீட்டுப் பணிப்பெண் ஆடுகளைப் பால் கறக்கிறாள்.
⟪गृहदासी⟫ ⟪धेनूर्दोग्धि⟫ ⟪।⟫

4\. ஆரியர்களின் எதிரிகள் வலிமையான க்ஷத்திரியர்களைக் கொல்கிறார்கள்.
⟪आर्यारयो⟫ ⟪बलवत्क्षत्रियान्घन्ति⟫ ⟪।⟫ (அல்லது: ⟪आर्यशत्रवो⟫...)

5\. ஒரு பூதம் பழங்களை உண்ணாது.
⟪भूतं⟫ ⟪फलानि⟫ ⟪नात्ति⟫ ⟪।⟫

6\. இவ்வாறு, [மறுபிறவி வழியாக] நன்றாகச் சென்றவர், சீடரிடம் பேசுகிறார்.
⟪एवं⟫ ⟪सुगतः⟫ ⟪श्रावकं⟫ ⟪वक्ति⟫ ⟪।⟫ (அல்லது: ⟪ब्रवीति⟫ ⟪।⟫ ⟪ब्रूते⟫ ⟪।⟫)

C) சமசுகிருதத்தில் யோகாவின் வரையறையை இரண்டு வழிகளில் தரவும்: ஒரு முறை சங்கிலிச் சொல்லைப் பயன்படுத்தி, ஒரு முறை அந்த சங்கிலிச் சொல்லைப் பிரித்து.

⟪योगश्चित्तवृत्तिनिरोधः⟫ ⟪।⟫ (⟪योगश्चित्तस्य⟫ ⟪वृत्तेर्निरोधः⟫ ⟪।⟫)

D) மொழிபெயர்க்கவும்:

(⟪धर्मः⟫) ⟪सर्वेषामाहिंसा⟫ ⟪सत्यं⟫ ⟪शौचमनसूयानृशंस्यं⟫ ⟪क्षमा⟫ ⟪च⟫ ⟪॥⟫
அனைவருடைய கடமை: அகிம்சை, உண்மை, சுத்தம், தனது பங்கைப் பற்றி முறையாமல் இருத்தல், கெடுதல் இல்லாமல் இருத்தல் மற்றும் பொறுமையான பொறுமை.
