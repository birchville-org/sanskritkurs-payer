# பாடம் 22

## 22.1. முற்றெச்சம் (⟪க்த்வா⟫ ⟪।⟫ ⟪ல்யப்⟫)

::: grammar-box

சமஸ்கிருதத்தில் ஒரு செயலாளரின் (⟪कर्तृ⟫) செயல், மற்றொரு செயலாளரின் செயலுக்கு முன்பாகவோ அல்லது அதனுடன் ஒரு தொடர்புடைய நிலையாகவோ இருப்பதை வெளிப்படுத்த விரும்பினால், தனிமைப் பெயரை (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫) பயன்படுத்துகிறார்கள். எனவே

"அது செய்த பிறகு, அவர் அது செய்கிறார்" ; "அவர் அது செய்கிறார், பின்னர் அவர் அது செய்கிறார்" ; "இதன் விளைவாக, அவர் அது செய்கிறார்" ; "நான் வந்தேன், பார்த்தேன், வென்றேன்" போன்றவை.

தனிமைப் பெயர் ஒரு வினை-விசேஷணம், அதாவது அது conjugate அல்லது declinate செய்ய முடியாது, ஆனால் அது எப்போதும் - சில விதிவிலக்குகள் தவிர - அதே செயலாளரை (⟪कर्तृ⟫) கொண்டுள்ளது, தனிமைப் பெயரால் குறிக்கப்படும் செயல், அதற்கு முன்பாகவோ அல்லது அதனை தொடர்ந்து வருகிறது. தனிமைப் பெயரின் செயலாளர் எனவே nominative (⟪प्रथमा⟫) அல்லது instrumental (⟪तृतीया⟫) இல் இருக்கிறார்.

சங்கிலிகளுடன், தனிமைப் பெயர் சமஸ்கிருதத்தில் மிகவும் பொதுவான வெளிப்பாட்டு முறைகளில் ஒன்றாகும்.

ஜெர்மனில் மொழிபெயர்க்கும் போது, தொடர்ந்து "பிறகு" என்று சொல்வதைத் தவிர்க்கவும். மாற்றாக, ஜெர்மனில் நேர வரிசைக்குறிப்புக்கான பொதுவான வெளிப்பாடுகளைப் பயன்படுத்தவும்.

**அமைப்பு:**

(தனிமைப் பெயருக்கான நெருக்கமான வரையறை: நிலை வரையறை, பொருள் போன்றவை) - தனிமைப் பெயர் - தனிமைப் பெயர் - ... - தனிமைப் பெயர் - ... செயலாளர் + வினை வாக்கியம் (செயலில் அல்லது எதிர்மறையில்)

:::
**உதாரணங்கள்:**

::: indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = எதிர்மறை கட்டமைப்பு: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**  
"ஆண் வீட்டிற்குள் நுழைகிறான், சிறிய பெண்ணைப் பார்க்கிறான் மற்றும் அவளுடன் பேசுகிறான்."

பலர்: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**
:::

**⟪ब्रह्मचर्य⟫ நடுவினையால்:** வேதத்தின் நிறைவேற்றம் (**⟪ब्रह्मन्⟫**) = வேதத்தின் படிப்பு முதல் வாழ்க்கை நிலையில் (**⟪ब्रह्मचारिन्⟫**), இது கடுமையான பாலியல் விலகலைத் தேவைப்படுத்துகிறது; எனவே மேலும்: பாலியல் விலகல், கன்னி வாழ்க்கை நடத்தை
