# பாடம் 22

## 22.1. தனிமைப் பெயர் (क्त्वा । ल्यप्)

:::grammar-box

சமஸ்கிருதத்தில் ஒரு செயலாளரின் (कर्तृ) செயல், மற்றொரு செயலாளரின் செயலுக்கு முன்பாகவோ அல்லது அதனுடன் ஒரு தொடர்புடைய நிலையாகவோ இருப்பதை வெளிப்படுத்த விரும்பினால், தனிமைப் பெயரை (क्त्वा । ल्यप्) பயன்படுத்துகிறார்கள். எனவே

"அது செய்த பிறகு, அவர் அது செய்கிறார்" ; "அவர் அது செய்கிறார், பின்னர் அவர் அது செய்கிறார்" ; "இதன் விளைவாக, அவர் அது செய்கிறார்" ; "நான் வந்தேன், பார்த்தேன், வென்றேன்" போன்றவை.

தனிமைப் பெயர் ஒரு வினை-விசேஷணம், அதாவது அது conjugate அல்லது declinate செய்ய முடியாது, ஆனால் அது எப்போதும் - சில விதிவிலக்குகள் தவிர - அதே செயலாளரை (कर्तृ) கொண்டுள்ளது, தனிமைப் பெயரால் குறிக்கப்படும் செயல், அதற்கு முன்பாகவோ அல்லது அதனை தொடர்ந்து வருகிறது. தனிமைப் பெயரின் செயலாளர் எனவே nominative (प्रथमा) அல்லது instrumental (तृतीया) இல் இருக்கிறார்.

சங்கிலிகளுடன், தனிமைப் பெயர் சமஸ்கிருதத்தில் மிகவும் பொதுவான வெளிப்பாட்டு முறைகளில் ஒன்றாகும்.

ஜெர்மனில் மொழிபெயர்க்கும் போது, தொடர்ந்து "பிறகு" என்று சொல்வதைத் தவிர்க்கவும். மாற்றாக, ஜெர்மனில் நேர வரிசைக்குறிப்புக்கான பொதுவான வெளிப்பாடுகளைப் பயன்படுத்தவும்.

**அமைப்பு:**

(தனிமைப் பெயருக்கான நெருக்கமான வரையறை: நிலை வரையறை, பொருள் போன்றவை) - தனிமைப் பெயர் - தனிமைப் பெயர் - ... - தனிமைப் பெயர் - ... செயலாளர் + வினை வாக்கியம் (செயலில் அல்லது எதிர்மறையில்)

:::**உதாரணங்கள்:**

:::indent
**गृहं प्रविश्य बालां दृष्ट्वा नरो वदति** = எதிர்மறை கட்டமைப்பு: **गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते**  
"ஆண் வீட்டிற்குள் நுழைகிறான், சிறிய பெண்ணைப் பார்க்கிறான் மற்றும் அவளுடன் பேசுகிறான்."

பலர்: **गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।**
:::## 22.2. பெருங்கூற்று வடிவமைப்பு

:::grammar-box
**பெருங்கூற்று வடிவமைப்பு**

*   முன்னொட்டு இல்லாத வினைச்சொற்கள்: **-tvā** என்ற பெருங்கூற்று
*   முன்னொட்டுள்ள வினைச்சொற்கள்: **-ya** அல்லது **-tya** என்ற பெருங்கூற்று
:::### 22.2.1. செயலிலிகள் முன்னொட்டு இல்லாதவை: -त्वा என்ற முடிபுடன் பெயர்ச்சொல்

:::grammar-box

**உருவாக்கம்:**

(பொதுவாக) ஆழ்நிலை வேர், PPP-க்கு முன் உள்ள வடிவத்தில் + **-tvā** (**-त्वा**)

எதிர்மறை **a-** / **an-** மட்டுமே **-त्वा** என்ற முடிப்புடன் இணையும்: **अकृत्वा** "செய்யாமல்"

:::**எடுத்துக்காட்டுகள்:**

:::indent
**आप्त्वा** "அவர் / அவர் / அது / நான் / நீ / நாங்கள் / அவர்கள் / நாம் இருவர் / நீங்கள் இருவர் / அவர்கள் இருவர் அடைந்த பின்"

**आसित्वा** "அவர் (...) அமர்ந்த பின்"

**इत्वा** "அவர் (...) சென்ற பின்"

**स्थित्वा** "அவர் (...) நின்ற பின்"

**जित्वा** "அவர் (...) வெற்றி பெற்ற பின்"

**उक्त्वा** "அவர் (...) பேசிய பின்"
:::### 22.2.2. இடைச்சொல் கொண்ட வினைச்சொற்கள்

#### 22.2.2.1. நீண்ட ஒலி ( -ā தவிர) அல்லது ஒலிவகைகளால் முடிவடையும் மூலச்சொற்கள்

:::grammar-box

**(பொதுவாக) ஆழ்நிலை மூலம் + -ya**

:::**எடுத்துக்காட்டுகள்:**

:::indent
**उपनीय** "(...) அழைத்துக் கொண்டு வந்த பின்"

**प्रभूय** "(...) வெளியேறின பின்" "(...) அதிகாரம் பெற்ற பின்"

**प्राप्य** "(...) பெற்ற பின்"
:::#### 22.2.2.2. -ā வால் முடிவடையும் மூலச்சொற்கள்

:::grammar-box

**மாறா உயர்நிலை மூலம் + -ya**

:::**எடுத்துக்காட்டு:**

:::indent
**उपस्थाय** "(...) நகர்ந்த பின்" ; (இடைச்சொல் இல்லாமல்: **स्थित्वा**)
:::#### 22.2.2.3. ஆழ்நிலையில் குற்றியலிக் குற்றியலிகளான -i, -u, -ṱ வால் முடிவடையும் மூலச்சொற்கள்

:::grammar-box

**ஆழ்நிலை மூலம் + -tya**

:::**எடுத்துக்காட்டுகள்:**

:::indent
**प्रस्तुत्य** "(...) பாராட்டப்பட்ட பின்"

**विस्मृत्य** "(...) மறக்கப்பட்ட பின்"

**संस्कृत्य** "(...) யagna-க்குத் தயார்படுத்தப்பட்ட பின்"
:::#### 22.2.2.4. ஆழ்நிலையில் -a வால் முடிவடையும் -am / -an வால் முடிவடையும் மூலச்சொற்கள்

:::grammar-box

**விருப்பத்திற்கு:**

**-am** / **-an** வால் முடிவடையும் மூலம் + **-ya**

அல்லது:

**-a** வால் முடிவடையும் மூலம் + **-tya**

:::**எடுத்துக்காட்டு:**

:::indent
**विगम्य** அல்லது **विगत्य** "(...) சென்ற பின்"

**ஆ) மொழிபெயர்க்கவும் மற்றும் சமசுகிருதத்தில் கலப்பினங்களைத் தீர்க்கவும்:**

अन्नं पक्त्वा ब्राह्मणदासो ऽत्ति ॥१॥

इष्टदेवतापूजां कृत्वेन्द्रादिदेवान्सद्ब्राह्मणाः स्तुवन्ति ॥२॥

प्रस्थाय रामः सपुत्रः सद्गुरुश्रवणार्थेन ब्राह्मणग्रामं गच्छति ॥३॥

अनिष्ट्वा नरो भगवद्भक्तिमात्रेणापि मोक्षमाप्नोति ॥४॥

गृहगर्भं प्रविश्य ब्राह्मणपुत्रमुपस्थाय क्षत्रियशूरो वक्ति ॥५॥

सम्बुध्य दुःखाद्यार्यसत्यानि प्रोच्य सुगतो मोक्षमार्गेण नरान्नयति ॥६॥

मन्त्रं विस्मृत्य यजन्यज्ञदोषं करोति ॥७॥

धनं प्राप्य बुद्धमार्गभिक्षवो दुष्यन्ति ॥८॥

अनार्यशत्रुभिः संगत्य नरसिंहा विजयन्ते ॥९॥

पुण्यं कृत्वा सत्यमेवोदित्वा नरो नरकं नोपपद्यते ॥१०॥
