# பாடம் 3

A) பின்வரும் வாக்கியங்களைப் பெயரெண்ணில் மாற்றவும்:

1\. dvijo brāhmaṇaḥ = द्विजो ब्राह्मणः

dvijā brāhmaṇāḥ.

द्वि्जा ब्राह्मणाः

2\. dvijaḥ kṣatriyaḥ = द्विजः क्षत्रियः

dvijāḥ kṣatriyāḥ.

द्विजाः क्षत्रियाः

3\. dvijo vaiśyaḥ = द्विजो vaiśyaḥ

dvijā vaiśyāḥ.

द्विजा वैश्याः

4\. gurur brāhmaṇaḥ = गुरुर्ब्राह्मणः

guravo brāhmaṇāḥ.

गुरवो ब्राह्मणाः

5\. sādhur guruḥ = साधुर्गुरुः

sādhavo guravaḥ.

साधवो गुरवः

6\. guruḥ kaviḥ = गुरुः कविः

guravaḥ kavayaḥ.

गुरवः कवयः

7\. sādhvī brāhmaṇī = साध्वी ब्राह्मणी

sādhvyo brāhmaṇyaḥ.

साध्व्यो ब्राह्मण्यः

8\. devatā guruḥ = देवता गुरुः

devatā guravaḥ.

देवता गुरवः

9\. paśur dhenuḥ = पशुर्धेनुः

paśavo dhenavaḥ.

पशवो धेनवः

10\. gurvī sādhvī = गुर्वी साध्वी

gurvyaḥ sādhvyaḥ.
गुर्व्यः साध्व्यः

B) பெயர்ச்சொல் வாக்கியங்களை உருவாக்கவும்:

1\. śrutis ... (veda) = श्रुतिस् ... वेद

śrutir vedaḥ.

श्रुतिर्वेदः

2\. paśus ... (dhenu) = पशुस् ... धेनु

paśur dhenuḥ.

पशुर्धेनुः

3\. devī ... (durgā, umā, indrāṇī) = देवी ... दुर्गा, उमा, इन्द्राणी

devī durgā. devy umā. devīndrāṇī.

देवी दुर्गा | देव्युमा | देवीन्द्राणी

4\. devatā ... (mīnākṣī, annapūrṇā) = देवता ... मीनाक्षी, अन्नपूर्णा

devatā mīnākṣī. devatānnapūrṇā.

देवता मीनाक्षी | देवतान्नपूर्णा

5\. śūdrā ... (itarā) = शूद्र ... इतरा

śūdretarā.

शूद्रेतरा

C) பெண்பால் மொழிபெயர்க்கவும்:

1\. gurur brāhmaṇaḥ = गुरुर्ब्राह्मणः

gurvī brāhmaṇī.

गुर्वी ब्राह्मणी

2\. sādhur guruḥ = साधुर्गुरुः

sādhvī gurvī.

साध्वी गुर्वी

3\. kṣatriyaḥ sādhuḥ = क्षत्रियः साधुः

kṣatriyā sādhvī.

क्षत्रिया साध्वी

D) சமஸ்கிருதத்திற்கு மொழிபெயர்க்கவும்:

1\. உமா ஒரு தேவதை.

devy umā.

देव्युमा

2\. வேதம் ஸ்ருதி ஆகும்.

śrutir vedaḥ.

श्रुतिर्वेदः

3\. ஆசிரியர்கள் தேவதைகள்.

devyo gurvyaḥ.

देव्यो गुर्व्यः

4\. பால் எருமைகள் விலங்குகள்.

paśavo dhenavaḥ.

पशवो धेनवः

5\. கவிஞர்கள் ஆசிரியர்கள்.

guravaḥ kavayaḥ.

गुरवः कवयः

6\. க்ஷத்திரியர்கள் இரட்டைப் பிறப்பு.

dvijāḥ kṣatriyāḥ.

द्वि्जाः क्षत्रियाः

7\. புனித ஆண்கள் சூத்திரர்கள்.

śūdrāḥ sādhavaḥ.

शूद्राः साधवः
