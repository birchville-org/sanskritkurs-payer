# பாடம் 17

## 17.1. இரண்டாம் பிரசென்ஸ் வகுப்பு (⟪अदादि⟫ = ⟪अद्⟫ போன்றவை)

வினைமுற்று வார்த்தைகள் வேர்ச்சொல்லின் நேரடியாக இணைகின்றன. அந்த வார்த்தைகளின் ஒலி மாற்றங்களை கவனிக்க வேண்டும்.

::::grammar-box

இரண்டாம் பிரசென்ஸ் வகுப்பில் பின்வரும் வடிவங்கள் உள்ளன:

1.  வேர்ச்சொற்கள் மூலக்கூறு மாற்றத்துடன்
    *   பெரும்பாலும்: உயர் நிலை - தாழ்நிலை
    *   சில வேர்ச்சொற்கள்: நீட்சி நிலை - தாழ்நிலை 
2.  வேர்ச்சொற்கள் மூலக்கூறு மாற்றமின்றி 
3.  -i/-ī உடன் இருசீர் வேர்ச்சொற்கள் மூலக்கூறு மாற்றத்துடன்

ஒருசில கீற்றுகள் பல வடிவங்களில் இரண்டு எழுத்துக்கள் கொண்டவை, அதாவது அவை ஒலி எழுத்து முடிவுக்கு முன் -i (அல்லது சில முடிவுகளுக்கு முன் -ī) கொண்டவை. ஆனால் இந்தக் கீற்றுகள் அகராதிகளில் மற்றும் உள்ளூர் இலக்கணவியலாளர்களால் ஒரு எழுத்துக்கள் கொண்டவையாகக் கருதப்படுகின்றன.
