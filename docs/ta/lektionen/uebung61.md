# பயிற்சி 61

பாடம் 61 சமசுகிருத பாடத்திட்டத்தின் முடிவைக் குறிக்கிறது மற்றும் மேலும் எந்த வாய்ப்பாட்டுப் பயிற்சிகளையும் கொண்டிருக்கவில்லை.

வேர் பெயர்ச்சொற்கள், சுயசார்பற்ற எதிர்காலம் மற்றும் பெயர்ச்சொற்றொடர்கள் ஆகியவற்றின் ஆய்வு மூலம், சமசுகிருத அசல் உரைகளைப் படிப்பதற்கான அடித்தளம் அமைக்கப்படுகிறது. இந்தப் பாடத்திட்டம், கற்பித்தல் நூலிலிருந்து சுயாதீனமான படிப்புக்கு மாற்றத்தைக் குறிக்கும் பாரம்பரியமான கணேச அழைப்புடன் (श्रीगणनाथ) முடிவடைகிறது.
