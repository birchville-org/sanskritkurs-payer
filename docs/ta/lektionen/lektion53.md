# பாடம் 53

## 53.1. இரட்டை (द्विवचन n.) பெயர்ச்சொற்களின் இரட்டை

:::: grammar-box
**இரட்டை (द्विवचनम्) "இரண்டு" என்பதைக் குறிக்கப் பயன்படுத்தப்படுகிறது:**

::: indent
**अश्विनौ** "இரு அசுவின்கள்"
:::

**இரண்டு பொருட்கள் அல்லது உயிரினங்கள் தொடர்பான இடங்களில் இரட்டை பயன்பாடு கட்டாயமாகும்:**

::: indent
**हस्तौ** "கைகள் (ஒரு நபரின்)"
**पादौ** "பாதங்கள் (ஒரு மனிதன், குரங்கு அல்லது பிற இருகாலி உயிரினத்தின்)"
:::

**சில சமயங்களில், இரட்டை ஒரு வகுப்பைச் (வகை, பேரினம்) சேர்ந்த ஒரு ஆண் மற்றும் ஒரு பெண் உயிரினத்தைக் குறிக்கும்:**

::: indent
**पितरौ** "தந்தை மற்றும் தாய் = பெற்றோர்"
:::

**"ஒரு ஜோடி" என்று பொருள்படும் சொற்கள் - எ.கா. युग n., द्वन्द्व n., द्वय n. - இரண்டு அல்லது அதற்கு மேற்பட்ட ஜோடிகள் அல்லாத வரை எப்போதும் ஒருமை பயன்படுத்தப்படுகின்றன:**

::: indent
**बाहुद्वयम्** "ஒரு ஜோடி கைகள்"
:::

::: indent

## 53.7. உரிச்சொற்றொடர் பண்பொழிவுகள்

கீழ்க்காணும் உரிச்சொற்றொடர் பண்பொழிவுகள் அனைத்து பால்வினைகளிலும் यद् போல் பால்வினை பெறும்:

*   अन्य 3 "ஒரு வேறு"
*   अन्यतर 3 "இருவற்றில் ஒரு"
*   इतर 3 "மற்றொரு"

*   सर्व 3 "ஒவ்வொரு, அனைத்தும்" அனைத்து பால்வினைகளிலும் நாம.அக்க.ஒ.ந (सर्वम्) தவிர அனைத்து பால்வினைகளிலும் यद् போல் பால்வினை பெறும்.
*   उभय 3 "இரு" இருபால் இல்லை. ஒருபால் மற்றும் பன்மை ஆண்பால் மற்றும் பெண்பால் இயல்பில் அது सर्व போல் பால்வினை பெறும். பெண்பால்: उभयी (देवी போல்).
*   उभ 3 "இரு" இருபாலில் மட்டுமே பயன்படுத்தப்படுகிறது மற்றும் அது देव ஆ.பால், फल ந.பால் மற்றும் देवता பெ.பால் போல் பால்வினை பெறும்.

கீழ்க்காணும் உரிச்சொற்றொடர் பண்பொழிவுகள் सर्व போல் பால்வினை பெறும். அபி.லோ.ஒ.ஆ.ந மற்றும் நாம.பன்.இல் அவற்றை -a அல்லது -ā பால்வினை முறையில் பால்வினை பெறலாம்:

*   अपर 3 "ஒரு வேறு"
*   उत्तर 3 "மேலான, வடக்கான, தொடர்ந்து வரும்"
*   पर 3 "தொடர்ந்து வரும், பிற்காலமான"
*   पूर्व 3 "முன்னர் வரும், கிழக்கான"
*   स्व 3 "சொந்தமான (என், உன், அவன் ...)"

## 53.8. விதிவிலக்கான உயர்வு

::: grammar-box
**ஒரு சில உரிச்சொற்கள் பின்வரும் कृत्-சந்தங்களைக் கொண்டு ஒப்பீடு மற்றும் அதிகபட்சம் வடிவங்களை உருவாக்குகின்றன (!):**

*   ஒப்பீடு: **-īyas**
*   அதிகபட்சம்: **-iṣṭha**

**तद्धित-சந்தங்கள் -तर மற்றும் -तम ஆகியவை உரிச்சொல்லின் பெண்பால் மூலத்திற்கு இணைக்கப்படும் போது, -ईयस् மற்றும் -इष्ठ சந்தங்கள் அந்த உரிச்சொல் வரும் மூலத்திற்கு (அத்தகைய மூலம் இருந்தால்!) இணைக்கப்படுகின்றன. மூலத்தின் குறியீடு உயர்ந்த நிலையில் இருக்கும்.**

**-iṣṭha (பெண்பால்: iṣṭhā) வடிவங்கள் a- அல்லது ā- மூலங்களைப் போலவே விகுதிகளுடன் அமைக்கப்படும்.**

**Deklination von -īyas siehe unten.**

### 53.10.1. அளவின் தீர்மானத்தின் முக்கியத்துவம்

அளவின் தீர்மானம் பின்வரும் காரணங்களுக்காக முக்கியமானது:

1.  **அழகியல்:** கவிதை அமைப்பு ஒரு கூற்றின் அழகை உருவாக்குகிறது. குறிப்பிட்ட கவிதை அமைப்புகள் குறிப்பிட்ட உணர்வுகளை வெளிப்படுத்த உதவுகின்றன அல்லது அவை குறிப்பிட்ட வகுப்புகளுக்கு (वर्ण) ஒதுக்கப்படுகின்றன. வெவ்வேறு கவிதை அமைப்புகள் வெவ்வேறு வகையில் ஒலிக்கப்படுகின்றன. [[br]] அழகியல் தாக்கத்தின் நல்ல கற்பனைக்கு, शिवताण्डवस्तोत्र-இன் (சிவனின் நடனத்தின் பாராட்டு) ஒலிப்பு ஒரு எடுத்துக்காட்டு: [http://de.youtube.com/watch?v=5KjfiJlkO58](http://de.youtube.com/watch?v=5KjfiJlkO58)
2.  **உரை விமர்சனம்:** கவிதை அமைப்பில் உள்ள பிழைகள், உரை ஒரு இடத்தில் சரியாகக் கையொப்பமிடப்படவில்லை என்பதற்கான அறிகுறியாக இருக்கலாம். கவிதை அமைப்பு உரை மேம்பாடுகளை மேற்கொள்ள உதவுகிறது.
3.  **காலவரிசை:** வரலாற்றின் போக்கில், சில கவிதை அமைப்புகள் குறிப்பிட்ட மாற்றங்களுக்கு உட்பட்டன. இது ஒரு உரையை தோராயமாக காலக்கணிப்பதில் உதவும். இதற்கான **ஒல்டென்பெர்க், ஹெர்மன் &lt;1854 - 1920&gt;:** த்ரிஷ்டுபத் வரலாற்றில்; அவர்: ஸ்லோக வரலாற்றில். -- இரண்டும் அச்சிடப்பட்டவை: [[br]] **ஒல்டென்பெர்க், ஹெர்மன் &lt;1854 - 1920&gt;:** சிறிய எழுத்துக்கள் / ஹெர்மன் ஒல்டென்பெர்க். கிளவுஸ் எல். ஜானெர்ட் திருத்தம். -- வீஸ்பாடன் : ஸ்டைனர். -- 3 தொகுதிகள். -- (க்ளாசென்பாஸ் அறக்கட்டளை ; ...). -- தொகுதி 2. -- 1967. -- பக். 1188 - 1255.

### 53.10.2. மீற்றங்களின் வகைகள்

::: grammar-box
**இந்தியர்கள் வேறுபடுத்துகிறார்கள்:**

*   **वृत्त n.:** அசைகளின் எண்ணிக்கை (अक्षर) நிர்ணயிக்கப்பட்ட மீற்றங்கள்
*   **जाति f.:** மீற்ற அலகுகளின் கூட்டுத்தொகை (मात्रा) (மோனங்கள்) நிர்ணயிக்கப்பட்ட மீற்றங்கள் (இவற்றைப் பற்றி பின்னர்)

**அசைகளின் எண்ணிக்கை நிர்ணயிக்கப்பட்ட மீற்றங்களில் (वृत्त) தொடக்கத்தில் மேலும் வேறுபடுத்தலாம்:**

*   அசைகளின் எண்ணிக்கை நிர்ணயிக்கப்பட்ட, ஆனால் அவற்றின் அளவு பகுதியாகவே நிர்ணயிக்கப்பட்ட மீற்றங்கள்
*   அசைகளின் எண்ணிக்கையும் அவற்றின் அளவும் நிர்ணயிக்கப்பட்ட மீற்றங்கள்

அனைத்து பாடாக்களிலும் ஐந்தாவது எழுத்து எளிதானது.
