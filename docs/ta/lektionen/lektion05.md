# பாடம் 5

:::deleteme-box
**இந்த பாடத்தில் நீங்கள் கற்றுக்கொள்வீர்கள்:**
- பெயர்ச்சொல் கலப்பொருட்களின் அடிப்படைகள் (சமாசம்)
- கலப்பொருட்களுக்கான தொழில்நுட்ப சொல்லியல்
- இணைப்பு கலப்பொருட்கள் (துவ்வி)
- துவ்விகளில் உறுப்புகளின் வரிசைமுறை
:::
## 5.1. பெயர்ச்சொல் சேர்க்கைகள் (சமாசம் ஆ. = ⟪समास⟫)

மிகப் பெரிய அளவில் சொல் சேர்க்கைகளை உருவாக்குதல் என்பது சமஸ்கிருதத்தின் ஒரு சிறப்பு அம்சமாகும்.

சேர்க்கைகளின் முக்கிய உருவாக்க வடிவங்கள் பின்வருமாறு:
- **இணைப்புச் சேர்க்கைகள்** (துவந்த்வ ஆ. = ⟪द्वन्द्व⟫)
- **தீர்மானிக்கும் சேர்க்கைகள்** (தத்புருஷ ஆ. = ⟪तत्पुरुष⟫)
- **சொந்தச் சேர்க்கைகள்** (பகுவ்ரிஹி ஆ. = ⟪बहुव्रीहि⟫)

(இறுதி இரண்டு வகைகளுக்குப் பின்னர் பார்க்கவும்!)

---

## 5.2. சமசுகிருத சொற்றொடர் வார்ப்புருக்களுக்கான கருத்துக்கள்

- **ghaṭakapadāni** n. pl. = ⟪घटकपदानि⟫ : ஒரு சேர்க்கையின் உறுப்புகள்
- **vigrahavākyam** n. = ⟪विग्रहवाक्यम्⟫ : ஒரு சேர்க்கையின் பிரித்தல்
- **nityasamāsaḥ** m. = ⟪नित्यसमासः⟫ : vigrahavākya-க்கு ஏதும் இல்லாத அல்லது சேர்க்கையின் சொற்களுடன் vigrahavākya-சாக்கியமாக இல்லாத சேர்க்கை.
- **aluksamāsaḥ** m. = ⟪अलुक्समासः⟫ : முன் உறுப்பு ஒரு விளிம்புச் சொற்றொடரைக் கொண்டிருக்கும் சேர்க்கை
- **luksamāsaḥ** m. = ⟪लुक्समासः⟫ : முன் உறுப்புகள் விளிம்புச் சொற்றொடர் இல்லாமல் இருக்கும் சேர்க்கை (சாதாரண நிலை)
- **madhyamapadalopī** m. = ⟪मध्यमपदलोपी⟫ : ஒரு அல்லது பல நடு உறுப்புகள் நீக்கப்பட்ட சேர்க்கை

---

## 5.3. இணைப்புச் சமசுகிருதச் சொற்கள் (Dvandva n. = ⟪द्वन्द्व⟫)

இணைப்புச் சமசுகிருதச் சொற்கள் இலக்கண ரீதியாக ஒத்த, ஒருங்கிணைக்கப்பட்ட உறுப்புகளை (பெயர்ச்சொற்கள் அல்லது விசேஷணங்கள்) இணைக்கப் பயன்படுகின்றன.

:::grammar-box
**ஒரு Dvandva குறிக்கிறது:**

1. **அல்லது அதன் தனித்தனி உறுப்புகளால் குறிக்கப்படும் நபர்கள், பொருட்கள், பண்புகளின் கூட்டு இணைப்பு:**
   Itaretaradvandva = ⟪इतरेतरद्वन्द्व⟫

2. **அல்லது அவை நபர்கள், பொருட்கள் அல்லது பண்புகளை ஒரு அலகாக இணைக்கிறது:**
   Samāhāradvandva ("ஒருங்கிணைப்பு Dvandva") = ⟪समाहारद्वन्द्व⟫

**முதல் நிலையில் (Itaretaradvandva):**
Dvandva அதன் கடைசி உறுப்பின் இலக்கண பாலத்தைப் பெறுகிறது மற்றும் இரட்டை எண்களின் முடிச்சுகள் (இரண்டு பொருட்களுக்கு) அல்லது பன்மை எண்களின் முடிச்சுகள் (இரண்டுக்கு மேற்பட்ட பொருட்களுக்கு). ஒருமை முடிச்சுகளும் அனுமதிக்கப்படுகின்றன.

**இரண்டாவது நிலையில் (Samāhāradvandva):**
Dvandva பொதுவாக ஒரு நடுப்பால் (கடைசி உறுப்பின் பாலத்தைப் பொருட்படுத்தாமல்) மற்றும் ஒருமை எண்ணில் இருக்கிறது.

**தீர்வு:**
"மற்றும்" (**ca** = ⟪च⟫) மூலம் நிகழ்கிறது, சில நேரங்களில் "அல்லது" (**vā** = ⟪वा⟫) அல்லது "ஒவ்வொன்றும்".
:::
இரட்டை Dvandvaக்களுக்கு பின்னர் பார்க்கவும்!

### 5.3.1. கூட்டுச்சொற்களின் முன் உறுப்புகள்

கூட்டுச்சொற்களின் (துவ்⟪‌⟫தவங்கள் மட்டும் அல்ல) முன் உறுப்புகள் பொதுவாக **பெயர் மூலத்தின்** மாற்றமற்ற வடிவத்தைக் கொண்டிருக்கும். கூட்டுச்சொற்களின் தனித்தனி உறுப்புகள் **சந்தசந்தி** விதிகளின்படி இணைக்கப்படுகின்றன (அதாவது, வார்த்தைக்குள் வடிவமைப்பு உறுப்புகளுக்கு முன் பயன்படுத்தப்படும் வார்த்தைச் சந்திக்கு மாறாக, நாம் இதுவரை கற்ற சந்தி).

### 5.3.2. பன்மை-இதரேதரத்வந்த்வா

பன்மைத் த்வந்த்வாவிற்கான எடுத்துக்காட்டுகள்:

**brāhmaṇa-kṣatriya-vaiśya-śūdrāḥ** = ⟪ब्राह्मणक्षत्रियवैश्यशूद्राः⟫
> = brāhmaṇāḥ kṣatriyā vaiśyāḥ śūdrāś ca = ⟪ब्राह्मणाः⟫ ⟪क्षत्रिया⟫ ⟪वैश्याः⟫ ⟪शूद्राश्च⟫
> (பிராமணர், க்ஷத்திரியர், வைசியர் மற்றும் சூத்திரர்)
> 
> அல்லது = brāhmaṇaḥ kṣatriyo vaiśyaḥ śūdraś ca = ⟪ब्राह्मणः⟫ ⟪क्षत्रियो⟫ ⟪वैश्यः⟫ ⟪शूद्रश्च⟫
> (ஒரு பிராமணர், க்ஷத்திரியர், வைசியர் மற்றும் சூத்திரர்)

**kavi-guravaḥ** = ⟪कविगुरवः⟫
> = kavayo guravaś ca = ⟪कवयो⟫ ⟪गुरवश्च⟫
> (கவிஞர்கள் மற்றும் ஆசிரியர்கள் [பன்மை])
> (குறிப்பு: "ஒரு கவிஞர் மற்றும் ஒரு ஆசிரியர்" என்பது இரட்டைப் பன்மையில் இருக்க வேண்டும்!)

**ஒரு த்வந்த்வாவில் உறுப்புகளின் வரிசைக்கு கீழ்க்கண்ட விதிகள் பொருந்தும்:**
- வெவ்வேறு வர்ணங்களின் (**varṇa**) பெயர்கள் அவற்றின் படிநிலைக்கு ஏற்ப (உயர்ந்தது முதலில்) வரிசைப்படுத்தப்பட வேண்டும்.
- மூத்த சகோதரரின் பெயர் இளைய சகோதரரின் பெயருக்கு முன் வைக்கப்பட வேண்டும்.
- பொதுவாக, முக்கியமான சொல் தொடக்கத்தில் வைக்கப்பட வேண்டும்.
- **-i** அல்லது **-u** ஆல் முடிவடையும் சொற்கள் முன் வைக்கப்பட வேண்டும்.
- **-a** ஆல் முடிவடையும் மற்றும் ஒரு ஒலித்தானால் தொடங்கும் சொற்கள் முன் வைக்கப்பட வேண்டும்.
- குறைந்த எண்ணிக்கையிலான எழுத்துக்களைக் கொண்ட சொற்கள் முன் வைக்கப்பட வேண்டும்.

கீழ்க்கண்ட மூன்று விதிகளில் எதுவும் ஒரே நேரத்தில் பொருந்தக்கூடிய நிலையில், எப்போதும் பின்னர் கொடுக்கப்பட்ட விதி பின்பற்றப்பட வேண்டும். (இந்த விதிகளுக்கான இரட்டைப் பன்மைத் த்வந்த்வாவிற்கான எடுத்துக்காட்டுகள் கியல்ஹோர்ன், இலக்கணம் § 570-ல் உள்ளன).

## 5.4. சொற்பட்டியல்

**கீழ்க்காணும் சொற்களைக் கற்றுக்கொள்ளுங்கள்:**

**abhiniveṣa** ஆ. = ⟪अभिनिवेष⟫ : ஒரு நோக்கு, வற்புறுத்தல், வற்புறுத்துதல்; குறிப்பாக: உடலை ஒரு தனிப்பட்ட பொருளாகக் கருதி அதில் பற்றுக்கொள்ளுதல்.

**kāma** ஆ. = ⟪काम⟫ : விருப்பம், ஆசை, விரும்பப்பட்ட பரிசு, காமநிவ⟪ृ⟫த்தி, அன்பு; காமதேவன்.

:::media
![](/images/lekt0501.webp)
படம்: காமதேவன் = kāmadeva = ⟪कामदेव⟫, 18-ஆம் நூற்றாண்டு.
(படத்தின் மூலம்: விக்கிப்பீடியா, பொதுவுடைமை)
:::
**krodha** ஆ. = ⟪क्रोध⟫ : கோபம்.

**kleśa** ஆ. = ⟪क्लेश⟫ : வேதனை, துன்பம்.

**trayī** பெ. = ⟪त्रयी⟫ : மூன்று எண்ணிக்கை; குறிப்பாக மூன்று வேதங்கள் (Ṛgveda, Sāmaveda, Yajurveda).

**daṇḍanīti** பெ. = ⟪दण्डनीति⟫ : அரசியல் (daṇḍa ஆ. = "கோல், அட்சி, ஆட்சி, தண்டனை" மற்றும் nīti பெ. = "சரியான வழிகாட்டுதல்" ஆகியவற்றால் ஆன ஒரு தத்புருஷ சமாசாரம்).

**dvijāti** 3 / **dvija** 3 = ⟪द्विजाति⟫ / ⟪द्विज⟫ : இரண்டுமுறை பிறந்தவர்.

**dveṣa** ஆ. = ⟪द्वेष⟫ : வெறுப்பு.

**maitrī** பெ. = ⟪मैत्री⟫ : நட்பு, நட்புத்தன்மை, நட்புநலம்.

**rāga** ஆ. = ⟪राग⟫ : (சிவப்பு) நிறம், ஆசை, அன்பு.

**lobha** ஆ. = ⟪लोभ⟫ : வறுமை, பொறாமை.

**varṇa** ஆ. = ⟪वर्ण⟫ : நிறம், வகை, நிலை.

**vārttā** பெ. = ⟪वार्त्ता⟫ : வாழ்வாதாரம், பொருளியல் (பொருளாதாரம்).

**vidyā** பெ. = ⟪विद्या⟫ : அறிவு, அறிவியல்.

**avidyā** பெ. = ⟪अविद्या⟫ : அறியாமை, அறிவின்மை.

**ca** = ⟪च⟫ : மற்றும்.
(இது இணைக்கப்படும் சொல்லிற்குப் பின்னால் வரும். பல சொற்கள் இணைக்கப்படும்போது, கடைசி இணைப்புச் சொல்லின் முதல் சொல்லிற்குப் பின்னால் வரும்: brāhmaṇāḥ kṣatriyā vaiśyāḥ śūdrāś ca = ⟪ब्राह्मणाः⟫ ⟪क्षत्रिया⟫ ⟪वैश्याः⟫ ⟪शूद्राश्च⟫).

**ca ... ca** = ⟪च⟫ ... ⟪च⟫ : இரு ... மற்றும்.

## 5.5. பயிற்சி

**அ) பின்வரும் வாக்கியங்கள் மற்றும் சமசுகிருத கலப்பினச் சொற்களை மொழிபெயர்க்கவும், அவற்றில் உள்ள துவந்த்வாவை (சமசுகிருதத்தில்) பிரிக்கவும்:**

1. catvāro varṇā brāhmaṇakṣatriyavaiśyaśūdrāḥ.
   (Āpastambīyadharmasūtra I,1,1,4 = Vāsiṣṭhadharmaśāstra II,1)
   ⟪चत्वारो⟫ ⟪वर्णा⟫ ⟪ब्राह्मणक्षत्रियवैश्यशूद्राः⟫ ||
   (விளக்கம்: catvāras = ⟪चत्वारस्⟫ = "நான்கு")

2. trayo varṇā dvijātayo brāhmaṇakṣatriyavaiśyāḥ.
   (Vāsiṣṭhadharmaśāstra II,1)
   ⟪त्रयो⟫ ⟪वर्णा⟫ ⟪द्विजातयो⟫ ⟪ब्राह्मणक्षत्रियवैश्याः⟫ ||
   (விளக்கம்: trayas = ⟪त्रयस्⟫ = "மூன்று")

3. sāmavedargvedayajurvedās trayī.
   (Kauṭilīya-arthaśāstra 1.3.1. / in gutem Sanskrit: sāmārgyajurvedās trayī)
   ⟪सामवेदर्ग्वेदयजुर्वेदास्त्रयी⟫ ||
   (சிறந்த சமசுகிருதத்தில்: ⟪सामार्यजुर्वेदास्त्रयी⟫)

4. மனிதனின் மூன்று எதிரிகள், நரகத்தின் வாயிலை உருவாக்குபவை (Viṣṇusmṛti 33,1+6):
   kāmakrodhalobhāḥ
   ⟪कामक्रोधलोभाः⟫ ||

5. maitrīkaruṇāmuditopekṣāś catvāro brahmavihārāḥ.
   ⟪मैत्रीकरुणामुदितोपेक्षाश्चत्वारो⟫ ⟪ब्रह्मविहाराः⟫ ||
   (விளக்கம்: brahmavihāra: "பிரம்மாவின் தங்குநிலைகள்", "அளவிலானவை" என்றும் அழைக்கப்படும். இவை பௌத்த தியான முறைகளாகும்.)

6. avidyāsmitārāgadveṣābhiniveṣāḥ pañca kleśāḥ.
   (Yogasūtra 2,3)
   ⟪अविद्यास्मितारागद्वेषाभिनिवेषाः⟫ ⟪पञ्च⟫ ⟪क्लेशाः⟫ ||
   (விளக்கம்: pañca = "ஐந்து")

7. ānvīkṣikītrayīvārttādaṇḍanitayo vidyāḥ.
   (Nach Kauṭilīya-arthaśāstra 1.2.1.)
   ⟪आन्वीक्षिकीत्रयीवार्त्तादण्डनितयो⟫ ⟪विद्याः⟫ ||

## 5.6. மீள்விளையாட்டு

**அ) மொழிபெயர்க்கவும்:**

1. vidyā vārttā.
   ⟪विद्या⟫ ⟪वार्त्ता⟫ |

2. brāhmaṇaḥ kṣatriyo vaiśyaś ca trayo varṇā dvijātayaḥ.
   ⟪ब्राह्मणः⟫ ⟪क्षत्रियो⟫ ⟪वैश्यश्च⟫ ⟪त्रयो⟫ ⟪वर्णा⟫ ⟪द्विजातयः⟫ |

3. dvijā vaiśyāḥ. (2 Möglichkeiten)
   ⟪द्विजा⟫ ⟪वैश्याः⟫ |

**ஆ) தொடர்புடைய வடிவத்தை உள்ளிடுக:**

1. (dvija, sādhu, kavi) ... rāmaḥ
   (⟪द्विज⟫, ⟪साधु⟫, ⟪कवि⟫) ... ⟪रामः⟫ |

2. (devī) ... indrāṇī
   (⟪देवी⟫) ... ⟪इन्द्राणी⟫ |

3. dvijātayas ... (vaiśyā, kṣatriya)
   ⟪द्विजातयस्⟫ ... (⟪वैश्या⟫, ⟪क्षत्रिय⟫) |

**இ) பின்வரும் வாக்கியத்தில் சமசுகிருதத்தில் சங்கமத்தைத் தீர்க்கவும், மேலும் இந்தத் தீர்க்கப்பட்ட வடிவத்துடன் அதே வாக்கியத்தை உருவாக்கவும்:**

sāmargyajurvedās trayī.
⟪सामर्ग्यजुर्वेदास्त्रयी⟫ |

**ஈ) இரண்டு வழிகளில் சமசுகிருதத்திற்கு மொழிபெயர்க்கவும் (ஒரு முறை சங்கமத்துடன், ஒரு முறை இல்லாமல்):**

"பிரம்மாவின் நிலைநிறுத்தங்கள்" என்பன: நட்பான நன்மை, கருணை, பிறரின் மகிழ்ச்சியில் பங்கு, சமநிலை.
