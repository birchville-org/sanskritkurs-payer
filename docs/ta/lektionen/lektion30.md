# பாடம் 30

## 30.1. ஒன்பதாம் நிகழ்கால வகுப்பு (⟪க்ரியாதி⟫ = "⟪க்ரீ⟫ முதலியன")

::: grammar-box
**உருவாக்கம்:**

*   வலிமையான மூலம்: ஆழ்நிலை வேர் + -nā-

*   பலவீனமான மூலம்:

    *   உயிரெழுத்திற்கு முன்: ஆழ்நிலை வேர் + -nī-

    *   உயிரெழுத்திற்கு முன்: ஆழ்நிலை வேர் + -n-
:::
உதாரணம்:

::: indent
⟪क्री⟫ 9U "வாங்கு"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. ஆள்:brபரமச்பதம்** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **3. ஆள்:brஆத்மனபதம்** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
இந்த முன்னிலை வகுப்பில், ⟪ज्ञा⟫ 9U "அறிதல், அறிவு" வேருக்கு முன்னிலை மூலத்தின் உருவாக்கத்தை குறிப்பாக கவனிக்க வேண்டும்:

::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. ஆள்:brபரமச்பதம்** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **3. ஆள்:brஆத்மனபதம்** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
⟪जा⟫ என்ற வடிவம், ⟪ज्ञा⟫-ன் முன்னிலை மூலத்திற்கு அடிப்படையாக உள்ளது, அது அல்லது -ā (ஆழ்நிலை) -nā (உயர்நிலை) என்ற அப்யாவதார வரிசை மூலம் விளக்கப்பட வேண்டும், அல்லது *jñā-nā-ti-லிருந்து தனிமைப்படுத்தல் மூலம்.

நீண்ட உயிரெழுத்துடன் கூடிய சில வேர்கள், 9-ஆம் வகுப்பின் முன்னிலை மூலப் பின்னணிக்கு முன் இந்த உயிரெழுத்தை சுருக்குகின்றன:

உதாரணம்:

::: indent
⟪पू⟫ 9U "சுத்தம் செய்"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. ஆள்:brபரமச்பதம்** | ⟪पुनाति⟫:br(pu-nā-ti) | ⟪पुनन्ति⟫:br(pu-n-anti) |
| **3. ஆள்:brஆத்மனபதம்** | ⟪पुनीते⟫:br(pu-nī-te) | ⟪पुनते⟫:br(pu-n-ate) |

## 30.2. ஆலோசனை முறை பயன்பாடு (⟪लिङ्⟫)

ஆத்திவம் பயன்படுத்தப்படுகிறது:

::: grammar-box
**1. குறிப்புக்காக**

*   **ஒரு விருப்பம்**
*   **ஒரு வேண்டுகோள்**
*   **ஒரு மென்மையான கட்டளை**

**(இங்கே ஆத்திவம் - ⟪लिङ्⟫ - ஆணைக்குறிப்புடன் - ⟪लोट्⟫ - ஒன்றிணைகிறது)**
:::
உதாரணம்:

::: indent
⟪दासो⟫ ⟪ग्राममागच्छेत्⟫ = "அடிமை கிராமத்திற்கு வாருங்கள்"
:::
::: grammar-box
**2. ஏதேனும் ஒன்றை**

*   **சாத்தியமானது**
*   **நிகழ்தகவுள்ள**
*   **சாத்தியமானது**

**என்று காட்ட வேண்டும்.**
:::
உதாரணம்:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं⟫ ⟪न⟫ ⟪शृणुयात्⟫ = "அவர் கிராமத்திலிருந்து வெளியே சென்றால், அவர் குருவைக் கேட்க மாட்டார்"
:::
::: grammar-box
**3. ஆத்திவத்துடன் கூடிய தொடர்பு வாக்கியங்கள் சில நேரங்களில் "யாராவது ஒருவர் ..." என்ற அர்த்தத்தைக் கொண்டுள்ளன.**
:::
உதாரணம்:

::: indent
⟪यो⟫ ⟪नृतं⟫ ⟪वदेत्स⟫ ⟪नरकं⟫ ⟪पतेत्⟫ = "யாராவது ஒருவர் பொய் சொன்னால், அவர் நரகத்திற்குச் செல்வார் = யாராவது ஒருவர் பொய் சொன்னால், அவர் நரகத்திற்குச் செல்வார்"
:::

## 30.5. இறுதி -ர் இன் சந்தி

::: grammar-box
**-ar அல்லாத வாரிய -r க்கு, வாரிய -s க்கு பொருந்தும் சந்தி விதிகள் அனைத்தும் பொருந்தும்.**

**-ar ஒலி வாரிய ஒலிகளுக்கு முன் -ar ஆகவே இருக்கும், ஆனால் r- க்கு முன் -r விழும், -a- க்கு பதிலாக -ā- வரும்.**
:::
உதாரணங்கள்:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
