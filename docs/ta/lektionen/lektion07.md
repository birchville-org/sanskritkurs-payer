# பாடம் 7

:::deleteme-box
**இந்த பாடத்தில் நீங்கள் கற்றுக்கொள்வீர்கள்:**
- நேரடிப் பொருளுடன் வினைத்தொடர்
- பெயர்ச்சொற்கள் மற்றும் விசேஷப்பெயர்களுக்கான பெயரெச்சம்
- -n கடைச்சீர் கொண்ட சொற்களின் சந்தி
- அ-கடைச் சொற்களின் பால்
- அசைகால முன்னெஞ்ச வகுப்புகள் (5-வது வகுப்பின் உதாரணத்தின் அடிப்படையில்)
:::## வார வாசகம்

:::center
⟪धर्मो⟫ ⟪जयति⟫ ⟪नधर्मः⟫
⟪सत्यं⟫ ⟪जयति⟫ ⟪नानृतम्⟫ |

செய்யுள் வெற்றி பெறுகிறது, அசெய்யுள் வெற்றி பெறாது,
உண்மை வெற்றி பெறுகிறது, பொய்மை வெற்றி பெறாது,
ஒப்புதல் வெற்றி பெறுகிறது, கோபம் வெற்றி பெறாது,
இறைவன் வெற்றி பெறுகிறான், எதிர்ப்பவன் வெற்றி பெறமாட்டான்.

## 7.1. நேரடிப் பொருளுடன் வினைத்தொடர்

:::grammar-box
**வடிவமைப்பு:**
**(காரகர் = kartṛ ஆண. = ⟪कर्तृ⟫) – நேரடிப் பொருள் (karman பெண. = ⟪कर्मन्⟫) – வினை**

எ.கா.
- **rāmaḥ phalaṃ khādati** = ⟪रामः⟫ ⟪फलं⟫ ⟪खादति⟫ : "ராமன் ஒரு பழத்தை உண்கிறான்."
- **brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो⟫ ⟪देवं⟫ ⟪यजति⟫ : "பிராமணர் ஒரு தெய்வத்தை ஒரு பலியின் மூலம் வணங்குகிறார் (ஒருவருக்காக)."
:::வினை Parasmaipada அல்லது Ātmanepada-ல் இருந்தால், நேரடிப் பொருள் (**karman** பெண. = ⟪कर्मन्⟫) பொதுவாக **Accusative** (Wenfall, dvitīyā பெண. = ⟪द्वितीया⟫) விகாரத்தில் இருக்கும்.

### 7.2.1. வினா மற்றும் அசைவுப் பெயர்ச்சொற்களின் ஒருமை மற்றும் பன்மை பண்புப் பால்

:::grammar-box
| | | ஆண்பால் | பெண்பால் | நடுப்பால் |
| :--- | :--- | :--- | :--- | :--- |
| **kim**:brயார்/என்ன | ஒருமை | **kam**:br⟪कम्⟫ | **kām**:br⟪काम्⟫ | **kim**:br⟪किम्⟫ |
| | பன்மை | **kān**:br⟪कान्⟫ | **kās**:br⟪कास्⟫ | **kāni**:br⟪कानि⟫ |
| **tad**:brஅவன்/அது/அந்த | ஒருமை | **tam**:br⟪तम्⟫ | **tām**:br⟪ताम्⟫ | **tad**:br⟪तद्⟫ |
| | பன்மை | **tān**:br⟪तान्⟫ | **tās**:br⟪तास्⟫ | **tāni**:br⟪तानि⟫ |
| **etad**:brஇது இங்கே | ஒருமை | **etam / enam**:br⟪एतम्⟫ / ⟪एनम्⟫ | **etām / enām**:br⟪एताम्⟫ / ⟪एनाम्⟫ | **etad / enad**:br⟪एतद्⟫ / ⟪एनद्⟫ |

| **idam**:brஇது | ஒருமை | **imam / enam**:br⟪इमम्⟫ / ⟪एनम्⟫ | **imām / enām**:br⟪इमाम्⟫ / ⟪एनाम्⟫ | **idam / enad**:br⟪इदम्⟫ / ⟪एनद्⟫ |

:::**enam** (⟪एनम्⟫) போன்ற வடிவங்கள் **enad** (⟪एनद्⟫) என்ற மூலத்திற்குரியவை, இது சில பண்புப் பால்களில் மட்டுமே வடிவங்களை உருவாக்குகிறது. **etad** மற்றும் **idam** ஆகியவற்றின் வடிவங்களுக்குப் பதிலாக, முந்தைய பகுதியில் ஏற்கனவே குறிப்பிடப்பட்டதைக் குறிக்கும்போது இவை பயன்படுத்தப்படுகின்றன.
உதாரணமாக: **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं⟫ ⟪देवः⟫ | ⟪एनं⟫ ⟪यजन्ते⟫ || : "அவர் ஒரு தேவன். அவருக்குப் பலி அளிப்பர்."

### 7.2.2. ஆக்கசேடிவின் பயன்பாடு (இரண்டாம் விபக்தி, dvitīyā f. = ⟪द्वितीया⟫ = "இரண்டாம் விபக்தி வடிவம்")

:::grammar-box
ஆக்கசேடிவ் (dvitīyā f. = ⟪द्वितीया⟫) பின்வரும் பொருள்களைக் குறிக்கிறது:
1. செயலிலா அல்லாத வினைத்தொடரில்: **நேரடிப் பொருள்** (karman n. = ⟪कर्मन्⟫) வினையால் வெளிப்படுத்தப்படும் செயலுக்கு:
   எ.கா.
   - **devaṃ yajati** = ⟪देवं⟫ ⟪यजति⟫ : "ஒரு தேவனைப் பலியிடுகிறான்."
   - **phalam āpnoti** = ⟪फलमाप्नोति⟫ : "பலனைப் பெறுகிறான் (எ.கா. தனது செயலின் பலன்)."
2. ஒரு இடத்திற்குச் செல்வது, ஒரு நகர்வு, ஒரு வழிநடத்தல் அல்லது இதரவற்றைக் குறிக்கும் வினைகளில், ஆக்கசேடிவ் நகர்வின் இலக்கைக் குறிக்கிறது:
   எ.கா.
   - **narakaṃ gacchati** = ⟪नरकं⟫ ⟪गच्छति⟫ : "நரகத்திற்குச் செல்கிறான்."
:::ஆக்கசேடிவின் பிற பயன்பாடுகள் பின்னர் விவரிக்கப்படும்.

## 7.3. வாரிய -n இன் சந்தி

:::grammar-box
**வாரிய -n:**

1. ஒலிப்புள்ள அசைவு மற்றும் ரெட்ரோபிளெக்ஸ் ச்பர்ச மற்றும் **ś-** முன் இவ்வொலிகளுக்கு ஏற்ப உள்ள மூக்கொலியால் மாற்றப்படுகிறது:
   - **-n** முன் **j-, jh-, ñ-, ś-** » **-ñ**
   - **-n** முன் **ḍ-, ḍh-, ṇ-, ṣ-** » **-ṇ**
   எ.கா. **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "அவர் க்ஷத்திரியர்களை வெற்றி பெறுகிறார்."
   வாரிய **ś-** பின்னர் பெரும்பாலும் **ch-** ஆல் மாற்றப்படுகிறது:
   **gurūn + śṛṇoti** » **gurūñ chṛṇoti** (gurūñ śṛṇoti க்கு இணையாக) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "அவர் ஆசான்களைக் கேட்கிறார்." "அவர் ஆசான்களைப் பின்பற்றுகிறார்."

2. வாரிய **l-** முன் **Anunāsika** (மூக்கான l, எழுத்தில் **⟪ल्⟫** Anunāsika **⟪ँ⟫** உடன்) ஆல் மாற்றப்படுகிறது:
   எ.கா. **paśūn + labhate** » ⟪पशूंल्लभते⟫ : "அவர் பயனுள்ள விலங்குகளைப் பெறுகிறார்."

3. வாரிய ஒலிப்பு அசைவு, ரெட்ரோபிளெக்ஸ் அல்லது தந்திரம் முன் **Anusvāra** + இவ்வொலிகளுக்கு ஏற்ப உள்ள சீசொலியால் மாற்றப்படுகிறது:
   - **-n** முன் **c-, ch-** » **-ṃś**
   - **-n** முன் **ṭ-, ṭh-** » **-ṃṣ**
   - **-n** முன் **t-, th-** » **-ṃs**
   எ.கா. **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : "மற்றும் தேவர்கள் (நிலை)"
   **devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : "ஆனால் தேவர்கள் (நிலை)"

4. குறுகிய ஒலிப்புக்கு பிறகு (பின்னர் பார்க்கவும்) தவிர, மற்ற அனைத்து நிலைகளிலும் வாரிய **-n** மாற்றமின்றி இருக்கும்.
:::---

## 7.4. நடுவினம் (napuṃsaka n. = ⟪नपुंसक⟫)

:::grammar-box
**நடுவினத்தில், பெயர்ச்சொல் (prathamā) மற்றும் பொருள்ச்சொல் (dvitīyā) வடிவங்கள் ஒன்றாகவே இருக்கும்.**
:::### 7.4.1. பெற்றியால் -a-வின் நடுவினையினம்

:::grammar-box
- **ஒருமை பெயர்ச்சொல் / அசைவு ஒருமை: -m**
  எ.கா. **phala** நடு. = ⟪फल⟫ = "பழம்": பெ. / அச. ஒரு. **phalam** = ⟪फलम्⟫
- **பன்மை பெயர்ச்சொல் / அசைவு பன்மை: -āni**
  எ.கா. **phala** நடு. = ⟪फल⟫: பெ. / அச. பன். **phalāni** = ⟪फलानि⟫
:::---

## 7.5. அத்தெமாட்டிக் பிரேசன் வகுப்புகள்

5-வது பிரேசன் வகுப்பு, ஒரு அத்தெமாட்டிக் பிரேசன் வடிவமைப்பை உருவாக்குகிறது, அதாவது, பிரேசன் வடிவமைப்பு, தீமாட்டிக் பிரேசன் வகுப்புகளுடன் (1., 4., 6., 10. வகுப்பு) "-a" என்ற "தீமா வோக்கல்" மீது முடிவதில்லை.

:::grammar-box
**அத்தெமாட்டிக் பிரேசன் வகுப்புகள் வடிவமைப்பு மாற்றத்தைக் கொண்டுள்ளன, அதாவது, பிரேசன் வடிவமைப்பின் இரண்டு வடிவங்கள் உள்ளன:**
1. **வலிமையான வடிவமைப்பு**: உயர் நிலை (அரிதாக விரிவாக்கப்பட்ட நிலை)
2. **வலிமை குறைந்த வடிவமைப்பு**: தாழ்ந்த நிலை

**வலிமையான வடிவமைப்பு இருக்கும்:**
- சுத்தமான ஒருமை பாரம்சைபத பிரேசன் (laṭ) மற்றும் அ-imperfect (laṅ)
- அ-imperative (loṭ) பாரம்சைபத மற்றும் Ātmanepada-வின் அனைத்து முதல் நபர்கள்
- மூன்றாவது நபர் ஒருமை அ-imperative (loṭ) பாரம்சைபத

**மற்ற அனைத்து வடிவங்களும் வலிமை குறைந்த பிரேசன் வடிவமைப்பைக் கொண்டுள்ளன.**
:::### 7.5.1. மூன்றாம் பன்மை ஒருமை வினைமுற்றுக்கள் அசைவற்ற மூலச்சொற்களுக்கு

:::grammar-box
**அசைவற்ற பெயர்ச்சொற்களுக்கு மூன்றாம் பன்மை ஒருமை வினைமுற்றுக்கள்:**
- **பரமைப்படை: -anti**
- **ஆதமநேபதம்: -ate**
:::### 7.5.2. ஐந்தாவது முன்னிலை விகுதி வகுப்பு (svādi = ⟪स्वादि⟫ = "su மற்றும் பல")

:::grammar-box
- **வலிமையான மூலம்**: (பொதுவாக) ஆழ்நிலை வேர் (கீழே குறிப்பிட்டது) + **-no-**
- **வீழ்ந்த மூலம்**: (பொதுவாக) ஆழ்நிலை வேர் (கீழே குறிப்பிட்டது) + **-nu-**

**ஒலி வார்த்தைகளுக்கு முன், ஒலி எழுத்துக்களின் முடிவில் -nu- என்பது -nv- ஆக மாற்றப்படும்; எழுத்துக்களின் முடிவில், ஒலி வார்த்தைகளுக்கு முன் -nu- என்பது -nuv- ஆக மாற்றப்படும்.**

## 7.6. சொற்பட்டியல்

**கீழ்க்காணும் சொற்களைக் கற்றுக்கொள்ளுங்கள்:**

- **aś** 5 Ā (aśnute) ⟪अश्⟫ ⟪अश्नुते⟫ : அடையுதல், அடைதல், பெறுதல்
- **āp** 5 P (āpnoti) ⟪आप्⟫ ⟪आप्नोति⟫ : அடையுதல், பெறுதல்
- **kup** 4 P (kupyati) ⟪कुप्⟫ ⟪कुप्यति⟫ : கோபித்தல்
- **krudh** 4 P (krudhyati) ⟪क्रुध्⟫ ⟪क्रुध्यति⟫ : கோபித்தல்
- **khād** 1 P (khādati) ⟪खाद्⟫ ⟪खादति⟫ : நக்கல், உண்ணுதல்
- **śru** 5 P (śṛṇoti !) ⟪श्रु⟫ ⟪शृणोति⟫ : கேட்டல் (ஒன்றை: பெயர்ச்சொல், ஒருவரை: பண்புப் பெயர் அல்லது பெயர்ச்சொல்; பற்றி: பெயர்ச்சொல்; ஒருவரிடமிருந்து: பண்புப் பெயர், விலக்கு, கருவி)
- **su** 5 U (sunoti) ⟪सु⟫ ⟪सुनोति⟫ : அமுக்கி எடுத்தல்
- **soma** m. ⟪सोम⟫ : அமுக்கிய பானம், சோமம்; நிலவு (சோமம் எந்தத் தாவரத்திலிருந்து அமுக்கப்பட்டது என்பது இன்றும் விவாதத்திற்குரியது).
:::media
![](/images/lekt0701.webp)
அடிக்குறிப்பு: வேத கால சோமத் தாவரம் இதுவா?: பூஞ்சை: *Amanita muscaria* (L.) Lam.
(படத்தின் மூலம்: [விவரங்கள்](/ta/licenses#lekt0701))
:::- **phala** n. ⟪फल⟫ : கனி (பொருள்நிலையில்: (கர்மத்தின்) கனிவு)
- **nṛtya** n. ⟪नृत्य⟫ : நடனம்
- **svarga** m. ⟪स्वर्ग⟫ : வானம்
- **naraka** m. ⟪नरक⟫ : நரகம் (ஒரு இந்துக் கருத்தின்படி, பிரபஞ்சம் ஒரு முட்டையின் வடிவத்தைக் கொண்டுள்ளது (**Brahmāṇḍa** m.n. = ⟪ब्रह्माण्ड⟫ = "பிரம்ம முட்டை"): பூமியின் மேல் ஏறுகிற ஆனந்தத்துடன் ஆறு வானங்கள் உள்ளன, பூமியின் கீழ் ஏழு **pātāla** n. = ⟪पाताल⟫, **nāga** m. = ⟪नाग⟫ (பாம்புகள்) மற்றும் பிற புராண உயிரினங்களின் வாழ்விடங்கள், அவற்றின் கீழ் ஏழு நரகங்கள் உள்ளன, அவை அதிகரிக்கும் வேதனைகளுடன்)
- **aṅga** n. ⟪अङ्ग⟫ : உடலின் உறுப்பு, பகுதி; மேலும் = **vedāṅga** = ⟪वेदाङ्ग⟫
- **gam** 1 P (gacchati) ⟪गम्⟫ ⟪गच्छति⟫ : செல்வது (உள்ளூர் வினை வகைப்படுத்தலின்படி, இது முதல் பிரேசன் வகுப்பைச் சேர்ந்தது, ஆனால் உண்மையில் இது ஒரு பிரேசன் கிளையமைப்புப் பின்னணி **-ccha-**: **gam** » ஆழ்நிலை (**gm** ») **ga-ccha-ti**) என்பதன் உருவாக்கமாகும்.

## 7.7. பயிற்சி

**அ) ஒவ்வொன்றையும் ஒருமை மற்றும் பன்மை ஆகியவற்றில் நேரடிப் பொருள் அல்லது திசைநிலைப் பன்மை ஆகியவற்றைப் பயன்படுத்தி நிரப்பவும்:**

   ⟪ब्राह्मणस्⟫ ... ⟪यजति⟫ (⟪देव⟫, ⟪देवी⟫, ⟪विष्णु⟫, ⟪अग्नि⟫, ⟪देवता⟫)
