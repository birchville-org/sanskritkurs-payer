## 12.1. பூதக்கால வினையெச்சம் செயப்பாட்டு வினை (PPP)

செவ்விய காலத்திற்கான எதிர்மை வாக்கியங்களை உருவாக்க ஒரு வழி, அழைக்கப்படும் முழுமை எதிர்மை பங்கீடு (PPP) கட்டமைப்புடன் ஆகும்.

::: grammar-box
**உண்மையில், PPP என்பது உண்மையான பங்கீடு அல்ல, ஏனெனில் அது ஒரு கால மூலத்திலிருந்து உருவாக்கப்படுவதில்லை. மாறாக, அது -ta அல்லது -na முதன்மை பின்னசொல்லுடன் மூலத்திற்கான ஒரு பெயர் உருவாக்கம் ஆகும். எனவே, இந்திய இலக்கணத்தில் kta பின்னசொல் என்று அழைக்கப்படுகிறது.**
:::

### 12.1.1. பரிமாண வினைச்சொற்களுக்கான வரைபடம்

::: grammar-box
செவ்விய காலத்திற்கான எதிர்மை வாக்கியங்களை உருவாக்க ஒரு வழி, அழைக்கப்படும் முழுமை எதிர்மை பங்கீடு (PPP) கட்டமைப்புடன் ஆகும்.

**உண்மையில், PPP என்பது உண்மையான பங்கீடு அல்ல, ஏனெனில் அது ஒரு கால மூலத்திலிருந்து உருவாக்கப்படுவதில்லை. மாறாக, அது -ta அல்லது -na முதன்மை பின்னசொல்லுடன் மூலத்திற்கான ஒரு பெயர் உருவாக்கம் ஆகும். எனவே, இந்திய இலக்கணத்தில் kta பின்னசொல் என்று அழைக்கப்படுகிறது.**

ஒரு உதவி வினைச்சொல் („இருத்தல்“) தேவையில்லை.

உதாரணங்கள்:
> **sādhunā svarga āptaḥ** = ⟪साधुनास्वर्गआप्तः⟫ = „(பரிசுத்தரால் ஒரு வானம் அடைக்கப்பட்டது) = பரிசுத்தரொரு வானத்தை அடைந்தார்.“
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेनदेवीष्टा⟫ = „(பிராமணரால் தேவியொரு பலியால் வழிபடப்பட்டாள்) = பிராமணரொரு தேவியைப் பலியால் வழிபட்டார்.“
:::

### 12.1.2. இயல்பு இல்லிய வினைச்சொற்கள் மற்றும் இயக்க வினைச்சொற்களுக்கான வரைபடம் I

::: grammar-box
செவ்விய காலத்திற்கான எதிர்மை வாக்கியங்களை உருவாக்க ஒரு வழி, அழைக்கப்படும் முழுமை எதிர்மை பங்கீடு (PPP) கட்டமைப்புடன் ஆகும்.

**உண்மையில், PPP என்பது உண்மையான பங்கீடு அல்ல, ஏனெனில் அது ஒரு கால மூலத்திலிருந்து உருவாக்கப்படுவதில்லை. மாறாக, அது -ta அல்லது -na முதன்மை பின்னசொல்லுடன் மூலத்திற்கான ஒரு பெயர் உருவாக்கம் ஆகும். எனவே, இந்திய இலக்கணத்தில் kta பின்னசொல் என்று அழைக்கப்படுகிறது.**

உதாரணம்:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया⟫ ⟪नगरं⟫ ⟪गता⟫ = „கṣatriயா நகரம் கதா“ = „கṣatriயா பெண் நகருக்கு சென்றாள்.“
:::

### 12.1.3. இயல்புச் சொற்கள் மற்றும் இயக்கச் சொற்களுக்கான வடிவமைப்பு II

::: grammar-box
செவ்விய காலத்திற்கான எதிர்மை வாக்கியங்களை உருவாக்க ஒரு வழி, அழைக்கப்படும் முழுமை எதிர்மை பங்கீடு (PPP) கட்டமைப்புடன் ஆகும்.

உதாரணம்:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(கட்சத்திரியனால் (நகருக்கு) செல்லப்பட்டது) = கட்சத்திரியன் (நகருக்கு) சென்றுள்ளான்.“

இரண்டாம் வகை அமைப்பு, முதல் வகை அமைப்பை விட மிகவும் அரிதாகக் காணப்படுகிறது.
:::

## 12.2. பிபிபி-யின் முக்கியத்துவம் பற்றி

எனவே, பரிமாண வினைகளுக்கு „பார்டிசிப் பெர்ஃபெக்ட் பாசிவ்“ என்பது முதலில் பாசிவ அர்த்தத்தைக் கொண்டுள்ளது (**āpta** = „அடைந்தது“), மற்றும் அப்பரிமாண வினைகள் மற்றும் இயக்க வினைகளுக்கு செயல் அர்த்தத்தைக் கொண்டுள்ளது (**gata** = „சென்றது“), சில வினைகள் உள்ளன, அவற்றில் பிபிபு செயல் மற்றும் பாசிவ அர்த்தம் இரண்டையும் கொண்டிருக்கலாம்:

எ.கா.
- **gata** = ⟪गत⟫ = „சென்றது“ (செயல்); ஆனால், **gato mārgaḥ** = ⟪गतो⟫ ⟪मार्गः⟫ = „ஒரு சென்ற பாதை“ (பாசிவ)
- **āpta** = ⟪आप्त⟫ = „அடைந்தது“ (பாசிவ), „அடைந்த“ (செயல்)

## 12.3. PPP உருவாக்கம்

::: grammar-box
கீழ்க்கண்ட உருவாக்க முறைகள் காணப்படுகின்றன (ஒவ்வொரு மூலச்சொல்லிற்கும் அதன் பிபிபி-யைக் கற்றுக்கொள்ள வேண்டும்!):

**(பொதுவாக) ஆழ்நிலை மூலச்சொல்**

- **+ -ta**
  - முன்னால் இணைந்நயன் **-i-** உடன்: **-ita**
  - இணைந்நயன் இல்லாமல்: **-ta**
- **+ -na**

பெண்பால் மூலங்கள்: **-tā**, **-itā**, **-nā**; நடுவினம் **phala** ந. போல் அசைகிறது.
:::

### 12.3.1. -ta (kta) இல் PPP

#### 12.3.1.1. இணைக்குரல் -i- இல்லாமல் (aniṭ)

**(பொதுவாக) ஆழ்நிலை மூலச்சொல்**

::: grammar-box
இணைப்பு உயிரெழுத்து இல்லாமல், பொதுவாக உயிரெழுத்துடன் முடிவடையும் மூலச்சொற்கள் மற்றும் பல பிற மூலச்சொற்களிலிருந்து PPP உருவாக்கப்படுகிறது; இணைப்பு உயிரெழுத்து எப்போது தோன்றும் அல்லது தோன்றாது என்பதற்கு நிலையான விதி எதுவும் இல்லை.

முன்னால் இணைந்நயன் **-i-** உடன்: **-ita**
:::

## 12.4. சொற்றொடரில் ஒலி இணைப்பு விதிகள்

*aniṭ* வடிவமைப்புகளில், சொற்றொடரில் ஒலி இணைப்பின் கீழ்க்கண்ட விதிகளைக் கவனத்தில் கொள்ள வேண்டும். **இந்த விதிகள் முழு சமசுகிருத வடிவியலையும் புரிந்துகொள்ள மிகவும் முக்கியமானவை.**

::: no-header
| | |
| :--- | :--- |
| **1. ஒலி இல்லாத அடைப்பு எழுத்துக்கு முன் (எ.கா. t, th) k, t, p மாற்றமின்றி இருக்கும்:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct என்பது kt ஆக மாற்றப்பட்டு ⟪क्त्⟫ ஆகும்:** | **muc + ta » muk-ta** = **⟪मुक्त⟫** |
| **3. śt என்பது ṣṭ ஆக மாற்றப்பட்டு ⟪ष्ट्⟫ ஆகும்:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. ஒலி உள்ள அடைப்பு எழுத்து – j தவிர – ஒலி இல்லாத ஒலிக்கு முன், அதற்கு ஒத்த ஒலி இல்லாத அடைப்பு எழுத்தால் மாற்றப்படும்:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (2-வது இறந்தகால வகுப்புக்கு முக்கியம்) |

## 12.6. பயிற்சி

**அ) [பாடம் 7](/lektionen/lektion07), பயிற்சி அ-வற்றிலுள்ள செய்பொருள் வாக்கியங்களைக் கொண்டு, கழிப்பொருள் வாக்கியங்களைக் கடந்தகாலத்தில் உருவாக்கவும். அசரீரி வினைச்சொற்கள் மற்றும் இயக்க வினைச்சொற்களுக்குக் கடந்தகால செய்பொருள் வாக்கியங்களை உருவாக்கவும்.**

**ப) [பாடம் 10](/lektionen/lektion10), பயிற்சி அ-வற்றிலுள்ள வினை வடிவங்களுக்குப் பொருத்தமான பூர்வகால பகுத்தாய்வுச் சொற்களை (PPP) உருவாக்கவும். இதில், sṛjati போன்ற ஒரு வடிவத்திற்கு மூன்று பால் வகைகளிலும் பூர்வகால பகுத்தாய்வுச் சொற்கள் (PPPs) பொருந்தும் என்பதைக் கவனிக்கவும்.**

**ச) [பாடம் 10](/lektionen/lektion10), பயிற்சி ச-வற்றிலுள்ள வாக்கியங்களைக் கடந்தகால கழிப்பொருள் வடிவில் எழுதுக.**
