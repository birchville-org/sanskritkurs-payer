# Lektion 56

## 56.1. Der reduplizierte Aorist

::: grammar-box
**உருவாக்கம்:**

**ஆக்மென்ட் + மீட்டெடுக்கப்பட்ட வேர் + a + தீமாட்டிக் இரண்டாம் முடிப்பு**

**வேர் சிலை ஆழ் அல்லது உயர் குறையக்கூடியது. -i அல்லது -u மூலக்கூறுகளுக்கு ஆழ் குறையானது விதி.**

**-i, -u ஆகியவை -iy அல்லது -uv ஆல் மாற்றப்படுகின்றன.**

**-ā ( -e க்கு) விடுபடுகிறது.**
:::

    ⟪कृष्⟫ 1P/6U: காரகம். ***⟪कर्ष⟫***⟪यति⟫, முன்னிலை. ⟪अच⟫***⟪कर्ष⟫***⟪त्⟫ / ⟪अची⟫***⟪कृ⟫***⟪षत्⟫

⟪पत्⟫ 1P "விழுவது": ⟪अपप्तत्⟫ (a-pa-pt-a-t; pt = pat க்கு ஆழ் குறையம்)

ஏற்கனவே குறிப்பிடப்பட்ட விதிகள் மூலசிலைக்குப் பயன்படுத்தப்பட்ட பிறகு, மறுபடியும் உச்சரிக்கும் சிலையின் உயிரெழுத்திற்கான பின்வரும் விதிகளைப் பின்பற்ற வேண்டும்:

::: grammar-box
இந்த வகை அஓரிஸ்ட் பின்வரும் வேர்கள் உருவாக்குகின்றன:

*   ⟪श्रि⟫ 1U "செல்வது"
*   ⟪कम्⟫ 1Ā "சேர்வது": ⟪अचकमत⟫ / ⟪अचीकमत⟫ (கீழே பார்க்கவும்!)
*   ⟪वच्⟫ 2P "சொல்வது": ⟪अवोचत्⟫ (a-va + uc-a-t)

**10-வது பிரேசன் வகுப்பின் அனைத்து வேர்கள் மற்றும் அனைத்து காரணீயங்களும் எப்போதும் மீட்டெடுக்கப்பட்ட அஓரிஸ்ட் உருவாக்குகின்றன.**

*   **i, u ஆகியவை, மூல உயிரோசை ஒரே ஒலி எழுத்தால் தொடங்கி மீட்டெடுக்கக் குறுகியதாக இருந்தால், ī, ū ஆக ஆகும்:**
    ⟪भिद्⟫ 7U: காரண. ⟪भेदयति⟫, அகர. ⟪अ⟫***⟪बी⟫***⟪भिदत्⟫  
    ⟪तुद्⟫ 6U: காரண. ⟪तोदयति⟫, அகர. ⟪अ⟫***⟪तू⟫***⟪तुदत्⟫

*   **a என்பது ī ஆக மாற்றப்படுகிறது, அடிச்சொல் அரைகுறையாக இருந்து ஒரே ஒலியால் தொடங்கினால். அடிச்சொல் அரைகுறையாக இருந்து ஒன்றுக்கு மேற்பட்ட ஒலிகளால் தொடங்கினால், மறுபடியும் சொல்லின் a என்பது i ஆக மாற்றப்படுகிறது. அடிச்சொல் அளவாக இருந்தால், a நிலைத்திருக்கும்:**
    ⟪नी⟫ 1U: காரக. ⟪नाययति⟫, அடிச்சொல் அகரத்தின் ⟪नय्⟫, அகர. ⟪अ⟫***⟪नी⟫***⟪नयत्⟫  
    ⟪कृ⟫ 8U: காரக. ⟪कारयति⟫, அடிச்சொல் அகரத்தின் ⟪कर्⟫, அகர. ⟪अ⟫***⟪ची⟫***⟪करत्⟫  
    ⟪त्यज्⟫ 1P: காரக. ⟪त्याजयति⟫, அடிச்சொல் அகரத்தின் ⟪त्यज्⟫, அகர. ⟪अ⟫***⟪ति⟫***⟪त्यजत्⟫  
    ⟪भू⟫ 1P: காரக. ⟪भावयति⟫, அடிச்சொல் அகரத்தின் ⟪भव्⟫, அகர. ⟪अ⟫***⟪बी⟫***⟪भवत्⟫

கீல்ஹோர்ன், இலக்கணம் § 435c தொடக்கம் ஆகியவற்றில் குறிப்பிட்ட மூலச்சொற்களின் சிறப்பு

**ஒலிப்புடன் தொடங்கும் மூலசிலைகள் பின்வரும் விதிகளின்படி மீண்டும் ஒலிக்கப்படும்:**

*   **ஒரு தொடக்க ஒலிக்குப் பிறகு ஒரே ஒரு ஒலிப்பொருள் அல்லது ஒலிப்பொருள் குழு ஒன்று மட்டுமே இருந்தால், அதன் முதல் உறுப்பு மூக்கொலியோ அல்லது தோ அல்லது ரோ இல்லையெனில், மீட்டெடுக்கப்பட்ட சீர் இவ்வாறு அமையும்:**

ஒலி - அதற்கு உடனடியாக வரும் ஒலிவகை (அல்லது மறுப்பு ஒலிவகையில் தேவையான பிரதிநிதி) - **i** - அனைத்து ஒலிவகைகளும்

:::

## 56.2. இஞ்சுங்க்டிவ்

::: grammar-box
**இனஜங்க்டிவ் என்பது ஆகமென்ட் இல்லாத வடிவம், அதாவது, அதன் வடிவங்கள் ஆகமென்ட் இல்லாத இண்டிகேடிவ் இம்பெர்க்ஃபெக்ட் அல்லது அஓரிஸ்ட் வடிவங்களுடன் ஒத்திருக்கின்றன. உள்ளூர் இந்திய வியாகரணம் இனஜங்க்டிவ் என்பதை ஒரு தனி வியாகரண வகையாக அங்கீகரிக்கவில்லை.**
:::

*   இனஜங்க்டிவ் அஓரிஸ்ட் முடிவடைந்த அச்பெக்ட்டைக் குறிக்கிறது.

**வேதத்திற்குப் பிறகுள்ள சமஸ்கிருத்தில், இனஜங்க்டிவ் தடைக் காரிய ⟪मा⟫ (+ இனஜங்க்டிவ் அஓரிஸ்ட்) அல்லது ⟪मा⟫ ⟪स्म⟫ (+ இனஜங்க்டிவ் பிரேசன் அல்லது அஓரிஸ்ட்) ஆகியவற்றோடு மட்டுமே பயன்படுத்தப்படுகிறது, வேறுபட்ட அச்பெக்ட்டு பொதுவாகப் பயன்படுத்தப்படுவதில்லை.**

(அச்பெக்ட்டுடன்

*   ⟪मा⟫ + இனஜங்க்டிவ் அஓரிஸ்ட் ஒரு புரோஹிடிவ் வாக்கியத்தைக் குறிக்கும்: "... தொடங்காதே!", "... செய்யாதே!"
*   ⟪मा⟫ ⟪स्म⟫ + இனஜங்க்டிவ் பிரேசன் ஒரு இனஹிபிட்டிவ் வாக்கியத்தைக் குறிக்கும், அதாவது, ஏற்கனவே நடைபெற்று வரும் செயல் அல்லது ஏற்கனவே உள்ள நிலை தடைசெய்யப்படுகிறது: "... தொடர்ந்து கேளாதே!", "... விட்டுவிடு!"

இந்த வேறுபாடு கிளாசிகல் சமஸ்கிருத்தில் பொதுவாகச் செய்யப்படுவதில்லை.)
:::
## 56.3. Der Verbotssatz

::: grammar-box
**முக்கிய வடிவம்:**

**⟪मा⟫ + இஞக்டிவ் அஹோரிஸ்ட்**

**⟪मा⟫ ⟪स्म⟫ + இஞக்டிவ் அஹோரிஸ்ட் அல்லது இஞக்டிவ் பிரேசன்ஸ்**
:::
உதாரணங்கள்:

::: indent
⟪मा⟫ ⟪कर्महेतुर्भूः⟫ "ஒரு செயலின் பலனால் ஊக்கமடையும் ஒருவனாக மாறாதே!" (இஞக்டிவ் அஹோரிஸ்ட்) (⟪भगवद्गीता⟫ 2,47c)

⟪क्लैब्यं⟫ ⟪मा⟫ ⟪स्म⟫ ⟪गमः⟫ "ஒரு ஆணின் தன்மையை இழந்தவனாக மாறாதே!" (இஞக்டிவ் அஹோரிஸ்ட்) (⟪भगवद्गीता⟫ 2,3a)
:::
::: media
![](/images/lekt5602.webp)
சுருக்கம்: ⟪क्लैब्यं⟫ ⟪मा⟫ ⟪स्म⟫ ⟪गमः⟫
வல்லச்சிரா (വാല്ലചിര), தൃச்சூர் (തൃശ്ശൂര്⟪‍⟫) ஒரு அரசியல் கட்சியின் போஸ்டர் (எர்னஸ்டோ சே குவாரா). "அதில் எழுதப்பட்டுள்ளதின் தோராயமான மொழிபெயர்ப்பு: புரட்சியாளருக்கு ஒரு மரணம் ஒரு கவர்ச்சியான அனுபவம். மற்றும் ஒரு துரதிர்ஷ்டவசமான நபருக்கு ஒரு பயங்கரமான தப்பிக்கும் வழி. சே ஒரு பயல்களுக்கு வழிகாட்டி அல்ல."
(பட மூலம்: [விவரங்கள்](/ta/licenses#lekt5602))
:::
இரண்டு உதாரணங்களும் தடை அர்த்தத்தைக் கொண்டுள்ளன. எனவே, இங்கே இஞக்டிவ் அஹோரிஸ்ட் அதன் அசல் அர்த்தத்தில் பயன்படுத்தப்படுகிறது. (இத்தகிய வாக்கியங்களில் இஞக்டிவ் அஹோரிஸ்ட் அதிகமாக இருப்பதற்கான காரணம், தடை வாக்கியங்கள் இனஹிபிட்டிவ் வாக்கியங்களை விட அதிகமாக இருப்பதால் இருக்கலாம், ஆனால் இந்தக் கேள்வி கிளாசிக்கல் சம்ஸ்கிருதத்திற்கு இன்னும் ஆய்வு செய்யப்பட வேண்டும்.)

::: grammar-box
**தடை வாக்கியங்களின் பிற வடிவங்கள்:**

*   **⟪मा⟫ + (⟪स्म⟫) + இம்பரேடிவ் (அரிதாக)  **
**எ.கா.  ⟪मा⟫ ⟪ते⟫ ⟪सङ्गो⟫ ⟪ऽस्त्वकर्मणि⟫**

*   ⟪अलम्⟫ அல்லது ⟪कृतम्⟫  = இனஹிபிட்டிவ் வாக்கியத்தில் இன்ஸ்ட்ருமென்டலிஸ்  
    எ.கா. ⟪अलं⟫  ⟪विषादेन⟫ "நிরাசையுடன் இருப்பதை நிறுத்து! = நிরাசையுடன் இருப்பதை நிறுத்து! = தலைநிமிர்ந்து இரு!"  

*   ⟪न⟫ + ஜெருண்டிவ் (தேவையின் பகுதிப்பெயர்)

இதற்கு அப்பால், தடை வாக்கியங்களின் பிற அரிதான வடிவங்கள் உள்ளன, எ.கா.

## 56.4. ⟪स्म⟫

::: grammar-box
**⟪स्म⟫ எடுத்துக்காட்டுகிறது: "உண்மையாக, நிச்சயமாக, கண்டிப்பாக, தான்"**

**மேலும், பின்வரும் கட்டமைப்பு மிகவும் முக்கியமானது:**

:::
::: indent
⟪स्म⟫ + இலக்கணப் பெயர்ச்சொல் முன்னிலை எதிர்காலம் அ⟪ती⟫த காலத்தில் கதை சொல்லப் பயன்படுகிறது, குறிப்பாக அ⟪ती⟫த காலத்தில் ஒரு கால அளவைக் குறிக்க:

எ.கா. ⟪वसति⟫ ⟪स्म⟫ "ஒரு காலத்தில் வசித்தது" (⟪स्म⟫ காலம் சிலசமயம் கிடையாது).
:::
