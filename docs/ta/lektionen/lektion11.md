# பாடம் 11

::: deleteme-box
**இந்த பாடத்தில் நீங்கள் கற்றுக்கொள்வீர்கள்:**
- இரட்டை அக்குசேட்டிவ் (நபர் மற்றும் பொருளின் அக்குசேட்டிவ்)
- **iti**, **evam** மற்றும் **na** ஆகிய அங்கவாசகங்களின் பயன்பாடு
- **dharma**, **adharma** மற்றும் **putra** போன்ற அடிப்படை கருத்துக்கள்
- **vad**, **prach** மற்றும் **iṣ** ஆகிய மூலங்களுக்குப் பெயர்ச்சொற்களை உருவாக்குதல்
:::

## 11.1. இரட்டை அக்குசேட்டிவ்

::: grammar-box
**சில வினைகள் இரட்டை அக்குசேட்டிவ் (dvitīyā) ஆட்சி செய்கின்றன: நபரின் அக்குசேட்டிவ் மற்றும் பொருளின் அக்குசேட்டிவ்.**

**இதில் அடங்குவன:**
- **பேசும் வினைகள்**: ஒருவரிடம் (அக்குசேட்டிவ்) ஒரு விஷயத்தைப் (அக்குசேட்டிவ்) பற்றி பேசுதல்; ஒருவரிடம் (அக்குசேட்டிவ்) ஒரு விஷயத்தை (அக்குசேட்டிவ்) சொல்வது
- **கேட்கும் வினைகள்**: ஒருவரிடம் (அக்குசேட்டிவ்) ஒரு விஷயத்தைப் (அக்குசேட்டிவ்) கேட்பது
- **கற்பிக்கும் வினைகள்**: ஒருவரிடம் (அக்குசேட்டிவ்) ஒரு விஷயத்தை (அக்குசேட்டிவ்) கற்பித்தல்
- வார்பட்டியலில் குறிப்பிடப்படும் சில பிற வினைகள்

**அத்தகைய அமைப்பு பாவத்திற்கு (Passiv) மாற்றப்படும்போது, நபர் (கேட்கப்படும் நபர் முதலியோர்) நாமத்திற்கு (prathamā) மாற்றப்படுகிறார், பொருள் (கேட்கப்படும் விஷயம் முதலியோர்) அக்குசேட்டிவ்விலேயே இருக்கும்.**

எ.கா. **rāmo brāhmaṇaṃ dharmaṃ pṛcchati** = रामो ब्राह्मणं धर्मं पृच्छति = "ராமர் பிராமணரிடம் தர்மத்தைக் கேட்கிறார்."
» பாவம்: **rāmeṇa brāhmaṇo dharmaṃ pṛcchyate** = रामेण ब्राह्मणो धर्मं पृच्छयते

**இந்த விதி நபரும் பொருளும் இரண்டும் பொருளாக இருக்கும்போது மட்டுமே பொருந்தும். ஒரு விஷயம் ஒரே பொருளாக இருந்தால், அது பாவ வாக்கியத்தின் அடிப்படை வடிப்படி நாமத்திற்கு (prathamā) மாற்றப்படும்:**

எ.கா. **rāmo dharmaṃ pṛcchati** = रामो धर्मं पृच्छति = "ராமர் தர்மத்தைப் பற்றி கேட்கிறார்."
» பாவம்: **rāmeṇa dharmaḥ pṛcchyate** = रामेण धर्मः पृच्छयते
:::

## 11.2. சொற்றொடர் பட்டியல்

**கீழ்க்காணும் சொற்களைக் கற்றுக்கொள்ளுங்கள்:**

- **iti** इति : இவ்வாறு
  - ஒரு யோசனை, விருப்பம், கூற்று, மேற்கோள் ஆகியவற்றிற்கு *பின்* எழுதப்படுகிறது, மேற்கோள் குறிப்பு ("") போல.
  - எ.கா. **sādhavaḥ svargaṃ gacchantīti brāhmaṇā vadanti** "பிராமணர்கள் கூறுகிறார்கள்: 'நீதிமான்கர்கள் சொர்க்கம் செல்வர்'" = "பிராமணர்கள், நீதிமான்கர்கள் சொர்க்கம் செல்வார்கள் என்று கூறுகிறார்கள்".
  - சமஸ்கிருதத்தில் மறைமுகமான பேச்சு இல்லை; **iti** உடன் உருவாக்கப்பட்டவை ஜெர்மன் மொழியில் பெரும்பாலும் மறைமுகமான பேச்சாக மொழிபெயர்க்கப்பட வேண்டும்.
  - **... (மேற்கோள்) ... iti śrutiḥ** = "வேதம் இவ்வாறு கூறுகிறது".
  - பெரும்பாலும் **iti** க்குப் பிறகு ஒரு சிந்தனை வினைச்சொல் சேர்க்கப்பட வேண்டும்: "சிந்தித்து: '...' செய்கிறான்". ஜெர்மன் மொழியில் வழக்கமான மொழிபெயர்ப்பு (எ.கா. "அவருக்கு பசியாக இருப்பதால், அவர் செல்கிறார்...").

- **evam** एवम् : இவ்வாறு (வினையிலக்கணம், எ.கா. **evaṃ jayati** "இவ்வாறு அவர் வெற்றி பெறுகிறார்").
- **na** न : இல்லை
  - தனிப்பட்ட சொற்களை மறுக்கிறது (உடனடியாக முன்பு இருக்கும்: **na sādhuḥ** "ஒரு நல்லவர் அல்லாதவர்") அல்லது முழு வாக்கியங்களையும் மறுக்கிறது (தொடக்கத்தில் அல்லது வினைச்சொல்லிற்கு உடனடியாக முன்பு இருக்கும்).

- **putra** ஆ. पुत्र : மகன் (இந்தியாவில், முன்னோர்களுக்கான பலிகளை அர்ப்பணிக்கக்கூடிய ஒரு மகனைப் பெறுவது அவசியம் ছিল.)
- **dharma** ஆ. धर्म : ("நிலையானது", அதாவது) நீதி, சட்டம், பழக்கவழக்கம், தன்மை.
  - இயற்கைச் சட்டம்/நீதிச் சட்டத்திற்கு மிகவும் பொருத்தமானது. ஒவ்வொருவரும் **varṇa** மற்றும் **āśrama** (வாழ்க்கை நிலை) அடிப்படையில் தங்கள் சொந்த கடமைகளைக் (**svadharma**) கொண்டுள்ளனர்.
- **adharma** ஆ. अधर्म : அநீதி (**dharma** க்கு எதிரானது).
- **iṣ** 6 ப (icchati) इष् इच्छति : விரும்புகிறது (**iṣ-ccha-ti**).

**சில பெயர் உருவாக்கங்கள்:**

- **vad** 1 ப वद् : கூறுகிறது
  - **vāda** ஆ. वाद : கூற்று, அறிக்கை, சொல்
  - **vadana** ந. वदन : பேசுதல்; பேசும் கருவி: வாய், முகம்

::: media

:::

- **prach** 6 ப प्रच्छ् : கேட்கிறது
  - **praśna** ஆ. प्रश्न : கேள்வி (பின்னணி **-na** **yaj-ña** போல)

- **iṣ** 6 ப इष् : விரும்புகிறது
  - **iṣṭi** பெ. इष्टि : விருப்பம் (**iṣ** + **-ti**)

## 11.3. பயிற்சி

**A) கீழே உள்ள வாக்கியங்களை மொழிபெயர்க்கவும்:**

1. ऋषिः सत्यं वदति |
2. ब्राह्मणः पुत्रमिच्छति |
3. साधुः स्वर्गं गच्छति |
4. ब्राह्मणो ऽनृतं न वदतीति स्मृतिः |
5. क्षत्रियो ब्राह्मणं धर्मं पृच्छति |
6. एवं ब्राह्मणो यज्ञेन देवं यजति |
7. पुत्रः पापं करोतीति वैश्या मन्यते |
8. क्षत्रियः क्षत्रियेण सह युध्यते
9. अधर्मो ऽनृतमिति पुत्रः पापं न करोति | |
10. अयं क्षत्रियो धर्मं रक्षति | |
11. को ऽग्निं यजते | |
12. स श्रावको बुद्धं धर्मं पृच्छति ||

**B) A) வாரியான வாக்கியங்களை செயற்பாடு அல்லாத வடிவத்தில் (Passivkonstruktion) எழுதுக.**

**C) A) வாரியான வாக்கியங்களில், பொருத்தமான இடங்களில், காரணம், பயன் மற்றும் வினையைப் பெருமைப்படுத்தவும்.**

**D) C) வாரியாக உருவாக்கப்பட்ட வாக்கியங்களுக்கு செயற்பாடு அல்லாத வடிவத்தை (Passivkonstruktion) உருவாக்குக.**

## 11.4. மீள் பயிற்சி

**அ) பின்வரும் வாசகங்களைச் சீனத்திலே, செயப்படுந் தொகை வடிவங்களால் மொழிபெயர்க்கவும்:**
1. வைச்யப் பெண்டிர் பிராமணர்களைச் சமயநெறி பற்றிக் கேட்கின்றனர்.
2. ஆசான் ஒரு மந்திரத்தை உரைக்கின்றான்.
3. புனிதப் பெண்டிர் ஒரு வானத்திற்கு அடைகின்றனர்.
4. ஒரு வேத முனிவர் எவ்வித தீங்கும் செய்யார்.
5. பிராமணர் பலியீற்றகராய், பெண்ணைப் பலிகளால் வணங்குகின்றனர்.
6. சூத்திரப் பெண்டிர் கிராமத்திற்குச் செல்கின்றாள்.
7. யார் உண்மையைக் காண்கின்றார்?

**ஆ)**
1. இருமுறை பிறந்தோர் எல்லோரின் கடமைகளையும் ஒரு துவந்த்வாவால் கூறுக. சீனத்திலே அச் சொற்றொடையைப் பிரித்துக் காட்டுக.
2. வைசியரின் கடமைகளையும் ஒரு துவந்த்வாவால் கூறுக. சீனத்திலே அச் சொற்றொடையைப் பிரித்துக் காட்டுக.

**இ) மொழிபெயர்க்கவும்:**

1. श्रवणेन श्रूयते | |
2. कर्षर्कैः कृष्यते | |
3. श्रावकेणेश्वरो नेज्यते | |
4. रक्षिक्या गुरू रक्ष्यते | |
5. ब्राह्मणेनानृतं नोद्यते | |
6. शूद्रेतरा | |
7. शिक्षा कल्पो व्याकरणं निरुक्तं छन्दो ज्योतिषमङ्गानि | |
8. आन्वीक्षिकीत्रयीवार्त्तादण्डनीतयो विद्याः ||

**ஈ) மொழிபெயர்க்கவும், மேலும் சீனத்திலே காரணம், பொருள், வினை ஆகியவற்றைப் பன்மை வடிவங்களால் அமைக்கவும்:**

1. फलमश्नुते | |
2. गुरुणा सत्यमुद्यते | |
3. वैश्यः पशुं लभते | |
4. पुत्रः पुण्यं करोति ||

**உ) ஆ) 1-5 வரையிலான வாசகங்களைச் செய்ந்நிலை வடிவங்களாக மாற்றுக.**
