# பாடம் 55

## 55.1. அ-அகாரி (தீர்வுக் காலம், தீர்வுக் காலம்)

:::grammar-box
**அ-அகாரி என்பது ஒரு முந்தைய காலம் (⟪लङ्⟫) போலவே அமைக்கப்படுகிறது, 6. முன்னணி வகுப்பு (⟪तुदादि⟫), அதாவது:**

**அகாரம் + ஆழமான வர்ணம் + அ + இரண்டாம் முடிவு**

**இந்த -அ- என்பது முந்தைய காலத்தில் உள்ள அதே வார்த்தைகளில் -ā- ஆக மாற்றப்படுகிறது.**

**நாசீகை இணைப்புகள் இல்லை.**

**ஆத்மனேபதம் அரிது; உபயபத வர்ணங்களுக்கு, இது பெரும்பாலும் பிற அகாரி வகுப்புகளுக்கு ஏற்ப அமைக்கப்படுகிறது (கீழே உள்ள அந்தந்த அகாரி வகுப்புகளைப் பார்க்கவும்).**

**இந்த அகாரி கொண்ட வர்ணங்களின் பட்டியல், கியல்ஹோர்ன், கிராமிக் §340.**
