# Lektion 61

## 61.1. Deklination der Wurzelnomina auf -ā, -ī, -ū

### 61.1.1. -ā க்கு இறுதியில் உள்ள மூலப்பெயர்ச்சொற்கள் ⟪तत्पुरुष⟫

::: grammar-box
**ஒலிக்கு முன் வரும் இறுதிச்சொற்களில், பலவீனமான வார்ப்புருக்களில் மூல ஒலி Ø குறைந்த நிலையைப் பெறுகிறது.**

**பாலினப் பாலினப் பெண்கள் மற்றும் பெண்கள் ஒரே மாதிரியானவை.**
:::
பாரடிக்மா:

⟪विश्वपा⟫ பெண்பால்/பால் "அனைத்தையும் பாதுகாக்கும்"

### 61.1.2. Feminine Wurzelnomina auf -ī

::: grammar-box
**Vor vokalischer Endung wird -ī durch -iy ersetzt.**

**வழக்கமான விபக்க முடிப்புகளுடன் கூடிய உருவாக்கங்களுக்கு அப்பால், த.ஒ.ப.ல.ஒ. மற்றும் ப.ப.ஒ. ஆகியவற்றில், -ī (⟪देवी⟫) என்ற பலசொற்றொடர் பெண்பால் சொற்களின் மாதிரியைப் பின்பற்றிய உருவாக்கங்களும் காணப்படுகின்றன.**

### 61.1.3. ⟪तत्पुरुष⟫ இறுதியில் -ī முடிவுடன் வரும் மூலப்பெயர்ச்சொற்கள்

::: grammar-box
**ஒலியியல் முனைகளுக்கு முன், -ī என்பது -y ஆக மாற்றப்படுகிறது, அதற்கு முன் வடிமூலத்துடன் தொடர்புடைய ஒலி எழுத்து ஒன்று மட்டுமே இருந்தால். வடிமூலத்துடன் தொடர்புடைய பல ஒலி எழுத்துகள் முன் இருந்தால், ஒலியியல் முனைக்கு முன் -ī என்பது -iy ஆக மாற்றப்படுகிறது.**

**பாலினம் ஆண்பால் மற்றும் பெண்பால் ஆகியவற்றில் ஒரே மாதிரியானது.**

**விதிவிலக்கு: -⟪नी⟫ "நிர்வகிக்கும்" என்பதால் அமைந்த சமசுகிருதச் சொற்கள், இடப்பெயரில் -ām (எனவே ⟪देवी⟫) என்ற முடிபைப் பெறுகின்றன:**
எ.கா. ⟪ग्रामणी⟫ "ஒரு கூட்டம்/ஊர் நிர்வகிக்கும்": இட.ஒ.பெ. ⟪ग्रामण्याम्⟫
:::

## 61.2. சுயவினைச்சொல் எதிர்காலம் (⟪लुट्⟫)

::: grammar-box
**எளிய எதிர்காலத்திற்கு (⟪ऌत्⟫) கூடுதலாக, ஒரு விலக்கிய எதிர்காலம் (⟪लुट्⟫) உள்ளது. உள்ளூர் வியாகரணாளிகளின் கருத்துப்படி, இது தொலைவான எதிர்காலத்தை ("நடப்பு நாளுக்குப் பிறகு") குறிக்கப் பயன்படுத்தப்படுகிறது, அதேசமயம் எளிய எதிர்காலம் அருகிலுள்ள எதிர்காலத்தை ("நடப்பு நாள்") குறிக்கிறது. வகுத்திய சமசுகிருதத்தில், இரண்டு எதிர்காலங்களின் பயன்பாட்டில் வேறுபாடு எதுவும் இல்லாமல் இருப்பது போலத் தெரிகிறது.**

**உருவாக்கம்:**

**விலக்கிய எதிர்காலம் -tṛ என்ற காரகப் பெயருடன் ⟪अस्⟫ 2-ன் முற்போக்கு இணைக்கப்படுவதால் உருவாக்கப்படுகிறது. மூன்றாவது பகுதிக்கு, எண்களின் வேறுபாடு இல்லாமல், தொடர்புடைய எண்ணில் எளிய பெயர் பயன்படுத்தப்படுகிறது. ⟪अस्⟫-உடன் இணைப்புகளில், அனைத்து பகுதிகளுக்கும் எண்களுக்கும் பெயர்.ஒ. -tā வடிவத்தில் இருக்கும்.**

## 61.4. Denominativa (⟪नामधातु⟫)

பெயர்ச்சொல் வழி வினைச்சொற்கள் (⟪नामधातवः⟫) ஆனவை, இதுவரை கையாளப்பட்ட வினைச்சொற்களுக்கு எதிராக, ஒரு வினைமூலத்திலிருந்து அல்லாமல், ஒரு பெயர்மூலத்திலிருந்து உருவாக்கப்படுகின்றன. இதில் பல்வேறு உருவாக்க வகைகள் உள்ளன.

### 61.4.1. சிறப்புச் சார்பில்லாத கல்வி, பரமஸ்பதம்

::: grammar-box
**பொருள்:**

:::
::: indent
**ஒரு நபர் அல்லது பொருள், பெயர் மூலத்தால் குறிக்கப்படும் அதே போல செயல்படுகிறது அல்லது ஒத்துப்போகிறது.**
:::
**இலக்கணம்:**

::: indent
**வருகைத் தனிமையில் முதல் வருகை வகை வினையின் போல (⟪भ्वादिगण⟫). பெயர்ச்சொல் மாவை ஒலியாகக் கொண்டிருந்தால், கடைசி ஒலி முதல் வகையின் மூலஒலியாகவே கருதப்படும். கடைசியில் -a முடிவது துணைஒலிக்கு முன் நீங்கும். கடைசி நேர்மொழிக்கு முன் உள்ள ஒலி அதற்குரிய நீண்டஒலியால் மாற்றப்படும்.**
:::

## 61.6. Der Konditionalis (⟪ऌङ्⟫)

::: grammar-box
**நிபந்தனை விசேஷணம் (⟪ऌङ्⟫) என்பது, நிபந்தனை வாக்கியங்களில், நிபந்தனையாகக் குறிப்பிடப்படுவது நிலை அல்ல / இருந்திருக்கவில்லை / இருக்கும் என்று வெளிப்படுத்த விரும்பும் போது பயன்படுத்தப்படுகிறது. அத்தகைய வாக்கியங்களில், நிபந்தனை வாக்கியத்திலும் முக்கிய வாக்கியத்திலும் நிபந்தனை விசேஷணம் பயன்படுத்தப்பட வேண்டும்.**

## 61.9. Entlassung in den Ozean der Sanskritliteratur: ಶ್ರೀಗಣನಾಥ / ⟪श्रीगणनाथ⟫
