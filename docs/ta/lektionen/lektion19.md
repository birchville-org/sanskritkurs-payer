# பாடம் 19

## 19.1. சார்பு வாக்கியம்

::: grammar-box

**அமைப்பு:**

**சார்பு உரிச்சொல் -- சார்பு வாக்கியம், அது பெயர்ச்சொல் அடங்கிய, சார்பு வாக்கியம் தொடர்புடைய -- (நினைவு உரிச்சொல்) -- முக்கிய வாக்கியம்**

**சார்பு வாக்கியம் முக்கிய வாக்கியத்திற்குப் பிறகு இருக்கலாம், ஆனால் அது முக்கிய வாக்கியத்திற்குள் செருகப்பட முடியாது.**

**சார்பு உரிச்சொல்லும் தொடர்புச் சொல்லும், அது ஜெர்மன் மொழியுடன் வேறுபாட்டாக, சார்பு வாக்கியத்தில் இருக்கும், சார்பு வாக்கியம் சூடோலாகி தேவையான கசஸில் இருக்கும். நினைவு உரிச்சொல் முக்கிய வாக்கியம் சூடோலாகி தேவையான கசஸில் இருக்கும்.**
:::

உதாரணங்கள்:

குறிப்பு: பொதுவான உள்ளடக்கம் கொண்ட சார்பு வாக்கியங்களில், இண்டிகேட்டிவிற்குப் பதிலாக ஆப்டேட்டிவ் பயன்படுத்தப்படுவது வழக்கம். எனவே, எங்கள் பல உதாரணங்கள் ஆப்டேட்டிவில் இருக்கும்.

**1. வாக்கியத்தின் காரணம் (⟪कर्तृ⟫) சார்பு வாக்கியத்தால் மேலும் குறிப்பிடப்படுகிறது:**

::: indent
⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪स⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫ =  ⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ = ⟪येन⟫ ⟪नरेण⟫ ⟪पुण्यम्⟫ ⟪क्रियते⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ மற்றும் பல = "நன்மை செய்பவன் சொர்க்கம் செல்கிறான்."
:::
**2. முக்கிய வாக்கியத்தின் நேரடி பொருள் (⟪कर्म⟫) சார்பு வாக்கியத்தால் மேலும் குறிப்பிடப்படுகிறது:**

::: indent
⟪यो⟫ ⟪ब्राह्मणो⟫ ⟪देवान्यजते⟫ ⟪तं⟫ ⟪देवा⟫ ⟪रक्षन्ति⟫ = "தெய்வங்கள் அவர்களுக்கு பலி கொடுக்கும் பிராமணனைக் காக்கின்றன."
:::
**3. முக்கிய வாக்கியத்தின் பெயர்ச்சொல்லின் மேலதிக குறிப்பு சார்பு வாக்கியத்தில் உள்ளது:**

::: indent
⟪ये⟫ ⟪नराः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪तेषां⟫ ⟪पुत्रा⟫ ⟪धनं⟫ ⟪न⟫ ⟪लभन्ते⟫ = "நன்மை செய்பவர்களின் மகன்கள் செல்வத்தைப் பெற மாட்டார்கள்."
:::
**4. சார்பு உரிச்சொல்லும் தொடர்புச் சொல்லும் ஜெனிட்டிவ் (⟪षष्ठी⟫)ில் உள்ளன:**

::: indent
⟪यस्य⟫ ⟪नरस्य⟫ ⟪पुत्राः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪स⟫ ⟪न⟫ ⟪सुखवान्⟫ = "தனது மகன்கள் நன்மை செய்பவன் மகிழ்ச்சியற்றவன்."
:::
**5. சார்பு உரிச்சொல்லும் தொடர்புச் சொல்லும் இன்ஸ்ட்ருமெண்டலிஸ் (⟪तृतीया⟫)ில் உள்ளன:**

::: indent
⟪येन⟫ ⟪शत्रुणा⟫ ⟪ग्रामो⟫ ⟪जितस्तं⟫ ⟪द्विषन्ति⟫ = "அவர்கள் தங்கள் கிராமத்தை வென்ற/கைப்பற்றிய எதிரியை வெறுக்கின்றனர்."
:::
**6. சார்பு உரிச்சொல்லும் தொடர்புச் சொல்லும் ஆக்கூசேட்டிவ் (⟪द्वितीया⟫)ில் உள்ளன:**

::: indent
⟪यं⟫ ⟪नरं⟫ ⟪देवी⟫ ⟪रक्षति⟫ ⟪स⟫ ⟪सुखमाप्नोति⟫ = "தெய்வம் காக்கும் மனிதன் செல்வம் பெறுகிறான்."
:::

## 19.3. சொல்லியல்

**⟪अर्थ⟫ ஆண.:** நோக்கம், இலக்கு, பொருள் (ஒரு சொல்லின்), செல்வம், சொத்து, வசதி. ⟪अर्थम्⟫ (அக்கு.), ⟪अर्थेन⟫ (இன்ஸ்ட்ரு.) ஜென. அல்லது பின் உறுப்பாக ஒரு தத்புருஷ: கலிப்பெயரில்: ... க்காக, ... வுக்காக.

⟪अर्थ⟫ என்பது மூன்று வாழ்க்கை நோக்கங்களில் (⟪पुरुषार्थ⟫) ஒன்றாகும், அவை பௌதீக மற்றும் மத இலக்கியங்களில் விவரிக்கப்படுகின்றன:

::: indent
**⟪धर्म⟫ ஆண.:** நேர்மையான செயல்களின் மூலம் புண்ணியத்தைப் பெறுதல், அல்லது குறைவாகவாவது தர்மத்தின் கட்டளைகளைப் பின்பற்றாமைக்கு ஏற்படும் தீங்குகளைத் தவிர்த்தல்.

**⟪अर्थ⟫ ஆண.:** நோக்கமுள்ள நடத்தை, செல்வத்தைப் பெறுதல்.

**⟪काम⟫ ஆண.:** காமம், குறிப்பாக பாலியல் துறையிலும்.
:::

**⟪स्था⟫ + ⟪प्र⟫ 1 ஆ ⟪प्रतिष्ठते⟫ :** புறப்படுதல், செல்வது.

:::

## 19.4. பயிற்சி

**சமஸ்கிருதத்திற்கு மொழிபெயர்க்கவும்:**

1\. தன் மகன் இறந்த வைசியப் பெண் அழுகிறாள்.

2\. ராமன் அவனைக் காக்கும் தெய்வத்திற்கு அர்ச்சனை செய்கிறான்.

3\. கவிஞன் தன் செல்வத்தை விரும்பும் க்ஷத்திரியனைப் பாராட்டுகிறான்.

4\. அக்னியை அர்ச்சனை செய்யாத ஆணின் வீட்டைத் தீ எரிக்கிறது.

5\. புலியைப் போன்ற ஆண் ராமனைத் தோற்கடித்த க்ஷத்திரியப் போர்வீரர்களைக் கொல்கிறான் (செய்யுள்).
