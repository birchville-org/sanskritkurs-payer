# பாடம் 19

## 19.1. தொடர்பு வாக்கியம்

:::: grammar-box

**வடிவமைப்பு:**

::: indent
**தொடர்பு உரிச்சொல் -- தொடர்பு வாக்கியம், அது பெயர்ச்சொல் அடங்கிய பெயர்ச்சொல், தொடர்பு வாக்கியம் தொடர்பு கொள்ளும் -- (நிர்ணய உரிச்சொல்) -- முக்கிய வாக்கியம்**
:::

**தொடர்பு வாக்கியம் முக்கிய வாக்கியத்திற்குப் பிறகு இருக்கலாம், ஆனால் அது முக்கிய வாக்கியத்திற்குள் செருகப்பட முடியாது.**

**தொடர்பு உரிச்சொல் மற்றும் தொடர்பு சொல், அது ஜெர்மனியில் இருந்து வேறுபாடு, தொடர்பு வாக்கியத்தில் இருக்கிறது, அது தொடர்பு வாக்கியம் வியக்கப்படுகிறது கசஸ், அது முக்கிய வாக்கியம் வியக்கப்படுகிறது கசஸ். நிர்ணய உரிச்சொல் அது முக்கிய வாக்கியம் வியக்கப்படுகிறது கசஸ்.**

::::

உதாரணங்கள்:

குறிப்பு: பொதுவான உள்ளடக்கம் கொண்ட தொடர்புகளில், அடையாளம் பதிலாக அடையாளம் பயன்படுத்தப்படுகிறது. எனவே எங்கள் எடுத்துக்காட்டுகளின் பெரும்பாலானவை அடையாளத்தில் இருக்க விரும்புவார்கள்.

**1. வாக்கியத்தின் காரணம் (कर्तृ) தொடர்பு வாக்கியால் மிகவும் குறிப்பிடப்படுகிறது:**

::: indent
यो नरः पुण्यं करोति स स्वर्गं गच्छति =  यो नरः पुण्यं करोति तेन स्वर्गं गम्यते = येन नरेण पुण्यम् क्रियते तेन स्वर्गं गम्यते மற்றும் பல = "நன்மை செய்பவன் கவனிக்கப்படுகிறான், அவன் கவனிக்கப்படுகிறான்."
:::

**2. முக்கிய வாக்கியத்தின் நேரடி பொருள் (कर्म) தொடர்பு வாக்கியால் மிகவும் குறிப்பிடப்படுகிறது:**

::: indent
यो ब्राह्मणो देवान्यजते तं देवा रक्षन्ति = "கடவுள்கள் ஒரு பிராமணனைக் காக்கிறார்கள், அவர்கள் அவருக்கு பலி கொடுக்கிறார்."
:::

**3. முக்கிய வாக்கியத்தின் பெயர்ச்சொல்லின் மிகவும் குறிப்பிடப்பட்டது தொடர்பு வாக்கியத்தில் உள்ளது:**

::: indent
ये नराः पापं कुर्वन्ति तेषां पुत्रा धनं न लभन्ते = "மக்களின் மக்கள், அவர்கள் கெட்ட செயல் செய்கிறார்கள், செல்வம் பெறவில்லை."
:::

**4. தொடர்பு உரிச்சொல் மற்றும் தொடர்பு சொல் ஜெனிட்டிவ் (षष्ठी) இல் உள்ளன:**

::: indent
यस्य नरस्य पुत्राः पापं कुर्वन्ति स न सुखवान् = "மக்கள் மக்கள் கெட்ட செயல் செய்கிறார்கள், அவர் மகிழ்ச்சியாக இல்லை."
:::

**5. தொடர்பு உரிச்சொல் மற்றும் தொடர்பு சொல் இன்ஸ்ட்ருமென்டலிஸ் (तृतीया) இல் உள்ளன:**

::: indent
येन शत्रुणा ग्रामो जितस्तं द्विषन्ति = "அவர்கள் எதிரியை வெறுக்கிறார்கள், அவர் அவர்களின் கிராமத்தை வென்றார் / கைப்பற்றினார்."
:::

**6. தொடர்பு உரிச்சொல் மற்றும் தொடர்பு சொல் அக்கூசேடிவ் (द्वितीया) இல் உள்ளன:**

::: indent
यं नरं देवी रक्षति स सुखमाप्नोति = "ஒரு மனிதன், அவளைக் கடவுள் காக்கிறான், அவன் மகிழ்ச்சி பெறுகிறான்."
:::

## 19.3. சொற்பட்டியல்

**अर्थ ஆண்பால்:** நோக்கம், இலக்கு, பொருள் (ஒரு சொல்லின்), செல்வம், சொத்து, வசதி. **अर्थम्** (பொருள்), **अर्थेन** (கருவி) பெயர்ச்சொல் அல்லது தத்புருஷாவின் பின்னங்கூறாக: ... காரணமாக, ... வசம்.

**अर्थ** என்பது மூன்று வாழ்க்கை நோக்கங்களில் (**पुरुषार्थ**) ஒன்றாகும், அவை பௌத்த மற்றும் மத இலக்கியங்களில் விவரிக்கப்படுகின்றன:

::: indent
**धर्म ஆண்பால்:** நன்மை செய்வதன் மூலம் புண்ணியத்தைப் பெறுதல், அல்லது குறைவாகவாவது தர்மத்தின் கட்டளைகளைப் பின்பற்றாமல் வரும் தீமைகளைத் தவிர்த்தல்

**अर्थ ஆண்பால்:** நோக்கமுள்ள நடத்தை, செல்வத்தைப் பெறுதல்

**काम ஆண்பால்:** காமம், குறிப்பாக பாலியல் துறையில்
:::

**स्था 2 ஆ.ப. तिष्ठति வினையெச்சம் स्थीयते முற்றெச்சம் स्थित :** நிற்பது, நிலைத்திருத்தல், தொடர்ந்து இருத்தல், அமைத்திருத்தல். (பாரம்பரியமாக முதல் இலக்கண வகுப்பில் அடங்கும், இருப்பினும் இது ஒரு மீண்டும் வரும் தீமை இலக்கண வகுப்பாகும், पा 1 पिबति போல)

**स्था + उप 1 உ. उपतिष्ठति :** முன்னேறி வருதல், ஒருவருக்கு முன் மரியாதையுடன் நிற்பது

**स्था + प्र 1 ஆ. प्रतिष्ठते :** புறப்படுதல், செல்வது

**स्था** இலிருந்து:

::: indent
**स्थान நடுப்பால்:** இடம், (சரியான) இடம், நிலை

**स्थिति பெண்பால்:** தங்குதல், நிலைத்தன்மை, நிலைப்பு
:::

**गर्भ ஆண்பால்:** கருப்பை, வயிறு, உட்பகுதி, கரு / குழந்தை. ஒரு பஹுவிரிஹியின் முடிவில் பெரும்பாலும்: "உட்பகுதி", எ.கா.

::: indent
**धनगर्भ 3:** "அதன் உட்பகுதி பணம் = பணம் அமைந்திருக்கும் இடம்"

## 19.4. பயிற்சி

**சமஸ்கிருதத்திற்கு மொழிபெயர்க்கவும்:**

1\. தன் மகன் இறந்த வைசியப் பெண் அழுகிறான்.

2\. ராமன் அவனைக் காக்கும் தெய்வத்திற்கு அர்ச்சனை செய்கிறான்.

3\. கவிஞன் தன் செல்வத்தை விரும்பும் க்ஷத்திரியனைப் பாராட்டுகிறான்.

4\. அக்னியை அர்ச்சனை செய்யாத ஆணின் வீட்டைத் தீ எரிக்கிறது.

5\. ராமனைத் தோற்கடித்த க்ஷத்திரியப் போர்வீரர்களைப் புலிபோன்ற ஆள் கொல்லுகிறான் (செய்யுள்).
