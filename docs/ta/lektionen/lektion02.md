# பாடம் 2

## 2.1. பெயர்ச்சொல் வாக்கியம்

::: grammar-box
**வார்ப்புரு: வினைச்சொல்லற்ற பெயர் - பொருள்**

எ.கா. devo viṣṇuḥ = ⟪देवो⟫ ⟪विष्णुः⟫ = "விஷ்ணு ஒரு கடவுள்."
:::
ஒரு வினைச்சொல்லான இணைப்பு ("ஆகும்", "ஆகின்றனர்", "நான் ஆகிறேன்", "நீ ஆகிறாய்", "நீங்கள் ஆகிறீர்கள்" என்று பொருள்படும்) தேவையில்லை, ஆனால் சில நேரங்களில் தோன்றலாம்.

**உரிச்சொற்கள் எதுவும் இல்லை**: **devaḥ** -- ⟪देवः⟫ "கடவுள்" அல்லது "ஒரு கடவுள்" என்று பொருள்படுத்தலாம்.

சமசுகிருதத்தில் வாக்கிய அமைப்பு மிகவும் சுதந்திரமானதாக இருந்தாலும் (குறிப்பாக கவிதைகளில்), ஒரு பெயர் வாக்கியத்தை மொழிபெயர்க்கும் போது, எப்போதும் மேலே உள்ள தரநிலை வார்ப்புருவின் அடிப்படையில் ஒரு மொழிபெயர்ப்பை முதலில் கருத்தில் கொள்ள வேண்டும்.

பெயர் வாக்கியத்தில், பொருள் பெயர்ச்சொல் விகாரத்தில் (முதல் விகாரம் = **prathamā** f. = ⟪प्रथमा⟫) இருக்கும். வினைச்சொல்லற்ற பெயர், பொருளுடன் எண்ணிக்கை மற்றும் விகாரத்தில் ஒத்துப்போகும்; வினைச்சொல்லற்ற பெயர் ஒரு உரிச்சொல்லாக இருந்தால், பாலத்திலும் ஒத்துப்போகும்.

## 2.2. வேற்றுமை உருபுகள் பற்றி (பெயர்ச்சொற்களின் வளைவு)

சமஸ்கிருதத்தில் உள்ளது:

- **மூன்று எண்ணமைப்புகள்** (எண்ணுருவங்கள்) = **vacana** n. -- ⟪वचन⟫
  - ஒருமை (ஒற்றை எண்) = **ekavacana** n. -- ⟪एकवचन⟫
  - இரட்டை (இரட்டை எண்) = **dvivacana** n. -- ⟪द्विवचन⟫
  - பலர் (பன்மை) = **bahuvacana** n. -- ⟪बहुवचन⟫
- **மூன்று பால்** (பாலியல் பண்புகள்) = **liṅga** n. / **vyakti** f. -- ⟪लिङ्ग⟫ / ⟪व्यक्ति⟫
  - ஆண்பால் (ஆண்) = **puṃs** m. -- ⟪पुंस्⟫
  - பெண்பால் (பெண்) = **strī** f. -- ⟪स्त्री⟫
  - நடுப்பால் (பால் இல்லாதது) = **napuṃsaka** n. -- ⟪नपुंसक⟫
- **எட்டு விகாரங்கள்** (நிலைகள்) = **sup** -- ⟪सुप्⟫ (= விகார முடிபுகள்)

விகாரத்திற்கு விகார முடிபுகள் (**sup** = ⟪सुप्⟫) **பெயர் மூலத்திற்கு** (Form des Nomens ohne Kasusendungen) இணைகின்றன.

உதாரணம்: **devas** = ⟪देवस्⟫ (நியமித்த ஒருமை ஆண்பால்) "தேவன்/ஒரு தேவன்" = **deva-** -- ⟪देव⟫- (பெயர் மூலம்) + **-s** -- -⟪स्⟫ (விகார முடிபு).

சமஸ்கிருத அகராதி பெயர்ச்சொற்களை **பெயர் மூலத்தில்** கொடுக்கிறது:
- **deva** m. -- ⟪देव⟫ m. (ஆண்பால்)
- **vacana** n. -- ⟪वचन⟫ n. (நடுப்பால்)
- **vyakti** f. -- ⟪व्यक्ति⟫ f. (பெண்பால்)

## 2.3. எழுவாய் ஒருமை

**பெயர்ச்சொல் ஒருமை = prathamā ekavacanam = ⟪प्रथमा⟫ ⟪एकवचनम्⟫**

::: grammar-box
**பெயர்ச்சொல் ஒருமை -s = -⟪स्⟫ அல்லது முடிச்சொல் இல்லாமல் இருக்கும்.**
:::
### 2.3.1. -s இல் நாமினேட்டிவ் ஒருமை

**பெயர்ச்சொல் ஒருமை -s = -⟪स्⟫ அல்லது முடிச்சொல் இல்லாமல் இருக்கும்.**

::: grammar-box
**-a** இறுதிச்சீர் கொண்ட பால்பெயர்ச்சொற்கள்: எ.கா. deva ஆண். = ⟪देव⟫ "தெய்வம்" -- பெயர்ச்சீர் ஒருமை: devas = ⟪देवस्⟫
**-i** இறுதிச்சீர் கொண்ட பால்பெயர்ச்சொற்கள்: எ.கா. kavi ஆண். = ⟪कवि⟫ "கவிஞர்" -- பெயர்ச்சீர் ஒருமை: kavis = ⟪कविस्⟫
**-u** இறுதிச்சீர் கொண்ட பால்பெயர்ச்சொற்கள்: எ.கா. guru ஆண். = ⟪गुरु⟫ "ஆசிரியர்" -- பெயர்ச்சீர் ஒருமை: gurus = ⟪गुरुस्⟫
:::

## 2.4. சந்தி -- ⟪सन्धि⟫

சமஸ்கிருதத்தில் ஒரு சொல்லின் இறுதி ஒலி, அதைத் தொடர்ந்து வரும் சொல்லின் தொடக்க ஒலியைப் பொறுத்தே அமைகிறது. இந்த நிகழ்வை **சந்தி** (m.) = ⟪सन्धि⟫ ("இணைப்பு") என்று அழைக்கிறோம்.

### 2.4.1. முடிவுறும் -s இன் சந்தி

மேலும் பின்வரும் மதிப்பாய்வையும் காண்க:

> **பேயர், அலோயிஸ் \<1944 - \>:** வெளிப்படும் -s இன் சந்தி. -- (சமஸ்கிருதப் பொருட்கள்). -- URL: http://www.payer.de/sanskritmaterialien/ssandhi.htm

இறுதியில் வரும் **-s**:

- **இறுதியில்** (வாக்கிய முடிவு) இது **விசர்கா (-ḥ)** ஆக மாறுகிறது:
  - **devas** = ⟪देवस्⟫ » **devaḥ** = ⟪देवः⟫
  - **kavis** = ⟪कविस्⟫ » **kaviḥ** = ⟪कविः⟫
  - **gurus** = ⟪गुरुस्⟫ » **guruḥ** = ⟪गुरुः⟫

- **ஒலிப்பில்லாத ஒலிகளுக்கு முன்**:
  - **k, kh, p, ph** மற்றும் **ś, ṣ, s** க்கு முன்: **Visarga (-ḥ)** ஆக மாறுகிறது
    - **devas + śivaḥ** » **devaḥ śivaḥ** = ⟪देवः⟫ ⟪शिवः⟫ ("சிவன் ஒரு கடவுள்")
  - **c, ch** க்கு முன்: **-ś** ஆக மாறுகிறது
  - **ṭ, ṭh** க்கு முன்: **-ṣ** ஆக மாறுகிறது
  - **t, th** க்கு முன்: **-s** ஆகவே இருக்கும்
    - **sādhus + caitanyas** » **sādhuś caitanyaḥ** = ⟪साधुश्चैतन्यः⟫ ("சைதன்யா ஒரு புனிதர்")

- **ஒலிப்பு மொழிபெயர்ப்பு**:
  - அல்லாத a-ஒலிப்புக்குப் பின்: **-r** ஆக மாறுகிறது
    - **kavis + Māghas** » **kavir māghaḥ** = ⟪कविर्माघः⟫ ("மாகா ஒரு கவிஞர்")
  - அல்லாத a-ஒலிப்புக்குப் பின் **r-** முன்: **-s** நீக்கப்படுகிறது, ஒலிப்பு நீட்டப்படுகிறது.
    - **gurus + rāmas** » **gurū rāmaḥ** = ⟪गुरू⟫ ⟪रामः⟫ ("ராமா ஒரு ஆசிரியர்")
  - **a-** பின்: **-as**
    - ஒலிப்பு மொழிபெயர்ப்பு/முன்: **-o** ஆக மாறுகிறது (முன்னொலி a நீக்கப்படுகிறது » ⟪ऽ⟫)
      - **devas viṣṇus** » **devo viṣṇuḥ** = ⟪देवो⟫ ⟪विष्णुः⟫
      - **devas agnis** » **devo 'gniḥ** = ⟪देवो⟫ ⟪ऽग्निः⟫
    - பிற ஒலிப்புக்கு முன்: **-a** ஆக மாறுகிறது (ஹியாட்டஸ்)
      - **devas + indras** » **deva indraḥ** = ⟪देव⟫ ⟪इन्द्रः⟫

## 2.5. சொற்களஞ்சியம்

**deva** p. -- ⟪देव⟫ : வானவன், கடவுள்; அரசன், மன்னன்.

**īśvara** p. -- ⟪ईश्वर⟫ : கர்த்தர், ஆட்சியாளர், கடவுள் (ஒருமைக் கொள்கை).

**brāhmaṇa** p. -- ⟪ब्राह्मण⟫ : பிராமணர் (ஆன்மீக வகுப்பு).

**kṣatriya** p. -- ⟪क्षत्रिय⟫ : க்ஷத்திரியர் (அரசர் மற்றும் போர்வகுப்பு).

**vaiśya** p. -- ⟪वैश्य⟫ : வைசியர் (உற்பத்தி மற்றும் வணிக வகுப்பு).

**śūdra** p. -- ⟪शूद्र⟫ : சூத்திரர் (சேவை வகுப்பு).

::: note-box Die vier Stände (varna)

சாத்திரப்படி (எ.கா. மனுசம்ஹிதை I, 88-91) பணிகள் பின்வருமாறு பிரிக்கப்பட்டுள்ளன:

- **பிராமணர்களின்**
  - வேதம் படித்தல்
  - கற்பித்தல்
  - தங்களுக்காக அர்ச்சனை செய்தல்
  - பிறருக்காக அர்ச்சனை செய்தல்
  - கொடுத்தல்
  - அன்பளிப்புகளைப் பெறுதல்
- **க்ஷத்திரியர்களின்**
  - மக்களைக் காத்தல்
  - அன்பளிப்புகளைக் (பிராமணர்களுக்கு) கொடுத்தல்
  - தங்களுக்காக அர்ச்சனை செய்தல்
  - வேதம் படித்தல்
- **வைசியர்களின்**
  - விலங்கு வளர்ப்பு
  - வேளாண்மை
  - வணிகம்
  - பணக் கடன் கொடுத்தல்
  - தங்களுக்காக அர்ச்சனை செய்தல்

  - தங்களுக்காக அர்ச்சனை செய்தல்
  - வேதம் படித்தல்
- **சூத்திரர்களின்**
  - மேல் மூன்று வகுப்பினருக்குச் சேவை செய்தல்
:::
**dvija** p. -- ⟪द्विज⟫ : "இரண்டுமுறை பிறந்தவர்" (மேல் மூன்று வகுப்பினரின் ஆரம்பநிலை: பிராமணர், க்ஷத்திரியர், வைசியர்).

**varṇa** p. -- ⟪वर्ण⟫ : நிறம், பிறப்பு வகுப்பு (நோக்கம்).

நான்கு வகுப்புகள் (**varṇa** p.) பெரும்பாலும் ஜாதி என்று தவறாகக் கருதப்படுகின்றன. ஆனால் நான்கு வகுப்புகள் -- ஜாதிகளுக்கு எதிராக -- இந்தியாவைச் சார்ந்தது அல்ல; ஐரோப்பாவிலும் நாம் (பகுதியாக முதல் உலகப் போர் வரை) வகுப்பு அமைப்பு இருந்தது, பின்வரும் 15-ஆம் நூற்றாண்டுப் புகைப்படம் நிரூபிக்கிறது:

**படக்குறிப்பு:**
- **யாத்திரிகர் வகுப்பு** (~பிராமணர்): Tu supplex ora = நீ வேண்டுகோள் விடு!
- **அரசர் வகுப்பு** (~க்ஷத்திரியர்): Tu protege = நீ காப்பாய்!
- **உழவர் வகுப்பு** (~வைசியர்/சூத்திரர்): Tuque labora = மற்றும் நீ வேலை செய்!

மூன்று வகுப்பினரும் தத்தமது வகுப்பு ஆடை அணிவர். கடவுள் விருப்பமான வகுப்புகளுக்கு மேல் கிறிஸ்து ஆட்சி புரிகிறார்.

மக்ஸ் வேபர் \<1864 – 1920\> வகுப்பை இவ்வாறு வரையறுக்கிறார்:

::: note-box
note-box
»**வகுப்பு**« என்பது ஒரு கூட்டத்தின் மக்கள், ஒரு அமைப்பிற்குள் செயல்படுவது
a) ஒரு வகுப்புச் சிறப்பு மதிப்பு, - சாத்தியமாக
b) வகுப்புச் சிறப்பு ஏகபோகங்களைக் கைப்பற்றுகிறது.

வகுப்புகள் உருவாகலாம்
a) முதன்மையாக, தனிப்பட்ட வகுப்பு வாழ்க்கை முறையால், குறிப்பாக **தொழில்** (**வாழ்க்கை முறை அல்லது தொழில் வகுப்புகள்**),
b) இரண்டாவதாக, பாரம்பரிய குணத்தால், வெற்றிகரமான மதிப்புக் கோரிக்கைகளால் வகுப்பு **பிறப்பு** (**பிறப்பு வகுப்புகள்**),
c) வகுப்பு **அதிகாரம்** அரசர் அல்லது ஆட்சியாளர் அதிகாரங்களை ஏகபோகமாகக் கைப்பற்றுவது (**அரசியல் அல்லது ஆட்சியாளர் வகுப்புகள்**).

பிறப்பு வகுப்பு வளர்ச்சி என்பது பொதுவாக (பாரம்பரிய) ஏகபோகத்தின் வடிவம், ஒரு அமைப்பு அல்லது தகுதி வாய்ந்த தனிநபர்களுக்கு. வாய்ப்புகளின் நிலையான ஏகபோகம், குறிப்பாக [அரசர்] [அதிகாரங்கள் அல்லது வருவாய்] வாய்ப்புகள், வகுப்பு உருவாக்கத்திற்கு வழிவகுக்கும். ஒவ்வொரு வகுப்பு உருவாக்கமும் அரசர் அதிகாரங்கள் மற்றும் வருவாய் வாய்ப்புகளின் ஏகபோக அமைப்புக்கு வழிவகுக்கும்.

வணிக அடிப்படையிலான பொருளாதாரத்தின் அடிப்படையில் வர்க்கங்கள் வளரும் போது, குடியேற்ற அல்லது கீழ்நிலை அல்லது வர்க்கப் பாரம்பரிய தேவைகளைப் பூர்த்தி செய்யும் கூட்டுறவுகளின் அடிப்படையில் நிலைகள் ஏற்படுகின்றன மற்றும் நிலைநிறுத்தப்படுகின்றன.

»**நிலை**« என்பது ஒரு சமூகம் நிலைகளின் அடிப்படையில் சமூக பிரிவினைக்கு உட்படுவதாகவும், »**வர்க்க**« என்பது அது வர்க்கங்களின் அடிப்படையில் நடக்கிறது என்றும் குறிக்கிறது. »நிலை«க்கு »வர்க்க«களிலிருந்து »சமூக« வர்க்கம் மிக அருகில் உள்ளது, »வணிக வர்க்கம்« மிகவும் தொலைவில் உள்ளது. நிலைகள் பெரும்பாலும் சொத்து வர்க்கங்களால் உருவாக்கப்படுகின்றன.

ஒவ்வொரு நிலை சமூகமும் பாரம்பரியமானது, வாழ்க்கை நடத்தையின் விதிகளால் வரிசைப்படுத்தப்பட்டது, எனவே பொருளாதார ரீதியாக அநீதியான நுகர்வு நிபந்தனைகளை உருவாக்குகிறது மற்றும் சுதந்திரமான சந்தை வளர்ச்சியைத் தடுக்கிறது.

## 2.6. பயிற்சி

**அ) சந்தியைக் கவனத்தில் கொண்டு எழுதுங்கள் மற்றும் பெயர்ச்சொல் வாக்கியங்களை உருவாக்குங்கள்:**

1. **தேவர்கள் ... (சிவ, அக்னி, விஷ்ணு, கணேச, கிருஷ்ண, இந்திர)**
   = ⟪देवस्⟫ ... (⟪शिव⟫, ⟪अग्नि⟫, ⟪विष्णु⟫, ⟪गणेश⟫, ⟪कृष्ण⟫, ⟪इन्द्र⟫)
2. **இரட்டைப் பிறப்புடையோர் ... (பிராமண, க்ஷத்திரிய, வைசிய)**
   = ⟪द्विजस्⟫ ... (⟪ब्राह्मण⟫, ⟪क्षत्रिय⟫, ⟪वैश्य⟫)
3. **குருக்கள் ... (பிராமண, சந்திரகீர்த்தி)**
   = ⟪गुरुस्⟫ ... (⟪ब्राह्मण⟫, ⟪चन्द्रकीर्ति⟫)
4. **வைசியர்கள் ... (துலாதர)**
   = ⟪वैश्यस्⟫ ... (⟪तुलाधर⟫)
5. **சாதுக்கள் ... (குரு, ராம)**
   = ⟪साधुस्⟫ ... (⟪गुरु⟫, ⟪राम⟫)
6. **கவிகள் ... (காளிதாச, மாঘ, பாரவி, ஹர்ஷதேவ)**
   = ⟪कविस्⟫ ... (⟪कालिदास⟫, ⟪माघ⟫, ⟪भारवि⟫, ⟪हर्षदेव⟫)

**ஆ) சமஸ்கிருதத்திற்கு மொழிபெயர்க்கவும்:**

1. ராமர் ஒரு பிராமணர்.

3. சூத்திரர் ஒரு புனித ஆண்.
4. கவிஞர் ஆசிரியர்.
5. விஷ்ணு ஆண்டவன்.
6. ஆண்டவன் சிவன்.
7. இரட்டைப் பிறப்புடையவர் ஒரு பிராமணர்.
8. புனித ஆண் ஒரு ஆசிரியர்.
9. ஆசிரியர் ஒரு புனித ஆண்.
