# பாடம் 2


## 2.1. பெயர்ச்சொல் வாக்கியம்

::: grammar-box
**அமைப்பு: இலக்கணப் பெயர் - வினைச்சொல்**

எ.கா., devo viṣṇuḥ = ⟪देवो विष्णुः⟫ = "விஷ்ணு ஒரு கடவுள்."
:::
வினைச்சொல் இணைப்பு ("ஆகும்", "ஆவர்", "நான் ஆகிறேன்", "நீ ஆகிறாய்", "நீங்கள் ஆகிறீர்கள்") தேவையில்லை, ஆனால் சில நேரங்களில் இருக்கலாம்.

**கட்டுப்பாடுகள் இல்லை**: **devaḥ** -- ⟪देवः⟫ "கடவுள்" அல்லது "ஒரு கடவுள்" என்று பொருள்படுத்தலாம்.

சமஸ்கிருதத்தில் வாக்கிய அமைப்பு மிகவும் சுதந்திரமாக இருப்பினும் (குறிப்பாக பாடல்களில்), பெயர்ச்சொல் வாக்கியத்தை மொழிபெயர்க்கும்போது எப்போதும் மேலே உள்ள நிலையான அமைப்புக்கு ஏற்ப மொழிபெயர்ப்பை முதலில் கருத்தில் கொள்ள வேண்டும்.

பெயர்ச்சொல் வாக்கியத்தில், வினைச்சொல் நேரடியாக (முதல் வார்ப்பு = **prathamā** f. = ⟪प्रथमा⟫). இலக்கணப் பெயர் வினைச்சொல்லின் எண்ணிக்கை மற்றும் வார்ப்புடன் ஒத்துப்போகும்; இலக்கணப் பெயர் ஒரு பண்புச்சொல்லாக இருந்தால், இனத்திலும் ஒத்துப்போகும்.


## 2.2. இலக்கணம் (பெயர்ச்சொல் வார்ப்பு) பற்றி

சமஸ்கிருதத்தில் உள்ளது:

**மூன்று எண்ணிக்கைகள்** (எண்ணும் வடிவங்கள்) = **vacana** n. -- ⟪वचन⟫
ஒருமை (ஒற்றை எண்ணிக்கை) = **ekavacana** n. -- ⟪एकवचन⟫
இருமை (இரட்டை எண்ணிக்கை) = **dvivacana** n. -- ⟪द्विवचन⟫
பலமை (பல எண்ணிக்கை) = **bahuvacana** n. -- ⟪बहुवचन⟫
**மூன்று இனங்கள்** (இலக்கண இனங்கள்) = **liṅga** n. / **vyakti** f. -- ⟪लिङ्ग⟫ / ⟪व्यक्ति⟫
ஆண்பால் (ஆண்) = **puṃs** m. -- ⟪पुंस्⟫
பெண்பால் (பெண்) = **strī** f. -- ⟪स्त्री⟫
நடுப்பால் (நடு) = **napuṃsaka** n. -- ⟪नपुंसक⟫
**எட்டு வார்ப்புகள்** (வார்ப்பு) = **sup** -- ⟪सुप्⟫ (= வார்ப்பு முடிப்புகள்)

இலக்கணத்திற்கு வார்ப்பு முடிப்புகள் (**sup** = ⟪सुप्⟫) அழைக்கப்படும் **பெயர்ச்சொல் வார்ப்பு** (வார்ப்பு முடிப்புகள் இல்லாத பெயர்ச்சொல் வடிவம்) சேர்க்கப்படும்.

உதாரணம்: **devas** = ⟪देवस्⟫ (பெயரடை ஒருமை ஆண்பால்) "கடவுள்/ஒரு கடவுள்" = **deva-** -- ⟪देव⟫- (பெயர் மூலம்) + **-s** -- -⟪स्⟫ (விபக்க முடிப்பு).

சமஸ்கிருத அகராதிகளில் பெயர்ச்சொற்கள் **பெயர் மூலத்தில்** (Nominalstamm) கொடுக்கப்படுகின்றன:
**deva** ஆ. -- ⟪देव⟩ ஆ. (ஆண்பால்)
**vacana** நடு. -- ⟪वचन⟩ நடு. (நடுவினையால்)
**vyakti** பெ. -- ⟪व्यक्ति⟩ பெ. (பெண்பால்)


## 2.3. ஒருமை ஆய்வுப்பெயர் (Nominativ Singular)

**ஆய்வுப்பெயர் ஒருமை = prathamā ekavacanam = ⟪प्रथमा एकवचनम्⟫**

::: grammar-box
**ஆய்வுப்பெயர் ஒருமை -s = -⟪स्⟩ என முடியும் அல்லது முடிப்பற்றதாக இருக்கும்.**
:::
### 2.3.1. -s என முடியும் ஆய்வுப்பெயர் ஒருமை

பின்வரும் பெயர் மூலங்கள், ஒலிக்குறிப்பால் முடியும், **-s** என ஆய்வுப்பெயர் ஒருமையை உருவாக்குகின்றன:

::: grammar-box
**ஆண்பால் -a ஆல் முடியும்:** எ.கா deva ஆ. = ⟪देव⟩ "கடவுள்" -- ஆய்.ஒ: devas = ⟪देवस्⟩
**ஆண்பால் -i ஆல் முடியும்:** எ.கா kavi ஆ. = ⟪कवि⟩ "கவிஞர்" -- ஆய்.ஒ: kavis = ⟪कविस्⟩
**ஆண்பால் -u ஆல் முடியும்:** எ.கா guru ஆ. = ⟪गुरु⟩ "ஆசிரியர்" -- ஆய்.ஒ: gurus = ⟪गुरुस्⟩
:::

## 2.4. சந்தி -- ⟪सन्धि⟫

ஒரு சொல்லின் இறுதி ஒலி, அதனைத் தொடர்ந்து வரும் சொல்லின் தொடக்க ஒலியைப் பொறுத்து சமஸ்கிருதத்தில் மாறும். இந்த நிகழ்வை **சந்தி** (m.) = ⟪सन्धि⟩ ("இணைப்பு") என்று அழைக்கிறோம்.

### 2.4.1. -s இன் சந்தி

மேலும் காண்க:

> **Payer, Alois (1944–):** -s இன் சந்தி. -- (சமஸ்கிருதப் பொருட்கள்). -- URL: http://www.payer.de/sanskritmaterialien/ssandhi.htm

இறுதியில் **-s**:

**தனித்த இறுதி** (வாக்கிய முடிவு) இல், அது **Visarga (-ḥ)** ஆக மாறும்:
**devas** = ⟪देवस्⟩ » **devaḥ** = ⟪देवः⟩
**kavis** = ⟪कविस्⟩ » **kaviḥ** = ⟪कविः⟩
**gurus** = ⟪गुरुस्⟩ » **guruḥ** = ⟪गुरुः⟩

**ஒலிப்பில்லாத ஒலிகளுக்கு முன்**:
**k, kh, p, ph** மற்றும் **ś, ṣ, s** க்கு முன்: இது **Visarga (-ḥ)** ஆக மாறுகிறது
**devas + śivaḥ** » **devaḥ śivaḥ** = ⟪देवः शिवः⟫ ("சிவன் ஒரு தெய்வம்")
**c, ch** க்கு முன்: இது **-ś** ஆக மாறுகிறது
**ṭ, ṭh** க்கு முன்: இது **-ṣ** ஆக மாறுகிறது
**t, th** க்கு முன்: இது **-s** ஆகவே இருக்கும்
**sādhus + caitanyas** » **sādhuś caitanyaḥ** = ⟪साधुश्चैतन्यः⟫ ("சைதன்யா ஒரு புனிதர்")

**ஒலிப்புள்ள ஒலிகளுக்கு முன்**:
அல்லாத-a உயிரெழுத்துக்களுக்குப் பிறகு: இது **-r** ஆக மாறுகிறது
**kavis + Māghas** » **kavir māghaḥ** = ⟪कविर्माघः⟫ ("மாঘா ஒரு கவிஞர்")
அல்லாத-a உயிரெழுத்துக்களுக்குப் பிறகு **r-** க்கு முன்: **-s** நீங்கி, உயிரெழுத்து நீட்டிக்கப்படும்.
**gurus + rāmas** » **gurū rāmaḥ** = ⟪गुरू रामः⟫ ("ராமா ஒரு ஆசிரியர்")
**a-** க்குப் பிறகு: **-as**
ஒலிப்புள்ள உயிரெழுத்துக்களுக்கு முன்/a: இது **-o** ஆக மாறுகிறது (தொடக்க a நீங்கி » ⟪ऽ⟫)
**devas viṣṇus** » **devo viṣṇuḥ** = ⟪देवो विष्णुः⟫
**devas agnis** » **devo 'gniḥ** = ⟪देवो ऽग्निः⟫
பிற உயிரெழுத்துக்களுக்கு முன்: இது **-a** ஆக மாறுகிறது (இடைவெளி)
**devas + indras** » **deva indraḥ** = ⟪देव इन्द्रः⟫


## 2.5. சொல்லியல்

**deva** m. -- ⟪देव⟫ : வானவர், தெய்வம்; அரசன், மன்னர்.

**īśvara** m. -- ⟪ईश्वर⟫ : கர்த்தர், ஆட்சியாளர், தெய்வம் (ஒருமைப்பாட்டு நம்பிக்கை).

**brāhmaṇa** m. -- ⟪ब्राह्मण⟫ : பிராமணர் (ஆன்மீக வகுப்பு).

**kṣatriya** m. -- ⟪क्षत्रिय⟫ : க்ஷத்திரியர் (அரசர் மற்றும் போர்படை வகுப்பு).

**vaiśya** m. -- ⟪वैश्य⟫ : வைசியர் (வேளாண்மை மற்றும் வணிக வகுப்பு).

**śūdra** m. -- ⟪शूद्र⟫ : சூத்திரர் (சேவை வகுப்பு).

::: note-box Die vier Stände (varna)
பாரம்பரிய கோட்பாட்டின்படி (எ.கா., மனுஸ்மிருதி I, 88-91) பணிகள் பின்வருமாறு பிரிக்கப்பட்டுள்ளன:

**dvija** m. -- ⟪द्विज⟫ : "இரண்டுமுறை பிறந்தவர்" (மேலான மூன்று வகுப்பினரின் தொடக்கநிலை: Brāhmaṇa, Kṣatriya, Vaiśya).

**varṇa** m. -- ⟪वर्ण⟫ : நிறம், பிறப்பு நிலை (வாழ்வியல்).

நான்கு வகுப்புகள் (**varṇa** m.) பெரும்பாலும் ஜாதி என்று தவறாக புரிந்து கொள்ளப்படுகின்றன. ஆனால் நான்கு வகுப்புகள் -- ஜாதிகளிலிருந்து வேறுபட்டவை -- இந்தியாவிற்கு மட்டுமானது அல்ல; ஐரோப்பாவிலும் நாம் (முதல் உலகப் போர் வரை பகுதியாக) ஒரு நிலை அமைப்பு இருந்தது, அதற்கு கீழே உள்ள படம் 15-ஆம் நூற்றாண்டை சார்ந்தது:

**பெயரிடல்:**
**ஆசாரியர் வகுப்பு** (~Brāhmaṇa): Tu supplex ora = நீ வேண்டுக!
**அரசர் வகுப்பு** (~Kṣatriya): Tu protege = நீ காப்பாய்!
**உழவர் வகுப்பு** (~Vaiśya/Śūdra): Tuque labora = நீ வேலை செய்!

மூன்று வகுப்பினரும் தங்கள் நிலை உடை அணிந்துள்ளனர். அதனால் கடவுள் விரும்பியதாக குறிப்பிடப்படும் -- மேலே கிறிஸ்து ஆட்சி செய்கிறார்.

மாக்ஸ் வெபர் (1864–1920) நிலையை இவ்வாறு வரையறுக்கிறார்:

::: note-box
»**நிலை**« என்பது ஒரு கூட்டமைப்பிற்குள் செயல்படும் மக்களின் பலத்தையே குறிக்கும்
a) ஒரு நிலை சிறப்பு மதிப்பீடு, - அதுவே இருந்தால்
b) நிலை சிறப்பு உரிமைகளைக் கோருவது.

வகுப்புகள் உருவாகலாம்
அ) முதன்மையானவை, தனித்துவமான வகுப்பு வாழ்க்கை முறையின் மூலம், குறிப்பாக **தொழிலின்** (**வாழ்க்கை முறை அல்லது தொழில் வகுப்புகள்**) தன்மையின் மூலம்,
ஆ) இரண்டாம் நிலை, பாரம்பரிய கர்மாவின் மூலம், வகுப்புவாரியான **பிறப்பு** (**பிறப்பு வகுப்புகள்**) மூலம் வெற்றிகரமான பாரம்பரிய கோரிக்கைகள் மூலம்,
இ) அரசியல் அல்லது ஆய்வு அதிகாரங்களை ஒற்றைப்படைகளாக **அதிகாரம்** (**அரசியல் அல்லது ஆய்வு வகுப்புகள்**) மூலம்.

பிறப்பு-வகுப்பு வளர்ச்சி என்பது பொதுவாக ஒரு குழு அல்லது தரமான தனிநபர்களுக்கு சலுகைகளை (பாரம்பரிய) அதிகாரம் செய்வதன் ஒரு வடிவமாகும். வாய்ப்புகளின் நிலையான அதிகாரம், குறிப்பாக [அதிபதிக] வாய்ப்புகள் அல்லது வருவாய் வாய்ப்புகள், வகுப்பு உருவாக்கத்திற்கு வழிவகுக்கும். ஒவ்வொரு வகுப்பு உருவாக்கமும் அதிகாரங்கள் மற்றும் வருவாய் வாய்ப்புகளின் ஒற்றைப்படை அதிகாரத்திற்கு வழிவகுக்கும்.

வருவாய் வகுப்புகள் சந்தை-சார்ந்த பொருளாதாரத்தின் அடிப்படையில் வளரும் போது, வகுப்புகள் முறையாக ஒற்றைப்படை-சார்ந்த அல்லது பூர்வீக அல்லது வகுப்பு-பாரம்பரிய தேவை நிறைவு செய்யும் குழுக்களின் அடிப்படையில் உருவாகின்றன.

»**வகுப்பு சார்ந்த**« என்பது ஒரு சமூகம் வகுப்புகளின் அடிப்படையில் சமூக பிரிவு செய்யப்பட்டால், »**வகுப்பு சார்ந்த**« என்பது வகுப்புகளின் அடிப்படையில் பிரிக்கப்பட்டால். 'வகுப்பு' என்பது 'சமூக' வகுப்பிற்கு மிக அருகில் உள்ளது, 'வருவாய் வகுப்பு' மிக தொலைவில் உள்ளது. வகுப்புகள் பெரும்பாலும் சொத்து வகுப்புகளால் உருவாக்கப்படுகின்றன.

ஒவ்வொரு வகுப்பு சார்ந்த சமூகமும் பாரம்பரியமாக, வாழ்க்கை முறை விதிகளால் ஒழுங்குபடுத்தப்படுகிறது, எனவே பொருளாதார ரீதியாக அநியாயமான நுகர்வு நிபந்தனைகளை உருவாக்குகிறது மற்றும் ஒற்றைப்படை அதிகாரங்கள் மூலம் மற்றும் தனிப்பட்ட வருவாய் திறனை சுதந்திரமாக நிர்ணயிப்பதைத் தடுக்கிறது.

[**வேபர், மேக்ஸ் (1864–1920):** பொருளாதாரம் மற்றும் சமூகம் : புரிந்துணர்வு சமூகவியலின் அடிப்படை. – 5., திருத்தப்பட்ட பதிப்பு. – டியூபிங்கன் : மோர், 1976. – பக். 625 தொடக்கம்.]
