## 15.2. நிர்ணயச் சேர்மங்கள் = தத்புருஷ பு. = ⟪तत्पुरुष⟫

பெயர்ச்சொற்களால் (பெயர்ச்சொல் மற்றும் விசேஷணம்) குறிக்கப்படும் பொருள்களுக்கு இடையேயான தொடர்பை, ஒரு பண்புவினைத் தொடரின் மூலம் மட்டுமல்லாமல், ஒரு தத்புருஷத்தின் (⟪तत्पुरुष⟫) மூலத்திலும் வெளிப்படுத்தலாம். அதேபோல, விசேஷணங்களின் பண்புத்தொடரமைப்பு அல்லது பெயர்ச்சொற்களின் பண்புத்தொடரமைப்பை, ஒரு குறிப்பிட்ட வகையான தத்புருஷத்தின் மூலம், அதாவது கர்மதாராய (ஆ.) = ⟪कर्मधारय⟫ என்ற வகையின் மூலம் வெளிப்படுத்தலாம்.

⟪तत्पुरुषः⟫ =  ⟪तस्य⟫ ⟪पुरुषः⟫ "அவனின் அடிமை", அதாவது, அத்தகைய கூட்டுச்சொற்களின் வகைக்கு ஒரு எடுத்துக்காட்டே பெயர்.
::: grammar-box

தீர்மானகூட்டுச்சொற்களில் (தத்புருஷம்), ஒரு பெயர்ச்சொல் (பெயர்ச்சொல் அல்லது விசேஷணம்) மற்றொரு பெயர்ச்சொல் அல்லது வினையெச்சத்தால் நெருக்கமாகக் குறிக்கப்படுகிறது. நெருக்கமாகக் குறிக்கப்படும் சொல் பொதுவாக கூட்டுச்சொல்லின் பின்னங்கூறாக அமைகிறது.

முன்னங்கூறின் (தீர்மானிக்கும் கூறு) பின்னங்கூற்றுடன் (தீர்மானிக்கப்பட்ட கூறு) உள்ள தொடர்பு பின்வருமாறு இருக்கலாம்:

*   பண்புத்தொடரமைப்பு அல்லது பண்புத்தொடரமைப்பு: கூட்டுச்சொல் பிரிக்கப்படும்போது, முன்னங்கூறு பின்னங்கூற்றை ஒரே விகுதியில் (நேர்வினைத் தொடர் (⟪प्रथमा⟫), வாக்கியத்தில் விகுதித் தேவையின் படி) நெருக்கமாகக் குறிக்கிறது.
*   விகுதித்தொடரமைப்பு: கூட்டுச்சொல் பிரிக்கப்படும்போது, முன்னங்கூறு பின்னங்கூற்றிலிருந்து வேறுபட்ட விகுதியில் அமைகிறது (நேர்வினைத் தொடர் அல்ல - ⟪प्रथमा⟫).
*   வினையெச்சத்தொடரமைப்பு: முன்னங்கூறு விகுதியற்ற சொல்.

ஒரு கூட்டுச்சொல்லின் இரு கூறுகளுக்கும் இடையேயான விகுதித்தொடரமைப்பு, அக்கூட்டுச்சொல் எந்த விகுதியில் அமைந்திருந்தாலும் மாறாது: ஏனெனில், கூட்டுச்சொல் என்பது ஒரு விகுதி பெறக்கூடிய ஒரே சொல் ஆகும்:

எடுத்துக்காட்டு:

> நே.ஒ.⟪तत्पुरुषः⟫ = ⟪तस्य⟫ ⟪पुरुषः⟫  
> அந்.ஒ.⟪तत्पुरुषम्⟫ = ⟪तस्य⟫ ⟪पुरुषम्⟫  
> கரு.ஒ.⟪तत्पुरुषेण⟫ = ⟪तस्य⟫ ⟪पुरुषेण⟫  
> வி.ஒ.⟪तत्पुरुषस्य⟫ = ⟪तस्य⟫ ⟪पुरुषस्य⟫  
> நே.ப.⟪तत्पुरुषाः⟫ = ⟪तस्य⟫ ⟪पुरुषाः⟫  
> முதலியன.

Das Geschlecht eines Tatpuruṣa ist - mit wenigen Ausnahmen - das seines Hintergliedes.

:::
## 15.3. பண்பு / அப் பொசிஷனல் முன்கூட்டிய உறுப்புடன் கூடிய நிர்ணய கூட்டுச்சொற்கள் = கர்மதாரய புல்லிங்கு =  ⟪कर्मधारय⟫
::: grammar-box

கர்மதாராயம் பிரிக்கப்படும்போது, தொகைச்சொல்லின் இரு சொற்களும் ஒரே விளித்தொகையில் அமையும்.

:::
எ.கா.

⟪गुणवत्पुत्रः⟫ = ⟪गुणवान्पुत्रः⟫ = "நல்ல குணங்களை உடைய ஒரு மகன்"  
ஒ.ஒ. ⟪गुणवत्पुत्रम्⟫  
ந.ஒ. ⟪गुणवत्पुत्राः⟫  

⟪पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती⟫ ⟪क्षत्रिया⟫ = "பெற்றோர் பெற்ற க்ஷத்திரியப் பெண்ணுக்கு"  

⟪साधुजनाः⟫ = ⟪साधवो⟫ ⟪जनाः⟫ = "நல்ல மக்கள்"  

⟪इष्टदेवता⟫ = ⟪इष्टा⟫ ⟪देवता⟫ = "வேண்டப்பட்ட தெய்வம் = ஒருவருக்கு சிறப்பு பக்தி மற்றும் அடைக்கல உறவு உள்ள தெய்வம்"

Zur Abfolge der Glieder in einem Karmadhāraya ist folgende Sonderregel zu beachten:

*   ஒரு கர்மதாராயம் ஒப்பீட்டைக் குறிக்கினால், ஒப்பிடப்படும் பொருள் தொகைச்சொல்லின் பின்சொல்லில் அமையும்:

    ⟪नरसिंहः⟫ = ⟪सिंह⟫ ⟪इव⟫ ⟪नरः⟫ = "சிங்கம் போன்ற ஒரு மனிதன்"  
    ⟪पुरुषव्याघ्रः⟫ = ⟪व्याघ्र⟫ ⟪इव⟫ ⟪पुरुषः⟫ = "புலி போன்ற ஒரு மனிதன்"

*   ஆனால் ஒரு கர்மதாராயம் பண்புத்தொகையை (பின்சொல்லை ஒரு பெயர்ச்சொல் மூலம் நெருக்கமாகக் குறிப்பிடல்) குறிக்கினால், நெருக்கமாகக் குறிப்பிடும் சொல் முன்சொல்லில் அமையும், இது ஒரு தத்த்புருஷத்தில் சொற்களின் வரிசைக்கான பொது விதியையும் பின்பற்றுகிறது:

    ⟪नरसिंहः⟫ இதைப் பிரிக்கலாம்: ⟪नर⟫ ⟪एव⟫ ⟪सिंहः⟫ = "ஒரு சிங்கம், அது (உண்மையில்) ஒரு மனிதன்."

    அத்தகைய பண்புத்தொகை கர்மதாராயங்கள் உள்ளூர் விளக்கங்களில் மேலே உள்ள உதாரணத்தின் மூலம் ⟪एव⟫ மூலம் பிரிக்கப்படுகின்றன.

## 15.4. முன் உறுப்பு பின் உறுப்புடன் பண்பு விவரிப்பு அல்லது இணைப்பு உருபு தொடர்பில் உள்ள ஒரு தீர்மானகூற்றுச் சொல் = மெல்லிய அர்த்தத்தில் தத்புருஷன்

::: grammar-box

தற்புருஷ இணைப்புகள் பெயர்ச்சொற்களின் (பெயர்ச்சொற்கள் மற்றும் குணப்பெயர்கள்) இணைப்புகளுக்கு சாத்தியமாகும், அவற்றில் முன் உறுப்பு - வியாகரண விதிகளின்படி - எந்த விகாரத்திலும் இருக்கலாம். எதிர்பார்த்தபடி, முன் உறுப்பு பெரும்பாலும் ஒரு பிறப்பு விகாரத்தைக் (⟪षष्ठी⟫) பிரதிநிதித்துவப்படுத்துகிறது, ஏனெனில் இது பெயர்ச்சொற்களின் விகாரத்தை வெளிப்படுத்தும் விகாரமாகும்.

:::
எ.கா.

⟪क्षत्रियपुत्रः⟫ = ⟪क्षत्रियस्य⟫ ⟪पुत्रः⟫ = "ஒரு க்ஷத்திரியின் மகன்", "ஒரு இளம் க்ஷத்திரியர்", "க்ஷத்திரியர்களின் குழுவைச் சேர்ந்த ஒருவர்"  
ஒருமை காரகம் ⟪क्षत्रियपुत्रम्⟫  
பிறப்பு ஒருமை ⟪क्षत्रियपुत्रस्य⟫  
மற்றும்.  

⟪गुरुभावः⟫ =  ⟪गुरोर्भावः⟫  = "ஒரு ஆசிரியரின் இயல்பு"

⟪धनलोभः⟫ = ⟪धनस्य⟫  ⟪लोभः⟫ = "செல்வத்தின் ஆசை, பொறாமை"

⟪लोकगतिः⟫ =  ⟪लोकस्य⟫ ⟪गतिः⟫ = "உலகின் நடத்தை, மக்களின் நடத்தை"

ஒவ்வொரு பிறப்பு விகாரத்தையும் ஒரு தற்புருஷத்தால் மாற்றலாம். சில விதிவிலக்குகள் எ.கா. கலே, ஒரு உயர் சமஸ்கிருத வியாகரணம் பிரிவு 211, அங்கே பாணினிக்கு ஏற்றமான இடங்கள்.

ஒரு தற்புருஷத்தின் முன் உறுப்பு தத்துவார்த்தமாக எந்த விகாரத்தையும் பிரதிநிதித்துவப்படுத்தலாம். இருப்பினும், அனைத்து வியாகரண ரீதியான விகார விகாரங்களையும் ஒரு தற்புருஷத்தால் மாற்ற முடியாது. சந்தேகத்தின் போது, கலே, ஒரு உயர் சமஸ்கிருத வியாகரணம் பிரிவு 203 - 217 அல்லது பாணினி 2,1,22 - 2,2,22 இல் ஏற்றமான விதிகளைக் காணலாம்.

::: grammar-box

ஒருங்கிணைப்பைத் தீர்க்கும் போது, முன் உறுப்பு ஒருமை, இரட்டை அல்லது பன்மை விகாரத்தில் இருக்கலாம். எந்த வாய்ப்பு உள்ளது என்பது அர்த்தம் மற்றும் சூழலிலிருந்து கண்டுபிடிக்கப்பட வேண்டும்.

:::
உதாரணங்கள்:

முன் உறுப்பு காரக விகாரத்தை பிரதிநிதித்துவப்படுத்துகிறது (⟪द्वितीया⟫): எ.கா. இயக்க வினைகளுக்கான சில PPP (பாணினி 2,1,24):

⟪ग्रामगतः⟫ = ⟪ग्रामं⟫ ⟪गतः⟫ = "கிராமத்திற்குச் சென்ற ஒருவர்"  
⟪नरकपतिता⟫ = ⟪नरकं⟫ ⟪पतिता⟫ = "ஒரு நரகத்தில் விழுந்த ஒருவர்"

முன் உறுப்பு கருவி விகாரத்தை பிரதிநிதித்துவப்படுத்துகிறது (⟪तृतीया⟫): எ.கா. பெரும்பாலும் காரணம் (⟪कर्तृ⟫) kṛt-பின்சொற்களுடன் பெயர் உருவாக்கங்கள் (எ.கா. PPP):

⟪देवकृतम्⟫ = ⟪देवेन⟫ / ⟪देवैः⟫ ⟪कृतम्⟫ = "ஒரு கடவுளால் / கடவுள்களால் செய்யப்பட்டது"  
இதுவும் தீர்க்கக்கூடியது: ⟪देवस्य⟫ / ⟪देवानां⟫ ⟪कृतम्⟫ = "ஒரு கடவுளின் செயல் / கடவுள்களின் செயல்; கடவுளின் செயல், கடவுள்களின் செயல்"  

⟪बुद्धरक्षिता⟫  = ⟪बुद्धेन⟫ ⟪रक्षिता⟫ = "பௌத்தரால் பாதுகாக்கப்பட்டவர்" (ஒரு தனிப்பெயர்)

## 15.5. சேர்மங்களை பிரித்தல் (துவந்த்வ தவிர)

::: grammar-box
சமஸ்கிருதத்தில் எந்த நீளத்திலான கூட்டுச்சொற்களையும் உருவாக்கலாம், மேலும் அவை மிகவும் அடிக்கடி உருவாக்கப்படுகின்றன (10 முதல் 30 உறுப்புகள் வரை கொண்ட கூட்டுச்சொற்கள் அரிதல்ல!). இருப்பினும், துவ்⟪‌⟫த்வாக்களைத் தவிர, அனைத்து கூட்டுச்சொற்களும் படிநிலை வரிசையில் இரண்டு பகுதிகளாகப் பிரிக்கப்பட வேண்டும்:

:::
::: media
![](/images/lekt1502.jpg)
சுருக்கம்: ⟪समासविच्छेदः⟫
(படத்தின் மூலம்: [விவரங்கள்](/ta/licenses#lekt1502))
:::
ஒவ்வொரு சொல் வடிவத்தையும் அடைந்தால் வரை.

எ.கா.

⟪गुणवत्पुत्रकृतपुण्यम्⟫

::: indent
1\. நிலை (முதன்மை இடைநிறுத்தம்): ⟪गुणवत्पुत्रकृतं⟫ ⟪॥१॥⟫ ⟪पुण्यम्⟫

2\. நிலை (1. துணை இடைநிறுத்தம்): ⟪गुणवत्पुत्रेण⟫ ⟪॥२॥⟫ ⟪कृतं⟫ ⟪॥१॥⟫ ⟪पुण्यम्⟫

3\. நிலை (2. துணை இடைநிறுத்தம்): ⟪गुणवता॥३॥⟫ ⟪पुत्रेण⟫ ⟪॥२॥⟫ ⟪कृतं⟫ ⟪॥१॥⟫ ⟪पुण्यम्⟫

= "என் நற்பேறுமிக்க மகன் செய்த நற்பேறுமிக்க செயல் (நற்பேறு)"
:::
இவ்வாறு வெவ்வேறு வகையான கூட்டுச்சொற்கள் கலக்கலாம், எ.கா. முன் உறுப்பு: பahuṛīhī (⟪बहुव्रीहि⟫) - பின் உறுப்பு: தத்புருஷ etc.

எ.கா.

⟪ब्राह्मणक्षत्रियवैश्यधर्मः⟫

::: indent
1\. நிலை: ⟪ब्राह्मणक्षत्रियवैश्यानां⟫ ⟪धर्मः⟫ (முன் உறுப்பு: இத்தரதரதுவ்வ)

2\. நிலை: ⟪ब्राह्मणानां⟫ ⟪क्षत्रियाणां⟫ ⟪वैश्यानां⟫ ⟪च⟫ ⟪धर्मः⟫

= "பிராமணர், க்ஷத்திரியர் மற்றும் வைசியர் ஆகியோரின் தர்மம்"
:::
ஒரு கூட்டுச்சொல்லிற்கு பல பிரிவு வாய்ப்புகள் பெரும்பாலும் உள்ளன. சரியானது அல்லது குறைந்தது சிறந்தது எது என்பதை உரையாடலின் சூழல் மற்றும் உரையின் உள்ளடக்கத்திலிருந்து மட்டுமே முடிவு செய்யலாம். சில சமயங்களில் இந்த முடிவு சாத்தியமில்லை. பெரும்பாலும், இரண்டு பிரிவு வாய்ப்புகள் ஆசிரியரால் நோக்கப்பட்டிருக்கலாம். அப்போது, மொழிபெயர்ப்பில் இரண்டு பிரிவு வாய்ப்புகளையும் மீண்டும் வழங்க வேண்டும் ("மற்றும்", "அல்லது" "அல்லது" போன்றவற்றால் இணைக்கப்பட்டது).

எ.கா.

::: indent

2. ⟪पुण्यवतः⟫ ⟪पुत्रस्य⟫ ⟪कृतम्⟫ = "என் நற்பேறுமிக்க மகனின் செயல்"
3. 1. ⟪पुण्यवत्⟫  ⟪पुत्रेण⟫ ⟪कृतम्⟫ = "என் மகனால் செய்யப்பட்ட நற்பேறுமிக்கது"
   2. ⟪पुण्यवत्⟫  ⟪पुत्रस्य⟫ ⟪कृतम्⟫ = "என் மகனின் நற்பேறுமிக்க செயல்"

## 15.6. கூட்டுச்சொற்களில் (⟪ஸமாஸ⟫ பு.) முற்பகுதியின் வடிவம்
::: grammar-box

அனைத்து வகையான கலப்பொருள்களிலும், முன்சொல் பொதுவாக மாற்றமடையாத சொற்றொகுதியாகவே இருக்கும். இருசொற்றொகுதி பெயர்ச்சொற்கள் பலவீனமான சொற்றொகுதியில் அமைவன. ஒரு கலப்பொருளில் அடுத்த சொல்லை அருகமைக்கும் பெண்பால் விசேஷணங்கள் பொதுவாக ஆண்பால் சொற்றொகுதியில் அமைவன:

எ.கா.

⟪पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती⟫ ⟪क्षत्रिया⟫ = "ஒரு க்ஷத்திரியப் பெண், நன்மைகளைக் கொண்ட"  
⟪गुणवत्पुत्रः⟫ = ⟪गुणवान्⟫ ⟪पुत्रः⟫ = "நல்ல குணங்களைக் கொண்ட ஒரு மகன்"

:::
## 15.7. பகுப்பு ⟪तत्पुरुष⟫

1.  ⟪प्रथमातत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫-இல் பெயர்ச்சொல் விகாரத்தில் உள்ளது (⟪प्रथमा⟫)
2.  ⟪द्वितीयातत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫-இல் எதிர்ச்சொல் விகாரத்தில் உள்ளது (⟪द्वितीया⟫)
3.  ⟪तृतीयातत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫-இல் கருவி விகாரத்தில் உள்ளது (⟪तृतीया⟫)
4.  ⟪चतुर्थीतत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫-இல் கொடுக்கும் விகாரத்தில் உள்ளது (⟪चतुर्थी⟫)
5.  ⟪पञ्चमीतत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫-இல் விலக்கும் விகாரத்தில் உள்ளது (⟪पज्चमी⟫)
6.  ⟪षष्ठीतत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫-இல் சொந்த விகாரத்தில் உள்ளது (⟪षष्ठी⟫)
7.  ⟪सप्तमीतत्पुरुषः⟫ : முன் உறுப்பு ⟪विग्रहवाक्य⟫-இல் இருக்கும் விகாரத்தில் உள்ளது (⟪सप्तमी⟫)

*   ⟪कर्मधारयः⟫ : பதவுத்திரை, குறிப்பாக:
    *   ⟪उपमानपूर्वपदकर्मधारयः⟫ : ⟪विग्रहवाक्य⟫ முதல் உறுப்புக்குப் பின் ⟪इव⟫
    *   ⟪उपमानोत्तरपदकर्मधारयः⟫ : ⟪विग्रहवाक्य⟫ இரண்டாவது உறுப்புக்குப் பின் ⟪इव⟫
    *   ⟪रूपकसमासः⟫ : ⟪विग्रहवाक्य⟫ ⟪एव⟫-உடன்
    *   ⟪द्विगुसमासः⟫ : எண்ணொன்று முன் உறுப்பில்
*   ⟪नञ्तत्पुरुषः⟫ (⟪निषेधतत्पुरुषः⟫) : முன் உறுப்பில் a-, an- எதிர்மறை உடன்
*   ⟪गतिसमासः⟫ : முன் உறுப்பில் பெயர்ச்சொல் உடன்
*   ⟪प्रथमातत्पुरुषः⟫ மற்றும் பிற (மேலே பார்க்கவும்)

### 15.7.1. பகுப்பு ⟪कर्मधारय⟫

1.  ⟪विशेषणपूर्वपदकर्मधारयः⟫ : முன் உறுப்பு பண்புச்சொல் (⟪विशेषण⟫)
2.  ⟪विशेषणोभयपदकर्मधारयः⟫ : இரண்டு உறுப்புகளும் பண்புச்சொற்கள்; காலவெளியைக் குறிக்கும் பண்புச்சொற்களும் இவ்வகையில் அடங்கும்: "முதலில் குளித்து, பின்னர் தேய்த்த"
3.  ⟪उपमानपूर्वपदकर्मधारयः⟫ : ⟪विग्रहवाक्य⟫ முதல் உறுப்புக்குப் பின் ⟪इव⟫
4.  ⟪उपमानोत्तरपदकर्मधारयः⟫ : ⟪विग्रहवाक्य⟫ இரண்டாவது உறுப்புக்குப் பின் ⟪इव⟫
5.  ⟪रूपकसमासः⟫ : ⟪विग्रहवाक्य⟫ ⟪एव⟫-உடன்
6.  ⟪संभावनपूर्वपदकर्मधारयः⟫ : இரண்டு உறுப்புகளும் ஒரே நபர் அல்லது பொருளைக் குறிக்கும்; எ.கா. ⟪कालिदासकविः⟫ = ⟪कालिदास⟫ ⟪इति⟫ ⟪कविः⟫ = "கவிஞர் காளிதாசர்"
7.  ⟪कर्मधारयः⟫ உடன் ⟪कु⟫ / ⟪कद्⟫ முன் உறுப்பாக: "மோசமான..."
8.  ⟪कर्मधारयः⟫ : பதவுத்திரை, குறிப்பாக:
9.  PPP + எதிர்மறை PPP: "பகுதியாக", எ.கா. ⟪कृताकृतम्⟫ = "பகுதியாகச் செய்யப்பட்டது"
10.  ⟪द्विगुसमासः⟫ : எண்ணொன்று முன் உறுப்பில்
