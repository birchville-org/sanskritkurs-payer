# பாடம் 54

கீழ்க்காணும் பிரேசன் அல்லது பெர்ஃபெக்ட் வடிவங்களுக்கு ஏற்ப அஓரிஸ்ட் வடிவங்களை உருவாக்கவும்:

::: grammar-box
| எண். | வடிவம் | குறிப்பு / பொருள் | அஓரிஸ்ட் |
|:---|:---|:---|:---|
| १. | **यन्ति** | அவர்கள் செல்கிறார்கள் | **अगुः** |
| २. | **पिबामि** | நான் குடிக்கிறேன் | **अपाम्** |
| ३. | **ददौ** | நான் / அவர் கொடுத்தேன் / கொடுத்தார் | **अदाम् / अदात्** |
| ४. | **बभूव** | நான் / அவர் / அவர்கள் இருந்தேன் / இருந்தார் / இருந்தார்கள் | **अभूवम् / अभूत् / अभूत** |
| ५. | **दधति** | அவர்கள் அமைக்கிறார்கள் | **अधुः** |
| ६. | **ऐम** | நாம் சென்றோம் | **अगाम** |
| ७. | **पपिथ** | நீ குடித்தாய் / பாதுகாத்தாய் | **अपाः** (*पा* "குடித்தல்" என்பதற்கு) |
| ८. | **तिष्ठति** | அவர் நிற்கிறார் | **अस्थात्** |
| ९. | **इयेथ** | நீ சென்றாய் | **अगाः** |
| १०. | **पप** | நீங்கள் குடித்தீர்கள் | **अपात** |
| ११. | **एष्यथ** | நீங்கள் செல்வீர்கள் | **अगात** |
| १२. | **तस्थुः** | அவர்கள் நின்றனர் | **अस्थुः** |
| १३. | **अधत्त** | நீங்கள் அமைத்தீர்கள் | **अधात** |
| १४. | **अददाः** | நீ கொடுத்தாய் | **अदाः** |
| १५. | **अभवन्** | அவர்கள் இருந்தனர் | **अभूवन्** |
| १६. | **ददिम** | நாம் கொடுத்தோம் | **अदाम** |
| १७. | **भिद्यते** அது பிளக்கப்படுகிறது | **अभेदि** |
| १८. | **उद्यते** அது சொல்லப்படுகிறது | **अवादि** |
| १९. | **स्तूयते** அவர் பாராட்டப்படுகிறார் | **अस्तावि** |
| २०. | **कृष्यते** அது விவசாயம் செய்யப்படுகிறது | **अकर्षि** |
| २१. | **जायते** அவர் பிறக்கிறார் | **अजनि** |
| २२. | **गीयते** அது பாடப்படுகிறது | **अगायि** |
| २३. | **गम्यते** அது செல்லப்படுகிறது | **अगामि** |
:::
