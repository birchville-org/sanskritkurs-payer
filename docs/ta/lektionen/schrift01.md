# டெவநாகரி = ⟪देवनागरी⟫

## எழுத்துப் பயிற்சி 1

சமஸ்கிருதம் பலவிதமான எழுத்து முறைகளில் எழுதப்பட்டு வருகிறது. பின்வரும் சுருக்கமான விளக்கம் அந்த எழுத்து முறைகளில் சிலவற்றைக் காட்டுகிறது:

![](/images/schrift001.webp)  
உரு: சமஸ்கிருத எழுத்து மாதிரிகள்
\[படம்: விக்கிப்பீடியா, GNU FD உரிமம்\]

நவீன வட இந்திய சமஸ்கிருத எழுத்து முறையில் மிகவும் முக்கியமானது டெவநாகரி:

![](/images/schrift002.webp)

ஒவ்வொரு உயிர்மெய் எழுத்தும், அந்த உயிர்மெய்க்குப் பின் வரும் 'அ' என்ற ஒலியையும் குறிக்கிறது. சுத்தமான உயிர்மெய் எழுத்தை (பின்வரும் ஒலியின்றி) எழுத வேண்டுமென்றால், அதற்குக் கீழே ஒரு சாய்வுக்கோடு -- விராமம் = ⟪विराम⟫ -- வைக்க வேண்டும்:

⟪क्⟫ = க, ⟪च्⟫ = ச, ⟪ट्⟫ = ட், ⟪त्⟫  = த, ⟪प्⟫ = ப

ஒரு உயிர்மெய்க்குப் பின் வரும் ஒலிகள் -- 'அ' தவிர்த்த மற்றவை -- இப்படி எழுதப்படும்:

⟪का⟫ = கா, ⟪कि⟫ = கி, ⟪की⟫ = கீ, ⟪कु⟫ = கு, ⟪कू⟫ = கூ, ⟪कृ⟫ = க்ரு, ⟪कॄ⟫ = க்ரீ, ⟪कॢ⟫  = க்ள

⟪के⟫ = கே, ⟪कै⟫ = கை, ⟪को⟫ = கோ, ⟪कौ⟫ = கௌ

உயிர்மெய் + ஒலி இணைப்புகளை எழுதும்போது கடைபிடிக்க வேண்டிய வரிசை:

![](/images/schrift003.jpg)

எழுதும்போது, ஒவ்வொரு எழுத்தையும் மேல் கோட்டுடன் முடித்துவிட்டே, அடுத்த எழுத்தை எழுதத் தொடங்க வேண்டும்.
