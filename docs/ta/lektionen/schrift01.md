# தெவநாகரி = ⟪देवनागरी⟫

## எழுத்துப் பயிற்சி 1

சமஸ்கிருதம் பல வகையான எழுத்துக்களில் எழுதப்பட்டதும், எழுதப்படுவதும் ஆகும். பின்வரும் சுருக்கம் இந்த எழுத்துக்களில் ஒரு சிறிய பகுதியைத் தருகிறது:

![](/images/schrift001.webp)  
அடிக்குறிப்பு: எழுத்து மாதிரிகள் சமஸ்கிருதம்  
\[படம் மூலம்: விக்கிப்பீடியா, GNU FD அனுமதி\]

ஒவ்வொத்து ஒலி எழுத்தும், அந்த ஒலி எழுத்திற்குப் பின் வரும் "a" என்ற ஒலியையும் குறிக்கிறது. சுத்தமான ஒலி எழுத்தை (பின் வரும் உயிரெழுத்தற்ற) எழுத வேண்டுமானால், அது ஒரு கீழ் வரிசை சாய்வுக் கோடு மூலம் குறிக்கப்பட வேண்டும் -- விராமம் = ⟪विराम⟫ -- எனக் குறிக்க வேண்டும்:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

ஒரு ஒலி எழுத்திற்குப் பின் வரும் உயிரெழுத்துக்கள் -- "a" தவிர்த்த -- இவ்வாறு எழுதப்படும்:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ <!-- TODO: Fallback translation -->

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau <!-- TODO: Fallback translation -->

இந்த ஒலி எழுத்து + உயிரெழுத்து இணைப்புகளை எழுதும் வரிசை:

![](/images/schrift003.jpg)

எழுதும் போது, ஒவ்வொரு எழுத்தும் மேல் வரிசைக் கோடு முழுவதும் முடிக்கப்பட்ட பின்னரே அடுத்த எழுத்து எழுதப்படும்.

## பயிற்சி

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

படிக்கவும் மற்றும் எழுத்துப்பெயர்த்திடவும்:

⟪तॄ⟫ ⟪पाप⟫ ⟪चट्⟫ ⟪चि⟫ ⟪चाप⟫ ⟪पॄ⟫ ⟪पति⟫ ⟪पितृ⟫ ⟪कॢप्⟫ ⟪कृ⟫ ⟪कुप्⟫ ⟪कुतो⟫ ⟪चैक⟫ ⟪पुट⟫ ⟪पचति⟫ ⟪तौ⟫ ⟪पू⟫ ⟪चेत्⟫ ⟪पतति⟫ ⟪ततो⟫ ⟪तट⟫ ⟪तपति⟫ ⟪तु⟫ ⟪ते⟫ ⟪कृ⟫ ⟪पीतौ⟫

கூடுதல் வாசிப்புப் பயிற்சி:

⟪पिता⟫ தந்தை, ⟪कपि⟫ குரங்கு, ⟪कृत⟫ செய்தது,  ⟪टीका⟫ உரைநூல், ⟪तत्⟫ இது, ⟪तट⟫ கரை, ⟪पत्⟫ எய்துதல், ⟪पट⟫ துணி, ⟪काच⟫ கண்ணாடி,  ⟪काकुत्⟫ வாய், ⟪चित्⟫ உணர்தல், ⟪पृच्⟫ கலத்தல்,  ⟪पोटक⟫ அடிமை, ⟪चेतु⟫ நோக்கம், ⟪तौतातित⟫ குமாரிலனின் பின்பற்றுநர் (மீமாங்கசம்), ⟪तूत⟫ எலுமிச்சை மரம், ⟪पीत⟫ குடித்தது,  ⟪पीति⟫ பானம், ⟪कॢप्⟫  பொருத்தம், ⟪कृपते⟫ அவன் அழுகிறான், ⟪पुटी⟫ வரி, ⟪चापि⟫ அதே போன்றது, ⟪तोक⟫ சந்ததி, ⟪तृपत्⟫ நிறைவு, ⟪पॄ⟫ நிரப்புதல், ⟪कृकाटी⟫ கழுத்து மூட்டு, ⟪पूपौ⟫ இரண்டு வடைகள், ⟪पैतृकी⟫ தந்தைக்குரியது (பெண்பால்), ⟪कौट⟫ ஏமாற்றுதல், ⟪कच⟫ தலைமுடி, ⟪कुतपे⟫ ஆடுசீலை மீது, ⟪कुचौ⟫ மார்பகம், ⟪चकिता⟫ பயத்தடைந்தது (பெண்பால்)
