# பாடம் 27

## 27.1. இடவினையின் பயன்பாடு (⟪सप्तमी⟫ f. = "ஏழாவது வினைச்சொல்")

::: grammar-box

**இடவினையெச்சம் (⟪सप्तमी⟫) பின்வரும் கேள்விகளுக்கு விடையளிக்கிறது:**
*   **எங்கே?**
*   **எப்போது?**
*   **எந்தச் சூழ்நிலையில்?**
*   **எதற்கு தொடர்பாக?**

:::
::: grammar-box

**1. நிலையியல் (⟪सप्तमी⟫) "எங்கே?" என்ற கேள்வியைக் குறிக்கிறது — செயலாளர் (⟪कर्ता⟫) அல்லது ஒரு செயலின் பொருள் அமைந்துள்ள இடம் அல்லது செயல் நடைபெறுமிடம்.**

> ⟪नगरे⟫ ⟪वसति⟫ = "அவர் நகரத்தில் வசிக்கிறார்"

:::
::: media
![](/images/lekt2701.webp)
படம்: ⟪जयपुरनगरे⟫
ஜெய்ப்பூர், 1875.
(பட மூலம்: [விவரங்கள்](/ta/licenses#lekt2701))
:::

::: grammar-box

**2. இடவினையெச்சம் "எப்போது?" என்ற கேள்வியைக் குறிக்கிறது: நேரம் அல்லது வெளிப்புற சூழல்:**

> ⟪तस्मिन्काले⟫ = "அந்த நேரத்தில், அந்த நேரத்தில்"

**இங்கேயே அழைக்கப்படும் லோகடீவஸ் அப்சோலட்டஸும் அடங்கும்:**

**ஒரு நபர் அல்லது பொருளின் செயல் அல்லது நிலை, மற்றொரு நபர் அல்லது பொருள் ஒரு செயலைச் செய்கிறதோ அல்லது குறிப்பிட்ட நிலையில் இருக்கிறதோ, அந்த நேரத்தை அல்லது அந்தச் சூழ்நிலைகளைத் தீர்மானித்தால், அந்த முதல் நபர் அல்லது பொருளைக் குறிக்கும் சொல், அதே சொல்லுடன் (அதிகமாக ஒரு பகுப்பாய்வு சொல்) அமைவதோடு, அமைவிடப் பால்வழியில் (⟪सप्तमी⟫):** வருகிறது.

> ⟪एवं⟫ ⟪गच्छति⟫ ⟪काले⟫ = "காலம் இவ்வாறு செல்லும்போது..."
>
> ⟪तस्मिन्गते⟫ = "அவர் சென்ற பின்..."

**சில சமயங்களில் செய்பவர் (⟪कर्ता⟫) தனியாகக் குறிப்பிடப்படுவதில்லை:**

> ⟪एवं⟫ ⟪सति⟫ = "அது இவ்வாறு அமைவதால்"

**Locativus absolutus-ஐ சூழலின் அடிப்படையில் "நேரத்தில்" (எ.கா. முன்னிலைப் பண்பெச்சம்), "பின்னர்", "அப்போது" (எ.கா. கீழ்ப்பொருள் பண்பெச்சம்), "ஏனெனில்", "வெகுமதி", "எனினும்", "எങ്കில்" போன்றவற்றால் மொழிபெயர்க்க வேண்டும்.**

குறிப்பு: தனிமைப் பண்புப்பெயரில், தனிமைப் பண்புப்பெயரின் செயலாளரும் முக்கிய வாக்கியத்தின் செயலாளரும் ஒரேவகையாக இருக்க வேண்டும்; தனிமை இடப்பெயரில், தனிமை இடப்பெயரின் செயலாளரும் முக்கிய வினையின் செயலாளரும் வேறுபட்டவர்களாக இருக்க வேண்டும்.

**3. நிலையொலி "எதற்கு தொடர்பாக?" போன்ற கேள்விகளுக்கும் பயன்படுத்தப்படும்:**

> ⟪अस्ति⟫ ⟪तस्य⟫ ⟪पुत्रे⟫ ⟪स्नेहः⟫ = "அவருக்குத் தனது மகன் மீது அன்பு உள்ளது" (சொற்பொருள்: "மகனைப் பொறுத்தவரை, அவரிடம் அன்பு உள்ளது")

> ⟪भू⟫ ⟪सत्तायाम्⟫ = "மூலம் ⟪भू⟫ 'இருத்தல்' (sat-tā) என்ற பொருளில்"

:::
இலக்கணத்தின் பிற பயன்பாடுகள் பின்னர்.

## 27.2. அமைவிடப் பால் உருவாக்கம் (⟪सप्तमी⟫)

::: grammar-box

**லோகத்திவின் (⟪सप्तमी⟫) வழக்கமான முடிபுகள் பின்வருமாறு:**
*   **ஒருமை: -i**
*   **பன்மை: -su**

**-su-க்கு முன் ஒலி மாற்றங்களைக் கவனிக்கவும், மேலும் -su-வின் சாத்தியமான மூளைப்படுத்தல் -ṣu-வாக மாறுவதையும் கவனிக்கவும்!**

:::

## 27.4. அனைத்து விகுத வடிவங்களும் (ஒருமை) கொண்ட ஒரு பாடம் :sig[⟪राम⟫]

::: media
![](/images/lekt2708.webp)
படம்: :sig[⟪रामे⟫] ⟪चित्तलयः⟫ ⟪सदा⟫ ⟪भवतु⟫ ⟪मे⟫ ⟪भो⟫ :sig[⟪राम⟫] ⟪मामुद्धर⟫ ⟪॥⟫
Rāma-Satz.
(பட மூலம்: [விவரங்கள்](/ta/licenses#lekt2708))
:::
:sig[⟪रामो⟫] ⟪राजमणिः⟫ ⟪सदा⟫ ⟪विजयते⟫ :sig[⟪रामं⟫] ⟪रमेशं⟫ ⟪भजे⟫
:sig[⟪रामेणा⟫]⟪भिहता⟫ ⟪निशाचरचमू⟫ :sig[⟪रामाय⟫] ⟪तस्मै⟫ ⟪नमः⟫ ⟪।⟫
:sig[⟪रामान्ना⟫]⟪स्ति⟫ ⟪परायणम्⟫ ⟪परतरं⟫ :sig[⟪रामस्य⟫] ⟪दासोऽस्म्यहम्⟫
:sig[⟪रामे⟫] ⟪चित्तलयः⟫ ⟪सदा⟫ ⟪भवतु⟫ ⟪मे⟫ ⟪भो⟫ :sig[⟪राम⟫] ⟪मामुद्धर⟫ ⟪॥⟫

**மொழிபெயர்ப்பு:**
1. **பெயர்ச்சொல்:** ராமா, ராஜாக்களில் (⟪राजन्⟩ ஆண்பால்) மணியான (⟪मणि⟩ ஆண்பால்) ராமா எப்போதும் வெற்றி பெறுகிறார் (⟪सदा⟩).
2. **பொருள்:** நான் (⟪भज्⟩ 1U) ராமாவை, ராமாவின் (⟪ईश⟩ ஆண்பால்) கணவரான மற்றும் ஆட்சியாளரான ராமாவை (லக்ஷ்மி =) விரும்புகிறேன்.
3. **கருவி:** ராமா இரவு நேரத் திருடர்களின் (⟪निशा⟩ பெண்பால் = இரவு) படை (⟪चमू⟩ பெண்பால்) அழித்தார்.
4. **சார்பு:** இந்த ராமாவிற்கு வணக்கம்!
5. **விலக்கு:** ராமாவை விட சிறந்த (⟪परतर⟩ 3) அடைக்கலம் (⟪परायण⟩ நடுப்பால்) இல்லை.
6. **சேர்க்கை:** நான் (⟪अहम्⟩) ராமாவின் (⟪अस्मि⟩) ஒரு அடிமை.
7. **இடம்:** ராமாவில் என் (⟪मे⟩) மனதின் (⟪लय⟩ ஆண்பால்) அமைதி எப்போதும் இருக்கட்டும் (⟪भवतु⟩).
8. **அழைப்பு:** ராமா, என்னை (⟪माम्⟩) காப்பாற்று (⟪उद्धर⟩ = ⟪उद्⟩ + ⟪हृ⟩ அல்லது ⟪उद्⟩ + ⟪धृ⟩)

## 27.6. பயிற்சி

**அ) பின்வரும் வாக்கியத்தில், அடைப்புக்குறிக்குள் உள்ள சொற்களை லோகத்தில (⟪सप्तमी⟫) ஒருமை மற்றும் - சாத்தியமான இடங்களில் - பன்மை ஆகியவற்றில் பயன்படுத்தவும். வெவ்வேறு சந்தியைக் கவனிக்கவும், அதாவது ஒவ்வொரு முறையும் முழு வாக்கியத்தையும் எழுதுங்கள்!**
