## 18.2. தீர்மானகூற்றுச் சொற்கள் (तत्पुरुष) வினையுரிமை முற்பகுதியுடன்

வினையுரிமை (விகாரணையற்ற) முற்பகுதியாக

*   வினையுரிமைகள்
*   விளிச்சொற்கள்
*   குறிப்பொழுகுகள்
*   பிற விகாரணைகள்

::: indent
பயன்படுத்தப்படலாம். அத்தகைய தத்புருஷ சமாசங்கள் பொதுவாக நித்யசமாச வகுப்பைச் சார்ந்தவை = नित्यसमास (ஆ. "நிலையான சமாசம்"), அதாவது, சமாசத்திற்குள் உள்ள சொற்களால் மட்டும் அல்லது எவ்வாறும் கரைக்க முடியாத சமாசங்கள்.
:::

எடுத்துக்காட்டுகள்:

अति "அதற்கு மேலும்":

::: indent
अतिगुरु 3: மிகவும் கடினமான, மிகவும் கனமான

अतिपुरुष ஆ.: சிறந்த ஆண், சூப்பர்மேன், வீரன்

अतिस्तुति பெ.: அளவுகடந்த பாராட்டு

अत्युक्ति பெ.: அளவுகடந்த பேச்சு, மிகைப்படுத்தல்
:::

முக்கியமான வினையுரிமை முற்பகுதிகள் a-/an-, su-, dus-.

अ (ஒலிக்கு முன்), अन् (ஒலிக்கு முன்): இல்லை-: சமாசத்தில் न "இல்லை" என்பதற்குப் பதிலாக அமைகிறது.

எடுத்துக்காட்டுகள்:

::: indent
अनृत பெ. = नर्तम् (= न + ऋतम्): பொய், பொய்ச்சொல்

अकृत 3 = न कृत 3: செய்யப்படாதது, செய்யப்படாதது

अब्राह्मणी பெ. = न ब्राह्मणी : ஒரு பிராமணியல்லாத பெண், பிராமணியல்லாதவள்

अदेव ஆ. = न देवः : ஒரு தேவனல்லாதவன், தேவனல்லாதவன்
:::

सु "நன்றாக, நல்ல"; சமாசத்தின் கரைசலில் விளக்கவுரைஞர்களால் "நல்ல" பொருள் கொண்ட பெயர்ச்சொல்லால் (எ.கா. सुष्टु 3, शोभन 3) மாற்றப்படுகிறது.

எடுத்துக்காட்டுகள்:

::: indent
सुकवि ஆ.: ஒரு நல்ல கவிஞர்

सुकृत பெ.: நல்ல செயல்

सुखादित 3: நன்றாக நக்கது

सुदुःख பெ.: பெரிய துக்கம்
:::

दुस् "மோசமாக, கெட்ட" (சந்தி கவனிக்கவும்!).

எடுத்துக்காட்டுகள்:

::: indent
दुर्नय ஆ.: மோசமான வழிநடத்தல், மோசமான நடத்தை

दुष्करण பெ.: மோசமான செயல், கடினமான செயல்
:::

இதற்கு பின்வரும் விதி பொருந்தும்:

:::: grammar-box

சமாசங்களில் -s இன் ஒலிமாற்றம்

வாக்கியசந்திக்கு எதிராக, சமாசத்தின் முற்பகுதியின் இறுதியில்:

\-s -i- அல்லது -u- க்குப் பிறகு ஒலியற்ற வாய்மொழி அல்லது உதழ் ஒலிக்கு முன் » -ṣ

எனவே: दुष्करण

::::

### 18.2.1. सुकर / दुष्कर வகைச் சொற்றொடர்கள்

:::: grammar-box

सुकर / दुष्कर வகைச் சொற்றொடர்கள் முக்கியமாக செயலற்ற சாத்தியத்தின் பொருளைக் கொண்டுள்ளன:

உதாரணங்கள்:

::: indent
सुकर 3: செய்வதற்கு எளிது

सुगम 3: செல்வதற்கு எளிது

दुर्गम 3: செல்வதற்குக் கடினம்

सुदुर्गम 3: மிகவும் கடினமாகச் செல்வது
:::

### 18.2.2. நான்-தத்புருஷத்தின் (அ- / அன்-) பொருள்கள்

அ- / அன்- உடன் கூடிய தத்புருஷத்தின் பின்வரும் பொருள்கள் இருக்கலாம்:

1.  ஒற்றுமை (तत्सादृश्यम्):  
    अब्राह्मणः = புனித நூலை (यज्ञोपवीत பெ.ந.) அணிந்திருக்கும் ஒரு க்ஷத்திரியன் அல்லது வைசியன், எனவே ஒரு பிராமணனைப் போன்றவன், ஆனால் அவனல்ல
2.  இன்மை, இல்லாமல் இருத்தல் (तदभावः):  
    अज्ञानम् = அறிவின்மை (அறிவின் இல்லாமல் இருத்தல்)
3.  வேறுபாடு (तदन्यत्वम्):  
    अपटम् = ஒரு வஸ்திரம் / ஆடை (पट பெ.ஒ: நெசவு, ஆடை) அல்லாதது
4.  சிறுமை (तदल्पता):  
    अनुदरम् = ஒரு சிறிய வயிறு (ஒரு வயிறல்லாதது)
5.  கண்டனம் (अप्राशास्त्यम्):  
    अकालः = காலமிக்காமல்
6.  பகைமை (निरोधः):  
    असुरः = எதிர்ப்பகைவான் (தவறான வார்த்தைப் பிறப்பியல் அ-சுர படி)

இந்தப் பொருள்களைக் கீழ்க்கண்ட சூத்திரம் சுருக்கமாகக் கூறுகிறது:

::: indent
तत्सादृश्यमभावश्च  
तदन्यत्वं तदल्पता ।  
अप्राशास्त्यं निरोधश्च  
नजर्थाः षट्प्रकीर्तिताः ॥

நான் (= அ-/அன்-) ஆறு பொருள்கள் அழைக்கப்படுகின்றன ....
:::

## 18.3. பெயர்ச்சொல் சேர்க்கைகள்

:::: grammar-box

::: indent
उपसर्गेण धात्वर्थो  
बलादन्यत्र नीयते ।  
गङ्गासलिलमाधुर्यं  
सागरेण यथाम्भसा ॥
:::

चन्द्रकीर्ति : प्रसन्नपदा பக். 2 வரி 14-15

ஒரு முன்னொட்டு ஒரு வேர்ச்சொல்லின் பொருளைக் கங்கை நீரின் இனிமையைக் கடல் நீர் மாற்றுவது போல வலியுற மாற்றுகிறது.

::::

:::: grammar-box

சமசுகிருதத்தில், வினைச்சொற்கள் முன்னொட்டுகளுடன் (उपसर्ग ஆ.பெ.) இணைக்கப்படலாம். பொதுவாக, அங்கத்தான் விதி பொருந்தும். முன்னொட்டுகள் வேர்ச்சொல்லின் பொருளைக் கணிசமாக மாற்றக்கூடும், எனவே பல சந்தர்ப்பங்களில், முன்னொட்டுடன் கூடிய வேர்ச்சொல்லின் பொருளைத் தனித்தனியாகக் கற்றுக்கொள்ள வேண்டும். முன்னொட்டுள்ள வினைச்சொற்கள் எளிமையான வேர்ச்சொல்லுக்கு வெவ்வேறு பங்குமை (ப, ஆ) கொண்டிருக்கலாம். ஒரு வேர்ச்சொல்லின் முன் ஒரே நேரத்தில் பல முன்னொட்டுகள் வைக்கப்படலாம்.

::::

சில முக்கிய முன்னொட்டுகள்:

उप "நோக்கி, கீழ், எதிராக"

உதாரணங்கள்:

::: indent
उपगम् 1 उपगच्छति : செல்வது, அணுகுதல்

उपदिश् 6 उपदिशति : சுட்டிக்காட்டுதல், கற்பித்தல், அறிவுரை கூறுதல்

उपपद् 4 ஆ उपपद्यते : அடைதல்

*   மு.வி.ப. उपपन्न 3: அமைந்த (கருவிப் பால்)

उपलभ् 1 ஆ उपलभते : பிடித்தல், அடைதல்
:::

प्र "முன்னோக்கி, வெளி"

உதாரணங்கள்:

::: indent
प्राप् (pra-āp) 5 प्राप्नोति : அடைதல்

प्रदिश् 6 प्रदिशति : காட்டுதல்

प्रबुध् 4 ஆ प्रबुध्यते : எழும்புதல், அறிதல்

प्रभू 1 प्रभवति : வெளிவருதல், மேம்படுதல், ஆட்சி செலுத்துதல் (பிறப்பு, இடப் பால், கொடுப்பான் பால்)

प्रवच् 2 प्रवक्ति மு.வி.ப. प्रोक्त (« pra + ukta) : விளக்குதல், தெரிவித்தல், உச்சரித்தல்

प्रवद् 1 प्रवदति : உச்சரித்தல், என்று குறிப்பிடுதல், என்று விளக்குதல்

प्रस्तु 2 प्रस्तौति : பாராட்டுதல், உரத்த பாராட்டுதல், ஏதேனும் ஒன்றைப் பற்றிப் பேசுதல், தொடங்குதல்
:::

वि "விலகி, பிரிந்து, கலைந்து, விரும்பி"

### 18.3.1. பெயர்ச்சொல் உருவாக்கங்கள் வினைச் சேர்க்கைகளுக்கு

:::: grammar-box

முன்னொட்டுகளுடன் கூடிய மூலங்களுக்கு, kṛt-பின்னொட்டுகள் மூலம் பெயர்ச்சொற்கள் உருவாக்கப்படலாம்.

::::

எடுத்துக்காட்டுகள்:

sam-kṛ + -a = संस्कार p.: அமைப்பு, தயாரிப்பு ; மாற்றக்கால விழாக்கள் = கருத்தரித்தலிலிருந்து இறப்பு வரை வாழ்க்கையின் பல்வேறு கட்டங்களைப் பின்தொடரும் விழாக்களின் பெயர் (இதற்கான சிறந்த சுருக்கத்திற்கு Basham, Wonder பக். 160 - 170! பார்க்கவும்)

upa-nī + -ana = उपनयन n.: அருகில் கொண்டு வருதல் (பலித்தீக்கு) = ஆண்களுக்கான மூன்று மேலான வகுப்பினருக்கு புனிதமான நூல் (यज्ञोपवीत n.) அணிவிக்கப்படும் மற்றும் புனிதமான வசனம் सावित्री காலை மற்றும் மாலை சூரிய உதயத்திற்கு பின்னர் அவர்கள் தினசரி ஜபிக்க வேண்டிய வசனம் காதுக்கு ஊதி எழுப்பப்படும் விழா. பிராமணர்களுக்கு, Ṛgveda III.62.10:

::: indent
"நம்மை நம்மை எண்ணங்களை இயக்கக்கூடிய 'இயக்குநர்' கடவுளின் சிறந்த ஒளியைப் பெற வல்லவராக இருக்க வேண்டும்."
:::

Upanayana மூலம் இரண்டாவது பிறவு நிகழ்கிறது, எனவே: द्विज । द्विजाति
