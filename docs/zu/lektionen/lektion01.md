Ekupheleni, into engajwayelekile:


>"Njengoba u-William Jones [1746–1794] no-Henry Thomas Colebrooke (1765—1857) bafunda iSanskrit ngokujulile kuqala, bese beyiguqula ingxenye, bese befika kokuthi inezincwadi eziningi futhi inobudlelwano obungaphansi nezilimi ezijwayelekile, bathola ukumelana okungaphansi. Ngoba ubudlelwano obunamandla beSanskrit nezilimi zaseYurophu ezikude kakhulu bezindawo bezinokungahambisani nezimfundiso zakudala, ebezibeka zonke izilimi ezivela kuHebheru noma ebezizikwele ngokuphelele, ngakho-ke umfundisi othi-Dugald Steward (1753—1828) wathatha indlela elula, ngokuthi wachaza umlando wonke ngesiSanskrit njengobukhali. Wabhala i-essay, lapho azama ukubonisa ukuthi yakhelwe ngokulinganisa neGrikhi neLatini ngama-Brahman abukhali, futhi ulimi kanye nezincwadi zombili zikhiqizwe. Le mfundiso yaphinde yathuthukiswa ngumprofethi e-Dublin, u-Charles William Wall, ngokuningiliziwe (Izibuyekezo ze-Göttingische gelehrte 1842 iph. 1888)."

## 1.2. Izwi le-Sanskrit

Izwi le-Sanskrit ngokwengqephu yase-Indiya yendabuko kanye nokubhalwa kwalo ngokwesayensi.

::: media
![](/images/lekt0106.webp)
(Umthombo wesithombe: [Imininingwane](/zu/licenses#lekt0106))
:::
Amadikshonari amanje e-Sanskrit ahlelwe ngokulandelana kwengqephu. Le ngqephu ayibalulekile ekutheni ukuqonda i-grammar ye-Sanskrit futhi ngakho-ke kumele ithathwe ngokukhumbula:

::: note-box
Ukuhlelwa
**izwi elilodwa** (samānākṣara -- ⟪समानाक्षर⟫):
⟪अ⟫ a, ⟪आ⟫ ā, ⟪इ⟫ i, ⟪ई⟫ ī, ⟪उ⟫ u, ⟪ऊ⟫ ū, ⟪ऋ⟫ ṛ, ⟪ॠ⟫ ṝ, ⟪ऌ⟫ ḷ
**Izwi eliphindwe kabili** (sandhyakṣara -- ⟪सन्ध्यक्षर⟫):
⟪ए⟫ e, ⟪ऐ⟫ ai, ⟪ओ⟫ o, ⟪औ⟫ au
**Izwi eliqinile** (vyañjana / hal -- ⟪व्यञ्जन⟫ / ⟪हल्⟫):
⟪क⟫ ka, ⟪ख⟫ kha, ⟪ग⟫ ga, ⟪घ⟫ gha, ⟪ङ⟫ ṅa
⟪च⟫ ca, ⟪छ⟫ cha, ⟪ज⟫ ja, ⟪झ⟫ jha, ⟪ञ⟫ ña
⟪ट⟫ ṭa, ⟪ठ⟫ ṭha, ⟪ड⟫ ḍa, ⟪ढ⟫ ḍha, ⟪ण⟫ ṇa
⟪त⟫ ta, ⟪थ⟫ tha, ⟪द⟫ da, ⟪ध⟫ dha, ⟪न⟫ na
⟪प⟫ pa, ⟪फ⟫ pha, ⟪ब⟫ ba, ⟪भ⟫ bha, ⟪म⟫ ma
⟪य⟫ ya, ⟪र⟫ ra, ⟪ल⟫ la, ⟪व⟫ va
⟪श⟫ śa, ⟪ष⟫ ṣa, ⟪स⟫ sa
⟪ह⟫ ha
:::
### 1.2.1. Ngokukhuluma kwelilungu ngalinye

::: laut-table
| Isilungu | Incazelo |
| :--- | :--- |
| **a - ⟪अ⟫** | "i-a emfushane" ivame ukukhulunywa ngama-Indiya -- kusukela ezikhathini zakudala -- njenge-ə. EYurophu, bayikhuluma njenge-a emfushane, eBengal njenge-o emnyama emfushane. |
| **ṛ - ⟪ऋ⟫** | njenge-r evokalizwe yaseBohemia. Ukunambitheka okuncane kwe-i. |
| **ṝ - ⟪ॠ⟫** | njenge-r evokalizwe yaseBohemia. Ukunambitheka okuncane kwe-u. |
| **jñ - ⟪ज्ञ्⟫** | futhi njenge-dny (i-Marāṭhī) noma i-gy (Ntshonalanga ye-Indiya). |
| **ś - ⟪श्⟫** | isilungu se-sch esinephethini yelungu elijikelezwe phansi. Kufana ne-sch ku-"mischen". |
| **ṣ - ⟪ष्⟫** | isilungu se-ach esinephethini yelungu elibuyiselwe emuva. Ngokuvamile kakhulu emuva emthunzini, okwenza kube sengathi kufana ne-kh. |
| **h - ⟪ह्⟫** | isilungu somoya, asikaze sibe uphawu lokwandisa. |
| **ḥ - :** | **Visarga (Visarjanīya)** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫. Isilungu somoya esingenamandla esinokunambitheka kwelilungu elandelayo noma ingxenye yesibili ye-diphthong ephambili: agniḥ -- ⟪अग्निः⟫ = agnihi, devaiḥ -- ⟪देवैः⟫ = devaihi, gauḥ -- ⟪गौः⟫ = gauhu |
| **ṃ** | **Anusvara** -- ⟪अनुस्वर⟫. Ngaphambi kwamasilungu e-z, h, l: ukunambitheka kwelilungu. Ekupheleni = m. Ngaphakathi ngaphambi kwamasilungu: inasal ehambisana nesilungu esilandelayo: saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
Ukukhuluma okuhle kakhulu kufinyelelwa uma ufunda izitatimende, imibhalo noma amagama kancane kancane nangokulinganayo, ngokucophelela ukuphila kwamasilungu.


## 1.3. Umzamo

**A) Funda lamagama alandelayo:**

1. varṇa brāhmaṇaḥ kṣatriya vaiśya śūdra — ⟪वर्ण ब्राह्मणः क्षत्रिय वैश्य शूद्र⟫
2. brahmā viṣṇu śiva — ⟪ब्रह्मा विष्णु शिव⟫
3. āśrama brāhmacārin gṛhastha vānaprastha saṃnyāsin — ⟪आश्रम ब्राह्मचारिन् गृहस्थ वानप्रस्थ संन्यासिन्⟫
4. ṛgveda sāmaveda yajurveda atharvaveda — ⟪ऋग्वेद सामवेद यजुर्वेद अथर्ववेद⟫
5. upaniṣad — ⟪उपनिषद्⟫
6. jaina bauddha — ⟪जैन बौद्ध⟫
7. prajñāpāramitā — ⟪प्रज्ञापारमिता⟫
8. cakra vajra — ⟪चक्र वज्र⟫
9. pitṝn — ⟪पितॄन्⟫
10. saṃskṛta — ⟪संस्कृत⟫
