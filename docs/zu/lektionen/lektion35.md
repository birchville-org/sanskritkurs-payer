# Isifundo 35

## 35.1. I-Perfekt Uhlobo III: Isisekelo esinamandla isigaba esiphakeme/isigaba eside

::: grammar-box
**Ukwakhiwa:**

**isisekelo esinamandla:**
*   3.sg.P: Isigaba eside
*   2.sg.P: Isigaba esiphakeme
*   1.sg.P: Isigaba esiphakeme noma isigaba eside ngokukhetha

**isisekelo esinobutho:** bheka ezinhlobo ezincane
:::
