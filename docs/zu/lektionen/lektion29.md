# Isifundo 29

## 29.1. Ukusetshenziswa kwe-Parasmaipada (⟪परस्मैपद⟫) ne-Ātmanepada (⟪आत्मनेपद⟫) ku-Kausativum


::: grammar-box

**I-Kausativ ivame ukuba yi-Ubayapada (⟪उभयपद⟫)**

:::

::: grammar-box

**Ku-Kausativum kusetshenziswa i-Ātmanepada (⟪आत्मनेपद⟫):**

**1. Uma umkhiqizo wesenzo esibangelwayo unentshisekelo yomcabangi:**

:::

Isibonelo:

⟪रामः कटं कारयते⟫ = "U-Rāma uyayalela ukuthi kwenziwe iphethini yaye (ngokwezintshisekelo zakhe)"

**2. Uma i-Kausativum yezenzo ezinentshukumo isetshenziswa ngendlela ye-reflexive ("ukuzibonisa", "ukuzivumela ukuthi zizweke", njll.), noma uma into yomphumela yenzelo elula iyi-Agens (⟪कर्तृ⟫) ye-Kausativ:**

Isibonelo:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "U-Viṣṇu ubonisa ukuthi uyabonakala emlandelayo wakhe"

Umphumela: ⟪भक्ता विष्णुं पश्यन्ति⟫ = "Abathembayo babona u-Viṣṇu"


Ngakho-ke, imithetho ihambisana nemithetho yokusetshenziswa kwe-Ātmanepada (⟪आत्मनेपद⟫) kwezilimi ze-Ubayapada (⟪उभयपद⟫).

## 29.3. Vertaal-oefening ter herhaling

Humusha ngokoqobo ngesiJalimane esihle futhi ubambe ngekhanda imibhalo yesiSanskrit:

1\. Definisie van ⟪अविद्या⟫ :

⟪अनित्याशुचिदुःखा⟫:sig[⟪नात्मसु⟫] ⟪नित्यशुचिसुखात्मख्यातिरविद्या ॥योगसूत्र २⟫.⟪५॥⟫

Incazelo: ⟪आत्मसु⟫ = Isimo sokwenzeka esisodwa se-⟪आत्मन्⟫ m. "umphefumulo; Okuphelele, njengoba kubonakala kumuntu ngamunye"

2\. ⟪कौटिलीयार्थशास्त्र⟫ 1.4. ngokusebenzisa kahle kuka- ⟪दण्ड⟫ :

⟪तीक्ष्णदण्डो भूताना⟫:sig[⟪मुद्वेजनीयो⟫] ⟪भवति ।८। मृदुदण्डः परिभूयते ।९। यथार्हदण्डः पूज्यते ।१०। सु⟫:sig[⟪विज्ञात⟫]⟪प्रणीतो हि दण्डः प्रजा धर्मार्थकामै⟫:sig[⟪र्योजयति⟫] ⟪।११। दुष्प्रणीतः⟫ :sig[⟪कामक्रोधाभ्याम⟫]⟪वज्ञानाद्वा वानप्रस्थपरिव्राजकानपि कोपयति⟫, :sig[⟪किमङ्ग⟫] ⟪पुनर्गृहस्थान् ।१२। अप्रणीतस्तु मात्स्यन्यायमुद्भावयति ।१३। बलीयान अबलं हि ग्रसते दण्डधराभावे ।१४। स तेन गुप्तः प्रभवतीति ।१५।⟫
