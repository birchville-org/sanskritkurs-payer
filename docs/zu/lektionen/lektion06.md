# Isifundo 6

## 6.1. Isitatimende se-verb

::: grammar-box

**Iskema I: Ifomu le-verb**
isb. **yajati** = ⟪यजति⟫ = "Uyabonga ngenikelo", "Uyenikela"

**Iskema II: Umsebenzisi (kartṛ m. = ⟪कर्तृ⟫) – Ifomu le-verb**
isb. **rāmo yajati** = ⟪रामो यजति⟫ = "U-Rāma uyabonga ngenikelo", "U-Rāma uyenikela"

:::

Uma umsebenzisi (**kartṛ** m. = ⟪कर्तृ⟫) ekhulunywa ngawo esitatimendeni se-verb esingeyona i-passive, umsebenzisi ubekwa ku-**Nominative** (isimo sokuqala, prathamā = ⟪प्रथमा⟫). Ngokwenani (inani, vacana n. = ⟪वचन⟫), umsebenzisi nefomu le-verb ziyahambisana.


## 6.2. Ngokwakhiwa kwama-verb forms

Ifomu le-verb elinamakhono, okungukuthi, ifomu le-verb elinokuphela kwabantu, libonisa okulandelayo eSanskrit:

1. **Incazelo** (**artha** m. ⟪अर्थ⟫)
2. **Umuntu** kanye **nenani** (inani, **vacana** n. = ⟪वचन⟫) (mina, wena, u-\<wena, u-\<yena\>, sonke ababili, nina ababili, bonke ababili, sonke, nina, bonke)
3. Indlela yokuziphatha (genus verbi):
1. **Parasmaipada** (n. = ⟪परस्मैपद⟫) ("Ifomu lezwi elinokubheka omunye"): I-Active. isb. **yajati** = ⟪यजति⟫ = "Uyabonga ngenikelo" (okungukuthi umphristi, ozenzisa inikelo komunye umuntu)
2. **Ātmanepada** (n. = ⟪आत्मनेपद⟫) ("Ifomu lezwi elinokubheka ukuzithandela"): I-Medium. isb. **yajate** = ⟪यजते⟫ = "Uyabonga ngenikelo esifundeni sakhe" (okungukuthi umnikeli, ozenzisa inikelo ngokwakhe nasekhayeni lakhe)
3. **Passive** (**karman** n. = ⟪कर्मन्⟫). isb. **ijyate** = ⟪इज्यते⟫ = "Kuyabongwa ngenikelo"

Ezimweni eziningi, ukwehluka kwesibalo se-Ātmanepada akunakubonakala; futhi, ababhali bezindaba abaningi basebenzisa i-Ātmanepada ngaphandle kokwehluka kwesibalo ku-Parasmaipada. Noma kunjalo, ekuthumeleni, kufanele uqaphele ngokucophelela ukuthi ingabe kukhona ukwehluka kwesibalo.

Izibalo ezisebenziswa ku-Parasmaipada kanye ne-Ātmanepada (ngendlela ekhethekile ye-Ātmanepada) zibizwa ngokuthi **Ubhayapada** (**ubhayapada** n. = ⟪उभयपद⟫ = "izimo zombili zamazwi").

Ezinye izibalo zisebenziswa noma kuphela ku-Parasmaipada noma kuphela ku-Ātmanepada. Kulezi zibalo, i-Ātmanepada noma i-Parasmaipada ayinayo indlela ekhethekile yokusho. Isib. **manyate** = ⟪मन्यते⟫ = "uyacabanga" (ngaphandle kwencazelo ekhethekile ye-Ātmanepada).

4. **Indlela yokusho** (Indlela):
1. **Indikativ**: Indlela yokusho
2. **Optativ**: Indlela yokukhuleka kanye nendlela yokukwazi
3. **Imperativ**: Indlela yomyalo
5. **Isikhathi** (Isikhathi):
1. **Präsens**: Manje
2. **Imperfekt**
3. **Perfekt**
4. **Aorist**
5. **Futur**: Izizukulwane
6. **Konditional**

Izikhathi zakhiwa ngamasimu esikhathi: isimu sika-Präsens, isimu sika-Aorist, isimu sika-Perfekt, isimu sika-Futur.

## 6.7. Ubuluhlu bamagama

::: grammar-box

E-Sanskrit, izenzo ziboniswa nge-**Fomu yemvelo**. Inombolo emva kwemvelo imele i-**Iqela lokuguquguquka**.

**P:** Imvelo i-Parasmaipada kuphela
**Ā:** Imvelo i-Ātmanepada kuphela
**U:** Ubhayapada ("zombini izimo zomzobo"): Imvelo isetshenziswa ku-Parasmaipada nakwi-Ātmanepada.
**():** Ngaphakathi kwesibhakabhaka kubhalwe i-3rd person singular present indicative (laṭ).

:::

**Funda lamagama alandelayo:**
**yaj** 1 U (yajati) ⟪यज् यजति⟫ : ukunikezela ngenkosi, ukunikeza
