## 44.2. Ngokuthinta kwamagama

Ezimeni lapho amagugu e-present ashoda ngezwiqephu, imithetho ethinta amagama esele isifundiswe kufanele ilandelwe.

Ngaphezu kwalokho, imithetho elandelayo yethinta amagama isetshenziswa.

(Ukuhlanganiswa okuningiliziwe konke okuhlobene nokuguquka kwelizwi kulapha ku-Kielhorn, Grammar p. 76f.)

### 44.2.1. Ngokuthinta kwamagama ku-dh-

::: grammar-box

1. **I-aspirate iboshwa yi-aspirate ngokufanayo ngokungaphansi kwayo:**
isib. ⟪रुध्⟫ 7U: ⟪रुन्ध्⟫ + ⟪ध्वे⟫ » ⟪रुन्द्ध्वे⟫ (run**ddh**ve)
2. **-h + dh- » -gdh-**
isib. ⟪दुह्⟫ 2U: ⟪दुह्⟫ + ⟪ध्वे⟫ » ⟪धुग्ध्वे⟫ (dhu**gdh**ve)
3. **-ṣ + dh- » -ḍḍh-** (Lolu hlobo lusebenza kuphela ku-conjugation!)
isib. ⟪द्विष्⟫ 2U: ⟪द्विष्⟫ + ⟪ध्वे⟫ » ⟪द्विड्ढ्वे⟫ (dvi**ḍḍh**ve)
4. **-s + dh- » -dh-** (Ukukhishwa kwe--s)
isib. ⟪आस्⟫ 2Ā: ⟪आस्⟫ + ⟪ध्वे⟫ » ⟪आध्वे⟫ (ādhve)

:::

### 44.2.2. Ngokuthinta kwamagama ku-s-

::: grammar-box

1. **-s + s- » -ts- noma (hhayi okukhethwayo!) -ss-** (njengoba kusebenza ku-2nd present class)
Izibonelo:
* ⟪वस्⟫ 1P: Future: ⟪वस्⟫ + ⟪स्य⟫ + ⟪ति⟫ » ⟪वत्स्यति⟫ (va**ts**yati)
* ⟪वस्⟫ 2Ā: ⟪वस्⟫ + ⟪से⟫ » ⟪वस्से⟫ (va**ss**e)
2. **-ṣ + s- » -kṣ-**
isib. ⟪द्विष्⟫ 2U: ⟪द्वेष्⟫ + ⟪सि⟫ » ⟪द्वेक्षि⟫ (dve**kṣ**i)

:::

## 44.4. I-Vocative (⟪आमन्त्रितम्⟫)

Abakwa-grammatikali abasekhaya ababoni i-Vocative (⟪आमन्त्रितम्⟫) njenge-case eyodwa, kodwa njengokuguquguquka kwe-Nominative (⟪प्रथमा⟫) kuphela.

::: important

**I-Vocative isetshenziselwa ukubiza, ukukhuluma, futhi ingaphandle kwesixhumanisi somzuzu, ngakho-ke ihlukile kwezinye izigaba eziveza ubudlelwano ne-verb noma igama elinye.**

**Ngokuvamile, i-Vocative ibekwa ekuqaleni komzuzu:**

:::

::: indent

⟪बाल किं वदसि⟫ = "Ingane, uthini?"

:::

::: important

**Qinisekisa ukuthi ungaguquki i-Vocative nge- "O ...". Sisebenzisa i-Vocative ngokuphelele ngesiJalimane, uma sibheka: "Siyabonga, singadla ini namuhla?". Akukho muntu ozokhuluma ngalolu hlobo: "**O** Siyabonga, singadla ini namuhla?**

:::
