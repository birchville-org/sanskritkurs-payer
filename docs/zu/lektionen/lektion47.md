# Isifundo 47

## 47.1. I-Imperative (⟪लोट्⟫)

::: grammar-box
I-Imperative (⟪लोट्⟫) zithumisa

*   **Umyalo** (futhi ingachazwa nge-Gerundive (⟪कृत्य⟫))
*   **Umthetho**
*   **Isicelo**
*   **Ukuthanda**
*   **Ukubiza**
*   **Ukucabanga**
*   **Umbuzo**
*   **Frage**

Lezi zinhlobo zokusho zihlanganiswa ne-Optative (⟪विधिलिङ्⟫).

Ngokusebenzisa i-Imperative, singachaza futhi:

*   **Uvumelekile**
*   **ukuthi isenzo sesikhathi** (futhi singachazwa nge-Gerundive (⟪कृत्य⟫))
*   **Ukuthanda ukupha isibusiso**
:::
Izibonelo:

::: indent
⟪एहि ।⟫ "Za!"

⟪ग्रामं भवानागच्छतु ।⟫ noma i-Optative: ⟪ग्रामं भवानगच्छेत् ।⟫ "Zani edolobheni!"

⟪वेदमध्ययै ।⟫ noma i-Optative: ⟪वेदमधीयीय ।⟫ "Ngifuna ukufunda i-Veda."

⟪इच्छामि भुङ्क्तां भवान् ।⟫ noma i-Optative: ⟪इच्छामि भुञ्जीत भवान् ।⟫ "Ngifuna ukuthi bade."

⟪किं वेदमध्ययै ।⟫ noma i-Optative: ⟪किं वेदमधीयीय ।⟫ "Ingabe ngifanele ukufunda i-Veda?"

⟪करोतु शस्त्रं भवान् ।⟫ noma i-Gerundive: ⟪भवता शस्त्रं कर्तव्यम् ।⟫ "Yenza isihlangu!" ; "Uvumelekile ukwenza isihlangu." ; "Isikhathi sesikhathi ukuthi wenze isihlangu."

⟪चिरं जीवतु भवान् ।⟫ "Uphile isikhathi eside!"
:::
::: grammar-box
Imiyalo ethobekile ivame ukuchazwa nge-Passive-Imperatives.
:::
Izibonelo:

::: indent
⟪भवता प्रविश्यताम् ।⟫ "Ngenisa **ngicela**!"

⟪निषद्यताम् ।⟫ "Ngicela, hlala!"
:::
Ku-Imperative ye-Sanskrit yasekamu, izimo zama-1st persons yizimo zangaphambili ze-Subjunctive. I-Vedic Subjunctive ikakhulukazi i-Modus ekhombisa ukuthanda: "Sifuna ukuhamba!" "Ake sihambe!"

::: grammar-box
I-Imperative yakhiqwa ngokusebenzisa isisekelo se-prezent.
:::

## 47.3. Imisebenzi

A) Guquka:

⟪यदि गच्छसि गच्छ त्वम् । अहं न गमिष्यामि ॥१॥ आर्य प्रेक्षस्व मे परिभवम् ॥२॥ भो राम यदि मया गन्तव्यं तदैषा कन्यापि मम सहायिनी भवतु ॥३॥⟫
