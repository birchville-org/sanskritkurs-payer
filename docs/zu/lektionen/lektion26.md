# Isifundo 26

## 26.1. Umthetho we-cerebralisations we- -s- ngaphakathi kwamagama

::: grammar-box
**-s-** ithathwa ndawo **-ṣ-**, uma **k, r, l** noma **voweli** — ngaphandle **a, ā** — ilandela ngqo noma kuphela ngokuhlukaniswa ⟪अनुस्वार⟫ noma ⟪विसर्ग⟫ futhi ilandela elinye ilizwi ngaphandle **ṛ, r**.

Lo Sandhi ulandela futhi **⟪दुस्⟫-** ngaphambi kwe-Guttural engenasandi ne-Labial ku-composita.
:::
*Izibonelo:*
::: indent
⟪तेषाम्⟫ (kusuka: *te-sām*)

kodwa: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. Umthetho we-cerebralisations we-Dental ngaphakathi kwamagama

::: grammar-box
Ama-Dental oclosure ashintshwa ngama-Retroflex afanayo ngemuva kwe-Retroflex (kuhlanganise **-ṣ-**):

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** ngenxa ye-**i** elandelayo, **ṭh** ngenxa ye-**ṣ** elandelayo)*
:::
## 26.3. Wortsandhi we-Palatal, Guttural, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

Bona izibonelo ngezansi
:::
## 26.4. Umthetho we-Grassmann we-Hauchdissimilation

## 26.6. Ukusetshenziswa kwesikhathi esilula esizayo (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**Isikhathi esilula esizayo (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) sibonisa:**

**izikhathi ezizayo**
**isenzo elinqunyiwe noma elifunwayo ("ngiya kuya", "ngifuna ukuhamba")**
**ukulindeleka ("kuzenzeka kanjalo")**
**ukuthemba**
**ukwesaba**
**ukunambitheka**
**ukubuka komkhulumi**
**uyalo**

**Isikhathi esizayo sisebenzisana ngokwengxenye ne-Optative (buka kamuva).**

## 26.7. Ukwakhiwa kwesikhathi esilula esizayo (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box

:::
::: grammar-box
**Isisekelo se-Future:**

:::
::: indent
**(okuvamile) impande ephezulu + -sya**  
**noma**

**Kumele ufunde ngokufunda ukuthi yimuphi umphandle onayo ukwakhiwa kwesisekelo se-Future!**

**Kunzima ukuthi imiphandle engeke yakhe i-Future ngaphandle kwe-vowel yokubopha -i-.**
