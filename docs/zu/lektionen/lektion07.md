## 7.3. Sandhi ka-n ophumayo

::: grammar-box
**-n ophumayo:**

1. Ngaphambi kwe-palatal ne-retroflex sparśi ezinamandla nangaphambi kuka-**ś-** kufaka indawo yalo mufanekiso:
**-n** ngaphambi kuka-**j-, jh-, ñ-, ś-** » **-ñ**
**-n** ngaphambi kuka-**ḍ-, ḍh-, ṇ-, ṣ-** » **-ṇ**
isib. **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "Uyaphumelela ama-Kṣatriya."
U-**ś-** olungaphambili luwafaka ngokuvamile u-**ch-**:
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (ngaphezu kuka-gurūñ śṛṇoti) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "Uyavuma abafundisi." "Uyavuma abafundisi."

2. Uma kuvela u-**l-** ngaphambi kwe-**l-** ene-Anunāsika (u-l onasali, ebhalweni ⟪ल्⟫ ene-Anunāsika ⟪ँ⟫) kufaka indawo:
isib. **paśūn + labhate** » ⟪पशूंल्लभते⟫ : "Uthola izilwane zokusebenza."

3. Ngaphambi kwe-palatal, retroflex noma dental engenasandi ekuqaleni, kufaka indawo **Anusvāra** + umsindo ophumayo ohambisana nalawo mazwi:
**-n** ngaphambi kwe-**c-, ch-** » **-ṃś**
**-n** ngaphambi kwe-**ṭ-, ṭh-** » **-ṃṣ**
**-n** ngaphambi kwe-**t-, th-** » **-ṃs**
isib. **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : "futhi izinkosi (Akk.)"
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : "kodwa izinkosi (Akk.)"

4. Ngaphandle kokulandela isyllable emfushane (buka kamuva), u-**n** ophumayo uhlala ungashintshi kuzo zonke ezinye izimo.
:::

## 7.5. Izinkathi ze-Präsens ezingenasandi

I-5th Präsens class yakha okubizwa ngokuthi yi-athematic Präsens stem, okusho ukuthi i-Präsens stem ayipheli ngokufana nezinkathi ze-Präsens ezinesandi (1., 4., 6., 10. class) nge-"vowel theme" **-a**.

::: grammar-box
**Izinkathi ze-Präsens ezingenasandi zinezinto ezimbili zokuphela, okusho ukuthi kunemifanekiso emibili ye-Präsens stem:**
1. **isemandla**: isigaba esiphezulu (kuyinto ejwayelekile ukuthi ibe yisigaba esikhulu)
2. **isemandla**: isigaba esiphansi

**Isiqinisekiso esinamandla sime:**
ku-Indikativ Singular Parasmaipada Präsens (laṭ) kanye ne-Imperfekt (laṅ)
zonke izindawo zokuqala ze-Imperativ (loṭ) Parasmaipada kanye ne-Ātmanepada
kwisimo sesithathu singular Imperativ (loṭ) Parasmaipada

**Zonke ezinye izimo zinomsuka we-Präsens obuthathayo.**
:::
### 7.5.1. Iziphetho zokuqala zezindawo zesithathu plural kumasuka angaphandle kwe-athematic

::: grammar-box
