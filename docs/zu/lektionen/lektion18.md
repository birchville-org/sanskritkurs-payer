### 18.2.2. Izincazelo ze-nañ-Tatpuruṣa (a- / an-)

I-Tatpuruṣa ene-a- / an- ingaba nezincazelo ezilandelayo:

1. Ufaniso (⟪तत्सादृश्यम्⟫):
⟪अब्राह्मणः⟫ = u-Kṣatriya noma u-Vaiśya obheke umqulu oyingcwe (⟪यज्ञोपवीत⟫ n.) futhi ngalokho ufana no-Brahman, kodwa akasoze abe ngu-Brahman
2. Ukuntula, ukungabikho (⟪तदभावः⟫):
⟪अज्ञानम्⟫ = ukungazi (ukuntula ulwazi)
3. Uhlukahlukana (⟪तदन्यत्वम्⟫):
⟪अपटम्⟫ = into engengowesitofu / ingubo (⟪पट⟫ m: ubucwebe, ingubo)
4. Ukuncipha (⟪तदल्पता⟫):
⟪अनुदरम्⟫ = isisu esincane (isisu esingeyona)
5. Ukungavumi (⟪अप्राशास्त्यम्⟫):
⟪अकालः⟫ = isikhathi esingafanele
6. Uhlazo (⟪निरोधः⟫):
⟪असुरः⟫ = uNkulunkulu ophikisayo (ngokwencazelo engalungile a-sura)

Umlandeli versihlaba lezi zinhloko:

::: indent

⟪तत्सादृश्यमभावश्च तदन्यत्वं तदल्पता । अप्राशास्त्यं निरोधश्च नजर्थाः षट्प्रकीर्तिताः ॥⟫

:::

## 18.3. Verbalkomposita

:::

⟪चन्द्रकीर्ति⟫ : ⟪प्रसन्नपदा⟫ S. 2 Zl. 14f.

Ngokusebenzisa i-preverb, isimo se-root siyashintshwa ngokudabukisayo, njengokuhle zamanzi e-Ganges ngamanzi olwandle.

::: grammar-box

Izibalo zingaxhunywa ne-preverbs (⟪उपसर्ग⟫ m.) e-Sanskrit. Ngokuvamile, i-sandhi yesitatimende isebenza. Izibalo zingashintsha isimo se-root ngokukhulu, ngakho-ke ezimweni eziningi, isimo se-root ne-preverb kufanele zifundwe ngokuhlukile. Izibalo ezine-preverb zingaba ne-modus (P, Ā) ehlukile kunaleyo ye-root elula. Ngaphambi kwe-root, izibalo eziningi zingabekwa ngasikhathi sinye.

:::
