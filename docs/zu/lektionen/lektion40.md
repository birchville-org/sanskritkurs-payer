## 40.2. Ukwakhiwa kwemifanekiso yezenzo yomuntu wokuqala we-Perfekt (⟪लिट्⟫)

Iziphetho zomuntu wokuqala (⟪तृतीयः⟫) ku-Perfekt (⟪लिट्⟫)

::: grammar-box

| ⟪परस्मैपदम्⟫ | ← | ⟪आत्मनेपदम्⟫ | ← |
| :---: | :---: | :---: | :---: |
| ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **-a** | **-ma** | **-e** | **-mahe** |

:::

::: grammar-box

Qaphela ukuthi iziphetho zomuntu wokuqala we-singular P,Ā ziyafana nezomuntu wesithathu we-singular. Ngakho-ke, kuzo zonke izinhlobo ze-Perfekt ngaphandle kwe-Typ III(a,b) ne-Typ V(a,b,c), imifanekiso yomuntu wokuqala we-singular P noma Ā ihlale ifana nezomuntu wesithathu we-singular P noma Ā.

Ku-Typ IV, u-1. sg. P uqeda njengo-3.sg.P ngo- -au.

Kuzinhlobo ze-Perfekt III ne-V, u-1. Singular Ā uhlale ufana no-3. Singular Ā.

Kuzinhlobo ze-Perfekt III ne-V, u-1. Singular P no-3. Singular P bangafana ngokukhetha: i-3.sg.P kufanele ibe ne-grade elandelayo (dehnstufig) kuzi-Typ zokwakha, i-1.sg.P ingaba ne-grade ephezulu (hochstufig) noma elandelayo (dehnstufig) ngokukhetha.

:::

::: grammar-box

Ngaphambi kokuthi amaphethini aqala nge-consonant, uvokali wokuxhumanisa -i- uvame ukubonakala emakhulwini amaningi.

Ngaphandle kokuba ngaphambi kophethini -re, lapho -i- kufanele kube khona njalo, okuyinto evokali wokuxhumanisa engabonakali ngaphambi kokuthi amaphethini aqala nge-consonant, ibonakala emakhulwini amane aphethini aqeda nge-ṛ noma -u, okungukuthi

1.  ⟪कृ⟫ 8U (ngaphandle ⟪संस्कृ⟫)
2.  ⟪भृ⟫ 1U
3.  ⟪वृ⟫ 9U "khetha"
4.  ⟪सृ⟫ 1P
5.  ⟪द्रु⟫ 1p "qhubeka"
6.  ⟪श्रु⟫ 5P
7.  ⟪स्तु⟫ 2U
8.  ⟪स्रु⟫ 1P "hamba"

Emakhulwini aqondene ne-⟪अनिट्⟫-roots, uvokali wokuxhumanisa ungafakwa noma ungafakwa. (Uluhlu lwalezi zimpande ku-Kielhorn, Grammar p. 92 § 298b,2,3)

:::

## 40.3. Ukwakhiwa kwemifanekiso yezibopho yomuntu wokuqala we-periphrastic perfect (⟪अनुप्रयोगलिट्⟫)

I-periphrastic perfect yakhiwa ngokuthi:

*   amagatsha ezibopho ezithuthukisiweyo (Kausativ, Desiderativ, Frequentativ, Denominativa), ikakhulukazi Kausativ
*   izimpande, eziqala ngevokal ephezulu (ngaphandle kuka-ā)
*   izimpande: Vokal (ngaphandle kuka-a)-Konsonant-Konsonant
*   ezinye ezimbalwa
*   ezimbalwa izimpande zingakhiwa zombili izakhiwo ze-periphrastic ngokukhetha: uṣ "ukushisa", vid "ukwazi", jāgṛ "ukuvuka", daridrā "ukuba nomkhuhlane"
*   ezilandelayo izimpande zingakhiwa zombili izakhiwo ze-periphrastic ngokukhetha futhi i-periphrastic perfect iyabhalwa, ngokwesibalo se-reduplication yepresens stem:
*   bhī "ukwesaba"
*   bhṛ "ukuthwala"
*   hu "ukunikeza"
*   hrī "ukuzizwa ngokungahlelekile"

## 40.4. Ngokwesakhiwo ngephuphumo lokuqala (⟪तृतीयः⟫)

::: grammar-box

Njengoba isenzo esiguqukayo (isenzo esiguqukayo) sibonisa umenzi (⟪कर्तृ⟫), akudingeki ukuthi "mina", "sina" kusetshenziswe ngokukhethekile ngesiphoqo somuntu ngokomuntu kumazwi angena ngokuphambana noma anesenzo esiguqukayo

:::

## 40.5. Izifiso zomuntu (⟪पुरुषार्थकसर्वनाम⟫) zophuphumo lokuqala lwe-singular ne-plural

::: grammar-box

Ifomu lesifiso somuntu (isifiso somuntu) lifana kuzo zonke izilimi.

:::

::: grammar-box

| | ⟪एकवचनम्⟫ :br"mina" | ⟪बहुवचनम्⟫ :br"sina" |
| :---: | :---: | :---: |
| ⟪प्रथमा⟫ | ⟪अहम्⟫ | ⟪वयम्⟫ |
| ⟪द्वितीया⟫ | ⟪माम्⟫ / ⟪मा⟫ | ⟪अस्मान्⟫ / ⟪नस्⟫ |
| ⟪तृतीया⟫ | ⟪मया⟫ | ⟪अस्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪मह्यम्⟫ / ⟪मे⟫ | ⟪अस्मभ्यम्⟫ / ⟪नस्⟫ |
| ⟪पञ्चमी⟫ | ⟪मत्⟫ | ⟪अस्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪मम⟫ / ⟪मे⟫ | ⟪अस्माकम्⟫ / ⟪नस्⟫ |
| ⟪सप्तमी⟫ | ⟪मयि⟫ | ⟪अस्मासु⟫ |

:::

::: grammar-box

Amafomu amafuphi, akhona endaweni yesibili (⟪मा⟫, ⟪मे⟫, ⟪नस्⟫) awavumelekile ukusetshenziswa ekuqaleni kwesitatimende noma ingoma.

Ngaphambi kwezinto ezifana ⟪च⟫, ⟪वा⟫, ⟪एव⟫, lezi zinto ezifana ne-enclitic azivumelekile ukusetshenziswa:

kuphela: ... ⟪मां च⟫ ... "nami"

:::

::: grammar-box

I-genitive (⟪षष्ठी⟫) yezifiso zomuntu isetshenziswa njengesifiso somuntu:

⟪मम । मे⟫ = "wami"

⟪अस्माकम् । नस्⟫ = "wethu"

:::

::: grammar-box

Njengengxenye yokuqala yezinto ezihlanganisiwe, lezi zifiso zomuntu zisebenzisa izimpande:

*   sg. ⟪मद्⟫
*   pl. ⟪अस्मद्⟫

z.B. ⟪मत्पुस्तकम्⟫ "mein Buch" ; ⟪अस्मद्पुस्तकानि⟫ "unsere Bücher"

:::
