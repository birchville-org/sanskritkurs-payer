# Isifundo 2


## 2.1. Isitatimende Esinomphumela

::: grammar-box
**Isakhiwo: Isinomphumela Esinomphumela - Isiphumeli**

isib. devo viṣṇuḥ = ⟪देवो विष्णुः⟫ = "U-Vishnu unkulunkulu."
:::
Akudingeki ukuthi kube khona i-copula yomphumela ("ukuba", "baya", "ngiyakuba", "wakuba", "ninye"), kodwa ingase ibe khona ngamanye amaxesha.

Akukho **amagama aphambili**: **devaḥ** -- ⟪देवः⟫ ingasho "umkulunkulu" noma "umculi."

Nakuba eSanskrit ukulandelana kwamasimu kuyakhululeka kakhulu (ikakhulukazi emaculweni), kufanele uqaphele ukuthi lapho ukumaphela isitatimende esinomphumela, kufanele uqaphele ukuthi kufanele ukumaphela ngokwesakhiwo esijwayelekile esingentla.

Esitatimendeni esinomphumela, isiphumeli siba yi-Nominative (isimo sokuqala = **prathamā** f. = ⟪प्रथमा⟫). Isinomphumela esinomphumela siyafana nesiphumeli ngokwenani nesimo; uma isinomphumela esinomphumela li-adjective, futhi ngokobulili.


## 2.2. Ngokwe-declination (Ukuguqulwa kwama-nomina)

E-Sanskrit kukhona:

**amanani amathathu** (amafomu okubala) = **vacana** n. -- ⟪वचन⟫
Singular (inani elilodwa) = **ekavacana** n. -- ⟪एकवचन⟫
Dual (inani elibili) = **dvivacana** n. -- ⟪द्विवचन⟫
Plural (amanani amaningi) = **bahuvacana** n. -- ⟪बहुवचन⟫
**izinto ezintathu** (izinto zomphumela) = **liṅga** n. / **vyakti** f. -- ⟪लिङ्ग⟫ / ⟪व्यक्ति⟫
Masculine (indoda) = **puṃs** m. -- ⟪पुंस्⟫
Feminine (umfazi) = **strī** f. -- ⟪स्त्री⟫
Neuter (into) = **napuṃsaka** n. -- ⟪नपुंसक⟫
**amasiko amasishiyagalombili** (amasiko) = **sup** -- ⟪सुप्⟫ (= amagama amaphela)

Ukwe-declination kufaka amagama amaphela (**sup** = ⟪सुप्⟫) kumagama abizwa ngokuthi **isigaba esinomphumela** (ifomu lenoma elingena amagama amaphela).

Isibonelo: **devas** = ⟪देवस्⟫ (Nominative Singular Masculine) "umunye/ukunye uNkulunkulu" = **deva-** -- ⟪देव⟫- (isisekelo se-noun) + **-s** -- -⟪स्⟫ (isiphetho se-case).

Ezincwadini zezigaba zesiSanskrit, izigaba zezigama ziboniswa ngokusekelwe **isisekelo se-noun**:
**deva** m. -- ⟪देव⟫ m. (masculine)
**vacana** n. -- ⟪वचन⟫ n. (neuter)
**vyakti** f. -- ⟪व्यक्ति⟫ f. (feminine)


## 2.3. I-Nominative Singular

**I-Nominative Singular iphetha ngo--s = -⟪स्⟫ noma ayinayo isiphetho.**

### 2.3.1. I-Nominative Singular iphetha ngo--s

Lezi zisekelo ze-noun eziphetha ngevowel, zakha i-Nominative Singular ngo--**s**:

::: grammar-box
**Amasculine aphetha ngo--a:** isib. deva m. = ⟪देव⟫ "uNkulunkulu" -- Nom. sg.: devas = ⟪देवस्⟫
**Amasculine aphetha ngo--i:** isib. kavi m. = ⟪कवि⟫ "umculi" -- Nom. sg.: kavis = ⟪कविस्⟫

:::

## 2.4. I-Sandhi -- ⟪सन्धि⟫

Ekuphetheni kwesigama kuncike nakwi-Sanskrit ngokwesiqalo sesigama esilandelayo. Lokhu kubizwa ngokuthi **I-Sandhi** (m.) = ⟪सन्धि⟫ ("ukuhlanganiswa").

### 2.4.1. I-Sandhi yoku--s okuphethayo

Bona futhi isifinyezo:

> **Payer, Alois (1944–):** I-Sandhi yoku--s okuphethayo. -- (Izinto zesiSanskrit). -- URL: http://www.payer.de/sanskritmaterialien/ssandhi.htm

Okuphethayo **-s**:

**ekuphetheni okuphelele** (ukuphetha kwesitatimende) kuba **Visarga (-ḥ)**:
**devas** = ⟪देवस्⟫ » **devaḥ** = ⟪देवः⟫
**kavis** = ⟪कविस्⟫ » **kaviḥ** = ⟪कविः⟫
**gurus** = ⟪गुरुस्⟫ » **guruḥ** = ⟪गुरुः⟫

**ngaphambi kwezinsimbi ezingenasandi**:
ngaphambi kwe-**k, kh, p, ph** kanye ne-**ś, ṣ, s**: iba ngu-**Visarga (-ḥ)**
**devas + śivaḥ** » **devaḥ śivaḥ** = ⟪देवः शिवः⟫ ("u-Śiva unkulunkulu")
ngaphambi kwe-**c, ch**: iba ngu--**ś**
ngaphambi kwe-**ṭ, ṭh**: iba ngu--**ṣ**
ngaphambi kwe-**t, th**: ihlala ngu--**s**
**sādhus + caitanyas** » **sādhuś caitanyaḥ** = ⟪साधुश्चैतन्यः⟫ ("u-Caitanya ungcwe")

**ngaphambi kwezinsimbi ezinesandi**:
emva kwezi-vokali ezingu-a: iba ngu--**r**
**kavis + Māghas** » **kavir māghaḥ** = ⟪कविर्माघः⟫ ("u-Māgha umbhali")
emva kwezi-vokali ezingu-a ngaphambi kwe-**r-**: u-**s** uyanyamalala, i-vokali iyandiswa.
**gurus + rāmas** » **gurū rāmaḥ** = ⟪गुरू रामः⟫ ("u-Rāma uthisha")
emva kwe-**a-**: **-as**
ngaphambi kwezinsimbi ezinesandi/a: iba ngu--**o** (u-a oqalayo uyanyamalala » ⟪ऽ⟫)
**devas viṣṇus** » **devo viṣṇuḥ** = ⟪देवो विष्णुः⟫
**devas agnis** » **devo 'gniḥ** = ⟪देवो ऽग्निः⟫
ngaphambi kwezinye izivokali: iba ngu--**a** (Hiatus)
**devas + indras** » **deva indraḥ** = ⟪देव इन्द्रः⟫

La maqembu amathathu agqoka ukugqoka kwalo mqembu. Ngaphezu kwala maqembu -- okuchazwe njengokufunwa uNkulunkulu -- uKristu uhlala esihlalweni sokuphatha.

UMax Weber (1864–1920) uchaza iqembu kanje:

::: note-box
»**Iqembu**« kumele libe yisibalo sabantu abasebenzayo
a) ukunikezwa okukhethekile kwamaqembu, - mhlawumbe
b) ukusebenzisa amamopholi amakhethiwe emaqenjini.

Izindima zingavela
a) zokuqala, ngokuziphatha kwendima yazo, okuhlanganisa ikakhulukazi indlela **yomsebenzi** (**izindima zokuziphatha noma zomsebenzi**),
b) zokwesibili, ezinokhokho abanezibongo, ngokuphumelela ekufuneni indima yabo ngokwezinga **zokuzalwa** (**izindima zokuzalwa**),
c) ngokuthatha **amandla** ezopolitiki noma ezingokomoya njengamamopholi ngezindima (**izindima zezopolitiki noma ezingokomoya**).

Ukuthuthuka kwezindima zokuzalwa kuvame ukuba yifomu yokuthatha amaphimbo (okhokho) kumbuthano noma kwabanye abaneziqu. Ukuthatha okunamandla izindlela, ikakhulukazi [zokuthatha] amandla [noma izindlela zokuziphila], kuyavumela ukwakheka kwezindima. Ukwakheka kwezindima kuyavumela ukuthathwa kwamamopholi amandla ezopolitiki noma izindlela zokuziphila.

Ngenkathi izigaba zokuziphila zikhula ngasemoyeni wemakethe, izindima zivame ukwakheka ngasemoyeni wamamopholi noma wemfundo yezindima noma yezindima zokuzalwa.

»**Izindima**« kufanele kube yisimo lapho ukwakheka kwesizwe kuyakhelwa izindima, »**izigaba**«, lapho ukwakheka kwesizwe kuyakhelwa izigaba. I »**indima**« isondelene kakhulu ne »**isigaba**« esizinzile, i »**isigaba**« esizinzile sisondele kakhulu. Izindima zivame ukwakheka ngokuthatha izigaba zokuziphila.

Yonke indima yezindima iyakhelwa izindlela zokuziphila, ikakhulukazi izindlela zokuziphila, ngakho-ke ikhiqiza izimo zokuziphila ezingezona ezokuziphila futhi ivimbela ukwakheka kwemakethe ngokuthatha amamopholi noma ngokukhipha izindlela zokuziphila.

:::

## 2.6. Ukuzivocavoca

**A) Faka ngokubheka i-Sandhi bese wakha amasentensi e-Nominal:**

1. **devas ... (Śiva, Agni, Viṣṇu, Gaṇeśa, Kṛṣṇa, Indra)**
= ⟪देवस्⟫ ... (⟪शिव⟫, ⟪अग्नि⟫, ⟪विष्णु⟫, ⟪गणेश⟫, ⟪कृष्ण⟫, ⟪इन्द्र⟫)
2. **dvijas ... (brāhmaṇa, kṣatriya, vaiśya)**
= ⟪द्विजस्⟫ ... (⟪ब्राह्मण⟫, ⟪क्षत्रिय⟫, ⟪वैश्य⟫)
3. **gurus ... (brāhmaṇa, Candrakīrti)**
= ⟪गुरुस्⟫ ... (⟪ब्राह्मण⟫, ⟪चन्द्रकीर्ति⟫)
4. **vaiśyas ... (Tulādhara)**
= ⟪वैश्यस्⟫ ... (⟪तुलाधर⟫)
5. **sādhus ... (guru, Rāma)**
= ⟪साधुस्⟫ ... (⟪गुरु⟫, ⟪राम⟫)
6. **kavis ... (Kālidāsa, Māgha, Bhāravi, Harṣadeva)**
= ⟪कविस्⟫ ... (⟪कालिदास⟫, ⟪माघ⟫, ⟪भारवि⟫, ⟪हर्षदेव⟫)
