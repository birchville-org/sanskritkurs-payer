# Isifundo 10

## 10.1. Isitatimendi se-Passive

::: grammar-box

**Isakhiwo:**
**(Umzenzi - kartṛ - nge-Instrumentalis (tṛtīyā)) - (into ebujwayele - karman - nge-Nominativ) - ifomu le-verb eliphathivu**

isib. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "UMbrahman uqhuba uNkulunkulu ngenikelo" (ngqo: "UNkulunkulu uqhubwa uMbrahman ngenikelo.")

Lesi sitatimendi **sifana ngokuphelele (!)** nesitatimendi:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫

:::

::: grammar-box

Esitatimendini se-passive, umzenzi (**kartṛ**) use-**Instrumentalis** (tṛtīyā f. "ukugqamisa kwesithathu"), into ebujwayele (**karman** n.) i-**Nominativ** (prathamā f.).
Izitatimendi ze-passive lapho umzenzi engachazwanga, zivame ukuba nencazelo engenaso isibizo ("umuntu"):
isib. **ijyate** = ⟪इज्यते⟫ "Kunikelwa" (ngqo: "kuqhubwa ngenikelo").

:::

::: grammar-box

**Nakuba isitatimendi esihambisanayo se-Active singaba ne-Accusative (dvitīyā) yento, lesi singabekwa ku-Nominativ (prathamā) esitatimendini se-passive:**

Esitatimendini se-Active **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "URāma uya esigodlweni." kufana nezitatimendi ze-passive:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
ngokungafani: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫

:::

::: grammar-box

**Amaphethini angena-objekti (amaphethini angena-objekti) avame ukuba nezakhiwo ze-passive, ikakhulukazi ezicelo ezihloniphekile:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "Kungena = Sicela ungene = Ngena!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "Kungahlala = Sicela uhlale = Sicela uhlale

:::

Izakhiwo ze-Sanskrit zokusebenzisa i-passive zivame kakhulu: ngempela, kulula ukwakha i-passive kunokuthi, isibonelo, izimpande eziningi ze-présent.

::: important

**Amasentensi e-passive e-Sanskrit ngokuvamile angaphindwa ngamasentensi e-passive ngesiJalimane, ngoba i-passive yesiJalimane inendima yesitayela ehlukile ngokuphelele.**

:::
