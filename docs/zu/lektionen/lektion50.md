# Isifundo 50

## 50.1. Ukwakhiwa kwama-noun: ukukhuphuka okujwayelekile

::: grammar-box

**Ukukhuphuka okujwayelekile kwenzeka nge-Suffix ⟪तद्धित⟫ ku-Sanskrit**
* **-⟪तर⟫ (fem.: ⟪तरा⟫) ku-"Komparativ"**
* **⟪तम⟫ (fem.: ⟪तमा⟫) ku-"Superlativ"**

**Lezi suffix zifakiwa emakhelweni amaskulin e-adjective. Kuma-noun anokwehla kwesikhumbuzi, afakiwa esikhumbuzeni esibuthakathaka esinesimo esifana nalokhu ngaphambi kokuphela -su kwe-Lokativ (⟪पञ्चमी⟫) Plural.**

:::

![](/images/lekt5007.webp)

(Umthombo wesithombe: [Imininingwane](/zu/licenses#lekt5007))

:::

::: grammar-box

**Incazelo:**

**I-"Komparativ" isho, uma into eqhathanisiwe ingachazwanga: "ngokwanele, kakhulu, kakhulu":**

:::

::: indent

isib. ⟪सुचितर⟫ 3 "ngokwanele ocwele", "ocwele kakhulu", "ocwele kakhulu"

:::

**Uma into eqhathanisiwe ichazwa, leyo nto ibekwe ku-Ablativ (⟪पञ्चमी⟫). I-Komparativ + I-Ablativ ilingana nokukhuphuka nge-"njengoba" ngesiJalimane.**

::: indent

isib. ⟪देवदत्ताद्रामो धीमत्तरः⟫ = wörtl.: "ukusuka ku-Devadatta ukubona u-Rāma unengqondo" = "u-Rāma unengqondo kunaku-Devadatta"

:::

**I-"Superlativ" isho, uma into eqhathanisiwe ingachazwanga: "kakhulu, kakhulu":**

::: indent

isib. ⟪सत्तम⟫ 3 (ku-⟪सन्त्⟫) "kubaluleke kakhulu, kahle kakhulu"

:::

**Uma into eqhathanisiwe ichazwa, leyo nto ibekwe ku-Genetiv (⟪षष्ठी⟫) ("uka", "phakathi") futhi i-Superlativ ilingana ne-Superlativ yesiJalimane (isigaba esiphezulu):**

::: indent

isib. ⟪द्विजानां सत्तमः⟫ = "okuhle kakhulu waba-Born kabili"

:::

**Amagama-okugcina -⟪तर⟫ kanye no-⟪तम⟫ angawafaki kuphela emagama-ajwayelekile, kodwa futhi nangemagama-ento, amangeniwe, nokwakheka kwemisebenzi:**

Izibonelo:

::: indent

⟪गजतम⟫ m. "indlovu enhle kakhulu" (⟪गज⟫) (futhi igama elibizwa ngalo uBuddha)

⟪गोतम⟫ m. "inkomo enkulu kakhulu" (⟪गो⟫) noma: "enokuthula okuningi kwezinkomo"

⟪उद्⟫ Indekl. "phezulu", "phezulu" » ⟪उत्तर⟫ 3 "phezulu kakhulu" » ⟪उत्तम⟫ 3 "phezulu kakhulu"

:::

**Uma la magama-okugcina efakiwe emisebenzi, aveza ngaso sonke isikhathi ngendlela ye-adverbial:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

Izibonelo:

::: indent

⟪पचतितराम्⟫ "ukopha kahle"

⟪पचतितमाम्⟫ "ukopha kahle kakhulu"

:::

**Le ndlela lawo magama-okugcina anayo, uma efakiwe emangeniwe futhi igama eliphumayo lisetshenziswa ngendlela ye-adverbial:**

::: indent

isib. ⟪सुतराम्⟫ (ku-⟪सु⟫) "ngendlela enhle" (ngendlela ye-adverbial)
