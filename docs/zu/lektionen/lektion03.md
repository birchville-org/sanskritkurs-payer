# Isifundo 3

## 3.1. Isimo sokugqamuka esingu-odwa kwesifazane

### 3.1.1. Isimo sokugqamuka esingu-odwa esiphela ngo-s

Futhi lezi zimpande zokubizwa, eziphela ngevowulithi, zakha isimo sokugqamuka esingu-odwa ngo-**s**:

::: grammar-box
**Izifazane eziphela ngo-i**: isib. **śruti** f. "ukulalela" -- Nom. sg.: **śrutis** = ⟪श्रुतिस्⟫
**Izifazane eziphela ngo-u**: isib. **dhenu** f. "inkawu yobisi" -- Nom. sg.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Isimo sokugqamuka esingu-odwa ngaphandle kwesiphetho

Isimo sokugqamuka esingu-odwa sakhiwa ngaphandle kwesiphetho:

::: grammar-box
**Izifazane eziphela ngo-ā**: isib. **devatā** f. "inkosikazi" -- Nom. sg.: **devatā** = ⟪देवता⟫
**Izifazane eziphela ngo-ī**: isib. **devī** f. "inkosikazi" -- Nom. sg.: **devī** = ⟪देवी⟫
:::
::: important
**Qaphela!** Ngaphezu kwalokho, kukhona izimpande zokubizwa zesifazane ezinombhalo omunye eziphela ngo-ī, ezinombhalo omunye, isimo sokugqamuka esingu-odwa siphela ngo-s: isib. dhī f. "cabango" -- Nom. sg.: dhīs = ⟪धीस्⟫. Futhi i-lakṣmī (⟪लक्ष्मी⟫) f., i-tarī (⟪तरी⟫) f. "umkhumbi" ne-tantrī (⟪तन्त्री⟫) f. "umgudu" zakha ngokungajwayelekile isimo sokugqamuka esingu-odwa ngo-s: i-lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Ukwakhiwa kwama-feminine ku-maskuline

::: grammar-box
**Ama-maskuline aphela ngo-a:**
**I-feminine ephela ngo-ā**: isib. **kṣatriya** m. » **kṣatriyā** f. "umkazi we-Kṣatriya" = ⟪क्षत्रिया⟫
**I-feminine ephela ngo-ī**: isib. **brāhmaṇa** m. » **brāhmaṇī** f. "i-Brahmanin" = ⟪ब्राह्मणी⟫

**Ama-maskuline aphela ngo-u:**
**I-feminine ephela ngo-ī**: isib. **sādhu** m. » **sādhvī** f. (kahle, uNgcwe) = ⟪साध्वी⟫
(**-u-** iba **-v-** ngaphambi kwevowulithi, ngakho **-u- + -ī** » **-vī**)
:::

## 3.3. Isimo sokugqamuka esiphindwe kabili ku-Maskuline ne-Feminine

::: grammar-box
Isiphetho sesimo sokugqamuka esiphindwe kabili ku-Maskuline ne-Feminine singu-**as**.
**Ama-maskuline aphela ngo-a**: **deva- + -as** » **devās** = ⟪देवास्⟫
**Izifazane eziphela ngo-ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**Ama-maskuline aphela ngo-i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**Izifazane eziphela ngo-i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**Izifazane eziphela ngo-ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**Ama-maskuline aphela ngo-u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**Izifazane eziphela ngo-u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Qaphazelo: **e** iyinqumo ephezulu (**guṇa**) ku-**i**, **o** iyinqumo ephezulu ku-**u**.


## 3.4. Vokalsandhi

::: grammar-box
**Amavokhali alula, angahlukahlukana noma ngokubanzi kuphela, "ahlangana" abe yivokhali ende efanelekileyo:**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)
:::
isib.

devatā + annapūrṇā » devatānnapūrṇā "U-Anna Purna ungumoya" = ⟪देवतान्नपूर्णा⟫

> (U-Anna Purna ungumoya wezokudla nokupheka, ubhekwa njengomzimba ka-Parvatī, umkakazi ka-Śiva.)

devī + indrāṇī » devīndrāṇī "U-Indrāṇī ungumoya" = ⟪देवीन्द्राणी⟫

> (U-Indrāṇī umkakazi kaNkulunkulu u-Indra.)

::: grammar-box
**Amavokhali alula (ngaphandle -a / -ā) angaphambi kwamavokhali angafaniyo aqondiswa ngokusebenzisa isigqi esifanelekileyo:**
i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**
(!! Kukhona izimiso ezithile zale mthetho, ikakhulukazi ezifanekisweni ze-Dual !!)
:::
isib.

devī + umā » devy umā "U-Umā ungumoya / umoya" = ⟪देव्युमा⟫

> (U-Umā igama lika-Parvatī, umkakazi ka-Śiva)

::: grammar-box
**-a / -ā ngaphambi kwamavokhali angafaniyo:**
a / -ā + i- / ī- » **-e-**
a / -ā + ṛ- » **-ar-**
a / -ā + e- / ai- » **-ai-**
a / -ā + o- / au- » **-au-**
:::

## 3.5. Isandhi sombhalo ka-ās

::: grammar-box
**-ās iboshwa zonke izwi eliphumayo ngokushintshwa -ā.**
:::
isib.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Abaiśya bangabazalwane kabili" = ⟪द्विजा वैश्याः⟫


## 3.6. Uhlu lwamagama

**Funda lamagama alandelayo:**

**śruti** f. = ⟪श्रुति⟫ : ukuzwa, ukudluliselwa okuhlala njalo (ukuchazwa kweVeda neBrāhmaṇa).

**smṛti** f. = ⟪स्मृति⟫ : ukukhumbula, ukukhumbula, ukukhumbula okucabayo = ukukhumbula, ukudluliselwa (ukuphikisana no- **śruti**). Hlanganisa:
ezintathu **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): ukukhuluma kahle
2. **chandas** n. (⟪छन्दस्⟫): umumo
3. **vyākaraṇa** n. (⟪व्याकरण⟫): umthetho wamagama
4. **nirukta** n. (⟪निरुक्त⟫) : ukuchazwa kwamagama, i-etymology
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : i-asthonoma, imfundiso yekhalenda
6. **kalpa** m. (⟪कल्प⟫) : ukusebenza
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : izincwadi zokufundisa ukwenza izihlalo ezinkulu
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : izincwadi zokufundisa izinkolo nezihlalo zokuphila kwansuku zonke
**dharmasūtra** n. (⟪धर्मसूत्र⟫) kanye **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : izincwadi zomthetho nesiko (ukuziphatha okufanele)
izindaba ezinkulu **mahābhārata** n. (⟪महाभारत⟫) kanye **rāmāyaṇa** n. (⟪रामायण⟫)
**purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫) : izincwadi zokufundisa ubuciko bokuphila

**smṛti** ikakhulukazi ukuchazwa kwezincwadi zomthetho.

**dhenu** f. = ⟪धेनु⟫ : inkukhu (yokuphuma amasi).

**paśu** m. = ⟪पशु⟫ : isilwane esilondoloziwe, izilwane (iqoqo).

**devatā** f. = ⟪देवता⟫ : uNkulunkulu (okungokoqobo nangokungokoqobo).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : uBrahmanin.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : uKṣatriya wesifazane.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : umkakhe uKṣatriya.

**vaiśyā** f. = ⟪वैश्या⟫ : uVaiśya wesifazane.

**śūdrā** f. = ⟪शूद्रा⟫ : uŚūdra wesifazane.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : umkakhe uŚūdra.

**devī** f. = ⟪देवी⟫ : uNkosikazi, ikakhulukazi uDurgā f. = ⟪दुर्गा⟫, umkakhe uŚiva = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
Isithombe: uDurgā = ⟪दुर्गा⟫, Orissa
Umthombo wesithombe: [Imininingwane](/images/lekt0303)
:::
**sādhvī** f. = ⟪साध्वी⟫ : isif. ku-sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : isif. ku-guru.

**asmitā** f. = ⟪अस्मिता⟫ : "ukuba ngu-ami", okungukuthi ukukholelwa (okungalungile): **Ngiyona** ngiyabona njll.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : iFilosofi (isayensi efika ekuphethweni kwayo ngokusebenzisa izizathu eziqondile ngokwe-logiki).

**upekṣā** f. = ⟪उपेक्षा⟫ : ukungakhathaleli, ukuzinza.

**karuṇā** f. = ⟪करुणा⟫ : ukuthanda abanye, ukuzwela.

**muditā** f. = ⟪मुदिता⟫ : ukujabula, ikakhulukazi ukujabula ngokwabo abanye (ukuqhelelana nokukhathala).


## 3.7. Imisebenzi

**A) Beka izitatimende ezilandelayo ngePlural:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**B) Yakha nominalsentences ngokufaka:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Guqula kube yifeminine:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**D) Humela kube yi-Sanskrit:**

1. U-Uma ungumlinganiswa.
2. U-Veda ngu-śruti.
3. Abafundisi bafazi ngabalinganiswa.
4. Izinkawu zokudubula zizilwanyana ezifakwe.
5. Ababali ngabafundisi.
6. Ama-Kṣatriyas ngabazalwa kabili.
7. Laba duni abangcwele ngama-Śūdras.
