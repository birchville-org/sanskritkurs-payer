# Imisebenzi 61

Isifundo 61 siyagcina isifundo seSanskrit futhi asiqukethe imisebenzi yokubhala eyengeziwe. 

Ngokufunda izimpande zama-nomina, isikhathi esizayo esijwayelekile, nama-denominativa, izisekelo zokufunda amathuba eSanskrit zibekwe. Isifundo siyagcina ngokubiza okujwayelekile ku-Gaṇeśa (⟪श्रीगणनाथ⟫), okuphatha ukudlula kusuka ebukhuleni bokufundisa kuya ekufundeni okuzimayo.
