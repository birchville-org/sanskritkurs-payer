# Isifundo 17

## 17.1. Iqela lesibili le-Präsens (⟪अदादि⟫ = ⟪अद्⟫ njll.)

Iziphumo ze-verb zibheka ngqo emgogodleni. Kule meko, kufuneka kuqwalaselwe utshintsho lwelizwi olubangelwa yi-sandhi yomzobo.

::: grammar-box

Kukho ezinye iindlela zokwakha kwiqela lesibili le-Präsens:

1.  Imigogodla enokwehla kwisiseko
*   ngokubanzi: Inqanaba eliphezulu - Inqanaba eliphantsi
*   ezinye iimzobo: Inqanaba elide - Inqanaba eliphantsi
2.  Imigogodla engena ukwehla kwisiseko
3.  Imigogodla emibini yesilabhi ephelelweyo nge -i/-ī enokwehla kwisiseko

:::
