# Imisebenzi 53

Umsebenzi we-Lektion 53 uhlanganisa ukuhlaziya kwe-metric (ukunquma isakhiwo se-Śloka) kwawo wonke ama-verse afundiswe ezifundweni ezilandelayo. 

Njengoba lokhu kuyimisebenzi yokuphinda futhi ukuhlaziya okujulile, akukho isixazululo esikhethekile esitholakalayo ngendlela ejwayelekile. Izixazululo zivela ekusetshenzisweni kwemithetho efundiswe ku-Lektion 53 ematextu asewaziwe.
