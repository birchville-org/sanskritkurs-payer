# Isifundo 5

## 5.1. Izakhiwo zamagama (samāsa m. = ⟪समास⟫)

Ukwakhiwa kwamaqoqo amagama ngobuningi obukhulu kakhulu yisici esiyinhloko seSanskrit.

Izimo ezibaluleke kakhulu zokwakhiwa kwamaqoqo amagama zilandelayo:
**amaqoqo amagama ahlanganisiwe** (dvandva n. = ⟪द्वन्द्व⟫)
**amaqoqo amagama anecaciso** (tatpuruṣa m. = ⟪तत्पुरुष⟫)
**amaqoqo amagama okunamandla** (bahuvrīhi m. = ⟪बहुव्रीहि⟫)

(Buka okunye ngalawa maqoqo amagama amabili okugcina kamuva!)


## 5.2. Ngemigomo yeSanskrit mayelana namaqoqo amagama

**ghaṭakapadāni** n. pl. = ⟪घटकपदानि⟫ : Izindandatho zamaqoqo amagama
**vigrahavākyam** n. = ⟪विग्रहवाक्यम्⟫ : Ukukhishwa kwamaqoqo amagama
**nityasamāsaḥ** m. = ⟪नित्यसमासः⟫ : Iqoqo lamagama elingenayo i-vigrahavākya noma elingenakho ukwakhiwa ngamagama alo mqoqo.
**aluksamāsaḥ** m. = ⟪अलुक्समासः⟫ : Iqoqo lamagama elinendandatho ye-kasus eligcinwe yindandatho yokuqala
**luksamāsaḥ** m. = ⟪लुक्समासः⟫ : Iqoqo lamagama elinendandatho yokuqala engenalendandatho ye-kasus (isimo sivamile)
**madhyamapadalopī** m. = ⟪मध्यमपदलोपी⟫ : Iqoqo lamagama elinendandatho eyodwa noma ngaphezulu ephakathi ephukile


## 5.3. Amaqoqo amagama ahlanganisiwe (Dvandva n. = ⟪द्वन्द्व⟫)

Amaqoqo amagama ahlanganisiwe asetshenziselwa ukuxhumanisa izindandatho ezifanayo ngokwesakhiwo (amagama noma izifanekiso).

::: grammar-box
**I-Dvandva ichaza:**

1. **noma ukuxhumaniswa okuhlanganisa izinto, izinto, noma izakhiwo ezichazwe yizindandatho zayo ezahlukene:**
Itaretaradvandva = ⟪इतरेतरद्वन्द्व⟫

2. **noma ihlanganisa lezi zinto, izinto, noma izakhiwo zibe yinto eyodwa:**
Samāhāradvandva ("I-Dvandva yokuhlanganisa") = ⟪समाहारद्वन्द्व⟫

**Kwimeko yokuqala (Itaretaradvandva):**
I-Dvandva ithatha isibalo somzimba sesigaba sayo sokugcina futhi isebenzisa iziphetho zombili (kwezinto ezimbili) noma iziphetho zokuphindaphindeka (kwezinto ezingaphezu kwesibili). Iziphetho zokuphindaphindeka zivumelekile.

**Kwimeko yesibili (Samāhāradvandva):**
I-Dvandva ngokuvamile iyi-Neutrum (ngokungakhathaleki isibalo somzimba sesigaba sayo sokugcina) futhi isebenzisa isiphetho sokuphindaphindeka.

**Ukuxazululwa:**
Kwenziwa nge-"futhi" (**ca** = ⟪च⟫), ngamanye amaxesha nge-"noma" (**vā** = ⟪वा⟫) noma "ngokulinganayo".
:::
Bheka i-Dualdvandva kamuva!

### 5.3.1. Izigaba zokuqala zama-Compound

Izigaba zokuqala zama-Compound (hhayi kuphela ama-Dvandva) ngokuvamile ziba nefomu le-**Nominalstem** elingashintshiwe. Izigaba ezahlukene zama-Compound zihlanganiswa ngokomthetho we-**Satzsandhi** (okungukuthi, i-Sandhi esiyifundile ngaphambili, ngokuhlukana ne-Wortsandhi, esetshenziswa ngaphakathi kwelithi ngaphambi kwezinto ezifakiwe).

### 5.3.2. Plural-Itaretaradvandva

Izibonelo ze-Pluraldvandva:

**brāhmaṇa-kṣatriya-vaiśya-śūdrāḥ** = ⟪ब्राह्मणक्षत्रियवैश्यशूद्राः⟫
> = brāhmaṇāḥ kṣatriyā vaiśyāḥ śūdrāś ca = ⟪ब्राह्मणाः क्षत्रिया वैश्याः शूद्राश्च⟫
> (Ama-Brahmanen, ama-Kṣatriya, ama-Vaiśya nama-Śūdra)
> 
> noma = brāhmaṇaḥ kṣatriyo vaiśyaḥ śūdraś ca = ⟪ब्राह्मणः क्षत्रियो वैश्यः शूद्रश्च⟫
> (umBrahmanen, u-Kṣatriya, u-Vaiśya no-Śūdra)

**kavi-guravaḥ** = ⟪कविगुरवः⟫
> = kavayo guravaś ca = ⟪कवयो गुरवश्च⟫
> (Abaholi nabafundisi [Plur.])
> (Qaphela: "Umholi omunye nofundi omunye" kufanele ibe yi-Dual!)

**Ngokwemigomo yohlelo lwezinto ezakha i-Dvandva, kusebenza phakathi kwelinye:**
Igama lezindiza ezahlukene (**varṇa**) kufanele lihleleke ngokuhambisana ne-hierarchy (ephezulu kuqala).
Igama lomzala omkhulu kufanele libe ngaphambi kwelomzala omncane.
Ngokuvamile, igama elibaluleke kakhulu kufanele libe ngaphambili.
Amagama aphela ngo-** -i** noma **-u** kufanele abe ngaphambili.
Amagama aphela ngo-** -a** futhi aqala ngevokalithi kufanele abe ngaphambili.
Amagama anezilimi ezimbalwa kufanele abe ngaphambili.

Lapho ezimbili kwezintathu zemigomo eyaziwe ngokulandelana ingasebenza ngasikhathi sinye, kufanele kulandelwe umqondo olandelayo. (Izibonelo ze-Dvandva yale migomo ku-Kielhorn, Grammar § 570).


## 5.4. Uhlu lwamagama

**Funda lamagama alandelayo:**

**abhiniveṣa** m. = ⟪अभिनिवेष⟫ : Ukukhetha, ukuzinza, ukumelana; ikakhulukazi: ukuthandana nempumulo njengento yakho.

**kāma** m. = ⟪काम⟫ : Uthando, ukufuna, isipho esifunwayo, ukuzonwabisa, uthando; uKāma, uNkulunkulu woThando.

::: media
![](/images/lekt0501.webp)
Isithombe: uNkulunkulu uKāma = kāmadeva = ⟪कामदेव⟫, i-18th century.
(Umthombo wesithombe: Wikipedia, Public domain)
:::
**krodha** m. = ⟪क्रोध⟫ : Ukudideka.

**kleśa** m. = ⟪क्लेश⟫ : Inkinga, ukubuhlungu.

**trayī** f. = ⟪त्रयी⟫ : Inombolo yesithathu; ikakhulukazi ama-Veda amathathu (Ṛgveda, Sāmaveda, Yajurveda).

**daṇḍanīti** f. = ⟪दण्डनीति⟫ : Amapholotiki (i-Tatpuruṣa evela ku-daṇḍa m. = "isikhwama, amandla, ukuphatha, isohlwayo" kanye no-nīti f. = "ukuhola kahle").

**dvijāti** 3 / **dvija** 3 = ⟪द्विजाति⟫ / ⟪द्विज⟫ : Okuzalwe kabili.

**dveṣa** m. = ⟪द्वेष⟫ : Ukukhathazela.

**maitrī** f. = ⟪मैत्री⟫ : Ubufazi, ukuthandana, ukuthanda ngokuhle.

**rāga** m. = ⟪राग⟫ : Umbala (obomvu), umoya, uthando.

**lobha** m. = ⟪लोभ⟫ : Ukukhula, ukuzithanda.

**varṇa** m. = ⟪वर्ण⟫ : Umbala, uhlobo, isigaba.

**vārttā** f. = ⟪वार्त्ता⟫ : Ukuthola, i-ekonomy (imfundo).

**vidyā** f. = ⟪विद्या⟫ : Ukwazi, isayensi.

**avidyā** f. = ⟪अविद्या⟫ : Ukungazi, ukungazi.

**ca** = ⟪च⟫ : Futhi.
(Iyabekwa emva kwelokhu okuxhumanisa. Uma izinto eziningi zixhumaniswa, kufanele ibe emva kwelokuqala kwesigaba sokuxhumanisa: brāhmaṇāḥ kṣatriyā vaiśyāḥ śūdrāś ca = ⟪ब्राह्मणाः क्षत्रिया वैश्याः शूद्राश्च⟫).

**ca ... ca** = ⟪च⟫ ... ⟪च⟫ : kokubili ... nakokubili.


## 5.5. Umsebenzi

**A) Hlola la mazwi namagama amakhulu bese usola ama-Dvandva akhona ngesiSanskrit:**

1. catvāro varṇā brāhmaṇakṣatriyavaiśyaśūdrāḥ.
(Āpastambīyadharmasūtra I,1,1,4 = Vāsiṣṭhadharmaśāstra II,1)
⟪चत्वारो वर्णा ब्राह्मणक्षत्रियवैश्यशूद्राः⟫ ||
(Incazelo: catvāras = ⟪चत्वारस्⟫ = "ane")

2. trayo varṇā dvijātayo brāhmaṇakṣatriyavaiśyāḥ.
(Vāsiṣṭhadharmaśāstra II,1)
⟪त्रयो वर्णा द्विजातयो ब्राह्मणक्षत्रियवैश्याः⟫ ||
(Incazelo: trayas = ⟪त्रयस्⟫ = "thathu")

3. sāmavedargvedayajurvedās trayī.
(Kauṭilīya-arthaśāstra 1.3.1. / ngesiSanskrit esihle: sāmārgyajurvedās trayī)
⟪सामवेदर्ग्वेदयजुर्वेदास्त्रयी⟫ ||
(nesiSanskrit esihle: ⟪सामार्यजुर्वेदास्त्रयी⟫)

4. Izitha ezintathu zomuntu, ezakha umnyango weNer (Viṣṇusmṛti 33,1+6):
   kāmakrodhalobhāḥ
⟪कामक्रोधलोभाः⟫ ||

5. maitrīkaruṇāmuditopekṣāś catvāro brahmavihārāḥ.
⟪मैत्रीकरुणामुदितोपेक्षाश्चत्वारो ब्रह्मविहाराः⟫ ||
(Incazelo: brahmavihāra: "izimo zokuhlala kwaBrahma", futhi zibizwa ngokuthi "Amaningi". Zizinhlobo zokuzicabangela kweBuddhism.)

6. avidyāsmitārāgadveṣābhiniveṣāḥ pañca kleśāḥ.
(Yogasūtra 2,3)
⟪अविद्यास्मितारागद्वेषाभिनिवेषाः पञ्च क्लेशाः⟫ ||
(Incazelo: pañca = "amahlanu")

7. ānvīkṣikītrayīvārttādaṇḍanitayo vidyāḥ.
(Ngokuka-Kauṭilīya-arthaśāstra 1.2.1.)
⟪आन्वीक्षिकीत्रयीवार्त्तादण्डनितयो विद्याः⟫ ||


## 5.6. Ukuzivocavoca kokuphinda

**A) Thumela:**

1. vidyā vārttā.
⟪विद्या वार्त्ता⟫ |

2. brāhmaṇaḥ kṣatriyo vaiśyaś ca trayo varṇā dvijātayaḥ.
⟪ब्राह्मणः क्षत्रियो वैश्यश्च त्रयो वर्णा द्विजातयः⟫ |

3. dvijā vaiśyāḥ. (Izindlela ezimbili)
⟪द्विजा वैश्याः⟫ |

**B) Faka ifomu elihambisanayo:**

1. (dvija, sādhu, kavi) ... rāmaḥ
(⟪द्विज⟫, ⟪साधु⟫, ⟪कवि⟫) ... ⟪रामः⟫ |

2. (devī) ... indrāṇī
(⟪देवी⟫) ... ⟪इन्द्राणी⟫ |

3. dvijātayas ... (vaiśyā, kṣatriya)
⟪द्विजातयस्⟫ ... (⟪वैश्या⟫, ⟪क्षत्रिय⟫) |

**C) Xazulula i-compositum esitatimendeni ngesiSanskrit bese wakha isitatimende esifanayo nalo lo mofaniso oxazululiwe:**

sāmargyajurvedās trayī.
⟪सामर्ग्यजुर्वेदास्त्रयी⟫ |

**D) Thumela ngezindlela ezimbili ngesiSanskrit (kanye nge-compositum, kanye ngaphandle):**

"Izimo zokuhlala kwaBrahma" zingu: ukuthanda ngokuthula, ukuzwela, ukujabula nabo, nokulingana.
