# Isifundo 34

## 34.1. I-Perfect (⟪लिट्⟫)

Ku-Sanskrit ejwayo, kukhona kuphela i-Indikativ ne-Participle esuka ku-perfect stem.

::: grammar-box

**Kukhona izinhlobo ezimbili zokwakhiwa kwe-Perfect:**
*   **i-Perfect ephindaphindayo = ⟪द्वित्वलिट्⟫**
*   **i-Perfect ephakathi = ⟪अनुप्रयोगलिट्⟫**

:::

::: grammar-box

**I-Perfect ephakathi (⟪अनुप्रयोगलिट्⟩) isetshenziswa:**
1. **ezifundweni ezixubile (Kausativ, Desiderativ, Frequentativ, Denominativa)**
2. **emazweni aqala ngevokal ephakeme (ngaphandle kuka-ā-), noma ngevokal (ngaphandle kuka-a-) ngaphambi kwezilimi ezimbili**
3. **ezinye izimpande**

:::

## 34.2. I-Perfect ephindaphindayo (⟪द्वित्वलिट्⟩)

### 34.2.1. Ukwehla kwesihluthulelo

::: grammar-box

**Ukwakhiwa:**

**Isihluthulelo esinamandla:** I-Singular Parasmaipada
*   **impande ephindaphindayo enesigaba esiphezulu noma eside + isiphetho se-Perfect**

**Isihluthulelo esinobutha:** zonke ezinye izimo
*   **impande ephindaphindayo enesigaba esiphansi + isiphetho se-Perfect**

:::

::: grammar-box

**Ngokuvamile (nakwamanye amagama ngaphandle kwe-Perfect) awanayo ukwehla kwesihluthulelo izimpande ezifana:**
*   **(Isilimi)-Isilimi-Isivokal eside-Isilimi**
*   **(Isilimi)-Isilimi-Isivokal-Isilimi-Isilimi**

**Ku-Perfect, futhi awanayo ukwehla kwesihluthulelo izimpande ezifana:**
*   **a-Isilimi**
*   **ā-Isilimi**

:::
