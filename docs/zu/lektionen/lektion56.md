# Isifundo 56

## 56.1. I-Aorist edonakele kabili

::: grammar-box

**Ukwakhiwa:**

**Augment + impande edonakele kabili + a + isiphetho sesibili sesimiso**

**Isyllable yempande ingaba ngezinga eliphansi noma eliphezulu. Kuzimpande ezinokuphela ngo--i noma -u, izinga eliphansi liyisimiso.**

**Ukuphela kwe--i, -u kushintshwa sibe -iy noma -uv.**

**Ukuphela kwe--ā (ku--e) kuyanyamalala.**

:::

I-paradigma:

⟪श्रि⟫ 1U "ukuya ku-, ukumisa ku-"

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | ⟪अशिश्रियम्⟩:br(⟪अ⟩-⟪शि⟩-⟪श्रिय्⟩-⟪अम्⟩) | ⟪अशिश्रियाम⟩ | ⟪अशिश्रिये⟩ | ⟪अशिश्रियामहि⟩ |
| **2. ⟪द्वितीयः⟩** | ⟪अशिश्रियस्⟩ | ⟪अशिश्रियत⟩ | ⟪अशिश्रियथास्⟩ | ⟪अशिश्रियध्वम्⟩ |
| **3. ⟪प्रथमः⟩** | ⟪अशिश्रियत्⟩ | ⟪अशिश्रियन्⟩ | ⟪अशिश्रियत⟩ | ⟪अशिश्रियन्त⟩ |

Le fomu ye-Aorist yakhiwa yizimpande ezifana nalezi:

*   ⟪श्रि⟩ 1U "ukuya ku-"
*   ⟪द्रु⟩ 1P "ukugijima"
*   ⟪कम्⟩ 1Ā "ukuthanda": ⟪अचकमत⟩ / ⟪अचीकमत⟩ (buka ngezansi!)
*   ⟪पत्⟩ 1P "ukwehla": ⟪अपप्तत्⟩ (a-pa-pt-a-t; pt = izinga eliphansi ku-pat)
*   ⟪वच्⟩ 2P "ukuthi": ⟪अवोचत्⟩ (a-va + uc-a-t)

::: grammar-box

**Zonke izimpande zeklasi yesi-10 yamanje kanye zonke izimpande zokubangela (Kausative) zakha i-Aorist edonakele kabili.**

:::

### 56.1.1. Ukwakhiwa kwe-Aorist yezimpande zokubangela nezimpande zeklasi yesi-10 yamanje

Isyllable yomgomo:

::: grammar-box

**Isisekelo yifomu yomgomo wamanje noma yomgomo wokubangela, leyo efumaneka ngokukhansela isakhi -aya- (ngakho-ke umgomo onokuphela ku--p kuzokubangela okuphela ku--paya-).**

**I-vowel yale syllable yomgomo ebizwa ngokuthi yi-"stem syllable" inqunywa ku-Aorist ngalezi zithetho zilandelayo:**

*   **-ā- ngaphambi kwekhonsonanti elula ithathwa ngokuthi -a-:**  
⟪पॄ⟫ 3P: Kaus. :sig[⟪पार⟫]⟪यति⟫, Aor. ⟪अपि⟫:sig[⟪पर⟫]⟪त् द्रु⟫ 1P: Kaus. :sig[⟪द्राव⟫]⟪यति⟫, Aor. ⟪अदु⟫:sig[⟪द्रव⟫]⟪त्⟫ / ⟪अदि⟫:sig[⟪द्रव⟫]⟪त् नी⟫ 1U: Kaus.  :sig[⟪नाय⟫]⟪यति⟫, Aor. ⟪अनी⟫:sig[⟪नय⟫]⟪त् ज्ञा⟫ 9U: Kaus. :sig[⟪ज्ञाप⟫]⟪यति⟫, Aor. ⟪अजि⟫:sig[⟪ज्ञप⟫]⟪त्⟫  

*   **-ī-, -e-, -ai- ngaphambi kwekhonsonanti elula ithathwa ngokuthi -i-:**  
⟪चित्⟫ 1P: Kaus. :sig[⟪चेत⟫]⟪यति⟫, Aor. (Ā) ⟪अची⟫:sig[⟪चित⟫]⟪त⟫  

*   **-u-, -o-, -au- ngaphambi kwekhonsonanti elula ithathwa ngokuthi -u-:**  
⟪चुर्⟫ 10U: :sig[⟪चोर⟫]⟪यति⟫, Aor. ⟪अचू⟫:sig[⟪चुर⟫]⟪त्⟫

**Kwezinye izimpande, ukuguquka okushiwo ngaphambili kungenzeka noma kufanele kungenzeki:**

*   **ukuthi i-ar, ār, īr, al ephambana nekhonsonanti yokugcina yesyllable yomphumela, eyendawo ye-ṛ, ṝ, ḷ, ihlala ingashintshi noma ithathwe ngokuthi ṛ noma ḷ:**  
⟪कॢप्⟫  1Ā: Kaus. :sig[⟪कल्प⟫]⟪यति⟫, Aor. ⟪अच⟫:sig[⟪कल्प⟫]⟪त्⟫ / ⟪अची⟫:sig[⟪कॢ⟫]⟪पत् कृष्⟫ 1P/6U: Kaus. :sig[⟪कर्ष⟫]⟪यति⟫, Aor. ⟪अच⟫:sig[⟪कर्ष⟫]⟪त्⟫ / ⟪अची⟫:sig[⟪कृ⟫]⟪षत्⟫

:::

Ivokali yesyllable yokuphindaphinda:

Ngemuva kokuthi imithetho eshoyo ngokushesha isetshenziswe kumphumela, imithetho elandelayo kufanele ilandelwe mayelana nevokali yesyllable yokuphindaphinda:

::: grammar-box

**Isisekelo sivela kuvokali evamile yokuphindaphinda, okusho ukuthi**

*   a ku-a, ā, ṛ,  ṝ, ḷ
*   i ku-i, ī, e, ai
*   u ku-u, ū, o, au

**Le vokali yokuphindaphinda ilandela ukuguquka okulandelayo:**

*   **i, u baphelwa ngu-ī, ū uma isyllable yomgodi iqala ngesigqi esisodwa futhi incane ngokwemithetho yezibalo:**  
⟪भिद्⟫ 7U: Kaus. ⟪भेदयति⟫, Aor. ⟪अ⟫:sig[⟪बी⟫]⟪भिदत् तुद्⟫ 6U: Kaus. ⟪तोदयति⟫, Aor. ⟪अ⟫:sig[⟪तू⟫]⟪तुदत्⟫  

*   **a baphelwa ngu-ī uma isyllable yomgodi incane ngokwemithetho yezibalo futhi iqala ngesigqi esisodwa. Uma isyllable yomgodi incane ngokwemithetho yezibalo futhi iqala ngezizigqi eziningi, a yesyllable yokuphindaphinda baphelwa ngu-i. Uma isyllable yomgodi inkulu ngokwemithetho yezibalo, a ihlala injalo:**  
⟪नी⟫ 1U: Kaus. ⟪नाययति⟫, isyllable yomgodi ye-Aor. ⟪नय्⟫, Aor. ⟪अ⟫:sig[⟪नी⟫]⟪नयत् कृ⟫ 8U: Kaus. ⟪कारयति⟫, isyllable yomgodi ye-Aor. ⟪कर्⟫, Aor. ⟪अ⟫:sig[⟪ची⟫]⟪करत् त्यज्⟫ 1P: Kaus. ⟪त्याजयति⟫, isyllable yomgodi ye-Aor. ⟪त्यज्⟫, Aor. ⟪अ⟫:sig[⟪ति⟫]⟪त्यजत् भू⟫ 1P: Kaus. ⟪भावयति⟫, isyllable yomgodi ye-Aor. ⟪भव्⟫, Aor. ⟪अ⟫:sig[⟪बी⟫]⟪भवत्⟫

Izinto ezikhethekile zamakhono athile ku-Kielhorn, Grammar § 435c ff.

**Izyllable zomgodi eziqala ngevokal ziphindaphindwa ngokwemithetho elandelayo:**

*   **Uma uvokal oqalayo ulandwa yisigqi esisodwa noma iqoqo lezizigqi, lapho ingxenye yokuqala ingeyona i-nasal noma i-d noma i-r, isyllable ephindaphindayo ibe:**

Uvokal - isigqi esilandelayo (noma umelwane wakhe ocelwayo esyllable yokuphindaphinda) - **i** - zonke izizigqi

:::

::: indent

⟪अश्⟫ 9P: Kaus. ⟪आशयति⟫, isyllable ephindaphindayo ⟪आशिश्⟫, Aor. ⟪आशिशत् इष्⟫ 6P: Kaus. ⟪एषयति⟫, isyllable ephindaphindayo ⟪एषिष्⟫, Aor. ⟪ऐषिषत् ईक्ष्⟫ 1Ā: Kaus. ⟪ईक्षयति⟫, isyllable ephindaphindayo ⟪ईचिक्ष्⟫, Aor. ⟪ऐचिक्षत्⟫

:::

*   Uma uvokali eliqala ngokukhala ilandelwe yiqoqo lezinhlamvu eziqala ngenhlamvu yomoya noma nge-d noma nge-r, khona-ke inhlayiya yesibili yalo mqoqo (noma umelwane wayo) ifakwa ngokulandelana kwe-i ngokwesigaba esilandelayo:


Uvokali - inhlayiya yokuqala - inhlayiya yesibili (umelwane) - i - inhlayiya yesibili

::: indent

⟪अञ्ज्⟫ 7P: Kaus. ⟪अञ्जयति⟫, isilabu ephindwe kabili ⟪अञ्जिज्⟫, Aor. ⟪आञ्जिजत् ऋ⟫ 1P: Kaus. ⟪अर्पयति⟫, isilabu ephindwe kabili ⟪अर्पिप्⟫, Aor. ⟪आर्पिपत् अर्ह्⟫ 1P: Kaus. ⟪अर्हयति⟫, isilabu ephindwe kabili ⟪अर्जिह्⟫, Aor. ⟪आर्जिहत्⟫

:::

Le ndlela yokuphindaphinda yezimpande ezihlanganisiwe eziquka uvokali ekuqaleni (ama-Kausative) ibizwa ngokuthi yi- "attic reduplication".
## 56.2. I-Injunctive

::: grammar-box

**I-Injunctive yifomu elingenawo i-augment efomweni ene-augment, okusho ukuthi amafomu ayo ayafana namafomu angenawo i-augment e-Indikative Imperfect noma Aorist. Ubulimi bebhuku lase-India abubonanga i-Injunctive njengekati yobulimi eyodwa.**

:::

Hoffmann, Karl (1915–1996): I-Injunctive ku-Veda : ukuhlolwa kokusebenza kwesikhathi / ngu-Karl Hoffmann. -- Heidelberg : Winter, 1967. -- 298 S. -- (Indogermanische Bibliothek : 3. Reihe, Untersuchungen)

:::

i-Injunctive ku-Veda inalezi zici ezilandelayo:

*   ayibiki, kodwa iyakhuluma
*   ayinawo isikhathi
*   i-Injunctive Present (= Imperfect engenawo i-augment) ibonisa i-aspect engapheli
*   i-Injunctive Aorist ibonisa i-aspect ephelele.

::: grammar-box

**Esisanskrit esikhathi sangemuva kwe-Veda, i-Injunctive isetshenziswa kuphela ndawonye ne-particle yokuthi ⟪मा⟫ (+ Injunctive Aorist) noma ⟪मा स्म⟫ (+ Injunctive Present noma Aorist) kuyilapho umehluko we-aspect uvame ukungasebenzi.**

(ngokwe-aspect

*   ⟪मा⟫ + Injunctive Aorist kungachaza isitatimende sokuthi "Ungaqali ...!", "Ungenzi ...!"
*   ⟪मा स्म⟫ + Injunctive Present kungachaza isitatimende sokuthi "Yeka ukwenza ...!", "Yeka ...!"

Kodwa-ke, lo mehluko awukwazi ukwenziwa ngokuvamile esanskriti yaseklasikhi.)

:::

## 56.3. Isitatimende sokuthi

::: grammar-box

**Ifomu eliyinhloko:**

**⟪मा⟫ + Injunctive Aorist**

:::

Izibonelo:

⟪मा कर्महेतुर्भूः⟫ "Ungabi umuntu othonywa umkhiqizo wemisebenzi!" (Injunctive Aorist) (⟪भगवद्गीता⟫ 2,47c)

**Amaformu wezinyathelo zokuvimbela:**

*   **⟪मा⟫ + (⟪स्म⟫) + I-Imperative (okujwayelekile kancane)**
**isib. ⟪मा ते सङ्गो ऽस्त्वकर्मणि⟫**

*   ⟪अलम्⟫ noma ⟪कृतम्⟫ = I-Instrumental esitatimweni sokuvimbela
isib. ⟪अलं विषादेन⟫ "Yeka ukukhathala! = Yeka ukuhlupheka! = Phakamisa inhloko!"

*   ⟪न⟫ + I-Gerundive (I-Participle yesidingo)

Ngaphezu kwalokho, kunamaformu amaningi angavamile wezinyathelo zokuvimbela, bheka isib.
