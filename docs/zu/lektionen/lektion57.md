# Isifundo 57

## 57.1. Aorist 4: i-s-Aorist

::: grammar-box
**I-s-Aorist yakhiwa emizileni eminingi ⟪अनिट्⟫, ngaphandle uma lezi zimila zinesimo esinye se-Aorist kuphela. Imizila ⟪अनिट्⟫ engakhetha ingakha nge-s-Aorist noma i-iṣ-Aorist ngokukhetha. Futhi, imizila ⟪अनिट्⟫ eyakha ⟪परस्मैपद⟩ emva kwesimo 1, 2 noma 5 se-Aorist, yakha ⟪आत्मनेपद⟫ ngokwesimo se-s-Aorist.**

**Ukwakhiwa: I-Augment + Umzila + s + isiphetho esingapheli**
:::
Ithebula leziphetho nezinto zokwakha isigaba

::: grammar-box

:::
::: grammar-box
**Kusetshenziswa umthetho ojwayelekile wokuthi i-sibilant iphela phakathi kwezibhokhwe ezimbili (bheka ⟪उद्⟫ + ⟪स्थित⟫ » ⟪उत्थित⟫), okusho ukuthi isigaba sokwakha isigaba -s- siyaphela ngaphambi kweziphetho eziqala nge- -t- noma -th- (kodwa hhayi emva kwe-nasal noma r-).**

Izibonelo:

:::
Lezi zimo zingase zihlobene ne-Wurzelaorist futhi zingase zihlobene nalo.
Abagxebi base-Indiya bafaka izimo ezifana no- ⟪अकृत⟫ (3.sg.Ā) ku-s-Aorist, okuyinto ecacile ukuthi ihlobene ne-Wurzelaorist. Ngalesi sizathu, abagxebi base-Indiya bakhonjise umthetho wokukhuluma we-s-Aorist:

::: indent
"Emva kwesikhathi esifushane sesikhathi esifushane, iziphetho eziqala ngo--st- noma --sth- zilahla i--s-."
:::
Ngokuvamile, imithetho yezwi mayelana nokuhlanganiswa kwama-khonsananti aphethayo nama-s- kumele igodliwe.
