# Isifundo 31

## 31.1. Iqela lesi-7 lesikhathi esiqhubekayo (⟪रुधादि⟫ = "⟪रुध्⟫ njll.")

::: grammar-box
**Ukwakhiwa:**

**Ngaphambi kwama-khonsananti aphelelayo weqembu eliphansi le-verb, okubizwa ngokuthi yi-Nasal infix (-na- noma -n-) kufakwa phakathi:**

*   **ekujuleni okamandla: -na-**
*   **ekujuleni okubuthakathaka: -n-**

**Imithetho efanayo esebenza ekuxhumaneni kwama-khonsananti aphelelayo e-verb nama-suffix aqala nge-khonsananti njengoba kusebenza kuqembu lesi-2 lesikhathi esiqhubekayo.**
:::
