# Isifundo 37

## 37.1. I-Adverb (⟪क्रियाविशेषणम्⟫)

Ama-adverb akhiwa ngesiSanskrit

1.  ngezimo zama-kasus ezama-nomena nama-pronomena
2.  ngokusebenzisa ama-suffix nama-ending athile

Esimweni sokuqala, umngcele phakathi kwe-kasus ephilayo ne-adverbuyahamba. Lokhu kuhlanganisa njengesimo esikhethekile ama-adverb ayizimo zama-kasus ezindala ezimanzi, kuyilapho ezinye izimo zisetshenziswa ekuklanyweni noma ama-nomena afanelekile awasebenzisi njenge-nomena manje.

## 37.2. Ukusetshenziswa kwe-adverbial kwama-kasus

### 37.2.1. I-Akkusativ (⟪द्वितीया⟫)

::: grammar-box
I-Akkusativ (⟪द्वितीया⟫) ingasetshenziswa njenge-adverbal emibuzweni:

*   ngendlela yini?
*   isikhathi esingakanani?
*   kuphi?
*   nokunye.

I-Akkusativ ingasetshenziswa njenge-adverbal:

*   ezama-substantive  
Izibonelo:  
⟪कामम्⟫ "ngokwesifiso, ngokwesifiso"  
⟪अर्थम्⟫ "ngenxa"

*   ezama-adjective e-Neutrum  
Izibonelo:  
⟪सुखम्⟫ "kalula, nethamsanqa"  
⟪नित्यम्⟫ "hlale"
⟪साधु⟫ "kulungile, kahle"

*   ezama-pronomena e-Neutrum  
Izibonelo:  
⟪तद्⟫ "khona-ke, ngalokho"
⟪यद्⟫ "uma, ukuthi"
⟪एतद्⟫ "kanjalo, lapha, manje"
:::
### 37.2.2. I-Instrumentalis (⟪तृतीया⟫)

::: grammar-box
I-Instrumentalis (⟪तृतीया⟫) ingasetshenziswa njenge-adverbal emibuzweni:

*   ngokwenzekani?
*   ngokuthini?
*   nokunye.

I-Instrumentalis ingasetshenziswa njenge-adverbal:

*   ezama-substantive  
Izibonelo:  
⟪अर्थेन⟫ "ngenxa"  
⟪क्षणेन⟫ "ngesikhathi, ngokushesha" (kusuka ku-⟪क्षण⟫ m. "isikhathi")

*   ezama-adjective, ngokuvamile nakwifomu le-plural  
Izibonelo:  
⟪दूरेण⟫ "kude, ukusuka kude" (ku-⟪दूर⟫ 3 "kude, kude")  
⟪उच्चैस्⟫ "phezulu, kakhulu" (ku-⟪उच्च⟫ 3 "phezulu, phezulu, kakhulu, ukhala (ngomsindo)")
:::

### 37.2.4. Ukusuka (⟪पञ्चमी⟫)

::: grammar-box
Ukusuka (⟪पञ्चमी⟫) kungasetshenziswa njengendabuko ngokuphendula imibuzo:

*   kungani?
*   ngenxa yekuphi?
*   kusuka kuphi?
*   nezinye ezifana nalokho

Ukusuka kungasetshenziswa njengendabuko:

*   ezinsukweni  
isib. ⟪बलात्⟫ "ngamandla, ngokudabula"  

*   ezifanekisweni  
isib. ⟪दूरात्⟫ "kude"  

*   ezibonakaliseni  
Izibonelo:  
⟪कस्मात्⟫ "kungani"  
⟪अकस्मात्⟫ "ngaphandle kwesibindi"
:::

## 37.11. Ukuqinisekisa ukuphendula

Guqukela ube yi-Sanskrit ngokusebenzisa kuphema izimo zomsebenzi we-Perfect:

Njengoba kwenzeka ukuthi umuntu omkhulu waya esikoleni esinye, waphumula endleleni. Wabe esehamba ukuze ahlale, waya emzileni wesihlahla se-mango esime ngakwesokudla. Kulesi sihlahla kwakukhona izithelo ezilungile. Umuntu omkhulu wathanda lezi zithelo. Kodwa akakwazanga ukuphuma esihlahleni futhi athole izithelo. Ngokusho kwakhe kwakukhona izinkukhu ezithile ezidla izithelo. Njengoba azibonile, umuntu omkhulu wajabula. Wenza ukuthini? Wathatha amatshe ambalwa, wamisa izinkukhu futhi wawaphonsa. Izinkukhu ezibuhlungu zathatha izithelo ezithile futhi zawaphonsa kumuntu omkhulu. Umuntu omkhulu wathatha lezi zithelo ngokujabula futhi waya endaweni ayifunayo. Bona, isimo somuntu omkhulu!
