Isiko elibaluleke kakhulu lesanskriti yaseNdiya enyakatho namuhla yi-Devanāgarī:

![](/images/schrift002.webp)

Isibonakaliso ngasinye sobukhali sibhekisa ku-"a" elandelayo olunconyeni. Uma ufuna ukubhala ubukhali obucacile (ngaphandle kwevokhal elilandelayo), kumele ubonise lokhu ngesiqondiso esiphansi -- virāma = ⟪विराम⟫ --:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

Amavokhal alandelayo ebukhali -- ngaphandle kuka-"a" -- abhalwa kanje:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

Ulandelelano lokubhala lezi zixhumanisi zobukhali + evokhal yileli:

![](/images/schrift003.jpg)

Ekubhaleni, ngalinye inombolo kufakwe umugqa ophezulu kuphela ngaphambi kokuba inombolo elandelayo ibhalwe.

## Umzamo

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā
