# Isifundo 25

## 25.1. Ukwakhiwa kwe-Ablative (⟪पञ्चमी⟫ = "isiphetho sesixwayiso sesithathu")

::: grammar-box

Ngaphandle kwe-Maskulina / Neutra ezinokuphela ngo- -a kanye nezifanekiso, ku-singular kuwo wonke amakhathalogi wokuhlukaniswa, imifanekiso ye-Ablative (⟪पञ्चमी⟫) ifana ne-Genetiv (⟪षष्ठी⟫).

Ngaphandle kwezifanekiso zomuntu, kuwo wonke ukuhlukaniswa ku-plural imifanekiso ye-Ablative ifana ne-Dativ (⟪चतुर्थी⟫).

:::

Manje ubona isizathu sokuhlelwa kwama-Kasus (⟪विभक्ति⟫) ku-Sanskrit: ahlelwe ngendlela yokuthi imifanekiso efanayo ibe eduze kangangoko - noma ngaphansi kwakho.

::: grammar-box

**Ablative Singular ye-Maskulina / Neutra ezinokuphela ngo- -a**

**devāt** (⟪देवात्⟫)

:::

## 25.2. Ukusetshenziswa kwe-Ablative (⟪पञ्चमी⟫)

"I-Ablative ibonisa lokho okuhlala kungashintshi lapho okuthile kusuka kuso."

Pāṇini 2,3,28 + 1,4,24

I-Ablative isetshenziswa ikakhulukazi emibuzweni "Uvela kuphi?", "Kungani?".

::: grammar-box

1\. Ngakho-ke, i-Ablative ibonisa indawo yokuqala, umthombo, kanye nento.

Ngakho-ke, i-ablative ingabhekisela nakwumuntu othenga, evame, ecela, njll.

:::

Izibonelo:

::: indent

⟪ग्रमादागच्छति⟫ = "Uya esikhaleni"

⟪अश्वात्पतितः⟫ = "waqubuka emoyeni"

⟪तेभ्यो लब्धम्⟫ = "wamukela kuwo (ukusuka kuwo)"

:::

Izibonelo:

::: indent

⟪गुरोर्धर्मं शृणोति⟫ = "uvame uMfundisi ngokuthi nge-Dharma"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "uBrahmane ucacisa ukuthi ufuna inkawu yobisi ku-Kṣatriya"

:::

::: grammar-box

2\. I-ablative isetshenziswa ezimeni zokuthi "ukuvimbela ekwenzeni", "ukuvikela ekutheni", "ukuzivikela ekutheni", "ukwesaba":

:::

Isibonelo:

::: indent

⟪अरिभ्यो रक्षति⟫ = "uvikela emahlaziyeni"

:::

::: grammar-box

3\. I-ablative ibhekisela endaweni noma isizathu:

:::

Izibonelo:

::: indent

⟪क्रोधात्पुत्रं हन्ति⟫ = "Ushaya indodana yakhe ngenxa yokuthukuthela"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "Ngoba enze okubi, uya esihogweni" (« Ngoba ungumuntu okwenza okubi)

⟪पापकरणान्नरकं गच्छति⟫ = "Ngoba enza / wenza okubi, uya esihogweni"

:::

Amagama angama-feminine angaba khona ukuze abhekise endaweni yokusebenza, angaba khona nge-instrumentalis (⟪तृतीया⟫) noma i-ablative (⟪पञ्चमी⟫). Ama-feminine ahlala e-instrumentalis, kodwa angaba khona nge-ablative.

## 25.3. Isuffix -⟪तस्⟫

::: grammar-box

Uma ufuna ukukhombisa ngokucacile ukuthi igama lisetshenziswe nge-ablative, ungafaka isuffix -⟪तस्⟫ emgogodleni wegama, okwakha amagama amaningi ane-ablative (ngokubuzwa "Kuphi?"):

:::

Izibonelo:

::: indent

⟪आदितस्⟫ = "kusukela ekuqaleni"

⟪धर्मतस्⟫ = "ngenxa ye-Dharma, ngenxa ye-Dharma"

:::

::: grammar-box

I-suffix -⟪तस्⟫ ivame ukufaka ezimpande ze-pronominal:

:::

::: indent

⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "kusukaphela, lapha, kulelo, kulokho, bese, ngakho"

⟪यद्⟫ : ⟪यतस्⟫ "okuyini, okuphi, kuphi, kuzophi, kungani, ngoba" (okuhlobene)

⟪किम्⟫ :  ⟪कुतस्⟫ "kuphi?" "kungani?"

:::

## 25.4. Ezinye izindlela zokukhombisa izizathu

::: grammar-box

**1\. Amasentensi ahlobene**

Amasentensi ahlobene avame ukukhombisa ubudlelwano obubangela (obunikeza isizathu), obulandelayo (obukhombisa umphumela) noma obuhlose (obunqulo) kunasentensi eyinhloko.

Izimo ze-pronoun ehlobene ezisebenza njenge-conjunction ebangelayo:

*   ablativically:
*   ⟪यतस्⟫ ... isentensi engaphansi ... ⟪ततस्⟫ ... isentensi eyinhloko ... = "ngoba ..., ngakho ..."
*   ⟪यस्मात्⟫ ... isentensi engaphansi ... ⟪तस्मात्⟫ ... isentensi eyinhloko ... = "ngoba ..., ngakho ..."
*   instrumental:
*   ⟪येन⟫ ... isentensi engaphansi ... ⟪तेन⟫ ... isentensi eyinhloko ... = "ngokuthi/ngoba ..., ngalokho / ngakho ..."

:::

Isibonelo:

::: indent

⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "Ngoba u-Rāma ufuna ukuthuthukiswa, uqhuba isethulo"

:::

::: grammar-box

**2\. ⟪हि⟫**

Amasentensi eyinhloko angaxhunywa ngokusebenzisa i-particle ⟪हि⟫ "ngoba, ngoba" ukuze axhunywe. Isentensi ene-⟪हि⟫ (engaqali, kodwa kumele ibe yesibili ku-prose) inikeza isizathu noma sesentensi edlule noma yesentensi elandelayo:

:::

Isibonelo:

::: indent

⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "Abantu benza izinto ezihloniphekayo. Ngoba bafuna ukuya esibhakabhakeni."

:::

::: grammar-box

**3\. Instrumentalis (⟪तृतीया⟫)**

Ngaphezu kwe-Ablativ (⟪पञ्चमी⟫), i-Instrumentalis (⟪तृतीया⟫) isetshenziselwa ukuchaza isizathu noma isizathu. Kuma-noun abesifazane, i-Instrumentalis ivame ukuba yimfuneko.

:::

Isibonelo:

::: indent

⟪क्रोधेन पुत्रं हन्ति⟫ = "Ushaya indodana yakhe ngenhlitiyo" = "Ushaya indodana yakhe enhliziyo"

:::

::: grammar-box

**4\. Ama-Noun**

Ngaphezu kwalokho, ungachaza izizathu ngokwakha

*   ⟪कारण⟫ n. "Isizathu": ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ m.
*   amanye ama-noun anesibalo "Isizathu"

\+ Genetiv (⟪षष्ठी⟫) noma njengenxenye yesibili yama-composita:

:::

Isibonelo:

::: indent

⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ njll.) = "ngenxa yomusa"

:::

::: grammar-box

**5\. ⟪इति⟫**

Isizathu senkolelo singachazwa njengocabango nge-⟪इति⟫:

:::

Isibonelo:

::: indent

⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫  = "Ngoba u-Sugata uvukile ngokuphelele ekuqinisweni, u-Ānanda ubuza u-Gautama ngokufundisa kwakhe" (« "Cabanga "U-Sugata uvukile ngokuphelele ekuqinisweni" ...)

:::
