# Isifundo 15

## 15.1. ⟪सुभाषितम् गुरुशुश्रूषया विद्या पुष्कलेन धनेन वा । अथवा विद्यया विद्या चतुर्थी नैव विद्यते ॥⟫

## 15.2. Determinativkomposita = Tatpuruṣa m. = ⟪तत्पुरुष⟫

Ubudlelwano phakathi kwezinto ezichazwe ngama-noun (izigama zento nezokuchaza) bungaboniswa ngokufaka i-genitive construction noma i-Tatpuruṣa (⟪तत्पुरुष⟫). Ngokufanayo, ukufaka ama-adjective noma ukufaka izigama zento ngendlela ye-apposition kungaboniswa ngohlobo oluthile lwe-Tatpuruṣa, okungukuthi i-Karmadhāraya (m.) = ⟪कर्मधारय⟫.

⟪तत्पुरुषः⟫ = ⟪तस्य पुरुषः⟫ "umuntu wakhe", okusho ukuthi isibonelo salolu hlobo lwe-composita sisetshenziswa njengesibonelo salolu hlobo.

::: grammar-box

Kuma-composita e-determinative (Tatpuruṣa), i-noun (isigama zento noma isigama sokuchaza) ichazwa ngokuningiliziwe yi-noun noma i-adverb. Igama elichazwayo liba ingxenye yesibili ye-compositum.

Ubudlelwano phakathi kwengxenye yokuqala (ingxenye e-determining) nengxenye yesibili (ingxenye e-determined) bungaba:

*   ngokufaka noma ngokufaka: uma i-composita iyahlukaniswa, ingxenye yokuqala ibe yisichasiso esiningiliziwe se-ingxenye yesibili ngokufaka okufanayo (okungukuthi, ngaphandle kwesitatimende, i-nominative (⟪प्रथमा⟫), noma i-syntactic case esitatimendeni)
*   ngokufaka: ingxenye yokuqala ibe yi-case ehlukile kune-ingxenye yesibili (okungukuthi, hhayi i-nominative - ⟪प्रथमा⟫)
*   ngokufaka: ingxenye yokuqala iyisigama esingaguquki

Ubudlelwano bekhazasi bobabili amagilana e-compositum abazimele ekutheni, ngaphansi kweliphi ikhazasi i-compositum imi: i-compositum ngempela iyigama elilodwa elingaguquguquki:

isb.

> Nom. sg. ⟪तत्पुरुषः⟫ = ⟪तस्य पुरुषः⟫  
> Akk. sg. ⟪तत्पुरुषम्⟫ = ⟪तस्य पुरुषम्⟫  
> Instr. sg. ⟪तत्पुरुषेण⟫ = ⟪तस्य पुरुषेण⟫  
> Gen. sg. ⟪तत्पुरुषस्य⟫ = ⟪तस्य पुरुषस्य⟫  
> Nom. pl. ⟪तत्पुरुषाः⟫ = ⟪तस्य पुरुषाः⟫  
> njll.

Isibalo se-Tatpuruṣa si- - ngaphandle kwezimpendulo ezimbalwa - sesigaba sayo esilandelayo.

:::

## 15.4. Izakhi zokumiyaza ezine-ekompound ephambili, ezinobudlelwano be-case obungu-attributive/appositional ne-ekompound yesibili = Tatpuruṣa ngokucacile

::: grammar-box

Izixhumanisi ze-Tatpuruṣa zivumelekile ezixhumaneni ze-nomina (ama-noun nama-adjective), lapho ingxenye ephambili — ngokuhambisana nemithetho ye-syntax — ingaba noma yikuphi i-case. Ngokwemvelo, ingxenye ephambili ivame ukumelela i-Genitive (⟪षष्ठी⟫), ngoba yilona case eliveza ubudlelwano phakathi kwe-nomina.

:::

isib.

⟪क्षत्रियपुत्रः⟫ = ⟪क्षत्रियस्य पुत्रः⟫ = "indodana ye-Kṣatriya", "i-Kṣatriya encane", "umuntu ohlanganisiwe kumbutho wezinkosi"  
Akk. sg. ⟪क्षत्रियपुत्रम्⟫  
Gen. sg. ⟪क्षत्रियपुत्रस्य⟫  
njll.  

⟪गुरुभावः⟫ =  ⟪गुरोर्भावः⟫  = "imvelo yomfundisi"

⟪धनलोभः⟫ = ⟪धनस्य लोभः⟫ = "ukukhathazeka ngempahla, ukukhathazeka"

⟪लोकगतिः⟫ =  ⟪लोकस्य गतिः⟫ = "ukuhamba kwendawo, ukuziphatha kwabantu"

Kacisibindi ubudlelwano be-genitive bungasebenzisa i-Tatpuruṣa. Izimiso ezimbalwa zokuhluka bheka isib. ku-Kale, A higher Sanskrit grammar § 211, lapho futhi khona izindawo ezihambisanayo ku-Pāṇini.

Kodwa-ke, ingxenye yokuqala ye-Tatpuruṣa ingamelela noma yikuphi i-kasus ngokomqondo. Noma kunjalo, akukwazi ukuthi zonke izimo ze-syntactic ze-kasus ziguqulwe zibe yi-Tatpuruṣa. Imithetho ehlobene nayo ingatholakala ku-Kale, A higher Sanskrit grammar § 203 - 217 noma ku-Pāṇini 2,1,22 - 2,2,22 uma kunenkinga.

::: grammar-box

Ingxenye yokuqala ingaba yi-singular, i-dual, noma i-plural lapho kuxazululwa khona i-composite. Ukuthi yiphi indlela ekhona kumele kutholakale ngokusho kwencazelo nesimo.

:::

Izibonelo:

Ingxenye yokuqala imele i-accusative (⟪द्वितीया⟫): isib. ezimweni ezithile ze-PPP kumazwi okuhamba (Pāṇini 2,1,24):

⟪ग्रामगतः⟫ = ⟪ग्रामं गतः⟫ = "umuntu oye edolobheni"
⟪नरकपतिता⟫ = ⟪नरकं पतिता⟫ = "owesifazane owahla emoyeni"

Ingxenye yokuqala imele i-instrumentalis (⟪तृतीया⟫): isib. njalo i-agens (⟪कर्तृ⟫) yezakhiwo zamagama ezine-suffix kṛt (isib. i-PPP):

⟪देवकृतम्⟫ = ⟪देवेन⟫ / ⟪देवैः कृतम्⟫ = "okwenziwe ngumlinganiswa / ngabalinganiswa"
Kwakungaxazululeka futhi: ⟪देवस्य⟫ / ⟪देवानां कृतम्⟫ = "umsebenzi / ukwenza komlinganiswa / ngabalinganiswa ; umsebenzi womlinganiswa, umsebenzi wabalinganiswa"

⟪बुद्धरक्षिता⟫ = ⟪बुद्धेन रक्षिता⟫ = "owokubuswa ngu-Buddha" (igama elithile)

## 15.6. Ifomu lophawu olungaphambili kuma-composite (⟪समास⟫ m.)

::: grammar-box

Kuzo zonke izinhlobo zama-composite, uphawu olungaphambili ngokuvamile luyisisekelo sombhalo ongashintshiwe. Izinombolo ezimbili zama-nomina zisebenzisa isisekelo esibuthakathaka. Ama-adjective ama-feminine, achaza ingxenye elandelayo ku-composite, ngokuvamile asebenzisa isisekelo sama-masculine:

umzekelo,

⟪पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती क्षत्रिया⟫ = "umfazi we-Kṣatriya onentshisekelo"  
⟪गुणवत्पुत्रः⟫ = ⟪गुणवान् पुत्रः⟫ = "umzala onezimpawu ezinhle"

:::

## 15.7. Ukwahlukaniswa kuka-⟪तत्पुरुष⟫

1. ⟪प्रथमातत्पुरुषः⟫ : Uphawu olungaphambili luse-⟪विग्रहवाक्य⟫ nge-Nominative (⟪प्रथमा⟫)
2. ⟪द्वितीयातत्पुरुषः⟫ : Uphawu olungaphambili luse-⟪विग्रहवाक्य⟫ nge-Accusative (⟪द्वितीया⟫)
3. ⟪तृतीयातत्पुरुषः⟫ : Uphawu olungaphambili luse-⟪विग्रहवाक्य⟫ nge-Instrumentalis (⟪तृतीया⟫)
4. ⟪चतुर्थीतत्पुरुषः⟫ : Uphawu olungaphambili luse-⟪विग्रहवाक्य⟫ nge-Dative (⟪चतुर्थी⟫)
5. ⟪पञ्चमीतत्पुरुषः⟫ : Uphawu olungaphambili luse-⟪विग्रहवाक्य⟫ nge-Ablative (⟪पज्चमी⟫)
6. ⟪षष्ठीतत्पुरुषः⟫ : Uphawu olungaphambili luse-⟪विग्रहवाक्य⟫ nge-Genitive (⟪षष्ठी⟫)
7. ⟪सप्तमीतत्पुरुषः⟫ : Uphawu olungaphambili luse-⟪विग्रहवाक्य⟫ nge-Locative (⟪सप्तमी⟫)

* ⟪कर्मधारयः⟫ : i-Tatpuruṣa engapositional, phakathi kwesinye:
* ⟪उपमानपूर्वपदकर्मधारयः⟫ : i-⟪विग्रहवाक्य⟫ ene-⟪इव⟫ emva kwengxenye yokuqala
* ⟪उपमानोत्तरपदकर्मधारयः⟫ : i-⟪विग्रहवाक्य⟫ ene-⟪इव⟫ emva kwengxenye yesibili
* ⟪रूपकसमासः⟫ : i-⟪विग्रहवाक्य⟫ ene-⟪एव⟫
* ⟪द्विगुसमासः⟫ : inombolo yezibalo ephawuni olungaphambili
* ⟪नञ्तत्पुरुषः⟫ (⟪निषेधतत्पुरुषः⟫) : ngokungavumiwa kuka-a-, an- ephawuni olungaphambili
* ⟪गतिसमासः⟫ : nge-preposition ephawuni olungaphambili
* ⟪प्रथमातत्पुरुषः⟫ njll. (buka phezulu)

### 15.7.1. Ukuhlukaniswa kwe-⟪कर्मधारय⟫

1.  ⟪विशेषणपूर्वपदकर्मधारयः⟫ : Isiqalo siyisichasiso (⟪विशेषण⟫)
2.  ⟪विशेषणोभयपदकर्मधारयः⟫ : zombili iziqalo ziyizichasiso, lapha kufakwa nezichasiso eziveza isikhathi esidlule: "kuqala wageza, wabe esegcotshwa"
3.  ⟪उपमानपूर्वपदकर्मधारयः⟫ (=  ⟪उपमासमासः⟫): esiqalweni isiqhathaniso, esiphethweni isici esiqhathanisiwe: isib. "muhle njengomlotha"
4.  ⟪उपमानोत्तरपदकर्मधारयः⟫ (=  ⟪उपमितसमासः⟫):  isiqhathaniso esiphethweni
5.  ⟪रूपकसमासः⟫ : ⟪विग्रहवाक्य⟫ ngo-⟪एव⟫ ngemuva kwesiqalo (umfanekiso)
6.  ⟪संभावनपूर्वपदकर्मधारयः⟫ : zombili iziqalo zibhekisela kumuntu noma entweni efanayo, isib. ⟪कालिदासकविः⟫ = ⟪कालिदास⟫ ⟪इति⟫ ⟪कविः⟫ = "imbongi uKālidāsa"
7.  ⟪कर्मधारयः⟫ ngo-⟪कु⟫ / ⟪कद्⟫ njengesiqalo: "kubi..."
8.  ⟪कर्मधारयः⟫ ngo-⟪किम्⟫ njengesiqalo: ukusola
9.  PPP + PPP eliphikisiwe: "ngokwengxenye", isib. ⟪कृताकृतम्⟫ = "kwenziwe ngokwengxenye"
10.  ⟪द्विगुसमासः⟫ : inombolo esiqalweni
