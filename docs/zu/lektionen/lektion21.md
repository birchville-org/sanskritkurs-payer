## 21.3. Izindlela ezihloniphasayo zokukhuluma

::: grammar-box

**Singakhuluma nomuntu ngendlela yesi-2 singular ngaphandle kokungahloniphi. Kodwa-ke, uma sifuna ukuba nobulili, singasebenzisa igama elinentshisekelo ethi "Oyihloniphekile" noma okufanayo, bese sisebenzisa isenzo esingu-3 singular noma plural, noma sisebenzise isakhiwo se-passive. Ukukhula kobulili ekusetshenzisweni kwesigaba sokukhuluma kungaba kanje:**

:::

::: indent

**2. sg. » 2. pl. » 3. sg. negama elihambisanayo » 3. pl. negama elihambisanayo**

:::

**Igama elibalulekile kakhulu lobulili ngu-⟪भवन्त्⟫ , fem.: ⟪भवती⟫ . Lihambisana nokuthi "Wena" okuhloniphekile.**
Le ⟪भवन्त्⟫ iyisisho esivela ku-⟪भगवन्त्⟫, ukuguquguquka kwako kuyokwama amagama aphethwe ngo-**-vant** (bheka [Lektion 13](lektion13.md)). Le ⟪भवन्त्⟫ kumele ihluke kwi-participle yesikhathi esiyimanje P ka-⟪भू⟫ "ukuba" ⟪भवन्त्⟫ : i-nom sg. mask. ka-⟪भवन्त्⟫ "Wena" ilungu ⟪भवान्⟫, leyo ye-participle ⟪भवन्⟫.

**Beispiele:**

::: indent

**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = "Wenzani?"

:::

höflicher:

::: indent

**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**

:::

Femininum:

::: indent

**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**

:::

Amanye amagama angasetshenziswa ngendlela efanayo ne-⟪भवन्त्⟫:

*   ⟪आर्य⟫ (ubulili besifazane: ⟪आर्या⟫) "Ohloniphekile". Isib. **⟪यदार्य⟫ ⟪इच्छति⟫** "Okufisayo"
*   ⟪महाभाग⟫ "lowo onesabelo / inhlanhla enkulu = ohloniphekile". Ngokuvamile isetshenziswa abesifazane lapho bekhuluma noma bekhuluma ngamadoda anesikhundla esihle. Ivamile kakhulu esiSanskrit sanamuhla esikhulunywayo.

Uma umuntu efuna ukuveza hhayi nje inhlonipho kodwa nokukhulekela othile, esikhundleni se-⟪भवन्त्⟫ kusetshenziswa i-⟪अत्रभवन्त्⟫ kumuntu okhona noma oseduze, kanti i-⟪तत्रभवन्त्⟫ kumuntu ongekho noma okude. I-⟪अत्रभवन्त्⟫ ne-⟪तत्रभवन्त्⟫ zingahunyushwa ngokuthi "Wena", "Mhlonishwa", "Mfundisi Omkhulu" njll.:

::: indent

**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = "Ingabe le nkosikazi (ekhona lapha) ingumkakho?"
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (encwadini noma ocingweni) = "Unjani?"

:::
