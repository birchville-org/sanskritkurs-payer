# Isifundo 54

## 54.1. Isaziso

Ngokusebenzisa uLwazi 54, isemestha yesibili siqala ezifundweni zeyunivesithi. Kusukela manje, uhlelo lusebenza ngasohlangothini lwesihloko esikhulu salesemestha: ukufunda i-Bhagavadgītā yonke. Injongo yokufunda ukuthola ukukhululeka okwanele ekufundeni umbhalo ophakathi nendawo ukuze ekugcineni kwesemestha, ingxenye enkulu ye-Bhagavadgītā ingaguqulwa ngokushesha. Ekugcineni, ezifundweni zeyunivesithi kwakunikezwa amaphuzu ezinhlamvu, kodwa kamuva abafundi kumele basebenzise izincwadi zezinhlamvu (Monier-Williams, Apte, PW).

Uhlelo lwe-Bhagavadgītā alukabonakali online.

Izifundo zohlelo lwe-Sanskrit zihlanganisa izihloko ze-Sanskrit grammar, ezingakabonakali.

## 54.5. Izinhlobo zokwakhiwa kwe-Aorist (⟪लुङ्⟫)

::: grammar-box
**Konke okufanayo yonke izinhlobo zokwakhiwa kwe-Aorist (⟪लुङ्⟫) yi-Augment a-, eyafakwa ngaphambi kwemithetho efanayo ne-Imperfect (⟪लङ्⟫).**

Kwi-Sanskrit, kuphela i-Indikativ ne-Prekativ zivame ukusetshenziswa kwi-Aorist.
:::
::: grammar-box
**Kukhona lezi zinhlobo zokwakhiwa kwe-Aorist (⟪लुङ्⟫):**

1.  Ama-Aorist angasimbi (asigmatic): 
*   54.1. I-Root Aorist: Augment + Root + Sekondari ending
*   54.2. I-Theme-vowel Aorist: Augment + Root + **a** + Sekondari ending
*   54.3. I-Reduplicated Aorist: Augment + **okuphindwe kabili** Root + **a** + Sekondari ending 
2.  Ama-Aorist asimbi (sigmatic Aorist: s noma isilabathi esine-s (ṣ) ephambili kumgomo wabantu 
*   54.4. I- -s-Aorist: Augment + Root + **s** \+ Sekondari ending
*   54.5. I- -iṣ-Aorist: Augment + Root + **i** + **ṣ** + Sekondari ending
*   54.6. I- -siṣ-Aorist: Augment + Root + **siṣ** + Sekondari ending
*   54.7. I- -sa-Aorist: Augment + Root + **s** + **a** + Sekondari ending

Ukwahlwa kwemithombo kumakhonkco okwakheka abhekisela kumakhonkco ngamunye
:::
