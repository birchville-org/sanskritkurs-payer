## 38.4. Ukwakheka kwama-noun: ⟪तद्धित⟫-suffix -in

## 38.6. I-syntactic malunga ne-⟪आत्मन्⟫

::: grammar-box

⟪आत्मन्⟫ **maskulinum** ingasebenziswa **kwisinye** njengophawu olubuyisela emva (reflexive pronoun) zonke izinto ezintathu, inani (kubandakanya i-dual kunye ne-plural) kunye nabantu.

:::

Imizekelo:

::: indent

⟪आत्मन्येषा दोषं न पश्यति ।⟫ "Uyabona ukuba akukho nje impazamo kuye"

⟪आत्मानं स्तुवन्ति ।⟫ "Bazidumisa ngokwabo"

:::

::: grammar-box

I-Genitive (⟪षष्ठी⟫) ⟪आत्मनस्⟫ ingaba khona endaweni yoko "yami/wakho/wakhe... ngokwakhe"

:::

Umzekelo:

::: indent

⟪आत्मनो गृहं प्रविशति ।⟫ "Ungena ekhaya lakhe."

:::

::: grammar-box
