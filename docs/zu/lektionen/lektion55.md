# Isifundo 55

## 55.1. I-a-Aorist (I-aorist enevokali yethemu)

::: grammar-box

**I-a-Aorist yakhiwa njenge-Imperfect (⟪लङ्⟫) ye-class yesi-6 ye-Prezent (⟪तुदादि⟫), okusho ukuthi:**

**Augment + impande esemazingeni aphansi + a + isiphetho sesibili**

**I-a- iboshwa izindawo ezifanayo njenge-Imperfect ngokushintshwa yi-ā-.**

**Akukho infix ye-nasal.**

**I-Ātmanepada ayivamile; emaphandleni e-Ubayapada ivame ukwakhiwa ngokwamanye ama-Aorist classes (bheka Kielhorn, Grammar §340 kanye ngezansi kuma-Aorist classes afanele).**

**Uhlu lwezimpande ezine-Aorist enjalo, ku-Kielhorn, Grammar §340.**

:::
