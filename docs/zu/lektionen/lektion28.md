# Isifundo 28

## 28.1. I-Kausativum (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Uma ufuna ukukhombisa ukuthi umuntu noma into ibangela noma ivumela ukuthi umuntu omunye noma into enye yenze noma ayibone into echazwa ngqo yi-Root (noma ingabe inepreverb noma cha), kusetshenziswa i-Kausativum (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫).**

Isibonelo:
⟪गम्⟫ "uya" » I-Kausativ: ⟪गमयति⟫ "uvumela ukuthi umuntu aye; uyathumela"
⟪दृश्⟫ "ubona" » I-Kausativ: ⟪दर्शयति⟫ "wenza ukuthi kubonakale = uyakhombisa"
:::

## 28.2. Ukwakhiwa kwesibhalo se-Kausativ (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Isakhiwo 1:**

**Uma i-Root (noma ingabe inepreverb noma cha) engemuva kwe-Kausativ INTRANSITIVE (okusho ukuthi ayikwazi ukuba ne-accusative object) noma ichaza ukunyakaza, ulwazi, ulwazi noma ukudla:**

**I-Agens (⟪कर्ता⟫) ye-Kausativ nge-Nominative (⟪प्रथमा⟫) — I-Agens yento ebangelwayo nge-Accusative (⟪द्वितीया⟫) — (Injongo yokunyakaza, into yolwazi njll. nge-Accusative = ⟪द्वितीया⟫) — I-Verb nge-Kausativ**
:::
Izibonelo:

⟪दुर्जनो रामं मोहयति⟫ = "umuntu ongenalungelo ubangela ukuthi u-Rāma adideke = udide u-Rāma = ubangela ukuthi u-Rāma aphambuke"
Umphumela: ⟪रामो मुह्यति⟫ = "u-Rāma udideke / ubuthe / uphambuke."

⟪रामः शत्रून्स्वर्गं गमयति⟫ = "u-Rāma wenza izitha ziye ezulwini = ethumela izitha ezulwini"
Umphumela: ⟪शत्रवः स्वर्गं गच्छन्ति⟫ = "izitha ziya ezulwini / zifika ezulwini"

⟪गुरू रामं वेदार्थं वेदयति⟫ = "Uthisha wenza u-Rāma azwe incazelo ye-Veda = achaze / afundise u-Rāma incazelo ye-Veda"
Umphumela: ⟪रामो वेदार्थं वेत्ति⟫ = "u-Rāma uyazi / uqonda incazelo ye-Veda"

⟪स रामं वेदमध्यापयति⟫ = "ufundisa uRama iVeda"
Umphumela: ⟪रामो वेदमधीते⟫ "uRama ufunda iVeda"

⟪रामो देवानामृतमाशयति⟫ = "uvumela izinkosi zidle ukudla kokungapheli = ukudla ukudla kokungapheli kwezinkosi" (⟪अश्⟫ 9 "ukudla")
Umphumela: ⟪देवा अमृतमश्नन्ति⟫ "Izinkosi zidla ukudla kokungapheli"

**Abagxebi basekhaya babheka lezi zimo njenge-Kausative:**

Izaziso:

2. **pālayati** yi-Kausative yangempela, kodwa ibhekele impande **pṛ** 3 "ukudlulisa, ukusindisa, ukuvikela": **pārayati** (pār-aya-ti) » **pālayati** (ezinye izindawo ze-India, u-r ulingana no-l, kwezinye u-l ulingana no-r).


## 28.4. Ukwakhiwa Kwe-Passive (⟪यक्⟫) ku-Kausative

::: grammar-box
**I-Passive ye-Kausative yakhiwa kanje:**

**I-Stem ye-Kausative NGAPHANDLE KO--aya- + I-Suffix ye-Passive -ya-**

Izibonelo:
**bhāvyate** (bhāv-ya-te) "ukuthi uyena/uyena/uyena ukhiqizwa"
**sthāpyate** (sthāp-ya-te) "ukuthi uyena/uyena/uyena ukhishwa"
:::
Ngenkathi i-Passive yempande yokuqala ivame ukwakhiwa ngempande ephansi, i-Passive ye-Kausative ivame ukwaziwa ngokuthi yakhiwa ngempande ephezulu noma enelungelo.

**budh** I-Future-Kausativ: **bodhayiṣyati** (bodh-ay-i-ṣya-ti): "uzokuvusa"

## 28.6. Ukwakhiwa kwe-PPP (⟪क्त⟫) ku-Kausativ

::: grammar-box
**I-Kausativ stem ephelele ku--ay- (ngaphandle kuka--a- ophumayo) + -i- + -ta**

Izibonelo:
**gam** — **gamayati** — **gamita** (gam-i-ta) "okuthumela" (I-PPP ye-root elula: **gata**)
**sthā** — **sthāpayati** — **sthāpita** (sthāp-i-ta) "okubeka"
:::

## 28.7. Ukwakhiwa kwe-Absolutiv (⟪क्त्वा⟫ . ⟪ल्यप्⟫) ku-Kausativ

::: grammar-box
**I-Absolutiv ephelele ku--tvā ivela ku-stem ye-Kausativ ephelele ku--ay- (ngaphandle kuka--a- ophumayo):**

**I-Kausativ stem ephelele ku--ay- + -i- + -tvā**

Isibonelo:
**sthāpayitvā** (sthā-pay-i-tvā) "ngemuva kokuba esebekile"
:::
::: grammar-box
**I-Absolutiv ephelele ku--ya ivela ku-Kausativa ene-preverb ngokuvamile ku-stem ye-Kausativ NGAPHANDLE kuka--aya-**

Izibonelo:
**prabudh** — **prabodhayati** — **prabodhya** (pra-bodh-ya) "ngemuva kokuba evuse"
**ānī** — **ānayati** — **ānāyya** (ā-nāy-ya) "ngemuva kokuba eshiye ukukhokhela, ngemuva kokuba eshiye ukuletha"
:::
::: grammar-box
**Kodwa-ke, uma i-syllable ye-root ye-Kausativ inokufaka okufushane -a- ngaphambi kwe-consonant eyodwa, u--ya we-Absolutiv uvela ku-stem ye-Kausativ ephelele ku--ay- (ngaphandle kuka--a- ophumayo)**

Isibonelo:
**āgam** — **āgamayati** — **āgamayya** (ā-gamay-ya) "ngemuva kokuba eshiye ukufika"
:::

## 28.8. Ukwakhiwa kwe-Infinitive (⟪तुमुन्⟫) ku-Causative

::: grammar-box
**I-Infinitive ye-Causative yakhiwa nge-Causative stem ephelela ngo- -ay- (ngaphandle kwe-a yokugcina):**

**I-Causative stem ephelela ngo- -ay- + -i- + -tum**

Isibonelo:
**jan** — **janayati** — **janayitum** (janay-i-tum) "ukuvela"
:::

**B. Thumela la maqamu alandelayo, yahlula ama-composita ngesiSanskrit bese wakha amasentensi usebenzisa izenzo ezilula ukuchaza okwenzekayo uma okubangelwa yi-Causative kwenziwa:**

Isibonelo: ⟪रामो दासं भारं हारयति⟫ » ⟪दासो भारं हरति शत्रुजयाय क्षत्रियो ब्राह्मणेन हरिहरं याजयित्वारीन्योत्स्यते ॥१॥ गुरुर्बालान्वेदमध्याप्य गृहं गतः ॥२॥ गर्भगृहे देवीप्रतिमा दृश्यते ॥३॥ यजन्नग्निनान्नमादयति पानं च पाययति ॥४॥ पुत्रे जाते ब्राह्मणी दासं ब्राह्मणं गमयति । ब्राह्मणस्तं दासं गृहं प्रवेश्य पुत्रं पृच्छति । सुभगः पुत्र इति दासो वक्ति । तच्छ्रुत्वा ब्राह्मणो सुखतां गच्छति ॥५॥ स्तुवता नरेण देवा महाकवेः स्तोत्राणि श्राविताः ॥६॥ आर्ययोधैर्महायुद्धे ऽरयो मार्यन्ते ॥७॥ सत्क्षत्रिया ब्राह्मणेनेष्टदेवतापूजां कारयति । स ब्राह्मणः पूजां कृत्वा क्षत्रियाया धनमेषिष्यति ॥८॥ धनं जेतुं महाक्षत्रियो योधव्याघ्रैर्व्रतानि चारयिष्यति ॥९॥ पापान्मोक्षार्थेन सुगत आर्यजनानार्यसत्यानि बोधयति ॥१०॥⟫
