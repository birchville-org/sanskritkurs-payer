# Isifundo 53

## 53.1. I-Dual (⟪द्विवचन⟫ n.) yamaNoun

::: grammar-box

**I-Dual (⟪द्विवचनम्⟫) isetshenziselwa ukuchaza "abili":**

:::

::: indent

⟪अश्विनौ⟫ "u-Aśvin ababili"

:::

**Ukusetshenziswa kwe-Dual kuyadingeka lapho kungamakhulu amabili noma okufanayo:**

::: indent

⟪हस्तौ⟫ "izandla (lomuntu oyedwa)"
⟪पादौ⟫ "izinyawo (lomuntu, inkomo noma okunye okunezinyawo ezimbili)"

:::

**Ngamunye, i-Dual ingachaza indoda kanye nenkosikazi yohlobo olufanayo (uhlobo, i-genus):**

::: indent

⟪पितरौ⟫ "ubaba nomama = abazali"

:::

**Amagama achaza "ipheya" - isib. ⟪युग⟫ n., ⟪द्वन्द्व⟫ n., ⟪द्वय⟫ n. - ahlala esetshenziswa nge-Singular, ngaphandle kokuba kungamapheya amabili noma ngaphezulu:**

::: indent

⟪बाहुद्वयम्⟫ "ipheya lezandla"
