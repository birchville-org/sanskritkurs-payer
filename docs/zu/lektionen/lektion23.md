# Isifundo 23

## 23.1. I-Infinitive (⟪तुमुन्⟫)

::: grammar-box

**Uma ufuna ukukhombisa ngesiSanskrit ukuthi umsebenzi owenzeka ngenxa yomunye umsebenzi ("ukuze"), ungasebenzisa i-Infinitive (⟪तुमुन्⟫) yomsebenzi owenzeka ngenxa yawo. I-Infinitive ichaza ikakhulukazi injongo noma inhloso:**

> ⟪रामो गुरुवचनं श्रोतुं गतः⟫ = "URama uye ukuze azwe ukhuluma kweNkosi."

**Qaphela ukuthi i-Infinitive — ngokukhethekile ezimweni ezimbalwa ezichaziwe kahle — ingase ibe yisihloko noma into yomkhondo wenkanyezi:**

> Ngakho-ke, akuvumelekile ukuthi uqaphele ngokuthi "ufunda ukudansa" nge-Infinitive ("ukudansa"), kodwa kufanele usebenzise igama lenkanyezi, isibonelo: ⟪नर्तनमधीते⟫ (⟪इ⟫ + ⟪अधि⟫ 2 Ā: "ukufunda").

**I-Infinitive isetshenziswa futhi namagama noma izinto ezinokuthi "ukufuna" noma "ukukhathala", uma i-Agens (⟪कर्तृ⟫) ye-Infinitive nenkanyezi ziyafana:**

> ⟪रामो गुरुवचनं श्रोतुमिच्छति⟫ = "URama ufuna ukuzwa ukhuluma kweNkosi."

**I-Infinitive isetshenziswa futhi namagama anokuthi "ukwazi", "ukuba khona", "ukwazi", "ukuqala":**

> ⟪साधुरधर्मं कर्तुं न शक्नोति⟫ = "Umuntu oyingcwe akakwazi ukwenza okungalungile."  
> ⟪अस्ति भोक्तुमन्नम्⟫ = "Kukhona ukudla okufanele kudliwe" (⟪भुज्⟫ 7: Ā: ukudla, P: ukulawula)

**I-Infinitive isetshenziswa futhi namagama anokuthi "anezinto ezanele", "anezinto ezikwazi" kanye nezinto ezinokuthi "ukwazi", "amandla", "ukukwazi":**

> ⟪अस्त्यग्नेर्विभवः सर्वं दग्धुम्⟫ = "Umlilo unamandla okushisa konke."

**Ngisho namagama angasho isikhathi angasetshenziswa khona i-infinitive emishini efana nokuthi "Kuyisikhathi sokwenza ...":**

> ⟪कालो भोजनं सेवितुम्⟫ = "Kuyisikhathi sokuzinza ekudleni" = "Kuyisikhathi sokudla"

**I-infinitive ingasetshenziswa ngendlela esebenzayo nangendlela ephathwayo. I-infinitive ephathwayo ngesiJalimane iboniswa ngesiSanskrit ngokuthi isenzo (kakhulu ⟪शक्⟫ "ukwazi, ukukwazi"), esivela kuyo i-infinitive, siba sephathwayo.**

**Ngokubhekiselele kwinto, i-infinitive iziphatha njengofomu lwesenzo, okusho ukuthi into eqondile (⟪कर्मन्⟫) ibekwe ku-akkusativ (⟪द्वितीया⟫), noma i-kasus eyidingayo isenzo esithile; lapho i-infinitive isetshenziswa ngendlela ephathwayo, into eqondile ibekwe ku-nominativ.**

isib.

> ⟪साधुरधर्मं कर्तुं न शक्नोति⟫ = ⟪साधुनाधर्मः कर्तुं न शक्यते⟫ = "Umntu oyingcwe akakwazi ukwenza ukungalungile."

**Kumuntu wesibili, ⟪अर्ह्⟫ + i-infinitive ivame ukusetshenziswa njengolawulo oluthambile: "Ufanele."**

**Uma i-infinitive ixhomekeke kwinani, ayikwazi ukuxhuma nalowo nombhalo ukuze kube yi-compositum. Ngaphandle kwe-Bahuvrīhi, enesigaba sesibili ⟪काम⟫ noma ⟪मनस्⟫:**

> ⟪वक्तुकामः⟫ = ⟪वक्तुं कामो यस्य सः⟫ = "owufuna ukukhuluma; othanda ukukhuluma".

:::

## 23.2. Ukwakhiwa kwe-Infinitiv (⟪तुमुन्⟫)

::: grammar-box

**isigaba esiphezulu se-root + -tum**

**noma**

**isigaba esiphezulu se-root + -i- + -tum**

**Amakhonkco aphelele e-root aguqulwa ngaphambi kwe-tum ngokufanayo nalokhu kuguquka okwenzeka ngaphambi kwe-ta ye-PPP.**

**Amaphrephhi anezingxenye yakha i-infinitive ngendlela efanayo nezimpande ezilula.**

:::

Izibonelo:

::: indent

⟪दिश्⟫ : ⟪देष्टुम् रुद्⟫ : ⟪रोदितुम्⟫

:::

Akukho imithetho eqinileyo engaqondakala ngokusetshenziswa kwe-vowel yokuxhumanisa -i-. Ngokuyisiseko, ukusabalala kwe-vowel yokuxhumanisa kwi-infinitive kuhambisana nalokho kwe-future.

Kufanele kuqagelwe ngokukhethekile la ma-infinitive ezimpande ezifundwe kuze kube manje:

::: indent

⟪गम्⟫ : ⟪गन्तुम् प्रच्छ्⟫ : ⟪प्रष्टुम्⟫

:::

-ra- as the high grade of -ṛ- have in the infinitive:

::: indent

⟪दृश्⟫ : ⟪द्रष्टुम् सृज्⟫ : ⟪स्रष्टुम्⟫

:::

Ezinye izimpande ezine -ṛ- endaweni yesibili ukusuka emuva zinikezela -ra- noma -ar-, uma zinganiṭ.

## Isifundo 23.6. Ukuqinisekisa
