# Μάθημα 31

## 31.1. Η 7η τάξη ενεστώτα (⟪रुधादि⟫ = «⟪रुध्⟫ κ.λπ.»)

::: grammar-box
**Εκπαίδευση:**

**Πριν από τα τελικά σύλλαβα της βαθιάς ρίζης, παρεμβάλλεται ένα λεγόμενο nasalinfix (-na- ή -n-):**

*   **στο ισχυρό στέλεχος: -na-**
*   **στο αδύναμο στέλεχος: -n-**

**Για τη σύνθεση των τελικών συλλαβών της ρίζης με καταλήξεις που ξεκινούν από σύλλαβο, ισχύουν οι ίδιοι κανόνες όπως για τη 2η κλάση παρατατικού.**
:::
Παραδείγματα:

⟪युज्⟫ 7U «συνδέω, ζεύγνυμι»

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. sg.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(vor Guttural im Wortinnern werden Nasale durch -ṅ- ersetzt) |
| | **3. pl.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Optativ** | **3. sg.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. pl.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Partizip Präsens** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brfem.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "σταματώ, φέρνω σε ακινησία"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. sg.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. pl.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Optativ** | **3. sg.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. pl.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Partizip Präsens** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brfem.: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**Σε ορισμένες ρίζες, το -n- του αδύναμου παρόντος θέματος έχει εισχωρήσει και σε μη-παροδικές κλίσεις, με αποτέλεσμα αυτές οι ρίζες να αναλύονται με προσαρτημένο ένρινο.**
:::
Παράδειγμα:

**⟪भञ्ज्⟫** 7P "σπάω"

::: indent
*   Οριστικό Παρελθόν (Ενεστώτας)
    *   3.πρ. **⟪भनक्ति⟫** (bha-na + j + ti)
    *   3.πλ. **⟪भञ्जन्ति⟫** (bha + n + j-anti)
*   Μέλλοντας: **⟪भङ्क्ष्यति⟫** (bha + n + j + sya + ti)
*   Παθητική: **⟪भज्यते⟫** (είτε από την αρχική ρίζα **⟪भज्⟫** είτε από *bhñj-ya-te)
*   PPP: **⟪भग्न⟫** (πιθανόν από *bhñj + na)
:::
