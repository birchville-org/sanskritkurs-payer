# Μάθημα 30

## 30.1. Η 9η τάξη ενεστώτα (⟪क्र्यादि⟫ = «⟪क्री⟫ κ.λπ.»)

::: grammar-box
**Παιδεία:**

*   ισχυρός ρίζας: βαθμίδα ρίζας + -nā-

*   αδύναμος ρίζας:

    *   πριν από σύμφωνο: βαθμίδα ρίζας + -nī-

    *   πριν από φωνήεν: ρίζα βαθιάς τάσης + -n-
:::
παράδειγμα:

::: indent
⟪क्री⟫ 9U "αγοράζω"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **3. Person:brĀtmanepada** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
Σε αυτή την τάση του ενεστώτα, πρέπει ιδιαίτερα να σημειωθεί ο σχηματισμός της ρίζας του ενεστωτικού για τη ρίζα ⟪ज्ञा⟫ 9U "αναγνωρίζω, γνωρίζω":

::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **3. Person:brĀtmanepada** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
Η μορφή ⟪जा⟫ που βρίσκεται στη βάση του ρίζας του ενεστώτα του ⟪ज्ञा⟫, εξηγείται είτε από μια σειρά φθοράς -ā (βαθμίδα) -nā (υψηλή βαθμίδα), είτε από dissimilation από *jñā-nā-ti.

Ορισμένες ρίζες με μακρύ φθόγγο συντομεύουν αυτόν πριν από το επίθημα ρίζας του ενεστώτα της 9ης τάξης:

Παράδειγμα:

::: indent
⟪पू⟫ 9U "καθαρίζω"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪पुनाति⟫:br(pu-nā-ti) | ⟪पुनन्ति⟫:br(pu-n-anti) |
| **3. Person:brĀtmanepada** | ⟪पुनीते⟫:br(pu-nī-te) | ⟪पुनते⟫:br(pu-n-ate) |

:::
Σύνταξη της μετοχής ενεστώτα στο Παράσμαιπαδα:

Παράδειγμα:

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant) · θηλυκό: ⟪क्रीणती⟫ (krī + n + at + ī)

## 30.2. Χρήση της Ευκτικής (⟪लिङ्⟫)

Η ευκτική χρησιμοποιείται:

::: grammar-box
**1. για τον χαρακτηρισμό**

*   **μιας επιθυμίας**
*   **μιας επιθυμίας**
*   **μιας παράκλησης**

**(εδώ επικαλύπτεται ο υποτακτικός - ⟪लिङ्⟫ - με τον απαγγελικό - ⟪लोट्⟫)**
:::
Παράδειγμα:

::: indent
⟪दासो⟫ ⟪ग्राममागच्छेत्⟫ = "Ας έρθει ο σκλάβος στο χωριό"
:::
::: grammar-box
**2. Όταν κάτι θεωρείται ως**

*   **δυνατόν**
*   **πιθανόν**
*   **υποθέσιμα**

**πρέπει να απεικονιστεί.**
:::
Παράδειγμα:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं⟫ ⟪न⟫ ⟪शृणुयात्⟫ = "Αν έφευγε από το χωριό, δεν θα άκουγε τον δάσκαλο"
:::
::: grammar-box
**3. Οι σχετικές προτάσεις με τον ευκτικό έχουν μερικές φορές την έννοια: "Αν κάποιος ..."**
:::
Παράδειγμα:

::: indent
⟪यो⟫ ⟪नृतं⟫ ⟪वदेत्स⟫ ⟪नरकं⟫ ⟪पतेत्⟫ = "Αν κάποιος έλεγε ψέματα, θα έπεφτε στην κόλαση = Αν κάποιος λέει ψέματα, πέφτει στην κόλαση"
:::

## 30.5. Sandhi του τελικού -r

::: grammar-box
**Εκτός από το -ar, ισχύουν οι ίδιοι κανόνες σάντχι για το τελικό -r όπως και για το τελικό -s.**

**-ar πριν από ηχητικά φωνήματα παραμένει -ar, ενώ πριν από r- το -r εξαφανίζεται και το -a- αντικαθίσταται από -ā-.**
:::
Παραδείγματα:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
