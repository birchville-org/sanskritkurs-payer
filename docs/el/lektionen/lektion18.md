## 18.2. Προσδιοριστικά σύνθετα (⟪तत्पुरुष⟫) με επιρρηματικό πρόθεμα

Ως επιρρηματικό (ακλιτό) πρόθετο μέλος μπορούν

*   σωματίδια
*   σωματίδια
*   σωματίδια
*   άλλα ακλίτα

::: indent
να χρησιμοποιούνται. Τέτοιοι τατπούρουσα ανήκουν συνήθως στην κατηγορία των νityasamāsa = ⟪नित्यसमास⟫ (αρσ. "μόνιμη σύνθετη λέξη"), δηλαδή των συνθέτων που δεν μπορούν να αναλυθούν καθόλου ή όχι μόνο με βάση τα λέξεις που εμφανίζονται στην ίδια τη σύνθεση.
:::
Παραδείγματα:

⟪अति⟫ "πέρα από αυτό":

::: indent
⟪अतिगुरु⟫ 3: εξαιρετικά δύσκολος, εξαιρετικά βαρύς

⟪अतिपुरुष⟫ κ.: υπέρτατος άνδρας, Superman, ήρωας

⟪अतिस्तुति⟫ θ.: υπερβολική επαφή

⟪अत्युक्ति⟫ θ.: υπερβολική ομιλία, υπέρβαση
:::
Τα πιο σημαντικά επιρρηματικά πρόθετα είναι a-/an-, su-, dus-.

⟪अ⟫ (συλλαμβάνοντας σύμφωνο), ⟪अन्⟫ (συλλαμβάνοντας φωνήεν): un-: εμφανίζεται στη σύνθετη λέξη αντί του ⟪न⟫ "όχι".

Παραδείγματα:

::: indent
⟪अनृत⟫ ουδ. = ⟪नर्तम्⟫ (= ⟪न⟫ + ⟪ऋतम्⟫): αναλήθεια, ψεύδος

⟪अकृत⟫ 3 = ⟪न⟫ ⟪कृत⟫ 3: μη-τελεσθέν, ατελής

⟪अब्राह्मणी⟫ f. = ⟪न⟫ ⟪ब्राह्मणी⟫ : μια μη-Βραχμάνιδα, αβραχμανίδα

⟪अदेव⟫ m. = ⟪न⟫ ⟪देवः⟫ : ένας μη-θεός, άθεος
:::
⟪सु⟫ "καλά, καλά"; κατά την ανάλυση της σύνθετης λέξης, οι σχολιαστές το αντικαθιστούν με επίθετο που σημαίνει "καλό" (π.χ. ⟪सुष्टु⟫ 3, ⟪शोभन⟫ 3).

Παραδείγματα:

::: indent
⟪सुकवि⟫ m.: ένας καλός ποιητής

⟪सुकृत⟫ n.: καλή πράξη

⟪सुखादित⟫ 3: καλά μασχαλισμένο

⟪सुदुःख⟫ n.: μεγάλο πάθος
:::
⟪दुस्⟫ "κακός, κακά" (προσοχή στο σάντι).

Παραδείγματα:

::: indent
⟪दुर्नय⟫ m.: κακή καθοδήγηση, κακή συμπεριφορά

⟪दुष्करण⟫ n.: κακή πράξη, δύσκολη πράξη

### 18.2.2. Σημασίες του nañ-Tatpuruṣa (α- / αν-)

Τα Tatpuruṣa με a- / an- μπορούν να έχουν τις ακόλουθες σημασίες:

1.  Ομοιότητα (⟪तत्सादृश्यम्⟫):
⟪अब्राह्मणः⟫ = ένας Kṣatriya ή Vaiśya που φέρει την ιερή κλωστή (⟪यज्ञोपवीत⟫ ουσ.) και ως εκ τούτου μοιάζει με έναν Βραχμάνο, χωρίς να είναι ένας
2.  Έλλειψη, μη ύπαρξη (⟪तदभावः⟫):
⟪अज्ञानम्⟫ = άγνοια (έλλειψη γνώσης)
3.  Ετερότητα (⟪तदन्यत्वम्⟫):
⟪अपटम्⟫ = κάτι που δεν είναι ύφασμα / ένδυμα (⟪पट⟫ αρσ.: ύφασμα, ένδυμα)
4.  Μικρότητα (⟪तदल्पता⟫):
⟪अनुदरम्⟫ = μικρή κοιλιά (μη-κοιλιά)
5.  Αποδοκιμασία (⟪अप्राशास्त्यम्⟫):
⟪अकालः⟫ = άκαιρος χρόνος
6.  Εχθρότητα (⟪निरोधः⟫):
⟪असुरः⟫ = αντίθετος θεός (σύμφωνα με την λανθασμένη ετυμολογία a-sura)

Ο ακόλουθος στίχος συνοψίζει αυτές τις σημασίες:

::: indent
⟪तत्सादृश्यमभावश्च⟫  
⟪तदन्यत्वं⟫ ⟪तदल्पता⟫ ⟪।⟫  
⟪अप्राशास्त्यं⟫ ⟪निरोधश्च⟫  
⟪नजर्थाः⟫ ⟪षट्प्रकीर्तिताः⟫ ⟪॥⟫

Έξι νοήματα του nañ (= a-/an-) αναφέρονται ....
:::
## 18.3. Ρηματικά σύνθετα

::: indent
⟪उपसर्गेण⟫ ⟪धात्वर्थो⟫  
⟪बलादन्यत्र⟫ ⟪नीयते⟫ ⟪।⟫  
⟪गङ्गासलिलमाधुर्यं⟫  
⟪सागरेण⟫ ⟪यथाम्भसा⟫ ⟪॥⟫
:::
⟪चन्द्रकीर्ति⟫ : ⟪प्रसन्नपदा⟫ σ. 2 γρ. 14επ.

Ένα πρόθεμα αλλάζει βίαια το νόημα μιας ρίζας, όπως η γλυκύτητα των υδάτων του Γάγγη από τα ύδατα της θάλασσας.

::: grammar-box

Τα ρήματα στο Σανσκριτικό μπορούν να συνδυάζονται με προθέσεις (⟪उपसर्ग⟩ αρσενικό). Συνήθως ισχύει ο σατσάντι της πρότασης. Οι πρόθεσεις μπορούν ενίοτε να τροποποιούν σημαντικά την έννοια της ρίζας, με αποτέλεσμα σε πολλές περιπτώσεις να απαιτείται η εκμάθηση της έννοιας μιας ρίζας με πρόθεση ως ξεχωριστή μονάδα. Τα ρήματα με πρόθεση μπορεί να έχουν διαφορετική φωνή (Π, Α) από την απλή ρίζα. Πριν από μια ρίζα μπορούν να τοποθετηθούν ταυτόχρονα πολλαπλές πρόθεσεις.

:::
Ορισμένες σημαντικές πρόθεσεις είναι:

⟪उप⟩ "προς, προς τα κάτω/μέσα, κατά"

Παραδείγματα:

::: indent
⟪उपगम्⟫ 1 ⟪उपगच्छति⟫ : προσέρχομαι, αναλαμβάνω

⟪उपदिश्⟫ 6 ⟪उपदिशति⟫ : υποδεικνύω, διδάσκω, συμβουλεύω

⟪उपपद्⟫ 4 Ā ⟪उपपद्यते⟫ : φθάνω, αποκαθίσταμαι

*   PPP ⟪उपपन्न⟫ 3: εξοπλισμένος με (Οργανική πτώση)

⟪उपलभ्⟫ 1 Ā ⟪उपलभते⟫ : καταλαμβάνω, αποκτώ
:::
⟪प्र⟫ "μπροστά, προς τα έξω"

Παραδείγματα:

::: indent
⟪प्राप्⟫ (pra-āp) 5 ⟪प्राप्नोति⟫ : αποκτώ

⟪प्रदिश्⟫ 6 ⟪प्रदिशति⟫ : δείχνω

⟪प्रबुध्⟫ 4 Ā ⟪प्रबुध्यते⟫ : ξυπνώ, αναγνωρίζω

⟪प्रभू⟫ 1 ⟪प्रभवति⟫ : προεξέχω, ξεχωρίζω, έχω εξουσία επί (γεν., τοπ. δοτ.)

⟪प्रवच्⟫ 2 ⟪प्रवक्ति⟫ PPP ⟪प्रोक्त⟫ (« pra + ukta) : εξηγώ, ανακοινώνω, εκφράζω

⟪प्रवद्⟫ 1 ⟪प्रवदति⟫ : εκφράζω, ονομάζω ως, θεωρώ

⟪प्रस्तु⟫ 2 ⟪प्रस्तौति⟫ : επαινώ, φωνάζω δυνατά, αναφέρομαι σε κάτι, ξεκινώ
:::
⟪वि⟫ "δια-, μακριά, δια-, απο-"

Παραδείγματα:

::: indent
⟪विगम्⟫ 1 ⟪विगच्छति⟫ : διασκορπίζομαι, παύω, εξαφανίζομαι

⟪विजि⟫ 1 Ā (!) ⟪विजयते⟫ : νικάω

⟪विमुच्⟫ 6 ⟪विमुञ्चति⟫ : αποσπάω, απαλλάσσω

⟪विवद्⟫ 1 ⟪विवदति⟫ : διαλέγομαι, αναλύω, διηγούμαι

⟪विस्मृ⟫ 1 ⟪विस्मरति⟫ : ξεχνώ

⟪विहन्⟫ 2 ⟪विहन्ति⟫ : συνθλίβω, καταστρέφω, εξοντώνω
:::
⟪सम्⟫ "μαζί, με"

Παραδείγματα:

::: indent
⟪समास्⟫ 2 Ā ⟪समास्ते⟫ : καθίζω μαζί, διαμένω, κατοικώ

⟪समि⟫ 2 ⟪समेति⟫ : συγκεντρώνομαι, ενώνομαι

⟪संगम्⟫ 1 Ā (!) ⟪संगच्छते⟫ : συγκεντρώνομαι, συναντιέμαι (φιλικά ή εχθρικά), έχω σεξουαλική επαφή με (Ακτ.)

⟪संजन्⟫ 4 Ā ⟪संजायते⟫ : να προκύψουν

*   PPP ⟪संजात⟫ 3: γεννημένος, προκύψας, εξελιγμένος

⟪सम्बुध्⟫ 4 Ā ⟪सम्बुध्यते⟫ : να ξυπνήσει πλήρως (στην αλήθεια)

⟪सम्पद्⟫ 4 Ā ⟪सम्पद्यते⟫ : να απονεμηθεί σε κάποιον, να πετύχει

*   PPP ⟪सम्पन्न⟫ 3: εξοπλισμένος με (Εργ.)
:::
::: grammar-box

Η ρίζα ⟪कृ⟫ "κάνω" δείχνει, σε σύνδεση με τα προθέματα ⟪सम्⟫ ⟪।⟫ ⟪उप⟫ ⟪।⟫ ⟪अप⟫ ⟪।⟫ ⟪परि⟫, επίσης τη μορφή ⟪स्कृ⟫

:::

::: indent
sam-kṛ 8 ⟪संस्करोति⟫ : ετοιμάζω, προετοιμάζω για θυσία, ιερουργώ

*   PPP ⟪संस्कृत⟫ 3: προετοιμασμένο για θυσία· ⟪संस्कृत⟫ n.: Σανσκριτικά: η γλώσσα που είναι κατάλληλη για θυσία· αντίστοιχο ⟪प्राकृत⟫ 3: συνηθισμένο, κοινό· ⟪प्राकृत⟫ n.: συνηθισμένη γλώσσα, Πρακρίτ (ορολογία για τις λαϊκές και επικοινωνιακές γλώσσες που σχετίζονται με τα Σανσκριτικά)

### 18.3.1. Ονοματικοί σχηματισμοί ρηματικών συνθέτων

::: grammar-box

Από ρίζες με προθέματα μπορούν να σχηματιστούν ουσιαστικά μέσω των suffigών kṛt.

:::

Β) Μεταφράστε χρησιμοποιώντας ρήματα της 2ης τάξης παρατατικού:

1\. Ο Βραχμανός επαινει τις θεότητες.

2\. Οι ήρωες προχωρούν στον δύσβατο δρόμο προς το χωριό των Αρίων.

3\. Η υπηρέτρια γαλάκτιζε τις αγελάδες.

4\. Οι εχθροί των Αρίων σκοτώνουν τους ισχυρούς Κσατρίγια.

5\. Ένα φάντασμα δεν τρώει φρούτα.

6\. Έτσι μιλάει αυτός, που [έχει διαβεί καλά τον δρόμο των μετενσαρκώσεων] προς τον μαθητή.
