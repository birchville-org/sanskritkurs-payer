# Άσκηση 58

## Α) Μετασχηματισμοί αορίστου σε -iṣ

Προσδιορίστε και μεταφράστε τους ακόλουθους τύπους και σχηματίστε τους αντίστοιχους τύπους του **αορίστου σε -iṣ**:

1.  ⟪औहे⟫ - ⟪ऊह्⟫ 1Ā 1. εν. Παρατ. Μ. εγώ έσπρωχνα - ⟪औहिषि⟫
2.  ⟪जाग्रति⟫ - ⟪जागृ⟫ 2P 3. πληθ. Οριστ. Ενεστ. Ε. αυτοί είναι ξύπνιοι - ⟪अजागरिषुः⟫
3.  ⟪जीर्यन्ति⟫ - ⟪जॄ⟫ 4P 3. πληθ. Οριστ. Ενεστ. Ε. αυτοί γερνούν - ⟪अजारिषुः⟫
4.  ⟪आनर्च⟫ - ⟪अर्च्⟫ 1P 1. 3. εν. 2. πληθ. Παρακείμ. Ε. λατρεύω - ⟪आर्चिषम्⟫ ⟪।⟫ ⟪आर्चीत्⟫ ⟪।⟫ ⟪आर्चिष्ट⟫
5.  ⟪खादामः⟫ - ⟪खाद्⟫ 1P 1. πληθ. Οριστ. Ενεστ. Ε. εμείς μασάμε - ⟪अखादिष्म⟫
6.  ⟪नेद⟫ - ⟪नद्⟫ 1P 2. πληθ. Παρακείμ. Ε. εσείς αντηχήσατε - ⟪अनादिष्ट⟫ ⟪।⟫ ⟪अनदिष्ट⟫
7.  ⟪आश्नीत⟫ - ⟪अश्⟫ 9P 2. πληθ. Παρατ. Ε. εσείς φάγατε - ⟪आशिष्ट⟫
8.  ⟪पुनते⟫ - ⟪पू⟫ 9U 3. πληθ. Οριστ. Ενεστ. Μ. αυτοί εξαγνίζουν προς το δικό τους συμφέρον - ⟪अपविषत⟫
9.  ⟪अशेरत⟫ - ⟪शी⟫ 2Ā 3. πληθ. Παρατ. Μ. αυτοί κείτονταν - ⟪अशयिषत⟫
10.  ⟪इयेषिथ⟫ - ⟪इष्⟫ 6P 2. εν. Παρακείμ. Ε. εσύ επιθύμησες - ⟪ऐषीः⟫
11.  ⟪आर्च्छत्⟫ - ⟪ऋ⟫ 1P 3. εν. Παρατ. Ε. αυτός πήγε - ⟪आरीत्⟫
12.  ⟪अर्हन्ति⟫ - ⟪अर्ह्⟫ 1P 3. πληθ. Οριστ. Ενεστ. Ε. αυτοί είναι άξιοι - ⟪आर्हिषुः⟫
13.  ⟪ऊदुः⟫ - ⟪वद्⟫ 1P 3. πληθ. Παρακείμ. Ε. αυτοί μίλησαν - ⟪अवादिषुः⟫
14.  ⟪इन्त्से⟫ - ⟪इन्ध्⟫ 7Ā 2. εν. Οριστ. Ενεστ. Μ. εσύ ανάβεις - ⟪ऐन्धिष्ठाः⟫
15.  ⟪आध्वे⟫ - ⟪आस्⟫ 2Ā 2. πληθ. Οριστ. Ενεστ. Μ. εσείς κάθεστε - ⟪आसिध्वम्⟫
16.  ⟪कल्पे⟫ - ⟪कॢप्⟫ 1. εν. Οριστ. Ενεστ. Μ. εγώ ταιριάζω - ⟪अकल्पिषि⟫
17.  ⟪आनीत्⟫ - ⟪अन्⟫ 2P 3. εν. Παρατ. Ε. αυτός ανέπνεε - ⟪आनीत्⟫
18.  ⟪ऐक्षध्वम्⟫ - ⟪ईक्ष्⟫ 1Ā 2. πληθ. Παρατ. Μ. εσείς είδατε - ⟪ऐक्षिध्वम्⟫
19.  ⟪अचेतः⟫ - ⟪चित्⟫ 1P 2. εν. Παρατ. Ε. εσύ αντιλήφθηκες - ⟪अचेतीः⟫
