# Μάθημα 50

## 50.1. Ονοματικός σχηματισμός: κανονική σύγκριση

::: grammar-box
**Η κανονική κλίση στο Σανσκριτό γίνεται με τα ⟪तद्धित⟫ καταλήξεις**
* **-⟪तर⟫ (θηλ.: ⟪तरा⟫) στον "Συγκριτικό"**
* **⟪तम⟫ (θηλ.: ⟪तमा⟫) στον "Υπερθετικό"**

**Αυτές οι καταλήξεις προστίθενται στα ουσιαστικά επιθέτων στον αρσενικό λόγο. Σε ουσιαστικά με κλίση ρίζας, προστίθενται στον αδύναμο λόγο, ο οποίος έχει τη μορφή όπως πριν από την κατάληξη -su του τοπικού (⟪पञ्चमी⟫) πληθυντικού.**
:::
::: media
![](/images/lekt5007.webp)
Εικ.: ⟪लोकस्योत्तमो⟫ ⟪गिरिः⟫
⟪सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = Mount Everest
(Πηγή εικόνας: [Λεπτομέρειες](/el/licenses#lekt5007))
:::

::: grammar-box
**Σημασία:**

**Ο "Συγκριτικός" σημαίνει, όταν δεν εκφράζεται το συγκρινόμενο αντικείμενο: "αρκετά, πολύ, υπερβολικά":**

:::
::: indent
π.χ. ⟪सुचितर⟫ 3 «σχετικά καθαρός», «πολύ καθαρός», «πάρα πολύ καθαρός»
:::
**Όταν εκφράζεται το αντικείμενο σύγκρισης, βρίσκεται στην Αιτιατική (⟪पञ्चमी⟫). Ο Συγκριτικός + Αιτιατική αντιστοιχεί στην κλίση με «από» στα Γερμανικά.**

::: indent
π.χ. ⟪देवदत्ताद्रामो⟫ ⟪धीमत्तरः⟫ = κυριολεκτικά: «από την άποψη του Devadatta, ο Rāma είναι πιο σοφός» = «ο Rāma είναι πιο σοφός από τον Devadatta»
:::
**Ο «Υπερθετικός» σημαίνει ότι δεν εκφράζεται αντικείμενο σύγκρισης: «εξαιρετικά, πολύ»:**

::: indent
π.χ. ⟪सत्तम⟫ 3 (προς ⟪सन्त्⟫) «εξαιρετικά καλός, πολύ καλός»
:::
**Όταν εκφράζεται το αντικείμενο σύγκρισης, βρίσκεται στην Γενική (⟪षष्ठी⟫) («από», «μεταξύ») και ο Υπερθετικός αντιστοιχεί στον Γερμανικό Υπερθετικό (Ανώτατο Βαθμός):**

::: indent
π.χ. ⟪द्विजानां⟫ ⟪सत्तमः⟫ = «ο καλύτερος των Διγεννημένων»
:::
**Τα επίθετα -⟪तर⟫ και -⟪तम⟫ μπορούν να προστεθούν όχι μόνο σε επίθετα, αλλά και σε ουσιαστικά, indeclinabilia και ακόμη και ρηματικές μορφές:**

Παραδείγματα:

::: indent
⟪गजतम⟫ αρσ. «ο καλύτερος ελέφαντας» (⟪गज⟫) (επίσης προσφώνηση του Βούδα)

⟪गोतम⟫ αρσ. «ο μεγαλύτερος ταύρος» (⟪गो⟫) ή: «ο πλουσιότερος σε βοοειδή»

⟪उद्⟫ Ακλ. «πάνω», «προς τα πάνω» » ⟪उत्तर⟫ 3 «υψηλότερος» » ⟪उत्तम⟫ 3 «ύψιστος»
:::
**Όταν αυτά τα επίθετα προσαρτώνται σε μια ρηματική μορφή, εμφανίζονται πάντα στην επιθετική (αυθαιρετική) μορφή:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

Παραδείγματα:

::: indent
⟪पचतितराम्⟫ «μαγειρεύει καλύτερα»

⟪पचतितमाम्⟫ «μαγειρεύει καλύτερα από όλους»
:::
**Αυτή τη μορφή έχουν και τα επίθετα, όταν προσαρτώνται σε αδιάλεκτα λέξεις και η παράγωγη λέξη χρησιμοποιείται επιρρηματικά:**

::: indent
π.χ. ⟪सुतराम्⟫ (από ⟪सु⟫) «με καλύτερο τρόπο» (επιρρηματικά)
:::
