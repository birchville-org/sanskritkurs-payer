# Μάθημα 37

## 37.1. Το επίρρημα (⟪क्रियाविशेषणम्⟫)

Τα επίρρημα στο Σανσκριτικό σχηματίζονται

1. μέσω πτώσεων ουσιαστικών και αντωνυμιών
2. με τη βοήθεια ειδικών καταλήξεων και επιθημάτων

Στην πρώτη περίπτωση, το όριο μεταξύ ζωντανής πτώσης και επιρρήματος είναι ρευστό. Σε αυτή την κατηγορία ανήκουν, ως ειδική περίπτωση, τα επίρρηματα που είναι παγιωμένες, αρχαίες πτώσεις, ενώ στη κλίση χρησιμοποιούνται άλλες μορφές ή τα αντίστοιχα ουσιαστικά δεν χρησιμοποιούνται πλέον ως ουσιαστικά.

## 37.2. Επιρρηματική χρήση πτώσεων

### 37.2.1. Αιτιατική (⟪द्वितीया⟫)

::: grammar-box
Η αιτιατική (⟪द्वितीया⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά στις ερωτήσεις:

*   με ποιον τρόπο;
*   για πόσο χρονικό διάστημα;
*   προς τα πού;
*   κ.λπ.

Η αιτιατική μπορεί να χρησιμοποιηθεί επιρρηματικά:

*   από ουσιαστικά  
Παραδείγματα:  
⟪कामम्⟫ "σύμφωνα με την επιθυμία, όπως επιθυμείς"  
⟪अर्थम्⟫ "λόγω"

*   από επίθετα στον ουδέτερο γένος  
Παραδείγματα:  
⟪सुखम्⟫ "εύκολα, ευτυχισμένα"  
⟪नित्यम्⟫ "πάντα"  
⟪साधु⟫ "σωστά, καλά"

*   από αντωνυμίες στον ουδέτερο γένος  
Παραδείγματα:  
⟪तद्⟫ "τότε, γι' αυτό"  
⟪यद्⟫ "αν, ότι"  
⟪एतद्⟫ "έτσι, εδώ, τώρα"
:::
### 37.2.2. Εργαλείικη (⟪तृतीया⟫)

::: grammar-box
Η εργαλείικη (⟪तृतीया⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά στις ερωτήσεις:

*   με τι;
*   από ποιο μέσο;
*   κ.λπ.

Η εργαλείικη μπορεί να χρησιμοποιηθεί επιρρηματικά:

*   από ουσιαστικά  
Παραδείγματα:  
⟪अर्थेन⟫ "λόγω"  
⟪क्षणेन⟫ "τη στιγμή, αμέσως" (από ⟪क्षण⟫ αρ. "στιγμή")

*   από επίθετα, συχνά και στον πληθυντικό  
Παραδείγματα:  
⟪दूरेण⟫ "μακριά, από μακριά" (προς ⟪दूर⟫ 3 "μακριά, μακριά από")  
⟪उच्चैस्⟫ "υψηλά, δυνατά" (προς ⟪उच्च⟫ 3 "υψηλά, αυξημένο, δυνατά, οξύ (για φωνή)")
:::
### 37.2.3. Δατικός (⟪चतुर्थी⟫)

::: grammar-box
Σπάνια χρησιμοποιείται ο δατικός (⟪चतुर्थी⟫) επιρρηματικά στις ερωτήσεις:

*   για ποιο σκοπό;
*   κ.λπ.

Παράδειγμα:
:::
::: indent
⟪अर्थाय⟫ "για τον σκοπό του, για χάρη του ..."
:::
### 37.2.4. Αβλατίβος (⟪पञ्चमी⟫)

::: grammar-box
Ο αβλατίβος (⟪पञ्चमी⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά στις ερωτήσεις:

*   γιατί;
*   εξαιτίας ποιου;
*   από πού;
*   κ.λπ.

Ο αβλατίβος μπορεί να χρησιμοποιηθεί επιρρηματικά:

*   από ουσιαστικά  
π.χ. ⟪बलात्⟫ "βίαια, με τη βία"  

*   από επίθετα  
π.χ. ⟪दूरात्⟫ "από μακριά"  

*   από αντωνυμίες  
Παραδείγματα:  
⟪कस्मात्⟫ "γιατί"  
⟪अकस्मात्⟫ "απρόσμενα"
:::
### 37.2.5. Γενικός (⟪षष्ठी⟫)

::: grammar-box
Σπάνια χρησιμοποιείται ο γενικός (⟪षष्ठी⟫) επιρρηματικά στην ερώτηση "μετά από πόσο καιρό;"

π.χ. ⟪चिरस्य⟫ "μετά από πολύ καιρό" (προς ⟪चिर⟫ 3 "μεγάλος (χρόνος)")
:::
### 37.2.6. Λοκατίβος (⟪सप्तमी⟫)

::: grammar-box
Ο λοκατίβος (⟪सप्तमी⟫) μπορεί να χρησιμοποιηθεί επιρρηματικά στις ερωτήσεις:

*   πού;
*   υπό ποιες συνθήκες;
*   κ.λπ.

Παραδείγματα:
:::
::: indent
\-⟪अर्थे⟫ "λόγω"  
\-⟪कृते⟫ "για χάρη"  
⟪दूरे⟫ "μακριά"
:::
## 37.3. Επιρρηματική χρήση πια μη συνηθισμένων πτώσεων

Παραδείγματα:
::: indent
⟪जातु⟫ "καθόλου" (αρχικά "από τη γέννηση, από τη φύση", Αιτ.εν.ουδ. προς ⟪जातु⟫ \<πια μη συνηθισμένο ως ουσιαστικό\>)

⟪तूष्णीम्⟫ "σιωπηλά" (Αιτ.εν. προς ένα πια μη συνηθισμένο ⟪तूष्णी⟫ θ. "σιωπή")

⟪एवम्⟫ "έτσι" (προς ένα αλλιώς χαμένο αντωνυμικό ρίζα ⟪एव⟫ "ένας, μόνος")
:::
## 37.4. Σχηματισμός επιρρημάτων με επιρρηματικά επίθετα

::: grammar-box
Από τις προθεματικές ρίζες ⟪तद्⟫, ⟪इदम्⟫ ή ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ ή ⟪कु⟫ μπορεί κανείς να παραγάγει επιρρηματικά επίθετα με τα επιρρηματικά επίθετα

*   \-⟪तस्⟫ (Αφαιρετική)
*   \-⟪त्र⟫ (Τοπική)
*   \-⟪था⟫ (Τρόπος)
*   \-⟪थम्⟫ (Τρόπος)
*   \-⟪दा⟫ (Χρόνος)

αντίστοιχα επιρρηματικά επίθετα.
:::
::: grammar-box

| Επίθετο | Προθεματική ρίζα | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(Αφαιρετική) | ⟪ततस्⟫ :brαπό εκεί, πάνω σε αυτό, γι' αυτό | ⟪इतस्⟫ :br ⟪अतस्⟫ :brαπό εδώ, γι' αυτόν | ⟪यतस्⟫ :brαπό πού, από τι | ⟪कुतस्⟫ :brαπό πού;, γιατί; |
| **-⟪त्र⟫** :br(Τοπική) | ⟪तत्र⟫ :brεκεί, εκεί | ⟪अत्र⟫ :brεδώ | ⟪यत्र⟫ :brπού | ⟪कुत्र⟫ :brπού; |
| **-⟪था⟫** :br(Τρόπος) | ⟪तथा⟫ :brέτσι | | ⟪यथा⟫ :brπώς | |
| **-⟪थम्⟫** :br(Τρόπος) | | | | ⟪कथम्⟫ :brπώς; |
| **-⟪दा⟫** :br(Χρόνος) | ⟪तदा⟫ :brτότε, τότε | | ⟪यदा⟫ :brόταν | ⟪कदा⟫ :brπότε; |

:::

## 37.5. Επιρρηματικά σύνθετα

### 37.5.1. Σύνθετα με επίρρημα ή επιρρηματικά χρησιμοποιούμενη πτώση ως δεύτερο μέλος

Παράδειγμα: ⟪सुचिरम्⟫ "πολύ μεγάλο (χρόνο)"

### 37.5.2. Επιρρηματικά χρησιμοποιούμενα ⟪बहुव्रीहि⟫

Παράδειγμα: ⟪रक्षार्थम्⟫ "με τον τρόπο κάποιου, του οποίου σκοπός είναι η φροντίδα, προς το σκοπό της προστασίας". Μπορεί επίσης να θεωρηθεί ότι ανήκει στο 5.1.: -⟪अर्थम्⟫ ως επιρρηματικό δεύτερο μέλος.

### 37.5.3. ⟪अव्ययीभाव⟫-σύνθετα

⟪अव्ययीभाव⟫ = "αμετάβλητο/ανεπίκλητο geworden"

::: grammar-box
Ένα ⟪अव्ययीभाव⟫ είναι ένα επιρρηματικό σύνθετο, του οποίου το πρώτο μέλος είναι ένα ανεπίκλητο (μεταθετική πρόθεση, σωματίδιο κ.λπ.) και του οποίου το δεύτερο μέλος είναι ένα ουσιαστικό που λαμβάνει την κατάληξη της αιτιατικής ενικού ουδετέρου.

Κατά την ανάλυση του συνθέτου, το πρώτο μέλος θα κυβερνούσε το δεύτερο:

Παραδείγματα:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = "προς το πυρ"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "σύμφωνα με τις δυνάμεις"

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = "προς τα εμπρός, απέναντι"
:::
Ιδιαίτερα σημαντικά είναι τα ⟪अव्ययीभाव⟫ με το ⟪यथा⟫ "όπως" ως πρώτο μέλος:

π.χ. ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ = "όπως είναι η επιθυμία, σύμφωνα με την επιθυμία, αυθαίρετα"

## 37.8. Η ερωτηματική πρόταση

::: grammar-box
"Ποιος;, πώς;, τι;, γιατί; για ποιο λόγο;  
Όποιος δεν ρωτά, μένει άσχετος."

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

Μotto της Sesamstrasse, το οποίο αποτελεί έναν καλό οδηγό για τη ζωή και τις σπουδές στα Σανσκριτικά
:::
Δείτε επίσης [Μάθημα 4](lektion04.md).

Πρέπει να διακρίνουμε μεταξύ

*   ερωτήσεων λέξης (Ergänzungsfragen)
*   ερωτήσεων πρότασης

Σε ερωτήσεις λέξης, ρωτάμε για ένα υποκείμενο (⟪कर्तृ⟫), αντικείμενο, ενέργεια, συνθήκη κ.λπ., π.χ.

*   ποιος έρχεται;
*   τι κάνει ο Rāma;
*   ποιον ακούει;
*   πώς μιλά Σανσκριτικά;
*   πού είναι η μητέρα;

Σε ερωτήσεις πρότασης, ρωτάμε για το συνολικό περιεχόμενο της πρότασης, π.χ.

*   πάει ο Rāma σήμερα στο Ofterdingen;
*   είναι σωστό ότι ... ;

### 37.8.1. Ερωτήσεις λέξης (Ergänzungsfragen)

::: grammar-box
Σχήμα:

Ερωτηματική αντωνυμία/επιρρήματος - Πρόταση
:::
Παραδείγματα:
::: indent
⟪को ग्रामं गच्छति⟫ =  ⟪केन ग्रामो गम्यते⟫ = "Ποιος πηγαίνει στο χωριό;"

⟪किं बाला अधीयीरन्⟫ = "Τι πρέπει να μάθουν τα παιδιά;"

⟪क्व रामो वसति⟫ = Πού μένει ο Rāma;
:::

![lekt3704.jpg](/images/lekt3704.webp)
Εικ.: ⟪किं बाला अधीयीरन्⟫
(Πηγή εικόνας: [Λεπτομέρειες](/el/licenses#lekt3704))
:::
### 37.8.2. Ερωτηματικές προτάσεις

::: grammar-box
Μερικές φορές είναι μόνο από το πλαίσιο προφανές, αν μια πρόταση είναι ερωτηματική.
:::
::: grammar-box
Σχήμα I:

Ρήμα - υπόλοιπη πρόταση
:::
Παράδειγμα:
::: indent
⟪गमिष्यति ब्राह्मणबालो गुरुम् ।⟫ "Θα πάει ο βραχμάνος μαθητής σε έναν δάσκαλο;"
:::
::: grammar-box
Σχήμα II:

Ερωτηματικό σωματίδιο (συνήθως στην αρχή της πρότασης) - πρόταση

Τα πιο σημαντικά ερωτηματικά σωματίδια είναι:

*   ⟪अपि⟫

*   ⟪किम्⟫ (συχνά υποδηλώνει αρνητική απάντηση)

*   ⟪कच्चिद्⟫


Αυτά τα σωματίδια αντιστοιχούν στο ερωτηματικό.
:::
Παράδειγμα:
::: indent
⟪अपि सत्यम् ।⟫ "Είναι αλήθεια;"

⟪किं शक्नोति ।⟫ "Μπορεί;"

⟪कच्चित्क्षत्रियेण शत्रवो जिताः ।⟫ "Νίκησε ο κσατρία τους εχθρούς;"
:::
Σημείωση: ⟪किम्⟫ μπορεί εκτός από το "τι;" και ως ερωτηματικό σωματίδιο να σημαίνει επίσης "γιατί, προς τι;". Ιδιαίτερα με τον οργανικό (⟪तृतीया⟫):
::: indent
⟪किं क्रोधेन ।⟫ "Προς τι ο θυμός; Τι ωφελεί ο θυμός; Τι θέλει να πει ο θυμός;"
:::

## 37.10. Άσκηση

A) Απαντήστε στις ακόλουθες ερωτήσεις στα Σανσκριτικά, χρησιμοποιώντας τις λέξεις που αναφέρονται εντός παρενθέσεων. Μεταφράστε τα ερωτήματα.

Παράδειγμα: ⟪क आगच्छति⟫ (⟪राम⟫) ⟪।⟫ » ⟪राम आगच्छति । कस्मै ब्राह्मण्यन्नं ददौ ॥१॥⟫ (⟪भिक्षु⟫, ⟪बाला⟫, ⟪दास⟫, ⟪भगवन्त्⟫)

⟪क आर्यसत्यान्यजानात् ॥२॥⟫ (⟪बुद्ध⟫, ⟪शाक्यमुनि⟫)

⟪कुत्राग्निश्चीयते ॥३॥⟫ (⟪यज्ञस्थान⟫, ⟪मही⟫)

⟪कदा ब्राह्माणा घृतमग्नौ जुह्वति ॥४॥⟫ (⟪यज्ञकाल⟫, ⟪देवान् स्तु⟫ \<Απολυτική\>)

⟪कस्मान्मतिमतयः पुण्यं चक्रुः ॥५॥⟫ (⟪स्वर्गलोभ⟫, ⟪नरकभय⟫, ⟪भीतनरकता⟫)

⟪किमेव शस्त्रं छिनत्ति ॥६॥⟫ (⟪शरीर⟫, ⟪अजीव⟫)

⟪किंकामः शत्रुरार्यैः सह युयुधे ॥७॥⟫ (⟪धनं जि⟫)

## 37.11. Άσκηση επανάληψης

Μεταφράστε στα Σανσκριτικά χρησιμοποιώντας αποκλειστικά ρηματικές μορφές του Παρακειμένου:

Μια φορά κι έναν καιρό, ένας γέροντας πήγαινε σε ένα άλλο χωριό και κουράστηκε στο δρόμο. Πήγε λοιπόν, για να ξεκουραστεί, στα πόδια ενός μανγκοδέντρου που βρισκόταν στο πλάι. Σε αυτό το δέντρο υπήρχαν ώριμα φρούτα. Ο γέροντας πείραξε και ήθελε αυτά τα φρούτα. Όμως δεν μπορούσε να ανέβει στο δέντρο και να πιάσει τα φρούτα. Για καλή του τύχη, σε αυτό το δέντρο υπήρχαν κάποια μαϊμούδια που έτρωγαν φρούτα. Όταν τα είδε, ο γέροντας χαρήκε. Τι έκανε; Πήρε μερικούς πέτρες, στοχεύσε τις μαϊμούδες και ρίξε. Οι θυμωμένες μαϊμούδες έκοψαν μερικά φρούτα και τα ρίξουν στον γέροντα. Ο γέροντας πήρε αυτά με χαρά και πήγε στην επιθυμητή περιοχή του. Ιδού, η μοίρα του γέροντα!
