# Μάθημα 25

## 25.1. Σχηματισμός της Αφαιρετικής (⟪पञ्चमी⟫ = «πέμπτη πτώση»)

::: grammar-box
Εκτός από τα αρσενικά/ουδέτερα σε -a καθώς και τα αντωνυμίες, στον ενικό οι μορφές της Αβλατίου (⟪पञ्चमी⟫) είναι πανομοιότυπες με αυτές της Γενικής (⟪षष्ठी⟫) σε όλες τις κλίσεις.

Εκτός από τα προσωπικές αντωνυμίες, στον πληθυντικό οι μορφές της Αβλατίου είναι πανομοιότυπες με αυτές της Δακτύλιου (⟪चतुर्थी⟫) σε όλες τις κλίσεις.
:::
Τώρα αναγνωρίζετε τον λόγο για τη σειρά των πτώσεων (⟪विभक्ति⟫) στα Σανσκριτικά: είναι διατεταγμένες έτσι ώστε οι ομόφωνες μορφές να βρίσκονται όσο το δυνατόν πιο κοντά - ή μεταξύ τους.

::: grammar-box
**Αβλατίος Ενικού των Αρσενικών/Ουδέτων σε -a**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Ερωτηματικές, Σχέσης και Ενδεικτικές Αντωνυμίες:

::: grammar-box

| | Ablativ Singular:brMaskulinum / Neutrum | Ablativ Singular:brFemininum |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Χρήση της αφαιρετικής (⟪पञ्चमी⟫)

"Η αιτιατική εκφράζει αυτό που παραμένει σταθερό, όταν κάτι απομακρύνεται από αυτό."

Pāṇini 2,3,28 + 1,4,24

Η αιτιατική χρησιμοποιείται κυρίως για τις ερωτήσεις "Από πού;", "Γιατί;".

::: grammar-box
1\. Η αιτιατική εκφράζει δηλαδή το σημείο εκκίνησης, την καταγωγή και το υλικό.

Ο Αιτιατικός μπορεί, ως εκ τούτου, να δηλώνει και το πρόσωπο από το οποίο αγοράζει κανείς κάτι, ακούει, επιθυμεί κ.λπ.
:::
Παραδείγματα:

::: indent
⟪ग्रमादागच्छति⟫ = "Έρχεται από το χωριό"

⟪अश्वात्पतितः⟫ = "πεσμένος από το άλογο"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "λαμβάνεται από αυτούς (εξ ου)"
:::
Παραδείγματα:

::: indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟫ = "ακούει από τον δάσκαλο περί του Ντάρμα"

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = "ο Βραχμάνος επιθυμεί από τον Κσάτριο μια αγελάδα που δίνει γάλα"
:::
::: grammar-box
2\. Η Αποθετική χρησιμοποιείται με ρήματα που σημαίνουν "απαλλάσσει από", "προστατεύει από", "αμύνεται κατά", "φοβάται":
:::
Παράδειγμα:

::: indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = "προστατεύει από τους εχθρούς"
:::
::: grammar-box
3\. Η Αποθετική δηλώνει τον λόγο ή την αιτία:
:::
Παραδείγματα:

::: indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = "σκοτώνει τον γιο του από οργή"

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = «Επειδή έκανε κακό, πάει στην κόλαση» («Επειδή είναι αυτός δια του οποίου έγινε κακό»)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = «Επειδή κάνει / έκανε κακό, πάει στην κόλαση»
:::
Τα ουσιαστικά που δεν είναι θηλυκά, μπορούν, για να δηλώσουν τον λόγο μιας ενέργειας, να βρίσκονται στον Εργατικό (⟪तृतीया⟫) ή στην Αιτιατική (⟪पञ्चमी⟫). Τα θηλυκά βρίσκονται σ’ αυτή την έννοια συνήθως στον Εργατικό, αλλά μπορούν περιστασιακά να βρίσκονται και στην Αιτιατική.

## 25.3. Το επίθημα -⟪तस्⟫

::: grammar-box
Αν θέλουμε να εκφράσουμε στον ενικό αριθμό (αποκλειστικά) ότι η λέξη χρησιμοποιείται με αποστιβική σημασία, μπορούμε να προσθέσουμε στο ρίζα της λέξης το επίθημα -⟪तस्⟫, που σχηματίζει επιρρήματα με συνήθως αποστιβική σημασία (απάντηση στο ερώτημα "Από πού;"):
:::
Παραδείγματα:

::: indent
⟪आदितस्⟫ = "από την αρχή"

⟪धर्मतस्⟫ = "λόγω του Ντιχάρμα, βάσει του Ντιχάρμα"
:::
::: grammar-box
Το επίθημα -⟪तस्⟫ εμφανίζεται επίσης σε ρίζες αντωνυμιών:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "από εκεί, εκεί, προς εκεί, πάνω σε αυτό, τότε, γι' αυτό"

⟪यद्⟫ : ⟪यतस्⟫ "από ποιο, από τι, από πού, πού, προς πού, γιατί" (σχετικό)

⟪किम्⟫ :  ⟪कुतस्⟫ "από πού;" "γιατί;"
:::
## 25.4. Άλλοι τρόποι έκφρασης αιτιολογήσεων

::: grammar-box
**1\. Σχέσεις**

Οι σχέσεις συχνά εκφράζουν μια αιτιακή (αιτιολογική), συνεπακόλουθη (επαγωγική) ή τελική (σκοποποιητική) σχέση με την κύρια πρόταση.

Μορφές του σχετικού αντωνύμου που λειτουργούν ως αιτιακή σύμφυση:

*   αφαιρετική:
    *   ⟪यतस्⟫ ... δευτερεύον πρότασης ... ⟪ततस्⟫ ... κύρια πρόταση ... = "επειδή ..., γι' αυτό ..."
    *   ⟪यस्मात्⟫ ... δευτερεύον πρότασης ... ⟪तस्मात्⟫ ... κύρια πρόταση ... = "επειδή ..., γι' αυτό ..."
*   όργανο:
    *   ⟪येन⟫ ... δευτερεύον πρότασης ... ⟪तेन⟫ ... κύρια πρόταση ... = "με/επειδή ..., γι' αυτό / εξαιτίας αυτού ..."
:::
Παράδειγμα:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = "Επειδή ο Ράμα επιθυμεί την ευημερία, τηρεί τον όρκο"
:::
::: grammar-box
**2\. ⟪हि⟫**

Οι κύριες προτάσεις μπορούν να συνδεθούν μεταξύ τους μέσω της σωματιδίου ⟪हि⟫ "γιατί, επειδή". Μια πρόταση με ⟪हि⟫ (η οποία δεν μπορεί να βρίσκεται στην πρώτη θέση, αλλά πρέπει στη πεζογραφία να βρίσκεται στη δεύτερη θέση) παρέχει μια αιτιολόγηση είτε για την προηγούμενη πρόταση είτε για την επόμενη πρόταση:
:::
Παράδειγμα:

::: indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = "Οι άνθρωποι κάνουν αρετές. Θέλουν δηλαδή να μπουν στον ουρανό."
:::
::: grammar-box
**3\. Όργανο (⟪तृतीया⟫)**

Εκτός από την Αφαιρετική (⟪पञ्चमी⟫), η Οργανική (⟪तृतीया⟫) χρησιμοποιείται για την ένδειξη του λόγου ή της αιτίας. Στα θηλυκά ουσιαστικά, η Οργανική είναι γενικά υποχρεωτική.
:::
Παράδειγμα:

::: indent
⟪क्रोधेन⟫ ⟪पुत्रं⟫ ⟪हन्ति⟫ = "Χτυπά τον γιο του από οργή" = "Χτυπά τον γιο του στην οργή"
:::
::: grammar-box
**4\. Ουσιαστικά**

Επιπλέον, φυσικά, μπορεί κανείς να εκφράσει αιτιολογίες και μέσω κατασκευών με

*   ⟪कारण⟫ n. "Αιτία": ⟪कारणात्⟫ ⟪।⟫ ⟪कारणेन⟫
*   ⟪हेतु⟫ m.
*   άλλα ουσιαστικά με τη σημασία "Αιτία"

Γενική (⟪षष्ठी⟫) ή ως δεύτερο συνθετικό σύνθετων:
:::
Παράδειγμα:

::: indent
⟪पुण्यस्य⟫ ⟪कारणात्⟫ (⟪हेतोः⟫ κ.ο.κ.) = «λόγω της αρετής»
:::
::: grammar-box
**5\. ⟪इति⟫**

Το κίνητρο για μια δράση μπορεί να δοθεί με τη σκέψη ⟪इति⟫:
:::
Παράδειγμα:

::: indent
⟪सम्यक्संबुद्धः⟫ ⟪सुगत⟫ ⟪इत्यानन्दो⟫ ⟪गौतमं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫  = «Επειδή ο Σουγκάτα έχει αφυπνιστεί πλήρως στην αλήθεια, ο Ānanda ρωτά τον Gautama για τη διδασκαλία του» («Σκεπτόμενος «Ο Σουγκάτα έχει αφυπνιστεί πλήρως στην αλήθεια» ...»)
:::

## 25.6. Άσκηση

A) Συμπληρώστε τα παραδείγματα κλίσης από την [Ενότητα 16](lektion16.md), Άσκηση Επανάληψης Α, προσθέτοντας την 4. Δατική (⟪चतुर्थी⟩) και την 5. Αφαιρετική (⟪पञ्चमी⟩). Σχηματίστε επίσης σειρές κλίσης με όλες τις μέχρι τώρα μαθητέες μορφές για

⟪१⟩. ⟪सन्त्⟩ (αρσ., ουδ.)

⟪२⟩. ⟪महान्त्⟩ (αρσ., ουδ.)

⟪३⟩. ⟪यद्⟩ (αρσ., ουδ., θηλ.)
