# Μάθημα 22

## 22.1. Το Απολύτως (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫)

::: grammar-box

Αν θέλουμε να εκφράσουμε στα Σανσκριτικά ότι μια πράξη του υποκειμένου (⟪कर्तृ⟫) προηγείται ή συνοδεύει μια άλλη πράξη του υποκειμένου, χρησιμοποιούμε την απόλυτη πτώση (⟪क्त्वा⟩ ⟪।⟩ ⟨⟪ल्यप्⟩). Άρα

«αφού το έκανε αυτό, κάνει εκείνο»· «κάνει αυτό, μετά κάνει εκείνο»· «λόγω αυτού, κάνει εκείνο»· «ήρθα, είδα και νίκησα» κ.ο.κ.

Η απόλυτη πτώση είναι ένα ρηματικό επίρρημα, δηλαδή δεν κλίνεται ούτε φλέγεται, αλλά έχει πάντα — με ελάχιστες εξαιρέσεις — το ίδιο υποκείμενο (⟪कर्तृ⟩) με την πράξη, στην οποία προηγείται ή συνοδεύει η πράξη που δηλώνεται από την απόλυτη πτώση. Το υποκείμενο της απόλυτης πτώσης βρίσκεται λοιπόν στην ονομαστική (⟪प्रथमा⟩) ή την αιτιατική (⟪तृतीया⟩).

Εκτός από τα σύνθετα, η απόλυτη πτώση είναι ένα από τα πιο συχνά μέσα έκφρασης στα Σανσκριτικά.

Κατά τη μετάφραση στα Γερμανικά, αποφεύγετε να λέτε συνεχώς «αφού». Αντ' αυτού, χρησιμοποιείτε τις συνηθισμένες γερμανικές εκφράσεις για χρονική ακολουθία.

**Σχήμα:**

(πιο ακριβής προσδιορισμός για την Αβσολούτο: περιστατικό, αντικείμενο κ.λπ.) - Αβsoύλο - Αβsoύλο - ... - Αβsoύλο - ... Πράκτορας + ρηματικό πρόταση (ενεργητική ή παθητική φωνή)

:::
**Παραδείγματα:**

::: indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = Παθητική Δομή: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**  
«Ο άνδρας εισέρχεται στο σπίτι, βλέπει το μικρό κορίτσι και του απευθύνεται.»

Πληθυντικός: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**
:::
## 22.2. Σχηματισμός του Απολύτου

::: grammar-box
**Σχηματισμός του Απολύτου**

*   Ρήματα χωρίς πρόθεμα: Απόλυτο σε **-tvā**
*   Ρήματα με πρόθεμα: Απόλυτο σε **-ya** ή **-tya**
:::
### 22.2.1. Ρήματα χωρίς πρόθημα: Απόλυτο σε -⟪त्वा⟫

::: grammar-box

**Παιδεία:**

(συνήθως) βαθιά ρίζα στη μορφή, την οποία προηγείται το PPP + **-tvā** (**-⟪त्वा⟫**)

Μόνο το αρνητικό **a-** / **an-** συμβιβάζεται με την κατάληξη **-⟪त्वा⟫** : **⟪अकृत्वा⟫"χωρίς να έχει κάνει"**

:::
**Παραδείγματα:**

::: indent
**⟪आप्त्वा⟫** «αφού έφτασε / είχε φτάσει»

**⟪आसित्वा⟫** «αφού καθόταν / είχε καθίσει»

**⟪इत्वा⟫** «αφού περπατούσε / είχε περπατήσει»

**⟪स्थित्वा⟫** «αφού στεκόταν / είχε στέκεται»

**⟪जित्वा⟫** "όταν έχει (..) νικήσει / είχε νικήσει"

**⟪उक्त्वा⟫** "όταν έχει (..) μιλήσει / είχε μιλήσει"
:::
### 22.2.2. Ρήματα με πρόθημα

#### 22.2.2.1. Ρίζες με μακρό φωνήεν (εκτός από -ā) ή σε σύμφωνο

::: grammar-box

**(συνήθως) βαθιάς κλίσης ρίζα + -ya**

:::
**Παραδείγματα:**

::: indent
**⟪उपनीय⟫** «αφού (...) προσέφερε / είχε προσφέρει»

**⟪प्रभूय⟫** «αφού (...) ξεχώριζε / ήταν» «αφού (...) είχε εξουσία»

**⟪प्राप्य⟫** «αφού απέκτησε / είχε αποκτήσει»
:::
#### 22.2.2.2. Ρίζες σε -ā

::: grammar-box

**αμετάβλητη υψηλού επιπέδου ρίζα + -ya**

:::
**παράδειγμα:**

::: indent
**⟪उपस्थाय⟫** «αφού (...) έπεσε / έχει πέσει»· (χωρίς πρόθεμα: **⟪स्थित्वा⟫**)
:::
#### 22.2.2.3. Ρίζές που λήγουν σε βραχύ -i, -u, -ṛ στην βαθμίδα μηδέν

::: grammar-box

**ριζικό βαθύτατο επίπεδο + -tya**

:::
**Παραδείγματα:**

::: indent
**⟪प्रस्तुत्य⟫** «αφού (...) επεσήμανε δυνατά / είχε επισημάνει»

**⟪विस्मृत्य⟫** «αφού (...) ξέχασε / είχε ξεχάσει»

**⟪संस्कृत्य⟫** «αφού ετοίμασε (...) για τη θυσία»
:::
#### 22.2.2.4. Ρίζες σε -am / -an, που στον αδύναμο κλίση λήγουν σε -a

::: grammar-box

**Προαιρετικό:**

Ρίζα σε **-am** / **-an** + **-ya**

ή:

Ρίζα σε **-a** + **-tya**

:::
**Παράδειγμα:**

::: indent
**⟪विगम्य⟫** ή **⟪विगत्य⟫** «αφού (...) πέρασε / ήταν»
:::
