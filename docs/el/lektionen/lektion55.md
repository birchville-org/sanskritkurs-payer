# Μάθημα 55

## 55.1. Ο α-Αόριστος (Αόριστος με θεματικό φωνήεν)

::: grammar-box
**Ο α-αόριστος σχηματίζεται όπως ένα παρατατικό (⟪लङ्⟫) της 6ης κλάσης ρίζας (⟪तुदादि⟫), δηλαδή:**

**Αύγημα + βαθιά στάθμη ρίζας + a + δευτερογενής κατάληξη**

**Το -a- αντικαθίσταται με -ā- στις ίδιες πτώσεις όπως στον παρατατικό.**

**Χωρίς θηλαστικά ενδοφυάσματα.**

**Το Ātmanepada είναι σπάνιο· συνήθως σχηματίζεται για τις ρίζες Ubhayapada μετά από άλλες κλάσεις αορίστου (βλ. Kielhorn, Γραμματική §340 καθώς και παρακάτω στις αντίστοιχες κλάσεις αορίστου).**

**Λίστα των ριζών που έχουν αυτόν τον αόριστο, στο Kielhorn, Γραμματική §340.**
:::
Παράδειγμα:

⟪सिच्⟫ 6U "επισπέρχω"

::: indent
|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| 1\. ⟪तृतीयः⟫ | ⟪असिचम्⟫ | ⟪असिचाम⟫ | ⟪असिचे⟫ | ⟪असिचामहि⟫ |
| 2\. ⟪मध्यमः⟫ | ⟪असिचस्⟫ | ⟪असिचत⟫ | ⟪असिचथास्⟫ | ⟪असिचध्वम्⟫ |
| 3\. ⟪प्रथमः⟫ | ⟪असिचत्⟫ | ⟪असिचन्⟫ | ⟪असिचत⟫ | ⟪असिचन्त⟫ |
:::

::: indent
