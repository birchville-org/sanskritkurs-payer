## 40.2. Σχηματισμός των ρηματικών τύπων του πρώτου προσώπου Παρακειμένου (⟪लिट्⟫)

Καταλήξεις της πρώτης προσώπου (⟪तृतीयः⟫) στον Παρακείμενο (⟪लिट्⟫)

::: grammar-box

| ⟪परस्मैपदम्⟫ | ← | ⟪आत्मनेपदम्⟫ | ← |
| :---: | :---: | :---: | :---: |
| ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **-a** | **-ma** | **-e** | **-mahe** |

:::
::: grammar-box
Σημειώστε ότι οι καταλήξεις της 1ης προσώπου ενικού P,Ā είναι ίδιες με αυτές της 3ης προσώπου ενικού. Επομένως, σε όλους τους τύπους παρακειμένου εκτός από τον τύπο III(a,b) και τον τύπο V(a,b,c), οι μορφές του 1ου ενικού P ή Ā είναι πάντα ίδιες με αυτές του 3ου ενικού P ή Ā.

Στον τύπο IV, η κατάληξη του 1ου ενικού P τελειώνει όπως αυτή του 3ου ενικού P, με -au.

Στους τύπους παρακειμένου III και V, το 1ο ενικό Ā είναι πάντα ίδιο με το 3ο ενικό Ā.

Στους τύπους παρακειμένου III και V, το 1ο ενικό P και το 3ο ενικό P είναι προαιρετικά ίδια: το 3.εν.P πρέπει σε αυτούς τους τύπους σχηματισμού να είναι πάντα με φωνήεν μακρό, ενώ το 1.εν.P μπορεί προαιρετικά να είναι με φωνήεν οξύ ή μακρό.
:::
::: grammar-box
Πριν από καταλήξεις που ξεκινούν με σύμφωνο, εμφανίζεται ο συνδετικός φθόγγος -i- για την πλειονότητα των ριζών.

Εκτός από πριν την κατάληξη -re, πριν την οποία πρέπει πάντα να εμφανίζεται το -i-, ο συνδετικός φθόγγος δεν εμφανίζεται ποτέ πριν σε καταλήξεις που αρχίζουν με σύμφωνο, για οκτώ ρίζες σε -ṛ ή -u, δηλαδή

1.  ⟪कृ⟫ 8U (εκτός από ⟪संस्कृ⟫)
2.  ⟪भृ⟫ 1U
3.  ⟪वृ⟫ 9U "επιλέγω"
4.  ⟪सृ⟫ 1P
5.  ⟪द्रु⟫ 1p "τρέχω"
6.  ⟪श्रु⟫ 5P
7.  ⟪स्तु⟫ 2U
8.  ⟪स्रु⟫ 1P "ρέω"

Για τις λεγόμενες προαιρετικές ⟪अनिट्⟫-ρίζες, ο συνδετικός φθόγγος μπορεί να παρεμβληθεί προαιρετικά ή όχι. (Αρίθμηση αυτών των ριζών στο Kielhorn, Γραμματική σ. 92 § 298b,2,3)
:::

## 40.3. Σχηματισμός των ρηματικών τύπων του πρώτου προσώπου του περιφραστικού Παρακειμένου (⟪अनुप्रयोगलिट्⟫)

Το περιφραστικό αόριστο σχηματίζεται από:

*   παραγωγά ριζικά στάδια (αιτιατικό, επιθυμητικό, συχναστικό, ονοματοποιημένα), ιδιαίτερα αιτιατικό
*   ρίζες, οι οποίες ξεκινούν με μακρύ φωνήεν (εκτός από ā)
*   ρίζες: φωνήεν (εκτός από a-)-σύμφωνο-σύμφωνο
*   μερικές άλλες
*   σε ορισμένες ρίζες μπορούν να σχηματιστούν προαιρετικά και τα δύο αόριστα: uṣ "καίω", vid "ξέρω", jāgṛ "γυπνάζω", daridrā "είμαι φτωχός"
*   στις ακόλουθες ρίζες μπορούν να σχηματιστούν προαιρετικά και τα δύο αόριστα, καθώς επίσης το περιφραστικό αόριστο είναι επαναληπτικό, με τη συλλαβή επανάληψης του σταδίου παρόντος:
    *   bhī "φοβάμαι"
    *   bhṛ "φέρω"
    *   hu "προσφέρω"
    *   hrī "ντρέπομαι"

*   1.sg.Ā ⟪ईक्षां⟫ ⟪चक्रे⟫ ⟪।⟫ ⟪ईक्षामास⟫ ⟪।⟫ ⟪ईक्षां⟫ ⟪बभूव⟫

## 40.4. Συντακτικά για την πρώτη πρόσωπο (⟪तृतीयः⟫)

::: grammar-box
Επειδή ένα πεπερασμένο ρήμα (συζευγμένο ρήμα) εκφράζει επίσης τον πράκτορα (⟪कर्तृ⟫), το «εγώ», «εμείς» σε μη παθητικές προτάσεις με πεπερασμένο ρήμα δεν χρειάζεται να εκφράζεται επιπλέον από ένα προσωπικό αντωνύμιο
:::
## 40.5. Προσωπικές αντωνυμίες (⟪पुरुषार्थकसर्वनाम⟫) του α' προσώπου ενικού και πληθυντικού

::: grammar-box
Η μορφή του προσωπικού αντωνύμου (προσωπικού υποκαταστάτου) είναι η ίδια για όλα τα γένη.
:::
::: grammar-box

| | ⟪एकवचनम्⟫ :br"ich" | ⟪बहुवचनम्⟫ :br"wir" |
| :---: | :---: | :---: |
| ⟪प्रथमा⟫ | ⟪अहम्⟫ | ⟪वयम्⟫ |
| ⟪द्वितीया⟫ | ⟪माम्⟫ / ⟪मा⟫ | ⟪अस्मान्⟫ / ⟪नस्⟫ |
| ⟪तृतीया⟫ | ⟪मया⟫ | ⟪अस्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪मह्यम्⟫ / ⟪मे⟫ | ⟪अस्मभ्यम्⟫ / ⟪नस्⟫ |
| ⟪पञ्चमी⟫ | ⟪मत्⟫ | ⟪अस्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪मम⟫ / ⟪मे⟫ | ⟪अस्माकम्⟫ / ⟪नस्⟫ |
| ⟪सप्तमी⟫ | ⟪मयि⟫ | ⟪अस्मासु⟫ |

:::
::: grammar-box
Οι συντομότερες μορφές, που αναφέρονται παραπάνω στη δεύτερη θέση (⟪मा⟫, ⟪मे⟫, ⟪नस्⟫), δεν επιτρέπεται ποτέ να χρησιμοποιούνται στην αρχή μιας πρότασης ή στίχου.

Πριν από τις μετοχές ⟪च⟫, ⟪वा⟫, ⟪एव⟫ δεν επιτρέπεται επίσης η χρήση αυτών των λεγόμενων ενκλιτικών μορφών:

μόνο: ... ⟪मां⟫ ⟪च⟫ ... "και εμένα"
:::
::: grammar-box
Η γενική πτώση (⟪षष्ठी⟫) των προσωπικών αντωνυμιών χρησιμοποιείται ως κτητική αντωνυμία:

⟪मम⟫ ⟪।⟫ ⟪मे⟫ = "το δικό μου"

⟪अस्माकम्⟫ ⟪।⟫ ⟪नस्⟫ = "οours"
:::
::: grammar-box
Ως πρόθετο σε σύνθετα, αυτά τα αντωνυμικά έχουν τις ρίζες:

*   εν. ⟪मद्⟫
*   πληθ. ⟪अस्मद्⟫
