# Μάθημα 17

## 17.1. Δεύτερη ενεστωτική τάξη (⟪अदादि⟫ = ⟪अद्⟫ κ.λπ.)

Οι τελικές καταλήξεις των ρημάτων προσαρτώνται απευθείας στη ρίζα. Πρέπει να ληφθούν υπόψη οι φωνητικές αλλαγές που προκύπτουν από τον σύνθετο λόγο (word sandhi).

::: grammar-box

Υπάρχουν οι ακόλουθες μορφές εκπαίδευσης στη δεύτερη τάση του ενεστώτα:

1.  Ρίζες με κλιμάκωση ριζικού
    *   κυρίως: οξύ βαθμό - βαρύ βαθμό
    *   μερικές ρίζες: τόνος βαθμός - βαρύ βαθμός
2.  Ρίζες χωρίς κλιμάκωση ριζικού
3.  Δισύλλαβες ρίζες σε -i/-ī με κλιμάκωση ριζικού

:::

## 17.5. Δισύλλαβες ρίζες σε -i/-ī με κλιμάκωση στελέχους

Πολλές ρίζες είναι σε μια σειρά μορφών δισύλλαβες, δηλαδή έχουν πριν από σύμφωνο τερματικό -i (αντίστοιχα πριν από ορισμένες καταλήξεις -ī). Αυτές οι ρίζες παρόλα αυτά θεωρούνται από τους εγχώριους γραμματικούς και σε λεξικά κ.λπ. ως μονοσύλλαβες.

Παραδείγματα:

⟪रुद्⟫ 2 Π "κλαίω, ουρλιάζω"

*   ισχυρός παρούσας ρίζα: rodi-
*   αδύναμος παρούσας ρίζα:
    *   πριν από σύμφωνο: rudi-
    *   πριν από φθόγγο: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U «μιλώ»

*   ισχυρός ρίζα ενεστώτα: bravī- (« bro- + -ī)
*   αδύναμος ρίζα ενεστώτα:
    *   vor Konsonant: brū-
    *   πριν από φωνήεν: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Επίσης ⟪स्तु⟫ 2 U «ἐπαινώ» έχει, εκτός από τις μορφές που αναφέρονται στο 3., μορφές σύμφωνα με αυτό το πρότυπο:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::
