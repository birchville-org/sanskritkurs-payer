# Μάθημα 10

::: deleteme-box
**Σε αυτή τη μαθησιακή ενότητα θα μάθετε:**
- Την παθητική φράση (Εργαλείο του Πραγματοποιού)
- την κλίση του Εργαλείου (tṛtīyā)
- τον κανόνα της εγκεφαλοποίησης για το -n- (Wortsandhi)
- τον σχηματισμό της παθητικής φωνής (yak) στον Ενεστώτα Οριστικής
- Λεξιλόγιο σχετικά με τη θυσία, την αλήθεια και τις κοινωνικές θέσεις

## 10.1. Η φράση Παθητική φωνή

::: grammar-box
**Σχήμα:**
**(Πραγματοποιός - kartṛ - στον Εργαλείο (tṛtīyā)) - (άμεσο αντικείμενο - karman - στην Ονομαστική) - παθητική ρηματική μορφή**

π.χ. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन⟫ ⟪देव⟫ ⟪इज्यते⟫ = "Ένας Βραχμάνης λατρεύει έναν θεό με μια θυσία" (λέξη προς λέξη: "Ένας θεός λατρεύεται από έναν Βραχμάνη με μια θυσία.")

Αυτή η πρόταση είναι **απόλυτα (!) ισοδύναμη** με την πρόταση:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो⟫ ⟪देवं⟫ ⟪यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
- Στην παθητική φράση, ο πράκτορας (**kartṛ**) βρίσκεται στον **Εργατικό** (tṛtīyā f. "τρίτη πτώση"), ενώ το απαντικό αντικείμενο (**karman** n.) βρίσκεται στον **Ονομαστική** (prathamā f.).
- Οι παθητικές φράσεις, στις οποίες δεν αναφέρεται ο πράκτορας, έχουν συνήθως απροσωπη σημασία ("κάποιος/κανείς"):
π.χ. **ijyate** = ⟪इज्यते⟫ "Θυσιάζεται" (κυριολεκτικά: "τιμάται με θυσία").
:::

::: grammar-box
**Ακόμη κι αν η αντίστοιχη ενεργητική φράση περιείχε αιτιατική (dvitīyā) του σκοπού, αυτός μπορεί να τεθεί στον Ονομαστική (prathamā) στην παθητική φράση:**

Στην ενεργητική φράση **rāmo grāmaṃ gacchati** = ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "Ο Rāma πηγαίνει στο χωριό." αντιστοιχούν οι παθητικές φράσεις:
- **rāmeṇa grāmaṃ gamyate** = ⟪रामेण⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫
- εναλλακτικά: **rāmeṇa grāmo gamyate** = ⟪रामेण⟫ ⟪ग्रामो⟫ ⟪गम्यते⟫
:::

::: grammar-box
**Τα άμεταβατα ρήματα (ρήματα χωρίς απαντικό αντικείμενο) έχουν συχνά παθητικές κατασκευές, ιδίως σε ευγενικές προσκλήσεις:**
- **praviśyatām** = ⟪प्रविश्यताम्⟫ = "Να εισέλθει κανείς = Παρακαλώ, μπείτε = Ελάτε!"
- **niṣadyatām** = ⟪निषद्यताम्⟫ = "Να καθίσει κανείς = Παρακαλώ, καθίστε = Παρακαλώ, πάρτε θέση"
:::
Οι παθητικές κατασκευές του Σανσκριτικού είναι εξαιρετικά συχνές: το παθητικό είναι, δηλαδή, ευκολότερο να σχηματιστεί από ό,τι numerous ρίζες ενεστώτα.

::: important
**Τα σύνταγμα του Σανσκριτικού παθητικού δεν πρέπει γενικά να αποδίδονται στη γερμανική γλώσσα με παθητικές προτάσεις, καθώς το γερμανικό παθητικό έχει εντελώς διαφορετική στιλιστική λειτουργία.**
:::

### 10.2.1. Για τη χρήση της οργανικής (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**Η Αιτιατική (tṛtīyā) χρησιμοποιείται κυρίως για τις ερωτήσεις:**
- **Με τι;**
- **Με ποιο μέσο/όργανο;**
- **Με ποιον;**

**Χρησιμοποιείται**
1. **στις παθητικές προτάσεις: ο αιτιατός (kartṛ) στην Αιτιατική**
2. **για να δηλώσει το μέσο ή το εργαλείο, με το οποίο επιτελείται κάτι**
3. **για να δηλώσει τον δρόμο, μέσω του οποίου φτάνει κάποιος οπουδήποτε**
4. **για να εκφράσει τη σύνδεση, την ένωση, τη συνοδεία με**
5. **με μεταθετικές προθέσεις με την έννοια "μαζί με, με· π.χ. saha = ⟪सह⟫ = "με" :brπ.χ.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन⟫ ⟪सह⟫ = "μαζί με τον Βραχμανικό"**
:::
Άλλες χρήσεις της Αιτιατικής (tṛtīyā) ακολουθούν αργότερα.

## 10.3. Ο λεγόμενος νόμος εγκεφαλικοποίησης για το -n- (ένα sandhi λέξεων)

::: grammar-box
Ένα **-n-**, το οποίο ακολουθείται από φωνήεν ή **n, m, y, v**, αντικαθίσταται από **-ṇ-**, όταν τα **ṛ, ṝ, r, ṣ** προηγούνται του **-n-** εντός της λέξης ή όταν δεν υπάρχει άλλος φθόγγος εκτός από φωνήεντα, γαργαλικά, χειλικά, **y, v, h** ή ανουσβάρα μεταξύ αυτών των φθόγγων και του επόμενου **-n-** εντός της λέξης.
:::

## 10.4. Η παθητική φωνή, Οριστική Ενεστώτα (yak = ⟪यक्⟫)

::: grammar-box
**Παιδεία:**
**(συνήθως) βαθιά ρίζα + -ya- + κατάληξη Ātmanepada**
:::
π.χ.

| Wurzel:br⟪धातु⟫ | 3. sg. Pass. Präs. Indik.:br⟪यक्⟫ ⟪लट्⟫ | 3. pl. Pass. Präs. Indik.:br⟪यक्⟫ ⟪लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"er wird geführt" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"er wird gedacht" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"es wird betreten" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Σημειώστε ότι στα ρήματα της 4ης κλίσης παρατατικού, οι μορφές του Ατμανεπάδα και η παθητική φωνή είναι ταυτόσημες! Σε αυτή την περίπτωση, το αν πρόκειται για Ατμανεπάδα ή παθητική φωνή μπορεί να εξαχθεί μόνο από τη σύνταξη της πρότασης.**

### 10.4.1. Ειδικοί κανόνες για τον σχηματισμό του Παθητικού

1. Οι ρίζες που λήγουν σε -i ή -u μακραίνουν τον φθόγγο τους πριν από το παθητικό επίθεμα **-ya-**:
   * **ji** 1 Π: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
   * **śru** 5 Π: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
   * **su** 5 Ο: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. Οι **ρίζες με -a- μεταξύ συμφώνων** (εκτός από nasals, y, r, v) παραμένουν σε υψηλή στάθμη:
   * **labh** 1 Α: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Ορισμένες ρίζες σχηματίζουν το παθητικό τους σε υψηλή στάθμη** (ή στην ablaut βαθμίδα του ρίζας του ενεστώτα):
   * **āp** 5 Π: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
   * **khād** 1 Π: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
   * **smṛ** 1 Π: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Βαθμίδα των ριζών που ξεκινούν με ya, va, ra, ή όπου αυτά τα φωνήματα ακολουθούν άλλο σύμφωνο (Samprasāraṇa = ⟪सम्प्रसारण⟫):**

   | Wurzel:br⟪धातु⟫ | Tiefstufe:br⟪सम्प्रसारण⟫ | Passiv:br⟪यक्⟫ |
   | :--- | :--- | :--- |
   | **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
   | **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
   | **prach** 6 P:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

Η παραδοσιακή εγχώρια ονομασία για αυτόν τον σχηματισμό της βαθιάς φάσης σε ρήματα με **ya** ή **va** είναι **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. Το **τελικό -ṛ** μετά από έναν μόνο σύμφωνο αντικαθίσταται πριν το παθητικό επίθεμα **-ya-** από **-ri-**:
   * **kṛ** 8η Κλ: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
   * Αλλά: **smṛ** 1η Κλ: **smaryate** :br⟪स्मर्यते⟫

6. **Ορισμένες ρίζες με -an έχουν εναλλακτικά δύο σχηματισμούς παθητικής ρίζας:**
   * μια **-an-ya**
   * μια **-ā-ya-** (το μακρό **ā** είναι εκπρόσωπος για ένα υποθετικό μακρύ nasale)

π.χ. **tan** 8η Κλ.
   * **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
   * **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (από \*tn-ya-nte)

## 10.6. Άσκηση

5. **nṛtyati** (⟪नृत्यति⟫)
6. **nayanti** (⟪नयन्ति⟫)

**Γ) Να μετατρέψετε τις ακόλουθες προτάσεις σε Παθητικό και να τις μεταφράσετε:**
1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो⟫ ⟪देवीं⟫ ⟪यजति⟫)
