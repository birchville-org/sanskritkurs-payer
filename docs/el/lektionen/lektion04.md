**Για την Ονοματική ενικού αρσενικού:**
- **sa, eṣa** (⟪स⟫ ⟪एष⟫) προηγείται όλων των φθόγγων εκτός από το βραχύ **-a**
- **so, eṣo** (⟪सो⟫ ⟪एषो⟫) προηγείται του **-a**, το οποίο ελαδιδοποιείται με Avagraha (απορρίπτεται)
- **saḥ, eṣaḥ** (⟪सः⟫ ⟪एषः⟫) εμφανίζεται μόνο σε παύση (τέλος προτάσεως, τέλους στίχου)

Για να μπορούν να σχηματιστούν προτάσεις με αυτά τα αντωνυμικά (sarvanāman n.), απαιτείται επίσης η γνώση των ακόλουθων κανόνων Sandhi:

### 4.1.2. Σάνσκριτ του τελικού -m

::: grammar-box
**Το τελικό -m πριν από σύμφωνα αντικαθίσταται από ανουσάρα (-ṃ). Στο τέλος της πρότασης ή του στίχου και πριν από φωνήεντα, το -m διατηρείται.**
:::
### 4.1.3. Σάνσκριτ του τελικού -e

::: grammar-box
1. **μπροστά σε a- το -e παραμένει αμετάβλητο: το αρχικό a- συντελείται με Αβάγραχα:**
π.χ. ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ «Αυτές οι φωτιές»

2. **Μπροστά σε φωνήεντα άλλα από το βραχύ a-, το -e συνήθως αντικαθίσταται από -a με διάσπαση φωνηέντων. Επίσης, η αντικατάσταση από -ay συμβαίνει:**
π.χ. ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (σπάνιο: imay īśvarāh = ⟪इमयीश्वराः⟫) «ΑΥΤΟΙ ΟΙ ΚΥΡΙΟΙ»
:::
### 4.1.4. Σάνσκριτ του τελικού -d

::: grammar-box
**Το τελικό -d σε παύση, καθώς και πριν από άηχα γουκάλια (k, kh) και χειλικά (p, ph), αντικαθίσταται από -t.**

Η αντικατάσταση πριν από άλλες σύμφωνους θα συζητηθεί αργότερα. Αποφύγετε προσωρινά τέτοιους συνδυασμούς φθόγγων!
:::
### 4.1.5. Ερωτηματικές φόρμουλες

Με τη βοήθεια αυτών των αντωνυμιών σχηματίζονται, για παράδειγμα, οι ακόλουθες ερωτηματικές φόρμουλες:

| :--- | :--- | :--- | :--- |

| ^^ | **Αρσενικό** | sa kaḥ? / kaḥ saḥ?:br⟪स⟫ ⟪कः⟫, ⟪कः⟫ ⟪सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष⟫ ⟪कः⟫, ⟪क⟫ ⟪एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं⟫ ⟪कः⟫, ⟪को⟫ ⟪ऽयम्⟫ | "Ποιος είναι αυτός;":br"Τι είναι;" |

| **Πληθυντικός** | **Ουδέτερο** | tāni kāni? / kāni tāni?:br⟪तानि⟫ ⟪कानि⟫, ⟪कानि⟫ ⟪तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि⟫ ⟪कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि⟫ ⟪कानि⟫, ⟪कानीमानि⟫ | |
| ^^ | **Αρσενικό** | te ke? / ke te?:br⟪ते⟫ ⟪के⟫, ⟪के⟫ ⟪ते⟫:brete ke? / ka ete?:br⟪एते⟫ ⟪के⟫, ⟪क⟫ ⟪एते⟫:brime ke? / ka ime?:br⟪इमे⟫ ⟪के⟫, ⟪क⟫ ⟪इमे⟫ | |
| ^^ | **Θηλυκό** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः⟫ ⟪काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः⟫ ⟪काः⟫, ⟪का⟫ ⟪एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः⟫ ⟪काः⟫, ⟪का⟫ ⟪इमाः⟫ | |

Ένα παράδειγμα άλλων ερωτήσεων:

> viṣṇuḥ kaḥ? = ⟪विष्णुः⟫ ⟪कः⟫ Απάντηση: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (Εδώ, σε μια ονοματική πρόταση, μπορεί κανείς να τοποθετήσει το υποκείμενο στην αρχή, για παράδειγμα, ώστε να τονιστεί η συνέχεια από την ερώτηση.)

ΣΗΜΕΙΩΣΗ: Οι απαντήσεις που μπορείτε να δώσετε σε τέτοιες ερωτήσεις με τις τρέχουσες γνώσεις σας στα Σανσκριτικά, φυσικά, δεν αντιστοιχούν ακόμη σε κάθε πτυχή της ιδιωματικά καλής Σανσκριτικής γλώσσας.

## 4.2. Άσκηση

**Α) Σχηματίστε προφορικά ερωτήσεις με τις ακόλουθες λέξεις σύμφωνα με το σχήμα viṣṇuḥ kaḥ (⟪विष्णुः⟫ ⟪कः⟫) και απαντήστε στις ερωτήσεις στα Σάνσκριτα:**

śruti, śiva, brāhmaṇa, dvija (Πληθυντικός), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫
