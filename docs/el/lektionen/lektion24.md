## 24.2. Σχηματισμός της Δοτικής (⟪चतुर्थी⟫)

::: grammar-box
**Οι κανονικές καταλήξεις της Δοτικής είναι:**

* **Ενικός: -e · φωνητικά λήγοντα θηλυκά ριζικά: -ai**
* **Πληθυντικός: Δοτική και Αφαιρετική ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. Συμφωνικές ρίζες

::: grammar-box

| | Dativ Singular | Dativ Plural |

| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. Ερωτηματικές αντωνυμίες

::: grammar-box

| | Maskulinum / Neutrum | Femininum |

:::

### 24.2.4. Φωνηεντικά θέματα

::: grammar-box
**Φωνητικοί κλίσεις**

* **Άρσυνα / Ουδέτερα σε -a:** ⟪देव⟫
  * Δικ. εν. **⟪देवाय⟫**
  * Δικ. πληθ. **⟪देवेभ्यस्⟫**
* **Άρσυνα σε -i:** ⟪कवि⟫
  * Δικ. εν. **⟪कवये⟫**
  * Δικ. πληθ. **⟪कविभ्यस्⟫**
* **Άρσυνα σε -u:** ⟪पशु⟫
  * Δικ. εν. **⟪पशवे⟫**
  * Δικ. πληθ. **⟪पशुभ्यस्⟫**
* **Θηλυκά σε -ā:** ⟪देवता⟫
  * Δικ. εν. **⟪देवतायै⟫**
  * Δικ. πληθ. **⟪देवताभ्यस्⟫**
* **Θηλυκά σε -ī:** ⟪देवी⟫
  * Δικ. εν. **⟪देव्यै⟫**
  * Δικ. πληθ. **⟪देवीभ्यस्⟫**
* **Θηλυκά σε -i:** ⟪श्रुति⟫
  * Δικ. εν. **⟪श्रुतये⟫** ή **⟪श्रुत्यै⟫** (δηλ. όπως ⟪कवि⟫ ή όπως ⟪देवी⟫)
  * Δικ. πληθ. **⟪श्रुतिभ्यस्⟫**
* **Θηλυκά σε -u:** ⟪धेनु⟫
  * Δικ. εν. **⟪धेनवे⟫** ή **⟪धेन्वै⟫**
  * Δικ. πληθ. **⟪धेनुभ्यस्⟫**
:::
## 24.3. Σάνσκριτ σύνδεση τελικού -ai και -au

::: grammar-box
**Sandhi από λήγοντος -ai και -au**

* **-ai πριν από αρχόμενο φωνήεν συνήθως αντικαθίσταται με -ā (σπανιότερα με -āy όπως εντός λέξεως)**
* **-au πριν από φωνήεν συνήθως αντικαθίσταται με -āv (σπανιότερα με -ā)**

Παράδειγμα:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा⟫ ⟪अग्नये⟫ = "σε αυτό το φωτιά"
:::

## 24.6. Περαιτέρω Άσκηση για τη χρήση της Διαινετικής

Μεταφράστε στα Σανσκριτικά:

1\. Η θεά, στην οποία δεν έγινε θυσία, θυμώνει με τους ανθρώπους.

2\. Αφήνει την αγελάδα να εισέλθει στο χωριό.

3\. Τώρα φτάνει = Αρκετή η υπομονή.

4\. Αυτό είναι καλό (⟪हित⟫, ⟪सुख⟫) για έναν Βραχμανό.

5\. Προσκύνημα (⟪नमस्⟩) ας είναι του Σίβα! Προσκύνημα ας είναι του Σρί Γκάνεσα!

7\. Αυτό το φρούτο αρκεί για φαγητό.

8\. Ένας πολεμιστής είναι άξιος του (άλλου) πολεμιστή (⟪शक्त⟫).

9\. Ακόμη και ο Viṣṇu δεν υπερβαίνει (⟪प्र⟫-⟪भू⟫ + Δοτ.) τον Śiva.

10\. Μετά που γονάτισα μπροστά στους τρεις σοφούς (Ακτ.) (⟪नमस्कृ⟫)... Γονατίζει μπροστά στον Narasiṃha (Δοτ.)
