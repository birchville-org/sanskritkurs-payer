# Μάθημα 12


## 12.1. Μετοχή Παρακειμένου Παθητικής Φωνής (PPP)

Μια δυνατότητα για τη σύνταξη παθητικών προτάσεων στον αόριστο είναι η χρήση της λεγόμενης κατασκευής με το ουσιαστικό Μέλλον (PPP).

::: grammar-box
**Στην πραγματικότητα, το PPP δεν είναι αληθινό ουσιαστικό, καθώς δεν σχηματίζεται από μια ρίζα χρόνου. Αντιθέτως, είναι μια ουσιαστική κατασκευή για τη ρίζα με το πρωτογενές επίθεμα -ta ή -na. Επομένως, στην ινδική γραμματική αναφερόμαστε στο επίθεμα kta.**
:::

### 12.1.1. Σχήμα για μεταβατικά ρήματα

::: grammar-box
**Αιτιαίο (kartṛ) στον Εργαλείο (tṛtīyā) -- Άμεσο Αντικείμενο (karman) στον Υποκείμενος (prathamā) -- Μετοχή Παρακειμένου Παθητικού**

Σε αυτή την περίπτωση, η ΜΠΠ συμφωνεί με το αντικείμενο σε αριθμό, πτώση και γένος.

Δεν απαιτείται ρήμα βοηθητικό («είμαι»).

Παραδείγματα:
> **sādhunā svarga āptaḥ** = ⟪साधुना⟫ ⟪स्वर्ग⟫ ⟪आप्तः⟫ = «(Από τον δίκαιοο αποκτήθηκε ο ουρανός) = Ο δίκαιος απέκτησε έναν ουρανό.»
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन⟫ ⟪देवीष्टा⟫ = «(Από τον βραχμάνο τιμήθηκε η θεά με μια προσφορά) = Ο βραχμάνος τίμησε τη θεά με μια προσφορά.»
:::

### 12.1.2. Σχήμα Ι για αμετάβατα ρήματα και ρήματα κίνησης

::: grammar-box
**Υποκείμενο (kartṛ) στην ονομαστική (prathamā) -- Μετοχή Παρακειμένου Παθητικού**

Σε αυτή την περίπτωση, το PPP συμφωνεί με το υποκείμενο σε αριθμό, πτώση και γένος. Η μετοχή παρακειμένου «παθητικού» έχει ενεργητική σημασία στα αμετάβατα ρήματα (ρήματα χωρίς απαντικα αντικείμενο) και στα ρήματα κίνησης.

Παράδειγμα:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया⟫ ⟪नगरं⟫ ⟪गता⟫ = «Η γυναίκα των Κσατρίγια μπήκε στην πόλη.»
:::

### 12.1.3. Σχήμα II για αμετάβατα ρήματα και ρήματα κίνησης

::: grammar-box
**Αιτιατός (kartṛ) στον Εργαλείο (tṛtīyā) -- PPP στο Ονοματική ενικού ουδέτερου γένους**

Παράδειγμα:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = «(Από τον Kṣatriya έγινε (προς την πόλη) πορεία) = Ο Kṣatriya έχει (προς την πόλη) μετακινηθεί.»

Η σύνταξη σύμφωνα με το Σχήμα II είναι πολύ πιο σπάνια από τη σύνταξη σύμφωνα με το Σχήμα I.
:::

## 12.2. Σχετικά με τη σημασία του PPP

Επομένως, ενώ το λεγόμενο «μετοχή παρακειμένου παθητικού» για τα μεταβατικά ρήματα έχει κυρίως παθητική σημασία (**āpta** = «επικύρωθηκε (παθητικά)») και για τα αμετάβατα ρήματα και τα ρήματα κίνησης ενεργητική σημασία (**gata** = «πήγε»), υπάρχουν μερικά ρήματα στα οποία το PPP μπορεί να έχει τόσο ενεργητική όσο και παθητική σημασία:

π.χ.
- **gata** = ⟪गत⟫ = «πήγε» (ενεργητική), αλλά επίσης: **gato mārgaḥ** = ⟪गतो⟫ ⟪मार्गः⟫ = «ένας δρόμος που έχει διανυθεί» (παθητική)
- **āpta** = ⟪आप्त⟫ = «έχει επικυρωθεί» (παθητική), «επικυρώνοντας» (ενεργητική)

## 12.3. Σχηματισμός της Μτχ. Παθ. Αορ.

::: grammar-box
Εμφανίζονται οι ακόλουθοι τύποι παραγωγής (για κάθε ρίζα πρέπει να μαθαίνεται το αντίστοιχο PPP της!):

**(συνήθως) βαθύβαθη ρίζα**

- **+ -ta**
  - με συνδετικό φθόγγο **-i-** πριν: **-ita**
  - **+ -na**
- **+ -na**

Οι θηλυκές ρίζες έχουν ως εξής: **-tā**, **-itā**, **-nā**; το ουδέτερο κλίνεται όπως **phala** n.
:::

### 12.3.1. Μετοχή Παθητικού Παρακειμένου σε -ta (kta)

#### 12.3.1.1. Χωρίς συνδετικό φωνήεν -i- (aniṭ)

*aniṭ* = «χωρίς (*an-*) το προτεθειμένο επίθημα (*-i-) *t*» (δηλαδή χωρίς τον συνδετικό φωνήεντα *i*).

::: grammar-box
Χωρίς συνδετικό φωνήεν, το PPP σχηματίζεται γενικά από ρίζες που λήγουν σε φωνήεν, καθώς και από πολλές άλλες ρίζες, χωρίς να μπορεί καν να δώσει μια σταθερή κανόνα για το πότε εμφανίζεται ή όχι ο συνδετικός φωνήεντας σε ρίζες με συγκεκριμένη δομή.

Μια λίστα των ριζών *aniṭ* βρίσκεται στο Kielhorn, *Grammatik* § 298.
:::
**Παραδείγματα:**

::: grammar-box
| Ρίζα | PPP (kta) |
| :--- | :--- |
| **bhū** 1 P:br(⟪भू⟫) | **bhū-ta** :br(⟪भूत⟫) |
| **smṛ** 1 P:br(⟪स्मृ⟫) | **smṛ-ta** :br(⟪स्मृत⟫) |
| **nṛt** 4 P:br(nṛt-ta):br(⟪नृत्त⟫) | **nṛt-ta** :br(⟪नृत्त⟫) |

| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |

#### 12.3.1.2. Με Συνδετικό φωνήεν -i- (seṭ)

*seṭ* = *sa-iṭ* = «με (*sa-*) το πρόθεμα καταλήξεως (*-i-) *t*» (δηλαδή με τον συνδετικό φθόγγο *i*).

## 12.4. Νόμοι της φωνητικής σύνδεσης στη λέξη

Στις σχηματισμούς με *aniṭ* πρέπει να ληφθούν υπόψη οι ακόλουθοι νόμοι της φωνητικής σύνθεσης εντός της λέξης. **Αυτοί οι νόμοι είναι πολύ σημαντικοί για την κατανόηση ολόκληρης της σλαβικής μορφολογίας.**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p vor stimmlosem Verschlusslaut (z.B. t, th) bleiben unverändert:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct wird durch kt = ⟪क्त्⟫ ersetzt:** | **muc + ta » muk-ta** = **⟪मुक्त⟫** |
| **3. śt wird durch ṣṭ = ⟪ष्ट्⟫ ersetzt:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. Stimmhafter unaspirierter Verschlusslaut – außer j – wird vor stimmlosem Laut durch den ihm entsprechenden stimmlosen unaspirierten Laut ersetzt:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (wichtig für die 2. Präsensklasse) |
| **5. jt wird durch kt oder ṣṭ ersetzt (nicht fakultativ!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. Stimmhafter aspirierter Verschlusslaut + stimmloser Verschlusslaut » stimmhafter unaspirierter Verschlusslaut + stimmhafter aspirierter Verschlusslaut (Bartholomaesches Aspiratengesetz):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t wird ersetzt durch ḍh mit Dehnung eines vorhergehenden i bzw. u; oder durch gdh. Vor einem solchen ḍh wird a durch o, seltener durch ā, ersetzt:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „etwas verbergen”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

- **budh**: **bodhi** m./f. ⟪बोधि⟫ : η αφύπνιση (μέσω της οποίας ένας Βούδας ή Τίρθικαράτα φτάνει στη λυτρωτική διαύγεια)
