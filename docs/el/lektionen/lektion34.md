# Μάθημα 34

## 34.1. Ο Παρακείμενος (⟪लिट्⟫)

Στο κλασικό σανσκρίτ υπάρχουν μόνο ο ενδεικτικός και το μετοχή από τη ρίζα του παρακειμένου.

::: grammar-box
**Υπάρχουν δύο είδη σχηματισμού του παρακειμένου:**
*   **ο αναδιπλασιασμένος παρακείμενος = ⟪द्वित्वलिट्⟫**
*   **ο περιφραστικός παρακείμενος = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Ο περιφραστικός παρακείμενος (⟪अनुप्रयोगलिट्⟫) χρησιμοποιείται:**
1. **στις παραγωμένες κλίσεις (αιτιατική, βουλητική, συχναστικό, ονοματοποιά)**
2. **στις ρίζες που ξεκινούν με μακρύ φωνήεν (εκτός από ā-) ή με φωνήεν (εκτός από a-) πριν από δύο σύμφωνα**
3. **σε ορισμένες άλλες ρίζες**
:::
## 34.2. Ο αναδιπλασιασμένος παρακείμενος (⟪द्वित्वलिट्⟫)

### 34.2.1. Βαθμίδωση ρίζας

::: grammar-box
**Πληροφόρηση:**

**Ισχυρός ρίζα:** Ενικός Παρασμαϊπάδα
*   **επαναλαμβανόμενο υψηλόβαθμο ή εκτεταμένο βαθμό ρίζας + κατάληξη παρακειμένου**

**Ασθενής ρίζα:** όλες οι υπόλοιπες μορφές
*   **επαναλαμβανόμενο χαμηλόβαθμο ρίζας + κατάληξη παρακειμένου**
:::
::: grammar-box
**Γενικά (ακόμη και εκτός του παρακειμένου) δεν έχουν βαθμίδα ρίζας οι ρίζες της μορφής:**
*   **(Σύμφωνο)-Σύμφωνο-Μακρόφωνο-Σύμφωνο**
*   **(Σύμφωνο)-Σύμφωνο-Φωνήεν-Σύμφωνο-Σύμφωνο**

**Στον παρακειμένο, επιπλέον, δεν έχουν βαθμίδα ρίζας οι ρίζες της μορφής:**
*   **a-Σύμφωνο**
*   **ā-Σύμφωνο**
:::
### 34.2.2. Οι καταλήξεις του Παρακειμένου

::: grammar-box

| | 3. Singular | 3. Plural |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |

:::
### 34.2.3. Συνδετικό φωνήεν -i-

::: grammar-box
**Πριν από την κατάληξη της 3ης πληθ.Ā (-re) εμφανίζεται πάντα ο συνδετικός φθόγγος -i-, πριν από τις άλλες καταλήξεις που ξεκινούν με σύμφωνο στις περισσότερες ρίζες.**
:::
### 34.2.4. Αναδιπλασιασμός ριζών που αρχίζουν με σύμφωνο

::: grammar-box
**Για τον αναδιπλασιασμό ριζών που αρχίζουν με σύμφωνο ισχύουν οι κανόνες που δίνονται στην [Μάθημα 33](lektion33.md).**

**Ο φθόγγος αναδιπλασιασμού για ρίζες που αρχίζουν με σύμφωνο είναι ο βραχύς φθόγγος της ρίζας.**

**Οι δίφθογγοι πριν από σύμφωνο μειώνονται στον αντίστοιχο βραχύ φθόγγο της βαθιάς στάσης.**

**ṛ, ṝ, ḷ και οι τελικοί δίφθογγοι αναπληρώνονται με -a-.**
:::
Παραδείγματα:

::: grammar-box

| Wurzel | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | *:sig[⟪बि⟫]*⟪भेद⟫ |
| ⟪मुच्⟫ | *:sig[⟪मु⟫]*⟪मोच⟫ |
| ⟪भृ⟫ | *:sig[⟪ब⟫]*⟪भार⟫ |

:::
::: grammar-box
**Ορισμένες ρίζες που αρχίζουν με y ή v, επαναλαμβάνονται με i ή u, το οποίο στις αδύναμες μορφές «συγχωνεύεται» με τον φθόγγο της ρίζας.**
:::
Παραδείγματα:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Αναδιπλασιασμός ριζών που αρχίζουν με φωνήεν

::: grammar-box
**1. Το αρχικό a-, ā- αναδιπλασιάζεται με a-, οπότε προκύπτει ā-.**
:::
Παραδείγματα:

::: grammar-box

| Wurzel | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "sein" und ⟪अस्⟫ 4 "werfen" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. Οι ρίζες με αρχικό i- έχουν ως συλλαβή επανάληψης στον ισχυρό λόγο iy-, και στον ασθενή λόγο i-, ο οποίος «συγχωνεύεται» με τον φθόγγο της ρίζας σε ī-. Το ίδιο ισχύει και για το αρχικό u-.**
:::
Παραδείγματα:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. Ρίζες που ξεκινούν με a- μπροστά από δύο σύμφωνα ή με ṛ-, έχουν ως συλλαβή επανάληψης (reduplication) το ān-**
:::
Παραδείγματα:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. Τύποι του αναδιπλασιασμένου Παρακειμένου

Κριτήριο ταξινόμησης: Ιδιαίτερα χαρακτηριστικά της κλίσης του ρίζας:
*   Παρακείμενος χωρίς κλίση ρίζας: Τύπος I
*   Παρακείμενος με κλίση ρίζας: Τύπος II - V
*   ακανόνιστες παρακείμενες κλίσεις

## 34.4. Παρακείμενος Τύπου Ι: Παρακείμενος χωρίς διαβάθμιση στελέχους

::: grammar-box
**Ο τύπος Ι του παρακειμένου (χωρίς κλίση ρίζας) έχει ρίζες των τύπων:**
*   **(Συνεπτικό)-Συνεπτικό-Μακρόφωνο-Συνεπτικό**
*   **(Συνεπτικό)-Συνεπτικό-Φωνήεν-Συνεπτικό-Συνεπτικό**
*   **a-Συνεπτικό**
*   **ā-Συνεπτικό**
