# Բառագիտության թեմաներ

Այս էջը տրամադրում է սանսկրիտական ընթացակարգի բոլոր քերականական թեմաների համակարգված նախադրյալ։ Ամեն 61 դասը այստեղ թեմատիկորեն դասակարգված է։

*   **Ներածություն եւ Śloka** -\> [Դաս 45](/hy/lektionen/lektion45), [Դաս 53](/hy/lektionen/lektion53)
