# Դաս 22

## 22.1. Աբսոլյուտիվ (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

Սանսկրիտով արտահայտելու համար, որ գործողության (⟪कर्तृ⟫) մի քայլը նախորդում է գործողության (⟪क्त्वा । ल्यप्⟫) մեկ այլ քայլին կամ ուղեկցում է դրան որպես լրացուցիչ հանգամանք, օգտագործվում է աբսոլյուտիվը (⟪क्त्वा । ल्यप्⟫): Այսպես

«նա արեց դա, հետո արեց այն» ; «նա արեց դա, հետո արեց այն» ; «դրանից հետո նա արեց այն» ; «ես եկա, տեսա և հաղթեցի» և այլն

Աբսոլյուտիվը վերաբերում է գործողության ձևին, այսինքն՝ այն ոչ է կոնյուգացվում, ոչ է դեկլինացվում, բայց միշտ — քչաթիվ դեպքերը բացառությամբ — ունի նույն գործողը (⟪कर्तृ⟫), ինչ գործողությունը, որին աբսոլյուտիվով արտահայտված գործողությունը նախորդում է կամ ուղեկցում: Աբսոլյուտիվի գործողը հետևաբար լինում է նոմինատիվ (⟪प्रथमा⟫) կամ ինստրումենտալ (⟪तृतीया⟫):

Կոմպոզիտների կողքին աբսոլյուտիվը սանսկրիտում ամենահաճախակի արտահայտչական միջոցներից է:

Գերմաներեն թարգմանելիս խուսափեք «հետո» բառը անընդհատ կրկնելուց: Փոխարենը օգտագործեք գերմաներենում ընդունված ժամանակային հաջորդականության արտահայտչական միջոցներ:

**Սխեմա:**

(ավելի մանրամասն որոշում աբսոլյուտիվին. հանգամանքային որոշում, օբյեկտ և այլն) - աբսոլյուտիվ - աբսոլյուտիվ - ... - աբսոլյուտիվ - ... գործող + արտահայտություն (ակտիվ կամ պասսիվ)

:::
**Օրինակներ:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = պասսիվ կառուցվածք: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**  
«Տղամարդը մտնում է տուն, տեսնում է փոքրիկ աղջկան և խոսում է նրա հետ»:

Հոգնակի: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. Աբսոլյուտիվի ձևավորումը

::: grammar-box
**Աբսոլյուտիվի ձևավորումը**

*   Գոյականներ առանց նախածանցի. Աբսոլյուտիվը **-tvā** վերջավորությամբ
*   Գոյականներ նախածանցով. Աբսոլյուտիվը **-ya** կամ **-tya** վերջավորությամբ
:::
### 22.2.1. Գոյականներ առանց նախածանցի. Աբսոլյուտիվը -⟪त्वा⟫

::: grammar-box

**Ձևավորում.**

(հիմնականում) խորացված արմատը այն տեսքով, որում այն առկա է PPP-ից առաջ + **-tvā** (**-⟪त्वा⟫**)

Միայն բացասական **a-** / **an-** համատեղելի է **-⟪त्वा⟫** վերջավորության հետ. ⟪अकृत्वा⟫ "առանց գործելու"

:::
**Օրինակներ.**

::: indent
⟪आप्त्वा⟫ "իր / նրա / իմ / քո / մեր / ձեր / նրանց / երկուսի/երկուսին հասնելուց հետո"

⟪आसित्वा⟫ "նստելուց հետո"

⟪इत्वा⟫ "գնալուց հետո"

⟪स्थित्वा⟫ "կանգնելուց հետո"

⟪जित्वा⟫ "հաղթելուց հետո"

⟪उक्त्वा⟫ "խոսելուց հետո"
:::
### 22.2.2. Գոյականներ նախածանցով

#### 22.2.2.1. Արմատներ երկար ձայնավորով (բացառությամբ -ā) կամ բաղաձայնով

::: grammar-box

**(հիմնականում) խորացված արմատ + -ya**

:::
**Օրինակներ.**

::: indent
⟪उपनीय⟫ "բերելուց հետո"

⟪प्रभूय⟫ "դուրս հայտնվելուց/լինելուց" "հզորություն ունենալուց հետո"

⟪प्राप्य⟫ "ստանալուց/հասնելուց հետո"
:::
#### 22.2.2.2. Արմատներ -ā վերջավորությամբ

::: grammar-box

**անփոփոխ բարձրացված արմատ + -ya**

:::
**Օրինակ.**

::: indent
⟪उपस्थाय⟫ "մոտենալուց/հասնելուց հետո" ; (բայց առանց նախածանցի. ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. Արմատներ, որոնք խորացված աստիճանում վերջանում են կարճ -i, -u, -ṛ

::: grammar-box

**խոր աստիճանի արմատ + -tya**

:::
**Օրինակներ.**

::: indent
⟪प्रस्तुत्य⟫ «իր (...)-ի մասին բարձր գովեստ արելուց հետո»

⟪विस्मृत्य⟫ «իր (...)-ը մոռացելուց հետո»

⟪संस्कृत्य⟫ «իր (...)-ը զոհաբերության համար պատրաստելուց հետո»
:::
#### 22.2.2.4. -am / -an վերջավորությամբ արմատներ, որոնք խոր աստիճանում -a-ով են ավարտվում

::: grammar-box

**Ըստ ընտրության.**

**-am** / **-an** վերջավորությամբ արմատ + **-ya**

կամ.

**-a** վերջավորությամբ արմատ + **-tya**

:::
**Օրինակ.**

::: indent
⟪विगम्य⟫ կամ ⟪विगत्य⟫ «իր (...)-ից հեռանալուց/հեռացելուց հետո»

⟪अन्नं पक्त्वा ब्राह्मणदासो ऽत्ति ॥१॥ इष्टदेवतापूजां कृत्वेन्द्रादिदेवान्सद्ब्राह्मणाः स्तुवन्ति ॥२॥ प्रस्थाय रामः सपुत्रः सद्गुरुश्रवणार्थेन ब्राह्मणग्रामं गच्छति ॥३॥ अनिष्ट्वा नरो भगवद्भक्तिमात्रेणापि मोक्षमाप्नोति ॥४॥ गृहगर्भं प्रविश्य ब्राह्मणपुत्रमुपस्थाय क्षत्रियशूरो वक्ति ॥५॥ सम्बुध्य दुःखाद्यार्यसत्यानि प्रोच्य सुगतो मोक्षमार्गेण नरान्नयति ॥६॥ मन्त्रं विस्मृत्य यजन्यज्ञदोषं करोति ॥७॥ धनं प्राप्य बुद्धमार्गभिक्षवो दुष्यन्ति ॥८॥ अनार्यशत्रुभिः संगत्य नरसिंहा विजयन्ते ॥९॥ पुण्यं कृत्वा सत्यमेवोदित्वा नरो नरकं नोपपद्यते ॥१०॥⟫
