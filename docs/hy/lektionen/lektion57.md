# Դաս 57

## 57.1. Աորիստ 4: s-աորիստ

::: grammar-box
**s-աորիստը կազմվում է ⟪अनिट्⟫ արմատների մեծամասնության հիման վրա, եթե դրանք չունեն բացառապես այլ աորիստային ձև։ Ընդհանուր առմամբ, ⟪अनिट्⟫ արմատները կարող են ձևավորել այս կամ iṣ-աորիստը։ Բացի այդ, ⟪अनिट्⟫ արմատները, որոնք ձևավորում են ⟪परस्मैपद⟩ աորիստի 1-ին, 2-րդ կամ 6-րդ ձևից հետո, ⟪आत्मनेपद⟩-ը ձևավորում են s-աորիստի համաձայն։**

**Կազմություն. Ավգմենտ + արմատ + s + աթեմատիկ երկայնական վերջավորություն**
:::
Վերջավորությունների աղյուսակ՝ արմատաձև ստեղծման հավելվածով

::: grammar-box

|   | ⟪परस्मैपदम्⟩ || ⟪आत्मनेपदम्⟩ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟩ | ⟪बहुवचनम्⟩ | ⟪एकवचनम्⟩ | ⟪बहुवचनम्⟩ |
| **1. ⟪तृतीयः⟩** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟩** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟩** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**Կիրառվում է ընդհանուր հնչյունաբանական օրենքը, ըստ որի՝ երկու պայթական հնչյունների միջև ընկած փողոցային հնչյունը (զիստ) ընկնում է (համեմատ. ⟪उद्⟩ + ⟪स्थित» ⟪उत्थित»), այսինքն՝ արմատաձև ստեղծման -s- հավելվածը ընկնում է այն վերջավորություններից առաջ, որոնք սկսվում են -t- կամ -th- տառերով (բայց ոչ քթահնչյունների կամ r-ից հետո)։**

Օրինակներ.

:::
::: indent
3.պարտ. a-kṣip + s + ta » ⟪अ⟩:sig[⟪क्षिप्त⟩]
2.պարտ. a-kṣip + s + thās » ⟪अ⟩:sig[⟪क्षिप्था⟩]⟪स्⟩
:::
Նման ձևերը կարող են պատկանել նաև արմատային աորիստին, և հավանաբար մասամբ էլ պատկանում են։
Հնդիկ քերականները նաև ⟪अकृत⟩ (3.պարտ.) ձևերը հաշվել են s-աորիստին, որոնք միանշանակ պատկանում են արմատային աորիստին։ Այդ նպատակով հնդիկ քերականները s-աորիստի համար ստեղծել են հետևյալ ad-hoc օրենքը.

::: indent
«Կարճ վանկից հետո -s- կամ -sth- սկսվող «վերջավորությունները» կորցնում են -s-ը։»
:::
Հակառակ դեպքում պետք է հաշվի առնել ձայնավորով ավարտվող բաղաձայների և s-ի միացման հնչյունաբանական կանոները։

dhvam-ի համար վերաբերում է.
