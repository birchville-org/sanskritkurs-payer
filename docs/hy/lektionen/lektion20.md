# Դաս 20

## 20.1. Սեփականության կոմպոզիտներ = ⟪बहुव्रीहि⟫ m.

::: media
![](/images/lekt2004.webp)
Նկար. ⟪बहुव्रीहिः पुरुषः⟫
Ժոդպուր = ⟪जोधपुर⟫
(Նկարի աղբյուրը. [Մանրամասներ](/hy/licenses#lekt2004))
:::
⟪बहुव्रीहिः⟫ = ⟪बहवो व्रीहयो यस्य सः⟫ = «մեկ, ով շատ բրինձ ունի»

::: grammar-box

**Բահուվրիհին տատպուռուշայի համեմատ նշանակում է այլ բան, քան դրա մասերով արտահայտվում է. եթե ⟪बालपुत्रः⟫-ը որպես տատպուռուշա լուծելիս նշանակում է «երիտասարդ որդի», այսինքն՝ բան, որը արտահայտվում է կոմպոզիտի վերջին մասով (⟪पुत्र⟫), ապա ⟪बालपुत्रः⟫-ը որպես բահուվրիհա լուծելիս նշանակում է «մեկ, ում որդին երիտասարդ է», այսինքն՝ նշանակվողը ոչ թե որդին է (⟪पुत्र⟫), ոչ թե անպայման երիտասարդ (⟪बाल⟫), այլ երիտասարդ որդուց տարբեր անձ, այսինքն՝ նրա հայրը։**

**Սեփականության կոմպոզիտները սկզբում միշտ ածականներ են, որոնք կարող են գոյականացվել։ Այդ պատճառով բահուվրիհայի քերականական սեռը կախված է նրանից, թե ինչին է վերաբերվում բահուվրիհան, և ոչ թե կոմպոզիտի վերջին մասի սեռից։**

:::
::: grammar-box

**Բահուվրիհայի լուծման սխեմա.**

**1. Առաջին մասը սովորաբար ներգործական հոլովում (⟪प्रथमा⟫) միքանակ, երկնակ կամ հոգնակի -- 2. մասը ներգործական հոլովում, միքանակ, երկնակ կամ հոգնակի -- Հարաբերական դերանունը այլ հոլովում, քան ներգործական (սովորաբար սեռական - ⟪षष्ठी⟫) և թվով ու սեռով համապատասխանում է ամբողջական բահուվրիհային -- Ցուցական դերանունը թվով, հոլովով և սեռով համապատասխանում է ամբողջական բահուվրիհային։**

:::
Օրինակներ.


::: indent
⟪गतपापः⟫ = ⟪गतं पापं यस्य सः⟫ = «մեկ, ուր գնացել է վատը» = «մեկ, ով ազատ է չարագործություններից»

:::

:::

## 20.6. Bahuvrīhi-ի վերջին բաղադրիչի ձևաբանությունը

::: grammar-box

**Bahuvrīhi-ի վերջին բաղադրիչը ձևաբանվում է որպես բազմասեռական ածական՝ անկախ իր սկզբնական սեռից։ Այսպես, եթե կազմակերպված բառում վերջին բաղադրիչն ունի այլ սեռ, քան իր սկզբնականը, ապա այն պետք է լինի Bahuvrīhi, եթե դա Samāhāradvanva (հոգնակի չեզոք) չէ։**

**Ածականացման դեպքում**

*   **-ā-արմատները հոգնակի և չեզոք սեռերում դառնում են -a-արմատներ**
*   **-a-արմատները (հոգնակի, չեզոք) կազմում են իրենց էգիտականը -ā կամ -ī վերջավորությամբ**
*   **-ī-արմատները (էգիտական) պետք է վերջում ընդունեն -ka, -kā, -ka (չեզոք) վերջավորությունը; այս վերջավորությունը կարող են ընդունել նաև այլ Bahuvrīhi-ներ**

## 20.7. Bahuvrīhi-ների տեսակների այլ դասակարգում

Օրինակները այստեղ տրված են հետագա ուսումնասիրության համար, որոշների համար դեռ չեն քննարկվել անհրաժեշտ քերականությունը և բառապաշարը

1.  որակավորող բառ առջևի մասում -- որակավորված բառ հետևի մասում. ⟪स्थिरचित्तः⟫ = ⟪स्थिरं चित्तं यस्य सः⟫
2.  Չփոխվող բառեր առջևի մասում. ⟪उच्चैःश्रवस्⟫
3.  Համեմատություն առջևի մասում. ⟪कुशाग्रधीः⟫ =  ⟪कुशाग्र इव धीर्यस्य सः⟫
4.  Անուղղակի համեմատություն. ⟪उष्ट्रमुखः⟫ = ⟪उष्ट्रस्य मुखमिव मुखं यस्य सः⟫ = «ուղտի բերանով» = որի բերանը ուղտի բերանին նման է
5.  Համարակալներ հետևի մասում մոտավոր թվերի դեպքում. ⟪उपसशाः⟫ = ⟪दशानां समीपे ये सन्ति ते⟫ = «մոտավորապես տասը»
6.  երկու բաղադրիչներն էլ համարակալ են. ⟪एकद्वाः⟫ = ⟪एको वा द्वौ वा⟫ = «մեկ կամ երկու»
7.  sa-/saha- առջևի մասում. ⟪सपुत्रः । सहपुत्रः⟫
8.  sa- (= ⟪समान⟫) առջևի մասում. ⟪सजनपदः⟫ = ⟪समानो जनपदो यस्य सः⟫

10.  նախդիրներով և այլն առջևի մասում. ⟪प्रवातः⟫ =⟪प्रकृष्टो वातो यस्मिन् सः⟫ ; ⟪निर्धनः⟫ = ⟪निर्गतं धनं यस्मात्सः⟫ ; ⟪सुबुद्धिः⟫ = ⟪सुष्ठु बुद्धिर्यस्य सः⟫ ; ⟪दुर्बुद्धिः⟫ = ⟪दुष्टा बुद्धिर्यस्य सः⟫

## 20.8. Բահուվրիհիի և հարաբերական նախադասության հարաբերությունը

Թեև յուրաքանչյուր բահուվրիհին կարելի է վերլուծել հարաբերական նախադասությամբ, բայց ոչ ամեն հարաբերական նախադասություն կարելի է փոխարինել բահուվրիհով։ Հերման Գեորգ Յակոբին (1850 - 1937), ով մանրամասն ուսումնասիրել է երկուսի հարաբերությունը (Compositum und Nebensatz, 1897), գրում է.

::: indent
«Եթե գերմաներենից կամ այլ ժամանակակից լեզուներից սանսկրիտ ենք թարգմանում, բոլոր երկրորդական նախադասությունները կարելի չէ փոխանցել ստորակետային բառակապակցություններով, այլ միայն զարդարող և նկարագրական. այնուամենայնիվ, ուղեկցող նախադասությունները, որոնք պարունակում են հայեցակարգորեն անհրաժեշտ կամ կարևոր որոշում, սանսկրիտով նույնպես հարաբերական նախադասություններով են արտահայտվում։»
:::

(Նկարի աղբյուրը. [Մանրամասներ](/hy/licenses#lekt2002))

Սա կարող է ճիշտ լինել։ Այնուամենայնիվ, հնդիկները շատ բան դիտարկում են որպես զարդարող և նկարագրական, մինչդեռ մենք դա կհամարենք «հայեցակարգորեն անհրաժեշտ կամ կարևոր»։

## 20.11. Վարժություն 2

Ա) Թարգմանեք և վերլուծեք սանսկրիտական կոմպոզիտները.

⟪इन्द्रशत्र्वनार्या देवेन्द्रेण जीयन्ते ॥१॥ शूरबलक्षत्रिययोधः शूरपुत्रमिच्छति ॥२॥ सुदुर्गममार्गेण स्वर्गं गम्यते । सुगमस्तु नरकमार्गः ॥३॥ मृतपुत्रब्राह्मणी रोदिति ॥४॥ वीतमोहब्राह्मणः सम्पन्नरूपामपि शूद्रां न लुभ्यति ॥५॥ सुनीतिपुत्रः प्राप्तमतिदर्शनसाधुं गच्छति ॥६॥ प्राप्तप्रभावक्षत्रिया दृष्टमात्राञ्छत्रून्घ्नन्ति ॥७॥ जितशत्रुयोधाः शत्रुजितान्मुञ्चन्ति ॥८॥ कृतोपनयनबालः शिवादिदेवपूजां करोति ॥९॥ बुद्धगता दुःखादिसत्यानि शृण्वन्ति ॥१०॥⟫

Բ) Սանսկրիտով թարգմանեք՝ օգտագործելով կոմպոզիտներ.

1\. Քաշատրիյան, ով ձեռքին կայծակ չի պահում, չի պաշտպանում ժողովրդին։

2\. Կալիդասան և մյուս բանաստեղծները սանսկրիտի ուսուցիչներն են։

3\. Քաշատրիյան կերպարվեստով է ապրում։

4\. Շուդրա կանայք նույնպես ունեն դարմայի չարաչարություն, անկեղծություն, մաքրություն, չմurmuring-ը, անվատություն և համբերություն։
