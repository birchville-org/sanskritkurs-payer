# Դաս 34

## 34.1. Պերֆեկտը (⟪लिट्⟫)

Դասական սանսկրիտում պերֆեկտի արմատից կան միայն ինդիկատիվը և պարտիցիպը։

::: grammar-box
**Կան պերֆեկտի կազմության երկու տեսակ.**
*   **վերականգնող պերֆեկտ = ⟪द्वित्वलिट्⟫**
*   **պերիֆրաստիկ պերֆեկտ = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Պերիֆրաստիկ պերֆեկտը (⟪अनुप्रयोगलिट्⟫) օգտագործվում է.**
1. **ածանցյալ ժամանակների համար (կաուզատիվ, դեսիդերատիվ, ֆրեկուենտատիվ, դենոմինատիվ)**
2. **արմատների համար, որոնք սկսվում են երկար ձայնավորով (բացառությամբ ā-), կամ ձայնավորով (բացառությամբ a-) երկու բաղաձայնից առաջ**
3. **որոշ այլ արմատների համար**
:::
## 34.2. Վերականգնող պերֆեկտ (⟪द्वित्वलिट्⟫)

### 34.2.1. Արմատի շարժառիթ

::: grammar-box
**Կազմություն.**

**ուժեղ արմատ. միայնակ Պարասմաիպադա**
*   **վերականգնող բարձր աստիճանի կամ երկարացված արմատ + պերֆեկտի վերջավորություն**

**թույլ արմատ. մնացած բոլոր ձևերը**
*   **վերականգնող ցածր աստիճանի արմատ + պերֆեկտի վերջավորություն**
:::
::: grammar-box
**Ընդհանուր առմամբ (նաև պերֆեկտից դուրս) չունեն արմատի շարժառիթ հետևյալ տեսքի արմատները.**
*   **(բաղաձայն)-բաղաձայն-երկար ձայնավոր-բաղաձայն**
*   **(բաղաձայն)-բաղաձայն-ձայնավոր-բաղաձայն-բաղաձայն**

**Պերֆեկտում, բացի այդ, չունեն արմատի շարժառիթ հետևյալ տեսքի արմատները.**
*   **ա-բաղաձայն**
*   **ā-բաղաձայն**
:::

### 34.2.3. Միացնող ձայնավոր -i-

::: grammar-box
**Նախքան 3.հոգնակի Ā (-re) վերջավորությունը, միշտ ավելանում է Միացնող ձայնավոր -i-, նախքան մյուս բաղաձայնով սկսվող վերջավորությունները հոգնակիում՝ արմատների մեծամասնության դեպքում։**
:::
### 34.2.4. Կոնսոնանտով սկսվող արմատների կրկնաձայնում

::: grammar-box
**Կոնսոնանտով սկսվող արմատների կրկնաձայնման համար գործում են [Դաս 33](lektion33.md)-ում նշված կանոնները։**

**Կոնսոնանտով սկսվող արմատների կրկնաձայնման շեշտը կարճ արմատական վոկալն է։**

**Կոնսոնանտից առաջ եկող դիֆթոնգները կրճատվում են համապատասխան կարճ ցածր շեշտով։**

**ṛ, ṝ, ḷ և վերջանող դիֆթոնգները կրկնաձայնվում են -a-ով։**
:::

## 34.3. Վերականգնված պարֆեկտի տեսակներ

Դասակարգման սկզբունք: Տարրի փոփոխության առանձնահատկությունները:
*   Պարֆեկտ առանց տարրի փոփոխության: Տեսակ I
*   Պարֆեկտ տարրի փոփոխությամբ: Տեսակ II - V
*   անկանոն պարֆեկտ կառուցվածքներ
