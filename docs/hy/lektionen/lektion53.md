# Դաս 53

## 53.1. Երկական թիվը (⟪द्विवचन⟫ n.) անունների

::: grammar-box
**Երկական թիվը (⟪द्विवचनम्⟫) օգտագործվում է «երկու» նշելու համար.**

:::
::: indent
⟪अश्विनौ⟫ «երկու Աշվինները»
:::
**Երկական թվի օգտագործումը պարտադիր է, երբ խոսքը վերաբերում է երկու առարկաներին և այլն.**

::: indent
⟪हस्तौ⟫ «ձեռքերը (մի անհատին)»
⟪पादौ⟫ «ոտքերը (մարդու, կապիկի կամ այլ երկոտանիի)»
:::
**Երբեմն երկական թիվը նշանակում է միևնույն դասին (տեսակ, ցեղ) պատկանող իգական և արական նմուշներ.**

::: indent
⟪पितरौ⟫ «հայր և մայր = ծնողներ»
:::
**«Զույգ» նշանակող բառերը, օրինակ՝ ⟪युग⟫ n., ⟪द्वन्द्व⟫ n., ⟪द्वय⟫ n. - միշտ օգտագործվում են եզակի թվով, եթե խոսքը վերաբերում է երկու կամ ավելի զույգերին.**

::: indent
⟪बाहुद्वयम्⟫ «զույգ թևեր»
:::

## 53.7. Սեռական ածանցյալներ

Հետևյալ սեռական ածանցյալները ընդունակ են բոլոր հոլովներում, ինչպես ⟪यद्⟫:

*   ⟪अन्य⟫ 3 «մեկ այլ»
*   ⟪अन्यतर⟫ 3 «երկուսից մեկը»
*   ⟪इतर⟫ 3 «մյուսը»

*   ⟪सर्व⟫ 3 «ամեն, բոլոր» ընդունակ է բոլոր հոլովներում, բացառությամբ ներգործականի և հայտարարականի (⟪सर्वम्⟫), ինչպես ⟪यद्⟫:
*   ⟪उभय⟫ 3 «երկուսը» չունի երկական հոլով: Այն միակ և բազմական թվերում, տղամարդկային և չեզոք սեռերում, ընդունակ է բոլոր հոլովներում, ինչպես ⟪सर्व⟫: Կին սեռը՝ ⟪उभयी⟫ (ինչպես ⟪देवी⟫):
*   ⟪उभ⟫ 3 «երկուսը» միայն երկական թվով է օգտագործվում, և այն տղամարդկային սեռի համար ընդունակ է բոլոր հոլովներում, ինչպես ⟪देव⟫, չեզոք սեռի համար՝ ⟪फल⟫, կին սեռի համար՝ ⟪देवता⟫:

Հետևյալ սեռական ածանցյալները ընդունակ են բոլոր հոլովներում, ինչպես ⟪सर्व⟫: Աբլատիվ և լոկատիվ միակ թվերում, տղամարդկային և չեզոք սեռերում, նաև բազմական թվի հայտարարական և հայտնական սեռերում, կարելի է ընդունակ բոլոր հո

*   ⟪अपर⟫ 3 «մեկ ուրիշը»
*   ⟪उत्तर⟫ 3 «վերին, հյուսիսային, հաջորդող»

*   ⟪पूर्व⟫ 3 «նախորդող, արևելյան»

## 53.11. Վարժություն

::: grammar-box
**Բոլոր նախկինում սովորած բանաստեղծությունների միջոցով ճշգրտեք չակաները։ Դրանց համար գրավոր կազմեք մետրական սխեման։ Նշեք հնարավոր անկանոնությունները կամ Վիպուլա տեսակները։**
