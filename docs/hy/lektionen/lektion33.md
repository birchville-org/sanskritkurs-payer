# Դաս 33

## 33.1. Կրկնաձայնումը (⟪अभ्यास⟫ հոդ.)

* Երրորդ ներկայի դասը
* (ինչպես նաև այլ ներկայի դասերի որոշ բայեր),
* լուծը,
* կրկնաձայնված աորիստը,
* հաճախականը և
* ձեռնտունակը

կազմվում են կրկնաձայնման միջոցով։ Կրկնաձայնված ձևի այն մասը, որը դրվում է արմատից առաջ, կոչվում է կրկնաձայնման վանակ։

Կրկնաձայնման վանակը բաղկացած է (մի խոչընդոտից և) մի ձայնավորից։

## 33.2. Երրորդ ներկայի դասը (⟪जुहोत्यादि⟫ = «⟪जुहोति⟫ և այլն»)

::: grammar-box
**Կազմություն.**

**ուժեղ արմատ:**  
**կրկնաձայնված բարձրաստիճան արմատ + վերջավորություն**

**թույլ արմատ:**  
**կրկնաձայնված ցածրաստիճան արմատ + վերջավորություն**

**Կրկնաձայնման համար գործում են վերև նշված կանոնները։**
:::

## 33.3. ā-ի աբլաուտի մասին

ā kann

* մի կողմից՝ -a- պարունակող աբլաուտային շարքերից մեկի երկարացված աստիճանը
* մյուս կողմից՝ ā-խմբի աբլաուտային շարքերում բարձր աստիճանը

ā-խմբի երկու ամենակարևոր աբլաուտային շարքերն են.

::: grammar-box
**Ա.**

* **Ցածր աստիճան**
* **համաձայնեղից առաջ. -i-**  
օրինակ՝ ⟪धा⟫ պ.բ.հ.՝ ⟪हित⟫ (hi-ta)
* **ձայնավորից առաջ. Ø**  
օրինակ՝ ⟪धा⟫ 3-րդ բազմ. միտ. ներկ. ⟪दधति⟫ (dadh-ati)
* **Բարձր աստիճան. -ā-**  
օրինակ՝ ⟪धा⟫ 3-րդ դ. միտ. ներկ. ⟪दधाति⟫
:::

:::

* **Глубокая ступень: -ī-**  
напр. ⟪पा⟫ 1: Ч.с.д. ⟪पीत⟫ (pī-ta)
* **Высокая ступень: -ā-**

## 33.4. Корни на -ā третьего класса настоящего времени

::: grammar-box
**Корни на -ā (кроме ⟪दा⟫ и ⟪धा⟫) в слабой форме обычно оканчиваются на -ī-** (см. Thumb-Hauschild, т. 1, ч. 1, стр. 271. Вероятно, здесь образец послужила вышеупомянутая чередовательная серия Б, хотя эти корни в остальном чередуются по серии А), **перед гласными окончаниями корневой гласная полностью исчезает (см. чередовательную серию А).**
:::
Примеры:

::: grammar-box
⟪मा⟫ 3А "измерять"

| | 3 л. ед.ч. А. | 3 мн.ч. А. |
| :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Аорист** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Сослагательное наклонение** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3П "покидать"

| | 3 л. ед.ч. П. | 3 мн.ч. П. |
| :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Аорист** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Сослагательное наклонение** | ⟪जह्यात्⟫:brjah-yā-t:br(Корень ⟪हा⟫ перед Optativ-yā/y имеет ту же форму, что и перед гласными!) | ⟪जह्युर्⟫:brjah-y-ur |
:::

## 33.7. Վարժություն

Ա) Հետևյալ նախադասության կառուցվածքում տեղադրեք փակագծերում նշված բառերի համապատասխան ձևերը.

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने बहुवचने च⟫) ... ⟪अन्नं ददाति ।⟫ (⟪भिक्षु । अग्नि । शूद्रा । गुनवान्पुत्र । देवान्स्तुवन्कवि । ब्राह्मणी । महान्साधु । धेनु⟫)

Բ) Տեղադրեք փակագծերում նշված բայերի համապատասխան ձևերը նշված տեսակներով.

⟪ब्राह्मणो घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥ बुद्धगता भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥ सुगतः कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥ दुर्जना भिक्षुभ्यो ऽन्नं न⟫ ... (⟪दा⟫) ⟪॥४॥ साधुः कृष्णे मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो लोकान्⟫ ... ⟪जनास्तु न⟫ ... (⟪मा⟫) ⟪॥६॥ दासा भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥ ब्राह्मणी पात्रं जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫

Թարգմանեք և վերածեք միայնակ ստորաբաժանումները հոգնակի ստորաբաժանումների, և հակառակը.
