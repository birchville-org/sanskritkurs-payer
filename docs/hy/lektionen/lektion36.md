## 36.2. Պերիֆրաստիկ պերֆեկտ (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
Պերիֆրաստիկ պերֆեկտը (⟪अनुप्रयोगलिट्⟫) օգտագործվում է՝

1. при производных спряжениях (каузатив, десидератив, фреквентатив, денеминативы)
2. при корнях, начинающихся с долгого гласного (кроме ā-), либо с гласного (кроме a-) перед двумя согласными
3. при некоторых других корнях
:::
::: grammar-box
**Образование:**

(слабый) основа настоящего времени + -ām + соответствующая форма перфекта от ⟪कृ⟫, ⟪अस्⟫ или ⟪भू⟫

Окончательный гласный основы гунируется перед -ām.
⟪अस्⟫ и ⟪भू⟫ спрягаются также в парасмайпада у глаголов атманепады.
:::
Перифразический перфект, вероятно, возник из винительного падежа вербального существительного на -ā. Этот винительный падеж используется, как и часто бывает, в адвербиальной функции.

Примеры:

| Корень:br⟪धातु⟫ | 3. ед. ч. Перф. П. | 3. мн. ч. Перф. П. | 3. ед. ч. Перф. Ā. | 3. мн. ч. Перф. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪ईक्ष्⟫ 1Ā | | | **⟪ईक्षां चक्रे⟫** :br ⟪ईक्षामास⟫ :br **⟪ईक्षां बभूव⟫** | **⟪ईक्षां चक्रिरे⟫** :br ⟪ईक्षामासुर्⟫ :br **⟪ईक्षां बभूवुर्⟫** |
| ⟪बन्ध्⟫ :brКазуатив: ⟪बन्धय⟫-:br"заставлять связывать" | **⟪बन्धयां चकार⟫** :br ⟪बन्धयामास⟫ :br **⟪बन्धयां बभूव⟫** | **⟪बन्धयां चक्रुर्⟫** :br ⟪बन्धयामासुर्⟫ :br **⟪बन्धयां बभूवुर्⟫** | | |
