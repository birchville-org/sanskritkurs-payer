# Վարժություն 61

Դասը 61-ը Սանսկրիտի դասընթացի ավարտն է և չի պարունակում այլ գրավոր վարժություններ։

Ծագման բառերի, պերիֆրաստիկ ապագայի և դենոմինատիվների ուսումնասիրությամբ ստեղծվել են Սանսկրիտի բնօրինակ տեքստերը կարդալու հիմունքներ։ Դասընթացը ավարտվում է Սանսկրիտի դասական կոչով՝ ԳաՆեշային (⟪श्रीगणनाथ⟫), որը նշանակում է անցում դասագրքից դեպի ինքնուրույն կարդալը։
