# Դաս 3

## 3.1. Հոլովական եզակի չեզոք սեռ

### 3.1.1. Հոլովական եզակի -s վերջավորությամբ

Նաև հետևյալ անվանական արմատները, որոնք վերջանում են ձայնավորով, կազմում են հոլովական եզակի **-s** վերջավորությամբ.

::: grammar-box
**Չեզոք սեռի -i վերջավորությամբ**. Օր. **śruti** f. "լսելը" -- Հոլ. եզակի: **śrutis** = ⟪श्रुतिस्⟫
**Չեզոք սեռի -u վերջավորությամբ**. Օր. **dhenu** f. "կաթնատու կով" -- Հոլ. եզակի: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Հոլովական եզակի առանց վերջավորության

Հոլովական եզակին կազմվում է առանց վերջավորության.

::: grammar-box
**Չեզոք սեռի -ā վերջավորությամբ**. Օր. **devatā** f. "աստվածություն" -- Հոլ. եզակի: **devatā** = ⟪देवता⟫
**Չեզոք սեռի -ī վերջավորությամբ**. Օր. **devī** f. "աստվածուհի" -- Հոլ. եզակի: **devī** = ⟪देवी⟫
:::
::: important
**Ուշադրություն!** Կան նաև միահնչյուն չեզոք սեռի արմատական անվանումներ -ī վերջավորությամբ, որոնց հոլովական եզակին վերջանում է -s-ով. Օր. dhī f. "միտք" -- Հոլ. եզակի: dhīs = ⟪धीस्⟫։ Ինչպես նաև lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "նավակ" և tantrī (⟪तन्त्री⟫) f. "լար" անկանոն կերպով են կազմում հոլովական եզակին -s վերջավորությամբ. lakṣmīs = ⟪लक्ष्मीस्⟫։
:::

## 3.2. Չեզոք սեռի կազմումը տղամարդկային սեռից

::: grammar-box
**Տղամարդկային սեռի -a վերջավորությամբ.**
**Չեզոք սեռի -ā վերջավորությամբ**. Օր. **kṣatriya** m. » **kṣatriyā** f. "կշատրիայուհի" = ⟪क्षत्रिया⟫
**Չեզոք սեռի -ī վերջավորությամբ**. Օր. **brāhmaṇa** m. » **brāhmaṇī** f. "բրահմանուհի" = ⟪ब्राह्मणी⟫

**Տղամարդկային սեռի -u վերջավորությամբ.**
**Չեզոք սեռի -ī վերջավորությամբ**. Օր. **sādhu** m. » **sādhvī** f. (լավ, սուրբ) = ⟪साध्वी⟫
(**-u-** ձայնավորից առաջ դառնում է **-v-**, ուստի **-u- + -ī** » **-vī**)
:::

## 3.3. Հոլովական հոգնակի տղամարդկային և չեզոք սեռ

::: grammar-box
Հոլովական հոգնակի տղամարդկային և չեզոք սեռում վերջավորությունը **-as** է։
**Տղամարդկային սեռի -a վերջավորությամբ**. **deva- + -as** » **devās** = ⟪देवास्⟫
**Չեզոք սեռի -ā վերջավորությամբ**. **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**Տղամարդկային սեռի -i վերջավորությամբ**. **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**Չեզոք սեռի -i վերջավորությամբ**. **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**Չեզոք սեռի -ī վերջավորությամբ**. **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**Տղամարդկային սեռի -u վերջավորությամբ**. **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**Չեզոք սեռի -u վերջավորությամբ**. **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Նշում. **e**-ն բարձրացված աստիճան է (**guṇa**) **i**-ին, **o**-ն բարձրացված աստիճան է **u**-ին:


## 3.4. Վոկալական սանդհի

::: grammar-box
**Պարզ վոկալներ, որոնք տարբերվում են միայն երկարությամբ կամ ընդհանրապես, «միաձուլվում» են համապատասխան երկար վոկալի.**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**))
:::
օրինակ

devatā + annapūrṇā » devatānnapūrṇā «Աննապուռնան աստվածություն է» = ⟪देवतान्नपूर्णा⟫

> (Աննապուռնան սնունդների և խոհարարության աստվածուհին է, նա համարվում է Պարվատիի՝ Շիվայի կնոջ, մարմնավորումը:)

devī + indrāṇī » devīndrāṇī «ԻնդրաՆին աստվածուհի է» = ⟪देवीन्द्राणी⟫

> (ԻնդրաՆին աստված Ինդրայի կինն է:)

![](/images/lekt0301.webp)

(Նկարի աղբյուր. [Մանրամասներ](/hy/licenses#lekt0301))
:::

::: grammar-box
**Պարզ վոկալները (բացի -a / -ā-ից) աննման վոկալների առջև փոխարինվում են համապատասխան կիսաձայնով.**
i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**
(!! Այս կանոնի համար, մասնավորապես երկական ձևերի համար, կան բացառություններ !!)
:::
օրինակ

devī + umā » devy umā «Ուման աստվածուհի է» = ⟪देव्युमा⟫

> (Ուման Պարվատիի, Շիվայի կնոջ անուններից մեկն է:)

::: grammar-box
**-a / -ā աննման վոկալի առջև.**
a / -ā + i- / ī- » **-e-**
a / -ā + ṛ- » **-ar-**
a / -ā + e- / ai- » **-ai-**
a / -ā + o- / au- » **-au-**
:::
Այս սանդհիի համար, այսպիսով, գործում է հետևյալ սխեման.

օր․ն․

śūdrā + itarā » śudretarā «Իտարան Շուդրա կին է» = ⟪शूद्रेतरा⟫


## 3.5. Նախադասության սանդհի -ās-ի համար

::: grammar-box
**-ās-ը բոլոր ձայնեղ հնչյունների առջև փոխարինվում է -ā-ով։**
:::
օր․ն․

dvijās + vaiśyāḥ » dvijā vaiśyāḥ «Վայշյաները երկվածներ են» = ⟪द्विजा वैश्याः⟫


## 3.6. Բառարան

**Սովորեք հետևյալ բառերը։**

**śruti** f. = ⟪श्रुति⟫ : լսողություն, հավերժական փոխանցում (վեդաների և բրահմաՆային գրքերի անվանումը)։

**smṛti** f. = ⟪स्मृति⟫ : հիշողություն, մեդիտատիվ հիշողություն = ուշադրություն, փոխանցում (**śruti**-ի հակադիր հասկացություն)։ Ներառում է՝
վեդանգների յոթը **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫)՝ ճիշտ արտասանություն
2. **chandas** n. (⟪छन्दस्⟫)՝ չափ
3. **vyākaraṇa** n. (⟪व्याकरण⟫)՝ քերականություն
4. **nirukta** n. (⟪निरुक्त⟫)՝ բառի բացատրություն, էտիմոլոգիա
5. **jyotiṣa** n. (⟪ज्योतिष⟫)՝ աստղագիտություն, տոմարաբանություն
6. **kalpa** m. (⟪कल्प⟫)՝ արարողություն
**śrautasūtra** n. (⟪श्रौतसूत्र⟫)՝ դասագրքեր մեծ զոհաբերությունների կատարման համար
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫)՝ դասագրքեր ամենօրյա կյանքի արարողությունների և զոհաբերությունների համար
**dharmasūtra** n. (⟪धर्मसूत्र⟫) և **dharmaśāstra** n. (⟪धर्मशास्त्र⟫)՝ իրավունքի և սովորույթների դասագրքեր (ճիշտ վարք)
մեծ էպոսները՝ **mahābhārata** n. (⟪महाभारत⟫) և **rāmāyaṇa** n. (⟪रामायण⟫)
**purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫)՝ կյանքի խելացնորության դասագրքեր

**smṛti**-ն հատկապես նաև դարմայի դասագրքերի անվանումն է։

**dhenu** f. = ⟪धेनु⟫ : (կաթն) խոշոր եղջերավոր անասուն։

**paśu** m. = ⟪पशु⟫ : ձեռքի տակ առնված օգտակար կենդանի, խոշոր եղջերավոր անասուն (համախումբ)։

**devatā** f. = ⟪देवता⟫ : աստվածություն (աբստրակտ և կոնկրետ)։

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : բրահմանուհի։

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : կշատրիյուհի։

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : կշատրիյայի կին։

**vaiśyā** f. = ⟪वैश्या⟫ : վայշյուհի։

**śūdrā** f. = ⟪शूद्रा⟫ : շուդրա։

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : շուդրայի կին։

**devī** f. = ⟪देवी⟫ : աստվածուհի, հատկապես Տուրգā f. = ⟪दुर्गा⟫, Շիվայի կինը = ⟪शिव⟫։

::: media
![](/images/lekt0303.webp)
Նկար.։ Տուրգā = ⟪दुर्गा⟫, Օռիսա
(Նկարի աղբյուր. [մանրամասներ](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : զուգահեռ է sādhu-ին։

**gurvī** f. = ⟪गुर्वी⟫ : զուգահեռ է guru-ին։

**asmitā** f. = ⟪अस्मिता⟫ : «ես-եմ-ություն», այսինքն՝ (սխալ) հավատը. **Ես** եմ, ով տեսնում է և այլն։

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : փիլիսոփայություն (գիտություն, որը իր եզրակացություններին է հասնում տրամաբանորեն ճիշտ արգելքներով)։

**upekṣā** f. = ⟪उपेक्षा⟫ : անտեսում, հավասարակշռություն։

**karuṇā** f. = ⟪करुणा⟫ : համակրանք, կարեկցանք։

**muditā** f. = ⟪मुदिता⟫ : ուրախություն, հատկապես գոհունակություն (զայրույթի հակադիրը)։


## 3.7. Վարժություն

**A) Արտահայտեք հետևյալ նախադասությունները շարականով.**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**Բ) Կազմեք գոյական նախադասություններ՝ տեղադրելով.**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**Գ) Փոխարկեք կինականի.**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫

**Դ) Թարգմանեք սանսկրիտ.**

1. Ուման աստվածուհի է։
2. Վեդան սրուտի է։
3. Աշակերտուհիները աստվածուհիներ են։
4. Կաթնատու խոշոր եղջերավորները տնային կենդանիներ են։
5. Բանաստեղծները ուսուցիչներ են։
6. Քշատրիյաները երկուսմածներ են։
7. Սուրբ տղամարդիկ շյուդրաներ են։
