# Դաս 54

## 54.1. Նախաբան

Դասընթացի 54-րդ դասով սկսվում է համալսարանական ուսուցման երկրորդ կիսամյակը։ Այժմ դասընթացը ընթանում է միայն այս կիսամյակի հիմնական թեմայի՝ Բհագավադգիտայի ամբողջական ընթերցման կողքին։ Ուսումնական նպատակը միջին բարդության տեքստեր կարդալու այնպիսի հմտություն է ձեռք բերելը, որ դասընթացի վերջին երրորդում հնարավոր լինի Բհագավադգիտայի մեծ հատվածները թարգմանել բռնկումից։ Դասընթացի սկզբին համալսարանում դեռ բաշխվում էին բառացուցակներ, հետո ուսանողները պետք է օգտագործեին համապատասխան բառարաններ (Մոնիեր-Ուիլյամս, Ապտե, PW)։

Բհագավադգիթայի դասընթացը ժամանակավորապես հասանելի չէ առցանց։

Սանսկրիտի դասընթացի դասերը քննարկում են սանսկրիտական քերակության թեմաներ, որոնք դեռևս քննարկված չեն։

## 54.3. Մետրիկա II։ էպիկական ⟪त्रिष्टुभ्⟫ և ⟪जगती⟫

::: grammar-box
⟪त्रिष्टुभ्⟫ ("երեք շնչառություն") էպիկական պոեզիայում հայտնվում է սովորական ⟪श्लोक⟫-հատվածների միջև, հենց այն տեղերում, որտեղ իրադարձությունները կամ գործողությունը հատուկ բարձրացում են ապրում կամ ավարտվում։

Ընդհանուր առմամբ, ⟪त्रिष्टुभ्⟫-տողը բաղկացած է չորս տասնմեկ-հանգավոր ⟪पाद⟫-ից, որոնք կառուցվածքով չեն տարբերվում միմյանցից։

⟪त्रिष्टुभ्⟫-ն ունի երկու հիմնական սխեմա՝ կախված նրանից, թե արդյոք կեսատողը (բառի վերջ, կազմակերպչական սահման կամ որոշակի վերջավորություններից առաջ, ինչպիսիք են -tara, -tama և այլն) գտնվում է ⟪पाद⟫-ի չորրորդ, թե հինգերորդ հանգից հետո։

## 54.5. Типы образования аориста (⟪लुङ्⟫)

::: grammar-box
**Общим для всех типов образования аориста (⟪लुङ्⟫) является авгумент a-, который ставится перед корнем по тем же правилам, что и в имперфекте (⟪लङ्⟫).**

В санскрите от аориста используются только изъявительное наклонение (индикатив) и желательное (прекатив).
:::
::: grammar-box
**Существуют следующие типы образования аориста (⟪लुङ्⟫):**

1. Несибилантные (асигматические) аористы: 
*   54.1. Корневой аорист: Авгумент + корень + вторичное окончание
*   54.2. Тематический аорист: Авгумент + корень + **a** + вторичное окончание
*   54.3. Редуплицированный аорист: Авгумент + **редуплицированный** корень + **a** + вторичное окончание 
2. Сибилантные (сигматические) аористы: s или слог, содержащий s (ṣ), стоит перед личным окончанием 
*   54.4. -s-аорист: Авгумент + корень + **s** \+ вторичное окончание
*   54.5. -iṣ-аорист: Авгумент + корень + **i** + **ṣ** + вторичное окончание
*   54.6. -siṣ-аорист: Авгумент + корень + **siṣ** + вторичное окончание
*   54.7. -sa-аорист: Авгумент + корень + **s** + **a** + вторичное окончание

Բաշխումը արմատների միջև առանձին ձևավորման տեսակների միջև տե՛ս առանձին տեսակներում
:::
