## 41.2. Այլ ⟪कृत्⟫-կազմություններ -a վերջավորությամբ

### 41.2.1. Ներկա դարձական (⟪लडादेशः⟫) Ā, Ներկա դարձական (⟪लडादेशः⟫) Ուղղակի, Ապագա դարձական (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Թեմատիկ ներկա թվանուններ, Ուղղակի և Ապագա

::: grammar-box
**Կազմություն.**

Ներկա թվանուն / Ուղղակի թվանուն / Ապագա թվանուն + -māna (հոգն. mānā)
:::
Օրինակներ.

⟪यज्⟫ 1U, Ներկա դարձ.Ā ⟪यजमान⟫ 3 «մեկը, ով զոհաբերության միջոցով պատվում է իր սեփական շահի համար = զոհաբերության տիրակալ»

⟪मन्⟫ 4Ā, Ներկա դարձ.Ā ⟪मन्यमान⟫ 3 «մտածող»

⟪कृ⟫ 8U, Ներկա դարձ.Ուղղակի ⟪क्रियमाण⟫ 3 «ինչ-որ բան, որ կատարվում է»

⟪दा⟫ 3U, Ապագա դարձ.Ā ⟪दास्यमान⟫ 3 «մեկը, ով կտա իր սեփական շահի համար»

#### 41.2.1.2. Աթեմատիկ ներկա դասեր

::: grammar-box
**Կազմություն.**

Թույլ ներկա թվանուն (նրա այն ձևով, որը նա ունի 3.հոգն.Ā -ate վերջավորությունից առաջ) + -āna (հոգն. -ānā)
:::
Օրինակներ.

::: grammar-box
| Արմատ / Դաս | Ներկա դարձական Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. «Մասնակի» պարտականության անցյալ կամ ապագայի իմաստով (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Պարտականության անցյալ կամ ապագայի իմաստը («ինչ պետք է արվի/պետք է») արտահայտելու համար կարելի է ընտրությամբ ածանցներով ստեղծել բառեր արմատներից և ածանցված ձայնավորական հիմքերից՝**

* **-⟪तव्य⟫** (հոգ. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (հոգ. **-⟪अनीया⟫**)
* **-⟪य⟫** (հոգ. **-⟪या⟫**)
* **-⟪त्य⟫** (հոգ. **-⟪त्या⟫**) (-⟪य⟫**-/ -⟪या⟫** փոխարեն)
:::
#### 41.2.2.1. -⟪तव्य⟫ / -⟪तव्या⟫ ածանցը

::: grammar-box
**-⟪तव्य⟫ / -⟪तव्या⟫ ածանցը ավելացվում է նույն ձևով, ինչպես անվանական ածանցը -⟪तुम्⟫ (տես [Դաս 23](lektion23.md)), այսինքն՝**

* **բարձրաստիճան արմատ + ⟪तव्य⟫**

կամ

* **բարձրաստիճան արմատ + -i- + ⟪तव्य⟫**

**Պատճառականում.**

* **-ay** վերջավորությամբ պատճառական հիմք + -i- + ⟪तव्य⟫
:::
Օրինակներ.

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟩ 1P | ⟪जेतव्य⟩ 3 | «պարտադիր հաղթվող; հաղթելու ենթակա» |
| ⟪वृत्⟩ 1Ā | ⟪वर्तितव्य⟩ 3 | «որտեղ պետք է գտնվել» |
| ⟪बुध्⟩ Պատ. | ⟪बोधयितव्य⟩ | «պարտադիր զգուշացվող; զգուշացնելու ենթակա» |

:::
#### 41.2.2.2. -⟪अनीय⟩ / -⟪अनीया⟩ ածանցը

::: grammar-box
**Ստեղծում.**

Բարձրաստիճան արմատ + -⟪अनीय⟩ / -⟪अनीया⟩

**Պատճառական և 10-րդ ներկայի դաս.**

Արմատ, ինչպես այն հայտնվում է պատճառական հիմքում, առանց -aya- + -⟪अनीय⟩ / -⟪अनीया⟩
:::
Օրինակներ.

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟩ 3U | ⟪दानीय⟩ 3 | «տալու ենթակա; պարտադիր տրվող» |
| ⟪जि⟩ 1P | ⟪जयनीय⟩ 3 | «հաղթվող» |
| ⟪कृ⟩ 8U | ⟪करणीय⟩ 3 | «անելու ենթակա» |
| ⟪दृश्⟩ | ⟪दर्शनीय⟩ 3 | «տեսնելու ենթակա; տեսանելի» |
| ⟪बुध्⟩ Պատ. | ⟪बोधनीय⟩ 3:brbodh-aya - aya + -anīya | «զգուշացնելու ենթակա» |
| ⟪दा⟩ Պատ. | ⟪दापनीय⟩ 3:brdā-paya - aya + -anīya | «տալու ենթակա» |

:::
#### 41.2.2.3. Հավելվածը -⟪य⟫ / -⟪या⟫

::: grammar-box
**Կազմություն.**

Արմատ (խոր, բարձր կամ երկարացված աստիճանով) + -⟪य⟫

Տես՝ Կիելհորն, Sanskrit-ի քերականություն էջ. 195 - 197:
:::
Վերջնական վանկերի մշակում.

::: grammar-box
**1. -ā վերջավորությամբ արմատները կազմում են այս գերունդիվը -eya վերջավորությամբ**
:::
Օրինակներ.

::: no-header

| | |

| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "տալու; պետք է տրվի" |

:::

#### 41.2.2.4. -⟪त्य⟫ / ⟪त्या⟫ վերջավորությունը (-⟪य⟫ / -⟪या⟫-ի փոխարեն)

### 41.2.3. Սինտակսիկական տեղեկություններ «անհրաժեշտության արտասահմանյան» (Gerundivum) մասնակիցների համար (⟪कृत्य⟫)

::: grammar-box
Gerundiv-ը կարող է օգտագործվել որպես ածական.

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = «քաղաք, որը պետք է տեսնել; արժե տեսնելու քաղաք»
:::
Gerundiv-ը կարող է նաև օգտագործվել որպես պրեդիկատային անուն նախադասություններում, որոնք արտահայտում են պարտավորություն կամ հրաման (⟪न⟫-ով՝ արգելք, անհնարինություն).

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = «Երկու անգամ ծնվածները պետք է տեսնեն Բենարեսը»
:::

### 41.2.4. Տարբերություններ Gerundiv-ի վանկակցումների օգտագործման մեջ

::: grammar-box
Այս վանկակցումների օգտագործումը լայնորեն համընկնում է

* **-⟪तव्य⟫ (մ. -⟪तव्या⟫):** միշտ արտահայտում է անհրաժեշտություն և նախընտրելի է օգտագործվում որպես պրեդիկատ (հազվադեպ՝ որպես ածական): Այս վանկակցումով կազմված բառերը չպետք է օգտագործվեն գոյական համադրություններում:
* **-⟪अनीय⟫ (մ. -⟪अनीया⟫) և -⟪य⟫ (մ. -⟪या⟫) / -⟪त्य⟫ (մ. -⟪त्या⟫) (-⟪य⟫/-⟪या⟫-ի փոխարեն):** կարող են ունենալ լրացուցիչ իմաստ (հատկապես -⟪य⟫) գերմանական «-արժե» (օրինակ՝ «տեսնելու արժանի») կամ միայն հնարավորություն «-ելի» (⟪दृश्य⟫ «տեսանելի») իմաստով: Այս վանկակցումներով կազմված բառերը կարող են ժխտվել ⟪अ⟫-/-⟪अन्⟫-ով (բայց ոչ -⟪तव्य⟫-ով կազմվածները), և գոյություն ունեն ⟪तत्पुरुष⟫, որոնք հանդես են գալիս որպես դրանց ետին մաս:
