# Դաս 29

## 29.1. Պարաշմայիպադայի (⟪परस्मैपद⟫) և Ātmanepada-ի (⟪आत्मनेपद⟫) կիրառումը հեղինակային ձևերում


::: grammar-box
**Հեղինակային ձևերը, քիչ բացառություններով, երկակի են (⟪उभयपद⟫)**
:::
::: grammar-box
**Հեղինակային ձևերում կիրառվում է Ātmanepada-ն (⟪आत्मनेपद⟫):**

**1. Երբ խթանված գործողության հետևանքը օգտակար է խթանողին.**
:::
Օրինակ.

⟪रामः कटं कारयते⟫ = «Ռաման իր համար (սեփական շահից ելնելով) գորգ է պատվիրում»

**2. Երբ հեղինակային ձևերը կիրառվում են անցողական բայերի հետ «ինքն իրեն ցույց տալ», «ինքն իրեն լսելի դարձնել» և այլն. կամ երբ պարզ բայի առարկան հեղինակային ձևի գործող է (⟪कर्तृ⟫).**

Օրինակ.

⟪विष्णुर्भक्तान्दर्शयते⟫ = «Վիշնուն իրեն ցույց է տալիս իր հավատացյալներին»

Արդյունք. ⟪भक्ता विष्णुं पश्यन्ति⟫ = «Հավատացյալները տեսնում են Վիշնուին»


Այսպիսով, կանոները ընդհանուր առմամբ համապատասխանում են Ātmanepada-ի (⟪आत्मनेपद⟫) կիրառման կանոններին երկակի (⟪उभयपद⟫) բայերի դեպքում։

## 29.3. Կրկնության թարգմանական վարժություն
