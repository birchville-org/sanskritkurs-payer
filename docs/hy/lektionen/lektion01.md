>«Երբ Ուիլյամ Ջոնսը [1746–1794] և Հենրի Տոմաս Կոլբրուկը (1765–1857) առաջին անգամ հիմնավոր ուսումնասիրեցին սանսկրիտը, մասամբ թարգմանեցին և հայտնաբերեցին, որ այն ունի հարուստ գրականություն և զգալի նմանություն դասական լեզուների հետ, նրանք բախվեցին ոչ փոքր դիմադրության։ Քանի որ սանսկրիտի այս ներքին կապը եվրոպական, աշխարհագրորեն այնքան հեռու գտնվող լեզուների հետ, չէր կարող համադրվել հին պատկերացումների հետ, որոնք կամ բոլոր լեզուները ստացված էին հրեաերեսից, կամ մասնակիորեն առանձին էին գտնվում, հայտնի փիլոսոֆ Տուգալդ Ստյուարդը (1753–1828) օգտագործեց պարզագույն ճանապարհը՝ հայտարարելով սանսկրիտ լեզվի ամբողջ պատմությունը կեղծիք։ Նա գրեց էսսե, որտեղ փորձում էր ապացուցել, որ այն ստեղծված է բրահմանների կողմից հունարենի և լատինականի նմանությամբ, և որպեսզի լեզուն և գրականությունը կեղծված լինեն։ Այս տեսակետն ավելի մանրամասն զարգացրեց դուբլինյան պրոֆեսոր Չարլզ Ուիլյամ Վալը 1840 թվականին (Գետինգենյան գիտական հայտարարություններ 1842 թ. էջ 1888)։»
>

## 1.2. Սանսկրիտի հնչյունները

Սանսկրիտի հնչյունները՝ ըստ ավանդական հնդկական դասակարգման և գիտական տառադարձության:

::: media
![](/images/lekt0106.webp)
(Նկարի աղբյուրը. [Մանրամասներ](/hy/licenses#lekt0106))
:::
Ժամանակակից սանսկրիտ բառարանները դասավորված են այդ դասակարգման հաջորդականությամբ: Այս դասակարգումը անհրաժեշտ է սանսկրիտ քերականությունը հասկանալու համար, ուստի այն պետք է իմանալ հիշողությամբ.

### 1.2.1. Մասին առանձին հնչյունների արտաբերությունը

::: laut-table
| Հնչյուն | Նկարագրություն |
| :--- | :--- |
| **a - ⟪अ⟫** | «կարճ a»-ն հնդիկների կողմից -- անհիշելի ժամանակներից ի վեր -- հաճախ արտաբերվում է ə-ի նման։ Եվրոպայում այն արտաբերվում է որպես կարճ a, իսկ Բենգալիայում՝ որպես կարճ մութ o։ |
| **ṛ - ⟪ऋ⟫** | ինչպես չեխական վոկալիզացված r-ը։ i-ի թույլ հնչունային արձագանք։ |
| **ṝ - ⟪ॠ⟫** | ինչպես չեխական վոկալիզացված r-ը։ u-ի թույլ հնչունային արձագանք։ |
| **jñ - ⟪ज्ञ्⟫** | նաև ինչպես dny (մարատհի) կամ gy (Հյուսիսային Հնդկաստան)։ |
| **ś - ⟪श्⟫** | sch հնչյուն՝ ներքև ծռված լեզվի գագաթով։ Նման է «mischen» բառի sch-ին։ |
| **ṣ - ⟪ष्⟫** | ach հնչյուն՝ հետ ծռված լեզվի գագաթով։ Հաճախ այնքան հետ է արտաբերվում կոկորդի խորքում, որ գրեթե kh-ի նման է հնչում։ |
| **h - ⟪ह्⟫** | շնչային հնչյուն, երբեք ոչ երկարացման նշան։ |
| **ḥ - :** | **Վիսարգա (Visarjanīya)** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫։ Անձայն շնչային հնչյուն՝ նախորդ վանկի կամ դիֆթոնգի երկրորդ մասի հնչունային արձագանքով։ agniḥ -- ⟪अग्निः⟫ = agnih, devaiḥ -- ⟪देवैः⟫ = devaih, gauḥ -- ⟪गौः⟫ = gauh |
| **ṃ** | **Անուսվարա** -- ⟪अनुस्वर⟫։ Շիլ հնչյունների, h-ի և l-ի դեպքում՝ վանկի նազալացում։ Բառավերջում = m-ը։ Բառի ներսում՝ բաղաձայններից առաջ։ համապատասխան բաղաձայնին համապատասխան նազալ։ saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
Լավագույն արտաբերությունը հասանելի է, եթե նախադասությունները, տողերը կամ բառերը ընթեռնում եք բավականին դանդաղ և մոնոտոն՝ խիստ հետևելով վանկերի երկարությանը։


## 1.3. Վարժություն

**Ա) Ընթեռնեք հետևյալ բառերը.**

2. brahmā viṣṇu śiva — ⟪ब्रह्मा विष्णु शिव⟫
