# Դաս 50

## 50.1. Ածականների կազմումը։ Սովորական աստիճանավորում

::: grammar-box
**Սովորական աստիճանավորումը սանսկրիտում կատարվում է ⟪तद्धित⟫ վերջավորություններով**
* **-⟪तर⟫ (հոգն.՝ ⟪तरा⟫) «համեմատական աստիճանում»**
* **⟪तम⟫ (հոգն.՝ ⟪तमा⟫) «գերադասական աստիճանում»**

**Այս վերջավորությունները կցվում են ածականների զուգահեռ հոդով։ Բազմաստիճան բառերի դեպքում դրանք կցվում են թույլ արմատին, որն ունի նույն ձևը, ինչ արտահայտությունից առաջ -su տեղական հոլովի (⟪पञ्चमी⟫) հոգնակի ձևը։**
:::
::: media
![](/images/lekt5007.webp)
Նկ. ⟪लोकस्योत्तमो गिरिः सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = Մաունտ Էվերեստ
(Նկարի աղբյուրը՝ [Մանրամասներ](/hy/licenses#lekt5007))
:::

::: grammar-box
**Իմաստը։**

**«Համեմատական աստիճանը» նշանակում է, եթե համեմատության առարկա չի արտահայտվում. «բավականին, շատ, չափազանց»։**

:::
::: indent
օր. ⟪सुचितर⟫ 3 «բավականին մաքուր», «շատ մաքուր», «չափազանց մաքուր»
:::
**Եթե համեմատության առարկա է արտահայտվում, այն գտնվում է աբլատիվում (⟪पञ्चमी⟫)։ Համեմատական աստիճան + աբլատիվ համապատասխանում է գերմաներեն «ինչպես» աստիճանավորմանը։**

::: indent
օր. ⟪देवदत्ताद्रामो धीमत्तरः⟫ = բառացի՝ «Դևադատայից նայելիս Ռաման ավելի հասկացող է» = «Ռաման ավելի հասկացող է, քան Դևադատան»
:::
**«Գերադասական աստիճանը» նշանակում է, եթե համեմատության առարկա չի արտահայտվում. «ամենաբարձր, շատ»։**

::: indent
օր. ⟪सत्तम⟫ 3 (կապված ⟪सन्त्⟫-ի հետ) «ամենալավ, շատ լավ»
:::
**Եթե համեմատության առարկա է արտահայտվում, այն գտնվում է ջենիտիվում (⟪षष्ठी⟫) («կողմից», «շրջանակում») և գերադասական աստիճանը համապատասխանում է գերմաներենի գերադասական աստիճանին (բարձրագույն աստիճան)։**

::: indent
օր. ⟪द्विजानां सत्तमः⟫ = «երկու անգամ ծնվածներից լավագույնը»
:::
**Կետադիրները՝ -⟪तर⟫ և -⟪तम⟫, կարող են ոչ միայն հատկանշականների, այլև գոյականների, անփոփոխելի բառերի և նույնիսկ դերբայների հետ կիրառվել.**

Օրինակներ.

::: indent
⟪गजतम⟫ հոգն. «լավագույն փիղ» (⟪गज⟫) (նաև Բուդդայի կոչումը)

⟪गोतम⟫ հոգն. «ամենամեծ ցուլ» (⟪गो⟫) կամ. «անասուններով ամենահարուստը»

⟪उद्⟫ Անփոփ. «վրա», «դեպի վեր» » ⟪उत्तर⟫ 3 «ավելի բարձր» » ⟪उत्तम⟫ 3 «ամենաբարձրը»
:::
**Եթե այս կետադիրները դերբային ձևի հետ են կիրառվում, ապա դրանք միշտ հայտնվում են իմաստաբանական (adverbial) ձևով.**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

Օրինակներ.

::: indent
⟪पचतितराम्⟫ «նա/իշխանուհին/այն ավելի լավ է եփում»

⟪पचतितमाम्⟫ «նա/իշխանուհին/այն ամենալավն է եփում»
:::
**Այս ձևը այդ կետադիրներն ունեն նաև, երբ դրանք կիրառվում են անփոփոխելի բառերի հետ, և ստացված բառը իմաստաբանական (adverbial) կերպով է օգտագործվում.**

::: indent
օր. ⟪सुतराम्⟫ (⟪सु⟫-ից) «ավելի լավ կերպով» (իրականացվում է որպես իմաստաբանական)
