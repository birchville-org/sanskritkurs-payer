# Դաս 26

## 26.1. Միջբառային -s-ի համար սրտանմանացման օրենք

::: grammar-box
**-s-** -ը փոխարինվում է **-ṣ-**ով, եթե **k, r, l** կամ **վանկարկող** — բացի **a, ā**-ից — անմիջապես կամ միայն ⟪अनुस्वार⟫ կամ ⟪विसर्ग⟫-ով բաժանված նախորդում է, և հետևում է այլ ձայնավոր, բացի **ṛ, r**-ից։

Այս սանդհին նաև հետևում է **⟪दुस्⟫-**ին՝ անհնչյուն գուտուրալների և լաբիալների դեպքում կոմպոզիտներում։
:::
*Օրինակներ:*
::: indent
⟪तेषाम्⟫ (*te-sām*-ից)

բայց՝ ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. Միջբառային դենտալների համար սրտանմանացման օրենք

::: grammar-box
Դենտալ պայթական ձայնարկները հետևում են ռետրոֆլեքսներին (ներառյալ **-ṣ-**ը) համապատասխան ռետրոֆլեքսներով փոխարինվում են։

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ**-ը նախորդող **i**-ի պատճառով, **ṭh**-ը հետևող **ṣ**-ի պատճառով)*
:::
## 26.3. Պալատալ, գուտուրալ, ṣ, h + -s-ի համար բառային սանդհի

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

Օրինակները տեսեք ներքևում
:::
## 26.4. Գրասմանի շնչադիսսիլյացիայի օրենք

::: grammar-box
**Երկու ասպիրատների (ասպիրատ - ձայնավոր - ասպիրատ) անմիջական հաջորդությունը հանգեցնում է առաջին ձայնի ասպիրացիայի կորստի։**

Օրինակ՝

:::
::: indent
\*dhu(gh) » du(g)h
:::
**Եթե ձայնական օրենքների հետևանքով երկրորդ ձայնը կորցնում է ասպիրացիան, ապա ասպիրացիան նորից հայտնվում է առաջին ձայնի դեպքում։**

## 26.6. Պարզ ապառնիի կիրառությունը (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**Պարզ ապառնին (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) արտահայտում է.**

- **ապագան**
- **մտադրված կամ ցանկալի գործողություն («ես կգնամ», «ես ցանկանում եմ գնալ»)**
- **սպասում («այդպես կլինի»)**
- **հույս**
- **երկյուղ, մտավախություն**
- **հավանականություն**
- **խոսողի կարծիք**
- **հրաման**

**Ապառնին մասամբ մրցակցում է ըղձականի հետ (տես հետագայում):**
:::
օրինակ՝ ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = «Ուխտ անել ցանկացողը գնում է տաճար:»

## 26.7. Պարզ ապառնիի կազմությունը (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**Պարզ ապառնի.**

:::
::: indent
**Ապառնիի հիմք + առաջնային վերջավորություն**
:::
::: grammar-box
**Ապառնիի հիմք.**

:::
::: indent
**(սովորաբար) բարձր աստիճանի արմատ + -sya**  
**կամ**  
**(սովորաբար) բարձր աստիճանի արմատ + -i- + -sya (= - iṣya)**
:::
**Թե որ արմատը ապառնիի հիմքի ինչպիսի կազմություն ունի, պետք է սովորել հիմնական ձևերի հետ:**  
**Ընդհանուր առմամբ արմատի ձևը և կապող ձայնավորը համընկնում են անորոշ դերբայի հետ:**  
**Որոշ արմատներ կարող են ապառնին կազմել ըստ ցանկության՝ կապող -i- ձայնավորով կամ առանց դրա:**  
**Ապառնիի Parasmaipada-ի ընդունելությունը կազմվում է ապառնիի հիմքին -nt- ածանց ավելացնելով, իգականը՝ ըստ ցանկության -ntī կամ -tī:**

⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
