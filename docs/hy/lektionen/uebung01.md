# Վարժություն 1

Դասը 1-ը գրավոր վարժություններ չի պարունակում, քանի որ այն նախատեսված է որպես ձայներեղանակի և արտասանության ներածություն։ Դասի վերջում տրվող ընթեռնության վարժությունները նպատակ ունեն ձայների գործնական վարժեցումը և չեն պահանջում առանձին պատասխանների բանալի։
