### 18.2.2. nañ-Tatpuruṣa-ի իմաստները (a- / an-)

Tatpuruṣa a- / an- նախածանցով կարող են ունենալ հետևյալ իմաստները.

1. Նմանություն (⟪तत्सादृश्यम्⟫):  
⟪अब्राह्मणः⟫ = Քշատրիյա կամ Վայśya, ով կրում է սուրբ թելը (⟪यज्ञोपवीत⟫ n.), և հետևաբար նման է բրահմանի, առանց դա լինելու
2. Բացակայություն, ոչ առկայություն (⟪तदभावः⟫):  
⟪अज्ञानम्⟫ = անգիտություն (գիտելիքի բացակայություն)
3. Այլասերում (⟪तदन्यत्वम्⟫):  
⟪अपटम्⟫ = այն, ինչը նյութ / հագուստ (⟪पट⟫ m: կեղև, հագուստ) չէ
4. Փոքրություն (⟪तदल्पता⟫):  
⟪अनुदरम्⟫ = փոքր որովայն (ոչ-որովայն)
5. Որակազերծում (⟪अप्राशास्त्यम्⟫):  
⟪अकालः⟫ = ոչ ժամանակին
6. Թշնամություն (⟪निरोधः⟫):  
⟪असुरः⟫ = հակաստվեր (սխալ etymol-ից a-sura)

## 18.3. Քերականական կոմպոզիտներ

::: indent
⟪उपसर्गेण धात्वर्थो बलादन्यत्र नीयते । गङ्गासलिलमाधुर्यं सागरेण यथाम्भसा ॥⟫
:::
⟪चन्द्रकीर्ति⟫ : ⟪प्रसन्नपदा⟫ էջ 2 տող 14f.

::: grammar-box

Սանսկրիտում բայերը կարող են նախդիրներով (⟪उपसर्ग⟫ m.) կապվել։ Սովորաբար գործում է սատասանդհին։ Նախդիրները կարող են արմատի իմաստը մեծապես փոխել, այնպես որ շատ դեպքերում նախդիրով արմատի իմաստը առանձին սովորելու կարիք ունեն։ Նախդիրով բայերը կարող են այլ մոդուս (P, Ā) ունենալ, քան պարզ արմատը։ Արմատի առջև միաժամանակ կարող են բազմաթիվ նախդիրներ դրվել։

:::
