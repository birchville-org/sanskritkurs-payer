# Դաս 15

## 15.1. ⟪सुभाषितम् गुरुशुश्रूषया विद्या पुष्कलेन धनेन वा । अथवा विद्यया विद्या चतुर्थी नैव विद्यते ॥⟫

## 15.2. Որոշիչ կազմական բարդություններ = Թատպուռուշա հոգ. = ⟪तत्पुरुष⟫

Բառերի (եզակի և ածականներ) միջև հարաբերությունը կարելի է արտահայտել ոչ միայն սեռական հոլովման կառուցվածքով, այլև Թատպուռուշա (⟪तत्पुरुष⟫) բարդությամբ։ Նույնպես կարելի է ատրիբուտիվ զուգակցումները ածականների կամ ատրիբուտիվ զուգակցումները եզակիների միջոցով արտահայտել որոշակի տեսակի Թատպուռուշա բարդությամբ, այսինքն՝ կարմադհարայա (հոգ.) = ⟪कर्मधारय⟫։

⟪तत्पुरुषः⟫ =  ⟪तस्य पुरुषः⟫ "նրա ծառան", այսինքն՝ այդ տեսակի բարդությունների անվանման համար օգտագործվում է այդպիսի բարդությունների օրինակ։

::: grammar-box

Որոշիչ կազմական բարդություններում (Թատպուռուշա) մի եզակին կամ ածականը մեկ այլ եզակով կամ չափանիշով ավելի մոտ է որոշվում։ Ավելի մոտ որոշված բառը սովորաբար կազմում է բարդության հետևի մասը։

Նախնական (որոշող) մասի և հետին (որոշված) մասի հարաբերությունը կարող է լինել.

*   ատրիբուտիվ կամ ատրիբուտիվ. բարդության լուծման դեպքում նախնական մասը հետին մասի համար կազմում է ավելի մոտ որոշում նույն հոլովում (այսինքն՝ արտաքին կառուցվածքում նոմինատիվ (⟪प्रथमा⟫), խոսքում սինտակտիկորեն պահանջվող հոլովում)
*   կասուալ. նախնական մասը բարդության լուծման դեպքում գտնվում է այլ հոլովում, քան հետին մասը (այսինքն՝ ոչ նոմինատիվ - ⟪प्रथमा⟫)
*   ադվերբիալ. նախնական մասը անհոլով բառ է

Կազմական հարաբերությունը կոմպոզիտում երկու անդամների միջև կախված չէ նրանից, թե որ դերբայով է կոմպոզիտը. քանի որ կոմպոզիտը մեկ ընդհանուր բառ է.

օրինակ՝

> Նոմ. սկզբ. ⟪तत्पुरुषः⟫ = ⟪तस्य पुरुषः⟫  
> Ակկ. սկզբ. ⟪तत्पुरुषम्⟫ = ⟪तस्य पुरुषम्⟫  
> Ինստ. սկզբ. ⟪तत्पुरुषेण⟫ = ⟪तस्य पुरुषेण⟫  
> Գեն. սկզբ. ⟪तत्पुरुषस्य⟫ = ⟪तस्य पुरुषस्य⟫  
> Նոմ. համ. ⟪तत्पुरुषाः⟫ = ⟪तस्य पुरुषाः⟫  
> և այլն։

Տատպուրուշայի սեռը՝ քչացած բացառություններով, համարվում է նրա հետևանքի սեռը։

:::

## 15.3. Որոշիչ կոմպոզիտներ՝ ածական / հավասարակշռված նախնի = Կարմադհարայա հ. = ⟪कर्मधारय⟫

::: grammar-box

Կարմադհարայայի լուծումը կոմպոզիտում երկու անդամները մնում են նույն դերբայով։

:::

օրինակ՝

⟪गुणवत्पुत्रः⟫ = ⟪गुणवान्पुत्रः⟫ = "մի որդի, ունենալով լավ հատկանիշներ"  
Ակկ. սկզբ. ⟪गुणवत्पुत्रम्⟫  
Նոմ. համ. ⟪गुणवत्पुत्राः पुण्यवत्क्षत्रिया⟫ = ⟪पुण्यवती क्षत्रिया⟫ = "մի արժանավոր կսատրիա կին"  

⟪साधुजनाः⟫ = ⟪साधवो जनाः⟫ = "լավ մարդիկ"  

⟪इष्टदेवता⟫ = ⟪इष्टा देवता⟫ = "ցանկալի աստվածություն = այն աստվածություն, որին մարդը ունի հատուկ սիրո և ապաստանի կապ"

::: media

![](/images/lekt1501.webp)

Նկար. ⟪लक्ष्मी⟫
(Նկարի աղբյուրը. [Մանրամասներ](/hy/licenses#lekt1501))

:::

::: grammar-box

Կարմադհարայի մեջ անդամների հաջորդականության հետ կապված հետևյալ հատուկ կանոնը պետք է նկատի ունենալ.

*   եթե Կարմադհարայը համեմատություն է արտահայտում, ապա այն, ինչի հետ համեմատվում է, գտնվում է կոմպոզիտի հետևանքում.

⟪नरसिंहः⟫ = ⟪सिंह इव नरः⟫ = "մի մարդ, ինչպես առյուծ"  
⟪पुरुषव्याघ्रः⟫ = ⟪व्याघ्र इव पुरुषः⟫ = "մի մարդ, ինչպես վագր"

*   Եթե Կարմադհարայը, սակայն, արտահայտում է բացատրություն (հետևի անդամի ավելի հստակ որոշում գոյականով), ապա որոշող անդամը կանգնում է առաջին դիրքում, ինչպես պահանջում է նաև Տատպուրուշայի ընդհանուր կանոնը.

⟪नरसिंहः⟫ կարող է նաև վերլուծվել՝ ⟪नर एव सिंहः⟫ = «Առյուծ, որը (իրականում) մարդ է:»

Նման բացատրական Կարմադհարայները բնիկ մեկնաբանություններում, ինչպես վերևի օրինակում, լուծվում են ⟪एव⟫-ի միջոցով:

:::

![](/images/lekt1503.webp)

Պատկեր՝ ⟪नरसिंहः⟫

## 15.4. Որոշիչ կոմպոզիտներ առաջին անդամով, որը հետևի անդամի հետ ոչ ատրիբուտիվ/բացատրական հոլովային կապի մեջ է = Տատպուրուշա նեղ իմաստով

::: grammar-box

Տատպուրուշա կոմպոզիտները հնարավոր են անունների (գոյականների և ածականների) միացությունների համար, որոնցում առաջին անդամը՝ ըստ շարահյուսության կանոնների, կարող է լինել ցանկացած հոլովով: Ինչպես և սպասելի է, առաջին անդամը առավել հաճախ ներկայացնում է սեռական հոլով (⟪षष्ठी⟫), քանի որ դա հենց այն հոլովն է, որն արտահայտում է անունների փոխհարաբերությունը:

:::

օրինակ՝

⟪क्षत्रियपुत्रः⟫ = ⟪क्षत्रियस्य पुत्रः⟫ = «Կշատրիայի որդին», «երիտասարդ կշատրիա», «կշատրիաների խմբի անդամ»  
Հայց. եզ. ⟪क्षत्रियपुत्रम्⟫  
Սեռ. եզ. ⟪क्षत्रियपुत्रस्य⟫  
և այլն:  

⟪गुरुभावः⟫ = ⟪गुरोर्भावः⟫ = «ուսուցչի բնույթը»

⟪धनलोभः⟫ = ⟪धनस्य लोभः⟫ = «հարստության ցանկություն, ագահություն»

⟪लोकगतिः⟫ = ⟪लोकस्य गतिः⟫ = «աշխարհի ընթացքը, մարդկանց վարքը»

Չնայած գրեթե բոլոր սեռական հարաբերությունները կարելի է փոխարինել տատպուրուշայով։ Ոչ մեծ բացառությունները տես, օրինակ՝ Կալեի «A higher Sanskrit grammar»-ում, § 211, այնտեղ նաև համապատասխան տեքստերը Պāնինիի մոտ։

Սակայն տատպուրուշայի առաջին անդամը սկզբունքորեն կարող է ներկայացնել ցանկացած հոլով։ Սակայն բոլոր սինտաքսիկորեն հնարավոր հոլովային հարաբերությունները չեն կարող փոխարինվել տատպուրուշայով։ Համապատասխան կանոնները երկմտելու դեպքում գտեք Կալեի «A higher Sanskrit grammar»-ում, § 203 - 217 կամ Պāնինի 2,1,22 - 2,2,22։

::: grammar-box

Տատպուրուշայի քայլ առ քայլ վերլուծության ժամանակ առաջին անդամը կարող է գտնվել միայնակ, երկական կամ հոգնակի թվով։ Թե որ տարբերակն է առկա, պետք է եզրակացնել իմաստից և համատեքստից։

:::

Օրինակներ։

Առաջին անդամը ներկայացնում է ուղղական հոլովը (⟪द्वितीया⟫)։ Օրինակ՝ որոշ շարժման բայերի համար (Պāնինի 2,1,24)։

⟪ग्रामगतः⟫ = ⟪ग्रामं गतः⟫ = «մեկը, ով գյուղ է մտել»
⟪नरकपतिता⟫ = ⟪नरकं पतिता⟫ = «նա, ով դժոխք է ընկել»

Առաջին անդամը ներկայացնում է գործիական հոլովը (⟪तृतीया⟫)։ Օրինակ՝ հաճախ գործող անձը (⟪कर्तृ⟫) կրող անվանական ձևերի համար (օրինակ՝ PPP)։

⟪देवकृतम्⟫ = ⟪देवेन⟫ / ⟪देवैः कृतम्⟫ = «աստծո կամ աստվածների կողմից ստեղծված»
Կարելի էր նաև վերլուծել. ⟪देवस्य⟫ / ⟪देवानां कृतम्⟫ = «աստծո կամ աստվածների գործ / արարք»

⟪बुद्धरक्षिता⟫ = ⟪बुद्धेन रक्षिता⟫ = «նա, ով Բուդդայի կողմից պահպանվել է» (անձնանուն)

## 15.5. Կոմպոզիտների վերլուծություն (բացառությամբ դվանդվաների)

::: grammar-box

Թեև սանսկրիտում կարելի է ձևավորել ցանկացած երկարությամբ կոմպոզիտներ և դա շատ հաճախ էլ տեղի է ունենում (10-30 անդամներից կազմված կոմպոզիտները հազվագյուտ չեն), սակայն՝ դվանդվաների բացառությամբ, բոլոր կոմպոզիտները աստիճանաբար հիերարխիկորեն պետք է վերլուծել երկու մասի։

:::

::: media

![](/images/lekt1502.jpg)

Պատկեր՝ ⟪समासविच्छेदः⟫
(Պատկերի աղբյուրը: [Details](/hy/licenses#lekt1502))

:::

և այլն, մինչև հասնենք առանձին բառարմատներին:

z.B.

⟪गुणवत्पुत्रकृतपुण्यम्⟫

::: indent

1-ին աստիճան (գլխավոր ցեզուրա)՝ ⟪गुणवत्पुत्रकृतं ॥१॥ पुण्यम्⟫

2-րդ աստիճան (1-ին երկրորդական ցեզուրա)՝ ⟪गुणवत्पुत्रेण ॥२॥ कृतं ॥१॥ पुण्यम्⟫

3-րդ աստիճան (2-րդ երկրորդական ցեզուրա)՝ ⟪गुणवता॥३॥ पुत्रेण ॥२॥ कृतं ॥१॥ पुण्यम्⟫

= «արժանի արարքը (վաստակը), որը կատարել է իմ առաքինի որդին»

:::

Ընդ որում, կոմպոզիտների տարբեր տեսակներ կարող են խառնվել, օրինակ՝ առաջին անդամ՝ Բահուվրիհի (⟪बहुव्रीहि⟫) - հետևի անդամ՝ Տատպուրուշա և այլն:

z.B.

⟪ब्राह्मणक्षत्रियवैश्यधर्मः⟫

::: indent

1-ին աստիճան՝ ⟪ब्राह्मणक्षत्रियवैश्यानां धर्मः⟫ (առաջին անդամ՝ Իտարետարադվանդվա)

2-րդ աստիճան՝ ⟪ब्राह्मणानां क्षत्रियाणां वैश्यानां च धर्मः⟫

= «բրահմանների, կշատրիաների և վայշյաների դհարման»

Շատ հաճախ կոմպոզիտի համար կան լուծման տարբեր հնարավորություններ: Թե որն է ճիշտ կամ առնվազն լավագույնը, կարելի է որոշել միայն տեքստի համատեքստից և բովանդակությունից: Երբեմն նման որոշումը հնարավոր չէ: Հաճախ հեղինակի կողմից նախատեսված են լուծման երկու տարբերակները: Այդ դեպքում թարգմանության մեջ պետք է վերարտադրել երկու տարբերակներն էլ (միացված «և», «կամ» շաղկապներով):

## 15.6. Քանդակի առաջին մասի ձևը կոմպոզիտներում (⟪समास⟫ m.)
