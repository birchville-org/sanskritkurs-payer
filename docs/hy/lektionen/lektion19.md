# Դաս 19

## 19.1. Հարաբերական նախադասություն

::: grammar-box

**Սխեմա.**


**Հարաբերական դերանուն -- հարաբերական նախադասություն, որը պարունակում է այն գոյականը, որին վերաբերվում է հարաբերական նախադասությունը -- (ցույց տվող դերանուն) -- հիմնական նախադասություն**

**Հարաբերական նախադասությունը կարող է գտնվել նաև հիմնական նախադասությունից հետո, սակայն այն չի կարող ներդրվել հիմնական նախադասության մեջ։**

**Հարաբերական դերանունը և կապակցման բառը, որն ի տարբերություն գերմաներենի՝ հայտնվում է հարաբերական նախադասության մեջ, գտնվում են այն հոլովի մեջ, որը սինտակտիկորեն պահանջվում է հարաբերական նախադասության կողմից։ Ցույց տվող դերանունը գտնվում է այն հոլովի մեջ, որը սինտակտիկորեն պահանջվում է հիմնական նախադասության կողմից։**
:::

Օրինակներ.

Ծանոթություն. Հարաբերական նախադասություններում, որոնք ունեն ընդհանուր արժեք, հաճախ նախընտրելի է օգտագործել ընդհանուր նպատակի (Optativ) ձևը ցույց տվողի (Indikativ) փոխարեն։ Այսպիսով, մեր շատ օրինակներում նախընտրելի կլինեն ընդհանուր նպատակի ձևերը։

**1. Գործողի (⟪कर्तृ⟫) նախադասությունը հարաբերական նախադասությամբ ավելի ճշգրտորեն որոշվում է.**

::: indent
⟪यो नरः पुण्यं करोति स स्वर्गं गच्छति⟫ =  ⟪यो नरः पुण्यं करोति तेन स्वर्गं गम्यते⟫ = ⟪येन नरेण पुण्यम् क्रियते तेन स्वर्गं गम्यते⟫ և այլն. = «Մարդ, ով բարի գործեր է կատարում, հայտնվում է երկնքում։»
:::
**2. Հիմնական նախադասության ուղղակի խոսքը (⟪कर्म⟫) հարաբերական նախադասությամբ ավելի ճշգրտորեն որոշվում է.**

::: indent
⟪यो ब्राह्मणो देवान्यजते तं देवा रक्षन्ति⟫ = «Աստվածները պաշտպանում են բրահմանին, ով նրանց զոհաբերության տիրոջ կարգավիճակով զոհաբերություն է մատուցում։»
:::
**3. Հիմնական նախադասության գոյականի ավելի ճշգրիտ որոշումը գտնվում է հարաբերական նախադասության մեջ.**

::: indent
⟪ये नराः पापं कुर्वन्ति तेषां पुत्रा धनं न लभन्ते⟫ = «Մարդկանց որդիներ, ովքեր չար են անում, առատություն չեն ստանում։»
:::
**4. Հարաբերական դերանունը և հղում բառը գտնվում են սեռական հոլովում (⟪षष्ठी⟫):**

::: indent
⟪यस्य नरस्य पुत्राः पापं कुर्वन्ति स न सुखवान्⟫ = «Ոչ ոք երջանիկ չէ, որի որդիները վատ բաներ են անում։»
:::
**5. Հարաբերական դերանունը և հղում բառը գտնվում են գործիական հոլովում (⟪तृतीया⟫):**

::: indent
⟪येन शत्रुणा ग्रामो जितस्तं द्विषन्ति⟫ = «Նրանք թշնամուն են ատում, ով հաղթել է / գրավել է իրենց գյուղը։»
:::
**6. Հարաբերական դերանունը և հղում բառը գտնվում են սեռական հոլովում (⟪द्वितीया⟫):**

::: indent
⟪यं नरं देवी रक्षति स सुखमाप्नोति⟫ = «Մարդը, ում պաշտպանում է աստվածուհին, հասնում է երջանկության։»
:::

## 19.3. Բառարան

**⟪अर्थ⟫ հոգ.՝.** նպատակ, ձեռքբերում, բառի իմաստ, հարստություն, ունեցվածք, կայունություն. ⟪अर्थम्⟫ (Հոլ.), ⟪अर्थेन⟫ (Գործ.)՝ Էլ. կամ որպես Տատփուրուշայի հետևի մաս. նպատակով ... , իրականացնելու համար:

⟪अर्थ⟫-ը երեք կյանքի նպատակներից մեկն է (⟪पुरुषार्थ⟫), ինչպես նկարագրված է աշխարհիկ և կրոնական գրականության մեջ.

## 19.4. Վարժություն

**Թարգմանեք սանսկրիտով.**

1\. Վայշյա կինը, որի որդին մահացել է, լաց է լինում։

2\. Ռաման նվիրաբերում է Աստծուն, ով պահպանում է նրան։

3\. Քնարերգուն գովում է Կշատրիյային, ում հարստությունը նա ցանկանում է։

4\. Հրդեհը այրում է տղամարդու տունը, ով Ագնիին չի պաշտում նվիրաբերությամբ։

5\. Շանթի նման տղամարդը սպանում է Կշատրիյա զինվորներին, ովքեր հաղթահարել են Ռամային (Պայթական)։
