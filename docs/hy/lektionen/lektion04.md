# Դաս 4

## 4.1. Պարզ հավելյալ հարցական նախադասություններ (բառային հարցեր) և պատասխաններ

### 4.1.1. Հարցական և ընդօրինակող դերանուններ

#### 4.1.1.1. Հարցական դերանուններ (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Հոլովական հոգնակի | Հոլովական բազմություն |
| :--- | :--- | :--- |
| **Չեզոք** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Էական** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Իգական** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Ընդօրինակող դերանուններ (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Ցեղեր** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"նա, նրանք, այն; այդ, այս":br(Հիշատակված)** | **etad = ⟪एतद्⟫:br"այս, այս":br(Շատ մոտ խոսողին)** | **idam = ⟪इदम्⟫:br"այս, այս":br(Մոտ)** |
| **Հոլովական հոգնակի** ||||
| **Չեզոք** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Էական** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Իգական** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Հոլովական բազմություն** ||||
| **Չեզոք** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Էական** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Իգական** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**Հոլ. հոգնակի էական.:**
**sa, eṣa** (⟪स एष⟫) կանգնում է բոլոր ձայների առաջ, բացի կարճ **-a**-ից
**so, eṣo** (⟪सो एषो⟫) կանգնում է **-a**-ի առաջ, որը Avagraha-ով չեղարկվում է (անհետանում)
**saḥ, eṣaḥ** (⟪सः एषः⟫) կանգնում է միայն ընդմիջման դեպքում (նախադասության ավարտ, բանաստեղծական տողի ավարտ)

Եթե ցանկանում եք կազմել նախադասություններ այս դերանուններով (sarvanāman n.), անհրաժեշտ է ծանոթանալ հետևյալ սանդհի կանոններին։

### 4.1.2. Վերջավորվող -m-ի սանդհին

::: grammar-box
**Տողի վերջում գտնվող -m-ը բաղաձայնների դեպքում փոխարինվում է Անուսվարայով (-ṃ): Նախադասության կամ տողի վերջում և ձայնավորների դեպքում -m-ը մնում է անփոփոխ։**
:::
### 4.1.3. Վերջավորվող -e-ի սանդհին

::: grammar-box
1. **a- ձայնավորի դեպքում -e-ը մնում է անփոփոխ. սկզբնական a- ձայնավորը էլիդացվում է Avagraha-ով:**
z.B. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Diese Feuer"

2. **Կարճ a- ձայնավորից բացի այլ ձայնավորների դեպքում -e-ը սովորաբար փոխարինվում է -a-ով՝ հիատուսով. հանդիպում է նաև -ay-ով փոխարինումը:**
z.B. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (selten: imay īśvarāh = ⟪इमयीश्वराः⟫) "Diese HERREN"
:::
### 4.1.4. Վերջավորվող -d-ի սանդհին

::: grammar-box
**Տողի վերջում գտնվող -d-ը պաուզայի, ինչպես նաև անձայն գուտուրալների (k, kh) և լաբիալների (p, ph) դեպքում փոխարինվում է -t-ով։**

**Այլ բաղաձայնների դեպքում փոխարինումը կքննարկվի ավելի ուշ. նախնական փուլում խուսափեք այդպիսի ձայնային բախումներից։**
:::
### 4.1.5. Frageformeln

**Այս դերանունների միջոցով, օրինակ, կարելի է կազմել հետևյալ հարցական ֆորմուլաները:**

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Singular** | **Neutrum** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं किम्⟫, ⟪किमिदम्⟫ | "Was ist das?" |
| ^^| **Maskulinum** | sa kaḥ? / kaḥ saḥ?:br⟪स कः⟫, ⟪कः सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष कः⟫, ⟪क एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं कः⟫, ⟪को ऽयम्⟫ | "Wer ist das?":br"Was ist der?" |
| ^^| **Femininum** | sā kā? / kā sā?:br⟪सा का⟫, ⟪का सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं का⟫, ⟪केयम्⟫ | "Wer ist das?":br"Wer ist die?" |
| **Plural** | **Neutrum** | tāni kāni? / kāni tāni?:br⟪तानि कानि⟫, ⟪कानि तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि कानि⟫, ⟪कानीमानि⟫ | |

Օրինակ այլ հարցերի.

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ Պատասխան. viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (Այստեղ կարելի է անվանական նախադասության մեջ թեմային բառը, օրինակ՝ սուբյեկտը, տեղադրել նախադասության սկզբում՝ շեշտը հարցին կապելու նպատակով:)

ՆՇՈՒՄ. Այն պատասխանները, որոնք դուք կարող եք տալ այդպիսի հարցերին՝ օգտագործելով ձեր նախկին սանսկրիտական գիտելիքները, իհարկե, դեռևս բոլոր առումներով չեն համապատասխանում ստանդարտ սանսկրիտին։


## 4.2. Վարժություն

**Ա) Առավոտյան կազմեք հետևյալ բառերով հարցեր՝ viṣṇuḥ kaḍ (⟪विष्णुः कः⟫) սխեմայով, և պատասխանեք հարցերին սանսկրիտով.**

śruti, śiva, brāhmaṇa, dvija (հոգնակի), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**Բ) Կազմեք հետևյալ ընթերցանության վարժության համար հարցեր՝ etat kim (⟪एतत्किम्⟫) նմուշով, և պատասխանեք հարցերին՝ օգտագործելով նշված բառերը և ապացուցողական դերանունները, օրինակ՝ eṣa bālaḥ (⟪एष बालः⟫).**
