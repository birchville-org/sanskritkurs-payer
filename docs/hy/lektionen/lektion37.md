# Դաս 37

## 37.1. Արտադիրը (⟪क्रियाविशेषणम्⟫)

Սանսկրիտում արտադիրները կազմվում են

1.  գոյականների և դերանունների հոլովային ձևերի միջոցով
2.  հատուկ վերջավորությունների և ծանցումների միջոցով

Առաջին դեպքում ողորկ հոլովի և արտադիրի սահմանը մշուշոտ է։ Այս խմբին են պատկանում որպես հատուկ դեպք արտադիրները, որոնք կայացած հին հոլովային ձևեր են, մինչդեռ խոնարհման մեջ օգտագործվում են այլ ձևեր, կամ համապատասխան գոյականներն արդեն չեն օգտագործվում որպես գոյականներ։

## 37.2. Հոլովային ձևերի արտադիրյան կիրառություն

### 37.2.1. Ուղղական (⟪द्वितीया⟫)

::: grammar-box
Ուղղականը (⟪द्वितीया⟫) կարող է օգտագործվել որպես արտադիր՝ հետևյալ հարցերին պատասխանելիս.

*   ինչպե՞ս։
*   որքա՞ն ժամանակով։
*   ուրա՞ղ։
* և այլն։

Ուղղականը կարող է օգտագործվել որպես արտադիր.

*   գոյականներից  
Օրինակներ.  
⟪कामम्⟫ «ցանկահամաձայն, ըստ ցանկության»  
⟪अर्थम्⟫ «համար»

*   չեզոք հատկանշականներից  
Օրինակներ.  
⟪सुखम्⟫ «հեշտ, երջանիկ»  
⟪नित्यम्⟫ «միշտ»  
⟪साधु⟫ «ճիշտ, լավ»

*   չեզոք դերանուններից  
Օրինակներ.  
⟪तद्⟫ «այն ժամանակ, այդ պատճառով»  
⟪यद्⟫ «երբ, որ»  
⟪एतद्⟫ «այսպես, այստեղ, հիմա»
:::
### 37.2.2. Ստեղծական (⟪तृतीया⟫)

::: grammar-box
Ստեղծականը (⟪तृतीया⟫) կարող է օգտագործվել որպես արտադիր՝ հետևյալ հարցերին պատասխանելիս.

*   ինչով՞։
*   ինչի՞ միջոցով։
* և այլն։

Ստեղծականը կարող է օգտագործվել որպես արտադիր.

*   գոյականներից  
Օրինակներ.  
⟪अर्थेन⟫ «համար»  
⟪क्षणेन⟫ «պահին, անմիջապես» (⟪क्षण⟩ m. «պահ»)

*   հատկանշականներից, հաճախ նաև հոգնակի ձևով  
Օրինակներ.  
⟪दूरेण⟫ «հեռու, հեռվից» (⟪दूर⟫ 3 «հեռու, հեռու»)  
⟪उच्चैस्⟫ «բարձր, ուժեղ» (⟪उच्च⟫ 3 «բարձր, բարձրացված, ուժեղ, սուր (ձայնի)»)
:::
### 37.2.3. Տրական (⟪चतुर्थी⟫)

::: grammar-box
Հազվադեպ է, որ տրականը (⟪चतुर्थी⟫) օգտագործվում է որպես մակբայ՝ պատասխանելով հետևյալ հարցերին.

*   ի՞նչ նպատակով։
*   և այլն

Օրինակ՝
:::
::: indent
⟪अर्थाय⟫ «նպատակով, ... համար»
:::
### 37.2.4. Հայցական (⟪पञ्चमी⟫)

::: grammar-box
Հայցականը (⟪पञ्चमी⟫) կարող է օգտագործվել որպես մակբայ՝ պատասխանելով հետևյալ հարցերին.

*   ի՞նչ պատճառով։
*   ի՞նչի պատճառով։
*   որտեղի՞ց։
*   և այլն

Հայցականը կարող է օգտագործվել որպես մակբայ.

*   գոյականներից  
օր. ⟪बलात्⟫ «բռնությամբ, ուժով»  

*   ածականներից  
օր. ⟪दूरात्⟫ «հեռվից»  

*   ժամանակավորականներից  
Օրինակներ.  
⟪कस्मात्⟫ «ինչու՞»  
⟪अकस्मात्⟫ «անսպասելիորեն»
:::
### 37.2.5. Սեռական (⟪षष्ठी⟫)

::: grammar-box
Հազվադեպ է, որ սեռականը (⟪षष्ठी⟫) օգտագործվում է որպես մակբայ՝ պատասխանելով «ինչքա՞ն ժամանակ անց» հարցին։

օր. ⟪चिरस्य⟫ «երկար ժամանակ անց» (հղում ⟪चिर⟫ 3 «երկար (ժամանակ)»)
:::
### 37.2.6. Տեղական (⟪सप्तमी⟫)

::: grammar-box
Տեղականը (⟪सप्तमी⟫) կարող է օգտագործվել որպես մակբայ՝ պատասխանելով հետևյալ հարցերին.

*   որտե՞ղ։
*   ի՞նչ հանգամանքներում։
*   և այլն

Օրինակներ.
:::
::: indent
\-⟪अर्थे⟫ «համար»  
\-⟪कृते⟫ «համար»  
⟪दूरे⟫ «հեռու»
:::
## 37.3. Ավելի չօգտագործվող հոլովների մակբայական օգտագործումը

Օրինակներ.
::: indent
⟪जातु⟫ «ընդհանրապես» (սկզբնական իմաստով «ծնունդով, բնությամբ», հոգնակի չեզոք սեռ) ⟪जातु⟫ \<այլևս որպես գոյական չօգտագործվող\>

⟪तूष्णीम्⟫ «համբերությամբ» (հոգնակի չեզոք սեռ) ոչ ավելի չօգտագործվող ⟪तूष्णी⟫ զ. «համբերություն»

⟪एवम्⟫ «այդպես» (հղում այլևս կորցված ժամանակավորական արմատին ⟪एव⟫ «մեկ, միակ»)
:::
## 37.4. Արտադրել մակբայները՝ օգտագործելով մակբայական հավելվածներ

## 37.5. Ադվերբիալ կոմպոզիտներ

### 37.5.1. Ադվերբ կամ ադվերբիալ օգտագործման դեպքում կացույցով հետևող մաս ունեցող կոմպոզիտներ

Օրինակ՝ ⟪सुचिरम्⟫ «շատ երկար (ժամանակ)»

### 37.5.2. Ադվերբիալ օգտագործման ⟪बहुव्रीहि⟫

Օրինակ՝ ⟪रक्षार्थम्⟫ «նման է նրան, ուստի նպատակը պահպանումն է, պահպանման նպատակով»: Կարելի է դիտարկել որպես պատկանող 5.1-ին՝ -⟪अर्थम्⟫ որպես ադվերբիալ հետևող մաս:

### 37.5.3. ⟪अव्ययीभाव⟫-կոմպոզիտներ

⟪अव्ययीभाव⟫ = «անփոփոխ/չծալվող դարձած»

::: grammar-box
⟪अव्ययीभाव⟫-ը ադվերբիալ կոմպոզիտ է, որի առջևի մասը անծալվող բառ է (հետդրություն, մասնիկ և այլն), իսկ հետևող մասը՝ գոյական, որը ստանում է չեզոք հոլովի միակետ կացույցի վերջավորությունը:

Կոմպոզիտի լուծման դեպքում առջևի մասը կկառավարեր հետևող մասին.

Օրինակներ՝
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = «կրակի դեմ»

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = «կարողության չափով»

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = «դեպի առջև, հակառակ»
:::

## 37.8. Հարցական նախադասություն

::: grammar-box
"Ո՞վ, ինչպե՞ս, ի՞նչ, ինչո՞ւ։ Ինչու՞, ինչի՞ համար։  
Ով չի հարցնում, մնում է անգետ։"

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

Սեսամփողոցի կարգախոսը, որը լավ ուղեցույց է կյանքի և սանսկրիտական ուսումնասիրության համար
:::
Տե՛ս նաև [Դաս 4](lektion04.md):

Պետք է տարբերակել

*   Բառային հարցեր (Ergänzungsfragen)
*   Նախադասության հարցեր

Բառային հարցերի դեպքում հարց է տրվում գործող անձի (⟪कर्तृ⟫), առարկայական լրացման, գործողության, հանգամանքի և այլն մասին, օր․

*   ո՞վ է գալիս։
*   ինչ՞ անում է Ռաման։
*   ում՞ է նա լսում։
*   ինչպե՞ս է նա խոսում սանսկրիտով։
*   որտե՞ղ է մայրը։

Նախադասության հարցերի դեպքում հարց է տրվում ամբողջ նախադասության բովանդակությանը, օր․

*   ի՞նչ է Ռաման այսօր գնում Օֆտերդինգեն։
*   արդյո՞ք ճիշտ է, որ ...։

## 37.11. Կրկնության վարժություն

Սանսկրիտով թարգմանեք՝ օգտագործելով միայն պերֆեկտի ձևեր.

Երբ մի տարեց մարդ գնում էր այլ գյուղ, նա ճանապարհին հոգնեց. Այդ պատճառով նա գնաց հանգստանալու կողքին աճած մանգոյի ծառի արմատը. Այդ ծառին հասուն պտուղներ կային: Տարեցը ցանկացավ այդ պտուղները: Սակայն նա չկարողացավ բարձրանալ ծառ և վերցնել պտուղները: Բարեբախտաբար, այդ ծառին կային մի որոշ վանդակներ, որոնք ուտում էին պտուղները: Երբ նա տեսավ դրանք, Տարեցը ուրախացավ: Ի՞նչ արեց նա. Նա վերցրեց մի քանի քար, նպատակավորվեց վանդակներին և նետեց: Վրդովված վանդակները հավաքեցին որոշ պտուղներ և նետեցին դրանք տարեցի վրա: Տարեցը ուրախությամբ վերցրեց դրանք և գնաց իր ցանկալի տարածք: Տեսե՛ք, տարեցի ճակատագիրը:
