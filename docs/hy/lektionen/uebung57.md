# Վարժություն 57

## Ա) Աորիստ-վերաձևակերպումներ

Թարգմանեք և որոշեք հետևյալ ձևերը, ապա կազմեք համապատասխան **աորիստ** ձևերը. Եթե ոչ կաուզատիվներ են, ոչ էլ **ս-աորիստ** կազմող արմատներ, փակագծերում նշված է համապատասխան աորիստի դասը.
