# Դաս 12


## 12.1. Անցյալի ժամանակի գործողական դերբայ (PPP)

Անցյալի ժամանակի գործողական նախադասություններ կազմելու մեկ եղանակ է այսպես կոչված անցյալի ժամանակի գործողական դերբայի (PPP) կառուցվածքը։

::: grammar-box
**Իրականում PPP-ն իսկական դերբայ չէ, քանի որ այն ձևավորվում է ոչ թե ժամանակային արմատից, այլ՝ բառակազմական ձև է արմատից՝ -ta կամ -na նախածանցով։ Այդ պատճառով հնդկական քերակության մեջ խոսում են kta նախածանցի մասին։**
:::

### 12.1.1. Անցյալի ժամանակի գործողական դերբայի սխեման փոխադարձ բայերի համար

::: grammar-box
**Գործող (kartṛ) գործիական հոլովում (tṛtīyā) -- ուղիղ խնդիր (karman) հոլովում (prathamā) -- Անցյալի ժամանակի գործողական դերբայ**

Այս դեպքում PPP-ն համընկնում է խնդրի հետ թվով, հոլովով և սեռով։

Օժանդակ բայ («լինել») անհրաժեշտ չէ։

Օրինակներ.
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = «(Աստվածաշնչյանը հասավ երկինք) = Աստվածաշնչյանը հասավ երկինք։»
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = «(Բրահմանը պաշտպանեց աստվածուհուն զոհաբերությամբ) = Բրահմանը պաշտպանեց աստվածուհուն զոհաբերությամբ։»
:::

### 12.1.2. Սխեմա I անցյալի ժամանակի գործողական դերբայի համար և շարժման բայեր

::: grammar-box
**Գործող (kartṛ) հոլովում (prathamā) -- Անցյալի ժամանակի գործողական դերբայ**

Այս դեպքում PPP-ն համընկնում է գործողի հետ թվով, հոլովով և սեռով։ Անցյալի ժամանակի «գործողական» դերբայն ունի ակտիվ իմաստ անցյալի ժամանակի գործողական դերբայների համար (առանց ուղիղ խնդրի) և շարժման բայեր։

Օրինակ.
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = «Կշատրիայ կինը գնաց քաղաք։»
:::

### 12.1.3. Սխեմա II անցողական բայերի և շարժումը նշող բայերի համար

::: grammar-box
**Գործող (kartṛ) գործիական հոլովում (tṛtīyā) -- PPP ներգործական հոլովում, միասնական չեզոք**

Օրինակ՝
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(Կշատրիյայի կողմից (քաղաք) գնացել է) = Կշատրիյան (քաղաք) գնացել է։“

Սխեման II-ով կառուցվածքը շատ ավելի հազվագյուտ է, քան սխեմա I-ով կառուցվածքը։
:::

## 12.2. PPP-ի իմաստը

Այսպիսով, այսպես կոչված «Պերֆեկտի պասիվ մասնակիցը» անցողական բայերի համար առաջին հերթին պասիվ իմաստ ունի (**āpta** = «հասած (է)») և անցողական բայերի և շարժումը նշող բայերի համար ակտիվ իմաստ ունի (**gata** = «գնացած»), կան մի քանի բայեր, որոնց դեպքում PPP-ն կարող է ունենալ և՛ ակտիվ, և՛ պասիվ իմաստ.

օր․
**gata** = ⟪गत⟫ = «գնացած» (ակտիվ); բայց նաև՝ **gato mārgaḥ** = ⟪गतो मार्गः⟫ = «գնացած ճանապարհ» (պասիվ)
**āpta** = ⟪आप्त⟫ = «հասած (է)» (պասիվ), «հասած» (ակտիվ)


## 12.3. PPP-ի կազմություն

::: grammar-box
Հանդիպում են հետևյալ կազմության եղանակները (յուրաքանչյուր արմատի համար պետք է սովորել նաև դրա PPP-ն)։

**(հիմնականում) խորը աստիճանի արմատ**

**+ -ta**
կապող վանկով **-i-** նախքան՝ **-ita**
առանց կապող վանկի՝ **-ta**
**+ -na**

Գոյականների չեզոք հոլովումը՝ **-tā**, **-itā**, **-nā**; չեզոքը հոլովվում է **phala** n-ի նման։
:::

### 12.3.1. -ta (kta) վերջավորությամբ PPP

#### 12.3.1.1. Առանց կապող վանկի -i- (aniṭ)

*aniṭ* = «առանց (*an-*) հավելվածից առաջ տեղադրված (*-i-*) *t*» (այսինքն՝ առանց կապող վանկի *i*)։

::: grammar-box
Без соединительного гласного причастие прошедшего времени (PPP) обычно образуется от корней, оканчивающихся на гласный, а также от многих других корней; при этом невозможно сформулировать чёткое правило о том, в каких именно случаях соединительный гласный присутствует или отсутствует.

Список *aniṭ*-корней приведён у Киельгорна, «Грамматика», § 298.
:::
**Примеры:**

::: grammar-box
| Корень | PPP (kta) |
| :--- | :--- |
| **bhū** 1 P:br(⟪भू⟫) | **bhū-ta** :br(⟪भूत⟫) |
| **smṛ** 1 P:br(⟪स्मृ⟫) | **smṛ-ta** :br(⟪स्मृत⟫) |
| **nṛt** 4 P:br(nṛt-ta):br(⟪नृत्त⟫) | **nṛt-ta** :br(⟪नृत्त⟫) |
| **nī** 1 U:br(⟪नी⟫) | **nī-ta** :br(⟪नीत⟫) |
| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |
| **su** 5 U:br(⟪सु⟫) | **su-ta** :br(⟪सुत⟫) |
| **gam** 1 P:br(⟪गम्⟫) | **ga-ta** (\< \*gm-ta):br(⟪गत⟫) |
| **ji** 1 P:br(⟪जि⟫) | **ji-ta** :br(⟪जित⟫) |
| **śru** 5 P:br(⟪श्रु⟫) | **śru-ta** :br(⟪श्रुत⟫) |
| **kṛ** 8 U:br(⟪कृ⟫) | **kṛ-ta** :br(⟪कृत⟫) |
| **tan** 8 U:br(⟪तन्⟫) | **ta-ta** (\< \*tn-ta):br(⟪तत⟫) |
| **iṣ** 6 P:br(⟪इष्⟫) | **iṣ-ṭa** :br(⟪इष्ट⟫) |
:::
#### 12.3.1.2. С соединительным гласным -i- (seṭ)

*seṭ* = *sa-iṭ* = «с (*sa-*) суффиксом, перед которым стоит (*-i-*) *t*» (т.е. с соединительным гласным *i*).

**Примеры:**

::: grammar-box
| Корень | PPP (kta) |
| :--- | :--- |
| **kup** 4 P:br(⟪कुप्⟫) | **kup-i-ta** :br(⟪कुपित⟫) |
| **khād** 1 P:br(⟪खाद्⟫) | **khād-i-ta** :br(⟪खादित⟫) |
| **rakṣ** 1 P:br(⟪रक्ष्⟫) | **rakṣ-i-ta** :br(⟪रक्षित⟫) |
| **vad** 1 P:br(⟪वद्⟫) | **ud-i-ta** (\< \*vd-i-ta):br(⟪उदित⟫) |
:::

## 12.4. Законы сандхи в слове

При утвореннях за правилом *aniṭ* слід дотримуватися таких законів сполучення звуків у слові. **Ці закони є дуже важливими для розуміння всієї санскритської морфології.**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p перед глухим вибухним (напр., t, th) залишаються незмінними:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct замінюється на kt = ⟪क्त्⟫:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt замінюється на ṣṭ = ⟪ष्ट्⟫:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. Дзвінкий неаспірований вибухний – окрім j – перед глухим звуком замінюється відповідним йому дзвінким неаспірованим звуком:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (важливо для 2-го класу тепазісу) |
| **5. jt замінюється на kt або ṣṭ (не факультативно!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. Дзвінкий аспірований вибухний + глухий вибухний » дзвінкий неаспірований вибухний + дзвінкий аспірований вибухний (аспіраційне правило Бартоломея):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t замінюється на ḍh з подовженням попереднього i або u; або ж на gdh. Перед таким ḍh a замінюється на o, рідше — на ā:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „ховати щось”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.6. Վարժություններ

**Ա) Կազմեք [Դաս 7](/lektionen/lektion07)-ի, Ա վարժության ակտիվ նախադասություններից անցյալ ժամանակի պասսիվ նախադասություններ՝ օգտագործելով PPP-ն, իսկ անցողական բայերի և շարժումը նշող բայերի դեպքում՝ ակտիվ նախադասություններ անցյալ ժամանակով։**

**Բ) Կազմեք համապատասխան PPP-ները [Դաս 10](/lektionen/lektion10)-ի, Ա վարժության բայերի ձևերին։ Հաշվի առեք, որ sṛjati ձևին համապատասխանում են PPP-ները բոլոր երեք թվերով։**

**Գ) Դարձրեք [Դաս 10](/lektionen/lektion10)-ի, Գ վարժության նախադասությունները պասսիվ և թարգմանեք դրանք անցյալ ժամանակով։**
