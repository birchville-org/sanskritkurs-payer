# Դաս 25

## 25.1. Աբլատիվի ձևավորում (⟪पञ्चमी⟫ = «հինգերորդ հոլովի վերջավորություն»)

::: grammar-box
Բացի -a վերջավորությամբ հոդակապ/հոլովվող զուգահեռներից և դերանուններից, միայնակ թվով բոլոր հոլովման դասերում աբլատիվի (⟪पञ्चमी⟫) ձևերը նույնական են գենիտիվի (⟪षष्ठी⟫) ձևերին։

Բացի անձնական դերանուններից, բոլոր հոլովումներում շարահյուսական թվով աբլատիվի ձևերը նույնական են դատիվի (⟪चतुर्थी⟫) ձևերին։
:::
Այժմ դուք հասկանում եք սանսկրիտերեն հոլովների (⟪विभक्ति⟫) դասավորության պատճառը. նրանք այնպես են դասավորված, որ համաձայնեցվող ձևերը կարելի է հնարավորինս մոտ, կամ իրար ներքևում տեղադրել։

::: grammar-box
**Աբլատիվ միայնակ թիվ հոդակապ/հոլովվող -a վերջավորությամբ**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Հարցական, հարաբերական և ընդգծող դերանուններ.

::: grammar-box

| | Աբլատիվ միայնակ թիվ.հոդակապ/հոլովվող | Աբլատիվ միայնակ թիվ.հոդակապ/հոլովվող |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Աբլատիվի կիրառություն (⟪पञ्चमी⟫)

«Աբլատիվը նշում է այն, ինչ մնում է անփոփոխ, երբ ինչ-որ բան հեռանում է դրանից։»

Պանինի 2,3,28 + 1,4,24

Աբլատիվը հիմնականում պատասխանում է «Որտեղի՞ց», «Ինչո՞ւ» հարցերին։

::: grammar-box
1\. Աբլատիվը նշում է սկզբնակետը, ծագումը և նյութը։

Աբլատիվը կարող է նաև նշել այն անձին, ումից գնում ենք, լսում ենք, ցանկանում ենք և այլն։
:::
Examples:

::: indent
⟪ग्रमादागच्छति⟫ = "He comes from the village"

⟪अश्वात्पतितः⟫ = "fallen from the horse"

⟪तेभ्यो लब्धम्⟫ = "received from them (her)"
:::
Examples:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "he hears from the teacher about the Dharma"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "the Brahmin wishes for a milk cow from the Kṣatriya"
:::
::: grammar-box
2. The Ablative is used with verbs meaning "to abstain from", "to protect from", "to defend against", "to fear":
:::
Example:

::: indent
⟪अरिभ्यो रक्षति⟫ = "he protects from the enemies"
:::
::: grammar-box
3. The Ablative denotes the reason or cause:
:::
Examples:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "He strikes down his son out of anger"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "Because he has done evil, he goes to hell" ("Because he is one through whom evil was done")

⟪पापकरणान्नरकं गच्छति⟫ = "Because he does / did evil, he goes to hell"
:::
Nouns that are not feminine can, to denote the reason for an action, stand in the Instrumental (⟪तृतीया⟫) or Ablative (⟪पञ्चमी⟫). Feminines usually stand in the Instrumental for this purpose, but can occasionally also stand in the Ablative.

## 25.3. The Suffix -⟪तस्⟫

::: grammar-box
If one wants to express clearly in the singular that a word is used with ablative meaning, one can attach the suffix -⟪तस्⟫ to the word stem, which forms adverbs with mostly ablative meaning (answering the question "From where?"):
:::
Օրինակներ.

::: indent
⟪आदितस्⟫ = «սկզբից ի վեր»

⟪धर्मतस्⟫ = «դհարմայի պատճառով, դհարմայի հիման վրա»
:::
::: grammar-box
⟪तस्⟫ վերջավորությունը հանդիպում է նաև արտահայտական արմատներին.
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) «այնտեղից, այնտեղ, դեպի այնտեղ, նրա վրա, ապա, հետևաբար»

⟪यद्⟫ : ⟪यतस्⟫ «որից, ինչից, որտեղից, որտեղ, ուր, ինչու» (հարաբերական)

⟪किम्⟫ :  ⟪कुतस्⟫ «որտեղից?» «ինչու՞»
:::
## 25.4. Պատճառաբանությունը արտահայտելու այլ եղանակներ

::: grammar-box
**1\. Հարաբերական նախադասություններ**

Հարաբերական նախադասությունները հաճախ արտահայտում են պատճառական (հիմնավորող), հետևանքային (եզրակացնող) կամ նպատակային (նպատակահարույց) առնչություն գլխավոր նախադասության հետ։

Հարաբերական դերանունի ձևեր, որոնք հանդես են գալիս որպես պատճառական մասնակից.

*   աբլատիվային.
*   ⟪यतस्⟫ ... ենթադաս ... ⟪ततस्⟫ ... գլխավոր դաս ... = «քանի որ ..., հետևաբար ...»
*   ⟪यस्मात्⟫ ... ենթադաս ... ⟪तस्मात्⟫ ... գլխավոր դաս ... = «քանի որ ..., հետևաբար ...»
*   ինստրումենտալ.
*   ⟪येन⟫ ... ենթադաս ... ⟪तेन⟫ ... գլխավոր դաս ... = «Որով/քանի որ ..., հետևաբար / այդ պատճառով ...»
:::
Օրինակ.

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = «Քանի որ Ռաման ցանկանում է բարօրություն, նա կատարում է երդումը»
:::
::: grammar-box
**2\. ⟪हि⟫**

Գլխավոր նախադասությունները կարելի է միացնել ⟪हि⟫ «քանի որ, քանզի» մասնակով։ ⟪हि⟫ պարտադիր չէ, որ գրվի նախադասության սկզբում (արձակում այն պետք է լինի երկրորդ տեղում), և այն նախադասությունը, որտեղ այն կիրառվում է, պատճառաբանություն է ներկայացնում կա՛մ նախորդ, կա՛մ հաջորդ նախադասության համար.

:::
::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = «Ժողովուրդը կատարում է արժանավոր գործեր։ Քանի որ նրանք ցանկանում են երկինք հասնել։»
:::
::: grammar-box
**3\. Գործիական հոլում (⟪तृतीया⟫)**

Աբլատիվի (⟪पञ्चमी⟫) հետ մեկտեղ գործիական հոլումը (⟪तृतीया⟫) օգտագործվում է պատճառի կամ հիմքի նշման համար։ Իգական սեռի գոյականների դեպքում գործիական հոլումը ընդհանուր առմամբ պարտադիր է։
:::
Օրինակ.

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = «Նա զայրույթից սպանում է իր որդուն» = «Նա զայրույթի մեջ սպանում է իր որդուն»
:::
::: grammar-box
**4\. Գոյականներ**

Սակայն, բնականաբար, հիմքերը կարելի է արտահայտել նաև

*   ⟪कारण⟫ n. «Պատճառ». ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ m.
*   այլ գոյականներ «Պատճառ» իմաստով

\+ Էգենիտիվ (⟪षष्ठी⟫) կամ որպես կոմպոզիտների երկրորդ մաս.
:::
Օրինակ.

::: indent
⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ և այլն) = «արժանավորության պատճառով»
:::
::: grammar-box
**5\. ⟪इति⟫**

Գործունեության մոտիվը կարելի է նշել որպես մտքեր ⟪इति⟫-ով.
:::
Օրինակ.

::: indent
⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫  = «Քանի որ Սուգատան կատարելապես արթնացել է ճշմարտությանը, Անանդան հարցնում է Գաուտամային նրա դոկտրինի մասին» (««Մտածելով «Սուգատան կատարելապես արթնացել է ճշմարտությանը» ...»)
:::
