# Դաս 30

## 30.1. 9-րդ ներկայի դաս (⟪क्र्यादि⟫ = "⟪क्री⟫ և այլն")

::: grammar-box
**Կազմություն:**

*   ուժեղ արմատ. խորացված արմատ + -nā-

*   թույլ արմատ.

*   բաղաձայնից առաջ. խորացված արմատ + -nī-

*   ձայնավորից առաջ. խորացված արմատ + -n-
:::
Օրինակ.

::: indent
⟪क्री⟫ 9U "գնել"
:::
::: grammar-box

| |Եզակի:br⟪एकवचन⟫|Հոգնակի:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3-րդ դեմք:brParasmaipada**|⟪क्रीणाति⟫:br(krī + nā + ti)|⟪क्रीणन्ति⟫:br(krī + n + anti)|
|**3-րդ դեմք:brĀtmanepada**|⟪क्रीणीते⟫:br(krī + nī + te)|⟪क्रीणते⟫:br(krī + n + ate)|

:::
Այս ներկայի դասում հատուկ ուշադրություն է պահանջվում ներկայի արմատի կազմության վրա ⟪ज्ञा⟫ 9U "ճանաչել, իմանալ" արմատի համար.

::: grammar-box

| |Եզակի:br⟪एकवचन⟫|Հոգնակի:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3-րդ դեմք:brParasmaipada**|⟪जानाति⟫:br(jā-nā-ti)|⟪जानन्ति⟫:br(jā-n-anti)|
|**3-րդ դեմք:brĀtmanepada**|⟪जानीते⟫:br(jā-nī-te)|⟪जानते⟫:br(jā-n-ate)|

:::
⟪जा⟫ ձևը, որն հիմք է հանդիսանում ⟪ज्ञा⟫ ներկայի արմատի համար, կարելի է բացատրել -ā (խորացված) -nā (բարձրացված) ապախտային շարքով, կամ էլ *jñā-nā-ti-ից դիսսիմիլյացիայով։

Որոշ երկար ձայնավորով արմատներ կրճատում են այդ ձայնավորը 9-րդ դասի ներկայի հավելվածից առաջ.

Օրինակ.

::: indent
⟪पू⟫ 9U "մաքրել"
:::
::: grammar-box

| |Եզակի:br⟪एकवचन⟫|Հոգնակի:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3-րդ դեմք:brParasmaipada**|⟪पुनाति⟫:br(pu-nā-ti)|⟪पुनन्ति⟫:br(pu-n-anti)|
|**3-րդ դեմք:brĀtmanepada**|⟪पुनीते⟫:br(pu-nī-te)|⟪पुनते⟫:br(pu-n-ate)|

:::
Ժամանակավոր մասնակցի կազմումը պարասայպադայի համար.

Օրինակ՝

:::
## 30.2. Օպտատիվի կիրառությունը (⟪लिङ्⟫)

Օպտատիվը կիրառվում է.

::: grammar-box
**1. նշանակելու համար**

*   **ցանկության**
*   **խնդրանքի**
*   **թուլացված հրամանի**

**(այստեղ օպտատիվը՝ ⟪लिङ्⟫, համընկնում է իմպերատիվին՝ ⟪लोट्⟫)**
:::
Օրինակ՝

::: indent
⟪दासो ग्राममागच्छेत्⟫ = «Բանվորը պետք է գա գյուղ»
:::
::: grammar-box
**2. Երբ ինչ-որ բան**

*   **հնարավոր**
*   **հավանական**
*   **ենթադրելի**

**պետք է ներկայացվի։**
:::
Օրինակ՝

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं न शृणुयात्⟫ = «Եթե նա գյուղից դուրս գար, չէր լսի վարպետին»
:::
::: grammar-box
**3. Օպտատիվով հարաբերական նախադասությունները երբեմն ունեն «Եթե ինչ-որ մեկը ...» նշանակություն։**
:::
Օրինակ՝

::: indent
⟪यो नृतं वदेत्स नरकं पतेत्⟫ = «Եթե ինչ-որ մեկը կեղծիք ասեր, նա կնետվեր դժոխք = Եթե ինչ-որ մեկը կեղծիք ասեր, նա ընկնում է դժոխք»
:::
## 30.3. Տրոհային վերջավորությունները երրորդ դեմքի համար միայնակ և շատություն

Օպտատիվը (⟪लिङ्⟫), անցյալ շարունակականը (⟪लङ्⟫), աորիստը (⟪लुङ्⟫), պրեկատիվը (⟪आशिर्लिङ्⟫) և կոնդիցիոնալը ունեն այսպես կոչված տրոհային վերջավորություններ.

::: grammar-box

| |Երրորդ դեմք միայնակ|Երրորդ դեմք շատություն|
| :--- | :--- | :--- |
|**Պարասայպադա**|**-t**|անթեմատիկ դասեր՝ **-an** կամ **-ur** :brՕպտատիվ՝ **-ur**|
|**Աթմանեպադա**|**-ta**|անթեմատիկ դասեր՝ **-ata** (*nta-ից):brՕպտատիվ՝ **-ran**|

:::

::: grammar-box

**Ներկայի արմատ + -i- (որը միախառնվում է -a- հետ՝ դառնալով -e-) + երկրորդական վերջավորություններ**

**հանգամանքներում, որոնց վերջավորությունները սկսվում են ձայնավորով.**
