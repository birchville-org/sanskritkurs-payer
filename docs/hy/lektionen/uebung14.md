# Վարժություն 14

Թարգմանեք հետևյալ ընդհանրացված ասույթները և հիշեք դրանք.

⟪निचो वदति न कुरुते वदति न साधुः करोत्येव ॥१॥⟫  
Ցածր մարդը չի խոսում և չի գործում, բարի մարդը չի խոսում, այլ գործում է։

⟪शीलं नरस्य भूषणम् ॥२॥⟫  
Առաքինությունը մարդու զարդն է։

⟪सत्येन जनानां सुखं भवति ॥३॥⟫  
Ճշմարտությամբ մարդկանց բախտ է հասնում։

⟪पापा नराः स्वर्गं न लभन्ते ॥४॥⟫  
Չար մարդիկ երկինք չեն մտնում։

⟪सत्यं लोकस्य दीपः ॥५॥⟫  
Ճշմարտությունը աշխարհի լույսն է։

Ա) Կազմեք հետևյալ բառերի երկուական և շեշտակի հոլովը։ Նշեք բառերի նշանակությունն ու սեռը.

⟪१⟫. ⟪अनृत⟫ : չեզոք։ Անճշտություն — ⟪अनृतस्य अनृतानाम् २⟫. ⟪ऋषि⟫ : զուգ. վեդական մարգարե — ⟪ऋषेः ऋषीणाम् ३⟩. ⟪पाद⟩ : զուգ. ոտք — ⟪पादस्य पादानाम् ४⟩. ⟪बुद्धि⟩ : իգ. գիտելիք — ⟪बुद्धेः⟩ (⟪बुद्ध्याः⟩) ⟪बुद्धीनाम् ५⟩. ⟪गुरु⟩ : զուգ. ուսուցիչ — ⟪गुरोः गुरूणाम् ६⟩. ⟪स्वर्ग⟩ : զուգ. երկինք — ⟪स्वर्गस्य स्वर्गाणाम् ७⟩. ⟪नगर⟩ : չեզոք. քաղաք — ⟪नगरस्य नगराणाम् ८⟩. ⟪धेनु⟩ : իգ. ցուլ — ⟪धेनोः⟩ (⟪धेन्वाः⟩) ⟪धेनूनाम् ९⟩. ⟪द्विज⟩ : զուգ. երկվորյակ — ⟪द्विजस्य द्विजानाम् १०⟩. ⟪मुक्ता⟩ : իգ. ազատվածը — ⟪मुक्तायाः मुक्तानाम् ११⟩. ⟪विद्या⟩ : իգ. գիտելիք, գիտություն — ⟪विद्यायाः विद्यानाम् १२⟩. ⟪वर्ण⟩ : զուգ. կարգ — ⟪वर्णस्य वर्णानाम् १३⟩. ⟪द्विजाति⟩ : 3 երկվորյակ — ⟪द्विजातेः⟩ (⟪द्विजात्याः⟩) ⟪द्विजातीनाम् १४⟩. ⟪रूप⟩ : չեզոք. ձև — ⟪रूपस्य रूपाणाम् १५⟩. ⟪प्रतिग्रह⟩ : զուգ. ընդունում — ⟪प्रतिग्रहस्य प्रतिग्रहाणाम्⟩

⟪१६⟫. ⟪सोढ⟫ : 3 ertragen — ⟪सोढस्य⟫ ⟪सोढायाः⟫ ⟪सोढानाम्⟫

⟪१७⟫. ⟪नायिका⟫ : f. Geliebte — ⟪नायिकायाः⟫ ⟪नयिकानाम्⟫

⟪१८⟫. ⟪साध्वी⟫ : f. Heilige — ⟪साध्व्याः⟫ ⟪साध्वीनाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 հանդուրժել — ⟪सोढस्य सोढायाः सोढानाम् १७⟫. ⟪नायिका⟫ : կ. սիրելի — ⟪नायिकायाः नयिकानाम् १८⟫. ⟪साध्वी⟫ : կ. սուրբ — ⟪साध्व्याः साध्वीनाम् १९⟫. ⟪अग्नि⟫ : լ. կրակ — ⟪अग्नेः अग्नीनाम् २०⟫. ⟪वैश्या⟫ : կ. վայշյա կին — ⟪वैश्यायाः वैश्यानाम् २१⟫. ⟪लोक⟫ : լ. աշխարհ, մարդիկ — ⟪लोकस्य लोकानाम् २२⟫. ⟪उक्ति⟫ : կ. ասույթ — ⟪उक्तेः⟫ (⟪उक्त्याः⟫) ⟪उक्तीनाम् २३⟫. ⟪शत्रु⟫ : լ. թշնամի — ⟪शत्रोः शत्रूणाम् २४⟫. ⟪सुखवन्त्⟫ : 3 երջանիկ — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : կ. մի կամ ավելի որդի ունեցող կին — ⟪पुत्रवत्याः पुत्रवतीनाम् २६⟫. ⟪जल⟫ : չ. ջուր — ⟪जलस्य जलानाम् २७⟫. ⟪मार्ग⟫ : լ. ճանապարհ — ⟪मर्गस्य मर्गाणाम् २८⟫. ⟪मोक्ष⟫ : լ. ազատագրում, փրկություն — ⟪मोक्षस्य मोक्षाणाम् २९⟫. ⟪शूद्रा⟫ : կ. շուդրա կին — ⟪शूद्रायाः शूद्राणाम् ३०⟫. ⟪अन्न⟫ : չ. սնունդ, ուտելիք — ⟪अन्नस्य अन्नानाम् ३१⟫. ⟪साधु⟫ : լ. սուրբ — ⟪साधोः साधनाम् ३२⟫. ⟪नीति⟫ : կ. ուղղորդում — ⟪नीत्याः नीतीनाम् ३३⟫. ⟪योध⟫ : լ. մարտիկ, զինվոր — ⟪योधस्य योधानाम् ३४⟫. ⟪सत्यवन्त्⟫ : 3 ճշմարիտ — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : լ. շահույթ — ⟪लाभस्य लाभानाम् ३६⟫. ⟪मोह⟫ : լ. շփոթություն, կուրացում — ⟪मोहस्य मोहानाम् ३७⟫. ⟪गति⟫ : կ. քայլ, նպատակ — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम् ३८⟫. ⟪प्रश्न⟫ : լ. հարց — ⟪प्रश्नस्य प्रश्नानाम् ३९⟫. ⟪सृष्टि⟫ : կ. ստեղծագործություն — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम् ४०⟫. ⟪नेत्र⟫ : չ. աչք — ⟪नेत्रस्य नेत्राणाम् ४१⟫. ⟪गुरुता⟫ : կ. վարպետություն — ⟪गुरुतायाः गुरुतानाम्⟫

⟪४६⟫. ⟪युद्ध⟫ : 3 պայքարել — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम् ४७⟫. ⟪दर्शन⟫ : n. տեսնել, երևույթ — ⟪दर्शनस्य दर्शनानाम् ४८⟫. ⟪धातु⟫ : m. տարր, անձնական — ⟪धातोः धातूनाम् ४९⟫. ⟪गूढा⟫ : f. թաքնված — ⟪गूढायाः गूढानाम् ५०⟫. ⟪ईष्टा⟫ (2 իմաստներ): f. ցանկալի, նվիրված — ⟪इष्टायाः इष्टानाम् ५१⟫. ⟪उदित⟫ : 3 ասված — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम् ५२⟫. ⟪इदम्⟫ : 3 այս — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 ինչ — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) Թարգմանեք.

⟪१⟫. ⟪ब्राह्मणस्य पुत्रो ब्राह्मण्या ग्रामं गतः ।⟫ (2 տարբերակ)
Բրահմանի որդին գնաց բրահմուհու գյուղ։ Բրահմանի որդին բրահմուհու հետ գնաց գյուղ։

⟪२⟫. ⟪यज्ञस्याग्निनान्नं दग्धम् ।⟫
Խնդրանքի կրակը այրեց սնունդը։

⟪३⟫. ⟪बुद्धः स्तयस्य बुद्ध्या मुक्तः ।⟫
Բուդդան ազատվեց ճշմարտության գիտելիքով։

⟪४⟫. ⟪अधर्मो ऽनृतस्य वदनमित्यृषयो वदन्ति ।⟫
Վեդական մարգարեները ասում են, որ ստելը չար է։

⟪५⟫. ⟪नरा देवानां यज्ञैर्न मुच्यन्ते ।⟫
Մարդիկ չեն ազատվում աստվածներին նվիրաբերությունների միջոցով։

⟪६⟫. ⟪बलवन्तः क्षत्रियाः शत्रूणां धनवन्ति नगराणि जयन्ति ।⟫
Հզոր կշատրիաները գրավում են թշնամիների հարուստ քաղաքները։

⟪७⟫. ⟪कवेरुक्तिं शृण्वन्ति ।⟫
Դուք լսում եք բանաստեղծի խոսքը։

⟪८⟫. ⟪कविर्देव्याः कृतं वद⟫ti ⟪।⟫
Բանաստեղծը պատմում է Աստվածուհու գործի մասին։

⟪९⟫. ⟪द्विजाः पशोर्लाभमिच्छन्ति ।⟫
Երկու անգամ ծնվածները ցանկանում են կենդանի ստանալ։

⟪१०⟫. ⟪रामः पुण्यवतो गुरोर्मन्त्रस्य स्मरति ।⟫
Ռաման հիշում է առաքինի վարդապետի մոտրան։

⟪११⟫. ⟪अयं बालः कस्याः पुत्रः ।⟫
Ո՞րի (գ.) որդին է այս տղան։

⟪१२⟫. ⟪केषामिमानि गृहाणि ।⟫
Ո՞րներին են պատկանում այս տները։

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम् ।⟫
Ո՞րի սնունդը է այս վեդական մարգարեն զոհաբերել։
