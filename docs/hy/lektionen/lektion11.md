# Դաս 11

## 11.1. Կրկնակի գոյական հոլով

::: grammar-box
**Որոշ բայեր կարող են վերահսկել կրկնակի գոյական հոլով (dvitīyā). Գոյականի դեպքում՝ մարդու և առարկայի համար։**

**Այսինքն՝.**
**Խոսքի բայեր**. խոսել ում հետ (գոյական) մի բանի մասին (գոյական); ում հետ (գոյական) ինչ-որ բան ասել
**Հարցման բայեր**. ում հետ (գոյական) ինչ-որ բանի մասին հարցնել
**Դասավանդման բայեր**. ում հետ (գոյական) ինչ-որ բան սովորեցնել
մի քանի այլ բայեր, որոնց դեպքում նշված է բառարաններում

**Եթե այսպիսին կառուցվածքը փոխարկենք գործիական հոլովի, ապա մարդը (ինչ-որ բան հարցնող և այլն) դառնում է գործիական հոլով (prathamā), իսկ առարկան (ինչ-որ բանի մասին հարցնող և այլն) մնում է գոյական հոլով։**

օրինակ՝ **rāmo brāhmaṇaṃ dharmaṃ pṛcchati** = ⟪रामो ब्राह्मणं धर्मं पृच्छति⟫ = «Ռաման հարցնում է բրահմանին դհարմայի մասին։»
» Գործիական հոլով. **rāmeṇa brāhmaṇo dharmaṃ pṛcchyate** = ⟪रामेण ब्राह्मणो धर्मं पृच्छयते⟫

**Այս կանոնը վերաբերում է միայն այն դեպքին, երբ և՛ մարդը, և՛ առարկան նպատակ են։ Եթե միայն առարկան է նպատակ, այն գործիական հոլովում (prathamā) է.**

օրինակ՝ **rāmo dharmaṃ pṛcchati** = ⟪रामो धर्मं पृच्छति⟫ = «Ռաման հարցնում է դհարմայի մասին։»
» Գործիական հոլով. **rāmeṇa dharmaḥ pṛcchyate** = ⟪रामेण धर्मः पृच्छयते⟫
:::

## 11.2. Բառարան

**Սովորեք հետևյալ բառերը.**

**iti** ⟪इति⟫. այսպես
Գալիս է *հետո* մտքի, ցանկության, խոսքի, վերաբերյալ արտահայտություններից հետո, որպես վերջակետ (").
օրինակ՝ **sādhavaḥ svargaṃ gacchantīti brāhmaṇā vadanti** «Բրահմաններ ասում են. «Աստվածային մարդիկ գնում են երկինք»։ = «Բրահմաններ ասում են, որ ազնիվ մարդիկ գնում են երկինք։»
Սանսկրիտում անուղղակի խոսք չկա. **iti**-ով կառուցվածքները գերմաներենում հաճախ անուղղակի խոսքով են վերարտադրվում։
**... (վերջակետ) ... iti śrutiḥ** = «այսպես է Վեդան ասում։»
Հաճախ **iti**-ից հետո ավելացվում է մտածողության բայ. «մտածելով՝ «...» անում է նա։ Գերմաներենում իդիոմատիկորեն վերարտադրել (օրինակ՝ «Քանի որ նա քաղցած է, գնում է...»):

**evam** ⟪एवम्⟫ : այսպես (գործածվում է որպես խոսքի մաս, օրինակ՝ **evaṃ jayati** «այսպես է հաղթում նա»):
**na** ⟪न⟫ : ոչ
Ժխտում է առանձին բառեր (կանգնում է դրանց անմիջապես առաջ՝ **na sādhuḥ** «ոչ լավ մարդ») կամ ամբողջ նախադասություններ (կանգնում է սկզբում կամ անմիջապես բայից առաջ):

**putra** հոգ. ⟪पुत्र⟫ : որդի (Հնդկաստանում անհրաժեշտ էր որդի ունենալ, ով կկարողանար մատուցել նահապետների համար զոհաբերություններ):
**dharma** հոգ. ⟪धर्म⟫ : («այն, ինչ ամուր է», այսինքն՝) իրավունք, օրենք, սովորույթ, բնութագիր:
Ամենաշատը համապատասխանում է բնական/բարոյական օրենքին: Յուրաքանչյուրն ունի իր սեփական պարտքերը (**svadharma**)՝ ըստ **varṇa**-ի և **āśrama**-ի (կյանքի փուլ):
**adharma** հոգ. ⟪अधर्म⟫ : անիրավություն (**dharma**-ի հակադրություն):
**iṣ** 6 խ. (icchati) ⟪इष् इच्छति⟫ : ցանկանալ (**iṣ-ccha-ti**):

**Որոշ անվանական ածանցումներ:**

**vad** 1 խ. ⟪वद्⟫ : ասել
**vāda** հոգ. ⟪वाद⟫ : արտահայտություն, պնդում, խոսք
**vadana** չեզ. ⟪वदन⟫ : խոսելը; խոսքի գործիք՝ բերան, դեմք

::: media

(Նկարի աղբյուրը՝ [մանրամասներ](/hy/licenses#lekt1102))

**prach** 6 խ. ⟪प्रच्छ्⟫ : հարցնել
**praśna** հոգ. ⟪प्रश्न⟫ : հարց (-**na** վերջավորությունը, ինչպես **yaj-ña**-ում)

**iṣ** 6 խ. ⟪इष्⟫ : ցանկանալ
**iṣṭi** իգ. ⟪इष्टि⟫ : ցանկություն (**iṣ** + **-ti**)

## 11.4. Կրկնության վարժություն

**A) Թարգմանեք սանսկրիտով՝ օգտագործելով անցական ձևերը.**
1. Vaiśya կանայք հարցնում են բրահմաններից դհարմայի մասին։
2. Աշխատակազմը մանտրա է ասում։
3. Սուրբ կանայք հասնում են երկինք։
4. Վեդական մի հայտնաբերող ոչինչ վատ չի անում։
5. Բրահմանները որպես զոհաբերության հովանավորներ պաշտում են աստվածուհուն զոհերով։
6. Śūdra կինը գնում է գյուղ։
7. Ո՞վ է տեսնում ճշմարտությունը։

**B)**
1. Նշեք բոլոր երկուսմբածների (dvija) պարտականությունները՝ օգտագործելով Dvandva կապակցությունը։ Լուծեք սանսկրիտում կազմված բարդ բառը։
2. Նշեք Vaiśya-ների պարտականությունները՝ օգտագործելով Dvandva կապակցությունը։ Լուծեք սանսկրիտում կազմված բարդ բառը։

**C) Թարգմանեք.**

4. ⟪रक्षिक्या गुरू रक्ष्यते⟫ | |
5. ⟪ब्राह्मणेनानृतं नोद्यते⟫ | |
6. ⟪शूद्रेतरा⟫ | |

8. ⟪आन्वीक्षिकीत्रयीवार्त्तादण्डनीतयो विद्याः⟫ ||
