# Դաս 10

## 10.1. Անաջակցական նախադասություն

::: grammar-box
**Սխեմա.**
**(Գործող անձ - kartṛ - գործիական հոլովում (tṛtīyā)) - (ուղիղ խնդիր - karman - հոլովում) - անաջակցական բայի ձև**

Օր. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "Բրահմանը պաշտում է աստծուն զոհաբերությամբ" (լրջորեն՝ "Աստծուն պաշտում է բրահմանը զոհաբերությամբ")

Այս նախադասությունը **լիովին (!) իմաստային** է նախադասության հետ.
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
Անաջակցական նախադասությունում գործող անձը (**kartṛ**) **գործիական** հոլովում է (tṛtīyā f. "երրորդ հոլովում"), ուղիղ խնդիրը (**karman** n.) **հոլովում** է (prathamā f.).
Անաջակցական նախադասություններ, որոնք չեն արտահայտում գործող անձը, սովորաբար ունեն անպատկեր իմաստ ("մարդ").
Օր. **ijyate** = ⟪इज्यते⟫ "Մարդը զոհաբերում է" (լրջորեն՝ "այն զոհաբերվում է զոհաբերությամբ").
:::

::: grammar-box
**Եթե համապատասխան ակտիվ նախադասությունը պարունակում էր դիրքային (dvitīyā) նպատակ, ապա այն կարող է անաջակցական նախադասությունում դրվել հոլովում (prathamā).**

Ակտիվ նախադասությանը **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "Ռաման գնում է գյուղ": համապատասխանում են անաջակցական նախադասությունները.
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
այլընտրանքային. **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**Անցողական բայերը (բայեր առանց ուղիղ խնդրի) հաճախ ունեն անաջակցական կառուցվածքներ, հատկապես բարեխոսական պահանջների դեպքում.**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "Թող մարդը մտնի = Խնդրում ենք մտեք = Մուտք գործեք!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "Թող մարդը նստի = Խնդրում ենք նստեք = Խնդրում ենք տեղավորվեք"
:::
Սանսկրիտյան ակտիվ կառուցվածքները չափազանց հաճախ են հանդիպում. ակտիվը, ի վերջո, ավելի հեշտ է կազմել, քան, օրինակ՝ բազմաթիվ ներկայի արմատներ։

::: important
**Սանսկրիտյան ակտիվ նախադասությունները ընդհանուր առմամբ գերմաներենով չպետք է վերադարձվեն ակտիվ նախադասությամբ, քանի որ գերմանական ակտիվն ունի շատ այլ ոճային գործառույթ։**
:::

### 10.2.1. Գործիական հոլովի (tṛtīyā = ⟪तृतीया⟫) օգտագործման մասին

::: grammar-box
**Գործիական հոլովը (tṛtīyā) հիմնականում պատասխանում է հետևյալ հարցերին.**
**Ինչով՞**
**Ո՞րի միջոցով**
**Կո՞ւմ հետ**

**Այն օգտագործվում է**
1. **անաակտիվ նախադասություններում՝ գործող (kartṛ) արտահայտված է գործիական հոլովով**
2. **միջոցը կամ գործիքը նշելու համար, որով ինչ-որ բան է կատարվում**
3. **ուղին նշելու համար, որով մեկը ինչ-որ տեղ է հասնում**
4. **կապը, միավորումը կամ ուղեկցությունը արտահայտելու համար**
5. **հետադարձ նախդիրների հետ «միասին, հետ» իմաստով. օր. saha = ⟪सह⟫ = «հետ»** :brօր.՝ **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = «բրահմանի հետ միասին»**
:::
Այլ կիրառություններ գործիչ հոլովի (tṛtīyā) համար կգան ավելի ուշ։


## 10.3. Այսպես կոչված լեզվաբանական օրենքը -n-ի համար (բառային սանդհի)

::: grammar-box
**-n-**ը, որին հաջորդում է ձայնավոր կամ **n, m, y, v**, փոխարինվում է **-ṇ-**ով, եթե **ṛ, ṝ, r, ṣ**-ը բառում նախորդում է **-n-**ին, կամ եթե այս ձայնների և հաջորդ **-n-**ի միջև բառում չկան այլ ձայներ, բացի ձայնավորներից, քմայիններից, շրթունքայիններից, **y, v, h**-ից կամ անուսվարայից։
:::
**Հետևաբար:**

::: grammar-box
| | Եզակի գործիչ հոլով |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**Այսպիսով, -ṇ-ը բացատրելի է նաև հետևյալ դեպքերում:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. Պասսիվ, ներկա դարձյալ (yak = ⟪यक्⟫)

::: grammar-box
**Կազմություն:**
**(հիմնականում) խորը աստիճանով արմատ + -ya- + Ātmanepada վերջավորություն**
:::
օրինակ

| Արմատ:br⟪धातु⟫ | 3. եզակի պասսիվ ներկա դարձյալ:br⟪यक् लट्⟫ | 3. հոգնակի պասսիվ ներկա դարձյալ:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"նրան տանում են" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"նրան մտածում են" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"նրան մտնում են" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Ուշադրություն դարձրեք, որ չորրորդ ներկայի դասին պատկանող բայերի դեպքում Ատմանեպադան և լուծականը նույն ձևերն ունեն։ Ատմանեպադա է, թե՞ լուծական, այս դեպքում կարելի է միայն նախադասության շինվածքից եզրակացնել։**



### 10.4.1. Լուծականի կազմության հատուկ կանոններ

1. **-i** կամ **-u** վերջավորությամբ **արմատները** լուծականի հետածանցից **-ya-** առաջ երկարացնում են իրենք վանկը.
* **ji** 1 գործ.: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 գործ.: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 խոս.: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Ուղղակի հնչյունների միջև -a- ունեցող արմատները** (բացառությամբ ընթեղենների, y-ի, r-ի և v-ի) մնում են բարձրաստիճան.
* **labh** 1 Ատ.: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Որոշ արմատներ լուծականը կազմում են բարձրաստիճան** (կամ ներկայի ցուլբառի հնչյունափոխության մակարդակով).
* **āp** 5 գործ.: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 գործ.: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
