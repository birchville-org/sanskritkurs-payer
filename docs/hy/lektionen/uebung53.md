# Վարժություն 53

Դասընթացի վարժությունը բաղկացած է 53-րդ դասում սովորված բոլոր վերստուգանքների մետրիկական վերլուծությունից (Շլոկայի սխեման որոշելը):

Քանի որ դա համակարգված կրկնության և վերլուծական առաջադրանք է, դասական իմաստով առանձին պատասխանների բանալի չկա: Լուծումները ստացվում են՝ կիրառելով 53-րդ դասում սովորեցված կանոնները արդեն հայտնի տեքստերին:
