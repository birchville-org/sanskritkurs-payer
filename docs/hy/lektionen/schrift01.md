# Devanagari = ⟪देवनागरी⟫

## Գրական պարապմունք 1

Սանսկրիտը գրվել է և գրվում է տարբեր այբուբեններով։ Ներկայացված ցանկը տալիս է այդ գրերի մի փոքր հատված.

![](/images/schrift001.webp)  
Նկ.: Սանսկրիտ գրատեսակների նմուշներ
\[Նկարի աղբյուրը. Վիքիպեդիա, GNU FD Լիցենզիա\]

Ամենակարևոր ժամանակակից հյուսիս-հնդկական սանսկրիտ գիրը դևանագարին է.

![](/images/schrift002.webp)

Յուրաքանչյուր բաղաձայն նշանը ցույց է տալիս բաղաձայնին հաջորդող «a» ձայնավորը։ Եթե պետք է գրել միայն բաղաձայնը (առանց հետևող ձայնավորի), դրա համար անհրաժեշտ է նշել ստորին թեք գիծով -- virāma = ⟪विराम⟫ --.

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

Բաղաձայնին հաջորդող ձայնավորները -- բացի «a»-ից -- գրվում են այսպես.

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

Այս բաղաձայն + ձայնավոր միացումների գրման հաջորդականությունը.

![](/images/schrift003.jpg)

Գրելիս յուրաքանչյուր տառ, ներառյալ վերին լայնական գիծը, ամբողջությամբ կատարվում է մինչև հաջորդ տառի գրումը։
