# Դաս 55

## 55.1. a-աորիստը (թեմայով աորիստ)

::: grammar-box
**a-աորիստը կազմվում է ինչպես անցյալի անորոշ դեմքը (⟪लङ्⟫) 6-րդ ներկայի դասի (⟪तुदादि⟫), այսինքն՝.**

**Ավգմենտ + խորացած արմատ + a + երկայնական վերջավորություն**

**-a-ը նույն դեպքերում, ինչ անցյալի անորոշ դեմքում, փոխարինվում է -ā-ով։**

**Ոչ մի նախդիր չկա։**

**Ātmanepada-ն հազվագյուտ է. Ubhayapada արմատների դեպքում այն սովորաբար կազմվում է այլ աորիստ դասերով (տես Kielhorn, Բառարան §340, ինչպես նաև ստորև՝ համապատասխան աորիստ դասերում)։**

**Արմատների ցանկը, որոնք ունեն այս աորիստը՝ Kielhorn, Բառարան §340։**
:::
Օրինակ.
