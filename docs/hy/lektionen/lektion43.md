# Դաս 43

## 43.1. 2-րդ դեմքի անձնական վերջավորություններ (⟪मध्यमः⟫ = «միջին \<դեմք\>»)

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Պրիմար վերջավորություններ** | -si | -tha | -se | -dhve |
| **Սեկունդար վերջավորություններ** | -s | -ta | -thās | -dhvam |
| **Պերֆեկտի վերջավորություններ** | -tha | -a | -se | -dhve |
:::
Ուշադրություն դարձրեք, որ 2-րդ դեմքի հոգնակիի սեկունդար վերջավորությունը նույնական է 3-րդ դեմքի եզակիի թարկային սեկունդար վերջավորությանը։
