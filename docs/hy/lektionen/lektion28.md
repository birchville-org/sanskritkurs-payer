# Դաս 28

## 28.1. Պատճառական բայը (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Եթե ցանկանում ենք հաղորդել, որ ինչ-որ մեկը կամ ինչ-որ բան ստիպում է, առաջացնում կամ պատճառում է, որ մեկ այլ անձ կամ բան կատարի կամ կրի գործողություն, որն արտահայտվում է արմատով (առանց կամ նախդիրով), ապա օգտագործվում է պատճառական բայը (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫).**

Օրինակ՝
⟪गम्⟫ «գնալ» » Պատճառական. ⟪गमयति⟫ «նա ստիպում է, որ մեկ ուրիշը գնա; նա ուղարկում է»
⟪दृश्⟫ «տեսնել» » Պատճառական. ⟪दर्शयति⟫ «նա ցույց է տալիս = նա դարձնում է տեսանելի»
:::

## 28.2. Նախադասության կառուցվածքը պատճառական բայով (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Սխեմա 1.**

**Եթե պատճառական բայի հիմքում ընկած արմատը (առանց կամ նախդիրով) ԱՆԱԿԻ ՎԱՐԵԼԻ Է (այսինքն՝ չի կարող ունենալ գործոռական հանգամանք) կամ արտահայտում է շարժում, գիտելիք, տեղեկատվություն կամ սնունդ.**

**Պատճառականի գործող (⟪कर्ता⟫) հոլովում է ներգործական (⟪प्रथमा⟫) — Ստիպված գործողության գործողը հոլովում է գործոռական (⟪द्वितीया⟫) — (Շարժման նպատակը, գիտելիքի առարկան և այլն հոլովում է գործոռական = ⟪द्वितीया⟫) — Բայը պատճառականում**
:::
Օրինակներ.

⟪दुर्जनो रामं मोहयति⟫ = «վատ մարդը առաջացնում է, որ Ռաման շփոթվի = խառնում է Ռամային = առաջացնում, որ Ռաման սխալվի»
Արդյունք. ⟪रामो मुह्यति⟫ = «Ռաման շփոթված է / կուրացել է / սխալվում է»:

⟪रामः शत्रून्स्वर्गं गमयति⟫ = «Ռաման ստիպում է թշնամիներին երկինք գնալ = ուղարկում է թշնամիներին երկինք»
Արդյունք. ⟪शत्रवः स्वर्गं गच्छन्ति⟫ = «թշնամիները գնում են երկինք / հայտնվում են երկնքում»

⟪गुरू रामं वेदार्थं वेदयति⟫ = «Գուրուն ստիպում է Ռամային Վեդայի իմաստը հասկանալ = բացատրում / դասավանդում է Ռամային Վեդայի իմաստը»
Արդյունք. ⟪रामो वेदार्थं वेत्ति⟫ = «Ռաման ճանաչում է / հասկանում է Վեդայի իմաստը»

⟪स रामं वेदमध्यापयति⟫ = «նա սովորեցնում է Ռամային Վեդան»
Արդյունքը. ⟪रामो वेदमधीते⟫ «Ռաման ուսումնասիրում է Վեդան»

⟪रामो देवानामृतमाशयति⟫ = «Ռաման ստիպում է աստվածներին ուտել անմահության սնունդ = տալիս է աստվածներին անմահության սնունդ ուտելու համար» (⟪अश्⟫ 9 «ուտել»)
Արդյունքը. ⟪देवा अमृतमश्नन्ति⟫ «Աստվածներն ուտում են անմահության սնունդ»

::: media
![](/images/lekt2802.webp)
Նկար. ⟪स नरान्प्रबन्धविज्ञानमध्यापयति⟫
ISKCON տաճար Բանգլոր։
(Նկարի աղբյուրը. [Մանրամասներ](/hy/licenses#lekt2801))
:::

::: grammar-box
**Ըստ սխեմայի 1 կառուցված են նաև ⟪दृश्⟫ արմատը.**

**Սխեմայի 1 բացառությունները տեսեք Սխեմա 2-ի դեպքում**

Օրինակ.
(⟪स⟫) ⟪रामं पुत्रं दर्शयति⟫ = «նա ցույց է տալիս Ռամային որդուն»
:::
Հետևյալ բանաստեղծությունը համակցում է օրինակներ Սխեմա 1-ի համաձայն կաուսատիվ ձևերի կազմության համար (բայական ձևերը 3-րդ դեմքի անցյալ ժամանակի պարասայպադա են).
::: indent
⟪शत्रूनगमयत्स्वर्गं वेदार्थं स्वानवेदयत् । आशयच्चामृतं देवान् वेदमध्यापयद्विधिम् । आसयत्सलिलै पृथ्वीं यः स मे श्रीहरिगतिः ॥⟫
:::

::: indent
Իմ ապաստարանն ու նպատակը Հարին է,
Ով թշնամիներին ուղարկեց երկինք,
Ով սովորեցնում էր իրեններին Վեդայի իմաստը,
Ով սնուցում էր աստվածներին անմահության սնունդով,
Ով սովորեցնում էր ստեղծողին Վեդան,
Ով երկիրը դրեց ջրի մեջ։
:::

Յադավպուր համալսարանի կառավարման շենք։
(Նկարի աղբյուրը. [Մանրամասներ](/hy/licenses#lekt2802))

::: grammar-box
**Սխեմա 2.**

**Երկարող բայերի դեպքում (բացառությամբ Սխեմա 1-ի նշածների)։ Նույնպես բոլոր այն բայերի դեպքում, երբ կաուսատիվով նշված գործողությունը պայմանավորվում է (երբ կաուսատիվը, այսինքն՝ կաուսատիվ է կաուսատիվի համար).**

**Գործող անձը (⟪कर्ता⟫) պատճառականի դեպքում ներածականով (⟪प्रथमा⟫) — խթանված գործողության կատարողը հոլովականով (⟪तृतीया⟫) — խթանված գործողության առարկան այն հոլովում, որը նա կունենար պարզ բայի դեպքում (սովորաբար ներգոլովական) — բայը պատճառականում**
:::
::: indent
Օրինակներ՝
(⟪स⟫) ⟪रामेण भार्यां त्याजयति⟫ = «Նա խթանում է Ռամային, որպեսզի նա լքի իր կնոջը»
Արդյունք՝ ⟪रामो भार्यां त्यजति⟫ = «Ռաման լքում է իր կնոջը»

⟪विष्णुमित्रो रामेण गोविन्दं गमयति⟫ = «Վիշնումիտրան խթանում է Ռամային, որպեսզի վերջինս խթանի Գովինդային գնալու = Վիշնումիտրան ուղարկում է Գովինդային Ռամայի միջոցով»
Արդյունք՝ ⟪रामो गोविन्दं गमयति⟫ = «Ռաման ուղարկում է Գովինդային»
Այս արդյունքի արդյունք՝ ⟪गोविन्दो गच्छति⟫ = «Գովինդան գնում է»
:::
::: grammar-box
**Բացառություններ 1-ին սխեմայի համար՝**

**2-րդ սխեմայով կառուցվում են նաև հետևյալ բայերը՝**

**Կազմվածք պատճառականի համար՝**
**⟪नी⟫ «վարել»/«ղեկավարել»**
**⟪वह्⟫ «շարժվել»/«երթևեկել» (միայն այն դեպքում, երբ խթանված գործողության կատարողը վարորդ չէ)**
**⟪स्मृ⟫ «հիշել»/«մտաբերել» (կան բացառություններ)**
**⟪अद्⟫ «ուտել»**
**⟪खाद्⟫ «ծամել»**
:::
Օրինակներ՝

⟪रामो भृत्येन भारं नाययति वाहयति वा⟫ = «Ռաման թողնում է, որ սպասավորը վարի կամ տանի բեռը»
Արդյունք՝ ⟪भृत्यो भारं नयति वहति वा⟫ = «Սպասավորը վարում կամ տանում է բեռը»

⟪रामो बालेनान्नमादयति खादयति वा⟫ = «Ռաման թողնում է, որ տղան ուտի կամ ծամի սնունդը»
Արդյունք՝ ⟪बालो ऽन्नमत्ति खादति वा⟫ = «տղան ուտում կամ ծամում է սնունդը»

(⟪स⟫) ⟪रामेण स्मारयति⟫ = «Նա առաջացնում է, որ Ռաման հիշի»
Արդյունք՝ ⟪रामः स्मरति⟫ = «Ռաման հիշում է»

::: grammar-box
**Հետևյալ պատճառականները կարող են ինչպես 1-ին, այնպես էլ 2-րդ սխեմայով կառուցվել.**

**⟪हृ⟫ "պահել, բերել"**
**⟪कृ⟫ "անել, արվեստ"**
**Ātmanepadakausativ ⟪दृश्⟫-ին**
:::
Օրինակներ.

⟪रामो भृत्यं कटं कारयति हारयति वा⟫ = "Ռաման թողնում է սպասավորին մատ (⟪कट⟫ m.) անել կամ բերել"
կամ.
⟪रामो भृत्येन कटं कारयति हारयति वा⟫
Արդյունք. ⟪भृत्यः कटं करोति हरति वा⟫ = "Սպասավորը անում կամ բերում է մատ"

⟪रामो बालं प्रतिमां दर्शयते⟫ = "Ռաման թողնում է տղային պատկերը տեսնել = ցույց է տալիս տղային պատկերը (իր շահի համար)"
կամ.
⟪रामो बालेन प्रतिमां दर्शयते⟫
Արդյունք. ⟪बालः प्रतिमां पश्यति⟫ = "տղան տեսնում է պատկերը"

Եթե պատճառականը կիրառվում է թղթակցության կառույցով, ապան գրեթե միշտ հետևյալ սխեման է կիրառվում.

::: grammar-box
**Սխեմա A (թղթակցության կառույց).**

**Պատճառականի գործողը ինստրումենտալով (⟪तृतीया⟫) — Ներառված գործողության գործողը նոմինատիվով (⟪प्रथमा⟫) — Ներառված գործողության օբյեկտը այն կազմով, որն ուներ պարզ բայի դեպքում (սովորաբար ակուզատիվ) — Պատճառական բայ**
:::
Օրինակներ.

⟪गुरुणा रामो ग्रामं गम्यते⟫ = "Ստեղծագործը Ռամային ուղարկում է գյուղ"
Արդյունք. ⟪रामो ग्रामं गच्छति⟫ = "Ռաման գնում է գյուղ"

⟪रामेण भृत्यः कटं कार्यते⟫ = "Ռաման թողնում է սպասավորին մատ անել"
Արդյունք. ⟪भृत्यः कटं करोति⟫ = "Սպասավորը անում է մատ"

⟪रामेण भृत्यो भारं हार्यते⟫ = "Ռաման թողնում է սպասավորին բեռը բերել"
Արդյունք. ⟪भृत्यो भारं हरति⟫ = "Սպասավորը բերում է բեռը"


## 28.3. Ձևավորում ներկայի արմատը պատճառականի համար (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Պատճառականի արմատին միանում են ներկայի թեմատական վերջավորությունները**
:::
Գոյություն ունեն տարբեր ձևավորման տիպեր.

::: grammar-box
**Ձևավորման տիպ 1. (հիմնականում) բարձրաստիճան արմատ + -aya-**
:::
Օրինակներ.
