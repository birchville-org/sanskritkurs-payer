## 44.2. Տառակցման մասին

Բաղաձայնով ավարտվող ներկա ժամանակի արմատների դեպքում պետք է հաշվի առնել տառակցման արդեն դիտարկված կանոնները։

Բացի այդ, կիրառվում են նաև հետևյալ տառակցման կանոնները։

(Այս բաժնին վերաբերող բոլոր ձայնական փոփոխությունների մանրամասն հավաքածուն՝ Կիելհորն, Քերականություն էջ 76-77)

### 44.2.1. dh- տառակցման մասին

::: grammar-box

1. **Շնչաբեր բաղաձայնը շնչաբերից առաջ փոխարինվում է համապատասխան ոչ շնչաբերով.**
օր. ⟪रुध्⟫ 7U: ⟪रुन्ध्⟫ + ⟪ध्वे⟫ » ⟪रुन्द्ध्वे⟫ (run**ddh**ve)
2. **-h + dh- » -gdh-**
օր. ⟪दुह्⟫ 2U: ⟪दुह्⟫ + ⟪ध्वे⟫ » ⟪धुग्ध्वे⟫ (dhu**gdh**ve)
3. **-ṣ + dh- » -ḍḍh-** (Այս կանոնը վերաբերում է միայն խոնարհմանը!)
օր. ⟪द्विष्⟫ 2U: ⟪द्विष्⟫ + ⟪ध्वे⟫ » ⟪द्विड्ढ्वे⟫ (dvi**ḍḍh**ve)
4. **-s + dh- » -dh-** (-s-ի վերացում)
օր. ⟪आस्⟫ 2Ā: ⟪आस्⟫ + ⟪ध्वे⟫ » ⟪आध्वे⟫ (ādhve)

:::

### 44.2.2. s- տառակցման մասին

::: grammar-box

1. **-s + s- » -ts- կամ (ոչ ընտրովի!) -ss-** (ինչպես 2-րդ նախնական դասում)
Օրինակներ.
* ⟪वस्⟫ 1P: Ապագա ժամանակ. ⟪वस्⟫ + ⟪स्य⟫ + ⟪ति⟫ » ⟪वत्स्यति⟫ (va**ts**yati)
* ⟪वस्⟫ 2Ā: ⟪वस्⟫ + ⟪से⟫ » ⟪वस्से⟫ (va**ss**e)
2. **-ṣ + s- » -kṣ-**
օր. ⟪द्विष्⟫ 2U: ⟪द्वेष्⟫ + ⟪सि⟫ » ⟪द्वेक्षि⟫ (dve**kṣ**i)

:::

## 44.4. Հրավիրականը (⟪आमन्त्रितम्⟫)

Տեղական քերականները հրավիրականը (⟪आमन्त्रितम्⟫) չեն դիտարկում որպես առանձին հոլով, այլ միայն ներգործականի (⟪प्रथमा⟫) մոդիֆիկացիա։

::: important

**Հրավիրականը ծառայում է կանչին, դիմելուն և գտնվում է նախադասության մյուս մասի հետ կապից դուրս, այսինքն՝ տարբերվում է մյուս հոլովներից, որոնք արտահայտում են կապը բայի կամ այլ գոյականի հետ։**

**Հաճախ հրավիրականը տեղադրվում է նախադասության սկզբում.**

:::

::: indent

⟪बाल किं वदसि⟫ = «Երեխա, ի՞նչ ես ասում»։
