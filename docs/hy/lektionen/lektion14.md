# Դաս 14

## 14.1. Որակական հարաբերության արտահայտումը գոյականներով նշվածի համար. շեշտակ (ṣaṣṭhī f. = ⟪षष्टी⟫ = վեցերորդ հոլովի վերջավորություն)

::: grammar-box

Եթե պետք է արտահայտել երկու գոյականներով նշվածի միջև հարաբերությունը, օգտագործվում է շեշտակը (ṣaṣṭhī f. «վեցերորդ հոլովի վերջավորություն»): Շեշտակը տարբերվում է մնացած բոլոր հոլովներից նրանով, որ այն — քիչ բացառություններով — չի ծառայում գործողությամբ արտահայտվածի մանրամասն նշման համար, այլ օգտագործվում է գոյականներով նշված անձանց կամ առարկաների միջև հարաբերությունը արտահայտելու համար: Հաճախ շեշտակը պատասխանում է «ովն է?» հարցին:

:::

Օրինակներ.

⟪कवेः पुत्रः⟫ «Գրողի որդին»

⟪धनस्य लोभः⟫ «Հարստության ձգտում»

⟪नगरस्यार्धम्⟫ «Քաղաքի կեսը»

⟪रामस्य कृतम्⟫ «Ռամայի գործը / Մեկ գործ Ռամայի»

::: grammar-box

Սովորական բառերի դասավորությունն է.

> **Շեշտակով որոշող բառ — Մանրամասնված գոյականը այլ հոլովում**

:::

**Շեշտակ և PPP.**

::: grammar-box

PPP-ների դեպքում շեշտակը կարող է փոխարինել գործիքականին (tṛtīyā) կատարողի (kartṛ) համար. Գործիքականով կառուցվածքում PPP-ն դիտարկվում է որպես անցողական բայաձև (գործիքականում գտնվողը նշում է կատարողին), իսկ շեշտակով կառուցվածքում PPP-ն դիտարկվում է որպես գոյական կամ ածական (շեշտակում գտնվողը իրականում կատարող չէ):

Ըստ Pāṇini-ի 2.3.67՝ PPP-ների դեպքում շեշտակն օգտագործվում է, եթե PPP-ն ներկա ժամանակի իմաստ ունի (տես վերևում), գործիքականը՝ եթե PPP-ն անցյալ ժամանակի իմաստ ունի.

> ⟪रामस्येष्टं फलम्⟫ «Ռամայի կողմից ցանկալի պտուղը = Պտուղը, որին այսօր ցանկանում է Ռաման»
> 
> ⟪रामेणेष्टं फलम्⟫ «Պտուղը, որին ցանկացել է Ռաման»

Անպայման, երբ PPP-ի չեզոք հոգնակի միայնակը օգտագործվում է որպես բայական աբստրակտ՝ այսինքն՝ որպես գոյական, ապա շեշտը դրվում է սեռական հոլովի վրա։

:::

## 14.2. Սեռական հոլովի ձևերի կազմումը (ṣaṣṭhī f. = ⟪षष्ठी⟫)

Սեռական հոլովը բայական արմատների դեպքում, որտեղ կա արմատային փոփոխություն, ձևավորվում է թույլ արմատից։

**Բաղաձայնով ավարտվող արմատների սեռական հոլովը.**

::: grammar-box

Բաղաձայնից հետո կան չափավոր սեռական վերջավորությունները.
* Միայնակ՝ **-as**
* Հոգնակի՝ **-ām**

:::

::: center

| Գոյական արմատ | Թույլ արմատ | Սեռական միայնակ | Սեռական հոգնակի |
| :--- | :--- | :--- | :--- |
| **guṇa-vant-** :br ⟪गुणवन्त्⟫ | **guṇa-vat-** :br ⟪गुणवत्⟫ | **guṇa-vat-as** :br ⟪गुणवतस्⟫ | **guṇa-vat-ām** :br ⟪गुणवताम्⟫ |
| **paśu-mant-** :br ⟪पशुमन्त्⟫ | **paśu-mat-** :br ⟪पशुमत्⟫ | **paśu-mat-as** :br ⟪पशुमतस्⟫ | **paśu-mat-ām** :br ⟪पशुमताम्⟫ |

:::

**Բաղաձայնով ավարտվող արմատների սեռական հոլովը, բացառությամբ միահնչյուն արմատական գոյականների և դիֆթոնգով ավարտվող արմատների.**

**Հոգնակի.**

::: grammar-box

Բաղաձայնով ավարտվող արմատների սեռական հոգնակին ձևավորվում է այսպես.

> **-երկար ավարտվող վանկի + -nām**

:::

::: center

| Գոյական արմատ | Սեռական հոգնակի |
| :--- | :--- |
| **deva** m.:br ⟪देव⟫ | **devā-nām** :br ⟪देवानाम्⟫ |
| **phala** n.:br ⟪फल⟫ | **phalā-nām** :br ⟪फलानाम्⟫ |
| **devatā** f.:br ⟪देवता⟫ | **devatā-nām** :br ⟪देवतानाम्⟫ |
| **kavi** m.:br ⟪कवि⟫ | **kavī-nām** :br ⟪कवीनाम्⟫ |
| **śruti** f.:br ⟪श्रुति⟫ | **śrutī-nām** :br ⟪श्रुतीनाम्⟫ |
| **devī** f.:br ⟪देवी⟫ | **devī-nām** :br ⟪देवीनाम्⟫ |
| **paśu** m.:br ⟪पशु⟫ | **paśū-nām** :br ⟪पशूनाम्⟫ |
| **dhenu** f.:br ⟪धेनु⟫ | **dhenū-nām** :br ⟪धेनूनाम्⟫ |

:::

**Եզակի գենիտիվ՝ վանկավորված հոդերով.**

::: grammar-box

Եզակի գենիտիվը վանկավորված հոդերով կազմվում է անկանոն, և այն լավ է պահպանել հիշողության մեջ։

:::

**Ձևերի հավասարություն:**

::: important

Բոլոր նախադասական հոդերի դեպքում, բացառությամբ լինելիք և չեզոք հոդերի -a վերջավորությամբ և դերանունների, եզակի գենիտիվի ձևը նույնն է, ինչ աբլատիվի (pañcamī "հինգերորդ կազմական վերջավորություն") եզակի ձևը։

Նկատի ունեցեք, որ բաղաձայնով ավարտվող արմատների դեպքում աբլատիվը և գենետիվը միասին հնչում են, ինչպես ակուզատիվը՝ հոգնակի զանգվածային և կանացի սեռերում:

:::

## 14.3. Գենետիվի կիրառման մասին (⟪षष्ठी⟫)

::: grammar-box

Վերը նշված հիմնական կանոնին հակառակ՝ գենետիվը օգտագործվում է որոշ բայերի իրականացնելու համար, օրինակ՝ հիշողության բայերի դեպքում:

> ⟪देवानां स्मरति⟫ «Նա հիշում է աստվածներին»

Սակայն այս բոլոր բայերի դեպքում իրականացնողը կարող է նաև ակուզատիվում լինել:

> ⟪देवान्स्मरति⟫ «Նա հիշում է աստվածներին»

Ավելին՝ հետո:

:::

## 14.4. Բառացանկ

* **bhūṣ-aṇa n** (⟪भूषण⟫) : զարդ
* **dīpa m.** (⟪दीप⟫) : լամպ

## 14.5. Subhāṣitāni = ⟪सुभाषितानि⟫ = Առածներ

Թարգմանեք հետևյալ առածները և պահպանեք դրանք հիշողության մեջ.

**⟪नीचो वद⟫ati ⟪न कुरुते⟫** **⟪वदति न साधुः करोत्येव ॥१॥⟫**

**⟪शीलं नरस्य भूषणम् ॥२॥⟫**

**⟪सत्येन जनानां सुखं भवति ॥३॥⟫**

**⟪पापा नराः स्वर्गं न लभन्ते ॥४॥⟫**

**⟪सत्यं लोकस्य दीपः ॥५॥⟫**
