# Դաս 21

## 21.1. Ներկայի այլ բազաներ -nt վերջավորությամբ

### 21.1.1. Ներկայի մասնակի (⟪लडादेशः⟫) Պարասմայպադա

::: grammar-box
Այս մասնակին անվանական ածանցում է ներկայի բազայից, այսինքն՝ իրական մասնակի։ Այն ածական է, որը ցույց է տալիս, թե ով կամ ինչ է հենց այժմ անում վերաբերյալը զարկերակի (+ նախածանց) կողմից արտահայտված գործողությունը, մինչդեռ տեղի է ունենում այլ իրադարձություն։ Կարելի է նաև արտահայտել մշտական վիճակ։

**Օրինակներ.**

:::
::: indent
"Մինչ հայրը կարդում է, նա ծխում է = կարդացող հայրը ծխում է"  
"լինող (= իրական, իսկական) բարեկամ"
:::
::: grammar-box

| **Ներկայի մասնակու Պարասմայպադայի կազմությունը թեմատիկ ներկայի բազաների համար.** |||
| :--- | :--- | :--- |
| **Հոդակիր, Չեզոք** | | |
| | **ուժեղ բազա** | Ներկայի բազա + **-nt-** |
| | **թույլ բազա** | Ներկայի բազա + **-t-** |
| **Իգական** | | |
| | | Ներկայի բազա + **-nt-** + **-ī** (ձևափոխությունը ինչպես **devī** :br⟪देवी⟫) |
| | **6-րդ ներկայի դաս** | Ներկայի բազա + **-nt-** + **-ī** :broder::brՆերկայի բազա + **-t-** + **-ī** |

:::

## 21.3. Հարգալից դիմումների ձևեր

::: grammar-box
**Սանսկրիտով կարելի է դիմել մեկին երկրորդ դեմքով՝ առանց անհարգալից լինելու։ Եթե սակայն ուզում եք հարգալից լինել, կարող եք օգտագործել բառ, որի իմաստը «հարգարժան» է և այլն, և բայը դնել երկրորդ դեմքի միակամ կամ հոգնակի ձևով, կամ օգտագործել անցողական ձև։ Հարգալից դիրքը դիմումների օգտագործման ընթացքում մոտավորապես հետևյալն է.**

:::
::: indent
**2. միակամ » 2. հոգնակի » 3. միակամ՝ համապատասխան բառով » 3. հոգնակի՝ համապատասխան բառով**
:::
**Ամենակարևոր այդպիսի հարգալից բառը ⟪भवन्त्⟫ է, չեզոք՝ ⟪भवती⟫։ Այն համապատասխանում է մեր «Դուք»-ին։**
Այս ⟪भवन्त्⟫-ը կրճատված է ⟪भगवन्त्⟫-ից, նրա դեկլինացիան -vant վերջավորությամբ անունների դեկլինացիան է (տես [Դաս 13](lektion13.md))։ Այս ⟪भवन्त्⟫-ը պետք է տարբերել ⟪भू⟫ "դառնալ" բայի P մասնակյանից ⟪भवन्त्⟫։ 3. միակամ չեզոք ⟪भवन्त्⟫-ի համար ճիշտ է ⟪भवान्⟫, մասնակյանի համար՝ ⟪भवन्⟫։

**Օրինակներ.**

::: indent
**⟪किं भवान्करोति⟫** = **⟪किं भवता क्रियते⟫** = «Ի՞նչ եք անում»:
:::
Ուղեկցող.

::: indent
**⟪किं भवन्तः कुर्वन्ति⟫** = **⟪किं भवद्भिः क्रियते⟫**
:::
Գոյական.
