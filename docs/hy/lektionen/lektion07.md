# Դաս 7


::: center
**Շաբաթվա ընդօրինակելի արտահայտություն**
:::


::: center
⟪धर्मो जयति नधर्मः सत्यं जयति नानृतम् | क्षमा जयति न क्रोधो देवो जयति नासुरः ||⟫

**dharmo jayati nādharmaḥ**
**satyaṃ jayati nānṛtam |**
**kṣamā jayati na krodho**
**devo jayati nāsuraḥ ||**

Արդարությունը հաղթում է, ոչ թե անարդարությունը,
Ամբողջական ճշմարտությունը հաղթում է, ոչ թե կեղծիքը,
Համբերությունը հաղթում է, ոչ թե բարկությունը,
Աստված հաղթում է, ոչ թե դիմացկունը։
:::


## 7.1. Բայական նախադասությունը ուղիղ խնդրով

::: grammar-box
**Սխեմա.**
**(Գործող = kartṛ m. = ⟪कर्तृ⟫) – ուղիղ խնդիր (karman n. = ⟪कर्मन्⟫) – բայ**

օրինակ
**rāmaḥ phalaṃ khādati** = ⟪रामः फलं खादति⟫ : «Ռաման ուտում է (կերակրում) մի պտուղ։»
**brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो देवं यजति⟫ : «Բրահմանը պաշտում է աստծուն զոհաբերությամբ (մեկ այլ անձի համար)։»
:::
Եթե բայը գտնվում է Parasmaipada կամ Ātmanepada ձևով, ապա ուղիլ խնդիրը (**karman** n. = ⟪कर्मन्⟫) ընդհանուր առմամբ գտնվում է **Ուղիղ հոլովում** (Wenfall, dvitīyā f. = ⟪द्वितीया⟫):


## 7.2. Ուղիղ հոլովում (Wenfall, dvitīyā f. = ⟪द्वितीया⟫ = «երկրորդ կազմակերպչական վերջավորություն»)

::: grammar-box
**Ուղիղ հոլովման միասնական թվի տղամարդկային և կանացի սեռերի վերջավորությունը՝ -m**

| Տղամարդկային սեռի վերջավորություններ | Ուղիղ հոլովում միասնական թվով |
| :--- | :--- |
| **-a**: deva | **devam** :br⟪देवम्⟫ |
| **-i**: kavi | **kavim** :br⟪कविम्⟫ |
| **-u**: guru | **gurum** :br⟪गुरुम्⟫ |
| Կանացի սեռի վերջավորություններ | Ուղիղ հոլովում միասնական թվով |
| **-ā**: devatā | **devatām** :br⟪देवताम्⟫ |
| **-i**: śruti | **śrutim** :br⟪श्रुतिम्⟫ |
| **-ī**: devī | **devīm** :br⟪देवीम्⟫ |
| **-u**: dhenu | **dhenum** :br⟪धेनुम्⟫ |
:::
::: grammar-box
**Հոլովական հոգնակի զանգվածային բառերի վրա հիմնված արմատներ (բացառություն՝ երկսլավակ արմատային արմատները երկար ձայնավորով). Այսպես կոչված, ելքային ձայնավորի երկարացում + -n**

| Զանգվածային բառերի վրա հիմնված | Հոլովական հոգնակի |
| :--- | :--- |
| **-a**: deva | **devān** :br⟪देवान्⟫ |
| **-i**: kavi | **kavīn** :br⟪कवीन्⟫ |
| **-u**: guru | **gurūn** :br⟪गुरून्⟫ |
:::
::: grammar-box
**Հոլովական հոգնակի զանգվածային բառերի վրա հիմնված արմատներ (բացառություն՝ երկսլավակ արմատային արմատները երկար ձայնավորով). Այսպես կոչված, ելքային ձայնավորի երկարացում + -s**

| Զանգվածային բառերի վրա հիմնված | Հոլովական հոգնակի |

| **-i**: śruti | **śrutīs** :br⟪श्रुतीस्⟫ |
| **-ī**: devī | **devīs** :br⟪देवीस्⟫ |

### 7.2.1. Հարցական և դեմոնստրատիվ ժամանակաշրջանների միասնական և հոգնակի ձևերը

::: grammar-box
| || Զանգվածային բառերի վրա հիմնված | Զանգվածային բառերի վրա հիմնված | Զանգվածային բառերի վրա հիմնված |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :brwer/was | sg. | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |
| | pl. | **kān** :br⟪कान्⟫ | **kās** :br⟪कास्⟫ | **kāni** :br⟪कानि⟫ |
| **tad** :brer/es/jenes | sg. | **tam** :br⟪तम्⟫ | **tām** :br⟪ताम्⟫ | **tad** :br⟪तद्⟫ |
| | pl. | **tān** :br⟪तान्⟫ | **tās** :br⟪तास्⟫ | **tāni** :br⟪तानि⟫ |
| **etad** :brdieses hier | sg. | **etam / enam** :br⟪एतम्⟫ / ⟪एनम्⟫ | **etām / enām** :br⟪एताम्⟫ / ⟪एनाम्⟫ | **etad / enad** :br⟪एतद्⟫ / ⟪एनद्⟫ |
| | pl. | **etān / enān** :br⟪एतान्⟫ / ⟪एनान्⟫ | **etās / enās** :br⟪एतास्⟫ / ⟪एनास्⟫ | **etāni / enāni** :br⟪एतानि⟫ / ⟪एनानि⟫ |
| **idam** :brdieses | sg. | **imam / enam** :br⟪इमम्⟫ / ⟪एनम्⟫ | **imām / enām** :br⟪इमाम्⟫ / ⟪एनाम्⟫ | **idam / enad** :br⟪इदम्⟫ / ⟪एनद्⟫ |
| | pl. | **imān / enān** :br⟪इमान्⟫ / ⟪एनान्⟫ | **imās / enās** :br⟪इमास्⟫ / ⟪एनास्⟫ | **imāni / enāni** :br⟪इमानि⟫ / ⟪एनानि⟫ |
:::
Ձևերը **enam** (⟪एनम्⟫) և այլն պատկանում են **enad** (⟪एनद्⟫) արմատին, որը ձևավորում է ձևեր միայն որոշ հոլովներում։ Այս ձևերը **etad** և **idam** ձևերի փոխարեն օգտագործվում են, երբ դրանք նշածը արդեն հիշատակվել է նախորդ տեքստում։
օր․ **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं देवः⟫ | ⟪एनं यजन्ते⟫ || : «Նա աստված է։ Նրան նահատակում են»։


### 7.2.2. Ուղղականի (վերացական հոլով, dvitīyā f. = ⟪द्वितीया⟫ = «երկրորդ հոլով») օգտագործումը

::: grammar-box
Ուղղականը (dvitīyā f. = ⟪द्वितीया⟫) նշանակում է՝
1. Ոչ պասսիվ բայական նախադասության մեջ՝ **ուղղակի խնդիր** (karman n. = ⟪कर्मन्⟫) բայով արտահայտված գործողության համար՝
օր․
**devaṃ yajati** = ⟪देवं यजति⟫ : «Նա նահատակում է աստծուն»։
**phalam āpnoti** = ⟪फलमाप्नोति⟫ : «Նա ստանում է պտուղը (օր․ իր գործողության)»։
2. Այն բայերի դեպքում, որոնք արտահայտում են գնալը, շարժումը, տանելը կամ նմանատիպ գործողությունները որևէ բանի ուղղությամբ, ուղղականը նշում է շարժման նպատակը՝
օր․
**narakaṃ gacchati** = ⟪नरकं गच्छति⟫ : «Նա գնում է դժոխք»։
:::
Ուղղականի այլ կիրառությունները քննարկվելու են հետագայում։



## 7.3. Վերջանող -n-ի սանդհին

::: grammar-box
**Վերջանող -n-ը.**

1. Միաձայն պալատական և ռետրոֆլեքս sparśa-ների և **ś-** առաջ փոխարինվում է այդ ձայներին համապատասխան նիզականով՝
**-n** **j-, jh-, ñ-, ś-** առաջ » **-ñ**
**-n** **ḍ-, ḍh-, ṇ-, ṣ-** առաջ » **-ṇ**
օր․ **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : «Նա հաղթում է կշատրիյաներին»։
Սկզբնական **ś-** սովորաբար փոխարինվում է **ch**-ով՝
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (նաև gurūñ śṛṇoti) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : «Նա լսում է ուսուցիչներին»։ «Նա լսում է ուսուցիչների խոսքը»։

2. Նախակերպ **l-****-n**-ի դեպքում փոխարինվում է **-l**-ով՝ անունասիկայով (նախակերպ l, գրվածքում ⟪ल्⟫ անունասիկայով ⟪ँ⟫):
օր. **paśūn + labhate** » ⟪पशूंल्लभते⟫ : «Նա ստանում է օգտակար կենդանիներ»:

3. Նախակերպ անձայն հոշոտ, ռետրեքս կամ դենթալ բաղաձայնների դեպքում փոխարինվում է **անուսվարա** + այդ ձայներին համապատասխանող շշուկով:
**-n** **c-, ch-** առաջ » **-ṃś**
**-n** **ṭ-, ṭh-** առաջ » **-ṃṣ**
**-n** **t-, th-** առաջ » **-ṃs**
օր. **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : «և աստվածները (հոլ.)»
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : «բայց աստվածները (հոլ.)»

4. Կարճ ձայնավորից հետո (տես հետագա) մնում է անփոփոխ բոլոր այլ դեպքերում:
:::

## 7.5. Աթեմատիկ ներկա դասեր

5-րդ ներկայի դասը կազմում է այսպես կոչված աթեմատիկ ներկայի արմատ, այսինքն՝ ներկայի արմատը չի վերջանում «թեմաձայնավորով» **-a**, ինչպես թեմատիկ ներկայի դասերում (1., 4., 6., 10. դաս):

::: grammar-box
**Աթեմատիկ ներկայի դասերն ունեն արմատական իջեցում, այսինքն՝ կան ներկայի արմատի երկու ձև:**
1. **ուժեղ արմատ**: բարձրաստիճան (հազվադեպ երկարաստիճան)
2. **թույլ արմատ**: ցածրաստիճան

**Հզոր արմատը կանգնած է.**
Ցուցական եղանակի միասնական հոլովում՝ Պարամեսիպադա ներկա (laṭ) և անցյալ ժամանակ (laṅ)
Ապացուցական եղանակի բոլոր առաջին դեմքեր՝ Պարամեսիպադա և Ատմանեպադա
Ապացուցական եղանակի երրորդ դեմք, միասնական հոլովում՝ Պարամեսիպադա

**Բոլոր մնացած ձևերը ունեն թույլ ներկայի արմատ։**
:::
### 7.5.1. Վեցերորդ դասի եզրաձևերը անհոգնային արմատների համար

::: grammar-box
**Անհոգնային ներկա արմատների դեպքում վեցերորդ դասի եզրաձևերը հետևյալն են.**
**Պարամեսիպադա։ -anti**
**Ատմանեպադա։ -ate**
:::
### 7.5.2. Հինդուի դաս (svādi = ⟪स्वादि⟫ = "su և այլն")

::: grammar-box
**Հզոր արմատ**։ (հիմնականում) խորը աստիճանի արմատ (ինչպես նշված է) + **-no-**
**Թույլ արմատ**։ (հիմնականում) խորը աստիճանի արմատ (ինչպես նշված է) + **-nu-**

**Երկարաձայն եզրաձևերի դեպքում, եթե արմատը վերջանում է ձայնավորով, -nu- փոխարինվում է -nv-, իսկ եթե կոնsonantով, ապա վանկարմատից հետո -nu- փոխարինվում է -nuv-.**
:::

## 7.6. բառացանկ

**Սովորեք հետևյալ բառերը.**

**aś** 5 Ā (aśnute) ⟪अश् अश्नुते⟫ : հասնել, ձեռք բերել
**āp** 5 P (āpnoti) ⟪आप् आप्नोति⟫ : հասնել, ձեռք բերել
**kup** 4 P (kupyati) ⟪कुप् कुप्यति⟫ : զայրանալ
**krudh** 4 P (krudhyati) ⟪क्रुध् क्रुध्यति⟫ : զայրանալ
**khād** 1 P (khādati) ⟪खाद् खादति⟫ : ծամել, ուտել
**śru** 5 P (śṛṇoti !) ⟪श्रु शृणोति⟫ : լսել (ինչ-որ բան՝ ուղիղ հոլով, ինչ-որ մեկին՝ սեռական կամ ուղիղ հոլով; ինչ-որ մեկից՝ սեռական, հայցական կամ գործիքական)
**su** 5 U (sunoti) ⟪सु सुनोति⟫ : սեղմել
**soma** m. ⟪सोम⟫ : սեղմած խմիչք, սոմա; Լուսին (Որ բույսից է սոման սեղմվել, մինչ օրս վիճելի է):
::: media
![](/images/lekt0701.webp)
Նկ.: Արդյո՞ք դա վեդական սոմայի բույսն էր. Մակարակը՝ *Amanita muscaria* (L.) Lam.
(Լուսանկարի աղբյուրը՝ [մանրամասներ](/hy/licenses#lekt0701))
:::
**phala** n. ⟪फल⟫ : պտուղ (նաև փոխաբերական իմաստով՝ (կարմի) արդյունքը գործից)
**nṛtya** n. ⟪नृत्य⟫ : պար
**svarga** m. ⟪स्वर्ग⟫ : երկինք
**naraka** m. ⟪नरक⟫ : դժոխք (ըստ հինդուական պատկերացման՝ տիեզերքն ունի ձվաձև ձև (**Brahmāṇḍa** m.n. = ⟪ब्रह्माण्ड⟫ = "Բրահմայի ձու"). Երկրի վերևում կան վեց երկինք՝ աճող բախտով, Երկրի տակ կան յոթ այսպես կոչված **pātāla** n. = ⟪पाताल⟫, **nāga** m. = ⟪नाग⟫ (օձեր) և այլ առասպելական էակների բնակավայրեր, որտեղ կան յոթ դժոխքներ՝ աճող տառապանքով)
**aṅga** n. ⟪अङ्ग⟫ : մարմնի անդամ, բաղկացուցիչ; նաև = **vedāṅga** = ⟪वेदाङ्ग⟫
**gam** 1 P (gacchati) ⟪गम् गच्छति⟫ : գնալ (ըստ տեղական դասակարգման՝ պատկանում է 1-ին ներկա ժամանակի դասին, բայց իրականում ստեղծված է ներկա արմատի **-ccha-** վերջավորությամբ. **gam** » խոր աստիճան (**gm** ») **ga-ccha-ti**)




## 7.7. Վարժություն

**Ա) Տեղադրեք միայնակ և հոգնակի թվերում ուղղական կամ ուղղություն արտահայտող հոլովը.**

⟪ब्राह्मणस्⟫ ... ⟪यजति⟫ (⟪देव⟫, ⟪देवी⟫, ⟪विष्णु⟫, ⟪अग्नि⟫, ⟪देवता⟫)
