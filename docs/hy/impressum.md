# Տեղեկություն, հեղինակային իրավունք և մատնանշման կարգը

*Հետևյալ տեքստը դուրս է մղվել դասերի ֆայլերից վերածնման ընթացքում՝ կարդալու հոսունությունը բարելավելու նպատակով։*

## Մատնանշման կարգը | cite as:
**Payer, Alois \<1944 - \>:** Sanskritkurs. -- 2010 թ. տարբերակ։ -- URL: http://www.payer.de/sanskritkurs/

## Նպատակը
Ստեղծվել է 1980 - 1984 թթ. ուսումնական դասընթացների համար

## Հեղինակային իրավունք
Այս տեքստը հասանելի է ընդհանուր օգտագործման համար։
Հրապարակումներում օգտագործման համար, որը գերազանցում է սովորական մատնանշումներին, անհրաժեշտ է հեղինակի բացահայտ թույլտվությունը։

Այս տեքստը **Tüpfli's Global Village Library**-ի Sanskrit բաժնի մաս է կազմում։
