# Lesson 45

## 45.1. Formation of the 2nd person verbal forms (⟪मध्यमः⟫) of athematic stems without vocally ending suffix (continuation)

| **Optative** :br⟪विधिलिङ्⟫ | ⟪जुहुयास्⟫ | ⟪जुहुयात⟫ | \&lt;⟪जुह्वीथास्⟫\&gt; | \&lt;⟪जुह्वीध्वम्⟫\&gt; |

### 45.1.2. Seventh present class (⟪रुधादि⟫)

::: grammar-box
**If a final k/g of the root comes to stand between the nasal ṅ and a dental of the ending, then the k/g may optionally drop**

e.g. **⟪युज्⟫** 3.sg.Ind.Pres.Ā ⟪युङ्क्ते⟫ or ⟪यु⟫***⟪ङ्ते⟫***
:::
⟪युज्⟫ 7U

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Indikativ Present** :br⟪लट्⟫ | ⟪युनक्षि⟫:bryu-na-j + si | ⟪युङ्क्थ⟫:br⟪युङ्थ⟫ | ⟪युङ्क्षे⟫ | ⟪युङ्ग्ध्वे⟫:br⟪युङ्ध्वे⟫ |
| **Imperfect** :br⟪लङ्⟫ | ⟪अयुनक्⟫:braus: a-yu-na-j + s | ⟪युङ्क्त⟫:br⟪अयुङ्त⟫ | ⟪अयुङ्क्थास्⟫:br⟪अयुङ्थास्⟫ | ⟪अयुङ्ग्ध्वम्⟫:br⟪अयुङ्ध्वम्⟫ |
| **Optative** :br⟪विधिलिङ्⟫ | ⟪युञ्ज्यास्⟫ | ⟪युञ्ज्यात⟫ | ⟪युञ्जीथास्⟫ | ⟪युञ्जीध्वम्⟫ |
:::

## 45.2. The vocative singular (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**Most vocatives of the singular are the stem with a strong ending.**

e.g. **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** etc.

**Exceptions are the feminine nouns ending in -ā and -ī as well as the stems ending in -in, whose vocative sg. is particularly noteworthy.**
:::
::: no-header
| | Vocative Singular |
| --- | --- |
| Maskulina auf -a | ⟪देव⟫ |
| Neutra auf -a | ⟪फल⟫ |
| Feminina auf -ā | ⟪देवते⟫ |
| Maskulina auf -i | ⟪कवे⟫ |
| Feminina auf -i | ⟪मते⟫ |
| Maskulina auf -u | ⟪शत्रो⟫ |
| Feminina auf -u | ⟪धेनो⟫ |
| Feminina auf -ī | ⟪देवि⟫ |
| Maskulina auf -ṛ | ⟪पितर्⟫ |
| Feminina auf -ṛ | ⟪मातर्⟫ |
| Maskulina auf -an | ⟪राजन्⟫ |
| Neutra auf -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Maskulina auf -man/-van | ⟪आत्मन्⟫ |
| Maskulina auf -in | ⟪बलिन्⟫ |
| Maskulina auf -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt m. | ⟪महन्⟫ |
| mahānt n. | ⟪महत्⟫:br= Nominative |
| Maskulina auf -mant/-vant | ⟪गुणवन्⟫ |
| Neutra auf -mant/-vant | ⟪गुणवत्⟫:br= Nominative |
| Pronouns | ein Vocative wird nicht gebildet |
:::

## 45.3. Word List

⟪वा⟫ ... ⟪वा⟫ : either ... or

## 45.4. Exercise

A) Translate into Sanskrit (for past tense forms, please use the Imperfect \&lt;⟪लङ्⟫\&gt;):

1\. You split the (Buddhist) community.

::: indent
regarding community schism (⟪सङ्घभेद⟫) see:

:::
2\. Have you enjoyed the earth?

3\. Have you received a gift from the king?

4\. Holy man, why do you not fear dangers?

5\. Father, where are you leaving the family?

6\. Śūdra woman, have you carried the load into the house of the rich Brāhmaṇa?

7\. Goddess, you should fulfill the wish for happiness of the Vaiśya, who has done meritorious deeds.

8\. Elephants, you should not break the bonds.

9\. You lion-like man, why do you not direct your entire attention to the Absolute (Brahman)?

10\. Have you, poet, measured the worlds?
