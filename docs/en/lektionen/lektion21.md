# Lesson 21

## 21.1. Further Present Stems in -nt

### 21.1.1. Present Participle (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
This participle is a nominal formation derived from the present stem, i.e., a true participle. It is an adjective indicating that someone or something is currently performing the action expressed by the verbal root (+ prefix) while something else is happening. A permanent state can also be expressed with it.

**Examples:**

:::
::: indent
"While father reads, he smokes = the reading father smokes"  
"a being (= real, true) friend"
:::
::: grammar-box

| **Formation of the Present Participle Parasmaipada for thematic present stems:** |||
| :--- | :--- | :--- |
| **Masculine, Neuter** | | |
| | **strong stem** | Present Stem + **-nt-** |
| | **weak stem** | Present Stem + **-t-** |
| **Feminine** | | |
| | | Present Stem + **-nt-** + **-ī** (declension like **devī** :br⟪देवी⟫) |
| | **6. Present class** | Present Stem + **-nt-** + **-ī** :broder::brPresent Stem + **-t-** + **-ī** |

:::

## 21.2. Sandhi for final nasals

::: grammar-box
**After a short vowel, final nasals – except -m – are doubled before an initial vowel.**

**Example:**

:::
::: indent
**⟪जयन्⟫ + ⟪अरिः⟫** » **⟪जयन्नरिः⟫** "the victorious enemy"
:::
## 21.3. Polite forms of address

::: grammar-box
**In Sanskrit, one can address someone in the 2nd person singular without being impolite. However, if one wishes to be polite, one can use a noun meaning "Venerable" and the like, and put the verb in the 3rd person singular or plural, or use a passive construction. The escalation of politeness in the use of person in address is roughly as follows:**

:::
::: indent
**2. sg. » 2. pl. » 3. sg. with corresponding noun » 3. pl. with corresponding noun**
:::
**The most important such politeness noun is ⟪भवन्त्⟫ , fem.: ⟪भवती⟫ . It corresponds in its usage to our polite "You" (formal).**
This **⟪भवन्त्⟫** is a contraction of **⟪भगवन्त्⟫**, its declension is that of nouns ending in **-vant** (see [Lesson 13](lektion13.md)). This **⟪भवन्त्⟫** is to be distinguished from the present participle P of **⟪भू⟫** "to become" **⟪भवन्त्⟫** : the nom. sg. masc. of **⟪भवन्त्⟫** "You" (formal) is **⟪भवान्⟫**, that of the participle **⟪भवन्⟫**. 

**Examples:**

::: indent
**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = "What are you doing?"
:::
more politely:

::: indent
**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**
:::
Feminine:

::: indent
**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**
:::
Further words that can be used similarly to **⟪भवन्त्⟫**:

*   **⟪आर्य⟫** (f.: **⟪आर्या⟫**) "Noble". e.g. **⟪यदार्य⟫ ⟪इच्छति⟫** "What you wish"
*   **⟪महाभाग⟫** "he whose share / fortune is great = Noble". Often used by women in address or when speaking about men of good standing. Very common in modern spoken Sanskrit.

If one wishes to express not only politeness but also reverence for someone, one uses **⟪अत्रभवन्त्⟫** instead of **⟪भवन्त्⟫** for someone who is present or nearby, and **⟪तत्रभवन्त्⟫** for someone absent or distant. **⟪अत्रभवन्त्⟫** and **⟪तत्रभवन्त्⟫** can be translated as "You", "Your Venerability", "Your Excellency", etc.:

::: indent
**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = "Is the gracious (here present) woman your wife?"  
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (in a letter or telephone conversation) = "Are you well?"
:::
