# Lesson 31

## 31.1. The 7th Present Class (⟪रुधादि⟫ = "⟪रुध्⟫ etc.")

::: grammar-box
**Formation:**

**Before the final consonants of the low-grade root, a so-called nasal infix (-na- or -n-) is inserted:**

*   **in the strong stem: -na-**
*   **in the weak stem: -n-**

**The rules for connecting the final consonants of the root with endings beginning with a consonant are the same as for the 2nd Present Class.**
:::
Examples:

⟪युज्⟫ 7U "to bind, to yoke"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicative** | **3. sg.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:(nasals are replaced by -ṅ- before gutturals within the word) |
| | **3. pl.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Optative** | **3. sg.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. pl.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Present Participle** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:(fem.: ⟪युञ्जती⟫:bryu + n + j-at-ī) | |

:::
⟪रुध्⟫ 7U "to stop, to bring to a standstill"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicative** | **3. sg.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. pl.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Optative** | **3. sg.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. pl.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Present Participle** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:(fem.: ⟪रुन्धती⟫:brru-n-dh-at-ī) | |

:::
::: grammar-box
**For some roots, the -n- of the weak present stem has also penetrated into non-present tenses, so that these roots are posited with an infigured nasal.**
:::
Example:

⟪भञ्ज्⟫ 7P "to break"

::: indent
*   Indicative Present
*   3.sg.P. ⟪भनक्ति⟫ (bha-na + j + ti)
*   3.pl.P. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Future: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Passive: ⟪भज्यते⟫ (either from the original root ⟪भज्⟫ or from *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (possibly from *bhñj + na)
:::
