# ⟪पाठ⟫ ⟪२७⟫

A) ⟪निम्नलिखित⟫ ⟪वाक्य⟫ ⟪में⟫ ⟪कोष्ठक⟫ ⟪में⟫ ⟪दिए⟫ ⟪गए⟫ ⟪शब्दों⟫ ⟪को⟫ ⟪स्थानी⟫ (⟪सप्तमी⟫) ⟪एकवचन⟫ ⟪और⟫ — ⟪जहाँ⟫ ⟪उचित⟫ ⟪लगे⟫ — ⟪बहुवचन⟫ ⟪में⟫ ⟪लिखें।⟫

**⟪रामस्⟫ ... ⟪वसति⟫ ⟪।⟫** (⟪ग्राम⟫ ⟪।⟫ ⟪गुरु⟫ ⟪।⟫ ⟪सत्यवान्कविः⟫ ⟪।⟫ ⟪पुत्रं⟫ ⟪लब्धुकामा⟫ ⟪ब्राह्मणी⟫ ⟪।⟫ ⟪गृह⟫ ⟪।⟫ ⟪तन्नगरम्⟫ ⟪।⟫ ⟪मुह्यञ्छत्रुः⟫)

⟪१⟫. ⟪रामो⟫ **⟪ग्रामे⟫** ⟪वसति⟫ ⟪।⟫

⟪२⟫. ⟪रामो⟫ **⟪गुरौ⟫** ⟪वसति⟫ ⟪।⟫ (⟪बहुवचन⟫: ⟪रामो⟫ **⟪गुरुषु⟫** ⟪वसति⟫ ⟪।⟫)

⟪३⟫. ⟪रामः⟫ **⟪सत्यवति⟫ ⟪कवौ⟫** ⟪वसति⟫ ⟪।⟫ (⟪बहुवचन⟫: ⟪रामः⟫ **⟪सत्यवत्सु⟫ ⟪कविषु⟫** ⟪वसति⟫ ⟪।⟫)

⟪४⟫. ⟪रामः⟫ **⟪पुत्रं⟫ ⟪लब्धुकामायाम्⟫ ⟪ब्राह्मण्याम्⟫** ⟪वसति⟫ ⟪।⟫ (⟪बहुवचन⟫: ⟪रामः⟫ **⟪पुत्रं⟫ ⟪लब्धुकामासु⟫ ⟪ब्राह्मणीषु⟫** ⟪वसति⟫ ⟪।⟫)

⟪५⟫. ⟪रामो⟫ **⟪गृहे⟫** ⟪वसति⟫ ⟪।⟫ (⟪बहुवचन⟫: ⟪रामो⟫ **⟪गृहेषु⟫** ⟪वसति⟫ ⟪।⟫)

⟪६⟫. ⟪रामस्⟫ **⟪तस्मिन्⟫ ⟪नगरे⟫** ⟪वसति⟫ ⟪।⟫

⟪७⟫. ⟪रामो⟫ **⟪मुह्यति⟫ ⟪शत्रौ⟫** ⟪वसति⟫ ⟪।⟫ (⟪बहुवचन⟫: ⟪रामो⟫ **⟪मुह्यत्सु⟫ ⟪शत्रुषु⟫** ⟪वसति⟫ ⟪।⟫)

B) ⟪अनुवाद⟫ ⟪करें⟫ ⟪और⟫ ⟪समासों⟫ ⟪को⟫ ⟪खोलें⟫:

⟪१⟫. **⟪धर्मं⟫ ⟪वदति⟫ ⟪गुरौ⟫ ⟪दुर्जना⟫ ⟪न⟫ ⟪शृण्वन्ति⟫ ⟪॥१॥⟫**
⟪बुरे⟫ ⟪लोग⟫ ⟪नहीं⟫ ⟪सुनते⟫, ⟪जब⟫ ⟪शिक्षक⟫ ⟪धर्म⟫ ⟪की⟫ ⟪घोषणा⟫ ⟪करते⟫ ⟪हैं।⟫

⟪२⟫. **⟪बुद्धकाले⟫ ⟪नरैरार्यसत्यानि⟫ ⟪श्रोतुं⟫ ⟪शक्यन्ते⟫ ⟪॥२॥⟫**
(⟪बुद्धस्य⟫ ⟪काले⟫)
⟪बुद्ध⟫ ⟪के⟫ ⟪समय⟫ ⟪में⟫ ⟪लोग⟫ ⟪सार्थक⟫ ⟪सत्य⟫ ⟪सुन⟫ ⟪सकते⟫ ⟪हैं।⟫

⟪३⟫. **⟪वसितसुवस्त्रां⟫ ⟪नरा⟫ ⟪लुभ्यन्ति⟫ ⟪।⟫ ⟪एवं⟫ ⟪सति⟫ ⟪सत्यो⟫ ⟪नरेभ्यः⟫ ⟪सुवस्त्राणीच्छन्ति⟫ ⟪॥३॥⟫**
(⟪वसितानि⟫ ⟪शोभनानि⟫ ⟪वस्त्राणि⟫ ⟪यया⟫ ⟪ताम्⟫ ⟪।⟫ ⟪शोभनानि⟫ ⟪वस्त्राणि⟫)
⟪पुरुष⟫ ⟪उस⟫ ⟪स्त्री⟫ ⟪को⟫ ⟪चाहते⟫ ⟪हैं⟫, ⟪जिसने⟫ ⟪सुंदर⟫ ⟪वस्त्र⟫ ⟪पहने⟫ ⟪हैं।⟫ ⟪इसलिए⟫ ⟪अच्छी⟫ ⟪स्त्रियाँ⟫ ⟪पुरुषों⟫ ⟪से⟫ ⟪सुंदर⟫ ⟪वस्त्रों⟫ ⟪की⟫ ⟪कामना⟫ ⟪करती⟫ ⟪हैं।⟫

⟪४⟫. **⟪पुत्रे⟫ ⟪मृते⟫ ⟪ऽपुत्रा⟫ ⟪ब्राह्मणी⟫ ⟪पुत्रं⟫ ⟪लब्धुं⟫ ⟪व्रतं⟫ ⟪करोति⟫ ⟪॥४॥⟫**
(⟪पुत्रो⟫ ⟪नास्ति⟫ ⟪यस्याः⟫ ⟪सा⟫)
⟪अपने⟫ ⟪पुत्र⟫ ⟪के⟫ ⟪मरने⟫ ⟪के⟫ ⟪बाद⟫, ⟪पुत्रहीन⟫ ⟪ब्राह्मणी⟫ ⟪एक⟫ ⟪पुत्र⟫ ⟪पाने⟫ ⟪के⟫ ⟪लिए⟫ ⟪व्रत⟫ ⟪लेती⟫ ⟪है।⟫

⟪५⟫. **⟪उपनीतबालैर्गुरुकुल⟫ ⟪उष्यते⟫ ⟪॥५॥⟫**
(⟪उपनीतैर्बालैः⟫ ⟪।⟫ ⟪गुरोः⟫ ⟪कुले⟫)
⟪दीक्षा⟫ ⟪के⟫ ⟪बाद⟫, ⟪लड़के⟫ ⟪गुरु⟫ ⟪के⟫ ⟪घर⟫ ⟪में⟫ ⟪रहते⟫ ⟪हैं।⟫

⟪६⟫. **⟪यज्ञकाले⟫ ⟪विगते⟫ ⟪ऽनिष्टदेवा⟫ ⟪विस्मृतयज्ञब्राह्मणेभ्यः⟫ ⟪क्रुध्यन्ति⟫ ⟪॥६॥⟫**
(⟪यज्ञस्य⟫ ⟪काले⟫ ⟪।⟫ ⟪नेष्टा⟫ ⟪देवाः⟫ ⟪।⟫ ⟪विस्मृतो⟫ ⟪यज्ञो⟫ ⟪यैस्तेभ्यो⟫ ⟪ब्राह्मणेभ्यः⟫)
⟪याग⟫ ⟪का⟫ ⟪समय⟫ ⟪बीत⟫ ⟪जाने⟫ ⟪के⟫ ⟪कारण⟫, ⟪उन⟫ ⟪ब्राह्मणों⟫ ⟪पर⟫, ⟪जिन्होंने⟫ ⟪याग⟫ ⟪भूल⟫ ⟪गए⟫, ⟪यज्ञ⟫ ⟪नहीं⟫ ⟪किए⟫ ⟪गए⟫ ⟪देवता⟫ ⟪क्रोधित⟫ ⟪हैं।⟫

⟪७⟫. **⟪गुरौ⟫ ⟪तिष्ठति⟫ ⟪बाल⟫ ⟪आसितुं⟫ ⟪नार्हति⟫ ⟪॥७॥⟫**
⟪जब⟫ ⟪गुरु⟫ ⟪खड़े⟫ ⟪होते⟫ ⟪हैं⟫, ⟪तो⟫ ⟪एक⟫ ⟪लड़के⟫ ⟪को⟫ ⟪नहीं⟫ ⟪बैठना⟫ ⟪चाहिए।⟫

⟪८⟫. **⟪एवं⟫ ⟪काले⟫ ⟪गच्छति⟫ ⟪स्वाचारक्षत्रिय⟫ ⟪इष्टं⟫ ⟪धनं⟫ ⟪न⟫ ⟪लभते⟫ ⟪॥८॥⟫**
(⟪साधुराचार⟫o ⟪यस्य⟫ ⟪सः⟫)
⟪समय⟫ ⟪इस⟫ ⟪प्रकार⟫ ⟪बीतने⟫ ⟪के⟫ ⟪कारण⟫, ⟪अच्छे⟫ ⟪आचरण⟫ ⟪वाले⟫ ⟪क्षत्रिय⟫ ⟪को⟫ ⟪वांछित⟫ ⟪समृद्धि⟫ ⟪नहीं⟫ ⟪मिलती।⟫

⟪९⟫. **⟪ब्राह्मण्यां⟫ ⟪महाकवावागच्छन्त्यां⟫ ⟪ब्राह्मणीपुत्रो⟫ ⟪ऽप्यागच्छति⟫ ⟪॥९॥⟫**
(⟪महति⟫ ⟪कवौ⟫ ⟪।⟫ ⟪ब्राह्मण्याः⟫ ⟪पुत्रः⟫)
⟪जब⟫ ⟪ब्राह्मणी⟫ ⟪महान⟫ ⟪कवि⟫ ⟪के⟫ ⟪पास⟫ ⟪पहुँचती⟫ ⟪है⟫, ⟪तो⟫ ⟪उसका⟫ ⟪पुत्र⟫ ⟪भी⟫ ⟪आता⟫ ⟪है।⟫

⟪१०⟫. **⟪गुरुषूपदिशत्सु⟫ ⟪सुनीतबाला⟫ ⟪वक्तुं⟫ ⟪नार्हन्ति⟫ ⟪॥१०॥⟫**
(⟪सुष्ठ⟫u ⟪नीता⟫ ⟪बालाः⟫)
⟪जब⟫ ⟪शिक्षक⟫ ⟪पढ़ाते⟫ ⟪हैं⟫, ⟪तो⟫ ⟪अच्छी⟫ ⟪तरह⟫ ⟪संस्कृत⟫ ⟪बालक⟫ ⟪नहीं⟫ ⟪बकवाज⟫ ⟪कर⟫ ⟪सकते⟫ (⟪बोल⟫ ⟪सकते⟫ ⟪हैं⟫)⟪।⟫
