# ਪਾਠ 56

## 56.1. ਦੁਹਰਾਇਆ ਗਿਆ ਅਓਰਿਸਟ

::: grammar-box
**ਬਣਤਰ:**

**ਆਗਮੈਂਟ + ਦੁਹਰਾਈ ਗਈ ਜੜ੍ਹ + a + ਵਿਸ਼ੇਸ਼ ਦੂਤਕ ਅੰਤ**

**ਜੜ੍ਹ ਦੀ ਸਿਲੇਬੀ ਡੂੰਘੀ ਜਾਂ ਉੱਚੀ ਹੋ ਸਕਦੀ ਹੈ⟪।⟫ -i ਜਾਂ -u 'ਤੇ ਸਮਾਪਤ ਜੜ੍ਹਾਂ ਲਈ, ਡੂੰਘੀ ਸਥਿਤੀ ਨਿਯਮ ਹੈ⟪।⟫**

**ਸਮਾਪਤੀ -i, -u ਨੂੰ -iy ਜਾਂ -uv ਦੁਆਰਾ ਬਦਲਿਆ ਜਾਂਦਾ ਹੈ⟪।⟫**

**ਸਮਾਪਤੀ -ā (-e ਲਈ) ਡਿੱਗ ਜਾਂਦੀ ਹੈ⟪।⟫**
:::

*   ਇੰਜੰਕਟਿਵ ਔਰਿਸਟ ਪੂਰੇ ਪਹਿਲੂ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ⟪।⟫
