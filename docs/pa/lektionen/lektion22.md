# ਪਾਠ 22

## 22.1. ਨਿਰਧਾਰਕ (क्त्वा । ल्यप्)

::: grammar-box

ਜੇਕਰ ਸੰਸਕ੍ਰਿਤ ਵਿੱਚ ਇਹ ਵਿਅਕਤੀ ਕਰਨ ਵਾਲੇ (कर्तृ) ਦੀ ਕਿਸੇ ਕਾਰਵਾਈ ਨੂੰ ਦੂਜੀ ਕਾਰਵਾਈ ਤੋਂ ਪਹਿਲਾਂ ਜਾਂ ਇਸਦੇ ਨਾਲ ਇੱਕ ਸਹਾਇਕ ਹਾਲਤ ਵਜੋਂ ਦਰਸਾਉਣਾ ਹੋਵੇ, ਤਾਂ ਨਿਰਧਾਰਕ (क्त्वा । ल्यप्) ਦੀ ਵਰਤੋਂ ਕੀਤੀ ਜਾਂਦੀ ਹੈ। ਇਸ ਲਈ

"ਜਦੋਂ ਉਸਨੇ ਇਹ ਕੀਤਾ, ਤਾਂ ਉਹ ਉਹ ਕਰਦਾ ਹੈ" ; "ਉਹ ਇਹ ਕਰਦਾ ਹੈ, ਫਿਰ ਉਹ ਉਹ ਕਰਦਾ ਹੈ" ; "ਇਸਦੇ ਨਤੀਜੇ ਵਜੋਂ ਉਹ ਉਹ ਕਰਦਾ ਹੈ" ; "ਮੈਂ ਆਇਆ, ਦੇਖਿਆ ਅਤੇ ਜਿੱਤਿਆ" ਆਦਿ।

ਨਿਰਧਾਰਕ ਇੱਕ ਕ੍ਰਿਆ-ਕ੍ਰਿਆਵਿਸ਼ੇਸ਼ਣ ਹੈ, ਭਾਵ ਇਹ ਨਾ ਤਾਂ ਵਿਅਕਤੀ-ਅਨੁਸਾਰ ਬਦਲਦਾ ਹੈ ਅਤੇ ਨਾ ਹੀ ਵਿਸ਼ੇਸ਼ਣ-ਅਨੁਸਾਰ, ਪਰ ਇਸਦੇ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ — ਕੁਝ ਛੋਟੀਆਂ ਅਪਵਾਦਾਂ ਨੂੰ ਛੱਡ ਕੇ — ਹਮੇਸ਼ਾ ਉਹੀ ਵਿਅਕਤੀ ਕਰਨ ਵਾਲਾ (कर्तृ) ਹੁੰਦਾ ਹੈ ਜਿਸਦੀ ਕਾਰਵਾਈ ਨਿਰਧਾਰਕ ਦੁਆਰਾ ਦਰਸਾਈ ਗਈ ਕਾਰਵਾਈ ਤੋਂ ਪਹਿਲਾਂ ਜਾਂ ਇਸਦੇ ਨਾਲ ਹੁੰਦੀ ਹੈ। ਇਸ ਲਈ ਨਿਰਧਾਰਕ ਦਾ ਵਿਅਕਤੀ ਕਰਨ ਵਾਲਾ ਨਾਮਵਚਨ (प्रथमा) ਜਾਂ ਕਰਣਵਚਨ (तृतीया) ਵਿੱਚ ਹੁੰਦਾ ਹੈ।

ਸੰਯੁਕਤ ਸ਼ਬਦਾਂ ਦੇ ਨਾਲ-ਨਾਲ, ਨਿਰਧਾਰਕ ਸੰਸਕ੍ਰਿਤ ਵਿੱਚ ਸਭ ਤੋਂ ਵੱਧ ਵਰਤੇ ਜਾਣ ਵਾਲੇ ਵਿਅਕਤੀ ਕਰਨ ਵਾਲੇ ਵਿੱਚੋਂ ਇੱਕ ਹੈ।

ਜਰਮਨ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰਦੇ ਸਮੇਂ, "ਜਦੋਂ" ਨੂੰ ਲਗਾਤਾਰ ਵਰਜਣ ਦੀ ਬਜਾਏ, ਸਮੇਂ ਦੇ ਕ੍ਰਮ ਨੂੰ ਦਰਸਾਉਣ ਲਈ ਜਰਮਨ ਵਿੱਚ ਮੁਕਾਬਲਤਨ ਵਰਤੇ ਜਾਣ ਵਾਲੇ ਵਿਅਕਤੀ ਕਰਨ ਵਾਲੇ ਵਿੱਚੋਂ ਇੱਕ ਦੀ ਵਰਤੋਂ ਕਰੋ।

**ਸਕੀਮ:**

(ਨਿਰਧਾਰਕ ਲਈ ਵਿਸ਼ੇਸ਼ ਵਿਸ਼ੇਸ਼ਤਾ: ਹਾਲਤ-ਵਿਸ਼ੇਸ਼ਤਾ, ਵਸਤੁ ਆਦਿ) - ਨਿਰਧਾਰਕ - ਨਿਰਧਾਰਕ - ... - ਨਿਰਧਾਰਕ - ... ਵਿਅਕਤੀ ਕਰਨ ਵਾਲਾ + ਕ੍ਰਿਆ-ਵਾਕ (ਕ੍ਰਿਆ ਜਾਂ ਕਰਮ ਵਿੱਚ)

:::

**ਉਦਾਹਰਣਾਂ:**

::: indent
**गृहं प्रविश्य बालां दृष्ट्वा नरो वदति** = ਕਰਮ-ਕ੍ਰਿਆ-ਵਾਕ: **गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते**  
"ਮਰਦ ਘਰ ਵਿੱਚ ਦਾਖਲ ਹੁੰਦਾ ਹੈ, ਛੋਟੀ ਕੁੜੀ ਨੂੰ ਦੇਖਦਾ ਹੈ ਅਤੇ ਉਸ ਨਾਲ ਗੱਲ ਕਰਦਾ ਹੈ।"

ਬਹੁਵਚਨ: **गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।**

## 22.2. absolutive ਦਾ ਗਠਨ

::: grammar-box
**absolutive ਦਾ ਗਠਨ**

*   ਬਿਨਾਂ ਪ੍ਰੇਵਰਬ ਵਾਲੇ ਕ੍ਰਿਆਪਦ: **-tvā** 'ਤੇ absolutive
*   ਪ੍ਰੇਵਰਬ ਵਾਲੇ ਕ੍ਰਿਆਪਦ: **-ya** ਜਾਂ **-tya** 'ਤੇ absolutive
:::

### 22.2.1. ਅਜਿਹੇ ਕ੍ਰਿਆਪਦ ਜਿਨ੍ਹਾਂ ਵਿੱਚ ਪ੍ਰਯੁਕਤ ਨਾ ਹੋਵੇ: -त्वा 'ਤੇ ਨਿਰਪੇਖ

::: grammar-box

**ਬਣਤਰ:**

(ਆਮ ਤੌਰ 'ਤੇ) ਡੂੰਘੀ ਸਥਿਤੀ ਵਾਲੀ ਮੂਲ, ਉਸ ਰੂਪ ਵਿੱਚ ਜਿਵੇਂ ਕਿ ਇਹ PPP ਤੋਂ ਪਹਿਲਾਂ ਹੁੰਦੀ ਹੈ + **-tvā** (**-त्वा**)

ਸਿਰਫ਼ ਨਕਾਰਾਤਮਕ **a-** / **an-** ਸਭਿਅਤਾ **-त्वा** ਨਾਲ ਸਹਿਮਤ ਹੁੰਦਾ ਹੈ: **अकृत्वा** "ਬਿਨਾਂ ਕੀਤੇ"

:::

**ਉਦਾਹਰਣਾਂ:**

::: indent
**आप्त्वा** "ਜਦੋਂ ਉਹ / ਉਸਨੇ / ਇਸਨੇ / ਮੈਂ / ਤੁਸੀਂ / ਅਸੀਂ / ਤੁਸੀਂ (ਬਹੁਵਚਨ) / ਉਹ / ਅਸੀਂ ਦੋਵੇਂ / ਤੁਸੀਂ ਦੋਵੇਂ / ਉਹ ਦੋਵੇਂ ਪ੍ਰਾਪਤ ਕੀਤਾ / ਕਰ ਰਿਹਾ ਸੀ / ਕਰਦੇ ਹਨ / ਕਰਦੇ ਸਨ"

**आसित्वा** "ਜਦੋਂ ਉਹ (...) ਬੈਠਾ / ਬੈਠੀ / ਬੈਠੇ ਸਨ / ਹਨ"

**इत्वा** "ਜਦੋਂ ਉਹ (...) ਗਿਆ / ਗਈ / ਗਏ ਸਨ / ਹਨ"

**स्थित्वा** "ਜਦੋਂ ਉਹ (...) ਖੜ੍ਹਾ / ਖੜ੍ਹੀ / ਖੜ੍ਹੇ ਸਨ / ਹਨ"

**जित्वा** "ਜਦੋਂ ਉਹ (...) ਜਿੱਤਿਆ / ਜਿੱਤੀ / ਜਿੱਤੇ ਹਨ / ਸਨ"

**उक्त्वा** "ਜਦੋਂ ਉਹ (...) ਬੋਲਿਆ / ਬੋਲੀ / ਬੋਲੇ ਹਨ / ਸਨ"
:::

### 22.2.2. ਪ੍ਰੇਤਕਾਂ ਨਾਲ ਕ੍ਰਿਆਪਦ

#### 22.2.2.1. ਲੰਬੇ ਸਵਰ (ਸਿਵਾ -ā ਦੇ) ਜਾਂ ਸੰਧੀ ਅੱਖਰ 'ਤੇ ਸਮਾਪਤ ਹੋਣ ਵਾਲੀਆਂ ਮੂਲ ਕ੍ਰਿਆਵਾਂ

::: grammar-box

**(ਆਮ ਤੌਰ 'ਤੇ)** ਘੱਟ ਸਵਰ ਵਾਲੀ ਮੂਲ ਕ੍ਰਿਆ + -ya

**ਉਦਾਹਰਣਾਂ:**

::: indent
**उपनीय** "ਜਦੋਂ ਉਸਨੇ (...) ਲਿਆਂਦਾ ਹੈ / ਲਿਆਂਦਾ ਸੀ"

**प्रभूय** "ਜਦੋਂ ਉਹ (...) ਬਾਹਰ ਨਿਕਲਿਆ ਹੈ / ਸੀ" "ਜਦੋਂ ਉਸਦੇ ਕੋਂ (...) ਸ਼ਕਤੀ ਸੀ"

**प्राप्य** "ਜਦੋਂ ਉਸਨੇ (...) ਪ੍ਾਪਤ ਕੀਤਾ ਹੈ / ਪ੍ਾਪਤ ਕੀਤਾ ਸੀ"
:::

#### 22.2.2.2. -ā 'ਤੇ ਸਮਾਪਤ ਹੋਣ ਵਾਲੀਆਂ ਮੂਲ ਕ੍ਰਿਆਵਾਂ

::: grammar-box

**ਬਦਲੇ ਨਹੀਂ ਉੱਚ ਸਵਰ ਵਾਲੀ ਮੂਲ ਕ੍ਰਿਆ + -ya**

:::

**ਉਦਾਹਰਣ:**

::: indent

#### 22.2.2.3. ਉਹ ਮੂਲ ਕ੍ਰਿਆਵਾਂ ਜੋ ਘੱਟ ਸਵਰ ਵਿੱਚ -i, -u, -ṛ 'ਤੇ ਸਮਾਪਤ ਹੁੰਦੀਆਂ ਹਨ

**ਘੱਟ ਸਵਰ ਵਾਲੀ ਮੂਲ ਕ੍ਰਿਆ + -tya**

::: indent
**प्रस्तुत्य** "ਜਦੋਂ ਉਸਨੇ (...) ਜੋਰ ਨਾਲ ਸਤਕਾਰ ਕੀਤਾ ਹੈ / ਸਤਕਾਰ ਕੀਤਾ ਸੀ"

**विस्मृत्य** "ਜਦੋਂ ਉਸਨੇ (...) ਭੁੱਲ ਗਿਆ ਹੈ / ਭੁੱਲ ਗਿਆ ਸੀ"

**संस्कृत्य** "ਜਦੋਂ ਉਸਨੇ (...) ਯਾਗ ਲਈ ਤਿਆਰ ਕੀਤਾ ਹੈ / ਤਿਆਰ ਕੀਤਾ ਸੀ"
:::

#### 22.2.2.4. -am / -an 'ਤੇ ਸਮਾਪਤ ਹੋਣ ਵਾਲੀਆਂ ਮੂਲ ਕ੍ਰਿਆਵਾਂ, ਜੋ ਘੱਟ ਸਵਰ ਵਿੱਚ -a 'ਤੇ ਸਮਾਪਤ ਹੁੰਦੀਆਂ ਹਨ

::: grammar-box

**ਵਿਕਲਪਿਕ:**

**-am** / **-an** 'ਤੇ ਸਮਾਪਤ ਮੂਲ ਕ੍ਰਿਆ + **-ya**

ਜਾਂ:

**-a** 'ਤੇ ਸਮਾਪਤ ਮੂਲ ਕ੍ਰਿਆ + **-tya**

**ਉਦਾਹਰਣ:**

**विगम्य** ਜਾਂ **विगत्य** "ਜਦੋਂ ਉਹ (...) ਗੁਜ਼ਰਿਆ ਹੈ / ਸੀ"

**अर्ह 1 ਪੁ  अर्हति ਪਾਸ.ਵਾਚਕ  अर्ह्यते ਪਪਪ  अर्हित ਅਨਿ.  अर्हितुम् :** ਕੁਝ ਯੋਗ ਹੋਣਾ (ਕੁਝ ਲਈ ਯੋਗ ਹੋਣਾ), ਅਧਿਕਾਰ ਰੱਖਣਾ, ਬੱਧ ਹੋਣਾ, ਕਰਨਾ ਚਾਹੀਦਾ ਹੈ (ਦੂਜੇ ਪੁਰਖ ਵਿੱਚ **अर्ह्** + ਅਨਿਤਿਵ ਦਾ ਪ੍ਰਯੋਗ ਅਕਸਰ ਮੱਧਮ ਹੁਕਮ ਵਜੋਂ ਕੀਤਾ ਜਾਂਦਾ ਹੈ: "ਤੁਹਾਨੂੰ ਚਾਹੀਦਾ ਹੈ")

::: indent
**अर्हन्त् 3** ਪਰਤ. ਵਰਤਮਾਨ ਪੁ: ਇੱਕ ਯੋਗ ਪੁਰਖ। ਬੁੱਧ ਧਰਮ ਅਤੇ ਜੈਨ ਧਰਮ ਵਿੱਚ: ਉਹ ਵਿਅਕਤੀ ਜਿਸਨੇ ਅੰਤਿਮ ਮੁਕਤੀ ਪ੍ਰਾਪਤ ਕਰ ਲਈ ਹੈ
:::

**व्रत ਨ.:** ਵਚਨ, ਧਾਰਮਿਕ ਕਰਤਵ્ય, ਧਾਰਮਿਕ ਪਾਲਣਾ (ਕੋਈ ਦੇਵਤਾ ਨੂੰ ਕੁਝ ਵਚਨ ਦਿੰਦਾ ਹੈ ਤਾਂ ਜੋ ਉਸ ਤੋਂ ਕੁਝ ਪ੍ਰਾਪਤ ਕਰ ਸਕੇ। ਉਦਾਹਰਣ: ਇੱਕ ਮਾਂ ਵਚਨ ਦਿੰਦੀ ਹੈ ਕਿ ਜੇਕਰ ਉਸਦੀ ਧੀ ਦੁਬਾਰਾ ਠੀਕ ਹੋ ਜਾਂਦੀ ਹੈ ਤਾਂ ਉਹ ਧੀ ਨੂੰ ਦੇਵੀਗ੍ਰਹਿਣੀ (**देवदासी**) ਵਜੋਂ ਸੌਂਪ ਦੇਵੇਗੀ। ਮਹੱਤਵਪੂਰਨ **व्रत** ਅੱਜਕੱਲ੍ਹ: ਉਪਵਾਸ; ਪਿਆਰੇ ਖਾਣੇ ਤੋਂ ਪਹਿਰਾਜ਼ਗੀ; ਯੋਨਿਕ ਪਹਿਰਾਜ਼ਗੀ; ਪਵਿੱਤਰ ਲਿਖਤਾਂ ਦਾ ਪੜ੍ਹਨਾ; ਕੁਝ ਰਸਮਾਂ ਦਾ ਪਾਲਣਾ; ਬ੍ਰਾਹਮਣਾਂ ਨੂੰ ਖੁਆਉਣਾ ਆਦਿ। **व्रत** ਬਾਰੇ ਸੰਖੇਪ: ਵਾਕਰ, ਹਿੰਦੂ ਵਰਲਡ ਭਾਗ II, ਪੰਨਾ 581f। ਵਿਸਤਾਰ: ਪੀ. ਵੀ. ਕਾਨੇ: ਧਰਮਸ਼ਾਸਤਰ ਦਾ ਇਤਿਹਾਸ ਭਾਗ 5,1 ਪੰਨਾ 1 - 462। ਉੱਥੇ ਪੰਨਾ 253 - 462 **व्रत** ਅਤੇ ਧਾਰਮਿਕ ਤਿਉਹਾਰਾਂ ਦੀ ਸੂਚੀ ("ਹੇਠਾਂ ਦਿੱਤੀ ਸੂਚੀ ... ਪੂਰੀ ਤਰ੍ਹਾਂ ਵਿਆਪਕ ਹੋਣ ਦਾ ਦਾਵਾ ਨਹੀਂ ਕਰਦੀ" !!!)

अन्नं पक्त्वा ब्राह्मणदासो ऽत्ति ॥१॥

इष्टदेवतापूजां कृत्वेन्द्रादिदेवान्सद्ब्राह्मणाः स्तुवन्ति ॥२॥

प्रस्थाय रामः सपुत्रः सद्गुरुश्रवणार्थेन ब्राह्मणग्रामं गच्छति ॥३॥

अनिष्ट्वा नरो भगवद्भक्तिमात्रेणापि मोक्षमाप्नोति ॥४॥

गृहगर्भं प्रविश्य ब्राह्मणपुत्रमुपस्थाय क्षत्रियशूरो वक्ति ॥५॥

सम्बुध्य दुःखाद्यार्यसत्यानि प्रोच्य सुगतो मोक्षमार्गेण नरान्नयति ॥६॥

मन्त्रं विस्मृत्य यजन्यज्ञदोषं करोति ॥७॥

धनं प्राप्य बुद्धमार्गभिक्षवो दुष्यन्ति ॥८॥

अनार्यशत्रुभिः संगत्य नरसिंहा विजयन्ते ॥९॥

पुण्यं कृत्वा सत्यमेवोदित्वा नरो नरकं नोपपद्यते ॥१०॥
