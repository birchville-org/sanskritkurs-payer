# ਪਾਠ 28

## 28.1. ਕਾਰਕ (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**ਜੇਕਰ ਇਹ ਦਰਸਾਉਣਾ ਹੈ ਕਿ ਕੋਈ ਵਿਅਕਤੀ ਜਾਂ ਕੋਈ ਚੀਜ਼ ਕਿਸੇ ਹੋਰ ਵਿਅਕਤੀ ਜਾਂ ਕੋਈ ਹੋਰ ਚੀਜ਼ ਨੂੰ ਕੋਈ ਕੰਮ ਕਰਨ ਜਾਂ ਅਨੁਭਵ ਕਰਨ ਲਈ ਪ੍ਰੇਰਿਤ ਜਾਂ ਕਾਰਨ ਬਣਦੀ ਹੈ, ਜੋ ਕਿ ਇੱਕ ਮੂਲ (ਪ੍ਰੇਰਕ ਸਮੇਤ ਜਾਂ ਬਿਨਾਂ) ਦੁਆਰਾ ਦਰਸਾਇਆ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਕਾਰਕ (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫) ਦੀ ਵਰਤੋਂ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।**

ਉਦਾਹਰਣ:
⟪गम्⟫ "ਜਾਣਾ" » ਕਾਰਕ: ⟪गमयति⟫ "ਉਹ ਕਿਸੇ ਨੂੰ ਜਾਣ ਲਈ ਪ੍ਰੇਰਿਤ ਕਰਦਾ ਹੈ; ਉਹ ਭੇਜਦਾ ਹੈ"
⟪दृश्⟫ "ਦੇਖਣਾ" » ਕਾਰਕ: ⟪दर्शयति⟫ "ਉਹ ਦਿਖਾਉਂਦਾ ਹੈ = ਉਹ ਦਿਖਾਉਂਦਾ ਹੈ"
:::

## 28.2. ਕਾਰਕ ਨਾਲ ਵਾਕ ਬਣਾਉਣਾ (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**ਸਕੀਮ 1:**

**ਜੇਕਰ ਕਾਰਕ ਦੇ ਅਧੀਨ ਮੂਲ (ਪ੍ਰੇਰਕ ਸਮੇਤ ਜਾਂ ਬਿਨਾਂ) ਅਕਰਮਕ ਹੈ (ਭਾਵ, ਇਸਦੇ ਨਾਲ ਕੋਈ ਕਰਮ ਕਾਰਕ ਨਹੀਂ ਹੋ ਸਕਦਾ) ਜਾਂ ਗਤੀ, ਜਾਣਕਾਰੀ, ਜਾਣਕਾਰੀ ਜਾਂ ਖਾਣੇ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ:**

**ਕਾਰਕ ਦਾ ਕਰਤਾ (⟪कर्ता⟫) ਨਾਮਵਾਚਕ ਵਿੱਚ (⟪प्रथमा⟫) — ਪ੍ਰੇਰਿਤ ਕਾਰਜ ਦਾ ਕਰਤਾ ਕਰਮ ਕਾਰਕ ਵਿੱਚ (⟪द्वितीया⟫) — (ਗਤੀ ਦਾ ਲਕਸ਼ਯ, ਜਾਣਕਾਰੀ ਦਾ ਵਸਤੂ ਆਦਿ ਕਰਮ ਕਾਰਕ ਵਿੱਚ = ⟪द्वितीया⟫) — ਕਾਰਕ ਵਿੱਚ ਕ੍ਰਿਆ**
:::
ਉਦਾਹਰਣਾਂ:

⟪दुर्जनो⟫ ⟪रामं⟫ ⟪मोहयति⟫ = "ਇੱਕ ਬੁਰਾ ਵਿਅਕਤੀ ਰਾਮ ਨੂੰ ਵਿਗੜਨ ਦਾ ਕਾਰਨ ਬਣਦਾ ਹੈ = ਰਾਮ ਨੂੰ ਵਿਗੜਦਾ ਹੈ = ਰਾਮ ਨੂੰ ਗਲਤੀ ਕਰਨ ਦਾ ਕਾਰਨ ਬਣਦਾ ਹੈ"
ਨਤੀਜਾ: ⟪रामो⟫ ⟪मुह्यति⟫ = "ਰਾਮ ਵਿਗੜਿਆ ਹੋਇਆ ਹੈ / ਅੰਧਾ ਹੈ / ਗਲਤੀ ਕਰ ਰਿਹਾ ਹੈ।"

⟪रामः⟫ ⟪शत्रून्स्वर्गं⟫ ⟪गमयति⟫ = "ਰਾਮ ਦੁਸ਼ਮਣਾਂ ਨੂੰ ਸਵਰਗ ਵਿੱਚ ਜਾਣ ਦਿੰਦਾ ਹੈ = ਦੁਸ਼ਮਣਾਂ ਨੂੰ ਸਵਰਗ ਭੇਜਦਾ ਹੈ"
ਨਤੀਜਾ: ⟪शत्रवः⟫ ⟪स्वर्गं⟫ ⟪गच्छन्ति⟫ = "ਦੁਸ਼ਮਣ ਸਵਰਗ ਜਾਂਦੇ ਹਨ / ਸਵਰਗ ਵਿੱਚ ਆਉਂਦੇ ਹਨ"

⟪गुरू⟫ ⟪रामं⟫ ⟪वेदार्थं⟫ ⟪वेदयति⟫ = "ਗੁਰੂ ਰਾਮ ਨੂੰ ਵੇਦ ਦਾ ਅਰਥ ਸਮਝਣ ਦਿੰਦਾ ਹੈ = ਰਾਮ ਨੂੰ ਵੇਦ ਦਾ ਅਰਥ ਸਮਝਾਉਂਦਾ ਹੈ / ਸਿਖਾਉਂਦਾ ਹੈ"
ਨਤੀਜਾ: ⟪रामो⟫ ⟪वेदार्थं⟫ ⟪वेत्ति⟫ = "ਰਾਮ ਵੇਦ ਦਾ ਅਰਥ ਜਾਣਦਾ ਹੈ / ਸਮਝਦਾ ਹੈ"

⟪स⟫ ⟪रामं⟫ ⟪वेदमध्यापयति⟫ = "ਉਹ ਰਾਮ ਨੂੰ ਵੇਦ ਸਿਖਾਉਂਦਾ ਹੈ"
ਨਤੀਜਾ: ⟪रामो⟫ ⟪वेदमधीते⟫ "ਰਾਮ ਵੇਦ ਦਾ ਅਧਿਐਨ ਕਰਦਾ ਹੈ"

⟪रामो⟫ ⟪देवानामृतमाशयति⟫ = "ਰਾਮ ਦੇਵਤਾਵਾਂ ਨੂੰ ਅਮ੍ਰਿਤ ਖਾਣ ਦਿੰਦਾ ਹੈ = ਦੇਵਤਾਵਾਂ ਨੂੰ ਅਮ੍ਰਿਤ ਖਾਣ ਲਈ ਦਿੰਦਾ ਹੈ" (⟪अश्⟩ 9 "ਖਾਣਾ")
ਨਤੀਜਾ: ⟪देवा⟫ ⟪अमृतमश्नन्ति⟫ "ਦੇਵਤਾ ਅਮ੍ਰਿਤ ਖਾਂਦੇ ਹਨ"

**ਸਕੀਮ 2:**

**ਸਰਗਤਮਾ ਕ੍ਰਿਆਵਾਂ ਲਈ (ਸਕੀਮ 1 ਵਿੱਚ ਦੱਸੀਆਂ ਗਈਆਂ ਕ੍ਰਿਆਵਾਂ ਤੋਂ ਇਲਾਵਾ)। ਇਸੇ ਤਰ੍ਹਾਂ ਸਾਰੀਆਂ ਕ੍ਰਿਆਵਾਂ ਲਈ, ਜਦੋਂ ਕੌਸ਼ਟਿਵ ਦੁਆਰਾ ਦਰਸਾਈ ਗਈ ਗੱਲ ਪ੍ਰੇਰਿਤ ਕੀਤੀ ਜਾਂਦੀ ਹੈ (ਜਦੋਂ ਕੌਸ਼ਟਿਵ ਇਸ ਲਈ ਕੌਸ਼ਟਿਵ ਦਾ ਕੌਸ਼ਟਿਵ ਹੁੰਦਾ ਹੈ):**
