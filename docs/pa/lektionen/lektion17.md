# ਪਾਠ 17

## 17.1. ਦੂਜਾ ਵਰਤਮਾਨ ਕਲਾ (⟪अदादि⟫ = ⟪अद्⟫ ਆਦਿ)

ਕ੍ਰਿਆਪਦ ਦੇ ਅੰਤ ਸਿੱਧੇ ਮੂਲ ਨਾਲ ਜੁੜਦੇ ਹਨ। ਇਸ ਸਥਿਤੀ ਵਿੱਚ ਸ਼ਬਦ-ਸੰਧੀ ਤੋਂ ਪੈਦਾ ਹੋਧਵੇਂ ਧੁਨਿਕ ਬਦਲਾਅਾਂ 'ਤੇ ਧਿਆਨ ਦੇਣਾ ਚਾਹੀਦਾ ਹੈ।

::: grammar-box

ਦੂਜੇ ਵਰਤਮਾਨ ਕਲਾ ਵਿੱਚ ਹੇਠ ਲਿਖੇ ਰੂਪ ਬਣਦੇ ਹਨ:

1.  ਮੂਲ ਜਿਨ੍ਹਾਂ ਵਿੱਚ ਮੂਲ-ਪੱਧਰ ਦਾ ਭੇਦ ਹੋਵੇ
    *   ਜ਼ਿਆਦਾਤਰ: ਉੱਚ ਪੱਧਰ - ਘੱਟ ਪੱਧਰ
    *   ਕੁਝ ਮੂਲ: ਲੰਬਾ ਪੱਧਰ - ਘੱਟ ਪੱਧਰ
2.  ਮੂਲ ਜਿਨ੍ਹਾਂ ਵਿੱਚ ਮੂਲ-ਪੱਧਰ ਦਾ ਭੇਦ ਨਾ ਹੋਵੇ
3.  -i/-ī 'ਤੇ ਸਮਾਪਤ ਦੋ-ਅਖਰੀ ਮੂਲ ਜਿਨ੍ਹਾਂ ਵਿੱਚ ਮੂਲ-ਪੱਧਰ ਦਾ ਭੇਦ ਹੋਵੇ

:::
