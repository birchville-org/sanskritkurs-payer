# ਪਾਠ 55

## 55.1. ਏ-ਔਰਸਿਟ (ਔਰਸਿਟ ਜਿਸ ਵਿੱਚ ਥੀਮਾਵੋਕਲ ਹੈ)

::: grammar-box
**ਏ-ਔਰਸਿਟ ਨੂੰ ਇਮਪਰਫੈਕਟ (⟪लङ्⟫) ਦੀ 6. ਪ੍ਰੇਸੈਂਸ ਕਲਾ (⟪तुदादि⟫) ਵਾਂਗ ਬਣਾਇਆ ਜਾਂਦਾ ਹੈ, ਭਾਵ:**

**ਔਗਮੈਂਟ + ਡੂੰਘੀ ਸ਼੍ਰੇਣੀ ਦੀ ਜੜ੍ਹ + ਏ + ਸੈਕੰਡਰੀ ਅੰਤ**

**-ਏ- ਨੂੰ ਉਨ੍ਹਾਂ ਹੀ ਕੇਸਾਂ ਵਿੱਚ -ਆ- ਨਾਲ ਬਦਲ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ ਜਿਵੇਂ ਇਮਪਰਫੈਕਟ ਵਿੱਚ⟪।⟫**

**ਕੋਈ ਨਾਸਲ ਇਨਫਿਕਸ ਨਹੀਂ⟪।⟫**

**ਆਤਮਨੇਪਦ ਦੁਰਲੱਭ ਹੈ; ਉਭਯਪਦਾ ਜੜ੍ਹਾਂ ਲਈ, ਇਹ ਆਮ ਤੌਰ 'ਤੇ ਹੋਰ ਔਰਸਿਟ ਕਲਾਵਾਂ ਅਨੁਸਾਰ ਬਣਾਇਆ ਜਾਂਦਾ ਹੈ (ਕਿਏਲਹੋਰਨ, ਗ੍ਰਾਮਰ §340 ਅਤੇ ਹੇਠਾਂ ਸੰਬੰਧਿਤ ਔਰਸਿਟ ਕਲਾਵਾਂ ਦੇਖੋ)⟪।⟫**

**ਇਸ ਔਰਸਿਟ ਵਾਲੀਆਂ ਜੜ੍ਹਾਂ ਦੀ ਸੂਚੀ, ਕਿਏਲਹੋਰਨ, ਗ੍ਰਾਮਰ §340 ਵਿੱਚ⟪।⟫**
:::
