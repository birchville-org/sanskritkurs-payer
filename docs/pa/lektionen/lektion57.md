# ਪਾਠ 57

## 57.1. ਔਰਿਸਟ 4: s-ਔਰਿਸਟ

::: grammar-box
**s-ਔਰਿਸਟ ਨੂੰ ⟪अनिट्⟫-ਮੂਲਾਂ ਦੇ ਜ਼ਿਆਦਾਤਰ ਨਾਲ ਬਣਾਇਆ ਜਾਂਦਾ ਹੈ, ਜਦੋਂ ਤੱਕ ਉਹਨਾਂ ਕੋਲ ਸਿਰਫ਼ ਇੱਕ ਹੋਰ ਔਰਿਸਟ ਰੂਪ ਨਾ ਹੋਵੇ⟪।⟫ ਵਿਕਲਪਿਕ ⟪अनिट्⟫-ਮੂਲ ਆਮ ਤੌਰ 'ਤੇ ਇਸਨੂੰ ਜਾਂ iṣ-ਔਰਿਸਟ ਨੂੰ ਬਣਾ ਸਕਦੇ ਹਨ⟪।⟫ ⟪अनिट्⟫-ਮੂਲ, ਜੋ ⟪परस्मैपद⟫ ਨੂੰ ਔਰਿਸਟ ਦੇ 1., 2. ਜਾਂ 6. ਰੂਪ ਤੋਂ ਬਾਅਦ ਬਣਾਉਂਦੇ ਹਨ, ⟪आत्मनेपद⟫ ਨੂੰ s-ਔਰਿਸਟ ਦੇ ਅਧਾਰ 'ਤੇ ਬਣਾਉਂਦੇ ਹਨ⟪।⟫**

**ਬਣਤਰ: ਔਗਮੈਂਟ + ਮੂਲ + s + ਅਥੇਮੈਟਿਕ ਸੈਕੰਡਰੀ ਅੰਤ**
:::
ਅੰਤ ਸਮੇਤ ਸ਼ਬਦ-ਬਣਤਾ ਸਫ਼ਿਕਸ ਦੀ ਸਾਰਣੀ

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |

| **3. ⟪प्रथमः⟫** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**ਸਧਾਰਨ ਧੁਨੀ ਨਿਯਮ ਲਾਗੂ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਕਿ ਇੱਕ ਸ਼ਿਸ਼਼ ਧੁਨੀ ਦੋ ਬੰਦ ਧੁਨੀਆਂ ਵਿਚਕਾਰ ਗਾਇਬ ਹੋ ਜਾਂਦੀ ਹੈ (ਵੇਖੋ ⟪उद्⟫ + ⟪स्थित⟫ » ⟪उत्थित⟫), ਭਾਵ, ਸ਼ਬਦ-ਬਣਤਾ ਸਫ਼ਿਕਸ -s- ਉਹਨਾਂ ਅੰਤਾਂ ਤੋਂ ਪਹਿਲਾਂ ਜੋ -t- ਜਾਂ -th- ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦੇ ਹਨ, ਗਾਇਬ ਹੋ ਜਾਂਦਾ ਹੈ (ਪਰ ਨਾਸਿਕ ਜਾਂ r- ਤੋਂ ਬਾਅਦ ਨਹੀਂ)⟪।⟫**

ਉਦਾਹਰਣਾਂ:

:::
::: indent
3.sg.Ā a-kṣip + s + ta » ⟪अ⟫**:sig[⟪क्षिप्त⟫]**
2.sg.Ā a-kṣip + s + thās » ⟪अ⟫**:sig[⟪क्षिप्था⟫]**⟪स्⟫
:::
ਅਜਿਹੇ ਰੂਪ ਮੂਲ-ਔਰਿਸਟ ਨਾਲ ਵੀ ਸੰਬੰਧਿਤ ਹੋ ਸਕਦੇ ਹਨ ਅਤੇ ਸੰਭਵ ਤੌਰ 'ਤੇ ਕੁਝ ਅਜਿਹੇ ਹੀ ਹਨ⟪।⟫
ਭਾਰਤੀ ਵਿਆਕਰਣਕਾਰਾਂ ਨੇ :sig[⟪अकृत⟫] (3.sg.Ā) ਵਰਗੇ ਰੂਪਾਂ ਨੂੰ ਵੀ s-ਔਰਿਸਟ ਵਿੱਚ ਗਿਣਿਆ ਹੈ, ਜੋ ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ ਮੂਲ-ਔਰਿਸਟ ਨਾਲ ਸੰਬੰਧਿਤ ਹਨ⟪।⟫ ਇਸ ਉਦੇਸ਼ ਲਈ, ਭਾਰਤੀ ਵਿਆਕਰਣਕਾਰਾਂ ਨੇ s-ਔਰਿਸਟ ਲਈ ਹੇਠ ਲਿਖੀ ad-hoc ਧੁਨੀ ਨਿਯਮ ਦੀ ਸਿਰਜਣਾ ਕੀਤੀ:

::: indent
"ਸੰਖੇਪ ਸਵਰਾਂ ਤੋਂ ਬਾਅਦ, -st- ਜਾਂ -sth- ਨਾਲ ਸ਼ੁਰੂ ਹੋਣ ਵਾਲੇ 'ਅੰਤ', -s- ਗੁਆਉਂਦੇ ਹਨ⟪।⟫"
:::
ਹੋਰ ਸਥਿਤੀਆਂ ਵਿੱਚ, ਸਮਾਪਤੀ ਵਾਲੀਆਂ ਸਹਿਜ਼ਾਤ ਧੁਨੀਆਂ ਨੂੰ s- ਨਾਲ ਜੋੜਨ ਵਾਲੇ ਧੁਨੀ ਨਿਯਮਾਂ ਦਾ ਧਿਆਨ ਰੱਖਣਾ ਚਾਹੀਦਾ ਹੈ⟪।⟫
