## 30.5. ਸਿੱਧੀ: ਅੰਤ ਵਿੱਚ -r

::: grammar-box
**-ar ਲਈ ਛੱਡ ਕੇ, ਅੰਤ ਵਿੱਚ -r ਲਈ ਉਹੀ ਸੰਧਿ ਨਿਯਮ ਲਾਗੂ ਹੁੰਦੇ ਹਨ ਜੋ ਅੰਤ ਵਿੱਚ -s ਲਈ ਲਾਗੂ ਹੁੰਦੇ ਹਨ⟪।⟫**

**-ar ਧੁਨੀਆਂ ਤੋਂ ਪਹਿਲਾਂ -ar ਰਹਿੰਦਾ ਹੈ, ਪਰ r- ਤੋਂ ਪਹਿਲਾਂ -r ਛੁੱਟ ਜਾਂਦਾ ਹੈ ਅਤੇ -a- ਨੂੰ -ā- ਨਾਲ ਬਦਲ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ⟪।⟫**
