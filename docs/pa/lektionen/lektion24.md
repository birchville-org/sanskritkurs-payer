# ਪਾਠ 24

## 24.1. ਡੇਟੀਵ (⟪चतुर्थी⟫ = "ਚੌਥਾ ਵਿਕਾਰ")

::: grammar-box
**1. ਕਿਸੇ ਕਾਰਜ ਦੇ ਉਦੇਸ਼ ਜਾਂ ਇਰਾਦੇ ("ਤਾਂ ਜੋ") ਨੂੰ ਦਰਸਾਉਣ ਲਈ, ਇਨਫਿਨੀਟਿਵ (⟪तुमुन्⟫) ਦੀ ਬਜਾਏ, ਕ੍ਰਿਤ-ਸੰਗਮ (kṛt-suffix) ਵਾਲੇ ਇੱਕ ਨਾਂਵ ਦੀ ਵਰਤੋਂ ਕੀਤੀ ਜਾ ਸਕਦੀ ਹੈ, ਜੋ ਕਿ ਇੱਕ ਕਾਰਜ ਜਾਂ ਅਵਸਥਾ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ, ਡੇਟੀਵ (⟪चतुर्थी⟫ = "ਚੌਥਾ ਵਿਕਾਰ") ਵਿੱਚ।**

ਉਦਾਹਰਣ:

ਇਸ ਦੀ ਬਜਾਏ:

:::
::: indent
⟪रामो गुरुवचनं श्रोतुं गतः ।⟫
:::
ਇਹ ਵੀ ਕਿਹਾ ਜਾ ਸਕਦਾ ਹੈ:

::: indent
⟪रामो गुरुवचनस्य श्रवणाय गतः ।⟫

ਜਾਂ:

⟪रामो गुरुवचनश्रवणाय गतः ।⟫
:::
= "ਰਾਮ ਗਿਆ ਹੈ, ਉਪਦੇਸ਼ਕ ਦੀ ਵਾਣੀ ਸੁਣਨ ਲਈ।"
::: media
![](/images/lekt2404.webp)
ਚਿੱਤਰ: ⟪बाला गुरुश्रवणाय गताः⟫
(ਚਿੱਤਰ ਸਰੋਤ: [ਵੇਰਵੇ](/pa/licenses#lekt2404))
:::

::: grammar-box
**2. ਡੇਟੀਵ (⟪चतुर्थी⟫) ਉਦੇਸ਼ ਦੇ ਇਨਫਿਨੀਟਿਵ ਦੇ ਪੂਰਕ ਵਜੋਂ ਜੁੜੇ ਆਬਜੈਕਟ ਨੂੰ ਵੀ ਦਰਸਾ ਸਕਦਾ ਹੈ:**

ਉਦਾਹਰਣ:

:::
::: indent
⟪फलेभ्यो ग्रामं गच्छति⟫ = "ਉਹ ਫਲਾਂ ਦੇ ਉਦੇਸ਼ ਨਾਲ ਪਿੰਡ ਜਾ ਰਿਹਾ ਹੈ = ਉਹ ਫਲ ਲਿਆਉਣ ਲਈ ਪਿੰਡ ਜਾ ਰਿਹਾ ਹੈ।"
:::
**ਇਸੇ ਤਰ੍ਹਾਂ, ਡੇਟੀਵ (⟪चतुर्थी⟫) ਕਿਸੇ ਵਸਤੂ ਜਾਂ ਕਾਰਜ ਦੇ ਉਦੇਸ਼ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ:**

ਉਦਾਹਰਣ:

::: indent
⟪यज्ञायान्नम्⟫ = "ਅਗਨੀ-ਆਰਪਣ ਦੇ ਉਦੇਸ਼ ਲਈ ਭੋਜਨ = ਅਗਨੀ-ਆਰਪਣ ਲਈ ਭੋਜਨ"
:::
::: media
![](/images/lekt2401.webp)
ਚਿੱਤਰ: ⟪यज्ञायान्नम्⟫
'ਅਨਾਕੁਤ' [⟪अन्नकूट⟫ = ⟪गोवर्धन पूजा⟫] ਇੱਕ ਪਰੰਪਰਾਗਤ ਹਿੰਦੂ ਘਟਨਾ ਹੈ ਜੋ ਸਾਰੇ BAPS [બોચાસનવાસી અક્ષ૨ પુરુષોત્તમ સ્વામિનારાયણ સંસ્થા = Bochasanwasi Akshar Purushottam Swaminarayan Sanstha] ਮੰਦਰਾਂ ਵਿੱਚ ਹਿੰਦੂ ਨਵੇਂ ਸਾਲ ਦੀਆਂ ਜਸ਼ਨਾਂ ਦੌਰਾਨ ਮਨਾਈ ਜਾਂਦੀ ਹੈ। ਇਸ ਦਿਨ ਭਗਵਾਨ ਸੁਰਿੰਦਰ ਨਾਰਾਇਣ [સ્વામિનારાયણ] ਨੂੰ ਸੈਂਕੜੇ ਸ਼ਾਕਾਹਾਰੀ ਪਕਵਾਨ ਅਰਪਿਤ ਕੀਤੇ ਜਾਂਦੇ ਹਨ।
(ਚਿੱਤਰ ਸਰੋਤ: [ਵੇਰਵੇ](/pa/licenses#lekt2401))
:::

::: grammar-box
**3. ਦਾਤਰਿ (⟪चतुर्थी⟫) ਕਾਰਕ ਕਿਸੇ ਕੰਮ ਦੇ ਵਸਤੂ ਲਈ ਨਿਰਧਾਰਿਤ ਵਿਅਕਤੀ ਜਾਂ ਵਸਤੂ (ਪ੍ਰਤੱਖ ਕਾਰਕ; ਸਵਾਲ: ਕਿਸਨੂੰ?) ਨੂੰ ਵੀ ਦਰਸਾਉਂਦਾ ਹੈ। (ਪਰ ਦੋਹਾਂ ਆਕਮੇਟਿਵ ਵਾਲੇ ਕ੍ਰਿਆਪਦਾਂ (⟪द्वितीया⟫) ਨੂੰ ਧਿਆਨ ਵਿੱਚ ਰੱਖੋ!)**

ਉਦਾਹਰਣ:

:::
::: indent
⟪रामाय फलं ददाति⟫ = "ਉਹ ਰਾਮ ਨੂੰ ਇੱਕ ਫਲ ਦਿੰਦਾ ਹੈ।" (ਵ੍ਰਿਤ্ত ⟪दा⟫ 3. ਵਰਤਮਾਨ ਕਲਾ)
:::
::: media

⟪अलम्⟫ ਵਿਸ਼ੇਸ਼ਣ: "ਕਾਫੀ, ਪਰਿਪੂਰਨ, ਸਮਰੱਥ": ⟪अलं योधो योधाय⟫ = "ਇੱਕ ਯੋਧਾ ਦੂਜੇ ਯੋਧੇ ਲਈ ਸਮਰੱਥ ਹੈ"

## 24.2. ਦਾਤਰਿ (⟪चतुर्थी⟫) ਦੀ ਬਣਾਵਟ

::: grammar-box
**ਦਾਤਰਿ ਕਾਰਕ ਦੇ ਨਿਯਮਿਤ ਅੰਤ ਸ਼ਬਦ ਹਨ:**

* **ਇਕਵਚਨ: -e ; ਸ਼ਬਦ-ਅੰਤ ਵਾਲੀਆਂ ਨਰੀਵਾਚਕ ਸਮੂਹ: -ai**
* **ਬਹੁਵਚਨ: ਦਾਤਰਿ ਅਤੇ ਆਪੇਟਿਵ ⟪पञ्चमी⟫: -bhyas**
:::

### 24.2.4. ਸਵਰ-ਅਧਾਰਿਤ ਨਾਮ

::: grammar-box
**ਸਵਰ-ਅਧਾਰਿਤ ਨਾਮ**

* **ਪੁਲਿੰਗ / ਨਪੁੰਸਕ ਲਿੰਗ -a 'ਤੇ ਸਮਾਪਤ:** ⟪देव⟫
* ਦਾਤ. ਵਚਨ ⟪देवाय⟫
* ਦਾਤ. ਬਹੁਵਚਨ ⟪देवेभ्यस्⟫
* **ਪੁਲਿੰਗ -i 'ਤੇ ਸਮਾਪਤ:** ⟪कवि⟫
* ਦਾਤ. ਵਚਨ ⟪कवये⟫
* ਦਾਤ. ਬਹੁਵਚਨ ⟪कविभ्यस्⟫
* **ਪੁਲਿੰਗ -u 'ਤੇ ਸਮਾਪਤ:** ⟪पशु⟫
* ਦਾਤ. ਵਚਨ ⟪पशवे⟫
* ਦਾਤ. ਬਹੁਵਚਨ ⟪पशुभ्यस्⟫
* **ਸਤ੍ਰੀ ਲਿੰਗ -ā 'ਤੇ ਸਮਾਪਤ:** ⟪देवता⟫
* ਦਾਤ. ਵਚਨ ⟪देवतायै⟫
* ਦਾਤ. ਬਹੁਵਚਨ ⟪देवताभ्यस्⟫
* **ਸਤ੍ਰੀ ਲਿੰਗ -ī 'ਤੇ ਸਮਾਪਤ:** ⟪देवी⟫
* ਦਾਤ. ਵਚਨ ⟪देव्यै⟫
* ਦਾਤ. ਬਹੁਵਚਨ ⟪देवीभ्यस्⟫
* **ਸਤ੍ਰੀ ਲਿੰਗ -i 'ਤੇ ਸਮਾਪਤ:** ⟪श्रुति⟫
* ਦਾਤ. ਵਚਨ ⟪श्रुतये⟫ ਜਾਂ ⟪श्रुत्यै⟫ (ਭਾਵ ⟪कवि⟫ ਵਾਂਗ ਜਾਂ ⟪देवी⟫ ਵਾਂਗ)
* ਦਾਤ. ਬਹੁਵਚਨ ⟪श्रुतिभ्यस्⟫
* **ਸਤ੍ਰੀ ਲਿੰਗ -u 'ਤੇ ਸਮਾਪਤ:** ⟪धेनु⟫
* ਦਾਤ. ਵਚਨ ⟪धेनवे⟫ ਜਾਂ ⟪धेन्वै⟫
* ਦਾਤ. ਬਹੁਵਚਨ ⟪धेनुभ्यस्⟫

## 24.3. ਸਮਾਪਤ -ai ਅਤੇ -au ਦਾ ਸੰਧੀ

::: grammar-box
**ਸਮਾਪਤ -ai ਅਤੇ -au ਦਾ ਸੰਧੀ**

* **-ai ਸ਼ੁਰੂਆਤੀ ਸਵਰ ਤੋਂ ਪਹਿਲਾਂ ਆਮ ਤੌਰ 'ਤੇ -ā ਨਾਲ ਬਦਲ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ (ਅੰਦਰੂਨੀ ਸ਼ਬਦਾਂ ਵਿੱਚ -āy ਵਾਂਗ ਘੱਟ ਹੀ)**
* **-au ਸਵਰ ਤੋਂ ਪਹਿਲਾਂ ਆਮ ਤੌਰ 'ਤੇ -āv ਨਾਲ ਬਦਲ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ (ਘੱਟ ਹੀ -ā)**

ਉਦਾਹਰਣ:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा अग्नये⟫ = "ਇਸ ਅੱਗ ਨੂੰ"
:::
## 24.4. ਸ਼ਬਦ-ਸੂਚੀ

⟪अलम्⟫ ਵਿਸ਼ੇਸ਼ਣ: ਕਾਫੀ, ਪਰਿਪੂਰਨ; (ਕੋਈ ਵਿਅਕਤੀ, ਕੁਝ) ਸਮਰੱਥ; ਡੇਟਿਵ ਨਾਲ: ਕਾਫੀ, ਪਰਿਪੂਰਨ; ਇੰਸਟ੍ਰੁਮੈਂਟਲ ਨਾਲ: ਕਾਫੀ, ਛੱਡ ਦਿਓ; ਉਦਾਹਰਣ ⟪अलं क्रोधेन⟫ = "ਕ੍ਰੋਧ ਨਾਲ ਕਾਫੀ = ਕ੍ਰੋਧ ਛੱਡ ਦਿਓ!"

ਇਸੇ ਤਰ੍ਹਾਂ ⟪अलम्⟫ ਨੂੰ ਇੰਸਟ੍ਰੁਮੈਂਟਲ ਨਾਲ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ:

::: indent
⟪अलंकार⟫ ਪੁਲਿੰਗ: ਸਜਾਵਟ, ਸਜਾਉਣ ਦਾ ਯੰਤਰ (ਕਾਵਿ ਵਿੱਚ)

⟪वृत्⟫ ਤੋਂ:

⟪ब्राह्मणो देवप्रतिमादर्शनाय गर्भगृहं विशति ॥१॥ नरा धनलाभाय व्रतानि चरन्ति ॥२॥ गुरुर्धर्मोपदेशाय नगरं गतः ॥३॥ बाला अपि गुरुवचनश्रुत्यै नगरं गताः ॥४॥ देवप्रतिमायै गृहं गर्भगृहम् ॥५॥ स्वर्गेभ्यो नराः पुण्यं कर्तुमिच्छन्ति ॥६॥ मोक्षार्थं बुद्धगता बुद्ध्याप्तिमिच्छन्ति ॥७॥ देवास्तेभ्यो ऽकृतपूजाब्राह्मणेभ्यः क्रुध्यन्ति ॥८॥ मरणाय जना जायन्ते ॥९॥⟫
