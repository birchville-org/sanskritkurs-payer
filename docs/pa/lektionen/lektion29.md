# ਪਾਠ 29

## 29.1. ਕਾਰਣਕ ਵਿੱਚ ਪਰਸਮੈਪਦ (परस्मैपद) ਅਤੇ ਆਤਮਨੇਪਦ (आत्मनेपद) ਦੀ ਵਰਤੋਂ


::: grammar-box
**ਕਾਰਣਕ ਕੁਝ ਵਿਸਤਾਰਾਂ ਨਾਲ ਉਭਯਪਦ (उभयपद) ਹੈ**
:::


::: grammar-box
**ਕਾਰਣਕ ਵਿੱਚ ਆਤਮਨੇਪਦ (आत्मनेपद) ਦੀ ਵਰਤੋਂ ਕੀਤੀ ਜਾਂਦੀ ਹੈ:**

**1. ਜਦੋਂ ਕਿ ਵਿਅਕਤੀ ਦੁਆਰਾ ਕੀਤੀ ਗਈ ਕਾਰਵਾਈ ਦਾ ਫਲ ਵਿਅਕਤੀ ਨੂੰ ਹੀ ਮਿਲਦਾ ਹੈ:**
:::

ਉਦਾਹਰਣ:

रामः कटं कारयते = "ਰਾਮ ਆਪਣੇ ਲਈ (ਆਪਣੇ ਫਾਇਦੇ ਲਈ) ਇੱਕ ਚਾਦਰ ਬਣਵਾਉਂਦਾ ਹੈ"

**2. ਜਦੋਂ ਕਾਰਣਕ ਵਿੱਚ ਸੰਕਰਮਕ ਕ੍ਰਿਆਵਾਂ ਦਾ ਪ੍ਰਤਿਕ੍ਰਿਆਤਮਕ (reflexive) ਉਪਯੋਗ ਕੀਤਾ ਜਾਂਦਾ ਹੈ ("ਆਪਣੇ ਆਪ ਨੂੰ ਦਿਖਾਉਣਾ", "ਆਪਣੇ ਆਪ ਨੂੰ ਸੁਣਾਉਣਾ" ਆਦਿ), ਜਾਂ ਜਦੋਂ ਸਧਾਰਨ ਕ੍ਰਿਆ ਦਾ ਕਰਤਾ ਕਾਰਣਕ ਦਾ ਕਰਤਾ (कर्तृ) ਹੁੰਦਾ ਹੈ:**

ਉਦਾਹਰਣ:

विष्णुर्भक्तान्दर्शयते = "ਵਿਸ਼ਨੁ ਆਪਣੇ ਭਕਤਾਂ ਨੂੰ ਆਪਣੇ ਆਪ ਨੂੰ ਦਿਖਾਉਂਦਾ ਹੈ"

ਨਤੀਜਾ: भक्ता विष्णुं पश्यन्ति = "ਭਗਤ ਵਿਸ਼ਨੁ ਨੂੰ ਦੇਖਦੇ ਹਨ"


ਇਸ ਲਈ ਨਿਯਮ ਆਮ ਤੌਰ 'ਤੇ ਉਭਯਪਦ (उभयपद) ਕ੍ਰਿਆਵਾਂ ਵਿੱਚ ਆਤਮਨੇਪਦ (आत्मनेपद) ਦੀ ਵਰਤੋਂ ਦੇ ਨਿਯਮਾਂ ਨਾਲ ਮੇਲ ਖਾਂਦੇ ਹਨ।

## 29.3. ਸੰਸਕ੍ਰਿਤ-ਪੰਜਾਬੀ ਅਨੁਵਾਦ ਅਭਿਆਸ

ਸ਼ਬਦ-ਦਰ-ਸ਼ਬਦ ਸੁੰਦਰ ਜਰਮਨ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰੋ ਅਤੇ ਸੰਸਕ੍ਰਿਤ ਪਾਠਾਂ ਨੂੰ ਰਟੋ:

1\. अविद्या ਦੀ ਪਰਿਭਾਸ਼ਾ :

अनित्याशुचिदुःखा***नात्मसु*** नित्यशुचिसुखात्मख्यातिरविद्या ॥योगसूत्र २.५॥

ਵਿਆਖਿਆ: आत्मसु = ਲੋਕ. اک. आत्मन् ਪੁੰਲਿੰਗ "ਆਤਮਾ ; ਬ੍ਰਹ्ਮ, ਜਿਵੇਂ ਕਿ ਵਿਅਕਤੀ ਵਿੱਚ ਸਾਕਾਰ ਹੁੰਦਾ ਹੈ"

2\. कौटिलीयार्थशास्त्र 1.4. दण्ड ਦੇ ਸਹੀ ਉਪਯੋਗ ਬਾਰੇ :

तीक्ष्णदण्डो भूताना***मुद्वेजनीयो*** भवति ।८।

मृदुदण्डः परिभूयते ।९।

यथार्हदण्डः पूज्यते ।१०।

सु***विज्ञात***प्रणीतो हि दण्डः प्रजा धर्मार्थकामै***र्योजयति*** ।११।

दुष्प्रणीतः ***कामक्रोधाभ्याम***वज्ञानाद्वा वानप्रस्थपरिव्राजकानपि कोपयति, ***किमङ्ग*** पुनर्गृहस्थान् ।१२।

अप्रणीतस्तु मात्स्यन्यायमुद्भावयति ।१३।

**बलीयान**अबलं हि ग्रसते दण्डधराभावे ।१४।

स तेन गुप्तः प्रभवतीति ।१५।
::: indent
**चतुर्व**र्णाश्रमो लोको

स्वधर्मकर्माभिरतो  
वर्तते **स्वेषु वर्त्मसु** ॥१६॥
:::

।११। विज्ञात ३ "ਪਛਾਣਿਆ ਗਿਆ" ; ਨਪੁੰਸਕਲਿੰਗ: ਪਛਾਣ

।११। योजयति (ਕਾਰਕ. युज् ਤੋਂ) "ਬੰਨ੍ਹਣਾ, ਜੋੜਨਾ, ਇਕਾਈ ਬਣਾਉਣਾ"

।१२। कामक्रोधाभ्याम् : ਇੰਸਟ੍ਰ., ਡੇਟ., ਐਬਲ., ਦੁਵਿੰਗ ਪੁੰਲਿੰਗ कामक्रोध (ਦੁਵਿੰਦਵੁ)

।१२। किमङ्ग "ਕਿੰਨਾ ਜ਼ਿਆਦਾ"

।१४। बलीयान् : ਨਾਮ. اک. ਪੁੰਲਿੰਗ बलीयस् ३ "ਮਜ਼ਬੂਤ"

।१६। चतुर् "ਚਾਰ" ਸੰਯੁਕਤ ਸ਼ਬਦ ਦੇ ਪਹਿਲੇ ਭਾਗ ਵਜੋਂ

राज्ञा ਇੰਸਟ੍ਰ. اک. ਪੁੰਲਿੰਗ राजन् ਪੁੰਲਿੰਗ "ਰਾਜਾ"

स्वेषु : ਲੋਕ. ਬਹੁਵਚਨ ਪੁੰਲਿੰਗ / ਨਪੁੰਸਕਲਿੰਗ स्व ३ "ਆਪਣਾ (ਮੇਰਾ, ਤੇਰਾ, ਉਸਦਾ ਆਦਿ)"

वर्त्मसु : ਲੋਕ. ਬਹੁਵਚਨ ਨਪੁੰਸਕਲਿੰਗ वर्त्मन् ਨਪੁੰਸਕਲਿੰਗ "ਮਾਰਗ, ਰੇਲ, ਰਾਹ"
