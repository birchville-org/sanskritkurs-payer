## 10.1. ਨਿਸ਼ਕਰਮਕ ਵਾਕ

::: grammar-box
**ਸਕੀਮ:**
**(ਕਰਤਾ - kartṛ - ਤੀਜੇ ਵਿਭਕਤੀ (tṛtīyā) ਵਿੱਚ) - (ਪ੍ਰਤੱਖ ਵਸਤੂ - karman - ਨਾਮਵਾਚਕ ਵਿੱਚ) - ਨਿਸ਼ਕਰਮਕ ਕ੍ਰਿਆ ਰੂਪ**

ਉਦਾਹਰਣ ਵਜੋਂ **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन⟫ ⟪देव⟫ ⟪इज्यते⟫ = "ਇੱਕ ਬ੍ਰਾਹਮਣ ਇੱਕ ਦੇਵਤਾ ਦੀ ਪੂਜਾ ਕਰਦਾ ਹੈ" (ਸ਼ਬਦ-ਦਰ-ਸ਼ਬਦ: "ਇੱਕ ਦੇਵਤਾ ਇੱਕ ਬ੍ਰਾਹਮਣ ਦੁਆਰਾ ਇੱਕ ਯਾਗ ਨਾਲ ਪੂਜਾ ਜਾਂਦਾ ਹੈ।")

ਇਹ ਵਾਕ ਉਸ ਵਾਕ ਦੇ **ਬਿਲਕੁਲ (!) ਅਰਥ ਵਿੱਚ ਸਮਾਨ** ਹੈ:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो⟫ ⟪देवं⟫ ⟪यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
- ਨਿਸ਼ਕਰਮਕ ਵਾਕ ਵਿੱਚ ਕਰਤਾ (**kartṛ**) **ਤੀਜੇ ਵਿਭਕਤੀ** (tṛtīyā f. "ਤੀਜਾ ਵਿਭਕਤੀ ਅੰਤ") ਵਿੱਚ ਹੁੰਦਾ ਹੈ, ਪ੍ਰਤੱਖ ਵਸਤੂ (**karman** n.) **ਨਾਮਵਾਚਕ** (prathamā f.) ਵਿੱਚ ਹੁੰਦੀ ਹੈ।
- ਨਿਸ਼ਕਰਮਕ ਵਾਕ, ਜਿਨ੍ਹਾਂ ਵਿੱਚ ਕਰਤਾ ਦਾ ਜ਼ਿਕਰ ਨਹੀਂ ਕੀਤਾ ਜਾਂਦਾ, ਆਮ ਤੌਰ 'ਤੇ ਨਿਰਪੇਖ ਅਰਥ ਰੱਖਦੇ ਹਨ ("ਮਨੁੱਖ"):
  ਉਦਾਹਰਣ ਵਜੋਂ **ijyate** = ⟪इज्यते⟫ "ਮਨੁੱਖ ਯਾਗ ਕਰਦਾ ਹੈ" (ਸ਼ਬਦ-ਦਰ-ਸ਼ਬਦ: "ਇੱਕ ਯਾਗ ਨਾਲ ਪੂਜਾ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।")
:::

::: grammar-box
**ਭਾਵੇਂ ਸੰਬੰਧਿਤ ਸਰਗਰਮ ਵਾਕ ਵਿੱਚ ਉਦੇਸ਼ ਦਾ ਦੂਜਾ ਵਿਭਕਤੀ (dvitīyā) ਹੋਵੇ, ਪਰੰਤੂ ਨਿਸ਼ਕਰਮਕ ਵਾਕ ਵਿੱਚ ਇਸਨੂੰ ਨਾਮਵਾਚਕ (prathamā) ਵਿੱਚ ਰੱਖਿਆ ਜਾ ਸਕਦਾ ਹੈ:**

ਸਰਗਰਮ ਵਾਕ **rāmo grāmaṃ gacchati** = ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "ਰਾਮ ਪਿੰਡ ਜਾਂਦਾ ਹੈ।" ਦੇ ਸੰਬੰਧਿਤ ਨਿਸ਼ਕਰਮਕ ਵਾਕ ਹਨ:
- **rāmeṇa grāmaṃ gamyate** = ⟪रामेण⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫
- ਵਿਕਲਪਿਕ ਤੌਰ 'ਤੇ: **rāmeṇa grāmo gamyate** = ⟪रामेण⟫ ⟪ग्रामो⟫ ⟪गम्यते⟫
:::

::: grammar-box
**ਨਿਰਕਰਮਕ ਕ੍ਰਿਆਵਾਂ (ਪ੍ਰਤੱਖ ਵਸਤੂ ਵਾਲੀਆਂ ਕ੍ਰਿਆਵਾਂ) ਵਿੱਚ ਅਕਸਰ ਨਿਸ਼ਕਰਮਕ ਬਣਤਰਾਂ ਹੁੰਦੀਆਂ ਹਨ, ਖਾਸ ਕਰਕੇ ਸ਼ਿਸ਼ਟ ਅਪੀਲਾਂ ਵਿੱਚ:**
- **praviśyatām** = ⟪प्रविश्यताम्⟫ = "ਕਿਰਪਾ ਕਰਕੇ ਅੰਦਰ ਆਉਣ = ਕਿਰਪਾ ਕਰਕੇ ਅੰਦਰ ਆਓ = ਅੰਦਰ ਆਓ!"
- **niṣadyatām** = ⟪निषद्यताम्⟫ = "ਕਿਰਪਾ ਕਰਕੇ ਬੈਠਣ = ਕਿਰਪਾ ਕਰਕੇ ਬੈਠੋ = ਕਿਰਪਾ ਕਰਕੇ ਥਾਂ ਲਓ"
:::
ਸੰਸਕ੍ਰਿਤ-ਨਿਸ਼ਕਰਮਕ ਬਣਤਰਾਂ ਬਹੁਤ ਹੀ ਆਮ ਹਨ: ਨਿਸ਼ਕਰਮਕ ਬਣਾਉਣਾ, ਉਦਾਹਰਣ ਵਜੋਂ ਕਈ ਵਰਤਮਾਨ ਕਾਲ ਦੇ ਸਟੈਮਾਂ ਨਾਲੋਂ, ਵਧੇਰੇ ਆਸਾਨ ਹੈ।

::: important
**ਸੰਸਕ੍ਰਿਤ-ਨਿਸ਼ਕਰਮਕ ਵਾਕਾਂ ਨੂੰ ਜਰਮਨ ਵਿੱਚ ਆਮ ਤੌਰ 'ਤੇ ਨਿਸ਼ਕਰਮਕ ਵਾਕ ਦੁਆਰਾ ਨਹੀਂ ਦਰਸਾਇਆ ਜਾ ਸਕਦਾ, ਕਿਉਂਕਿ ਜਰਮਨ ਨਿਸ਼ਕਰਮਕ ਦੀ ਇੱਕ ਬਿਲਕੁਲ ਵੱਖਰੀ ਸ਼ੈਲੀਗਤ ਭੂਮਿਕਾ ਹੈ।**
:::

### 10.2.1. ਕਰਣ (tṛtīyā = ⟪तृतीया⟫) ਦੇ ਉਪਯੋਗ ਬਾਰੇ

::: grammar-box
**ਕਰਣ (tṛtīyā) ਮੁੱਖ ਤੌਰ 'ਤੇ ਹੇਠ ਲਿਖੇ ਸਵਾਲਾਂ 'ਤੇ ਆਉਂਦਾ ਹੈ:**
- **ਕਿਸ ਦੁਆਰਾ?**
- **ਕਿਸ ਨਾਲ?**
- **ਕਿਸ ਨਾਲ?**

**ਇਹ ਆਉਂਦਾ ਹੈ**
1. **ਕਰਮਵਾਚਕ ਵਾਕਾਂ ਵਿੱਚ: ਕਰਤਾ (kartṛ) ਕਰਣ ਵਿੱਚ**
2. **ਉਸ ਮੱਧਮ ਜਾਂ ਔਜ਼ਾਰ ਦੀ ਸੂਚਨਾ ਲਈ, ਜਿਸ ਨਾਲ ਕੋਈ ਕੰਮ ਪੂਰਾ ਕੀਤਾ ਜਾਂਦਾ ਹੈ**
3. **ਉਸ ਰਸਤੇ ਦੀ ਸੂਚਨਾ ਲਈ, ਜਿਸ ਰਾਹੀਂ ਕੋਈ ਵਿਅਕਤੀ ਕਿਤੇ ਪਹੁੰਚਦਾ ਹੈ**
4. **ਸੰਬੰਧ, ਸੰਯੋਗ, ਸਾਥ ਦਾ ਪ੍ਰਗਟਾਵਾ ਕਰਨ ਲਈ**
5. **ਪਿਛੋਕੜੀ ਸ਼ਬਦਾਂ ਦੇ ਨਾਲ "ਸਾਥ, ਨਾਲ" ਅਰਥ ਵਿੱਚ; ਜਿਵੇਂ ਕਿ: saha = ⟪सह⟫ = "ਨਾਲ"** :brਜਿਵੇਂ ਕਿ:br **brāhmaṇena saha** = ⟪ब्राह्मणेन⟫ ⟪सह⟫ = "ਬ੍ਰਾਹਮਣ ਦੇ ਨਾਲ ਸਾਂਝੇ ਤੌਰ 'ਤੇ"
:::
ਕਰਣ (tṛtīyā) ਦੇ ਹੋਰ ਉਪਯੋਗ ਬਾਅਦ ਵਿੱਚ ਆਉਣਗੇ।


## 10.3. -n- ਲਈ ਸੰਜੀਵਨ ਨਿਯਮ (ਇੱਕ ਸ਼ਬਦ ਸੰਧੀ)

::: grammar-box
ਇੱਕ **-n-**, ਜਿਸਦੇ ਬਾਅਦ ਇੱਕ ਸਵਰਨ ਅੱਖਰ ਜਾਂ **n, m, y, v** ਆਉਂਦਾ ਹੈ, **-ṇ-** ਦੁਆਰਾ ਬਦਲ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ, ਜੇਕਰ ਸ਼ਬਦ ਵਿੱਚ **ṛ, ṝ, r, ṣ** **-n-** ਤੋਂ ਪਹਿਲਾਂ ਆਉਂਦੇ ਹਨ ਜਾਂ ਇਨ੍ਹਾਂ ਧੁਨੀਆਂ ਅਤੇ ਅਗਲੇ **-n-** ਵਿਚਕਾਰ ਸਵਰਨ, ਗੁੰਠਿਤ, ਓਠਜ, **y, v, h** ਜਾਂ ਅਨੁਸਵਾਰ ਤੋਂ ਇਲਾਵਾ ਕੋਈ ਹੋਰ ਧੁਨੀ ਨਹੀਂ ਹੈ।
:::
**ਇਸ ਲਈ:**

| | ਕਰਣ ਵਿੱਚ ਇਕਵਚਨ |

| :--- | :--- |

| **ਸ਼ੂਦਰ** :br⟪शूद्र⟫ | **ਸ਼ੂਦਰੇਣ** :br⟪शूद्रेण⟫ |
| **ਈਸ਼ਵਰ** :br⟪ईश्वर⟫ | **ਈਸ਼ਵਰੇਣ** :br⟪ईश्वरेण⟫ |
| **ਕ੍ਸ਼ਤ੍ਰਿਯ** :br⟪क्षत्रिय⟫ | **ਕ੍ਸ਼ਤ੍ਰਿਯੇਣ** :br⟪क्षत्रियेण⟫ |
| **ਨਰਕ** :br⟪नरक⟫ | **ਨਰਕੇਣ** :br⟪नरकेण⟫ |

**ਇਸ ਤਰ੍ਹਾਂ -ṇ- ਦਾ ਵਿਆਖਿਆ ਵੀ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ:**

## 10.4. ਪੈਸਿਵ, ਇੰਡੀਕੇਟਿਵ ਪ੍ਰੇਜ਼ੈਂਸ (yak = ⟪यक्⟫)

::: grammar-box
**ਬਣਾਉਣਾ:**
**(ਆਮ ਤੌਰ 'ਤੇ) ਡੀਪ ਸਟੈਂਡ ਰੂਟ + -ya- + ਆਤਮਨੇਪਦਾ ਖਤਮ**

## 10.6. ਅਭਿਆਸ

**A) ਹੇਠ ਲਿਖੇ ਕ੍ਰਿਆ ਰੂਪਾਂ ਦਾ ਨਿਸੇਧ ਬਣਾਓ (ਕ੍ਰਿਆ ਰੂਪ ਦਾ ਅਨੁਵਾਦ ਨਾਲ):**

1. **sṛjati** (⟪सृजति⟫)
2. **yudhyate** (⟪युध्यते⟫)
3. **bhavanti** (⟪भवन्ति⟫)
4. **yajati** (⟪यजति⟫)
5. **nṛtyati** (⟪नृत्यति⟫)
6. **nayanti** (⟪नयन्ति⟫)
7. **smarati** (⟪स्मरति⟫)
8. **śṛṇvanti** (⟪शृण्वन्ति⟫)
9. **paśyati** (⟪पश्यति⟫) (ਨਿਸੇਧ **dṛś** ਤੋਂ ਬਣਦਾ ਹੈ!)
10. **jayanti** (⟪जयन्ति⟫)
11. **kurvate** (⟪कुर्वते⟫)
12. **āpnuvanti** (⟪आप्नुवन्ति⟫)
13. **viśati** (⟪विशति⟫)
14. **khādanti** (⟪खादन्ति⟫)
15. **sunoti** (⟪सुनोति⟫)
16. **gacchati** (⟪गच्छति⟫)
17. **manyante** (⟪मन्यन्ते⟫)
18. **labhante** (⟪लभन्ते⟫)
19. **rakṣanti** (⟪रक्षन्ति⟫)
20. **vadanti** (⟪वदन्ति⟫)
21. **pṛcchanti** (⟪पृच्छन्ति⟫)
22. **tanvanti** (⟪तन्वन्ति⟫) (2 ਰੂਪ!)

**B) ਸੰਸਕ੍ਰਿਤ ਵਿੱਚ ਸਿੱਖੇ ਗਏ ਸਾਰੇ ਨਾਂਵਾਂ ਲਈ ਇੰਸਟਰੂਮੈਟਲ ਸਿੰਗੁਲਰ ਅਤੇ ਪਲੂਰਲ ਬਣਾਓ।**

**C) ਹੇਠ ਲਿਖੇ ਵਾਕਾਂ ਨੂੰ ਪੈਸਿਵ (ਕਰਮਕਾਰੀ) ਵਿੱਚ ਬਦਲੋ ਅਤੇ ਉਨ੍ਹਾਂ ਦਾ ਅਨੁਵਾਦ ਕਰੋ:**
1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो⟫ ⟪देवीं⟫ ⟪यजति⟫)
2. **sādhuḥ svargaṃ gacchati.** (⟪साधुः⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫)
3. **śūdraṃ jayati.** (⟪शूद्रं⟫ ⟪जयति⟫)
4. **guruḥ phalāni khādati.** (⟪गुरुः⟫ ⟪फलानि⟫ ⟪खादति⟫)
5. **gurūñchṛṇoti.** (⟪गुरूञ्छृणोति⟫)
6. **ko 'gniṃ paśyati.** (⟪को⟫ ⟪ऽग्निं⟫ ⟪पश्यति⟫)
7. **ayaṃ kavirmantraṃ smarati.** (⟪अयं⟫ ⟪कविर्मन्त्रं⟫ ⟪स्मरति⟫)
8. **iyaṃ devī kṣatriyā rakṣati.** (⟪इयं⟫ ⟪देवी⟫ ⟪क्षत्रिया⟫ ⟪रक्षति⟫)
9. **kṣatriyā viṣṇuṃ yajante.** (⟪क्षत्रिया⟫ ⟪विष्णुं⟫ ⟪यजन्ते⟫) (2 ਸੰਭਾਵਨਾਵਾਂ)
10. **brāhmaṇo 'gniṃ karoti.** (⟪ब्राह्मणो⟫ ⟪ऽग्निं⟫ ⟪करोति⟫)
11. **vaiśyā imaṃ grāmaṃ gacchanti.** (⟪वैश्या⟫ ⟪इमं⟫ ⟪ग्रामं⟫ ⟪गच्छन्ति⟫) (2 ਸੰਭਾਵਨਾਵਾਂ)
12. **ete gurūṃstu śṛṇvanti.** (⟪एते⟫ ⟪गुरूंस्तु⟫ ⟪शृण्वन्ति⟫)
13. **sādhuḥ svargamāpnoti.** (⟪साधुः⟫ ⟪स्वर्गमाप्नोति⟫)
14. **brāhmāṇāḥ somaṃ sunvanti.** (⟪ब्राह्मणाः⟫ ⟪सोमं⟫ ⟪सुन्वन्ति⟫)
15. **paśūllabhate.** (⟪पशूल्लभते⟫)
16. **ke yodhāḥ kṣatriyaiḥ saha yudhyante.** (⟪के⟫ ⟪योधाः⟫ ⟪क्षत्रियैः⟫ ⟪सह⟫ ⟪युध्यन्ते⟫)

**D) ਸੰਸਕ੍ਰਿਤ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰੋ:**
1. ਇੱਕ ਬ੍ਰਾਹਮਣ ਇੱਕ ਵੈਸ਼ਯ ਦੇ ਨਾਲ ਪਿੰਡ ਜਾਂਦਾ ਹੈ।
2. ਉਹ ਇੱਕ ਬਲੀਦਾਨ ਨਾਲ ਵਿਸ਼ਣੂ ਦੀ ਉਪਾਸਨਾ ਕਰਦਾ ਹੈ। (ਬਲੀਦਾਨ **yajña** ਨੂੰ ਦਰਸਾਓ!)
3. ਵੇਦ ਨੂੰ ਸ਼ਰੁਤੀ ਕਿਹਾ ਜਾਂਦਾ ਹੈ। (**vad**)
