# ਦੇਵਨਾਗਰੀ = ⟪देवनागरी⟫

## ਲਿਖਤ ਅਭਿਆਸ 1

ਸੰਸਕ੍ਰਿਤ ਨੂੰ ਵੱਖ-ਵੱਖ ਲਿਪੀਆਂ ਵਿੱਚ ਲਿਖਿਆ ਜਾਂਦਾ ਰਿਹਾ ਹੈ ਅਤੇ ਹੁਣ ਵੀ ਲਿਖਿਆ ਜਾ ਰਿਹਾ ਹੈ। ਹੇਠਾਂ ਦਿੱਤੀ ਸਾਰਣੀ ਇਨ੍ਹਾਂ ਲਿਪੀਆਂ ਵਿੱਚੋਂ ਇੱਕ ਛੋਟਾ ਜਿਹਾ ਨਮੂਨਾ ਪੇਸ਼ ਕਰਦੀ ਹੈ:

![](/images/schrift001.webp)  
ਚਿੱਤਰ: ਸੰਸਕ੍ਰਿਤ ਲਿਪੀ ਦੇ ਨਮੂਨੇ
\[ਚਿੱਤਰ ਸਰੋਤ: ਵਿਕੀਪੀਡੀਆ, GNU FD ਲਾਇਸੈਂਸ\]

ਮੁੱਖ ਆਧੁਨਿਕ ਉੱਤਰੀ ਭਾਰਤੀ ਸੰਸਕ੍ਰਿਤ ਲਿਪੀ ਦੇਵਨਾਗਰੀ ਹੈ:

![](/images/schrift002.webp)

ਹਰੇਕ ਵਿਆਜਨ (consonant) ਚਿੰਹ ਇੱਕ 'a' ਸਵਰ ਨੂੰ ਦਰਸਾਉਂਦੀ ਹੈ ਜੋ ਵਿਆਜਨ ਦੇ ਬਾਅਦ ਆਉਂਦਾ ਹੈ। ਜੇਕਰ ਸਿਰਫ਼ ਵਿਆਜਨ ਨੂੰ ਲਿਖਣਾ ਹੋਵੇ (ਬਿਨਾਂ ਕਿਸੇ ਸਵਰ ਦੇ), ਤਾਂ ਇਸਨੂੰ ਹੇਠਾਂ ਲਗਾਇਆ ਗਿਆ ਢਲਾਣ ਵਾਲੀ ਰੇਖਾ -- ਵਿਰਾਮ = ⟪विराम⟫ -- ਦੁਆਰਾ ਸਪੱਸ਼ਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

ਵਿਆਜਨ ਦੇ ਬਾਅਦ ਆਉਂਦੇ ਸਵਰ -- 'a' ਨੂੰ ਛੱਡ ਕੇ -- ਇਸ ਤਰ੍ਹਾਂ ਲਿਖੇ ਜਾਂਦੇ ਹਨ:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

ਇਹਨਾਂ ਵਿਆਜਨ + ਸਵਰ ਜੋੜਿਆਂ ਨੂੰ ਲਿਖਣ ਦਾ ਕ੍ਰਮ ਇਹ ਹੈ:

![](/images/schrift003.jpg)

ਲਿਖਦੇ ਸਮੇਂ ਹਰੇਕ ਅੱਖਰ ਨੂੰ ਉਪਰਲੀ ਰੇਖਾ ਤੱਕ ਪੂਰਾ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਫਿਰ ਅਗਲਾ ਅੱਖਰ ਲਿਖਿਆ ਜਾਂਦਾ ਹੈ।

## ਅਭਿਆਸ

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

ਪੜ੍ਹੋ ਅਤੇ ਟ੍ਰਾਂਸਲਿਟੇਰੇਟ ਕਰੋ:

⟪तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ⟫

ਵਾਧੂ ਪੜ੍ਹਨ ਦੀ ਅਭਿਆਸ:

⟪पिता⟫ ਪਿਤਾ, ⟪कपि⟫ ਵਾਂਦਰ, ⟪कृत⟫ ਕੀਤਾ ਹੈ, ⟪टीका⟫ ਉਪ-ਟਿੱਪਣੀ, ⟪तत्⟫ ਇਹ, ⟪तट⟫ ਕਿਨਾਰਾ, ⟪पत्⟫ ਛੱਡਣਾ/ਭੇਜਣਾ, ⟪पट⟫ ਬੁਣਾਈ/ਕੱਪੜਾ, ⟪काच⟫ ਸ਼ੀਸ਼ਾ/ਗਲਾਸ, ⟪काकुत्⟫ ਤਾਲੂ (ਮੂੰਹ ਦੀ ਛੱਤ), ⟪चित्⟫ ਸੰਵੇਦਨਾ/ਪਛਾਣ, ⟪पृच्⟫ ਮਿਲਾਉਣਾ/ਮਿਸ਼ਰਨ, ⟪पोटक⟫ ਨੌਕਰ/ਦਾਸ, ⟪चेतु⟫ ਇਰਾਦਾ/ਮਨਸ਼ਾ, ⟪तौतातित⟫ ਕੁਮਾਰਿਲ (ਮੀਮਾਂਸਾ) ਦਾ ਅਨੁਯਾਈ, ⟪तूत⟫ ਸ਼ੇਰੜ ਦਾ ਰੁੱਖ, ⟪पीत⟫ ਪੀਤਾ ਹੈ, ⟪पीति⟫ ਪਿਆਲਾ/ਪੀਣ ਦਾ ਵਸਤੂ, ⟪कॢप्⟫ ਢੁਕਵਾਂ ਹੋਣਾ/ਸਥਿਤੀ, ⟪कृपते⟫ ਉਹ ਰੋਂਦਾ/ਗਿਲਾ ਕਰਦਾ ਹੈ, ⟪पुटी⟫ ਝੁਕੜ/ਭਾਂਜ, ⟪चापि⟫ ਇਸੇ ਤਰ੍ਹਾਂ/ਉੱਨਤ, ⟪तोक⟫ ਵੰਸ਼/ਪਰਵਾਰ, ⟪तृपत्⟫ ਭਰਿਆ/ਸੰਤੁਸ਼ਟ, ⟪पॄ⟫ ਭਰਨਾ/ਪੂਰਾ ਕਰਨਾ, ⟪कृकाटी⟫ ਗਲੇ ਦਾ ਜੋੜ/ਗਰਦਨ, ⟪पूपौ⟫ ਦੋ ਕੇਕ/ਰੋਟੀ, ⟪पैतृकी⟫ ਪਿਤਾ-ਸੰਬੰਧੀ (ਇਸਤ੍ਰੀ ਲਿੰਗ), ⟪कौट⟫ ਧੋਖਾਦੇਹ/ਕਪਟੀ, ⟪कच⟫ ਸਿਰ ਦੇ ਵਾਲ/ਮੁੱਖ-ਵਾਲ, ⟪कुतपे⟫ ਬਕਰੇ ਦੇ ਵਾਲਾਂ ਦੀ ਚਾਦਰ 'ਤੇ, ⟪कुचौ⟫ ਛਾਤੀ/ਬੁੱਖ, ⟪चकिता⟫ ਡਰਿਆ ਹੋਇਆ (ਇਸਤ੍ਰੀ ਲਿੰਗ)
