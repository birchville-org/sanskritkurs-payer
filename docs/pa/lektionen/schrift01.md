# देवनागरी = देवनागरी

## ਲਿਪਿ ਅਭਿਆਸ 1

ਸੰਸਕ੍ਰਿਤ ਨੂੰ ਅਤੇ ਇਸਨੂੰ ਲਿਖਣ ਲਈ ਕਈ ਤਰ੍ਹਾਂ ਦੀਆਂ ਲਿਪੀਆਂ ਵਿੱਚ ਲਿਖਿਆ ਜਾਂਦਾ ਹੈ। ਹੇਠਾਂ ਦਿੱਤੀ ਸਾਰਣੀ ਇਨ੍ਹਾਂ ਲਿਪੀਆਂ ਵਿੱਚੋਂ ਇੱਕ ਛੋਟਾ ਜਿਹਾ ਚਿੱਤਰ ਦਿੰਦੀ ਹੈ:

![](/images/schrift001.webp)  
ਚਿੱਤਰ: ਸੰਸਕ੍ਰਿਤ ਲਿਪੀ ਦੇ ਨਮੂਨੇ  
\[ਚਿੱਤਰ ਸਰੋਤ: ਵਿਕੀਪੀਡੀਆ, GNU FD ਲਾਇਸੈਂਸ\]

Die wichtigste moderne nordindische Sanskritschrift ist die Devanāgarī:

![](/images/schrift002.webp)

ਹਰੇਕ ਵਰਣਮਾਲਾ ਦਾ ਅੱਖਰ ਇੱਕ ਅਨੁਸਾਰੀ "a" ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ। ਜੇਕਰ ਸਿਰਫ਼ ਅਨੁਸਾਰੀ ਲਿਖਣੀ ਹੋਵੇ (ਬਿਨਾਂ ਅਨੁਸਾਰੀ ਵੋਕਲ ਦੇ), ਤਾਂ ਇਸਨੂੰ ਇੱਕ ਹੇਠਾਂ ਲਿਖੇ ਤਿਰਛੇ ਰੇਖਾ ਦੁਆਰਾ ਦਰਸਾਇਆ ਜਾਣਾ ਚਾਹੀਦਾ ਹੈ -- ਵਿਰਾਮ = विराम --:

क् = k, च् = c, ट् = ṭ, त्  = t, प् = p

ਅਨੁਸਾਰੀ ਤੋਂ ਬਾਅਦ ਵੋਕਲ -- "a" ਨੂੰ ਛੱਡ ਕੇ -- ਇਸ ਤਰ੍ਹਾਂ ਲਿਖੇ ਜਾਂਦੇ ਹਨ:

का = kā, कि = ki, की = kī, कु = ku, कू = kū, कृ = kṛ, कॄ = kṝ, कॢ  = kḷ

के = ke, कै = kai, को = ko, कौ = kau

ਇਨ੍ਹਾਂ ਅਨੁਸਾਰੀ + ਵੋਕਲ ਜੋੜਿਆਂ ਨੂੰ ਲਿਖਣ ਦਾ ਕ੍ਰਮ ਹੈ:

![](/images/schrift003.jpg)

ਲਿਖਦੇ ਸਮੇਂ ਹਰੇਕ ਅੱਖਰ ਨੂੰ ਉੱਪਰਲੀ ਰੇਖਾ ਸਮੇਤ ਪੂਰਾ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਫਿਰ ਅਗਲਾ ਅੱਖਰ ਲਿਖਿਆ ਜਾਂਦਾ ਹੈ।

## ਅਭਿਆਸ

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

ਪੜ੍ਹੋ ਅਤੇ ਟ੍ਰਾਂਸਲਿਟਰੇਟ ਕਰੋ:

तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ

ਵਾਧੂ ਪੜ੍ਹਨ ਦਾ ਅਭਿਆਸ:

पिता ਪਿਤਾ, कपि ਵਾਨਰ, कृत ਕੀਤਾ, टीका ਉਪ-ਟਿੱਪਣੀ, तत् ਇਹ, तट ਤਟ, पत् ਛੱਡਣਾ, पट ਬੁਣਾਈ, काच ਕੱਚ, काकुत् ਤਾਲੂ, चित् ਸੰਵੇਦਨਾ, पृच् ਮਿਲਾਉਣਾ, पोटक ਦਾਸ, चेतु ਉਦੇਸ਼, तौतातित ਕੁਮਾਰਿਲਾ (ਮੀਮਾਂਸ਼ਾ) ਦਾ ਅਨੁਯਾਈ, तूत ਸ਼ੇਰਦਾਨ ਦਾ ਰੁੱਖ, पीत ਪੀਤਾ, पीति ਪੀਣ, कॢप् ਢਲਣਾ, कृपते ਉਹ ਚਿੰਤਾ ਕਰਦਾ ਹੈ, पुटी ਝੁਰੀ, चापि ਇਸੇ ਤਰ੍ਹਾਂ, तोक ਵੰਸ਼, तृपत् ਸੰਤੁਸ਼ਟ, पॄ ਭਰਨਾ, कृकाटी ਗਰਦਨ ਦਾ ਜੋੜ, पूपौ ਦੋ ਕੇਕ, पैतृकी ਪਿਤਾਮਾ (ਸਤੀ), कौट ਧੋਖਾ, कच ਸਿਰ ਦਾ ਵਾਲ, कुतपे ਬੱਕਰੀ ਦੇ ਵਾਲਾਂ ਦੀ ਚਾਦਰ 'ਤੇ, कुचौ ਛਾਤੀ, चकिता ਡਰਪੋਸ਼ (ਸਤੀ)
