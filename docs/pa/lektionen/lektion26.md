# ਪਾਠ 26

## 26.1. ਸ਼ਬਦ ਦੇ ਅੰਦਰੂਨੀ -s- ਲਈ ਮਸਤਿਸ୍କੀਕਰਨ ਨਿਯਮ

::: grammar-box
**-s-** ਨੂੰ **-ṣ-** ਨਾਲ ਬਦਲ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ, ਜਦੋਂ **k, r, l** ਜਾਂ ਇੱਕ **ਸਵਰ** — **a, ā** ਨੂੰ ਛੱਡ ਕੇ — ਤੁਰੰਤ ਜਾਂ ਸਿਰਫ਼ **⟪अनुस्वार⟫** ਜਾਂ **⟪विसर्ग⟫** ਦੁਆਰਾ ਵੱਖ ਕੀਤਾ ਗਿਆ ਪੂਰਵਗਾਮੀ ਹੋਵੇ ਅਤੇ **ṛ, r** ਤੋਂ ਇਲਾਵਾ ਕੋਈ ਹੋਰ ਧ⟪्व⟫ਨੀ ਅਨੁਵਾਦੀ ਹੋਵੇ⟪।⟫

ਇਸ ਸੰਧੀ ਦਾ ਪਾਲਣ **⟪दुस्⟫-** ਵੀ ਕਰਦਾ ਹੈ ਜਦੋਂ ਕਿ ਸੰਯੁਕਤਾਂ ਵਿੱਚ ਨਿਸ਼ਬਦ ਗੁੰਠਿਤ ਅਤੇ ਓਠਜ ਧ⟪्व⟫ਨੀਆਂ ਤੋਂ ਪਹਿਲਾਂ⟪।⟫
:::
*ਉਦਾਹਰਣਾਂ:*
::: indent
**⟪तेषाम्⟫** (ਤੋਂ: *te-sām*)

ਪਰੰਤੂ: **⟪तासाम्⟫** (*tā-sām*)
:::
## 26.2. ਸ਼ਬਦ ਦੇ ਅੰਦਰੂਨੀ ਹਿੱਸੇ ਵਿੱਚ ਦੰਤਾਂ ਲਈ ਮਸਤਿਸ୍କੀਕਰਨ ਦਾ ਨਿਯਮ

::: grammar-box
ਦੰਤ ਬੰਦ ਧ⟪्व⟫ਨੀਆਂ, ਪਿਛਾੜੀਆਂ (ਸ਼ਾਮਲ **-ṣ-**) ਦੇ ਬਾਅਦ, ਸੰਬੰਧਿਤ ਪਿਛਾੜੀਆਂ ਦੁਆਰਾ ਬਦਲ ਦਿੱਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ:

- **iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
  *(**ṣ** ਪਿਛਲੇ **i** ਕਾਰਨ, **ṭh** ਫਿਰ ਪਿਛਲੇ **ṣ** ਕਾਰਨ)*
:::
## 26.3. ਪਲੇਟਲ, ਗੁਟੂਰਲ, ṣ, h + -s ਲਈ ਵਾਰਤਸੰਧੀ

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

ਉਦਾਹਰਣਾਂ ਹੇਠਾਂ ਦੇਖੋ
:::
## 26.4. ਗ੍ਰਾਸਮੈਨ ਦਾ ਸਾਹ-ਅਸਮਾਨਤਾ ਕਾਨੂੰਨ

::: grammar-box
**ਦੋ ਖੰਭਦਾਰਾਂ (ਖੰਭਦਾਰ - ਸਵਰ - ਖੰਭਦਾਰ) ਦੀ ਸਿੱਧੀ ਪ੍ਰਭਾਵ ਪਹਿਲੇ ਧੁਨੀ ਦੇ ਖੰਭਦਾਰਤਾ ਦੇ ਨੁਕਸਾਨ ਦਾ ਕਾਰਨ ਬਣਦੀ ਹੈ:**

ਉਦਾਹਰਨ:

## 26.5. ਵਰ੍ਤ-ਸੰਧੀ -m, -n ਲਈ ਝੁੰਬਰ ਧ⟪्व⟫ਨੀਆਂ ਤੋਂ ਪਹਿਲਾਂ

::: grammar-box
**ਝੁੰਬਰ ਧ⟪्व⟫ਨੀਆਂ ਤੋਂ ਪਹਿਲਾਂ -n ਅਤੇ -m ਨੂੰ -ṃ- ਦੁਆਰਾ ਬਦਲਿਆ ਜਾਂਦਾ ਹੈ:**

ਉਦਾਹਰਣ: ਸ. ਹੇਠਾਂ ਭਵਿੱਖ ਕਾਲ ⟪मन्⟫ ਦਾ
:::
## 26.6. ਸਧਾਰਣ ਭਵਿੱਖ ਕਾਲ ਦੀ ਵਰਤੋਂ (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ਫ਼ੀ.)

::: grammar-box
**ਸਧਾਰਣ ਭਵਿੱਖ ਕਾਲ (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ਫ਼ੀ.) ਇਹ ਦਰਸਾਉਂਦਾ ਹੈ:**

- **ਭਵਿੱਖ**
- **ਇੱਕ ਇਰਾਦੇਬੰਦ ਜਾਂ ਚਾਹੁੰਦੀ ਕਾਰਵਾਈ ("ਮੈਂ ਜਾਵਾਂਗਾ", "ਮੈਂ ਜਾਣਾ ਚਾਹੁੰਦਾ ਹਾਂ")**
- **ਉਮੀਦ ("ਇਸ ਤਰ੍ਹਾਂ ਹੀ ਹੋਵੇਗਾ")**
- **ਆਸ**
- **ਘਬਰਾਹਟ**
- **ਸੰਭਾਵਨਾ**
- **ਬੋਲਣ ਵਾਲੇ ਦੀ ਰਾਏ**
- **ਹੁਕਮ**

**ਭਵਿੱਖ ਕਾਲ ਕੁਝ ਹੱਦ ਤੱਕ ਉਮੇਦਵਾਚਕ ਕਾਲ (ਭਵਿੱਖ ਕਾਲ ਬਾਅਦ ਵਿੱਚ ਦੇਖੋ) ਨਾਲ ਮੁਕਾਬਲਾ ਕਰਦਾ ਹੈ⟪।⟫**
:::
ਉਦਾਹਰਣ ਵਜੋਂ, ⟪व्रतं⟫ ⟪करिष्यन्देवगृहं⟫ ⟪गच्छति⟫ = "ਇੱਕ ਵਿਅਕਤੀ ਜੋ ਇੱਕ ਵਾਅਦਾ ਕਰਨਾ ਚਾਹੁੰਦਾ ਹੈ, ਮੰਦਰ ਜਾਂਦਾ ਹੈ⟪।⟫"

## 26.7. ਸਧਾਰਣ ਭਵਿੱਖ ਕਾਲ ਦਾ ਗਠਨ (⟪ऌत्⟫, ⟪भविष्यन्ती⟫  ਫ਼ੀ.)

::: grammar-box
**ਸਧਾਰਣ ਭਵਿੱਖ ਕਾਲ:**

:::
::: indent
**ਭਵਿੱਖ ਕਾਲ ਦਾ ਮੂਲ + ਪ੍ਰਾਇਮਿਕ ਅੰਤ**
:::
::: grammar-box
**ਭਵਿੱਖ ਕਾਲ ਦਾ ਮੂਲ:**

:::
::: indent
**(ਆਮ ਤੌਰ 'ਤੇ) ਉੱਚ ਸਤਾ ਵਾਲੀ ਜੜ੍ਹ + -sya**  
**ਜਾਂ**  
**(ਆਮ ਤੌਰ 'ਤੇ) ਉੱਚ ਸਤਾ ਵਾਲੀ ਜੜ੍ਹ + -i- + -sya (= - iṣya)**
:::
**ਕਿਹੜੀ ਜੜ੍ਹ ਭਵਿੱਖ ਕਾਲ ਦੇ ਮੂਲ ਦਾ ਕਿਹੜਾ ਗਠਨ ਕਰਦੀ ਹੈ, ਇਹ ਮੂਲ ਰੂਪਾਂ ਨਾਲ ਸਿੱਖਣਾ ਪੈਂਦਾ ਹੈ!**  
**ਆਮ ਤੌਰ 'ਤੇ ਜੜ੍ਹ ਦਾ ਰੂਪ ਅਤੇ ਭਵਿੱਖ ਕਾਲ ਦਾ ਜੋੜਨ ਵਾਲਾ ਸਵਰ, ਅਨਿਰਦੇਸ਼ (Infinitive) ਨਾਲ ਮੇਲ ਖਾਂਦਾ ਹੈ⟪।⟫**  
**ਕੁਝ ਜੜ੍ਹਾਂ ਭਵਿੱਖ ਕਾਲ ਨੂੰ ਵਿਕਲਪਿਕ ਤੌਰ 'ਤੇ ਜੋੜਨ ਵਾਲੇ ਸਵਰ -i- ਦੇ ਨਾਲ ਅਤੇ ਬਿਨਾਂ ਬਣਾ ਸਕਦੀਆਂ ਹਨ⟪।⟫**  
**ਭਵਿੱਖ ਕਾਲ ਦਾ ਪਰਸਮੈਪਦਾ ਪਦਕ (Partizip) ਭਵਿੱਖ ਕਾਲ ਦੇ ਮੂਲ ਵਿੱਚ -nt- ਪਿੱਛੇਤਰ ਜੋੜ ਕੇ ਬਣਾਇਆ ਜਾਂਦਾ ਹੈ, ਫ਼ੀਮਿਨਿਨ ਵਿਕਲਪਿਕ ਤੌਰ 'ਤੇ -ntī ਜਾਂ -tī 'ਤੇ:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
