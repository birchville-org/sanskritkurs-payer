# ਪਾਠ 3

::: deleteme-box
**ਇਸ ਪਾਠ ਵਿੱਚ ਤੁਸੀਂ ਸਿੱਖੋਗੇ:**
- ਇਸਤਰੀ ਲਿੰਗ ਦੇ ਇਕਵਚਨ ਦਾ ਕਰਤਾ
- ਪੁਰਸ਼ ਲਿੰਗ ਅਤੇ ਇਸਤਰੀ ਲਿੰਗ ਦੇ ਬਹੁਵਚਨ ਦਾ ਕਰਤਾ
- ਪੁਰਸ਼ ਲਿੰਗ ਤੋਂ ਇਸਤਰੀ ਲਿੰਗ ਬਣਾਉਣ ਦਾ ਤਰੀਕਾ
- ਸੰਧੀ (Vokalsandhi)
- Satzsandhi von -ās
:::
## 3.1. ⟪स्त्रीलिङ्गस्य⟫ ⟪एकवचनं⟫ ⟪प्रथमा⟫

### 3.1.1. ਇਕਵਚਨ ਵਿੱਚ -s ਨਾਲ ਸਮਾਪਨ

ਹੇਠ ਲਿਖੇ ਨਾਮਵਾਕ ਜੜ੍ਹ, ਜੋ ਇੱਕ ਸਵਰਨ ਨਾਲ ਸਮਾਪਤ ਹੁੰਦੇ ਹਨ, ਇਕਵਚਨ ਵਿੱਚ **-s** ਨਾਲ ਸਮਾਪਨ ਬਣਾਉਂਦੇ ਹਨ:

::: grammar-box
- **ਇਸਤ੍ਰੀ ਲਿੰਗ -i ਨਾਲ**: ਜਿਵੇਂ **śruti** f. "ਸੁਣਨਾ" -- ਇਕ. ਵਿ.: **śrutis** = ⟪श्रुतिस्⟫
- **ਇਸਤ੍ਰੀ ਲਿੰਗ -u ਨਾਲ**: ਜਿਵੇਂ **dhenu** f. "ਦੁੱਧ ਗਾਊ" -- ਇਕ. ਵਿ.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. ਇਕ ਵਚਨ ਵਿੱਚ ਨਾਮਕਾਰਕ, ਬਿਨਾਂ ਅੰਤਿਮਾ ਦੇ

ਇਕ ਵਚਨ ਵਿੱਚ ਨਾਮਕਾਰਕ, ਬਿਨਾਂ ਅੰਤਿਮਾ ਦੇ ਬਣਦੇ ਹਨ:

::: grammar-box
- **ਇਸਤ੍ਰੀ ਲਿੰਗ -ā 'ਤੇ ਸਮਾਪਤ**: ਜਿਵੇਂ **devatā** ਇਸਤ੍ਰੀ. "ਦੇਵਤਾ" -- ਨਾਮ. ਇਕ.ਵ: **devatā** = ⟪देवता⟫
- **ਇਸਤ੍ਰੀ ਲਿੰਗ -ī 'ਤੇ ਸਮਾਪਤ**: ਜਿਵੇਂ **devī** ਇਸਤ੍ਰੀ. "ਦੇਵੀ" -- ਨਾਮ. ਇਕ.ਵ: **devī** = ⟪देवी⟫
:::
::: important
**ਧਿਆਨ ਰੱਖੋ!** ਇਸ ਤੋਂ ਇਲਾਵਾ ਇਕ-ਅਖਰੀ ਇਸਤ੍ਰੀ ਲਿੰਗ ਮੂਲ ਨਾਮ, ਜਿਨ੍ਹਾਂ ਦੇ ਨਾਮ. ਇਕ.ਵ -s 'ਤੇ ਸਮਾਪਤ ਹੁੰਦੇ ਹਨ: ਜਿਵੇਂ dhī ਇਸਤ੍ਰੀ. "ਵਿਚਾਰ" -- ਨਾਮ. ਇਕ.ਵ: dhīs = ⟪धीस्।⟫ ਇਸੇ ਤਰ੍ਹਾਂ lakṣmī (⟪लक्ष्मी⟫) ਇਸਤ੍ਰੀ., tarī (⟪तरी⟫) ਇਸਤ੍ਰੀ. "ਨੌਕਾ" ਅਤੇ tantrī (⟪तन्त्री⟫) ਇਸਤ੍ਰੀ. "ਤਾਰ" ਅਸਧਾਰਨ ਢੰਗ ਨਾਲ ਨਾਮ. ਇਕ.ਵ -s 'ਤੇ ਬਣਾਉਂਦੇ ਹਨ: lakṣmīs = ⟪लक्ष्मीस्।⟫
:::

## 3.2. ਪੁੰਗਲਿੰਗੀਆਂ ਤੋਂ ਸਤੀ ਲਿੰਗੀਆਂ ਦਾ ਨਿਰਮਾਣ

::: grammar-box
**ਆ-ਨਿਰੰਤਰ ਪੁੰਗਲਿੰਗੀ:**
- **-ā ਨਿਰੰਤਰ ਸਤੀ**: ਜਿਵੇਂ **kṣatriya** ਪੁ. » **kṣatriyā** ਸਤੀ "ਕਸ਼ਤਰੀਯਾ" = ⟪क्षत्रिया⟫
- **-ī ਨਿਰੰਤਰ ਸਤੀ**: ਜਿਵੇਂ **brāhmaṇa** ਪੁ. » **brāhmaṇī** ਸਤੀ "ਬ੍ਰਾਹ⟪्म⟫ਣੀ" = ⟪ब्राह्मणी⟫

**ਉ-ਨਿਰੰਤਰ ਪੁੰਗਲਿੰਗੀ:**
- **-ī ਨਿਰੰਤਰ ਸਤੀ**: ਜਿਵੇਂ **sādhu** ਪੁ. » **sādhvī** ਸਤੀ (ਭਲਾ, ਪਵਿੱਤਰ) = ⟪साध्वी⟫
  (**-u-** ਸੰਧਿ ਵਿੱਚ **-v-** ਬਣ ਜਾਂਦਾ ਹੈ, ਇਸਲਈ **-u- + -ī** » **-vī**)
:::

## 3.3. ਨਾਮਵਾਚਕ ਬਹੁਵਚਨ ਪੁਲਿੰਗ ਅਤੇ ਸਤੀਲਿੰਗ

::: grammar-box
ਪੁਲਿੰਗ ਅਤੇ ਸਤੀਲਿੰਗ ਵਿੱਚ ਨਾਮਵਾਚਕ ਬਹੁਵਚਨ ਦਾ ਅੰਤਮ **-as** ਹੈ⟪।⟫
- **-a** 'ਤੇ ਸਮਾਪਤ ਪੁਲਿੰਗ: **deva- + -as** » **devās** = ⟪देवास्⟫
- **-ā** 'ਤੇ ਸਮਾਪਤ ਸਤੀਲਿੰਗ: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **-i** 'ਤੇ ਸਮਾਪਤ ਪੁਲਿੰਗ: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **-i** 'ਤੇ ਸਮਾਪਤ ਸਤੀਲਿੰਗ: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **-ī** 'ਤੇ ਸਮਾਪਤ ਸਤੀਲਿੰਗ: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **-u** 'ਤੇ ਸਮਾਪਤ ਪੁਲਿੰਗ: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **-u** 'ਤੇ ਸਮਾਪਤ ਸਤੀਲਿੰਗ: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
ਟਿੱਪਣੀ: **e** **i** ਦਾ ਉੱਚ ਪੱਧਰ (**guṇa**) ਹੈ, **o** **u** ਦਾ ਉੱਚ ਪੱਧਰ ਹੈ⟪।⟫

## 3.4. ਵੋਕਲਸੰਧਿ

::: grammar-box
**ਸਧਾਰਨ ਵੋਕਲ, ਜੋ ਕਿ ਸਿਰਫ਼ ਆਪਣੀ ਲੰਬਾਈ ਵਿੱਚ ਵੱਖਰੇ ਹੁੰਦੇ ਹਨ, "ਘੁਲ ਜਾਂਦੇ" ਹਨ ਅਤੇ ਸੰਬੰਧਿਤ ਲੰਬੇ ਵੋਕਲ ਵਿੱਚ ਬਦਲ ਜਾਂਦੇ ਹਨ:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::

devatā + annapūrṇā » devatānnapūrṇā "ਅਨਨਪੂਰਨਾ ਇੱਕ ਦੇਵਤਾ ਹੈ" = ⟪देवतान्नपूर्णा⟫

## 3.6. ਸ਼ਬਦਾਵਲੀ

**ਹੇਠ ਲਿਖੇ ਸ਼ਬਦ ਸਿੱਖੋ:**

**śruti** f. = ⟪श्रुति⟫ : ਸੁਣਨਾ, ਸ਼ਾਸ਼ਵਤ ਪਰੰਪਰਾ (ਵੇਦਾਂ ਅਤੇ ਬ੍ਰਾਹਮਣਾਂ ਦਾ ਸੰਕੇਤ)⟪।⟫

**smṛti** f. = ⟪स्मृति⟫ : ਸਮਕਾਲੀਨਤਾ, ਯਾਦ, ਧਿਆਨਮਈ ਸਮਕਾਲੀਨਤਾ = ਸੁਚੇਤਤਾ, ਪਰੰਪਰਾ (**śruti** ਦਾ ਵਿਰੋਧੀ ਸੰਕਲਪ)⟪।⟫ ਇਸ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ:
- ਛੇ **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): ਸਹੀ ਉਚਾਰਣ
  2. **chandas** n. (⟪छन्दस्⟫): ਮੀਟਰ
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): ਵਿਆਕਰਣ
  4. **nirukta** n. (⟪निरुक्त⟫) : ਸ਼ਬਦ ਵਿਆਖਿਆ, ਨਿਰੁਕਤੀ
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : ਜ⟪्य⟫ੋਤਿਸ਼, ਕੈਲੰਡਰ ਵਿਗਿਆਨ
  6. **kalpa** m. (⟪कल्प⟫) : ਰਸਮੀ ਵਿਧੀ
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : ਵੱਡੇ ਯਾਗਾਂ ਦੇ ਨਿਯੋਜਨ ਲਈ ਸਿੱਖਿਆ ਗ੍ਰੰਥ
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : ਰੋਜ਼ਾਨਾ ਜੀਵਨ ਦੀਆਂ ਰਸਮਾਂ ਅਤੇ ਯਾਗਾਂ ਲਈ ਸਿੱਖਿਆ ਗ੍ਰੰਥ
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) ਅਤੇ **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : ਕਾਨੂੰਨ ਅਤੇ ਰਵਾਇਤ 'ਤੇ ਸਿੱਖਿਆ ਗ੍ਰੰਥ (ਸਹੀ ਵਿਵਹਾਰ)
- ਵੱਡੇ ਇਪਿਕ ਗ੍ਰੰਥ **mahābhārata** n. (⟪महाभारत⟫) ਅਤੇ **rāmāyaṇa** n. (⟪रामायण⟫)
- **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : ਜੀਵਨ ਦੀ ਸਮਝ 'ਤੇ ਸਿੱਖਿਆ ਗ੍ਰੰਥ

**smṛti** ਖਾਸ ਤੌਰ 'ਤੇ ਧਰਮ ਸਿੱਖਿਆ ਗ੍ਰੰਥਾਂ ਦਾ ਸੰਕੇਤ ਵੀ ਹੈ⟪।⟫

**dhenu** f. = ⟪धेनु⟫ : (ਦੁੱਧ) ਗਾਇ⟪।⟫

**paśu** m. = ⟪पशु⟫ : ਪਾਲਤੂ ਉਪਯੋਗੀ ਜਾਨਵਰ, ਮੱਝ (ਸਮੂਹਿਕ ਸੰਕੇਤ)⟪।⟫

**devatā** f. = ⟪देवता⟫ : ਦੇਵਤਾ (ਅਬਸਟਰੈਕਟ ਅਤੇ ਕੰਕਰੀਟ)⟪।⟫

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : ਬ੍ਰਾਹਮਣੀ⟪।⟫

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : ਮਾਦਾ ਕṣatriya⟪।⟫

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : ਇੱਕ ਕṣatriya ਦੀ ਪਤਨੀ⟪।⟫

**vaiśyā** f. = ⟪वैश्या⟫ : ਮਾਦਾ Vaiśya⟪।⟫

**śūdrā** f. = ⟪शूद्रा⟫ : ਮਾਦਾ Śūdra⟪।⟫

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : ਇੱਕ Śūdra ਦੀ ਪਤਨੀ⟪।⟫

**devī** f. = ⟪देवी⟫ : ਦੇਵੀ, ਖਾਸ ਤੌਰ 'ਤੇ Durgā f. = ⟪दुर्गा⟫, ਸ਼ਿਵ ਦੀ ਪਤਨੀ = ⟪शिव।⟫

:::
**sādhvī** f. = ⟪साध्वी⟫ : ਮਾਦਾ ਰੂਪ sādhu ਦਾ⟪।⟫

**gurvī** f. = ⟪गुर्वी⟫ : ਮਾਦਾ ਰੂਪ guru ਦਾ⟪।⟫

**asmitā** f. = ⟪अस्मिता⟫ : "ਮੈਂ-ਹੋਣ-ਭਾਵ", ਭਾਵ ਇਹ (ਗਲਤ) ਵਿਸ਼ਵਾਸ: **ਮੈਂ** ਹੀ ਵੇਖਣ ਵਾਲਾ ਹਾਂ ਆਦਿ⟪।⟫

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : ਦਰਸ਼ਨ (ਉਹ ਵਿਗਿਆਨ ਜੋ ਤਰਕਸੰਗਤ ਸਹੀ ਤਰਕਾਂ ਦੁਆਰਾ ਆਪਣੇ ਸਿੱਟਿਆਂ ਤੱਕ ਪਹੁੰਚਦਾ ਹੈ)⟪।⟫

**upekṣā** f. = ⟪उपेक्षा⟫ : ਨਜ਼ਰਅੰਦਾਜ਼ ਕਰਨਾ, ਸਮਤਾ⟪।⟫

**karuṇā** f. = ⟪करुणा⟫ : ਕਰੁਣਾ, ਦਿਆ⟪।⟫

**muditā** f. = ⟪मुदिता⟫ : ਖੁਸ਼ੀ, ਖਾਸ ਤੌਰ 'ਤੇ ਸਹਿ-ਖੁਸ਼ੀ (ਹਿੰਮਤ ਦਾ ਵਿਰੋਧੀ)⟪।⟫

## 3.7. ਅਭਿਆਸ

**A) ਹੇਠ ਲਿਖੇ ਵਾਕਾਂ ਨੂੰ ਬਹੁਵਚਨ ਵਿੱਚ ਬਦਲੋ:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**B) ਨਾਮਵਾਕ ਬਣਾਓ:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) ਇਸਤ੍ਰੀ ਲਿੰਗ ਵਿੱਚ ਬਦਲੋ:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**D) ਸੰਸਕ੍ਰਿਤ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰੋ:**

1. ਉਮਾ ਇੱਕ ਦੇਵੀ ਹੈ⟪।⟫
2. ਵੇਦ ਸ਼ਰੁਤੀ ਹੈ⟪।⟫
3. ਅਧਿਆਪਕਾਵਾਂ ਦੇਵੀਆਂ ਹਨ⟪।⟫
4. ਦੁੱਧ ਗਾਵਾਂ ਪਾਲਤੂ ਜਾਨਵਰ ਹਨ⟪।⟫
5. ਕਵੀ ਅਧਿਆਪਕ ਹਨ⟪।⟫
6. ਕਸ਼ਤ੍ਰੀ ਦੋ ਵਾਰ ਜੰਮੇ ਹਨ⟪।⟫
7. ਪਵਿੱਤਰ ਪੁਰਸ਼ ਸੂਦਰ ਹਨ⟪।⟫
