# ਪਾਠ 3

::: deleteme-box
**ਇਸ ਪਾਠ ਵਿੱਚ ਤੁਸੀਂ ਸਿਖੋਗੇ:**
ਔਰਤਾਂ ਦੇ ਇਕ ਵਚਨ ਦਾ ਨਾਮਵਾਚੀ (Nominativ)
ਮਰਦਾਂ ਅਤੇ ਔਰਤਾਂ ਦੇ ਬਹੁ ਵਚਨ ਦਾ ਨਾਮਵਾਚੀ (Nominativ)
ਮਰਦਾਂ ਲਈ ਔਰਤਾਂ ਦੇ ਰੂਪ ਬਣਾਉਣਾ
ਸਵਰ ਸੰਧੀ (Vokalsandhi)
ās ਵਾਲੇ ਸ਼ਬਦਾਂ ਦੀ ਸੰਧੀ (Satzsandhi)
:::
## 3.1. ਔਰਤਾਂ ਦਾ ਇਕ ਵਚਨ ਨਾਮਵਾਚੀ

### 3.1.1. -s ਨਾਲ ਖਤਮ ਹੋਣ ਵਾਲਾ ਇਕ ਵਚਨ

ਹੇਠ ਲਿਖੇ ਨਾਂਵ ਜੋ ਸਵਰ 'ਤੇ ਖਤਮ ਹੁੰਦੇ ਹਨ, ਉਹ ਇਕ ਵਚਨ ਵਿੱਚ **-s** ਨਾਲ ਖਤਮ ਹੁੰਦੇ ਹਨ:

::: grammar-box
**-i** 'ਤੇ ਖਤਮ ਹੋਣ ਵਾਲੀਆਂ ਔਰਤਾਂ: ਜਿਵੇਂ **śruti** f. "ਸੁਣਨਾ" -- ਇਕ ਵਚਨ: **śrutis** = ⟪श्रुतिस्⟫
**-u** 'ਤੇ ਖਤਮ ਹੋਣ ਵਾਲੀਆਂ ਔਰਤਾਂ: ਜਿਵੇਂ **dhenu** f. "ਦੁੱਧ ਦਾ ਗਾਇ" -- ਇਕ ਵਚਨ: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. ਬਿਨਾਂ ਅੰਤ ਵਿਸ਼ੇਸ਼ਣ ਦੇ ਇਕ ਵਚਨ

ਬਿਨਾਂ ਕਿਸੇ ਅੰਤ ਵਿਸ਼ੇਸ਼ਣ ਦੇ ਇਕ ਵਚਨ ਬਣਾਉਂਦੇ ਹਨ:

::: grammar-box
**-ā** 'ਤੇ ਖਤਮ ਹੋਣ ਵਾਲੀਆਂ ਔਰਤਾਂ: ਜਿਵੇਂ **devatā** f. "ਦੇਵੀ" -- ਇਕ ਵਚਨ: **devatā** = ⟪देवता⟫
**-ī** 'ਤੇ ਖਤਮ ਹੋਣ ਵਾਲੀਆਂ ਔਰਤਾਂ: ਜਿਵੇਂ **devī** f. "ਦੇਵੀ" -- ਇਕ ਵਚਨ: **devī** = ⟪देवी⟫
:::
::: important
**ਧਿਆਨ ਦਿਓ!** ਇਸ ਤੋਂ ਇਲਾਵਾ ਕੁਝ ਛੋਟੇ ਮੂਲ ਨਾਂਵ ਜੋ **-ī** 'ਤੇ ਖਤਮ ਹੁੰਦੇ ਹਨ, ਉਹਨਾਂ ਦਾ ਇਕ ਵਚਨ **-s** ਨਾਲ ਖਤਮ ਹੁੰਦਾ ਹੈ: ਜਿਵੇਂ dhī f. "ਸੋਚ" -- ਇਕ ਵਚਨ: dhīs = ⟪धीस्⟫। lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "ਨੌਕਾ" ਅਤੇ tantrī (⟪तन्त्री⟫) f. "ਤਾਰ" ਵੀ ਅਨਿਯਮਿਤ ਢੰਗ ਨਾਲ ਇਕ ਵਚਨ ਵਿੱਚ **-s** ਲੈਂਦੇ ਹਨ: lakṣmīs = ⟪लक्ष्मीस्⟫।
:::

## 3.2. ਮਰਦਾਂ ਲਈ ਔਰਤਾਂ ਦੇ ਰੂਪ ਬਣਾਉਣਾ

::: grammar-box
**-a** 'ਤੇ ਖਤਮ ਹੋਣ ਵਾਲੇ ਮਰਦ:
**-ā** 'ਤੇ ਖਤਮ ਹੋਣ ਵਾਲੀਆਂ ਔਰਤਾਂ: ਜਿਵੇਂ **kṣatriya** m. » **kṣatriyā** f. "ਕਸ਼ਤਰੀ ਔਰਤ" = ⟪क्षत्रिया⟫
**-ī** 'ਤੇ ਖਤਮ ਹੋਣ ਵਾਲੀਆਂ ਔਰਤਾਂ: ਜਿਵੇਂ **brāhmaṇa** m. » **brāhmaṇī** f. "ਬ੍ਰਾਹਮਣ ਔਰਤ" = ⟪ब्राह्मणी⟫

**-u** 'ਤੇ ਖਤਮ ਹੋਣ ਵਾਲੇ ਮਰਦ:
**-ī** 'ਤੇ ਖਤਮ ਹੋਣ ਵਾਲੀਆਂ ਔਰਤਾਂ: ਜਿਵੇਂ **sādhu** m. » **sādhvī** f. (ਭਲਾ, ਪਵਿੱਤਰ) = ⟪साध्वी⟫
(**-u-** ਸਵਰ ਤੋਂ ਪਹਿਲਾਂ **-v-** ਬਣ ਜਾਂਦਾ ਹੈ, ਇਸ ਲਈ **-u- + -ī** » **-vī**)
:::

## 3.3. ਨਾਮਵਾਚਕ ਬਹੁਵਚਨ ਪੁਲਿੰਗ ਅਤੇ ਸਤਰੀਂਗ

::: grammar-box
ਨਾਮਵਾਚਕ ਬਹੁਵਚਨ ਦਾ ਪਿਛੇਤਰ ਪੁਲਿੰਗ ਅਤੇ ਸਤਰੀਂਗ ਵਿੱਚ **-as** ਹੈ।
**ਪੁਲਿੰਗ ਜੋ -a 'ਤੇ ਖਤਮ ਹੁੰਦੇ ਹਨ**: **deva- + -as** » **devās** = ⟪देवास्⟫
**ਸਤਰੀਂਗ ਜੋ -ā 'ਤੇ ਖਤਮ ਹੁੰਦੇ ਹਨ**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**ਪੁਲਿੰਗ ਜੋ -i 'ਤੇ ਖਤਮ ਹੁੰਦੇ ਹਨ**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**ਸਤਰੀਂਗ ਜੋ -i 'ਤੇ ਖਤਮ ਹੁੰਦੇ ਹਨ**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**ਸਤਰੀਂਗ ਜੋ -ī 'ਤੇ ਖਤਮ ਹੁੰਦੇ ਹਨ**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**ਪੁਲਿੰਗ ਜੋ -u 'ਤੇ ਖਤਮ ਹੁੰਦੇ ਹਨ**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**ਸਤਰੀਂਗ ਜੋ -u 'ਤੇ ਖਤਮ ਹੁੰਦੇ ਹਨ**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
ਨੋਟ: **e** ਦਾ ਉੱਚ ਪੜਾਅ (**guṇa**) **i** ਹੈ, ਅਤੇ **o** ਦਾ ਉੱਚ ਪੜਾਅ **u** ਹੈ।


## 3.4. ਸਵਰ ਸੰਧੀ

::: grammar-box
**ਸਰਲ ਸਵਰ ਜੋ ਇੱਕ ਦੂਜੇ ਨਾਲ ਮਿਲਦੇ ਹਨ ਜਾਂ ਸਿਰਫ਼ ਆਪਣੀ ਲੰਬਾਈ ਵਿੱਚ ਵੱਖ ਹੁੰਦੇ ਹਨ, ਉਹ ਸੰਬੰਧਿਤ ਲੰਬੇ ਸਵਰ ਵਿੱਚ "ਮਿਲ ਜਾਂਦੇ ਹਨ":**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)
:::
ਉਦਾਹਰਣ ਵਜੋਂ

devatā + annapūrṇā » devatānnapūrṇā "ਅਨਨਪੂਰਣਾ ਇੱਕ ਦੇਵੀ ਹੈ" = ⟪देवतान्नपूर्णा⟫

> (ਅਨਨਪੂਰਣਾ ਭੋਜਨ ਅਤੇ ਰਸੋਈ ਦੀ ਦੇਵੀ ਹਨ, ਉਹ ਪਾਰਬਤੀ, ਸ਼ਿਵ ਦੀ ਪਤਨੀ ਦੇ ਅਵਤਾਰ ਮੰਨੇ ਜਾਂਦੇ ਹਨ।)

devī + indrāṇī » devīndrāṇī "ਇੰਦਰਾਣੀ ਇੱਕ ਦੇਵੀ ਹੈ" = ⟪देवीन्द्राणी⟫

> (ਇੰਦਰਾਣੀ ਦੇਵ ਇੰਦਰ ਦੀ ਪਤਨੀ ਹਨ।)

i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**
(!! ਇਸ ਨਿਯਮ ਲਈ, ਖਾਸ ਤੌਰ 'ਤੇ ਦੋਵਚਨ ਰੂਪਾਂ ਲਈ ਅਪਵਾਦ ਹਨ !!)
:::
ਉਦਾਹਰਣ ਵਜੋਂ

devī + umā » devy umā "ਉਮਾ ਇੱਕ / ਦੇਵੀ ਹੈ" = ⟪देव्युमा⟫

> (ਉਮਾ ਪਾਰਵਤੀ, ਸ਼ਿਵ ਦੀ ਪਤਨੀ ਦਾ ਇੱਕ ਨਾਂ ਹੈ)

::: grammar-box
**-a / -ā ਅਸਮਾਨ ਸਵਰ ਤੋਂ ਪਹਿਲਾਂ:**
a / -ā + i- / ī- » **-e-**
a / -ā + ṛ- » **-ar-**
a / -ā + e- / ai- » **-ai-**
a / -ā + o- / au- » **-au-**
:::

## 3.5. -ās ਦਾ ਵਾਕ-ਸੰਧੀ

::: grammar-box
**-ās ਸਾਰੇ ਅਨੁਨਾਦੀ ਧ्वਨੀਆਂ ਤੋਂ ਪਹਿਲਾਂ -ā ਦੁਆਰਾ ਬਦਲਿਆ ਜਾਂਦਾ ਹੈ।**
:::
ਉਦਾਹਰਣ ਵਜੋਂ

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "ਵੈਸ਼ਯ ਦੋ ਵਾਰ ਜਨਮੇ ਹਨ" = ⟪द्विजा वैश्याः⟫


## 3.6. ਸ਼ਬਦ-ਸੂਚੀ

**ਹੇਠ ਲਿਖੇ ਸ਼ਬਦ ਯਾਦ ਕਰੋ:**

**śruti** f. = ⟪श्रुति⟫ : ਸੁਣਨਾ, ਆਦਿ-ਪਰੰਪਰਾ (ਵੇਦਾਂ ਅਤੇ ਬ੍ਰਹਮਣਾਂ ਦਾ ਨਾਂ)।

**smṛti** f. = ⟪स्मृति⟫ : ਯਾਦ, ਸਿਮਰਨ, ਧਿਆਨ-ਭਰਪੂਰ ਯਾਦ = ਸੁਚੇਤਨਾ, ਪਰੰਪਰਾ (**śruti** ਦਾ ਵਿਰੋਧੀ ਸ਼ਬਦ)। ਇਸ ਵਿੱਚ ਸ਼ਾਮਲ ਹਨ:
ਛੇ **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): ਸਹੀ ਉਚਾਰਨ
2. **chandas** n. (⟪छन्दस्⟫): ਛੰਦ
3. **vyākaraṇa** n. (⟪व्याकरण⟫): ਵਿਆਕਰਣ
4. **nirukta** n. (⟪निरुक्त⟫) : ਸ਼ਬਦ-ਵਿਗਿਆਨ, ਨਿਰੁਕਤੀ
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : ਜ्यੋਤਿਸ਼, ਕੈਲੰਡਰ-ਵਿਗਿਆਨ
6. **kalpa** m. (⟪कल्प⟫) : ਧਾਰਮਿਕ ਰਸਮ
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : ਵੱਡੇ ਯਾਗਾਂ ਦੇ ਨਿਯੋਜਨ ਲਈ ਸੂਤਰ
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : ਰੋਜ਼ਾਨਾ ਜੀਵਨ ਦੀਆਂ ਧਾਰਮਿਕ ਰਸਮਾਂ ਅਤੇ ਬਲੀਦਾਨ ਲਈ ਸੂਤਰ
**dharmasūtra** n. (⟪धर्मसूत्र⟫) ਅਤੇ **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : ਕਾਨੂੰਨ ਅਤੇ ਰਵਾਇਤ ਬਾਰੇ ਸੂਤਰ (ਸਹੀ ਵਿਵਹਾਰ)
ਵੱਡੇ ਮਹਾਂਕਾਵਿ **mahābhārata** n. (⟪महाभारत⟫) ਅਤੇ **rāmāyaṇa** n. (⟪रामायण⟫)
**purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫) : ਜੀਵਨ-ਕਲਾ ਬਾਰੇ ਸੂਤਰ

**smṛti** ਖਾਸ ਤੌਰ 'ਤੇ ਧਰਮ ਸਿੱਖਿਆ ਦੇ ਗ੍ਰੰਥਾਂ ਲਈ ਵੀ ਇੱਕ ਨਾਮ ਹੈ।

**dhenu** f. = ⟪धेनु⟫ : (ਦੁੱਧ) ਗਾਈ।

**paśu** m. = ⟪पशु⟫ : ਪਾਲਤੂ ਜਾਨਵਰ, ਮੱਝ (ਸਮੂਹਿਕ ਸ਼ਬਦ)।

**devatā** f. = ⟪देवता⟫ : ਦੇਵਤਾ (ਅਮੂਰਤ ਅਤੇ ਮੂਰਤ)।

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : ਬ੍ਰਾਹਮਣੀ।

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : ਮਾਦਰੀ ਕṣatriya।

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : ਇੱਕ ਕṣatriya ਦੀ ਪਤਨੀ।

**vaiśyā** f. = ⟪वैश्या⟫ : ਮਾਦਰੀ Vaiśya।

**śūdrā** f. = ⟪शूद्रा⟫ : ਮਾਦਰੀ Śūdra।

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : ਇੱਕ Śūdra ਦੀ ਪਤਨੀ।

**devī** f. = ⟪देवी⟫ : ਦੇਵੀ, ਖਾਸ ਤੌਰ 'ਤੇ Durgā f. = ⟪दुर्गा⟫, ਸ਼ਿਵ ਦੀ ਪਤਨੀ = ⟪शिव⟫।

::: media
![](/images/lekt0303.webp)
ਚਿੱਤਰ: Durgā = ⟪दुर्गा⟫, ਉੜੀਸਾ
(ਚਿੱਤਰ ਸਰੋਤ: [ਵੇਰਵੇ](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : sādhu ਦਾ ਮਾਦਰੀ ਰੂਪ।

**gurvī** f. = ⟪गुर्वी⟫ : guru ਦਾ ਮਾਦਰੀ ਰੂਪ।

**asmitā** f. = ⟪अस्मिता⟫ : "ਮੈਂ-ਹੋਣਾ", ਭਾਵ (ਗਲਤ) ਵਿਸ਼ਵਾਸ: **ਮੈਂ** ਹੀ ਦੇਖਣ ਵਾਲਾ ਆਦਿ ਹਾਂ।

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : ਦਰਸ਼ਨ (ਉਹ ਵਿਗਿਆਨ ਜੋ ਤਰਕਸੰਗਤ ਭਾਵਾਂ ਰਾਹੀਂ ਆਪਣੇ ਸਿੱਟਿਆਂ ਤੱਕ ਪਹੁੰਚਦਾ ਹੈ)।

**upekṣā** f. = ⟪उपेक्षा⟫ : ਨਜ਼ਰਅੰਦਾਜ਼ੀ, ਸਮਭਾਵ।

**karuṇā** f. = ⟪करुणा⟫ : ਦਿਆ, ਹਮਦਰਦੀ।

**muditā** f. = ⟪मुदिता⟫ : ਖੁਸ਼ੀ, ਖਾਸ ਤੌਰ 'ਤੇ ਦੂਜਿਆਂ ਦੀ ਖੁਸ਼ੀ ਵਿੱਚ ਸਾਂਝੀ ਖੁਸ਼ੀ (ਹਿੰਦਾ ਦੇ ਉਲਟ)।


## 3.7. ਅਭਿਆਸ

**A) ਹੇਠ ਲਿਖੇ ਵਾਕਾਂ ਨੂੰ ਬਹੁਵਚਨ ਵਿੱਚ ਬਦਲੋ:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
