# ਵਿਸ਼ਾ ਸੂਚੀ

ਵਿਸ਼ਾ ਸੂਚੀ ਸਾਰੇ ਪਾਠਾਂ ਦੇ ਸਿਰਨਾਵਿਆਂ ਤੋਂ ਆਟੋਮੈਟਿਕ ਤੌਰ 'ਤੇ ਜਨਰੇਟ ਕੀਤੀ ਜਾਂਦੀ ਹੈ। ਇਹ ਖਾਸ ਵਿਆਕਰਣਕ ਘਟਨਾਵਾਂ ਤੱਕ ਤੇਜ਼ ਪਹੁੰਚ ਸੰਭਵ ਬਣਾਉਂਦੀ ਹੈ।
