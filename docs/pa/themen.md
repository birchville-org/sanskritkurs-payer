# ਵਿਆਕਰਣ ਸੂਚੀਪਤ੍ਰ

ਵਿਆਕਰਣ ਸੂਚੀਪਤ੍ਰ ਸੰਸਕ੍ਰਿਤ ਕੋਰਸ ਤੋਂ ਸਾਰੇ ਵਿਆਕਰਣਕ ਥੀਮਾਂ ਅਤੇ ਵਰਤਾਰਿਆਂ ਨੂੰ ਸੂਚੀਬੱਧ ਕਰਦਾ ਹੈ ਅਤੇ ਖਾਸ ਪਾਠਾਂ ਤੇ ਜਲਦੀ ਪਹੁੰਚ ਦੀ ਸਹੂਲਤ ਦਿੰਦਾ ਹੈ।
