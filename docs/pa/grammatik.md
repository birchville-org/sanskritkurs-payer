# ਵਿਸ਼ਾ: ਵ⟪्या⟫ਕਰਣ

ਇਹ ਸਫ਼ਾ ਸੰਸਕ੍ਰਿਤ ਕੋਰਸ ਦੇ ਸਾਰੇ ਵਿਆਕਰਣਕ ਮੁੱਦਿਆਂ ਬਾਰੇ ਇੱਕ ਸਿਸਟਮੈਟਿਕ ਝਲਕ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ⟪।⟫ 61 ਵਿੱਚੋਂ ਹਰੇਕ ਪਾਠ ਇੱਥੇ ਵਿਸ਼ਾ-ਅਧਾਰਿਤ ਤੌਰ 'ਤੇ ਵਰਗੀਕ੍ਰਿਤ ਹੈ⟪।⟫

## 1. ਧੁਨੀ ਵਿਗਿਆਨ ਅਤੇ ਲਿਪੀ (ਸੰਹਿਤਾ ਅਤੇ ਲਿਪੀ)

*   **ਸ਼ਬਦਾਂ ਦਾ ਪਰਿਚਯ**: ਪ੍ਰਣਾਲੀ ਅਤੇ ਉਚਾਰਣ → [ਪਾਠ 1](/pa/lektionen/lektion01)
*   **ਲਿਪੀ ਪਰਿਚਯ (ਦੇਵਨਾਗਰੀ)**:
    *   ਸਵਰ ਅਤੇ ਸਧਾਰਣ ਵਿਅੰਜਨ → [ਪਾਠ 40](/pa/lektionen/lektion40)
    *   ਸੰਯੁਕਤ ਵਿਅੰਜਨ (ਲਿਗੇਚਰ) → [ਪਾਠ 41](/pa/lektionen/lektion41) ਅਤੇ [ਪਾਠ 42](/pa/lektionen/lektion42)
*   **ਸੰਧੀ (ਸ਼ਬਦ-ਸੰਯੋਗ)**:
    *   ਵਿਸਰਜਨ **-s/ਵਿਸਰਜ** ਦੀ ਸੰਧੀ → [ਪਾਠ 2](/pa/lektionen/lektion02), [ਪਾਠ 3](/pa/lektionen/lektion03), [ਪਾਠ 30](/pa/lektionen/lektion30)
    *   **-m, -e, -d** ਦੀ ਸੰਧੀ → [ਪਾਠ 4](/pa/lektionen/lektion04)
    *   **ਸਵਰ-ਸੰਧੀ** → [ਪਾਠ 3](/pa/lektionen/lektion03), [ਪਾਠ 24](/pa/lektionen/lektion24)
    *   **-n** ਦੀ ਸੰਧੀ → [ਪਾਠ 7](/pa/lektionen/lektion07)
    *   **ਨਾਸਿਕ** ਲਈ ਸੰਧੀ → [ਪਾਠ 21](/pa/lektionen/lektion21), [ਪਾਠ 26](/pa/lektionen/lektion26)
    *   ਮੂਲੀਕਰਣ (**n → ṇ / s → ṣ**) → [ਪਾਠ 10](/pa/lektionen/lektion10), [ਪਾਠ 26](/pa/lektionen/lektion26)
    *   ਸ਼ਬਦ-ਸੰਧੀ (h-, ch-) → [ਪਾਠ 44](/pa/lektionen/lektion44), [ਪਾਠ 51](/pa/lektionen/lektion51)
    *   **ਵਿਅੰਜਨ-ਸੰਧੀ** (ਸੰਖੇਪ) → [ਪਾਠ 16](/pa/lektionen/lektion16), [ਪਾਠ 43](/pa/lektionen/lektion43)
