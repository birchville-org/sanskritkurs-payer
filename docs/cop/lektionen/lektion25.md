## 25.1. ϫⲓⲛⲉⲥⲓⲥ ⲛ̄ⲧⲉ ⲡⲓⲁⲃⲗⲁⲧⲓⲃ (⟪पञ्चमी⟫ = "ⲧⲉⲗⲉⲓⲱⲥⲓⲥ ⲛ̄ⲧⲉ ⲡⲓⲕⲁⲥⲟⲥ ⲛ̄ϩⲙⲉ")

::: grammar-box
A better way to phrase this might be `ⲛⲓⲁⲛⲧⲱⲛⲩⲙⲓⲁ ⲛ̀ⲉⲣⲱⲧⲏⲧⲓⲕⲟⲛ, ⲛ̀ⲣⲉⲗⲁⲧⲓⲃⲟⲛ, ⲛⲉⲙ ⲛ̀ⲇⲉⲓⲕⲧⲓⲕⲟⲛ:` (Interrogative, relative, and demonstrative pronouns). This is more standard for grammatical terms.

Final version for L12: `ⲛⲓⲁⲛⲧⲱⲛⲩⲙⲓⲁ ⲛ̀ⲉⲣⲱⲧⲏⲧⲓⲕⲟⲛ, ⲛ̀ⲣⲉⲗⲁⲧⲓⲃⲟⲛ ⲛⲉⲙ ⲛ̀ⲇⲉⲓⲕⲧⲓⲕⲟⲛ:`
:::
Jetzt erkennen Sie den Grund für die Reihenfolge der Kasus (⟪विभक्ति⟫) im Sanskrit: sie sind so angeordnet, dass gleichlautende Formen möglichst beieinander - bzw. untereinander - stehen.

## 25.2. Gebrauch des Ablativ (⟪पञ्चमी⟫) <!-- TODO: Fallback translation -->

"ⲡⲓϣⲟⲡ ⲛⲧⲉ ϯⲙⲏⲧ ⲡⲓϣⲟⲡ ϯⲛⲁⲕ ⲉϥⲙⲟⲧⲛⲁⲕ ⲉϥⲙⲟⲧⲛⲁⲕ."

Pāṇini 2,3,28 + 1,4,24

Der Ablativ steht vor allem auf die Fragen "Woher?", "Warum?". <!-- TODO: Fallback translation -->

::: grammar-box
1\. Der Ablativ bezeichnet also den Ausgangspunkt, die Herkunft und den Stoff.

ⲡⲓϧⲟⲃ ϩⲛ ⲡⲉⲙϫⲓⲥ ϩⲛ ⲡⲉⲙϣⲱⲃ. <!-- TODO: Fallback translation -->

⟪अश्वात्पतितः⟫ = "ϩⲛ ⲡⲉⲙϣⲱⲃ"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "ϩⲛ ⲡⲉⲙϣⲱⲃ"

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = "ⲡⲓϣⲟⲛ ⲉϥⲃⲱⲕ ϫⲟⲛ ⲉϥϣⲱⲡ ϫⲓⲛ ⲉⲃϥⲙⲟⲧ" (« ⲡⲓϣⲟⲛ ϫⲉ ⲥⲱⲡϣⲟⲛ)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = "ⲡⲓϣⲟⲛ ⲉϥⲃⱧⲓ / ϫⲟⲛ ⲉϥϣⱧⲓ ϫⲓⲛ ⲉⲃϥⲙⲟⲧ"
:::
Nomina, die nicht Feminina sind, können, um den Grund einer Tätigkeit zu bezeichnen, im Instrumentalis (⟪तृतीया⟫) oder Ablativ (⟪पञ्चमी⟫) stehen. Feminina stehen in diesem Sinn in der Regel im Instrumentalis, können aber gelegentlich auch im Ablativ stehen. <!-- TODO: Fallback translation -->

## 25.3. Das Suffix -⟪तस्⟫

::: grammar-box
ⲉϣⲱⲡ ⲉⲣⲉ ⲟⲩⲁⲓ ⲟⲩⲱϣ ⲉⲧⲁⲙⲟ ϧⲉⲛ ⲡⲓⲟⲩⲁⲓ (ϧⲉⲛ ⲟⲩⲙⲉⲧⲥⲱⲟⲩⲧ) ϫⲉ ⲥⲉⲭⲣⲱ ⲙ̀ⲡⲓⲥⲁϫⲓ ϧⲉⲛ ⲟⲩⲙⲉⲧⲉⲣⲙⲏⲛⲓⲁ ⲛ̀ⲁⲃⲗⲁⲧⲓⲃⲟⲥ, ⲉϣϫⲟⲙ ⲙ̀ⲙⲟϥ ⲉⲧⲁϩⲟ ⲛ̀ⲡⲓⲥⲟⲩϥⲓⲝ -⟪तस्⟫ ⲉϫⲉⲛ ⲧⲛⲟⲩⲛⲓ ⲛ̀ⲧⲉ ⲡⲓⲥⲁϫⲓ, ⲫⲁⲓ ⲉⲧⲥⲱⲛⲧ ⲛ̀ϩⲁⲛⲉⲡⲓⲣⲣⲏⲙⲁ ϧⲉⲛ ⲟⲩⲙⲉⲧⲉⲣⲙⲏⲛⲓⲁ ⲛ̀ⲁⲃⲗⲁⲧⲓⲃⲟⲥ ⲉⲛⲉϩⲟⲟⲩ (ⲉϫⲉⲛ ⲡⲓϫⲓⲛⲉϣⲛⲉ "ⲉⲃⲟⲗ ⲑⲱⲛ;"):
:::
ϩⲁⲛⲡⲁⲣⲁⲇⲓⲅⲙⲁ:

::: indent

## 25.4. Ϩⲉⲛⲕⲉⲙⲁⲓⲛ ⲛ̄ⲧⲉ ⲧⲁⲥⲁϫⲓ ⲛ̄ⲛⲓⲣⲉⲥⲟⲛ

**1\. Ϩⲉⲛⲕⲉⲙⲁⲓⲛ**

Ⲟϥⲧⲉⲙⲁⲓⲛ ⲡϫⲟⲥ Ϧⲏⲓ ⲛⲁϫⲱⲙ Ϧⲉⲧⲛⲁϥ ⲛⲓⲱⲧ (ⲡⲉϫⲟⲥ), ⲕⲛⲏⲧ (ϫⲉⲙⲁⲓ), ⲡⲉϫⲟⲥ (ⲛⲁϣⲱⲙ).

ⲡⲉⲕϫⲟⲥ Ϧⲉⲛⲕⲉⲙⲁⲓⲛ, ⲡϫⲟⲥ Ϧⲉⲧⲛⲁϥ ⲛⲓⲱⲧ:

*   ⲙ̀ⲡⲓⲁⲃⲗⲁⲧⲓⲃⲟⲥ:
    *   ⟪यतस्⟫ ... ϣⲁϫⲉ ⲉϥϣⲏϣ ... ⟪ततस्⟫ ... ϣⲁϫⲉ ⲛ̀ϣⲟⲣⲡ ... = "ϫⲉ ..., ⲉⲑⲃⲉ ⲫⲁⲓ ..."
    *   ⟪यस्मात्⟫ ... ϣⲁϫⲉ ⲉϥϣⲏϣ ... ⟪तस्मात्⟫ ... ϣⲁϫⲉ ⲛ̀ϣⲟⲣⲡ ... = "ϫⲉ ..., ⲉⲑⲃⲉ ⲫⲁⲓ ..."
*   ⲙ̀ⲡⲓⲓⲛⲥⲧⲣⲟⲩⲙⲉⲛⲧⲁⲗ:
    *   ⟪येन⟫ ... ϣⲁϫⲉ ⲉϥϣⲏϣ ... ⟪तेन⟫ ... ϣⲁϫⲉ ⲛ̀ϣⲟⲣⲡ ... = "ⲉⲑⲃⲉ ⲫⲏ/ϫⲉ ..., ⲉⲑⲃⲉ ⲫⲁⲓ / ⲉⲑⲃⲉ ⲫⲁⲓ ..."
:::
ⲡⲁⲣⲁⲇⲓⲅⲙⲁ:

::: indent

::: grammar-box
**2\. ⟪हि⟫**

Ⲛⲓϣⲁϫⲉ ⲛ̀ϣⲟⲣⲡ ⲟⲩⲟⲛ ϣϫⲟⲙ ⲉⲧⲟⲩϫⲟⲩ ⲉ̀ⲛⲟⲩⲉⲣⲏⲟⲩ ⲉⲃⲟⲗ ϩⲓⲧⲉⲛ ϯⲡⲁⲣⲧⲓⲕⲉⲗⲏ ⟪हि⟫ "ⲅⲁⲣ, ϫⲉ". Ⲟⲩϣⲁϫⲉ ⲛⲉⲙ ⟪हि⟫ (ⲉⲧⲉ ⲛⲥⲉⲛⲁⲧⲁⲁⲥ ⲁⲛ ϧⲉⲛ ⲡⲓⲙⲁ ⲛ̀ϣⲟⲣⲡ, ⲁⲗⲗⲁ ⲉⲥⲉⲣϣⲁ ⲉⲥⲭⲏ ϧⲉⲛ ⲡⲓⲙⲁ ⲙⲁϩⲥ̀ⲛⲁⲩ ϧⲉⲛ ⲡⲓⲗⲟⲅⲟⲥ) ϯ ⲛ̀ⲟⲩⲧⲁϩⲟ ⲉⲣⲁⲧϥ ⲏ ⲉ̀ⲡϣⲁϫⲉ ⲉⲧϩⲓϫⲱϥ ⲏ ⲉ̀ⲡϣⲁϫⲉ ⲉⲑⲛⲏⲟⲩ ⲙⲉⲛⲉⲛⲥⲱϥ:
:::
