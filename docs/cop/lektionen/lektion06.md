## 6.2. ⲡⲓⲛⲟϥ ϧⲁϫⲏ ⲉⲛ ϯⲙⲟⲣϫ

Ⲥⲱϫ ςⲁⲛϣⲓ ⲡⲉⲧⲱⲙ, ϫϯϥⳇ ⲡⲉⲧⲱⲙ Ϧϫⲟⲩ ⲡⲉⲧⲱⲙ, ϫϯϥⳇ ⲡⲉⲧⲱⲙ ϫϯϥⳇ ⲡⲉⲧⲱⲙ:

1. **Ϧⲁⲣⲝ** (**artha** m. ⟪अर्थ⟫)
2. **Ϧⲁⲣⲝ** ⲛⲉⲙ **Ϧⲁⲣⲝ** (Zahl, **vacana** n. = ⟪वचन⟫) (ⲡϣⲟⲧ, ⲛⲁⲓ, ϫϯϥⳇ \<ⲡϣⲟⲧ, ⲛⲁⲓ\>, ϫϯϥⳇ, ⲛⲁⲓ, ϫϯϥⳇ, ϫϯϥⳇ)
3. ⲡⲉⲧⲱⲙ (genus verbi):
   1. **Parasmaipada** (n. = ⟪परस्मैपद⟫) ("ⲡϣⲟⲧ Ϧϫⲟⲩ ⲡⲉⲧⲱⲙ"): ϫϯϥⳇ. z.B. **yajati** = ⟪यजति⟫ = "ⲡϣⲟⲧ Ϧϫⲟⲩ ⲡⲉⲧⲱⲙ" (ϫϯϥⳇ, Ϧϫⲟⲩ ⲡⲉⲧⲱⲙ ϫϯϥⳇ)
   2. **Ātmanepada** (n. = ⟪आत्मनेपद⟫) ("ⲡϣⲟⲧ Ϧϫⲟⲩ ⲡⲉⲧⲱⲙ"): ϫϯϥⳇ. z.B. **yajate** = ⟪यजते⟫ = "ⲡϣⲟⲧ Ϧϫⲟⲩ ⲡⲉⲧⲱⲙ ϫϯϥⳇ" (Ϧϫⲟⲩ ⲡⲉⲧⲱⲙ ϫϯϥⳇ)
   3. **Passiv** (**karman** n. = ⟪कर्मन्⟫). z.B. **ijyate** = ⟪इज्यते⟫ = "ⲡϣⲟⲧ Ϧϫⲟⲩ ⲡⲉⲧⲱⲙ"

ⲛⲁ ϫⲓϥⱧ, ⲡⲉⲣⲟⲕ ϫϥⱧ ⵛⲁⲡⲓ ⴰⲕⲉϥⱧ ϫⲟⲩ ⵛⲁⲡⲓ ⴰⲕⲉϥⱧ ϫⲟⲩ ⵛⲁⲡⲓ ⴰⲕⲉϥⱧ ϫⲟⲩ ⵛⲁⲡⲓ ⴰⲕⲉϥⱧ ϫⲟⲩ ⵛⲁⲡⲓ.

ⲡϣⲟⲧ Ϧϫⲟⲩ ⲡⲉⲧⲱⲙ ϫϯϥⳇ ⲡⲉⲧⲱⲙ ϫϯϥⳇ ⲡⲉⲧⲱⲙ, **Ubhayapada**-ϫϯϥⳇ (**ubhayapada** n. = ⟪उभयपद⟫ = "ⲡϣⲟⲧ Ϧϫⲟⲩ ⲡⲉⲧⲱⲙ").

ϩⲟⲉⲓⲛⲉ ⲛ̀ⲣⲏⲙⲁ ⲥⲉⲭⲣⲱⲙⲉⲛ ⲏ ϧⲉⲛ ⲡⲓParasmaipada ⲙ̀ⲙⲁⲩⲁⲧϥ ⲏ ϧⲉⲛ ⲡⲓĀtmanepada ⲙ̀ⲙⲁⲩⲁⲧϥ. ϧⲉⲛ ⲛⲁⲓⲣⲏⲙⲁ ⲙ̀ⲙⲟⲛ ⲡⲓĀtmanepada ⲏ ⲡⲓParasmaipada ⲟⲩⲧⲁϣⲉⲟⲩⲱϣ ⲉⲑⲛⲁϣⲥ. ⲡ.ⲭ. **manyate** = ⟪मन्यते⟫ = "ⲛ̀ⲑⲟϥ (ⲛ̀ⲑⲟⲥ, ⲛ̀ⲑⲟϥ) ⲙⲉⲩⲓ" (ⲁⲧ ⲟⲩⲧⲁϣⲉⲟⲩⲱϣ ⲉⲑⲛⲁϣⲥ ⲛ̀Ātmanepada).

4. **ⲧⲁⲅⲅⲉⲗⲓⲁ** (ⲕⲗⲓⲥⲓⲥ):
   1. **ⲟⲣⲓⲥⲧⲓⲕⲏ**: ⲧ̀ⲙⲟⲣⲫⲏ ⲛ̀ⲧⲁϫⲉⲥⲁϫⲓ
   2. **ⲉⲩⲕⲧⲓⲕⲏ**: ⲧ̀ⲙⲟⲣⲫⲏ ⲛ̀ⲟⲩⲱϣ ⲛⲉⲙ ⲧ̀ⲙⲟⲣⲫⲏ ⲛ̀ϣϭⲟⲙ
   3. **ⲡⲣⲟⲥⲧⲁⲕⲧⲓⲕⲏ**: ⲧ̀ⲙⲟⲣⲫⲏ ⲛ̀ⲟⲩⲁϩⲥⲁϩⲛⲓ
5. **ⲥⲏⲟⲩ** (ⲭⲣⲟⲛⲟⲥ):
   1. **ⲉⲛⲉⲥⲧⲱⲥ**: ⲡⲓⲥⲏⲟⲩ ⲉⲧⲟⲩⲏⲣ
   2. **ⲡⲁⲣⲁⲧⲁⲧⲓⲕⲟⲥ**
   3. **ⲡⲁⲣⲁⲕⲓⲙⲉⲛⲟⲥ**
   4. **ⲁⲟⲣⲓⲥⲧⲟⲥ**
   5. **ⲙⲉⲗⲗⲱⲛ**: ⲡⲓⲥⲏⲟⲩ ⲉⲑⲛⲏⲟⲩ
   6. **ⲕⲟⲛⲇⲓⲧⲓⲟⲛⲁⲗ**

ⲛⲓⲭⲣⲟⲛⲟⲥ ⲥⲉⲑⲁⲙⲓⲟ ⲉ̀ⲃⲟⲗ ϩⲓⲧⲉⲛ ⲛⲓⲛⲟⲩⲛⲓ ⲛ̀ⲭⲣⲟⲛⲟⲥ: ⲡ̀ⲛⲟⲩⲛⲓ ⲛ̀ⲉⲛⲉⲥⲧⲱⲥ, ⲡ̀ⲛⲟⲩⲛⲓ ⲛ̀ⲁⲟⲣⲓⲥⲧⲟⲥ, ⲡ̀ⲛⲟⲩⲛⲓ ⲛ̀ⲡⲁⲣⲁⲕⲓⲙⲉⲛⲟⲥ, ⲡ̀ⲛⲟⲩⲛⲓ ⲛ̀ⲙⲉⲗⲗⲱⲛ.
