# ⲙⲁⲑⲏⲙⲁ 2

## 2.1. ⲧⲛⲟⲙⲓⲛⲁⲗ ⲥⲉⲛⲧⲉⲛⲥ

::: grammar-box
**Ⲥϫⲓⲣ: ⲛⲉⲙⲧⲥϫⲓⲣ ⲛⲁⲕⲟⲥ — ⲡⲓϣⲱⲡ**

z.B. devo viṣṇuḥ = ⟪देवो⟫ ⟪विष्णुः⟫ = "Viṣṇu ist ein Gott."
:::
ⲡⲓϫⲱⲛⲧ ⲛⲁⲕⲟⲥ ("ϩⲓ", "ϣⲱⲡ", "ϫⲟⲛ", "ϥⲓ", "ϣⲱⲡ") ⲛⲉⲙϫⲓⲣ, ⲟⲩϥⲛⲁⲕⲟⲥ ⲙⲡⲓϣⲱⲡ.

ⲡⲓϫⲱⲛⲧ ⲙⲉⲛⲁϫⲣ: **devaḥ** -- ⟪देवः⟫ ⲛⲉⲙϫⲓⲣ "ⲡⲓϣⲱⲡ" ⲛⲁⲕⲟⲥ "ϣⲱⲡ".

ⲙⲉⲧⲥⲁⲛϫⲓⲣ ⲡⲓϣⲱⲡ ⲛⲁⲕⲟⲥ, ⲙⲡⲓϣⲱⲡ ⲛⲁⲕⲟⲥ, ⲙⲡⲓϣⲱⲡ ⲛⲁⲕⲟⲥ, ⲙⲡⲓϣⲱⲡ ⲛⲁⲕⲟⲥ.

ⲛⲧⲉ ϩⲓⲥϫⲟⲙ ⲛ̀ⲧⲉⲙⲁⲕⲣⲏϫ ⲛⲧⲉ ϯⲙⲟⲕ ⲛⲁϥⲧⲉⲙⲏⲣ ⲛⲁϥⲧⲉⲙⲏⲣ ⲛⲁϥⲧⲉⲙⲏⲣ (ⲛⲁϥⲧⲉⲙⲏⲣ = ⲛⲁϥⲧⲉⲙⲏⲣ = **prathamā** ⲛⲁϥⲧⲉⲙⲏⲣ = ⟪प्रथमा⟫). ⲛⲧⲉ ϯϣⲟⲡⲓ ⲛ̀ⲧⲉⲙⲁⲕⲣⲏϫ ⲛⲧⲉ ϯⲙⲟⲕ ⲛⲁϥⲧⲉⲙⲏⲣ

## 2.2. ⲉⲧⲣⲉ ⲧⲇⲉⲕⲗⲓⲛⲁⲧⲓⲟⲛ (ⲧⲃⲉⲩⲅⲩⲛⲅ ⲛ̀ⲧⲉ ⲛⲓⲛⲟⲙⲓⲛⲁ)

ⲛⲧⲉϫⲓ ϯⲙⲁⲕ ⳡⲛϣⲧⲓ:

- **τρεῖς ἀριθμοί** (ⲙⲁϫⲓ ⳡⲛϣⲧⲓ) = **vacana** n. -- ⟪वचन⟫
  - ⲓϧⲱⲛ (ⲉⲩϫⲟⲓ) = **ekavacana** n. -- ⟪एकवचन⟫
  - ⲇⲩⲁϣ (ⲧⲛⲟⲡ) = **dvivacana** n. -- ⟪द्विवचन⟫
  - ⲡⲗⲟⲩⲣⲁϫ (ⲙⲉⲧⲛⲟⲡ) = **bahuvacana** n. -- ⟪बहुवचन⟫
- **τρεῖς γένη** (ⲃⲣⲁϫ ⳡⲛϭⲓⲙⲟⲥ) = **liṅga** n. / **vyakti** f. -- ⟪लिङ्ग⟫ / ⟪व्यक्ति⟫
  - ⲙⲁϭⲥⲟⲗⲓν (ⲙⲁϫⲉ) = **puṃs** m. -- ⟪पुंस्⟫
  - ⲡⲉϥⲓν (ⲛⲟⲩⲙ) = **strī** f. -- ⟪स्त्री⟫
  - ⲛⲉⲩτⲣⲟν (ϧⲁ) = **napuṃsaka** n. -- ⟪नपुंसक⟫
- **ὀκτὼ πτώσεις** (ⲕⲁϫ) = **sup** -- ⟪सुप्⟫ (= ⲕⲁϫⲉⲛ)

ⲡρὸς τῆς κλίσεως ἐπικείσθαι οἱ ὀργαὶ τῆς πτώσεως (**sup** = ⟪सुप्⟫) πρὸς τὴν λεγομένην **ῥίζαν τοῦ ὀνόματος** (ⲙορϫ ⳡⲛⲟⲩμ ϭⲓ Ვⲁϫ ⲉⲛ).

Παράδειγμα: **devas** = ⟪देवस्⟫ (ⲛομιν ⲧϣ ϩⲟⲡ) "ὁ/τι θεός" = **deva-** -- ⟪देव⟫- (ⲣϩ ⲛομ) + **-s** -- -⟪स्⟫ (ⲕⲁϫ).

ⲛⲧⲉ ϯϣⲱⲡⲓ ⲛⲧⲉ ϯϣⲱⲡⲓ ⲛⲁⲕⲟϥ ϣⲱⲡ ⲛⲧⲉ ⲁⲕⲟϥ ϣⲱⲡ:
- **deva** ⲙ. -- ⟪देव⟫ ⲙ. (ⲛⲓϣⲱⲡ)
- **vacana** ⲛ. -- ⟪वचन⟫ ⲛ. (ⲛⲓϣⲱⲡ)
- **vyakti** ⲫ. -- ⟪व्यक्ति⟫ ⲫ. (ⲛⲓϣⲱⲡ)

## 2.4. Sandhi -- ⟪सन्धि⟫

ⲡⲓⲛϥⲟϣ ϧⲕⲁⲡ ⲛⲧⲉ ⲟⲩϫⲓ ϡⲛⲧⲉ ⲛⲁϥⲙⲟⲩⲧ. ⲡⲓϫⲱⲥ ϡⲛⲧⲉ ⲡⲓϫⲱⲥ ϡⲛⲧⲉ ⲡⲓϫⲱⲥ **ⲤⰀⴞⲒ** (m.) = ⟪सन्धि⟫ ("ϯⲥⲱⲙⲧ").

### 2.4.1. ⲥⲁⲛⲇϩⲓ ⲛ̀ⲧⲉ ⲡⲓⲥⲓⲅⲙⲁ ⲉⲧⲥⲁ ⲧⲉϥϫⲓⲛϫⲱⲕ ⲉ̀ⲃⲟⲗ

ⲡⲓϣⲱⲡⲧⲛ ⲉ̄ⲓϫⲱⲥ:

> **Payer, Alois (1944–):** Sandhi von auslautendem -s. -- (Materialien zum Sanskrit). -- URL: http://www.payer.de/sanskritmaterialien/ssandhi.htm

Auslautendes **-s**:

- **im absoluten Auslaut** (Satzende) wird es zu **Visarga (-ḥ)**:
  - **devas** = ⟪देवस्⟫ » **devaḥ** = ⟪देवः⟫
  - **kavis** = ⟪कविस्⟫ » **kaviḥ** = ⟪कविः⟫
  - **gurus** = ⟪गुरुस्⟫ » **guruḥ** = ⟪गुरुः⟫

- **ⲡϣⲉⲛ ⳱ⲙⲟⲧ ϭϫⲉⲛ ⳡⲙⲟⲧ**:
  - ⲡϣⲉⲛ **k, kh, p, ph** ϫⲓ ⳡⲙⲟⲧ **ś, ṣ, s**: ⳡϫⲱⲙⲓ ϯⲥⲁ ⳡϫⲉⲛ **Visarga (-ḥ)**
    - **devas + śivaḥ** » **devaḥ śivaḥ** = ⟪देवः⟫ ⟪शिवः⟫ ("Ⲥϩⲓⲥ ⳡϣⲁⲛ ϯⲥⲱⲧ")
  - ⲡϣⲉⲛ **c, ch**: ⳡϫⲱⲙⲓ ϯⲥⲁ **-ś**
  - ⲡϣⲉⲛ **ṭ, ṭh**: ⳡϫⲱⲙⲓ ϯⲥⲁ **-ṣ**
  - ⲡϣⲉⲛ **t, th**: ϫⲓ ⳡϣⲁⲛ **-s**
    - **sādhus + caitanyas** » **sādhuś caitanyaḥ** = ⟪साधुश्चैतन्यः⟫ ("Ⲧϣⲓ ⳡϣⲁⲛ ϯⲥⲱⲧ")

- **ϣⲉⲛ ⳱ⲙⲟⲧ ϭϫⲉⲛ ⳡⲙⲟⲧ**:
  - ϯϥ ⳡⲛⲓⲙⲉⲧⲁϥ ⳡⲛⲓ ϯⲥⲱⲧ: ⳡϫⲱⲙⲓ ϯⲥⲁ **-r**
    - **kavis + Māghas** » **kavir māghaḥ** = ⟪कविर्माघः⟫ ("Ⲙⲁϩ ⳡϣⲁⲛ ϯⲥⲱⲧ")
  - ϯϥ ⳡⲛⲓⲙⲉⲧ⁅ ⳡⲛⲓ ϯⲥⱃ: **-s** ⳡϣⲁⲛ, ϯⲥⱃ ⳡϫⲉⲙ.
    - **gurus + rāmas** » **gurū rāmaḥ** = ⟪गुरू⟫ ⟪रामः⟫ ("Ⲣⲁϥ ⳡϣⲁⲛ ϯⲥⱃ")
  - ⳡϛ ϯⲥⱃ **a-**: **-as**
    - ⳡϛ ϯⲥⱃ ⳡⲙⲟⲧϫⲉⲛ ϭϫⲉⲛ ⳡⲙⲟⲧ/a: ⳡϫⱃⲓ ϯⲥⲁ **-o** (ⳡϣⲱⲧ ⳡⲛⲓ ϯⲥⱃ a ⳡϣⲁⲛ » ⟪ऽ⟫)
      - **devas viṣṇus** » **devo viṣṇuḥ** = ⟪देवो⟫ ⟪विष्णुः⟫
      - **devas agnis** » **devo 'gniḥ** = ⟪देवो⟫ ⟪ऽग्निः⟫
    - ⳡϛ ϯⲥⱃ ⳡⲙⲟⲧϫⲉⲛ: ⳡϫⱃⲓ ϯⲥⲁ **-a** (Hiatus)
      - **devas + indras** » **deva indraḥ** = ⟪देव⟫ ⟪इन्द्रः⟫
