## 20.1. Possesivkomposita = ⟪बहुव्रीहि⟫ m.

::: media
![](/images/lekt2004.webp)
Abb.: ⟪बहुव्रीहिः⟫ ⟪पुरुषः⟫
Jodhpur = ⟪जोधपुर⟫
(Bildquelle: [Details](/licenses#lekt2004))
:::
⟪बहुव्रीहिः⟫ = ⟪बहवो⟫ ⟪व्रीहयो⟫ ⟪यस्य⟫ ⟪सः⟫ = "one who possesses much rice"

::: grammar-box

**ⲟⲩⲃⲁϩⲟⲩⲃⲣⲓϩⲓ ϥⲥⲏⲙⲁⲓⲛⲉ, ϧⲉⲛ ⲟⲩϣⲓⲃⲧ ⲉ ⲡⲓⲧⲁⲧⲡⲟⲩⲣⲟⲩϣⲁ, ⲉ ⲕⲉϩⲱⲃ ⲉϩⲟⲧⲉ ⲡⲉⲧⲥⲁϫⲓ ⲉⲃⲟⲗ ϩⲓⲧⲉⲛ ⲛⲉϥⲙⲉⲗⲟⲥ: ⲉⲧⲱⲙ ⟪बालपुत्रः⟫ ⲉⲣⲉ ⲡⲉϥⲃⲱⲗ ⲉⲃⲟⲗ ϩⲱⲥ ⲟⲩⲧⲁⲧⲡⲟⲩⲣⲟⲩϣⲁ

**Possessivkomposita sind zunächst immer Adjektive, die allerdings substantiviert werden können. Deshalb hängt das grammatische Geschlecht eine Bahuvrīhi von dem ab, worauf sich das Bahuvrīhi bezieht, und nicht von Geschlecht des letzten Kompositionsgliedes.**

:::
::: grammar-box

**ⲛⲓϧⲟⲩⲱⲡ ⲛⲧⲉ ϣⲟⲡⲓⲥ ⲛⲁϩⲱⲙ Bahuvrīhi:**

**1. ⲛⲓϧⲟⲩⲱⲡ ⲙⲛⲧⲁϣ ϭⲉ ⲡⲓⲛⲟⲩϣ (⟪प्रथमा⟫) ⲛⲓϣⲟⲡ, ⲙⲉⲧⲁϣ ϭⲉ ⲡⲓⲛⲟⲩϣ, ϭⲉ ⲡⲓⲛⲟⲩϣ -- 2. ⲛⲓϧⲟⲩⲱⲡ ⲙⲛⲧⲁϣ ϭⲉ ⲡⲓⲛⲟⲩϣ, ⲙⲉⲧⲁϣ ϭⲉ ⲡⲓⲛⲟⲩϣ, ϭⲉ ⲡⲓⲛⲟⲩϣ -- ⲛⲓⲥⲁϫⲉ ϭⲉ ⲛⲓⲙⲟϥ ⲛⲧⲉ ϣⲟⲡⲓⲥ ⲛⲁϩⲱⲙ (ⲙⲛⲧⲁϣ ⲛⲓⲥⲁϫⲉ - ⟪षष्ठी⟫) ϭⲉ ⲛⲓϧⲟⲩⲱⲡ -- ⲛⲓϫⲟⲩⲱⲡ ϭⲉ ⲛⲓϧⲟⲩⲱⲡ.** <!-- TODO: Fallback translation -->

:::
ⲛⲓϫⲟⲩⲱⲡ:

::: indent
⟪गतपापः⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪सः⟫ = "ⲛⲓϧⲟⲩⲱⲡ ⲛⲧⲉ ϣⲟⲡⲓⲥ ⲛⲁϩⲱⲙ" = "ⲛⲓϧⲟⲩⲱⲡ ⲛⲧⲉ ϣⲟⲡⲓⲥ ⲛⲁϩⲱⲙ"

## 20.7. Eine andere Einteilung der Arten von Bahuvrīhis

Die Beispiele sind hier zur späteren Durcharbeitung gegeben, für einige sind bisher die nötige Grammatik und der Wortschatz noch nicht besprochen <!-- TODO: Fallback translation -->

1.  `"nordöstlich"` -> "northeasterly" -> "ⲉ̀ⲡⲓⲥⲁ ⲛ̀ⲓⲁⲃⲧ ⲛⲉⲙ ⲡⲓⲙⲏϣ" (This is a bit tricky. "North-east" is ⲡⲓⲙⲏϣ-ⲓⲁⲃⲧ. The adjectival form is what's needed. Let's just translate the German word) -> "ⲉ̀ⲡⲓⲥⲁ-ⲙⲏϣ-ⲓⲁⲃⲧ"
2.  Translation: 11. ⲛⲓⲥⲁϫⲓ ⲛ̀ⲧⲉ ⲛⲓⲙⲁ ⲉⲑⲣⲉⲩⲥⲏⲙⲁⲓⲛⲉⲓⲛ ⲛ̀ⲛⲓⲙⲁ ⲛ̀ⲙⲉⲥⲟⲥ: ⟪⟨DEVA_
3.  Vergleich im Vorderglied: ⟪कुशाग्रधीः⟫ =  ⟪कुशाग्र⟫ ⟪इव⟫ ⟪धीर्यस्य⟫ ⟪सः⟫
4.  Impliziter Vergleich: ⟪उष्ट्रमुखः⟫ = ⟪उष्ट्रस्य⟫ ⟪मुखमिव⟫ ⟪मुखं⟫ ⟪यस्य⟫ ⟪सः⟫ = "kamelmündig" = dessen Mund wie der eines Kamels ist
5.  Numerale als Hinterglied bei ungefährer Zahl:. ⟪उपसशाः⟫ = ⟪दशानां⟫ ⟪समीपे⟫ ⟪ये⟫ ⟪सन्ति⟫ ⟪ते⟫ = "ungefähr zehn"
6.  beide Glieder sind Numeralia: ⟪एकद्वाः⟫ = ⟪एको⟫ ⟪वा⟫ ⟪द्वौ⟫ ⟪वा⟫ = "ein oder zwei"
