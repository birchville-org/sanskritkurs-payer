# Lesson 45

## 45.1. Formation of the verbal forms of the 2nd person (⟪मध्यमः⟫) athematic stems without vocally ending suffix (continuation)

### 45.1.2. Seventh present class (⟪रुधादि⟫)

::: grammar-box
**If a final k/g of the root comes to stand between the nasal ṅ and a dental of the ending, then the k/g may optionally drop out**

e.g. ⟪युज्⟫ 3.sg.Ind.Pres.Ā ⟪युङ्क्ते⟫ or ⟪यु⟫:sig[⟪ङ्ते⟫]
:::
⟪युज्⟫ 7U

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Indicative Present** :br⟪लट्⟫ | ⟪युनक्षि⟫:bryu-na-j + si | ⟪युङ्क्थ⟫:br⟪युङ्थ⟫ | ⟪युङ्क्षे⟫ | ⟪युङ्ग्ध्वे⟫:br⟪युङ्ध्वे⟫ |
| **Imperfect** :br⟪लङ्⟫ | ⟪अयुनक्⟫:braus: a-yu-na-j + s | ⟪युङ्क्त⟫:br⟪अयुङ्त⟫ | ⟪अयुङ्क्थास्⟫:br⟪अयुङ्थास्⟫ | ⟪अयुङ्ग्ध्वम्⟫:br⟪अयुङ्ध्वम्⟫ |

## 45.2. The Vocative Singular (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**Most vocatives of the singular are the stem with a strong ending.**

e.g. **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** etc.

**Exceptions are the feminine nouns ending in -ā and -ī as well as stems ending in -in, whose vocative singular must be memorized especially carefully.**
:::
::: no-header
| | Vocative Singular |
| --- | --- |
| Masculines in -a | ⟪देव⟫ |
| Neuters in -a | ⟪फल⟫ |
| Feminines in -ā | ⟪देवते⟫ |
| Masculines in -i | ⟪कवे⟫ |
| Feminines in -i | ⟪मते⟫ |
| Masculines in -u | ⟪शत्रो⟫ |
| Feminines in -u | ⟪धेनो⟫ |
| Feminines in -ī | ⟪देवि⟫ |
| Masculines in -ṛ | ⟪पितर्⟫ |
| Feminines in -ṛ | ⟪मातर्⟫ |
| Masculines in -an | ⟪राजन्⟫ |
| Neuters in -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Masculines in -man/-van | ⟪आत्मन्⟫ |
| Masculines in -in | ⟪बलिन्⟫ |
| Masculines in -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt m. | ⟪महन्⟫ |
| mahānt n. | ⟪महत्⟫:br= Nominative |
| Masculines in -mant/-vant | ⟪गुणवन्⟫ |
| Neuters in -mant/-vant | ⟪गुणवत्⟫:br= Nominative |
| Pronouns | no vocative is formed |
:::

3. Did you receive a gift from the king?

Holy man, why do you not fear dangers?

Father, where are you leaving the family?

Śūdra woman, did you carry the load into the house of the rich Brāhmaṇa?

Goddess, you should fulfill the wish for happiness of the Vaiśya who has performed meritorious deeds.

Elephants, you should not break the fetters.

You lion-like man, why do you not direct your entire attention to the Absolute (Brahman)?

Poet, have you measured the worlds?
