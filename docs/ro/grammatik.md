### 2.2 Pronume și adverbe

:::info
**VitePress Notice:** This section covers pronominal and adverbial forms in Sanskrit, with a focus on their grammatical functions and usage in classical texts.
:::

#### 2.2.1 Pronume personale

Sanskritul are un sistem complex de pronume personale, care variază în funcție de persoană, număr și gen.

⟨DEVA_1⟩
⟨IAST_L_1⟩

Acesta este pronumele de a treia persoană singular, neutru.

⟨DEVA_2⟩
⟨IAST_L_2⟩

Acesta este pronumele de a treia persoană singular, masculin.

⟨DEVA_3⟩
⟨IAST_L_3⟩

Acesta este pronumele de a treia persoană singular, feminin.

#### 2.2.2 Pronume demonstrative

Pronumele demonstrative în Sanskrit sunt folosite pentru a indica persoane sau obiecte specifice.

⟨DEVA_4⟩
⟨IAST_L_4⟩

Acesta este pronumele demonstrativ „acesta” (masculin).

⟨DEVA_5⟩
⟨IAST_L_5⟩

Acesta este pronumele demonstrativ „aceasta” (feminin).

⟨DEVA_6⟩
⟨IAST_L_6⟩

Acesta este pronumele demonstrativ „acesta” (neutru).

#### 2.2.3 Adverbe de loc

Adverbele de loc indică direcția sau poziția unei acțiuni.

⟨DEVA_7⟩
⟨IAST_L_7⟩

Acesta este adverbul de loc „aici”.

⟨DEVA_8⟩
⟨IAST_L_8⟩

Acesta este adverbul de loc „acolo”.

#### 2.2.4 Adverbe de timp

Adverbele de timp indică momentul în care are loc o acțiune.

⟨DEVA_9⟩
⟨IAST_L_9⟩

Acesta este adverbul de timp „acum”.

⟨DEVA_10⟩
⟨IAST_L_10⟩

Acesta este adverbul de timp „ieri”.

⟨DEVA_11⟩
⟨IAST_L_11⟩

Acesta este adverbul de timp „mâine”.

#### 2.2.5 Exerciții

1. Traduceți următoarea propoziție: ⟨DEVA_12⟩ ⟨IAST_L_12⟩
2. Identificați pronumele demonstrativ din propoziția: ⟨DEVA_13⟩ ⟨IAST_L_13⟩
3. Completați spațiul liber cu adverbul de loc potrivit: „⟨DEVA_14⟩” ⟨IAST_L_14⟩
4. Traduceți adverbul de timp: „⟨DEVA_15⟩” ⟨IAST_L_15⟩
5. Explicați diferența dintre ⟨DEVA_16⟩ și ⟨DEVA_17⟩. ⟨IAST_L_16⟩ ⟨IAST_L_17⟩

**Atenție:** Asigurați-vă că înțelegeți distincția dintre pronumele personale și cele demonstrative înainte de a trece la exercițiile avansate.
