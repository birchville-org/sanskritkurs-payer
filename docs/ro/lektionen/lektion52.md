# Lecție 52

## 52.1. Neutrumul temelor în -i și -u

::: grammar-box
**Înainte de terminări care încep cu o vocală, se inserează un -n-, acesta fiind un influențat al temelor în n (-in).**
:::
::: grammar-box
| | **⟪वारि⟫ n.:br"apă"** | **⟪मधु⟫ n.:br"miere"** |
| :--- | :---: | :---: |
| ⟪एकवचनम्⟫ |||
| **⟪प्रथमा⟫, ⟪द्वितीया⟫** | ⟪वारि⟫ | ⟪मधु⟫ |
| ⟪तृतीया⟫ | ⟪वारिणा⟫ | ⟪मधुना⟫ |
| ⟪चतुर्थी⟫ | ⟪वारिणे⟫ | ⟪मधुने⟫ |
| ⟪पञ्चमी⟫ | ⟪वारिणस्⟫ | ⟪मधुनस्⟫ |
| ⟪षष्ठी⟫ | ⟪वारिणस्⟫ | ⟪मधुनस्⟫ |
| ⟪सप्तमी⟫ | ⟪वारिणि⟫ | ⟪मधुनि⟫ |
| ⟪आमन्त्रितम्⟫ | ⟪वारि⟫:br⟪वारे⟫ | ⟪मधु⟫:br⟪मधो⟫ |
| ⟪बहुवचनम्⟫ |||
| **⟪प्रथमा⟫, ⟪द्वितीया⟫, ⟪आमन्त्रितम्⟫** | ⟪वारीणि⟫ | ⟪मधूनि⟫ |
| ⟪तृतीया⟫ | ⟪वारिभिस्⟫ | ⟪मधुभिस्⟫ |

| ⟪सप्तमी⟫ | ⟪वारिषु⟫ | ⟪मधुषु⟫ |
:::
## 52.2. Formarea nominală

### 52.2.1. PPP + -vant: Participiul trecut Parasmaipada

::: grammar-box
**Un particip Parasmaipada al trecutului se formează astfel:**

**PPP + -vant / fem.: vatī**
**Declinație ca temele în -vant respectiv f. ⟪देवी⟫**
:::
PPP + -vant / fem.: vatī

Declinație ca temele în -vant respectiv f. ⟪देवी⟫

Exemple:

::: indent
⟪कृतवन्त्⟫ (kṛta-vant) / ⟪कृतवती⟫ "cel/care a făcut"

⟪भिन्नवन्त्⟫ "cel care a spart"
:::
### 52.2.2. ⟪तद्धित⟫-sufix -maya / -mayī

::: grammar-box
**Sufixul ⟪तद्धित⟫ -maya / f.: -mayī formează adjective din substantive cu sensul**

*   **"făcut din"**
*   **"compus din"**
*   **"bogat în"**

**Înainte de -maya (așa cum înainte de -⟪मात्र⟫) consoanele oclusive finale de pauză trebuie înlocuite cu nasalul corespunzător.**
:::
Exemple:

::: indent
⟪अन्नमय⟫ 3 "bogat în hrană"

⟪चिन्मय⟫ 3 (în raport cu ⟪चित्⟫ f. "inteligență") "constând din gândire / minte"

⟪वाङ्मय⟫ 3 (în raport cu ⟪वाच्⟫ f. "limbă") "constând din vorbire"

⟪सोममय⟫ 3 "făcut din Soma, constând din Soma"
:::
::: grammar-box
**Substantivele în -maya sunt folosite ocazional ca substantive neutre și indică atunci abundența a ceea ce este denumit de substantivul la care se adaugă -maya.**
:::
::: indent
de ex. ⟪अन्नमय⟫ n. "abundență de hrană"
:::

### 52.2.3. Suffixul ⟪तद्धित⟫ -eya

::: grammar-box
**Suffixul ⟪तद्धित⟫ -eya / f.: -eyī apare, printre altele, la feminine în sensul de**

*   **"copil al"**
*   **"descendent al"**

**Gradul lung (⟪वृद्धि⟫) al primei vocale.**

de ex. ⟪कौन्तेय⟫ m. "fiul lui ⟪कुन्ती⟫"

## 52.3. Formarea adverbelor: Suffixul adverbial -śas

::: grammar-box
**Suffixul adverbial -śas formează adverbe cu semnificație (în principal) distributivă din:**

*   **Numere**  
Exemple:  
⟪एकशस्⟫ "individual, câte unul"  
⟪द्विशस्⟫ "în perechi, câte doi"  
⟪शतशस्⟫ "în sute, câte o sută"

*   **altor cuvinte**  
Exemple:  
⟪भागशस्⟫ "pe părți"  
⟪सर्वशस्⟫ "pretutindeni, cu totul"  
⟪नित्यशस्⟫ "constant"

## 52.4. Compuse verbale care exprimă că ceva devine sau este făcut ceea ce nu era înainte (⟪अभुततद्भावः⟫)

### 52.4.1. Formări cvi-

::: grammar-box
**În fața rădăcinilor**

*   **⟪कृ⟫ 8U "a face"**
*   **⟪अस्⟫ 2P "a fi"**
*   **⟪भू⟫ 1P "a deveni"**

**Substantivele și adjectivale pot fi plasate ca preverbe pentru a exprima că cineva face o persoană sau un lucru ceea ce este, sau că o persoană sau un lucru devine ceea ce este indicat de acel substantiv.**

**Finalul substantivului este tratat după cum urmează:**


Finalul substantivului este tratat după cum urmează:

*   **-a final și -ā ale cuvintelor declinabile sunt înlocuite cu -ī  **
Exemple:  
⟪कृष्णीभवति⟫ "ceva care nu este negru devine negru"  
⟪कृष्णीकरोति⟫ "el face ceva care nu este negru, negru"  
⟪गङ्गीभवति⟫ "el/ea devine Gangele"  

*   **-i și -u final sunt înlocuite cu vocala lungă corespunzătoare  **
Exemple:  
⟪शुचीभवति⟫ "el/ea/el devine pur"  
⟪गुरूभवामि⟫ "eu devin stăpân"  

*   **-ṛ final este înlocuit cu --rī  **
de ex. ⟪पित्रीभवति⟫ "cineva care nu este tată (⟪पितृ⟩) devine tată = un bărbat își naște primul copil"  

*   **-n final cade și vocala precedentă este tratată conform regulilor menționate mai sus  **
de ex. ⟪राजीबभूव⟫ "cineva (care nu era rege) a devenit rege (⟪राजन्⟫)"

*   **alte substantive nume proprii se află în forma de rădăcină, pe care o au la Locativ (⟪सप्तमी⟫) Plural. Rădăcina este supusă apoi regulilor obișnuite de Sandhi. Vezi Kielhorn, Gramatică § 489,3. **
de ex. ⟪तिर्यक्करोति⟫ "el așează lateral (⟪तिर्यच्⟫)"
:::

### 52.4.2. Suffixul -sāt

::: grammar-box
**Pentru a exprima că o persoană sau un lucru devine complet ceea ce este, sau că cineva face pe altcineva sau ceva să fie în totalitate ceea ce este indicat de un substantiv, se poate adăuga la substantiv**

**suffixul -sāt (care nu devine niciodată -ṣāt)**

**și cuvântul format astfel se poate combina cu rădăcinile**

*   ⟪कृ⟫ 8U "a face"
*   ⟪अस्⟫ 2P "a fi"
*   ⟪भू⟫ 1P "a deveni"
*   ⟪सम्⟫-⟪पद्⟫ 4Ā

**pentru a forma un verb compus.**
:::
Exemple:

::: indent
⟪अग्निसाद्भवति । अग्निसात्संपद्यते⟫ "el devine complet foc"

⟪भस्मसात्करोति⟫ "el se transformă complet în cenușă (⟪भस्मन्⟫ n. "cenușă"))
:::
::: grammar-box
**Uneori, suffixul -sāt înseamnă că o persoană sau un lucru**


*   **devine dependent de ceva sau**
*   **intră în posesia acelui lucru**
*   **sau că cineva face pe altcineva dependent de ceva**

**ceea ce este indicat de substantiv**
:::
Exemplu:

::: indent
⟪राजसाद्भवति⟫ "el devine dependent de rege, el devine proprietatea regelui"
:::
::: grammar-box
**După formările cu -sāt, rădăcinile nu sunt tratate ca după prefixe, deci Absolutiv:**

:::
::: indent
⟪भस्मसात्कृ⟫:sig[⟪त्वा⟫]
:::
## 52.5. Repetiții de cuvinte (⟪द्विरुक्तम्⟫)

::: grammar-box
**Repetiția de cuvinte exprimă în sanscrită:**

*   **Repetiția acțiunii**  
ex. ⟪पुनः पुनः⟫ "mereu din nou"
*   **Distribuție**  
Exemple:  
⟪पृथक्पृथक्⟫ "fiecare în parte, fiecare individual"  
⟪यद्यद्⟫ ... ⟪तत्तद्⟫ "ceea ce este ... totul"  
⟪युगे युगे⟫ "în fiecare epocă cosmică individual"

**Ocazional, din astfel de combinații se poate forma un compus**

:::
Exemple:

::: indent
⟪एकैक⟫ 3 "fiecare individual"
⟪अल्पाल्प⟫ 3 "foarte mic"
⟪नवनव⟫ 3 "mereu nou"
:::
Referitor la așa-numitele compuse ⟪आम्रेडित⟫, în care cuvintele flexionate sunt repetate, dar al doilea a primit un accent în perioada preclasică, deci este vorba de un compus, vezi Wackernagel, Altindische Grammatik II,1 p. 142 și următoarele.
## 52.6. Numeralul (⟪सम्ख्या⟩ f.)

Cele neabordate aici se găsesc, de ex., la Kielhorn, Grammatik §201 și următoarele.

### 52.6.1. Numere cardinale

#### 52.6.1.1. Adjective numerale (pentru 1 până la 19)

::: grammar-box
**Numerele pentru *1 până la 19* sunt adjective.**
**Numerele pentru **1 până la 4** au declinări diferite pentru cele trei genuri.**

**Pentru numerele de la **5 până la 19** (:sig[⟪नवदशन्⟫]) există o singură declinare pentru cele trei genuri.**

**Pentru aceste adjective numerale, valabil ca pentru toate adjectivele: trebuie să fie în același caz, număr și gen cu substantivul corespunzător și invers (adică pentru 1 singular, pentru 2 dual, pentru restul plural).**
:::
Adjective numerale:

::: indent
1 ⟪एक⟫ 3 (Declinatie ca ⟪सर्व⟫, la plural: "câțiva")
2 ⟪द्वि⟫ 3
3 ⟪त्रि⟫ 3
4 ⟪चतुर्⟫ 3
5 ⟪पञ्चन्⟫ 3
6 ⟪षष्⟫ 3
7 ⟪सप्तन्⟫ 3
8 ⟪अष्टन्⟫ 3
9 ⟪नवन्⟫ 3
10 ⟪दशन्⟫ 3
:::
Declinarea este prezentată acolo unde este necesar în listele de cuvinte.

Pentru celelalte adverbii numerale până la 19, consultați de exemplu Kielhorn, Grammatik §201.

#### 52.6.1.2. Substantive numerale (pentru 19 și mai mult)

::: grammar-box
**Cuvintele numerale pentru *19 (⟪एकोनविंशति⟫ "unu mai puțin decât 20") *până la 99* sunt substantive feminine și se declină ca ⟪मति⟩ f. sau substantive de rădăcină în -t (de exemplu, ⟪त्रिंशत्⟩ f.).**

:::
Exemple:

::: indent
20 ⟪विंशति⟩ f.:br
30 ⟪त्रिंशत्⟩ f.
:::

::: grammar-box

**Cuvintele numerale pentru numere **de la 100** sunt substantive neutre. Se declină ca ⟪फलम्⟩.**
:::

Exemple:

::: indent
100 ⟪शत⟩ n.:br
1000 ⟪सहस्र⟩ n.
:::
Pentru fiecare substantiv numeral în parte, consultați de exemplu Kielhorn, Grammatik §201.
#### 52.6.1.3. Aspecte sintactice ale numeralelor cardinale

::: grammar-box
**Din diferența dintre adjectivele verbale și substantivele verbale pentru numerele cardinale rezultă următoarea consecință sintactică:**
*   cuvintele numerale cardinale adjectivale pot fi legate de substantivul care numără doar ca adjective  
de exemplu, ⟪तिसृभिर्नारीभिः⟩ "prin trei femei"  
*   cuvintele numerale cardinale substantivale pot fi legate de substantivul care numără în trei moduri
*   guvernează genitivul (⟪षष्ठी⟩) numitului  
de exemplu, ⟪विंशत्या नारीणाम्⟩ "prin 20 de femei"  
*   stau ca o aposiție în același caz (dar la singular) cu numitul  
de exemplu, ⟪विंशत्या नारीभिः⟩ "prin 20 de femei" 
*   stau ca elementul posterior al unui ⟪तत्पुरुष⟩ cu numitul ca element anterior  
de exemplu, ⟪गोविंशत्या⟩ "prin 20 de vaci"

:::
### 52.6.2. Numere ordinale

Vezi, de exemplu, la Kielhorn, Gramatică §201f.

a) "-mal":

### 52.6.5. Compuse cu numere cardinale în primul element

**⟪बहुव्रीहि⟫ de acest tip se formează foarte regulat.**

Exemplu:

⟪चतुर्मुख⟫ m. "unul, care are patru fețe" = ⟪चत्वारि मुखानि यस्य सः⟫ (un epitet al lui Brahmā)

::: grammar-box
**⟪तत्पुरुष⟫ cu un număr cardinal în primul element nu trebuie formate arbitrar:**

**Regula 1: Cuvintele care indică o direcție cardinală (cum ar fi ⟪पूर्व⟫ 3 "oriental", ⟪उत्तर⟫ 3 "septentrional"), și cuvintele pentru numere cardinale pot forma un ⟪कर्मधारय⟫-compus cu alte cuvinte doar dacă compusul este folosit ca nume propriu.**
:::
De aceea, de exemplu, nu se poate forma un Tatpuruṣa din ⟪उत्तरा वृक्षाः⟫ "copaci de nord" sau din ⟪पञ्च ब्राह्मणः⟫. Din ⟪सप्तन्⟫ și ⟪ऋषि⟫ se poate însă forma Tatpuruṣa ⟪सप्तर्षि⟫ m. "cei șapte Ṛṣis", dacă acesta este folosit ca nume pentru constelația Ursul Mare (Ursa maior).
::: media
![](/images/lekt5206.jpg)
Fig.: ⟪सप्तर्षयः⟫
Constelația celor șapte stele = cei șapte cele mai strălucitori steli ai Ursului Mare (Ursa maior)
(Sursa imaginii: [Detalii](/ro/licenses#lekt5206))
:::

::: grammar-box
**Regula 2: În mod excepțional față de Regula 1, un cuvânt care denumește o direcție cerescă sau un număr cardinal poate forma cu un alt substantiv un Tatpuruṣa, dacă**

1.  se adaugă la compusul format astfel un sufix Taddhita  
Exemple:  
pūrva + śālā ("sală) » \*pūrvaśālā (nu este permis să fie folosit așa!) + Taddhita -a » ⟪पौर्वशाल⟫ 3 "care se află în sala de est"  
ṣaṣ + mātṛ » \*ṣaṇmātṛ (nepermis!) + Taddhita -a » ⟪षण्मातुर⟫ m. "copilul a șase mame" (= ⟪कार्त्तिकेय⟫)  

2.  compusul format astfel este folosit într-un sens care în mod obișnuit este exprimat printr-un sufix Taddhita (în acest caz, trecerea la Bahuvrīhi este fluidă):  
Exemple:  
dvi + go » ⟪द्विगु⟫ : nu: "două vaci", ci: "**cumpărat pentru două vaci**"  
⟪द्विवर्ष⟫ nu: "doi ani", ci: "**de doi ani vechime**"  

3.  compusul format astfel formează primul element al unui alt compus  
Exemplu:  
pañca + go » pañcagava (nepermis ca cuvânt individual!) + dhana » ⟪पञ्चगवधन⟫ m. "Cel ale cărui averi sunt cinci vaci"
:::
::: media
![](/images/lekt5207.webp)
Fig.: ⟪षण्मातुरः कार्त्तिकेय⟫:
Jalakandapuram = ஜலகண்டபுரம்
(Sursa imaginii: [Detalii](/ro/licenses#lekt5207))
:::

::: grammar-box
**O denumire pentru un număr cardinal (dar nu pentru o direcție cardinală) poate funcționa ca element anterior într-un alt substantiv, formând un Tatpuruṣa chiar și atunci când compusul rezultat denumește agregatul mai multor lucruri, adică reunește două sau mai multe lucruri într-o unitate.**

**Tatpuruṣa, cele formate conform acestei reguli se numesc Dvigu (:sig[⟪द्विगु⟫]).**

**Compusele Dvigu, care denumesc o unitate, sunt de obicei neutre. Dacă al doilea element se termină în -a, atunci sufixul feminin -ī poate fi adăugat. Dacă al doilea element se termină în fem. -ā, atunci acesta este înlocuit fie de Neutru -a, fie de Feminin -ī. Dacă al doilea element se termină în -an, atunci acesta este substituit de -a sau -ī.**
:::
Exemple:

::: indent
⟪त्रि⟫ + ⟪भुवनव्⟫ » ⟪त्रिभुवन⟫ n. "agregatul celor trei lumi, cele trei lumi ca unitate, tri-lume (cer-pământ-lună de jos)

⟪त्रिलोक⟫ n. ⟪। त्रिलोकी⟫ n. "tri-lume"
:::
::: grammar-box
**Compusele Dvigu, cărora nu li se adaugă un sufix Taddhita, dar care au semnificația indicată de un sufix Taddhita, își determină genul în funcție de substantivul pe care îl specifică (în realitate, acestea sunt probabil Bahuvrīhi)**
:::
Exemplu:

::: indent
⟪पञ्चगु⟫ 3: "achiziționat pentru cinci vaci"
:::
