# Lecția 31

## 31.1. Cea de-a 7-a clasă de prezent (रुधादि = "रुध् etc.")

:::: grammar-box
**Formare:**

**Înainte de consoanele finale ale rădăcinii de nivel profund, se inserează un așa-numit infix nazal (-na- sau -n-):**

*   **în tema puternică: -na-**
*   **în tema slabă: -n-**

**Pentru legarea consoanelor finale ale rădăcinii cu terminațiile care încep cu consoană, se aplică aceleași reguli ca și pentru clasa de prezent a 2-a.**
::::

Exemple:

युज् 7U "a lega, a împerechea"

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicativ** | **3. sg.** | युनक्ति[[br]]yu-na-j + -ti | युङ्क्ते[[br]]yu + n + j + te[[br]](în interiorul cuvântului, nazalele sunt înlocuite de -ṅ- în fața guturalelor) |
| | **3. pl.** | युञ्जन्ति[[br]]yu + n + j-anti | युञ्जते[[br]]yu + n + j-ate |
| **Optativ** | **3. sg.** | युञ्ज्यात्[[br]]yu + n + j-yā-t | युञ्जीत[[br]]yu + n + j-ī-ta |
| | **3. pl.** | युञ्ज्युर्[[br]]yu + n + j-y-ur | युञ्जीरन्[[br]]yu + n + j-ī-ran |
| **Participiu Prezent** | | युञ्जन्त्-[[br]]yu + n + j-ant-[[br]]fem.: युञ्जती[[br]]yu + n + j-at-ī | |

::::

रुध् 7U "a opri, a aduce la oprire"

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicativ** | **3. sg.** | रुणद्धि[[br]]ru + na + dh + ti | रुन्द्धे[[br]]ru-n + dh + te |
| | **3. pl.** | रुन्धन्ति[[br]]ru-n-dh-anti | रुन्धते[[br]]ru-n-dh-ate |
| **Optativ** | **3. sg.** | रुन्ध्यात्[[br]]ru-n-dh-yā-t | रुन्धीत[[br]]ru-n-dh-ī-ta |
| | **3. pl.** | रुन्ध्युर्[[br]]ru-n-dh-y-ur | रुन्धीरन्[[br]]ru-n-dh-ī-ran |
| **Participiu Prezent** | | रुन्धन्त्-[[br]]ru-n-dh-ant-[[br]]fem.: रुन्धती[[br]]ru-n-dh-at-ī | |

::::

:::: grammar-box
**La unele rădăcini, -n- al temei slabe de prezent a pătruns și în timpurile non-prezent, astfel încât aceste rădăcini sunt considerate cu infix nazal.**
::::

Exemplu:

**भञ्ज्** 7P "a rupe"

::: indent
*   Indicativ Prezent
    *   3.sg.P. **भनक्ति** (bha-na + j + ti)
    *   3.pl.P. **भञ्जन्ति** (bha + n + j-anti)
*   Viitor: **भङ्क्ष्यति** (bha + n + j + sya + ti)
*   Pasiv: **भज्यते** (fie din rădăcina originală **भज्**, fie din *bhñj-ya-te)
*   PPP: **भग्न** (posibil din *bhñj + na)
:::

## 31.2. Listă de cuvinte

**युज्** 7U **युनक्ति** : a încordă, a atârna, a lega, a fixa; Ā de asemenea: a se încorda (= a se strădui), a se uni cu, a se concentra pe (Locativ, सप्तमी)
::: indent
**Fut. योक्ष्यति**
**Pass. युज्यते**
**Kaus. योजयति**
**PPP युक्त**
**Inf. योक्तुम्**

din care:
**युग n. → युग n.:** jug, pereche, epocă a lumii (există patru epoci ale lumii:
1. **कृत**
2. **त्रेता**
3. **द्वापर**
4. **कलि**

**कलियुग** a început în jurul anului 3102 î.Hr., anul războiului **महाभारत**. Mai multe detalii la Basham, Wonder p. 323)

**योग m.:** "încordare, legare", efort, unire, Yoga (vezi Basham, Wonder p. 327ss.)
:::

## 31.3. Exercițiu

A) Traduceți următoarele propoziții și descompuneți compusele:

शस्त्राणि शरीरमेव छिन्दन्ति जीवस्तु न म्रियत इति भगवद्गीतायां भगवतोच्यते ॥२॥
