# Lecție 24

## 24.1. Dativul (⟪चतुर्थी⟫ = "a patra terminație cazuală")

::: grammar-box
**1. Pentru a reda scopul sau intenția ("pentru a") unei acțiuni, se poate utiliza în locul infinitivului (⟪तुमुन्⟫) și un substantiv cu sufix kṛt, care denumește o acțiune sau o stare, în dativ (⟪चतुर्थी⟫ = "a patra terminație cazuală").**

Exemplu:

în loc de:

:::
::: indent
⟪रामो गुरुवचनं श्रोतुं गतः ।⟫
:::
se poate spune și:

::: indent
⟪रामो गुरुवचनस्य श्रवणाय गतः ।⟫

sau:

⟪रामो गुरुवचनश्रवणाय गतः ।⟫
:::
= "Rāma a mers pentru a asculta discursul profesorului."
::: media
![](/images/lekt2404.webp)
Fig.: ⟪बाला गुरुश्रवणाय गताः⟫
(Sursa imaginii: [Detalii](/ro/licenses#lekt2404))
:::

::: grammar-box
**2. Dativul (⟪चतुर्थी⟫) poate indica, de asemenea, obiectul unui infinitiv al scopului care trebuie completat:**

Exemplu:

:::
::: indent
⟪फलेभ्यो ग्रामं गच्छति⟫ = "El merge la sat în scopul fructelor = El merge la sat pentru a lua fructe."
:::
**În același mod, dativul (⟪चतुर्थी⟫) indică scopul unui lucru sau al unei acțiuni:**

Exemplu:

::: indent
⟪यज्ञायान्नम्⟫ = "Mâncare în scopul unui sacrificiu = Mâncare pentru un sacrificiu"
:::
::: media
![](/images/lekt2401.webp)
Fig.: ⟪यज्ञायान्नम्⟫
'Annakut' [⟪अन्नकूट⟫ = ⟪गोवर्धन पूजा⟫] este un eveniment hindus tradițional care are loc în timpul sărbătorilor Anului Nou Hindu la toate mandirele BAPS [બોચાસનવાસી અક્ષ૨ પુરુષોત્તમ સ્વામિનારાયણ સંસ્થા = Bochasanwasi Akshar Purushottam Swaminarayan Sanstha]. Sute de feluri de mâncare vegetariene sunt oferite lui Bhagwan Swaminarayan [સ્વામિનારાયણ] în această zi.
(Sursa imaginii: [Detalii](/ro/licenses#lekt2401))
:::

::: grammar-box
**3. Dativul (⟪चतुर्थी⟫) indică, de asemenea, persoana sau lucrul pentru care obiectul unei acțiuni este destinat (obiect indirect; întrebare: cui?). (Luați în considerare, totuși, verbele cu dublu acuzativ (⟪द्वितीया⟫)!)**

Exemplu:

:::
::: indent
⟪रामाय फलं ददाति⟫ = "El îi dă lui Rāma un fruct." (Rădăcină ⟪दा⟫ Clasa de prezent 3)
:::
::: media
![](/images/lekt2402.webp)
Fig.: ⟪बाला बालाय रक्षबन्धनं ददाति⟫
Raksha bandhan este sărbătorit cu entuziasm și bucurie în toată India. Acest festival întruchipează iubirea necondiționată dintre frați și surori.
(Sursa imaginii: [Detalii](/ro/licenses#lekt2402))
:::

::: grammar-box
**4. Dativul apare la unele verbe (și la alte câteva cuvinte) similar cu germana, răspunzând la întrebarea "cui?":**

Exemple:

:::
::: indent
⟪क्रुध्⟫ : ⟪देवो नरेभ्यो क्रुध्यति⟫ = "Zeul se mânie pe oameni."

⟪अलम्⟫ Adverb: "suficient, adecvat, pe măsură": ⟪अलं योधो योधाय⟫ = "un războinic este pe măsura celuilalt războinic"
:::
::: media
![](/images/lekt2403.webp)
Fig.: ⟪अलं योधो योधाय⟫
"Rama (dreapta) șezând pe umerii lui Hanuman, se luptă cu regele demon Ravana." c. 1820
(Sursa imaginii: [Detalii](/ro/licenses#lekt2403))
:::
Alte utilizări ale dativului mai târziu.

## 24.2. Formarea dativului (⟪चतुर्थी⟫)

::: grammar-box
**Terminațiile regulate ale dativului sunt:**

* **Singular: -e ; temele feminine care se termină în vocală: -ai**
* **Plural: Dativ și Ablativ ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. Teme consonantice

::: grammar-box

| | Dativ Singular | Dativ Plural |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. Pronume interogative

::: grammar-box

| | Masculin / Neutru | Feminin |
| :--- | :--- | :--- |

:::

::: grammar-box

:::
### 24.2.4. Teme vocalice

::: grammar-box
**Teme vocalice**

* **Masculine / Neutre în -a:** ⟪देव⟫
* Dat. sg. ⟪देवाय⟫
* Dat. pl. ⟪देवेभ्यस्⟫
* **Masculine în -i:** ⟪कवि⟫
* Dat. sg. ⟪कवये⟫
* Dat. pl. ⟪कविभ्यस्⟫
* **Masculine în -u:** ⟪पशु⟫
* Dat. sg. ⟪पशवे⟫
* Dat. pl. ⟪पशुभ्यस्⟫
* **Feminine în -ā:** ⟪देवता⟫
* Dat. sg. ⟪देवतायै⟫
* Dat. pl. ⟪देवताभ्यस्⟫
* **Feminine în -ī:** ⟪देवी⟫
* Dat. sg. ⟪देव्यै⟫
* Dat. pl. ⟪देवीभ्यस्⟫
* **Feminine în -i:** ⟪श्रुति⟫
* Dat. sg. ⟪श्रुतये⟫ sau ⟪श्रुत्यै⟫ (adică ca ⟪कवि⟫ sau ca ⟪देवी⟫)
* Dat. pl. ⟪श्रुतिभ्यस्⟫
* **Feminine în -u:** ⟪धेनु⟫
* Dat. sg. ⟪धेनवे⟫ sau ⟪धेन्वै⟫
* Dat. pl. ⟪धेनुभ्यस्⟫
:::
## 24.3. Sandhi pentru -ai și -au finale

::: grammar-box
**Sandhi pentru -ai și -au finale**

* **-ai înaintea unei vocale inițiale este de obicei înlocuit cu -ā (mai rar cu -āy, ca în interiorul cuvântului)**
* **-au înainte de o vocală este de obicei înlocuit cu -āv (mai rar cu -ā)**

Exemplu:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा अग्नये⟫ = "acestui foc"
:::
## 24.4. Listă de cuvinte

⟪अलम्⟫ Adverb: suficient, îndeajuns, (cineva, ceva) pe măsură ; cu dativ: suficient pentru, îndeajuns pentru, pe măsura ; cu instrumentalul: suficient cu, renunță la , de ex. ⟪अलं क्रोधेन⟫ = "suficient cu mânia = renunță la mânie!"

⟪कृतम्⟫ : ⟪कृतं क्रोधेन⟫ = "S-a făcut cu mânia = renunță la mânie!"
