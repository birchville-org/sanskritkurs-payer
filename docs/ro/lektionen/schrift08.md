### Consoane aglutinate

Dacă într-un cuvânt sau propoziție două sau mai multe consoane se succed imediat, acestea se scriu cu ligatură (semn unit).

1. Dacă primul dintre semnele consoanelor de unit se termină cu linia verticală din dreapta, acesta își pierde această linie și este plasat în fața celei de-a doua consoane.

Excepție: dacă a doua consoană este ⟪न्⟫ sau ⟪ल्⟫, aceasta este plasată sub prima consoană, cu pierderea liniei orizontale. În funcție de tipografia utilizată, există alte excepții, enumerate mai jos. Dacă într-o anumită tipografie o ligatură nu este prevăzută, se plasează un Virāma.
