# Lecție 22

## 22.1. Absolutivul (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

Dacă se dorește exprimarea în sanscrită faptul că o acțiune a agentului (⟪कर्तृ⟫) precede sau însoțește ca circumstanță o altă acțiune a agentului, se utilizează absolutivul (⟪क्त्वा । ल्यप्⟫). Așadar

"după ce a făcut aceasta, face aceea"; "face aceasta, apoi face aceea"; "în urma acestui lucru, face acela"; "am venit, am văzut și am învins" etc.

Absolutivul este un verb-advorb, adică nu se conjugă și nici nu se declină; totuși, are întotdeauna – cu puține excepții – același agent (⟪कर्तृ⟫) ca acțiunea pe care o precede sau însoțește absolutivul. Astfel, agentul absolutivului este la nominativ (⟪प्रथमा⟫) sau instrumental (⟪तृतीया⟫).

Alături de compuse, absolutivul este unul dintre cele mai frecvente mijloace de exprimare în sanscrită.

La traducerea în germană, se evită repetarea constantă a cuvântului "după ce". Se folosesc în schimb expresiile uzuale germane pentru succesiunea temporală.

**Schema:**

(precizare referitoare la absolutiv: circumstanțial, obiect etc.) - Absolutiv - Absolutiv - ... - Absolutiv - ... Agent + propoziție verbală (la activ sau pasiv)

:::
**Exemple:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = construcție pasivă: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**
"Bărbatul intră în casă, vede fetița mică și îi vorbește."

Plural: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. Formarea abstractivei

::: grammar-box
**Formarea abstractivei**

*   Verbe fără prefix: abstractiv în **-tvā**
*   Verbe cu prefix: abstractiv în **-ya** sau **-tya**
:::
### 22.2.1. Verbe fără prefix: abstractiv în -⟪त्वा⟫

::: grammar-box

**Formare:**

(de obicei) rădăcina în gradul redus, în forma pe care o are înainte de PPP + **-tvā** (**-⟪त्वा⟫**)

Doar negațiunea **a-** / **an-** se poate combina cu sufixul **-⟪त्वा⟫** : ⟪अकृत्वा⟫ "fără a fi făcut"

:::
**Exemple:**

::: indent
⟪आप्त्वा⟫ "după ce el/ea/el (subiect neutru)/eu/tu/noi/voi/ei/nei/dvoi/voi doi/aceștia din urmă a atins/a atinsese/a au atins/a au atinsese"

⟪आसित्वा⟫ "după ce el (...) a stat șezând/a statusese"

⟪इत्वा⟫ "după ce el (...) a mers/a mersese"

⟪स्थित्वा⟫ "după ce el (...) a stat în picioare/a statusese"

⟪जित्वा⟫ "după ce el (...) a învins/a învinsese"

⟪उक्त्वा⟫ "după ce el (...) a vorbit/a spusese"
:::
### 22.2.2. Verbe cu prefix

#### 22.2.2.1. Rădăcini cu vocală lungă (în afară de -ā) sau cu consoană

::: grammar-box

**(de obicei) rădăcina în gradul redus + -ya**

:::
**Exemple:**

::: indent
⟪उपनीय⟫ "după ce el (...) a adus/a adusesese"

⟪प्रभूय⟫ "după ce el (...) a ieșit în evidență/a ieșise" "după ce el (...) a avut putere"

⟪प्राप्य⟫ "după ce el (...) a obținut/a obținuse"
:::
#### 22.2.2.2. Rădăcini în -ā

::: grammar-box

**rădăcina în gradul plin, neschimbată + -ya**

:::
**Exemplu:**

::: indent
⟪उपस्थाय⟫ "după ce el (...) a intrat/a intrase" ; (dar fără prefix: ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. Rădăcini care în gradul redus se termină cu -i scurt, -u, -ṛ

::: grammar-box

**radical profund + -tya**

:::
**Exemple:**

::: indent
⟪प्रस्तुत्य⟫ "după ce a (...) lăudat cu voce tare / avusese"

⟪विस्मृत्य⟫ "după ce a (...) uitat / avusese"

⟪संस्कृत्य⟫ "după ce a (...) pregătit pentru jertfă / avusese"
:::
#### 22.2.2.4. Rădăcini în -am / -an, care la forma profundă se termină în -a

::: grammar-box

**Opțional:**

Rădăcină în **-am** / **-an** + **-ya**

sau:

Rădăcină în **-a** + **-tya**

:::
**Exemplu:**

::: indent
⟪विगम्य⟫ sau ⟪विगत्य⟫ "după ce a (...) trecut / fusese"
:::
