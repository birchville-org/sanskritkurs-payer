# Lecția 29

## 29.1. Utilizarea Parasmaipada (⟪परस्मैपद⟫) și Ātmanepada (⟪आत्मनेपद⟫) în Causativ


::: grammar-box
**Cauzativul este, cu puține excepții, Ubhayapada (⟪उभयपद⟫)**
:::
::: grammar-box
**În causativ se folosește Ātmanepada (⟪आत्मनेपद⟫):**

**1. Când rezultatul acțiunii cauzate îi folosește celui care cauzează:**
:::
Exemplu:

⟪रामः⟫ ⟪कटं⟫ ⟪कारयते⟫ = „Rāma face să fie făcută o saltea pentru sine (în propriul interes)”

**2. Când causativul verbelor tranzitive este folosit reflexiv („a se arăta”, „a se lăsi auzit” etc.), sau când obiectul verbului simplu este Agens (⟪कर्तृ⟫) al causativului:**

Exemplu:

⟪विष्णुर्भक्तान्दर्शयते⟫ = „Viṣṇu li se arată devotaților săi”

Rezultat: ⟪भक्ता⟫ ⟪विष्णुं⟫ ⟪पश्यन्ति⟫ = „Credincioșii îl văd pe Viṣṇu”


Regulile corespund, în general, regulilor pentru utilizarea Ātmanepada (⟪आत्मनेपद⟫) la verbele Ubhayapada (⟪उभयपद⟫).
