# Exercițiul 57

## A) Transformări ale aoristului

Traduceți și determinați următoarele forme și formați formele corespunzătoare ale **aoristului**. În afară de cauzative și rădăcini care formează **aoristul s**, clasa aoristului corespunzător este indicată între paranteze:

::: grammar-box
| Nr. | Formă | Determinare / Semnificație | Aorist |
|:---|:---|:---|:---|
| १. | **पेचिथ** | *पच्* 1U: 2. Sg. Perf. P. (tu ai păzit) | **अपाक्षीः** |
| २. | **अवक्** (३) | *वच्* 2P: 2. 3. Sg. Impf. P. (tu ai vorbit / el a vorbit) | **अवोचः / अवोचत्** |
| ३. | **सोष्यसि** | *सु* 1/2P: 2. Sg. Fut. P. (tu te vei înmulți) | **असौषीः** |
| ४. | **छिन्दे** | *छिद्* 7U: 1. Sg. Ind. Präs. Ā. (taies) | **अच्छित्सि** |
| ५. | **कुरुषे** | *कृ* 8U: 2. Sg. Ind. Präs. Ā. (faci în interesul tău) | **अकृथाः** |
| ६. | **आधत्ते** | *आ-धा* 3Ā: 3. Sg. Ind. Präs. Ā. (așază) | **आधित** |
| ७. | **पद्यते** | *पद्* 4Ā: 3. Sg. Ind. Präs. Ā. (merge) | **अपादि** |
| ८. | **जिगाय** | *जि* 1P: 1. 3. Sg. Perf. P. (eu am triumfat / el a triumfat) | **अजैषीत्** |
| ९. | **जिघ्रामः** (१,६) | *घ्रा* 1P: 1. Pl. Ind. Präs. P. (mirosim) | **अघ्रास्म / अघ्राम** |
| १०. | **शासति** (२) | *शास्* 2P: 3. Pl. Ind. Präs. P. (ei poruncesc) | **अशिषन्** |
| ११. | **स्तुवे** | *स्तु* 2U: 1. Sg. Ind. Präs. Ā. (laud) | **अस्तोषi** |
| १२. | **दिग्धे** | *दिह्* 2U: 3. Sg. Ind. Präs. Ā. (unge) | **अदिग्ध** |
| १३. | **प्लवध्वे** | *प्लु* 1Ā: 2. Pl. Ind. Präs. Ā. (notați înotând) | **अप्लोढ्वम्** |
| १४. | **तस्थिथ** (१) | *स्था* 1P: 2. Sg. Perf. P. (tu ai stat) | **अस्थाः** |
| १५. | **बिभ्यति** | *भी* 3P: 3. Pl. Ind. Präs. P. (ei se tem) | **अभैषुः** |
| १६. | **ततर्प** | *तृप्* 4/6P: 1. 3. Sg. Perf. P. (eu / el a saturat) | **अतार्प्सीत् / अत्राप्सीत्** |
| १७. | **जुहुथ** | *हु* 3P: 2. Pl. Ind. Präs. P. (notați jertfind) | **अहौष्ट** |
| १८. | **ऊषुः** | *वस्* 1P: 3. Pl. Perf. P. (ei locuiau) | **अवात्सुः** |
| १९. | **ससर्जिथ** | *सृज्* 6P: 2. Sg. Perf. P. (tu ai creat) | **अस्राक्षीः** |
| २०. | **लिल्यिरे** | *ली* 4Ā: 3. Pl. Perf. Ā. (ei se strâng) | **अलेषत / अलासत** |
| २१. | **अत्याजयम्** | *त्यज्* 1P: 1. Sg. Impf. P. Kaus. (am lăsat să părăsească) | **अतित्यजम्** |
| २२. | **सिध्यथ** (२) | *सिध्* 4P: 2. Pl. Ind. Präs. P. (notați fiți la țintă) | **असिधत** |
| २३. | **निन्य** | *नी* 1U: 2. Pl. Perf. P. (notați ați condus) | **अनैष्ट** |
| २४. | **कर्षन्ति** | *कृष्* 1P: 3. Pl. Ind. Präs. P. (ei trag) | **अकार्क्षुः / अक्राक्षुः** |
| २५. | **अप्रच्छयन्** | *प्रच्छ्* 6P: 3. Pl. Impf. P. Kaus. (ei au lăsat să întrebe) | **अपप्रच्छन्** |
:::
