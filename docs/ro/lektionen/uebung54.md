# Exercițiul 54

Formați corespunzătoarele forme de aorist pentru următoarele forme de prezent sau perfect:

:::grammar-box
| Nr. | Formă | Determinare / Semnificație | Aorist |
|:---|:---|:---|:---|
| १. | **यन्ति** | ei merg | **अगुः** |
| २. | **पिबामि** | eu beau | **अपाम्** |
| ३. | **ददौ** | eu am dat / el a dat | **अदाम् / अदात्** |
| ४. | **बभूव** | eu / el / ei a fost / ați fost | **अभूवम् / अभूत् / अभूत** |
| ५. | **दधति** | ei așază | **अधुः** |
| ६. | **ऐम** | noi am mers | **अगाम** |
| ७. | **पपिथ** | tu ai băut / ai păzit | **अपाः** (la *पा* "a bea") |
| ८. | **तिष्ठति** | el stă | **अस्थात्** |
| ९. | **इयेथ** | tu ai mers | **अगाः** |
| १०. | **पप** | voi ați băut | **अपात** |
| ११. | **एष्यथ** | voi veți merge | **अगात** |
| १२. | **तस्थुः** | ei au stat | **अस्थुः** |
| १३. | **अधत्त** | voi ați așezat | **अधात** |
| १४. | **अददाः** | tu ai dat | **अदाः** |
| १५. | **अभवन्** | ei au fost | **अभूवन्** |
| १६. | **ददिम** | noi am dat | **अदाम** |
| १७. | **भिद्यते** | este spart | **अभेदि** |
| १८. | **उद्यते** | este spus | **अवादि** |
| १९. | **स्तूयते** | el este lăudat | **अस्तावि** |
| २०. | **कृष्यते** | este arat | **अकर्षि** |
| २१. | **जायते** | el se naște | **अजनि** |
| २२. | **गीयते** | este cântat | **अगायि** |
| २३. | **गम्यते** | este mers | **अगामि** |
