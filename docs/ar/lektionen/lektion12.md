# الدرس 12


## 12.1. اسم المفعول الماضي (PPP)

إحدى طرق بناء جمل المبني للمجهول في الزمن الماضي هي استخدام ما يُعرف باسم اسم المفعول الماضي (PPP).

::: grammar-box
**في الواقع، ليس اسم المفعول الماضي (PPP) اسماً حقيقياً للمفعول، لأنه لا يُشتق من جذر الزمان. بل هو اشتقاق اسمي للجذر مع اللاحقة الأولية -ta أو -na. ولذلك يُطلق على هذه اللاحقة في القواعد الهندية اسم kta.**
:::

### 12.1.1. مخطط للأفعال المتعدية

::: grammar-box
**الفاعل (kartṛ) في أداة الفاعل (tṛtīyā) -- المفعول به المباشر (karman) في الفاعل (prathamā) -- اسم المفعول الماضي**

يتطابق اسم المفعول الماضي في هذه الحالة مع المفعول من حيث العدد والحالة والنوع.

لا حاجة لفعل مساعد (مثل "يكون").

أمثلة:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = "(تم بلوغ الجنة من قبل الصالح) = لقد بلغ الصالح الجنة."
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = "(تم تعظيم الإلهة من قبل البراهماني بذبيحة) = لقد عظم البراهماني الإلهة بذبيحة."
:::

### 12.1.2. المخطط الأول للأفعال اللازمة وأفعال الحركة

::: grammar-box
**الفاعل (kartṛ) في الفاعل (prathamā) -- اسم المفعول الماضي**

في هذه الحالة، يتطابق اسم المفعول الماضي مع الفاعل من حيث العدد والحالة والنوع. يحمل اسم المفعول "المبني للمجهول" معنى فاعلاً عند الأفعال اللازمة (الأفعال التي لا مفعول بها مباشر) وأفعال الحركة.

مثال:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = "لقد ذهبت امرأة الكشترية إلى المدينة."
:::

### 12.1.3. المخطط الثاني للأفعال اللازمية وأفعال الحركة

::: grammar-box
**الفاعل (kartṛ) في أداة Instrumentalis (tṛtīyā) -- اسم المفعول الماضي PPP في حالة الرفع المفرد المذكر**

مثال:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(من قبل الكشترية تم الذهاب (إلى المدينة)) = لقد ذهب الكشatriya (إلى المدينة).“

بناءً على المخطط الثاني هو أقل شيوعًا بكثير من البناء وفقًا للمخطط الأول.
:::

## 12.2. حول معنى اسم المفعول الماضي PPP

بينما فإن ما يسمى بـ "اسم المفعول الماضي" للأفعال المتعدية له في المقام الأول معنى سلبي (**āpta** = „تم الوصول“) ولأفعال اللازمية وأفعال الحركة له معنى إيجابي (**gata** = „ذهب“) هناك بعض الأفعال التي يمكن أن يكون فيها اسم المفعول الماضي PPP له كل من المعاني الإيجابية والسلبية:

على سبيل المثال
**gata** = ⟪गत⟫ = „ذهب“ (إيجابي)؛ ولكن أيضًا: **gato mārgaḥ** = ⟪गतो मार्गः⟫ = „طريق قد سلك“ (سلبي)
**āpta** = ⟪आप्त⟫ = „تم الوصول إليه“ (سلبي) ، „في حالة الوصول“ (إيجابي)


## 12.3. تكوين اسم المفعول الماضي PPP

::: grammar-box
توجد طرق التكوين التالية (لكل جذر يجب تعلم اسم المفعول الماضي PPP الخاص به!):

**(في الغالب) جذر في درجة منخفضة**

**+ -ta**
مع حرف ربط **-i-** قبله: **-ita**
بدون حرف ربط: **-ta**
**+ -na**

تصريف المؤنث: **-tā**، **-itā**، **-nā**؛ بينما المذكر يتصرف مثل **phala** n.
:::

### 12.3.1. اسم المفعول الماضي PPP على -ta (kta)

#### 12.3.1.1. بدون حرف ربط -i- (aniṭ)

*aniṭ* = „بدون (*an-*) قبل اللاحقة *-i-* *t*“ (أي بدون حرف الربط *i*).

::: grammar-box
بدون حرف ربط، يُشتق الفعل الماضي التام (PPP) بشكل عام من الجذور التي تنتهي بحرف متحرك، وكذلك من العديد من الجذور الأخرى، دون وجود قاعدة ثابتة تحدد متى يظهر حرف الربط ومتى لا يظهر في الجذور ذات البنية المحددة.

توجد قائمة بالجذور *aniṭ* في كتاب كيلهورن، *قواعد اللغة* الفقرة 298.
:::
**أمثلة:**

::: grammar-box
| الجذر | الفعل الماضي التام (kta) |
| :--- | :--- |
| **bhū** 1 P:br(⟪भू⟫) | **bhū-ta** :br(⟪भूत⟫) |
| **smṛ** 1 P:br(⟪स्मृ⟫) | **smṛ-ta** :br(⟪स्मृत⟫) |
| **nṛt** 4 P:br(nṛt-ta):br(⟪नृत्त⟫) | **nṛt-ta** :br(⟪नृत्त⟫) |
| **nī** 1 U:br(⟪नी⟫) | **nī-ta** :br(⟪नीत⟫) |
| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |
| **su** 5 U:br(⟪सु⟫) | **su-ta** :br(⟪सुत⟫) |
| **gam** 1 P:br(⟪गम्⟫) | **ga-ta** (\< \*gm-ta):br(⟪गत⟫) |
| **ji** 1 P:br(⟪जि⟫) | **ji-ta** :br(⟪जित⟫) |
| **śru** 5 P:br(⟪श्रु⟫) | **śru-ta** :br(⟪श्रुत⟫) |
| **kṛ** 8 U:br(⟪कृ⟫) | **kṛ-ta** :br(⟪कृत⟫) |
| **tan** 8 U:br(⟪तन्⟫) | **ta-ta** (\< \*tn-ta):br(⟪तत⟫) |
| **iṣ** 6 P:br(⟪इष्⟫) | **iṣ-ṭa** :br(⟪इष्ट⟫) |
:::
#### 12.3.1.2. مع حرف ربط -i- (seṭ)

*seṭ* = *sa-iṭ* = "مع (*sa-*) اللاحقة السابقة (*-i-) *t*" (أي مع حرف الربط *i*).

**أمثلة:**

::: grammar-box
| الجذر | الفعل الماضي التام (kta) |
| :--- | :--- |
| **kup** 4 P:br(⟪कुप्⟫) | **kup-i-ta** :br(⟪कुपित⟫) |
| **khād** 1 P:br(⟪खाद्⟫) | **khād-i-ta** :br(⟪खादित⟫) |
| **rakṣ** 1 P:br(⟪रक्ष्⟫) | **rakṣ-i-ta** :br(⟪रक्षित⟫) |
| **vad** 1 P:br(⟪वद्⟫) | **ud-i-ta** (\< \*vd-i-ta):br(⟪उदित⟫) |
:::

## 12.4. قوانين الاتصال الصوتي في الكلمة

في تشكيلات *aniṭ*، يجب مراعاة قوانين الاتصال الصوتي التالية داخل الكلمة. **هذه القوانين مهمة جداً لفهم صرف اللغة السنسكريتية بأكمله.**

::: no-header
| | |
| :--- | :--- |
| **1. تبقى الحروف k, t, p قبل الإقفال غير المنطوق (مثل t, th) دون تغيير:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. يُستبدل ct بـ kt = ⟪क्त्⟫:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. يُستبدل śt بـ ṣṭ = ⟪ष्ट्⟫:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. الإقفال المنطوق غير المطبق – ما عدا j – يُستبدل قبل الصوت غير المنطوق بالصوت الإقفالي غير المطابق له:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (مهم لفئة Present II) |
| **5. يُستبدل jt بـ kt أو ṣṭ (ليس اختيارياً!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. الإقفال المنطوق المطبق + الإقفال غير المنطوق » الإقفال المنطوق غير المطبق + الإقفال المنطوق المطبق (قانون التنقيح الخاص ببارتولوماي):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. يُستبدل h-t بـ ḍdh مع إطالة i أو u السابقة؛ أو بـ gdh. قبل مثل هذا ḍdh، يُستبدل a بـ o، وأقل شيوعاً بـ ā:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) "يخفي شيئاً"):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.5. قائمة الكلمات

**budh** 4 Ā (budhyate) / 1 U (bodhati)، PPP **buddha** ⟪बुध् बुध्यते बोधति बुद्ध⟫ : أن يستيقظ، أن يستيقظ إلى الإدراك؛ PPP **buddha** 3 مستيقظ، ومن هنا **Buddha** = "المتيقظ" (وليس: المنير)

::: media
![](/images/lekt1201.webp)
التسمية: ⟪गौतमो बुद्धः⟫
(مصدر الصورة: [تفاصيل](/ar/licenses#lekt1201))
:::
**dah** 1 P (dahati)، PPP **dagdha** ⟪दह् दहति दग्ध⟫ : (شيء ما) يحرق
**sah** 1 Ā (sahate)، PPP **soḍha** ⟪सह्⟫ sahate soḍha : يتغلب على، يتحمل، يتحمله بصبر = يغفر
**mṛga** m. ⟪मृग⟫ : حيوان بري
**mārga** m. ⟪मार्ग⟫ : طريق (غالباً ما كانت الطرق مسارات للحيوانات البرية)

::: media
![](/images/lekt1202.webp)
التسمية: ⟪मार्गः⟫
(مصدر الصورة: [تفاصيل](/ar/licenses#lekt1202))
:::
**api** ⟪अपि⟫ : أيضاً (مؤخر)

تُصنّف بعض الجذور من قِبل النحويين المحليين ضمن الصف السادس للأزمنة الحاضرة، حيث تُكوّن جذع الزمن الحاضر باستخدام infix الأنف وفتحة الموضوع a، على سبيل المثال:

**muc** 6 U (muñcati)، PPP **mukta** ⟪मुच् मुञ्चति मुक्त⟫ : يحرر، يطلق سراحه؛ تحرير من دورة التناسخ (**saṃsāra** m.) = الخلاص
**sic** 6 U (siñcati)، PPP **sikta** ⟪सिच् सिञ्चति सिक्त⟫ : يرش

حول تكوين الكلمات:

**muc**: **mokṣa** m. ⟪मोक्ष⟫ : التحرر، الخلاص، الفداء
**sic** + **abhi-**: **abhiṣeka** m. ⟪अभिषेक⟫ : رش الملك عند تتويجه، تتويج ملك
**budh**: **bodhi** m./f. ⟪बोधि⟫ : الاستيقاظ (الذي من خلاله يصل بوذا أو جينا إلى البصيرة الخلاصة)

**buddhi** f. (**budh** + **-ti**) ⟪बुद्धि⟫ : المعرفة، أداة المعرفة.

## 12.6. التمرين

**أ) صيغ جمل المبني للمجهول في الماضي من الجمل الفعالة الواردة في [الدرس 7](/lektionen/lektion07)، التمرين أ، وفيما يتعلق بالأفعال اللازمة وأفعال الحركة صيغ جمل فعلية في الماضي.**

**ب) كوّن التصريفات المناسبة من Participium Perfekt Passiv (PPP) لأشكال الأفعال الواردة في [الدرس 10](/lektionen/lektion10)، التمرين أ. لاحظ أن شكلاً مثل sṛjati يقابله PPP في جميع الأجناس الثلاثة.**

**ج) حوّل جمل [الدرس 10](/lektionen/lektion10)، التمرين ج، إلى المبني للمجهول في زمن الماضي.**
