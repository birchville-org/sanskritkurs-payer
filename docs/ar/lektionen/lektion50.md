# الدرس الخامس0

## 50.1. تكوين الأسماء: الزيادة المنتظمة

::: grammar-box
**يتم التدرج المنتظم في السنسكريتية باستخدام لاحقات ⟪तद्धित⟫**
* **-⟪तर⟫ (المؤنث: ⟪तरा⟫) في "المقارن"**
* **⟪तम⟫ (المؤنث: ⟪तमा⟫) في "التفضيل"**

**تُضاف هذه اللواحق إلى جذر المذكر في الصفات. وفي الأسماء ذات تدرج الجذر، تُضاف إلى الجذر الضعيف، الذي يكون له شكل مثل الجمع في حالة الخافض (-su) (⟪पञ्चमी⟫).**
:::
::: media
![](/images/lekt5007.webp)
التوضيح: ⟪लोकस्योत्तमो⟫ ⟪गिरिः⟫
⟪सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = جبل إيفرست
(مصدر الصورة: [تفاصيل](/ar/licenses#lekt5007))
:::

::: grammar-box
**المعنى:**

**يُقصَد بـ "المقارنة"، عندما لا يُعبَّر عن الشيء المُقارَن: "إلى حدٍّ ما، جداً، زائد/مفرط":**

:::
::: indent
مثلاً ⟪सुचितर⟫ 3 "نظيف إلى حد ما"، "نظيف جداً"، "نظيف جداً"
:::
**عند التعبير عن شيء يُقارن به، يأتي في حالة النصب (⟪पञ्चमी⟫). الصيغة التفضيلية + حالة النصب تعادل التدرج باستخدام "من" في الألمانية.**

::: indent
مثلاً ⟪देवदत्ताद्रामो⟫ ⟪धीमत्तरः⟫ = حرفياً: "من منظور ديفاداتا، راما أكثر حكمة" = "راما أكثر حكمة من ديفاداتا"
:::
تعني "الدرجة العليا" عدم التعبير عن كائن مقارن: "بشكل مفرط، جداً":

::: indent
على سبيل المثال، ⟪सत्तम⟫ 3 (إلى ⟪सन्त्⟫) "جيد للغاية، جيد جداً"
:::
**عند التعبير عن شيء مُقارَن، يأتي هذا الشيء في حالة المضاف إليه (⟪षष्ठी⟫) ("من"، "تحت") ويتوافق التفضيل الأعلى مع التفضيل الأعلى الألماني (أعلى درجة):**

::: indent
على سبيل المثال، ⟪द्विजानां⟫ ⟪सत्तमः⟫ = "أفضل المولودين مرتين"
:::
**لا تقتصر لاحقات -⟪तर⟫ و -⟪तम⟫ على الصفات فحسب، بل يمكن أن تأتي أيضًا بعد الأسماء، والأسماء غير المتغيرة، وحتى أشكال الأفعال:**

أمثلة:

::: indent
⟪गजतम⟫ م. "أفضل فيل" (⟪गज⟫) (أيضاً وصف للبوذا)

⟪गोतम⟫ م. "أكبر الثيران" (⟪गो⟫) أو: "الأغنى بالماشية"

⟪उद्⟫ أداة لا محل لها من الإعراب: "إلى"، "فوق" » ⟪उत्तर⟫ 3 "أعلى" » ⟪उत्तम⟫ 3 "الأعلى"
:::
**إذا أُضيفت هذه اللواحق إلى صيغة فعلية، فإنها تظهر دائمًا في الصيغة الظرفية:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

أمثلة:

::: indent
⟪पचतितराम्⟫ "هو/هي/إنه يطبخ بشكل أفضل"

⟪पचतितमाम्⟫ "يَطْبُخُ أَحْسَنَ"
:::
**لهذه الصيغة هذه اللاحقات أيضًا، عندما ترتبط بكلمة غير متغيرة ويُستخدم المشتق كظرف:**

::: indent
مثلاً ⟪सुतराम्⟫ (إلى ⟪सु⟫) "بطريقة أفضل" (ظرف)
:::
::: media
![](/images/lekt5006.webp)
الشكل: ⟪का⟫ ⟪पचतितमाम्⟫
ليسو = 傈僳族، ⟪अरुणाचल⟫ ⟪प्रदेश⟫
(مصدر الصورة: [تفاصيل](/ar/licenses#lekt5006))
:::
