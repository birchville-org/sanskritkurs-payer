# الدرس 17

## 17.1. الفئة الثانية من المضارع (⟪अदादि⟫ = ⟪अद्⟫ وما إلى ذلك)

تظهر الخواص الفعلية مباشرةً بعد الجذر. ويجب مراعاة التغيرات الصوتية الناتجة عن ساندِيا الكلمات.

::: grammar-box

توجد أشكال التعليم التالية في الفئة الزمنية الثانية:

1.  جذور مع تدرج في جذر الكلمة
    *   في الغالب: المستوى العالي - المستوى المنخفض
    *   بعض الجذور: مستوى المد - المستوى المنخفض
2.  جذور بدون تدرج في جذر الكلمة
3.  جذور ثنائية المقطع تنتهي بـ -i/-ī مع تدرج في جذر الكلمة

:::

## 17.4. جذور صنف المضارع الثاني بدون تدرج في الجذر

::: grammar-box
بدون تدرج عشائري، جذور الفئة الثانية من الأزمنة تنتهي بـ -ā
:::
مثال:

⟪पा⟫ 2 P "يحمي، يحفظ، يرعى"

::: no-header

| 3\. pl. Präs. P | ⟪पान्ति⟫ (« pā- + -anti) |

:::

## 17.5. الجذور ثنائية المقطع التي تنتهي بـ -i/-ī مع تدرج الجذر

توجد جذور عديدة في سلسلة من الأشكال ثنائية المقطع، أي أنها تحتوي على -i (أو -ī قبل بعض النهايات) قبل النهاية الساكنة. ومع ذلك، يتم اعتبار هذه الجذور من قبل النحويين المحليين وفي القواميس وما إلى ذلك أحادية المقطع.

أمثلة:

⟪रुद्⟫ 2 P "يبكي، ينوح"

*   جذع المضارع القوي: rodi-
*   جذع المضارع الضعيف:
    *   قبل الساكن: rudi-
    *   قبل المتحرك: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 "يقول"

*   جذع المضارع القوي: bravī- (« bro- + -ī)
*   جذع المضارع الضعيف:
    *   vor Konsonant: brū-
    *   قبل الصوت: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
كما أن ⟪स्तु⟫ 2 "يُثْنِي" له، بالإضافة إلى الأشكال المذكورة في 3، أشكال تتبع هذا النمط:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::

## الدرس 17.7. تمرين 1

أ) أدخل الفعل في الجمل التالية وترجمها:

⟪१⟫. ⟪ब्राह्मणो⟫ ⟪ऽनृतं⟫ ⟪न⟫ ... (⟪ब्रू⟫ ⟪।⟫ ⟪वच्⟫ ⟪।⟫ ⟪वद्⟫)

ب) أضف الفاعل والفعل في الجمل المكونة في أ) إلى صيغة الجمع
