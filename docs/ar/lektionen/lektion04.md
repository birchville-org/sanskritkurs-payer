# الدرس 4

## 4.1. أسئلة الإكمال البسيطة (أسئلة الكلمات) والردود

### 4.1.1. ضمائر الاستفهام وضمائر الإشارة

#### 4.1.1.1. ضمائر الاستفهام (praśnārthakasarvanāma n. = ⟪⟪प्रश्नार्थकसर्वनामन्⟪⟪)

::: grammar-box
| | المجرّد المفرد | المجرّد الجمع |
| :--- | :--- | :--- |
| **المحايد** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **المذكر** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **المؤنث** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. الضمائر الدالة (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **القبائل** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"er, sie, es; der, die, das":br(Erwähnte)** | **etad = ⟪एतद्⟫:br"dieser, diese, dieses":br(dem Sprechenden sehr Nahe)** | **idam = ⟪इदम्⟫:br"dieser, diese, dieses":br(Nahe)** |
| **المرفوع المفرد** ||||
| **المحايد** | **tad = ⟪तद्⟩** | **etad = ⟪एतद्⟩** | **idam = ⟪इदम्⟩** |
| **المذكر** | **sa, so saḥ = ⟪स⟩ ⟪सो⟩ ⟪सः⟩** | **eṣa, eṣo, eṣaḥ = ⟪एष⟩ ⟪एषो⟩ ⟪एषः⟩** | **ayam = ⟪अयम्⟩** |
| **المؤنث** | **sā = ⟪सा⟩** | **eṣā = ⟪एषा⟩** | **iyam = ⟪इयम्⟩** |
| **المرفوع الجمع** ||||
| **المحايد** | **tāni = ⟪तानि⟩** | **etāni = ⟪एतानि⟩** | **imāni = ⟪इमानि⟩** |
| **المذكر** | **te = ⟪ते⟩** | **ete = ⟪एते⟩** | **ime = ⟪इमे⟩** |
| **المؤنث** | **tās = ⟪तास्⟩** | **etās = ⟪एतास्⟩** | **imās ⟪इमास्⟩** |
:::
**بالنسبة للمرفوع المفرد المذكر:**
- **sa, eṣa** (⟪स⟩ ⟪एष⟩) تأتي قبل جميع الأصوات ما عدا **-a** القصيرة
- **so, eṣo** (⟪सो⟩ ⟪एषो⟩) تأتي قبل **-a**، والتي تُحذف بالإبدال (تسقط)
- **saḥ, eṣaḥ** (⟪सः⟩ ⟪एषः⟩) تأتي فقط في الوقفة (نهاية الجملة، نهاية البيت الشعري)

لكي تتمكن من تكوين جمل باستخدام هذه الضمائر (sarvanāman n.)، يلزم معرفة قواعد الساندھا التالية:

### 4.1.2. ساندي لـ -m النهائية

::: grammar-box
**يُستبدل -m النطقية الساكنة قبل الحروف الساكنة بـ anusvāra (-ṃ). وفي نهاية الجملة أو البيت، وقبل الحروف المتحركة، يبقى -m كما هو.**
:::
### 4.1.3. ساندِها من -e النطقية الساكنة

::: grammar-box
1. **قبل a- يبقى -e كما هو: الهمزة الأولية a- تُحذف مع أغراها:**
   مثال: ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ "هؤلاء الآلهة"

2. **قبل حروف العلة الأخرى ما عدا أ- القصيرة، يُستبدل -e عادةً بـ -a مع حدوث هياستس. كما يحدث أيضًا الاستبدال بـ -ay:**
   مثال: ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (نادرًا: imay īśvarāh = ⟪इमयीश्वराः⟫) "هؤلاء الأسياد"
:::
### 4.1.4. ساندِها من -d في نهاية الكلمة

::: grammar-box
**يُستبدل الحرف -d في نهاية الكلمة في الوقفة، وكذلك قبل الحروف الغارية الصامتة (k, kh) والشفتية (p, ph) بالحرف -t.**

يتم مناقشة الاستبدال قبل الساكنات الأخرى لاحقًا. تجنب هذه الاصطدامات الصوتية مؤقتًا!
:::
### 4.1.5. صيغ الأسئلة

باستخدام هذه الضمائر، تُصاغ عبارات الاستفهام التالية على سبيل المثال:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **المفرد** | **المحايد** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं⟫ ⟪तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं⟫ ⟪किम्⟫, ⟪किमिदम्⟫ | "ما هذا؟" |
| ^^ | **المذكر** | sa kaḥ? / kaḥ saḥ?:br⟪स⟫ ⟪कः⟫, ⟪कः⟫ ⟪सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष⟫ ⟪कः⟫, ⟪क⟫ ⟪एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं⟫ ⟪कः⟫, ⟪को⟫ ⟪ऽयम्⟫ | "من هذا؟":br"من هو؟" |
| ^^ | **المؤنث** | sā kā? / kā sā?:br⟪सा⟫ ⟪का⟫, ⟪का⟫ ⟪सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा⟫ ⟪का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं⟫ ⟪का⟫, ⟪केयम्⟫ | "من هذا؟":br"من هي؟" |
| **الجمع** | **المحايد** | tāni kāni? / kāni tāni?:br⟪तानि⟫ ⟪कानि⟫, ⟪कानि⟫ ⟪तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि⟫ ⟪कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि⟫ ⟪कानि⟫, ⟪कानीमानि⟫ | |
| ^^ | **المذكر** | te ke? / ke te?:br⟪ते⟫ ⟪के⟫, ⟪के⟫ ⟪ते⟫:brete ke? / ka ete?:br⟪एते⟫ ⟪के⟫, ⟪क⟫ ⟪एते⟫:brime ke? / ka ime?:br⟪इमे⟫ ⟪के⟫, ⟪क⟫ ⟪इमे⟫ | |
| ^^ | **المؤنث** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः⟫ ⟪काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः⟫ ⟪काः⟫, ⟪का⟫ ⟪एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः⟫ ⟪काः⟫, ⟪का⟫ ⟪इमाः⟫ | |
:::
مثال آخر للأسئلة:

> viṣṇuḥ kaḥ? = ⟪विष्णुः⟫ ⟪कः⟫ الإجابة: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (يمكن في جملة الاسم وضع المفعول به في البداية مثلاً، للتأكيد على الارتباط بالسؤال.)

ملاحظة: الإجابات التي يمكنك تقديمها بناءً على معرفتك الحالية بالسنسكريتية لأسئلة من هذا القبيل، بالطبع، لا تزال لا تتوافق في جميع الجوانب مع السنسكريتية السليمة من حيث الاصطلاح.

## 4.2. تمرين

**أ) كوّنوا شفهيًا أسئلة حول الكلمات التالية وفق المخطط viṣṇuḥ kaḥ (⟪विष्णुः⟫ ⟪कः⟫) وأجبوا عن الأسئلة باللغة السنسكريتية:**

śruti، شيفا، براهمنا، ديجا (جمع)، إندراณี، دهنو، تولادهارا، كاليదاسا

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**ب) كوّنوا أسئلةً حول تمرين القراءة التالي وفقاً للنمط etat kim (⟪एतत्किम्⟫) وأجيبوا عن الأسئلة باستخدام الكلمات المحددة وأدوات الإشارة، على سبيل المثال: eṣa bālaḥ (⟪एष⟫ ⟪बालः⟫):**
