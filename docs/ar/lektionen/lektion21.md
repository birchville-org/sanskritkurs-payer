# الدرس 21

## 21.1. جذور المضارع الإضافية على -nt

### 21.1.1. اسم الفاعل المضارع (⟪लडादेशः⟫) باراسمايبادا

::: grammar-box
يُعدّ هذا الحال (Partizip) اشتقاقًا اسميًا من جذر المضارع، أي أنه حال حقيقي. وهو صفة تُشير إلى أن شخصًا أو شيئًا ما يقوم حاليًا بالفعل المُعبَّر عنه بواسطة جذر الفعل (+ حرف الجر)، بينما تحدث أحداث أخرى. كما يمكن التعبير عن حالة مستمرة باستخدامه.

**أمثلة:**

:::
::: indent
"بينما يقرأ الأب، يدخن = الأب القارئ يدخن"
"صديقٌ موجود (أي حقيقي، أصيل)"
:::
::: grammar-box

| **تكوين اسم الفاعل المضارع (باراسمايبادا) للأصول المضارعية الموضوعية:** |||
| :--- | :--- | :--- |
| **المذكر، المحايد** | | |
| | **الجذر القوي** | جذر المضارع + **-nt-** |
| | **الجذر الضعيف** | جذر المضارع + **-t-** |
| **المؤنث** | | |
| | | Präsensstamm + **-nt-** + **-ī** (Deklination wie **devī** :br⟪देवी⟫) |
| | **الفئة السادسة للمضارع** | جذر المضارع + **-nt-** + **-ī** :broder::brجذر المضارع + **-t-** + **-ī** |

:::

## 21.3. صيغ المجاملة في الخطاب

::: grammar-box
**يمكن في السنسكريتية مخاطبة شخص ما بصيغة المفرد الغائب الثاني دون وقاحة. ولكن إذا أردت أن تكون محترمًا، يمكنك استخدام اسم ذات دلالة "أيها الجليل" وما شابه، ووضع الفعل في صيغة الغائب المفرد أو الجمع، أو استخدام بناء المبني للمجهول. وتدرج الاحترام في استخدام الشخص عند النداء يكون على النحو التالي:**

:::
::: indent
**2. مفرد » 2. جمع » 3. مفرد مع اسم مناسب » 3. جمع مع اسم مناسب**
:::
**أهم اسم للتعظيم من هذا النوع هو ⟪भवन्त्⟫ ، مؤنث: ⟪भवती⟫ . وهو يقابل في استخدامه "أنتم" المحترمة لدينا.**
هذا **⟪भवन्त्⟫** هو اختصار من **⟪भगवन्त्⟫**، وتصريفه هو تصريف الأسماء المنتهية بـ **-vant** (انظر [الدرس 13](lektion13.md)). يجب التمييز بين هذا **⟪भवन्त्⟫** عن اسم الفاعل الماضي P من **⟪भू⟫** "يصبح" **⟪भवन्त्⟫** : مفرد مذكر من **⟪भवन्त्⟫** "أنتم" هو **⟪भवान्⟫**، ومفرد اسم الفاعل **⟪भवन्⟫**.

**أمثلة:**

::: indent
**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = "ماذا تفعل؟"
:::
بشكل أكثر لباقة:

::: indent
**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**
:::
المؤنث:

::: indent
**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**
:::
كلمات أخرى يمكن استخدامها بشكل مشابه لـ **⟪भवन्त्⟫**:

*   **⟪आर्य⟫** (مؤنث: **⟪आर्या⟫**) "نبيل". مثال: **⟪यदार्य⟫ ⟪इच्छति⟫** "ما تفضلتم به"
*   **⟪महाभाग⟫** "الذي حظّه / نصيبه كبير = نبيل". يُستخدم غالباً من قبل النساء في الخطاب أو عند التحدث عن الرجال من الطبقة الراقية. شائع جداً في السنسكريتية المحكية الحديثة.

إذا أردتَ التعبير ليس فقط عن الأدب، بل أيضاً عن التقدير لشخصٍ ما، فتُستخدم عند الحاضر أو القريب **⟪भवन्त्⟫** **⟪अत्रभवन्त्⟫**، وعند الغائب أو البعيد **⟪तत्रभवन्त्⟫**. ويمكن ترجمة **⟪अत्रभवन्त्⟫** و**⟪तत्रभवन्त्⟫** بـ "حضرتكم"، "فضيلتكم"، "مقامكم الرفيع"، وما إلى ذلك:

::: indent
**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = "هل الزوجة اللطيفة (الحاضرة هنا) هي زوجتك؟"
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (في رسالة خطية أو مكالمة هاتفية) = "كيف حالك؟"
:::
