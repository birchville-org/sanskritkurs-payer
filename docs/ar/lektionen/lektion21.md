# الدرس 21

## 21.1. جذوع المضارع الإضافية المنتهية بـ -nt

### 21.1.1. اسم الفاعل المضارع (⟪लडादेशः⟫) باراسمايبادا

::: grammar-box
هذا الاسم الفاعل هو اشتقاق اسمي من جذع المضارع، أي أنه اسم فاعل حقيقي. وهو صفة تشير إلى أن شخصاً أو شيئاً يقوم بالفعل المعبر عنه بجذر الفعل (+ البادئة) في الوقت الذي يحدث فيه شيء آخر. كما يمكن التعبير عن حالة مستمرة به أيضاً.

**أمثلة:**

:::
::: indent
"بينما يقرأ الأب، يدخن = يدخن الأب القارئ"  
"صديق حقيقي (= فعلي، أصيل)"
:::
::: grammar-box

| **تشكيل اسم الفاعل المضارع باراسمايبادا للجذوع الموضوعية للمضارع:** |||
| :--- | :--- | :--- |
| **المذكر، المحايد** | | |
| | **الجذر القوي** | جذع المضارع + **-nt-** |
| | **الجذر الضعيف** | جذع المضارع + **-t-** |
| **المؤنث** | | |
| | | جذع المضارع + **-nt-** + **-ī** (إعراب مثل **devī** :br⟪देवी⟫) |
| | **الفئة 6 من المضارع** | جذع المضارع + **-nt-** + **-ī** :broder::brجذع المضارع + **-t-** + **-ī** |

:::

## 21.3. صيحات المجاملة في الخطاب

::: grammar-box
**يمكنك في السنسكريتية، دون أن تكون غير لائق، مخاطبة شخص ما بصيغة المفرد الغائب الثاني. ولكن إذا أردت أن تكون محترماً، يمكنك استخدام اسم ذي معنى "أيها الكريم" وما شابه ذلك، ووضع الفعل في صيغة الغائب المفرد أو الجمع، أو استخدام بناء المبني للمجهول. وتدرج المجاملة في استخدام الشخص عند الخطاب يكون تقريباً كالتالي:**

:::
::: indent
**2. مفرد » 2. جمع » 3. مفرد مع اسم مناسب » 3. جمع مع اسم مناسب**
:::
**أهم هذه الأسماء المجاملة هو ⟪भवन्त्⟫ ، مؤنثه: ⟪भवती⟫ . وهو يقابل في استخدامه "أنتم" المحترمة لدينا.**
هذا ⟪भवन्त्⟫ هو اختصار من ⟪भगवन्त्⟫، وتصريفه هو تصريف الأسماء المنتهية بـ **-vant** (انظر [الدرس 13](lektion13.md)). يجب التمييز بين هذا ⟪भवन्त्⟫ وبين اسم الفاعل الماضي P من ⟪भू⟫ "يصبح" ⟪भवन्त्⟫ : المفرد المذكر من ⟪भवन्त्⟫ "أنتم" هو ⟪भवान्⟫، بينما اسم الفاعل ⟪भवन्⟫.

**أمثلة:**

::: indent
**⟪किं भवान्करोति⟫** = **⟪किं भवता क्रियते⟫** = "ماذا تفعل؟"
:::
بأدب:

::: indent
**⟪किं भवन्तः कुर्वन्ति⟫** = **⟪किं भवद्भिः क्रियते⟫**
:::
المؤنث:

::: indent
**⟪किं भवती करोति⟫** = **⟪किं भवत्या क्रियते⟫**  
**⟪किं भवत्यः कुर्वन्ति⟫** = **⟪किं भवतीभिः क्रियते⟫**
:::
كلمات أخرى يمكن استخدامها بشكل مشابه لـ ⟪भवन्त्⟫:

*   ⟪आर्य⟫ (مؤنث: ⟪आर्या⟫) "نبيل". على سبيل المثال، **⟪यदार्य इच्छति⟫** "ما تودونه"
*   ⟪महाभाग⟫ "الذي حظّه / نصيبه كبير = مرموق". تُستخدم غالباً من قبل النساء عند المخاطبة أو التحدث عن الرجال ذوي المكانة الرفيعة. شائعة جداً في السنسكريتية المحكية الحديثة.

إذا أردنا التعبير ليس فقط عن الأدب، بل أيضاً عن التقدير لشخص ما، نستخدم بدلاً من ⟪भवन्त् अत्रभवन्त्⟫ للشخص الحاضر أو القريب، و ⟪तत्रभवन्त्⟫ للشخص الغائب أو البعيد. يمكن ترجمة ⟪अत्रभवन्त्⟫ و ⟪तत्रभवन्त्⟫ إلى "أنتم"، "حضرتكم العظيمة"، "فضيلتكم" وما شابه:

::: indent
**⟪किमत्रभवत्यत्रभवतां भार्या⟫** = "هل السيدة الكريمة (الحاضرة هنا) هي زوجتك؟"  
**⟪किं तत्रभवतां कुशलवृत्तम्⟫** (في رسالة أو مكالمة هاتفية) = "هل أنتم بخير؟"
:::

⟪मृतं दहन्नग्निः सतीमपि दहति ॥१॥ सद्गुरुर्महाकविस्तोत्रैर्महादेवं स्तौति ॥२॥ महान्ति फलान्यदन्तो बाला जलमापि पिबन्ति ॥३॥ पूजां कुर्वञ्जनो यजते च स्तौति च देवताम् ॥४॥ गुरूपनीतनरो द्विजः ॥५॥⟫

⟪जितक्रोधो घ्नन्तमप्यरिं न द्वेष्टि । क्रोधजितस्तु द्वेष्टि ॥६॥⟫
