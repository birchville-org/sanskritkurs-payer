# الدرس 30

## 30.1. الفئة التاسعة من المضارع (⟪क्र्यादि⟫ = "⟪क्री⟫ وما إلى ذلك")

::: grammar-box
**التعليم:**

*   جذع قوي: جذر بصوت منخفض + -nā-

*   جذع ضعيف:

    *   قبل الساكن: جذر منخفض الدرجة + -nī-

    *   قبل الحرف المتحرك: جذر منخفض الدرجة + -n-
:::
مثال:

::: indent
⟪क्री⟫ 9U "يشتري"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **3. Person:brĀtmanepada** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
في هذه الفئة الزمنية، يجب الانتباه بشكل خاص إلى صياغة جذر المضارع للجذر ⟪ज्ञा⟫ 9U "يعرف، يعلم":

::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **3. Person:brĀtmanepada** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
الشكل ⟪जा⟫ الذي يستند إليه جذر المضارع من ⟪ज्ञा⟫، يمكن تفسيره إما من خلال سلسلة تبادلية -ā (المرحلة المنخفضة) -nā (المرحلة العالية)، أو من خلال التشتت من *jñā-nā-ti.

تختصر بعض الجذور ذات الصوت الطويل هذا الصوت قبل لاحقة جذر المضارع من الصف التاسع:

مثال:

::: indent
⟪पू⟫ 9U "ينظّف"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪पुनाति⟫:br(pu-nā-ti) | ⟪पुनन्ति⟫:br(pu-n-anti) |
| **3. Person:brĀtmanepada** | ⟪पुनीते⟫:br(pu-nī-te) | ⟪पुनते⟫:br(pu-n-ate) |

:::
تكوين اسم الفاعل المضارع في صيغة باراماسيبادا:

مثال:

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant) ؛ مؤنث: ⟪क्रीणती⟫ (krī + n + at + ī)
:::
## 30.2. استخدام صيغة التمني (⟪लिङ्⟫)

يُستخدم الصيغة التمنية:

::: grammar-box
**1. للتسمية**

*   **رغبة**
*   **رغبة**
*   **طلب**

**(هنا يتداخل الصيغة التمنية - ⟪लिङ्⟫ - مع الصيغة الأمرية - ⟪लोट्⟫)**
:::
مثال:

::: indent
⟪दासो⟫ ⟪ग्राममागच्छेत्⟫ = "ليكن العبد الراجع إلى القرية"
:::
::: grammar-box
**2. إذا كان شيء ما كـ**

*   **ممكن**
*   **محتمل**
*   **على الأرجح**

**يجب تمثيله.**
:::
مثال:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं⟫ ⟪न⟫ ⟪शृणुयात्⟫ = "لو خرج من القرية، لما سمع المعلم"
:::
::: grammar-box
**3. الجمل النسبية مع صيغة التمني قد تحمل أحياناً المعنى: "إذا كان شخص ما ..."**
:::
مثال:

::: indent
⟪यो⟫ ⟪नृतं⟫ ⟪वदेत्स⟫ ⟪नरकं⟫ ⟪पतेत्⟫ = "لو قال شخص كذبة، لوقع في الجحيم = إذا قال شخص كذبة، يقع في الجحيم"
:::
## 30.3. نهايات الشخص الثالث المفرد والجمع

يتمتع الصيغة التمنية (⟪लिङ्⟫)، والماضي المستمر (⟪लङ्⟫)، وأورست (⟪लुङ्⟫)، والبريكاتيف (⟪आशिर्लिङ्⟫)، والشروطي بـ ما يُعرف بالنهايات الثانوية:

::: grammar-box

| | 3. Person Singular | 3. Person Plural |
| :--- | :--- | :--- |
| **Parasmaipada** | **-t** | athematische Klassen: **-an** oder **-ur** :brOptativ: **-ur** |
| **Ātmanepada** | **-ta** | athematische Klassen: **-ata** (aus *nta):brOptativ: **-ran** |

:::

## 30.5. ساندي لـ -r النهائية

::: grammar-box
**باستثناء الكلمات المنتهية بـ -ar، تنطبق على الكلمات المنتهية بـ -r نفس قواعد الساندحي (الدمج الصوتي) التي تنطبق على الكلمات المنتهية بـ -s.**

**-ar قبل الأصوات الصامتة يبقى -ar، أما قبل r- فيسقط الـ -r ويحل محله -ā- بدلاً من -a-.**
:::
أمثلة:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
