# الدرس 26

## 26.1. قانون السيريالية لـ -s- في وسط الكلمة

::: grammar-box
يتم استبدال **-s-** بـ **-ṣ-**، إذا سبقها مباشرةً أو فقط بـ **⟪अनुस्वार⟫** أو **⟪विसर्ग⟫** الحروف **k, r, l** أو أحد **الحروف المتحركة** — باستثناء **a, ā** — وتليها صوت آخر غير **ṛ, r**.

يتبع هذا الساندي أيضًا **⟪दुस्⟫-** قبل الحروف الغارية والشفوية الصامتة في المركبات.
:::
*أمثلة:*
::: indent
**⟪तेषाम्⟫** (من: *te-sām*)

لكن: **⟪तासाम्⟫** (*tā-sām*)
:::
## 26.2. قانون الت cerebralisation لل dental في وسط الكلمة

::: grammar-box
تُستبدل الأصوات المقطعية السنية بأصواتها اللثوية المقعرة المقابلة (بما في ذلك **-ṣ-**) بعد الأصوات اللثوية المقعرة (بما في ذلك **-ṣ-**):

- **iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
  *(**ṣ** بسبب **i** السابق، **ṭh** بسبب **ṣ** الذي يسبقه)*
:::
## 26.3. وود ساندي للأصوات الحنكية والحنجرية وṣ وh + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

انظر الأمثلة أدناه
:::
## 26.4. قانون غراسمان للتشتت التنفسي

::: grammar-box
**نتيجة مباشرة لوجود اثنين من الحروف المنفجرة المشددة (مفجّر مشدّد - حرف علة - مفجّر مشدّد) هي فقدان التنفيس (الهمس) للحرف الأول:**

مثال:

:::
::: indent
*dhu(gh) » du(g)h
:::
**إذا فقد الصوت الثاني همسه بسبب قوانين الصوتيات، فإن الهمسة تعود إلى الصوت الأول.**

أمثلة: انظر أدناه المستقبل من  ⟪दुह्⟫ و  ⟪बुध्⟫

## 26.5. ساندهي الكلمات لـ -m، -n قبل الأصوات الزجزاجية

::: grammar-box
**قبل الحروف الساترة، يتم استبدال -n و -m بـ -ṃ-:**

مثال: انظر أدناه المستقبل من ⟪मन्⟫
:::
## 26.6. استخدام المستقبل البسيط (⟪ऌत्⟫، ⟪भविष्यन्ती⟫ م.)

::: grammar-box
**Das Einfache Futur (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) drückt aus:** <!-- TODO: Fallback translation -->

- **المستقبل**
- **فعل مقصود أو مرغوب فيه ("سأذهب"، "أريد أن أذهب")**

## الدرس 26.7. صياغة المستقبل البسيط (⟪ऌत्⟫، ⟪भविष्यन्ती⟫ مؤنث)

::: grammar-box
**المستقبل البسيط:**

:::
::: indent
**مضارع جذر + نهاية أساسية**
:::
::: grammar-box
**مضارع المستقبل:**

:::
::: indent
**(في الغالب) جذر في درجة عليا + -sya**  
**أو**  
**(في الغالب) جذر في درجة عليا + -i- + -sya (= - iṣya)**
:::
**يجب تعلم أي جذر له أي صيغة من صيغ جذر المستقبل مع الأشكال الجذرية!**  
**بشكل عام، تتطابق صيغة الجذر وحرف الربط للمستقبل مع المصدر.**  
**بعض الجذور يمكنها تكوين المستقبل اختياريًا مع وبدون حرف الربط -i-.**  
**يتم تشكيل اسم الفاعل للماضي البعيد (Parasmaipada) بإضافة اللاحقة -nt- إلى جذر المستقبل، والمؤنث اختياريًا على -ntī أو -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
أمثلة:
