# الدرس 26

## 26.1. قانون التcerebralization لـ -s- في وسط الكلمة

::: grammar-box
يُستبدل **-s-** بـ **-ṣ-** إذا سبقه مباشرة أو فقط بفصل ⟪अनुस्वार⟫ أو ⟪विसर्ग⟫ **k, r, l** أو **حرف متحرك** — باستثناء **a, ā** — وتليها صوت آخر غير **ṛ, r**.

يتبع هذا التساندي أيضاً **⟪दुस्⟫-** قبل الحروف الغارية والشفوية الصامتة في التراكيب المركبة.
:::
*أمثلة:*
::: indent
⟪तेषाम्⟫ (من: *te-sām*)

لكن: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. قانون التcerebralization للدنتالات في وسط الكلمة

::: grammar-box
تستبدل أصوات الإغلاق الدنتالية بعد الأصوات الرجعية (بما في ذلك **-ṣ-**) بالأصوات الرجعية المقابلة:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** بسبب **i** السابق، و**ṭh** بسبب **ṣ** الذي يليها)*
:::
## 26.3. تساندي الكلمة للباديات، الغارية، ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

انظر الأمثلة أدناه
:::
## 26.4. قانون تمييز الهاء لغراسمان

::: grammar-box
**نتيجة مباشرة لتتابع متحركين مشبعين بالهواء (متحرك - حرف متحرك - متحرك) هي فقدان الهاء في الصوت الأول:**

مثال:

:::
::: indent
\*dhu(gh) » du(g)h
:::
**إذا فقد الصوت الثاني هاءه بسبب قوانين صوتية، فإن الهاء تعود إلى الظهور في الصوت الأول.**

أمثلة: انظر أدناه المستقبل من  ⟪दुह्⟫ و  ⟪बुध्⟫

## 26.5. واندحي الكلمات: -m، -n قبل الأصوات الزمرية

::: grammar-box
**تُستبدل -n و-m بـ-ṃ- قبل الأصوات الزمرية:**

مثال: انظر أدناه المستقبل من ⟪मन्⟫
:::
## 26.6. استخدام المستقبل البسيط (⟪ऌत्⟫، ⟪भविष्यन्ती⟫ مؤنث)

::: grammar-box
**يعبر المستقبل البسيط (⟪ऌत्⟫، ⟪भविष्यन्ती⟫ مؤنث) عن:**

**المستقبل**
**فعل مقصود أو مرغوب فيه ("سأذهب"، "أريد أن أذهب")**
**توقع ("سيحدث هذا على هذا النحو")**
**الأمل**
**الخوف**
**الاحتمالية**
**رأي المتكلم**
**الأمر**

**يأتي المستقبل أحياناً في منافسة مع التمني (انظر لاحقاً).**
:::
على سبيل المثال، ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = "الشخص الذي يرغب في أخذ نذر، يذهب إلى المعبد."

## 26.7. تكوين المستقبل البسيط (⟪ऌत्⟫، ⟪भविष्यन्ती⟫ مؤنث)

::: grammar-box
**المستقبل البسيط:**

:::
::: indent
**ساق المستقبل + النهايات الأولية**
:::
::: grammar-box
**ساق المستقبل:**

:::
::: indent
**(في الغالب) جذر في درجة عالية + -sya**  
**أو**  
**(في الغالب) جذر في درجة عالية + -i- + -sya (= - iṣya)**
:::
**يجب تعلم أي جذر له أي تكوين لساق المستقبل مع الأشكال الجذرية!**  
**بشكل عام، يتطابق شكل الجذر وحرف الربط للمستقبل مع المصدر.**  
**بعض الجذور يمكن أن تكون المستقبل اختيارياً بحرف ربط -i- أو بدونه.**  
**يُكوّن اسم الفاعل للماضي البسيط بإضافة اللاحقة -nt- إلى ساق المستقبل، والمؤنث اختياري على -ntī أو -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫، ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
أمثلة:

::: grammar-box

| الجذر | المستقبل 3. مفرد مذكر (Ā) |
| :--- | :--- |
| ⟪नी⟫ | ⟪नेष्यति⟫ |
| ⟪भू⟫ | ⟪भविष्यति⟫ (⟪भो⟫ +  ⟪इ⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दिश्⟫ | ⟪देक्ष्यति⟫ (⟪देश्⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दृश्⟫ | ⟪द्रक्ष्यति⟫ |
| ⟪पच्⟫ | ⟪पक्ष्यति⟫ |
| ⟪प्रच्छ्⟫ | ⟪प्रक्ष्यति⟫ |
| ⟪यज्⟫ | ⟪यक्ष्यति⟫ |
| ⟪सृज्⟫ | ⟪स्रक्ष्यति⟫ |
| ⟪पद्⟫ | ⟪पत्स्यति⟫ |
| ⟪अद्⟫ | ⟪अत्स्यति⟫ |
| ⟪दुह्⟫ | ⟪धोक्ष्यति⟫ (⟪दोग्⟫ +  ⟪स्य⟫ + ⟪ति⟫) |
| ⟪बुध्⟫ | ⟪भोत्स्यते⟫ (⟪बोध्⟫ قبل الصوت الصامت = ⟪भोत्⟫) |
| ⟪मन्⟫ | ⟪मंस्यते⟫ (⟪मन्⟫ + ⟪स्य⟫ + ⟪ते⟫) |

:::
