# الدرس 14

ترجم الأمثال التالية واحفظها عن ظهر قلب:

⟪निचो⟫ ⟪वदति⟫ ⟪न⟫ ⟪कुरुते⟫  
⟪वदति⟫ ⟪न⟫ ⟪साधुः⟫ ⟪करोत्येव⟫ ⟪॥१॥⟫  
يتكلم الشخص الدنيء ويتصرف، أما الشخص الصالح فلا يتكلم بل يتصرف.

⟪शीलं⟫ ⟪नरस्य⟫ ⟪भूषणम्⟫ ⟪॥२॥⟫  
الفضيلة هي زينة الإنسان.

⟪सत्येन⟫ ⟪जनानां⟫ ⟪सुखं⟫ ⟪भवति⟫ ⟪॥३॥⟫  
بالصدق يصبح الناس سعداء.

⟪पापा⟫ ⟪नराः⟫ ⟪स्वर्गं⟫ ⟪न⟫ ⟪लभन्ते⟫ ⟪॥४॥⟫  
لا يدخل الناس الأشرار إلى السماء.

⟪सत्यं⟫ ⟪लोकस्य⟫ ⟪दीपः⟫ ⟪॥५॥⟫  
الحقيقة هي نور العالم.

أ) كوّن حالة المضاف إليه المفرد والمثنى للكلمات التالية. أعطِ المعنى والجنس النحوي للكلمات:

⟪१⟩. ⟪अनृत⟩ : n. كذب — ⟪अनृतस्य⟩ ⟪अनृतानाम्⟩

⟪२⟩. ⟪ऋषि⟩ : m. حكيم فيديا — ⟪ऋषेः⟩ ⟪ऋषीणाम्⟩

⟪३⟩. ⟪पाद⟩ : m. قدم — ⟪पादस्य⟩ ⟪पादानाम्⟩

⟪४⟩. ⟪बुद्धि⟩ : f. معرفة — ⟪बुद्धेः⟩ (⟪बुद्ध्याः⟩) ⟪बुद्धीनाम्⟩

⟪५⟩. ⟪गुरु⟩ : m. معلم — ⟪गुरोः⟩ ⟪गुरूणाम्⟩

⟪६⟩. ⟪स्वर्ग⟩ : m. سماء — ⟪स्वर्गस्य⟩ ⟪स्वर्गाणाम्⟩

⟪७⟩. ⟪नगर⟩ : n. مدينة — ⟪नगरस्य⟩ ⟪नगराणाम्⟩

⟪८⟩. ⟪धेनु⟩ : f. بقرة — ⟪धेनोः⟩ (⟪धेन्वाः⟩) ⟪धेनूनाम्⟩

⟪९⟩. ⟪द्विज⟩ : m. مرتين المولود — ⟪द्विजस्य⟩ ⟪द्विजानाम्⟩

⟪१०⟩. ⟪मुक्ता⟩ : f. المنقذة — ⟪मुक्तायाः⟩ ⟪मुक्तानाम्⟩

⟪११⟩. ⟪विद्या⟩ : f. معرفة، علم — ⟪विद्यायाः⟩ ⟪विद्यानाम्⟩

⟪१२⟩. ⟪वर्ण⟩ : m. طبقة اجتماعية — ⟪वर्णस्य⟩ ⟪वर्णानाम्⟩

⟪१३⟩. ⟪द्विजाति⟩ : 3 مرتين المولود — ⟪द्विजातेः⟩ (⟪द्विजात्याः⟩) ⟪द्विजातीनाम्⟩

⟪१४⟩. ⟪रूप⟩ : n. شكل — ⟪रूपस्य⟩ ⟪रूपाणाम्⟩

⟪१५⟩. ⟪प्रतिग्रह⟩ : m. استقبال — ⟪प्रतिग्रहस्य⟩ ⟪प्रतिग्रहाणाम्⟩

⟪१६⟩. ⟪सोढ⟩ : 3 يتحمل — ⟪सोढस्य⟩ ⟪सोढायाः⟩ ⟪सोढानाम्⟩

⟪१७⟩. ⟪नायिका⟩ : f. حبيبة — ⟪नायिकायाः⟩ ⟪नयिकानाम्⟩

⟪१८⟩. ⟪साध्वी⟩ : f. مقدسة — ⟪साध्व्याः⟩ ⟪साध्वीनाम्⟩

⟪१९⟩. ⟪अग्नि⟩ : m. نار — ⟪अग्नेः⟩ ⟪अग्नीनाम्⟩

⟪२०⟩. ⟪वैश्या⟩ : f. امرأة فيشيا — ⟪वैश्यायाः⟩ ⟪वैश्यानाम्⟩

⟪२१⟩. ⟪लोक⟩ : m. عالم، ناس — ⟪लोकस्य⟩ ⟪लोकानाम्⟩

⟪२२⟩. ⟪उक्ति⟩ : f. قول — ⟪उक्तेः⟩ (⟪उक्त्याः⟩) ⟪उक्तीनाम्⟩

⟪२३⟩. ⟪शत्रु⟩ : m. عدو — ⟪शत्रोः⟩ ⟪शत्रूणाम्⟩

⟪२४⟩. ⟪सुखवन्त्⟩ : 3 سعيد — ⟪सुखवतः⟩ (⟪सुखवत्याः⟩) ⟪सुखवताम्⟩ (⟪सुखवतीनाम्⟩)

⟪२५⟩. ⟪पुत्रवती⟩ : f. امرأة لديها ابن واحد أو أكثر — ⟪पुत्रवत्याः⟩ ⟪पुत्रवतीनाम्⟩

⟪२६⟩. ⟪जल⟩ : n. ماء — ⟪जलस्य⟩ ⟪जलानाम्⟩

⟪२७⟩. ⟪मार्ग⟩ : m. طريق — ⟪मर्गस्य⟩ ⟪मर्गाणाम्⟩

⟪२८⟩. ⟪मोक्ष⟩ : m. تحرير، خلاص — ⟪मोक्षस्य⟩ ⟪मोक्षाणाम्⟩

⟪२९⟩. ⟪शूद्रा⟩ : f. امرأة شودرا — ⟪शूद्रायाः⟩ ⟪शूद्राणाम्⟩

⟪३०⟩. ⟪अन्न⟩ : n. طعام، أكل — ⟪अन्नस्य⟩ ⟪अन्नानाम्⟩

⟪३१⟩. ⟪साधु⟩ : m. مقدس — ⟪साधोः⟩ ⟪साधनाम्⟩

⟪३२⟩. ⟪नीति⟩ : f. قيادة — ⟪नीत्याः⟩ ⟪नीतीनाम्⟩

⟪३३⟩. ⟪योध⟩ : m. محارب، جندي — ⟪योधस्य⟩ ⟪योधानाम्⟩

⟪३४⟩. ⟪सत्यवन्त्⟩ : 3 صادق — ⟪सत्यवतः⟩ (⟪सत्यवत्याः⟩) ⟪सत्यवताम्⟩ (⟪सत्यवतीनाम्⟩)

⟪३५⟩. ⟪लाभ⟩ : m. ربح — ⟪लाभस्य⟩ ⟪लाभानाम्⟩

⟪३६⟩. ⟪मोह⟩ : m. ارتباك، جهل — ⟪मोहस्य⟩ ⟪मोहानाम्⟩

⟪३७⟩. ⟪गति⟩ : f. مشي، هدف — ⟪गतेः⟩ (⟪गत्याः⟩) ⟪गतीनाम्⟩

⟪३८⟩. ⟪प्रश्न⟩ : m. سؤال — ⟪प्रश्नस्य⟩ ⟪प्रश्नानाम्⟩

⟪३९⟩. ⟪सृष्टि⟩ : f. خلق — ⟪सृष्तेः⟩ (⟪सृष्ट्याः⟩) ⟪सृष्टीनाम्⟩

⟪४०⟫. ⟪नेत्र⟫ : n. العين — ⟪नेत्रस्य⟫ ⟪नेत्राणाम्⟫

⟪४१⟫. ⟪गुरुता⟫ : f. المهارة — ⟪गुरुतायाः⟫ ⟪गुरुतानाम्⟫

⟪४२⟫. ⟪ईश्वर⟫ : m. السيد — ⟪ईश्वरस्य⟫ ⟪ईश्वराणाम्⟫

⟪४३⟫. ⟪कारण⟫ : n. السبب — ⟪कारणस्य⟫ ⟪कारणानाम्⟫

⟪४४⟫. ⟪कृत⟫ : 3 فعل — ⟪कृतस्य⟫ (⟪कृतायाः⟫) ⟪कृतानाम्⟫

⟪४५⟫. ⟪धर्मवन्त्⟫ : 3 عادل، ديني — ⟪धर्मवतः⟫ (⟪धर्मवत्याः⟫) ⟪धर्मवताम्⟫ (⟪धर्मवतीनाम्⟫)

⟪४६⟫. ⟪युद्ध⟫ : 3 حارب — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम्⟫

⟪४७⟫. ⟪दर्शन⟫ : n. رؤية، ظهور — ⟪दर्शनस्य⟫ ⟪दर्शनानाम्⟫

⟪४८⟫. ⟪धातु⟫ : m. عنصر، جذر فعلي — ⟪धातोः⟫ ⟪धातूनाम्⟫

⟪४९⟫. ⟪गूढा⟫ : f. واحدة مختفية — ⟪गूढायाः⟫ ⟪गूढानाम्⟫

⟪५०⟫. ⟪ईष्टा⟫ (معنيان): f. واحدة مرغوبة، واحدة مقدّمة — ⟪इष्टायाः⟫ ⟪इष्टानाम्⟫

⟪५१⟫. ⟪उदित⟫ : 3 قال — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम्⟫

⟪५२⟫. ⟪इदम्⟫ : 3 هذا — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 ماذا — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

ب) ترجموا:

⟪१⟫. ⟪ब्राह्मणस्य⟫ ⟪पुत्रो⟫ ⟪ब्राह्मण्या⟫ ⟪ग्रामं⟫ ⟪गतः⟫ ⟪।⟫ (طريقتان)
ذهب ابن البراهمة إلى قرية البراهمة. ذهب ابن البراهمة مع البراهمة إلى القرية.

⟪२⟫. ⟪यज्ञस्याग्निनान्नं⟫ ⟪दग्धम्⟫ ⟪।⟫
أحرق نار القرابين الطعام.

⟪३⟫. ⟪बुद्धः⟫ ⟪स्तयस्य⟫ ⟪बुद्ध्या⟫ ⟪मुक्तः⟫ ⟪।⟫
تم خلاص بوذا من خلال إدراك الحقيقة.

⟪४⟫. ⟪अधर्मो⟫ ⟪ऽनृतस्य⟫ ⟪वदनमित्यृषयो⟫ ⟪वदन्ति⟫ ⟪।⟫
يقول الحكماء الفيدية أن قول الكذب هو ظلم.

⟪५⟫. ⟪नरा⟫ ⟪देवानां⟫ ⟪यज्ञैर्न⟫ ⟪मुच्यन्ते⟫ ⟪।⟫
لا يُخلّص الناس من خلال القرابين للآلهة.

⟪६⟫. ⟪बलवन्तः⟫ ⟪क्षत्रियाः⟫ ⟪शत्रूणां⟫ ⟪धनवन्ति⟫ ⟪नगराणि⟫ ⟪जयन्ति⟫ ⟪।⟫
يغزو الكشترية الأقوياء مدن الأعداء الغنية.

⟪७⟫. ⟪कवेरुक्तिं⟫ ⟪शृण्वन्ति⟫ ⟪।⟫
هم يسمعون قول الشاعر.

⟪८⟫. ⟪कविर्देव्याः⟫ ⟪कृतं⟫ ⟪वद⟫ti ⟪।⟫
يبلغ الشاعر عن فعل الإلهة.

⟪९⟫. ⟪द्विजाः⟫ ⟪पशोर्लाभमिच्छन्ति⟫ ⟪।⟫
يرغب المولودان مرتين في الحصول على الماشية.

⟪१०⟫. ⟪रामः⟫ ⟪पुण्यवतो⟫ ⟪गुरोर्मन्त्रस्य⟫ ⟪स्मरति⟫ ⟪।⟫
يتذكر راما مانترا المعلم الصالح.

⟪११⟫. ⟪अयं⟫ ⟪बालः⟫ ⟪कस्याः⟫ ⟪पुत्रः⟫ ⟪।⟫
ابن من (م.) هو هذا الفتى؟

⟪१२⟫. ⟪केषामिमानि⟫ ⟪गृहाणि⟫ ⟪।⟫
لمن تنتمي هذه المنازل؟

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम्⟫ ⟪।⟫
أي طعام قدّم هذا الحكيم الفيدي كقرابين؟
