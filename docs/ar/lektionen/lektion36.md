## 36.2. المضي التقريري (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
يُستخدم الفعل التام الدائري (⟪अनुप्रयोगलिट्⟫):

1. في التصريفات المشتقة (السببية، والرغبية، والتكرارية، والمشتقة من الأسماء)
2. في الجذور التي تبدأ بحرف متحرك طويل (باستثناء ā-)، أو بحرف متحرك (باستثناء a-) يسبقه ساكنان
3. في بعض الجذور الأخرى
:::
::: grammar-box
**التعليم:**

(ضعيف) جذر المضارع + -ām + الصيغة المقابلة من التصريف التام لـ ⟪कृ⟫، ⟪अस्⟫ أو ⟪भू⟫

- Auslautender Stammvokal wird vor -ām guṇiert.
- ⟪अस्⟫ و ⟪भू⟫ تُصرف أيضًا مع أفعال آتمانيبادا في صيغة باراسمايبادا.
:::
Das periphrastische Perfekt ist wohl aus dem Akkusativ eine Verbalnomens auf -ā entstanden. Dieser Akkusativ wird -- wie auch sonst oft -- adverbial verwendet.

أمثلة:

| Wurzel:br⟪धातु⟫ | 3. م. مف. ماض. بن. | 3. ج. مف. ماض. بن. | 3. م. مف. ماض. بن. | 3. ج. مف. ماض. بن. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪ईक्ष्⟫ 1Ā | | | **⟪ईक्षां⟫ ⟪चक्रे⟫** :br ⟪ईक्षामास⟫ :br **⟪ईक्षां⟫ ⟪बभूव⟫** | **⟪ईक्षां⟫ ⟪चक्रिरे⟫** :br ⟪ईक्षामासुर्⟫ :br **⟪ईक्षां⟫ ⟪बभूवुर्⟫** |
| ⟪बन्ध्⟫ :brKausativ: ⟪बन्धय⟫-:br"binden lassen" | **⟪बन्धयां⟫ ⟪चकार⟫** :br ⟪बन्धयामास⟫ :br **⟪बन्धयां⟫ ⟪बभूव⟫** | **⟪बन्धयां⟫ ⟪चक्रुर्⟫** :br ⟪बन्धयामासुर्⟫ :br **⟪बन्धयां⟫ ⟪बभूवुर्⟫** | | |

## 36.3. ماضي مبني للمجهول

::: grammar-box
في صيغة الماضي التام، تُستخدم تصاريح الفعل الذاتي للمبني للمجهول. ومع ذلك، يُفضل استخدام اسم المفعول (PPP). يكون التكوين في كلتا الحالتين هو جمل المبني للمجهول:

:::
::: indent
⟪तेन⟫ ⟪पुण्यं⟫ ⟪चक्रे⟫ = ⟪तेन⟫ ⟪पुण्यं⟫ ⟪कृतम्⟫ = "لقد قام بعملٍ ذي فضيلة"
:::
