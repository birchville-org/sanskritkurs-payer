# Lektion 31

## 31.1. वर्तमानस्य सप्तमः वर्गः (⟪रुधादि⟫ = "⟪रुध्⟫ इत्यादि")

::: grammar-box
**التعليم:**

**قبل الأحرف الساكنة النهائية للجذر ذي الدرجة المنخفضة، يُدخل ما يُسمى بـ "الناصين الثابت" (-na- أو -n-):**

*   **في الجذر القوي: -na-**
*   **في الجذر الضعيف: -n-**

**تنطبق نفس القواعد على ربط الحروف الساكنة النهائية للجذر مع النهايات التي تبدأ بحرف ساكن، كما هو الحال مع فئة التصريف الحالية الثانية.**
:::
أمثلة:

⟪युज्⟫ 7U "يُوصِل، يُرْهِن"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. sg.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(vor Guttural im Wortinnern werden Nasale durch -ṅ- ersetzt) |
| | **3. pl.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Optativ** | **3. sg.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. pl.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Partizip Präsens** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brfem.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "يُوقِفُ، يُبْطِئُ"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. sg.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. pl.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Optativ** | **3. sg.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. pl.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Partizip Präsens** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brfem.: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**في بعض الجذور، اختراق حرف -n- من جذر المضارع الضعيف إلى الأزمنة غير المضارعية، مما يجعل هذه الجذور تُكتب مع إضافة نون.**
:::
مثال:

**⟪भञ्ज्⟫** 7P "ينكسر"

::: indent
*   صيغة المخاطب المضارع
    *   المفرد الغائب **⟪भनक्ति⟫** (bha-na + j + ti)
    *   الجمع الغائب **⟪भञ्जन्ति⟫** (bha + n + j-anti)
*   المستقبل: **⟪भङ्क्ष्यति⟫** (bha + n + j + sya + ti)
*   المبني للمجهول: **⟪भज्यते⟫** (إما من الجذر الأصلي **⟪भज्⟫** أو من *bhñj-ya-te)
*   اسم المفعول الماضي: **⟪भग्न⟫** (ربما من *bhñj + na)
:::
## 31.2. قائمة الكلمات

**⟪युज्⟫** 7U **⟪युनक्ति⟫** : يَجْهَزُ، يُحَمِّلُ، يَرْبِطُ، يُثَبِّتُ؛ Ā أيضاً: يَجْتَهِدُ (= يُبْذِلُ الجُهْدَ)، يَتَّصِلُ بِـ، يَرْكُزُ عَلَى (باللوكاتيف، ⟪सप्तमी⟫)
::: indent
**المستقبل: ⟪योक्ष्यति⟫**
**المبني للمجهول: ⟪युज्यते⟫**
**السببي: ⟪योजयति⟫**
**اسم المفعول الماضي: ⟪युक्त⟫**
**المصدر: ⟪योक्तुम्⟫**

من ذلك:
**⟪युग⟫ م. → ⟪युग⟫ م.:** عهدة، زوج، عصر عالمي (هناك أربعة عصور عالمية:
1. ⟪कृत⟫
2. ⟪त्रेता⟫
3. ⟪द्वापर⟫
4. ⟪कलि⟫

بدأ **⟪कलियुग⟫** حوالي عام 3102 قبل الميلاد، وهو عام حرب **⟪महाभारत⟫**. مزيد من التفاصيل لدى باشام، العجيب ص 323)

**⟪योग⟫ م.:** "التوصيل، الشد"، الجهد، الاتصال، اليوغا (انظر باشم، العجيب ص 327 وما بعدها)
