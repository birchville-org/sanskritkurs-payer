## 41.2. تكوينات ⟪कृत्⟫ إضافية تنتهي بـ -a

### 41.2.1. اسم الفاعل المضارع (⟪लडादेशः⟫) Ā، اسم الفاعل المضارع (⟪लडादेशः⟫) المبني للمجهول، اسم الفاعل المستقبل (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. جذوع المضارع الموضوعي، المبني للمجهول والمستقبل

::: grammar-box
**التعليم:**

جذر المضارع / جذر المبني للمجهول / جذر المستقبل + -māna (مؤنث: mānā)
:::
أمثلة:

⟪यज्⟫ 1U، Part.Präs.Ā ⟪यजमान⟫ 3 "شخص يُكرَّم بذبيحة لمصلحته الخاصة = رب الذبيحة"

⟪मन्⟫ 4Ā، صيغة المضارع التام للفاعل ⟨⟪मन्यमान⟫ 3 "واحد يفكر"

⟪कृ⟫ 8U، صيغة الفعل المضارع المبني للمجهول ⟨⟪क्रियमाण⟫ 3 "شيء يُفعل"

⟪दा⟫ 3U، صيغة المستقبل للفاعل ⟨�दास्यमान⟫ 3 "شخص سيعطي لمصلحته الخاصة"

#### 41.2.1.2. فئات الحاضر غير الأوزانية

::: grammar-box
**التعليم:**

جذر المضارع الضعيف (بالصيغة التي تسبق النهاية -ate للجمع الثالث المفرد ā) + -āna (مؤنث -ānā)
:::
أمثلة:

::: grammar-box
| الجذر / الصنف | اسم الفاعل المضارع Ā |
| :--- | :--- |
| **⟪द्विष्⟫** 2U | ⟪द्विषाण⟫ |
| **⟪हु⟫** 3P | \<⟪जुह्वान⟫\>:brju-hu + āna |
| **⟪सु⟫** 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| **⟪रुध्⟫** 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| **⟪तन्⟫** 8U | ⟪तन्वान⟫:brtan-u + āna |
| **⟪क्री⟫** 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "اسم الفاعل" الخاص بالضرورة السلبية (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**للتعبير عن الضرورة السلبية ("ما يجب فعله/أن يُفعل")، يمكن تشكيل الصفات المشتقة من الجذور والأصول الفعلية المشتقة إما باستخدام اللاحقات التالية:**

* **-⟪तव्य⟫** (مؤنث **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (مؤنث **-⟪अनीया⟫**)
* **-⟪य⟫** (مؤنث **-⟪या⟫**)
* **-⟪त्य⟫** (مؤنث **-⟪त्या⟫**) (بدلاً من **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. اللاحقة -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Das Suffix -⟪तव्य⟫ / -⟪तव्या⟫ wird an Wurzeln und abgeleitete Verbalstämme (z.B. Kausativ) auf dieselbe Weise angefügt wie das Infinitivsuffix -⟪तुम्⟫ (s. [Lektion 23](lektion23.md)), d.h.**

* **جذر عالي المستوى + ⟪तव्य⟫**

أو

* **جذر عالي الدرجة + -i- + ⟪तव्य⟫**

**في السببية:**

* **صيغ السببية على -ay + -i- + ⟪तव्य⟫**
:::
أمثلة:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "jemand, der besiegt werden muss; ein zu besiegender" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "das, wo man sich befinden soll" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "jemand, der geweckt werden soll; ein zu erweckender" |

:::
#### 41.2.2.2. اللاحقة -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**التعليم:**

جذر عالي الدرجة + -⟪अनीय⟫ / -⟪अनीया⟫

**السببي وفئة الأفعال العاشرة:**

الجذر، كما يظهر في صيغة السببية، بدون -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
أمثلة:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "zu gebendes; was gegeben werden muss" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "zu besiegender" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "zu tuendes" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "was man sehen muss; sehenswertes" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "ein zu weckender" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "was man geben lassen muss" |

:::
#### 41.2.2.3. اللاحقة -⟪य⟫ / -⟪या⟫

::: grammar-box
**التكوين:**

جذر (في درجة العمق، أو الارتفاع، أو الشد) + -⟪य⟫

انظر القواعد الدقيقة في كيلهورن، قواعد اللغة السنسكريتية، ص. 195 - 197!
:::
معالجة الحروف المتحركة في نهاية الكلمة:

::: grammar-box
**1. الجذور المنتهية بـ -ā تشكل هذا الاسم المفعولي على -eya**
:::
أمثلة:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "ما يجب معرفته؛ ما لا بد من إدراكه" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "ما لا بد من تقديمه" |

:::
::: grammar-box
**2. الجذور المنتهية بـ -i /-ī / -u / -ū /-ṛ لها عادة درجة الارتفاع أو الشد، إلا إذا كانت من تلك الجذور المنتهية بـ -i / -u /-ṛ التي تشكل اسماً مفعولياً باللاحقة -⟪त्य⟫ (مؤنث: -⟪त्या⟫) (قائمة هذه الجذور في كيلهورن، القواعد §537).**
:::
مثال:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 | "ما لا بد من تذكره" |

:::
::: grammar-box
**2a. الجذور المنتهية بـ -i/-ī لها درجة الارتفاع**
:::
أمثلة:

::: no-header

| | | |
| :--- | :--- | :--- |

| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "ما لا بد من قيادته" |

:::

#### 41.2.2.4. اللاحقة -⟪त्य⟫ / ⟪त्या⟫ (بدلاً من -⟪य⟫ / -⟪या⟫)

::: grammar-box
قائمة الجذور المنتهية بـ -i / -u / -ṛ، التي تُشكّل اسم المفعول (Gerundivum) بدلاً من -⟪य⟫ / -⟪या⟫ باستخدام اللاحقة -⟪त्य⟫ (المؤنث -⟪त्या⟫)، لدى كيلهورن، النحو §537.

**التعليم:**

جذر عميق المستوى + -⟪त्य⟫ / -⟪त्या⟫
:::
أمثلة:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "zu gehender" |
| ⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "zu hörender" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "zu tuender" |

:::

### 41.2.4. الفروق في استخدام لاحقات الفعل المنصوب

::: grammar-box
تتطابق إلى حد كبير استخدام هذه الملحق

* **-⟪तव्य⟫ (مؤنث -⟪तव्या⟫):** تعبر دائماً عن الضرورة، ويُستعمل تفضيلاً في وظيفة الخبر (وبشكل أقل في وظيفة الصفة). لا ينبغي استخدام المشتقات بهذا اللاحقة في التركيبات الاسمية المركبة.
* **-⟪अनीय⟫ (مؤنث -⟪अनीया⟫) و -⟪य⟫ (مؤنث -⟪या⟫) / -⟪त्य⟫ (مؤنث -⟪त्या⟫) (بدلاً من -⟪य⟫/-⟪या⟫):** يمكن أن تحمل معنى إضافياً (خاصة -⟪य⟫) بمعنى الألمانية "-wert" (مثل "sehenswert" أي "جدير بالملاحظة") أو مجرد إمكانية "-bar" (⟪दृश्य⟫ "sichtbar" أي "مرئي"). يمكن نفي المشتقات بهذه اللاحقات باستخدام ⟪अ⟫/-⟪अन्⟫- (ولكن لا يمكن نفي المشتقات بـ -⟪तव्य⟫)، وهناك ⟪तत्पुरुष⟫ كعنصر خلفي لها تظهر فيه.
:::
### 41.2.5. لا يوجد ارتباط مع ⟪सु⟫- و ⟪दुस्⟫-

::: grammar-box
لا يجوز ربط الصفات الفعلية (Gerundive) بـ ⟪सु⟫ و ⟪दुस्⟫ بمعنى "خفيف" أو "ثقيل". وبدلاً من ذلك، تظهر ⟪तत्पुरुष⟫ من نوع ⟪सुकर⟫ 3 ("سهل التنفيذ") (انظر [الدرس 18](lektion18.md)).
:::

## الدرس 41.4. تمرين

A) اترجم الأمثال الشائعة في بداية الدرس.
