اللذين مرتبطان ببعضهما البعض بقوة
مثل الكلمة والمعنى للفهم
معنى الكلمة.

### 1.2.1. حول نطق الأصوات الفردية

::: laut-table
| الصوت | الوصف |
| :--- | :--- |
| **a - ⟪अ⟫** | يُنطق "أ قصيرة" لدى الهنود -- منذ زمن بعيد -- غالباً مثل ə. في أوروبا يُنطق كألف قصيرة، وفي البنغال كـ "أ" داكنة قصيرة. |
| **ṛ - ⟪ऋ⟫** | مثل الـ r المممة في التشيكية. صداه الخفيف من i. |
| **ṝ - ⟪ॠ⟫** | مثل الـ r المممة في التشيكية. صداه الخفيف من u. |
| **jñ - ⟪ज्ञ्⟫** | أيضاً مثل dny (الماراثية) أو gy (شمال الهند). |
| **ś - ⟪श्⟫** | صوت ش مع طرف اللسان منحني للأسفل. مشابه لـ sch في "mischen". |
| **ṣ - ⟪ष्⟫** | صوت خ مع طرف اللسان منحني للخلف. غالباً ما يُنطق في مؤخرة الحلق لدرجة أنه يبدو تقريباً مثل kh. |
| **h - ⟪ह्⟫** | صوت همس، ليس أبداً علامة إطالة. |
| **ḥ - :** | **فيسارغا (Visarjanīya)** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫. صوت همس صامت مع صداء للحرف المتحرك السابق أو الجزء الثاني من الثنائي الصوتي السابق: agniḥ -- ⟪अग्निः⟫ = agnihī، devaiḥ -- ⟪देवैः⟫ = devaihī، gauḥ -- ⟪गौः⟫ = gauhū |
| **ṃ** | **أنوسفار (Anusvara)** -- ⟪अनुस्वर⟫. قبل الأصوات الصريرية، h، l: أنفية للحرف المتحرك. في نهاية الكلمة = m. في وسط الكلمة قبل الساكنات: الأنفي المقابل للساكن التالي: saṃdhi -- ⟪संधि⟫ = sandhī -- ⟪सन्धि⟫ |
:::
يتم تحقيق أفضل نطق عندما تقرأ الجمل أو الأبيات أو الكلمات ببطء نسبي وبطريقة رتيبة مع مراعاة دقيقة لطول الحروف المتحركة.
