# الدرس 24

## 24.1. حالة الجر (⟪चतुर्थी⟫ = "النهاية الإعرابية الرابعة")

::: grammar-box
**1. لإظهار الغرض أو النية ("لكي") لفعل، يمكن بدلاً من المصدر (⟪तुमुन्⟫) استخدام اسم مع لاحقة kṛt، الذي يشير إلى فعل أو حالة، في حالة الجر (⟪चतुर्थी⟫ = "النهاية الإعرابية الرابعة").**

مثال:

بدلاً من:

:::
::: indent
⟪रामो गुरुवचनं श्रोतुं गतः ।⟫
:::
يمكن أيضاً القول:

::: indent
⟪रामो गुरुवचनस्य श्रवणाय गतः ।⟫

أو:

⟪रामो गुरुवचनश्रवणाय गतः ।⟫
:::
= "ذهب راما لسماع خطبة المعلم."
::: media
![](/images/lekt2404.webp)
التوضيح: ⟪बाला गुरुश्रवणाय गताः⟫
(مصدر الصورة: [تفاصيل](/ar/licenses#lekt2404))
:::

::: grammar-box
**2. يمكن أيضاً أن تشير حالة الجر (⟪चतुर्थी⟫) إلى مفعول مصدر الغرض الذي يجب إكماله:**

مثال:

:::
::: indent
⟪फलेभ्यो ग्रामं गच्छति⟫ = "يذهب إلى القرية لغرض الفواكه = يذهب إلى القرية لجلب الفواكه."
:::
**وبنفس الطريقة تشير حالة الجر (⟪चतुर्थी⟫) إلى غرض شيء أو فعل:**

مثال:

::: indent
⟪यज्ञायान्नम्⟫ = "طعام لغرض ذبيحة = طعام لذبائح"
:::

(مصدر الصورة: [تفاصيل](/ar/licenses#lekt2401))

::: grammar-box
**3. يُستخدم حالة الجر (⟪चतुर्थी⟫) أيضاً للدلالة على الشخص أو الشيء الذي يُخصص له كائن الفعل (المفعول به غير المباشر؛ السؤال: لمن؟). (مع ذلك، انتبه إلى الأفعال ذات المفعولين المزدوجين (⟪द्वितीया⟫)!)**

مثال:

:::
::: indent

أمثلة:

:::
::: indent

⟪अलम्⟫ ظرف: "كافٍ، مناسب، مساوٍ": ⟪अलं योधो योधाय⟫ = "محارب يساوي محارباً آخر"

## 24.2. تكوين حالة الجر (⟪चतुर्थी⟫)

::: grammar-box
**النهايات المنتظمة لحالة الجر هي:**

* **المفرد: -e ؛ جذوع المؤنث المنتهية بحرف متحرك: -ai**
* **الجمع: حالة الجر وحالة النزع ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. الجذوع الساكنة

::: grammar-box

| | حالة الجر المفرد | حالة الجر الجمع |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. ضمائر الاستفهام

::: grammar-box

| | المذكر / المحايد | المؤنث |
| :--- | :--- | :--- |
| **المفعول له المفرد** | ⟪कस्मै⟫ | ⟪कस्यै⟫ |
| **المفعول له الجمع** | ⟪केभ्यस्⟫ | ⟪काभ्यस्⟫ |

:::
### 24.2.3. ضمائر الإشارة

::: grammar-box

| | | ⟪तद्⟫ | ⟪एतद्⟫ | ⟪इदम्⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **المذكر / المحايد** | **م. مفرد** | ⟪तस्मै⟫ | ⟪एतस्मै⟫ | ⟪अस्मै⟫ |
| | **م. جمع** | ⟪तेभ्यस्⟫ | ⟪एतेभ्यस्⟫ | ⟪एभ्यस्⟫ |
| **المؤنث** | **م. مفرد** | ⟪तस्यै⟫ | ⟪एतस्यै⟫ | ⟪अस्यै⟫ |
| | **م. جمع** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::
### 24.2.4. الجذور المتحركة

::: grammar-box
**الجذور المتحركة**

* **المذكرات / المحايدات المنتهية بـ -a:** ⟪देव⟫
* م. مفرد ⟪देवाय⟫
* م. جمع ⟪देवेभ्यस्⟫
* **المذكرات المنتهية بـ -i:** ⟪कवि⟫
* م. مفرد ⟪कवये⟫
* م. جمع ⟪कविभ्यस्⟫
* **المذكرات المنتهية بـ -u:** ⟪पशु⟫
* م. مفرد ⟪पशवे⟫
* م. جمع ⟪पशुभ्यस्⟫
* **المؤنثات المنتهية بـ -ā:** ⟪देवता⟫
* م. مفرد ⟪देवतायै⟫
* م. جمع ⟪देवताभ्यस्⟫
* **المؤنثات المنتهية بـ -ī:** ⟪देवी⟫
* م. مفرد ⟪देव्यै⟫
* م. جمع ⟪देवीभ्यस्⟫
* **المؤنثات المنتهية بـ -i:** ⟪श्रुति⟫
* م. مفرد ⟪श्रुतये⟫ أو ⟪श्रुत्यै⟫ (أي مثل ⟪कवि⟫ أو مثل ⟪देवी⟫)
* م. جمع ⟪श्रुतिभ्यस्⟫
* **المؤنثات المنتهية بـ -u:** ⟪धेनु⟫
* م. مفرد ⟪धेनवे⟫ أو ⟪धेन्वै⟫
* م. جمع ⟪धेनुभ्यस्⟫
:::
## 24.3. سانده الحروف المتحركة النهائية -ai و -au

::: grammar-box
**سانده الحروف المتحركة النهائية -ai و -au**

* **-ai قبل حرف متحرك ابتدائي يُستبدل عادة بـ -ā (نادراً ما يستبدل بـ -āy كما هو الحال في وسط الكلمة)**
* **-au قبل حرف متحرك يُستبدل عادة بـ -āv (نادراً ما يستبدل بـ -ā)**

مثال:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा अग्नये⟫ = "لهذا النار"
:::
## 24.4. قائمة الكلمات

⟪अलम्⟫ ظرف: يكفي، كافٍ، (شخص ما أو شيء) قادر على ؛ مع حالة الجر: يكفي لـ، كافٍ لـ، قادر على؛ مع أداة التعريف: يكفي بـ، توقف عن ، مثال ⟪अलं क्रोधेन⟫ = "يكفي الغضب = توقف عن الغضب!"

## 24.6. تمارين إضافية حول استخدام حالة البيانات

ترجم إلى السنسكريتية:

1\. الإلهة التي لم تُقدَّم لها القرابين تغضب البشر.

2\. يترك البقرة تذهب إلى القرية.

3\. الآن يكفي = كفى بالصبر.

4\. هذا جيد (⟪हित⟫، ⟪सुख⟫) لبراهمن.

5\. التحية (⟪नमस्⟫) لشيفا! التحية لـشري غانيشا!

::: media
![](/images/lekt2409.webp)
التوضيح: ⟪श्रीगणेशाय नमः⟫
(مصدر الصورة: [تفاصيل](/ar/licenses#lekt2409))
:::
6\. مع السلامة! (= السلامة (⟪स्वस्ति⟫ مؤنث) لكم!)

7\. هذه الثمرة تكفي للأكل.

8\. المحارب يقاوم (⟪शक्त⟫) للمحارب (الآخر).

9\. حتى فيشنو لا يتفوق على (⟪प्र⟫-⟪भू⟫ + بيانات.) شيفا.

13\. لا ينظر إليه على أنه ساق عشب.
