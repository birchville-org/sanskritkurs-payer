# Devanāgarī = ⟪देवनागरी⟫

## Exercício de Escrita 1

O sânscrito foi e continua sendo escrito em uma variedade de escritas. A seguinte visão geral oferece um pequeno recorte dessas escritas:

![](/images/schrift001.webp)  
Fig.: Amostras de escrita sânscrita
\[Fonte da imagem: Wikipedia, Licença GNU FD\]

Die wichtigste moderne nordindische Sanskritschrift ist die Devanāgarī:

![](/images/schrift002.webp)

Cada sinal consonantal inclui um "a" que segue a consoante. Se a consoante pura deve ser escrita (sem vogal subsequente), isso deve ser indicado por uma barra inclinada subscrita -- virāma = ⟪विराम⟫ --:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

Vogais seguintes a uma consoante — exceto "a" — são escritas assim:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

A ordem para escrever essas combinações de consoante + vogal é:

![](/images/schrift003.jpg)

Na escrita, cada letra, incluindo o traço horizontal na linha superior, é completada antes que a próxima letra seja escrita.

## Exercício

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

Lesen und transliterieren Sie:

⟪तॄ⟫ ⟪पाप⟫ ⟪चट्⟫ ⟪चि⟫ ⟪चाप⟫ ⟪पॄ⟫ ⟪पति⟫ ⟪पितृ⟫ ⟪कॢप्⟫ ⟪कृ⟫ ⟪कुप्⟫ ⟪कुतो⟫ ⟪चैक⟫ ⟪पुट⟫ ⟪पचति⟫ ⟪तौ⟫ ⟪पू⟫ ⟪चेत्⟫ ⟪पतति⟫ ⟪ततो⟫ ⟪तट⟫ ⟪तपति⟫ ⟪तु⟫ ⟪ते⟫ ⟪कृ⟫ ⟪पीतौ⟫

Zusätzliche Leseübung:

⟪पिता⟫ pai, ⟪कपि⟫ macaco, ⟪कृत⟫ fez,  ⟪टीका⟫ subcomentário, ⟪तत्⟫ este, ⟪तट⟫ margem, ⟪पत्⟫ disparar, ⟪पट⟫ tecido, ⟪काच⟫ vidro,  ⟪काकुत्⟫ paladar, ⟪चित्⟫ perceber, ⟪पृच्⟫ misturar,  ⟪पोटक⟫ servo, ⟪चेतु⟫ intenção, ⟪तौतातित⟫ seguidor de Kumārila (Mīmāṃsā), ⟪तूत⟫ amoreira, ⟪पीत⟫ bebeu,  ⟪पीति⟫ bebida, ⟪कॢप्⟫  caber, ⟪कृपते⟫ ele lamenta, ⟪पुटी⟫ ruga, ⟪चापि⟫ igualmente, ⟪तोक⟫ descendência, ⟪तृपत्⟫ satisfeito, ⟪पॄ⟫ encher, ⟪कृकाटी⟫ articulação do pescoço, ⟪पूपौ⟫ dois bolos, ⟪पैतृकी⟫ paterno (fem.), ⟪कौट⟫ fraudulento, ⟪कच⟫ cabelo do topo da cabeça, ⟪कुतपे⟫ sobre a esteira de pelos de cabra, ⟪कुचौ⟫ seio, ⟪चकिता⟫ assustado (fem.)
