# Lição 33

## 33.1. A reduplicação (⟪अभ्यास⟫ m.)

* A terceira classe do presente
* (bem como alguns verbos de outras classes do presente),
* o perfeito,
* o aoristo reduplicado,
* o frequentativo e
* o desiderativo

são formados por meio de reduplicação. A parte de uma forma reduplicada, que é colocada antes da raiz, chama-se sílaba de reduplicação.

A sílaba de reduplicação consiste em (uma consoante e) uma vogal.

### 33.1.1. A consoante de reduplicação

::: grammar-box
**1. Geralmente:**
**Repetição da primeira consoante da raiz**
:::
Exemplos:

::: indent
⟪दा⟫ 3 "dar"
* 3.sg.P.Ind.Präs. ⟪ददाति⟫

⟪पॄ⟫ 3 "encher"
* 3.sg.P.Ind.Präs. sig[⟪पि⟫]⟪पर्ति⟫

⟪मा⟫ 3Ā "medir"
* 3.sg.Ā.Ind.Präs. sig[⟪मि⟫]⟪मीते⟫
:::
::: grammar-box
**2. Uma consoante inicial aspirada de uma raiz é reduplicada pela consoante não aspirada correspondente.**
:::
Exemplos:

::: indent
⟪धा⟫ 3 "colocar"
* 3.sg.P.Ind.Präs. ⟪दधाति⟫

⟪भी⟫ 3 "temer"
* 3.sg.P.Ind.Pres. sig[⟪बि⟫]⟪भेति⟫
:::
::: grammar-box
**3. Uma gutural é reduplicada pela palatal não aspirada correspondente:**

:::
::: indent
⟪क्⟫, ⟪ख्⟫ por ⟪च्⟫
⟪ग्⟫, ⟪घ्⟫ por ⟪ज्⟫
:::
**⟪ह्⟫ é sempre reduplicado por ⟪ज्⟫.**
Exemplos:

::: indent
⟪हु⟫ 3 "derramar (como oferenda) no fogo"
* 3.sg.P.Ind.Pres. ⟪जुहोति⟫
:::
::: grammar-box
**4. Se uma raiz começa com várias consoantes, apenas a primeira é repetida (se necessário, aplicando a regra 2 ou 3).**
:::
::: grammar-box
**5. Se uma raiz começa com um grupo consonantal de sibilante + consoante surda, não é a sibilante que é reduplicada, mas sim a consoante surda seguinte, de acordo com as regras acima.**
:::
Exemplo:

::: indent
⟪स्था⟫ 1 "estar de pé"
* 3.sg.P.Ind.Pres. ⟪तिष्ठति⟫
:::
## 33.2. A terceira classe do presente (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ etc.")

::: grammar-box
**Formação:**

**Radical forte:**
**raiz reduplicada de grau forte + desinência**

**Radical fraco:**
**raiz reduplicada de grau fraco + desinência**

**Para a consoante de reduplicação, aplicam-se as regras dadas acima.**
:::
### 33.2.1. A vogal de reduplicação da 3ª classe do presente

::: grammar-box
* **A vogal de reduplicação regular é -i-**
* **Raízes que contêm u reduplicam com -u-**
* **as raízes ⟪दा⟫, ⟪धा⟫, ⟪हा⟫ com -a-**
:::
Exemplos:

::: grammar-box
⟪हु⟫ 3P "(derramar no fogo como oferenda)"

* **tema forte:** ⟪जुहो⟫
* **tema fraco:** ⟪जुहु⟫

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicativo Presente** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | \<⟪जुहुते⟫\> | \<⟪जुह्वते⟫\>:brjuhu + ate |
| **Imperfeito** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | \<⟪अजुहुत⟫\> | \<⟪अजुह्वत⟫\>:bra-juhu + ata |
| **Optativo** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | \<⟪जुह्वीत⟫\>:brjuhu + ī-ta | \<⟪जुह्वीरन्⟫\>:brjuhu + ī-ran |
:::
## 33.3. Sobre o Ablaut de ā

ā kann

* por um lado, ser o grau alongado de uma das séries de apofonia com -a-
* andrerseits Hochstufe in einer Ablautreihe der ā-Gruppe sein

Die beiden wichtigsten Ablautreihen der ā-Gruppe sind:

::: grammar-box
**A.**

* **Grau fraco**
  * **antes de consoante: -i-**
p.ex. ⟪धा⟫ PPP: ⟪हित⟫ (hi-ta)
  * **antes de vogal: Ø**
p.ex. ⟪धा⟫ 3.pl.P.Ind.Pres. ⟪दधति⟫ (dadh-ati)
* **Grau forte: -ā-**
p.ex. ⟪धा⟫ 3.sg.P.Ind.Pres. ⟪दधाति⟫
:::
A este grupo pertence também, p.ex.:

::: indent
⟪स्था⟫ 1
* PPP ⟪स्थित⟫ (sthi-ta)
* 3.sg.P.Fut. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **Grau fraco: -ī-**
p.ex. ⟪पा⟫ 1: PPP ⟪पीत⟫ (pī-ta)
* **Grau forte: -ā-**
p.ex. ⟪पा⟫ 1: Inf. ⟪पातुम्⟫
:::
## 33.4. Raízes em -ā da terceira classe do presente

::: grammar-box
**As raízes em -ā (exceto ⟪दा⟫ e ⟪धा⟫) geralmente alternam para -ī- no tema fraco** (veja sobre isso Thumb-Hauschild Vol. 1,1 p. 271. Presumivelmente, a série de apofonia B mencionada acima serviu de modelo, embora estas raízes, de resto, sigam a apofonia da série A), **antes de terminações vocálicas, a vogal da raiz desaparece completamente (veja a série de apofonia A).**
:::
Exemplos:

::: grammar-box
⟪मा⟫ 3Ā "medir"

| | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- |
| **Indicativo Presente** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Imperfeito** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Optativo** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3P "abandonar"

| | 3. sg. P. | 3. pl. P. |
| :--- | :--- | :--- |
| **Indicativo Presente** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Imperfeito** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Optativo** | ⟪जह्यात्⟫:brjah-yā-t:br(Die Wurzel ⟪हा⟫ hat vor dem Optativ-yā/y die gleiche Form wie vor Vokalen!) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. As raízes ⟪दा⟫ e ⟪धा⟫

::: grammar-box
**As raízes ⟪दा⟫ e ⟪धा⟫ reduplicam com a vogal -a- e perdem a vogal da raiz no tema fraco.**

**Observe em ⟪धा⟫ a lei da dissimilação de aspiração!**
:::
::: grammar-box
⟪धा⟫ 3U "colocar, estabelecer, atribuir"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicativo Presente** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Erklärung: Thumb-Hauschild 1,1 S. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Imperfeito** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Optativo** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::
As formas de ⟪दा⟫ são obtidas substituindo-se **dh** por **d** no paradigma de ⟪धा⟫. Assim:

::: grammar-box
⟪दा⟫ 3U "dar"

| | 3. sg. P. | 3. pl. P. | 3. sg. Ā. | 3. pl. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indicativo Presente** | ⟪ददाति⟫ | ⟪ददति⟫ | ⟪दत्ते⟫ | ⟪ददते⟫ |
| **Imperfeito** | ⟪अददात्⟫ | ⟪अददुर्⟫ | ⟪अदत्त⟫ | ⟪अददत⟫ |
| **Optativo** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
:::
## 33.5. O Particípio Presente Parasmaipada das raízes da 3ª classe do presente

::: grammar-box
**Os verbos da 3ª classe formam todas as formas do particípio presente Parasmaipada a partir do radical fraco.**

**Exceção: O nominativo/acusativo plural neutro pode ser formado opcionalmente a partir do radical forte ou fraco.**
:::
⟪दा⟫ Particípio presente Parasmaipada:

::: grammar-box
| | Maskulinum:br⟪पुंल्लिङ्ग⟫ | Neutrum:br⟪नपुंसकलिङ्ग⟫ | Femininum:br⟪स्त्रीलिङ्ग⟫ |
| :--- | :--- | :--- | :--- |
| **Singular** | | | |
| **1. Nominativo** | ⟪ददत्⟫:brdad-at + s | ⟪ददत्⟫:brdad-at-Ø | ⟪ददती⟫ |
| **2. Acusativo** | ⟪ददतम्⟫:brdad-at-am | ⟪ददत्⟫ | |
| **Plural** | | | |
| **1. Nominativo** | ⟪ददतस्⟫ | ⟪ददति⟫:brdad-at-i:br⟪ददन्ति⟫:brdad-ant-i | |
| **2. Acusativo** | ⟪ददतस्⟫ | ⟪ददति⟫:br⟪ददन्ति⟫ | |
:::
