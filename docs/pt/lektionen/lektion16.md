# Lição 16

## 16.1. Sobre o Sandhi de consoantes finais

Para a formação de compostos, cujo primeiro membro é um tema de terminação consonantal, são necessárias as seguintes regras:

Oclusivas guturais, retroflexas, dentais e labiais finais (isto é, sem nasais e palatais).

::: no-header

|   |   |
| :--- | :--- |
| **em pausa e antes de sons surdos** | **Substituição pelo som surdo não aspirado correspondente:** :br **p. ex.** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **antes de sons sonoros não nasais** | **Substituição pelo som sonoro não aspirado correspondente:** :br **p. ex.** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **antes de nasais** | **Substituição pela nasal correspondente:** :br **p. ex.** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::
Exceção à regra acima:

Oclusiva dental final (não nasal):

::: no-header

|   |   |
| :--- | :--- |
| **antes de Palatal** | **Substituição pela palatal não aspirada correspondente:** :br **ou seja** :br :indent -t + c- » -cc- :br :indent -d + c- » -cc- :br :indent -th + c- » -cc- :br :indent -dh + c- » -cc- :br :indent -t/-th/-d/-dh + ch- » -cch- :br :indent -t/-th/-d/-dh + j- » -jj- :br :indent -t/-th/-d/-dh + jh- » -jjh- |
| **+ ś** | **» -cś- ou -cch-** |
| **antes de Retroflexa** | **Substituição pela retroflexa não aspirada correspondente:** :br **ou seja** :br :indent -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- :br :indent -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **antes de l-** | **Substituição por -l:** :br **ou seja** :br :indent -t/-th/-d/-dh + l- » -ll- |

:::
Exemplos:

⟪तद्⟫ + ⟪फल⟫ = ⟪तत्फल⟫

⟪पुण्यवत्⟫ + ⟪ब्राह्मण⟫ = ⟪पुण्यवद्ब्राह्मण⟫

⟪पुण्यवत्⟫ + ⟪नर⟫ = ⟪पुण्यवन्नर⟫

⟪पुण्यवत्⟫ + ⟪पुरुष⟫ = ⟪पुण्यवत्पुरुष⟫

⟪सत्यवत्⟫ + ⟪चैतन्य⟫ =⟪सत्यवच्चैतन्य⟫

⟪सुखवत्⟫ + ⟪लोक⟫ = ⟪सुखवल्लोक⟫

⟪पुत्रवत्⟫ + ⟪जन⟫ = ⟪पुत्रवज्जन⟫

⟪बलवत्⟫ + ⟪शत्रु⟫ = ⟪बलवच्छत्रु⟫
