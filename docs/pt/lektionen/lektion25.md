# Lição 25

## 25.1. Formação do ablativo (⟪पञ्चमी⟫ = "quinta terminação de caso")

::: grammar-box
Com exceção dos masculinos / neutros em -a, bem como dos pronomes, as formas do ablativo (⟪पञ्चमी⟫) no singular são idênticas às do genitivo (⟪षष्ठी⟫) em todas as classes de declinação.

Exceto nos pronomes pessoais, em todas as declinações no plural, as formas do ablativo são idênticas às do dativo (⟪चतुर्थी⟫).
:::
Agora você reconhece a razão para a ordem dos casos (⟪विभक्ति⟫) em sânscrito: eles são organizados de tal forma que as formas homófonas fiquem o mais próximo possível umas das outras - ou seja, umas sob as outras.

::: grammar-box
**Ablativo singular dos masculinos / neutros em -a**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Pronomes interrogativos, relativos e demonstrativos:

::: grammar-box

| | Ablativo Singular:brMasculino / Neutro | Ablativo Singular:brFeminino |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Uso do Ablativo (⟪पञ्चमी⟫)

"O ablativo designa aquilo que permanece fixo quando algo se afasta dele."

Pāṇini 2,3,28 + 1,4,24

O ablativo responde principalmente às perguntas "De onde?", "Por quê?".

::: grammar-box
O ablativo designa, portanto, o ponto de partida, a origem e a matéria.

O ablativo pode, por isso, também designar a pessoa de quem se compra, ouve, deseja algo, etc.
:::
Exemplos:

::: indent
⟪ग्रमादागच्छति⟫ = "Ele vem da aldeia"

⟪अश्वात्पतितः⟫ = "caído do cavalo"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "recebido deles"
:::
Exemplos:

::: indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟫ = "ele ouve do mestre sobre o Dharma"

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = "o brâmane deseja do kṣatriya uma vaca leiteira"
:::
::: grammar-box
O ablativo é usado com verbos com os significados "impedir de", "proteger de", "defender de", "ter medo de":
:::
Exemplo:

::: indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = "ele protege dos inimigos"
:::
::: grammar-box
O ablativo indica o motivo ou a causa:
:::
Exemplos:

::: indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = "Ele mata o seu filho por raiva"

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = "Porque ele fez o mal, ele vai para o inferno" (« Porque ele é aquele por quem o mal foi feito)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = "Porque ele faz / fez o mal, ele vai para o inferno"
:::
Nomes que não são femininos podem, para indicar a razão de uma atividade, estar no instrumental (⟪तृतीया⟫) ou no ablativo (⟪पञ्चमी⟫). Os femininos, neste sentido, estão geralmente no instrumental, mas ocasionalmente também podem estar no ablativo.

## 25.3. O sufixo -⟪तस्⟫

::: grammar-box
Se se quiser expressar no singular (de forma inequívoca) que a palavra é usada com um sentido ablativo, pode-se anexar o sufixo -⟪तस्⟫ ao radical da palavra, que forma advérbios com um significado maioritariamente ablativo (respondendo à pergunta "De onde?"):
:::
Exemplos:

::: indent
⟪आदितस्⟫ = "desde o início"

⟪धर्मतस्⟫ = "por causa do Dharma, devido ao Dharma"
:::
::: grammar-box
O sufixo -⟪तस्⟫ também ocorre com radicais pronominais:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "de lá, lá, para lá, sobre isso, então, por isso"

⟪यद्⟫ : ⟪यतस्⟫ "do qual, de que, de onde, onde, para onde, por que, porque" (relativo)

⟪किम्⟫ : ⟪कुतस्⟫ "de onde?" "por quê?"
:::
## 25.4. Outras maneiras de expressar justificativas

::: grammar-box
**1. Orações relativas**

As orações relativas frequentemente expressam uma relação causal (justificativa), consecutiva (consequencial) ou final (de finalidade) com a oração principal.

Formas do pronome relativo que servem como conjunção causal:

*   ablativo:
    *   ⟪यतस्⟫ ... oração subordinada ... ⟪ततस्⟫ ... oração principal ... = "porque ..., por isso ..."
    *   ⟪यस्मात्⟫ ... oração subordinada ... ⟪तस्मात्⟫ ... oração principal ... = "porque ..., por isso ..."
*   instrumental:
    *   ⟪येन⟫ ... oração subordinada ... ⟪तेन⟫ ... oração principal ... = "pelo que/porque ..., por isso / por essa razão ..."
:::
Exemplo:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = "Porque Rāma deseja prosperidade, ele pratica o voto"
:::
::: grammar-box
**2\. ⟪हि⟫**

Orações principais podem ser conectadas umas às outras por meio da partícula ⟪हि⟫ "pois, porque". Uma oração com ⟪हि⟫ (que não pode estar na primeira posição, mas em prosa deve estar na segunda) fornece uma razão seja para a oração anterior, seja para a oração seguinte:
:::
Exemplo:

::: indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = "As pessoas praticam atos meritórios. Pois elas querem ir para o céu."
:::
::: grammar-box
**3. Instrumental (⟪तृतीया⟫)**

Além do ablativo (⟪पञ्चमी⟫), o instrumental (⟪तृतीया⟫) é usado para indicar o motivo ou a causa. Com substantivos femininos, o instrumental é geralmente obrigatório.
:::
Exemplo:

::: indent
⟪क्रोधेन⟫ ⟪पुत्रं⟫ ⟪हन्ति⟫ = "Ele mata seu filho por raiva" = "Ele mata seu filho com raiva"
:::
::: grammar-box
**4. Substantivos**

Além disso, as justificativas podem, naturalmente, também ser expressas através de construções com

*   ⟪कारण⟫ n. "causa": ⟪कारणात्⟫ ⟪।⟫ ⟪कारणेन⟫
*   ⟪हेतु⟫ m.
*   outros nomes com o significado de "causa"

\+ Genitivo (⟪षष्ठी⟫) ou como último membro de compostos:
:::
Exemplo:

::: indent
⟪पुण्यस्य⟫ ⟪कारणात्⟫ (⟪हेतोः⟫ etc.) = "por causa do mérito"
:::
::: grammar-box
**5\. ⟪इति⟫**

O motivo para uma atividade pode ser indicado como um pensamento com ⟪इति⟫:
:::
Exemplo:

::: indent
⟪सम्यक्संबुद्धः⟫ ⟪सुगत⟫ ⟪इत्यानन्दो⟫ ⟪गौतमं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫ = "Porque o Sugata despertou completamente para a verdade, Ānanda pergunta a Gautama sobre o seu ensinamento" (« "Pensando 'O Sugata despertou completamente para a verdade' ...)
:::
