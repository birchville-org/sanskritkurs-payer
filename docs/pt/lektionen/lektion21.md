# Lição 21

## 21.1. Outros radicais de presente em -nt

### 21.1.1. Particípio Presente (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
Este particípio é uma formação nominal a partir do tema do presente, portanto, um verdadeiro particípio. É um adjetivo que indica que alguém ou algo está a fazer o que é expresso pela raiz verbal (+ preverbo), enquanto outra coisa acontece. Também pode expressar um estado duradouro.

**Exemplos:**

:::
::: indent
"Enquanto o pai lê, ele fuma = o pai que lê fuma"
"um amigo que é (= real, verdadeiro)"
:::
::: grammar-box

| **Formação do Particípio Presente Parasmaipada para temas do presente temáticos:** |||
| :--- | :--- | :--- |
| **Masculino, Neutro** | | |
| | **tema forte** | Tema do presente + **-nt-** |
| | **tema fraco** | Tema do presente + **-t-** |
| **Feminino** | | |
| | | Präsensstamm + **-nt-** + **-ī** (Deklination wie **devī** :br⟪देवी⟫) |
| | **6ª classe do presente** | Tema do presente + **-nt-** + **-ī** :brou::brTema do presente + **-t-** + **-ī** |

:::

## 21.2. Sandhi para nasais finais

::: grammar-box
**Após uma vogal curta, as nasais finais – exceto -m – são duplicadas antes de uma vogal inicial.**

**Exemplo:**

:::
::: indent
**⟪जयन्⟫ + ⟪अरिः⟫** » ⟪जयन्नरिः⟫ "o inimigo vitorioso"
:::
## 21.3. Formas corteses de tratamento

::: grammar-box
**Em sânscrito, pode-se dirigir a alguém na 2ª pessoa do singular sem ser indelicado. No entanto, se se quiser ser polido, pode-se usar um substantivo cujo significado seja "Venerável" e semelhantes, e colocar o verbo na 3ª pessoa do singular ou do plural, ou usar uma construção passiva. A gradação de polidez no uso da pessoa no tratamento é aproximadamente a seguinte:**

:::
::: indent
**2ª sing. » 2ª pl. » 3ª sing. com o substantivo correspondente » 3ª pl. com o subst. correspondente**
:::
**O substantivo de polidez mais importante desse tipo é ⟪भवन्त्⟫ , fem.: ⟪भवती⟫ . No seu uso, corresponde ao nosso tratamento formal "o senhor"/"a senhora".**
Este ⟪भवन्त्⟫ é uma contração de ⟪भगवन्त्⟫, a sua declinação é a dos substantivos em **-vant** (ver [Lição 13](lektion13.md)). Este ⟪भवन्त्⟫ deve ser distinguido do particípio presente P de ⟪भू⟫ "tornar-se" ⟪भवन्त्⟫ : o nom. sing. masc. de ⟪भवन्त्⟫ "o senhor" é ⟪भवान्⟫, o do particípio é ⟪भवन्⟫.

**Exemplos:**

::: indent
**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = "O que faz o senhor?"
:::
mais polido:

::: indent
**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**
:::
Feminino:

::: indent
**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**
:::
Outras palavras que podem ser usadas de forma semelhante a ⟪भवन्त्⟫:

*   ⟪आर्य⟫ (f.: ⟪आर्या⟫) "Nobre". p. ex. **⟪यदार्य⟫ ⟪इच्छति⟫** "O que Vossa Senhoria deseja"
*   ⟪महाभाग⟫ "aquele cuja porção / sorte é grande = Nobre". Frequentemente usado por mulheres ao se dirigirem ou falarem sobre homens de boa posição. Muito comum no sânscrito falado moderno.

Se se deseja expressar não apenas cortesia, mas também veneração por alguém, usa-se ⟪अत्रभवन्त्⟫ em vez de ⟪भवन्त्⟫ para alguém que está presente ou próximo, e ⟪तत्रभवन्त्⟫ para alguém ausente ou distante. ⟪अत्रभवन्त्⟫ e ⟪तत्रभवन्त्⟫ podem ser traduzidos como "Vossa Senhoria", "Vossa Reverência", "Sua Eminência", etc.:

::: indent
**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = "A senhora (aqui presente) é sua esposa?"
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (numa carta ou conversa telefónica) = "Está bem?"
:::
