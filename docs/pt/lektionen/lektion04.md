## 4.1. Perguntas abertas simples (perguntas de palavra) e respostas

### 4.1.1. Pronomes interrogativos e demonstrativos

#### 4.1.1.1. Pronomes interrogativos (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Nominativo singular | Nominativo plural |
| :--- | :--- | :--- |
| **Neutro** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Masculino** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Feminino** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Pronomes demonstrativos (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Temas** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"er, sie, es; der, die, das":br(Erwähnte)** | **etad = ⟪एतद्⟫:br"dieser, diese, dieses":br(dem Sprechenden sehr Nahe)** | **idam = ⟪इदम्⟫:br"dieser, diese, dieses":br(Nahe)** |
| **Nominativo singular** ||||
| **Neutro** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Masculino** | **sa, so saḥ = ⟪स⟫ ⟪सो⟫ ⟪सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष⟫ ⟪एषो⟫ ⟪एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Feminino** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Nominativo plural** ||||
| **Neutro** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Masculino** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Feminino** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**Sobre o Nom. sg. masc.:**
- **sa, eṣa** (⟪स⟫ ⟪एष⟫) ocorre antes de todos os sons, exceto o **-a** breve
- **so, eṣo** (⟪सो⟫ ⟪एषो⟫) ocorre antes de **-a**, que é elidido (omitido) com Avagraha
- **saḥ, eṣaḥ** (⟪सः⟫ ⟪एषः⟫) ocorre apenas em Pausa (fim de frase, fim de verso) <!-- TODO: Fallback translation -->

Para poder formar frases com estes pronomes (sarvanāman n.), é ainda necessário o conhecimento das seguintes regras de Sandhi:

### 4.1.2. Sandhi de -m final

::: grammar-box
**O -m final é substituído pelo Anusvāra (-ṃ) antes de consoantes. No final de uma frase ou verso e antes de vogais, o -m é mantido.**
:::
### 4.1.3. Sandhi de -e final

::: grammar-box
1. **antes de a-, o -e permanece inalterado: o a- inicial sofre elisão com Avagraha:**
p.ex. ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ "Estes fogos"

2. **Antes de vogais que não sejam o a- curto, o -e é geralmente substituído por -a com hiato. A substituição por -ay também ocorre:**
p.ex. ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (raramente: imay īśvarāh = ⟪इमयीश्वराः⟫) "Estes SENHORES"
:::
### 4.1.4. Sandhi de -d final

::: grammar-box
**O -d final é substituído por -t em pausa, bem como antes de guturais surdas (k, kh) e labiais (p, ph).**

A substituição antes de outras consoantes será discutida mais tarde. Por enquanto, evite tais encontros de sons!
:::
### 4.1.5. Fórmulas interrogativas

Por meio destes pronomes, formam-se, p. ex., as seguintes fórmulas interrogativas:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Singular** | **Neutro** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं⟫ ⟪तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं⟫ ⟪किम्⟫, ⟪किमिदम्⟫ | "O que é isto?" |
| ^^ | **Masculino** | sa kaḥ? / kaḥ saḥ?:br⟪स⟫ ⟪कः⟫, ⟪कः⟫ ⟪सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष⟫ ⟪कः⟫, ⟪क⟫ ⟪एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं⟫ ⟪कः⟫, ⟪को⟫ ⟪ऽयम्⟫ | "Quem é este?":br"O que é ele?" |
| ^^ | **Feminino** | sā kā? / kā sā?:br⟪सा⟫ ⟪का⟫, ⟪का⟫ ⟪सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा⟫ ⟪का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं⟫ ⟪का⟫, ⟪केयम्⟫ | "Quem é esta?":br"Quem é ela?" |
| **Plural** | **Neutro** | tāni kāni? / kāni tāni?:br⟪तानि⟫ ⟪कानि⟫, ⟪कानि⟫ ⟪तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि⟫ ⟪कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि⟫ ⟪कानि⟫, ⟪कानीमानि⟫ | |
| ^^ | **Masculino** | te ke? / ke te?:br⟪ते⟫ ⟪के⟫, ⟪के⟫ ⟪ते⟫:brete ke? / ka ete?:br⟪एते⟫ ⟪के⟫, ⟪क⟫ ⟪एते⟫:brime ke? / ka ime?:br⟪इमे⟫ ⟪के⟫, ⟪क⟫ ⟪इमे⟫ | |
| ^^ | **Feminino** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः⟫ ⟪काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः⟫ ⟪काः⟫, ⟪का⟫ ⟪एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः⟫ ⟪काः⟫, ⟪का⟫ ⟪इमाः⟫ | |
:::
Um exemplo de outras perguntas:

> viṣṇuḥ kaḥ? = ⟪विष्णुः⟫ ⟪कः⟫ Resposta: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (Aqui, na frase nominal, pode-se colocar o sujeito, por exemplo, no início para enfatizar a conexão com a pergunta.)

NOTA: As respostas que você pode dar a tais perguntas com seu conhecimento atual de sânscrito, naturalmente, ainda não correspondem em todos os aspectos a um sânscrito idiomaticamente bom.
