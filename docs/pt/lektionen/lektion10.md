## 10.1. A Oração Passiva

::: grammar-box
**Esquema:**
**(Agente - kartṛ - no instrumental (tṛtīyā)) - (objeto direto - karman - no nominativo) - forma verbal passiva**

p. ex. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन⟫ ⟪देव⟫ ⟪इज्यते⟫ = "Um brâmane adora um deus com um sacrifício" (literalmente: "Um deus é adorado por um brâmane com um sacrifício.")

Esta frase é **completamente (!) idêntica em significado** à frase:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो⟫ ⟪देवं⟫ ⟪यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
- Na frase passiva, o agente (**kartṛ**) está no **Instrumental** (tṛtīyā f. "terceira terminação de caso"), o objeto direto (**karman** n.) no **Nominativo** (prathamā f.).
- Frases passivas nas quais o agente não é especificado, têm geralmente um significado impessoal ("se"):
p. ex. **ijyate** = ⟪इज्यते⟫ "Sacrifica-se" (literalmente: "adora-se com um sacrifício").
:::

::: grammar-box
**Mesmo que a frase ativa correspondente contivesse um Acusativo (dvitīyā) de destino, este pode, na frase passiva, ser colocado no Nominativo (prathamā):**

À frase ativa **rāmo grāmaṃ gacchati** = ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "Rāma vai para a aldeia." correspondem as frases passivas:
- **rāmeṇa grāmaṃ gamyate** = ⟪रामेण⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫
- alternativamente: **rāmeṇa grāmo gamyate** = ⟪रामेण⟫ ⟪ग्रामो⟫ ⟪गम्यते⟫
:::

::: grammar-box
**Verbos intransitivos (verbos sem objeto direto) frequentemente têm construções passivas, especialmente também em pedidos educados:**
- **praviśyatām** = ⟪प्रविश्यताम्⟫ = "Que se entre = Por favor, entre = Entre!"
- **niṣadyatām** = ⟪निषद्यताम्⟫ = "Que se sente = Por favor, sente-se = Por favor, tome assento"
:::
As construções passivas em sânscrito são extremamente comuns: a passiva é, de fato, mais fácil de formar do que, por exemplo, os numerosos radicais do presente.

::: important
**As frases passivas em sânscrito geralmente não devem ser traduzidas para o português por uma frase passiva, pois a passiva em português tem uma função estilística completamente diferente.**
:::

## 10.2. O Instrumental (tṛtīyā f. = ⟪तृतीया⟫ = "terceira desinência de caso")

::: grammar-box
**As terminações regulares do instrumental (tṛtīyā):**
- **Singular: -ā**
- **Plural: -bhis**

**Formações regulares:**

| | Instrumental Singular | Instrumental Plural |
| :--- | :--- | :--- |
| **Feminina auf -i**:brśruti:br⟪श्रुति⟫ | **śruty-ā** :br⟪श्रुत्या⟫ | **śruti-bhis** :br⟪श्रुतिभिस्⟫ |
| **Feminina auf -ī**:brdevī:br⟪देवी⟫ | **devy-ā** :br⟪देव्या⟫ | **devī-bhis** :br⟪देवीभिस्⟫ |
| **Feminina auf -u**:brdhenu:br⟪धेनु⟫ | **dhenv-ā** :br⟪धेन्वा⟫ | **dhenu-bhis** :br⟪धेनुभिस्⟫ |

**Formações irregulares (Singular):**

| | Instrumental Singular | Instrumental Plural |
| :--- | :--- | :--- |
| **Maskulina auf -i**:brkavi:br⟪कवि⟫ | **kavi-n-ā** :br⟪कविना⟫ | **kavi-bhis** :br⟪कविभिस्⟫ |
| **Maskulina auf -u**:brpaśu:br⟪पशु⟫ | **paśu-n-ā** :br⟪पशुना⟫ | **paśu-bhis** :br⟪पशुभिस्⟫ |
| **Feminina auf -ā**:brdevatā:br⟪देवता⟫ | **devat-ay-ā** :br⟪देवतया⟫ | **devatā-bhis** :br⟪देवताभिस्⟫ |

**Masculinos e Neutros em -a (irregular no singular e no plural):**

| | Instrumental Singular | Instrumental Plural |

**Pronome interrogativo kim:**

| | Instrumental Singular | Instrumental Plural |
| :--- | :--- | :--- |

**Pronomes Demonstrativos:**

| Pronome | Gênero | Instrumental Singular | Instrumental Plural |
| :--- | :--- | :--- | :--- |
| **tad** :br"er, sie, es; der, die, das" (Erwähnte):br⟪तद्⟫ | M/N | **tena** :br⟪तेन⟫ | **tais** :br⟪तैस्⟫ |
| | F | **tayā** :br⟪तया⟫ | **tābhis** :br⟪ताभिस्⟫ |
| **etad** :br"dieser, diese, dieses" (dem Sprechenden sehr Nahe):br⟪एतद्⟫ | M/N | **etena / enena** :br⟪एतेन⟫ / ⟪एनेन⟫ | **etais** :br⟪एतैस्⟫ |
| | F | **etayā / enayā** :br⟪एतया⟫ / ⟪एनया⟫ | **etābhis** :br⟪एताभिस्⟫ |
| **idam** :br"dieser, diese, dieses" (Nahe):br⟪इदम्⟫ | M/N | **anena / enena** :br⟪अनेन⟫ / ⟪एनेन⟫ | **ebhis** :br⟪एभिस्⟫ |
| | F | **anayā / enayā** :br⟪अनया⟫ / ⟪एनया⟫ | **ābhis** :br⟪आभिस्⟫ |
:::

::: deleteme-box
Exceto no nominativo e acusativo, as formas dos neutros em -a, do pronome interrogativo e dos pronomes demonstrativos são idênticas às formas do masculino correspondente.
:::

### 10.2.1. Sobre o uso do Instrumental (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**O Instrumental (tṛtīyā) responde principalmente às perguntas:**
- **Através de quê?**
- **Com quê?**
- **Com quem?**

**Ele é usado**
1. **em frases passivas: Agente (kartṛ) no Instrumental**
2. **para indicar o meio ou instrumento com o qual algo é realizado**
3. **para indicar o caminho pelo qual alguém chega a algum lugar**
4. **para expressar conexão, união, acompanhamento de**
5. **com posposições no sentido de "junto com, com"; por ex. saha = ⟪सह⟫ = "com"** :brpor ex.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन⟫ ⟪सह⟫ = "juntamente com o brâmane"
:::
Outros usos do Instrumental (tṛtīyā) serão abordados mais tarde.

## 10.3. A chamada lei de cerebralização para -n- (um sandhi de palavra)

::: grammar-box
Um **-n-** seguido por uma vogal ou **n, m, y, v** é substituído por **-ṇ-** se **ṛ, ṝ, r, ṣ** preceder o **-n-** na palavra, ou se nenhum outro som além de vogais, guturais, labiais, **y, v, h** ou Anusvāra ocorrer entre esses sons e o **-n-** seguinte na palavra.
:::
**Portanto:**

::: grammar-box
| | Instrumental Singular |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**Assim também se explica o -ṇ- em:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::

## 10.4. A voz passiva, Indicativo presente (yak = ⟪यक्⟫)

::: grammar-box
**Formação:**
**(geralmente) raiz de grau fraco + -ya- + desinência do Ātmanepada**
:::
p. ex.

| Wurzel:br⟪धातु⟫ | 3. sg. Pass. Präs. Indik.:br⟪यक्⟫ ⟪लट्⟫ | 3. pl. Pass. Präs. Indik.:br⟪यक्⟫ ⟪लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"er wird geführt" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"er wird gedacht" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"es wird betreten" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Note que, para os verbos da 4ª classe do presente, o Ātmanepada e o passivo têm formas idênticas! Se se trata de Ātmanepada ou de passivo, neste caso, só pode ser deduzido a partir da construção da frase.**

### 10.4.1. Regras especiais para a formação do passivo

1. **Raízes terminadas em -i ou -u** alongam a sua vogal antes do sufixo passivo **-ya-**:
   * **ji** 1 P: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
   * **śru** 5 P: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
   * **su** 5 U: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Raízes com -a- entre consoantes** (exceto nasais, y, r, v) permanecem no grau forte:
   * **labh** 1 Ā: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Algumas raízes formam seu passivo no grau forte** (ou no grau de ablaute do tema do presente):
   * **āp** 5 P: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
   * **khād** 1 P: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
   * **smṛ** 1 P: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Grau zero de verbos que começam com ya, va, ra, ou nos quais esses sons aparecem após outra consoante (Samprasāraṇa = ⟪सम्प्रसारण⟫):**

   | Wurzel:br⟪धातु⟫ | Tiefstufe:br⟪सम्प्रसारण⟫ | Passiv:br⟪यक्⟫ |
   | :--- | :--- | :--- |
   | **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
   | **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
   | **prach** 6 P:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

A designação nativa tradicional para esta formação do grau zero em verbos com **ya** ou **va** é **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. O **-ṛ** final após uma única consoante é substituído por **-ri-** antes do sufixo passivo **-ya-**:
   * **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
   * Mas: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **Algumas raízes em -an têm alternativamente duas formações de tema passivo:**
   * uma **-an-ya**
   * uma **-ā-ya-** (o **ā** longo é um representante de uma nasal longa hipotética)

p. ex. **tan** 8 U.
   * **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
   * **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (de \*tn-ya-nte)

## 10.5. Lista de palavras

**Aprenda as seguintes palavras:**

- **gṛha** n. ⟪गृह⟫ : casa
- **grāma** m. ⟪ग्राम⟫ : aldeia
- **nagara** n. ⟪नगर⟫ : cidade

  ::: note-box
Para a vida na cidade e na aldeia, veja Basham, *Wonder*, cap. 6.
  :::

- **yajña** m. ⟪यज्ञ⟫ : sacrifício

  ::: note-box
O sacrifício na Índia é, primeiramente, uma veneração da divindade como um convidado. Através disso, a divindade é colocada em obrigação.

Formação da palavra: **yaj** 1 U + sufixo kṛt **-na-**.
  :::

- **puṇya** n. ⟪पुण्य⟫ : boa obra, mérito

  ::: note-box
Através do que se ganha bem-estar e bons renascimentos.
  :::

- **pāpa** n. ⟪पाप⟫ : má ação, mal (oposto de **puṇya**)
- **satya** n. ⟪सत्य⟫ : verdade

::: note-box
Na Índia, atribuía-se poder mágico à palavra verdadeira; de fato, toda a ordem do mundo é mantida e criada pela palavra verdadeira. Para esta importante concepção, veja a obra fundamental:

1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो⟫ ⟪देवीं⟫ ⟪यजति⟫)

3. O Veda é chamado de śruti. (**vad**)
