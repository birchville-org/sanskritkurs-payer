# Lição 24

## 24.1. O Dativo (⟪चतुर्थी⟫ = "quarta terminação de caso")

::: grammar-box
**1. Para expressar o propósito ou a intenção ("a fim de") de uma ação, em vez do infinitivo (⟪तुमुन्⟫), pode-se também usar um substantivo com sufixo kṛt, que designa uma ação ou um estado, no dativo (⟪चतुर्थी⟫ = "quarta terminação de caso").**

Exemplo:

em vez de:

:::
::: indent
⟪रामो⟫ ⟪गुरुवचनं⟫ ⟪श्रोतुं⟫ ⟪गतः⟫ ⟪।⟫
:::
pode-se também dizer:

::: indent
⟪रामो⟫ ⟪गुरुवचनस्य⟫ ⟪श्रवणाय⟫ ⟪गतः⟫ ⟪।⟫

ou:

⟪रामो⟫ ⟪गुरुवचनश्रवणाय⟫ ⟪गतः⟫ ⟪।⟫
:::
= "Rāma foi para ouvir o discurso do mestre."
::: media
![](/images/lekt2404.webp)
Fig.: ⟪बाला⟫ ⟪गुरुश्रवणाय⟫ ⟪गताः⟫
(Fonte da imagem: [Detalhes](/licenses#lekt2404))
:::

::: grammar-box
**2. O dativo (⟪चतुर्थी⟫) pode também designar o objeto de um infinitivo de finalidade implícito:**

Exemplo:

:::
::: indent
⟪फलेभ्यो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "Ele vai à aldeia com o propósito de [obter] frutos = Ele vai à aldeia para buscar frutos."
:::
**Da mesma forma, o dativo (⟪चतुर्थी⟫) indica o propósito de uma coisa ou de uma ação:**

Exemplo:

::: indent
⟪यज्ञायान्नम्⟫ = "Comida com o propósito de um sacrifício = Comida para um sacrifício"
:::
::: media
![](/images/lekt2401.webp)
Fig.: ⟪यज्ञायान्नम्⟫
'Annakut' [⟪अन्नकूट⟫ = ⟪गोवर्धन⟫ ⟪पूजा⟫] is a traditional Hindu event that takes place on the Hindu New Year celebrations at all BAPS [બોચાસનવાસી અક્ષ૨ પુરુષોત્તમ સ્વામિનારાયણ સંસ્થા = Bochasanwasi Akshar Purushottam Swaminarayan Sanstha] mandirs. Hundreds of vegetarian dishes are offered to Bhagwan Swaminarayan [સ્વામિનારાયણ] on this day.
(Fonte da imagem: [Details](/licenses#lekt2401))
:::

::: grammar-box
**3. O dativo (⟪चतुर्थी⟫) também designa a pessoa ou coisa para a qual o objeto de uma ação é destinado (objeto indireto; pergunta: a quem?). (Note, no entanto, os verbos com duplo acusativo (⟪द्वितीया⟫)!)**

Exemplo:

:::
::: indent
⟪रामाय⟫ ⟪फलं⟫ ⟪ददाति⟫ = "Ele dá um fruto a Rāma." (Raiz ⟪दा⟫ 3ª classe do presente)
:::
::: media
![](/images/lekt2402.webp)
Fig.: ⟪बाला⟫ ⟪बालाय⟫ ⟪रक्षबन्धनं⟫ ⟪ददाति⟫
Raksha bandhan is celebrated with fervour and joy all across India. This festival epitomizes the unconditional love between brothers and sisters.
(Fonte da imagem: [Detalhes](/licenses#lekt2402))
:::

::: grammar-box
**4. O dativo é usado com alguns verbos (e algumas outras palavras), de forma semelhante ao alemão, em resposta à pergunta "a quem?":**

Exemplos:

:::
::: indent
⟪क्रुध्⟫ : ⟪देवो⟫ ⟪नरेभ्यो⟫ ⟪क्रुध्यति⟫ = "O deus ira-se com os homens."

⟪अलम्⟫ Advérbio: "suficiente, bastante, à altura": ⟪अलं⟫ ⟪योधो⟫ ⟪योधाय⟫ = "um guerreiro está à altura do outro guerreiro"
:::
::: media
![](/images/lekt2403.webp)

## 24.2. Formação do Dativo (⟪चतुर्थी⟫)

::: grammar-box
**As terminações regulares do dativo são:**

* **Singular: -e ; radicais femininos terminados em vogal: -ai**
* **Plural: Dativo e Ablativo ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. Radicais consonantais

::: grammar-box

| | Dativo Singular | Dativo Plural |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. Pronome interrogativo

::: grammar-box

| | Masculino / Neutro | Feminino |
| :--- | :--- | :--- |
| **Dativo Singular** | ⟪कस्मै⟫ | ⟪कस्यै⟫ |
| **Dativo Plural** | ⟪केभ्यस्⟫ | ⟪काभ्यस्⟫ |

:::
### 24.2.3. Pronomes Demonstrativos

::: grammar-box

| | | ⟪तद्⟫ | ⟪एतद्⟫ | ⟪इदम्⟫ |
| :--- | :--- | :--- | :--- | :--- |

| | **Dat. pl.** | ⟪तेभ्यस्⟫ | ⟪एतेभ्यस्⟫ | ⟪एभ्यस्⟫ |
| **Feminino** | **Dat. sg.** | ⟪तस्यै⟫ | ⟪एतस्यै⟫ | ⟪अस्यै⟫ |
| | **Dat. pl.** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::

::: grammar-box

  * Dat. pl. ⟪देवेभ्यस्⟫
* **Masculinos em -i:** ⟪कवि⟫
  * Dat. sg. ⟪कवये⟫
  * Dat. pl. ⟪कविभ्यस्⟫
* **Masculinos em -u:** ⟪पशु⟫
  * Dat. sg. ⟪पशवे⟫
  * Dat. pl. ⟪पशुभ्यस्⟫
* **Femininos em -ā:** ⟪देवता⟫
  * Dat. sg. ⟪देवतायै⟫
  * Dat. pl. ⟪देवताभ्यस्⟫
* **Femininos em -ī:** ⟪देवी⟫
  * Dat. sg. ⟪देव्यै⟫
  * Dat. pl. ⟪देवीभ्यस्⟫
* **Femininos em -i:** ⟪श्रुति⟫
  * Dat. sg. ⟪श्रुतये⟫ ou ⟪श्रुत्यै⟫ (i.e., como ⟪कवि⟫ ou como ⟪देवी⟫)
  * Dat. pl. ⟪श्रुतिभ्यस्⟫
* **Femininos em -u:** ⟪धेनु⟫
  * Dat. sg. ⟪धेनवे⟫ ou ⟪धेन्वै⟫
  * Dat. pl. ⟪धेनुभ्यस्⟫
:::
## 24.3. Sandhi de -ai e -au finais

::: grammar-box
**Sandhi de -ai e -au finais**

* **-ai antes de vogal inicial é geralmente substituído por -ā (mais raramente por -āy como no interior da palavra)**
* **-au antes de vogal é geralmente substituído por -āv (mais raramente por -ā)**

Exemplo:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा⟫ ⟪अग्नये⟫ = "a este fogo"
:::
## 24.4. Lista de palavras
