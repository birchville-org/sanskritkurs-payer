# Lição 30

## 30.1. A 9ª classe do presente (⟪क्र्यादि⟫ = "⟪क्री⟫ etc.")

::: grammar-box
**Formação:**

*   tema forte: raiz em grau zero + -nā-

*   tema fraco:

    *   antes de consoante: raiz em grau zero + -nī-

    *   antes de vogal: raiz em grau zero + -n-
:::
Exemplo:

::: indent
⟪क्री⟫ 9U "comprar"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3ª Pessoa:brParasmaipada** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **3ª Pessoa:brĀtmanepada** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
Nesta classe de presente, deve-se atentar especialmente para a formação do tema do presente da raiz ⟪ज्ञा⟫ 9U "reconhecer, saber":

::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3.ª Pessoa:brParasmaipada** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **3.ª Pessoa:brĀtmanepada** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
A forma ⟪जा⟫, que está na base do tema do presente de ⟪ज्ञा⟫, explica-se ou por uma série de apofonia -ā (grau zero) -nā (grau pleno), ou por dissimilação de *jñā-nā-ti.

Algumas raízes com vogal longa encurtam-na antes do sufixo do tema do presente da 9.ª classe:

Exemplo:

::: indent
⟪पू⟫ 9U "purificar"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3ª pessoa:brParasmaipada** | ⟪पुनाति⟫:br(pu-nā-ti) | ⟪पुनन्ति⟫:br(pu-n-anti) |
| **3ª pessoa:brĀtmanepada** | ⟪पुनीते⟫:br(pu-nī-te) | ⟪पुनते⟫:br(pu-n-ate) |

:::
Formação do particípio presente Parasmaipada:

Exemplo:

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant) ; fem.: ⟪क्रीणती⟫ (krī + n + at + ī)
:::
## 30.2. Uso do Optativo (⟪लिङ्⟫)

O Optativo é usado:

::: grammar-box
**1. para designar**

*   **um desejo**
*   **um pedido**
*   **uma ordem atenuada**

**(neste caso, o optativo - ⟪लिङ्⟫ - sobrepõe-se ao imperativo - ⟪लोट्⟫)**
:::
Exemplo:

::: indent
⟪दासो⟫ ⟪ग्राममागच्छेत्⟫ = "Que o servo venha para a aldeia"
:::
::: grammar-box
**2. Quando algo deve ser**

*   **possível**
*   **provável**
*   **presumível**

**apresentado como.**
:::
Exemplo:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं⟫ ⟪न⟫ ⟪शृणुयात्⟫ = "Se ele saísse da aldeia, não ouviria o mestre"
:::
::: grammar-box
**3. Orações relativas com o optativo por vezes têm o significado de: "Se alguém..."**
:::
Exemplo:

::: indent
⟪यो⟫ ⟪नृतं⟫ ⟪वदेत्स⟫ ⟪नरकं⟫ ⟪पतेत्⟫ = "Se alguém dissesse uma inverdade, cairia no inferno = Quem diz uma inverdade, cai no inferno"
:::
## 30.3. Desinências secundárias da 3ª pessoa do singular e do plural

O optativo (⟪लिङ्⟫), o imperfeito (⟪लङ्⟫), o aoristo (⟪लुङ्⟫), o precativo (⟪आशिर्लिङ्⟫) e o condicional têm as chamadas desinências secundárias:

::: grammar-box

| | 3ª Pessoa do Singular | 3ª Pessoa do Plural |
| :--- | :--- | :--- |
| **Parasmaipada** | **-t** | classes atemáticas: **-an** ou **-ur** :brOptativo: **-ur** |
| **Ātmanepada** | **-ta** | classes atemáticas: **-ata** (de *nta):brOptativo: **-ran** |

:::

## 30.5. Sandhi do -r final

::: grammar-box
**Exceto para -ar, para o -r final valem as mesmas regras de sandhi que para o -s final.**

**-ar antes de sons sonoros permanece -ar, mas antes de r-, o -r é elidido e o -a- é substituído por -ā-.**
:::
Exemplos:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
