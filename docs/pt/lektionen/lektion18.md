# Lição 18

## 18.1. ⟪सुभाषितम्⟫

::: indent
⟪नास्ति⟫ ⟪कामसमो⟫ ⟪व्याधिर्⟫  
⟪नास्ति⟫ ⟪मोहसमो⟫ ⟪रिपुः⟫ ⟪।⟫  
⟪नास्ति⟫ ⟪क्रोधसमो⟫ ⟪वह्निर्⟫  
⟪नास्ति⟫ ⟪ज्ञानसमं⟫ ⟪सुखम्⟫ ⟪॥⟫
:::
## 18.2. Compostos determinativos (⟪तत्पुरुष⟫) com primeiro membro adverbial

Como primeiro membro adverbial (indeclinável) podem

*   Advérbios
*   Preposições
*   Partículas
*   outros indeclináveis

::: indent
ser usados. Tais Tatpuruṣas pertencem geralmente à classe dos Nityasamāsa = ⟪नित्यसमास⟫ (m. "composto permanente"), ou seja, dos compostos que não se podem analisar de todo, ou não apenas por meio das palavras que ocorrem no próprio composto.
:::
Exemplos:

⟪अति⟫ "além disso":

::: indent
⟪अतिगुरु⟫ 3: extremamente pesado, extremamente ponderoso

⟪अतिपुरुष⟫ m.: homem superior, super-homem, herói

⟪अतिस्तुति⟫ f.: louvor excessivo

⟪अत्युक्ति⟫ f.: fala excessiva, exagero
:::
Os primeiros membros adverbiais mais importantes são a-/an-, su-, dus-.

⟪अ⟫ (antes de consoante), ⟪अन्⟫ (antes de vogal): in-: é usado em compostos em vez de ⟪न⟫ "não".

Exemplos:

::: indent
⟪अनृत⟫ n. = ⟪नर्तम्⟫ (= ⟪न⟫ + ⟪ऋतम्⟫): inverdade, mentira

⟪अकृत⟫ 3 = ⟪न⟫ ⟪कृत⟫ 3: não feito

⟪अब्राह्मणी⟫ f. = ⟪न⟫ ⟪ब्राह्मणी⟫ : uma não-brâmane, uma mulher não-brâmane

⟪अदेव⟫ m. = ⟪न⟫ ⟪देवः⟫ : um não-deus, um anti-deus
:::
⟪सु⟫ "bem, bom"; é substituído na análise do composto pelos comentadores por um adjetivo com o significado de "bom" (p. ex. ⟪सुष्टु⟫ 3, ⟪शोभन⟫ 3).

Exemplos:

::: indent
⟪सुकवि⟫ m.: um bom poeta

⟪सुकृत⟫ n.: boa ação

⟪सुखादित⟫ 3: bem mastigado

⟪सुदुःख⟫ n.: grande sofrimento
:::
⟪दुस्⟫ "mau, ruim" (observe o Sandhi!).

Exemplos:

::: indent
⟪दुर्नय⟫ m.: má conduta, mau comportamento

⟪दुष्करण⟫ n.: má ação, ato difícil
:::
A este respeito, aplica-se a seguinte lei:

::: grammar-box

Alteração fonética de -s em compostos

Ao contrário do sandhi de frase, no final do primeiro membro de compostos, aplica-se o seguinte:

\-s após -i- ou -u- antes de uma gutural ou labial surda » -ṣ

Portanto: ⟪दुष्करण⟫

:::
### 18.2.1. Compostos do tipo ⟪सुकर⟫ / ⟪दुष्कर⟫

::: grammar-box

Compostos do tipo ⟪सुकर⟫ / ⟪दुष्कर⟫ têm principalmente o significado de possibilidade passiva:

Exemplos:

:::
::: indent
⟪सुकर⟫ 3: fácil de fazer

⟪सुगम⟫ 3: fácil de ir

⟪दुर्गम⟫ 3: difícil de ir

⟪सुदुर्गम⟫ 3: muito difícil de ir
:::
### 18.2.2. Significados de nañ-Tatpuruṣa (a- / an-)

Tatpuruṣa com a- / an- podem ter os seguintes significados:

1.  Semelhança (⟪तत्सादृश्यम्⟫):
⟪अब्राह्मणः⟫ = um Kṣatriya ou Vaiśya, que usa o cordão sagrado (⟪यज्ञोपवीत⟫ n.) e, assim, se assemelha a um brâmane, sem o ser
2.  Falta, ausência (⟪तदभावः⟫):
⟪अज्ञानम्⟫ = Ignorância (falta de conhecimento)
3.  Alteridade (⟪तदन्यत्वम्⟫):
⟪अपटम्⟫ = algo que não é um tecido / uma veste (⟪पट⟫ m: tecido, veste)
4.  Pequenez (⟪तदल्पता⟫):
⟪अनुदरम्⟫ = um ventre pequeno (um não-ventre)
5.  Desaprovação (⟪अप्राशास्त्यम्⟫):
⟪अकालः⟫ = Tempo inoportuno
6.  Inimizade (⟪निरोधः⟫):
⟪असुरः⟫ = Antideus (segundo a falsa etimologia a-sura)

O seguinte verso resume estes significados:

::: indent
⟪तत्सादृश्यमभावश्च⟫  
⟪तदन्यत्वं⟫ ⟪तदल्पता⟫ ⟪।⟫  
⟪अप्राशास्त्यं⟫ ⟪निरोधश्च⟫  
⟪नजर्थाः⟫ ⟪षट्प्रकीर्तिताः⟫ ⟪॥⟫

Mencionam-se seis significados de nañ (= a-/an-) ....
:::
## 18.3. Compostos verbais

::: indent
⟪उपसर्गेण⟫ ⟪धात्वर्थो⟫  
⟪बलादन्यत्र⟫ ⟪नीयते⟫ ⟪।⟫  
⟪गङ्गासलिलमाधुर्यं⟫  
⟪सागरेण⟫ ⟪यथाम्भसा⟫ ⟪॥⟫
:::
⟪चन्द्रकीर्ति⟫ : ⟪प्रसन्नपदा⟫ p. 2, l. 14s.

Por um preverbo, o significado de uma raiz é violentamente alterado, assim como a doçura da água do Ganges pela água do mar.

::: grammar-box

Em sânscrito, os verbos podem ser combinados com preverbos (⟪उपसर्ग⟫ m.). Nesse caso, geralmente se aplica o sandhi de frase. Os preverbos podem, sob certas circunstâncias, modificar significativamente o sentido da raiz, de modo que, em muitos casos, o sentido de uma raiz com preverbo deve ser aprendido separadamente. Verbos com preverbo podem ter um modo (P, Ā) diferente da raiz simples. Vários preverbos podem ser colocados simultaneamente antes de uma raiz.

:::
Alguns preverbos importantes são:

⟪उप⟫ "para, em direção a, contra"

Exemplos:

::: indent
⟪उपगम्⟫ 1 ⟪उपगच्छति⟫ : ir para, aproximar-se de

⟪उपदिश्⟫ 6 ⟪उपदिशति⟫ : indicar, instruir, aconselhar

⟪उपपद्⟫ 4 Ā ⟪उपपद्यते⟫ : chegar a, alcançar

*   PPP ⟪उपपन्न⟫ 3: dotado de (com Instrumental)

⟪उपलभ्⟫ 1 Ā ⟪उपलभते⟫ : obter, alcançar
:::
⟪प्र⟫ "para a frente, adiante"

Exemplos:

::: indent
⟪प्राप्⟫ (pra-āp) 5 ⟪प्राप्नोति⟫ : obter

⟪प्रदिश्⟫ 6 ⟪प्रदिशति⟫ : mostrar

⟪प्रबुध्⟫ 4 Ā ⟪प्रबुध्यते⟫ : acordar, reconhecer

⟪प्रभू⟫ 1 ⟪प्रभवति⟫ : emergir, sobressair, ter poder sobre (Gen., Loc., Dat.)

⟪प्रवच्⟫ 2 ⟪प्रवक्ति⟫ PPP ⟪प्रोक्त⟫ (« pra + ukta) : explicar, comunicar, pronunciar

⟪प्रवद्⟫ 1 ⟪प्रवदति⟫ : pronunciar, designar como, declarar como

⟪प्रस्तु⟫ 2 ⟪प्रस्तौति⟫ : louvar, louvar em voz alta, mencionar algo, começar
:::
⟪वि⟫ "separadamente, para longe, des-, dis-"

Exemplos:

::: indent
⟪विगम्⟫ 1 ⟪विगच्छति⟫ : separar-se, perecer, desaparecer

⟪विजि⟫ 1 Ā (!) ⟪विजयते⟫ : derrotar, vencer

⟪विमुच्⟫ 6 ⟪विमुञ्चति⟫ : soltar, libertar

⟪विवद्⟫ 1 ⟪विवदति⟫ : disputar, debater, narrar

⟪विस्मृ⟫ 1 ⟪विस्मरति⟫ : esquecer

⟪विहन्⟫ 2 ⟪विहन्ति⟫ : esmagar, destruir, aniquilar
:::
⟪सम्⟫ "junto, com"

Exemplos:

::: indent
⟪समास्⟫ 2 Ā ⟪समास्ते⟫ : sentar-se junto, permanecer, morar

⟪समि⟫ 2 ⟪समेति⟫ : reunir-se, unir-se

⟪संगम्⟫ 1 Ā (!) ⟪संगच्छते⟫ : reunir-se, encontrar-se (amigável ou hostilmente), ter relações sexuais com (Ac.)

⟪संजन्⟫ 4 Ā ⟪संजायते⟫ : surgir

*   PPP ⟪संजात⟫ 3: nascido, surgido, tornado

⟪सम्बुध्⟫ 4 Ā ⟪सम्बुध्यते⟫ : despertar completamente (para a verdade)

⟪सम्पद्⟫ 4 Ā ⟪सम्पद्यते⟫ : ser concedido a alguém, ter sucesso

*   PPP ⟪सम्पन्न⟫ 3: provido de (Instr.)
:::
::: grammar-box

A raiz ⟪कृ⟫ "fazer" mostra, em combinação com os preverbos ⟪सम्⟫ ⟪।⟫ ⟪उप⟫ ⟪।⟫ ⟪अप⟫ ⟪।⟫ ⟪परि⟫, também a forma ⟪स्कृ⟫

:::
Exemplo:

::: indent
sam-kṛ 8 ⟪संस्करोति⟫ : preparar, preparar para o sacrifício, consagrar

*   PPP ⟪संस्कृत⟫ 3: preparado para o sacrifício ; ⟪संस्कृत⟫ n.: Sânscrito: a língua adequada para o sacrifício ; Contrapartida ⟪प्राकृत⟫ 3: comum, ordinário ; ⟪प्राकृत⟫ n.: língua comum, Prácrito (designação para as línguas populares e vernáculas que são aparentadas com o Sânscrito)
:::
### 18.3.1. Formações nominais a partir de compostos verbais

::: grammar-box

A partir de raízes com preverbos, podem ser formados substantivos por meio de sufixos kṛt.

:::
Exemplos:

sam-kṛ + -a = ⟪संस्कार⟫ m.: Consagração, preparação; ritos de passagem = designação para as cerimónias que acompanham as diferentes fases da vida, da conceção até à morte (v. para isso o excelente resumo em Basham, Wonder pp. 160 - 170!).

::: media
![](/images/lekt1804.webp)
Fig.: ⟪विवाहः⟫
Casamento = ⟪विवाह⟫ m., um importante ⟪संस्कारः⟫
(Fonte da imagem: [Detalhes](/licenses#lekt1804))
:::
upa-nī + -ana = ⟪उपनयन⟫ n.: a condução (para junto do fogo sacrificial) = cerimónia na qual aos membros masculinos das três classes superiores é colocado o cordão sagrado (⟪यज्ञोपवीत⟫ n.) e o verso sagrado ⟪सावित्री⟫ lhes é sussurrado ao ouvido, que eles a partir de então recitam diariamente ao nascer e ao pôr do sol. Para os Brâmanes, este é o Ṛgveda III.62.10:

::: indent
"Que possamos receber o excelente esplendor do deus 'Impulsor', que possa pôr os nossos pensamentos em movimento."
:::
Através do Upanayana ocorre o segundo nascimento, por isso: ⟪द्विज⟫ ⟪।⟫ ⟪द्विजाति⟫
