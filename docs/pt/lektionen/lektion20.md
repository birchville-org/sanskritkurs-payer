# Lição 20

## 20.1. Compostos possessivos = ⟪बहुव्रीहि⟫ m.

::: media
![](/images/lekt2004.webp)
Fig.: ⟪बहुव्रीहिः⟫ ⟪पुरुषः⟫
Jodhpur = ⟪जोधपुर⟫
(Fonte da imagem: [Detalhes](/licenses#lekt2004))
:::
⟪बहुव्रीहिः⟫ = ⟪बहवो⟫ ⟪व्रीहयो⟫ ⟪यस्य⟫ ⟪सः⟫ = "aquele que possui muito arroz"

::: grammar-box

**Um Bahuvrīhi, em contraste com um Tatpuruṣa, designa algo diferente do que é expresso pelos seus membros: enquanto ⟪बालपुत्रः⟫, quando analisado como um Tatpuruṣa, significa "um filho jovem", ou seja, algo que é expresso pelo último membro do composto (⟪पुत्र⟫), ⟪बालपुत्रः⟫, quando analisado como um Bahuvrīhi, significa "aquele cujo filho é jovem", isto é, o referente não é nem o filho (⟪पुत्र⟫) nem necessariamente jovem (⟪बाल⟫), mas sim uma pessoa diferente do filho jovem, nomeadamente o seu pai.**

**Os compostos possessivos são inicialmente sempre adjetivos, que, no entanto, podem ser substantivados. Por isso, o género gramatical de um Bahuvrīhi depende daquilo a que o Bahuvrīhi se refere, e não do género do último membro do composto.**

:::
::: grammar-box

**Esquema para a resolução de um Bahuvrīhi:**

**1º membro geralmente no nominativo (⟪प्रथमा⟫) sing., dual ou plural -- 2º membro no nominativo sing., dual ou plural -- Pronome relativo num caso diferente do nominativo (geralmente genitivo - ⟪षष्ठी⟫) e no género e número do Bahuvrīhi completo -- Pronome demonstrativo no número, caso e género do Bahuvrīhi completo.**

:::
Exemplos:

::: indent
⟪गतपापः⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪सः⟫ = "aquele cujo mal se foi" = "aquele que está livre de más ações"

Ac. sg. ⟪गतपापम्⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तम्⟫

Inst. sg. ⟪गतपापेन⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तेन⟫

Gen. sg. ⟪गतपापस्य⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तस्य⟫

Nom. pl. ⟪गतपापाः⟫ = ⟪गतानि⟫ ⟪पापानि⟫ ye⟪षां⟫ ⟪ते⟫

etc.

⟪अस्तमोहा⟫ = ⟪अस्तो⟫ ⟪मोहो⟫ ⟪यया⟫ ⟪सा⟫ = "uma (mulher) que abandonou a ilusão"

⟪प्राप्तोदको⟫ ⟪ग्रामः⟫ = ⟪प्राप्तमुदकं⟫ ⟪यं⟫ s ⟪ग्रामः⟫ = "Uma aldeia à qual a água chegou" = "uma aldeia ameaçada pela inundação"

⟪पुण्यवत्पुत्रः⟫ como Bahuvrīhi = ⟪पुण्यवान्पुत्रो⟫ ⟪यस्य⟫ ⟪सः⟫, ou: ⟪पुण्यवन्तः⟫ ⟪पुत्रा⟫ ⟪यस्य⟫ ⟪सः⟫ = "aquele cujo filho possui mérito" ou: "aquele cujos filhos possuem mérito"
:::
::: grammar-box

**A relação do primeiro membro com o segundo membro em um Bahuvrīhi pode ser:**

*   **atributiva**
*   **aposicional**
*   **casual**
*   **adverbial**

**Como no Tatpuruṣa, o membro mais especificado geralmente está em segundo lugar.**

:::
Tradicionalmente, distingue-se:

*   ⟪समानाधिकरणबहुव्रीहिः⟫ : em ⟪विग्रहवाक्य⟫ o membro anterior e o membro posterior estão no mesmo caso

*   ⟪व्यधिकरणबहुव्रीहिः⟫ : em ⟪विग्रहवाक्य⟫ o membro anterior e o membro posterior estão em casos diferentes

## 20.2. Bahuvrīhi com um membro anterior atributivo

::: grammar-box

**Esquema:**

:::
::: indent
**Adjetivo -- Substantivo**
:::
**Exemplo:**

::: indent
⟪गुणवत्पुत्रो⟫ ⟪ब्राह्मणः⟫ =  ⟪गुणवान्पुत्रो⟫ ⟪यस्य⟫ ⟪स⟫ ⟪ब्राह्मणः⟫ = "um brâmane cujo filho / filhos possui / possuem boas qualidades"
:::
**Especialmente frequente é a determinação atributiva por um PPP — que é rara no Tatpuruṣa. O pronome relativo, na análise, está então geralmente no instrumental (⟪तृतीया⟫) (mais raramente no genitivo / ⟪षष्ठी⟫).**

**Regra geral:**

*   **PPP - Substantivo = geralmente Bahuvrīhi**
*   **Substantivo -- PPP = geralmente Tatpuruṣa**

**Exemplo:**

::: indent
⟪कृतफल⟫ ⟪३⟫ = ⟪कृतं⟫ ⟪फलं⟫ ye⟪न⟫ ⟪सः⟫ ⟪।⟫ ⟪यया⟫ ⟪सा⟫ ⟪।⟫ ye⟪न⟫ ⟪तत्⟫ = "um / uma, que produziu um resultado, alguém / algo eficaz"
:::
## 20.3. Bahuvrīhi com primeiro membro aposicional

::: grammar-box

**Esquema:**

:::
::: indent
**Substantivo -- Substantivo**
:::
**Exemplos:**

::: indent
⟪शूरपुत्रो⟫ ⟪नरः⟫ = ⟪शूरा⟫ ⟪एव⟫ ⟪पुत्रा⟫ ⟪यस्य⟫ ⟪स⟫ ⟪नरः⟫ = "um homem cujos filhos são heróis"

⟪तदन्त⟫ ⟪३⟫ = ⟪सो⟫ ⟪ऽन्तो⟫ ⟪यस्य⟫ ⟪सः⟫ ⟪।⟫ ⟪यस्याः⟫ ⟪सा⟫ ⟪।⟫ ⟪यस्य⟫ ⟪तत्⟫ = "aquele/aquela/aquilo cujo fim é este" = "que termina com isso"
:::
::: grammar-box

**Muito importantes são os Bahuvrīhis aposicionais com os membros finais ⟪आदि⟫ ⟪।⟫ ⟪आदिक⟫ ⟪।⟫ ⟪आद्य⟫ "primeiro, começo", mais raramente ⟪प्रभृति⟫ "começo". Tais compostos correspondem a "etc.":**

**Exemplo:**

:::
::: indent
⟪देवा⟫ ⟪इन्द्रादयः⟫ =  ⟪इन्द्र⟫ ⟪आदिर्येषां⟫ ⟪ते⟫ ⟪देवाः⟫ = "Os deuses, cujo começo é Indra" = "os deuses Indra etc." = "Indra e os outros deuses"
:::
**Para expressar "apenas", pode-se usar bahuvrīhis com ⟪मात्रा⟫ f. "medida, limitação" como membro posterior:**

**Exemplo:**

::: indent
⟪शब्दमात्रम्⟫ = ⟪शब्दो⟫ ⟪मात्रा⟫ ⟪यस्य⟫ ⟪तत्⟫ = "aquilo cuja medida é uma palavra" = "apenas uma palavra"
:::
**⟪मात्र⟫ depois de um PPP deve ser traduzido como "assim que":**

**Exemplo:**

::: indent
⟪जातमात्रं⟫ ⟪शत्रुं⟫ ⟪घ्नन्ति⟫ = ⟪जातं⟫ ⟪मात्रा⟫ ⟪यस्य⟫ ⟪तं⟫ ⟪शत्रुं⟫ ⟪घ्नन्ति⟫ = "eles matam um inimigo, cuja medida é o surgimento" = "eles matam o inimigo, assim que ele surge"
:::

## 20.4. Bahuvrīhi com membro anterior em caso

i.e., Bahuvrīhis cujo primeiro membro representa um caso diferente do nominativo (⟪प्रथमा⟫).

Exemplo:

::: indent
⟪देवरूपा⟫ = ⟪देवस्यैव⟫ ⟪रूपं⟫ ⟪यस्याः⟫ ⟪सा⟫ = "uma (mulher) cuja forma é a de um deus", "uma mulher de aparência divina"
:::
::: grammar-box

**Exceção à regra geral sobre a ordem dos membros da composição:**

**O membro casual vem em segundo lugar quando designa uma parte do corpo (especialmente a mão):**

**Exemplo:**

:::
::: indent
⟪दण्डहस्तः⟫ =  ⟪दण्डो⟫ ⟪हस्ते⟫ (Loc. sg.) ⟪यस्य⟫ ⟪सः⟫ = "aquele em cuja mão há um bastão" = "aquele que carrega um bastão na mão."
:::

## 20.5. Bahuvrīhi com um primeiro membro adverbial

No primeiro membro encontra-se um advérbio, uma preposição, um preverbo ou outro indeclinável; tais compostos são geralmente ⟪नित्यसमास⟫.

Exemplos:

::: indent
⟪अपुत्रो⟫ ⟪नरः⟫ = ⟪पुत्रो⟫ ⟪यस्य⟫ ⟪नास्ति⟫ ⟪स⟫ ⟪नरः⟫ = "um homem que não tem filho" = "um homem sem filho"

⟪दुर्बल⟫ ⟪३⟫ = "alguém / algo cuja força é má" = "sem força, fraco"
:::
::: grammar-box

**⟪सह⟫ "com" como primeiro membro de um Bahuvrīhi é frequentemente substituído por ⟪स⟫.**

**Exemplo:**

:::
::: indent
⟪सपुत्रः⟫ =  ⟪सहपुत्रः⟫ =  ⟪पुत्रेण⟫ ⟪सहितः⟫ ⟪।⟫ ⟪पुत्रेण⟫ ⟪सह्⟫ = "com um filho", "acompanhado por um filho"
:::

## 20.6. Flexão do membro final de um Bahuvrīhi

::: grammar-box

**O membro final de um Bahuvrīhi é flexionado como um adjetivo de múltiplos gêneros, independentemente de seu gênero original. Portanto, se em um composto o membro final tem um gênero diferente do seu original, deve ser um Bahuvrīhi, a menos que seja um Samāhāradvanva (neutro sing.).**

**Na adjetivação:**

*   **temas em -ā no masculino e neutro tornam-se temas em -a**
*   **temas em -a (m., n.) formam seu feminino em -ā ou -ī**
*   **temas em -ī (f.) no final de Bahuvrīhis devem receber o sufixo -ka, -kā, -ka (n.); este sufixo também pode ou deve ser adicionado a muitos outros Bahuvrīhis**

:::
## 20.7. Outra classificação dos tipos de Bahuvrīhis

Os exemplos são dados aqui para estudo posterior, para alguns a gramática e o vocabulário necessários ainda não foram discutidos

1.  palavra qualificadora no primeiro membro -- palavra qualificada no segundo membro: ⟪स्थिरचित्तः⟫ = ⟪स्थिरं⟫ ⟪चित्तं⟫ ⟪यस्य⟫ ⟪सः⟫
2.  Indeclinável no primeiro membro: ⟪उच्चैःश्रवस्⟫
3.  Comparação no primeiro membro: ⟪कुशाग्रधीः⟫ =  ⟪कुशाग्र⟫ ⟪इव⟫ ⟪धीर्यस्य⟫ ⟪सः⟫
4.  Comparação implícita: ⟪उष्ट्रमुखः⟫ = ⟪उष्ट्रस्य⟫ ⟪मुखमिव⟫ ⟪मुखं⟫ ⟪यस्य⟫ ⟪सः⟫ = "de boca de camelo" = aquele cuja boca é como a de um camelo
5.  Numeral como segundo membro para um número aproximado:. ⟪उपसशाः⟫ = ⟪दशानां⟫ ⟪समीपे⟫ ⟪ये⟫ ⟪सन्ति⟫ ⟪ते⟫ = "aproximadamente dez"
6.  ambos os membros são numerais: ⟪एकद्वाः⟫ = ⟪एको⟫ ⟪वा⟫ ⟪द्वौ⟫ ⟪वा⟫ = "um ou dois"
7.  com sa-/saha- no primeiro membro: ⟪सपुत्रः⟫ ⟪।⟫ ⟪सहपुत्रः⟫
8.  com sa- (= ⟪समान⟫) no primeiro membro: ⟪सजनपदः⟫ = ⟪समानो⟫ ⟪जनपदो⟫ ⟪यस्य⟫ ⟪सः⟫
9.  ⟪नञ्बहुव्रीहिः⟫ = com a-/an- no primeiro membro: ⟪अपुत्रः⟫ = ⟪न⟫ ⟪विद्यते⟫ ⟪पुत्रो⟫ ⟪यस्य⟫ ⟪सः⟫ ; ⟪अनङ्गः⟫ = ⟪न⟫ ⟪विद्यते⟫ ⟪अङ्गं⟫ ⟪यस्य⟫ ⟪सः⟫
10.  com preposição e similares no primeiro membro: ⟪प्रवातः⟫ =⟪प्रकृष्टो⟫ ⟪वातो⟫ ⟪यस्मिन्⟫ ⟪सः⟫ ; ⟪निर्धनः⟫ = ⟪निर्गतं⟫ ⟪धनं⟫ ⟪यस्मात्सः⟫ ; ⟪सुबुद्धिः⟫ = ⟪सुष्ठु⟫ ⟪बुद्धिर्यस्य⟫ ⟪सः⟫ ; ⟪दुर्बुद्धिः⟫ = ⟪दुष्टा⟫ ⟪बुद्धिर्यस्य⟫ ⟪सः⟫
11.  designações de direção para indicar direções intermédias: ⟪पुर्वोत्तरा⟫ "nordeste"
12.  PPP como primeiro membro: ⟪कृतकटः⟫ = ⟪कृतः⟫ ⟪कटो⟫ ⟪येन⟫ ⟪सः⟫
13.  e outros

## 20.8. Relação entre Bahuvrīhi e oração relativa

Embora todo Bahuvrīhi seja resolvido por uma oração relativa, nem toda oração relativa pode ser substituída por um Bahuvrīhi. Hermann Georg Jacobi (1850 - 1937), que investigou mais de perto a relação entre ambos (Compositum und Nebensatz, 1897), escreve:

::: indent
"Ao traduzir do alemão ou de outra língua moderna para o sânscrito, nem todas as orações subordinadas podem ser representadas por compostos, mas apenas as que são ornamentais e descritivas; aquelas, no entanto, que contêm uma determinação conceitualmente necessária ou importante, aparecem também em sânscrito como orações relativas."
:::
::: media
![](/images/lekt2002.jpg)
Fig.: Hermann Jacobi
(Fonte da imagem: [Detalhes](/licenses#lekt2002))
:::
Isso pode ser verdade. No entanto, os indianos consideram muitas coisas como ornamentais e descritivas, que nós consideraríamos como "conceitualmente necessárias ou importantes".

## 20.10. Exercício 1

Analise os seguintes compostos como Bahuvrīhi e/ou Dvandva e/ou Tatpuruṣa de todas as maneiras que lhe pareçam possíveis em sânscrito (exceção: compostos com um primeiro membro adverbial).
