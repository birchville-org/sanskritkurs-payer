# Lição 17

## 17.1. Segunda classe do presente (⟪अदादि⟫ = ⟪अद्⟫ etc.)

As terminações verbais anexam-se diretamente à raiz. Devem ser observadas as alterações fonéticas resultantes do sandhi de palavras.

::: grammar-box

Existem as seguintes formas de formação na segunda classe do presente:

1.  Raízes com gradação vocálica do tema
    *   geralmente: grau forte - grau zero
    *   algumas raízes: grau alongado - grau zero
2.  Raízes sem gradação vocálica do tema
3.  raízes dissilábicas terminadas em -i/-ī com gradação vocálica do tema

:::
## 17.2. Raízes da segunda classe do presente com gradação vocálica do tema: grau forte - grau zero

Exemplos:

⟪द्विष्⟫ 2 U "odiar"

*   tema forte do presente: dveṣ-
*   tema fraco do presente: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3ª sg. Pres. P | ⟪द्वेष्टि⟫ (« dveṣ + -ti) |
| 3ª pl. Pres. P | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 3ª sg. Pres. Ā | ⟪द्विष्टे⟫ (« dviṣ + -te) |
| 3ª pl. Pres. Ā | ⟪द्विषते⟫ (dviṣ-ate) |

:::
A seguinte lei de sandhi externo aplica-se aqui:

::: grammar-box
Sandhi externo de -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-
:::
Outros exemplos:

⟪इ⟫ 2 P "ir" (Ā após certos preverbos)

*   radical forte do presente: e-
*   radical fraco do presente:
    *   antes de consoante: i-
    *   antes de vogal: y-/iy-

::: no-header

| | |
| :--- | :--- |
| 3ª sg. Pres. P | ⟪एति⟫ (e-ti) |
| 3ª pl. Pres. P | ⟪यन्ति⟫ (y-anti) |
| 3ª sg. Pres. Ā | ⟪इते⟫ (i-te) |
| 3ª pl. Pres. Ā | ⟪इयते⟫ (iy-ate) |

:::
⟪दुह्⟫ 2 U "ordenhar"

*   radical forte do presente: doh-
*   radical fraco do presente: duh-

::: no-header

| | |
| :--- | :--- |
| 3ª sg. Pres. P | ⟪दोग्धि⟫ (« doh- + -ti) |
| 3ª pl. Pres. P | ⟪दुहन्ति⟫ (duh-anti) |
| 3ª sg. Pres. Ā | ⟪दुग्धे⟫ (« duh- + -te) |
| 3ª pl. Pres. Ā | ⟪दुहते⟫ (duh-ate) |

:::
⟪हन्⟫ 2 P "golpear, matar, assassinar"

*   radical forte do presente: han-
*   radical fraco do presente:
    *   antes de consoante: ha- (« \*hn-)
    *   antes de vogal: ghn-/han-

::: no-header

| | |
| :--- | :--- |
| 3ª p. sg. Pres. P | ⟪हन्ति⟫ (han-ti) |
| 3ª p. pl. Pres. P | ⟪घ्नन्ति⟫ (ghn-anti) |
| 3ª p. sg. Pres. Ā | ⟪हते⟫ (ha-te) |
| 3ª p. pl. Pres. Ā | ⟪घ्नते⟫ (ghn-ate) |

:::
⟪अस्⟫ 2 P "ser"

*   tema forte do presente: as-
*   tema fraco do presente: s-

::: no-header

| | |
| :--- | :--- |
| 3ª pess. sing. Pres. P | ⟪अस्ति⟫ (as-ti) |
| 3ª pess. pl. Pres. P | ⟪सन्ति⟫ (s-anti) |

:::
## 17.3. Raízes da segunda classe do presente com apofonia do tema: grau de alongamento - grau zero

Exemplo:

⟪स्तु⟫ 2 U "louvar"

*   tema do presente forte: stau-
*   tema do presente fraco:
    *   antes de consoante: stu-
    *   antes de vogal: stuv-

::: no-header

| | |
| :--- | :--- |
| 3ª sg. Pres. P | ⟪स्तौति⟫ (stau-ti):broder: ⟪स्तवीति⟫ |
| 3ª pl. Pres. P | ⟪स्तुवन्ति⟫ (stuv-anti) |
| 3ª sg. Pres. Ā | ⟪स्तुते⟫ (stu-te) |
| 3ª pl. Pres. Ā | ⟪स्तुवते⟫ (stuv-ate) |

:::
## 17.4. Raízes da segunda classe do presente sem gradação do tema

::: grammar-box
As raízes da segunda classe do presente terminadas em -ā não têm gradação do tema.
:::
Exemplo:

⟪पा⟫  2 P "proteger, guardar, vigiar"

::: no-header

| | |
| :--- | :--- |
| 3ª p. sg. Pres. P | ⟪पाति⟫ (pā-ti) |
| 3ª p. pl. Pres. P | ⟪पान्ति⟫ (« pā- + -anti) |

:::
Também algumas outras raízes da segunda classe não têm gradação da raiz:

Exemplos:

⟪अद्⟫ 2 P "comer"

::: no-header

| | |
| :--- | :--- |
| 3ª sg. Pres. P | ⟪अत्ति⟫ (« ad- + -ti) |
| 3ª pl. Pres. P | ⟪अदन्ति⟫ (ad-anti) |

:::
⟪आस्⟫ 2 Ā "sentar-se"

::: no-header

| | |
| :--- | :--- |
| 3ª sg. Pres. Ā | ⟪आस्ते⟫ (ās-te) |
| 3ª pl. Pres. Ā | ⟪आसते⟫ (ās-ate) |

:::
⟪वच्⟫ 2 P "dizer"

::: no-header

| | |
| :--- | :--- |
| 3ª sg. Pres. P | ⟪वक्ति⟫ (« vac- + -ti) |
| 3ª pl. Pres. P | não ocorre |

:::
## 17.5. Raízes dissilábicas em -i/-ī com apofonia do tema

Várias raízes são dissilábicas em uma série de formas, ou seja, elas têm um -i (ou -ī antes de algumas terminações) antes de uma terminação consonantal. No entanto, essas raízes são, mesmo assim, listadas como monossilábicas pelos gramáticos nativos e em dicionários, etc.

Exemplos:

⟪रुद्⟫ 2 P "chorar, lamentar"

*   tema forte do presente: rodi-
*   tema fraco do presente:
    *   antes de consoante: rudi-
    *   antes de vogal: rud-

::: no-header

| | |
| :--- | :--- |
| 3ª sg. Pres. P | ⟪रोदिति⟫ (rodi-ti) |
| 3ª pl. Pres. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "falar"

*   tema forte do presente: bravī- (« bro- + -ī)
*   tema fraco do presente:
    *   vor Konsonant: brū-
    *   antes de vogal: bruv-

::: no-header

| | |
| :--- | :--- |
| 3ª sg. Pres. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3ª pl. Pres. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3ª sg. Pres. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3ª pl. Pres. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Também ⟪स्तु⟫ 2 U "louvar" tem, além das formas indicadas em 3., formas segundo este padrão:

::: no-header

| | |
| :--- | :--- |
| 3ª p. sg. Pres. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::

## 17.7. Exercício 1

A) Insira o verbo nas seguintes frases e traduza:

⟪१⟫. ⟪ब्राह्मणो⟫ ⟪ऽनृतं⟫ ⟪न⟫ ... (⟪ब्रू⟫ ⟪।⟫ ⟪वच्⟫ ⟪।⟫ ⟪वद्⟫)

⟪२⟫. ⟪क्षत्रियो⟫ ⟪जनान्⟫ ... (⟪पा⟫ ⟪।⟫ ⟪रक्ष्⟫)

⟪३⟫. ⟪बलवद्योधो⟫ ⟪द्विजारीन्⟫ ... (⟪जि⟫ ⟪।⟫ ⟪हन्⟫ ⟪।⟫ ⟪युध्⟫)

⟪४⟫. ⟪ब्राह्मणकविर्लोकेश्वरम्⟫ ... (⟪स्तु⟫ ⟪।⟫ ⟪यज्⟫)

⟪७⟫. ⟪द्विजदासो⟫ ⟪मृगमार्गेण⟫ ⟪ब्राह्मणग्रामम्⟫ ... (⟪गम्⟫ ⟪।⟫ ⟪इ⟫ ⟪।⟫ ⟪पद्⟫)

⟪९⟫. ⟪बालब्राह्मणी⟫ ... (⟪रुद्⟫ ⟪।⟫ ⟪आस्⟫ ⟪।⟫ ⟪मृ⟫)

B) Coloque o agente e o verbo no plural nas frases formadas em A).
