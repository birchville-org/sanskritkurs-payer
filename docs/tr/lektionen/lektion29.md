# Ders 29

## 29.1. Parasmaipada (⟪परस्मैपद⟫) ve Ātmanepada (⟪आत्मनेपद⟫) kullanımının Kausativum'da


::: grammar-box
**Kausativ, birkaç istisna dışında Ubhayapada (⟪उभयपद⟫)dir**
:::
::: grammar-box
**Kausativum'da Ātmanepada (⟪आत्मनेपद⟫) kullanılır:**

**1. Eğer kışkırtılan eylemin meyvesi, kışkırtana fayda sağlıyorsa:**
:::
Örnek:

⟪रामः कटं कारयते⟫ = "Rāma, kendi (kendi çıkarı) için bir minder yaptıır"

**2. Eğer Kausativum, geçişli fiillerin yansıtlı olarak kullanılması ("kendini göstermek", "duyulmak" vb.) veya basit fiilin nesnesi Kausativ'in Agens'i (⟪कर्तृ⟫) ise:**

Örnek:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "Viṣṇu, kendine tapınanlara kendini gösterir"

Sonuç: ⟪भक्ता विष्णुं पश्यन्ति⟫ = "İnançlılar Viṣṇu'yu görürler"


Kurallar, dolayısıyla genel olarak Ubhayapada (⟪उभयपद⟫) fiillerinde Ātmanepada (⟪आत्मनेपद⟫) kullanım kurallarına uyar.
