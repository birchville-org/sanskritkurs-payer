# Ders 30

## 30.1. 9. Şimdiki Zaman Sınıfı (⟪क्र्यादि⟫ = "⟪क्री⟫ ve benzerleri")

::: grammar-box
**Oluşum:**

*   Güçlü kök: dereceli (güdümlü) kök + -nā-

*   Zayıf kök:

*   Ünsüzden önce: Dereceli kök + -nī-

*   Ünlüden önce: dereceli kök + -n-
:::
Örnek:

::: indent
⟪क्री⟫ 9U "satın almak"
:::
::: grammar-box

| |Tekil:br⟪एकवचन⟫|Çoğul:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3. Kişi:brParasmaipada**|⟪क्रीणाति⟫:br(krī + nā + ti)|⟪क्रीणन्ति⟫:br(krī + n + anti)|
|**3. Kişi:brĀtmanepada**|⟪क्रीणीते⟫:br(krī + nī + te)|⟪क्रीणते⟫:br(krī + n + ate)|

:::
Bu şimdiki zaman sınıfında, ⟪ज्ञा⟫ 9U "tanımak, bilmek" köküne dayalı şimdiki zaman kökünün oluşumu özellikle dikkat edilmesi gereken husustur:

::: grammar-box

| |Tekil:br⟪एकवचन⟫|Çoğul:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3. Kişi:brParasmaipada**|⟪जानाति⟫:br(jā-nā-ti)|⟪जानन्ति⟫:br(jā-n-anti)|
|**3. Kişi:brĀtmanepada**|⟪जानीते⟫:br(jā-nī-te)|⟪जानते⟫:br(jā-n-ate)|

:::
⟪जा⟫ biçimi, ⟪ज्ञा⟫ şimdiki zaman köküne temel oluşturur; bu biçim ya -ā (dereceli) -nā (yüksek) apophoni dizisiyle açıklanabilir, ya da *jñā-nā-ti'den dissimilasyonla türemiştir.

Uzun ünlüyle biten bazı kökler, 9. sınıfın şimdiki zaman eki öncesinde bu ünlüyü kısaltırlar:

Örnek:

::: indent
⟪पू⟫ 9U "temizlemek"
:::
::: grammar-box

| |Tekil:br⟪एकवचन⟫|Çoğul:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3. Kişi:brParasmaipada**|⟪पुनाति⟫:br(pu-nā-ti)|⟪पुनन्ति⟫:br(pu-n-anti)|
|**3. Kişi:brĀtmanepada**|⟪पुनीते⟫:br(pu-nī-te)|⟪पुनते⟫:br(pu-n-ate)|

:::
Partizip Präsens Parasmaipada'nın oluşumu:

Örnek:

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant) ; dişil: ⟪क्रीणती⟫ (krī + n + at + ī)
:::
## 30.2. Optativ'in kullanımı (⟪लिङ्⟫)

Optativ şu durumlarda kullanılır:

::: grammar-box
**1. Bir şeyi belirtmek için**

*   **bir dilek**
*   **bir rica**
*   **hafifletilmiş bir emir**

**(bu durumda Optativ - ⟪लिङ्⟫ - İmperatif ile örtüşür - ⟪लोट्⟫)**
:::
Örnek:

::: indent
⟪दासो ग्राममागच्छेत्⟫ = "Köle köye gelsin"
:::
::: grammar-box
**2. Bir şey**

*   **olası**
*   **muhtemel**
*   **tahminen**

**olarak sunulmak istendiğinde.**
:::
Örnek:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं न शृणुयात्⟫ = "Köyden ayrılsa, ustasını duymazdı"
:::
::: grammar-box
**3. Optativ içeren sıfat cümleleri bazen "Eğer biri ... ise" anlamına gelir.**
:::
Örnek:

::: indent
⟪यो नृतं वदेत्स नरकं पतेत्⟫ = "Eğer biri yalan söylese, cehenneme düşer = Eğer biri yalan söylerse, cehenneme düşer"
:::

## 30.5. Kelime sonundaki -r için Sandhi

::: grammar-box
**-ar dışındaki kelimelerin kelime sonundaki -r için, kelime sonundaki -s ile aynı Sandhi kuralları geçerlidir.**

**-ar, ünlü harflerden önce -ar olarak kalır; ancak r- sesinden önce -r düşer ve -a- sesi -ā- ile değiştirilir.**
:::
Örnekler:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना रोदिति⟫
:::

⟪जना आर्यसत्यानि जानीयुरिति सुगतेनार्याणां सुखाय जना धर्मं ज्ञाप्यन्ते ॥१॥ ये नरा देवान्न यजेरन्व्रतानि च न चरेयुरनृतं च वदेयुरधर्मं च कुर्युस्ते सुखं नाप्नुयुर्मृत्वा च नरकं पतेयुः ॥२॥ ज्ञातिरागच्छेतितीष्ट्वार्यपुत्रो ज्ञातिं दासमाययति ॥३॥ अन्नलोभाद्दुःखं जायेतेति प्राप्तज्ञानः सुफलानि नाश्नाति ॥४॥ क्रयेण च विक्रयेण च वैश्या जीवेयुरिति वैश्यधर्मः । एवं सति वैश्यपुत्राः क्रीणन्ति विक्रीणते च ॥५॥ कृतपापो नरश्चेन्नरके पापात्पूतः स्यात्पुनर्भवं गच्छेत् ॥६॥ ब्राह्मणपुत्रा वेदाध्यायांश्च स्मृत्यध्यायांश्च पुनः पुनरधीयीरन्नित्यार्यधर्मः ॥७॥ यो ब्राह्मणः शूद्रां कामयेत स सद्ब्राह्मणो न स्यात् । सद्ब्राह्मणो हि ब्राह्मणीं कामयेत ॥८॥ सत्यं ब्रूयात्प्रियं ब्रूयान्न ब्रूयात्सत्यमप्रियम् । प्रियं च नानृतं ब्रूयादेष धर्मः सनातनः ॥९॥ ॥मनुस्मृति ४⟫.⟪१३८॥⟫
