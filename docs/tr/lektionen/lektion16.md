# Ders 16

## 16.1. Kelimenin sonunda çıkan ünsüzlerin Sandhi'si hakkında

Ön bileşeni ünsüzle biten köklerden oluşan bileşik kelimelerin oluşturulması için aşağıdaki kurallar gereklidir:

Sessiz ünsüzler ve palatal olmayan, yani nazal olmayan gutural, retrofleks, dental ve labial pürüzlü ünsüzler.

::: no-header

|   |   |
| :--- | :--- |
| **Duraklarda ve sessiz ünsüzlerden önce** | **Onlara karşılık gelen sessiz, aspiresiz (üflemeli olmayan) ünsüzle değiştirilir:** :br **örneğin** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **Ünsüz olmayan, nazal olmayan ünlü seslerden önce** | **Onlara karşılık gelen ünsüz, aspiresiz (üflemeli olmayan) ünlü sesle değiştirilir:** :br **örneğin** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **Nazal seslerden önce** | **Onlara karşılık gelen nazal sesle değiştirilir:** :br **örneğin** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::
Yukarıdaki kuralın istisnası:

Sessiz dental ünsüz (nazal olmayan):

::: no-header

|   |   |
| :--- | :--- |
| **Palatal seslerden önce** | **İlgili aspiresiz (üflemeli olmayan) palatal sesle değiştirilir:** :br **yani** :br :indent -t + c- » -cc- :br :indent -d + c- » -cc- :br :indent -th + c- » -cc- :br :indent -dh + c- » -cc- :br :indent -t/-th/-d/-dh + ch- » -cch- :br :indent -t/-th/-d/-dh + j- » -jj- :br :indent -t/-th/-d/-dh + jh- » -jjh- |
| **+ ś** | **» -cś- veya -cch-** |
| **Retrofleks seslerden önce** | **İlgili aspiresiz (üflemeli olmayan) retrofleks sesle değiştirilir:** :br **yani** :br :indent -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- :br :indent -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **l- sesinden önce** | **-l ile değiştirilir:** :br **yani** :br :indent -t/-th/-d/-dh + l- » -ll- |

:::
Örnekler:

⟪तद्⟫ + ⟪फल⟫ = ⟪तत्फल पुण्यवत्⟫ + ⟪ब्राह्मण⟫ = ⟪पुण्यवद्ब्राह्मण पुण्यवत्⟫ + ⟪नर⟫ = ⟪पुण्यवन्नर पुण्यवत्⟫ + ⟪पुरुष⟫ = ⟪पुण्यवत्पुरुष सत्यवत्⟫ + ⟪चैतन्य⟫ =⟪सत्यवच्चैतन्य सुखवत्⟫ + ⟪लोक⟫ = ⟪सुखवल्लोक पुत्रवत्⟫ + ⟪जन⟫ = ⟪पुत्रवज्जन बलवत्⟫ + ⟪शत्रु⟫ = ⟪बलवच्छत्रु⟫
