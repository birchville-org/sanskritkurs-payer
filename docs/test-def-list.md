in Pausa und vor stimmlosen Lauten
: Ersetzung durch den ihnen entsprechenden stimmlosen nicht-aspirierten Laut:
  z.B.
  - -g + p- » -kp-
  - -d + ph- » -tph-
  - -dh + p- » -tp-

vor stimmhaften nichtnasalen Lauten
: Ersetzung durch den ihnen entsprechenden stimmhaften nicht-aspirierten Laut:
  z.B.
  - -t + g- » -dg-
  - -k + b- » -gb-
  - -dh + d- » -dd-
  - -k + a- » -ga-
