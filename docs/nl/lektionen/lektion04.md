## 4.1. Preguntas de complemento simples (preguntas por palabras) y respuestas

### 4.1.1. Pronombres interrogativos y pronombres demostrativos

#### 4.1.1.1. Pronombre interrogativo (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Nominativo singular | Nominativo plural |
| :--- | :--- | :--- |
| **Neutro** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Masculino** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Femenino** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Pronombres demostrativos (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Radicales** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"él, ella, ello; el, la, lo":br(Mencionado)** | **etad = ⟪एतद्⟫:br"este, esta, esto":br(Muy cercano al hablante)** | **idam = ⟪इदम्⟫:br"este, esta, esto":br(Cercano)** |
| **Nominativo singular** ||||
| **Neutro** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Masculino** | **sa, so saḥ = ⟪स⟫ ⟪सो⟫ ⟪सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष⟫ ⟪एषो⟫ ⟪एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Femenino** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Nominativo plural** ||||
| **Neutro** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Masculino** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Femenino** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**Para el Nom. sg. masc.:**
- **sa, eṣa** (⟪स⟫ ⟪एष⟫) aparece antes de todos los sonidos excepto la vocal corta **-a**
- **so, eṣo** (⟪सो⟫ ⟪एषो⟫) aparece antes de **-a**, que se elide con Avagraha (desaparece)
- **saḥ, eṣaḥ** (⟪सः⟫ ⟪एषः⟫) aparece solo en pausa (final de oración, final de verso)

Para poder formar oraciones con estos pronombres (sarvanāman n.), se necesita además el conocimiento de las siguientes reglas de Sandhi:

### 4.1.2. Sandhi de la terminación -m

::: grammar-box
**La terminación -m se reemplaza por Anusvāra (-ṃ) antes de consonantes. Al final de la oración o verso, y ante vocales, se conserva -m.**
:::
### 4.1.3. Sandhi de la terminación -e

::: grammar-box
1. **ante a- se conserva -e sin cambio: la vocal inicial a- se elide con Avagraha:**
p.ej. ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ "Estos fuegos"

2. **Ante otras vocales que no sean la corta a- se reemplaza -e por lo general con -a en hiato. También ocurre la sustitución por -ay:**
p.ej. ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (raro: imay īśvarāh = ⟪इमयीश्वराः⟫) "Estos SEÑORES"
:::
### 4.1.4. Sandhi de la terminación -d

::: grammar-box
**La terminación -d se reemplaza por -t en pausa, así como ante guturales sordas (k, kh) y labiales sordas (p, ph).**

La sustitución ante otras consonantes se tratará más adelante. ¡Evite por ahora estas colisiones de sonidos!
:::
### 4.1.5. Fórmulas interrogativas

Con estos pronombres se forman, por ejemplo, las siguientes fórmulas interrogativas:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |

| **Enkelvoud** | **Onzijdig** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं⟫ ⟪तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं⟫ ⟪किम्⟫, ⟪किमिदम्⟫ | "Wat is dat?" |
| ^^| **Mannelijk** | sa kaḥ? / kaḥ saḥ?:br⟪स⟫ ⟪कः⟫, ⟪कः⟫ ⟪सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष⟫ ⟪कः⟫, ⟪क⟫ ⟪एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं⟫ ⟪कः⟫, ⟪को⟫ ⟪ऽयम्⟫ | "Wie is dat?":br"Wat is die?" |
| ^^| **Vrouwelijk** | sā kā? / kā sā?:br⟪सा⟫ ⟪का⟫, ⟪का⟫ ⟪सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा⟫ ⟪का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं⟫ ⟪का⟫, ⟪केयम्⟫ | "Wie is dat?":br"Wie is zij?" |
| **Meervoud** | **Onzijdig** | tāni kāni? / kāni tāni?:br⟪तानि⟫ ⟪कानि⟫, ⟪कानि⟫ ⟪तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि⟫ ⟪कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि⟫ ⟪कानि⟫, ⟪कानीमानि⟫ | |
|^^ | **Mannelijk** | te ke? / ke te?:br⟪ते⟫ ⟪के⟫, ⟪के⟫ ⟪ते⟫:brete ke? / ka ete?:br⟪एते⟫ ⟪के⟫, ⟪क⟫ ⟪एते⟫:brime ke? / ka ime?:br⟪इमे⟫ ⟪के⟫, ⟪क⟫ ⟪इमे⟫ | |
| ^^| **Vrouwelijk** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः⟫ ⟪काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः⟫ ⟪काः⟫, ⟪का⟫ ⟪एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः⟫ ⟪काः⟫, ⟪का⟫ ⟪इमाः⟫ | |
:::
Een voorbeeld van andere vragen:

> viṣṇuḥ kaḥ? = ⟪विष्णुः⟫ ⟪कः⟫ Antwoord: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (Hier kan men in de nominale zin het onderwerp bijvoorbeeld aan het begin plaatsen om de aansluiting bij de vraag te benadrukken.)

OPMERKING: De antwoorden die u met uw huidige kennis van het Sanskriet op dergelijke vragen kunt geven, komen vanzelfsprekend nog niet in alle opzichten overeen met idiomatisch goed Sanskriet.


## 4.2. Oefening

**A) Vorm mondeling met de volgende woorden vragen volgens het schema viṣṇuḥ kaḥ (⟪विष्णुः⟫ ⟪कः⟫) en beantwoord de vragen in het Sanskriet:**

śruti, śiva, brāhmaṇa, dvija (meervoud), indrāṇī, dhenu, tulādhara, kālidāsa
