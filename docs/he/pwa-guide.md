# שימוש לא מקוון (PWA)

ניתן להתקין את קורס הסנסקריט של פאייר בתור **Progressive Web App (PWA)** במכשיר שלך. הדבר מאפשר לך לגשת לכל הקורס גם ללא חיבור פעיל לאינטרנט – מושלם ללימוד תוך כדי תנועה.

## התקנה

### במחשב שולחני (PC / Mac)
1. פתח אתר זה בדפדפן מודרני (כגון Google Chrome או Microsoft Edge).
2. לחץ על **סמל ההתקנה** בצד שורת הכתובת או בתפריט הדפדפן. לחלופין, ייתכן שתמצא כפתור "התקן אפליקציה" בדף הבית.
3. אשר את ההתקנה. האפליקציה תהיה זמינה כעת כתוכנה עצמאית במחשב שלך.

### בנייד (סמארטפון / טאבלט)
- **iOS (iPhone/iPad)**: פתח את האתר ב-Safari, הקש על כפתור "שיתוף" ובחר **"הוסף למסך הבית"**.
- **Android**: פתח את האתר ב-Chrome. בדרך כלל יופיע באנר בתחתית: "הוסף את קורס הסנסקריט למסך הבית". אם לא, פתח את התפריט (שלוש נקודות) ובחר **"התקן אפליקציה"**.

## עבודה במצב לא מקוון

לאחר שהאפליקציה מותקנת וביקרת באתר לפחות פעם אחת, הקבצים החיוניים נשמרים (במטמון) במכשיר שלך.

**שפות ותכנים:**
כברירת מחדל, האפליקציה מורידה תכנים בשפות מסוימות (כגון גרמנית, אנגלית) לאחסון הלא מקוון. 
אם ברצונך להוסיף שפה חדשה, תזדקק ל**חיבור זמני לאינטרנט**. עבור אל **"הגדרות"** בסרגל הצד ובחר את השפה הרצויה. האפליקציה תוריד את התוכן הדרוש ברקע.

במהלך תהליך סנכרון זה, תראה באנר קטן בחלק העליון של המסך. ברגע שהוא נעלם, השפה החדשה זמינה במצב לא מקוון.

## פינוי מקום

האפליקציה מאחסנת טקסט ותמונות ביעילות. עם זאת, אם ברצונך לפנות שטח אחסון, בצע את הפעולות הבאות:
1. פתח את **הגדרות**.
2. שם תמצא מחוון המציג את ניצול שטח האחסון הנוכחי שלך.
3. השתמש בכפתור **"נקה מטמון"** כדי להסיר את התוכן המאוחסן מקומית. כדי להשתמש באפליקציה במצב לא מקוון שוב לאחר מכן, יהיה עליך לבחור מחדש את השפות הרצויות.
