# שיעור 21

א) פתחו את הצירופים הבאים בסנסקריט ותרגמו אותם:

⟪१⟫. **⟪अनादिकालिकसंसरः⟫** ⟪।⟫
⟪अनादिः⟫ ⟪कालो⟫ ⟪यस्य⟫ ⟪सो⟫ ⟪ऽनादिकालिकः⟫ ⟪संसरः⟫ ⟪।⟫
הריצון דרך ההתגלמויות מחדש ללא תחילה וזמן קבוע.

⟪२⟫. **⟪अनादिमध्यान्तः⟫** ⟪।⟫
⟪न⟫ ⟪आदिश्च⟫ ⟪मध्यं⟫ ⟪च⟫ ⟪अन्तश्च⟫ ⟪यस्य⟫ ⟪सः⟫ ⟪।⟫
ללא תחילה, אמצע וסוף.

⟪३⟫. **⟪महामैत्रीकरुणाचित्तः⟫** ⟪।⟫
⟪महती⟫ ⟪मैत्री⟫ ⟪च⟫ ⟪करुणा⟫ ⟪च⟫ ⟪यस्मिंस्तच्चित्तं⟫ ⟪यस्य⟫ ⟪सः⟫ ⟪।⟫
לב מלא חמלה גדולה ורחמים.

⟪४⟫. **⟪सर्वहतान्धकारः⟫** ⟪।⟫
⟪सर्वस्मिन्हतो⟫ ⟪ऽन्धकारो⟫ ⟪येन⟫ ⟪सः⟫ ⟪।⟫
זה שפיזר את האפלה בכל מקום.

ב) תרגמו:

⟪१⟫. ⟪मृतं⟫ ⟪दहन्नग्निः⟫ ⟪सतीमपि⟫ ⟪दहति⟫ ⟪॥⟫
האש ששורפת את המתים שורפת גם את אשתו הנאמנה (סטי).

⟪२⟫. ⟪सद्गुरुर्महाकविस्तोत्रैर्महादेवं⟫ ⟪स्तौति⟫ ⟪॥⟫
המורה הטוב משבח את האל הגדול בשירי הלל של המשוררים הגדולים.

⟪३⟫. ⟪महान्ति⟫ ⟪फलान्यदन्तो⟫ ⟪बाला⟫ ⟪जलमापि⟫ ⟪पिबन्ति⟫ ⟪॥⟫
הנערים שאוכלים פירות גדולים שותים גם מים.

⟪४⟫. ⟪पुजां⟫ ⟪कुर्वञ्जनो⟫ ⟪यजते⟫ ⟪च⟫ ⟪स्तौति⟫ ⟪च⟫ ⟪देवताम्⟫ ⟪॥⟫
במהלך ההשתחווה מקריב האיש ומשבח את האלילות.

⟪५⟫. ⟪गुरूपनीतनरो⟫ ⟪द्विजः⟫ ⟪॥⟫
דו-פעמי הלידה הוא גבר שהתחיל אותו המורה בודהה.

⟪६⟫. ⟪जितक्रोधो⟫ ⟪घ्नन्तमप्यरिं⟫ ⟪न⟫ ⟪द्वेष्टि⟫ ⟪।⟫ ⟪क्रोधजितस्तु⟫ ⟪द्वेष्टि⟫ ⟪॥⟫
מי שניצח את הכעס אינו שונא אויב, גם אם זה הורג אותו. מי שנכנע לכעס שונא.
