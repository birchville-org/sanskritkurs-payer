## 10.1. משפט סביל

::: grammar-box
**תבנית:**
**(סוכן - kartṛ - באמצעי (tṛtīyā)) - (אובייקט ישיר - karman - בנרטיב) - צורת פועל סבילה**

למשל **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन⟫ ⟪देव⟫ ⟪इज्यते⟫ = "ברמן משבח אלוה עם קורבן" (מילולית: "אלוה נשבח על ידי ברמן עם קורבן.")

משפט זה הוא **לגמרי (!) שווה במשמעות** עם המשפט:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो⟫ ⟪देवं⟫ ⟪यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
- במשפט סביל, הסוכן (**kartṛ**) נמצא ב**אמצעי** (tṛtīyā f. "סיומת מקרה שלישית"), והאובייקט הישיר (**karman** n.) נמצא ב**נרטיב** (prathamā f.).
- משפטים סבילים, בהם הסוכן אינו מצוין, לרוב בעלי משמעות לא אישית ("אדם"):
  למשל **ijyate** = ⟪इज्यते⟫ "אדם מקריב" (מילולית: "זה נשבח עם קורבן.").
:::

::: grammar-box
**גם אם המשפט הפעיל המתאים מכיל אקוזטיב (dvitīyā) של הכוונה, ניתן להציב אותו במשפט הסביל בנרטיב (prathamā):**

למשפט הפעיל **rāmo grāmaṃ gacchati** = ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "ראמה הולך לכפר." מתאימים המשפטים הסבילים:
- **rāmeṇa grāmaṃ gamyate** = ⟪रामेण⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫
- לחלופין: **rāmeṇa grāmo gamyate** = ⟪रामेण⟫ ⟪ग्रामो⟫ ⟪गम्यते⟫
:::

::: grammar-box
**פעלים אינטיטיביים (פעלים ללא אובייקט ישיר) לרוב בעלי מבני סביל, במיוחד בבקשות מכובדות:**
- **praviśyatām** = ⟪प्रविश्यताम्⟫ = "אדם יכנס = בבקשה היכנס = פנימה!"
- **niṣadyatām** = ⟪निषद्यताम्⟫ = "אדם ישב = בבקשה שבת = בבקשה קח מקום"
:::
מבני סביל בסנסקריט נפוצים מאוד: הסביל קל יותר לבנייה מאשר למשל מספר רב של שורשי הווה.

::: important
important
**משפטים סבילים בסנסקריט באופן כללי לא ניתן לתרגם לגרמנית באמצעות משפט סביל, שכן הסביל הגרמני בעל פונקציה סגנונית שונה לחלוטין.**
:::

## 10.3. מה שמכונה חוק הצרברליזציה עבור -n- (סנדהי-מילים)

::: grammar-box
**-n-**, שאחריו עולה תנועה או **n, m, y, v**, מוחלף ב-**ṇ-**, אם **ṛ, ṝ, r, ṣ** במילה קודמים ל-**n-** או שאין אחרת אלא תנועות, גורגלים, שפתיים, **y, v, h** או אנוסווארה בין צלילים אלו ובין ה-**n-** הבא במילה.
:::
**Deshalb:**

::: grammar-box
| | Instrumentalis יחיד |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**כך יש להסביר גם את ה-ṇ- ב:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::

## 10.4. Das סביל, Indikativ Präsens (yak = ⟪यक्⟫) <!-- TODO: Fallback translation -->

::: grammar-box
**בנייה:**
**(בדרך כלל) שורש ברמת נמוכה + -ya- + סיומת Ātmanepada**
:::
למשל

| Wurzel:br⟪धातु⟫ | 3. sg. Pass. Präs. Indik.:br⟪यक्⟫ ⟪लट्⟫ | 3. pl. Pass. Präs. Indik.:br⟪यक्⟫ ⟪लट्⟫ |
| :--- | :--- | :--- |
| **nī**:br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"er wird geführt" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man**:br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"er wird gedacht" | **manyante** :br(⟪मन्यन्ते⟫) |

**שימו לב, כי בפועלים מהכיתה הרביעית של עבר הווה, ל-Ātmanepada ולפעל הסביל יש צורות זהות! במקרה זה, ניתן להסיק האם מדובר ב-Ātmanepada או בפעל הסביל רק מהמבנה המשפטי.**

### 10.4.1. כללים מיוחדים לבניית הפעל הסביל

1. **שורשים המסתיימים ב-i או -u** מאריכים את התנועה לפני הסיומת הפעלית **-ya-**:
* **ji** 1 P: **jīyate**, **jīyante**
⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 P: **śrūyate**, **śrūyante**
⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 U: **sūyate**, **sūyante**
⟪सूयते⟫, ⟪सूयन्ते⟫

2. **שורשים עם -a- בין עיצורים** (למעט נחצי, y, r, v) שומרים על דרגה גבוהה:
* **labh** 1 Ā: **labhyate**, **labhyante**
⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **שימו לב, כי בפועלים מהכיתה הרביעית של עבר הווה, ל-Ātmanepada ולפעל הסביל יש צורות זהות! במקרה זה, ניתן להסיק האם מדובר ב-Ātmanepada או בפעל הסביל רק מהמבנה המשפטי.**
* **āp** 5 P: **āpyate**, **āpyante**
⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 P: **khādyate**, **khādyante**
⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 P: **smaryate**, **smaryante**
⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **רמת עומק של פעלים המתחילים ב-ya, va, ra או בהם מופיע צליל זה לאחר עיצור אחר (סמפסָארַנַּ = ⟪सम्प्रसारण⟫):**

   | Wurzel:br⟪धातु⟫ | Tiefstufe:br⟪सम्प्रसारण⟫ | Passiv:br⟪यक्⟫ |
   | :--- | :--- | :--- |
   | **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
   | **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
   | **prach** 6 P:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

השם המקומי המסורתי לצורה זו בשלב העמוק אצל פעלים עם **ya** או **va** הוא **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **-ṛ** בסוף המילה אחרי עיצור יחיד מוחלף ב-**ri-** לפני הסיומת הפעיל **-ya-**:
* **kṛ** 8 U: **kriyate**, **kriyante**
⟪क्रियते⟫, ⟪क्रियन्ते⟫
* אבל: **smṛ** 1 P: **smaryate**
⟪स्मर्यते⟫

6. **שורשים מסוימים עם -an יש להם לחלופין שתי בנייני שורש פעיל:**
   * אחת **-an-ya**
   * אחת **-ā-ya-** (ה-**ā** הארוך הוא נציג של אפנון היפותטי ארוך)

למשל, **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte**
⟪तन्यते⟫, ⟪तन्यन्ते⟫

## 10.5. רשימת מילים

**למדו את המילים הבאות:**

- **gṛha** n. ⟪गृह⟫ : בית
- **grāma** m. ⟪ग्राम⟫ : כפר
- **nagara** n. ⟪नगर⟫ : עיר

  ::: note-box
  באמצעותו זוכה לאושר ולישועות טובות.
  :::

- **yajña** m. ⟪यज्ञ⟫ : קורבן

  ::: note-box
  הקורבן הוא בהודו קודם כל השתחוויה לאל כאל אורח. בכך מתחייבים את האל.

  בניין מילים: **yaj** 1 U + סיומת **-na-**.
  :::

- **puṇya** n. ⟪पुण्य⟫ : מעשה זכות, זכות

  ::: note-box
  **satya** n. ⟪सत्य⟫ : אמת
  :::

- **pāpa** n. ⟪पाप⟫ : עבירה, רע (ניגוד ל-**puṇya**)
- **satya** n. ⟪सत्य⟫ : אמת

## 10.6. תרגיל

**א) בניין את הפסיבי לצורות הפועל הבאות (עם תרגום צורת הפועל):**

1. **sṛjati** (⟪सृजति⟫)
2. **yudhyate** (⟪युध्यते⟫)
3. **bhavanti** (⟪भवन्ति⟫)
4. **yajati** (⟪यजति⟫)
5. **nṛtyati** (⟪नृत्यति⟫)
6. **nayanti** (⟪नयन्ति⟫)
7. **smarati** (⟪स्मरति⟫)
8. **śṛṇvanti** (⟪शृण्वन्ति⟫)
9. **paśyati** (⟪पश्यति⟫) (הפסיבי נבנה מ-**dṛś**!)
10. **jayanti** (⟪जयन्ति⟫)
11. **kurvate** (⟪कुर्वते⟫)
12. **āpnuvanti** (⟪आप्नुवन्ति⟫)
13. **viśati** (⟪विशति⟫)
14. **khādanti** (⟪खादन्ति⟫)
15. **sunoti** (⟪सुनोति⟫)
16. **gacchati** (⟪गच्छति⟫)
17. **manyante** (⟪मन्यन्ते⟫)
18. **labhante** (⟪लभन्ते⟫)
19. **rakṣanti** (⟪रक्षन्ति⟫)
20. **vadanti** (⟪वदन्ति⟫)
21. **pṛcchanti** (⟪पृच्छन्ति⟫)
22. **tanvanti** (⟪तन्वन्ति⟫) (2 צורות!)

**ב) צרו את הכלי היחיד והרבים לכל השמות שלמדנו עד כה.**

**ג) המירו את המשפטים הבאים לפעל סביל ותרגמו אותם:**
1. **brāhmaṇo devīm yajati.** (⟪ब्राह्मणो⟫ ⟪देवीं⟫ ⟪यजति⟫)
2. **sādhuḥ svargaṃ gacchati.** (⟪साधुः⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫)
3. **śūdraṃ jayati.** (⟪शूद्रं⟫ ⟪जयति⟫)
4. **guruḥ phalāni khādati.** (⟪गुरुः⟫ ⟪फलानि⟫ ⟪खादति⟫)
5. **gurūñchṛṇoti.** (⟪गुरूञ्छृणोति⟫)
6. **ko 'gniṃ paśyati.** (⟪को⟫ ⟪ऽग्निं⟫ ⟪पश्यति⟫)
7. **ayaṃ kavirmantraṃ smarati.** (⟪अयं⟫ ⟪कविर्मन्त्रं⟫ ⟪स्मरति⟫)
8. **iyaṃ devī kṣatriyā rakṣati.** (⟪इयं⟫ ⟪देवी⟫ ⟪क्षत्रिया⟫ ⟪रक्षति⟫)
9. **kṣatriyā viṣṇuṃ yajante.** (⟪क्षत्रिया⟫ ⟪विष्णुं⟫ ⟪यजन्ते⟫) (2 אפשרויות)
10. **brāhmaṇo 'gniṃ karoti.** (⟪ब्राह्मणो⟫ ⟪ऽग्निं⟫ ⟪करोति⟫)
11. **vaiśyā imaṃ grāmaṃ gacchanti.** (⟪वैश्या⟫ ⟪इमं⟫ ⟪ग्रामं⟫ ⟪गच्छन्ति⟫) (2 אפשרויות)
12. **ete gurūṃstu śṛṇvanti.** (⟪एते⟫ ⟪गुरूंस्तु⟫ ⟪शृण्वन्ति⟫)
13. **sādhuḥ svargamāpnoti.** (⟪साधुः⟫ ⟪स्वर्गमाप्नोति⟫)
14. **brāhmāṇāḥ somaṃ sunvanti.** (⟪ब्राह्मणाः⟫ ⟪सोमं⟫ ⟪सुन्वन्ति⟫)
15. **paśūllabhate.** (⟪पशूल्लभते⟫)
16. **ke yodhāḥ kṣatriyaiḥ saha yudhyante.** (⟪के⟫ ⟪योधाः⟫ ⟪क्षत्रियैः⟫ ⟪सह⟫ ⟪युध्यन्ते⟫)

**ד) תרגמו לסנסקריט:**
1. ברהמן הולך עם ויישה לכפר.
2. הוא משבח את וישנו עם קורבן. (להביע קורבן **yajña**!)
3. הודה נקרא שרוטי. (**vad**)
4. מותחים את שרשרת האריגה. (2 אפשרויות)

5. שאלות המורה. (בניין סביל)
6. העין מובילה. (מבנה סביל)
7. המשורר רואה אלוהות. (מבנה סביל)
8. מי (נקבה) שומרת על הילדה? (מבנה סביל)
9. הקשטריה משבח את האדון עם קורבן. (מבנה סביל, ללא שימוש במילה **yajña**)
10. באמצעות נדיבות, תלמיד של בודהה מגיע לשמיים.
