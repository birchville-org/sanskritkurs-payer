# שיעור 25

## 25.1. יצירת האבלטיב (⟪पञ्चमी⟫ = "סיומת מקרה חמישית")



:::grammar-box
למעט מין זכר / נייטרליים המסתיימים ב- a, כמו גם תחליפים, בצורת היחיד בכל מחלקות ההטייה, צורות האבלטיב (⟪पञ्चमी⟫) זהות לאלו של הגנטיב (⟪षष्ठी⟫). :::

למעט בכינויי היחיד, בכל ההטיות ברבים, צורות האבלטיב זהות לאלו של הדאטיב (⟪चतुर्थी⟫).

:::כעת אתה מזהה את הסיבה לסדר המקרים (⟪विभक्ति⟫) בסנסקריט: הם מסודרים כך שצורות בעלות אותה הגייה נמצאות ככל האפשר אחת ליד השנייה — או אחת מתחת לשנייה.



:::grammar-box

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)

::::## 25.2. שימוש באבלטיב (⟪पञ्चमी⟫)

האבלטיב מציין את הדבר שנשאר קבוע כאשר משהו מתרחק ממנו.

פאניני 2,3,28 + 1,4,24

האבלטיב עומד בעיקר בפני השאלות "מאיפה؟" ו"מדוע؟".



:::grammar-box
1\. האבלטיב מציין אפוא את נקודת המוצא, המוצא והחומר.

לכן, האblativ יכול גם לציין את האדם שממנו קונים, שומעים, מבקשים וכו'.

:::דוגמאות:



:::indent
⟪ग्रमादागच्छति⟫ = "הוא בא מהכפר"

⟪अश्वात्पतितः⟫ = "נפל מהסוס"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "מֵהֶם (מִמֶּנּוּ) נִקְבָּל"

:::דוגמאות:



:::indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟫ = "הוא שומע מהמורה על הדהרמה"

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = "הברמן מעוניין בשור חלב מהקְשַׁטְרְיָה"

::::::grammar-box
2\. המקום הנסתר משמש בפעלים במשמעות של "להרחיק מ-", "להגן מפני", "להגן נגד", "לפחד מ-":

:::דוגמה:



:::indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = "הוא מגן מפני האויבים"

::::::grammar-box
3\. האבלטיב מציין את הסיבה או הגורם:

:::דוגמאות:



:::indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = "הוא הורג את בנו מכעס"

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = "מכיוון שהוא עשה רע, הוא בא לגיהנום" (« מכיוון שהוא אחד שדרך רע נעשתה בו)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = "מכיוון שהוא עושה/עשה רע, הוא יורד לגיהנום"

:::שמות עצם שאינם נקביים יכולים, כדי לציין את סיבת פעולה, להופיע במכשיר (⟪तृतीया⟫) או במגביר (⟪पञ्चमी⟫). נקביים מופיעים במובן זה בדרך כלל במכשיר, אך לעיתים קרובות גם במגביר.

## 25.3. הסיומת -⟪तस्⟫



:::grammar-box
כדי לבטא בצורה חד-משמעית במספר יחיד שהמילה משמשת במשמעות אבליטיבית, ניתן לצרף לשורש המילה את הסיומת -⟪तस्⟫, היוצרת מילות תואר בעלות משמעות אבליטיבית ברובן (על השאלה "מאיפה?"):

:::דוגמאות:



:::indent
⟪आदितस्⟫ = "מאז ומעולם"

⟪धर्मतस्⟫ = "מטעם הדֶרְמָה, בשל הדֶרְמָה"

::::::grammar-box
הסיומת -⟪तस्⟫ מופיעה גם על שרשי תחליפין:

::::::indent
⟪तद्⟫ : ⟪ततस्⟫ (« טָטָס) "משם, שם, לשם, עליו, אז, בגלל זה"

⟪यद्⟫ : ⟪यतस्⟫ "מִמֶּנּוּ, מִמֶּנָּה, מִמֶּנּוֹ, מִמֶּנָּה, מִמֶּנּוֹ, מִמֶּנָּה, מִמֶּנּוֹ, מִמֶּנָּה" (יחסית)

⟪किम्⟫ : ⟪कुतस्⟫ "מאיפה?" "למה?"

:::## 25.4. דרכים אחרות לנסח נימוקים



:::grammar-box
**1\. משפטים יחס**

משפטים יחס מבטאים לעיתים קרובות קשר סיבתי (מסביר), מסקני (מסיק) או סופי (מכוון) כלפי המשפט הראשי.

צורות של pronomen יחס המשמשות כקונונקציה סיבתית:

*   אבליטיבי:
    *   ⟪यतस्⟫ ... משפט משנה ... ⟪ततस्⟫ ... משפט ראשי ... = "מכיוון ש..., לכן..."
    *   ⟪यस्मात्⟫ ... משפט משנה ... ⟪तस्मात्⟫ ... משפט ראשי ... = "מכיוון ש..., לכן..."
*   אינסטרומנטלי:
    *   ⟪येन⟫ ... משפט משנה ... ⟪तेन⟫ ... משפט ראשי ... = "באמצעות/מכיוון ש..., דרך זה/בגלל זה..."

:::דוגמה:



:::indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = "מכיוון שרמה מעוניין בשפע, הוא מקיים את הנדר"

::::::grammar-box
**2\. ⟪हि⟫**

משפטים ראשיים ניתן לקשר באמצעות החלקיק ⟪हि⟫ "כי, משום". משפט הכולל את ⟪हि⟫ (שאינו יכול להופיע במקום הראשון, אלא חייב להופיע במקום השני בפרוזה) מציין נימוק, הן עבור המשפט הקודם והן עבור המשפט הבא:

:::דוגמה:



:::indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = "האנשים עושים מעשים זכאים. שכן הם רוצים להיכנס לשמים."

::::::grammar-box
**3\. אינסטרומטיבל (⟪तृतीया⟫)**

בנוסף לאבלטיב (⟪पञ्चमी⟫), משמש האינסטרומטיוו (⟪तृतीया⟫) לציון הסיבה או הגורם. בשמות עצם נקביים, האינסטרומטיוו הוא בדרך כלל חובה.

:::דוגמה:



:::indent
⟪क्रोधेन⟫ ⟪पुत्रं⟫ ⟪हन्ति⟫ = "הוא הורג את בנו מתוך כעס" = "הוא הורג את בנו בכעס"

::::::grammar-box
**4\. שמות עצם**

בנוסף, ניתן כמובן לבטע נימוקים גם באמצעות מבנים עם

*   ⟪कारण⟫ נ. "סיבה": ⟪कारणात्⟫ ⟪।⟫ ⟪कारणेन⟫
*   ⟪हेतु⟫ מ.
*   שמות עצם אחרים במשמעות "סיבה"

+ תבוסת (⟪षष्ठी⟫) או כהרכב מאוחר:

:::דוגמה:



:::indent
⟪पुण्यस्य⟫ ⟪कारणात्⟫ (⟪हेतोः⟫ וכו') = "בזכות הזכות"

::::::grammar-box
**5\. ⟪इति⟫**

את המוטיב לפעילות ניתן לציין כמחשבה עם ⟪इति⟫:

:::דוגמה:



:::indent
⟪सम्यक्संबुद्धः⟫ ⟪सुगत⟫ ⟪इत्यानन्दो⟫ ⟪गौतमं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫ = "מכיוון שהסוגטה התעורר באופן מושלם לאמת, אנואנדה שואל את גאוטמה על לימודו" (« "חושב 'הסוגטה התעורר באופן מושלם לאמת' ...")
