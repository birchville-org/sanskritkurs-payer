# שיעור 25

## 25.1. יצירת ה-Ablativ (⟪पञ्चमी⟫ = "סיומת מקרה חמישית")

::: grammar-box
מלבד לזכרים/נטרלים המסתיימים ב-a וכמו כן לנטיית הפעלים, בצורת היחיד בכל מחלקות הנטייה צורות ה-Ablativ (⟪पञ्चमी⟫) זהות לאלו של ה-Genetiv (⟪षष्ठी⟫).

מלבד לנטיית הפעלים, בצורת הרבים בכל מחלקות הנטייה צורות ה-Ablativ זהות לאלו של ה-Dativ (⟪चतुर्थी⟫).
:::
כעת אתה מבין את הסיבה לסדר המקרים (⟪विभक्ति⟫) בסנסקריט: הם מסודרים כך שצורות זהות נמצאות ככל האפשר אחת ליד השנייה - או זו מתחת לשכנתה.

::: grammar-box
**סיומת יחיד גברי/נקבי בסוג נייטרלי על -a**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
תארים, שמות עצם וסמיכות:

::: grammar-box

| | Ablativ Singular:brMaskulinum / Neutrum | Ablativ Singular:brFemininum |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. שימוש באבלטיב (⟪पञ्चमी⟫)

"האבלטיב מציין את הדבר שנשאר קבוע כאשר משהו עוזב אותו."

פאניני 2,3,28 + 1,4,24

האבלטיב מופיע בעיקר בתשובה לשאלות "מאיפה?" ו"למה?".

::: grammar-box
1\. האבלטיב מציין אפוא את נקודת המוצא, המקור והחומר.

האבלטיב יכול אפוא גם לציין את האדם שממנו קונים, שומעים, מבקשים וכו'.
:::
דוגמאות:

::: indent
⟪ग्रमादागच्छति⟫ = "הוא בא מהכפר"

⟪अश्वात्पतितः⟫ = "נפל מהסוס"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "מֵהֶם (לָהֶם) נִקְבַּל"
:::
דוגמאות:

::: indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟩ = "הוּא שׁוֹמֵעַ מִן הָרַב עַל הַדְּהַרְמָה"

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = "הַבְּרָהֲמָן מִשְׁתַּחֵל לַכְּשָׁטְרִיָּה בָּקָר חָלָב"
:::
::: grammar-box
2\. הָאֲבְלַטִיב מוּצָב אֶצֶל פְעֻלוֹת בַּמִּשְׁמָעוֹת "לְהַחֲזִיק מֵ", "לִשְׁמֹר מִן", "לְהִתְגַּנֵּב מִן", "לְהִרָאֶה מֵ":
:::
דוגמה:

::: indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = "הוּא מִשְׁמָר מֵן הַצָרוֹת"
:::
::: grammar-box
3\. הָאֲבְלַטִיב מַצְייֵן אֶת הַסָּבָב אוֹ הַגְּרוּם:
:::
דוגמאות:

::: indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = "הוא הורג את בנו מתוך כעס"

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = "מכיוון שהוא עשה רע, הוא יורד לגיהנום" (« מכיוון שהוא אחד שבו נעשה רע»)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = "מכיוון שהוא עושה / עשה רע, הוא יורד לגיהנום"
:::
שמות עצם שאינם נקביים יכולים, כדי לציין את סיבת פעולה, להופיע במגמה (⟪तृतीया⟫) או באבליטיב (⟪पञ्चमी⟫). שמות עצם נקביים מופיעים במשמעות זו בדרך כלל במגמה, אך לעיתים נדירות הם יכולים גם להופיע באבליטיב.

## 25.3. הסיומת -⟪तस्⟫

::: grammar-box
אם רוצים להביע במשפט יחיד (באופן חד־משמעי) שהמילה משמשת במשמעות אָבְּלַטִיבית, ניתן לצרף לשורש המילה את הסיומת -⟪तस्⟫, היוצרת מילות תואר־הזמן בעלות משמעות אָבְלַטִיבית ברובן (על השאלה "מאיפה?"):
:::
דוגמאות:

::: indent
⟪आदितस्⟫ = "מאז תחילת הדברים"

⟪धर्मतस्⟫ = "בגלל הדרמה, בשל הדֶרְמָה"
:::
::: grammar-box
הסיומת -⟪तस्⟫ מופיעה גם על שורשי כינויי־הקיצור:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« טָה־טַס) "משם, שם, לשם, על כך, אז, בגלל זה"

⟪यद्⟫ : ⟪यतस्⟫ "מאיזה, ממה, מאיפה, איפה, לאן, מדוע, כי" (יחסית)

⟪किम्⟫ :  ⟪कुतस्⟫ "מאיפה?" "מדוע?"
:::
## 25.4. דרכים אחרות להבעת נימוקים

::: grammar-box
**1\. משפטים יחסיים**

משפטי יחס מביעים לעיתים קרובות קשר סיבתי (נימוקי), מסקנתי (מסקנה) או מטרה (כוונתי) למשפט הראשי.

צורות של pronomen יחס המשמשות כמילת חיבור סיבתית:

*   Ablativ:
    *   ⟪यतस्⟫ ... משפט תלוי ... ⟪ततस्⟫ ... משפט ראשי ... = "מכיוון ש..., לכן..."
    *   ⟪यस्मात्⟫ ... משפט תלוי ... ⟪तस्मात्⟫ ... משפט ראשי ... = "מכיוון ש..., לכן..."
*   Instrumental:
    *   ⟪येन⟫ ... משפט תלוי ... ⟪तेन⟫ ... משפט ראשי ... = "באמצעות/מכיוון ש..., דרך זה / לכן..."
:::
דוגמה:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = "מכיוון שרמה מעוניין בשפע, הוא מקיים את הנדר"
:::
::: grammar-box
**2\. ⟪हि⟫**

ניתן לקשר משפטים ראשיים באמצעות החלקיק ⟪हि⟩ "שכן, מכיוון". משפט עם ⟪हि⟩ (שלא יכול להופיע במקום הראשון, אלא חייב להופיע במקום השני בפרוזה) מציין נימוק, הן למשפט הקודם והן למשפט הבא:
:::
דוגמה:

::: indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = "האנשים עושים מעשים זכאים. הם רוצים להגיע לשמיים."
:::
::: grammar-box
**3\. אינסטרומטלי (⟪तृतीया⟩)**

בנוסף למאבל (⟪पञ्चमी⟫), משמש האינסטרומטיווס (⟪तृतीया⟫) להצבת הסיבה או הגורם. בשמות עצם נקביים, האינסטרומטיווס הוא בדרך כלל חובה.
:::
דוגמה:

::: indent
⟪क्रोधेन⟫ ⟪पुत्रं⟫ ⟪हन्ति⟫ = "הוא הורג את בנו מתוך כעס" = "הוא הורג את בנו בכעס"
:::
::: grammar-box
**4\. שמות עצם**

כמובן, ניתן לבטא נימוקים גם באמצעות מבנים עם

*   ⟪कारण⟫ n. "סיבה": ⟪कारणात्⟫ ⟪।⟫ ⟪कारणेन⟫
*   ⟪हेतु⟫ m.
*   שמות עצם אחרים במשמעות "סיבה"

תחילת שם עצם (⟪षष्ठी⟫) או כחלק מאחורי צירופים:
:::
דוגמה:

::: indent
⟪पुण्यस्य⟫ ⟪कारणात्⟫ (⟪हेतोः⟫ וכו') = "בגלל הזכות"
:::
::: grammar-box
**5\. ⟪इति⟫**

ניתן לציין את המניע לפעולה כמחשבה עם ⟪इति⟫:
:::
דוגמה:

::: indent
⟪सम्यक्संबुद्धः⟫ ⟪सुगत⟫ ⟪इत्यानन्दो⟫ ⟪गौतमं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫  = "מכיוון שהסוגטה התעורר באופן מושלם לאמת, אָנַנְדָּא שואל את גאוטמה על לימודיו" (« "חושב 'הסוגטה התעורר באופן מושלם לאמת' ..." ...)
:::
