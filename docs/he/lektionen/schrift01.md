# דוונאגארִי = ⟪देवनागरी⟫

## תרגיל כתיבה 1

סנסקריט נכתב ונכתבת במגוון רחב של כתבים. סקירה זו מציגה קטע קטן מתוך הכתבים הללו:

![](/images/schrift001.webp)  
איור: דוגמאות כתיבה בסנסקריט
\[מקור התמונה: ויקיפדיה, רישיון GNU FD\]

הכתב הצפון-הודי המודרני החשוב ביותר לסנסקריט הוא דוונאגארִי:

![](/images/schrift002.webp)

כל סימן עיצור מציין גם "א" העוקב אחר העיצור. אם יש לכתוב את העיצור הטהור (ללא תנועה עוקבת), יש לסמן זאת באמצעות קו נטוי מתחת -- ויראמה = ⟪विराम⟫ -- כדי להבהיר:

⟪क्⟫ = ק', ⟪च्⟫ = צ', ⟪ट्⟫ = ט', ⟪त्⟫  = ת', ⟪प्⟫ = פ'

תנועות העוקבות אחר עיצור -- למעט "א" -- נכתבות כך:

⟪का⟫ = קָא, ⟪कि⟫ = קִי, ⟪की⟫ = קִיּ, ⟪कु⟫ = קוּ, ⟪कू⟫ = קוּא, ⟪कृ⟫ = קְרִי, ⟪कॄ⟫ = קְרֵא, ⟪कॢ⟫  = קְלִי

⟪के⟫ = קֵא, ⟪कै⟫ = קַאי, ⟪को⟫ = קוֹא, ⟪कौ⟫ = קָאוּ

הסדר בכתיבת צירופים אלו של עיצור + תנועה הוא:

![](/images/schrift003.jpg)

בעת הכתיבה, כל אות כולל הקו האופקי נשלמת עד לקו העליון לפני שכותבים את האות הבאה.
