# ד⟪ेवनागरी⟫ = ⟪देवनागरी⟫

## תרגיל כתיבה 1

סנסקריט נכתבה ונכתבת במגוון רחב של כתבים. סקירה זו מציגה קטע קטן מתוך כתבים אלו:

![](/images/schrift001.webp)  
איור: דוגמאות כתב סנסקריט  
\[מקור התמונה: ויקיפדיה, רישיון GNU FD\]

Die wichtigste moderne nordindische Sanskritschrift ist die Devanāgarī:

![](/images/schrift002.webp)

כל סימן עיצור מצייין "a" הבא אחרי העיצור. אם רוצים לכתוב את העיצור הנקי (ללא תנועה הבאה אחריו), יש לסמן זאת באמצעות קו נטוי מתחת -- וירמה = ⟪विराम⟫ -- כך:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

תנועות הבאות אחרי עיצור -- למעט "a" -- נכתבות כך:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

סדר הכתיבה של שילובים אלו של עיצור + תנועה הוא:

![](/images/schrift003.jpg)

בעת הכתיבה, כל אות, כולל הקו האופקי, מושלמת עד הקו העליון לפני כתיבת האות הבאה.
