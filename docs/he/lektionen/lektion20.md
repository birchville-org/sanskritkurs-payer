# שיעור 20

## 20.1. קומפוזיטות בעלות אופי של רכוש = ⟪बहुव्रीहि⟫ m.

::: media
![](/images/lekt2004.webp)
איור: ⟪बहुव्रीहिः पुरुषः⟫
ג'ודפור = ⟪जोधपुर⟫
(מקור התמונה: [פרטים](/he/licenses#lekt2004))
:::
⟪बहुव्रीहिः⟫ = ⟪बहवो व्रीहयो यस्य सः⟫ = "מי שיש לו הרבה אורז"

::: grammar-box

**קומפוזיציה מסוג באהובריאהי, בניגוד לטאטפורוש, מציינת משהו אחר מאשר מה שמוצג על ידי רכיביה: בעוד ש-⟪बालपुत्रः⟫ כטאטפורוש מתפרש כ"בן צעיר", כלומר משהו המיוצג על ידי הרכיב האחרון של הקומפוזיציה (⟪पुत्र⟫), ⟪बालपुत्रः⟫ כבאהובריאהי מתפרש כ"מי שיש לו בן צעיר", כלומר המצויין אינו הבן (⟪पुत्र⟫) ולא בהכרח צעיר (⟪बाल⟫), אלא אדם שונה מהבן הצעיר, כלומר אביו.**

**קומפוזיטות בעלות אופי של רכוש הן תחילה תמיד תארים, אך ניתן להפוך אותם לשמות עצם. לכן, המין הדקדוקי של באהובריאהי תלוי במה שהבאהובריאהי מתייחס אליו, ולא במין של הרכיב האחרון בקומפוזיציה.**

:::
::: grammar-box

**תרשים לפתרון באהובריאהי:**

**1. הרכיב הראשון לרוב במשמעות נומינטיבי (⟪प्रथमा⟫) יחיד, דואל או רבים -- 2. הרכיב השני בנומינטיבי יחיד, דואל או רבים -- תארים יחסים במשמעות אחרת מנומינטיבי (לרוב ג'נטיב - ⟪षष्ठी⟫) ובמין ומספר של הבאהובריאהי הכולל -- תארים הדגשיים במספר, מקרה ומין של הבאהובריאהי הכולל.**

:::
דוגמאות:


::: indent
⟪गतपापः⟫ = ⟪गतं पापं यस्य सः⟫ = "מי שרעתו הלכה" = "מי שהוא נקי מעבירות"

אק. סג' ⟪गतपापम्⟫ = ⟪गतं पापं यस्य तम्⟫

אינס. סג' ⟪गतपापेन⟫ = ⟪गतं पापं यस्य तेन⟫

גנ. סג' ⟪गतपापस्य⟫ = ⟪गतं पापं यस्य तस्य⟫

נומ. פל' ⟪गतपापाः⟫ = ⟪गतानि पापानि⟫ ye⟪षां ते⟫

וכו׳.

⟪अस्तमोहा⟫ = ⟪अस्तो मोहो यया सा⟫ = "אישה שהשליכה את הבורות"

⟪प्राप्तोदको ग्रामः⟫ = ⟪प्राप्तमुदकं यं⟫ s ⟪ग्रामः⟫ = "כפר אליו הגיע המים" = "כפר הסכן משיטפון"

⟪पुण्यवत्पुत्रः⟫ כבאהובריהי = ⟪पुण्यवान्पुत्रो यस्य सः⟫, או: ⟪पुण्यवन्तः पुत्रा यस्य सः⟫ = "מי שיש לו בן בעל זכות" או: "מי שיש לו בני-זכר בעלי זכות"
:::
::: grammar-box

**היחס בין הרכיב הקדמי לרכיב האחורי יכול להיות בבאהובריהי:**

*   **תוארני**
*   **אפוזיציוני**
*   **כסואלי**
*   **אדבריאלי**

**כמו בטטפורוש, הרכיב המדויק יותר נמצא לרוב במקום השני.**

:::
במסורת מבדילים בין:

*   ⟪समानाधिकरणबहुव्रीहिः⟫ : ב-⟪विग्रहवाक्य⟫ הרכיב הקדמי והאחורי נמצאים באותו כס

*   ⟪व्यधिकरणबहुव्रीहिः⟫ : ב-⟪विग्रहवाक्य⟫ הרכיב הקדמי והאחורי נמצאים בכס שונים

:::

::: indent

*   **PPP - שם עצם = לרוב באהוויריהי**

## 20.6. הנטייה של הרכיב האחרון בבהובריהי

::: grammar-box

**הרכיב האחרון של בהובריהי מנוטי כצורת תואר רב-מגדרי, ללא קשר למין המקורי שלו. אם כן, ברכיב מורכב שבו לרכיב האחרון יש מגדר אחר מהמגדר המקורי שלו, חייבת להיות זו בהובריהי, אם אינה סמאההאראדווַנְוָה (זכר יחיד).**

**בצירוף תוארי**

*   **שורשי -ā הופכים בשני המינים זכר ונקבה לשורשי -a**
*   **שורשי -a (זכר, נקבה) יוצרים את הנקבה שלהם בסיומת -ā או -ī**
*   **שורשי -ī (נקבה) חייבים לקבל בסוף בהובריהי את הסיומת -ka, -kā, -ka (זכר); סיומות אלו יכולות או חייבות לקבל גם בהובריהי רבים אחרים**

:::
## 20.7. סיווג אחר של סוגי בהובריהי

הדוגמאות כאן ניתנות לעיבוד מאוחר יותר, עבור חלק מהן עדיין לא נלמד הדקדוק והאוצר הנדרשים

1. מילה מתארת בגזע הקדמי -- מילה נקבעת בגזע האחורי: ⟪स्थिरचित्तः⟫ = ⟪स्थिरं चित्तं यस्य सः⟫
2. מילים בלתי משתנות בגזע הקדמי: ⟪उच्चैःश्रवस्⟫
3. השוואה בגזע הקדמי: ⟪कुशाग्रधीः⟫ =  ⟪कुशाग्र इव धीर्यस्य सः⟫
4. השוואה מרומזת: ⟪उष्ट्रमुखः⟫ = ⟪उष्ट्रस्य मुखमिव मुखं यस्य सः⟫ = "בעל פה כפיהו" = שפה שלו כמו של גמל
5. מספרים כרכיב האחורי למספר משוער: ⟪उपसशाः⟫ = ⟪दशानां समीपे ये सन्ति ते⟫ = "בערך עשרה"
6. שני הגזעים הם מספרים: ⟪एकद्वाः⟫ = ⟪एको वा द्वौ वा⟫ = "אחד או שניים"
7. עם sa-/saha- בגזע הקדמי: ⟪सपुत्रः । सहपुत्रः⟫
8. עם sa- (= ⟪समान⟫) בגזע הקדמי: ⟪सजनपदः⟫ = ⟪समानो जनपदो यस्य सः⟫
9. ⟪नञ्बहुव्रीहिः⟫ = עם a-/an- בגזע הקדמי: ⟪अपुत्रः⟫ = ⟪न विद्यते पुत्रो यस्य सः⟫ ; ⟪अनङ्गः⟫ = ⟪न विद्यते अङ्गं यस्य सः⟫
10. עם מילות יחס וכדומה בגזע הקדמי: ⟪प्रवातः⟫ =⟪प्रकृष्टो वातो यस्मिन् सः⟫ ; ⟪निर्धनः⟫ = ⟪निर्गतं धनं यस्मात्सः⟫ ; ⟪सुबुद्धिः⟫ = ⟪सुष्ठु बुद्धिर्यस्य सः⟫ ; ⟪दुर्बुद्धिः⟫ = ⟪दुष्टा बुद्धिर्यस्य सः⟫
11. תיאורי כיוון לתיאור כיוונים ביניים: ⟪पुर्वोत्तरा⟩ "צפון-מזרחי"
12. שם תואר פעולה בעבר (PPP) כגזע קדמי: ⟪कृतकटः⟫ = ⟪कृतः कटो येन सः⟫
13. ואחרים

## 20.8. יחס בין באהובריהי למשפט יחסי

אמנם כל באהובריהי ניתן לפירוק באמצעות משפט יחסי, אך לא כל משפט יחסי ניתן להחלפה בבאהובריהי. הרמן גאורג יקובי (1850 - 1937), שחקר את היחס בין השניים לעומק (Compositum und Nebensatz, 1897), כותב:

::: indent
"כאשר מתרגמים מגרמנית או משפה מודרנית אחרת לסנסקריט, לא ניתן להחליף את כל המשפטים הטפילים ברכיבים מורכבים, אלא רק את אלו המוסיפים תיאורים ופרטים; אלה לעומת זאת, הכוללים קביעה הכרחית או חשובה מבחינה מושגית, יופיעו גם בסנסקריט כמשפטים יחסיים."
:::
::: media
![](/images/lekt2002.jpg)
איור: הרמן יקובי
(מקור התמונה: [פרטים](/he/licenses#lekt2002))
:::
ייתכן שזה נכון. עם זאת, ההודים רואים דברים רבים כתיאוריים ומוסיפי פרטים, בעוד שאנו היינו רואים אותם כ"הכרחיים או חשובים מבחינה מושגית".

## 20.11. תרגיל 2

א) תרגמו ופרקו את הרכבים בשנסקרית:

⟪इन्द्रशत्र्वनार्या देवेन्द्रेण जीयन्ते ॥१॥ शूरबलक्षत्रिययोधः शूरपुत्रमिच्छति ॥२॥ सुदुर्गममार्गेण स्वर्गं गम्यते । सुगमस्तु नरकमार्गः ॥३॥ मृतपुत्रब्राह्मणी रोदिति ॥४॥ वीतमोहब्राह्मणः सम्पन्नरूपामपि शूद्रां न लुभ्यति ॥५॥ सुनीतिपुत्रः प्राप्तमतिदर्शनसाधुं गच्छति ॥६॥ प्राप्तप्रभावक्षत्रिया दृष्टमात्राञ्छत्रून्घ्नन्ति ॥७॥ जितशत्रुयोधाः शत्रुजितान्मुञ्चन्ति ॥८॥ कृतोपनयनबालः शिवादिदेवपूजां करोति ॥९॥ बुद्धगता दुःखादिसत्यानि शृण्वन्ति ॥१०॥⟫

ב) תרגמו לשנסקרית באמצעות הרכבים:

1\. קְשַׁטְרִיָה שלא אוחז במקל בידו, אינו מגן על העם.

2\. קָלִידָאסַה ושאר המשוררים הם המורים בשנסקרית.

3\. לקְשַׁטְרִיָה יש את פרנסתו באמצעות נשק.

4\. גם לנשים שׁוּדְרָה יש כדת דמיה, אמת, טהרה, אי-לחישות, אי-רשעות וסבלנות.
