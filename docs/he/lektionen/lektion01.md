### 1.2.1. על הגיית צלילים בודדים

::: laut-table
| צליל | תיאור |
| :--- | :--- |
| **a - ⟪अ⟫** | "א' קצרה" נהוג אצל ההודים -- כבר מזמן רב שנים -- להגות לעיתים קרובות כ-ə. באירופה מגיאים אותה כא' קצרה, ובבנגל כ-א' כהה קצרה. |
| **ṛ - ⟪ऋ⟫** | כמו r מוּקלית בצ'כית. הדהוד קל של i. |
| **ṝ - ⟪ॠ⟫** | כמו r מוּקלית בצ'כית. הדהוד קל של u. |
| **jñ - ⟪ज्ञ्⟫** | גם כמו dny (מראטהית) או gy (צפון הודו). |
| **ś - ⟪श्⟫** | צליל ש׳ עם קצה לשון כפוף כלפי מטה. דומה ל-sh במילה "לערבב". |
| **ṣ - ⟪ष्⟫** | צליל שׁ עם קצה לשון כפוף אחורה. לעיתים קרובות מבוטא כל כך רחוק בגרון עד שהוא נשמע כמעט כמו kh. |
| **h - ⟪ह्⟫** | צליל נשיפה, לעולם לא סימן להארכה. |
| **ḥ - :** | **ויסרגה (Visarjanīya)** -- ⟪विसर्ग⟫ / ⟪विसर्जनीय⟫. צליל נשיפה חסר קול עם הדהוד של התנועה הקודמת או החלק השני של הדפתונג הקודם: agniḥ -- ⟪अग्निः⟫ = agnihi, devaiḥ -- ⟪देवैः⟫ = devaihi, gauḥ -- ⟪गौः⟫ = gauhu |
| **ṃ** | **אנוסברה** -- ⟪अनुस्वर⟫. לפני צלילי זמזום, h, l: נטילת אף של התנועה. בסוף מילה = m. בתוך מילה לפני עיצור: האף המתאים לעיצור הבא: saṃdhi -- ⟪संधि⟫ = sandhi -- ⟪सन्धि⟫ |
:::
ההגייה הטובה ביותר מושגת כאשר קוראים את המשפטים, הפסוקים או המילים לאט יחסית ובאופן מונוטוני, תוך התחשבות מדויקת באורך התנועות.

## 1.3. תרגיל

**א) קראו את המילים הבאות:**

1. וַרְנָה בְּרָהְמָנָה קְשַׁטְרִיָה וַיְשְׁיָה שׁוּדְרָה — ⟪वर्ण⟫ ⟪ब्राह्मणः⟫ ⟪क्षत्रिय⟫ ⟪वैश्य⟫ ⟪शूद्र⟫
2. בְּרָהְמָה וִישְׁנּוּ שִׁיְוָה — ⟪ब्रह्मा⟫ ⟪विष्णु⟫ ⟪शिव⟫
3. אָשְׁרָמָה בְּרָהְמָכָרִין גְּרְהַסְתָה וָנָפְרַסְתָה סַנְיָסִין — ⟪आश्रम⟫ ⟪ब्राह्मचारिन्⟫ ⟪गृहस्थ⟫ ⟪वानप्रस्थ⟫ ⟪संन्यासिन्⟫
4. רְגְוֵדָה סָמָוֵדָה יַגְוֵדָה אַתְהַרְוֵדָה — ⟪ऋग्वेद⟫ ⟪सामवेद⟫ ⟪यजुर्वेद⟫ ⟪अथर्ववेद⟫
5. אוּפָנִישַׁד — ⟪उपनिषद्⟫
6. גִּינָה בּוּדְהָה — ⟪जैन⟫ ⟪बौद्ध⟫
7. פְּרַגְנָפָרָמִיטָה — ⟪प्रज्ञापारमिता⟫
8. צַקְרָה וָגְ'רָה — ⟪चक्र⟫ ⟪वज्र⟫
9. פִּיטְרִין — ⟪पितॄन्⟫
10. סַנְסְקְרִיטָה — ⟪संस्कृत⟫

**ב) קראו את הביטויים בסנסקריט במיון הגבהים הנ\"ל.**
