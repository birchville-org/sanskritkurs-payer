### ⟪३⟫. ציווי מסתיים ב-⟪पय⟫ (וצורות מיוחדות)

| שורש | ציווי | משמעות |
| :--- | :--- | :--- |
| ⟪स्था⟫ | ⟪स्थापयति⟫ | להציב, לקבוע |
| ⟪दुष्⟫ | ⟪दूषयति⟫ | להשחית |
| ⟪पा⟫ ⟪१⟫ (לשתות) | ⟪पाययति⟫ | לתת לשתות |
| ⟪पा⟫ ⟪२⟫ (להגן) | ⟪पालयति⟫ | לשמור, להגן |
| ⟪लभ्⟫ | ⟪लम्भयति⟫ | לאפשר לשמור |
| ⟪हन्⟫ | ⟪घातयति⟫ | לגרום להריגה, להמית |
| ⟪जि⟫ | ⟪जापयति⟫ | לאפשר ניצחון |
| ⟪जीव्⟫ | ⟪जीवयति⟫ | להחיות |
:::B) תרגמו את המשפטים הבאים וצרו באמצעות הפעלים הפשוטים משפטים המבטאים מה קורה כאשר מה שמתבטא על ידי הציווי מתממש.

⟪१⟫. **⟪शत्रुजयाय⟫ ⟪क्षत्रियो⟫ ⟪ब्राह्मणेन⟫ ⟪हरिहरं⟫ ⟪याजयित्वारीन्योत्स्यते⟫ ⟪॥१॥⟫**
הקְשַׁטְרִיָה, כדי להביס את האויבים, הורה לבִּרְהְמָן בשם הָרִי וְהָרָה להקריב קורבן, והוא יילחם באויבים.
(בסיס: **⟪ब्राह्मणो⟫ ⟪हरिहरं⟫ ⟪यजति⟫ ⟪।⟫**)

⟪२⟫. **⟪गुरुर्बालान्वेदमध्याप्य⟫ ⟪गृहं⟫ ⟪गतः⟫ ⟪॥२॥⟫**
המורה לימד את הנער את הוודה ואז הלך הביתה.
(בסיס: **⟪बाला⟫ ⟪वेदमधीयते⟫ ⟪।⟫**)

⟪३⟫. **⟪गर्भगृहे⟫ ⟪देवीप्रतिमा⟫ ⟪दर्श्यते⟫ ⟪॥३॥⟫**
בתוך הקודש הקודשים מוצגת תמונת האלה.
(בסיס: **⟪देवीप्रतिमा⟫ ⟪दृश्यते⟫ ⟪।⟫**)

⟪४⟫. **⟪यजन्नग्निनान्नमादयति⟫ ⟪पानं⟫ ⟪च⟫ ⟪पाययति⟫ ⟪॥४॥⟫**
המקריב נותן לאש אוכל לאכול ושתיה לשתות.
(בסיס: **⟪अग्निरन्नमत्ति⟫ ⟪पानं⟫ ⟪च⟫ ⟪पिबति⟫ ⟪।⟫**)

⟪५⟫. **⟪पुत्रे⟫ ⟪जाते⟫ ⟪ब्राह्मणी⟫ ⟪दासं⟫ ⟪ब्राह्मणं⟫ ⟪गमयति⟫ ⟪।⟫ ⟪ब्राह्मणस्तं⟫ ⟪दासं⟫ ⟪गृहं⟫ ⟪प्रवेश्य⟫ ⟪पुत्रं⟫ ⟪पृच्छति⟫ ⟪॥५॥⟫**
ברגע שהבן נולד, שולחת הברמןית משרת אצל הברמן. הברמן מאפשר למשרת להיכנס לבית ושואל על בנו.
(בסיס: **⟪दासो⟫ ⟪ब्राह्मणं⟫ ⟪गच्छति⟫ ⟪।⟫ ⟪दासो⟫ ⟪गृहं⟫ ⟪प्रविशति⟫ ⟪।⟫**)

⟪६⟫. **⟪स्तुवता⟫ ⟪नरेण⟫ ⟪देवा⟫ ⟪महाकवेः⟫ ⟪स्तोत्राणि⟫ ⟪श्राविताः⟫ ⟪॥६॥⟫**
האיש המהלל מביא לאלים את שירי ההלל של המשורר הגדול.
(בסיס: **⟪देवा⟫ ⟪महाकवेः⟫ ⟪स्तोत्राणि⟫ ⟪शृण्वन्ति⟫ ⟪।⟫**)

⟪७⟫. **⟪आर्ययोधैर्महायुद्धे⟫ ⟪ऽरयो⟫ ⟪मार्यन्ते⟫ ⟪॥७॥⟫**
הלוחמים האצילים הורגים באויבים בקרב הגדול.
(בסיס: **⟪अरयो⟫ ⟪म्रियन्ते⟫ ⟪।⟫**)

⟪८⟫. **⟪सत्क्षत्रिया⟫ ⟪ब्राह्मणेनेष्टदेवतापूजां⟫ ⟪कारयति⟫ ⟪॥८॥⟫**
הקשטריה הטובה מאפשרת לברמן להעריץ את האל האישי שלה.
(בסיס: **⟪ब्राह्मण⟫ ⟪इष्टदेवतापूजां⟫ ⟪करोति⟫ ⟪।⟫**)

⟪९⟫. **⟪धनं⟫ ⟪जेतुं⟫ ⟪महाक्षत्रियो⟫ ⟪योधव्याघ्रैर्व्रतानि⟫ ⟪चारयिष्यति⟫ ⟪॥९॥⟫**
כבש לסיפוק עושר, יתן הקשטריה הגדול ללוחמים הדומים לטיגריס לקיים נדרים.
(בסיס: **⟪योधव्याघ्रा⟫ ⟪व्रतानि⟫ ⟪चरिष्यन्ति⟫ ⟪।⟫**)

⟪१०⟫. **⟪पापाद्मोक्षार्थेन⟫ ⟪सुगत⟫ ⟪आर्यजनानार्यसत्यानि⟫ ⟪बोधयति⟫ ⟪॥१०॥⟫**
כדי לשחרר אותם מרע, מאפשר הבודהה לאנשים אצילים להכיר באמתות האצילות.
(בסיס: **⟪आर्यजना⟫ ⟪आर्यसत्यानि⟫ ⟪बुध्यन्ते⟫ ⟪।⟫**)
