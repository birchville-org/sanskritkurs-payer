# שיעור 47

## 47.1. האימפרטיב (⟪लोट्⟫)

::: grammar-box
הציווי (⟪लोट्⟫) מציין

*   **פקודה** (ניתן גם להביע באמצעות הגרונדיבום (⟪कृत्य⟫))
*   **תקנה**
*   **דרישה**
*   **משאלה**
*   **בקשה**
*   **הזמנה**
*   **מחשבה**
*   **שאלה**

המשמעויות הנזכרות הן משותפות לו ולאופטיב (⟪विधिलिङ्⟫).

באמצעות הציווי ניתן להביע גם:

*   **היתר**
*   **שפעולה היא בעתה** (ניתן גם להביע באמצעות הגרונדיבום (⟪कृत्य⟫))
*   **ברכה**
:::
דוגמאות:

::: indent
⟪एहि⟫ ⟪।⟫ "בוא!"

⟪ग्रामं⟫ ⟪भवानागच्छतु⟫ ⟪।⟫ או אופטיב: ⟪ग्रामं⟫ ⟪भवानगच्छेत्⟫ ⟪।⟫ "בואו לכפר!"

⟪वेदमध्ययै⟫ ⟪।⟫ או אופטיב: ⟪वेदमधीयीय⟫ ⟪।⟫ "ברצוני ללמוד את הוודה."

⟪इच्छामि⟫ ⟪भुङ्क्तां⟫ ⟪भवान्⟫ ⟪।⟫ או אופטיב:  ⟪इच्छामि⟫ ⟪भुञ्जीत⟫ ⟪भवान्⟫ ⟪।⟫ "ברצוני שיאכלו."

⟪किं⟫ ⟪वेदमध्ययै⟫ ⟪।⟫ או אופטיב: ⟪किं⟫ ⟪वेदमधीयीय⟫ ⟪।⟫ "האם עליי ללמוד את הוודה?"

⟪करोतु⟫ ⟪शस्त्रं⟫ ⟪भवान्⟫ ⟪।⟫ או גרונדיב: ⟪भवता⟫ ⟪शस्त्रं⟫ ⟪कर्तव्यम्⟫ ⟪।⟫ "הכין סכין!" ; "מותר לך להכין סכין." ; "הגיע הזמן שתכין סכין."

⟪चिरं⟫ ⟪जीवतु⟫ ⟪भवान्⟫ ⟪।⟫ "תחיה לאורך ימים!"
:::
::: grammar-box
פקודות מנומסות מובעות לעיתים קרובות באמצעות ציווי בשפה הפעילה (Passiv-Imperativ).
:::
דוגמאות:

::: indent
⟪भवता⟫ ⟪प्रविश्यताम्⟫ ⟪।⟫ "היכנס **אנא**!"

⟪निषद्यताम्⟫ ⟪।⟫ "אנא, התיישב!"
:::
בציווי של סנסקריט קלאסית, צורות האדם הראשון הן צורות קונג'ונקטיב עתיקות. הקונג'ונקטיב הוודי הוא בעיקר המשטר המביע משאלה: "ברצוננו ללכת!" "בואו נלך!"

::: grammar-box
הציווי נבנה מגזע הפרייזן.
:::

::: grammar-box

| **אדם ראשון** :br⟪तृतीयः⟫ | \-āni | \-āma | \-ai | \-āmahai |
| **אדם שני** :br⟪मध्यमः⟫ | \-ø / \-tāt¹ | \-ta | \-sva | \-dhvam |

הערה: ¹ את סיומות הגוף השני והשלישי יחיד ניתן להחליף ב- -tāt, כאשר יש צורך לבטל משאלה לברכה:

::: indent

ב.) תרגמו לסנסקריט (השתמשו בציווי):

1\. אני רוצה להישמע.

2\. הוא צריך להיות מרוצה.

3\. אנחנו רוצים לקרוא.

4\. אני רוצה להכריע בפניך (⟪चतुर्थ्या⟫).

5\. מעשה זה צריך להיעשות.

6\. הם צריכים לישון (מבנה פסיבי).

7\. בניי יבקש עושר!

8\. התחילו את הלימודים!

9\. תנו (⟪प्र⟫-⟪यम्⟫) לאבות אורז כדורי!

10\. הם צריכים להתענג!

11\. אני רוצה להביט אל העולם.

12\. אנחנו רוצים ללכת לבנרס (⟪पद्⟫).

13\. הם (רבים) צריכים להכבד את האלים בקורבן כמארחי קורבן.

14\. שירו שיר הלל!

15\. בני צריכים להיוולד לי!

16\. אני רוצה להראות לך את ביתי.

17\. לך ממני!

18\. הוא צריך להשתחרר!

19\. אני רוצה לשמור על אשתך.

20\. מת, אויב!

21\. קרבו!

22\. הם (רבים) ירצו להורות.

23\. אנחנו רוצים לגור בביתך.

24\. כך צריך לקרות!

25\. הכה את הסוס!

26\. הם (רבים) צריכים להסתובב.

27\. השתכרו!

28\. הסוס צריך לגרור את המשא.

29\. אנחנו רוצים לסדר את העולמות.

30\. שתו את המשקה!

31\. חשבו!

32\. הם (רבים) צריכים להיכנע!

33\. אנחנו רוצים להובל על ידיך.

34\. שיהיה לברכה (יקרה)! (ברכה)
