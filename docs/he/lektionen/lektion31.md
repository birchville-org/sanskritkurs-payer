# שיעור 31

## 31.1. מחלקת ההווה השביעית (⟪רודהאדי⟫ = "⟪רודה⟫ וכו'")

::: grammar-box
**בנייה:**

**לפני עיצורים סופיים של שורש ברמת צליל נמוכה, מוחדר כהגיה כהתקף אף (-na- או -n-):**

*   **בשורש החזק: -na-**
*   **בשורש החלש: -n-**

**עבור חיבור התנוקות הסופיות של השורש עם סיומות המתחילות בעיצור, חלים אותם הכללים כמו עבור מחלקת הנוכחית השנייה.**
:::
