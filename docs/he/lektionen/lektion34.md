# שיעור 34

## 34.1. הפרפקט (⟪ליט⟫)

בסנסקריט קלאסית קיימים מהשורש של הופע רק יידוע ומשתתף.

::: grammar-box
**קיימות שתי דרכים לבניית הניקוד:**
*   **ניקוד כפול = ⟪द्वित्वलिट्⟫**
*   **ניקוד פריפראסטי = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**משמש ה-periphrastische Perfekt (⟪अनुप्रयोगलिट्⟫):**
1. **בזמן conjugations גזורים (Kausativ, Desiderativ, Frequentativ, Denominativa)**
2. **על שורשים המתחילים בתנועה ארוכה (למעט ā-) או בתנועה (למעט a-) לפני שתי עיצורים**
3. **על כמה שורשים אחרים**
:::
## 34.2. הפרפקט המוכפל (⟪דוויטוואליט⟫)

### 34.2.1. דירוג הגזע

::: grammar-box
**חינוך:**

**שורש חזק:** יחיד פרסמאפדה
*   **שורש מרופד בדרגה גבוהה או מוארכת + סיומת אידיאמה**

**שורש חלש:** כל הצורות האחרות
*   **שורש מרופד בדרגה נמוכה + סיומת אידיאמה**
:::
::: grammar-box
**באופן כללי (גם מחוץ לאידיאמה) אין הנמכת שורש לשורשים מהצורה:**
*   **(עיצור)-עיצור-תנועה ארוכה-עיצור**
*   **(עיצור)-עיצור-תנועה-עיצור-עיצור**

**באידיאמה, בנוסף, אין הנמכת שורש לשורשים מהצורה:**
*   **א-עיצור**
*   **אה-עיצור**
:::

### 34.2.3. תנועת קישור -i-

::: grammar-box
**לפני הסיומת של גוף שלישי רבים (-re) תמיד באה התנועה המחברת -i-, ולפני שאר הסיומות המתחילות בעיצור אצל רוב השורשים.**
:::
### 34.2.4. כפולת שורשים המתחילים בעיצור

::: grammar-box
**לכפולת עיצורים מתחילים חלים הכללים שניתנו ב[שיעור 33](lektion33.md).**

**תנועת הכפולה בשורשים המתחילים בעיצור היא תנועת השורר הקצרה.**

**דיפתונגים שלפני עיצור מצטמצמים לתנועת נמוכה קצרה מתאימה.**

**ṛ, ṝ, ḷ ודיפטונגים בסוף הברה מרופדים באמצעות -a-.**
:::
