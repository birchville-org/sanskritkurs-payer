# שיעור 19

## 19.1. פסוקית זיקה

::: grammar-box

**סכמה:**

**שם תואר יחס -- משפט יחס הכולל את השם אליו מתייחס משפט היחס -- (שם תואר הדגשה) -- משפט ראשי**

**משפט היחס יכול גם לבוא לאחר המשפט הראשי, אך לא ניתן להכניסו לתוך המשפט הראשי.**

**הכינוי היחסי והמילה היחסית, שכן — בניגוד לגרמנית — נמצאת במשפט היחסי, נמצאות במשפט שמשפט היחסי דורש תחבירית. הכינוי הדemonstrative נמצא במשפט שמשפט הראשי דורש תחבירית.**
:::

דוגמאות:

הערה: בביטויים יחסים בעלי תוקף כללי, נהוג להשתמש בזמן האופטיבי במקום בזמן האינדיקאטיבי. לכן, רבים מהדוגמאות שלנו היו מועדפות להיות בניסוח אופטיבי.

**1. הנושא (⟪कर्तृ⟫) של המשפט מוגדר על ידי משפט יחס:**

::: indent
⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪स⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫ =  ⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ = ⟪येन⟫ ⟪नरेण⟫ ⟪पुण्यम्⟫ ⟪क्रियते⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ וכו' = "אדם שעושה מעשים זכאיים בא לשמים."
:::
**2. אובייקט ישיר (⟪कर्म⟫) של הצירוף הראשי נקבע על ידי הצירוף היחסי:**

::: indent
⟪यो⟫ ⟪ब्राह्मणो⟫ ⟪देवान्यजते⟫ ⟪तं⟫ ⟪देवा⟫ ⟪रक्षन्ति⟫ = "אלוהים מגינים על ברהמן המקריב להם קורבן כבעל הקורבן."
:::
הערה: בביטויים יחסים בעלי תוקף כללי מועדף השימוש בלשון משאלה (אופטיבי) במקום בלשון קביעה (אינדיקטיבי). לפיכך, רבים מדוגמאותינו היו מוצגים באופן מועדף בלשון משאלה.

::: indent
⟪ये⟫ ⟪नराः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪तेषां⟫ ⟪पुत्रा⟫ ⟪धनं⟫ ⟪न⟫ ⟪लभन्ते⟫ = "בני גברים שעושים רע אינם זוכים לעושר."
:::
**4. שם תואר יחס ומילה יחסית נמצאים בגניטיב (⟪षष्ठी⟫):**

::: indent
⟪यस्य⟫ ⟪नरस्य⟫ ⟪पुत्राः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪स⟫ ⟪न⟫ ⟪सुखवान्⟫ = "לא גבר מאושר שכן עושים רע."
:::
**5. תואר־היחס ומילת־היחס נמצאים בְּכֶלִי (⟪तृतीया⟫):**

::: indent
⟪येन⟫ ⟪शत्रुणा⟫ ⟪ग्रामो⟫ ⟪जितस्तं⟫ ⟪द्विषन्ति⟫ = "הם שונאים את האויב שכבש את הכפר שלהם."
:::
**6. תארים יחס ומילה יחסית נמצאים במצב תחילה (⟪द्वितीया⟫):**

::: indent
⟪यं⟫ ⟪नरं⟫ ⟪देवी⟫ ⟪रक्षति⟫ ⟪स⟫ ⟪सुखमाप्नोति⟫ = "אדם שאלוהה מגינה עליו זוכה למזל."
:::

## 19.3. רשימת מילים

**⟪अर्थ⟫ m.:** מטרה, יעד, משמעות (של מילה), עושר, רכוש, הון. **⟪अर्थम्⟫** (אק'), **⟪अर्थेन⟫** (אינס') עם גנ' או כהרכב מאוחר של טטפורוס: למען ... כדי.

**⟪अर्थ⟫** הוא אחד משלושת יעדי החיים (**⟪पुरुषार्थ⟫**), כפי שהם מתוארים בספרות החילונית והדתית:

**⟪काम⟫ m.:** תענוגות חושים, במיוחד גם בתחום המיני

## 19.4. תרגיל

**תרגם לסנסקריט:**

1\. אשת הוֹיָשָׁה, שבנה מתה, בוכה.

רָמָה מקריב קורבן לאלוהות השומרת עליו.

3\. המשורר משבח את הַכְּשַׁטְרִיָה, שאת עושרו הוא חפץ.

4\. אש שורפת את ביתו של האיש המכבד את אגני בקורבן.

5\. האיש הדומה לנמר הורג את לוחמי הכושטריה, שרמא ניצח (פסיב).
