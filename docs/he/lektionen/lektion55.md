# Lektion 55

## 55.1. Der a-Aorist (Aorist mit Themavokal)

::: grammar-box
**האָ-אָוריסט נבנה כמו אימפרפקט (⟪लङ्⟫) של כיתה השישית של הפרסנס (⟪तुदादि⟩), כלומר:**

**אוגמנט + שורש במצב נמוך + a + סיומת משנית**

**ה-a- מוחלף ב-ā- באותן צורות כמו באימפרפקט.**

**ללא אינפיקס נשימה.**

**האָטמנפדה נדיר; לשורשים אוּבְהַיָּפָּדָה הוא נבנה לרוב לפי כיתות אָוריסט אחרות (ראה קילהורן, דקדוק §340 וכן להלן בכיתות האָוריסט הרלוונטיות).**

**רשימת השורשים בעלי אָוריסט זה, אצל קילהורן, דקדוק §340.**
:::
