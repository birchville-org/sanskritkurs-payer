# שיעור 28

## 28.1. הקאוזטיב (⟪ני⟫, ⟪ניצ'⟫, ⟪קאריטא⟫)

::: grammar-box
**כדי לבטא שאדם או דבר גורם לאחר או לדבר אחר לעשות או לסבול פעולה המתוארת על ידי שורש (עם או בלי קידומת), משתמשים בצורת ההִפְעִיל (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫).**

דוגמה:
⟪गम्⟫ "ללכת" » הִפְעִיל: ⟪गमयति⟫ "הוא גורם למישהו ללכת; הוא שולח"
⟪दृश्⟫ "לראות" » הִפְעִיל: ⟪दर्शयति⟫ "הוא גורם לראות = הוא מראה"
:::

## 28.2. בניית משפט עם הקאוסטיב (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**סכמה 1:**

**אם השורש שעליו מבוסס הפיעול (עם או בלי קידומת) הוא לא-מעבר (כלומר, אינו יכול לקחת מושא במצב תחבירי) או שהוא מביע תנועה, ידע, מידע או אכילה:**

**הסוגר (⟪कर्ता⟫) של הקאוזטיב בנרד (⟪प्रथमा⟫) — הסוגר של הפעולה המיוזמת באקוזטיב (⟪द्वितीया⟫) — (יעד התנועה, חפץ הידיעה וכו׳ באקוזטיב = ⟪द्वितीया⟫) — הפועל בקאוזטיב**
:::
דוגמאות:

⟪दुर्जनो⟫ ⟪रामं⟫ ⟪मोहयति⟫ = "אדם רע גורם שרמה מבלבל = מבלבל את רמה = גורם שרמה טועה"

⟪रामः⟫ ⟪शत्रून्स्वर्गं⟫ ⟪गमयति⟫ = "רָמָה עוֹשָׂה אֶת הָאוֹיְבִים לָלֶכֶת לַשָּׁמַיִם = שׁוֹלֵחַ אֶת הָאוֹיְבִים לַשָּׁמַיִם"
תוצאה: ⟪शत्रवः⟫ ⟪स्वर्गं⟫ ⟪गच्छन्ति⟫ = "הָאוֹיְבִים הֵם הוֹלְכִים אֶל הַשָּׁמַיִם / בָּאִים אֶל הַשָּׁמַיִם"

## 28.3. בניית שורש הנוכח של הקאוסטיב (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**לשורש הסיבתית נוספות הסופיות התמטיות של שורש הנקודה**
:::
ישנם סוגי חינוך שונים:

::: grammar-box
**סוג בנייה 1: (ברוב המקרים) שורש ברמה גבוהה + -aya-**
:::
דוגמאות:

| שורש | גוזם 3. יח' יחיד הוה | משמעות |
| :--- | :--- | :--- |
| ⟪विश्⟫ | ⟪वेशयति⟫ | הוא/היא/זה גורם לכניסה, מוביל פנימה |
| ⟪लुभ्⟫ | ⟪लोभयति⟫ | לשאוף, לגרום לתשוקה, לפתות |
| ⟪दृश्⟫ | ⟪दर्शयति⟫ | להראות = להציג |
| ⟪वृत्⟫ | ⟪वर्तयति⟫ | לגרום לסבב, להפוך (במובן העברת), לגלגל (במובן העברת), להניע לגלגול |

::: grammar-box
**סוג בנייה 2: שורש עם דרגה מוארכת + -aya-**

**לעיתים קרובות אצל שורשים המסתיימים בתנועה, ואצל שורשים שאחרי -a- באה עיצור סופי יחיד.**
:::
דוגמאות:

| שורש | קאוסטיב 3. יח' אינדיקטיב פרזנס | משמעות |
| :--- | :--- | :--- |
| ⟪भू⟫ | ⟪भावयति⟫:br(aus: bhau-aya-ti) | לגרום לכך שמישהו או משהו יהפוך, לייצר |
| ⟪इ⟫ | ⟪आययति⟫:br(aus: ai-aya-ti) | גורמים לכך שמישהו הולך |
| ⟪नी⟫ | ⟪नाययति⟫:br(aus: nai-aya-ti) | להוביל |
| ⟪कृ⟫ | ⟪कारयति⟫:br(kār-aya-ti) | לגרום |
| ⟪वच्⟫ | ⟪वाचयति⟫:br(vāc-aya-ti) | לגרום לדבר, להפוך לדובר, (לקרוא טקסט בקול =) לקרוא בקול |

::: grammar-box
**סוג בנייה 3: שורש בעומק נמוך + -aya-**

**מגיע.**
:::
דוגמה:

| שורש | קאוסטיב 3. יח' אינדיקטיב פרזנס | משמעות |
| :--- | :--- | :--- |
| ⟪दुष्⟫ | ⟪दूषयति⟫:br(dūṣ-aya-ti) | (לְהַשְׁחִית) |

::: grammar-box
**סוג בניין 4: שורש + -paya-**

**על שורשים המסתיימים ב-ā וכמה שורשים אחרים.**
:::
דוגמאות:

| שורש | קאוסטיב 3. יח' אינדיקטיב פרזנס | משמעות |
| :--- | :--- | :--- |
| ⟪स्था⟫ | ⟪स्थापयति⟫:br(sthā-paya-ti) | להקים, להציב |
| ⟪इ⟫ + ⟪अधि⟫:br"studieren" | ⟪अध्यापयति⟫:br(aus: adhi+ā-paya-ti):br(zur Erklärung siehe Thumb-Hauschildt Bd. I,2 S. 341) | לגרום ללמידה, ללמד |

::: grammar-box
**צורות לא סדירות:**

**דקדקנים מקומיים רואים בצורות הבאות גורמים:**

- **han** : גורם. **ghātayati**¹ "להכות, לגרום למות"
- **pā** 2 "לשמור": **pālayati**² "להעביר, להציל, להגן"
:::
הערות:
1. **ghātayati** הוא פועל מדרג שני, הנגזר מהשם **ghāta** m. "מכה" (denominativum) ומשמש במקום הגורם של **han**.
2. **pālayati** הוא גורם אמיתי, אך מהשורש **pṛ** 3 "להעביר, להציל, לשמור": **pārayati** (pār-aya-ti) » **pālayati** (בחלקים מסוימים של הודו r מקביל ל-l, ובחלקים אחרים להפך, l מקביל ל-r).

## 28.4. בניית הפעל הסביל (⟪यक्⟫) לגורם

::: grammar-box
**הפסיב של הקאוזיטיב נוצר כך:**

**שורש הסיבתיות ללא -aya- + סיומת הפעלה -ya-**

דוגמאות:
**bhāvyate** (bhāv-ya-te) "הוא/היא/זה נוצר"
**sthāpyate** (sthāp-ya-te) "הוא/היא/זה מוצב"
:::
בעוד שהפעיל הפסיבי בדרך כלל נגזר מהשורש ברמתו הנמוכה ביותר, ניתן לזהות בדרך כלל את הפעיל הפסיבי של הסיבת על כך שהוא נגזר מהשורש ברמה הגבוהה או המודגשת.

## 28.5. בניית העתיד (⟪ऌट्⟫, ⟪भविष्यन्ती⟫ f.) לגבי הסיבת

::: grammar-box
**עתיד של הפיעול נבנה משורש ההפיעול, כאשר הסיומת -a- בסוף ההפיעול נופלת:**

**-ay-iṣya-**

דוגמה:
**budh** עתיד-פיעל: **bodhayiṣyati** (bodh-ay-i-ṣya-ti): "הוא/היא/זה יעיר"
:::

## 28.6. בניית ה-PPP (⟪क्त⟫) לגורם

::: grammar-box
**שורש הסיבתיות בסיומת -ay- (ללא a בסוף) + -i- + -ta**

דוגמאות:
**gam** — **gamayati** — **gamita** (gam-i-ta) "נשלח" (PPP של השורש הפשוט: **gata**)
**sthā** — **sthāpayati** — **sthāpita** (sthāp-i-ta) "הוצב"
:::

## 28.7. יצירת האבסולטיב (⟪क्त्वा⟫ . ⟪ल्यप्⟫) לקאוזטיב

::: grammar-box
**הבינוי עם -tvā נבנה מהשורש הסיבתוני עם -ay- (ללא a בסוף):**

**שורש הסיבתיות על -ay- + -i- + -tvā**

דוגמה:
**sthāpayitvā** (sthā-pay-i-tvā) "לאחר שהקים"
:::
::: grammar-box
**האבסולטיבום על -ya מופיע בדרך כלל בצירופי סיבה עם פריקס עם שורש הסיבה בלי -aya**

דוגמאות:
**prabudh** — **prabodhayati** — **prabodhya** (pra-bodh-ya) "לאחר שהעיר"
**ānī** — **ānayati** — **ānāyya** (ā-nāy-ya) "לאחר שהתיר להביא, לאחר שהתיר להביא"
:::
::: grammar-box
**עם זאת, אם צלע השורש של הפיעול מכילה א'-קצרה לפני עיצור יחיד, נוספת סיומת האבסולוטיום -ya לשורש הפיעול -ay- (ללא א'-סופית)**

דוגמה:
**āgam** — **āgamayati** — **āgamayya** (ā-gamay-ya) "לאחר שהתיר לו לבוא"
:::

## 28.8. בניית האינפיניטיב (⟪तुमुन्⟫) לגורם

::: grammar-box
**אינפיניטיב של קאוזטיב נבנה משורש הקאוזטיב בסיומת -ay- (ללא א' סופית):**

**שורש הסיבת -ay- + -i- + -tum**

דוגמה:
**jan** — **janayati** — **janayitum** (janay-i-tum) "כדי לייצר"
:::

## 28.9. מחלקת ההווה העשירית (⟪צ'וראדי⟫ = ⟪צ'ור⟫ וכו')

::: grammar-box
**באותה מידה שבה פועלים בגזירה עושים את הזמן הנוכחי (וגם את הזמנים האחרים) כמה שורשים של מחלקת הזמן העשירית, בלי גזירה.** :::

דוגמאות:
1.  שורש עם דרגת הארכה + -aya- : **⟪कम्⟫** 10Ā **⟪कामयते⟫** "לאהוב"
2.  שורש בדרגת חוד (Guna) + -aya- : **cur** 10U **corayati** "לגנוב"; עתיד: **corayiṣyate**; פסיבי: **coryate**
:::
::: grammar-box
**צורות הסיבתיות לזמרים של מחלקת ה-10 של זמן הנוכחי זהות לצורות הפועל הפשוט. ההחלטה האם קיימת סיבתיות אפשרית רק מהמשמעות או לפעמים מהמבנה.** :::
:::
