# שיעור 50

## 50.1. תצורה שמנית: דרגות השוואה רגילות

::: grammar-box
**ההשוואה הסדירה מתבצעת בסנסקריט עם הסיומות ⟪तद्धित⟫**
* **-⟪तर⟫ (נק': ⟪तरा⟫) ב"דרגת ההשוואה" (Comparative)**
* **⟪तम⟫ (נק': ⟪तमा⟫) ב"דרגת העליונות" (Superlative)**

**סיומות אלו נצמדות לשורש הזכר של תארים. בשמות עצם עם שינויי שורש (Guna/Vrddhi), הן נצמדות לשורש החלש, בעל הצורה כמו לפני הסיומת -su של המקום (⟪पञ्चमी⟫) ברבים.**
:::
::: media
![](/images/lekt5007.webp)
איור: ⟪लोकस्योत्तमो⟫ ⟪गिरिः⟫
⟪सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = Har Mount Everest
(מקור התמונה: [פרטים](/he/licenses#lekt5007))
:::

::: grammar-box
**משמעות:**

**"דרגת ההשוואה" (Comparative) משמעה, כאשר לא מבוטא חפץ להשוואה: "יחסית, מאוד, מדי":**

:::
::: indent
לדוגמה: ⟪सुचितर⟫ 3 "טהור יחסית", "טהור מאוד", "טהור מדי"
:::
**כאשר מבוטא חפץ להשוואה, זה נמצא במשלים (⟪पञ्चमी⟩). דרגת ההשוואה + משלים מקבילים להשוואה עם "מ-" בגרמנית.**

::: indent
לדוגמה: ⟪देवदत्ताद्रामो⟫ ⟪धीमत्तरः⟫ = מיל': "מנקודת מבטו של דבדטה, ראמה הוא בעל שיקול דעת יותר" = "ראמה בעל שיקול דעת יותר מדבדטה"
:::
**"דרגת העליונות" (Superlative) משמעה, כאשר לא מבוטא חפץ להשוואה: "במיוחד, מאוד":**

::: indent
לדוגמה: ⟪सत्तम⟫ 3 (ל⟪सन्त्⟫) "טוב ביותר, טוב מאוד"
:::
**כאשר מבוטא חפץ להשוואה, זה נמצא בבעלות (⟪षष्ठी⟫) ("של", "בין") ודרגת העליונות מקבילה לדרגת העליונות הגרמנית (רמת השיא):**

::: indent
לדוגמה: ⟪द्विजानां⟫ ⟪सत्तमः⟫ = "הטוב ביותר מבין פעמי הלידה"
:::
**הסיומות -⟪तर⟫ ו-⟪तम⟫ יכולות להופיע לא רק בתארים, אלא גם בשמות עצם, מילים בלתי משתנות ואפילו בצורות פועל:**

דוגמאות:

::: indent
⟪गजतम⟫ ז. "הפיל הטוב ביותר" (⟪गज⟫) (כינוי לבודהה)

⟪गोतम⟫ ז. "השור הגדול ביותר" (⟪गो⟫) או: "העשיר ביותר בשורים"

⟪उद्⟫ בלתי משתנה "למעלה", "למעלה" » ⟪उत्तर⟫ 3 "גבוה יותר" » ⟪उत्तम⟫ 3 "הגבוה ביותר"
:::
**כאשר סיומות אלו נצמדות לצורת פועל, הן תמיד מופיעות בצורה מילתית (Adverbial):**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

דוגמאות:

::: indent
⟪पचतितराम्⟫ "הוא/היא/זה בישל טוב יותר"

⟪पचतितमाम्⟫ "הוא/היא/זה בישל הטוב ביותר"
:::
**צורה זו יש לסיומות אלו גם כאשר הן נצמדות למילה בלתי משתנה והמילה הנגזרת משמשת בצורה מילתית:**

::: indent
לדוגמה: ⟪सुतराम्⟫ (ל⟪सु⟫) "באופן טוב יותר" (בצורה מילתית)
:::
