# שיעור 57

## 57.1. אאוריסט 4: s-אאוריסט

::: grammar-box
**הס-אָאוֹרִיסט נבנה לשורשי ⟪अनिट्⟫ רובם המוחלט, כל עוד אין להם צורת אָאוֹרִיסט אחרת בלבד. שורשי ⟪अनिट्⟫ אופציונליים יכולים בדרך כלל לבחור בין בניית הס-אָאוֹרִיסט לבין אָאוֹרִיסט אישִׁיס. גם שורשי ⟪अनिट्⟫ היוצרים את ⟪परस्मैपद⟫ לפי הצורה הראשונה, השנייה או השישית של האָאוֹרִיסט, יוצרים את ⟪आत्मनेपद⟫ לפי הס-אָאוֹרִיסט.**

**בנייה: אוֹגְמֶנט + שורש + s + סיומת סֶתְמָטית משנית**
:::
טבלת סיומות עם סיומת בניית שורש

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟫** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟫** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**חל עליה הכלל הפונטי הכללי, לפיו חריק בין שתי עצירות נופל (ראה ⟪⟪उद्⟫⟩ + ⟪⟪स्थित⟫⟩ » ⟪⟪उत्थित⟫⟩), כלומר סיומת בניית השורש -s- נופלת לפני סיומות המתחילות ב-t- או th- (לא לאחר נחצי או r-).**

דוגמאות:

:::
::: indent
3.ש.כ.Ā a-kṣip + s + ta » ⟪⟪अ⟫⟩***⟪⟪क्षिप्त⟫⟩***
2.ש.כ.Ā a-kṣip + s + thās » ⟪⟪अ⟫⟩***⟪⟪क्षिप्था⟫⟩***⟪⟪स्⟫⟩
:::
צורות כאלה עשויות גם שייכות לאאוריסט של השורש, וסביר להניח שהן אכן שייכות לשם בחלק מהמקרים.
לדקדוקים ההודים היו גם צורות כמו ⟪⟪अकृत⟫⟩ (3.ש.כ.) ששייכות לס-אָאוֹרִיסט, שברור ששייכות לאָאוֹרִיסט שורש. למטרה זו המציאו הדקדוקים ההודים את כלל הפונטי הבא עבור הס-אָאוֹרִיסט:

::: indent
"לאחר תנועה קצרה, הסיומות המתחילות ב-st- או sth- מאבדות את ה-s-."
:::
בשאר המקרים יש לשים לב לכללי הפונטיים לחיבור עיצורים מסתיימים עם s-.

עבור -dhvam חל:

::: grammar-box
**ה-dh- של -dhvam מוחלף ב--ḍh- לאחר כל התנועות שאינן a/ā, וגם לאחר -r.**

:::
::: indent
למשל, ***⟪⟪चि⟫⟩*** 5U: 2.ר.כ.Ā ***⟪⟪अचेढ्वम्⟫⟩***
:::
::: grammar-box
**ה-dh- של -dhvam מוחלף ב-ḍh- לאחר כל התנועות שאינן a/ā, וגם לאחר -r.**

*   **⟪⟪परस्मैपद⟫⟩ : דרגת הארכה**
*   **⟪आत्मनेपद⟫ :**
    *   **צורת השורש:**
    *   **שורשים עם i/ī/u/ū בסוף: דרגה גבוהה**
    *   **-ṝ בסוף מוחלף ב-īr או -ūr**
    *   **שורשים עם ablaut על ā/e/o: דרגה נמוכה**
:::
