# שיעור 57

## 57.1. אאוריסט 4: s-אאוריסט

::: grammar-box
**ה-s-אאוריסט נוצר לשורשים רובם המוחלט של ⟪अनिट्⟫, כל עוד הם אינם בעלי צורת אאוריסט אחרת בלבד. שורשים של ⟪अनिट्⟫ יכולים בדרך כלל ליצור באופן אופציונלי את ה-s-אאוריסט או את ה-iṣ-אאוריסט. גם שורשים של ⟪अनिट्⟫, היוצרים את ה-⟪परस्मैपद⟫ לאחר הצורה הראשונה, השנייה או השישית של האאוריסט, יוצרים את ה-⟪आत्मनेपद⟫ לפי סדר האאוריסט.**

**יצירה: אוגמנט + שורש + s + סיומת משנית אתמטית**
:::
טבלת סיומות עם תחילית יצירת שורש

::: grammar-box

|   | ⟪परस्मैपदम्⟩ || ⟪आत्मनेपदम्⟩ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟩ | ⟪बहुवचनम्⟩ | ⟪एकवचनम्⟩ | ⟪बहुवचनम्⟩ |
| **1. ⟪तृतीयः⟩** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟩** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟩** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**חל החוק הכללי של שינוי הצליל, לפיו צליל זז בין שני עיצורי עצירה נופל (ראה ⟪उद्⟩ + ⟪स्थित⟩ » ⟪उत्थित⟩), כלומר תחילית יצירת השורש -s- לפני סיומות המתחילות ב-t- או th- נופלת (לא לאחר אפיים או r-).**

דוגמאות:

:::
::: indent
3.sg.Ā a-kṣip + s + ta » ⟪अ⟩:sig[⟪क्षिप्त⟩]
2.sg.Ā a-kṣip + s + thās » ⟪अ⟩:sig[⟪क्षिप्था⟩]⟪स्⟩
:::
צורות כאלה יכולות גם שייכות לאאוריסט השורש וסביר להניח חלקן אכן שייכות אליו.
הדקדוקאים ההודים גם ספרו צורות כמו ⟪अकृत⟩ (3.sg.Ā) ל-s-אאוריסט, שהן חד משמעית שייכות לאאוריסט השורש. למטרה זו המציאו הדקדוקאים ההודים את חוק השינוי הבא של הצליל באופן ad-hoc עבור ה-s-אאוריסט:

::: indent
"בעלי תנועה קצרה מאבדים את הסיומות המתחילות ב- -st- או ב- -sth- את ה- s-."
:::
אחרת יש לשים לב לכללי הצליל לחיבור של עיצורים מסתימים עם s-.

עבור -dhvam תקף:

::: grammar-box
**ה- dh- של -dhvam מוחלף ב- ḍh- לאחר כל התנועות שאינן a/ā וגם לאחר -r.**

:::
::: indent
למשל: :sig[⟪चि⟫] 5U: 2.pl.Ā :sig[⟪अचेढ्वम्⟫]
:::
::: grammar-box
**צורת השורש:**

*   **⟪परस्मैपद⟫ :דרגת הארכה**
*   **⟪आत्मनेपद⟫ :**
*   **שורשים עם i/ī/u/ū בסוף: דרגה גבוהה**
*   **-ṝ בסוף מוחלף ב- īr או -ūr**
*   **שורשים עם ablaut על ā/e/o: דרגה נמוכה**
*   **תנועות שורש אחרות: ללא שינוי (כלומר בדרך כלל בדרגה נמוכה)**

**⟪अगसि⟫ (« \*a-gm-si) ⟪। अगथास् । अगत⟫ (ב-P ל-⟪गम्⟫ יש את האָאוריסט התימטי)**

2. ⟪पद्⟫ 4Ā הוא בצורה סדירה (למשל, ⟪अपत्सि⟫), אך בגוף שלישי יחיד של Ā הוא מקבל את צורת העבר שורש פסיבי:
⟪अपादि⟫ "הוא הלך"

⟪अबोधि⟫ / ⟪अबुद्ध⟫ "הוא הכיר"
