# שיעור 22

## 22.1. האבסולטיבי (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

אם רוצים להביע בסנסקריט שפעולה של הפועל (⟪कर्तृ⟫) קודמת לפעולה אחרת של אותו הפועל או מתרחשת במקביל לה כנסיבות מלוות, משתמשים באבסולטיבי (⟪क्त्वा । ल्यप्⟫). כלומר

"לאחר שעשה זאת, הוא עושה את זה"; "הוא עושה את זה ואז עושה את זה"; "בגלל זה הוא עושה את זה"; "באתי, ראיתי וניצחתי" וכדומה.

האבסולטיבי הוא אדבריום פועלי, כלומר אינו מוטעם ולא משתנה בדקלנציה, אך תמיד – עם מעט חריגים – יש לו את אותו הפועל (⟪कर्तृ⟫) כמו לפעולה שהפעולה המצוינת באבסולטיבי קודמת לה או מלווה אותה. הפועל של האבסולטיבי נמצא אפוא במתן (⟪प्रथमा⟫) או באינסטרומטליס (⟪तृतीया⟫).

לצד הקומפוזיטה, האבסולטיבי הוא אחד הכלים הנפוצים ביותר לביטוי בסנסקריט.

בעת תרגום לגרמנית יש להימנע משימוש מתמיד במילה "לאחר". במקום זאת יש להשתמש בביטויים המקובלים בגרמנית לסידור זמן.

**סכמה:**

(קביעה מדויקת יותר לאבסולטיבי: קביעת נסיבות, אובייקט וכו') - אבסולטיבי - אבסולטיבי - ... - אבסולטיבי - ... פועל + משפט פעולה (באקטיב או בפסיבי)

:::
**דוגמאות:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = מבנה פסיבי: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**
"האדם נכנס לבית, רואה את הילדה הקטנה ומדבר אליה."

רבים: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. יצירת האבסולוטיבי

::: grammar-box
**יצירת האבסולוטיבי**

*   פועל ללא פרפיקסה: אבסולוטיבי מסתיים ב-**tvā**
*   פועל עם פרפיקסה: אבסולוטיבי מסתיים ב-**ya** או **-tya**
:::
### 22.2.1. פועל ללא פרפיקסה: אבסולוטיבי מסתיים ב-⟪त्वा⟫

::: grammar-box

**יצירה:**

(בדרך כלל) שורש במצב נמוך בצורתו, כפי שהוא מופיע לפני ה-PPP + **-tvā** (**-⟪त्वा⟫**)

רק השלילה **a-** / **an-** תואמת את הסיומת **-⟪त्वा⟫** : ⟪अकृत्वा⟫ "ללא ביצוע פעולה"

:::
**דוגמאות:**

::: indent
⟪आप्त्वा⟫ "לאחר שהגיע" (זכר/נקבה/ניטרלי, יחיד/רבים)

⟪आसित्वा⟫ "לאחר שהתיישב"

⟪इत्वा⟫ "לאחר שהלך"

⟪स्थित्वा⟫ "לאחר שעמד"

⟪जित्वा⟫ "לאחר שהשיג ניצחון"

⟪उक्त्वा⟫ "לאחר שדיבר"
:::
### 22.2.2. פועל עם פרפיקסה

#### 22.2.2.1. שורשים המסתיימים בתנוכה ארוכה (למעט -ā) או בעיצור

::: grammar-box

**(בדרך כלל) שורש במצב נמוך + -ya**

:::
**דוגמאות:**

::: indent
⟪उपनीय⟫ "לאחר שהביא"

⟪प्रभूय⟫ "לאחר שהציץ החוצה" / "לאחר ששלט בכוח"

⟪प्राप्य⟫ "לאחר שהשיג"
:::
#### 22.2.2.2. שורשים המסתיימים ב-ā

::: grammar-box

**שורש במצב גבוה ללא שינוי + -ya**

:::
**דוגמה:**

::: indent
⟪उपस्थाय⟫ "לאחר שנכנס" ; (אך ללא פרפיקסה: ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. שורשים המסתיימים במצב נמוך ב-i קצר, -u, או -ṛ

::: grammar-box

**שורש ברמה הנמוכה ביותר + -tya**

:::
**דוגמאות:**

::: indent
⟪प्रस्तुत्य⟫ "לאחר ש(...) שיבח בקול / היה משיב"

⟪विस्मृत्य⟫ "לאחר ש(...) שכח / היה שוכח"

⟪संस्कृत्य⟫ "לאחר ש(...) הכין לקורבן / היה מכין"
:::
#### 22.2.2.4. שורשים המסתיימים ב- -am / -an, אשר ברמה הנמוכה ביותר מסתיימים ב- a

::: grammar-box

**אופציונלי:**

שורש המסתיים ב- **-am** / **-an** + **-ya**

או:

שורש המסתיים ב- **-a** + **-tya**

:::
**דוגמה:**

::: indent
⟪विगम्य⟫ או ⟪विगत्य⟫ "לאחר ש(...) עבר / היה עובר"
:::
