# שיעור 22

## 22.1. האבסולוטיב (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫)

::: grammar-box

כדי לבטא בסנסקריט שמעשה של הפועל (⟪कर्तृ⟫) קודם למעשה אחר של אותו הפועל, או שהוא מתרחש במקביל כנסיבה מלווה, משתמשים באבדטיב (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫). כלומר

«אַחַר שֶׁעָשָׂה זֹאת, הוּא עוֹשֶׂת אוֹתָה»; «הוּא עוֹשֶׂת זֶה, אַחַר מָּכָן הוּא עוֹשֶׂה אוֹתָה»; «בְּמַעֲשֵׂה זֶה הוּא עוֹשֶׂה אוֹתָה»; «בָּאתִי, רָאִיתִי וְכָבַשְׁתִּי» וכו'.

האבסולוטיוּם הוא אדברבֵּלִי, כלומר אינו מוטֶה ולא מוּטֶה, אך תמיד — מלבד מספר חריגות — יש לו את אותו אגֵּנְס (⟪कर्तृ⟫) כמו הפעולה שקדמה לה או שמלווה אותה. האגֵּנְס של האבסולוטיוּם נמצא אפוא בנימוֹן (⟪प्रथमा⟫) או באינסטרומֵטִיבַליס (⟪तृतीया⟫).

בנוסף לקומפוזיטה, האבסולטיב הוא אחד הכללים הנפוצים ביותר בסיאנסקריפט.

בתרגום לגרמנית יש להימנע משימוש חוזר ונשנה במילה "nachdem". במקום זאת יש להשתמש בביטויים המקובלים בגרמנית לתיאור רצף זמני.

**תבנית:**

(הגדרה מדויקת יותר לאבסולטיב: תואר נסיבות, אובייקט וכו') - אבסולטיב - אבסולטיב - ... - אבסולטיב - ... סוכן + משפט בינאלי (באקטיב או פסיב)

:::
**דוגמאות:**

::: indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = בניין הפעיל: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**  
"האיש נכנס לבית, רואה את הילדה הקטנה ומדבר אליה."

רבים: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**
:::
## 22.2. תצורת האבסולוטיב (גרונד)

::: grammar-box
**יצירת הנושא**

*   פעלים ללא פריפראזיה: אבסולוטיב מסתיים ב-**tvā**
*   פעלים עם פריפראזיה: אבסולוטיב מסתיים ב-**ya** או **-tya**
:::
### 22.2.1. פעלים ללא פְּרֶבֶרְבּ: אבסולוטיב ב-⟪त्वा⟫

::: grammar-box

פעלים ללא פריפראזיה: אבסולוטיב מסתיים ב-**tvā**

(רוב) שורש ברמה הנמוכה ביותר בצורה שקדמה ל-PPP + **-tvā** (**-⟪त्वा⟫**)

רק **a-** / **an-** השלילי מסוגל לשאת את הסיומת **-⟪त्वा⟫** : **⟪अकृत्वा⟫** "ללא פעולה"

:::
**דוגמאות:**

::: indent
**⟪आप्त्वा⟫** "לאחר שהגיע" / "הגיע" (זכר, נקבה, ניטרלי; יחיד, רבים)

**⟪आसित्वा⟫** "כאשר הוא (...) ישב / היה"

**⟪इत्वा⟫** "כאשר הוא (...) הלך / היה"

**⟪स्थित्वा⟫** "כאשר הוא (...) עמד / היה"

**⟪जित्वा⟫** "כאשר הוא (...) ניצח / היה"

**⟪उक्त्वा⟫** "לאחר שאמר (...) / אמר"
:::
### 22.2.2. פעלים עם פריפראזה

#### 22.2.2.1. שורשים עם תנוכה ארוכה (למעט -ā) או עם עיצור

::: grammar-box

פעלים ללא פריפראזיה: אבסולוטיב מסתיים ב-**tvā**

:::
**דוגמאות:**

::: indent
**⟪उपनीय⟫** "לאחר שהביא (...) / הוביל (...)"

**⟪प्रभूय⟫** "לאחר שהצטיין (...) / היה (...)" "לאחר ש(...) הייתה לו כוח"

**⟪प्राप्य⟫** "לאחר שהשיג (...) / היה (...)"
:::
#### 22.2.2.2. שורשים המסתיימים ב-ā

::: grammar-box

**שורש ברמה גבוהה ללא שינוי + -ya**

:::
**דוגמה:**

::: indent
**⟪उपस्थाय⟫** "כאשר (...) נכנס / עמד" ; (אבל ללא פריקס: **⟪स्थित्वा⟫**)
:::
#### 22.2.2.3. שורשים המסתיימים בצורה נמוכה ב-i קצר, -u, -ṛ

::: grammar-box

**שורש ברמה הנמוכה ביותר + -tya**

:::
**דוגמאות:**

::: indent
**⟪प्रस्तुत्य⟫** "לאחר ש(...) שיבח בקול רם / היה משייח"

**⟪विस्मृत्य⟫** "לאחר ש(...) שכח / היה שוכח"

**⟪संस्कृत्य⟫** "לאחר שהכין / הכין (...) לקורבן"
:::
#### 22.2.2.4. שורשים המסתיימים ב- / -am -an, המתגלגלים ל- a בשלב הנמוך

::: grammar-box

**אופציונלי:**

שורש על **-am** / **-an** + **-ya**

או:

או:

:::
**דוגמה:**

::: indent
**⟪विगम्य⟫** או **⟪विगत्य⟫** "לאחר ש(...) עבר / היה"
:::
