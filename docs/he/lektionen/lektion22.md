# שיעור 22

## 22.1. הפועל הפעול (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫)



:::
קופסת דקדוק

כדי לבטא בסנסקריט שמעשה של הפועל (⟪कर्तृ⟫) קודם למעשה אחר של אותו הפועל, או שהוא מתרחש במקביל כנסיבה מלווה, משתמשים באבדטיב (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫). כלומר

"לאחר שעשה זאת, הוא עושה את זה" ; "הוא עושה את זה, ואז הוא עושה את זה" ; "כתוצאה מזה הוא עושה את זה" ; "באתי, ראיתי וניצחתי" וכו'.

האבסולוטיוּם הוא אדברבֵּלִי, כלומר אינו מוטֶה ולא מוּטֶה, אך תמיד — מלבד מספר חריגות — יש לו את אותו אגֵּנְס (⟪कर्तृ⟫) כמו הפעולה שקדמה לה או שמלווה אותה. האגֵּנְס של האבסולוטיוּם נמצא אפוא בנימוֹן (⟪प्रथमा⟫) או באינסטרומֵטִיבַליס (⟪तृतीया⟫).

בנוסף לקומפוזיטה, האבסולטיב הוא אחד הכללים הנפוצים ביותר בסיאנסקריפט.

בתרגום לגרמנית יש להימנע משימוש חוזר ונשנה במילה "nachdem". במקום זאת יש להשתמש בביטויים המקובלים בגרמנית לתיאור רצף זמני.

**תבנית:**

(הגדרה מדויקת יותר לאבסולטיב: תואר נסיבות, אובייקט וכו') - אבסולטיב - אבסולטיב - ... - אבסולטיב - ... סוכן + משפט בינאלי (באקטיב או פסיב)



:::
**דוגמאות:**



:::indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = בניין הפעיל: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**  
"האיש נכנס לבית, רואה את הילדה הקטנה ומדבר אליה."

רבים: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**

:::
## 22.2. בניית הנושא



:::grammar-box
**יצירת הנושא**

*   פעלים ללא פריפראזיה: אבסולוטיב מסתיים ב-**tvā**
*   פעלים עם פריפראזיה: אבסולוטיב מסתיים ב-**ya** או **-tya**

:::
### 22.2.1. פעלים ללא פריפראב: אבסולוטיב בסיומת -⟪त्वा⟫



:::
קופסת דקדוק

**חינוך:**

(רובו המכריע) שורש ברמה הנמוכה ביותר בצורתו לפני ה-PPP + **-tvā** (**-⟪त्वा⟫**)

רק הניקודה השלילית **a-** / **an-** תואמת לסיומת **-⟪त्वा⟫** : **⟪अकृत्वा⟫** "ללא ביצוע"



:::
**דוגמאות:**



:::indent
**⟪आप्त्वा⟫** "לאחר שהגיע / הגיעה / הגיע / הגעתי / הגעת / הגענו / הגעתם / הגיעו / הגענו שנינו / הגעתם שניכם / הגיעו שניהם"

**⟪आसित्वा⟫** "לאחר ש (...) ישב / היה"

**⟪इत्वा⟫** "לאחר ש (...) הלך / היה"

**⟪स्थित्वा⟫** "לאחר שהודה / היה"

**⟪जित्वा⟫** "לאחר שניצח / ניצח"

**⟪उक्त्वा⟫** "לאחר ש(...) דיבר / היה מדבר"

:::
### 22.2.2. פעלים עם פריזב

#### 22.2.2.1. שורשים בתנועה ארוכה (למעט -ā) או בתנועה קצרה



:::
קופסת דקדוק

**(ברובו) שורש ברמה הנמוכה ביותר + -ya**



:::
**דוגמאות:**



:::indent
**⟪उपनीय⟫** "לאחר שהביא (...) / הוביל"

**⟪प्रभूय⟫** "לאחר ש(...) בלט / היה" "לאחר ש(...) הייתה לו כוח"

**⟪प्राप्य⟫** "לאחר ש(...) קיבל / היה לו"

:::
#### 22.2.2.2. שורשים המסתיימים ב-ā



:::
קופסת דקדוק

**שורש ברמה גבוהה ללא שינוי + -ya**



:::
**דוגמה:**



:::indent
**⟪उपस्थाय⟫** "לאחר ש(...) נכנס / עמד" ; (אך ללא קידומת: **⟪स्थित्वा⟫**)

:::
#### ⟪२२⟫.⟪२⟫.⟪२⟫.⟪३⟫. שורשים המסתיימים ב-i, -u, -ṛ קצר במדרגה עמוקה



:::
קופסת דקדוק

**שורש ברמה נמוכה מאוד + -tya**



:::
**דוגמאות:**



:::indent
**⟪प्रस्तुत्य⟫** "לאחר ש(...) שיבח בקול / היה"

**⟪विस्मृत्य⟫** "לאחר שכ (...) שכח / היה שוכח"

**⟪संस्कृत्य⟫** "לאחר שהכין / היה מוכן (...) לקורבן"

:::
#### 22.2.2.4. שורשים מסתיימים ב-אם / -אן, המסתיימים בשלב הנמוך ב-א



:::
קופסת דקדוק

**אופציונלי:**

שורש על **-am** / **-an** + **-ya**

או:

שורש על **-a** + **-tya**



:::
**דוגמה:**



:::indent
**⟪विगम्य⟫** או **⟪विगत्य⟫** "לאחר ש(...) עבר / היה"

:::
