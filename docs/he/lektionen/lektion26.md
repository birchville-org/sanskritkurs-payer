# שיעור 26

## 26.1. חוק הצריפיקציה עבור -s- בתוך המילה

::: grammar-box
**-s-** מוחלף ב-**-ṣ-**, כאשר **k, r, l** או תנועה — למעט **a, ā** — באים מיד או רק בנפרד על ידי ⟪अनुस्वार⟫ או ⟪विसर्ग⟫, ועוקב אחריהם צליל אחר מ-**ṛ, r**.

ל-Sandhi זה נשמע גם **⟪दुस्⟫-** לפני גוטורלים ולביאלים חסרי צליל בהרכבים.
:::
*דוגמאות:*
::: indent
⟪तेषाम्⟫ (מ: *te-sām*)

אך: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. חוק הצריפיקציה עבור דנטלים בתוך המילה

::: grammar-box
חסימות דנטליות מוחלפות על ידי החסימות הרטרופלקסיות המתאימות לאחר רטרופלקסים (כולל **-ṣ-**):

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** בשל **i** הקודם, **ṭh** בשל **ṣ** שאחריו)*
:::
## 26.3. וורטסנדי עבור פלטלים, גוטורלים, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

ראו דוגמאות להלן
:::
## 26.4. חוק דיסימילציית החיכוך של גרסמן

::: grammar-box
**רצף מיידי של שתי אספירטות (אספירה - תנועה - אספירה) גורב לאובדן החיכוך של הצליל הראשון:**

דוגמה:

:::
::: indent
\*dhu(gh) » du(g)h
:::

## 26.6. שימוש בעתיד פשוט (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**העתיד הפשוט (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) מבטא:**

**את העתיד**
**פעולה מתוכננת או רצויה ("אני אהיה הולך", "אני רוצה ללכת")**
**ציפייה ("זה יקרה כך")**
**תקווה**
**פחד/חשש**
**סבירות**
**דעת הדובר**
**פקודה**

**העתיד עומד לעיתים במתחרות עם האופטיבי (ראה מאוחר יותר).**
:::
למשל, ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = "מי שרוצה לקחת נדר, הולך למקדש."

## 26.7. בניית העתיד הפשוט (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**עתיד פשוט:**

:::
::: indent
**שורש עתיד + סיומת ראשונית**
:::
::: grammar-box
**שורש העתיד:**

:::
::: indent
**(בדרך כלל) שורש ברמת גבוה + -sya**  
**או**  
**(בדרך כלל) שורש ברמת גבוה + -i- + -sya (= - iṣya)**
:::
**יש ללמוד אילו שורשים מקבלים איזו בנייה של שורש העתיד יחד עם צורות השורש!**  
**באופן כללי, צורת השורש והאות המחברת של העתיד תואמות לאינפיניטיב.**  
**חלק מהשורשים יכולים לבנות את העתיד באופן אופציונלי עם וללא האות המחברת -i-.**  
**הבינוי Parasmaipada של העתיד נוצר על ידי חיבור הסיומת -nt- לשורש העתיד, ונקבה באופן אופציונלי על -ntī או -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
דוגמאות:

::: grammar-box

| שורש | עתיד 3. יח' ג' (Ā) |
| :--- | :--- |
| ⟪नी⟫ | ⟪नेष्यति⟫ |
| ⟪भू⟫ | ⟪भविष्यति⟫ (⟪भो⟫ +  ⟪इ⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दिश्⟫ | ⟪देक्ष्यति⟫ (⟪देश्⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दृश्⟫ | ⟪द्रक्ष्यति⟫ |
| ⟪पच्⟫ | ⟪पक्ष्यति⟫ |
| ⟪प्रच्छ्⟫ | ⟪प्रक्ष्यति⟫ |
| ⟪यज्⟫ | ⟪यक्ष्यति⟫ |
| ⟪सृज्⟫ | ⟪स्रक्ष्यति⟫ |
| ⟪पद्⟫ | ⟪पत्स्यति⟫ |
| ⟪अद्⟫ | ⟪अत्स्यति⟫ |
| ⟪दुह्⟫ | ⟪धोक्ष्यति⟫ (⟪दोग्⟫ +  ⟪स्य⟫ + ⟪ति⟫) |
| ⟪बुध्⟫ | ⟪भोत्स्यते⟫ (⟪बोध्⟫ לפני חוכך = ⟪भोत्⟫) |
| ⟪मन्⟫ | ⟪मंस्यते⟫ (⟪मन्⟫ + ⟪स्य⟫ + ⟪ते⟫) |

:::
