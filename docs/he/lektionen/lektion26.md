# שיעור 26

## 26.1. חוק הסרברליזציה עבור -s- בתוך המילה

::: grammar-box
**-s-** מוחלף ב-**ṣ-**, כאשר **k, r, l** או תנועה — למעט **a, ā** — קודמים מידית או רק בהפרדה של ⟪अनुस्वार⟫ או ⟪विसर्ग⟫, ועוקב אחריהם צליל אחר מ-**ṛ, r**.

ל-Sandhi זה נמשך גם **⟪दुस्⟫-** לפני גוטורלים ולביאלים חסרי צליל בהרכבים.
:::
*דוגמאות:*
::: indent
⟪तेषाम्⟫ (מ: *te-sām*)

אך: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. חוק הצרפתי של מילים פנימיות בדיפתונגלים

::: grammar-box
עיצורי עצירה דנטליים מוחלפים על ידי העיצורים הרטרופלקסיביים המתאימים לאחר רטרופלקסים (כולל **-ṣ-**):

- **iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** בשל **i** הקודם, **ṭh** בשל **ṣ** שאחריו)*
:::
## 26.3. סנדה מילית לפלטים, גוטורלים, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

ראו דוגמאות להלן
:::
## 26.4. חוק הדסימילציה של גרסמן

## 26.6. שימוש בעתיד פשוט (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ נק')

::: grammar-box
**העתיד הפשוט (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ נק') מבטא:**

- **העתיד**
- **פעולה מתוכננת או רצונית ("אני אהיה הולך", "אני רוצה ללכת")**
- **ציפייה ("זה יקרה כך")**
- **תקווה**
- **חשש**
- **סבירות**
- **דעת הדובר**
- **פקודה**

**העתיד בא במקום חלקי למשאל (ראה להלן).**
:::
למשל ⟪व्रतं⟫ ⟪करिष्यन्देवगृहं⟫ ⟪गच्छति⟫ = "אדם הרוצה לקיים נדר הולך למקדש."

::: indent

**יש ללמוד אילו שורשים מקבלים איזה סוג של בניין עתיד, יחד עם צורות השורש!**  
**באופן כללי, צורת השורש והתנוכה המחבר של העתיד תואמות לאינפיניטיב.**  
**חלק מהשורשים יכולים ליצור את העתיד באופן אופציונלי עם או בלעדי התנוכה המחבר -i-.**
