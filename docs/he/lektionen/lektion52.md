## 52.2. תצורה שמנית

### 52.2.1. PPP + -vant: שם תואר פעיל בעבר (Parasmaipada)

::: grammar-box
**שם תואר פעיל בעבר (Parasmaipada) נוצר כך:**

**PPP + -vant / נק': vatī**
**הטייה כשורשים על -vant או נק' ⟪देवी⟫**
:::
PPP + -vant / נק': vatī

הטייה כשורשים על -vant או נק' ⟪देवी⟫

דוגמאות:

::: indent
⟪कृतवन्त्⟫ (kṛta-vant) / ⟪कृतवती⟫ "מי שעשה"

⟪भिन्नवन्त्⟫ "מי שחילק"
:::
### 52.2.2. סיומת ⟪तद्धित⟫ -maya / -mayī

::: grammar-box
**סיומת ⟪तद्धित⟫ -maya / בנקבה: -mayī יוצרת תארים משמות עצם במשמעות**

*   **"עשוי מ"**
*   **"מורכב מ"**
*   **"עשיר ב"**

**הגידי סגירה הנמצאים לפני -maya (כמו לפני -⟪मात्र⟫) בסוף מילה, יש להחליף בנזל המתאים להם.**
:::
דוגמאות:

::: indent
⟪अन्नमय⟫ 3 "עשיר במזון"

⟪चिन्मय⟫ 3 (ל- ⟪चित्⟫ f. "אינטלקט") "מורכב מחשיבה/שכל"

⟪वाङ्मय⟫ 3 (ל-⟪वाच्⟫ פ. "שפה") "המורכב מדיבור"

⟪सोममय⟫ 3 "העשוי מסומא, המורכב מסומא"
:::
::: grammar-box
**שמות עצם המסתיימים ב-maya משמשים לעיתים כשמות עצם נקביים, ומציינים בכך עודף של מה שמתואר על ידי השם העצמי אליו נוסף ה-suffix -maya.**
:::
::: indent
למשל, ⟪अन्नमय⟫ נ. "עודף מזון"
:::

## 52.4. מורכבות פועליות, die ausdrücken, dass etwas zu etwas wird oder gemacht wird, was es vorher nicht ist (⟪अभुततद्भावः⟫)

### 52.4.1. תצורות cvi

::: grammar-box
**אל השורשים**

*   **⟪कृ⟫ 8U "לעשות"**
*   **⟪अस्⟫ 2P "להיות"**
*   **⟪भू⟫ 1P "להפוך"**

**ניתן להשתמש בשמות עצם ותארים כפרי-תחיליות כדי לבטא שמישהו הופך אדם או דבר למה שמציינת השם, או שדבר מה הופך למה שהשם מצביע עליו.**

**סיום השם מטופל כדלקמן:**

סיום השם מטופל כדלקמן:

*   **סיומות -a ו-ā של מילים מתחלפות נשללות באמצעות -ī**
דוגמאות:  
⟪कृष्णीभवति⟫ "דבר שאינו שחור הופך לשחור"  
⟪कृष्णीकरोति⟫ "הוא הופך דבר שאינו שחור לשחור"  
⟪गङ्गीभवति⟫ "הוא/היא הופך לגנגס"

*   **סיומות -i ו-u נשללות באמצעות האורך המתאים**
דוגמאות:  
⟪शुचीभवति⟫ "הוא/היא/זה הופך טהור"  
⟪गुरूभवामि⟫ "אני הופך לבעל"

*   **סיום -ṛ נשלל באמצעות --rī**
למשל, ⟪पित्रीभवति⟫ "מי שאינו אב (⟪पितृ⟫) הופך לאב = גבר מקבל את ילדו הראשון"

*   **הסיומת -n בסוף המילה נופלת, והתנועה שלפניה מטופלת לפי הכללים שצוינו לעיל**
למשל, ⟪राजीबभूव⟫ "אחד (שהיה לא מלך) הפך למלך (⟪राजन्⟫)"

*   **שמות עצם אחרים רב-מקוריים מופיעים בצורת המקור שלהם, כפי שהם מופיעים במיקוד (⟪सप्तमी⟫) רבים. המקור כפוף לכללי הסנדה הרגילים. ראה קילפורן, דקדוק סעיף 489,3.**

### 52.4.2. הסיומת -sāt

::: grammar-box
**כדי לבטא שאדם או דבר הופך לחלוטין למה שמתואר בשם עצם, או שאדם הופך למישהו אחר לחלוטין, ניתן להוסיף לשם העצם**

**את הסיומת -sāt (שלא הופכת ל-ṣāṭ)**

**נוספים ונצרף את המילה שנוצרה עם השורשים**

*   ⟪कृ⟫ 8U "לעשות"
*   ⟪अस्⟫ 2P "להיות"
*   ⟪भू⟫ 1P "להיות"
*   ⟪सम्⟫-⟪पद्⟫ 4Ā

**לצירוף לרכיב פעלי.**
:::
דוגמאות:

::: indent
⟪अग्निसाद्भवति⟫ ⟪।⟫ ⟪अग्निसात्संपद्यते⟫ "הוא הופך לגמרי לאש"

⟪भस्मसात्करोति⟫ "הוא הופך לגמרי לאפר (⟪भस्मन्⟫ נ' "אפר"))
:::
::: grammar-box
**Manchmal bedeutet das Suffix -sāt, dass eine Person oder Sache**

*   **תלוי ב־ או**
*   **עובר לבעלותו של**
*   **או שמישהו הופך תלוי בו**

**מה שהשם מציינו**
:::
דוגמה:

::: indent
⟪राजसाद्भवति⟫ "הוא הופך תלוי במלך, הוא נכנס לבעלות המלך"
:::
::: grammar-box
**בנייה עם -sāt אינה מטופלת כשורשים כמו אחריות של קידומות, כלומר אינפיניטיב:**

:::
::: indent
⟪भस्मसात्कृ⟫*:sig[⟪त्वा⟫]*

## 52.6. שם המספר (⟪סאמקהיא⟫ נ.)

ללא טיפול כאן ראה למשל אצל קילהורן, גרמטיקה §201f.

### 52.6.1. מספרים מונים

#### 52.6.1.1. מספרים תואריים (עבור 1 עד 19)

::: grammar-box
**מילות המספר עבור *1 עד 19* הן תואריים.**
**מילות המספר עבור **1 עד 4** שונות בשלושת המגדרים בהטייה.**

**עבור מילות המספר עבור **5 עד 19** ***(:sig[⟪नवदशन्⟫])*** יש רק הסטת הטייה אחת לשלושת המגדרים.**

**עבור מספרים תואריים אלו, כפי שחל על כל התארים: עליהם להיות באותו מקרה, מספר ומגדר כמו השם הקשור להם ולהפך (כלומר עבור 1 יחיד, עבור 2 שניים/דואל, ועבור השאר רבים).**
:::
מספרים תואריים:

::: indent
1 ⟪एक⟫ 3 (הטייה כ-⟪सर्व⟫, ברבים: "כמה")
2 ⟪द्वि⟫ 3
3 ⟪त्रि⟫ 3
4 ⟪चतुर्⟫ 3
5 ⟪पञ्चन्⟫ 3
6 ⟪षष्⟫ 3
7 ⟪सप्तन्⟫ 3
8 ⟪अष्टन्⟫ 3
9 ⟪नवन्⟫ 3
10 ⟪दशन्⟫ 3
:::
ההטייה מופיעה במקום המתאים ברשימות המילים.

ראה למשל אצל קילפורן, דקדוק סעיף 201, את שאר המספרים העצמיים עד 19.

#### 52.6.1.2. שמות עצם של מספרים (ל-19 ומעלה)

::: grammar-box
**מילות המספר עבור *19 (⟪एकोनविंशति⟫* "אחד פחות מ-20") *עד 99* הן שמות עצם נקביים ומטויות כ-⟪मति⟩ נ' או כמו שורשים בשם עצם עם סיומת -t (למשל ⟪त्रिंशत्⟩ נ').**

:::
דוגמאות:

::: indent
20 ⟪विंशति⟫ f.:br
30 ⟪त्रिंशत्⟫ f.
:::

::: grammar-box

**מספרי הכמות למספרים **מעל 100** הם שמות עצם ניטרליים. הם מנוסחים כמו ⟪फलम्⟫.**
:::

דוגמאות:

::: indent
100 ⟪शत⟫ נ.:br
1000 ⟪सहस्र⟫ נ.
:::
את שמות העצם של המספרים הבודדים ראו למשל אצל קילפורן, דקדוק סעיף 201.
#### 52.6.1.3. תחביר למספרי הכמות

::: grammar-box
**מההבדל בין תוארי הפועל לשמות העצם של הפועל למספרי הכות נובעת ההשלכה הבאה לתחביר:**
*   מילות מספר הכמות תואריות יכולות להתחבר רק כמו תארים עם השם עצם של המנויים
למשל ⟪तिसृभिर्नारीभिः⟫ "דרך שלוש נשים"

    *   הם שולטים במשפט הגנטי (⟪षष्ठी⟫) של המנויים
למשל ⟪विंशत्या⟫ ⟪नारीणाम्⟫ "דרך 20 נשים"
    *   הם עומדים כהסבר באותו מקרה (אבל ביחיד) כמו המנויים
למשל ⟪विंशत्या⟫ ⟪नारीभिः⟫ "דרך 20 נשים"
    *   הם עומדים כחלק מאחורי של ⟪तत्पुरुष⟫ עם המנויים כחלק קדמי
למשל ⟪गोविंशत्या⟫ "דרך 20 פרות"
