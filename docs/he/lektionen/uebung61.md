# שיעור 61

שיעור 61 מהווה את סיום קורס הסנסקריט ואינו מכיל תרגילים כתובים נוספים.

עם לימודם של שמות עצם שורשיים, עתיד פרפרזטי ודנומינטיבים, הונחו היסודות לקריאת טקסטים מקוריים בסנסקריט. הקורס מסתיים עם הפנייה המסורתית לגנש (⟪श्रीगणनाथ⟩), המסמנת את המעבר מספר הלימוד לקריאה עצמאית.
