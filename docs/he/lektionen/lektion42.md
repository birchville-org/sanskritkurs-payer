# Lektion 42

## 42.1. Stämme auf -ṛ

### 42.1.1. שבטים עם דרגת הארכה בשורש החזק

::: grammar-box
כל הזכרים המסתיימים ב-ṛ, למעט שמות הקרבה המפורטים בסעיף 1.3. ביניהם נכללים גם שמות הקרבה הבאים:

*   **⟪नप्तृ⟫** ז. "נכד"
*   **⟪भर्तृ⟫** ז. "בעל (מילולית: מקיים)"

רוב השמות הנכללים בקטגוריה זו הם שמות פעולה (Nomina agentis) עם הסיומת ⟪कृत्⟩ -⟪तृ⟩.

**יצירת צורות:**

*   **שורש חזק: -ār**
*   **שורש חלש**
*   **לפני תנועה: -r**
*   **לפני עיצור: -ṛ**

שימו לב לצורות לא סדירות (מסומנות ב**אדום**)!
:::

### 42.1.2. בניין שם עצם: סיומת ⟪कृत्⟫ -⟪तृ⟫
