# שיעור 29

## 29.1. שימוש בפראסמפדה (⟪परस्मैपद⟫) ואטמןפדה (⟪आत्मनेपद⟫) בקאוזיטיבום


::: grammar-box
**הקאוזיטיב הוא, למעט מספר חריגות, אווביאיהפדה (⟪उभयपद⟫)**
:::
::: grammar-box
**בקאוזיטיבום משתמשים באטמןפדה (⟪आत्मनेपद⟫):**

**1. כאשר תוצאת הפעולה המיוזמת משרתת את היוזם:**
:::
דוגמה:

⟪रामः कटं कारयते⟫ = "ראמה מצווה להכין לעצמו (לטובת עצמו) שטיח"

**2. כאשר הקאוזיטיב של פעלים מעברים משמש בצורה רפלקסיבית ("להראות את עצמו", "להשמיע קול" וכו'), או כאשר אובייקט של הפועל הבסיסי הוא האגנס (⟪कर्तृ⟫) של הקאוזיטיב:**

דוגמה:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "וישנו מראה את עצמו למעריציו"

תוצאה: ⟪भक्ता विष्णुं पश्यन्ति⟫ = "המאמינים רואים את וישנו"


הכללים אפוא תואמים, באופן כללי, לכללים לשימוש באטמןפדה (⟪आत्मनेपद⟫) בפעלים אווביאיהפדה (⟪उभयपद⟫).

## 29.3. תרגיל תרגום לחזרה

תרגמו מילה במילה לגרמנית טובה וזכרו את הטקסטים בסנסקריט בעל פה:

1\. הגדרת ⟪अविद्या⟫ :

⟪अनित्याशुचिदुःखा⟫:sig[⟪नात्मसु⟫] ⟪नित्यशुचिसुखात्मख्यातिरविद्या ॥योगसूत्र २⟫.⟪५॥⟫

הסבר: ⟪आत्मसु⟫ = מקום יחיד ל- ⟪आत्मन्⟫ m. "נשמה; המוחלט, במידה שהוא מתממש באדם"

2\. ⟪कौटिलीयार्थशास्त्र⟫ 1.4. לגבי השימוש הנכון ב- ⟪दण्ड⟫ :
