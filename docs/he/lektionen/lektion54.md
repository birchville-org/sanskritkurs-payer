# שיעור 54

## 54.1. הערת פתיחה

עם שיעור 54 מתחיל בקורס האוניברסיטאי הסמסטר השני. מהשלב הזה והלאה הקורס מתקיים במקביל לנושא המרכזי של סמסטר זה: קריאת הבהגוודג׳יטה כולה. מטרת הלמידה היא רמת שוטפות כזו בקריאת טקסט בינוני-בינוני, שתאפשר בתחילתו השלישי של הסמסטר לתרגם בחלקו הגדול של הבהגוודג׳יטה מתוך ראש. בהתחלה הופצו ברשימות מילים באוניברסיטה, מאוחר יותר נדרשו הסטודנטים להשתמש במילונים מתאימים (מונייר-ויליאמס, אופטה, PW).

קורס הבהגוודג׳יטה לא יסופק זמנית באופן מקוון.

שיעורי קורס הסנסקריט עוסקים בנושאי דקדוק סנסקריטי שלא טופלו עד כה.

## 54.3. מטריקה II: ה-⟪त्रिष्टुभ्⟫ האפית וה-⟪जगती⟫

::: grammar-box
ה⟪त्रिष्टुभ्⟫ ("שלושה נהמות") מופיעה באפיים באמצע הקטעים הרגילים של ה⟪श्लोक⟫ בדיוק במקומות שבהם מצב הרוח או העלילה זוכים לדחף מיוחד או לסיום מיוחד.

השיר ה⟪त्रिष्टुभ्⟫ מורכב מארבעה שירי 11 הברות ה⟪पाद⟫, שאינם שונים זה מזה במבנה.

ל⟪त्रिष्टुभ्⟫ יש שני סכימות בסיסיות, תלוי אם הקזורה (סוף מילה, סף קומפוזיציה או לפני סיומות מסוימות כמו -tara, -tama וכו׳) נמצאת אחרי ההברה ה-4 או ה-5 של ה⟪पाद⟫.

## 54.5. טיפוסי בנייה של האאוריסט (⟪לונג⟫)

::: grammar-box
**משותף לכל סוגי הבנייה של האוריסט (⟪लुङ्⟫) הוא האוגמנט a-, המוצמד לפי אותן כללים כמו באימפרפקט (⟪लङ्⟫).**

בסנסקריט נפושים רק אינדיקטיב ופרקטיב של האוריסט.
:::
::: grammar-box
**קיימים סוגי הבנייה הבאים של האוריסט (⟪लुङ्⟫):**

1.  אוריסטים לא סיבנטיים (אסיגמטיים): 
    *   54.1. אוריסט שורש: אוגמנט + שורש + סיומת משנית
    *   54.2. אוריסט תמטי: אוגמנט + שורש + **a** + סיומת משנית
    *   54.3. אוריסט מרובה: אוגמנט + **שורש מרובה** + **a** + סיומת משנית 
2.  אוריסטים סיבנטיים (סיגמטיים: s או הברה המכילה s (ṣ) מופיעה לפני הסיומת האישית 
    *   54.4. אוריסט -s: אוגמנט + שורש + **s** \+ סיומת משנית
    *   54.5. אוריסט -iṣ: אוגמנט + שורש + **i** + **ṣ** + סיומת משנית
    *   54.6. אוריסט -siṣ: אוגמנט + שורש + **siṣ** + סיומת משנית
    *   54.7. אוריסט -sa: אוגמנט + שורש + **s** + **a** + סיומת משנית

חלוקת השורשים לסוגי בנייה שונים ראה בסוגים השונים
:::
