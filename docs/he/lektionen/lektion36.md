## 36.2. הבינוני הפריפרסטי (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
הבינוני הפריפרסטי (⟪अनुप्रयोगलिट्⟫) משמש:

1. אצל ההטיות הנגזרות (סיבת, חפץ, תדירות, שמות גזירה)
2. אצל שורשים המתחילים בתנועה ארוכה (למעט ā-) או בתנועה (למעט a-) לפני שתי עיצורים
3. אצל כמה שורשים נוספים
:::
::: grammar-box
**בנייה:**

שורש הווה (חלש) + -ām + צורת בינוני מתאימה של ⟪कृ⟫, ⟪अस्⟫ או ⟪भू⟫

- Auslautender Stammvokal wird vor -ām guṇiert.
- ⟪अस्⟫ ו-⟪भू⟫ משמשים גם בפיסוק פעלים של אטמןפדה בפארסמהיפדה.
:::
Das periphrastische Perfekt ist wohl aus dem Akkusativ eine Verbalnomens auf -ā entstanden. Dieser Akkusativ wird -- wie auch sonst oft -- adverbial verwendet.
