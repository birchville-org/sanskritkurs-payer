# Mësimi 39

## 39.1. Përfundimet personale të personit të parë (:sig[तृतीयः] ⟪पुरुषः⟫ = "**personi i tretë**")

Përfundimet e personit të parë (:sig[⟪तृतीयः⟫] ⟪पुरुषः⟫ = "**personi i tretë**") janë:

::: grammar-box

| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Përfundim primar për stame tematike** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **Përfundim primar për stame atematike** | ^^ | ^^ | **-e** | ^^ |
| **Përfundim sekondar për stame tematike** | **-m** | **-ma** | **-i** | **-mahi** |
| **Përfundim sekondar për stame atematike** | **-am** | ^^ | ^^ | ^^ |
| **Përfundim optativ** | ^^ | ^^ | **-a** | ^^ |
| **Përfundim perfekt** | **-a** | ^^ | **-e** | **-mahe** |

:::
¹ Shënim: në fakt, përfundimi primar Ā për stamat tematike duhet të vendoset edhe si -e, para të cilit vokali tematik -a- bie për shkak të analogjisë. Megjithatë, efekti është sikur përfundimi -i t'i bashkohet vokalit tematik -a-: a + i » e.
