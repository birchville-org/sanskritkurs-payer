## 43.2. Formimi i formave verbale të personit të dytë (⟪मध्यमः⟫)

Personi i dytë:

*   Singular: "ti"
*   Plural: "ju" (më shumë se dy!)

## 43.3. Personalpronominet e personit të dytë

*   Shumës: ⟪युष्मद्⟫ "ju"

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम् त्वा⟫ | ⟪युष्मान् वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम् ते⟫ | ⟪युष्मभ्यम् वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |

::: indent
⟪त्वां मां च⟫ "ty dhe mua"
