## 4.1. Eenvoudige aanvullingsvrae (woordvrae) en antwoorde

### 4.1.1. Vraag- en aanwysende voornaamwoorde

#### 4.1.1.1. Vraende voornaamwoorde (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Nominatief enkelvoud | Nominatief meervoud |
| :--- | :--- | :--- |
| **Onsydig** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Manlik** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Vroulik** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Aanwysende voornaamwoorde (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Stamme** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"hy, sy, dit; die":br(Reeds genoem)** | **etad = ⟪एतद्⟫:br"hierdie":br(Baie naby aan die spreker)** | **idam = ⟪इदम्⟫:br"hierdie":br(Naby)** |
| **Nominatief enkelvoud** ||||
| **Onsydig** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Manlik** | **sa, so saḥ = ⟪स⟫ ⟪सो⟫ ⟪सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष⟫ ⟪एषो⟫ ⟪एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Vroulik** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Nominatief meervoud** ||||
| **Onsydig** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Manlik** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Vroulik** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**Aangaande die Nom. enk. man.:**
- **sa, eṣa** (⟪स⟫ ⟪एष⟫) staan voor alle klanke behalwe kort **-a**
- **so, eṣo** (⟪सो⟫ ⟪एषो⟫) staan voor **-a**, wat met Avagraha geëlideer word (wegval)
- **saḥ, eṣaḥ** (⟪सः⟫ ⟪एषः⟫) staan slegs in Pausa (einde van 'n sin, einde van 'n vers)

Om sinne met hierdie voornaamwoorde (sarvanāman n.) te kan vorm, is kennis van die volgende Sandhi-reëls nog nodig:

### 4.1.2. Sandhi van uitgaande -m

::: grammar-box
**Uitgaande -m word voor konsonante deur Anusvāra (-ṃ) vervang. Aan die einde van 'n sin of versreël en voor vokale bly -m behoue.**
:::
### 4.1.3. Sandhi van uitgaande -e

::: grammar-box
1. **voor a- bly -e onveranderd: die aanvangende a- word met Avagraha geëlideer:**
bv. ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ "Hierdie vure"

2. **Voor ander vokale as 'n kort a- word -e gewoonlik deur -a met hiatus vervang. Die vervanging deur -ay kom ook voor:**
bv. ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (selde: imay īśvarāh = ⟪इमयीश्वराः⟫) "Hierdie HERE"
:::
### 4.1.4. Sandhi van uitgaande -d

::: grammar-box
**Finale -d word in pausa asook voor stemlose gutturale (k, kh) en labiale (p, ph) deur -t vervang.**

Die vervanging voor ander konsonante word later bespreek. Vermy voorlopig sulke klankbotsings!
:::
### 4.1.5. Vraagformules

Met behulp van hierdie pronomina vorm 'n mens bv. die volgende vraagformules:

| :--- | :--- | :--- | :--- |

| ^^| **Vroulik** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः⟫ ⟪काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः⟫ ⟪काः⟫, ⟪का⟫ ⟪एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः⟫ ⟪काः⟫, ⟪का⟫ ⟪इमाः⟫ | |

'n Voorbeeld van ander vrae:

> viṣṇuḥ kaḥ? = ⟪विष्णुः⟫ ⟪कः⟫ Antwoord: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (Hier kan 'n mens in die nominale sin die subjek bv. aan die begin plaas om die verbinding met die vraag te beklemtoon.)

OPMERKING: Die antwoorde wat u met u huidige kennis van Sanskrit op sulke vrae kan gee, is vanselfsprekend nog nie in elke opsig idiomaties goeie Sanskrit nie.
