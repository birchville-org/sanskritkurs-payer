# Lesing 4

## 4.1. Enkel aanvullende vrae (woordvrae) en antwoorde

### 4.1.1. Vraagvoornaamwoorde en demonstratiewe voornaamwoorde

#### 4.1.1.1. Vraagvoornaamwoorde (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Nominatief enkelvoud | Nominatief meervoud |
| :--- | :--- | :--- |
| **Neutrum** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Maskulinum** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Femininum** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Demonstratiewe voornaamwoorde (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Stamme** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"hy, sy, dit; die":br(Genoem)** | **etad = ⟪एतद्⟫:br"hierdie":br( baie naby aan die spreker)** | **idam = ⟪इदम्⟫:br"hierdie":br(Naby)** |
| **Nominatief enkelvoud** ||||
| **Neutrum** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Maskulinum** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Femininum** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Nominatief meervoud** ||||
| **Neutrum** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Maskulinum** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Femininum** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**Vir die Nom. sg. mask.:**
**sa, eṣa** (⟪स एष⟫) word voor alle klank behalwe kort **-a** gebruik
**so, eṣo** (⟪सो एषो⟫) word voor **-a** gebruik, wat met Avagraha elisieer (verdwyn)
**saḥ, eṣaḥ** (⟪सः एषः⟫) word slegs in pause (einde van sin, einde van vers) gebruik

Om sin hierdie voornaamwoorde (sarvanāman n.) te kan gebruik om sinne te vorm, is die kennis van die volgende Sandhi-reëls nodig:

### 4.1.2. Sandhi van uitgaande -m

::: grammar-box
**Uitgaande -m word voor medeklinkers deur Anusvāra (-ṃ) vervang. Aan die einde van 'n sin of vers, en voor klinkers, bly -m behoue.**
:::
### 4.1.3. Sandhi van uitgaande -e

::: grammar-box
1. **voor a- bly -e onveranderd: die aanvangende a- word geëlideer met Avagraha:**
bv. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Hierdie vuur"

2. **Voor ander klinkers as kort a- word -e gewoonlik deur -a met Hiatus vervang. Die vervanging deur -ay kom ook voor:**
bv. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (selde: imay īśvarāh = ⟪इमयीश्वराः⟫) "Hierdie HERE"
:::
### 4.1.4. Sandhi van uitgaande -d

::: grammar-box
**Uitgaande -d word in pause sowel as voor stemlose gutturale (k, kh) en labiale (p, ph) deur -t vervang.**

Die vervanging voor ander medeklinkers word later bespreek. Vermy voorlopig sulke klankbotsings!
:::
### 4.1.5. Vraeformules

Met behulp van hierdie voornaamwoorde vorm men byvoorbeeld die volgende vraeformules:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Enkelvoud** | **Neutrum** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं किम्⟫, ⟪किमिदम्⟫ | "Wat is dit?" |
| ^^| **Maskulinum** | sa kaḥ? / kaḥ saḥ?:br⟪स कः⟫, ⟪कः सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष कः⟫, ⟪क एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं कः⟫, ⟪को ऽयम्⟫ | "Wie is dit?":br"Wat is die?" |
| ^^| **Femininum** | sā kā? / kā sā?:br⟪सा का⟫, ⟪का सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं का⟫, ⟪केयम्⟫ | "Wie is dit?":br"Wie is die?" |
| **Meervoud** | **Neutrum** | tāni kāni? / kāni tāni?:br⟪तानि कानि⟫, ⟪कानि तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि कानि⟫, ⟪कानीमानि⟫ | |
|^^ | **Maskulinum** | te ke? / ke te?:br⟪ते के⟫, ⟪के ते⟫:brete ke? / ka ete?:br⟪एते के⟫, ⟪क एते⟫:brime ke? / ka ime?:br⟪इमे के⟫, ⟪क इमे⟫ | |
| ^^| **Femininum** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः काः⟫, ⟪का एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः काः⟫, ⟪का इमाः⟫ | |
:::
'n Voorbeeld van ander vrae:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ Antwoord: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (In 'n nominale sin kan die onderwerp byvoorbeeld na die begin geplaas word om aansluiting by die vraag te beklemtoon.)

AANTEKENING: Die antwoorde wat u met u tot dusver verkryde Sanskritkennis op sulke vrae kan gee, stem natuurlik nog nie in elke opsig idiomaties goeie Sanskrit nie.
