## 30.5. Sandhi von auslautendem -r <!-- TODO: Fallback translation -->

::: grammar-box
**Ausser für -ar gelten für auslautendes -r dieselben Sandhiregeln wie für auslautendes -s.** <!-- TODO: Fallback translation -->

**-ar vor tönenden Lauten bleibt -ar, vor r- aber fällt das -r aus und das -a- wird durch -ā- ersetzt.** <!-- TODO: Fallback translation -->
:::

::: indent
