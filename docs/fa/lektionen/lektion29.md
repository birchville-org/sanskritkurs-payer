# درس ۲۹

## 29.1. استفاده از پاراسمایپادا (⟪परस्मैपद⟫) و آتمانپادا (⟪आत्मनेपद⟫) در فعل سببی

::: grammar-box
**علت‌زا به ندرت اوبه‌ی‌پادا (⟪उभयपद⟫) است.**
:::
::: grammar-box
**در علت‌زا از آتمَ‌نِپادا (⟪आत्मनेपद⟫) استفاده می‌شود:**

**۱. اگر نتیجهٔ عمل باعث شده، به نفع عامل (Veranlasser) باشد:**
:::
مثال:

⟪रामः⟫ ⟪कटं⟫ ⟪कारयते⟫ = «راما برای خود (به نفع خودش) یک حصیر می‌سازد»

**۲. اگر علت‌زای افعال متعدی به صورت انعکاسی (reflexiv) به کار رود («خود را نشان دادن»، «شنیده شدن» و غیره)، یا اگر مفعول فعل ساده، عامل (⟪कर्तृ⟫) علت‌زا باشد:**

مثال:

⟪विष्णुर्भक्तान्दर्शयते⟫ = "ویشْ누 خود را به پیروان خود نشان می‌دهد"

نتیجه: ⟪भक्ता⟫ ⟪विष्णुं⟫ ⟪पश्यन्ति⟫ = "مؤمنان ویشْ누 را می‌بینند"

بنابراین، قواعد عموماً با قواعد استفاده از آتمَ‌پادا (⟪आत्मनेपद⟫) در افعال دوجانبه (⟪उभयपद⟫) مطابقت دارند.
