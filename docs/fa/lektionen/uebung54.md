# تمرین 54

برای شکل‌های حال یا کامل زیر، معادل‌های آوریست مربوطه را بسازید:

::: grammar-box
| شماره | شکل | تعیین / معنا | آوریست |

| ⟪२⟫. | ⟪पिबामि⟫ | من می‌نوشم | ⟪अपाम्⟫ |
| ⟪३⟫. | ⟪ददौ⟫ | من/او داده است | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | ⟪बभूव⟫ | من/او/آن‌ها بودید / بودید | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | ⟪दधति⟫ | آن‌ها قرار می‌دهند | ⟪अधुः⟫ |

| ⟪८⟫. | ⟪तिष्ठति⟫ | او ایستاده است | ⟪अस्थात्⟫ |
