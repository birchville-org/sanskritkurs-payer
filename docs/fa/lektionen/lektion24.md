# درس ۲۴

## 24.1. حالت برایی (⟪चतुर्थी⟫ = "چهارمین پایانه حالت")

::: grammar-box
**۱. برای بیان هدف یا نیت («تا») یک عمل، می‌توان به جای مصدر (⟪तुमुन्⟫) از اسمی با پسوند کرت که عمل یا حالتی را نشان می‌دهد، در مورد سوم (⟪चतुर्थी⟫ = «پایه چهارم») استفاده کرد.**

به جای:

به جای:

:::
::: indent
⟪रामो⟫ ⟪गुरुवचनं⟫ ⟪श्रोतुं⟫ ⟪गतः⟫ ⟪।⟫
:::

::: indent
⟪रामो⟫ ⟪गुरुवचनस्य⟫ ⟪श्रवणाय⟫ ⟪गतः⟫ ⟪।⟫

یا:

⟪रामो⟫ ⟪गुरुवचनश्रवणाय⟫ ⟪गतः⟫ ⟪।⟫

## 24.2. ساخت حالت برایی (⟪चतुर्थी⟫)

::: grammar-box
**پایه‌های منظم داتیو عبارتند از:**

* **مفرد: -e ; پایه‌های مؤنث که به واکه ختم می‌شوند: -ai**
* **جمع: داتیو و ابلیت ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. بن‌های همخوانی

::: grammar-box

| | مفرد حالت برایی | جمع حالت برایی |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. ضمیر پرسشی

::: grammar-box

| | مذکر / خنثی | مؤنث |

:::
### 24.2.3. ضمایر اشاره

::: grammar-box

| :--- | :--- | :--- | :--- | :--- |

:::
### 24.2.4. ریشه‌های مصوت‌دار

::: grammar-box
**بن‌های مصوتی**

* **مذکر/خنثی با پسوند -a:** ⟪देव⟫
  * مفرد نصب مفعولی **⟪देवाय⟫**
  * جمع نصب مفعولی **⟪देवेभ्यस्⟫**
* **مذکر با پسوند -i:** ⟪कवि⟫
  * مفرد نصب مفعولی **⟪कवये⟫**
  * جمع نصب مفعولی **⟪कविभ्यस्⟫**
* **مذکر با پسوند -u:** ⟪पशु⟫
  * مفرد نصب مفعولی **⟪पशवे⟫**
  * جمع نصب مفعولی **⟪पशुभ्यस्⟫**
* **مونث با پسوند -ā:** ⟪देवता⟫
  * مفرد نصب مفعولی **⟪देवतायै⟫**
  * جمع نصب مفعولی **⟪देवताभ्यस्⟫**
* **مونث با پسوند -ī:** ⟪देवी⟫
  * مفرد نصب مفعولی **⟪देव्यै⟫**
  * جمع نصب مفعولی **⟪देवीभ्यस्⟫**
* **مونث با پسوند -i:** ⟪श्रुति⟫
  * مفرد نصب مفعولی **⟪श्रुतये⟫** یا **⟪श्रुत्यै⟫** (یعنی مانند ⟪कवि⟫ یا مانند ⟪देवी⟫)
  * جمع نصب مفعولی **⟪श्रुतिभ्यस्⟫**
* **مونث با پسوند -u:** ⟪धेनु⟫
  * مفرد نصب مفعولی **⟪धेनवे⟫** یا **⟪धेन्वै⟫**
  * جمع نصب مفعولی **⟪धेनुभ्यस्⟫**
:::
## 24.3. ساندھیِ -ai و -au پایانی

::: grammar-box
**ساندھی -ai و -au پایانی**

* **-ai پیش از مصوت آغازین معمولاً با -ā جایگزین می‌شود (به ندرت مانند داخل کلمه با -āy)**
* **-au پیش از مصوت معمولاً با -āv جایگزین می‌شود (به ندرت با -ā)**

مثال:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा⟫ ⟪अग्नये⟫ = "به این آتش"
:::
