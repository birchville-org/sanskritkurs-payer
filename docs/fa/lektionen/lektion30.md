# درس ۳۰

## 30.1. رده نهم حال (⟪क्र्यादि⟫ = «⟪क्री⟫ و غیره»)

::: grammar-box
**آموزش:**

*   بن قوی: ریشه با آهنگ پایین + -nā-

*   بن ضعیف:

    *   پیش از همخوان: ریشه با آهنگ پایین + -nī-

    *   پیش از واکه: ریشه با صدای پایین + -n-
:::
مثال:

::: indent
⟪क्री⟫ 9U "خریدن"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **3. Person:brĀtmanepada** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
در این دسته از افعال حال، به‌ویژه باید به ساختار بن فعل حال نسبت به ریشه ⟪ज्ञा⟫ 9U «شناختن، دانستن» توجه کرد:

::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **3. Person:brĀtmanepada** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
شکل ⟪जा⟫ که در پایه حال فعل ⟪ज्ञा⟫ نهفته است، یا از طریق یک سری آبلوت -ā (مرحله پایین) -nā (مرحله بالا) قابل توضیح است، یا از طریق دی‌سیمیلیشن از *jñā-nā-ti.

برخی ریشه‌ها با واکه بلند، این واکه را پیش از پسوند پایه حال کلاس نهم کوتاه می‌کنند:

مثال:

::: indent
⟪पू⟫ 9U "پاک کردن"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪पुनाति⟫:br(pu-nā-ti) | ⟪पुनन्ति⟫:br(pu-n-anti) |
| **3. Person:brĀtmanepada** | ⟪पुनीते⟫:br(pu-nī-te) | ⟪पुनते⟫:br(pu-n-ate) |

:::
ساخت مشارکت حال (پاراسمای‌پادا):

مثال:

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant) ; مؤنث: ⟪क्रीणती⟫ (krī + n + at + ī)
:::
## 30.2. کاربرد التزامی (⟪लिङ्⟫)

از حالت التزامی (اُپتاتیو) استفاده می‌شود:

::: grammar-box
**۱. برای اشاره**

*   **به یک خواسته**
*   **به یک خواسته**
*   **به یک درخواست**

**(در اینجا حالت التزامی - ⟪लिङ्⟫ - با حالت امری - ⟪लोट्⟫ - همپوشانی دارد)**
:::
مثال:

::: indent
⟪दासो⟫ ⟪ग्राममागच्छेत्⟫ = «بندهٔ پیمان‌بسته بیاید به دهکده»
:::
::: grammar-box
**۲. وقتی که چیزی به عنوان**

*   **ممکن**
*   **محتمل**
*   **به نظر می‌رسد / گمان می‌رود**

**باید نشان داده شود.**
:::
مثال:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं⟫ ⟪न⟫ ⟪शृणुयात्⟫ = "اگر او از روستا می‌رفت، استاد را نمی‌شنید"
:::
::: grammar-box
**۳. جملات موصولی با حالت آرزویی (Optativ) گاهی به معنای: "اگر کسی ..." هستند.**
:::
مثال:

::: indent
⟪यो⟫ ⟪नृतं⟫ ⟪वदेत्स⟫ ⟪नरकं⟫ ⟪पतेत्⟫ = "اگر کسی دروغ می‌گفت، به دوزخ سقوط می‌کرد = اگر کسی دروغ بگوید، به دوزخ سقوط می‌کند"
:::

## 30.5. سَندهی -r پایانی

::: grammar-box
**به جز -ar، همان قواعد ساندھی برای -r پایانی مانند -s پایانی صدق می‌کند.**

**-ar پیش از صامت‌های وزنی به صورت -ar باقی می‌ماند، اما پیش از r- حرف r حذف شده و a- به ā- تبدیل می‌شود.**
:::
مثال‌ها:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
