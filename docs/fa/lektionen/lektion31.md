# درس ۳۱

## ۳۱.۱. کلاس صرفی هفتم (⟪रुधादि⟫ = "⟪रुध्⟫ و غیره")

::: grammar-box
**ساختار:**

**پیش از همخوان‌های پایانی ریشه با درجه آوایی پایین (tiefstufig)، یک پسوند میانجی بینی‌شکل (Nasalinfix) به صورت (-na- یا -n-) درج می‌شود:**

*   **در بن قوی: -na-**
*   **در بن ضعیف: -n-**

**قوانین مربوط به اتصال همخوان‌های پایانی ریشه به پایان‌بندهایی که با همخوان آغاز می‌شوند، همان قوانینی است که برای کلاس صرفی دوم صدق می‌کند.**
:::
مثال‌ها:

⟪युज्⟫ ۷U "پیوندن، به کار بستن"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **اخباری** | **۳. مفرد** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(در میان واژه، ناسال‌ها پیش از گوتورال‌ها با -ṅ- جایگزین می‌شوند) |
| | **۳. جمع** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **آرزویی** | **۳. مفرد** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **۳. جمع** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **اسم مفعولی حال** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brمؤنث: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ ۷U "توقف دادن، به حالت سکون درآوردن"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **اخباری** | **۳. مفرد** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **۳. جمع** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **آرزویی** | **۳. مفرد** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **۳. جمع** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **اسم مفعولی حال** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brمؤنث: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**در برخی از ریشه‌ها، -n- بن حال ضعیف به زمان‌های غیرحالی نیز راه یافته است، بنابراین این ریشه‌ها با یک ناسال درونی (infix) فرض می‌شوند.**
:::
مثال:

**⟪भञ्ज्⟫** 7P "شکستن"

::: indent
*   وجه اخباری حال
    *   3.sg.P. **⟪भनक्ति⟫** (bha-na + j + ti)
    *   3.pl.P. **⟪भञ्जन्ति⟫** (bha + n + j-anti)
*   آینده: **⟪भङ्क्ष्यति⟫** (bha + n + j + sya + ti)
*   مجهول: **⟪भज्यते⟫** (یا از ریشه اصلی **⟪भज्⟫** یا از *bhñj-ya-te)
*   PPP: **⟪भग्न⟫** (احتمالاً از *bhñj + na)
:::
## 31.2. فهرست واژگان

**⟪युज्⟫** 7U **⟪युनक्ति⟫** : زین کردن، یال بستن، کشیدن محکم، متصل کردن ; Ā همچنین: خود را کشیدن (= تلاش کردن)، پیوندن با، تمرکز بر (لکنا، ⟪सप्तमी⟫)
::: indent

از آن:
**⟪युग⟫ n. → ⟪युग⟫ n.:** یوغ، جفت، عصر جهان (چهار عصر جهان وجود دارد:

3. ⟪द्वापर⟫
4. ⟪कलि⟫

**⟪कलियुग⟫** در حدود ۳۱۰۲ قبل از میلاد، سال جنگ **⟪महाभारत⟫** آغاز شد. برای جزئیات بیشتر به باشام، شگفتی‌ها ص ۳۲۳ مراجعه کنید)
