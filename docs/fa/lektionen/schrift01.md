# دواناگاری = ⟪देवनागरी⟫

## تمرین خط ۱

سنسکریت در گذشته و حال با طیف وسیعی از خط‌ها نوشته می‌شود. جدول زیر نمایانگر بخش کوچکی از این خطوط است:

![](/images/schrift001.webp)  
تصویر: نمونه‌های خط سنسکریت
\[منبع تصویر: ویکی‌پدیا، مجوز GNU FD\]

Die wichtigste moderne nordindische Sanskritschrift ist die Devanāgarī: <!-- TODO: Fallback translation -->

![](/images/schrift002.webp)

هر نشانهٔ همخوان، صدای «آ» که پس از آن می‌آید را نیز در بر دارد. اگر بخواهیم همخوان خالص (بدای واکة پسین) بنویسیم، باید آن را با یک خط مورب زیرنویسی‌شده نشان دهیم — ویراما = ⟪विराम⟫:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

مصوت‌های پس از یک همخوان، به جز «a»، چنین نوشته می‌شوند:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ <!-- TODO: Fallback translation -->

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau <!-- TODO: Fallback translation -->

ترتیب نوشتن این ترکیبات هم‌آوا (صامت + مصوت) به این صورت است:

![](/images/schrift003.jpg)

هنگام نوشتن، هر حرف شامل خط افقی زیر نوار بالایی پیش از نوشتن حرف بعدی کامل می‌شود.
