# دواناگاری = ⟪देवनागरी⟫

## تمرین خط ۱

سنسکریت در گذشته و حال با طیف وسیعی از خط‌ها نوشته می‌شود. خلاصه زیر نمونه کوچکی از این خطوط را نشان می‌دهد:

![](/images/schrift001.webp)  
تصویر: نمونه‌های خط سنسکریت
\[منبع تصویر: ویکی‌پدیا، مجوز GNU FD\]

مهم‌ترین خط مدرن شمال هند برای سنسکریت، دواناگاری است:

![](/images/schrift002.webp)

هر نشانه همخوان، یک «آ» که به همخوان می‌پیوندد را نیز نشان می‌دهد. اگر بخواهیم خودِ همخوان خالص (بدون واکل پسین) را بنویسیم، باید آن را با یک اسلش زیرخطی -- ویراما = ⟪विराम⟫ -- مشخص کنیم:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

واکل‌هایی که به یک همخوان می‌پیوندند -- به جز «آ» -- به این صورت نوشته می‌شوند:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

ترتیب نوشتن این ترکیب‌های همخوان + واکل به این صورت است:

![](/images/schrift003.jpg)

هنگام نوشتن، هر حرف شامل خط افقی بالا قبل از نوشتن حرف بعدی کامل می‌شود.

## تمرین

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

بخوانید و تANSKRIP کنید:

⟪तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ⟫
