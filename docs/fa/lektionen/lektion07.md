## ۷.۱. جمله فعلی با مفعول مستقیم

::: grammar-box
**الگو:**
**(فاعل = kartṛ m. = ⟪कर्तृ⟫) – مفعول مستقیم (karman n. = ⟪कर्मन्⟫) – فعل**

به عنوان مثال
- **rāmaḥ phalaṃ khādati** = ⟪रामः फलं खादति⟫ : "راما میوه‌ای را می‌خورد (می‌کند)."
- **brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो देवं यजति⟫ : "براهمن یک خدا را با قربانی (برای دیگری) پرستش می‌کند."
:::
اگر فعل در پاراسمایپادا (Parasmaipada) یا آتم‌نیپادا (Ātmanepada) باشد، مفعول مستقیم (**karman** n. = ⟪कर्मन्⟫) به طور کلی در حالت **اکتیوس** (Wenfall، dvitīyā f. = ⟪द्वितीया⟫) قرار می‌گیرد.


## ۷.۲. حالت اکتیوس (Wenfall، dvitīyā f. = ⟪द्वितीया⟫ = "پایه موردی دوم")

::: grammar-box
**پایان اکتیوس مفرد مذکر و مؤنث پس از مصوت: -m**

| اسم‌های مذکر با پایان | اکتیوس مفرد |
| :--- | :--- |
| **-a**: deva | **devam** :br⟪देवम्⟫ |
| **-i**: kavi | **kavim** :br⟪कविम्⟫ |
| **-u**: guru | **gurum** :br⟪गुरुम्⟫ |
| اسم‌های مؤنث با پایان | اکتیوس مفرد |
| **-ā**: devatā | **devatām** :br⟪देवताम्⟫ |
| **-i**: śruti | **śrutim** :br⟪श्रुतिम्⟫ |
| **-ī**: devī | **devīm** :br⟪देवीम्⟫ |
| **-u**: dhenu | **dhenum** :br⟪धेनुम्⟫ |
:::

| اسم‌های مذکر با پایان | اکتیوس جمع |

| **-a**: deva | **devān** :br⟪देवान्⟫ |

### ۷.۲.۱. اکتیوس مفرد و جمع ضمایر پرسشی و اشاره‌ای

::: grammar-box
| || مذکر | مؤنث | خنثی |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :brچه/چرا؟ | مفرد. | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |
| | جمع. | **kān** :br⟪कान्⟫ | **kās** :br⟪कास्⟫ | **kāni** :br⟪कानि⟫ |
| **tad** :brاو/آن | مفرد. | **tam** :br⟪तम्⟫ | **tām** :br⟪ताम्⟫ | **tad** :br⟪तद्⟫ |
| | جمع. | **tān** :br⟪तान्⟫ | **tās** :br⟪तास्⟫ | **tāni** :br⟪तानि⟫ |
| **etad** :brاینجا این | مفرد | **etam / enam** :br⟪एतम्⟫ / ⟪एनम्⟫ | **etām / enām** :br⟪एताम्⟫ / ⟪एनाम्⟫ | **etad / enad** :br⟪एतद्⟫ / ⟪एनद्⟫ |
| | جمع | **etān / enān** :br⟪एतान्⟫ / ⟪एनान्⟫ | **etās / enās** :br⟪एतास्⟫ / ⟪एनास्⟫ | **etāni / enāni** :br⟪एतानि⟫ / ⟪एनानि⟫ |
| **idam** :brاین | مفرد | **imam / enam** :br⟪इमम्⟫ / ⟪एनम्⟫ | **imām / enām** :br⟪इमाम्⟫ / ⟪एनाम्⟫ | **idam / enad** :br⟪इदम्⟫ / ⟪एनद्⟫ |
| | جمع | **imān / enān** :br⟪इमान्⟫ / ⟪एनान्⟫ | **imās / enās** :br⟪इमास्⟫ / ⟪एनास्⟫ | **imāni / enāni** :br⟪इमानि⟫ / ⟪एनानि⟫ |
:::
شکل‌های **enam** (⟪एनम्⟫) و غیره متعلق به بن **enad** (⟪एनद्⟫) هستند که تنها در برخی از حالت‌ها شکل می‌سازد. این‌ها به جای شکل‌های **etad** و **idam** استفاده می‌شوند، زمانی که چیزی که با آن اشاره شده در پیشینه ذکر شده باشد.
مثلاً **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं देवः⟫ | ⟪एनं यजन्ते⟫ || : "او یک خداست. به او قربانی می‌کنند."


### 7.2.2. کاربرد حالت مفعولی (دویتیایا، dvitīyā f. = ⟪द्वितीया⟫ = "پایه دوم حالت")

::: grammar-box
حالت مفعولی (dvitīyā f. = ⟪द्वितीया⟫) نشان می‌دهد:
۱. در جمله فعلی غیرمفعولی: **مفعول مستقیم** (karman n. = ⟪कर्मन्⟫) عملی که توسط فعل بیان می‌شود:
مثلاً
- **devaṃ yajati** = ⟪देवं यजति⟫ : "او یک خدا را با قربانی ستایش می‌کند."
- **phalam āpnoti** = ⟪फलमाप्नोति⟫ : "او به ثمره (مثلاً عمل خود) می‌رسد."
۲. در افعالی که رفتن، حرکت، هدایت یا مشابه آن را به سمت چیزی بیان می‌کنند، حالت مفعولی هدف حرکت را نشان می‌دهد:
مثلاً
- **narakaṃ gacchati** = ⟪नरकं गच्छति⟫ : "او به جهنم می‌رود."
:::
کاربردهای دیگر حالت مفعولی بعداً بررسی خواهند شد.



## 7.3. ساندی -n پایانی

::: grammar-box
**-n پایانی:**

۱. قبل از اسپارشا‌های نرم کلامی و رتروفلکس و همچنین قبل از **ś-** توسط بینی‌ای که معادل این صداهاست جایگزین می‌شود:
- **-n** قبل از **j-, jh-, ñ-, ś-** » **-ñ**
- **-n** قبل از **ḍ-, ḍh-, ṇ-, ṣ-** » **-ṇ**
مثلاً **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "او کشتیری‌ها را شکست می‌دهد."
**ś-** آغازین معمولاً توسط **ch-** جایگزین می‌شود:
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (در کنار gurūñ śṛṇoti) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "او معلمان را می‌شنود." "او به معلمان گوش می‌دهد."

۲. قبل از **l-** آغازین توسط **-l** با آنوناسیکا (l بینی‌دار، در خط ⟪ल्⟫ با آنوناسیکا ⟪ँ⟫) جایگزین می‌شود:
مثلاً **paśūn + labhate** » ⟪पशूंल्लभते⟫ : "او حیوانات مفید دریافت می‌کند."

۳. قبل از پالیتال، رتروفلکس یا دنتال بی‌صدا آغازین توسط **آnusvāra** + صدای زوزه‌کش معادل این صداها جایگزین می‌شود:
- **-n** قبل از **c-, ch-** » **-ṃś**
- **-n** قبل از **ṭ-, ṭh-** » **-ṃṣ**
- **-n** قبل از **t-, th-** » **-ṃs**
مثلاً **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : "و خدایان (مفعول)"
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : "اما خدایان (مفعول)"

۴. به جز بعد از واکه کوتاه (بعداً بررسی می‌شود)، **-n** پایانی در تمام موارد دیگر تغییر نمی‌کند.
:::

## 7.4. خنثی (napuṃsaka n. = ⟪नपुंसक⟫)

::: grammar-box
**در حالت خنثی، شکل‌های نام (prathamā) و مفعولی (dvitīyā) یکسان هستند.**
:::
### 7.4.1. خنثی از پایه‌های منتهی به -a

::: grammar-box
- **پایان نام / مفعولی مفرد: -m**
مثلاً **phala** خ. = ⟪फल⟫ = "میوه": نام / مفع. مفرد **phalam** = ⟪फलम्⟫
- **پایان نام / مفعولی جمع: -āni**
مثلاً **phala** خ. = ⟪फल⟫: نام / مفع. جمع **phalāni** = ⟪फलानि⟫
:::

## 7.5. کلاس‌های مضارع بی‌واکه

کلاس پنجم مضارع، یک بن مضارع به اصطلاح بی‌واکه می‌سازد، یعنی بن مضارع برخلاف کلاس‌های مضارع دارای واکه (کلاس‌های 1، 4، 6 و 10) به "واکه موضوعی" **-a** ختم نمی‌شود.

::: grammar-box
**کلاس‌های مضارع بی‌واکه دارای تغییر بن هستند، یعنی دو شکل از بن مضارع وجود دارد:**
1. **بن قوی**: درجه بالا (به ندرت درجه کشیده)
2. **بن ضعیف**: درجه پایین

**بن قوی در موارد زیر قرار می‌گیرد:**
- در اخباری مفرد پاراسمپادا مضارع (laṭ) و ماضی ناقص (laṅ)
- در تمام اشخاص اول امری (loṭ) پاراسمپادا و آتمنپادا
- در شخص سوم مفرد امری (loṭ) پاراسمپادا

**تمام شکل‌های دیگر دارای بن مضارع ضعیف هستند.**
:::
### 7.5.1. پایان‌های اولیه شخص سوم جمع در پایه‌های بی‌واکه

::: grammar-box
**در بن‌های مضارع بی‌واکه، پایان‌های اولیه شخص سوم جمع به این صورت است:**
- **پاراسمپادا: -anti**
- **آتمنپادا: -ate**
:::
### 7.5.2. کلاس پنجم مضارع (svādi = ⟪स्वादि⟫ = "سوا و غیره")

::: grammar-box
- **بن قوی**: (معمولاً) ریشه درجه پایین (همانطور که ذکر شد) + **-no-**
- **بن ضعیف**: (معمولاً) ریشه درجه پایین (همانطور که ذکر شد) + **-nu-**

**پیش از پایان‌های مصوتی، در ریشه‌هایی که به مصوت ختم می‌شوند -nu- توسط -nv- جایگزین می‌شود، و در ریشه‌هایی که به همخوان ختم می‌شوند پیش از پایان‌های مصوتی -nu- توسط -nuv- جایگزین می‌شود.**
:::
**مثال‌ها:**

| ریشه:br⟪धातु⟫ | بن قوی | بن ضعیف | پیش از مصوت:br(ضعیف) |
| :--- | :--- | :--- | :--- |
| **āp** :br5 P:br⟪आप्⟫:br"رسیدن" | **āp-no** :br(3.sg. āpnoti = ⟪आप्नोति⟫) | **āp-nu** | **āp-nuv** :br(3.pl. āpnuvanti = ⟪आप्नुवन्ति⟫) |
| **aś** :br5 Ā:br⟪अश्⟫:br"رسیدن" | — | **aś-nu** :br(3.sg. aśnute = ⟪अश्नुते⟫) | **aś-nuv** :br(3.pl. aśnuvate = ⟪अश्नुवते⟫) |
| **su** :br5 U:br⟪सु⟫:br"فشار دادن" | **su-no** :br(3.sg. sunoti = ⟪सुनोति⟫) | **su-nu** :br(3.sg. sunute = ⟪सुनुते⟫) | **su-nv** :br(3.pl. sunvanti = ⟪सुन्वन्ति⟫,:br3.pl. sunvate = ⟪सुन्वते⟫) |
| **śru** :br5 P:br⟪श्रु⟫:br"شنیدن" | **śṛ-ṇo** :br(3.sg. śṛṇoti = ⟪शृणोति⟫) | **śṛ-ṇu** | **śṛ-ṇv** :br(3.pl. śṛṇvanti = ⟪शृण्वन्ति⟫) |


## 7.6. واژه‌نامه

**واژگان زیر را بیاموزید:**

- **aś** 5 آ (aśnute) ⟪अश् अश्नुते⟫ : رسیدن، به دست آوردن
- **āp** 5 پ (āpnoti) ⟪आप् आप्नोति⟫ : رسیدن، به دست آوردن
- **kup** 4 پ (kupyati) ⟪कुप् कुप्यति⟫ : خشمگین شدن
- **krudh** 4 پ (krudhyati) ⟪क्रुध् क्रुध्यति⟫ : خشمگین شدن
- **khād** 1 پ (khādati) ⟪खाद् खादति⟫ : جویدن، خوردن
- **śru** 5 پ (śṛṇoti !) ⟪श्रु शृणोति⟫ : شنیدن (چیزی: مفعولی، کسی را: اضافی یا مفعولی؛ درباره: مفعولی؛ از کسی: اضافی، منهای یا ابزار)
- **su** 5 ی (sunoti) ⟪सु सुनोति⟫ : فشار دادن
- **soma** م. ⟪सोम⟫ : نوشابه پرسیده شده، سوم؛ ماه (اینکه سوم از کدام گیاه فشار داده می‌شد تا امروز مورد بحث است).

- **phala** n. ⟪फल⟫ : میوه (همچنین به معنای مجازی: نتیجه (کارمایی) یک عمل)
- **nṛtya** n. ⟪नृत्य⟫ : رقص

- **aṅga** n. ⟪अङ्ग⟫ : اندام بدن، جزء؛ همچنین = **vedāṅga** = ⟪वेदाङ्ग⟫
- **gam** 1 P (gacchati) ⟪गम् गच्छति⟫ : رفتن (بر طبق دسته‌بندی بومی افعال، به کلاس فعلی 1 تعلق دارد، اما در واقع یک شکل با پسوند تشکیل زمان حال **-ccha-** است: **gam** » مرحله عمیق (**gm** ») **ga-ccha-ti**)

1. sādhuḥ svargaṃ ... (āp, gam, aś)
