# درس ۲۵

## 25.1. ساخت حالت جدایی (⟪पञ्चमी⟫ = "پنجمین پایان حالت")

::: grammar-box
به‌جز در مورد اسم‌های مذکر/خنثی منتهی به -a و همچنین ضمایر، در مفرد در همهٔ طبقات صرفی، شکل‌های حالت ابلاتیو (⟪पञ्चमी⟫) با شکل‌های حالت جنیتیو (⟪षष्ठी⟫) یکسان هستند.

به‌جز در مورد ضمایر شخصی، در همهٔ صرف‌ها در جمع، شکل‌های حالت ابلاتیو با شکل‌های حالت دیتیو (⟪चतुर्थी⟫) یکسان هستند.
:::
اکنون دلیل ترتیب حالات (⟪विभक्ति⟫) در سانسکریت را می‌شناسید: آن‌ها به گونه‌ای چیده شده‌اند که شکل‌های هم‌آوا تا حد امکان در کنار یکدیگر — یا زیرمجموعهٔ هم — قرار گیرند.

::: grammar-box
**ابلاتیو مفرد اسم‌های مذکر/خنثی منتهی به -a**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
ضمایر پرسشی، موصولی و اشاره‌ای:

## 25.2. کاربرد حالت ازی (⟪पञ्चमी⟫)

«ابلاتیو ( Ablativ ) آن چیزی را نشان می‌دهد که ثابت می‌ماند، وقتی که چیز دیگری از آن دور می‌شود.»

پانی‌نی ۲،۳،۲۸ + ۱،۴،۲۴

ابلاتیو ( Ablativ ) عمدتاً به پرسش‌های «از کجا؟»، «چرا؟» پاسخ می‌دهد.

::: grammar-box
۱\. بنابراین ابلاتیو ( Ablativ ) نقطه شروع، خاستگاه و ماده را نشان می‌دهد.

بنابراین ابدیتو همچنین می‌تواند شخص را نشان دهد که از او چیزی خریداری، شنیدن، آرزو و غیره می‌شود.
:::
مثال‌ها:

::: indent
⟪ग्रमादागच्छति⟫ = "او از دهه می‌آید"

⟪अश्वात्पतितः⟫ = "از اسب افتاده"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "از آن‌ها (به) دریافت"
:::
مثال‌ها:

::: indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟫ = «او از معلم دربارهٔ دharma می‌شنود»

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = «براهمن از کشتیریس گاو شیری می‌خواهد»
:::
::: grammar-box
۲\. ابلاتیو در کنار فعل‌هایی با معانی «دور نگه داشتن از»، «محافظت کردن در برابر»، «دفاع کردن در برابر»، «ترسیدن از» می‌آید:
:::
مثال:

::: indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = «او از دشمنان محافظت می‌کند»
:::
::: grammar-box
۳\. ابلاتیو علت یا دلیل را نشان می‌دهد:
:::
مثال‌ها:

::: indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = «او پسرش را از روی خشم می‌کشد»

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = «چون بدی کرده است، به دوزخ می‌رود» («چون کسی است که از طریق او بدی انجام شده»)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = «چون بدی می‌کند/کرده است، به دوزخ می‌رود»
:::
اسم‌هایی که مؤنث نیستند، می‌توانند برای بیان علت یک فعالیت، در حالت ابزار (⟪तृतीया⟫) یا حالت مصدری (⟪पञ्चमी⟫) بیایند. اسم‌های مؤنث معمولاً در این معنا در حالت ابزار می‌آیند، اما گاهی اوقات ممکن است در حالت مصدری نیز بیایند.

## 25.3. پسوند -⟪तस्⟫

::: grammar-box
اگر بخواهیم به‌طور مفرد (به‌صورت واضح) بیان کنیم که واژه در معنای ابلاتیو به کار رفته است، می‌توانیم پسوند -⟪तस्⟫ را به بن واژه اضافه کنیم که قیدهایی با معنای عمدتاً ابلاتیو می‌سازد (پاسخ به پرسش «از کجا؟»):
:::
مثال‌ها:

::: indent
⟪आदितस्⟫ = «از ابتدا، از همان آغاز»

⟪धर्मतस्⟫ = «به‌خاطر دِرمَ، به سبب دِرمَ»
:::
::: grammar-box
پسوند -⟪तस्⟫ همچنین به بن‌های ضمیری می‌چسبد:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) «از آنجا، آنجا، به آنجا، بر آن، آنگاه، برای همین»

⟪यद्⟫ : ⟪यतस्⟫ «از کدام، از چه چیزی، از کجا، کجا، به کجا، چرا، زیرا» (نسبی)

⟪किम्⟫ :  ⟪कुतस्⟫ "از کجا؟" "چرا؟"
:::
## ۲۵.۴. راه‌های دیگر برای بیان دلایل

::: grammar-box
**۱\. جملات وصفی**

جملات وصفی اغلب رابطه‌ای علّی (توجیه‌کننده)، توالی‌مند (پیرو) یا غایی (هدفمند) را با جمله اصلی بیان می‌کنند.

شکل‌های ضمیر موصولی که به عنوان حروف ربط علّی عمل می‌کنند:

*   ابلیتیو (ابلاغی):
    *   ⟪यतस्⟫ ... جمله وابسته (نوبساتز) ... ⟪ततस्⟫ ... جمله اصلی (هائپتساتز) ... = "چون/زیرا ..., بنابراین ..."
    *   ⟪यस्मात्⟫ ... جمله وابسته (نوبساتز) ... ⟪तस्मात्⟫ ... جمله اصلی (هائپتساتز) ... = "چون/زیرا ..., بنابراین ..."
*   اینسترومنتال (ابزار):
    *   ⟪येन⟫ ... جمله وابسته (نوبساتز) ... ⟪तेन⟫ ... جمله اصلی (هائپتساتز) ... = "از طریق/چون ..., از این رو / به همین دلیل ..."
:::
مثال:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = "چون رام ثروت می‌خواهد، او نذر را به جا می‌آورد"
:::
::: grammar-box
**2\. ⟪हि⟫**

جملات اصلی را می‌توان با استفاده از ذره ⟪हि⟩ "زیرا/چون" به هم پیوند داد. جمله‌ای با ⟪हि⟩ (که نمی‌تواند در جایگاه اول باشد، بلکه باید در نثر در جایگاه دوم بیاید) یک توجیه را یا برای جمله قبلی و یا برای جمله بعدی بیان می‌کند:
:::
مثال:

::: indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = "مردان کار شایسته انجام می‌دهند. آن‌ها در واقع به آسمان می‌خواهند بروند."
:::
::: grammar-box
**۳\. اینسترومنتال (⟪तृतीया⟫)**

علاوه بر ابلاتیو (⟪पञ्चमी⟫)، اینسترومنتالیس (⟪तृतीया⟫) نیز برای بیان دلیل یا علت به کار می‌رود. در مورد اسم‌های مؤنث، اینسترومنتالیس به طور کلی الزامی است.
:::
مثال:

::: indent
⟪क्रोधेन⟫ ⟪पुत्रं⟫ ⟪हन्ति⟫ = "او از روی خشم پسرش را می‌کشد" = "او در حال خشم پسرش را می‌کشد"
:::
::: grammar-box
**۴\. اسم‌ها**

علاوه بر این، می‌توان دلایل را به طور طبیعی از طریق ساختارهای زیر بیان کرد:

*   ⟪कारण⟫ n. "علت": ⟪कारणात्⟫ ⟪।⟫ ⟪कारणेन⟫
*   ⟪हेतु⟫ m.
*   سایر اسم‌ها به معنای "علت"

حالت مضاف‌الیه (⟪षष्ठी⟫) یا به عنوان بخش دوم ترکیب‌های اسمی:
:::
مثال:

::: indent
⟪पुण्यस्य⟫ ⟪कारणात्⟫ (⟪हेतोः⟫ و غیره) = «به خاطر فضیلت»
:::
::: grammar-box
**5\. ⟪इति⟫**

می‌توان انگیزه یک فعالیت را با اندیشه‌ای که همراه با ⟪इति⟫ بیان می‌شود، مشخص کرد:
:::
مثال:

::: indent
⟪सम्यक्संबुद्धः⟫ ⟪सुगत⟫ ⟪इत्यानन्दो⟫ ⟪गौतमं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫  = «چون سوگاتا به حقیقت کاملاً بیدار شده است، آناندا از گوتاما درباره آموزه‌اش می‌پرسد» («با این فکر که "سوگاتا به حقیقت کاملاً بیدار شده است" ...»)
:::
