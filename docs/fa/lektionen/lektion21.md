# درس ۲1

## 21.1. ساقه‌های مضارع دیگر با -nt

### 21.1.1. صفت فاعلی مضارع (⟪لَداوِشَه⟫) پاراسمایپادا

::: grammar-box
این مشاریک، یک ساختار اسمی از بن حال است، بنابراین یک مشاریک واقعی می‌باشد. این یک صفت است که نشان می‌دهد کسی یا چیزی که توسط ریشه فعل (+ پیشوند) بیان شده است، همزمان با رخ دادن امری دیگر، در حال انجام آن کار است. همچنین می‌تواند یک وضعیت پایدار را نیز بیان کند.

**مثال‌ها:**

:::
::: indent
«در حالی که پدر می‌خواند، سیگار می‌کشد = پدرِ خواننده سیگار می‌کشد»
«دوستی که هست (یعنی واقعی، اصیل)»
:::
::: grammar-box

| **ساخت صفت فاعلی مضارع پاراسمای‌پادا برای بن‌های مضارع تماتیک (با مصوت):** |||
| :--- | :--- | :--- |
| **مذکر، خنثی** | | |
| | **بن قوی** | بن مضارع + **-nt-** |
| | **بن ضعیف** | بن مضارع + **-t-** |
| **مؤنث** | | |
| | | بن مضارع + **-nt-** + **-ī** (صرف مانند **devī** :br⟪देवी⟫) |
| | **طبقه ششم مضارع** | بن مضارع + **-nt-** + **-ī** :brیا::brبن مضارع + **-t-** + **-ī** |

:::

## 21.3. اشکال مودبانه خطاب

::: grammar-box
**در سنسکریت می‌توان بدون بی‌احترامی، شخص را در دومین شخص مفرد خطاب کرد. اما اگر می‌خواهیم مؤدب باشیم، می‌توانیم از اسمی استفاده کنیم که معنای "عالیجناب" و مانند آن را دارد، و فعل را به سومین شخص مفرد یا جمع قرار دهیم یا از ساختار مجهول استفاده کنیم. افزایش ادب در استفاده از شخص در خطاب به این صورت است:**

:::
::: indent
**شما مفرد (مخاطب) » شما جمع (مخاطبان) » او مفرد (غایب) با اسم مناسب » شما جمع (مخاطبان) با اسم مناسب**
:::
**مهم‌ترین چنین واژه‌ای برای ادب ⟪भवन्त्⟫ است، مؤنث: ⟪भवती⟫ . این واژه در کاربرد خود معادل «شما»ی محترمانه ما است.**
این **⟪भवन्त्⟫** از **⟪भगवन्त्⟫** گرفته شده است، صرف آن مانند اسم‌های منتهی به **-vant** است (به [درس ۱۳](lektion13.md) مراجعه کنید). این **⟪भवन्त्⟫** باید از اسم‌مفعولی حال P **⟪भू⟫** به معنای «شدن» **⟪भवन्त्⟫** متمایز شود: مفرد مذکر اسم «شما» **⟪भवन्त्⟫** به صورت **⟪भवान्⟫** و مفرد مذکر اسم‌مفعولی **⟪भवन्⟫** به صورت ... است.

**مثال‌ها:**

::: indent
**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = «شما چه می‌کنید؟»
:::
محترمانه‌تر:

::: indent
**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**
:::
مؤنث:

::: indent
**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**
:::
واژگان دیگری که می‌توانند به‌طور مشابه مانند **⟪भवन्त्⟫** استفاده شوند:

*   **⟪आर्य⟫** (مؤنث: **⟪आर्या⟫**) "نجیب". به‌عنوان مثال، **⟪यदार्य⟫ ⟪इच्छति⟫** "همان‌طور که مایلید"
*   **⟪महाभाग⟫** "کسی که سهم/بخش او بزرگ است = نجیب". اغلب توسط زنان در خطاب یا هنگام صحبت درباره مردان از طبقه خوب استفاده می‌شود. در سانسکریت محاوره‌ای مدرن بسیار رایج است.

اگر بخواهید نه تنها ادب، بلکه احترام نیز برای کسی ابراز کنید، به جای **⟪भवन्त्⟫** برای کسی که حاضر یا نزدیک است **⟪अत्रभवन्त्⟫** و برای کسی که غایب یا دور است **⟪तत्रभवन्त्⟫** استفاده می‌شود. **⟪अत्रभवन्त्⟫** و **⟪तत्रभवन्त्⟫** را می‌توان به "شما"، "حضرت عالی" و غیره ترجمه کرد:

::: indent
**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = "آیا آن بانوی محترمی که در اینجا حاضر است همسر شماست؟"  
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (در نامه یا مکالمه تلفنی) = "آیا شما خوب هستید؟"
:::
