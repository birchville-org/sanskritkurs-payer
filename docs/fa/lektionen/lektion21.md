# درس ۲۱

## ۲۱.۱. بن‌های مضارع دیگر با پسوند -nt

### ۲۱.۱.۱. اسم مفعول مضارع (⟪लडादेशः⟫) در صرف پاراسمپادا

::: grammar-box
این اسم مفعول، یک ساختار اسمی از بن مضارع است و بنابراین یک اسم مفعول واقعی محسوب می‌شود. این یک صفت است که نشان می‌دهد کسی یا چیزی در حال انجام کاری است که توسط ریشه فعل (+ پیشوند) بیان شده، همزمان با وقوع رویدادی دیگر. همچنین می‌تواند یک وضعیت پایدار را نیز بیان کند.

**مثال‌ها:**

:::
::: indent
"در حالی که پدر می‌خواند، او سیگار می‌کشد = پدرِ خواننده سیگار می‌کشد"  
"یک دوستِ هستی‌بخش (= واقعی، اصیل)"
:::
::: grammar-box

| **ساختار اسم مفعول مضارع پاراسمپادا برای بن‌های مضارع موضوعی:** |||
| :--- | :--- | :--- |
| **مذکر، خنثی** | | |
| | **بن قوی** | بن مضارع + **-nt-** |
| | **بن ضعیف** | بن مضارع + **-t-** |
| **مونث** | | |

:::

## ۲۱.۳. شکل‌های محترمانه خطاب

::: grammar-box
**در سانسکریت می‌توان بدون بی‌احترامی، کسی را با ضمیر دوم شخص مفرد خطاب کرد. اما اگر بخواهیم محترمانه باشیم، می‌توانیم از اسمی استفاده کنیم که معنای «بزرگوار» و مانند آن را می‌دهد، و فعل را به سوم شخص مفرد یا جمع قرار دهیم یا از یک ساختار مجهول استفاده کنیم. افزایش احترام در استفاده از شخص در خطاب به این صورت است:**

:::
::: indent
**۲. مفرد » ۲. جمع » ۳. مفرد با اسم مناسب » ۳. جمع با اسم مناسب**
:::
**مهم‌ترین چنین اسم محترمانه‌ای ⟪भवन्त्⟫ است، مؤنث: ⟪भवती⟫ . این در استفاده معادل «شما»ی محترمانه ما است.**
این ⟪भवन्त्⟫ یک فشرده‌سازی از ⟪भगवन्त्⟫ است، صرف آن مانند اسم‌های منتهی به **-vant** است (به [درس ۱۳](lektion13.md) مراجعه کنید). این ⟪भवन्त्⟫ باید از اسم‌واره زمان حال P فعل ⟪भू⟫ "شدن" ⟪भवन्त्⟫ متمایز شود: مفرد مذکر ⟪भवन्त्⟫ "شما" به صورت ⟪भवान्⟫ است، و اسم‌واره ⟪भवन्⟫.

**مثال‌ها:**

::: indent
**⟪किं भवान्करोति⟫** = **⟪किं भवता क्रियते⟫** = «چه می‌کنید؟»
:::
مؤدبانه‌تر:

::: indent
**⟪किं भवन्तः कुर्वन्ति⟫** = **⟪किं भवद्भिः क्रियते⟫**
:::
مؤنث:

::: indent
**⟪किं भवती करोति⟫** = **⟪किं भवत्या क्रियते⟫**  
**⟪किं भवत्यः कुर्वन्ति⟫** = **⟪किं भवतीभिः क्रियते⟫**
:::
واژه‌های دیگری که می‌توانند به‌شکلی مشابه ⟪भवन्त्⟫ استفاده شوند:

*   ⟪आर्य⟫ (م.: ⟪आर्या⟫) «نجیب». مثلاً **⟪यदार्य इच्छति⟫** «آنچه شما مایلید»
*   ⟪महाभाग⟫ «کسی که سهم/سعادتش بزرگ است = باوقار». اغلب توسط زنان در خطاب یا هنگام صحبت درباره مردان از طبقه خوب استفاده می‌شود. در سانسکریت گفتاری مدرن بسیار رایج است.

اگر بخواهید نه تنها ادب، بلکه احترام نیز برای کسی ابراز کنید، در مورد کسی که حاضر یا نزدیک است به‌جای ⟪भवन्त् अत्रभवन्त्⟫ و در مورد کسی که غایب یا دور است ⟪तत्रभवन्त्⟫ استفاده می‌شود. ⟪अत्रभवन्त्⟫ و ⟪तत्रभवन्त्⟫ را می‌توان با «شما»، «حضرتعالی»، «جناب عالی» و غیره ترجمه کرد:

::: indent
**⟪किमत्रभवत्यत्रभवतां भार्या⟫** = «آیا آن بانوی محترمه (که اینجا حاضر است) همسر شماست؟»  
**⟪किं तत्रभवतां कुशलवृत्तम्⟫** (در نامه یا تماس تلفنی) = «آیا حالتان خوب است؟»
:::

⟪१⟫. ⟪अनादिकालिकसंसारः २⟫. ⟪अनादिमध्यान्तः ३⟫. ⟪महामैत्रीकरुणाचित्तः ४⟫. ⟪सर्वहतान्धकारः⟫

ب) ترجمه کنید:

⟪मृतं दहन्नग्निः सतीमपि दहति ॥१॥ सद्गुरुर्महाकविस्तोत्रैर्महादेवं स्तौति ॥२॥ महान्ति फलान्यदन्तो बाला जलमापि पिबन्ति ॥३॥ पूजां कुर्वञ्जनो यजते च स्तौति च देवताम् ॥४॥ गुरूपनीतनरो द्विजः ॥५॥⟫

⟪जितक्रोधो घ्नन्तमप्यरिं न द्वेष्टि । क्रोधजितस्तु द्वेष्टि ॥६॥⟫
