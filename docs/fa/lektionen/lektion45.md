## 45.2. خطاب مفرد (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**بیشتر خطاب‌های مفرد، بن با پایان بلند هستند.**

به عنوان مثال **⟪देव⟫، ⟪कवे⟫، ⟪शत्रो⟫، ⟪राजन्⟫، ⟪पितर्⟫** و غیره.

**استثناها، مؤنث‌های منتهی به -ā و -ī و همچنین بن‌های منتهی به -in هستند که خطاب مفرد آن‌ها باید به ویژه به خاطر سپرده شود.**
:::
::: no-header
| | خطاب مفرد |
| --- | --- |
| مذکر منتهی به -a | ⟪देव⟫ |
| خنثی منتهی به -a | ⟪फल⟫ |
| مؤنث منتهی به -ā | ⟪देवते⟫ |
| مذکر منتهی به -i | ⟪कवे⟫ |
| مؤنث منتهی به -i | ⟪मते⟫ |
| مذکر منتهی به -u | ⟪शत्रो⟫ |
| مؤنث منتهی به -u | ⟪धेनो⟫ |
| مؤنث منتهی به -ī | ⟪देवि⟫ |
| مذکر منتهی به -ṛ | ⟪पितर्⟫ |
| مؤنث منتهی به -ṛ | ⟪मातर्⟫ |
| مذکر منتهی به -an | ⟪राजन्⟫ |
| خنثی منتهی به -an | ⟪नामन्⟫:br⟪नाम⟫ |
| مذکر منتهی به -man/-van | ⟪आत्मन्⟫ |
| مذکر منتهی به -in | ⟪बलिन्⟫ |
| مذکر منتهی به -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt مذکر | ⟪महन्⟫ |
| mahānt خنثی | ⟪महत्⟫:br= فاعلی |
| مذکر منتهی به -mant/-vant | ⟪गुणवन्⟫ |

## ۴۵.۳. فهرست واژگان

⟪वा⟫ ... ⟪वा⟫ : یا ... یا

## ۴۵.۴. تمرین

الف) به سانسکریت ترجمه کنید (لطفاً برای افعال گذشته از نیم‌ماضی ⟪लङ्⟫ استفاده کنید):

۱. تو جامعه (بوداییان) را تفرقه می‌اندازی.

::: indent
برای تفرقه در جامعه (⟪सङ्घभेद⟫) مراجعه کنید به:

**پایر، آلوئیس (۱۹۴۴–):** وینایاموخا : مفاهیم بنیادین قوانین و حقوق صومعه‌ای در تروادا. -- بخش اول. -- (مواد مربوط به مفاهیم بنیادی بودیسم). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::
۲. آیا از زمین لذت بردید؟

۳. آیا هدیه‌ای از پادشاه دریافت کردی؟

۴. ای مرد مقدس، چرا از خطرات نمی‌ترسی؟

۵. ای پدر، چرا خانواده را ترک می‌کنی؟

۶. ای زن شودرا، آیا بار را به خانه برهمن ثروتمند بردی؟

۷. ای الهی، تو باید خواسته خوشبختی وایسیا که کارهای شایسته انجام داده است، برآورده کنی.

۸. ای فیل‌ها، شما نباید زنجیرها را بشکنید.

۹. ای مرد هم‌تراز شیر، چرا تمام توجه خود را بر مطلق (برهمن) متمرکز نمی‌کنی؟

۱۰. ای شاعر، آیا جهان‌ها را اندازه گرفتی؟

ب) ترجمه کنید:

⟪अर्जुन हतो वा प्राप्स्यसि स्वर्गं जित्वा वा भोक्ष्यसे महीं । तस्माद्भवता योध्यम् ॥१॥ भवति कथमनन्तदुःखमरुणत् ॥२॥ ब्राह्मण किमग्नौ घृतमजुहोः ॥३॥ शत्रो शस्तेण जीवं न छिनत्सि ॥४॥⟫
