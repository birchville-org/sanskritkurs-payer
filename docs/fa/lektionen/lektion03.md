# درس 3

::: deleteme-box
**در این درس یاد می‌گیرید:**
- حالت مرفوع مفرد مؤنث
- حالت مرفوع جمع مذکر و مؤنث
- ساخت مؤنث از مذکر
- ساندهای مصوتی
- Satzsandhi von -ās
:::
## 3.1. فاعل مفرد مؤنث

### 3.1.1. فاعلی مفرد بر -s

همچنین ریشه‌های اسمی زیر که به مصوت ختم می‌شوند، مفرد مرفوع را با **-s** تشکیل می‌دهند:

::: grammar-box
- **مؤنث‌های ختم شده به -i**: مثلاً **śruti** f. "شنیدن" -- مفرد مرفوع: **śrutis** = ⟪श्रुतिस्⟫
- **مؤنث‌های ختم شده به -u**: مثلاً **dhenu** f. "گاو شیری" -- مفرد مرفوع: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. فاعل مفرد بدون پایان

مفرد مرفوع را بدون پسوند تشکیل می‌دهند:

::: grammar-box
- **مؤنث‌های ختم شده به -ā**: مثلاً **devatā** f. "معنوی" -- مفرد مرفوع: **devatā** = ⟪देवता⟫
- **مؤنث‌های ختم شده به -ī**: مثلاً **devī** f. "الهه" -- مفرد مرفوع: **devī** = ⟪देवी⟫
:::
::: important
**توجه!** در کنار آن‌ها، ریشه‌های اسمی مؤنث یک‌بخشی با پسوند -ī وجود دارند که مفرد مرفوع آن‌ها به -s ختم می‌شود: مثلاً dhī f. "فکر" -- مفرد مرفوع: dhīs = ⟪धीस्⟫. همچنین lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "قایق" و tantrī (⟪तन्त्री⟫) f. "سیم" به صورت نامنظم مفرد مرفوع را با -s تشکیل می‌دهند: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. ساخت مؤنث از مذکر

::: grammar-box
**مذکرهای پایان‌یافته به -a:**
- **مونث پایان‌یافته به -ā**: مثلاً **kṣatriya** m. » **kṣatriyā** f. «زن کشتری» = ⟪क्षत्रिया⟫
- **مونث پایان‌یافته به -ī**: مثلاً **brāhmaṇa** m. » **brāhmaṇī** f. «برهمنی» = ⟪ब्राह्मणी⟫

**مذکرهای پایان‌یافته به -u:**
- **مونث پایان‌یافته به -ī**: مثلاً **sādhu** m. » **sādhvī** f. (خوب، زاهد) = ⟪साध्वी⟫
(**-u-** پیش از واکه به **-v-** تبدیل می‌شود، بنابراین **-u- + -ī** » **-vī**)
:::

## 3.3. فاعلی جمع مذکر و مؤنث

::: grammar-box
پایان حالت مرفوع جمع در مذکر و مؤنخ **-as** است.
- **مذکرها با پایان -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **مؤنث‌ها با پایان -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **مذکرها با پایان -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **مؤنث‌ها با پایان -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **مؤنث‌ها با پایان -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **مذکرها با پایان -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **مؤنث‌ها با پایان -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
نکته: **e** شکل تقویت‌شده (**guṇa**) معادل **i**، و **o** شکل تقویت‌شده معادل **u** است.

## 3.4. ساندھی مصوت

::: grammar-box
**حروف صداد ساده‌ای که تفاوتشان تنها در طول است یا اصلاً ندارند، به حرف صدای بلند متناظر «ادغام» می‌شوند:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
به عنوان مثال

devatā + annapūrṇā » devatānnapūrṇā "آناپورنا یک الهه است" = ⟪देवतान्नपूर्णा⟫

> (آناپورنا الهه غذاها و آشپزی است، او به عنوان تجسم پارواتی، همسر شیوا در نظر گرفته می‌شود.)

devī + indrāṇī » devīndrāṇī "ایندرا‌نی یک الهه است" = ⟪देवीन्द्राणी⟫

> (اِندراณี همسر خداوند اِندر است.)

(منبع تصویر: [جزئیات](/fa/licenses#lekt0301))
:::

::: grammar-box
**حروف بی‌واک ساده (به جز -a / -ā) پیش از حروف صدادار ناپیوسته، با حرف نیمه‌واک متناظر جایگزین می‌شوند:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! برای این قاعده به‌ویژه در حالت دوگانه استثناها وجود دارد !!)
:::
مثال:

devī + umā » devy umā "اُما یک/خداوند زن است" = ⟪देव्युमा⟫

> (اوما نامی برای پاروتی، همسر شیوا است)

::: grammar-box
**-a / -ā پیش از مصوت نامشبیه:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::
بنابراین برای این ساندی، طرح زیر صدق می‌کند:

:::
به این نوع افت ریشه که «سوم» نامیده می‌شود، بعداً مراجعه کنید!

مثلاً

śūdrā + itarā » śudretarā « ایتارا یک شودرا زن است ⟪शूद्रेतरा⟫

## 3.5. ساندھی جمله‌ای -ās

::: grammar-box
**-ās wird vor allen stimmhaften Lauten durch -ā ersetzt.**
:::
به عنوان مثال

dvijās + vaiśyāḥ » dvijā vaiśyāḥ «وایسیاها دوجاده‌زاد هستند» = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. فهرست واژگان

**واژگان زیر را بیاموزید:**

**śruti** f. = ⟪श्रुति⟫ : شنیدن، سنت ابدی (نامی برای وداها و براهماṇاها).

**smṛti** f. = ⟪स्मृति⟫ : یادآوری، حافظه، یادآوری مدیتیک = توجه، سنت (مخالف **śruti**). شامل:
- شش **vedāṅga** n. (⟪वेदाङ्ग⟫)
  1. **śikṣā** f. (⟪शिक्षा⟫): تلفظ صحیح
  2. **chandas** n. (⟪छन्दस्⟫): وزن شعر
  3. **vyākaraṇa** n. (⟪व्याकरण⟫): دستور زبان
  4. **nirukta** n. (⟪निरुक्त⟫) : تفسیر واژه، ریشه‌شناسی
  5. **jyotiṣa** n. (⟪ज्योतिष⟫) : نجوم، تقویم‌شناسی
  6. **kalpa** m. (⟪कल्प⟫) : آیین‌شناسی
- **śrautasūtra** n. (⟪श्रौतसूत्र⟫) : متون آموزشی برای اجرای قربانی‌های بزرگ
- **gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : متون آموزشی برای آیین‌ها و قربانی‌های زندگی روزمره
- **dharmasūtra** n. (⟪धर्मसूत्र⟫) و **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : متون آموزشی درباره حقوق و آداب (رفتار صحیح)
- حماسه‌های بزرگ **mahābhārata** n. (⟪महाभारत⟫) و **rāmāyaṇa** n. (⟪रामायण⟫)
- **purāṇa** n. (⟪पुराण⟫)
- **nītiśāstra** n. (⟪नीतिशास्त्र⟫) : متون آموزشی خرد زندگی

**smṛti** همچنین به‌ویژه نامی برای متون آموزشی دهارما است.

**dhenu** f. = ⟪धेनु⟫ : گاو (شیرده).

**paśu** m. = ⟪पशु⟫ : دام اهلی، چهارپایان (مجموعه).

**devatā** f. = ⟪देवता⟫ : ایزد (انتزاعی و عینی).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : برهمن‌زن.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : کشتی‌گیر زن.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : همسر یک کشتی‌گیر.

**vaiśyā** f. = ⟪वैश्या⟫ : ویشیا زن.

**śūdrā** f. = ⟪शूद्रा⟫ : شودرا زن.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : همسر یک شوद्र.

**devī** f. = ⟪देवी⟫ : الهه، به‌ویژه دورگا f. = ⟪दुर्गा⟫، همسر شیوا = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
تصویر: دورگا = ⟪दुर्गा⟫، اوریسا
(منبع تصویر: [جزئیات](/images/lekt0303))
:::
**sādhvī** f. = ⟪साध्वी⟫ : مؤنثِ sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : مؤنثِ guru.

**asmitā** f. = ⟪अस्मिता⟫ : «هویت من»، یعنی باور (نادرست) به اینکه: **من** کسی هستم که می‌بیند و غیره.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : فلسفه (علمی که از طریق استدلال‌های منطقی صحیح به نتیجه‌گیری‌های خود می‌رسد).

**upekṣā** f. = ⟪उपेक्षा⟫ : بی‌توجهی، بی‌طرفی.

**karuṇā** f. = ⟪करुणा⟫ : همدلی، شفقت.

**muditā** f. = ⟪मुदिता⟫ : شادی، به‌ویژه همدردی (مخالف حسادت).

## 3.7. تمرین

**الف) جملات زیر را به جمع تبدیل کنید:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**ب) با جایگذاری، جملات اسمی بسازید:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**ج) به مؤنث تبدیل کنید:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**د) به سنسکریت ترجمه کنید:**

1. اوما یک الهه است.
2. اوما یک الهه است.
3. ودای شروتی است.
4. معلم‌ها الهه هستند.
5. گاوهای شیری حیوانات اهلی هستند.
6. شاعران معلم‌اند.
7. مردان مقدس شودرها هستند.
