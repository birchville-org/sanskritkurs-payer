# درس ۴

::: deleteme-box
**در این درس یاد می‌گیرید:**
- ضمایر پرسشی و ضمائر اشاره در حالت مرفوع (نominative)

## ۴.۱. پرسش‌های تکمیلی ساده (پرسش واژگانی) و پاسخ‌ها

### ۴.۱.۱. ضمایر پرسشی و ضمائر اشاره

#### ۴.۱.۱.۱. ضمیر پرسشی (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | حالت مرفوع مفرد | حالت مرفوع جمع |
| :--- | :--- | :--- |
| **خنثی** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **مذکر** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **مونث** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### ۴.۱.۱.۲. ضمائر اشاره (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **بن‌ها** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"او (مذکر/خنثی)، آن":br(اشاره به ذکر شده)** | **etad = ⟪एतद्⟫:br"این (مذکر/خنثی)":br(بسیار نزدیک به گوینده)** | **idam = ⟪इदम्⟫:br"این (مذکر/خنثی)":br(نزدیک)** |

| **حالت مرفوع جمع** ||||
| **خنثی** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **مذکر** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |

**در مورد حالت مرفوع مفرد مذکر:**
- **sa, eṣa** (⟪स एष⟫) پیش از همه آواها به جز **-a** کوتاه می‌آید.
- **so, eṣo** (⟪सो एषो⟫) پیش از **-a** می‌آید که با آواگراها حذف (الیدی) می‌شود.
- **saḥ, eṣaḥ** (⟪सः एषः⟫) فقط در وقف (پایان جمله، پایان شعر) می‌آید.

برای اینکه بتوان با این ضمایر (sarvanāman n.) جمله ساخت، دانستن قواعد ساندی زیر ضروری است:

### ۴.۱.۲. ساندیِ پایان‌واژه‌ای -m

::: grammar-box
**پایان‌واژه -m پیش از همخوان‌ها با انوسوارا (-ṃ) جایگزین می‌شود. در پایان جمله یا شعر و پیش از مصوت‌ها، -m حفظ می‌شود.**
:::
### ۴.۱.۳. ساندیِ پایان‌واژه‌ای -e

::: grammar-box
۱. **پیش از a-، -e بدون تغییر می‌ماند: a- آغازین با آواگراها حذف می‌شود:**
مثال: ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "این‌ها آتش‌ها"

۲. **پیش از سایر مصوت‌های غیر از a- کوتاه، -e معمولاً با -a همراه هیاتوس جایگزین می‌شود. همچنین جایگزینی آن با -ay نیز رخ می‌دهد:**
مثال: ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (به ندرت: imay īśvarāh = ⟪इमयीश्वराः⟫) "این‌ها اربابان"
:::
### ۴.۱.۴. ساندیِ پایان‌واژه‌ای -d

::: grammar-box
**پایان‌واژه -d در وقف و پیش از گوتورال‌های بی‌صدا (k, kh) و لبیالی‌ها (p, ph) با -t جایگزین می‌شود.**

جایگزینی آن پیش از سایر همخوان‌ها بعداً بررسی خواهد شد. فعلاً چنین برخورد آواهایی را پرهیز کنید!
:::
### ۴.۱.۵. فرمول‌های پرسشی

نمونه‌ای از پرسش‌های دیگر:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ پاسخ: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (در اینجا می‌توان در جمله اسمی، فاعل را مثلاً به ابتدا برد تا تأکید بر پیوند با پرسش شود.)

یادداشت: پاسخ‌هایی که شما می‌توانید با دانش سانسکریت خود تاکنون به چنین پرسش‌هایی بدهید، طبیعی است که هنوز از هر نظر با سانسکریت اصیل و روان همخوانی کامل ندارند.


## ۴.۲. تمرین

**الف) با واژگان زیر به صورت شفاهی پرسش‌هایی بر اساس الگوی viṣṇuḥ kaḥ (⟪विष्णुः कः⟫) بسازید و به پرسش‌ها به سانسکریت پاسخ دهید:**

śruti, śiva, brāhmaṇa, dvija (جمع), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**ب) برای تمرین خواندن زیر، پرسش‌هایی بر اساس الگوی etat kim (⟪एतत्किम्⟫) بسازید و به پرسش‌ها با واژگان مشخص‌شده و ضمائر اشاره، مثلاً eṣa bālaḥ (⟪एष बालः⟫) پاسخ دهید:**
