# درس ۴

::: deleteme-box
**در این درس یاد می‌گیرید:**
- ضمایر پرسشی و ضمائر اشاره در حالت مرفوع (نominativ)
- ساندیِ پایان‌واژه‌ای -m
- ساندیِ پایان‌واژه‌ای -e
- ساندیِ پایان‌واژه‌ای -d

## 4.1. پرسش‌های تکمیلی ساده (پرسش‌های کلمه‌ای) و پاسخ‌ها

### 4.1.1. Fragepronomina und ضمایر اشاره

#### 4.1.1.1. ضمیر پرسشی (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | مفرد مرفوع | جمع مرفوع |
| :--- | :--- | :--- |
| **خنثی** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **مذکر** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **مونث** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. ضمایر اشاره (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **بن‌ها** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"er, sie, es; der, die, das":br(Erwähnte)** | **etad = ⟪एतद्⟫:br"dieser, diese, dieses":br(dem Sprechenden sehr Nahe)** | **idam = ⟪इदम्⟫:br"dieser, diese, dieses":br(Nahe)** |
| **مفرد مرفوع** ||||
| **خنثی** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **مذکر** | **sa, so saḥ = ⟪स⟫ ⟪सो⟫ ⟪सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष⟫ ⟪एषो⟫ ⟪एषः⟫** | **ayam = ⟪अयम्⟫** |
| **مونث** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **جمع مرفوع** ||||
| **خنثی** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **مذکر** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **مونث** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**برای مفرد مرفوع مذکر:**
- **sa, eṣa** (⟪स⟫ ⟪एष⟫) پیش از همه آواها به جز **-a** کوتاه می‌آید
- **so, eṣo** (⟪सो⟫ ⟪एषो⟫) پیش از **-a** می‌آید که با آگراها حذف (الیدیسه) می‌شود
- **saḥ, eṣaḥ** (⟪सः⟫ ⟪एषः⟫) فقط در مکث (پایان جمله، پایان شعر) می‌آید

برای اینکه بتوان با این ضمایر (sarvanāma n.) جمله ساخت، دانستن قواعد زیر در مورد ساندھی لازم است:

### 4.1.2. سَندھی -m پایانی

::: grammar-box
**مخرج -m پیش از هم‌صداها به انوسوارا (-ṃ) تبدیل می‌شود. در پایان جمله یا بیت و پیش از مصوت‌ها، -m حفظ می‌گردد.**
:::
### 4.1.3. ساندای -e پایانی

::: grammar-box
1. **پیش از a-، -e بدون تغییر می‌ماند: a- آغازین با آگراها حذف می‌شود:**
مثال: ete + agnayas » ete 'gnayaḥ = ⟪एते⟫ ⟪ऽग्नयः⟫ "این آتش‌ها"

2. **پیش از سایر مصوت‌های کوتاه a-، -e معمولاً با -a همراه هیاتوس جایگزین می‌شود. همچنین گاه با -ay نیز جایگزین می‌گردد:**
مثال: ime + īśvarās » ima īśvarāḥ = ⟪इम⟫ ⟪ईश्वराः⟫ (به‌ندرت: imay īśvarāh = ⟪इमयीश्वराः⟫) "این اربابان"
:::
### 4.1.4. سَندھی -d پایانی

::: grammar-box
**مخرج -d در وقف و پیش از گوتورال‌های بی‌واکا (k, kh) و لبیالی‌ها (p, ph) به -t تبدیل می‌شود.**

جایگزینی در مقابل سایر همخوان‌ها بعداً بررسی می‌شود. فعلاً از چنین برخوردی آواها خودداری کنید!
:::
### 4.1.5. عبارات پرسشی

نمونه‌ای دیگر از پرسش:

> viṣṇuḥ kaḥ? = ⟪विष्णुः⟫ ⟪कः⟫ پاسخ: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (در اینجا می‌توان در جمله اسمی، فاعل را مثلاً به ابتدا برد تا تأکید بر پیوند با پرسش صورت گیرد.)

یادداشت: پاسخ‌هایی که شما با دانش فعلی سانسکریت خود به چنین پرسش‌هایی می‌دهید، طبیعی است که هنوز از هر نظر با سانسکریت اصیل و روان همخوانی کامل ندارند.

## 4.2. تمرین

**الف) با استفاده از کلمات زیر، بر اساس الگوی viṣṇuḥ kaḥ (⟪विष्णुः⟫ ⟪कः⟫) به صورت شفاهی سوال طرح کنید و پاسخ‌ها را به زبان سانسکریت بدهید:**

śruti, śiva, brāhmaṇa, dvija (جمع), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**ب) برای تمرین خواندن زیر، پرسش‌هایی بر اساس الگوی etat kim (⟪एतत्किम्⟫) طرح کنید و با استفاده از کلمات مشخص‌شده و ضماییر اشاره به آن‌ها پاسخ دهید؛ مثلاً eṣa bālaḥ (⟪एष⟫ ⟪बालः⟫):**
