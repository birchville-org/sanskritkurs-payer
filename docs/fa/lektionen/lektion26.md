# درس ۲۶

## ۲۶.۱. قانون سیری‌شدگی برای -s- در میان واژه

::: grammar-box
**-s-** با **-ṣ-** جایگزین می‌شود، اگر **k, r, l** یا یک **مصوت** — به جز **a, ā** — بلافاصله یا تنها با فاصله ⟪अनुस्वार⟫ یا ⟪विसर्ग⟫ پیش از آن بیاید و صدای دیگری به جز **ṛ, r** پس از آن دنبال شود.

این ساندها همچنین **⟪दुस्⟫-** را پیش از گوتورال‌ها و لبیال‌های بی‌واکا در کلمه‌های مرکب دنبال می‌کند.
:::
*مثال‌ها:*
::: indent
⟪तेषाम्⟫ (از: *te-sām*)

اما: ⟪तासाम्⟫ (*tā-sām*)
:::
## ۲۶.۲. قانون سیری‌شدگی برای دنتال‌ها در میان واژه

::: grammar-box
دنتال‌های بسته پس از رتروفلکس‌ها (شامل **-ṣ-**) با معادل رتروفلکسی خود جایگزین می‌شوند:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** به دلیل **i** پیشین، **ṭh** به دلیل **ṣ** پس از آن)*
:::
## ۲۶.۳. ساندهای واژه‌ای برای پالاتال، گوتورال، ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

برای مثال‌ها به پایین مراجعه کنید
:::
## ۲۶.۴. قانون دیسی‌میلیاسیون هواس گراسمن

::: grammar-box
**پیامد مستقیم دو هواس (هواس - مصوت - هواس) از دست دادن هواس صدای اول است:**

مثال:

:::
::: indent
\*dhu(gh) » du(g)h
:::
**اگر صدای دوم به دلیل قوانین آوایی خود را از هواس بزداید، هواس دوباره در صدای اول ظاهر می‌شود.**

مثال‌ها: به پایین مراجعه کنید برای آینده از  ⟪दुह्⟫ و  ⟪बुध्⟫

## ۲۶.۵. وورشتاندی برای -m، -n پیش از زیش‌لاوت

::: grammar-box
**پیش از زیش‌لاوت‌ها، -n و -m با -ṃ- جایگزین می‌شوند:**

مثال: س. در زیر، آینده از ⟪मन्⟫
:::
## ۲۶.۶. کاربرد آینده ساده (⟪ऌत्⟫، ⟪भविष्यन्ती⟫ مؤنث)

::: grammar-box
**آینده ساده (⟪ऌत्⟫، ⟪भविष्यन्ती⟫ مؤنث) بیانگر است:**

**آینده**
**یک عمل قصد شده یا خواسته ("من می‌روم"، "می‌خواهم بروم")**
**یک انتظار ("اینگونه خواهد شد")**
**امید**
**ترس**
**احتمال**
**نظر گوینده**
**دستور**

**آینده تا حدی در رقابت با اپتاتیو قرار دارد (بعداً ببینید).**
:::
مثلاً ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = "کسی که آرزوی بستن نذر دارد، به معبد می‌رود."

## ۲۶.۷. شکل‌گیری آینده ساده (⟪ऌत्⟫، ⟪भविष्यन्ती⟫  مؤنث)

::: grammar-box
**آینده ساده:**

:::
::: indent
**بن آینده + پایان اولیه**
:::
::: grammar-box
**بن آینده:**

:::
::: indent
**(معمولاً) ریشه با درجه بالا + -sya**  
**یا**  
**(معمولاً) ریشه با درجه بالا + -i- + -sya (= - iṣya)**
:::
**اینکه کدام ریشه چه شکلی از بن آینده را دارد، باید با شکل‌های بن یاد گرفت!**  
**به طور کلی، فرم ریشه و حرف ربط آینده با مصدر مطابقت دارد.**  
**برخی ریشه‌ها می‌توانند آینده را اختیاریاً با و بدون حرف ربط -i- شکل دهند.**  
**اسم مفعول پاراشماپادا آینده با افزودن پسوند -nt- به بن آینده شکل می‌گیرد، مؤنث اختیاریاً با -ntī یا -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫، ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
مثال‌ها:

::: grammar-box

| ریشه | آینده سوم شخص مفرد P (Ā) |
| :--- | :--- |
| ⟪नी⟫ | ⟪नेष्यति⟫ |
| ⟪भू⟫ | ⟪भविष्यति⟫ (⟪भो⟫ +  ⟪इ⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दिश्⟫ | ⟪देक्ष्यति⟫ (⟪देश्⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दृश्⟫ | ⟪द्रक्ष्यति⟫ |
| ⟪पच्⟫ | ⟪पक्ष्यति⟫ |
| ⟪प्रच्छ्⟫ | ⟪प्रक्ष्यति⟫ |
| ⟪यज्⟫ | ⟪यक्ष्यति⟫ |
| ⟪सृज्⟫ | ⟪स्रक्ष्यति⟫ |
| ⟪पद्⟫ | ⟪पत्स्यति⟫ |
| ⟪अद्⟫ | ⟪अत्स्यति⟫ |
