## ۱۲.۱. مشارک ماضی مجهول (PPP)

یک راه برای ساخت جملات مجهول گذشته، استفاده از ساختار با مشارک ماضی مجهول (PPP) است.

::: grammar-box
**در واقع، PPP یک مشارک واقعی نیست، زیرا از بن زمان ساخته نمی‌شود. بلکه بیشتر یک ساختار اسمی برای ریشه با پسوند اولیه -ta یا -na است. به همین دلیل در دستور زبان هندوستان از پسوند kta سخن می‌گوییم.**
:::

### ۱۲.۱.۱. طرح کلی برای افعال متعدی

::: grammar-box
**فاعل (kartṛ) در حالت ابزاری (tṛtīyā) -- مفعول مستقیم (karman) در حالت فاعلی (prathamā) -- مشارک ماضی مجهول**

در این مورد، PPP با مفعول از نظر تعداد، حالت و جنس مطابقت دارد.

به فعل کمکی («بودن») نیازی نیست.

مثال‌ها:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = «(بهشت توسط فرد شایسته به دست آمد) = فرد شایسته بهشت را به دست آورد.»
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = «(توسط برهمنان، الهه با قربانی ستایش شد) = برهمن الهه را با قربانی ستایش کرد.»
:::

### ۱۲.۱.۲. طرح I برای افعال لازوم و افعال حرکت

::: grammar-box
**فاعل (kartṛ) در حالت فاعلی (prathamā) -- مشارک ماضی مجهول**

در این مورد، PPP با فاعل از نظر تعداد، حالت و جنس مطابقت دارد. مشارک ماضی «مجهول» در افعال لازوم (افعال بدون مفعول مستقیم) و افعال حرکت، معنای فعال دارد.

مثال:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = «زن کشتیری به شهر رفت.»
:::

### ۱۲.۱.۳. طرح II برای افعال لازوم و افعال حرکت

::: grammar-box
**فاعل (kartṛ) در حالت ابزاری (tṛtīyā) -- PPP در حالت فاعلی مفرد مذکر**

مثال:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = «(توسط کشتیری (به شهر) رفت) = کشتیری (به شهر) رفت.»

ساختار بر اساس طرح II بسیار نادرتر از ساختار بر اساس طرح I است.
:::

## ۱۲.۲. در مورد معنای PPP

بنابراین، آنچه «مشارک ماضی مجهول» نامیده می‌شود برای افعال متعدی در اصل معنای مجهول دارد (**āpta** = «رسیده (شده)») و برای افعال لازوم و افعال حرکت معنای فعال دارد (**gata** = «رفته»)؛ اما برخی افعال وجود دارند که PPP آن‌ها می‌تواند هم معنای فعال و هم معنای مجهول داشته باشد:

به عنوان مثال
- **gata** = ⟪गत⟫ = «رفته» (فعال)؛ اما همچنین: **gato mārgaḥ** = ⟪गतो मार्गः⟫ = «راهی که طی شده» (مجهول)
- **āpta** = ⟪आप्त⟫ = «رسیده شده» (مجهول)، «دارای رسیدن» (فعال)


## ۱۲.۳. شکل‌دهی PPP

::: grammar-box
روش‌های شکل‌دهی زیر وجود دارد (برای هر ریشه باید PPP مربوط به آن را یاد گرفت!):

**(معمولاً) ریشه در سطح عمیق**

- **+ -ta**
- با حرف ربط **-i-** قبل از آن: **-ita**
- بدون حرف ربط: **-ta**
- **+ -na**

ریشه‌های مؤنث عبارتند از: **-tā**، **-itā**، **-nā**؛ مفرد خنثی مانند **phala** n صرف می‌شود.
:::

### 12.3.1. اسم مفعول گذشته (PPP) با پسوند -ta (kta)

#### 12.3.1.1. بدون واکه پیوند -i- (aniṭ)

*aniṭ* = «بدون (*an-*) پیشوند شده با پسوند (*-i-) *t*» (یعنی بدون واکه پیوند *i*).

::: grammar-box
بدون واکه پیوند، اسم مفعول گذشته (PPP) به طور کلی از ریشه‌هایی که با واکه ختم می‌شوند و همچنین بسیاری از ریشه‌های دیگر ساخته می‌شود، بدون اینکه بتوان قاعده ثابتی برای آن تعیین کرد که در مورد کدام ریشه‌های ساختاریافته واکه پیوند ظاهر می‌شود یا نمی‌شود.

فهرستی از ریشه‌های *aniṭ* در کیلهورن، *دستور زبان* § 298 یافت می‌شود.
:::
**مثال‌ها:**

::: grammar-box
| ریشه | PPP (kta) |
| :--- | :--- |
| **bhū** 1 P:br(⟪भू⟫) | **bhū-ta** :br(⟪भूत⟫) |
| **smṛ** 1 P:br(⟪स्मृ⟫) | **smṛ-ta** :br(⟪स्मृत⟫) |
| **nṛt** 4 P:br(nṛt-ta):br(⟪नृत्त⟫) | **nṛt-ta** :br(⟪नृत्त⟫) |
| **nī** 1 U:br(⟪नी⟫) | **nī-ta** :br(⟪नीत⟫) |
| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |
| **su** 5 U:br(⟪सु⟫) | **su-ta** :br(⟪सुत⟫) |
| **gam** 1 P:br(⟪गम्⟫) | **ga-ta** (\< \*gm-ta):br(⟪गत⟫) |
| **ji** 1 P:br(⟪जि⟫) | **ji-ta** :br(⟪जित⟫) |
| **śru** 5 P:br(⟪श्रु⟫) | **śru-ta** :br(⟪श्रुत⟫) |
| **kṛ** 8 U:br(⟪कृ⟫) | **kṛ-ta** :br(⟪कृत⟫) |
| **tan** 8 U:br(⟪तन्⟫) | **ta-ta** (\< \*tn-ta):br(⟪तत⟫) |
| **iṣ** 6 P:br(⟪इष्⟫) | **iṣ-ṭa** :br(⟪इष्ट⟫) |
:::
#### 12.3.1.2. با واکه پیوند -i- (seṭ)

*seṭ* = *sa-iṭ* = «با (*sa-*) پیشوند شده با پسوند (*-i-) *t*» (یعنی با واکه پیوند *i*).

**مثال‌ها:**

::: grammar-box
| ریشه | PPP (kta) |
| :--- | :--- |
| **kup** 4 P:br(⟪कुप्⟫) | **kup-i-ta** :br(⟪कुपित⟫) |
| **khād** 1 P:br(⟪खाद्⟫) | **khād-i-ta** :br(⟪खादित⟫) |
| **rakṣ** 1 P:br(⟪रक्ष्⟫) | **rakṣ-i-ta** :br(⟪रक्षित⟫) |
| **vad** 1 P:br(⟪वद्⟫) | **ud-i-ta** (\< \*vd-i-ta):br(⟪उदित⟫) |
:::

## 12.4. قوانین ترکیب آوایی در واژه

در ساخت‌های *aniṭ*، قوانین زیر ترکیب آوایی در واژه باید مورد توجه قرار گیرند. **این قوانین برای درک کل دستور شکل‌شناسی سانسکریت بسیار مهم هستند.**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p پیش از انسداد بی‌واک (مثلاً t, th) بدون تغییر می‌مانند:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct توسط kt = ⟪क्त्⟫ جایگزین می‌شود:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt توسط ṣṭ = ⟪ष्ट्⟫ جایگزین می‌شود:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. انسداد هم‌صدا بی‌واک – به جز j – پیش از صدای بی‌واک توسط هم‌صدا بی‌واک متناظر خود جایگزین می‌شود:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (مهم برای کلاس دوم فعل حال) |
| **5. jt توسط kt یا ṣṭ جایگزین می‌شود (اختیاری نیست!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. انسداد هم‌صدا واکدار + انسداد بی‌واک » انسداد هم‌صدای بی‌واک + انسداد واکدار (قانون واکداری بارثولوما):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t با ḍh (با کشش i یا u قبلی) جایگزین می‌شود؛ یا با gdh. پیش از چنین ḍh ای، a (به‌ندرت ā) با o جایگزین می‌شود:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh ۱ (gūhati) «پنهان کردن»):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.6. تمرین

**A) از جملات فعال درس [Lektion 7](/lektionen/lektion07)، تمرین A، جملات مجهول گذشته را برای افعال لازم و افعال حرکتی به صورت جملات فعال گذشته تشکیل دهید.**

**B) اسم‌های مفعولی گذشته (PPP) مربوط به شکل‌های فعلی درس [Lektion 10](/lektionen/lektion10)، تمرین A را تشکیل دهید. توجه داشته باشید که به یک شکل مانند sṛjati، PPPها در هر سه جنسیت (مذکر، مؤنث و خنثی) متناظر هستند.**

**C) جملات درس [Lektion 10](/lektionen/lektion10)، تمرین C را به صورت مجهول در زمان گذشته بنویسید.**
