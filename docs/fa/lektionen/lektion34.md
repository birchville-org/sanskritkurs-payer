# درس 34

## 34.1. ماضی (⟪लिट्⟫)

در سنسکریت کلاسیک، از بن ماضی کامل فقط افعال خبری و اسم‌های فاعلی وجود دارند.

::: grammar-box
**دو نوع ساخت ماضی کامل وجود دارد:**
*   **ماضی کامل تکراری = ⟪द्वित्वलिट्⟫**
*   **ماضی کامل پیراسته = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**ماضی کامل پیراسته (⟪अनुप्रयोगलिट्⟫) به کار می‌رود:**
1. **در صرف‌های مشتق (علت‌آور، تمناوری، مکرر، اسم‌ساز)**
2. **در ریشه‌هایی که با یک مصوت بلند (به جز ā-) آغاز می‌شوند، یا با یک مصوت (به جز a-) پیش از دو همخوان**
3. **در برخی ریشه‌های دیگر**
:::
## 34.2. Das reduplizierte Perfekt (⟪द्वित्वलिट्⟫) <!-- TODO: Fallback translation -->

### 34.2.1. درجه‌بندی پایه

::: grammar-box
**ساختار:**

**بن قوی:** مفرد، پاراسمایاپادا
*   **ریشه با افزوده شدن دوباره‌سازی و درجه بلند یا کشیده + پایان ماضی نقلی**

**بن ضعیف:** تمام شکل‌های دیگر
*   **ریشه با افزوده شدن دوباره‌سازی و درجه کوتاه + پایان ماضی نقلی**
:::
::: grammar-box
**به طور کلی (حتی خارج از ماضی نقلی)، ریشه‌هایی با فرم زیر فاقد تغییر درجه بن هستند:**
*   **(همخوان)-همخوان-مصوت بلند-همخوان**
*   **(همخوان)-همخوان-مصوت کوتاه-همخوان-همخوان**

**در ماضی نقلی، علاوه بر موارد فوق، ریشه‌هایی با فرم زیر نیز فاقد تغییر درجه بن هستند:**
*   **a-همخوان**
*   **ā-همخوان**
:::

### 34.2.3. مصوت ربط -i-

::: grammar-box
**پیش از پایانۀ سوم شخص جمع (ā- (-re)) همواره واکۀ اتصال -i- می‌آید، پیش از سایر پایان‌های همخوانی که با آن آغاز می‌شوند در بیشتر ریشه‌ها.**
:::
### 34.2.4. Reduplikation konsonantisch anlautender Wurzeln <!-- TODO: Fallback translation -->

::: grammar-box
**قواعد مربوط به تکرار همخوان‌های آغازین، همان قواعدی هستند که در [درس ۳۳](lektion33.md) ارائه شده‌اند.**

**واکۀ تکرار در ریشه‌های همخوانی-آغاز، همان واکه کوتاه ریشه است.**

**دیفثونگ‌های پیش از همخوان، به واکه کوتاه سطح پایین متناظر کاهش می‌یابند.**

**ṛ، ṝ، ḷ و دیفتون‌های پایانی با -a- دوباره تولید می‌شوند.**
:::
مثال‌ها:

::: grammar-box

| Wurzel | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | *:sig[⟪बि⟫]*⟪भेद⟫ |
| ⟪मुच्⟫ | *:sig[⟪मु⟫]*⟪मोच⟫ |
| ⟪भृ⟫ | *:sig[⟪ब⟫]*⟪भार⟫ |

:::
::: grammar-box
**برخی ریشه‌هایی که با y یا v آغاز می‌شوند، با i یا u دوباره‌سازی می‌کنند که در شکل‌های ضعیف با واکه ریشه «ادغام» می‌شود.**
:::
مثال‌ها:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. تکرار ریشه‌های آغاز شده با واکه

::: grammar-box
**۱. حروف الفای آغازین a- و ā- با reduplication (تکرار) به صورت a- می‌آیند، بنابراین ā- ظاهر می‌شود.**
:::
مثال‌ها:

::: grammar-box

| Wurzel | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "sein" und ⟪अस्⟫ 4 "werfen" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**۲. ریشه‌هایی که با i- آغاز می‌شوند، در بن قوی به صورت syllable تکرار iy- و در بن ضعیف به صورت i- ظاهر می‌شوند که با واکه ریشه به ī- «ادغام» می‌یابد. همین قاعده برای u- آغازین نیز صدق می‌کند.**
:::
مثال‌ها:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**۳. ریشه‌هایی که با a- پیش از دو همخوان یا با ṛ- آغاز می‌شوند، به عنوان بخش تکرار (Reduplikation) ān- دارند**
:::
مثال‌ها:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. انواع ماضی نقلی تکراری

## 34.4. ماضی نقلی نوع اول: ماضی نقلی بدون تغییر ریشه

::: grammar-box
**نوع اول فعل ماضی کامل (بدون تغییر ریشه) دارای ریشه‌های از انواع زیر است:**
*   **(همخوان)-همخوان-بلندمصوت-همخوان**
*   **(همخوان)-همخوان-کوتاهمصوت-همخوان-همخوان**
*   **a-همخوان**
*   **ā-همخوان**
:::
