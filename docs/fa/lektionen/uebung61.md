# تمرین 61

درس ۶۱ پایان دورهٔ زبان سنسکریت است و تمرین نوشتاری دیگری ندارد.

با مطالعهٔ اسم‌های ریشه‌ای، آیندهٔ پیرفرست و مشتقات انتسابی، پایه‌های لازم برای خواندن متون اصلی سنسکریت فراهم شده است. این دوره با دعای سنتی به گَنِش (⟪श्रीगणनाथ⟫) پایان می‌یابد که نشانگر گذار از کتاب درسی به مطالعهٔ مستقل است.
