# Lezione 43

## 43.1. Desinenze personali della seconda persona (मध्यमः = "persona *media*")

::: grammar-box
| | परस्मैपदम् || आत्मनेपदम् ||
| --- | --- | --- | --- | --- |
| | **Singolare** | **Plurale** | **Singolare** | **Plurale** |
| **Desinenze primarie** | -si | -tha | -se | -dhve |
| **Desinenze secondarie** | -s | -ta | -thās | -dhvam |
| **Desinenze perfettiche** | -tha | -a | -se | -dhve |
:::

Si noti che la desinenza secondaria della seconda persona plurale è identica alla desinenza secondaria della terza persona singolare della coniugazione ātmanepada.

## 43.2. Formazione delle forme verbali della seconda persona (मध्यमः)

Seconda persona:

*   Singolare: "tu"
*   Plurale: "voi" (più di due!)

## 43.3. Il pronome personale di seconda persona

*   Singolare: त्वद् "tu"
*   Plurale: युष्मद् "voi"

::: grammar-box
| | एकवचनम् (त्वद्) | बहुवचनम् (युष्मद्) |
| --- | --- | --- |
| **प्रथमा** | त्वम् | यूयम् |
| **द्वितीया** | त्वाम् त्वा | युष्मान् वस् |
| **तृतीया** | त्वया | युष्माभिस् |
| **चतुर्थी** | तुभ्यम् ते | युष्मभ्यम् वस् |
| **पञ्चमी** | त्वत् | युष्मत् |
| **षष्ठी** | तव ते | युष्माकम् वस् |
| **सप्तमी** | त्वयि | युष्मासु |
:::

Le forme त्वा, ते, वस् non possono essere utilizzate all’inizio di una frase o di un verso. Inoltre, non possono essere impiegate prima di च, वा, एव e di altre particelle simili:

::: indent
त्वां मां च "te e me"
:::
