# Lezione 61

## 61.1. Declinazione dei nomi radicali in -ā, -ī, -ū

### 61.1.1. Nomi radicali in -ā alla fine di तत्पुरुष (Tatpuruṣa)

::: grammar-box
**Davanti a desinenze vocaliche, la vocale tematica nelle forme deboli dei casi assume la forma ridotta (stadio di indebolimento) Ø.**
:::

La declinazione al maschile e al femminile è identica.

### 61.1.3. Nomi radicali in -ī alla fine di तत्पुरुष (tatpurusha)

::: grammar-box

## 61.2. Il futuro perifrastico (लुट्)

::: grammar-box
**Oltre al futuro semplice (ऌत्), esiste un futuro perifrastico (लुट्). Secondo la dottrina dei grammatici indiani, esso viene utilizzato per indicare il futuro lontano ("dopo il giorno corrente"), mentre il futuro semplice indica il futuro prossimo ("nel giorno corrente"). Nel sanscrito classico, sembra che non venga solitamente fatta distinzione nell'uso dei due futuri.**
:::

Formazione:

Il futuro perifrastico si forma unendo un nome d'agente in -tṛ con il presente del verbo अस् 'essere'. Come terza persona si utilizza il nome semplice nella corrispondente quantità numerica, senza distinzione di genere grammaticale. Nelle combinazioni con अस्, il nome assume in tutte le persone e i numeri la forma del singolare nominale in -tā.

Le desinenze del futuro perifrastico sono quindi:

|   | परस्मैपदम् | आत्मनेपदम् | | | | |
| --- | --- | --- | --- | --- | --- | --- |
|   | Singolare | Duale | Plurale | Singolare | Duale | Plurale |
| 1\. Terza persona | \-tāsmi   | | | | | |
(-tā + asmi) | \-tāsvas | \-tāsmas   | | | | |
(-tā smas) | \-tāhe | \-tāsvahe | \-tāsmahe | | | | |
| 2\. Seconda persona | \-tāsi | \-tāsthas | \-tāstha | \-tāse | \-tāsāthe | \-tādhve |
| 3\. Prima persona | \-tā | \-tārau | \-tāras | \-tā | \-tārau | \-tāras |

::: grammar-box
**Forma della radice: La radice ha generalmente la stessa forma del futuro semplice. Lo stesso vale per la vocale di giunzione -i-.**
:::

Esempi:

| दा 3U | दातास्मि, दतासि, दाता ecc. |
| --- | --- |
| भू 1P | भवितास्मि ... भाविता ecc. |
| तुद् 6U | तोत्तास्मि ... तोत्ता ecc. |
| गै 1P | गातास्मि ... गाता ecc. |

Paradigma:

दा 3U

::: grammar-box
|   | परस्मैपदम् | आत्मनेपदम् | | | | |
| --- | --- | --- | --- | --- | --- | --- |
|   | Singolare | Duale | Plurale | Singolare | Duale | Plurale |
| 1\. Terza persona | दातास्मि | दातास्वस् | दातास्मस् | दाताहे | दातास्वहे | दातास्महे |
| 2\. Seconda persona | दातासि | दातास्थस् | दातास्थ | दातासे | दातासथे | दाताध्वे |
| 3\. Prima persona | दाता | दातारौ | दातारस् | दाता | दातारौ | दातारस् |
:::

::: grammar-box
**Solo molto raramente il verbo अस् è separato dal tema nominale.**
:::

## 61.3. L’Intensivum (Frequentativum) (चर्करीतम्)

::: grammar-box
**Da ogni radice monosillabica, che inizia con una consonante, delle prime nove classi di presente, può essere formato un Intensivum (चर्करीतम्); vale a dire: con poche eccezioni, non può essere formato un Intensivum da radici bisillabiche (ad es. जागृ), da radici che iniziano con una vocale e da radici della decima classe di presente (चुरादिगण).**
:::

L’Intensivum significa:

*   che una persona o cosa fa o subisce ripetutamente ciò che è espresso dalla radice  
    कृ 8U: चेक्रीयते / चर्करीति "egli fa di continuo"  
    भू 1P: बोभूयते / बोभवीति "egli è (diventa) spesso"  
     
*   che una persona o cosa fa o subisce intensamente ciò che è espresso dalla radice:  
    कृ 8U: चेक्रीयते / चर्кरीति "egli fa intensamente, egli fa con vigore"  
     
*   nelle radici che esprimono un movimento, l’Intensivum significa un movimento curvo:  
    व्रज् 1P:  वव्रज्यते "egli cammina con curve" (NON: "egli cammina spesso")  
     
*   in alcune radici (elenco: Kielhorn, Grammatik § 458b) l’Intensivum esprime biasimo:  
    लुप् 6U: लोलुप्यते "egli taglia male"  
    सद् 1P: सासद्यते "egli si siede male"

::: media
![](/images/lekt6104.jpg)
Fig.: सर्पो वव्रज्यते ॥
(Fonte dell'immagine: [Dettagli](/licenses#lekt6104))
:::
::: grammar-box
**Formazione dell’Intensivum:**

**Esistono due tipi di formazione dell’Intensivum:**
:::

*   Intensivum in Ātmanepada
*   Intensivum in Parasmaipada

Entrambi sono formati dalla radice reduplicata con reduplicazione forte. Entrambi non differiscono nel significato. Entrambi possono essere formati dalle stesse radici.

### 61.3.1. Intensivum in Ātmanepada

::: grammar-box
**Formazione:**

**radice reduplicata + -ya-**

**Forma della radice: in generale come nel passivo, cioè solitamente al grado zero (guṇa/zero-grade):**
:::

Esempi:

::: indent
स्वप् 2P: Pass. सुप्यते ; Intens. सोषुप्यते
दा 3U: Pass. दीयते ; Intens. देदीयते
:::

Le regole nel dettaglio si trovano in Kielhorn, *Grammatik* § 461.

Reduplicazione: secondo le regole generali. La vocale di reduplicazione, tuttavia, al posto di a, i, u diventa ā, e, o.

Esempi:

| दा 3U | देदीय- |
| --- | --- |
| भू 1P | बोभूय- |
| कृ 8U | चेक्रीय- |
| जीव् 1P | जेजीव्य- |
| शास् 2P | शेशिष्य- |
| ज्ञा 9U | जाज्ञाय- |

Le radici della forma -a-Nasale non allungano la vocale nella sillaba di reduplicazione, ma ripetono il nasale.

::: indent
ad es. यम् 1P: यंयम्य-
:::

In alcune radici, tra la vocale della sillaba di reduplicazione e la consonante iniziale della radice, interviene -nī- o -rī- (-rī- nelle radici che contengono un ṛ nell'intensivum).

::: indent
ad es.
पत् 1P: पनीपत्य-
वृत् 1Ā: वरीवृत्य-
:::

::: grammar-box
**Coniugazione:**

*   **Stema del presente: come un Ātmanepada della quarta classe di presente (दिवादिगण).**
*   **Passivo e gli altri temi temporali: se al -ya- del tema intensivo precede una vocale, il -ya- viene sostituito da -y-; se precede una consonante, il -ya- cade:**
    *   **Passivo Presente: बुध् : बोबुध्यते ; भू : बोभूय्यते**
    *   **Perfetto: perifrastico: बोबुधाञ्चक्रे ; बोभूयाञ्चक्रे**
    *   **Aoristo: Aoristo in iṣ (Aoristo 5): अबोबुधिष्ट ; अबोभूयिष्ट**
    *   **Futuro: seṭ: बोबुधिष्यते ; बोभूयिष्यते**
    *   **Futuro perifrastico: बोबुधिता ; बोभूयिता**
:::

### 61.3.2. Intensivo in Parasmaipada

::: grammar-box
**Stema del presente (le altre forme sono estremamente rare): formazione e coniugazione come un verbo della 3ª classe del presente (juhotyādi-gaṇa), con la differenza che la vocale della sillaba di reduplicazione è di livello alto (udātta), mentre nel caso di -a- è di livello allungato (dīrgha).**
:::

Al singolare dell'indicativo presente, nonché alla 2ª e 3ª persona singolare dell'imperfetto e all'imperativo 3ª persona singolare, può essere inserita una -ī- tra la radice e la desinenza. Se questa -ī- viene inserita, una vocale breve nella penultima posizione non deve subire guṇa.

Per quanto riguarda la reduplicazione con nasale, nonché l'inserimento di -nī- o -rī-, vale quanto detto per l'Intensivo in Ātmanepada. Invece di -rī-, può comparire facoltativamente -ri-.

## 61.4. Denominativa (नामधातु)

Le denominativa (नामधातवः), a differenza dei verbi trattati finora, non derivano da una radice verbale, ma da un tema nominale. In questo contesto si distinguono diversi tipi di formazione.

### 61.4.1. Formazione senza suffisso particolare, Parasmaipada

:::: grammar-box
**Significato:**

::: indent
**una persona o una cosa si comporta in modo simile a ciò che è designato dal tema nominale, o ne è simile.**
:::
::::

Coniugazione:

::: indent
nel tema del presente come un verbo della prima classe del presente (भ्वादिगण). Se il nome ha come ultima vocale una vocale, solo l'ultima vocale viene trattata come la vocale radicale della prima classe. La -a finale cade davanti alla vocale tematica. La vocale prima della nasale finale viene sostituita dalla corrispondente vocale lunga.
:::

Esempi:

| कवि m. "poeta" | कवयति "si comporta come un poeta" |
| --- | --- |
| भू f. "terra" | भवति "si comporta come la terra" |
| पितृ "padre" | पितरति "si comporta come un padre" |
| कृष्ण m. Kṛṣṇa | कृष्णति "si comporta come Kṛṣṇa" |
| माला f. "corona" | मालाति "è simile a una corona" |
| राजन् m. "re" | राजानति "si comporta come un re" |

### 61.4.2. Formazione con suffisso -ya, Parasmaipada

::: grammar-box
**Significato:**

*   **qualcuno desidera ciò che è designato dal tema nominale**
*   **qualcuno tratta o considera una persona o una cosa come ciò che è designato dal tema nominale**
:::

Formazione della radice:

::: indent
prima del suffisso -ya, la finale del tema nominale subisce le seguenti modificazioni:

*   a, ā » ī : पुत्र » पुत्रीय-
*   i, u  » ī, ū : कवि » कवीय-
*   ṛ » rī : कर्तृ » कर्त्रीय-
*   o » av : गो » गव्य-
*   au » āv : नौ » नाव्य-
*   la nasale finale cade, mentre la vocale precedente viene trattata secondo le regole sopra indicate: राजन् » राजीय-
*   le altre consonanti finali restano invariate
:::

Esempi:

::: grammar-box
| पुत्र m. "figlio" | पुत्रीयति "egli desidera un figlio" |
| --- | --- |
| कवि m. "poeta" | कवीयति "egli desidera un poeta" |
| गो f. "mucca" | गव्यति "egli desidera una mucca" |
| राजन् m. "re" | राजीयति "egli desidera un re" |
| विष्णु m. Viṣṇu | विष्णूयति "egli tratta qualcuno come Viṣṇu" |
| प्रासाद m. "palazzo" | प्रासादीयति "egli considera (ad esempio la sua capanna) come un palazzo" |
:::

Si presti attenzione al significato di:

| तपस् n. "ascetismo" | तपस्यति "egli pratica l'ascetismo" |
| --- | --- |
| नमस् n. "riverenza" | नमस्यति "egli riverisce" |

### 61.4.5. Formazione con il suffisso -ya, Ātmanepada

:::: grammar-box
**Significato:**

::: indent
**qualcuno si comporta come ciò che è designato dal tema nominale, o gli assomiglia.**
:::
::::

Formazione:

*   finale -a » -ā
*   finale -ā rimane invariata
*   altrimenti come prima di -ya, Parasmaipada (vedi sopra 4.2.)
*   finale -as opzionalmente » -ā
*   tema femminile generalmente » tema maschile

Esempi:

| कृष्ण m. Kṛṣṇa | कृष्णायते "egli si comporta come Kṛṣṇa" |
| --- | --- |

## 61.5. Il Benedittivo (आशीर्लिङ्)

:::: grammar-box
**Significato:**

::: indent

:::

**radice in grado profondo (guru) + yās + desinenza secondaria**

## 61.6. Il condizionale (ऌङ्)

**Il condizionale (ऌङ्) si utilizza quando si vuole esprimere, nelle proposizioni condizionali, che quanto è indicato come condizione non è / non è stato / non sarà il caso. In tali frasi, il condizionale deve essere impiegato sia nella proposizione condizionale sia nella proposizione principale.**
:::

Esempio:

::: indent
सुवृष्टिश्चेदभविष्यत्सुभिक्षमभविष्यत् "Se ci fosse stata (o ci fosse) una buona pioggia, ci sarebbe stato (o ci sarebbe) un abbondante nutrimento. (Ma non ha piovuto [abbastanza].)"
:::

::: grammar-box
**Formazione del condizionale (ऌङ्):**

**Augmento + tema del futuro semplice (ऌत्) + desinenze secondarie**
:::

cioè come un imperfetto (लङ्) rispetto al tema del futuro.

Esempio: अदास्यम् ; अभविष्यम् ; अतोत्स्यम्

Paradigma:

भू "essere, divenire"
