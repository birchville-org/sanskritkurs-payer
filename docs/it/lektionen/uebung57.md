# Esercizio 57

## A) Trasformazioni dell’Aoristo

Traduci e determina le seguenti forme e forma le corrispondenti forme dell’**Aoristo**. Fuori dai Causativi e dalle radici che formano l’**aoristo in s**, tra parentesi è indicata la classe dell’aoristo corrispondente:

:::grammar-box
| Nr. | Form | Bestimmung / Bedeutung | Aorist |
|:---|:---|:---|:---|
| ⟪१⟫. | **⟪पेचिथ⟫** | *⟪पच्⟫* 1U: 2. Sg. Perf. P. (tu fosti) | **⟪अपाक्षीः⟫** |
| ⟪२⟫. | **⟪अवक्⟫** (⟪३⟫) | *⟪वच्⟫* 2P: 2. 3. Sg. Impf. P. (tu parlavi / egli parlava) | **⟪अवोचः⟫ / ⟪अवोचत्⟫** |
| ⟪३⟫. | **⟪सोष्यसि⟫** | *⟪सु⟫* 1/2P: 2. Sg. Fut. P. (tu ti moltiplicherai) | **⟪असौषीः⟫** |
| ⟪४⟫. | **⟪छिन्दे⟫** | *⟪छिद्⟫* 7U: 1. Sg. Ind. Präs. Ā. (io taglio) | **⟪अच्छित्सि⟫** |
| ⟪५⟫. | **⟪कुरुषे⟫** | *⟪कृ⟫* 8U: 2. Sg. Ind. Präs. Ā. (tu agisci per tuo interesse) | **⟪अकृथाः⟫** |
| ⟪६⟫. | **⟪आधत्ते⟫** | *⟪आ⟫-⟪धा⟫* 3Ā: 3. Sg. Ind. Präs. Ā. (egli depone) | **⟪आधित⟫** |
| ⟪७⟫. | **⟪पद्यते⟫** | *⟪पद्⟫* 4Ā: 3. Sg. Ind. Präs. Ā. (egli va) | **⟪अपादि⟫** |
| ⟪८⟫. | **⟪जिगाय⟫** | *⟪जि⟫* 1P: 1. 3. Sg. Perf. P. (io trionfai / egli trionfò) | **⟪अजैषीत्⟫** |

| ⟪१२⟫. | **⟪दिग्धे⟫** | *⟪दिह्⟫* 2U: 3. Sg. Ind. Präs. Ā. (egli unge) | **⟪अदिग्ध⟫** |
| ⟪१३⟫. | **⟪प्लवध्वे⟫** | *⟪प्लु⟫* 1Ā: 2. Pl. Ind. Präs. Ā. (voi nuotate) | **⟪अप्लोढ्वम्⟫** |
| ⟪१४⟫. | **⟪तस्थिथ⟫** (⟪१⟫) | *⟪स्था⟫* 1P: 2. Sg. Perf. P. (tu stavi) | **⟪अस्थाः⟫** |

| ⟪२२⟫. | **⟪सिध्यथ⟫** (⟪२⟫) | *⟪सिध्⟫* 4P: 2. Pl. Ind. Präs. P. (voi siete alla meta) | **⟪असिधत⟫** |
| ⟪२३⟫. | **⟪निन्य⟫** | *⟪नी⟫* 1U: 2. Pl. Perf. P. (voi avete condotto) | **⟪अनैष्ट⟫** |
| ⟪२४⟫. | **⟪कर्षन्ति⟫** | *⟪कृष्⟫* 1P: 3. Pl. Ind. Präs. P. (essi tirano) | **⟪अकार्क्षुः⟫ / ⟪अक्राक्षुः⟫** |
