# Devanāgarī = देवनागरी

## Esercizio di Scrittura 1

Il sanscrito è stato e viene scritto in una varietà di scritture. La seguente panoramica offre una piccola selezione di queste scritture:

![](/images/schrift001.jpg)  
Fig.: Campioni di scrittura Sanscrito

La più importante scrittura nord-indiana moderna è la Devanāgarī:

!*[](/images/schrift002.jpg)*

Ogni segno consonantico include un "a" che segue la consonante. Se si desidera scrivere la consonante pura (senza la vocale successiva), occorre indicarlo con un segno di barra inferiore -- virāma = विराम --:

क् = k, च् = c, ट् = ṭ, त्  = t, प् = p

Le vocali che seguono una consonante -- eccetto "a" -- si scrivono così:

का = kā, कि = ki, की = kī, कु = ku, कू = kū, कृ = kṛ, कॄ = kṝ, कॢ  = kḷ

के = ke, कै = kai, को = ko, कौ = kau

L'ordine nella scrittura di queste combinazioni di Consonante + Vocale è:

![](/images/schrift003.jpg)

Durante la scrittura, ogni lettera, incluso il tratto orizzontale superiore, viene completata prima di scrivere la lettera successiva.

## Esercizio

Scrivete in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

Leggete e traslitterate:

तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ

Esercizio di lettura aggiuntivo:

पिता Vater, कपि Affe, कृत getan,  टीका Subkommentar, तत् dieses, तट Ufer, पत् dahinschießen, पट Gewebe, काच Glas,  काकुत् Gaumen, चित् wahrnehmen, पृच् mischen,  पोटक Knecht, चेतु Absicht, तौतातित Anhänger des Kumārila (Mīmāṃsā), तूत Maulbeerbaum, पीत getrunken,  पीति Trank, कॢप्  passen, कृपते er jammert, पुटी Falte, चापि desgleichen, तोक Nachkommenschaft, तृपत् satt, पॄ füllen, कृकाटी Halsgelenk, पूपौ zwei Kuchen, पैतृकी väterlich (fem.), कौट betrügerisch, कच Haupthaar, कुतपे auf der Ziegenhaardecke, कुचौ Busen, चकिता erschrocken (fem.)
