# Esercizio 53

L'esercizio per la Lezione 53 consiste nell'analisi metrica (determinazione dello schema śloka) di tutti i versi appresi nelle lezioni precedenti. 

Poiché si tratta di un'ampia attività di ripasso e analisi, non è presente un soluzionario separato nel senso classico. Le soluzioni derivano dall'applicazione delle regole trasmesse nella Lezione 53 ai testi già noti.
