# Lezione 32

## 32.1. I tempi passati

Nella letteratura sanscrita più antica e tra i grammatici indigeni i tre tempi del passato sono distinti nettamente nel loro uso:

*   l’Aoristo (लुङ् , अद्यतनी) indica o semplicemente il completamento di un’azione o ciò che è avvenuto nel giorno corrente, il passato prossimo  
*   l’Imperfetto (लङ्) indica ciò che è avvenuto prima del giorno corrente, il passato remoto  
*   il Perfetto (लिट्) indica, come l’Imperfetto, il passato remoto, ma, a differenza dell’Imperfetto, è usato solo per eventi che il parlante non ha visto personalmente  

Nella letteratura sanscrita classica i tre tempi passati sono usati senza distinzione di significato (eccezione: il poema d’arte di भारवि  किरातार्जुनीय).

## 32.2. L’Imperfetto (लङ्)

**Formazione:**  

Augment a‑ + tema del presente + desinenza secondaria  

Le tre persone del singolare Parasmaipada dell’imperfetto, per le radici atematiche, si formano dal tema forte del presente; tutte le altre forme dal tema debole del presente.  

L’Imperfetto ha solo l’indicativo.

**Esempi**

> भू 3 sg. Impf. P. अभवत् (a‑bhava‑t)  
> सु  
> * 3 sg. Impf. P. असुनोत् (a‑suno‑t)  
> * 3 pl. Impf. P. असुन्वन् (a + sunu + an)

## 32.3. Regole per l’augment

1. Se l’augment a‑ precede una radice che inizia per vocale, l’augment e l’iniziale della radice si fondono nella **वृद्धि** della vocale radice.  

   **Esempi**

   |            | 3 sg. Impf. | 3 pl. Impf. |
   |------------|------------|------------|
   | इष्        | ऐच्छत् (a‑+ iccha‑t) |            |
   | इ          | ऐत् (a‑+ e + t) | आयन् (a + i + an) |
   | आस्        | आस्त (a + ās‑ta) |            |

2. Se un prefisso precede una radice, l’augment a‑ si inserisce **dopo** il prefisso e **immediatamente** prima della radice.  

   **Esempi**

   |            | 3 sg. Impf. |
   |------------|------------|
   | आगम्       | आगच्छत् (ā + a + gaccha‑t) |
   | संगम्      | समगच्छत् (sam‑a‑gaccha‑t) |
   | उपगम्      | उपागच्छत् (upa + a + gaccha‑t) |
   | उपागम्     | उपागच्छत् (upa + ā + a + gaccha‑t) |
