# Lektion 28

## 28.1. Das Kausativum (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Si vis exprimere quod aliquis vel aliquid persuadet vel efficit ut alius vel aliud faciat aut patiatur, quod per radicem (cum vel sine praebito) exprimitur, causativum adhibetur (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫).**

Exemplum:
⟪गम्⟫ "ire" » Causativum: ⟪गमयति⟫ "ei facit ut aliquis eat; mittit"
⟪दृश्⟫ "videre" » Causativum: ⟪दर्शयति⟫ "facit videre = ostendit"
:::

## 28.2. Constructio causativa cum causativo (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Schema 1:**

**Si radix, cui causativum innititur (cum vel sine praebito), INTRANSITIVA est (id est, quod obiectivum accusativum secum habere non potest) vel motum, scientiam, informationem vel cibum exprimit:**

**Agens (⟪कर्ता⟫) causativi in casu nominativo (⟪प्रथमा⟫) — Agens actionis alicuius imperatae in casu accusativo (⟪द्वितीया⟫) — (Finis motus, objectum cognitionis etc. in casu accusativo = ⟪द्वितीया⟫) — Verbum in causativo**
:::
Exempla:

⟪दुर्जनो⟫ ⟪रामं⟫ ⟪मोहयति⟫ = "homo malus facit ut Rāma turbetur = Rāmam turbat = facit ut Rāma erraret"
Resultatum: ⟪रामो⟫ ⟪मुह्यति⟫ = "Rāma turbatus est / caecatus est / errat."

⟪रामः⟫ ⟪शत्रून्स्वर्गं⟫ ⟪गमयति⟫ = "Rāma facit inimicos in caelum ire = mittit inimicos in caelum"
Resultatum: ⟪शत्रवः⟫ ⟪स्वर्गं⟫ ⟪गच्छन्ति⟫ = "inimici vadunt ad caelum / veniunt in caelum"

⟪गुरू⟫ ⟪रामं⟫ ⟪वेदार्थं⟫ ⟪वेदयति⟫ = "Magister facit Rāmam sensum Vedarum intelligere = explicat / docet Rāmam sensum Vedarum"
Resultatum: ⟪रामो⟫ ⟪वेदार्थं⟫ ⟪वेत्ति⟫ = "Rāma novit / intelligit sensum Vedarum"

⟪स⟫ ⟪रामं⟫ ⟪वेदमध्यापयति⟫ = "docet Rāma Vēdam"
Resultatum: ⟪रामो⟫ ⟪वेदमधीते⟫ "Rāma studet Vēdam"

⟪रामो⟫ ⟪देवानामृतमाशयति⟫ = "Rāma deos immortalitatis cibum edere facit = deis immortalitatis cibum ad edendum dat" (⟪अश्⟫ 9 "edere")
Resultatum: ⟪देवा⟫ ⟪अमृतमश्नन्ति⟫ "Dei immortalitatis cibum edunt"

::: grammar-box
**Schema 2:**

**Apud verba transitiva (praeter ea quae in Schema 1 memorata sunt). Item apud omnia verba, cum id quod causativum designatur causatur (si causativum est causativi):**

**Agens (⟪कर्ता⟫) causativi in Nominativo (⟪प्रथमा⟫) — Agens actionis causatae in Instrumentali (⟪तृतीया⟫) — Objectum actionis causatae in casu, quem post verbum simplex haberet (id est, plerumque in Accusativo) — Verbum in Causativo**
:::
::: indent
Exempla:
(⟪स⟫) ⟪रामेण⟫ ⟪भार्यां⟫ ⟪त्याजयति⟫ = "Ille facit ut Rāma uxorem suam relinquat"
Effectus: ⟪रामो⟫ ⟪भार्यां⟫ ⟪त्यजति⟫ = "Rāma uxorem suam relinquit"

⟪विष्णुमित्रो⟫ ⟪रामेण⟫ ⟪गोविन्दं⟫ ⟪गमयति⟫ = "Viṣṇumitra iubet Rāma ut Govindam mittat = Viṣṇumitra mittit Rāma ut Govindum mittat"
Resultatum: ⟪रामो⟫ ⟪गोविन्दं⟫ ⟪गमयति⟫ = "Rāma mittit Govindum"
Resultatum huius resultati: ⟪गोविन्दो⟫ ⟪गच्छति⟫ = "Govinda vadit"
:::
::: grammar-box
**Exceptiones ad Schema 1:**

**Construuntur etiam secundum Schema 2 haec verba:**

**Causativum ad:**
- **⟪नी⟫ "ducere"**
- **⟪वह्⟫ "vehere" (solum quando agens actionis causatae non est vehens)**
- **⟪स्मृ⟫ "repraesentare" (sunt exceptiones)**
- **⟪अद्⟫ "edere"**
- **⟪खाद्⟫ "masticare"**
:::
Exempla:

⟪रामो⟫ ⟪भृत्येन⟫ ⟪भारं⟫ ⟪नाययति⟫ ⟪वाहयति⟫ ⟪वा⟩ = "Rāma iubet servum onus portare vel vehere"
Resultatum: ⟪भृत्यो⟫ ⟪भारं⟫ ⟪नयति⟫ ⟪वहति⟫ ⟪वा⟫ = "Servus onus portat vel vehit"

⟪रामो⟫ ⟪बालेनान्नमादयति⟫ ⟪खादयति⟫ ⟪वा⟫ = "Rāma puerum cibum edere vel manducare facit"
Resultatum: ⟪बालो⟫ ⟪ऽन्नमत्ति⟫ ⟪खादति⟫ ⟪वा⟫ = "puer cibum edit vel manducat"

(⟪स⟫) ⟪रामेण⟫ ⟪स्मारयति⟫ = "Id facit ut Rāma meminerit"
Resultatum: ⟪रामः⟫ ⟪स्मरति⟫ = "Rāma meminit"

::: grammar-box
**Haec causativa tam secundum schemata I quam secundum schemata II construere possunt:**

- **⟪हृ⟫ "tenere, capere"**
- **⟪कृ⟫ "facere, agere"**
- **Ātmanepadakausativum ad ⟪दृश्⟫**
:::
Exempla:

⟪रामो⟫ ⟪भृत्यं⟫ ⟪कटं⟫ ⟪कारयति⟫ ⟪हारयति⟫ ⟪वा⟫ = "Rāma iubet servum stragulum (⟪कट⟫ f.) facere vel adferre"
aut:
⟪रामो⟫ ⟪भृत्येन⟫ ⟪कटं⟫ ⟪कारयति⟫ ⟪हारयति⟫ ⟪वा⟫
Resultatum: ⟪भृत्यः⟫ ⟪कटं⟫ ⟪करोति⟫ ⟪हरति⟫ ⟪वा⟫ = "Servus stragulum facit vel adfert"

⟪रामो⟫ ⟪बालं⟫ ⟪प्रतिमां⟫ ⟪दर्शयते⟩ = "Rāma puerum imaginem videre facit = puerum imaginem ostendit (sua interest)"
aut:
⟪रामो⟫ ⟪बालेन⟫ ⟪प्रतिमां⟫ ⟪दर्शयते⟫
Effectus: ⟪बालः⟫ ⟪प्रतिमां⟫ ⟪पश्यति⟫ = "puer imaginem videt"

Si causativum in constructione passiva adhibetur, schema sequens fere semper applicatur:

::: grammar-box
**Schema A (Constructio passiva):**

**Agens causativi in Instrumentali (⟪तृतीया⟫) — Agens actionis causatae in Nominativo (⟪प्रथमा⟫) — Objectum actionis causatae in casu, quem post verbum simplex haberet (id est, plerumque in Accusativo) — Verbum in causativo**
:::
Exempla:

⟪गुरुणा⟫ ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गम्यते⟫ = "Magister Rāmum in vicum mittit"
Resultatum: ⟪रामो⟫ ⟪ग्रामं⟫ ⟪गच्छति⟫ = "Rāmus in vicum vadit"

⟪रामेण⟫ ⟪भृत्यः⟫ ⟪कटं⟫ ⟪कार्यते⟫ = "Rāma iubet servum stramen facere"
Resultatum: ⟪भृत्यः⟫ ⟪कटं⟫ ⟪करोति⟫ = "Servus stramen facit"

⟪रामेण⟫ ⟪भृत्यो⟫ ⟪भारं⟫ ⟪हार्यते⟫ = "Rāma iubet servum onus adferre"
Resultatum: ⟪भृत्यो⟫ ⟪भारं⟫ ⟪हरति⟫ = "Servus onus adfert"

## 28.3. Formationis radix praesentis ad causativum (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Ad radicem causativam desinentes thematici praesentis**
:::
Sunt varii typi formationis:

::: grammar-box
**Typus formationis 1: (plerumque) radix sublimior + -aya-**
:::
Exempla:

| Wurzel | Kausativ 3. sg. Indikativ Präsens | Bedeutung |
| :--- | :--- | :--- |
| ⟪विश्⟫ | ⟪वेशयति⟫ | er/sie/es lässt eintreten, führt hinein |
| ⟪लुभ्⟫ | ⟪लोभयति⟫ | begehren machen, begehrlich machen, verlocken |
| ⟪दृश्⟫ | ⟪दर्शयति⟫ | sehen machen = zeigen |
| ⟪वृत्⟫ | ⟪वर्तयति⟫ | sich drehen machen, wenden (transitiv), rollen (transitiv), ins Rollen bringen |

::: grammar-box
**Typus formationis 2: radix producta + -aya-**

**Saepe in radicibus vocaliter desinentibus, et in radicibus in quibus post -a- consonans finalis sola sequitur.**
:::
Exempla:

| Wurzel | Kausativ 3. sg. Indikativ Präsens | Bedeutung |
| :--- | :--- | :--- |
| ⟪भू⟫ | ⟪भावयति⟫:br(aus: bhau-aya-ti) | bewirken, dass jemand oder etwas wird, hervorbringen |
| ⟪इ⟫ | ⟪आययति⟫:br(aus: ai-aya-ti) | bewirken, dass jemand geht |
| ⟪नी⟫ | ⟪नाययति⟫:br(aus: nai-aya-ti) | führen lassen |
| ⟪कृ⟫ | ⟪कारयति⟫:br(kār-aya-ti) | machen lassen |
| ⟪वच्⟫ | ⟪वाचयति⟫:br(vāc-aya-ti) | sprechen lassen, sprechen machen, (einen Text sprechen machen =) laut lesen |

::: grammar-box
**Typus educationis 3: radix humillima + -aya-**

**Praecedunt.**
:::
Exemplum:

| Wurzel | Kausativ 3. sg. Indikativ Präsens | Bedeutung |
| :--- | :--- | :--- |
| ⟪दुष्⟫ | ⟪दूषयति⟫:br(dūṣ-aya-ti) | (jemanden) verderben |

::: grammar-box
**Typus educationis 4: Radix + -paya-**

**Radix in -ā et aliis quibusdam radicibus.**
:::
Exempla:

| Wurzel | Kausativ 3. sg. Indikativ Präsens | Bedeutung |
| :--- | :--- | :--- |
| ⟪स्था⟫ | ⟪स्थापयति⟫:br(sthā-paya-ti) | stehen machen, aufstellen |
| ⟪इ⟫ + ⟪अधि⟫:br"studieren" | ⟪अध्यापयति⟫:br(aus: adhi+ā-paya-ti):br(zur Erklärung siehe Thumb-Hauschildt Bd. I,2 S. 341) | studieren lassen, unterrichten |

::: grammar-box
**Formae irregulariter formatae:**

**Grammatici indigeni has formas causativas habent:**

- **han** : Caus. **ghātayati**¹ "facere percuti, facere interfici"
- **pā** 2 "custodire": **pālayati**² "transducere, servare, protegere"
:::
Notae:
1. **ghātayati** est verum verbum, quod a substantivo **ghāta** m. "ictus" derivatum est (denominativum) et pro causativo **han** usurpatur.
2. **pālayati** est verum causativum, sed ad radicem **pṛ** 3 "transducere, servare, protegere": **pārayati** (pār-aya-ti) » **pālayati** (in quibusdam regionibus Indiae r respondet l, in aliis contra l respondet r).

## 28.4. Formatio passivi (⟪यक्⟫) ad causativum

::: grammar-box
**Passivum causativi ita formatur:**

**Stativus causativus sine -aya- + suffigium passivum -ya-**

Exempla:
**bhāvyate** (bhāv-ya-te) "ab eo/ea/id effertur"
**sthāpyate** (sthāp-ya-te) "ab eo/ea/id constituitur"
:::
Cum passivum ad radicem primam fere a radice gradus infimi formetur, passivum causativi saepe ex radice gradis alti vel producti formatur.

## 28.5. Formatio Futuri (⟪ऌट्⟫, ⟪भविष्यन्ती⟫ f.) ad Causativum

::: grammar-box
**Futurum causativi a radice causativa formatum est, ubi terminale -a suffixi causativi cadit:**

**-ay-iṣya-**

Exemplum:
**budh** Futurum Causativum: **bodhayiṣyati** (bodh-ay-i-ṣya-ti): "ille/illa/id excitabit"
:::

## 28.6. Formatio PPP (⟪क्त⟫) ad causativum

::: grammar-box
**Stipulatio causativa in -ay- (sine littera finali a) + -i- + -ta**

Exempla:
**gam** — **gamayati** — **gamita** (gam-i-ta) "missum" (PPP radicis simplicis: **gata**)
**sthā** — **sthāpayati** — **sthāpita** (sthāp-i-ta) "positum"
:::

## 28.7. Formatio absolutivi (⟪क्त्वा⟫ . ⟪ल्यप्⟫) ad causativum

::: grammar-box
**Casus absolutus in -tvā a causativo in -ay- (sine a finali) formatur:**

**Stamens causativus in -ay- + -i- + -tvā**

Example:
**sthāpayitvā** (sthā-pay-i-tvā) "after he has placed"
:::
::: grammar-box
**The absolutive in -ya occurs with causatives with prefix usually at the causative stem WITHOUT -aya-**

Exempla:
**prabudh** — **prabodhayati** — **prabodhya** (pra-bodh-ya) "postquam evigilavit"
**ānī** — **ānayati** — **ānāyya** (ā-nāy-ya) "postquam adducere permisit, postquam ferre permisit"
:::
::: grammar-box
**Radix tamen causativa syllabam -a- brevem ante unicum consonantem continens, -ya absolutivi ad radicem causativam -ay- advenit (sine finali -a-)**

Exemplum:
**āgam** — **āgamayati** — **āgamayya** (ā-gamay-ya) "postquam eum venire permisit"
:::

## 28.8. Formatio infinitivi (⟪तुमुन्⟫) causativo

::: grammar-box
**Infinitivus causativi a radice causativa in -ay- (sine a finali) formatur:**

**Radix causativa in -ay- + -i- + -tum**

Exemplum:
**jan** — **janayati** — **janayitum** (janay-i-tum) "ut generet"
:::

## 28.9. Die 10. Präsensklasse (⟪चुरादि⟫ = ⟪चुर्⟫ u.s.w.)

::: grammar-box
**Eodem modo ac causativa, praesens (aliaque tempora) radices decimae classis praesentis sine causativis formant.**

Exempla:
1.  Radix cum gradu ā + -aya- : **⟪कम्⟫** 10Ā **⟪कामयते⟫** "amare"
2.  Radix cum gradu uṣṭha + -aya- : **cur** 10U **corayati** "furari"; Futurum: **corayiṣyate**; Passivum: **coryate**
:::
::: grammar-box
**Formae causativi ad verba decimae classis praesentis identicae sunt formis simplicis verbi. Iudicium de causativo praesente ex sensu vel interdum ex constructione tantum fieri potest.**
:::
