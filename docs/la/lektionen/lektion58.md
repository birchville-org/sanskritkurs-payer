## 58.6. Aoristus 5: Aoristus iṣ

::: grammar-box
**Aoristus iṣ a radice omni seṭ format, pro qua non expresse alia forma aoristi sola docetur.**

**Formatio:**

**Augmentum + radix + i + s + desinens secundaria athema**

***!!!*** Forma 2.sg.P vel 3.sg.P ex ***-***īs vel -īt oritur ***!!!*** (Ex translatione imperfecti radicum typi अब्रवीत् ortum est; sunt igitur formae aoristi radicalis).
:::

Suffixum formationis radicis + desinentes aoristi iṣ ita sonant:

::: grammar-box

|   | **परस्मैपदम्** || **आत्मनेपदम्** ||
| :--- | :---: | :---: | :---: |
|   | **एकवचनम्** | **बहुवचनम्** | **एकवचनम्** | **बहुवचनम्** |
| **1. तृतीयः** | **-iṣam** | **-iṣma** | **-iṣi** | **-iṣmahi** |
| **2. द्वितीयः** | ***-īs*** | **-i�ṣṭa** | **-iṣṭhās** | ***-***idhvam / [[br]]-iḍhvam[[br]](alternative post -h vel semivocalem) |
| **3. प्रथमः** | ***-īt*** | **-iṣur** | **-iṣṭa** | **-iṣata** |

:::

::: grammar-box
**Forma radicis:**

*   **Radices cum vocali brevi ante consonantem simplicem: Gradus altus in P et Ā**  
    Exemplia:  
    बुध् 1U: 1.sg.P अबोधिषम्  
    कॢप् 1Ā: 1.sg.Ā अकल्पिषि

*   **Radices cum vocali finali:**
    *   **P: Gradus longus**
    *   **Ā: Gradus altus**

    Exemplia:  
    पू 9U: 1.sg.P अपाविषम् ; 1. sg.Ā अपविषि

*   **Radices in -ar., -al atque वद् 1P "dicere", व्रज् 1P "abire": P: Gradus longus**  
    Exemplia:  
    चर् 1P: 1.sg.P अचारिषम्  
    वद् 1P: 1.sg.P अवादिषम्

*   **Aliae radices formae (Cons.-)Cons.-a-Cons.: in P alternative Gradus longus (non valet pro radicibus in -h, -m, -y atque aliis nonnullis radicibus)**  
    Exemplum:  
    तन् 8U: 1.sg.P अतनिषम् / अतानिषम्  
    sed:  
    क्रम् 1U: 1.sg.P अक्रमिषम्
:::
