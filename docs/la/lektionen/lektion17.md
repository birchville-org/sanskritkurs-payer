## 17.1. Secundae classis praesentis (अदादि = अद् etc.)

Radix verbi terminis praesentis affigitur. Mutationes phoneticae ex sandhi verbi resultantia observandae sunt.

:::: grammar-box

Formae sequentes in secunda classe praesentis existunt:

1.  Radices cum alternatione syllabarum radicalium
    *   plerumque: gradus altus - gradus humilis
    *   nonnullae radices: gradus productus - gradus humilis
2.  Radices sine alternatione syllabarum radicalium
3.  Radices bisyllabae in -i/-ī cum alternatione syllabarum radicalium

::::

## 17.2. Radices secundae classis praesentis cum gradatione radicali: Gradus altus - Gradus humilis

Exempla:

द्विष् 2 U "odisse"

*   radix praesentis fortis: dveṣ-
*   radix praesentis infirma: dviṣ-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. sg. praes. P | द्वेष्टि (« dveṣ + -ti) |
| 3\. pl. praes. P | द्विषन्ति (dviṣ-anti) |
| 3\. sg. praes. Ā | द्विष्टे (« dviṣ + -te) |
| 3\. pl. praes. Ā | द्विषते (dviṣ-ate) |

:::

::::

Hoc lexema sandhi sequens operatur:

::: grammar-box
Sandhi lexematis -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-
:::

## 17.3. Radices classis secundae praesentis cum gradatione radicali: gradus longus - gradus brevis

Exemplum:

स्तु 2 U "laudare"

*   radix praesentis fortis: stau-
*   radix praesentis infirma:
    *   ante consonantem: stu-
    *   ante vocalem: stuv-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. sg. praes. P | स्तौति (stau-ti)[[br]]aut: स्तवीति |
| 3\. pl. praes. P | स्तुवन्ति (stuv-anti) |
| 3\. sg. praes. Ā | स्तुते (stu-te) |
| 3\. pl. praes. Ā | स्तुवते (stuv-ate) |

:::

## 17.5. Bisyllabica radices in -i/-ī cum gradatione radicali

Plures radices in serie formarum bisyllabicae sunt, id est, ante terminationem consonanticam habent -i (vel ante aliquas terminationes -ī). Hae radices tamen a grammaticis indigenis et in lexiconibus etc. ut monosyllabicae constituuntur.

Exempla:

रुद् 2 P "plangere, ululare"

*   radix praesentis fortis: rodi-
*   radix praesentis debilis:
    *   ante consonantem: rudi-
    *   ante vocalem: rud-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Praes. P | रोदिति (rodi-ti) |
| 3\. pl. Praes. P | रुदन्ति (rud-anti) |

:::

::::

ब्रू 2 U "loqui"

*   radix praesentis fortis: bravī- (« bro- + -ī)
*   radix praesentis debilis:
    *   vor Konsonant: brū-
    *   ante vocalem: bruv-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Praes. P | ब्रवीति (bravī-ti) |
| 3\. pl. Praes. P | ब्रुवन्ति (bruv-anti) |
| 3\. sg. Praes. Ā | ब्रूते (brū-te) |
| 3\. pl. Praes. Ā | ब्रुवते (bruv-ate) |

:::

::::

Etiam स्तु 2 U "laudare" habet, praeter formas sub 3. indicatas, formas secundum hoc exemplum:

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Praes. P | स्तवीति (« sto + ī + ti)[[br]]aut: स्तौति |

:::

::::

## 17.7. Exercitatio I

A) In sequentibus sententiis verbum inserite et vertite:

१. ब्राह्मणो ऽनृतं न ... (ब्रू । वच् । वद्)

२. क्षत्रियो जनान् ... (पा । रक्ष्)

३. बलवद्योधो द्विजारीन् ... (जि । हन् । युध्)

४. ब्राह्मणकविर्लोकेश्वरम् ... (स्तु । यज्)

५. अग्निर्यज्ञान्नम् ... (अद् । दह्)

६. बालवैश्यो धेनुम् ... (दुह् । रक्ष् । पा)

७. द्विजदासो मृगमार्गेण ब्राह्मणग्रामम् ... (गम् । इ । पद्)

८. द्विजदासः शूद्रस् ... (अस् २ । भू)

९. बालब्राह्मणी ... (रुद् । आस् । मृ)

१०. साधुजनो ऽधर्मम् ... (द्विष् । न कृ)
