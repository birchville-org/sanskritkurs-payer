## 12.1. Participium Perfecti Passivi (PPP)

Modus unus, passive sententias temporis praeteriti formandi, est constructio cum particula, quae dicitur Participium Perfecti Passivi (PPP).

::: grammar-box
**In veritate PPP non est verum participium, quia non a tempore radice formatum est. Est potius nominatio ad radicem cum suffixo primario -ta vel -na. Ideo in grammatica indica de suffixo kta loquimur.**
:::

---

### 12.1.1. Schema pro verba transitiva

::: grammar-box
**Agens (kartṛ) in Instrumentali (tṛtīyā) -- Objectum directum (karman) in Nominativo (prathamā) -- Participium Perfecti Passivi**

PPP in hoc casu cum objecto in numero, casu, et genere concordat.

Verbum auxiliare ('esse') non necessarium est.

Exempla:
> **sādhunā svarga āptaḥ** = साधुना स्वर्ग आप्तः = '(A sancto caelum est adeptum) = Sanctus caelum adeptus est.'
> 
> **brāhmaṇena devīṣṭā** = ब्राह्मणेन देवीष्टा = '(A brahmano dea est honorata) = Brahmano deam honoravit.'
:::

---

### 12.1.2. Schema I pro verba intransitiva et verba motus

::: grammar-box
**Agens (kartṛ) in Casu Nominativo (prathamā) -- Participium Perfecti Passivi**

In hoc casu PPP cum Agente in numero, casu, et genere concordat. Participium Perfecti „Passivum“ apud verba intransitiva (verba sine objecto directo) et verba motus significat activam.

Exemplum:
> **kṣatriyā nagaraṃ gatā** = क्षत्रिया नगरं गता = „Mulier Kṣatriya in urbem abiit.“
:::

---

### 12.1.3. Schema II pro verbis intransitivis et verbis motus

::: grammar-box
**Agens (kartṛ) in Instrumentali (tṛtīyā) -- PPP in Nominativo Singulari Neutro**

Exemplum:
> **kṣatriyeṇa (nagaraṃ) gatam** = क्षत्रियेण (नगरं) गतम् = „(A Kṣatriya est (in urbem) itum) = Kṣatriya est (in urbem) iturus.“

Constructio secundum Schema II multo rarius occurrit quam constructio secundum Schema I.
:::

---

## 12.2. De pondere PPP

Cum igitur particulae perfecti participii passivi, pro verbis transitivis, significatio primaria passiva est (**āpta** = "adventus (est)"), et pro verbis intransitivis et verbis motus activam significatio (**gata** = "ivi"), sunt aliqua verba, quibus PPP tam activam quam passivam significatio habere potest:

sc.
- **gata** = गत = "ivi" (activum); sed etiam: **gato mārgaḥ** = गतो मार्गः = "via pergens" (passivum)
- **āpta** = आप्त = "adventus est" (passivum), "adventum habens" (activum)

---

## 12.3. Formatio PPP

::: grammar-box
Sequentes modi formationis occurrunt (ad quamlibet radicem suum PPP discendum est!):

**(plerumque) radix gradus infimi**

- **+ -ta**
  - cum vocali iunctiva **-i-** ante: **-ita**
  - sine vocali iunctiva: **-ta**
- **+ -na**

Stemmas feminini sunt: **-tā**, **-itā**, **-nā**; neutrum declinatur ut **phala** n.
:::

---

### 12.3.1. PPP in -ta (kta)

#### 12.3.1.1. Sine vocali coniunctiva -i- (aniṭ)

*aniṭ* = „sine (*an-*) suffixo praeposito (*-i-*) *t*“ (id est, sine vocali coniunctiva *i*).

::: grammar-box
Sine vocali coniunctiva participium perfectum passivum (PPP) generaliter radices vocali terminatas, necnon multas alias radices, format, ita ut regula certa pro structura radicum, quae vocalem coniunctivam adhibent vel omitterunt, assignari non possit.

Lista radicum *aniṭ* apud Kielhorn, *Grammatica* § 298 invenitur.
:::

**Exempla:**

::: grammar-box
| Radix | PPP (kta) |
| :--- | :--- |
| **bhū** 1 P[[br]](भू) | **bhū-ta**[[br]](भूत) |
| **smṛ** 1 P[[br]](स्मृ) | **smṛ-ta**[[br]](स्मृत) |
| **nṛt** 4 P[[br]](nṛt-ta)[[br]](नृत्त) | **nṛt-ta**[[br]](नृत्त) |
| **nī** 1 U[[br]](नी) | **nī-ta**[[br]](नीत) |
| **man** 4 Ā[[br]](मन्) | **ma-ta** (\*mn-ta)[[br]](मत) |
| **su** 5 U[[br]](सु) | **su-ta**[[br]](सुत) |
| **gam** 1 P[[br]](गम्) | **ga-ta** (&lt; \*gm-ta)[[br]](गत) |
| **ji** 1 P[[br]](जि) | **ji-ta**[[br]](जित) |
| **śru** 5 P[[br]](श्रु) | **śru-ta**[[br]](श्रुत) |
| **kṛ** 8 U[[br]](कृ) | **kṛ-ta**[[br]](कृत) |
| **tan** 8 U[[br]](तन्) | **ta-ta** (&lt; \*tn-ta)[[br]](तत) |
| **iṣ** 6 P[[br]](इष्) | **iṣ-ṭa**[[br]](इष्ट) |
:::

#### 12.3.1.2. Cum vocali coniunctiva -i- (seṭ)

*seṭ* = *sa-iṭ* = „cum (*sa-*) suffixo praeposito (*-i-*) *t*“ (id est, cum vocali coniunctiva *i*).

**Exempla:**

::: grammar-box
| Radix | PPP (kta) |
| :--- | :--- |
| **kup** 4 P[[br]](कुप्) | **kup-i-ta**[[br]](कुपित) |
| **khād** 1 P[[br]](खाद्) | **khād-i-ta**[[br]](खादित) |
| **rakṣ** 1 P[[br]](रक्ष्) | **rakṣ-i-ta**[[br]](रक्षित) |
| **vad** 1 P[[br]](वद्) | **ud-i-ta** (&lt; \*vd-i-ta)[[br]](उदित) |
:::

## 12.4. Leges coniunctionis phonicae in voce

In formationibus *aniṭ* sequentes leges coniunctionis phonicae in voce observandae sunt. **Haec leges ad intellegendam totam morphologiam Sanscriticam valde importantes sunt.**

:::: grammar-box

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p ante consonantem clusam surdam (e.g. t, th) manent immutatae:** | **pt, tt, kt** = **प्त्, त्त्, क्त्** |
| **2. ct per kt = क्त् mutatur:** | **muc + ta » muk-ta** = **मुक्त** |
| **3. śt per ṣṭ = ष्ट् mutatur:** | **dṛś + ti » dṛṣṭi** = **दृष्टि**[[br]]**dṛś + ta » dṛṣṭa** = **दृष्ट**[[br]]**viś + ta » viṣṭa** = **विष्ट** |
| **4. Consonans clusa sonora non aspirata – excepta j – ante sonum surdum per consonantem surdam non aspiratam ei correspondentem mutatur:** | **d + t(h) » tt(h)** = **त्त्, त्थ्** (importante pro classe 2. Praesentis) |
| **5. jt per kt vel ṣṭ mutatur (non facultative!):** | **yuj + ta » yuk-ta** = **युक्त**[[br]]**yaj + ta » iṣ-ṭa** = **इष्ट** (&lt; \*yj-ta)[[br]]**sṛj + ta » sṛṣ-ṭa** = **सृष्ट**[[br]]**sṛj + ti » sṛṣ-ṭi** = **सृष्टि** |
| **6. Consonans clusa sonora aspirata + consonans clusa surda » consonans clusa sonora non aspirata + consonans clusa sonora aspirata (Lex aspirata Bartholomaei):** | **bh-t » b-dh:**[[br]]**labh + ta » lab-dha** = **लब्ध**[[br]]**dh-t » d-dh:**[[br]]**budh + ta » bud-dha** = **बुद्ध**[[br]]**yudh + ta » yud-dha** = **युद्ध**[[br]]**krudh + ta » krud-dha** = **क्रुद्ध** |
| **7. h-t per ḍth cum productione praecedentis i vel u mutatur; vel per gdh. Ante huiusmodi ḍth, a per o, rarius per ā, mutatur:** | **dah + ta » dag-dha** = **दग्ध**[[br]]**guh + ta » gūḍha** = **गूढ** (guh 1 (gūhati) "aliquid celare")[[br]]**muh + ta » mug-dha / mūḍha** = **मुग्ध / मूढ**[[br]]**sah + ta » soḍha** = **सोढ** |
:::

## 12.5. Lexicon verborum

- **budh** 4 Ā (budhyate) / 1 U (bodhati), PPP **buddha** बुध् बुध्यते बोधति बुद्ध : evigilare, ad cognitionem evigilare, cognoscere; PPP **buddha** 3 evigilatus, inde **Buddha** = "evigilatus" (non: illuminatus)

- **dah** 1 P (dahati), PPP **dagdha** दह् दहति दग्ध : (aliquid) urere
- **sah** 1 Ā (sahate), PPP **soḍha** सह् sahate soḍha : superare, tolerare, patienter tolerare = ignoscere
- **mṛga** m. मृग : fera
- **mārga** m. मार्ग : via (viae saepe erant semitae ferarum)

::: media
![](/images/lekt1202.webp)
Fig.: मार्गः
(Fons imaginis: [Detalia](/la/licenses#lekt1202))
:::

- **api** अपि : etiam (postpositum)

Ad sextam classem praesentis, grammatici indigeni radices quaedam referunt, quae praesentis stemma cum infixu nasali et vocali tematica a formant, e.g.:

- **muc** 6 U (muñcati), PPP **mukta** मुच् मुञ्चति मुक्त : solvere, dimittere, liberare; de circulo renavitae (**saṃsāra** m.) liberare = redimere
- **sic** 6 U (siñcati), PPP **sikta** सिच् सिञ्चति सिक्त : aspergere

Ad verborum formationem:

- **muc**: **mokṣa** m. मोक्ष : solutio, liberatio, redemptio
- **sic** + **abhi-**: **abhiṣeka** m. अभिषेक : aspersio regis in consecratione regia, consecratio regia
- **budh**: **bodhi** m./f. बोधि : evigilatio (qua Buddha vel Jina ad insightum redimentem pervenit)

- **buddhi** f. (**budh** + **-ti**) बुद्धि : cognitio, organum cognitionis.

**B) Formate PPPs correspondentia ad formas verborum ex [Lektion 10](/lektionen/lektion10), Exercitatio A. Notate, quod formae ut sṛjati PPPs in omnibus tribus generibus respondet.**

**C) Sententias ex [Lektion 10](/lektionen/lektion10), Exercitatio C, in tempus praeteritum passivum convertite.**
