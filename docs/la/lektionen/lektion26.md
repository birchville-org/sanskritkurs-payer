# Lectio 26

## 26.1. Lexematisatio -s- in medio verbi

::: grammar-box
**-s-** per **-ṣ-** mutatur, si **k, r, l** vel **vocalis** — praeter **a, ā** — immediate aut per **अनुस्वार** vel **विसर्ग** separata praecedit, et alia consonans quam **ṛ, r** sequitur.

Huic Sandhi etiam **दुस्-** praecedit ante gutturales et labiales mutas in compositionibus.
:::

*Exempla:*
::: indent
**तेषाम्** (ex: *te-sām*)

sed: **तासाम्** (*tā-sām*)
:::

## 26.2. Lexematisatio cerebralisis dentium in medio verbi

::: grammar-box
Consonantes dentales post retroflexos (incluso **-ṣ-**) per retroflexos correspondentes substituuntur:

- **iṣ** + **-ta** = **iṣṭa** (इष्ट)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (तिष्ठति)
  *(**ṣ** propter **i** praecedens, **ṭh** propter **ṣ** subsequens)*
:::

## 26.3. Sandhi verborum pro palatalibus, gutturalibus, ṣ, h + -s

::: grammar-box
**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

Exempla infra vides
:::

## 26.4. Lexem Grassmannianum de dissimilatione aspiratarum

:::: grammar-box
**Consequens immediatum duarum aspiratarum (aspirata - vocalis - aspirata) est amissio aspirationis primi soni:**

Exemplum:

::: indent
\*dhu(gh) » du(g)h
:::

**Si secundus sonus, lege phonetica, amittit aspirationem, tunc aspiratio iterum apparet in primo sono.**

Exempla: vide infra Futurum verborum दुह् et बुध्
::::

## 26.6. Usus futuri simplicis (ऌत्, भविष्यन्ती f.)

::: grammar-box
**Futur simplex (ऌत्, भविष्यन्ती f.) exprimit:**

- **futurum**
- **actionem intentam seu volitam ("ibo", "volo ire")**
- **expectationem ("ita eveniet")**
- **spem**
- **timorem**
- **probabilitatem**
- **sententiam oratoris**
- **imperium**

**Futurum partim cum optativo contendit (vide infra).**
:::

e. g. व्रतं करिष्यन्देवगृहं गच्छति = "Qui votum facere vult, ad templum it."

## 26.7. Formatio futuri simplicis (ऌत्, भविष्यन्ती  f.)

:::: grammar-box
**Futur simplex:**

::: indent
**Stamens futuri + desinentes primariae**
:::
::::

:::: grammar-box
**Stamens futuri:**

::: indent
**(plerumque) radix gradus supremi + -sya**  
**aut**  
**(plerumque) radix gradus supremi + -i- + -sya (= - iṣya)**
:::

**Quam radices futuri staminis formationem habeant, cum formis staminalibus discendum est!**  
**In genere, forma radicum et vocalis iunctiva futuri cum infinitivo congruunt.**  
**Quaedam radices futurum optionem cum et sine vocali iunctiva -i- formare possunt.**  
**Participium Parasmaipada futuri per suffixum -nt- ad staminem futuri adiunctum formatur, femininum facultative in -ntī vel -tī:**

::: indent
कृ :  करिष्यन्त्, करिष्यन्ती / करिष्यती
:::
::::

Exempla:

:::: grammar-box

| Radix | Futurum 3. sg. P (Ā) |
| :--- | :--- |
| नी | नेष्यति |
| भू | भविष्यति (भो +  इ + स्य + ति) |
| दिश् | देक्ष्यति (देश् + स्य + ति) |
| दृश् | द्रक्ष्यति |
| पच् | पक्ष्यति |
| प्रच्छ् | प्रक्ष्यति |
| यज् | यक्ष्यति |
| सृज् | स्रक्ष्यति |
| पद् | पत्स्यति |
| अद् | अत्स्यति |
| दुह् | धोक्ष्यति (दोग् +  स्य + ति) |
| बुध् | भोत्स्यते (बोध् ante sordida = भोत्) |
| मन् | मंस्यते (मन् + स्य + ते) |

::::
