# Lectio 21

## 21.1. Ulteriores tempestates praesentes in -nt

### 21.1.1. Participium Praesens (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
Hoc participium est forma nominalis e radicis praesentis, scilicet participium verum. Est adiectivum quod indicat aliquem vel aliquid quod per radicem verbi (cum praefixione) expressum agere, dum aliud fit. Etiam status durabilis hoc modo exprimi potest.

**Exempla:**

:::
::: indent
"Legente patre, ille fumat = pater legens fumet"
"amans (scil. verus, verus) amicus"
:::
::: grammar-box

| **Participii praesentis activi formationem ad tematica praesentis temata:** |||
| :--- | :--- | :--- |
| **Masculinum, Neutrum** | | |
| | **strenuum radix** | praesentis radix + **-nt-** |
| | **remissus radix** | praesentis radix + **-t-** |
| **Femininum** | | |
| | | Präsensstamm + **-nt-** + **-ī** (Deklination wie **devī** :br⟪देवी⟫) |
| | **6. praesentis classis** | praesentis radix + **-nt-** + **-ī** :broder::brpraesentis radix + **-t-** + **-ī** |

:::

## 21.3. Formae honorificae salutationis

::: grammar-box
**In Sanscrito, sine officiositate, potest quisquam in persona secunda singulari alloqui. Si vero officiosus esse vis, nomen adhibere potes, cuius significatio est "Venerabilis" et similia, et verbum in tertiam personam singularem vel pluralis ponere, vel constructionem passivam adhibere. Incrementum officiositatis in usu personae in alloquio tale est:**

:::
::: indent
**2. sg. » 2. pl. » 3. sg. cum nomine correspondente » 3. pl. cum nomine correspondente**
:::
**Hoc nomen maiestaticum maxime necessarium est ⟪भवन्त्⟫ , fem.: ⟪भवती⟫ . Usu suo nostro "Vos" honifico respondet.**
Hoc ⟪भवन्त्⟫ est contractio ex ⟪भगवन्त्⟫; declinatio eius est nominum in **-vant** (vide [Lectio 13](lektion13.md)). Hoc ⟪भवन्त्⟫ a participio praesentis P ex ⟪भू⟫ "fieri" ⟪भवन्त्⟫ distinguendum est: nom. sg. masc. ex ⟪भवन्त्⟫ "Vos" est ⟪भवान्⟫, participii autem ⟪भवन्⟫.

**Exempla:**

::: indent
**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = "Quid agis?"
:::
polite:

::: indent
**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**
:::
Femininum:

::: indent
**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**
:::
Alia verba, quae similiter uti possunt:

*   ⟪आर्य⟫ (f.: ⟪आर्या⟫) "Nobilis". E.g. **⟪यदार्य⟫ ⟪इच्छति⟫** "Quod vis"
*   ⟪महाभाग⟫ "cuius pars / fortuna magna est = Nobilis". Saepissime a mulieribus in adulatione vel de viris bonae sortis loquentibus adhibetur. In Sanscrito colloquiali moderno valde frequens.

Si non solum comitatem, sed etiam colentiam erga aliquem exprimere vis, pro eo qui praesens vel prope est, uteris ⟪भवन्त्⟫ ⟪अत्रभवन्त्⟫ loco; pro absente autem vel remoto, ⟪तत्रभवन्त्⟫. ⟪अत्रभवन्त्⟫ et ⟪तत्रभवन्त्⟫ verti possunt ut "Vos", "Venerabiles", "Reverendi" etc.:

::: indent
**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = "Estne pia (hic praesens) uxor tua?"
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (in epistula vel colloquio telephonico) = "Valetisne?"
:::
