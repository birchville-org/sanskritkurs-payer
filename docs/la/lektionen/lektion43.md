# Lectio 43

## 43.1. Desinenses personae secundae (मध्यमः = "media &lt;Persona&gt;")

::: grammar-box
| | परस्मैपदम् || आत्मनेपदम् ||
| --- | --- | --- | --- | --- |
| | **एकवचनम्** | **बहुवचनम्** | **एकवचनम्** | **बहुवचनम्** |
| **Desinenses primariae** | -si | -tha | -se | -dhve |
| **Desinenses secundariae** | -s | -ta | -thās | -dhvam |
| **Desinenses perfecti** | -tha | -a | -se | -dhve |
:::

Nota est desinens secundaria pluralis secundae personae idem esse ac desinens secundaria singularis tertiae personae activi.

## 43.2. Formatio formarum verbalium secundae personae (मध्यमः)

Secunda persona:

*   Singularis: "tu"
*   Pluralis: "vos" (plures quam duo!)

## 43.3. De pronominibus personalibus secunda persona

*   Singularis: त्वद् "tu"
*   Pluralis: युष्मद् "vos"

::: grammar-box
| | एकवचनम् (त्वद्) | बहुवचनम् (युष्मद्) |
| --- | --- | --- |
| **प्रथमा** | त्वम् | यूयम् |
| **द्वितीया** | त्वाम् त्वा | युष्मान् वस् |
| **तृतीया** | त्वया | युष्माभिस् |
| **चतुर्थी** | तुभ्यम् ते | युष्मभ्यम् वस् |
| **पञ्चमी** | त्वत् | युष्मत् |
| **षष्ठी** | तव ते | युष्माकम् वस् |
| **सप्तमी** | त्वयि | युष्मासु |
:::

Formae त्वा, ते, वस् non ad primam positionem orationis vel dimetrum adhiberi debent. Neque ante च, वा, एव atque alias particulas nonnullas uti licet:

::: indent
त्वां मां च "te et me"
:::
