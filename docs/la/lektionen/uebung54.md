# Exercitatio 54

Formas Aoristi correspondentes ad formas sequentes Praesentis vel Perfectorum formate:

::: grammar-box
| Nr. | Forma | Determinatio / Significatio | Aoristus |
|:---|:---|:---|:---|
| १. | **यन्ति** | eunt | **अगुः** |
| २. | **पिबामि** | bibo | **अपाम्** |
| ३. | **ददौ** | dedi / dedit | **अदाम् / अदात्** |
| ४. | **बभूव** | fui / fuisti | **अभूवम् / अभूत् / अभूत** |
| ५. | **दधति** | ponunt | **अधुः** |
| ६. | **ऐम** | ivimus | **अगाम** |
| ७. | **पपिथ** | bibisti / custodisti | **अपाः** (ad *पा* "bibere") |
| ८. | **तिष्ठति** | stat | **अस्थात्** |
| ९. | **इयेथ** | ivisti | **अगाः** |
| १०. | **पप** | bibistis | **अपात** |
| ११. | **एष्यथ** | ibitis | **अगात** |
| १२. | **तस्थुः** | steterunt | **अस्थुः** |
| १३. | **अधत्त** | posuistis | **अधात** |
| १४. | **अददाः** | dedisti | **अदाः** |
| १५. | **अभवन्** | fuerunt | **अभूवन्** |
| १६. | **ददिम** | dedimus | **अदाम** |
| १७. | **भिद्यते** | scinditur | **अभेदि** |
| १८. | **उद्यते** | dicitur | **अवादि** |
| १९. | **स्तूयते** | laudatur | **अस्तावि** |
| २०. | **कृष्यते** | aratur | **अकर्षि** |
| २१. | **जायते** | nascitur | **अजनि** |
| २२. | **गीयते** | cantatur | **अगायि** |
| २३. | **गम्यते** | itum est | **अगामि** |
:::
