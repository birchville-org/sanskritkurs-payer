# Lectio 45

## 45.1. Formation of the verbal forms of the second person (⟪मध्यमः⟫) athematic stems without vocally ending suffix (continuation)

### 45.1.2. Seventh present class (⟪रुधादि⟫)

::: grammar-box
**If a final k/g of the root comes to stand between the nasal ṅ and a dental of the ending, then k/g may optionally fall away**

e.g. ⟪युज्⟫ 3.sg.Ind.Pres.Ā ⟪युङ्क्ते⟫ or ⟪यु⟫:sig[⟪ङ्ते⟫]
:::
⟪युज्⟫ 7U

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Indicative Present** :br⟪लट्⟫ | ⟪युनक्षि⟫:bryu-na-j + si | ⟪युङ्क्थ⟫:br⟪युङ्थ⟫ | ⟪युङ्क्षे⟫ | ⟪युङ्ग्ध्वे⟫:br⟪युङ्ध्वे⟫ |
| **Imperfect** :br⟪लङ्⟫ | ⟪अयुनक्⟫:braus: a-yu-na-j + s | ⟪युङ्क्त⟫:br⟪अयुङ्त⟫ | ⟪अयुङ्क्थास्⟫:br⟪अयुङ्थास्⟫ | ⟪अयुङ्ग्ध्वम्⟫:br⟪अयुङ्ध्वम्⟫ |

## 45.2. Vocativus Singularis (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**Plerique vocativi singularis sunt radix cum gradu pleno finali.**

e.g. **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** etc.

**Exceptiones sunt feminina in -ā et -ī necnon radices in -in, quorum vocativus singularis praecipue memorandus est.**
:::
::: no-header
| | Vocativus Singularis |
| --- | --- |
| Masculina in -a | ⟪देव⟫ |
| Neutra in -a | ⟪फल⟫ |
| Feminina in -ā | ⟪देवते⟫ |
| Masculina in -i | ⟪कवे⟫ |
| Feminina in -i | ⟪मते⟫ |
| Masculina in -u | ⟪शत्रो⟫ |
| Feminina in -u | ⟪धेनो⟫ |
| Feminina in -ī | ⟪देवि⟫ |
| Masculina in -ṛ | ⟪पितर्⟫ |
| Feminina in -ṛ | ⟪मातर्⟫ |
| Masculina in -an | ⟪राजन्⟫ |
| Neutra in -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Masculina in -man/-van | ⟪आत्मन्⟫ |
| Masculina in -in | ⟪बलिन्⟫ |
| Masculina in -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt m. | ⟪महन्⟫ |
| mahānt n. | ⟪महत्⟫:br= Nominativus |
| Masculina in -mant/-vant | ⟪गुणवन्⟫ |
| Neutra in -mant/-vant | ⟪गुणवत्⟫:br= Nominativus |
| Pronominalia | vocativus non formatur |
:::

## 45.4. Exercitatio

A) In Sanscritum vertite (pro formis praeteriti temporis Imperfectum ⟪लङ्⟫ adhibete):

1\. Sanghān (Buddhisticōrum) scindis.

:::
2\. Terram frūctūs vestrōs percepistisne?

3\. Mūnē dōnum accēpistine?

4\. O vir sancte, cur periculīs nōn timēs?

5\. Pater, quo familiam relinquis?

6\. O mulier Śūdrā, onus in domum divitis Brahmanae portāvistine?

7\. O dea, votum felicitātis Vaiśyae, qui merita gessit, perficere debēs.

8\. O elephanti, vincula frangere nōn debētis.

9\. O vir leōnis similis, cur totam mentem in Absolutum (Brahman) nōn dirigis?

10\. O poēta, mundōs mīsusne es?

B) Vertite:
