# Lectio 25

## 25.1. Formationis Ablativi (⟪पञ्चमी⟫ = "quinta casus desinentia")

::: grammar-box
Praeter masculina et neutra in -a ac Pronominalia, in singulari omnibus declinationum generibus formae Ablativi (⟪पञ्चमी⟫) cum Genitivi (⟪षष्ठी⟫) identicae sunt.

Praeter personalia Pronominalia, in plurali omnibus declinationibus formae Ablativi cum Dativis (⟪चतुर्थी⟫) identicae sunt.
:::
Nunc causam ordinis casuum (⟪विभक्ति⟫) in Sanscrito agnoscitis: ita disponuntur ut formae eodem nomine sonantes quam proxime inter se - vel subalternatim - stent.

::: grammar-box
**Ablativi Singularis masculinae/neutrum in -a**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Interrogativa, relativa et demonstrativa Pronominalia:

::: grammar-box

| | Ablativi Singularis:brMasculinum / Neutrum | Ablativi Singularis:brFemininum |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Usus Ablativi (⟪पञ्चमी⟫)

"Ablativum id significat quod manet fixum, cum aliquid inde abeat."

Pāṇini 2,3,28 + 1,4,24

Ablativus praecipue ad quaestiones "Unde?", "Cur?" ponitur.

::: grammar-box
1\. Ablativus ergo initium, originem et materiem designat.

Ablativus igitur personam quoque designare potest, a qua aliquid emitur, auditur, optatur etc.
:::
Exempli gratia:

::: indent
⟪ग्रमादागच्छति⟫ = "Ex vico venit"

⟪अश्वात्पतितः⟫ = "Equo excidit"

⟪तेभ्यो लब्धम्⟫ = "Ab eis accipitur"
:::
Exempli gratia:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "A doctore de Dharma audit"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "Brahmanus a Kṣatriya vaccam lactiferam optat"
:::
::: grammar-box
2\. Ablativus cum verbis adhibetur, quae significat "abstinere ab", "tueri contra", "defendere adversus", "timere":
:::
Exemplum:

::: indent
⟪अरिभ्यो रक्षति⟫ = "Ab hostibus tuetur"
:::
::: grammar-box
3\. Ablativus causam vel rationem designat:
:::
Exempli gratia:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "Filiam iracundia occidit"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "Quia malum fecit, in infernum venit" (« Quia est is, per quem malum factum est)

⟪पापकरणान्नरकं गच्छति⟫ = "Quia malum facit / fecit, in infernum venit"
:::
Nomina, quae non sunt feminina, ut causam actionis designent, in Instrumentali (⟪तृतीया⟫) vel Ablativo stare possunt. Feminina in hoc sensu regulariter in Instrumentali stant, sed interdum quoque in Ablativo stare possunt.

## 25.3. Suffixum -⟪तस्⟫

::: grammar-box
Si in singulari (explicite) exprimere vis, vocabulum sensu ablativo adhiberi, suffixum -⟪तस्⟫ radicibus vocabulorum adiungere potest, quod adverbium plerumque sensu ablativo format (ad quaestionem "Unde?"):
:::
Exemplaria:

::: indent
⟪आदितस्⟫ = "ab initio"

⟪धर्मतस्⟫ = "propter dharman, ex causa dharmæ"
:::
::: grammar-box
Suffixum -⟪तस्⟫ etiam ad stems pronominales apponitur:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "inde, ibi, eo, super hoc, deinde, propterea"

⟪यद्⟫ : ⟪यतस्⟫ "a quo, unde, ubi, quo, cur" (relativum)

⟪किम्⟫ :  ⟪कुतस्⟫ "unde?" "cur?"
:::
## 25.4. Aliæ modī, rationes exprimendi

::: grammar-box
**1\. Proposita relativa**

Propositiones relativæ saepe causalem (rationalem), consecutivam (consequentem) vel finalem (finalisticam) relationem ad propositionem principalem exprimunt.

Formæ pronominis relativī, quæ ut conjunctiones causales servantur:

*   ablativum:
*   ⟪यतस्⟫ ... subiectum ... ⟪ततस्⟫ ... praedicatum ... = "quod ..., ideo ..."
*   ⟪यस्मात्⟫ ... subiectum ... ⟪तस्मात्⟫ ... praedicatum ... = "quod ..., ideo ..."
*   instrumentale:
*   ⟪येन⟫ ... subiectum ... ⟪तेन⟫ ... praedicatum ... = "quod/propter ..., ideo / propterea ..."
:::
Exemplum:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "Quia Rāma divitias optat, votum observat"
:::
::: grammar-box
**2\. ⟪हि⟫**

Propositiones principales per particulam ⟪हि⟫ "enim, quia" coniungi possunt. Propositio cum ⟪हि⟫ (quæ non in prima positione stare debet, sed in prosa in secunda positione stare necesse est) rationem indicat vel pro praecedente propositione vel pro subsequente propositione:
:::
Exemplum:

::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "People do meritorious deeds. For they wish to enter heaven."
:::
::: grammar-box
**3\. Instrumental (⟪तृतीया⟫)**

Besides the Ablative (⟪पञ्चमी⟫), the Instrumental (⟪तृतीया⟫) is used to indicate reason or cause. With feminine nouns, the Instrumental is generally obligatory.
:::
Example:

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = "He strikes down his son out of anger" = "He strikes down his son in anger"
:::
::: grammar-box
**4\. Nouns**

Furthermore, reasons can of course also be expressed through constructions with

*   ⟪कारण⟫ n. "cause": ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ m.
*   other nouns meaning "cause"

\+ Genitive (⟪षष्ठी⟫) or as the second member of compounds:
:::
Example:

::: indent
⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ etc.) = "because of the merit"
:::
::: grammar-box
**5\. ⟪इति⟫**

The motive for an action can be indicated as a thought with ⟪इति⟫:
:::
Example:

::: indent
⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫  = "Because the Sugata has fully awakened to truth, Ānanda asks Gautama about his teaching" (« "Thinking 'The Sugata has fully awakened to truth' ..." )
:::
