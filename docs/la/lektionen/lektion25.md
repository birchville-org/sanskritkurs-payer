# Lectio 25

## 25.1. Formatio casus ablativi (⟪पञ्चमी⟫ = "quinta desinentia casus")

::: grammar-box
Praeter masculina/neutra in -a atque pronomina, in singulari omnium declinationum classium formae ablativi (⟪पञ्चमी⟫) sunt idem quae genitivi (⟪षष्ठी⟫).

Praeter personalia pronomina, in omnibus declinationibus pluralis, formae ablativi cum dativis (⟪चतुर्थी⟫) identicae sunt.
:::
Nunc causam ordinis casuum (⟪विभक्ति⟫) in Sanscrito agnoscis: ita dispositi sunt, ut formae eodem nomine dictae, quantum fieri possit, iuxta se positae sint, sive inter se.

::: grammar-box
**Ablativus Singularis Masculinorum / Neutrorum in -a**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Pronomina interrogativa, relativa et demonstrativa:

::: grammar-box

| | Ablativus Singularis:brMasculinum / Neutrum | Ablativus Singularis:brFemininum |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Usus Ablativi (⟪पञ्चमी⟫)

"Ablativus est casus qui indicat id, quod manet, cum aliquid ab eo recedit."

Pāṇini 2,3,28 + 1,4,24

Ablativus praesertim ad quaestiones "Unde?", "Cur?" respondet.

::: grammar-box
1\. Ablativus ergo originem, originis materiamque designat.

Ablativus igitur etiam personam indicare potest, a qua aliquid emitur, auditur, optatur etc.
:::
Exempla:

::: indent
⟪ग्रमादागच्छति⟫ = "Ex vicō venit"

⟪अश्वात्पतितः⟫ = "equo delapsus"

⟪तेभ्यो⟫ ⟪लब्धम्⟫ = "ab eis accipiuntur"
:::
Exempla:

::: indent
⟪गुरोर्धर्मं⟫ ⟪शृणोति⟫ = "audit a magistro de dharma"

⟪ब्राह्मणः⟫ ⟪क्षत्रियाद्धेनुमिच्छति⟫ = "brāhmaṇus a kṣatriyā vacam vacat"
:::
::: grammar-box
2\. Ablativus cum verbis, quae significant "abstinere ab", "tueri contra", "defendere adversus", "timere":
:::
Exemplum:

::: indent
⟪अरिभ्यो⟫ ⟪रक्षति⟫ = "pro inimicis defendit"
:::
::: grammar-box
3\. Ablativus causam vel rationem indicat:
:::
Exempla:

::: indent
⟪क्रोधात्पुत्रं⟫ ⟪हन्ति⟫ = "Occidit filium suum ex ira"

⟪कृतपापत्वान्नरकं⟫ ⟪गच्छति⟫ = "Quia malum fecit, ad inferna descendit" (quia scilicet est per quem malum factum est)

⟪पापकरणान्नरकं⟫ ⟪गच्छति⟫ = "Quia malum facit/fecit, ad inferna venit"
:::
Nomina, quae non sunt feminina, ut causam actionis designent, in Instrumentali (⟪तृतीया⟫) vel Ablativo (⟪पञ्चमी⟫) stare possunt. Feminina in hoc sensu solent in Instrumentali stare, sed interdum etiam in Ablativo stare possunt.

## 25.3. Suffixum -⟪तस्⟫

::: grammar-box
Si vis singulariter (perspicue) exprimere quod verbum ablativi sensu adhibetur, suffixum -⟪तस्⟫ radicibus verbis adiungere potest, quod adverbium plerumque ablativi sensus format (ad quaestionem "Unde?"):
:::
Exempla:

::: indent
⟪आदितस्⟫ = "ab initio"

⟪धर्मतस्⟫ = "propter dharma, propter dharma"
:::
::: grammar-box
Suffixum -⟪तस्⟫ etiam ad pronominales radices adhaeret:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "illinc, illic, illuc, super eo, deinde, propter id"

⟪यद्⟫ : ⟪यतस्⟫ "a quo, a qua, a quod, unde, ubi, quo, cur, quia" (relativus)

⟪किम्⟫ :  ⟪कुतस्⟫ "unde?" "cur?"
:::
## 25.4. Aliae facultates, rationes exprimendi

::: grammar-box
**1\. De relative**

Relativa saepe relationem causalem (fundamentalem), consecutivam (consequentem) vel finalem (intentam) cum propositione principali exprimunt.

Formae pronomis relativī, quae ut coniunctio causālis fungitur:

*   ablativo:
    *   ⟪यतस्⟩ ... subiectum ... ⟪ततस्⟩ ... praecipuum ... = "quod ..., ideo ..."
    *   ⟪यस्मात्⟩ ... subiectum ... ⟪तस्मात्⟩ ... praecipuum ... = "quod ..., ideo ..."
*   instrumento:
    *   ⟪येन⟩ ... subiectum ... ⟪तेन⟩ ... praecipuum ... = "quo/quod ..., eo ..."
:::
Exemplum:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो⟫ ⟪व्रतं⟫ ⟪चरति⟫ = "Quia Rāma divitias optat, votum illud exercet"
:::
::: grammar-box
**2\. ⟪हि⟫**

Propositiones principales per particulam ⟪हि⟩ "enim, quia" coniungi possunt. Propositio cum ⟪हि⟩ (quae non in prima sede stare debet, sed in prosa in secunda sede stare debet) rationem dat vel pro propositione praecedente vel pro propositione subsequente:
:::
Exemplum:

::: indent
⟪जनाः⟫ ⟪पुण्यं⟫ ⟪कुर्वन्ति⟫ ⟪।⟫ ⟪स्वर्गं⟫ ⟪हि⟫ ⟪गन्तुमिच्छन्ति⟫ = "Homines meritoria agunt. Ad caelum enim ascendere volunt."
:::
::: grammar-box
**3\. Instrumentalis (⟪तृतीया⟫)**

Praeter ablativum (⟪पञ्चमी⟫) instrumentalis (⟪तृतीया⟫) ad indicandam causam vel rationem adhibetur. Nomina feminina instrumentali uti plerumque necesse est.
:::
Exemplum:

::: indent
⟪क्रोधेन⟫ ⟪पुत्रं⟫ ⟪हन्ति⟫ = "Occidit filium suum ex ira" = "Occidit filium suum in ira"
:::
::: grammar-box
**4\. Nomina**

Praeterea quidem rationes etiam per constructiones cum

*   ⟪कारण⟫ n. "causa": ⟪कारणात्⟩ ⟪।⟩ ⟪कारणेन⟩
*   ⟪हेतु⟩ m.
*   Genetivus (⟪षष्ठी⟫) vel ut pars posterior compositionum:

\+ genitivus (⟪षष्ठी⟫) aut ut pars posterior compositionum:
:::
Exemplum:

::: indent
⟪पुण्यस्य⟫ ⟪कारणात्⟫ (⟪हेतोः⟫ et cetera) = "propter meritum"
:::
::: grammar-box
**5\. ⟪इति⟫**

Motivum actionis ut cogitatio cum ⟪इति⟫ indicari potest:
:::
Exemplum:

::: indent
⟪सम्यक्संबुद्धः⟫ ⟪सुगत⟫ ⟪इत्यानन्दो⟫ ⟪गौतमं⟫ ⟪धर्मं⟫ ⟪पृच्छति⟫ = "Quia Sugatus ad veritatem perfecte evigilavit, Ānanda de doctrina Gautamae interrogat" (« "Cogitans 'Sugatus ad veritatem perfecte evigilavit' ...)
:::
