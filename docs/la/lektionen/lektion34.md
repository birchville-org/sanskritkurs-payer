# Lectio 34

## 34.1. De Perfecto (लिट्)

In Sanscrito classico, e radicis perfecti, indicativus et participium tantum supersunt.

::: grammar-box
**Duplicia sunt genera perfecti formandi:**
*   **perfectum reduplicatum = द्वित्वलिट्**
*   **perfectum periphrasticum = अनुप्रयोगलिट्**
:::
::: grammar-box
**Perfectum periphrasticum (अनुप्रयोगलिट्) adhibetur:**
1. **in coniugationibus derivatis (causativo, desiderativo, frequentativo, denominativis)**
2. **in radicibus, quae vocali longa (praeter ā-) incipiunt, vel vocali (praeter a-) ante duas consonantes**
3. **in quibusdam aliis radicibus**
:::

## 34.2. Perfectum cum duplicatione (द्वित्वलिट्)

### 34.2.1. Gradatio radicalis

::: grammar-box
**Conformatio:**

**gradatio fortis:** Singular Parasmaipada
*   **radix reduplicata, gradu alto seu longo, vel gradu producta, cum termino perfecti**

**gradatio debilis:** omnes reliquae formae
*   **radix reduplicata, gradu humili, cum termino perfecti**
:::
::: grammar-box
**Generaliter (etiam extra perfectum) gradationem radicales non habent radices formae:**
*   **(consonans)-consonans-vocalis longa-consonans**
*   **(consonans)-consonans-vocalis-consonans-consonans**

**In perfecto etiam gradationem non habent radices formae:**
*   **a-consonans**
*   **ā-consonans**
:::

### 34.2.2. Des perfectionis terminations

:::: grammar-box

| | 3. Singularis | 3. Pluralis |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |

::::

### 34.2.3. Vocalis iunctiva -i-

::: grammar-box
**Post terminum 3.pl.Ā (-re) semper vocalis iunctiva -i- apponitur, ante alias terminaciones consonantibus incipientes apud radices plerumque.**
:::

### 34.2.4. Reduplicatio radicum consonantibus incipientium

::: grammar-box
**Regulae in [Lectio 33](lektion33.md) datae valent pro reduplicatione consonantium incipientium.**

**Vocalis reduplicativa radicum consonantibus incipientium est vocalis radicalis brevis.**

**Diphthongi ante consonantem per vocalem brevem gradus infimi correspondentem reducuntur.**

**ṛ, ṝ, ḷ, et diphthongi finales per -a- reduplicantur.**
:::

Exempla:

:::: grammar-box

| Radix | 3. sg. Perf. P. |
| :--- | :--- |
| भिद् | ***बि***भेद |
| मुच् | ***मु***मोच |
| भृ | ***ब***भार |

::::

::: grammar-box
**Quaedam radices y- vel v- incipientes per i- vel u- reduplicant, quod in formis infirmis cum vocali radicali "confrangitur".**
:::

Exempla:

:::: grammar-box

| Radix | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| वच् | उवाच[[br]]u-vāc-a | ऊचुर्[[br]]u + uc-ur |
| यज् | इयाज[[br]]i-yāj-a | ईजुर्[[br]]i + ij-ur |

::::

### 34.2.5. Reduplicatio radicum vocaliter incipientium

::: grammar-box
**1. incipiens a-, ā- reduplicatur per a-, ut ā- appareat.**
:::

Exempla:

:::: grammar-box

| Radix | 3. sg. Perf. P. |
| :--- | :--- |
| अस् 2 "esse" et अस् 4 "iacere" | आस[[br]]a + as-a |

::::

::: grammar-box
**2. Radices incipiente i- habent syllabam reduplicationis in forti stamine iy-, in debili stamine i-, quae cum vocali radicali in ī- "confunditur. Analogum valet pro incipiente u-.**
:::

Exempla:

:::: grammar-box

| Radix | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| इ | इयाय[[br]]iy + ai + a | ईयुर्[[br]]i + iy-ur |
| इष् | इयेष[[br]]iy-eṣ-a | ईषुर्[[br]]i + iṣ-ur |

::::

::: grammar-box
**3. Radices quae a- ante duas consonantes vel ṛ- incipiunt, habent syllabam reduplicationis ān-**
:::

Exempla:

:::: grammar-box

| Radix | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| अञ्ज् | आनञ्ज | आनञ्जुर् |
| एध् | आनर्ध | आनृधुर् |

::::

## 34.3. Typi perfecti reduplicati

Principium classificationis: Peculiaritates gradationis radicis:
*   Perfectum sine gradatione radicis: Typus I
*   Perfectum cum gradatione radicis: Typus II - V
*   formationes perfectae irregulares

## 34.4. Perfectum Typus I: Perfectum sine gradu radicali

::: grammar-box
**Perfectum Typus I (sine gradu radicali) habent radices generum:**
*   **(Consonant)-Consonant-Vocalis longa-Consonant**
*   **(Consonant)-Consonant-Vocalis-Consonant-Consonant**
*   **a-Consonant**
*   **ā-Consonant**
:::

Exempla:

:::: grammar-box

| Radix | 3. sg. Perf. | 3. pl. Perf. |
| :--- | :--- | :--- |
| बन्ध् 9P | बबन्ध[[br]]ba-bandh-a | बबन्धुर् |
| जीव् 1P | जिजीव | जिजीवुर् |
| आप् 5P | आप[[br]]a + āp-a | आपुर् |
| अस् 2P "esse"[[br]]अस् 4 "iacere" | आस[[br]]a + as-a | आसुर् |
| अश् | आनशे[[br]]reduplicatio irregularis! | आनशिरे |

::::

## 34.5. Perfectum Typus II: Radix fortis gradu alto, radix infirma gradu basso

::: grammar-box
**A radicibus formae:**
*   **(Consonans)-(Consonans)-i/u/ṛ/ḷ-Consonans**

**Formatio:**
*   **radix fortis: gradu alto**
*   **radix infirma: gradu basso**
:::

Exempla:

:::: grammar-box

| Radix | 3. sg. Perf. Act. | 3. pl. Perf. Act. | 3. sg. Perf. Med. | 3. pl. Perf. Med. |
| :--- | :--- | :--- | :--- | :--- |
| भिद् | बिभेद | बिभिदुर् | बिभिदे | बिभिदिरे |
| इष् | इयेष | ईषुर् | | |
| मुच् | मुमोच | मुमुचुर् | मुमुचे | मुमुचिरे |
| वृत् | | | ववृते | ववृतिरे |
| कॢप् | | | चकॢपे | चकॢपिरे |

::::

## 34.8. Exercitium translationis

Textum hunc ex पद्मपुराण de donis Brahmanis factis translate:

क्षितिं सशस्यां यो दद्याद्ब्राह्मणाय द्विजो***त्तम*** ।  
विष्णुलोके सुखं भुङ्क्ते यावदिन्द्रा***श्चतुर्दश*** ॥१॥  
***सप्त***द्वीपां महीं दत्त्वा यत्पुण्यं प्राप्यते द्विज ।  
तत्पुण्यं प्राप्नुयान्मर्त्यो धेनुं यच्छन्द्विजातये ॥२॥  
तिलप्रमाणं स्वर्णं यो ब्राह्मणाय प्रयच्छति ।  
हरिनिकेतनं याति युक्तं कोटिकुलैरपि ॥३॥  
सालङ्कारां द्विजश्रेष्ठ कन्यां यच्छति यो नरः ।  
स गच्छेद्ब्रह्मसदनं पुन***र्जन्म*** न विद्यते ॥४॥  
अन्नं वारि द्विजश्रेष्ठ येन दत्तं महीतले ।  
तेन दत्तानि दानानि सर्वाणि च द्विजर्षभ ॥५॥

Explanationes:

::: indent
**Vocativus singularis** masculinorum/neutrorum in -a terminat in -a: exempli gratia **देव** "O Deus!"

**चतुर्दश** quattuordecim

**सप्त** septem

**जन्म** Nominativus/Accusativus singularis ad **जन्मन्** n. ortum

**सर्व** 3 "omnes, totus" (declinatur secundum declinationem pronominalium)
:::
