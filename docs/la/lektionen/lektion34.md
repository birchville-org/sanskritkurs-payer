# Lektion 34

## 34.1. Das Perfekt (⟪लिट्⟫)

In Sanskrito classico tantummodo indicativus et participium a radicā perfectī manent.

::: grammar-box
**Sunt duo genera perfecti formandi:**
*   **perfectum reduplicatum = ⟪द्वित्वलिट्⟫**
*   **perfectum periphrasticum = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Perfectum periphrasticum (⟪अनुप्रयोगलिट्⟫) adhibetur:**
1. **in coniugationibus derivatis (causativum, desiderativum, frequentativum, denominativa)**
2. **in radicibus, quae vocali longa (praeter ā-) incipiunt, vel vocali (praeter a-) ante duas consonantes**
3. **in quibusdam aliis radicibus**
:::
## 34.2. Perfectum reduplicatum (⟪द्वित्वलिट्⟫)

### 34.2.1. Gradus thematis

::: grammar-box
**Educatio:**

**thema forte:** singularis Parasmaipada
*   **reduplizierte hochstufige bzw. dehnstufige Wurzel + Perfektendung**

**stamen infirmum:** omnes reliquae formae
*   **radix reduplicata cum syllaba profunda + desinens perfecti**
:::
::: grammar-box
**Generaliter (etiam extra perfectum) non habent mutationem staminis radices formae:**
*   **(consonans)-consonans-vocalis longa-consonans**
*   **(consonans)-consonans-vocalis-consonans-consonans**

**In perfecto quoque radices formae:**
*   **a-consonans**
*   **ā-consonans**
:::
### 34.2.2. Desinens perfecti

::: grammar-box

| | 3. Singular | 3. Plural |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |

:::
### 34.2.3. Bindevokal -i-

::: grammar-box
**Ante terminationem 3.pl.Ā (-re) semper vocem coniunctivam -i- apponit, ante alias terminationes consonantibus incipientes apud radices plerumque.**
:::
### 34.2.4. Reduplicatio radicum consonantibus incipientium

::: grammar-box
**Pro reduplicatione consonantium initialium regulae in [Lektion 33](lektion33.md) datae valent.**

**Reduplicationis vocalis apud radices consonantibus incipientes est brevis radix vocalis.**

**Diphthongi ante consonantes per vocalem brevem acuta declinata reducuntur.**

**ṛ, ṝ, ḷ, et diphtongos finales per -a- reduplicantur.**
:::
Exempla:

::: grammar-box

| Wurzel | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | *⟪बि⟫*⟪भेद⟫ |
| ⟪मुच्⟫ | *⟪मु⟫*⟪मोच⟫ |
| ⟪भृ⟫ | *⟪ब⟫*⟪भार⟫ |

:::
::: grammar-box
**Radices quae y- vel v- initio praeditae sunt, cum i- vel u- reduplicant, quod in formis infirmis cum vocali radicali "confunditur".**
:::
Exempla:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Reduplicatio radicum vocaliter incipientium

::: grammar-box
**1. a- et ā- initialia cum a- duplicantur, ut ā- appareat.**
:::
Exempla:

::: grammar-box

| Wurzel | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "sein" und ⟪अस्⟫ 4 "werfen" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. Radices cum i- initiali habent ut syllaba reduplicativa in stemmate forti iy-, in stemmate debili i-, quae cum vocali radicali in ī- "confunditur. Idem valet pro u- initiali.**
:::
Exempla:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. Radices quae syllaba a- ante duas consonantes vel syllaba ṛ- incipiunt, syllabam reduplicationis ān- habent**
:::
Exempla:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. Typi perfecti reduplicati

Principium divisionis: proprietates gradus thematis:
*   Perfectum sine gradu thematis: Typus I
*   Perfectum cum gradu thematis: Typus II - V
*   unregelmäßige Perfektbildungen

## 34.4. Perfectum Typus I: Perfectum sine gradatione radicis

::: grammar-box
**Perfectum Typus I (sine mutatione radicis) habent radices typorum:**
*   **(Consonans)-Consonans-Vocalis longa-Consonans**
*   **(Consonans)-Consonans-Vocalis-Consonans-Consonans**
*   **a-Consonans**
*   **ā-Consonans**
:::
Exempla:

::: grammar-box

| Wurzel | 3. sg. Perf. | 3. pl. Perf. |
| :--- | :--- | :--- |
| ⟪बन्ध्⟫ 9P | ⟪बबन्ध⟫:brba-bandh-a | ⟪बबन्धुर्⟫ |
| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |
| ⟪आप्⟫ 5P | ⟪आप⟫:bra + āp-a | ⟪आपुर्⟫ |
| ⟪अस्⟫ 2P "sein":br⟪अस्⟫ 4 "werfen" | ⟪आस⟫:bra + as-a | ⟪आसुर्⟫ |
| ⟪अश्⟫ | ⟪आनशे⟫:brunregelmässige Reduplikation! | ⟪आनशिरे⟫ |

:::
## 34.5. Perfectum Typus II: Robustum radix gradus altus, infirmus radix gradus bassus

::: grammar-box
**A forma radicum huiusmodi compositum:**
*   **(Consonans)-(Consonans)-i/u/ṛ/ḷ-Consonans**

**Formatio:**
*   **strenuus radix: Gradus altus**
*   **imbecillus radix: Gradus humilis**
:::
Exempla:

::: grammar-box

| Wurzel | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪भिद्⟫ | ⟪बिभेद⟫ | ⟪बिभिदुर्⟫ | ⟪बिभिदे⟫ | ⟪बिभिदिरे⟫ |
| ⟪इष्⟫ | ⟪इयेष⟫ | ⟪ईषुर्⟫ | | |
| ⟪मुच्⟫ | ⟪मुमोच⟫ | ⟪मुमुचुर्⟫ | ⟪मुमुचे⟫ | ⟪मुमुचिरे⟫ |
| ⟪वृत्⟫ | | | ⟪ववृते⟫ | ⟪ववृतिरे⟫ |

:::
