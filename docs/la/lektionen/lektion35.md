# Lectio 35

## 35.1. Perfectum Typus III: Robustus radix gradus fortis/gradus productus

::: grammar-box
**Conformatio:**

**radix robusta:**
*   3.sg.P: gradus productus
*   2.sg.P: gradus fortis
*   1.sg.P: gradus fortis vel gradus productus arbitrio

**radix infirmus:** vide apud subtypos
:::

### 35.1.1. Perfectum Typus IIIa: Radix fortis gradus altus/longus, radix debilis gradus infimus

:::: grammar-box
**Conformatio:**

::: indent
**radix debilis:** gradus infimus
:::

Ex radicibus huiusmodi formatur:
*   (Consonans)-(Consonans) - i/ī/u/ū
*   (Consonans) - ṛ

Ante terminationem vocalicum:
*   -i/-ī per -iy
*   -u/-ū per -uv
*   -ṛ durch r
::::

Exempla:

:::: grammar-box

| Radix | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| इ 2P | इयाय[[br]]iy-ai + a | ईयुर्[[br]]i + iy + ur | | |
| नी 1U | निनाय | निन्युर्[[br]]ni-nī + ur | निन्ये | निन्यिरे |
| स्तु 2U | तुष्टाव[[br]]tu + stau + a | तुष्टुवुर्[[br]]tu + stuv-ur | तुष्टुवे | तुष्टुविरे |
| पू | पुपाव[[br]]pu-pau + a | पुपुवुर्[[br]]pu-puv-ur | पुपुवे | पुपुविरे |
| कृ | चकार | चक्रुर्[[br]]ca-kr-ur | चक्रे | चक्रिरे |

::::

### 35.1.2. Perfectum Typus IIIb: Radix fortis gradus superior/gradus productus, radix debilis gradus superior

:::: grammar-box
**Conformatio:**

::: indent
**radix debilis:** gradus superior
:::

Ex radicibus huiusmodi formatur:
*   (Consonans)-(Consonans)-ṝ
*   Consonans-Consonans-ṛ (id est, radices in -ṛ desinentes, si plures consonantes praecedant)
::::

::::

## 35.2. Perfectum Typ IV: Radices in -ā / -āi

::: grammar-box
**Conformatio:**

**stamma fortis:**
*   3./1. sg. P Perfectum terminatur in -au
*   2\. sg. P : gradus altus -ā vel gradus humilis -i

**stanna debilis:**
*   ante consonantem: gradus humilis -i
*   ante vocalem: gradus humilis Ø

A radicibus in -ā / -āi formatum
:::

Exemplum:

:::: grammar-box

| Radix | 3. sg. Perf. P.[[br]]1. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| दा 3U | ददौ | ददुर्[[br]]da-d-ur | ददे | ददिरे[[br]]da-d-i-re |

::::

## 35.3. Perfectum Typus V: Radices Consonant-a-Consonant

::: grammar-box
**Constitutio:**

**stamma fortis:**
*   3.sg.P: Gradus dilatus
*   2.sg.P: Gradus excelsus
*   1.sg.P: Gradus excelsus vel gradus dilatus arbitrio

**stamma debilis:** vide subtypos

A radicibus typi (Consonant)-Consonant-a-Consonant constituitur
:::

### 35.3.1. Perfectum Typus Va: radix infirma gradus profundus

:::: grammar-box
**Constitutio:**

::: indent
**radix infirma:** gradus profundus
:::

Formantur inter alia e radicibus:
*   गम्
*   हन्
*   जन्
*   वच्
*   वद्
*   यज्
::::

::::

### 35.3.2. Perfectum Typus Vb: radix infirma Contractio (typus e-)

:::: grammar-box
**Constitutio:**

::: indent
**radix infirma:** nulla reduplicatio. Substitutio -a- radicis per -e-  
(vid explanationem Thumb-Hauschild 1,2 p. 286 seq.)
:::

Formatur ex radicibus cum -a- inter duas consonantes simplices, quarum consonans initialis in syllaba reduplicationis non mutatur (id est, cuius consonans initialis non est gutturalis, aspirata, vel h).
::::

Exemplum:

:::: grammar-box

| Radix | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| पच् 1U | पपाच | ***पे***चुर् | ***पे***चे | ***पे***चिरे |

::::

### 35.3.3. Perfectum Typus Vc: Radices consonant-a-consonans. Stamen debilis gradu superiori

::: grammar-box
**Conformatio:**

**stamen debilis:** gradu superiori

Ab omnibus aliis radicibus medio -a- instructis, id est radicibus medio -a-
*   quae duobus consonantibus incipiunt
*   quae gutturali incipiunt
*   quae aspirata incipiunt
*   quae h littera incipiunt

formatur,
nisi ad Perfectum Typum Va pertinent.
:::

Exemplum:

:::: grammar-box

| Radix | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| क्रम् 1U | चक्राम | चक्रमुर् | चक्रमे | चक्रमिरे |

::::
