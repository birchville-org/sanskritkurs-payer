# Lektion 30

## 30.1. Die 9. Präsensklasse (⟪क्र्यादि⟫ = "⟪क्री⟫ u.s.w.")

::: grammar-box
**Educatio:**

*   radix valida: radix gradus infimus + -nā-

*   radix infirma:

    *   ante consonantem: radix acuta + -nī-

    *   ante vocalem: radix acuta + -n-
:::
Exemplum:

::: indent
⟪क्री⟫ 9U "emere"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **3. Person:brĀtmanepada** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
In hac classe praesentis maxime observanda est formatio radicalis praesentis ad radicem ⟪ज्ञा⟫ 9U "scire, noscere":

::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **3. Person:brĀtmanepada** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
Forma ⟪जा⟫, quae radicam praesentis ⟨ज्ञा⟩ subiacet, vel per series ablautium -ā (gradus infimus) -nā (gradus summus) explicari potest, vel per dissimilationem e *jñā-nā-ti.

Quaedam radices vocalem longam ante suffixum praesentis radicis nonae classis breviant:

Exemplum:

::: indent
⟪पू⟫ 9U "purgo"
:::

## 30.2. Usus optativi (⟪लिङ्⟫)

Optativus adhibetur:

::: grammar-box
**1. ad designationem**

*   **cuiuslibet voti**
*   **cuiuslibet voti**
*   **cuiuslibet precis**

**(hic optativus - ⟪लिङ्⟫ - cum imperativo - ⟪लोट्⟫ - congruit)**
:::
Exemplum:

::: indent
⟪दासो⟫ ⟪ग्राममागच्छेत्⟫ = "Servus ad villam veniat"
:::
::: grammar-box
**2. Si quid ut**

*   **possibile**
*   **probabile**
*   **verisimile**

**repraesentari debet.**
:::
Exemplum:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं⟫ ⟪न⟫ ⟪शृणुयात्⟫ = "Si e vico egressus esset, magistrum non audiret"
:::
::: grammar-box
**3. Relativa cum optativo saepe significare possunt: "Si quis ..."**
:::
Exemplum:

::: indent
⟪यो⟫ ⟪नृतं⟫ ⟪वदेत्स⟫ ⟪नरकं⟫ ⟪पतेत्⟫ = "Si quis mendacium diceret, in inferna descenderet = Si quis mendacium dicit, in inferna descendit"
:::
## 30.3. Secundariae terminationes personarum tertiae singularis et pluralis

| **Ātmanepada** | **-ta** | athematische Klassen: **-ata** (aus *nta):brOptativ: **-ran** |

:::

## 30.5. Sandhi von auslautendem -r

::: grammar-box
**Praeter quam pro -ar, pro -r finali eadem valent regulae Sandhi quam pro -s finali.**

**-ar ante sonantes consonantes manet -ar, ante r- vero excidit -r et -a- per -ā- substituitur.**
:::
Exempla:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
