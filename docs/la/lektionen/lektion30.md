# Lectio 30

## 30.1. Nonum Praesentis Classis (क्र्यादि = "क्री etc.")

::: grammar-box
**Conformatio:**

*   radix fortis: radix gradus infimi + -nā-
    
*   radix infirma:
    
    *   ante consonantem: radix gradus infimi + -nī-
        
    *   ante vocalem: radix gradus infimi + -n-
:::
        

Exemplum:

::: indent
क्री 9U "emere"
:::

::: grammar-box

| |Singularis[[br]]एकवचन|Pluralis[[br]]बहुवचन|
| :--- | :--- | :--- |
|**Persona tertia[[br]]Parasmaipada**|क्रीणाति[[br]](krī + nā + ti)|क्रीणन्ति[[br]](krī + n + anti)|
|**Persona tertia[[br]]Ātmanepada**|क्रीणीते[[br]](krī + nī + te)|क्रीणते[[br]](krī + n + ate)|

:::

In hac praesentis classe maxime est observandus praesentis radix formationem ad radices ज्ञा 9U "scire, noscere":

::: grammar-box

| |Singularis[[br]]एकवचन|Pluralis[[br]]बहुवचन|
| :--- | :--- | :--- |
|**Persona tertia[[br]]Parasmaipada**|जानाति[[br]](jā-nā-ti)|जानन्ति[[br]](jā-n-anti)|
|**Persona tertia[[br]]Ātmanepada**|जानीते[[br]](jā-nī-te)|जानते[[br]](jā-n-ate)|

:::

Nonnullae radices vocalem longam ante praesentis classis suffixum abbreviant:

Exemplum:

::: indent
पू 9U "purgare"

## 30.2. Usus Optativi (लिङ्)

Optativus adhibetur:

::: grammar-box
**1. ad significandum**

*   **voluntatem**
*   **precatio**
*   **mandatum mitius**

**(hic Optativus - लिङ् - cum Imperativo - लोट् - coërcet)**
:::

Exemplum:

::: indent
दासो ग्राममागच्छेत् = "Servus ad vicum veniat"
:::

::: grammar-box
**2. Si aliquid ut**

*   **possibile**
*   **probabile**
*   **verisimile**

**repraesentari debet.**
:::

Exemplum:

::: indent
ग्रामाच्चेद्गच्छेद्गुरुं न शृणुयात् = "Si e vico exiret, dominum non audiret"
:::

::: grammar-box
**3. Proposiciones relativae cum Optativo interdum valent: "Si quis ..."**
:::

Exemplum:

::: indent
यो नृतं वदेत्स नरकं पतेत् = "Si quis falsum diceret, in infernum caderet = Si quis falsum dicit, in infernum cadit"
:::

## 30.3. Secundarum flexionum personarum tertiae singularis et pluralis

Optativus (लिङ्), Imperfectum (लङ्), Aoristus (लुङ्), Prekatīvum (आशिर्लिङ्) et Conditionalis habent secundas flexiones, quae vocantur:

::: grammar-box

| |Persona tertia singularis|Persona tertia pluralis|
| :--- | :--- | :--- |
|**Parasmaipada**|**-t**|classes athematicae: **-an** vel **-ur**[[br]]Optativus: **-ur**|
|**Ātmanepada**|**-ta**|classes athematicae: **-ata** (ex *nta)[[br]]Optativus: **-ran**|

:::

## 30.5. Sandhi vocis finalis -r

::: grammar-box
**Praeter vocalem -ar, eadem regula Sandhi viget pro finali -r, quae pro finali -s.**

**-ar ante sonantem consonantem manet -ar, ante r- vero excidit -r, et -a- mutatur in -ā-.**
:::


Exempla:

::: indent
भवेयुर् + च » भवेयुश्च

पुनर् + अग्निः » पुनरग्निः

पुनर् + रोदिति » पुना रोदिति
:::
