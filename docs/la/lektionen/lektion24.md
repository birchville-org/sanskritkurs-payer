# Lectio 24

## 24.1. Dativus (चतुर्थी = "quartus casus terminatio")

:::: grammar-box
**1. Ut finem vel intentionem ("ut") actionis repraesentetur, potest pro infinitivo (तुमुन्) nomen cum suffixo kṛt, quod actionem vel statum designat, in Dativivo (चतुर्थी = "quartus casus terminatio") adhiberi.**

Exemplum:

pro:

::: indent
रामो गुरुवचनं श्रोतुं गतः ।
:::

dicere potest:

::: indent
रामो गुरुवचनस्य श्रवणाय गतः ।

aut:

रामो गुरुवचनश्रवणाय गतः ।
:::

= "Rāma abiit, ut orationem magistri audiret."
::::

::: media
![](/images/lekt2404.jpg)
Abb.: बाला गुरुश्रवणाय गताः
(Fons imaginis: [Detalia](/la/licenses#lekt2404))
:::

:::: grammar-box
**2. Dativus (चतुर्थी) etiam objectum infinitivi propositi supplendi designare potest:**

Exemplum:

::: indent
फलेभ्यो ग्रामं गच्छति = "Ad fructuum causam ad villam it = Ad villam it, ut fructus colligat."
:::

**Eodem modo Dativus (चतुर्थी) rei vel actionis causam designat:**

Exemplum:

::: indent
यज्ञायान्नम् = "Cibus pro sacrificii causa = Cibus pro sacrificio"
:::
::::

::: media
![](/images/lekt2401.jpg)
Abb.: यज्ञायान्नम्

Centenaria ieiunia vegetariana Bhagwan Swaminarayan [સ્વામિનારાયણ] in hac die offeruntur.
(Fons imaginis: [Detalia](/la/licenses#lekt2401))
:::

:::: grammar-box
**3. Dativus (चतुर्थी) etiam personam vel rem designat, pro qua objectum actionis destinatum est (objectum indirectum; quaestio: cui?). (Sed verba cum duplici Accusativo (द्वितीया) attende!)**

Exemplum:

::: indent
रामाय फलं ददाति = "Dat Rāmāe fructum." (Radix दा 3. Praesentis classis)
:::
::::

::: media
![](/images/lekt2402.jpg)
Abb.: बाला बालाय रक्षबन्धनं ददाति
Raksha bandhan cum fervore et gaudio per omnem Indiam celebratur. Hoc festivalium fraternam et sororalem amorem sine conditione repraesentat.
(Fons imaginis: [Detalia](/la/licenses#lekt2402))
:::

:::: grammar-box
**4. Dativus apud aliqua verba (et alia quaedam verba) similiter ac in Germanico ad quaestionem "cui?" ponitur:**

Exempla:

::: indent
क्रुध् : देवो नरेभ्यो क्रुध्यति = "Deus viris irascitur."

अलम् Adverbium: "satis, sufficiens, aequans": अलं योधो योधाय = "miles altero milite aequans est"
:::
::::

## 24.2. Formatio casus dativi (चतुर्थी)

::: grammar-box
**Desinens casus dativi regularis sunt:**

* **Singularis: -e ; feminina vocali terminata: -ai**
* **Pluralis: Dativus et Ablativus पञ्चमी: -bhyas**
:::

### 24.2.1. Stemma consonantica

:::: grammar-box

| | Dativus Singularis | Dativus Pluralis |
| :--- | :--- | :--- |
| यजन्त् | **यजते**[[br]]yaja-t-e | **यजद्भ्यस्**[[br]]aus yaja-t-bhyas |
| महान्त् | **महते** | **महद्भ्यस्** |
| पशुमन्त् | **पशुमते** | **पशुमद्भ्यस्** |
| गुणवन्त् | **गुणवते** | **गुणवद्भ्यस्** |

::::

### 24.2.2. Questiones interrogativae

:::: grammar-box

| | Masculinum / Neutrum | Femininum |
| :--- | :--- | :--- |
| **Dativus Singularis** | **कस्मै** | **कस्यै** |
| **Dativus Pluralis** | **केभ्यस्** | **काभ्यस्** |

::::

### 24.2.3. Pronomina demonstrativa

:::: grammar-box

| | | तद् | एतद् | इदम् |
| :--- | :--- | :--- | :--- | :--- |
| **Masculinum / Neutrum** | **Dat. sg.** | **तस्मै** | **एतस्मै** | **अस्मै** |
| | **Dat. pl.** | **तेभ्यस्** | **एतेभ्यस्** | **एभ्यस्** |
| **Femininum** | **Dat. sg.** | **तस्यै** | **एतस्यै** | **अस्यै** |
| | **Dat. pl.** | **ताभ्यस्** | **एताभ्यस्** | **आभ्यस्** |

::::

### 24.2.4. Stemmata vocalica

::: grammar-box
**Stemmata vocalica**

* **Masculina / Neutra in -a:** देव
  * Dat. sg. **देवाय**
  * Dat. pl. **देवेभ्यस्**
* **Masculina in -i:** कवि
  * Dat. sg. **कवये**
  * Dat. pl. **कविभ्यस्**
* **Masculina in -u:** पशु
  * Dat. sg. **पशवे**
  * Dat. pl. **पशुभ्यस्**
* **Femina in -ā:** देवता
  * Dat. sg. **देवतायै**
  * Dat. pl. **देवताभ्यस्**
* **Femina in -ī:** देवी
  * Dat. sg. **देव्यै**
  * Dat. pl. **देवीभ्यस्**
* **Femina in -i:** श्रुति
  * Dat. sg. **श्रुतये** aut **श्रुत्यै** (id est ut कवि aut ut देवी)
  * Dat. pl. **श्रुतिभ्यस्**
* **Femina in -u:** धेनु
  * Dat. sg. **धेनवे** aut **धेन्वै**
  * Dat. pl. **धेनुभ्यस्**
:::

## 24.3. Sandhi vocis finalis -ai et -au

:::: grammar-box
**Sandhi vocis finalis -ai et -au**

* **-ai ante vocalem initialem per -ā (rarior per -āy, ut in medio verbi) solitur mutari**
* **-au ante vocalem per -āv (rarior per -ā) solitur mutari**

Exemplum:

::: indent
तस्मै + अग्नये » तस्मा अग्नये = "igni huic"
:::
::::

## 24.4. Lexicon verborum

अलम् Adverbium: satis, sufficiens, (alicui, alicui rei) par ; cum Dativo: satis pro, sufficiens pro, par ei ; cum Instrumentali: satis cum, desiste a , e.g. अलं क्रोधेन = "satis ira = desiste ab ira!"

Eodem modo quo अलम् cum Instrumentali adhibetur:

कृतम् : कृतं क्रोधेन = "Factum est cum ira = desiste ab ira!"

## 24.6. Exercitationes de uso Dativi

Traducite in Sanscritum:

1\. Dea, cui non sacrificatum est, homines irascitur.

2\. Ille vaccam in vicum dimittit.

3\. Nunc satis est = Patientiae satis est.

4\. Id bonum est (हित, सुख) pro Brahmana.

5\. Veneratio (नमस्) sit Śivae! Vereatio sit Śrī Gaṇeśae!
