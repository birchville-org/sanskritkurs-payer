## 4.1. Quaestiones supplementariae simplices (quaestiones verborum) et responsiones

### 4.1.1. Questiones pronomina et pronomina demonstrativa

#### 4.1.1.1. Quaestio pronomina (praśnārthakasarvanāma n. = प्रश्नार्थकसर्वनामन्)

#### 4.1.1.2. Pronomina demonstrativa (nidarśakasarvanāmāni n. = निदर्शकसर्वनामानि)

::: grammar-box
| **Stamina** ||||
| :--- | :---: | :---: | :---: |

| **Neutrum** | **tāni = तानि** | **etāni = एतानि** | **imāni = इमानि** |
| **Masculinum** | **te = ते** | **ete = एते** | **ime = इमे** |
| **Femininum** | **tās = तास्** | **etās = एतास्** | **imās इमास्** |

**De Nom. sg. masc.:**
- **sa, eṣa** (स एष) ante omnes sonos praeter breve **-a** ponitur
- **so, eṣo** (सो एषो) ante **-a**, quod Avagraha eliditur (cadit) ponitur
- **saḥ, eṣaḥ** (सः एषः) tantum in pausa (fine sententiae, fine versus) ponitur

Ut his pronomina (sarvanāman n.) sententias formare possimus, notitia sequentium regulas Sandhi necessaria est:

### 4.1.2. Sandhi vocis finalis -m

::: grammar-box
**Vox finalis -m ante consonantes per Anusvāra (-ṃ) mutatur. In fine propositionis vel versus, ac ante vocales, -m manet.**
:::

### 4.1.3. Sandhi vocis finalis -e

::: grammar-box
1. **ante a- manet -e immutatum: initialis a- eliditur cum Avagraha:**
   exempli gratia: ete + agnayas » ete 'gnayaḥ = एते ऽग्नयः "Haec ignes"

2. **Ante alios vocales quam breve a- solet -e per -a cum hiato substitui. Etiam substitutio per -ay occurrit:**
   exempli gratia: ime + īśvarās » ima īśvarāḥ = इम ईश्वराः (rarum: imay īśvarāh = इमयीश्वराः) "Haec domini"
:::

### 4.1.4. Sandhi vocis finalis -d

::: grammar-box
**Vox finalis -d in pausa atque ante gutturales sordidas (k, kh) et labiales (p, ph) per -t mutatur.**

Mutatio ante alios consonantes postea tractabitur. Evita huiusmodi consonantium concursus interim!
:::

### 4.1.5. Formulae interrogativae

Hoc pronominibus, formulae interrogativae, ut exemplum, formantur:

::: grammar-box
| | | | |
| :--- | :--- | :--- | :--- |
| **Singularis** | **Neutrum** | quid est? / quod est?[[br]]तत्किम्, किं तत्[[br]][[br]]hoc quid? / quid hoc?[[br]]एतत्किम्, किमेतत्[[br]][[br]]id quid? / quid id?[[br]]इदं किम्, किमिदम् | "Quid est hoc?" |
| | **Masculinum** | quis est? / quis ille?[[br]]स कः, कः सः[[br]][[br]]hic quis? / quis hic?[[br]]एष कः, क एषः[[br]][[br]]is quis? / quis is?[[br]]अयं कः, को ऽयम् | "Quis est ille?"[[br]]"Quis est hic?" |
| | **Femininum** | quae est? / quae illa?[[br]]सा का, का सा[[br]][[br]]haec quae? / quae haec?[[br]]एषा का, कैषा[[br]][[br]]ea quae? / quae ea?[[br]]इयं का, केयम् | "Quae est illa?"[[br]]"Quae est haec?" |
| **Pluralis** | **Neutrum** | quae sunt? / quae illa?[[br]]तानि कानि, कानि तानि[[br]][[br]]haec quae? / quae haec?[[br]]एतानि कानि, कान्येतानि[[br]][[br]]haec quae? / quae haec?[[br]]इमानि कानि, कानीमानि | |
| | **Masculinum** | qui sunt? / qui illi?[[br]]ते के, के ते[[br]][[br]]hi qui? / qui hi?[[br]]एते के, क एते[[br]][[br]]ii qui? / qui ii?[[br]]इमे के, क इमे | |
| | **Femininum** | quae sunt? / quae illae?[[br]]ताः काः, कास्ताः[[br]][[br]]hae quae? / quae haec?[[br]]एताः काः, का एताः[[br]][[br]]illae quae? / quae illae?[[br]]इमाः काः, का इमाः | |
:::


Exemplum alterius quaestionis:

> viṣṇuḥ kaḥ? = विष्णुः कः Responsio: viṣṇur īśvaraḥ = विष्णुरीश्वरः. (Hic in propositione nominali subiectum, exempli gratia, ad initium ponere licet, ut nexum cum quaestione sublineatur.)

NOTA: Responso, quod cum tuis hactenus scientiis Sanscriticis ad has quaestiones dare potes, non omnibus modis idiomate bono Sanscritico respondet.
