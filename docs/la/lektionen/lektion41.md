## 41.2. Weitere ⟪कृत्⟫-Bildungen auf -a

### 41.2.1. Participium Praesens (⟪लडादेशः⟫) Ā, Participium Praesens (⟪लडादेशः⟫) Passivumum, Participium Futuri (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Tematica praesentis, passivi et futuri

::: grammar-box
**Formatio:**

radix praesentis / radix passivi / radix futuri + -māna (fem. mānā)
:::
Exempla:

⟪यज्⟫ 1U, Part.Præs.Ā ⟪यजमान⟫ 3 "qui propter suum commodum sacrificium colit = dominus sacrificii"

⟪मन्⟫ 4Ā, Part.Præs.Ā ⟪मन्यमान⟫ 3 "mensans"

⟪कृ⟫ 8U, Part.Præs.Pass. ⟪क्रियमाण⟫ 3 "quod fit"

⟪दा⟫ 3U, Part.Fut.Ā ⟪दास्यमान⟫ 3 "qui propter suum commodum daturus est"

#### 41.2.1.2. Classes de praesentia athematica

::: grammar-box
**Formatio:**

Stamen praesentis infirmum (in forma, quam habet ante terminationem -ate tertiae pluralis Ā) + -āna (femininum -ānā)
:::
Exempla:

::: grammar-box
| Radix / Classis | Participium praesentis Ā |
| :--- | :--- |
| **⟪द्विष्⟫** 2U | ⟪द्विषाण⟫ |
| **⟪हु⟫** 3P | \&lt;⟪जुह्वान⟫\&gt;:brju-hu + āna |
| **⟪सु⟫** 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| **⟪रुध्⟫** 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| **⟪तन्⟫** 8U | ⟪तन्वान⟫:brtan-u + āna |
| **⟪क्री⟫** 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "Participium" necessitatis passivae (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Ut necessitatem passivam exprimatur ("quod faciendum est/solum"), adiectiva ex radicibus et stemmatibus verbalibus derivatis vel cum sequentibus suffixis formari possunt:**

* **-⟪तव्य⟫** (fem. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (fem. **-⟪अनीया⟫**)
* **-⟪य⟫** (fem. **-⟪या⟫**)
* **-⟪त्य⟫** (fem. **-⟪त्या⟫**) (pro **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Suffixum -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Suffixum -⟪तव्य⟫ / -⟪तव्या⟫ radicibus et stemmatibus verbalibus derivatis (e.g. causativo) eodem modo adicitur quo suffixum infinitivale -⟪तुम्⟫ (vid. [Lectio 23](lektion23.md)), id est.**

* **radix gradu supremo + ⟪तव्य⟫**

autem

* **radix summi gradus + -i- + ⟪तव्य⟫**

**In causativo:**

* **stamen causativum in -ay + -i- + ⟪तव्य⟫**
:::
Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "jemand, der besiegt werden muss; ein zu besiegender" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "das, wo man sich befinden soll" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "jemand, der geweckt werden soll; ein zu erweckender" |

:::
#### 41.2.2.2. Suffixum -⟪अनीय⟫ / -⟪⟪अनीया⟫

::: grammar-box
**Formatio:**

Radix gradus optativi + -⟪अनीय⟫ / -⟪अनीया⟫

**Causativum et decima classis praesentis:**

Radix, qualis in causativo apparet, sine -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "zu gebendes; was gegeben werden muss" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "zu besiegender" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "zu tuendes" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "was man sehen muss; sehenswertes" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "ein zu weckender" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "was man geben lassen muss" |

:::
#### 41.2.2.3. Suffixum -⟪य⟫ / -⟪या⟫

::: grammar-box
**Formatio:**

Radix (in gradu profundo, alto vel producti) + -⟪य⟫

Regulas exactas vide apud Kielhorn, Grammatica Linguae Sanscritae, p. 195 - 197!
:::
Tractatio vocium finalium:

::: grammar-box
**1. Radices in -ā gerundivum formant in -eya**
:::
Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "zu wissendes; was erkannt werden muss" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "was gegeben werden muss" |

:::
::: grammar-box
**2. Radices in -i /-ī / -u / -ū /-ṛ habent regulariter gradum altum vel productum, nisi ad eas radices in -i / -u /-ṛ pertinent quae gerundivum cum suffixo -⟪त्य⟫ (fem. -⟪त्या⟫) formant (lista earum radicum apud Kielhorn, Grammatica §537).**
:::
Exemplum:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P | ⟪स्मर्य⟫ 3 | "woran man sich erinnern muss" |

:::
::: grammar-box
**2a. Radices in -i/-ī gradum altum habent**
:::
Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | "zu verkaufen; verkäuflich" |
| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "zu führender" |

:::

**2b. Radices in -u /-ū substitutum altum gradum -o ante -ya per -av, quod productum gradum -au per -āv. Producta formatio hoc loco necessitatem significat.**

#### 41.2.2.4. Suffixum -⟪त्य⟫ / ⟪त्या⟫ (pro -⟪य⟫ / -⟪या⟫)

::: grammar-box
Lista radicum in -i / -u /-ṛ, quae gerundivum non cum -⟪य⟫ / -⟪या⟫ sed cum suffixo -⟪त्य⟫ (fem. -⟪त्या⟫) formant, apud Kielhorn, Grammatica §537.

**Formatio:**

radix profunda + -⟪त्य⟫ / -⟪त्या⟫
:::
Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "zu gehender" |
| ⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "zu hörender" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "zu tuender" |

:::
### 41.2.3. Syntactica de "participio" necessitatis passivae (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
Gerundivum attributive adhiberi potest:

:::
::: indent
**⟪दर्शनीयं⟫ ⟪नगरम्⟫** = "urbs videnda; urbs spectabilis"
:::
Gerundivum quoque ut nomen praedicativum in sententiis cum constructione passiva adhiberi potest, quae obligationem vel imperium exprimunt (cum ⟪न⟫ prohibetio, impossibilitas):

::: indent
**⟪काशी⟫ ⟪द्विजैर्द्रष्टव्या⟫** = "Bis ter natos Benaresas videre oportet"
:::

### 41.2.4. Differentiae in usu suffixorum gerundivi

::: grammar-box
Fere congruit usus horum suffixorum

* **-⟪तव्य⟫ (fem. -⟪तव्या⟫):** semper necessitatem exprimit et praedicative adhiberi solet (rarissime attributive). Formae hoc suffixo constructae in compositionibus nominalibus non adhiberi debent.
* **-⟪अनीय⟫ (fem. -⟪अनीया⟫) et -⟪य⟫ (fem. -⟪या⟫) / -⟪त्य⟫ (fem. -⟪त्या⟫) (pro -⟪य⟫/-⟪या⟫):** aliam significationem habere possunt (praesertim -⟪य⟫) secundum Germanicam "-valor" (e.g. "visu dignus") vel tantum possibilitatem "-bilis" (⟪दृश्य⟫ "visibilis"). Formae his suffixis constructae cum ⟪अ⟫/-⟪अन्⟫ negari possunt (non tamen formae cum -⟪तव्य⟫) et sunt ⟪तत्पुरुष⟫ ut pars posterior quae occurrit.
:::
### 41.2.5. Nulla coniunctio cum ⟪सु⟫- et ⟪दुस्⟫-

::: grammar-box
Cum ⟪सु⟫- et ⟪दुस्⟫- in significatione "facilis" vel "difficilis", gerundiva coniungi non debent. Pro quibus stant ⟪तत्पुरुष⟫ generis ⟪सुकर⟫ 3 ("facile faciendum") (s. [Lectio 18](lektion18.md)).
:::
