## 41.2. Ulteriores formationes कृत् in -a

### 41.2.1. Participium Praesentis (लडादेशः) Ā, Participium Praesentis (लडादेशः) Passivum, Participium Futuri (ऌडादेशः) Ā

#### 41.2.1.1. Thematische Praesentstämme, Passivum et Futurum

::: grammar-box
**Constitutio:**

Praesentistammas / Passivustammas / Futurstammas + -māna (fem. mānā)
:::

Exempla:

यज् 1U, Part.Praes.Ā यजमान 3 "qui propter suum interesse cum sacrificio colitur = dominus sacrificii"

मन् 4Ā, Part.Praes.Ā  मन्यमान 3 "cogitans"

कृ 8U, Part.Praes.Passiv क्रियमाण 3 "quod fit"

दा 3U, Part.Fut.Ā दास्यमान 3 "qui propter suum interesse daturus est"

#### 41.2.1.2. Athematicae Praesentis classes

::: grammar-box
**Constitutio:**

Debilis praesentistammas (in forma, quam habet ante terminationem -ate 3.pl.Ā) + -āna (fem. -ānā)
:::

Exempla:

::: grammar-box
| Radix / Classis | Participium Praesentis Ā |
| :--- | :--- |
| **द्विष्** 2U | द्विषाण |
| **हु** 3P | &lt;जुह्वान&gt;[[br]]ju-hu + āna |
| **सु** 5U | सुन्वान[[br]]su-nu + āna |
| **रुध्** 7U | रुन्धान[[br]]ru-n-dh-āna |
| **तन्** 8U | तन्वान[[br]]tan-u + āna |
| **क्री** 9U | क्रीणान[[br]]krī + n-āna |
:::

### 41.2.2. "Particivum" necessitatis passivae (Gerundivum) (कृत्य)

::: grammar-box
**Ut necessitatem passivam exprimant ("quod facere debet/oportet"), adiectiva ex radicibus et stemmatibus verbalibus derivatis vel cum sequentibus suffixis formantur:**

* **-तव्य** (fem. **-तव्या**)
* **-अनीय** (fem. **-अनीया**)
* **-य** (fem. **-या**)
* **-त्य** (fem. **-त्या**) (pro **-य**/**-या**)
:::

#### 41.2.2.1. Suffixum -तव्य / -तव्या

::: grammar-box
**Suffixum -तव्य / -तव्या radicibus et stemmatibus verbalibus derivatis (e.g. Causativo) eodem modo adicitur quo suffixum infinitivi -तुम् (v. [Lectio 23](lektion23.md)), id est**

* **radix gradus supremo + तव्य**

aut

* **radix gradus supremo + -i- + तव्य**

**In Causativo:**

* **stemma causativum in -ay + -i- + तव्य**
:::

Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| जि 1P | जेतव्य 3 | "qui vincendus est; vincendus" |
| वृत् 1Ā | वर्तितव्य 3 | "ubi esse debet" |
| बुध् Caus. | बोधयितव्य | "qui evocandus est; evocandus" |

:::

#### 41.2.2.2. Suffixum -अनीय / -अनीया

::: grammar-box
**Formatio:**

Radix gradus supremo + -अनीय / -अनीया

**Causativum et 10. classis praesentis:**

Radix, qualis in stemmate causativo apparet, sine -aya- + -अनीय / -अनीया
:::

Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| दा 3U | दानीय 3 | "dandum; quod dari debet" |
| जि 1P | जयनीय 3 | "vincendus" |
| कृ 8U | करणीय 3 | "faciendum" |
| दृश् | दर्शनीय 3 | "quod videri debet; spectabile" |
| बुध् Caus. | बोधनीय 3[[br]]bodh-aya - aya + -anīya | "evocandus" |
| दा Caus. | दापनीय 3[[br]]dā-paya - aya + -anīya | "quod dari iussu debet" |

:::

#### 41.2.2.3. Suffixum -य / -या

::: grammar-box
**Formatio:**

Radix (in profundo, supremo, seu producte gradu) + -य

Regulas exactas vide apud Kielhorn, Grammaticam Linguae Sanscritae, p. 195 - 197!
:::

Tractatio vocalium finalium:

::: grammar-box
**1. Radices in -ā hoc gerundivum in -eya formant**
:::

Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| ज्ञा 9U | ज्ञेय 3 | "scendum; quod cognosci debet" |
| दा 3U | देय 3 | "quod dari debet" |

:::

::: grammar-box
**2. Radices in -i /-ī / -u / -ū /-ṛ habent solite gradum supremum seu productum, nisi ad eas radices in -i / -u /-ṛ pertinent, quae gerundivum cum suffixo -त्य (fem. -त्या) formant (lista harum radicum apud Kielhorn, Grammatica §537).**
:::

Exemplum:

::: no-header

| | | |
| :--- | :--- | :--- |
| स्मृ 1P |  स्मर्य 3 | "de quo meminisse debet" |

:::

::: grammar-box
**2a. Radices in -i/-ī habent gradum supremum**
:::

Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| विक्री 9Ā | विक्रेय 3 | "vendendus; venalis" |
| नी 1U | नेय 3 | "ducendus" |

:::

#### 41.2.2.4. Suffixum -त्य / त्या (pro -य / -या)

::: grammar-box
Lista radicum in -i / -u /-ṛ, quae gerundivum non cum -य / -या sed cum suffixo -त्य (fem. -त्या) formant, apud Kielhorn, Grammatica §537.

**Formatio:**

radix gradus infimi + -त्य / -त्या
:::

Exempla:

::: no-header

| | | |
| :--- | :--- | :--- |
| इ 2P | इत्य 3 | "eundus" |
|  श्रु 5P |  श्रुत्य 3 | "audiendus" |
| कृ 8U | कृत्य 3 | "faciendus" |

:::

### 41.2.3. Syntactica de "Participio" necessitatis passivae (Gerundivum) (कृत्य)

:::: grammar-box
Gerundivum attributive adhiberi potest:

:::

::: indent
**काशी द्विजैर्द्रष्टव्या** = "Dvija Benares videre debet"

### 41.2.4. Differentiae in usu suffixorum gerundivi

::: grammar-box
Vix differt usus horum suffixorum

* **-तव्य (fem. -तव्या):** semper necessitatem exprimit et praedicative adhiberi solet (rarissime attributive). Formae hoc suffixo usae non in compositionibus nominalibus adhiberi debent.
* **-अनीय (fem. -अनीया) et -य (fem. -या) / -त्य (fem. -त्या) (pro -य/-या):** aliam significationem habere possunt (praesertim -य) sensu Germanico "-valoris" (e.g. "visu dignus") vel tantum possibilitatis "-ibilis" (दृश्य "visibilis"). Formae his suffixis usae cum अ/-अन् negari possunt (non vero formae cum -तव्य) et sunt तत्पुरुष ut eorum compositio occurrant.
:::

### 41.2.5. Nulla coniunctio cum सु et दुस्

::: grammar-box
Cum सु et दुस्, quae significat "levē" vel "grāve", gerundiva coniungi non debent. Pro his, तत्पुरुष generis सुकर 3 ("facile faciendum") stant (s. [Lectio 18](lektion18.md)).
:::
