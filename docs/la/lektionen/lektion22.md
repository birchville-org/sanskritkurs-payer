# Lectio 22

## 22.1. De absolutivo (क्त्वा । ल्यप्)

::: grammar-box

Si in Sanscrito exprimere volueris, actionem unius agentis (कर्तृ) aliam actionem eiusdem agentis praecedere, vel eam ut circumstantiam concomitantem comitari, absolutivum (क्त्वा । ल्यप्) adhibes. Ita

"postquam hoc fecit, illud facit"; "hoc facit, deinde illud facit"; "ex hoc sequitur, ut illud faciat"; "veni, vici, vici" et similia.

Absolutivum est adverbium verbi, id est nec coniugari nec declinari potest, sed semper — paucis exceptis — eundem agentem (कर्तृ) habet, quem habet actio, cui actionem per absolutivum significatam praecedit vel comitatur. Ita agentis absolutivi in nominativo (प्रथमा) vel instrumentalī (तृतीया) stat.

Praeter composita, absolutivum est unum ex frequentissimis modis exprimendi in Sanscrito.

In translatione in Germanicam linguam vitare oportet, saepe "postquam" dicere. In locum eorum, expressiones temporales in Germanica lingua usitatas adhibe.

**Schema:**

(determinatio proxima ad absolutivum: circumstantia, objectum, etc.) - absolutivum - absolutivum - ... - absolutivum - ... agens + oratio verbalis (in activo vel passivo)

:::

**Exempla:**

::: indent
**गृहं प्रविश्य बालां दृष्ट्वा नरो वदति** = constructio passiva: **गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते**  
"Vir intrat domum, puellam parvam videt eamque alloquitur."

Pluralis: **गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।**
:::

## 22.2. Formationis absolutivi

::: grammar-box
**Formatio absolutivi**

*   Verba sine praepositione: absolutivum in **-tvā**
*   Verba cum praepositione: absolutivum in **-ya** vel **-tya**
:::

### 22.2.1. Verba sine praebito: Absolutiv in -त्वा

::: grammar-box

**Conformatio:**

(plerumque) radix gradus imi forma, quam habet ante PPP + **-tvā** (**-त्वा**)

Solum negans **a-** / **an-** cum suffixo **-त्वा** patitur: **अकृत्वा** "sine facto"

:::

**Exempla:**

::: indent
**आप्त्वा** "postquam ille / illa / illud / ego / tu / nos / vos / illi / nos duo / vos duo / illi duo pervenit / pervenerat / perveniunt / pervenerunt"

**आसित्वा** "postquam ille (...) sedebat / sedet"

**इत्वा** "postquam ille (...) ibat / iit"

**स्थित्वा** "postquam ille (...) stabat / stetit"

**जित्वा** "postquam ille (...) vicit / vicerat"

**उक्त्वा** "postquam ille (...) locutus est / locutus erat"
:::

### 22.2.2. Verba cum praepositione

#### 22.2.2.1. Radices in vocale longa (praeter -ā) vel in consonante terminantes

::: grammar-box

**(plerumque) radix gradus imi + -ya**

:::

**Exempla:**

::: indent
**उपनीय** "postquam eum (...) adduxit / adduxerat"

**प्रभूय** "postquam eum (...) extulit / extulerat" "postquam potestatem habuit"

**प्राप्य** "postquam eum (...) adeptus est / adeptus erat"
:::

#### 22.2.2.2. Radices in -ā terminantes

::: grammar-box

**inmutatus gradus acutus radix + -ya**

:::

**Exemplum:**

::: indent
**उपस्थाय** "postquam eum (...) ingressus est / ingressus erat" ; (sed sine praepositione: **स्थित्वा**)
:::

#### 22.2.2.3. Radices, quae in gradu imo in brevi -i, -u, -ṛ terminant

::: grammar-box

**radix gradus imi + -tya**

:::

**Exempla:**

::: indent
**प्रस्तुत्य** "postquam eum (...) laudavit / laudaverat"

**विस्मृत्य** "postquam eum (...) obliviscens est / obliviscens erat"

**संस्कृत्य** "postquam eum (...) pro sacrificio paravit / paraverat"
:::

#### 22.2.2.4. Radices in -am / -an terminantes, quae in gradu imo in -a terminant

::: grammar-box

**Optionale:**

Radix in **-am** / **-an** + **-ya**

aut:

Radix in **-a** + **-tya**

:::

**Exemplum:**

::: indent
**विगम्य** aut **विगत्य** "postquam eum (...) transiit / transierat"
:::

::: indent
**अर्हन्त् 3** Part. Praes. P: dignus. In Buddhismo et Iainismo: qui liberationem ultimam consecutus est
:::

**व्रत n.:** votum, officium religiosum, observantia religiosa (promittit aliquis deo aliquid ut aliquid ab eo accipiat. Exemplum: mater promittit filiam suam ut templi meretricem (**देवदासी**) det, si filia sua iterum sanata fuerit. **व्रत** hodie importantes: ieiunium; abstinentia a cibis quos amat; abstinentia sexualis; lectio scripturarum sacrarum; exsecutio rituum quorundam; pascendi Brahmanas et cetera. Breviter de **व्रत**: Walker, Hindu World Vol. II, p. 581 seq. Dilucide: P. V. Kane: History of Dharmaśāstra Vol. 5,1 p. 1 - 462. Ibi p. 253 - 462 lista **व्रत** et festorum religiosorum ("haec lista ... non vult esse omnino exhausteria" !!!)

**चर् 1 P  charati Pass.  charyate PPP  charita Inf.  charitum (Sanskrit: चर् 1 P चरति Pass.  चर्यते PPP  चरित Inf.  चरितुम्) :** pascere, errare, se movere, agere, exercere, exsequi (e.g. **व्रतं चर्**: votum exercere, praesertim abstinentia sexualis)

ex quo:

::: indent
**चर ३:** mobilis; n.: mobile = animalia (in differentia a plantis)

**चरण n., m.:** pes

**चरित n.:** vita, res gestae

**ब्रह्मचर्य n.:** exsecutio Vedarum (**ब्रह्मन्**) = studium Vedarum in primo gradu vitae (gradus **ब्रह्मचारिन्**), qui abstinentiam strictam sexalem requirit; ideo etiam: abstinentia sexualis, vita celibata
