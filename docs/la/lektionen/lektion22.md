# Lektion 22

## 22.1. Das Absolutivum (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫)

::: grammar-box

Si vis Sanscritice exprimere actionem agentis (⟪कर्तृ⟫) alteri actioni agentis praecedere aut eam comitari, usurus es absolutivo (⟪⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫). Ergo

"postquam hoc fecit, illud facit" ; "hoc facit, deinde illud facit" ; "ex hoc facit illud" ; "veni, vidi, vici" et cetera.

Absolutivum est adverbium verbale, hoc est neque coniungitur neque declinatur, sed semper — paucis exceptis — idem agens habet (⟪कर्तृ⟫) quod actio, cui praecedit aut comitatur actio per absolutivum designata. Ergo agens absolutivi in nominativo (⟪प्रथमा⟫) vel ablativo (⟪तृतीया⟫) stat.

Praeter composita, abstrativus est unum e frequentissimis expressionis modis in Sanscrito.

In translatione ad linguam Germanicam, vitare oportet saepius "postquam" dicere. Proinde utendum est locutionibus in lingua Germanica usitatis pro successionem temporalem exprimenda.

**Schema:**

(notior determinatio ad absolutivum: circumstantia, obiectum, etc.) - absolutivum - absolutivum - ... - absolutivum - ... agens + oratio verbalis (in activo vel passivo)

:::
**Exempla:**

::: indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = Constructio passiva: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**  
"Vir domum intrat, puellam parvam videt eamque alloquitur."

Plural: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**
:::
## 22.2. Formationem absolutivi

::: grammar-box
**Formatio casus nominativi**

*   Verba sine praefixis: Absolutiv in **-tvā**
*   Verba cum praefixis: Absolutiv in **-ya** vel **-tya**
:::
### 22.2.1. Verba sine praefixis: Absolutiv in -⟪त्वा⟫

::: grammar-box

**Educatio:**

(meist) tiefstufige Wurzel in der Gestalt, die sie vor dem PPP hat + **-tvā** (**-⟪त्वा⟫**)

Solum negans **a-** / **an-** cum suffixo **-⟪त्वा⟫** compatitur: **⟪अकृत्वा⟫** "sine facto"

:::
**Exempla:**

::: indent
**⟪आप्त्वा⟫** "postquam ille/illa/id ego tu nos vos nos duo vos duo illi duae illa duo advenit/adventum est/advenere/adventum sunt"

**⟪आसित्वा⟫** "postquam (...) sedit / est"

**⟪इत्वा⟫** "postquam (...) abiit / abit"

**⟪स्थित्वा⟫** "postquam (...) confessus est / est"

**⟪जित्वा⟫** "postquam (...) vicit / vicerat"

**⟪उक्त्वा⟫** "postquam (...) dixit / dixerat"
:::
### 22.2.2. Verba cum praepositione

#### 22.2.2.1. Radices in vocale longum (praeter -ā) vel consonantem desinentes

::: grammar-box

**(plerumque) radice infimae gradus + -ya**

:::
**Exempla:**

::: indent
**⟪उपनीय⟫** "postquam (...) adduxit / adduxerat"

**⟪प्रभूय⟫** "postquam (...) emicuit / fuit" "postquam (...) potestatem habuit"

**⟪प्राप्य⟫** "postquam (...) adeptus est / habuit"
:::
#### 22.2.2.2. Radices in -ā

::: grammar-box

**radix immutata summi gradus + -ya**

:::
**Exemplum:**

::: indent
**⟪उपस्थाय⟫** "postquam (...) adstitit / stetit"; (sed sine praefixione: **⟪स्थित्वा⟫**)
:::
#### 22.2.2.3. Radices, quae in gradu profundo terminantur brevi -i, -u, -ṛ

::: grammar-box

**radix infima + -tya**

:::
**Exempla:**

::: indent
**⟪प्रस्तुत्य⟫** "postquam (...) laudavit / laudaverat"

**⟪विस्मृत्य⟫** "postquam (...) obliviscitur / oblitus est"

**⟪संस्कृत्य⟫** "postquam (...) pro sacrificio paravit / paraverat"
:::
#### 22.2.2.4. Radices in -am / -an, quae in gradu profundo in -a desinunt

::: grammar-box

**Opzionale:**

Radix in **-am** / **-an** + **-ya**

aut:

Radix in **-a** + **-tya**

:::
**Exemplum:**

::: indent
**⟪विगम्य⟫** sive **⟪विगत्य⟫** "postquam (...) abiit / fuit"
:::
