# Lectio 31

## 31.1. Classis VII. Praesentis (रुधादि = "रुध् et cetera")

:::: grammar-box
**Formatio:**

**Consonantes finales radicis, quae in gradu profundo stat, praecedunt, infixum quoddam nasale (-na- vel -n-) inseritur:**

*   **in stemmate forti: -na-**
*   **in stemmate debili: -n-**

**De coniunctione consonantium finalium radicis cum terminationibus consonantice incipientibus, eadem valent regulae ac pro classe praesentis secunda.**
::::

Exempla:

युज् 7U "iungere, iugum imponere"

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicativus** | **3. sg.** | युनक्ति[[br]]yu-na-j + -ti | युङ्क्ते[[br]]yu + n + j + te[[br]](ante gutturales in medio verbi, nales per -ṅ- mutantur) |
| | **3. pl.** | युञ्जन्ति[[br]]yu + n + j-anti | युञ्जते[[br]]yu + n + j-ate |
| **Optativus** | **3. sg.** | युञ्ज्यात्[[br]]yu + n + j-yā-t | युञ्जीत[[br]]yu + n + j-ī-ta |
| | **3. pl.** | युञ्ज्युर्[[br]]yu + n + j-y-ur | युञ्जीरन्[[br]]yu + n + j-ī-ran |
| **Participium Praesentis** | | युञ्जन्त्-[[br]]yu + n + j-ant-[[br]]fem.: युञ्जती[[br]]yu + n + j-at-ī | |

::::

रुध् 7U "sistere, ad quietem perducere"

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicativus** | **3. sg.** | रुणद्धि[[br]]ru + na + dh + ti | रुन्द्धे[[br]]ru-n + dh + te |
| | **3. pl.** | रुन्धन्ति[[br]]ru-n-dh-anti | रुन्धते[[br]]ru-n-dh-ate |
| **Optativus** | **3. sg.** | रुन्ध्यात्[[br]]ru-n-dh-yā-t | रुन्धीत[[br]]ru-n-dh-ī-ta |
| | **3. pl.** | रुन्ध्युर्[[br]]ru-n-dh-y-ur | रुन्धीरन्[[br]]ru-n-dh-ī-ran |
| **Participium Praesentis** | | रुन्धन्त्-[[br]]ru-n-dh-ant-[[br]]fem.: रुन्धती[[br]]ru-n-dh-at-ī | |

::::

:::: grammar-box
**In nonnullis radicibus, -n- stemmat praesentis debilis, etiam in temporibus extra praesens intravit, ita ut haec radices cum infixu nasali constituendae sint.**
::::

Exemplum:

**भञ्ज्** 7P "frangere"

::: indent
*   Indicativus Praesentis
    *   3.sg.P. **भनक्ति** (bha-na + j + ti)
    *   3.pl.P. **भञ्जन्ति** (bha + n + j-anti)
*   Futurum: **भङ्क्ष्यति** (bha + n + j + sya + ti)
*   Passivum: **भज्यते** (sive ex radice originali **भज्** sive ex *bhñj-ya-te)
*   PPP: **भग्न** (fortasse ex *bhñj + na)
:::

## 31.2. Lexicon verborum

**युज्** 7U **युनक्ति** : iungere, iugum imponere, intendere, firmare; Ā quoque: intendere (= se exercere), coniungere cum, intendere ad (Locativus, सप्तमी)
::: indent
**Fut. योक्ष्यति**
**Pass. युज्यते**
**Kaus. योजयति**
**PPP युक्त**
**Inf. योक्तुम्**

unde:
**युग n. -&gt; युग n.:** iugum, par, aetas mundi (sunt quattuor aetates mundi:
1. **कृत**
2. **त्रेता**
3. **द्वापर**
4. **कलि**

**कलियुग** incepit circa annum 3102 a.C.n., anno belli **महाभारत**. De his rebus amplius apud Basham, Mirabilia p. 323)

**योग m.:** "iugatio, intentio", exercitatio, coniunctio, Yoga (vide ad hoc Basham, Mirabilia pp. 327 seq.)
