# Lekcja 12


## 12.1. Imiesłów Przeszły Bierny (PPP)

Jednym ze sposobów tworzenia zdań biernych w czasie przeszłym jest konstrukcja z tzw. Imiesłowem Przeszłym Biernym (PPP).

::: grammar-box
**W rzeczywistości PPP nie jest prawdziwym imiesłowem, ponieważ nie tworzy się go od tematu czasownikowego. Jest raczej formą nominalną utworzoną od rdzenia z sufiksem pierwotnym -ta lub -na. Dlatego w gramatyce indyjskiej mówi się o sufiksie kta.**
:::

### 12.1.1. Schemat dla czasowników przechodnich

::: grammar-box
**Agent (kartṛ) w narzędniku (tṛtīyā) -- bezpośredni obiekt (karman) w mianowniku (prathamā) -- Imiesłów Przeszły Bierny**

W tym przypadku PPP zgadza się z obiektem pod względem liczby, przypadka i rodzaju.

Czasownik posiłkowy („być“) nie jest konieczny.

Przykłady:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = „(Ojcem niebios został osiągnięty przez świętego) = Święty osiągnął niebiosa.“
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = „(Bóstwo zostało uczczone przez brahmana ofiarą) = Brahman uczcił bóstwo ofiarą.“
:::

### 12.1.2. Schemat I dla czasowników nieprzechodnich i czasowników ruchu

::: grammar-box
**Agent (kartṛ) w mianowniku (prathamā) -- Imiesłów Przeszły Bierny**

W tym przypadku PPP zgadza się z agentem pod względem liczby, przypadka i rodzaju. Imiesłów Przeszły „bierny“ ma w przypadku czasowników nieprzechodnich (czasowników bez bezpośredniego obiektu) i czasownikach ruchu znaczenie czynne.

Przykład:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = „Żona kszatrija poszła do miasta.“
:::

### 12.1.3. Schemat II dla czasów nieprzechodnich i czasów ruchu

::: grammar-box
**Agens (kartṛ) w narzędniku (tṛtīyā) -- PPP w mianowniku liczby pojedynczej rodzaju nijakiego**

Przykład:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(Przez Kṣatriyę) (do miasta) poszlo” = „Kṣatriya (poszedł do miasta).”

Konstrukcja według Schematu II jest znacznie rzadsza niż konstrukcja według Schematu I.
:::

## 12.2. Znaczenie PPP

Podczas gdy tzw. „Imiesłów przymiotny czasu przeszłego biernego” dla czasów przechodnich ma przede wszystkim znaczenie bierne (**āpta** = „osiągnięte (zostało)”), a dla czasów nieprzechodnich i czasów ruchu znaczenie czynne (**gata** = „poszedł”), istnieją niektóre czasowniki, u których PPP może mieć zarówno znaczenie czynne, jak i bierne:

np.
**gata** = ⟪गत⟫ = „poszedł” (czynne); ale też: **gato mārgaḥ** = ⟪गतो मार्गः⟫ = „przejściowa ścieżka” (biernie)
**āpta** = ⟪आप्त⟫ = „osiągnięte (zostało)” (biernie), „osiągający” (czynne)


## 12.3. Tworzenie PPP

::: grammar-box
Występują następujące sposoby tworzenia (każdy rdzeń należy zapamiętać wraz ze swoim PPP!):

**(zwykle) rdzeń w stopniu niskim**

**+ -ta**
z samogłoską łączną **-i-** przed: **-ita**
bez samogłoski łącznej: **-ta**
**+ -na**

Formy żeńskie brzmią: **-tā**, **-itā**, **-nā**; rodzaj nijaki odmienia się jak **phala** n.
:::

### 12.3.1. PPP na -ta (kta)

#### 12.3.1.1. Bez samogłoski łącznej -i- (aniṭ)

*aniṭ* = „bez (*an-*) przedrostka (*-i-*) *t*” (tj. bez samogłoski łącznej *i*).

::: grammar-box
Bezpiecznik bez spójnika tworzy się generalnie od rdzeni kończących się samogłoską oraz wielu innych rdzeni, bez podania ścisłej reguły dotyczącej tego, przy jak ustrukturyzowanych rdzeniach występuje lub nie występuje spójnik.

Lista rdzeni *aniṭ* znajduje się u Kielhorn, *Grammatik* § 298.
:::
**Przykłady:**

::: grammar-box
| Rdzeń | PPP (kta) |
| :--- | :--- |
| **bhū** 1 P:br(⟪भू⟫) | **bhū-ta** :br(⟪भूत⟫) |
| **smṛ** 1 P:br(⟪स्मृ⟫) | **smṛ-ta** :br(⟪स्मृत⟫) |
| **nṛt** 4 P:br(nṛt-ta):br(⟪नृत्त⟫) | **nṛt-ta** :br(⟪नृत्त⟫) |
| **nī** 1 U:br(⟪नी⟫) | **nī-ta** :br(⟪नीत⟫) |
| **man** 4 Ā:br(⟪मन्⟫) | **ma-ta** (\*mn-ta):br(⟪मत⟫) |
| **su** 5 U:br(⟪सु⟫) | **su-ta** :br(⟪सुत⟫) |

#### 12.3.1.2. Ze spójnikiem -i- (seṭ)

*seṭ* = *sa-iṭ* = „z (*sa-*) przedrostkowym (*-i-*) *t*” (czyli ze spójnikiem *i*).

**Przykłady:**

::: grammar-box
| Rdzeń | PPP (kta) |
| :--- | :--- |
| **kup** 4 P:br(⟪कुप्⟫) | **kup-i-ta** :br(⟪कुपित⟫) |
| **khād** 1 P:br(⟪खाद्⟫) | **khād-i-ta** :br(⟪खादित⟫) |

| **vad** 1 P:br(⟪वद्⟫) | **ud-i-ta** (\< \*vd-i-ta):br(⟪उदित⟫) |
:::

## 12.4. Prawa połączeń fonetycznych w słowie

Przy formacjach z *aniṭ* należy uwzględnić następujące prawa łączenia dźwięków w słowie. **Prawa te są bardzo ważne dla zrozumienia całej sanskryckiej morfologii.**

::: no-header
| | |
| :--- | :--- |
| **1. k, t, p przed bezdźwięcznym spółgłoską zwartą (np. t, th) pozostają bez zmian:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct zastępowane jest przez kt = ⟪क्त्⟫:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt zastępowane jest przez ṣṭ = ⟪ष्ट्⟫:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. Zwarty dźwięczny nieaspirowany – z wyjątkiem j – przed bezdźwięcznym dźwiękiem zastępowany jest odpowiadającym mu bezdźwięcznym nieaspirowanym dźwiękiem:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (ważne dla 2. klasy czasownika) |
| **5. jt zastępowane jest przez kt lub ṣṭ (nie opcjonalnie!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. Zwarty dźwięczny aspirowany + bezdźwięczny zwarty » zwarty dźwięczny nieaspirowany + zwarty dźwięczny aspirowany (prawo aspiracji Bartholomaeusa):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t zastępowane jest przez ḍh z wydłużeniem poprzedzającego i lub u; albo przez gdh. Przed takim ḍh a zastępowane jest przez o, rzadziej przez ā:** | **dah + ta » dag-dha** = ⟪दग्ध⟫ :br **guh + ta » gūḍha** = ⟪गूढ⟫ (guh 1 (gūhati) „ukrywać coś”):br **muh + ta » mug-dha / mūḍha** = **⟪मुग्ध⟫ / ⟪मूढ⟫** :br **sah + ta » soḍha** = ⟪सोढ⟫ |
:::

## 12.5. Słownik haseł

**api** ⟪अपि⟫ : także (postpozycyjnie)

Do szóstej klasy czasownikowej indyjni gramatyki zaliczają niektóre rdzenie, które tworzą temat czasu teraźniejszego za pomocą infixu nosowego i samogłoski tematu a, np.:

**muc** 6 U (muñcati), PPP **mukta** ⟪मुच् मुञ्चति मुक्त⟫ : uwalniać, puszczać na wolność; wyzwalać z cyklu odrodzeń (**saṃsāra** m.) = zbawiać
**sic** 6 U (siñcati), PPP **sikta** ⟪सिच् सिञ्चति सिक्त⟫ : oblwać

**budh**: **bodhi** m./f. ⟪बोधि⟫ : przebudzenie (dzięki któremu Budda lub Dżina dochodzi do zbawczego zrozumienia)
