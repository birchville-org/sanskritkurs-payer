# Lekcja 25

## 25.1. Tworzenie ablativu (⟪पञ्चमी⟫ = "piąta końcówka przypadkowa")

::: grammar-box
Z wyjątkiem rodzajnika męskiego i nijakiego na -a oraz zaimków, w liczbie pojedynczej we wszystkich klasach deklinacyjnych formy ablativu (⟪पञ्चमी⟫) są identyczne z formami genetywu (⟪षष्ठी⟫).

Z wyjątkiem zaimków osobowych, we wszystkich deklinacjach w liczbie mnogiej formy ablativu są identyczne z formami dativu (⟪चतुर्थी⟫).
:::
Teraz rozpoznajesz powód kolejności przypadków (⟪विभक्ति⟩) w sanskrycie: są one ułożone tak, aby identyczne formy znajdowały się jak najbliżej siebie – lub jedna pod drugą.

::: grammar-box
**Ablativ liczby pojedynczej rodzajnika męskiego / nijakiego na -a**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Zaimki pytające, względne i wskazujące:

::: grammar-box

| | Ablativ liczby pojedynczej:brrodzaj męski / nijaki | Ablativ liczby pojedynczej:brrodzaj żeński |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Użycie ablativu (⟪पञ्चमी⟫)

"Ablativ oznacza to, co pozostaje stałe, gdy coś z niego odchodzi."

Pāṇini 2,3,28 + 1,4,24

Ablativ występuje przede wszystkim na pytania "Skąd?", "Dlaczego?".

::: grammar-box
1\. Ablativ oznacza więc punkt wyjścia, pochodzenie i materiał.

Ablativ może więc oznaczać osobę, od której kupujemy, słyszymy, życzymy sobie itp.
:::
Przykłady:

::: indent
⟪ग्रमादागच्छति⟫ = "On przychodzi z wioski"

⟪अश्वात्पतितः⟫ = "spadł z konia"

⟪तेभ्यो लब्धम्⟫ = "otrzymano od nich (stamtąd)"
:::
Przykłady:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "on słyszy od nauczyciela o dhammie"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "brahman życzy sobie od kṣatriyi krowy mlecznej"
:::
::: grammar-box
2\. Ablativ występuje przy czasownikach o znaczeniach "powstrzymywać od", "chronić przed", "bronić przeciwko", "bać się":
:::
Przykład:

::: indent
⟪अरिभ्यो रक्षति⟫ = "chroni przed wrogami"
:::
::: grammar-box
3\. Ablativ oznacza przyczynę lub powód:
:::
Przykłady:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "Zabija swojego syna ze złości"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "Ponieważ uczynił zło, trafia do piekła" (« Ponieważ jest kimś, przez kogo dokonano zła)

⟪पापकरणान्नरकं गच्छति⟫ = "Ponieważ czyni / dokonał zła, trafia do piekła"
:::
Rzeczowniki, które nie są rodzaju żeńskiego, mogą dla oznaczenia przyczyny czynności wystąpić w narzędniku (⟪तृतीया⟫) lub ablatywie (⟪पञ्चमी⟫). Rzeczowniki rodzaju żeńskiego w tym znaczeniu zwykle występują w narzędniku, ale mogą czasami również stać w ablatywie.

## 25.3. Suffix -⟪तस्⟫

::: grammar-box
Jeśli chcemy w liczbie pojedynczej (wyraźnie) wyrazić, że słowo jest użyte w znaczeniu ablatywnym, można do rdzenia słowa dodać suffix -⟪तस्⟫, który tworzy przysłówki o przeważnie ablatywnym znaczeniu (na pytanie "Skąd?"):
:::
Przykłady:

::: indent
⟪आदितस्⟫ = "od początku"

⟪धर्मतस्⟫ = "ze względu na dharma, z powodu dharmy"
:::
::: grammar-box
Przyrostek -⟪तस्⟫ występuje również na rdzeniach zaimek:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) "stamtąd, tam, tamtędy, na tym, następnie, dlatego"

⟪यद्⟫ : ⟪यतस्⟫ "od którego, z czego, skąd, gdzie, dokąd, dlaczego, ponieważ" (relatywny)

⟪किम्⟫ :  ⟪कुतस्⟫ "skąd?" "dlaczego?"
:::
## 25.4. Inne sposoby wyrażania uzasadnień

::: grammar-box
**1\. Zdania względne**

Zdania względne często wyrażają przyczynową (uzasadniającą), konsekwencyjną (wynikającą) lub finalną (celową) relację do zdania głównego.

Formy zaimka względnego, które służą jako spójnik przyczynowy:

*   ablatywnie:
*   ⟪यतस्⟫ ... zdanie podrzędne ... ⟪ततस्⟫ ... zdanie główne ... = "ponieważ ..., dlatego ..."
*   ⟪यस्मात्⟫ ... zdanie podrzędne ... ⟪तस्मात्⟫ ... zdanie główne ... = "ponieważ ..., dlatego ..."
*   instrumentalnie:
*   ⟪येन⟫ ... zdanie podrzędne ... ⟪तेन⟫ ... zdanie główne ... = "poprzez/ponieważ ..., dzięki temu / dlatego ..."
:::
Przykład:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = "Ponieważ Rāma pragnie dobrobytu, praktykuje on ślub"
:::
::: grammar-box
**2\. ⟪हि⟫**

Zdania główne można łączyć za pomocą cząstki ⟪हि⟫ "gdyż, ponieważ". Zdanie z ⟪हि⟫ (które nie może stać na pierwszym miejscu, ale w prozie musi stać na drugim miejscu) podaje uzasadnienie albo dla poprzedniego zdania, albo dla następującego po nim zdania:
:::
Przykład:

::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "Ludzie czynią zasługę. Chociaż chcą bowiem wejść do nieba."
:::
::: grammar-box
**3\. Narzędnik (⟪तृतीया⟫)**

Oprócz ablativu (⟪पञ्चमी⟫) narzędnik (⟪तृतीया⟫) służy do wyrażenia powodu lub przyczyny. W przypadku rzeczowników żeńskich narzędnik jest ogólnie obowiązkowy.
:::
Przykład:

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = "Zabija swego syna ze złości" = "Zabija swego synu w gniewie"
:::
::: grammar-box
**4\. Rzeczowniki**

Poza tym oczywiście można również wyrazić uzasadnienie poprzez konstrukcje z

*   ⟪कारण⟫ n. "przyczyna": ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ m.
*   inne rzeczowniki w znaczeniu "przyczyna"

\+ dopełniacz (⟪षष्ठी⟫) lub jako drugi człon złożenia:
:::
Przykład:

::: indent
⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ itd.) = "ze względu na zasługę"
:::
::: grammar-box
**5\. ⟪इति⟫**

Motyw działania można podać jako myśl z ⟪इति⟫:
:::
Przykład:

::: indent
⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫  = "Ponieważ Sugata całkowicie obudził się do prawdy, Ānanda pyta Gautamę o jego naukę" (« "Myśląc: 'Sugata całkowicie obudził się do prawdy' ..."
:::
