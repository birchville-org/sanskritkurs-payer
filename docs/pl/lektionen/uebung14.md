# Ćwiczenie 14

Przetłumacz następujące przysłowia i zapamiętaj je na pamięć:

⟪निचो वदति न कुरुते वदति न साधुः करोत्येव ॥१॥⟫  
Nędzny człowiek nie mówi i nie postępuje; dobry człowiek nie mówi, lecz działa.

⟪शीलं नरस्य भूषणम् ॥२॥⟫  
Cnota jest ozdobą człowieka.

⟪सत्येन जनानां सुखं भवति ॥३॥⟫  
Prawda przynosi ludziom szczęście.

⟪पापा नराः स्वर्गं न लभन्ते ॥४॥⟫  
Zli ludzie nie dostaną się do nieba.

⟪सत्यं लोकस्य दीपः ॥५॥⟫  
Prawda jest światłem świata.

A) Utwórz dopełniacz liczby pojedynczej i mnogiej do następujących słów. Podaj znaczenie i rodzaj rzeczowników:

⟪१⟫. ⟪अनृत⟫ : n. nieprawda — ⟪अनृतस्य अनृतानाम् २⟫. ⟪ऋषि⟫ : m. wedyjski mędrzec — ⟪ऋषेः ऋषीणाम् ३⟫. ⟪पाद⟫ : m. stopa — ⟪पादस्य पादानाम् ४⟫. ⟪बुद्धि⟫ : f. wiedza — ⟪बुद्धेः⟩ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम् ५⟫. ⟪गुरु⟫ : m. mistrz — ⟪गुरोः गुरूणाम् ६⟫. ⟪स्वर्ग⟫ : m. niebo — ⟪स्वर्गस्य स्वर्गाणाम् ७⟫. ⟪नगर⟫ : n. miasto — ⟪नगरस्य नगराणाम् ८⟫. ⟪धेनु⟫ : f. krowa — ⟪धेनोः⟫ (⟪धेन्वाः⟫) ⟪धेनूनाम् ९⟫. ⟪द्विज⟫ : m. dwurodzony — ⟪द्विजस्य द्विजानाम् १०⟫. ⟪मुक्ता⟫ : f. wyzwolona — ⟪मुक्तायाः मुक्तानाम् ११⟫. ⟪विद्या⟫ : f. wiedza, nauka — ⟪विद्यायाः विद्यानाम् १२⟫. ⟪वर्ण⟫ : m. stan — ⟪वर्णस्य वर्णानाम् १३⟫. ⟪द्विजाति⟫ : 3 dwurodzony — ⟪द्विजातेः⟫ (⟪द्विजात्याः⟫) ⟪द्विजातीनाम् १४⟫. ⟪रूप⟫ : n. forma — ⟪रूपस्य रूपाणाम् १५⟫. ⟪प्रतिग्रह⟫ : m. przyjmowanie — ⟪प्रतिग्रहस्य प्रतिग्रहाणाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 ertragen — ⟪सोढस्य⟫ ⟪सोढायाः⟫ ⟪सोढानाम्⟫

⟪१७⟫. ⟪नायिका⟫ : f. Geliebte — ⟪नायिकायाः⟫ ⟪नयिकानाम्⟫

⟪१८⟫. ⟪साध्वी⟫ : f. Heilige — ⟪साध्व्याः⟫ ⟪साध्वीनाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 znosić — ⟪सोढस्य सोढायाः सोढानाम् १७⟫. ⟪नायिका⟫ : f. ukochana — ⟪नायिकायाः नयिकानाम् १८⟫. ⟪साध्वी⟫ : f. święta — ⟪साध्व्याः साध्वीनाम् १९⟫. ⟪अग्नि⟫ : m. ogień — ⟪अग्नेः अग्नीनाम् २०⟫. ⟪वैश्या⟫ : f. kobieta z varny vaiśja — ⟪वैश्यायाः वैश्यानाम् २१⟫. ⟪लोक⟫ : m. świat, ludzie — ⟪लोकस्य लोकानाम् २२⟫. ⟪उक्ति⟫ : f. wypowiedź — ⟪उक्तेः⟫ (⟪उक्त्याः⟫) ⟪उक्तीनाम् २३⟫. ⟪शत्रु⟫ : m. wróg — ⟪शत्रोः शत्रूणाम् २४⟫. ⟪सुखवन्त्⟫ : 3 szczęśliwy — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : f. kobieta z jednym lub więcej synami — ⟪पुत्रवत्याः पुत्रवतीनाम् २६⟫. ⟪जल⟫ : n. woda — ⟪जलस्य जलानाम् २७⟫. ⟪मार्ग⟫ : m. droga — ⟪मर्गस्य मर्गाणाम् २८⟫. ⟪मोक्ष⟫ : m. wyzwolenie, odkupienie — ⟪मोक्षस्य मोक्षाणाम् २९⟫. ⟪शूद्रा⟫ : f. kobieta z varny śūdra — ⟪शूद्रायाः शूद्राणाम् ३०⟫. ⟪अन्न⟫ : n. pokarm, jedzenie — ⟪अन्नस्य अन्नानाम् ३१⟫. ⟪साधु⟫ : m. święty — ⟪साधोः साधनाम् ३२⟫. ⟪नीति⟫ : f. prowadzenie — ⟪नीत्याः नीतीनाम् ३३⟫. ⟪योध⟫ : m. wojownik, żołnierz — ⟪योधस्य योधानाम् ३४⟫. ⟪सत्यवन्त्⟫ : 3 prawdziwy — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : m. zysk — ⟪लाभस्य लाभानाम् ३६⟫. ⟪मोह⟫ : m. zamieszanie, oślepienie — ⟪मोहस्य मोहानाम् ३७⟫. ⟪गति⟫ : f. chód, cel — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम् ३८⟫. ⟪प्रश्न⟫ : m. pytanie — ⟪प्रश्नस्य प्रश्नानाम् ३९⟫. ⟪सृष्टि⟫ : f. stworzenie — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम् ४०⟫. ⟪नेत्र⟫ : n. oko — ⟪नेत्रस्य नेत्राणाम् ४१⟫. ⟪गुरुता⟫ : f. mistrzostwo — ⟪गुरुतायाः गुरुतानाम्⟫

⟪४६⟫. ⟪युद्ध⟫ : 3 zwalczać — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम् ४७⟫. ⟪दर्शन⟫ : n. Widzenie, zjawisko — ⟪दर्शनस्य दर्शनानाम् ४८⟫. ⟪धातु⟫ : m. Element, rdzeń czasownikowy — ⟪धातोः धातूनाम् ४९⟫. ⟪गूढा⟫ : f. Ukryta — ⟪गूढायाः गूढानाम् ५०⟫. ⟪ईष्टा⟫ (2 znaczenia): f. Żądana, Ofiarowana — ⟪इष्टायाः इष्टानाम् ५१⟫. ⟪उदित⟫ : 3 mówić — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम् ५२⟫. ⟪इदम्⟫ : 3 ten — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 co — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) Przetłumacz:

⟪१⟫. ⟪ब्राह्मणस्य पुत्रो ब्राह्मण्या ग्रामं गतः ।⟫ (2 możliwości)
Syn bráhmana poszedł do wioski bráhmanī. Syn bráhmana poszedł z bráhmáną do wioski.

⟪२⟫. ⟪यज्ञस्याग्निनान्नं दग्धम् ।⟫
Ogień ofiarny spalił pokarm.

⟪३⟫. ⟪बुद्धः स्तयस्य बुद्ध्या मुक्तः ।⟫
Buddyta został wyzwolony przez poznanie prawdy.

⟪४⟫. ⟪अधर्मो ऽनृतस्य वदनमित्यृषयो वदन्ति ।⟫
Mądrzy wedyjscy mówią, że kłamstwo jest nieprawością.

⟪५⟫. ⟪नरा देवानां यज्ञैर्न मुच्यन्ते ।⟫
Ludzie nie zostają wyzwoleni przez ofiary składane bogom.

⟪६⟫. ⟪बलवन्तः क्षत्रियाः शत्रूणां धनवन्ति नगराणि जयन्ति ।⟫
Potężni kṣatriyas podbijają bogate miasta wrogów.

⟪७⟫. ⟪कवेरुक्तिं शृण्वन्ति ।⟫
Słyszycie słowa poety.

⟪८⟫. ⟪कविर्देव्याः कृतं वद⟫ti ⟪।⟫
Poeta opowiada o czynie bogini.

⟪९⟫. ⟪द्विजाः पशोर्लाभमिच्छन्ति ।⟫
Dwurodzeni pragną otrzymać bydło.

⟪१०⟫. ⟪रामः पुण्यवतो गुरोर्मन्त्रस्य स्मरति ।⟫
Rāma przypomina sobie mantra cnotliwego mistrza.

⟪११⟫. ⟪अयं बालः कस्याः पुत्रः ।⟫
Czyj (f.) syn jest to chłopiec?

⟪१२⟫. ⟪केषामिमानि गृहाणि ।⟫
Czyim należą te domy?

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम् ।⟫
Czyje jedzenie ofiarował ten wiedycki mędrczy?
