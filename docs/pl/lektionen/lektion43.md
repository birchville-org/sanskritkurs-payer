# Lekcja 43

## 43.1. Końcówki osobowe drugiej osoby (⟪मध्यमः⟫ = "osoba środkowa")

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Końcówki pierwotne** | -si | -tha | -se | -dhve |
| **Końcówki wtórne** | -s | -ta | -thās | -dhvam |
| **Końcówki perfektu** | -tha | -a | -se | -dhve |
:::
Należy zauważyć, że końcówka wtórna drugiej osoby liczby mnogiej jest identyczna z końcówką wtórną trzeciej osoby liczby pojedynczej trybu oznajmującego.

## 43.2. Tworzenie form czasownikowych drugiej osoby (⟪मध्यमः⟫)

Druga osoba:

*   Liczba pojedyncza: "ty"
*   Liczba mnoga: "wy" (więcej niż dwie osoby!)

## 43.3. Zaimki osobowe drugiej osoby

*   Liczba pojedyncza: ⟪त्वद्⟫ "ty"
*   Liczba mnoga: ⟪युष्मद्⟫ "wy"

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम् त्वा⟫ | ⟪युष्मान् वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम् ते⟫ | ⟪युष्मभ्यम् वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪तव ते⟫ | ⟪युष्माकम् वस्⟫ |
| ⟪सप्तमी⟫ | ⟪त्वयि⟫ | ⟪युष्मासु⟫ |
:::
Formy ⟪त्वा⟫, ⟪ते⟫, ⟪वस्⟫ nie mogą być używane na początku zdania lub półwersu. Nie można ich również stosować przed ⟪च⟫, ⟪वा⟫, ⟪एव⟫ i niektórymi innymi partykułami:

::: indent
⟪त्वां मां च⟫ "ciebie i mnie"
:::
