## 41.2. Dalsze ⟪कृत्⟫-tworzenia na -a

### 41.2.1. Imiesłów czasu teraźniejszego (⟪लडादेशः⟫) Ā, imiesłów czasu teraźniejszego (⟪लडादेशः⟫) Bierny, imiesłów czasu przyszłego (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Tematyczne rdzenie czasu teraźniejszego, Bierny i Przeszły

::: grammar-box
**Tworzenie:**

Rdzeń czasu teraźniejszego / rdzeń Bierny / rdzeń Przeszły + -māna (żeń. mānā)
:::
Przykłady:

⟪यज्⟫ 1U, Imiesł. czasu ter. Ā ⟪यजमान⟫ 3 "ten, który czci ofiarą we własnym interesie = pan ofiary"

⟪मन्⟫ 4Ā, Imiesł. czasu ter. Ā  ⟪मन्यमान⟫ 3 "myślący"

⟪कृ⟫ 8U, Imiesł. czasu ter. Bierny ⟪क्रियमाण⟫ 3 "to, co jest robione"

⟪दा⟫ 3U, Imiesł. czasu prz. Ā ⟪दास्यमान⟫ 3 "ten, który da we własnym interesie"

#### 41.2.1.2. Atematyczne klasy czasu teraźniejszego

::: grammar-box
**Tworzenie:**

Słaby rdzeń czasu teraźniejszego (w formie, jaką ma przed końcówką -ate 3.os.lic.mn. Ā) + -āna (żeń. -ānā)
:::
Przykłady:

::: grammar-box
| Rdzeń / Klasa | Imiesł. czasu ter. Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | ⟪जुह्वान⟫:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:brru-n-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brtan-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:brkrī + n-āna |
:::
### 41.2.2. "Participium" biernego koniecznego (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Aby wyrazić bierny konieczny ("to, co musi być zrobione/miałoby zostać zrobione"), można tworzyć przymiotniki od rdzeni i pochodnych pni czasownikowych, wybierając spośród następujących przyrostków:**

* **-⟪तव्य⟫** (żeń. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (żeń. **-⟪अनीया⟫**)
* **-⟪य⟫** (żeń. **-⟪या⟫**)
* **-⟪त्य⟫** (żeń. **-⟪त्या⟫**) (zamiast **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Przyrostek -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Przyrostek -⟪तव्य⟫ / -⟪तव्या⟫ jest dołączany do rdzeni i pochodnych pni czasownikowych (np. kauzatywu) w ten sam sposób, co przyrostek infinitywny -⟪तुम्⟫ (por. [Lekcja 23](lektion23.md)), tzn.**

* **stopa wzmacniona rdzenia + ⟪तव्य⟫**

lub

* **stopa wzmacniona rdzenia + -i- + ⟪तव्य⟫**

**W kauzatywie:**

* **pień kauzatywny na -ay + -i- + ⟪तव्य⟫**
:::
Przykłady:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1Os. | ⟪जेतव्य⟫ 3 | "ten, kto musi być pokonany; ten do pokonania" |
| ⟪वृत्⟫ 1Os. | ⟪वर्तितव्य⟫ 3 | "to, gdzie należy się znajdować" |
| ⟪बुध्⟫ Kauz. | ⟪बोधयितव्य⟫ | "ten, kto musi zostać obudzony; ten do wybudzenia" |

:::
#### 41.2.2.2. Przyrostek -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Tworzenie:**

Stopa wzmacniona rdzenia + -⟪अनीय⟫ / -⟪अनीया⟫

**Kauzatyw i 10. klasa czasownika:**

Rdzeń, w formie występującej w pniu kauzatywnym, bez -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Przykłady:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "do podania; to, co musi być dane" |
| ⟪जि⟫ 1Os. | ⟪जयनीय⟫ 3 | "ten do pokonania" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "do zrobienia" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "to, co należy zobaczyć; godne zobaczenia" |
| ⟪बुध्⟫ Kauz. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "ten do wybudzenia" |
| ⟪दा⟫ Kauz. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "to, co należy sprawić, by podano" |

:::
#### 41.2.2.3. Sufiks -⟪य⟫ / -⟪या⟫

::: grammar-box
**Tworzenie:**

Korzeń (w stopniu niskim, wysokim lub wzmożonym) + -⟪य⟩

Dokładne reguły zob. w Kielhorn, Gramatyka języka sanskryckiego, s. 195 - 197!
:::
Postępowanie z samogłoskami końcowymi:

::: grammar-box
**1. Korzenie na -ā tworzą to gerundiwum na -eya**
:::
Przykłady:

::: no-header

| | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "to, co należy znać; to, co musi zostać poznane" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "to, co należy dać" |

:::
::: grammar-box
**2. Korzenie na -i /-ī / -u / -ū /-ṛ mają zazwyczaj stopień wysoki lub wzmożony, chyba że należą do tych korzeni na -i / -u /-ṛ, które tworzą gerundiwum z sufiksem -⟪त्य⟫ (żeń. -⟪त्या⟫) (lista tych korzeni u Kielhorn, Gramatyka §537).**
:::
Przykład:

::: no-header

| | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 | "w czym należy pamiętać" |

:::
::: grammar-box
**2a. Korzenie na -i/-ī mają stopień wysoki**
:::
Przykłady:

#### 41.2.2.4. Suffix -⟪त्य⟫ / ⟪त्या⟫ (zamiast -⟪य⟫ / -⟪या⟫)

::: grammar-box
Lista rdzeni kończących się na -i / -u /-ṛ, które tworzą gerundiw nie z użyciem -⟪य⟫ / -⟪या⟫, lecz z użyciem suffixu -⟪त्य⟫ (żeń. -⟪त्या⟫), zob. u Kielhorna, Gramatyka §537.

**Tworzenie:**

rdzeń w stopniu niskim + -⟪त्य⟫ / -⟪त्या⟫
:::
Przykłady:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "ten, który należy iść" |
|  ⟪श्रु⟫ 5P |  ⟪श्रुत्य⟫ 3 | "ten, który należy słyszeć" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "ten, który należy czynić" |

:::
### 41.2.3. Syntaktyka "participium" biernego przymusu (gerundivum) (⟪कृत्य⟫)

::: grammar-box
Gerundivum może być użyte atrybutowo:

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = "miasto, które trzeba zobaczyć; miasto warte zobaczenia"
:::
Gerundivum może być również użyte jako orzecznik w zdaniach z konstrukcją bierną, wyrażających obowiązek lub rozkaz (z ⟪न⟫ zakaz, niemożliwość):

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = "Dwurodzeni muszą zobaczyć Benares"
:::

### 41.2.4. Różnice w użyciu sufiksów gerundivum

::: grammar-box
Zastosowanie tych sufiksów w dużej mierze się pokrywa.

* **-⟪तव्य⟫ (żeń. -⟪तव्या⟫):** zawsze wyraża konieczność i jest preferowane w użyciu orzecznikowym (rzadziej atrybutywnym). Tworzenia z tym sufiksem nie należy używać w złożeniach nominalnych.
* **-⟪अनीय⟫ (żeń. -⟪अनीया⟫) oraz -⟪य⟫ (żeń. -⟪या⟫) / -⟪त्य⟫ (żeń. -⟪त्या⟫) (zamiast -⟪य⟫/-⟪या⟫):** mogą mieć dodatkowe znaczenie (zwłaszcza -⟪य⟫) w niemieckim odpowiedniku "-wert" (np. "warte zobaczenia") lub tylko możliwości "-bar" (⟪दृश्य⟫ "widoczny"). Tworzenia z tymi sufiksami mogą być przeczone przez ⟪अ⟫-/-⟪अन्⟫- (nie można jednak przeczyć tworzeń z -⟪तव्य⟫) i występują jako końcowe człony w ⟪तत्पुरुष⟫.
:::
### 41.2.5. Brak połączenia z ⟪सु⟫- i ⟪दुस्⟫-

::: grammar-box
Z gerundivum nie należy łączyć ⟪सु⟫- i ⟪दुस्⟫- w znaczeniu "łatwo" lub "trudno". Zamiast tego występują ⟪तत्पुरुष⟫ typu  ⟪सुकर⟫ 3 ("łatwy do zrobienia") (zob. [Lekcja 18](lektion18.md)).
:::
