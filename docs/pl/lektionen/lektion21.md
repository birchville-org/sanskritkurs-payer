# Lekcja 21

## 21.1. Dalsze tematy czasu teraźniejszego na -nt

### 21.1.1. Imiesłów czasu teraźniejszego (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
Ten imiesłów jest formą nominalną utworzoną z tematu czasu teraźniejszego, czyli prawdziwym imiesłowem. Jest to przymiotnik wskazujący, że ktoś lub coś właśnie wykonuje czynność wyrażoną przez rdzeń czasownikowy (+ przedrostek), podczas gdy dzieje się coś innego. Można nim również wyrazić stan trwały.

**Przykłady:**

:::
::: indent
"Gdy ojciec czyta, pali papierosa = czytający ojciec pali"  
"przyjaciel będący (= prawdziwy, rzeczywisty)"
:::
::: grammar-box

| **Tworzenie imiesłowu czasu teraźniejszego Parasmaipada dla tematycznych tematów czasu teraźniejszego:** |||
| :--- | :--- | :--- |
| **Męski, nijaki** | | |
| | **Silny temat** | Temat czasu teraźniejszego + **-nt-** |
| | **Słaby temat** | Temat czasu teraźniejszego + **-t-** |
| **Żeński** | | |
| | | Temat czasu teraźniejszego + **-nt-** + **-ī** (deklinacja jak **devī** :br⟪देवी⟫) |
| | **6. klasa czasu teraźniejszego** | Temat czasu teraźniejszego + **-nt-** + **-ī** :broder::brTemat czasu teraźniejszego + **-t-** + **-ī** |

:::

## 21.3. Grzecznościowe formy zwrotu

::: grammar-box
**W sanskrycie można zwracać się do kogoś w drugiej osobie liczby pojedynczej, nie będąc niegrzecznym. Jeśli jednak chcemy być uprzejmi, możemy użyć rzeczownika oznaczającego "Czcigodny" i podobnie, a czasownik postawić w trzeciej osobie liczby pojedynczej lub mnogiej, albo użyć konstrukcji biernych. Stopniowanie uprzejmości w użyciu osoby przy zwrocie jest mniej więcej następujące:**

:::
::: indent
**2. lm » 2. mn » 3. lm z odpowiednim rzeczownikiem » 3. mn z odp. rzeczownikiem**
:::
**Najważniejszym takim rzeczownikiem grzecznościowym jest ⟪भवन्त्⟫ , rodzaj żeński: ⟪भवती⟫ . Odpowiada on naszemu grzecznościowemu "Pan/Pani".**
To ⟪भवन्त्⟫ jest skróceniem z ⟪भगवन्त्⟫, jego deklinacja to deklination rzeczowników na **-vant** (zobacz [Lekcja 13](lektion13.md)). To ⟪भवन्त्⟫ należy odróżnić od imiesłowu czasu teraźniejszego P od ⟪भू⟫ "stać się" ⟪भवन्त्⟫ : dopełniacz liczby pojedynczej rodzaju męskiego od ⟪भवन्त्⟫ "Pan/Pani" brzmi ⟪भवान्⟫, a imiesłowu ⟪भवन्⟫.

**Przykłady:**

::: indent
**⟪किं भवान्करोति⟫** = **⟪किं भवता क्रियते⟫** = "Co Pan robi?"
:::
grzecznościowy:

::: indent
**⟪किं भवन्तः कुर्वन्ति⟫** = **⟪किं भवद्भिः क्रियते⟫**
:::
rodzaj żeński:

::: indent
**⟪किं भवती करोति⟫** = **⟪किं भवत्या क्रियते⟫**
**⟪किं भवत्यः कुर्वन्ति⟫** = **⟪किं भवतीभिः क्रियते⟫**
:::
Inne słowa, które można używać podobnie jak ⟪भवन्त्⟫:

*   ⟪आर्य⟫ (rodz. żeń.: ⟪आर्या⟫) "Szlachetny". Np. **⟪यदार्य इच्छति⟫** "Czego Pan życzy"
*   ⟪महाभाग⟫ "ten, którego udział/szczęście jest wielki = Szlachetny". Często używane przez kobiety w zwrotach lub przy mówieniu o mężczyznach dobrego rodu. W współczesnym języku mówionym sanskrycie bardzo częste.

Jeśli chce się wyrazić nie tylko grzeczność, ale także czcigodny szacunek dla kogoś, używa się ⟪भवन्त् अत्रभवन्त्⟫ wobec osoby obecnej lub w pobliżu, a ⟪तत्रभवन्त्⟫ wobec osoby nieobecnej lub oddalonej. ⟪अत्रभवन्त्⟫ i ⟪तत्रभवन्त्⟫ można przetłumaczyć jako "Pan/Pani", "Wielmożny", "Ekscelencja" itp.:

::: indent
**⟪किमत्रभवत्यत्रभवतां भार्या⟫** = "Czy ta szanowna (obecna tu) pani jest Państwa małżonką?"
**⟪किं तत्रभवतां कुशलवृत्तम्⟫** (w liście lub rozmowie telefonicznej) = "Czy się Pan/Pani ma dobrze?"
:::
