# Lekcja 10

## 10.1. Zdanie bierne (passyw)

::: grammar-box
**Schemat:**
**(Agens - kartṛ - w narzędniku (tṛtīyā)) - (bezpośredni obiekt - karman - w mianowniku) - forma czasownikowa bierna**

np. **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "Brahman czci boga ofiarą" (dosłownie: "Bóg jest czczony przez brahmana ofiarą.")

To zdanie jest **zupełnie (!) równoznaczne znaczeniowo** z zdaniem:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
W zdaniu biernym agens (**kartṛ**) występuje w **narzędniku** (tṛtīyā f. "trzecia końcówka przypadkowa"), a bezpośredni obiekt (**karman** n.) w **mianowniku** (prathamā f.).
Zdania bierne, w których agens nie jest określony, mają zwykle znaczenie bezosobowe ("się"):
np. **ijyate** = ⟪इज्यते⟫ "Ofiaruje się" (dosłownie: "czci się ofiarą").
:::

::: grammar-box
**Nawet jeśli odpowiadające mu zdanie czynne zawierałoby biernik (dvitīyā) kierunku, może on w zdaniu biernym wystąpić w mianowniku (prathamā):**

Zdanu czynnemu **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "Rāma idzie do wioski" odpowiadają zdania bierne:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
alternatywnie: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**Czasowniki nieprzechodnie (bez bezpośredniego obiektu) często tworzą konstrukcje bierne, zwłaszcza w uprzejmych rozkazach:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "Niech ktoś wejdzie = Proszę wejść = Wchodzić!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "Niech ktoś usiądzie = Proszę usiąść = Proszę zająć miejsce"
:::
Konstrukcje bierne sanskryckie są wyjątkowo częste: bierna jest przecież łatwiejsza do utworzenia niż np. liczne tematy teraźniejszego czasu.

::: important
**Zdania bierne w sanskrycie ogólnie nie należy oddawać w języku niemieckim za pomocą zdania biernego, ponieważ niemiecki bierny ma zupełnie inną funkcję stylistyczną.**
:::

### 10.2.1. O użyciu narzędnika (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**Narzędnik (tṛtīyā) odpowiada głównie na pytania:**
**Czym?**
**Z kim?**
**Z czym?**

**Stosuje się go**
1. **w zdaniach biernych: Agens (kartṛ) w narzędniku**
2. **do określenia środka lub narzędzia, za pomocą którego coś się dokonuje**
3. **do określenia drogi, którą ktoś dociera do celu**
4. **do wyrażenia połączenia, zjednoczenia, towarzystwa**
5. **przy przyimkach w znaczeniu "wraz z, z"; np. saha = ⟪सह⟫ = "z"** :brnp.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "wraz z Brahmaninem"
:::
Kolejne zastosowania narzędnika (tṛtīyā) pojawią się później.


## 10.3. Tzw. prawo cerebraalizacji dla -n- (sandhi wyrazowy)

::: grammar-box
**-n-**, któremu towarzyszy samogłoska lub **n, m, y, v**, zastępowane jest przez **-ṇ-**, jeśli w wyrazie przed **-n-** występuje **ṛ, ṝ, r, ṣ** lub jeśli między tymi dźwiękami a następującym **-n-** w wyrazie nie ma żadnego innego głosu niż samogłoski, guturale, labiale, **y, v, h** lub anuswara.
:::
**Dlatego:**

::: grammar-box
| | L. poj. |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**W ten sposób wyjaśnić można również -ṇ- w:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. Bierny, tryb oznajmujący czasu teraźniejszego (yak = ⟪यक्⟫)

::: grammar-box
**Tworzenie:**
**(zwykle) stopień głęboki rdzenia + -ya- + końcówka Ātmanepada**
:::
np.

| Rdzeń:br⟪धातु⟫ | 3. lm. Bierny. Czas. ter.:br⟪यक् लट्⟫ | 3. lm. Bierny. Czas. ter.:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"on jest prowadzony" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"on jest myślany" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"on jest wchodzony" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Należy pamiętać, że w czasownikach czwartej klasy obecnej formy Atmanepady i biernego są identyczne! W takim przypadku można rozstrzygnąć, czy mamy do czynienia z Atmanepadą, czy biernym, wyłącznie na podstawie konstrukcji zdania.**



### 10.4.1. Zasady szczególne dotyczące tworzenia strony biernéj

1. **Korzenie kończące się na -i lub -u** przed sufiksem biernym **-ya-** wydłużają swój samogłoskę:
* **ji** 1 os.: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 os.: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 os.: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Korzenie z -a- między spółgłoskami** (z wyjątkiem nosowych, y, r, v) pozostają w stopniu wysokim:
* **labh** 1 At.: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Niektóre korzenie tworzą swoją formę bierną w stopniu wysokim** (lub w stopniu ablautu tematu prezentowego):
* **āp** 5 os.: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 os.: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 os.: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Stopień niski czasowników zaczynających się na ya, va, ra lub takich, w których te dźwięki występują po innej spółgłosce (Samprasāraṇa = ⟪सम्प्रसारण⟩):**

| Korzeń:br⟪धातु⟫ | Stopień niski:br⟪सम्प्रसारण⟫ | Forma bierna:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 At.:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 os.:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 os.:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

Tradycyjną rodzimą nazwą dla tej formacji na poziomie głębokim w czasownikach z **ya** lub **va** jest **Samprasāraṇa** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **Końcowe -ṛ** po pojedynczej spółgłosce przed sufiksem biernym **-ya-** zastępowane jest przez **-ri-**:
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* Ale: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **Niektóre rdzenie na -an mają alternatywnie dwie formacje tematu biernego:**
* **-an-ya**
* **-ā-ya-** (długie **ā** jest reprezentantem hipotetycznego długiego nosowego)

np. **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (z \*tn-ya-nte)

  W sprawie życia miejskiego i wiejskiego zob. Basham, *Wonder*, rozdz. 6.

**yajña** m. ⟪यज्ञ⟫ : ofiara

  ::: note-box
  Ofiara w Indiach jest przede wszystkim czczeniem bóstwa jako gościa. W ten sposób zobowiązuje się ono do bóstwa.
