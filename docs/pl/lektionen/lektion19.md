# Lekcja 19

## 19.1. Zdanie względne

::: grammar-box

**Schemat:**


**Zaimek względny -- zdanie względne, które określa rzeczownik, na który się odnosi -- (zaimek wskazujący) -- zdanie główne**

**Zdanie względne może również wystąpić po zdaniu głównym, ale nie można go wtrącać do wnętrza zdania głównego.**

**Zaimek względny oraz słowo odniesienia, które – w przeciwieństwie do języka niemieckiego – znajduje się w zdaniu względnym, występują w przypadku wymaganym syntaktycznie przez zdanie względne. Zaimek wskazujący występuje w przypadku wymaganym syntaktycznie przez zdanie główne.**
:::

Przykłady:

Uwaga: W zdaniach względnych o charakterze ogólnym chętnie stosuje się tryb przypuszczający (optativ) zamiast oznajmującego (indikativ). Większość naszych przykładów byłaby więc preferowana w trybie przypuszczającym.

**1. Agens (⟪कर्तृ⟫) zdania jest bliżej określony przez zdanie względne:**

::: indent
⟪यो नरः पुण्यं करोति स स्वर्गं गच्छति⟫ =  ⟪यो नरः पुण्यं करोति तेन स्वर्गं गम्यते⟫ = ⟪येन नरेण पुण्यम् क्रियते तेन स्वर्गं गम्यते⟫ itd. = "Mężczyzna, który dokonuje zasługujących na pochwałę czynów, trafia do nieba."
:::
**2. Biernik (⟪कर्म⟫) zdania głównego jest bliżej określony przez zdanie względne:**

::: indent
⟪यो ब्राह्मणो देवान्यजते तं देवा रक्षन्ति⟫ = "Bogowie chronią brāhmaṇa, który składa im ofiarę jako gospodarz rytuału."
:::
**3. Określenie bliższe rzeczownika w zdaniu głównym znajduje się w zdaniu względnym:**

::: indent
⟪ये नराः पापं कुर्वन्ति तेषां पुत्रा धनं न लभन्ते⟫ = "Synowie mężczyzn, którzy dokonują złych czynów, nie odziedziczą bogactwa."
:::
**4. Zaimek względny i rzeczownik odniesienia występują w dopełniaczu (⟪षष्ठी⟫):**

::: indent
⟪यस्य नरस्य पुत्राः पापं कुर्वन्ति स न सुखवान्⟫ = "Mężczyzna nie jest szczęśliwy, którego synowie czynią zło."
:::
**5. Zaimek względny i rzeczownik odniesienia występują w narzędniku (⟪तृतीया⟫):**

::: indent
⟪येन शत्रुणा ग्रामो जितस्तं द्विषन्ति⟫ = "Nienawidzą wroga, który pokonał / zdobył ich wieś."
:::
**6. Zaimek względny i rzeczownik odniesienia występują w bierniku (⟪द्वितीया⟫):**

::: indent
⟪यं नरं देवी रक्षति स सुखमाप्नोति⟫ = "Mężczyzna, którego chroni bogini, osiąga szczęście."
:::
## 19.2. Zaimek względny = ⟪व्यपेक्षकसर्वनाम⟫ n.

::: grammar-box

**⟪यद्⟫ "który, która, które" odmienia się jak ⟪तद्⟫, ale z regularnym sandhi.**

| | **Rodzaj męski** :br ⟪पुंस्⟫ | **Rodzaj nijaki** :br ⟪नपुंसक⟫ | **Rodzaj żeński** :br ⟪स्त्री⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **Liczba pojedyncza** :br ⟪एकवचन⟫ | **1. Mianownik** :br ⟪प्रथमा⟫ | **yas** :br ⟪यस्⟫ | **yad** :br ⟪यद्⟫ | **yā** :br ⟪या⟫ |
| | **2. Biernik** :br ⟪द्वितीया⟫ | **yam** :br ⟪यम्⟫ | **yad** :br ⟪यद्⟫ | **yām** :br ⟪याम्⟫ |
| | **3. Narzędnik** :br ⟪तृतीया⟫ | **yena** :br ⟪येन⟫ | **yena** :br ⟪येन⟫ | **yayā** :br ⟪यया⟫ |
| | **6. Dopełniacz** :br ⟪षष्ठी⟫ | **yasya** :br ⟪यस्य⟫ | **yasya** :br ⟪यस्य⟫ | **yasyās** :br ⟪यस्यास्⟫ |
| **Liczba mnoga** :br ⟪बहुवचन⟫ | **1. Mianownik** :br ⟪प्रथमा⟫ | **ye** :br ⟪ये⟫ | **yāni** :br ⟪यानि⟫ | **yās** :br ⟪यास्⟫ |
| | **2. Biernik** :br ⟪द्वितीया⟫ | **yān** :br ⟪यान्⟫ | **yāni** :br ⟪यानि⟫ | **yās** :br ⟪यास्⟫ |
| | **3. Narzędnik** :br ⟪तृतीया⟫ | **yais** :br ⟪यैस्⟫ | **yais** :br ⟪यैस्⟫ | **yābhis** :br ⟪याभिस्⟫ |
| | **6. Dopełniacz** :br ⟪षष्ठी⟫ | **yeṣām** :br ⟪येषाम्⟫ | **yeṣām** :br ⟪येषाम्⟫ | **yāsām** :br ⟪यासाम्⟫ |

**Jako przedmiot składowy w złożeniach występuje rdzeń ⟪यद्⟫ (z uwzględnieniem sandhi).**

:::

## 19.4. Ćwiczenie

**Przetłumacz na sanskryt:**

1. Żona Vaiśji, której syn zmarł, płacze.

2. Rāma składa ofiarę bogu, który go strzeże.

3. Poeta chwali Kṣatriję, którego bogactwa pragnie.

4. Ogień spala dom mężczyzny, który nie czci Agni ofiarą.

5. Mężczyzna podobny do tygrysa zabija wojowników Kṣatrijów, którzy zostali pokonani przez Rāmę (Biernik).
