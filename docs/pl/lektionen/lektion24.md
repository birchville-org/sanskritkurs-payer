# Lekcja 24

## 24.1. Celownik (⟪चतुर्थी⟫ = "czwarta końcówka przypadkowa")

::: grammar-box
**1. Aby oddać cel lub zamiar ("aby") działania, można zamiast bezokolicznika (⟪तुमुन्⟫) użyć rzeczownika z sufiksem kṛt, który oznacza czynność lub stan, w celowniku (⟪चतुर्थी⟫ = "czwarta końcówka przypadkowa").**

Przykład:

zamiast:

:::
::: indent
⟪रामो गुरुवचनं श्रोतुं गतः ।⟫
:::
można też powiedzieć:

::: indent
⟪रामो गुरुवचनस्य श्रवणाय गतः ।⟫

lub:

⟪रामो गुरुवचनश्रवणाय गतः ।⟫
:::
= "Rāma poszedł, aby wysłuchać wykładu nauczyciela."
::: media
![](/images/lekt2404.webp)
Ilustracja: ⟪बाला गुरुश्रवणाय गताः⟫
(Źródło obrazu: [Szczegóły](/pl/licenses#lekt2404))
:::

::: grammar-box
**2. Celownik (⟪चतुर्थी⟫) może również oznaczać obiekt bezokolicznika celu, który należy uzupełnić:**

Przykład:

:::
::: indent
⟪फलेभ्यो ग्रामं गच्छति⟫ = "Idzie do wioski z celem zebrania owoców = Idzie do wioski, aby położyć owoce."
:::
**W ten sam sposób celownik (⟪चतुर्थी⟫) oznacza cel rzeczy lub czynności:**

Przykład:

::: indent
⟪यज्ञायान्नम्⟫ = "Jedzenie z celem ofiary = Jedzenie na ofiarę"
:::

:::

::: grammar-box
**3. Celownik (⟪चतुर्थी⟫) oznacza również osobę lub rzecz, dla których obiekt czynności jest przeznaczony (celownik pośredni; pytanie: komu?). (Należy jednak pamiętać o czasownikach z podwójnym biernikiem (⟪द्वितीया⟫)!)**

Przykład:

:::
::: indent
⟪रामाय फलं ददाति⟫ = "On daje Ramie owoc." (Rdzeń ⟪दा⟫ 3. klasa czasu teraźniejszego)

::: grammar-box
**4. Celownik występuje przy niektórych czasownikach (i innych słowach) podobnie jak w języku niemieckim na pytanie "komu?":**

Przykłady:

:::
::: indent
⟪क्रुध्⟫ : ⟪देवो नरेभ्यो क्रुध्यति⟫ = "Bóg gniewa się na ludzi."

⟪अलम्⟫ Przysłówek: "wystarczająco, odpowiednio, dorównujący": ⟪अलं योधो योधाय⟫ = "wojownik jest dorównujący innemu wojownikowi"

## 24.2. Tworzenie celownika (⟪चतुर्थी⟫)

::: grammar-box
**Regularne końcówki celownika to:**

* **Liczba pojedyncza: -e; żeńskie tematy samogłoskowe: -ai**
* **Liczba mnoga: Celownik i Ablativ ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. Tematy spółgłoskowe

::: grammar-box

| | Celownik liczby pojedynczej | Celownik liczby mnogiej |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. Zaime pytające

::: grammar-box

| | Rod męski / nijaki | Rod żeński |
| :--- | :--- | :--- |
| **Dativ liczby pojedynczej** | ⟪कस्मै⟫ | ⟪कस्यै⟫ |
| **Dativ liczby mnogiej** | ⟪केभ्यस्⟫ | ⟪काभ्यस्⟫ |

:::
### 24.2.3. Zaimki wskazujące

::: grammar-box

| | | ⟪तद्⟫ | ⟪एतद्⟫ | ⟪इदम्⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **Rod męski / nijaki** | **Dat. sg.** | ⟪तस्मै⟫ | ⟪एतस्मै⟫ | ⟪अस्मै⟫ |
| | **Dat. pl.** | ⟪तेभ्यस्⟫ | ⟪एतेभ्यस्⟫ | ⟪एभ्यस्⟫ |
| **Rod żeński** | **Dat. sg.** | ⟪तस्यै⟫ | ⟪एतस्यै⟫ | ⟪अस्यै⟫ |
| | **Dat. pl.** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::
### 24.2.4. Tematy samogłoskowe

::: grammar-box
**Tematy samogłoskowe**

* **Rod męski / nijaki na -a:** ⟪देव⟫
* Dat. sg. ⟪देवाय⟫
* Dat. pl. ⟪देवेभ्यस्⟫
* **Rod męski na -i:** ⟪कवि⟫
* Dat. sg. ⟪कवये⟫
* Dat. pl. ⟪कविभ्यस्⟫
* **Rod męski na -u:** ⟪पशु⟫
* Dat. sg. ⟪पशवे⟫
* Dat. pl. ⟪पशुभ्यस्⟫
* **Rod żeński na -ā:** ⟪देवता⟫
* Dat. sg. ⟪देवतायै⟫
* Dat. pl. ⟪देवताभ्यस्⟫
* **Rod żeński na -ī:** ⟪देवी⟫
* Dat. sg. ⟪देव्यै⟫
* Dat. pl. ⟪देवीभ्यस्⟫
* **Rod żeński na -i:** ⟪श्रुति⟫
* Dat. sg. ⟪श्रुतये⟫ lub ⟪श्रुत्यै⟫ (tj. jak ⟪कवि⟫ lub jak ⟪देवी⟫)
* Dat. pl. ⟪श्रुतिभ्यस्⟫
* **Rod żeński na -u:** ⟪धेनु⟫
* Dat. sg. ⟪धेनवे⟫ lub ⟪धेन्वै⟫
* Dat. pl. ⟪धेनुभ्यस्⟫

Przykład:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा अग्नये⟫ = "temu ogniu"
:::
## 24.4. Słownik

⟪अलम्⟫ Przysłówek: wystarczająco, dostatecznie; (z kimś, czymś) równy sytuacji ; z celownikiem: wystarczająco dla, dostatecznie dla; z narzędnikiem: dość z, odstąp od , np. ⟪अलं क्रोधेन⟫ = "dosyć gniewu = odstąp od gniewu!"
