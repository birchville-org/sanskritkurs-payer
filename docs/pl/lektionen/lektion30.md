# Lekcja 30

## 30.1. Dziewiąta klasa czasu teraźniejszego (⟪क्र्यादि⟫ = "⟪क्री⟫ itd.")

::: grammar-box
**Tworzenie:**

*   silny stem: stopa głęboka + -nā-

*   słaby stem:

*   przed spółgłoską: stopa głęboka + -nī-

*   przed samogłoską: stopa głęboka + -n-
:::
Przykład:

::: indent
⟪क्री⟫ 9U "kupować"
:::
::: grammar-box

| |Singular:br⟪एकवचन⟫|Plural:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3. Osoba:brParasmaipada**|⟪क्रीणाति⟫:br(krī + nā + ti)|⟪क्रीणन्ति⟫:br(krī + n + anti)|
|**3. Osoba:brĀtmanepada**|⟪क्रीणीते⟫:br(krī + nī + te)|⟪क्रीणते⟫:br(krī + n + ate)|

:::
W tej klasie czasu teraźniejszego należy szczególnie zwrócić uwagę na tworzenie tematu czasu teraźniejszego od rdzenia ⟪ज्ञा⟫ 9U "rozpoznawać, wiedzieć":

::: grammar-box

| |Singular:br⟪एकवचन⟫|Plural:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3. Osoba:brParasmaipada**|⟪जानाति⟫:br(jā-nā-ti)|⟪जानन्ति⟫:br(jā-n-anti)|
|**3. Osoba:brĀtmanepada**|⟪जानीते⟫:br(jā-nī-te)|⟪जानते⟫:br(jā-n-ate)|

:::
Forma ⟪जा⟫, która leży u podstaw tematu czasu teraźniejszego ⟪ज्ञा⟫, może być wyjaśniona albo przez szereg ablautowy -ā (stopa głęboka) -nā (stopa wysoka), albo przez dissimilację z *jñā-nā-ti.

Niektóre rdzenie na długą samogłoskę skracają ją przed sufiksem tematu czasu teraźniejszego dziewiątej klasy:

Przykład:

::: indent
⟪पू⟫ 9U "oczyszczać"
:::
::: grammar-box

| |Singular:br⟪एकवचन⟫|Plural:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3. Osoba:brParasmaipada**|⟪पुनाति⟫:br(pu-nā-ti)|⟪पुनन्ति⟫:br(pu-n-anti)|
|**3. Osoba:brĀtmanepada**|⟪पुनीते⟫:br(pu-nī-te)|⟪पुनते⟫:br(pu-n-ate)|

:::
Tworzenie imiesłowu czasu teraźniejszego Parasmaipada:

Przykład:

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant) ; żeń.: ⟪क्रीणती⟫ (krī + n + at + ī)
:::
## 30.2. Użycie trybu łączącego (⟪लिङ्⟫)

Tryb łączący jest używany:

::: grammar-box
**1. do wyrażenia**

*   **życzenia**
*   **prośby**
*   **zmiękczonego rozkazu**

**(w tym przypadku tryb łączący - ⟪लिङ्⟫ - pokrywa się z trybem rozkazującym - ⟪लोट्⟫)**
:::
Przykład:

::: indent
⟪दासो ग्राममागच्छेत्⟫ = "Niewolnik niech przyjdzie do wioski"
:::
::: grammar-box
**2. Gdy coś ma być**

*   **możliwe**
*   **prawdopodobne**
*   **przypuszczalne**

**przedstawione.**
:::
Przykład:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं न शृणुयात्⟫ = "Gdyby wyszedł z wioski, nie usłyszałby mistrza"
:::
::: grammar-box
**3. Zdania względne z trybem łączącym mają czasem znaczenie: "Gdyby ktoś ..."**
:::
Przykład:

::: indent
⟪यो नृतं वदेत्स नरकं पतेत्⟫ = "Gdyby ktoś powiedział nieprawdę, wpadłby do piekła = Jeśli ktoś mówi nieprawdę, wpada do piekła"
:::
## 30.3. Końcówki wtórne dla trzeciej osoby liczby pojedynczej i mnogiej

Tryb łączący (⟪लिङ्⟫), imperfekt (⟪लङ्⟫), aoryst (⟪लुङ्⟫), prekativ i kondycjonalis mają tzw. końcówki wtórne:

::: grammar-box

| |3. osoba liczby pojedynczej|3. osoba liczby mnogiej|
| :--- | :--- | :--- |
|**Parasmaipada**|**-t**|klasy atematyczne: **-an** lub **-ur** :brOptativ: **-ur**|
|**Ātmanepada**|**-ta**|klasy atematyczne: **-ata** (z *nta):brOptativ: **-ran**|

:::

## 30.5. Sandhi wygłosowego -r

::: grammar-box
**Poza przypadkiem -ar, do wygłosowego -r stosuje się te same reguły sandhi co do wygłosowego -s.**

**-ar przed dźwięcznymi spółgłoskami pozostaje -ar, ale przed r- końcowe -r znika, a -a zastępowane jest przez -ā.**
:::
Przykłady:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना रोदिति⟫
:::

⟪जना आर्यसत्यानि जानीयुरिति सुगतेनार्याणां सुखाय जना धर्मं ज्ञाप्यन्ते ॥१॥ ये नरा देवान्न यजेरन्व्रतानि च न चरेयुरनृतं च वदेयुरधर्मं च कुर्युस्ते सुखं नाप्नुयुर्मृत्वा च नरकं पतेयुः ॥२॥ ज्ञातिरागच्छेतितीष्ट्वार्यपुत्रो ज्ञातिं दासमाययति ॥३॥ अन्नलोभाद्दुःखं जायेतेति प्राप्तज्ञानः सुफलानि नाश्नाति ॥४॥ क्रयेण च विक्रयेण च वैश्या जीवेयुरिति वैश्यधर्मः । एवं सति वैश्यपुत्राः क्रीणन्ति विक्रीणते च ॥५॥ कृतपापो नरश्चेन्नरके पापात्पूतः स्यात्पुनर्भवं गच्छेत् ॥६॥ ब्राह्मणपुत्रा वेदाध्यायांश्च स्मृत्यध्यायांश्च पुनः पुनरधीयीरन्नित्यार्यधर्मः ॥७॥ यो ब्राह्मणः शूद्रां कामयेत स सद्ब्राह्मणो न स्यात् । सद्ब्राह्मणो हि ब्राह्मणीं कामयेत ॥८॥ सत्यं ब्रूयात्प्रियं ब्रूयान्न ब्रूयात्सत्यमप्रियम् । प्रियं च नानृतं ब्रूयादेष धर्मः सनातनः ॥९॥ ॥मनुस्मृति ४⟫.⟪१३८॥⟫
