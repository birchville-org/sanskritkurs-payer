# Lekcja 35

## 35.1. Perfekt Typ III: Silny rdzeń stopa podwyższona/stopa przedłużona

::: grammar-box
**Tworzenie:**

**silny rdzeń:**
*   3.os.l.P: stopa przedłużona
*   2.os.l.P: stopa podwyższona
*   1.os.l.P: opcjonalnie stopa podwyższona lub stopa przedłużona

**słaby rdzeń:** patrz podtypy
:::
### 35.1.1. Perfekt Typ IIIa: Silny rdzeń stopa podwyższona/stopa przedłużona, słaby rdzeń stopa obniżona

::: grammar-box
**Tworzenie:**

:::
::: indent
**słaby rdzeń:** stopa obniżona
:::
Tworzone od rdzeni typów:
*   (Spółgłoska)-(Spółgłoska) - i/ī/u/ū
*   (Spółgłoska) - ṛ

Przed końcówką zaczynającą się samogłoską następuje zastąpienie:
*   -i/-ī przez -iy
*   -u/-ū przez -uv
*   -ṛ przez r
Przykłady:


| Rdzeń | 3. os. Perf. P. | 3. lm. Perf. P. | 3. os. Perf. Ā. | 3. lm. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:brī + iy + ur | | |
| ⟪नी⟫ 1U | ⟪निनाय⟫ | ⟪निन्युर्⟫:brnī-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2U | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

### 35.1.2. Perfekt Typ IIIb: Silny rdzeń stopa podwyższona/stopa przedłużona, słaby rdzeń stopa podwyższona

## 35.2. Perfekt Typ IV: Korzenie na -ā / -āi

::: grammar-box
**Tworzenie:**

**silny rdzeń:**
*   3./1. os. l.poj. czasu Perfekt Tryb Oznajmujący kończy się na -au
*   2. os. l.poj. Tryb Oznajmujący: stopa wysoka -ā lub stopa niska -i

**słaby rdzeń:**
*   przed spółgłoską: stopa niska -i
*   przed samogłoską: stopa niska Ø

Tworzone od korzeni na -ā / -āi
:::
Przykład:


| Korzeń | 3. os. l.poj. Perfekt P.:br1. os. l.poj. Perfekt P. | 3. lm. Perfekt P. | 3. os. l.poj. Perfekt Biernik | 3. lm. Perfekt Biernik |
| :--- | :--- | :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪ददौ⟫ | ⟪ददुर्⟫:brda-d-ur | ⟪ददे⟫ | ⟪ददिरे⟫:brda-d-i-re |

## 35.3. Perfekt Typ V: Korzenie Konsonant-a-Konsonant

::: grammar-box
**Tworzenie:**

**silny rdzeń:**
*   3.os.P: stopa wydłużona
*   2.os.P: stopa wysoka
*   1.os.P: opcjonalnie stopa wysoka lub stopa wydłużona

**słaby rdzeń:** zobacz podtypy

Tworzone od korzeni typu (Konsonant)-Konsonant-a-Konsonant
:::
### 35.3.1. Perfekt Typ Va: słaby rdzeń stopa niska

::: grammar-box
**Tworzenie:**

:::
::: indent
**słaby rdzeń:** stopa niska
:::
Tworzone m.in. od korzeni:

### 35.3.2. Perfekt Typ Vb: słaby stem, kontrakcja (typ e)

::: grammar-box
**Tworzenie:**

:::
::: indent
**słaby stem:** brak reduplikacji. Zastąpienie -a- w korzeniu przez -e-
(dla wyjaśnienia zob. Thumb-Hauschild 1,2 s. 286n.)
:::
Tworzone od korzeni z -a- między dwoma prostymi spółgłoskami, których początkowa spółgłoska w sylabie reduplikacyjnej nie ulega zmianie (tzn. że ich początkowa spółgłoska nie jest guturalna, aspirata ani h).
Przykład:

| Korzeń | 3. lm. Perf. P. | 3. mn. Perf. P. | 3. lm. Perf. Ā. | 3. mn. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 1U | ⟪पपाच⟫ | :sig[⟪पे⟫]⟪चुर्⟫ | :sig[⟪पे⟫]⟪चे⟫ | :sig[⟪पे⟫]⟪चिरे⟫ |

### 35.3.3. Perfekt Typ Vc: Korzenie spółgłoska-a-spółgłoska. Słaby stem w stopniu pełnym

::: grammar-box
**Tworzenie:**

**słaby stem:** stopień pełny (guṇa)

Tworzone od wszystkich pozostałych korzeni ze środkowym -a-, tzn. korzenie ze środkowym -a-
*   które zaczynają się od dwóch spółgłosek
*   które zaczynają się od guturalnej
*   które zaczynają się od aspiraty
*   które zaczynają się od h

o ile nie należą do Perfekt Typ Va.
:::
Przykład:

| Korzeń | 3. lm. Perf. P. | 3. mn. Perf. P. | 3. lm. Perf. Ā. | 3. mn. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪क्रम्⟫ 1U | ⟪चक्राम⟫ | ⟪चक्रमुर्⟫ | ⟪चक्रमे⟫ | ⟪चक्रमिरे⟫ |
