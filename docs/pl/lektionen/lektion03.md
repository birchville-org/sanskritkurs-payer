# Lekcja 3

## 3.1. Mianownik liczby pojedynczej rodzaju żeńskiego

### 3.1.1. Mianownik liczby pojedynczej na -s

Następujące rdzenie rzeczowników, które kończą się samogłoską, tworzą mianownik liczby pojedynczej na **-s**:

::: grammar-box
**Rodzaj żeński na -i**: np. **śruti** f. "słuchanie" -- Mian. lp.: **śrutis** = ⟪श्रुतिस्⟫
**Rodzaj żeński na -u**: np. **dhenu** f. "krowa mleczna" -- Mian. lp.: **dhenus** = ⟪धेनुस्⟫
:::
### 3.1.2. Mianownik liczby pojedynczej bez końcówki

Mianownik liczby pojedynczej tworzy się bez końcówki:

::: grammar-box
**Rodzaj żeński na -ā**: np. **devatā** f. "bóstwo" -- Mian. lp.: **devatā** = ⟪देवता⟫
**Rodzaj żeński na -ī**: np. **devī** f. "bogini" -- Mian. lp.: **devī** = ⟪देवी⟫
:::
::: important
**Uwaga!** Istnieją również jednosylabiczne żeńskie rdzeniowe rzeczowniki na -ī, których mianownik liczby pojedynczej kończy się na -s: np. dhī f. "myśl" -- Mian. lp.: dhīs = ⟪धीस्⟫. Również lakṣmī (⟪लक्ष्मी⟫) f., tarī (⟪तरी⟫) f. "łódź" i tantrī (⟪तन्त्री⟫) f. "struna" tworzą nieregularnie mianownik liczby pojedynczej na -s: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::

## 3.2. Tworzenie rzeczowników żeńskich od męskich

::: grammar-box
**Rzeczowniki męskie na -a:**
**Rodzaj żeński na -ā**: np. **kṣatriya** m. » **kṣatriyā** f. "żona Kszatryja" = ⟪क्षत्रिया⟫
**Rodzaj żeński na -ī**: np. **brāhmaṇa** m. » **brāhmaṇī** f. "brahmanka" = ⟪ब्राह्मणी⟫

**Rzeczowniki męskie na -u:**
**Rodzaj żeński na -ī**: np. **sādhu** m. » **sādhvī** f. (dobra, święta) = ⟪साध्वी⟫
(**-u-** przed samogłoską zmienia się na **-v-**, stąd **-u- + -ī** » **-vī**)
:::

## 3.3. Mianownik liczby mnogiej rodzaju męskiego i żeńskiego

::: grammar-box
Końcówka mianownika liczby mnogiej w rodzaju męskim i żeńskim to **-as**.
**Rzeczowniki męskie na -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
**Rodzaj żeński na -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**Rzeczowniki męskie na -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**Rodzaj żeński na -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**Rodzaj żeński na -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**Rzeczowniki męskie na -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**Rodzaj żeński na -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::
Uwaga: **e** jest stopniem wzmacniającym (**guṇa**) wobec **i**, **o** jest stopniem wzmacniającym wobec **u**.


## 3.4. Sandhi samogłosek

::: grammar-box
**Proste samogłoski, które różnią się tylko długością lub wcale, „stopniują” do odpowiedniej długiej samogłoski:**
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)
:::
np.

devatā + annapūrṇā » devatānnapūrṇā „Annapūrṇā jest boginią” = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā jest boginią jedzenia i gotowania, uważana za wcielenie Pārvatī, małżonki Śiwy.)

devī + indrāṇī » devīndrāṇī „Indrāṇī jest boginią” = ⟪देवीन्द्राणी⟫

> (Indrāṇī jest małżonką boga Indry.)

::: grammar-box
**Proste samogłoski (z wyjątkiem -a / -ā) przed różnymi samogłoskami są zastępowane odpowiednią półsamogłoską:**
i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**
(!! Do tej reguły istnieją wyjątki, szczególnie w formach podwójnych !!)
:::
np.

devī + umā » devy umā „Umā jest boginią” = ⟪देव्युमा⟫

> (Umā to imię Pārvatī, małżonki Śiwy)

::: grammar-box
**-a / -ā przed różną samogłoską:**
a / -ā + i- / ī- » **-e-**
a / -ā + ṛ- » **-ar-**
a / -ā + e- / ai- » **-ai-**
a / -ā + o- / au- » **-au-**
:::

## 3.5. Sandhi zdaniowe -ās

::: grammar-box
**-ās przed wszystkimi dźwięcznymi spółgłoskami zastępowane jest przez -ā.**
:::
np.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Vaiśjowie są narodzeni ponownie" = ⟪द्विजा वैश्याः⟫


## 3.6. Słownictwo

**Zapamiętaj następujące słowa:**

**śruti** f. = ⟪श्रुति⟫ : słuchanie, wieczna tradycja (określenie na Wedy i Brāhmaṇy).

**smṛti** f. = ⟪स्मृति⟫ : uobecnienie, pamięć, medytacyjne uobecnienie = uważność, tradycja (przeciwieństwo do **śruti**). Obejmuje:
sześć **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): właściwa wymowa
2. **chandas** n. (⟪छन्दस्⟫): metrum
3. **vyākaraṇa** n. (⟪व्याकरण⟫): gramatyka
4. **nirukta** n. (⟪निरुक्त⟫) : wyjaśnienie słów, etymologia
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : astronomia, nauka o kalendarzu
6. **kalpa** m. (⟪कल्प⟫) : ceremoniał
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : traktaty dotyczące przeprowadzania wielkich ofiar
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : traktaty dotyczące ceremonii i ofiar z życia codziennego
**dharmasūtra** n. (⟪धर्मसूत्र⟫) i **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : traktaty dotyczące prawa i obyczajów (właściwego postępowania)
wielkie eposy **mahābhārata** n. (⟪महाभारत⟫) i **rāmāyaṇa** n. (⟪रामायण⟫)
**purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫) : traktaty o mądrości życiowej

**smṛti** jest szczególnie również określeniem na traktaty dotyczące dharma.

**dhenu** f. = ⟪धेनु⟫ : krowa (mleczna).

**paśu** m. = ⟪पशु⟫ : udomowione zwierzę gospodarskie, bydło (zbiór).

**devatā** f. = ⟪देवता⟫ : bóstwo (abstrakcyjne i konkretne).

**brāhmaṇī** f. = ⟪ब्राह्मणी⟫ : brāhmaṇī.

**kṣatriyā** f. = ⟪क्षत्रिया⟫ : kobieta kṣatriya.

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : żona kṣatriya.

**vaiśyā** f. = ⟪वैश्या⟫ : kobieta vaiśya.

**śūdrā** f. = ⟪शूद्रा⟫ : kobieta śūdra.

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : żona śūdry.

**devī** f. = ⟪देवी⟫ : bogini, zwłaszcza Durgā f. = ⟪दुर्गा⟫, małżonka Śiwy = ⟪शिव⟫.

::: media
![](/images/lekt0303.webp)
Ilustracja: Durgā = ⟪दुर्गा⟫, Orissa
(Źródło obrazu: [Szczegóły](/images/lekt0303))

**sādhvī** f. = ⟪साध्वी⟫ : forma żeńska od sādhu.

**gurvī** f. = ⟪गुर्वी⟫ : forma żeńska od guru.

**asmitā** f. = ⟪अस्मिता⟫ : "ja-owość", tj. (fałszywe) przekonanie: **Ja** jestem tym, który widzi itp.

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : filozofia (nauka dochodząca do wniosków poprzez logicznie poprawne uzasadnienia).

**upekṣā** f. = ⟪उपेक्षा⟫ : ignorowanie, obojętność.

**karuṇā** f. = ⟪करुणा⟫ : współczucie, litość.

**muditā** f. = ⟪मुदिता⟫ : radość, szczególnie współodczuwanie radosności (przeciwieństwo zazdrości).


## 3.7. Ćwiczenie

**A) Przekształć poniższe zdania w liczbę mnogą:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**B) Utwórz zdania nominalne przez uzupełnienie:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Przetłumacz na rodzaj żeński:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः साधुः⟫

**D) Przetłumacz na sanskryt:**

1. Umā jest boginią.
2. Weda to śruti.
3. Nauczycielki są boginiami.
4. Krowy mleczne to zwierzęta domowe.
5. Poeci są nauczycielami.
6. Kṣatriyas to dwurodzeni (dvija).
7. Święci mężczyźni to Śūdras.
