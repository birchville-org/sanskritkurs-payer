# Lekcja 33

## 33.1. Reduplikacja (⟪अभ्यास⟫ m.)

* Trzecia klasa czasów teraźniejszych
* (oraz niektóre czasowniki innych klas czasów teraźniejszych),
* czas przeszły doskonały (perfekt),
* aoryst z reduplikacją,
* frequentatyw i
* desideratyw

są tworzone za pomocą reduplikacji. Część zreduplikowanej formy, która umieszczana jest przed rdzeniem, nazywa się sylabą reduplikacyjną.

Sylaba reduplikacyjna składa się z (jednej spółgłoski i) samogłoski.

### 33.1.1. Spółgłoska reduplikacyjna

::: grammar-box
**1. Zazwyczaj:**  
**Powtórzenie pierwszej spółgłoski rdzenia**
:::
Przykłady:

::: indent
⟪दा⟫ 3 "dawać"
* 3.os.P.Ind.Ter. ⟪ददाति पॄ⟫ 3 "napełniać"
* 3.os.P.Ind.Ter. :sig[⟪पि⟫]⟪पर्ति मा⟫ 3Ā "mierzyć"
* 3.os.Ā.Ind.Ter. :sig[⟪मि⟫]⟪मीते⟫
:::
::: grammar-box
**2. Aspirowana spółgłoska początkowa rdzenia jest reduplikowana przez odpowiadającą jej nieaspirowaną spółgłoskę.**
:::
Przykłady:

::: indent
⟪धा⟫ 3 "sadzić"
* 3.os.P.Ind.Ter. ⟪दधाति भी⟫ 3 "bać się"
* 3.os.P.Ind.Ter. :sig[⟪बि⟫]⟪भेति⟫
:::
::: grammar-box
**3. Gutturale jest reduplikowana przez odpowiadającą jej nieaspirowaną palatalną:**

:::
::: indent
⟪क्⟫, ⟪ख्⟫ przez ⟪च् ग्⟫, ⟪घ्⟫ przez ⟪ज्⟫
:::
**⟪ह्⟫ jest zawsze reduplikowana przez ⟪ज्⟫.**
Przykłady:

::: indent
⟪हु⟫ 3 "lać (ofiarę) do ognia"
* 3.os.P.Ind.Ter. ⟪जुहोति⟫
:::
::: grammar-box
**4. Jeśli rdzeń zaczyna się od kilku spółgłosek, powtarzana jest tylko pierwsza (ewentualnie zgodnie z zasadami 2 lub 3).**
:::
::: grammar-box
**5. Jeśli rdzeń zaczyna się od grupy spółgłosek: zwarta + bezdźwięczna, nie jest reduplikowana spółgłoska zwarta, lecz następująca po niej bezdźwięczna spółgłoska zgodnie z powyższymi zasadami.**
:::
Przykład:

::: indent
⟪स्था⟫ 1 "stać"
* 3.os.Poziom.Ind.Ter.Przest. ⟪तिष्ठति⟫
:::
## 33.2. Trzecia klasa czasów teraźniejszych (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ itd.")

::: grammar-box
**Tworzenie:**

**Silny rdzeń:**  
**zreduplikowany rdzeń w stopniu wysokim + końcówka**

**Słaby rdzeń:**  
**zreduplikowany rdzeń w stopniu niskim + końcówka**

**Zasady dotyczące spółgłoski reduplikacyjnej są podane powyżej.**
:::
### 33.2.1. Samogłoska reduplikacyjna trzeciej klasy czasów teraźniejszych

::: grammar-box
* **Regularną samogłoską reduplikacyjną jest -i-**
* **Rdzenie zawierające u reduplikują się z -u-**
* **Rdzenie ⟪दा⟫, ⟪धा⟫, ⟪हा⟫ z -a-**
:::
Przykłady:

::: grammar-box
⟪हु⟫ 3os "(do ofiary) lać do ognia"

* **Silny rdzeń:** ⟪जुहो⟫
* **Słaby rdzeń:** ⟪जुहु⟫

| | 3. os. P. | 3. lm. P. | 3. os. Ā. | 3. lm. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| **Indyktyw czasu teraźniejszego** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | ⟪जुहुते⟫ | ⟪जुह्वते⟫:brjuhu + ate |
| **Imperfekt** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | ⟪अजुहुत⟫ | ⟪अजुह्वत⟫:bra-juhu + ata |
| **Optyw** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | ⟪जुह्वीत⟫:brjuhu + ī-ta | ⟪जुह्वीरन्⟫:brjuhu + ī-ran |
:::
## 33.3. Ablaut ā

ā kann

* z jednej strony może być stopniem rozciągniętym jednej z serii ablautowych z -a-
* z drugiej strony może być stopniem wysokim w serii ablautowej grupy ā

Dwie najważniejsze serie ablautowe grupy ā to:

::: grammar-box
**A.**

* **Stopień niski**
* **przed spółgłoską: -i-**  
np. ⟪धा⟫ PPP: ⟪हित⟫ (hi-ta)
* **przed samogłoską: Ø**  
np. ⟪धा⟫ 3lm.Poziom.Ind.Ter.Przest. ⟪दधति⟫ (dadh-ati)
* **Stopień wysoki: -ā-**  
np. ⟪धा⟫ 3os.Poziom.Ind.Ter.Przest. ⟪दधाति⟫
:::
Należą do nich np.:

::: indent
⟪स्था⟫ 1
* PPP ⟪स्थित⟫ (sthi-ta)
* 3.os.Fut. ⟪स्थास्यति⟫ (sthā-sya-ti)
:::
::: grammar-box
**B.**

* **Stopień głęboki: -ī-**  
np. ⟪पा⟫ 1: PPP ⟪पीत⟫ (pī-ta)
* **Stopień wysoki: -ā-**  
np. ⟪पा⟫ 1: Inf. ⟪पातुम्⟫
:::
## 33.4. Korzenie na -ā trzeciej klasy czasownikowej

::: grammar-box
**Korzenie na -ā (z wyjątkiem ⟪दा⟫ i ⟪धा⟫) w słabej formie zazwyczaj przybierają formę -ī-** (patrz Thumb-Hauschild, t. 1, s. 271. Prawdopodobnie wzorem dla tego zjawiska była powyżej wymieniona seria ablautu B, mimo że korzenie te inaczej podlegają serii A), **przed końcówkami samogłoskowymi samogłoska rdzeniowa znika całkowicie (patrz seria ablautu A).**
:::
Przykłady:

::: grammar-box
⟪मा⟫ 3Ā "mierzyć"

| | 3. os. Ā. | 3. lm. Ā. |
| :--- | :--- | :--- |
| **Indikativ Präsens** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Imperfekt** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Optativ** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
:::
::: grammar-box
⟪हा⟫ 3P "opuszczać"

| | 3. os. P. | 3. lm. P. |
| :--- | :--- | :--- |
| **Indikativ Präsens** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Imperfekt** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Optativ** | ⟪जह्यात्⟫:brjah-yā-t:br(Dla rdzenia ⟪हा⟫ przed Optativ-yā/y występuje ta sama forma, co przed samogłoskami!) | ⟪जह्युर्⟫:brjah-y-ur |
:::
### 33.4.1. Korzenie ⟪दा⟫ i ⟪धा⟫

::: grammar-box
**Korzenie ⟪दा⟫ i ⟪धा⟫ reduplikują się z samogłoską -a- i tracą w słabej formie samogłoskę rdzeniową.**

**Zwróć uwagę na zasadę dissimilacji aspiracyjnej w przypadku ⟪धा⟫!**
:::
::: grammar-box
⟪धा⟫ 3U "umieścić, ustalić, przydzielić"

| | 3. lm. O. | 3. lm. O. | 3. lm. B. | 3. lm. B. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Przeszły** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Objaśnienie: Thumb-Hauschild 1,1 s. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Imperfekt** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Optyw** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
:::
Formy ⟪दा⟫ otrzymuje się, zastępując w paradygmacie ⟪धा⟫ **dh** przez **d**. Czyli:

::: grammar-box
⟪दा⟫ 3U "dać"

| | 3. lm. O. | 3. lm. O. | 3. lm. B. | 3. lm. B. |
| :--- | :--- | :--- | :--- | :--- |
| **Indikativ Przeszły** | ⟪ददाति⟫ | ⟪ददति⟫ | ⟪दत्ते⟫ | ⟪ददते⟫ |
| **Imperfekt** | ⟪अददात्⟫ | ⟪अददुर्⟫ | ⟪अदत्त⟫ | ⟪अददत⟫ |
| **Optyw** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
:::

## 33.7. Ćwiczenie

A) W poniższym wzorze zdaniowym wstaw odpowiednie formy słów podanych w nawiasie:

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने बहुवचने च⟫) ... ⟪अन्नं ददाति ।⟫ (⟪भिक्षु । अग्नि । शूद्रा । गुनवान्पुत्र । देवान्स्तुवन्कवि । ब्राह्मणी । महान्साधु । धेनु⟫)

B) Wstaw odpowiednie formy czasowników podanych w nawiasach w trybie oznajmującym czasu teraźniejszego, niedokonanego i optywnym:

⟪ब्राह्मणो घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥ बुद्धगता भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥ सुगतः कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥ दुर्जना भिक्षुभ्यो ऽन्नं न⟫ ... (⟪दा⟫) ⟪॥४॥ साधुः कृष्णे मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो लोकान्⟫ ... ⟪जनास्तु न⟫ ... (⟪मा⟫) ⟪॥६॥ दासा भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥ ब्राह्मणी पात्रं जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫

C) Przetłumacz i przekształć zdania pojedyncze na mnogowe oraz odwrotnie:

⟪योगयुक्तो मतिं दुःखमक्षनयन्त्यां प्रज्ञायां समाधत्ते ॥१॥ यो भिक्षवे दानानि दद्यात्सो ऽपि दानपुण्यमाददीत ॥२॥ ब्राह्मणा भारं न बिभ्रतीति ब्राह्मणदासो भारं गृहमबिभः ॥३॥⟫
