# Lekcja 57

## 57.1. Aoryst 4: aoryst s-

::: grammar-box
**Aoryst s- jest tworzony do większości ⟪अनिट्⟫-rdzeni, o ile nie mają one wyłącznie innej formy aorystu. Fakultatywne ⟪अनिट्⟫-rdzenie mogą ogólnie tworzyć na wybór ten lub aoryst iṣ-. Także ⟪अनिट्⟫-rdzenie, które tworzą ⟪परस्मैपद⟫ po 1., 2. lub 6. formie aorystu, tworzą ⟪आत्मनेपद⟫ według aorystu s-.**

**Tworzenie: Augment + rdzeń + s + beztematowe końcówki wtórne**
:::
Tabela końcówek z sufiksem tworzącym temat

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟫** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟫** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**Stosuje się ogólną zasadę fonetyczną, że spółgłoska szumiąca między dwiema spółgłoskami zwartymi wypada (por. ⟪उद्⟩ + ⟪स्थित⟩ » ⟪उत्थित⟩), tzn. że sufiks tworzący temat -s- przed końcówkami zaczynającymi się na -t- lub -th- wypada (nie jednak po nosowych ani r-).**

Przykłady:

:::
::: indent
3.lg.Ā a-kṣip + s + ta » ⟪अ⟩:sig[⟪क्षिप्त⟩]
2.lg.Ā a-kṣip + s + thās » ⟪अ⟩:sig[⟪क्षिप्था⟩]⟪स्⟩
:::
Takie formy mogłyby należeć również do aorystu rdzeniowego i prawdopodobnie częściowo tam też należą.
Indyjscy gramatykowie zaliczyli również formy takie jak ⟪अकृत⟩ (3.lg.Ā) do aorystu s-, które jednoznacznie należą do aorystu rdzeniowego. W tym celu indyjscy gramatykowie wymyślili następującą ad-hoc zasadę fonetyczną dla aorystu s-:

::: indent
"Po krótkiej samogłosce końcówki zaczynające się od -st- lub -sth- tracą -s-."
:::
W pozostałych przypadkach należy stosować reguły fonetyczne dotyczące łączenia końcowych spółgłosek z s-.

Dla -dhvam obowiązuje:

::: grammar-box
**-dh- w -dhvam jest zastępowane przez -ḍh- po wszystkich samogłoskach innych niż a/ā, a także po -r.**

:::
::: indent
np. :sig[⟪चि⟫] 5U: 2.os.Ā :sig[⟪अचेढ्वम्⟫]
:::
::: grammar-box
**Forma rdzenia:**

*   **⟪परस्मैपद⟫ : stopień przedłużony**
*   **⟪आत्मनेपद⟫ :**
*   **Rdzenie z końcowym i/ī/u/ū: stopień wysoki**
*   **końcowe -ṝ jest zastępowane przez -īr lub -ūr**
*   **rdzenie podlegające ablautowi na ā/e/o: stopień niski**
*   **inne samogłoski rdzeniowe: bez zmian (tj. zazwyczaj w stopniu niskim)**
:::
Przykłady:

|   | **3.os.P** |
| --- | --- |
| ⟪चि⟫ 5U | ⟪अचैषीत्⟫ |
| ⟪श्रु⟫ 5P | ⟪अश्रौषीत्⟫ |
| ⟪कृ⟫ 8U | ⟪अकार्षीत्⟫ |
| ⟪भज्⟫ 1U | ⟪अभाक्षीत्⟫ |
| ⟪भञ्ज्⟫ 7P | ⟪अभाङ्क्षीत्⟫ |
| ⟪भुज्⟫ 7U | ⟪अभौक्षीत्⟫ |

|   | **3.os.Ā** |
| --- | --- |
| ⟪चि⟫ 5U | ⟪अचेष्ट⟫ |
| ⟪नी⟫ 1U | ⟪अनेष्ट⟫ |
| ⟪सू⟫ 2/4 | ⟪असोष्ट⟫ |
|   | **os.Ā** |
| ⟪दा⟫ 3U | ⟪अदिषि⟫:br ⟪अदिथास्⟫ :br ⟪अदित⟫ |
|   | **1.os.Ā** |
| ⟪कृ⟫ 8U | ⟪अकृषि⟫ |
| ⟪पच्⟫ 1U | ⟪अपक्षि⟫ |

::: grammar-box
**⟪दृश्⟫ i ⟪सृज्⟫ mają w ⟪परस्मैपद⟫ stopień przedłużony ze wzrastającym dyftongiem -rā-:**

:::
::: indent
⟪दृश्⟫ 3.os.P ⟪अ⟫:sig[⟪द्राक्षी⟫]⟪त्⟫
:::
Także aoryst innych rdzeni z -ṛ- na przedostatnim miejscu może być tworzony w ten sposób:

::: indent
⟪कृष्⟫ 1P/6U 3.os.P ⟪अकार्क्षीत्⟫ / ⟪अ⟫:sig[⟪क्राक्षी⟫]⟪त्⟫

**Formy nieregularne:**

**1. Korzenie na nosówkę (⟪गम्⟫, ⟪मन्⟫, ⟪रम्⟫) tworzą aoryst s-stopniowany w stopniu pełnym:**
**⟪अगंसि । अमंसि । अरंस्त⟫**
**Obok tego dla ⟪गम्⟫ występują regularne formy w stopniu zredukowanym:**
**⟪अगसि⟫ (« \*a-gm-si) ⟪। अगथास् । अगत⟫ (w P ⟪गम्⟫ ma aoryst tematykowy z samogłoską tematyczną)**

2. ⟪पद्⟫ 4Ā jest regularne (np. ⟪अपत्सि⟫), w 3.os.Ħ ma jednak formę aorystu korzeniowego biernego:
⟪अपादि⟫ "poszedł"

3. ⟪बुध्⟫ Ħ może w 3.os.Ħ przyjmować opcjonalnie formę aorystu korzeniowego biernego:
⟪अबोधि⟫ / ⟪अबुद्ध⟫ "rozpoznał"
:::
