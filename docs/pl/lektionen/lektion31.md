# Lekcja 31

## 31.1. Siódma klasa czasownika (⟪रुधादि⟫ = "⟪रुध्⟫ itd.")

::: grammar-box
**Tworzenie:**

**Przed końcowymi spółgłoskami korzenia w stopie głębokiej (guṇa) wstawia się tzw. infix nosowy (-na- lub -n-):**

*   **w silnym temacie: -na-**
*   **w słabym temacie: -n-**

**Dla połączenia końcowych spółgłosek korzenia z końcówkami zaczynającymi się na spółgłoskę obowiązują te same zasady, co dla siódmej klasy czasownika.**
:::
Przykłady:

⟪युज्⟫ 7U "łączyć, zaprzęgać"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Tryb oznajmujący** | **3. os. lp.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(wewnątrz słowa przed guturalami nosowe zastępowane są przez -ṅ-) |
| | **3. os. lm.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Tryb przypuszczający** | **3. os. lp.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. os. lm.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Imiesłów czasu teraźniejszego** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brżeń.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "zatrzymywać, doprowadzać do zatrzymania"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Tryb oznajmujący** | **3. os. lp.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. os. lm.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Tryb przypuszczający** | **3. os. lp.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. os. lm.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Imiesłów czasu teraźniejszego** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brżeń.: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**U niektórych rdzeni -n- słabej formy tematu czasu teraźniejszego przeniknęło również do czasów pozaprezentycznych, tak że te rdzenie należy analizować z wstawnym nosowym.**
:::
Przykład:

⟪भञ्ज्⟫ 7P "łamać"

::: indent
*   Tryb oznajmujący, czas teraźniejszy
*   3.os.l.p. ⟪भनक्ति⟫ (bha-na + j + ti)
*   3.os.l.m. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Czas przyszły: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Biernik: ⟪भज्यते⟫ (lub z pierwotnego rdzenia ⟪भज्⟫, lub z *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (ewentualnie z *bhñj + na)
:::
## 31.2. Słownik

⟪युज्⟫ 7U ⟪युनक्ति⟫ : zaprzęgać, nakładać uprząż, napinać, mocować ; Ā także: napinać się (= wysilać się), łączyć się z, koncentrować na (Celownik, ⟪सप्तमी⟫)
::: indent
**Czas przyszły: ⟪योक्ष्यति⟫**
**Biernik: ⟪युज्यते⟫**
**Zwrot przyczynowy: ⟪योजयति⟫**
**PPP ⟪युक्त⟫**
**Infinitiv: ⟪योक्तुम्⟫**

stąd:
**⟪युग⟫ n. → ⟪युग⟫ n.:** jarzmo, para, epoka świata (istnieją cztery epoki świata:
1. ⟪कृत⟫
2. ⟪त्रेता⟫
3. ⟪द्वापर⟫
4. ⟪कलि⟫

Epoka ⟪कलियुग⟫ rozpoczęła się około 3102 r. p.n.e., w roku wojny ⟪महाभारत⟫. Więcej szczegółów u Bashama, Wonder s. 323)

**⟪योग⟫ m.:** "zaprzęgnięcie, naprężenie", wysiłek, połączenie, joga (patrz Basham, Wonder s. 327n.)
