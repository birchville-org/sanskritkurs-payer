# Lekcja 28

## 28.1. Forma kauzatywna (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Jeśli chce się wyrazić, że ktoś lub coś powoduje lub sprawia, iż inna osoba lub inny przedmiot wykonuje doznaje czegoś wyrażonego przez rdzeń (z ewentualnym przyrostkiem), używa się formy kauzatywnej (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫).**

Przykład:
⟪गम्⟫ "iść" » Kauzatyw: ⟪गमयति⟫ "on powoduje, że ktoś idzie; on wysyła"
⟪दृश्⟫ "widzieć" » Kauzatyw: ⟪दर्शयति⟫ "on sprawia, że się widzi = on pokazuje"
:::

## 28.2. Konstrukcja zdania z kauzatywem (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Schemat 1:**

**Gdy rdzeń leżący u podstawy kauzatywu (z ewentualnym przyrostkiem) jest NIEPRZETOCZNÝ (tzn. nie może mieć dopełnienia biernego) lub wyraża ruch, wiedzę, informację lub jedzenie:**

**Agent (⟪कर्ता⟫) kauzatywu w mianowniku (⟪प्रथमा⟫) — Agent wywoływanej czynności w bierniku (⟪द्वितीया⟫) — (Cel ruchu, obiekt wiedzy itp. w bierniku = ⟪द्वितीया⟫) — Czasownik w kauzatywie**
:::
Przykłady:

⟪दुर्जनो रामं मोहयति⟫ = "zły człowiek powoduje, że Rāma jest zdezorientowany = dezorientuje Ramę = sprawia, iż Rama błądzi"
Wynik: ⟪रामो मुह्यति⟫ = "Rāma jest zdezorientowany / oślepiony / błądzi."

⟪रामः शत्रून्स्वर्गं गमयति⟫ = "Rāma sprawia, że wrogowie idą do nieba = wysyła wrogów do nieba"
Wynik: ⟪शत्रवः स्वर्गं गच्छन्ति⟫ = "wrogowie idą do nieba / przybywają do nieba"

⟪गुरू रामं वेदार्थं वेदयति⟫ = "Mistrz sprawia, że Rāma wie sens Wedy = wyjaśnia / uczy Ramę sensu Wedy"
Wynik: ⟪रामो वेदार्थं वेत्ति⟫ = "Rāma zna / rozumie sens Wedy"

⟪स रामं वेदमध्यापयति⟫ = „on naucza Ramę Wedy“
Wynik: ⟪रामो वेदमधीते⟫ „Rāma studuje Wedę“

⟪रामो देवानामृतमाशयति⟫ = „Rāma każe bogom jeść pokarm nieśmiertelności = podaje bogom pokarm nieśmiertelności do zjedzenia“ (⟪अश्⟩ 9 „jeść“)
Wynik: ⟪देवा अमृतमश्नन्ति⟫ „Bogowie jedzą pokarm nieśmiertelności“

::: grammar-box
**Schemat 2:**

**W przypadku czasowników przechodnich (poza wymienionymi pod Schematem 1). Również we wszystkich czasownikach, jeśli to, co oznacza kausatywa, jest wywoływane (jeśli więc kausatywa jest kausatywą od kausytywy):**

**Agens (⟪कर्ता⟫) kausatywu w mianowniku (⟪प्रथमा⟫) — Agens wywołanej czynności w narzędniku (⟪तृतीया⟫) — Obiekt wywołanej czynności w przypadku, jaki wymagałby od niego czasownik podstawowy (tj. zwykle w bierniku) — Czasownik w kausatywie**
:::
::: indent
Przykłady:
(⟪स⟫) ⟪रामेण भार्यां त्याजयति⟫ = "On skłania Rāmę do porzucenia jego żony"
Wynik: ⟪रामो भार्यां त्यजति⟫ = "Rāma porzuca swoją żonę"

⟪विष्णुमित्रो रामेण गोविन्दं गमयति⟫ = "Viṣṇumitra skłania Rāmę do tego, by ten skłonił Govindę do odejścia = Viṣṇumitra każe Rāmie odesłać Govindę"
Wynik: ⟪रामो गोविन्दं गमयति⟫ = "Rāma odesyła Govindę"
Wynik tego wyniku: ⟪गोविन्दो गच्छति⟫ = "Govinda odchodzi"
:::
::: grammar-box
**Wyjątki od schematu 1:**

**Zgodnie ze schematem 2 zbudowane są m.in. następujące czasowniki:**

**Kausatyw do:**
**⟪नी⟫ "prowadzić"**
**⟪वह्⟫ "jechać" (tylko jeśli agens wywołanej czynności nie jest kierowcą)**
**⟪स्मृ⟫ "przypominać sobie" (istnieją do tego wyjątki)**
**⟪अद्⟫ "jeść"**
**⟪खाद्⟫ "żuć"**
:::
Przykłady:

⟪रामो भृत्येन भारं नाययति वाहयति वा⟫ = "Rāma każe słudze prowadzić lub jechać z ciężarem"
Wynik: ⟪भृत्यो भारं नयति वहति वा⟫ = "Sługa prowadzi lub jedzie z ciężarem"

⟪रामो बालेनान्नमादयति खादयति वा⟫ = "Rāma każe chłopcu jeść lub żuć pokarm"
Wynik: ⟪बालो ऽन्नमत्ति खादति वा⟫ = "chłopiec jeście lub żuje pokarm"

(⟪स⟫) ⟪रामेण स्मारयति⟫ = "On sprawia, że Rāma sobie przypomina"
Wynik: ⟪रामः स्मरति⟫ = "Rāma sobie przypomina"

::: grammar-box
**Poniższe kausatywy mogą być konstruowane zarówno według schematu 1, jak i według schematu 2:**

**⟪हृ⟫ "trzymać, przynieść"**
**⟪कृ⟫ "robić, czynić"**
**Kausatyw w formie Atmanepadakusativ do ⟪दृश्⟫**
:::
Przykłady:

⟪रामो भृत्यं कटं कारयति हारयति वा⟫ = "Rāma każe słudze zrobić lub przynieść matę (⟪कट⟫ m.)"
albo:
⟪रामो भृत्येन कटं कारयति हारयति वा⟫
Wynik: ⟪भृत्यः कटं करोति हरति वा⟫ = "Sługa robi lub przynosi matę"

⟪रामो बालं प्रतिमां दर्शयते⟫ = "Rāma każe chłopcu zobaczyć obraz = pokazuje chłopcemu obraz (we własnym interesie)"
albo:
⟪रामो बालेन प्रतिमां दर्शयते⟫
Wynik: ⟪बालः प्रतिमां पश्यति⟫ = "chłopiec widzi obraz"

Gdy kausatyw jest używany w konstrukcji biernej, prawie zawsze stosuje się następujący schemat:

::: grammar-box
**Schemat A (konstrukcja bierna):**

**Agent kausatywu w narzędniku (⟪तृतीया⟫) — agent wywołanej czynności w mianowniku (⟪प्रथमा⟫) — obiekt wywołanej czynności w przypadku, jaki miałby według czasownika podstawowego (tj. zwykle w bierniku) — czasownik w formie kausatywu**
:::
Przykłady:

⟪गुरुणा रामो ग्रामं गम्यते⟫ = "Mistrz wysyła Rāmę do wioski"
Wynik: ⟪रामो ग्रामं गच्छति⟫ = "Rāma idzie do wioski"

⟪रामेण भृत्यः कटं कार्यते⟫ = "Rāma każe słudze zrobić matę"
Wynik: ⟪भृत्यः कटं करोति⟫ = "Sługa robi matę"

⟪रामेण भृत्यो भारं हार्यते⟫ = "Rāma każe słudze przynieść ciężar"
Wynik: ⟪भृत्यो भारं हरति⟫ = "Sługa przynosi ciężar"


## 28.3. Tworzenie tematu czasu teraźniejszego od kausatywy (⟪णि⟫, ⟪णिच्⟫, ⟪कारित⟫)

::: grammar-box
**Do tematu kausatywy dołączane są tematowe kończyny czasu teraźniejszego**
:::
Występują różne typy tworzenia:

::: grammar-box
**Typ tworzenia 1: (zwykle) stopień wysoki rdzenia + -aya-**
:::
Przykłady:

| Rdzeń | Kausatywa 3. os. l.poj. trybu oznajmującego czasu teraźniejszego | Znaczenie |
| :--- | :--- | :--- |
| ⟪विश्⟫ | ⟪वेशयति⟫ | pozwala wejść, wprowadza do środka |
| ⟪लुभ्⟫ | ⟪लोभयति⟫ | sprawia, że ktoś pragnie, czyni pożądliwym, kuszy |
| ⟪दृश्⟫ | ⟪दर्शयति⟫ | sprawia, że ktoś widzi = pokazuje |
| ⟪वृत्⟫ | ⟪वर्तयति⟫ | sprawia, że ktoś się obraca, zwraca (przechodnio), toczy (przechodnio), wprowadza w ruch |

::: grammar-box
**Typ tworzenia 2: stopień przedłużony rdzenia + -aya-**

**Często przy rdzeniach kończących się samogłoską oraz przy rdzeniach, po których -a- następuje pojedyncza spółgłoska końcowa.**
:::
Przykłady:

| Rdzeń | Kausatywa 3. os. l.poj. trybu oznajmującego czasu teraźniejszego | Znaczenie |
| :--- | :--- | :--- |
| ⟪भू⟫ | ⟪भावयति⟫:br(aus: bhau-aya-ti) | sprawia, że ktoś lub coś staje się, produkuje |
| ⟪इ⟫ | ⟪आययति⟫:br(aus: ai-aya-ti) | sprawia, że ktoś idzie |
| ⟪नी⟫ | ⟪नाययति⟫:br(aus: nai-aya-ti) | pozwala iść, prowadzi |
| ⟪कृ⟫ | ⟪कारयति⟫:br(kār-aya-ti) | pozwala robić, każe zrobić |
| ⟪वच्⟫ | ⟪वाचयति⟫:br(vāc-aya-ti) | pozwala mówić, każe powiedzieć, (każe wypowiedzieć tekst =) czyta na głos |

::: grammar-box
**Typ tworzenia 3: stopień niski rdzenia + -aya-**

**Występuje.**
:::
Przykład:

| Rdzeń | Kausatywa 3. os. l.poj. trybu oznajmującego czasu teraźniejszego | Znaczenie |
| :--- | :--- | :--- |
| ⟪दुष्⟫ | ⟪दूषयति⟫:br(dūṣ-aya-ti) | (kogoś) psuje, rujnuje |

::: grammar-box
**Typ 4 tworzenia: rdzeń + -paya-**

**W przypadku rdzeni kończących się na -ā oraz niektórych innych rdzeni.**
:::
Przykłady:

| Rdzeń | Kausatyw 3. os. l.p. trybu oznajmującego czasu teraźniejszego | Znaczenie |
| :--- | :--- | :--- |
| ⟪स्था⟫ | ⟪स्थापयति⟫:br(sthā-paya-ti) | stawiać, ustawiać |
| ⟪इ⟫ + ⟪अधि⟫:br"studiować" | ⟪अध्यापयति⟫:br(zwyk.: adhi+ā-paya-ti):br(patrz komentarz w: Thumb-Hauschildt, tom I, s. 341) | zlecać studia, uczyć |

::: grammar-box
**Tworzenia nieregularne:**

**Miejscowi gramatykowie uznają następujące formy za kausatywy:**

**han** : Kaus. **ghātayati**¹ "każać zabić, każe zranić"
**pā** 2 "strzec": **pālayati**² "przeprowadzać, ratować, chronić"
:::
Uwagi:
1. **ghātayati** jest w rzeczywistości czasownikiem pochodnym od rzeczownika **ghāta** m. "uderzenie" (denominativum) i jest używany zamiast kausatywu od **han**.
2. **pālayati** jest prawdziwym kausatywem, jednakże do rdzenia **pṛ** 3 "przeprowadzać, ratować, chronić": **pārayati** (pār-aya-ti) » **pālayati** (w niektórych regionach Indii odpowiada mu r litera l, w innych odwrotnie: l odpowiada r).


## 28.4. Tworzenie biernego (⟪यक्⟫) od kausatywu

::: grammar-box
**Bierny od kausatywu tworzy się w następujący sposób:**

**Rdzeń kausatywu BEZ -aya- + sufiks bierny -ya-**

Przykłady:
**bhāvyate** (bhāv-ya-te) "on/ona/on jest wyprowadzany"
**sthāpyate** (sthāp-ya-te) "on/ona/on jest ustawiany"
:::
Podczas gdy bierny od pierwotnego rdzenia zwykle tworzy się z rdzenia w stopniu niskim, bierny od kausatywu można zwykle rozpoznać po tym, że tworzy się z rdzenia w stopniu wysokim lub wzmacnionym.


## 28.5. Tworzenie czasu przyszłego (⟪ऌट्⟫, ⟪भविष्यन्ती⟫ f.) dla kausatywu

::: grammar-box
**Czas przyszły kausatywu tworzy się od pnia kausatywnego, przy czym końcowe -a sufiksu kausatywnego znika:**

**-ay-iṣya-**

Przykład:
**budh** przyszły-kausatyw: **bodhayiṣyati** (bodh-ay-i-ṣya-ti): "on/ona/onit będzie budzić"
:::

## 28.6. Tworzenie PPP (⟪क्त⟫) dla kausatywu

::: grammar-box
**Pień kausatywny na -ay- (bez końcowego a) + -i- + -ta**

Przykłady:
**gam** — **gamayati** — **gamita** (gam-i-ta) "wysłany" (PPP prostej korzenia: **gata**)
**sthā** — **sthāpayati** — **sthāpita** (sthāp-i-ta) "ustawiony"
:::

## 28.7. Tworzenie absolutywu (⟪क्त्वा⟫ . ⟪ल्यप्⟫) dla kausatywu

::: grammar-box
**Absolutyw na -tvā tworzy się od pnia kausatywnego na -ay- (bez końcowego a):**

**Pień kausatywny na -ay- + -i- + -tvā**

Przykład:
**sthāpayitvā** (sthā-pay-i-tvā) "po tym, jak ustawił"
:::
::: grammar-box
**Absolutyw na -ya występuje u kausatywów z przyimkiem zazwyczaj na pniu kausatywnym BEZ -aya-**

Przykłady:
**prabudh** — **prabodhayati** — **prabodhya** (pra-bodh-ya) "po tym, jak obudził"
**ānī** — **ānayati** — **ānāyya** (ā-nāy-ya) "po tym, jak pozwolił przyprowadzić, po tym, jak pozwolił przynieść"
:::
::: grammar-box
**Jeśli jednak sylaba rdzenia kausatywu zawiera krótkie -a przed pojedynczą spółgłoską, -ya absolutywu występuje na pniu kausatywnym na -ay- (bez końcowego a)**

Przykład:
**āgam** — **āgamayati** — **āgamayya** (ā-gamay-ya) "po tym, jak pozwolił przyjść"
:::

## 28.8. Tworzenie bezokolicznika (⟪तुमुन्⟫) od kauzatywu

::: grammar-box
**Bezokolicznik od kauzatywu tworzy się od pnia kauzatywnego na -ay- (bez końcowego a):**

**Pień kauzatywny na -ay- + -i- + -tum**

Przykład:
**jan** — **janayati** — **janayitum** (janay-i-tum) „aby wytworzyć”
:::

## 28.9. Dziesiąta klasa czasu teraźniejszego (⟪चुरादि⟫ = ⟪चुर्⟫ itd.)

::: grammar-box
**W ten sam sposób, co kauzatywy, czas teraźniejszy (i inne czasy) tworzą niektóre rdzenie dziesiątej klasy czasu teraźniejszego, nie będąc jednocześnie kauzatywami.**

Przykłady:
1. Rdzeń w stopniu przedłużonym + -aya- : ⟪कम्⟫ 10Ā ⟪कामयते⟫ „kochać”
2. Rdzeń w stopniu wzmożonym + -aya- : **cur** 10U **corayati** „kradnąć”; Futurum: **corayiṣyate**; Passivum: **coryate**
:::
::: grammar-box
**Formy kauzatywu od czasowników dziesiątej klasy czasu teraźniejszego są identyczne z formami czasownika prostego. Decyzja, czy mamy do czynienia z kauzatywem, możliwa jest wyłącznie na podstawie znaczenia lub czasem konstrukcji.**
:::
