# Lekcja 4

## 4.1. Proste pytania uzupełniające (pytania o słowo) i odpowiedzi

### 4.1.1. Zaimek pytajny i zaimek wskazujący

#### 4.1.1.1. Zaimek pytajny (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Mianownik liczby pojedynczej | Mianownik liczby mnogiej |
| :--- | :--- | :--- |
| **Rodnikij** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Rodmęski** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Rod żeński** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Zaimki wskazujące (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Osnowy** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"on, ona, ono; ten, ta, to":br(Wspominany)** | **etad = ⟪एतद्⟫:br"ten, ta, to":br(Bardzo blisko mówiącego)** | **idam = ⟪इदम्⟫:br"ten, ta, to":br(Blisko)** |
| **Mianownik liczby pojedynczej** ||||
| **Rodnikij** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Rodmęski** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Rod żeński** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Mianownik liczby mnogiej** ||||
| **Rodnikij** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Rodmęski** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Rod żeński** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**Co do M. sg. rodmięskiego:**
**sa, eṣa** (⟪स एष⟫) występuje przed wszystkimi dźwiękami z wyjątkiem krótkiego **-a**
**so, eṣo** (⟪सो एषो⟫) występuje przed **-a**, które ulega elizji z Avagraha (znika)
**saḥ, eṣaḥ** (⟪सः एषः⟫) występuje tylko w pauzie (koniec zdania, koniec wersu)

Aby móc tworzyć zdania z tymi zaimekami (sarvanāman n.), konieczna jest znajomość następujących zasad sandhi:

### 4.1.2. Sandhi końcowego -m

::: grammar-box
**Końcowe -m przed spółgłoskami zastępowane jest anusvārą (-ṃ). Na końcu zdania lub wersu oraz przed samogłoskami -m pozostaje bez zmian.**
:::
### 4.1.3. Sandhi końcowego -e

::: grammar-box
1. **przed a- końcowe -e pozostaje bez zmian: początkowe a- ulega elizji z avagraha:**
np. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Te ogniska"

2. **Przed innymi samogłoskami niż krótkie a- końcowe -e zwykle zastępowane jest przez -a z hiusem. Występuje również zastąpienie przez -ay:**
np. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (rzadko: imay īśvarāh = ⟪इमयीश्वराः⟫) "CI PANOWIE"
:::
### 4.1.4. Sandhi końcowego -d

::: grammar-box
**Końcowe -d w pauzie oraz przed bezdźwięcznymi gardłowymi (k, kh) i labialami (p, ph) zastępowane jest przez -t.**

Zastąpienie przed innymi spółgłoskami zostanie omówione później. Na razie należy unikać takich zbiegów głosek!
:::
### 4.1.5. Formuły pytające

Za pomocą tych zaimków tworzy się np. następujące formuły pytające:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Liczba pojedyncza** | **Rodnik nijaki** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं किम्⟫, ⟪किमिदम्⟫ | "Co to jest?" |
| ^^| **Rod męski** | sa kaḥ? / kaḥ saḥ?:br⟪स कः⟫, ⟪कः सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष कः⟫, ⟪क एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं कः⟫, ⟪को ऽयम्⟫ | "Kim jest to?":br"Kim jest on?" |
| ^^| **Rod żeński** | sā kā? / kā sā?:br⟪सा का⟫, ⟪का सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं का⟫, ⟪केयम्⟫ | "Kim jest to?":br"Kim jest ona?" |
| **Liczba mnoga** | **Rodnik nijaki** | tāni kāni? / kāni tāni?:br⟪तानि कानि⟫, ⟪कानि तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि कानि⟫, ⟪कानीमानि⟫ | |
|^^ | **Rod męski** | te ke? / ke te?:br⟪ते के⟫, ⟪के ते⟫:brete ke? / ka ete?:br⟪एते के⟫, ⟪क एते⟫:brime ke? / ka ime?:br⟪इमे के⟫, ⟪क इमे⟫ | |
| ^^| **Rod żeński** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः काः⟫, ⟪का एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः काः⟫, ⟪का इमाः⟫ | |
:::
Przykład innych pytań:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ Odpowiedź: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (W zdaniu nominalnym można np. umieścić podmiot na początku, aby podkreślić nawiązanie do pytania.)

UWAGA: Odpowiedzi, które można udzielić na takie pytania przy użyciu dotychczasowej wiedzy z sanskrytu, oczywiście jeszcze nie we wszystkich aspektach odpowiadają idiomatycznie dobremu sanskrytowi.


## 4.2. Ćwiczenie

**A) Utwórz ustnie pytania według schematu viṣṇuḥ kaḥ (⟪विष्णुः कः⟫) z następującymi słowami i odpowiedz na pytania po sanskrycku:**

śruti, śiva, brāhmaṇa, dvija (liczba mnoga), indrāṇī, dhenu, tulādhara, kālidāsa
