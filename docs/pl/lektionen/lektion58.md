## 58.6. Aoryst 5: aoryst iṣ

::: grammar-box
**Aoryst iṣ jest tworzony ze wszystkich rdzeni seṭ, dla których nie nauczono wyraźnie wyłącznie innej formy aorystu.**

**Tworzenie:**

**Augment + rdzeń + i + s + beztematowe końcówki wtórne**

**!!!** 2.os.lp. oraz 3.os.lp. pochodzą od **-**īs lub -īt z **!!!** (Pochodzi to z przeniesienia imperfektu rdzeni typu ⟪अब्रवीत्⟫; są to więc właściwie formy aorystu rdzeniowego).
:::
Suffix tworzący temat + końcówki aorystu iṣ brzmią więc:

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | **-iṣam** | **-iṣma** | **-iṣi** | **-iṣmahi** |
| **2. ⟪द्वितीयः⟫** | **-īs** | **-iṣṭa** | **-iṣṭhās** | **-**idhvam / :br-iḍhvam:br(wyborczo po -h lub półsamogłosce) |
| **3. ⟪प्रथमः⟫** | **-īt** | **-iṣur** | **-iṣṭa** | **-iṣata** |

:::
::: grammar-box
**Forma rdzenia:**

*   **Rdzenie z krótką samogłoską przed pojedynczą spółgłoską: stopa wysoka w lp i Ā**  
Przykłady:  
⟪बुध्⟫ 1U: 1.os.lp. ⟪अबोधिषम् कॢप्⟫ 1Ā: 1.os.Ā ⟪अकल्पिषि⟫

*   **Korzenie zakończone samogłoską:**
*   **P: stopa wzmożona**
*   **Ā: stopa wysoka**

Przykłady:  
⟪पू⟫ 9U: 1.os.P ⟪अपाविषम्⟫ ; 1. os.Ā ⟪अपविषि⟫

*   **Korzenie na -ar., -al oraz ⟪वद्⟫ 1P "mówić", ⟪व्रज्⟫ 1P "odchodzić": P: stopa wzmożona**  
Przykłady:  
⟪चर्⟫ 1P: 1.os.P ⟪अचारिषम् वद्⟫ 1P: 1.os.P ⟪अवादिषम्⟫

*   **Inne korzenie typu (Kons.-)Kons.-a-Kons.: w P opcjonalnie stopa wzmożona (nie dotyczy korzeni na -h, -m, -y oraz kilku innych)**  
Przykład:  
⟪तन्⟫ 8U: 1.os.P ⟪अतनिषम्⟫ / ⟪अतानिषम्⟫  
ale:  
⟪क्रम्⟫ 1U: 1.os.P ⟪अक्रमिषम्⟫
:::
