# Lekcja 26

## 26.1. Prawo cerebralizacji -s- wewnątrz słowa

::: grammar-box
**-s-** zastępowane jest przez **-ṣ-**, jeśli bezpośrednio lub oddzielone tylko ⟪अनुस्वार⟫ lub ⟪विसर्ग⟫ poprzedza **k, r, l** lub samogłoska — z wyjątkiem **a, ā** — a następnie następuje inny dźwięk niż **ṛ, r**.

Sandhiemu temu podlega również **⟪दुस्⟫-** przed bezdźwięcznymi guturalami i labialami w złożeniach.
:::
*Przykłady:*
::: indent
⟪तेषाम्⟫ (z: *te-sām*)

ale: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. Prawo cerebralizacji dentali wewnątrz słowa

::: grammar-box
Dentalne spółgłoski zwarte są po retrofleksach (włącznie z **-ṣ-**) zastępowane przez odpowiednie retropleksy:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** ze względu na poprzedzające **i**, **ṭh** ze względu na następnie następujące **ṣ**)*
:::

## 26.4. Prawo dissimilacji aspiraty Grassmanna

::: grammar-box
**Bezpośrednie wystąpienie dwóch aspirat (aspirata - samogłoska - aspirata) powoduje utratę aspiracji pierwszej spółgłoski:**

Przykład:

\*dhu(gh) » du(g)h
:::

## 26.5. Sandhi słów z końcówkami -m, -n przed spółgłoskami szumiącymi

::: grammar-box
**Przed spółgłoskami szumiącymi -n i -m zastępowane są przez -ṃ-:**

Przykład: zob. niżej forma czasu przyszłego od ⟪मन्⟫
:::
## 26.6. Użycie prostego czasu przyszłego (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**Prosty czas przyszły (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.) wyraża:**

**przyszłość**
**zamiar lub wolę wykonania czynności („pójdę”, „chcę pójść”)**
**oczekiwanie („tak się stanie”)**
**nadzieję**
**obawę**
**prawdopodobieństwo**
**opinę mówiącego**
**rozkaz**

**Czas przyszły występuje częściowo w konkurencji z trybem łaknięcym (patrz dalej).**
:::
np. ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = „Osoba, która pragnie złożyć ślubowanie, udaje się do świątyni.”

## 26.7. Tworzenie prostego czasu przyszłego (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ f.)

::: grammar-box
**Prosty czas przyszły:**

:::
::: indent
**Rzeczownik przyszły + końcówka pierwotna**
:::
::: grammar-box
**Rzeczownik przyszły:**

:::
::: indent
**(zwykle) stopień wzmacniany rdzenia + -sya**  
**lub**  
**(zwykle) stopień wzmacniany rdzenia + -i- + -sya (= - iṣya)**
:::
**Który rdzeń tworzy jaką formę rzeczownika przyszłego, należy zapamiętać wraz z formami podstawowymi!**  
**Zasadniczo forma rdzenia i spójnik w czasie przyszłym pokrywają się z bezokolicznikiem.**  
**Niektóre rdzenie mogą opcjonalnie tworzyć czas przyszły ze spójnikiem -i- lub bez niego.**  
**Imiesłów czasu przyszłego w trybie Parasmaipada tworzy się przez dodanie sufiksu -nt- do rzeczownika przyszłego, rodzaj żeński opcjonalnie na -ntī lub -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
