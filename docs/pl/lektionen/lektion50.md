# Lekcja 50

## 50.1. Tworzenie rzeczowników: regularne stopniowanie

::: grammar-box
**Regularne stopniowanie w sanskrycie odbywa się za pomocą sufiksów ⟪तद्धित⟫**
* **-⟪तर⟫ (fem.: ⟪तरा⟫) w "komparatywie"**
* **⟪तम⟫ (fem.: ⟪तमा⟫) w "superlatywie"**

**Sufiksy te dodaje się do męskiego tematu przymiotników. W przypadku rzeczowników ze zmianą tematu dodaje się je do słabego tematu, który ma formę taką jak przed końcówką -su w locative (⟪पञ्चमी⟩) liczby mnogiej.**
:::
::: media
![](/images/lekt5007.webp)
Ilustracja: ⟪लोकस्योत्तमो गिरिः सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = Mount Everest
(Źródło obrazu: [Szczegóły](/pl/licenses#lekt5007))
:::

::: grammar-box
**Znaczenie:**

**"Komparatyw" oznacza, gdy nie jest wyrażony porównywany obiekt: "dość, bardzo, za":**

:::
::: indent
np. ⟪सुचितर⟫ 3 "dość czysty", "bardzo czysty", "za bardzo czysty"
:::
**Gdy wyrażony jest porównywany obiekt, stoi on w ablatywie (⟪पञ्चमी⟩). Komparatyw + Ablativ odpowiada stopniowaniu z "niż" w języku niemieckim.**

::: indent
np. ⟪देवदत्ताद्रामो धीमत्तरः⟫ = dosłownie: "patrząc z perspektywy Devadatty, Rāma jest bardziej roztropny" = "Rāma jest bardziej roztropny niż Devadatta"
:::
**"Superlatyw" oznacza, gdy nie jest wyrażony porównywany obiekt: "najbardziej, bardzo":**

::: indent
np. ⟪सत्तम⟫ 3 (z ⟪सन्त्⟫) "najbardziej dobry, bardzo dobry"
:::
**Gdy wyrażony jest porównywany obiekt, stoi on w genetywie (⟪षष्ठी⟩) ("z", "spośród"), a superlatyw odpowiada niemieckiemu superlatywowi (stopień najwyższy):**

::: indent
np. ⟪द्विजानां सत्तमः⟫ = "najlepszy spośród dwurodzonych"
:::
**Okońcówki -⟪तर⟫ i -⟪तम⟫ mogą występować nie tylko przy przymiotnikach, ale także rzeczownikach, indeklinabiliach i nawet formach czasownikowych:**

Przykłady:

::: indent
⟪गजतम⟫ m. "najlepszy słoń" (⟪गज⟫) (również określenie Buddy)

⟪गोतम⟫ m. "największy wół" (⟪गो⟫) lub: "najbogatszy w bydło"

⟪उद्⟫ indekl. "na", "w górę" » ⟪उत्तर⟫ 3 "wyższy" » ⟪उत्तम⟫ 3 "najwyższy"
:::
**Gdy te okoliczniki przybierają formę czasownikową, występują zawsze w formie przysłówkowej:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

Przykłady:

::: indent
⟪पचतितराम्⟫ "on/ona/onie gotuje lepiej"

⟪पचतितमाम्⟫ "on/ona/onie gotuje najlepiej"
:::
**Tę formę mają te okoliczniki również, gdy przybierają indeklinabil i wywodzony rzeczownik jest używany przysłówkowo:**

::: indent
np. ⟪सुतराम्⟫ (do ⟪सु⟫) "w lepszy sposób" (przysłówkowo)
:::
::: media
![](/images/lekt5006.webp)
Ilustracja: ⟪का पचतितमाम्⟫
Lisu = 傈僳族, ⟪अरुणाचल प्रदेश⟫
(Źródło obrazu: [Szczegóły](/pl/licenses#lekt5006))
:::
