# Lekcja 34

## 34.1. Perfekt (⟪लिट्⟫)

W klasycznym sanskrycie od tematu perfektu występuje tylko tryb oznajmujący i imiesłów.

::: grammar-box
**Istnieją dwa rodzaje tworzenia perfektu:**
*   **perfekt reduplikowany = ⟪द्वित्वलिट्⟫**
*   **perfekt periphrastyczny = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Perfekt periphrastyczny (⟪अनुप्रयोगलिट्⟫) jest używany:**
1. **w przypadku koniugacji pochodnych (kauzatyw, desidieratyw, frequentatyw, denominatywy)**
2. **w przypadku rdzeni zaczynających się długim samogłoską (z wyjątkiem ā-) lub samogłoską (z wyjątkiem a-) przed dwiema spółgłoskami**
3. **w przypadku niektórych innych rdzeni**
:::
## 34.2. Perfekt reduplikowany (⟪द्वित्वलिट्⟫)

### 34.2.1. Stopniowanie tematu

::: grammar-box
**Tworzenie:**

**mocny temat:** liczba pojedyncza Parasmaipada
*   **reduplikowany rdzeń w stopniu najwyższym lub wzmożonym + końcówka perfektu**

**słaby temat:** wszystkie pozostałe formy
*   **reduplikowany rdzeń w stopniu najniższym + końcówka perfektu**
:::
::: grammar-box
**Ogólnie (również poza perfektem) nie podlegają stopniowaniu tematu rdzenie o formie:**
*   **(spółgłoska)-spółgłoska-długosamogłoska-spółgłoska**
*   **(spółgłoska)-spółgłoska-samogłoska-spółgłoska-spółgłoska**

**W perfekcie dodatkowo nie podlegają stopniowaniu tematu rdzenie o formie:**
*   **a-spółgłoska**
*   **ā-spółgłoska**
:::
### 34.2.2. Końcówki perfektu

::: grammar-box

| | 3. liczba pojedyncza | 3. liczba mnoga |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |

:::
### 34.2.3. Samogłoska łącząca -i-

::: grammar-box
**Przed końcówką 3.lm. Ā (-re) zawsze występuje samogłoska łącząca -i-, przed pozostałymi końcówkami zaczynającymi się spółgłoską u większości rdzeni.**
:::
### 34.2.4. Reduplikacja rdzeni zaczynających się spółgłoską

::: grammar-box
**Zasady dotyczące reduplikacji spółgłosek na początku rdzenia są takie same, jak te podane w [Lekcja 33](lektion33.md).**

**Samogłoska reduplikacyjna w rdzeniach zaczynających się spółgłoską to krótka samogłoska rdzenia.**

**Diftongi przed spółgłoską są redukowane do odpowiedniej krótkiej samogłoski stopu niskiego.**

**ṛ, ṝ, ḷ oraz diftongi na końcu są reduplikowane przez -a-.**
:::
Przykłady:

::: grammar-box

| Rdzeń | 3. os. lp. Perf. Act. |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::
::: grammar-box
**Niektóre rdzenie zaczynające się na y- lub v- reduplikują się przez i- lub u-, które w słabych formach "zlewają" się z samogłoską rdzenia.**
:::
Przykłady:

::: grammar-box

| Rdzeń | 3. os. lp. Perf. Act. | 3. os. lm. Perf. Act. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Reduplikacja rdzeni zaczynających się samogłoską

::: grammar-box
**1. Początkowe a-, ā- jest reduplikowane przez a-, co daje ā-.**
:::
Przykłady:

::: grammar-box

| Rdzeń | 3. os. lp. Perf. Act. |
| :--- | :--- |
| ⟪अस्⟫ 2 "być" i ⟪अस्⟫ 4 "rzucać" | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. Rdzenie zaczynające się na i- mają w silnym stemieniu sylabę reduplikacyjną iy-, a w słabym i-, która "zlewa" się z samogłoską rdzenia dając ī-. Analogicznie dotyczy to rdzeni zaczynających się na u-.**
:::
Przykłady:

::: grammar-box

| Rdzeń | 3. os. lp. Perf. Act. | 3. os. lm. Perf. Act. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. Rdzenia zaczynające się na a- przed dwiema spółgłoskami lub na ṛ-, mają sylabę reduplikacyjną ān-**
:::
Przykłady:

::: grammar-box

| Rdzeń | 3. os. l.poj. Perf. Aktywny | 3. os. l.mn. Perf. Aktywny |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. Typy reduplikowanego perfektu

Zasada klasyfikacji: Szczególności stopniowania tematu:
*   Perfekt bez stopniowania tematu: Typ I
*   Perfekt ze stopniowaniem tematu: Typ II - V
*   nieregularne formy perfektu

## 34.4. Perfekt Typ I: Perfekt bez stopniowania tematu

::: grammar-box
**Perfekt Typ I (bez stopniowania tematu) tworzą rdzenie typów:**
*   **(Spółgłoska)-Spółgłoska-Długi Samogłoska-Spółgłoska**
*   **(Spółgłoska)-Spółgłoska-Samogłoska-Spółgłoska-Spółgłoska**
*   **a-Spółgłoska**
*   **ā-Spółgłoska**
:::
Przykłady:

::: grammar-box

| Rdzeń | 3. os. l.poj. Perf. | 3. os. l.mn. Perf. |
| :--- | :--- | :--- |
| ⟪बन्ध्⟫ 9P | ⟪बबन्ध⟫:brba-bandh-a | ⟪बबन्धुर्⟫ |
| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |
| ⟪आप्⟫ 5P | ⟪आप⟫:bra + āp-a | ⟪आपुर्⟫ |
| ⟪अस्⟫ 2P "być":br⟪अस्⟫ 4 "rzucać" | ⟪आस⟫:bra + as-a | ⟪आसुर्⟫ |
| ⟪अश्⟫ | ⟪आनशे⟫:brnieregularna reduplikacja! | ⟪आनशिरे⟫ |

:::
