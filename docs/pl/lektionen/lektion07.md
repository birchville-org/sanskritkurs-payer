## 7.1. Zdanie czasownikowe z dopełnieniem biernym

::: grammar-box
**Schemat:**
**(Agens = kartṛ m. = ⟪कर्तृ⟫) – dopełnienie bierne (karman n. = ⟪कर्मन्⟫) – czasownik**

np.
**rāmaḥ phalaṃ khādati** = ⟪रामः फलं खादति⟫ : "Rāma je (kaut) owoc."
**brāhmaṇo devaṃ yajati** = ⟪ब्राह्मणो देवं यजति⟫ : "Brahman czci boga ofiarą (za kogoś innego)."
:::
Jeśli czasownik występuje w parasmaipada lub ātmanepada, to dopełnienie bierne (**karman** n. = ⟪कर्मन्⟫) zazwyczaj występuje w **bierniku** (Wenfall, dvitīyā f. = ⟪द्वितीया⟫).


## 7.2. Biernik (Wenfall, dvitīyā f. = ⟪द्वितीया⟫ = "druga końcówka przypadkowa")

::: grammar-box
**Końcówka biernika liczby pojedynczej rodzaju męskiego i żeńskiego po samogłosce: -m**

| Rodzaj męski na | Biernik liczby pojedynczej |
| :--- | :--- |
| **-a**: deva | **devam** :br⟪देवम्⟫ |
| **-i**: kavi | **kavim** :br⟪कविम्⟫ |
| **-u**: guru | **gurum** :br⟪गुरुम्⟫ |
| Rodzaj żeński na | Biernik liczby pojedynczej |
| **-ā**: devatā | **devatām** :br⟪देवताम्⟫ |
| **-i**: śruti | **śrutim** :br⟪श्रुतिम्⟫ |
| **-ī**: devī | **devīm** :br⟪देवीम्⟫ |
| **-u**: dhenu | **dhenum** :br⟪धेनुम्⟫ |
:::
::: grammar-box

### 7.2.1. Biernik liczby pojedynczej i mnogiej zaimek pytający i wskazujący

::: grammar-box
| || Rodzaj męski | Rodzaj żeński | Rodzaj nijaki |
| :--- | :--- | :--- | :--- | :--- |
| **kim** :brkto/co | lp. | **kam** :br⟪कम्⟫ | **kām** :br⟪काम्⟫ | **kim** :br⟪किम्⟫ |

| | lm. | **tān** :br⟪तान्⟫ | **tās** :br⟪तास्⟫ | **tāni** :br⟪तानि⟫ |

Formy **enam** (⟪एनम्⟫) itp. należą do rdzenia **enad** (⟪एनद्⟫), który tworzy formy tylko w niektórych przypadkach. Zamiast form **etad** i **idam** używa się ich wtedy, gdy oznaczony nimi przedmiot został już wcześniej wspomniany.
np. **ayaṃ devaḥ, enaṃ yajante.** = ⟪अयं देवः⟫ | ⟪एनं यजन्ते⟫ || : "On jest bogiem. Ofiarują mu."


### 7.2.2. Użycie biernika (Wenfall, dvitīyā f. = ⟪द्वितीया⟫ = "druga końcówka przypadkowa")

::: grammar-box
Biernik (dvitīyā f. = ⟪द्वितीया⟫) oznacza:
1. W zdaniu niebiernym: **bezpośredni obiekt** (karman n. = ⟪कर्मन्⟫) czynności wyrażonej czasownikiem:
np.
**devaṃ yajati** = ⟪देवं यजति⟫ : "On czci boga ofiarą."
**phalam āpnoti** = ⟪फलमाप्नोति⟫ : "On osiąga owoc (np. swojego działania)."
2. W przypadku czasowników wyrażających pójście, ruch, prowadzenie lub podobne w kierunku czegoś, biernik oznacza cel ruchu:
np.
**narakaṃ gacchati** = ⟪नरकं गच्छति⟫ : "On idzie do piekła."
:::
Inne użycia biernika zostaną omówione później.



## 7.3. Sandhi końcowego -n

::: grammar-box
**Końcowe -n:**

1. Przed zwartymi spółgłoskami podniebiennymi i retrofleksywnymi oraz przed **ś-** zastępowane jest przez nosówkę odpowiadającą tym dźwiękom:
**-n** przed **j-, jh-, ñ-, ś-** » **-ñ**
**-n** przed **ḍ-, ḍh-, ṇ-, ṣ-** » **-ṇ**
np. **kṣatriyān + jayati** » **kṣatriyāñ jayati** = ⟪क्षत्रियांञ्जयति⟫ : "On pokonuje Kszatrijów."
Początkowe **ś-** jest wtedy zwykle zastępowane przez **ch-**:
**gurūn + śṛṇoti** » **gurūñ chṛṇoti** (obok gurūñ śṛṇoti) = ⟪गुरूञ्छृणोति⟫ (⟪गुरूञ्शृणोति⟫) : "On słucha nauczycieli." "On słucha nauczycieli."

2. Przed wygłosowym **l-** przez **-l** z Anunāsiką (nazalizowane l, w piśmie ⟪ल्⟫ z Anunāsiką ⟪ँ⟫) zastępowane jest:
np. **paśūn + labhate** » ⟪पशूंल्लभते⟫ : "On otrzymuje bydło."

3. Przed wygłosowym bezdźwięcznym podniebiennym, retrofleksywnym lub zębowym przez **Anusvārę** + odpowiedni szumiący dźwięk zastępowane jest:
**-n** przed **c-, ch-** » **-ṃś**
**-n** przed **ṭ-, ṭh-** » **-ṃṣ**
**-n** przed **t-, th-** » **-ṃs**
np. **devān + ca** » **devāṃś ca** = ⟪देवांश्च⟫ : "i bogowie (Biernik)"
**devān + tu** » **devāṃs tu** = ⟪देवांस्तु⟫ : "ale bogowie (Biernik)"

4. Poza przypadkiem krótkiej samogłoski (patrz dalej) końcowe **-n** we wszystkich pozostałych przypadkach pozostaje niezmienione.
:::

## 7.5. Nieatematyczne klasy czasu teraźniejszego

Piąta klasa czasu teraźniejszego tworzy tzw. nieatematyczny stem czasownika, tzn. że stem czasu teraźniejszego nie kończy się jak w przypadku tematycznych klas czasu teraźniejszego (1., 4., 6., 10. klasa) na "samogłoskę tematyczną" **-a**.

::: grammar-box
**Nieatematyczne klasy czasu teraźniejszego mają ablaut, tzn. że istnieją dwie formy stemu czasu teraźniejszego:**
1. **mocny stem**: stopień wysoki (rzadko stopień przedłużony)
2. **słaby stem**: stopień niski

**Silny rdzeń występuje:**
w trybie oznajmującym liczby pojedynczej Parasmaipada czasu teraźniejszego (laṭ) i niedawnego (laṅ)
we wszystkich osobach trybu rozkazującego (loṭ) Parasmaipada i Ātmanepada
w trzeciej osobie liczby pojedynczej trybu rozkazującego (loṭ) Parasmaipada

**Wszystkie pozostałe formy mają słaby rdzeń czasownika teraźniejszego.**
:::
### 7.5.1. Końcówki wtórne trzeciej osoby liczby mnogiej u rdzeni bezsamogłoskowych

::: grammar-box
**U rdzeni czasownika teraźniejszego bezsamogłoskowych końcówki wtórne trzeciej osoby liczby mnogiej brzmią:**
**Parasmaipada: -anti**
**Ātmanepada: -ate**
:::
### 7.5.2. Pięta klasa czasownika teraźniejszego (svādi = ⟪स्वादि⟫ = "su itp.")

::: grammar-box
**Silny rdzeń**: (zazwyczaj) stopień niski rdzenia (jak podano wyżej) + **-no-**
**Słaby rdzeń**: (zazwyczaj) stopień niski rdzenia (jak podano wyżej) + **-nu-**

**Przed końcówkami samogłoskowymi u rdzeni zakończonych na samogłoskę -nu- zastępowane jest przez -nv-, a u rdzeni zakończonych na spółgłoskę przed końcówkami samogłoskowymi -nu- zastępowane jest przez -nuv-.**
:::
**Przykłady:**

| Rdzeń:br⟪धातु⟩ | Silny rdzeń | Słaby rdzeń | Przed samogłoską:br(słaby) |
| :--- | :--- | :--- | :--- |
| **āp** :br5 P:br⟪आप्⟩:br"osiągnąć" | **āp-no** :br(3.l.p. āpnoti = ⟪आप्नोति⟩) | **āp-nu** | **āp-nuv** :br(3.l.m. āpnuvanti = ⟪आप्नुवन्ति⟩) |
| **aś** :br5 Ā:br⟪अश्⟩:br"osiągnąć" | — | **aś-nu** :br(3.l.p. aśnute = ⟪अश्नुते⟩) | **aś-nuv** :br(3.l.m. aśnuvate = ⟪अश्नुवते⟩) |
| **su** :br5 U:br⟪सु⟩:br"wyciskać" | **su-no** :br(3.l.p. sunoti = ⟪सुनोति⟩) | **su-nu** :br(3.l.p. sunute = ⟪सुनुते⟩) | **su-nv** :br(3.l.m. sunvanti = ⟪सुन्वन्ति⟩,:br3.l.m. sunvate = ⟪सुन्वते⟩) |
| **śru** :br5 P:br⟪श्रु⟩:br"słuchać" | **śṛ-ṇo** :br(3.l.p. śṛṇoti = ⟪शृणोति⟩) | **śṛ-ṇu** | **śṛ-ṇv** :br(3.l.m. śṛṇvanti = ⟪शृण्वन्ति⟩) |


## 7.6. Słownik

**Zapoznaj się z następującymi słowami:**

**aś** 5 Ā (aśnute) ⟪अश् अश्नुते⟫ : osiągać, docierać do, zyskiwać
