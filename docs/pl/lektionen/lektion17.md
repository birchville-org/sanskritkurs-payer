# Lekcja 17

## 17.1. Druga klasa czasownika (⟪अदादि⟫ = ⟪अद्⟫ itd.)

Końcówki czasownikowe są bezpośrednio dołączane do rdzenia. Należy przy tym uwzględnić zmiany fonetyczne wynikające z sandhi wyrazowego.

::: grammar-box

Istnieją następujące formy tworzenia w drugiej klasie czasownika:

1. Rdzenie ze zmianą stopnia rdzenia
*   najczęściej: stopień wysoki - stopień niski
*   niektóre rdzenie: stopień pogłoszony - stopień niski
2. Rdzenie bez zmiany stopnia rdzenia
3. Dwisylabiczne rdzenie na -i/-ī ze zmianą stopnia rdzenia

:::
## 17.2. Rdzenie drugiej klasy czasownika ze zmianą stopnia rdzenia: stopień wysoki - stopień niski

Przykłady:

⟪द्विष्⟫ 2 U "nienawidzić"

*   silny stem czasownika teraźniejszego: dveṣ-
*   słaby stem czasownika teraźniejszego: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3\. os. lp. czasu teraźniejszego C | ⟪द्वेष्टि⟫ (« dveṣ + -ti) |
| 3\. os. lm. czasu teraźniejszego C | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 3\. os. lp. czasu teraźniejszego A | ⟪द्विष्टे⟫ (« dviṣ + -te) |
| 3\. os. lm. czasu teraźniejszego A | ⟪द्विषते⟫ (dviṣ-ate) |

:::
Działa tu następujące prawo sandhi wyrazowego:

::: grammar-box
Sandhi wyrazowe -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-
:::
Dalsze przykłady:

⟪इ⟫ 2 P "iść" (A po określonych przyimkach)

*   silny stem czasownika teraźniejszego: e-
*   słaby stem czasownika teraźniejszego:
*   przed spółgłoską: i-
*   przed samogłoską: y-/iy-

::: no-header

| | |
| :--- | :--- |
| 3\. os. lp. czasu teraźniejszego C | ⟪एति⟫ (e-ti) |
| 3\. os. lm. czasu teraźniejszego C | ⟪यन्ति⟫ (y-anti) |
| 3\. os. lp. czasu teraźniejszego A | ⟪इते⟫ (i-te) |
| 3\. os. lm. czasu teraźniejszego A | ⟪इयते⟫ (iy-ate) |

:::
⟪दुह्⟫ 2 U "doić"

*   silny stem czasownika teraźniejszego: doh-
*   słaby stem czasownika teraźniejszego: duh-

::: no-header

| | |
| :--- | :--- |
| 3\. os. lp. czasu teraźniejszego C | ⟪दोग्धि⟫ (« doh- + -ti) |
| 3\. os. lm. czasu teraźniejszego C | ⟪दुहन्ति⟫ (duh-anti) |
| 3\. os. lp. czasu teraźniejszego A | ⟪दुग्धे⟫ (« duh- + -te) |
| 3\. os. lm. czasu teraźniejszego A | ⟪दुहते⟫ (duh-ate) |

:::
⟪हन्⟫ 2 D "bić, zabijać, mordować"

*   mocny rdzeń trybu teraźniejszego: han-
*   słaby rdzeń trybu teraźniejszego:
*   przed spółgłoską: ha- (« \*hn-)
*   przed samogłoską: ghn-/han-

::: no-header

| | |
| :--- | :--- |
| 3\. os. lp. ter. D | ⟪हन्ति⟫ (han-ti) |
| 3\. lm. ter. D | ⟪घ्नन्ति⟫ (ghn-anti) |
| 3\. os. lp. ter. B | ⟪हते⟫ (ha-te) |
| 3\. lm. ter. B | ⟪घ्नते⟫ (ghn-ate) |

:::
⟪अस्⟫ 2 D "być"

*   mocny rdzeń trybu teraźniejszego: as-
*   słaby rdzeń trybu teraźniejszego: s-

::: no-header

| | |
| :--- | :--- |
| 3\. os. lp. ter. D | ⟪अस्ति⟫ (as-ti) |
| 3\. lm. ter. D | ⟪सन्ति⟫ (s-anti) |

:::
## 17.3. Rdzenie drugiej klasy trybu teraźniejszego z ablautem rdzenia: stopień pełny - stopień zredukowany

Przykład:

⟪स्तु⟫ 2 U "wielbić"

*   mocny rdzeń trybu teraźniejszego: stau-
*   słaby rdzeń trybu teraźniejszego:
*   przed spółgłoską: stu-
*   przed samogłoską: stuv-

::: no-header

| | |
| :--- | :--- |
| 3\. os. lp. ter. D | ⟪स्तौति⟫ (stau-ti):broder: ⟪स्तवीति⟫ |
| 3\. lm. ter. D | ⟪स्तुवन्ति⟫ (stuv-anti) |
| 3\. os. lp. ter. B | ⟪स्तुते⟫ (stu-te) |
| 3\. lm. ter. B | ⟪स्तुवते⟫ (stuv-ate) |

:::
## 17.4. Rdzenie drugiej klasy trybu teraźniejszego bez ablautu rdzenia

::: grammar-box
Bez ablautu rdzenia są rdzenie drugiej klasy trybu teraźniejszego na -ā
:::
Przykład:

⟪पा⟫ 2 D "chronić, strzec, pilnować"

::: no-header

| | |
| :--- | :--- |
| 3\. os. lp. ter. D | ⟪पाति⟫ (pā-ti) |
| 3\. lm. ter. D | ⟪पान्ति⟫ (« pā- + -anti) |

:::
Niektóre inne rdzenie drugiej klasy również nie mają ablautu:

Przykłady:

⟪अद्⟫ 2 D "jeść"

::: no-header

| | |
| :--- | :--- |
| 3\. os. lp. ter. D | ⟪अत्ति⟫ (« ad- + -ti) |
| 3\. lm. ter. D | ⟪अदन्ति⟫ (ad-anti) |

:::
⟪आस्⟫ 2 Ā "siedzieć"

::: no-header

| | |
| :--- | :--- |
| 3\. os. tryb teraźniejszy Ā | ⟪आस्ते⟫ (ās-te) |
| 3\. lm. tryb teraźniejszy Ā | ⟪आसते⟫ (ās-ate) |

:::
⟪वच्⟫ 2 P "mówić"

::: no-header

| | |
| :--- | :--- |
| 3\. os. tryb teraźniejszy P | ⟪वक्ति⟫ (« vac- + -ti) |
| 3\. lm. tryb teraźniejszy P | nie występuje |

:::
## 17.5. Dwisylabiczne rdzenie na -i/-ī z ablautem

Kilka rdzeni jest w szeregu form dwusylabicznych, tzn. przed końcówką spółgłoskową mają -i (odpowiednio przed niektórymi końcówkami -ī). Mimo to rdzenie te są przez rodzimych gramatyków i w słownikach itp. zapisywane jako jednosylabiczne.

Przykłady:

⟪रुद्⟫ 2 P "płakać, wyć"

*   silny stemień trybu teraźniejszego: rodi-
*   słaby stemień trybu teraźniejszego:
*   przed spółgłoską: rudi-
*   przed samogłoską: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. os. tryb teraźniejszy P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. lm. tryb teraźniejszy P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "mówić"

*   silny stemień trybu teraźniejszego: bravī- (« bro- + -ī)
*   słaby stemień trybu teraźniejszego:
*   przed spółgłoską: brū-
*   przed samogłoską: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. os. tryb teraźniejszy P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. lm. tryb teraźniejszy P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. os. tryb teraźniejszy Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. lm. tryb teraźniejszy Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Również ⟪स्तु⟫ 2 U "chwalić" ma obok form podanych w pkt. 3 formy według tego wzoru:

::: no-header

| | |
| :--- | :--- |
| 3\. os. tryb teraźniejszy P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::
