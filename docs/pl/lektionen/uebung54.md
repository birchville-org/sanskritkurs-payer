# Ćwiczenie 54

Utwórz odpowiednie formy aorystu od podanych form czasu teraźniejszego lub perfectum:

::: grammar-box
| Nr. | Forma | Określenie / Znaczenie | Aoryst |
|:---|:---|:---|:---|
| ⟪१⟫. | ⟪यन्ति⟫ | oni idą | ⟪अगुः⟫ |
| ⟪२⟫. | ⟪पिबामि⟫ | ja piję | ⟪अपाम्⟫ |
| ⟪३⟫. | ⟪ददौ⟫ | ja dałem / on dał | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | ⟪बभूव⟫ | ja / on / oni byliście | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | ⟪दधति⟫ | oni sadzą | ⟪अधुः⟫ |
| ⟪६⟫. | ⟪ऐम⟫ | my szliśmy | ⟪अगाम⟫ |
| ⟪७⟫. | ⟪पपिथ⟫ | ty piłeś / strzegłeś | ⟪अपाः⟫ (do :sig[⟪पा⟫] "pić") |
| ⟪८⟫. | ⟪तिष्ठति⟫ | on stoi | ⟪अस्थात्⟫ |
| ⟪९⟫. | ⟪इयेथ⟫ | ty poszedłeś | ⟪अगाः⟫ |
| ⟪१०⟫. | ⟪पप⟫ | wyście pili | ⟪अपात⟫ |
| ⟪११⟫. | ⟪एष्यथ⟫ | wy pójdziecie | ⟪अगात⟫ |
| ⟪१२⟫. | ⟪तस्थुः⟫ | oni stali | ⟪अस्थुः⟫ |
| ⟪१३⟫. | ⟪अधत्त⟫ | wy sadziliście | ⟪अधात⟫ |
| ⟪१४⟫. | ⟪अददाः⟫ | ty dałeś | ⟪अदाः⟫ |
| ⟪१५⟫. | ⟪अभवन्⟫ | oni byli | ⟪अभूवन्⟫ |
| ⟪१६⟫. | ⟪ददिम⟫ | myśmy dali | ⟪अदाम⟫ |
| ⟪१७⟫. | ⟪भिद्यते⟫ | jest łamany | ⟪अभेदि⟫ |
| ⟪१८⟫. | ⟪उद्यते⟫ | jest mówiony | ⟪अवादि⟫ |
| ⟪१९⟫. | ⟪स्तूयते⟫ | on jest chwalony | ⟪अस्तावि⟫ |
| ⟪२०⟫. | ⟪कृष्यते⟫ | jest orany | ⟪अकर्षि⟫ |
| ⟪२१⟫. | ⟪जायते⟫ | on jest rodzony | ⟪अजनि⟫ |
| ⟪२२⟫. | ⟪गीयते⟫ | jest śpiewany | ⟪अगायि⟫ |
| ⟪२३⟫. | ⟪गम्यते⟫ | jest chodzony | ⟪अगामि⟫ |
:::
