# Lekcja 16

## 16.1. Sandhi spółgłosek końcowych

Do tworzenia złożenia, których pierwszy człon stanowią rdzenie zakończone spółgłoską, potrzebne są następujące zasady:

Końcowe zwarte gardłowe, retrofleksyjne, dziąsłowe i wargowe (tj. nie nosowe i nie palatalne).

::: no-header

|   |   |
| :--- | :--- |
| **w pauzie i przed głosami bezdźwięcznymi** | **Zastąpienie odpowiadającym im bezdźwięcznym nieaspirowanym głosem:** :br **np.** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **przed głosami dźwięcznymi, nienosowymi** | **Zastąpienie odpowiadającym im dźwięcznym nieaspirowanym głosem:** :br **np.** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **przed nosowymi** | **Zastąpienie odpowiadającym im nosem:** :br **np.** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::
Wyjątek od powyższej zasady:

> Końcowy zwarty dziąsłowy (nie nosowy):

::: no-header

|   |   |
| :--- | :--- |
| **przed palatalnym** | **Zastąpienie odpowiednim nieaspirowanym palatalnym:** :br **tzn.** :br :indent -t + c- » -cc- :br :indent -d + c- » -cc- :br :indent -th + c- » -cc- :br :indent -dh + c- » -cc- :br :indent -t/-th/-d/-dh + ch- » -cch- :br :indent -t/-th/-d/-dh + j- » -jj- :br :indent -t/-th/-d/-dh + jh- » -jjh- |
| **+ ś** | **» -cś- lub -cch-** |
| **przed retrofleksywnym** | **Zastąpienie odpowiednim nieaspirowanym retrofleksywnym:** :br **tzn.** :br :indent -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- :br :indent -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **przed l-** | **Zastąpienie przez -l:** :br **tzn.** :br :indent -t/-th/-d/-dh + l- » -ll- |

:::
Przykłady:

⟪तद्⟫ + ⟪फल⟫ = ⟪तत्फल पुण्यवत्⟫ + ⟪ब्राह्मण⟫ = ⟪पुण्यवद्ब्राह्मण पुण्यवत्⟫ + ⟪नर⟫ = ⟪पुण्यवन्नर पुण्यवत्⟫ + ⟪पुरुष⟫ = ⟪पुण्यवत्पुरुष सत्यवत्⟫ + ⟪चैतन्य⟫ =⟪सत्यवच्चैतन्य सुखवत्⟫ + ⟪लोक⟫ = ⟪सुखवल्लोक पुत्रवत्⟫ + ⟪जन⟫ = ⟪पुत्रवज्जन बलवत्⟫ + ⟪शत्रु⟫ = ⟪बलवच्छत्रु⟫
