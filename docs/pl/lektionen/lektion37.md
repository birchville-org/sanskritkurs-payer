# Lekcja 37

## 37.1. Przysłówki (⟪क्रियाविशेषणम्⟫)

Przysłówki w sanskrycie tworzy się

1. poprzez formy przypadkowe rzeczowników i zaimków
2. za pomocą specjalnych przyrostków i końcówek

W pierwszym przypadku granica między żywą formą przypadkową a przysłówkiem jest płynna. Należą do nich jako przypadek szczególny przysłówki, które są zsztywniałymi, starożytnymi formami przypadkowymi, podczas gdy w deklinacji używa się innych form lub odpowiednich rzeczowników nie są już używane jako rzeczowniki.

## 37.2. Użycie przypadkowe w funkcji przysłówkowej

### 37.2.1. Biernik (⟪द्वितीया⟫)

::: grammar-box
Biernik (⟪द्वितीया⟫) może być używany przysłówkowo na pytania:

*   w jaki sposób?
*   jak długo?
*   dokąd?
*   itp.

Biernik może być używany przysłówkowo:

*   od rzeczowników  
Przykłady:  
⟪कामम्⟫ "według życzenia, zgodnie z wolą"  
⟪अर्थम्⟫ "ze względu na"

*   od przymiotników w rodzaju nijakim  
Przykłady:  
⟪सुखम्⟫ "łatwo, szczęśliwie"  
⟪नित्यम्⟫ "zawsze"
⟪साधु⟫ "właściwie, dobrze"

*   od zaimków w rodzaju nijakim  
Przykłady:  
⟪तद्⟫ "wtedy, dlatego"
⟪यद्⟫ "gdy, że"
⟪एतद्⟫ "tak, tutaj, teraz"
:::
### 37.2.2. Narzędnik (⟪तृतीया⟫)

::: grammar-box
Narzędnik (⟪तृतीया⟫) może być używany przysłówkowo na pytania:

*   czym?
*   za pomocą czego?
*   itp.

Narzędnik może być używany przysłówkowo:

*   od rzeczowników  
Przykłady:  
⟪अर्थेन⟫ "ze względu na"
⟪क्षणेन⟫ "w tej chwili, natychmiast" (od ⟪क्षण⟫ m. "chwila")

*   od przymiotników, często również w liczbie mnogiej  
Przykłady:  
⟪दूरेण⟫ "daleko, z daleka" (do ⟪दूर⟫ 3 "daleko, daleki od")
⟪उच्चैस्⟫ "wysoko, głośno" (do ⟪उच्च⟫ 3 "wysoki, podniesiony, głośny, ostry (o głosie)")
:::
### 37.2.3. Celownik (⟪चतुर्थी⟫)

::: grammar-box
Rzadko celownik (⟪चतुर्थी⟫) jest używany przysłówkowo na pytania:

*   z jakiego celu?
*   itp.

Przykład:
:::
::: indent
⟪अर्थाय⟫ "z powodu, dla..."
:::
### 37.2.4. Ablatyw (⟪पञ्चमी⟫)

::: grammar-box
Ablatyw (⟪पञ्चमी⟫) może być używany przysłówkowo na pytania:

*   dlaczego?
*   z powodu czego?
*   skąd?
*   itp.

Ablatyw może być używany przysłówkowo:

*   od rzeczowników  
np. ⟪बलात्⟫ "gwałtownie, z siłą"  

*   od przymiotników  
np. ⟪दूरात्⟫ "z daleka"  

*   od zaimków  
Przykłady:  
⟪कस्मात्⟫ "dlaczego"  
⟪अकस्मात्⟫ "nieoczekiwanie"
:::
### 37.2.5. Dopełniacz (⟪षष्ठी⟫)

::: grammar-box
Rzadko dopełniacz (⟪षष्ठी⟫) jest używany przysłówkowo na pytanie "po jakim czasie?"

np. ⟪चिरस्य⟫ "po długim czasie" (do ⟪चिर⟫ 3 "długi (czas)")
:::
### 37.2.6. Lokatyw (⟪सप्तमी⟫)

::: grammar-box
Lokatyw (⟪सप्तमी⟫) może być używany przysłówkowo na pytania:

*   gdzie?
*   w jakich okolicznościach?
*   itp.

Przykłady:
:::
::: indent
\-⟪अर्थे⟫ "z powodu"  
\-⟪कृते⟫ "dla"  
⟪दूरे⟫ "daleko"
:::
## 37.3. Użycie przysłówkowe nieistniejących już form przypadków

Przykłady:
::: indent
⟪जातु⟫ "w ogóle" (początkowo "z natury, z urodzenia", biernik lp. nijaki do ⟪जातु⟫ \<nieużywany już jako rzeczownik\>)

⟪तूष्णीम्⟫ "milcząc" (biernik lp. do nieużywanego już ⟪तूष्णी⟫ f. "milczenie")

⟪एवम्⟫ "tak" (do inaczej zaginionego rdzenia zaimkowego ⟪एव⟫ "jeden, jedyny")
:::
## 37.4. Tworzenie przysłówków z przyrostkami adwerbialnymi

::: grammar-box
Od rdzeni zaimekowych ⟪तद्⟫, ⟪इदम्⟫ oraz ⟪अ⟫-, ⟪यद्⟫, ⟪किम्⟫ lub ⟪कु⟫ można utworzyć przy użyciu następujących przyrostków adwerbialnych

*   \-⟪तस्⟫ (ablatyw)
*   \-⟪त्र⟫ (lokatyw)
*   \-⟪था⟫ (sposób)
*   \-⟪थम्⟫ (sposób)
*   \-⟪दा⟫ (czas)

odpowiednie zaimeczne przysłówki.
:::
::: grammar-box

| Przyrostek | Rdzeń zaimekowy | | | |
| :--- | :--- | :--- | :--- | :--- |
| | ⟪तद्⟫ | ⟪इदम्⟫ :br **⟪अ⟫-** | ⟪यद्⟫ | ⟪किम्⟫ :br **⟪कु⟫-** |
| **-⟪तस्⟫** :br(ablatyw) | ⟪ततस्⟫ :brstamtąd, na tym podstawie, dlatego | ⟪इतस्⟫ :br ⟪अतस्⟫ :brstąd, z tego powodu | ⟪यतस्⟫ :brskąd, z czego | ⟪कुतस्⟫ :bskąd?, dlaczego? |
| **-⟪त्र⟫** :br(lokatyw) | ⟪तत्र⟫ :brtam, tamże | ⟪अत्र⟫ :brtutaj | ⟪यत्र⟫ :brgdzie | ⟪कुत्र⟫ :brgdzie? |
| **-⟪था⟫** :br(sposób) | ⟪तथा⟫ :brtak | | ⟪यथा⟫ :braz jak | |
| **-⟪थम्⟫** :br(sposób) | | | | ⟪कथम्⟫ :brjak? |
| **-⟪दा⟫** :br(czas) | ⟪तदा⟫ :bwtedy, wówczas | | ⟪यदा⟫ :bkiedy (w momencie gdy) | ⟪कदा⟫ :bkiedy? |

:::
::: grammar-box
Innym przysłówkiem pytajnym jest: ⟪क्व⟫ "gdzie?"
:::

::: grammar-box

**Inne przyrostki adwerbialne**

| Przyrostek | |
| :--- | :--- |
| **-⟪वत्⟫** | można dołączyć do dowolnych rzeczowników, aby wyrazić znaczenie "według rodzaju, jak":brnp. ⟪पुत्रवत्⟫ "jak syn" |
| **-⟪तस्⟫** | do rzeczowników i zaimków. Zazwyczaj znaczenie ablatywne "skąd?", ale także "gdzie?", "dokąd?":brnp. ⟪आदितस्⟫ "od początku" |
| **-⟪धा⟫** | 1. W przysłówkach liczbowych w znaczeniu "-krotny", "-razy":brnp. ⟪द्विधा⟫ "dwukrotny":br2. w znaczeniu "w ten i ów sposób":brnp. ⟪समधा⟫ "w ten sam sposób" (do ⟪सम⟫ 3 "taki sam") |

:::
## 37.5. Złożenia przysłówkowe

### 37.5.1. Złożenia z przysłówkiem lub przypadkiem używanym adwerbialnie jako drugim członem

Przykład: ⟪सुचिरम्⟫ "bardzo długo (czas)"

### 37.5.2. Używane adwerbialnie ⟪बहुव्रीहि⟫

Przykład: ⟪रक्षार्थम्⟫ "w rodzaju kogoś, którego celem jest strzeżenie, w celu strzeżenia". Można to również uznać za należące do 5.1.: -⟪अर्थम्⟫ jako adwerbialny drugi człon.

### 37.5.3. Złożenia ⟪अव्ययीभाव⟫-

⟪अव्ययीभाव⟫ = "stale/niezdeklinowalne"

::: grammar-box
Złożenie ⟪अव्ययीभाव⟫ to złożenie adwerbialne, którego pierwszy człon jest indeklinowalny (przyimek wtórny, cząstka itp.), a drugi człon to rzeczownik przyjmujący końcówkę biernika liczby pojedynczej rodzaju nijakiego.

Przy rozkładzie złożenia pierwszy człon rządziłby drugim:

Przykłady:
:::
::: indent
⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = "przeciw ogniu"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "według sił"

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = "do przodu, naprzeciw"
:::
Szczególnie ważne są złożenia ⟪अव्ययीभाव⟫ z ⟪यथा⟫ "jak" jako pierwszym członem:

np. ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ = "jak życzenie, zgodnie z życzeniem, dowolnie"

## 37.7. Zaimek nieokreślony

::: grammar-box
Zaimki nieokreślone (zaimek nieokreślony) tworzy się przez dodanie

*   \-⟪चिद्⟫
*   \-⟪चन⟫
*   ⟪अपि⟫

do przypadka zaimek pytajny ⟪किम्⟫.

np.
:::
::: indent
⟪कश्चिद्⟫ = ⟪कश्चन⟫ = ⟪को ऽपि⟫ = "jakiś, ktoś"  
⟪कस्यचिद्⟫ = czyjś
:::
## 37.8. Zdanie pytające

::: grammar-box
"Kto?, jak?, co, dlaczego? po co?, dlaczego?  
Kto nie pyta, ten się głupi."

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

Motto Sesamstrasse, które jest dobrą wytyczną do życia i nauki sanskrytu
:::
Zobacz też [Lektion 4](lektion04.md).

Należy rozróżnić

*   pytania słowne (pytania uzupełniające)
*   zdania pytające

W przypadku pytań słownych zapytujemy o agens (⟪कर्तृ⟫), obiekt, czynność, okoliczności itp., np.

*   kto przychodzi?
*   co robi Rāma?
*   kogo słyszy?
*   jak mówi ona sanskryt?
*   gdzie jest matka?

W przypadku pytań zdaniowych zapytujemy o całą treść zdania, np.

*   czy Rāma idzie dzisiaj do Ofterdingen?
*   czy to prawda, że ... ?

### 37.8.1. Pytania słowne (pytania uzupełniające)

::: grammar-box
Schemat:

Zaimek pytajny/przysłówek pytający - zdanie
:::
Przykłady:
::: indent
⟪को ग्रामं गच्छति⟫ =  ⟪केन ग्रामो गम्यते⟫ = "Kto idzie do wioski?"

⟪किं बाला अधीयीरन्⟫ = "Co powinni uczyć się dzieci?"

⟪क्व रामो वसति⟫ = Gdzie mieszka Rāma?
:::

Rys.: ⟪किं बाला अधीयीरन्⟫
(Źródło obrazu: [Details](/pl/licenses#lekt3704))
:::
### 37.8.2. Pytania zdaniowe

::: grammar-box
Czasami tylko z kontekstu wynika, czy zdanie jest pytaniem.
:::
::: grammar-box
Schemat I:

Czasownik - reszta zdania
:::
Przykład:
::: indent
⟪गमिष्यति ब्राह्मणबालो गुरुम् ।⟫ "Czy braminowy chłopiec pójdzie do mistrza?"
:::
::: grammar-box
Schemat II:

Czastka pytająca (zwykle na początku zdania) - zdanie

Najważniejsze czastki pytające to:

*   ⟪अपि⟫

*   ⟪किम्⟫ (często sugeruje oczekiwanie na odpowiedź przeczącą)

*   ⟪कच्चिद्⟫


Te czastki odpowiadają znakowi zapytania.
:::
Przykład:
::: indent
⟪अपि सत्यम् ।⟫ "Czy to też jest prawdą?"

⟪किं शक्नोति ।⟫ "Czy on może?"

⟪कच्चित्क्षत्रियेण शत्रवो जिताः ।⟫ "Czy może Kṣatriya pokonał wrogów?"
:::
Uwaga: ⟪किम्⟫ może oznaczać nie tylko "co?", ale jako czastka pytająca również "dlaczego?, po co?". Szczególnie z narzędnikiem (⟪तृतीया⟫):
::: indent
⟪किं क्रोधेन ।⟫ "Po co gniew? Co zyskuje gniew? Czego ma być gniew?"
:::

## 37.10. Ćwiczenia

A) Odpowiedz na poniższe pytania po sanskrycie, używając słów podanych w nawiasach. Przetłumacz pytania.

Przykład: ⟪क आगच्छति⟫ (⟪राम⟫) ⟪।⟫ » ⟪राम आगच्छति । कस्मै ब्राह्मण्यन्नं ददौ ॥१॥⟫ (⟪भिक्षु⟫, ⟪बाला⟫, ⟪दास⟫, ⟪भगवन्त्⟫)

⟪क आर्यसत्यान्यजानात् ॥२॥⟫ (⟪बुद्ध⟫, ⟪शाक्यमुनि⟫)

⟪कुत्राग्निश्चीयते ॥३॥⟫ (⟪यज्ञस्थान⟫, ⟪मही⟫)

⟪कदा ब्राह्माणा घृतमग्नौ जुह्वति ॥४॥⟫ (⟪यज्ञकाल⟫, ⟪देवान् स्तु⟫ \<Absolutiv\>)

⟪कस्मान्मतिमतयः पुण्यं चक्रुः ॥५॥⟫ (⟪स्वर्गलोभ⟫, ⟪नरकभय⟫, ⟪भीतनरकता⟫)

⟪किमेव शस्त्रं छिनत्ति ॥६॥⟫ (⟪शरीर⟫, ⟪अजीव⟫)

⟪किंकामः शत्रुरार्यैः सह युयुधे ॥७॥⟫ (⟪धनं जि⟫)

⟪कया भिक्षुरादितः ॥८॥⟫ (⟪गुणवती शूद्रा⟫)

⟪कुतः सुपुनर्भवं गम्यते ॥९॥⟫ (⟪कृतपुण्यत्व⟫, ⟪सुनीति⟫)

⟪केन शूद्रा न काम्येत ॥१०॥⟫ (⟪द्विजाति⟫, ⟪ब्राह्मण⟫, ⟪साधु⟫)

⟪कस्याः पुत्र्रः कृष्ण आसीत् ॥१२॥⟫ (⟪देवकी⟫)

## 37.11. Ćwiczenie powtórkowe

Przetłumacz na sanskryt, używając wyłącznie form czasownika w czasie Perfekt:

Pewnego razu pewien starzec szedł do innej wioski i zmęczył się w drodze. Poszedł więc, aby odpocząć, pod mango rosnące po boku drogi. Na tym drzewie były dojrzałe owoce. Starzec ochłonął na nie. Ale nie mógł wspiąć się na drzewo i sięgnąć po owoce. Na szczęście na tym drzewie były jakieś małpy, które jadły owoce. Gdy je zobaczył, ucieszył się starzec. Co zrobił? Wziął kilka kamieni, wymierzył w małpy i rzucił. Rozgniewane małpy zerwały jakieś owoce i rzuciły nimi w starca. Starzec z radością wziął te owoce i poszedł do pożądanej okolicy. Oto los starca!
