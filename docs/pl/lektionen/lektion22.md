# Lekcja 22

## 22.1. Absolutyw (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

Jeśli w sanskrycie chce się wyrazić, że czynienie Agensa (⟪कर्तृ⟫) poprzedza inny czyn Agensa lub towarzyszy mu jako okoliczność, używa się absolutywu (⟪क्त्वा । ल्यप्⟫). Zatem

"gdy to zrobił, robi tamto"; "robi to, potem robi tamto"; "w wyniku tego robi tamto"; "przyszedłem, zobaczyłem i zwyciężyłem" itp.

Absolutyw jest przyimkiem czasownikowym, tzn. nie odmienia się przez czasy ani przypadki; ma jednak zawsze – z nielicznymi wyjątkami – tego samego Agensa (⟪कर्तृ⟫) jak czynienie, któremu czynienie oznaczone przez absolutyw poprzedza lub mu towarzyszy. Agens absolutywu stoi więc w mianowniku (⟪प्रथमा⟫) lub instrumentalnym (⟪तृतीया⟫).

Oprócz złożeń absolutyw jest jednym z najczęstszych środków wyrazu w sanskrycie.

Przy tłumaczeniu na niemiecki należy unikać ciągłego używania słowa "po tym jak". Należy zamiast tego stosować w języku niemiecku powszechne sposoby wyrażania czasowego następstwa.

**Schemat:**

(określenie bliższe absolutywu: okolicznik, dopełnienie itp.) - absolutyw - absolutyw - ... - absolutyw - ... Agens + zdanie czasownikowe (w stronie czynnej lub biernej)

:::
**Przykłady:**

::: indent
**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = konstrukcja bierna: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**
"Mężczyzna wchodzi do domu, widzi małą dziewczynkę i zwraca się do niej."

Liczba mnoga: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**
:::
## 22.2. Tworzenie absolutiwu

::: grammar-box
**Tworzenie absolutiwu**

*   Czasowniki bez przedrostka: absolutyw na **-tvā**
*   Czasowniki z przedrostkiem: absolutyw na **-ya** lub **-tya**
:::
### 22.2.1. Czasowniki bez przedrostka: absolutyw na -⟪त्वा⟫

::: grammar-box

**Tworzenie:**

(zwykle) stopa głęboka rdzenia w formie, jaką ma przed PPP + **-tvā** (**-⟪त्वा⟫**)

Tylko przeczące **a-** / **an-** współgra z sufiksem **-⟪त्वा⟫** : ⟪अकृत्वा⟫ "nie zrobiwszy"

:::
**Przykłady:**

::: indent
⟪आप्त्वा⟫ "po tym, jak on / ona / ono / ja / ty / my / wy / oni / my dwaj / wy dwaj / oni dwaj osiągnął / osiągnęła / osiągnęło"

⟪आसित्वा⟫ "po tym, jak on (...) siedział / jest"

⟪इत्वा⟫ "po tym, jak on (...) poszedł / jest"

⟪स्थित्वा⟫ "po tym, jak on (...) stał / jest"

⟪जित्वा⟫ "po tym, jak on (...) zwyciężył / zwyciężał"

⟪उक्त्वा⟫ "po tym, jak on (...) mówił / powiedział"
:::
### 22.2.2. Czasowniki z przedrostkiem

#### 22.2.2.1. Rdzenie na długi samogłoskę (oprócz -ā) lub spółgłoskę

::: grammar-box

**(zwykle) stopa głęboka rdzenia + -ya**

:::
**Przykłady:**

::: indent
⟪उपनीय⟫ "po tym, jak on (...) przyprowadził / przyprowadzał"

⟪प्रभूय⟫ "po tym, jak on (...) wystawał / wystąpił" "po tym, jak miał moc"

⟪प्राप्य⟫ "po tym, jak on (...) uzyskał / uzyskiwał"
:::
#### 22.2.2.2. Rdzenie na -ā

::: grammar-box

**niezmieniona stopa wysoka rdzenia + -ya**

:::
**Przykład:**

::: indent
⟪उपस्थाय⟫ "po tym, jak on (...) wszedł / wchodził" ; (ale bez przedrostka: ⟪स्थित्वा⟫)
:::
#### 22.2.2.3. Rdzenie, które w stopie głębkiej kończą się na krótkie -i, -u, -ṛ

::: grammar-box

**głęboka stopa rdzenia + -tya**

:::
**Przykłady:**

::: indent
⟪प्रस्तुत्य⟫ "po tym, jak (...) głośno chwalił / pochwalił"

⟪विस्मृत्य⟫ "po tym, jak (...) zapomniał / zapamiętał"

⟪संस्कृत्य⟫ "po tym, jak (...) przygotował do ofiary / był przygotowany"
:::
#### 22.2.2.4. Rdzenie kończące się na -am / -an, które w głębokiej stopie wygłaszają się na -a

::: grammar-box

**Opcjonalnie:**

Rdzeń na **-am** / **-an** + **-ya**

albo:

Rdzeń na **-a** + **-tya**

:::
**Przykład:**

::: indent
⟪विगम्य⟫ lub ⟪विगत्य⟫ "po tym, jak (...) minął / był"
:::
