# Pamoka 34

## 34.1. Perfektas (⟪लिट्⟫)

Klasikinėje sanskrito kalboje iš perfektinio kamieno yra tik indikatyvas ir dalyvis.

::: grammar-box
**Yra du perfektinio kamieno formavimo būdai:**
*   **reduplikuotas perfektas = ⟪द्वित्वलिट्⟫**
*   periphrastinis perfektas = ⟪अनुप्रयोगलिट्⟫
:::
::: grammar-box
**Periphrastinis perfektas (⟪अनुप्रयोगलिट्⟩) vartojamas:**
1. **išvestinėse konjugacijose (kauzatyvas, desideratyvas, frequentatyvas, denominatyvai)**
2. **šaknyse, kurios prasideda ilgąja balsė (išskyrus ā-), arba balsės (išskyrus a-) prieš dvi priebalses**
3. **keliuose kitose šaknyse**
:::
## 34.2. Reduplikuotas perfektas (⟪द्वित्वलिट्⟩)

### 34.2.1. Kamieno laipsnių kaita

::: grammar-box
**Formavimas:**

**Stiprusis kamienas:** vienaskaita Parasmaipada
*   **reduplikuotas aukštojo arba pailginto laipsnio šaknis + perfektinė galūnė**

**Silpnasis kamienas:** visos kitos formos
*   **reduplikuotas žemojo laipsnio šaknis + perfektinė galūnė**
:::
::: grammar-box
**Bendruoju atveju (taip pat ir už perfektinio) kamieno laipsnių kaitos neturi šaknys, sudarytos pagal formą:**
*   **(priebalsis)-priebalsis-ilgabalsė-priebalsis**
*   **(priebalsis)-priebalsis-balsė-priebalsis-priebalsis**

**Perfekto atveju, be to, kamieno laipsnių kaitos neturi šaknys, sudarytos pagal formą:**
*   **a-priebalsis**
*   **ā-priebalsis**
:::
### 34.2.2. Perfektinės galūnės

::: grammar-box

| | 3. vienaskaita | 3. daugiskaita |
| :--- | :--- | :--- |
| **Parasmaipada** | **-a** | **-ur** |
| **Ātmanepada** | **-e** | **-re** |
:::
### 34.2.4. Reduplication of roots beginning with a consonant

::: grammar-box
**For the reduplication of initial consonants, the rules given in [Lesson 33](lektion33.md) apply.**

**The reduplicative vowel for roots beginning with a consonant is the short root vowel.**

**Diphthongs before a consonant are reduced to the corresponding short low-grade vowel.**

**ṛ, ṝ, ḷ, and final diphthongs are reduplicated with -a-.**
:::
Examples:

::: grammar-box

| Root | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::
::: grammar-box
**Some roots beginning with y- or v- reduplicate with i- or u-, which "merges" with the root vowel in the weak forms.**
:::
Examples:

::: grammar-box

| Root | 3. sg. Perf. P. | 3. pl. Perf. P. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Reduplication of roots beginning with a vowel

::: grammar-box
**1. Initial a- and ā- are reduplicated with a-, resulting in ā-.**
:::
Examples:

::: grammar-box

| Root | 3. sg. Perf. P. |
| :--- | :--- |
| ⟪अस्⟫ 2 "sein" und ⟪अस्⟫ 4 "werfen" | ⟪आस⟫:bra + as-a |

:::

## 34.3. Types of the reduplicated perfect

Classification principle: Particularities of stem gradation:
*   Perfect without stem gradation: Type I
*   Perfect with stem gradation: Types II - V
*   irregular perfect formations

## 34.4. Perfect Type I: Perfect without stem gradation

::: grammar-box
**Perfect Type I (without stem gradation) are formed by roots of the types:**
*   **(Consonant)-Vowel-Long Vowel-Consonant**
*   **(Consonant)-Vowel-Vowel-Consonant-Consonant**
*   **a-Consonant**
*   **ā-Consonant**
:::
Examples:

::: grammar-box

| Root | 3. sg. Perf. | 3. pl. Perf. |
| :--- | :--- | :--- |
| ⟪बन्ध्⟫ 9P | ⟪बबन्ध⟫:brba-bandh-a | ⟪बबन्धुर्⟫ |
| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |
| ⟪आप्⟫ 5P | ⟪आप⟫:bra + āp-a | ⟪आपुर्⟫ |
| ⟪अस्⟫ 2P "to be":br⟪अस्⟫ 4 "to throw" | ⟪आस⟫:bra + as-a | ⟪आसुर्⟫ |
| ⟪अश्⟫ | ⟪आनशे⟫:brunregular reduplication! | ⟪आनशिरे⟫ |

:::
## 34.5. Perfect Type II: Strong stem full grade, weak stem zero grade

::: grammar-box
**Formed by roots of the form:**
*   **(Consonant)-(Consonant)-i/u/ṛ/ḷ-Consonant**

**Formation:**
*   **strong stem: full grade**
*   **weak stem: zero grade**
:::
Examples:

::: grammar-box

| Root | 3. sg. Perf. P. | 3. pl. Perf. P. | 3. sg. Perf. Ā. | 3. pl. Perf. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪भिद्⟫ | ⟪बिभेद⟫ | ⟪बिभिदुर्⟫ | ⟪बिभिदे⟫ | ⟪बिभिदिरे⟫ |
| ⟪इष्⟫ | ⟪इयेष⟫ | ⟪ईषुर्⟫ | | |
| ⟪मुच्⟫ | ⟪मुमोच⟫ | ⟪मुमुचुर्⟫ | ⟪मुमुचे⟫ | ⟪मुमुचिरे⟫ |
| ⟪वृत्⟫ | | | ⟪ववृते⟫ | ⟪ववृतिरे⟫ |
