# Pamoka 55

## 55.1. a-aoristas (aoristas su teminiu balsiu)

::: grammar-box
**a-aoristas sudaromas kaip imperfektas (⟪लङ्⟫) iš 6-osios presento klasės (⟪तुदादि⟫), t. y.:**

**Augmentas + žemojo laipsnio šaknis + a + antrinė galūnė**

**-a- tais atvejais, kai imperfekte keičiasi į -ā-.**

**Nėra nosinės infixų.**

**Ātmanepada retas; abipusėms šaknims jis dažniausiai sudaromas pagal kitas aoristo klases (žr. Kielhorn, Gramatika §340 ir toliau atitinkamose aoristo klasėse).**

**Šaknų, turinčių šį aoristą, sąrašas: Kielhorn, Gramatika §340.**
:::
