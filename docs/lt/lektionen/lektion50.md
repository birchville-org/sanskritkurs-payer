# Pamoka 50

## 50.1. Daiktavardžių darymas: reguliarus laipsniavimas

::: grammar-box
**Reguliarus laipsniavimas sanskrite atliekamas su ⟪तद्धित⟫ priesagomis**
* **-⟪तर⟫ (moter. g.: ⟪तरा⟫) "komparatyve"**
* **⟪तम⟫ (moter. g.: ⟪तमा⟫) "superlatyve"**

**Šios priesagos pridedamos prie daiktavardžių vyriškosios giminės kamieno. Esant kamienų kaitai, jos pridedamos prie silpnojo kamieno, kuris turi formą kaip prieš -su lokatyvo (⟪पञ्चमी⟩) daugiskaitos priesagą.**
:::
::: media
![](/images/lekt5007.webp)
Pav.: ⟪लोकस्योत्तमो गिरिः सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = Mount Everest
(Nuotraukos šaltinis: [Išsamiau](/lt/licenses#lekt5007))
:::

::: grammar-box
**Reikšmė:**

**"Komparatyvas" reiškia, kai nėra išreiškiamo lyginamojo daikto: "pakankamai, labai, per daug":**

:::
::: indent
pvz. ⟪सुचितर⟫ 3 "pakankamai švarus", "labai švarus", "per daug švarus"
:::
**Jei išreiškiamas lyginamasis daiktas, jis stovi abliatyve (⟪पञ्चमी⟩). Komparatyvas + abliatyvas atitinka laipsniavimą su "nei" vokiečių kalboje.**

::: indent
pvz. ⟪देवदत्ताद्रामो धीमत्तरः⟫ = žodž.: "žiūrint iš Devadattos perspektyvos, Rāma yra protingesnis" = "Rāma yra protingesnis nei Devadatta"
:::
**"Superlatyvas" reiškia, jei nėra išreiškiamo lyginamojo daikto: "ypač, labai":**

::: indent
pvz. ⟪सत्तम⟫ 3 (iš ⟪सन्त्⟫) "ypač geras, labai geras"
:::
**Jei išreiškiamas lyginamasis daiktas, jis stovi genityve (⟪षष्ठी⟩) ("iš", "tarp"), o superlatyvas atitinka vokiečių kalbos superlatyvą (aukščiausią laipsnį):**

::: indent
pvz. ⟪द्विजानां सत्तमः⟫ = "geriausias iš dviejų kartų gimusių"
:::
**Priesagės -⟪तर⟫ ir -⟪तम⟫ gali būti pridedamos ne tik prie daiktavardžių, bet ir prie būdvardžių, indeklinablių ir netgi veiksmažodinių formų:**

Pavyzdžiai:

::: indent
⟪गजतम⟫ m. "geriausias dramblys" (⟪गज⟫) (taip pat Budo titulas)

⟪गोतम⟫ m. "didžiausias jaujis" (⟪गो⟫) arba: "turtingiausias galvijais"

⟪उद्⟫ indekl. "į", "aukštyn" » ⟪उत्तर⟫ 3 "aukštesnis" » ⟪उत्तम⟫ 3 "aukščiausias"
:::
**Jei šios priesagos pridedamos prie veiksmažodinės formos, jos visada pasireiškia prieveiksmine forma:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

Pavyzdžiai:

::: indent
⟪पचतितराम्⟫ "jis/ji/ji gamina geriau"

⟪पचतितमाम्⟫ "jis/ji/ji gamina geriausiai"
:::
**Šią formą šios priesagos įgyja ir tada, kai jos pridedamos prie indeklinablio ir išvestinis žodis vartojamas prieveiksmiškai:**

::: indent
pvz. ⟪सुतराम्⟫ (nuo ⟪सु⟫) "geresniu būdu" (prieveiksmiškai)
:::
::: media
![](/images/lekt5006.webp)
Pav.: ⟪का पचतितमाम्⟫
Lisu = 傈僳族, ⟪अरुणाचल प्रदेश⟫
(Nuotraukos šaltinis: [Išsamiau](/lt/licenses#lekt5006))
:::
