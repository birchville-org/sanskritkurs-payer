## 41.2. Kitos ⟪कृत्⟩ formacijos su -a

### 41.2.1. Esamojo laiko dalyvis (⟪लडादेशः⟩) Ā, esamojo laiko dalyvis (⟪लडादेशः⟩) pasyvus, būsimosios laiko dalyvis (⟪ऌडादेशः⟩) Ā

#### 41.2.1.1. Teminiai esamojo laiko kamieniai, pasyvus ir būsimasis laikas

::: grammar-box
**Formavimas:**

Esamojo laiko kamienas / pasyvaus laiko kamienas / būsimosios laiko kamienas + -māna (mot. g. mānā)
:::
Pavyzdžiai:

⟪यज्⟩ 1U, es. dalyv. Ā ⟪यजमान⟩ 3 „tas, kas garbina savo naudai su aukojimu = aukotojas“

⟪मन्⟩ 4Ā, es. dalyv. Ā ⟪मन्यमान⟩ 3 „mąstantis“

⟪कृ⟩ 8U, es. dalyv. pasyvus ⟪क्रियमाण⟩ 3 „tai, kas daroma“

⟪दा⟩ 3U, būs. dalyv. Ā ⟪दास्यमान⟩ 3 „tas, kas duos savo naudai“

#### 41.2.1.2. Atėminiai esamojo laiko klasės

::: grammar-box
**Formavimas:**

Silpnasis esamojo laiko kamienas (toje formoje, kurią jis turi prieš galūnę -ate 3.dg. Ā) + -āna (mot. g. -ānā)

### 41.2.2. "Dalyvis" nuošimpos būtinybės (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Norint išreikšti nuošimpę būtinybę ("ką reikia/daryti"), galima pasirinktinai sudaryti daiktavardžius iš šaknų ir išvestinių veiksmažodžių kamienų su šiais priesagomis:**

* **-⟪तव्य⟫** (mot. g. **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (mot. g. **-⟪अनीया⟫**)
* **-⟪य⟫** (mot. g. **-⟪या⟫**)
* **-⟪त्य⟫** (mot. g. **-⟪त्या⟫**) (vietoj **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Priesaga -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Priesaga -⟪तव्य⟫ / -⟪तव्या⟫ pridedama prie šaknų ir išvestinių veiksmažodžių kamienų (pvz., kausatyvo) tuo pačiu būdu kaip ir infinityvo priesaga -⟪तुम्⟫ (žr. [23 pamoka](lektion23.md)), t.y.**

* **aukštojo laipsnio šaknis + ⟪तव्य⟫**

arba

* **aukštojo laipsnio šaknis + -i- + ⟪तव्य⟫**

**Kausatyve:**

* **kausatyvo kamienas su -ay + -i- + ⟪तव्य⟫**
:::
Pavyzdžiai:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | "tas, kurį reikia nugalėti; nugalėtinas" |
| ⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | "tai, kur reikia būti" |
| ⟪बुध्⟫ Kaus. | ⟪बोधयितव्य⟫ | "tas, kurį reikia pažadinti; pažadinimas" |

:::
#### 41.2.2.2. Priesaga -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Sudarymas:**

Aukštojo laipsnio šaknis + -⟪अनीय⟫ / -⟪अनीया⟫

**Kausatyvas ir 10. prezentų klasė:**

Šaknis, tokia, kokia pasireiškia kausatyvo kamienyje, be -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Pavyzdžiai:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "duodamas; tai, ką reikia duoti" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "nugalėtinas" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "daromas; tai, ką reikia daryti" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "ką reikia matyti; verta žiūrėti" |
| ⟪बुध्⟫ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "pažadinimas" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "ką reikia leisti duoti" |

:::
#### 41.2.2.3. The suffix -⟪य⟫ / -⟪या⟫

::: grammar-box
**Formation:**

Root (in weak, strong or guṇa grade) + -⟪य⟫

For the exact rules, see Kielhorn, Grammar of the Sanskrit Language, pp. 195 - 197!
:::
Treatment of final vowels:

::: grammar-box
**1. Roots ending in -ā form this gerundive on -eya**
:::
Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "to be known; that which must be recognized" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "that which must be given" |

:::
::: grammar-box
**2. Roots ending in -i /-ī / -u / -ū /-ṛ generally have strong or guṇa grade, unless they belong to those roots ending in -i / -u /-ṛ that form a gerundive with the suffix -⟪त्य⟫ (fem. -⟪त्या⟫) (list of these roots in Kielhorn, Grammar §537).**
:::
Example:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 | "that which must be remembered" |

:::
::: grammar-box
**2a. Roots ending in -i/-ī have strong grade**
:::
Examples:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | "to be sold; sellable" |
| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "to be led" |

:::
::: media
![lekt4103.jpg](/images/lekt4103.webp)
Fig.: ⟪विक्रेयाणि पुष्पानि⟫
(Image source: [Details](/lt/licenses#lekt4103))
:::

::: grammar-box
**2b. Roots ending in -u /-ū replace the strong grade -o before -ya with -av, and the guṇa grade -au with -āv. Guṇa grade formation in this case denotes necessity.**
:::
Example:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्तु⟫ 2U | ⟪स्तव्य⟫ 3 | "that which should be praised" |
|   | ⟪स्ताव्य⟫ 3 | "that which must necessarily be praised" |

:::
Pavyzdžiai for konsonantiniu pabaigiamus šaknis (taisyklės žr. Kielhorn, Gramatika § 533ff.):

#### 41.2.2.4. Galūnė -⟪त्य⟫ / ⟪त्या⟫ (vietoj -⟪य⟫ / -⟪या⟫)

::: grammar-box
Šaknų, baigiančiųsi -i / -u /-ṛ, sąrašas, kurios sudaro gerundyvą ne su -⟪य⟫ / -⟪या⟫, o su galūne -⟪त्य⟫ (moter. g. -⟪त्या⟫), žr. Kielhorn, Gramatika §537.

**Formavimas:**

žemo laipsnio šaknis + -⟪त्य⟫ / -⟪त्या⟫
:::
Pavyzdžiai:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "eina" |
| ⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "girdima" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "daroma" |

:::

### 41.2.4. Skirtumai vartojant gerundivo priesagas

::: grammar-box
Šių priesagų vartojimas iš esmės persikloja

* **-⟪तव्य⟫ (moter. g. -⟪तव्या⟫):** visada reiškia būtinybę ir dažniau vartojamas predikatyviai (rečiau epitetiškai). Žodžiai, sudaryti su šia priesaga, neturėtų būti naudojami daiktavardžių junginiuose (kompozituose).
* **-⟪अनीय⟫ (moter. g. -⟪अनीया⟫) ir -⟪य⟫ (moter. g. -⟪या⟫) / -⟪त्य⟫ (moter. g. -⟪त्या⟫) (vietoj -⟪य⟫/-⟪या⟫):** gali turėti papildomą reikšmę (ypač -⟪य⟫) vokiečių kalbos „-wert“ (pvz., „vertas dėmesio“) arba tik galimybės „-bar“ (⟪दृश्य⟫ „matomas“) prasme. Žodžiai, sudaryti su šiomis priesagomis, gali būti neigiami naudojant ⟪अ⟫-/-⟪अन्⟫- (bet ne žodžiai su -⟪तव्य⟫), ir egzistuoja ⟪तत्पुरुष⟫ kaip jų galinė dalis, kurią jie sudaro.
:::
### 41.2.5. Nėra ryšio su ⟪सु⟫- ir ⟪दुस्⟫-

::: grammar-box
Su ⟪सु⟫- ir ⟪दुस्⟫-, reiškiančiais „lengva“ arba „sunku“, gerindivai neturėtų būti jungiami. Vietoj to vartojami ⟪तत्पुरुष⟫ tipo žodžiai, pvz., ⟪सुकर⟫ 3 („lengva padaryti“) (žr. [18 pamoka](lektion18.md)).
:::
