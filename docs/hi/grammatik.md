# व्याकरण विषय

यह पृष्ठ संस्कृत पाठ्यक्रम के सभी व्याकरणिक विषयों का एक व्यवस्थित अवलोकन प्रदान करता है। यहाँ 61 पाठों में से प्रत्येक को विषयगत रूप से वर्गीकृत किया गया है।

## 1. ध्वनिविज्ञान एवं लिपि (संहिता एवं लिपि)

*   **ध्वनि परिचय**: व्यवस्था और उच्चारण → [पाठ 1](/hi/lektionen/lektion01)
*   **लिपि परिचय (देवनागरी)**:
    *   स्वर और सरल व्यंजन → [पाठ 40](/hi/lektionen/lektion40)
    *   संयुक्त व्यंजन (लिगेचर) → [पाठ 41](/hi/lektionen/lektion41) और [पाठ 42](/hi/lektionen/lektion42)
*   **संधि (ध्वनि संयोग)**:
    *   निष्ठागत **-स/विसर्ग** की संधि → [पाठ 2](/hi/lektionen/lektion02), [पाठ 3](/hi/lektionen/lektion03), [पाठ 30](/hi/lektionen/lektion30)
    *   **-म, -ए, -द** की संधि → [पाठ 4](/hi/lektionen/lektion04)
    *   **स्वरसंधि** → [पाठ 3](/hi/lektionen/lektion03), [पाठ 24](/hi/lektionen/lektion24)
    *   **-न** की संधि → [पाठ 7](/hi/lektionen/lektion07)
    *   **अनुनासिकों** के लिए संधि → [पाठ 21](/hi/lektionen/lektion21), [पाठ 26](/hi/lektionen/lektion26)
    *   मूर्धन्यीकरण (**n → ṇ / s → ṣ**) → [पाठ 10](/hi/lektionen/lektion10), [पाठ 26](/hi/lektionen/lektion26)
    *   शब्दसंधि (h-, ch-) → [पाठ 44](/hi/lektionen/lektion44), [पाठ 51](/hi/lektionen/lektion51)
    *   **व्यंजनसंधि** (सारांश) → [पाठ 16](/hi/lektionen/lektion16), [पाठ 43](/hi/lektionen/lektion43)
