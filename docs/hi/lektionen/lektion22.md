# पाठ 22

## 22.1. अप्सर्ग (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫)

:::grammar-box

यदि संस्कृत में यह व्यक्त करना चाहते हैं कि किसी कर্তा (⟪कर्तृ⟫) की किसी अन्य क्रिया से पूर्व या उसके साथ सहचरी अवस्था के रूप में होती है, तो अप्सर्ग का प्रयोग किया जाता है (⟪क्त्वा⟫ ⟪।⟫ ⟪ल्यप्⟫)। अतः

"उसने किया है, बाद में वह करता है" ; "वह करता है, फिर वह करता है" ; "इसके फलस्वरूप वह करता है" ; "मैं आया, देखा और जीता" आदि।

अप्सर्ग एक क्रियाविशेषण है, अर्थात न तो यह क्रियापद है और न ही विशेषण, परंतु हमेशा - कुछ अपवाद छोड़कर - उसी कर্তा (⟪कर्तृ⟫) को धारण करता है जिसकी क्रिया के पूर्व या उसके साथ वह होती है। अतः अप्सर्ग का कर্তा नैमित्तिक (⟪प्रथमा⟫) या करण (⟪तृतीया⟫) में होता है।

संयुक्त शब्दों के अतिरिक्त अप्सर्ग संस्कृत में सबसे सामान्य व्यक्तिकरण साधनों में से एक है।

जर्मन में अनुवाद करते समय लगातार "बाद में" कहने से बचें। इसके बजाय जर्मन में समयिक अनुक्रम के लिए प्रचलित व्यक्तिकरण साधनों का प्रयोग करें।

**आरेख:**

(अप्सर्ग के लिए निकटतम निर्धारण: अवस्था निर्धारण, वस्तु आदि) - अप्सर्ग - अप्सर्ग - ... - अप्सर्ग - ... कर্তा + क्रियावाक्य (क्रिया या निष्क्रिय में)

:::
**उदाहरण:**

:::indent
**⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरो⟫ ⟪वदति⟫** = निष्क्रिय संरचना: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरेणोद्यते⟫**  
"पुरुष घर में प्रवेश करता है, छोटी लड़की को देखता है और उसे संबोधित करता है।"

बहुवचन: **⟪गृहं⟫ ⟪प्रविश्य⟫ ⟪बालां⟫ ⟪दृष्ट्वा⟫ ⟪नरा⟫ ⟪वदन्ति⟫ ⟪।⟫**

## 22.2. निरपेक्ष कारक का निर्माण

:::grammar-box
**निरपेक्ष कारक का निर्माण**

*   उपसर्ग रहित क्रियाएँ: **-tvā** पर समाप्त होने वाला निरपेक्ष कारक
*   उपसर्ग युक्त क्रियाएँ: **-ya** या **-tya** पर समाप्त होने वाला निरपेक्ष कारक
:::
### 22.2.1. प्रत्यय-रहित क्रियापद: -⟪त्वा⟫ पर समापि

:::grammar-box

**निर्माण:**

(अधिकतर) गभीर-स्तरित धातु, उस रूप में, जो उस पर PPP से पूर्व होती है + **-tvā** (**-⟪त्वा⟫**)

केवल अपकारक **a-** / **an-** ही प्रत्यय **-⟪त्वा⟫** को सहन करते हैं: **⟪अकृत्वा⟫** "बिना किए हुए"

:::
**उदाहरण:**

:::indent
**⟪आप्त्वा⟫** "जब वह / वह / वह / मैं / तुम / हम / आप / वे / हम दोनों / आप दोनों / वे दोनों प्राप्त कर चुका / थी / था / हैं / थे"

**⟪आसित्वा⟫** "जब वह (...) बैठा / थी / था / है / थे"

**⟪इत्वा⟫** "जब वह (...) गया / थी / था / है / थे"

**⟪स्थित्वा⟫** "जब वह (...) खड़ा / थी / था / है / थे"

**⟪जित्वा⟫** "जब वह (...) विजयी हुआ / थी / था / है / थे"

**⟪उक्त्वा⟫** "जब वह (...) बोला / थी / था / है / थे"
:::
### 22.2.2. प्रत्यययुक्त क्रियापद

#### 22.2.2.1. दीर्घ स्वर (−ā को छोड़कर) या व्यंजन पर समाप्त होने वाली मूलधातुएँ

:::grammar-box

**(अधिकतर) गुणित स्तर की मूलधातु + −ya**

:::
**उदाहरण:**

:::indent
**⟪उपनीय⟫** "जब उसने (...) आगे बढ़ाया / था"

**⟪प्रभूय⟫** "जब उसने (...) बाहर निकला / था" "जब उसने (...) शक्ति प्राप्त की / थी"

**⟪प्राप्य⟫** "जब उसने (...) प्राप्त की / थी"
:::
#### 22.2.2.2. −ā पर समाप्त होने वाली मूलधातुएँ

:::grammar-box

**बदले बिना उच्च स्तर की मूलधातु + −ya**

:::
**उदाहरण:**

:::indent
**⟪उपस्थाय⟫** "जब उसने (...) कदम रखा / है" ; (लेकिन प्रत्यय के बिना: **⟪स्थित्वा⟫**)
:::
#### 22.2.2.3. गुणित स्तर में लघु −i, −u, −ṛ पर समाप्त होने वाली मूलधातुएँ

:::grammar-box

**गुणित स्तर की मूलधातु + −tya**

:::
**उदाहरण:**

:::indent
**⟪प्रस्तुत्य⟫** "जब उसने (...) प्रसिद्ध किया / था"

**⟪विस्मृत्य⟫** "जब उसने (...) भूल गया / था"

**⟪संस्कृत्य⟫** "जब उसने (...) यज्ञ के लिए तैयार किया / था"
:::
#### 22.2.2.4. −am / −an पर समाप्त होने वाली मूलधातुएँ, जो गुणित स्तर में −a पर समाप्त होती हैं

:::grammar-box

**वैकल्पिक:**

**−am** / **−an** पर समाप्त होने वाली मूलधातु + **−ya**

या:

**−a** पर समाप्त होने वाली मूलधातु + **−tya**

:::
**उदाहरण:**

:::indent
**⟪विगम्य⟫** या **⟪विगत्य⟫** "जब उसने (...) बीत गया / था"
:::
