**१. संबंधी वाक्य**

संबंधी वाक्य अक्सर मुख्य वाक्य के साथ कारण (कारण), अनुवर्ती (निष्कर्ष) या अंतिम (उद्देश्य) संबंध व्यक्त करते हैं।

कारण संयोजक के रूप में कार्य करने वाले संबंधी सर्वनाम के रूप:

*   अपादानवाचक:
*   ⟪⟪यतस्⟫⟫ ... उपवाक्य ... ⟪⟪ततस्⟫⟫ ... मुख्य वाक्य ... = "क्योंकि ..., इसलिए ..."
*   ⟪⟪यस्मात्⟫⟫ ... उपवाक्य ... ⟪⟪तस्मात्⟫⟫ ... मुख्य वाक्य ... = "क्योंकि ..., इसलिए ..."
*   करणवाचक:
*   ⟪⟪येन⟫⟫ ... उपवाक्य ... ⟪⟪तेन⟫⟫ ... मुख्य वाक्य ... = "जिससे/क्योंकि ..., उसी से / इसलिए ..."
:::
