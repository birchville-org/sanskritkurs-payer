# पाठ 54

निम्नलिखित वर्तमान काल या पूर्ण काल के रूपों के संगत अतीत काल के रूप बनाइए:

::: grammar-box
| क्र.सं. | रूप | निर्धारण / अर्थ | अतीत काल |
|:---|:---|:---|:---|
| ⟪१⟫. | **⟪यन्ति⟫** | वे जाते हैं | **⟪अगुः⟫** |
| ⟪२⟫. | **⟪पिबामि⟫** | मैं पीता हूँ | **⟪अपाम्⟫** |

| ⟪४⟫. | **⟪बभूव⟫** | मैं / तुम / वे थे / थे | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |

| ⟪१७⟫. | **⟪भिद्यते⟫** | उसे तोड़ा जाता है | **⟪अभेदि⟫** |
