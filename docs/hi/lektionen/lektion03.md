# पाठ 3

## 3.1. स्त्रीलिंग का एकवचन (नामकारक)

### 3.1.1. -s पर समाप्त होने वाला एकवचन (नामकारक)

निम्नलिखित नामप्रवर्ग, जो एक स्वर पर समाप्त होते हैं, भी -s पर अपना एकवचन (नामकारक) बनाते हैं:

::: grammar-box
- **-i** पर समाप्त होने वाले स्त्रीलिंग: उदा. **śruti** f. "श्रवण" -- Nom. sg.: **śrutis** = ⟪⟪श्रुतिस्⟫⟫
- **-u** पर समाप्त होने वाले स्त्रीलिंग: उदा. **dhenu** f. "गाय" -- Nom. sg.: **dhenus** = ⟪⟪धेनुस्⟫⟫
:::
### 3.1.2. बिना प्रत्यय के एकवचन (नामकारक)

बिना प्रत्यय के अपना एकवचन (नामकारक) बनाते हैं:

::: grammar-box
- **-ā** पर समाप्त होने वाले स्त्रीलिंग: उदा. **devatā** f. "देवता" -- Nom. sg.: **devatā** = ⟪⟪देवता⟫⟫
- **-ī** पर समाप्त होने वाले स्त्रीलिंग: उदा. **devī** f. "देवी" -- Nom. sg.: **devī** = ⟪⟪देवी⟫⟫
:::
::: important
**सावधान!** इसके अलावा, -ī पर समाप्त होने वाले एक-अक्षरीय स्त्रीलिंग मूलनाम हैं, जिनका एकवचन (नामकारक) -s पर समाप्त होता है: उदा. dhī f. "विचार" -- Nom. sg.: dhīs = ⟪⟪धीस्⟫⟫। इसी प्रकार, lakṣmī (⟪⟪लक्ष्मी⟫⟫) f., tarī (⟪⟪तरी⟫⟫) f. "नाव" और tantrī (⟪⟪तन्त्री⟫⟫) f. "तार" अनियमित रूप से -s पर अपना एकवचन (नामकारक) बनाते हैं: lakṣmīs = ⟪⟪लक्ष्मीस्⟫⟫।
:::

## 3.2. पुल्लिंग से स्त्रीलिंग का निर्माण

::: grammar-box
**-a** पर समाप्त होने वाले पुल्लिंग:
- **-ā** पर समाप्त होने वाला स्त्रीलिंग: उदा. **kṣatriya** m. » **kṣatriyā** f. "क्षत्रिय महिला" = ⟪⟪क्षत्रिया⟫⟫
- **-ī** पर समाप्त होने वाला स्त्रीलिंग: उदा. **brāhmaṇa** m. » **brāhmaṇī** f. "ब्राह्मण महिला" = ⟪⟪ब्राह्मणी⟫⟫

**-u** पर समाप्त होने वाले पुल्लिंग:
- **-ī** पर समाप्त होने वाला स्त्रीलिंग: उदा. **sādhu** m. » **sādhvī** f. (सुंदर, संत) = ⟪⟪साध्वी⟫⟫
(**-u-** स्वर से पहले **-v-** बन जाता है, इसलिए **-u- + -ī** » **-vī**)
:::

## 3.3. पुल्लिंग और स्त्रीलिंग का बहुवचन (नामकारक)

::: grammar-box
पुल्लिंग और स्त्रीलिंग के बहुवचन (नामकारक) का प्रत्यय **-as** है।
- **-a** पर समाप्त होने वाले पुल्लिंग: **deva- + -as** » **devās** = ⟪⟪देवास्⟫⟫
- **-ā** पर समाप्त होने वाले स्त्रीलिंग: **devatā- + -as** » **devatās** = ⟪⟪देवतास्⟫⟫
- **-i** पर समाप्त होने वाले पुल्लिंग: **kavi-** » **kave- + -as** » **kavayas** = ⟪⟪कवयस्⟫⟫
- **-i** पर समाप्त होने वाले स्त्रीलिंग: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪⟪श्रुतयस्⟫⟫
- **-ī** पर समाप्त होने वाले स्त्रीलिंग: **devī- + -as** » **devyas** = ⟪⟪देव्यस्⟫⟫
- **-u** पर समाप्त होने वाले पुल्लिंग: **guru-** » **guro- + -as** » **guravas** = ⟪⟪गुरवस्⟫⟫
- **-u** पर समाप्त होने वाले स्त्रीलिंग: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪⟪धेनवस्⟫⟫
:::
टिप्पणी: **e** स्तर उच्च स्तर (**guṇa**) है **i** का, **o** स्तर उच्च स्तर है **u** का।


## 3.4. वokalसंधि (स्वर संधि)

::: grammar-box
**सरल स्वर, जो या तो अलग हैं या केवल अपनी लंबाई में भिन्न हैं, संगत दीर्घ स्वर में "विलीन" हो जाते हैं:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::
उदा.

devatā + annapūrṇā » devatānnapūrṇā "अन्नपूर्णा एक देवता हैं" = ⟪⟪देवतान्नपूर्णा⟫⟫

> (अन्नपूर्णा भोजन और रसोई की देवी हैं, वे शिव की पत्नी पार्वती के अवतार माने जाती हैं।)

devī + indrāṇī » devīndrāṇī "इन्द्राणी एक देवी हैं" = ⟪⟪देवीन्द्राणी⟫⟫

> (इन्द्राणी देवता इन्द्र की पत्नी हैं।)

**सरल स्वर (-a / -ā को छोड़कर) असमान स्वरों के पहले संबंधित अर्धस्वर द्वारा प्रतिस्थापित होते हैं:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**

## 3.6. शब्दावली

**निम्नलिखित शब्दों को याद करें:**

**śruti** f. = ⟪⟪श्रुति⟫⟫ : श्रवण, शाश्वत परंपरा (वेदों और ब्राह्मणों के लिए संकेत)।

**smṛti** f. = ⟪⟪स्मृति⟫⟫ : स्मरण, याद, ध्यानपूर्ण स्मरण = सतर्कता, परंपरा (**śruti** का विपरीत शब्द)। इसमें शामिल हैं:
- छह **vedāṅga** n. (⟪⟪वेदाङ्ग⟫⟫)
1. **śikṣā** f. (⟪⟪शिक्षा⟫⟫): सही उच्चारण
2. **chandas** n. (⟪⟪छन्दस्⟫⟫): छंद
3. **vyākaraṇa** n. (⟪⟪व्याकरण⟫⟫): व्याकरण
4. **nirukta** n. (⟪⟪निरुक्त⟫⟫) : शब्द व्याख्या, etymology
5. **jyotiṣa** n. (⟪⟪ज्योतिष⟫⟫) : खगोल विज्ञान, कैलेंडर सिद्धांत
6. **kalpa** m. (⟪⟪कल्प⟫⟫) : अनुष्ठान
- **śrautasūtra** n. (⟪⟪श्रौतसूत्र⟫⟫) : बड़े यज्ञों के निष्पादन के लिए पाठ्य
- **gṛhyasūtra** n. (⟪⟪गृह्यसूत्र⟫⟫) : दैनिक जीवन के अनुष्ठानों और यज्ञों के लिए पाठ्य
- **dharmasūtra** n. (⟪⟪धर्मसूत्र⟫⟫) और **dharmaśāstra** n. (⟪⟪धर्मशास्त्र⟫⟫) : कानून और रीति-रिवाजों के लिए पाठ्य (सही व्यवहार)
- महान महाकाव्य **mahābhārata** n. (⟪⟪महाभारत⟫⟫) और **rāmāyaṇa** n. (⟪⟪रामायण⟫⟫)
- **purāṇa** n. (⟪⟪पुराण⟫⟫)
- **nītiśāstra** n. (⟪⟪नीतिशास्त्र⟫⟫) : जीवन की बुद्धिमत्ता के लिए पाठ्य

**smṛti** विशेष रूप से धर्म ग्रंथों के लिए संकेत भी है।

**dhenu** f. = ⟪⟪धेनु⟫⟫ : (दूध) गाय।

**paśu** m. = ⟪⟪पशु⟫⟫ : पालतू उपयोगी जानवर, मवेशी (समुच्चय)।

**devatā** f. = ⟪⟪देवता⟫⟫ : देवता (अमूर्त और मूर्त)।

**brāhmaṇī** f. = ⟪⟪ब्राह्मणी⟫⟫ : ब्राह्मण स्त्री।

**kṣatriyā** f. = ⟪⟪क्षत्रिया⟫⟫ : नरेश की स्त्री।

**kṣatriyī** f. = ⟪⟪क्षत्रियी⟫⟫ : क्षत्रिय की पत्नी।

**vaiśyā** f. = ⟪⟪वैश्या⟫⟫ : वैश्य स्त्री।

**śūdrā** f. = ⟪⟪शूद्रा⟫⟫ : शूद्र स्त्री।

**śūdrī** f. / **śūdrāṇī** f. = ⟪⟪शूद्री⟫⟫ ⟪⟪शूद्राणी⟫⟫ : शूद्र की पत्नी।

**devī** f. = ⟪⟪देवी⟫⟫ : देवी, विशेष रूप से Durgā f. = ⟪⟪दुर्गा⟫⟫, शिव की पत्नी = ⟪⟪शिव⟫⟫।

:::
**sādhvī** f. = ⟪⟪साध्वी⟫⟫ : स्त्रीलिंग, sādhu से।

**gurvī** f. = ⟪⟪गुर्वी⟫⟫ : स्त्रीलिंग, guru से।

**asmitā** f. = ⟪⟪अस्मिता⟫⟫ : "मैं-होना", अर्थात (गलत) विश्वास: **मैं** ही देखता हूँ आदि।

**ānvīkṣikī** f. = ⟪⟪आन्वीक्षिकी⟫⟫ : दर्शनशास्त्र (वह विद्या जो तार्किक रूप से सही आधारों के माध्यम से अपने निष्कर्षों तक पहुँचती है)।

**upekṣā** f. = ⟪⟪उपेक्षा⟫⟫ : उपेक्षा, समभाव।

**karuṇā** f. = ⟪⟪करुणा⟫⟫ : करुणा, दया।

**muditā** f. = ⟪⟪मुदिता⟫⟫ : प्रसन्नता, विशेष रूप से परितोष (ईर्ष्या के विपरीत)।


## 3.7. अभ्यास

**A) निम्नलिखित वाक्यों को बहुवचन में बदलें:**

1. dvijo brāhmaṇaḥ = ⟪⟪द्विजो⟫⟫ ⟪⟪ब्राह्मणः⟫⟫
2. dvijaḥ kṣatriyaḥ = ⟪⟪द्विजः⟫⟫ ⟪⟪क्षत्रियः⟫⟫
3. dvijo vaiśyaḥ = ⟪⟪द्विजो⟫⟫ ⟪⟪वैश्यः⟫⟫
4. gurur brāhmaṇaḥ = ⟪⟪गुरुर्ब्राह्मणः⟫⟫
5. sādhur guruḥ = ⟪⟪साधुर्गुरुः⟫⟫
6. guruḥ kaviḥ = ⟪⟪गुरुः⟫⟫ ⟪⟪कविः⟫⟫
7. sādhvī brāhmaṇī = ⟪⟪साध्वी⟫⟫ ⟪⟪ब्राह्मणी⟫⟫
8. devatā guruḥ = ⟪⟪देवता⟫⟫ ⟪⟪गुरुः⟫⟫
9. paśur dhenuḥ = ⟪⟪पशुर्धेनुः⟫⟫
10. gurvī sādhvī = ⟪⟪गुर्वी⟫⟫ ⟪⟪साध्वी⟫⟫

**B) शब्द डालकर नामवाक्य बनाएं:**

1. śrutis ... (veda) = ⟪⟪श्रुतिस्⟫⟫ ... ⟪⟪वेद⟫⟫
2. paśus ... (dhenu) = ⟪⟪पशुस्⟫⟫ ... ⟪⟪धेनु⟫⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪⟪देवी⟫⟫ ... ⟪⟪दुर्गा⟫⟫, ⟪⟪उमा⟫⟫, ⟪⟪इन्द्राणी⟫⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪⟪देवता⟫⟫ ... ⟪⟪मीनाक्षी⟫⟫, ⟪⟪अन्नपूर्णा⟫⟫
5. śūdrā ... (itarā) = ⟪⟪शूद्रा⟫⟫ ... ⟪⟪इतरा⟫⟫

**C) स्त्रीलिंग में अनुवाद करें:**

1. gurur brāhmaṇaḥ = ⟪⟪गुरुर्ब्राह्मणः⟫⟫
2. sādhur guruḥ = ⟪⟪साधुर्गुरुः⟫⟫
3. kṣatriyaḥ sādhuḥ = ⟪⟪क्षत्रियः⟫⟫ ⟪⟪साधुः⟫⟫

**D) संस्कृत में अनुवाद करें:**

1. उमा एक देवी हैं।
वेद श्रुति है।
शिक्षिकाएँ देवियाँ हैं।
दूध देने वाली गायें पालतू जानवर हैं।
कवि शिक्षक हैं।
क्षत्रिय द्विज हैं।
पवित्र पुरुद्र शूद्र हैं।
