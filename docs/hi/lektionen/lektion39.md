# पाठ 39

## 39.1. प्रथमपुरुष के विभक्तिप्रत्यय (***⟪तृतीयः⟫*** ⟪पुरुषः⟫ = "***तृतीय*** पुरुष")

प्रथमपुरुष के प्रत्यय (***⟪तृतीयः⟫*** ⟪पुरुषः⟫ = "***तृतीय*** पुरुष") ये हैं:

:::grammar-box

| | **⟪परस्मैपदम्⟫** || **⟪आत्मनेपदम्⟫** ||
| :--- | :---: | :---: | :---: | :---: |
| | **⟪एकवचनम्⟫** | **⟪बहुवचनम्⟫** | **⟪एकवचनम्⟫** | **⟪बहुवचनम्⟫** |
| **विषम-प्रत्यय विषम-पद** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **विषम-प्रत्यय अविषम-पद** | ^^ | ^^ | **-e** | ^^ |
| **द्वितीय-प्रत्यय विषम-पद** | **-m** | **-ma** | **-i** | **-mahi** |
| **द्वितीय-प्रत्यय अविषम-पद** | **-am** | ^^ | ^^ | ^^ |
| **आशीर्वाद-प्रत्यय** | ^^ | ^^ | **-a** | ^^ |
| **पूर्ण-प्रत्यय** | **-a** | ^^ | **-e** | **-mahe** |

:::
1 टिप्पणी: वास्तव में, विषम-पदों का विषम-प्रत्यय Ā भी -e के रूप में माना जाता है, जिसके पहले विषम-स्वर -a- समानता के कारण गिर जाता है। प्रभाव यह होता है, मानो प्रत्यय -i विषम-स्वर -a- से जुड़ता है: a + i » e.
