# पाठ 39

## 39.1. प्रथम पुरुष के व्यक्तिप्रत्यय (:sig[⟪तृतीयः⟫] ⟪⟪पुरुषः⟫⟫ = "**तृतीय** पुरुष")

प्रथम पुरुष के व्यक्तिये (:sig[⟪⟪तृतीयः⟫⟫] ⟪⟪पुरुषः⟫⟫ = "**तृतीय** पुरुष") ये हैं:

::: grammar-box

| | ⟪⟪परस्मैपदम्⟫⟫ || ⟪⟪आत्मनेपदम्⟫⟫ ||
| :--- | :---: | :---: | :---: | :---: |
| | ⟪⟪एकवचनम्⟫⟫ | ⟪⟪बहुवचनम्⟫⟫ | ⟪⟪एकवचनम्⟫⟫ | ⟪⟪बहुवचनम्⟫⟫ |
| **प्रथमिक प्रत्यय विषम स्तम्भ** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **प्रथमिक प्रत्यय अविषम स्तम्भ** | ^^ | ^^ | **-e** | ^^ |
| **द्वितीयक प्रत्यय विषम स्तम्भ** | **-m** | **-ma** | **-i** | **-mahi** |
| **द्वितीयक प्रत्यय अविषम स्तम्भ** | **-am** | ^^ | ^^ | ^^ |
| **आशावाचक प्रत्यय** | ^^ | ^^ | **-a** | ^^ |
| **पूर्णकालिक प्रत्यय** | **-a** | ^^ | **-e** | **-mahe** |

:::
¹ टिप्पणी: वास्तव में, विषम स्तम्भों के लिए प्रथमिक प्रत्यय Ā भी -e के रूप में माना जाता है, जिसके पहले विषम स्वर -a- समानता के कारण गायब हो जाता है। लेकिन प्रभाव यह होता है, जैसे कि अंत -i विषम स्वर -a- से जुड़ जाए: a + i » e.

::: grammar-box
**नियम:**
**-mi, -mas, -ma, -mahe, -mahi के पहले विषम स्वर -a- को -ā- से बदल दिया जाता है !!!**
:::
