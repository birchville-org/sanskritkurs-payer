## 58.6. Аорист 5: iṣ-аорист

iṣ-аорист образуется от всех корней класса seṭ, для которых явно не предписывается исключительно другая форма аориста.

Образование:

Аугмент + корень + i + s + безгласное (атематическое) вторичное окончание

!!! 2.l.e. и 3.l.e. восходят к формам на -īs и -īt !!! (Это возникло в результате переноса имперфекта от корней типа अब्रवीत्; таким образом, это фактически формы корневых аористов).

Суффикс образования основы + окончания iṣ-аориста звучат следующим образом:

| | परस्मैпदम् (действительный залог) | | आत्मनेपदъ (средний залог) | |
| :--- | :--- | :--- | :--- | :--- |
| | **Ед. ч.** | **Мн. ч.** | **Ед. ч.** | **Мн. ч.** |
| **1. तृतीयः (3-е лицо)** | -iṣam | -iṣma | -iṣi | -iṣmahi |
| **2. द्वितीयः (2-е лицо)** | -īs | -iṣṭa | -iṣṭhās | -idhvam / -iḍhvam (по выбору после -h или полугласного) |
| **3. प्रथमः (1-е лицо)** | -īt | -iṣur | -iṣṭa | -iṣata |

Форма корня:

*   Корни с кратким гласным перед простым согласным: усиленная ступень (гуна/вред) в परस्मैпдъ и высшая ступень (диред) в आत्मनेपдъ  
    Примеры:  
    बुध् 1U: 1.l.e.P а-бо-ди-шам  
    कॢप् 1Ā: 1.l.e.Ā а-кал-пи-ши  
     
*   Корни с конечным гласным:
    
    *   P: усиленная ступень (гуна/вред)
    *   Ā: высшая ступень (диред)
    
    Примеры:  
    पू 9U: 1.l.e.P а-па-ви-шам ; 1.l.e.Ā а-па-ви-ши  
     
    
*   Корни на -ar., -al, а также वद् 1P «говорить», व्रज् 1P «уходить»: P: усиленная ступень (гуна/вред)  
    Примеры:  
    चर् 1P: 1.l.e.P а-ча-ри-шам  
    वद् 1P: 1.l.e.P а-ва-ди-шам  
     
*   Другие корни формы (согл.-)согл.-a-согл.: в P по выбору усиленная ступень (гуна/вред) (не относится к корням на -h, -m, -y, а также некоторым другим корням)  
    Пример:  
    तन् 8U: 1.l.e.P а-та-ни-шам / а-та-а-ни-шам  
    но:  
    क्रम् 1U: 1.l.e.P а-кра-ми-шам

Параметры спряжения:

पू 9U «очищать»

::: indent
परस्मैपदम्आत्मनेपदम् एकवचनम्बहुवचनम्एकवचनम्बहुवचनम्**1. तृतीयः**अपाविषम्पाविष्मअपविषिअपविष्महि**2. द्वितीयः**अपावीस्अपाविष्टअपविष्ठास्अपविध्वम् / अपविढ्वम्**3. प्रथमः**अपावीत्अपाविषुर्अपविष्टपविषत
:::

बुध् 1U «пробуждаться, узнавать»

::: indent
परस्मैपदम् एकवचनम्बहुवचनम्**1. तृतीयः**अबोधिषम्अबोधिष्म**2. द्वितीयः**अबोधीस्अबोधिष्ट**3. प्रथमः**अबोधीत्अबोधिषुर्
:::

कॢप् 1Ā «быть подходящим»

::: indent
आत्मनेपदम् एकवचनम्बहुवचनम्**1. तृतीयः**अकल्पिषिअकल्पिष्महि**2. द्वितीयः**अकल्पिष्ठास्अकल्पिध्वम्**3. प्रथमः**अकल्पिष्टअकल्पिषत
:::

Особенности:

1.  У некоторых корней соединительный гласный -i- в आत्मनेपдъ может заменяться на -ī-. После ग्रह् 9U «захватывать» эта замена должна происходить как в P, так и в Ā:  
    а-гра-хи-шам, а-гра-хи-ши  
     
    
2.   Корни 8-го класса настоящего времени на -n (или -ṇ) могут иметь слабую ступень (нидха) во 2.3.l.e.Ā:  
    तन् 8U: 2.l.e.Ā а-та-ни-штхас / а-та-тхас (корневой аорист) ; 3.l.e. Ā а-та-ни-шт / а-та-т  
     
    
3.   दीप् 4Ā, जन् 4Ā и др. могут вместо 3.l.e. Ā принимать форму страдательного аориста:  
    а-ди-пи-шт / а-ди-пи ; а-джа-ништ / а-джа-ни  
     
    
4.   विज् 7P не имеет чередования гласных:  
    а-ви-джи́т
