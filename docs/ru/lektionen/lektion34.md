# Урок 34

## 34.1. Перфект (⟪लिट्⟫)

В классическом санскрите от основы перфекта существуют только изъявительное наклонение и причастие.

::: grammar-box
**Существует два способа образования перфекта:**
*   **редуплицированный перфект = ⟪द्वित्वलिट्⟫**
*   **перифразический перфект = ⟪अनुप्रयोगलिट्⟫**
:::
::: grammar-box
**Перифразический перфект (⟪अनुप्रयोगलिट्⟫) используется:**
1. **в производных спряжениях (каузатив, десидератив, фрекватив, денеминативы)**
2. **в корнях, начинающихся с долгого гласного (кроме ā-), либо с гласного (кроме a-) перед двумя согласными**
3. **в некоторых других корнях**
:::
## 34.2. Редуплицированный перфект (⟪द्वित्वलिट्⟫)

### 34.2.1. Степенная чередование основы

::: grammar-box
**Образование:**

**сильная основа:** единственное число, парасмайпада
*   **редуплицированная основа корня в сильной степени (гуна) или удлиненная форма + окончание перфекта**

**слабая основа:** все остальные формы
*   **редуплицированная основа корня в слабой степени (варга) + окончание перфекта**
:::
::: grammar-box
**В целом (и вне перфекта) не имеют степенной чередования корни формы:**
*   **(согласный)-Согласный-ДолгийГласный-Согласный**
*   **(согласный)-Согласный-Гласный-Согласный-Согласный**

**В перфекте, кроме того, не имеют степенной чередования корни формы:**
*   **a-Согласный**
*   **ā-Согласный**
:::
### 34.2.2. Окончания перфекта

::: grammar-box

| | 3 л. ед. ч. | 3 л. мн. ч. |
| :--- | :--- | :--- |
| **Парасмайпада** | **-a** | **-ur** |
| **Āтманепада** | **-e** | **-re** |

:::
### 34.2.3. Соединительный гласный -i-

::: grammar-box
**Перед окончанием 3 л. мн. ч. Ā (-re) всегда ставится соединительный гласный -i-, перед другими согласными окончаниями мн. ч. у большинства корней.**
:::
### 34.2.4. Редупликация корней, начинающихся на согласный

::: grammar-box
**Для редупликации согласных, стоящих в начале слова, действуют правила, изложенные в [Урок 33](lektion33.md).**

**Редупликационный гласный в корнях, начинающихся на согласный, — это краткий гласный корня.**

**Дифтонги перед согласным редуцируются до соответствующего краткого гласного низкого градации.**

**ṛ, ṝ, ḷ и дифтонги в конце слова редуплицируются с помощью -a-.**
:::
Примеры:

::: grammar-box

| Корень | 3 л. ед. ч. Перф. П. |
| :--- | :--- |
| ⟪भिद्⟫ | :sig[⟪बि⟫]⟪भेद⟫ |
| ⟪मुच्⟫ | :sig[⟪मु⟫]⟪मोच⟫ |
| ⟪भृ⟫ | :sig[⟪ब⟫]⟪भार⟫ |

:::
::: grammar-box
**Некоторые корни, начинающиеся на y- или v-, редуплицируются с помощью i- и u- соответственно, которые в слабых формах «сливаются» с гласным корня.**
:::
Примеры:

::: grammar-box

| Корень | 3 л. ед. ч. Перф. П. | 3 л. мн. ч. Перф. П. |
| :--- | :--- | :--- |
| ⟪वच्⟫ | ⟪उवाच⟫:bru-vāc-a | ⟪ऊचुर्⟫:bru + uc-ur |
| ⟪यज्⟫ | ⟪इयाज⟫:bri-yāj-a | ⟪ईजुर्⟫:bri + ij-ur |

:::
### 34.2.5. Редупликация корней, начинающихся на гласный

::: grammar-box
**1. Начальные a-, ā- редуплицируются с помощью a-, в результате чего появляется ā-.**
:::
Примеры:

::: grammar-box

| Корень | 3 л. ед. ч. Перф. П. |
| :--- | :--- |
| ⟪अस्⟫ 2 «быть» и ⟪अस्⟫ 4 «бросать» | ⟪आस⟫:bra + as-a |

:::
::: grammar-box
**2. Корни с начальным i- имеют в сильной основе редупликационный слог iy-, а в слабой основе — i-, который сливается с гласным корня, образуя ī-. Аналогично для начального u-.**
:::
Примеры:

::: grammar-box

| Корень | 3 л. ед. ч. Перф. П. | 3 л. мн. ч. Перф. П. |
| :--- | :--- | :--- |
| ⟪इ⟫ | ⟪इयाय⟫:briy + ai + a | ⟪ईयुर्⟫:bri + iy-ur |
| ⟪इष्⟫ | ⟪इयेष⟫:briy-eṣ-a | ⟪ईषुर्⟫:bri + iṣ-ur |

:::
::: grammar-box
**3. Корни, начинающиеся на a- перед двумя согласными или на ṛ-, имеют в качестве слога редупликации ān-**
:::
Примеры:

::: grammar-box

| Корень | 3 л. ед. ч. Перф. П. | 3 л. мн. ч. Перф. П. |
| :--- | :--- | :--- |
| ⟪अञ्ज्⟫ | ⟪आनञ्ज⟫ | ⟪आनञ्जुर्⟫ |
| ⟪एध्⟫ | ⟪आनर्ध⟫ | ⟪आनृधुर्⟫ |

:::
## 34.3. Типы редуплицированного перфекта

Принцип классификации: особенности чередования основы:
*   Перфект без чередования основы: Тип I
*   Перфект с чередованием основы: Тип II - V
*   нерегулярные образования перфекта

## 34.4. Перфект Тип I: Перфект без чередования основы

::: grammar-box
**Перфект Тип I (без чередования основы) имеют корни следующих типов:**
*   **(Согласный)-Согласный-Долгийгласный-Согласный**
*   **(Согласный)-Согласный-Гласный-Согласный-Согласный**
*   **a-Согласный**
*   **ā-Согласный**
:::
Примеры:

::: grammar-box

| Корень | 3 л. ед. ч. Перф. | 3 л. мн. ч. Перф. |
| :--- | :--- | :--- |
| ⟪बन्ध्⟫ 9P | ⟪बबन्ध⟫:brba-bandh-a | ⟪बबन्धुर्⟫ |
| ⟪जीव्⟫ 1P | ⟪जिजीव⟫ | ⟪जिजीवुर्⟫ |
| ⟪आप्⟫ 5P | ⟪आप⟫:bra + āp-a | ⟪आपुर्⟫ |
| ⟪अस्⟫ 2P "быть":br⟪अस्⟫ 4 "бросать" | ⟪आस⟫:bra + as-a | ⟪आसुर्⟫ |
| ⟪अश्⟫ | ⟪आनशे⟫:brunнерегулярная редупликация! | ⟪आनशिरे⟫ |

:::
## 34.5. Перфект Тип II: Сильная основа в сильной степени, слабая основа в слабой степени

::: grammar-box
**Образуется от корней формы:**
*   **(Согласный)-(Согласный)-i/u/ṛ/ḷ-Согласный**

**Образование:**
*   **сильная основа: сильная степень**
*   **слабая основа: слабая степень**
:::
Примеры:

::: grammar-box

| Корень | 3 л. ед. ч. притатив, действ. залога | 3 л. мн. ч. притатив, действ. залога | 3 л. ед. ч. притатив, страдат. залога | 3 л. мн. ч. притатив, страдат. залога |
| :--- | :--- | :--- | :--- | :--- |
| ⟪भिद्⟫ | ⟪बिभेद⟫ | ⟪बिभिदुर्⟫ | ⟪बिभिदे⟫ | ⟪बिभिदिरे⟫ |
| ⟪इष्⟫ | ⟪इयेष⟫ | ⟪ईषुर्⟫ | | |
| ⟪मुच्⟫ | ⟪मुमोच⟫ | ⟪मुमुचुर्⟫ | ⟪मुमुचे⟫ | ⟪मुमुचिरे⟫ |
| ⟪वृत्⟫ | | | ⟪ववृते⟫ | ⟪ववृतिरे⟫ |
| ⟪कॢप्⟫ | | | ⟪चकॢपे⟫ | ⟪चकॢपिरे⟫ |

:::
