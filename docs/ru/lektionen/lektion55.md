# Урок 55

## 55.1. Аорист на -a- (аорист с тематическим гласным)

::: grammar-box
**Аорист на -a- образуется как imperfect (⟪लङ्⟫) 6-го класса настоящего времени (⟪तुदादि⟫), т.е.:**

**Авгмент + корень в слабой степени + a- + вторичные окончания**

**Гласный -a- заменяется на -ā- в тех же падежах, что и в imperfect.**

**Без назального инфикса.**

**Атманепада встречается редко; для двупредметных корней она обычно образуется по другим классам аориста (см. Кильтхорн, Грамматика §340, а также ниже при соответствующих классах аориста).**

**Список корней, имеющих этот аорист, см. у Кильтхорна, Грамматика §340.**
:::
Пример:

⟪सिच्⟫ 6U "обрызгивать"

::: indent
|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| 1\. ⟪तृतीयः⟫ | ⟪असिचम्⟫ | ⟪असिचाम⟫ | ⟪असिचे⟫ | ⟪असिचामहि⟫ |
| 2\. ⟪मध्यमः⟫ | ⟪असिचस्⟫ | ⟪असिचत⟫ | ⟪असिचथास्⟫ | ⟪असिचध्वम्⟫ |
| 3\. ⟪प्रथमः⟫ | ⟪असिचत्⟫ | ⟪असिचन्⟫ | ⟪असिचत⟫ | ⟪असिचन्त⟫ |
:::
Нерегулярные образования:

::: indent
⟪अस्⟫ 4P "бросать": ***:sig[⟪आस्थम्⟫], :sig[⟪आस्थत्⟫]*** (объяснение см. Thumb-Hauschild §541,4)

⟪ख्या⟫ + ⟪आ⟫ 2P "рассказывать": ***:sig[⟪अख्यम्⟫], :sig[⟪अख्यत्⟫]***

⟪दृश्⟫ "видеть": ***:sig[⟪अदर्शम्⟫], :sig[⟪अदर्शत्⟫]*** (сильная степень!)
:::
Обратите внимание:

::: indent
⟪शास्⟫ 2P "приказывать": ⟪अशिषत्⟫ (регулярная слабая степень!)
:::
