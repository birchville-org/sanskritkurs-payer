# Урок 55

## 55.1. А-аорист (аорист с тематическим гласным)

А-аорист образуется аналогично имперфекту (लङ्) 6-го класса настоящего времени (तुदादि), а именно:

Аугмент + корень в слабой степени + a + вторичные окончания

Гласный -a- во всех падежах заменяется на -ā-, как и в имперфекте.

Никаких насадных инфиксов.

Атманепада встречается редко; к двупредметным (убхаяпада) корням она обычно образуется по правилам других классов аориста (см. Киельхорн, Грамматика §340, а также ниже, при рассмотрении соответствующих классов аориста).

Список корней, имеющих этот аорист, см. у Киельхорна, Грамматика §340.

Пример:

सिच् 6U "брызгать"

::: grammar-box
|   | परस्मैपदम् | आत्मनेपदम् | | |
| --- | --- | --- | | |
|   | एकवचनम् | बहुवचनम् | एकवचनम् | बहुवचनम् |
| 1\. तृतीयः | असिचम् | असिचाम | असिचे | असिचामहि |
| 2\. मध्यमः | असिचस् | असिचत | असिचथास् | असिचध्वम् |
| 3\. प्रथमः | असिचत् | असिचन् | असिचत | असिचन्त |
:::

Нерегулярные образования:

::: indent
अस् 4P "бросать": आस्थम्, आस्थत् (объяснение см. Thumb-Hauschild §541,4)

ख्या + आ 2P "рассказывать": अख्यम्, अख्यत्

दृश् "видеть": अदर्शम्, अदर्शत् (сильная степень!)
:::

Обратите внимание:

::: indent
शास् 2P "приказывать": अशिषत् (регулярная слабая степень!)
:::
