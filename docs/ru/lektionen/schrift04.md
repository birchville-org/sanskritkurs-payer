# Деванагари = ⟪देवनागरी⟫

## Практика письма 4

![](/images/schrift006.webp)

Ануспара ṃ: точка над буквой, предшествующая звуку: ⟪कं⟫ ⟪कां⟫ ⟪किं⟫ ⟪कीं⟫ ⟪कुं⟫ ⟪कूं⟫ ⟪कें⟫ ⟪कैं⟫ ⟪कों⟫ ⟪कौं⟫

Написание:

![](/images/schrift007.jpg)

Обратите внимание на обязательное написание hṛ: ⟪हृ⟫
