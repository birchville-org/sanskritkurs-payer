# Урок 20

## 20.1. Притяжательные составные слова = ⟪बहुव्रीहि⟫ м.

::: media
![](/images/lekt2004.webp)
Рис.: ⟪बहुव्रीहिः⟫ ⟪पुरुषः⟫
Джайпур = ⟪जोधपुर⟫
(Источник изображения: [Подробности](/ru/licenses#lekt2004))
:::
⟪बहुव्रीहिः⟫ = ⟪बहवो⟫ ⟪व्रीहयो⟫ ⟪यस्य⟫ ⟪सः⟫ = «тот, кто обладает большим количеством риса»

::: grammar-box

**В отличие от Татпурushi, Бхуврихи обозначает нечто иное, чем выражено его членами: в то время как ⟪बालपुत्रः⟫ как Татпурushi раскрывается как «молодой сын», то есть то, что выражено последним членом составного слова (⟪पुत्र⟫), ⟪बालपुत्रः⟫ как Бхуврихи раскрывается как «тот, чей сын молод», то есть обозначаемое ни есть сын (⟪पुत्र⟫), ни обязательно молод (⟪बाल⟫), а есть лицо, отличное от молодого сына, а именно его отец.**

**Притяжательные составные слова всегда являются прилагательными, которые, однако, могут быть субстантивированы. Поэтому грамматический род Бхуврихи зависит от того, на что относится Бхуврихи, а не от рода последнего члена составного слова.**

:::
::: grammar-box

**Схема раскрытия Бхуврихи:**

**1. Член обычно в именительном падеже (⟪प्रथमा⟫) ед. ч., двойственном или мн. ч. -- 2. Член в именительном падеже ед. ч., двойственном или мн. ч. -- Относительное местоимение в другом падеже, кроме именительного (обычно родительный падеж - ⟪षष्ठी⟫) и в роде и числе всего Бхуврихи -- Указательное местоимение в числе, падеже и роде всего Бхуврихи.**

:::
Примеры:

::: indent
⟪गतपापः⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪सः⟫ = «тот, чье зло ушло» = «тот, кто свободен от дурных поступков»

Акк. ед. ч. ⟪गतपापम्⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तम्⟫

Инстр. ед. ч. ⟪गतपापेन⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तेन⟫

Род. ед. ч. ⟪गतपापस्य⟫ = ⟪गतं⟫ ⟪पापं⟫ ⟪यस्य⟫ ⟪तस्य⟫

Имен. мн. ч. ⟪गतपापाः⟫ = ⟪गतानि⟫ ⟪पापानि⟫ ye⟪षां⟫ ⟪ते⟫

и т. д.

⟪अस्तमोहा⟫ = ⟪अस्तो⟫ ⟪मोहो⟫ ⟪यया⟫ ⟪सा⟫ = «(женщина), которая сбросила заблуждение»

⟪प्राप्तोदको⟫ ⟪ग्रामः⟫ = ⟪प्राप्तमुदकं⟫ ⟪यं⟫ s ⟪ग्रामः⟫ = «деревня, к которой подошла вода» = «деревня, угрожаемая наводнением»

⟪पुण्यवत्पुत्रः⟫ как Бхуврихи = ⟪पुण्यवान्पुत्रो⟫ ⟪यस्य⟫ ⟪सः⟫, или: ⟪पुण्यवन्तः⟫ ⟪पुत्रा⟫ ⟪यस्य⟫ ⟪सः⟫ = «тот, чей сын обладает заслугой» или: «тот, чьи сыновья обладают заслугой»
:::
::: grammar-box

**Отношение между первым и вторым членом может быть при Бхуврихи:**

*   **атрибутивное**
*   **аппозитивное**
*   **каузальное**
*   **адвербиальное**

**Как и при Татпурushi, более определенный член обычно стоит на втором месте.**

:::
Традиционно различают:

*   ⟪समानाधिकरणबहुव्रीहिः⟫ : в ⟪विग्रहवाक्य⟫ первый и второй члены стоят в одном и том же падеже

*   ⟪व्यधिकरणबहुव्रीहिः⟫ : в ⟪विग्रहवाक्य⟫ первый и второй члены стоят в разных падежах

## 20.2. Бахуврихи с атрибутивным передним членом

::: grammar-box

**Схема:**

:::
::: indent
**Прилагательное -- Имя существительное**
:::
**Пример:**

::: indent
⟪गुणवत्पुत्रो⟫ ⟪ब्राह्मणः⟫ =  ⟪गुणवान्पुत्रो⟫ ⟪यस्य⟫ ⟪स⟫ ⟪ब्राह्मणः⟫ = «брахман, чей сын / сыновья обладают хорошими качествами»
:::
**Особенно часто встречается атрибутивное определение с помощью причастия прошедшего времени (PPP), что редко для Татпурushi. При разложении местоимение обычно стоит в творительном падеже (⟪तृतीया⟫) (реже в родительном падеже / ⟪षष्ठी⟫).**

**Правило большого пальца:**

*   **PPP - Имя существительное = чаще всего Бахуврихи**
*   **Имя существительное -- PPP = чаще всего Татпурushi**

**Пример:**

::: indent
⟪कृतफल⟫ ⟪३⟫ = ⟪कृतं⟫ ⟪फलं⟫ ye⟪न⟫ ⟪सः⟫ ⟪।⟫ ⟪यया⟫ ⟪सा⟫ ⟪।⟫ ye⟪न⟫ ⟪तत्⟫ = «тот, кто / которая / что произвёл результат, кто-то / что-то эффективное»
:::
## 20.3. Бахуврихи с аппозитивным первым членом

::: grammar-box

**Схема:**

:::
::: indent
**Существительное -- Существительное**
:::
**Примеры:**

::: indent
⟪शूरपुत्रो⟫ ⟪नरः⟫ = ⟪शूरा⟫ ⟪एव⟫ ⟪पुत्रा⟫ ⟪यस्य⟫ ⟪स⟫ ⟪नरः⟫ = "мужчина, чьи сыновья — герои"

⟪तदन्त⟫ ⟪३⟫ = ⟪सो⟫ ⟪ऽन्तो⟫ ⟪यस्य⟫ ⟪सः⟫ ⟪।⟫ ⟪यस्याः⟫ ⟪सा⟫ ⟪।⟫ ⟪यस्य⟫ ⟪तत्⟫ = "тот, чей конец — это этот" = "оканчивающийся этим"
:::
::: grammar-box

**Очень важны бахуврихи с аппозитивным вторым членом ⟪आदि⟫ ⟪।⟫ ⟪आदिक⟫ ⟪।⟫ ⟪आद्य⟫ "первый, начало", реже ⟪प्रभृति⟫ "начало". Такие составные слова соответствуют значению "и т.д.":**

**Пример:**

:::
::: indent
⟪देवा⟫ ⟪इन्द्रादयः⟫ =  ⟪इन्द्र⟫ ⟪आदिर्येषां⟫ ⟪ते⟫ ⟪देवाः⟫ = "боги, чьим началом является Индра" = "боги Индра и т.д." = "Индра и остальные боги"
:::
**Для выражения значения "только" можно использовать бахуврихи со вторым членом ⟪मात्रा⟫ ж.р. "мера, граница":**

**Пример:**

::: indent
⟪शब्दमात्रम्⟫ = ⟪शब्दो⟫ ⟪मात्रा⟫ ⟪यस्य⟫ ⟪तत्⟫ = "то, чья мера — слово" = "только одно слово"
:::
**⟪मात्र⟫ после причастия прошедшего времени страдательного залога переводится как "как только":**

**Пример:**

::: indent
⟪जातमात्रं⟫ ⟪शत्रुं⟫ ⟪घ्नन्ति⟫ = ⟪जातं⟫ ⟪मात्रा⟫ ⟪यस्य⟫ ⟪तं⟫ ⟪शत्रुं⟫ ⟪घ्नन्ति⟫ = "они убивают врага, чья мера — возникновение" = "они убивают врага, как только он возник"
:::

## 20.4. Бахуврихи с каузальным первым членом

то есть Бахуврихи, чей первый член представляет собой падеж, отличный от именительного (⟪प्रथमा⟫).

Пример:

::: indent
⟪देवरूपा⟫ = ⟪देवस्यैव⟫ ⟪रूपं⟫ ⟪यस्याः⟫ ⟪सा⟫ = «женщина, чей облик есть облик божества» «женщина божественной красоты»
:::
::: grammar-box

**Исключение из общего правила о порядке компонентов состава:**

**Каузальный член стоит на втором месте, если он обозначает часть тела (в особенности руку):**

**Пример:**

:::
::: indent
⟪दण्डहस्तः⟫ =  ⟪दण्डो⟫ ⟪हस्ते⟫ (лок. ед. ч.) ⟪यस्य⟫ ⟪सः⟫ = «тот, в чьей руке находится палка» = «тот, кто носит палку в руке.»
:::
::: media
![](/images/lekt2001.webp)
Рис.: ⟪इन्द्रो⟫ ⟪वज्रपाणिः⟫
Сиемреап (ក្រុងសៀមរាប), Камбоджа, IX в. н. э.

## 20.5. Бахуврихи с наречным первым членом

В первом члене стоит наречие, предлог, префикс или другое неизменяемое слово; такие составные слова обычно являются ⟪नित्यसमास⟫.

Примеры:

::: indent
⟪अपुत्रो⟫ ⟪नरः⟫ = ⟪पुत्रो⟫ ⟪यस्य⟫ ⟪नास्ति⟫ ⟪स⟫ ⟪नरः⟫ = "мужчина, у которого нет сына" = "бессыновный мужчина"

⟪दुर्बल⟫ ⟪३⟫ = "тот, чья сила плоха" = "бессильный, слабый"
:::
::: grammar-box

**⟪सह⟫ "с" как первый член Бахуврихи часто заменяется на ⟪स⟫.**

**Пример:**

:::
::: indent
⟪सपुत्रः⟫ =  ⟪सहपुत्रः⟫ =  ⟪पुत्रेण⟫ ⟪सहितः⟫ ⟪।⟫ ⟪पुत्रेण⟫ ⟪सह्⟫ = "с сыном", "сопровождаемый сыном"
:::

## 20.6. Склонение конечного компонента Bahuvrīhi

::: grammar-box

**Конечный компонент Bahuvrīhi склоняется как прилагательное трех родов, независимо от его исходного рода. Таким образом, если в составе сложного слова конечный компонент имеет род, отличный от его исходного, то это должно быть Bahuvrīhi, если только это не Samāhāradvanva (средний род, единственное число).**

**При прилагательствовании**

*   **-ā-основи в мужском и среднем роде переходят в -a-основи**
*   **-a-основи (м.р., ср.р.) образуют женский род на -ā или -ī**
*   **-ī-основи (ж.р.) должны в конце Bahuvrīhi принимать суффикс -ka, -kā, -ka (ср.р.); этот суффикс могут или должны также принимать многие другие Bahuvrīhi**

:::
## 20.7. Другое деление типов бахуврихи

Примеры приведены здесь для последующего разбора, для некоторых из них необходимая грамматика и лексика ещё не были рассмотрены

1.  определяющее слово в первой части — определяемое слово во второй части: ⟪स्थिरचित्तः⟫ = ⟪स्थिरं⟫ ⟪चित्तं⟫ ⟪यस्य⟫ ⟪सः⟫
2.  неизменяемые слова в первой части: ⟪उच्चैःश्रवस्⟫
3.  сравнение в первой части: ⟪कुशाग्रधीः⟫ =  ⟪कुशाग्र⟫ ⟪इव⟫ ⟪धीर्यस्य⟫ ⟪सः⟫
4.  подразумеваемое сравнение: ⟪उष्ट्रमुखः⟫ = ⟪उष्ट्रस्य⟫ ⟪मुखमिव⟫ ⟪मुखं⟫ ⟪यस्य⟫ ⟪सः⟫ = "верблюдорылый" = чей рот подобен рту верблюда
5.  числительное во второй части при приблизительном числе: ⟪उपसशाः⟫ = ⟪दशानां⟫ ⟪समीपे⟫ ⟪ये⟫ ⟪सन्ति⟫ ⟪ते⟫ = "около десяти"
6.  обе части являются числительными: ⟪एकद्वाः⟫ = ⟪एको⟫ ⟪वा⟫ ⟪द्वौ⟫ ⟪वा⟫ = "один или два"
7.  с sa-/saha- в первой части: ⟪सपुत्रः⟫ ⟪।⟫ ⟪सहपुत्रः⟫
8.  с sa- (= ⟪समान⟫) в первой части: ⟪सजनपदः⟫ = ⟪समानो⟫ ⟪जनपदो⟫ ⟪यस्य⟫ ⟪सः⟫
9.  ⟪नञ्बहुव्रीहिः⟫ = с a-/an- в первой части: ⟪अपुत्रः⟫ = ⟪न⟫ ⟪विद्यते⟫ ⟪पुत्रो⟫ ⟪यस्य⟫ ⟪सः⟫ ; ⟪अनङ्गः⟫ = ⟪न⟫ ⟪विद्यते⟫ ⟪अङ्गं⟫ ⟪यस्य⟫ ⟪सः⟫
10.  с предлогом и т.п. в первой части: ⟪प्रवातः⟫ =⟪प्रकृष्टो⟫ ⟪वातो⟫ ⟪यस्मिन्⟫ ⟪सः⟫ ; ⟪निर्धनः⟫ = ⟪निर्गतं⟫ ⟪धनं⟫ ⟪यस्मात्सः⟫ ; ⟪सुबुद्धिः⟫ = ⟪सुष्ठु⟫ ⟪बुद्धिर्यस्य⟫ ⟪सः⟫ ; ⟪दुर्बुद्धिः⟫ = ⟪दुष्टा⟫ ⟪बुद्धिर्यस्य⟫ ⟪सः⟫
11.  обозначения направлений для указания промежуточных направлений: ⟪पुर्वोत्तरा⟫ "северо-восточный"
12.  причастие прошедшего времени действительного залога в качестве первой части: ⟪कृतकटः⟫ = ⟪कृतः⟫ ⟪कटो⟫ ⟪येन⟫ ⟪सः⟫

## 20.8. Соотношение бахуврихи и придаточного предложения

Хотя каждое бахуврихи может быть раскрыто с помощью придаточного предложения, не каждое придаточное предложение может быть заменено бахуврихи. Герман Георг Джакоби (1850–1937), который более подробно исследовал соотношение этих двух конструкций (Compositum und Nebensatz, 1897), пишет:

::: indent
«Если переводить с немецкого или другого современного языка на санскрит, то не все придаточные предложения могут быть переданы с помощью сложных слов, а только украшающие и описательные; те же, которые содержат концептуально необходимую или важную детализацию, в санскрите также выступают как придаточные предложения».
:::
::: media
![](/images/lekt2002.jpg)
Рис.: Герман Джакоби
(Источник изображения: [Сведения](/ru/licenses#lekt2002))
:::
Это может быть верно. Однако индийцы многое считают украшающим и описательным, тогда как мы бы считали это «концептуально необходимым или важным».
