# Урок 38

## 38.1. Решение недели

⟪मनुस्मृति ४⟫.⟪३२⟫ о правильном мочеиспускании:

::: indent
⟪प्रत्य⟫:sig[⟪ग्नि⟫] ⟪प्रतिसूर्यं च प्रतिसोमोदकद्विजम् । प्रति⟫:sig[⟪गु⟫] ⟪प्रतिवातं च प्रज्ञा नश्यति मेहतः ॥⟫
:::
Пояснения:

\-⟪अग्नि⟫ Средний род, именительный/винительный падеж, единственное число к ⟪अग्नि⟫ м.

\-⟪गु⟫ Средний род, именительный/винительный падеж, единственное число к ⟪गो⟫ м.ж. "Бык, корова"

## 38.2. Фонетические изменения носовых в слове

::: grammar-box
Носовые в слове ассимилируются к следующим за ними согласным, т. е. они заменяются на носовой, соответствующий этому согласному.

После c- и j- -n- заменяется на -ñ-.
:::
## 38.3. Склонение основ на -n

### 38.3.1. Существительные на -an, а также существительные на -man и -van после гласного
::: grammar-box
Существительные на **-an**, а также существительные **-man** и **-van** после гласного имеют три основы:

| Основа | -an | -man | -van | Употребление |
| :--- | :---: | :---: | :---: | :--- |
| **Сильная основа** | **-ān** | **-mān** | **-vān** | Имен., Вин., Зв. ед. ч. м. ж.:brИмен., Вин., Зв. дв. ч. м. ж.:brИмен., Зв. мн. ч. м. ж.:brИмен., Вин. мн. ч. ср. |
| **Средняя слабая основа** | **-a** :br(от -*n) | **-ma** :br(от -*mn) | **-va** :br(от -*vn) | Остальные падежи перед согласным началом окончания:brТакже возможно использование для Локал. ед. ч. м. ср. ж. |
| **Слабейшая основа** | **-n** | **-mn** | **-vn** | Остальные падежи перед гласным началом окончания |

**Окончания являются регулярными. Именительный падеж единственного числа м. ж. образуется без конечного -n.**
:::
Примеры:

⟪राजन्⟫ м. р. "царь"

*   сильный корень: ⟪राजान्⟫
*   средний корень: ⟪राज⟫
*   слабый корень: ⟪राज्ञ् सीमन्⟫ ж. р. "граница"

*   сильный корень: ⟪सीमान्⟫
*   средний корень: ⟪सीम⟫
*   слабый корень: ⟪सीम्न् नामन्⟫ ср. р. "имя"

*   сильный корень: ⟪नामान्⟫
*   средний корень: ⟪नाम⟫
*   слабый корень: ⟪नाम्न्⟫
::: grammar-box

### 38.3.2. Существительные на -man и -van после согласных

::: grammar-box
*   Сильный корень: -mān, -vān
*   Слабый корень:
*   перед окончаниями, начинающимися с согласной: -ma, -va (из -\*mn, -\*vn)
*   перед окончаниями, начинающимися с гласной: **\-man, -van**

Иначе образование, как в 3.1.
:::
Примеры:

⟪आत्मन्⟫ n. "душа"

*   сильный корень: ⟪आत्मान्⟫
*   слабый корень:
*   перед согласным: ⟪आत्म⟫
*   перед гласным: ⟪आत्मन् ब्रह्मन्⟫ n.: Абсолютное, Веда, Брахман

*   сильный корень: ⟪ब्रह्मान्⟫
*   слабый корень:
*   перед согласным: ⟪ब्रह्म⟫
*   перед гласным: ⟪ब्रह्मन्⟫

### 38.3.3. Мужского и среднего рода на -in, -min, -vin

::: grammar-box
Эти существительные **не имеют** чередования корня.

Nom.sg.m. и Nom.Akk.pl.n. образованы по аналогии с основами на -an (удлинение -i-), так же как и основа на **\-i-** перед согласным окончанием.

Женский род образуется с помощью суффикса -ī: например, ⟪बलिनी⟫
:::

## 38.4. Образование имён прилагательных: суффикс ⟪तद्धित⟫ -in

::: grammar-box
С помощью (очень важного!) суффикса ⟪तद्धित⟫ **-in** из существительных образуются прилагательные со значением:

**отличающийся чем-либо, обладающий**

Изначально образование с помощью суффикса **-⟪इन्⟫** отличалось от образования с помощью **-⟪मन्त्⟫/-⟪वन्त्⟫** тем, что **-⟪इन्⟫** обозначало признак чем-то особенным, тогда как **-⟪मन्त्⟫/-⟪वन्त्⟫** выражало обладание чем-либо, признак чем-то обычным, общим.
:::
Пример:

⟪हस्तिन्⟫ м.р.: тот, кто отмечен особой рукой = слон (его рука ведь не обычная рука, а хобот)

::: media
![](/images/lekt3806.webp)
Рис.: ⟪हस्ती⟫
(Источник изображения: [Подробности](/ru/licenses#lekt3806))
:::
⟪हस्तवन्त्⟫ : тот, у кого есть (человеческие) руки

::: media
![](/images/lekt3807.webp)
Рис.: ⟪हस्तवान्⟫
(Источник изображения: [Подробности](/ru/licenses#lekt3807))

::: grammar-box
Прилагательные на **-⟪इन्⟫** охотно образуются в составе сложных слов.
:::
Пример:

⟪सत्यवादिन्⟫ к ⟪सत्यवाद⟫ м.р. "говорение правды": "тот, кто отмечен говорением правды = тот, кто всегда говорит правду"

## 38.5. Синтаксис ⟪नामन्⟫

::: grammar-box
Чтобы выразить "некто по имени Н.Н.", используется конструкция:

**И.Н. (в именительном падеже) ⟪नाम⟫**

Буквально: "имя есть/было Н.Н". Таким образом, речь идёт о вставленном именном предложении.
:::
Пример:

::: indent
⟪आसीद्राजा नलो नाम वीरसेनसुतो बली ।⟫ "Был когда-то царь **по имени Нала**, сильный сын Вирасены."
:::
Разумеется, то же самое можно выразить с помощью ⟪बहुव्रीहि⟫:

::: indent
⟪देवदत्तनामा पुरुषः⟫ «мужчина, чьё имя — Девадатта»

⟪मदयन्तिकानाम्नी बाला⟫ «девушка, чьё имя — Мадаянтика»
:::

## 38.6. Синтаксис ⟪आत्मन्⟫

::: grammar-box
⟪आत्मन्⟫ **мужского рода** может в **единственном числе** использоваться как возвратное местоимение (рефлексивное местоимение) для всех трёх родов, чисел (включая двойственное и множественное число) и лиц.
:::
Примеры:

::: indent
⟪आत्मन्येषा दोषं न पश्यति ।⟫ «Она не видит ошибки в себе самой»

⟪आत्मानं स्तुवन्ति ।⟫ «Они восхваляют себя самих»
:::
::: grammar-box
Генитив (⟪षष्ठी⟫) ⟪आत्मनस्⟫ может стоять в значении «мой/твой/его/... собственный»
:::
Пример:

::: indent
⟪आत्मनो गृहं प्रविशति ।⟫ «Он входит в свой собственный дом.»
:::
## 38.7. Основа на согласный в качестве первого компонента композитивов

::: grammar-box
Основа, оканчивающаяся на согласный, выступает в качестве первого компонента композитива в своей (слабой) форме, которую она принимает перед окончанием -су локатива (⟪सप्तमी⟫) множественного числа.
:::
Пример:

::: indent
sig[⟪राज⟫]⟪पुत्र⟫ «сын царя»
:::
## 38.8. Основа на -an в качестве второго компонента ⟪बहुव्रीहि⟫

::: grammar-box
В качестве второго компонента ⟪बहुव्रीहि⟫ основа на -an может использоваться для всех трёх родов. Однако, как правило, женский род образуется от самой слабой формы мужского рода с помощью суффикса -ī.
:::
Пример:

::: indent
⟪दुर्णाम्नी⟫ «имя которого дурно; богиня-демон болезни»
:::
