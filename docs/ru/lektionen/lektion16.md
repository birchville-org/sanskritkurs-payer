# Урок 16

## 16.1. О сандхи конечных согласных

Для образования составных слов (самас), в которых первая часть представляет собой основу, оканчивающуюся на согласный, необходимо знать следующие правила:

Конечные калитные, ретрофлексные, зубные и губные смычные (т.е. не носовые и не палатальные).

::: no-header

|   |   |
| :--- | :--- |
| **в паузе и перед глухими звуками** | **Замена на соответствующий им глухой неаспирated звук:** [[br]] **напр.** [[br]] [[indent]] -g + p- » -kp- [[br]] [[indent]] -d + ph- » -tph- [[br]] [[indent]] -dh + p- » -tp- |
| **перед звонкими неносовыми звуками** | **Замена на соответствующий им звонкий неаспирated звук:** [[br]] **напр.** [[br]] [[indent]] -t + g- » -dg- [[br]] [[indent]] -k + b- » -gb- [[br]] [[indent]] -dh + d- » -dd- [[br]] [[indent]] -k + a- » -ga- |
| **перед носовыми** | **Замена на соответствующий им носовой:** [[br]] **напр.** [[br]] [[indent]] -t + n- » -nn- [[br]] [[indent]] -p + n- » -mn- |

Исключение из вышеуказанного правила:

Конечный зубной смычный (не носовой):

::: no-header

|   |   |

| **перед палатными** | **Замена на соответствующий неаспирated палатный:** [[br]] **т.е.** [[br]] [[indent]] -t + c- » -cc- [[br]] [[indent]] -d + c- » -cc- [[br]] [[indent]] -th + c- » -cc- [[br]] [[indent]] -dh + c- » -cc- [[br]] [[indent]] -t/-th/-d/-dh + ch- » -cch- [[br]] [[indent]] -t/-th/-d/-dh + j- » -jj- [[br]] [[indent]] -t/-th/-d/-dh + jh- » -jjh- |
| **+ ś** | **» -cś- или -cch-** |
| **перед ретрофлексными** | **Замена на соответствующий неаспирated ретрофлексный:** [[br]] **т.е.** [[br]] [[indent]] -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- [[br]] [[indent]] -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **перед l-** | **Замена на -l:** [[br]] **т.е.** [[br]] [[indent]] -t/-th/-d/-dh + l- » -ll- |

Примеры:

तद् + फल = तत्फल

पुण्यवत् + ब्राह्मण = पुण्यवद्ब्राह्मण

पुण्यवत् + नर = पुण्यवन्नर

पुण्यवत् + पुरुष = पुण्यवत्पुरुष

सत्यवत् + चैतन्य =सत्यवच्चैतन्य

सुखवत् + लोक = सुखवल्लोक

पुत्रवत् + जन = पुत्रवज्जन

बलवत् + शत्रु = बलवच्छत्रु

१. योगश्चित्तवृत्तिनिरोधः ॥योगसूत्र १.२॥

२. स्वधर्मो ब्राह्मणस्याध्ययनमध्यापनं यजनं याजनं दानं प्रतिग्रहश्च ॥५॥

क्षत्रियस्याध्ययनं यजनं दानं शस्त्राजीवो भूतरक्षणं च ॥६॥

वैश्यस्याध्ययनं यजनं दानं कृषिपाशुपाल्ये वणिज्या च ॥७॥

शूद्रस्य द्विजातिशुश्रूषा वार्त्ता कारुकुशीलवकर्म च ॥८॥

सर्वेषामहिंसा सत्यं शौचमनसूयानृशंस्यं क्षमा च ॥१३॥

(कौटिलीयार्थशास्त्र १.३.५-८, १३)

::: indent
Пояснения;

Предложение 7: कृषिपाशुपाल्यе — двойственное число, именительный/винительный падеж: дандва (составное слово), обозначающее две «вещи».

Предложение 8: कर्म — именительный/винительный падеж, единственное число, средний род от कर्मन् «дело, действие».

Предложение 13: सर्वेषाम — родительный падеж, множественное число, мужской род от सर्व «каждый, все» (местоимение, склоняется не как deva).
:::
