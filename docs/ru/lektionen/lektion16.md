# Урок 16

## 16.1. О сандхи конечных согласных

Для образования составов, в которых первая часть состоит из основ с конечным согласным, необходимы следующие правила:

Конечные гортанные, ретрофлексные, зубные и губные взрывные (т.е. не носовые и не палатальные).

::: no-header

|   |   |
| :--- | :--- |
| **в паузе и перед глухими звуками** | **Замена на соответствующий им глухой не придыхательный звук:** :br **напр.** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **перед звонкими неназальными звуками** | **Замена на соответствующий им звонкий не придыхательный звук:** :br **напр.** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **перед носовыми** | **Замена на соответствующий им назальный звук:** :br **напр.** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::
Исключение из вышеуказанного правила:

Конечный зубной взрывной (не носовой):

::: no-header

|   |   |
| :--- | :--- |
| **перед палатальным** | **Замена на соответствующий не придыхательный палатальный:** :br **т.е.** :br :indent -t + c- » -cc- :br :indent -d + c- » -cc- :br :indent -th + c- » -cc- :br :indent -dh + c- » -cc- :br :indent -t/-th/-d/-dh + ch- » -cch- :br :indent -t/-th/-d/-dh + j- » -jj- :br :indent -t/-th/-d/-dh + jh- » -jjh- |
**+ ś** | **» -cś- или -cch-** |
| **перед ретрофлексным** | **Замена на соответствующий не придыхательный ретрофлексный:** :br **т.е.** :br :indent -t/-th/-d/-dh + ṭ(h)- » -ṭṭ(h)- :br :indent -t/-th/-d/-dh + ḍ(h)- » -ḍḍ(h)- |
| **перед l-** | **Замена на -l:** :br **т.е.** :br :indent -t/-th/-d/-dh + l- » -ll- |

:::
Примеры:

⟪तद्⟫ + ⟪फल⟫ = ⟪तत्फल पुण्यवत्⟫ + ⟪ब्राह्मण⟫ = ⟪पुण्यवद्ब्राह्मण पुण्यवत्⟫ + ⟪नर⟫ = ⟪पुण्यवन्नर पुण्यवत्⟫ + ⟪पुरुष⟫ = ⟪पुण्यवत्पुरुष सत्यवत्⟫ + ⟪चैतन्य⟫ =⟪सत्यवच्चैतन्य सुखवत्⟫ + ⟪लोक⟫ = ⟪सुखवल्लोक पुत्रवत्⟫ + ⟪जन⟫ = ⟪पुत्रवज्जन बलवत्⟫ + ⟪शत्रु⟫ = ⟪बलवच्छत्रु⟫
