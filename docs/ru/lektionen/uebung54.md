# Урок 54

Образуйте соответствующие формы аориста от следующих форм настоящего или совершенного времени:

::: grammar-box
| № | Форма | Определение / Значение | Аорист |
|:---|:---|:---|:---|
| १. | **यन्ति** | они идут | **अगुः** |
| २. | **पिबामि** | я пью | **अपाम्** |
| ३. | **ददौ** | я имею / он имеет дал | **अदाम् / अदात्** |
| ४. | **बभूव** | я / он / они были / были | **अभूवम् / अभूत् / अभूत** |
| ५. | **दधति** | они сажают | **अधुः** |
| ६. | **ऐम** | мы шли | **अगाम** |
| ७. | **पपिथ** | ты пил / охранял | **अपाः** (к *पा* "пить") |
| ८. | **तिष्ठति** | он стоит | **अस्थात्** |
| ९. | **इयेथ** | ты пошел | **अगाः** |
| १०. | **पप** | вы пили | **अपात** |
| ११. | **एष्यथ** | вы пойдете | **अगात** |
| १२. | **तस्थुः** | они стояли | **अस्थुः** |
| १३. | **अधत्त** | вы сажали | **अधात** |
| १४. | **अददाः** | ты дал | **अदाः** |
| १५. | **अभवन्** | они были | **अभूवन्** |
| १६. | **ददिम** | мы дали | **अदाम** |
| १७. | **भिद्यते** | раскалывается | **अभेदि** |
| १८. | **उद्यते** | говорится | **अवादि** |
| १९. | **स्तूयते** | он хвалится | **अस्तावि** |
| २०. | **कृष्यते** | пашется | **अकर्षि** |
| २१. | **जायते** | он рождается | **अजनि** |
| २२. | **गीयते** поется | **अगायि** |
| २३. | **गम्यते** | идет | **अगामि** |
:::
