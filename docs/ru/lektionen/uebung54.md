# Упражнение 54

Образуйте соответствующие формы аориста от следующих форм настоящего или совершенного времени:

::: grammar-box
| № | Форма | Определение / Значение | Аорист |
|:---|:---|:---|:---|
| ⟪१⟫. | ⟪यन्ति⟫ | они идут | ⟪अगुः⟫ |
| ⟪२⟫. | ⟪पिबामि⟫ | я пью | ⟪अपाम्⟫ |
| ⟪३⟫. | ⟪ददौ⟫ | я дал / он дал | **⟪अदाम्⟫ / ⟪अदात्⟫** |
| ⟪४⟫. | ⟪बभूव⟫ | я / он / они были / вы были | **⟪अभूवम्⟫ / ⟪अभूत्⟫ / ⟪अभूत⟫** |
| ⟪५⟫. | ⟪दधति⟫ | они садят / помещают | ⟪अधुः⟫ |
| ⟪६⟫. | ⟪ऐम⟫ | мы шли | ⟪अगाम⟫ |
| ⟪७⟫. | ⟪पपिथ⟫ | ты выпил / защитил | ⟪अपाः⟫ (от :sig[⟪पा⟫] "пить") |
| ⟪८⟫. | ⟪तिष्ठति⟫ | он стоит | ⟪अस्थात्⟫ |
| ⟪९⟫. | ⟪इयेथ⟫ | ты пошел / ушел | ⟪अगाः⟫ |
| ⟪१०⟫. | ⟪पप⟫ | вы выпили | ⟪अपात⟫ |
| ⟪११⟫. | ⟪एष्यथ⟫ | вы пойдете / уйдете | ⟪अगात⟫ |
| ⟪१२⟫. | ⟪तस्थुः⟫ | они стояли | ⟪अस्थुः⟫ |
| ⟪१३⟫. | ⟪अधत्त⟫ | вы сели / поместили | ⟪अधात⟫ |
| ⟪१४⟫. | ⟪अददाः⟫ | ты дал | ⟪अदाः⟫ |
| ⟪१५⟫. | ⟪अभवन्⟫ | они были | ⟪अभूवन्⟫ |
| ⟪१६⟫. | ⟪ददिम⟫ | мы дали | ⟪अदाम⟫ |
| ⟪१७⟫. | ⟪भिद्यते⟫ | раскалывается / разделяется | ⟪अभेदि⟫ |
| ⟪१८⟫. | ⟪उद्यते⟫ | говорится / сказано | ⟪अवादि⟫ |
| ⟪१९⟫. | ⟪स्तूयते⟫ | он хвалится / прославляется | ⟪अस्तावि⟫ |
| ⟪२०⟫. | ⟪कृष्यते⟫ | пахается / вспахивается | ⟪अकर्षि⟫ |
| ⟪२१⟫. | ⟪जायते⟫ | он рождается / появляется на свет | ⟪अजनि⟫ |
| ⟪२२⟫. | ⟪गीयते⟫ | поется / исполняется песня | ⟪अगायि⟫ |
| ⟪२३⟫. | ⟪गम्यते⟫ | идет / совершается движение | ⟪अगामि⟫ |
:::
