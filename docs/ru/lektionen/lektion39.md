

# Lektion 39

## 39.1. Die Personalendungen der ersten Person (***तृतीयः*** पुरुषः = "***dritte*** Person")

Окончания первого лица (***तृतीयः*** पुरुषः = "***третья*** Person") следующие:

:::: grammar-box

| | **परस्मैपदम्** || **आत्मनेपदम्** ||
| :--- | :---: | :---: | :---: | :---: |
| | **एकवचनम्** | **बहुवचनम्** | **एकवचनम्** | **बहुवचनम्** |
| **Основное окончание тематических основ** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **Основное окончание атематических основ** | ^^ | ^^ | **-e** | ^^ |
| **Вторичное окончание тематических основ** | **-m** | **-ma** | **-i** | **-mahi** |
| **Вторичное окончание атематических основ** | **-am** | ^^ | ^^ | ^^ |
| **Окончание оптиматива** | ^^ | ^^ | **-a** | ^^ |
| **Окончание перфекта** | **-a** | ^^ | **-e** | **-mahe** |

::::
1 Примечание: на самом деле основное окончание Ā тематических основ следует реконструировать как -e, перед которым тематический гласный -a- по аналогии выпадает. Однако результат таков, как если бы окончание -i присоединялось к тематическому гласному -a-: a + i » e.
