# Урок 39

## 39.1. Окончания первого лица (***तृतीयः*** पुरुषः = "***третье*** лицо")

Окончания первого лица (***तृतीयः*** पुरुषः = "***третье*** лицо") таковы:

::::grammar-box

| | **परस्मैपदम्** || **आत्मनेपदम्** ||
| :--- | :---: | :---: | :---: | :---: |
| | **एकवचनम्** | **बहुवचनम्** | **एकवचनम्** | **बहुवचनम्** |
| **Окончание первичное тематических основ** | **-mi** | **-mas** | **-i**¹ | **-mahe** |
| **Окончание первичное атематических основ** | ^^ | ^^ | **-e** | ^^ |
| **Окончание вторичное тематических основ** | **-m** | **-ma** | **-i** | **-mahi** |
| **Окончание вторичное атематических основ** | **-am** | ^^ | ^^ | ^^ |
| **Окончание оптиматива** | ^^ | ^^ | **-a** | ^^ |
| **Окончание перфекта** | **-a** | ^^ | **-e** | **-mahe** |

::::1 Примечание: на самом деле первичное окончание тематических основ Ā следует также рассматривать как -e, перед которым тематический гласный -a- по аналогии выпадает. Однако эффект таков, как если бы окончание -i присоединялось к тематическому гласному -a-: a + i » e.
