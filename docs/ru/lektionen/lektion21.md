# Урок 21

## 21.1. Другие основы настоящего времени на -nt

### 21.1.1. Причастие настоящего времени (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
Это причастие является номинализацией от основы настоящего времени, то есть настоящим причастием. Это прилагательное, указывающее на то, что кто-то или нечто совершает действие, выраженное глагольным корнем (+ префиксом), в то время как происходит что-то другое. Также с его помощью может выражаться постоянное состояние.

**Примеры:**

:::
::: indent
"Пока отец читает, он курит = читающий отец курит"
"друг, который есть (= настоящий, подлинный)"
:::
::: grammar-box

| **Образование причастия настоящего времени Parasmaipada от тематических основ настоящего времени:** |||
| :--- | :--- | :--- |
| **Мужской род, Средний род** | | |
| | **сильная основа** | Основа настоящего времени + **-nt-** |
| | **слабая основа** | Основа настоящего времени + **-t-** |
| **Женский род** | | |
| | | Основа настоящего времени + **-nt-** + **-ī** (склонение как **devī** :br⟪देवी⟫) |
| | **6. класс настоящего времени** | Основа настоящего времени + **-nt-** + **-ī** :broder::brОснова настоящего времени + **-t-** + **-ī** |

:::

## 21.2. Сандхи для конечных носовых

::: grammar-box
**После краткого гласного конечные носовые – кроме -m – перед начальным гласным удваиваются.**

**Пример:**

:::
::: indent
**⟪जयन्⟫ + ⟪अरिः⟫** » ⟪जयन्नरिः⟫ "победоносный враг"
:::
## 21.3. Вежливые формы обращения

::: grammar-box
**На санскрите можно обращаться к кому-либо во 2-м лице единственного числа, не проявляя невежливости. Однако если вы хотите быть вежливым, можно использовать существительное со значением «достопочтенный» и тому подобное, а глагол поставить в 3-е лицо единственного или множественного числа либо использовать пассивную конструкцию. Повышение уровня вежливости при использовании лиц в обращении примерно следующее:**

:::
::: indent
**2 ед. ч. » 2 мн. ч. » 3 л. с соответствующим существительным » 3 л. мн. ч. с соотв. существительным**
:::
**Самым важным таким вежливым существительным является ⟪भवन्त्⟫ , жен. род: ⟪भवती⟫ . По своему употреблению оно соответствует нашему вежливому «Вы».**
Это ⟪भवन्त्⟫ является сокращением от ⟪भगवन्त्⟫, его склонение соответствует существительным на **-vant** (см. [Урок 13](lektion13.md)). Это ⟪भवन्त्⟫ следует отличать от причастия настоящего времени P от ⟪भू⟫ "становиться" ⟪भवन्त्⟫ : им. падеж, мужской род, единственное число от ⟪भवन्त्⟫ "Вы" звучит как ⟪भवान्⟫, а причастия ⟪भवन्⟫.

**Примеры:**

::: indent
**⟪किं भवान्करोति⟫** = **⟪किं भवता क्रियते⟫** = "Что вы делаете?"
:::
вежливо:

::: indent
**⟪किं भवन्तः कुर्वन्ति⟫** = **⟪किं भवद्भिः क्रियते⟫**
:::
Женский род:

::: indent
**⟪किं भवती करोति⟫** = **⟪किं भवत्या क्रियते⟫**  
**⟪किं भवत्यः कुर्वन्ति⟫** = **⟪किं भवतीभिः क्रियते⟫**
:::
Другие слова, которые можно использовать аналогично ⟪भवन्त्⟫:

*   ⟪आर्य⟫ (ж.р.: ⟪आर्या⟫) "Благородный". Например, **⟪यदार्य इच्छति⟫** "Чем могу служить"
*   ⟪महाभाग⟫ "тот, чья доля / счастье велико = Благородный". Часто используется женщинами при обращении или в разговоре о мужчинах хорошего происхождения. В современном разговорном санскрите очень распространено.

Если хотят выразить не только вежливость, но и благоговение перед кем-либо, то по отношению к присутствующему или находящемуся рядом лицу используют вместо ⟪भवन्त् अत्रभवन्त्⟫ , а по отношению к отсутствующему или удалённому ⟪तत्रभवन्त्⟫. ⟪अत्रभवन्त्⟫ и ⟪तत्रभवन्त्⟫ можно перевести как "Вы", "Ваше Превосходительство", "Ваше Высокопреосвященство" и т.д.:

::: indent
**⟪किमत्रभवत्यत्रभवतां भार्या⟫** = "Является ли милостивая (здесь присутствующая) женщина вашей супругой?"  
**⟪किं तत्रभवतां कुशलवृत्तम्⟫** (в письме или телефонном разговоре) = "Как ваши дела?"
:::
