# Урок 21

## 21.1. Дополнительные настоящие корни на -nt

### 21.1.1. Причастие настоящего времени (⟪लडादेशः⟫) Парасмайпада

::: grammar-box
Это причастие является именной формой от основы настоящего времени, то есть настоящим причастием. Это прилагательное, указывающее на то, что кто-то или что-то совершает действие, выраженное глагольным корнем (+ префиксом), в то время как происходит что-то другое. Также с его помощью может выражаться постоянное состояние.

**Примеры:**

:::
::: indent
"Пока отец читает, он курит = курящий отец курит"  
"друг, который есть (= настоящий, истинный)"
:::
::: grammar-box

| **Образование des Partizip Настоящее время Parasmaipada zu thematischen Настоящее времяstämmen:** |||
| :--- | :--- | :--- |
| **Мужской род, Средний род** | | |
| | **starker Основа** | Презенс-основа + **-nt-** |
| | **schwacher Основа** | Презенс-основа + **-t-** |
| **Женский род** | | |
| | | Презенс-основа + **-nt-** + **-ī** (Deklination wie **devī** :br⟪देवी⟫) |

:::

## 21.2. Сандхи для конечных носовых

::: grammar-box
**После краткого гласного конечные носовые – кроме -m – перед начальным гласным удваиваются.**

**Пример:**

**⟪जयन्⟫ + ⟪अरिः⟫** » **⟪जयन्नरिः⟫** "побеждающий враг"
:::
## 21.3. Вежливые формы обращения

::: grammar-box
**В санскрите можно обращаться к кому-либо во 2-м лице единственного числа, не будучи невежливым. Однако если вы хотите быть вежливым, можно использовать существительное со значением «достопочтенный» и тому подобное, а глагол поставить в 3-е лицо единственного или множественного числа, либо использовать пассивную конструкцию. Степень вежливости при обращении по лицам примерно следующая:**

:::
::: indent
**2 ед. ч. » 2 мн. ч. » 3 ед. ч. с соответствующим существительным » 3 мн. ч. с соответствующим существительным**
:::
**Самым важным таким вежливым существительным является ⟪भवन्त्⟫ , жен. род: ⟪भवती⟫ . По своему употреблению оно соответствует нашему вежливому «Вы» (на «Вы»).**
Это **⟪भवन्त्⟫** является сокращением от **⟪भगवन्त्⟫**, его склонение соответствует существительным на **-vant** (см. [Урок 13](lektion13.md)). Это **⟪भवन्त्⟫** следует отличать от причастия настоящего времени P от **⟪भू⟫** «становиться» **⟪भवन्त्⟫** : именительный падеж единственного числа мужского рода от **⟪भवन्त्⟫** «Вы» (вежл.) имеет форму **⟪भवान्⟫**, а от причастия **⟪भवन्⟫** — **⟪किं⟫**. 

**Примеры:**

::: indent
**⟪किं⟫ ⟪भवान्करोति⟫** = **⟪किं⟫ ⟪भवता⟫ ⟪क्रियते⟫** = «Что Вы делаете?»
:::
вежливей:

::: indent
**⟪किं⟫ ⟪भवन्तः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवद्भिः⟫ ⟪क्रियते⟫**
:::
Женский род:

::: indent
**⟪किं⟫ ⟪भवती⟫ ⟪करोति⟫** = **⟪किं⟫ ⟪भवत्या⟫ ⟪क्रियते⟫**  
**⟪किं⟫ ⟪भवत्यः⟫ ⟪कुर्वन्ति⟫** = **⟪किं⟫ ⟪भवतीभिः⟫ ⟪क्रियते⟫**
:::
Другие слова, которые можно использовать аналогично **⟪भवन्त्⟫**:

*   **⟪आर्य⟫** (ж. р.: **⟪आर्या⟫**) «Благородный». Например, **⟪यदार्य⟫ ⟪इच्छति⟫** «Чего Вы желаете?»
*   **⟪महाभाग⟫** «тот, чья доля/счастье велика = Благородный». Часто используется женщинами при обращении или при разговоре о мужчинах хорошего положения. В современном разговорном санскрите очень распространено.

Если нужно выразить не только вежливость, но и благоговение перед кем-либо, то по отношению к лицу, которое присутствует или находится поблизости, вместо **⟪भवन्त्⟫** используют **⟪अत्रभवन्त्⟫**, а по отношению к отсутствующему или удалённому лицу — **⟪तत्रभवन्त्⟫**. **⟪अत्रभवन्त्⟫** и **⟪तत्रभवन्त्⟫** можно перевести как «Вы», «Ваше благородие», «Ваше высокопреосвященство» и т. п.:

::: indent
**⟪किमत्रभवत्यत्रभवतां⟫ ⟪भार्या⟫** = «Не является ли уважаемая (здесь присутствующая) женщина Вашей супругой?»  
**⟪किं⟫ ⟪तत्रभवतां⟫ ⟪कुशलवृत्तम्⟫** (в письме или по телефону) = «Как Ваше здоровье?»
:::
