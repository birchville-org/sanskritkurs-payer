# Урок 21

## 21.1. Дополнительные основы настоящего времени на -nt

### 21.1.1. Причастие настоящего времени (⟪लडादेशः⟫) Parasmaipada

::: grammar-box
Это причастие является номинализацией, образованной от основы настоящего времени, то есть настоящим причастием. Оно является прилагательным, которое указывает на то, что кто-то или нечто совершает действие, выраженное глагольным корнем (+ префиксом), в то время как происходит что-то другое. Также с его помощью может выражаться постоянное состояние.

**Примеры:**

:::
::: indent
"Пока отец читает, он курит = читающий отец курит"
"друг, который есть (= настоящий, подлинный)"
:::
::: grammar-box

| **Образование причастия настоящего времени Parasmaipada для тематических основ настоящего времени:** |||
| :--- | :--- | :--- |
| **Мужской род, Средний род** | | |
| | **сильная основа** | Основа настоящего времени + **-nt-**
| | **слабая основа** | Основа настоящего времени + **-t-**
| **Женский род** | | |
| | | Основа настоящего времени + **-nt-** + **-ī** (склонение как **devī** :br⟪देवी⟫)

:::

## 21.2. Сандхи для конечных носовых согласных

::: grammar-box
**После краткого гласного конечные носовые согласные, за исключением -m, перед начальным гласным удваиваются.**

**Пример:**

:::
::: indent
**⟪जयन्⟫ + ⟪अरिः⟫** » ⟪जयन्नरिः⟫ "побеждающий враг"
:::
## 21.3. Вежливые формы обращения

::: grammar-box
**На санскрите можно обращаться к кому-либо во 2-м лице единственного числа, не проявляя невежливости. Однако если вы хотите быть вежливым, можно использовать существительное со значением «достопочтенный» и тому подобное, а глагол поставить в 3-е лицо единственного или множественного числа либо использовать пассивную конструкцию. Степень вежливости при использовании лиц в обращении примерно следующая:**

:::
::: indent
**2 ед.ч. » 2 мн.ч. » 3 ед.ч. с соответствующим существительным » 3 мн.ч. соотв. существительное**
:::
**Самым важным таким вежливым существительным является ⟪भवन्त्⟫ , жен. род: ⟪भवती⟫ . Оно соответствует нашему вежливому «Вы».**
Это ⟪भवन्त्⟫ является слиянием из ⟪भगवन्त्⟫, его склонение соответствует существительным на **-vant** (см. [Урок 13](lektion13.md)). Это ⟪भवन्त्⟫ следует отличать от причастия настоящего времени P от ⟪भू⟫ "становиться" ⟪भवन्त्⟫ : им. падеж, ед. число, мужской род от ⟪भवन्त्⟫ "Вы" звучит как ⟪भवान्⟫, а от причастия ⟪भवन्⟫. 

**Примеры:**

::: indent
**⟪किं भवान्करोति⟫** = **⟪किं भवता क्रियते⟫** = "Что вы делаете?"
:::
более вежливо:

::: indent
**⟪किं भवन्तः कुर्वन्ति⟫** = **⟪किं भवद्भिः क्रियते⟫**
:::
Женский род:

::: indent
**⟪किं भवती करोति⟫** = **⟪किं भवत्या क्रियते⟫**  
**⟪किं भवत्यः कुर्वन्ति⟫** = **⟪किं भवतीभिः क्रियते⟫**
:::
Другие слова, которые могут использоваться аналогично ⟪भवन्त्⟫:

*   ⟪आर्य⟫ (ж. р.: ⟪आर्या⟫) "Благородный". Например, **⟪यदार्य इच्छति⟫** "Как вы желаете"
*   ⟪महाभाग⟫ "тот, чья доля / счастье велико = Благородный". Часто используется женщинами при обращении или в речи о мужчинах хорошего происхождения. В современном разговорном санскрите очень распространено.

Если вы хотите выразить не только вежливость, но и уважение к кому-то, то для присутствующего или находящегося рядом человека вместо ⟪भवन्त् अत्रभवन्त्⟫ используется ⟪तत्रभवन्त्⟫, а для отсутствующего или удалённого — ⟪अत्रभवन्त्⟫. ⟪तत्रभवन्त्⟫ и ⟪किमत्रभवत्यत्रभवतां⟫ можно перевести как "Вы", "Ваше Превосходительство", "Ваше Высокопреосвященство" и т. д.:

::: indent
**⟪भार्या किं⟫** = "Является ли эта милостивая (здесь присутствующая) женщина вашей супругой?"  
**⟪तत्रभवतां कुशलवृत्तम् भज्⟫** (в письме или телефонном разговоре) = "Как ваши дела?"
:::
