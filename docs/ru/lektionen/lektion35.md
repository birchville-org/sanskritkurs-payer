# Урок 35

## 35.1. Перфект типа III: сильный корень с удлинённой/усиленной ступенью

::: grammar-box
**Образование:**

**сильный корень:**
*   3.l.п.: удлинённая ступень
*   2.l.п.: усиленная ступень
*   1.l.п.: по выбору — усиленная или удлинённая ступень

**слабый корень:** см. подтипы
:::
### 35.1.1. Перфект типа IIIa: сильный корень с высшей/удлинённой ступенью, слабый корень с низкой ступенью

::: grammar-box
**Образование:**

:::
::: indent
**слабый корень:** низкая ступень
:::
Образуется от корней следующих типов:
*   (Согласный)-(Согласный) - i/ī/u/ū
*   (Согласный) - ṛ

Перед гласной начальной окончанием заменяется:
*   -i/-ī на -iy
*   -u/-ū на -uv
*   -ṛ на r
Примеры:

| Корень | 3. ед. ч. Перф. П. | 3. мн. ч. Перф. П. | 3. ед. ч. Перф. Ā. | 3. мн. ч. Перф. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इयाय⟫:briy-ai + a | ⟪ईयुर्⟫:bri + iy + ur | | |
| ⟪नी⟫ 1U | ⟪निनाय⟫ | ⟪निन्युर्⟫:brni-nī + ur | ⟪निन्ये⟫ | ⟪निन्यिरे⟫ |
| ⟪स्तु⟫ 2U | ⟪तुष्टाव⟫:brtu + stau + a | ⟪तुष्टुवुर्⟫:brtu + stuv-ur | ⟪तुष्टुवे⟫ | ⟪तुष्टुविरे⟫ |
| ⟪पू⟫ | ⟪पुपाव⟫:brpu-pau + a | ⟪पुपुवुर्⟫:brpu-puv-ur | ⟪पुपुवे⟫ | ⟪पुपुविरे⟫ |
| ⟪कृ⟫ | ⟪चकार⟫ | ⟪चक्रुर्⟫:brca-kr-ur | ⟪चक्रे⟫ | ⟪चक्रिरे⟫ |

### 35.1.2. Перфект типа IIIb: сильный корень в степени усиления/удлинения, слабый корень в степени усиления

::: grammar-box
**Образование:**

:::
::: indent
**слабый корень:** степень усиления
:::
Образуется от корней следующих типов:
*   (Согласный)-(Согласный)-ṝ
*   Согласный-Согласный-ṛ (т.е. корни на -ṛ, если им предшествует несколько согласных)
Примеры:

| Корень | 3. ед. ч. Перф. П. | 3. мн. ч. Перф. П. | 3. ед. ч. Перф. Ā. | 3. мн. ч. Перф. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पॄ⟫ 3П | ⟪पपार⟫ | ⟪पपरुर्⟫ | | |
| ⟪स्मृ⟫ 1П | ⟪सस्मार⟫ | ⟪सस्मरुर्⟫ | | |
| ⟪संस्कृ⟫ 8У | ⟪सञ्चस्कार⟫:brsam + ca-skār-a | ⟪सञ्चस्करुर्⟫ | ⟪सञ्चस्करे⟫ | ⟪सञ्चस्करिरे⟫ |

## 35.2. Перфект типа IV: корни на -ā / -āi

::: grammar-box
**Образование:**

**сильный корень:**
*   3./1. ед. ч. Перфекта на -au
*   2\. ед. ч. P : высшая ступень -ā или низшая ступень -i

**слабый корень:**
*   перед согласным: низшая ступень -i
*   перед гласным: низшая ступень Ø

Образуется от корней на -ā / -āi
:::
Пример:

| Корень | 3. ед. ч. Перф. P.:br1. ед. ч. Перф. P. | 3. мн. ч. Перф. P. | 3. ед. ч. Перф. А. | 3. мн. ч. Перф. А. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪ददौ⟫ | ⟪ददुर्⟫:brda-d-ur | ⟪ददे⟫ | ⟪ददिरे⟫:brda-d-i-re |

## 35.3. Перфект типа V: корни типа согласный-а-согласный

::: grammar-box
**Образование:**

**сильная основа:**
*   3.ед.ч.п.: ступень удлинения
*   2.ед.ч.п.: высшая ступень
*   1.ед.ч.п.: высшая ступень или ступень удлинения на выбор

**слабая основа:** см. подтипы

Образуется от корней типа (согласный)-согласный-а-согласный
:::
### 35.3.1. Перфект типа Va: слабый корень, глубокая ступень

::: grammar-box
**Образование:**

:::
::: indent
**слабый корень:** глубокая ступень
:::
Образуется, среди прочего, от корней:
*   ⟪गम्⟫
*   ⟪हन्⟫
*   ⟪जन्⟫
*   ⟪वच्⟫
*   ⟪वद्⟫
*   ⟪यज्⟫
Примеры:

| Корень | 3. ед. ч. Перф. П. | 3. мн. ч. Перф. П. | 3. ед. ч. Перф. Ā. | 3. мн. ч. Перф. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪गम्⟫ 1P | ⟪जगाम⟫ | ⟪जग्मुर्⟫:brja-gm-ur | | |
| ⟪हन्⟫ 2P | sig[⟪जघान⟫] :brja-**ghān**-a | *⟪जघ्नुर्⟫* | | |
| ⟪जन्⟫ 4Ā | | | ⟪जज्ञे⟫:brja-jñ-e | ⟪जज्ञिरे⟫ |
| ⟪वच्⟫ 2P | ⟪उवाच⟫ | ⟪ऊचुर्⟫:bru + uc-ur | | |
| ⟪वद्⟫ 1P | ⟪उवाद⟫ | ⟪ऊदुर्⟫ | \<⟪ऊदे⟫\> | \<⟪ऊदिरे⟫\> |
| ⟪यज्⟫ 1U | ⟪इयाज⟫ | ⟪ईजुर्⟫:bri + ij-ur | ⟪ईजे⟫ | ⟪ईजिरे⟫ |

### 35.3.2. Перфект типа Vb: слабый корень, сокращение (тип e)

::: grammar-box
**Образование:**

:::
::: indent
**слабый корень:** без редупликации. Замена -a- корня на -e-  
(для пояснения см. Thumb-Hauschild 1,2 стр. 286f.)
:::
Образуется от корней с -a- между двумя простыми согласными, начальный согласный которых в слоге редупликации не изменяется (т.е. начальный согласный корня не является гуттуральным, аспиратом или h).
Пример:
Пример:

| Корень | 3. ед. ч. Перф. П. | 3. мн. ч. Перф. П. | 3. ед. ч. Перф. А. | 3. мн. ч. Перф. А. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪पच्⟫ 1U | ⟪पपाच⟫ | *⟪पे⟫*⟪चुर्⟫ | *⟪पे⟫*⟪चे⟫ | *⟪पे⟫*⟪चिरे⟫ |

### 35.3.3. Тип совершенного времени Vc: корни с согласным-a-согласным. Слабая основа в сильной степени

::: grammar-box
**Образование:**

**слабая основа:** сильная степень

Образуется от всех остальных корней со средним -a-, т.е. корней со средним -a-
*   которые начинаются с двух согласных
*   которые начинаются с увулярных
*   которые начинаются с аспиратов
*   которые начинаются с h

если они не относятся к типу совершенного времени Va.
:::
Пример:

| Корень | 3. ед. ч. сов. вр. действ. залога | 3. мн. ч. сов. вр. действ. залога | 3. ед. ч. сов. вр. страд. залога | 3. мн. ч. сов. вр. страд. залога |
| :--- | :--- | :--- | :--- | :--- |
| ⟪क्रम्⟫ 1U | ⟪चक्राम⟫ | ⟪चक्रमुर्⟫ | ⟪चक्रमे⟫ | ⟪चक्रमिरे⟫ |
