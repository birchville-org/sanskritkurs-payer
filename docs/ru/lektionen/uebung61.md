# Упражнение 61

Урок 61 завершает курс санскрита и не содержит дополнительных письменных упражнений.

Изучение корневых существительных, перифразического будущего времени и номинальных производных закладывает основы для чтения оригинальных текстов на санскрите. Курс завершается традиционным обращением к Га́нешу (⟪श्रीगणनाथ⟫), которое обозначает переход от учебника к самостоятельному чтению.
