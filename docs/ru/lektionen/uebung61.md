# Урок 61

Урок 61 завершает курс санскрита и не содержит дополнительных письменных упражнений.

Изучение корневых существительных, перифрастического будущего времени и номинальных производных закладывает основы для чтения оригинальных текстов на санскрите. Курс завершается традиционным обращением к Гаṇеше (श्रीगणनाथ), которое отмечает переход от учебника к самостоятельному чтению.
