# Урок 25

## 25.1. Образование аблатива (⟪पञ्चमी⟫ = "пятый падежный окончание")

::: grammar-box
За исключением мужского и среднего рода на -a, а также местоимений, в единственном числе во всех склонениях формы аблатива (⟪पञ्चमी⟫) идентичны формам генитива (⟪षष्ठी⟫).

За исключением личных местоимений, во всех склонениях во множественном числе формы аблатива идентичны формам датива (⟪चतुर्थी⟫).
:::
Теперь вы понимаете причину порядка падежей (⟪विभक्ति⟫) в санскрите: они расположены так, чтобы одинаковые формы находились как можно ближе друг к другу — или одна под другой.

::: grammar-box
**Аблатив единственного числа мужского и среднего рода на -a**

- **deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)
:::
Вопросительные, относительные и указательные местоимения:

::: grammar-box

| | Аблатив единственного числа:brМужской род / Средний род | Аблатив единственного числа:brЖенский род |
| :--- | :--- | :--- |
| ⟪किम्⟫ | **kasmāt** :br(⟪कस्मात्⟫) | **kasyāḥ** :br(⟪कस्याः⟫) |
| ⟪यद्⟫ | **yasmāt** :br(⟪यस्मात्⟫) | **yasyāḥ** :br(⟪यस्याः⟫) |
| ⟪तद्⟫ | **tasmāt** :br(⟪तस्मात्⟫) | **tasyāḥ** :br(⟪तस्याः⟫) |
| ⟪एतद्⟫ | **etasmāt** :br(⟪एतस्मात्⟫) | **etasyāḥ** :br(⟪एतस्याः⟫) |
| ⟪इदम्⟫ | **asmāt** :br(⟪अस्मात्⟫) | **asyāḥ** :br(⟪अस्याः⟫) |

:::
## 25.2. Употребление аблатива (⟪पञ्चमी⟫)

"Аблатив обозначает то, что остаётся на месте, когда от чего-то отходят."

Пāṇини 2,3,28 + 1,4,24

Аблатив стоит прежде всего на вопросы "Откуда?", "Почему?".

::: grammar-box
1\. Аблатив обозначает исходную точку, происхождение и материал.

Аблатив может поэтому также обозначать лицо, от которого покупают, слышат, желают и т. д.
:::
Примеры:

::: indent
⟪ग्रमादागच्छति⟫ = "Он приходит из деревни"

⟪अश्वात्पतितः⟫ = "упав с лошади"

⟪तेभ्यो लब्धम्⟫ = "принятый от них (оттуда)"
:::
Примеры:

::: indent
⟪गुरोर्धर्मं शृणोति⟫ = "он слышит от учителя о дхарме"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "брахман желает себе от кшатрия корову, дающую молоко"
:::
::: grammar-box
2\. Аблатив стоит при глаголах со значениями "воздерживаться от", "защищать от", "отражать против", "бояться перед":
:::
Пример:

::: indent
⟪अरिभ्यो रक्षति⟫ = "он защищает от врагов"
:::
::: grammar-box
3\. Аблатив обозначает причину или основание:
:::
Примеры:

::: indent
⟪क्रोधात्पुत्रं हन्ति⟫ = "Он убивает своего сына из гнева"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "Поскольку он совершил зло, он попадает в ад" (« Поскольку он тот, через кого было совершено зло)

⟪पापकरणान्नरकं गच्छति⟫ = "Поскольку он совершает / совершил зло, он попадает в ад"
:::
Существительные, не являющиеся женского рода, могут для обозначения причины действия стоять в инструменталиве (⟪तृतीया⟫) или аблативе (⟪पञ्चमी⟫). Существительные женского рода в этом смысле обычно стоят в инструменталиве, но иногда могут стоять и в аблативе.

## 25.3. Суффикс -⟪तस्⟫

::: grammar-box
Если в единственном числе (однозначно) нужно выразить, что слово используется в значении аблатива, к основе слова можно присоединить суффикс -⟪तस्⟫, который образует наречия со значением преимущественно аблатива (на вопрос "Откуда?"):
:::
Примеры:

::: indent
⟪आदितस्⟫ = «с самого начала»

⟪धर्मतस्⟫ = «из-за дхармы, вследствие дхармы»
:::
::: grammar-box
Суффикс -⟪तस्⟫ также присоединяется к местоименным основам:
:::
::: indent
⟪तद्⟫ : ⟪ततस्⟫ (« ta-tas) «оттуда, там, туда, на это, затем, поэтому»

⟪यद्⟫ : ⟪यतस्⟫ «от которого, от чего, откуда, где, куда, почему» (относительное)

⟪किम्⟫ :  ⟪कुतस्⟫ «откуда?» «почему?»
:::
## 25.4. Другие способы выражения обоснования

::: grammar-box
**1\. Относительные придаточные предложения**

Относительные придаточные предложения часто выражают причинную (обосновывающую), следственную или целевую связь с главным предложением.

Формы относительного местоимения, служащие причинным союзом:

*   аблативные:
*   ⟪यतस्⟫ ... придаточное предложение ... ⟪ततस्⟫ ... главное предложение ... = «поскольку ..., поэтому ...»
*   ⟪यस्मात्⟫ ... придаточное предложение ... ⟪तस्मात्⟫ ... главное предложение ... = «поскольку ..., поэтому ...»
*   инструментальные:
*   ⟪येन⟫ ... придаточное предложение ... ⟪तेन⟫ ... главное предложение ... = «благодаря чему/поскольку ..., тем самым / поэтому ...»
:::
Пример:

::: indent
⟪यतो⟫ (⟪यस्माद्⟫ / ⟪येन⟫) ⟪धर्ममिच्छति⟫ \[⟪ततो⟫ (⟪तस्माद्⟫ / ⟪तेन⟫)\] ⟪रामो व्रतं चरति⟫ = «Поскольку Рама желает благополучия, он соблюдает обет»
:::
::: grammar-box
**2\. ⟪हि⟫**

Главные предложения можно связывать с помощью частицы ⟪हि⟫ «ведь, потому что». Предложение с ⟪हि⟫ (которое не может стоять в начале, а в прозе должно занимать второе место) указывает на обоснование либо для предыдущего предложения, либо для следующего:
:::
Пример:

::: indent
⟪जनाः पुण्यं कुर्वन्ति । स्वर्गं हि गन्तुमिच्छन्ति⟫ = "Люди совершают заслуживающие похвалы поступки. Ведь они хотят попасть на небеса."
:::
::: grammar-box
**3\. Творительный падеж (⟪तृतीया⟫)**

Наряду с аблятивом (⟪पञ्चमी⟫) творительный падеж (⟪तृतीया⟫) используется для указания причины или основания. При женских существительных творительный падеж, как правило, обязателен.
:::
Пример:

::: indent
⟪क्रोधेन पुत्रं हन्ति⟫ = "Он убивает своего сына от гнева" = "Он убивает своего сына в гневе"
:::
::: grammar-box
**4\. Существительные**

Кроме того, разумеется, причины можно выражать также с помощью конструкций со

*   ⟪कारण⟫ ср. род "причина": ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ м. род
*   другие существительные в значении "причина"

\+ Родительный падеж (⟪षष्ठी⟫) или в качестве второго компонента составных существительных:
:::
Пример:

::: indent
⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ и т.д.) = "из-за заслуги"
:::
::: grammar-box
**5\. ⟪इति⟫**

Мотив действия можно выразить как мысль с помощью ⟪इति⟫:
:::
Пример:

::: indent
⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫  = "Поскольку Сугата полностью пробудился к истине, Āнанда спрашивает Гаутаму о его учении" (« "Думая: «Сугата полностью пробудился к истине» ..."
:::
