

# Lektion 24

## 24.1. Der Дательный падеж (चतुर्थी = "vierte Kasusendung")

:::: grammar-box
**1. Для выражения цели или намерения («чтобы») действия вместо инфинитива (तुमुन्) можно использовать существительное с крут-суффиксом, обозначающим действие или состояние, в дативе (चतुर्थī = «четвертый падежный окончание»).**

Пример:

вместо:

::: indent
रामो गुरुवचनं श्रोतुं गतः ।
:::

можно также сказать:

::: indent
रामो गुरुवचनस्य श्रवणाय गतः ।

или:

रामो गुरुवचनश्रवणाय गतः ।
:::

= «Рама пошел, чтобы услышать речь учителя».
::::

::: media
![](/images/lekt2404.jpg)
Рис.: बाला गुरुश्रवणाय गताः
(Источник изображения: [Детали](/licenses#lekt2404))
:::

:::: grammar-box
**2. Датив (चतुर्थī) может также обозначать объект дополняемого инфинитива цели:**

Пример:

::: indent
फलेभ्यो ग्रामं गच्छति = «Он идет в деревню ради плодов = Он идет в деревню, чтобы собрать плоды».
:::

**Аналогичным образом датив (चतुर्थī) обозначает цель вещи или действия:**

Пример:

::: indent
यज्ञायान्नम् = «Пища ради жертвоприношения = Пища для жертвоприношения».
:::
::::

::: media
![](/images/lekt2401.jpg)
Рис.: यज्ञायान्नम्
(Источник изображения: [Детали](/licenses#lekt2401))
:::

:::: grammar-box
**3. Датив (चतुर्थī) также обозначает лицо или предмет, для которых предназначен объект действия (косвенный объект; вопрос: кому?). (Обратите внимание на глаголы с двойным винительным падежом (द्वितीया)! )**

Пример:

::: indent
रामाय फलं ददाति = «Он дает Рама фрукт». (Корень दा 3. класс настоящего времени)
:::
::::

::: media
![](/images/lekt2402.jpg)
Рис.: बाला बालाय रक्षबन्धनं ददाति
(Источник изображения: [Детали](/licenses#lekt2402))
:::

:::: grammar-box
**4. Датив стоит у некоторых глаголов (и некоторых других слов) подобно немецкому вопросу «кому?»:**

Примеры:

::: indent
क्रुध् : देवो नरेभ्यो क्रुध्यति = «Бог гневается на людей».

अलम् Наречие: «достаточно, достаточно, справляется»: अलं योधो योधाय = «воин является равным другому воину».
:::
::::

::: media
![](/images/lekt2403.jpg)
Рис.: अलं योधो योधाय
(Источник изображения: [Детали](/licenses#lekt2403))
:::

Другие употребления датива будут рассмотрены позже.

## 24.3. Sandhi von auslautendem -ai und -au

::: grammar-box
**Сандхи конечных -ai и -au**

* **-ai перед гласным, стоящим в начале следующего слова, как правило, заменяется на -ā (реже — на -āy, как внутри слова)**
* **-au перед гласным, стоящим в начале следующего слова, как правило, заменяется на -āv (реже — на -ā)**

Пример:

::: indent
तस्मै + अग्नये » तस्मा अग्नये = «этому огню»
:::
:::

## 24.4. Словарь

अलम् Наречие: достаточно, вполне; (кому-л., чему-л.) по силам; с дательным падежом: достаточно для, вполне для, по силам; с творительным падежом: довольно с, оставь , напр. अलं क्रोधेन = «довольно гнева = оставь гнев!»

Аналогично с творительным падежом используется अलम्:

कृतम् : कृतं क्रोधेन = «Сделано с гневом = оставь гнев!»

## 24.6. Weitere Упражнениеen zum Употребление des Дательный падеж

Переведите на санскрит:

1\. Богиня, которой не принесли жертву, гневается на людей.

2\. Он отпускает корову в деревню.

3\. Теперь достаточно = Хватит терпения.

4\. Это хорошо (हित, सुख) для брахмана.

5\. Почитание (नमस्) да будет Шиве! Почитание да будет Шри Ганеше!
