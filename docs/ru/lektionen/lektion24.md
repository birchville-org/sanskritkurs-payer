# Урок 24

## 24.1. Дательный падеж (⟪चतुर्थी⟫ = "четвертое окончание падежа")

::: grammar-box
**1. Чтобы выразить цель или намерение ("чтобы") действия, вместо инфинитива (⟪तुमुन्⟫) можно использовать существительное с аффиксом крэт, обозначающим действие или состояние, в дательном падеже (⟪चतुर्थी⟫ = "четвертое окончание падежа").**

Пример:

вместо:

:::
::: indent
⟪रामो गुरुवचनं श्रोतुं गतः ।⟫
:::
можно также сказать:

::: indent
⟪रामो गुरुवचनस्य श्रवणाय गतः ।⟫

или:

⟪रामो गुरुवचनश्रवणाय गतः ।⟫
:::
= "Рама ушел, чтобы услышать речь учителя."
::: media
![](/images/lekt2404.webp)
Рис.: ⟪बाला गुरुश्रवणाय गताः⟫
(Источник изображения: [Details](/ru/licenses#lekt2404))
:::

::: grammar-box
**2. Дательный падеж (⟪चतुर्थी⟫) также может обозначать объект инфинитива цели, который необходимо дополнить:**

Пример:

:::
::: indent
⟪फलेभ्यो ग्रामं गच्छति⟫ = "Он идет в деревню ради плодов = Он идет в деревню, чтобы собрать плоды."
:::
**Аналогичным образом дательный падеж (⟪चतुर्थी⟫) обозначает цель предмета или действия:**

Пример:

::: indent
⟪यज्ञायान्नम्⟫ = "Пища ради жертвоприношения = Пища для жертвоприношения"
:::
::: media
![](/images/lekt2401.webp)
Рис.: ⟪यज्ञायान्नम्⟫
'Аннакут' [⟪अन्नकूट⟫ = ⟪गोवर्धन पूजा⟫] — это традиционное индуистское мероприятие, которое проводится в день празднования Нового года по индуистскому календарю во всех храмах BAPS [બોચાસનવાસી અક્ષ૨ પુરુષોત્તમ સ્વામિનારાયણ સંસ્થા = Bochasanwasi Akshar Purushottam Swaminarayan Sanstha]. В этот день тысячи вегетарианских блюд предлагаются Бхагвану Свами Нараяне [સ્વામિનારાયણ].
(Источник изображения: [Details](/ru/licenses#lekt2401))
:::

::: grammar-box
**3. Дательный падеж (⟪चतुर्थी⟫) также обозначает лицо или предмет, для которых предназначен объект действия (косвенное дополнение; вопрос: кому?). (Обратите внимание на глаголы с двойным винительным падежом (⟪द्वितीया⟫)!)**

Пример:

:::
::: indent
⟪रामाय फलं ददाति⟫ = "Он даёт Раме фрукт." (Корень ⟪दा⟫ 3. класс настоящего времени)
:::
::: media
![](/images/lekt2402.webp)
Рис.: ⟪बाला बालाय रक्षबन्धनं ददाति⟫
Ракша бандхан празднуется с энтузиазмом и радостью по всей Индии. Этот фестиваль олицетворяет безусловную любовь между братьями и сёстрами.
(Источник изображения: [Детали](/ru/licenses#lekt2402))
:::

::: grammar-box
**4. Дательный падеж используется с некоторыми глаголами (и другими словами) так же, как в немецком языке на вопрос "кому?":**

Примеры:

:::
::: indent
⟪क्रुध्⟫ : ⟪देवो नरेभ्यो क्रुध्यति⟫ = "Бог гневается на людей."

⟪अलम्⟫ Наречие: "достаточно, в достаточной мере, равный": ⟪अलं योधो योधाय⟫ = "воин равен другому воину"
:::
::: media
![](/images/lekt2403.webp)
Рис.: ⟪अलं योधो योधाय⟫
"Рама (справа), сидящий на плечах Ханумана, сражается с демоном-королем Раваной." ок. 1820 г.
(Источник изображения: [Детали](/ru/licenses#lekt2403))
:::

## 24.2. Образование дательного падежа (⟪चतुर्थी⟫)

::: grammar-box
**Правильные окончания дательного падежа:**

* **Единственное число: -e; женские основы на гласную: -ai**
* **Множественное число: Дательный и Аблатив ⟪पञ्चमी⟫: -bhyas**
:::
### 24.2.1. Согласные основы

::: grammar-box

| | Дательный падеж, единственное число | Дательный падеж, множественное число |
| :--- | :--- | :--- |
| ⟪यजन्त्⟫ | ⟪यजते⟫ :bryaja-t-e | ⟪यजद्भ्यस्⟫ :braus yaja-t-bhyas |
| ⟪महान्त्⟫ | ⟪महते⟫ | ⟪महद्भ्यस्⟫ |
| ⟪पशुमन्त्⟫ | ⟪पशुमते⟫ | ⟪पशुमद्भ्यस्⟫ |
| ⟪गुणवन्त्⟫ | ⟪गुणवते⟫ | ⟪गुणवद्भ्यस्⟫ |

:::
### 24.2.2. Вопросительные местоимения

::: grammar-box

| | Мужской и средний род | Женский род |
| :--- | :--- | :--- |
| **Дательный падеж, единственное число** | ⟪कस्मै⟫ | ⟪कस्यै⟫ |
| **Дательный падеж, множественное число** | ⟪केभ्यस्⟫ | ⟪काभ्यस्⟫ |

:::
### 24.2.3. Указательные местоимения

::: grammar-box

| | | ⟪तद्⟫ | ⟪एतद्⟫ | ⟪इदम्⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **Мужской и средний род** | **Дат. ед.** | ⟪तस्मै⟫ | ⟪एतस्मै⟫ | ⟪अस्मै⟫ |
| | **Дат. мн.** | ⟪तेभ्यस्⟫ | ⟪एतेभ्यस्⟫ | ⟪एभ्यस्⟫ |
| **Женский род** | **Дат. ед.** | ⟪तस्यै⟫ | ⟪एतस्यै⟫ | ⟪अस्यै⟫ |
| | **Дат. мн.** | ⟪ताभ्यस्⟫ | ⟪एताभ्यस्⟫ | ⟪आभ्यस्⟫ |

:::
### 24.2.4. Гласные основы

::: grammar-box
**Гласные основы**

* **Мужской и средний род на -a:** ⟪देव⟫
* Дат. ед. ⟪देवाय⟫
* Дат. мн. ⟪देवेभ्यस्⟫
* **Мужской род на -i:** ⟪कवि⟫
* Дат. ед. ⟪कवये⟫
* Дат. мн. ⟪कविभ्यस्⟫
* **Мужской род на -u:** ⟪पशु⟫
* Дат. ед. ⟪पशवे⟫
* Дат. мн. ⟪पशुभ्यस्⟫
* **Женский род на -ā:** ⟪देवता⟫
* Дат. ед. ⟪देवतायै⟫
* Дат. мн. ⟪देवताभ्यस्⟫
* **Женский род на -ī:** ⟪देवी⟫
* Дат. ед. ⟪देव्यै⟫
* Дат. мн. ⟪देवीभ्यस्⟫
* **Женский род на -i:** ⟪श्रुति⟫
* Дат. ед. ⟪श्रुतये⟫ или ⟪श्रुत्यै⟫ (т.е. как ⟪कवि⟫ или как ⟪देवी⟫)
* Дат. мн. ⟪श्रुतिभ्यस्⟫
* **Женский род на -u:** ⟪धेनु⟫
* Дат. ед. ⟪धेनवे⟫ или ⟪धेन्वै⟫
* Дат. мн. ⟪धेनुभ्यस्⟫
:::
## 24.3. Сандхи конечных -ai и -au

::: grammar-box
**Сандхи конечных -ai и -au**

* **-ai перед гласной обычно заменяется на -ā (реже — на -āy, как внутри слова)**
* **-au перед гласной обычно заменяется на -āv (реже — на -ā)**

Пример:

:::
::: indent
⟪तस्मै⟫ + ⟪अग्नये⟫ » ⟪तस्मा अग्नये⟫ = "этому огню"
:::
## 24.4. Словарь

⟪अलम्⟫ нареч.: достаточно, в достаточной мере; (с кем-л., чем-л.) справляться, быть в состоянии ; с дативом: достаточно для, в достаточной мере для; с инструменталом: довольно с, отступиться от , напр. ⟪अलं क्रोधेन⟫ = "довольно гнева = отступись от гнева!"
