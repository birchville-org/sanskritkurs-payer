# Урок 29

## 29.1. Использование парасмайпада (⟪परस्मैपद⟫) и атманепады (⟪आत्मनेपद⟫) в каузативе


::: grammar-box
**Каузатив, за исключением нескольких случаев, является убхайапада (⟪उभयपद⟫)**
:::
::: grammar-box
**В каузативе используется атманепада (⟪आत्मनेपद⟫):**

**1. Когда результат вызванного действия идет на пользу тому, кто вызывает:**
:::
Пример:

⟪रामः कटं कारयते⟫ = «Рама заставляет сделать для себя (в собственных интересах) циновку»

**2. Когда каузатив транзитивных глаголов используется рефлексивно («показывать себя», «давать о себе знать» и т.д.), либо когда объект простого глагола является агентом (⟪कर्तृ⟫) каузатива:**

Пример:

⟪विष्णुर्भक्तान्दर्शयते⟫ = «Вишну показывает себя своим поклонникам»

Результат: ⟪भक्ता विष्णुं पश्यन्ति⟫ = «Верующие видят Вишну»


Таким образом, правила в целом соответствуют правилам использования атманепады (⟪आत्मनेपद⟫) при глаголах убхайапада (⟪उभयपद⟫).

## 29.3. Упражнение на перевод для повторения

Переведите дословно на хороший русский язык и выучите санскритские тексты наизусть:

1\. Определение ⟪अविद्या⟫ :

⟪अनित्याशुचिदुःखा⟫:sig[⟪नात्मसु⟫] ⟪नित्यशुचिसुखात्मख्यातिरविद्या ॥योगसूत्र २⟫.⟪५॥⟫

Пояснение: ⟪आत्मसु⟫ = Локал. ед.ч. к ⟪आत्मन्⟫ m. "душа; Абсолют, поскольку он реализуется в индивидууме"

2\. ⟪कौटिलीयार्थशास्त्र⟫ 1.4. о правильном использовании ⟪दण्ड⟫ :

⟪तीक्ष्णदण्डो भूताना⟫:sig[⟪मुद्वेजनीयो⟫] ⟪भवति ।८। मृदुदण्डः परिभूयते ।९। यथार्हदण्डः पूज्यते ।१०। सु⟫:sig[⟪विज्ञात⟫]⟪प्रणीतो हि दण्डः प्रजा धर्मार्थकामै⟫:sig[⟪र्योजयति⟫] ⟪।११। दुष्प्रणीतः⟫ :sig[⟪कामक्रोधाभ्याम⟫]⟪वज्ञानाद्वा वानप्रस्थपरिव्राजकानपि कोपयति⟫, :sig[⟪किमङ्ग⟫] ⟪पुनर्गृहस्थान् ।१२। अप्रणीतस्तु मात्स्यन्यायमुद्भावयति ।१३। बलीयान अबलं हि ग्रसते दण्डधराभावे ।१४। स तेन गुप्तः प्रभवतीति ।१५।⟫
