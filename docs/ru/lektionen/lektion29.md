# Урок 29

## 29.1. Использование парасмапада (⟪परस्मैपद⟫) и атманепада (⟪आत्मनेपद⟫) в каузативе

::: grammar-box
**Каузатив, за исключением нескольких случаев, является убхайапада (⟪उभयपद⟫)**
:::
::: grammar-box
**В каузативе используется атманепад (⟪आत्मनेपद⟫):**

**1. Если результат вызванного действия приносит пользу тому, кто вызывает:**
:::
Пример:

⟪रामः⟫ ⟪कटं⟫ ⟪कारयते⟫ = «Рама заставляет сделать циновку для себя (в собственных интересах)»

**2. Если каузатив глаголов переходного значения употребляется возвратным образом («показываться», «давать о себе знать» и т.п.), либо если объект простого глагола является агентом каузатива (⟪कर्तृ⟫):**

Пример:

⟪विष्णुर्भक्तान्दर्शयते⟫ = «Вишну показывает себя своим почитателям»

Результат: ⟪भक्ता⟫ ⟪विष्णुं⟫ ⟪पश्यन्ति⟫ = «Верующие видят Вишну»

Таким образом, правила в целом соответствуют правилам использования атманепада (⟪आत्मनेपद⟫) при глаголах убхайапада (⟪उभयपद⟫).
