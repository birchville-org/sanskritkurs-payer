# Упражнение 14

Переведите следующие пословицы и выучите их наизусть:

⟪निचो वदति न कुरुते वदति न साधुः करोत्येव ॥१॥⟫  
Низкий человек не говорит и не действует, хороший человек не говорит, но действует.

⟪शीलं नरस्य भूषणम् ॥२॥⟫  
Добродетель — украшение человека.

⟪सत्येन जनानां सुखं भवति ॥३॥⟫  
Истина приносит людям счастье.

⟪पापा नराः स्वर्गं न लभन्ते ॥४॥⟫  
Злые люди не попадают на небо.

⟪सत्यं लोकस्य दीपः ॥५॥⟫  
Истина — свет мира.

A) Образуйте родительный падеж единственного и множественного числа для следующих слов. Укажите значение и род слов:

⟪१⟫. ⟪अनृत⟫ : ср. род. Неправда — ⟪अनृतस्य अनृतानाम् २⟫. ⟪ऋषि⟫ : м. род. ведийский мудрец — ⟪ऋषेः ऋषीणाम् ३⟫. ⟪पाद⟫ : м. род. стопа — ⟪पादस्य पादानाम् ४⟫. ⟪बुद्धि⟫ : ж. род. познание — ⟪बुद्धेः⟫ (⟪बुद्ध्याः⟫) ⟪बुद्धीनाम् ५⟫. ⟪गुरु⟫ : м. род. учитель — ⟪गुरोः गुरूणाम् ६⟫. ⟪स्वर्ग⟫ : м. род. небо — ⟪स्वर्गस्य स्वर्गाणाम् ७⟫. ⟪नगर⟫ : ср. род. город — ⟪नगरस्य नगराणाम् ८⟫. ⟪धेनु⟫ : ж. род. корова — ⟪धेनोः⟫ (⟪धेन्वाः⟫) ⟪धेनूनाम् ९⟫. ⟪द्विज⟫ : м. род. дваждырождённый — ⟪द्विजस्य द्विजानाम् १०⟫. ⟪मुक्ता⟫ : ж. род. спасённая — ⟪मुक्तायाः मुक्तानाम् ११⟫. ⟪विद्या⟫ : ж. род. знание, наука — ⟪विद्यायाः विद्यानाम् १२⟫. ⟪वर्ण⟫ : м. род. сословие — ⟪वर्णस्य वर्णानाम् १३⟫. ⟪द्विजाति⟫ : 3 дваждырождённый — ⟪द्विजातेः⟫ (⟪द्विजात्याः⟫) ⟪द्विजातीनाम् १४⟫. ⟪रूप⟫ : ср. род. форма — ⟪रूपस्य रूपाणाम् १५⟫. ⟪प्रतिग्रह⟫ : м. род. принятие — ⟪प्रतिग्रहस्य प्रतिग्रहाणाम्⟫

⟪१६⟫. ⟪सोढ⟫ : 3 выносить — ⟪सोढस्य सोढायाः सोढानाम् १७⟫. ⟪नायिका⟫ : ж. возлюбленная — ⟪नायिकायाः नयिकानाम् १८⟫. ⟪साध्वी⟫ : ж. святая — ⟪साध्व्याः साध्वीनाम् १९⟫. ⟪अग्नि⟫ : м. огонь — ⟪अग्नेः अग्नीनाम् २०⟫. ⟪वैश्या⟫ : ж. жена вайшьи — ⟪वैश्यायाः वैश्यानाम् २१⟫. ⟪लोक⟫ : м. мир, люди — ⟪लोकस्य लोकानाम् २२⟫. ⟪उक्ति⟫ : ж. изречение — ⟪उक्तेः⟫ (⟪उक्त्याः⟫) ⟪उक्तीनाम् २३⟫. ⟪शत्रु⟫ : м. враг — ⟪शत्रोः शत्रूणाम् २४⟫. ⟪सुखवन्त्⟫ : 3 счастливый — ⟪सुखवतः⟫ (⟪सुखवत्याः⟫) ⟪सुखवताम्⟫ (⟪सुखवतीनाम्⟫)

⟪२५⟫. ⟪पुत्रवती⟫ : ж. женщина с одним или несколькими сыновьями — ⟪पुत्रवत्याः पुत्रवतीनाम् २६⟫. ⟪जल⟫ : ср. вода — ⟪जलस्य जलानाम् २७⟫. ⟪मार्ग⟫ : м. путь — ⟪मर्गस्य मर्गाणाम् २८⟫. ⟪मोक्ष⟫ : м. освобождение, избавление — ⟪मोक्षस्य मोक्षाणाम् २९⟫. ⟪शूद्रा⟫ : ж. жена шудры — ⟪शूद्रायाः शूद्राणाम् ३०⟫. ⟪अन्न⟫ : ср. пища, еда — ⟪अन्नस्य अन्नानाम् ३१⟫. ⟪साधु⟫ : м. святой — ⟪साधोः साधनाम् ३२⟫. ⟪नीति⟫ : ж. руководство — ⟪नीत्याः नीतीनाम् ३३⟫. ⟪योध⟫ : м. воин, солдат — ⟪योधस्य योधानाम् ३४⟫. ⟪सत्यवन्त्⟫ : 3 правдивый — ⟪सत्यवतः⟫ (⟪सत्यवत्याः⟫) ⟪सत्यवताम्⟫ (⟪सत्यवतीनाम्⟫)

⟪३५⟫. ⟪लाभ⟫ : м. прибыль — ⟪लाभस्य लाभानाम् ३६⟫. ⟪मोह⟫ : м. смятение, заблуждение — ⟪मोहस्य मोहानाम् ३७⟫. ⟪गति⟫ : ж. ход, цель — ⟪गतेः⟫ (⟪गत्याः⟫) ⟪गतीनाम् ३८⟫. ⟪प्रश्न⟫ : м. вопрос — ⟪प्रश्नस्य प्रश्नानाम् ३९⟫. ⟪सृष्टि⟫ : ж. творение — ⟪सृष्तेः⟫ (⟪सृष्ट्याः⟫) ⟪सृष्टीनाम् ४०⟫. ⟪नेत्र⟫ : ср. глаз — ⟪नेत्रस्य नेत्राणाम् ४१⟫. ⟪गुरुता⟫ : ж. мастерство — ⟪गुरुतायाः गुरुतानाम्⟫

⟪४२⟫. ⟪ईश्वर⟫ : м. ГОСПОДИН — ⟪ईश्वरस्य ईश्वराणाम् ४३⟫. ⟪कारण⟫ : ж. Причина — ⟪कारणस्य कारणानाम् ४४⟫. ⟪कृत⟫ : 3 сделал — ⟪कृतस्य⟫ (⟪कृतायाः⟫) ⟪कृतानाम् ४५⟫. ⟪धर्मवन्त्⟫ : 3 справедливый, религиозный — ⟪धर्मवतः⟫ (⟪धर्मवत्याः⟫) ⟪धर्मवताम्⟫ (⟪धर्मवतीनाम्⟫)

⟪४६⟫. ⟪युद्ध⟫ : 3 боролся — ⟪युद्धस्य⟫ (⟪युद्धायाः⟫) ⟪युद्धानाम् ४७⟫. ⟪दर्शन⟫ : ж. Видение, явление — ⟪दर्शनस्य दर्शनानाम् ४८⟫. ⟪धातु⟫ : м. Элемент, глагольный корень — ⟪धातोः धातूनाम् ४९⟫. ⟪गूढा⟫ : ж. Скрытая — ⟪गूढायाः गूढानाम् ५०⟫. ⟪ईष्टा⟫ (2 значения): ж. Желаемая, приносимая в жертву — ⟪इष्टायाः इष्टानाम् ५१⟫. ⟪उदित⟫ : 3 сказал — ⟪उदितस्य⟫ (⟪उदितायाः⟫) ⟪उदितानाम् ५२⟫. ⟪इदम्⟫ : 3 этот — ⟪अस्य⟫ (⟪अस्याः⟫) ⟪एषाम्⟫ (⟪आसाम्⟫)

⟪५३⟫. ⟪किम्⟫ : 3 что — ⟪कस्य⟫ (⟪कस्याः⟫) ⟪केषाम्⟫ (⟪कासाम्⟫)

B) Переведите:

⟪१⟫. ⟪ब्राह्मणस्य पुत्रो ब्राह्मण्या ग्रामं गतः ।⟫ (2 варианта)
Сын брахмана отправился в деревню брахмани. Сын брахмана отправился с брахмани в деревню.

⟪२⟫. ⟪यज्ञस्याग्निनान्नं दग्धम् ।⟫
Жертвенный огонь сжег пищу.

⟪३⟫. ⟪बुद्धः स्तयस्य बुद्ध्या मुक्तः ।⟫
Будда был освобожден через познание истины.

⟪४⟫. ⟪अधर्मो ऽनृतस्य वदनमित्यृषयो वदन्ति ।⟫
Ведические мудрецы говорят, что говорить неправду — это несправедливо.

⟪५⟫. ⟪नरा देवानां यज्ञैर्न मुच्यन्ते ।⟫
Люди не освобождаются через жертвоприношения богам.

⟪६⟫. ⟪बलवन्तः क्षत्रियाः शत्रूणां धनवन्ति नगराणि जयन्ति ।⟫
Могущественные кшатрии завоевывают богатые города врагов.

⟪७⟫. ⟪कवेरुक्तिं शृण्वन्ति ।⟫
Вы слышите изречение поэта.

⟪८⟫. ⟪कविर्देव्याः कृतं वद⟫ti ⟪।⟫
Поэт повествует о деянии богини.

⟪९⟫. ⟪द्विजाः पशोर्लाभमिच्छन्ति ।⟫
Дваждырождённые желают получить скот.

⟪१०⟫. ⟪रामः पुण्यवतो गुरोर्मन्त्रस्य स्मरति ।⟫
Рама вспоминает мантру добродетельного учителя.

⟪११⟫. ⟪अयं बालः कस्याः पुत्रः ।⟫
Чей (ж.р.) сын этот мальчик?

⟪१२⟫. ⟪केषामिमानि गृहाणि ।⟫
Кому принадлежат эти дома?

⟪१३⟫. ⟪कस्यान्नमनेनर्षिणेष्टम् ।⟫
Чью пищу принёс в дар этот ведический мудрец?
