# Урок 17

## 17.1. Второй класс настоящего времени (⟪अदादि⟫ = ⟪अद्⟩ и т.д.)

Окончания глагола присоединяются непосредственно к корню. При этом следует учитывать изменения звуков, возникающие в результате словесного сандхи.

::: grammar-box

Существуют следующие способы образования форм во втором классе настоящего времени:

1.  Корни с чередованием основы
    *   чаще всего: сильная ступень — слабая ступень
    *   некоторые корни: удлиненная ступень — слабая ступень
2.  Корни без чередования основы
3.  Двусложные корни на -i/-ī с чередованием основы

:::
## 17.2. Корни второго класса настоящего времени с чередованием сильной ступени и слабой ступени

Примеры:

⟪द्विष्⟫ 2 U "ненавидеть"

*   сильная основа настоящего времени: dveṣ-
*   слабая основа настоящего времени: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. вр. P | ⟪द्वेष्टि⟫ (« dveṣ + -ti) |
| 3\. мн.ч. наст. вр. P | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 3\. ед.ч. наст. вр. Ā | ⟪द्विष्टे⟫ (« dviṣ + -te) |
| 3\. мн.ч. наст. вр. Ā | ⟪द्विषते⟫ (dviṣ-ate) |

:::
При этом действует следующее правило словесного сандхи:

::: grammar-box
Словесное сандхи -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-
:::
Другие примеры:

⟪इ⟫ 2 P "идти" (Ā после определенных превербов)

*   сильная основа настоящего времени: e-
*   слабая основа настоящего времени:
    *   перед согласным: i-
    *   перед гласным: y-/iy-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. вр. P | ⟪एति⟫ (e-ti) |
| 3\. мн.ч. наст. вр. P | ⟪यन्ति⟫ (y-anti) |
| 3\. ед.ч. наст. вр. Ā | ⟪इते⟫ (i-te) |
| 3\. мн.ч. наст. вр. Ā | ⟪इयते⟫ (iy-ate) |

:::
⟪दुह्⟫ 2 U "доить"

*   сильная основа настоящего времени: doh-
*   слабая основа настоящего времени: duh-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. вр. P | ⟪दोग्धि⟫ (« doh- + -ti) |
| 3\. мн.ч. наст. вр. P | ⟪दुहन्ति⟫ (duh-anti) |
| 3\. ед.ч. наст. вр. Ā | ⟪दुग्धे⟫ (« duh- + -te) |
| 3\. мн.ч. наст. вр. Ā | ⟪दुहते⟫ (duh-ate) |

:::
⟪हन्⟫ 2 P "бить, убивать, умерщвлять"

*   сильная основа настоящего времени: han-
*   слабая основа настоящего времени:
    *   перед согласным: ha- (« \*hn-)
    *   перед гласным: ghn-/han-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. вр. P | ⟪हन्ति⟫ (han-ti) |
| 3\. мн.ч. наст. вр. P | ⟪घ्नन्ति⟫ (ghn-anti) |
| 3\. ед.ч. наст. вр. Ā | ⟪हते⟫ (ha-te) |
| 3\. мн.ч. наст. вр. Ā | ⟪घ्नते⟫ (ghn-ate) |

:::
⟪अस्⟫ 2 P "быть"

*   сильная основа настоящего времени: as-
*   слабая основа настоящего времени: s-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. вр. P | ⟪अस्ति⟫ (as-ti) |
| 3\. мн.ч. наст. вр. P | ⟪सन्ति⟫ (s-anti) |

:::
## 17.3. Корни второго класса настоящего времени с чередованием удлиненной ступени и слабой ступени

Пример:

⟪स्तु⟫ 2 U "хвалить"

*   сильная основа настоящего времени: stau-
*   слабая основа настоящего времени:
    *   перед согласным: stu-
    *   перед гласным: stuv-

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. вр. P | ⟪स्तौति⟫ (stau-ti):broder: ⟪स्तवीति⟫ |
| 3\. мн.ч. наст. вр. P | ⟪स्तुवन्ति⟫ (stuv-anti) |
| 3\. ед.ч. наст. вр. Ā | ⟪स्तुते⟫ (stu-te) |
| 3\. мн.ч. наст. вр. Ā | ⟪स्तुवते⟫ (stuv-ate) |

:::
## 17.4. Корни второго класса настоящего времени без чередования основы

::: grammar-box
Без чередования основы являются корни второго класса настоящего времени на -ā
:::
Пример:

⟪पा⟫ 2 P "защищать, оберегать, хранить"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪पाति⟫ (pā-ti) |
| 3\. pl. Präs. P | ⟪पान्ति⟫ (« pā- + -anti) |

:::
Некоторые другие корни второго класса также не имеют чередования основы:

Примеры:

⟪अद्⟫ 2 P "есть"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪अत्ति⟫ (« ad- + -ti) |
| 3\. pl. Präs. P | ⟪अदन्ति⟫ (ad-anti) |

:::
⟪आस्⟫ 2 Ā "сидеть"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. Ā | ⟪आस्ते⟫ (ās-te) |
| 3\. pl. Präs. Ā | ⟪आसते⟫ (ās-ate) |

:::
⟪वच्⟫ 2 P "говорить"

::: no-header

| | |
| :--- | :--- |
| 3\. ед. ч. наст. вр., действ. залога | ⟪वक्ति⟫ (« vac- + -ti) |
| 3\. мн. ч. наст. вр., действ. залога | не встречается |

:::
## 17.5. Двусложные корни на -i/-ī с чередованием основы

Несколько корней в ряде форм являются двусложными, то есть они имеют -i (или перед некоторыми окончаниями -ī) перед согласным окончанием. Эти корни, тем не менее, местными грамматиками и в словарях и т.д. считаются односложными.

Примеры:

⟪रुद्⟫ 2 P "плакать, выть"

*   сильный Presentstem: rodi-
*   слабый Presentstem:
    *   перед согласным: rudi-
    *   перед гласным: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "говорить"

*   сильный Presentstem: bravī- (« bro- + -ī)
*   слабый Presentstem:
    *   vor Konsonant: brū-
    *   перед гласным: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Также ⟪स्तु⟫ 2 U "хвалить" имеет, помимо форм, указанных под 3., формы по этому образцу:

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::

A) Вставьте в следующие предложения глагол и переведите:
