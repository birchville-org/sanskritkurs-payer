# Урок 17

## 17.1. Второй класс настоящего времени (⟪अदादि⟫ = ⟪अद्⟫ и т.д.)

Глагольные окончания присоединяются непосредственно к корню. При этом следует учитывать изменения звуков, возникающие в результате словесного сандхи.

::: grammar-box

В рамках второго класса настоящего времени существуют следующие способы образования:

1. Корни с чередованием основы 
*   чаще всего: сильная ступень — слабая ступень
*   некоторые корни: удлиненная ступень — слабая ступень 
2. Корни без чередования основы 
3. Двусложные корни на -i/-ī с чередованием основы

:::
## 17.2. Корни второго класса настоящего времени с чередованием сильная ступень — слабая ступень

Примеры:

⟪द्विष्⟫ 2 U «ненавидеть»

*   сильная основа настоящего времени: dveṣ-
*   слабая основа настоящего времени: dviṣ-

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр., пр. | ⟪द्वेष्टि⟫ (« dveṣ + -ti) |
| 3\. л. мн. ч. наст. вр., пр. | ⟪द्विषन्ति⟫ (dviṣ-anti) |
| 3\. л. ед. ч. наст. вр., страд. | ⟪द्विष्टे⟫ (« dviṣ + -te) |
| 3\. л. мн. ч. наст. вр., страд. | ⟪द्विषते⟫ (dviṣ-ate) |

:::
При этом действует следующее правило сандхи:

::: grammar-box
Сандхи -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-
:::
Дополнительные примеры:

⟪इ⟫ 2 П «идти» (страд. после определенных превербов)

*   сильная основа настоящего времени: e-
*   слабая основа настоящего времени:
*   перед согласным: i-
*   перед гласным: y-/iy-

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр., пр. | ⟪एति⟫ (e-ti) |
| 3\. л. мн. ч. наст. вр., пр. | ⟪यन्ति⟫ (y-anti) |
| 3\. л. ед. ч. наст. вр., страд. | ⟪इते⟫ (i-te) |
| 3\. л. мн. ч. наст. вр., страд. | ⟪इयते⟫ (iy-ate) |

:::
⟪दुह्⟫ 2 U «доить»

*   сильная основа настоящего времени: doh-
*   слабая основа настоящего времени: duh-

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр., действ. з. | ⟪दोग्धि⟫ (« doh- + -ti) |
| 3\. мн. ч. наст. вр., действ. з. | ⟪दुहन्ति⟫ (duh-anti) |
| 3\. л. ед. ч. наст. вр., страд. з. | ⟪दुग्धे⟫ (« duh- + -te) |
| 3\. мн. ч. наст. вр., страд. з. | ⟪दुहते⟫ (duh-ate) |

:::
⟪हन्⟫ 2 д. "бить, убивать, умерщвлять"

*   сильный Presentstem: han-
*   слабый Presentstem:
*   перед согласным: ha- (« \*hn-)
*   перед гласным: ghn-/han-

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр., действ. з. | ⟪हन्ति⟫ (han-ti) |
| 3\. мн. ч. наст. вр., действ. з. | ⟪घ्नन्ति⟫ (ghn-anti) |
| 3\. л. ед. ч. наст. вр., страд. з. | ⟪हते⟫ (ha-te) |
| 3\. мн. ч. наст. вр., страд. з. | ⟪घ्नते⟫ (ghn-ate) |

:::
⟪अस्⟫ 2 д. "быть"

*   сильный Presentstem: as-
*   слабый Presentstem: s-

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр., действ. з. | ⟪अस्ति⟫ (as-ti) |
| 3\. мн. ч. наст. вр., действ. з. | ⟪सन्ति⟫ (s-anti) |

:::
## 17.3. Корни второго класса Present с чередованием основы: ступень усиления - ступень ослабления

Пример:

⟪स्तु⟫ 2 д. "восхвалять"

*   сильный Presentstem: stau-
*   слабый Presentstem:
*   перед согласным: stu-
*   перед гласным: stuv-

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр., действ. з. | ⟪स्तौति⟫ (stau-ti):broder: ⟪स्तवीति⟫ |
| 3\. мн. ч. наст. вр., действ. з. | ⟪स्तुवन्ति⟫ (stuv-anti) |
| 3\. л. ед. ч. наст. вр., страд. з. | ⟪स्तुते⟫ (stu-te) |
| 3\. мн. ч. наст. вр., страд. з. | ⟪स्तुवते⟫ (stuv-ate) |

:::
## 17.4. Корни второго класса Present без чередования основы

::: grammar-box
Без чередования основы являются корни второго класса Present на -ā
:::
Пример:

⟪पा⟫ 2 д. "защищать, оберегать, пасти"

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр., действ. з. | ⟪पाति⟫ (pā-ti) |
| 3\. мн. ч. наст. вр., действ. з. | ⟪पान्ति⟫ (« pā- + -anti) |

:::
Также некоторые другие корни второго класса не имеют чередования основы:

Примеры:

⟪अद्⟫ 2 P "есть"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪अत्ति⟫ (« ad- + -ti) |
| 3\. pl. Präs. P | ⟪अदन्ति⟫ (ad-anti) |

:::
⟪आस्⟫ 2 Ā "сидеть"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. Ā | ⟪आस्ते⟫ (ās-te) |
| 3\. pl. Präs. Ā | ⟪आसते⟫ (ās-ate) |

:::
⟪वच्⟫ 2 P "говорить"

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪वक्ति⟫ (« vac- + -ti) |
| 3\. pl. Präs. P | не встречается |

:::
## 17.5. Двусложные корни на -i/-ī с чередованием основы

Несколько корней являются двусложными в ряде форм, то есть перед согласным окончанием они имеют -i (а перед некоторыми окончаниями — ī). Тем не менее, эти корни местными грамматиками и в словарях и т. д. записываются как односложные.

Примеры:

⟪रुद्⟫ 2 P "плакать, выть"

*   сильный Presentstem: rodi-
*   слабый Presentstem:
*   перед согласным: rudi-
*   перед гласным: rud-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪रोदिति⟫ (rodi-ti) |
| 3\. pl. Präs. P | ⟪रुदन्ति⟫ (rud-anti) |

:::
⟪ब्रू⟫ 2 U "говорить"

*   сильный Presentstem: bravī- (« bro- + -ī)
*   слабый Presentstem:
    *   vor Konsonant: brū-
*   перед гласным: bruv-

::: no-header

| | |
| :--- | :--- |
| 3\. sg. Präs. P | ⟪ब्रवीति⟫ (bravī-ti) |
| 3\. pl. Präs. P | ⟪ब्रुवन्ति⟫ (bruv-anti) |
| 3\. sg. Präs. Ā | ⟪ब्रूते⟫ (brū-te) |
| 3\. pl. Präs. Ā | ⟪ब्रुवते⟫ (bruv-ate) |

:::
Также ⟪स्तु⟫ 2 U "хвалить" имеет, наряду с формами, указанными в п. 3., формы по этому образцу:

::: no-header

| | |
| :--- | :--- |
| 3\. ед. ч., наст. вр., действ. залога | ⟪स्तवीति⟫ (« sto + ī + ti):broder: ⟪स्तौति⟫ |

:::
