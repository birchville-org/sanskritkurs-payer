# Урок 17

## 17.1. Второй класс настоящего времени (अदादि = अद् и др.)

Глагольные окончания присоединяются непосредственно к корню. При этом необходимо учитывать фонетические изменения, возникающие в результате словесного сандхи.

:::: grammar-box

Второй класс настоящего времени образует следующие типы основ:

1.  Корни с чередованием ступени корня (гуна/аугхья):
    *   в большинстве случаев: высшая ступень — низшая ступень
    *   для некоторых корней: удлинённая ступень — низшая ступень
2.  Корни без чередования ступени корня
3.  Двусложные корни на -i/-ī с чередованием ступени корня

::::

## 17.2. Корни второго класса настоящего времени с чередованием основы: сильная ступень — слабая ступень

Примеры:

द्विष् 2 U «ненавидеть»

*   сильная основа настоящего времени: dveṣ-
*   слабая основа настоящего времени: dviṣ-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр. P | द्वेष्टи (« dveṣ + -ti) |
| 3\. л. мн. ч. наст. вр. P | द्विषन्ति (dviṣ-anti) |
| 3\. л. ед. ч. наст. вр. Ā | द्विष्टे (« dviṣ + -te) |
| 3\. л. мн. ч. наст. вр. Ā | द्विषते (dviṣ-ate) |

:::

::::

Здесь действует следующее правило сандхи слова:

Сандхи слова для -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-

Другие примеры:

इ 2 P «идти» (Ā после определённых префиксов)

*   сильная основа настоящего времени: e-
*   слабая основа настоящего времени:
    *   перед согласным: i-
    *   перед гласным: y-/iy-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр. P | एति (e-ti) |
| 3\. л. мн. ч. наст. вр. P | यन्ति (y-anti) |
| 3\. л. ед. ч. наст. вр. Ā | इते (i-te) |
| 3\. л. мн. ч. наст. вр. Ā | इयते (iy-ate) |

:::

::::

## 17.3. Корни второго класса настоящего времени с чередованием основы: ступень усиления — ступень ослабления

स्तु 2 U «хвалить»

    *   перед согласным: stu-
    *   перед гласным: stuv-

:::: grammar-box

::: no-header

| :--- | :--- |

| 3 л. мн. ч. наст. вр. P | स्तुवन्ति (stuv-anti) |
| 3 л. ед. ч. наст. вр. Ā | स्तुते (stu-te) |
| 3 л. мн. ч. наст. вр. Ā | स्तुवते (stuv-ate) |

:::

## 17.4. Корни второго класса настоящего времени без чередования корня

Без чередования корня корни второго класса настоящего времени на -ā

Пример:

पा 2 P «защищать, оберегать, хранить»

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. ед. ч. наст. вр. P | पाति (pā-ti) |
| 3\. мн. ч. наст. вр. P | पान्ति (« pā- + -anti) |

:::

::::

## 17.5. Двусложные корни на -i/-ī с чередованием основы

Несколько корней в ряде форм являются двусложными, то есть имеют перед согласным окончанием -i (либо перед некоторыми окончаниями -ī). Тем не менее, эти корни всё же рассматриваются индийскими грамматиками и словарями как односложные.

Примеры:

रुद् 2 P «плакать, рыдать»

*   сильная основа настоящего времени: rodi-
*   слабая основа настоящего времени:
    *   перед согласным: rudi-
    *   перед гласным: rud-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр. пр. | रोदिति (rodi-ti) |
| 3\. л. мн. ч. наст. вр. пр. | रुदन्ति (rud-anti) |

:::

::::

ब्रू 2 U «говорить»

*   сильная основа настоящего времени: bravī- (« bro- + -ī)
*   слабая основа настоящего времени:
    *   перед согласным: brū-
    *   перед гласным: bruv-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр. пр. | ब्रवीति (bravī-ti) |
| 3\. л. мн. ч. наст. вр. пр. | ब्रुवन्ति (bruv-anti) |
| 3\. л. ед. ч. наст. вр. средн. | ब्रूते (brū-te) |
| 3\. л. мн. ч. наст. вр. средн. | ब्रुवते (bruv-ate) |

:::

::::

Также स्तु 2 U «хвалить» имеет, помимо форм, указанных в п. 3, формы по этому же образцу:

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр. пр. | स्तवीति (« sto + ī + ti)[[br]]или: स्तौति |

:::

::::
