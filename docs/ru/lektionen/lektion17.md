# Урок 17

## 17.1. Второй класс настоящего времени (अदादि = अद् и т.д.)

Спряжение происходит непосредственно к корню. При этом следует учитывать фонетические изменения, возникающие из словослияния (сандхи).

:::: grammar-box

Существуют следующие формы образования в втором классе настоящего времени:

1.  Корни с чередованием корневой гласной
    *   в большинстве случаев: полный уровень — слабый уровень
    *   некоторые корни: удлиненный уровень — слабый уровень
2.  Корни без чередования корневой гласной
3.  Двусложные корни на -i/-ī с чередованием корневой гласной

::::

## 17.2. Корни второго класса настоящего времени с чередованием основы: сильная ступень — слабая ступень

Примеры:

द्विष् 2 U «ненавидеть»

*   сильная основа настоящего времени: dveṣ-
*   слабая основа настоящего времени: dviṣ-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр. P | द्वेष्टि (« dveṣ + -ti) |
| 3\. л. мн. ч. наст. вр. P | द्विषन्ति (dviṣ-anti) |
| 3\. л. ед. ч. наст. вр. Ā | द्विष्टे (« dviṣ + -te) |
| 3\. л. мн. ч. наст. вр. Ā | द्विषते (dviṣ-ate) |

:::

::::

При этом действует следующее правило сандхи слова:

Сандхи слова для -ṣ + t(h)-

\-ṣ + t(h)- » -ṣṭ(h)-

Другие примеры:

इ 2 P «идти» (Ā после определённых префиксов)

*   сильная основа настоящего времени: e-
*   слабая основа настоящего времени:
    *   перед согласным: i-
    *   перед гласным: y-/iy-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр. P | एति (e-ti) |
| 3\. л. мн. ч. наст. вр. P | यन्ति (y-anti) |
| 3\. л. ед. ч. наст. вр. Ā | इते (i-te) |
| 3\. л. мн. ч. наст. вр. Ā | इयते (iy-ate) |

:::

::::

दुह् 2 U «доить»

*   сильная основа настоящего времени: doh-
*   слабая основа настоящего времени: duh-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр. P | दोग्धि (« doh- + -ti) |
| 3\. л. мн. ч. наст. вр. P | दुहन्ति (duh-anti) |
| 3\. л. ед. ч. наст. вр. Ā | दुग्धे (« duh- + -te) |
| 3\. л. мн. ч. наст. вр. Ā | दुहते (duh-ate) |

:::

::::

हन् 2 P «бить, убивать, умерщвлять»

*   сильная основа настоящего времени: han-
*   слабая основа настоящего времени:
    *   перед согласным: ha- (« \*hn-)

| 3\. л. ед. ч. наст. вр. Ā | हते (ha-te) |

अस् 2 P «быть»

*   слабая основа настоящего времени: s-

:::

## 17.3. Корни второго класса настоящего времени с чередованием основы: ступень усиления — ступень ослабления

Пример:

स्तु 2 U "хвалить"

*   сильная основа настоящего времени: stau-
*   слабая основа настоящего времени:
    *   перед согласным: stu-
    *   перед гласным: stuv-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. л. ед. ч. наст. вр. P | स्तौति (stau-ti)[[br]]или: स्तवीति |
| 3\. л. мн. ч. наст. вр. P | स्तुवन्ति (stuv-anti) |
| 3\. л. ед. ч. наст. вр. Ā | स्तुते (stu-te) |
| 3\. л. мн. ч. наст. вр. Ā | स्तुवते (stuv-ate) |

:::

::::

## 17.4. Корни второго класса настоящего времени без чередования корня

Без чередования корня корни второго класса настоящего времени на -ā

Пример:

पा 2 кл. "защищать, оберегать, охранять"

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3 л. ед. ч. наст. вр. П | पाति (pā-ti) |
| 3 л. мн. ч. наст. вр. П | पान्ति (« pā- + -anti) |

:::

::::

Некоторые другие корни второго класса также не имеют чередования корня:

Примеры:

अद् 2 кл. "есть"

| 3 л. ед. ч. наст. вр. П | अत्ति (« ad- + -ti) |
| 3 л. мн. ч. наст. вр. П | अदन्ति (ad-anti) |

:::

::::

आस् 2 кл. А "сидеть"

| 3 л. ед. ч. наст. вр. А | आस्ते (ās-te) |
| 3 л. мн. ч. наст. вр. А | आसते (ās-ate) |

## 17.5. Двусложные корни на -i/-ī с чередованием основы

Несколько корней в ряде форм являются двусложными, то есть имеют перед согласным окончанием -i (либо перед некоторыми окончаниями -ī). Эти корни всё же рассматриваются местными грамматиками и в словарях и т.д. как односложные.

Примеры:

रुद् 2 П "плакать, выть"

*   сильная основа настоящего времени: rodi-
*   слабая основа настоящего времени:
    *   перед согласным: rudi-
    *   перед гласным: rud-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. вр. П | रोदिति (rodi-ti) |
| 3\. мн.ч. наст. вр. П | रुदन्ति (rud-anti) |

:::

::::

ब्रू 2 У "говорить"

*   сильная основа настоящего времени: bravī- (« bro- + -ī)
*   слабая основа настоящего времени:
    *   перед согласным: brū-
    *   перед гласным: bruv-

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. вр. П | ब्रवीति (bravī-ti) |
| 3\. мн.ч. наст. вр. П | ब्रुवन्ति (bruv-anti) |
| 3\. ед.ч. наст. вр. А | ब्रूते (brū-te) |
| 3\. мн.ч. наст. вр. А | ब्रुवते (bruv-ate) |

:::

::::

Также स्तु 2 У "хвалить" имеет, помимо указанных в п. 3 форм, формы по этому образцу:

:::: grammar-box

::: no-header

| | |
| :--- | :--- |
| 3\. ед.ч. наст. вр. П | स्तवीति (« sto + ī + ti)[[br]]или: स्तौति |

:::

::::
