

# Lektion 30

## 30.1. Die 9. Настоящее времяklasse (क्र्यादि = "क्री u.s.w.")

::: grammar-box
**Образование:**

*   сильный корень: корень в слабой степени + -nā-

*   слабый корень:

    *   перед согласным: корень в слабой степени + -nī-

    *   перед гласным: корень в слабой степени + -n-
:::

Пример:

::: indent
क्री 9U «покупать»
:::

::: grammar-box

| | Единственное число[[br]]एकवचन | Множественное число[[br]]बहुवचन |
| :--- | :--- | :--- |
| **3-е лицо[[br]]Parasmaipada** | क्रीणाति[[br]](krī + nā + ti) | क्रीणन्ति[[br]](krī + n + anti) |
| **3-е лицо[[br]]Ātmanepada** | क्रीणीते[[br]](krī + nī + te) | क्रीणते[[br]](krī + n + ate) |

:::

При этом классе настоящего времени особое внимание следует обратить на образование основы настоящего времени от корня ज्ञा 9U «познавать, знать»:

::: grammar-box

| | Единственное число[[br]]एकवचन | Множественное число[[br]]बहुवचन |
| :--- | :--- | :--- |
| **3-е лицо[[br]]Parasmaipada** | जानाति[[br]](jā-nā-ti) | जानन्ति[[br]](jā-n-anti) |
| **3-е лицо[[br]]Ātmanepada** | जानीते[[br]](jā-nī-te) | जानते[[br]](jā-n-ate) |

:::
Форма जा, лежащая в основе настоящего времени корня ज्ञा, либо объясняется чередованием гласных -ā (слабая степень) — nā (сильная степень), либо дассимиляцией от *jñā-nā-ti.

Некоторые корни с долгим гласным сокращают этот гласный перед суффиксом основы настоящего времени 9-го класса:

Пример:

::: indent
पू 9U «очищать»
:::

::: grammar-box

| | Единственное число[[br]]एकवचन | Множественное число[[br]]बहुवचन |
| :--- | :--- | :--- |
| **3-е лицо[[br]]Parasmaipada** | पुनाति[[br]](pu-nā-ti) | पुनन्ति[[br]](pu-n-anti) |
| **3-е лицо[[br]]Ātmanepada** | पुनीते[[br]](pu-nī-te) | पुनते[[br]](pu-n-ate) |

:::

Образование действительного причастия настоящего времени (Parasmaipada):

Пример:

::: indent
क्रीणन्त् (krī + n + ant); жен. род: क्रीणती (krī + n + at + ī)
:::

::: grammar-box

## 30.5. Sandhi von auslautendem -r

::: grammar-box
**За исключением случаев конечного -ar, к конечному -r применяются те же правила сандхи, что и к конечному -s.**

**-ar перед звонкими звуками сохраняется как -ar, но перед r- конечное -r выпадает, а -a- заменяется на -ā-.**
:::

Примеры:

::: indent
भवेयुर् + च » भवेयुश्च

पुनर् + अग्निः » पुनरग्निः

पुनर् + रोदिति » पुना रोदिति
:::
