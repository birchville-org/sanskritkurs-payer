# Урок 30

## 30.1. Девятый класс настоящего времени (⟪क्र्यादि⟫ = "⟪क्री⟫ и т.д.")

::: grammar-box
**Образование:**

*   сильная основа: корень в слабой степени + -nā-

*   слабая основа:

*   перед согласным: корень в слабой степени + -nī-

*   перед гласным: корень в слабой степени + -n-
:::
Пример:

::: indent
⟪क्री⟫ 9U "покупать"
:::
::: grammar-box

| |Единственное число:br⟪एकवचन⟫|Множественное число:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3 лицо:brParasmaipada**|⟪क्रीणाति⟫:br(krī + nā + ti)|⟪क्रीणन्ति⟫:br(krī + n + anti)|
|**3 лицо:brĀtmanepada**|⟪क्रीणीते⟫:br(krī + nī + te)|⟪क्रीणते⟫:br(krī + n + ate)|

:::
При этом классе настоящего времени особенно важно обратить внимание на образование основы настоящего времени от корня ⟪ज्ञा⟫ 9U "познавать, знать":

::: grammar-box

| |Единственное число:br⟪एकवचन⟫|Множественное число:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3 лицо:brParasmaipada**|⟪जानाति⟫:br(jā-nā-ti)|⟪जानन्ति⟫:br(jā-n-anti)|
|**3 лицо:brĀtmanepada**|⟪जानीते⟫:br(jā-nī-te)|⟪जानते⟫:br(jā-n-ate)|

:::
Форма ⟪जा⟫, лежащая в основе настоящего времени от корня ⟪ज्ञा⟫, может быть объяснена либо чередованием -ā (слабая степень) — nā (сильная степень), либо диссимиляцией из *jñā-nā-ti.

Некоторые корни с долгим гласным сокращают этот гласный перед суффиксом основы настоящего времени девятого класса:

Пример:

::: indent
⟪पू⟫ 9U "очищать"
:::
::: grammar-box

| |Единственное число:br⟪एकवचन⟫|Множественное число:br⟪बहुवचन⟫|
| :--- | :--- | :--- |
|**3 лицо:brParasmaipada**|⟪पुनाति⟫:br(pu-nā-ti)|⟪पुनन्ति⟫:br(pu-n-anti)|
|**3 лицо:brĀtmanepada**|⟪पुनीते⟫:br(pu-nī-te)|⟪पुनते⟫:br(pu-n-ate)|

:::
Образование действительного причастия настоящего времени Parasmaipada:

Пример:

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant) ; жен. род: ⟪क्रीणती⟫ (krī + n + at + ī)
:::
## 30.2. Употребление сослагательного наклонения (⟪लिङ्⟫)

Сослагательное наклонение употребляется:

::: grammar-box
**1. для обозначения**

*   **желания**
*   **просьбы**
*   **смягчённого повеления**

**(при этом сослагательное наклонение - ⟪लिङ्⟫ - пересекается с повелительным наклонением - ⟪लोट्⟫)**
:::
Пример:

::: indent
⟪दासो ग्राममागच्छेत्⟫ = "Пусть раб придёт в деревню"
:::
::: grammar-box
**2. Если что-то должно быть представлено как**

*   **возможное**
*   **вероятное**
*   **предполагаемое**

**.
:::
Пример:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं न शृणुयात्⟫ = "Если бы он вышел из деревни, то не услышал бы учителя"
:::
::: grammar-box
**3. Относительные придаточные предложения с сослагательным наклонением иногда имеют значение: "Если кто-то ..."**
:::
Пример:

::: indent
⟪यो नृतं वदेत्स नरकं पतेत्⟫ = "Если бы кто-то сказал неправду, он упал бы в ад = Если кто-то говорит неправду, он падает в ад"
:::
## 30.3. Вторичные окончания для 3-го лица единственного и множественного числа

Сослагательное наклонение (⟪लिङ्⟫), имперфект (⟪लङ्⟫), аорист (⟪लुङ्⟫), прекатив (⟪आशिर्लिङ्⟫) и кондиционалис имеют т.н. вторичные окончания:

::: grammar-box

| |3-е лицо ед. ч.|3-е лицо мн. ч.|
| :--- | :--- | :--- |
|**Parasmaipada**|**-t**|неатематические классы: **-an** или **-ur** :brСослагательное наклонение: **-ur**|
|**Ātmanepada**|**-ta**|неатематические классы: **-ata** (от *nta):brСослагательное наклонение: **-ran**|

:::

### 30.4.1. Тематические классы настоящего времени

**перед окончаниями, начинающимися с согласной:**

**основа настоящего времени + -i- (которая сливается с -a-, превращаясь в -e-) + вторичные окончания**

**перед окончаниями, начинающимися с гласной:**

**основа настоящего времени + -i- (» -e-) + -y- + вторичное окончание**

## 30.5. Сандхи конечного -r

::: grammar-box
**За исключением случаев с окончанием -ar, к конечному -r применяются те же правила сандхи, что и к конечному -s.**

**-ar перед звонкими звуками остаётся как -ar, но перед r- звук -r выпадает, а -a заменяется на -ā.**
:::
Примеры:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना रोदिति⟫
:::
