# Урок 30

## 30.1. 9-й класс настоящего времени (⟪क्र्यादि⟫ = "⟪क्री⟫ и т.д.")

::: grammar-box
**Образование:**

*   сильный корень: корень в слабой степени + -nā-

*   слабый корень:

    *   перед согласным: корень в слабой степени + -nī-

    *   перед гласным: корень в слабой степени + -n-
:::
Пример:

::: indent
⟪क्री⟫ 9U "покупать"
:::
::: grammar-box

| | Единственное число:br⟪एकवचन⟫ | Множественное число:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3-е лицо:brParasmaipada** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **3-е лицо:brĀtmanepada** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
При этом классе настоящего времени особенно важно обратить внимание на образование основы настоящего времени от корня ⟪ज्ञा⟫ 9U "познавать, знать":

::: grammar-box

| | Единственное число:br⟪एकवचन⟫ | Множественное число:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3-е лицо:brParasmaipada** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **3-е лицо:brĀtmanepada** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
Форма ⟪जा⟫, лежащая в основе настоящего времени от ⟪ज्ञा⟫, объясняется либо чередованием -ā (слабая степень) -nā (сильная степень), либо диссимиляцией от *jñā-nā-ti.

Некоторые корни с долгим гласным укорачивают его перед суффиксом основы настоящего времени 9-го класса:

Пример:

::: indent
⟪पू⟫ 9U "очищать"
:::
::: grammar-box

| | Единственное число:br⟪एकवचन⟫ | Множественное число:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3-е лицо:brParasmaipada** | ⟪पुनाति⟫:br(pu-nā-ti) | ⟪पुनन्ति⟫:br(pu-n-anti) |
| **3-е лицо:brĀtmanepada** | ⟪पुनीते⟫:br(pu-nī-te) | ⟪पुनते⟫:br(pu-n-ate) |

:::
Образование причастия настоящего времени Parasmaipada:

Пример:

::: indent
⟪क्रीणन्त्⟫ (krī + n + ant) ; жен. род: ⟪क्रीणती⟫ (krī + n + at + ī)
:::
## 30.2. Использование сослагательного наклонения (⟪लिङ्⟫)

Сослагательное наклонение используется:

::: grammar-box
**1. для обозначения**

*   **желания**
*   **просьбы**
*   **смягчённого приказа**

**(здесь сослагательное наклонение - ⟪लिङ्⟫ - пересекается с повелительным наклонением - ⟪लोट्⟫)**
:::
Пример:

::: indent
⟪दासो⟫ ⟪ग्राममागच्छेत्⟫ = «Пусть крепостной придёт в деревню»
:::
::: grammar-box
**2. Если что-то представлено как**

*   **возможное**
*   **вероятное**
*   **предполагаемое**

**следует отразить.**
:::
Пример:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं⟫ ⟪न⟫ ⟪शृणुयात्⟫ = «Если бы он ушёл из деревни, он не услышал бы хозяина»
:::
::: grammar-box
**3. Относительные придаточные с сослагательным наклонением иногда имеют значение: «Если кто-то ...»**
:::
Пример:

::: indent
⟪यो⟫ ⟪नृतं⟫ ⟪वदेत्स⟫ ⟪नरकं⟫ ⟪पतेत्⟫ = «Если бы кто-то сказал неправду, он упал бы в ад = Если кто-то говорит неправду, он падает в ад»
:::
## 30.3. Вторичные окончания 3-го лица единственного и множественного числа

Оптив (⟪लिङ्⟫), имперфект (⟪लङ्⟫), аорист (⟪लुङ्⟫), прекатив (⟪आशिर्लिङ्⟫) и кондиционалис имеют так называемые вторичные окончания:

::: grammar-box

| | 3. Person Единственное число | 3. Person Множественное число |
| :--- | :--- | :--- |
| **Парасмайпада** | **-t** | athematische Klassen: **-an** oder **-ur** :brОптатив: **-ur** |
| **Āтманепада** | **-ta** | athematische Klassen: **-ata** (aus *nta):brОптатив: **-ran** |

:::

## 30.5. Сандхи конечного -r

::: grammar-box
**Для конечного -r, за исключением случаев -ar, действуют те же правила сандхи, что и для конечного -s.**

**-ar перед звонкими звуками остается -ar, но перед r- конечное -r выпадает, а -a- заменяется на -ā-.**
:::
Примеры:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
