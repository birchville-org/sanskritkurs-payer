# Деванагари = देवनागरी

## Практика письма 1

Сanskrit писался и продолжает писаться множеством различных систем письма. Следующая таблица представляет небольшой фрагмент этих систем:

![](/images/schrift001.webp)  
Рис.: Образцы письма на санскрите  
\[Источник изображения: Википедия, лицензия GNU FD\]

Die wichtigste moderne nordindische Sanskritschrift ist die Devanāgarī:

![](/images/schrift002.webp)

Каждая буква согласного обозначает также следующее за согласным звук «a». Если нужно записать чистый согласный (без следующего гласного), это обозначается нижним наклонным штрихом — вирамой = विराम — следующим образом:

क् = k, च् = c, ट् = ṭ, त्  = t, प् = p

Следующие за согласным гласные — кроме «a» — записываются так:

का = kā, कि = ki, की = kī, कु = ku, कू = kū, कृ = kṛ, कॄ = kṝ, कॢ  = kḷ

के = ke, कै = kai, को = ko, कौ = kau

Порядок записи таких сочетаний «согласный + гласный» следующий:

![](/images/schrift003.jpg)

При написании каждая буква, включая поперечную черту, полностью завершается на верхней линии, прежде чем пишется следующая буква.

## Упражнение

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

Прочитайте и транслитерируйте:

तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ
