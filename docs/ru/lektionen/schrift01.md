# Devanāgarī = ⟪देवनागरी⟫

## Письменное упражнение 1

Санскрит писался и пишется множеством различных шрифтов. Приведенная ниже обзорная таблица демонстрирует небольшой фрагмент этих письменностей:

![](/images/schrift001.webp)  
Рис.: Образцы санскритского письма
\[Источник изображения: Википедия, лицензия GNU FD\]

Самым важным современным североиндийским письмом санскрита является деванагари:

![](/images/schrift002.webp)

Каждый знак согласного обозначает также следующую за ним гласную «a». Если необходимо написать чистый согласный (без следующей гласной), это следует обозначить подстрочным слэшем -- вирама = ⟪विराम⟫ --:

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

Гласные, следующие за согласным (кроме «a»), пишутся следующим образом:

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

Порядок записи таких сочетаний «согласный + гласный» следующий:

![](/images/schrift003.jpg)

При письме каждая буква, включая горизонтальную черту (шире), завершается полностью перед тем, как пишется следующая буква.

## Упражнение

Schreiben Sie in Devanāgarī:

kaka kāka kapa kapi kaṭa kuṭi tap tac cāpa kṛta caita cūta pat pitā pīta puta cātu cāti ṭīkā ṭāka ṭoṭa tepa tṛta kḷp kopa kaupa poka peta tṝ pṝ pṛc pat pati capeṭā

Прочитайте и транслитерируйте:

⟪तॄ पाप चट् चि चाप पॄ पति पितृ कॢप् कृ कुप् कुतो चैक पुट पचति तौ पू चेत् पतति ततो तट तपति तु ते कृ पीतौ⟫

Дополнительное упражнение на чтение:

⟪पिता⟫ отец, ⟪कपि⟫ обезьяна, ⟪कृत⟫ сделал,  ⟪टीका⟫ субкомментарий, ⟪तत्⟫ этот, ⟪तट⟫ берег, ⟪पत्⟫ стрелять, ⟪पट⟫ ткань, ⟪काच⟫ стекло,  ⟪काकुत्⟫ нёбо, ⟪चित्⟫ воспринимать, ⟪पृच्⟫ смешивать,  ⟪पोटक⟫ слуга, ⟪चेतु⟫ намерение, ⟪तौतातित⟫ последователь Кумарилы (Миманса), ⟪तूत⟫ тутовое дерево, ⟪पीत⟫ выпил,  ⟪पीति⟫ напиток, ⟪कॢप्⟫  подходить, ⟪कृपते⟫ он сетует, ⟪पुटी⟫ складка, ⟪चापि⟫ подобно, ⟪तोक⟫ потомство, ⟪तृपत्⟫ сытый, ⟪पॄ⟫ наполнять, ⟪कृकाटी⟫ шейный позвонок, ⟪पूपौ⟫ два куска пирога, ⟪पैतृकी⟫ отцовский (жен. род), ⟪कौट⟫ обманчивый, ⟪कच⟫ волосы на голове, ⟪कुतपे⟫ на одеяле из козьей шерсти, ⟪कुचौ⟫ грудь, ⟪चकिता⟫ испуганный (жен. род)
