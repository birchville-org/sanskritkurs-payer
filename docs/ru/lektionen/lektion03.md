# Урок 3

:::deleteme-box
**На этом уроке вы изучите:**
- именительный падеж единственного числа среднего рода
- именительный падеж множественного числа мужского и среднего рода
- образование среднего рода от мужских основ
- вокалический сандхи
- Сандхи предложений для -ās
:::## 3.1. Единственное число именительного падежа женского рода

### 3.1.1. Именительный падеж единственного числа на -s

Следующие основы существительных, оканчивающиеся на гласный, образуют именительный падеж единственного числа на **-s**:

:::grammar-box
- **Женского рода на -i**: например, **śruti** ж.р. "слышание" -- И.п. ед.ч.: **śrutis** = ⟪श्रुतिस्⟫
- **Женского рода на -u**: например, **dhenu** ж.р. "дойная корова" -- И.п. ед.ч.: **dhenus** = ⟪धेनुस्⟫
:::### 3.1.2. Именительный падеж единственного числа без окончания

Именительный падеж единственного числа образуется без окончания:

:::grammar-box
- **Женский род на -ā**: напр. **devatā** ж.р. "божество" -- И.п. ед.ч.: **devatā** = ⟪देवता⟫
- **Женский род на -ī**: напр. **devī** ж.р. "богиня" -- И.п. ед.ч.: **devī** = ⟪देवी⟫
::::::important
**Внимание!** Наряду с этим существуют односложные женские корневые существительные на -ī, у которых именительный падеж единственного числа оканчивается на -s: напр. dhī ж.р. "мысль" -- И.п. ед.ч.: dhīs = ⟪धीस्⟫. Также lakṣmī (⟪लक्ष्मी⟫) ж.р., tarī (⟪तरी⟫) ж.р. "лодка" и tantrī (⟪तन्त्री⟫) ж.р. "струна" образуют именительный падеж единственного числа на -s нерегулярно: lakṣmīs = ⟪लक्ष्मीस्⟫.
:::---

## 3.2. Образование женского рода от существительных мужского рода

:::grammar-box
**Существительные мужского рода на -a:**
- **Женский род на -ā**: напр. **kṣatriya** м. р. » **kṣatriyā** ж. р. «Кшатри-женщина» = ⟪क्षत्रिया⟫
- **Женский род на -ī**: напр. **brāhmaṇa** м. р. » **brāhmaṇī** ж. р. «Брахманинка» = ⟪ब्राह्मणी⟫

**Существительные мужского рода на -u:**
- **Женский род на -ī**: напр. **sādhu** м. р. » **sādhvī** ж. р. (благородный, святая) = ⟪साध्वी⟫
  (**-u-** перед гласной превращается в **-v-**, поэтому **-u- + -ī** » **-vī**)
:::---

## 3.3. Именительный падеж, множественное число, мужской и женский род

:::grammar-box
Окончание именительного падежа множественного числа в мужском и женском роде — **-as**.
- **Мужской род на -a**: **deva- + -as** » **devās** = ⟪देवास्⟫
- **Женский род на -ā**: **devatā- + -as** » **devatās** = ⟪देवतास्⟫
- **Мужской род на -i**: **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
- **Женский род на -i**: **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
- **Женский род на -ī**: **devī- + -as** » **devyas** = ⟪देव्यस्⟫
- **Мужской род на -u**: **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
- **Женский род на -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫
:::Примечание: **e** является усиленной ступенью (**гуна**) от **i**, **o** — усиленной ступенью от **u**.

## 3.4. Вокалический сандхи

:::grammar-box
**Простые гласные, которые отличаются друг от друга только длиной или не отличаются вовсе, «сливаются» в соответствующий долгий гласный:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::напр.

devatā + annapūrṇā » devatānnapūrṇā «Аннапурна — это богиня» = ⟪देवतान्नपूर्णा⟫

> (Аннапурна — богиня пищи и кулинарии, она считается воплощением Парвати, супруги Шивы.)

devī + indrāṇī » devīndrāṇī «Индра́ни — это богиня» = ⟪देवीन्द्राणी⟫

> (Индра́ни — супруга бога Индры.)

:::media
![](/images/lekt0301.webp)
Рис.: Индра и Индра́ни на слоне Айравате, миниатюра, Раджастхан, 1670/80
(Источник изображения: [Подробности](/ru/licenses#lekt0301))
::::::grammar-box
**Простые гласные (кроме -a / -ā) перед неодинаковыми гласными заменяются на соответствующий полугласный:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
(!! К этому правилу существуют, особенно для форм двойственного числа, исключения !!)
:::напр.

devī + umā » devy umā «Ума — это / та самая богиня» = ⟪देव्युमा⟫

> (Ума — имя Парвати, супруги Шивы)

:::grammar-box
**-a / -ā перед неодинаковым гласным:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::Для данного сандхи действует следующая схема:

:::См. далее об этом так называемом чередовании основ!

напр.

śūdrā + itarā » śudretarā «Итара — шудра» = ⟪शूद्रेतरा⟫

## 3.5. Сандхи предложений для -ās

:::grammar-box
**-ās wird vor allen stimmhaften Lauten durch -ā ersetzt.**
:::например,

dvijās + vaiśyāḥ » dvijā vaiśyāḥ «Вайшьи — дваждырождённые» = ⟪द्विजा⟫ ⟪वैश्याः⟫

## 3.6. Список слов

**Выучите следующие слова:**

**śruti** ж. р. = ⟪श्रुति⟫ : слушание, вечное предание (название для Вед и Брахман).

**smṛti** ж. р. = ⟪स्मृति⟫ : воспроизведение, память, медитативное воспроизведение = осознанность, предание (противоположность **śruti**). Включает:
- шесть **vedāṅga** ср. р. (⟪वेदाङ्ग⟫)
  1. **śikṣā** ж. р. (⟪शिक्षा⟫): правильное произношение
  2. **chandas** ср. р. (⟪छन्दस्⟫): метрика
  3. **vyākaraṇa** ср. р. (⟪व्याकरण⟫): грамматика
  4. **nirukta** ср. р. (⟪निरुक्त⟫) : объяснение слов, этимология
  5. **jyotiṣa** ср. р. (⟪ज्योतिष⟫) : астрономия, календарное учение
  6. **kalpa** м. р. (⟪कल्प⟫) : церемониал
- **śrautasūtra** ср. р. (⟪श्रौतसूत्र⟫) : учебные тексты для проведения больших жертвоприношений
- **gṛhyasūtra** ср. р. (⟪गृह्यसूत्र⟫) : учебные тексты для церемоний и жертвоприношений повседневной жизни
- **dharmasūtra** ср. р. (⟪धर्मसूत्र⟫) и **dharmaśāstra** ср. р. (⟪धर्मशास्त्र⟫) : учебные тексты о праве и обычаях (правильное поведение)
- великие эпосы **mahābhārata** ср. р. (⟪महाभारत⟫) и **rāmāyaṇa** ср. р. (⟪रामायण⟫)
- **purāṇa** м. р. (⟪पुराण⟫)
- **nītiśāstra** ср. р. (⟪नीतिशास्त्र⟫) : учебные тексты о жизненной мудрости

**smṛti** также особенно является названием для текстов о дхарме.

**dhenu** ж. р. = ⟪धेनु⟫ : (молочная) корова.

**paśu** м. р. = ⟪पशु⟫ : одомашненное полезное животное, скот (коллективное число).

**devatā** ж. р. = ⟪देवता⟫ : божество (абстрактное и конкретное).

**brāhmaṇī** ж. р. = ⟪ब्राह्मणी⟫ : брахманка.

**kṣatriyā** ж. р. = ⟪क्षत्रिया⟫ : женщина-кшатрий.

**kṣatriyī** ж. р. = ⟪क्षत्रियी⟫ : жена кшатрия.

**vaiśyā** ж. р. = ⟪वैश्या⟫ : женщина-вайшья.

**śūdrā** ж. р. = ⟪शूद्रा⟫ : женщина-шудра.

**śūdrī** ж. р. / **śūdrāṇī** ж. р. = ⟪शूद्री⟫ ⟪शूद्राणी⟫ : жена шудры.

**devī** ж. р. = ⟪देवी⟫ : богиня, в особенности Дурга ж. р. = ⟪दुर्गा⟫, супруга Шивы = ⟪शिव⟫.

:::media
![](/images/lekt0303.webp)
Рис.: Дурга = ⟪दुर्गा⟫, Орисса
(Источник изображения: [Подробности](/images/lekt0303))
:::**sādhvī** ж. р. = ⟪साध्वी⟫ : женский род от sādhu.

**gurvī** ж. р. = ⟪गुर्वी⟫ : женский род от guru.

**asmitā** ж. р. = ⟪अस्मिता⟫ : "я-бытие", т.е. (ложное) верование: **Я** есть тот, кто видит и т.д.

**ānvīkṣikī** ж. р. = ⟪आन्वीक्षिकी⟫ : философия (наука, которая приходит к своим выводам через логически корректные обоснования).

**upekṣā** ж. р. = ⟪उपेक्षा⟫ : невнимание, равнодушие.

**karuṇā** ж. р. = ⟪करुणा⟫ : сострадание, жалость.

**muditā** ж. р. = ⟪मुदिता⟫ : радость, в особенности со-радость (противоположность зависти).

## 3.7. Упражнение

**A) Преобразуйте следующие предложения во множественное число:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो⟫ ⟪ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः⟫ ⟪क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो⟫ ⟪वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः⟫ ⟪कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी⟫ ⟪ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता⟫ ⟪गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी⟫ ⟪साध्वी⟫

**B) Составьте номинальные предложения, вставив пропущенные слова:**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Переведите в женский род:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**D) Переведите на санскрит:**

1. Ума — богиня.
2. Веда — шрути.
3. Учителя — богини.
4. Коро́вы — одомашненные животные.
5. Поэты — учителя.
6. Кшатрии — дваждырожденные.
7. Священные люди — шудры.
