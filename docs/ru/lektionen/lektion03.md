## 3.1. Именительный падеж Единственное число des Женский родs

### 3.1.1. Именительный падеж Единственное число auf -s

Auch folgende Nominalstämme, die mit einem Vokal enden, bilden den Nominativ Singular auf **-s**: <!-- TODO: Fallback translation -->

::: grammar-box
- **Feminina auf -i**: z.B. **śruti** f. "das Hören" -- Nom. sg.: **śrutis** = श्रुतिस् <!-- TODO: Fallback translation -->
- **Feminina auf -u**: z.B. **dhenu** f. "Milchkuh" -- Nom. sg.: **dhenus** = धेनुस् <!-- TODO: Fallback translation -->
:::

### 3.1.2. Именительный падеж Единственное число ohne Окончание

Den Nominativ Singular bilden ohne Endung: <!-- TODO: Fallback translation -->

::: grammar-box
- **Feminina auf -ā**: z.B. **devatā** f. "Gottheit" -- Nom. sg.: **devatā** = देवता <!-- TODO: Fallback translation -->
- **Feminina auf -ī**: z.B. **devī** f. "Göttin" -- Nom. sg.: **devī** = देवी <!-- TODO: Fallback translation -->
:::

::: important
**Achtung!** Daneben gibt es einsilbige feminine Wurzelnomina auf -ī, deren Nominativ Singular auf -s endet: z.B. dhī f. "Gedanke" -- Nom. sg.: dhīs = धीस्. Auch lakṣmī (लक्ष्मी) f., tarī (तरी) f. "Boot" und tantrī (तन्त्री) f. "Saite" bilden unregelmäßig den Nominativ Singular auf -s: lakṣmīs = लक्ष्मीस्. <!-- TODO: Fallback translation -->
:::

## 3.2. Образование der Feminina zu Maskulina

::: grammar-box
**Мужские существительные на -a:**
- **Женские существительные на -ā**: напр. **kṣatriya** м.р. » **kṣatriyā** ж.р. «кшатрийка» = क्षत्रिया
- **Женские существительные на -ī**: напр. **brāhmaṇa** м.р. » **brāhmaṇī** ж.р. «брахманка» = ब्राह्मणी

**Мужские существительные на -u:**
- **Женские существительные на -ī**: напр. **sādhu** м.р. » **sādhvī** ж.р. (благородная, святая) = साध्वी
  (**-u-** перед гласной превращается в **-v-**, поэтому **-u- + -ī** » **-vī**)
:::

## 3.3. Именительный падеж Множественное число Мужской род und Женский род

::: grammar-box
Окончание именительного падежа множественного числа для мужского и женского рода — **-as**.

- **Мужской род на -a**: **deva- + -as** » **devās** = देवास्
- **Женский род на -ā**: **devatā- + -as** » **devatās** = देवतास्
- **Мужской род на -i**: **kavi-** » **kave- + -as** » **kavayas** = कवयस्
- **Женский род на -i**: **śruti-** » **śrute- + -as** » **śrutayas** = श्रुतयस्
- **Женский род на -ī**: **devī- + -as** » **devyas** = देव्यस्
- **Мужской род на -u**: **guru-** » **guro- + -as** » **guravas** = गुरवस्
- **Женский род на -u**: **dhenu-** » **dheno- + -as** » **dhenavas** = धेनवस्
:::

Примечание: **e** является усиленной ступенью (**гуна**) от **i**, **o** является усиленной ступенью от **u**.

## 3.4. Vokalsandhi

::: grammar-box
**Простые гласные, которые различаются либо не различаются вовсе, либо только по длине, «сливаются» в соответствующий долгий гласный:**
- -a / -ā + a- / ā- » **-ā-**
- -i / -ī + i- / ī- » **-ī-**
- -u / -ū + u- / ū- » **-ū-**
- (-ṛ + ṛ- » **-ṝ-**)
:::

напр.

devatā + annapūrṇā » devatānnapūrṇā «Аннапурна — это божество» = देवतान्नपूर्णा

> (Аннапурна — богиня пищи и кулинарии, она считается воплощением Парвати, супруги Шивы.)

devī + indrāṇī » devīndrāṇī «Индрани — это богиня» = देवीन्द्राणी

> (Индрани — супруга бога Индры.)

::: media
![](/images/lekt0301.jpg)
Рис. Индра и Индрани на слоне Айравате, миниатюра, Раджастхан, 1670/80
(Источник изображения: [Детали](/licenses#lekt0301))
:::

::: grammar-box
**Простые гласные (кроме -a / -ā) перед неодинаковыми гласными заменяются соответствующим полугласным:**
- -i / -ī » **-y-**
- -u / -ū » **-v-**
- -ṛ » **-r-**
 (!! К этому правилу существуют исключения, особенно для форм двойственного числа !!)
:::

напр.

devī + umā » devy umā «Ума — это / богиня» = देव्युमा

> (Ума — имя Парвати, супруги Шивы)

::: grammar-box
**-a / -ā перед неодинаковым гласным:**
- -a / -ā + i- / ī- » **-e-**
- -a / -ā + ṛ- » **-ar-**
- -a / -ā + e- / ai- » **-ai-**
- -a / -ā + o- / au- » **-au-**
:::

Для данного сандхи применяется следующая схема:

напр.

śūdrā + itarā » śudretarā «Итара — женщина из шудр» = शूद्रेतरा

## 3.5. Satzsandhi von -ās

::: grammar-box
**Окончание -ās перед всеми звонкими звуками заменяется на -ā.**
:::

напр.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ «Вайшьи — дваждырождённые» = द्विजा वैश्याः

## 3.6. Словарь

**śruti** ж.р. = श्रुति : слушание, вечное предание (название для Вед и Брахман).

**smṛti** ж.р. = स्मृти : воспроизведение в памяти, воспоминание, медитативное воспроизведение = осознанность, предание (противоположное понятие по отношению к **śruti**). Включает:
- шесть **vedāṅga** ср.р. (वेदाङ्г)
  1. **śikṣā** ж.р. (शिक्षа): правильное произношение
  2. **chandas** ср.р. (छन्दас): метр
  3. **vyākaraṇa** ср.р. (व्याकरण): грамматика
  4. **nirukta** ср.р. (निरुक्त): объяснение слов, этимология
  5. **jyotiṣa** ср.р. (ज्योतिष): астрономия, учение о календаре
  6. **kalpa** м.р. (कल्प): церемониал
- **śrautasūtra** ср.р. (श्रौतसूत्र): учебные тексты для проведения великих жертвоприношений
- **gṛhyasūtra** ср.р. (गृह्यसूत्र): учебные тексты для церемоний и жертвоприношений повседневной жизни
- **dharmasūtra** ср.р. (धर्मसूत्र) и **dharmaśāstra** ср.р. (धर्मशास्त्र): учебные тексты о праве и обычаях (правильном поведении)
- великие эпосы **mahābhārata** ср.р. (महाभारत) и **rāmāyaṇa** ср.р. (रामायण)
- **purāṇa** ср.р. (पुराण)
- **nītiśāstra** ср.р. (नीतिशास्тр): учебные тексты о жизненной мудрости

**smṛti** является также особым названием для текстов о дхарме.

**dhenu** ж.р. = धेनु : (молочная) корова.

**paśu** м.р. = पशु : одомашненное сельскохозяйственное животное, скот (собирательное понятие).

**devatā** ж.р. = देवता : божество (абстрактное и конкретное).

**brāhmaṇī** ж.р. = ब्राह्मणी : брахманка.

**kṣatriyā** ж.р. = क्षत्रिया : женщина-кшатрий.

**kṣatriyī** ж.р. = क्षत्रियī : жена кшатрия.

**vaiśyā** ж.р. = वैश्या : женщина-вайшья.

**śūdrā** ж.р. = शूद्रा : женщина-шудра.

**śūdrī** ж.р. / **śūdrāṇī** ж.р. = शूद्री शूद्राणी : жена шудры.

**devī** ж.р. = देवी : богиня, в частности Durgā ж.р. = दुर्गा, супруга Шивы = शिव.

::: media
![](/images/lekt0303.jpg)
Рис.: Durgā = दुर्га, Орисса
(Источник изображения: [Details](/images/lekt0303))
:::

**sādhvī** ж.р. = साध्वī : женский род от sādhu.

**gurvī** ж.р. = गुर्वī : женский род от guru.

**asmitā** ж.р. = अस्मिता : «я-бытие», то есть (ложное) убеждение: **Я** есть тот, кто видит и т.д.

**ānvīkṣikī** ж.р. = आन्वीक्षिकī : философия (наука, которая приходит к своим выводам посредством логически корректных обоснований).

**upekṣā** ж.р. = उपेक्षा : невнимание, равнодушие.

**karuṇā** ж.р. = करुणा : сострадание, жалость.

**muditā** ж.р. = मुदितā : радость, в частности сочувственная радость (противоположность зависти).

## 3.7. Упражнение

**A) Преобразуйте следующие предложения во множественное число:**

1. dvijo brāhmaṇaḥ = द्विजो ब्राह्मणः
2. dvijaḥ kṣatriyaḥ = द्विजः क्षत्रियः
3. dvijo vaiśyaḥ = द्विजो वैश्यः
4. gurur brāhmaṇaḥ = गुरुर्ब्राह्मणः
5. sādhur guruḥ = साधुर्गुरुः
6. guruḥ kaviḥ = गुरुः कविः
7. sādhvī brāhmaṇī = साध्वी ब्राह्मणी
8. devatā guruḥ = देवता गुरुः
9. paśur dhenuḥ = पशुर्धेनुः
10. gurvī sādhvī = गुर्वी साध्वी

**B) Составьте номинальные предложения, подставив указанные слова:**

1. śrutis ... (veda) = श्रुतिस् ... वेद
2. paśus ... (dhenu) = पशुस् ... धेनु
3. devī ... (durgā, umā, indrāṇī) = देवी ... दुर्गा, उमा, इन्द्राणी
4. devatā ... (mīnākṣī, annapūrṇā) = देवता ... मीनाक्षी, अन्नपूर्णा
5. śūdrā ... (itarā) = शूद्रा ... इतरा

**C) Переведите в женский род:**

1. gurur brāhmaṇaḥ = गुरुर्ब्राह्मणः
2. sādhur guruḥ = साधुर्गुरुः
3. kṣatriyaḥ sādhuḥ = क्षत्रियः साधुः

**D) Переведите на санскрит:**

1. Ума является богиней.
2. Веда является śruti.
3. Учителя являются богинями.
4. Коро́вы являются одомашненными животными.
5. Поэты являются учителями.
6. Кшатрии являются дваждырожденными.
7. Святые люди являются шудрами.
