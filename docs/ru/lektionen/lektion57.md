# Урок 57

## 57.1. Аорист 4: s-аорист

::: grammar-box
**s-аорист образуется от большинства ⟪अनिट्⟫-основ, если у них нет исключительно другой формы аориста. Факультативные ⟪अनिट्⟫-основы в целом могут образовывать либо этот, либо iṣ-аорист. Также ⟪अनिट्⟫-основы, которые образуют ⟪परस्मैपद⟫ после 1., 2. или 6. формы аориста, образуют ⟪आत्मनेपद⟫ по модели s-аориста.**

**Образование:_augment_ + основа + s + атематическое вторичное окончание**
:::
Таблица окончаний с суффиксом образования основы

::: grammar-box

|   | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| :--- | :---: | :---: | :---: | :---: |
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **1. ⟪तृतीयः⟫** | -sam | -sma | -si | -smahi |
| **2. ⟪द्वितीयः⟫** | **-sīs** | -sta | -sthās | **-dhvam** |
| **3. ⟪प्रथमः⟫** | **-sīt** | -sur | -sta | -sata |
:::
::: grammar-box
**Применяется общее фонетическое правило, согласно которому шипящий выпадает между двумя смычными (ср. ⟪उद्⟫ + ⟪स्थित⟫ » ⟪उत्थित⟫), т.е. суффикс образования основы -s- перед окончаниями, начинающимися на -t- или -th-, выпадает (но не после носовых или r-).**

Примеры:

:::
::: indent
3.ед.ā a-kṣip + s + ta » ⟪अ⟫**:sig[⟪क्षिप्त⟫]**
2.ед.ā a-kṣip + s + thās » ⟪अ⟫**:sig[⟪क्षिप्था⟫]**⟪स्⟫
:::
Такие формы могли бы также относиться к основному аористу и, вероятно, частично действительно к нему относятся.
Индийские грамматики также причислили формы вида :sig[⟪अकृत⟫] (3.ед.ā) к s-аористу, которые явно относятся к основному аористу. Для этой цели индийские грамматики изобрели следующее эклектическое фонетическое правило для s-аориста:

::: indent
"После краткого гласного 'окончания', начинающиеся на -st- или -sth-, теряют -s-."
:::
В остальных случаях следует учитывать фонетические правила соединения конечных согласных с s-.

Для -dhvam действует:

::: grammar-box
**-dh- в -dhvam после всех нем/a/ā-гласных, а также после -r, заменяется на -ḍh-.**

:::
::: indent
напр. **:sig[⟪चि⟫]** 5U: 2.мн.ā **:sig[⟪अचेढ्वम्⟫]**
:::
::: grammar-box
**Форма основы:**

*   **⟪परस्मैपद⟫ : удлиненная ступень**
*   **⟪आत्मनेपद⟫ :**
    *   **основы с конечным i/ī/u/ū: высокая ступень**
    *   **конечное -ṝ заменяется на -īr или -ūr**
    *   **основы с чередованием ā/e/o: низкая ступень**
    *   **другие гласные основы: без изменений (т.е. обычно низкая ступень)**
:::
Примеры:

|   | **3.ед.р** |
| --- | --- |
| :sig[⟪चि⟫] 5U | ⟪अचैषीत्⟫ |
| ⟪श्रु⟫ 5P | ⟪अश्रौषीत्⟫ |
| ⟪कृ⟫ 8U | ⟪अकार्षीत्⟫ |
| ⟪भज्⟫ 1U | ⟪अभाक्षीत्⟫ |
| ⟪भञ्ज्⟫ 7P | ⟪अभाङ्क्षीत्⟫ |
| ⟪भुज्⟫ 7U | ⟪अभौक्षीत्⟫ |

|   | **3.ед.а** |
| --- | --- |
| :sig[⟪चि⟫] 5U | ⟪अचेष्ट⟫ |
| ⟪नी⟫ 1U | ⟪अनेष्ट⟫ |
| ⟪सू⟫ 2/4 | ⟪असोष्ट⟫ |
|   | **ед.а** |
| ⟪दा⟫ 3U | ⟪अदिषि⟫:br ⟪अदिथास्⟫ :br ⟪अदित⟫ |
|   | **1.ед.а** |
| ⟪कृ⟫ 8U | ⟪अकृषि⟫ |
| ⟪पच्⟫ 1U | ⟪अपक्षि⟫ |

::: grammar-box
**⟪दृश्⟫ и ⟪सृज्⟫ имеют в ⟪परस्मैपद⟫ удлиненную ступень с восходящим дифтонгом -rā-:**

:::
::: indent
⟪दृश्⟫ 3.ед.р ⟪अ⟫**:sig[⟪द्राक्षी⟫]**⟪त्⟫
:::
Аорист других корней с -ṛ- на предпоследнем месте тоже может образовываться таким образом:

::: indent
⟪कृष्⟫ 1P/6U 3.ед.р ⟪अकार्क्षीत्⟫ / ⟪अ⟫**:sig[⟪क्राक्षी⟫]**⟪त्⟫
:::

**Нерегулярные формы:**

**1. Корни на носовой (⟪गम्⟫, ⟪मन्⟫, ⟪रम्⟫) образуют s-аорист с высокой ступенью:**
**⟪अगंसि⟫ ⟪।⟫ ⟪अमंसि⟫ ⟪।⟫ ⟪अरंस्त⟫**
**Помимо этого, для ⟪गम्⟫ существуют регулярные формы с низкой ступенью:**
**⟪अगसि⟫ (« \*a-gm-si) ⟪।⟫ ⟪अगथास्⟫ ⟪।⟫ ⟪अगत⟫ (в перфекте ⟪गम्⟫ имеет тематический аорист)**

2.  ⟪पद्⟫ 4Ā является регулярным (например, ⟪अपत्सि⟫), но в 3.ед.ч.Ā он имеет форму пассивного корневой аориста:
    ⟪अपादि⟫ «он пошёл»

3.  ⟪बुध्⟫ Ā может в 3.ед.ч.Ā по выбору принимать форму пассивного корневой аориста:
    ⟪अबोधि⟫ / ⟪अबुद्ध⟫ «он узнал»
:::
