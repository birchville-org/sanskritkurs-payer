# Урок 43

## 43.1. Личные окончания 2-го лица (⟪मध्यमः⟫ = "средняя \&lt;персона\&gt;")

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||
| --- | --- | --- | --- | --- |
| | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| **Первичные окончания** | -si | -tha | -se | -dhve |
| **Вторичные окончания** | -s | -ta | -thās | -dhvam |
| **Окончания перфекта** | -tha | -a | -se | -dhve |
:::
Обратите внимание, что вторичное окончание 2-го лица мн.ч. тождественно вторичному окончанию 3-го лица ед.ч. А.

## 43.2. Образование глагольных форм 2-го лица (⟪मध्यमः⟫)

2-е лицо:

*   Единственное число: "ты"
*   Множественное число: "вы" (более двух!)

## 43.3. Личное местоимение второго лица

*   Единственное число: ⟪त्वद्⟫ "ты"
*   Множественное число: ⟪युष्मद्⟫ "вы"

::: grammar-box
| | ⟪एकवचनम्⟫ (⟪त्वद्⟫) | ⟪बहुवचनम्⟫ (⟪युष्मद्⟫) |
| --- | --- | --- |
| ⟪प्रथमा⟫ | ⟪त्वम्⟫ | ⟪यूयम्⟫ |
| ⟪द्वितीया⟫ | ⟪त्वाम्⟫ ⟪त्वा⟫ | ⟪युष्मान्⟫ ⟪वस्⟫ |
| ⟪तृतीया⟫ | ⟪त्वया⟫ | ⟪युष्माभिस्⟫ |
| ⟪चतुर्थी⟫ | ⟪तुभ्यम्⟫ ⟪ते⟫ | ⟪युष्मभ्यम्⟫ ⟪वस्⟫ |
| ⟪पञ्चमी⟫ | ⟪त्वत्⟫ | ⟪युष्मत्⟫ |
| ⟪षष्ठी⟫ | ⟪तव⟫ ⟪ते⟫ | ⟪युष्माकम्⟫ ⟪वस्⟫ |
| ⟪सप्तमी⟫ | ⟪त्वयि⟫ | ⟪युष्मासु⟫ |
:::
Формы ⟪त्वा⟫, ⟪ते⟫, ⟪वस्⟫ не могут использоваться в начале предложения или стихотворной строки. Они также не могут использоваться перед ⟪च⟫, ⟪वा⟫, ⟪एव⟫ и некоторыми другими частицами:

::: indent
⟪त्वां⟫ ⟪मां⟫ ⟪च⟫ "тебя и меня"
:::
