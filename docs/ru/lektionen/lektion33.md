# Урок 33

## 33.1. Повторение (⟪अभ्यास⟫ m.)

* Третий класс настоящего времени
* (а также некоторые глаголы других классов настоящего времени),
* совершенное время,
* аорист с повторением,
* фрекватив и
* десидератив

образуются с помощью повторения. Часть редуплицированной формы, которая ставится перед корнем, называется слогом повторения.

Слог повторения состоит из (одного согласного и) гласного.

### 33.1.1. Согласный редупликации

:::grammar-box
**1. Обычно:**  
**Повторение первого согласного корня**
:::
Примеры:

:::indent
**⟪दा⟫** 3 "давать"
* 3.sg.P.Ind.Präs. **⟪ददाति⟫**

**⟪पॄ⟫** 3 "наполнять"
* 3.sg.P.Ind.Präs. ***⟪पि⟫***⟪पर्ति⟫

**⟪मा⟫** 3Ā "измерять"
* 3.sg.Ā.Ind.Präs. ***⟪मि⟫***⟪मीते⟫
::::::grammar-box
**2. Аспирированный начальный согласный корня редуплицируется соответствующим неаспирatedным согласным.**
:::
Примеры:

:::indent
**⟪धा⟫** 3 "сидеть"
* 3.sg.P.Ind.Präs. **⟪दधाति⟫**

**⟪भी⟫** 3 "бояться"
* 3.sg.P.Ind.Präs. ***⟪बि⟫***⟪भेति⟫
:::::::grammar-box
**3. Гуттуральный звук редуплицируется соответствующим ему неаспирatedным палатальным:**

:::indent
**⟪क्⟫**, **⟪ख्⟫** через **⟪च्⟫**  
**⟪ग्⟫**, **⟪घ्⟫** через **⟪ज्⟫**
:::
**⟪ह्⟫ всегда редуплицируется через ⟪ज्⟫.**
::::
Примеры:

:::indent
**⟪हु⟫** 3 "(жертвенный огонь) лить"
* 3.sg.P.Ind.Präs. **⟪जुहोति⟫**
::::::grammar-box
**4. Если корень начинается с нескольких согласных, повторяется только первый (возможно, с применением правил 2 или 3).**
::::::grammar-box
**5. Если корень начинается с группы согласных, состоящей из шипящего и глухого согласного, то шипящий не повторяется, а глухой согласный, следующий за ним, редуплицируется согласно вышеуказанным правилам.**
:::
Пример:

:::indent
**⟪स्था⟫** 1 "стоять"
* 3.sg.P.Ind.Präs. **⟪तिष्ठति⟫**
:::
## 33.2. Третий класс настоящего времени (⟪जुहोत्यादि⟫ = "⟪जुहोति⟫ и т.д.")

:::grammar-box
**Образование:**

**сильный корень:**  
**редуплицированная высокоступенчатая основа корня + окончание**

**слабый корень:**  
**редуплицированная низкоступенчатая основа корня + окончание**

**Для согласного редупликации применяются вышеизложенные правила.**
:::
### 33.2.1. Гласный редупликации 3-го класса настоящего времени

:::grammar-box
* **Регулярный гласный редупликации — -i-**
* **Корни, содержащие u, редуплицируются с помощью -u-**
* **корни ⟪दा⟫, ⟪धा⟫, ⟪हा⟫ — с помощью -a-**
:::
Примеры:

::::grammar-box
**⟪हु⟫** 3-е л. ед. ч. "(в жертву) лить в огонь"

* **сильная основа:** ⟪जुहो⟫
* **слабая основа:** ⟪जुहु⟫

| | 3. ед. ч. из. | 3. мн. ч. из. | 3. ед. ч. а. | 3. мн. ч. а. |
| :--- | :--- | :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪जुहोति⟫ | ⟪जुह्वति⟫:brjuhu + ati | &lt;⟪जुहुते⟫&gt; | &lt;⟪जुह्वते⟫&gt;:brjuhu + ate |
| **Аорист** | ⟪अजुहोत्⟫:bra-juho-t | ⟪जुहवुर्⟫:bra-juho + ur | &lt;⟪अजुहुत⟫&gt; | &lt;⟪अजुह्वत⟫&gt;:bra-juhu + ata |
| **Сослагательное наклонение** | ⟪जुहुयात्⟫:brjuhu-yā-t | ⟪जुहुयुर्⟫:brjuhu-y-ur | &lt;⟪जुह्वीत⟫&gt;:brjuhu + ī-ta | &lt;⟪जुह्वीरन्⟫&gt;:brjuhu + ī-ran |
::::
## 33.3. О чередовании ā

ā kann

* с одной стороны, удлиненная ступень одного из рядов чередования с -a-
* andrerseits Hochstufe in einer Ablautreihe der ā-Gruppe sein

Die beiden wichtigsten Ablautreihen der ā-Gruppe sind:

:::grammar-box
**A.**

* **Низкая ступень**
  * **перед согласным: -i-**  
    напр. **⟪धा⟫** прич. пр. страд. залога: **⟪हित⟫** (hi-ta)
  * **перед гласным: Ø**  
    напр. **⟪धा⟫** 3 л. мн.ч. Ind. Пр. вр. **⟪दधति⟫** (dadh-ati)
* **Высокая ступень: -ā-**  
  напр. **⟪धा⟫** 3 л. ед.ч. P. Ind. Пр. вр. **⟪दधाति⟫**
:::
К сюда относится, например:

:::indent
**⟪स्था⟫** 1
* прич. пр. страд. залога **⟪स्थित⟫** (sthi-ta)
* 3 л. ед.ч. Пр. вр. **⟪स्थास्यति⟫** (sthā-sya-ti)
:::::::grammar-box
**B.**

* **Низкая ступень: -ī-**  
  напр. **⟪पा⟫** 1: прич. пр. страд. залога **⟪पीत⟫** (pī-ta)
* **Высокая ступень: -ā-**  
  напр. **⟪पा⟫** 1: инф. **⟪पातुम्⟫**
::::
## 33.4. Корни на -ā третьего класса настоящего времени

:::grammar-box
**Корни на -ā (кроме ⟪दा⟫ и ⟪धा⟫) в слабой форме обычно имеют окончание -ī-** (см. Thumb-Hauschild, том 1, часть 1, стр. 271. Вероятно, на это повлияла указанная выше серия чередований B как образец, хотя эти корни обычно чередуются по серии A), **перед гласными окончаниями гласная корня полностью исчезает (см. серию чередований A).**
:::
Примеры:

::::grammar-box
**⟪मा⟫** 3Ā "мерить"

| | 3. ед. ч. Ā. | 3. мн. ч. Ā. |
| :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪मिमीते⟫:brmimī-te | ⟪मिमते⟫:brmim-ate |
| **Аорист** | ⟪अमिमीत⟫ | ⟪अमिमत⟫ |
| **Сослагательное наклонение** | ⟪मिमीत⟫:brmim-ī-ta ! | ⟪मिमीरन्⟫:brmim-ī-ran |
::::::::grammar-box
**⟪हा⟫** 3P "оставлять"

| | 3. ед. ч. P. | 3. мн. ч. P. |
| :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪जहाति⟫ | ⟪जहति⟫:brjah-ati |
| **Аорист** | ⟪अजहात्⟫ | ⟪अजहुर्⟫ |
| **Сослагательное наклонение** | ⟪जह्यात्⟫:brjah-yā-t:br(Корень **⟪हा⟫** имеет перед сослагательным наклонением -yā/y ту же форму, что и перед гласными!) | ⟪जह्युर्⟫:brjah-y-ur |
::::
### 33.4.1. Корни **⟪दा⟫** и **⟪धा⟫**

:::grammar-box
**Корни ⟪दा⟫ и ⟪धा⟫ редуплицируются с гласным -a- и теряют корневой гласный в слабой основе.**

**Обратите внимание на закон диссимиляции придыхания при ⟪धा⟫!**
:::::::grammar-box
**⟪धा⟫** 3U "ставить, устанавливать, распределять"

| | 3. л. ед. ч. Ind. | 3. л. мн. ч. Ind. | 3. л. ед. ч. Pass. | 3. л. мн. ч. Pass. |
| :--- | :--- | :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪दधाति⟫ | ⟪दधति⟫:brdadh-ati | ⟪धत्ते⟫:brdadh-te:br(Пояснение: Thumb-Hauschild 1,1 стр. 302f.) | ⟪दधते⟫:brdadh-ate |
| **Аорист** | ⟪अदधात्⟫ | ⟪अदधुर्⟫ | ⟪अधत्त⟫:bra + dadh + ta | ⟪अदधत⟫ |
| **Сослагательное наклонение** | ⟪दध्यात्⟫:brdadh-yā-t | ⟪दध्युर्⟫ | ⟪दधीत⟫:brdadh-ī-ta | ⟪दधीरन्⟫ |
::::
Формы **⟪दा⟫** получаются путем замены **dh** на **d** в парадигме **⟪धा⟫**. Таким образом:

::::grammar-box
**⟪दा⟫** 3U "давать"

| | 3. л. ед. ч. Ind. | 3. л. мн. ч. Ind. | 3. л. ед. ч. Pass. | 3. л. мн. ч. Pass. |
| :--- | :--- | :--- | :--- | :--- |
| **Изъявительное наклонение, настоящее время** | ⟪ददाति⟫ | ⟪ददति⟫ | ⟪दत्ते⟫ | ⟪ददते⟫ |
| **Аорист** | ⟪अददात्⟫ | ⟪अददुर्⟫ | ⟪अदत्त⟫ | ⟪अददत⟫ |
| **Сослагательное наклонение** | ⟪दद्यात्⟫ | ⟪दद्युर्⟫ | ⟪ददीत⟫ | ⟪ददीरन्⟫ |
::::
## 33.5. Причастие настоящего времени Parasmaipada корней 3-го класса настоящего времени

:::grammar-box
**Глаголы 3-го класса образуют все формы причастия настоящего времени Parasmaipada от слабой основы.**

**Исключение: именительный/винительный падеж, множественное число, средний род может образовываться как от сильной, так и от слабой основы.**
:::

::::grammar-box

## 33.7. Упражнение

A) Вставьте в следующую схему предложения соответствующие формы слов в скобках:

⟪रामस्⟫ ... (⟪चतुर्थ्येकवचने⟫ ⟪बहुवचने⟫ ⟪च⟫) ... ⟪अन्नं⟫ ⟪ददाति⟫ ⟪।⟫ (⟪भिक्षु⟫ ⟪।⟫ ⟪अग्नि⟫ ⟪।⟫ ⟪शूद्रा⟫ ⟪।⟫ ⟪गुनवान्पुत्र⟫ ⟪।⟫ ⟪देवान्स्तुवन्कवि⟫ ⟪।⟫ ⟪ब्राह्मणी⟫ ⟪।⟫ ⟪महान्साधु⟫ ⟪।⟫ ⟪धेनु⟫)

B) Вставьте соответствующие формы указанных в скобках глаголов в изъявительном наклонении (настоящее время, имперфект и опатив):

⟪ब्राह्मणो⟫ ⟪घृतमग्नौ⟫ ... (⟪हु⟫) ⟪॥१॥⟫

⟪बुद्धगता⟫ ⟪भयान्न⟫ ... (⟪भी⟫) ⟪॥२॥⟫

⟪सुगतः⟫ ⟪कुलम्⟫ ... (⟪हा⟫) ⟪॥३॥⟫

⟪दुर्जना⟫ ⟪भिक्षुभ्यो⟫ ⟪ऽन्नं⟫ ⟪न⟫ ... (⟪दा⟫) ⟪॥४॥⟫

⟪साधुः⟫ ⟪कृष्णे⟫ ⟪मतिम्⟫ ... (⟪धा⟫ + ⟪सम्⟫ + ⟪आ⟫) ⟪॥५॥⟫

⟪ईश्वरो⟫ ⟪लोकान्⟫ ... ⟪जनास्तु⟫ ⟪न⟫ ... (⟪मा⟫) ⟪॥६॥⟫

⟪दासा⟫ ⟪भारान्⟫ ... (⟪भृ⟫) ⟪॥७॥⟫

⟪ब्राह्मणी⟫ ⟪पात्रं⟫ ⟪जलेन⟫ ... (⟪पॄ⟫) ⟪॥८॥⟫

C) Переведите и преобразуйте синглярные предложения в пуральные и наоборот:

⟪योगयुक्तो⟫ ⟪मतिं⟫ ⟪दुःखमक्षनयन्त्यां⟫ ⟪प्रज्ञायां⟫ ⟪समाधत्ते⟫ ⟪॥१॥⟫

⟪यो⟫ ⟪भिक्षवे⟫ ⟪दानानि⟫ ⟪दद्यात्सो⟫ ⟪ऽपि⟫ ⟪दानपुण्यमाददीत⟫ ⟪॥२॥⟫

⟪ब्राह्मणा⟫ ⟪भारं⟫ ⟪न⟫ ⟪बिभ्रतीति⟫ ⟪ब्राह्मणदासो⟫ ⟪भारं⟫ ⟪गृहमबिभः⟫ ⟪॥३॥⟫
