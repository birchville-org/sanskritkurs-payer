# Урок 26

## 26.1. Закон церебрализации -s- внутри слова

::: grammar-box
**-s-** заменяется на **-ṣ-**, если ему непосредственно или только через ⟪अनुस्वार⟫ или ⟪विसर्ग⟫ предшествует **k, r, l** или **гласный**, кроме **a, ā**, и за ним следует другой звук, чем **ṛ, r**.

Этот сандхи также следует за **⟪दुस्⟫-** перед глухими калальными и губными согласными в составе сложных слов.
:::
*Примеры:*
::: indent
⟪तेषाम्⟫ (из: *te-sām*)

но: ⟪तासाम्⟫ (*tā-sām*)
:::
## 26.2. Закон церебрализации зубных согласных внутри слова

::: grammar-box
Зубные смычные согласные после ретрофлексных (включая **-ṣ-**) заменяются на соответствующие ретрофлексные:

- **iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
- **ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** из-за предшествующего **i**, **ṭh** из-за последующего затем **ṣ**)*
:::

## 26.4. Закон диссимиляции придыхания Гримма

::: grammar-box
**Непосредственная последовательность двух придыхательных (придыхательная - гласный - придыхательная) приводит к потере придыхания первого звука:**

Пример:

:::
::: indent
\*dhu(gh) » du(g)h
:::
**Если в результате фонетических законов второй звук теряет придыхание, то придыхание возвращается к первому звуку.**

## 26.6. Употребление простого будущего (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ж.р.)

::: grammar-box
**Простое будущее (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ж.р.) выражает:**

- **будущее время**
- **намеренное или желаемое действие («я пойду», «я хочу пойти»)**
- **ожидание («так и произойдет»)**
- **надежду**
- **опасение**
- **вероятность**
- **мнение говорящего**
- **приказ**

**Формы будущего времени частично конкурируют с формой сослагательного наклонения (см. далее).**
:::
например, ⟪व्रतं करिष्यन्देवगृहं गच्छति⟫ = «Тот, кто желает дать обет, идет в храм.»

## 26.7. Образование простого будущего (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ ж.р.)

::: grammar-box
**Простое будущее:**

:::
::: indent
**Основа будущего + первичное окончание**
:::
::: grammar-box
**Основа будущего:**

:::
::: indent
**(как правило) сильная степень корня + -sya**  
**или**  
**(как правило) сильная степень корня + -i- + -sya (= - iṣya)**
:::
**Какой корень образует какую форму основы будущего, необходимо заучивать вместе с формами основ!**  
**В целом форма корня и соединительный гласный будущего совпадают с инфинитивом.**  
**Некоторые корни могут образовывать будущее время факультативно как с соединительным гласным -i-, так и без него.**  
**Причастие среднего залога будущего времени образуется путем присоединения суффикса -nt- к основе будущего, женский род факультативно на -ntī или -tī:**

::: indent
⟪कृ⟫ :  ⟪करिष्यन्त्⟫, ⟪करिष्यन्ती⟫ / ⟪करिष्यती⟫
:::
Примеры:

::: grammar-box

| Корень | Будущее время, 3 л. ед. ч. P (Ā) |
| :--- | :--- |
| ⟪नी⟫ | ⟪नेष्यति⟫ |
| ⟪भू⟫ | ⟪भविष्यति⟫ (⟪भो⟫ +  ⟪इ⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दिश्⟫ | ⟪देक्ष्यति⟫ (⟪देश्⟫ + ⟪स्य⟫ + ⟪ति⟫) |
| ⟪दृश्⟫ | ⟪द्रक्ष्यति⟫ |
| ⟪पच्⟫ | ⟪पक्ष्यति⟫ |
| ⟪प्रच्छ्⟫ | ⟪प्रक्ष्यति⟫ |
| ⟪यज्⟫ | ⟪यक्ष्यति⟫ |
| ⟪सृज्⟫ | ⟪स्रक्ष्यति⟫ |
| ⟪पद्⟫ | ⟪पत्स्यति⟫ |
| ⟪अद्⟫ | ⟪अत्स्यति⟫ |
| ⟪दुह्⟫ | ⟪धोक्ष्यति⟫ (⟪दोग्⟫ +  ⟪स्य⟫ + ⟪ति⟫) |
| ⟪बुध्⟫ | ⟪भोत्स्यते⟫ (⟪बोध्⟫ перед глухим = ⟪भोत्⟫) |
| ⟪मन्⟫ | ⟪मंस्यते⟫ (⟪मन्⟫ + ⟪स्य⟫ + ⟪ते⟫) |

:::
