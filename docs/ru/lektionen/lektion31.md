# Урок 31

## 31.1. 7-й класс настоящего времени (रुधादि = "रुध् и т.д.")

:::: grammar-box
**Образование:**

**Перед конечными согласными корня глубокого ступени вставляется т.н. на infix (-na- или -n-):**

*   **в сильной основе: -na-**
*   **в слабой основе: -n-**

**Для соединения конечных согласных корня с оканчивающимися на согласные окончаниями действуют те же правила, что и для 2-го класса настоящего времени.**
::::

Примеры:

युज् 7U "соединять, запрягать"

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. sg.** | युनक्ति[[br]](yu-na-j + -ti) | युङ्क्ते[[br]](yu + n + j + te)[[br]](перед заднеязычными внутри слова назальные заменяются на -ṅ-) |
| | **3. pl.** | युञ्जन्ति[[br]](yu + n + j-anti) | युञ्जते[[br]](yu + n + j-ate) |
| **Optativ** | **3. sg.** | युञ्ज्यात्[[br]](yu + n + j-yā-t) | युञ्जीत[[br]](yu + n + j-ī-ta) |
| | **3. pl.** | युञ्ज्युर्[[br]](yu + n + j-y-ur) | युञ्जीरन्[[br]](yu + n + j-ī-ran) |
| **Partizip Präsens** | | युञ्जन्त्-[[br]](yu + n + j-ant-)[[br]]fem.: युञ्जती[[br]](yu + n + j-at-ī) | |

::::

रुध् 7U "останавливать, приводить в состояние покоя"

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indikativ** | **3. sg.** | रुणद्धि[[br]](ru + na + dh + ti) | रुन्द्धे[[br]](ru-n + dh + te) |
| | **3. pl.** | रुन्धन्ति[[br]](ru-n-dh-anti) | रुन्धते[[br]](ru-n-dh-ate) |
| **Optativ** | **3. sg.** | रुन्ध्यात्[[br]](ru-n-dh-yā-t) | रुन्धीt[[br]](ru-n-dh-ī-ta) | → | रुन्धीत[[br]](ru-n-dh-ī-ta) |
| | **3. pl.** | रुन्ध्युर्[[br]](ru-n-dh-y-ur) | रुन्धीरन्[[br]](ru-n-dh-ī-ran) |
| **Partizip Präsens** | | रुन्धन्त्-[[br]](ru-n-dh-ant-)[[br]]fem.: रुन्धती[[br]](ru-n-dh-at-ī) | |

::::

:::: grammar-box
**У некоторых корней -n- слабого корня настоящего времени проник и в непременные времена, поэтому такие корни рассматриваются с вставным на infix.**
::::

Пример:

**भञ्ज्** 7P "ломать"

::: indent
*   Indikativ Präsens
    *   3.sg.P. **भनक्ति** (bha-na + j + ti)
    *   3.pl.P. **भञ्जन्ति** (bha + n + j-anti)
*   Futur: **भङ्क्ष्यति** (bha + n + j + sya + ti)
*   Passiv: **भज्यते** (либо из первоначального корня **भज्**, либо из *bhñj-ya-te)
*   PPP: **भग्न** (возможно, из *bhñj + na)
:::

## 31.2. Список слов

**युज्** 7U **युनक्ति** : запрягать, припрягать, напрягать, прикреплять; Ā также: напрягаться (= прилагать усилия), соединяться с, концентрироваться на (Локатив, सप्तमी)
::: indent
**Фут. योक्ष्यति**
**Pass. युज्यते**
**Kaus. योजयति**
**PPP युक्त**
**Inf. योक्तुम्**

от этого:
**युग n. → युग n.:** ярмо, пара, эпоха мира (существует четыре эпохи мира:
1. **कृत**
2. **त्रेता**
3. **द्वापर**
4. **कलि**

**कलियुग** началась около 3102 г. до н.э., в год **महाभारत**-войны. Подробнее у Башам, Wonder, стр. 323)

**योग m.:** "запряжка, напряжение", усилие, соединение, йога (см. Башам, Wonder, стр. 327ff.)
:::
