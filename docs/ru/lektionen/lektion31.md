# Lektion 31

## 31.1. Die 7. Настоящее времяklasse (रुधादि = "रुध् u.s.w.")

:::: grammar-box
**Образование:**

**Перед конечными согласными корня в низком (глубоком) уровне тона вставляется так называемое насадное н (назальный инфикс) (-na- или -n-):**

*   **в сильной основе: -na-**
*   **в слабой основе: -n-**

**Для соединения конечных согласных корня с окончаниями, начинающимися на согласный, действуют те же правила, что и для 2-го класса настоящего времени.**
::::

Примеры:

युज् 7U «соединять, запрягать»

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicativus** | **3. sg.** | युनक्ति[[br]](yu-na-j + -ti) | युङ्क्ते[[br]](yu + n + j + te)[[br]](vor Guttural im Wortinnern werden Nasale durch -ṅ- ersetzt) |
| | **3. pl.** | युञ्जन्ति[[br]](yu + n + j-anti) | युञ्जते[[br]](yu + n + j-ate) |
| **Optativus** | **3. sg.** | युञ्ज्यात्[[br]](yu + n + j-yā-t) | युञ्जीत[[br]](yu + n + j-ī-ta) |
| | **3. pl.** | युञ्ज्युर्[[br]](yu + n + j-y-ur) | युञ्जीरन्[[br]](yu + n + j-ī-ran) |
| **Partizip Настоящее время** | | युञ्जन्त्-[[br]](yu + n + j-ant-)[[br]]fem.: युञ्जती[[br]](yu + n + j-at-ī) | |

::::

रुध् 7U «останавливать, приводить в состояние покоя»

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicativus** | **3. sg.** | रुणद्धि[[br]](ru + na + dh + ti) | रुन्द्धे[[br]](ru-n + dh + te) |
| | **3. pl.** | रुन्धन्ति[[br]](ru-n-dh-anti) | रुन्धते[[br]](ru-n-dh-ate) |
| **Optativus** | **3. sg.** | रुन्ध्यात्[[br]](ru-n-dh-yā-t) | रुन्धीt[[br]](ru-n-dh-ī-ta) | -&gt; | रुन्धीत[[br]](ru-n-dh-ī-ta) |
| | **3. pl.** | रुन्ध्युर्[[br]](ru-n-dh-y-ur) | रुन्धीरन्[[br]](ru-n-dh-ī-ran) |
| **Partizip Настоящее время** | | रुन्धन्त्-[[br]](ru-n-dh-ant-)[[br]]fem.: रुन्धती[[br]](ru-n-dh-at-ī) | |

::::

:::: grammar-box
**У некоторых корней -n- слабой основы настоящего времени проникло и в непременные времена, вследствие чего эти корни рассматриваются с назальным инфиксом.**
::::

Пример:

**भञ्ज्** 7P «ломать»

::: indent
*   Indicativus Praesentis
    *   3.sg.P. **भनक्ति** (bha-na + j + ti)
    *   3.pl.P. **भञ्जन्ति** (bha + n + j-anti)
*   Futurum: **भङ्क्ष्यति** (bha + n + j + sya + ti)
*   Passivum: **भज्यते** (либо от исходного корня **भज्**, либо от *bhñj-ya-te)
*   PPP: **भग्न** (возможно, от *bhñj + na)
:::

## 31.2. Словарь

**युज्** 7U **युनक्ति** : запрягать, припрягать, напрягать, прикреплять; Ā также: напрягаться (= прилагать усилия), соединяться с, концентрироваться на (локатив, саптами)
::: indent
**Фут. योक्ष्यति**
**Пасс. युज्यते**
**Каус. योजयति**
**PPP युक्त**
**Инф. योक्तुम्**

от него:
**युग n. -&gt; युग n.:** ярмо, пара, мировая эпоха (существует четыре мировые эпохи:
1. **कृत**
2. **त्रेता**
3. **द्वापर**
4. **कलि**

**कलियुг** начался около 3102 г. до н. э., в год войны **महाभारत**. Подробнее у Башама, Wonder, стр. 323)

**योग m.:** «запряжение, напряжение», усилие, соединение, йога (см. Башам, Wonder, стр. 327 и сл.)
