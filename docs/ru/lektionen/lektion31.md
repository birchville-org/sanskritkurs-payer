# Урок 31

## 31.1. 7-й класс настоящего времени (⟪रुधादि⟫ = "⟪रुध्⟫ и т.д.")

::: grammar-box
**Образование:**

**Перед конечными согласными корня глубокого ступени вставляется т.н. назальный инфикс (-na- или -n-):**

*   **в сильной основе: -na-**
*   **в слабой основе: -n-**

**Для соединения конечных согласных корня с окончаниями, начинающимися на согласную, действуют те же правила, что и для 2-го класса настоящего времени.**
:::
Примеры:

⟪युज्⟫ 7U "связывать, запрягать"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Изъявительное наклонение** | **3. л., ед. ч.** | ⟪युनक्ति⟫:bryu-na-j + -ti | ⟪युङ्क्ते⟫:bryu + n + j + te:br(перед губными внутри слова назальные заменяются на -ṅ-) |
| | **3. л., мн. ч.** | ⟪युञ्जन्ति⟫:bryu + n + j-anti | ⟪युञ्जते⟫:bryu + n + j-ate |
| **Сослагательное наклонение** | **3. л., ед. ч.** | ⟪युञ्ज्यात्⟫:bryu + n + j-yā-t | ⟪युञ्जीत⟫:bryu + n + j-ī-ta |
| | **3. л., мн. ч.** | ⟪युञ्ज्युर्⟫:bryu + n + j-y-ur | ⟪युञ्जीरन्⟫:bryu + n + j-ī-ran |
| **Причастие настоящего времени** | | ⟪युञ्जन्त्⟫-:bryu + n + j-ant-:brж.р.: ⟪युञ्जती⟫:bryu + n + j-at-ī | |

:::
⟪रुध्⟫ 7U "останавливать, приводить в покой"

::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Изъявительное наклонение** | **3. л., ед. ч.** | ⟪रुणद्धि⟫:brru + na + dh + ti | ⟪रुन्द्धे⟫:brru-n + dh + te |
| | **3. л., мн. ч.** | ⟪रुन्धन्ति⟫:brru-n-dh-anti | ⟪रुन्धते⟫:brru-n-dh-ate |
| **Сослагательное наклонение** | **3. л., ед. ч.** | ⟪रुन्ध्यात्⟫:brru-n-dh-yā-t | ⟪रुन्धीत⟫:brru-n-dh-ī-ta |
| | **3. л., мн. ч.** | ⟪रुन्ध्युर्⟫:brru-n-dh-y-ur | ⟪रुन्धीरन्⟫:brru-n-dh-ī-ran |
| **Причастие настоящего времени** | | ⟪रुन्धन्त्⟫-:brru-n-dh-ant-:brfem.: ⟪रुन्धती⟫:brru-n-dh-at-ī | |

:::
::: grammar-box
**У некоторых корней -n- слабого настоящего корня проник и в непременные времена, так что эти корни следует рассматривать с инфиксальным носовым.**
:::
Пример:

⟪भञ्ज्⟫ 7P "ломать"

::: indent
*   Индикатив настоящего времени
*   3.ед.ч. ⟪भनक्ति⟫ (bha-na + j + ti)
*   3.мн.ч. ⟪भञ्जन्ति⟫ (bha + n + j-anti)
*   Будущее время: ⟪भङ्क्ष्यति⟫ (bha + n + j + sya + ti)
*   Пассив: ⟪भज्यते⟫ (либо из первоначального корня ⟪भज्⟫, либо от *bhñj-ya-te)
*   PPP: ⟪भग्न⟫ (возможно, от *bhñj + na)
:::
## 31.2. Словарь

1. ⟪कृत⟫
2. ⟪त्रेता⟫
3. ⟪द्वापर⟫
4. ⟪कलि⟫

Эпоха ⟪कलियुग⟫ началась около 3102 г. до н.э., в год войны ⟪महाभारत⟫. Подробнее у Башама, Wonder стр. 323)

**⟪योग⟫ m.:** "запрягание, напряжение", усилие, соединение, йога (см. Башам, Wonder стр. 327 и далее)
