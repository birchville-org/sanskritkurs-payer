## 10.1. Der Passivsatz

::: grammar-box
**Схема:**
**(Агент — kartṛ — в творительном падеже (tṛtīyā)) — (прямой объект — karman — в именительном падеже) — пассивная форма глагола**

напр. **brāhmaṇena deva ijyate** = ब्राह्मणेन देव इज्यते = «Брахман приносит жертву богу» (дословно: «Бог почитается брахманом посредством жертвоприношения»).

Этот предложение **полностью (!) тождественно по значению** следующему:
**brāhmaṇo devaṃ yajati / yajate** = ब्राह्मणो देवं यजति / यजते
:::

::: grammar-box
- В пассивном предложении агент (**kartṛ**) стоит в **творительном падеже** (tṛtīyā ж. «третий падеж»), а прямой объект (**karman** м.) — в **именительном падеже** (prathamā ж.).
- Пассивные предложения, в которых агент не указан, обычно имеют безличное значение («можно», «следует»):
  напр. **ijyate** = इज्यते «Совершается жертвоприношение» (дословно: «почитается посредством жертвоприношения»).
:::

::: grammar-box
**Даже если соответствующее активное предложение содержало бы винительный падеж (dvitīyā) цели, в пассивном предложении он может переходить в именительный падеж (prathamā):**

Активному предложению **rāmo grāmaṃ gacchati** = रामो ग्रामं गच्छति = «Рама идёт в деревню» соответствуют пассивные предложения:
- **rāmeṇa grāmaṃ gamyate** = रामेण ग्रामं गम्यते
- альтернативно: **rāmeṇa grāmo gamyate** = रामेण ग्रामो गम्यते
:::

::: grammar-box
**Непереходные глаголы (глаголы без прямого объекта) часто образуют пассивные конструкции, особенно в вежливых повелительных формах:**
- **praviśyatām** = प्रविश्यताम् = «Пусть войдёт = Прошу войти = Проходите!»
- **niṣadyatām** = निषद्यताम् = «Пусть сядет = Прошу сесть = Прошу занять место»
:::

Санскритские пассивные конструкции встречаются крайне часто: пассив действительно легче образуется, чем, например, множество настоящих основ глаголов.

::: important
**Санскритские пассивные предложения в целом не следует переводить на немецкий язык с помощью пассивной конструкции, поскольку немецкий пассив выполняет совершенно иную стилистическую функцию.**
:::

## 10.3. Das sogenannte Cerebralisationsgesetz für -n- (ein Wortsandhi)

::: grammar-box
**-n-**, за которым следует гласная или **n, m, y, v**, заменяется на **-ṇ-**, если в слове перед **-n-** стоят **ṛ, ṝ, r, ṣ** или если между этими звуками и следующим **-n-** в слове нет других звуков, кроме гласных, гуттуральных, лабиальных, **y, v, h** или анусвары.
:::

**Следовательно:**

::: grammar-box
| | Творительный падеж Единственное число[[br]]तृतीया एकवचन |
| :--- | :--- |
| **guru**[[br]]गुरु | **guruṇā**[[br]]गुरुणा |
| **śūdra**[[br]]शूद्र | **śūdreṇa**[[br]]शूद्रेण |
| **īśvara**[[br]]ईश्वर | **īśvereṇa**[[br]]ईश्वरेण |
| **kṣatriya**[[br]]क्षत्रिय | **kṣatriyeṇa**[[br]]क्षत्रियेण |
| **naraka**[[br]]नरक | **narakeṇa**[[br]]नरकेण |
:::

**Таким же образом объясняется наличие -ṇ- в:**

> **śravaṇa** श्रवण
&gt;
> **śṛṇoti** शृणोति
&gt;
> **kāraṇa** कारण
&gt;
> **brāhmaṇa** ब्राह्मण

## 10.4. Das Passiv, Indikativ Настоящее время (yak = यक्)

::: grammar-box
**Образование:**
**(как правило) глубокая ступень корня + -ya- + окончание Атманапада**

**Примеры:**

| Корень[[br]]धातु | 3. sg. Pass. Präs. Indik.[[br]]यक् लट् | 3. pl. Pass. Präs. Indik.[[br]]यक् लट् |
| :--- | :--- | :--- |
| **nī**[[br]]1 кл.[[br]](nayati) | **nīyate**[[br]](नीयते)[[br]]"er wird geführt" | **nīyante**[[br]](नीयन्ते) |
| **man**[[br]]4 кл. Ат.[[br]](manyate) | **manyate**[[br]](मन्यते)[[br]]"er wird gedacht" | **manyante**[[br]](मन्यन्ते) |
| **viś**[[br]]6 кл. Пар.[[br]](viśati) | **viśyate**[[br]](विश्यते)[[br]]"es wird betreten" | **viśyante**[[br]](विश्यन्ते) |

::: note-box
У глаголов 4-го класса настоящего времени формы Атманапада и страдательного залога тождественны! Это можно установить только исходя из синтаксической конструкции предложения.

## 10.5. Словарь

  ::: note-box
  О городской и сельской жизни см. Башам, *Wonder*, гл. 6.

- **yajña** m. यज्ञ : жертвоприношение

  ::: note-box
  В Индии жертвоприношение — это прежде всего почитание божества как гостя. Тем самым человек берет на себя обязательства перед божеством.
