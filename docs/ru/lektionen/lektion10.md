## 10.1. Пассивный синтаксис

::: grammar-box
**Схема:**
**(Агент - kartṛ - в инструментале (tṛtīyā)) - (прямой объект - karman - в именительном падеже) - пассивная форма глагола**

Например, **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "Брахман почитает бога жертвоприношением" (дословно: "Бог почитается брахманом с помощью жертвоприношения").

Это предложение **полностью (!) тождественно по значению** предложению:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫
:::

::: grammar-box
- В пассивном синтаксисе агент (**kartṛ**) стоит в **инструментале** (tṛtīyā ж. "третий падеж"), а прямой объект (**karman** м.) — в **именительном падеже** (prathamā ж.).
- Пассивные предложения, в которых агент не указан, обычно имеют безличное значение ("можно", "делают"):
Например, **ijyate** = ⟪इज्यते⟫ "Жертвоприношение совершается" (дословно: "его почитают с помощью жертвоприношения").
:::

::: grammar-box
**Даже если соответствующее активное предложение содержало бы винительный падеж (dvitīyā) цели, в пассивном синтаксисе он может быть переведен в именительный падеж (prathamā):**

Активному предложению **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "Рама идет в деревню" соответствуют пассивные предложения:
- **rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
- альтернативно: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫
:::

::: grammar-box
**Непереходные глаголы (глаголы без прямого дополнения) часто образуют пассивные конструкции, особенно в вежливых повелительных формах:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "Пусть войдут = Пожалуйста, войдите = Прошу!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "Пусть сядут = Пожалуйста, садитесь = Прошу занять место"
:::
Пассивные конструкции санскрита встречаются чрезвычайно часто: пассив, в конце концов, образуется легче, чем, например, множество настоящих основ.

::: important
**Пассивные предложения санскрита в целом не следует переводить на немецкий язык с помощью пассивной конструкции, поскольку немецкий пассив выполняет совершенно иную стилистическую функцию.**
:::

## 10.2. Третий падеж (tṛtīyā f. = ⟪तृतीया⟫ = "окончание третьего падежа")

::: grammar-box
**Регулярные окончания творительного падежа (tṛtīyā):**
**Единственное число: -ā**
**Множественное число: -bhis**

**Регулярные образования:**

| | Творительный падеж, ед. ч. | Творительный падеж, мн. ч. |

### 10.2.1. О употреблении инструменталиса (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box
**Третий падеж (tṛtīyā) в основном отвечает на вопросы:**
**Чем?**
**С помощью чего?**
**С кем?**

**Он употребляется**
1. **в пассивных предложениях: агент (kartṛ) в творительном падеже**
2. **для указания средства или инструмента, с помощью которого совершается действие**
3. **для указания пути, по которому кто-либо куда-то прибывает**
4. **для выражения связи, соединения, сопровождения с**
5. **после постпозиций в значении "вместе с, с"; например, saha = ⟪सह⟫ = "с"** :brнапр.:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "вместе с брахманом"
:::
Дальнейшие употребления творительного падежа (tṛtīyā) будут рассмотрены позже.


## 10.3. Так называемый закон церебрализации для -n- (слоговой сандхи)

::: grammar-box
**-n-**, перед которым следует гласный или **n, m, y, v**, заменяется на **-ṇ-**, если в слове перед **-n-** стоят **ṛ, ṝ, r, ṣ** или если между этими звуками и следующим **-n-** в слове нет других звуков, кроме гласных, килевых (гортанных), губных, **y, v, h** или анусвара.
:::
**Поэтому:**

::: grammar-box
| | Творительный падеж, ед. ч. |
| :--- | :--- |
| **guru** :br⟪गुरु⟫ | **guruṇā** :br⟪गुरुणा⟫ |
| **śūdra** :br⟪शूद्र⟫ | **śūdreṇa** :br⟪शूद्रेण⟫ |
| **īśvara** :br⟪ईश्वर⟫ | **īśvereṇa** :br⟪ईश्वरेण⟫ |
| **kṣatriya** :br⟪क्षत्रिय⟫ | **kṣatriyeṇa** :br⟪क्षत्रियेण⟫ |
| **naraka** :br⟪नरक⟫ | **narakeṇa** :br⟪नरकेण⟫ |
:::
**Таким образом, -ṇ- также объясняется в:**

::: indent
**śravaṇa** ⟪श्रवण⟫

**śṛṇoti** ⟪शृणोति⟫

**kāraṇa** ⟪कारण⟫

**brāhmaṇa** ⟪ब्राह्मण⟫
:::


## 10.4. Страдательный залог, изъявительное наклонение, настоящее время (yak = ⟪यक्⟫)

::: grammar-box
**Образование:**
**(преимущественно) глубокая ступень корня + -ya- + окончание Атманепады**
:::
например

| Корень:br⟪धातु⟫ | 3. л., ед. ч., страж. наст. вр. изъясн.:br⟪यक् लट्⟫ | 3. л., мн. ч., страж. наст. вр. изъясн.:br⟪यक् लट्⟫ |
| :--- | :--- | :--- |
| **nī** :br1 U:br(nayati) | **nīyate** :br(⟪नीयते⟫):br"его ведут" | **nīyante** :br(⟪नीयन्ते⟫) |
| **man** :br4 Ā:br(manyate) | **manyate** :br(⟪मन्यते⟫):br"о нём думают" | **manyante** :br(⟪मन्यन्ते⟫) |
| **viś** :br6 P:br(viśati) | **viśyate** :br(⟪विश्यते⟫):br"в него входят" | **viśyante** :br(⟪विश्यन्ते⟫) |

**Обратите внимание, что у глаголов четвёртого класса настоящего времени формы Атманепады и страдательного залога совпадают! В этом случае определить, имеется ли в виду Атманепада или страдательный залог, можно только из конструкции предложения.**



### 10.4.1. Особые правила образования страдательного залога

1. **Корни на -i или -u** удлиняют свой гласный перед страдательным суффиксом **-ya-**:
* **ji** 1 P: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 P: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 U: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **Корни с -a- между согласными** (кроме носовых, y, r, v) сохраняют высокую ступень:
* **labh** 1 Ā: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **Некоторые корни образуют страдательный залог в высокой ступени** (или в степени чередования основы настоящего времени):
* **āp** 5 P: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 P: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 P: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **Глубокая ступень глаголов, начинающихся на ya, va, ra, либо при наличии этих звуков после другого согласного (Сампрасара́на = ⟪सम्प्रसारण⟫):**

| Корень:br⟪धातु⟫ | Глубокая ступень:br⟪सम्प्रसारण⟫ | Пассив:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
| **prach** 6 P:br⟪प्रच्छ्⟫ | \*prcch &raquo; pṛcch | **pṛcchyate** :br⟪पृच्छ्यते⟫:br **pṛcchyante** :br⟪पृच्छ्यन्ते⟫ |

Традиционное индийское название этой формы глубокой ступени у глаголов с **ya** или **va** — **Сампрасара́на** (⟪नपुंसकम्⟫ = ⟪सम्प्रसारण⟫).

5. **Исходящее -ṛ после единственного согласного перед пассивным суффиксом **-ya-** заменяется на -ri-:**
* **kṛ** 8 U: **kriyate**, **kriyante** :br⟪क्रियते⟫, ⟪क्रियन्ते⟫
* Но: **smṛ** 1 P: **smaryate** :br⟪स्मर्यते⟫

6. **Некоторые корни на -an имеют альтернативно две формы образования пассивного корня:**
* **-an-ya**
* **-ā-ya-** (долгое **ā** является представителем гипотетического долгого носового)

Например, **tan** 8 U.
* **tan-ya-te**, **tan-ya-nte** :br⟪तन्यते⟫, ⟪तन्यन्ते⟫
* **tā-ya-te**, **tā-ya-nte** :br⟪तायते⟫, ⟪तायन्ते⟫ (из \*tn-ya-nte)



## 10.5. Словарь

  ::: note-box
  О городской и сельской жизни см. Башам, *Wonder*, гл. 6.
  :::

**yajña** m. ⟪यज्ञ⟫ : Жертвоприношение

  ::: note-box
  В Индии жертвоприношение является прежде всего почтением божества как гостя. Тем самым человек обязывает это божество.

  Словообразование: **yaj** 1 U + kṛt-суффикс **-na-**.
  :::

**puṇya** n. ⟪पुण्य⟫ : благое дело, заслуга

  ::: note-box
  Тем, чем человек заслуживает благополучие и хорошие перерождения.
