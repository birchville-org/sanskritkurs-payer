## 10.1. Страдательный залог (Passiv)

::: grammar-box
**Схема:**
**(Агент - kartṛ - в инструменталисе (tṛtīyā)) - (прямой объект - karman - в номинативе) - страдательная форма глагола**

напр. **brāhmaṇena deva ijyate** = ब्राह्मणेन देव इज्यते = «Брахман почитает бога жертвоприношением» (дословно: «Бог почитается брахманом с помощью жертвоприношения»)

Это предложение **полностью (!) тождественно по значению** предложению:
**brāhmaṇo devaṃ yajati / yajate** = ब्राह्मणो देवं यजति / यजते
:::

::: grammar-box
- В страдательном предложении агент (**kartṛ**) стоит в **инструналисе** (tṛtīyā ж. «третий падеж»), а прямой объект (**karman** м.) — в **номинативе** (prathamā ж.).
- Страдательные предложения, в которых агент не указан, обычно имеют безличное значение («можно», «следует»):
  напр. **ijyate** = इज्यते «Жертвоприношение совершается» (дословно: «с ним совершается почитание через жертвоприношение»).
:::

::: grammar-box
**Даже если соответствующее активное предложение содержало бы винительный падеж (dvitīyā) цели, в страдательном предложении он может быть переведен в номинатив (prathamā):**

Активному предложению **rāmo grāmaṃ gacchati** = रामो ग्रामं गच्छति = «Рама идет в деревню» соответствуют страдательные предложения:
- **rāmeṇa grāmaṃ gamyate** = रामेण ग्रामं गम्यते
- альтернативно: **rāmeṇa grāmo gamyate** = रामेण ग्रामो गम्यते
:::

::: grammar-box
**Непереходные глаголы (глаголы без прямого объекта) часто имеют страдательные конструкции, особенно в вежливых повелениях:**
- **praviśyatām** = प्रविश्यताम् = «Пусть войдут = Пожалуйста, войдите = Проходите!»
- **niṣadyatām** = निषद्यताम् = «Пусть сядут = Пожалуйста, садитесь = Пожалуйста, занимайте место»
:::

Санскритские страдательные конструкции встречаются чрезвычайно часто: ведь страдательный залог образовывать проще, чем, например, множество основ настоящего времени.

::: important
**Санскритские страдательные предложения в целом не должны переводиться на немецкий язык с помощью страдательного залога, поскольку немецкий страдательный залог выполняет совершенно иную стилистическую функцию.**
:::

## 10.2. Инструментальный падеж (tṛtīyā f. = तृतीया = "третий падеж")

### 10.2.1. Об использовании творительного падежа (tṛtīyā = तृतीया)

::: grammar-box
**Творительный падеж (tṛtīyā) отвечает в основном на вопросы:**
- **Чем?**
- **С чем?**
- **С кем?**

**Он используется**
1. **в пассивных предложениях: агент (kartṛ) в творительном падеже**
2. **для указания средства или инструмента, с помощью которого совершается действие**
3. **для указания пути, по которому кто-либо куда-либо попадает**
4. **для выражения связи, объединения, сопровождения с**
5. **после постпозиций в значении «вместе с, с»; например, saha = सह = «с»**[[br]]например[[br]]**brāhmaṇena saha** = ब्राह्मणेन सह = «вместе с брахманом»
:::

Другие употребления творительного падежа (tṛtīyā) будут рассмотрены позже.

## 10.3. Так называемый закон церебрализации для -n- (словосочетание)

::: grammar-box
**-n-**, за которым следует гласный или **n, m, y, v**, заменяется на **-ṇ-**, если в слове перед **-n-** стоят **ṛ, ṝ, r, ṣ** или если между этими звуками и следующим **-n-** в слове нет других звуков, кроме гласных, гуттуральных, лабиальных, **y, v, h** или анусвāры.
:::

**Следовательно:**

::: grammar-box
| | Инструментальный падеж, единственное число |
| :--- | :--- |
| **guru**[[br]]गुरु | **guruṇā**[[br]]गुरुणा |
| **śūdra**[[br]]शूद्र | **śūdreṇa**[[br]]शूद्रेण |
| **īśvara**[[br]]ईश्वर | **īśvereṇa**[[br]]ईश्वरेण |
| **kṣatriya**[[br]]क्षत्रिय | **kṣatriyeṇa**[[br]]क्षत्रियेण |
| **naraka**[[br]]नरक | **narakeṇa**[[br]]नरकेण |
:::

**Таким образом, -ṇ- также объясняется в:**

::: indent
**śravaṇa** श्रवण

**śṛṇoti** शृणोति

**kāraṇa** कारण

**brāhmaṇa** ब्राह्मण
:::

## 10.4. Страдательный залог, изъявительное наклонение, настоящее время (yak = यक्)

::: grammar-box
**Образование:**
**(в основном) глубокая ступень корня + -ya- + окончание Атманапада**
:::

напр.

| Корень[[br]]धातु | 3. ед. ч. страд. наст. изъясн.[[br]]यक् लट् | 3. мн. ч. страд. наст. изъясн.[[br]]यक् लट् |
| :--- | :--- | :--- |
| **nī**[[br]]1 U[[br]](nayati) | **nīyate**[[br]](नीयते)[[br]]"им ведут" | **nīyante**[[br]](नीयन्ते) |
| **man**[[br]]4 Ā[[br]](manyate) | **manyate**[[br]](मन्यते)[[br]]"о нём думают" | **manyante**[[br]](मन्यन्ते) |
| **viś**[[br]]6 P[[br]](viśati) | **viśyate**[[br]](विश्यते)[[br]]"в него входят" | **viśyante**[[br]](विश्यन्ते) |

**Обратите внимание, что у глаголов 4-го класса настоящего времени формы Атманапада и страдательного залога совпадают! В этом случае можно определить, имеется ли в виду Атманапада или страдательный залог, только исходя из конструкции предложения.**

---

### 10.4.1. Особые правила образования пассива

1. **Корни на -i или -u** удлиняют свой гласный перед суффиксом пассива **-ya-**:
   * **ji** 1 П: **jīyate**, **jīyante**[[br]]जीयते, जीयन्ते
   * **śru** 5 П: **śrūyate**, **śrūyante**[[br]]श्रूयते, श्रूयन्ते
   * **su** 5 У: **sūyate**, **sūyante**[[br]]सूयते, सूयन्ते

2. **Корни с -a- между согласными** (кроме носовых, y, r, v) сохраняют высокий уровень:
   * **labh** 1 А: **labhyate**, **labhyante**[[br]]लभ्यते, लभ्यन्ते

3. **Некоторые корни образуют свой пассив на высоком уровне** (или в ступени чередования настоящего корня):
   * **āp** 5 П: **āpyate**, **āpyante**[[br]]आप्यते, आप्यन्ते
   * **khād** 1 П: **khādyate**, **khādyante**[[br]]खाद्यते, खाद्यन्ते
   * **smṛ** 1 П: **smaryate**, **smaryante**[[br]]स्मर्यते, स्मर्यन्ते

4. **Низкая степень глаголов, начинающихся с ya, va, ra, либо у которых эти звуки стоят после другого согласного (Сампрашарана = सम्प्रसारण):**

   | Корень[[br]]धातु | Низкая степень[[br]]सम्प्रसारण | Пассив[[br]]यक् |
   | :--- | :--- | :--- |
   | **yaj** 1 У[[br]]यज् | \*yj &raquo; ij | **ijyate**[[br]]इज्यते[[br]]**ijyante**[[br]]इज्यन्ते |
   | **vad** 1 П[[br]]वद् | \*vd &raquo; ud | **udyate**[[br]]उद्यते[[br]]**udyante**[[br]]उद्यन्ते |
   | **prach** 6 П[[br]]प्रच्छ् | \*prcch &raquo; pṛcch | **pṛcchyate**[[br]]पृच्छ्यते[[br]]**pṛcchyante**[[br]]पृच्छ्यन्ते |

   Традиционное местное название этого образования низкой степени у глаголов с **ya** или **va** — **Сампрашарана** (नपुंसकम् = सम्प्रसारण).

5. **Финальное -ṛ** после единственного согласного перед суффиксом пассива **-ya-** заменяется на **-ri-**:
   * **kṛ** 8 У: **kriyate**, **kriyante**[[br]]क्रियते, क्रियन्ते
   * Но: **smṛ** 1 П: **smaryate**[[br]]स्मर्यते

6. **Некоторые корни на -an** имеют альтернативно два способа образования пассивного корня:
   * один **-an-ya**
   * другой **-ā-ya-** (долгое **ā** является представителем гипотетического долгого носового)

   напр. **tan** 8 У.
   * **tan-ya-te**, **tan-ya-nte**[[br]]तन्यते, तन्यन्ते
   * **tā-ya-te**, **tā-ya-nte**[[br]]तायते, तायन्ते (из \*tn-ya-nte)
