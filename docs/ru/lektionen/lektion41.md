## 41.2. Дальнейшие образования ⟪कृत्⟫ на -a

### 41.2.1. Причастие настоящего времени (⟪लडादेशः⟫) Ā, страдательное причастие настоящего времени (⟪लडादेशः⟫), будущее причастие (⟪ऌडादेशः⟫) Ā

#### 41.2.1.1. Тематические основы настоящего времени, страдательный залог и будущее время

::: grammar-box
**Образование:**

Основа настоящего времени / основа страдательного залога / основа будущего времени + -māna (жен. род mānā)
:::
Примеры:

⟪यज्⟫ 1U, прич. наст. вр. Ā ⟪यजमान⟫ 3 "тот, кто почитается жертвой в собственных интересах = господин жертвы"

⟪मन्⟫ 4Ā, прич. наст. вр. Ā ⟪मन्यमान⟫ 3 "мыслящий"

⟪कृ⟫ 8U, прич. наст. вр. страд. залога ⟪क्रियमाण⟫ 3 "то, что делается"

⟪दा⟫ 3U, прич. буд. вр. Ā ⟪दास्यमान⟫ 3 "тот, кто даст в собственных интересах"

#### 41.2.1.2. Аттематические классы настоящего времени

::: grammar-box
**Образование:**

Слабая основа настоящего времени (в той форме, которую она имеет перед окончанием -ate 3 л. мн.ч. Ā) + -āna (жен. род -ānā)
:::
Примеры:

::: grammar-box
| Корень / Класс | Причастие настоящего времени Ā |
| :--- | :--- |
| ⟪द्विष्⟫ 2U | ⟪द्विषाण⟫ |
| ⟪हु⟫ 3P | \<⟪जुह्वान⟫\>:brju-hu + āna |
| ⟪सु⟫ 5U | ⟪सुन्वान⟫:brsu-nu + āna |
| ⟪रुध्⟫ 7U | ⟪रुन्धान⟫:br̥d-dh-āna |
| ⟪तन्⟫ 8U | ⟪तन्वान⟫:brt-an-u + āna |
| ⟪क्री⟫ 9U | ⟪क्रीणान⟫:bhr̥-kṛ + n-āna |
:::
### 41.2.2. «Причастие» пассивной необходимости (Gerundivum) (⟪कृत्य⟫)

::: grammar-box
**Для выражения пассивной необходимости («то, что должно быть сделано/следует сделать») можно образовать прилагательные от корней и производных глагольных основ, используя следующие суффиксы:**

* **-⟪तव्य⟫** (жен. род **-⟪तव्या⟫**)
* **-⟪अनीय⟫** (жен. род **-⟪अनीया⟫**)
* **-⟪य⟫** (жен. род **-⟪या⟫**)
* **-⟪त्य⟫** (жен. род **-⟪त्या⟫**) (вместо **-⟪य⟫**/**-⟪या⟫**)
:::
#### 41.2.2.1. Суффикс -⟪तव्य⟫ / -⟪तव्या⟫

::: grammar-box
**Суффикс -⟪तव्य⟫ / -⟪तव्या⟫ присоединяется к корням и производным глагольным основам (например, каузативу) тем же способом, что и суффикс инфинитива -⟪तुम्⟫ (см. [Урок 23](lektion23.md)), т.е.**

* **усиленная степень корня + ⟪तव्य⟫**

или

* **усиленная степень корня + -i- + ⟪तव्य⟫**

**В каузативе:**

* **каузативная основа на -ay + -i- + ⟪तव्य⟫**
:::
Примеры:

::: no-header

| | | |
| :--- | :--- | :--- |
⟪जि⟫ 1P | ⟪जेतव्य⟫ 3 | «тот, кого следует победить; тот, которого нужно победить» |
⟪वृत्⟫ 1Ā | ⟪वर्तितव्य⟫ 3 | «то место, где следует находиться» |
⟪बुध्⟫ Каз. | ⟪बोधयितव्य⟫ | «тот, кого следует разбудить; тот, которого нужно разбудить» |

:::
#### 41.2.2.2. Суффикс -⟪अनीय⟫ / -⟪अनीया⟫

::: grammar-box
**Образование:**

Усиленная степень корня + -⟪अनीय⟫ / -⟪अनीया⟫

**Каузатив и 10. класс настоящего времени:**

Корень в той форме, в которой он появляется в каузативной основе, без -aya- + -⟪अनीय⟫ / -⟪अनीया⟫
:::
Примеры:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪दा⟫ 3U | ⟪दानीय⟫ 3 | "то, что должно быть дано; то, что подлежит дарению" |
| ⟪जि⟫ 1P | ⟪जयनीय⟫ 3 | "то, что должно быть побеждено" |
| ⟪कृ⟫ 8U | ⟪करणीय⟫ 3 | "то, что должно быть сделано" |
| ⟪दृश्⟫ | ⟪दर्शनीय⟫ 3 | "то, что должно быть увиденно; достойное созерцания" |
| ⟪बुध्⟩ Kaus. | ⟪बोधनीय⟫ 3:brbodh-aya - aya + -anīya | "то, что должно быть пробуждено" |
| ⟪दा⟫ Kaus. | ⟪दापनीय⟫ 3:brdā-paya - aya + -anīya | "то, что должно быть отдано" |

:::
#### 41.2.2.3. Суффикс -⟪य⟫ / -⟪या⟫

::: grammar-box
**Образование:**

Корень (в глубокой, высокой или усиленной степени) + -⟪य⟫

Точные правила см. у Киельгорна, «Грамматика санскритского языка», стр. 195 - 197!
:::
Обработка конечных гласных:

::: grammar-box
**1. Корни на -ā образуют это герундив на -eya**
:::
Примеры:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪ज्ञा⟫ 9U | ⟪ज्ञेय⟫ 3 | "то, что должно быть познано; то, что подлежит осознанию" |
| ⟪दा⟫ 3U | ⟪देय⟫ 3 | "то, что должно быть отдано" |

:::
::: grammar-box
**2. Корни на -i /-ī / -u / -ū /-ṛ обычно имеют высокую или усиленную степень, за исключением тех корней на -i / -u /-ṛ, которые образуют герундив с суффиксом -⟪त्य⟫ (жен. род -⟪त्या⟫) (список таких корней у Киельгорна, Грамматика §537).**
:::
Пример:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪स्मृ⟫ 1P |  ⟪स्मर्य⟫ 3 | "о чём следует помнить" |

:::
::: grammar-box
**2a. Корни на -i/-ī имеют высокую степень**
:::
Примеры:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪विक्री⟫ 9Ā | ⟪विक्रेय⟫ 3 | "то, что должно быть продано; продаваемый" |
| ⟪नी⟫ 1U | ⟪नेय⟫ 3 | "то, что должно быть ведено" |

:::

**2b. Корни на -u /-ū заменяют высокоступенное -o перед -ya на -av, а удлиненноступенное -au на -āv. Образование с удлиненной ступенью означает в данном случае необходимость.**

#### 41.2.2.4. Суффикс -⟪त्य⟫ / ⟪⟪त्या⟫ (вместо -⟪य⟫ / -⟪या⟫)

::: grammar-box
Список корней на -i / -u /-ṛ, которые образуют герундив не с помощью суффикса -⟪य⟫ / -⟪या⟫, а с помощью суффикса -⟪त्य⟫ (жен. род -⟪त्या⟫), см. Кильхорн, Грамматика §537.

**Образование:**

корень в слабой степени + -⟪त्य⟫ / -⟪त्या⟫
:::
Примеры:

::: no-header

| | | |
| :--- | :--- | :--- |
| ⟪इ⟫ 2P | ⟪इत्य⟫ 3 | "который следует видеть" |
| ⟪श्रु⟫ 5P | ⟪श्रुत्य⟫ 3 | "который следует слышать" |
| ⟪कृ⟫ 8U | ⟪कृत्य⟫ 3 | "который следует делать" |

:::
### 41.2.3. Синтаксис "причастия" пассивной необходимости (герундива) (⟪कृत्य⟫)

::: grammar-box
Герундив может использоваться в качестве определения:

:::
::: indent
**⟪दर्शनीयं नगरम्⟫** = "город, который необходимо увидеть; достопримечательный город"
:::
Герундив также может использоваться как именная часть сказуемого в предложениях с пассивной конструкцией, выражающих обязательство или приказ (с помощью ⟪न⟫ — запрет, невозможность):

::: indent
**⟪काशी द्विजैर्द्रष्टव्या⟫** = "Дваждырожденные должны увидеть Варанаси"
:::

### 41.2.4. Различия в употреблении суффиксов герундива

::: grammar-box
Употребление этих суффиксов во многом пересекается

* **-⟪तव्य⟫ (жен. род -⟪तव्या⟫):** всегда выражает необходимость и предпочтительно используется в предикативной функции (реже — в атрибутивной). Образования с этим суффиксом не должны использоваться в номинальных композитах.
* **-⟪अनीय⟫ (жен. род -⟪अनीया⟫) и -⟪य⟫ (жен. род -⟪या⟫) / -⟪त्य⟫ (жен. род -⟪त्या⟫) (вместо -⟪य⟫/-⟪या⟫):** могут иметь дополнительное значение (особенно -⟪य⟫) в смысле немецкого "-wert" (например, "sehenswert") или только возможности "-bar" (⟪दृश्य⟫ "видимый"). Образования с этими суффиксами могут быть отрицаны с помощью ⟪अ⟫-/-⟪अन्⟫- (но не образования с -⟪तव्य⟫), и существуют ⟪तत्पुरुष⟫ в качестве их второго компонента, с которыми они встречаются.
:::
### 41.2.5. Отсутствие связи с ⟪सु⟫- и ⟪दुस्⟫-

::: grammar-box
С ⟪सु⟫- и ⟪दुस्⟫- в значении «лёгкий» или «тяжёлый» герундивы не употребляются. Вместо них используются ⟪तत्पुरुष⟫ типа  ⟪सुकर⟫ 3 («лёгкий для выполнения») (см. [Урок 18](lektion18.md)).
:::

⟪कन्यां व्युवह तस्यां च पुत्रमजनयं महाधनं च लेभ एवं सुखमापेत्यतीते मुमोह । ततः प्रजज्ञौ सुखाद्दुःखं जायते तस्माल्लोकसुखमपि त्यजनीयं न च किंचिदिन्द्रियैः स्प्रष्टव्यमिति ॥३॥⟫
