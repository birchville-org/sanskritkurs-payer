# Урок 45

## 45.2. Звательный падеж единственного числа (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**Большинство звательных форм единственного числа совпадает со основой, имеющей высокий уровень.**

напр. **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** и т.д.

**Исключения составляют женского рода на -ā и -ī, а также основы на -in, звательный падеж единственного числа которых следует запомнить особо.**
:::
::: no-header
| | Звательный падеж Единственное число |
| --- | --- |
| Мужского рода на -a | ⟪देव⟫ |
| Среднего рода на -a | ⟪फल⟫ |
| Женского рода на -ā | ⟪देवते⟫ |
| Мужского рода на -i | ⟪कवे⟫ |
| Женского рода на -i | ⟪मते⟫ |
| Мужского рода на -u | ⟪शत्रो⟫ |
| Женского рода на -u | ⟪धेनो⟫ |
| Женского рода на -ī | ⟪देवि⟫ |
| Мужского рода на -ṛ | ⟪पितर्⟫ |
| Женского рода на -ṛ | ⟪मातर्⟫ |
| Мужского рода на -an | ⟪राजन्⟫ |
| Среднего рода на -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Мужского рода на -man/-van | ⟪आत्मन्⟫ |
| Мужского рода на -in | ⟪बलिन्⟫ |
| Мужского рода на -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt m. | ⟪महन्⟫ |
| mahānt n. | ⟪महत्⟫:br= Именительный падеж |
| Мужского рода на -mant/-vant | ⟪गुणवन्⟫ |
| Среднего рода на -mant/-vant | ⟪गुणवत्⟫:br= Именительный падеж |
| Местоимения | ein Звательный падеж wird nicht gebildet |
:::

## 45.4. Упражнение

A) Переведите на санскрит (для форм прошедшего времени, пожалуйста, используйте имперфект \&lt;⟪लङ्⟫\&gt;):

1\. Ты раскалываешь (буддийскую) сангху.

::: indent
о раскалывании сангхи (⟪सङ्घभेद⟫) см.:

**Пайер, Алоис (1944–):** Винаямукха : Основные понятия монашеских правил и монашеского права Тхеравады. -- Часть I. -- (Материалы по основным понятиям буддизма). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::
2\. Наслаждались ли вы землёй?

3\. Получили ли вы дар от царя?

4\. Святой муж, почему ты не боишься опасностей?

5\. Отец, куда ты оставляешь семью?

6\. Шудра-женщина, перенесла ли ты ношу в дом богатого брахмана?

7\. Богиня, ты должна исполнить желание счастья вайшьи, совершившего заслуженные дела.

8\. Слоны, вы не должны разбивать оковы.

9\. Ты, львоподобный муж, почему не направляешь всё своё внимание на Абсолютное (Брахмана)?

10\. Измерил ли ты, поэт, миры?

B) Переведите:

⟪अर्जुन⟫ ⟪हतो⟫ ⟪वा⟫ ⟪प्राप्स्यसि⟫ ⟪स्वर्गं⟫ ⟪जित्वा⟫ ⟪वा⟫ ⟪भोक्ष्यसे⟫ ⟪महीं⟫ ⟪।⟫ ⟪तस्माद्भवता⟫ ⟪योध्यम्⟫ ⟪॥१॥⟫
