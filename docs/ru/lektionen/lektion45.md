# Урок 45

## 45.1. Образование форм глагола второго лица (⟪मध्यमः⟫) безгласных основ без суффикса, оканчивающегося на гласный (продолжение)

### 45.1.2. Седьмой класс настоящего времени (⟪रुधादि⟫)

::: grammar-box
**Если конечный k/g корня оказывается между носовым ṅ и зубным согласным окончания, то k/g может опускаться по выбору**

например ⟪युज्⟫ 3.ед.Инд.Наст.Ā ⟪युङ्क्ते⟫ или ⟪यु⟫:sig[⟪ङ्ते⟫]
:::
⟪युज्⟫ 7У

::: grammar-box
| | ⟪परस्मैपदम्⟫ || ⟪आत्मनेपदम्⟫ ||

| **Индикатив Настоящее время** :br⟪लट्⟫ | ⟪युनक्षि⟫:bryu-na-j + si | ⟪युङ्क्थ⟫:br⟪युङ्थ⟫ | ⟪युङ्क्षे⟫ | ⟪युङ्ग्ध्वे⟫:br⟪युङ्ध्वे⟫ |
| **Imперфект** :br⟪लङ्⟫ | ⟪अयुनक्⟫:braus: a-yu-na-j + s | ⟪युङ्क्त⟫:br⟪अयुङ्त⟫ | ⟪अयुङ्क्थास्⟫:br⟪अयुङ्थास्⟫ | ⟪अयुङ्ग्ध्वम्⟫:br⟪अयुङ्ध्वम्⟫ |

:::

## 45.2. Звательный сингуляр (⟪आमन्त्रितमेकवचने⟫)

::: grammar-box
**Большинство звательных форм сингуляра совпадает с основой, имеющей сильную ступень в окончании.**

например **⟪देव⟫, ⟪कवे⟫, ⟪शत्रो⟫, ⟪राजन्⟫, ⟪पितर्⟫** и т.д.

**Исключениями являются женские роды на -ā и -ī, а также основы на -in, звательный сингуляр которых следует запомнить особо.**
:::
::: no-header
| | Звательный сингуляр |
| --- | --- |
| Мужской род на -a | ⟪देव⟫ |
| Средний род на -a | ⟪फल⟫ |
| Женский род на -ā | ⟪देवते⟫ |
| Мужской род на -i | ⟪कवे⟫ |
| Женский род на -i | ⟪मते⟫ |
| Мужской род на -u | ⟪शत्रो⟫ |
| Женский род на -u | ⟪धेनो⟫ |
| Женский род на -ī | ⟪देवि⟫ |
| Мужской род на -ṛ | ⟪पितर्⟫ |
| Женский род на -ṛ | ⟪मातर्⟫ |
| Мужской род на -an | ⟪राजन्⟫ |
| Средний род на -an | ⟪नामन्⟫:br⟪नाम⟫ |
| Мужской род на -man/-van | ⟪आत्मन्⟫ |
| Мужские роды на -in | ⟪बलिन्⟫ |
| Мужские роды на -ant | ⟪बलिन्⟫:br⟪बलि⟫ |
| mahānt м. род | ⟪महन्⟫ |
| mahānt ср. род | ⟪महत्⟫:br= Именительный падеж |
| Мужские роды на -mant/-vant | ⟪गुणवन्⟫ |
| Средний род на -mant/-vant | ⟪गुणवत्⟫:br= Именительный падеж |
| Местоимения | звательный падеж не образуется |
:::

## 45.4. Упражнения

A) Переведите на санскрит (для форм прошедшего времени используйте имперфект \<⟪लङ्⟫\>):

1\. Ты разделяешь (буддийскую) общину.

::: indent
о разделении общины (⟪सङ्घभेद⟫) см.:

**Payer, Alois \<1944 - \>:** Vinayamukha : Основные понятия правил монашеской дисциплины и церковного права тхеравады. -- Часть I. -- (Материалы по основным понятиям буддизма). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::
2\. Наслаждались ли вы землёй?

3\. Получили ли вы дар от царя?

4\. Святой муж, почему ты не боишься опасностей?

5\. Отец, куда оставляешь ты семью?

6\. Жена шудры, несут ли вы ношу в дом богатого брахмана?

7\. Богиня, ты должна исполнить желание счастья вайшьи, совершившего заслугу.

8\. Слоны, вы не должны разбивать оковы.

9\. Ты, подобный льву муж, почему не направляешь всё своё внимание на Абсолют (Брахман)?

10\. Поэт, измерил ли ты миры?

B) Переведите:

⟪अर्जुन हतो वा प्राप्स्यसि स्वर्गं जित्वा वा भोक्ष्यसे महीं । तस्माद्भवता योध्यम् ॥१॥ भवति कथमनन्तदुःखमरुणत् ॥२॥ ब्राह्मण किमग्नौ घृतमजुहोः ॥३॥ शत्रो शस्तेण जीवं न छिनत्सि ॥४॥⟫
