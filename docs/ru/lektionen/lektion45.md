## 45.2. Der Звательный падеж Единственное число (आमन्त्रितमेकवचने)

::: grammar-box
**Большинство форм звательного падежа единственного числа представляет собой основу с конечным гласным высокой степени (гуна).**

напр. **देव, कवे, शत्रो, राजन्, पितर्** и т.д.

**Исключениями являются женские роды на -ā и -ī, а также основы на -in, звательный падеж единственного числа которых следует запомнить особо.**
:::

:::: grammar-box
::: no-header
| | Звательный падеж Единственное число |

| Neutra auf -a | फल |

| Maskulina auf -i | कवे |
| Feminina auf -i | मते |
| Maskulina auf -u | शत्रो |
| Feminina auf -u | धेनो |
| Feminina auf -ī | देवि |

## 45.4. Упражнение

A) Переведите на санскрит (для форм прошедшего времени используйте имперфект &lt;लङ्&gt;):

1\. Ты раскалываешь (буддийскую) сангху.

::: indent
О раскалывании сангхи (सङ्घभेда) см.:

**Payer, Alois &lt;1944 – &gt;:** Vinayamukha : Основные понятия монашеских правил и монашеского права тхеравады. -- Часть I. -- (Материалы по основным понятиям буддизма). -- _URL_: [http://www.payer.de/buddhgrund/vinaya01.htm](http://www.payer.de/buddhgrund/vinaya01.htm)
:::

2\. Наслаждались ли вы землёй?

3\. Принял ли ты от царя дар?

4\. Святой муж, почему ты не боишься опасностей?

5). Отец, куда ты оставляешь семью?

6\. Шудра-женщина, перенесла ли ты ношу в дом богатого брахмана?

7). Богиня, ты должна исполнить желание счастья вайшьи, совершившего заслуги.

8). Слоны, вы не должны разбивать оковы.

9). Ты, муж, равный льву, почему не направляешь всё своё внимание на Абсолютное (Брахман)?

10). Измерил ли ты, поэт, миры?

B) Переведите:

अर्जुन हतो वा प्राप्स्यसि स्वर्गं जित्वा वा भोक्ष्यसे महीं । तस्माद्भवता योध्यम् ॥१॥

भवति कथमनन्तदुःखमरुणत् ॥२॥

ब्राह्मण किमग्नौ घृतमजुहोः ॥३॥

शत्रो शस्तेण जीवं न छिनत्सि ॥४॥
