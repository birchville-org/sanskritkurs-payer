# Урок 54

## 54.1. Предисловие

С урока 54 в университетском курсе начинается второй семестр. Теперь курс будет идти параллельно с основной темой этого семестра: чтением полного текста «Бхагавадгиты». Цель обучения — достичь такой беглости в чтении текстов средней сложности, чтобы в последней трети семестра можно было переводить большие фрагменты «Бхагавадгиты» с ходу. В начале университетского курса раздавались списки слов, позже студенты должны были самостоятельно пользоваться соответствующими словарями (Monier-Williams, Apte, PW).

Курс по «Бхагавадгите» пока не будет доступен онлайн.

Уроки курса санскрита рассматривают темы грамматики санскрита, которые ранее не изучались.

## 54.2. Словообразование: суффикс -u ⟪कृत्⟫ к основам желательного наклонения

::: grammar-box
**К основам желательного наклонения (⟪इच्छाप्रकृति⟫) («желать сделать что-то»; «намереваться совершить действие») для образования существительных действительного причастия (agentis) добавляется суффикс -u.**

(Образование основ желательного наклонения рассматривается позже)

Пример:

:::
::: indent
⟪युयुत्सु⟫ (yu-yudh + s + u) «жаждущий сражения, намеревающийся вступить в бой»
:::

## 54.3. Метрика II: эпическая ⟪त्रिष्टुभ्⟫ и ⟪जगती⟫

::: grammar-box
⟪त्रिष्टुभ्⟫ («тройная стопа») встречается в эпосах среди обычных частей ⟪श्लोक⟫ именно в тех местах, где настроение или действие переживают особый подъем или завершение.

⟪त्रिष्टुभ्⟫-строфа состоит из четырех одиннадцатисложных ⟪पाद⟫, которые не отличаются друг от друга по строению.

⟪त्रिष्टुभ्⟫ имеет две основные схемы в зависимости от того, находится ли цезура (конец слова, граница композиции или перед определенными суффиксами, такими как -tara, -tama и т.д.) после 4-го или 5-го слога ⟪पाद⟫.

Схема I:

:::
::: metrik-schema
× — × — / × ◡ — **— ◡ — —**
:::
Схема II:

::: metrik-schema
× — × — × / × ◡ **— ◡ — —**
:::
Таким образом, количество четырех последних слогов в обеих схемах одинаково.

⟪जगती⟫-основная форма: как у ⟪त्रिष्टुभ्⟫, но двенадцатисложная. Последние 5 слогов каждого пады имеют следующие количества:

::: metrik-schema
**— ◡ — ◡ —**
:::
Кроме того, существует т.н. типично избыточная ⟪त्रिष्टुभ्⟫ с пятисложным начальным членом, которая продолжается как ⟪त्रिष्टुभ्⟫ с четырехсложным начальным членом:

::: metrik-schema
— × — × / × ◡ — **— ◡ — —**
:::
В более поздний период формы ⟪त्रिष्टुभ्⟫ фиксируются согласно строгой схеме длинных и кратких слогов, цезура больше не играет роли. Наиболее важные поздние формы:

a) ⟪इन्द्रवज्रा⟫

::: metrik-schema
**—** — ◡ — , — ◡ ◡ — ◡ — —
:::
b) ⟪उपेन्द्रवज्रा⟫

::: metrik-schema
**◡** — ◡ — , — ◡ ◡ — ◡ — —
:::
c) ⟪उपजाति⟫

::: indent
⟪पाद⟫ в ⟪इन्द्रवज्रा⟫ и ⟪पाद⟫ в ⟪उपेन्द्रवज्रा⟫ смешаны в одну строфу.
:::
::: grammar-box
**Запоминающие стихи:**

**⟪स्यादिन्द्रवज्रा यदि तौ जगौ गः ।⟫**

:::
::: indent
"Это Индравāйрā, если слоги во всех падах — та та я га га.
:::
⟪उपेन्द्रवज्रा प्रथमे लघौ सा ।⟫

::: indent
«Upendravajrā подобна Indravajrā, которая в начале имеет лёгкую слоговую структуру»
:::
⟪अनन्तरोदीरितलक्ष्मभाजौ पदौ यदीयावुपजातयस्ताः । इत्थं किलान्यास्वपिमिश्रितासु वदन्ति जातिष्विदमिदमेवनाम ॥⟫

::: indent
«Если два пады, обладающие характеристиками Indravajrā и Upendravajrā соответственно, участвуют в одном стихе, то это upajāti. Даже если в стихе смешаны другие метры, его также называют upajāti.»
:::

## 54.5. Типы образования аориста (⟪लुङ्⟫)

::: grammar-box
**Общим для всех типов образования аориста (⟪लुङ्⟫) является авгмент a-, который добавляется по тем же правилам, что и в имперфекте (⟪लङ्⟫).**

В санскрите от аориста используются только изъявительное наклонение (индикатив) и прескатив.
:::
::: grammar-box
**Существуют следующие типы образования аориста (⟪लुङ्⟫):**

1. Несибилантные (асигматические) аористы:
*   54.1. Корневой аорист: авгмент + корень + вторичное окончание
*   54.2. Тематический аорист: авгмент + корень + **a** + вторичное окончание
*   54.3. Редуплицированный аорист: авгмент + **редуплицированный** корень + **a** + вторичное окончание
2. Сибилантные (сигматические) аористы: s или слог, содержащий s (ṣ), предшествует личному окончанию
*   54.4. -s-аорист: авгмент + корень + **s** \+ вторичное окончание
*   54.5. -iṣ-аорист: авгмент + корень + **i** + **ṣ** + вторичное окончание
*   54.6. -siṣ-аорист: авгмент + корень + **siṣ** + вторичное окончание
*   54.7. -sa-аорист: авгмент + корень + **s** + **a** + вторичное окончание

Распределение корней по типам словообразования см. в описании каждого типа
:::
## 54.6. Корневой аорист

::: grammar-box
**Образование:**

**Аугмент + корень + вторичное окончание**
:::
Окончание 3 л. мн. ч. — -ur. Атманепада не употребляется.

Пример:

⟪पा⟫ 1P «пить»

::: grammar-box
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| --- | --- | --- |
| 1. ⟪तृतीयः⟫ | ⟪अपाम्⟫:bra-pā + am | ⟪अपाम⟫ |
| 2. ⟪मध्यमः⟫ | ⟪अपास्⟫ | ⟪अपात⟫ |
| 3. ⟪प्रथमः⟫ | ⟪अपात्⟫ | ⟪अपुर्⟫:bra-p-ur (слабая степень!) |
:::
Корневой аорист образуется только от 12 корней:

1.  ⟪गा⟫ 3 «идти»
2.  ⟪घ्रा⟫ 1P «нюхать»
3.  ⟪छो⟫ 6 «резать» (⟪अच्छात्⟫)
4.  ⟪दा⟫ 3U «давать»
5.  ⟪दो⟫  , 4 «резать»
6.  ⟪धा⟫ 3U «садить»
7.  ⟪धे⟫ 1 «сосать» (⟪अधात्⟫)
8.  ⟪पा⟫ 1P «пить»
9.  ⟪शो⟫ 4P «затачивать»
10. ⟪सो⟫ «оканчивать»
11. ⟪स्था⟫ 1P «стоять»
12. ⟪भू⟫ 1P «быть»

Для ⟪भू⟫ 1P корневой аорист образуется следующим образом:

::: grammar-box
|   | ⟪एकवचनम्⟫ | ⟪बहुवचनम्⟫ |
| --- | --- | --- |
| 1. ⟪तृतीयः⟫ | ⟪अभूवम्⟫ | ⟪अभूम⟫ |
| 2. ⟪मध्यमः⟫ | ⟪अभू्स्⟫ | ⟪अभूत⟫ |
| 3. ⟪प्रथमः⟫ | ⟪अभूत्⟫ | :sig[⟪अभूवन्⟫] (!!!) |
:::
### 54.6.1. Аорист 3 л. ед. ч. страдательного залога

Специальной формой корневого аориста является аорист 3 л. ед. ч. страдательного залога. Он может образовываться от всех корней.

::: grammar-box
**Образование:**

**Аугмент + корень + i**

**Корень имеет следующую форму:**

Сильная степень:

*   Корни с кратким гласным (кроме a) перед простым согласным, а также ⟪जन्⟫ и большинство корней на -am  
Примеры:  
::: indent
⟪भिद्⟫ 7U: ⟪अभेदि⟫ «он был расщеплён»
⟪तुद्⟫ 6U: ⟪अतोदि⟫ «он был толкнут»
:::

Степень удлинения:

*   Корни с конечным гласным  
Примеры:  
::: indent
⟪नी⟫ 1U: ⟪अनायि⟫ "он был ведён"
⟪स्तु⟫ 2U: ⟪अस्तावि⟫ "она была восхвалена"
⟪कृ⟫ 8U: ⟪अकारि⟫ "это было сделано"
:::


*   Корни с a перед простым согласным (кроме ⟪जन्⟫ и корней на -am)  
Пример:  
::: indent
⟪वद्⟫ 1P: ⟪अवादि⟫ "это было сказано"
но:
⟪जन्⟫ 4Ā: ⟪अजनि⟫ "она была рождена"
:::


*   некоторые корни на -am  
Пример:  
::: indent
⟪गम् अगामि⟫
:::


Вставка y перед окончанием:

*   Корни на -ā, -e, -ai, -o вставляют y между -ā корня и окончанием:  
Пример:  
::: indent
⟪दा⟫ 3U: ⟪अदायि⟫ "это было дано"
:::


Насальный инфикс:

*   некоторые корни имеют насальный инфикс:  
Пример:  
::: indent
⟪लभ्⟫ 1Ā: ⟪अलम्भि⟫ наряду с ⟪अलाभि⟫ : "это было принято"
:::


(Остальные формы пассива в аористе передаются формами атманепады).
:::
