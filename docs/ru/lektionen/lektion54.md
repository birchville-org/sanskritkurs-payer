# Урок 54

## 54.1. Предисловие

С урока 54 в рамках университетского курса начинается второй семестр. С этого момента курс проходит параллельно с основной темой данного семестра: чтением полного текста «Бхагавадгиты». Цель обучения — достичь такого уровня беглости чтения средне-сложных текстов, чтобы в последние трети семестра можно было переводить значительные фрагменты «Бхагавадгиты» с места. В начале занятий студентам раздавались списки слов; впоследствии студенты должны были самостоятельно пользоваться соответствующими словарями (Monier-Williams, Apte, PW).

Курс по «Бхагавадгите» пока не будет доступен онлайн.

Уроки санскритского курса рассматривают темы санскритской грамматики, которые ранее не изучались.

## 54.2. Словообразование: суффикс -u к десидеративным основам

**К десидеративным основам (इच्छाप्रकृति) («желать совершить действие»; «намереваться совершить действие») для образования существительных действия (nomina agentis) присоединяется суффикс -u.**
:::

(Образование десидеративных основ рассматривается ниже)

Пример:

::: indent
युयुत्सु (yu-yudh + s + u) «жаждащий сражения, намеревающийся сражаться»
:::

## 54.3. Метрика II: эпическая त्रिष्टу́бх и जगती

Тритштубх (त्रिष्टु́भъ, «три яу́хара») появляется в эпосах среди обычных частей шлока именно в тех местах, где настроение или действие переживают особый подъём или завершение.

Строфа тритштубх состоит из четырёх одиннадцатисложных па́д, которые по своему строению не отличаются друг от друга.

У тритштубх есть две основные схемы в зависимости от того, находится ли цезура (конец слова, композиционная граница или перед определёнными суффиксами, такими как -тара, -тама и т.д.) после четвёртой или пятой слога па́ды.

Схема I:

::: indent
̽ ˉ ̽ ˉ / ̽ ˘ˉˉ˘ˉˉ
:::

Схема II:

::: indent
̽ ˉ ̽ ˉ ̽  / ̽ ˘ˉ˘ˉˉ
:::

Таким образом, количество последних четырёх слогов в обеих схемах одинаково.

Основная форма jagati: как у тритштубх, но двенадцатисложная. Последние пять слогов каждого па́ды имеют следующее количество:

::: indent
ˉ˘ˉ˘ˉ
:::

Кроме того, существует так называемая типично избыточная тритштубх с пятислоговой начальной частью, которая продолжается как тритштубх с четырёхслоговой начальной частью:

::: indent
ˉ ̽ ˉ ̽  / ̽ ˘ˉˉ˘ˉˉ
:::

В более поздние время формы тритштубх фиксируются по строгой схеме длинных и коротких слогов, цезура больше не играет роли. Наиболее важные поздние формы:

a) индраванджа

::: indent
ˉˉ˘ˉ,ˉ˘˘ˉ˘ˉˉ
:::

b) упендраванджа

::: indent
˘ˉ˘ˉ,ˉ˘˘ˉ˘ˉˉ
:::

c) упджати

::: indent
Па́ды в индравандже и па́ды в упендравандже смешаны в одной строфе.
:::

::: grammar-box
**Запоминающие стихи:**

**स्यादिन्द्रवज्रा यदि तौ जगौ गः ।**
:::

::: indent
"Это индраванджа, если слоги во всех па́дах та та я га га."
:::

उपेन्द्रवज्रा प्रथमे लघौ सा ।

::: indent
"Упендраванджа — это как индраванджа, имеющая в начале лёгкий слог"
:::

अनन्तरोदीरितलक्ष्मभाजौ  
पदौ यदीयावुपजातयस्ताः ।  
इत्थं किलान्यास्वपिमिश्रितासु  
वदन्ति जातिष्विदमिदमेवनाम ॥

::: indent
"Если два па́ды, имеющие признаки индраванджи и упендраванджи соответственно, участвуют в одном стихе, то это упджати. Также если другие метры смешаны в одном стихе, это называется упджати."
:::

## 54.5. Типы образования аориста (लुङ्)

::: grammar-box
**Общим для всех типов образования аориста (लुङ्) является аугмент a-, который ставится перед основой по тем же правилам, что и в имперфекте (लङ्).**
:::

В санскрите из аориста употребительны только изъяснительное наклонение (индикатив) и сослагательное наклонение (прекатив).

::: grammar-box
**Существуют следующие типы образования аориста (लुङ्):**
:::

1.  Несибилантные (асигматические) аористы:
    *   54.1. Корневой аорист: аугмент + корень + вторичное окончание
    *   54.2. Тематический аорист: аугмент + корень + a + вторичное окончание
    *   54.3. Редуцированный аорист: аугмент + редуцированный корень + a + вторичное окончание
2.  Сибилантные (сигматические) аористы: s или слог, содержащий s (ṣ), ставится перед личным окончанием
    *   54.4. -s-аорист: аугмент + корень + s + вторичное окончание
    *   54.5. -iṣ-аорист: аугмент + корень + i + ṣ + вторичное окончание
    *   54.6. -siṣ-аорист: аугмент + корень + siṣ + вторичное окончание
    *   54.7. -sa-аорист: аугмент + корень + s + a + вторичное окончание

Распределение корней по отдельным типам см. в описании соответствующих типов.

## 54.6. Корневой аорист

::: grammar-box
**Образование:**

**Аугмент + корень + вторичное окончание**
:::

Окончание 3 л. мн. ч. — `-ur`. Атманапада не употребляется.

Пример:

पा 1P «пить»

::: grammar-box
|   | Единственное число | Множественное число |
| --- | --- | --- |
| 1\. Третье лицо | अपाम   | |
| a-pā + am | अपाम | | |
| 2\. Второе лицо | अपास् | अपात |
| 3\. Первое лицо | अपात् | अपुर्   |
| a-p-ur (слабая ступень!) | | | |
:::

Корневой аорист образуется только от 12 корней:

1.  गा 3 «идти»
2.  घ्रा 1P «нюхать»
3.  छो 6 «резать» (अच्छात्)
4.  दा 3U «давать»
5.  दो  1, 4 «резать»
6.  धा 3U «сажать»
7.  धे 1 «сосать» (अधात्)
8.  पा 1P «пить»
9.  शो 4P «затачивать»
10.  со «завершать»
11.  स्था 1P «стоять»
12.  भू 1P «быть»

От корня भू 1P корневой аорист образуется следующим образом:

::: grammar-box
|   | Единственное число | Множественное число |
| --- | --- | --- |
| 1\. Третье лицо | अभूवम् | अभूम |
| 2\. Второе лицо | अभू्स् | अभूत |
| 3\. Первое лицо | अभूत् | अभूवन् (!!!) |
:::

### 54.6.1. Аорист 3-го лица единственного числа страдательного залога

Специальной формой корневого аориста является аорист 3-го лица единственного числа страдательного залога. Он может образовываться от всех корней.

::: grammar-box
**Образование:**

**Авгмент + корень + i**

**Корень принимает следующую форму:**
:::

Усиленная ступень (гуна):

*   Корни с кратким гласным (кроме a) перед простым согласным, а также जन् и большинство корней на -am  
    Примеры:  
    भिद् 7U: अभेदि «он был расщеплён»  
    तुद् 6U: अतोदि «он был толкну́т»
    

Удлинённая ступень (вартимана):

*   Корни с конечным гласным  
    Примеры:  
    नी 1U: अनायि «он был приведён»  
    स्तु 2U: अस्तावि «она была восхвалена»  
    कृ 8U: अकारि «это было сделано»  
     
    
*   Корни с a перед простым согласным (кроме जन् и корней на -am)  
    Пример:  
    वद् 1P: अवादि «это было сказано»  
    однако:  
    जन् 4Ā: अजनि «она была рождена»  
     
    
*   некоторые корни на -am  
    Пример:  
    गम् अगामि
    

Вставка y перед окончанием:

*   Корни на -ā, -e, -ai, -o вставляют между -ā корня и окончанием y:  
    Пример:  
    दा 3U: अदायи «это было дано»
    

Назальное инфиксное дополнение:

*   некоторые корни имеют назальное инфиксное дополнение:  
    Пример:  
    लभ् 1Ā: अलम्भि наряду с अलाभि : «это было получено»
    

(Остальные формы страдательного залога в аористе выражаются формами атманапады).
