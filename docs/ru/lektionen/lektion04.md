## 4.1. Простые дополняющие вопросы (вопросы к слову) и ответы

### 4.1.1. Вопросительные и указательные местоимения

#### 4.1.1.1. Вопросительные местоимения (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box
| | Именительный падеж, единственное число | Именительный падеж, множественное число |
| :--- | :--- | :--- |
| **Средний род** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **Мужской род** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **Женский род** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |
:::
#### 4.1.1.2. Указательные местоимения (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box
| **Основа** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"он, она, оно; тот, та, то":br(Упомянутый)** | **etad = ⟪एतद्⟫:br"этот, эта, это":br(Очень близко к говорящему)** | **idam = ⟪इदम्⟫:br"этот, эта, это":br(Близко)** |
| **Именительный падеж, единственное число** ||||
| **Средний род** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **Мужской род** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **Женский род** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **Именительный падеж, множественное число** ||||
| **Средний род** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **Мужской род** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **Женский род** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |
:::
**К им. ед. ч. м. р.:**
- **sa, eṣa** (⟪स एष⟫) стоит перед всеми звуками, кроме краткого **-a**
- **so, eṣo** (⟪सो एषो⟫) стоит перед **-a**, которое элидируется с помощью авиграхи (выпадает)
- **saḥ, eṣaḥ** (⟪सः एषः⟫) стоит только в паузе (конец предложения, конец стиха)

Чтобы можно было образовывать с этими местоимениями (sarvanāman n.) предложения, необходимо также знание следующих правил сандхи:

### 4.1.2. Сандхи конечного -m

::: grammar-box
**Конечное -m перед согласными заменяется на анусвāру (-ṃ). В конце предложения или стиха, а также перед гласными -m сохраняется.**
:::
### 4.1.3. Сандхи конечного -e

::: grammar-box
1. **перед a- конечное -e остаётся неизменным: начальное a- элидируется с авиграхой:**
напр. ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "Эти огонь"

2. **Перед другими гласными, кроме краткого a-, конечное -e обычно заменяется на -a с хайатусом. Также встречается замена на -ay:**
напр. ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (редко: imay īśvarāh = ⟪इमयीश्वराः⟫) "Эти ГОСПОДА"
:::
### 4.1.4. Сандхи конечного -d

::: grammar-box
**Конечное -d в паузе, а также перед глухими кавальными (k, kh) и губными согласными (p, ph) заменяется на -t.**

Замена перед другими согласными будет рассмотрена позже. Временно избегайте таких слияний звуков!
:::
### 4.1.5. Вопросительные формулы

С помощью этих местоимений образуются, например, следующие вопросительные формулы:

::: no-header
| | | | |
| :--- | :--- | :--- | :--- |
| **Единственное число** | **Средний род** | tat kim? /kiṃ tat?:br⟪तत्किम्⟫, ⟪किं तत्⟫:bretat kim? /kim etat?:br⟪एतत्किम्⟫, ⟪किमेतत्⟫:bridaṃ kim? / kim idam:br⟪इदं किम्⟫, ⟪किमिदम्⟫ | "Что это?" |
| ^^| **Мужской род** | sa kaḥ? / kaḥ saḥ?:br⟪स कः⟫, ⟪कः सः⟫:breṣa kaḥ? / ka eṣaḥ:br⟪एष कः⟫, ⟪क एषः⟫:brayaṃ kaḥ? / ko 'yam?:br⟪अयं कः⟫, ⟪को ऽयम्⟫ | "Кто это?":br"Что такое?" |
| ^^| **Женский род** | sā kā? / kā sā?:br⟪सा का⟫, ⟪का सा⟫:breṣā kā? / kaiṣā? (= kā + eṣā):br⟪एषा का⟫, ⟪कैषा⟫:briyaṃ kā? / keyam? (= kā + iyam):br⟪इयं का⟫, ⟪केयम्⟫ | "Кто это?":br"Кто она?" |
| **Множественное число** | **Средний род** | tāni kāni? / kāni tāni?:br⟪तानि कानि⟫, ⟪कानि तानि⟫:bretāni kāni? / kāny etāni?:br⟪एतानि कानि⟫, ⟪कान्येतानि⟫:brimāni kāni? / kānīmāni? (= kāni + imāni):br⟪इमानि कानि⟫, ⟪कानीमानि⟫ | |
|^^ | **Мужской род** | te ke? / ke te?:br⟪ते के⟫, ⟪के ते⟫:brete ke? / ka ete?:br⟪एते के⟫, ⟪क एते⟫:brime ke? / ka ime?:br⟪इमे के⟫, ⟪क इमे⟫ | |
| ^^| **Женский род** | tāḥ kāḥ? / kās tāḥ?:br⟪ताः काः⟫, ⟪कास्ताः⟫:bretāḥ kāḥ? / kā etāḥ?:br⟪एताः काः⟫, ⟪का एताः⟫:brimāḥ kāḥ? / kā imāḥ?:br⟪इमाः काः⟫, ⟪का इमाः⟫ | |
:::
Пример других вопросов:

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ Ответ: viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫. (В номинативном предложении можно, например, вынести подлежащее в начало, чтобы подчеркнуть связь с вопросом.)

ПРИМЕЧАНИЕ: Ответы, которые вы можете дать на такие вопросы с помощью ваших текущих знаний санскрита, конечно же, еще не во всех отношениях соответствуют идиоматически хорошему санскриту.


## 4.2. Упражнение

śruti, śiva, brāhmaṇa, dvija (множественное число), indrāṇī, dhenu, tulādhara, kālidāsa
