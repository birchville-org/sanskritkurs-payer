## 61.2. Перифрастическое будущее время (लुट्)

::: grammar-box
**Помимо простого будущего времени (ऌत्) существует перифрастическое будущее время (लुट्). Согласно учению местных грамматиков, оно используется для обозначения отдалённого будущего («после текущего дня»), тогда как простое будущее время обозначает ближайшее будущее («в текущий день»). В классическом санскрите, как правило, не делается различия в употреблении двух форм будущего времени.**
:::

Образование:

Перифрастическое будущее время образуется путём соединения имени действия на -tṛ с формой настоящего времени глагола अस् 2. В качестве третьей лица выступает простое имя в соответствующем числе, без различия по грамматическому роду. При соединениях с глаголом अस् имя во всех лицах и числах имеет форму именительного падежа единственного числа на -tā.

Окончания перифрастического будущего времени звучат следующим образом:

|   | परस्मैपदम् | आत्मनेपदम् | | | | |
| --- | --- | --- | --- | --- | --- | --- |
|   | एकवचनम् | द्विवचनम् | बहुवचनम् | एकवचनम् | द्विवचनम् | बहुवचनम् |
| 1\. तृतीयः | \-tāsmi   | | | | | |
(-tā + asmi) | \-tāsvas | \-tāsmas   | | | | | |
(-tā smas) | \-tāhe | \-tāsvahe | \-tāsmahe | | | | |
| 2\. मध्यमः | \-tāsi | \-tāsthas | \-tāstha | \-tāse | \-tāsāthe | \-tādhve |
| 3\. प्रथमः | \-tā | \-tārau | \-tāras | \-tā | \-tārau | \-tāras |

::: grammar-box
**Форма корня: Корень, как правило, имеет ту же форму, что и в простом будущем времени. То же самое относится к соединительному гласному -i-.**
:::

Примеры:

| दा 3U | दातास्मि, दतासि, दाता и т.д. |
| --- | --- |
| भू 1P | भवितास्मि ... भाविता и т.д. |
| तुद् 6U | तोत्तास्मि ... तोत्ता и т.д. |
| गै 1P | गातास्मि ... गाता и т.д. |

## 61.3. Интенсив (Фреквентатив) (चर्करीतम्)

::: grammar-box
**От каждого односложного корня, начинающегося на согласный, из первых девяти классов настоящего времени может быть образован интенсив (चर्करीतम्); то есть: за исключением нескольких случаев, от двухсложных корней (напр., जागृ), корней, начинающихся на гласный, и корней 10-го класса настоящего времени (चुरादिगण) интенсив не образуется.**
:::

Интенсив означает:

*   что лицо или предмет вновь и вновь совершает или претерпевает то, что выражено корнем:  
    कृ 8U: चेक्रीयते / चर्करीति «он делает вновь и вновь»  
    भू 1P: बोभूयते / बोभवीति «он часто бывает (становится)»  
     
*   что лицо или предмет совершает или претерпевает то, что выражено корнем, с усилением:  
    कृ 8U: चेक्रीयते / चर्करीति «он делает интенсивно, он делает усердно»  
     
*   у корней, выражающих движение, интенсив означает изогнутое движение:  
    व्रज् 1P:  वव्रज्यते «он движется извиваясь» (НЕ: «он часто движется»)  
     
*   у некоторых корней (перечисление: Кильтгорн, Грамматика § 458b) интенсив выражает порицание:  
    लुप् 6U: लोलुप्यते «он режет плохо»  
    सद् 1P: सासद्यते «он садится плохо»

::: media
![](/images/lekt6104.jpg)
Рис.: सर्पो वव्रज्यते ॥
(Источник изображения: [Детали](/licenses#lekt6104))
:::
::: grammar-box
**Образование интенсива:**

**Существует два типа образования интенсива:**
:::

*   Интенсив в форме Ātmanepada
*   Интенсив в форме Parasmaipada

Оба образуются от корня, редуплицированного с сильным редупликационным слогом. Оба не различаются по значению. Оба могут образовываться от одних и тех же корней.

### 61.3.1. Ātmanepada-интенсив

::: grammar-box
**Образование:**

**редуплицированный корень + -ya-**

**Форма корня: в общем случае как в страдательном залоге, т.е. обычно в слабой степени:**
:::

Примеры:

::: indent
स्वप् 2P: Pass. सुप्यते ; Intens. सोषुप्यते
दा 3U: Pass. दीयते ; Intens. देदीयते
:::

Подробные правила приведены у Киельгорна, Грамматика § 461.

Редупликация: по общим правилам. Однако редупликационный гласный: вместо a, i, u стоит ā, e, o.

Примеры:

| दा 3U | देदीय- |
| --- | --- |
| भू 1P | बोभूय- |
| कृ 8U | चेक्रीय- |
| जीव् 1P | जेजीव्य- |
| शास् 2P | शेशिष्य- |
| ज्ञा 9U | जाज्ञाय- |

Корни формы -a-назаль не удлиняют гласный в редупликационном слоге, а повторяют назальный согласный.

::: indent
напр. यम् 1P: यंयम्य-
:::

У некоторых корней между гласным редупликационного слога и начальным согласным корня появляется -nī- или -rī- (-rī- у корней, содержащих в интензиве ṛ).

::: indent
напр.
पत् 1P: पनीपत्य-
वृत् 1Ā: वरीवृत्य-
:::

::: grammar-box
**Спряжение:**

*   **Презентный основа: как у Ātmanepada 4-го класса презенса (दिवादिगण).**
*   **Страдательный залог и остальные временные основы: если перед -ya- интензивной основы стоит гласный, то -ya- заменяется на -y-; если перед -ya- стоит согласный, то -ya- опускается:**
    *   **Презент страдательного залога: बुध् : बोबुध्यते ; भू : बोभूय्यते**
    *   **Перфект: перифразический: बोबुधाञ्चक्रे ; बोभूयाञ्चक्रे**
    *   **Аорист: иш-аорист (аорист 5): अबोबुधिष्ट ; अबोभूयिष्ट**
    *   **Фьютур: seṭ: बोबुधिष्यते ; बोभूयिष्यते**
    *   **перифразический фьютур: बोबुधिता ; बोभूयिता**
:::

### 61.3.2. Параснайпада-интензив

::: grammar-box
**Основа настоящего времени (остальные формы встречаются крайне редко): образование и спряжение аналогичны глаголу 3-го класса настоящего времени (группа जुһотяди), с тем отличием, что гласный в слоге редупликации имеет высокий уровень (удатта), а при -a- — протяжённый уровень (дирга).**
:::

В единственном числе изъявительного наклонения настоящего времени, а также во 2-м и 3-м лице единственного числа имперфекта и 3-м лице единственного числа повелительного наклонения между корнем и окончанием может вставляться -ī-. Если этот -ī- вставляется, краткий глас на предпоследнем месте не должен подвергаться гуна-усилению.

Что касается редупликации с носовым согласным, а также вставки -nī- или -rī-, то здесь действует то же правило, что и для атманапада-интензива. Вместо -rī- может стоять -ri-.

Парадигма:

भू 1P

Изъявительное наклонение настоящего времени (лат):

::: grammar-box
|   | Единственное число | Двойственное число | Множественное число |
| --- | --- | --- | --- |
| 1\. Третье лицо | бобхоми. бобха́ви | бобӯвас | бобӯмас |
| 2\. Второе лицо | бобхоши. бобха́виши | бобӯтхас | бобӯтах |
| 3\. Первое лицо | бобхохи. бобха́вити | бобӯтас | бобувати |
:::

## 61.4. Деноминативы (नामधातु)

Деноминативы (नामधातवः), в отличие от ранее рассмотренных глаголов, образуются не от глагольного корня, а от именной основы. При этом выделяются различные типы словообразования.

### 61.4.1. Образование без специального суффикса, Parasmaipada

:::: grammar-box
**Значение:**

::: indent
**одно лицо или предмет ведёт себя подобно тому, что обозначается номинальным корнем, или подобен ему.**
:::
::::

Спряжение:

::: indent
в настоящем времени как глагол 1-го класса настоящего времени (भ्वादिगण). Если имя содержит гласный *meh*, то только последний гласный рассматривается как корневой гласный 1-го класса. Окончательное -a выпадает перед тематическим гласным. Гласный перед конечным носовым заменяется соответствующим долгим гласным.
:::

Примеры:

| कवि m. "поэт" | कवयति "он ведёт себя как поэт" |
| --- | --- |
| भू f. "земля" | भवति "он ведёт себя как земля" |
| पितृ "отец" | पितरति "он ведёт себя как отец" |
| कृष्ण m. Кṛṣṇa | कृष्णति "он ведёт себя как Кṛṣṇa" |
| माला f. "гирлянда" | मालाति "он подобен гирлянде" |
| राजन् m. "царь" | राजानति "он ведёт себя как царь" |

### 61.4.2. Образование с суффиксом -ya, парасмайапада

::: grammar-box
**Значение:**

*   **кто-то желает того, что обозначается номинальной основой**
*   **кто-то обращается или относится к лицу или предмету так, как если бы он был тем, что обозначается номинальной основой**
:::

Образование основы:

::: indent
перед суффиксом -ya конечный звук номинальной основы претерпевает следующие изменения:

*   a, ā » ī : पुत्र » पुत्रीय-
*   i, u  » ī, ū : कवि » कवीय-
*   ṛ » rī : कर्तृ » कर्त्रीय-
*   o » av : गो » गव्य-
*   au » āv : नौ » नाव्य-
*   конечный носовой звук выпадает, предшествующий ему гласный изменяется согласно вышеприведённым правилам: राजन् » राजीय-
*   другие конечные согласные остаются неизменными
:::

Примеры:

::: grammar-box
| पुत्र m. "сын" | पुत्रीयति "он желает сына" |
| --- | --- |
| कवि m. "поэт" | कवीयति "он желает поэта" |
| गो f. "корова" | गव्यति "он желает корову" |
| राजन् m. "царь" | राजीयति "он желает царя" |
| विष्णु m. Вишну | विष्णूयति "он обращается с кем-то как с Вишну" |
| प्रासाद m. "дворец" | प्रासादीयति "он считает (например, свою хижину) дворцом" |
:::

Обратите внимание на значение следующих слов:

| तपस् n. "аскеза" | तपस्यति "он практикует аскезу" |
| --- | --- |
| नमस् n. "почитание" | नमस्यति "он почитает" |

### 61.4.5. Образование с суффиксом -ya, ātmanepada

:::: grammar-box
**Значение:**

::: indent
**кто-то ведёт себя как то, что обозначено номинальным основой, или подобен ему.**
:::
::::

Образование:

*   конечное -a » -ā
*   конечное -ā остаётся без изменений

:::: grammar-box
**Значение:**

::: indent

## 61.6. Кондиционалис (ऌङ्)

**Кондиционалис (ऌङ्) используется для выражения в условных предложениях того, что условие, названное как таковое, не является фактом / не было фактом / не станет фактом. В таких предложениях кондиционалис должен использоваться как в придаточном условии, так и в главном предложении.**
:::

Пример:

::: indent
सुवृष्टिश्चेदभविष्यत्सुभिक्षमभविष्यत् «Если бы хорошо пошёл дождь (или пойдёт), было бы изобилие пищи. (Но дождь не шёл (достаточно).)»
:::

::: grammar-box
**Образование кондиционалиса (ऌङ्):**

**Авгмент + основа простого будущего (ऌत्) + вторичные окончания**
:::

то есть как имперфект (लङ्) к основе будущего времени.

Например: अदास्यम् ; अभविष्यम् ; अतोत्स्यम्
