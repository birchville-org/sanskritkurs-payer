# Урок 42

## 42.1. Основа на -ṛ

### 42.1.1. Основа с удлиненной ступенью в сильной основе

::: grammar-box
Все существительные мужского рода на -ṛ, за исключением приведенных в 1.3. названий родства. Сюда относятся также следующие названия родства:

*   **नप्तृ** m. "внук"
*   **भर्तृ** m. "супруг (букв. "содержатель")"

Большую часть существительных, относящихся к этой группе, составляют действующие существительные с суффиксом कृत् -तृ.

**Образование:**

*   **Сильная основа: -ār**
*   **Слабая основа**
    *   **перед гласным: -r**
    *   **перед согласным: -ṛ**

Обратите внимание на нерегулярные образования (выделены ***красным***)!
:::

Мужской род:

::: indent
**दातृ** m. "дающий"
:::

::: grammar-box

| | एकवचनम् | बहुवचनम् |
| :--- | :--- | :--- |
| प्रथमा | ***दाता*** | दातारस् |
| द्वितीया | दातारम् | ***दातॄन्*** |
| तृतीया | दात्रा | दातृभिस् |
| चतुर्थी | दात्रे | दातृभ्यस् |
| पञ्चमी | ***दातुस्*** | दातृभ्यस् |
| षष्ठी | ***दातुस्*** | ***दातॄणाम्*** |
| सप्तमी | ***दातरि*** | दातृषु |

:::

См. Thumb-Hauschild I,2 стр. 76 -81 для объяснения нерегулярных образований.

Женский род:

::: indent
**स्वसृ** f. склоняется как **दातृ**, за исключением винительного падежа (**द्वितीया**) множественного числа: ***स्वसॄस्***.
:::

### 42.1.2. Образование существительных: कृत्-суффикс -तृ

::: grammar-box
С помощью очень часто встречающегося कृत्-суффикса -तृ образуются имена агенса (обозначения для कर्तृ) почти от каждого корня или каузативной основы.

**Образование:**

*   **основа высокой степени + -tṛ**

или

*   **основа высокой степени / каузативная основа + i + tṛ**
:::

Примеры:

::: indent
**कर्तृ** м.р. "Творец"

**जेतृ** м.р. "Победитель"

**धातृ** м.р. "Создатель"

**रक्षितृ** м.р. "Защитник"

**बोधयितृ** м.р. "Пробуждающий"
:::

::: media
![lekt4201.jpg](/images/lekt4201.jpg)
Рис.: अयं बोधयिता
(Источник изображения: [Подробности](/ru/licenses#lekt4201))
:::

::: grammar-box
Редко встречающиеся средние роды на -तृ имеют частично собственное склонение (см. Киельгорн, Грамматика § 148).

Женский род от основ на -तृ оканчивается на **-त्री** (как **देवी**).

напр. **कर्त्री** ж.р. "Творец" (жен.)
:::

### 42.1.3. Родственные названия с усиленной ступенью в сильной основе

::: grammar-box
К ним относятся следующие обозначения родства:

*   **पितृ** м. "Отец"
*   **मातृ** ж. "Мать"
*   **दुहितृ** ж. "Дочь"
*   **भ्रातृ** м. "Брат"
*   **देवृ** м. "Брат мужа (швагер жены)"
*   **यातृ** ж. "Жена брата мужа"
*   **ननान्दृ** ж. "Сестра мужа (швагера жены)"

**Образование:**

*   **сильная основа: -ar**
*   **слабая основа**
    *   **перед гласным: -r**
    *   **перед согласным: -ṛ**
:::

Примеры:

::: indent
**पितृ** м. "Отец"

**मातृ** ж. "Мать"
:::

::: grammar-box

| | पुंस् (एकवचनम्) | पुंस् (बहुवचनम्) | स्त्री (एकवचनम्) | स्त्री (बहुवचनम्) |
| :--- | :--- | :--- | :--- | :--- |
| प्रथमा | पिता | ***पितरस्*** | माता | ***मातरस्*** |
| द्वितीया | ***पितरम्*** | पितॄन् | ***मातरम्*** | मातॄस् |
| Остальное как दातृ | ← | ← | ← | ← |

:::

### 42.1.4. Основа на -ṛ в составе сложных слов

::: grammar-box
В качестве первого компонента (впередлежащего элемента) сложных слов существительные на -ṛ стоят, разумеется, в своей слабой основе, т.е.

*   **перед согласным: -ṛ**
*   **перед гласным: -r**
:::

भर्तृ м. (от भृ «нести, поддерживать»): хранитель, прокормитель, супруг

भार्या ж.р., जाया ж.р. पत्नी ж.р.: супруга (भार्या = герундив от भृ : та, которую следует носить, та, которую следует поддерживать, имеющая право на содержание)

पितृ м.: отец

पितृ м. мн. ч.: умершие мужские предки, т.е.

1.  отец, дед, прадед
2.  предки человечества

В отношении тех и других совершаются ритуалы, так называемые श्राद्ध ср. Ежедневно трем мужским предкам (по отцовской и по материнской линии) приносят воду и в определенные дни рисовые или мучные шарики (पिण्ड м. «шарики»). Таким образом предки получают пищу. Совершение этой церемонии является одной из причин, почему мужчина должен зачать сына. Те, кто связан этим даром पिण्ड, называются सपिण्ड (с которыми у них есть पिण्ड). सपिण्ड охватывает шесть поколений: три назад (до прадеда) и три вперед (до правнука).
