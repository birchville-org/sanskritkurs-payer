# Урок 19

## 19.1. Относительное придаточное предложение

::: grammar-box

**Схема:**


**Относительное местоимение -- относительное придаточное предложение, содержащее существительное, к которому относится это придаточное -- (указательное местоимение) -- главное предложение**

**Относительное придаточное предложение может стоять после главного, но его нельзя вставлять внутрь главного предложения.**

**Относительное местоимение и определяемое слово, которое (в отличие от немецкого языка) находится в относительном придаточном предложении, стоят в том падеже, который синтаксически требует относительное придаточное предложение. Указательное местоимение стоит в том падеже, который синтаксически требует главное предложение.**
:::

Примеры:

Примечание: В относительных предложениях общего характера часто используется сослагательное наклонение (optativ) вместо изъявительного. Поэтому многие из наших примеров предпочтительно было бы построить с использованием сослагательного наклонения.

**1. Субъект (⟪कर्तृ⟫) предложения уточняется с помощью относительного придаточного:**

::: indent
⟪यो नरः पुण्यं करोति स स्वर्गं गच्छति⟫ =  ⟪यो नरः पुण्यं करोति तेन स्वर्गं गम्यते⟫ = ⟪येन नरेण पुण्यम् क्रियते तेन स्वर्गं गम्यते⟫ и т.д. = "Человек, совершающий благие дела, попадает на небо."
:::
**2. Прямое дополнение (⟪कर्म⟫) главного предложения уточняется с помощью относительного придаточного:**

::: indent
⟪यो ब्राह्मणो देवान्यजते तं देवा रक्षन्ति⟫ = "Богие защищают брахмана, который приносит им жертву в качестве хозяина жертвоприношения."
:::
**Уточняющее определение существительного главного предложения находится в относительном придаточном:**

::: indent
⟪ये नराः पापं कुर्वन्ति तेषां पुत्रा धनं न लभन्ते⟫ = "Сыновья людей, совершающих злодеяния, не получают богатства."
:::
**4. Относительное местоимение и определяемое слово стоят в родительном падеже (⟪षष्ठी⟫):**

::: indent
⟪यस्य नरस्य पुत्राः पापं कुर्वन्ति स न सुखवान्⟫ = "Не счастлив тот человек, чьи сыновья совершают зло."
:::
**5. Относительное местоимение и определяемое слово стоят в творительном падеже (⟪तृतीया⟫):**

::: indent
⟪येन शत्रुणा ग्रामो जितस्तं द्विषन्ति⟫ = "Они ненавидят врага, который победил / захватил их деревню."
:::
**6. Относительное местоимение и определяемое слово стоят в винительном падеже (⟪द्वितीया⟫):**

::: indent
⟪यं नरं देवी रक्षति स सुखमाप्नोति⟫ = "Человек, которого защищает богиня, обретает счастье."
:::
## 19.2. Относительное местоимение = ⟪व्यपेक्षकसर्वनाम⟫ ср. род

::: grammar-box

**⟪यद्⟫ "который, которая, которое" склоняется как ⟪तद्⟫, но с регулярным сандхи.**

| | **Мужской род** :br ⟪पुंस्⟫ | **Средний род** :br ⟪नपुंसक⟫ | **Женский род** :br ⟪स्त्री⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **Единственное число** :br ⟪एकवचन⟫ | **1. Именительный** :br ⟪प्रथमा⟫ | **yas** :br ⟪यस्⟫ | **yad** :br ⟪यद्⟫ | **yā** :br ⟪या⟫ |
| | **2. Винительный** :br ⟪द्वितीया⟫ | **yam** :br ⟪यम्⟫ | **yad** :br ⟪यद्⟫ | **yām** :br ⟪याम्⟫ |
| | **3. Творительный** :br ⟪तृतीया⟫ | **yena** :br ⟪येन⟫ | **yena** :br ⟪येन⟫ | **yayā** :br ⟪यया⟫ |
| | **6. Родительный** :br ⟪षष्ठी⟫ | **yasya** :br ⟪यस्य⟫ | **yasya** :br ⟪यस्य⟫ | **yasyās** :br ⟪यस्यास्⟫ |
| **Множественное число** :br ⟪बहुवचन⟫ | **1. Именительный** :br ⟪प्रथमा⟫ | **ye** :br ⟪ये⟫ | **yāni** :br ⟪यानि⟫ | **yās** :br ⟪यास्⟫ |
| | **2. Винительный** :br ⟪द्वितीया⟫ | **yān** :br ⟪यान्⟫ | **yāni** :br ⟪यानि⟫ | **yās** :br ⟪यास्⟫ |
| | **3. Творительный падеж** :br ⟪तृतीया⟫ | **yais** :br ⟪यैस्⟫ | **yais** :br ⟪यैस्⟫ | **yābhis** :br ⟪याभिस्⟫ |
| | **6. Родительный падеж** :br ⟪षष्ठी⟫ | **yeṣām** :br ⟪येषाम्⟫ | **yeṣām** :br ⟪येषाम्⟫ | **yāsām** :br ⟪यासाम्⟫ |

**В составе сложных слов корень ⟪यद्⟫ выступает в качестве первого компонента (с учётом правил сандхи).**

:::


## 19.3. Словарь

**⟪अर्थ⟫ m.:** цель, задача, значение (слова), богатство, имущество, состояние. ⟪अर्थम्⟫ (винительный падеж), ⟪अर्थेन⟫ (творительный падеж) с родительным падежом или в качестве второго компонента татпуруши: ради ..., для того чтобы.

⟪अर्थ⟫ является одним из трёх жизненных целей (⟪पुरुषार्थ⟫), как они описаны в светской и религиозной литературе:

::: indent
**⟪धर्म⟫ m.:** обретение заслуги через совершение того, что является должным, либо, по крайней мере, избегание зла, которое могло бы последовать из несоблюдения дхармы.

**⟪अर्थ⟫ m.:** целесообразное поведение, обретение благополучия.

**⟪काम⟫ m.:** чувственное наслаждение, в частности также в сексуальной сфере.

## 19.4. Упражнение

**Переведите на санскрит:**

1\. Жена вайшь, чей сын умер, плачет.

2\. Рама приносит жертву божеству, которое его охраняет.

3\. Поэт прославляет кшатрия, богатством которого он желает обладать.

4\. Огонь сжигает дом мужчины, который не почитал Агни жертвоприношением.

5\. Тигроподобный мужчина убивает кшатрий-воинов, которые победили Раму (страдательный залог).

## 19.5. ⟪सुभाषितानि⟩

**Переведите:**

::: indent
⟪येन येन च वातेन वारिदो वारि मुञ्चति । तेन तेन च वातेन छत्रं वहति पण्डितः ॥१॥⟫
:::
Пояснение: ⟪वारि⟩ Именительный, Винительный падежи ед. ч. от ⟪वारि⟩ ср.р.: вода

::: indent
⟪यो धर्ममर्थं कामं च यथाकालं निषेवते । धर्मार्थकामसंयोगं सो ऽमुत्रेह च विन्दति ॥२॥⟫
:::
Пояснение: ⟪यथाकालम्⟩ Авыайибхава-композиция: в своё время ; всегда, когда для этого имеется подходящий момент.

::: indent
⟪सा भार्या या प्रियं ब्रूते स पुत्रो यस्तु जीवति । स जीवति गुणो यस्य धर्मो यस्य स जीवति ॥३॥ यस्यार्थास्तस्य मित्राणि यस्यार्थास्तस्य बान्धवाः । यस्यार्थाः स पुमांल्लोके यस्यार्थाः स हि पण्डितः ॥४॥⟫
:::
