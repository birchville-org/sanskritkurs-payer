# Урок 19

## 19.1. Относительное предложение

::: grammar-box

**Схема:**

**Относительное местоимение -- относительное предложение, содержащее существительное, к которому относится относительное предложение -- (указательное местоимение) -- главное предложение**

**Относительное предложение может также стоять после главного предложения, но оно не может быть вставлено в главное предложение.**

**Относительное местоимение и слово связи, которое, в отличие от немецкого языка, стоит в относительном предложении, стоят в том падеже, который синтаксически требует относительное предложение. Указательное местоимение стоит в том падеже, который синтаксически требует главное предложение.**
:::

Примеры:

Примечание: В относительных предложениях общеизвестного содержания часто используется оптив вместо индикатива. Таким образом, многие из наших примеров предпочтительно были бы в оптиве.

**1. Агент (⟪कर्तृ⟫) предложения уточняется относительным предложением:**

::: indent
⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪स⟫ ⟪स्वर्गं⟫ ⟪गच्छति⟫ =  ⟪यो⟫ ⟪नरः⟫ ⟪पुण्यं⟫ ⟪करोति⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ = ⟪येन⟫ ⟪नरेण⟫ ⟪पुण्यम्⟫ ⟪क्रियते⟫ ⟪तेन⟫ ⟪स्वर्गं⟫ ⟪गम्यते⟫ и т.д. = "Мужчина, совершающий заслуживающие похвалы действия, попадает на небеса."
:::
**2. Прямой объект (⟪कर्म⟫) главного предложения уточняется относительным предложением:**

::: indent
⟪यो⟫ ⟪ब्राह्मणो⟫ ⟪देवान्यजते⟫ ⟪तं⟫ ⟪देवा⟫ ⟪रक्षन्ति⟫ = "Бог защищают брахмана, который приносит им жертву как хозяин жертвоприношения."
:::
**3. Уточнение существительного главного предложения стоит в относительном предложении:**

::: indent
⟪ये⟫ ⟪नराः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪तेषां⟫ ⟪पुत्रा⟫ ⟪धनं⟫ ⟪न⟫ ⟪लभन्ते⟫ = "Сыновья мужчин, совершающих зло, не получают богатства."
:::
**4. Относительное местоимение и слово связи стоят в генитиве (⟪षष्ठी⟫):**

::: indent
⟪यस्य⟫ ⟪नरस्य⟫ ⟪पुत्राः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪स⟫ ⟪न⟫ ⟪सुखवान्⟫ = "Не счастлив мужчина, чьи сыновья совершают зло."
:::
**5. Относительное местоимение и слово связи стоят в инструменталисе (⟪तृतीया⟫):**

::: indent
⟪येन⟫ ⟪शत्रुणा⟫ ⟪ग्रामो⟫ ⟪जितस्तं⟫ ⟪द्विषन्ति⟫ = "Они ненавидят врага, который победил / захватил их деревню."
:::
**6. Относительное местоимение и слово связи стоят в аккузативе (⟪द्वितीया⟫):**

::: indent
⟪यं⟫ ⟪नरं⟫ ⟪देवी⟫ ⟪रक्षति⟫ ⟪स⟫ ⟪सुखमाप्नोति⟫ = "Мужчина, которого защищает богиня, обретает счастье."
:::
## 19.2. Относительное местоимение = ⟪व्यपेक्षकसर्वनाम⟫ ср. род.

::: grammar-box

**⟪यद्⟫ "который, которая, которое" склоняется как ⟪तद्⟫, но с правильным сандхи.**

| | | **Мужской род** :br ⟪पुंस्⟫ | **Средний род** :br ⟪नपुंसक⟫ | **Женский род** :br ⟪स्त्री⟫ |
| :--- | :--- | :--- | :--- | :--- |
| **Единственное число** :br ⟪एकवचन⟫ | **1. Именительный падеж** :br ⟪प्रथमा⟫ | **yas** :br ⟪यस्⟫ | **yad** :br ⟪यद्⟫ | **yā** :br ⟪या⟫ |
| | **2. Винительный падеж** :br ⟪द्वितीया⟫ | **yam** :br ⟪यम्⟫ | **yad** :br ⟪यद्⟫ | **yām** :br ⟪याम्⟫ |
| | **3. Творительный падеж** :br ⟪तृतीया⟫ | **yena** :br ⟪येन⟫ | **yena** :br ⟪येन⟫ | **yayā** :br ⟪यया⟫ |
| | **6. Родительный падеж** :br ⟪षष्ठी⟫ | **yasya** :br ⟪यस्य⟫ | **yasya** :br ⟪यस्य⟫ | **yasyās** :br ⟪यस्यास्⟫ |
| **Множественное число** :br ⟪बहुवचन⟫ | **1. Именительный падеж** :br ⟪प्रथमा⟫ | **ye** :br ⟪ये⟫ | **yāni** :br ⟪यानि⟫ | **yās** :br ⟪यास्⟫ |
| | **2. Винительный падеж** :br ⟪द्वितीया⟫ | **yān** :br ⟪यान्⟫ | **yāni** :br ⟪यानि⟫ | **yās** :br ⟪यास्⟫ |
| | **3. Творительный падеж** :br ⟪तृतीया⟫ | **yais** :br ⟪यैस्⟫ | **yais** :br ⟪यैस्⟫ | **yābhis** :br ⟪याभिस्⟫ |
| | **6. Родительный падеж** :br ⟪षष्ठी⟫ | **yeṣām** :br ⟪येषाम्⟫ | **yeṣām** :br ⟪येषाम्⟫ | **yāsām** :br ⟪यासाम्⟫ |

**В качестве первой части составных слов выступает основа ⟪यद्⟫ (с учётом сандхи).**

:::

## 19.3. Словарь

**⟪अर्थ⟫ м.р.:** цель, задача, значение (слова), богатство, имущество, состояние. ⟪अर्थम्⟫ (вин. п.), ⟪अर्थेन⟫ (твор. п.) с родительным падежом или в качестве второй части составного слова типа Татпурӯша: ради ..., для того чтобы.

⟪अर्थ⟫ является одним из трёх жизненных целей (⟪पुरुषार्थ⟫), как они описаны в светской и религиозной литературе:

::: indent
**⟪धर्म⟫ м.р.:** обретение заслуги через совершение того, что является праведным, либо, по меньшей мере, избегание зла, которое могло бы последовать из несоблюдения Дхармы

**⟪अर्थ⟫ м.р.:** целесообразное поведение, обретение благополучия

**⟪काम⟫ м.р.:** чувственное наслаждение, в особенности в сексуальной сфере

## 19.4. Упражнение

**Переведите на санскрит:**

1\. Вдова вайшьи, чей сын умер, плачет.

2\. Рама приносит жертву божеству, которое его охраняет.

3\. Поэт прославляет кшатрия, чье богатство он желает.

4\. Огонь сжигает дом мужчины, который не почитает Агни жертвоприношением.

5\. Муж, подобный тигру, убивает кшатриев-воинов, которые победили Раму (страдательный залог).
