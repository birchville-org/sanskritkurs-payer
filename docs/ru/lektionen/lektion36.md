## 36.2. Перифрастическое перфектное время (⟪अनुप्रयोगलिट्⟫)

::::grammar-box
Перифрастическое перфектное время (⟪अनुप्रयोगलिट्⟫) употребляется:

1. у производных спряжений (каузатив, десидератив, фрекватив, номинальные глаголы)
2. у корней, начинающихся с долгого гласного (кроме ā-), либо с гласного (кроме a-) перед двумя согласными
3. у некоторых других корней
::::::::grammar-box
**Образование:**

(слабый) Presentstemmen + -ām + соответствующая форма перфектного времени от ⟪कृ⟫, ⟪अस्⟫ или ⟪भू⟫

- Конечный гласный основы подвергается гуне перед -ām.
- ⟪अस्⟫ и ⟪भू⟫ также спрягаются в парасмайападе у глаголов атманепады.
::::
Перифрастический перфект, по всей видимости, возник из аккузатива отглагольного существительного на -ā. Этот аккузатив употребляется -- как и в других случаях -- адвербиально.

Примеры:

| Корень:br⟪धातु⟫ | 3. ед. ч. перф. пар. | 3. мн. ч. перф. пар. | 3. ед. ч. перф. ат. | 3. мн. ч. перф. ат. |
| :--- | :--- | :--- | :--- | :--- |
| **⟪ईक्ष्⟫** 1А | | | **⟪ईक्षां⟫ ⟪चक्रे⟫**:br**⟪ईक्षामास⟫**:br**⟪ईक्षां⟫ ⟪बभूव⟫** | **⟪ईक्षां⟫ ⟪चक्रिरे⟫**:br**⟪ईक्षामासुर्⟫**:br**⟪ईक्षां⟫ ⟪बभूवुर्⟫** |
| **⟪बन्ध्⟫**:brКаузатив: ⟪बन्धय⟫-:br"заставлять связывать" | **⟪बन्धयां⟫ ⟪चकार⟫**:br**⟪बन्धयामास⟫**:br**⟪बन्धयां⟫ ⟪बभूव⟫** | **⟪बन्धयां⟫ ⟪चक्रुर्⟫**:br**⟪बन्धयामासुर्⟫**:br**⟪बन्धयां⟫ ⟪बभूवुर्⟫** | | |
