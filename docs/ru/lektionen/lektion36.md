# Урок 36

## 36.1. Особые образования перфекта

::: grammar-box
1. Некоторые корни после слогов редупликации демонстрируют изменение начального звука корня.
:::

| :--- | :--- | :--- | :--- | :--- |
| ⟪जि⟫ 1P:brPerf. IIIa | ⟪जि⟫:sig[⟪गा⟫]⟪य⟫ | ⟪जि⟫:sig[⟪ग्यु⟫]⟪र्⟫:brji-gi + ur | | |
| ⟪चि⟫ 5U:brPerf. IIIa | ⟪चि⟫:sig[⟪का⟫]⟪य⟫:br ⟪चिचाय⟫ | ⟪चि⟫:sig[⟪क्यु⟫]⟪र्⟫:br ⟪चिच्युर्⟫ | ⟪चि⟫:sig[⟪क्ये⟫] :br ⟪चिच्ये⟫ | ⟪चि⟫:sig[⟪क्यि⟫]⟪रे⟫:br ⟪चिच्यिरे⟫ |

:::
::: grammar-box
| Корень:br⟪धातु⟫ | 3. л., ед.ч., перфект, действ. залога | 3. л., мн.ч., перфект, действ. залога |

## 36.2. Перифразический перфект (⟪अनुप्रयोगलिट्⟫)

::: grammar-box
Перифразический перфект (⟪अनुप्रयोगलिट्⟫) используется:

1. при производных спряжениях (каузатив, десидератив, фреквентатив, денеминативы)
2. при корнях, начинающихся с долгого гласного (кроме ā-), либо с гласным (кроме a-) перед двумя согласными
3. при некоторых других корнях
:::
::: grammar-box
**Образование:**

(слабый) Presentstem + -ām + соответствующая форма перфекта от ⟪कृ⟫, ⟪अस्⟫ или ⟪भू⟫

Окончательный гласный корня гунируется перед -ām.
⟪अस्⟫ и ⟪भू⟫ спрягаются также в парасмайападе для глаголов атманепада.
:::
Перифразический перфект, вероятно, возник из винительного падежа вербального существительного на -ā. Этот винительный падеж используется, как и часто бывает, в адвербиальном значении.

Примеры:

| Корень:br⟪धातु⟫ | 3. ед. ч. Перф. П. | 3. мн. ч. Перф. П. | 3. ед. ч. Перф. Ā. | 3. мн. ч. Перф. Ā. |
| :--- | :--- | :--- | :--- | :--- |
| ⟪ईक्ष्⟫ 1Ā | | | **⟪ईक्षां चक्रे⟫** :br ⟪ईक्षामास⟫ :br **⟪ईक्षां बभूव⟫** | **⟪ईक्षां चक्रिरे⟫** :br ⟪ईक्षामासुर्⟫ :br **⟪ईक्षां बभूवुर्⟫** |
| ⟪बन्ध्⟫ :brКаузатив: ⟪बन्धय⟫-:br"заставлять связывать" | **⟪बन्धयां चकार⟫** :br ⟪बन्धयामास⟫ :br **⟪बन्धयां बभूव⟫** | **⟪बन्धयां चक्रुर्⟫** :br ⟪बन्धयामासुर्⟫ :br **⟪बन्धयां बभूवुर्⟫** | | |




## 36.3. Перфект пассива

::: grammar-box
В перфекте для пассива используются формы атманепада. Однако предпочтительным является использование PPP (причастия прошедшего времени действительного залога). Конструкция в обоих случаях является конструкцией пассивных предложений:

:::
::: indent
⟪तेन पुण्यं चक्रे⟫ = ⟪तेन पुण्यं कृतम्⟫ = "Он совершил заслуженное дело"
:::
