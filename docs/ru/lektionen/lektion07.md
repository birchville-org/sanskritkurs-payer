## 7.1. Глагольное предложение с прямым дополнением

::: grammar-box
**Схема:**
**(Агент = kartṛ m. = कर्तृ) – прямое дополнение (karman n. = कर्मन्) – глагол**

напр.
- **rāmaḥ phalaṃ khādati** = रामः फलं खादति : «Рама ест (кушает) плод.»
- **brāhmaṇo devaṃ yajati** = ब्राह्मणो देवं यजति : «Брахман почитает бога жертвоприношением (за кого-то другого).»
:::

Если глагол стоит в парасмайпада или атманепада, то прямое дополнение (**karman** n. = कर्मन्) обычно стоит в **винительном падеже** (винительный падеж, dvitīyā f. = द्वितीया).

### 7.2.1. Винительный падеж единственного и множественного числа вопросительных и указательных местоимений

::: grammar-box
| | | Мужской род | Женский род | Средний род |
| :--- | :--- | :--- | :--- | :--- |
| **kim**[[br]]кто/что | ед.ч. | **kam**[[br]]कम् | **kām**[[br]]काम् | **kim**[[br]]किम् |
| | мн.ч. | **kān**[[br]]कान् | **kās**[[br]]कास् | **kāni**[[br]]कानि |
| **tad**[[br]]он/оно/то | ед.ч. | **tam**[[br]]तम् | **tām**[[br]]ताम् | **tad**[[br]]तद् |
| | мн.ч. | **tān**[[br]]तान् | **tās**[[br]]तास् | **tāni**[[br]]तानि |
| **etad**[[br]]этот здесь | ед.ч. | **etam / enam**[[br]]एतम् / एनम् | **etām / enām**[[br]]एताम् / एनाम् | **etad / enad**[[br]]एतद् / एनद् |
| | мн.ч. | **etān / enān**[[br]]एतान् / एनान् | **etās / enās**[[br]]एतास् / एनास् | **etāni / enāni**[[br]]एतानि / एनानि |
| **idam**[[br]]этот | ед.ч. | **imam / enam**[[br]]इमम् / एनम् | **imām / enām**[[br]]इमाम् / एनाम् | **idam / enad**[[br]]इदम् / एनद् |
| | мн.ч. | **imān / enān**[[br]]इमान् / एनान् | **imās / enās**[[br]]इमास् / एनास् | **imāni / enāni**[[br]]इमानि / एनानि |
:::

Формы **enam** (एनम्) и т.д. принадлежат к основе **enad** (एनद्), которая образует формы лишь в некоторых падежах. Они используются вместо форм **etad** и **idam**, когда обозначаемое ими лицо или предмет уже упоминалось в предыдущем контексте.
напр. **ayaṃ devaḥ, enaṃ yajante.** = अयं देवः | एनं यजन्ते || : «Он есть бог. Ему приносят жертву.»

### 7.2.2. Использование винительного падежа (второй падеж, dvitīyā f. = द्वितीया = "вторая окончание падежа")

::: grammar-box
Винительный падеж (dvitīyā f. = द्वितीया) обозначает:
1. В непассивном глагольном предложении: **прямой объект** (karman n. = कर्मन्) действия, выраженного глаголом:
   например,
   - **devaṃ yajati** = देवं यजति : "Он почитает бога жертвоприношением."
   - **phalam āpnoti** = फलमाप्नोति : "Он обретает плод (например, своих действий)."
2. При глаголах, выражающих движение, перемещение, ведение или подобное, винительный падеж обозначает цель движения:
   например,
   - **narakaṃ gacchati** = नरकं गच्छति : "Он идёт в ад."
:::

Другие использования винительного падежа будут рассмотрены позже.

## 7.3. Сандхи конечного -n

::: grammar-box
**Конечное -n:**

1. Перед звонкими палатальными и ретрофлексными спарша, а также перед **ś-** заменяется на назальную, соответствующую этим звукам:
   - **-n** перед **j-, jh-, ñ-, ś-** » **-ñ**
   - **-n** перед **ḍ-, ḍh-, ṇ-, ṣ-** » **-ṇ**
   напр. **kṣatriyān + jayati** » **kṣatriyāñ jayati** = क्षत्रियांञ्जयति : «Он побеждает кшатриев».
   Начальное **ś-** при этом обычно заменяется на **ch-**:
   **gurūn + śṛṇoti** » **gurūñ chṛṇoti** (вместе с gurūñ śṛṇoti) = गुरूञ्छृणोति (गुरूञ्शृणोति) : «Он слышит учителей». «Он прислушивается к учителям».

2. Перед начальным **l-** заменяется на **-l** с анунасакой (носимое l, в письме **ल्** с анунасакой **ँ**):
   напр. **paśūn + labhate** » पशूंल्लभते : «Он получает скот».

3. Перед глухими палатальными, ретрофлексными или дентальными заменяется на **анусвāру** + шипящий, соответствующий этим звукам:
   - **-n** перед **c-, ch-** » **-ṃś**
   - **-n** перед **ṭ-, ṭh-** » **-ṃṣ**
   - **-n** перед **t-, th-** » **-ṃs**
   напр. **devān + ca** » **devāṃś ca** = देवांश्च : «и боги (вин. п.)»
   **devān + tu** » **devāṃs tu** = देवांस्तु : «но боги (вин. п.)»

4. Кроме случаев после краткого гласного (см. далее), конечное **-n** во всех остальных случаях остаётся неизменным.
:::

## 7.4. Средний род (napuṃsaka n. = नपुंसक)

::: grammar-box
**В среднем роде формы именительного (prathamā) и винительного (dvitīyā) падежей идентичны.**
:::

### 7.4.1. Средний род основ на -a

::: grammar-box
- **Окончание именительного / винительного падежа единственного числа: -m**
  например, **phala** ср. р. = फल = "плод": им. / вин. ед. ч. **phalam** = फलम्
- **Окончание именительного / винительного падежа множественного числа: -āni**
  например, **phala** ср. р. = फल: им. / вин. мн. ч. **phalāni** = फलानि
:::

## 7.5. Атематические классы настоящего времени

5-я класс настоящего времени образует так называемую атематическую основу настоящего времени, т.е. основа настоящего времени оканчивается не на «тематический гласный» **-a**, как в тематических классах настоящего времени (1., 4., 6., 10. класс).

::: grammar-box
**Атематические классы настоящего времени имеют чередование основ, т.е. существуют две формы основы настоящего времени:**
1. **сильная основа**: высшая ступень (редко удлиненная)
2. **слабая основа**: низкая ступень

**Сильная основа стоит:**
- в изъявительном наклонении единственного числа Parasmaipada настоящего времени (laṭ) и имперфекта (laṅ)
- во всех лицах первого лица повелительного наклонения (loṭ) Parasmaipada и Ātmanepada
- в третьем лице единственного числа повелительного наклонения (loṭ) Parasmaipada

**Все остальные формы имеют слабую основу настоящего времени.**
:::

### 7.5.1. Первичные окончания 3-го лица мн. числа у атематических основ

::: grammar-box
**У атематических настоящих основ первичные окончания 3-го лица мн. числа имеют вид:**
- **Паразмапада: -anti**
- **Āтманепада: -ate**
:::

### 7.5.2. 5. класс настоящего времени (svādi = स्वादि = "su и т.д.")

::: grammar-box
- **Сильный корень**: (в основном) глубокая ступень корня (как указано) + **-no-**
- **Слабый корень**: (в основном) глубокая ступень корня (как указано) + **-nu-**

**Перед гласными окончаниями у корней, оканчивающихся на гласную, -nu- заменяется на -nv-, а у корней, оканчивающихся на согласную, перед гласными окончаниями -nu- заменяется на -nuv-.**
:::

**Примеры:**

| Корень[[br]]धातु | Сильный корень | Слабый корень | Перед гласной[[br]](слабый) |
| :--- | :--- | :--- | :--- |
| **āp**[[br]]5 P[[br]]आप्[[br]]"достигать" | **āp-no**[[br]](3.л.ед.ч. āpnoti = आप्नोति) | **āp-nu** | **āp-nuv**[[br]](3.л.мн.ч. āpnuvanti = आप्नुवन्ति) |
| **aś**[[br]]5 Ā[[br]]अश्[[br]]"достигать" | — | **aś-nu**[[br]](3.л.ед.ч. aśnute = अश्नुते) | **aś-nuv**[[br]](3.л.мн.ч. aśnuvate = अश्नुवते) |
| **su**[[br]]5 U[[br]]सु[[br]]"выжимать" | **su-no**[[br]](3.л.ед.ч. sunoti = सुनोति) | **su-nu**[[br]](3.л.ед.ч. sunute = सुनुते) | **su-nv**[[br]](3.л.мн.ч. sunvanti = सुन्वन्ति,[[br]]3.л.мн.ч. sunvate = सुन्वते) |
| **śru**[[br]]5 P[[br]]श्रु[[br]]"слышать" | **śṛ-ṇo**[[br]](3.л.ед.ч. śṛṇoti = शृणोति) | **śṛ-ṇu** | **śṛ-ṇv**[[br]](3.л.мн.ч. śṛṇvanti = शृण्वन्ति) |

## 7.6. Список слов

**Выучите следующие слова:**

- **aś** 5 Ā (aśnute) अश् अश्नुते : достигать, добираться до, обретать
- **āp** 5 P (āpnoti) आप् आप्नोति : достигать, обретать
- **kup** 4 P (kupyati) कुप् कुप्यति : гневаться
- **krudh** 4 P (krudhyati) क्रुध् क्रुध्यति : гневаться
- **khād** 1 P (khādati) खाद् खादति : жевать, есть
- **śru** 5 P (śṛṇoti !) श्रु शृणोति : слышать (что-л.: винительный падеж, кого-л.: родительный или винительный; о чём-л.: винительный; от кого-л.: родительный, аблятив, инструменталис)
- **su** 5 U (sunoti) सु सुनोति : отжимать
- **soma** m. सोम : напиток, получаемый отжимом; Сома; Луна (Из какого растения получали Сому, до сих пор является предметом споров).
::: media
![](/images/lekt0701.jpg)
Рис.: Было ли это ведийским растением сомы?: мухомор красный: *Amanita muscaria* (L.) Lam.
(Источник изображения: Википедия, лицензия GNU FDL)
:::
- **phala** n. फल : плод (также в переносном смысле: (кармический) плод деяния)
- **nṛtya** n. नृत्य : танец
- **svarga** m. स्वर्ग : небо
- **naraka** m. नरक : ад (согласно одному из индуистских представлений, вселенная имеет форму яйца (**Brahmāṇḍa** m.n. = ब्रह्माण्ड = "Яйцо Брахмы"): над землёй находятся шесть небес с возрастающим блаженством, под землёй расположены семь так называемых **pātāla** n. = पाताल, обиталищ **nāga** m. = नाग (змей) и других мифических существ, там же находятся 7 адов с возрастающими муками)
- **aṅga** n. अङ्ग : часть тела, составная часть; также = **vedāṅga** = वेदाङ्ग
- **gam** 1 P (gacchati) गम् गच्छति : идти (Согласно местной классификации глаголов относится к 1-му классу настоящего времени, но на самом деле является образованием с суффиксом образования основы настоящего времени **-ccha-**: **gam** » глубокая ступень (**gm** ») **ga-ccha-ti**)
