# Урок 14

## 14.1. Выражение отношения между обозначаемыми существительными: родительный падеж (ṣaṣṭhī f. = ⟪षष्टी⟫ = шестое окончание падежа)

::: grammar-box
Если необходимо выразить отношение между двумя обозначаемыми существительными, используется родительный падеж (ṣaṣṭhī f. "шестое окончание падежа"). Родительный падеж отличается от всех остальных тем, что — за исключением нескольких случаев — он служит не для уточнения действия, выраженного глаголом, а для выражения отношения между лицами или предметами, обозначаемыми существительными. Часто родительный падеж отвечает на вопрос: Чей?
:::
Примеры:

⟪कवेः पुत्रः⟫ "Сын поэта"

⟪धनस्य लोभः⟫ "Жажда богатства"

⟪नगरस्यार्धम्⟫ "Половина города"

⟪रामस्य कृतम्⟫ "Дело / Подвиг Рамы"

::: grammar-box
Обычный порядок слов:

> **Определяющее слово в родительном падеже — Определяемое существительное в другом падеже**
:::
**Родительный падеж и причастие прошедшего времени (PPP):**

::: grammar-box
При использовании причастий прошедшего времени (PPP) родительный падеж может заменять творительный падеж (tṛtīyā) для обозначения агенса (kartṛ); в конструкции с творительным падежем PPP рассматривается как пассивная глагольная форма (стоящее в творительном падеже обозначает агенса), а в конструкции с родительным падежом PPP рассматривается как существительное или прилагательное (таким образом, стоящее в родительном падеже не является агентом).

Согласно Панини 2.3.67, при использовании причастия прошедшего времени (PPP) родительный падеж применяется, если PPP имеет настоящее время значения (см. выше), а творительный падеж — еслиPPP имеет значение прошедшего времени:

> ⟪रामस्येष्टं फलम्⟫ "Желаемая Рамой награда = Награда, которую Рāма желает в данный момент"
> 
> ⟪रामेणेष्टं फलम्⟫ "Награда, которую Рāма желал"

Очевидно, что при использовании среднего рода единственного числа причастия прошедшего времени (PPP) в качестве вербального абстракта — то есть существительного, — используется родительный падеж.
:::
## 14.2. Образование форм родительного падежа (ṣaṣṭhī f. = ⟪षष्ठी⟫)

Родительный падеж у вербальных основ с чередованием гласных образуется от слабой основы.

**Родительный падеж основ, оканчивающихся на согласную:**

::: grammar-box

После согласных регулярные окончания родительного падежа:
* Единственное число: **-as**
* Множественное число: **-ām**

:::
::: center

| Именная основа | Слабая основа | Родительный падеж ед. ч. | Родительный падеж мн. ч. |
| :--- | :--- | :--- | :--- |
| **guṇa-vant-** :br ⟪गुणवन्त्⟫ | **guṇa-vat-** :br ⟪गुणवत्⟫ | **guṇa-vat-as** :br ⟪गुणवतस्⟫ | **guṇa-vat-ām** :br ⟪गुणवताम्⟫ |
| **paśu-mant-** :br ⟪पशुमन्त्⟫ | **paśu-mat-** :br ⟪पशुमत्⟫ | **paśu-mat-as** :br ⟪पशुमतस्⟫ | **paśu-mat-ām** :br ⟪पशुमताम्⟫ |

:::
**Родительный падеж основ, оканчивающихся на гласную, за исключением односложных корневых существительных и основ, оканчивающихся на дифтонг:**

**Множественное число:**

::: grammar-box

Родительный падеж множественного числа основ, оканчивающихся на гласную, образуется следующим образом:

> **-долгий гласный основы + -nām**

:::
::: center

| Именная основа | Родительный падеж мн. ч. |
| :--- | :--- |
| **deva** m.:br ⟪देव⟫ | **devā-nām** :br ⟪देवानाम्⟫ |
| **phala** n.:br ⟪फल⟫ | **phalā-nām** :br ⟪फलानाम्⟫ |
| **devatā** f.:br ⟪देवता⟫ | **devatā-nām** :br ⟪देवतानाम्⟫ |
| **kavi** m.:br ⟪कवि⟫ | **kavī-nām** :br ⟪कवीनाम्⟫ |
| **śruti** ж.р.:ед. ⟪श्रुति⟫ | **śrutī-nām** :ед. ⟪श्रुतीनाम्⟫ |
| **devī** ж.р.:ед. ⟪देवी⟫ | **devī-nām** :ед. ⟪देवीनाम्⟫ |
| **paśu** м.р.:ед. ⟪पशु⟫ | **paśū-nām** :ед. ⟪पशूनाम्⟫ |
| **dhenu** ж.р.:ед. ⟪धेनु⟫ | **dhenū-nām** :ед. ⟪धेनूनाम्⟫ |

:::
**Родительный падеж единственного числа основ, оканчивающихся на гласную:**

::: grammar-box

Родительный падеж единственного числа основ, оканчивающихся на гласную, образуется нерегулярно и его следует выучить наизусть.

:::
::: center

| Основа | Родительный падеж ед.ч. |
| :--- | :--- |
| **deva** м.р.:ед. ⟪देव⟫ | **devasya** :ед. ⟪देवस्य⟫ |
| **phala** ср.р.:ед. ⟪फल⟫ | **phalasya** :ед. ⟪फलस्य⟫ |
| **devatā** ж.р.:ед. ⟪देवता⟫ | **devatāyās** :ед. ⟪देवतायास्⟫ |
| **kavi** м.р.:ед. ⟪कवि⟫ | **kaves** :ед. ⟪कवेस्⟫ |
| **paśu** м.р.:ед. ⟪पशु⟫ | **paśos** :ед. ⟪पशोस्⟫ |
| **devī** ж.р.:ед. ⟪देवी⟫ | **devyās** :ед. ⟪देव्यास्⟫ |
| **śruti** ж.р.:ед. ⟪श्रुति⟫ | **śrutes / śrutyās** :ед. **⟪श्रुतेस्⟫ / ⟪श्रुत्यास्⟫** :ед.(т.е. либо как kavi, либо как devī) |
| **dhenu** ж.р.:ед. ⟪धेनु⟫ | **dhenos / dhenvās** :ед. **⟪धेनोस्⟫ / ⟪धेन्वास्⟫** :ед.(т.е. либо как paśu, либо как многосложные женского рода на -ū) |

:::

::: center

| | | kim | tad | etad | idam |

| **Женский род** | **Родительный падеж ед.ч.** | kasyās:ед. ⟪कस्यास्⟫ | tasyās:ед. ⟪तस्यास्⟫ | etasyās:ед. ⟪एतस्यास्⟫ | asyās:ед. ⟪अस्यास्⟫ |
| | **Родительный падеж, множественное число** | kāsām:br ⟪कासाम्⟫ | tāsām:br ⟪तासाम्⟫ | etāsām:br ⟪एतासाम्⟫ | āsām:br ⟪आसाम्⟫ |

:::
**Совпадение форм:**

::: important

У всех именных основ, за исключением мужского и среднего рода на -a, а также местоимений, форма родительного падежа единственного числа совпадает с формой аблятива (pañcamī «пятый случай») единственного числа!

Обратите внимание, что у основ на согласные аблятив и родительный падеж единственного числа звучат так же, как винительный падеж множественного числа мужского и женского рода!

:::
## 14.3. Дополнительно о употребительности родительного падежа (⟪षष्ठी⟫)

::: grammar-box
Вопреки вышеизложенному основному правилу, родительный падеж используется для выражения объекта некоторых глаголов, например, у глаголов памяти:

> ⟪देवानां स्मरति⟫ "Он вспоминает о богах"

Однако у всех этих глаголов объект может стоять и в винительном падеже:

> ⟪देवान्स्मरति⟫ "Он вспоминает о богах"

:::
