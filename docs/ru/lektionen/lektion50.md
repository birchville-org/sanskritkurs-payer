# Урок 50

## 50.1. Образование существительных: регулярная степень сравнения

::: grammar-box
**Регулярная степень сравнения в санскрите образуется с помощью суффиксов ⟪तद्धित⟫**
* **-⟪तर⟫ (жен. род: ⟪तरा⟫) в "компаративе"**
* **⟪तम⟫ (жен. род: ⟪तमा⟫) в "суперлативе"**

**Эти суффиксы присоединяются к основе мужского рода прилагательных. При существительных с чередованием основ они присоединяются к слабой основе, которая имеет форму перед окончанием -su локатива (⟪पञ्चमी⟩) множественного числа.**
:::
::: media
![](/images/lekt5007.webp)
Рис.: ⟪लोकस्योत्तमो गिरिः सगरमाथा⟫ = ཇོ་མོ་གླང་མ _=_ 珠穆朗玛峰 = Mount Everest
(Источник изображения: [Details](/ru/licenses#lekt5007))
:::

::: grammar-box
**Значение:**

**"Компаратив" означает, если не выражено сравниваемое лицо/предмет: "довольно, очень, слишком":**

:::
::: indent
напр. ⟪सुचितर⟫ 3 "довольно чистый", "очень чистый", "слишком чистый"
:::
**Если выражено сравниваемое лицо/предмет, то оно стоит в аблативе (⟪पञ्चमी⟩). Компаратив + аблатив соответствует степени сравнения с "чем" в немецком языке.**

::: indent
напр. ⟪देवदत्ताद्रामो धीमत्तरः⟫ = досл.: "с точки зрения Деводатты Рама более разумный" = "Рама более разумен, чем Деводатта"
:::
**"Суперлатив" означает, если не выражено сравниваемое лицо/предмет: "крайне, очень":**

::: indent
напр. ⟪सत्तम⟫ 3 (от ⟪सन्त्⟫) "крайне хороший, очень хороший"
:::
**Если выражено сравниваемое лицо/предмет, то оно стоит в генитиве (⟪षष्ठी⟩) ("из", "среди"), и суперлатив соответствует немецкому суперлативу (превосходная степень):**

::: indent
напр. ⟪द्विजानां सत्तमः⟫ = "лучший из дваждырожденных"
:::
**Суффиксы -⟪तर⟫ и -⟪तम⟫ могут присоединяться не только к прилагательным, но и к существительным, неизменяемым словам и даже глагольным формам:**

Примеры:

::: indent
⟪गजतम⟫ м.р. "лучший слон" (⟪गज⟫) (также название Будды)

⟪गोतम⟫ м.р. "наибольший бык" (⟪गो⟫) или: "наиболее богатый коровами"

⟪उद्⟫ неизм. "на", "вверх" » ⟪उत्तर⟫ 3 "более высокий" » ⟪उत्तम⟫ 3 "наивысший"
:::
**Если эти суффиксы присоединяются к глагольной форме, они всегда появляются в наречной форме:**

* **-⟪तराम्⟫**
* **-⟪तमाम्⟫**

Примеры:

::: indent
⟪पचतितराम्⟫ "он/она/оно готовит лучше"

⟪पचतितमाम्⟫ "он/она/оно готовит лучше всех"
:::
**Такую же форму имеют эти суффиксы, когда они присоединяются к неизменяемым словам и производное слово используется в наречном значении:**

::: indent
например, ⟪सुतराम्⟫ (от ⟪सु⟫) "более хорошим образом" (наречное употребление)
:::
::: media
![](/images/lekt5006.webp)
Рис.: ⟪का पचतितमाम्⟫
Лису = 傈僳族, ⟪अरुणाचल प्रदेश⟫
(Источник изображения: [Подробности](/ru/licenses#lekt5006))
:::
