# Урок 55

| ⟪२⟫. | **⟪बुबोध⟫** | *:sig[⟪बुध्⟫]* 1U: 1. 3. ед. ч. Пр. вр. Сосл. накл. (я пробудился / он пробудился) | **⟪अबुधम्⟫ / ⟪अबुधत्⟫** |
