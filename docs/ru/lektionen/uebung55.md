# Урок 55

Определите и переведите следующие формы, а также образуйте соответствующие формы **a-аориста**:

:::grammar-box
| № | Форма | Определение / Значение | a-аорист |
|:---|:---|:---|:---|
| १. | **दोक्ष्यन्ति** | *दुष्* 4P: 3. мн. ч. Буд. вр. Сосл. накл. (они погибнут) | **अदुषन्** |
| २. | **बुबोध** | *बुध्* 1U: 1. 3. ед. ч. Пр. вр. Сосл. накл. (я пробудился / он пробудился) | **अबुधम् / अबुधत्** |
| ३. | **क्रुध्यसि** | *क्रुध्* 4P: 2. ед. ч. Изъяв. накл. Наст. вр. Сосл. накл. (ты гневишься) | **अक्रुधः** |
| ४. | **तोक्ष्यथ** | *तुष्* 4P: 2. мн. ч. Буд. вр. Сосл. накл. (вы будете довольны) | **अतुषत** |
| ५. | **कुप्यामः** | *कुप्* 4P: 1. мн. ч. Изъяв. накл. Наст. вр. Сосл. накл. (мы гневимся) | **अकुपाम** |
| ६. | **आप** | *आप्* 5P: 1. 3. ед. ч. 2. мн. ч. Пр. вр. Сосл. накл. (я / он / они достигли) | **आपम् / आपत् / आपत** |
| ७. | **जग्मुः** | *गम्* 1P: 3. мн. ч. Пр. вр. Сосл. накл. (они пошли) | **अगमन्** |
| ८. | **छेत्स्यसि** | *छिद्* 7U: 2. ед. ч. Буд. вр. Сосл. накл. (ты отрежешь) | **अच्छिदः** |
| ९. | **पश्यथ** | *दृश्* 4P: 2. мн. ч. Изъяв. накл. Наст. вр. Сосл. накл. (вы видите) | **अदर्शत** |
| १०. | **ध्रोक्ष्यामि** | *द्रुह्* 4P: 1. ед. ч. Буд. вр. Сосл. накл. (я причиню вред) | **अद्रुहम्** |

| १२. | **भिन्त्थ** | *भिद्* 7U: 2. мн. ч. Изъяв. накл. Наст. вр. Сосл. накл. (вы раскалываете) | **अभिदत** |
| १३. | **भ्राम्यामः** | *भ्रम्* 4P: 1. мн. ч. Изъяв. накл. Наст. вр. Сосл. накл. (мы блуждаем) | **अभ्रमाम** |
| १४. | **मुञ्चति** | *मुच्* 6U: 3. ед. ч. Изъяв. накл. Наст. вр. Сосл. накл. (он отпускает) | **अमुचत्** |
| १५. | **मुह्यसि** | *मुह्* 4P: 2. ед. ч. Изъяв. накл. Наст. вр. Сосл. накл. (ты блуждаешь) | **अमुहः** |
| १६. | **अरोदीत्** | *रुद्* 2P: 3. ед. ч. Несош. вр. Сосл. накл. (он плакал) | **अरुदत्** |
| १७. | **रुरोधिथ** | *रुध्* 7U: 2. ед. ч. Пр. вр. Сосл. накл. (ты остановился) | **अरुधः** |
| १८. | **श्राम्यन्ति** | *श्रम्* 4P: 3. мн. ч. Изъяв. накл. Наст. вр. Сосл. накл. (они трудятся) | **अश्रमन्** |
| १९. | **विन्दथ** | *विद्* 6U: 2. мн. ч. Изъяв. накл. Наст. вр. Сосл. накл. (вы находите) | **अविदत** |
| २०. | **असीदन्** | *सद्* 1P: 3. мн. ч. Несош. вр. Сосл. накл. (они сидели) | **असदन्** |

| २२. | **अशात्** | *शास्* 2P: 3. ед. ч. Несош. вр. Сосл. накл. (он приказал) | **अशिषत्** |
| २३. | **सेक्ष्यसे** | *शिच्* 6U: 2. ед. ч. Буд. вр. Ā. (ты окропишь) | **असिचथाः** |
| २४. | **अयुनक्** | *युज्* 7U: 2. 3. ед. ч. Несош. вр. Сосл. накл. (ты запряг / он запряг) | **अयुजः / अयुजत्** |
| २५. | **आरिथ** | *ऋ* 3P: 2. ед. ч. Пр. вр. Сосл. накл. (ты пошел) | **आरः** |
| २६. | **अक्लिद्यन्** | *क्लिद्* 4P: 3. мн. ч. Несош. вр. Сосл. накл. (они стали влажными) | **अक्लिदन्** |

| ३२. | **सिष्णेह** | *स्निह्* 4P: 1. 3. ед. ч. Пр. вр. Сосл. накл. (я любил / он любил) | **अस्निहम् / अस्निहत्** |
