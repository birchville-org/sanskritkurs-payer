# Offline-Nutzung (PWA)

Der Payer Sanskritkurs kann als **Progressive Web App (PWA)** auf Ihrem Gerät installiert werden. Dadurch haben Sie die Möglichkeit, den gesamten Kurs auch ohne aktive Internetverbindung zu nutzen – ideal zum Lernen unterwegs.

## Installation

### Auf dem Desktop (PC / Mac)
1. Öffnen Sie diese Website in einem modernen Browser (z. B. Google Chrome oder Microsoft Edge).
2. Klicken Sie auf das kleine **Installieren-Symbol** rechts in der Adresszeile oder im Browsermenü. Alternativ finden Sie auf der Startseite häufig einen Button "App installieren".
3. Bestätigen Sie die Installation. Die App wird nun als eigenständiges Programm auf Ihrem Computer abgelegt.

### Auf dem Smartphone / Tablet
- **iOS (iPhone/iPad)**: Öffnen Sie die Seite in Safari, tippen Sie auf den "Teilen"-Button und wählen Sie **"Zum Home-Bildschirm"**.
- **Android**: Öffnen Sie die Seite in Chrome. Häufig erscheint unten ein Banner "Sanskritkurs zum Startbildschirm hinzufügen". Falls nicht, öffnen Sie das Menü (drei Punkte) und wählen Sie **"App installieren"**.

## Offline arbeiten

Sobald die App installiert ist und Sie die Seite mindestens einmal aufgerufen haben, werden die wichtigsten Dateien auf Ihrem Gerät gespeichert (gecacht).

**Sprachen und Inhalte:**
Standardmäßig lädt die App die Inhalte in bestimmten Sprachen (z. B. Deutsch, Englisch) in den Offline-Speicher herunter. 
Wenn Sie eine neue Sprache hinzufügen möchten, benötigen Sie **kurzzeitig eine Internetverbindung**. Gehen Sie in der linken Seitenleiste auf **"Einstellungen" (Settings)** und wählen Sie die gewünschte Sprache aus. Die App wird im Hintergrund die notwendigen Inhalte herunterladen. 

Während dieses Synchronisationsvorgangs sehen Sie einen kleinen Banner am oberen Bildschirmrand. Sobald dieser verschwindet, ist die neue Sprache offline verfügbar.

## Speicherplatz freigeben

Die App speichert Textinhalte und Bilder effizient. Wenn Sie dennoch den Speicherplatz freigeben möchten, gehen Sie wie folgt vor:
1. Öffnen Sie die **Einstellungen**.
2. Dort finden Sie eine Anzeige zum aktuellen Speicherverbrauch.
3. Über den Button **"Cache leeren"** können Sie die lokal gespeicherten Inhalte entfernen. Um die App danach offline zu nutzen, müssen Sie die gewünschten Sprachen erneut auswählen.
