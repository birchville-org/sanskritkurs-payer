# ክፍሊ 54

## 54.1. ቅድመ-ማስታወሻ

በክፍሊ 54 የዩኒቨርስቲ ትምህርት ሁለተኛውን ክፍል ያስጀምራል። ከዚያን ጊዜ ጀምሮ ትምህርቱ ከዚህ ክፍል ዋና ጉዳይ በተለየ መንገድ ይከናወናል፡ የባሃጋድጊታ ሙሉ ቅርፅን መጽሐፍ ማንበብ ነው። የትምህርት ዓላማ በመካከለኛ ክብደት ያላቸው ጽሑፎችን በማንበብ ያለመ ነጻነት ማሳደር ሲሆን በክፍሉ መጨረሻ ላይ የባሃጋድጊታ ብዙ ክፍሎች በተለየ መንገድ ሊተርጉሙ ይችላሉ። በመጀመሪያው ጊዜ የቃል ዝርዝሮች በዩኒቨርስቲ ትምህርት ይሰጡ ነበር፣ በኋላ ላይ ተማሪዎች የራሳቸውን መጽሐፍት (Monier-Williams, Apte, PW) መጠቀም አለባቸው።

የባሃጋድጊታ ትምህርት በአሁኑ ጊዜ ከመስመር ውጭ አይቀርብም።

የሳንስክሪት ትምህርቶች ስለ ሳንስክሪት ቋንቋ ያልተጠቀሱ ርዕሰ ቁም ነገሮች ያካትታሉ።

## 54.5. የአኦሪስት (⟪लुङ्⟫) የአሠራር ዓይነቶች

::: grammar-box

**ለሁሉም የአኦሪስት (⟪लुङ्⟫) የአሠራር ዓይነቶች የጋራ የሆነው የa- ቅጥያ ነው፤ ይህ ቅጥያ እንደ ኢምፐርፌክት (⟪लङ्⟫) ተመሳሳይ ሕጎች መሠረት ይቀድማል።**

እም ኣኦሪስት እም ሳንስክሪት ጥራይ እም ኢንዲካቲቭ ወ-ፕረካቲቭ ይትረከብ።

:::

::: grammar-box

**እሉ እሉ ኣይነት ኣኦሪስት (⟪ሉङ्⟫) ኣለዉ፦**

1.  ዘይሲቢላንታዊ (ኣሲግማዊ) ኣኦሪስት፦
    *   54.1. ስርወ-ኣኦሪስት፦ ኣውግመንት + ስርው + ካልኣዊ ፍጻሜ
    *   54.2. ቴማዊ ኣኦሪስት፦ ኣውግመንት + ስርው + **a** + ካልኣዊ ፍጻሜ
    *   54.3. ድግግማዊ ኣኦሪስት፦ ኣውግመንት + **ድግግማዊ** ስርው + **a** + ካልኣዊ ፍጻሜ
2.  ሲቢላንታዊ (ሲግማዊ) ኣኦሪስት፦ s ወይ ሓደ ሲላብ ዝሓዘ s (ṣ) ቅድሚ ግላዊ ፍጻሜ ይመጽእ
    *   54.4. -s-ኣኦሪስት፦ ኣውግመንት + ስርው + **s** + ካልኣዊ ፍጻሜ
    *   54.5. -iṣ-ኣኦሪስት፦ ኣውግመንት + ስርው + **i** + **ṣ** + ካልኣዊ ፍጻሜ
    *   54.6. -siṣ-ኣኦሪስት፦ ኣውግመንት + ስርው + **siṣ** + ካልኣዊ ፍጻሜ
    *   54.7. -sa-ኣኦሪስት፦ ኣውግመንት + ስርው + **s** + **a** + ካልኣዊ ፍጻሜ

ስርዓተ-ግንባቢያት ንምክፍፋል ስርዓተ-ስራሕ ኣብ ዝምልከት ርአ

:::

### 54.6.1. ስርዓተ-ግንባቢያት ንምክፍፋል ስርዓተ-ስራሕ

ሓደ ካብ ዝተፈላለየ መልክዕ እዩ ዝፍጠር። ካብ ኩሉ ስርዓተ-ስራሕ ይፍጠር።

::: grammar-box

**ግንባቢያት:**

**ኣውጅመንት + ስርዓተ-ስራሕ + i**

**ስርዓተ-ስራሕ ከምዚ ይመስል፦**

ላዕለዋይ ደረጃ፦

*   ስርዓተ-ስራሕ ኣብ ቅድሚ ሓደ ኮንሶናንት ዘለዎም (ካብ a ወጻኢ) ከምኡውን ⟪जन्⟫ ከምኡውን መብዛሕትኦም ስርዓተ-ስራሕ ኣብ -am ዝውድእ
ኣብነት፦
⟪भिद्⟫ 7U: ⟪አበዲ⟫ "እዩ ተቖሪጹ"
⟪ቱድ⟫ 6U: ⟪አቶዲ⟫ "እዩ ተገላቢጡ"

ደረጃ ማዘናን:

*   ሥሮች ቀጣይነት ያለው የድምፅ መቁረጥ  
ምሳሌዎች:  
⟪नी⟫ 1U: ⟪अनायि⟫ "እንደተመራ"  
⟪स्तु⟫ 2U: ⟪अस्तावि⟫ "እንደተመሰገነ"  
⟪कृ⟫ 8U: ⟪अकारि⟫ "እንደተሠራ"  


*   ሥሮች ከአንድ ቀጣይነት ያለው ልክ ከሚቀጥል ቅድመ-አስተማምኖ (በውስጡ ⟪जन्⟫ እና ሥሮች በ-am የሚጠናቀቁ) ውጭ  
ምሳሌ:  
⟪वद्⟫ 1P: ⟪अवादि⟫ "እንደተባለ"  
ነገር ግን:  
⟪जन्⟫ 4Ā: ⟪अजनि⟫ "እንደተፈለቀ"  


*   አንዳንድ ሥሮች በ-am የሚጠናቀቁ  
ምሳሌ:  
⟪गम् अगामि⟫


በመካከል የy መጨመር ከመወሰን በፊት:

*   ሥሮች በ-ā, -e, -ai, -o የሚጠናቀቁ በ-ā ከሥር እና ከመወሰን መካከል y ይጨምራሉ:  
ምሳሌ:  
⟪दा⟫ 3U: ⟪अदायि⟫ "እንደተሠጠ"


የናስ-ኢንፊክስ:

*   አንዳንድ ሥሮች የናስ-ኢንፊክስ አላቸው:  
ምሳሌ:  
⟪लभ्⟫ 1Ā: ⟪अलम्भि⟫ ከ ⟪अलाभि⟫ ጋር : "እንደተቀበለ"


(ሌሎች የፓስቭ ቅርጾች በአዮሪስት ውስጥ በĀtmanepada-ቅርጾች ይወከላሉ).
