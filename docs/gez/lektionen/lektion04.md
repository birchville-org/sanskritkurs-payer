# ቀጥታ 4

## 4.1. ቀላል ማጠናከሪያ ጥያቄዎች (የቃል ጥያቄዎች) እና መልሶች

### 4.1.1. የጥያቄ ተካዮች እና የማሳየት ተካዮች

#### 4.1.1.1. የጥያቄ ተካዮች (praśnārthakasarvanāma n. = ⟪प्रश्नार्थकसर्वनामन्⟫)

::: grammar-box

| | ኖሚናቲቭ ሐዋስ | ኖሚናቲብ ብዙነት |
| :--- | :--- | :--- |
| **ኒውትረም** | **kim = ⟪किम्⟫** | **kāni = ⟪कानि⟫** |
| **ማስኩሊነም** | **kas = ⟪कस्⟫** | **ke = ⟪के⟫** |
| **ፌሚኒነም** | **kā = ⟪का⟫** | **kās = ⟪कास्⟫** |

:::

#### 4.1.1.2. የማሳየት ተካዮች (nidarśakasarvanāmāni n. = ⟪निदर्शकसर्वनामानि⟫)

::: grammar-box

| **ስታምፖች** ||||
| :--- | :---: | :---: | :---: |
| | **tad = ⟪तद्⟫:br"እሱ፣ እነርሱ፣ ይህ; ማለትም፣ እርሷ፣ ይህ":br(የተጠቀሰ)** | **etad = ⟪एतद्⟫:br"ይህ፣ ይህች፣ ይህ":br(ለደብተኛ በጣም ቀርቦ)** | **idam = ⟪इदम्⟫:br"ይህ፣ ይህች፣ ይህ":br(ቀርቦ)** |

| **ኒውትረም** | **tad = ⟪तद्⟫** | **etad = ⟪एतद्⟫** | **idam = ⟪इदम्⟫** |
| **ማስኩሊነም** | **sa, so saḥ = ⟪स सो सः⟫** | **eṣa, eṣo, eṣaḥ = ⟪एष एषो एषः⟫** | **ayam = ⟪अयम्⟫** |
| **ፌሚኒነም** | **sā = ⟪सा⟫** | **eṣā = ⟪एषा⟫** | **iyam = ⟪इयम्⟫** |
| **ኖሚናቲቭ ብዙነት** ||||
| **ኒውትረም** | **tāni = ⟪तानि⟫** | **etāni = ⟪एतानि⟫** | **imāni = ⟪इमानि⟫** |
| **ማስኩሊነም** | **te = ⟪ते⟫** | **ete = ⟪एते⟫** | **ime = ⟪इमे⟫** |
| **ፌሚኒነም** | **tās = ⟪तास्⟫** | **etās = ⟪एतास्⟫** | **imās ⟪इमास्⟫** |

:::

**ለኖሚ. ሐዋስ. ማስ.:**
**sa, eṣa** (⟪स एष⟫) ከሁሉም ድምፆች በስተቀር ረጅም **-a** ይመጣል
**so, eṣo** (⟪सो एषो⟫) ከ **-a** ጋር ይመጣል፣ ይህም በአቫግራሃ ተወግዷል (ተወግዶ)
**saḥ, eṣaḥ** (⟪सः एषः⟫) በፓውሳ (የደብተር መጨረሻ፣ የመስመር መጨረሻ) ብቻ ይመጣል

ከነዚህ ስሞች (sarvanāman n.) ጋር ዓረፍተ ነገሮችን ለመመስረት፣ የሚከተሉትን የሳንዲሂ ህጎች ማወቅ አስፈላጊ ነው፦

### 4.1.2. ሳንዲሂ የመጨረሻው -m

::: grammar-box

**የመጨረሻው -m ከነባቢዎች በፊት በአኑስቫራ (-ṃ) ይተካል። በአረፍተ ነገር ወይም በቁጥር መጨረሻ እና ከአናባቢዎች በፊት -m ሳይለወጥ ይቆያል።**

:::

### 4.1.3. ሳንዲሂ የመጨረሻው -e

::: grammar-box

1. **ከ a- በፊት -e ሳይለወጥ ይቆያል፦ መጀመሪያ ያለው a- በአቫግራሃ ይወገዳል፦**
ለምሳሌ፡- ete + agnayas » ete 'gnayaḥ = ⟪एते ऽग्नयः⟫ "እነዚህ እሳቶች"

2. **ከአጭር a- ውጪ ከሆኑ ሌሎች አናባቢዎች በፊት -e ብዙውን ጊዜ በ -a ከሂያተስ ጋር ይተካል። በ -ay መተካትም ይከሰታል፦**
ለምሳሌ፡- ime + īśvarās » ima īśvarāḥ = ⟪इम ईश्वराः⟫ (አልፎ አልፎ፡ imay īśvarāh = ⟪इमयीश्वराः⟫) "እነዚህ ጌቶች"

:::

### 4.1.4. ሳንዲሂ የመጨረሻው -d

::: grammar-box

**የመጨረሻው -d በፓውሳ እንዲሁም ከድምፅ አልባ ጉተራሎች (k, kh) እና ላቢያሎች (p, ph) በፊት በ -t ይተካል።**

ከሌሎች ተነባቢዎች በፊት ያለው መተካት በኋላ ይብራራል። ለጊዜው እንደዚህ ያሉ የድምፅ ግጭቶችን ያስወግዱ!

:::

> viṣṇuḥ kaḥ? = ⟪विष्णुः कः⟫ መልስ፦ viṣṇur īśvaraḥ = ⟪विष्णुरीश्वरः⟫። (በዚህ ሁኔታ በስም ዓለማዊ አጻጻፍ ላይ ተሳቢውን ለምሳሌ ወደ ፊት በማስቀመጥ ከጥያቄው ጋር ያለውን ትስስር መግባባት ማሳየት ይቻላል።)

ማስታወሻ፦ እስካሁን ያለው የሳንስክርት ጥበብዎን በመጠቀም እነዚህን ጥያቄዎች የምትመልሱበት መልስ በአጠቃላይ ከእያንዳንዱ ሁኔታ አንጻር በተሟላ መልኩ ተፈጥሯዊ የሆነ ጥበባዊ ሳንስክርት አይደለም።


## 4.2. ልምምድ

**ሀ) ከተካፈሉት ቃላት ጋር viṣṇuḥ kaḥ (⟪विष्णुः कः⟫) የሚለውን ቅርጽ በመከተል በድምፅ ያስቡ እና ጥያቄን ይፃፉ እና በሳንስክርት መልስ ይስጡ፦**

śruti, śiva, brāhmaṇa, dvija (ብዙ ቁጥር), indrāṇī, dhenu, tulādhara, kālidāsa

= ⟪श्रुति⟫, ⟪शिव⟫, ⟪ब्राह्मण⟫, ⟪द्विज⟫ (⟪बहुवचनम्⟫), ⟪इन्द्राणी⟫, ⟪धेनु⟫, ⟪तुलाधर⟫, ⟪कालिदास⟫

**ለ) ከሚከተለው የማንበብ ልምምድ ጋር etat kim (⟪एतत्किम्⟫) የሚለውን ቅርጽ በመከተል ጥያቄ ይፃፉ እና በተሰጡት ቃላት እና ማመልከቻ ክፍለ ቃላት ምሳሌ eṣa bālaḥ (⟪एष बालः⟫) በመጠቀም መልስ ይስጡ፦**
