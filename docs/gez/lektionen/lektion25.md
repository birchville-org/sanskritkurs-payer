# ቀጥታ 25

## 25.1. የአባለቲቭ (⟪पञ्चमी⟫ = "አምስተኛው የግራ ስርዓት") መፍጠር

::: grammar-box

ከማስኩሊና / ኒውትራ በ-a የተጠቀሙ እንዲሁም ከፕሮኖሚና በስተቀር፣ በሁሉም የዲክሊነሽን ክፍሎች ውስጥ በአንድ ቁጥር (ሲንጉላር) ውስጥ የአባለቲቭ (⟪पञ्चमी⟫) ቅርጾች ከጀኔቲቭ (⟪षष्ठी⟫) ጋር ተመሳሳይ ናቸው።

ከግል ፕሮኖሚና በስተቀር፣ በሁሉም የዲክሊነሽን ክፍሎች ውስጥ በብዛት ቁጥር (ፕሉራል) ውስጥ የአባለቲቭ ቅርጾች ከዳቲቭ (⟪चतुर्थी⟫) ጋር ተመሳሳይ ናቸው።

:::

አሁን የስንስክርት (⟪विभक्ति⟫) የግራ ስርዓቶችን ቅደም ተከተል ምክንያት ያውቃሉ፡ ተመሳሳይ የድምጽ ቅርጾች እንዲቀራረቡ ወይም በአጻጻፉ ስር እንዲሆኑ በሚያስችል መልኩ ተደርገው የተሠሩ ናቸው።

::: grammar-box

**የማስኩሊና / ኒውትራ በ-a የተጠቀሙ አባለቲቭ ሲንጉላር**

**deva** (⟪देव⟫) → **devāt** (⟪देवात्⟫)

:::

ጥያቄ፣ ተዛማጅ እና ዲሞንስትሬቲቭ ፕሮኖሚና፡

## 25.2. የአባለቲቭ (⟪पञ्चमी⟫) ተግባር

"አባለቲቭ ከሚነገርበት ነገር ሲወጣ የሚቀርበውን ነገር ያመለክታል።"

ፓኒኒ 2,3,28 + 1,4,24

አባለቲቭ በዋናነት "የትከው?"፣ "ለምን?" የሚለውን ጥያቄ ይመልሳል።

::: grammar-box

1\. ስለዚህ አባለቲቭ የመነሻ ነጥብን፣ ምንጭን እና ቁስ (ሞተር) ያመለክታል።

እምዝኒ፡ እቲ፡ ንዋያዊ፡ ግስ፡ ውሳኔ፡ ንሰብ፡ ይትረጎም፡ እምነሁ፡ ሰብ፡ ይግዛእ፡ ወይስምዕ፡ ወይፈቅድ፡ ወዘተ።

:::

Beispiele:

::: indent

⟪ग्रमादागच्छति⟫ = "Er kommt aus dem Dorf"

⟪अश्वात्पतितः⟫ = "vom Pferde gefallen"

⟪तेभ्यो लब्धम्⟫ = "von ihnen (her) empfangen"

:::

Beispiele:

::: indent

⟪गुरोर्धर्मं शृणोति⟫ = "እምመምህር፡ ይስምዕ፡ ዘሃይማኖት"

⟪ब्राह्मणः क्षत्रियाद्धेनुमिच्छति⟫ = "ብራህማን፡ እምክሻትሪያ፡ ላሕም፡ ይፈቅድ"

:::

::: grammar-box

2. እቲ፡ ንዋያዊ፡ ግስ፡ ምስ፡ ግሶች፡ ይትቀነይ፡ ዘትርጉሞሙ፡ "እምዝ፡ ይከልእ"፡ "እምዝ፡ ይዕቀብ"፡ "እምዝ፡ ይከላከል"፡ "እምዝ፡ ይፈርህ"፡

:::

⟪अरिभ्यो रक्षति⟫ = "እምጸላእት፡ ይዕቀብ"

:::

::: grammar-box

3. እቲ፡ ንዋያዊ፡ ግስ፡ ምኽንያት፡ ወይስ፡ ሰበብ፡ ይትረጎም፡

:::

Beispiele:

::: indent

⟪क्रोधात्पुत्रं हन्ति⟫ = "ወልዱ፡ እምቍጥዓ፡ ይቀትል"

⟪कृतपापत्वान्नरकं गच्छति⟫ = "እስመ፡ ኃጢአት፡ ገብረ፡ ናብ፡ ሲኦል፡ ይኸይድ" (« እስመ፡ ኃጢአት፡ ተገብረ፡ በኣኡ)

⟪पापकरणान्नरकं गच्छति⟫ = "እስመ፡ ኃጢአት፡ ይገብር፡ / ገብረ፡ ናብ፡ ሲኦል፡ ይኸይድ"

:::

ኣስማት፡ ዘኣይኮኑ፡ ኣንስትዮ፡ ንምትርጓም፡ ምኽንያት፡ ተግባር፡ ኣብ፡ ንዋያዊ፡ ግስ፡ (⟪तृतीया⟫) ወይስ፡ ንዋያዊ፡ ግስ፡ (⟪पञ्चमी⟫) ይትቀነዩ። ኣንስትዮ፡ በዚ፡ ትርጉም፡ ብሓፈሻ፡ ኣብ፡ ንዋያዊ፡ ግስ፡ ይትቀነያ፡ ግናኸ፡ ሓሓሊፉ፡ ኣብ፡ ንዋያዊ፡ ግስ፡ እውን፡ ይትቀነያ።

## 25.3. Das Suffix -⟪तस्⟫

::: grammar-box

ኣብ፡ ነጠላ፡ (ብግልጺ)፡ እቲ፡ ቃል፡ ብትርጉም፡ ንዋያዊ፡ ግስ፡ ከምዝተጠቀመ፡ ንምግላጽ፡ ንስም፡ መሰረት፡ ቅጥያ፡ -⟪तस्⟫ ክትውስኽ፡ ይከኣል፡ እዚ፡ ቅጥያ፡ ንግሳዊ፡ ግሶች፡ ብሓፈሻ፡ ንዋያዊ፡ ትርጉም፡ ይፈጥር፡ (ንሕቶ፡ "እምየት?"፡)፡

:::

ኣብነታት፦

::: indent

⟪आदितस्⟫ = "ኣብ መጀመርታ"

⟪धर्मतस्⟫ = "ብሰንኪ ዓርማ፣ ብመሰረት ዓርማ"

:::

::: grammar-box

እቲ ስጉምቲ -⟪तस्⟫ ኣብ ስም-ግላዊ ቃላት እውን ይመጽእ፦

:::

::: indent

⟪तद्⟫ ፦ ⟪ततस्⟫ (« ta-tas) "ኣብዚ፣ ኣብዚ፣ ናብዚ፣ ኣብዚ፣ ድሕርኡ፣ ብሰንኪ እዚ"

⟪यद्⟫ ፦ ⟪यतस्⟫ "ኣብዚ፣ ካበይ፣ ናበይ፣ ብምኽንያት እንታይ" (ዝምርቂ)

⟪किम्⟫ ፦  ⟪कुतस्⟫ "ካበይ?" "ብምኽንያት እንታይ?"

:::

## 25.4. ካልኦት መንገድታት ምኽንያት ንምግላጽ

::: grammar-box

**1\. ዝምርቂ ሓሳባት**

ዝምርቂ ሓሳባት ብተደጋጋሚ ምስቲ ናይ ቀንዲ ሓሳብ ዘለዎም ካውዛል (ምኽንያታዊ)፣ ኮንሴኩቲቭ (ውጽኢታዊ) ወይ ፋይናል (ንጉሆ) ዝምድና የመልክቱ።

ናይ ዝምርቂ ስም-ግላዊ ቃል ዝመስሉ ኣብ ስርዓተ-ጽሑፋት ከም ካውዛል ኮንጁንክሽን ዝያዳ ስም-ግላዊ ቃል ክኸውን ዝኽእሉ፦

*   ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ስርዓተ-ጽሑፋት ኣብ ::: grammar-box

**3\. Instrumental (⟪तृतीया⟫)**

Besides the Ablative (⟪पञ्चमी⟫), the Instrumental (⟪तृतीया⟫) is used to indicate reason or cause. With feminine nouns, the Instrumental is generally obligatory.

:::

Example:

::: indent

⟪क्रोधेन पुत्रं हन्ति⟫ = "He kills his son out of anger" = "He kills his son in anger"

:::

::: grammar-box

**4\. Nouns**

Furthermore, reasons can of course also be expressed through constructions with

*   ⟪कारण⟫ n. "cause": ⟪कारणात् । कारणेन⟫
*   ⟪हेतु⟫ m.
*   other nouns meaning "cause"

\+ Genitive (⟪षष्ठी⟫) or as the second member of compounds:

:::

Example:

::: indent

⟪पुण्यस्य कारणात्⟫ (⟪हेतोः⟫ etc.) = "because of the merit"

:::

::: grammar-box

**5\. ⟪इति⟫**

The motive for an action can be expressed as a thought with ⟪इति⟫:

:::

Example:

::: indent

⟪सम्यक्संबुद्धः सुगत इत्यानन्दो गौतमं धर्मं पृच्छति⟫  = "Because the Sugata has fully awakened to truth, Ānanda asks Gautama about his teaching" (« "Thinking 'The Sugata has fully awakened to truth' ..."

:::
