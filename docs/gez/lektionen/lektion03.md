# ትምህርት 3

## 3.1. የአንጻራዊ ስም ብቸኛ (Nominativ Singular) የሴት ጾታ

### 3.1.1. የአንጻራዊ ስም ብቸኛ በ -s የሚጠናቀቅ

እንዲሁም የሚከተሉት ስማዊ መሰረቶች፣ በአናት የሚጠናቀቁ፣ አንጻራዊ ስም ብቸኛ በ **-s** ይፈጠራል፡-

::: grammar-box

**በ -i የሚጠናቀቁ ሴት ስማዊ መሰረቶች**፡ ምሳሌ **śruti** f. "ማድመግ" -- አንጻራዊ ስም ብቸኛ፡ **śrutis** = ⟪श्रुतिस्⟫
**በ -u የሚጠናቀቁ ሴት ስማዊ መሰረቶች**፡ ምሳሌ **dhenu** f. "ወተት የምታፅድ" -- አንጻራዊ ስም ብቸኛ፡ **dhenus** = ⟪धेनुस्⟫

:::

### 3.1.2. አንጻራዊ ስም ብቸኛ ያለ መጨረሻ

አንጻራዊ ስም ብቸኛ ያለ መጨረሻ የሚፈጠሩት፡-

::: grammar-box

**በ -ā የሚጠናቀቁ ሴት ስማዊ መሰረቶች**፡ ምሳሌ **devatā** f. "እግዚአብሔር" -- አንጻራዊ ስም ብቸኛ፡ **devatā** = ⟪देवता⟫
**በ -ī የሚጠናቀቁ ሴት ስማዊ መሰረቶች**፡ ምሳሌ **devī** f. "እንስት እግዚአብሔር" -- አንጻራዊ ስም ብቸኛ፡ **devī** = ⟪देवी⟫

:::

::: important

**ጥንቃቄ!** በተጨማሪም አንድ ሰው የሆኑ ሴት ሥር ስማዊ መሰረቶች በ -ī የሚጠናቀቁ ሲሆን አንጻራዊ ስም ብቸኛ በ -s ይጠናቀቃል፡ ምሳሌ dhī f. "አስተላላፊ" -- አንጻራዊ ስም ብቸኛ፡ dhīs = ⟪धीस्⟫. እንዲሁም lakṣmī (⟪लक्ष्मी⟫) f.፣ tarī (⟪तरी⟫) f. "መርከብ" እና tantrī (⟪तन्त्री⟫) f. "መስመር" ያልተለመደ አንጻራዊ ስም ብቸኛ በ -s ይፈጠራል፡ lakṣmīs = ⟪लक्ष्मीस्⟫.

:::

## 3.2. የሴት ስማዊ መሰረቶችን ከወንድ ስማዊ መሰረቶች ጋር ማጣመር

::: grammar-box

**በ -a የሚጠናቀቁ ወንድ ስማዊ መሰረቶች**፡
**በ -ā የሚጠናቀቅ ሴት ስማዊ መሰረት**፡ ምሳሌ **kṣatriya** m. » **kṣatriyā** f. "የክሽትሪያ ሴት" = ⟪क्षत्रिया⟫
**በ -ī የሚጠናቀቅ ሴት ስማዊ መሰረት**፡ ምሳሌ **brāhmaṇa** m. » **brāhmaṇī** f. "የብራህማኒ ሴት" = ⟪ब्राह्मणी⟫

**በ -u የሚጠናቀቁ ወንድ ስማዊ መሰረቶች**፡
**በ -ī የሚጠናቀቅ ሴት ስማዊ መሰረት**፡ ምሳሌ **sādhu** m. » **sādhvī** f. (ጥሩ፣ ቅዱስ) = ⟪साध्वी⟫
(**-u-** በአናት ላይ ወደ **-v-** ይቀየራል፣ ስለዚህ **-u- + -ī** » **-vī**)

:::

## 3.3. የአንጻራዊ ስም ብዛት ወንድ እና ሴት

::: grammar-box

የአንጻራዊ ስም ብዛት መጨረሻ በ ወንድ እና ሴት **-as** ነው።
**በ -a የሚጠናቀቁ ወንድ ስማዊ መሰረቶች**፡ **deva- + -as** » **devās** = ⟪देवास्⟫
**በ -ā የሚጠናቀቁ ሴት ስማዊ መሰረቶች**፡ **devatā- + -as** » **devatās** = ⟪देवतास्⟫
**በ -i የሚጠናቀቁ ወንድ ስማዊ መሰረቶች**፡ **kavi-** » **kave- + -as** » **kavayas** = ⟪कवयस्⟫
**በ -i የሚጠናቀቁ ሴት ስማዊ መሰረቶች**፡ **śruti-** » **śrute- + -as** » **śrutayas** = ⟪श्रुतयस्⟫
**በ -ī የሚጠናቀቁ ሴት ስማዊ መሰረቶች**፡ **devī- + -as** » **devyas** = ⟪देव्यस्⟫
**በ -u የሚጠናቀቁ ወንድ ስማዊ መሰረቶች**፡ **guru-** » **guro- + -as** » **guravas** = ⟪गुरवस्⟫
**በ -u የሚጠናቀቁ ሴት ስማዊ መሰረቶች**፡ **dhenu-** » **dheno- + -as** » **dhenavas** = ⟪धेनवस्⟫

:::

ማስታወሻ፡ **e** ከ **i** የተነሳ (guṇa) ሲሆን **o** ደግሞ ከ **u** የተነሳ ነው።


## 3.4. የድምጽ ማጣመር (Vokalsandhi)

::: grammar-box

ቀላል ድምጾች እርስ በርስ ሲዛመዱ ወይም በረጅማቸው ብቻ ሲለያዩ ወደ ተመጣጣኝ ረጅም ድምጽ ይቀየራሉ፡
a / -ā + a- / ā- » **-ā-**
i / -ī + i- / ī- » **-ī-**
u / -ū + u- / ū- » **-ū-**
(-ṛ + ṛ- » **-ṝ-**)

:::

ለምሳሌ

devatā + annapūrṇā » devatānnapūrṇā "Annapūrṇā አንዷ እግዚአብሔር ናት" = ⟪देवतान्नपूर्णा⟫

> (Annapūrṇā የምግብ እና የማሰስ አለዋት ስትል ትታወቃለች፤ እንዲሁም የśiva ጽኑ ወይም ትዳር ናት።)

devī + indrāṇī » devīndrāṇī "Indrāṇī አንዷ እግዚአብሔር ናት" = ⟪देवीन्द्राणी⟫

> (Indrāṇī የእግዚአብሔር Indra ሚስት ናት።)

::: grammar-box

ቀላል ድምጾች (በ-a / -ā በስተቀር) ከማይመሳሰሉ ድምጾች በፊት ተመጣጣኝ ግማሽ-ድምጽ በመተካት ይቀየራሉ፡
i / -ī » **-y-**
u / -ū » **-v-**
ṛ » **-r-**

:::

ለምሳሌ

devī + umā » devy umā "Umā አንዷ / እግዚአብሔር ናት" = ⟪देव्युमा⟫

## 3.5. Satzsandhi von -ās

::: grammar-box

**-āḥ wird vor allen stimmhaften Lauten durch -ā ersetzt.**

:::

z.B.

dvijās + vaiśyāḥ » dvijā vaiśyāḥ "Vaiśyas sind Zweimalgeborene" = ⟪द्विजा वैश्याः⟫


## 3.6. Wortliste

**እነዚህን ቃላት ተማሩ፡**

**śruti** f. = ⟪श्रुति⟫ : das Hören, die ewige Überlieferung (Bezeichnung für die Veden und Brāhmaṇa's).

**smṛti** f. = ⟪स्मृति⟫ : Vergegenwärtigung, Erinnerung, meditative Vergegenwärtigung = Achtsamkeit, Überlieferung (Gegenbegriff zu **śruti**). Umfasst:
die sechs **vedāṅga** n. (⟪वेदाङ्ग⟫)
1. **śikṣā** f. (⟪शिक्षा⟫): rechte Aussprache
2. **chandas** n. (⟪छन्दस्⟫): Metrum
3. **vyākaraṇa** n. (⟪व्याकरण⟫): Grammatik
4. **nirukta** n. (⟪निरुक्त⟫) : Worterklärung, Etymologie
5. **jyotiṣa** n. (⟪ज्योतिष⟫) : Astronomie, Kalenderlehre
6. **kalpa** m. (⟪कल्प⟫) : Zeremoniell
**śrautasūtra** n. (⟪श्रौतसूत्र⟫) : Lehrwerke für den Vollzug der grossen Opfer
**gṛhyasūtra** n. (⟪गृह्यसूत्र⟫) : Lehrwerke für die Zeremonien und Opfer des täglichen Lebens
**dharmasūtra** n. (⟪धर्मसूत्र⟫) und **dharmaśāstra** n. (⟪धर्मशास्त्र⟫) : Lehrwerke zu Recht und Sitte (rechtes Verhalten)
die grossen Epen **mahābhārata** n. (⟪महाभारत⟫) und **rāmāyaṇa** n. (⟪रामायण⟫)
die **purāṇa** n. (⟪पुराण⟫)
**nītiśāstra** n. (⟪नीतिशास्त्र⟫) : Lehrwerke der Lebensklugheit

**smṛti** ፡ በተለይ የሕግ ትምህርቶች ስያሜ ነው።

**kṣatriyī** f. = ⟪क्षत्रियी⟫ : የክሽጥሪያ ሚስት።

**vaiśyā** f. = ⟪वैश्या⟫ : የቫይሺያ ሚስት።

**śūdrā** f. = ⟪शूद्रा⟫ : የሱድራ ሚስት።

**śūdrī** f. / **śūdrāṇī** f. = ⟪शूद्री शूद्राणी⟫ : የሱድራ ሚስት።

**devī** f. = ⟪देवी⟫ : አምላክ፣ በተለይ ዱርጋ f. = ⟪दुर्गा⟫፣ የሺቫ ሚስት = ⟪शिव⟫።

::: media

![](/images/lekt0303.webp)

Abb.: ዱርጋ = ⟪दुर्गा⟫, ኦሪስሳ

(የምስል ምንጭ: [ዝርዝሮች](/images/lekt0303))

:::

**sādhvī** f. = ⟪साध्वी⟫ : ሴታዊ ን sādhu።

**gurvī** f. = ⟪गुर्वी⟫ : ሴታዊ ን guru።

**asmitā** f. = ⟪अस्मिता⟫ : "እኔ-መሆን"፣ ማለትም (የተሳሳተ) እምነት፡ **እኔ** ይህን ማየት እያለ ነው።

**ānvīkṣikī** f. = ⟪आन्वीक्षिकी⟫ : ፈልስፎ (በትክክለኛ የሎጂካዊ ምክንያቶች ወደ መደምደሚያ የሚመጣ ሳይንስ)።

**upekṣā** f. = ⟪उपेक्षा⟫ : አለመጠንቀቅ፣ እኩልነት።

**karuṇā** f. = ⟪करुणा⟫ : ምሕረት፣ ቅንነት።

**muditā** f. = ⟪मुदिता⟫ : ደስታ፣ በተለይም የሌሎችን ደስታ መከፈል (የጨለማ ተቃራኒ)።


## 3.7. ማሰባበር

**A) የሚከተሉትን ሐረጎች በብዛት ያስቀምጡ:**

1. dvijo brāhmaṇaḥ = ⟪द्विजो ब्राह्मणः⟫
2. dvijaḥ kṣatriyaḥ = ⟪द्विजः क्षत्रियः⟫
3. dvijo vaiśyaḥ = ⟪द्विजो वैश्यः⟫
4. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
5. sādhur guruḥ = ⟪साधुर्गुरुः⟫
6. guruḥ kaviḥ = ⟪गुरुः कविः⟫
7. sādhvī brāhmaṇī = ⟪साध्वी ब्राह्मणी⟫
8. devatā guruḥ = ⟪देवता गुरुः⟫
9. paśur dhenuḥ = ⟪पशुर्धेनुः⟫
10. gurvī sādhvī = ⟪गुर्वी साध्वी⟫

**ለ) ስሞችን በማስገባት የስም ዓረፍተ ነገሮችን ፍጠሩ፡**

1. śrutis ... (veda) = ⟪श्रुतिस्⟫ ... ⟪वेद⟫
2. paśus ... (dhenu) = ⟪पशुस्⟫ ... ⟪धेनु⟫
3. devī ... (durgā, umā, indrāṇī) = ⟪देवी⟫ ... ⟪दुर्गा⟫, ⟪उमा⟫, ⟪इन्द्राणी⟫
4. devatā ... (mīnākṣī, annapūrṇā) = ⟪देवता⟫ ... ⟪मीनाक्षी⟫, ⟪अन्नपूर्णा⟫
5. śūdrā ... (itarā) = ⟪शूद्रा⟫ ... ⟪इतरा⟫

**C) Übertragen Sie ins Femininum:**

1. gurur brāhmaṇaḥ = ⟪गुरुर्ब्राह्मणः⟫
2. sādhur guruḥ = ⟪साधुर्गुरुः⟫
3. kṣatriyaḥ sādhuḥ = ⟪क्षत्रियः⟫ ⟪साधुः⟫

**መ) ወደ ሳንስክሪት ተርጉሙ፡**

1. Umā ist eine Göttin.
2. Der Veda ist śruti.
3. Die Lehrerinnen sind Göttinnen.
4. Milchkühe sind domestizierte Tiere.
5. Dichter sind Lehrer.
6. Kṣatriyas sind Zweimalgeborene.
7. Die heiligen Männer sind Śūdras.
