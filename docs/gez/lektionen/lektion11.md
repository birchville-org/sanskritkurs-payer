# ክፍለ-ወር 11

## 11.1. ድርብ አካሳቴቭ

::: grammar-box

**አንዳንድ ቃላት ድርብ አካሳቴቭ (dvitīyā) ይጠይቃሉ፡ የአካል አካሳቴቭ እና የምርት አካሳቴቭ።**

**እነዚህም ይካተታሉ፡**
**የማወቅ ቃላት፡** ለአንድ ሰው (አካሳቴቭ) ስለ ነገር (አካሳቴቭ) መናገር፤ ለአንድ ሰው (አካሳቴቭ) ነገር (አካሳቴቭ) መናገር
**የመጠይቅ ቃላት፡** ስለ ነገር (አካሳቴቭ) ሰውን (አካሳቴቭ) መጠየቅ
**የማስተምር ቃላት፡** ሰውን (አካሳቴቭ) ነገር (አካሳቴቭ) ማስተማር
አንዳንድ ተጨማሪ ቃላት፣ በቃል ዝርዝሮች ላይ የተጠቀሱ

**እንዲህ ዓይነት አወቃቀር ወደ ተገላቢጦሽ ሲቀየር፣ አካሉ (የሚጠየቅ ወዘተ) ወደ ፕራቴማ (prathamā) ይቀየራል፣ ምርቱ (ስለምን ይጠየቃል) በአካሳቴቭ ይቆያል።**

ምሳሌ **rāmo brāhmaṇaṃ dharmaṃ pṛcchati** = ⟪रामो ब्राह्मणं धर्मं पृच्छति⟫ = "ራማ ብራህማኑን ስለ ዳርማ ይጠይቃል።"
» ተገላቢጦሽ **rāmeṇa brāhmaṇo dharmaṃ pṛcchyate** = ⟪रामेण ब्राह्मणो धर्मं पृच्छयते⟫

**ይህ ሕግ የሚያስተምረው አካል እና ምርት ሁለቱም ኦብጀክት ሲሆኑ ብቻ ነው። አንድ ምርት ብቸኛ ኦብጀክት ከሆነ በተገላቢጦሽ ማዕከለኛ አውቃቀር መሰረት በፕራቴማ (prathamā) ይቆያል፡**

ምሳሌ **rāmo dharmaṃ pṛcchati** = ⟪रामो धर्मं पृच्छति⟫ = "ራማ ስለ ዳርማ ይጠይቃል።"
» ተገላቢጦሽ **rāmeṇa dharmaḥ pṛcchyate** = ⟪रामेण धर्मः पृच्छयते⟫

:::

## 11.2. የቃል ዝርዝር

**የሚከተሉትን ቃላት ይማሩ፡**

**iti** ⟪इति⟫ : እንዲህ
*ከ* አስተሳሰብ፣ ምኞት፣ አስተያየት ወይም ንብረት *ኋለ* ሲቀመጥ እንደ ንብረት ቅጽ (") ያስተውላል።
ምሳሌ **sādhavaḥ svargaṃ gacchantīti brāhmaṇā vadanti** "ብራህማኖች ይናገራሉ፡ 'ቅዱሞች ወደ ጎበዝ ይሄዳሉ'" = "ብራህማኖች ቅዱሞች ወደ ጎበዝ እንደሚሄዱ ይናገራሉ"።
በስንስክርት ያልተወሰነ ቃል የለም፤ ከ **iti** ጋር የተሰሩ አወቃቀሮች በጀርመን ብዙውን ጊዜ ያልተወሰነ ቃል መልክ ሊጻፉ ይገባል።
**... (ንብረት) ... iti śrutiḥ** = "ይህ ምስጢር ነው"።
ብዙ ጊዜ ከ **iti** *ኋለ* የማሰብ ቃል ይጠበቃል፡ "ማሰብ፡ '...' ያደርጋል"። በጀርመን ባህላዊ መልክ ማስተውል (ምሳሌ "ፈቱ ከሆነ ይሄዳል...")።

**evam** ⟪एवम्⟫ : ስለዚህ (በአባባል፣ ለምሳሌ **evaṃ jayati** "ስለዚህ ያሸን፣ል")
**na** ⟪न⟫ : አይደለም፣ አያስ
ቃላትን (በቀጥታ ከመነሻው በፊት ይቀመጣል፡ **na sādhuḥ** "ማይሻለው") ወይም ሙሉ አገላለጾችን (በመነሻ ላይ ወይም በቀጥታ ከተዋሃደ ቁጥር በፊት) ያስተካክላል።

**putra** ሰ. ⟪पुत्र⟫ : ወንድ ግብረ (በኢንዲያ የተፈለገው ወንድ ግብረ ነበር፣ የተሻለውን ማቅረብ ይችል ነበር)
**dharma** ሰ. ⟪धर्म⟫ : ("የተሻለው" ማለት) ቅድመ-ታሪክ፣ ሕግ፣ ተፈጥሮ፣ ስነ-ምግባር
በተሻለው ሁኔታ ከተፈጥሮ-ሕግ/ስነ-ምግባር ሕግ ጋር ይዛመዳል። እያንዳንዱ ሰው በ **varṇa** እና **āśrama** (የሕይወት ደረጃ) መሠረት የተለየ ቁርጥ ስምዎን (**svadharma**) ይኖረዋል።
**adharma** ሰ. ⟪अधर्म⟫ : ያልተሻለ (ከ **dharma** ጋር ተቃራኒ)
**iṣ** 6 ቁ (icchati) ⟪इष् इच्छति⟫ : ማስቀጠል (**iṣ-ccha-ti**)

**አንዳንድ የስም ልማት፡**

**vad** 1 ቁ ⟪वद्⟫ : ማለት
**vāda** ሰ. ⟪वाद⟫ : ቃል፣ ማስተዋወቂያ
**vadana** ነ. ⟪वदन⟫ : ማለት፤ የማሰብ መሳሪያ፡ ሙት፣ አድማ

::: media

(ምስል ምንጭ፡ [ዝርዝሮች](/gez/licenses#lekt1102))

**prach** 6 ቁ ⟪प्रच्छ्⟫ : ማጠየቅ
**praśna** ሰ. ⟪प्रश्न⟫ : ጥያቄ (የመጨረሻ **-na** እንደ **yaj-ña**)

**iṣ** 6 ቁ ⟪इष्⟫ : ማስቀጠል
**iṣṭi** ሴ. ⟪इष्टि⟫ : ፍላጎት (**iṣ** + **-ti**)

## 11.4. ምድጋም

**A) ናብ ስንስክሪት ተርጉም፡**
