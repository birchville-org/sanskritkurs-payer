# ትምህርት 55

## 55.1. የ a-አዎርስት (የአውሮርስት በቲማ ቃል)

::: grammar-box
**የ a-አዎርስት እንደ ስም፣ (⟪लङ्⟫) ክፍለ ጊዜ 6 (⟪तुदादि⟫) እንደ ስም፣ ይህም:**

**Augment + ጥልቀት ውስጣዊ ቃል + a + ሁለተኛ መደበኛ**

**-a- በእንግሊዝኛ እና በአውሮርስት ይተካል።**

**ምንም የአውሮርስት መደበኛ አይገባም።**

**የ Ātmanepada አስተዋጽኦ ነው; ለ Ubhayapada ውስጣዊ ቃላት በተለምዶ ከሌሎች አውሮርስት ክፍለ ጊዜዎች ይሰራል (እነዚህን ከ Kielhorn, Grammatik §340 እና ከታች በተዛመዱ አውሮርስት ክፍለ ጊዜዎች ያያሉ)።**

**የውስጣዊ ቃላት ዝርዝር እነዚህን አውሮርስት የያዙ፣ በ Kielhorn, Grammatik §340 ይታያሉ።**
:::
