# ዴቫናጋሪ = ⟪देवनागरी⟫

## የጽሑፍ ልምምድ 1

ሳንስክሪት በብዙ ዓይነት ጽሑፎች ተጽፏል እናም ይጻፋል። የሚከተለው ማጠቃለያ ከእነዚህ ጽሑፎች ትንሽ ክፍል ያሳያል፡

![](/images/schrift001.webp)  
ስዕል፡ የሳንስክሪት ጽሑፍ ናሙናዎች  
\[ምንጭ፡ ዊኪፔዲያ፣ GNU FD ፍቃድ\]

ዋናው ዘመናዊ ሰሜን ሕንድ ሳንስክሪት ጽሑፍ ዴቫናጋሪ ነው፡

![](/images/schrift002.webp)

እያንዳንዱ የቁምፊ ምልክት ከቁምፊ በኋላ የሚመጣ "a" ድምጽ ያካትታል። ጽሩይ ቁምፊ (ያለ ተከታይ ቀጥታ ድምጽ) ለመጻፍ፣ ይህን በታች የተዘጋጀ ቀጥተኛ መስመር -- virāma = ⟪विराम⟫ -- በማሳየት መለየት ያስፈልጋል፡

⟪क्⟫ = k, ⟪च्⟫ = c, ⟪ट्⟫ = ṭ, ⟪त्⟫  = t, ⟪प्⟫ = p

ከቁምፊ በኋላ የሚመጡ ቀጥታ ድምጾች -- "a" ብቻ ሳይሆን -- እንደሚከተለው ይጻፋሉ፡

⟪का⟫ = kā, ⟪कि⟫ = ki, ⟪की⟫ = kī, ⟪कु⟫ = ku, ⟪कू⟫ = kū, ⟪कृ⟫ = kṛ, ⟪कॄ⟫ = kṝ, ⟪कॢ⟫  = kḷ

⟪के⟫ = ke, ⟪कै⟫ = kai, ⟪को⟫ = ko, ⟪कौ⟫ = kau

እነዚህን የቁምፊ + ቀጥታ ድምጽ ጥምረቶች ሲጽፉ ቅደም ተከተሉ፡

![](/images/schrift003.jpg)

ሲጽፉ እያንዳንዱ ፊት ለፊት ከላይኛው መስመር ጋር በሙሉ ከተጠናቀቀ በኋላ ቀጣዩ ፊት ለፊት ይጻፋል።

Zusätzliche Leseübung:

⟪पिता⟫ ኣቡሁ፣ ⟪कपि⟫ ኣድጊ፣ ⟪कृत⟫ ተገብረ፣ ⟪टीका⟫ ንኡስ ሓተታ፣ ⟪तत्⟫ እዚ፣ ⟪तट⟫ ገምገም፣ ⟪पत्⟫ ይወድቕ፣ ⟪पट⟫ ጨርቂ፣ ⟪काच⟫ መርኣያ፣ ⟪काकुत्⟫ ጐሮሮ፣ ⟪चित्⟫ ይፈልጥ፣ ⟪पृच्⟫ ይሓዋውስ፣ ⟪पोटक⟫ ገብረ፣ ⟪चेतु⟫ ሓሳብ፣ ⟪तौतातित⟫ ተኸታሊ ኩማሪላ (ሚማምሳ)፣ ⟪तूत⟫ ሓርጭ፣ ⟪पीत⟫ ሰተየ፣ ⟪पीति⟫ መስተ፣ ⟪कॢप्⟫ ይኸውን፣ ⟪कृपते⟫ ይበኪ፣ ⟪पुटी⟫ ዕጣፍ፣ ⟪चापि⟫ ከምኡውን፣ ⟪तोक⟫ ወለዶ፣ ⟪तृपत्⟫ ጸገበ፣ ⟪पॄ⟫ ይመልእ፣ ⟪कृकाटी⟫ መሓውር ክሳድ፣ ⟪पूपौ⟫ ክልተ ቊርሲ፣ ⟪पैतृकी⟫ ኣቦኣዊ (ኣን.)፣ ⟪कौट⟫ ተንኮለኛ፣ ⟪कच⟫ ጸጕሪ ርእሲ፣ ⟪कुतपे⟫ ኣብ ልዕሊ ጸጕሪ ፍየል፣ ⟪कुचौ⟫ ኣጥባት፣ ⟪चकिता⟫ ፈሪሓ (ኣን.)
