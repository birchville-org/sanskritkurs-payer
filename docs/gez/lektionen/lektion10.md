# ክፍለ-ወር 10

## 10.1. የፓሲቭ ሐዲስ

::: grammar-box

**ሰንጠረዥ:**
**(አጀንስ - ካርትሪ - በኢንስትሩመንታል (ትሬቲያ) - (ቀጥተኛ ኦብጀክት - ካርማን - በኖሚናቲቭ) - ፓሲቭ የግስ ቅርጽ**

ምሳሌ **brāhmaṇena deva ijyate** = ⟪ब्राह्मणेन देव इज्यते⟫ = "አንድ ብራህማኒ በቅርበት አምላክን ያመልጣል" (ቃል በቃል: "አንድ አምላክ በአንድ ብራህማኒ በቅርበት ይመለጣል")

ይህ ሐዲስ **በጣም (!) ትርጉሙ እኩል** ነው ምስ ሐዲስ:
**brāhmaṇo devaṃ yajati / yajate** = ⟪ब्राह्मणो देवं यजति⟫ / ⟪यजते⟫

:::

::: grammar-box

በፓሲቭ ሐዲስ ውስጥ አጀንስ (**ካርትሪ**) በ**ኢንስትሩመንታል** (ትሬቲያ ፊ. "ሦስተኛ ካሱስ መጨረሻ") ይቀመጣል፣ ቀጥተኛ ኦብጀክት (**ካርማን** ኤን.) በ**ኖሚናቲቭ** (ፕራተማ ፊ.) ይቀመጣል።
ፓሲቭ ሐዲስ፣ አጀንስ በማይጠቀሱበት ሁኔታ ብዙውን ጊዜ ያልተለመደ ትርጉም አላቸው ("ማንም"):
ምሳሌ **ijyate** = ⟪इज्यते⟫ "ማንም ይቅርበዋል" (ቃል በቃል: "እንደ ቅርበት ይመለጣል")።

:::

::: grammar-box

**በተመሳሳይ ስራዊት ሐዲስ አኩዬቲቭ (ድቪቲያ) የሚፈልግ ከሆነም፣ ይህ በፓሲቭ ሐዲስ ውስጥ ኖሚናቲቭ (ፕራተማ) ሊደረግ ይችላል:**

ስራዊት ሐዲስ **rāmo grāmaṃ gacchati** = ⟪रामो ग्रामं गच्छति⟫ = "ራማ ወደ ገጠር ይሄዳል" የሚባለውን ሐዲስ ይመጥናል:
**rāmeṇa grāmaṃ gamyate** = ⟪रामेण ग्रामं गम्यते⟫
ሌላ አማራጭ: **rāmeṇa grāmo gamyate** = ⟪रामेण ग्रामो गम्यते⟫

:::

::: grammar-box

**ትራንዚቲቭ ግሶች (ቀጥተኛ ኦብጀክት የሌላቸው ግሶች) ብዙውን ጊዜ የፓሲቭ መዋቅር አላቸው፣ በተለይም በአክብሮት ማስጠንቀቂያዎች ውስጥ:**
**praviśyatām** = ⟪प्रविश्यताम्⟫ = "ማንም እንዲገባ ይሁን = እባክዎ ይግቡ = ስላል!"
**niṣadyatām** = ⟪निषद्यताम्⟫ = "ማንም እንዲቀመጥ ይሁን = እባክዎ ተቀመጡ = እባክዎ ቦታ ይውሰዱ"

:::

ግስያተ ሳንስክሪት ዘይትገበር ብዙኅ እዩ፡ እስመ ዘይትገበር ይትገበር እምነ ብዙኃት ግብረ ግስያት ዘበአምሳለ ዛቲ።

::: important

**ግስያተ ሳንስክሪት ዘይትገበር በአጠቃላይ በጀርመንኛ በግስያተ ዘይትገበር ኢይትነገር፡ እስመ ግስያተ ጀርመንኛ ዘይትገበር ካልእ ኄልዎቱ ዘይትገበር።**

:::

### 10.2.1. ኣብ ምጥቃም ከምነታ (tṛtīyā = ⟪तृतीया⟫)

::: grammar-box

**ከምነታ (tṛtīyā) ብዙሕ ኣብ ሕቶታት ይውጽእ:**
**በኸመይ?**
**ብምንታይ?**
**ስጋድ ምስ ኣየናይ?**

**ከምነታ**
1. **ኣብ ሓደጋ ቃላት: ኣገባብ (kartṛ) ከምነታ**
2. **ንመጠን ወይ መሳርሒ ንምግላጽ ብዝኾነ ነገር ይውሰን**
3. **ንመገዲ ንምግላጽ ብኸመይ ሰብ ናብ ዝበለጸ ቦታ**
4. **ንምትእስሳር፣ ምውህሃድ፣ ምስ ኣየናይ**
5. **ኣብ ምስሊ ቃላት ከም "ጽንዓት ምስ"፣ "ሓቢርካ"; ንኣብነት saha = ⟪सह⟫ = "ሓቢርካ"** :brንኣብነት:br **brāhmaṇena saha** = ⟪ब्राह्मणेन सह⟫ = "ሓቢርካ ምስ ብራህማን"

:::

ዝኾነ ካልእ ጥቅምታት ናይ ትርጓሜ (tṛtīyā) ይስዕብ ኣሎ።


## 10.3. እቲ ን -n- ዝምልከት ስርዓተ-ጽሑፍ (Wortsandhi)

::: grammar-box

**-n-**፡ ብቀጻሊ ድምጺ ወይ **n, m, y, v** እንተ ተኸቲሉ፡ **ṛ, ṝ, r, ṣ** ኣብ ቃል እንተ ዘለዉ፡ ብ **-ṇ-** ይቕየር። እዚ ኸኣ **y, v, h** ወይ Anusvāra ጥራይ እንተ ዘይኮነ ኣብ መንጎ እዞም ድምጽታትን ነቲ ቀጺሉ ዘሎ **-n-** እውን ኣብ ቃል።

:::

:::

**እዚ ኸኣ -ṇ- ከምዚ ዝስዕብ ክንርዳእ ኢና፡**

### 10.4.1. כללים מיוחדים ליצירת הסביל

1. **שורשים המסתיימים ב-i או -u** מאריכים את התנועה לפני הסיומת הפעילה **-ya-**:
* **ji** 1 P: **jīyate**, **jīyante** :br⟪जीयते⟫, ⟪जीयन्ते⟫
* **śru** 5 P: **śrūyate**, **śrūyante** :br⟪श्रूयते⟫, ⟪श्रूयन्ते⟫
* **su** 5 U: **sūyate**, **sūyante** :br⟪सूयते⟫, ⟪सूयन्ते⟫

2. **שורשים עם -a- בין עיצורים** (למעט נזלים, y, r, v) נשארים בשלב הגבוה:
* **labh** 1 Ā: **labhyate**, **labhyante** :br⟪लभ्यते⟫, ⟪लभ्यन्ते⟫

3. **כמה שורשים יוצרים את הסביל בשלב הגבוה** (או בשלב האבלאט של שורש הנוכחי):
* **āp** 5 P: **āpyate**, **āpyante** :br⟪आप्यते⟫, ⟪आप्यन्ते⟫
* **khād** 1 P: **khādyate**, **khādyante** :br⟪खाद्यते⟫, ⟪खाद्यन्ते⟫
* **smṛ** 1 P: **smaryate**, **smaryante** :br⟪स्मर्यते⟫, ⟪स्मर्यन्ते⟫

4. **שלב נמוך של פועלים המתחילים ב-ya, va, ra, או כשהעיצורים האלה עוקבים אחרי עיצור אחר (Samprasāraṇa = ⟪सम्प्रसारण⟫):**

| שורש:br⟪धातु⟫ | שלב נמוך:br⟪सम्प्रसारण⟫ | סביל:br⟪यक्⟫ |
| :--- | :--- | :--- |
| **yaj** 1 U:br⟪यज्⟫ | \*yj &raquo; ij | **ijyate** :br⟪इज्यते⟫:br **ijyante** :br⟪इज्यन्ते⟫ |
| **vad** 1 P:br⟪वद्⟫ | \*vd &raquo; ud | **udyate** :br⟪उद्यते⟫:br **udyante** :br⟪उद्यन्ते⟫ |
