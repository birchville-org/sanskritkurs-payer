# ትምህርት 19

## 19.1. የአንጻራዊ ሁኔታ

::: grammar-box

**ስዕላዊ መግለጫ:**


**የአንጻራዊ ቃል -- የአንጻራዊ ሁኔታ፣ ይህም የያዘውን ስም ያመለከታል -- (የማሳያ ቃል) -- ዋና ሁኔታ**

**የአንጻራዊ ሁኔታ ከዋናው ሁኔታ በኋላም ሊመጥን ይችላል፣ ነገር ግን በዋናው ሁኔታ ውስጥ መተርጓሙ አይችልም።**

**የአንጻራዊ ቃል እና የማገናኛው ቃል (እንደ ጀርመንኛ በተቃራኒ) በአንጻራዊ ሁኔታ ውስጥ የሚገኙት፣ በአንጻራዊ ሁኔታው የሚያስፈልገውን ስም ይይዛሉ። የማሳያው ቃል በዋናው ሁኔታ የሚያስፈልገውን ስም ይይዛል።**

:::

ምሳሌዎች፡-

ማስታወሻ፡ በአጠቃላይ ትክክለኛ ይዘት ላላቸው አንጻራዊ ሁኔታዎች ውስጥ ብዙውን ጊዜ የመሳቂያ (Optativ) ከፍተኛ ምልክት በመጠቀም ይሰማል። ስለዚህ ብዙ ከምሳሌያችን በመሳቂያ ሁኔታ ይገኛል።

**1. የሥራ አስኪያጁ (⟪कर्तृ⟫) በአንጻራዊ ሁኔታ ይበልጥ ተመራምሯል፡-**

::: indent

⟪यो नरः पुण्यं करोति स स्वर्गं गच्छति⟫ =  ⟪यो नरः पुण्यं करोति तेन स्वर्गं गम्यते⟫ = ⟪येन नरेण पुण्यम् क्रियते तेन स्वर्गं गम्यते⟫ ወዘተ. = "ሰው ጥቅም አለው፣ ወደ ሰማይ ይሄዳል።"

:::

**2. ቀጥተኛው ነገር (⟪कर्म⟫) በዋናው ሁኔታ በአንጻራዊ ሁኔታ ይበልጥ ተመራምሯል፡-**

::: indent

⟪यो ब्राह्मणो देवान्यजते तं देवा रक्षन्ति⟫ = "እግዚአብሔር ብራህማኖችን ይጠብቃል፣ እነሱም ለእርሱ የሚቀርብ ነገር ይሰጣል።"

:::

**3. የዋናው ስም ተጨማሪ መለያ በአንጻራዊ ሁኔታ ውስጥ ይገኛል፡-**

::: indent

⟪ये नराः पापं कुर्वन्ति तेषां पुत्रा धनं न लभन्ते⟫ = "የሰው ልጆች ይበልጥ ትክክለኛ ናቸው፣ ምንም ብዛት አያገኙም።"

:::

**4. ተውሳከ ስም ዘግበር ወስም ዘግበር ይትነበሩ በግንኙነት (⟪षष्ठी⟫):**

::: indent

⟪यस्य⟫ ⟪नरस्य⟫ ⟪पुत्राः⟫ ⟪पापं⟫ ⟪कुर्वन्ति⟫ ⟪स⟫ ⟪न⟫ ⟪सुखवान्⟫ = "እቲ ሰብኣይ ኣይኮነን ሕጉስ፣ እቶም ደቁ ክፉእ ዝገብሩ።"

:::

**5. ተውሳከ ስም ዘግበር ወስም ዘግበር ይትነበሩ በምስጋና (⟪तृतीया⟫):**

::: indent

⟪येन⟫ ⟪शत्रुणा⟫ ⟪ग्रामो⟫ ⟪जितस्तं⟫ ⟪द्विषन्ति⟫ = "ንጸላኢ ይጸልእዎ፣ ንሱ ንዓዶም ዝሰዓረ / ዝሓዘ።"

:::

**6. ተውሳከ ስም ዘግበር ወስም ዘግበር ይትነበሩ በግሱም (⟪द्वितीया⟫):**

::: indent

⟪यं⟫ ⟪नरं⟫ ⟪देवी⟫ ⟪रक्षति⟫ ⟪स⟫ ⟪सुखमाप्नोति⟫ = "እቲ ሰብኣይ፣ እታ ኣምላኽ እትሕልዎ፣ ሓጎስ ይረክብ።"

:::

## 19.3. የቃላት ዝርዝር

**⟪अर्थ⟫ ስፍራ (m.): ዓላማ፣ መዕቀኛ፣ ትርጉም (የአንድ ቃል)፣ ንብረት፣ ሀብት። ⟪अर्थम्⟫ (አክዩሴቲቭ)፣ ⟪अर्थेन⟫ (ኢንስትሩመንታል) ከጄነቲቭ ጋር ወይም እንደ ኋላ ክፍል በታትፑሩሻ ምስጢር: ለ... እንዲሁም።**

⟪अर्थ⟫ ከሦስቱ የኑር ዓላማዎች (⟪पुरुषार्थ⟫) አንዱ ነው፣ እንደሚገለጸው በዓለም አቀፍ እና ሃይማኖታዊ ትምህርት ውስጥ:

::: indent

**⟪धर्म⟫ ስፍራ (m.): በትክክለኛው ሥርዓት መሠረት የተግባር ማከናወን በመሆኑ የተጠቀም ማግኘት ወይም ቢያንስ ከዳርማ ህግ መተው የሚመጣን ክፋት መቆጠብ**

**⟪अर्थ⟫ ስፍራ (m.): ዓላማ-አስተዳደር ባህሪ፣ የብልጽግና ማግኘት**

**⟪काम⟫ ስፍራ (m.): የኢንደርስ ንቅናቄ፣ በተለይም በሴክስዋል መስክ**

:::

## 19.4. Übung

**ናብ ሳንስክሪት ተርጉም:**

1\. ብእሲተ ወይስያ ዘወልዳ ሞተ ታበኪ።

2\. ራማ ንኣምላኽ የቕርብ፣ እቲ ዝሕልዎ።

3\. እቲ ገጣሚ ንክሻትሪያ የውድስ፣ እቲ ንብረቱ ዝምነዮ።

4\. ሓዊ ንቤት እቲ ሰብኣይ የቃጽል፣ እቲ ንኣግኒ ብመስዋእቲ ዘየምልኽ።

5. ብእሲ ዘከመ ነብር ይቀትል ሐርበኛታት ክሻትርያ ዘሰዐሩ ራማ (ተገብሮ).
