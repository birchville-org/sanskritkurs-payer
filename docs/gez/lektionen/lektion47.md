# ትምህርት 47

## 47.1. ትዕዛዝ (⟪लोट्⟫)

::: grammar-box

ትዕዛዝ (⟪लोट्⟫) ይገልጻል

*   **ትዕዛዝ** (በገረንዲቭም (⟪कृत्य⟫) ይገለጻልም)
*   **መመሪያ**
*   **ጥያቄ/ደላይነት**
*   **ፈቃድ/ምኞት**
*   **እርማት/መጠየቂያ**
*   **ድንገተኛ ጥሪ**
*   **ስታን፣ ማሰብ/መወያየት**
*   **ጥያቄ**

እነዚህ ትርጉሞች ከኦፕታቲቭ (⟪विधिलिङ्⟫) ጋር ይጋራል።

በትዕዛዝ ሌሎችንም የሚከተሉትን እናገልጻለን፡

*   **ፍቃድ/መንገድ**
*   **አንድ ሥራ በጊዜው መከናወን እንዳለበት** (በገረንዲቭም (⟪कृत्य⟫) ይገለጻልም)
*   **የእንቅስቃሴ ምኞት/ጸጋ**

:::

ምሳሌዎች፡

::: indent

⟪एहि ।⟫ "መጣ!"

⟪ग्रामं भवानागच्छतु ।⟫ ወይም ኦፕታቲቭ : ⟪ग्रामं भवानगच्छेत् ।⟫ "ወደ ገጠርው ይመጡ!"

⟪वेदमध्ययै ।⟫ ወይም ኦፕታቲቭ: ⟪वेदमधीयीय ।⟫ "ቬዳን ማጥናት እፈልጋለሁ።"

⟪इच्छामि भुङ्क्तां भवान् ।⟫ ወይም ኦፕታቲቭ:  ⟪इच्छामि भुञ्जीत भवान् ।⟫ "እነሱ እንዲበሉ ምኞቴ ነው።"

⟪किं वेदमध्ययै ।⟫ ወይም ኦፕታቲቭ: ⟪किं वेदमधीयीय ।⟫ "ቬዳን ማጥናት አለብኝ?"

⟪करोतु शस्त्रं भवान् ।⟫ ወይም ገረንዲቭ: ⟪भवता शस्त्रं कर्तव्यम् ।⟫ "ጠርዝ ይሥሩ!" ; "ጠርዝ ማምረት ይችላሉ" ; "ጊዜው የተሟላ ሆኖ ይገኛል እንዲያስሩ ጠርዝ ይሥሩ።"

⟪चिरं जीवतु भवान् ।⟫ "ረጅም ሕይወት ይኖርልዎት!"

:::

::: grammar-box

ልባዊ ትዕዛዞች በተለምዶ በፓሲቭ-ትዕዛዝ ይገለጻሉ።

:::

ምሳሌዎች፡

::: indent

⟪भवता प्रविश्यताम् ।⟫ "እባክዎን **ይግቡ!**"

⟪निषद्यताम् ।⟫ "እባክዎን ተቀመጡ!"

:::

በክላሲካል ሳንስክሬት ትዕዛዝ ውስጥ የ1ኛ ሰው ቅርጾች ያሉት አልድ ኮንጀክቲቭ ቅርጾች ናቸው። ቬዲክ ኮንጀክቲቭ በተለይም ምኞት የሚገልጽ መንገድ ነው፡ "እኛ እንሂድ!" "እኛ እንሂድ።"

::: grammar-box

ይህ ትዕዛዝ ከገለጻ ሥር ይመሰረታል።

:::

## 47.3. Übung
