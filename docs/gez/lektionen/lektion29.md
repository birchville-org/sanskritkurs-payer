# ሊቅነት 29

## 29.1. የፓራስማይፓዳ (⟪परस्मैपद⟫) እና Ātmanepada (⟪आत्मनेपद⟫) መጠቀም በኩሳቲቭም ውስጥ


::: grammar-box

**ኩሳቲቭ በጥቂት ልዩነቶች Ubhayapada (⟪उभयपद⟫) ነው**

:::

::: grammar-box

**በኩሳቲቭም ውስጥ Ātmanepada (⟪आत्मनेपद⟫) ይጠቀማል:**

**1. የተዘዋወረው ግብር ንቅናቄ ለተዘዋዋሪው ጠቃሚ ሲሆን፡**

:::

ምሳሌ፡

⟪रामः कटं कारयते⟫ = "ራማ ለራሱ (በግል ጥቅም) ድንጋይ እንዲሰራ ያዛል"

**2. ኩሳቲቭ የተለመዱ ግስ-ገቢ ቃላት በተንከለካ (reflexive) መልኩ ሲጠቀሙ ("የመያዝ" "የማስተናገድ" ወዘተ)፣ ወይም የቀላል ግስ-ገቢ ቃል ንቅናቄ (⟪कर्तृ⟫) የኩሳቲቭ ንቅናቄ ሲሆን፡**

ምሳሌ፡

⟪विष्णुर्भक्तान्दर्शयते⟫ = "ቢሽኑ ለአማልድት እንዲያይ ያሳየ"

ውጤት፡ ⟪भक्ता विष्णुं पश्यन्ति⟫ = "እምነተኞች ቢሽኑን ይመለከታል"


ስለዚህ ሕጎቹ በአጠቃላይ ከĀtmanepada (⟪आत्मनेपद⟫) ሕጎቹ ጋር ይስማሙ Ubhayapada (⟪उभयपद⟫)-ቃላት።

## 29.3. Übersetzungsübung zur Wiederholung

ብቓል ብቓሉ ናብ ጽቡቕ ጀርመንኛ ተርጉም እሞ ነቲ ናይ ሳንስክሪት ጽሑፋት ብልቢ ተማሃሮ፦

1\. Definition von ⟪अविद्या⟫ :

⟪अनित्याशुचिदुःखा⟫:sig[⟪नात्मसु⟫] ⟪नित्यशुचिसुखात्मख्यातिरविद्या ॥योगसूत्र २⟫.⟪५॥⟫

መብርሂ: ⟪आत्मसु⟫ = ናይ ቦታ መስተዋድድ ነጠላ ናይ ⟪आत्मन्⟫ ተባዕታይ "ነፍሲ፤ ፍጹምነት፡ ኣብ ውልቀሰብ ከም ዝተረጋገጸ"

2\. ⟪कौटिलीयार्थशास्त्र⟫ 1.4. በቀኝ መጠቀም ስለ ⟪दण्ड⟫ :
