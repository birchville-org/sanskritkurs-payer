# ቀጥታ ክፍል 26

## 26.1. ለ-ስ- በውስጥ ቃል የሚያዛባ ሕግ

::: grammar-box

**-ስ-** በ**-ṣ-** ይተካል፣ **k, r, l** ወይም **ቃላት** — በስተጀርባ **a, ā** ውጪ — ቀጥተኛ ሆነው ወይም በ⟪अनुस्वार⟫ ወይም ⟪विसर्ग⟫ ብቻ የተለዩ ከሆነ እና ሌላ ድምፅ **ṛ, r** ከተከተለ።

ይህ ስንዲ በ**⟪दुस्⟫-** ቅድመ-ገለልተኛ ጉትቱራል እና ላቢያል በኮምፖዚታ ይከተላል።

:::

*ምሳሌዎች:*

::: indent

⟪तेषाम्⟫ (ከ: *te-sām*)

ነገር ግን: ⟪तासाम्⟫ (*tā-sām*)

:::

## 26.2. ለደንታል በውስጥ ቃል የሚያዛባ ሕግ

::: grammar-box

ደንታል ቃላት በሬትሮፍለክስ (በ**-ṣ-** ጨምሮ) በተዛማጅ ሬትሮፍለክስ ይተካሉ:

**iṣ** + **-ta** = **iṣṭa** (⟪इष्ट⟫)
**ti** + **sth** + **a** + **ti** = **tiṣṭhati** (⟪तिष्ठति⟫)
*(**ṣ** ምክንያት የቀድሞ **i**, **ṭh** ምክንያት የቀድሞ **ṣ**)*

:::

## 26.3. ለፓላታል, ጉትቱራል, ṣ, h + -s የቃል ስንዲ

::: grammar-box

**-k, -kh, -g, -gh; -c, -j; -ś, -ṣ; -h** + **s-** » **-kṣ**

ምሳሌዎች ከታች ይመልከቱ

:::

## ፳፮.፮. አጠቃቀም ግስ ዘወደፊት (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ አንስታይ)

**ግስ ዘወደፊት (⟪ऌत्⟫, ⟪भविष्यन्ती⟫ አንስታይ) ይገልጽ:**

**ተስፋ ("ከመዝ ይከውን")**
**ተስፋ**
**ፍርሃት**
