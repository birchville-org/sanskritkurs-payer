# ትምህርት 37

## 37.1. ቃል-አዋጭ (⟪क्रियाविशेषणम्⟫)

ቃል-አዋጆች በሳንስክርት ውስጥ

1.  በመደበኛ ቃላት እና በምስጢር ምልክቶች
2.  በተለየ መንገድ እና ምልክቶች

በመጀመሪያው ሁኔታ ውስጥ መካከለኛው ቃል እና ቃል-አዋጭ ያለ ልዩነት ነው። እንደ ብሔር ምልክት የተጠቀሱ ቃል-አዋጆች ይኖራሉ፣ እነዚህም የተጠቀሱ ቃል-አዋጆች ናቸው፣ እንዲሁም በመደበኛ ቃላት ውስጥ ሌሎች ቅርጾች ይጠቀማሉ ወይም ተመሳሳይ ቃላት እንደ ቃል-አዋጆች አይጠቀሙም።

## 37.2. ቃል-አዋጭ የመደበኛ ቃላት ምልክቶች

### 37.2.1. መደበኛ (⟪द्वितीया⟫)

::: grammar-box

መደበኛ (⟪द्वितीया⟫) ቃል-አዋጭ ሊሆን ይችላል በሚከተሉት ጥያቄዎች፡

*   በምን መልኩ?
*   ምን ያህል ጊዜ?
*   ከየትኛው ቦታ?
*   እና ሌሎች።

ቃል-አዋጭ ሊሆን የሚችለው መደበኛ፡

*   ከመደበኛ ቃላት  
ምሳሌዎች፡  
⟪कामम्⟫ "በፈለገው መልኩ"  
⟪अर्थम्⟫ "ለምክንያት"  

*   ከአስተሳሰብ ቃላት በገለልተኛ ሁኔታ  
ምሳሌዎች፡  
⟪सुखम्⟫ "ቀላል"  
⟪नित्यम्⟫ "ሁልጊዜ"  
⟪साधु⟫ "ትክክል"  

*   ከምስጢር ምልክቶች በገለልተኛ ሁኔታ  
ምሳሌዎች፡  
⟪तद्⟫ "ወቅት"  
⟪यद्⟫ "እንደ"  
⟪एतद्⟫ "እንደ"

:::

### 37.2.2. መደበኛ (⟪तृतीया⟫)

::: grammar-box

መደበኛ (⟪तृतीया⟫) ቃል-አዋጭ ሊሆን ይችላል በሚከተሉት ጥያቄዎች፡

*   በምን መልኩ?
*   ምስጢር ምልክት?
*   እና ሌሎች።

ቃል-አዋጭ ሊሆን የሚችለው መደበኛ፡

*   ከመደበኛ ቃላት  
ምሳሌዎች፡  
⟪अर्थेन⟫ "ለምክንያት"  
⟪क्षणेन⟫ "በዚህ ጊዜ" (ከ ⟪क्षण⟫ m. "ጊዜ")  

*   ከአስተሳሰብ ቃላት፣ በተለምዶ በአንስተኛ ቅርጽ  
ምሳሌዎች፡  
⟪दूरेण⟫ "ርቆ" (ከ ⟪दूर⟫ 3 "ርቆ")  
⟪उच्चैस्⟫ "ከፍ" (ከ ⟪उच्च⟫ 3 "ከፍ")

:::

### 37.2.3. ዳቲቭ (⟪चतुर्थी⟫)

::: grammar-box

በጣም አልተለመደም ሆኖ ዳቲቭ (⟪चतुर्थी⟫) በሚከተሉት ጥያቄዎች ላይ እንደ አስተሳሰብ ያገለግላል፡

*   ለምን ዓላማ?
*   እና ተመሳሳይ

ምሳሌ፡

:::

::: indent

⟪अर्थाय⟫ "ለ... ዓላማ፣ ለ... እንዲሁ"

:::

### 37.2.4. አብላቲቭ (⟪पञ्चमी⟫)

::: grammar-box

አብላቲቭ (⟪पञ्चमी⟫) እንደ አስተሳሰብ በሚከተሉት ጥያቄዎች ላይ ያገለግላል፡

*   ለምን?
*   በምን ምክንያት?
*   ከየት?
*   እና ተመሳሳይ

አብላቲቭ እንደ አስተሳሰብ ሊያገለግል ይችላል፡

*   ከስም (Substantive)  
ምሳሌ፡ ⟪बलात्⟫ "በኃይል፣ በመጠቀም"  

*   ከተዋሕዶ (Adjektive)  
ምሳሌ፡ ⟪दूरात्⟫ "ከርቀት"  

*   ምሳሌ (ተውሳከ ስም)
ምሳሌዎች፡  
⟪कस्मात्⟫ "ለምን"  
⟪अकस्मात्⟫ "ያልተጠበቀ"

:::

### 37.2.5. ጄኔቲቭ (⟪षष्ठी⟫)

::: grammar-box

በጣም አልተለመደም ሆኖ ጄኔቲቭ (⟪षष्ठी⟫) "ከምን ዓመት በኋላ?" ለሚለው ጥያቄ እንደ አስተሳሰብ ያገለግላል

ምሳሌ፡ ⟪चिरस्य⟫ "ከረጅም ጊዜ በኋላ" (እስከ ⟪चिर⟫ 3 "ረጅም (ጊዜ)")

:::

### 37.2.6. ሎካቲቭ (⟪सप्तमी⟫)

::: grammar-box

ሎካቲቭ (⟪सप्तमी⟫) እንደ አስተሳሰብ በሚከተሉት ጥያቄዎች ላይ ያገለግላል፡

*   እየት?
*   በምን ሁኔታዎች?
*   እና ተመሳሳይ

ምሳሌዎች፡

:::

::: indent

\-⟪अर्थे⟫ "በምክር"  
\-⟪कृते⟫ "ለ... እንዲሁ"  
⟪दूरे⟫ "ርቆ"

:::

## 37.3. አስተሳሰባዊ ትርጉም ያልበለጠ የኩሳስ ቅርፆች

ምሳሌዎች፡

::: indent

⟪जातु⟫ "በአጠቃላይ" (መነሻው "ከልደት፣ ከተፈጥሮ" ሲል፣ አኩዘቲቭ ነጠላ ስም ወደ ⟪जातु⟫ \<በስም አልተለመደም\>)

⟪तूष्णीम्⟫ "በድምጽ" (አኩዘቲቭ ነጠላ ወደ አልተለመደም ስም ⟪तूष्णी⟫ "ድምጽ")

⟪एवम्⟫ "እንዲሁ" (ወደ ሌላ የተጠቀመው ፕሮኖምናል ስም ⟪एव⟫ "አንድ፣ ብቸኛ")

:::

## 37.4. ግብረ ግብረ-ግስ በግብረ-ግስ ቅጥያ

## 37.5. ንቁሳዊ ስም-ስም ቅርጽታት

### 37.5.1. ስም-ስም ቅርጽታት ኣዮርቢያዊ ወይ ከም ኣዮርቢያዊ ዝጥቀመሉ ስም-ስም ቅርጺ ከም ደብዳበኛ

ኣብነት: ⟪सुचिरम्⟫ "ንዝሓለፈ ጊዜ ብቐጻልነት"

### 37.5.2. ከም ኣዮርቢያዊ ዝጥቀመሉ ⟪बहुव्रीहि⟫

ኣብነት: ⟪रक्षार्थम्⟫ "ከም ኣብ ልዕሊ እቲ ዝተመርጸ ነገር ዘሎ ሓደ፣ ንምክልኻል እቲ ዝተመርጸ ነገር"። እዚ ድማ ከም 5.1. ክርአ ይኽእል፦ -⟪अर्थम्⟫ ከም ኣዮርቢያዊ ደብዳበኛ።

### 37.5.3. ⟪अव्ययीभाव⟫-ስም-ስም ቅርጽታት

⟪अव्ययीभाव⟫ = "ዘይቀያየር/ዘይተለዋወጥ ዝኾነ"

::: grammar-box

ሓደ ⟪अव्ययीभाव⟫ ኣብ ውሽጡ ሓደ ንቁስ-ንቁስ ቅርጺ ዘለዎ ስም-ስም ቅርጽታት እዩ፣ ከምኡ’ውን ደሓር-ስም ስም-ስም ቅርጺ ኣብ ውሽጡ ሓደ ንቁስ-ንቁስ ቅርጺ ዘለዎ ስም-ስም ቅርጽታት እዩ።

ኣብ ምስራሕ እቲ ስም-ስም ቅርጺ ኣብ ውሽጡ ሓደ ንቁስ-ንቁስ ቅርጺ ዘለዎ ስም-ስም ቅርጽታት እዩ፦

ኣብነታት፦

:::

::: indent

⟪प्रत्यग्नि⟫ = ⟪अग्निं प्रति⟫ = "ኣብ ልዕሊ እቲ ዝተመርጸ ነገር"

⟪यथाशक्ति⟫ = ⟪शक्तिमनतिक्रम्य⟫ = "ኣብ ልዕሊ እቲ ዝተመርጸ ነገር"

⟪अभिमुखम्⟫ = ⟪मुखम् अभि⟫ = "ኣብ ልዕሊ እቲ ዝተመርጸ ነገር"

:::

ብፍላይ ⟪अव्ययीभाव⟫ ምስ ⟪यथा⟫ "ከም" ኣብ ውሽጡ ሓደ ንቁስ-ንቁስ ቅርጺ ዘለዎ ስም-ስም ቅርጽታት እዩ፦

ኣብነት፦ ⟪यथाकामम्⟫ = ⟪कामो यथास्ति⟫ = "ከም እቲ ዝተመርጸ ነገር"

## 37.8. የጥያቄ ሀረግ

::: grammar-box

"ማን?, እንዴት?, ምን?, ለምን? ለምን?, ለምን?  
ጥያቄ የማይጠይቅ ቁራጭ ነው."

⟪कः कथं किं केन कस्मात्कस्मै । यो न पृच्छेन् मूर्खस्तिष्ठेत् ॥⟫

የሴስም ስትሪት መርህ፣ በሕይወት እና በስንስክሪት ትምህርት ላይ የተሻለ መመሪያ ነው

:::

## 37.11. መልመጃ ተደጋጋሚ

ወደ ሳንስክሪት ተርጉም፣ የግስ ቅርጾችን ብቻ በመጠቀም ፍጹም ጊዜ (Perfekt)፡

አንድ ጊዜ አንድ ሽማግሌ ወደ ሌላ መንደር በሄደ ጊዜ፣ በመንገድ ላይ ደከመ። ከዚያም ለማረፍ በአጠገቡ ወደቆመው የማንጎ ዛፍ ሥር ሄደ። በዚህ ዛፍ ላይ የበሰሉ ፍራፍሬዎች ነበሩ። ሽማግሌው እነሱን ለመብላት ፈለገ። ነገር ግን ዛፉ ላይ መውጣትና ፍራፍሬዎቹን መያዝ አልቻለም። እንደ እድል ሆኖ፣ በዚህ ዛፍ ላይ ፍራፍሬዎችን የሚበሉ አንዳንድ ዝንጀሮዎች ነበሩ። እነሱን ባየ ጊዜ ሽማግሌው ተደሰተ። ምን አደረገ? አንዳንድ ድንጋዮችን ወስዶ ዝንጀሮዎቹን አነጣጥሮ ወረወረ። የተናደዱት ዝንጀሮዎች አንዳንድ ፍራፍሬዎችን ለቅመው በሽማግሌው ላይ ወረወሩ። ሽማግሌውም እነዚህን በደስታ ወስዶ ወደሚፈልገው አካባቢ ሄደ። እነሆ፣ የሽማግሌው ብልሃት!
