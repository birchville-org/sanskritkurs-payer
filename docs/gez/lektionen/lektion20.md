# ትምህርት 20

## 20.1. የመብት ውስብስቦች = ⟪बहुव्रीहि⟫ m.

::: media

![](/images/lekt2004.webp)

ስዕል፡ ⟪बहुव्रीहिः पुरुषः⟫
ጆድፑር = ⟪जोधपुर⟫
(ምንጭ ስዕል፡ [ዝርዝሮች](/gez/licenses#lekt2004))

:::

⟪बहुव्रीहिः⟫ = ⟪बहवो व्रीहयो यस्य सः⟫ = "በብዙ ሽንኩርት የሚገለግል"

::: grammar-box

**አንድ ባሁቭሪፂ ከታትፑሩሻ ጋር በተለየ መልኩ ከገንዘቡ አካላት የሚገለጽ ሌላ ነገርን ያመለክታል፡ እስከ ጊዜው ⟪बालपुत्रः⟫ እንደ ታትፑሩሻ "አንድ ወጣት ልጅ" ተብሎ የተፈታው ሲሆን ይህም በውስብስቡ መጨረሻ ላይ ካለው አካል (⟪पुत्र⟫) የሚገለጽ ነው፣ ⟪बालपुत्रः⟫ እንደ ባሁቭሪፂ "ልጁ ወጣት የሆነ ሰው" ተብሎ ይፈታል፣ ማለትም የተጠቀሰው ነገር ልጁ (⟪पुत्र⟫) ወይም በግልጽ ወጣት (⟪बाल⟫) አይደለም፣ ነገር ግን ከወጣት ልጁ የተለየ ሰው ነው፣ ይህም አባቱ ነው።**

**የመብት ውስብስቦች በመጀመሪያ ሁልጊዜ ቃላት ናቸው፣ እነዚህም ስያሜዎች መሆን ይችላሉ። ስለዚህ የባሁቭሪፂ ተመሳሳይነት ከባሁቭሪፂ ጋር የሚዛመድበት ነገር ላይ የተመሰረተ ነው፣ እናም በመጨረሻው የውስብስብ አካል ላይ ይዞታውን የሚያገኝ አይደለም።**

:::

::: grammar-box

**ለባሁቭሪፂ መፍትሄ ስኬማ፡**

**1. አባል በተለምዶ በመግቢያ (⟪प्रथमा⟫) ነጠላ፣ ሁለት ወይም ብዙ -- 2. አባል በመግቢያ ነጠላ፣ ሁለት ወይም ብዙ -- በሌላ ኬስ ላይ ያለ የግንኙነት ቃል (በተለምዶ ጀነቲቭ - ⟪षष्ठी⟫) እና በጠቅላላው ባሁቭሪፂ ውስጥ በወንድምና እና ቁጥር -- በጠቅላላው ባሁቭሪፂ ውስጥ በወንድምና፣ ኬስ እና ቁጥር ያለ የማመልከቻ ቃል።**

:::

ምሳሌዎች፡


::: indent

⟪गतपापः⟫ = ⟪गतं पापं यस्य सः⟫ = "የተሳሳተው የሄደበት" = "ከጥፋት ነፃ የሆነ"

Akk. sg. ⟪गतपापम्⟫ = ⟪गतं पापं यस्य तम्⟫

Inst. sg. ⟪गतपापेन⟫ = ⟪गतं पापं यस्य तेन⟫

Gen. sg. ⟪गतपापस्य⟫ = ⟪गतं पापं यस्य तस्य⟫

Nom. pl. ⟪गतपापाः⟫ = ⟪गतानि पापानि⟫ ye⟪षां ते⟫

etc.

⟪अस्तमोहा⟫ = ⟪अस्तो मोहो यया सा⟫ = "a (woman) who has cast off delusion"

⟪प्राप्तोदको ग्रामः⟫ = ⟪प्राप्तमुदकं यं⟫ s ⟪ग्रामः⟫ = "A village to which the water has reached" = "a village threatened by flooding"

⟪पुण्यवत्पुत्रः⟫ as Bahuvrīhi = ⟪पुण्यवान्पुत्रो यस्य सः⟫, or: ⟪पुण्यवन्तः पुत्रा यस्य सः⟫ = "one who possesses merit in his son" or: "one who possesses merit in his sons"

:::

::: grammar-box

**The relationship between the first member and the second member in a Bahuvrīhi can be:**

*   **attributive**
*   **appositional**
*   **case-related**
*   **adverbial**

**As with Tatpuruṣa, the specified member usually stands in second place.**

:::

Traditionally, one distinguishes:

*   ⟪समानाधिकरणबहुव्रीहिः⟫ : in ⟪विग्रहवाक्य⟫ the first member and second member stand in the same case

*   ⟪व्यधिकरणबहुव्रीहिः⟫ : in ⟪विग्रहवाक्य⟫ the first member and second member stand in different cases


## 20.2. Bahuvrīhi with attributive first member

::: grammar-box

**Schema:**

:::

::: indent

**Adjective -- Noun**

:::

**Example:**

::: indent

⟪गुणवत्पुत्रो ब्राह्मणः⟫ =  ⟪गुणवान्पुत्रो यस्य स ब्राह्मणः⟫ = "a Brahmin whose son / sons possesses / possess good qualities"

:::

**Particularly frequent is the -- rare in Tatpuruṣa -- attributive determination by a PPP. The relative pronoun then usually stands in the Instrumental (⟪तृतीया⟫) upon resolution (rarely in the Genitive / ⟪षष्ठी⟫).**

**Faustregel:**

*   **PPP - Substantiv = meistens Bahuvrīhi**
*   **Substantiv -- PPP = meistens Tatpuruṣa**

**Example:**

::: indent

⟪कृतफल ३⟫ = ⟪कृतं फलं⟫ ዘ⟪ንኡሱ። ዘእያሁ።⟫ ዘ⟪ንኡሱ⟫ = "፩/፩/፩ ዘአምጽአ ፍሬ፣ ፩/፩ ዘይትገበር"

:::

## 20.3. Bahuvrīhi mit appositionellem Vorderglied

::: indent

⟪तदन्त ३⟫ = ⟪ውእቱ ፍጻሜ ዘአልቦሙ እሱኡ። ዘአልቦሙ እያሁ። ዘአልቦሙ እሱኡ።⟫ = "ውእቱ/እያሁ/እሱኡ ዘፍጻሜሁ ውእቱ" = "በዝንቱ ዘይትፈጸም"

**Example:**

:::

## 20.6. የባሁቭሪሂ መጨረሻ ክፍል ቅርጽ

::: grammar-box

**የባሁቭሪሂ መጨረሻ ክፍል ከመነሻ ስም (gender) በተለየ መልኩ እንደ ብዙ ስሚያዊ (mehrgeschlechtliches) አመልካች ይቀርጻል። ስለዚህ በአንድ ውስብስብ ቃል (Kompositum) መጨረሻ ክፍል ከመነሻ ስም በተለየ ከሆነ፣ እንደ ባሁቭሪሂ መሆኑ ካልሆነ ሳማሃራድቭንፋ (Neutrum sing.) ከሆነ ያስፈልጋል።**

**በአመልካችነት ሲቀርጹ**

*   **-ā-መሰረቶች በወንድ እና በጾታ ሁለቱም ወደ -a-መሰረቶች ይቀየራሉ**
*   **-a-መሰረቶች (ወንድ፣ ጾታ) የሴት ቅርጻቸውን በ-ā ወይም -ī ይሰራሉ**
*   **-ī-መሰረቶች (ጾታ) በባሁቭሪሂ መጨረሻ ላይ -ka፣ -kā፣ -ka (ጾታ) ማስተዋወቂያ መውሰድ አለባቸው፤ ይህ ማስተዋወቂያ ብዙ ሌሎች ባሁቭሪሂዎችም መውሰድ ወይም መጠቀም አለባቸው**

:::

## 20.7. የባሁቭሪሂ ዓይነቶች ሌላኛ ክፍልፋይ

ምሳሌዎች እዚህ ለኋለኛ ትምህርት የተሰጡ ሲሆን፣ ለአንዳንዶቹ የተስማሚው ቋንቋ እና ቃላት አሁንም ድረስ ሳይነገርባቸው ቀርተዋል

1.   ማስተካከያ ቃል በፊት ክፍል -- የተሰየመ ቃል በኋለኛ ክፍል፡ ⟪स्थिरचित्तः⟫ = ⟪स्थिरं चित्तं यस्य सः⟫

4.   ቀጥተኛ ማነፃፀር፡ ⟪उष्ट्रमुखः⟫ = ⟪उष्ट्रस्य मुखमिव मुखं यस्य सः⟫ = "የቱላ ወንበር" = የወንበሩ ክፍል እንደ ቱላ ነው

8.   በፊት ክፍል ላይ sa- (= ⟪समान⟫) ጋር፡ ⟪सजनपदः⟫ = ⟪समानो जनपदो यस्य सः⟫

10.   በፊት ክፍል ላይ ቅድመ-ቃል እና ወዘተ. ጋር፡ ⟪प्रवातः⟫ =⟪प्रकृष्टो वातो यस्मिन् सः⟫ ; ⟪निर्धनः⟫ = ⟪निर्गतं धनं यस्मात्सः⟫ ; ⟪सुबुद्धिः⟫ = ⟪सुष्ठु बुद्धिर्यस्य सः⟫ ; ⟪दुर्बुद्धिः⟫ = ⟪दुष्टा बुद्धिर्यस्य सः⟫
11.   አቅጣጫ ስማት መካከለኛ አቅጣጫዎችን ለመግለጽ፡ ⟪पुर्वोत्तरा⟫ "ሰሜን-ምስራቅ"
