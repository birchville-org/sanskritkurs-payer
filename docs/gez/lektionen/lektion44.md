## 44.2. On Word Sandhi

For present stems ending in consonants, the already discussed laws of word sandhi must be observed.

Additionally, the following laws of word sandhi apply.

(For a comprehensive compilation of all sound changes belonging here, see Kielhorn, Grammar p. 76f.)

### 44.2.1. On Word Sandhi for dh-

::: grammar-box

1. **An aspirate is replaced by the corresponding non-aspirate before an aspirate:**
e.g. ⟪रुध्⟫ 7U: ⟪रुन्ध्⟫ + ⟪ध्वे⟫ » ⟪रुन्द्ध्वे⟫ (run**ddh**ve)
2. **-h + dh- » -gdh-**
e.g. ⟪दुह्⟫ 2U: ⟪दुह्⟫ + ⟪ध्वे⟫ » ⟪धुग्ध्वे⟫ (dhu**gdh**ve)
3. **-ṣ + dh- » -ḍḍh-** (This rule applies only to conjugation!)
e.g. ⟪द्विष्⟫ 2U: ⟪द्विष्⟫ + ⟪ध्वे⟫ » ⟪द्विड्ढ्वे⟫ (dvi**ḍḍh**ve)
4. **-s + dh- » -dh-** (Loss of -s)
e.g. ⟪आस्⟫ 2Ā: ⟪आस्⟫ + ⟪ध्वे⟫ » ⟪आध्वे⟫ (ādhve)

:::

### 44.2.2. On Word Sandhi for s-

::: grammar-box

1. **-s + s- » -ts- or (not optionally!) -ss-** (as in the 2nd Present Class)
Examples:
* ⟪वस्⟫ 1P: Future: ⟪वस्⟫ + ⟪स्य⟫ + ⟪ति⟫ » ⟪वत्स्यति⟫ (va**ts**yati)
* ⟪वस्⟫ 2Ā: ⟪वस्⟫ + ⟪से⟫ » ⟪वस्से⟫ (va**ss**e)
2. **-ṣ + s- » -kṣ-**
e.g. ⟪द्विष्⟫ 2U: ⟪द्वेष्⟫ + ⟪सि⟫ » ⟪द्वेक्षि⟫ (dve**kṣ**i)

:::

## ፵፬.፬. ቃለ ምጽዋዕ (⟪आमन्त्रितम्⟫)

ሊቃውንት ሰዋስው ዘሀገር አልቊጽርዎሙ ለቃለ አድኅሮት (⟪आमन्त्रितम्⟫) ከመ ጾታ ስም ዘርእስ፣ አላ ከመ ለውጥ ዘጾታ ስም ዘርእስ (⟪प्रथमा⟫)።

::: important

**ቃለ አድኅሮት የዓዋቂት ወይስ የጥሪት ቃል ነው፣ ወአልቦቱ ተዛምዶ ምስለ ካልእ ቃል ዘዓረፍተ ነገር፣ ወበዝንቱ ይትፌለጥ እምካልአት ጾታ ስም ዘይትናገራ ተዛምዶ ምስለ ግስ ወይስ ምስለ ካልእ ስም።**

**በአብዛኛው ቃለ አድኅሮት በቅድሚት ዓረፍተ ነገር ይትነበር:**

:::

::: indent

⟪बाल किं वदसि⟫ = "Kind, was sagst du?"

:::

::: important

**Avoid translating the vocative with "**O** ...". We constantly use vocatives in German when we say, for example: "Darling, what are we cooking today?". No one would say in this sense: "**O** Darling, what are we cooking today?"**

:::

## 44.5. Wortliste

⟪प्रति⟫ Präverb: zurück, wider, gegen - hin

::: indent
