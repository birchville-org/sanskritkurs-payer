# ንብረት 31

## 31.1. ንብረት 7 (⟪रुधादि⟫ = "⟪रुध्⟫ ወዘተ")

::: grammar-box

**መፈጠር:**

**ከጥልቅ ደረጃ ሥር ኋላ-ድምፅ በኩል የሚመስለው ናሲን-ግብዕና (-na- ወይም -n-) ይከላከላል፦**

*   **በጠንካራ ሥር፦ -na-**
*   **በደካማ ሥር፦ -n-**

**ለሥር ኋላ-ድምፅ እና ለቃላት በመነሻው ድምፅ የተዛመዱ መወጫ-ቃላት ተያይዘው የሚከተሉት ህጎች ንብረት 2 ተመሳሳይ ናቸው።**

:::
