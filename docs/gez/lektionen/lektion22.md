# ትምህርት 22

## 22.1. ስለ አብሶልቲቭ (⟪क्त्वा । ल्यप्⟫)

::: grammar-box

ስንት በሳንስክሪት አንድ የአገልጋይ (⟪कर्तृ⟫) ስራ ከሌላ የአገልጋይ ስራ በፊት ይከናወን ወይም እንደ ተያያዥ ሁኔታ ይከሰት እንደሆነ ለማስቀመጥ አብሶልቲቭ (⟪क्त्वा । ल्यप्⟫) ይጠቀማሉ። ስለዚህ

"ከተሰራ በኋላ ይህን ስራ ያደርጋል" ; "ይህን ስራ ያደርጋል ከዚያ ይህን ስራ ያደርጋል" ; "ከዚህ ምክንያት ይህን ስራ ያደርጋል" ; "መጣሁ አየሁ ኢዘኩ" ወዘተ.

አብሶልቲቭ የግስ-አድቫርብ ነው ማለትም ይህ የግስ ቃል አይቀየርም እንዲሁም አይለወጥም ነገር ግን ሁልጊዜ - በትንሽ መስተጓጎያዎች ብቻ ሳይሆን - አንድ አይነት የአገልጋይ (⟪कर्तृ⟫) አለው እንደ ስራው ይከተል ወይም ይመቻች። የአብሶልቲቭ አገልጋይ በኖሚናቲቭ (⟪प्रथमा⟫) ወይም ኢንስትሩመንታሊስ (⟪तृतीया⟫) ይገኛል።

ከኮምፖዚታ ጋር በአንድነት አብሶልቲቭ ከፍተኛ የሆነ የመግለጫ መንገድ በሳንስክሪት ውስጥ ነው።

በመተርጎም ወደ ጀርማን "ከተሰራ በኋላ" ብለን ስንል አይደለም። በተለመዱ የጊዜ ቅደም ተከተል መግለጫዎች ይጠቀሙ።

**ስኬማ:**

(በዝርዝር ስለ አብሶልቲቭ: የአኗኗር ሁኔታ፣ ኦብጀክት ወዘተ.) - አብሶልቲቭ - አብሶልቲቭ - ... - አብሶልቲቭ - ... የአገልጋይ + ፊደላዊ ንባብ (በአክቲቭ ወይም ፓሲቭ)

:::

**ምሳሌዎች:**

::: indent

**⟪गृहं प्रविश्य बालां दृष्ट्वा नरो वदति⟫** = ፓሲቭ መዋቅር: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरेणोद्यते⟫**  
"ወንዱ ቤቱን ይግባል ጓሮውን ያያል እና ይነግረዋል።"

ብዙ: **⟪गृहं प्रविश्य बालां दृष्ट्वा नरा वदन्ति ।⟫**

:::

## 22.2. ስላብሶልቲቭም (Absolutivum) መፈጠር

::: grammar-box

**ስላብሶልቲቭም (Absolutivum) መፈጠር**

*   ቅድመ-ተሰማሪያ ሌለባቸው ቁጥር-ተዋሕዶች (Verben): ስላብሶልቲቭም በ **-tvā** ያበቃል
*   ቅድመ-ተሰማሪያ ያለባቸው ቁጥር-ተዋሕዶች (Verben): ስላብሶልቲቭም በ **-ya** ወይም **-tya** ያበቃል

:::

### 22.2.1. ቅድመ-ተሰማሪያ ሌለባቸው ቁጥር-ተዋሕዶች (Verben): ስላብሶልቲቭም በ -⟪त्वा⟫ ያበቃል

::: grammar-box

**መፈጠር:**

(በብዛት) በ PPP ፊት የሚገኘው ቅርጽ ያለው ጥልቅ-ደረጃ (tiefstufige) ሥር + **-tvā** (**-⟪त्वा⟫**)

የማይነግድ **a-** / **an-** ብቻ ነው ከ **-⟪त्वा⟫** ጋር የሚስማማው፡ ⟪अकृत्वा⟫ "ምንም ሳይሰራ"

:::

**ምሳሌዎች:**

::: indent

⟪आप्त्वा⟫ "ከተገኘ በኋላ / ከነበር"

⟪आसित्वा⟫ "ከቀመሰ በኋላ / ነው"

⟪इत्वा⟫ "ከሄደ በኋላ / ነው"

⟪स्थित्वा⟫ "ከነበረ በኋላ / ነው"

⟪जित्वा⟫ "ከተሸነፈ በኋላ / ነበር"

⟪उक्त्वा⟫ "ከገለጸ በኋላ / ነበር"

:::

### 22.2.2. ቅድመ-ተሰማሪያ ያለባቸው ቁጥር-ተዋሕዶች

#### 22.2.2.1. በረጅም ሰማዊ (vowel) (-ā ውጪ) ወይም በቁም-ፊት (Konsonant) የሚያልቅ ሥሮች

::: grammar-box

**(በብዛት) ጥልቅ-ደረጃ (tiefstufige) ሥር + -ya**

:::

**ምሳሌዎች:**

::: indent

⟪उपनीय⟫ "ከተቀረበ በኋላ / ነበር"

⟪प्रभूय⟫ "ከወጣ በኋላ / ነበር" "ኃይል ከነበረው በኋላ"

⟪प्राप्य⟫ "ከተገኘ በኋላ / ነበር"

:::

#### 22.2.2.2. በ -ā የሚያልቅ ሥሮች

::: grammar-box

**ለውጥ የሌለበት ከፍተኛ-ደረጃ (hochstufige) ሥር + -ya**

:::

**ምሳሌ:**

::: indent

⟪उपस्थाय⟫ "ከተገባ በኋላ / ነው" ; (ነፃ ግን ቅድመ-ተሰማሪያ ከሌለ፡ ⟪स्थित्वा⟫)

:::

#### 22.2.2.3. በጥልቅ ደረጃ ላይ በአጭር -i, -u, -ṛ የሚያልቁ ሥሮች

::: grammar-box

**ዝቅተኛ ደረጃ ሥር + -tya**

:::

**ምሳሌዎች፡**

::: indent

⟪प्रस्तुत्य⟫ "ከተወሰነ ጊዜ በኋላ (...) ብቁ ነው / ኖረ"

⟪विस्मृत्य⟫ "ከተወሰነ ጊዜ በኋላ (...) አስታውሷል / ኖረ"

⟪संस्कृत्य⟫ "ከተወሰነ ጊዜ በኋላ (...) ለቅዱስ ክብር ዝግጁ አድርጓል / ኖረ"

:::

#### 22.2.2.4. በ-am / -an የሚጠናቀቁ ሥሮች፣ በዝቅተኛ ደረጃ ላይ በ-a የሚጠናቀቁ

::: grammar-box

**አማራጭ፡**

ሥር በ **-am** / **-an** + **-ya**

ወይም፡

ሥር በ **-a** + **-tya**

:::

**ምሳሌ፡**

::: indent

⟪विगम्य⟫ ወይም ⟪विगत्य⟫ "ከተወሰነ ጊዜ በኋላ (...) ያለፈ ነው / ኖረ"

:::

**ለ) ተርጉምን ንውሁዳት ቃላት ብሳንስክሪት ፍታሕን፡**

⟪अन्नं पक्त्वा ब्राह्मणदासो ऽत्ति ॥१॥ इष्टदेवतापूजां कृत्वेन्द्रादिदेवान्सद्ब्राह्मणाः स्तुवन्ति ॥२॥ प्रस्थाय रामः सपुत्रः सद्गुरुश्रवणार्थेन ब्राह्मणग्रामं गच्छति ॥३॥ अनिष्ट्वा नरो भगवद्भक्तिमात्रेणापि मोक्षमाप्नोति ॥४॥ गृहगर्भं प्रविश्य ब्राह्मणपुत्रमुपस्थाय क्षत्रियशूरो वक्ति ॥५॥ सम्बुध्य दुःखाद्यार्यसत्यानि प्रोच्य सुगतो मोक्षमार्गेण नरान्नयति ॥६॥ मन्त्रं विस्मृत्य यजन्यज्ञदोषं करोति ॥७॥ धनं प्राप्य बुद्धमार्गभिक्षवो दुष्यन्ति ॥८॥ अनार्यशत्रुभिः संगत्य नरसिंहा विजयन्ते ॥९॥ पुण्यं कृत्वा सत्यमेवोदित्वा नरो नरकं नोपपद्यते ॥१०॥⟫

**ሐ) ካብ ላዕለዋይ ዓረፍተ ነገራት (ካብ ዓረፍተ ነገራት 8ን 10ን ብዘይካ) ተገብሮ ግሲታት ስራሕ**
