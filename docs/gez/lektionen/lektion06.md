# ትምህርት 6

## 6.1. የግስ ሐረግ

::: grammar-box

**ስኬማ I: የግስ ቅርጽ**
ምሳሌ **yajati** = ⟪यजति⟫ = "እሱ (እሷ፣ ይህ) በቅዳማ ማከበር"፣ "እሱ (እሷ፣ ይህ) ቅዳማ ያቀርባል"

**ስኬማ II: ግንባር (kartṛ m. = ⟪कर्तृ⟫) – የግስ ቅርጽ**
ምሳሌ **rāmo yajati** = ⟪रामो यजति⟫ = "ራማ በቅዳማ ያከብራል"፣ "ራማ ቅዳማ ያቀርባል"

:::

ግንባር (**kartṛ** m. = ⟪कर्तृ⟫) በሰዋስው ሐረግ ውስጥ ካልተጠቀሰ በስተቀር (በአክቲቭ)፣ ግንባሩ በ**ናሚነቲቭ** (የመጀመሪያ ሁኔታ፣ prathamā = ⟪प्रथमा⟫) ይቀመጣል። በቁጥር (vacana n. = ⟪वचन⟫) ግንባር እና የግስ ቅርጽ ይዛመዳሉ።


## 6.2. የግስ ቅርጾችን ማዘጋጀት

አንድ የተወሰነ የግስ ቅርጽ (ማለትም በግላዊ መጨረሻ የተጠናቀቀ) በስንስክርት ውስጥ የሚከተለውን ያመለክታል፡

1. **ትርጉም** (**artha** m. ⟪अर्थ⟫)
2. **ግለ** እና **ቁጥር** (vacana n. = ⟪वचन⟫) (እኔ፣ አንተ፣ እሱ/እሷ/ይህ ፣ እኛ ሁለታችን፣ አንተሁለትዎ፣ እነርሱ ሁለታቸው፣ እኛ ብዙ፣ አንተሁለትዎ ሰውነት፣ እነርሱ ብዙ)
3. የተግባር አይነት (genus verbi)፡
1. **Parasmaipada** (n. = ⟪परस्मैपद⟫) ("ለሌላ ሰው የተዘጋጀ ቃል")፡ አክቲቭ ሁኔታ። ምሳሌ **yajati** = ⟪यजति⟫ = "እሱ በቅዳማ ያከብራል" (ለምሳሌ ልዩ አገልጋይ ለሌላ ሰው ቅዳማ የሚያቀርበው)
2. **Ātmanepada** (n. = ⟪आत्मनेपद⟫) ("ለራሱ የተዘጋጀ ቃል")፡ ሚዲየም ሁኔታ። ምሳሌ **yajate** = ⟪यजते⟫ = "እሱ በቅዳማ ለራሱ ይከበራል" (ለምሳሌ የቤተሰቡ አባል ራሱን እና ቤተሰቡን ለማክበር የሚያቀርበው)
3. **Passiv** (**karman** n. = ⟪कर्मन्⟫)። ምሳሌ **ijyate** = ⟪इज्यते⟫ = "በቅዳማ ይከበራል"

በብዙ ጉዳዮች ውስጥ የĀtmanepada ትርጉም ልዩነት አይታወቅም፤ እንዲሁም ጥበባውያን ተፈጻሚዎች ሁልጊዜ Ātmanepadaን ከParasmaipada ጋር ተመሳሳይ በሆነ መልኩ ይጠቀማሉ። ነገር ግን በትርጉም ወቅት እያንዳንዱ ትርጉም ልዩነት እንዳለ መመልከት አስፈላጊ ነው።

ግስቶች በፓራማስቴፓዳ እና ሣትመነጐፓዳ (በተለየው የሣትመነጐፓዳ ትርጓሜ) ሲያገለግሉ **ኡባይፓዳ**-ግስቶች (ubhayapada n. = ⟪उभयपद⟫ = "ሁለቱ ቃል መዋቅሮች") ይባላሉ።

ገና አንዳንድ ግስቶች በፓራማስቴፓዳ ብቻ ወይም በሣትመነጐፓዳ ብቻ ይከተላሉ። በእነዚህ ግስቶች ውስጥ የሣትመነጐፓዳ ወይም ፓራማስቴፓዳ የተለየ ትርጓሜ አይኖረውም። ምሳሌ **manyate** = ⟪मन्यते⟫ = "እሱ (እሷ፣ ይህ) ያስባል" (የተለየ የሣትመነጐፓዳ ትርጓሜ ሳይኖር)።

4. **የማሰብ መንገድ** (Mode):
1. **ኢንዲኬታቭ**: የማረጋገጫ መዋቅር
2. **ኦፕታቲቭ**: የምንዛሬ መዋቅር እና ሊሆን የሚችል መዋቅር
3. **ኢምፐራቲቭ**: የእዝዝ መዋቅር
5. **ጊዜ** (Tempus):
1. **ፕረዘንስ**: የአሁኑ ጊዜ
2. **ኢምፐርፌክት**
3. **ፐርፌክት**
4. **አዮሪስት**
5. **ፉቹር**: የወደፊት ጊዜ
6. **ኮንዲሽናል**

ጊዜያቱ ከቴምፑስ መሰረቶች ይመነጫሉ: ፕረዘንስ መሰረት፣ አዮሪስት መሰረት፣ ፐርፌክት መሰረት፣ ፉቹር መሰረት።


## 6.3. ኢንዲኬታቭ ፕረዘንስ (laṭ = ⟪लट्⟫)

ፕረዘንስ የአሁኑ ጊዜ ቃል ነው፣ በተለይም የቆየ ጊዜን ያመለክታል።

::: grammar-box

## 6.6. ዝተዛረበ ሳንስክርት፡ ካልእ ሕቶታት (praśna ስም = ⟪प्रश्न⟫)

::: grammar-box

**N. N. kiṃ karoti?** = N.N. ⟪किं करोति⟫ = "N. N. እንታይ ይገብር?"
**N. N. (plural) kiṃ kurvanti?** = N.N. ⟪किं कुर्वन्ति⟫ = "N.N.s እንታይ ይገብሩ?"
(karoti, kurvanti ን **kṛ** = ⟪कृ⟫ 8 U: "ግበር፣ ስራሕ")
**kiṃ kuśalam?** = ⟪किं कुशलम्⟫ = "ሰላም ኢኻ?፣ እንታይ ይመስል?"
መልሲ: **sarvathā kuśalam** = ⟪सर्वथा कुशलम्⟫ = "(ኣነ) ኣብ ኩሉ ረቀሒ ሰላም እየ።"

:::

## 6.7. ቃላት ዝርዝር

::: grammar-box

በሳንስክርት ቋንቋ ግጥሚያዎች በ**መነሻ-ቅርፅ** ይቀርባሉ። በመነሻው ከኋላ የሚቀርበው ቁጥር **የመዛመድ ክፍልን** ያሳያል።
