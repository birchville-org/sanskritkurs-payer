# ክፍሊ 15

## 15.1. ⟪सुभाषितम् गुरुशुश्रूषया विद्या पुष्कलेन धनेन वा । अथवा विद्यया विद्या चतुर्थी नैव विद्यते ॥⟫

## 15.2. Determinativkomposita = Tatpuruṣa m. = ⟪तत्पुरुष⟫

ርክብ በስም (ሰማዊ እና ቅጽል) የተገለጹ ነገሮች እርስ በርስ ሊገለፅ ይችላል፣ ከጀነቲቭ ግንኙነት በተጨማሪ በTatpuruṣa (⟪तत्पुरुष⟫) ሊገለፅ ይችላል። በተመሳሳይ ሁኔታ ቅጽሎችን ወይም በተዛማጅ መልኩ ስሞችን ለመዛመድ በተለየ ዓይነት Tatpuruṣa ማለትም በKarmadhāraya (m.) = ⟪कर्मधारय⟫ ሊጠቀም ይችላል።

⟪तत्पुरुषः⟫ =  ⟪तस्य पुरुषः⟫ "የእግዚአብሔር አገልጋይ" ማለትም ይህ የኮምፖዚታ ምርት እንደ ዓይነት ኮምፖዚታ ምሳሌ ያስገኛል።

::: grammar-box

በDeterminativkomposita (Tatpuruṣa) ውስጥ ስም (ሰማዊ እና ቅጽል) በሌላ ስም ወይም በአዮብ ተጨማሪ ግልጽነት ይኖረዋል። የተጨማሪ ግልጽነት ያለው ቃል በተለምዶ የኮምፖዚታ ክፍል ይሆናል።

የቅድመ ክፍል (Determinativkomposita) እና የኋለኛ ክፍል (Determinativkomposita) ርክብ ሊሆን ይችላል፡

*   ቅጽላዊ ወይም በተዛማጅ መልኩ፡ ኮምፖዚታውን ሲያስተካክሉ ቅድመ ክፍል የኋለኛውን ክፍል በተመሳሳይ ሁኔታ (ማለትም ከጥያቄው ውጭ በNominativ (⟪प्रथमा⟫) ውስጥ በሆነ ሁኔታ) የተጨማሪ ግልጽነት ይኖረዋል
*   kasuell፡ ቅድመ ክፍል በኮምፖዚታው ሲያስተካክል በሌላ ሁኔታ ውስጥ ነው (ማለትም በNominativ - ⟪प्रथमा⟫ ውስጥ አይደለም)
*   adverbial፡ ቅድመ ክፍል የማይቀየር ቃል ነው

ግንኙነት ዘነገር ዘክልኤቱ ክፍላት ዘውሕድ ቃል ኢይትአዘዝ በዝንቱ ነገር ዘውሕድ ቃል ይትረከብ፡ እስመ ውሕድ ቃል ውእቱ ቃል ዘይትነገር፡

z. B.

> Nom. sg. ⟪तत्पुरुषः⟫ = ⟪तस्य पुरुषः⟫  
> Akk. sg. ⟪तत्पुरुषम्⟫ = ⟪तस्य पुरुषम्⟫

> Gen. sg. ⟪तत्पुरुषस्य⟫ = ⟪तस्य पुरुषस्य⟫  
> Nom. pl. ⟪तत्पुरुषाः⟫ = ⟪तस्य पुरुषाः⟫  
usw.

## ፲፭.፬. ውሕድ ቃላት ዘወሰን ምስለ ቅድመይቱ ክፍል ዘሎቱ ምስለ ድኅረይቱ ክፍል በግንኙነት ዘነገር ዘኢይትወሰን/ዘኢይትወሰን = ታትፑሩሡ በጠባብ ትርጉም

::: grammar-box

ውህደታት ታትፑሩሻ ይከኣሉ ንውህደታት ኣስማት (ስሞች ወግሩም ስሞች)፣ እቲ ቅድመ-ክፍል - ብመሰረት ሕግታት ኣገባብ - ኣብ ዝኾነ ፍጻሜ ክኸውን ይኽእል። ከም ትጽቢት፣ እቲ ቅድመ-ክፍል ኣዝዩ ብዙሕ ግዜ ፍጻሜ ንብረት (⟪षष्ठी⟫) ይውክል፣ ከመይሲ እዚ እዩ እቲ ፍጻሜ ንዝምድና ኣስማት ንምግላጽ።

:::

z.B.

⟪क्षत्रियपुत्रः⟫ = ⟪क्षत्रियस्य पुत्रः⟫ = "ወዲ ኽሻትሪያ"፣ "ሓደ ንእሽቶ ኽሻትሪያ"፣ "ሓደ ኣባል ጉጅለ ኽሻትሪያታት"
ፍጻሜ ቀጥታዊ ግብሪ ነጠላ ⟪क्षत्रियपुत्रम्⟫
ፍጻሜ ንብረት ነጠላ ⟪क्षत्रियपुत्रस्य⟫
ወዘተ.

⟪गुरुभावः⟫ = ⟪गुरोर्भावः⟫ = "ባህሪ መምህር"

⟪धनलोभः⟫ = ⟪धनस्य लोभः⟫ = "ትምኒት ሃብቲ፣ ስስዔ"

⟪लोकगतिः⟫ = ⟪लोकस्य गतिः⟫ = "ኣካይዳ ዓለም፣ ባህሪ ሰባት"

በአብዛኛው የጄነቲቭ ግንኙነት በታትፑሩሻ (Tatpuruṣa) ሊተካ ይችላል። የቀሩትን ስርዓተ-ክስተቶች እንደ ካል (Kale)፣ A higher Sanskrit grammar § 211 ይመልከቱ፣ እዚያም በፓኒኒ (Pāṇini) ላይ ተመሳሳይ ክፍለ-ቃላት ይገኛሉ።

ነገር ግን የታትፑሩሻ (Tatpuruṣa) ቅድመ-ክፍል በንብረት ሁሉንም ኬሳስ (Kasus) መወከል ይችላል። ነገር ግን ሁሉም በስነ-ቃል (syntactically) የተፈቀዱ ኬሳስ ግንኙነቶች በታትፑሩሻ (Tatpuruṣa) ሊተኡ አይችሉም። ተዛማጅ ሕጎችን በረግጠኛነት ላይ ካል (Kale)፣ A higher Sanskrit grammar § 203 - 217 ወይም ፓኒኒ (Pāṇini) 2,1,22 - 2,2,22 ይፈልጉ።

::: grammar-box

የቅድመ-ክፍሉ ክፈት በአንዴቁም (Singular)፣ ዱኤል (Dual) ወይም ብዴቁም (Plural) ሊሆን ይችላል። የትኛው አማራጭ እንዳለ ከቃል ትርጓሜ እና ከአውድ መተንበይ ያስፈልጋል።

:::

ምሳሌዎች፡

የቅድመ-ክፈሉ አኩዛቲቭ (⟪द्वितीया⟫) ይወክላል፡ ለምሳሌ በተለይ ከእንቅስቃሴ ስም (PPP) ጋር የተያያዙ ቃላት (ፓኒኒ 2,1,24)፡

⟪ग्रामगतः⟫ = ⟪ग्रामं गतः⟫ = "ወደ ጎበዝ የሄደ"  
⟪नरकपतिता⟫ = ⟪नरकं पतिता⟫ = "ወደ ጊዜያት የፈረሰች"

የቅድመ-ክፈሉ ኢንስትሩማቲቭ (⟪तृतीया⟫) ይወክላል፡ ለምሳሌ ብዙውን ጊዜ አጀንስ (⟪कर्तृ⟫) ነው፣ በክርት-ሶፊክስ (kṛt-Suffixes) ስም ቅርጾች (ለምሳሌ PPP) ውስጥ፡

⟪देवकृतम्⟫ = ⟪देवेन⟫ / ⟪देवैः कृतम्⟫ = "በእግዚአብሔር / በእግዚአብሔራን የተሰረ"  
እንዲሁም ሊከፋፈል ይችላል፡ ⟪देवस्य⟫ / ⟪देवानां कृतम्⟫ = "የእግዚአብሔር / የእግዚአብሔራን ስራ / ተግባር ; የእግዚአብሔር ስራ"  

⟪बुद्धरक्षिता⟫  = ⟪बुद्धेन रक्षिता⟫ = "የቡዳን በሚጠበቅ" (ስም)
