# ክፍለ ቃል 14

## 14.1. የሚገለጸውን ግንኙነት በስም ቃላት፡ የመታወቂያ (Genetiv) ጥምረት (ṣaṣṭhī f. = ⟪षष्टी⟫ = ሻድሻይኛ የመታወቂያ መጨረሻ)

::: grammar-box

ሁለት ስም ቃላትን በመጠቀም የሚገለጸው ግንኙነት ከመጠቀም የሚያስፈልግ ከመታወቂያ (Genetiv) ጥምረት ነው። የመታወቂያ ጥምረት ከሁሉም ሌሎች የመታወቂያ መጨረሻዎች ጋር በተለየ መልኩ ነው። ይህ ጥምረት በአብዛኛው ከተግባር ስም ቃላት ጋር በተያያዘ ነው። ይህ ጥምረት በተለይ ከሚገልጸው ስም ቃላት ጋር በተያያዘ ነው። ብዙውን ጊዜ የመታወቂያ ጥምረት በጥያቄው "የማን?" ይገለጻል።

:::

ምሳሌዎች፡-

⟪कवेः पुत्रः⟫ "የግጥም ሰው ልጅ"

⟪धनस्य लोभः⟫ "የብዛት ምኞት"

⟪नगरस्यार्धम्⟫ "የከተማው ግማሽ"

⟪रामस्य कृतम्⟫ "የራማ ተግባር"

::: grammar-box

መደበኛው የቃላት ቅደም ተከተል፡-

> **በመታወቂያ ጥምረት ውስጥ ያለው ቃል — በሌላ የመታወቂያ መጨረሻ ውስጥ ያለው ስም ቃል**

:::

**የመታወቂያ ጥምረት እና PPP፡-**

::: grammar-box

በ PPPs ውስጥ የመታወቂያ ጥምረት ከመጀመሪያ (tṛtīyā) ጥምረት ይልቅ ሊጠቀም ይችላል። በመጀመሪያ ጥምረት ውስጥ PPP እንደ ተጨማሪ የተግባር ስም ቃል ይቆጠራል (በመጀመሪያ ጥምረት ውስጥ ያለው ቃል ነጻ ሰውን ይወክላል)። በመታወቂያ ጥምረት ውስጥ PPP እንደ ስም ቃል ወይም ቅጽበት ቃል ይቆጠራል (በመታወቂያ ጥምረት ውስጥ ያለው ቃል በእርግጥ ነጻ ሰውን አይወክልም)።

በ Pāṇini 2.3.67 መሰረት PPP ላይ የመታወቂያ ጥምረት ይጠቀማል፣ PPP የአሁን ጊዜ ትርጓሜ ካለው (እንደ ላይ)፣ መጀመሪያ ጥምረት ይጠቀማል፣ PPP የድንገተኛ ጊዜ ትርጓሜ ካለው፡-

> ⟪रामस्येष्टं फलम्⟫ "የራማ የተፈለገው ፍሬ = ዛሬ በራማ የተፈለገው ፍሬ"
> 
> ⟪रामेणेष्टं फलम्⟫ "ራማ የፈለገው ፍሬ"

በተፈጥሮም ስለ PPP ኒውትረም ሲንጉላር እንደ ቃል-አስተምሮ (Verbalabstraktum) - ማለትም እንደ ቃል (Substantiv) - በሚጠቀምበት ሁኔታ የጀነቲቭ (Genetiv) ይሆናል።

:::

## 14.2. የጀነቲቭ ቅርጾች (ṣaṣṭhī f. = ⟪षष्ठी⟫) መፈጠር

::: important

ኵሎሙ፡ ቃላት፡ ስም፡ ዘእንበለ፡ ተባዕታይ፡ ወኣንስታይ፡ ዘይትፈጸም፡ በ-a፡ ወቃላት፡ መርአያ፡ ውእቱ፡ መልክዕ፡ ግዕዛዊ፡ ጾታ፡ ሓደ፡ ቁጽር፡ ዘከመ፡ መልክዕ፡ ንብረት፡ ጾታ፡ (pañcamī "ሓምሳዊ፡ ፍጻሜ፡ ቃላት፡") ሓደ፡ ቁጽር፡!

ልብ ይበሉ፣ በድምጺ-መጨረሻ ስርዓቶች ውስጥ አቤለቲቭ እና ጀኔቲቭ ነጠላ ቁጥር ከአኩዬቲቭ ብዙ ቁጥር ማስኩሊንም እና ፌሚኒነም ጋር ተመሳሳይ ነው።

:::

## 14.3. ስለ ጀኔቲቭ ተጠቃሚነት ተጨማሪ (⟪षष्ठी⟫)

::: grammar-box

በተቃራኒ፡ እምነ፡ ሕግ፡ ላዕላይ፡ ግዕዛዊ፡ ጾታ፡ ይትረከብ፡ ለገላጺ፡ ንብረት፡ ቃላት፡ ግስ፡ ከም፡ ንኣብነት፡ ምስ፡ ቃላት፡ ግስ፡ ዘመዘክር፡

> ⟪देवानां स्मरति⟫ "እሱ የገዛ እግዚአብሔርን ያስታውሳል"

በእነዚህ ቃላት ሁሉ ውስጥ ነገር ቢኖር በአኩዬቲቭ ሊሆን ይችላል፡-

> ⟪देवान्स्मरति⟫ "እሱ የገዛ እግዚአብሔርን ያስታውሳል"

ተጨማሪ በኋላ ይመጣል።

:::

## 14.5. Subhāṣitāni = ⟪सुभाषितानि⟫ = ገላጭ ቃላት

የሚከተሉትን ገላጭ ቃላት ያስተውሉ እና በአእምሮዎ ውስጥ አስቀምጧቸው፡

**⟪नीचो वद⟫ati ⟪न कुरुते⟫** **⟪वदति न साधुः करोत्येव ॥१॥⟫**

**⟪शीलं नरस्य भूषणम् ॥२॥⟫**
