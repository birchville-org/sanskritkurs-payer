# ክፍለ ቃል 12


## 12.1. ምስረታ ተዋጽኦ ንጹር ስም (PPP)

ሓደ ካብቶም ቃላት ንጹር ስም (PPP) ብምጥቃም ናይ ዝሓለፈ ግዜ ቃላት ንምስራሕ ዝጥቀመሉ መንገዲ እዩ።

::: grammar-box

**ብሓቂ እቲ PPP ምስረታ ተዋጽኦ ንጹር ስም (PPP) እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ ስም ዝተዋህበ ቃል እንተዘይኮነስ፣ ካብ

### ፲፪.፩.፩. ሥርዓተ ግስ ዘይትዐደው

::: grammar-box

**ገብሪ (ከርቱር) በኀይለ-መሣርያ (ትርቲያ) -- ቅቡል ነገር (ከርመን) በስም-አመላካቲ (ፕረተማ) -- ተፈጻሚ ግስ ዘሓለፈ ግዜ**

በዝንቱ ነገር፣ ተሳቢ ግስ ዘኀለፈ ጊዜ ይትዋሐድ ምስለ ተሳቢ በቍጽር፣ በዐውድ ወበጾታ።

ግስ ዘይትረድእ ("ኮነ") ኢይትአዘዝ።

Examples:
> **sādhunā svarga āptaḥ** = ⟪साधुना स्वर्ग आप्तः⟫ = „(Vom Heiligen wurde ein Himmel erlangt) = Der Heilige hat einen Himmel erlangt.“
> 
> **brāhmaṇena devīṣṭā** = ⟪ब्राह्मणेन देवीष्टा⟫ = „(Vom Brahmanen wurde die Göttin mit einem Opfer verehrt) = Der Brahmane hat die Göttin mit einem Opfer verehrt.“

:::

### ፲፪.፩.፪. ሥርዓት ፩ ለግስ ዘኢይትዐደው ወለግስ ዘእንቅስቃሴ

::: grammar-box

**ገብሪ (ከርቱር) በስም-አመላካቲ (ፕረተማ) -- ተፈጻሚ ግስ ዘሓለፈ ግዜ**

በዝንቱ ነገር፣ ተሳቢ ግስ ዘኀለፈ ጊዜ ይትዋሐድ ምስለ ፈጻሚ በቍጽር፣ በዐውድ ወበጾታ። ተሳቢ ግስ ዘኀለፈ ጊዜ "ተገብሮ" ለግስ ዘኢይትዐደው (ግስ ዘአልቦ ተሳቢ ቀጥተኛ) ወለግስ ዘእንቅስቃሴ ትርጉም ዘፈጻሚ አለው።

ምሳሌ:
> **kṣatriyā nagaraṃ gatā** = ⟪क्षत्रिया नगरं गता⟫ = „እታ ኽሻትርያ ናብ ከተማ ኸይዳ።“

:::

### 12.1.3. المخطط الثاني للأفعال اللازمية وأفعال الحركة

::: grammar-box

**الفاعل (kartṛ) في الآلة (tṛtīyā) -- اسم المفعول الماضي في حالة الرفع المفرد المحايد**

مثال:
> **kṣatriyeṇa (nagaraṃ) gatam** = ⟪क्षत्रियेण⟫ (⟪नगरं⟫) ⟪गतम्⟫ = „(ذهب من قبل الكشاتريا إلى المدينة) = ذهب الكشاتريا (إلى المدينة).“

بناء المخطط الثاني أقل شيوعاً بكثير من بناء المخطط الأول.

:::

## 12.2. حول معنى اسم المفعول الماضي (PPP)

بينما يحمل ما يُسمى „اسم المفعول الماضي“ للأفعال المتعدية في المقام الأول معنى المبني للمجهول (**āpta** = „تم الوصول إليه“) وللأفعال اللازمية وأفعال الحركة معنى المبني للمعلوم (**gata** = „ذهب“)؛ هناك بعض الأفعال التي يمكن أن يحمل فيها اسم المفعول الماضي معنيين: المبني للمعلوم والمبني للمجهول:

على سبيل المثال
**gata** = ⟪गत⟫ = „ذهب“ (مبني للمعلوم)؛ ولكن أيضاً: **gato mārgaḥ** = ⟪गतो मार्गः⟫ = „طريق قد سلك“ (مبني للمجهول)
**āpta** = ⟪आप्त⟫ = „تم الوصول إليه“ (مبني للمجهول)، „ذو الوصول/البلوغ“ (مبني للمعلوم)


## 12.3. تكوين اسم المفعول الماضي (PPP)

::: grammar-box

توجد طرق التكوين التالية (يجب حفظ اسم المفعول الماضي لكل جذر!):

**(في الغالب) الجذر في درجة الصوت المنخفضة (Guna/Vriddhi context implies low grade root here)**

**+ -ta**
مع حرف ربط **-i-** قبله: **-ita**
بدون حرف ربط: **-ta**
**+ -na**

تصريف مذكر المؤنث: **-tā**، **-itā**، **-nā**؛ ويصرف المحايد مثل **phala** محايد.

:::

## 12.4. ሕግታት ናይ ቃላዊ ምውህሃድ ድምጺ

በ*aniṭ*-አሠራር፣ እሉ ሕግጋት ዘድምፅ ውሕደት በቃለ ይትዐቀቡ። **እሉ ሕግጋት ለመረዳት ኵሉ ሥርዓተ ቃላት ዘሳንስክሪት እሙንቱ እጅግ አገብርት።**

::: no-header

| | |
| :--- | :--- |
| **1. k, t, p before voiceless stop (e.g. t, th) remain unchanged:** | **pt, tt, kt** = **⟪प्त्⟫, ⟪त्त्⟫, ⟪क्त्⟫** |
| **2. ct is replaced by kt = ⟪क्त्⟫:** | **muc + ta » muk-ta** = ⟪मुक्त⟫ |
| **3. śt is replaced by ṣṭ = ⟪ष्ट्⟫:** | **dṛś + ti » dṛṣṭi** = ⟪दृष्टि⟫ :br **dṛś + ta » dṛṣṭa** = ⟪दृष्ट⟫ :br **viś + ta » viṣṭa** = ⟪विष्ट⟫ |
| **4. Voiced unaspirated stop – except j – before a voiceless sound is replaced by the corresponding voiceless unaspirated sound:** | **d + t(h) » tt(h)** = **⟪त्त्⟫, ⟪त्थ्⟫** (important for the 2nd conjugation class) |
| **5. jt is replaced by kt or ṣṭ (not optional!):** | **yuj + ta » yuk-ta** = ⟪युक्त⟫ :br **yaj + ta » iṣ-ṭa** = ⟪इष्ट⟫ (\< \*yj-ta):br **sṛj + ta » sṛṣ-ṭa** = ⟪सृष्ट⟫ :br **sṛj + ti » sṛṣ-ṭi** = ⟪सृष्टि⟫ |
| **6. Voiced aspirated stop + voiceless stop » voiced unaspirated stop + voiced aspirated stop (Bartholomae’s Law of Aspirates):** | **bh-t » b-dh:** :br **labh + ta » lab-dha** = ⟪लब्ध⟫ :br **dh-t » d-dh:** :br **budh + ta » bud-dha** = ⟪बुद्ध⟫ :br **yudh + ta » yud-dha** = ⟪युद्ध⟫ :br **krudh + ta » krud-dha** = ⟪क्रुद्ध⟫ |
| **7. h-t is replaced by ḍh with lengthening of a preceding i or u; or by gdh.
