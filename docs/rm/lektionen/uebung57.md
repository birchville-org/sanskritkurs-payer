# Lecziun 57

## A) Aorist-Transformaziuns

Traducir e determinar las suandantas formas e furmar las correspundentas formas dal **Aorist**. A maun da Causativs e radichas, che furman l'**aorist-s**, è en parentesis la classa dal aorist correspundent indicada:

::: grammar-box
| Nr. | Form | Determinaziun / Significaziun | Aorist |
|:---|:---|:---|:---|
| १. | **पेचिथ** | *पच्* 1U: 2. Sg. Perf. P. (ti has custodì) | **अपाक्षीः** |
| २. | **अवक्** (३) | *वच्* 2P: 2. 3. Sg. Impf. P. (ti has dischì / el ha dischì) | **अवोचः / अवोचत्** |
| ३. | **सोष्यसि** | *सु* 1/2P: 2. Sg. Fut. P. (ti naschiras) | **असौषीः** |
| ४. | **छिन्दे** | *छिद्* 7U: 1. Sg. Ind. Präs. Ā. (jau tagli) | **अच्छित्सि** |
| ५. | **कुरुषे** | *कृ* 8U: 2. Sg. Ind. Präs. Ā. (ti fas en tes agen interes) | **अकृथाः** |
| ६. | **आधत्ते** | *आ-धा* 3Ā: 3. Sg. Ind. Präs. Ā. (el posiziescha) | **आधित** |
| ७. | **पद्यते** | *पद्* 4Ā: 3. Sg. Ind. Präs. Ā. (el va) | **अपादि** |
| ८. | **जिगाय** | *जि* 1P: 1. 3. Sg. Perf. P. (jau hai vitgì / el ha vitgì) | **अजैषीत्** |
| ९. | **जिघ्रामः** (१,६) | *घ्रा* 1P: 1. Pl. Ind. Präs. P. (nus odin) | **अघ्रास्म / अघ्राम** |
| १०. | **शासति** (२) | *शास्* 2P: 3. Pl. Ind. Präs. P. (els cumandan) | **अशिषन्** |
| ११. | **स्तुवे** | *स्तु* 2U: 1. Sg. Ind. Präs. Ā. (jau laud) | **अस्तोषi** |
| १२. | **दिग्धे** | *दिह्* 2U: 3. Sg. Ind. Präs. Ā. (el unctescha) | **अदिग्ध** |
| १३. | **प्लवध्वे** | *प्लु* 1Ā: 2. Pl. Ind. Präs. Ā. (vos nadais) | **अप्लोढ्वम्** |
| १४. | **तस्थिथ** (१) | *स्था* 1P: 2. Sg. Perf. P. (ti has stà) | **अस्थाः** |
| १५. | **बिभ्यति** | *भी* 3P: 3. Pl. Ind. Präs. P. (els han tema) | **अभैषुः** |
| १६. | **ततर्प** | *तृप्* 4/6P: 1. 3. Sg. Perf. P. (jau / el ha satgà) | **अतार्प्सीत् / अत्राप्सीत्** |
| १७. | **जुहुथ** | *हु* 3P: 2. Pl. Ind. Präs. P. (vos offrits) | **अहौष्ट** |
| १८. | **ऊषुः** | *वस्* 1P: 3. Pl. Perf. P. (els han abità) | **अवात्सुः** |
| १९. | **ससर्जिथ** | *सृज्* 6P: 2. Sg. Perf. P. (ti has creat) | **अस्राक्षीः** |
| २०. | **लिल्यिरे** | *ली* 4Ā: 3. Pl. Perf. Ā. (els sa struschin) | **अलेषत / अलासत** |
| २१. | **अत्याजयम्** | *त्यज्* 1P: 1. Sg. Impf. P. Kaus. (jau hai laschà bandunar) | **अतित्यजम्** |
| २२. | **सिध्यथ** (२) | *सिध्* 4P: 2. Pl. Ind. Präs. P. (vos essas al objectiv) | **असिधत** |
| २३. | **निन्य** | *नी* 1U: 2. Pl. Perf. P. (vos avais guidà) | **अनैष्ट** |
| २४. | **कर्षन्ति** | *कृष्* 1P: 3. Pl. Ind. Präs. P. (els tiran) | **अकार्क्षुः / अक्राक्षुः** |
