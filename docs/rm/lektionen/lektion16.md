# Lecziun 16

## 16.1. Al sandhi da consonantas finalas

Per la furmaziun da cumponiments, cun ils quals il element avant ha stems che fineschan cun consonanta, ha basegn da las suandantas reglas:

Consonantas declusivas gutturales, retroflesas, dentals e labialas finalas (i.e. nagins nasals e nagins palatales).

::: no-header

|   |   |
| :--- | :--- |
| **en pausa e davant sons sord** | **Sustituziun cun il son sord non-aspirà correspundent:** :br **p.ex.** :br :indent -g + p- » -kp- :br :indent -d + ph- » -tph- :br :indent -dh + p- » -tp- |
| **davant sons sonants non-nasals** | **Sustituziun cun il son sonor non-aspirà correspundent:** :br **p.ex.** :br :indent -t + g- » -dg- :br :indent -k + b- » -gb- :br :indent -dh + d- » -dd- :br :indent -k + a- » -ga- |
| **davant nasals** | **Sustituziun cun il nasal correspundent:** :br **p.ex.** :br :indent -t + n- » -nn- :br :indent -p + n- » -mn- |

:::

Consonanta declusiva dentala finala (nagin nasal):
