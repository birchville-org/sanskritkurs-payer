# Leziun 16

## 16.1. Dal Sandhi da consonants finalas

Per furmar cumponids, cun in prim element che furma stins consonantics, ha bisugna da las suandantas reglas:

Consonants finalas gutturals, retroflexas, dentals e labials (d.h. nagins nasals e nagins palatais).

:::: grammar-box

::: no-header

| :--- | :--- |

| **avant consonants sonoras non-nasalas** | **Sustituziun cun il consonant sonor correspundent, non-aspirà:** [[br]] **p.ex.** [[br]] [[indent]] -t + g- » -dg- [[br]] [[indent]] -k + b- » -gb- [[br]] [[indent]] -dh + d- » -dd- [[br]] [[indent]] -k + a- » -ga- |
| **avant nasals** | **Sustituziun cun il nasal correspundent:** [[br]] **p.ex.** [[br]] [[indent]] -t + n- » -nn- [[br]] [[indent]] -p + n- » -mn- |

Exemples:

तद् + फल = तत्फल

पुण्यवत् + ब्राह्मण = पुण्यवद्ब्राह्मण

पुण्यवत् + नर = पुण्यवन्नर

पुण्यवत् + पुरुष = पुण्यवत्पुरुष

सत्यवत् + चैतन्य =सत्यवच्चैतन्य

सुखवत् + लोक = सुखवल्लोक

पुत्रवत् + जन = पुत्रवज्जन

बलवत् + शत्रु = बलवच्छत्रु
