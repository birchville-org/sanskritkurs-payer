# Lecziun 31

## 31.1. La 7. classa da presens (रुधादि = "रुध् e.c.")

:::: grammar-box
**Furmaziun:**

**Davant ils consonants da final da la radis cun ton profund vegn inserì in cun num «nasalinfix» (-na- resp. -n-):**

*   **en la radis ferma: -na-**
*   **en la radis debila: -n-**

**Per la connexiun dals consonants da final da la radis cun desinenzas che cumenzan cun consonant valan las medemas reglas sco per la 2. classa da presens.**
::::

Exempels:

युज् 7U "colliar, attachar"

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicativ** | **3. sg.** | युनक्ति[[br]]yu-na-j + -ti | युङ्क्ते[[br]]yu + n + j + te[[br]](davant consonants gutturals en l'intern da la parola vegnan nasals remplazzads cun -ṅ-) |
| | **3. pl.** | युञ्जन्ति[[br]]yu + n + j-anti | युञ्जते[[br]]yu + n + j-ate |
| **Optativ** | **3. sg.** | युञ्ज्यात्[[br]]yu + n + j-yā-t | युञ्जीत[[br]]yu + n + j-ī-ta |
| | **3. pl.** | युञ्ज्युर्[[br]]yu + n + j-y-ur | युञ्जीरन्[[br]]yu + n + j-ī-ran |
| **Participi presens** | | युञ्जन्त्-[[br]]yu + n + j-ant-[[br]]fem.: युञ्जती[[br]]yu + n + j-at-ī | |

::::

रुध् 7U "fermar, fermar"

:::: grammar-box

| | | Parasmaipada | Ātmanepada |
| :--- | :--- | :--- | :--- |
| **Indicativ** | **3. sg.** | रुणद्धि[[br]]ru + na + dh + ti | रुन्द्धे[[br]]ru-n + dh + te |
| | **3. pl.** | रुन्धन्ति[[br]]ru-n-dh-anti | रुन्धते[[br]]ru-n-dh-ate |
| **Optativ** | **3. sg.** | रुन्ध्यात्[[br]]ru-n-dh-yā-t | रुन्धीत[[br]]ru-n-dh-ī-ta |
| | **3. pl.** | रुन्ध्युर्[[br]]ru-n-dh-y-ur | रुन्धीरन्[[br]]ru-n-dh-ī-ran |
| **Participi presens** | | रुन्धन्त्-[[br]]ru-n-dh-ant-[[br]]fem.: रुन्धती[[br]]ru-n-dh-at-ī | |

::::

:::: grammar-box
**Cun quai che radis èn il -n- dal stem da presens debil er penetrà en tempus extra-presens, uschia che questas radis vegnan supponidas cun nasalinfix.**
::::

Exempl:

**भञ्ज्** 7P "fracturar"

::: indent
*   Indicativ presens
    *   3.sg.P. **भनक्ति** (bha-na + j + ti)
    *   3.pl.P. **भञ्जन्ति** (bha + n + j-anti)
*   Futur: **भङ्क्ष्यति** (bha + n + j + sya + ti)
*   Passiv: **भज्यते** (u dal stem da radis originar **भज्** u da *bhñj-ya-te)
*   PPP: **भग्न** (event. da *bhñj + na)
:::
