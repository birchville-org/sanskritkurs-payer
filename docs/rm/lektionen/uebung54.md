# Lecziun 54

Furmà il correspundent aorist per las suandantas formas da present u perfet:

::: grammar-box
| Nr. | Form | Determinaziun / significà | Aorist |
|:---|:---|:---|:---|

| २. | **पिबामि** | jau biva | **अपाम्** |
| ३. | **ददौ** | jau hai / el ha dà | **अदाम् / अदात्** |
| ४. | **बभूव** | jau / el / ella era / vus essas | **अभूवम् / अभूत् / अभूत** |

| ६. | **ऐम** | nus èn ids | **अगाम** |

| ८. | **तिष्ठति** | el stà | **अस्थात्** |
