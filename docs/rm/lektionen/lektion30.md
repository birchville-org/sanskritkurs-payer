# Lektion 30

## 30.1. La 9. classa dal temp preschent (⟪kryādi⟫ = "⟪krī⟫ e.u.v.")

::: grammar-box
**Educaziun:**

*   Stamm stark: Wurzelniveau tief + -nā-

*   stem debole:

    *   avant consonant: Rad in bassu nivell + -nī-

    *   avant vocal: radice a bassu nivell + -n-
:::
Esempel:

::: indent
⟪क्री⟫ 9U "cumprar"
:::
::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪क्रीणाति⟫:br(krī + nā + ti) | ⟪क्रीणन्ति⟫:br(krī + n + anti) |
| **3. Person:brĀtmanepada** | ⟪क्रीणीते⟫:br(krī + nī + te) | ⟪क्रीणते⟫:br(krī + n + ate) |

:::
En questa classa da prezens è da observar specialmain la furmaziun dal stem da prezens per la radis ⟪ज्ञा⟫ 9U "reconuscher, savair":

::: grammar-box

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |
| :--- | :--- | :--- |
| **3. Person:brParasmaipada** | ⟪जानाति⟫:br(jā-nā-ti) | ⟪जानन्ति⟫:br(jā-n-anti) |
| **3. Person:brĀtmanepada** | ⟪जानीते⟫:br(jā-nī-te) | ⟪जानते⟫:br(jā-n-ate) |

:::
La furma ⟪जा⟫, ch’è alla basa dal stemma dal present da ⟪ज्ञा⟫, po vegnir explicada u tras ina serie da ablaut -ā (stadi bass) -nā (stadi aut), u tras dissimilaziun da *jñā-nā-ti.

Quai radis cun vocal lunga curtgian questa avant il suffix dal stadi da presens da la 9. classa:

Esempel:

::: indent
⟪पू⟫ 9U "purifitgar"
:::

| | Singular:br⟪एकवचन⟫ | Plural:br⟪बहुवचन⟫ |

| **3. Person:brParasmaipada** | ⟪पुनाति⟫:br(pu-nā-ti) | ⟪पुनन्ति⟫:br(pu-n-anti) |
| **3. Person:brĀtmanepada** | ⟪पुनीते⟫:br(pu-nī-te) | ⟪पुनते⟫:br(pu-n-ate) |

:::

Esempel:

## 30.2. Usgo dal Optativ (⟪लिङ्⟫)

L'optativ vegn adina

::: grammar-box
**1. per designaziun**

*   **d'in desideri**
*   **d'in desideri**
*   **d'ina petiziun**

**(quai quai il optativ - ⟪⟪लिङ्⟫ - cun l'imperativ - ⟪⟪लोट्⟫ -)**
:::
Ezempli:

::: indent
⟪⟪दासो⟫⟫ ⟪⟪ग्राममागच्छेत्⟫⟫ = "Che servus vegnia al vitg"
:::
::: grammar-box
**2. Sche quai sco**

*   **possìbel**
*   **probablamain**
*   **probablamain**

**dargestellt werden soll.**
:::
Beispiel:

::: indent
⟪ग्रामाच्चेद्गच्छेद्गुरुं⟫ ⟪न⟫ ⟪शृणुयात्⟫ = "Scheu ch'el dal vitg, el na udess il maister"
:::
::: grammar-box
**3. Fratschas relativas cun optativ han a vartas il significà: "Sche in ustra ..."**
:::
Esempel:

::: indent
⟪यो⟫ ⟪नृतं⟫ ⟪वदेत्स⟫ ⟪नरकं⟫ ⟪पतेत्⟫ = "Schei na chaschtaivüna, schei na chaschtaivüna = Schei na chaschtaivüna, schei na chaschtaivüna"
:::

## 30.5. Sandhi von auslautendem -r

::: grammar-box
**Per -ar valan las medemas reglas da Sandhi per -r final sco per -s final.**

**-ar vor tönenden Lauten bleibt -ar, vor r- aber fällt das -r aus und das -a- wird durch -ā- ersetzt.**
:::
Exempels:

::: indent
⟪भवेयुर्⟫ + ⟪च⟫ » ⟪भवेयुश्च⟫

⟪पुनर्⟫ + ⟪अग्निः⟫ » ⟪पुनरग्निः⟫

⟪पुनर्⟫ + ⟪रोदिति⟫ » ⟪पुना⟫ ⟪रोदिति⟫
:::
